# Opposite SAT verdicts that collide on every small modulus

The [three-file exhaustion](three-files-for-the-unrestricted-sat-clock.md) calls for opposite-labeled formulas that give identical bounded replies. A genuine part of this search can be carried out without any complexity hypothesis. For every integer $B\ge2$ there are **two equal-length canonical proper 3-CNFs of maximum occurrence four**, one SAT and one UNSAT, with identical byte histograms and identical tagged-integer residues modulo **every integer from 1 to $B$**. Their common bit length can be taken to be $O(B\log B)$. The two files have identical length metadata and physical bit parity. Even for arbitrary binary strings, distinct equal-length strings agreeing on all those residues require $\Omega(B)$ bits. The two strings below can be computed by finite search. The $O(B\log B)$ bound is on the output size.

## Picking the queried bit after the collision

Let $M=\operatorname{lcm}(1,\ldots,B)$. Write $\Lambda(t)=\operatorname{lcm}(1,\ldots,t)$. We have $2^B/(B+1)\le M<2^{4B}$. For the lower estimate, each binomial coefficient of order $B$ divides $M$ by the prime valuation formula; their sum is $2^B$. For the upper estimate, $\Lambda(2t)/\Lambda(t)$ divides $\binom{2t}t$. Each new prime power in $(t,2t]$ contributes just its prime to the ratio and that prime divides the binomial coefficient, again by the valuation formula. Multiply the estimates $\binom{2t}t\le2^{2t}$ at doubling values of $t$ up to the first power of two at least $B$. Two distinct strings of equal length $N$ give distinct tagged binary integers less than $2^{N+1}$; their nonzero difference is less than $2^N$. Divisibility by $M$ implies $N>\log_2 M$.

Use a power of two $r$ between $8B+16$ and $16B+32$. Build a multiplexer with $r$ Boolean data inputs and $\log_2 r$ Boolean index inputs, whose output is the **one selected data bit**. A binary tree of $r-1$ gates conditional on level-specific index bits suffices. Each gate has four proper clauses expressing equivalence to the left or right child under its selector value. Require the root true; this can be done by four proper clauses with two fresh auxiliaries. Apply the same [signed occurrence-copy and one-bit physical input construction](physical-selector-parity-cubes.md) as for parity. Each coordinate chooses ASCII digit 2 or 3 in a fixed byte, sorting and density persist, and every variable has at most four occurrences. The gate count and number of input occurrences are $O(r)$. The whole file therefore costs $O(r\log r)$ bits. Number the data selectors before the index selectors, so all their edited bytes precede the first editable index byte.

Fix a provisional index, and consider masks of Hamming weight $r/2$ for the data. There are $\binom r{r/2}\ge2^r/(r+1)>M$. Two distinct masks give equal residues modulo $M$ for the tagged file. Choose a coordinate on which those masks differ and change the common index to that coordinate in both files. Every index edit adds the same signed power of two to the tagged integer of either file because the bytes at the index positions are identical and independent of the data positions. Thus the congruence survives. The two masks have equal Hamming weights, so even their counts of all 256 byte values agree. The selected data bits now give opposite actual SAT verdicts. This identifies a precise operation missing for general RAM signatures: agreement at a provisional index must survive the **same index edit applied to both files**. A general program can read the new index, then load the selected data word.

The same construction can simultaneously fool a prescribed finite list of deterministic streaming tests that read the file once from left to right. Suppose their combined state has at most $S$ possibilities at the cut just before the first edited index byte, on files of this size. Count the prefix state tuple and the tagged prefix residue together. It suffices to choose $\binom r{r/2}>S M$. After selecting the distinguishing data coordinate, the rest of the file is identical between the two runs, including the newly chosen index, so all final states agree. For a fixed finite product of state spaces, $r=O(B+\log(S+2))$ suffices. This is the ordinary one-way indexing argument with the checksums, byte histogram and individual word locations fixed. Earlier journal work already uses SAT to encode arbitrary tables and indices. [Earlier indexing family and state count](private-probe-contexts-in-read-only-sat.md)

## All affine rolling checksums at bounded moduli

The same data/index choice gives a polynomial-size pair simultaneously defeating *every* update $h\gets u h+f(b)\pmod m$ on successive bytes $b$, where $m\le B$, the base $u$, byte table $f$ and initial residue are arbitrary. For each prime $p\le B$ use its largest power $t_p\le B$. For a data mask $S$, at the provisional index, record
$$
  \sum_{i\in S} u^{e_i}\pmod{t_p}
  \quad\text{for all }0\le u<t_p ,
$$
where $e_i$ counts the physical bytes after the $i$th data digit. The number of bits needed to bound the log of the tuple's range is at most $\sum_p t_p\log_2 t_p\le B\log_2 M=O(B^2)$. Thus $r=O(B^2)$ switches in one equal-weight layer suffice for a collision, giving output length $O(B^2\log(B+2))$ bits. The difference between two rolling hashes is $f(3_{\rm ASCII})-f(2_{\rm ASCII})$ times the difference of these evaluation sums. All other bytes and any initial residue cancel. Common index changes keep the positions and this difference fixed. Project to each required prime power factor of $m$; vanishing there implies vanishing modulo $m$. This is a simultaneous conclusion even for byte maps chosen after seeing the files. There is no corresponding invariance under a RAM's arbitrary indirect loads.

## An algebraic lift from $B$ to $B+1$ that retains the clauses

For ordinary valid DIMACS allowing whitespace, **two changed bits** suffice throughout one nested construction. Force variables 1, 4 and 2 false and variable 3 true by their four-clause pins with helpers 6 and 7. Append two clauses whose third names are the editable digits. The first clause is $(1\lor4\lor z)$ and the second $(\neg1\lor4\lor z')$. In the positive file set $(z,z')=(3,2)$; in the negative file set $(z,z')=(2,3)$. They have the same header, byte histogram and bit length, and only the first clause determines whether a model exists. A one-bit pair can never agree modulo three, so distance two is minimal once $B\ge3$. Changing ASCII 2 to 3 toggles one bit. Every clause is proper.

Read the file's bytes as the digits of a big-endian base-256 integer with a common leading marker. Let $u$ be the number of bytes following the second editable digit and $s$ the byte distance between the two digits. The signed difference of the two tagged integers is exactly
$$
   256^u(256^s-1).
$$
Let $E_B$ be the order of 256 modulo the odd part of $\Lambda(B)$, taking order one for modulus one. Then $E_B\mid E_{B+1}$ and $E_B$ can be found by a finite search. Start with the two unpadded clauses separated by a newline, at digit distance $s_0$. At stage $B$ put $s=s_0 E_B$ by inserting spaces **between complete clauses**, and append enough common whitespace to ensure $8u\ge\lfloor\log_2 B\rfloor$. The odd part divides the second factor in the display and the two-part divides the first. Moving to $B+1$ only inserts common bytes; every old clause and every previous congruence survives, and both verdicts stay opposite. This implements the proposed algebraic successor for an unbounded family of concrete observation programs. A fixed correct solver for the two formula types can test the known positive assignment and the known small negative clause set, with a general fallback. It defeats this lift at linear time on every stage. The long stride can be replaced by the previous many-mask construction if output length matters. [Distance-two construction in canonical degree-four files](two-bit-switches-at-a-prescribed-stride.md)

In the 32-data-bit example a search through 3,479 masks found a pair of 136,018-byte files. Selecting the common index 24 gives opposite SAT verdicts. The smallest modulus separating the files is 43. The [physical audit](switch_index_checksum_audit.py) checks each satisfying assignment directly on the parsed clauses and checks the negative verdict with PicoSAT. The [Lean proof](ChecksumSwitchIndex.lean) checks the finite-mask collision, selection of a differing coordinate and preservation under a common affine change of the digest. The clause construction, asymptotic length bounds and native time of the distinguishing program are manuscript arguments. Historical priority for the combined SAT construction has not been established.
