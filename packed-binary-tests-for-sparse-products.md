# One uniform linear-time SAT path for a growing sparsity range

There is a single deterministic logarithmic-word RAM and a computable threshold
$$
 K(d)=d^{\,1-O(\log\log\log d/\log\log d)}
$$
such that on every compact projected SAT file with $1\le |AB-C|\le K(d)$ it returns SAT in $O(N)$ steps, where $|\cdot|$ counts nonzero entries and $N=\Theta(d^2)$ is the file length in bits. The same program decides SAT correctly on all other files via fallback. Both the program and the constant in its linear clock are independent of any chosen exponent $1-\epsilon$. The proof gives an actual erroneous coordinate within the same clock. On the matrix problem with an external promise $|AB-C|\le K(d)$ it gives an exact deterministic $O(d^2)$ algorithm. For unrestricted triples a zero syndrome is insufficient to certify equality. The method builds on the [fixed-field sparse moment test](uniform-fast-paths-for-sparse-product-errors.md) and the [compact file construction](compact-bit-projection-of-matrix-mismatch.md).

## Binary tests for one digit

Take the matrix side $d=2^t$, padding a general side to the next power of two. Let the lane width $q=2^b$ be the largest power of two no greater than $\min(w/8,t/8)$ for large $d$, where $w=\Theta(\log d)$ is the native word width. Hence $q=\Theta(t)$ and $b=\Theta(\log t)$. Split the $t$ address bits into $\ell=\lceil t/b\rceil$ digits, each with radix $s=2^b$ except for a possible last radix $s=2^{t-b(\ell-1)}$. The product of the radices is exactly $d$.

Choose a binary polynomial basis for $\mathbb F_q$. Label the $s$ positions of a digit by distinct field elements $a$. Take the $s$ extension-field rows $(a^j)_a$ in the order $j=0,\ldots,s-1$, with $0^0=1$. Expand each into $b$ binary rows, one per basis coordinate. Process these binary rows in order, retaining an original row only when independent of earlier retained rows. The retained rows form an invertible binary matrix $T_s$ of order $s$. Indeed the full field Vandermonde is invertible and so its binary component rows have trivial kernel on binary input. Assign each retained row from exponent $j$ a cost $j+1$. The rows are in nondecreasing cost order.

For any nonzero binary vector of weight $h$, one retained row of cost at most $h$ detects it. The Vandermonde on its $h$ distinct support positions has full rank in the first $h$ powers; the retained binary rows from that prefix span every binary component of those powers. Also
$$
       \sum_{i=1}^s 1/\operatorname{cost}(i)\le b H_s\le 2b^2,
$$
since at most $b$ rows come from any exponent. Construct the field by finding an irreducible polynomial of degree $b$ using trial division. All field setup, Vandermonde generation and binary elimination take $\operatorname{poly}(q)$ time. These small field operations occur only during setup. Every transform on matrix data uses binary operations.

## Which tensor rows to inspect

Use the tensor product $T$ of the $\ell$ digit transforms. A tensor row $u_\alpha$ has cost $v(\alpha)$, the product of its digit-row costs. For a nonzero bit array of weight $h$ on any number of digit axes, some tensor row detects it and has cost at most $h$. To prove this, split the array into slices along the first axis. If $p$ slices are nonzero, the lightest nonzero slice has weight $h'\le h/p$. By induction it is detected by some test on the remaining axes of cost at most $h'$. Applying this test to all slices gives a nonzero first-axis bit vector of weight at most $p$. A first-axis test of cost at most $p$ detects it. Their product is a detecting tensor row with cost at most $h$. One axis is precisely the Vandermonde lemma.

Set $L=(2b^2)^{2\ell}$ and, for all sufficiently large $d$, take
$$
          K(d)=\lfloor d/L\rfloor .
$$
There are at most $K(d)L\le d$ pairs with $v(\alpha)v(\beta)\le K(d)$: upper-bound the indicator of this inequality by $K(d)/(v(\alpha)v(\beta))$ and sum the products. Here $\log_2 L=O(t\log b/b)=o(t)$. This gives the advertised threshold, which eventually exceeds $d^{1-\epsilon}$ for every fixed positive $\epsilon$. When the actual side was padded one may use the padded side's threshold or decrease the asymptotic constant. All small sides can be handled by direct computation. Many more than $K(d)$ errors can also trigger a positive check.

Compute $TA$, $BT^\mathsf T$ and $TCT^\mathsf T$ and inspect the selected entries of $(TA)(BT^\mathsf T)-TCT^\mathsf T$. A nonzero entry is exactly $u_\alpha^\mathsf T(AB-C)u_\beta$. The detection lemma on $2\ell$ axes ensures that any nonzero error of weight at most $K(d)$ triggers at least one check.

## The native cost of a growing digit

The arrays consist of single bits. Pack $q$ consecutive columns per native word. For a digit of radix $s$ and fixed values of the other row digits, take the $s$ rows in that digit group. At one packed column position this gives $s$ words of $q$ bits. There are $q/s$ adjoining $s$-bit fields in each word. Transpose each of the $q/s$ little $s$-square bit matrices **in parallel**. This takes $O(s(1+\log_2 s))$ word operations. At stage $j$ pair rows whose indices differ in bit $j$ and interchange row-index bit $j$ with column-index bit $j$. A repeated periodic mask selects columns having that bit zero, its complement selects the others, and shifts by $2^j$ transfer the two off-diagonal parts between each pair. These moves stay in each $s$-bit field since $2^j<s$ and only the indicated half of each $2^{j+1}$-block moves left or right.

After transposition each $s$-bit field holds one vector to transform. A table indexed by the entire low $q$ bits of a word replaces all its fields by the results of $T_s$. Transpose back using the same bit-index interchanges. The tables over both allowed radices take $2^q\operatorname{poly}(q)=o(d)$ preprocessing operations and words. The arbitrary strides between grouped rows are fixed by power-of-two digit positions, computable with shifts, additions and masks; enumerating the tiles takes at most constant additional work per row per tile. Thus the cost of one digit on the whole $d\times d$ array is $O((d^2/q)(1+\log_2 s))$. Summing over the digits gives $O((d^2/q)(t+\ell))=O(d^2)$. This charges the bit permutations as well as the table accesses. To act on columns, a constant number of whole matrix transposes moving individual bits costs $O(d^2)$ in total.

The index cost $v(\alpha)\le d$ can be tabulated by a digit recurrence in $O(d\ell)$ time. Compute the $d$ cutoffs $\lfloor K(d)/v(\alpha)\rfloor$ before enumerating all $d^2$ pairs. Standard shift-and-subtract on $O(\log d)$ bits per cutoff fits the clock. The threshold itself is computed by capped integer powers, and its definition can use a direct small-side branch when $L>d$. Each qualifying pair costs at most $O(d)$ steps for its binary dot product. The working matrices occupy $O(d^2/q)$ words, in addition to small tables and scratch. Thus the construction fits the standard polynomial address range, even with workspace restricted to $o(d^2)$ words.

After a failed scalar check the program can exhibit a wrong entry. Generate $v=u_\beta$ explicitly, compute $Ev=A(Bv)-Cv$, and choose a nonzero row index $i$ of that vector. Directly compute row $i$ of $AB$ and compare it with row $i$ of $C$. All of this costs $O(d^2)$ operations, including generating $v$ by digit products. On the recognized template that pair of indices specifies a satisfying assignment to the two selectors. The detection and extraction bounds supply an early exit for actual SAT programs and a restriction on candidate positive time witnesses for a universal RAM lower bound.

This also supplies a test for the computable [one-triple-per-dimension exhaustion](uniform-fast-paths-for-sparse-product-errors.md). Combine this detector with the [growing-rank detector](detecting-growing-rank-errors-in-native-sat-time.md) and any fixed additional $o(d^2)$ scalar binary linear measurements that can all be evaluated within $O(d^2)$ time. Take these measurements to be fixed at each dimension, or fixed given the two operands. Altogether the two detectors and the additions impose fewer than $d^2$ binary linear equations on $E$, since the detectors inspect $O(d)+O(dw)$ scalar outputs. For each large $d$ their common kernel therefore contains a nonzero error, even with both operands fixed before picking it. A globally correct SAT program can return immediately on a detected discrepancy and deliberately delay for $d^3$ steps on a miss before its complete fallback. Because the exhaustion preserves *this program's* failure of a positive quadratic clock, infinitely many of its selected errors must evade **all** these measurements at once. In particular those selected triples have both $|E|>K(d)$ and rank greater than $c\log\log d$. This does not presume general matrix verification is slow; a different solver may handle exactly those triples quickly.

## Exact distance for a chosen set of tensor checks

For an invertible ordered binary digit transform let $p_i$ be the smallest weight of an input whose first nonzero transformed coordinate is $i$. Given several such digit transforms, fix a downward-closed set $J$ of multi-indices in componentwise order. The least weight of a nonzero array missed by every check in $J$ is exactly
$$
       \min_{\alpha\notin J}\ \prod_h p_{h,\alpha_h},
$$
with an empty minimum indicating that every error is detected. To see the lower bound, use the lexicographically first nonzero coordinate of the whole transformed array. Apply only the first-axis transform, obtaining tail arrays $Y_i$. The arrays at smaller first indices than the pivot are identically zero, since applying the remaining invertible transforms cannot make a nonzero array zero. At every nonzero site of the pivot array $Y_i$ the original axis vector therefore has at least $p_i$ nonzeros. Induction on the remaining axes proves the product bound. For the reverse bound, take a minimum-weight vector with first nonzero output at each selected digit index and tensor them together. The transformed support lies in the upper orthant of $\alpha$, so no tested index is present. This is the partial-distance argument for tensor kernels used in coding theory, applied to the set of measurements the verifier selects. [Korada, Şaşoğlu and Urbanke, *Polar Codes: Characterization of Exponent, Bounds, and Constructions*](https://arxiv.org/abs/0901.0536)

Here the set of rows with cost product at most $K(d)$ is downward closed. Its exact minimum missed weight is governed by the formula, while the simpler slice proof suffices for the uniform clock.
