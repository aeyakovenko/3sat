# Certifying one negative forecast beyond an unbounded threshold

Let $V(W)$ be the fixed two-seed delayed recurrence. A width is a positive integer written in ordinary binary with leading one. Write $[r]$ for the widths beginning with $r$ and $n(W)$ for the bit length. The proposition
$$
 E(r,t) \quad\Longleftrightarrow\quad
 \exists W\in[r]\; [\,n(W)\ge t\ \land\ V(W)=0\,]
$$
places no upper bound on the witness width. The input to a compiler or a proof checker consists of $r$ and the binary integer $t$. The horizon in the physical forecast is fixed separately at each width. [Recurrence and two native simulation clocks](one-variable-delay-and-one-binary-product.md)

Let $F(r,t)$ be any fixed, possibly partial compiler to explicit ordinary SAT. Its only semantic guarantee is that each satisfiable output implies $E(r,t)$. For **each correct deterministic SAT RAM $S$** there is a fixed binary prefix $r$ on which every sufficiently long width actually has zero verdict. For all sufficiently large $t$, every satisfiable formula produced by $F(r,t)$ in $o(2^t/t)$ work takes $\Omega_{F,S}(2^t/t)$ instructions on the actual run of $S$. More precisely, every satisfiable output requires at least this order of combined compiler and solver work. The simulation charges input preparation and all writes. Both computations must run with constant simulation overhead in $O(t)$-bit words when the combined work is within this budget. A usual word RAM compiler using logarithmic words in its input length is covered, as is a compiler using a fixed multiple of $t$ bits per word; for a short ordinary formula the SAT guest's native word width also fits. There is no time hypothesis on $S$ and no further restriction on its workspace. ## Repeating every earlier test

A wide guest parses the code of its simulation mode and program, followed by two self-delimiting tuning integers $h,t_0$. Their entire concatenation is $r$. On every width extending this prefix with $n=n(W)\ge t_0$, start each virtual test at $(r,t)$ for $t_0\le t\le n$. Run $F$ then $S$, with the same capped instruction budget at threshold $t$ on every longer width. Return zero on the first completed YES. If no test succeeds, run forever. The decoder can read its own code as part of the actual input. The virtual tests use the widths prescribed by their own inputs and a fixed $O(t)$-bit convention when required. They do not inherit the potentially larger address range of the outer width. A test that cannot produce a well-formed available formula within that schedule cannot signal.

For sufficiently large $t_0$, the caps
$$
 b_t=2^{t-\lceil\log_2(t+1)\rceil-h}
$$
are positive integers, nondecreasing and at least double every two steps. In fact $\lceil\log_2(t+3)\rceil-\lceil\log_2(t+1)\rceil\le1$ for $t\ge1$. The entire schedule costs at most $4b_n$ capped trial instructions. Pairing successive budgets and using two-step doubling gives the bound even after dyadic rounding. Separate stage address banks preserve fresh zero-initialized memory; the stage tag takes $O(\log n)$ address bits. Counters through $b_n$ fit $O(n)$-bit host words. The guest costs $O(b_n+\operatorname{poly}(n))$ steps. Fix $h$ large enough after the guest code is fixed, then choose $t_0$ large enough to cover the header, setup and all simulator estimates throughout $n\ge t_0$. The fixed simulator completes and latches each such timely return before observation since $W/n\ge 2^{n-1}/n$. The constants used here are independent of the input values of the two tuning fields. Parsing and capped clock arithmetic for them can be limited to polynomial setup on the designated inputs.

If the bounded test at threshold $t$ succeeded, every width in $[r]$ of length at least $t$ would latch one. An earlier success also gives one. Soundness promises a width in just that unbounded tail with value zero, a contradiction. Hence no capped test succeeds. The guest then never returns, so the verdict track remains zero on every such width. The claimed actual SAT execution lower bound follows since $b_t=\Theta_{F,S}(2^t/t)$. The cutoff protects the smallest width that could witness soundness. A search fast only eventually on widths past an unspecified exceptional interval could leave the promised zero inside that interval. [Lean proof of persistence and the cumulative budget](PersistentForecastSearch.lean)

For $k=1,2,3$, it would suffice to find one sound compiler having infinitely many satisfiable outputs on each resulting solver prefix, with $o(2^t/t)$ construction work and $o((2^t/t)^{1/k})$ encoded SAT bits on those thresholds. It need never identify the width whose existence it certifies. Under these bounds the actual runs contradict an $O(N^k)$ SAT clock. The full-prefix hit property remains open here.

A finite block admits the same synchronized test without a search over thresholds. Fix an efficiently computable prefix length $\ell(n)\le n$ tending to infinity, for example $\lceil\log_2(n+1)\rceil$ for large $n$. A shared formula $D(n,u)$ may certify only that at least one of the $2^{n-\ell(n)}$ widths beginning with the $\ell(n)$ bits of $u$ is negative. The guests at **every** width of a block independently present the very same formula to $S$ and return zero only on YES. Once $u$ contains their full simulation header, every block so addressed contains a genuine negative: success implies it by soundness, while a shared negative answer or divergence leaves every width at zero. On a cheaply constructed satisfiable output a solver faster than a small constant times $2^n/n$ would make *all* forecasts one. The same elapsed-time lower bound thus applies with no factor for enumerating the block. If a coupled model permits only one width in a block of two to latch one, a constant tautology already soundly certifies a zero for the pair. In that model the required simultaneous latch on a shared YES cannot be inferred. The independent forecast guests can all latch one, as the program returning zero immediately demonstrates.

## Cost of finite evidence for an unbounded existential

Fix a deterministic, possibly partial logarithmic-word verifier $R(r,t,p)$. An accepted binary proof must imply $E(r,t)$. There are a prefix $r$ and constants $a,c>0$ such that all its sufficiently long widths have value zero. At every sufficiently large $t$, each accepted proof obeys
$$
         2^{|p|}(1+T_R(r,t,p))\ \ge\ c\,2^{4t}/t^a .
$$
In particular every accepted proof of this unbounded existential claim for a polynomial-time verifier has at least $4t-O_R(\log t)$ bits. On the fixed prefix the statement itself uses only $O(\log(t+2))$ bits. This concerns a claim allowing an arbitrarily late witness, including witnesses far outside the time and space allowed for discovering the proof.

Use the narrow simulation mode, with $O(\log n)$-bit words on a native width of bit length $n$. As before the guest tests all $t_0\le t\le n$. For a fixed positive tuning integer $b$, set $J(t)=4t-b\lceil\log_2(t+2)\rceil$. At each $t$, for every nonnegative stage $j\le J(t)$ and $0\le i\le j$, enumerate all $2^i$ strings of length $i$ and run the verifier for up to $2^{j-i}$ steps apiece. Any acceptance returns zero. The guest otherwise keeps running after the search ends. Parsing, counters and clearing the verifier's memory cost polynomial factors in $n$. In the simulated calls, $|r|\le n$, the proof has length at most $4n$ and the verifier's address space is polynomial in $n$. The host can simulate the verifier at the same native guest width on every later replay of a given bounded call. Its stage and proof clocks themselves need $O(n)$ bits stored across many words.

For fixed $b$ the total narrow guest work over all $t\le n$ is $O_R(n^A 2^{4n}/n^b)$ once $n$ is sufficiently large, for an exponent $A$ independent of $b$. Split at $n/2$. Below it even an uncensored $2^{4t}$ upper bound is exponentially smaller. Above it the common denominator loss is at most a fixed factor $2^b$ times polynomial-in-$n$ rounding terms. One may compute $J$ by multiplying a binary logarithm by $b$, skipping the stage if $b>n$ until that field fits. The algorithm uses no loops with nesting depth $b$. The narrow physical simulator has a budget $c_Q W^4/n^{a_Q}$ for its fixed guest. Pick $b>A+a_Q+2$ in the input header, and then pick the start threshold large enough for every permitted replay. Consequently an acceptance in any scheduled test would make every permitted witness width in its tail latch one. Soundness again excludes it. An accepting proof whose $|p|+\lceil\log_2(1+T_R)\rceil$ is at most $J(t)$ would have been found. This gives the displayed inequality and the proof-length consequence. These resource estimates use the manuscript's machine simulation.

A stronger logical statement holds for certifying *unboundedly many* negative widths at once. Let $A$ be any computably enumerable, globally sound set of certificates of $I(r):=\forall t\ E(r,t)$, with an effective projection to the certified header. There is an explicitly constructed header $r$ such that **every sufficiently long width in $[r]$ is zero and $A$ never certifies $I(r)$**, with no bound on proof length or search time. On its own prefix a guest simulates the first $n$ steps of the fixed enumeration, returning zero only if it finds a certificate for that exact prefix. Otherwise it idles. The finite simulation and checking of matching emitted headers take polynomial time in $n$ and fit at every sufficiently large width. If a genuine certificate for this prefix appeared at any finite stage, all sufficiently large widths would give one, violating its claim. Thus none appears, and every guest in the cylinder stays silent. This also handles semidecidable certificate checks by dovetailing. In a sufficiently strong sound arithmetic theory each individual $E(r,t)$ on such a prefix can still be proved by verifying a particular finite negative computation. The theorem for individual proof lengths and this theorem for $I$ may use different constructed headers.

## A complete family with cheap positive hits

The arithmetical complexity of the targets can be read on a single computable family of guest headers. A fixed guest reads a self-delimited enumerator code $e$ from its input. In one mode it simulates $e$ for the first $n$ steps, returns one if the simulated machine halted, and returns zero otherwise. On every sufficiently large width of the prescribed header $r_e$ the forecast is zero exactly when that finite test succeeds. The virtual tape and decoding cost polynomial work in $n$ uniformly for headers that fit inside the width. There is a fixed start length $t_*$ covering this guest's simulation threshold. With $t=\max(t_*,|r_e|)$ this maps ordinary halting to $E(r_e,t)$. Conversely an affirmative $E$ has a finite witness discoverable by evaluating widths. Thus $E$ is $\Sigma^0_1$-complete under computable many-one reductions. In particular a total computable reduction to ordinary SAT giving the correct verdict for **every** header and threshold is impossible even with unbounded construction time.

In the other mode return one precisely if a fresh enumerated item appeared at step $a(n)=\lfloor\sqrt{\lfloor\log_2 n\rfloor}\rfloor$. Simulate and compare the finite outputs directly in time polynomial in $|r_e|+\log(n+2)$. Every sufficiently large integer step number occurs as $a(n)$. There are arbitrarily late zero widths exactly when $e$ enumerates infinitely many distinct items. Membership of $I$ in $\Pi^0_2$ follows from its defining quantifiers. For hardness, given a computable predicate $R(x,a,b)$, make an enumerator emit successive integers $a=0,1,\ldots$ as it finds a witness $b$ for each in order. It enumerates infinitely many items precisely when $\forall a\,\exists b\,R(x,a,b)$. This proves $\Pi^0_2$-completeness on the fixed guest family, the usual completeness argument for the infinitude index set. [Classical index-set classification](https://people.clas.ufl.edu/cenzer/files/Closed-Sets-Book-2017.pdf)

There are genuine short positive SAT outputs on the halting family. A uniform compiler recognizes its exact headers, simulates $e$ for $\lceil\log_2(t+2)\rceil$ steps, and emits a fixed satisfiable proper 3-CNF on detecting a halt; on all other inputs it emits a fixed unsatisfiable proper 3-CNF. A halting computation guarantees a zero at some width of length at least $t$, irrespective of the current threshold. On every halting header the compiler succeeds at **every sufficiently large threshold** in time polynomial in the bit length of $(r_e,t)$. The same compiler can also handle the pulse headers. When $t\ge\max(t_*,|r_e|)$, check if a fresh item appears at the step $a(t)$, and emit the fixed satisfiable formula exactly when it does. Every width of length $t$ on that header then supplies a sound witness. For every enumerator producing infinitely many items, the compiler hits infinitely many thresholds. In fact its successful thresholds have **upper asymptotic density one**. A pulse at step $j$ yields every threshold in $[2^{j^2},2^{(j+1)^2})$. At the right endpoint the missed proportion is at most $2^{-2j-1}$ up to the endpoint convention. There are infinitely many such $j$ and the work is polynomial in the encoded input length on every trial. Thus a fixed uniform procedure gives constant-size satisfiable outputs at these rates on a family where identifying the headers with unbounded zeros is $\Pi^0_2$-complete. Covering the headers that repeatedly run the compiler and the SAT solver is the additional requirement in the time-bound theorem. Computability classification alone does not decide that coverage question.
