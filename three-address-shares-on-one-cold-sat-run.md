# A packed scan and subsequent graph probes on adjacent SAT executions

Fix any correct deterministic SAT program on a logarithmic-word RAM, with read-only input, zero initial work memory and a bounded number of word accesses per instruction. There are arbitrarily large **single** proper ASCII 3-CNF files of encoded length $N$ with the following property. For each of many logical source–sink queries, there are $\Omega(N/\log N)$ pairs of edited files. One member of each pair is SAT and the other UNSAT. The files in a pair differ by **one physical bit**. Across the pairs for a given query, the sets of modified physical positions are disjoint. The three- and four-edit members all follow the same $\Omega(N/\log N)$ initial instructions of the restored file. After that prefix, each member of each hard pair must do both of the following.

* Read $\Omega(N/\log N)$ distinct input words in a public selector region.
* Retrieve $\Omega(\log N/\log\log N)$ distinct old graph or work words. Graph words are the words in a separate input region that can depend on the graph. An old work word is read before it has been written in the suffix, including reads of previously untouched addresses.

The two kinds of addresses are disjoint. No restriction on the solver's time or work space is needed. Each logical query in this statement is a different source–sink pair of one butterfly graph. The hard logical queries include a matching of size $\Omega(L)$, where $L$ is the number of sources in the butterfly below. Disjoint supports are asserted *within* each logical query. ## Encoding the query at three sites

Take a public degree-$B$, depth-$d$ butterfly, with $L=B^d$ source and sink labels and $E=dBL$ possible edges. Choose $B$ a power of two of order $(d\log(2d))^4$. Its subgraph is specified by $E$ presence bits. Put $R=E$ and give each of four banks $R$ editable bits, indexed by a label in $[L]$ and a copy in $[dB]$. Labels are binary words with addition given by XOR. The file initially has zeros at all four banks. In each of banks A, B, C compute both the parity of the bank and the XOR of the labels of its set bits, obtaining $a,b,c$. The fourth bank supplies one parity $z$. Whenever any of the first three bank parities is zero, the formula is satisfiable. Otherwise the verdict is nonreachability from $a\mathbin\oplus b$ to $b\mathbin\oplus c$, complemented when $z=1$.

This predicate has $O(E)$ gates and proper clauses after the ordinary fixed-fanin circuit encoding. Combine replicas of each label by XOR. On a binary tree of labels compute each subtree parity once. For each label-bit position, XOR the right-child subtree parities at its corresponding depth. The total size over all depths is $O(L)$, as each right-child subtree contributes to exactly one such XOR. For reachability, initialize the source layer to the one-hot decoding of the source address. At every later layer take an OR of the reachable parents gated by their edge-presence bits. The total fan-in is $O(E)$. Select the sink bit by a binary multiplexer. These gate equivalences implement both verdict polarities. Use two complementary names per editable bit, both constrained by two binary clauses, and a padded unit selecting which name is true. Assign the two decimal identifiers to end in ASCII 2 and 3. All other gates and their physical positions can be fixed before choosing the subgraph, with a single graph region containing the edge-presence bits. Space the editable names by $\Theta(\log E)$ bits. Pad the two regions apart or discard the $O(1)$ boundary words. Thus $N=\Theta(E\log E)$, each input word meets at most a machine-dependent constant number of marked sites, and selector or template words can be reconstructed without observing the graph. [Raw DIMACS compiler and audit](reachability_share_edit_audit.py)

For a query $(s,t)$ and a choice $(j,h)\in [L]\times[dB]$, edit the sites
$$
      A[s\mathbin\oplus j,h],\quad B[j,h],\quad C[t\mathbin\oplus j,h].
$$
This sets the logical endpoints to $s,t$. Either leave the fourth bank alone or also edit $T[j,h]$. The two files now give opposite verdicts. Each triple or quadruple from this presentation uses disjoint named sites from the triples and quadruples at every *other* choice for the same $(s,t)$. This follows because translation by a fixed binary word is a bijection in each bank. Any $u$ inspected sites therefore spoil at most $u$ of the $R$ choices for **each** query. All masks of at most two selector changes from the zero base are satisfiable.

Three edits are minimal for this uniform avoidance property at these dimensions. For any fixed decoder assigning a unique logical query to each edit pattern on $M$ sites, the $L^2$ inverse images are disjoint. If each query can be represented with at most two edits avoiding any $u$ forbidden sites, each inverse image except the base query has at least $u+1$ representations: otherwise choose one forbidden site from every representation. Consequently $(L^2-1)(u+1)\le 1+M+\binom M2$. At $M=O(E)$ the right side allows $u=O((dB)^2)$, well below $\Theta(E)$. The three-edit construction tolerates any $R-1$ forbidden sites. This sharp arity statement concerns the *query decoder*, which distinguishes all logical queries even when several happen to have the same SAT verdict.

## Forcing expensive adjacent executions

Simulate the actual program on the restored file for $b_0=\lfloor c_0 R\rfloor$ instructions or until it halts, with a sufficiently small constant $c_0>0$. Mark all selector sites in input words it has read. For **every** logical query, at most $\eta R$ of its $R$ paired representations touch a marked site, where $\eta$ can be made an arbitrarily small positive constant. A clean pair runs identically to the restored file throughout the simulated prefix. Save its registers, graph information and a static dictionary of its at most $O(b_0)$ written cells. An absent key has value zero. A restored file that halts early gives the same answer on both members of every clean pair, contradicting correctness. Thus the full prefix exists. [Fredman, Komlós and Szemerédi on static dictionaries](https://doi.org/10.1145/828.1884)

A cell-probe query simulator knows the logical endpoints, share choice and polarity. It can reconstruct all non-graph input words, overlay its four or fewer edits, and simulate all suffix writes and repeated reads in private memory. Each distinct inherited work address or graph input word costs $O(1)$ probes to the index. Public descriptions, the saved registers and membership in the marked-site sets take $O(1)$ initial probes. This deliberately charges no probes even if the actual RAM spends a long time reading every selector word. [Pătraşcu's cell-probe model and Reduction 5.1](https://people.csail.mit.edu/mip/papers/structures/paper.pdf)

Call a choice hard for $(s,t)$ if it is clean and **both** of the adjacent suffixes require at least $\gamma d$ of these distinct old addresses, for a sufficiently small constant $\gamma>0$. Call a logical pair hard if at least $\varepsilon R$ choices are hard. Here $\varepsilon>0$ is another sufficiently small absolute constant. We prove that some graph has a matching of at least $\alpha L$ hard logical pairs for a constant $\alpha>0$.

Suppose the contrary at a hard scale. For each graph store the endpoints of a maximal matching of hard logical pairs and a membership flag per terminal. This vertex cover has fewer than $2\alpha L$ vertices and meets every hard logical pair. Use Pătraşcu's reduction from two-blocked lopsided set disjointness. Bob knows the graph, and Alice's $L$ logical queries form a perfect matching from sources to sinks. Bob can send the entire cover bitmap in $O(L)$ bits. Alice sends the endpoints of all matching queries that touch it, and Bob answers those queries directly. There are at most $2\alpha L$ such queries. [Pătraşcu, Lemmas 3.1–3.2 and Section 5](https://people.csail.mit.edu/mip/papers/structures/paper.pdf)

For each other query sample a uniform share choice using public randomness. If clean, interleave the two polarity simulations for $O(\gamma d)+O(1)$ probe rounds, enough to finish the cheaper simulation if either suffix uses fewer than $\gamma d$ distinct old addresses. Translate a completed answer back to ordinary reachability using its known polarity. Mark a query unresolved if dirty or if neither simulation finishes. Its probability of remaining unresolved is at most $\eta+\varepsilon$. Regardless of dependence among the samples, the expected total unresolved is at most $(\eta+\varepsilon)L$. If the total exceeds $\kappa L$, abort. Otherwise Alice sends the endpoints of all unresolved queries and Bob supplies their exact answers. Choose $\kappa$ sufficiently small for the communication budget, then choose $\eta,\varepsilon$ so that $(\eta+\varepsilon)/\kappa<1/10000$. Markov's inequality bounds the error on the *whole* two-blocked disjointness input even though there are $L$ reachability questions. No single-query randomized butterfly bound is assumed.

For clarity let $S=E(\log E)^{O(1)}$ bound the number of index cells, and $w=\Theta(\log E)$ the cell width. Simulate the $O(\gamma d)+O(1)$ rounds for the $O(L)$ parallel probes in each round using a subset-of-addresses message from Alice, sorting and deduplicating within that round. The address cost is $O(L\log(2+S/L))$ bits per round. Bob returns $O(Lw)$ bits per round. Directly resolving cover and unresolved matches costs Alice $O((\alpha+\kappa)L\log L)$ bits and Bob $O(L)$ bits. Since $\log L=d\log B$, $\log(2+S/L)=O(\log B)$, and $w=o(\sqrt B)$, choose $\alpha,\kappa,\gamma$ small enough that Alice communicates below the small constant times $dL\log B$ allowed by the lopsided-disjointness bound. Bob communicates $o(dL\sqrt B)$ bits. The additive $O(dL)$ overhead of the blocked versions is affordable. This contradicts the bounded-error communication theorem with a fixed sufficiently small Alice coefficient. [Pătraşcu, Theorem 1.4](https://people.csail.mit.edu/mip/papers/structures/paper.pdf)

Finally every file in any clean pair is sensitive to **every** fourth-bank bit, since all three primary bank parities are odd. Each execution must read each such position at least once, or toggling it would preserve the execution and change the answer. Most of these $R$ sites remain unread after the common prefix. They occupy $\Omega(R)$ distinct selector words, in addition to the old graph or work words forced by the preceding proof. In particular even an unrestricted solver cannot pay for the second bound by scanning selector bits.

## The surviving gap

The public butterfly has a unique path for any specified source and sink. On this fixed layout a RAM can accumulate all bank parities and addresses while scanning the input, store the edge bits, and then check the $d$ edges of the specified path. The named padded slots use $O(1)$ words per row. Packed decimal spellings up to the largest identifier can be precomputed in $O(E)$ steps by generating each child spelling from its parent's, and the canonical gate rows can be verified during the scan. A fallback SAT algorithm handles a template mismatch. Thus the same files admit $O(E+d)=O(N/\log N)$ time for a globally correct solver, with $O(d)$ additional graph accesses after decoding. The unconditional result identifies which work is genuinely additional on one run. Repeating it over many continuations does not multiply the time of any one run. The compilation and execution theorem are manuscript proofs, with the bit encoding and verdicts checked on small graphs. Priority for this combination has not been established.
