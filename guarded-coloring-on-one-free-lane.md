# Both verdicts with large local certificates in one free lane

The construction uses the fixed eighteen-vertex anchor and the seven-triangle compiler for one permuted lane. [Single-lane reduction](one-permuted-lane-and-the-sat-clock.md) · [SAT graph encoding](branching-in-equations-over-six-permutations.md) · [Data-entry exchanges](charge-decision-on-simple-permutations.md)

Fix an ordinary SAT input of encoded length \(n\), normalize it to proper ternary clauses with \(O(n/\log(n+2)+1)\) gate or literal records using the existing conversion, and choose \(t=\Theta(n/\log(n+2)+1)\) rounded up to a multiple of three at least nine. For each input control vector \(b\in(\mathbb Z/6)^t\), require the following Boolean predicate of the ordinary witness \(w\):
\[
 S=1\quad\lor\quad (S=0\land F(w)),\qquad S=\sum_i b_i\pmod6.
\]
A deterministic fan-in-two Boolean circuit of \(O(t)\) gates computes the residue by a prefix chain of constant-size adders. Encode the circuit including \(F(w)\) by definitional clauses and a true output; pad short clauses by repeated literals in the not-all-equal graph gadgets. Temporarily leave the three bits for each control coordinate free, with its permitted code for numbers zero through five fixed by the pins below. Forcing \(b=0\) preserves arbitrary SAT exactly. Force-YES and force-NO cases always exist by choosing total one or two respectively. The physically distinct files below correspond only to legal control vectors.

Use the ordinary palette-triangle reduction, positive and negative literal vertices joined to each other and to the base palette color, and local not-all-equal triangle gadgets for the gates. The false palette vertex itself is the false terminal in the second not-all-equal gadget. For each control bit add to the baseline graph edges \((q,T),(l,F_0)\), where \(q\) is its positive literal, \(l\) a private leaf, and \(T,F_0\) are the two Boolean palette vertices. The baseline demands false. Encode this graph by two Hamilton paths with fixed red order and a blue-slot array using the existing graph encoder. The red inequality pairs are fixed. In blue, exchanging the two distinct incidence data entries belonging to the palette ends of these two edges changes the represented constraints to \((q,F_0),(l,T)\). The control bit becomes true and the leaf extends in either case. Distinct pins have distinct slots, even at the shared palette. Apply the seven-triangle single-lane compiler directly to this two-path order. In its free lane each old blue entry now supplies one seven-tip block. Its seven labels depend only on that entry. A control-bit exchange transposes two of these complete blocks. All moved physical positions and all moved tip **IDs** associated with different coordinates are disjoint. One coordinate involves at most 42 tip fields (three bit exchanges of 14 fields), independent of \(t\). The old guard graph and final strip have \(\Theta(t)\) items and \(N=\Theta(t\log t)=\Theta(n)\) physical bits. These constructions, including the all-zero SAT reduction, fit \(O(n)\) native steps. The inverse coloring-to-ordinary-SAT encoding has the same linear physical guarantees.

**Local colorability on the entire promise.** Fix any negative image and a set of fewer than \(t\) vertices in its final strip and anchor, including arbitrary scattered vertices. Some coordinate's set of movable labels misses all these vertices. Change this coordinate so the total becomes one. The new file is positive. Every changed edge has an endpoint in that coordinate's movable **labels**, since all fixed red edges and all free-lane adjacencies between unmoved entries retain their slots. Thus the two induced subgraphs on the chosen vertices coincide, and a coloring of the positive file restricts to a coloring there. This holds on positive images as well by direct restriction. In particular, the SAT-equivalent promise excludes every fixed-size uncolorable pattern as an ordinary subgraph, and even excludes uncolorable subgraphs on a fixed positive fraction of the final vertices. The set of patterns here is unrestricted, including all four-tip incursions. On the ordinary canonical coloring CNF, any set of \(o(t)\) clauses involves only \(o(t)\) graph vertices and is jointly satisfiable by the same argument, including the common padding pin.

**An opposite legal file on either verdict.** For every file and each coordinate, fixing the appropriate replacement residue sends the total to two on a YES file or one on a NO file, so that the answer reverses. Both inputs are inside the same locally colorable promise. Other fields and the physical header are identical. A correct deterministic run must touch a word intersecting every coordinate's group. In DIMACS the input-dependent slots are precisely the copied endpoint tokens belonging to the movable free-lane slots; adjacent slots that appear in the same edge clause use disjoint padded token fields. A word meets constantly many groups in each format. Every program deciding the promise takes \(\Omega(t)=\Omega(N/\log N)\) instructions on every single file. On a Monte Carlo machine with error at most \(\epsilon<1/2\) on *this promise*, couple the file and each of its neighbors by fixing equal random coins. Until its group is read their transcripts agree, hence the probability of hitting each group is at least \(1-2\epsilon\). Linearity of expectation gives the same order on every file in expectation. This does not charge executions on arbitrary SAT files by their proof complexity.

Since all-zero controls carry all of SAT, a uniform \(O(N^j)\) solver on this promise is equivalent to one for all explicit SAT for \(j=1,2,3\). Even a one-sided deadline on all positive promise images is enough if the program never emits a false positive, via the all-zero compiler and a timeout. This strengthens a scan bound from an easy subfamily to a near-linear-size promise that still contains the full decision question. It yields no increase beyond reading linearly many native words.

**Value dependence through every file.** For \(S=r\), the verdict vector on residues is \(g_0=\delta_1\) if \(F\) is unsatisfiable and \(g_1=\delta_1+\delta_0\) if \(F\) is satisfiable. At any actual \(b\), choose one Boolean toggle per coordinate. Use increments 3 and 2 at the first two sites and \(+1\) elsewhere, except for \(r\in\{0,\ldots,5\}\) of the remaining coordinates where the increment is \(-1\). Each physical bit of the rendered cube is constant, that coordinate's toggle or its complement. For \(\Delta_jg(s)=g(s+j)-g(s)\), its top integer Möbius coefficient is
\[
 (-1)^r(\Delta_1^{t-2}\Delta_2\Delta_3g)(0).
\]
Indeed \(\Delta_{-1}=-S^{-1}\Delta_1\) for the forward cyclic shift \(S\). On the image of \(\Delta_2\Delta_3\) one has \(\Delta_1^3=I\): the polynomial \(((X-1)^3-1)(X^2-1)(X^3-1)\) is divisible by \(X^6-1\), since \((X-1)^3-1=(X-2)(X^2-X+1)\). With \(t\equiv0\pmod3\), the remaining exponent reduces to one. Direct evaluation gives \((\Delta_1\Delta_2\Delta_3g_0)(0)=(\Delta_1\Delta_2\Delta_3g_1)(0)=1\). Hence the mixed coefficient is a unit in every field. This gives full exact multilinear degree on a common physical \(t\)-switch cube incident to *each* promised file, and all its vertices satisfy the same local-colorability promise.

**Labeled neighborhoods.** For every set \(T\) of fewer than \(t/5\) vertices the entire list of edges incident to those vertices in both paths agrees on an opposite-verdict promise image, with the same labels. Its closed neighborhood contains fewer than \(t\) vertices because degree is at most four. Choose the opposite coordinate avoiding that neighborhood. No moved tip was a neighbor of a vertex in \(T\) or belonged to \(T\), so neither side of any blue incidence at \(T\) changes. Taking \(T\) to be a ball gives agreement of individually prescribed labeled balls through radius \(\log_3 t-O(1)\). Different prescribed sets can use different opposite images.

For a fixed source, the uniform distributions on total one and total two induce **identical** marginals on any fewer than \(t\) entire coordinates. The final unchecked coordinate can absorb every prescribed residue in exactly the same number of ways. This remains true for adaptive transcripts that expose fewer than \(t\) coordinates, by conditioning on the transcript. Thus opposite-promise indistinguishability holds distributionally as well as pointwise. All-zero controls encode the original source. More precisely a promised solver \(A\) induces the ordinary program \(B(F)=A(C(F,0))\) with time bounded by its actual native time on that exact image plus \(O(|F|)\) construction work. A runtime claim about a different SAT program on an individual \(F\) need not transfer. Obtaining a superlinear source lower bound for every such composite program is open.

**Finite verification.** The end-to-end audit uses two controls with the equivalent CRT representation (one parity bit and three unary mod-three flags). It checks both a satisfiable pair of units and an opposite pair of units across all 36 control settings, generating 72 physical orders with 142,749 entries. For each it decodes the seven-tip layout from the final free lane, recovers the exchanged source inequalities from the two-path incidence slots, and exhausts the payload assignments. For all 18 positive cases it constructs a coloring and checks every edge in the physical order, and all 144 opposite-image comparisons check the actual edited field and vertex-label pools. The CRT audit uses 56 potential fields per coordinate, against 42 for the binary-code argument. The independent core-Lean file checks \(\Delta_1^3\) on the range of \(\Delta_2\Delta_3\), its iterates for every length \(3q+3\), the integer coefficient 1 and the reversal identity. The RAM running-time and labeled-neighborhood theorems are manuscript proofs.
