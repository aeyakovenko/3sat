# A common SAT pair with a literal name crossing each word boundary of a data packet

For the aligned logarithmic-word RAM, a single pair of ordinary proper 3-CNF files forces **every solver in a polynomial roster** to spend $\Omega(N/\log N)$ charged non-load instructions on **both** files after a data-dependent prefix. The files have $N$ encoded bits and differ in one bit. Each solver can use arbitrary prefix time and every addressable word of workspace. The cut is its first read of one of a common set of still-variable query words. At least $\lfloor cN/(r\log N)\rfloor$ distinct database symbols have already been disclosed to that solver, where $r$ is the roster size. The conclusion also applies when a solver has already read and preprocessed the *entire* database by the cut. Some other solvers encounter the cut with much of the database still unread.

Count numerical operations or comparison branches consuming a marked operand, stores consuming a marked operand, and the distinct numerical addresses or payloads of remaining stores. The precise marking convention permits every pure pointer-following load and direct local parsing of a new query word for free. Each non-load instruction contributes at most two towards this charge. In addition, on both diagonal files every solver has to read all $2m$ original data and query word halves and at least $(1-\eta)m$ previously unseen query words after the cut, for $m=\Theta(N/\log N)$. The word-width coefficient is a sufficiently large fixed constant. Register, instruction arity and program-counter assumptions are those of the common-roster proof. ## A mixed literal instead of separate clauses

Fix $0<\alpha<1/2$. Let $d=\lfloor\alpha\log_{10}m\rfloor$, $K=10^d$, and use strings $a,x\in[K]^m$, with digits zero-padded to $d$ places. For each ordered symbol pair $(u,v)$ use a distinct positive decimal name $Y_{u,v}$ whose spelling has a fixed nonzero prefix followed by those digits for $u$ and $v$. It occupies only $O(\log m)$ bits, even though all $K^2$ pairs use separate names. A word boundary falls **inside** that spelling. A physical data word $A_i$ ends with the prefix and digits for $a_i$. Its neighboring query word $X_i$ starts with the digits for $x_i$. Position-dependent material such as the private gate name $z_i$ belongs outside $X_i$. The complete numeric value of $X_i$ is a public function of only $x_i$ and one of three tag settings. This is the step which escapes the static upper bound for encodings whose clauses each belong to just one side. [Static ceiling for separated equality](the-static-ceiling-for-equality-encoded-as-sat.md)

Public clauses force $Y_{u,v}$ to equal a truth bit $t$ for $u=v$, and to equal $\neg t$ for $u\ne v$. The two halves of position $i$ jointly supply the proper clause $\neg z_i\lor Y_{a_i,x_i}\lor f$ with a false anchor $f$. Include $t\Rightarrow z_i$ at each position and require at least one $z_i$ by a bounded-fan-in OR circuit. Each query word also contains a separate proper clause pinning its tag literal. The neutral spelling is a universally true literal on this family. Exactly one query word instead pins either $t$ or $\neg t$ using complementary aliases differing as decimal digits 4 and 5. When $t=1$ all $z_i$ must be true, requiring $a=x$. When $t=0$ one may choose any nonmatching position for a true $z_i$, and a mismatch is necessary. The two actual tag files thus have opposite verdicts on every pair of strings.

The printed layout uses exactly $7m+2K^2+9$ aligned words and $6m+2K^2+8$ clauses, including the fixed dictionary, controls, anchors, long OR, padding and header. Each private pair is preceded by a public word containing the start of its clause. For $D$ total word positions, take the smallest $e$ with $CeD+2\le2^e$ and $N=CeD$; then $W=Ce=C\lceil\log_2(N+2)\rceil$ for a sufficiently large fixed byte-compatible $C$. [Physical compiler and solver tests](mixed_decimal_equality_packets.py) For the stated width this is $N=\Theta(m\log m)$ bits while the database entropy is $L=m\log_2 K=\Theta(N)$. At the diagonal $x=a$ each $A_i$ and each $X_i$ is individually pivotal under a single physical bit flip: flip the low bit in one decimal digit (0/1, 2/3, 4/5, 6/7 or 8/9). This preserves its field width, the chosen tag, and all other coordinates. Global SAT correctness forces a read of each of the $2m$ private input words before it is first overwritten.

## A layout compatible with all the machine prefixes

Fix a small constant $\eta\in(0,1/8)$ and a database $a$. Run each program on neutral query fields and matching symbols until it has first read an $A_i$ or $X_i$ for each of $u=\lfloor\eta m/r\rfloor$ distinct coordinates. Before the final tag is determined these replies can be simulated from $a$. A query half exposed now gives the genuine value of $a_i$ and will be held fixed at that value for all subsequent completions. Keep every program's registers and writes private. The union $V$ of coordinates touched at these cuts has $|V|\le ru\le\eta m$.

No program may halt before its quota, or run forever while avoiding all new coordinates. Complete the history by placing one tag at an unseen query word, and compare its two settings. It cannot first overwrite any private half it has not read. On a diagonal completion with a tag in an uninspected query word, change only one digit in the proposed overwrite target. These two valid files have opposite verdicts and the overwrite would erase their only difference. If the target is the tag word its tag spelling can stay fixed on both files. The alternative after a digit edit need not itself be diagonal: global correctness on proper 3-CNF inputs supplies the comparison.

Let $H$ consist of the query halves $X_i$ with $i\notin V$ and choose the least such $i$ for the tag. Fix $X_i=a_i$ for $i\in V$. All $A_i$ contain the actual database and remain in each machine's static cut memory, subject to that machine's prefix writes. Extend each simulation until its first load of an original word in $H$, and cut immediately before the reply. It may in the meantime read every $A_i$ and preprocess them arbitrarily. A premature halt or infinite avoidance is again excluded by the two tags on the diagonal. An attempt to erase an unread word in $H$ first is excluded by a one-digit edit at that word on the diagonal, with the tag held fixed. The resulting states and first request addresses depend on $a$ and the roster, and are independent of the later words on $H$. All the prefixes are prefixes of the same physical pair.

## Counting diagonals with a cheap sign or program

For each $a$, preprocess the actual per-program cut memories into first-hole indices. Word width $W=\Theta(\log m)$ ensures polynomially many addressable cells, even after unbounded prefix time. Charge the cut controller, including its program counter, with its native size $h=\log^{O(1)}m$ words. The query simulator knows the code of the selected program and the candidate query. The static replay needs $O(1+h+t+p)$ probes on a suffix of charge $t$, where $p$ counts distinct actual raw hole replies used as pointer addresses. Here $p\le 3K$ on *any* query. This charge is $o(m)$ even when every fresh input word is fetched and freely used as a pointer. [Time-sensitive pointer and store replay](processing-after-the-database-packets-of-a-sat-file.md)

If a diagonal $x=a$ has any one cheap program and tag, describe the database by the $m$-bit mask of $V$, the $|V|$ symbols $a_i$ in indexed order, the chosen program and tag, and the content and address of every static cell probed by the chosen simulation. Fixed-width and padded fields give at most
$$
 m+|V|\lceil\log_2 K\rceil+O\big(\log(r+2)+(1+h+t+K)\log m\big)
$$
bits. Each polynomial-size static index may use a common address layout with unused cells zero. The $m$ query symbols themselves are absent.

Suppose two databases $a,a'$ gave identical descriptions. On the representation for $a'$, run the recorded tag and program on the original query $x=a$. Their common masks and recorded symbols give $a'_i=a_i$ throughout $V$. Thus this is a legal completion of the cut for $a'$: its frozen query words already equal the required values. The variable holes are filled from the public function of $V$, $x$ and the tag. Every probe made on $a$ sees the same static content on $a'$. Induction on successive probes yields the original halting verdict. It asserts equality on the equality tag, and rejects inequality on the other. Since the actual completed formula for the second database computes this test too, $a'=a$.

Set $t=\epsilon m$. For a sufficiently small constant $\epsilon>0$ the length displayed above is at most $L/2$ for large $m$: $m/L\to0$, $K\log m=o(L)$, and $|V|\lceil\log_2 K\rceil\le(\eta+o(1))L$. Thus at most $2^{L/2}$ of $K^m$ diagonals have *any* cheap sign or program. Every other diagonal supplies the stated common opposite pair. A machine with code length bounded independently of $m$ fits the model, as do the correct members of an increasing finite program-size docket satisfying the uniform controller and roster bounds.

## Actual time on the family

The input contains the two fields to compare at neighboring, known physical addresses. A RAM can scan those pairs, validating their format and accumulating a mismatch bit. It can also scan all $A_i$ first, store the symbols, then perform the same comparisons on the query pass. On this latter program every single database symbol can be disclosed before the first genuine query. The computation across adjacent words is still only one constant-cost symbol comparison per position, including all layout and digit validation. In the supplied layout the difference of the physical word count and declared clause count recovers $m+1$. Tabulate packed decimal spellings for the $O(m)$ scaffold indices from the already packed spelling of their quotients by 10, or with a decimal odometer, and regenerate each prescribed public word in constant word operations. An $O(K)$-entry dictionary validates symbol fields using sparse direct addresses. On mismatch transfer to a complete SAT procedure preserving the original file. The globally correct fast path takes $O(m)$ steps on the whole family. [Recognition details and the all-prefix theorem](graded-prefixes-of-a-packed-equality-file.md) Consequently this theorem prices a full scan's worth of non-load processing under unrestricted prefix storage. It does not give an exclusion of linear time in the encoded length; multiplying this charge by the number of overlapping descriptions of the same pairs would count the same comparisons more than once.

The static lower bound attains a more general ceiling. If a database owner can store a query-independent $N$-bit template and a $b$-bit description of its variable locations, and the query plus these strings determine the whole ordinary SAT file, any query can be answered with $O(1+(N+b)/W)$ deterministic cell probes under unlimited local computation. Read the packed template and directory, reconstruct the file and decide it locally by exhaustive search. An arbitrarily long **adaptive batch** of queries on the same template and directory obeys the *same total probe bound* if local state is retained across queries: cache those words once and use them for every reconstruction. Here $b\le m+O(1)$, so the $\Omega(m)$ static diagonal lower bound matches this upper. In fact the number of switches of ownership gives a sharp interpolation between separated clauses and the present mixed-digit files. [Boundary-count theorem](equality-with-boundedly-many-switches-of-input-ownership.md) The probe computation treats maintaining or computing with the local state as free. On a 24-coordinate pair, at their respective first variable-query reads three concrete scanning strategies had already read all 24, three, and zero physical data halves. All had the predicted common prefixes and all 48 private words were pivotal. These are traces of aligned word accesses, not a formal enumeration of arbitrary RAM programs.
