# A lower bound of 5/2 native instructions per input word for fixed SAT programs

Let \(m=N/w-O(1)\). There is an explicit family of satisfiable, ordinary proper DIMACS files \(F_N\) such that every **fixed finite** correct program \(P\) on the separate-operation logarithmic-word RAM satisfies
\[
 \liminf_{N\to\infty}\frac{T_P(F_N)}m\ \ge\ \frac52 .
\]
Lengths are byte-aligned, with byte-aligned native width \(w=\Theta(\log N)\) and \(2^w\ge N\). The two width rules below are covered whenever the resulting word width is itself divisible by eight, namely \(16\lceil\log_2(N+2)/16\rceil\) and \(12\lceil\log_2(N+2)\rceil\).
The machine has the twenty numerical operations listed in the [native catalog](native_four_bit_planes.hpp), direct and register-indirect loads and stores, fixed-target comparisons, and fixed verdicts. A memory access consumes a register or an immediate for its full address. Input is little-endian in a zero-initialized store. There is unrestricted workspace and arbitrary program-dependent code, constants, and register count.

The file itself is independent of \(P\). An additive constant in the operation count depends on \(P\). A code size allowed to grow with \(N\) changes the answer: a separate program can hardwire the addresses and check this positive file in \(2m+O(1)\) instructions. A single fixed scan takes \(3m+o(m)\) on the positive family. The units are physical words of \(w\) bits, so this remains a packed-scan bound for ordinary SAT. ## One-bit edits in complete native words

Write \(U=2^w,\ W=w/8\). Each marked word completes the preceding clause and starts the next. It begins with a space, then spaces up to byte \(k\), then one digit \(d\in\{6,7,8,9\}\), followed by the six-byte string's remaining characters \(\texttt{ 1 0}\) and newline. The remaining bytes are spaces except for the last byte, digit \(\texttt{4}\). Call this value \(A\). In the alternative word \(B\) the last byte is \(\texttt{5}\), changing one physical bit. In particular \(A\) is divisible by 32, both have positive signs, and \(A/U\) lies between \(52/256\) and \(53/256\).

A public prefix fixes \(x_1,x_d,x_5\) false and \(x_4\) true. For each forced literal \(L\) use the four sign choices of \(L\lor(\pm x_2)\lor(\pm x_3)\). The prefix ends at a word boundary with digit \(\texttt{4}\) starting the first repeated clause. After the \(m\) marked words append whitespace followed by \(d,\texttt{1 0}\) and newline to complete the last clause. The header declares \(m+17\) clauses. All original clauses hold. Each individual replacement falsifies the clause initiated by the changed byte. Any subset of the edits preserves a valid proper DIMACS file; exactly six variable names occur.

With a sufficiently large fixed \(C\) use \(m=\lfloor N/w\rfloor-C\), align the prefix by inserting spaces immediately before its final digit, and fill any remaining bytes with spaces. The public prefix and trailer use \(O(1)\) native words. The marked addresses form a positive interval \(I\) of length \(m\) with minimum \(O(1)\). Put \(\ell=\lceil\log_2(1+\max I)\rceil\). Then \(2^\ell=\Theta(m)\) and \(w-\ell\to\infty\) because \(2^w\ge N\). Thus \(A\equiv B\pmod{2^\ell}\) at large widths.

Take \(k\) with \(w/32768<256^k\le w/128\), which gives \(k\ge1\) eventually. Select \(d\) so \(r=A\bmod w\) has circular distance at least \(w/100000\) from \(0,w/2,w-\ell\). The four possible residues differ by steps \(256^k\), fit in a circular arc of length \(3w/128\), and have pairwise circular distance above \(w/32768\). Each of the three forbidden neighborhoods removes at most one. In determining \(\ell\), the four candidate layouts can use the same prefix alignment: digit \(d\) always has one character and the header can declare nine variables for all of them. At finitely many small widths the family can be defined arbitrarily.

## Which instructions can first produce the required addresses?

Follow \(P\) on the positive file. For each of the \(m\) marked cells select its first original-word load. It must occur before any overwrite because the one-cell alternative flips the verdict. The set of initially available numerical values consists of the finite program's immediates, the initialized register values including any public width and length words, zero, the raw word \(A\), and the \(O(1)\) distinct public input words. Its size is at most \(L=O_P(1)\), uniformly over lengths. A load from scratch can only recover a value previously stored there or the initial zero.

Every selected address \(t\in I\) outside this initially available set must have a **first numerical producer**, an executed numerical instruction returning \(t\). Loads, stores and pure register copies cannot create its numerical value for the first time. These chosen instructions are all distinct and disjoint from the selected loads. Write \(g\ge m-L\) for their count and \(E=T-m-g\) for the other executed instructions. Let \(h\) be the number of distinct additional numerical values outside \(I\) beyond the initially available values. Each has a first numerical producer in those \(E\) slots, so \(h\le E\).

For each of the \(m\) single-word edits, charge its first effective consumption on the base execution. Until that point the only differing memory is the one original word, and register differences are \(A\) versus \(B\) in registers loaded from its unoverwritten original. A numerical operation is effective when its result differs, a branch when its outcome differs, a memory access when its address differs or a store writes a different payload. Equal numerical results erase any discrepancy from their consumed operands. An unchanged-address load of the edited original merely supplies another raw register. If the original is overwritten with the same baseline payload on both runs, its continuing memory discrepancy disappears. If no effective consumption ever occurs, the runs have the same verdict, a contradiction.

Thus each charge uses a raw value with a particular original address as its provenance. One executed instruction can receive at most two charges, one per explicit operand. The selected original loads cannot receive charges because every selected address is small and \(A\notin I\). A store of a raw value or an indirect load using it pays for its first effect immediately; no later alias must be assigned that charge.

Among the \(E\) other instructions, the \(h\) first producers of new outside values can receive at most one charge apiece except when both base operands are \(A\). In that case their distinct outputs are among the fixed opcode values \(f(A,A)\), so there are \(O(1)\) exceptions. All \(E\) slots together receive at most \(2E-h+O(1)\) charges. A true unary numerical instruction merely adds a bounded number of possible results on \(A\). It remains to bound charges received by the \(g\) chosen first producers of addresses. Repeated calculations of the same numerical address have already gone to the \(E\) slots.

## At most two generic fresh addresses per outside operand

A chosen first address producer receiving a charge uses a raw \(A\). Let \(y\) be its other baseline operand. The following estimate counts numerical output values, so an exceptional set of \(o(m)\) addresses applies once over the entire execution. For a doubled raw operand \(y=A\), a single instruction could receive two charges. Its result is among the \(O(1)\) values \(f(A,A)\).

* The possibilities from a small partner \(y\in I\) have \(o(m)\) distinct sensitive outputs in \(I\), across all such \(y\).
* Outside a further \(o(m)\) exceptional output values, a fixed partner \(y\notin I\) can contribute at most two sensitive outputs in \(I\). Different partners may supply different pairs.

The estimates use the actual operation tables. For example \(A\mathbin{\&}y\) has a zero in every eighth low bit of the output for all \(y\), since the input is ASCII. If small XOR or subtraction is possible, \(y\) lies in a short interval near \(A\). There small AND and addition are impossible, leaving only XOR and at most one subtraction direction. If small addition is possible, \(y\) lies near \(-A\). On any interval of \(O(m)\) possible partners, the small product, right-shift, and rotation values are sparse. The multiplication estimate uses \(255\cdot256 A=a2^w+e\) for a fixed \(a\) and \(|e|=\Theta(w)\). Such a short interval of partners meets only \(O(1)\) preimages of the small output interval under multiplication by \(e\). Outside the arithmetic neighborhoods, only the product and one of the right shift or two rotations can supply nonsparse distinct values. The shift claim uses the two cyclic zero intervals on a small rotated word and the choice of \(r\). Every orientation of each instruction is accounted for in the [full numerical image proof](small-address-images-of-shifts-and-products.md).

There are at most \(h+L\) outside partners on the base. The \(m\) sources therefore satisfy
\[
 m\le 2E-h+2(h+L)+o(m)+O(1)
   \le 3E+o(m)+O_P(1).
\]
Since \(T=m+g+E\ge 2m-L+E\), this proves a coefficient of \(7/3\) already for the one-bit editing promise. The deficit term from a fixed finite roster can be made common to the entire roster by taking its largest finite constant.

## Pairing a scalar with the instruction that first supplied it

For the full SAT lower bound, keep the **same positive physical file** and choose a different valid word \(B'\) for the singleton alterations. It has final digit 5. Its padding between the preceding newline and that final digit consists of whitespace chosen so that \(A\equiv B'\pmod w\). The meaningful literals are unchanged from the one-bit alternative. For \(w=2^s q\) with \(q\) odd, use only bytes high enough to preserve the residue modulo \(2^s\). Modulo \(q\), each free byte offers a translate of \(256^i\{0,1,23\}\), using TAB, line feed, or space. These additions cover the cyclic group after at most \(\lceil(q-1)/2\rceil\) positions for \(q>23\). There are \(W-O(\log w)\) free positions and \(q\le W\). A finite dynamic program makes the choice uniform. [Cyclic growth proof and direct ordinary-file test](matching-the-native-shift-count-with-dimacs-whitespace.md)

Repeat the first-effective-consumption count using \(B'\). This time no full or modulo shift or rotation with raw \(A\) as the count can receive a charge. Both full counts saturate, including on a signed shift, and both modulo counts coincide. Shifting or rotating \(A\) as the data can produce only \(O(w)\) distinct values, regardless of the partner. Small AND has only \(o(m)\) possible results because the high bit of each ASCII byte of \(A\) vanishes. Small OR is impossible. These are facts about the fixed base \(A\); no equal low-bit assumption on \(B'\) is used here.

Write \(D_0=2^\ell=\Theta(m)\). An interval of \(O(m)\) source values \(z\) has only \(o(m)\) possible \(z\)'s for which \(Az\bmod U\) belongs to **any specified interval** of \(O(m)\) target values, including intervals away from zero. Indeed \(D A=aU+e\) with \(D=255\cdot256\) and \(|e|=\Theta(w)\). The integers \(ez\) traverse a segment of length \(O(|e|m)=O(U)\). A target interval of length \(O(m)\), multiplied by the fixed \(D\), occupies a segment of length \(O(m)=o(U)\) modulo \(U\). Only \(O(1)\) translates can meet the first segment and each contains at most \(1+O(m)/|e|=o(m)\) values of \(z\). Wrapping intervals split into two. This is the translated form of the [small-product estimate](small-address-images-of-shifts-and-products.md).

Remove a shared exceptional set of \(o(m)\) charged first-address producers from the counts below. It includes small shifts, comparisons, and AND values, and small products whose partners are in any of the boundedly many intervals used in the argument. A single removed producer receives at most two charges. Partners among the \(O_P(1)\) initial scalar values contribute at most \(O_P(1)\) further nonsparse address charges. For each of the \(h\) genuinely new outside scalars \(y\), let \(c(y)\) count first consumptions charged to its own first production and \(b(y)\) the remaining charged first-address productions with other operand \(y\). Each address producer has just one such partner after discarding the \(O(1)\) numerical values \(f(A,A)\). Similarly \(c(y)\le1\) after a bounded number of exceptions. We have the following possibilities for \(b(y)\).

1. In the \(D_0\)-neighborhood of \(A\), multiplication is sparse. Two distinct useful addresses require both \(\tau=A\mathbin{\mathtt{xor}} y\) and \(\sigma=|A-y|\) to belong to \(I\), with \(\tau\ne\sigma\). This yields \(b(y)\le2\).
2. In the \(D_0\)-neighborhood of \(-A\bmod U\), only addition can supply a nonsparse small address. Away from the two neighborhoods only the product can do so, giving \(b(y)\le1\). These statements include the previous elimination of the small arithmetic outputs of partners in \(I\).

The total \(c(y)+b(y)\) can exceed two only for a scalar \(y\) with \(c(y)=1,\ b(y)=2\). Both \(\tau,\sigma\) are then genuinely first produced **later** than \(y\), by two different instructions. The instruction that generated \(y\) was itself charged by a raw source. Let its other operand be \(z\).

* If \(y=A\mathbin{\&}z\) or \(A\mathbin{|}z\), one of \(A,y\) contains every set bit of the other, giving \(\tau=\sigma\). XOR would give \(z=\tau\), already numerically available, contrary to its later first production.
* If \(y=A+z\) or \(A-z\) modulo \(U\), the possible operands are \(\sigma\) and \(-\sigma\bmod U\). The former is excluded by its later first production. Reserve the earlier scalar \(z=-\sigma\bmod U\). If \(y=z-A\), reserve \(z=A+y\bmod U\).
* If \(y=Az\bmod U\), reserve \(z\) itself. If \(z\) is in \(I\), near \(A\), near \(-A\), in \(-I\), or near \(2A\), it ranges over a bounded union of intervals of length \(O(m)\). The product lands near \(A\). The translated product estimate bounds the number of such \(y\) by \(o(m)\); remove their excess as well.
* The remaining instruction types cannot produce more than \(O(w)\) such charged \(y\)'s. Numerical comparisons have bounded range. Shifting the raw value has \(O(w)\) outcomes, and using it as a shift count has no effect under this edit. A unary opcode acting on a raw value supplies a single possible result per opcode.

The reserved scalars in \(-I\) and in the neighborhood of \(2A\) are outside the two arithmetic neighborhoods. Products from those short source intervals into \(I\) were removed by the same interval lemma. Thus both kinds have \(b(z)=0\). In the product case \(z\) is outside the arithmetic neighborhoods and its only generic small address could be \(Az\bmod U\). That very product is \(y\), near \(A\) and outside \(I\). Hence again \(b(z)=0\).

The reservations are distinct. Two scalars assigning the same \(-\sigma\) would claim the same later first producer of address \(\sigma\), which has a single assigned partner. The rule \(z=A+y\) is injective in \(y\), as is assigning \(z\) with fixed product \(Az=y\) in the direction needed here: one \(z\) has just one product. The intervals \(-I\) and \(2A+[-D_0,D_0]\) are disjoint at large widths. Product reservations in either interval were removed. Removing the \(O_P(1)\) cases with preavailable \(z\) is harmless. No reserved scalar can itself have high charge, since it has no later address charge.

Each remaining high-charge scalar and its reserve contribute at most four charges together. Each unpaired new outside scalar contributes at most two. Including the \(E-h\) surplus slots not used to first produce an outside scalar gives
\[
 m\le 2(E-h)+2h+o(m)+O_P(1)=2E+o(m)+O_P(1).
\]
Together with \(T\ge2m+E-O_P(1)\), this is \(T\ge(5/2-o(1))m\). The positive inputs have one-bit negative neighbors at every designated word. The stronger \(5/2\) proof also uses legal multi-byte whitespace alternatives, and the \(7/3\) proof alone applies to a solver promised only the original one-bit alternatives.

## A uniform upper and its relevance to the time goal

One fixed program with public length and width words generates the public layout and the expected repeated word in \(\operatorname{poly}(w)=o(m)\) steps. All residue computations and decimal header formatting take polynomially many bit operations. Check the \(O(1)\) public words and any final partial word. Starting just before the first marked address, repeat three instructions: increment the pointer, load its word, and branch back to the increment if the loaded word equals \(A\). At the first mismatch, check the actual pointer against the known first trailer address. The ordinary trailer word differs from \(A\) since it has no trailing initial digit for another clause. Upon any failed check call a complete SAT solver. This recognizes exactly the target file before the fast acceptance and takes \(3m+o(m)\) actual instructions on it. The two-record promise has the same upper order. The file enforces separate costs for address generation and input processing, but those costs still have bounded sum per packed word.

Standard RAM cost conventions distinguish address calculation, storage access and arithmetic. The repertoire matters for the coefficient in this theorem. The asymptotic per-bit SAT lower bounds in the time-space literature address a different range and impose a workspace tradeoff. A targeted search found no prior source stating this particular fixed-program coefficient; priority is unconfirmed.
