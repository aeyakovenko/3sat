# Simulating the first additional address calculation in a six-slot scan

Consider a stream of RAM loads $x_i=M[p_i]$ at public addresses $p_i=S^i(p_0)$ for a permutation $S$. There is a single compulsory store between successive loads, $M[x_i]\gets p_{i+2}$. Branches may terminate the run early. This covers a particular six-slot architecture: two comparison branches, one LOAD, one STORE, an increment of a scan counter, and a second ALU that computes a two-address lookahead into a separate register. Require all four data sites on the continuing cycle with this read/write schedule, so a branch has no access to an additional memory word. For a modular increment, all address registers are public throughout a continuing run. The loaded word is available to the comparisons. Other six-slot arrangements are outside this proposition.

The two-address example writes arbitrarily many words in one pass even from a constant memory image. Nevertheless there is an exact small-space simulation. Let $L$ be the period of $p_0$, let $h$ count all initial word values including a possible one-store prologue payload, and put $P=\lceil m/L\rceil$ for a run with $m$ loads. Until the first event satisfying $x_i=p_{i+1}$, at most $1+(P+1)(2P+1)h$ distinct addresses have been written. After that event every subsequent load on the continuing run is known as a function of its index. [The one-address last-writer bound and the dense two-address example](ancestry-of-crossed-stores.md)

Indeed, equality at $i$ makes the next write set $M[p_{i+1}]=p_{i+2}$. The next read is at $p_{i+1}$ with no intervening writer, so the equality propagates. Before the first such equality associate $(p_i,x_i)$ to each read. If its value is from an earlier scan write at $u$, the pair transforms by $F(a,b)=(b,S^2(a))$. Along two successive last-writer links $u<j<v$ we have $p_v=S^2(p_u)$ and $v-u\equiv2\pmod L$. The possibility $v=u+2$ would force $j=u+1$ and $x_u=p_j=p_{u+1}$. This contradicts the prefix condition. Thus $v-u\ge L+2$. The argument also works at $L=1,2$ because $v-u\ge2$ before excluding equality. Each pair of links consumes a full pass, and an unmatched final link contributes at most one further application of $S^2$ to a transported root value. As in the one-address proof, every pair has an endpoint in $U=\bigcup_{t=0}^{P}S^{2t}(H)$, a set of size at most $(P+1)h$. In particular the displayed, looser $(2P+1)h$ bound holds. Addresses inside $U$ count once; for each write to an address outside $U$ the read took place in $U$, at most $P$ times per position. The first equality itself may be processed directly without recording its store. A final exit before the scheduled STORE is harmless.

The simulator keeps a dictionary up to this equality. It then executes all remaining register and control operations with the exact public loaded values and can omit subsequent writes when there are no later off-schedule reads. A dense interval of changed memory therefore need not imply large simulation space. With a fixed modular increment of nonzero integer $a$, period $L\ge2^w/|a|$ and word width $w=\log_2 N+O(1)$, the same witness and sparse-input arguments as for five slots rule out a worst-case $O(N^{11/10})$ DIMACS solver of this particular six-slot form. Variable renaming gives the same $6/5$ refinement under ordinary DIMACS naming. For a three-address lookahead, a single equality need not determine every later read. On one increasing pass start with $M[0]=1$ and give each address $3j+2$ an independent value from $\{0,1\}$. Before wrap, reads at $3j$ give $3j+1$, those at $3j+1$ give $3j+3$, and each read at $3j+2$ returns its original bit. Stores from these latter positions hit only 0 or 1, already read. This identifies the failure of the equality-propagation proof at the next lookahead without implying a time upper bound for SAT.
