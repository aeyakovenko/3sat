# Recovering a unique model along a path of two-bit edits

Let a proper 3-CNF of encoded length $N$ have exactly one satisfying assignment on its $v$ occurring variables. Any correct deterministic SAT decision program can be used to recover that assignment in at most

$$\lfloor 2v/3\rfloor+3\lceil\log_2(16v)\rceil$$

calls for $v\ge1$. Every queried file is an ordinary proper 3-CNF of $N\log^{O(1)}(N+2)$ bits with zero or one model. They can all be chosen **nonadaptively**, each at one specified physical bit flip from a common, satisfiable center. Consecutive queries then differ in at most two bits. Constructing the initial template and decoding a recovered code each take $N\log^{O(1)}(N+2)$ RAM time. One may use the standard $v$ variable-pin queries when that bound is smaller, with the same two-bit update layout. The empty assignment covers $v=0$.

The factor $2/3$ is the classical satisfiability coding bound of Paturi, Pudlák and Zane. Impagliazzo and Paturi already describe searching a circuit on compressed witness bits, and deterministic PPZ uses small permutation families. The construction here computes **one specified short seed from each source model** in quasilinear time. This preserves model counts through the conditional queries, including negative answers, and permits the two-edit implementation. Priority for this combination has not been established. [Paturi, Pudlák and Zane, Lemma 2](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/PaturiPudlakZane_1999_cjtcs.pdf) · [Impagliazzo and Paturi, §1.2](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/ImpagliazzoPaturi_2001_jcss.pdf) · [Horiyama et al., Lemma 13, citing PPZ](https://drops.dagstuhl.de/storage/00lipics/lipics-vol358-ipec2025/html/LIPIcs.IPEC.2025.25/LIPIcs.IPEC.2025.25.html)

## A quasilinear encoder with one seed per model

Given a satisfying assignment $a$, let $j$ count its isolated variables, those whose individual flip destroys satisfaction. For each such variable select the first clause in file order whose only true literal is that variable's occurrence. A scan finds all $j$ selections. Give the occurring names public dense indices $0,\ldots,v-1$. Arbitrarily long decimal names can be normalized and interned using a trie of their digit strings in $O(N)$ word operations, with the first-occurrence order for the dense indices. The canonicalization and all computations below have deterministic tie rules.

Set $b=\lceil\log_2(16v)\rceil$. Work in a fixed polynomial basis of $K=\mathbb F_{2^b}$. For example choose the first monic irreducible of degree $b$ in coefficient order. Testing every candidate still takes $O(v\operatorname{poly}(b))$ bit operations by modular squaring and polynomial gcd. Use the public order of binary basis representations. For a seed $s=(A,B,C)\in K^3$ order names $u$ by $(Au^2+Bu+C,u)$. A uniform seed gives independent uniform hash values on any three distinct names by quadratic interpolation. With no tie each member of a triple is equally likely to come last. A union bound on the three equalities gives probability at least $1/3-3/2^b$ for the designated member to come last after the prescribed tie rule. For the $j$ chosen clauses the expected number of successes is greater than $j/3-1/3$. The integral optimum is at least $\lceil j/3\rceil$, including when $j=0$.

Compute a single seed achieving this bound given $a$. Visit its $3b$ binary coordinates in a fixed order and choose the bit maximizing the conditional expected number of successes, breaking equality towards zero. For each chosen clause and partial seed, count completions that put its designated name after each of the other two. For each comparison enumerate the first differing hash position, or a tie allowed by the name order. Equal earlier bits and the required pair $1,0$ at the first difference are linear equations in the remaining seed bits over $\mathbb F_2$. Field multiplication by the fixed names and their squares is linear in the coefficients. Each pair of comparison cases therefore costs one Gaussian elimination on $O(b)$ variables and equations. The $O(b^2)$ cases are disjoint. Sum their solution counts, each zero or a power of two. Conditional hit counts for both candidate seed bits have the same denominator and $O(b+\log(v+1))$-bit numerators after summing the $j$ clauses. The $3b$ rounds take $v\operatorname{polylog}(v+2)$ bit operations. The selected seed reaches the initial expectation.

In that order assign each variable by its currently active unit clause if present, otherwise copy its value from $a$ into a guess tape. A selected head that comes last in its clause already has a unit forcing it. The tape therefore uses at most $v-\lceil j/3\rceil$ bits. Conversely, given the seed and guess tape, the PPZ decoder recovers $a$. Along a satisfying path any simultaneous units for the current name agree. For every variable in order, its signed occurrence lists suffice to test which incident clauses already have all other literals false. Each clause is inspected a bounded number of times in both encoding and decoding. Sorting the hash keys and writing the assignment fit the quasilinear bound.

More generally fix a public threshold $j_0\le v$. Retain models with $j\ge j_0$. Append the recorded guesses to the seed and pad them with zeros to exactly $v-\lceil j_0/3\rceil$ guess positions. Each retained source model has exactly one code, and different models have different codes by deterministic decoding. For a unique source take $j_0=v$.

## A parsimonious template and consecutive edits

Use the source assignment as the primary variables. Check the source, compute $j$ and its canonical padded code by the preceding deterministic procedure, and expose its bits. A clocked deterministic RAM verifier has a quasilinear parsimonious ordinary-CNF simulation using chronological CPU records, deterministic memory sorting and gate equivalences. Fixed initial memory, padding and terminal records give one table per primary assignment. Fix all declared padding names if the counting convention includes unused names. The input-specific template and its proper ternary padding can be generated in the same quasilinear bound. For each fixed prefix of code bits, its number of models is exactly the number of retained source assignments whose canonical codes start with that prefix. [Parsimonious RAM transcript and proper CNF construction](projected-parity-holes.md#a-parsimonious-ordinary-3-cnf-near-the-native-clock)

For each code position $i$ reserve three variables with positive decimal identifiers $10i+0,10i+1,10i+3$, using a disjoint range of positive $i$. Force them to equal, respectively, true, the complement of the code bit, and the code bit. Put one selectable positive identifier in a clause with two distinct fixed-false variables. Its last digit $0,1,3$ gives the three modes unrestricted, prescribed zero, prescribed one. The transition $0\to1$ and the transition $1\to3$ each flip one bit of a single ASCII digit. All declared names can be made to occur and any gaps forced by linear-size padding in the number of reserved names. Under full-header counting, every otherwise unused declared name is thereby fixed. [Two-bit warm repair on proper DIMACS](two-bit-warm-repair-of-unique-3sat.md)

On a unique source, start from the all-unrestricted center. For each code position independently change its digit from $0$ to $1$. There is one code at the center, so the resulting file is satisfiable exactly when that code bit is zero. All masks are known before any call, every queried file differs from the center in one bit, and the full collection of answers fixes the code. One can thus amortize preprocessing of the same center across all calls whenever a warm-query method is available. A completely precomputed answer table for all one-bit flips would serve here, with its construction time charged.

For a source with several retained models, nonadaptive bit answers can belong to different models. Prefix search instead works as follows. Start with all positions unrestricted. At each step prescribe zero at the next position. A positive verdict leaves it at zero, while a negative one fixes its value to one because the preceding prefix was feasible. The next queried file therefore changes at most one old digit and one new digit, with one physical bit per change. Knowing the source is positive removes the need for an initial decision. If only zero-or-one is promised, one initial feasibility query suffices. After the last answer, decode the model from the code. No reconstruction of a rejected computation is required.

The common center and the compressed model are computable objects of different costs. Initial template construction does not use the unknown model, while computing its canonical seed uses the model inside the verifier. The query count remains linear in $v$. A fresh execution on each length-$L$ query costs up to the decider's full worst-case time at $L$. Even a common parsimonious template and two identified input changes give no general bound here on how much work its executions can share. These estimates leave the unrestricted linear, quadratic and cubic SAT clocks open.

The [finite audit](parsimonious_witness_code_audit.py) compares exact linear-system counts to full enumeration for all 1,524 triple-and-prefix cases over the four-element field. On the 256 formulas formed from subsets of all eight proper clauses on three declared names, it checks 1,024 formula/model pairs, including the compressed single-bit query responses for all eight uniquely satisfiable cases. It tests the finite coding and pin calculations. The asymptotic runtime and full transcript compilation above are proved on paper.
