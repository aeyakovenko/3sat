# How much state must an adaptive read-only SAT program bring to one input address?

Consider a deterministic word RAM with read-only input, register computation and no writable memory other than its controller state. At a LOAD the old contents of the destination register can be discarded once the address has been evaluated. A **context at a probe** specifies the LOAD site and the live state just before the reply: it must determine the entire post-LOAD state given either of the two possible reply words. This is an upper-bound criterion that can be checked directly on instructions. The controller may choose every probe adaptively and may take unlimited time.

**Theorem.** There are proper ASCII 3-CNFs indexed by a Boolean truth table $T$ on $t$ bits and a string $u$ of $t$ address bits, with SAT value $T(u)$. For a fixed table, only $t$ distinct packed words depend on $u$, one per bit. If the RAM decides these files, then for some table and one of its private words there are $\Omega(2^t/t^2)$ different reachable probe contexts across the $2^t$ choices of $u$. In a bounded-word-alphabet version at lengths $n=\Theta(2^t t^2)$, this is $\Omega(n/\log^4 n)$ contexts at one address. They can occur on different executions. A correct machine need not visit that address many times on one execution.

## Encoding arbitrary truth tables by satisfiability

Give a full binary tree of height $t$ distinct variables for its nodes. Give level $j$ a separate selector variable $u_j$. For each internal variable $v$ with children $l,r$ include four clauses
$$
 (u_j\lor\neg v\lor l),\quad (u_j\lor v\lor\neg l),\quad
 (\neg u_j\lor\neg v\lor r),\quad(\neg u_j\lor v\lor\neg r).
$$
Once the selector is pinned, these equate $v$ to the selected child. Reserve three other names $a,b,z$ and use the seven proper clauses forbidding every assignment except $(0,0,0)$ to them. Pin each leaf to its table entry, each selector to its private bit, and the root to true, by a clause $(\pm v\lor a\lor b)$. Upward induction forces a unique node assignment once table and selectors are given, and the forced root equals $T(u)$. All clauses use three different names.

Serialize the signs in space-or-minus slots and align each selector's sign byte in its own packed word. Both variants are proper DIMACS. Other bytes in that word are fixed. The tree and all table signs are public when $T$ is fixed. The same physical length and selector word addresses work for every $T,u$ of a given order. With ordinary dense names this takes $O(2^t t)$ bits, allowing padding to $\Theta(2^t t)$. A selector occurrence elsewhere in a tree clause is a *fixed reference to the same variable*. Only the sign of its pin changes.

For the small-alphabet version, use the [aligned name encoding](orbit-orders-and-parity-pinned-sat.md#encoding-a-sparse-system-of-parity-equations). After a leading 1, encode each bit of a name's index by a full word of zero digits with last digit 0 or 1. Fixed-size sign/leading-digit blocks, terminators and the three short dummy names need only a bounded number of other word types. The largest used index needs $O(t)$ bits. The header declares the largest corresponding decimal identifier, and its decimal clause count takes $O(1)$ words. Since the header name consists of encoded bits, a fixed byte alignment gives at most a constant number of word types even there. Choose a large fixed $C$, select a byte-aligned length $n$ near $C(D+1) 2^t t^2$ for the journal word rule $w=16\lceil D\log_2(n+2)/16\rceil$, and append ordinary whitespace. With $w=\Theta_D(t)$ the tree fits, and any partial final word supplies just one additional type. Across all settings the original RAM words, including zero, have a palette of size $h=O_D(1)$. This version uses the DIMACS convention permitting unused variable identifiers.

## Contract the walks through public memory

Fix a table. For each private address, collect all live contexts that actually occur there on some input $u$. Let $K$ bound their number per address for all tables. Give each of the $t$ private sites $K$ vertex slots. The slots may be named afresh for each table. Their labels as queries of a particular bit are fixed by their positions in this array; the numerical machine states need not be written into the graph.

From each reachable slot and each reply bit follow the deterministic continuation to its next private probe, verdict or divergence. All intervening reads have fixed public values for this table. The same live context and reply therefore give an unambiguous edge, even if the original run spent an unbounded time before that probe. An edge reached only on inconsistent histories may be filled arbitrarily if its target is absent; all genuine executions still follow their own path. The initial continuation similarly supplies a starting slot or terminal. Include three terminal symbols for the two verdicts and divergence. This produces a directed graph with one start choice and two edge choices for each of the $tK$ slots. Loops are allowed.

Consequently the number of different functions realized is at most
$$
 (tK+3)^{2tK+1}.
$$
Every one of the $2^{2^t}$ tables must give its own function of $u$. If $tK\le2^t$, take one base-two logarithm and use $\log_2(tK+3)\le t+2$ to get $2^t\le (2tK+1)(t+2)$. If $tK>2^t$, the stated bound already follows. This proves the theorem. This is the subfunction-counting argument underlying Nečiporuk's method applied to the live states at actual RAM probes. The argument and its use in branching-program lower bounds predate this journal. [Beame, Grosshans, McKenzie and Segoufin](https://arxiv.org/abs/1608.01932)

## Five stored instructions

Suppose a read-only five-slot program has two branches, a single LOAD $x\gets M[p]$ with $x\ne p$, and two numerical sites. If $x,p$ are its only mutable registers, a fixed private address fixes $p$, and the LOAD overwrites $x$. At that instruction there is exactly one possible live context for the address. It follows that **no such program decides SAT at any speed**, even when its next address depends on previously loaded data and both numerical instructions update it. The same conclusion holds for a single self-addressed mutable register. No classification of opcode pairs is needed for these cases.

**An eight-clause witness for the two-register class.** Take all six clauses $(\pm x_1\lor s x_2\lor r x_3)$ with signs $s,r$ other than $(+,+)$. These leave just the two assignments with $x_2=x_3=0$. Append $(\pm x_1\lor x_2\lor x_3)$ twice, choosing the two signs independently. The resulting four files have verdicts SAT, UNSAT, UNSAT, SAT. Each is 87 bytes. Under the model's standard 16-bit words at this length, the only changing bytes are at zero-based offsets 69 and 78, in words 34 and 39. Eight clauses are minimal for an unsatisfiable proper 3-CNF since each clause excludes exactly one eighth of assignments. This establishes minimal clause count for a four-file witness containing both verdicts; shorter byte encodings may exist.

After contracting public steps, there is one query vertex for each of those two words. Enumerating all $5^5=3{,}125$ graphs (a start and four edges, each with five destinations) gives 14 total two-bit functions. Exactly XOR and equality are missing. On a fixed pair of signs, any trajectory that revisits a query vertex repeats forever. The [Lean proof](TwoPrivateProbeSites.lean) verifies the equality obstruction with arbitrarily many allowed steps, the truth function of the eight clauses, their literal 87-byte strings, the little-endian layout, and the impossibility for a read-only CPU with registers $x,p$, a program counter and a fixed-successor LOAD. The executable audit separately parses the strings as DIMACS. This gives an actual finite suite for one uniform machine class, independent of its literals or time. A different five-slot program handles these four files with two direct LOADs at 34 and 39 and three comparison branches implementing equality. [Files and graph enumeration](table_probe_context_audit.py)

There are also three-register cases. Suppose $x$ is solely the LOAD destination, with one numerical site writing $p$ and one writing $y$ in each continuing turn. For the following bounds use the small-alphabet files, with raw word $v$ in their palette $H$. For example:

* If a write to $y$ after the last update to $p$ and before the next LOAD has the form $y\gets G(p,x)$, then $p$ is already the specified private address and $x\in H$. Thus at most $h$ different $y$ values survive. The first partial turn adds at most a constant in this regular-cycle convention.
* If the address update is $p\gets F(y,x)$ and, for each fixed $v\in H$, the equation $F(y,v)=p$ has at most $\mu$ solutions, then at most $h\mu$ pairs of $y,v$ can have produced a specified address. A later numerical update of $y$ before the next LOAD is a deterministic function of this pair and the fixed $p$. Thus $K\le h\mu+O(1)$. This includes addition or subtraction in either order, XOR, and rotation of $y$ by the raw count. A fixed invertible map $p\gets F(y)$ with no intervening $y$ update gives $K=1$ on complete turns.

These examples assume the fixed register conventions at startup. If a case permits more than one exceptional context at an off-cycle private probe, include all its contexts in $K$ as the general theorem requires. In particular a five-slot read-only program with all three data sites on the unique cycle and the single LOAD specified above has no extra LOAD on its exit path. The analysis gives no upper bound on $K$ for a general update using both the old cursor and an independently changing register. A write to ordinary RAM would also leave state between probes not encoded by the register tuple. The [complete read-only case split](read-only-five-instructions-on-ordinary-sat.md) combines this method with separate opcode arguments for the remaining allocations. ## Moving the pins removes the bounded-fiber assumption for the standard width

For $p\gets F(y,x)$ as above, the conclusion in fact holds for **every** fixed word function $F$ at the standard width ($D=1$), and more generally for fixed $1\le D<2$. Choose the bounded-alphabet layout with enough trailing padding to translate the whole selector-pin section together by any of $L=\Theta(n/w)$ consecutive word offsets. Insert the corresponding number of all-space words before this section and take the same number from the trailing padding. Start at a word boundary, between clauses, and preserve the aligned header and the palette $H$ over all translations and truth tables. No change to the semantics occurs. There is only one LOAD on the cycle. Before its first execution the initial registers and partial-turn actions are input-independent at this fixed length, so at most one additional context per site suffices.

For $a\in\{0,\ldots,Q-1\}$ put $m(a)=|\{(y,v):v\in H, F(y,v)=a\}|$. Then $\sum_a m(a)=hQ$ because the pairs are partitioned by their output. If the unshifted private addresses are $a_1,\ldots,a_t$, averaging over the translations gives one common $z$ with
$$
 \sum_{j=1}^t m(a_j+z)\le t hQ/L.
$$
For each $j$ the $L$ translated addresses are distinct. The bound is independent of the truth table; $F$ uses only the displayed operands and fixed length or program constants. A pair $y,v$ producing a private address determines the remaining live state after the address is updated, including a later update to $y$ if present. Thus at site $j$ reserve $1+m(a_j+z)$ slots, uniformly for all tables. For $S$ slots in total the earlier graph count is $(S+3)^{2S+1}$, since the query label of each slot is still fixed. All truth tables require $S=\Omega(2^t/t)$. But here $S\le t+thQ/L=O_D(t^2 n^{D-1})$ and $2^t/t=\Theta(n/t^3)$. These bounds contradict each other for $D<2$. This covers even an address function with very large fibers at particular addresses. It makes essential use of the freedom to place the private probes elsewhere in the ordinary file.

The [Lean file](TableProbeContexts.lean) proves that contracting deterministic stretches of public steps preserves both terminating verdicts, including when the underlying system admits cycles. The graph count and its opcode applications are manuscript arguments. A [finite audit](table_probe_context_audit.py) uses an equivalent constant-size false-variable gadget and tests the packed multiplexer encoding by solving the serialized formula. Across every table and address for $t=0,1,2,3$ it checked 2,122 formulas, with independent exhaustive assignment checks for $t\le1$.
