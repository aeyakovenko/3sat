# The relation that every negative pushdown certificate must contain

Fix $k\ge1$. An input contains one pushdown automaton and $k-1$ finite automata over a shared constant alphabet. Its binary transition-list length is $B$. In their synchronized product, a balanced path starts and ends with the same underlying stack and never pops into it. An inductive relation $R$ on pairs of product states contains all diagonal and neutral-transition pairs, is closed under concatenation, and encloses any of its pairs between compatible push and pop transitions. A negative certificate excludes the designated start/end pair from $R$. Actual balanced reachability is the least such closed relation. Closely related negative certificates using matrices are due to Chistikov, Majumdar and Schepper. [Subcubic Certificates for CFL Reachability](https://arxiv.org/abs/2102.13095)

There are explicit sparse negative instances on which **every** such certificate, even with arbitrarily many extra pairs, requires at least $B^{2k}/\operatorname{polylog} B$ wires if its relation is represented by reachability in a directed network with separate input and output terminals for the states. Directed acyclic networks of unbounded depth and unlimited sharing are allowed. For general Boolean circuits there is a different, conditional conclusion. If explicit SAT takes unrestricted deterministic RAM time $O(n^c)$, $c\in\{1,2,3\}$, then for each fixed $k>c^2$ and $\epsilon>0$ with $k/c^2-\epsilon>1$, infinitely many negative inputs have no such certificate computable by a Boolean circuit of size at most $B^{k/c^2-\epsilon}$ on the binary endpoint names.

## Forcing a prescribed submatrix on a negative instance

Take $h$ a multiple of $k$, put $M=2^h$, and choose a polynomial-time bit function $g$ on $h$ bits. We build a negative instance with distinguished product states $p_x,q_y$ indexed by $x,y\in\{0,1\}^h$, with

$$
                   R(p_x,q_y)=g(x\mathbin{\oplus}y)
$$

for every closed relation excluding the start/end pair. This construction uses $O_k(2^{h/k}\operatorname{poly}(h))$ binary input bits for a uniformly polynomial-size circuit family for $g$.

The $k$ components store one $h/k$-bit register each, with the first register in the PDA control. A single finite controller in the PDA issues synchronized commands. A command can test or set a specified register bit. The corresponding component enforces the test or performs the update; other registers stay unchanged. A stack operation can save or retrieve one bit. A test followed by a conditional write can therefore implement an XOR update. Control locations for all loops below can be written out explicitly.

To verify $g(w)=b$ while the registers keep $w$ unchanged, use a bounded-fan-in circuit for $g$. Give each gate two entries, one for each requested value. At an AND gate requested to be true, call both input gates for true in succession. At an AND gate requested to be false, choose one input and call it for false. Use the dual cases at OR gates and reverse the requested bit at NOT gates. Input gates test the requested register bit. The stack holds return tags so a successful call resumes at its own continuation; failure has no continuation. The circuit is acyclic. Induction proves that a successful verification exists precisely for the true value, restores its entry stack, and preserves all registers. Unfolding may take a long run, while the finite controller stores only polynomially many gate and continuation locations.

Use these three stages, with a unique start and end and no other accepting state.

1. Guess $w$ in the registers and verify $g(w)=0$. In increasing coordinate order choose $x_i$, push $y_i=w_i\oplus x_i$ onto the stack, and replace the register bit by $x_i$. The resulting control location and registers define $p_x$ independently of the protected word $y$ below it.
2. Starting from $p_x$, in increasing order guess a bit $y'_i$, push it, and replace the current bit $x_i$ by $x_i\oplus y'_i$. Verify $g(x\oplus y')=1$. Pop the $h$ saved bits in reverse order into their corresponding register positions. The fixed exit location and registers now define $q_{y'}$. This stage is balanced above its entry stack.
3. Starting from $q_{y'}$, pop the $h$ older bits in reverse order, test equality with the corresponding register bits, and clear each tested register entry. Accept at the designated end.

A complete run would require $y=y'$ and opposite signs of $g(x\oplus y)$, so the intersection is empty. For a one entry of the displayed matrix, stage 2 alone gives an actual balanced path, forcing it into $R$. For a zero entry pick $w=x\oplus y$ in stage 1 and use the actual suffix in stage 3 with the same $y$. If $R$ contained $(p_x,q_y)$, the closing rules would enclose that pair by the matching outer pushes and pops and concatenate the genuine intervening operations to derive the excluded start/end pair. Equivalently, adding this one neutral edge to the product would produce a balanced accepting path, and the same $R$ would be closed for the augmented graph. Thus an overapproximation cannot fill any zero of this matrix.

In fact an extra pair is consistent with *some* root-excluding closed relation if and only if the root stays unreachable after adding its neutral edge: in that case take the least balanced relation of the augmented system. The equivalence and its implication for forced bits are verified in Lean 4.19. The automaton construction and resource estimates are the mathematical arguments here. [Lean proof](PushdownNegativePorts.lean)

For implementation over constant alphabets, a command for a named coordinate or control operation can be serialized into a fixed-length binary code of $O(\log(h+2))$ bits; the command repertoire is polynomial in $h$. Each component reads it in a deterministic prefix tree, executes its own local update at the end, and returns to the code boundary. The PDA permits just the command choices of its current control stage. Its finite-control tests, finite choices and stack actions may be split into bounded-fanout transitions; represent a return tag by a fixed-length string of stack bits, with the appropriate reverse-order pop and checks. A pop can select its bit by branching on the observed stack symbol. Extra clock letters or public binary substeps can be used for these bounded control transitions with all other automata idling. Register updates on a specified bit are ordinary transitions between register valuations. Taking the product of a single register's $2^{h/k}$ valuations with polynomially many local control locations, also during decoding, gives the stated bound per component. There are $O(1)$ outgoing transitions per state after binary branching and encoding, and transition identifiers cost $O_k(h)$ bits. The designated endpoints are at complete code and tag boundaries. These implementations preserve the balanced middle paths and the outside matching context.

The same matrix also gives answers to edits of the **individual input automata**. Reserve a fresh symbol $\#$ in the common constant alphabet. For query $(x,y)$ add exactly one $\#$ transition to each component, from its local coordinate of $p_x$ to its local coordinate of $q_y$; the PDA transition leaves the stack unchanged. Their synchronous product has exactly the one new neutral edge. For a one entry, every use of that edge in a balanced run can be replaced by the genuine balanced stage 2 path above the current stack. The edited instance stays negative. For a zero entry, the prefix and suffix give an accepting path using the new edge. Thus the matrix of nonemptiness answers is $1-g(x\oplus y)$. At fixed $h,k$ these edited transition lists can share a common format, with $O(k\log B)$ bits specifying the additional records. Both signs satisfy the network lower bound below.

## Size of a network presenting the relation

Take $g$ to be Xin Li's explicit bit extractor for the sum over $\mathbb F_2$ of two independent $h$-bit sources of min-entropy at least $C\log_2 h$, with fixed error $1/4$. Its evaluator has uniformly constructible polynomial-size Boolean circuits. For $q=\lceil h^C\rceil$ (increased by a constant factor to absorb rounding), an all-zero or all-one rectangle in the displayed matrix cannot have $q$ distinct rows and $q$ distinct columns. Independent uniform draws from its two sides would contradict the extractor guarantee. Uniform draws from the full sides show that each sign occurs on at least $M^2/4$ entries. [Li, Theorem 1.7](https://eccc.weizmann.ac.il/report/2023/023/download/)

Restrict any network for $R$ to the named inputs and outputs. Private source/sink copies may be attached for these terminals at a cost of $O(M)$ wires. For a vertex $v$ write $I(v)$ for the source names reaching it and $O(v)$ for the sink names reachable from it. The full rectangle $I(v)\times O(v)$ consists of ones. On a path for an accepted pair, choose the first edge $u\to v$ at which $|I(v)|\ge q$. Its tail has fewer than $q$ reachable source names and its head has fewer than $q$ reachable sink names. If the threshold is never reached, use the last edge into the private sink; its output side has size one. Each selected wire accounts for at most $q^2$ pairs. Hence the network uses $\Omega(M^2/q^2)$ wires. This is the classical rectangle-free lower bound for rectifier networks. It covers a depth-two listing of rectangles as well as multi-stage OR networks. A raw bound on the number of rectangles would count a single row with an arbitrarily long column list as one object. [Find et al., including the Mehlhorn–Pippenger bound](https://pmc.ncbi.nlm.nih.gov/articles/PMC5432968/)

The construction includes the $2^{h/k}$ register valuations in its explicit state lists, giving $\log B=\Theta_k(h)$. Substitution proves the $B^{2k}/\operatorname{polylog}B$ wire bound. In contrast, the forced matrix by itself has the polynomial-in-$h$ Boolean evaluator $(x,y)\mapsto g(x\oplus y)$. The constructed instances also have a common short mathematical proof of emptiness, namely the contradictory sign tests. This distinguishes the cost of a network presenting an invariant from the cost of deciding emptiness.

## Searching arbitrary Boolean invariant circuits under a SAT clock

Here the automata may be arbitrary instances from the deterministic pushdown time lower bound. Normalize the acceptance condition to one balanced start/end pair, as in its compiled instances. A bottom marker and final stack-drain phase can also enforce empty-stack acceptance when needed. Let $s$ bound the bit length of a candidate bounded-fan-in Boolean circuit describing $R$ on the two endpoint names; encoding $s$ gates costs only an additional logarithmic factor in the polynomial range used below.

For a given candidate, a defect has a short nondeterministic description: a missing diagonal pair, a missing neutral step, a transitivity failure on three product states, a bracketing failure with a matching push/pop and an asserted middle pair, or inclusion of the excluded root. For a synchronous product transition, guess one original transition record per component and check its endpoints and the common letter in the public input. Check the indicated circuit values on well-formed states, rejecting malformed purported defect witnesses. Correctly formatted circuits can be evaluated conservatively in $O((B+s)\operatorname{polylog}(B+s))$ RAM time; enforce syntax in the outer verifier. The disjunction of all defects has a uniform ordinary SAT encoding of length $\widetilde O(B+s)$, with both input and candidate included in the size. If there is no defect, induction over balanced paths certifies nonreachability. [Packed bounded-computation encoding](packed-band-transfer.md)

Under the $O(n^c)$ deterministic RAM SAT hypothesis, a nondeterministic outer machine can guess the $s$-bit circuit and accept if that *deterministic* solver rejects its defect query. Its bounded clock is $\widetilde O((B+s)^c)$. Encode the outer machine into a second ordinary SAT query and use the assumed solver again. This gives a deterministic RAM decision in $\widetilde O((B+s)^{c^2})$ for existence of a small valid negative invariant. On tapes, scanning address/value records for the latest write gives $\widetilde O((B+s)^{2c^2})$, including construction and public input. The guessed circuit is hidden inside the outer SAT query. An ordinary yes/no answer to the inner query cannot choose it.

If all but finitely many negative inputs had a circuit of $s\le B^{k/c^2-\epsilon}$ gates, this would decide the entire pushdown problem in deterministic multitape time $O(B^{2k-\delta})$ for some $\delta>0$, since $k/c^2-\epsilon>1$ and logarithmic factors fit the gap. Positive instances never admit a valid negative invariant; finitely many exceptions may be hardwired. This contradicts Balasubramanian and Majumdar's deterministic time hierarchy reduction on sparse constant-alphabet instances. Thus, for example, quadratic SAT would force negative five-machine instances on which *every* invariant circuit needs more than $B^{5/4-\epsilon}$ gates for each fixed $0<\epsilon<1/4$. Cubic SAT gives $B^{10/9-\epsilon}$ at ten machines for $0<\epsilon<1/9$. These conditional hard inputs need not be the explicit extractor construction. An upper bound on invariant circuit size below this threshold on **all** negative instances would give the corresponding unrestricted SAT separation; establishing that upper bound is open here. [Balasubramanian and Majumdar, Theorems 5, 10, 12 and 14](https://arxiv.org/html/2611.27814v2) · [Earlier pushdown clocks and positive grammar witnesses](pushdown-source-and-grammar-witnesses.md)

An independently checkable proof of nonemptiness or emptiness has a different exponent. If a fixed sound nondeterministic RAM recognizer for either sign has a timely accepting branch by $B^{k/c-\epsilon}$ on every input of that sign, with $k/c-\epsilon>1$, a single bounded-computation SAT query decides that sign. Its deterministic tape clock is $\widetilde O(B^{2k-2c\epsilon})$. The hierarchy therefore rules out that combination with $O(n^c)$ RAM SAT. A circuit naming a negative invariant still needs its universal closure check, which is why the circuit-size bound uses $c^2$.
