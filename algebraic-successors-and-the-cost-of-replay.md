# When an algebraic successor for the SAT exhaustion can be replayed

Fix the deadline $j(n+1)^d$ for $d=1,2,3$, the short contradiction $A_j$ and the coefficient-four interpreter with its finite visible descriptions. The other two test files have opposite true SAT verdicts and lengths at least $L_j=|A_j|$. Write $M_j$ for the larger length. A *defeating triple* here means that every template parameter fails on at least one of these three files. The argument below exhibits a parameter passing all three. It therefore applies even when the proposed proof does not require identical timed signatures. [Three-file exhaustion](three-files-for-the-unrestricted-sat-clock.md)

Assume one fixed computable construction emits two files at each stage, in a known order of their labels. The time to compute the labels is included if the construction must discover the orientation. Two barriers follow.

* **Efficient powers fail at the dyadic stages.** If from $k$ alone a single native procedure emits the ordered pair at $j=2^k$ in $O(k(1+M_j)^d)$ steps, then for every sufficiently large such stage its triple admits a timely classifier. The files can have arbitrary lengths and Hamming differences. For example, a composable successor with $k$ doubling operations meeting that total budget cannot produce the desired triples at all stages.
* **Fast successive updates force a polynomial bound on the lengths.** Suppose the two files at stage $i$ can be generated from the preceding pair and the binary stage index for $O((1+M_i)^d+(1+M_{i-1})^d)$ steps. If all sufficiently large stages defeat the interpreter, then $M_j\le (1+j)^{O(1)}$. This also holds for lengths that decrease and later rise again. When the lengths do grow faster than every polynomial along a subsequence, a prefix of the construction can be replayed within the actual deadline on infinitely many record stages.

For these statements use a concrete ordinary implementation of the journal's interpreter. Decode the guest's fixed lists of instructions and operands once into arrays at initialization, with the ordinary binary self-delimiting field for one nonnegative literal. Changing just the value $z$ of this literal then costs $\log_2(z+2)+O(\log\log(z+4))+O_P(1)$ payload bits. Once decoded, native cost per guest step is bounded independently of $z$ when it fits one guest word. Equivalently this can be specified as a fixed interpreter mode supplying a self-delimited integer to a fixed guest routine. This instantiation matters for the adjustable deadlines below. The existence and sharpness of the three-file characterization continue to hold with this representation. [Interpreter and sparse memory costs](anchored-interpreter-for-ram-exhaustion.md)

The generator can be a uniform separate-operation RAM transformation with any fixed word-width coefficient, using binary indices, ordinary packed previous files and explicit outputs. The input size determining its word width must be available from its input or the declared working horizon. Equivalently one can give uniform native cost bounds for generating the files up to a given maximum length. For a direct call on binary $k$, its own input length is known. A generator allowed a working horizon $M_j$ can instead take the horizon explicitly and generate the ordered pair for that horizon, provided an incorrect supplied horizon can only cause abstention or yield a correctly labeled file. Simulating with a different guessed width that changes a verdict is insufficient. A multitape generator also meets the assumptions when its native simulation costs obey the stated bounds.

### Regenerating a file with its label

The anchor has at least $\log_2 j$ occurring variables and hence $L_j\ge\log_2 j$ bits. There are at least $2\log_2(L_j+2)-O(1)$ payload bits before the terminator at its width. Every classifier starts with the fixed sound guard that rejects files containing the eight proper sign clauses of the anchor. On these anchors the guard runs in $O(n+1)$ time. It can be implemented by a bounded scan for the delimited patterns, which is sound on all valid files. The finitely many compiled routines used below have fixed code size beyond the one binary literal.

To recognize one selected polarity, compute the construction, compare its file of that polarity with the actual input, and return that polarity only on an exact match. On a mismatch, overflow of the working horizon, or expiration of a deliberately set deadline, return the opposite polarity. Thus on the opposite-labeled file the routine always gives the right answer as soon as it stops. Only the endpoint of the selected polarity has to pay for a successful regeneration. Choose the polarity of the larger endpoint for that stage. Two fixed choices suffice. A prefix computation may compare with every earlier file of that polarity, since an exact earlier match also has the same true label.

At a record endpoint of length $M$, a fixed native replay program can simulate all stages through that record with constant overhead per step plus the cost of presenting and comparing the files. The earlier file lengths and the binary length of every stage index are $O(M)$ here, using $M_i\ge L_i\ge\log_2 i$. Guest widths can be computed from those lengths in polynomial time in their logarithms. One wider fixed coefficient suffices for all guest widths in the prefix. Binary arithmetic on a bounded number of limbs, masking to the current width and reciprocal division for packed offsets give constant work per operation after setup. Initialize fresh simulated memory lazily and log writes for resetting it at the end of a stage. Keep the original input separate. Computing a stage width and moving its input or output costs $O(1+M_i+M_{i-1}+\log(i+2))$. Replaying on a much shorter file can run out of representable addresses or buffers. Detect that before truncation and take the opposite default. This preserves soundness of each exact-match report. The final interpreter can simulate $T$ guest steps in $O(T+\operatorname{polylog}(n+2))$ host time when $O((T+1)(n+2)^{1/4}+n)$ host words fit its coefficient-four width. These bounds allow a time multiplier growing with the particular stage, which requires the space check.

### Computing a distant power

Put $j=2^k$. If $M_j\le k^{3/2}$, test equality with the shorter length when the two lengths differ. At a common length, select any differing physical bit. Include the orientation and anchor guard. The payload uses at most $(3/2)\log_2 k+O(\log\log(k+4))$ bits and fits at all three files. A single chosen parameter thus fits the triple in $O(n+1)$ time.

For $M_j>k^{3/2}$ the literal $k$ itself still fits the anchor. On input length $n$, take the opposite default immediately if $n^2<k^3$. Otherwise run the chosen polarity check for at most $D k(n+1)^d$ simulated steps, where the fixed $D$ covers the generator and comparisons on the larger file. Tests, budgets and counts are ordinary integer operations in a fixed sufficiently wide guest. On this branch $k\le n^{2/3}$, so even for $d=3$ the host storage just estimated is $O(n^{3+2/3+1/4})=o(n^4)$. The classifier completes on each of the files within $O(k(n+1)^d)$ native host steps. This is less than $2^k(n+1)^d$ for all sufficiently large $k$. The larger file passes its equality test and the other file receives its correct label. If the guard fires, its rejection is already correct. This proves the first assertion without requiring monotone lengths or disjoint successive pairs.

### A finite list of possible algebraic powers

The direct obstruction also covers a construction that cannot select the correct branch. Restrict to the cofinal stages $k=2^m$, $j=2^k$. Here $L_j=\Theta(k\log(k+2))$ because the anchor uses $\Theta(k)$ dense variable names and includes every one of them. Fix a native generator $G(k,u)$ with explicit outputs. There is a constant $c>0$ such that the following holds at every sufficiently large such stage. If **any one** branch
$$
             0\le u < c\,k^2(\log_2 k)^2
$$
outputs the proposed two files within $Dk(1+M_j)^d$ steps, with uniform $D$, then some parameter passes all three files. Only this branch needs to terminate or generate the claimed files. It can list them in either order. Two bits of the program tag choose which output has the larger length and its true polarity. The choice of $u$, output index and polarity can be made after seeing both files.

To encode both $m$ and $u$ in the anchor, use a fixed mode with a **raw final integer** $z$ before its terminating symbol. This uses no length field for $z$. A fixed guest program can be an earlier self-delimited part of the mode's description. Let $b_m=\max(1,\lfloor 4^m m^2/2^q\rfloor)$ for a fixed large $q$ and assign the consecutive interval of $b_m$ integers following the blocks $b_1,\ldots,b_{m-1}$. Its last integer is at most $m+(4/3)4^m m^2/2^q$. The estimate follows by replacing every $i^2$ by $m^2$ in the geometric sum. A fixed tag, the two choices and the terminator leave room for all $0\le z<c_0 L_j^2$ for some constant $c_0>0$. Choosing $q$ sufficiently large puts the whole block within that range. Every stated $u$ fits for a sufficiently small fixed $c$. The decoder sums the block sizes until it reaches $z$, then subtracts the start to recover $u$ and sets $k=2^m$. Its $O(m+1)$ word operations fit on the anchor and longer files. Intermediate values use $O(\log(L_j+2))$ bits there. This adds a fixed parameter convention to the interpreter.

When $M_j\le k^{3/2}$ the earlier bit or length probe works without any branch information. Otherwise use the chosen label and output index, and regenerate **only** the single selected branch with the cap and early default from the dyadic proof. On the larger endpoint it finishes in time. On the shorter endpoint an exact match to that same designated output is impossible because the two verdicts differ. Use the actual source width of the transduction from $(k,u)$, detecting representational overflow before it can change a computed result. A generator using a guessed output horizon on the short input requires the additional soundness condition for wrong horizons specified above. The guarantee cannot be inferred solely from running such a generator correctly at the larger horizon. The output clocks and host memory bounds are unchanged.

Equivalently, on these stages an explicit bounded search tree may leave up to $\lfloor 2\log_2 k + 2\log_2\log_2 k-O(1)\rfloor$ bits of choice along a path. Reading them adaptively is allowed. If one such indexed path regenerates the pair at the stated cost then the triple already has a timely classifier. This says nothing about the SAT labels or runtime of the other paths.

### The cost of traversing all previous stages

Let $U_j=\max_{i\le j}M_i$, $a_j=(1+U_j)^d$ and $S_j=\sum_{i=1}^j a_i$. At any record stage $M_j=U_j$, a complete replay through both files costs at most $K S_j$ simulated steps under the successor-cost assumption, for a constant $K$. Initial stages and the cost of data movement are included.

**Prefix estimate.** If $U_j$ has no polynomial upper bound, then for every $\epsilon>0$ there are arbitrarily large record stages with both $M_j\ge j^2$ and $S_j<\epsilon j a_j$. To prove this, suppose for some $0<c<1$ that all sufficiently large records with $U_j\ge j^2$ have $S_j\ge c j a_j$. At an intervening nonrecord whose value still exceeds $j^2$, the last record also exceeded the square of its own index. Its lower bound persists because each subsequent summand until $j$ equals the current maximum. Discarding finitely many indices, every $j$ now has either $a_j\le(1+j^2)^d$ or $S_j\ge c j a_j$. In the second case set $m=\lceil(1-c/2)j\rceil$. Then
$$
 c j a_j\le S_j\le m a_m+(j-m)a_j,\qquad
 a_j\le (2/c)a_m .
$$
For large $j$, $(m+1)/(j+1)\le1-c/4$. To obtain $a_j\le D(j+1)^p$ by induction, take $p\ge 2d$ with $(2/c)(1-c/4)^p\le1$ and enlarge $D$ for the finite initial segment. This contradicts the assumed growth of $U_j$. [Lean checks of the finite prefix inequalities](ReplayClockGrowth.lean)

At the resulting record stages choose $\ell=\lfloor\log_2 j\rfloor-b$ for a fixed positive integer $b$. Its binary field uses $\log_2\log_2 j+O(\log\log\log(j+16))$ bits and fits the anchor along with a fixed replay program and polarity. On a file of length $n$, cap the replay at
$$
 \min\{2^\ell,\lfloor\sqrt{n+1}\rfloor\}(n+1)^d
$$
guest steps. One can clamp the shift before forming the power, using the public word length or a bit-length comparison. Integer square root and computing the cap each cost $\operatorname{polylog}(n+2)$ steps. The clamp fits $O(n^{d+1/2+1/4})=o(n^4)$ host memory even on the shorter endpoint. Take $b$ large enough to absorb the fixed simulation and timeout-accounting constants on every file. Since $M_j\ge j^2$, the clamp does not reduce $2^\ell$ on the larger file. Choose $\epsilon<2^{-b-1}/K$ in the prefix estimate. Its complete replay fits the budget there since $2^\ell\ge 2^{-b-1}j$. The other endpoint finishes with its correct label regardless of the progress of its replay. The anchor guard also finishes in time. This contradicts defeat on all sufficiently large stages and proves the polynomial upper bound on $M_j$.

A geometric increase gives a stronger conclusion at each stage. If $1+M_{i+1}\ge q(1+M_i)$ eventually for a fixed $q>1$, the geometric sum yields $S_j=O((1+M_j)^d)$ for every large $j$. A fixed constant budget times $(n+1)^d$ for each polarity recognizer suffices on the larger endpoint. Its fixed opposite default is timely on the shorter one. The two guarded programs between them therefore fit every sufficiently large triple. This version needs no stage literal.

### Consequences for the proposed induction

Two separate size constraints apply to genuine triples. At different endpoint lengths, the length-interpolation classifier in the three-file argument fits the three labels whenever $M_j\le 2^{L_j^{2-\epsilon}}$ for a fixed $0<\epsilon<1$ and large $j$. A sound anchor guard preserves this property. At equal lengths and bit distance two, the parity of the bits at positions with address bit $t$ set distinguishes the files whenever $t$ distinguishes the two edited addresses. A guarded orientation of this streaming test fits the anchor and both endpoints. Encoding the integer $t$ in a compact fixed-width field at the anchor yields the [stronger quantitative bound](sparse-edit-address-parities.md). For the consequence here, ordinary self-delimitation already allows every $0\le t<\lfloor L_j^{3/2}\rfloor$. Equal residues of the two positions modulo $2^{\lfloor L_j^{3/2}\rfloor}$ force $M_j>2^{\lfloor L_j^{3/2}\rfloor}$. Either length condition gives a superpolynomial lower bound in $j$ along the affected stages.

Consequently any single matched-time successor as above that defeats all sufficiently large stages must eventually use **equal lengths**, and it can use bit distance two at only finitely many stages. With the address-moment tests of the [sparse-edit bound](sparse-edit-address-parities.md), the eventual edit count $h_j$ is even and satisfies $(h_j/2)\lceil \log_2 M_j\rceil>cL_j^2$. The anchor serializes every identifier through at least $\log_2 j$, so its length is $\Omega(\log j\,\log\log j)$. The polynomial bound on $M_j$ now forces **$h_j=\Omega(\log j\,(\log\log j)^2)$ changed physical bits** on every sufficiently large stage. The implied constant can depend on the generator. On the other hand a fast-powerable successor is already excluded without an edit restriction. These arguments leave open successors with expensive construction, existential choices of new witnesses, and more complicated edits on polynomial-length pairs. Classical hard-sequence results also distinguish efficient generation from the running time of an algorithm on its generated inputs. The time multiplier, finite anchor and two true labels are essential here. [Chen, Flum and Müller, *Hard instances of algorithms and proof systems*](https://www.fim.uni-passau.de/fileadmin/dokumente/fakultaeten/fim/lehrstuhl/muller/Hard_instances.pdf)
