# Encoding the selected two rows of a checkpoint table at its information size

In the single-address monitor simulation a SAT call searches for a bad interval. Its public input includes every guessed checkpoint. An accepting branch chooses one interval index $i$ and can inspect exactly rows $i$ and $i+1$ of that table. Materializing the entire table as arbitrary random-access input pays an extra logarithm in the encoded length. The physical SAT encoding below spends $O(pkL)$ bits on a table of $p$ checkpoints of $k$ words of $\Theta(L)$ bits each. For arbitrary checkpoint tables this is optimal up to constants for an encoding of the selector relation itself.

Let the public scale be $H$, $L=\lceil\log_2(H+2)\rceil$, $p$ a fixed power of $L$ up to rounding with $p\ge L$, and $k=\Theta(H/L^B)$ for fixed $B$. Write $D=\Theta(kL)$ for the number of bits in a row. There are $p$ valid left-end indices and $p+1$ concrete rows. For an interval-index input and exterior bits for two rows, the selector relation asserts that the exterior bits equal the indicated two endpoints. Data are fixed at construction time and the topology of the emitted formula may depend on them. The small clock counts the construction as well as solving the resulting formula.

Decode the index to $p$ one-hot selector wires and require it in range. Put successive indices into groups of $\ell=\max(1,\lfloor L/8\rfloor)$, padding the last group with false selectors. In each group compute a wire for every subset OR of its selector wires. Splitting by the last element added to a subset constructs the whole family with $O(2^\ell)$ gates. For each endpoint bit and each group, form the $\ell$-bit mask of indices for which the corresponding public row carries a one. Wire that group's subset OR into a disjunction over groups. The resulting wire carries the selected row bit for **every** allowed index. For the second endpoint build the masks from the same table shifted by one row. Adjacent intervals may reuse the same data. This type of circuit decomposition groups minterms and shares subset disjunctions, as in classical Boolean circuit synthesis. [O. B. Lupanov, *A method of circuit synthesis*](https://radiophysics.unn.ru/issues/1958/1/120)

The number of gates is
$$
 O\!\left(p\log(p+2)+\lceil p/\ell\rceil 2^\ell+
                     D\lceil p/\ell\rceil\right)=O(pk).
$$
The shared subset families are cheap here because $2^\ell=O(H^{1/8})=o(k)$. A Tseytin encoding uses $O(L)$ bits per gate, including every use of a shared variable. Each output can be wired to its prescribed interface bit with constant extra gates. Standard clause padding with forced false variables gives proper ternaries. The same count applies in ASCII DIMACS. Computing the masks reads at most $O(\ell)$ words per output-bit and group pair. One bit can be extracted from a random public word in constant time. The resulting $O(pkL)$ word operations also cover emitting every clause, even byte by byte. This construction needs an actual accessible table when the formula is materialized. Its sublinear-in-table-size *circuit* does not give a sublinear-in-table-size RAM construction.

The distinct table functions give at least $2^{pD}$ different selector relations even if the last row is held fixed. Indeed fixing the index and exposing the two endpoints recovers each of the first $p$ rows. Require fixed external variable labels and no separately supplied table. Even allowing arbitrary auxiliary variables, fewer than $2^{s+1}$ binary strings have length at most $s$. Thus, apart from a fraction at most $2^{-b+1}$ of these tables, every encoding of their full selector relation has length greater than $pD-b$. The upper construction costs $O(pD)$ bits. This counting lower bound applies to the specified interface. The scalar decision that some selected interval is bad can forget table information.

For the monitor theorem the selected outputs become the initial values of a separate $O(k)$-word input bank of the failing-interval verifier. Its ordinary bounded-run reduction keeps the smaller $m+O(k)$ other public words and charges the simulated interval's $R$ steps. Use the same guessed, range-checked $i$ for the endpoint selector, validity checks and time bounds. No other operation of the verifier reads the table. Hence the full materialized encoding and construction cost are
$$
 O\big(RL^3+(m+k)L^2+pkL+\operatorname{poly}(L)\big).
$$
For a solver taking $O(N\log^a N)$ put $A=a+3$ and suppose the root retrieval budget on the virtual formula is $k=\Theta(H/L^B)$. With $p=\lceil L^x\rceil$ the interval term scales as $HL^{2A-x}$ after the SAT call. The entire checkpoint table contributes $HL^{x-B+A-2}$. The existential machine generating the table spends $O(pk)$ guess steps, included in the latter term. At $x=(A+B+2)/2$ the common exponent is $(3A-B-2)/2$. At $B=3A-1$ this subtracts $1/2$ in each iteration and $2A-B=1-A<0$ is the recurrence's floor. After a fixed number of iterations the complementary machine contradicts the diagonal clock under the joint hypothesis. The original encoded formula uses $O(HL^3)$ bits, so this excludes a lifetime retrieval cap of $O(N/\log^{3a+11}N)$. No further change to the monitor, its quantifiers or the word width is required.
