# Superlinear accumulated work on stopped continuations of one SAT execution

Can the cost of answering many delayed queries be charged to one actual SAT run? This construction lets the program read and process each actual query in turn before the test branches. The quantitative result passes the linear threshold in **encoded bits**. The complete file verifies all the claimed answers. It has exactly one model per false claim. Its cost inequality includes work on different complete stopped continuations; this is the term still to be controlled for a single-run time bound.

Let $s$ be a large power of two, $M=s^4$, $K=M^D$ for a fixed integer $D\ge2$, and $q=Ks$. Use a fixed logarithmic-word RAM with aligned reads, a constant-size controller, read-only input, initially zero work memory and a sufficiently large fixed coefficient in its word width. A template has $p=M^2+3q$ data-bearing word positions. Its encoded ASCII DIMACS bit length is $L=\Theta_D(p\log M)$. Write
\[
                      H=(\log M/\log\log M)^2 .
\]
For **every** correct deterministic SAT program, at every sufficiently large such scale there are two complete files differing in the tag bit of the final claimed answer. One has all answers correct and is UNSAT. The other has exactly one wrong answer and is uniquely SAT. Their common execution satisfies
\[
 T+\sum_{j=1}^{q}\min\big\{s,\ u_{j,0}+g_{j,0},\ u_{j,1}+g_{j,1}\big\}
   =\Omega_{P,D}(qH)
   =\Omega_{P,D}\!\left(L\,\frac{\log L}{(\log\log L)^2}\right).
 \tag{1}
\]
The definition of the terms matters.

* $T$ is the actual common elapsed time through issue of the load of the last claimed answer. Each full run takes at least this long. The $q$ marked cuts are **after** the program has received the corresponding genuine query packet and executed all instructions up to its next request for a previously unseen packet. Their master prefixes are nested.
* At the pending address supply one of the two ordinary answer annotations for the delivered query. Fill every still-unseen position with a position-specific dummy. These are ordinary blank-padded transcript prefixes. The two choices of answer tag differ by one physical bit; one complete file has a unique satisfying assignment and the other is unsatisfiable. On both files the instruction, address and reply histories through the issue of the pending annotation load are the real master history through that point. The query operands were already present before this fork. Different cuts give different pairs.
* On either stopped suffix, $u$ counts distinct reads of **previously exposed** packet addresses and of work addresses read before their first suffix write. Unwritten zeros count. The known candidate annotation, fixed syntax, later private writes and registers are free here.
* Fix any data-independent public ordering of the $p$ positions, for instance their physical order. At the pending annotation load, the still-unseen positions form disjoint maximal intervals in that order. The term $g$ counts how many such intervals the suffix touches by reading a dummy other than that annotation. Ten thousand dummy reads in the same interval contribute one. The hard master can depend on the public order. A different choice based on the run requires communicating how to test membership.

This imports the amortized lower bound in Young Kun Ko's November 2026 preprint, without an independent verification of its proof. The reduction below also works with a different amortized lower bound after substituting its parameters. The $H=\omega(\log M)$ rate is what beats the explicit bit length here. Prior work in this journal charges elapsed time plus discarded suffix lengths under successive input edits. The present sum starts *after* native work on each genuine query, caps each pair by a direct source algorithm, counts distinct inherited words and discounts whole runs of blank addresses. ## An ordinary proper formula at every branch

The source database is $M$ subsets $S_1,\ldots,S_M$ of $[M]$. Each of $K$ batches starts with its own empty set. Each of its $s$ rounds inserts one element and queries whether the current set is disjoint from a specified $S_a$. Each query receives a distinct chronological ID $j\in[q]$. The input contains its proposed Boolean answer as a separate subsequent packet. The insertion immediately before query $j$ also has time $j$.

The public part of the CNF has exactly-one selectors for a query ID, a batch and a source set. Use OR equivalence trees with true roots and forbid simultaneous true siblings. For each chronological update time $t$ precompute a wire $H_t=[J\ge t]$ by suffix ORs of the query selector leaves. Introduce variables $g_{a,e}$ for the database bits and $R_e$ for the chosen row. For each $a,e$, two ternaries say that selecting row $a$ forces $R_e=g_{a,e}$. Each physical packet position $v$ has an auxiliary bit $y_v$, a hit bit $z_v$ and a receipt bit $h_v$ for the query being selected. Assert $\bigvee_v h_v$. Compute $D_0=\neg\bigvee_v z_v$ and assert $A\oplus D_0$, where $A$ records the alleged answer. Give $A$ and its complement equal-length decimal names with the same digits except for a final 2 versus 3. Auxiliary gates use full equivalences.

* A graph packet pins one $g_{a,e}$ and fixes its local bits to zero. The full file has exactly one such packet per graph bit.
* An insertion $(b,t,e)$ sets $h_v=0$, $y_v\leftrightarrow(B_b\land H_t)$ and $z_v\leftrightarrow(y_v\land R_e)$, where $B_b$ selects its batch.
* A query packet with ID $j$, batch $b$ and source set $a$ fixes $y_v=z_v=0$ and $h_v\leftrightarrow J_j$. If $J_j$ is selected, it pins the chosen batch to $b$ and the chosen row to $a$.
* An answer packet for $j$ with tag $a'$ has zero local bits. Its effective clause is $\neg J_j\lor A_{a'}$, where $A_{a'}$ is the member of the answer-name pair asserting $A=a'$. Flipping the annotation changes one physical bit. A dummy fixes all its local bits to zero.

Use seven proper ternaries on three distinct anchors to force their all-zero setting. Pad shorter clauses with distinct false anchors and packets with satisfied public rows, keeping a common constant number of proper clauses in every packet. Allocate identifier ranges arithmetically, pin filler variables, and use fixed whitespace to align and fill each word. A sufficiently large fixed coefficient in $w=\Theta_D(\log M)$ accommodates one complete packet. The formula has $O(p+M^2)$ clauses and identifiers of $O(\log p)$ bits. A public padded bit length $L$ of the stated order can be fixed before calculating the word alignment. Everything outside the $p$ positions is independent of the database and stream.

In a full or blank-padded prefix transcript with a claim for every delivered query, the receipt disjunction permits only a delivered $J=j$. Its query packet fixes one batch and row. The $H_t$'s retain exactly the insertions at or before that query. Every other variable is now forced, including $A$ by its answer packet. This choice gives a model exactly when the genuine disjointness bit differs from the annotation. Thus the **model count equals the number of incorrect delivered answers**, regardless of physical order, repeated requests to a set, and the number of unused future IDs. If the first $j-1$ annotations are truthful, the true and false candidate annotations for $j$ produce respectively zero and one model after future packets are replaced by dummies. There is no mode bit communicating that the test has branched.

## Realizing the whole stream in a single native access order

When the solver first requests a new position, supply the next logical packet and cache that position's value on repeats. First supply $M^2$ graph packets in fixed logical order. Then supply the insertion, actual query description, and truthful answer annotation for each round, batch after batch. The auxiliary, hit and receipt variables in a packet always refer to its actual physical position. Immediately after supplying each query, run the master up to its issue of the *following* new load. At this cut test the two ordinary candidate annotation words in the pending position, filling all other unseen positions with the prescribed dummies. Either simulation yields the correct next annotation to place in the continuing file. There is no circularity: the Boolean answer to query $j$ depends only on the delivered operands. The testing algorithm tries concrete candidate annotations and learns which one gives a fully truthful prefix. The online algorithm for computing it with controlled probes is given below.

Every needed new discovery occurs in finite time. A partial master prefix admits a total completion using the rest of its legal packets and all truthful annotations. It has zero models. A second such completion changes just the last annotation to its opposite. Until that last annotated word has been supplied, the two completions agree on all observed bytes and have opposite verdicts. Thus a correct solver must eventually make its next new load. This argument works already during graph initialization.

Fixing the resulting layout gives a genuine complete input by determinism. None of its first-discovery choices was prescribed to the SAT program. At the last pending load, give the true annotation in one file and its one-bit opposite in the other. Every cut in (1), including the last one, is on the common prefix. Thus the program really did receive **all** intervening query words and earlier truthful answers on the same run. The source simulation stops before following either of the two final answer replies.

## The online simulator and the cost of blank words

In Ko's cell-probe model computation during a single operation is free, while persistent state between operations is held in cells. Keep the native work array, observed packet values, current controller and pending address in separate tagged banks; choose cell width a sufficiently large fixed multiple of $\log M$. Persist even the $O(1)$ controller words at operation boundaries. The dynamic algorithm implements each master instruction with $O(1)$ probes. It prepares the initial graph and its first-discovery prefix during preprocessing. After each insertion or query it supplies the appropriate packet and resumes the real master until the next pending discovery. At the end of a source query it also supplies the computed truthful answer packet and advances to the next pending insertion, except that the final answer reply can be omitted. This entire part costs $O(T+p)$, including persisting the controller and identity of pending reads. For an ISA with several memory events in an instruction, take the cut at an ordered read subevent and save its constant-size temporaries.

On the first probe of a work address in a stopped suffix, get its pre-cut value from the frozen work bank unless the suffix already wrote it. Cache replies and simulate private writes and repeated reads in transient local computation. There is no assumption that the concrete SAT program uses little space or that it caches anything itself.

A fresh dummy is easy to evaluate once its status is known, but determining that it was unseen can cost a cell probe. The following directory pays once per **gap actually touched in that fork**. Give every unseen position a pointer to a descriptor for its maximal still-unseen interval in the public order. At a master discovery within an interval delete that position. If this splits the interval, keep the old descriptor for the larger side and redirect the positions of the smaller side to a new descriptor. Record the new endpoints. If there is only one nonempty side, retain its descriptor. Each re-labeled position's component loses at least half its size, so all $p$ discoveries together need $O(p\log(p+2))$ cell probes for maintenance. Space is $O(p)$. Initial positions and a list of free descriptor addresses have a public initialization; at most $O(p)$ descriptors are ever created.

In a stopped query, consult the map for a slot when neither a cached value nor a previously recovered blank interval applies. At an old slot fetch and cache its packet. At an unseen position obtain its descriptor and endpoints, then remember that entire interval locally. The known candidate annotation takes priority at its own position. Thus a complete signed fork costs $O(1+u+g)$ probes after the common prefix. This argument works regardless of the number of new dummy loads and stores performed by the native suffix. All local caches are discarded at the end of the online operation. [Finite directory audit](blank_gap_directory_audit.py) · [Lean halving and total rewrite bounds](BlankGapDirectory.lean)

Race the two signed simulations by individual cell probes. Each halts on its genuine completed file and supplies the exact source bit, since its sign is known. A third exact algorithm stores each batch's updates as they arrive. On query it scans at most $s$ saved elements, using the preprocessed database matrix to check membership. Race this baseline as well, so the query surcharge is
\[
              O\big(1+\min\{s,u_{j,0}+g_{j,0},u_{j,1}+g_{j,1}\}\big).
\]
A computation segment between probes terminates on the genuine simulation (or the simulation halts). The unbounded transient private state of one online operation allows the three simulations to alternate without persisting their scratch arrays. The master remains frozen during this race. It resumes with the truthful answer, which becomes part of the genuine input seen by all later cuts. As the source algorithm is exact, no heuristic about a candidate SAT answer enters the reduction.

Ko proves an expected lower bound $\Omega(sH)$ for one batch on a database and stream distribution fixed independently of the algorithm. To add this over $K$ batches sharing one graph, choose a uniform batch number $J$ in free preprocessing of a *single* genuine instance. Given the genuine database, sample and simulate $J-1$ earlier batches independently from their conditional distribution, and keep the resulting state. Run the genuine online batch in slot $J$. This is an admissible algorithm on one Ko instance. Its expected forward cost is the average cost of the $K$ batch positions under the joint sampling experiment. The simulation can fall back on direct inspection for any input outside the expected format or horizon; it is exact on every legal fixed input. Width $\Theta_D(\log M)$ remains within Ko's convention. Consequently the expected cost summed over all positions is $\Omega(KsH)$. Each dynamic step, including gap maintenance, is accounted for above. Since $p\log(p+2)=O_D(q\log M)=o(qH)$, the directory cost can be absorbed for large $M$. Taking one master at least as large as the resulting average proves (1).

## Consequences on complete executions

For fixed $D$, if all masters take $O(L)$ time, some master has $\Omega_{P,D}(KH)$ **distinct** query positions where each of the two genuine stopped traces costs $\Omega_{P,D}(H)$ in $u+g$. Indeed truncate the contribution of each pair at $s$. If fewer than $c qH/s$ positions exceeded $cH$, the sum in (1) would be too small for suitably small $c$. Each pair has its first and only changed annotation in a different physical word; different prefix lengths also have different numbers of delivered queries. The same implication holds if every master prefix costs at most a sufficiently small fixed multiple of $qH$. For every fixed $\epsilon>0$, taking $D$ sufficiently large gives at least $L^{1-\epsilon}$ such pairs for sufficiently large sizes, all attached to one master, with a constant in the probe bound depending on $D$.

If, on every input, the revealed positions form one interval in the specified public order, at most two gaps can be charged in a fork. For a public scan order matching the discovery order there is at most one gap. More generally if the $q$ cuts together have $o(qH)$ missing intervals, (1) still holds with $g$ removed up to a change of lower-bound constant. Thus on such access schedules, $O(L)$ master time entails superlinear-in-$L$ **total retrieval of previously existing values** across the cheaper signed completions. If the schedules are unrestricted, their dependence on the data is part of what a simulator must pay for. The gap term prevents a false inference from free knowledge of the physical first-discovery order.

The [native-window theorem](ambiguous-answers-after-a-window-of-native-sat-instructions.md) also requires that the recent instruction values on the same run be compatible with opposite next answers at these costly pairs. A related single-run exclusion follows. A solver whose cheaper stopped continuations and gap visits together average $o(H)$ at every master cannot keep every master below $o(L\log L/(\log\log L)^2)$ elapsed time. This assertion allows arbitrary memory, processing between discoveries, and work by the other sign. It still has an extra latency hypothesis. An explicit upper bound is important here. On either a full or padded annotated stream, restore the time order by the packet IDs and verify all supplied answers directly in $O(L+qs)$ time, by inspecting at most $s$ inserted elements per query. This gives a globally correct SAT algorithm on the stated families by checking the exact packet templates, graph inventory and valid query, update and answer IDs before a fast return and using a complete SAT fallback on any failed check. For the padded case verify a complete graph, a prefix of well-formed rounds, one annotation per delivered query and only dummy packets in all remaining positions. In these bounds $s=O_D(L^{1/(4D+1)})$. The family is consequently a candidate only for the *linear* milestone; it already has a strictly subquadratic algorithm. Changing any one truthful answer gives a model, on either a full stream or a nonempty padded prefix. No unrestricted superlinear lower bound for full transcript verification follows from (1).

The underlying complete-transcript problem also contains Boolean matrix-product verification. For $d$-by-$d$ binary matrices $U,V,W$, use one query set per row of $U$, with membership on the original $d$ coordinates given by its row, and a designated empty set. Use one batch per column of $V$. In its first $d$ rounds insert coordinate $k$ when $V_{kj}=1$ and a distinct public dummy otherwise, and always query the empty set with the truthful answer. In its next $d$ rounds insert fresh dummy coordinates belonging to no query set and query row $i$ with reported disjointness $1-W_{ij}$. A universe of $3d$ elements plus padding suffices and insertions within each batch are distinct. Exactly the wrong entries in $W$ produce false answers. The general packet construction (here with $d$ batches of $2d$ rounds and $O(d)$ rows and coordinates, independently of the Ko hard-distribution parameters) gives $O(d^2\log d)$ encoded bits and exactly the Hamming distance from the **Boolean-semiring** product as its model count. This connection identifies an offline subproblem; the amortized dynamic theorem alone says nothing about its native decision time.

One simpler control uses inert query packets, with the entire normal master rejected whenever no stop is present. It also supports the dynamic fork simulation and has an $O(L)$ decoder on every master and stopped file. The annotations and threshold gates above remove that shortcut and ensure each online answer contributes to the actual final SAT decision. Even so, a static solver can defer checking prior annotations while an online data structure must produce the next one. The expensive stopped continuations in (1) are genuine executions on different files. The missing implication would assign enough of their work to disjoint parts of the continuing computation. The [two-scan counterexample](all-tree-prefix-scans.md) separately tests this implication for protocols at many cuts of one fixed input.
