# Linear-length DIMACS with at most one assignment per independent matrix error

For binary $d\times d$ matrices $A,B,C$, write $E=AB-C$ over $\mathbb F_2$. There is a uniform, dense, proper ASCII 3-CNF of length $N=\Theta(d^2)$ bits whose satisfying assignments correspond bijectively to the ones of $E$ that occur first in both their row and their column. Its verdict is matrix mismatch. The number of assignments is at most $\operatorname{rank}(E)$, and is exactly one for a rank-one discrepancy even when all $d^2$ entries are wrong. A diagonal matrix of rank $K$ attains $K$ assignments. Each input bit has at most three physical occurrences. The RAM compiler uses $O(d^2)$ steps.

The earlier bit-once projection gives one assignment for *every* erroneous coordinate. Requiring a first error in only one line can still leave $d$ assignments for an all-one error. Requiring both conditions bounds ambiguity through a triangular minor. In increasing order of their rows the witness columns, taken in matched order, have ones on the diagonal and zeros above it. When $E\ne0$ its first nonzero row supplies a witness. ## The two selected error lines

First take $d=2^t$. The selector bits name exactly one row $i$ and one column $j$. Use four arrays of $d$ proposed bits for $a=A_{i,:}$, $b=B_{:,j}$, $u=C_{i,:}$ and $v=C_{:,j}$. We enforce that the first one of $aB-u$ is at $j$ and the first one of $Ab-v$ is at $i$. Ordinary prefix-OR gates and a one-hot decoder check these conditions once the two error lines are known.

For the physical layout use a power-of-two chunk length $h$ with $t/16<h\le t/8$ for sufficiently large $t$. Take $h=1$ at small dimensions. Each data-dependent name consists of a positive decimal bank number followed by exactly $h$ ASCII digits, each a 0 or 1. Thus a bit change in a chunk toggles just the low bit of that digit wherever the name is used. Use a separate bank for each proposed bit in each of the four selected arrays. Its variable with suffix $m\in\{0,1\}^h$ is the Boolean value $[y=m[\mathrm{low}]]$, where $y$ is the proposed bit and the low selector bits choose a position in the chunk. Conditional equivalence clauses for all low selector positions enforce this value. For each high selector value, one clause requires its bank variable, named by the corresponding physical data chunk, to be true if the high selector is active. All four selected arrays are determined uniquely given $i,j$.

To check the *whole row* against $B$, partition $a$ into $d/h$ chunks. For each chunk $g$ make one more bank. Its variable $D_{g,m}$ is the parity of the coordinates selected by mask $m$ from that chunk of $a$. Set $D_{g,0}=0$. For each nonzero $m$, clear one specified one-bit and use an XOR equivalence with the corresponding entry of $a$. The library is shared by every column of $B$. For column $l$ and middle-index chunk $g$, the $h$ entries of $B$ give $m$. Equate a fresh term wire to $D_{g,m}$ with two padded implication clauses. XOR the $d/h$ term wires for $l$ and compare the result with $u_l$. This computes the selected row of $E$. Apply the transposed construction to chunks of $b$, using masks from $A$ to compute the selected column of $E$ against $v$.

Decode selectors, compute prefix flags and enforce both first-one conditions with deterministic gate equivalences. Every library entry, term, prefix flag and gate wire has a unique value on fixed selectors and source data, irrespective of how often a mask was selected. Pin every unused numerical identifier in the reserved range to false. Short clauses are padded by distinct false variables pinned by seven proper clauses on three names. Unused identifiers and padding bits therefore introduce no extra assignments.

## Length, bit occurrences and construction time

There are $4d+2d/h$ banks, with $O(dh2^h)$ fixed library clauses in total. The number of reserved identifiers to fill is $O(d10^h)$. Both costs are $o(d^2/\log d)$ for the asymptotic choice of $h$. The data clauses, term equalities and the two parity computations use $O(d^2/h)$ clauses. All names have $O(\log d)$ decimal digits. The number of **bits** in the file is $O(d^2)$, with the opposite bound from the changing digits. For power-of-two dimensions each $A$ or $B$ bit appears once in a selector lookup and twice in the two clauses for a parity lookup. Each $C$ bit appears once in a row lookup and once in a column lookup. All other digits and signs are fixed for that dimension. Every clause has three distinct variable names, and all names up to the declared maximum occur.

For arbitrary $d$, pad all three matrices with zero rows and columns to the next power of two. This preserves the rank, witnesses and assignment count, and multiplies the area by less than four for nonpowers of two. To construct the file, transcribe packed source rows into power-of-two bit lanes and read chunk digits by shifts and masks, including transposed accesses. Enumerate and emit the deterministic gate and library records using the same decimal-name tables as the bit-once projection. Even enumerating the $O(h)$ digits separately per dynamic name costs $O(d^2)$ steps in total. [Packed layout and construction details](compact-bit-projection-of-matrix-mismatch.md)

This gives a concrete matrix-verification test for reductions to SAT with few satisfying assignments. Handling all files whose source has rank-one error still leaves the question of a solver's execution time on unrestricted SAT.

The audit parses and enumerates assignments of 8,228 actual DIMACS files. It exhausts every binary $A,B,C$ of side two for each of two chunk widths. Across the five tested layouts it found 9,271 assignments, all with different witnesses within their file. It also compares each serialized file byte for byte against the zero template with the prescribed digit changes. The asymptotic compiler and rank bound above are manuscript arguments.
