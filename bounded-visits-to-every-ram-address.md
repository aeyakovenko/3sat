# A RAM simulation with a bound on every address's lifetime traffic

For each fixed rational $0<\epsilon\le1$ and $k\in\{1,2,3\}$, ordinary SAT has a deterministic $O(N^k)$-time word-RAM solver exactly when it has one with the following two properties. The solver reads the packed input once in increasing address order. On every run, **each physical writable address receives at most $O(N^\epsilon)$ loads and stores combined**. The controller has a fixed number of registers. The bound includes every auxiliary table and every pointer used to implement the simulation. Here $N$ counts encoded bits. The machine uses logarithmic words with enough address bits for the allocation below. The journal's concrete $12\lceil\log_2(N+2)\rceil$-bit convention suffices for these three clocks.

## A radix table migrated one entry at a time

Let a guest have $w$-bit addresses, let $B=2^b$ with $1\le b\le w$, and put $d=\lceil w/b\rceil$. Split each address into $d$ base-$B$ digits with high zero padding. Represent the logical array by a trie with one live root pointer in a register. An internal table entry gives the current header pointer for one child, or zero for an all-zero subtree. A bottom-level table entry gives the value. Allocate previously unused blocks by advancing a register. Reserving a range of initially zero addresses takes constant work.

A node header holds two array bases $S,D$ and an index $q$, initially zero. The current table is the prefix of $D$ of length $q$ followed by the suffix of $S$. On each visit, copy $S[q]$ to $D[q]$. To look up digit $j$ on this visit, use $D[j]$ if $j\le q$, otherwise $S[j]$. If $q+1<B$, increment the header index. Otherwise form a fresh header with source $D$, a fresh destination, and index zero, and replace the pointer to this node. At the root this pointer is in a register. At every other level the correct location is the active parent entry chosen on the present descent. Keep that location in one register. A write entering an absent subtree allocates the missing node. A read entering an absent subtree immediately returns zero. The selected bottom-level location serves the guest load or store.

Copying the next entry preserves the represented table before the guest operation. At rollover all entries have moved, so the new header represents exactly the old table. Any later change of a child pointer or bottom-level word goes to the selected current location. This proves correctness under fully data-dependent guest addresses. The algorithm descends without recursion or a physically reused stack. Each level uses a constant number of native steps, including zero-block reservation, rollover and parent pointer updates. The **worst-case** cost of one guest access is $O(d)$.

The header index receives at most $2B$ probes before that header retires. Each of its base fields is initialized once and read at most $B$ times. Consider offset $j$ of one physical array. As destination it can serve the guest on at most $B-j$ visits, numbered $j,\ldots,B-1$. As source in the next header it can serve on at most $j$ visits, numbered $0,\ldots,j-1$. It can receive one lookup and one child-pointer update per such visit, one migration write and one migration read. Hence **$2B+2$** bounds its total traffic. Nodes visited infrequently can persist for a long chronological interval.

For $t$ guest operations, the number of physical words actually probed is $O(1+td)$. The largest numerical address is $O((1+td)(B+1))$, since each newly reserved block occupies up to $B$ numerical addresses. These are different bounds. An address-width convention that forbids this range requires a separate argument.

## Applying the bound to SAT

First scan the packed input into a second simulated trie. All subsequent guest input probes consult this trie. With different fixed word widths, a register buffer repacks a constant number of physical words into guest words, retaining the final partially filled word. Out-of-range input accesses obey the guest's original convention. Choose $b=\max(1,\lfloor\epsilon\lfloor\log_2(N+2)\rfloor\rfloor)$ capped at the guest width. The logarithms and powers needed to set up the digit layout cost $O(\log N)$ native steps once. For a fixed logarithmic-word guest, $d=O_\epsilon(1)$, $B=O(N^\epsilon)$, and both the scan and simulation fit $O(N^k)$ time. Names up to $O(N^{k+1})$ suffice for the allocated blocks. If word width is specified up to a machine-dependent constant, choose the host constant large enough for both the guest arithmetic and these block addresses. The reverse implication follows by running the restricted program on the unrestricted machine.

One fixed program can achieve subpolynomial per-address traffic with a growing slowdown. For example, choose $b=\lceil w/\lceil\log_2\log_2(N+4)\rceil\rceil$. It has $N^{O(1/\log\log N)}$ probes per work word and time $O(N^k\log\log N)$ under the original clock hypothesis. For polylogarithmic traffic, $b=\Theta(\log\log N)$ instead gives $O(N^k\log N/\log\log N)$ time.

Writing $v_a$ for all visits to physical word $a$, the same construction at fixed $\epsilon$ gives $\sum_a \binom{v_a}{2}=O(N^{k+\epsilon})$. Thus a putative linear-time SAT algorithm could keep the number of same-address pairs in $O(N^{1+\epsilon})$ for every fixed $\epsilon>0$, with a separate constant-size program per exponent. A polynomial excess in that statistic forced on every correct program would rule out a linear solver. The simulation by itself supplies no such excess.

A concrete test is the journal's tiled expander family. A complete solver takes $O(N/\log N)$ guest steps there despite the family's communication lower bound at every balanced cut. With $B=2$, the simulation takes $O(N)$ steps on the family and uses at most **six probes per physical work word**, including the input copy. For global correctness, run the simulated recognizer and fast path under a fixed $CN$ host-step cap chosen to cover this family. On an unrecognized file or at timeout, invoke a complete solver on the original input. Every member of the family finishes on the fast path.
