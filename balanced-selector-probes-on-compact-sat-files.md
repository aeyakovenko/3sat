# The sharp number of query states at one private SAT word

Let $t$ selector bits index the $M=2^t$ bits of an arbitrary truth table $T$. The [private-probe argument](private-probe-contexts-in-read-only-sat.md) counted states that different selector strings bring to the same input address. Here its worst-case bound is attained, up to constants, by an explicit graph construction and a linear-time RAM algorithm on proper DIMACS files.

**Result.** There is a projection $(T,u)\mapsto F_{T,u}$ with $\operatorname{SAT}(F_{T,u})=T(u)$. For every sufficiently large $t$ and every integer $1\le b\le\lfloor t/8\rfloor$ it has the following properties.

* The files have a common bit length $n=\Theta_D(Mt/b)$ under the journal's word rule $w=16\lceil D\log_2(n+2)/16\rceil$ for fixed $D\ge1$. Their combined packed-word alphabet has $O(2^b)$ values. Each of the $M$ table bits appears as **one ASCII digit in one position**, changing only its low bit. Each selector bit varies the sign in just one packed word. All clause triples have distinct variable names.
* For some table, every exact deterministic query graph for its selector function needs $\Omega(M/t)$ query vertices in total and $\Omega(M/t^2)$ for some one selector. This applies to the graphs obtained from arbitrary deterministic SAT programs with unrestricted writable memory by contracting computations between original selector reads. No cap on the number of steps or repeated queries enters the count.
* For **every** table, there is a read-once graph of depth $t$ with $O(M/t)$ vertices and $O(M/t^2)$ vertices labeled by **each** selector. The same fixed total SAT algorithm can decide all of the displayed files in $O(n)$ native steps, attaining these query-state upper bounds on each of them at fixed $T,t,b$ across the choices of $u$.

Thus the common-word-alphabet and per-address state bounds can both be sharp on a family with a linear-time SAT algorithm. At $b=1$ the encoding saves a logarithmic factor over the earlier bounded-alphabet tree. At $b=\lfloor t/8\rfloor$ it has length $\Theta(M)$ and uses identifiers of polynomial numerical size. The lower bound counts states across different runs. Reading a selector on one particular run takes a single native probe.

## Balancing which variable labels the large levels

Set $r=\lceil\log_2 t\rceil$, $q=t-r$ and $k=\lfloor\log_2 q\rfloor-1$, taking $t$ sufficiently large. Thus $q/4<2^k\le q/2$. A complete tree first queries $r$ head bits to select a group $g\in\{0,\ldots,2^r-1\}$. In group $g$, read the $q$ remaining selectors in cyclic order starting at $g\bmod q$. Its first $q-k$ questions form a complete binary tree. Each outgoing edge at its last level specifies a table on the final $k$ variables. Its $2^k$ truth values are the original table bits having this prefix. Those blocks partition all of $T$, even though different groups order the variables differently.

Use a shared graph for suffixes. For each of the $q$ rotations, for each remaining depth $d=1,\ldots,k$, include one vertex for **every** truth table on the last $d$ selectors in that order. Its zero and one children carry its two restrictions to the final $d-1$ selectors. At depth zero they are the Boolean terminals. Writing the truth-table bits of a suffix as its binary index in this list makes the block of original table bits itself the choice of the child at the prefix boundary. On each traversal the remaining truth table is restricted by the actual next bit. Thus the graph returns $T(u)$ after exactly $t$ queries.

There are fewer than $2^{t-k}$ prefix vertices and $q\sum_{d=1}^k 2^{2^d}=O(q2^{q/2})$ library vertices. Their total is $O(M/t)$. A head variable labels at most $2^{r-1}=O(t)$ vertices. At a given tail prefix level $j$, a specified remaining variable labels the $2^j$ vertices of at most $\lceil2^r/q\rceil=O(1)$ groups. Summing over $0\le j<q-k$ gives $O(2^{q-k})=O(M/t^2)$ occurrences. Even counting the entire library again leaves this estimate unchanged. The group-dependent rotation matters: a single shared order could place all the largest prefix levels on the same few physical probes. The classical worst-case $O(2^t/t)$ total-size bound for ordered binary decision diagrams predates this argument. The rotation here controls the maximum number of vertices with one label. Priority for the latter construction is unestablished. [Bollig and Wegener, *Asymptotically optimal bounds for OBDDs*](https://eccc.weizmann.ac.il/report/1999/048/download/)

For the matching lower bound, allocate $K$ slots per selector, allowing unused slots, two possible successors per slot, an initial state, both verdicts and divergence. At most $(tK+3)^{2tK+1}$ graphs are possible. A single graph has at most one total truth table. If $K$ is a sufficiently small constant times $M/t^2$, these graphs number $2^{cM}$ for some $c<1$. Almost every table therefore exceeds that budget. For a total slot budget $S$ with arbitrary vertex labels, an upper count is $t^S(S+3)^{2S+1}$ and gives $S=\Omega(M/t)$ in the same way. One can choose a common table defeating both small budgets, by the union bound. For a writable RAM, record its overlay relative to the original file, including which addresses have ever been written, and the controller. At fixed $T$, the public reads and all reads of written words can be computed from this state. A private query occurs only at an original selector word without a prior write. Contract the intervening deterministic operations; a public divergence becomes its own terminal. All runs with true selector replies are preserved. The count applies also to any smaller deterministic representation that preserves the labeled queries and their continuations. This use of counting belongs to the classical subfunction method. [Beame et al., *An Abstract Formulation of Nečiporuk's Lower Bound Method*](https://arxiv.org/abs/1608.01932)

## A length-optimal ordinary encoding

Give each graph vertex its own Boolean name $z_v$, including accept and reject, and give each selector a name $u_j$. Use three fresh names $a,b_0,c$ and the seven proper clauses forcing these three false. A pin on another variable $v$ is $(\pm v\lor a\lor b_0)$. Pin each selector to its input value, the root to true, and the reject vertex to false. At an internal vertex $v$ labeled $j$ with zero and one children $l,h$, use only
$$
 (\neg z_v\lor u_j\lor z_l),\qquad(\neg z_v\lor\neg u_j\lor z_h).
$$
No child is its own parent in the construction. If the walk reaches reject, every marking satisfying these clauses must mark it, contradicting its negative pin. Otherwise mark exactly the vertices on the actual root path and extend the selector and dummy pins as specified. The implications and both endpoint pins hold. In particular the child name at each table-dependent edge occurs just once in that edge's clause, with no consistency copy of the table field elsewhere.

Use fixed binary identifier codes of $\ell=O(t)$ bits, with disjoint namespaces for the dummies, selectors, prefix vertices and suffix vertices. A prefix vertex is described by its depth and its path bits with padding. A suffix name describes its rotation, depth, and truth table as a low-order field with zero padding to a public width; its parent's reference can use the actual block bits verbatim. Reserve at least $2^k$ bit positions for that field. All names at a particular $t,b$ use the same code length. They need not be consecutive. Encode each code as a positive decimal identifier: start with the digit 1, then replace each successive $b$-bit group (using leading zero padding if needed) by a full word of $W=w/8$ decimal digits, $W-b$ zeros followed by its $b$ bits written as digits. A fixed aligned word holds the sign slot and the leading 1. Put whitespace between names and a separated zero terminator at the end of each clause. Terminals also have distinct ordinary variable names.

The header may declare the all-ones code, including unused identifiers. Its long name has a periodic interior formed by repetitions of the same digit block. Its decimal clause count has $O(t)$ digits, or $O_D(1)$ packed words. Give the public parameters $t,b$ a self-delimiting whitespace representation after the header on word boundaries, for example $t$ then $b$ copies of one whitespace word, each list ending in a different whitespace word. This costs $O(tw)$ bits. A width can equivalently be computed from the file length before reading this prefix. Every body word is one of a bounded set of structural words or a digit block with $b$ variable low digits. The word palette including the header, controls, padding and zero background has size $O(2^b)$ across all inputs.

There are $O(M/t)$ clauses, with $O(1+\ell/b)$ packed words each. Choose the common byte-aligned length near $C_D M t/b$ bits for a sufficiently large constant fixed in advance. Then $w=\Theta_D(t)$, $W\ge b$, and this budget fits the construction; append whitespace. On the other hand, at any fixed selector setting these files are distinct for all tables: each table entry has its own digit. More generally in any common layout where fixed substitutions of the private selectors realize all $2^M$ tables, equal base files induce the same function. If $h$ packed words are available throughout the layout, $h^{\lceil n/w\rceil}\ge2^M$. For $h=O(2^b)$ this needs $\lceil n/w\rceil=\Omega(M/b)$. The displayed representation attains this information bound. This argument counts both the public table and the selectors in the encoded length.

## Cost on an actual unrestricted RAM

There is a uniform total SAT solver with a fast path for this syntax. Read the header and public parameters with size checks; regenerate the public template in order and compare its words to the input. Accept either valid sign at each selector word and discard the distinction immediately. Each table-dependent digit may independently be 0 or 1, and every choice of all these digits specifies a valid table. Save the corresponding target vertex in a public-at-fixed-$T$ edge array. Verify the trailing padding. Malformed parameters or deviations from the template transfer to an ordinary exhaustive solver on the original input. The input remains available to that solver. The enumeration uses $O(t)$ word operations per node for names, field comparisons and child construction: bit positions are available by shifts, and the fixed-zero part of an aligned digit block can be tested in bulk as one word. More explicitly each name can be generated in $O(1+\ell)$ word operations by appending its $b$ bit digits to a word prefilled with ASCII zeros in $O(b)$ steps per block. The suffix-restriction masks fit in $O(1)$ words. Padding and headers can also be checked in $O(n)$ native time. A dense array indexed by enumeration ordinal uses $O(M/t+t)=o(n)$ words, fitting the standard address width. A suffix vertex ordinal is computed from its three fields using the known library block sizes. Cap candidate parameters and allocations before using them on an unrelated input.

After validation, follow one graph edge for each selector read. Keep only the current vertex between probes, along with the fixed public parameters and arrays. Clear selector-dependent temporaries before the next private probe, during validation as well as during evaluation; no selector-dependent writes are needed. Node depth supplies any needed traversal position. The check of a selector word uses one original LOAD, then permits either legal form and returns to the same continuation. Thus across the promised executions the validation adds at most one probe context per selector; the traversal needs at most one per graph vertex. Both stages together cost $O(n)$ on these files, including verification that the fast path is legitimate for a total solver. On any syntax with other restrictions or length coefficients, only the stated construction and bounds are asserted.

The [Lean proof](SelectorReachabilityClauses.lean) establishes equivalence of the two conditional clauses per vertex to existence of a successor-closed marking containing the start and excluding reject. It applies even to cyclic graphs under the unreachable-reject convention. The [finite audit](balanced_selector_graph_audit.py) evaluates 285 graphs on 15,272 paths and solves 72 of the small 3-CNFs independently. It also changes each of 256 table bits in isolation at three digit block sizes, checks that exactly one ASCII low bit changes, parses the base files and checks all eight distinct selector sites. The asymptotic size analysis and the uniform RAM cost bound are manuscript proofs.
