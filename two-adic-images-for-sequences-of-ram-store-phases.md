# Historical predecessors for polynomial-address RAM store phases

Suppose a RAM bank has \(2^b\) addresses, with native arithmetic modulo \(2^b\). In phase \(i\) the machine makes one full sweep through the local ordinals \(t=0,\ldots,2^b-1\), writing to address \(P_i(t)\). The integer polynomial \(P_i\) has degree at most \(k\); its coefficients may be different in every phase and can be supplied by the original input or preceding computation. After \(p\) phases, all last-write questions, at arbitrary historical cutoffs and addresses, have one index of size \(p\operatorname{poly}(k,b,\log(p+2))\) bits. Processing each new phase takes \(\operatorname{poly}(k,b,\log(p+2))\) word operations, and each query takes the same time, independent of a linear scan through the phases or their \(2^b\) visits. A stored value can be retrieved if it is independently computable at the returned phase and ordinal. The address result makes no assumption on payloads.

The index also handles arbitrary truncated sweeps when the address polynomial is evaluated at the bit-reversal of the local ordinal. Normal chronological order admits arbitrary cutoffs within the currently queried full sweep. All arithmetic blowups are polynomial for \(b,\log(p+2)\) fitting in a fixed number of host words. Fixed \(k\) already allows arbitrarily singular roots, repeated writes, different maps on every phase, and huge variation of root multiplicities.

## Uniformly partitioning one input sweep

Write \(R_b=\mathbb Z/2^b\mathbb Z\). A ball of precision \(h\) is a low-bit residue class \(x=a\bmod 2^h\). Starting at precision zero, expand on a ball
\[
 P(a+2^h y)=c_0+c_1 y+\cdots+c_k y^k\pmod{2^b}.
\]
Compute the coefficients by the binomial formula or repeated Horner substitution. Assign valuation \(b\) to zero residues. Let \(s\) be the minimum valuation among \(c_1,\ldots,c_k\), or \(b\) when there are none. If \(s=b\), the image is the singleton \(c_0\). If \(s<b\) and only \(c_1\) attains the minimum, the image is the whole ball \(c_0\bmod 2^s\). Indeed the normalized nonconstant part divided by \(2^s\) has an odd linear coefficient and even coefficients in all higher powers. It permutes every \(R_j\): it permutes the two parities and changing the next input bit changes exactly the next output bit modulo that precision. Also \(s\ge h\), so the \(b-h\) remaining input bits supply at least \(b-s\) bits for the permutation. Otherwise split into the two precision-\((h+1)\) children. Every ball stops by \(h=b\).

The resulting tree has \(O(1+kb)\) nodes, including for modulus-dependent coefficients. The following proof uses the ordinary formal derivative \(D=P'\) of an integer lift. Constants can be treated immediately. For a nonconstant lift, \(D\) is a nonzero integer polynomial. On any input ball write \(D(a+2^h y)\), remove the common power of two from all coefficients, and take the degree of the resulting polynomial modulo two. Call this nonnegative integer the weight. A weight-zero polynomial has its constant coefficient strictly below the valuations of all its other coefficients.

The two children's weights sum to at most the parent weight. For the normalized parent polynomial \(H\), take one child residue \(r=0,1\). If \(r\) is not a root modulo two, the child has weight zero. If its multiplicity is \(u>0\), the coefficient of \(y^u\) in \(H(r+2y)\) has valuation exactly \(u\). Higher coefficients have strictly larger valuation because they include the higher power of two. Removing the common child content therefore leaves degree at most \(u\) modulo two. Sum the two residue multiplicities. There are consequently at most \(k-1\) positive-weight balls at any depth. This potential is needed only in the proof; the implementation can work modulo \(2^b\) throughout.

If the derivative has weight zero on a parent, both children of that parent pass the stopping test for \(P\). To see this, let the parent precision be \(h-1\) and let \(a\) represent a child. Translating the center within the parent preserves the strict dominance of the derivative's constant coefficient: after division by its content the entire reduction is still the same nonzero constant. In the expansion \(P(a+t)=\sum_j A_j t^j\) the nonconstant coefficients of the parent derivative are \(j A_j2^{(h-1)(j-1)}\), \(j\ge2\), all strictly higher in valuation than \(A_1\). At the child precision, \(A_j2^{h(j-1)}\) has valuation at least that of this derivative coefficient, since \(j-1\geq\nu_2(j)\). Thus \(A_1 2^h\) strictly dominates every higher nonconstant term of the child's expansion, unless they all vanish at the working precision, which also stops. Only two children per positive-weight parent can require a further split. This proves the stated node count.

The classical literature computes root sets and their representatives modulo prime powers. The tree above serves a different output interface: all dyadic **input-to-image** pieces for a single polynomial are constructed together before a target address is known. The local lifting and valuation arguments are standard. Priority for the particular image bound or its use in a phase directory is unestablished. ## Recovering the greatest local write

Fix target \(z\) and a leaf at input precision \(h\) whose output ball contains it. On a constant leaf every input ordinal in that ball works. Otherwise invert the normalized polynomial on \((z-c_0)/2^s\bmod 2^{b-s}\) by lifting one bit at a time. If \(y_0\) is the answer, all original input ordinals on that leaf giving \(z\) form exactly one class
\[
                 x=a+2^h y_0 \pmod {2^{h+b-s}}.
\]
For an ordinary cutoff \(t<L\), the maximum in any such class is elementary division after checking whether the least nonnegative member is already too large. Take the maximum across the \(O(1+kb)\) leaves. The reasoning uses full equality of word addresses with standard carries, not separate low-degree equations in their binary coordinates. [Bit-coordinate scatter and its different complexity](last-writers-for-affine-and-quadratic-native-store-addresses.md)

For a bit-reversed sweep, \(x=\operatorname{rev}_b(t)\). The preimage class \(x=a'\bmod 2^u\) now becomes the ordinary chronological interval whose top \(u\) bits are \(\operatorname{rev}_u(a')\). Intersect that interval with the supplied cutoff. To preprocess a phase stopped at an arbitrary length \(L\leq2^b\), decompose \([0,L)\) into \(O(b+1)\) high-bit chronological prefix intervals. Their bit-reversals are low-bit input balls on which the same image partition starts directly. This uses \(O((b+1)(1+kb))\) leaves and supports arbitrary earlier cutoffs within the phase. For ordinary order a truncated phase's image can need exponentially many low-bit balls: the first half of the identity sweep occupies half the modulus and contains no nonsingleton low-bit ball. This is an obstruction to that particular directory.

## All historical phases together

Store the polynomial and leaf list once for each phase. For every output ball among its leaves, append the phase number to a dictionary list keyed by the precision and low residue. Duplicate occurrences within a phase can be deduplicated or left adjacent. Ordered phase installation keeps each list sorted. An array with geometric growth or a balanced search tree provides the stated construction and access bounds (balanced trees allow worst-case online per-operation clocks).

For cutoff within phase \(i\), first ask its own local predecessor. On a miss, visit the \(b+1\) possible low-prefix keys of \(z\), taking the largest list predecessor **strictly below** \(i\) at any of them. That is exactly the latest completed phase which wrote \(z\). Recover its last local ordinal by the leaf procedure, with the entire completed phase available. A miss on all keys means initialization. Constant-address scalar events can also be inserted directly as singleton output balls with their own phase numbers. This permits an ordinary online RAM suffix to overwrite earlier results. Index space still charges the stored phases. If a phase's payload calculation reads a changing bank during its own sweep, locating its last ordinal alone supplies no word value. Simultaneous frozen-value polynomial permutation passes admit a different dynamic reduction which can omit nearly all prior phases.
