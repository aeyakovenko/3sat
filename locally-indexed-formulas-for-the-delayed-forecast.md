# Extending a uniquely satisfiable file against all programs in a finite portfolio

Let $A$ be any fixed ordinary proper ASCII 3-CNF with exactly one assignment to all its declared variables. Fix a description budget $C$ for deterministic logarithmic-word RAM programs. There is a computably specified construction on dyadic scales $B=2^j$ giving, for all sufficiently large $j$, a proper ASCII 3-CNF $D$ with the following properties.

* Its body begins with all of $A$'s clauses with their original names, signs, spacing and order. The DIMACS counts are updated. The new clauses use fresh names, and the old model extends in exactly one way.
* Every globally correct SAT program of at most $C$ description bits takes $\Omega_{A,C}(B)$ steps on this same satisfiable file. The encoded length is $N=\Theta_{A,C}(B(\log B)^3)$.
* The lower bound holds even for programs promised a correct indexed presentation and freely given its public construction parameters, including the old file and its model. Here soundness is required on the **whole family** of bounded deterministic computations specified below. For a partial program whose only guarantee is that every YES is correct, the bound is on time to a YES signal. A program that decides the promise must give that signal on the terminal positive file. Requiring correctness only on the eventually positive output sequence for this fixed $A,C$ would permit a constant answer after its threshold.

All available native memory is allowed. Each removed program is caught answering YES on an explicit unsatisfiable extension at the very same scale. The procedure runs at most once more than the number of candidate programs. With the public parameters, every input word is computable in constant native time after sublinear setup in $B$. The lower bound therefore still charges elapsed computation in a model that can bypass access to a physical file. A separate globally correct promise program specialized to the selected fixed template evaluates its bounded deterministic computation in $O_{A,C}(B)$ on these presentations. Its description length is unrestricted.

## The indexed family and its exact extension count

For a fixed deterministic native program $U$, a public virtual input $y$ of length $B$ and any auxiliary construction parameters, compile the predicate that $U$ returns one by step $B$. Use its actual fixed word-width convention at length $B$. Let $D_{A,U}(B,y)$ conjoin $A$ with this bounded computation on a disjoint consecutive block of fresh names. The applications use a self-delimiting parameter prefix, a zero tail and constant-time packed access to $y$. Inputs too short for the stipulated format can be handled separately. The constructor accepts arbitrary well-formed $U$ and $A$ with a supplied satisfying assignment. All these valid presentations can be effectively enumerated and their answers tested. The result counts extensions uniquely for each satisfying assignment to $A$ when the compiled predicate holds.

A bounded native trace has $O(B)$ instruction rows and $O(B)$ memory events after adding initializations and dummies. Each event has $O(j)$ bits. To ensure a unique witness use a deterministic sorting circuit for the events, ordered by bank, address, time and within-step order with a fixed deterministic tie rule. The locally indexed construction has $O(Bj)$ compare-exchanges of $O(j)$ bits each and constant-time access after $O(B^\delta)$ preparation for any fixed $\delta>0$. It uses a constant number of recursive columnsort levels and shares a precomputed small AKS leaf schedule among the blocks. Copied initialized values, reads, writes and final outputs are checked with the chronological and sorted adjacency tests of the packed computation reduction. Make idle steps and dummies canonical, including every unused lane and every auxiliary scratch value. Check the exact deterministic register transitions, including word-width operations and their fixed exceptional cases. Standard fixed arithmetic has $O(j^2)$ gates per row. Alternatively division uses the unique quotient and remainder for a nonzero divisor, with their dummy values pinned in every inactive branch. Once the initial state is fixed, sorting and memory consistency force each successive genuine state; the deterministic circuit then fixes every other bit. Give each gate its full truth-table equivalence and pin the result. Thus zero or one satisfying assignment is possible on the new names. A simpler implementation with Batcher's bitonic sorting network uses $O(Bj^2)$ comparisons and one more logarithm in the file length. Simplify repeated or complementary occurrences within a gate clause before padding it to three distinct variables. Three fresh anchors are fixed false by the seven proper clauses forbidding each of the other three-bit assignments. Distinct false anchors pad shorter clauses; a clause forcing a spare variable false uses two of the anchors. A constant true clause on the anchors can fill a reserved output slot. Allocate and constrain every new variable, including any dummy slots, so declaring the last used name introduces no unconstrained gaps. Pad the template to $\Theta(Bj^2)$ records with individually constant many literals. Choose fixed field widths of $\Theta(j)$ ASCII bytes for those literals, writing spaces before a sign or its canonical numeral to fill the slot. Copy $A$'s body as supplied, with a token separator if its last line had no terminator. This gives the asserted $\Theta(Bj^3)$ **bits**, including decimal names.

Beyond the sorting schedule, the single-row arithmetic gate and word-formatting templates need $\operatorname{poly}(j)$ preprocessing. Per-clause lookup splits an index into the family, time or wire, comparator stage, and small gate/bit slot. Arithmetic templates use adjacent indices or a fixed row offset, and the sorting construction supplies the wire coordinates for its comparisons. Array strides can be padded to powers of two. For decimal conversion, take $b=\max(1,\lfloor j/16\rfloor)$ digits per chunk and tabulate the padded and unpadded spellings and digit count for integers below $10^b$. This costs $O(10^b\operatorname{poly}(j))=o(B)$; each packed spelling occupies a constant number of words. An $O(j)$-bit integer has $O(1)$ base-$10^b$ chunks. Divide by the precomputed chunk base, attach fully padded lower chunks and the ordinary spelling of the leading chunk, then place leading spaces and the adjacent sign. Zero and the DIMACS header are handled separately. Division by the public powers can also use precomputed reciprocals at fixed double-word precision, with a single compare/correction after a fixed-limb product. A native word of any fixed coefficient intersects only $O(1)$ template records, with the constant allowed to depend on that coefficient. Bit shifts and masks combine the pieces. The old body is a fixed string. This supplies true packed words in $O(1)$ time after $o(B)$ setup.

## Eliminating a false positive at the same scale

For a fixed list of candidates, the driver receives an activity mask $u$ with one bit per candidate. Let $y_u$ include this mask and the public parameters. Construct a driver $Q$ with access to its own finite description. Syntactically a program template on parameters $(z,x)$ computes the specialization of $z$ with its first argument fixed to $z$, then uses that code as the driver parameter of the formula generator. Specializing the template at its own code produces $Q$. The generator indexes transition templates for $Q$ and never follows the execution being encoded. This constant syntactic specialization is independent of the input clock and mask.

On its actual input, $Q$ supplies every active candidate the virtual file $D_u=D_{A,Q}(B,y_u)$ with this very mask. Give a promise candidate the genuine parameters as well. On ordinary program entry it receives only the physical file interface. Use separate tags for the two interfaces if both are included in the budget. Charge each trial an explicit budget of elementary simulator operations, including instruction interpretation and virtual input accesses. A YES in budget makes $Q$ return zero and record the signalling index. Without such a YES, $Q$ returns one. Make the aggregate budgets small enough that all trials, setup and return fit before the computation clock $B$ for every mask. The uniform implementation below gives such budgets. Different trials start with the correct initial bank, including flags to distinguish a write of zero to an input word from an untouched word. No restriction is placed on which addresses the original candidates may use.

Start with every index active and simulate this *bounded* $Q$ on $y_u$. If it returns zero on a YES by $p$, the actual proper formula $D_u$ is unsatisfiable by the deterministic compilation, and $p$ gave a positive answer on that exact file. Remove $p$ and repeat at the same $B$, supplying the new mask to the driver, the generator and the promise candidates. Only programs witnessed to be unsound on genuine presentations are removed. If $Q$ returns one, $D_u$ is uniquely satisfiable and no remaining program emitted YES within its trial. Every correct candidate remains, and halting correctly on this final file requires returning YES. An empty mask also returns one. Thus with $m$ candidates there are at most $m$ explicit unsatisfiable counterexamples and one final uniquely satisfiable file. The resulting finite suite also covers programs that are wrong on some inputs. Every removed program has a false positive on a recorded member. On the terminal member, every surviving program either fails to decide correctly or takes more than its allotted timely-YES budget. The trace of each removed trial supplies its code, its mistaken answer and the complete data defining the file. No SAT oracle or estimate of when a bad program might fail somewhere else is used. At fixed $A,C$, the external learner can find the terminal mask in $O_{A,C}((m+1)B)$ word steps by running the driver itself before emitting the physical formula. All rejected physical files can be generated too, charging their aggregate output. The terminal mask can be shown to the predictor; its inclusion as trusted input was already part of every trial on that mask.

For each fixed $A,C$, allocate a fixed positive fraction of $B$ simulator work to each active code, with the sum below the cap. Each genuine instruction of each fixed candidate takes bounded simulator work after setup. A correct decider therefore needs $\Omega_{A,C}(B)$ steps on the terminal file. A larger solver can recognize the fixed template using its genuine public parameters, run $Q$ itself for $B$ steps and use ordinary SAT on other promised presentations. With a word coefficient covering this fixed direct simulation the cost on the selected template is $O_{A,C}(B)$. Knowing the template or the old satisfying assignment is consistent with both bounds.

The finite elimination and its exact trial bound are formalized for arbitrary mask-dependent responses; faithfulness of the native compilation is a hypothesis there. A small physical-file test constructs actual proper formulas whose hidden record is unique on each terminal mask, solving each one by counting its models. ## One driver for growing portfolios

Here is an explicit encoding for which the portfolio size itself can grow. Fix a standard finite operand/register ISA with the usual logarithmic-word operations and programs given by ordinary finite tables of instructions. Require a polynomial-time syntactic decoder on the program bits (fixed-register instruction formats with explicitly written literals and jump labels suffice). First give every candidate the **same** width $D\lceil\log_2(N+2)\rceil$ for a fixed $D$. The universal driver has its own sufficiently large constant word coefficient. Set $j=\log_2 B$, $C=\lfloor\log_2 j\rfloor$, and enumerate all bit strings of length through $C$ in length-lexicographic order. Include invalid strings as inert programs. The index count $m$ is $O(2^C)=O(j)$, also with a constant number of interface tags. Index ranks $i=0,\ldots,m-1$ have a fixed order independent of $B$.

Put the old file $A$, its declared-variable model, offsets, count, the current mask and the necessary parameters in the virtual length-$B$ input. It suffices that the byte length of $A$ and its largest declared name are at most $B^{1/4}$, which can always be arranged when extending any fixed old file. The rest of $y_u$ is zero. Supply the old file/model and parameters as metadata to the promise solvers, excluding any assertion that the present mask is terminal. This single $Q$ works as $A,C,B,u$ vary. It can parse the old header and check the relevant ranges in $O(B^{1/4}\operatorname{poly}(j))$ setup. An index into the old body is a direct read from its input. An initialization bit for the *new* bounded computation is read from this same actual $y_u$. Fresh names are offset by the declared bound of $A$. The new template has $N=\Theta(Bj^3)$ bits uniformly over the permitted inputs. Predecode all $C$-bit program texts into indexed instructions in $2^{O(C)}\operatorname{poly}(C)=\operatorname{poly}(j)$ setup, using only the fixed syntax. Tables of $O(B^\delta)$ size for sorting and decimal conversion fit the driver clock with any fixed $\delta<1$ (choose smaller digit chunks if necessary). These tasks can be shared among all trials on this input.

Use a fixed clock implementation that charges one trial operation per elementary simulator step, with constant driver overhead. With a sufficiently large fixed integer $K$, allocate to rank $i$ the sum
$$
  \left\lfloor\frac{B}{K m}\right\rfloor+
  \left\lfloor\frac{B}{K2^{i+1}}\right\rfloor
$$
in trial operations. Ignore its allocation if the mask is inactive. The sum of even the fully active allocations is at most $2B/K$. A shift exceeding the counter width gives a zero second allocation. For fixed $D$, a candidate's word at length $N$ fits in a fixed number of host words, independently of the candidate and $B$. The driver coefficient can be chosen high enough to address distinct overlay banks for all trials and separate written flags with rank tags of $O(\log j)$ bits. Program fetch by its predecoded offset, ordinary word arithmetic and access to any true packed input word therefore have uniformly bounded cost. Including trial switching and all setup, $Q$ returns within $B$ on every mask for all sufficiently large $j$. Only these elementary resource thresholds apply; correctness of a candidate is never part of the qualification for a scale.

At each such scale the terminal file consequently needs $\Omega(B/2^C)=\Omega(N/(\log N)^4)$ native steps for **every** correct fixed-$D$ candidate of at most $C$ bits, with a constant independent of $C$. Simultaneously the allocation to any fixed rank is a fixed positive fraction of $B$ at all sufficiently large scales. Every fixed correct program $p$ eventually needs $\Omega_p(B)=\Omega_p(N/(\log N)^3)$ steps, with its own constant.

One can also let a candidate specify a **binary width multiplier** $1\le D_p\le 2^C$ in its code, for the convention $D_p\lceil\log_2(N+2)\rceil$. Preserve a single fixed width for $Q$. Split addresses and values into $O(1+D_p)$ digits of $\max(1,\lfloor j/8\rfloor)$ bits. A radix trie holds the overlay by address digits. Each trie cell address is a tagged pair (allocated row number, digit), fitting a fixed host word since a new row requires a charged operation and at most $O(B)$ rows are allocated in a trial. Missing paths cost only the actual traversed depth. On a read with no prior write, a large address can be compared with the true input range before reading its $O(1+D_p)$ output limbs. Use fresh row numbers or disjoint root tags across trials. With digit-size multiplication and division available, ordinary schoolbook multiplication and normalized long division cost $O((1+D_p)^2)$ host instructions including the bounded corrections per quotient digit. A highest-set-bit table on a digit has size $O(B^{1/8})$ and handles normalization. Precompute widths once per program; oversize shifts and the zero-divisor convention have fixed explicit tests. This gives a uniform $O((1+D_p)^2)$ bound per native instruction. The equal share now guarantees $\Omega(B/2^{3C})=\Omega(N/(\log N)^6)$ for the full growing cohort, and the geometric share still guarantees $\Omega_p(N/(\log N)^3)$ for each fixed correct code. A more exotic width declaration can change this uniform dependence on description length. [Fixed-limb simulation, radix addresses and division](native-unary-clock-band.md)

Use the terminal file as the next $A$, keeping its unique assignment (recoverable by evaluating the actual deterministic trace and all checker gates). Choose $j'=ej$ large enough to satisfy the elementary input-size bounds for this old $A$ and to increase the code budget at least by one; then $B'=B^e$. It is enough to pick the least such multiple above an explicit size bound, or test increasing multiples if the harmless small-scale conventions are in use. All drivers and masks in one learning stage have the same $B'$ and new clause layout. Every candidate eliminated there has a certified error on a proper extension of precisely that old $A$. If the uniform setup constants are not supplied as external numbers, a search can run the bounded simulated drivers, check that the final one really returned one by its deadline and check the charged instruction counts for the prescribed finite target; all sufficiently large scales with the prescribed margins succeed. This gives a computable increasing chain of actual uniquely satisfiable files. Only the DIMACS header changes before the end of the old body. The positive witness restricts to the entire old model, and the time guarantee holds afresh on each sufficiently late file for every fixed correct program. The selection work itself includes the races that establish the lower bound.

## What direct compilation of the forecast itself buys

There is also an unconditional positive answer to the narrower one-sided certificate question **if the encoded-length cutoff is relaxed**. On input $\operatorname{bin}W$ of length $n$, a bounded deterministic native program simulates the single-interval tape that implements the delayed recurrence for exactly $W^4$ tape updates and checks its zero output. An array of $W$ tape cells, initialized implicitly, implements the finite tape transition in constant native time. Include the correct initial wall and head; any required explicit $O(W)$ initialization fits. Pad the $O(W^4)$ clock to a dyadic horizon of that order. Generate the ordinary formula above for the zero verdict with the public input carrying $W$, without materializing the physical file inside the source simulator. The deterministic new clauses have a single model exactly when $V(W)=0$. A fixed satisfiable old $A$ can again be prepended. For the elementary bitonic implementation here the resulting length is $N=\Theta(W^4 n^4)$. At this clock the decimal table remains affordable inside the source guest. The horizon has binary logarithm $4n+O(1)$, so the table with chunk length $b=\lfloor(4n+O(1))/16\rfloor$ costs $W^{(\log_2 10)/4}\operatorname{poly}(n)=o(W/n)$ steps. Subsequently each packed word takes $O(1)$ guest instructions.

For any globally correct solver $S$, place in the wide diagonal header the guest that simulates $S$ on this virtual ordinary file, returning zero only on YES. Simulating each of its instructions takes $O_S(1)$ wide-guest steps. Use separate direct-addressed banks for written flags and values. Their addresses fit by choosing the guest width coefficient above the solver coefficient times the fixed ratio $\log N/n$, and only the words touched before the cutoff need space in the interval interpreter. The sub-$W/n$ initialization is included in the guest clock. On every sufficiently large own-header width the forecast is zero by one-sided soundness, so the file really is uniquely satisfiable. The actual elapsed time of $S$ on it is $\Omega_S(W/n)=\Omega_S(N^{1/4}/(\log N)^2)$. The exponent loss is visible even with free local generation of the long file. The earlier native construction attains the stronger $\Omega(N/(\log N)^3)$ computational bound on its own family. Both bounds fall below the requested exclusion of linear, quadratic or cubic RAM time.
