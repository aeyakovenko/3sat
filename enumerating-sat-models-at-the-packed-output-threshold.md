# Enumerating dense 3-SAT at the packed-output threshold

Let \(H\) be the hypergraph of distinct three-variable clause supports in a proper 3-CNF on \(v\) named variables. Write \(E\) for the number of independent subsets of \(H\) of size at least three, \(J=1+v+\binom v2+E\), and \(w_0=\max(1,\lfloor\log_2(v+2)\rfloor)\). For every fixed \(C\), a deterministic logarithmic-word RAM enumerates all models, as packed full bit vectors with a common name dictionary, in
\[
                  O_C\bigl(1+v^3+vE/w_0\bigr)
\]
native steps given the support and sign table whenever \(E\le C v^2 w_0^2\). This parameter measures sets allowed by the *unsigned* support hypergraph; actual output can be smaller or empty for particular signs. On a proper comment-free packed DIMACS file of \(N\) bits add \(O(1+N/\log(N+2))\) for parsing. Accordingly \(E=O(v^2\log v)\) permits time of packed-scan order, and \(E=O(v^2\log^2 v)\) permits \(O(N)\) steps. The latter time bound also allows ordinary bytewise parsing with whole comment lines.

These two promise thresholds are sharp in asymptotic order for enumerating full vectors. Omit exactly the triples contained in a set of size \(t\), and put the all-negative clause on every remaining triple. Then \(E=2^t-1-t-\binom t2\), and setting every other variable to zero already gives \(2^t\) models. With consecutive decimal names and \(t\le v/2\), the file length is \(\Theta(v^3\log v)\). Writing full packed vectors requires \(\Omega(v2^t/\log v)\) word writes. Taking \(2^t/(v^2\log v)\) or \(2^t/(v^2\log^2 v)\) unbounded violates, respectively, a packed-scan or byte-linear enumeration clock. For a proposed promise growing beyond one of those thresholds, choose an appropriate power of two below it; adjacent powers differ by a factor of two. This output lower bound makes no claim about decision alone or compressed descriptions of the set of models. The clock for arbitrary SAT remains open.

## Sibling lookup in the support enumeration

Use the [balanced layout](balanced-splits-for-incomplete-clause-triples.md), with one weighted representative triple per independent set of size at least three. At a level with interval width \(\ell\) on a padded domain of size \(p\in[v,2v)\), put \(b=p/\ell\). Recall two properties of this common layout. The total weighted score over all levels and all ordered block pairs containing a representative in their union is at most \(16E\). The weight \(A_j\) on representatives wholly in one level-\(j\) block satisfies \(A_j\le4E/b^2\), since \(b A_j\le P_j\le4E/b\). Thus the total number of independent sets of size at least three lying wholly inside one block at level \(j\) is also at most \(A_j\). Each such set contains its representative and belongs to a unique block.

To obtain the weights, construct the length-\(v\) packed missing-link vector \(M_{a,b}\) for each pair in \(O(v^3+1)\) steps. Enumerate independent sets by cardinality, with a set identified by its prefix and its largest member. For every existing independent \(S=P\cup\{s\}\) with \(s=\max S\), store the packed eligible extension set \(D(S)\) and
\[
               L(P,s)=\bigcap_{y\in P} M_{y,s}.
\]
The empty intersection consists of all positions. Index the latter vectors at the current cardinality by \((\mathrm{ID}(P),s)\). For an admissible next vertex \(x\in D(S)\), its sibling \(P\cup\{x\}\) is independent and has the **same cardinality** as \(S\). Its stored vector \(L(P,x)\) is already available. Consequently only two packed intersections are needed:
\[
 L(S,x)=L(P,x)\cap M_{s,x},\qquad
 D(S\cup\{x\})=D(S)\cap L(S,x)\cap\{z:z>x\}.
\]
Use the direct initial formula for \(S=\varnothing\). Each node generates just its own larger admissible children. Iterate its packed set in \(O(1+v/w_0+\#\mathrm{children})\) operations, for example with a small lookup table for locating the lowest one bit in chunks of \(\lfloor w_0/2\rfloor\) bits. A deterministic sorted predecessor table or balanced dictionary costs \(O(\log(J+2))=O_C(w_0)\) per child, absorbed in \(O(1+v/w_0)\). The first three indices retained in each node suffice to add its representative weight. Stop before the given cap on \(J\) is exceeded if testing the promise. The preprocessing costs \(O_C(1+v^3+Jv/w_0)\), including the \(O((v+E)\log(v+2))\) balanced partition.

## Variables whose two values survive the old pairs

Process the chosen order in aligned chunks \(I\) of power-of-two width \(q=\Theta(w_0)\), with \(q\le w_0/4\) for sufficiently large \(v\). The padded dummy variables are fixed to zero. Let \(O\) be the earlier real variables at the beginning of a chunk, and let \(S_O\) be all satisfying assignments on the induced old instance. For every old row, the [complete-case packed rectangle](complete-csp-in-linear-dimacs-time.md) computes a pair of \(q\)-bit masks giving every ban on a new bit caused by two old coordinates. The hereditary shattering and balanced-layout bound give \(O(v^2\log(v+2)+E+qv^2)\) native steps per chunk, including all unit-leaf probes. A missing support supplies no ban. Dummies contribute the fixed ban on one.

For \(j\in I\) real, let \(X_j\) consist of old solutions for which **both** values at \(j\) survive all these old-pair constraints. If \(A\subseteq O\) is shattered by \(X_j\), then \(A\cup\{j\}\) is independent in \(H\). A present support within \(A\) already excludes an old signing. A present support \(\{a,b,j\}\) with \(a,b\in A\) has a forbidden pair of old values coupled to one forbidden value of \(j\). Shattering \(A\) would realize that pair in an old row from \(X_j\), contradicting availability of both values. Applying the strong Sauer inequality \(|X_j|\le|\operatorname{Sh}(X_j)|\) yields
\[
 |X_j|\le \#\{A\subseteq O:A\cup\{j\}\in\mathrm{Ind}(H)\}.
\]
For brevity let \(C_I\) be the sum of these *right-hand sides* for real \(j\in I\). Over all chunks, \(\sum_I C_I\le J\): every counted nonempty independent set has the unique largest variable \(j\) in the chosen layout. Thus in the entire computation at most \(J\) old-row/next-variable pairs are ambiguous in this old-pair test. This is specific to SAT/CSP constraints on triples.

Call a chunk good if every triple of its real coordinates is a present support. There are at most \(4E q^2/p^2\) bad chunks, since each contains a distinct missing triple that is itself one of the charged independent sets inside a single block at this level. There are only \(O_C(w_0^4)\) bad chunks on our promise. Process each using the preceding ordinary single-stage rectangle solver in \(O_C(qJ\log(v+2))\) steps, including persistent path updates. The total cost of these fallback chunks is \(O_C(v^2\operatorname{polylog}(v+2))=O_C(1+v^3)\).

For each good chunk enumerate all \(2^q\) local strings, discard those violating an internal clause or a dummy, and record both the list and a membership array. There are \(O(q^2+1)\) local models by the projection bound for a complete triple instance. Even naive local verification in \(O(2^q q^3)\) steps per block fits in the global cubic budget. For an old row with any doubly forbidden position emit no candidate. If all remaining positions are forced, extract the unique \(q\)-bit string and test its local membership in constant time. For a row with some ambiguous position scan the local list and test each word against the two ban masks. The expensive scans cost \(O(J q^2)\) over the **entire** run. Mask extraction takes constant native work per row, even when the old-pair flags were stored interleaved: a deterministic deinterleaving table of \(4^q\) entries fits the initialization budget. The resulting tentative family \(Y_I\) satisfies all constraints on three old variables, two old plus one new, and three new variables. Only the constraints on one old and two new variables remain.

## Testing one old and two new coordinates together

For each tentative pair \((x,y)\), where \(x\) is an old root and \(y\) its packed local word, compute the OR of its violated one-old/two-new constraints. Start with one old axis covering the full \(p\)-domain and two new axes covering \(I\). Descend only on the old axis until its width is \(q\); then halve all three axes together. Only use old positions in \(O\), strictly ordered distinct real new positions, and present clause masks when checking a leaf. Old-axis patterns use canonical nodes; new-axis patterns are simply substrings of the same word \(y\). Batch the exact states of all tentative pairs with the same fixed-width radix sort and scatter links as for complete CSPs. This construction tests the correct native predicates even though some tentative rows violate this final group of clauses.

Here is the state count needed precisely for those tentative rows. A shattered set in a projection across the three current intervals has old part \(A\) and new part \(B\). The new part has size at most two by internal completeness. The old part is independent. For every \(j\in B\), the set \(A\cup\{j\}\) is independent as well: all old-old-new clauses were enforced on every tentative pair, so a shattered set cannot contain their three coordinates. A given pattern on the union uniquely determines all component node identifiers and substring codes at their fixed locations. Strong Sauer thus charges each possible state to a permissible shattered subset.

* If \(B=\varnothing\) and \(|A|\le2\), the coarse levels \(\ell\ge q\) cost \(O((p/\ell)(1+\ell^2))\) each, or \(O(v^2)\) together. On finer levels there are \((p/\ell)(q/\ell)^2\) location tuples; multiplying by \(O(\ell^2)\) charges \(O(vq^2)\) together over all dyadic \(\ell<q\).
* If \(B=\varnothing\) and \(|A|\ge3\), the coarse levels contribute at most \(\sum_j A_j=O(E)\) per chunk. At a fine level each old block is used by \((q/\ell)^2\) ordered new-block pairs; the count for all old blocks is at most \(A_j\le4E(\ell/p)^2\). Summed over the fine levels this costs \(O(E(q/p)^2\log(q+2))=O(E)\) per chunk.
* If \(A=\varnothing\) and \(B\ne\varnothing\), the coarse levels cost at most \(O(\sum_{\ell\ge q}(p/\ell)q^2)=O(vq)\). At fine levels each new-interval union has at most \(O(\ell^2)\) subsets of size at most two. Across the same tuple counts as above the total is \(O(vq^2)\).
* If \(A,B\) are both nonempty, choose the least \(j\in B\), along with the possible other new variable or a null marker. There are at most \((q+1)C_I\) such \((A,B)\) pairs in this chunk. At each level, nonempty \(A\) lies inside at most one old interval. The new locations are fixed on the coarse levels. On a fine level, at most \(2q/\ell\) ordered new block pairs contain the chosen \(j\) in their union. These multiplicities sum to \(O(\log(v+2)+q)\). This last charge over the **whole run** is \(O(Jq(\log(v+2)+q))\).

It follows that every good chunk costs \(O(v^2+E+vq^2)\) mixed states, plus the displayed global charge. At most eight child records are emitted per state. Radix bases of order \(\sqrt v\) keep the sum of counter initialization costs below the displayed bounds. The \(O(v/q+1)\) chunk starts, mixed checks and root scans cost \(O_C(v^3+vE/w_0)\) altogether. Indeed \(J\operatorname{polylog}(v+2)=O_C(v^3+1)\) on the stated promise. Reject each tentative pair with a mixed violation; the surviving pairs are exactly the next prefix solutions.

## Persistent update and packed output

Install one entire chunk at a time. Each ancestor state on the one path of this chunk is keyed by the old ancestor identifier and the new chunk word. The updated bit pattern locally determines both: zero the chunk to recover the previous old pattern. Starting from all accepted roots, radix-group distinct states, project each to its one child along the path, and store the unaffected sibling pointer. Work back up from the pretabulated chunk nodes, using one fresh identifier per distinct nonzero update and reusing original identifiers for zero updates. A particular ancestor sees only completely satisfying next-prefix rows. At a width-\(\ell\) ancestor at most \(O(\ell^2)+A_j\) distinct patterns can occur by the independent-set bound. Summing along the ancestry gives \(O(v^2+E)\) records per installation. The algorithm never scans the whole path separately for each output row.

For each resulting full model traverse just down to the \(q\)-bit chunk nodes, whose stored identifiers give the actual bit word by indexed lookup. This takes \(O(1+v/q)\) steps per model. To omit dummy gaps, a precomputed table on two \(q\)-bit words compacts the real positions selected by the chunk's fixed mask, and emits their count for packing consecutive chunks together. It uses \(O(q4^q)\) initialization work. Give the dictionary in the chosen real-variable order. Thus reporting all \(\le J\) assignments fits in \(O_C(v^3+vE/w_0)\) word operations. This representation writes each complete assignment as an ordinary packed vector; its meaning is independent of the internal prefix trees.

Under the initial promise \(E=O_C(v^2\log^2 v)=o(v^3)\), all but lower-order many supports are present and \(N=\Omega_C(v^3\log(v+2))\) as in the [missing-support proof](linear-time-sat-with-missing-clause-triples.md). If recognizing the promise, reject insufficiently many distinct supports before allocating the cubic table, and abort the published preprocessing at its node cap. For padded files use the monotonicity of \(N/\log(N+2)\) to justify the packed bound. [Packed fixed-arity parser](packed-normalization-of-dimacs-clauses.md)
