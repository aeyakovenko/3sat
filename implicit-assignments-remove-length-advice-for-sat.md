# Removing length advice for SAT by searching for one false clause

Suppose a fixed deterministic word-RAM takes an explicit proper 3-SAT file and an advice string. On each sufficiently large physical length at least one string gives the correct verdict throughout that length. Different lengths may use unrelated strings. If all rows have a known quasilinear clock and use at most $O(\log\log N)$ bits of advice, **one deterministic RAM decides the same SAT problem in quasilinear time without advice**. In particular, whether an arbitrary fixed collection of quasilinear-time RAM measurements suffices to determine SAT up to a different decoding table at every length is equivalent to ordinary uniform quasilinear-time decidability, for a fixed finite measurement alphabet.

More quantitatively, for a constructible clock $t(N)=N^{c+o(1)}$, $c\ge1$, and a known constructible $o(\log N)$ cap on the advice length, the uniform bound is $N^{c^3+o(1)}$. A clock $N^c\log^{O(1)}N$ and $O(\log\log N)$ bits give $N^{c^3}\log^{O(1)}N$. The order of the three physical SAT query lengths matters. The proof never prints a whole assignment computed by the advised algorithm.

## The three lengths

Write $K(u)$ for the size of the explicitly enumerable advice menu on length $u$. Time out every trial row at its declared deadline and give it a fixed Boolean default. Normalize variable names in the input $F$ on $N$ bits to the $v\le N$ distinct occurring names. Assignments and their lexicographic order refer to these names, so unused names in a large decimal header do not contribute coordinates. A formula with no clauses can be accepted immediately.

1. **Select the least model.** For a proposed $v$-bit word $x$, build a proper SAT file $C(F,x)$ asking if there is a model $y$ of $F$ with $y<x$. Intern names by a decimal trie, append a linear-gate comparator, and encode the constant-fanin gates. Simplify repeated literals, discard tautologies and expand shorter clauses on fresh padding variables in all sign combinations. The direct physical construction uses at most $N\log^{O(1)}N$ time and bits, including decimal names. Pad by spaces to a common constructible byte length $S=S(N)$ of this order, independent of $x$. In the bound calculations all lengths refer to bits at those byte boundaries. For each trial advice $h$ at $S$ use the predicate
   $$R_h(x)=[x\text{ satisfies }F]\land[h(C(F,x))=\mathrm{NO}].$$
   If $F$ is satisfiable and $h$ is correct at $S$, exactly one $x$ passes, its least model. The test only executes the named row. It makes no assertion of its soundness. On an unsatisfiable $F$ no $x$ passes for any $h$.

2. **Give an assignment implicitly.** For each coordinate $i$ form the proper file $B(F,h,i)$ for the nondeterministic computation guessing $x$ and checking $R_h(x)$ and $x_i=1$. The physical clock covers building $C$ and running the advised machine. Pad every such file for this source length to $M=\widetilde O(t(S)+S)$. For each trial advice $g$ at $M$ let $a_{h,g}(i)$ be the Boolean answer of $g$ on that file. This defines a consistent total assignment for *every* $h,g$. When $F$ is satisfiable, some pair defines its least model. Reading a single coordinate costs $\widetilde O(M+t(M))$ time, including constructing the file. No uniqueness of auxiliary encodings or transcripts in $B$ is required.

3. **Check a short witness against the implicit assignment.** For fixed $F,h,g$, a proposed index $j$ is a valid counterexample if it is in range and clause $j$ is false under $a_{h,g}$. A verifier obtains the three variable indices and signs from $F$ and uses at most three coordinate computations from step 2. It spends $\widetilde O(t(M)+M)$ time. Let $d=\lceil\log_2(m+1)\rceil$ for $m$ clauses indexed from zero. For a prefix $p$ of a $d$-bit index, compile the existential question whether $p$ has a valid completion. Use the common physical length $L=\widetilde O(t(M)+M)$ for all prefixes, inputs of this source length and trial parameters. For every candidate advice $k$ at $L$, start with the empty prefix. At each level query whether the left child has a valid completion. Take it on YES and take the right child otherwise. At depth $d$ check the resulting index with the actual deterministic verifier.

A valid returned index certifies failure of this particular assignment, whoever supplied the bits. If a bad clause exists, the correct $k$ at $L$ follows prefixes with a valid completion and must find one. Thus if every trial fails to return a valid index, the assignment satisfies all clauses. Accept if any $(h,g)$ survives this test. For satisfiable $F$ the two correct rows in steps 1 and 2 give a surviving pair. For unsatisfiable $F$ every pair yields a real false clause. The hypothesis concerns all sufficiently large lengths and the proof uses it at three enlarged lengths. A promise of correctness on an arbitrary infinite set of lengths does not suffice.

## Time and implications for exhaustion

For a fixed standard logarithmic-word instruction set, a bounded nondeterministic computation of time $u$ here has a proper SAT compilation using $u\log^{O(1)}u$ bits and physical generation time. One construction guesses register and memory events, sorts the latter by address and timestamp using a uniform sorting network, and verifies initial values, successive writes, and each local instruction. Polynomial-size-in-word-width Boolean checks suffice for the standard arithmetic operations. Starting from a sequential bank of explicit source bits and adding input initialization fits the same bound. Gate constraints use a constant number of proper ternary clauses per gate and logarithmic-size printed names. Subsimulations mask guest word widths, start with fresh zero memory and leave polynomial address space for their host. This is the quasilinear SAT-completeness ingredient. [Fortnow, Lipton, van Melkebeek and Viglas](https://lance.fortnow.com/papers/files/tst.pdf)

With nondecreasing effective clock and menu envelopes, a bound including complete production of queries is
$$O\!\left(K(S)K(M)K(L)(d+1)\,[t(L)+L]\log^{O(1)}(L+2)\right).$$
Use common computable upper envelopes for output lengths, aligned to bytes and chosen to dominate the input length, time to write the query, and cost of supplying trial advice. If $K(u)\le u^{a+o(1)}$ and $t(u)\le u^{c+o(1)}$ for such envelopes, the exponent is at most $c^3+a(1+c+c^2)+o(1)$. Bounded advice strings of variable length can be tried in length-lexicographic order up to the known cap. For the quasilinear assertion $K$ is polylogarithmic and every one of the fixed number of compositions stays quasilinear. If an $o(\log N)$ advice allowance has no specified effective sublogarithmic envelope, each fixed $\varepsilon>0$ still gives an individually uniform $N^{c^3+\varepsilon}$ upper bound by trying advice up to a sufficiently small fixed multiple of $\log N$ and absorbing the finitely many exceptional lengths.

Consequently, if one rules out uniform quadratic time, then for each fixed $c<\sqrt[3]{2}$, $c\ge1$, every fixed finite roster of $N^{c+o(1)}$-time trit measurements has arbitrarily large proper lengths with opposite-verdict inputs sharing the entire signature. Otherwise trial advice could specify the full decoding table. This gives an implication from a still-unproved clock exclusion. For a fixed roster of globally correct deciders, any timely answer is honest, so the readings reduce to YES, NO and all-timeout. For three signatures the length-only calibration construction gives a sharper $c^2$ exponent. For larger $c$ the previous method costing one clock per variable can also be cheaper. A solver that already decides SAT uniformly supplies its own two-valued measurement, so the new argument does not exhibit the required hard pair against that solver. ## A cheaper deterministic test when a file has few models

If all yes-inputs in a promise have at most $B(N)$ assignments on the occurring names, and $B$ is a known polylogarithmic bound, two levels suffice. The advice premise still concerns ordinary unrestricted SAT on all the query lengths. For each $1\le j\le B(N)$, an existential coordinate file guesses $j$ strictly increasing models, verifies every one on $F$, and requires bit $i$ of the first model to be one. Its size and physical construction time are $\widetilde O(NB(N))$. When $j$ equals the true positive number of models, their ordered list is forced. A correct advice row at the common coordinate length then gives a genuine assignment. For every other trial the bits still describe an ordinary assignment. Search for a false clause exactly as in step 3. An unsatisfiable input always rejects and a satisfiable input with at most $B(N)$ models always accepts. With $t(u)=u^c\log^{O(1)}u$ and $O(\log\log u)$ advice bits this takes $N^{c^2}\log^{O(1)}N$ deterministically. With $B=1$ the coordinate queries simply add one proposed bit to $F$. A satisfying assignment found on an input outside the promise also gives a valid acceptance.

## Why explicitly checkable clauses matter

There is an exact obstruction to replacing the clause test by black-box validation of a whole witness. Fix a hidden $v$-bit word $s$ and a hidden bit $b$. A raw probe to $(i,z)$ returns one precisely at $(b,s)$. The question is whether side 1 contains a witness. Allow arbitrarily powerful auxiliary Boolean decision queries about the table, giving the algorithm both answers, in known order for the two counterfactual worlds $(0,s)$ and $(1,s)$. These are four possible reports. In the true world the unknown decoder is just projection onto coordinate $b$. Auxiliary queries may be adaptive and can include any Boolean predicate of the entire marked table.

With at most $q$ auxiliary reports and at most $D\ge1$ raw probes, this black-box task is deterministically solvable for all $(s,b)$ exactly when
$$D\,4^q\ \ge\ 2^v.$$
On the branch where every raw probe returns zero, a transcript of $q$ reports fixes at most $D$ candidate raw addresses, projecting away the side. There are at most $4^q$ padded report transcripts. If some $s$ is absent from their union, both worlds at that $s$ follow identical actual paths and produce the same answer. Conversely, in one query use the side of the unique marker to select which of two successive bits of its address to return. The ordered pair reveals both bits of $s$. After $q$ such queries, test the remaining candidate addresses on side 1. Zero padding handles odd $v$. For independent uniform $(s,b)$ the same zero-transcript count bounds randomized success by $1/2+D4^q/2^{v+1}$, averaged over the internal coins. Under this uniform distribution the sharp success probability is $\min(1,1/2+D4^q/2^{v+1})$: learn the first $2q$ bits where present, probe up to $D$ different addresses of the residual set on side 1, and default to side 0. This is a query result for this specified protocol and does not relativize the physical SAT theorem. In a proper CNF the counterexample to an implicit assignment is addressable in $O(\log N)$ bits even when a complete assignment has far more bits.

## Relation to prior work and verification

Karp and Lipton already removed logarithmic advice for polynomial-time SAT via self-reduction. Fortnow, Santhanam and Trevisan give a quantitative advice-removal lemma for their optimal randomized 3SAT search algorithm, using full assignments and a quadratic validation term. [Karp and Lipton, §5](https://doi.org/10.5169/seals-52237) · [Fortnow, Santhanam and Trevisan, Lemma 14](https://cs.stanford.edu/people/trevisan/pubs/promise.pdf#page=6)

The cost at issue here is a full-length query for each variable. The easy-witness literature also uses succinct assignments and the fact that one violated local constraint disproves a candidate. Naik, Regan and Sivakumar study the cost of *outputting* witnesses using decision queries. Here the long assignment stays implicit, while the witness actually retrieved has only a logarithmic number of bits. The exponent accounting for this explicit SAT encoding is a research-journal claim. Priority is unestablished. [Murray and Williams, *Circuit Lower Bounds for Nondeterministic Quasi-Polytime via Easy Witness Lemmas*](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf) · [Naik, Regan and Sivakumar, §4](https://cse.buffalo.edu/~regan/papers/pdf/NRS95.pdf)

The Lean proof checks the least-model filter, the actual binary descent under a truthful prefix reader, direct validation under any reader, and correctness of searching the candidate assignments for a survivor. The finite audit evaluates every subset of the eight clauses on a fixed proper triple, varying the potentially incorrect reads independently at the three stages. It also checks the constructive black-box upper bound for all hidden words through seven bits. The uniform RAM compiler, advice enumeration costs, and asymptotic bounds are proved in the text.
