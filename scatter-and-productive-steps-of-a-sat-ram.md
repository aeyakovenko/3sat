# A SAT RAM must deliver a value with large local support

Fix one of the sparse hard pairs of 3-SAT incidence structures. Write $v$ for the number of source variables and $D=\Theta(v)$ for the number of domain points, including clauses. The two structures have opposite verdicts and agree in counting logic with $k=\Omega(v)$ variables. Permuting all $D$ names and serializing gives proper DIMACS files of $N=\Theta(v\log v)$ bits. A physical input word on any one labeling is determined by the types and port incidences on at most $p=O(1)$ actual names. We may preload these words at known addresses for free. A **local support** of a record at a labeled input $X$ is a set of names whose pointwise stabilizer preserves the record's numerical value at $X$. It is chosen separately at each input. [Sparse encoding and hard-pair construction](name-support-of-a-native-ram-word.md) · [Atserias–Dawar–Ochremiak, Theorem 3](https://arxiv.org/pdf/1901.07825#page=29)

**Delivered-value theorem.** For any total deterministic SAT RAM with a bounded number of word operands and memory accesses per instruction, there is a labeling from the pair on which an actual instruction issues an address, transfers a datum, uses or produces a scalar, or makes a control decision whose numerical equality to its actual value has minimum local support $\Omega(v)$. Scalar observations include operand and result words of a copy. The statement concerns actual instruction activity. A value merely sitting in an unaccessed work cell is insufficient to witness it. No bound on the elapsed time, workspace, or time since the last write is imposed.

## Comparing actual transfers without observing passive memory

Use a finite sequence of stages at the given input size. Totality gives a finite maximum time on all labelings of the pair. Give halts an absorbing verdict. Split each instruction into a fixed bounded number of stages, ordering multiple stores and loads as the instruction specifies. The program counter and scalar transitions have their usual numerical values. A memory read exposes its request and a record consisting of its request together with the returned word. A store records its address and datum. Unused slots receive an inactive tag. Registers can themselves be regarded as storage at fixed addresses, with their operand reads and writes exposed only when performed. All work cells begin with public values except for the specified raw input preload. The model allows ordinary bounded-arity word operations on delivered operands.

For each ordinary scalar or issued-request record, equality to a particular value is the OR of conjunctions of at most $b$ earlier scalar or delivered-record equalities. Enumerate the instruction and its bounded tuple of operand values to obtain the conjunctions. The number of alternatives is unrestricted. The constant $b$ depends on the machine. A load returning a word from mutable storage is handled separately below. No event for the accumulated contents of a passive work cell appears in this list.

Suppose all exposed records, including their tags, have local supports of size at most $h$ everywhere on the pair. A tuple of constantly many exposed fields with individual supports of size $h_0$ has a support of size $O(h_0)$, by taking their union. Allow $h\ge p$ to absorb raw initial-cell supports. A winning partial correspondence in the ordinary $k$-pebble game can be extended from either side to a new name while a free pebble remains. Restricting such a correspondence and transporting it by bijections of the labeled domains both preserve its winning status. The counting-equivalent hard pair supplies the empty winning position. [Counting equivalence and pebble games](https://www.cs.upc.edu/~atserias/papers/definable-inapproximability/definable-inapproximability.pdf)

Induct over all exposed records. The induction assertion for record $f$ is that $f(X)=f(Y)$ whenever $X,Y$ come from opposite orbits and the identity on chosen local supports $S_X\cup S_Y$ is winning. Here and below the supports in the assertion have size at most $h$. At the input base, extend the winning correspondence from $X$ over the at most $p$ names determining that initial word. Relabel $Y$, keeping $S_X\cup S_Y$ fixed, until the map on these names is the identity. Partial isomorphism now gives the same physical word. Fixing $S_Y$ preserves its original value.

For an ordinary record, take a conjunction true on $X$ for its actual value. Extend the winning correspondence over local supports on $X$ of these earlier records, then relabel $Y$ so the extended correspondence is the identity. On the resulting $Y'$, choose supports of the *same physical earlier records*, extend in reverse over those supports, and relabel $X$ to make the correspondence the identity everywhere held. Call the result $X'$. Every relabeling here fixes the parent supports. The second relabeling fixes every chosen earlier support on $X$, so its earlier value and support both persist on $X'$. Forgetting to the two supports of each earlier record allows the inductive assertion to be used separately for each. The conjunction is now true on $Y'$ as well. This also proves a transport rule used below: with any pebbled parent supports kept fixed, one may align the values of one selected earlier record across the two sides, and thereafter forget the transient pebbles.

Consider a load record at stage $t$ whose values differ across the two sides. Keep the local supports of both complete load records pebbled throughout. Apply the transport rule first to the earlier issued request. The request is a field of the pinned load record, so differing requests would contradict that comparison. An inactive request has a fixed empty response. Thus the only remaining case has a common active address $a$ with two distinct pinned returned data.

On one side take the last write to $a$ before this read. Let its time be $s<t$ and its datum $d$, the pinned return on this side. If there was no write, use a virtual stage before the run recording the initial word at $a$. Apply the transport rule to this particular earlier store record or initial word. After relabeling, both sides wrote $d$ to $a$ at stage $s$, or both had initial value $d$ in the virtual case. The other side still returns its pinned value different from $d$. Its *current* execution must therefore have an actual, strictly later write to $a$ before $t$. Forget the earlier-record pebbles and switch to that side with its last write. The pinned load supports persist as local supports under the relabelings fixing them. This repeats with a strictly increasing sequence of write times below $t$, which is impossible. Relabeling can change either history beyond the pebbled names. The only information carried from one round to the next is the pinned discrepancy and the new lower bound on the last-write time.

At most $2h+p$ names are needed for the base and $(2+2\max(b,1))h$ for a transport or ordinary step. The load proof reuses the same pebbles independently of the number of earlier writes. Lean verifies the increasing-last-write argument, the preload case, and its use of aligned earlier records in the partial game. [Lean proof](AlternatingLastWrite.lean) The final invariant verdict has the empty local support on each orbit and differs across them. The empty position therefore contradicts the induction for $h$ a sufficiently small positive constant times $v$. At least one record, and hence at least one field of a record of fixed arity, has the asserted local lower bound.

If a high-support observation on the witness input is an inactive microstage, freezing the actual instruction and the boundedly many control or guard fields deciding its inactivity also freezes that observation. Hence an actual control or guard field already has large local support. At a stage after a genuine halt, freezing the halt-state counter at the actual halting time freezes all subsequent inactive observations and its verdict (include the halt-value field if stored separately). This moves any such witness to the actual halt. Constant or fixed physical input fields can account for at most $p$ names. The theorem permits a transferred word's value to have been assembled entirely by earlier routing choices.

## Cost after input loading and direct copies are free

There is a distinct operation-count consequence on **every labeling of both structures**. Give the machine unbounded free copying, fan-out and unary word transformations at publicly specified addresses. The free operations may use constants and arbitrary preprocessing depending only on the input length. They may also be scheduled using the transcript already exposed by charged operations. Charge a bounded-arity step that combines independent data words or uses data to choose a branch or a memory address. A data-dependent store destination incurs a charge even when all it does is deposit a constant. A publicly specified store of a copied or unary-transformed word is free. The model requires that a free stage's schedule, its addressing, and its unary functions be fixed by public information and the previously exposed transcript.

An execution with $q$ charged steps is simulated, regardless of its number of free operations, by an adaptive procedure probing at most $O(q+1)$ raw input words. Condition on the exposed transcript. Every current storage location is represented by a known constant or by a known unary function of one designated raw input word. This holds initially under free input loading. Fixed-address copying, fan-out and composition with free unary functions preserve this representation. When a charged step occurs, evaluate its bounded tuple of data and addressing operands with at most one raw probe for each. If it accesses storage, the addresses now known determine which other operands must be evaluated; a bounded list of sequential accesses uses only a bounded number of further probes. Its branch and computed writes are then known. Update the affected symbolic locations, leaving other locations as before. Evaluate the final answer using at most one more probe. This simulation can use arbitrarily expensive public bookkeeping.

Every labeling of each hard structure requires $\Omega(v)$ distinct raw probes, so the charged-step count is $\Omega(v)=\Omega(N/\log N)$ on every such input. Under equal mixing of the two uniform labeling distributions, a randomized solver with fixed positive advantage has the same lower bound in expectation by applying the probe simulation after fixing its coins. This counts work that remains when moving and inspecting a single data source at a predetermined location costs nothing. It reaches a linear bound in the number of packed input words. ## Why data-dependent routing matters

A fixed deterministic RAM can decide SAT with all of its nontrivial arithmetic, branch conditions and issued addresses having constant local support on the sparse encoding if unrestricted time is available. For input length $N$, evaluate the complete Shannon decision tree on the $N$ raw input bits in a depth-first traversal that visits **both** children at every node. At a leaf compute SAT on the public candidate string given by the path. Leaf computations and traversal times depend on the length and candidate, independently of the actual input. A polynomial-space SAT decider suffices for these leaf computations. The stack needs polynomially many logarithmic-width words.

At an internal node of depth $i$, load raw input bit $i$. Use its value as a one-bit offset into the two slots containing the child answers, then copy the selected answer into the parent slot. Implement this selection with a fixed sequence of instructions, so its duration is independent of the raw bit and the transported answer. All numerical addresses and selection arithmetic are then public or functions of a single raw physical word. That word has constant local support on the serialized family. Intermediate transported answers can have large support, but they are never used to choose a route, a branch, or an arithmetic result. At the root the final verdict is invariant under relabeling. This construction uses exponential time and makes a large number of data-dependent selections. It demonstrates why the delivered-value conclusion includes copies and why the operation lower bound charges those selections. On a specific explicit counting-width hard pair, a second implementation keeps arithmetic and addresses locally supported even within $O(N)$ native time.
