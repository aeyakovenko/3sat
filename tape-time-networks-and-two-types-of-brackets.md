# The tape simulation exponent is the exponent for two types of brackets

Fix a finite field $F$ and use its exact binary-wire trivalent tensor networks. For an integer $u$ let $D_F(u)$ be the maximum, over token lengths $m\le u$, of the minimum volume for membership in $\mathrm{Dyck}_2$ at length $m$. Each supplied token has two bits, one for open/close and one for bracket type. A closing bracket must match the opener at the top of the stack in type. Underflow and a nonempty final stack both reject. Networks may be chosen separately at each length.

**Tape simulation.** For every fixed deterministic finite-alphabet multitape Turing machine running in time $T$ on $n$ input bits, its acceptance predicate has an exact network of volume
$$
 O_M\!\left(n+T+D_F(C_M(n+T+1))\right).
$$
Conversely, a fixed deterministic multitape machine decides $\mathrm{Dyck}_2$ in linear time. Consequently for every $a\ge0$ the universal $O_M(u(\log(u+2))^a)$ exact-network simulation bound for multitape time, $u=n+T$, holds **if and only if** that bound holds for $D_F(u)$. This identifies the exact exponent question with a single named language. Its numerical optimum remains unknown here. A bounded-fan-in Boolean circuit upper bound for the language is sufficient for the forward implication. An arbitrary network upper bound yields the stated exact-network simulation. Pippenger–Fischer gives $a=1$ through Boolean circuits. Book and Greibach's characterization of quasirealtime languages through intersections of context-free languages is a close precedent. The count-preserving property is needed here in finite characteristic. ## Checking just one padded tape run

Use two finite stacks per tape, holding the cells strictly to the left and strictly to the right of the head, nearest cell on top. Keep the current symbol with the control. A write followed by a right move pushes the written symbol on the left, pops the right stack and sets the current symbol to the popped value. A left move interchanges the sides. A stationary write replaces only the current symbol. Push $T+1$ blanks on each stack at initialization, followed on the input tape's right stack by the remaining input in reverse order. The initial current symbol is the first input symbol, or blank on an empty tape. There are enough blanks for every movement. Two-way infinite tapes suffice; an endmarker can be included in the finite alphabet for a one-way convention.

Guess one constant-size record per clock tick, with the state, current symbols, instruction and landing symbols, and check adjacent records by constant-size Boolean gates. Require unused fields to have a prescribed value. A halt has one canonical padded continuation and retains its verdict. Project the rows onto each stack's push/pop/idle actions. The directions and types of these actions are determined by each local record. Only the real deterministic run can give a valid sequence on every stack: inductively each pop reads the unique stored symbol and every other field follows from the transition rule. The real run always produces these sequences.

After the $T$ rows, a stack has at most $n+2T+1$ symbols. Give each stack that many cleanup slots. The only allowed cleanup is zero or more pops followed by idle slots. Test that regular format with linear overhead. Requiring a balanced result determines the number of pops and their exact types. Each stack has its own projection and ordered cleanup; no ordering of independent pops is guessed. With the canonical halt padding this gives precisely one complete valid auxiliary assignment if the machine accepts, zero if it rejects. [Lean cleanup and coding proof](CanonicalDyckCompletion.lean)

To check each projection with ordinary binary typed brackets, choose a constant, even code length $d$ sufficient for one stack symbol. Encode a push by $d$ opens of its binary code types and a pop by the $d$ matching closes in reverse order. Encode an idle by $d/2$ copies of a fixed matched pair. At every block boundary the stack holds whole symbol codes. The transformed word is in $\mathrm{Dyck}_2$ exactly when the typed action string starts and finishes empty without a failed pop. Initialization, actual ticks and cleanup give a fixed token length $O_M(n+T+1)$ regardless of the input and the guesses. Take one Dyck network per stack, combine it with the finite checks, pin the verdict and sum over the record and cleanup bits. Copy vertices, gates and interface bits outside the constant number of Dyck networks cost $O_M(n+T+1)$. Each stack predicate contributes its exact zero or one even if it was itself implemented by a contraction with cancellations. The outer sum is therefore the acceptance bit in every characteristic. In the reverse direction, a work tape with its head at the top of a stack implements the ordinary Dyck scan in constant time per token. [Exhaustion of genuine and forged logs](tape_dyck_history_audit.py)

For SAT this needs an upper bound for $D_F$ below the list theorem's loss. Use a putative linear-time tape solver with its *UNSAT* verdict selected. Compose its network with the fixed-layout SAT projection of the list. The resulting scalar is exactly list distinctness, using $O(n)$ extra pins, complements and copies on a list with $n$ input bits. Thus $D_F(u)=o(u(\log u)^\sigma)$ would exclude linear deterministic multitape time for this SAT encoding, where $\sigma$ is the list exponent for the same field. A subpower-logarithmic overhead would suffice without knowing the numerical $\sigma$. An $O(u\log u)$ simulation falls short. Standard RAM addresses can jump to arbitrary cells and have no bounded pair of adjacent tape stacks per step. ## Two consecutive mountains already test a cyclic shift

Number $2m$ token positions from zero. Fix the opening/closing directions to
$$
 +^k -^k +^{m-k} -^{m-k},\qquad 0\le k<m .
$$
Call each balanced run of opens followed by closes a mountain. Put the independent type bit $x_i$ at even position $2i$ and the independent bit $y_j$ at odd position $2j+1$. In the first mountain, matching reflects positions about their center and paired indices sum to $2k-1$. In the second they sum to $2m+2k-1$. Hence for all $i$ the bit $x_i$ must equal $y_{(k-1-i)\bmod m}$. These $m$ equalities are sufficient as well. On reversing the indexing in one bank, this is the exact graph of a cyclic shift. No data bit is copied in this restriction. As $k$ varies, each input bit has every output bit as its destination exactly once. [Lean pairing and unique-offset proof](TwoMountainPairing.lean)

In the other direction, given a word promised to have this shape, get $k$ from the end of its initial opening run; a single mountain gives the same reflection with $k=m$ or zero. A linear-size Boolean circuit computes the first transition as a one-hot vector by prefix conjunctions. Convert a one-hot vector of $O(m)$ bits to binary by a binary tree, emitting the selected index at each node in $O(j)$ gates at height $j$. The total cost is $O(m)$. From a supplied binary $k$, conversely decode all its thresholds in $O(m)$ gates by a decoder tree and prefix ORs. The three changes of direction occur at $k,2k,m+k$, so all promised directions can be generated or verified in $O(m)$ additional gates. For powers of two, modular changes of shift convention also use $O(\log m)$ gates. Thus the exact-network size of the two-mountain membership predicate, with arbitrary behavior allowed outside the promise, agrees with the size of the cyclic-shift **graph predicate** up to $O(m)$ in both directions. Checking the shape makes the same true for the total language rejecting other shapes. The circuit version of this equivalence is likewise between two scalar decision predicates. A circuit that generates the shifted output string has a different interface. [Afshani, Freksen, Kamma and Larsen on the output shift problem](https://doi.org/10.4230/LIPIcs.ICALP.2019.10)

In any field *without ports* in the sense of the matrix preprint, its uniform-destinations lemma gives $\Omega(m\sqrt{\log m})$ network volume on these two-mountain instances alone. Use the same topology of a purported verifier for every $k$, pin the directions and view the odd legs as outputs. It realizes the independent wires of every reflected shift. Each even leg has $m$ equiprobable destinations. The $O(m)$ pins can be absorbed in the lower bound. Consequently a universal tape simulation with logarithmic overhead exponent below $1/2$ is impossible over such a field, and even $o(\sqrt{\log n})$ overhead is impossible there. In particular it cannot beat a list exponent $\sigma\le1/2$ in that field. This is conditional on the stated property of the field. The preprint proves the full list theorem with a separate argument for fields with ports, which does not establish this rotation bound there. Even token lengths are the relevant lengths, since odd ones always reject. With one bracket type the whole language has $O(m)$ Boolean gates. A block summary is its total signed excess of opens and its minimum prefix excess including the empty prefix. Merge summaries by addition and a minimum after offsetting the right block. At height $j$ of a balanced tree, each summary has $O(j+1)$ bits and there are $O(m/2^j)$ blocks. The circuit accepts at total excess zero with nonnegative minimum. With two types, a *single* mountain is also linear-size since the matching is one fixed reversal. Two mountains are the first case here in which the unknown split implements a variable rotation.
