# Checking partial RAM laps by challenging a skipped predecessor

Fix a log-word deterministic RAM, a transaction convention fixed by the machine, and one of the two SAT verdicts. Each transaction performs at most a fixed number of standard word operations and physical accesses. The input is read-only and randomly accessible. Mutable memory has a known random-access initialization. A **partial lap** is an interval of consecutive transactions. Outside a set of exceptional work addresses, each address occurs in the footprint of at most one transaction of that lap. A transaction can use a word several times, and its subsequent addresses can depend on freshly retrieved values. The set of exceptional addresses, denoted by \(S\), applies to the whole run. These addresses can be accessed and rewritten arbitrarily often. Both the set and the division into laps can vary with the particular computation. No prescribed bank or full-coverage condition is required.

**Behavioral SAT lower bound.** Let \(N\) be the proper encoded input length. Fix \(L\ge1\), \(e\ge0\), and \(c\ge1\) satisfying
\[
                 c^{L+1}\frac{L(1+e)}{L+1}<1 .
\]
No correct deterministic SAT solver has both a global \(O(N^c)\) clock and, on every sufficiently large input of one specified verdict, a partition into at most \(L\) partial laps outside \(O(T^e)\) exceptional words, with \(T\) its global clock. The same exclusion holds at global \(O(N\log^d N)\) time with \(o(\sqrt{\log N/\log\log N})\) laps and \(2^{o(\sqrt{\log N\log\log N})}\) exceptional words, for any fixed \(d\). Little-oh bounds apply uniformly over instances of the selected verdict at each length. For example, at \(L=2\), no hot words and \(c<(3/2)^{1/3}\), every solver respecting the global clock has arbitrarily large histories of **each** verdict requiring more than two partial laps. A machine may use arbitrarily many words in total and may decide other instances with unrestricted access patterns. The unrestricted RAM lower bound remains open.

## A canonical execution for dishonest boundary guesses

Let \(w=O(\log(T+N+2))\). For a chosen block parameter \(B\ge2\), guess the genuine halt time at most \(T\), the lap endpoints, the sorted distinct addresses of at most \(s\) exceptional words, and the controller plus values of those words at every boundary of a block of up to \(B\) transactions. Partition each lap by its fixed successive blocks and include the final boundary. The common header has at most
\[
                  H=O((1+s)(T/B+L+1)w)
\]
bits. Check its format, initial data and the selected terminal state. Use an absorbing halted state to continue a deterministic simulation up to any claimed endpoint; an early halt in these simulated rows counts as a defect. Boot and zero-time cases are direct.

For **every** well-formed header, define ideal rows by induction on laps, then by local chronological simulation within a block. Start the controller and exceptional words at the claimed block-start values. Simulate the hot memory normally throughout that block. Start every other word of **every transaction** from the final value of the last transaction in a strictly earlier lap whose footprint contained that address. If there is no such transaction, use initialization. Within one transaction, forward all repeated accesses to the local word and record its final value; a read-only touch keeps its value. Fixing these rules determines even rows in forged, overlapping laps or rows following a bad checkpoint. Call the resulting semantics the frozen execution. It is used only as a mathematical reference; the verifier never materializes its full memory.

## The backward challenge

A structural sketch for time \(v\) simulates the block from its supplied start through transaction \(v\). For each new cold word needed in a transaction, claim either initialization or a specific supplier transaction \(u\) in an earlier lap. In the latter case attach a structural sketch through \(u\); check that its footprint contains the required address and take its final word. Check the simulated instructions, common header lookups, address computations and terminal row of every node. A physical write that needs no previous value may omit a retrieval. Code a claim of initialization by \(u=-1\). A forest may contain two root sketches to test two rows. No absence list or address permutation is supplied.

A challenger can select *any* old-word claim anywhere in the forest, including inside a supplier's subsketch. It alleges that a later earlier-lap row touched the very same address: give a time \(v'\) with \(u<v'<\operatorname{start}(\text{claim's lap})\) and a structural sketch for that row whose footprint contains the address. Such a challenge succeeds only if the new sketch is itself valid under the same rule. A structurally sound forest is valid when no such challenge succeeds. Every counterchallenge has strictly smaller maximum root-lap index, so this defines validity by induction. A challenger cannot win by inventing a row or by suggesting an intervention from the current lap. Last-touch semantics also checks later candidates in the *supplier's own* lap, which is important on forged headers.

For any header and any row, its ideal value has a valid sketch, and every valid sketch gives that same row. To prove both assertions simultaneously, induct on the maximum root-lap index. For completeness, build the sketch with actual latest suppliers in the frozen execution. On all claims there is no genuine intervening row. By lower-rank soundness no valid contrary proposal exists. For soundness, each attached child of a valid forest is itself valid: every successful challenge to that child would already be an allowed challenge to the entire forest. Its output is therefore authentic by induction. A genuine later row for any claim also has a valid witness by lower-rank completeness. Its absence from all successful challenges proves the chosen supplier is latest, or proves initialization correct. Chronological deterministic replay within the block now gives exactly the frozen row. These arguments hold for arbitrary controller and hot-word headers. The latest-supplier test and the finite-rank game identity have elementary [Lean checks](PartialLapChallenge.lean).

A bad header has a defect in its format, boot, halt or cap conditions, a wrong controller/exceptional-word endpoint, or an address outside \(S\) touched by two transactions in the same lap. Guess the position or pair of positions, and a valid forest exposing it. For a hot endpoint mismatch, choose the single erroneous key and compare just that key. If there is no defect, every block concatenates, and cold disjointness within each lap makes the frozen semantics equal to ordinary in-place execution. The indicated verdict is genuine. Conversely the actual run with the claimed access property has a defect-free truthful header. Correctness on the unpromised verdict follows from soundness for every header.

If the maximum lap index is \(j\) counting from one, the bad-header game needs at most \(j\) alternating blocks starting existentially. The first player provides a structural defect witness and its forest; every next player offers a strictly lower-rank counterclaim. An illegal move loses immediately for its maker. Padding short games by dummy ignored moves yields an ordinary alternating bounded-string predicate. Thus the whole signer is an existential header followed by at most \(L\) alternating blocks starting universally.

For a fixed arity constant \(C\), one forest uses at most \(O((CB)^L\operatorname{polylog}(T+N))\) bits and deterministic verification work. A node simulates at most \(B\) transactions; each of their \(O(1)\) initial cold reads attaches at most one child. Multiplying branching factors gives a geometric sum, with no sum over all candidate predecessor times or lap orders. Check at most one counterclaim per further move. At a new node, access the hot portion of that block's read-only common header by indexed lookup. During local replay keep a private sparse overlay of the at most \(CB\) hot keys modified by that node, and fall back to its header on an overlay miss. Membership in \(S\) uses binary search. A deterministic binary trie of depth \(w\), with a fresh empty root per node, gives \(O(w)\)-time access and allocation per update; initialize new nodes explicitly. Thus a per-node copy of \(s\) hot words is unnecessary. A forest may be encoded with indexed, bottom-up records for child outputs and offsets, or with delimiters and a stack in a depth-first scan. The time to select and verify a challenge to an indexed record, including membership in the previous valid parse, is at most this same uniform bound. A branch of the game reads at most \(L\) such moves. The global format check may scan the actual header once, costing \(O(H\operatorname{polylog}(T+N))\).

## Transferring the game to SAT

Use hierarchy clock \(t=u^2\) on length \(u\). On the accepting sign take a language of nondeterministic multitape time \(O(t)\) outside nondeterministic time \(O(t/\log u)\). On the rejecting sign take a complementary nondeterministic \(O(t)\)-time language outside nondeterministic \(O(t/\log^2u)\), by complementing the padded bounded-universal interpreter on its own proposed decider's description. Even the logarithmic overhead for tape-number normalization fits this latter gap. Reduce the nondeterministic language (the complement in the second case) to an ordinary proper SAT file of \(M=t\operatorname{polylog}t\) bits whose individual bits can be generated from the input and index in \(\operatorname{polylog}t\) time. Padding with harmless proper syntax ensures lengths tend uniformly to infinity. Access the first file virtually, without paying to print its \(M\) bits. Every call for a later, smaller SAT formula uses the presumed global unrestricted clock on a physically materialized file. A terminal nondeterministic RAM of time \(A\) can be simulated by nondeterministically guessing the chronological word events and checking their address-sorted order and instruction arithmetic on tapes in \((u+A)\operatorname{polylog}t\) time. Each guessed word costs its full binary length. [Theorem 3.1 of Williams](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Locally computable reductions](https://arxiv.org/abs/1311.3171) · [Seiferas, Fischer and Meyer](https://doi.org/10.1145/322047.322061) · [Model and proper encoding details](sparse-checkpoints-through-permutation-laps.md)

For fixed \(L\), put \(T=O(M^c)\) and take \(B\) within a constant factor of \(T^{(1+e)/(L+1)}\). The headline's strict inequality entails \(e<1/L\), so the extra \(sL\) header term fits. Both header and move sizes are \(T^{L(1+e)/(L+1)+o(1)}\). Rational upper bounds for \(c,e\) and rational choices for the exponent of \(B\) within the strict margin give constructible caps if the original constants are real. Keep the first header nondeterministic, and eliminate each of the remaining \(L\) blocks using one bounded nondeterministic computation and a SAT call, reversing acceptance for a universal block. Include the underlying input and actual move transcript in the reduction parameter size. The final exponent is at most
\[
       t^{c^{L+1}L(1+e)/(L+1)+o(1)} + u^{c^L+o(1)} .
\]
The second term fits as well since \(c^L<2\). This contradicts the designated hierarchy for either sign. Costs of physical reductions and word-bit conversion are included in the vanishing exponent.

For growing depth, write \(X=\log_2(T+2)\), \(Y=\log_2(X+2)\),
\[
 D=\lfloor\epsilon\sqrt{X/Y}\rfloor,\qquad
 B=2^{\lceil A(D+1)Y\rceil},\qquad
 s_*=2^{\lceil D Y\rceil}.
\]
Use integer bit lengths, a rational \(\epsilon>0\), rounded integer square roots and rounded exponents instead if desired. Use caps \(D,s_*\) directly; no modulus for either little-oh hypothesis is needed. The true clock is bounded by \(T=O(M\log^d M)\). Under the selected-sign hypotheses the true header fits these caps for all sufficiently large instances. The number of bits and verification work for one move are bounded by \(P=(CB)^D\operatorname{polylog}T\); choosing \(A\epsilon^2<1/4\) ensures \(P<T^{1/3}\) eventually. Write \(U=u+H+D P\operatorname{polylog}T+\operatorname{polylog}T\), using the cap for \(H\), so every history of moves is at most \(U\) bits and the final predicate fits \(U\operatorname{polylog}T\) time.

Uniformity of eliminating \(D\) blocks matters. Use one fixed existential machine that takes a code parameter, the original input, the cap and a packed game position. It guesses the next padded move and runs the fixed recursive deterministic evaluator on the extended position with the indicated polarity. The evaluator decides whether such a branch exists by materializing the proper bounded-run SAT reduction for this *same* machine and the next smaller-depth clock. Pass the machine its fixed code as a data parameter, also forwarding that parameter to the lower-depth evaluator. Thus no compiler needs to splice copies of a program proportional to the recursion depth. The base evaluator checks a completed game branch directly, including illegal moves and their parity. Reversal of the Boolean answer handles universal blocks. The machine on every bounded source instance is uniform. Physical Cook reduction and the assumed SAT solver increase each stage's bound from \(A_{k-1}\) to at most
\[
       A_k\le F(U+A_{k-1}),\qquad F=(\log T)^K ,
\]
where the fixed \(K\) covers construction and materialized input length, transport of game data, machine interpretation, and the assumed \(N\log^dN\) clock. The bound assumes intermediate times at most \(T^2\); the stronger bound below certifies it inductively. Clock computation with fixed powers, uniform loops and saturation at \(T^2\) costs only \(\operatorname{polylog} T\) per stage. The machine can pass \(D,B,s_*,T\) as explicit numbers throughout; the exponents of the fixed reductions do not depend on the chosen constant \(A\).

It follows that \(A_D\le (2F)^{D+O(1)} U\). Here \((2F)^D=2^{O(DY)}=T^{o(1)}\); it keeps the \(u\), \(D P\) and \(s_* D w\) terms below \(T^{2/3}\). In the large header term \(s_* T w/B\), the factor \(B\) absorbs \(s_*(2F)^{D+O(1)}\) and any fixed power of \(\log T\): first choose \(A>K+O(1)\) with slack, then choose the small \(\epsilon\) above. Hence the final cost is \(o(t/\log^k t)\) for any prescribed fixed \(k\) after increasing the threshold input length. Include the final tape simulation in this choice. The nondeterministic hierarchy contradiction follows without using a growing-depth time-hierarchy assertion.

## Scope of the restriction

A correct unrestricted SAT solver can belong to the slow structural class: an exhaustive solver can pad every run past \(2^N\) steps while retaining only \(O(N\operatorname{polylog}N)\) workspace words, including the padding counter. Word addresses still fit \(O(\log N)\) bits. Taking all its work cells as exceptional leaves a single partial lap and uses \(O((\log T)^2)\) exceptions on its padded runs. No claim about the existence of a correct solver with a fixed empty exceptional set and very few laps is needed for the behavioral implication.

There are linear-time native traces that need many partial laps even after exceptions. Interleave \(b\) lanes over \(r\) rounds. A lane transaction reads the preceding round's immutable cell in its lane and writes its next state into a fresh timestamped cell, using only a constant number of words per transaction and unrestricted read-only input. Equivalently use adjacent separate read and write as one fixed transaction. On each lane the \(r-1\) writer-to-next-reader intervals have disjoint sets of permissible boundary positions. Removing \(s\) addresses leaves one lane with at least \(r-1-\lfloor s/b\rfloor\) such required cuts. With \(b=r\) and \(s=o(br)\) this is \(\Omega(\sqrt{T})\) laps for an actual linear-time \(T=\Theta(br)\) RAM trace. Each payload has a known unique writer and is read at most once later. This defeats a universal partial-lap partition of native traces; changing the algorithm or encoding its memory could change the conclusion.

The [finite checker](partial_lap_challenge_audit.py) compares every proposed header and every structural sketch in small adaptive instances against independent mutable and frozen executions. Its checks include genuine uses of a writer two laps back, intervening-row challenges, the uniform resource inequality and the disjoint-boundary count. The full machine and hierarchy transfer is a manuscript proof.
