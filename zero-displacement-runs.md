# When long-range color changes cancel

Use the opened 18-point anchor. Normalize its six boundary colors in red-then-blue order to $(1,0,2,1,2,1)$. The strip has $m\ge 2$ vertices in consecutive red order and two blue lists, one for each parity. [Anchor construction](one-point-growth-with-mandatory-ram-reads.md)

For a proper red coloring $h$ write $d_i=h_{i+1}-h_i\in\{1,-1\}$ over $\mathbb F_3$. A natural skip $\{i,i+2\}$ is proper exactly when $d_i=d_{i+1}$. The $b$ missing skips partition the $m-1$ red gaps into $b+1$ nonempty runs of lengths $\ell_1,\ldots,\ell_{b+1}$. All increments within a run equal one sign. Let $k$ count the **nonfinal** runs whose lengths are not divisible by three.

There is a deterministic algorithm of time $O(m+(b+1)2^k)$ and space $O(m)$ words, including validation of the parity lists. Try each of the three initial colors and enumerate signs only for those $k$ runs. Every run now starts at a known color. A nonfinal run of length divisible by three adds zero to its starting color for either sign, and the final run need not transmit a color any farther. At distance $r$ into a remaining run its color is its known start plus $r$ times that run's one Boolean sign modulo three. At a shared endpoint use the following run's start. At the last red point use the final run's endpoint.

Retained skips and red edges are already satisfied. Each of the $b$ other within-lane edges compares two colors, each constant or dependent on one Boolean sign. Forbid each of the at most four assignments giving equal colors, yielding clauses of width at most two. If both ends use the same variable, selecting contradictory assignments gives a tautological clause and selecting identical assignments gives a unit. The six anchor inequalities yield units or constant conditions. Thus after guessing the active signs the remaining feasibility question is one 2-CNF on $O(b+1)$ variables and clauses. Conversely its satisfying assignment gives all red gap signs and all vertex colors. Precompute each exceptional endpoint's run and distance modulo three in one scan, then solve each resulting 2-CNF in $O(b+1)$ time using implication graph components. This gives linear time at fixed $k$ even for $b=\Theta(m)$. [Aspvall, Plass and Tarjan](https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2007WS/2SAT.pdf)

For an explicit family of both verdicts, take $m=6s$ with the odd lane increasing. Group the even labels into the $s$ red triples $(6j+2,6j+4,6j+6)$, starting at $j=0$. Permute these triples in any order in blue and orient each independently. Missing skips occur only at $i=6j$, so $k=0$ throughout all $2^s s!$ files. For example, listing first the odd-numbered triples and then the even-numbered triples breaks a linear number of old adjacencies, in either orientation of each triple.

On this family the verdict is YES exactly when the *last red triple* is reversed in blue. The first strip vertex is forced to 0 since it sees anchor colors 1 and 2. Each block of six gap increments away from the final partial block has constant sign internally (the only possible break occurs between blocks), so each block starts at color 0. Its even colors in red triple order have the form $(u_j,0,-u_j)$, $u_j\in\{1,-1\}$. In its blue orientation call the first color $v_j$, so its last color is $-v_j$. Blue joins force $v_j$ equal for successive triples, and the first blue even vertex avoids anchor color 2 so all $v_j=1$. The last odd vertex $x_{m-1}$ has color $u_{s-1}$ and must avoid 1. Thus the triple containing the largest red rank must be reversed. When it is, set each block sign equal to 1 if forward and $-1$ if reversed. This gives all required colors. The assigned labels satisfy each blue join, including any surviving natural boundary skip. The final red color is nonzero and the final even-lane color is 2, as required. The arbitrary-source seven-triangle tiles have at least three nonfinal runs of length indivisible by three per complete tile. The missing successive-tip pairs at offsets 0, 1, 2 and 4 yield consecutive red-gap run lengths 2, 2 and 4 inside that tile. Thus the parameter bound on the compiler images is exponential in the number of tiles. [Seven-triangle compiler](single_lane_sat.py)

The run decoder computes the verdict, $k$, and $b$. Its audit compares all 18,055 lane pairs through length ten to the phase decoder, and checks 700 triple permutations before and after the same-strip contraction. The Lean lemmas verify cancellation modulo three for every run length divisible by three. The reduction to 2-SAT, the family characterization, and the running-time bound are manuscript proofs.
