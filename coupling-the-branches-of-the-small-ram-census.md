# Exhausting shared branches of a clocked RAM on a finite SAT catalog

The finite model has four-bit native words, arbitrary code, binary branches and sixteen initially zero or input-filled writable cells. A short accepting path for each file separately does not give a short program for the whole catalog. Indeed every positive and every negative four-word file already has an eight-step path: read and compare each word to its own literal. The comparisons reject any different file to an unrestricted fallback. A program meeting eight steps **on every file** must also decide all those fallback branches within the same deadline. [Catalog and native instructions](exact-clocks-for-two-word-sat-inputs.md) · [Seven and eight steps on adjacent positive files](eight-steps-on-one-four-word-sat-input.md)

The following finite synthesis test enforces this extra requirement before trying to enlarge the input. Give it samples of either verdict and an executed-instruction bound $D$. For each sample, introduce a row with $D$ symbolic instructions. Choices include a load, store, any of the 20 native ALU functions, and a binary branch comparing words or literals. Operands reference earlier word results or any of the sixteen constants. The row simulates its exact writable initial memory on the entire chosen path, using the latest matching store on any indirect read. Each step emits a bit, equal to the comparison outcome on a branch and zero for every other operation. Moves and fixed jumps on an unrolled path do not add a data value or make a decision.

For every two rows and every time, if their earlier emitted bit strings coincide, require **the entire next instruction** (opcode and operands) to coincide. Require rows of opposite verdicts to have different final strings. At a row where changing one original word can change the actual SAT verdict, require a load of its initial value before it is overwritten. The latter condition follows from correctness on the full catalog. It can rule out a program that only happens to be correct on the samples. The final instruction may be taken to be a comparison. A terminal can be delayed by a sequence of constant comparisons through the fixed horizon. A final nonbranching instruction with no later control use can be replaced by a constant comparison. Before the first load or store, all computations and branch outcomes are public constants. Inline a first constant result or its fixed successor, and fill a saved initial position with an unused direct load when an exact length is needed. Register versions can be named by instruction position. Giving store and branch positions the public constant zero as an operand only duplicates an available literal.

Every globally correct program with clock $D$ satisfies the formula: take its padded paths on the samples. Conversely a Boolean model gives a single tree on their common prefixes. At every observed prefix the next instruction is unambiguously specified; differing outcomes are available only after a real binary branch. Label the observed leaves by their common verdict. Any previously unobserved subtree can be replaced by either constant leaf. The audit completes these leaves by majority verdict among the full-catalog inputs arriving there, then **runs the actual synthesized tree**. A counterexample from its error set can be added to the next formula. A complete verified tree proves an upper bound. An independently replayed LRAT refutation proves a lower bound for the chosen operation and prefix options. A satisfiable sample or a timed-out synthesis call settles neither inequality.

There are two search modes. The direct-prefix mode prescribes the four literal loads of addresses 0 through 3 before any other operation. Its lower bounds concern that prefix only; a successful full-catalog eight-step tree there would still be a genuine upper bound in the full model. The unrestricted mode permits all operations and operands from the start. Pairwise prefix synchronization is quadratic in the sample count, without constructing a complete binary tree of all possible programs or all $2^D$ paths. The self-test executes a known nine-step program on all 65,536 inputs, reconstructs its fixed paths inside the Boolean encoding, and independently checks LRAT refutations for an impossible clock and a pair of individually correct programs that demand different instructions at the root. Lean proves that equal-prefix agreement assembles one policy that replays all sample states and labels. It treats the per-instruction transition function abstractly.
