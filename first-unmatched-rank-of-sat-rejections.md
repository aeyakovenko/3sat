# A missed SAT deadline from the first unmatched rank

Fix a nonempty finite set of correct SAT deciders and clip each at its proposed $a_i(L+1)^k$ deadline, $k\in\{1,2,3\}$. They check small queries only. For $L=2^h$ consider a separate menu of $m=L$ arbitrary programs, indexed by all $h$-bit strings. No soundness is required of this large menu. At every sufficiently large $h$ there is a computable integer $\rho_h\in[0,m]$ with the following property.

Let a fixed deterministic procedure given $h$ output an estimate of $\rho_h/m$. It can use $O(h)$-bit words and the value of $L$; equivalently give it an all-zero input of length $L$ with length available. Count all its work. If its additive error tends to zero along an unbounded sequence of scales and it runs in $O(L^{1-\epsilon})$ time for some fixed $0<\epsilon<1$, there are arbitrarily large $L$ at which **one actual unsatisfiable proper $L$-bit file makes every small checker miss its own deadline**. The rank depends on those checkers and deadlines. This implication is unconditional. The last section gives a globally correct checker for which the premise provably fails, regardless of the complexity of SAT.

In particular, if even one listed decider meets its clock everywhere, **the sequence $\rho_h/2^h$ has no limit-computable real as a limit point**. For such a real take a computable rational sequence converging to it, with no required modulus. Under a growing time allowance compute more consecutive terms, keep the last one completed, and truncate to $h$ bits. A cutoff of $L^{1/3}$ elementary steps is ample for convergence with no promised rate. Multiplying the approximation by $L$ and rounding gives the integer prediction below.

## What the rank counts

For each $s=0,\ldots,m$ use a proper file $G_s$ of the same predetermined length $N=m L^k h^B$. Its public rank tag is readable in $h^{O(1)}$ steps. For example, begin the body with $h+1$ fixed-stride clauses on fresh variables; a bit chooses the digit 2 or 3 in an otherwise fixed positive clause. Every tag admits a common satisfying assignment on these fresh names. The rest of the file enforces the computation described here. $N$ determines $h$.

Define an edge from rank $s$ to large program $i$ if a circuit $D$ of at most $g=\lfloor L/(A h)\rfloor$ gates passes a test: at least one small checker returns NO by its deadline on the file $H(s,i,D)$ of length $L$. This file asks for a defect in the purported rejecting run of $i$ on the actual $G_s$, up to a fixed polynomial deadline in $N$ (take $N^k$). The circuit gives all registers and the preceding-store stamp at each work load. Each edge therefore certifies a genuine bounded rejection on that physical file, even though the rejecting program can be wrong about SAT. A short, satisfiability-neutral tag in the small file carries $h,s,i$ in a fixed syntax. Code $i$ of length $h$ is public inside this small test. Fix a common logarithmic word-width coefficient for the auxiliary menu and a sufficiently large fixed simulation coefficient for the host. The small SAT solvers have their own fixed conventions. The menu uses a universal fixed-register load/store convention, so decoding one of its instructions costs $h^{O(1)}$ Boolean gates. Invalid programs can simply idle. [Clock, local memory checks and physical size of the defect file](testing-a-short-rejection-history-on-a-smaller-sat-file.md)

Compile $G_r$ to ask for an injective matching of the entire prefix $0,\ldots,r$ into the menu. Its verifier guesses the row, circuit and small checker for each required rank, rejects duplicate rows, emits each small file and actually runs its chosen checker. Use a fresh work bank for each simulation or reset the cells written, charging the reset to the simulated work. The time is $O(m L^k h^{b_0})$ for a fixed $b_0$ allowing input preparation, the universal machine convention and the length-$m$ distinctness table. Choose $B$ to absorb this clock and the local Cook compilation. For the leaf calculations of $H(s,i,D)$, the word indexer for $G_s$ uses the **same template** with public rank $s$. It computes the syntax of the bounded computation, without running that verifier. Its input parameter for the template is its own fixed program number, as in the two-length construction. Neither the mask produced by a search nor any past matching is hardwired into $G_r$.

The truth values of these physical files are monotone in $r$ since every prefix of a matching is a matching. There are only $m$ columns, so $G_m$ is UNSAT. Define $\rho_h$ as the first UNSAT rank. There is a matching on all earlier stages, with the empty matching allowed. Every matched row actually returned NO on a satisfiable earlier file. A row that does not reject any earlier rank can be appended if it has an edge at $\rho_h$; that would make $G_{\rho_h}$ satisfiable, a contradiction. In the endpoint case $\rho_h=m$, all rows were already used, so the very existence of such a fresh row rules out that endpoint. This uses the definition of a matching alone. [Hall's classical paper on distinct representatives](https://doi.org/10.1112/jlms/s1-10.37.26)

## Hardwiring an offset, without hardwiring the entire rank

Use a universal menu with a self-delimiting routine header followed by a raw payload of known remaining length. Each fixed routine gets $h-d$ payload bits at all sufficiently large $h$, for its fixed header length $d$. This is a choice of auxiliary enumeration, not a change to the SAT machine being tested. Given any fixed integer predictor $p(h)$, one routine decodes its payload as an offset index, computes $p(h)$, and outputs NO exactly on the tagged rank specified by adding that signed offset. The offsets in increasing absolute value include an interval of radius at least $2^{h-d-2}$; out-of-range results match nothing. The row need not answer correctly on other files. If $|p(h)-\rho_h|=o(m)$ on a subsequence, some available payload selects $\rho_h$ at every sufficiently large such scale. The chosen row never returns NO on an earlier tagged file.

If its forecast computation uses $p$ actual instructions including reading the tag and payload, its authentic rejecting history at the selected rank has a Boolean circuit with $O((p+1)h+h^2)$ gates. Hardwire the prehalt table of registers and source stamps, decode the early time to a one-hot index by a binary tree, and select each of the $O(h)$ output bits. After halt a comparison and a selector return the prescribed constant idle fields. The polynomial-in-$h$ setup and interpreter overhead for any fixed $L^{1-\epsilon}$-time forecast still fit $o(L/h^2)$ instructions. Thus an exact circuit $D$ fits $g$. The test $H(\rho_h,i,D)$ really is UNSAT. Any timely NO on it would supply the forbidden additional edge, proving the common miss.

The same proof excludes more than approximate numeric forecasts under a globally valid clock. For any fixed indexed list computable in $L^{1-\epsilon}$ time per entry and having $o(m)$ entries, $\rho_h$ lies outside it at all sufficiently large $h$. Hardwire the entry number in the payload. No uniform algorithm is needed to *find* the successful payload in the implication from an accurate prediction, although enumerating the bounded circuits for the edges and solving the finite matching problems computes all the ranks. The announced normalized conclusion does not say that their sequence has a limit.

## A failed shortcut by counting

In the abstract edge graph on $m$ columns, put a private diagonal edge at each of the first $m$ ranks except rank $j$ and no edge at rank $m$. Every such graph has $m-1$ edges and maximum matching size $m-1$. Its first failed prefix is $j$, ranging over all $0,\ldots,m-1$. With only edge probes, any deterministic method guaranteeing integer error at most $e$ must make at least $m-(2e+1)$ probes in the worst case on this family. Follow the answers of the complete diagonal; unqueried diagonal positions remain possible holes. At most $2e+1$ possible integer holes fit around the reported answer. This tests the black-box counting proposal, not the complexity of exploiting native program values. Likewise, accepting the rank printed on the current file supplies no fresh row: a row rejecting every tag may already have been used in the prefix.

An honest globally fast SAT algorithm could determine the rank by binary search on $G_s$. That costs up to $O(\log m)$ calls at lengths $N$ much larger than $L$. It supplies no small circuit for the register history of the program making those calls. A proposed rank estimate has to use the actual small tester and must pass the following control. The earlier forecast journal used native output histograms; the quantity here is a threshold of actual proper SAT files with edge witnesses supplied by actual small-file runs. Priority for this formulation is unestablished. [Earlier clock counts](short-clock-prefix-allocation.md)

## A correct SAT checker that defeats every fast predictor on this construction

Add one small checker to any fixed collection and recompute the files for that collection. It is globally correct by an explicit fast path with exhaustive fallback. There is **no** $L^{1-\epsilon}$-time predictor of vanishing fractional error on any unbounded subsequence for the resulting ranks, unconditionally, for any fixed $\epsilon>0$. In particular their normalized sequence has no limit-computable limit point even if SAT takes exponential time. Thus a universal prediction lemma of this form, for all small-checker rosters, is false.

On a putative small test, the checker extracts and validates the fixed-format $h,s,i$. It directly simulates at most $P=\lfloor L/h^D\rfloor$ native instructions of the large row $i$ on the locally indexed $G_s$, for a sufficiently large fixed $D$. It keeps the preceding-store timestamps alongside the live work words. If a genuine NO appears, it builds one *canonical table circuit* for this precise trace through its first NO and the subsequent idle suffix. It then generates the exact test $H(s,i,D_{\rm table})$ for that circuit. It returns NO on an exact byte match and uses an ordinary complete SAT procedure in all other cases. A match proves that there is no local defect in an actual returning computation. This fact is independent of whether the large row's NO is a correct verdict on $G_s$. It also holds if a different circuit happens to print identical bytes.

The partial replay and unpadded test generation take $P h^{O(1)}+h^{O(1)}$ native steps: each virtual input read costs $h^{O(1)}$, one can use a dictionary for the visited work cells, and the literal table circuit has $O((P+1)h+h^2)$ gates. Choose $D$ large enough that this time is $O(L/h)$ and the circuit fits $g$. Remaining canonical padding is checked as packed words in $O(L/h)$ time. A fixed linear deadline therefore covers the fast path. Computing a virtual word of $G_s$ only runs the uniform syntax indexer, even if the computation being encoded includes this checker. Formally the fixed template can carry its verifier number in public parameters; its specialized checker takes that same number when invoking the indexer and the small-file generator. Universal interpretation along this path terminates by its explicit caps. No recursive call to SAT on $G_s$ is used. Cap the recognition attempt on every input before fallback. If a globally fast correct SAT algorithm exists, using it for fallback preserves its asymptotic time. A fixed width with sufficient constant coefficient or constant-many host words handles all large guest addresses.

If a predictor succeeded, the dedicated payload row at the first missing rank would halt with NO within $P$ instructions. Its canonical table would fit, and the new checker would definitely issue a timely NO on the corresponding test. The forbidden matching extension would follow. This argument applies at every sufficiently large successful scale, proving the assertion. It also works for the indexed-list version: the retained payload names the position of the predicted rank.

The resulting rank sequence is itself computable by finite search. If its normalized values converged, their limit would be limit-computable by definition. Hence the sequence does not converge. Choose a rational strictly between its liminf and limsup. Since this rational is not a cluster point, some fixed neighborhood is avoided eventually. Infinitely many upward and downward single-scale jumps cross that whole neighborhood. Even smooth extrapolation of this particular census across neighboring budgets fails.

This control identifies the failure in the forecast route. Forcing a smaller timeout by this matching argument against a pool containing the checker requires another source of a fresh edge. For example, a long authentic rejection with a short circuit for its time-indexed history can escape the checker's literal replay budget. Constructing such a rejection that singles out the actual terminal rank, or obtaining the common miss by another route, remains open.
