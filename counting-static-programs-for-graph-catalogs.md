# More graph catalogs than six-slot native programs

On k named variables fix a graph G and its background 2-CNF consisting of (¬xᵢ∨¬xⱼ) for every edge ij. A k-bit selector specifies which positive unit clauses xᵢ to add. The formula is satisfiable precisely when the selected vertices are an independent set: any edge within the set is a contradiction, and otherwise assigning all remaining variables false satisfies the formula. In particular the verdict on each two-element selector recovers one edge bit. These are distinct SAT decision tables for all 2^{k(k−1)/2} graphs.

The graph here is **precompiled**: the RAM receives only the selector, packed densely into w=⌈log₂ k⌉ bit words, with spare padding bits zero. Its code may specialize to G. The graph itself is not available in input memory or a free read-only table. This is a different problem from the fixed sign-plane catalog. If the CNF encoding instead supplies the graph clauses, the same program can use that additional input to implement many different selector tables.

## The code count

For C static instruction sites put h=C+2 and a=C+2^w. At most C distinct registers can be written; rename these registers and replace every other register read by the zero literal. Thus a bounds the number of data operand choices. Overcount by allowing any of h destinations, including both fixed verdict terminals, after each instruction and at entry. In the native instruction set there are 20 binary data operators (bitwise, arithmetic, shifts, rotations and materialized comparisons). EQ, unsigned LT, and signed LT suffice for control, since reversing operands and exchanging successors implements their other orientations and complements. LOAD and STORE each take register or literal addresses. Including arbitrary loops and padding smaller programs with unreachable sites gives the code bound

$$
P(C,w)=h\bigl(20C a^2h+Cah+a^2h+3a^2h^2\bigr)^C .
$$

At C=6 and w=4 this is 8·562,496⁶<2¹²⁰. Therefore more than 80% of the labeled 16-vertex backgrounds admit no six-slot evaluator even just on the 120 two-element selectors. This holds at any fixed deadline and also if one counts only terminating computations without imposing a deadline. It is a finite instance of the classical Shannon counting method; priority is not claimed. [Shannon, *The Synthesis of Two-Terminal Switching Circuits*](https://www.nokia.com/bell-labs/publications-and-media/publications/the-synthesis-of-two-terminal-switching-circuits/).

## Appending vertices

One can choose nested hard catalogs at 16 and 17 vertices. The 17th bit increases native word width to five. Every old graph has 2¹⁶ extensions preserving all its edges. Of the 2¹³⁶ graphs on 17 vertices, at most P(6,4)·2¹⁶ have an old graph realizable on the pair tests at length 16, and at most P(6,5) are realizable on the new tests. The sum is strictly less than 2¹³⁶. Hence at least one induced pair defeats six slots at both sizes, and in particular defeats five at 16 and six at 17. This is an existence statement about a pair. No specific adjacency matrix was certified. For finite deadlines there is a deterministic, albeit enormous, construction: enumerate candidate program pair tables at both sizes, then choose the lexicographically first extension absent from the larger table list whose restriction is absent from the smaller list.

For **any prescribed old** 16-vertex graph there is a guaranteed extension by seven vertices. The 112 old-to-new edges and 21 new-to-new edges can be chosen freely, and 2¹³³>P(6,5). Select a missing pair table among these extensions. More generally, adding t vertices to any k-vertex graph gives this conclusion against C slots whenever 2^{kt+t(t−1)/2}>P(C,⌈log₂(k+t)⌉). A separate way to preserve an arbitrary satisfiable 16-selector SAT catalog is to conjoin an independent graph catalog on 18 fresh selectors. The old verdict is unchanged when all fresh selectors are zero; fixing one satisfiable old selector exposes all 153 new pair tests. At 34 total selectors the word width is six and P(6,6)<2¹⁵³. [Lean verification of the four integer inequalities](GraphCatalogCodeCount.lean).

At growing k the log code count is O(C(log k+log(C+2))). In particular, along doubling block extensions one can keep all previously fixed edges and choose the new edges to defeat C=⌊c k²/log₂ k⌋ slots at each new total size k, for sufficiently small absolute c and large k. The number of new edges is of order k² and exceeds the log code count. The growing information resides in the chosen fixed background. The argument yields no superlinear time lower bound for ordinary explicit SAT and does not establish a six-slot lower bound for the particular unchanged sign-plane language.
