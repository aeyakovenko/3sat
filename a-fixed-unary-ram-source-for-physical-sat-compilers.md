# One fixed unary RAM source that costs a quadratic number of steps to compile

There is a fixed nondeterministic logarithmic-word program \(H\), running in \(O(n^2)\) instructions on \(1^n\), with the following property. For any finite list of deterministic procedures that physically emit an ordinary proper DIMACS file with verdict \(H(1^n)\), there are arbitrarily large accepting lengths on which **every** procedure in the list takes at least \(c n^2\) native steps. There are also arbitrarily large rejecting lengths with the same property. The constant \(c>0\) can depend on the list. The native source can be given as the fixed program, an actual guest payload \(1^n\), and a sufficient unary clock \(t=Cn^2\). Every bit of this entire file is determined by the \(O(\log n)\)-bit number \(n\). Its guest has \(\Theta(\log n)\)-bit words.

A second consequence concerns transferring this same source to fixed smaller-word RAMs. For a fixed \(0<\delta<1/2\), an \(o(n^2)\)-time deterministic transducer cannot always preserve its verdict in a guest with clock \(O(n^2)\) and word width \(O((\log n)^{1/2-\delta})\). The target also may guess arbitrary words and change all accepting multiplicities. A fixed finite list cannot guarantee that at least one such transfer is cheap at each length of either specified verdict. These are lower bounds for physical preparation or change of machine parameters. They give no time lower bound for a program given an already materialized SAT file.

## The fixed unary machine and its intervals

Use \(w(n)=12\lceil\log_2(n+2)\rceil\), a fixed native instruction set and register convention with one complete word per nondeterministic choice. Choose a sufficiently large fixed integer \(B_0\) and put \(B_{j+1}=2^{B_j^3}\). Assign an opponent index \(i_j\) and a positive quota \(p_j\) to each interval \([B_j,B_{j+1})\), so each pair occurs infinitely often. For example, decode the integer \(\nu_2(j+1)\) by an ordinary pairing bijection as \((i_j,p_j-1)\). Treat invalid opponent codes as rejecting programs. Lengths below \(B_0\) are harmless. This is Žák's unary delayed diagonalization, with an extra publicly computable quota. [Žák, *A Turing machine time hierarchy*](https://doi.org/10.1016/0304-3975(83)90015-4) · [Seiferas, Fischer and Meyer](https://doi.org/10.1145/322047.322061)

On length \(n\) find its interval using integer comparisons. Form \(2^{B_j^3}\) only when the exponent fits below \(\lfloor\log_2(n+1)\rfloor\), with a separate test for the endpoint \(n+1=B_{j+1}\). The number of scheduling operations is polynomial in \(\log n\). Reject a nonunary input after a packed scan. On an interior length simulate opponent \(M_{i_j}\) nondeterministically on \(1^{n+1}\) with a budget of \(n^2\) simulated-host work units, accepting if that simulation accepts in time. Counting host work can be implemented with a fixed instruction overhead. All sufficiently fast branches of a fixed opponent get through. The guest word width at \(n+1\) differs by at most 12 bits. Wider arithmetic takes a constant number of limbs, and fixed-depth sparse tries with digits of \(\Theta(\log n)\) bits serve the at most \(O(n^2)\) actual guest writes even across the rounded-width boundary. Registers, interpreter data and guest cells have disjoint backing stores. Predecode the finite code once. On a fixed opponent, setup is \(o(n^2)\) and each simulated instruction has bounded cost independent of the interval and quota. When two host nondeterministic words are used to form one wider guest choice, canonical high-bit padding may be required. [Native simulation in separate banks](native-unary-clock-band.md)

At \(e=B_{j+1}-1\), let \(b=B_j\). Deterministically accept exactly if \(M_{i_j}(1^b)\) has **no** accepting path within \(b^2\) guest steps. Enumerate at most \(2^{w(b)b^2}\) choice strings and simulate each from the true initial state. This is \(2^{O(b^2\log b)}\operatorname{poly}(b)=o(e)\) work for all large \(b\), including program decoding and clearing scratch. The choice counter and string fit the endpoint host's \(O(\log e)\)-bit words. Use, for instance, a touched list or a fresh bounded run buffer for each replay. This defines an \(O(n^2)\)-time nondeterministic machine on *all* of its input lengths.

The useful interval fact is exact. Let a fixed alternative \(Q\) run fast enough on every length \(b,\ldots,e\) in an interval assigned to its own code that each simulation in the interior is faithful, and that its runs on \(b\) finish within \(b^2\) guest instructions. If \(Q\) agreed with \(H\) everywhere in this interval, the equalities
\[
 H(1^n)=Q(1^{n+1})\quad(b\le n<e)
\]
would propagate the same verdict from \(b\) through \(e\), while \(H(1^e)=1-Q(1^b)\). Thus some length disagrees. In particular \(H\) lies outside all nondeterministic \(o(n^2)\)-time deciders in this native model. The argument never complements an unknown nondeterministic computation at the same short length.

## Physical ordinary-SAT production

A physical producer writes at most a fixed constant number of actual packed words per instruction to its delimited output. It may run on \(1^n\), its binary length with a native width based on the expanded source, or the fixed unary-clock native input above. In all cases its word width is \(O(\log n)\); on the original \(1^n\)-host each current source word and each of the producer's sparse accesses can be simulated with constant overhead on the \(O(n^2)\) steps used here. An implicitly zero-filled address space accompanied by an arbitrary synthetic file length is not a physical producer in this assertion. All members of the list must give the correct verdict whenever the wrapper consumes their completed files.

Fix a fallback bit \(d\). On \(1^n\) one fixed opponent \(Q_d\) recovers \(p=p_j\) from the interval. Run each procedure in turn for \(\lfloor n^2/p\rfloor\) guest steps, retaining the first properly completed file and discarding every timed-out attempt. If there is none return \(d\). Otherwise verify the completed SAT file nondeterministically. Its length satisfies \(M=O((1+n^2/p)\log n)\). The packed DIMACS verifier uses \(O(1+M/\log(2+M))\) host steps. For \(M\ge n\), this is \(O(n^2/p+1)\); below \(n\) an additive \(O(n)\) suffices. Initialize and clear all scratch in the same bounds. Over all paths the wrapper costs at most \(K(n^2/p+n+\operatorname{polylog}n)\), where \(K\) depends on the fixed list but is independent of \(p\). [Packed nondeterministic SAT verification](packed-verification-of-locally-indexed-unique-sat.md)

Once this opponent code has been fixed, choose \(p\) large enough that the upper bound also fits the source's interior universal-simulation budget and the endpoint's guest-step bound for all large lengths. On **every** sufficiently late interval assigned to \((Q_d,p)\), the interval fact supplies a disagreement. A completed file would have given the correct verdict. Hence no producer finishes by the cutoff there and the true verdict is \(1-d\). Take both choices of \(d\). This proves the claimed simultaneous lower bound with a constant quota, without having to calculate a convergence rate from a purported little-\(o\) guarantee.

## Smaller guest words

For a finite list, let each fixed deterministic metadata producer take \(o(n^2)\) time on every length and propose a payload and binary deadline for a fixed target program. The original and target decisions agree; different targets can use different programs. Fix common constants \(C,K\) and \(0<\delta<1/2\). Instead of waiting for printed SAT files, test whether a proposed clock is at most \(Cn^2\) and its genuine guest width at most \(K(\log n)^{1/2-\delta}\). The bounds can be rounded constructibly, for example by using a fixed rational \(\delta\) or a slightly weaker rational exponent. The actual physical guest payload then has \(u\le 2^{O((\log n)^{1/2-\delta})}=n^{o(1)}\) bits. If needed the target program can be given a larger external clock \(Cn^2\) only **inside its checking implementation**, with an explicitly enforced stop at the original deadline; never silently extend its accepting paths.

The packed native verifier for any qualifying candidate takes \(O(n^{2-\eta}+n^2/(\log n)^{2\delta}+n^{o(1)})=o(n^2)\) steps for some fixed \(\eta>0\). Use the \(1^n\)-host's own \(W=\Theta(\log n)\) as the search and table width, and use \(Cn^2\) as the public upper size for chunking even if the actual deadline is much smaller than \(u\). The actual trace still has exactly the proposed number of slots. Tables of size \(n^{O(\epsilon)}\) can be built uniformly below the indicated budget; pick a sufficiently small fixed \(\epsilon\). The purely physical target suffix may instead be constructed or validated in \(O(n^2/\log n)\). [Packed verifier and address chronology](packed-chronological-checking-on-narrow-ram-guests.md)

Use the first qualifying candidate, else return the fixed fallback. This defines a genuinely \(o(n^2)\)-time alternative on every length. On every sufficiently late interval assigned to it, the same argument supplies a length of verdict \(1-d\) at which all candidates fail the public limits. Consequently a uniformly fast preparer cannot obtain a near-square time narrow guest even for this binary-describable unary source. No guess-count promise on the target was used.
