# An exact executed-step hierarchy for proper SAT files under sparse edits

Use the [separate-operation logarithmic-word RAM](five-instruction-loops-on-dimacs-sat.md). The program may be chosen separately for every finite suite, with arbitrary code size, word literals, register count and writable memory. Each LOAD reads one word, a STORE copies one payload to one address, an ALU instruction applies one of the specified at-most-binary word operations, and a branch compares at most two words with fixed successors. The two verdicts are terminals.

**Theorem.** For every sufficiently large byte-aligned bit length $n$ there is a family of proper DIMACS 3-CNF files containing $m=\lceil n/w\rceil-256$ distinguished words. At each of them there are five possible settings. The all-center file is satisfiable and every noncenter setting of at least one word makes the file unsatisfiable. For $1\le k\le m$, promise that at most $k$ distinguished words differ from center. Among deterministic programs correct on the promise, the exact optimum worst-case number of executed instructions is
$$
                 2m-\left\lfloor\frac{m}{k+1}\right\rfloor.
$$
Every such program pays at least this many instructions on the *same all-center file*. In particular a correct general SAT decider requires at least $2m$ steps there, even if its text is specialized to $n$ and contains all the input addresses as immediate operands. For unrestricted text this improves the earlier $5m/3-O(1)$ bound on a different homogeneous-word family. The previous $(2+\delta)m-O(C+1)$ bound for $C$ stored instructions gives a stronger coefficient for each fixed-size program. ## Five choices for a packed word

Write $Q=2^w$, $W=w/8$, with the journal's $w=16\lceil D\log_2(n+2)/16\rceil$ for fixed $D\ge1$. Let $o$ be the odd part of $w$. It satisfies $o\le W/2$. For some $1\le \ell\le o$, the base-256 repunit $S_\ell=1+256+\cdots+256^{\ell-1}$ is divisible by $o$. Indeed two of $S_0,\ldots,S_o$ coincide modulo $o$, and a power of 256 can be cancelled from their difference. Define
$$
       \Delta=256^{W-\ell}S_\ell .
$$
Then $w\mid\Delta$ for all sufficiently large $w$ and $\Delta^2=0\pmod Q$. The power of two in $\Delta$ is at least $2^{w/2}$.

For $d\in\{3,4,5,6,7\}$, let $v_d$ be the decimal identifier beginning with 1 and followed by $\ell$ copies of digit $d$. Give $v_5$ value true and give $v_3,v_4,v_6,v_7,1,2$ value false using 28 public proper clauses. To pin one signed literal $l$ use all four clauses $(l\lor\pm x_8\lor\pm x_9)$. Each of the $m$ edited records represents $(x_{v_d}\lor x_1\lor x_2)$, with one additional public occurrence using $v_5$.

The distinguished word of type $d$ begins with the ASCII bytes for ` 1 2 0` followed by a newline. Fill with spaces until there is just room for `1` and the $\ell$ copies of $d$. This word finishes the previous clause and starts the decimal name of the next. Before the first such word, place the header declaring $v_7$ and $m+29$ clauses, the 28 pinning clauses, whitespace and the incomplete public name $v_5$ ending precisely before the word boundary. For example end that prefix at address 128 in word units. These records fit for sufficiently large $w$: each variable name has at most $W/2+1$ digits, the number of occurrences is bounded, and the clause count has $O(w)$ decimal digits with coefficient at most one. After the last marked word finish its clause with the same fixed suffix and append whitespace to reach exactly $n$ bits. The choice of 256 overhead words leaves room for a partial final word. The largest numerical identifier is polynomial in $n$ for a fixed $D$.

Let $A$ be the center word and $X_d$ the word of type $d$. In little-endian order
$$
     X_d=A+(d-5)\Delta .
$$
All memory addresses of distinguished sites are below $A$ since its highest byte is ASCII 53 and $\lceil n/w\rceil=o(Q)$. Also $X_4$ is a proper bitwise submask of $A$, and $X_7$ is a proper bitwise supermask: these claims hold byte by byte for the encodings of 4, 5 and 7. Every $X_d$ has the same shift count under reduction modulo $w$, and all counts exceed $w$ under a saturating convention. These five settings are the alphabet $E$, with center $A$.

## What one comparison or numerical instruction can constrain

For a binary numerical instruction on two *different* private raw variables, impose that its output equal its value at $(A,A)$. For a branch on them, impose that its outcome equal the original outcome. Write $R$ for either binary relation on $E$. The diagonal center pair is always allowed. Designate either operand as parent and the other as child. At least one of the following properties holds in that orientation:

1. With the parent fixed to $A$ some noncenter value of the child is allowed.
2. Every parent value in $E$ has at least one allowed child value in $E$.

For addition use opposite deviations from $A$. For multiplication use the same opposite deviations and $(A+e\Delta)(A-e\Delta)=A^2$ modulo $Q$. For subtraction in either order use identical choices. Identical choices also preserve every comparison on the diagonal, both as a numerical result and as a branch. For a bitwise truth table whose diagonal is constant, identical choices suffice. If its diagonal is the identity or complement, the truth table is AND, OR, one of the two projections, or the complement of one of these four functions. For AND keep one operand at center and change the other to its supermask; for OR use the submask. The complementary outputs impose the same relation. A projection allows any change to its ignored operand, and a parent on that ignored side can be changed freely with the child at center. A constant output imposes no restriction. For a shift or rotation the count stays identical under all choices, so one can change the count alone. This handles either orientation by keeping the data at $A$ when the parent supplies the count. These cases include moves and the allowed unary operations when an operand is ignored.

**Tree lemma.** Put one variable with alphabet $E$ at each vertex of a finite nonempty tree. Each edge carries a center-preserving relation with the two properties above in either orientation (at least one property per orientation). There is a satisfying setting different from the all-center setting.

More precisely, at any chosen root either there is a nontrivial satisfying extension *with root at center*, or every root value admits a satisfying extension. A single vertex satisfies the latter. Combine the child subtrees inductively. A nontrivial extension anchored at a child center already gives one anchored at the parent center, with every other subtree at center. Otherwise every child value extends on each subtree. If any parent-child relation allows its child to change while the parent stays at center, this supplies an anchored nontrivial extension. In the remaining case every edge allows a child value for every parent value, and the subtrees can be completed independently. In the second alternative choose any noncenter root. This proves the lemma without a bound on tree size.

## Counting constraints on a single accepting RAM execution

Run the candidate on the center file and choose the **first original LOAD** at each of the $m$ distinguished addresses. Every address must have such a LOAD before a write there, since correctness on each one-word edit requires a different verdict. If the center run never halts it already misses every deadline. Denote its finite length by $T$.

Fix its actual sequence of memory addresses. Symbolically replay its register and memory values as follows. An original private word carries the tag of its site, denoting the *entire raw variable* $X_i$. All original public words and literal data are fixed. LOADs and STORE payloads forward tags or fixed values. For every numerical operation require its output to equal its center-run output and propagate that fixed word afterwards. For every branch require its original outcome. Every memory access requires its original address. Thus each of these conditions depends only on raw variables supplied *directly* to this instruction, since numerical outputs are fixed by their own constraints. Any full setting satisfying all the conditions gives precisely the same executed instructions and verdict, by induction over actual execution time. In particular a STORE payload can change and be forwarded through an arbitrarily long series of later instructions. The memory address of that STORE alone is constrained.

A selected LOAD has **no constraint**: a tag-valued address would be $A$ on the center run and the selected address is below $A$. Each of the other $T-m$ instructions contributes at most one constraint. Its scope has either zero, one or two distinct raw variables. Two occurrences of a single tag belong to the unary case. A binary constraint between two different raw variables can only come from a numerical operation or branch, so it is a relation covered by the tree lemma. Count one edge between these two variables for every such constraint, including parallel edges. Place each unary constraint at its single vertex. A zero-variable constraint may be discarded since it holds originally.

If $c$ of the connected components of the resulting multigraph are trees carrying no unary constraint, then the number of constraints is at least $m-c$. Every connected component of $s$ vertices needs $s-1$ edges; one that contains a cycle or a unary constraint pays at least $s$. Hence $c\ge 2m-T$. Any of these $c$ trees could be perturbed while the other components stayed at center. Correctness on the promise implies that each such tree has at least $k+1$ vertices, since its perturbation changes at most its vertex count. Consequently $c\le\lfloor m/(k+1)\rfloor$. This gives the claimed executed-step bound, independently of all data literals, initial fixed words, control graphs and writable addresses.

There is also a counting statement for testing a candidate whose correctness is unknown. If it accepts the center within $2m-d$ steps, then at least $2^d$ different files in this family have exactly the same address and branch sequence and receive the same verdict, provided it read every original marked site. Choose one nontrivial extension on each of $d$ disjoint unconstrained trees and either apply it or leave that tree unchanged. Thus at least $2^d-1$ wrong answers occur. The read-every-site proviso follows automatically for a candidate that passes every single-edit test. A candidate that skips a site already accepts a single edit at that site. The RAM can carry different raw payloads along the shared execution trace. All numerical results, branch decisions and instruction counts coincide.

## Matching programs and the obstruction to a time lift

Divide the $m$ marked sites into disjoint blocks of $k+1$ and a final remainder. For each full block, load its first word and require every other word of the block to equal it, using one LOAD and one comparison branch per further site. If an entire block equals a noncenter word then it already has more than $k$ edits. For the remainder, compare each loaded word to the literal $A$. Reject at the first failed comparison, and otherwise accept. With fully unrolled immediate addresses the center run and worst case use exactly $2m-\lfloor m/(k+1)\rfloor$ instructions. This machine is required to decide only the promised family.

At $k=m$ the $2m$ lower bound on the common base applies to every globally correct program. Equality in the exact minimax formula was proved on the promise. There is a globally correct decider specialized to this one file that accepts it in $2\lceil n/w\rceil+O(1)$ steps: first fall back if the literal $2^{w_*-1}$ is zero in the current width, where $w_*$ is the designated file’s width, then compare the public length, compare every original word to its literal, and run an unrestricted correct SAT procedure on a mismatch. The first check handles shorter words in which the length literal might otherwise wrap. The initial checks are read-only. This also works for *any* designated yes file. A single common base, even with arbitrary numbers of counterfactual alternatives, cannot beat the latter deadline when program text may specialize to the length and file. For the research target the hard input may depend on the fixed solver, and the target counts encoded bits. This exact hierarchy reaches neither an unrestricted linear-time exclusion nor a proof of the quadratic or cubic target. The classical branching-program lower bounds for element distinctness and linear-time RAMs impose a memory restriction; this native counting argument imposes the specified opcode interface. Priority for the native hierarchy has not been established.
