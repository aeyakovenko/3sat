# Compiling the packed challenger without its scanning history

For the unary hierarchy challenger $Q$, the long final operation verifies that a reconstructed array is a satisfiable proper DIMACS file. Its grammar, conversion of decimal names, trie operations, and assignment lookups need **no clauses at all** when the reconstructed bytes are fixed and already available as a proper file: output that file. This observation really does remove the history of the packed verifier. It gives the following more precise test of the proposed shortcut. [Definition of the challenger](algebraic-degree-of-a-compact-physical-sat-indexer.md) · [Unary interval opponent](a-fixed-unary-ram-source-for-physical-sat-compilers.md)

Fix a length $n$ and an honest proposed table whose bytes are verified by the challenger's smaller defect query. Its final assignment exists exactly when the restored file is satisfiable. On lengths satisfying the reconstruction promise every validated proposal gives the same physical bytes; at least one such proposal exists. Therefore when compiling just this operation extensionally at the successor length $n+1$, one may return the locally supplied original file $F_{n+1}$, including its true decimal variable names. This retains each original clause and does not emit a dictionary consistency tableau. If the file has $t$ bits, the number $D$ of distinct clauses is $O(1+t/\log(2+t))$. Indeed each distinct signed ordered triple has a distinct canonical serialization over a fixed alphabet. At most exponentially many such strings have length below $\frac12\log_{|\Sigma|}D$, so at least half of the $D$ strings have length $\Omega(\log D)$, and their disjoint occurrences occupy at least $\Omega(D\log D)$ source bits. This count does not furnish the local ordinal of a deduplicated clause. When the rows are already fixed slots of $\Theta(\log t)$ bits, copying the original slots gives the desired number and local form directly.

On an interior length of an interval assigned to this very $Q$, $H(1^n)=Q(1^{n+1})$ whenever the quota admits the full simulation. The clause returned by the shortcut is thus obtained by calling the as-yet-unconstructed indexer at **$n+1$**. In particular a definition that literally forwards the address through consecutive interior lengths makes $e-n$ successor calls before hitting the endpoint $e=2^{b^3}-1$. At $n=b$ the terminal operation represents the negation of bounded acceptance by $Q(1^b)$. Endpoint brute force is fast relative to $e$ but its worst-case budget $2^{O(b^2\log b)}$ does not give a polylogarithmic evaluation procedure in $b$, or even the required $o(b^2)$ preparer at the start of the interval. This is a failure of this specific forwarding algorithm. A different index equation or fast-forward operation could change this conclusion.

## Trying one fixed network for every tentative table

There is an explicit family that prices the alternative of generating clauses for one fixed assignment router before the table parameters are known. Let $v=2^k$ and let $s$ be an unknown $k$-bit translation. Give the $2v$ assignment bits distinct ordinary decimal names. For $X_i$ use a leading digit 7 followed by $k$ digits, 1 or 2 according to the bits of $i$. For $Y_j$ use prefix 8 with the same convention. For every $i$, require $X_i=Y_{i\mathbin{\mathrm{xor}}s}$. Use the two implications and pad each binary clause $U\lor V$ by the pair $U\lor V\lor z$, $U\lor V\lor\neg z$ on fresh name $z=1$. This is $4v$ proper clauses, all distinct. For every fixed $s$ there are exactly $2^v$ possible $X$ fields and each determines its $Y$ field. Arbitrary further pins on the fields make this a genuine checking relation; without pins the verdict is always SAT.

Each physical bit of the compact row descriptions is particularly simple. Reserve a power-of-two number of bytes $B=\Theta(k)$ per four-clause row; use a space in a positive literal's sign slot and minus in a negative slot. The row range starts at byte $vB$ after the header and $O(vB)$ optional whitespace, so its $k$ row bits directly equal $i$. On the row range a fixed within-row offset selects a constant, one bit $i_h$, or one bit $i_h\mathbin{\mathrm{xor}}s_h$, possibly complemented, according to two adjacent ASCII digit values. The bit function is a sum over the $8B$ within-row offsets of the corresponding address indicator times that selected affine form. Its degree on this whole range is at most $1+\log_2(8B)=O(\log k)$, for every $s$. The initial header has $O(k)$ bytes, so on its own aligned $O(k)$-byte segment its degree is also $O(\log k)$. The rest of the initial padding is constant whitespace, whose individual bits have degree at most three. Thus this genuine $\Theta(vk)$-bit file uses only constantly many low-degree address intervals, and the choice among the tables uses just $k$ bits. Each requested bit can be computed directly in $\operatorname{poly}(k)$ work from $s$ and its address.

Consider recompilers that first realize this read pattern by a fixed acyclic network of ordinary two-input, two-output switches, with a choice of straight/cross configuration depending arbitrarily on $s$. A wire carries one input bit intact. Each active route ends at its unique output port. The smallest such network has exactly $vk/2$ switches. Fix an input $i$ and choose one routing for each $s$. Following its route produces a binary sequence of port choices, with one bit per encountered switch. Its $v$ different destinations are sinks, so these sequences are prefix-free. Kraft's inequality and the arithmetic/geometric mean inequality give average length at least $\log_2 v=k$ under uniform $s$. Summing over inputs gives at least $vk$ traversals on average, while each switch can carry at most two of the $v$ values in one routing. Conversely, $k$ consecutive stages with $v/2$ switches at stage $h$ pair indices differing in bit $h$; crossing those switches precisely when $s_h=1$ attains the count. This is a transitive-family instance of the classical shifting-network argument. [Pippenger and Valiant, *Shifting Graphs and Their Applications*](https://doi.org/10.1145/321958.321962)

An ordinary gate-by-gate serialization that introduces distinct output names for the switches therefore has $\Omega(vk\log(vk))=\Omega(vk^2)$ bits. Taking $t=\Theta(vk)$ gives $\Omega(t\log t)$, an extra logarithm over the physical compact target. This holds even though the original reconstructed instance has only $4v=O(t/\log t)$ clauses and needs $2v+1$ actual assignment bits. In this example there is also a cheap way out: reading one $Y$ name in row zero reveals all of $s$. After specializing to the true table, clause-copying again gives the $\Theta(t)$-bit file. The lower bound applies to the stated intact-data switching construction. It leaves open arithmetic checks, arbitrary Boolean or existential encodings, and a decision-only compiler that specializes the unique true table.

The special challenger thus offers a real reduction in the number of clauses once the verified table is known. The attempts here supply neither a uniform short indexer for the root of its delayed recurrence nor a way to keep that length when compiling arbitrary tentative tables by ordinary switches. The form of the fixed unary source and the small defect-query assumption matter to the first point. The shift lower bound does not concern the running time of a RAM presented with a SAT file.
