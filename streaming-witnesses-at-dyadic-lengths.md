# Linear-time search through a stream of dyadic SAT candidates

Let $n$ be a power of two measured in **bytes**. A fixed deterministic generator $G(i,n)$ starts with an $n$-byte zero buffer and emits addressed byte replacements and candidate marks. Its $j$th mark designates the current file, starting at $j=0$ and stopping before $j=n$. The generator can use private RAM throughout. Its input scale and word-width rule are fixed at $n$. Suppose that for each row $i$, every candidate asserted for that row is marked within $A_i n$ generator steps, for some constant $A_i$. File labels, an inverse from files to their indices, and a bound on $A_i$ are unnecessary.

**Transfer.** For this $G$ there is one tally language in nondeterministic linear word-RAM time with the following property. If it has a deterministic $O(m^k)$ RAM decider, $k\ge1$, one globally correct deterministic SAT program takes $O_i(n^k)$ time on every marked proper file of row $i$. In particular, at $k=1$ this holds for up to $n$ candidates per dyadic length, even though printing every file afresh can cost $\Theta(n^2)$ bytes. The hypothesis concerns the whole update stream through the required marks. [Tally construction for individually printed candidates](unary-tests-for-program-indexed-sat-witnesses.md)

**Unary reconstruction.** Assign to trial $r$ and candidate $j$ the length $m_j=2^r(2(n+j)+1)$. Given $1^m$, count its length, remove its power of two, and set $u=((m/2^r)-1)/2$. Reject $u=0$. The highest set bit of $u$ gives $n=2^{\lfloor\log_2 u\rfloor}$, then $j=u-n$ and $i=\nu_2(r+1)$. Replay $G(i,n)$ through **at most $m_j$ generator steps**, stopping on mark $j$ if it occurs. Accept exactly if the mark was timely and its buffer holds a satisfiable proper formula. An out-of-range edit or malformed stream event before the chosen mark rejects. Later events have no effect. Zeroing the buffer, reconstruction and SAT verification take $O(m)$ time with one fixed constant. A digit trie identifies occurring variable names and guesses their truth bits on first appearance. Long names cost time proportional to the digits read. The generator is one fixed native transition system. The verifier and the solver below count the same guest steps at the same guest width, excluding wrapper instructions. A sufficiently wide fixed host can mask the guest's word operations and hold a separate guest memory bank. Substituting a general interpreter requires charging its canonical microsteps in *both* replays.

**Searching with the original file available.** On $x$ of dyadic length $n$, consider $r=0,\ldots,\lfloor\log_2 n\rfloor$. Start each trial with the same zero buffer and the number $d$ of positions where it differs from $x$. For an edit at $p$, subtract $[\mathrm{old}\ne x_p]$, overwrite that byte, and add $[\mathrm{new}\ne x_p]$. Thus $d=0$ is exact equality at every mark, including after repeated updates to one position. In one replay through $m_{n-1}=2^r(4n-1)$ steps, match mark $j$ only if $d=0$ and its generator timestamp is at most $m_j$. A late mark can be followed by a timely one. For example, at $n=2,r=0$, marks at times 6 and 7 face deadlines 5 and 7. Stop the replay on a malformed event, on the last mark, or at its overall cap. On the first valid match run the deterministic decider on $1^{m_j}$ and return its answer. If every trial fails, or $n$ is nondyadic, use an exhaustive SAT fallback. No mark can change the verdict on a different input because equality was exact.

For row $i$, take a fixed $r_i$ with $\nu_2(r_i+1)=i$ and $2^{r_i}(2n+1)\ge A_i n$ for all $n$. Such trials are unbounded for each fixed $i$. On all sufficiently large lengths the solver reaches this trial or matches earlier. The total guest work through it is $O_i(n)$ by the geometric series. Initializing the $n$-byte buffers costs $O_i(n)$ too. Logically fresh generator scratch can use per-trial tags or a log of touched addresses cleared in time proportional to the preceding trial's accesses. The original input stays pristine. Only one unary decision is needed, on length $O_i(n)$, and its unary input can be written in $O_i(n)$ time. For arbitrary unmatched inputs, $m_{n-1}<4n^2$ throughout the bounded search, so one fixed wider host suffices also for the unary decider's virtual words and addresses. Finitely many small files per row can be absorbed into the row's constant.

**Physical sign edits.** Three disjoint triples on variables $(1,2,3),(4,5,6),(7,8,9)$ each get the seven clauses forbidding the Boolean triples other than all ones. Append the cross-clause line `-1 -4  7 0` with two spaces before `7`. Its positive literal makes the unique all-ones assignment a model. Replacing the `-` before `4` with a space preserves that unique model. Restoring this byte, then replacing the *second* space before `7` with `-`, gives an unsatisfiable proper file. Other rows use disjoint triples, so the cross-clause remains distinct in all three cases. Pad inside a separator to a requested dyadic file length. On disjoint copies, initialize the base once, mark it, and apply, mark and undo each individual sign edit. One can use $\Theta(n/\log n)$ copies while leaving space for their distinct decimal names. Initial output and the entire sequence of edits take $O(n)$ time. This example displays both verdicts without embedding their labels in the output interface.

The [executable audit](dyadic_edit_stream_audit.py) compares independent per-candidate reconstruction with shared scanning on 88,888 finite clocked cases, including repeated edits. It checks the late-then-timely boundary separately and counts the models on twelve physical proper files at dyadic lengths from 256 to 2,048 bytes. The global transfer and runtime bounds are manuscript arguments. They supply a conditional test on explicitly generated candidates and leave the unrestricted SAT time question open.
