# Work forced after the last previously unseen data word

Suppose a deterministic program decides ordinary SAT in $O(N\,\mathrm{polylog}\,N)$ time on an aligned-read logarithmic-word RAM with unrestricted workspace. Fix a sufficiently large constant in the word width so that a complete query packet fits in a word. On arbitrarily long proper DIMACS files there is a pair, one satisfiable and one unsatisfiable, differing in exactly one physical bit, with the following behavior.

* The runs have identical instruction, address and reply histories through the address of the load that finishes covering **all data-bearing input words**. Their first different reply is the value of that word.
* After that load, **both** runs must read $\Omega(\log N/\log\log N)$ distinct old input or work words. An old work word counts only if the suffix reads it before its first suffix write to that address. The final packet, fixed public input and the initial registers are free in this count.
* On the family below every satisfiable file has a unique model. One globally correct solver takes $O(N)$ time on the entire family, with only $O(\log N/\log\log N)$ steps after the last new data word. The tail bound is tight even though this family permits cold linear time.

The proof needs only a near-linear, up to polylogarithms, number of nonzero work words just before the last packet in the executions used by the adversary. Prefix time can be arbitrarily large under this storage hypothesis. Equivalently, fix an exponent $K$: at every sufficiently large family size a solver must exceed the corresponding prefix storage cap $N\log^K N$ on some input, or have a pair with the stated tail, with the implicit lower constant depending on $K$. The machine chooses its own input read order from its first instruction on an already complete immutable file. ## A static query placed at the solver's actual last discovery

Consider a SAT template with a public fixed region and $p+1$ interchangeable aligned input words, each containing a packet of complete clauses. For one database there are $p$ data packets. The additional packet contains a query. Any permutation of these packets has the same SAT verdict. Fix any order of the database packets. Simulate the given solver offline until it requests a previously unseen packet. For the first $p$ such requests, install the next data packet at the requested address. On a repeat, give the same packet. Supply all public words normally. Stop immediately before the next new packet is read. The surviving position, the arranged data words, the registers and the work memory at this cut are independent of the query.

Every partial arrangement has a completion to an ordinary file. In our signed templates there are two possible query packets with opposite verdicts for any fixed query indices, so the solver cannot halt before requesting the last position. It cannot run forever on the common prefix either, since any one completed file then gives that same infinite computation. At the cut choose the actual query word and freeze the whole arrangement. Determinism proves that the complete native execution on this file has precisely the recorded prefix. Thus the data structure built by this procedure can answer a subsequent externally supplied query using a suffix of a real **cold** execution; the original solver itself never receives an external query or a prescribed discovery order.

Save the frozen input words in an array, and the prefix's nonzero work address/value pairs in a linear-size constant-probe static dictionary. Each word-sized address has a default of zero. Include the constant-size controller and the last address. Static preprocessing is unrestricted in the lower-bound model. After inserting the known final word, replay the real suffix. Any work store is kept in free per-query local storage. First incoming values at distinct old addresses can be read once and cached there, including zeros. The public input and final packet are known. Thus $u$ distinct old words on a suffix suffice for $O(u+1)$ cell probes, regardless of how many native instructions separate the probes. This use of free query computation only strengthens the simulator. [Deterministic static dictionaries](https://www.rasmuspagh.net/papers/det-jour.pdf)

The pair version needs both suffixes to be expensive. Given the query indices, emulate its two complementary tag choices from the one frozen state, alternating by requests for previously unknown old cells. Between requests the simulation is free. The first halting simulation gives the static answer because its tag is known. If one of the two real suffixes always used at most $u$ distinct old words, this procedure would need $O(u+1)$ probes in the worst case. A static lower bound therefore gives one pair for which **each** suffix pays. There is no assumption that their addresses agree after the differing reply.

## The physical formulas

Use a butterfly of depth $d$, degree $B=2^{\lceil4\log_2(d+2)\rceil}$, $V=dB^d$ nonsinks and $E=BV$ possible edges. A source and sink determine one possible path. At level $i$, an edge belongs to this path exactly when the source has its specified suffix and the sink has its specified prefix. The database says which edges are present. [Pătraşcu, Theorem 2 and §5](https://arxiv.org/pdf/1010.3783)

In the fixed CNF put one Boolean presence variable per potential edge. Give each source and sink a leaf variable. Impose exactly one selected source and one selected sink. For example use complete binary OR trees with equivalence gates, assert each root, and forbid both children of any node to be true simultaneously. The two digit orders generate the required suffix and prefix flags as in the warm-query construction. For each edge a deterministic gate computes the clause saying that its presence is required if its two path flags hold. A final AND equals the reachability answer. Give this output and its forced complement two equal-length decimal identifiers ending in 2 and 3 with the same preceding digits. Gates, flags, any declared filler names and padding anchors have uniquely determined values once the edge bits and endpoint choices are fixed.

A data packet contains a unit pinning one edge variable and two public satisfied clauses. A query packet pins its source leaf, its sink leaf and one member of the output/complement pair by positive units. Pad short clauses with fixed false variables disjoint from the clause; seven proper ternaries on three new anchors can select their all-zero assignment. A satisfied padding row may use their three distinct negations. Gate definitions can simplify duplicate or constant literals before padding. Each packet has three proper complete clauses. The two query tags differ in the low bit of a single ASCII digit. Every valid ordered data packet list sets each edge value exactly once. A selected sign of the Boolean path answer gives one model; its opposite gives none.

All identifiers have $O(\log(E+2))$ bits, and the fixed region and $E+1$ variable packets use $O(E\log(E+2))$ bits. For definiteness one can choose the total encoded bit length $N=2^h=\Theta(E\log(E+2))$ with a sufficiently large constant factor and the standard aligned RAM convention $w=8C\lceil\log_2(N+2)\rceil$ bits for a fixed large $C$. Each packet then fits one word. Add public DIMACS whitespace before the variable region to align it, within each packet to fill its word, and after the formula to fill its declared length. Choose $C$ first, then the padding factor. The header clause count and every byte outside the advertised words are common to the whole family. All lengths are part of the usual explicit input; the fixed region is free only to the lower-bound simulation. For a narrower fixed word coefficient a packet can span a bounded number of words: the same proof locates the first touch of the last previously untouched packet. Claiming that its first touch reveals all remaining bits uses the stated one-word packing. This note assumes aligned native reads.

Word width matters to the storage-only conclusion. In the narrower convention $w=\lceil\log_2 N\rceil+O(1)$, the literal final word has only $O(N)$ possible values. A solver with unbounded prefix time can hold out a chosen data word, compute the verdict for every possible reply using a virtual input, and pack all answers into $O(N/w)$ words. It then reads the last word and one stored answer word. Ordinary brute-force SAT fits in $O(N)$ scratch words, so even the total storage is linear, with the usual choice of a width constant/additive offset leaving enough addresses. One can reduce the scratch requirement to $O(N/w)$ words by storing one assignment bit per literal occurrence, repeatedly comparing encoded names in the virtual input and checking all clauses, with unbounded scan time. Syntactically invalid replies may be handled by the decider's usual parsing rule. This narrow-word example shows why the coefficient in the literal last-word, storage-only result cannot be silently changed.

Pătraşcu's §5 alternatives for a static representation of $S$ words and $q$ probes include $(q/d)\log(Sd/V)=\Omega(\log B)$ or $(q/d)w=\Omega(\sqrt B)$. With $S=O(N\log^K N)$, $\log(Sd/V)=O_K(\log B)$ and $w=O(\sqrt B)$. Hence $q=\Omega_K(d)$ and $d=\Theta(\log N/\log\log N)$. This is where the genuine post-load cost enters. Merely counting which physical input positions the machine ever reads gives no such tail.

For the upper bound validate the public template and ordered-independent packet multiset, building a direct edge array and retaining the query indices when encountered. Read the public region and trailing padding before the variable sweep. Parse each packet, enforce key ranges and detect any duplicate; use counters and the common inventory to validate the whole input. On a failed check use a complete SAT procedure. If validation passes, test the $d$ edges by successively replacing butterfly digits. These updates need constant arithmetic operations per level. Packed decimal names of $O(\log N)$ digits can also be read in constant native time per field with a small public preprocessing table. Split them into chunks of at most $\lfloor\log_2 N/16\rfloor$ bytes, tabulate powers, digit validity and integer values at all possible raw chunk words in $O(\sqrt{N}\,\mathrm{polylog}\,N)$ preprocessing time, and combine the constant number of chunks. Fixed-width packet fields or direct prefix dispatch avoid searching for unknown field boundaries on the last instruction block. Hence even when the query or the last missing edge is read last, the remaining native time on these files is $O(d)$; usual one-time validation and preprocessing take $O(N)$.

The proof charges distinct accesses to data from *before* the cut. A solver can copy its input into work memory, or keep the input and read it again, so separating those two sources requires an additional hypothesis. The earlier finite signed pairing construction can make a huge number of opposite-verdict pairs reach their final covering load within a packed scan. The butterfly lower bound forces further real instructions for both members of such a pair. Its contribution remains additive after one cut.
