# Many powered walks on one SAT database

A batch of $Q$ walks on one shared balanced database of $s$ rows and $B$ columns has an all-good matrix of binary rank $2^{\Theta(s\min\{Q,B\})}$. The same exponent holds for the SAT verdict “some selected bit is zero.” At $Q=B/2$ this is a $\Theta(B)$-fold gain in **log rank** over a single walk, at the same order of physical formula length. Every selected miss has an actual satisfying assignment of a proper DIMACS file with only one copy of the data packets. Nevertheless one globally correct deterministic SAT program decides all the canonical batch files of $N$ bits in $O(N\log\log N/\log N)$ native steps. It recovers every walk's answer in that time. The construction explains both the gain from adding walks and the stopping point for that proposed induction.

## The proper files and the rank increase

Use the [powered-walk compiler and size parameters](near-complete-disclosure-on-one-bit-sat-pairs.md). There are $s$ rows with $B=\Theta(\log s/\log\log s)$ columns, a $B$-vertex square torus of even side, and independent $d$-row segments with $d=\Theta(\log s)$ dividing $s$. A segment seed is an initial column and $d-1$ labels of the $D=16^{160}$-regular powered walk. Its bits fit in $h\le(\log_2 s)/256$ bits with the original fixed parameter constants. Take $Q$ a power of two with $Q\le s^C$ for fixed $C$. The original dyadic choices of $s,B,d,h$ work. Let $w=\Theta(\log N)$ be the aligned native word width with the original sufficiently large fixed coefficient.

Keep the public gate libraries for the $h$-bit data masks and segment-seed predicates. Add $\log_2 Q$ free Boolean query selectors. The formula guesses a query ID, one row, and one column. Its data multiplexer uses only column and row selectors and therefore still uses $p=sB/h$ packets. Its seed multiplexer uses the high row bits followed by the query selectors and consumes $Qs/d$ seed packets in logical batch order. Require that the guessed bit be zero and that this seed select the guessed column. The optional one-bit tag restricts the guessed row to its designated half. All gates, pads, aliases and packet clauses have the same proper ternary implementation as for a single query. Once the selectors are fixed the gates and pins have a unique extension when those requirements hold. A batch can contain repeated walks.

Public circuit generation needs $O(p+Qs/d+d2^h+\operatorname{polylog}s)$ clauses and native iterations, since every gate in a high-address selector tree costs a constant and the two low-address libraries are shared. Each logical packet occupies an entire physical word and may occur in any packet order. Padding and decimal lengths give $N=\Theta(sB+Qs)$ as in the single-query layout. In particular $N=\Theta(sB)$ throughout $1\le Q\le B/2$. At $Q>1$ a size-only DIMACS comment supplies public layout parameters. The compiler leaves the original bytes unchanged at $Q=1$. [Implementation](packed_row_queries.py)

Pair the positions in each horizontal torus line consecutively. For every $y$, the shifted shear $x\mapsto x+2y+1$ followed by the inverse plain shear translates $x$ by $+1$. Reversing the two elementary motions translates by $-1$. Fill the rest of the 160 labels with holds. Either member of each horizontal pair can therefore stay or move to the other in **one powered step**, on every row transition. This argument works off the horizontal axis too.

Take $m=\min(Q,B/2)$ disjoint pairs. In each data row $i$ independently select the good endpoint $x_{i,p}\in\{0,1\}$ of each pair $p<m$. Give every unused pair its first endpoint as a good entry. Each row is balanced. Query walk $p$ visits the endpoint prescribed by an arbitrary independent $y_{i,p}$ at every row. It starts each new segment at the required column. If $Q>m$, duplicate the first walk. All selected entries are good exactly when $x=y$ on **all $sm$ bits**. The identity submatrix therefore has order $2^{sm}$. Its complement over $\mathbb F_2$ has the same rank: with $J$ all ones, $(J+I)^2=I$ because $2^{sm}$ is even. The SAT matrix without a tag tests the complement. A fixed half tag has the same argument with half as many rows. [Lean identity, complement rank and shear calculations](BatchedWalkEquality.lean)

The same family embeds all partial-assignment tests on $s\min(Q,B/4)$ coordinates. Tile the torus by disjoint two-by-two squares, assign one lane to each used square, and choose as good entries one of its two lower endpoints together with its upper-left corner. The fourth entry is zero. Unused squares also have exactly two ones. At every row the query may require either value of its data bit by selecting the corresponding lower endpoint, or leave the bit untested by selecting the always-good corner. Any two corners of a square are connected within a powered transition: the vertical shear pair translates by one in the other coordinate, so at most four elementary labels and holds suffice. This gives an independent symbol from $\{0,1,*\}$ at every row and lane. In particular ordinary set disjointness on this many bits is represented by requiring zero or leaving the bit untested. No collection of auxiliary queries or summation over responses is needed.

No database contributes more than $sB$ bits to log rank. The total number of separately encoded labeled batch queries is $(B D^{d-1})^{Qs/d}$, whose base-two logarithm is $O(Qs)$ with fixed $D$. These two bounds give the asserted order of the log rank. If the entire batch instead has a fixed $b$-bit description, the rank of any scalar answer matrix on these data is at most $2^{\min(b,sB)}$. Thus an identity with $2^{sm}$ rows forces $b\ge sm$. The explicit queries use $\Theta(sQ)$ physical bits, optimal up to constants for this specific amplification while $Q\le B/2$.

**Actual opposite tags.** Run the data-first packet construction for these restricted databases. At the first $p$ distinct packet requests install the data in logical order. Until the next new request every binary payload has completions making one row half entirely good and the other half contain a miss. Choose $y=x$ on the first half and flip one lane in one row of the other half, then exchange the tag. A correct decider must request another packet. Put the tag there and the segment seeds at the remaining addresses in sorted physical order. The two actual completions differ in a single ASCII bit and have opposite SAT verdicts. Over the whole set of binary completions the OR of the two tag verdicts is the untagged verdict. The number of unread packets is $R=1+Qs/d$ among $p+R$ total; it is a vanishing fraction when $Q=o(B)$ and a constant fraction at $Q=B/2$. Encoding the pending subset and designated tag address needs $O((Qs/d)\log(2+B/Q)+\log N)$ bits for $Q\le B/2$. This is $o(sQ)$ uniformly. The physical order of installed data is already represented in its cut-state features, as in the original proof.

### The same full query with any ordered pair of row blocks

Take a power of two $t\le s$, and partition the rows into $t$ equal consecutive blocks. In the optional two-block format two additional packets specify an ordered pair $u,v\in\{0,\ldots,t-1\}$. The one-bit tag selects $u$ on its zero side and $v$ on its one side. The **complete** $Qs/d$ seed packets retain their original meanings on the full physical file. Changing either selector or the tag changes none of them. In particular a disagreement in a third block remains encoded on both sides.

The public gates test the high $\log_2 t$ row bits against each possible block ID. Two packet flags are equated to the named tests for $u$ and $v$. A fresh Boolean tag selector multiplexes these two flags and the result must be true. The existing two consecutive positive DIMACS aliases are now tied to the tag selector and its complement, so either tag spelling is exactly the same width and differs in one bit. Fixing the tag also fixes its selector. A satisfying assignment guesses a miss from any of the full query's walks, at a row in exactly the chosen block. The ordered pair may repeat the same block. These extra public tests cost $O(t)$ gates, so the lengths become $\Theta(sB+Qs+tw)$ up to the existing word-compatibility constants. In particular, for fixed $t$, or $t=O((sB+Qs)/w)$, the earlier length bound holds.

For $t\ge2$ the same adversarial placement installs only the $p$ ordered data packets first on the actual machine. After the data are fixed, completions of the binary pair payload can agree throughout any selected block and disagree at a row of a different block. Consequently the next fresh packet request must occur. Put the tag there. Assign the remaining $Qs/d+2$ logical packets (all full query seeds, then both selectors) to the other pending physical addresses in increasing order. This prefix and its placement are independent of $y,u,v$ and both tag values. It supplies files on which the two actual continuations have precisely the two indicated block verdicts. The header bound only gains the two extra pending slots. The packed scanner verifies both selector packets and restricts its accumulated miss bits to the chosen range; it may run its row-group table with all-ones data masks outside that range, retaining all transitions and the correct start at an interior boundary.

## A packed algorithm for all the answers

The program handles every packet permutation of the canonical files. First verify the public circuit and all packets and restore the numeric row masks and the seed ID for every (query, segment). A block lexer on $\lfloor\log_2 N/32\rfloor$ bytes precomputes the token delimiters, validity, lengths and decimal values of all pieces. Its uniform table costs $N^{1/4}\operatorname{polylog}N$ time. Each canonical decimal token spans $O(1)$ blocks and the table entries can be iterated at a cost of one step per token or block. Combine boundary digit strings numerically using precomputed powers of ten. There are $O(N/w)$ tokens and blocks, so this costs $O(N/w)$ steps including padding. Compare the public clause sequence, numerically, with the generated gates and check the header counts, parameter bounds, tag and every packet including its flag ID and permitted seed range. The IDs index dense arrays; reject the fast path on a repeated or missing packet. Restore consecutive data masks in a packed array without emitting a separate word for each logical row. The original $Q=1$ layout parameters are recoverable from the public circuit as in [the single-walk verification](nonlinear-work-after-the-one-bit-sat-cut.md). On a failed check invoke complete SAT. Every template the scanner accepts has the proved semantics; malformed candidates can be declined before any oversized allocation. [Packed decimal parsing conventions](packed-normalization-of-dimacs-clauses.md)

Write $L=640$ for bits per powered label. Let $r$ be a power of two of order $\log w$, dividing $d$, and let $t$ be a power of two of order $w/\log w$ with $t\le d/r$. Use small fixed constant factors, so that
$$
 rB+t\log_2 B+t\lambda\le (\log_2 s)/4,\qquad
 \lambda=2^{\lceil\log_2(rL)\rceil}.
$$
Such choices exist because $B=\Theta(w/\log w)$ and $d=\Theta(w)$. A universal table takes $r$ consecutive row masks, $q\le t$ starting columns and $q$ pieces of $r$ powered labels each, with each piece padded to $\lambda$ bits. It returns the $q$ terminal columns and $q$ bits recording which walks encountered any zero. Examine the starting position on each row before applying its transition. The $r$th transition supplies the correct start for the next group. Ignore the final segment endpoint using an arbitrary fixed padding label. Include every power-of-two panel width $q\le t$. Exhaustive generation by direct walk simulation costs $s^{1/4}\operatorname{polylog}s$. Separately tabulate for each full seed its starting column and its $d/r$ successive fields with the required padding. This costs $O(d 2^h)$ steps, and each seed's fields occupy $O(1)$ native words (indeed $\lambda d/r\le 2Ld$). All these setup costs fit within $O(sB/w)$.

Process at most $t$ queries per panel. Since $Q,t$ are powers of two, every panel has the same $q=\min(Q,t)$. At each segment, obtain $q$ prepacked seed words. Each has $d/r$ fields. Partition the **field columns** into tiles of $q$ and transpose every $q$-by-$q$ tile simultaneously. The row of the word and the low $\log_2 q$ bits of the field position exchange roles; the higher field-position bits stay fixed. To exchange bit $j$ of these two indices, pair words whose row indices differ only at $j$. In each pair swap the fields in which the two index bits disagree, using a fixed mask, shifts and XOR. This takes $O(q)$ word steps per stage, hence $O(q\log(2q))$ for the whole layout change. The transposed labels for group $a$ form one contiguous field group in output word $a\bmod q$, starting at field $a-(a\bmod q)$. The transposition adapts the usual square-word bit-swap algorithm by preserving the high field-index bits and the bits inside each field. [Boyle–Naor, Claim B.2](https://eprint.iacr.org/2015/863.pdf)

Pack the starting columns in $O(q)$ steps, then traverse the $d/r$ row groups. Each group's row masks occupy at most a constant number of adjoining words. The transposed label group, row masks and the previous terminal columns form its table address. Accumulate the returned flags with bitwise OR, including across segments for the same batch panel. Report the flags for the requested row half or evaluate the entire file. The total time is
$$
 O\left(\frac{N}{w}+\frac{s}{d}\left\lceil\frac{Q}{t}\right\rceil
            \left(q\log(2q)+\frac{d}{r}\right)\right)
 = O\left(\frac{sB}{w}+\frac{Qs\log w}{w}\right).
$$
Here $s/r=\Theta(sB/w)$ pays for a short panel and $rt=\Theta(w)$. This proves the claimed bound for all $Q\le s^C$. For $Q=O(w/(\log w)^2)$ it is $O(N/w)$ even when the program returns all $Q$ verdicts. For $Q\ge s^\delta$ with fixed $\delta>0$, a second algorithm also costs $O_\delta(N/w)$. Choose $r'=\Theta_\delta(\log s)$ dividing $d$ small enough that $BD^{r'-1}\le\sqrt Q$. Precompute the hit flag of every possible $r'$-row piece separately for each actual row group, in $O(s\sqrt Q)$ total steps. The seed library can precompute the piece ID including the actual start at every boundary for each complete seed. Each query/segment then needs $O_\delta(1)$ lookups, and $s\sqrt Q=O(Qs/d)$. The intermediate batch sizes are covered by the general transpose algorithm.

## A sparse prefix for the scalar batch verdict

The free-affine suffix measure has a second upper bound, valid on the complete powered-walk family. Use a scanner that sees the canonical ordered data before requesting the tag and that validates all packets, with the same complete fallback. Partition the $sB$ consecutive database bits into blocks of $b=\lfloor c\log_2 N\rfloor$ bits for a fixed small $c>0$, padding the final block. At a fixed physical base for each block, write a one in the slot indexed by the block's actual value; every other slot has its initial zero. Only one word per block is written into these ranges. The distinct ranges fit in the native address space. The data-only prefix takes $O(N)$ real steps including public checks.

With all seeds and the tag supplied, the target coordinates in each block are known. Within each block, XOR the contents of exactly those sentinel slots whose index has a zero in at least one targeted coordinate. This is the correct miss flag since exactly one slot is nonzero. The addresses and the choice of XOR terms depend only on the disclosed query, so that even the potentially long enumeration incurs no affine charge. Pack the flags of $w$ blocks into one word by public shifts and XOR and do one zero test per resulting word. Thus both tag continuations of the scanner have $O(1+sB/w^2)$ charged operations, for arbitrary walks and any $Q$. At $Q=B/2$ this is $O(N/\log^2 N)$ after an actually linear prefix. For $Q\le B/2$ the full scan of all candidate slots can be realized in $O_\delta(N^{1+\delta})$ native steps for each fixed $\delta>0$ by choosing $c$ small enough. The fast all-verdict algorithm above instead bounds ordinary time on every packet ordering. These are different implementations. The sparse bound concerns the scalar disjunction of misses on the selected half. [Affine charging at a native cut](nonlinear-work-after-the-one-bit-sat-cut.md)

## Shared choices across segments

Equality among the segment seeds can compress the query list further. For example, assign each segment to a named variable with one free choice of complete seed, used identically at every occurrence. Ask whether choices exist that select only good bits throughout. Within each name class, intersect the $B$-bit row masks of its segments at each relative row offset. A successful seed for that class exists precisely when a walk meets these $d$ intersection masks in order. In the full powered library, propagate its reachable columns from one mask to the next using the $D$ labeled transitions. This costs $O(dBD)$ per class, with $D$ fixed, and $O(s)$ for the initial intersections once row masks are decoded. For $G\le s/d$ nonempty classes the total is $O(s+GdB)=O(sB)$ steps. This observation concerns identical free seed choices with one shared value per class and a conjunction of successful checks. Arbitrary circuits generating correlated segment seeds have different semantics.

On two independent column pairs and two rows, 512 half-tagged physical files recover the $16\times16$ identity with 256 one-bit changes, 96 of them changing satisfiability. Lean checks the finite identity and rank on both Boolean verdicts and the displacement identities of the torus generators.
