# What the list and matrix tests charge a RAM or a tape

Let $B=2w\,2^w$ be the number of explicitly supplied list bits and let a word have $\Theta(w)$ bits. A deterministic word RAM decides distinctness in $O(B/w)$ steps. Regard each record as two radix-$2^w$ digits, perform two stable counting-sort passes and scan adjacent records. Initializing the counters and output arrays takes $O(2^w)$ word operations. The source network theorem and its Boolean circuit consequence require $\Omega(Bw^\sigma)$ volume and gates for some $\sigma>0$. The journal also exhibits the $O(B/w)$ algorithm on the corresponding dense ASCII SAT files. For a language on every bit length one can test a largest prefix of the specified list length, ignoring the remaining bits, and fix the ignored bits when deriving the circuit lower bound. Successive list lengths have bounded ratio. Thus there is a uniform linear-time word-RAM language requiring superlinear Boolean circuits. [Theorem and verification scope](checking-the-sat-circuit-bound.md) · [Dense SAT projection and fast path](scan-time-on-the-dense-list-projection.md)

The quotient is $\Omega(w^{1+\sigma})$ gates per executed word step **for the complete list computation**. An isolated fixed-address read uses input wires directly. For a different example, a standalone lookup selecting one of $m$ independent $w$-bit words needs $\Theta(mw)$ bounded-fan-in gates for $m\ge2$. All $mw$ data inputs affect the result. The subgraph feeding the $w$ output bits has at most $w$ connected components, so counting gate input edges gives at least $mw-w$ binary gates. A binary multiplexer tree for each bit gives the upper bound. Costs of composing many reads can be much lower than separately adding these standalone costs.

## Tape time

A deterministic ordinary finite-alphabet multitape computation with time bound $T$ has Boolean circuits of size $O(B+T\log(T+2))$ by Pippenger and Fischer. An oblivious schedule already known for this input length gives $O(T+B)$ gates: connect each read directly to the preceding write at the same tape position, or to its initial input symbol. Finite-state updates and reading and writing the fixed number of symbols cost $O(1)$ gates per step. Hence the SAT circuit lower bound gives $\Omega(B(\log B)^{\sigma-1})$ from the former simulation and $\Omega(B(\log B)^\sigma)$ on oblivious machines in the usual worst-case regime. For inversion of the logarithm it suffices to consider $T\le B^2$, since larger times already exceed both thresholds. [Pippenger and Fischer, *Relations Among Complexity Measures*](https://research.ibm.com/publications/relations-among-complexity-measures)

The exponent inherited from **this list family** satisfies $\sigma\le1$. Ajtai, Komlós and Szemerédi sort $2^w$ records with $O(2^w w)$ comparators. A compare-exchange on $2w$-bit records costs $O(w)$ Boolean gates; adjacent equality adds $O(B)$. The resulting $O(B\log B)$ circuit converts to a tensor network with linear overhead. Thus this family and the stated general multitape simulation cannot exclude linear time on ordinary multitape machines, even if the unspecified exponent were optimal. An improved simulation tailored to SAT or a stronger SAT-specific circuit lower bound would be a separate result. The optimum exponent for simulation of arbitrary tape decision computations is not determined by this calculation. [Ajtai, Komlós and Szemerédi, *Sorting in c log n parallel steps*](https://www.researchwithrutgers.org/en/publications/sorting-in-c-log-n-parallel-steps/)

## What a polynomial binary-product bound would imply

Let $G_d(A,B,C)=[AB=C]$ for binary $d$-square matrices, with multiplication in $\mathbb F_2$. As an exact tensor, designating $C$ as output indices or testing a proposed $C$ gives the same zero-one array. An internal contraction need not evaluate as an efficient deterministic multiplication algorithm. Algebraic rank of the formal trilinear multiplication tensor measures a different object. [Existing verification reduction](verifying-matrix-products-from-sat.md) · [Binary witness discussion](binary-witness-cost-of-matrix-products.md)

The mismatch encoding chooses an erroneous entry $(i,j)$ and checks it by selecting row $i$, column $j$, the proposed entry, and their dot product. It uses $O(d^2)$ Boolean gates, and its decision 3-CNF has $N=O(d^2\log d)$ bits. The template is fixed for each $d$ with input entries placed as literal pins. A SAT Boolean circuit of size $s(N)$ gives a Boolean circuit for $G_d$ of size $O(s(N)+N)$ by complementing its answer, then an exact binary-wire network of the same order. A deterministic SAT RAM of time $O(N^k)$ for $k\ge1$ gives an exact binary-wire network for $G_d$ of volume $d^{2k+o(1)}$. For this direction, check a padded deterministic trace, including chronological memory consistency using a deterministic sorting network and the initialization words. On fixed exterior data there is a unique valid trace and unique gate evaluations. Pin the machine's verdict to the no-mismatch answer. Fixed logarithmic-word operations and routing the trace cost $O((T+N)\operatorname{polylog}(T+N))$ gates; internal trace bits are summed. This uses unambiguous verification of the whole RAM computation. [Bounded trace and word costs](packed-band-transfer.md)

Consequently a bit-network lower bound $d^{2+\delta-o(1)}$ for $G_d$ would exclude SAT time $O(N^k)$ for every $k<1+\delta/2$ and give a polynomially superlinear SAT circuit lower bound along the reduction lengths. Equality at the endpoint does not follow. A bounded-fan-in Boolean circuit for the graph itself is obtained from an actual binary matrix multiplication circuit and equality tests. The arithmetic upper exponent initially set a ceiling of $9/8$ on this comparison. The exact signed network now gives graph exponent at most $11/5$ over all fields of characteristic different from two, reducing the ceiling to $11/10$. Thus a polynomial improvement in the SAT time lower bound by this particular graph route would require a different coefficient characteristic.
