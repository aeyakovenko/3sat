# The price of answering SAT with few reads after the last data word

Fix positive integers $k$ and $t\le k$, aligned input loads, and a sufficiently large word-width coefficient depending on $k$. There is an explicit family of proper ASCII DIMACS 3-CNFs of length $N=\Theta_k(m)$ bits, for $m$ a power of two, with this property. Consider any deterministic program $P$ correct for SAT, given the whole file at the start. On every family file of some one verdict, suppose the run uses at most $t$ **distinct old word reads** after the last previously unseen data-bearing input word. At each sufficiently large family size, some satisfiable and unsatisfiable files differing in one bit have the same prefix through the address of that last load, and at its issue there are at least
\[
             \Omega_{P,k,t}\big((N/\log N)^{k/t}\big)
\]
occupied input or work words. For $k/t>1$ the same lower bound holds for prefix **elapsed instructions** on both files, even on a machine with arbitrarily scattered working storage. All work words start at zero. An input word counts only if it is one of the variable packets. The time bound follows by subtracting their $O_k(N/\log N)$ words and charging the remaining nonzero cells to distinct earlier stores.

For $t\mid k$ and $k/t\ge2$, the exponent and the powers of the logarithm are sharp. In particular, with four banks and one old read, the optimal worst-case prefix time is $\Theta((N/\log N)^4)$. With four old reads the same files admit a globally correct SAT program taking $O(N)$ total time. The restriction is on actual suffix reads, irrespective of how long the suffix computes, where the machine places its memory, and which data word its program decides to discover last. Time on SAT with unrestricted suffixes is still open.

## Placing the query on a genuine run

The data are $k$ arbitrary independent bit tables of length $m$. For indices $q\in[m]^k$ and a tag $b$, satisfiability means $F(q,x)=b$, where $F(q,x)=\bigwedge_{j=1}^k x_j[q_j]$. The file consists of fixed syntax, interchangeable data packets and one query packet. Each packet is one aligned native word. The two possible tags for any query change a single physical bit and give opposite verdicts. The construction below makes every satisfiable file uniquely satisfiable.

Fix the database and its canonical list of data packets. Whenever the program first asks for a new packet slot, give it the next data packet, consistently on repetitions, until one slot remains. At every point some pair of complete files with opposite answers extends what the program has read. Correctness forces the next discovery in finite time. Freeze the layout when the last new address is issued, before its reply. For every choice of $q,b$ this prefix is the actual deterministic computation on an ordinary complete input. The register state, layout and memory are all independent of $q,b$. [Detailed prefix argument](work-after-the-last-unseen-sat-word.md)

An old read is a read of an earlier data packet or of a work address before any suffix write to it, counted once per address. This includes a read of an unwritten zero. Reads of public fixed words and the final query, register calculations, and reads after a suffix write cost the simulator nothing. It keeps a local cache of fetched words and private stores. Fix $b=1$. If the suffix is cheap on every satisfiable completion, stop at the request for a $(t+1)$st old word and return false. If the suffix is cheap on every unsatisfiable completion, return true at that request. A halt before the cap returns the real verdict. This is exact in both cases, for every $x,q$. With a uniform cap $S$ on the occupied prefix words of these canonical executions, it gives a static algorithm for $F$. A large prefix found by the lower bound is shared by both signs by choosing the two tags *after* that prefix. A hypothesis on just one verdict suffices.

## Sparse native addresses at their actual communication cost

Alice has $q$; Bob has $x$. Write $w=\Theta_k(\log N)$ for the native word length, chosen large enough for the packet and address range below. Bob computes the cut by unbounded preprocessing. He sends the constant-size control, registers and last address using $O_P(w)$ bits. Treat variable input and workspace as disjoint address namespaces. Their union has at most $2^{O(w)}$ possible keys and at most $S$ occupied keys. A native read of any absent key returns zero. The aim is to spend only $\log_2\max(1,S)+O(1)$ **Alice bits** per adaptive distinct read. Replacing one sparse lookup with a constant number of compact probes would lose a constant in the power $k/t$.

For a fixed size and cap, choose public lists of hash functions by the probabilistic method. No computation-time or uniformity restriction is imposed on the communication protocol.

1. Use a power-of-two number $H$ of buckets between $\max(1,S/w)$ and $2\max(1,S/w)$. Under a uniformly random function a fixed support of size at most $S$ has maximum load at most $L=\min(S,\lceil Cw\rceil)$ with probability at least $1/2$, taking the constant $C$ sufficiently large. Indeed a bucket has mean at most $w$, so a binomial tail and a union bound over at most $2^{O(w)}$ buckets suffice. If $S\le Cw$, the load cap is automatic. There are $2^{O(w(S+1))}$ possible supports. A list of $O(w(S+1))$ functions therefore covers every support. Bob sends one working list index in $O(w)$ bits.
2. In each bucket use a second random function into a power-of-two number $J$ of slots with $2L\le J<4L$. The empty-support case is trivial. The chance of avoiding collisions on any one subset of at most $L$ keys is at least $2^{-L}$. A public list of $O(2^L w(L+1))$ functions covers all such subsets by a union bound. Bob can specify a working list index for a requested bucket in $O(w)$ bits.
3. Alice sends the bucket label. Bob sends its second function index. Alice sends its slot label. Bob sends the slot's original key, value and occupancy bit. Alice uses zero if the slot is empty or the key differs. Her two labels total $\log_2(HJ)\le\log_2\max(1,S)+O(1)$ bits because $HJ=O(\max(1,S))$. Bob's per-read communication is $O(w)$. This handles absent requests and arbitrary reuse exactly. [Lean lookup identity](SparsePacketLookup.lean)

Pad the protocol out to $t$ rounds with dummy messages, and have Alice report the final bit. Total communication is $a\le t\log_2\max(1,S)+O(t+1)$ bits from Alice and $b'=O_P((t+1)w)$ from Bob. Fixed message lengths can be used throughout. The leading coefficient of $\log S$ matters here.

## Counting the rectangles

Restrict the database columns to tables with at least $m/2$ ones in each bank. There are at least $v=2^{km-k}$ such columns and each contains at least $u=(m/2)^k$ positive query rows. For each column Bob's messages are determined by the prior conversation, so it reaches at most $2^a$ distinct leaves. Choose a positive leaf with at least $u/2^a$ rows for that column. There are at most $2^{a+b'}$ transcripts. Some one chosen transcript therefore has at least $v/2^{a+b'}$ columns. Its rectangle consists entirely of positive entries and has at least $r=u/2^a$ rows. This is the deterministic richness argument. [Miltersen, Nisan, Safra and Wigderson, Lemma 5](https://www.math.ias.edu/~avi/PUBLICATIONS/MYPAPERS/MILTERSEN/JOURNAL/final.pdf)

If the rectangle has row set $R$, each column must contain a one at every site in every coordinate projection of $R$. The projection sizes have product at least $|R|$, hence sum at least $k|R|^{1/k}$. The rectangle has at most $2^{km-k r^{1/k}}$ columns. Comparing the two bounds gives
\[
       \tfrac{km}{2}\,2^{-a/k}\le k+a+b'=O_{P,k,t}(w).
\]
Here $S\le 2^{O(w)}$ can always be assumed. Substituting the bound on $a$ proves $S=\Omega_{P,k,t}((m/w)^{k/t})$. The finiteness of each size lets us take $S$ to be the maximum over all its realized cut states.

The same exponent holds for a pair with **both** suffixes above the probe budget. Use two separate simulations, one per tag. Each accepts only if it halts within its $t$ probes and its decoded answer is $F=1$; a truncated simulation rejects. Every accepting rectangle consists of true positive entries. If at each positive entry either sign halts within its budget, the union of these rectangles covers every positive entry. A column reaches at most $2^{a+1}$ leaves across the two protocols, and there are at most $2^{a+b'+1}$ leaves in total. Repeating the rectangle proof with the extra factors of two gives the same $S=\Omega_{P,k,t}((m/w)^{k/t})$. Hence with a smaller cap on all these prefixes, some $x,q$ with $F=1$ has a costly suffix on *both* files. Running the two procedures serially in a single deterministic protocol would have charged twice as many probes. Counting their sound accepting rectangles avoids that loss. ## Encoding the table bits and the final query in linear length

Write $s=\log_2 m$. Choose a power of two $h=\Theta(s)$ with $h\le s/8$ for sufficiently large sizes. Divide a bank into $m/h$ chunks of $h$ bits. For each bank the fixed region provides two separate one-hot selectors, one for the high chunk index and one for its low bit offset. Binary OR trees with a true root, deterministic OR gates and mutual exclusion at every pair of siblings enforce one-hotness in linear size. Once a selected leaf is pinned in each tree all auxiliary values in the trees are determined.

Give bank $j$ one value variable $v_j$. For every $h$-bit mask $\mu$ reserve a name $M_{j,\mu}$. For every low index $i$ put in the fixed region the two clauses enforcing
\[
       \mathrm{low}_{j,i}\;\Longrightarrow\;
       (M_{j,\mu}\leftrightarrow [v_j=\mu_i]).
\]
A variable packet for bank $j$, high index $a$ and mask $\mu$ contains the single effective clause $\neg\mathrm{high}_{j,a}\lor M_{j,\mu}$ plus satisfied rows. There is one such packet for every $j,a$. At the selected high chunk this forces $v_j$ to be its selected bit. The clauses for all unselected chunks are satisfied by their negated high-index literals. All mask names now have unique values. Fixed deterministic gates form the AND of the $v_j$ and its complement. The query packet contains $2k$ units pinning the selected high and low indices plus one positive unit pinning the tagged output. Use adjacent output names with the same decimal digits except the last digit 2 and 3, respectively. Thus changing $b$ flips exactly one ASCII bit. All other packets have the same $2k+1$ complete proper ternaries after padding. Three public false anchors, fixed by seven proper clauses, permit distinct-literal padding, and their negations permit satisfied filler rows.

The mask identifiers can be decimal strings with a fixed nonzero bank prefix followed by $h$ digits chosen from 0 and 1. Reserve those ranges and pin undeclared intermediate names to a fixed value to make the numbering dense; $O_k(10^h)$ filler names suffice. Allocate the remaining names in contiguous ranges with an arithmetic rule for their high and low indices. The construction has $O_k(m/h+h2^h+10^h)$ fixed clauses plus $O_k(m/h)$ data packets, with $O_k(s)$ bits per clause. Its bit length is $O_k(m)$, and the packet region alone has $\Omega_k(m)$ bits. Choose a common padded total bit length $N=2^a=\Theta_k(m)$ for each size and $w=8C_k\lceil\log_2(N+2)\rceil$ with $C_k$ fixed sufficiently large to hold $2k+1$ padded clauses and address the tables in the upper bound. Aligned packet positions are public; use fixed DIMACS whitespace to fill each word. Fixed fields or whitespace padding make each field's boundaries public within each packet format. Correctness applies to full ordinary SAT files independent of how a program reads them. Single native word packing assumes aligned loads and this word-width coefficient. On a narrower machine the packet argument by itself locates a last previously untouched block of a constant number of words.

## A matching program and the ceiling of the argument

Split the $k$ banks into $t$ groups of at most $g=\lceil k/t\rceil$ banks each. Split each bank into blocks of $\lfloor w/g\rfloor$ bits, padding the last block. For every tuple of block indices in a group store one word concatenating the corresponding blocks. There are $O_{k,t}((m/w)^g+1)$ words to generate. A query uses one old read per group, extracts its selected bits by shifts and takes their AND. A direct table of single bits would miss the power of $\log N$ in this comparison. When $g=1$ this just reads the original packed banks.

To implement the upper bound on genuine files, choose the input read order in the program. Validate the public region and trailing padding before scanning the packets. Process all but the last packet, validating keys and detecting duplicates. Keep the missing key when necessary via a running XOR against the public inventory. If the query is still missing, all banks are complete. Build the grouped table before loading the last word. On that word validate the query and its fixed punctuation, decode its $2k$ indices in registers, and compute the $t$ word addresses and AND. Parsing the final word byte by byte takes $O_k(w)$ operations with no data-dependent lookup in old memory. If the query arrived earlier, exactly one data key is missing. Before loading the last packet keep its expected key, the selected offset if relevant, and the AND of all already available selected bits in registers. The final word can then be validated and its contribution extracted with no inherited read. Fixed $k$ allows a constant number of registers, or private scratch initialized by suffix writes. On any failed validation use a full SAT decider; correctness on arbitrary files follows because the fast return certifies an exact member of the template. Generation and checking of the fixed syntax, masks, packet inventory and initial packed banks take $O_k(N)$ operations. Enumeration of block tuples takes constant time per tuple for fixed $k,t$. Thus total time on every family file is $O_{k,t}(N+(N/\log N)^g)$. In the divisible case with $g\ge2$ this matches the necessary prefix time.

This also tests the proposed induction in machine size. Adding a bank raises the static exponent when the suffix probe budget stays fixed. A solver can instead read the extra table once. Repeating this construction therefore gives no induction against a solver free to increase its suffix budget. Moreover, in a model granting free local computation, rereading all variable input words suffices to recover the entire file at every single cut. Adding lower bounds at several cuts requires proving that their charged operations are disjoint on an actual run.
