# The exact affine cost of repeated RAM reads on one execution

Let a memory table $T$ have $M=2^s$ cells of $b$ bits each, with $s,b\ge1$. Supply $t\ge1$ addresses $a_i\in\mathbb F_2^s$. Treat all table bits and addresses as independently editable inputs. Fix an actual table $T_0$ and an execution on which all $t$ addresses equal the same $a_*$. Write $h$ for the largest dimension of an affine space through $a_*$ on which the vector-valued function $T_0$ is affine. This value always exists and is at least one.

**The minimum number of independent affine equations through this input that make all $t$ replies affine functions of the input is**
$$
 C(T_0,a_*,t)=\min_{0\le p\le h}
       \big\{t(s-p)+b(2^p-1)\big\}.                                      \tag{1}
$$
The equations may mix arbitrary table bits and all the addresses. They need not fix the addresses or make them independent. If $t$ additional $b$-bit words are supplied as replies, the least codimension of an affine flat through the honest input on which every reply is correct is exactly $tb+C(T_0,a_*,t)$. Affine changes from independent address seeds to addresses determined by earlier replies preserve both results.

For an isolated read (1) gives $s$, for any $T_0$ and any payload width. For a batch of $t=2^s$ reads with $b=s$, it gives $t\log_2 s+O(t)$ on a zero table and $t(s-1)+s$ on the field-cubing table below. The requested addresses and the actual reply words are identical in these two executions. On an ordinary proper DIMACS representation, the value $tb+C$ is an exact lower bound on the number of affine input dimensions lost by the corresponding SAT run when its final yes/no control decision is included. A single globally correct program attains the bound and runs on the entire layout in packed scan time.

The graph of a single table lookup and its tensor cut ranks have been studied elsewhere. Parity-query certificates and the lifting properties of the index function also have a literature. Here the quantity is the largest affine flat through a **specified table and address tuple**, with joint restrictions on all reads. Priority for (1) is unestablished. ## Why changing the address with the table cannot evade the bound

Suppose $E$ is any affine flat through the specified input on which the tuple of replies is affine. Its projection to the table coordinates is a flat $P$. Let $B$ be the space of **pure address directions** along $E$, namely the kernel of this projection on its direction space. For read $i$ let $U_i$ be the projection of $B$ to address $i$, and put $p=\max_i\dim U_i$. Then $\dim B\le tp$. On the fixed table $T_0$ the affine reply has a linear derivative on $B$. At position $i$ this derivative factors through $U_i$, because a direction leaving address $i$ fixed also leaves its reply unchanged. Write the resulting map as $\lambda_i:U_i\to\mathbb F_2^b$. It follows at the specified point that $T_0$ is affine on $a_*+U_i$, whence $p\le h$.

Choose $i$ attaining $p$. For **every** table $T\in P$ some address tuple gives a point of $E$. Translating that point along $B$ proves
$$
 T[a_i+u]=T[a_i]+\lambda_i(u)\qquad(u\in U_i).
$$
The starting address $a_i$ may depend on $T$. Still, at least one coset of $U_i$ in the address space must have all the prescribed differences. Choose a base point in each coset. Use as table coordinates its base word and the differences of every other word in that coset from the base. This is an invertible binary linear map. Each coset gives a disjoint block of $d=b(2^p-1)$ difference bits. Every table in $P$ has some block exactly equal to its prescribed target.

**Disjoint-block lemma.** If a nonempty affine flat consists entirely of inputs with at least one such target block, its codimension is at least $d$. To prove this, suppose its equations have rank $c<d$. Within each block, changes supported on that block alone have a nonzero vector in the kernel of all $c$ equations. Start at any point of the flat. For each block currently at its target, apply that block's kernel vector. This preserves all equations and leaves every other block untouched. It produces a point missing every target. The case $d=0$ needs no argument. Extra unconstrained coordinates cause no change. [Lean proof of the finite kernel and disjoint-block argument](SharedReadAffineBlocks.lean)

Now $\dim E=\dim P+\dim B$ by rank-nullity. In the ambient $Mb+ts$ bits this gives codimension at least $b(2^p-1)+t(s-p)$. This proof permits the table projection to satisfy different cosets on different points.

Conversely, take any $p$-dimensional flat $H$ through $a_*$ inside a flat witnessing $h$. Require each address to belong to $H$, independently. On the cells in $H$ require $T[x]=T_0[x]+z$ for one common arbitrary $b$-bit shift $z$. All other cells are free. These constraints have the claimed codimension, and every read returns the affine word $T_0[a_i]+z$. Minimizing proves (1). A graph-contained flat projects injectively to its table and addresses, on which its replies are affine. Conversely their affine graph lifts a flat without changing its dimension. Adding the $tb$ reply coordinates proves the graph assertion.

In particular the all-zero table gives $h=s$. The difference of consecutive candidate costs at $p,p+1$ is $b2^p-t$. For $b=s,t=2^s$ the first minimizer is $p=\lceil\log_2(t/b)\rceil$, giving the stated asymptotic. Identify the address and data words with $\mathbb F_{2^s}$ using a binary basis and take $T_0(x)=x^3$. Its second difference in independent directions $u,v$ is $uv(u+v)\ne0$, so $h=1$ at every address. The exact cost is $\min(ts,t(s-1)+b)$. Field cubing is a classical example of an almost perfect nonlinear function. With $a_*=0$ both example tables return only zero replies. [Carlet on graphs of almost perfect nonlinear functions](https://eprint.iacr.org/2023/621)

## When different addresses can share the saving

For **any** $T_0$ and any actual address tuple, $t\le b$ gives exactly $ts$ as the price of making the replies affine. The lower proof did not use coincidence of the actual addresses until comparing $p$ to $h$. Its bound $t(s-p)+b(2^p-1)$ is at least $ts$ in this range. Fixing all addresses attains it.

For a general address tuple, write $h_i$ for the local maximum affine dimension of $T_0$ at address $a_i^0$, and set $h_{\max}=\max_i h_i$. The lower bound given by (1) with $h_{\max}$ always holds. If $t>b$, **it is attained exactly when all the actual addresses lie in a common $p$-dimensional flat on which $T_0$ is affine**, for some minimizing $p$. For the cubing table $h_i=1$ throughout. Thus the lower bound $t(s-1)+b$ is attained exactly when the reads visit at most two distinct cells.

Here is why correlations with the table do not introduce other equality cases. Choose an affine section from $P$ into $E$, writing its $i$th address as $a_i(T)$. Put $p_i=\dim U_i$ and let $r_i$ be the rank of the linear part of $a_i(T)\bmod U_i$ on $P$. The set of cells used by read $i$ anywhere on $E$ is an affine space $S_i$ of size $2^{p_i+r_i}$. A table direction $D$ in the kernel of that quotient map changes the section address by some $u_D\in U_i$. The affine reply has a fixed difference along this section direction, independent of where it is taken on $E$. At any reachable address $x$ the difference is
$$
 (T+D)[x+u_D]+T[x]=D[x]+\lambda_i(u_D),
$$
using the pure-address derivative on the new table. The second term depends only on the direction, so $D[x]$ is constant over the entire $S_i$. The kernel has codimension $\operatorname{codim}P+r_i$ in the table space. Constancy across $S_i$ costs $b(2^{p_i+r_i}-1)$ independent constraints. Consequently
$$
 \operatorname{codim}P\ \ge\ b(2^{p_i+r_i}-1)-r_i
 \quad\text{for every read }i.
$$
This gives a second proof of the needed data penalty even for $r_i>0$. For $p_i\ge1,r_i>0$ it is strictly larger than $b(2^{p_i}-1)$.

Equality in the global lower bound requires $\dim B=tp$ and $\operatorname{codim}P=b(2^p-1)$. Thus every $p_i=p$. Since $t>b$ and $h_{\max}\ge1$, $p=0$ cannot minimize. The sharper inequality forces every $r_i=0$. Each $S_i$ is therefore a fixed coset of $U_i$ on which the differences of the table are prescribed on all of $P$. These constraints already have the full codimension of $P$, so they define $P$ exactly. Two different $S_i$ would give different constraints, since changing one cell lying only in one of them violates its prescribed difference to another cell in that set. Hence all $S_i$ coincide. The table $T_0$ must be affine there. The product construction used for (1) proves the converse. In fact every flat attaining this lower bound in the positive-$p$ case consists of precisely those tables with the prescribed differences and all independent address choices in the common coset.

## Adaptive queries and limiting cases

Allow query $i$ to use the independent public seed $z_i$ plus an arbitrary fixed affine map $\ell_i$ of **actual earlier replies**. On triples of table bits, seed bits and claimed replies $y$, the change $a_i=z_i+\ell_i(y_1,\ldots,y_{i-1})$ is an invertible affine shear. The full adaptive graph is carried onto the original graph, since successively checking the replies determines a unique run. The codimension through a correct tuple is unchanged. A domain flat where all true replies are affine is equivalent to a flat of the same dimension in that graph. Formula (1) therefore also gives the domain restriction cost at an adaptive run whose actual addresses coincide. This covers, for example, XOR of the preceding word into each next address when $b=s$. This is an affine isometry of the graph. A dense feedback map can itself take many instructions to evaluate. The scan-time assertion below uses physical address fields, and also applies to the single preceding-word XOR example with its constant native cost. Nonlinear feedback requires a different argument.

Fixing a **single** choice of precomputed table as a promise changes the answer. With no editable table bits, the least restriction cost is exactly $t(s-h)$ on the same-address input. Each projection of a valid flat to an address must then be a flat through $a_*$ on which the fixed table is affine, and independent choices in a maximizing flat attain the bound. Under the editable-table problem (1) prices the additional constraint needed to share this freedom. Likewise, arbitrary actual address tuples need not attain (1) with a single common local $h$. The upper construction uses a flat containing all the base addresses.

## Transfer to proper ASCII SAT and to genuine instructions

Use the journal's earlier read-discrepancy construction with a single mark per word value. Give each table row a Boolean name $R_i$, each possible payload a name $V_z$, and each query a selector $q_j$. Print
$$
 R_i\Rightarrow V_{T_i},\qquad q_j\Rightarrow R_{a_j},\qquad q_j\Rightarrow\neg V_{y_j}
$$
and require at least one selector. The formula is satisfiable exactly when some claimed read is wrong. A wrong read lets us enable only its selector and row, set the corresponding true value mark, and clear its claimed mark. Any enabled selector at a correct read would force the same mark both ways. Realize the disjunction with $u_0$, $\neg u_t$, and $\neg u_{j-1}\lor q_j\lor u_j$. Seven proper signed ternary clauses pin names 1, 2 and 3 to zero. Pad units and binary clauses using distinct false names. The other names start with their bank's decimal digit and use a fixed number of octal digits as the suffix of the decimal spelling. Public widths depend on $s,b,t$ alone. A changing suffix bit changes exactly one ASCII bit. Each table word, address and claim has only one changing occurrence. The header uses a fixed bound on all names at that scale and may declare unused variables. [Prior mismatch reduction](verifying-a-spanning-star.md) · [Byte-level and satisfiability audit](shared_table_affine_audit.py)

For the balanced scales $M=t=2^s,b=s$, the literal fields carry $O(s)$ bits each and the physical encoded length is $N=\Theta(ts)$. All independent source bits appear affinely in the immutable input. Follow any correct SAT program on an all-correct base file. At each instruction retain an affine flat through this file inside the preceding one, with the same control path and with each bit of every register and each fixed-address mutable cell affine. The total codimension lost includes all restrictions imposed so far. Use distinct accepting and rejecting control states, or count the terminal branch that reads the verdict bit. At return the verdict on the final flat is fixed, so it lies in the all-correct read graph. Its codimension must be at least $tb+C$ on this **one actual run**, even when the program uses unbounded memory and input-dependent read and write addresses. If the ISA instead ends at a common halt returning an arbitrary affine bit without charging its terminal branch, fixing that bit costs at most one further equation, giving the unconditional lower bound $tb+C-1$ in that convention. In fact that convention saves exactly one for an optimal solver. On an extremal graph flat let one extra free bit toggle one designated claimed payload bit. A branchless comparator accumulates bitwise OR of the word mismatches and returns its nonzero bit after successful syntax validation. Only the designated bit can differ, so the accumulator and the Boolean result are affine throughout this enlarged flat. The same adjustment applies on the fixed negative source below. [Original definition of the run measure](affine-dimension-along-sat-runs.md)

There is one SAT program attaining this bound at every same-address, all-correct base file on the balanced layouts. Identify the scale from the file length, check the entire known syntax, extract the table into consecutively addressed words, and compare each lookup with its claim. If layout recognition fails, run a general SAT decider on the original input. The program can accumulate a mismatch flag and complete the syntax check before giving a verdict. On valid layouts it takes $O(M+t)=O(N/\log N)$ native steps. In detail, the banks, dummies, clauses and header outside the data digits are fixed at a scale, and the encoded length strictly increases with $s$. Trying successive scales and computing lengths costs $\mathrm{polylog}\,N$ using the fixed record widths. Digits of the changing fields have fixed high ASCII bits and their low three bits are the source. A decoder tabulated for chunks of at most half a logarithmic word (also at most half $\log_2 N$ bits) validates and extracts their bits in constant time per chunk. Each field uses a constant number of chunks, with $O(\sqrt N\,\mathrm{polylog}\,N)$ uniform setup. Fixed row identifiers can be generated in the same budget and $O(M+t)$ further work, for instance by a chunk table emitting packed octal digits. Hash tables, comparisons between independently varying names, and writes indexed by input data are unnecessary. Store each data word at its known row address. Use an aligned base for the lookup so inserting the address field is affine.

For any extremal flat from the upper construction, impose also the equations giving the honest claims on that flat. Throughout the scanner the extracted address and payload bits are affine, each input-dependent validation flag has its fixed successful value, writes go to known rows, and the true read result is affine. Store the raw file separately from work arrays. Thus the entire valid flat survives from the first instruction to the last if selected at the start. This justifies attainment by an actual solver. On each of these all-correct inputs, changing the low digit bit of any one claim makes the file satisfiable. A word of $O(\log N)$ bits intersects at most a constant number of these distinct claim records at the balanced scales. Consequently every correct solver takes $\Omega(t)$ native steps on the all-correct inputs, independently of the table. The same construction with affine feedback is interpreted on the original physical address layout after the shear, which need only preserve affineness.

## Keeping the unrestricted SAT clock in the same family

The run bound can be imposed on a class whose **negative running time alone** carries all three unrestricted SAT deadlines. Given any proper 3-SAT input $F$ of length $n$, take $s$ with $s2^s=\Theta(n)$, set $t=M=2^s,b=s$, and output
$$
                  F\ \lor\ [\text{some supplied table reply is wrong}].
$$
Use the field-cubing table with all addresses and replies zero. Thus the ordinary output verdict equals $\operatorname{SAT}(F)$. For the affine lower bound hold $F$ fixed and permit every table, address and reply bit to vary. All resulting DIMACS files remain legal. At the designated cubing base file of **every unsatisfiable** $F$ the input to the reading problem is honest, and a deterministic SAT run must lose at least
$$
                    ts+t(s-1)+s
$$
affine dimensions just in the data coordinates. This is stronger than requiring the bound on a separate set of preselected easy negative inputs.

For the compiler, densely rename the variables of $F$ and deduplicate clauses first. If $m$ distinct clauses remain then $m\log(2+m)=O(n)$, since they had distinct source strings over a fixed alphabet. A fixed-alphabet trie handles the original fields in $O(n)$ time. An empty formula is handled directly or by a fixed equivalent formula. Put the source and read test in distinct banks and give the disjunction a new selector. Guard each ternary clause of each side, splitting the resulting four-literal clause into two proper ternary clauses on a fresh existential variable. For a guarded clause $g\lor l_1\lor l_2\lor l_3$, use $(g\lor l_1\lor z)$ and $(\neg z\lor l_2\lor l_3)$. Preserve the one physical occurrence of each changing digit. The source names may use fields of length $O(\log(2+m))$ in a separate bank, independent of the data bank's larger width. The same bound applies to the source side's fresh names. This matters when many source bytes came from duplicates. Allocate the read side's fresh names using its own fixed-width fields. Thus the compiler takes $O(n)$ steps and outputs $\Theta(n)$ bits. Fixed extents and decimal header bounds may be manipulated as text or a constant number of native words. A degree-$s$ irreducible over $\mathbb F_2$ can be constructed deterministically in $\mathrm{poly}(s)$ time. Two shift-and-reduce word multiplications per address then build the cube table in $O(s2^s)$ native steps. [Shoup, *New Algorithms for Finding Irreducible Polynomials over Finite Fields*](https://www.shoup.net/papers/detirred.pdf) · [Dense normalization on the RAM](dense-sorted-cores-for-ram-exhaustion.md)

For $k=1,2,3$, a globally sound rejection algorithm finishing in $O(N^k)$ on all these generated negative files would decide all proper 3-SAT in $O(n^k)$. Compile the source, simulate to the promised deadline, reject on a rejection, and otherwise accept. The reverse implication uses an ordinary $O(n^k)$ SAT decider. The deadline counts $N$ bits of actual output, with no oracle access or hidden word-length change beyond the usual fixed-factor word simulation.

Within the varying read data, the affine bound on each negative base file is still **exact**. A single globally correct solver can recognize the guarded layout, recover and solve the source first, and on an unsatisfiable source run the direct comparison. Use disjoint banks and check the fresh-variable and occurrence pattern before trusting either component. This validation on the data side checks known types and fields or decodes words affinely as in the scanner. On fixed $F$ every source calculation is constant across the data perturbations. The direct comparison then attains the same flat as before. If a general source solver is slow, its time precedes all processing that requires these shared lookup values. The affine cost is compulsory on the entire negative clock test, yet attached at a cost that the linear deadline can already pay.

This resolves a cost ambiguity in the proposed value-based attack. The same native addresses and replies at the read instructions support substantially different affine costs depending on the surrounding memory values. Both examples still have the same tight native clock. Any proof that turns this loss into superlinear time must bound additional work that the direct scanner cannot perform in one word instruction.
