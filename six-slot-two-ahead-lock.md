# A six-instruction scan that cannot decide SAT at any speed

Fix a nonzero integer stride \(d\). Let the word width on an \(n\)-bit file be \(w=16\lceil\log_2(n+2)/16\rceil\), let \(Q=2^w\), and let \(p_i=p_0+id\bmod Q\). At stage \(i\), a machine reads \(x_i=M[p_i]\) and, if it continues, writes \(M[x_i]\gets p_{i+2}\). These are its only memory operations. It has fixed finite control, can compute arbitrarily in a constant number of word registers, and can branch before or after either operation. The initial cursor and register state are public functions of length, the input is packed little-endian, and memory outside it starts at zero.

**Theorem.** Every such deterministic machine either gives a wrong answer or fails to halt on a well-formed proper ASCII DIMACS 3-CNF. For odd \(d\) this happens at infinitely many lengths admitting the construction below. On every constructed equality file at these lengths the memory replies of a continuing run become a public sequence within the first lap. A six-instruction realization uses a LOAD, two adds for the cursor and lookahead, a STORE, and two comparison branches. The previous analysis of this schedule gave a running-time lower bound. The argument here allows arbitrary running time. [Earlier two-ahead simulation](two-ahead-stores-in-a-six-slot-scan.md)

## A first visit before the replies become public

Call stage \(u\) locked if \(x_u=p_{u+1}\). Its store writes \(p_{u+2}\) into the very next cell read, so every subsequent stage \(j\) has \(x_j=p_{j+1}\) as long as the scan continues.

Write \(H=\{M_0[a]:a\in[0,Q)\}\). Suppose \(p_0,\ldots,p_i\) are distinct, \(p_i\notin H\), and no earlier stage was locked. Then \(M[p_i]=M_0[p_i]\) when stage \(i\) reads. Otherwise some \(j<i\) wrote to \(p_i\), so \(x_j=p_i\). This value was absent initially. At a still earlier stage \(u<j\) a store therefore wrote \(p_{u+2}=p_i\) at \(p_j\). Because \(u+2\le i\), distinctness gives \(u+2=i\) and \(j=u+1\). That writer's destination was \(x_u=p_j=p_{u+1}\), an earlier lock.

Consequently if \(M_0[p_i]=p_{i+1}\) and \(p_i\notin H\), the scan locks by its first visit to \(p_i\). Also, with \(h=|H|\), there are at most \(2h\) distinct store destinations in the first lap before any lock. Each stage at a position outside \(H\) reads an original value and writes into \(H\). The remaining stages read at distinct positions inside \(H\) and contribute at most \(h\) further destinations in total. This argument allows an early halt. The [Lean proof](TwoAheadFirstLapLock.lean) defines the full memory after each store and proves the first-visit and lock assertions for any address sequence with a distinct prefix.

## Planting the lock in valid ASCII for both signs of stride

For each sufficiently large multiple \(w\) of 16 put \(W=w/8\). For \(1\le L<W\), let \(r_L\) encode \(L-1\) ASCII spaces followed by a newline as a zero-extended little-endian word. Thus \(r_1=10\) and \(r_{L+1}=256r_L+32\). Consider a file consisting of \(a_L=r_L-d\) full words and that final partial word. Its encoded bit length is
\[
n_L=w(r_L-d)+8L .
\]
Choose the least \(L\) with \(n_L+2>2^{w-16}\). This \(L\) exists below \(W\) since \(r_{W-1}\ge 10\cdot 2^{w-16}\). It tends to infinity with \(w\). Around this crossing, \(n_L/n_{L-1}\to256\), since \(d\) is fixed and \(r_{L-1}\to\infty\). Thus eventually \(n_L+2\le512\cdot 2^{w-16}=Q/128\). In particular the prescribed width at \(n=n_L\) really is \(w\). Set \(a=a_L\). We have \(a>0\), \(a\asymp n/w\) and \(a=o(Q)\).

Use the [aligned proper 3-CNF equality layout](communication-bound-for-public-crossed-scans.md#a-constant-word-alphabet-for-deterministic-equality) with \(k=\lfloor n/(C(\log_2 n)^2)\rfloor\) private bits per party. For sufficiently large fixed \(C\) the entire public header and the two clause lists fit in the first half of the available full words. The literal for each privately signed variable is forced by four proper clauses containing both polarities of each of two other variables. The two lists can be satisfied jointly exactly when the strings agree. The aligned decimal identifier construction uses a constant total number of different packed words across the inputs at fixed length. All bytes of each full word are ASCII of value at least 9. Fill the remaining full words with spaces and append the prescribed partial word, including its final newline. This contributes at most two more word values and preserves every SAT answer.

In each of these files \(M_0[a]=r_L=a+d\). Every full packed word has unsigned value at least \(9Q/256>a\) for large \(w\). The only other initial values are \(0\) and \(r_L\), both different from \(a\). Therefore \(a\notin H\). When \(d\) is odd the scan visits \(a\) in its first lap for every starting cursor. Its next cursor there is \(a+d\), and the first-visit lemma forces the lock.

## Communication up to the lock

Alice owns word addresses from zero through the end of her clause list. Bob owns the complementary interval, including all unused memory. Each knows the public layout. During the first lap with a fixed signed stride \(d\), ownership of the current position switches at most \(2|d|\) times. Indeed at each of the two interval boundaries at most \(|d|\) possible starting addresses for a single step can cross the boundary, and each such address is visited only once.

The owner at the current position simulates every register step, branch, and read until ownership changes, the machine halts, or it locks. The owner keeps the most recent write to each destination in a dictionary over the original input. At a handoff transmit the controller state and the whole dictionary. There are at most \(2h\) entries before lock, so all handoffs together use \(O_d((h+1)w)=O_d(w)\) bits. This works also when some writes reach the other party's private words. The receiver can consult their own original words and the dictionary for all subsequent reads in their interval. From the first lock onward, the current owner can simulate every remaining instruction locally because every later LOAD reply is the next cursor, including on paths with arbitrarily delayed exits. Early halts likewise require only a verdict message. If the machine is a decider these simulations terminate.

On this suite a correct SAT decider would therefore give a deterministic equality protocol using \(O_d(w)\) bits for \(k=\Theta(n/(\log n)^2)\)-bit strings. The \(2^k\) diagonal pairs must have distinct accepting transcripts by the rectangle property. Hence at least \(k\) bits are needed, a contradiction.

For even \(d\), reads after entry all have a single parity. The [aligned sensitive formula](read-only-five-instructions-on-ordinary-sat.md#a-family-with-two-zero-low-bits) has unboundedly many separately flippable words of each parity. Even an intervening overwrite cannot reveal a changed original without its first read. This gives the stated exclusion for both signed even strides, including when a bounded entry phase reads finitely many more words.

## Stored instructions and initialization

For a concrete native realization use a cycle that reads \(x\gets M[p]\), computes \(y\gets p+2d\), stores \(M[x]\gets y\), and then updates \(p\gets p+d\). Insert the two fixed-target comparison branches anywhere on the cycle, each continuing along the cycle or departing directly to a verdict. The theorem applies with the initial PC at the LOAD. It also applies with any rotation of the entry point under the journal's native initialization, where all registers start at zero except optional public \(n,w\). On the partial cycle before the first LOAD there can be at most one STORE. It uses the initial \(x\) as its address and takes its payload from the initial \(y\) or the initial \(p\) plus \(2d\) modulo \(Q\). None of these words equals \(a\) at the selected lengths because \(w\ll a\ll n\le Q/128\), and negative fixed offsets near zero wrap near \(Q\). The public change preserves both hypotheses on \(a\) and adds at most one value to the palette. The proof then starts at the first LOAD and works for the resulting cursor, or an earlier verdict already fails on one input. A clean start permits an arbitrary public initial cursor. A preliminary arbitrary write changing the designated cell needs a separate argument.

This excludes one specific recurrent six-slot architecture. Other six-slot programs and the unrestricted RAM time bounds remain open. The length construction, communication argument, and instruction embedding are manuscript proofs. The finite audit checks 381,315 scan initializations through three laps, 372 width/stride pairs, and 384 actual padded equality files against their assignments.
