# Five stored instructions cannot decide DIMACS SAT, even with unlimited running time

**Theorem (manuscript).** For each fixed deterministic program with at most five stored instructions in the separate-operation word RAM below, there is a well-formed proper ASCII DIMACS 3-CNF on which the program gives the wrong answer or never halts. The program may use all $2^w$ writable words and execute arbitrarily many steps. The standard width here is $w=16\lceil\log_2(n+2)/16\rceil$, for encoded input length $n$ in bits.

Registers are zero initially, apart from optional public $n,w$. A LOAD and a STORE each move one word, with immediate or register address. A numerical site has one fixed destination and at most two operands, and implements modular addition, subtraction, multiplication, bitwise Boolean operations, shifts, rotations, moves or comparisons. Branches compare words and have fixed targets. There is a fixed initial instruction, and YES and NO are terminal vertices. Literals are fixed integers interpreted at the current width. The ISA has no autoincrement, fused load/arithmetic, indirect jump or data-dependent return instruction. Input starts at address zero in little-endian words, with zero outside the file. The input grammar allows whitespace between tokens and unused identifiers below the header's variable bound. Some constructions use decimal identifiers with $O(\log^2 n)$ digits. ## Exhaustion over control graphs and operands

1. A terminating correct computation must sometimes read arbitrarily many original words. There are satisfiable files having unboundedly many separate words at each of which a valid one-word edit changes the verdict. A deterministic computation missing an original word, including by overwriting it before its first read, gives the same result on its edited counterpart. Thus an acyclic program cannot suffice. Both verdicts must be reachable. If there are $s$ reachable instructions and $b$ binary branches, the connected underlying multigraph has $s+2$ vertices and at most $s+b$ edges. A cycle needs $b\ge2$. With exactly two branches there is only one possible recurrent cycle, traversed in a fixed instruction order until exit. This counts stored operations independently of the number of iterations. [Control graph](five-instruction-loops-on-dimacs-sat.md#the-control-graph-and-accessible-data)
2. **If a STORE is available**, a viable recurrent write leaves room for one LOAD, one numerical update and two branches. A fixed scratch address cannot transmit its old content across two private reads: an intervening compulsory STORE overwrites it. For the self-addressed LOAD the preceding scratch write also fixes the hidden register when a chosen low private address is reached. Writes to the address in the raw input word, with own-address or fixed payload, have only a bounded set of marked cells on an appropriate table-index family. The remaining operands give missed original words, compressible sets of visited or marked cells, or public scans. For the public scan writing the advanced cursor to the address just read, a planted pointer erases each private sign before the scan reads it a second time. The proof includes the off-cycle STORE and both orderings of each recurrent write. [Complete writable case split](writable-five-slots-without-a-clock.md) · [Shifted scan proof](arbitrary-stride-private-sign-erasure.md) · [Odd-marker walks](odd-self-marked-cursors-without-a-clock.md)
3. **If there is no STORE**, the one-numerical-site theorem handles any number of LOADs and branches. The remaining allocation is two branches, one LOAD and two numerical instructions. If only two registers vary and the LOAD overwrites one using the other as its address, four eight-clause inputs suffice. For a third live register, encode an arbitrary truth table $T$ on $t$ bits and its argument $u$ into proper 3-CNF with SAT value $T(u)$. At fixed $T$ only $t$ private words vary with $u$. Contract all computation between reads of private words. If $S$ is the total number of private-query states allotted at these sites, there are at most $(S+3)^{2S+1}$ resulting directed graphs, loops included. Realizing all tables forces $S=\Omega(2^t/t)$. On files of length $n=\Theta(2^t t^2)$ with a bounded word alphabet, one may translate the private sites over $\Theta(n/w)$ word positions. Thus any instruction pair admitting only $2^w\operatorname{poly}(w)$ possible combinations of next address and live state can realize only a polynomial in $\log n$ slots at a suitable common translation at the standard width. That contradicts the graph count. Other operand pairs miss sensitive address residues, confine a register to a small orbit, or give a public address sequence with just one accumulator. These alternatives exhaust the at-most-binary operand choices. ## A concrete part of the proof that Lean checks

Four files have 87 bytes, three variables and eight clauses each. Six common clauses leave only the assignments with $x_2=x_3=0$. The two remaining clauses pin $x_1$ with independently chosen signs, so the SAT answer is equality of those signs. At this length the signs occupy distinct 16-bit memory words, at addresses 34 and 39. A machine with a single fixed-successor LOAD $x\gets M[p]$ and only $x,p$ as mutable registers cannot decide all four. At each private read the address fixes $p$ and the LOAD overwrites $x$. Public stretches then contract to two query vertices, one per sign. Among all 3,125 cyclic graphs of this form, 14 of the 16 total two-bit functions occur. Equality and XOR are precisely the missing two.

Lean proves the CPU obstruction on the literal little-endian memories, the four lengths, the changing word positions and the satisfiability predicate for the eight clauses. The Python audit independently parses the actual DIMACS bytes and exhausts all eight assignments. Eight clauses are necessary for any unsatisfiable proper 3-CNF, since each clause excludes one eighth of assignments. This is a minimum in clause count. A five-slot program with **two** direct LOADs and three branches decides this particular four-file suite. Different parts of the full theorem use different witnesses. [Lean, including `cpu_cannot_decide_packed_sample`](TwoPrivateProbeSites.lean) · [DIMACS parser and graph enumeration](table_probe_context_audit.py)

The same four literal files also suffice with a writable cell at any single fixed address, including either changing word, if a STORE is compulsory between successive LOADs through the distinct cursor. The old scratch content can be discarded immediately after a LOAD because another STORE must replace it before the next LOAD. Lean proves the resulting simulation and the obstruction. This covers the fixed-scratch row with distinct register-indirect addressing. The self-addressed LOAD with a separate numerical destination uses the manuscript argument. The complete ISA exhaustion and the asymptotic reductions are manuscript proofs. Lean covers the concrete subcase and selected intermediate results, including contraction of public computations, erasure of a stamped sign and local invariants of the adaptive walks. There is no end-to-end Lean proof of the five-slot theorem. Priority has not been established. [Context count](TableProbeContexts.lean) · [Shifted write](ShiftedStrideOrigin.lean) · [Adaptive writes](AdaptiveMarkedRead.lean)

The conclusion is a minimum of **six stored instructions** for any correct solver on this exact machine. Whether six suffice is unresolved. A RAM with unrestricted program size is outside the exhaustion, so the result leaves the project's linear, quadratic and cubic running-time targets open. The earlier deadline proof treated a range of width coefficients and polynomially bounded numerical identifiers. Its hypotheses differ from those of the unlimited-time proof here.
