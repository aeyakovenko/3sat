# Searching a finite roster without guessing the set of honest SAT programs

For each proposed exponent $k=1,2,3$ there is a fixed arithmetic assertion about a deterministic program with the following property. If a proof of that assertion fits its $h^4$-bit cap, it yields a satisfiable file and an unsatisfiable file extending a designated satisfiable seed. Every globally correct RAM program in the designated roster exceeds its own $a(N+1)^k$ clock on both, measured at the bit length $N$ of each file. The native search costs **polynomial time in the number of candidate programs**. The previous program tested every subset of the roster. The new result allows a fixed fraction of $h$ description bits at width $h$, and can keep the physical files polynomial in $h$ by imposing a stated bound on the encoded clock and word-width coefficients.

The hypothesis concerns the new program's own sentence and literal arithmetic proof checker. Finite reflection gives an unconditional $K h^4$-bit proof. The required $h^4$-bit proof for unbounded fixed-code budgets is still missing. The sharper search cost gives no leading-constant improvement in the reflection theorem. ## Two finite search procedures

First ignore self-reference. Let $F$ be an explicit verifier on $d$ bits with some accepting string. At an old positive seed $B$ use ordinary proper DIMACS files $g_B(Q)$ which retain its clause-body bytes and append a fresh translation of $Q$ and a neutral proper clause. The verdict is the truth of $Q$. A clocked voter may vote YES or NO or time out. It can make mistakes. For each group containing only voters that never make a false YES vote on this image, the following deterministic procedure either recovers an accepting string or issues a positive file on which no member of the group votes YES.

Start with every voter active. Ask for a timely YES on the root proof-existence file. If nobody votes YES, stop. Otherwise start at the root and ask both children, the two files fixing the next witness bit. Descend to the first child with a timely YES. At a leaf directly run $F$. If the leaf passes, return the string. At a failing leaf or an internal node where neither child got a YES, delete all active voters who voted YES at that node and restart at the root. At least one voter is deleted whenever the procedure restarts. There are at most $m+1$ rounds for $m$ voters and at most $1+2d$ query files per round. Inclusive deadlines and actual file bits are used at every guest call.

Fix the unknown sound group. At a failed leaf its members could not have voted YES. At an internal terminal node there are two possibilities. If its file is unsatisfiable, deletion also preserves every member of the group. If it is satisfiable, at least one of the **two children actually queried** is satisfiable. Neither got a vote from the active pool. Looking at the first such round retains the entire sound group up to that point. The remaining failure case is the positive root with no vote. This proves the promised common miss without giving the native procedure any hidden ground-truth labels. In fact the genuinely false YES votes removed before this first miss, with one bad file per removed voter, certify failure of every subset containing any of those voters. The common missed file certifies every subset of the remaining pool. For the negative direction a prefix-only version encounters a different problem. Consider a hidden passing word of $d$ bits and $2d$ syntactic voters, one for each coordinate and value. Such a voter rejects a prefix exactly when it fixes that coordinate to the opposite value. The outputs are independent of the hidden word. For each possible word the subgroup with its correct values rejects every impossible prefix and rejects no possible prefix. With access limited to those voter responses and testing complete words for equality with the secret, a deterministic method may need $2^d-1$ failed word tests to identify the word, and $2^d$ trials if it must actually see a passing test. This is a finite oracle example. An actual input formula also supplies executable verification code.

Use that code. Let $z$ be the lexicographically least string accepted by $F$. For each voter $i$, construct a new SAT predicate on $x$ saying that $F(x)$ accepts and $i$ votes NO on the physical question “is there a passing $y<x$?” A negative-sound voter rejecting the comparison at $z$ makes $z$ the unique projected solution of this new predicate. Polynomially many ordinary SAT questions then test evaluations of the polynomial having the bits of $z$ as coefficients. If a group of negative-sound voters collectively rejects every incorrect side, some one group member supplies enough distinct evaluation points to interpolate $z$. Try all pairs of voters, and accept a reconstructed string only after checking it. The search does not assume any constituent answers all the comparison queries or that the two roles use the same constituent. [Construction, both codes and signed receipts](isolating-a-proof-with-negative-sat-votes.md) · [Lean proofs of isolation and the finite coverage argument](LeastWitnessFromNegativeVotes.lean)

A failed negative search therefore gives each designated negative-sound group an UNSAT file missed by all its members. It is either an actually issued outer query, or the single comparison at $z$. That comparison is represented inside the constructed formulas. It can be materialized using an external exhaustive search for the least accepted string. It need not have been issued during the native run. The external certification of failures of all subsets needs at most $m+1$ files per polarity, including individual wrong-sign votes. A globally correct decider cannot cast the wrong vote, so on the signed pair the absence of each appropriate vote means its actual time to its verdict exceeds its declared clock.

## Program, budgets, and two physical lengths

For a literal finite axiom-list code $\gamma$, the fixed constructor $P(\gamma)$ makes $F$ the syntactic check of a length-coded proof of the assertion $J(P(\gamma),h)$ that its own run has not returned one by $2^h-1$ native steps. Use the input seed and closed instance convention of the fixed-cap construction. Set $d=h^4+1$ (marker and payload). The program runs the two searches, returning one only upon recovering a string accepted by the actual checker. The tag mechanism $j=v_2(h)$ supplies a small literal satisfying seed $B$ and its assignment. Use two modes.

* In fixed-budget mode the tag also supplies $c$. Include all ordinary clocked texts of length at most $c$. In a separate $h$-step warmup read a fixed dovetailed enumeration of failures on the entire unpadded extension image. Skip both searches only on a completed receipt that every subset at this tag has an error in each of the two voting modes. The earlier exhaustive learner suffices here. Its full running time is never charged inside this width, only its first $h$ steps. Each fixed tag recurs on its arithmetic progression, eventually with every one of its fixed codes within the host capacity. Confirm invalid encodings and out-of-capacity tags by a short guard before allocating anything.
* In growing-budget mode the tag supplies fixed positive upper bounds on the guest multiplier and word-width coefficient, or one common bound $A$. There is no retirement guard in this mode. Include all valid texts of at most $c=\lfloor h/K_0\rfloor$ bits meeting the bounds, where $K_0$ is a sufficiently large fixed integer. One may use the same numeric bounds in a finite experiment. This mode tests exponentially many actual descriptions. It imposes a true ceiling on the per-program constants. Allowing a different, arbitrarily large hidden time constant for every file would invalidate the interpretation.

For fixed $k$, all work is bounded by $2^{D c}(h+1)^{D'}$ for fixed constants after bounding the seed and coefficient-bound data by the literal tag length or by $h$. The roster has $m\le2^{c+1}+2$ entries. In the parity implementation, the outer search makes $2m^2q^2$ clipped calls with $8md\le q<16md$. Generating masks, reading program texts, deterministic bit simulation with a list of touched cells, building the comparison and outer circuits, and solving the resulting linear systems take a fixed polynomial in the parameters. Even uncapped positive binary coefficients in a $c$-bit description are at most $2^c$; a sparse bit-level simulation and its explicit circuit have a fixed polynomial overhead in these coefficients. The bounded nesting depth matters. Choose $K_0>D+2$ sufficiently large also for the RAM implementation and space bound. The result then fits the $h$-bit native host's horizon and accessible storage at all large valid widths. In fixed-budget mode one can enforce the same inequality $K_0c\le h$. The fixed finite arithmetic presentation changes only constants. Fixed group simulation at compiler size $c$ and the *offline* time to identify the mathematically honest sublist are separate costs.

In growing-budget mode all files can have **two predetermined physical lengths**. Choose a byte length $n_1(h)$, polynomial in $h$, above the largest root, prefix and least-witness comparison file, including seed and syntax. Pad each of these to exactly $n_1$ bytes with allowed whitespace after the appended records. Use the very same padded emitter within $F_i$. An individual inner code has $O(h)$ bits and coefficients at most $A$, so the computation on $8n_1$ bits has a Boolean circuit of size polynomial in $h$ for this fixed tag and $k$. The outer query includes a *literal* $d$-bit parity mask. It does not contain the $m$ voter descriptions or the table of all masks. Choose a second polynomial byte length $n_2(h)\ge n_1(h)$ covering each outer file, pad those files to $n_2$, and apply the respective physical deadline on $8n_2$ bits. Integer powers with sufficiently large fixed coefficients and exponents suffice, and may be fixed uniformly by using $A\le h$ and checking the guard before starting. The order of the two sizes avoids putting a simulation of a run on the already padded outer file inside that same file. The positive miss has length $8n_1$ bits, and the negative miss has length $8n_1$ or $8n_2$. Both retain the complete old clause body. In fixed-budget mode use the unpadded queries in the exact image used by the retirement learner.

Fix the constructor, including the literal checker, before adjoining to a finite arithmetic base the uniform, true syntactic implications for proof extraction and the completed-receipt guard over all $\gamma$. Set $A_{\rm th}$ to this theory and $p=P(\gamma_{A_{\rm th}})$. This use of two true control-flow axioms is a choice of proof presentation. A return would display a genuine $A_{\rm th}$-proof that no such return occurred. External soundness gives quietness. Pudlák's bounded partial-truth argument applies with the same fixed end template and literal cap, yielding a constant $K$ such that $L_h\le K h^4$. On a skipped fixed tag the warmup already provides the signed failures. On every other sufficiently large valid width where $L_h\le h^4$, the searches must finish without recovering a proof; the two finite search arguments then give the elapsed-time witnesses. [Pudlák, Theorem 3.7](https://users.math.cas.cz/~pudlak/improved.pdf) · [Details of the same-checker specialization](fixed-cap-reflection-on-the-native-program.md)

For a fixed tag, if every group in both modes errs then its authenticated retirement eventually occurs and a fixed proof of retirement gives $O_j(1+\log h)$-bit quietness instances. If an OR group decides the image exactly, each of its YES voters is positive-sound and collectively they cover the positive questions. If an AND group decides exactly, its NO voters are negative-sound and cover the negative questions. In either case the corresponding search would recover any proof within the cap. Its length must therefore exceed the cap at all sufficiently large widths of that tag. Fixed groups deciding throughout the extension image compile into genuine $O(N^k)$ SAT deciders by fixed finite simulation and the linear extension reduction. Conversely any genuine $O(N^k)$ solver eventually appears with a sufficient multiplier. Thus cap crossing at suitable widths for unbounded **fixed-budget tags** is equivalent to the original time exclusion. Crossing on the prescribed linearly growing budgets would be stronger.

The distinction also appears with length advice. Suppose a fixed advised machine is correct on all files of each of the two padded lengths, using a possibly different advice word at each. For each length, compile its length guard and its correct advice into a separate partial program, abstaining on other lengths. Each is globally verdict-sound. A literal advice word of length $s$ can be initialized by an unrolled sequence of fixed instructions to store one bit and increment an index, using $O(s+\log n_2)$ code bits including the two length guards and fixed machine. This adds $O(s+\log n_2)$ time. In the usual case $s=O(n_1)$ those setup steps fit the polynomial deadline with a fixed multiplier. If both compiled texts, complete with encoded clocks and width coefficients, are eligible and meet their deadlines, they cover every query of both signs. At that width a cap proof is impossible. This argument applies even when neither advice word is uniformly computable. It explains why moving directly to the largest affordable budgets can demand a genuine nonuniform lower bound.

## Relation to earlier complexity results

The qualitative collapse from short instance descriptions is classical. For example, suppose every UNSAT file of $N$ bits has a negative-sound clocked voter of $O(\log(N+2))$ description bits making the timely NO vote, with all clock and width constants charged. Enumerate all such short voters and output the unary text indices of those voting NO. Let the tally set contain the indices of voters that make a false NO somewhere. A file is SAT exactly when all indices on its list belong to this set. This is a polynomial-time conjunctive reduction to a sparse set. Arvind et al.'s Corollary 3.4 already implies $P=NP$. Their theorem also credits independent work of Ranjan and Rohatgi. Conversely under $P=NP$ a polynomial-time solver meets the designated $k$-clock on each target by hardwiring a sufficiently large multiplier for that length in $O(\log N)$ bits. A multiplier growing with the target length is allowed in this example and gives no uniform $O(N^k)$ bound. The finite search here quantifies the actual algorithm, signed comparisons and costs needed inside one native self-referential program. Priority for that finite formulation is unestablished.
