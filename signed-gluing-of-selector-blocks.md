# Connecting the 19 selector formulas through shared variables

Of the 19 selector bytes that jointly defeat every six-step program in the [finite RAM census](eight-bit-executed-clock.md), **64 is the only one with a constraint beyond individual variable values or immediate inconsistency**. With arbitrary signed connections between blocks, byte 64 by itself expresses ordinary 3-SAT. With that byte removed, an arbitrary network using the other 18 can be decided in linear time. These facts distinguish two ways to grow the experiment. The finite instruction lower bound depends on distinguishing the rows. The expressive power of their composition can reside entirely in the connections between identical rows.

## What a connection means

A block consists of the selector byte and four ordered ports. Each port receives a signed occurrence of a Boolean variable. The positive and negative masks are $P=x\bmod16$ and $M=\lfloor x/16\rfloor$. For the vector $v$ of the four port truth values the local relation requires
$$
 v\ne0,\qquad v\mathbin{\&}P=P,\qquad v\mathbin{\&}M=0.
$$
The network asks whether a single global assignment meets every block relation. Variables may recur across arbitrarily many blocks, in any order and with unrelated signs. All hardness constructions below use four **distinct** underlying variables within each block. The algorithms also work if within-block repetitions are permitted. The observation in the original census is one Boolean verdict per byte, obtained by existentially choosing its four local bits. A connection shares these bits *before* existential quantification, which changes what is computed.

For a concrete bit encoding take one byte identifier for the mask, four sign bits, and four delimited binary or decimal variable names with no redundant leading zeros. Fixed separators or ASCII signs and whitespace change sizes only by constants. The dense fixed-width variant charges each occurrence the common field width and uses identifiers bounded by a constant times the number of occurrences. Write $n$ for the actual encoded bit length. The RAM has $\Theta(\log n)$-bit words and enough addresses for its $O(n)$-word workspace.

## Which of the 256 rows can express 3-SAT?

The classification follows by first satisfying all the indicated units.

| Local relation | Selector bytes in the full catalog | Count |
| --- | --- | ---: |
| Empty | $P\mathbin{\&}M\ne0$ or $M=15$ | 176 |
| Only fixed coordinates | consistent $P\ne0$, or $P=0$ and $M$ has three set bits | 69 |
| Fixed coordinates and a two-port OR | $P=0$, $M$ has two set bits | 6 |
| Fixed coordinates and a three-port OR | $16,32,64,128$ | 4 |
| Four-port OR | $0$ | 1 |

When $P\ne0$ and the masks are consistent, a forced true coordinate already satisfies the disjunction. With $P=0$, discard the coordinates forced false and retain the single OR on those left. The rows with just one remaining coordinate impose another unit.

It follows that every set of allowed bytes avoiding $0,16,32,64,128$ gives a linear-time signed network problem. Expand to a 2-CNF and test its implication graph for inconsistent strongly connected components. Variable names can be interned in a fixed-alphabet trie, charging one RAM step per digit up to constant factors. The graph has constant size per block. Direct indexing works as well on dense fields. [Aspvall, Plass and Tarjan, linear-time 2-SAT](https://doi.org/10.1016/0020-0190(79)90002-4)

Each of the five exceptional bytes individually suffices to encode every proper 3-CNF. For one false port and three free ports, put the three source clause literals on the free ports and put a single global fresh variable $f$ positively on the false port of every block. Every block then enforces precisely its source clause together with $\neg f$. For byte zero, use the two four-port blocks $(C\lor f)$ and $(C\lor\neg f)$ for each proper source 3-clause $C$. They jointly enforce $C$ for either value of $f$. The same $f$ works in every block, and an empty source formula maps to an empty network. For arbitrary decimal names, reserve 1 for $f$ and append a digit to each source identifier. The transformation copies each original token a bounded number of times. It has linear encoded length and takes $O(n)$ time on a logarithmic-word RAM.

Of the 19 specific bytes, the empty rows are $166,228,42,172,55,113,155,187,17,94$. The rows $164,30,44,1,180,33,150,56$ only pin coordinates. The remaining row $64$ is exactly
$$
  \neg v_3\quad\land\quad(v_1\lor v_2\lor v_4).
$$
Thus the 18-row signed-network algorithm needs just one consistency check per forced variable, even with arbitrary cyclic overlap. In a network using only row 64, each isolated block is individually satisfiable. Trying to preserve the six-step obstruction by independently paying the standalone verdict cost for each block gives no lower bound on this subfamily.

## One and two complemented ports

If every connection is positive, all residual ORs are positive. Record the forced units, reject any contradictory pair, set every unforced variable true, and check all residual ORs. This gives a linear-time algorithm with arbitrary overlap. More generally, if at most one port per block is complemented, the resulting clauses are dual Horn. The units can have either sign. Complementing all variables changes dual Horn to Horn, which admits a linear-time propagation algorithm. One can also find a consistent *global* change of variable signs making all clauses dual Horn whenever one exists. For each pair of literals in a nonunit clause, forbid the two rename choices that make both negative. This gives at most six binary clauses per block. First discard tautological clauses and repeated literals. A satisfying assignment to this 2-CNF supplies the required renaming. [Mannila and Mehlhorn, renamable Horn](https://people.mpi-inf.mpg.de/~mehlhorn/ftp/RenamingHorn.pdf) · [Dowling and Gallier, Horn satisfiability](https://doi.org/10.1016/0743-1066(84)90014-1)

Already **two** complemented ports per block suffice for the row-64 reduction. Replace each input variable $x$ by two fresh variables $u_x,v_x$ for its positive and negative literal. Translate each source clause to a positive three-way OR of its three representatives. For each appearing $x$ also impose
$$
 (u_x\lor v_x\lor b)\quad\land\quad(\neg u_x\lor\neg v_x\lor b)
$$
where $b$ is a single global false padding variable. Use one row-64 block for each displayed or translated OR, with its false port attached positively to a different fresh variable $f$. To force $b$ false, add one more row-64 block with false port $b$ and three fresh positive free ports. Its OR can always be satisfied. Now exactly one representative per variable holds, so assignments correspond in both directions after projecting auxiliary bits. The only blocks with two complemented ports are the second clauses for complementary pairs. The four names within each block are distinct, including in every padding block. Empty inputs can map to the empty network.

Use decimal names $x0$ and $x1$ for the representatives and distinct one-digit names for the shared constants and the three final fresh variables. Emitting the two complementary-pair blocks once per occurrence instead of once per distinct variable avoids any deduplication cost. All copies impose identical constraints. This proves the same linear-bit-length, linear-time forward reduction even on ASCII inputs with sparse or unusually long names. For dense fixed-width input, at most a constant number of new names per old variable and constant additional names increase field width by $O(1)$.

## How many copies of row 64 can an exhaustion use?

Suppose only the 19 census bytes are allowed and at most $k$ blocks use row 64. A fixed RAM decides every signed network of encoded length $n$ in $O(n+2^k)$ time when $k=O(\log n)$. In particular an arbitrary pattern of signs and shared variables still admits a linear-time solver up to $k=\lfloor\log_2 n\rfloor$.

Reject an empty row or contradictory units and substitute all forced coordinates, including the false port of each row 64. At most $k$ clauses with three or fewer remaining variables each survive. If there are $v$ distinct unpinned variables in them then $v\le3k$. For a subset of the clauses, their simultaneous falsification is either inconsistent or fixes $d$ distinct variables. Its contribution to the inclusion–exclusion count of satisfying assignments is zero in the inconsistent case, and otherwise is $(-1)^{|S|}2^{v-d}$. Keep a positive and negative fixing count for each variable, plus totals for variables fixed and variables with conflicts. A reflected Gray traversal toggles one clause between successive subsets, updating at most three positions. Its recursive toggle sequence takes $O(2^k)$ total stack operations. The signed accumulator has at most $v+k+2$ bits, hence fits a constant number of RAM words for the claimed parameter range. An unrelated variable outside these clauses can be assigned freely after honoring its units. Return SAT precisely for a positive count. The enumeration bound charges its full time on this input.

## Returning to proper ASCII 3-CNF

Each block expands into at most eight units and one OR of width at most four, with signs inherited from its ports. Remove tautological ORs and duplicate literals. An empty clause or an empty relation can be replaced by a fixed unsatisfiable proper 3-CNF. Encode a width-two clause $C$ by $(C\lor q)\land(C\lor\neg q)$. Encode a unit by its four three-literal clauses with the possible signs of $q,r$. Both padding variables are fresh and can be shared globally. Width-three clauses are already proper.

The elementary split of $a\lor b\lor c\lor d$ gives $(a\lor b\lor h)\land(\neg h\lor c\lor d)$. Allocating a fresh serial number per block can cost $\Theta(k\log k)$ bits for $k$ blocks with consistently short input names. Instead share the auxiliary $h_{a,b}$ whenever its first two signed literals are the same ordered pair. Set $h_{a,b}=\neg(a\lor b)$ to extend any satisfying assignment of the original blocks. Conversely, resolving the two split clauses on $h_{a,b}$ recovers the original clause for every block. All resulting clauses have three distinct names.

One decimal naming scheme tags original identifiers with an initial digit 1 and ordered-pair auxiliaries with 2, reserving single-digit names 3 and 4 for $q,r$. A signed token of digit length $j$ can be coded by its sign bit, $j$ digits 1, one digit 0, and its original digits. Concatenating two such self-delimiting codes after the tag gives the helper a name of length $O(1+|a|+|b|)$. The productions copy each source token only a bounded number of times. The DIMACS header needs at most the maximum name length plus the decimal clause count. If dense names are desired, intern the resulting names in a decimal trie and number its terminals in order of increasing depth. The rank of a name of $j$ digits is at most the number of strings of length at most $j$, so its new decimal name has at most $j+1$ digits. A breadth-first traversal visits each trie node a constant number of times. Cache the decimal ranks by incrementing a decimal counter and copying each representation once per terminal. Even sparse ASCII instances therefore give dense proper ASCII 3-CNF of linear total encoded length in linear RAM time. Here identifiers are printed as strings, so the reduction never needs a giant integer in one machine word. For binary input names, one may print their original bits as the decimal digits 0 and 1 inside the tagged identifier before applying the same renumbering.

## Circuit lower bound with all selector bytes fixed

For the delimited ASCII network encoding above, even networks using **only byte 64 and at most two complemented ports per block** require $\Omega(n(\log n)^\sigma)$ fan-in-two Boolean gates at the attained projection lengths for some $\sigma>0$. The lower-bound premise is the upstream list-distinctness theorem used in the [dense ASCII 3-SAT circuit proof](checking-the-sat-circuit-bound.md). That proof projects a list of $q=2w2^w$ bits to a proper 3-CNF of $\Theta(q)$ encoded bits. At fixed $w$, all sign bits, token boundaries and clause positions are public. Its varying bits only copy list bits into fixed-width decimal flag names. Its verdict reports a duplicate, the complement of list distinctness.

Apply the two-complemented-port translation above and emit a complementary-pair constraint for **every** source occurrence, retaining duplicates. The chosen representative in each positive three-way OR is $x0$ or $x1$ according to the public source sign. Both complementary-pair blocks contain the original name $x$ followed by a fixed digit, with fixed port signs. Their three free underlying names are $u_x,v_x,b$, all distinct, and the fourth is the distinct $f$. The source triple has three distinct variables, so its three representatives and $f$ are also distinct. The five dummy names can be distinct one-digit constants. The additional block forcing $b$ has four distinct ports. Every nonconstant output bit is therefore a direct copy of one list bit; the repeated gadgets require no parser, comparison or address calculation inside the circuit. Any optional header counting blocks can be fixed as a function of $w$. The new length $L$ is $O(q)$ by constant duplication, and the row references already occupy $\Omega(q)$ bits. Thus $L=\Theta(q)$ and $w=\Theta(\log L)$.

A Boolean circuit of size $s$ on $L$ bits, restricted by these wires and followed by one output negation, computes list distinctness. Its tensor network has size $O(s+q)$ by the copy-tree argument in the linked proof. The source lower bound $\Omega(q w^\sigma)$ gives the stated conclusion. The circuit argument uses the original tagged ASCII representation, before optional dense renumbering. All mask bytes and all port signs can be fixed at their constructed values for each source width. Only the copied name digits vary. The result gives a circuit lower bound on this explicit subfamily and leaves the word-RAM clock question open. [Upstream theorem and specialization](checking-the-sat-circuit-bound.md) · [Circuit lower bound for the underlying list predicate over Boolean gates](https://github.com/danielweis/list-distinctness-circuits/tree/eea4c995b8693f510be51cb685765864863046fb)

The [finite audit](signed_selector_gluing_audit.py) checks the displayed row classification against the original relation at all $256\cdot16=4096$ byte/assignment pairs. Both row-64 encodings are checked on every ordered pair of proper signed ternary clauses on four variables at every global assignment, totaling 16,384 tests each. The guard check enumerates every auxiliary assignment. Another 300 tests compare the inclusion–exclusion count to direct enumeration of truth assignments.

This is an application of the classical Boolean constraint-language framework. The catalog-specific observations are the five exceptional bytes, the unique ternary row of the 19, and the reductions with their encoding costs. The positive-port algorithm supplies an explicit counteralgorithm to that proposed amplification. Allowing two complemented ports provides an encoding equivalent in the stated time and length sense to the native SAT target. It supplies no time lower bound for that encoding.
