# A linear-length, bit-once DIMACS encoding of binary matrix mismatch

For three binary $d$-square matrices there is a dense, proper ASCII DIMACS file of $N=\Theta(d^2)$ **bits**, with exactly
$$\#\operatorname{SAT}(F_{A,B,C})=\bigl|\{(i,j):(AB)_{ij}\ne C_{ij}\}\bigr|,$$
where multiplication uses $\mathbb F_2$. Each of the $3d^2$ source bits occupies exactly **one** ASCII low bit, at a distinct position, and every other output bit is constant for that dimension. All declared variables occur. Every clause has exactly three distinct names. The construction is implementable in $O(d^2)$ native steps given the explicitly packed entries. The unrestricted RAM hypothesis is used only in subsequent applications to a putative solver.

The earlier mismatch verifier used $O(d^2)$ gates and $O(d^2\log d)$ encoded bits. Recovering the logarithm while keeping each bit in only one place matters both for read-once programs and for lower bounds measured per encoded bit. We use the journal's [shared truth-table construction](balanced-selector-probes-on-compact-sat-files.md) and its [decimal digit names](checking-the-sat-circuit-bound.md). Small function tables serving as precomputed parts of a larger Boolean circuit are classical. [Frandsen and Miltersen](https://doi.org/10.7146/brics.v12i9.21875) · [Original mismatch test](verifying-matrix-products-from-sat.md)

## Selecting one erroneous coordinate

First let $d=2^t$. Choose a power of two $b=2^{\max(0,\lfloor\log_2 t\rfloor-3)}$ for $t\ge1$, with $b=1$ at $t=0$. Asymptotically $t/16<b\le t/8$. A chunk is a length-$b$ string of actual matrix bits. The two free $t$-bit selectors $i,j$ identify an entry. Build deterministic one-hot decoders for their high parts, low parts and the full value of $i$ as needed. A binary prefix tree of equivalences realizes each decoder in $O(d)$ gates and has unique wire values. Introduce proposed values $a_k,b_k$ for the selected $A_{ik},B_{kj}$ and a proposed bit $c$ for $C_{ij}$.

Use a separate library for each column of $A$, each row of $B$, and one for $C$. Within one library write $y$ for its proposed bit and $u$ for its low selector: the low bits of $i$ in an $A$ column and those of $j$ in the other cases. For every $b$-bit mask $m$ define a Boolean variable
$$S_m=[y=m[u]].$$
For each $0\le h<b$ the public low-selector flag for $u=h$ conditionally enforces $S_m\leftrightarrow[y=m[h]]$ by two ternary clauses. Exactly one low-selector flag is true. Every library variable, including a variable never chosen by the matrix, therefore has a unique value once those bits are given.

For an $A$ column, each chunk contributes the single clause saying that if the high part of $i$ selects that chunk then its $S_m$ must be true. Pad this implication by one forced-false literal to width three. Do the corresponding operation in each $B$ row. A chunk of row $i_0$ in $C$ uses the clause $(\neg[i=i_0]\lor\neg[j_{\rm high}=g]\lor S_m)$ for its chunk number $g$. The chosen mask name appears **once** in each data clause. Every matrix bit belongs to one chunk in one such clause. The active clauses force all $a_k,b_k,c$ to their intended values. A deterministic chain of AND and XOR gate equivalences then requires $c\ne\bigoplus_k(a_k\land b_k)$. Thus for each choice of $i,j$ there is precisely one completion if it witnesses an error and none otherwise. In particular one error gives one model on the full declared name range. For a general $d$ add zero rows and columns through the next power of two to all three matrices; the erroneous coordinates and their count are preserved.

## Paying for identifiers, layouts and the RAM construction

Use bank prefixes $1,\ldots,2d+1$. Write the positive decimal name of $S_m$ as its bank number followed by the $b$ characters 0 or 1 of the mask. Suffixes have exactly $b$ digits, so different banks cannot alias. This is an ordinary decimal DIMACS token. Use names 1, 2 and 3 as false bits, forced jointly by the seven proper clauses excluding all other settings. Give the other gates fresh names above the bank range. Force each unused numerical name in the reserved range to zero with a clause padded by two false bits. This gives unique values even to the fillers. A short fixed clause can always be filled with distinct false bits outside its variable set. For $d=1$ coincident selector constants simplify first.

The three types of data clauses total $3d^2/b$. All libraries together require $O(d b2^b)$ fixed clauses and the vacant dense names require $O(d10^b)$. Both are $o(d^2/t)$ at the chosen $b$. The decoders and parity circuit use $O(d)$ further clauses. Names have $O(t+1)$ decimal digits each. This proves $N=O(d^2)$; the distinct changing digits give the reverse bound. The header and all punctuation and bank prefixes are public. Changing a source bit changes just the low bit distinguishing ASCII 0 from 1. Constructing all fixed records by direct enumeration and writing their decimal names costs $O(d^2)$ word steps. One can precompute the decimal representations of all used ordinals in total linear output cost, by extending prefixes in a radix-ten tree. For nonsequential references into a physically packed row-major input, first transcribe the three source matrices sequentially into scratch with $2^p$ useful bits per word, where $p=\lfloor\log_2 w\rfloor$ for the native width $w$. Reset the original lane counter whenever it reaches $w$. The new layout uses $O(d^2/w)$ words, and a bit ordinal gives its address and lane by a shift and mask. Thus even transposed references take constant work per emitted data digit in the separate-operation ISA without integer division. Write the output sequentially, packing bytes with a running lane counter. Decimal names contain $O(w)$ bits each, so their precomputed digit strings also need only $O(1)$ native words per used ordinal. The number of ordinals is $O(d^2/\log d)$, leaving room for the input, scratch and packed output at standard word width for sufficiently large dimensions.

The length statement also permits padding to an arbitrary sufficiently large byte length. The lengths for consecutive power-of-two sides have bounded ratio and grow unboundedly, so one can choose a dimension with $d^2=\Theta(N)$ whose template fits and append fixed whitespace. This preserves the changing-bit map and the model count.

The [executable audit](compact_product_projection_audit.py) parses the serialized files, checks dense names and three distinct literals per clause, enumerates complete assignments with PicoSAT, and decodes the chosen coordinates. It checked 44 files, 284 satisfying assignments and 267 separate one-bit edits on five layouts. The asymptotic construction and size proof are manuscript results.

## Consequences for ordinary SAT files

The product-graph rectangle theorem gives $2^{\Omega(d^2)}$ lower bounds for a deterministic read-once branching program deciding either matrix verdict, or a DNNF for the equality verdict. Restricting a representation of a SAT file to the fixed bits above and identifying each remaining pin with its distinct source bit preserves the read-once and decomposability conditions. Thus deciding ordinary DIMACS **SAT** on $N$ input bits takes $2^{\Omega(N)}$ vertices in deterministic free binary decision diagrams. Recognizing **UNSAT** takes $2^{\Omega(N)}$ in decomposable negation normal form, including nondeterministic syntactic read-once branching programs via their conversion to DNNF. The circuit need only be correct on well-formed files; the restriction never supplies any other input. General algorithms can copy and reread data. No priority claim is made for the SAT read-once lower bound. [Product rectangles and knowledge-compilation references](product-rectangles-at-adaptive-cuts.md)

An exact bit-network lower bound $V(d)$ for matrix verification would now transfer to a SAT Boolean circuit lower bound of order $V(d)$ whenever $V(d)/d^2$ grows unboundedly, at input length $N=\Theta(d^2)$. The construction removes the input-encoding log loss from the [earlier implication for unrestricted SAT](list-and-matrix-costs-for-ram-and-tapes.md). Validating a general adaptive RAM trace in a tensor network still incurs the memory verification and instruction costs. The next result instead runs the actual RAM on these very files and tracks its memory traffic directly. [Unrestricted RAM access traces](travel-in-actual-sat-ram-runs.md)

On this specific projection, a promise of at most $O(d/\log d)$ satisfying assignments yields a matching $\Theta(d^2)$ Boolean circuit bound. [Sparse-error verification](sparse-product-verification-bit-circuits.md)
