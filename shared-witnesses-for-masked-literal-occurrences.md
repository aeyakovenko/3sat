# Exact isolation with globally shared witnesses for masked SAT files

Give each literal occurrence $o$ of a fixed proper 3-CNF $F$ an enable bit $e_o$. At mask $E$ keep just the literals whose bits are one. A clause with no enabled literal is false. The output must decide SAT for **every mask**, including after independently disabling different occurrences of the same signed variable.

Allow a verifier as many globally shared hidden bits as it likes. Each constraint can inspect all these bits. A constraint can inspect at most one enable bit, and its dependence on that bit must be increasing. A proper CNF row containing just one positive enable literal is a special case. Individual enables may appear arbitrarily often. Only the mask is fixed when counting hidden assignments. In this model the attainable minimum number of accepting witnesses at $E$ is exactly the number of **consistent selections of one enabled occurrence per clause**. Consistency means no variable is selected in both signs. The same verifier attains the minimum at every mask.

In particular, for a uniquely satisfiable $7m$-clause source the minimum at the fully enabled mask can already be $24^m$, allowing all hidden variables to be shared. To keep the number of accepting witnesses at most two at *every* mask of this file, at least $5m-1$ different enables must permit a negative test. This is sharp. Requiring the positive output count to equal one modulo two at every satisfiable mask instead gives a different exact minimum of $189^m$ actual assignments at the fully enabled mask.

## Why shared auxiliary variables do not identify the minimal masks

For a fixed hidden assignment, either some constraint fails for both values of its observed bit, or the acceptable masks are precisely all supersets of some required set $R$. Intersecting any two masks accepted by this assignment preserves acceptance. Every minimally accepted mask $P$ therefore needs a witness whose required set is exactly $P$. Such a witness survives on every $E\supseteq P$. Distinct minimal masks need distinct witnesses. These are the minimal true points of a monotone Boolean function, equivalently its monotone prime implicants. Conversely one witness per minimal mask suffices. [Lean check of the intersection and injection](SharedEnableWitnesses.lean) · [Fredman and Khachiyan on monotone normal forms](https://www.cs.tau.ac.il/~fiat/dmsem03/On%20the%20complexity%20of%20Dualization%20of%20monotone%20Disjunctive%20Normal%20Forms%20-%201996.pdf)

For masked SAT, each consistent one-per-clause selection suffices by assigning the selected signed variables their required values. Every accepted mask contains such a selection by retaining one true literal of each clause under a satisfying assignment. Each selection becomes rejecting if any chosen occurrence is removed. Thus these are exactly the minimal masks, even with repeated variables or opposite signs across clauses.

There is a uniform implementation of the exact minimum. Guess selection bits, enforce exactly one per clause, and for each variable prohibit simultaneous use of a positive and a negative occurrence. Two OR trees per variable suffice. Test each selected occurrence against its enable with a positive port row. Gate equivalences fix all temporary bits uniquely. Distinct fixed-false bits pad short rows to proper ternaries and can themselves be uniquely forced. This uses $O(q+1)$ clauses and names for a source with $q$ clauses, or $O((q+1)\log(q+2))$ explicit DIMACS bits. It takes linear encoded time and length on the family below. The use of global consistency avoids guessing truth values for variables never selected. In a clause-by-clause encoding which retains the original assignment, each consistent selection is instead counted once for every source assignment extending it. ## Exact price of allowing some negative enable tests

Suppose $F$ has one satisfying assignment $\alpha$. Strengthening its clauses by disabling occurrences cannot create a different satisfying assignment. Let $t_i\ge1$ be the number of true occurrences in clause $i$ under $\alpha$. As a Boolean function of the mask, the answer is the conjunction of the disjunctions of those $t_i$ separate bits. Occurrences false under $\alpha$ are immaterial to this function.

Allow an arbitrary fixed set of enables to be tested in either polarity. A constraint, after those signed enables have been fixed, may now depend arbitrarily on hidden bits and at most one other enable, monotonically. Write $h_i$ for the number of signed enables among the $t_i$ live occurrences of clause $i$. The minimum achievable **worst-case number of accepting witnesses over all masks** is
$$
                      \prod_i \max(1,t_i-h_i).
$$
For the lower bound, in every clause with a live unsigned enable fix its signed live enables to zero. In the remaining clauses enable one signed live occurrence. Fix all other signed bits consistently with these choices. Set all unsigned bits to one at the test input. The residual function is an independent OR on each nonempty set of surviving unsigned live bits. It has the displayed number of minimal positive masks below that input. The shared-witness proof still applies on this restriction.

For equality, order the signed live enables within each clause. If any are on, allow exactly the first one as that clause's selection. If none are on, allow any enabled live unsigned occurrence, tested only positively. The choices multiply. One can implement this without being given $\alpha$ by guessing a satisfying source assignment, testing its literals in the selection and enforcing that priority. On this family any successful choice forces the guessed assignment to equal $\alpha$. Signed enables can be copied into internal wires by two implications, one per polarity. The other enables only need the positive test on a chosen occurrence.

Take $m$ independent triples of variables. On each put the seven proper clauses forbidding every assignment except $111$. Per triple the values $t_i$ are $3,2,2,2,1,1,1$. At the full mask the positive-only optimum is $24^m$. For any $h$ distinct enables allowed to be tested negatively, the displayed worst-case product is at least
$$
                 1+\sum_i(\max(1,t_i-h_i)-1)\ \ge\ 1+5m-h .
$$
Allow all but one live bit in each clause to be tested negatively, except in one clause where two live bits remain unsigned. This uses exactly $5m-1$ signed enables and gives maximum ambiguity two. With $5m$ it gives maximum ambiguity one. These counts concern which bit positions may occur in negative tests somewhere in the verifier. An ordinary RAM instruction reading a packed word can obtain information of both polarities about its bits.

The whole tradeoff can be optimized on this example. For $0\le h\le3m$ the optimal worst-case ambiguity is $24^m/2^h$. Each of the $3m$ two-choice clauses can be reduced by a factor two for one signed position, the largest possible reduction per position. After those choices are used, put additional signed positions in pairs into the three-choice clauses. Two tests there give a factor three, while distributing one each over two untouched three-choice clauses gives only a factor $9/4$. Giving priority to the two-choice clauses is optimal even across this boundary: moving one signed position from a three-choice clause to an unresolved two-choice clause never increases the product. With $h=3m+2j$ the result is $3^{m-j}$. With $h=3m+2j+1\le5m$ it is $2\cdot3^{m-j-1}$. It stays one for $h\ge5m$. [Exhaustive single-block mask and signed-use audit](shared_enable_mask_audit.py)

## Congruences with an exact decision bit

Require zero witnesses at every rejecting mask, and a count congruent to **one** modulo a fixed prime $p$ at every accepting mask. Write $g$ for the SAT decision bit of the masked file. Let $d_R$ count the hidden assignments with required set exactly $R$. Then $f(E)=\sum_{R\subseteq E}d_R$ is the physical witness count. By Boolean-lattice Möbius inversion,
$$
 d_R\equiv \mu_g(R)=\sum_{J\subseteq R}(-1)^{|R|-|J|}g(J)\pmod p .
$$
Each $d_R$ is at least the least nonnegative residue. An unrestricted finite verifier attains these least residues simultaneously by labeling its witnesses by $R$ and a residue-sized counter. Enforce the $R$-membership bits with positive single-enable checks. All disallowed labels are rejected independently of the enables. If $g(E)=0$, monotonicity gives $\mu_g(R)=0$ for every $R\subseteq E$, so rejection has literally zero witnesses. The unrestricted representation can store the entire table of coefficients. [Rota on Möbius functions](https://webhomes.maths.ed.ac.uk/~v1ranick/papers/rota1.pdf)

For a uniquely satisfiable source the calculation is explicit and efficiently realizable. At an accepting mask let $s_i$ be the number of enabled live occurrences of clause $i$. The nonzero coefficients come from choosing a nonempty subset in each clause, using no dead occurrences. They equal $(-1)^{|R|-q}$. The number of such subsets below $E$ is $H=\prod_i(2^{s_i}-1)$, and the signed sum is $g(E)=1$. Hence the positive and negative coefficient counts are $(H+1)/2$ and $(H-1)/2$. The attainable minimum actual number of models is
$$
                      1+p(H-1)/2 .
$$
To realize it, guess a source assignment and a nonempty subset of its true occurrences in each clause. Only selected occurrences require an enabled bit. There is one possible source assignment on every positive query. For even $|R|-q$ allow one counter code, and for odd parity allow exactly $p-1$ codes. Deterministic gate equivalences compute the parity and counter comparisons. There are $O(q+\log p+1)$ clauses and names, with logarithmic overhead in physical bits. At a rejecting mask no selection exists.

For the $7m$-clause family at the full mask, $H=(7\cdot3^3)^m=189^m$. In characteristic two this is the exact minimum. For odd $p$ the global parity check can be shared across all clauses. The separate-clause minimum instead multiplies the individual local counts. Signed tensor weights allow additional cancellations. This example pinpoints the cost of single-enable monotone tests even with arbitrarily shared hidden state; the one-sort promised SAT construction uses a more general computational model.
