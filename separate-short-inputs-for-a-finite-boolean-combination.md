# A tree of short inputs for a finite Boolean combination of fast computations

On a logarithmic-word RAM there is a nondeterministic language decidable in \(O(n)\) native steps which no fixed Boolean combination of a constant number of the following predicates decides on all inputs: each predicate runs nondeterministically in \(o(n)\) native steps and uses at most \(O(n)\) binary guess bits on every path. The outer language may guess whole words. There is a version with a one-bit-guess outer machine when the component machines' guess bits are \(o(n)\). In particular this latter version applies to \(o(n)\)-time machines whose only guess instruction produces one bit. These are time-hierarchy statements about diagonal languages. No family of SAT instances is involved, and nothing here bounds the time needed to decide a supplied SAT file.

A separate choice of stretch gives the full-word-guess statement
\[
  H\in \operatorname{NTIME}_{\rm word}[O(n)],\qquad
  H\ \text{outside every fixed Boolean combination of}\quad
  \operatorname{NTIME}_{\rm word}\!\left[o\!\left(\frac{n\log\log n}{\log n}\right)\right].
\]
Here no additional guess cap is imposed: one guess instruction may return a whole native word. The hard inputs in these linear-clock statements have a binary track field and a zero tail. For polynomially separated clocks, \(O(\log n)\) bits suffice to describe each entire hard input. For each fixed number \(k\) of components there is also a source with **only unary inputs** when \(k\) and the polynomial exponents meet the capacity inequality below.

The numerical primitive is delayed diagonalization, as in Žák's nondeterministic time hierarchy. Bounded-query separations across exponential and polynomial time have been proved by Fu, Li and Zhong, Mocas, and Fu, Li and Zhang. Those results treat a different clock regime; we do not assert priority for separate-track diagonalization or for the precise native bounds. [Žák](https://doi.org/10.1016/0304-3975(83)90015-4) · [Fu, Li and Zhang, introduction and §5](https://faculty.utrgv.edu/liyu.zhang/cocoon118.pdf) · [Buhrman, Fenner, Fortnow and Torenvliet on the relativized boundary](https://lance.fortnow.com/papers/files/nexp.pdf)

## Which computation runs at each input

Fix component programs \(A_0,\ldots,A_{k-1}\), \(k\ge2\), and a Boolean truth table \(f\). Write \(Q(x)=f(A_0(x),\ldots,A_{k-1}(x))\), where each \(A_j(x)\) is its existential acceptance bit. Repeated predicates, negations and constants are permitted; no nesting of their accepted sets is required. For a depth \(L\) use physical lengths \(n_0=B<n_1<\cdots<n_L\), with \(k^{L-i}\) distinct inputs at length \(n_i\). The longest input is the root. Each node at stage \(i+1\) has \(k\) different children at stage \(i\). Number them \(0,\ldots,k-1\).

At a nonroot input \(x\) with parent \(y\) and child number \(j\), the source simulates **only** \(A_j(y)\) nondeterministically within its own clock. At the root it deterministically exhausts all the component computations on every short leaf, computes the Boolean bits \(Q\) there, and evaluates the finite tree upward with \(f\) as the internal gate. It returns the opposite of that computed root bit. The last operation is allowed time based on the root's large physical length.

If \(Q\) agreed with the source everywhere in the tree, then for each parent \(y\) its children's \(Q\) values would be exactly \((A_0(y),\ldots,A_{k-1}(y))\). Thus \(Q(y)\) would equal \(f\) applied to their \(Q\) values. Induction from the actual short leaf verdicts would identify \(Q\) at the root with the value the root flips. Hence at least one input disagrees whenever the prescribed simulations finish faithfully. This is a separate site for each component, with unrestricted Boolean evaluation of all the **short** verdicts at the endpoint. Copying or negating one monotone functional of nested predicates at each site gives a different abstract system. [The monotone fixed-point argument and its scope](whole-intervals-without-a-fast-negative-sat-certificate.md)

One fixed source can treat the component count, literal program texts and the table \(f\) as self-delimiting fields on the padded inputs. The rest of a structured input encodes the base \(B\), the stretch parameters, the tree depth, its stage and a root-to-node sequence of \(h=\lceil\log_2 k\rceil\)-bit child numbers, then zeros. Equivalently reserve a fixed-size metadata prefix for a given tree and place the sequence immediately after it. The program validates lengths, stages and digit ranges within a hard native work cap, defaulting to reject on malformed input or exhaustion. Finite codes of unbounded size therefore do not change its global clock. For each fixed list and truth table, all their decoding constants are fixed while \(B\) grows. Nonunary encodings of different trees can coexist even at the same physical length.

To simulate the parent, replace the stage field, remove the last child number and extend the zero tail. The modified header uses a fixed number of native registers on structured inputs (the opponent code itself can be viewed as a fixed range of the original input). An aligned or crossing parent input word is formed from constantly many header words and original track bits with masks and shifts. The guest input length is the parent's *physical* length, including its long zeros. Wider parent words occupy constantly many host limbs when \(\log n_{i+1}/\log n_i\) is bounded. Simulate its distinct writable cells by the usual sparse constant-depth radix trie on those limbs, with separate interpreter and guest banks. For constant limb count the usual native arithmetic and virtual input operations have fixed overhead per guest instruction for a fixed opponent. Reserve a sufficient fixed multiple of \(\log(n+2)\) host bits for polynomial clocks; the journal's factor twelve suffices for the quadratic and cubic examples. More generally take the width constant larger than the outer polynomial time exponent plus fixed addressing slack. [Native guest-width and sparse-memory simulation](native-unary-clock-band.md)

For endpoint exhaustion, stream each short machine's choices in their chronological order from a padded candidate bit string. A word guess consumes its full native word width, a bit guess one bit. Input-independent padding of unused bits preserves the existential verdict. Impose both the specified step cap and the supplied bit cap, including on bad guesses. The root runs deterministic finite simulations only. It can clear scratch by a touched list, enumerate all track strings and evaluate their finite tree by depth-first traversal. For fixed \(k\), leaf time at most \(B^{O(1)}\), depth \(L\le B^{O(1)}\), leaf bit cap \(G\le B^{O(1)}\), and fixed Boolean table, a sufficient terminal step bound is
\[
              k^L\,2^G\operatorname{poly}(B).
\]
This includes construction of each leaf's \(B\)-bit physical payload and all internal Boolean gates. The program need not construct the long parent strings at the other sites. Each of the applications leaves enough exponential slack above this endpoint estimate and allows setup within the advertised source clock.

## The linear native clock

Let \(B=2^b\). Put \(L=\lfloor B/(8h)\rfloor\) and \(n_i=B2^{ui}\), so all short track fields fit in \(B/8\) bits plus metadata. The current stage calculation uses \(\log_2 n_i=b+ui\) and never constructs an exponentially longer root on a short host. On malformed inputs comparisons and all parameter processing are bounded by the source's global linear clock. On the valid trees even a complete \(O(n_i)\) format scan fits with a fixed overhead; packed copying or testing the padding is also available.

For predicates of \(o(n)\) native time and at most \(Cn\) guessed bits choose a fixed integer \(g>C\). Encode \(G=gB\), or the multiplier \(g\), in the tree's common metadata. Choose a fixed \(u\) sufficiently larger than \(h+8hg\) that \(n_L=B2^{uL}\) exponentially exceeds \(k^L 2^G\operatorname{poly}(B)\). The stretch \(2^u\) is a constant for this opponent. Every interior guest's actual clock is \(o(n_i)\) at all sufficiently large bases, even after simulation. Each short computation also fits a polynomial step cap, for example \(B^2\). This proves the first statement with a whole-word-guess outer source. If the competing computations each use \(o(n)\) **bits**, replacing each guest word choice by individual bit guesses costs a total of \(o(n_i)\) additional native steps at the fixed stretch. This gives the one-bit-guess outer version. The same physical linear-clock machine can allow \(u,g\) as parameters on its inputs; no uniform constants on the competing family are being assumed.

For the displayed full-word-guess clock, use \(u=\max(1,\lfloor (\log_2 b)/2\rfloor)\). Then \(2^u=O(\sqrt{\log B})\). On every interior parent length \(m\ge B\), its time bound divided by the child length is at most
\[
    o(1)\,2^u\frac{\log\log m}{\log m}=o(1),
\]
uniformly as \(B\to\infty\) by eventual decrease of the log ratio. With a fixed machine word-width constant, all bits guessed on a leaf number \(o(B\log\log B)=o(Bu)\). Set, for example, \(G=\lfloor Bu/(32h)\rfloor\). This dominates the genuine leaf choices for large \(B\). The terminal exponent \(uL\) exceeds \(G+L\log_2 k+O(\log B)\) by an unbounded positive multiple of \(B\). Interior guesses here are simulated as whole words. This proof does not exclude every \(o(n)\)-time *whole-word*-guess Boolean decomposition without a separate guess cap.

When the relevant components on all structured inputs use \(O(n/\log n)\) guessed bits, the fixed-stretch construction can instead use \(L=\Theta(B/\log B)\), with the constants tuned to the component bound. Then every track has a zero-padded description of \(O(B/\log B+\log n_i)\) bits. A raw unary input does not have room for freely selecting this many different track bits at a single length.

## Polynomial clocks, and when only unary lengths suffice

Fix rational \(1\le p\), \(0<q<p\), and opponent time \(O(n^{q+o(1)})\). For a fixed rational \(1<a<p/q\), start with \(b_0=\log_2 B\), let \(b_{i+1}=\lceil a b_i\rceil\) and \(n_i=2^{b_i}\). For full word guesses take \(L\) minimal with \(b_L\ge B^{q+\theta}\), for sufficiently small fixed rational \(\theta>0\). Then \(L=O(\log B)\). Whole-word guest choices may even be simulated with one outer bit instruction per guessed bit because \(n_{i+1}^{q+o(1)}\log n_{i+1}=o(n_i^p)\). At the root an upper bit cap \(G=\lceil B^{q+\theta/2}\rceil\) dominates the actual leaves, and their enumeration fits in \(n_L^p\). All track, stage and common metadata have \(O(\log n_i)\)-bit descriptions, including the literal zero tail via its endpoint. Thus for every polynomial gap \(p>q\) this method gives a padded, binary-describable \(O(n^p)\)-time one-bit-guess source outside such a fixed Boolean decomposition.

For a **tally** source, suppose in addition that the number of guess bits at length \(n\) is at most \(n^{\beta+o(1)}\), with \(\beta\ge0\). If
\[
                         q k^\beta <p,
\]
choose \(k^\beta<a<p/q\), and then \(\theta>0\) with \(k^{\beta+\theta}<a\). Use the first \(L\) with \(b_L\ge B^{\beta+\theta}\). There are
\[
       k^L \le B^{(\beta+\theta)\log_a k+o(1)}=o(B)
\]
short leaves. At stage \(i\) give its \(k^{L-i}\) tracks the actual unary lengths \(n_i+j\), \(0\le j<k^{L-i}\). Their blocks are disjoint for large \(B\). The parent of rank \(j\) is the unary string of length \(n_{i+1}+\lfloor j/k\rfloor\), with selected component \(j\bmod k\). Simulation on the virtual all-one string and the two end markers takes constant input work per guest access. The leaf clock is polynomial in \(B\) and its actual bits fit \(B^{\beta+\theta/2}\), even though a leaf may have length up to \(2B\). Root time dominates all short computations as before.

For a single fixed unary program, use disjoint epochs starting at powers of two \(B\), with next start \(2^{B^r}\) for a fixed integer \(r>\beta+\theta+1\). Cycle the fixed-arity opponent codes and Boolean tables so each reappears infinitely often. Code recovery and epoch tests use saturated comparisons with \(\log_2(n+2)\); form the huge next length only when within range. Stage exponents up to \(O(B^{\beta+\theta})\) themselves take \(O(\log B)\) bits. At a genuine stage the current and parent lengths fit constantly many current-width limbs. Off-stage unary lengths return a default; reject nonunary inputs after a packed scan. The per-input source budget is \(O(n^p)\). Thus all of these hard inputs are literally unary. Full word guesses permit \(\beta=q\) with the strict slack. For example \(p=2,k=3,q=\beta=2/3\) satisfies the inequality. So does \(p=2,k=3,q=1,\beta=1/2\) when the guess restriction is supplied. The component predicates in the sublinear-time unary example need agree only on the designated unary inputs. The inequality is sufficient for this particular track layout; there is no converse hierarchy claim.

## An unknown patch to a physical SAT file

Apply the binary linear-clock source to a compiler required to cover all of its designated tracks. Suppose the correct ordinary SAT file is given by a proposed base file with either zero or one genuine patch, at an unknown site. An index names a candidate site, and there is a sound fast test that it is an actual discrepancy and recovers its correct replacement. The true number of discrepancies need not be supplied. Assume three specific procedures meet the \(o(n)\) native time and \(o(n)\) guessed-*bit* bounds on all branches:

* verify that the unpatched base file is satisfiable;
* guess and verify one actual discrepancy;
* guess and verify one actual discrepancy and verify satisfiability of the file with that patch made.

Call the resulting nondeterministic predicates \(P,U,V\), respectively. The genuine answer equals \(V\lor(P\land\neg U)\). The multi-input theorem excludes an always-correct compiler of this form even when the pristine SAT verdict itself is unknown. For example it suffices that the base and any one genuinely corrected proper file of \(M=O(n)\) bits can be produced as actual packed words in \(o(n)\) native work, a true patch can be certified within those two resource caps, and its site and replacement have \(o(n)\) guessed bits. The packed ordinary verifier then uses \(O(1+M/\log(2+M))\) further steps and guessed bits. False candidate sites and malformed branches must stop within the same bounds. If the target is promised valid only after all repairs, a total time-capped scanner must handle other files with a specified base semantics. [Packed SAT verifier and its physical name conventions](packed-verification-of-locally-indexed-unique-sat.md)

For a fixed upper bound \(r\) on the number of genuinely distinct patches there is a finite Boolean extension. Let \(U_j\) certify \(j\) distinct genuine sites and \(V_j\) certify those sites and satisfiability after all \(j\) specified changes, taking \(V_0=P\) and \(U_{r+1}=0\). Use \(\bigvee_{j=0}^{r}(V_j\land\neg U_{j+1})\). Only the actual full patch count can give a true disjunct, since \(V_j\) itself witnesses at least \(j\) changes. This application requires the per-component clocks, bit budgets and soundness on partial proposals as above. It concerns a stronger required compiler domain than one selected earlier unary program; the linear construction uses different short track inputs. The pure-unary polynomial variant applies to its own source if its quantitative bounds hold. No rate for deciding an already supplied ordinary SAT file follows from these obstructions.

Lean proves the abstract relay: if a query equals the gate applied to its components at every site, and each child's query equals the corresponding component of its parent, then evaluating the gate tree on the leaf queries returns the root query, so a root that outputs the opposite bit disagrees. It also proves the one-patch truth table. The audit exhausts the relay on small trees with arbitrary component bits, the patch-count formula for at most three candidate patches, and exact integer instances of the unary and linear capacity inequalities. The constant-overhead native simulations, the endpoint exhaustion cost and the asymptotic capacity statements are manuscript arguments that rely on the cited simulation notes.
