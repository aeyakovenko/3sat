# A canonical short witness for a locally indexed SAT formula

For every well-formed proper ASCII DIMACS formula of length $M$ bits with canonical decimal variable names, there is a binary proof of length $O(1+M/\log(2+M))$ per satisfying assignment to the occurring names. **Each assignment has exactly one proof.** A bad proof has a local counterexample: a test with $O(\log(2+M))$ address bits reads a constant number of proof records of $O(\log(2+M))$ bits each and $\operatorname{polylog}(2+M)$ raw formula bits. The position challenge can be chosen adversarially. All tests are computed uniformly in polylogarithmic time with random access. Counts include no unused names from the header.

The earlier short check allowed several choices of a hash function. The packed, multiplicity-preserving verifier needed to scan the physical output. Here the order of long decimal tokens and their adjacent longest common prefixes have unique certificates. This removes the scan and preserves the number of accepted witnesses when the bits of the formula are supplied by a local indexer. Short guesses for explicit SAT and verification of string order both have earlier literature. Priority for this combination has not been established. [Earlier local challenge](compact-compilers-and-linear-sat-time.md) · [Packed verification](packed-verification-of-locally-indexed-unique-sat.md) · [Salamon and Wehar, effective guessing](https://doi.org/10.1007/s00224-023-10119-x) · [Burkhardt and Kärkkäinen, suffix array checking](https://www.cs.helsinki.fi/juha.karkkainen/publications/cpm03.pdf)

## Certificate and local tests

Write $H$ for a positive integer of order $\log(M+2)$ **bytes**, small enough that $10^H\le (M+2)^{1/4}$ for large $M$, and $B=\Theta(\log^2(M+2))$ bytes. Use ceiling arithmetic and fixed separate rules for bounded $M$. All unused fields and padding bits are zero. Align the following records in arrays of known capacity.

1. At each $B$-byte boundary put the unique state of the lexical scanner. Its $O(\log M)$ bits record the header/comment mode, token and sign state, start offsets and the last three completed literal intervals of the current clause. A test checks the initial state or replays one block to the next boundary. Use synthetic terminal whitespace. These tests force the states by induction. From the boundary before any nominated byte, the tester can determine the lexical state there using at most $B$ raw bytes. In particular, at a separator ending a numeral, it knows the entire numeral's start. Ends of clauses identify their three literal intervals and signs.
2. For each short positive name of at most $H$ digits store a bit and a first-digit offset, with a distinct absent marker. A nonabsent pointer must point to a literal spelling precisely that name. At every occurrence, its table pointer must be nonabsent and no later than this occurrence. An absent name has bit zero. These checks force every pointer to be precisely its first occurrence, so unused bits cannot multiply the count. The entire table costs $O(10^H\log(M+2))$ bits.
3. For every aligned $H$-byte block supply one bit. Use it for a literal whose digit string has length greater than $H$ and starts in that block. At most one such start fits. Check that the bit is zero if it has no such occurrence. The tester can decide this by replaying the block with its lexical state and looking at the next $H$ digits of a possible start. This takes polylogarithmically many raw probes and constantly many boundary states, even at a block crossing. For a proposed pair of names with lengths between $H+1$ and $B$, a test compares their digits directly and rejects different truth bits for equal strings. Signs play no role in grouping the underlying names.
4. Reserve one slot for each aligned $B$-byte block. It stores the two endpoints of a literal digit string of more than $B$ digits starting there, or is empty. There is at most one such start per block. Scan at most two blocks of raw bytes to see whether that start exists, and check any claimed end by reading the lexical state at its separator. That separator must close the numeral having the claimed first digit. Thus the slot list is unique, including for unusually long variable names.
5. Supply a permutation of all the slots. An out-of-range entry or a repeated image can be exposed by at most two positions. Require empties before occupied slots and increasing slot numbers on adjacent empty entries. Order occupied slots by their full digit strings lexicographically, breaking equalities by starting offset. For each adjacent occupied pair give an integer $l$ claimed to be the length of their common prefix. Other adjacency fields are zero. Check $0\le l\le\min(|u|,|v|)$. A challenge can specify *one* offset $j<l$ and compare the two raw digits there. At position $l$, either both strings continue and the next digits are strictly increasing, or the left one ends first, or both end together. In the last case require increasing starts and equal truth bits from the $H$-block array. A right string ending strictly first is rejected. These tests force the exact longest common prefix, including for equal or prefix-related strings. They force a unique total order on the positions. Equal names occur consecutively, so equality of the assigned bits propagates through a whole name group. No comparison needs to read an entire unbounded numeral.
6. A clause test reads the bits for its three occurrences and rejects three false literals. A malformed range, pointer, permutation entry, link, or nonzero unused field has its own challenge. All ranges and addresses have canonical fixed-width representations. Tests on a well-formed file do not need to guess where the file ends.

The block-bit array costs $O(M/H)$ bits. The lexical states, endpoint slots, slot permutation and prefix lengths cost $O((1+M/B)\log(2+M))$ together. All tables other than the truth bits are uniquely fixed by the file. On a satisfying assignment the bits are uniquely fixed as well, and conversely every passing certificate defines one assignment. A family of disjoint proper clauses on distinct dense names has $7^m$ satisfying assignments at length $\Theta(m\log(m+1))$, so the proof length is worst-case optimal in order for a one-to-one representation. [Lean checks for maximal common prefixes and first occurrences](CanonicalLongNames.lean) · [Physical truth-count and certificate corruption tests](canonical_local_names_audit.py)

Local verification here means a universally quantified set of tests. Scanning all possible challenges would exceed the claimed cost for an individual test.

## Clock descent with a promise on accepting branches

Suppose a deterministic SAT solver takes $O(N)$ time on the unrestricted word RAM. Under that hypothesis, there is no uniform compiler with the following properties, already for bounded native acceptance with **at most one accepting path**.

* It returns well-formed, canonically named proper DIMACS on the promised inputs. Output bits and length are readable in $\operatorname{polylog}(s+2)$ time on a native instance of size $s$ with a unary clock.
* On a native instance with zero accepting paths its output is unsatisfiable. On an instance with one accepting path its output has exactly one model on occurring names, and its length is $o(s\log(s+2))$ on those positive inputs, uniformly. Outputs on negative inputs may be longer; the length and addresses still fit a fixed number of native words, or the verifier rejects overlong lengths immediately.

Indeed the first diagonal program is deterministic, so its path count is zero or one. In the clock descent use the new proof instead of the hash-based witness. On a guessed complete proof $z$, construct one ordinary SAT file for the existence of a failed local challenge and run the assumed deterministic solver. With $u$ bits of physically stored payload, its construction and running time are $O(W+(u+1)\operatorname{polylog}(s+2))$, where $W=O(1+M/\log(2+M))$. This follows by the compact lookup construction: a constant number of whole proof records and bits are multiplexed using the decimal-mask library; raw file probes call the local indexer on the old virtually represented payload and unary clock. The distinct challenge types above use a bounded number of large-array reads. The raw scanning and arithmetic can use polylogarithmically many small local operations. Pad each final partial word of the guessed string canonically, rejecting every nonzero excess bit. Apart from guessing $z$, the new program is deterministic. Thus every accepting path is counted exactly once per output model. [Challenge-to-SAT construction and native diagonal](compact-compilers-and-linear-sat-time.md)

Fix a constant $R\ge2$. While the old cap $t>n^{3/2}$, make the new cap $\lfloor t/R\rfloor$, starting from $t=O(n^2)$ on the diagonal of input length $n$. The physically stored old payload only grows by $O(\log n)$ per round, and $s=(1+o(1))t$ in this range, as in the earlier descent. On sufficiently large positive instances all canonical accepting paths fit, since $W=o(t)$ and $(u+1)\operatorname{polylog}(s)=o(t)$. A negative input cannot gain a path by a timeout. The verifier may first compare the known $M$ with a polynomial bound in its submitted clock and reject if too long, without losing any positive satisfying the stated size bound. The controller only puts the preceding program, payload and binary clock in the new input. After $O(\log n)$ rounds the ordinary quasilinear bounded-run compiler and the hypothetical SAT solver decide the original diagonal in $O(n^{3/2}\operatorname{polylog}(n+2))$. This contradicts its deterministic quadratic hierarchy lower bound.

More generally fix constants $C,d\ge1$ and $\epsilon>0$. Assume the compiler is sound at zero; for native inputs of positive path count $A\le2^{t^\epsilon}$ with physically stored payload of at most $t^{3/4}$ bits suppose its outputs have $1\le A'\le (s+2)^C(A+1)^d$ models and uniformly $o(s\log(s+2))$ bits. The same contradiction follows. With $T=O(n^2)$ the initial cap, write $L_i=\log_2(1+A_i)$. Along positive descents $L_{i+1}\le O(\log(T+2))+d L_i$ and $L_0=1$. After $j$ rounds we have $L_j\le O(\log(T+2))(2d)^{j+1}$. There are at most $1+(\log_2 T)/\log_2 R$ rounds. Choose $R$ a sufficiently large fixed constant that $2\log_R(2d)<\epsilon$. Then the upper bound is $o(n^{3\epsilon/2})$, and throughout every round needing another compiler call $A_j\le2^{t_j^\epsilon}$. Induction makes all uses of the compiler promise legitimate. For the unambiguous case no multiplicity growth occurs and $R=2$ suffices.

## A slower indexer whose replies have short native proofs

In the descent theorem the formula bits may be much harder to access. Suppose that on the promised native inputs a fixed nondeterministic RAM, given the virtual source $y$, a valid bit address $j$ and a claimed bit $b$, accepts within $L=s^{1-\delta}$ steps **if and only if** $b$ is the actual output bit, for some fixed rational $0<\delta<1$, rounding the cap up to an integer. More generally use a uniform time-constructible clock, charging its setup time. Both possible replies must be covered by this exact specification. Different proofs of the same reply are allowed. For each bit of the output length it suffices to have a bounded nondeterministic test for that length bit being one. Assume the length uses at most a uniform $O(\log(s+2))$ bits. The same incompatibility with deterministic linear-time SAT follows on the same ambiguity promises. In particular a deterministic indexer running in strongly sublinear time suffices.

To see this, inside the new native verifier determine each bit of the length deterministically with the assumed SAT solver. Write an ordinary explicit instance for acceptance of the small length-test program with its bounded clock and run the solver. The input to that program consists of the actual short payload and the old clock in binary. Its wrapper answers reads of the old virtual unary-clock input through constant-size index arithmetic. The word widths of the wrapper and the old program differ by at most a fixed factor in this descent. The usual bounded-run compiler takes $O((u+1+L)\operatorname{polylog}(s+2))$ time and bits, including its physical output. There are only logarithmically many length queries. [Native simulation and bounded-run compiler](native-linear-time-and-locally-uniform-circuit-depth.md) · [Fortnow, Lipton, van Melkebeek and Viglas](https://lance.fortnow.com/papers/files/tst.pdf)

Next use one SAT instance to ask whether the guessed complete proof $z$ has a failed test. An ordinary nondeterministic computation guesses the challenge and the replies to its constant number of proof-record reads. It tracks the addresses of these reads. A range error in a proposed proof field has its own immediate failure test. All other tests check bounds before probing and use fixed public sentinels at the file ends. On each valid raw-bit request the simulated test guesses a reply and runs the reply certifier within $L$ steps. Reject this simulated challenge if certification fails. There are $\operatorname{polylog}s$ raw queries, including those from parsing local blocks. The total native work on the short physical payload is $O((u+1+L)\operatorname{polylog}s)$. In its ordinary chronological trace encoding expose the constant number of guessed proof-record words and their addresses by copying them into designated output slots. Memory consistency and CPU checks still have the usual quasilinear overhead, and the certifier never needs $z$ as a long physical input. At those exposed wires conjoin the compact data-lookup gadgets for the actual record arrays of $z$, with $O(W)$ encoded bits in total. This gives size and construction time
$$
                      O(W+(u+1+L)\operatorname{polylog}s)=o(t)
$$
on sufficiently large promised positive files. Each accepting inner trace proves a real local failure, and each real failure has such a trace. Multiplicity of inner traces is irrelevant because the outer verifier runs the **deterministic** SAT solver on that one test. Thus the outer path count still equals the number of output models. The extension also permits any indexed time $L(s)$ with $L(s)\log^{B}(s+2)=o(s)$ for a sufficiently large fixed $B$ covering these actual compiler and checking overheads. A length-computation or challenge that times out on a negative input cannot create an accepting outer path: the program times out as a whole, or runs the correct solver on a completed, correctly generated test.

The extra freedom in how bits are certified still has a soundness condition on negative native inputs. If all proposed bit replies could lack proofs there, the inner failed-challenge search could be empty for an invalid $z$. A useful candidate for this route must exhibit actual bounded proofs for the correct reply on those inputs too.

## Selecting a shortest presentation without increasing ambiguity

Consider a family of outputs $F(y,r)$ indexed by a polynomial-length pad of bits or words $r$. Suppose the predicate $|F(y,r)|\le k$ has an exact bounded nondeterministic test in time $L=s^{1-\delta}$, with the same effective clock convention as above. This is a one-sided threshold test: existence of an accepting path decides the inequality. It need not return a witness for a false inequality. Lengths have $O(\log s)$ bits. The test reads the pad by ordinary RAM probes. Assume the formula-bit reply certifier above works for minimum-length presentations. The semantic and model-count promises in the descent need hold **only for presentations attaining the globally minimum length**. Outputs at other lengths can have either verdict. The minimum must still be $o(s\log s)$ on promised positives. These hypotheses also give the contradiction to linear-time SAT.

The reason is that a single outer guess can select one canonical shortest presentation. Fix an input and let $k_*$ be its minimum output length. Take any pad attaining it and an accepting path of the length test at threshold $k_*$. Copy its initial contents on the at most $O(L)$ inspected pad words into an otherwise zero pad. In a writable-pad simulation preserve the initial values first read before overwrite. The same nondeterministic choices now follow the same path, so the sparse pad also produces length at most $k_*$. Global minimality forces equality. Unaligned reads crossing word boundaries only change the support bound by a fixed factor. This argument uses soundness of the threshold test on **every** pad.

Fix a canonical sparse encoding listing at most $C L$ nonzero word edits in increasing address order, with a count, fixed field widths and zero unused fields. Use a fixed threshold width covering every legal length and require zero unused bits in the last guessed native word as well. Its length is $O((1+L)\log(s+2))$. For each qualifying encoding and threshold $k$ order the pair $(k,\text{encoding})$ lexicographically, comparing the numeric threshold first. There is a unique least qualifying pair. Its threshold is $k_*$ by sparse replay. Its pad therefore meets the required verdict and multiplicity guarantees.

The outer verifier guesses this entire pair, checks the canonical format, and runs the hypothetical **deterministic** SAT solver on two ordinary instances. One asks whether its length test has an accepting path. The other asks whether there is a strictly earlier qualifying pair. For the second instance guess one candidate pair and an accepting path of its length test. Sparse edits can be looked up in a sorted array in $O(\log(s+2))$ time per probe, while simulated writes use the verifier's private memory. Comparing two encodings and checking their format takes $O((1+L)\operatorname{polylog}s)$ steps. The virtual old file is supplied by the short physical payload. Both ordinary bounded-run reductions and the two deterministic SAT calls therefore cost $O((u+1+L)\operatorname{polylog}s)=o(t)$. No sequence of individual SAT calls to recover the guessed edit bits is required.

Reject unless the first answer is yes and the second is no. Exactly one outer presentation guess survives, including on negative inputs. At that presentation use the canonical assignment certificate and the single failed-challenge query above. The slow bit certifier can read the selected edit table by the same sparse lookup. It need only be correct on promised inputs at their shortest presentations. Thus the number of time-bounded paths never exceeds the required bound, and all required paths fit on sufficiently large positives. For the zero/one case the resulting verifier preserves zero or one exactly. This combines the sparseness of length-test transcripts with canonical selection of a pad whose length test may itself be nondeterministic. [Sparse replay for ordinary polylogarithmic length tests](locally-short-sat-compilers-with-a-free-presentation.md)

This isolates a smaller compiler construction problem. The many-branch source machine with $2^{\Theta(s\log s)}-1$ accepting paths supplies no obstruction to the zero/one version. The positive descent still requires a short local representation for a *uniquely* accepting unrestricted RAM history. Neither the canonical certificate nor the hierarchy provides that representation.
