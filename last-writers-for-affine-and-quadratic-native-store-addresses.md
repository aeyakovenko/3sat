# Looking up the last write in an affine or quadratic store schedule

A store to an address described by affine functions of its chronological visit index has a polynomial-time predecessor lookup in the bit length of that index. For degree two, deciding whether a specified address was ever written is already NP-complete in the size of the succinct schedule. The hard schedule occurs at one fixed instruction in a globally correct deterministic SAT program on ordinary proper DIMACS files. Its final native load gives the SAT verdict. Counting solutions of bounded-degree Boolean equations also gives a deterministic power saving over enumerating all visits. These are different resource scales.

## The affine lookup

There are \(T=2^d\) visits indexed in binary, with optional eligibility specified by affine equations over \(\mathbb F_2\). A store at visit \(i\) has address \(Mi+v\). For a requested target \(z\) append the equations \(Mi=z+v\). The interval \([0,j)\) is a disjoint union of at most \(d\) high-bit prefix subcubes, with the full cube handled separately. For each subcube determine feasibility by Gaussian elimination. To maximize a feasible index, try to set each remaining bit to one in decreasing order, and keep it exactly when elimination still finds a solution. Take the largest answer across the subcubes. A union of \(p\) separately given affine schedules costs \(p\) such lookups. Arbitrary numeric intervals have the same conclusion by prefix decomposition.

For any fixed degree \(k\) and polynomially many address and eligibility equations of that degree, the same prefix tests reduce to counting solutions of a bounded-degree Boolean polynomial system. The deterministic algorithm of Lokshtanov, Paturi, Tamaki, Williams and Yu yields \(T^{1-\epsilon_k+o(1)}\) time for some fixed \(\epsilon_k>0\), including reconstruction of the last visit by prefix tests. A polynomial-time algorithm in the much shorter description for every quadratic schedule would imply \(P=NP\). [Lokshtanov et al., Theorem 1.2](https://people.csail.mit.edu/rrw/polyEqSoda2017Submit.pdf)

## A proper SAT formula whose verdict comes from the final load

Start with a proper three-literal formula on \(v\) variables and \(m\) clauses with names in \([1,v]\). For the assignment \(x\), let \(A_j,B_j,C_j\) be the three false-literal indicators in clause \(j\). Each is a bit or its complement. Introduce one auxiliary bit \(U_j\) per clause, set \(d=v+m\), and index all \(2^d\) strings \((x,U)\) by the binary-reflected Gray word \(g(i)=i\oplus(i\gg 1)\). Emit the following \(2m\)-bit address at site visit \(i\), with the indicated operations bitwise on the \(m\)-bit planes:
\[
 K(i)= \bigl(U\oplus(A\land B)\bigr)
       \;|\; \bigl((U\land C)\ll m\bigr).
\]
The Gray map is a linear bijection on the binary visit-index bits, so every coordinate of \(K(i)\) has degree at most two in those bits. Address zero requires \(U_j=A_jB_j\) and \(A_jB_jC_j=0\) for each clause. Hence every satisfying assignment has exactly one zero-address visit, and these are all the zero-address visits. Outputting the coordinate polynomials from the short formula costs polynomial time. This is the usual NP-completeness construction for Boolean quadratic equations, restricted here to the two displayed kinds of coordinates and a definite RAM instruction. The occurrence question belongs to NP by its \(d\)-bit visit certificate. The corresponding unrestricted function returning the last index is at least as hard as the occurrence decision. [Boolean quadratic systems and related algorithms](https://arxiv.org/abs/1112.6263) · [Earlier arbitrary-predicate store schedule](succinct-memory-defects.md)

To realize the schedule, append ordinary whitespace so the genuine physical file has \(N\ge 2^d\) bits, for example the least byte length meeting this bound and the length of the original text. This padding is part of the native-run example. The NP reduction outputs only the succinct schedule. The exponentially padded physical realization demonstrates the native run. In the journal's model \(w=12\lceil\log_2(N+2)\rceil\), so an index, address, marker \(i+1\), loop limit and the disjoint bank offsets fit in a constant number of native words (one suffices with these parameters). Initially zero memory gives the private marker bank its blank symbol.

Parse the formula, computing four mask dictionaries whose keys are one-hot words. For a variable key \(2^h\), the first three masks name all clauses in which that variable occurs in literal positions one, two, three respectively. The fourth dictionary toggles the single auxiliary coordinate when \(h\ge v\). All unused entries are zero. Initialize the planes for the zero assignment. From ordinal \(i-1\) to \(i>0\), the Gray word changes exactly by \(i\;\texttt{AND}\;(-i)\). Load the four mask words at this key and XOR them into their planes. No scan of occurrences or bit-position search is required. At every visit, including zero, construct the displayed key and store \(i+1\) to the marker bank. No other instruction writes that bank. At the end, load marker zero and accept if and only if its word is nonzero. Thus the load returns the last satisfying visit plus one, or zero when there is none.

The loop uses a constant number of actual instructions between consecutive visits after the first. With \(O(N)\) work to parse the padded file, this is an \(O(N)\) execution on the exhibited inputs. The test can be installed in a complete solver by falling back to any ordinary exact algorithm when the file or parameters fail its format, width and \(2^d\le N\) checks. Decimal token values can be range-checked incrementally, and the branch may require dense header names bounded by the physical width. Large fresh banks are sparsely addressed. The NP-hard description problem charges none of the physical writes already made by this run.

## Checking a proposed controller trace using small store schedules

A separate consequence concerns the journal's actual rejecting runs of a hypothesized \(O(N^K)\) deterministic SAT solver, for \(K=2,3\). Let \(s\) be the gate count of a circuit for the raw chronological controller on one such formula. Cover the true store events by a list of circuits. Circuit \(i\), of size \(a_i\), on a binary time reports a domain bit and the address it claims was written. Each true store belongs to some domain and every claim is accurate. Overlaps are allowed. Input and instruction-slot indices use \(O(\log N)\) bits under the fixed time cap. The controller also supplies written and loaded values, as in the original trace theorem. The charts describe only when and where a write occurs.

For every fixed \(\epsilon>0\), on all sufficiently large members of that solver's self-input family, any such circuits satisfy
\[
 s+\sum_i(1+a_i)^K > N^{1/K-\epsilon}.
\]
The bound follows by replacing the inner search of the existing signed verifier. Guess the controller circuit and the proposed charts under the indicated budget. An outer defect test can guess a time. It evaluates the controller and all charts at that time, detecting any omitted, spurious or incorrectly addressed store there. This adds their combined size, up to a polylogarithmic factor. To certify a wrong initial read or a wrong preceding writer, the same outer test guesses the consumer and optional writer in the controller, obtaining the actual proposed address as a concrete word. For each chart in turn ask ordinary SAT if it contains a matching write in the open intervening interval (or in the initial prefix). That query includes one copy of that chart and \(\operatorname{polylog} N\) address and time work. On an accurate cover there is no intervening store precisely when all these queries answer no. An inaccurate cover already has its own positive defect. The local CPU/input checks and halt test are unchanged.

The nondeterministic defect computation now has time and public data bounded by
\[
 \bigl(1+s+\sum_i(1+a_i)^K\bigr)(\log N)^{O_K(1)} .
\]
Materialize its one outer SAT query and solve it with the same assumed solver. Under the negation of the displayed lower bound this costs \(o(N/(\log N)^3)\), below the source clock \(\Theta(N/(\log N)^3)\) in the signed diagonal. Guessing all descriptions also fits. Using precisely the previous proof's initialization, width conventions and self-input, this would certify actual rejection in time on the formula that accepts exactly on such a certificate. In particular, for charts each of polylogarithmic size the raw-controller size plus the number of charts is \(N^{1/K-o(1)}\) in the lower-bound sense above. For affine charts one may run the linear-algebra test directly. The completeness of a description by even one arbitrary chart is trivially achieved by extracting stores from the full controller; that choice recovers the older \(1/K^2\) raw exponent. No small cover for each actual unrestricted solver has been established.
