# A circuit lower bound for shortening a supplied switch set by one

There is a sequence of encoded lengths $L$ on which bounded-fan-in Boolean circuits need $\Omega(L(\log L)^\sigma)$ gates to decide the following promise problem, for some $\sigma>0$. An explicitly edge-listed, connected, simple bipartite graph of maximum degree three has one designated leaf. A switch toggles its neighbors. The input gives a switch set producing a one at the designated leaf and zeros elsewhere. Is any smaller set possible? The supplied set has $O(\log L)$ members and is either optimal or one larger than optimal. The graph has diameter $O(\log L)$.

Each undirected edge is listed once as a pair of binary vertex names, in a prescribed order. The vertices are exactly the names appearing as endpoints. Names use $O(\log L)$ bits, with a polynomial-size namespace. There is no separate array indexed by every possible name and no header reporting the number of distinct vertex names. The edge count, name width, target name, and list of names of supplied switches are explicit. The varying bits are solely in edge endpoints. This encoding distinction is essential to the reduction.

The mathematical dependency is OpenAI's list-volume theorem. For $m=2^w$, a list of $m$ records of $2w$ bits has $2mw$ input bits. Over $\mathbb F_2$ its distinctness tensor requires trivalent volume greater than $2mw\,w^\sigma$ for all sufficiently large $w$. The theorem includes products of up to $m$ such tensors. ## From two injective lists to a known near-shortest path

Suppose $A$ and $B$ are two lists of $m$ keys each, with $O(w)$ bits per key. Each list is internally injective. Build two full binary trees, separately named, both of height $h=w+1$. In each tree the first $m$ leaves use that list's keys as names, in one common key namespace. All other leaves and all internal vertices have distinct private names. Thus one common key identifies exactly one leaf from each tree. Choose one private leaf from each tree and connect these two special leaves by a fixed bridge. Attach a new leaf $r$ to the left root and a new ground leaf $g$ to the right root. Denote this ordinary undirected graph by $J$. Its edge count is fixed for this $w$, even when names coincide.

If $A\cap B$ is empty, the trees communicate only by the bridge. The distance from $r$ to $g$ is $2h+3$. If they intersect, passing through one shared leaf gives a path of length $2h+2$. No path can be shorter. In any simple path, before the first transition between trees and after the last such transition there are at least $h$ tree edges on each respective end. A transition at a shared leaf has zero crossing cost and the bridge costs one. The terminal leaf edges contribute two. In particular, the path through the two designated private leaves is an input-independent feasible path, exactly optimal or one too long.

To convert to switches, take one row for every vertex of $J$ except $g$, and a column for every edge of $J$. Let $H$ be the binary incidence matrix: the ground edge's column has one entry, all others have two. The output is the **undirected incidence graph** on these row and column vertices, with the ground row omitted. Use public column names based on the construction's edge slots. The root $r$ remains a leaf, and removing the ground row only removed an endpoint leaf. The graph is simple and connected; row degrees are at most three and column degrees at most two. Any two vertices can also be joined via the fixed bridge within $O(h)$ incidence edges.

Writing the chosen switches in the two parts as $(y,z)$, their required light pattern is $Hz=e_r$, $H^{\mathsf T}y=0$. Each feasible $z$ selects edges in $J$ of odd degree at $r$ and $g$ and even degree elsewhere. These two odd vertices must lie in one component of the selected edges, so their distance lower-bounds $|z|$. A shortest path supplies equality, with $y=0$. The given switch list consists of the $2h+3$ column names on the known bridge path. It follows that it can be shortened iff the key lists intersect. This uses only the column-degree-two case of open-neighborhood decoding. [General graph reduction and shortest-path argument](one-false-read-and-a-subcubic-graph.md)

There are $\Theta(m)$ incidence edges with $\Theta(w)$ bits per endpoint field and $O(h)$ additional supplied names. Fixed-width prefixes distinguish the row types, namespaces and columns. For each of the $2m$ variable leaves, its only raw occurrence is in the one edge record connecting its row name to its tree-edge column. The raw leaf name bits are copied directly. All remaining bits are constants. Hence this map of injective-list inputs to sparse named incidence graphs has size $L=\Theta(mw)$ and requires only linear bit wiring. The graph's implicit vertex identifications follow from equality of names in the input format.

## Handling unrestricted input lists without checking an extra permutation

Let $x_0,\ldots,x_{m-1}$ be arbitrary $2w$-bit source records. Set $A_i=(0,i,x_i)$. Internally sum over $m$ proposed $2w$-bit records $y_j$, row indices $r_j\in[0,m)$, and $m$ selection bits. Multiply by the Boolean indicator $y_0<\cdots<y_{m-1}$. For each $j$, set $B_j=(0,r_j,y_j)$ if selected and $B_j=(1,j,0^{2w})$ otherwise. In every term with nonzero order indicator, both $A$ and $B$ are separately injective for **all** row indices and selections. Unsorted guesses have zero weight. A graph circuit may take arbitrary values on those off-promise inputs. [Earlier signed contraction through two unit-clause lists](matrix-list-unit-sat.md#one-sat-answer-tensor-with-two-ordered-lists-of-literal-positions)

Use the graph answer bit “supplied set is optimal,” complementing a strict-improvement circuit for a single instance. For fixed sorted $y$ and fixed $r$, put $J_0=\{j:x_{r_j}\ne y_j\}$. Optimality is equivalent to disjointness, which holds precisely when all selected indices belong to $J_0$. The parity of the resulting $2^{|J_0|}$ successful selections is one iff $J_0$ is empty. Now sum over $r,y$. For distinct source records there is one sorted list and one choice of indices reaching it. For a repeated source record no sorted list of $m$ distinct values can be reached. Thus the contraction computes exactly list distinctness.

Adjacent comparisons, selector multiplexers, all fanouts with explicit copy trees, and constant bit pins cost $O(mw)$ trivalent volume. In particular, the diagram never fetches $x_{r_j}$ directly; a variable leaf shared with $A_{r_j}$ implements the necessary equality. An $s$-gate graph circuit contributes $O(s+L)$ to this volume by representing its gates as truth-relation tensors. The cited lower bound gives $s=\Omega(L(\log L)^\sigma)$. For one circuit giving the product of the **optimality** bits on $t$ disjointly supplied graphs, the same argument with $t$ independent outer constructions gives $\Omega(tL(\log L)^\sigma)$ for $1\le t\le m$.

## Bipartiteness, tree recognition and matching recognition

The ordinary row graph $J$ before conversion to its incidence graph already has the required bit layout. When the lists are disjoint it is a tree. Identifying $k$ pairs of leaves preserves connectivity and all edges, and removes exactly $k$ vertices, so its cycle rank is $k$. Moreover every shared key exhibits a simple odd cycle. In each tree, follow the path between that key's leaf and the private bridge leaf; that path has even length since both leaves are at depth $h$. Joining the two paths with the single bridge edge produces the cycle. The respective internal vertices belong to different trees, and the paths have no other key leaves in their interiors. Thus on these connected graphs of maximum degree three, **tree recognition and bipartiteness each compute disjointness** and inherit the same circuit bound. The incidence graph used for the switching problem remains bipartite in both cases.

Matching recognition needs no trees. Make one edge from a different private endpoint to each of the $2m$ supplied key names. The resulting graph is a disjoint union of one-edge paths and two-edge paths. It is a matching precisely when no key occurs in both lists. Even on this promise, testing whether the supplied edge set is a matching needs $\Omega(L(\log L)^\sigma)$ gates in the sparse encoding. No maximum-matching computation occurs in this test. The varying information is whether names at different locations denote the same endpoint.

The [finite audit](sparse_named_graph_list_audit.py) checks 1,694 injective input pairs through $m=4$. It compares shortest paths with the marked baseline, evaluates the actual switch-induced light syndrome, and checks cycle rank, bipartiteness and the matching test. For all 16 unrestricted two-record raw lists it also evaluates all 1,536 graph terms surviving the strict-order filter and checks the complete parity contraction.

## Native and encoding limits

An ordinary logarithmic-word RAM can radix-sort the $O(m)$ endpoint names in $O(m)$ word steps, assign dense indices, build adjacency lists, and run breadth-first search in the row graph or test the two key lists directly on the template. The sparse-name reduction therefore gives no superlinear RAM running-time bound. In particular, the general NP-hardness of the subcubic unit-syndrome promise is not used for the circuit proof; the graphs here already admit a shortest-path algorithm.

Demanding a reciprocal adjacency array in dense identifier order changes the input. The relative positions of the two appearances of a shared key are now input-dependent. Converting the varying sparse leaf names to compact dense IDs or building a dense table by radix sorting is a fast RAM algorithm, but the above argument supplies no $O(mw)$-gate Boolean encoder for it. Even a format requiring a header with the exact number of distinct vertex names would expose the number of intersections on this construction. Padding with every possible key would exceed the stated length.

If the entire output graph had maximum degree two, connectedness and the designated leaf would force a path. Number its vertices from the target endpoint. The first equation fixes the second switch to one, and the internal equations propagate constant values on each parity of vertex indices. The last equation makes a feasible solution possible only on paths with an even number of vertices; that solution is unique, with all even-numbered switches on. Consequently every supplied feasible set on a connected degree-two instance is already optimal. Allowing degree three on the row side is necessary for the strict-improvement decision on these promises.
