# Two possible records for each instruction of a RAM execution

A list gives at most two possibilities for the complete record of each native instruction. At a writable-memory load its record includes the time of the last preceding write or an initialization marker. Then existence of a legal run of a specified verdict is a 2-SAT problem. Each implication edge can be tested by inspecting the lists at just the two times it names. The actual machine may choose addresses and overwrite words adaptively.

One extra option already allows a fixed deterministic RAM interpreter to evaluate any Boolean circuit. Its time-indexed lists have at most two records **before adding the writer time**, and at most three records with that time included. Each live gate cell is written at most twice.

## Pairwise constraints on actual events

Use a fixed program, an input, a horizon \(T\geq1\), and ordinary deterministic load/store semantics. Halt padding can be checked by the same local transition rule. The fixed registers, program counter and any finite-control fields are in the before and after controllers of a record. Include the instruction's effective address and actual written or returned word when applicable. The memory initializes to a known function, normally zero, and a separate immutable input is directly readable. There is at most one work event per instruction. A constant number of primitive events can be expanded in their native order when the corresponding candidates are supplied.

Associate a Boolean choice \(x_i\) to each time \(0\leq i<T\). Duplicate a singleton record. An empty list makes the test unsatisfiable. Add the following forbidden choices or pairs of choices.

* Disallow a record with a bad local instruction transition, a wrong immutable read, or an invalid time, PC or inactive-field convention. Require the proper initial controller, target final halt and agreement between consecutive controllers. For an initialized work load require its initialized word. For a named source require an earlier time.
* If a selected load at \(i\) names time \(j\), disallow every candidate at \(j\) which fails to store the load's address and value.
* Disallow selecting that load alongside any store to its address at \(j<k<i\). For an initialization marker this applies to every \(k<i\).

A unary prohibition is a unit clause and a binary prohibition is a two-literal clause. A satisfying assignment gives a complete consistent sequence. Chronological induction proves it is the actual run of the machine. CPU and input checks give each next transition, and the timestamp conditions force the genuine work-memory reply even when an intervening write would repeat the same payload. Conversely a covered genuine run satisfies the constraints for its own verdict.

There are at most \(O(T^2)\) potential clauses. They need not be enumerated. For a given pair of time/options, check the unary predicates if required, controller agreement if consecutive, and both possible reader/writer roles. The floor cost is a constant number of calls to the record supplier plus native word operations and a constant number of original input reads. In the implication graph, a prohibition of choices \(v,u\) gives arcs \(v\to\bar u\) and \(u\to\bar v\). Its edge test therefore also refers only to the two named times. Use a reserved locally invalid option in place of each missing list entry when lists with zero entries are allowed. [Aspvall, Plass and Tarjan, implication graphs for 2-SAT](https://doi.org/10.1016/0020-0190(79)90002-4)

## A list lower bound on each of two SAT executions

Assume ordinary SAT has a deterministic unrestricted-workspace \(O(n\log^a(n+2))\)-time algorithm for fixed \(a\). Put \(M=2^j\). The two priority-pinned formulas \(F_{j,0},F_{j,1}\) have length \(N=\Theta(M(j+1)^3)\). Their words are locally available from scale and pin. Any sound deterministic tester for one color of the pinned bit takes \(\Omega(M)\) steps on every sufficiently late scale where it signals. Fix a pair-correct solver \(D\), a polynomial cap \(M^p\), a fixed deterministic point evaluator, and \(0<\epsilon<1\). Then for a constant \(C\), on **each pin at every sufficiently large scale**, the following holds whenever \(D\)'s actual halting time is \(T\leq M^p\).

Let \(s\) bits of instance-dependent advice enable the evaluator in at most \(M^{1-\epsilon}\) native steps per time to give two augmented record candidates. The evaluator can probe the actual formula and the advice. Suppose the true record is absent at \(e\) times before the halt. Then
\[
                         s+e\log(M+2)\ \geq\ \frac{M}{(\log(M+2))^C}.
\]
Each time can have an arbitrary competing record alongside the true one. The bound charges only complete misses. A single selector bit per time would itself occupy \(T\) bits. [Pinned inputs and tester theorem](priority-pinned-sat.md) · [Single-field verification and its other resource tradeoffs](one-certified-index-for-all-writes-of-a-ram-run.md)

Guess the evaluator advice, \(T\) and a sorted list of true replacement records for exceptional times. Each replacement with its time has \(O_p(j)\) bits. Replace that time's menu by the specified singleton. A wrong guessed repair or evaluator cannot create a false certified verdict since every satisfying selection describes a legal computation of \(D\).

The two-row 2-CNF for an outcome is unsatisfiable precisely when some literal \(v\) and its complement reach one another in its \(2T\)-vertex implication graph. Give every vertex a self-loop for path padding. Fix an integer \(r>2p/\epsilon\) and let \(L=\lceil(2T)^{1/r}\rceil\). For either directed path it suffices to test existence of a walk of length exactly \(L^r\). Guess \(L-1\) ordered intermediate vertices. Universally choose one of the \(L\) gaps. Recurse on that gap for a walk of length \(L^{r-1}\). At the bottom guess its vertices and check its \(L\) edges directly. Both initial paths can share this verifier or be tested in succession. There are a fixed number of quantified blocks. On each branch all vertex lists cost \(O_r(L\log(T+2))\) bits, and the deterministic bottom work including correction lookups costs \(\widetilde O(L(1+M^{1-\epsilon}))\), using \(O(1)\) point evaluations per edge. This is \(O(M^{1-\epsilon/2}\operatorname{poly}(j))\). Ceilings and powers can be calculated with a fixed number of \(O_p(j)\)-bit limbs.

Complement this reachability test to check list satisfiability. The outermost existential choice of advice and repairs precedes that check. Each alternation is removed by a short ordinary SAT instance for the bounded next computation, including its whole public payload, and a call to the assumed solver. Negate the resulting deterministic answer when the block is universal. With \(r,p,a,\epsilon\) fixed, the total work is
\[
  O\!\left((1+s+e j+M^{1-\epsilon/2})(j+1)^{C_0}\right)
\]
up to the pinned simulation's \(o(M)\) uniform setup. This follows from the packed compiler's fixed-polylogarithmic cost at each of the constant number of layers. At all levels the long original formula is regenerated from the scale and pin. Each layer includes the full common advice or repair arrays to which its verifier has access. The point evaluator has a fixed cap even for arbitrary guessed advice. Equivalently choose a rational exponent strictly between \(1-\epsilon\) and \(1-\epsilon/2\) for the evaluator clock and increase \(r\) to retain a strict bottom saving. [Native compiler](packed-band-transfer.md) · [Public payloads](materialized-input-census.md)

To obtain a fixed sound tester, enforce a single budget \(s+ej\leq\lfloor M/(j+1)^H\rfloor\) on all guesses, with fixed \(H>C_0+2\). Test one fixed pin and one proposed outcome. A signal gives its corresponding priority color. The budget and the bottom saving make the runtime \(o(M)\), which precludes any signal at sufficiently late scales. The correct field choices would signal on the genuine outcome if its advice and misses violated the claimed bound. Take common constants for the four pin/outcome testers. The same proof allows wider menus at an announced set of exceptional times by paying for the truthful choices there, whenever their decoded rows can be accessed within the point clock.

## Two possible raw rows can implement a NAND gate

Use a topologically ordered circuit over two-input NAND gates. Reserve fresh memory cell \(g\) for gate \(g\) and one dummy cell \(d\) never read. Input bits have their own cells with known initialization or are copied once from an immutable bit array. Given the public operand numbers \(u,v\) and destination \(g\), perform the following straight-line native instructions with the sole nonpublic register \(r\), initialized to zero at every gate.

1. Load \(M[v]\) into \(r\), set \(r=1-r\), write \(r\) to \(M[g]\), then clear \(r\).
2. Load \(M[u]\) into \(r\), multiply it by the public integer \(d-g\), then add \(g\).
3. Store \(1\) to \(M[r]\), then clear \(r\).

When \(M[u]=0\), the second store goes to \(g\) and leaves it equal to one. When \(M[u]=1\), the second store goes to \(d\) and \(g\) retains \(1-M[v]\). Hence \(g\) computes the intended NAND. The explicit clearing before a new independent load ensures that even the combined before/after controllers have only two possibilities. At each instruction all candidate numerical register states, native addresses and words can be written down directly from the public gate indices and the fixed substep. Public loop and instruction-fetch registers are computed from this data. A final read returns the last circuit value. For fixed word-record input layouts one uniform RAM fetches the public gate records. A validity promise for the topological gate list suffices.

For a later read of gate cell \(g\), let \(\tau_1,\tau_2\) be the known mandatory and optional store times. The augmented pairs (writer time, returned word) are among
\[
                (\tau_1,0),\qquad(\tau_1,1),\qquad(\tau_2,1).
\]
They all occur for a gate on two freely assigned input bits. The three options have only two distinct raw load records. Input cells have known initialization or copy times. Each non-dummy gate cell receives at most two writes and no dummy-cell retrieval ever needs a timestamp. Thus even under these restrictions the verdict problem on explicit source circuits and lists includes ordinary Circuit Value, which is \(P\)-complete under logarithmic-space reductions. The program above is deterministic throughout. A cheap general decoding procedure beyond the two-augmented case would also apply to these computations. [Ladner, Circuit Value](https://doi.org/10.1145/990518.990519)

A local attempt to repair the two-choice reduction with auxiliary 2-CNF variables encounters an exact obstruction. Solutions to every 2-CNF are closed under coordinatewise majority of three solutions, and this closure survives existentially projecting any auxiliary coordinates. For an AND gate, input/output triples \(010,100,111\) are valid and their majority \(110\) is invalid. Complementing the last coordinate gives the NAND case. This excludes an exact 2-CNF representation of that local Boolean relation. It gives no general computational separation between polynomial time and logarithmic nondeterministic space. [Lean proof for arbitrarily many auxiliary variables](TwoRowsPerNativeTime.lean)

## A time obstruction using only ordinary instructions

Use the deterministic priority construction above to compute its bit \(b_j\) in \(O(M)\) ordinary RAM steps on a canonical input of nominal length \(M\). It gives a compact family of Boolean circuits of size \(O(M^2\operatorname{poly}(j))\) computing \(b_j\). One direct construction allocates a fixed grid of instruction rows. Each time's CPU and ALU outputs use ordinary polynomial-in-\(j\) Boolean templates. For a putative work load, scan all earlier instruction rows in increasing order, compare the current address with each earlier store address, and keep the most recent matching word, starting at zero. This is a deterministic circuit with \(O(M\operatorname{poly}(j))\) gates per simulated time. The initial input array is fixed. Compile bounded fan-in gates to NAND, padding to fixed template sizes. From \(j\) and a gate ordinal one can recover its operation and parents in \(\operatorname{poly}(j)\) time by grid coordinates and local word-arithmetic templates. Longer grid slots for unused comparisons can simply propagate the previous result. [Priority program and width](priority-pinned-sat.md)

Evaluate this circuit with the interpreter above. Its schedule has \(X=O(M^2\operatorname{poly}(j))\) steps (use quadratically many padded slots), with two raw or three augmented candidates per time computable in \(\operatorname{poly}(j)\) from \(j\). Their true final verdict is \(b_j\). A sound deterministic reporter using these implicit lists and the scale therefore requires \(\Omega(M)\) native time on every sufficiently late successful scale if its row-generation work is charged. If it instead receives unit-cost list queries, each query can be simulated with a fixed polynomial-in-\(j\) loss, giving \(\Omega(\sqrt X/\operatorname{polylog}X)\) steps including its number of queries in this convention. This bound uses the original priority computation and ordinary native instructions without a SAT-time assumption. It prices decoding a true execution from succinct candidate lists. It provides no superlinear execution-time bound for a SAT file.
