# Four explicit SAT inputs for a machine with a fixed scratch address

**Theorem.** Take the four 87-byte DIMACS files with private sign words at 16-bit word addresses 34 and 39. A deterministic controller has two mutable data registers, one LOAD that reads through the address register into the other register and always resumes at the same instruction, and one writable address of its choice. Suppose there is at least one STORE between successive LOADs on each halting run. For every choice of scratch address, some file receives a wrong verdict or never receives a verdict. The scratch may be address 34 or 39. There is no time bound. [The four files and their SAT labels](private-probe-contexts-in-read-only-sat.md#five-stored-instructions) · [Lean theorem `FiveSlotScratchSample.cannot_decide_packed_sample`](TwoPrivateProbeSites.lean)

The six public clauses leave precisely the two assignments with variables 2 and 3 false. Each remaining clause pins variable 1 to its chosen sign, so agreement of the two signs is exactly satisfiability. The four files share all other words.

Keep the most recent scratch payload while simulating the interval between a STORE and a LOAD. When the LOAD reads the scratch after a STORE, this known payload determines the reply even if the address contains a private sign in the original file. A LOAD observing an original private word sets the data register to the reply, fixes the address register to the sign location, and resumes at the common instruction. At every LOAD discard the saved scratch payload from the simulation. Before a subsequent LOAD can observe the physical scratch, a STORE must replace it with a value computed from the public control and the two registers. The intervening operations therefore remain reproducible. This also covers an initial LOAD with no preceding STORE and a final stretch that halts before any further STORE.

Contract the deterministic computation between original private reads. Each sign location has only one possible continuation for a given reply, regardless of the prior scratch value. The resulting graph has one query vertex per sign, two verdicts, and a divergence outcome. A deterministic graph with one query vertex per sign cannot decide equality. Lean proves the simulation on arbitrary finite halting executions and applies the existing graph theorem to the literal little-endian memories of the four files. The simulation allows arbitrary public register operations, arbitrary STORE payloads computed from those registers, and arbitrarily many program locations. The LOAD always returns to one fixed location.

This covers the distinct-register fixed-scratch branch of a five-slot cycle. The self-addressed LOAD with a separate mutable register, stores to varying addresses, and the global five-slot classification use other arguments.
