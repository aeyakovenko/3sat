# A logarithmic random seed for fast batch verification

The original weighted dominance transcript has a one-sided randomized decision procedure using $O(\log n)$ random bits, $O(L)$ worst-case word time, and false-negative probability $O(1/\log n)$ on each erroneous transcript. Truthful files always receive the correct UNSAT verdict. For any fixed $k$, independent repetition gives false-negative probability $O_k((\log n)^{-k})$ while keeping the asymptotic time and seed length. Here $L=\Theta(n\log n)$, and a false annotation is a witness for SAT. The algorithm computes a CountSketch of the *unknown* discrepancy vector without first computing that vector or receiving its entries as stream updates. The sketch and its second-moment argument are classical. [Charikar, Chen and Farach-Colton](https://www.cs.princeton.edu/courses/archive/spring04/cos598B/bib/CharikarCF.pdf)

Let $e_j=A_j-F_j$ be the difference between the supplied and true answer at query $j$. Give each query a bucket $h_j\in[g]$ with $g=\lceil\log_2(n+1)\rceil$ and a sign $s_j\in\{-1,0,+1\}$. Compute every signed bucket sum $U_a=\sum_{j:h_j=a}s_je_j$. Use two disjoint point sets per bucket, for the two nonzero signs. Partition all query records once and retain them in chronological order. Each of these $O(g)$ groups needs the transposed unweighted dominance index. For a group of $v$ points the geometry construction costs $O((v+1)\log n)$, sharing the same chunk lookup table across groups. Time-boundary searches can be done on its original ordered time list rather than rescanning the whole stream per group. For $u=O(n/\log^2 n)$ sparse insertions, all count queries on a group cost $O(u\log^2 n)$. The groups contain at most $n$ points in total. This gives $O(n\log n+gu\log^2 n)=O(L)$ worst-case steps. If some $U_a$ is nonzero then the file is SAT. A nonzero bucket can be bisected to find a specific erroneous claim and output its full model within the same asymptotic time. Here is a uniform short-seed implementation. Choose an odd prime $p$ between $n$ and $2n$ for sufficiently large $n$, by sieving within $O(n\log n)$ time. Evaluate an independent random affine polynomial and a random polynomial of degree at most three over $\mathbb F_p$ at the distinct query IDs. Reduce the first value modulo $g$ for its bucket. For the second assign sign zero to residue zero and opposite signs to the lower and upper halves of the nonzero residues. Under independent uniform coefficients the bucket family is pairwise independent before reduction modulo $g$, with collision probability at most $1/g+1/p$. The signs are four-wise independent, since evaluation on up to four distinct points is surjective. They have mean zero, second moment $\nu=1-1/p$, and fourth moment $\nu$.

Fix a nonzero discrepancy vector, set $V=\sum e_j^2$, and consider $Z=\sum_a U_a^2$. Its mean is $\nu V$. Expand the diagonal term $\sum_j s_j^2 e_j^2$ and the cross terms $2s_i s_j [h_i=h_j]e_i e_j$. Their covariances vanish by independence and centering, including between unequal pairs that share an index. Thus
$$
 \operatorname{Var}(Z)\le \nu(1-\nu)\sum_j e_j^4
      +4\nu^2(1/g+1/p)\sum_{i<j}e_i^2e_j^2.
$$
By Chebyshev's inequality the probability of $Z=0$ is at most $(1-\nu)/\nu+2/g+2/p$. To use a bounded number of fair bits, choose each of the six coefficients by reducing an independent $3\lceil\log_2(2n+1)\rceil$-bit string modulo $p$. Its distance from uniform is $O(n^{-2})$, and the six-variable joint distance is also $O(n^{-2})$. Polynomial evaluation at all IDs needs $O(L)$ time even if each modular multiplication uses a shift-and-add method. Intermediate exact totals and $Z$ occupy a constant number of words. This proves the claimed bound and, before the rounding in sampling, a relative-variance estimate $O(1/g)$ for the squared discrepancy.

For comparison, a truly independent sparse assignment of each ID to a random $r$-element subset of $g$ buckets gives miss probability at most $1/\binom gr$ on every nonzero vector, with unsigned sums and constant $r$. Condition on all other assignments and choose an ID with nonzero discrepancy. Only one bucket vector for that ID can make all totals zero. Opposite errors of equal magnitude at two IDs attain this collision probability. The total point memberships increase to $rn$, giving $O(rn\log n+gu\log^2 n)$ work. This argument uses independence of the chosen ID from *all* the other assignments; the short-seed proof above uses moments instead.

A fixed family of only a few such signatures can miss canceling integer errors. For example, for a single unsigned partition with more queries than buckets there are two queries in the same bucket. Opposite unit changes at them pass that partition whenever legal. The short random seed gives an efficient probabilistic test and a model on detection. It does not certify an unrestricted truthful file deterministically. [Finite moment and modulus checks](range_signature_arithmetic_audit.py)
