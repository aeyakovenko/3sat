# Finding an isolated timeout at one physical SAT file length

For each $k\in\{2,3\}$ there is a fixed, globally correct deterministic RAM SAT program $P_k$ and an integer $C_k$ with the following property. From any $n$-bit proper 3-CNF $x$, form an indexed family of proper DIMACS files $T(x,h,y)$, all of the same length $N=\Theta(n+1)$. Here $y$ ranges over assignments to the $v$ occurring variables of $x$ and $h$ specifies a filter. Model counts for the source refer to assignments on its occurring names. All the physical files are uniquely satisfiable. On these files the actual RAM running time obeys

$$t_{P_k}(T(x,h,y))> C_k(N+1)^k\quad\Longleftrightarrow\quad y\models x\ \text{and}\ h(y)=1.$$

The filters below include the unrestricted filter, Toeplitz hash prefixes and explicit deterministic filters for bounded numbers of solutions. Consequently even two changes of the timeout bit, in an arbitrarily chosen ordering of the files, can hide a unique solution to an arbitrary Unique-SAT instance. This is an exact-clock test for one particular globally correct program. The program already runs in $O(N^k)$ on all these files, including the deliberately delayed ones. The result therefore does not exclude any asymptotic SAT clock.

**Equivalence for unlabelled search.** On the unrestricted-filter subfamily, a procedure given the generating parameters that produces the marked file whenever there is exactly one is equivalent, within $O(n)$ encoding and decoding time, to finding a satisfying assignment for a proper 3-CNF promised to have a unique model. An output assignment constructs the file and a marked file yields the assignment. $P_k$'s entire code can be supplied to the finder. When applying a finder under a singleton promise we run it up to its known bound on every call. On other instances its outputs are treated as candidates and are checked directly against the original $x$. This avoids having to test the timeout by spending its full native deadline.

## Encoding the verdict-preserving files

Use an ordinary self-delimiting description of $x$, $y$, the filter and its parameters, padded to a fixed $L=O(n+1)$ bits depending only on source length. All data below, including the largest hash seed, fit in such a block. Represent $y$ in first-occurrence order of the normalized numerical variable names of $x$ and use zeroes for unused capacity. Take $b\ge1$ minimum with $b2^b\ge L$ and $K=2^b$. Use its $K$ consecutive $b$-bit chunks, with zero padding at the end. Choose $B$ to be the first decimal power greater than $2K+3$ and $V$ the smallest multiple of three at least $B+K-1$. Pin every variable from 1 to $V$ true by putting the seven proper clauses forbidding assignments other than `111` on each successive disjoint triple. In addition, for $i=0,\ldots,K-1$ print the positive clause on names $2i+1,2i+2,B+z_i$, where $z_i$ is chunk $i$. The library names $B,\ldots,B+K-1$ have the same decimal width. No data clause duplicates a pin clause since its anchor pair lies below a gap from the entire library. The data clauses are distinct by their anchors. Every declared name occurs. Fix the clause order, token spelling and separators once.

The physical bit length is independent of the payload values and is $\Theta(K\log(K+1))=\Theta(L)$. A word RAM prints the file in $O(N)$ time using decimal counters or division by the fixed constant ten. On input, the header's clause count minus $7V/3$ gives $K$. The parser checks the power of two, all size relations, spelling, pins, anchors and library ranges. Its cost is linear in the file length on the recognized branch. Customarily this can be implemented by saturating counters at the file length and abandoning the recognizer on missing input. The source assignment check takes $O(n)$ time with a decimal digit trie. The filtered verification takes at most $O(N^2)$ on all recognized inputs by the implementations below, with malformed metadata returning YES. Outside the syntactically verified carrier use an ordinary complete SAT decider with the input pristine. On a recognized file the answer is already YES and only its timing remains to be chosen.

Choose $C_k$ large enough for all ordinary work of this fixed recognizer, decoder and verifier on carrier files. When the displayed predicate is true, execute more than $C_k(N+1)^k$ instructions and return YES. Fixed nested loops with $k$ counters up to $N+1$ suffice, and the larger overall polynomial coefficient is uniform. A fixed, sufficiently large logarithmic word-width coefficient covers the trie and working storage. If a fast general SAT decider already exists at this exponent, it may be used outside the carrier after checking the layout in $O(N)$ time, giving a globally $O(N^k)$ version. [Guarded native timing and common multipliers](first-failure-lengths-for-exact-sat-clocks.md)

## A deterministic sharp filter count for bounded ambiguity

Fix an integer $s\ge2$. For every source with between one and $s$ satisfying assignments, **$O_s(v)$ deterministic filters suffice** to obtain a singleton. They can be prepared in $O_s((v+1)\operatorname{polylog}(v+2))$ time and each parameter block fits inside the same $N$-bit file length. For at most three solutions it suffices to use the unrestricted filter and the two choices of one specified coordinate value, at each coordinate. If the solution set has two or three elements, some nonconstant coordinate has a value taken exactly once.

For general fixed $s$, write $Q=2^d$ with $v\le Q<2v$ for $v\ge2$. Identify an assignment with the coefficient list of a polynomial of degree below $u=\lceil v/d\rceil$ over $\mathbb F_Q$, padding its last chunk. Take $\binom{s}{2}(u-1)+1$ distinct evaluation points. This many exist for sufficiently large $v$ at fixed $s$. Finitely many smaller sizes can be searched directly. Every pair of distinct assignments collides at no more than $u-1$ points. Some evaluation is therefore injective on the actual solution set.

On the $Q$ possible output symbols, use Porat and Rothschild's strongly selective family. Their Theorem 1 constructs $O_s(\log Q)$ subsets in $O_s(Q\log Q)$ operations. For every set of at most $s$ symbols and each of its elements, some subset intersects that set in just the selected element. For each outer evaluation point and each inner subset, take its inverse image as a filter. There are $O_s(v)$ filters in total. An inner subset can be supplied literally as a $Q$-bit mask, so no local construction or search through $2^v$ items is needed. Find an irreducible polynomial of degree $d$ by enumerating the $O(Q)$ monic possibilities, using repeated squaring and polynomial gcd with $X^{2^j}-X$ for $1\le j\le\lfloor d/2\rfloor$ in $\operatorname{poly}(d)$ bit operations per possibility. The standard irreducibility test also checks $X^{2^d}=X$ in the quotient. Supply the modulus and evaluation point as parameters. Horner evaluation takes $O(u d)=O(v+d)$ word operations using shift-and-add multiplication in characteristic two with immediate modular reduction. For global soundness on carrier files only the specified deterministic predicate needs to be evaluated. The listed legitimate parameters ensure isolation. [Porat and Rothschild, *Explicit Non-Adaptive Combinatorial Group Testing Schemes*, Theorem 1](https://arxiv.org/pdf/0712.3876)

Let $U(n)$ bound the time of a singleton-timeout finder, with constant-factor stretch of the input scale absorbed for fixed polynomial or polynomial-logarithmic clocks. Deterministic search on sources with one through $s$ solutions costs

$$O_s\bigl((v+1)(U(n)+n)+(v+1)\operatorname{polylog}(v+2)\bigr).$$

The same clock decides SAT under the promise of at most $s$ models. It gives a globally correct solver fast on the specified *positive* sources by falling back to exhaustive search after an entirely unsuccessful scan. Since distinct occurring decimal names require $v=O(1+n/\log(n+2))$, finder time $O(n\log(n+2))$ suffices for a quadratic promise decision clock and $O(n^2\log(n+2))$ for a cubic one. No such finder was obtained here.

The deterministic filter count is optimal even with adaptive choices if the only access to the unknown witness set is a device that returns a witness on singleton intersections and is permitted to abstain otherwise. Along the all-abstain transcript, $a$ filters give at most $2^a$ membership signatures on $2^v$ possible assignments. If $a<v$, two assignments have the same signature and their pair is never isolated. If a method may also guess a final witness directly, removing that one guessed point gives the same $\Omega(v)$ bound. All two-element witness sets on $v$ bits can be realized as projected models of actual proper 3-CNFs of $O(v\log(v+2))$ encoded bits. Pin common coordinates and tie differing coordinates, with their indicated signs, to one differing pivot. A fixed set of auxiliary variables pinned false by seven clauses on a triple can pad each unit or binary constraint to three distinct literals, preserving a unique extension. A procedure reading the CNF can exploit its syntax. The lower bound concerns its use as an unknown witness set.

## Random isolation at fixed length

For unrestricted witness counts, choose the diagonal bits of a random $(v+1)$-by-$v$ binary Toeplitz matrix $A$ and an independent random offset $b$. Filter level $j$ requires the first $j$ bits of $Ay+b$ to vanish. The same $O(v)$-bit seed works for all $0\le j\le v+1$. Direct evaluation inside $P_k$ takes $O(v^2)$ steps, so no parity constraints or computation tableau enlarge the carrier files. For $s_x>0$ true assignments take $j_0=\lceil\log_2 s_x\rceil+1$ in the analysis. Pairwise independence gives $\mathbb P[|W_{j_0}|=1]\ge3/16$. Indeed $\mu=s_x/2^{j_0}\in[1/4,1/2]$ and $\mathbb E[Z(Z-1)]\le\mu^2$ for $Z=|W_{j_0}|$. The indicator of a singleton dominates $Z-Z(Z-1)$. The standard isolation argument and common Toeplitz seed have been worked out earlier in this journal. [Valiant and Vazirani](https://ics.uci.edu/~vazirani/ValVaz.pdf) · [Nested witness isolation](nested-witness-isolation.md)

Trying all levels with the finder costs $O((v+1)(U(n)+n))$ per trial. Checking the resulting assignment against $x$ costs $O(n)$. An invalid answer on a nonpromise call cannot cause false acceptance. Alternatively, an algorithm that processes the shared seed and all levels in **total** worst-case $O(n^k)$ time, returning a candidate satisfying assignment whenever some level has exactly one timeout, would yield a one-sided randomized $O(n^k)$ SAT decision procedure after constant repetition. A singleton-only finder gives no reliable signal distinguishing an empty level from a level with two or more witnesses. Binary search on the last nonempty level in the earlier verified-header construction used general SAT decisions for precisely that distinction.

## A linear-query obstruction even with compact native predicates

The loss from choosing a blind isolation scale can persist with a compactly described witness set. In a universe with $2^v$ elements, identify elements with $\mathbb F_{2^v}$. Choose $t$ uniformly from $0,\ldots,v$, and take a fixed $t$-dimensional binary coordinate space $H_t$. Let $W=aH_t+b$ for a uniformly random nonzero field element $a$ and a uniformly random $b$. For a fixed filter $D$ and fixed $t$, $Z=|D\cap W|$ has mean $\mu=|D|2^{t-v}$ and variance at most $\mu$. Indeed the field affine maps act transitively on ordered pairs of distinct points, so the two-point membership probability is $2^t(2^t-1)/(2^v(2^v-1))$, at most the square of the one-point probability. For $\mu\le1$ use $\Pr[Z=1]\le\mu$, and for $\mu\ge2$ use Chebyshev to bound it by $4/\mu$. Use the bound one when $1<\mu<2$. Summing these bounds over the geometrically spaced means, including the empty-filter case separately, gives $\Pr[Z=1]=O(1/(v+1))$ over the mixed input distribution, uniformly in the filter.

Fix the coins of an adaptive randomized procedure and follow its all-abstain transcript until the first singleton. Its $a$ prospective filters there are fixed, so a union bound gives $O(a/(v+1))$ probability of ever receiving a witness from the device. A direct final membership guess can be counted as one extra singleton filter. Thus constant worst-input success takes $\Omega(v)$ probes in this black-box model. Dell, Kabanets, van Melkebeek and Watanabe proved the general black-box isolation lower bound with a geometric mixture of random subsets. The compact distribution here uses affine images of coordinate spaces. [Dell et al., *Is Valiant–Vazirani's Isolation Probability Improvable?*, Theorem 4.4](https://pages.cs.wisc.edu/~dieter/Papers/isolation-full.pdf)

These sets can be the actual timeout pattern of the same fixed program, by allowing a further mode that checks whether the high $v-t$ bits of $a' y+b'$ vanish in the field, and optionally intersects this predicate with one of the supplied filters. Taking the inverse field-affine map yields the distribution above. The parameters and a degree-$v$ irreducible modulus use $O(v)$ bits. Schoolbook carryless multiplication and polynomial remainder take $O(v^2)$ bit operations in linear scratch. This mode always has the same uniquely satisfiable carrier. The query lower bound applies only when access to $W$ is through the stipulated singleton device. A reader of the short field parameters knows $t$, and can in fact solve the displayed affine constraint directly. The example therefore isolates a limitation of adaptive black-box search without asserting any lower bound against an unrestricted SAT solver.
