# One certified predecessor index for all writes in a RAM execution

Suppose a deterministic word RAM runs for at most \(T\) steps. One \(\exists\forall\) verification takes \(\widetilde O(T^{(4+\sigma)/5})\) time if, on the input in question, **one** of the following is available with description and evaluation cost at most \(T^\sigma\), for a fixed \(0\leq\sigma<1\).

* At a time \(i\), give the native store indicator and, when present, its effective address and written word.
* At a time \(i\) which performs a writable-memory load, give its returned word. The evaluator may give arbitrary values at other times.

The short description is existentially guessed. The evaluator can access the original read-only input by its ordinary interface. The guarantee covers positive and negative outcomes of the actual run. Soundness holds without the description promise. Completeness holds on each run satisfying it. The program may dynamically select arbitrary read and write addresses, reuse its entire address space, and have long internal computations between successive accesses. It need not have locally accessible controllers. The verifier charges the first existential message in **bits** and the deterministic suffix in native steps. The original input, word model and time cap are shared by all branches. Use a fixed number of registers, word length \(\Theta(\log T)\), initialized writable memory, separate native LOAD and STORE, and at most one writable-memory access per step. Fixed-arity instructions can be split into constantly many elementary events when their intermediate state is available. The cap and powers used below are constructible, with a fixed rational choice of exponents or slightly weaker rational bounds.

## Certifying all queries from the positive image

Let \(g(j)\) give the store indicator and its address at time \(0\leq j<T\). Temporarily regard \(g\) as a supplied deterministic function, regardless of the run from which it is supposed to come. Index one set of \(M=T(1+\lceil\log_2 T\rceil)\) pairs \((\ell,j)\). Map the pair to a key comprising the level, the ordinal \(\lfloor j/2^\ell\rfloor\) of its dyadic time interval, and the store address tagged as a store. A nonstore instead supplies a separate reserved symbol. This single function \(f\) has a polynomial-size key universe, including every admissible native address. Its domain and key can be represented with constantly many logarithmic words. The last interval at each level may end after \(T\). No index outside the original time domain is a preimage.

For fixed \(0<\rho\leq3/4\), there is a common index of \(\widetilde O(T^{1-\rho/3})\) bits and a fixed uniform RAM query algorithm using \(\widetilde O(T^\rho)\) steps with unit-cost evaluation of \(f\). On every occupied key it returns some preimage. This is the classical Fiat–Naor worst-case inversion tradeoff. Aronov, Cardinal, Dallant and Iacono give the extended codomain in Corollary 1.1 and derive orthogonal range search, which also gives the underlying address/interval lookup directly. No new data-structure upper bound is needed. The deterministic index can be selected by unbounded preprocessing. Equivalently, fix successful amplified tables and any query coin tapes. Each run uses at most \(\widetilde O(T^\rho)\) additional coin bits, which fit the common budget for the stated range. Reuse one tape for all queries in each independent repetition. The pointwise failure bound for a fixed occupied key suffices for a union bound over at most \(M\) keys after \(O(\log M)\) independent repetitions. Verify each returned preimage against the actual key. [Fiat and Naor](https://doi.org/10.1137/S0097539795280512) · [Aronov et al., Theorem 1.1 and Corollary 1.1](https://par.nsf.gov/servlets/purl/10496291) · [Golovnev et al., Theorem 3.1](https://arxiv.org/abs/1907.08355)

The verifier guesses this index. It bounds every computation and every access to the index on arbitrary messages. A timeout, an invalid source position, or a proposed preimage with the wrong key gives a miss. There is now a short **public test for the meaning of every miss**. Universally choose a domain position \(p\), compute \(f(p)\), and demand that the checked index returns a preimage of that key. If these challenges all pass, every occupied key is found. The key of a legitimate store has a particular interval and address, so every reported hit is genuine. This works even if the returned time differs from the challenged time or many writes have identical addresses and values.

For a writable-memory load at time \(t\) and address \(a\), cover \([0,t)\) by at most \(1+\lceil\log_2 T\rceil\) dyadic intervals. Find its rightmost interval containing a write to \(a\), then descend into the right child whenever that child has a matching write. The leaf gives the last writer. If the entire cover is empty of such writes, use the initial value at \(a\). The case \(t=0\) needs no query. An arbitrary proposed return still requires verification of the actual stored **word**, which comes from the writer's chronological event.

## Replaying a block with one supplied field

Pad a halted run to \(T\) by idling. Guess its controller at the boundaries of blocks of \(B\) steps, including the initial and final controller. A controller has \(O(\log T)\) bits. Guess one bounded description for the proposed field and the common inversion index. Use a fixed total evaluator, for example a circuit with input views or an explicitly clocked deterministic interpreter. Include its description size and all per-query costs in \(s\). Invalid input-views, descriptors or clocks are rejected or given explicitly fixed default behavior. Check the true initial state and claimed final answer.

With a proposed store field, define \(f\) directly from the proposed stores. A universal branch replays a selected block, starting from the claimed boundary controller. It executes native ALU instructions, branches and input loads normally. For every writable-memory load, it uses the certified predecessor lookup on the proposed schedule and obtains the proposed writer's value from the field. At **every** step compare the store indicator, and if set the address and payload, against the actual instruction emitted by the simulated CPU. Compare the last controller to the next claimed boundary. The other universal branches test the image of \(f\) as above. If all branches pass, chronological induction gives exact CPU states and writable contents. In particular a proposed schedule cannot insert a convenient unexecuted store.

With a proposed return-word field, define a deterministic evaluator for a complete speculative event at time \(j\). Start at that time's claimed block controller, use ordinary input loads, and feed the proposed value to each writable-memory load. Record the address and value of the event reached at \(j\). This takes \(O(B(1+s))\) steps. Ignore all stores for purposes of supplying speculative replies. The evaluator is uniquely determined even on inconsistent descriptions and checkpoints. Build \(f\) from its speculative store events. Universal branches challenge an image point, a block endpoint, or a particular writable load, checking its proposed value against the value at its latest speculative writer or initialization. There is no nested call to the inversion index during the speculative replay that defines \(f\). If all challenges pass, every block joins to the next one and every speculative reply is the one supplied by real memory. Induction from initialization proves the target answer. On a true run with a valid field description, choose the genuine checkpoints and an honest inversion index.

Up to logarithmic factors the common message takes
\[
 s+T/B+T^{1-\rho/3}
\]
bits, and one branch takes \(O(B(1+s)T^\rho)\) steps. In the store case this pays for up to \(B\) indexed lookups. In the return case it pays for one lookup whose individual probes each invoke up to \(B\) speculative instructions. For \(s\leq T^\sigma\), choose \(B\) of order \(T^{(1-\sigma)/5}\) and \(\rho=3(1-\sigma)/5\). Each quantity is \(\widetilde O(T^{(4+\sigma)/5})\). With a complete external event array already available, there are no controller checkpoints to guess. Direct local CPU and load checks and \(\rho=3/4\) give the simpler \(\widetilde O(T^{3/4})\) external-trace bound.

## An address-only substitution fails on proper SAT inputs

Consider the journal's physically aligned proper 3-CNF parity chain, with a fixed tag and \(kL\) independently variable sign packets. Each original input-word probe reveals at most one of these bits. A correct solver can recognize this family, check its public structure, scan the bits and decide its exact parity verdict, falling back to any ordinary solver on other files. During this scan let it store the parity of each of the \(k\) consecutive length-\(L\) blocks in a predetermined fresh address. Use fixed-time arithmetic for the sign updates and fixed loop and store times, resetting the parity register after each block and accumulating the total verdict separately. The recognized good-file branch can check its public fields with word comparisons and update one discrepancy flag by bitwise operations, deferring any fallback branch until the checks and the scan finish. Thus on these files the addresses and times of these stores do not disclose their values. The block size can be obtained from a public length schedule, or fixed within a scale by choosing \(k\) and \(L\) as public functions of the number of packets. [Proper parity files and packed-word layout](unseen-ordinary-words-after-the-first-query-packet.md)

Suppose an input-relative field evaluator has \(S\) additional bits depending arbitrarily on the run, in addition to the common public schedule. To recover any one block's stored parity it adaptively probes at most \(q\) original input words. Then
\[
 S\ \geq\ k-\lfloor kq/L\rfloor
\]
whenever the right-hand side is positive. Fix an advice string and perform all \(k\) queries on a random bit filling. On each leaf in the resulting deterministic tree, no more than \(\lfloor kq/L\rfloor\) whole blocks have been read. The other block parities are independent fair bits even conditional on that leaf. Its conditional probability of getting all answers right is at most \(2^{-k+\lfloor kq/L\rfloor}\). Summing over leaves and taking a union over advice strings proves the bound. With no input-dependent advice the final parity for a single block needs all \(L\) probes. With \(L\geq 2q\), the \(k\) block queries need at least \(k/2\) advice bits. This identifies a missing resource in the proposed replacement by address information alone. In this example \(k\) bits of value-dependent advice suffice.

On an unrestricted solver run no short input-relative representation of either numerical field has been established. Materializing \(T\) arbitrary return words costs \(O(T\log T)\) bits, and using the program itself as the evaluator by replay from initialization costs up to \(T\) steps **per evaluation**. The index above resolves last writers once the indicated local values are available. The existing pinned-family theorem under a near-linear SAT algorithm also limits polynomial-time, small-space predictors given the genuine preceding stream. [Pinned writable-load replies](priority-pinned-load-replies.md) · [Chronological register circuits](chronological-solver-registers.md)

The finite audit executes a native-state example with input-dependent accesses. It tests both field choices against altered endpoints, store payloads, load returns and missing image keys, using an exact reference dictionary on its small domains. Lean establishes checked-index completeness and the chronological soundness induction. The published inversion tradeoff and its machine resource accounting are used at manuscript level. ## A numerical field on actual SAT runs, to polylogarithmic precision

Assume a reference SAT algorithm \(A\) takes \(O(n\log^a(n+2))\) time for fixed \(a\), with unrestricted workspace. Use the two actual pinned formulas \(F_{j,0},F_{j,1}\) of length \(N=\Theta(M(j+1)^3)\), where \(M=2^j\). Each of their packed input words is locally available from its numerical address and the scale/pin. Every deterministic tester sound for one color of the pinned bit takes \(\Omega(M)\) steps at every sufficiently late scale where it signals. Let \(D\) be any fixed deterministic program correct on these pairs. Fix a polynomial clock \(M^p\) and a deterministic point evaluator. Its immutable advice can depend arbitrarily on the formula, and it can inspect the genuine formula through the native read-only input view. It starts from its fixed initial scratch at each call. [Construction and exact tester lower bound](priority-pinned-sat.md)

There is a constant \(C\) such that on **each pin at every sufficiently large scale**, if \(D\) halts in \(T\leq M^p\) steps, the following holds. Suppose advice of \(s\) bits and at most \(d\) evaluation steps per time give either of the two numerical fields above, with at most \(e\) erroneous times. The return-word condition counts errors only at work loads. The store condition counts a spurious or omitted store as an error. Then
\[
       s + e\log(M+2) + \sqrt{T(d+1)}
                    \ \geq\ \frac{M}{(\log(M+2))^C}.
\]
Clocks are enforced by the verifier on arbitrary advice. Thus a near-linear-time \(D\) cannot have both \(N/(\log N)^{C'}\)-bit advice and \(N/(\log N)^{C'}\)-time point evaluation with only \(N/(\log N)^{C'}\) errors, for some sufficiently large fixed \(C'\). This concerns actual individual field values of a solver under the reference hypothesis. The previous predictor theorem treats polynomial per-event time, mutable small-space predictors, and polynomial solver clocks, with a factor \(2^{O(\sqrt{\log M\log\log M})}\) in its budget. [Earlier pinned predictor theorem](priority-pinned-load-replies.md)

Here ordinary SAT calls replace the inversion data structure, which avoids needing Fiat–Naor estimates at a vanishing power parameter. For a chosen time cap \(T\) and block length \(B\), guess the field advice, a sorted list of at most \(e\) replacement events, and the \(O(1+T/B)\) boundary controllers. Correct a query by binary search in the replacement list. A full replacement event or a return word, including its time, uses \(O_p(j)\) bits. The checker for a claimed answer rejects bad clocks and malformed lists, checks the true start state and a halting final state, and permits idle padding. Time and cap integers require \(O_p(j)\) bits. Fix the following common budget up to factors polynomial in \(j+1\):
\[
          K=1+s+ej+\lceil T/B\rceil+B(d+1).
\]
Each fixed-clock nondeterministic test taking \(\widetilde O(K)\) native steps on \(\widetilde O(K)\) supplied public bits has a deterministic \(\widetilde O(K)\)-time decision under \(A\). Use the packed RAM-to-SAT compiler with clock at least the public-payload length, materialize the resulting ordinary formula and call \(A\). Tildes here allow fixed powers of \(j+1\), independent of \(s,e,d,T,B\) in the clock range. Public data include the entire guessed advice, correction list and checkpoint list whenever a subcall can index them. Scale and pin suffice in place of the long original formula. The fixed-program, sparse-address and word-width simulations are the ones used by the pinned tester. Small shared arithmetic-table setup, if needed, costs \(M^{1/4}\operatorname{poly}(j)=o(M)\) even through a fixed number of near-linear eliminations. Alternatively implement fixed-limb arithmetic by elementary polynomial-in-\(j\) operations. [Packed reduction and width accounting](packed-band-transfer.md) · [Materializing arbitrary public data](materialized-input-census.md)

For proposed **work-load returns**, replay any speculative event in \(\widetilde O(B(d+1))\) time from its preceding checkpoint. A defect can be a failed join or a consumer with the wrong source value. Guess the consumer and the claimed preceding writer, or the initialization marker. Check the consumer and source events directly. One inner ordinary SAT call asks if there is an intervening matching store in the proposed replay. An actual last writer with wrong value, or an initial wrong read with no earlier write, is exactly a positive defect. This argument quantifies over the speculative stream determined by the common data and does not presuppose that its checks passed.

For a proposed **store field**, do not pay the advice length once for each load in the block. Guess a bad block, all its work-load replies and their proposed source times or initialization markers, altogether \(\widetilde O(B)\) bits. Replay from its boundary controller with these guesses. For each load require its named source to be an earlier proposed store with the same address and claimed payload, or require the initialized value when the marker is used. Checking the \(O(B)\) required point values costs \(\widetilde O(B(d+1))\). Record the load addresses/times and named sources. One inner ordinary SAT call asks whether **any** listed source is invalidated by a matching proposed store strictly between its time and its consumer, or anywhere in the consumer's prefix for an initialization marker. A bad block accepts only when that call finds none and replay produced a wrong next boundary or a disagreement with the proposed store status/address/value. A legal replay with respect to the whole proposed store schedule exists uniquely from each fixed boundary by determinism. Consequently a bad block is found exactly when this required consistency fails. The inner search receives the entire advice once.

For both choices eliminate the existential defect test by a second SAT call. The outcome tester now nondeterministically guesses all common data and requires absence of defects. A third SAT call decides whether it can succeed. On every scale a positive outcome certifies the genuine run, so signaling on a fixed requested pin and outcome is sound for the associated color. The three layers are fixed independently of all numeric parameters. No simultaneous running-time claim for all input lengths of \(D\) is needed.

For uniform clocks, impose a single budget \(\lfloor M/(j+1)^H\rfloor\) on the components of \(K\) and all description lengths before running the nested testers. The integers \(T,B,d,e,s\) are guessed subject to these tests, with \(1\leq B\leq T\leq M^p\) and fixed polynomial caps on the remaining integers. Select \(H\) larger than the fixed total log loss of the constant number of compilations. The resulting four deterministic pin/outcome testers take \(o(M)\) whenever they signal, so none signals at a sufficiently late scale. On a genuine fast run with \(1+d\leq T\), take \(B=\max(1,\lceil\sqrt{T/(1+d)}\rceil)\). Then \(\lceil T/B\rceil+B(1+d)=O(1+\sqrt{T(1+d)})\). If \(1+d>T\), the square root already exceeds \(T\), which is \(\Omega_D(M)\) by the pinned-family theorem. The genuine fields, exceptions and checkpoint values otherwise furnish a successful guess whenever the displayed lower bound fails for \(C\) sufficiently large. Taking common constants for both fields and the two pins yields the assertion.
