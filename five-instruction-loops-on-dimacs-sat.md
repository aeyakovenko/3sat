# Five stored instructions cannot decide DIMACS SAT in time O(N^1.1) in a separate-operation RAM

Fix a little-endian word RAM with $w=16\lceil\log_2(N+2)/16\rceil$ and $N$ encoded input bits. Input occupies consecutive writable words starting at zero, with zero padding in the last word and zero elsewhere. Registers initially contain zero except for an optional length register containing $N$. Providing $w$ as another public word is harmless. The fixed numerical instructions are modular add, subtract, multiply, bitwise Boolean operations, shifts, rotations, moves and word comparisons. A binary branch tests a comparison and writes no data. LOAD and STORE take a register or an immediate as address; there is no implicit increment, fused operation, indirect jump or memory-valued verdict. A program literal denotes a fixed integer reduced modulo $2^w$. The machine may access all $2^w$ writable words. Use ordinary comment-free ASCII DIMACS 3-CNF, allowing whitespace between tokens. The claim concerns well-formed inputs, so a solver supporting comments as well is included.

**Claim.** For every program with at most five static slots, every $C>0$ and every length threshold $B$, there is a valid formula of $N\ge B$ bits on which the program gives a wrong verdict or fails to finish within $CN^{11/10}$ steps. Thus a correct five-slot solver would have an unbounded worst-case time-to-$N^{11/10}$ ratio. In fact a number of the instruction allocations below fail irrespective of their runtime. This is a statement about a particular static instruction budget and a particular encoding. A fixed compiler can change that budget. Using injective, sparse decimal variable names in the hard virtual files improves the excluded clock to $O(N^{6/5})$ and covers other fixed logarithmic-width coefficients. [Six-fifths refinement](sparse-decimal-names-in-dimacs.md)

## Two properties of the encoding

1. A satisfiable base formula has $k=\Theta(N/w)$ consecutive full tail words such that, for each, a same-length sign change confined to that word gives an unsatisfiable formula. Every base word is even, and the circular norm of each full tail word is at least $10\,2^w/256$. The alphabet $H$ of original **word** values (including zero) has bounded size on these bases, independent of $N$.
2. On the canonical DIMACS outputs used to transfer a general SAT instance, $h=|H|=O(N^{0.511})$. Under a hypothetical $O(N^{11/10})$ clock, a program with at most $O(N^{0.711})$ distinct modified addresses on these outputs gives a deterministic simulation of nondeterministic linear time on length $n$ in $O(n^{1.101})$ time and $O(n^{0.712})$ bits of workspace. The decimal formula has length $N\le n\,\log^{O(1)}n$. Fortnow, Lipton, van Melkebeek and Viglas, Corollary 5.8, exclude space $o(n^{0.728})$ at this time exponent. The same conclusion holds for a program with a uniform $O(1)$ bound on its modified addresses. [Original time-space theorem](https://lance.fortnow.com/papers/files/tst.pdf) · [Virtual access to the decimal formula and explicit space accounting](public-scan-crossed-stores-on-ordinary-sat.md)

For the first property use $10^j$ clauses in total. Four sign choices on two shared dummy variables force each of variables 2, 4 and 6 true, using twelve proper 3-clauses. Use 8 and 20 for dummies. Fill the rest with $(2\lor4\lor6)$. Replacing one such clause by $(\neg2\lor\neg4\lor\neg6)$ is the desired sign edit. In each clause reserve a space or a minus at an **odd** byte offset for every sign, inserting extra spaces as needed and making every line an even byte length. Variable names, spaces, newline and the terminator have even ASCII codes. The header is `p cnf 20 ` followed by 1 and $j$ zeros and an optional space before newline to give even length. For all sufficiently large word widths the first byte of the header is even and its other odd bytes occur strictly inside the first word; every subsequent word boundary within the header begins at a zero digit, whitespace or newline. As $w/8$ is even, the low byte of every body word is even. All bytes in the repeated tail are between 10 and 56. The high byte gives the claimed circular norm. The repeated clause has fixed byte period. The header has $O(w)$ bytes and the forcing prefix has constant size; together with the tail period and final padding this gives bounded $|H|$. Every full interior tail word contains a full record for sufficiently large $j$. If its original contents were not loaded before an overwrite or a verdict, the alternative formula would receive the same answer. [Executable layout and sign-edit audit](dimacs_five_slot_layout.py)

For the second property the hard outputs need only decimal digits, sign, space, newline and four header letters. These give at most $17^{w/8}$ possible complete words. The virtual input construction emits fixed-width fields with left whitespace before decimal tokens. A simulated memory access can use a trie of the cells actually overwritten and a read-only generator for the original word. Generating the virtual formula word, updating the trie and implementing a word instruction incur only polylogarithmic time overhead. For the source model one can first apply Theorem 3.3 of the cited paper to obtain a nondeterministic multitape computation in quasilinear time, then verify its bounded run using the locally indexed clause construction. This invokes a lower bound about **arbitrary SAT** on hard outputs, so it can be used even if the periodic edit family alone is easy for the simulated program.

## The control graph and accessible data

On the periodic base the machine must read unboundedly many different original cells. A constant-size acyclic program cannot do that. A useful loop that can give both verdicts needs two binary branch sites. A program with no value-making operation can access only the bounded initial alphabet and its fixed operands. With no indirect STORE it changes only boundedly many cells and property 2 rules out the proposed clock. Thus at size five there are exactly two branch sites, one LOAD, one indirect STORE and one value-making ALU. Two branches and two terminal verdicts give at most seven edges on the seven reachable vertices; a cycle must be unique in the underlying multigraph. On a continuing run all data sites on it execute once per turn in a fixed cyclic order. If the LOAD or ALU is off the cycle the edit family defeats it. If the STORE is off the cycle use property 2. Off-cycle control may choose to halt, but cannot take a different route and rejoin the cycle. [Control graph and four-slot proof](bounded-ram-programs-and-separate-sat-witnesses.md)

Values outside the destinations of the LOAD and ALU are fixed on an input. A LOAD at such a fixed address fails the required-read test; a STORE at such an address gives a constant-space simulation. Hence all remaining addresses come from the mutable registers. A fixed STORE payload below may also be one of the length metadata or zero. A finite initial partial cycle has at most one STORE before the first LOAD. In raw-alphabet arguments include its known initial address and payload and the initial register values in $H$, at $O(1)$ cost. An exceptional original overwritten by this prologue is already unavailable to any required-read test.

## An address bound for repeated resets

Consider the required original reads on the periodic base. Suppose each such read resets the continuing computation into one of $h_0=O(|H|+1)$ possible states, and between resets the sequence of **load addresses** follows a deterministic path from the last reset state. It suffices that the continuation with *no further reset* be deterministic; the decision whether a reset actually occurs may depend on writable memory. An episode starts just after the previous reset and includes the opportunity at its ending reset. Charge the first required original read at each distinct address. Auxiliary resets also end episodes. Include the initial phase as one extra start. In the first $d$ load opportunities of these continuations at most $h_0d$ distinct endpoints are possible, counting all starting states. Choose $d=\lfloor k/(2h_0)\rfloor$. At least $k-h_0d$ of the distinct required endpoints therefore have an episode of more than $d$ load opportunities. Their ending resets are different, so these episodes are disjoint. This requires $\Omega(k^2/h_0)$ time when $k/h_0$ grows. On the periodic base $h_0=O_P(1)$, so the resulting $\Omega_P(N^2/\log^2 N)$ exceeds the proposed clock. The count also holds when the reset determines just the next load address and a fixed transition function specifies future addresses until the next reset. [Lean counting certificate](ResetEpisodePacking.lean)

If LOAD and ALU write the same register $r$, a nonconstant address is $r$ and a STORE at $r$ writes $r$ or a fixed word. A LOAD thus returns an initial-alphabet word, the fixed payload, or its own address. Treat all original reads and all fixed-payload returns as resets. Between them the LOAD acts as the identity and the register and control are deterministic. The episode bound applies.

For distinct destinations write $x$ for the loaded value and $y$ for the ALU result. If LOAD is self-addressed through $x$, a STORE at $x$ between successive loads destroys the next original before reading it. If STORE is at $y$ with payload $x$ or a fixed value, all successive $x$ lie in $H$ plus the fixed value. If it writes $y$, a modified cell contains its own address, so a self-addressed LOAD preserves $x$ there. Again all $x$ lie in $H$. Each alternative misses some required original. Hence suppose from now on that LOAD is $x\gets M[y]$.

## Which operation can generate the addresses?

On the periodic base a single Boolean ALU site produces words constant on the bit-position classes of the bounded initial word palette, which includes the program literals. This bounds the number of distinct words uniformly. A single direction of shift or rotation produces at most $O(w)$ shifts of each initial word; a comparison adds at most two data values. Multiplication by a fixed-on-input word has orbits of length $O(w)$ if its multiplier is even. If odd, it preserves the 2-adic valuation of every nonzero word over the entire execution, giving only boundedly many distinct valuations; consecutive required addresses have unboundedly many. Under a squaring instruction each initial word reaches zero or one after $O(w)$ squarings. These arguments include shifts with data-dependent counts, initial metadata, immediate operands and register aliasing. [Word-algebra details](bounded-ram-programs-and-separate-sat-witnesses.md)

**The ALU uses both mutable registers.** For addition, subtraction in either order, and multiplication, even operands give an even result. When STORE copies a register or an even fixed payload, all registers and memory stay even on the periodic base. Required odd addresses are unreachable. If STORE writes a fixed odd integer $c$ and is addressed through $x$, every load yields a word in $H\cup\{c\}$, so only $O(h+1)$ addresses are ever changed on general hard inputs. Apply property 2. If instead STORE and LOAD use $y$, order them between successive ALU updates. A STORE before the LOAD at that address prevents reading its original. In the other order, LOAD sees the original word on first visit and $c$ on revisits. Multiplication still keeps $y$ even, since it is an operand in every update.

For addition or subtraction, write $Q=2^w$ and $\|u\|=\min(u\bmod Q,(-u)\bmod Q)$. At a first required read at address $a$ the loaded word $R$ satisfies $\|R\|\ge10Q/256$ and $a\le\lceil N/w\rceil=o(Q)$. The next address is $a+R$, $a-R$ or $R-a$, of norm at least $10Q/256-a$. Until the walk next returns to the physical input range, every read sees zero or the fixed marker $c$. Each outside update changes the circular norm by at most $|c|$, since a reflection preserves this norm and a translation changes it by at most its circular length. Hence before the next input read it needs $\Omega(Q/(1+|c|))$ updates. The intervals starting at the first visits to the $k$ required cells, except possibly the last one, are disjoint. On the base this gives $\Omega(kQ/(1+|c|))=\Omega_P(N^2/\log N)$ time. This argument uses that an odd literal is a fixed integer; both optional length metadata are even.

**The ALU updates $y=f(x)$ independently of its old value.** The following cases work for any word function $f$ fixed at this input length. If STORE uses $y$, group operations by a constant value of $y$. A STORE before LOAD destroys the original. With LOAD before STORE, a payload $x$ writes back exactly what was read, giving at most a prologue exception and a small-space simulation. A fixed payload restricts $x$ to a bounded palette on the base. A payload $y$ marks each visited cell with its address. The next load address is then $f(y)$ on a marked cell and belongs to $f(H)$ on an original read. Apply the reset bound.

If STORE uses $x$ and writes $x$ or a fixed word, all loaded values stay in $H$ plus the fixed word. Indeed even a self-mark can only be made at a previously available $x$. This bounds the load addresses $f(x)$ on the base. For STORE at $x$ with payload $y$, start a turn by loading $b=M[a]$ at $y=a$. A STORE before the ALU performs $M[b]\gets a$. Outside $H$ memory always equals the original $M_0$, and $M[h']=a'\notin H$ at $h'\in H$ implies $M_0[a']=h'$. To verify this, a read outside $H$ returns its original member of $H$ and establishes the required reverse link. A read inside $H$ followed by a write outside restores exactly the original value there. If both addresses are inside $H$, the implication involving an outside address is unaffected or removed. This invariant gives a dictionary of only $O(h+1)$ **possibly different** cells, even if restored cells are touched frequently. A simulation need store no entry when a write equals the virtual original. If STORE follows the ALU, the write is $M[b]\gets f(b)$. A load at $a$ now yields its original value or $f(a)$. The next address consequently resets to $f(H)$ or advances by the fixed map $a\mapsto f(f(a))$. The episode bound applies.

**The ALU updates $y=f(y)$ without using $x$.** Its load addresses are public at fixed length until the first exit. After the word-algebra eliminations above, a constant, copy, $d-y$, $y-y$ or doubled $y$ gives either a bounded address set or a doubling orbit of length $O(w)$. The remaining case is $y\gets y+d$ (including subtraction by a fixed operand). When $d$ is always even on the base, parity of $y$ never changes and some compulsory address is missed. Otherwise the increment is a fixed nonzero program integer. Its public orbit has period $Q/\gcd(Q,d)\ge Q/|d|$. A run of $O(N^{11/10})$ steps makes $p=O_P(N^{1/10})$ passes.

For STORE at $y$, STORE before LOAD destroys originals. In the opposite order a payload $x$ is a writeback, and a payload $y$ or a fixed word is independent of the original value. Simulate those loads directly: within the first public period read the original word; afterward return its mark. An initial isolated write or an initial marked address is handled explicitly. Keep the iteration counter and registers in $O(w)$ bits under the proposed polynomial clock. For STORE at $x$ with payload $x$ or a fixed word, only $O(h+1)$ values of $x$ ever occur, by the palette induction above. Finally, STORE at $x$ with payload $y$ writes either the current or the next public address. Following two successive last-writer links takes a full pass up to an endpoint, since the older and newer scan addresses are equal or adjacent in the cyclic order. This bounds the total number of distinct STORE destinations by $1+(p+1)^2(h+1)=O_P(N^{0.711})$, including transient writes. The sparse simulation and property 2 apply. [Last-writer proof, exponent calculation and audit](ancestry-of-crossed-stores.md)

All periodic arguments use arbitrarily large lengths. For the simulation cases, correctness and the clock on all sufficiently large lengths suffice: a simulator may answer the finitely many smaller cases with fixed code. This proves the stated quantifier over programs, including candidates that already err elsewhere. When the complete code has a bit budget as well, there are finitely many candidates, so the union of one witness per candidate is a finite suite. The proof does not give the smallest such length.

The cases exhaust the operand choices of the single data-producing instruction. They establish the claimed step to five stored instructions for this DIMACS model. At six slots a separate counter and a second arithmetic site can coexist with the writer and the two branches. The reset, parity and public-scan invariants above no longer cover all those schedules. No unrestricted time lower bound follows, and priority for this code-size result has not been established.
