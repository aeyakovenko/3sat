# Adaptive five-slot scans whose marked addresses have short descriptions

Two adaptive scan schedules with one LOAD, one numerical operation and one STORE cannot decide ordinary DIMACS SAT at any speed. In each schedule the next load address is $f(x)$, where $x$ is the value just read and $f$ is fixed after a bounded prologue. It may depend on the word width, immutable registers and program operands. The read address need not follow an input-independent order. On every continuing turn the scan acts as one of the following two rows.

| Schedule | Load at $p$ | Compulsory write | Next load address |
| --- | --- | --- | --- |
| Mark the address read | $x\gets M[p]$ | $M[p]\gets p$ after the read | $f(x)$ |
| Mark the value read | $x\gets M[p]$ | $M[x]\gets f(x)$ | $f(x)$ |

The address and payload in the table determine the claimed scope, including their timing. The branches can compare the actual words and can exit early. Take an iteration boundary immediately after the regular data operations and include the control phase in the recorded state. A bounded acyclic prologue and bounded acyclic exits are allowed as in the [five-slot control graph](five-instruction-loops-on-dimacs-sat.md). There is no bound on laps or on elapsed time. In the proof of the two rows, $f$ can even be an arbitrary fixed-on-configuration function rather than one ALU opcode. The theorem uses its public description from the fixed program and the bounded initial state.

## Sets of addresses during the actual execution

Let $Q=2^w$. Call the memory after the prologue $M_0$, its image $H$ and its image size $h$. Include the initial load address $p_0$ among the possible starting addresses. For the regular iterations completed at a boundary, let $D$ be the addresses written and $W$ be the addresses read by the LOAD. Count a write even when the value is unchanged. Both sets grow monotonically. By an orbit prefix for a unary map $g$ from a seed $s$ we mean the set of its first $\ell$ distinct successive points, ending at or before the first repetition. It takes at most $w+1$ bits to specify its length.

In the first row $D=W$. After the read at an already marked address $p$, the next address is $f(p)$. At a first read it is $f(M_0[p])\in f(H)$. Cut the sequence of read addresses into episodes at the latter transitions. Each episode is an initial part of an $f$-orbit from one of the at most $h+1$ seeds in $f(H)\cup\{p_0\}$. Taking the longest prefix per seed represents the exact union $W$. The contents throughout $W$ are public given its addresses.

In the second row, a marked address $p$ always contains $f(p)$. A read at an unmarked address writes at $M_0[p]\in H$. A read at a marked address can add $f(p)$ to $D$. Therefore $D$ is a union of $f$-orbit prefixes from $H$. Inductively, adding a seed starts a prefix and adding the successor of a point already in the union either leaves the union unchanged or extends one prefix by one point.

For the read addresses in this row put $g=f\circ f$. A marked read at $p$ continues to $g(p)$; an unmarked read continues to a seed in $f(H)$. Consequently $W$ is a union of $g$-orbit prefixes from $f(H)\cup\{p_0\}$, using the same episode partition as in the first row. There can be previously read addresses whose memory has not been overwritten. In fact
$$
 |W\setminus D|\le h+1.
$$
For each $p\in W\setminus D$, consider an episode that visited $p$, from seed $s$. At all its visits up to the boundary $p$ was unmarked, so it ended each of those episodes. No episode from $s$ could pass the first occurrence of $p$ on its $g$-orbit by the boundary. Thus $p$ is the final point of the longest prefix reached from $s$. Each seed has at most one such final point. This remains true if the current episode is incomplete or an orbit enters a cycle. Keep the actual contents of all cells in $W\setminus D$ in the state description.

In both rows the resulting description takes $O_P((h+1)w)$ bits. It records $H$, the relevant prefix lengths, the constant number of registers and the control phase. The second row adds the addresses and contents just bounded. Also retain the $O_P(1)$ addresses probed or written during the prologue and their original and post-prologue values, so that those exceptions can be compared across executions. Register values determining $f$ and the initial cursor are included. Decoding these finite sets need not be fast. An elapsed timestamp is absent from the description.

## Gluing a prefix of one SAT run to a suffix of another

Use the [bounded-alphabet parity-pin family and its balanced-cut lemma](orbit-orders-and-parity-pinned-sat.md). It has an even number $k=\Theta(N/\log^2 N)$ of vertex signs, one bit $X_u$ per vertex of a fixed bounded-degree graph, and edge signs $Y_{uv}$. All settings are valid proper 3-CNFs and SAT is equivalent to $Y_{uv}=X_u\oplus X_v$ for every edge. Each private sign occupies a different physical word. Across all sign settings the original word palette has bounded size; a bounded prologue adds only $O_P(1)$ further values. In each exactly balanced cut of the graph vertices there is a crossing matching of size $\gamma k$ for a fixed $\gamma>0$. Choose a yes input by taking independent uniform $X$ and the corresponding $Y$. Every individual sign word is sensitive on each yes file. In particular a correct accepting run must observe every such original word before a write erases it.

Let $P_0$ be the addresses read or written in the prologue. On every accepting run take the first complete-iteration boundary for which $P_0\cup W$ contains $k/2$ vertex sign words. For sufficiently large $k$ the starting set contains fewer. The fixed-length exit path could account for only $O_P(1)$ later original reads, and a single complete iteration adds at most one address to $W$. Thus the boundary exists on each such run, including one whose last regular turn exits partway through. Use the preceding short description as its label. The label determines the complete set $T=P_0\cup W$ and hence a balanced cut of the vertex signs, possibly a different cut for each label.

Suppose that two yes executions have the same label. Take all original words at addresses in $T$ from the first input and all other original words from the second. The mixed string is another valid member of the sign family. Its prefix follows the first execution, since that prefix can only observe original values from $T$. At the boundary its full configuration also agrees with the second execution. At addresses in $D$ the compulsory write fixes the value from the address itself. In $W\setminus D$ the remaining contents agree by the recorded values. Post-prologue values on the exceptional $P_0$ are also recorded. Outside $T$, words have the second input's original contents except for the same public-form updates in $D$. Registers and control agree as well. The mixed input thus follows the second run's accepting suffix, including all its future memory accesses and branch tests. This argument uses no synchronization of the two prefix lengths.

For one label consider a matching edge crossing its vertex cut. Its edge bit belongs to one side. The other side then has a single vertex bit in that edge's parity equation. That vertex bit must be constant among all yes inputs bearing the label. Otherwise mixing two such inputs keeps the pair of bits on one side from one input and changes the singleton bit, falsifying the equation on an accepted file. The matching fixes at least $\gamma k$ distinct independent vertex bits, so one label covers at most a $2^{-\gamma k}$ fraction of yes inputs. There are at most $2^{O_P(w)}$ labels because $h=O_P(1)$. This contradicts acceptance of all yes inputs for sufficiently large $N$. The same proof bounds the fraction accepted by any scan sound on the whole sign family, even if it can run forever elsewhere. ## Coincident register destinations

There is a direct no-clock exclusion when the one LOAD and one numerical instruction both write the same register $r$ and the only other data instruction is a STORE. Assume their regular turns traverse all three sites. With no other mutable register a nonconstant load must be self-addressed. Denote the load result by $x$ and write its ALU successor as $f(x)$, including the case where operands alias. Use the [bounded-palette file with many sensitive addresses](five-instruction-loops-on-dimacs-sat.md); the original image and a bounded number of prologue values together have size $O_P(1)$.

* If the STORE is through $r$ after the ALU and before the next LOAD, it overwrites the next load address. Later loads at such turns cannot observe any new original word.
* An indirect STORE between the LOAD and the ALU is at $x$. Its payload is $x$ or a fixed-on-input word $c$. In the first case every value ever written or returned stays in the initial palette: it copies the word just read. In the second case the only extra memory value is $c$. Thus all regular load addresses after the first lie in the image of this bounded palette under $f$.
* For a STORE at a fixed address $a$, storing $r$ between LOAD and ALU just copies $x$. Storing $r$ after the ALU places the next load address in cell $a$; whenever the next LOAD observes that cell the stored value is $a$. A fixed payload adds at most that fixed word to the set of values returned. In all cases only a bounded number of regular load addresses are possible. The prologue and bounded exit can observe only a bounded additional number of originals.

A LOAD at a fixed address observes at most that original address in the loop. These alternatives cannot observe all the sensitive original words on the file.

## An additive cursor and bounded STORE destinations

Suppose instead the loads are $x\gets M[p]$ and the single ALU sets the next address to $p+x$, $p-x$ or $x-p$ modulo $Q$. Suppose all possible write destinations on the chosen base lie in a fixed set $B$ of bounded size. It suffices that $B$ exist for each base. In particular, if the STORE is $M[x]\gets c$ with fixed-on-input payload $c$, then every value ever read belongs to $H\cup\{c\}$ and that set bounds its destinations. A STORE at a fixed address also meets the hypothesis with arbitrary payload. Add any exceptional initial writes to $B$.

Use a [homogeneous DIMACS base](executed-operands-on-homogeneous-sat-words.md) with $m=\lceil N/w\rceil-O(1)$ distinct sensitive addresses carrying the same large word $A$. Its top byte is 45. Thus $A$ and $-A$ are separated from zero by a fixed fraction of $Q$, while the physical input occupies $o(Q)$ low addresses. If a marked address $r$ is read in its original state, the next regular load address $q$ is one of $r+A,r-A,A-r$ according to the fixed opcode. Both $q$ and $-q$ are outside the physical input. Discard the at most $2|B|$ addresses $r$ for which one of them is in $B$: the maps from $r$ to either of these addresses are injective. The two outside cells for any remaining $r$ are permanently zero. Ignoring exits, the machine is henceforth confined to the two load addresses $q,-q$. This follows by substituting $x=0$ in its fixed update. A bounded exit can read only $O_P(1)$ other originals. At most one of the unboundedly many remaining marked addresses can therefore be read in its original state during the scan before the trap. This contradicts the sensitivity requirement independently of the time available.

The arguments cover the register and STORE schedules as specified. In particular the bounded-destination trap does not analyze adding an odd marker stored at each current cursor address, nor a shifted crossed write with unbounded destinations. The full five-slot decidability question and the unrestricted superlinear RAM-time goal remain open.

The [finite audit](adaptive_marked_prefix_audit.py) replayed 21,334 initial-memory, function and cursor choices across the two rows. It checked 82,169 trace states and 305,340 splices of distinct initial memories. The prefix lengths checked for $W$ are the longest *actually traversed episode* from each seed. A prefix that merely happens to lie inside $W$ could pass an unmarked point using addresses discovered from a different seed. The [Lean file](AdaptiveMarkedRead.lean) verifies the crossed address recurrence, the unmarked endpoint implication for one episode, and pointwise equality of the spliced memory. The orbit-prefix counts and expander argument are manuscript proofs.
