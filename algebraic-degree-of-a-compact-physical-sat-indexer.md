# A compact SAT file for one native source needs high degree in its address

Fix the unary nondeterministic RAM language \(H\) with actual clock \(t=Cn^2\) on \(1^n\). Suppose a uniform procedure supplies the length \(M\le A t\) of an ordinary proper DIMACS file with verdict \(H(1^n)\), and supplies each physical bit in \((\log t)^{O(1)}\) native work from \(n\) and its address. Computing the length and any public setup takes \(o(t)\) time; the bit-query bound includes all subsequent local computation. Then **on infinitely many lengths, the Boolean algebraic degree of the file bit as a function of its address is \(\Omega(\log t)\)**. Degree is over \(\mathbb F_2\). It is the minimum extension degree when the physical length is not a power of two. No polynomial coefficients or degree bounds have to be provided by the indexer. The trivial address-length upper bound is \(O(\log t)\).

This prices local descriptions of the file for a specific native hierarchy source. SAT on an already supplied ordinary file has no established superlinear deterministic RAM time lower bound here. The same calculation gives a possible route to each requested time exclusion if an approximate description of the requisite kind can actually be constructed. ## Recovering a file from sparse address queries

Put \(L=\lceil\log_2(t+2)\rceil\) and \(\ell=\lceil\log_2 M\rceil\). For \(M<\sqrt t\) query all bits directly. Otherwise \(\ell=\Theta(L)\). Reserve the bottom \(b\) physical address bits for a group of \(B=2^b=\Theta(L)\) consecutive file bits fitting in one native word. Write \(m=\ell-b\). On each low lane the Boolean function of the high address has degree at most the whole file's degree. A degree cap \(d\le m/4\) will be used to *attempt* reconstruction. It is safe to run the capped algorithm even when the true degree is larger. Its time bound applies in either event.

For each high address of Hamming weight at most \(d\), query its \(B\) individual file bits, setting invalid addresses in the final range to zero. Pack these into a word. The number of high addresses needed is \(S(m,d)=\sum_{j\le d}\binom mj\). The subset Möbius transform on this downward-closed set gives all coefficient words indexed by degree at most \(d\). In each coordinate sweep XOR the predecessor with that coordinate cleared into the entry with the coordinate set. A combinatorial list of the sparse masks and their indices can be constructed in \(S(m,d)\operatorname{poly}(m)\) time; a direct-address sparse dictionary is also available. For a valid physical position every high submask on its lane gives a smaller, valid physical position. Consequently assigned zeros outside the file cannot corrupt a valid result under the promised extension degree.

Emit the high-address words by descending the high coordinates in physical order. At a node with \(r\) coordinates left, store coefficient arrays for each degree in increasing numerical mask order. The blocks of degree \(j\) first contain the terms omitting the largest variable and then those containing it, the latter in the order of their remaining \(j-1\) coordinates. The zero child uses the first blocks. For the one child XOR into the degree-\(j\) block its matching upper segment from degree \(j+1\). Precompute all lengths by Pascal's recurrence. Segment overhead is at most a constant per nonempty segment, even as \(d\) grows. Word copies and all source/target offsets take constant time per entry. A terminal word is already in physical low-lane order. The exact combinatorial estimate for the total entry visits is
\[
 \sum_{r=0}^m 2^{m-r} S(r,d)
 \le 2^m\sum_{j=0}^d\sum_{r=j}^\infty 2^{-r}\binom rj
 =2^{m+1}(d+1).
\]
A final partial word is masked. This gives a producer of cost
\[
 O\!\left(S(m,d)\,[B\tau+\operatorname{poly}(L)]
           +(d+1)(1+M/B)\right)
\]
for raw-bit evaluation cost \(\tau\). Its hidden constant on the second term is independent of \(d\). Coefficient-based exhaustive polynomial evaluation and degree-dependent upper bounds are established. Here the coefficients are recovered through the unknown physical file's bit interface, and the coefficient words generate consecutive actual file bits. [Bouillaguet, Algorithm 1052](https://doi.org/10.1145/3699957) · [Liu et al., bounded-weight polynomial evaluation](https://eprint.iacr.org/2026/040)

For a separate random-access version, split the \(m\) high bits into \(c\) contiguous nearly equal groups. Let \(Z_i\) set group \(i\) to zero. A monomial missing that group is annihilated by \(I+Z_i\). If every monomial misses at least one group, as happens at degree \(<c\), then
\[
 f=\bigoplus_{i=1}^c\, Z_i\prod_{j<i}(I+Z_j)f .
\]
The terms commute. Each summand ignores group \(i\). Initialize its packed table by sampling the hyperplane with group \(i\) zero. For each earlier group XOR each entry with the one clamped at that earlier group. Use a fresh target array or visit indices in descending order to preserve the old zero slice. Now *any* requested physical word costs \(O(c)\) native operations. The construction uses \(O(c\,2^{\ell-\lfloor m/c\rfloor}(\tau+1+c/B))\) steps. This finite-difference identity is a grouped form of established anchored decompositions. Our Lean proof handles sums of arbitrary Boolean functions with a commuting clamp that fixes each summand. [Kuo, Sloan, Wasilkowski and Woźniakowski](https://doi.org/10.1090/S0025-5718-09-02319-9) · [Formal reconstruction identity](GroupedAddressRestrictions.lean)

## A linear fraction of all address variables

Use the published unary delayed diagonal. Its opponent learns a positive integer quota \(p\) from the current interval. For \(M\ge\sqrt t\) take \(d=\min(\lfloor L/p\rfloor,\lfloor m/4\rfloor)\) and run the first producer. For \(d\le m/4\), the standard binomial estimate gives \(S(m,d)\le 2^{h_2(1/4)m}\), where \(h_2(1/4)<0.812\). Thus setup is \(o(t)\) uniformly in \(p\). Packed generation and nondeterministic SAT verification together cost \(K t/p+o(t)\) for a fixed \(K\) independent of \(p\). The interval opponent checks that the produced bytes are valid before consuming the result, or uses a total time-limited version of the promised-input verifier. On an incorrectly reconstructed or malformed string all branches must still respect the advertised clock. A hard cap above the displayed implementation bound suffices. On the small-\(M\) branch use the exact directly queried file.

Fix the opponent code, then choose a sufficiently large fixed \(p\) that its actual runs are fast enough for the interval simulations. On each sufficiently late interval assigned to this opponent and quota, at least one answer disagrees with \(H\). If every file there had degree at most \(\lfloor L/p\rfloor\), the large-\(M\) reconstruction would be exact (the \(m/4\) cap is inactive for the chosen large \(p\)), and the small-\(M\) case was exact already. Thus there is a length with degree exceeding \(L/p\) in each such interval. This proves the headline quantitatively, even if the true degree as a function of length is unavailable to the opponent. It gives no choice of the true verdict on these bad lengths.

## Sparse errors in a polynomial approximation

Changing one bit of a constant table can create a full-degree address function. There is a more robust necessary condition when the number of exceptions is publicly computable. In this section the indexer is defined on the entire \(\ell\)-bit cube, with arbitrary uniformly accessible padding beyond physical address \(M-1\). Suppose the true table \(f\) differs from some polynomial \(g\) of degree \(\le d\) on exactly \(e\) points. Neither \(g\) nor the locations are supplied. For \(k=d+1\), partition the address into \(a=\lfloor\ell/k\rfloor\) blocks of \(k\) bits and any unused high bits. Work over \(\mathbb F_{2^k}\). For each tag \((u_1,\ldots,u_{a-1})\) consider the \(k\)-dimensional binary subspace
\[
 V_u=\{(z,u_1z,\ldots,u_{a-1}z,0):z\in\mathbb F_{2^k}\}.
\]
Two differently tagged subspaces meet only at zero. The XOR of a degree-\(<k\) polynomial on every affine \(k\)-flat is zero; restriction to its binary coordinates preserves degree, and each surviving monomial has an even number of ones on the flat. At any point \(x\) choose \(2e+1\) distinct tags. Taking the XOR of \(f\) on \((x+V_u)\setminus\{x\}\) gives the true \(g(x)\) except on at most \(e\) of these votes. Majority therefore recovers \(g(x)\) **exactly**. This is the standard disjoint-check argument for binary Reed–Muller codes. The field can be built uniformly by enumerating monic degree-\(k\) polynomials and testing irreducibility in polynomial time in \(k\) per candidate, e.g. by repeated squaring and polynomial gcd. [Low-degree local correction and earlier literature](https://arxiv.org/abs/2411.07374)

In fact the raw bit interface may take \(t^\alpha\operatorname{poly}(L)\) steps for a fixed \(0\le\alpha<1\). Write \(E\le t^\gamma\), with \(\alpha+\gamma<1\), for an explicit upper bound on the number of errors. Pick \(\gamma<\theta<1-\alpha\), and directly query all physical bits if \(M<t^\theta\). On the remaining lengths \(\ell\ge\theta\log_2 t-O(1)\). Fix \(p\) large. With \(d\le L/p\) and \(k=d+1\), the supply of tags \(2^{k(a-1)}\ge 2^{\ell-2k}\) exceeds \(2E+1\). The number of degree-\(\le d\) monomials in the **full address** satisfies
\[
 R=\sum_{j=0}^d\binom{\ell}{j}\le t^{\delta_p+o(1)},\qquad \delta_p\longrightarrow0
 \quad(p\longrightarrow\infty).
\]
For instance use binary entropy at \(d/\ell\le 2/(\theta p)\). Small quotas use a fixed default. This choice ensures that all the following exponent margins hold simultaneously for every sufficiently large fixed \(p\).

Recover \(g(x)\) by the disjoint votes only at the \(R\) addresses of Hamming weight at most \(d\). The subset Möbius transform there gives every coefficient of the actual polynomial. This costs \(O(R(1+E)2^k(t^\alpha+1)\operatorname{poly}(L))=o(t)\). From these coefficients we may evaluate \(g\) at any further position in \(O(R\operatorname{poly}(L))\) time. When the **exact** count \(e\le E\) is uniformly available, guess \(e\) distinct positions and check \(f(x)\ne g(x)\) at each. The total further cost is \(O((1+E)(t^\alpha+R)\operatorname{poly}(L))=o(t)\). Every successful guess now contains precisely all true exceptions. To generate the polynomial's physical table, construct a word coefficient for each high monomial by summing the supplied full coefficients on every low lane, in \(R\operatorname{poly}(L)\) time overall: each full monomial bears one high coordinate set and contributes one precomputed low-lane mask. Then use the ordered descent above, restoring the guessed positions inside the physical file. The cost that scales with \(M\) remains \(O((d+1)(1+M/B))\). If a promise fails, time-limit the check on the resulting string. On every true promised length all surviving branches output the actual formula and there is at least one correct branch before testing satisfiability.

Thus compact uniformly indexed files for \(H\) cannot always be within this many **publicly counted** exceptions of degree \(o(\log t)\). The constant-quota proof again forces an obstruction at a positive fixed fraction of \(L\). Uniformly enumerated exceptions or a fixed public header qualify. The same conclusion holds with an upper bound alone when the formula has the following semantic property. Restoring *any subset* of the genuine corrections to the base \(g\) produces a proper file whose satisfiability implies satisfiability of the fully corrected file. Then guess any number up to \(E\), check that each proposed correction is genuine, and verify the partially restored file. The true full set is available to a branch. Any satisfiable partial restoration is sound. For example, replacing independently designated clauses by clauses whose model sets contain the old ones has this property when the replacements and their distinct physical edits correspond one-to-one. The exact degree theorem without exceptions also works at any \(\alpha<1\) by taking \(E=0\).

## An unknown distribution of defects and the three SAT time targets

Let \(K\in\{1,2,3\}\). Suppose the fixed source admits a proper file of \(M=O(t)\) physical bits with the following properties.

* A uniform procedure supplies its length and public descriptor in \(o(t)\) time. The descriptor has \(O(t^\lambda\operatorname{poly}(L))\) bits and is available to the short computation below; it may be just the binary length \(n\).
* Starting from this descriptor and the address, an original bit costs at most \(t^\alpha\operatorname{poly}(L)\) actual native operations. These calls need no hidden large preprocessing table.
* Its physical positions are a union of at most \(1+\lfloor t^\gamma\rfloor\) consecutive intervals, and on each interval the bit function agrees with some binary polynomial of degree \(o(\log t)\) in the absolute binary address. The degree bound is uniform over the intervals as \(n\) grows. Boundaries and coefficients may be entirely unknown. In particular, this includes a file within \(t^\gamma\) unknown bit changes of a single such polynomial, adjusting the harmless constant on the interval bound.
* The fixed nonnegative exponents satisfy \(\max(\alpha,\gamma,\lambda)<1/K\).

**Existence of this one decision-preserving representation would exclude deterministic \(O(N^K)\) SAT time on the unrestricted RAM.** For instance a quarter-power bound on each of local computation, public descriptor and number of intervals meets the numerical inequalities for all three proposed exponents. No such representation for this source is known here.

Assume a deterministic \(O(N^K)\) SAT solver. As before, choose a small fixed \(\theta<1-\alpha\) and directly produce very short outputs with \(M<t^\theta\). Otherwise \(\ell=\Theta(L)\). For \(d=\min(\lfloor L/p\rfloor,\lfloor m/4\rfloor)\), guess a sorted partition of the valid addresses into the stated number of intervals, with their endpoints and the \(R\) low-degree coefficients for each interval. Reject invalid endpoints or gaps. For sufficiently large fixed \(p\), the whole proposed table of descriptions has \(t^{\gamma+\delta_p+o(1)}\) bits. It allows evaluation of the predicted bit at one address by locating its interval and evaluating that polynomial. A sequential search of the entire proposed descriptor would also fit the exponent used below.

A defect in the proposal is a single physical address \(x<M\) at which the predicted bit differs from the actual local computation \(f(x)\). Guessing such an address and checking the difference is a short nondeterministic computation. Fix a rational \(\rho\) strictly between \(\max(\alpha,\gamma,\lambda)\) and \(1/K\). Increase the fixed lower cutoff for \(p\) so that proposal length, input descriptor and challenge time all have exponents strictly below \(\rho\). The opponent returns a fixed default below this cutoff. It builds the ordinary quasilinear-overhead bounded-computation SAT formula for the challenge; all named output bits and their construction fit in \(O(t^\rho)\). One call to the hypothesized solver thus costs \(O(t^{K\rho})=o(t)\). If any defect exists, reject the proposal. Otherwise every bit on every interval is exactly right. This step validates every surviving branch, including when different descriptions agree on a short interval. [Bounded native RAM compiler and ordinary named clauses](native-linear-time-and-locally-uniform-circuit-depth.md) · [Jahanjou, Miles and Viola, locally supplied clauses with logarithmic factors](https://eccc.weizmann.ac.il/report/2013/099/)

For this challenge pass the actual public descriptor, the binary \(n,M,\ell\), the quota and the proposed coefficients and endpoints. To realize the guest word width, add and pay for a physical zero pad of \(t^\xi\) bits with fixed \(0<\xi<\rho\). The \(O(\log t)\)-bit operations of the original local indexer use a fixed number of guest limbs. A sparse constant-depth trie simulates larger addresses at constant overhead for a fixed width ratio. The bound covers the guest input, the binary descriptor, its permitted run length, and the physical materialization of all names. A bit of an original unary source or clock, when wanted by the local algorithm, is calculated from the supplied numerical endpoints.

To print a verified proposal, split each interval into at most \(2\ell+1\) disjoint aligned binary address blocks. For each block fix its leading address bits in that interval's polynomial. Accumulate by high monomial and physical low-lane mask as above in \(R\operatorname{poly}(L)\) time per block. On a block shorter than one output word, directly evaluate its at most \(B\) positions. On a longer block of length \(s\), the word-coefficient descent uses \(O((1+d)s/B)\) further operations. Consecutive block fragments concatenate with at most constant native shifts and masks per emitted word or partial word. All blocks together therefore cost
\[
 O(t^{\gamma+\delta_p+o(1)} + (1+d)(1+M/B)).
\]
On any length meeting the representation promise there is an honest guess. Every surviving guess is the physical file after the defect test. Use the packed nondeterministic verifier on this result. The entire opponent costs at most \(K't/p+o(t)\) on large fixed quotas, with \(K'\) independent of \(p\). On all sufficiently late lengths of any one such quota, \(o(\log t)\) degree fits beneath the cap. Choosing a sufficiently large fixed quota on its own delayed-diagonal intervals gives the contradiction. This argument tests the *small site-disagreement formula* with the hypothetical deterministic SAT solver; the large restored file is handled by a nondeterministic verifier.

For \(0\le\beta<1\) the same implication allows \(M=O(tL^\beta)\) physical bits if the interval degree promise is \(o(L^{1-\beta})\). Set \(d=\min(\lfloor L^{1-\beta}/p\rfloor,\lfloor m/4\rfloor)\). The printed words and subsequent nondeterministic verification cost \(O(t/p+t/L^{1-\beta})\); the earlier coefficient and defect bounds continue to hold. At the full \(t\log t\) length scale, packed production and ordinary verification already consume a constant multiple of \(t\).

The local-reduction theorem cited above gives quasilinear-size clause descriptions for its machine model. It does not furnish the \(O(t)\)-bit ordinary DIMACS length and piecewise address structure required here. Constructing these, with the stated uniform timing, is the step missing from a proof of any RAM milestone.
