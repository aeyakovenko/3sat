# One LOAD, one STORE and one ALU cannot decide the four-word catalog in five slots

On the dense 16-bit sign-plane SAT catalog, no five-static-slot program with one LOAD instruction, one STORE instruction and one ALU instruction gives the correct verdict on every input, **even with unbounded running time**. Input cells 0, 1, 2 and 3 contain the four-bit words $P_0,P_1,N_0,N_1$. Scratch cells and registers begin at zero. SAT requires $P_j\mathbin{\&}N_j=0$ for both $j$ and $(N_0,N_1)\ne(15,15)$. The ALU may use the full arithmetic, bitwise, shift and comparison basis from the four-word experiment. Both fixed-target comparison branches may read any registers or literals. [Catalog and instruction semantics](exact-clocks-for-two-word-sat-inputs.md)

## Which instructions must repeat

Discard unreachable instructions and let $s$ count the remainder. With at most two branch sites there are at most $s+2$ edges amongst the $s$ instructions and two reachable verdict vertices. A connected graph containing a cycle must have at least $s+2$ edges, even counting parallel arcs and loops. Thus any cycle is unique. Edges outside it form trees. If one branch precedes the cycle and determines whether to enter it, the entire subgraph entered on that edge has only one reachable terminal. Totality allows replacement by its fixed verdict. If there is one branch after the cycle, it can compare the registers at exit. If both are on the cycle, their off-cycle continuations give fixed verdicts. This is the same control-graph argument used for the two-word experiment. [Four-slot control analysis](static-program-size-on-two-sign-planes.md)

Use the 324 assignments with all four input words at least 4 and with $P_j\mathbin{\&}N_j=0$ for both $j$. They are SAT. Replacing any one word by 15 causes a conflict with its nonzero partner. Hence on **each** of these inputs the execution must read all four original words, before any store overwrites a word whose value has not yet been read. A load through a fixed address cannot do so. The single LOAD must lie on the cycle.

The ALU must also lie on the cycle. Otherwise it can produce at most one new word in a run. Words available as data in registers and memory are then zero, the four original high inputs, the single ALU result, and at most one immediate payload from the STORE. A literal used only as a branch threshold or an address is never supplied as a data value by that use. The possible indirect load addresses among $\{0,1,2,3\}$ therefore number at most three. This argument includes programs with two different register destinations and programs storing through either.

The list of continuing data operations is now especially simple. If the STORE lies on the cycle, some permutation of the three data instructions repeats. If it precedes the cycle, a single initial STORE is followed by alternating LOAD and ALU, in either order. If it follows the cycle, it cannot change the final verdict since no further LOAD or ALU remains. This case is covered by an ineffective initial STORE. Any initial branch before the first data instruction sees only zero registers and public literals. After the last observation on the cycle the program cannot read any further memory into a register.

## An exact test for stationary stopping rules

Fix the operands, register aliases and continuing schedule of data operations. Ignore both branches and step the data instructions forever. Give a prospective verifier a stronger exit rule than the original comparisons. At *each* gap after a data instruction, any function of the cyclic phase and the complete current register pair may answer YES, answer NO or continue. In the single-register case the other register is zero. This permits both comparisons at a single gap, an arbitrary final comparison after exit, and several possible exit phases. For each input the infinite walk is deterministic. Its complete memory, registers and fixed-phase position are finite, so its observed sequence can be reduced to the list of observations in first-occurrence order. If the first occurrence of an observation continues, every subsequent occurrence does too.

For finite lists with prescribed Boolean answers the following procedure exactly decides whether such a stopping rule exists. Start with no observations forced to continue. On each input, advance past its initial forced observations. If its entire list is exhausted, reject. Otherwise record the required output at its first remaining observation. If opposite outputs meet at one observation, that observation must continue: both inputs reach it under any putative solution, and either terminal would give a wrong verdict on one. Add all such observations and repeat. If no conflict remains, label each current observation by its unique required output and label all forced observations to continue. Every input then terminates correctly. Each unsuccessful iteration adds a forced observation, which proves termination. [Lean proof of the stopping-rule algorithm](ForcedStoppingRules.lean)

## Finite checks

The checker first ignores branches and requires that every high sensitive input eventually reveal all four original words. It then tests the surviving schedules against the sixteen inputs with each of the four words in $\{0,1\}$. On these inputs SAT is $(1-P_0N_0)(1-P_1N_1)$. The second test grants the arbitrary stopping rule just described. Full-state cycle detection, independently of the observed register pairs, makes both checks unbounded in time.

| --- | ---: | ---: | ---: | ---: |
| LOAD and ALU overwrite the same register | 295 | 682,040 | 0 | 0 |
| Separate registers, LOAD addressed through its own destination | 607 | 1,573,344 | 10 | 0 |
| Separate registers, LOAD addressed through the ALU destination | 607 | 1,573,344 | 14,740 | 0 |

These are valuations of the full four-bit ALU, with arbitrary literals and either source order. Two-register tables have 256 entries; unary tables have 16. Deduplication identifies instructions only when their entire tables agree. With one destination register there are 17 possible STORE address operands and 17 payload operands; with two registers there are 18 of each. The eight possible data schedules account for the remaining factor. Unwritten registers are constant zero.

In the implementation a four-bit mask tracks which original cells have ever been overwritten and another tracks which have been loaded before being overwritten. Memory includes all sixteen writable words. The complete state is compared at the same phase with Brent cycle detection. Positive controls run a counter that scans all four words on the 324 inputs and verify that a nonconstant single-word predicate is expressible by the stopping policy. The code asserts the three sets of counts above. [Complete C++17 checker](one_load_one_store_five_slots.cpp)

This excludes the writable-memory case with one arithmetic instruction at five static slots. The finite instance and the fixed instruction allocation are essential to the result. Other allocations and general SAT running time require additional arguments.
