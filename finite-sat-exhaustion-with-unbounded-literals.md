# What finite SAT exhaustion can certify when a stored literal has no size limit

Fix a budget of $s$ stored instructions and a deadline $t(n)=C(n+1)^k$ with positive integers $C,k$. Use the separate-operation RAM and proper, whitespace-padded ASCII DIMACS 3-CNF of the [five-instruction theorem](five-instructions-cannot-decide-dimacs-sat.md). The width is $w_D(n)=16\lceil D\log_2(n+2)/16\rceil$, with a fixed positive integer $D$. A numeric literal can be any ordinary integer. Only its residue modulo $2^{w_D(n)}$ is available to a running program. Code locations and register names affect only control flow and register selection. They cannot be inspected as data. A timeout or wrong terminal is a failure.

Call a byte-aligned length $L$ **good** when some program of at most $s$ slots passes the deadline on every valid file of that length. The witness program for one good length can differ completely from the next. If for some fixed integer $h>1$ every sufficiently large interval $[a,a^h]$ contains a good length, then **$\mathrm P=\mathrm{NP}$**. Consequently if $\mathrm P\ne\mathrm{NP}$, every choice of $D,s,C,k,h$ has arbitrarily large intervals $[a,a^h]$ in which *every* byte-aligned length has a finite suite defeating all $s$-slot programs at that clock. One such suite at length $L$ contains at most $A_s2^{2s w_D(L)}$ files, where $A_s$ is independent of $L$.

This is a consequence of the classical logarithmic-advice theorem for SAT and padding. The details below address arbitrary immediate integers, actual proper formulas of the same length and unrestricted guest memory. Fortnow and Santhanam studied simulation on polynomial intervals of lengths. No historical priority is claimed for the underlying advice or length arguments. [Karp and Lipton, *Some connections between nonuniform and uniform complexity classes*](https://doi.org/10.1145/800141.804678) · [Fortnow and Santhanam, *Robust Simulations and Significant Separations*](https://arxiv.org/abs/1012.2034)

## What a program on one width can encode

Renumber the finitely many registers in order of first appearance, reserving the distinguished public registers. A program of at most $s$ slots has at most $A_s$ remaining choices for its finite structure. These choices specify opcodes, direct labels, entry point, named registers and the locations of immediate operands. Each structure has at most $r=2s$ numeric operand positions. At width $w$ their values have at most $2^{rw}$ choices. Every tuple of residues can itself be used as the tuple of ordinary nonnegative program literals. If a length is bad, one failing valid input per structure and residue tuple is a simultaneous defeating suite of the claimed size. This is an existence count. Finding a smallest suite may take much longer.

There is a separate question for a *whole horizon*. Given $D,s,t$, the following are equivalent.

1. For each $N$, one ordinary-integer program of at most $s$ slots passes on every valid file of length at most $N$.
2. One finite program structure of at most $s$ slots passes on every valid file if its numeric operands are allowed to be fixed **2-adic integers**. Here this simply means an infinite sequence of binary digits per literal, supplying its lowest $w_D(n)$ bits at length $n$.

For the forward direction some structure passes unboundedly many horizons since there are finitely many structures. Interleave its literal digits in rounds, going from the low bits toward the high bits of each operand. A prefix is legal if all tests that can already see their entire required width pass. A truncation of a legal prefix is legal. Every finite depth has a legal prefix: all lengths whose width becomes visible by that depth are bounded, so take a program of this structure passing that horizon. If the structure uses no immediates its runs are already fixed. Otherwise the binary prefix tree has a node at every depth. At a node with unbounded extension depth at least one child also has unbounded extension depth. Repeated choices give an infinite path and the required residues. Conversely, truncating each infinite operand at the largest width of any file through $N$ gives an ordinary integer program for that horizon. The same equivalence holds with clock-free correctness as a predicate on finite-width runs. The polynomial-time uniformization below uses the clock.

The distinction is real for decidable labellings. Enumerate all polynomially clocked deterministic Turing machines, with timeouts defaulting to rejection. At $n_j=2^{16j-1}$ bits choose a fixed valid proper formula padded to that length, for $j\ge1$. At $D=1$ the width there is $16j$. Relabel every valid file of width $16j$ by the opposite of the $j$-th machine's answer on that chosen file. The resulting relabelling is decidable and has no polynomial-time decider. An oracle-free machine can compute each label by the specified finite simulation, using arbitrarily long time. Yet three fixed slots, supplied public $w$, fit every finite horizon in three steps: subtract 1 from $w$, shift a literal right by that count, and branch on whether the result is zero. Choose the literal's bit $16j-1$ equal to the prescribed label in every visible block. All tested shifts have effective count $w-1$ under both standard shift conventions. This example uses a different labelling of the same syntax, so the SAT-specific analysis still requires a proof about satisfying assignments.

## Removing the literals by verified assignment search

Let $F$ be a valid file of length $n$. Record its $q$ distinct occurring variable identifiers, ignoring unused ones in the header. To force a previously unpinned variable $x$ to a chosen value, append the four clauses
$$
     (\ell_x\lor\pm y\lor\pm z)
$$
with all four sign pairs. Here $y,z$ are two distinct identifiers in $\{1,2,3\}$ different from $x$, and the sign of $\ell_x$ specifies the desired value. When $\ell_x$ is false the actual values of $y,z$ falsify one of these four clauses. Hence the four added clauses are equivalent to the pin even if $y,z$ occur in other constraints. Raise the declared variable bound to at least 3 if necessary and update the clause count.

Any restriction fixing each of a subset of the occurring variables once has a proper DIMACS representation of at most $B=b(n+1)$ bits for one absolute integer $b$, which can be chosen divisible by eight. The variable names copied four times in the pins have total original digit length at most the file length, since each distinct name appears in $F$. The dummy names have one digit, and the header and delimiters fit the same bound. For *any* byte-aligned $L\ge B$, pad every one of these files to exactly $L$ with trailing whitespace. This works even when the unpadded restrictions have different numbers of clauses and the header declares unused identifiers with many digits.

For each byte-aligned $L$ from $B$ through $B^h$, enumerate all the finite structures and all literal residues at that width. For a fixed candidate, build one assignment in order. At each variable, query the candidate on the current restriction extended by setting this variable false, padded to $L$. Keep that choice if it reports satisfiable, otherwise try the true value as the next prefix without making a second query. A timeout can discard this candidate. After the last variable, verify the assignment by evaluating the *original* clauses. Accept only a verified assignment. Return no after all candidates at all these lengths have failed.

An unsatisfiable file never has a verified assignment. If $F$ is satisfiable, any candidate correct on all files at one tested length maintains a satisfiable prefix at every stage and supplies a verified assignment. Thus one good length in the interval suffices. Finite exceptions at small lengths can be handled by any exhaustive decider.

The calls for a prescribed length $L$ number at most $qA_s2^{r w_D(L)}$ and each uses at most $t(L)$ guest steps. Across the interval both the number of lengths and the cost per guest simulation are polynomial in $n$, because $r,D,h,C,k$ are fixed. A deterministic Turing machine can simulate the guest by keeping a list of written cells, consulting the initial file on a miss and implementing the fixed arithmetic on $O(\log n)$ bits. This includes an arbitrary indirect read or write. Alternatively, a uniform host RAM with a sufficiently large fixed width coefficient can reserve $2^{w_D(L)}$ guest addresses and simulate the native operations on masked guest words. This proof requires polynomial uniform cost and does not assume that a host at coefficient one can directly address every cell of a guest at a larger length. It proves proper 3-SAT in polynomial time and hence $\mathrm P=\mathrm{NP}$.

When we quantify over **all** positive integer width coefficients, slot budgets and polynomial clocks, the following three statements are equivalent.

* $\mathrm P\ne\mathrm{NP}$.
* Every such budget and clock have a finite simultaneous defeating suite.
* Every such budget and clock have a bad file suite at every byte-aligned length on arbitrarily large intervals $[a,a^h]$, for each fixed integer $h>1$.

The first implies the third by the verified search and the third implies the second. If $\mathrm P=\mathrm{NP}$, some fixed polynomial-time SAT decider has a conventional polynomial-time RAM implementation, with a sufficiently large fixed width coefficient to address its polynomial work tape. Its finite program and all-length clock contradict the second statement. Keeping a particular small $D$ fixes the physical address range; only the forward implications have been shown at that specified coefficient. For the project's specific linear, quadratic or cubic deadline, failure of finite exhaustion for *one* slot budget would already imply $\mathrm P=\mathrm{NP}$. The reverse implication at a prescribed exponent would require achieving that very clock. No unconditional failure at unbounded slot budgets has been derived.

## An executable successor rule and the missing termination proof

One partial computable exhaustion has a precise global stopping condition. Start at stage $j=2$. Search successive integers $a$ above the end of the last accepted interval, taking $a\ge16$ so the interval contains byte-aligned lengths. On each byte-aligned $L\in[a,a^j]$, test all coefficients $1\le D\le j$, all structures with at most $j$ instructions, and all their residues at $w_D(L)$. Require that every candidate miss at least one valid file within $j(L+1)^j$ steps. Enumerate all files of length $L$, test syntax, and compute each valid SAT label by exhaustive assignment to the occurring variables. Every proposed interval can be checked in finite time. On success output the interval with one defeating file per candidate at each length, and advance to $j+1$.

**This search completes every stage if and only if $\mathrm P\ne\mathrm{NP}$.** In the forward proof from $\mathrm P\ne\mathrm{NP}$, the good lengths for the *union* of the finitely many coefficients $D\le j$ must still have arbitrarily large gaps $[a,a^j]$. Otherwise the same uniform assignment search can try all $D\le j$ at every tested length and decide SAT in polynomial time. Gaps for each coefficient considered independently would not by themselves give a common gap. In the other direction, a polynomial-time SAT decider of finite size at some fixed coefficient eventually fits the stage's width, slot and polynomial-clock budgets and blocks that stage.

This is a successor *search*. A proof that it always finds its next interval would settle $\mathrm P\ne\mathrm{NP}$. If the deadline at stage $j$ is instead only $j(L+1)$, termination of all stages suffices to exclude every fixed-coefficient uniform linear-time solver. The polynomial-time converse supplies no decision at this one exponent. The search does not itself transport an old witness to a new slot budget.
