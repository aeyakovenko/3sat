# A SAT solver can leave a polynomial block of its matrix file until after the verdict on a repaired copy

Fix any correct deterministic SAT RAM $P$, with worst-case time $T(N)$ at encoded length $N$. There is a correct deterministic SAT RAM with worst-case time $O(N+T(N))$ for which every canonical binary-product mismatch file has this behavior. Before examining any of a public set of $\Theta(N^\rho)$ source bits, it has finished its only SAT subroutine call. It then spends $O(1)$ steps per remaining original word. After the final data-bearing load it uses $O(1)$ steps and reads **zero** old input or work addresses. The statement holds for every fixed rational $0<\rho<1/(\log_2 7-1)=0.55329\ldots$ by Strassen's algorithm alone, and for every rational $0<\rho<2\sqrt{2}-2=0.82842\ldots$ using the November 2026 rectangular multiplication upper bound. The source bits form most of a square block of the claimed product. The total clock includes all preprocessing and the repaired SAT instance. [Strassen (1969)](https://doi.org/10.1007/BF02165411) · [Pinned rectangular exponent theorem](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/lean/docs/107.md)

## Repairing a file before reading its pending words

Use the bit-once, dense proper DIMACS projection of $AB\ne C$ over $\mathbb F_2$, with $d$ a power of two. Each differing coordinate contributes exactly one satisfying assignment. Pad with whitespace to $N=Kd^2$ bits for a fixed sufficiently large byte-aligned $K$, so the machine can recover the dimension from the input length. The template has an $O(N)$ construction giving the file and the changing-bit map. Canonical files here have the construction's fixed clause order. We use aligned loads, a constant number of working registers, bitwise word operations, and a sufficiently large fixed coefficient in the $\Theta(\log N)$ word width. [Bit-once encoding and implementation](compact-bit-projection-of-matrix-mismatch.md)

Take $r$ a power of two within a factor two of $d^\rho$. Reserve all original data-bearing words whose variable bits belong entirely to the leading $r\times r$ block of $C$ and include at least one such bit. On each selected row its selected chunks occur consecutively. At most two boundary words per row contain both selected and unselected digits. Thus $r^2-O(r\log N)$ selected bits are reserved. Each chunk record has $O(\log d)$ bits and $\Theta(\log d)$ varying digits. The number of reserved words is consequently $\Theta(r^2/\log N)$. For large $d$, the chunk width divides $r$. [Physical layout](compact_product_projection_audit.py)

Scan and copy the other original words, testing every public bit outside the reserved words against its template. Unexpected structure goes directly to $P$ on the original file. From the copied factors compute $(AB)_{[r],[r]}$. Construct the reserved words in scratch as though their data bits agreed with this block, including every public bit dictated by the template. Run $P$ on that completed file. This gives the verdict on discrepancies outside the reserved bits. For a canonical original, SAT is precisely the disjunction of the saved verdict and a differing reserved bit. Each remaining original word needs one load, an XOR against its prepared value, and masked tests of the differences at fixed and varying positions. Accumulate both flags, scanning to the end even after a difference. If some fixed bit was wrong, run $P$ on the original. Otherwise return the disjunction. For the last word load its metadata into registers beforehand. The concluding flag logic and return can run entirely in registers. All canonical positive and negative inputs take this fast concluding branch.

The scratch guest sees a legal canonical input whenever it runs. Arrange disjoint guest and host address spaces, with the guest's word semantics simulated by a fixed number of host instructions if the width coefficient is enlarged. For a fallback, another disjoint segment or clearing the guest's write log restores initial scratch. At most two guest calls of length $N$ occur. The bound compares worst-case clocks, since the guest's elapsed time on the repaired file may differ from its time on the original. Short lengths and other dimensions can go directly to $P$.

## Cost of the predicted block

Partition the inner dimension into $d/r$ panels and apply Strassen to each square product. This takes $O(d r^{\log_2 7-1})$ binary field operations, fitting $O(d^2)$ in the first range. For the second range the documented rectangular exponent for weights $(1,\rho,\rho)$ is $1+\rho+\rho^2/4<2$. To pass from the algebraic exponent to a single RAM, write $\rho=a/b$ and choose a fixed sufficiently large power-of-two base dimension $s^b$. A straight-line algorithm with strict exponent slack yields a bilinear decomposition for $s^a$ by $s^b$ by $s^a$ multiplication over $\mathbb F_2$. Extracting both input bidegrees $(1,0),(0,1)$ and the $(1,1)$ component costs a constant factor in rank. Choose the base large enough that the resulting product count $R$ is less than $s^{2b}$. Hardwire that finite scheme and recurse on blocks, padding dimensions up to powers of the base. The linear combinations over a fixed scheme cost at most a constant times the number of entries at each recursive node. At recursion depth $j$ the total work is bounded by a constant times $R^j$ times the largest input or output block area there. Both $R$ and the largest area $s^{a+b}$ of a base matrix are strictly less than $s^{2b}$, so summing levels still fits $O(d^2)$. Field operations are constant-cost word instructions. The proof uses strict slack, with no big-O claim at the second endpoint. [Rectangular statement](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/lean/docs/107.md)

Choose any changing bit in the wrapper's fixed last word. Toggling it pairs **all** $2^{2d^2}$ exact products injectively with distinct uniquely satisfiable files. Both endpoints expose all source bits and share the prefix through the final load address. Thus even maximum pair count, physical distance one and uniqueness together permit a constant post-load clock on this family. Earlier results forcing many subsequent old reads use a different template with interchangeable query packets. For exact bilinear predictors using only the factors, the journal gives a matching patch-size exponent in the second range. A general SAT RAM can also use the claimed product and arbitrary interleaved operations. ## When even an operand can be withheld

There is a variant for almost every exact center in which the pending block belongs to $A$. Group the data clauses by matrix and order each $A$ column consecutively. This is a public reordering of proper clauses and preserves the assignment count. Align the three banks with public whitespace. Take the same $r$ and standard index sets $I=K_0=[r]$. Read $B$ first. Look for a nonsingular $r$-square submatrix $B_{K_0,J}$ in $L=\lfloor d^\eta\rfloor$ disjoint column groups, where $\eta>0$ satisfies $\eta+\rho<1$ and $\eta+\rho(9/4+\delta)<2$ for a small fixed $\delta>0$. These inequalities admit a solution throughout the second range. Rank and inversion cost $O(r^{9/4+\delta})$ per attempt using fast elimination with pivoting and the same square multiplication upper bound. Under uniform $B$ each independent group passes with probability $\prod_{j=1}^r(1-2^{-j})>1/4$. The first two factors give $3/8$ and the remaining product is at least $1-\sum_{j\ge3}2^{-j}=3/4$. Failure probability is at most $(3/4)^L$. On failure use the $C$ procedure above. [Rank-revealing elimination and inversion](https://arxiv.org/abs/1112.5717)

On success, defer the pure words of $A_{I,K_0}$. Copy everything else. Put zero in the entire selected block to obtain $A^{(0)}$, and compute
$$
 X=(C_{I,J}-A^{(0)}_{I,:} B_{:,J}) (B_{K_0,J})^{-1}.
$$
Every completion satisfying $AB=C$ has $A_{I,K_0}=X$. Construct the synthetic input with $X$ in the entire block, keeping any already exposed disagreements as a flag. Rectangular multiplication and one square multiplication fit $O(d^2)$. If any actual bit of the block differs from $X$, the actual file is SAT. If all agree, its verdict is exactly the guest's. The same template checks and wordwise suffix therefore apply. For independent uniform factors the operand branch succeeds with probability $1-\exp(-\Omega(d^\eta))$, also conditioned on isolation since isolated centers have density tending to one. An operand flip can induce several erroneous entries.

There is also a worst-case operand guarantee on **every isolated center**. Put $q=\lceil\log_2(d+1)\rceil$. The $d$ rows of $B$ are distinct and nonzero, so their rank is at least $q$. Before reading $A$, select $q$ independent rows $K_0$ of $B$ and their $q$ pivot columns $J$ by incremental Gaussian elimination. Reduce each incoming packed row against at most $q$ basis rows, in $O(d^2q/w+dq)=O(d^2)$ word steps for $w=\Theta(\log N)$. Row XORs, pivot tests, and a scan for a new pivot suffice. Defer the pure words of these $q$ **entire** $A$ columns, losing at most two boundary words per column. To apply the displayed formula with all $d$ rows in $I$, pack $B_{k,J}$ into a word for each $k$. For each $i$, XOR the packed vectors selected by the exposed $A_{ik}$ outside $K_0$ to obtain the right-hand side in $O(d)$ work. Solving the $q$-dimensional systems for all $d$ rows takes $O(q^3+dq^2)$ more work. The final comparisons handle $dq-O(qw)$ pending operand bits. A separate wrapper can use this rule whenever the rank is sufficient, and the output-patch branch when it is deficient.

The dimension guarantee for unique recovery of whole columns is sharp. If the corresponding rows of $B$ are dependent, one may change a row of $A$ by the dependence vector, supported inside the missing columns, without affecting $C$. For $d\ge3$ take a $q$-dimensional subspace of the even-weight vectors of length $d$ (possible since $q\le d-1$). Choose $d$ distinct nonzero rows spanning it, and take $A=B^{\mathsf T}$. Then both row and column isolation conditions hold and $\operatorname{rank} B=q$. This sharpness concerns a single forced completion. Other ways of using advice, or testing consistency without reconstructing the missing columns, are outside the argument. [Isolation characterization](isolated-products-at-the-last-sat-input-read.md)
