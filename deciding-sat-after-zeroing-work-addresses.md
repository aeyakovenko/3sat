# Deciding SAT after zeroing work addresses

Fix a deterministic SAT RAM with immutable random-access input, zero-initialized work words, and a public deadline $T$. For an input $x$ and a set $U$ of work addresses, let $v_x(U)$ be its projected verdict. Stores to $U$ take effect normally and all reads outside $U$ return zero. Give timeouts a fixed Boolean verdict and use that convention on every projection. The genuine computation halts by $T$.

## Two competing address sets

Fix a public constructible budget $k(N)$, where $N$ is the encoded input length. Suppose on every input there is a set $P_x$ of at most $k$ addresses such that

$$
  v_x(P_x\cup Q)=\operatorname{SAT}(x)
  \qquad\text{for every }Q\text{ of at most }k\text{ addresses}.
$$

Then the following three-block alternating test decides SAT. Universally choose $Q$ of size at most $k$. Existentially choose $P$ of size at most $k$ and the checkpoint states of the deterministic $P\cup Q$ projection. Universally choose one checkpoint interval and check its execution, including the prescribed initial state and the accepting final state at the incident boundaries. On a satisfying file the same $P_x$ works against every $Q$. On an unsatisfiable file the universal player chooses $Q=P_x$. Since union is commutative every existential response then computes zero. Both implications concern only the final verdict. Either side's winning projection can have incorrect reads and can follow a completely different instruction sequence from the genuine run.

In fact, only the unsatisfiable side needs a single set that defeats all opponents. On a satisfying input $P$ may depend on $Q$. It suffices that each $k$-address projection can be made accepting by retaining at most $k$ additional addresses. This allows different repairs for different projected runs.

For $p$ intervals the existential guess costs $O(p(k+1))$ words. A selected interval costs $O(T/p+k+1)$ native steps, apart from the simulated input access cost. Encode the lists in sorted order with fixed padding. Merge them and rebuild an address-to-slot dictionary at each chosen start in $O(k+1)$ operations. Only the at most $2k$ stored slot values and the fixed controller need to be checkpointed. The public input to the existential block contains the original input and $Q$; it does not contain $P$ or the checkpoint list. These costs and the quantifier ordering are exactly those used in the journal's three-block transfer. Thus the same simultaneous resource exclusions apply under this two-verdict hypothesis, including $c(c+e)<2$ for the stated polynomial time and support exponents, and the log-precision linear-clock exclusion for constructible budgets $k=\lceil N/\log^{3a+11}N\rceil$ (or fixed constant multiples) at time $O(N\log^a N)$. The clock, virtual input access and log-precision lookup estimates are imported from that transfer. For small enlargements the challenger budget matters. For example, on four addresses let $v(U)=1$ exactly at set sizes $0,1,4$. The genuine verdict is one. Budget one succeeds using the empty set, but every proposal of size at most two can be enlarged to a two-element set by at most two addresses. Consequently a bound on the *minimum* successful budget cannot simply be padded to a larger prescribed budget. If a protected set guarantees the correct verdict for **all** enlargements, or even for arbitrarily chosen work replies outside it, padding is valid. The theorem then excludes the corresponding joint time and set-size cap on all files. The two-player test by itself gives no per-verdict conclusion.

## A linear native trace separating protection from sensitivity

Fix integers $1\le h\le m$. A register holds the correct bit $b$. Store one in work addresses $1,\ldots,m$, then read each address once. Count how many replies disagree with one and flip $b$ exactly if the count reaches $h$, after finishing the scan. The genuine run uses $2m$ work operations and $O(m)$ native instructions. The counter and loop indices reside in registers.

Say a work address is faulty if some reply there differs from the actual last written value along the proposed execution. The inclusion-minimal faulty-address sets that produce the wrong verdict are **all** $h$-element subsets of $[m]$. Every such fault can be implemented just by discarding the indicated writes. A set that guarantees the genuine verdict against arbitrary replies elsewhere must contain at least $m-h+1$ addresses, and this suffices. The same optimum holds for protection against all enlargements of a deterministic zero projection. In the two-player test with this program the optimum also equals $m-h+1$, since the challenger can choose the empty set.

The maximum number of disjoint minimal fault sets is $\lfloor m/h\rfloor$. The minimum fractional hitting-set weight is $m/h$. Giving each address weight $1/h$ attains it. Conversely, summing all constraints on the $h$-subsets counts each address the same $\binom{m-1}{h-1}$ times. With $h=\lceil m/2\rceil$, linear protection coexists with bounded fractional hitting and bounded disjoint packing. At $h>1$ every individual erased write preserves the genuine verdict. At a minimal erroneous execution all $h$ repairs are individually decisive, and a first incorrect reply can occur at any of the first $m-h+1$ chronological reads.

Both verdicts occur in a single globally correct DIMACS program realizing these exact figures on arbitrarily long files. Use the proper ternary rows on three variables forbidding all assignments, or all except $111$, followed by arbitrary spaces. A register-only parser recognizes each of these two fixed prefixes and checks the trailing spaces. It knows the verdict on a match and runs the array procedure with $m=\lfloor N/4\rfloor$ and $h=\lceil m/2\rceil$. On any other file it invokes an ordinary complete SAT solver. Thus the clock on these files is linear in encoded length, including the parser. A program that directly returns the parsed bit on the same family needs no work replies at all. The size of the protection certificate alone does not distinguish these two programs' asymptotic decision times on the family.

## Individually decisive repairs along a single false execution

For arbitrary adaptive control, take any inclusion-minimal set $B$ of faulty addresses achievable by a clocked false-verdict execution. Fix one such execution. Make its read replies deterministic by returning its recorded values at its erroneous (time, address) pairs and the correct last-written word everywhere else. Subdivide a clock tick into distinct ordered memory slots if necessary. This reproduces the false execution. For any $a\in B$, turn off just the overrides at $a$, leaving the same policy everywhere else, including after any divergence. Every faulty address in the resulting run lies in $B\setminus\{a\}$. Minimality forces the genuine verdict. Thus a single false chronology can witness $|B|$ different individually decisive address repairs. Its path before each respective first changed reply is exactly the original false path.

In a finite nonempty family of achievable minimal fault sets, let $\tau$ be the least integral hitting-set size, $\nu$ the maximal number of pairwise disjoint members and $r$ the largest member size. A maximal disjoint family covers every member by its union, giving $\tau\le\nu r$. Consequently $\tau>k$ forces either more than $\sqrt k$ disjoint erroneous supports (with distinct first-error addresses on the genuine run) or a false execution with more than $\sqrt k$ individually decisive repairs. The threshold program realizes the second alternative with no individually decisive address on the genuine run. This argument uses the minimal-block certificate bound familiar from Boolean decision trees.
