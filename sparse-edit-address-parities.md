# How far apart must two sparsely edited SAT witnesses be?

Let the [three-file RAM exhaustion](three-files-for-the-unrestricted-sat-clock.md) use its explicit UNSAT anchor of bit length $L$ for multiplier $C$ and a fixed exponent $d=1,2,3$. Add the fixed classifier modes below to the coefficient-four interpreter. They share its terminated parameter encoding and fallback. For every sufficiently large $C$, consider two longer $N$-bit files with opposite SAT verdicts at Hamming distance $k$. **If the anchor and these two files defeat every parameter, then $k$ is even and**
$$
             (k/2)\lceil\log_2 N\rceil > cL^2
$$
for an absolute $c>0$ for this template. The classifiers use a linear clock on the tested inputs with a multiplier bounded by $C$. The rejected pairs can have the same byte histogram, match all bounded rolling checksums, and depend on $C$. No SAT computation is needed to specify the modes. The particular parameter and its output orientation can depend on both files. This is an obstruction to using a sparse edit in a three-file exhaustion.

## Two changed bits at arbitrary offsets

Number bits by $8a+j$, starting with byte zero and the least significant bit $j=0$ within each byte. For parameter $t$, XOR the input bits whose address has binary digit $t$ equal to one. If the changed addresses are $p,q$, this output changes by $p_t\mathbin\oplus q_t$. For distinct addresses, the least $t$ that distinguishes them is $v_2(|p-q|)$. A fixed program implements a scan of $N$ bits with counters, shifts and an XOR. Decode the mode and its orientation, then take the remaining data up to the terminator as the ordinary binary integer $t$. This last integer needs no second length field. Guard the mode by rejecting any input exhibiting the eight fixed contradictory anchor clauses. The guard succeeds on the anchor and can only force a correct negative label on other inputs. Choose the orientation so the two unguarded outputs match their labels.

The host at the anchor sees $H(L)/2\ge2\log_2(L+2)$ two-bit symbols. A fixed tag, orientation and terminator cost a constant number of them. Thus all $0\le t<\lfloor cL^2\rfloor$ are available for some fixed $c>0$, with a uniform linear clock. Oversized shifts at shorter lengths can return zero when $t$ exceeds the number of digits of any address. As a consequence an opposite pair with two physical changes that survives the test must have
$$
                    p\equiv q\pmod {2^{\lfloor cL^2\rfloor}}.
$$
The required gap holds even if the whole file is much longer than this modulus. The [Lean proof](SparseEditAddressParities.lean) derives this congruence from the actual parity scans on any list with no repeated addresses containing both edits.

For the [canonical distance-two checksum construction](two-bit-switches-at-a-prescribed-stride.md), the bit-address gap is eight times the byte stride $D$. In the ordinary $B=48$ files the bit addresses are 3,896 and 641,456. Partitioning by address digit 3 gives parity 1 on the satisfiable file and 0 on the unsatisfiable file. For its all-base $B=32$ example the addresses are 3,840 and 447,360. Digit 7 gives 0 and 1. The two tests need neither physical offset in the stored program.

More generally for the ordinary optimal stride $D=E_B$, each odd prime power $p^e\le B$ contributes an order dividing $p^{e-1}(p-1)$ for base 2. Changing to base $256=2^8$ divides out up to three powers of two from that order. Their lcm satisfies $v_2(E_B)\le\max(0,\lfloor\log_2 B\rfloor-3)$. The all-base optimal stride $D=\Lambda_B$ likewise has $v_2(D)\le\lfloor\log_2 B\rfloor$, by bounding each prime-power unit-group exponent by its order. These bounds also control the test after arbitrary common byte padding before or after the edits. Multiplying a stride by a chosen power of two can postpone its first distinguishing digit.

## A single parameter for more changes

At length $N\ge2$ put $s=\lceil\log_2 N\rceil$. Index the elements of $K=\mathbb F_{2^s}$ by the binary coefficient vectors in a fixed polynomial basis. An address $a<N$ gives a distinct element $u(a)$. For an input $x$ take the moments
$$
             P_j(x)=\sum_{a:x_a=1}u(a)^j\quad\text{in }K,
$$
with $u^0=1$ including at address zero. If two files differ at $k$ sites, $P_0$ separates them whenever $k$ is odd. For even $k$, at least one odd $j$ in $1,3,\ldots,k-1$ separates them. Indeed the Vandermonde matrix with rows of degrees $0,\ldots,k-1$ and columns the distinct changed field elements is invertible. Some coordinate of its product with the all-ones vector is nonzero. The zeroth coordinate vanishes for even $k$ and $P_{2j}=P_j^2$, so any nonzero positive even-degree difference reduces to an odd-degree one. These are the classical binary error-correcting syndromes. [Bose and Ray-Chaudhuri](https://doi.org/10.1016/S0019-9958(60)90287-4)

A raw nonnegative parameter $z$ names the desired bit. Use $z=0$ for physical parity and $z=1+((j-1)/2)s+t$ for field coordinate $0\le t<s$ of an odd degree $j$. Thus the resulting program can be selected from the first $1+(k/2)s$ indices. The host recomputes $s$ from the public length so the parameter stores exactly one number after its fixed tag and orientation. The same guard handles the anchor. The deadline for these modes has enough slack even if $k$ grows with $C$.

Here are the native costs. At length $N$ the host can construct a deterministic irreducible binary polynomial of degree $s$ in $s^{O(1)}$ steps using Shoup's fixed-characteristic algorithm. Represent field elements in that polynomial basis. Set the chunk width to $b=\max(1,\lfloor s/8\rfloor)$. Tabulate all binary carryless products of two $b$-bit chunks. In a second table store the reduction of $vX^{ib}$ for every chunk $v$ and each position $i$ of a raw double-width product. Individual entries take polynomial time in $s$ by shifting, XOR and polynomial long division. There are $O(2^{2b})$ entries because the number of chunks per field element is bounded by an absolute constant. This setup and the field construction cost $O(N)$ in total. A product thereafter uses only a constant number of lookups, shifts and XORs. A coefficient-four host has room for the tables, indices and a fixed number of limbs for intermediate products. The power at a given address costs $O(1+\log(j+2))$ field multiplications by repeated squaring. Scan the physical bits to compute the selected moment in $O(N(1+\log(j+2)))$ native time with uniform constants. Long division of the single parameter by the public $s$ during initialization takes polynomial time in the host word length. A comparison with the available width can handle unsuitable parameters. [Shoup's deterministic construction](https://www.shoup.net/papers/detirred.pdf)

When $(k/2)s\le cL^2$, all indices used above fit inside a completed anchor prefix. Their degrees have $\log(j+2)=O(\log(L+2))$. The anchor construction has $L=O(\log(C+2)\log\log(C+4))$, so eventually the multiplier $C$ pays for even the linear-time clock at both longer inputs and on the guarded anchor. This proves the stated necessary inequality. The added modes are fixed once for all stages and preserve the [finite representative bound](anchored-interpreter-for-ram-exhaustion.md).

There is also a version for a short cluster of edits in an arbitrarily long file. Choose a power of two $s'$ with $1\le s'\le2\lceil\log_2 N\rceil$. Project each changed address to its low $s'$ bits. Let $h$ be the number of residues occurring an odd number of times in this projection. If $h>0$, the same proof separates the files with physical parity or an odd degree $j<h$ over $\mathbb F_{2^{s'}}$. Encode $j$ using $\log_2(j+2)+O(\log\log(j+4))$ self-delimited bits. Put $s'+t$ in the final field for coordinate $t<s'$. The leading one of this last field specifies $s'$ exactly. The total payload is at most $\log_2(s'(h+1))+O(\log\log(h+4)+1)$. Chunk tables for $s'$ still have $O(\sqrt{N+1})$ entries. Reject out-of-range requests for $s'$ before allocating the tables. The scan therefore meets the same bound on time. For example the residues of a cluster of diameter $D$ are distinct whenever $2^{s'}>D$, regardless of the absolute addresses of the edits.

## Information available to a finite census

For $m$ independently editable physical bits, all masks of weight at most $u$ lie within pairwise distance $2u$. Any vector of $R$ ternary replies distinguishing *every* such sparse pair must supply
$$
                    3^R\ \ge\ \sum_{i=0}^u\binom mi.
$$
The canonical SAT selector cubes give valid files for all these masks. This packing estimate applies even if some labels agree. Thus it constrains an attempt to distinguish all differences by a uniformly short feature vector. For $1\le u\le m/2$ it requires $\Omega(u\log(m/u))$ bits. The address moments need $1+u\lceil\log_2N\rceil$ binary tests. When $m=\Theta(N/\log N)$ and $u\le\sqrt{m}$ the bounds agree up to constants. For the actual SAT lower bound the target requires opposite labels in a collision. Packing alone leaves that condition open. An unrestricted RAM can compute the checks in this note within the stated clock.

The [finite audit](sparse_edit_address_audit.py) rebuilds the two actual witnesses, checks both SAT verdicts through their independent solver audit and computes the address parities from every byte of each file. It also checks all 65,808 nonempty difference supports over the four binary fields of orders 2, 4, 8 and 16, and 1,252 table-multiplication comparisons. The general field-moment and native time arguments are manuscript proofs. The Lean theorem covers the distance-two parity calculation on the whole input.
