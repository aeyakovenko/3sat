# When one short RAM-to-SAT presentation is enough

Let $U(y)$ be bounded nondeterministic RAM acceptance with a unary clock. Let $s=|y|$ in bits. A compiler takes $y$ and a pad $r$ of $s^{O(1)}$ bits. Its output is a proper ASCII DIMACS 3-CNF, its length fits $O(\log s)$ bits, and uniform deterministic length and individual output-bit indexers use $(\log(s+2))^{O(1)}$ time with random access to both inputs. A polynomially bounded pad length computable from $s$ in polylogarithmic time suffices. A presentation can also specify a permutation of a polynomial-sized domain through forward and inverse queries. The baseline presentation uses zero padding and the identity permutation.

**Positive-presentation theorem.** Suppose every presentation preserves $U(y)$. If each sufficiently large positive $y$ has at least one presentation with output length $o(s\log s)$ uniformly in $y$, deterministic linear time for ordinary SAT on the unrestricted logarithmic-word RAM is impossible. Negative files have no length requirement. The same result holds for $O(N\log^a N)$ solvers when the positive lengths are $O(s\log^\beta s)$ with $a,\beta\ge0$ and $a+\beta<1$. The existence of a compiler meeting these hypotheses remains open. ## A shortest presentation can have few edits

Fix a positive file and one short presentation. Run its deterministic length indexer. Copy just the pad words it inspects into an otherwise zero pad. Any queried input word crossing boundaries can be handled by preserving all underlying coordinates it intersects. For a forward permutation query record its argument and answer; for an inverse query record the forward pair in reverse order. The observed pairs form a partial bijection. Its directed components are cycles and paths; close each path to a cycle by mapping its end to its start, and fix the other elements. This moves at most twice the number of recorded pairs. Both index paths and the resulting length are preserved by induction on the transcript. Thus some short presentation is specified by polylogarithmically many bits even if the original permutation had factorially many possibilities. On a positive file the replacement formula is satisfiable by the preservation hypothesis. Lean verifies replay of a deterministic query tree on a sparsified pad and the existence of a permutation supported on the observed endpoints. [Core Lean proofs](SparseCompilerPresentation.lean)

The fixed verifier can nondeterministically guess lists of modifications to the pad and permutation. Check bounds, distinct keys and agreement of the finite permutation tables with each other, treating missing entries as fixed. The latter check can require that the moved lists have identical key and image sets and are mutual inverses there. These checks cost polylogarithmic time. On every guess they specify a genuine presentation. Local formula queries use this one presentation throughout the verification. A word query may be simulated by $O(\log s)$ individual bit queries if the pad representation is bit-addressed.

Here is why the controller does not need to find the good presentation. Start at the native square-time deterministic diagonal on an input of $n$ bits with clock $t=\Theta(n^2)$. At each step $y=(P,x',1^t)$ is virtually indexed from a physical payload of $u$ bits. For an actual length $M$, the compact verifier guesses $O(1+M/\log(2+M))$ assignment and indexing bits. A challenge can check a clause, a boundary scanner record or an inconsistent pair of names. It needs polylogarithmically many locally generated formula bits and constantly many probes to assignment bits or packed records. Its explicit SAT defect test has length and construction time $O((u+1)\log^b s+1+M/\log(2+M))$ for a fixed $b$. This uses the compact table encoding for the constantly many witness reads. The new polylogarithmic pad lists can be multiplexed separately inside the local calculations. Consult the hypothetical fast SAT solver on this defect test. An accepting branch certifies that the particular displayed formula is satisfiable. [Verifier, decimal names and physical costs](compact-compilers-and-linear-sat-time.md)

Feed the same program its predecessor descriptor and a new unary clock $\lfloor t/2\rfloor$. A branch exceeding this cap does not accept. Negative files stay negative on every branch. On positive files a short presentation and a valid witness give a branch taking
$$
       O\big((u+1)\log^{b'}s+(1+M/\log(2+M))\log^a s\big).
$$
For $t>n^{3/2}$ the payload is $n+O(\log^2 n)$ through $O(\log n)$ halvings. Thus $s=(1+o(1))t$ and the displayed bound is $o(t)$ under the hypotheses. The fixed verifier need not compute a little-$o$ modulus. Only its clock, the preceding program and the old payload are passed forward. At $t\le n^{3/2}$ the standard quasilinear native-to-SAT compiler and the alleged SAT algorithm finish in $o(n^2)$ time, contradicting the diagonal. In particular, assuming fast linear SAT, every such decision-preserving local compiler has infinitely many positive files on which **all** presentations have length at least $c s\log s$, for some $c>0$ depending on the compiler.

## How much positive pad density suffices?

For this section take ordinary independent uniform pad bits. Require that a negative $y$ have an unsatisfiable output for **every** pad. On a positive input only some pads need work. For a given $M$ and a complete short-verifier string $z$, let $G_{y,M,z}(r)$ mean that the length is $M$ and every challenge to $z$ passes. This includes any indexing data needed to belong to the proposed assignment, including scanner boundaries and hashes. Suppose each sufficiently large positive $y$ admits one admissibly short $M$ as above and one fixed $z$ with
$$
                  \Pr_r[G_{y,M,z}(r)]\ \ge\ 2^{-s^\delta}
                  \quad\text{for a fixed }0\le\delta<1 .
$$
The same native time exclusions follow.

With $y,M,z$ and a challenge fixed, its correctness depends on the pad through a deterministic adaptive tree of depth $\operatorname{polylog}s$ in *bit* queries. One clause forbids each rejecting path of the tree. All challenges and the length check therefore give one CNF on the pad with at most $m=2^{\operatorname{polylog}s}$ clauses. There are at most $2^{\operatorname{polylog}s}$ challenge indices. This CNF is used only as a mathematical test. By Tal's bound, $O(\log(2+m)\log((2+m)/\epsilon))$-wise independence fools this CNF to error $\epsilon$. Choose $\epsilon=2^{-s^\delta}/2$ and a fixed rational $\delta<\gamma<1$. For large $s$, $k=\lceil s^\gamma\rceil$ suffices. Hence some generated pad passes all tests for that same $z$. [Tal, §4.2, Theorem 22 and its consequence](https://drops.dagstuhl.de/storage/00lipics/lipics-vol079-ccc2017/LIPIcs.CCC.2017.15/LIPIcs.CCC.2017.15.pdf) · [Bazzi's earlier bounded-independence theorem](https://doi.org/10.1137/070691954)

To implement the pad, embed its indices into $\mathbb F_{2^j}$ for $j=O(\log s)$, choose a degree-$<k$ polynomial with uniform coefficients, and take one fixed binary coordinate of its value. Distinct evaluation points give uniform independent field values for any at most $k$ of them. The verifier guesses the $kj$ coefficient bits and a monic degree-$j$ polynomial for field arithmetic. An irreducible modulus exists for completeness. Every guessed monic modulus still defines a deterministic pad for soundness, even if reducible. Ceilings of fixed rational powers can be computed by integer arithmetic in polylogarithmic time. Horner evaluation costs $k\operatorname{polylog}s$ bit operations per desired bit. In the explicit challenge circuit, unroll each such evaluation as a straight-line circuit with the actual seed bits as constants. There are only polylogarithmically many such evaluations. The total size, including gate names, and uniform construction time added to the defect test are $k\operatorname{polylog}s=o(t)$; this still holds after multiplying by any fixed power of $\log s$ from the solver. The compact witness table continues to be read only constantly many times in a challenge. This implementation avoids a quadratic simulation in the seed length.

If favorable pads have some density $p$ but carry different witnesses, it suffices that their successful pairs $(M,z)$ can be covered by $K$ fixed choices and $\log_2(K/p)\le s^\delta$. One pair then works on density at least $p/K$. Without a bound on $K$, a density bound for the union alone does not imply this hypothesis. Pinning $v$ formula variables to $v$ independent pad bits gives total acceptance density one and density $2^{-v}$ per fixed assignment.

There is also a direct test against using a small independence order on that union. For $k\ge1$ let $L$ be the least power of two at least $k+1$ and choose $L$ evaluation indices forming the coordinate subspace of dimension $\log_2 L$ on the low index bits. The fixed output bit of every degree-$<k$ polynomial as above has even parity on those $L$ indices. Indeed the monomial $x^e$ factors as a product of $\operatorname{popcount}(e)$ Frobenius-linear maps. For $e<k\le L-1$, its Boolean degree on the subspace is strictly below the dimension, so its sum there is zero. The constant case also has zero sum. A formula pinning these $L$ data bits and imposing **odd** parity by a prefix XOR chain accepts half the pads and none of these generated pads. It has $O(k\log(2+k))$ encoded bits, a locally indexable fixed layout and uniquely determined auxiliaries for each accepted input. This example concerns the specified generator at this independence order.

## An unconditional price for public pad bits on parity

A fixed native program can test the parity of $n$ input bits in $O(n)$ time. Its bounded-acceptance input, with a sufficient unary clock and an ordinary packed payload, has length $\Theta(n)$. More generally let a verifier for even parity use an independently sampled public pad and at most $v$ witness bits. For fixed pad and witness it accepts when every deterministic challenge passes. Let each challenge read at most $D\ge1$ of the actual $n$ input bits adaptively, counting bits of any accessed word. Assume no odd input can pass. If $p(x)$ is the probability of some accepting witness at even $x$, then
$$
       \mathop{\mathbb E}_{x\ {\rm even}} p(x)
                 \ \le\ 2^{1+v-n/D}.
$$
Thus common success probability at least $p$ forces $v+\log_2(1/p)\ge n/D-1$. At most a $2^{1+v-n/D}/p$ fraction of even inputs can reach probability $p$. This concerns the actual source bits queried by a challenge, independent of its private workspace.

Fix one pad and one witness. Forbid every rejecting transcript of every challenge, obtaining a width-$D$ CNF on the input. Every accepted input is an isolated solution because every one-bit neighbor has odd parity. The satisfiability coding lemma bounds the number of such solutions by $2^{n-n/D}$. Union over $2^v$ witness strings (fixed-width padding), then average over the pad. The case of full success and $v$ auxiliary bits has an established equivalent CNF width bound. The public-pad inequality adds an averaging step to this known argument. [Paturi, Pudlák and Zane](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/PaturiPudlakZane_1999_cjtcs.pdf) · [Emdin, Kulikov, Mihajlin and Slezkin](https://doi.org/10.4230/LIPIcs.MFCS.2022.47) · [Related physical SAT proof tradeoff](parity-chain-verdict-checks.md)

The exponent is exact when $D$ divides $n$ and $0\le v\le n/D-1$. Partition the payload into $n/D$ blocks of $D$ bits. Supply running parities at all internal block boundaries using $v$ witness bits and $n/D-1-v$ independent uniform pad bits. Both endpoint parities are prescribed zero. Each challenge checks its block against its two supplied boundary bits. Every odd input fails. Every even input has unique correct boundaries and succeeds with exactly $2^{-(n/D-1-v)}$ pad probability.

## One short accepting pad always exists if arbitrary trace advice is allowed

There is an unconditional existential compiler on **all** native inputs of length $s$, with every output of length $O(s)$ and just three distinct DIMACS names. Run the standard fixed nondeterministic native verifier for $U$ with its $O(s)$ clock, including parsing; idle after halting to a fixed endpoint. Give the pad the chronological configuration registers, guesses and memory events, a second copy of the events in address/time order, and forward and inverse index maps between the two copies. Addresses, time tags and values use $O(\log s)$ bits, with constant many registers and memory slots per step. Use fixed dummy slots and order ties by slot number. The whole pad costs $O(s\log s)$ bits and can be padded to a simple polynomially bounded capacity.

At each time check the fixed ISA transition and consistency of the chronological event slots with the registers and opcode. Check the source input reads against the actual public bits. At each index check both directions of the permutation, equality of the paired records, and the sorted ordering including unique time/slot tags. Within each address group check the first value against the prescribed initial contents and successive read/write state across its consecutive records; equivalently attach the incoming and outgoing values to each event. Require the initial state and final accepting halt. These bounded-arity checks are local polylogarithmic computations, one constant number per time or event. Forcibly set three guards to zero using the seven proper clauses forbidding the other patterns. For each check print one fixed-width proper row. On failure print the disjunction of the three positive guards, and on success negate one guard in that row. Pad whitespace to equal lengths. This gives constant output bytes per check and polylogarithmic indexing time. A positive input has at least one satisfiable pad. Every pad on a negative input produces a contradiction. [Native trace sorting and verifier](native-linear-time-and-locally-uniform-circuit-depth.md) · [Local reductions for nondeterministic time](https://arxiv.org/abs/1311.3171)

The length test here is constant in the pad. Its sparse replay preserves that length and can destroy satisfiability. On the parity restriction the unconditional density bound shows why a short output with only three assignment bits cannot make its accepting pads common when each check reads few source coordinates. The conditional criteria above still need a compression valid on enough presentations, with a witness usable within the smaller native clock. No unrestricted SAT time bound is derived from the trace compiler.
