# A common hard distribution for SAT scans in arbitrary cyclic orders

Fix the input length $N$ in bits and byte-aligned word width $w=16\lceil D\log_2(N+2)/16\rceil$, for fixed $D\ge1$. A scan reads a public cycle of distinct word addresses repeatedly, starting at a public point. If read $i$ at $p_i$ returns $x_i$, the machine may skip its write or set $M[x_i]\gets p_{i+\delta_i}$ with $0\le\delta_i\le r$ for fixed $r$. Within these rules all choices, register operations, and halting can depend on the data. The controller has $O(w)$ bits of register and finite-control state. Its writable memory comprises all $2^w$ words. The order, the subset of addresses, and even the initial public register values may vary arbitrarily with length.

**Result.** For each sufficiently large byte-aligned $N$ one explicit distribution on satisfiable proper ASCII DIMACS 3-CNFs of length $N$ works for every such order. Any scan sound on all valid files accepts an exponentially small fraction of the distribution within $c N^{3/2}/(\log N)^{5/2}$ steps, for a sufficiently small constant $c>0$. The fraction is $2^{-\Omega(N/\log^2 N)}$. If $r=0$, the time threshold improves to $c N^2/(\log N)^4$. The constants can be chosen uniformly for a fixed $D,r$ and bound on the number of control bits per word. For a cycle covering every address the two thresholds improve to $c 2^w\sqrt{N}/(\log N)^{3/2}$ and $c 2^w N/(\log N)^3$, respectively. Soundness means the scan can never accept an unsatisfiable file. It may reject or run beyond the deadline on any yes file.

This gives a single hard formula even for a list of $2^{c' N/\log^2 N}$ sound choices, for sufficiently small $c'>0$. No program-size restriction is needed beyond the communicated state bound. A fully adaptive RAM can choose its next address from memory and write an arbitrary word. The proof below places restrictions on both operations.

## Encoding a sparse system of parity equations

Use a simple graph $G$ of fixed maximum degree $\Delta$ with $k$ vertices, $k$ even, such that every exactly balanced cut has a matching of size at least $\gamma k$ for an absolute $\gamma>0$. For example, take a Margulis–Gabber–Galil graph on $m^2$ vertices for even $m$, erase loops and merge parallel edges. The spectral gap gives $\Omega(k)$ edges across each bisecting cut counting multiplicity, and bounded multiplicity preserves that bound after simplification. Greedy matching loses a factor at most $2\Delta-1$. These graphs have no isolated vertices for the orders used here. Take $m$ to be the largest even integer below $\sqrt{N/(C_D(\log_2 N)^2)}$ for a sufficiently large constant $C_D$. [Gabber and Galil](https://doi.org/10.1016/0022-0000(81)90040-4) · [Verified spectral bound for this graph family](https://devel.isa-afp.org/thys/Expander_Graphs/Expander_Graphs_MGG.html)

There is one Boolean variable $X_v$ per vertex and one $Y_e$ per edge. For $e=uv$ four public clauses forbid the four odd triples of $(X_u,X_v,Y_e)$. All clauses have three distinct variables. A seven-clause public gadget on three more variables $a,b,z$ forbids every triple except $(0,0,0)$. For each vertex or edge variable $t$, include one clause $(\pm t\lor a\lor b)$. Its sign is the one private bit for that coordinate. Positive forces $t=1$ and negative forces $t=0$. Independently of how the signs are split among owners, every setting gives a well-formed formula. It is satisfiable precisely when all the pinned values obey $Y_{uv}=X_u\mathbin{\oplus}X_v$. Draw $X$ as $k$ independent fair bits and set $Y$ by those equations. Each resulting yes file becomes unsatisfiable on flipping any one vertex or edge sign.

Here are length and memory details. Use short identifiers 1, 2, 3 for $a,b,z$ and word-aligned decimal names for the graph variables. With $W=w/8$ and $K=\lceil\log_2(k+|E|+1)\rceil$, begin each graph name with the digit 1, then represent each of its $K$ index bits by $W-1$ ASCII zeros and that bit written as a decimal digit. Start its literal on a word boundary with $W-2$ spaces, the sign byte, and the initial 1. A positive sign byte is a space. Give short literals, clause terminators and boundaries their own aligned blocks as needed. The three short names differ from all graph names for large $N$. The header declares the all-ones name, the clause count, and suitable whitespace for alignment. The largest name has $O((\log N)^2)$ decimal digits. The grammar permits unused identifiers. The graph uses $O(k\log^2 N)$ bits. The alphabet of all its packed words is bounded independently of $N$ and the private signs. The long header name repeats one fixed block even at an unaligned phase. The decimal count, the ends of the header, and its transitions occupy only $O_D(1)$ further words. [DIMACS format, section 2.1](https://www.cs.ubc.ca/~babic/doc/dimacs_cnf.pdf) · [Word-aligned name layout](communication-bound-for-public-crossed-scans.md)

Reserve a fixed positive fraction of the file for copies of the nine-byte clause line `-3 1 2 0\n`, with a real newline. For example, take $\lfloor N/512\rfloor$ copies and include them in the header count. The public gadget makes all these clauses true. Changing a leading minus to a space in any single copy makes its clause false. Once $W\ge9$, each full word in the interior of this region contains such a sign. The repeated nine-byte pattern contributes at most nine distinct interior words. Pad to exactly $N$ bits with whitespace and end with a newline. The complete initial memory has $h=O_D(1)$ different word values, counting zero outside the file.

On any accepted yes file the scan must read the address of every sensitive sign word. Two files differing only in an unobserved initial word yield identical observations until that word is read, and a prior overwrite can erase its difference. Thus every cycle capable of acceptance visits all $k$ vertex sign words, all edge sign words, and $\Omega(N/w)$ distinct words in the repeated-clause region. In particular its period $L$ is at least $\Omega(N/w)$.

## The ownership cut and the cost of simulating writes

Fix any productive cycle. Give Alice the initial arc of the cycle ending at the $k/2$-th vertex sign word, and give Bob the remaining arc. Assign off-cycle words publicly to either party. The vertex bits have a balanced partition and there are at most two changes of memory owner per period. Each party can initialize its own words from its private signs and the public text. The ownership cut may depend on the schedule. The files and their probability distribution are the same across all cuts.

Write $P=\lceil t/L\rceil$ for a deadline of $t$ machine steps. The parties can simulate any run up to that deadline in $O_{D,r}((P+1)^2w)$ communicated bits, uniformly in the choice of cycle. When $r=0$ the bound is $O_D((P+1)w)$. Only polynomial deadlines are needed here, so communicating an elapsed-time counter costs $O(w)$ bits. The constants also account for the controller's state size.

For detail, extend the successor $S$ of the cycle by the identity elsewhere. Let $H$ be the actual initial image of memory. The last-writer argument gives, for every read pair $(p_i,x_i)$, either an endpoint in $U=\bigcup_{s=0}^{rP}S^s(H)$ or a signed orbit distance at most $rP$ between its endpoints. This proof only uses that two reads at the same cycle position are congruent modulo $L$. A last-writer link acts on pairs by $(a,b)\mapsto(b,S^\delta(a))$. Two links advance the two coordinates separately. If their time span is less than $L$, it equals the earlier offset modulo $L$ and is no larger than $r$. The second pair then has signed displacement of absolute value at most $r$. Each subsequent two-link group changes displacement by at most $r$. At most $P-1$ disjoint groups of span at least $L$ fit. With no short group, the original-value endpoint instead advances at most $rP$ steps through the ancestry. [Detailed derivation and Lean lemmas](communication-bound-for-public-crossed-scans.md)

One owner simulates a whole run of consecutive local reads and buffers only the last write to each foreign word. It passes those pairs and the controller state at handoff. There are $O(P+1)$ runs of one owner. A locally close pair with foreign write crosses one of two arc boundaries, so its destination is one of $O(rP+1)$ orbit words. A destination in $U$ costs at most one record per run. For any remaining pair the source belongs to $U$, and each source occurs at most $P$ times. Since $|U|\le(rP+1)h$, the claimed count follows. The parties need no oracle for $H$ or $U$. For $r=0$, the close pairs are self-writes and never foreign, while $U=H$ throughout.

## Why every accepting transcript fixes many independent bits

A deterministic binary communication transcript defines a rectangle in the private sign inputs. Pick a crossing matching of size at least $\gamma k$. For each matching edge $uv$, the word pinning $Y_{uv}$ belongs to one owner. The opposite owner has exactly one of the three private bits of that equation. If two yes inputs give the same accepting transcript, exchange the private inputs of the two owners. The result still has that transcript and must be satisfiable by soundness. The endpoint on the singleton side must have the same value on both original inputs, because the two bits from the other side determine it. The matching gives $\gamma k$ distinct fixed vertex bits. Under the common uniform distribution on $X$, any one accepting transcript therefore has mass at most $2^{-\gamma k}$.

A protocol of worst-case bit cost $b$ has at most $2^b$ leaves. Thus acceptance within the deadline has probability at most $2^{b-\gamma k}$. Taking $b\le\gamma k/2$ gives the advertised exponential bound. With fixed $r$ this allows $t$ up to a small constant times $L\sqrt{k/w}$, and with $r=0$ up to a small constant times $Lk/w$. Substituting $L=\Omega(N/w)$ and $k=\Theta_D(N/\log^2 N)$ gives the stated powers. A full cycle has $L=2^w$. These bounds also apply to length-dependent odd or even strides whenever they form the read cycle, without any bound on the integer representing the stride.

## A test of the induction over programs

For a menu of sound scans, summing the per-scan probability bounds gives one file missed by all of them at their deadlines. An extra $s$ bits selecting among sound scan programs cost a factor $2^s$ in this sum. The same proof covers a deterministic program whose accepting runs can follow one of the listed orders if consistency with the proposed order is checked during simulation and inconsistent runs reject. For an input-independent random choice among sound scans the acceptance probability on the joint experiment is bounded by averaging, with no charge for the number of choices. This last conclusion uses soundness for every choice.

The single-order predecessor used equalities between two contiguous groups. Pairing pins across the median handles one arbitrary order; a matching chosen for one cut can put every pair on the same side of another. Sparse parity equations on the expander give the common family. Exponential multi-partition lower bounds for linear codes, and expander-based read-once branching-program lower bounds, predate this construction. The application here combines those ideas with a bound on communication for actual indirect writes to a cyclic RAM scan. Priority for the combined statement has not been established. [Ďuriš et al., multi-partition communication](https://doi.org/10.1016/j.ic.2004.05.002) · [Glinskih and Itsykson, Tseitin functions](https://doi.org/10.4230/LIPIcs.MFCS.2017.26) · [Bova et al., expander CNFs](https://arxiv.org/abs/1411.1995)

For an unrestricted RAM, repeated adaptive reads can revisit a public hub between unrelated addresses. In the compulsory-write simulation four such reads already implement an arbitrary memory operation. This prevents the number of cyclic scan programs in the argument from serving as an upper bound for an arbitrary program of a given instruction count. The missing induction step would have to handle those traces, including their data values. [Four-probe simulation](adaptive-reads-and-compulsory-next-address-writes.md)

There is an ordinary RAM decider that solves this entire family, on both verdicts, in linear encoded time. Branch over the eight truth settings of the three most frequent variables, in order. At sufficiently large lengths these variables are $a,b,z$. They occur throughout the repeated nine-byte guard, while each graph variable has bounded degree and appears only a bounded number of times. Every setting except the specified one falsifies a public gadget clause. Under the surviving setting the pin clauses become units fixing every other variable. A single pass to gather these units and another to test the clauses decide the branch. For arbitrary input the same algorithm may encounter an unresolved branch; run an exhaustive decider there to make the whole program correct. On the displayed family all branches are decided by the scans. This argument survives permutations of the clauses and injective renaming of all variables.

For linear time even with long decimal names, intern normalized identifiers in a decimal trie. Give each node a first-child link, a next-sibling link, a digit and a word of bookkeeping; finding a child examines at most ten siblings. A constant number of scans processes each byte in constant time. The number of trie nodes is at most one plus the number of digit bytes, and a standard logarithmic-word workspace suffices. For a parse with unused names, the trie creates nodes only for identifiers actually present. On these families this gives a concrete reason the restricted result cannot witness a worst-case time bound for every ordinary RAM.
