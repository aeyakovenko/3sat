# A positive cylinder missed by every verifier whose soundness a fixed theory proves

Suppose ordinary SAT on the packed logarithmic-word RAM has a correct deterministic algorithm of time $O(N^k)$, for $k=2$ or $3$. Fix a sound arithmetic theory $F$ with a polynomial-time predicate for its binary derivations and enough elementary arithmetic to reason about fixed program encodings. There is a fixed opponent prefix $p$ such that **every sufficiently long extension of $p$** belongs to the positive side of the native diagonal $J_8$. On all of them, every nondeterministic native verifier of positive membership whose soundness has an $F$-proof needs at least

$$
 \Omega_C\!\left(n^{8/k}/L^3\right),\qquad L=\lceil\log_2(n+2)\rceil,
$$

steps on any accepting branch. A verifier may have no accepting branch. The prefix and common starting length for positivity can depend on $F,k$ and the assumed solver. Each fixed certified verifier $C$ has its own multiplicative constant and starting length for the time bound. The free suffix need carry no advice. In particular the bound holds on the all-zero suffix at every sufficiently large $n$. Here $n$ counts bits of the native input and $N$ counts bits of an ordinary SAT input. [Diagonal and strategy certificate criterion](strategy-dag-certificates.md)

## Building one proof checker

Write $J_8(x)=1$ exactly when the deterministic program in the self-delimiting prefix of $x$ rejects $x$ within $n^8$ guest instructions. The diagonal assigns zero on timeout. Use the journal's fixed-register RAM with $12L$-bit words. For a nondeterministic guest code $e$, let $\operatorname{Sound}(e)$ be the arithmetic sentence saying that every input with a finite accepting branch of $e$ has $J_8(x)=1$. It contains the literal code and a fixed universal machine predicate. Use canonical binary syntax for codes, proofs and numerals. In particular a binary numeral for $n$ has $O(L)$ symbols. [Native machine and instruction convention](native-unary-clock-band.md)

A single fixed nondeterministic RAM $U$ has two branches.

* Guess a program $e$ and an $F$-derivation of precisely $\operatorname{Sound}(e)$. Check syntax, the proof and its conclusion. Simulate one branch of $e(x)$ and accept only on a witnessed accepting halt.
* Parse the actual program prefix $r$ of $x$, and check that the rest consists of zeros. Construct the sentence $\sigma(r,n)$ expressing $J_8(r0^{n-|r|})=1$, where concatenation with that many zeros is defined by a fixed arithmetic relation. The syntax includes the actual bits of $r$ and the binary numeral for $n$. Guess and check an $F$-proof of this precise sentence. Accept only on successful verification.

Malformed lengths, instructions, proofs and conclusion mismatches never yield acceptance. Guess each string bit by bit with a word length field and validate the length against the available array range. Lengths fitting any honest short branch below are representable. A fixed polynomial-time tape proof check can be implemented using RAM tape cells. Both branches are globally sound by the truth of the theorems of $F$.

In the first branch each **fixed** code and soundness proof costs a constant to guess, parse and check, apart from length-dependent workspace setup in $O(n+\operatorname{poly}(L))$ time. The simulated guest also uses $12L$-bit words and reads the actual immutable input. Fetch instructions from the validated code and use a fixed-depth radix trie for sparse guest addresses. A digit of $\max(1,\lfloor(\log_2 n)/4\rfloor)$ bits makes the depth bounded by an absolute constant. A fresh row has initially zero direct-address slots indexed by its row number and a digit. Allocate rows only on stores and reject on row-counter overflow at $n^5$ rows. Give the guessed text, proof checker and guest trie disjoint numeric banks with bounds-checked access. The row number concatenated with a digit fits well below the $12L$-bit address bound. At most a constant number of rows is allocated per guest step. The cutoff therefore preserves fixed-verifier simulations of $O(n^4/L^3)$ steps. A run of $t$ such steps costs $O_C(n+\operatorname{poly}(L)+t)$. The external checker clock also limits branches that never finish guessing a proof.

## A cutoff with three logarithms

Let $h$ be a fixed positive integer. Choose the cap $s=s_h(n)$ as a power of two with exponent

$$
 \max\bigl(0,\lfloor 8\lfloor\log_2 n\rfloor/k\rfloor-3\lceil\log_2 L\rceil-h\bigr).
$$

For all sufficiently large $n$, this is within absolute constant factors of $2^{-h}n^{8/k}/L^3$, and $n+\operatorname{poly}(L)=o(s)$. Let $\Phi_h(x)$ be the ordinary 3-CNF for an accepting $U(x)$ branch in at most $s$ steps. The fixed packed compiler uses $O((n+s)L^3)$ bits. Pad its fixed ranges with tautological records to size $\Theta((n+s)L^3)$ with local random access. In the native bounded-acceptance query, $x$ and the virtual unary clock have fixed program fields and length delimiters. Each requested packed input word takes constant time to generate. The compiled formula's packed words take constant time after polynomial-in-$L$ setup. [Compiler, routing and packed reads](packed-band-transfer.md)

Define the deterministic opponent $D_h(x)$ to return the assumed SAT solver's answer on $\Phi_h(x)$. As $N$ is polynomial in $n$, a solver word occupies a constant number of host words, with sparse addressing and fixed-limb arithmetic as in the native simulation. Through $n^8$ steps, the row number and a radix digit still fit in the host width. Including simulation costs, the running time for all sufficiently large $n$ is bounded by

$$
 O(n+\operatorname{poly}(L))+K\bigl((n+s)L^3\bigr)^k.
$$

The leading constant $K$ can be chosen independently of $h$. One driver computes $s_h$ by shifting with the integer $h$, and runs the same checking program, compiler and solver. Embedding a fixed $h$ can add a fixed initialization cost. Choose $h$ large enough that the last display is less than $n^8$ eventually. This calculation may first be made for the simulation truncated at $n^8$ steps. The estimate guarantees that the truncation then never cuts off a solver execution. The diagonal counts $D_h$'s guest instructions. Its interpreting overhead is outside that count. [Sparse word simulation and division](native-unary-clock-band.md) · [High-clock diagonal implementation](strategy-dag-certificates.md)

Take $p$ to be the code prefix for this $D_h$. On every sufficiently long extension, $D_h=1$ is equivalent to timely acceptance by $U$. Such acceptance implies $J_8=1$. Meanwhile $D_h$ is timely, so $J_8=1-D_h$ there. Thus $D_h=0$, $J_8=1$, and no $U$-branch accepts by $s$, for every such extension. A fixed $F$-certified verifier with a branch of length at most $c_Cs$ would fit in $U$'s clock for a sufficiently small positive $c_C$ and all large $n$. This gives the claimed bound on every accepting branch.

## Individual proofs and ordinary UNSAT formulas

On $x=p0^{n-|p|}$, the sentence $\sigma(p,n)$ is true, has $O_p(L)$ symbols and can be constructed from binary $n$ in $\operatorname{poly}_p(L)$ time. For each proof of bit length $u$, suppose the cost to guess and check it in branch two is $O_p(n+(u+L+1)^v L^a)$ for $u\le n^5$, with $v\ge1$ and $a\ge0$ fixed. Restrict the estimate to proofs that fit the honest verification space when necessary. A standard bit-tape polynomial proof predicate guessed and verified in the indicated total steps admits such a bound for the proof sizes relevant here, since a computation taking at most $s$ steps uses at most that many tape positions. Then every $F$-proof of $\sigma(p,n)$, for every sufficiently large $n$, has length

$$
  \Omega\!\left(n^{8/(kv)} / L^{(3+a)/v}\right).
$$

Indeed a proof below a sufficiently small constant times the displayed scale would yield verification within $s_h$. This is conditional on the SAT clock and concerns a particular sequence of finite native computation claims. Lower bounds for short arithmetical sentences and the finite Gödel sentences asserting their own proof-length bounds have classical antecedents. [Pudlák, §3.1](https://arxiv.org/pdf/1601.01487)

The actual queries $\Phi_h(x)$ on the hard cylinder are all unsatisfiable. There is also a verification lower bound on these explicit formulas when $F$ proves the following implication for some fixed $n_0$. On extensions of $p$ of length at least $n_0$, unsatisfiability of $\Phi_h(x)$ implies $J_8(x)=1$. To ensure this premise in the conditional construction, start with arithmetic containing the true statements of correctness and a fixed clock bound for the assumed SAT solver, together with the elementary uniform resource and semantic lemmas for the compiler and interpreter. These lemmas can be stated for arbitrary program codes before choosing $F$ and constructing $U$. Specializing them to this driver proves the implication. The solver answers zero on an unsatisfiable query and the driver halts within $n^8$. This reasoning can be formalized without a truth assertion about proofs in $F$.

Let $P$ be a nondeterministic native verifier whose soundness for UNSAT on explicitly encoded formulas is provable in that $F$. A guest $C_P$ checks the prefix and threshold, then simulates $P$ on the local packed view of $\Phi_h(x)$, accepting on an accepting branch. The implication above and $P$'s soundness prove $\operatorname{Sound}(C_P)$ in $F$, using the verified virtual-view simulation. Use the fixed-number-of-limbs simulation for the width of a formula word and cap the number of allocated radix rows as above. On any fast branch the simulation takes $O_P(n+\operatorname{poly}(L)+t)$ for $t$ verifier steps. All sufficiently long extensions thus give explicit unsatisfiable formulas on which every accepting branch of $P$ takes $\Omega_P(s)=\Omega_P(N/\log^3 N)$ steps. The lower bound also applies when $P$ accepts every UNSAT instance. It is below the time to read all packed input words. Its content is the simultaneous choice of a succinctly described family, including one query for each large source length on the zero suffix. Each certified checker has its own threshold.

## Short proofs that there is any later positive instance

There is a stronger choice of opponent. For a valid program prefix $r$ and $m\ge |r|$ let $E(r,m)$ be the arithmetic sentence asserting existence of one extension $z$ of $r$ with $|z|\ge m$ and $J_8(z)=1$. The witness length has **no upper bound**. In addition to all the preceding lower bounds, one can arrange that at every sufficiently large $m$, even an $F$-proof of $E(p,m)$ takes $\Omega(m^{8/k}/\log^3 m)$ steps to guess and check by a fixed ordinary bit-tape proof checker. This limits the use of a proof that leaves the favorable later length and all its padding unspecified.

Use a fixed tape program $V_F$ which takes $(r,m)$ in canonical binary encoding, constructs $E(r,m)$, guesses a finite binary proof and accepts if the proof derives that exact sentence. Put $b_h(m)=s_h(m)$ with the dyadic scale above. Change the SAT query of the driver to the disjunction of two bounded native acceptance predicates.

1. The original $U(x)$ accepts by $s_h(n)$.
2. For the actual parsed prefix $r$ of $x$, some $m$ with $|r|\le m\le n$ makes $V_F(r,m)$ accept by $b_h(m)$ tape steps.

For the second test guess $m$ in binary, check its range, and use separate RAM tape banks for the fixed tape program. The cutoff counts that program's actual steps from its standard initial configuration and depends only on $m$. Prepare its input in $O(n+\operatorname{poly}(L))$ time. Either test costs at most a fixed constant times $n+\operatorname{poly}(L)+\max_{j\le n} b_h(j)$ native steps. The maximum is $O(1+2^{-h} n^{8/k}/L^3)$ with constant independent of $h$, by comparison with the eventually increasing real function $u^{8/k}/(\log_2(u+2))^3$. A computable upper cap covering **all** the inner steps can alternatively use a scan over $j\le n$ to take the exact maximum, with $O(n\operatorname{poly}(L))$ setup, still $o(b_h(n))$ for each fixed $h$. A single fixed compiler for the disjunction includes this setup in its clock. Its formula size and solver time satisfy the preceding estimates after adjusting constants and choosing $h$ sufficiently large. One can provide $h$ as a fixed binary parameter to a common verifier so that its running coefficient and local templates are uniform in $h$. On a small input or a simulation capacity failure the driver may default to one. Use this default wherever the full specified query cannot be implemented. For all sufficiently large inputs the ordinary query is implemented exactly and the driver halts by $n^8$. On any input, an enabled second test precludes a rejecting answer, including when the external diagonal clock expires.

Let $p$ now denote the code of the new driver. Suppose the second test had an eligible accepting computation on $(p,m)$. By soundness of $F$ there is a witness $z$ to $E(p,m)$. On this $z$, the same $m$ and the same tape computation enable the second test. The driver can only answer one or time out in the external clock, so $J_8(z)=0$. This contradicts the witness property. Consequently **no such computation exists** for any $m\ge |p|$. An eventual-size estimate alone would leave a loophole at a short witness $z$. The conservative default and proof test that persists to every length at least $m$ remove it. Other prefixes may pass the second test. On the driver's own prefix only the globally sound first test survives, proving positivity of the full cylinder and all the lower bounds above for the new choice of $p$ and query.

Under the same proof-checking cost hypothesis as for $\sigma(p,m)$, the proof length lower bound for $E(p,m)$ is $\Omega(m^{8/(kv)}/\log^{(3+a)/v}m)$. Constructing its sentence on the fixed prefix takes only a polynomial in $\log m$, which fits this exponent comparison. Every sufficiently large $E(p,m)$ is actually true. When $F$ supports instantiation of a fixed universal derivation at a binary numeral at polynomial-in-$\log m$ checking cost, $F$ cannot even prove that there are arbitrarily long positive extensions of $p$. Such a derivation would give cheap proofs of all $E(p,m)$. For the formula version suppose $F$ proves the stated implication from the driver's query being unsatisfiable on a sufficiently long extension to that extension having $J_8=1$. It follows that $F$ cannot prove infinitely many such queries along the cylinder are unsatisfiable, although every sufficiently long extension in fact supplies one. The earlier verifier hardcoding the entire cylinder shows exactly why semantic soundness of all specialized verifiers cannot replace provable soundness in these statements.

## An unconditional tape bound on the same test

Fix a maximum $K$ on the number of work tapes of candidate verifiers, a fixed finite tape alphabet and constant branching. Give them two read-only sequential tapes, one holding $x$ and one its binary length $n$. Both heads start at the left. There is a prefix $p$ with every sufficiently long extension positive, for which every $F$-certified sound verifier of this kind needs $\Omega_C(\log n\sqrt{\log\log n})$ steps per accepting branch throughout that cylinder. For this choice of $p$, the same bound with parameter $m$ holds for $V_F(p,m)$ on the weak tail-existence statements $E(p,m)$. This uses the deterministic simulation of nondeterministic **tapes** and needs no hypothetical polynomial-time SAT algorithm. [Strassle and Subercaseaux, Theorem 1](https://arxiv.org/abs/2611.11832)

For the first test a fixed machine guesses and checks a guest code and its soundness proof, then simulates the guest on a separate work tape for each of its at most $K$ tapes. Its two input heads wait during proof checking. A fixed guest transition table can be scanned in $O_C(1)$ time per step. Take a dyadically rounded cap $t(n)=\Theta(\delta L\sqrt{\log_2(L+2)})$ with small fixed $\delta$. Supply the first $t+1$ cells of each sequential input, preserving any reachable endmarker. A fixed linear-time nondeterministic machine copies those prefixes from an $O(t)$-length padded input and simulates the checker using a unary fuel tape. The cited theorem decides this bounded test in $2^{O(t/\sqrt{\log(t+2)})}$ deterministic steps.

For the second test try every $|r|\le m\le n$ by the same method on $V_F(r,m)$ with cap $t(m)$. If $|r|>L$, return one. Every fixed prefix eventually fits. With $\delta$ small, the $n+1$ tests, input preparation and native simulation of the deterministic tapes together fit $n^8$ steps eventually. Default to one on short lengths or capacity overflow. An enabled tail test again precludes a rejecting output on every eligible extension. The tail witness argument and the pointwise diagonal now give the claims. Native RAM verifiers may use indirect addressing and full-word guesses.

## Testing finite reflection

The fixed checker that accepts every extension of $p$ beyond a sufficiently large threshold and rejects elsewhere is globally sound. Its accepting branch takes $O_p(n)$ steps or less. Its soundness therefore has no proof in $F$. If $F$ verifies this elementary prefix test, $F$ cannot prove the universal positivity assertion for any particular sufficiently large threshold either. A proof merely asserting the existence of an unspecified threshold need not give a proof for a specific one in a classical theory.

To obtain a SAT time contradiction by finite reflection, it would suffice to supply $F$-proofs of the particular $\sigma(p,n)$ guessable and checkable in at most $s_h(n)$ native steps for infinitely many $n$. The classical polynomial bounds on finite consistency apply to sentences excluding contradiction derivations and depend on the theory and proof calculus. Even the linear upper bound for the C-rule in finitely axiomatized sequential theories concerns consistency at a specified proof-length cutoff. Using it here requires a derivation that covers the soundness assertions used on a proposed $U$-branch, relates them to this particular rejecting computation, and fits the cutoff including proof verification. In the bit-by-bit proof branch the external clock allows inspecting proofs of up to $s_h$ bits. An $O(s_h)$ length estimate for a proof of a different assertion gives neither a verification bound within this same $s_h$-step clock nor a derivation of $\sigma(p,n)$. No suitable finite-reflection upper bound was found. Historical priority for the cylinder and implementation-specific bounds is unverified.
