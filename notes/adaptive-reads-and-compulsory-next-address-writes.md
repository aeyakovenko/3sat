# A coupled read and write can simulate a full RAM

The public-scan lower bound uses two hypotheses. The read addresses advance by a fixed increment, and the only permitted write targets the address named by the word just read. Dropping the first hypothesis has an exact consequence. Allow the controller to choose the next read address. Even if **every read must write, and its payload must be exactly the next read address**, the resulting machine simulates a general word RAM on ordinary ASCII DIMACS with constant overhead per guest instruction and a single initial copy of the file. All but two of every four simulation reads use the same two public addresses in fixed positions. [The public-scan lower bound](communication-bound-for-public-crossed-scans.md)

## The four reads

At head $p$ the sole memory primitive observes $s=M[p]$, selects $q$, performs $M[s]\gets q$, and moves the head to $q$. The controller has a fixed finite number of registers, ordinary word ALU operations, and conditional control. Charge all its arithmetic and branches. In the construction $q$ may even be selected before observing $s$ in the current primitive.

Simulate a guest with $w$-bit words on a host with $W=2w$ bits. Use byte-aligned logarithmic widths, $2^w\ge N$, where $N$ is the input bit length. This change of width is permitted in a RAM family closed under doubling. Write $Q=2^W$ and choose the disjoint high tags
$$A(a)=Q/2+a,\qquad V(v)=Q/2+2^w+v,\qquad Y=Q-1,\qquad H=Q-2.$$
Here $a,v$ range over the $w$-bit guest words. Maintain $M[Y]=H$. A guest cell $a$ has either $M[A(a)]=V(v_{old})$ or the initial $M[A(a)]=0$ representing zero. For every $v$, $M[V(v)]\in\{0,H\}$. The head starts each simulated access at $Y$.

| Current head | Observed value | Next head, also written at the observed address |
|---|---|---|
| $Y$ | $H$ | $A(a)$ |
| $A(a)$ | $s=0$ or $V(v_{old})$ | $H$ |
| $H$ | $A(a)$ | $V(v_{new})$ |
| $V(v_{new})$ | $0$ or $H$ | $Y$ |

Row two leaves the temporary pointer at $H$ intact because $s\ne H$. Row three therefore writes the new tagged value to the intended guest address. Row four can affect only physical zero or $H$, both disposable at the end of an access. A guest LOAD takes $v_{new}=v_{old}$, decoding an untouched zero as guest zero. A guest STORE uses its supplied value. Aliasing, repeated writes and overwrites of guest input all obey the guest semantics. The public heads $Y,H$ separate every pair of private heads. Repeating a visit at $Y$ before leaving it also allows arbitrarily many fixed idle probes per access. ## Starting in ordinary input memory

Initially only the packed input is present in memory and all other words are zero. A full little-endian host word of comment-free ASCII DIMACS is below $Q/2$, and at least $9Q/256$, since its highest byte is a nonzero ASCII character of code at least nine. For large $N$ these values exceed every physical input address. A zero-padded last word is still below $Q/2$ but its numeric value can name a physical input cell. The following initialization accommodates that case. It makes no initial free write.

Start the head at zero. Save the first original word while moving to address 1. Read its original word $h$ there and move to $Y$. If at least two full words are present, both original values are in the safe range just described. The five visits with head sequence $0,1,Y,h,H,Y$ write successively at the first original value, $h$, zero, $Y$ and zero. In particular $Y$ now contains $H$. This holds when the first two original words are equal. The tagged address and value arrays still contain zeros.

Copy the host input words in order. Use the saved word zero for the first. To read another original word $j$, take $Y\to j\to Y$. This changes $M[H]$ and then the cell named by that original word. For a full input word the latter lies outside the input and below the high tags. The four-step guest access stores each of the two $w$-bit halves at guest addresses $2j$ and $2j+1$; skip any half outside the guest address range. Only physical cell zero among the low input positions can be affected by this four-step access, and its contents were saved. Process the final partial word last. Its compulsory indirect write can overwrite an earlier physical input word after that word has already been copied. All words outside the copied guest input remain encoded as zero. The copy costs $O(1+N/w)$ operations, with $O(\log N)$ additional setup if the host must compute its own width. For inputs shorter than two full host words, the first two reads recover the whole input in registers: a nonempty printable first word never names address 1. These exceptional lengths are bounded for each fixed width convention and can use a finite register-only decision table.

The fixed host program simulates the guest program's finite control directly, stores its fixed register file in host registers, and masks guest numerical results to $w$ bits. From the end of initialization the only physical memory accesses are the four rows of the table for each guest LOAD or STORE. If a guest runs in time $T(N)$, the coupled host takes $O_P(T(N)+N/w+\log N)$ time. Conversely an ordinary RAM can implement the primitive by one ordinary LOAD, one STORE, and head-register bookkeeping. This gives an equivalence for the linear, quadratic and cubic *exclusions* across this width family and input syntax. The construction gives no numerical six-slot upper bound on the host code. For an arbitrary binary problem one can instead give the coupled host the input written in ASCII `0` and `1`. The host strips this fixed byte encoding and packs the guest input in $O(N)$ time by the same initialization procedure, using $N$ for the number of represented bits and supplying the appropriate guest metadata. For example, use $w=16\lceil\log_2(N+2)/16\rceil$ for the guest and $2w$ at host length $8N$; this is still a logarithmic width rule. An ordinary RAM can materialize the framed input and emulate its coupled solver in linear preprocessing time with a sufficiently wide host. This observation concerns a specified linear-time reencoding of the binary problem.

The same primitive with **current** address as payload, $M[M[p]]\gets p$, has a different invariant even for adaptive $p$. Outside the image of initial memory, cells keep their original values. If an image cell $h$ points outside to $b$, the original value at $b$ is $h$, so the next reverse write there only restores it. The five-slot proof already uses this invariant for one allocation. For the next-address primitive the four-step construction can modify arbitrary guest data. Therefore an extension of the public-scan theorem to *all adaptive heads* at lookahead one would settle the unrestricted SAT milestone in this model. Public anchors at every second probe, compulsory writes, and a single allowed payload do not supply the missing argument. [Current-address invariant](five-instruction-loops-on-dimacs-sat.md)
