# A word-operation lower bound for proper 3-SAT after free binary-affine preprocessing

There is a family of ordinary ASCII DIMACS formulas, each with three distinct variables per clause, with the following property. Fix a deterministic SAT decider, a file of either verdict in the family, and its actual run on that file. Even if all the input bits and arbitrary binary-affine transformations of them are available for free, the run requires
\[
                         \Omega(N/w)
\]
word instructions involving nonlinear data processing, data-dependent control, or data-dependent addressing. Here \(N\) is the actual number of file bits and \(w=\Theta(\log N)\) is the RAM word length. Loads and stores at already determined addresses may be free. The lower bound holds individually on every file in the family, even if the algorithm is required to decide only this promise. Arbitrary explicit SAT has a uniform linear-time and linear-length reduction to the family. The exponent milestones for unrestricted RAM time all remain open.

The earlier packed inner-product construction already charged quadratic tests on an efficiently decidable family. The construction here retains a linear-length reduction from arbitrary SAT as well as a per-input charge. [Earlier quadratic test bound](quadratic-explanations-of-packed-sat-runs.md)

The proof packs independent control bits into *decimal digits of variable names*. Once the original formula is fixed, every physical input bit is constant, a control bit or its complement. Every affine set consistent with a correct decision on the controls has codimension on the order of the entire **bit length**. This is what charges operations after the input has already been made available. ## An explicit family with linearly many independent input bits

Normalize a source formula to a proper ternary payload \(F\) on dense variable names. The existing explicit-encoding conversion uses \(O(n/\log(n+2)+1)\) records and \(O(n)\) encoded bits and native time for a source of \(n\) bits. The short-name and duplicate-clause cases matter to this accounting. Choose \(t=\Theta(n/\log(n+2)+1)\), at least as large as the number of payload clauses and occurring variables up to a constant. Let \(b=\lfloor\log_{10}t\rfloor\) for large \(t\). There are \(t\) independently chosen records, each with \(b\) bits, giving \(m=tb\) switches. [Linear-bit conversion for unrestricted CNF](exact-network-ceiling-for-ordinary-sat.md)

For each residue \(j\in\{0,1,2\}\) reserve a distinct leading decimal tag. Append exactly \(b\) decimal digit positions after the tag. On the permitted records each digit is zero or one. Force the variable named by this tag and suffix to be true exactly when the number of ones in the suffix is \(j\bmod 3\). These truth-table clauses, including any entries for unused names, are independent of **all record choices**. Even a full table with every decimal suffix uses \(O(10^b)=O(t)\) entries per tag. Other variable names come from disjoint ranges. A reference for a record uses the tag followed by the actual \(b\) digits of that record. The only changing bytes are ASCII zeros and ones in fixed positions.

A three-state accumulator starts at zero and adds each record's table value modulo three. Constantly many proper clauses per record suffice. For example, if the preceding residue is \(a\) and the recorded residue is \(b'\), two negated one-hot flags imply the new flag for \(a+b'\). Require exactly one state per position. For the final residue \(S\) impose
\[
                        S=1\quad\lor\quad(S=0\land F).
\]
One can forbid state two and guard every clause of \(F\) by the condition that the final state differs from zero. Split each resulting four-literal clause with a private variable. Short clauses can be padded using three distinct auxiliary variables forced false by the seven clauses excluding each other truth triple. No source assignment is needed when \(S=1\). All-zero record choices give exactly the source decision. For each fixed \(F\), over all \(2^m\) physical files the decision is a nonconstant Boolean function of \(\operatorname{wt}(x)\bmod 3\), including when \(F\) is identically false or identically true.

The table and accumulator together have \(O(t)\) records. Each variable name fits \(O(\log t)\) digits, and constantly many references for each control word have \(b+1\) digits. Hence the actual output bit length satisfies \(N=\Theta(t\log t)\), and \(m=\Theta(N)\). A native RAM can precompute the decimal names and table values in \(O(t\log t)\) steps, then render the file in another \(O(N)\) steps. Fixing \(F,t,b\) fixes its length, header and field positions. Each of the \(m\) switches occurs in a literal name, and the two allowed ASCII bytes differ in exactly one bit. The map from the switch cube to physical strings is injective and affine over \(\mathbb F_2\).

## Largest binary affine spaces missing a Hamming-weight residue modulo three

For \(m\ge3\), the largest dimension of a binary affine subspace in \(\{0,1\}^m\) whose Hamming weights omit at least one residue modulo three is exactly
\[
                         \lfloor m/2\rfloor+1.
\]
At dimensions \(m=0,1,2\) the exact maxima are \(0,1,1\).

Write the flat as \(a+V\). For each coordinate \(i\) consider the linear functional \(v\mapsto v_i\) on \(V\). Suppose these functionals differ at \(i,j\), and \(e_i+e_j\notin V\). Intersect the flat with \(x_i+x_j=1\) over \(\mathbb F_2\). This always cuts its dimension by exactly one. Delete coordinates \(i,j\) from the intersection. The only possible nonzero kernel vector of this projection on the slice's direction space would be \(e_i+e_j\), which was excluded. Every weight decreases by exactly one, so the new flat still omits a residue. Induction on \(m-2\) proves the upper bound in this case.

Otherwise, partition coordinates by equality of their functionals on \(V\). If there is only one class, \(\dim V\le1\). With at least two classes, all cross-class vectors \(e_i+e_j\) lie in \(V\). Their graph is connected. Summing along paths gives every pair vector, hence \(V\) contains the entire even-parity subspace. For \(m\ge5\), both the even and the odd coset realize all three residues, at weights \(0,2,4\) or \(1,3,5\). This contradicts the omission. For \(m=3,4\) the stated upper bound excludes only the entire cube, which contains all residues. The smaller base cases follow directly. For even \(m\ge4\) take the odd-parity flat on four coordinates and use complementary pairs \((u,1-u)\) on the others. The core has weights one or three and the other pairs add a constant. For odd \(m\) use a free singleton with complementary pairs. These examples attain the bound. The census enumerates all affine subspaces through eight coordinates, including 7,866,259 distinct flats in dimension eight. [Exhaustive affine-space audit](../audits/affine_weight_flat_audit.py)

Its proof uses the fact that affine sets are closed under ternary symmetric difference. The stronger cardinality statement in the same file applies directly to any such closed family. This is a statement about the **largest single monochromatic certificate** over all three choices of the omitted residue. Exact worst-case parity decision-tree depth for MOD3 was studied by Chistopolskaya and Podolskii. The minimum over inputs of parity certificate complexity and lower bounds on the full depth are different parameters. For any odd modulus \(q\ge3\), the same proof gives the exact maximum \(\lfloor m/2\rfloor+q-2\) for \(m\ge2q-3\). The two initial lengths \(2q-3,2q-2\) have maximum \(m-1\), attained by the odd-parity hyperplane. Starting at \(2q-1\), each parity class contains all \(q\) residues because two is invertible modulo \(q\). Deleting a complementary pair still shifts all weights by one. Adding complementary pairs to the two base examples proves equality at the larger lengths.

## Charging the actual instruction sequence

Fix the payload, layout, and one run. Work on its \(m\)-bit control cube. Initially every input bit and every constant in the initial memory is affine. Between charged instructions allow arbitrary affine maps of any available input and memory bits over \(\mathbb F_2\), without charging their fan-in, number, or storage. The choice of map or fixed address at this point may use the previously determined transcript. Along a fixed history it is part of the program. This includes known-address loads, copies, XORs, and fixed bit permutations.

At a nonlinear operation, freeze the values of its bounded number of word operands to those on the chosen run. This adds at most \(Cw\) linear equations on the controls for a model-dependent constant \(C\). Its return value is now fixed. At a computed-address load or store it suffices to freeze the address to select the same memory cell. The current contents or a newly written value can remain symbolic affine words. Freeze any data controlling an instruction choice, jump, or variable-length loop when that control is used. A standard bounded-arity word RAM fits this simulation, including multiplication, comparisons and bitwise operations. A primitive that both reads and processes a word can be split into a constant number of these actions. The constants are independent of input length and program run. Unrestricted writable workspace adds no equations. Only the finitely many cells encountered on this fixed path need symbolic contents.

After \(s\) such instructions there is an affine set through the actual input of codimension at most \(Cws\) following the simulated path. At a normal YES/NO halt the output is fixed, or one additional binary-affine condition fixes a returned affine decision bit. If a convention interprets a whole word by a zero test, include that test as a charged operation. Correctness makes the resulting flat monochromatic. It must omit a residue of the Hamming weight because both values of the verdict occur among the three residues. Thus on this **individual** run
\[
                 Cws+1\ \ge\ \lceil m/2\rceil-1.
\]
Equivalently, one must condition on linearly many operand or address bits in this simulation. The conclusion holds even when the solver is given the **correct answer to the payload** in advance for the fixed cube. It applies to programs with input-independent tables as well. Accessing such a table at a data-dependent address is charged.

## Bounded error on each residue distribution

There is also a distributional version for algorithms with error at most a fixed \(\epsilon<1/2\) on every promised input. For each fixed payload and each of the three residues, on a uniformly chosen control of that residue the expected number of charged instructions, averaging over the algorithm's coins, is \(\Omega_\epsilon(N/w)\).

Let \(\zeta\) be a primitive complex cube root of unity. Every normalized binary Walsh coefficient of \(x\mapsto\zeta^{\operatorname{wt}(x)}\) has modulus at most \((\sqrt3/2)^m\), by multiplying the single-coordinate factors \((1\pm\zeta)/2\). The mean of this function on a flat of codimension at most \(c\) sums at most \(2^c\) of these coefficients with signs. Fourier inversion on the three residues implies that on each such flat each residue has probability \(1/3+O(2^c(\sqrt3/2)^m)\). Choose \(c=\lfloor\alpha m\rfloor\) with \(0<\alpha<\log_2(2/\sqrt3)\).

Fix the coins and partition the short returning runs by their full sequence of frozen word values, including the returned bit. These are disjoint flats. Those with \(Cws+1\le c\) have nearly uniform residue distributions. For the union of any collection of their leaves, its probability under the uniform controls conditioned on a particular residue differs from that under any other residue by exponentially little. The error is relative to the unconditioned mass of each leaf, so summing does not multiply the error by the number of leaves. Fix one residue and one of opposite verdict. On the first, a short correct output has probability at most \(\epsilon+o(1)\) after averaging the coins, since on the second that same output is erroneous. A short erroneous output costs at most another \(\epsilon\) on the first. Therefore a fraction at least \(1-2\epsilon-o(1)\) of runs on each residue have more than \((c-1)/(Cw)\) charges. This part gives an average within each residue. The deterministic part gave a bound on every single input.

## What the bound prices

With the payload verdict fixed and supplied, the enhanced model can evaluate the controls in \(O(1+m/w)\) charged steps. Pack groups of \(\Theta(w)\) individual input bits by free affine operations. A lookup in a length-specific table gives each group's Hamming weight modulo three. A constant number of charged word operations incorporates each result into the running residue. The table can use a sufficiently small fixed fraction of the word width per group to keep its size polynomial. Even ordinary deterministic direct parsing suffices to exploit the regular fixed layout. The packing experiment therefore reaches the right order for this control predicate. It does not bound from above the time for an unknown payload.

More generally, if further computation on answers is free, an arbitrary \(N\)-bit input is fully exposed after \(\lceil N/w\rceil\) batches of \(w\) coordinate parities. No certificate-codimension argument on that input can exceed \(N\) independent conditions. Passing the linear-time milestone requires a new charge once the values have been exposed, or a different measure that continues to grow. The reduction and the RAM theorem are manuscript arguments.
