# An injective decoder with the same first missing word

**Research journal, 2026-11-24.** A bounded universal computation can reuse every duplicate or unsuccessful description and still preserve its first missing word. It needs no extra header. The resulting decoder is total and injective on short descriptions. Its only missing word is the original first hole. This normalization also identifies exactly which programs it can replace before that hole.

## An online completion

Let M=2ᵈ. Give each of the M−1 binary names shorter than d its original outcome, a d-bit address or a timeout. Include wrong-length outputs among timeouts. Process names in order of length and then lexicographically, starting with all M addresses free. When a name produces a free address, assign that address to it. Otherwise assign it the largest free address. Remove the assigned address. At least two addresses are free before processing the last name.

After i assignments the free addresses are exactly the **smallest M−i gaps** in the image of the first i original outcomes. To prove this, suppose a new original outcome belongs to the free set. Removing it removes the same gap from the ordered original omissions. If the outcome lies outside the free set or is a timeout, it leaves the first M−i old gaps intact. Removing the largest of those selects the first M−i−1. Induction proves the claim.

The completed decoder therefore misses only the original first gap w. Every originally produced address has been assigned by the time of its earliest original name, which preserves or reduces its shortest description length. More precisely, **each x<w is first assigned at its original earliest name**. The address w remains free throughout, so every fallback takes an address greater than w. An original producer must make the first assignment of x.

The construction is forced if the decoder must assign one distinct address per arriving name irrevocably and preserve the first gap for every continuation. After i outcomes, each of the first M−i current gaps could be the final first gap. For the jth gap, output the j−1 earlier gaps using the remaining M−1−i names, then time out. Every one of these M−i possible holes must still be free. This accounts for the entire free set, fixing the assignment at each step.

## The source clocks

Use the fixed efficient universal multitape program V with n public and d=n or d=2(n−1). At cutoff T, a fixed multitape decoder G simulates V directly for at most T steps per original name up through its own input name. It keeps a sequential table of free addresses and scans it to implement each update. Including tape resets, clocks and address comparisons, its running time is O(M(T+M)poly(n)) for T=2^{O(n)}. No extra universal simulation is charged when specifying G as the source machine with V built into its transition control. With the original T=2^(20n), this already presents the original first hole as the unique omission of a single-exponential total injection. [Original diagonal source](address-diagonal.md)

Alternatively use T=2^(17n). Then G finishes within B=2^(20n) on every short name at sufficiently large n. The actual missing word of G at B is the first word omitted by V at T. It still has the list and interval consequences relevant to cubic and linear SAT. For example, under cubic SAT, tabulating a fixed 2ⁿpoly(n)-time nondeterministic predecessor verifier and computing all gap ranks costs at most 2^(8n+O(log n)) native tape steps. A quadratic universal simulation by V finishes within T. A short rank that would print w contradicts its omission by V. In this application one may include the fast outputs of V in the scored set. The certificate transfer uses bounded incompressibility on V and the exact identity of the two holes. G itself need only compute the completed injection on short names. ## A predecessor certificate must find a producer in the oracle model

Fix any actual table f of original outcomes, its first gap w, and x<w. Suppose an accepting certificate probes entries adaptively and claims x differs from the first gap. Require soundness for every table agreeing with its probed outcomes. **At least one probe must return x.** Otherwise change every entry producing x into a timeout. This leaves the transcript and every output below x intact and makes x the first gap. The same argument works for a batch certificate by fixing any claimed predecessor x. In particular a single universally sound batch that covers k distinct predecessors must see at least k distinct producers. If every producer for one of those predecessors runs longer than F, literal simulations in such a transcript must include a run longer than F. This bound applies to the actual table of V even though the soundness premise ranges over other tables. A proof that uses V's particular program can distinguish those tables.

There is a separate sharp cost for a verifier covering the entire completed image with bounded ambiguity. Write P=M−1 and take P independent timeout bits. Name i either emits i or times out, for 0≤i<P. The last address P differs from the first hole exactly when at least one bit indicates a timeout. Suppose every yes instance has between one and A accepting certificates, every no instance has zero, and each accepting transcript uses at most q probes. Then **Aq≥P**, even for this family.

To see this, count modulo two the pairs consisting of an oracle and a nonempty subset of at most A of its accepting transcripts. A yes oracle with t accepting transcripts contributes 2ᵗ−1, which is odd. There are 2ᴾ−1 yes oracles. Conversely, each fixed set of at most A transcripts is simultaneously valid on a subcube fixing at most Aq bits, or nowhere. If Aq<P each such count is even, a contradiction. Use finite proof strings and include the proof and the observed answers in the transcript. The argument accommodates adaptive queries. A deterministic evaluator of a one-hole injection gives A=1 by using the raw name as certificate and accepting exactly when it produces P. Thus some evaluation needs all P probes. The underlying unambiguous subcube model and unambiguous representations of OR are classical. [Robin Kothari](https://eccc.weizmann.ac.il/report/2015/195/download/)

For every 1≤q≤P the ambiguity bound ⌈P/q⌉ is attained for membership in the completed image throughout this oracle family. For x<P the test x≠w is the OR of at most P literals: an earlier name times out, or name x succeeds. For x=P use the P timeout literals. Split these literals into public groups of size at most q. The proof names one group and the verifier evaluates it. Every true input admits between one and ⌈P/q⌉ successful groups. This tradeoff concerns a verifier for the image. It does not construct a fast row evaluator on the general source.

The completion gives a unique, genuine inverse name for each predecessor without a header penalty. The online rule preserves its earliest producer. Obtaining substantially cheaper certificates for late predecessors still requires information about the actual machine beyond observed output entries. The SAT time lower bound remains unresolved. Lean checks the free-set invariant, the characterization of the last gap and the adversary that forces an accepting transcript to read an actual producer.
