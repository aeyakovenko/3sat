# Time and stored bits for querying a solver's actual states

**Research journal, 24 November 2026.** Fix a correct deterministic packed-word RAM SAT algorithm with time $O(N^k)$, $k=2$ or $3$, and a fixed deterministic RAM decoder. A query gives the decoder the original formula $F$, a packed summary $z$, a native time $t$, and either a controller-field index or an arbitrary legal writable address. The controller includes every register, the instruction pointer and halt status. The decoder must return the actual value at the start of step $t$. It can adapt its reads of both $F$ and $z$ and use its own initially blank writable memory.

Write $L=\max(2,\lceil\log_2(N+2)\rceil)$ and $K=N^{1/k}/L^{3/k}$. There is one solver- and decoder-dependent family of unsatisfiable formulas, one for each sufficiently large source padding length. On each formula let $E$ be the first rejecting halt. For **every** summary of $s$ bits answering all legal queries through $E$ in at most $q\ge1$ steps per query,
$$
 qL^3+s\min(q,L)=\Omega(K). \tag{1}
$$
In particular a constant-time decoder needs $\Omega(\sqrt N/L^{3/2})$ bits for quadratic SAT time, or $\Omega(N^{1/3}/L)$ bits for cubic SAT time. This concerns ordinary adaptive RAM queries to a representation of the actual state. A circuit describing a predicate inductive on many configurations is a different representation. ## Detecting an error in one step

On source input $x$ of $n_0$ bits take the bounded signed universal interpreter with deadline $h=n_0^{2k+2}$. Its padded, locally addressable explicit formula $F_x$ has $N=\Theta(h\log^3 h)$. The verifier guesses $z$, its true length, a decoder clock $q$, and the proposed halt time $E$. Use fixed polynomial header limits covering the true solver clock. In proving the lower bound one can discard larger sizes and query clocks since (1) then holds directly.

Build one existential SAT instance for a defect. At time zero challenge any controller field or work address against the known initial state. For a transition challenge choose $0\le t<E$ and any writable address $a$. Decode the old controller and run one native instruction, obtaining its actual effective addresses from the decoded words in program order. Read the old decoder whenever a prior write in that instruction does not supply the word. Read immutable input words from the real $F_x$. Compare the resulting controller to the decoder at $t+1$ and the value at $a$ to the decoder there, including when the instruction never accessed $a$. A bounded number of old and new queries suffices on the fixed ISA. Finally challenge the controller at $E$ for a rejecting halt. Fixed default answers on malformed outputs and timeouts define total candidate states. With no defect, induction from initialization forces every represented cell and controller at every advertised time to be genuine. This also works when $E=0$ or a halted machine idles. A correct representation through the genuine rejecting halt passes all checks.

After compiling the local-generator tables once, each read of $F_x$ takes $O(1)$ native operations on $x$ and those tables. The constructor can pin the tables as $\operatorname{poly}(L)$ public data. Solver and decoder scratch, and successive fresh decoder calls, occupy separate banks or use call-number tags. A bounded defect run has $O(q+1)$ steps. By the public-port reduction, supplying $z$ as $O(1+s/L)$ immutable words costs
$$
 O(q L^3+s L+n_0 L^2+\operatorname{poly}(L))
$$
encoded bits, including true source input. The materialized query is solved once by the assumed SAT algorithm. [Public-port construction](materialized-input-census.md) · [Local source generator and physical-width audit](packed-band-transfer.md)

For $q<L$ use a second encoding. On each of the $O(q+1)$ decoder-step slots, replace an advice-bank read by a guessed word constrained by a hardwired lookup circuit on its *actual* address. Guard the constraint by the instruction and bank flags. Fixed precomputed generator tables never read $z$. To look up a table of $r=\max(1,\lceil s/w\rceil)$ words of $w=\Theta(L)$ bits, form one row indicator per physical word by a binary trie on the relevant index bits. Reject high index bits or implement the standard out-of-range value; pad the partial word with zeroes. Split the $w$ columns into groups of $\max(1,\lfloor(\log_2 r)/2\rfloor)$ bits. In each group OR together row indicators with the same stored pattern, then OR the appropriate pattern classes for each output bit. This uses $O(r(1+w/\log(r+2))+w)$ gates, including the trie. The constructor can form the pattern classes in one pass per group and emit their gate lists. When $s\ge N^\delta$, $\delta=1/(8k+8)$, this costs $O(s)$ encoded bits and construction steps per copy. For $s<N^\delta$ direct tables for all $O(L)$ reads cost $O(N^\delta\operatorname{poly}(L))=o(n_0)$ instead. Bit-unaligned reads use a constant number of packed words. The two encodings give the smaller of $sL$ and $O(sq)$ in (1), up to the additive source overhead. [Whole-row lookup constructions](bulk-snapshot-selection.md)

There is a distinct-probe refinement. If each honest decoder call touches at most $r$ distinct packed advice words, take $1\le r\le q$, raising a zero count to one. In (1) the advice multiplier can be $\min(r,L)$. For $r<L$ instrument each decoder invocation with a fresh presence bank and an integer count. Before serving a previously unseen advice address that would exceed $r$, terminate that invocation with a fixed default output, without reading the new word. This preserves every honest answer and defines a deterministic candidate state even on over-budget queries. The presence bank adds constant time per simulated step. Now collect every active advice-bank read in the bounded checker's chronological records, including its proposed return value. Route the $O(q)$ records by activity and address, require equal answers within each group, and mark its first record. A second ordinary permutation network places all marked records in at most $O(r)$ ports, enforcing the cap; the constant accounts for the bounded number of decoder calls. At those ports check the address and proposed value with direct copies of the genuine ROM. Unmarked active reads are tied to their representative by adjacent equality, and out-of-range reads return the stipulated value. These two routers cost $O(qL^3)$ encoded bits, already in the native term. This lets a long computation use few distinct advice words. Only the maximum over honest in-domain queries is needed for completeness. Merely omitting an over-budget defect trace could falsely certify a summary; the guard is part of the simulated decoder.

## Contiguous time blocks and a partially represented run

Allow $P\ge1$ independent rows on arbitrary consecutive time blocks covering $0,\ldots,E$. Row $i$ answers the same arbitrary-time and arbitrary-address queries within its block, using its own payload and true length. Let $S$ be the total payload bits and $u$ the maximum row length. Empty rows are allowed. The same hard family satisfies
$$
 qL^3 + P L+\min\{S+uL,\ S\min(q,L)\}=\Omega(K). \tag{2}
$$
In particular when $q=O(1)$ and $P=o(K/L)$ the total of the row lengths is $\Omega(K)$, even if one row contains almost all bits. When all rows have common width and $P\ge L$, the $uL$ term is absorbed in $S$ at arbitrary $q$. These bounds permit oracle choice of the best summaries and breakpoints separately for each formula.

The constructor checks increasing times and valid lengths. A transition challenge chooses a block and a time in that block, with the final endpoint assigned to the last row. Select this row and its successor, using the same block choice, and switch to the successor only if $t+1$ crosses a boundary. Initialization and terminal challenges use the corresponding endpoint rows. The two bulk selectors with true length and timestamp headers cost $O(S+PL+uL+N^{2\delta}L^2+\operatorname{poly}(L))$ bits and construction time, including the selected buffers' public pins. Indeed the row/column grouping threshold in the linked construction can be $2^{\lfloor\delta L\rfloor}$; the small buckets contain $O(N^{2\delta})$ bits apiece and $N^{2\delta}L^2=o(n_0)$. Alternatively select only the headers, including packed bit offsets into the concatenated rows. Bounds-check every access against the selected length. The whole-pool encoding then costs $O(PL+S\min(q,L))$ beyond the source, clock and small-bucket terms. The sparse lookup also gives $S\min(r,L)$ in the last minimum in (2). Paired reads across a boundary and physically unaligned rows increase the number of distinct global packed words by at most a fixed factor. The size rule $P\le N$ can be imposed in the verifier, since larger $P$ already implies (2). [Variable-width selector and uniform constructor](bulk-snapshot-selection.md)

There is also a prefix form. Represent only the true states through time $e\le E$. Write $g=E-e$, and let $d$ count distinct writable addresses read in the suffix before their first suffix write. In the native $qL^3$ term of (1) and (2) replace $q$ by $Q=g+(d+1)(q+1)$. In the direct-ROM advice multiplier it suffices to replace $q$ by $J=(d+1)r$, truncating at $L$ as before. An extra defect type decodes the controller at $e$ and runs the $g$ remaining native steps. Store local writes and cache incoming reads, with separate presence bits so written zero is never mistaken for absence. Fetch at most $d$ incoming words from the decoder for $e$. Make exceeding the advertised cap a defect before starting the excess fetch. Require a rejecting halt at the end. This uses $O(Q+1)$ time even on false summaries. The number of decoder calls is $O(d+1)$, so sparse lookup needs only $O(J)$ distinct advice words on a genuine check. The earlier checks now enforce the initial state and every transition through $e$, while the suffix check replaces the terminal obligation. The selected final row suffices for the entire suffix. The bound is meaningful when a long suffix requires few incoming words or when the omitted tail is short.

## Why the family is unsatisfiable

A single fixed nondeterministic verifier guesses the format and its data, constructs the indicated defect formula, and signals success when the solver returns UNSAT. On this verifier's own padded source description the bounded interpreter formula is satisfiable exactly if some such signal occurs within $h$ steps. A signal proves that the correct solver rejects that same formula. Hence no signal occurs by the deadline, and the source formula is genuinely unsatisfiable. Every honest sufficiently small representation would nevertheless signal in time. Specifically, if the relevant left side were at most $cK$, the materialized query would have $O(cK+n_0 L^2+\operatorname{poly}(L))$ bits. Guessing, scanning the rows, and writing the query are all charged. The SAT call costs the $k$th power of its bit length. Since $K=\Theta(h^{1/k})$ and $n_0^k\operatorname{poly}(L)=o(h)$, the honest branch fits the clock for sufficiently small fixed $c$. Actual SAT calls have polynomially bounded widths and addresses in $n_0$; the same-width universal interpreter can use the fixed word-width coefficient and disjoint banks from the signed transfer. A fixed opponent has constant interpretation slowdown. The construction gives no small-state-query upper bound for an arbitrary fast solver, so the unrestricted SAT time question remains open.
