# Checking every assignment in a deterministic edit stream

**Research journal, 24 November 2026.** A deterministic RAM has a read-only explicit 3-CNF and ordinary writable memory. Its write-only output describes point changes to an assignment initialized to zero. An instruction may overwrite or toggle a coordinate, or mark the current assignment as a candidate. A program can equivalently mark after every edit. Assume every satisfiable input eventually has a satisfying mark. The program may never halt and may mark arbitrarily many invalid assignments. For a satisfiable input of encoded length $N$, charge $K=\sum_{t<E}(1+|\operatorname{supp} M_t|)$ up through the instruction marking the first satisfying assignment. If the editor can read an assignment array, that array is ordinary charged writable memory. Each index and edit occupies a constant number of logarithmic words. Invalid coordinates can uniformly be ignored.

**Claim.** For every fixed $c<(1+\sqrt5)/2$, the worst positive-input $K$ is outside $O(N^c)$. With an independent sound nondeterministic UNSAT reference of time $N^{d+o(1)}$ on negatives, $d\ge1$, the exclusion holds whenever $d(c-1)<1$. Both statements allow unrestricted workspace and arbitrary running time on negative inputs. The [simpler block-output proof](positive-output-watchdogs.md) uses the physical length of each printed assignment. A point editor can mark a new candidate after one instruction. The proof below replaces the length charge with a gap reduction and an existentially selected list of clauses.

## A single list for the entire run

Suppose an unsatisfiable formula has $J$ clauses and every assignment violates at least $\delta J$ of them. A fixed cutoff run visits $p$ marked assignments. A uniform list of $k$ independently sampled indices, with replacement, misses the violated clauses of any one assignment with probability at most $(1-\delta)^k$. The fraction of lists missing at least one mark is at most $p(1-\delta)^k$. At $k>\ln(p+1)/\delta$ some list witnesses a false clause at every mark. The marks can repeat and the run can depend on the entire formula. The simulated editor never receives the chosen list or feedback from these checks, so its true sequence is fixed independently of the sample. This is an existence proof for a nondeterministic certificate. On a satisfiable formula every list fails at a genuine satisfying mark.

For a fixed proposed list, keep only its clause texts, the values of the at most $3k$ watched coordinates, and the machine's own memory and controller. Update all matching watched slots on each edit, including repeated variables. At a mark require at least one watched clause to be false. Charge the *native* cumulative cost before each instruction and stop just before the first instruction exceeding $B=\Theta(N^c)$, or upon halt. A terminal mark inside the budget is tested before any timeout signal. Halt or timeout with every completed mark checked signals UNSAT. On a positive input with the hypothesized bound no branch can give that signal. A negative input to the gap reduction has a successful list, since $p\le B+1$ and $k=O(\log N)$ suffices. The extra working words and overhead per simulated instruction are polylogarithmic. The lists are ordinary binary strings guessed and paid for outside checkpoint verification. The same argument covers any fixed edit convention for which the values of these watched coordinates can be maintained within these costs.

## A locally readable gap reduction with charged preprocessing

The complementary simulation starts with a bounded nondeterministic RAM test with horizon $R$, $m$ physical public words, and $H=\max(2,R,m)$. We need a genuine explicit 3-CNF with $H^{1+o(1)}$ bits, perfect completeness, a constant fraction of clauses false under *every* assignment on nonacceptance, and $\operatorname{polylog}H$ time per word lookup during replay. A materialized quasilinear gap reduction alone does not supply the last property. We first compute an error-correcting encoding of the actual public input outside the monitored run. Counting input words conservatively as $O(\log H)$ bits each, this takes $(m+1)H^{o(1)}$ time and space. Only this short bank needs to be retained read-only. In particular preprocessing costs sublinear time at a hierarchy root where $m$ is a small power of $R$.

Here is one self-contained choice of binary code. For an $M$-bit input choose $a=\max(1,\lceil\sqrt{\log_2(M+2)}\rceil)$, $b=2^a$, $j=\max(1,\lceil\log_b(M+1)\rceil)$ and a binary extension field of size $q$ with $4jb\le q<8jb$. Pad the bits by zero and use them as the coefficients of a polynomial in $j$ variables, of individual degree below $b$. Evaluate on the whole $q^j$ grid. Encode each field output by all $q$ binary inner products with its coordinate vector. Distinct inputs differ on at least $3/4$ of the grid by the polynomial zero bound, then on half of the inner products at each differing symbol. Relative distance is at least $3/8$. A brute-force search for an irreducible modulus and field operations cost $2^{O(\log q)}$ or less per basic setup or arithmetic operation. Successively evaluating one coordinate at a time by direct polynomial evaluation costs $O(jbq^j\operatorname{poly}(\log q))$ field-level bit operations, up to RAM addressing overhead. Writing the inner table adds $q^{j+1}\operatorname{poly}(\log q)$. These quantities and the code length $P=q^{j+1}$ are at most $(M+2)2^{O(\sqrt{\log(M+2)}\log\log(M+4))}$. Choose fixed conventions for the field basis and coefficient order. Small inputs can be handled directly. Finite-field arithmetic, code indexing and its actual encoding use a fixed deterministic program.

Use a public header of $O(\log H)$ bits fixing the machine parameters, input dimensions and clock. Let the implicit binary input $y$ repeat the codeword cyclically to a power-of-two length $L\ge\max(H,2P)$ chosen minimally. Any requested bit is one indexed read modulo $P$. For this header the pair language consists of the words of exactly that repeated form encoding an input on which the bounded machine accepts. Distinct repeated words disagree on more than a fixed positive fraction, since full copies occupy at least half the positions. Thus the true implicit input is in the language on acceptance and is at relative distance at least $3/16$ from every word of that length in the language on nonacceptance, with the empty language allowed.

This is a fixed pair language decidable nondeterministically within $U^{1+o(1)}$ ordinary tape steps for total length $U$. Check the header, including $R\le L$, input length within the stated layout and reproduction of $L$. Guess the input, compute the code, compare all repetitions, and verify the bounded native computation. One can check a logarithmic-word RAM computation on tapes by guessing its transcript, checking the chronological CPU records, sorting memory accesses by bank, address and time, and checking adjacent accesses and the initial input bank. This costs a fixed polylogarithmic factor times the number of instructions and input words. The same conversion applies to the encoding computation. All bounds above are covered by a fixed nondecreasing $T(U)=U\,2^{O((\log(U+2))^{2/3})}$ with suitably enlarged constants. Reject malformed headers before allocating purportedly oversized data.

Apply Ben-Sasson, Goldreich, Harsha, Sudan and Vadhan, Theorem 2.6, to this *pair* language with a constant proximity parameter below $3/16$, constant soundness error below one, and fixed $\epsilon=1/8$. It uses $\log_2 T+o(\log T)$ random bits, a constant number of oracle queries, and verification time polynomial in the header length and logarithms of $L,T$. Its bounded proof address range is explicit in the verifier construction in §7. In this application $U=H^{1+o(1)}$ and these verifier times are polylogarithmic in $H$. [Short PCPs Verifiable in Polylogarithmic Time, Theorem 2.6 and §7](https://people.csail.mit.edu/madhu/papers/2005/bghsv2-full.pdf)

Pad the random block to a locally computable integer $r=\lceil\log_2 H\rceil+O(1+(\log H)^{3/4})$, with sufficiently large fixed constants and integral upper rounding. This also bounds the logarithm of the proof address range. The extra coins duplicate tests equally. For each one of the $2^r$ seeds run the verifier for each possible sequence of answers to its constantly many binary proof queries, reading true implicit bits from the public code bank. A rejecting branch forbids the conjunction of the stated proof-bit values along its path. Inconsistent answer paths give tautologies. This yields a constant number of constant-width clauses per seed. Convert a long clause into a chain of width-three clauses with fresh variables private to this seed and path. An empty rejecting clause can be implemented by two incompatible unit clauses. Fill the constant per-seed stride by tautologies and repeat literals for width three. If a seed rejects a fixed assignment to proof variables, at least one clause of that seed fails for *every* setting of private variables. Perfect completeness permits simultaneous choices of all private variables. Soundness therefore gives the required constant gap after division by the fixed stride. Names consist of a proof address or a seed with a constant local offset. The header, literals and padding are retrievable in $\operatorname{polylog} H$ per packed formula word, and the resulting encoded length is $H^{1+o(1)}$. The only nonlocal resource used by this generator is the honestly computed codeword.

This preprocessing is necessary for this particular representation. On the unencoded input to a parity machine, flip any bit of a rejecting input. The resulting input has an accepting proof. For the old input a constant fraction of clauses must fail under that same proof. Whenever the generator for a clause misses the flipped bit, the corresponding clause is identical on the two inputs. Each input bit must therefore be inspected by a constant fraction of clause generators. Averaging forces linear bit probes per clause on the old input (or linear divided by word width for packed probes). This assumes a common padded layout and proof indices. It explains the charge for encoding the true input at each recursion level. [Related raw-input obstruction](horn-gap-rounds.md)

## Cost in the complementary simulation

On an arbitrary explicit input a reference UNSAT recognizer may maintain the *entire* current assignment in a work array. At each mark it guesses a false clause just in time and tests its three values. On a negative input an honest branch always succeeds, and a true satisfying mark kills every branch. Timeout using the positive time promise. This takes $N^{c+o(1)}$ time and only needs polynomially bounded dense variable names; default-zero directly addressed cells also handle unused variables. The reference has no cumulative-space requirement. Alternatively the locally readable gap formula and logarithmic monitoring list provide the base $H^{c+o(1)}$ bound directly for bounded source computations.

Suppose their nonacceptance already has a nondeterministic simulation in $(R^e+m^d+1)H^{o(1)}$ time, initially $e=d$ with the independent reference or $e=d=c$ from the positive bound. Deterministically encode the actual public input, and guess the list of watched clauses. For fixed list the monitored negative computation is deterministic and has cumulative word cost $H^{c+o(1)}$ up to its signal. The cumulative cutoff caps the native prefix even on inputs where the editor runs forever. Guess a least-cost snapshot in each full window of $H^x$ steps on an honest run, including its controller and monitor state. The guessed chart uses $H^{c-x+o(1)}$ bits. The all-address defect check replays at most $2H^x+O(1)$ steps and can challenge one claimed endpoint. It receives the original public data, the computed code bank, the list and the chart as immutable data. Their total length is $(m+H^{c-x}+1)H^{o(1)}$. Recompute the code of each *new* public input only at the outside of its own recursive verifier, after the outer guesses are fixed. A branch cannot substitute an unverified codeword for its actual input.

Applying the preceding nonacceptance simulation to this defect test costs $(H^{xe}+H^{d(c-x)}+m^d+1)H^{o(1)}$, including construction of the public code and chart. A verified negative signal is sound on every positive source. On true nonacceptance, the gap and the finite-list argument guarantee an honest list and chart. Setting $x=cd/(e+d)$ thus gives $e'=cde/(e+d)$. At fixed $d(c-1)<1$ the iteration from $e=d$ crosses below one after finitely many steps (take a slightly larger $c>1$ if necessary). The fixed-depth $H^{o(1)}$ factors preserve that strict saving. With $R=m^D$ for fixed $D>d$, this contradicts the bounded complementary diagonal for the [packed RAM](packed-band-transfer.md). The diagonal and window induction are derived in the [cumulative theorem](cumulative-sat-memory.md).

## Near-quadratic cumulative cost with a near-linear reference

Suppose the reference UNSAT time is $O(N\log^a N)$ for fixed $a$. A quantitative variant gives, on infinitely many satisfiable inputs of each fixed editor, $K\ge N^2/\log^A N$ for some fixed $A$. Here we use Mie's constant-query PCPP with randomness $\log_2 T+O(\log\log T)$ and proof length $T\operatorname{polylog}T$. The shorter randomness bound controls the number of explicit clauses. [Mie, *Short PCPPs verifiable in polylogarithmic time with O(1) queries*](https://link.springer.com/article/10.1007/s10472-009-9169-y) · [Parameters in Bhangale, Harsha, Paradise and Tal, Theorem 8.1](https://arxiv.org/pdf/2005.03123)

The pair language above actually has a tape time bound $T(U)=U\operatorname{polylog} U$. Its implicit string has length at least the full code length $P=q^{j+1}$. Computing the grid costs $jbq^j\operatorname{poly}(\log q)\le P\operatorname{poly}(\log P)$, inner encoding costs $P\operatorname{poly}(\log P)$, and even the initial field search takes at most $P$ times a logarithmic factor for all sufficiently large $j$. Malformed headers can be rejected by testing the claimed dimensions and $P\le L$ with bounded integer arithmetic before expanding. On a signed hierarchy root of public length $m$ and horizon $H=m^D$ for fixed $D>1$, the actual code takes $mH^{o(1)}=o(H)$ time to prepare. Its repeated implicit input has length $\Theta(H)$. Thus this root's gap formula has $H\le N\le H\log^{O(1)} H$ with uniform fixed-width padding. Its generator and each editor instruction have polylogarithmic overhead, as do the $O(\log H)$ watched slots.

Set the native cutoff $B=\lfloor H^2/\log^{A_0}H\rfloor$ with a large fixed integer $A_0$. The self-input source guesses the watching list and a chart for a no-satisfying-mark signal through this cutoff. On any honest such monitored run of native cost at most $B$, the augmented cumulative cost is at most $(1+B)\operatorname{polylog}H$. With windows of $\lceil\sqrt B\rceil$ instructions, the total guessed chart and each replay cost $O((1+\sqrt B)\operatorname{polylog}H)$. Construct the ordinary explicit formula for an existential defect and use the reference to certify its unsatisfiability. Its physical public data also include the $mH^{o(1)}$ encoded source. Total time is $O(\sqrt B\log^u H)+mH^{o(1)}$ for a fixed $u$. Choose $A_0>2u+2$ so completion fits within $H$. The powers in this overhead are independent of $A_0$: the clock and source remain polynomially bounded and its fixed exponent is a program constant. [Signed self-input construction](packed-band-transfer.md)

If that bounded source has no accepting branch on its padded self-input, the gap formula is negative. Its honest list and chart would give an accepting branch in time, a contradiction. Consequently its formula is positive. A chart accepted in time certifies a genuine run through the halt or cutoff with a false watched clause at every mark, so that positive formula cannot have had a satisfying mark before the cutoff. The promised editor eventually marks one, giving $K>B$ on this formula. Converting $H$ to $N$ enlarges the logarithmic exponent by a fixed amount. This uses the signed construction only at the root; the one inner reference call uses the ordinary bounded-computation formula.

The new claim concerns positive-output cumulative work. A linear-time native execution can accumulate quadratic work, even with a mark on every step. No prior result asserting this exact edit-stream tradeoff was identified in the sources examined; its priority is unverified. One possible attack on elapsed time would encode the solver’s changing private state throughout the run and watch only a few consistency checks. A literal stored codeword with fixed coordinates already has a maintenance cost: changing a single message bit changes at least a constant fraction of the codeword bits, hence requires writing at least that many bits divided by word width. Our code bank represents one immutable input per verifier call. An implicit representation for changing memory would have to pay for its queries and ensure that the adaptive private reads of the actual solver are correct. The monitored output edits give no such guarantee for internal memory.
