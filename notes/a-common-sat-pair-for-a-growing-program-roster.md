# A common one-bit SAT test for a growing list of RAM programs

Give each of $r$ deterministic SAT deciders its own copy of a file and unrestricted writable memory. At infinitely many encoded bit lengths $N$, there are two ordinary proper ASCII 3-CNF files, one satisfiable and one unsatisfiable, differing in one bit, with the following property. For **every** program, after a common prefix on the pair has inspected at least $\lfloor cN/(r\log N)\rfloor$ distinct data packets, **both** runs still incur $\Omega(N/\log^2 N)$ charged numerical operations and stores. The bound on the continuation holds uniformly as programs are added. Each run must also read every one of the $m=\Theta(N/\log N)$ designated original input words.

Use an aligned integer RAM with a fixed, sufficiently large logarithmic word-width coefficient, one initially populated writable address space, separate load and store instructions, fixed-arity operations, and terminal verdicts. The list may change with $N$ and have polynomial size. Its instruction arity and word-width bounds are uniform, each program counter fits a constant number of native words, and each register file occupies at most a fixed polylogarithmic number $h$ of words. In particular this includes every fixed finite roster of standard programs with a fixed number of registers. For growing prior disclosure, take $r=o(N/\log N)$. The time and occupied space before the cut are unrestricted.

## Which operations are charged

Start each suffix with the registers unmarked. A LOAD result is marked unless its unmarked address refers to an original query hole or to a cell last written in the suffix. A copy preserves the mark. Numerical operations produce unmarked results. Count numerical operations or comparison branches consuming a marked operand ($c_0$), and stores consuming a marked operand ($s_0$). Collect distinct numerical addresses and payloads of the other stores in $D$. The lower bound applies to $c_0+s_0+|D|$. Thus reading query words and parsing them with register operations can be free. All $L$ basis words are still unread at either permitted cut, and each must be read on both diagonal files, by the pivotal-bit argument below. Every counted event uses a non-LOAD instruction and each instruction contributes at most a constant. [First-hole replay for writable memory](processing-after-the-database-packets-of-a-sat-file.md)

## Two possible raw words at any seed position

Take $m$ private aligned word positions. A database $a$ has $L=\lfloor\gamma m\rfloor$ independent bits, with $\gamma>0$ a sufficiently small fixed constant below $1/3$. A query $x$ has the same length. One tag asks whether $x=a$. The other asks whether $x\ne a$. Both tags work for every query, including one-bit perturbations of $x$.

Use a public $L$-by-$m$ binary matrix $G$ whose transpose encodes with distance $\delta m$, for fixed $\delta>0$, and for which $z\mapsto Gz$ has an $O(m)$-gate XOR circuit. Such matrices exist for infinitely many $m$. Start with an asymptotically good binary code having a linear-size XOR/fanout encoder, restrict the input coordinates to $L$, and transpose. Replace each resulting zero column of $G$ by the first unit vector. This cannot decrease the Hamming weight of any encoded vector, and adds at most $m$ XOR gates to the first output. All columns are now nonzero. After deletion of fewer than $\delta m$ columns the others span the whole output space, since a nonzero vector perpendicular to them would encode to a nonzero codeword supported on the deleted positions. The transposed code with this spanning property is the published linear bit-fixing extractor. [Ishai, Kushilevitz, Ostrovsky and Sahai, Theorem 3.2](https://web.cs.ucla.edu/~sahai/work/web/2008%20Publications/STOC2008.pdf) · [Spielman's original codes](https://www.cs.yale.edu/homes/spielman/PAPERS/linearTimeIT.pdf)

The public circuit computes $x=Gz$ from the $m$ physical slot bits, then compares $x$ with the database and applies the tag. In total it has $O(m)$ gates. Each movable data packet forces one named database bit. A tag pins one of two complementary verdict wires via a separate one-bit change. Each data, tag and filler packet also sets its physical slot bit to zero. A seed packet sets its slot bit to its supplied binary value. There are just **two possible entire numerical seed words**, shared by all positions. End each movable aligned word with ASCII digit 4 or 5; start the next public word with the fixed-width decimal suffix naming the physical slot. The two resulting positive variable names are complementary by fixed public clauses. Two false anchors pad the pinned literal to a proper ternary clause. Thus changing the low bit of the last digit of a private word from 4 to 5 or conversely changes only its slot bit, preserving any data pin and tag. The slot identifier lives in public bytes. The public gate list and neighboring words take $N=\Theta(m\log m)$ physical bits for the fixed sufficiently large width coefficient. This construction measures the actual encoded length, including every public clause and padding byte. ## Saving a prefix for every machine

Choose a small constant $\eta>0$ with $\eta<\min(\gamma,\delta)/2$ and $H_2(\eta)<\gamma/8$, for binary entropy $H_2$. Give each program a quota $u=\lfloor\eta m/r\rfloor$ of distinct original private words. Fix $a$. Simulate programs in succession, keeping writes and registers private, but assigning the next unused database packet to each newly requested private position in one shared partial original file. Stop each machine at its quota. The union $V$ of visited private positions has size at most $ru\le\eta m<L$. Use a public deterministic rule for every choice in this construction.

Correctness forces each quota to be reached. Suppose one machine first tried to overwrite an unread private word. Considering only that machine's own observations, reserve that word as the tag, then choose a basis of columns from the positions outside its reads and this tag. The distance inequality permits this. There is room to place every still unused data packet since $2L+1\le m$. The two completed files with the same arbitrary query and opposite tags give different answers; the store would erase their sole difference without reading it. An early halt or an infinite continuation with no new read is excluded by the same two completions. These *counterfactual* pairs can disregard positions seen only by other machines. The prefixes retained after the joint construction all replay on the same two final files.

Make the least position outside $V$ the tag, then take the first increasing greedy column basis outside $V$ and the tag. Write $B$ for this $L$-element basis, $H$ for the basis and tag together. Fill all nonreserved words with the remaining data and fillers. The canonical overlay for a query is $z_B=G_B^{-1}x$ with zeros elsewhere. It depends only on $V$ and the proposed $x$. The register and memory snapshots at the cuts are independent of the eventual query and tag. One may alternatively advance each prefix until its first actual load of a word in $H$. At this stage a write to an unread basis word before any original hole read is impossible by the diagonal query $x=a$ and an alternative flipping just that basis word. The two tags give the corresponding assertion for the tag location.

## One cheap execution would identify the entire database

For each $a$, build a static index of each program's cut memory, with original locations in $H$ provisionally zeroed. The replay index records power, orbit-equality and first-hole information for the resulting memory function, even when subsequent suffix stores shadow original words. For the selected program include its actual controller and registers. Each cell has $O(\log m)$ bits. The full native universe has $2^W=m^{O(1)}$ addresses, $W=\Theta(\log m)$, so the index has polynomial size even if the prefix uses the entire memory. Fix a common address layout across databases, allowing unused zero cells. The index can take arbitrarily long to build; the argument uses no uniform fast constructor for it.

Once $V,x$ and a tag are given, replay costs at most $C(1+c_0+s_0+|D|+p)+O(h)$ static probes. Here $p$ is the number of distinct raw numerical original hole replies later used unmodified as LOAD addresses. All the original holes contain only two possible numeric seed words and one actual tag word. Hence $p\le3$, independent of the number of holes. The simulator's private arithmetic and elapsed local time are free. [Proof including timestamped writes and first-hole resets](processing-after-the-database-packets-of-a-sat-file.md)

Call $a$ cheap if on the query $x=a$ **any one** of its programs, on **either** tag, has suffix charge at most $t$. Describe each cheap $a$ using

* an enumerative code for $V$, of at most $\log_2\sum_{i\le\eta m}\binom mi+O(1)\le mH_2(\eta)+O(1)$ bits;
* the selected program's index and tag, of cost $O(1+\log r)$ bits;
* the addresses and contents of that execution's static probes, including its controller, using $O((1+h+t)\log m)$ bits.

Use fixed-length fields with padding up to the common budget. There is no field containing the query $x=a$. To prove injectivity, suppose two databases $a,a'$ have the same description. Run the recorded program and tag on the *same* query $x=a$ against the representation for $a'$. The common $V$ gives the same directory and hence the same hole overlay. Every static address probed on $a$ has the recorded contents on $a'$. Induction on probes reproduces the halting computation. Its verdict says that $x$ equals the database (for the inequality tag, it correctly rejects). Correctness on the corresponding physical completion for $a'$ gives $a=a'$. The proof compares computations on a fixed query. A decoder need not first recover that query. Lean checks this transcript transport and injectivity for abstract adaptive probe trees. The native reduction and its asymptotic bounds are manuscript proofs. [Lean transcript theorem](../lean/ErasedCodeRosterEquality.lean) · [Small code, erasure and transport audit](../audits/constant_alphabet_roster_audit.py)

Take $t=\epsilon L/\log m$ for a sufficiently small fixed $\epsilon>0$. The complete description has at most $L/2$ bits for large $m$. Thus at most $2^{L/2}$ of the $2^L$ databases are cheap. For each remaining database the canonical diagonal gives a pair on which **every program and both tags** have charge greater than $t$. This density is over the database bits, with physical layout constructed for that database and roster; it makes no random-DIMACS assertion.

On either diagonal tag, changing the final 4/5 digit in *any* private word adds its nonzero column of $G$ to $x$ while preserving $a$ and the tag. The opposite verdict then forces every correct program to read every original private word, before overwriting it. Combining disjoint instruction types gives at least $m+\Omega(m/\log m)$ native steps on each hard file. The $m$ here counts the designated private words, and the physical file also contains public words.

## What survives when a program is added

At most $2^{C+1}-1$ binary strings have at most $C$ bits. With a fixed program encoding the theorem applies to the correct members of that list, under the same uniform controller and word-width bounds. Passing to a larger admissible $m$ can restore the prior-disclosure quota as $C$ increases. The suffix bound retains its order as the list grows. This is a fresh common test against an enlarged list; no one-clause extension of a previous test is assumed to stay hard.

A RAM can evaluate the supplied acyclic circuit and its pins in $O(N)$ time on this family. In particular the established cost fits a linear clock on every constructed pair. To exclude $O(N)$ one must force greater elapsed work on one execution. The diagonal argument spends at most the entropy of one database and has no second disjoint charge of that magnitude. In fact this separated equality problem has a matching deterministic static upper bound after unlimited preprocessing.
