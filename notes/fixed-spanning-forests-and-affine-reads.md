# What minimum spanning forests can certify about a RAM read

Fix an integer $k\ge1$. There are explicit weighted graphs on which the first $k$ successive minimum spanning forests, at every weight threshold, depend only on the number of vertices and the public construction. One four-cell RAM program reads zero on the all-zero input for every graph in the family. Deciding whether at least a specified number of independent input bits can vary on a subspace through zero while this read remains affine is NP-complete, even when the labeled degrees at every weight threshold are fixed and the graph has maximum degree at most $2k+2$. The result concerns the difficulty of **analyzing the read**. Executing the given program takes one pass through the edges.

Khanna, Putterman and Song's Theorem 1.1 gives a uniform deterministic $O(m)$-time MST algorithm on connected graphs with $m$ edges and opaque comparable weights. Their comparison bound uses certificates for contractions and deletions and Pettie and Ramachandran's theorem converts that MST comparison bound into a time bound. Here we test a specific use of minimum spanning forests in a SAT proof, namely keeping threshold connectivity information as a substitute for the effects of preceding writes. We do not need the full MST algorithm to compute the forests below. [DLMST manuscript](https://github.com/Louiealbp/DLMST/blob/0072335716b145032b418760883daed2a89809db/final.pdf) · [Earlier test on parity constraints](threshold-forests-with-many-parity-pins.md)

There is also an exact positive result for edge deletion. At a single threshold, some acyclic subgraph preserves the read's maximum affine dimension exactly when minimum vertex cover exceeds maximum matching by at most one. Across all thresholds, even preserving that one number on a bipartite graph can force every edge to remain. On a single triangular bipartite graph the optimal edge count with additive error $e$ is of order $s^2/(e+1)$ for $s$ vertices per side and $s\ge4(e+1)$. [Proof, matching construction and precision bounds](acyclic-certificates-for-a-memory-read.md)

## One load, with an exact optimum

Given a simple graph $J$, start four cells at zero. For each edge $uv$, store one at the two-bit address $(x_u,x_v)$. Read cell $11$ at the end. The Boolean output is $f_J(x)=\bigvee_{uv\in E(J)} x_u x_v$. Edge order, orientations and weights leave this output unchanged. Let $a(J)$ be the maximum dimension of a linear subspace through zero on which $f_J$ is affine. Since $f_J(0)=0$, on such a subspace its restriction is linear.

The largest dimension of a zero subspace is the maximum independent-set size $\alpha(J)$. If two adjacent coordinate forms are nonzero on a zero subspace, they can take value one simultaneously, whether they are equal or linearly independent. Thus all the varying coordinates form an independent set. Freeing a maximum independent set realizes the bound. A nonconstant linear read has a zero kernel of codimension one. If the complement of a maximum independent set contains an edge, adjoin the indicator of that edge to its coordinate subspace. This gives $a(J)=\alpha(J)+1$. The general certificate and its converse appear in the [pointwise load analysis](affine-guards-for-writable-memory.md).

## Fixing all the forest layers

Take any simple data graph $G$ on $q\ge1$ labeled vertices $v_i$. Give each $v_i$ a private clique on $2k+1$ new vertices, labeled $0,\ldots,2k-1,p$. Write $a_j=j$ and $b_j=k+j$ within that clique, for $0\le j<k$. Add the edge $v_i a_j$ for each $j$. Between consecutive cliques add $b_{i,j}a_{i+1,j}$. All of these edges and labels are public and independent of $G$.

On residues modulo $2k$, the path with successive vertices
$$
j,\ j-1,\ j+1,\ j-2,\ j+2,\ldots,\ j-(k-1),\ j+(k-1),\ j-k
$$
visits every residue once. Consecutive endpoint sums alternate between $2j-1$ and $2j$ modulo $2k$. The residue classes of sums for different $j$ are disjoint, so these are $k$ edge-disjoint paths. For $k=1$ the path is simply $0,1$. Within each clique extend path $j$ to $p$ by edge $a_jp$. Across the whole graph, join these paths using the links of index $j$ and attach each data vertex by its edge to $a_j$. This is a spanning tree $T_j$, and different $T_j$ share no edges.

Give the edges of $T_j$ weight $j+1$, all remaining public edges weight $k+1$, and all data edges weight $k+2$. At any threshold the first $k$ residual forests are obtained by repeatedly taking a minimum spanning forest and deleting its edges. At threshold above or equal to $k$, they are exactly $T_0,\ldots,T_{k-1}$. Each is the unique lightest available spanning tree on its round. At a lower threshold the available initial segment of trees is followed by empty forests. This determines even their labeled edge sets, regardless of how equal weights are ordered.

Every independent set of the full graph $J$ takes at most one vertex per clique and at most $\alpha(G)$ data vertices. Conversely all the $p$ vertices coexist with a maximum independent set of data vertices. In the complement there is an edge between two residues of a private clique. Hence
$$
                   a(J)=q+\alpha(G)+1.
$$
If $G$ is cubic, the degrees of the labeled data vertices at the top threshold are all $k+3$. Every other threshold degree and every scaffold degree is determined by $q,k$ and the labels. To see the degree bound, each residue vertex has $2k$ clique neighbors, at most one inter-clique neighbor, and at most one data neighbor. All other vertices likewise have degree at most $2k+2$. For fixed $k$, the construction adds $O(q)$ vertices and edges.

For completeness, cubic Independent Set can be obtained from 3-SAT directly. In a formula with three literal occurrences per clause, replace a variable with $d\ge2$ occurrences by a $2d$-cycle, or a single edge for $d=1$. Each maximum independent choice takes one of the two alternating sides. Give each clause a triangle. Join each of its literal vertices to the vertex of the falsifying side at that occurrence's private position. Reaching $\sum d+\#\mathrm{clauses}$ chooses a consistent assignment and a true literal per clause, and any satisfying assignment reaches it. Degrees are at most three. For each unit of degree deficit at an original vertex attach a private copy of $K_4$ with one edge subdivided, connecting that subdividing vertex to the deficit vertex. The five-vertex attachment contributes at most two independent vertices, and both endpoints of its former edge attain two without using its subdivider. Thus each attachment adds exactly two to the optimum and the resulting graph is cubic. Together with the formula for $a(J)$ this proves NP-hardness with the prescribed threshold data. Membership follows by guessing a data independent set of the required size on this family, or by the general graph certificate. [Alimonti and Kann on cubic Independent Set](https://doi.org/10.1016/S0304-3975(98)00158-3)

## How many extra bits are needed to answer two-coordinate queries?

Let the cubic data graph consist of a fixed cycle on $s\ge3$ left vertices, a fixed cycle on $s$ right vertices, and a perfect matching between them. The matching has $s!$ possibilities. In the entire four-cell program allow just one specified left coordinate and one specified right coordinate to vary, pinning every other input to zero. The read is their AND if they are matched, and identically zero otherwise. AND has maximum affine dimension one on the two-dimensional input plane. The zero function has maximum dimension two. An exact summary that can answer these dimension queries for every named pair therefore determines the entire matching. The shared forests and degree profiles convey none of its identity. An additional fixed-width summary needs at least $\lceil\log_2(s!)\rceil$ bits. This order is attained by listing the matching, and after indexing it a word RAM can answer a pair query in constant time. ## What the matrix multiplication paper adds

The November 24 preprint's list-distinctness theorem states that for a fixed finite field and some $\sigma>0$, one trivalent bit tensor network computing whether $N=2^w$ records of $2w$ bits are distinct needs volume greater than $2Nw\,w^\sigma$ for all sufficiently large $w$. This is its one-list case. A bounded-fan-in Boolean circuit with $s$ gates and $e$ input bits embeds with volume $O(s+e)$ by using gate truth tables and binary copies. Our deduction uses this specific theorem as published in the preprint. We have not reverified its full proof or its companion results. [Theorem on volume of list distinctness](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/build/obstruction.tex) · [Proof from routing tagged records](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/build/list.tex)

For each fixed $k$, the affine-dimension threshold of the four-cell read with its first $k$ forests prescribed requires $\Omega(L(\log L)^\sigma)$ bounded-fan-in Boolean gates along a sequence of encoded graph lengths $L$. Here we use the graph family with general data degrees. The cubic degree conclusion above used a different reduction whose circuit cost for routing occurrences has not been established here.

Use the [fixed-layout dense 3-CNF for a repeated record](matrix-list-unit-sat.md). Briefly, split each record into two $w$-bit indices. A selected row must turn on the flag at its index in each of two separate banks. Require two selected rows and at most one flag in each bank by fixed prefix circuits. These conditions hold precisely when a record repeats. Gate equivalences and constant-size padding give exact-three clauses with $v=O(N)$ variables and $c=O(N)$ clauses, with fixed counts and layout. The map to the literal fields has bounded-fan-in cost $O(Nw)$. Every data-dependent reference is a fixed bank offset plus a source index.

Now make a variable edge per variable, a triangle per clause, and one incompatibility edge for every literal occurrence to the opposite variable choice. The resulting simple graph $G$ has $q=2v+3c$ vertices. Each occurrence has its own clause vertex. Its independence number is at most $v+c$, attained exactly on satisfiable formulas. The endpoint lists have a fixed order and length. Computing an endpoint uses at most a constant number of additions of fixed offsets, shifts and sign choices on $O(w)$-bit indices. This costs $O(Nw)$ gates in total. Use the graph $J$ above and test whether $a(J)\ge q+v+c+1$. Only the incompatibility endpoints vary. The $k$ forest lists can be supplied as additional constants. With a fixed-width edge-list encoding $L=\Theta(Nw)$, including those lists if desired. Negating the answer computes distinctness. A circuit below the stated bound followed by this composition would violate the paper's one-list volume theorem, since the additional $O(Nw)$ gates can be absorbed for large $w$.

There is a counting obstacle to making the degree profile constant by *local* padding of this circuit reduction. Suppose each record independently prints a chunk of $b_i$ unweighted edge slots apart from a shared fixed graph, with all topology taken at the final threshold. Holding the other records fixed shows that chunk $i$ must itself have a constant labeled degree vector. It touches at most $2b_i$ predetermined vertex names. Hence it can realize at most $(2b_i)^{2b_i}$ ordered endpoint lists. To see why row $i$ must distinguish any two possible values, include the first candidate once in the other rows, omit the second, and fill the remaining positions with mutually distinct alternatives. The outputs then differ. Consequently $b_i\log(2b_i)\ge w$, requiring $\Omega(Nw/\log w)$ edges in all and $\Omega(Nw^2/\log w)$ bits with $\Theta(w)$-bit names. A construction that mixes records before producing degrees is outside this counting argument.

The same duplicate-list instances have a direct $O(N)$-word-step algorithm on the promised layouts. Recover the two $w$-bit indices per row from its fixed endpoint slots. Concatenate them to address an initially zero flag in a table of $N^2$ bits. For each row OR the old flag into a single CPU register and write one to the flag. The register reports a duplicate exactly when some flag was already set. This uses a fixed loop with a fixed number of loads and stores, and each flag address comes directly from the current record, independently of all prior read replies. The target word width can address this polynomial universe and the RAM convention initializes memory to zero. The algorithm touches at most $N$ flags and changes each touched flag at most once. Including the input scan its time is $O(L/\log L)$. Stable radix sorting is an alternative using $O(N)$ words of dense workspace.

Consequently the preprint's network theorem already forces $\Omega(w^{1+\sigma})$ volume per input record in an exact trivalent implementation of this particular $O(N)$-step computation, even with *zero* bit resets in addressable working memory. The [general simulation concentrating writable memory](normalizing-stores-in-a-sat-solver.md) cannot by itself eliminate this network cost. Any attempt to contradict the list theorem from a fast general SAT solver needs something more specific than a small circuit for every such bit-write-once run. Historical priority for the combined statements has not been established.
