# A proof-length criterion for the next pair of elapsed-time witnesses

Fix $k=1,2,3$ separately. The objects tested below are ordinary proper ASCII 3-CNFs. A clocked description includes a deterministic word-RAM program, its logarithmic word-width coefficient and a positive integer multiplier $a$. Its deadline is $a(N+1)^k$ on a file of $N$ physical bits. All integer constants are explicitly binary encoded. The RAM has unrestricted work memory in its address universe. A legal program that decides SAT may return its correct verdict after its claimed deadline.

There is one specified native program and one sound finitely axiomatized arithmetic proof checker for each exponent. The assertion $J_h$ about that program says it has not reached its return-one location by step $2^h-1$ at native word width $h$. Let $L_h$ be the least literal bit length of an accepted arithmetic proof of $J_h$. All widths below use this same program, sentence template, checker, and finite-alphabet proof encoding. The parameter $h$ is separate from the bit length $N$ of an actual SAT query.

* **Unconditionally**, $J_h$ is true, and $L_h\le K h^4$ for all large $h$ for a fixed constant $K$. The arithmetic theory includes two specified true control-flow axioms. The finite-reflection argument establishing this particular constant-factor upper bound is given in the [companion note](fixed-cap-reflection-on-the-native-program.md).
* A width specifies a satisfiable old formula $B$ with a supplied assignment and a finite program budget $c$. If $L_h\le h^4$ at a sufficiently large such width, an effectively generated finite list contains **two strict extensions of $B$**, one SAT and one UNSAT, on which **every globally correct listed program misses its own $a(N+1)^k$ deadline**. Each witness retains the old clause-body bytes and all old variable names. Its multiplier applies to its own new encoded length. The list also supplies an actual erroneous decision file for every bounded group test defined below. The two signed witnesses need not have equal length.
* For every fixed valid tag $(B,\beta,c)$, exactly one of two cases holds. If every group test at that tag has an erroneous file, then $L_h=O_{B,\beta,c}(1+\log h)$ on its whole sufficiently large width progression. If even one group test is correct throughout the image of $B$, then $L_h>h^4$ on that progression at every sufficiently large width, and that group yields an $O(N^k)$ solver for ordinary SAT.

Thus there are actual short proofs on each finished budget and a constant-factor near-cap proof even on a budget whose status is unknown. The missing step is to cross the **same** cap $h^4$ at a valid width for each next budget. A proof of length $K h^4$, for an unspecified $K$, gives no single counterexample at that width. The earlier [nested exhaustion](nested-satisfiable-seeds-for-ram-exhaustion.md) already characterized a time separation by the indefinite success of an unbounded search preserving old clauses. Here an accepted bounded proof restricts the search for each error to old recorded files or prefix queries that a particular program actually issued, all of length polynomial in $h$.

## A length-preserving reduction into extensions of an old formula

Take a canonical proper $B$ with a checked satisfying assignment $\beta$ on its occurring names. Write $g_B(Q)$ by replacing the header, copying the entire old clause body, and appending a renamed proper $Q$ and one satisfiable positive triple on three extra names. Choose distinct decimal namespaces above the old declared variable maximum for the translated names and for the final triple. For example, prepend a fixed nonzero tag of more digits than the old maximum to each normalized decimal name of $Q$, using a different equal-length tag for the final triple. Use a header bound at least the maximum of the old declared bound and all translated names. Unused declared variables are allowed. The appended records ensure strict growth on a canonical seed, with header counts that never shrink in digit length. The old bytes after the header occur verbatim at the start of the new body. For fixed $B$ this costs $O_B(N+1)$ physical bits and deterministic word steps. Every old assignment satisfying $B$ extends precisely when $Q$ is satisfiable. It is enough to test canonical proper $Q$. The journal gives a physical linear-length and linear-time reduction from arbitrary ordinary CNF to proper 3-CNF. [Reduction and encoding conventions](exact-network-ceiling-for-ordinary-sat.md)

For each subset of the raw clocked descriptions at budget $c$, use two decision procedures on $g_B(Q)$. The first returns YES if any member returns YES by its deadline, and NO otherwise. The second returns NO if any member returns NO by its deadline, and YES otherwise. The procedures are defined even for the empty subset. Timeout or an invalid return supplies no timely vote. The underlying programs may be untrustworthy. Record a failure of the **whole procedure**, with its subset, mode, tag and physical input file. If all members really are correct deciders, a wrong answer by the first procedure requires a satisfiable input on which every member timed out. A wrong answer by the second requires the same on an unsatisfiable input. These statements also hold for timeouts plus honest partial programs, with failure to return promptly in place of elapsed time to a final answer.

For a fixed finite group, evaluating this test takes $O(N^k)$ standard RAM steps for a suitably large fixed word-width coefficient. Compile the finite instruction bodies or interpret their fixed code at constant cost on that machine. Use disjoint tagged ranges for the guest memories, initialize their packed inputs, mask operations to their own word widths, and maintain their clocks. A fixed number of limbs suffices for the clock and addresses. Choosing a larger fixed word coefficient covers the tag and guest widths. Direct evaluation of native multiplication, division and the fixed elementary operations is then available with fixed overhead. Thus correctness on the entire image of $g_B$ implies a genuine $O(N^k)$ ordinary SAT solver, by first applying the linear reduction. Ignoring one wrong answer by each individual program would be unsound: two programs can err on different files and their AND can remain correct everywhere those errors occur.

## One native run for all code budgets and all seeds

Encode a finite tag $(B,\beta,c)$ by a positive integer $j$ with a literal self-delimiting binary representation whose decoder runs in polynomial time in the code length. In particular the literal seed, displayed assignment and code for the integer budget have total bit length bounded by the encoded tag length. At $h>0$, read $j=v_2(h)$, the number of trailing zero bits in $h$, and decode it if valid. Each fixed tag occurs on the whole progression $h=2^j(2u+1)$. Permit it only when $4^c\le h$, an eventual condition on each such progression. Check the capacity condition with a capped comparison before constructing exponentials. The literal old seed costs $O(1+\log\log(h+2))$ bits, so renaming by a prefix of at most its length keeps every varying-tag query polynomial in $h$. A malformed tag, a bad assignment, or a failed capacity check stays quiet. The binary representation of $j$ has $O(1+\log\log(h+2))$ bits. Include all well-formed binary clocked texts of length at most $c$. One may also include the two fixed, total assignment-enumerating solvers described below at multiplier one, at *every* budget. This makes even the initial stage contain correct ordinary solvers.

A fixed dovetailed tape learner enumerates tags, their group tests, and canonical $Q$, evaluates each clipped decision and computes the exact truth of $Q$ by finite search. For each actual disagreement it can emit a complete tagged record with the literal $g_B(Q)$ file. Arrange that it also emits $\mathrm{DONE}(j)$ after recording a disagreement for every test at that tag. Use only completed records. The selection, dovetail and outputs do not use an unverified SAT answer or any arithmetic proof search. For every erroneous fixed test a failure is eventually printed. Stop the warmup after **$h$ learner tape steps**, so every file in its output has length $O(h)$ bits. Keep $\mathrm{DONE}$ permanent once printed. If this tag has a $\mathrm{DONE}$, the native program goes quiet without trying any proof. Otherwise skip only the particular tests whose authenticated errors have already been printed.

At every remaining test build the same proper file for the existence of a proof of **this very $J_h$** with at most $b=h^4$ literal bits. A final marker and fixed zero padding encode all lengths up to the cap in $b+1$ bits. The verifier is deterministic and polynomial-time on these strings. A standard bounded computation encoding gives an ordinary proper file $F_h$ of polynomial-in-$h$ physical bit length. From the leftmost proof bit onwards, ask the group test about $g_B(Q)$, where $Q$ is $F_h$ pinned to the current proof prefix followed by zero. Encode pins using the usual forced-false anchors so the result remains proper. Append zero on YES and one on NO. After the $b+1$ choices, decode the resulting literal candidate and run the genuine syntactic checker on it. Return one only if this check accepts. Otherwise continue to the next test. The program can use one common run or identical sites. It uses no unconditional prephase that can latch independently of the retirement guard. [Bounded-run encoding in physical DIMACS](local-sorting-for-parsimonious-ram-encodings.md)

All of these tests, including the last verification, finish before the horizon for all sufficiently large $h$, even with wrong votes. There are at most $2^{c+1}+2\le2\sqrt h+2$ eligible texts including the two fixed solvers. Enumerating two modes for every subset gives $2^{O(\sqrt h)}$ tests. The constituent multipliers and word-width coefficients are $O(\sqrt h+1)$. A private simulated word or address therefore needs only $O((\sqrt h+1)\log h)$ bits on files of polynomial length. Test the guest run for at most $O(\sqrt h+1)(N+1)^k$ steps. Even a linear dictionary of all touched guest cells, with full address comparisons and bitwise simulation of word operations, gives a polynomial-in-$h$ cost per vote. This polynomial slowdown is for the **exhaustion program**. The preceding fixed-group standard RAM cost is separately $O(N^k)$. Reuse or clear scratch between trials. Tags, prefix files and the subsets are generated sequentially, and the whole native work $2^{O(\sqrt h)}h^{O(1)}$ fits the $2^h-1$ time and $2^h$-bit space of the auxiliary host with slack. All file lengths in the resulting list are polynomial in $h$.

## What a single short proof buys

For every finite theory code $\gamma$ perform the construction with its syntactic proof checker and with the program's own literal seed, as in the fixed-cap note. All-latch would exhibit an actual checked $\gamma$-proof of its own quietness of length at most $b$. Also a completed $\mathrm{DONE}(j)$ in the common $s$-step prefix, $s\le h$, implies quietness for that tag. These are true first-order control-flow implications for **all** theory codes, including inconsistent ones. Fix the native constructor before adding these two universal implications as axioms to the finite arithmetic base in the companion note. Call the resulting true finite theory $A$ and instantiate the constructor on its axiom-list code. This is a deliberate proof-presentation choice. In particular it does not assume the soundness of $A$ inside $A$. Externally $A$ is sound, so a genuine completed return would contradict the very arithmetic proof that triggered it. Thus $J_h$ holds. The finite-reflection proof in the companion note needs only the uniform syntactic extraction implication, a fixed bounded-depth end template, and finitely many true axioms of fixed complexity. It applies here too, giving $L_h\le K h^4$ for one fixed $K$ independently of the varying tag.

Suppose now that a literal $A$-proof at the cap exists. The root proof query is satisfiable. On the actual prefix path of any active test, if all of its votes are correct then each choice retains at least one valid completion. The final length-coded string must be a proof. Its genuine check would return one, contradicting $J_h$. Hence the test was wrong on at least one of **its own** prefix queries. A retired test already has a concrete recorded wrong file. This argument also covers the $\mathrm{DONE}$ branch, where all failures come from the warmup. The program need not recognize which current vote is wrong. The proof makes the offending file effectively recoverable from the finite list by computing ground truth. A self-referential formula without an accepted short proof need not produce any wrong vote. [Lean proofs of recovery on the actual path, retirement, and signed timeouts](../lean/FinitePortfolioProofReceipts.lean)

Take the subset of all eligible underlying programs which decide all ordinary SAT inputs correctly, with each of their encoded clock multipliers. Both of its modes were among the tests. Their wrong files give the two common elapsed-time witnesses in the statement. This existential selection uses no decision procedure for global machine correctness. The finite output can simply list a verified wrong file for every group, including this subset. If a single eligible group is correct throughout the extension image, then it never retires and, at a sufficiently large valid width, its trial would recover any proof within the cap. Therefore $L_h>b$ at every such width, without a separate assumption that the program index stabilizes.

If every test at a fixed tag is erroneous, let $s$ be any standard learner time by which its $\mathrm{DONE}$ was printed. That particular finite computation has an arithmetic proof, possibly enormous, with length depending on the tag and $s$ alone. The skip axiom proves the whole corresponding tail. One can state it using the low-bit term $H_j(u)=2^j(2u+1)$, expressed as a fixed chain of binary numeral constructors. For fixed $j,s$, elementary arithmetic proves that $H_j(u)$ has this tag and is sufficiently large for the guards for all sufficiently large $u$. The remaining finitely many quiet instances have individual arithmetic proofs by finite computation. Combining them gives one $A$-proof of $\forall u\,J(P(\gamma_A),H_j(u))$. Instantiating this fixed proof with the binary numeral for $u$ takes $O_{j,s}(1+\log h)$ symbols. Apart from a finite edge case the Horner term for $H_j(\bar u)$ is literally the binary numeral for $h$. The cutoff in $O_{j,s}$ is not uniform. It is obtained here from an actual completed retirement record, not from a speculative proof of stabilization.

This also characterizes a single arithmetic theorem for a fixed budget and seed. Every group has an error on that image if and only if $A$ proves $\forall u\,J(P(\gamma_A),H_j(u))$. The forward implication is the actual retirement and specialization argument. For the converse, a fixed universal proof produces $O_j(\log h)$-length instances on this progression, which a group correct throughout the image would forbid. Every instance is true externally in both cases.

## How far the successor can be run

Starting with a fixed positive $B$, increase $c$ by one. Search the new tag's progression for a proof passing $h^4$ at a valid width above the uniform completion threshold. An alternative search is to wait for the finite group's $\mathrm{DONE}$; dovetail the two. A completed proof gives the bounded menu above. A $\mathrm{DONE}$ directly provides the menu of authenticated failures and also gives short proofs on its tail. Use a common slow satisfiable witness as a next seed if a suitable correct sublist is designated. To produce an effective chain for *all* eligible codes without identifying the globally correct sublist, eliminate codes with observed wrong halts by running a separate full, unclocked error search in parallel. The remaining finite list eventually consists of partial verdict-sound programs and possibly erroneous programs whose wrong halts have not yet been found. Among the enumerated positive and negative candidate files search for a pair where every not-yet-eliminated machine either has a proved wrong halt on a proper file or exceeds its deadline on both members. Once all actually wrong-halting codes have been identified, the OR and AND errors for the remaining honest sublist guarantee that the finite check succeeds. Timeout-only partial programs can remain in this sublist. Choose the positive member, obtain an actual satisfying assignment by exhaustive search and repeat. This produces an actual computable choice whenever the new budget is completed. No step assumes a time bound for doing the mathematical search itself.

If SAT has no $O(N^k)$ solver then every fixed group at every satisfiable seed has some error in that seed's image, by the linear reduction and fixed-group closure. Thus every step eventually succeeds. If such a solver exists, a fixed, properly clocked description of it appears once $c$ is large enough (enlarge its multiplier for any small exceptional inputs). Its singleton is correct on every seed's image, and blocks success at that budget. For a fixed seed the target is also equivalent to there being width tags for unbounded budgets with a proof at or below cap at sufficiently large widths. The cap test localizes actual elapsed-time failures but the all-budget termination result remains conditional. In particular, it gives no a priori bound for how large the new encoded formulas must be compared with the old ones, or an extension at the very next byte length.

### Why a computable maximum test length is a substantive requirement

For the original class of individual clocked texts up to $c$, use the deterministic verdict NO on timeout. Let $W_k(c)$ be the largest first error length among texts that ever err on a proper SAT file, with value zero for an empty set. If SAT is outside the stated time class, every such total clipped decision procedure eventually errs. Scanning lengths in order and evaluating ground truth until each well-formed code has its first error therefore computes $W_k$. Without that hypothesis the halting oracle still computes $W_k$ by deciding which finite searches to perform.

Conversely, suppose an $O(N^k)$ correct solver $S$ exists. Hardwire it and a sufficient multiplier. From a blank-tape machine $M$ compile a **globally correct** SAT solver that simulates $M$ for $N$ steps, runs $S$, and delays the correct verdict for $(N+1)^{k+1}$ extra steps if a halt was observed. An explicitly large multiplier covers the first two operations for every $N$, including the cost of the fixed simulation. The no-halt code always meets that clock. A halting $M$ eventually makes the code miss the clock on every sufficiently large legal input, including satisfiable ones where the default NO is wrong. A computable upper bound on $W_k$ would decide whether $M$ halts by testing through the bound at the compiled code size. Thus $W_k$ has the Turing degree of the halting problem in this case. Even an upper bound required only for first late files of genuinely correct but asymptotically slow solvers cannot be recursive in this case, by the same construction testing whether the correct verdict was delayed. This last claim imposes no requirement on a correct solver which always meets its clock. The result does not imply that the cutoff for the *nested portfolio as a whole* grows at a Busy Beaver rate. [Radó, *On non-computable functions*](https://doi.org/10.1002/j.1538-7305.1962.tb00480.x)

### A nonempty initial clock census

For a nonempty base case the two fixed programs scan full assignments one at a time, stopping at the first model, with opposite initial bit values and binary count directions. For an arbitrary old positive $B$ force $m$ fresh variables to zero and $m$ others to one, using all four choices of signs of two free, distinct anchors to express each unit as four proper clauses. The result is satisfiable. Add an opposite pin for one of those variables to get an unsatisfiable extension. In any ordering of coordinates, the ascending count before a model on the positive input is at least $2^m-1$, since it must set $m$ ones. From the opposite endpoint at least $2^m-1$ positions must likewise be passed since it must set $m$ zeros. Each enumerator executes at least one native instruction per assignment considered. The negative input exhausts all assignments. Encoding costs $O_B(m\log(m+2))$ bits. This supplies signed deadline failures at the first budget for any fixed $k$ and any fixed multipliers **on the actual extension image** by choosing $Q$ to contain these fresh pins, and taking $g_B(Q)$ on both signs. The extra positive triple and namespace translation do not affect the bound. Choose an encoding in which the empty text is invalid, so budget zero adds no unknown solver.
