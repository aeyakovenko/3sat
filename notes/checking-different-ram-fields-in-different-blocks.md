# Checking different RAM fields in different time intervals

A deterministic RAM execution of length $T$ can be certified in six alternating quantifier blocks when, in each time interval, one can predict either its writable load replies or its store events. The choice may change at every boundary. The maximum cost of one prediction enters additively. A version that retains selected bits of the actual words gives a strict improvement on a permutation computation. Neither version currently supplies the required estimates for unrestricted SAT.

## Six messages

Use the separate-load/store RAM with immutable input, zero-initialized work memory, a constant-size controller, and word width $w=O(\log(T+|x|+2))$. Take a public time cap and idle after halt. The terminal controller must indicate the requested verdict. A chart divides the time axis into at most $P$ consecutive nonempty blocks of at most $B$ instructions. Boundaries and modes may depend on the whole input and run. In an R block a fixed clocked point evaluator must predict the returned word at every writable load. In a W block it must predict whether each instruction stores, and its address and payload if it does. An R evaluator may give arbitrary answers away from loads. The evaluator sees the original input, global advice, the directory, the time and block index. Any local descriptions are included in the common advice of $S$ bits. Queries start with clean private scratch and take at most $q$ steps. Optional per-block programs require an explicitly priced uniform interpreter.

**Certificate theorem.** A fixed alternating verifier is sound on every input and complete on each run admitting such a chart. The total of deterministic path work and all transferred choice bits is
\[
             O\bigl(S+(P+B+1)w+q\bigr).
\]
Use constructible public caps, or include numerical caps within one public total budget and enforce it on every branch. All guessed addresses, times, lengths and offsets must fit in the chosen word convention, with constantly many words when required. The earlier one-field verifier uses either chronological store events on the whole run or load replies on the whole run. [Whole-run field verification](one-certified-index-for-all-writes-of-a-ram-run.md) · [Incoming reads and canonical block replay](live-segment-snapshot-queries.md)

1. Guess the common data, the block directory and controllers at the boundaries. Pay $O(Pw)$ bits for mode, endpoints, controller and indexed offsets. Check a gap-free partition of the specified clock, all size bounds, the initial controller, and the terminal verdict. Charge any indexing data outside this directory to $S$.
2. Universally select a block.
3. Guess its full local transcript, including controllers, access events and one source time or initialization marker for each writable load. This uses $O(Bw)$ bits.
4. Universally challenge a CPU transition, a predicted field, an endpoint, or a load's named source and an arbitrary intervening time. Check that the transcript follows the CPU, handles immutable input directly, matches both boundary controllers and matches the chosen field. A store source must lie strictly before its load and have the right address and payload. No subsequent matching store before that load is allowed. An initialization marker requires the initial value and excludes matching stores throughout the prefix.
5. To check the preceding tests, at most two chronological store queries may be needed. On a W block query the evaluator directly. On an R block guess a raw local transcript from the directory's initial controller to the queried position and extract the proposed store there. This costs $O(Bw)$ further bits, even when two raw transcripts are needed.
6. Universally check a local step of either supplied raw transcript. The CPU transition is deterministic when the R evaluator supplies each writable load's reply. This check uses at most a constant number of point evaluations. No sources of those raw replies are recursively requested.

One may pad all six messages to their caps. Out-of-range universal indices give a vacuous challenge. Existential transcripts must have the prescribed lengths and legal encodings. Each transcript includes its adjacent controller rows, implements idle precisely, and represents a constant number of words per step. Indexing an outer message or a row uses native random access to materialized words. Reading or packing a whole message still fits its stated bit budget.

For any fixed first message, including a dishonest one, define a global proposed store field $G$. On W intervals it is the clocked evaluator's claimed event. On R intervals it comes from deterministic raw replay with the proposed R replies and the claimed starting controller. The last two messages force any store query to have this unique answer. Malformed point encodings can be assigned a fixed default. A passing third message describes CPU-legal steps and stores equal to $G$. For R blocks the equality follows from deterministic raw replay. For W blocks it is tested. Each of its loads agrees with the latest matching write in $G$, or with initialization. Choosing passing third messages for every block and concatenating them now produces the genuine run by instruction induction. Conversely the genuine messages pass on an honest chart. In particular a third message cannot change its alleged writer after seeing the intervening time.

A fixed polylogarithmic-time decoder is unnecessary. For example, $P,B,S,q\le T^{1-\epsilon}$ for fixed $0<\epsilon\le1/2$ gives a polynomial saving on any length regime with $w=O(\log T)$. The transcript of the queried R interval is guessed after the store query is named, which avoids $B$ successive point evaluations on a path.

## Consequence for every proposed near-linear SAT solver

Assume a reference ordinary SAT decider takes $O(N\log^a(N+2))$ time at fixed $a$. Use the journal's pinned pair at scale $M=2^j$ and let $D$ be any fixed deterministic program correct on those pairs. Fix a polynomial clock $M^p$ and a uniform point evaluator. For each pin at every sufficiently large scale where $D$ halts by $T\le M^p$, every oriented description of its genuine run obeys
\[
       S+q+(P+\lceil\sqrt T\rceil+1)\log(M+2)
          \ \ge\ M/(\log(M+2))^{C}
\]
for some fixed $C$. Here $P$ counts the original, possibly input-dependent blocks, with no bound on their lengths. The evaluator may consult the original directory. Subdivide into pieces of at most $\lceil\sqrt T\rceil$ steps and retain that directory, adding one reference to the original block per new piece. There are $O(P+\sqrt T+1)$ pieces and their additional controllers fit the displayed cost. [Pinned solver runs and deterministic color-tester bound](priority-pinned-sat.md)

Indeed, one can test the claimed terminal verdict on the locally generated pinned input with the six-message verifier. Guess clocks and directory inside the common budget. Enforce every cap even on dishonest data. Each bounded alternating block can be eliminated under the reference hypothesis by materializing a bounded native computation as a proper ordinary SAT call, complementing for universal choices. Six eliminations lose a fixed power of $\log M$ and the generated original formula is queried locally from the scale and pin. Thus a chart of total cost below $M/\log^C M$, for sufficiently large fixed $C$, gives a sound deterministic color tester in $o(M)$ steps on the scales where it succeeds. This contradicts the pinned theorem. Taking the fixed program $D$ to be the reference decider itself gives the stated obstruction on runs of every hypothetical near-linear SAT solver. The missing unconditional premise for a SAT speedup is a uniformly affordable chart on sufficiently many executions of the native diagonal machine. The journal's fixed-depth elimination criterion specifies its precise logarithmic margin. [Bounded alternating elimination and the ordinary SAT clock](alternating-native-speedup.md)

## What switching fields can hide

Fix any native transducer emitting a word in each of a sequence of publicly indexed slots of a fixed-duration simulation. Write each output to a work cell and immediately load it back. If that cell already has a use, save its value in a register before the pair and restore it afterwards. A whole step record can be echoed with constantly many such pairs. A block containing both marked instructions discloses the payload through either orientation. At most $P-1$ disjoint pairs are cut by a directory of $P$ blocks. Materialize their outputs and indices in $O(Pw)$ additional bits. The directory, direct point evaluator and sorted patches then recover every original output with $O(q+\log(P+2))$ steps per query. Thus a universal short-chart theorem for these genuine fields would also provide short indexed descriptions of complete chronological word outputs of arbitrary native transducers. The standard implementation fixes the number of padding slots per source instruction, including each possible branch and an idle suffix.

## Certifying only the bits needed on this execution

Let the advice additionally describe a fixed mask $m(a)$ for each work address and masks $r(t,k)$ for the registers at each time. Include these descriptions in $S$ and their point evaluation in $q$. Keep the program counter exact. The canonical machine clears unretained register bits after each instruction, stores word $v\mathbin{\&}m(a)$ and returns a projected word on each writable load. Its chart describes only these canonical fields. The interval headers hold projected controllers. The initial controller is the projection of the true one.

Add a local universal test to the fourth message. Give one concrete filling of the current register words consistent with their masks, and, at a writable load, one concrete reply consistent with the canonical reply and its address mask. Require the same effective address as the canonical transition for every memory access, the same successor PC or verdict, the same next register projections and the same projected store value when applicable. Read immutable input at the checked address. A filling that disagrees with the current register projections, or whose putative load value disagrees with the preserved bits at the already verified address, places no requirement. Check address agreement before excusing an inconsistent load value. The complete challenge uses $O(w)$ bits. In the fifth and sixth messages replay the deterministic canonical machine. The soundness proof above gives its genuine canonical history. The additional test now inductively maintains that actual registers and memory project to that history. This works with entirely malicious masks. Completeness requires local stability for all fillings at a challenged canonical row, including fillings that never occur on the real run. The same pinned consequence holds with $S,q$ including the masks. [Lean simulation lemma](../lean/ProjectedRamFieldSteps.lean)

This changes which values the certificate must encode. Take a word-aligned permutation $\pi$ of $[m]$ and $m$ immutable guard words. Scatter $i$ into work cell $\pi(i)$ in a public-duration loop. In a second loop load cell $j$, echo the returned word to a separate scratch cell and load it back. OR its bitwise AND with guard $j$ into an accumulator. Return whether the accumulator is nonzero. This program takes $\Theta(m)$ native steps. Nonzero guards can change the answer.

On inputs with all guards zero, use zero masks on the work banks and on the temporary inverse values, and full masks on addresses, guards, the accumulator and loop control while they are needed. Dedicated registers for these roles make all masks constant. Input permutation addresses still have their true value. Every filling of the inverse temporary yields zero at the AND. The whole run has constant-description R replies equal to zero with constant query latency. Dividing it into $\Theta(\sqrt m)$ blocks yields verification cost $O(\sqrt m\log m)$.

For genuine unmasked fields, any fixed constant-input-probe point evaluator and $P=O(\sqrt m)$ blocks need $S=\Omega(m)$ for some permutation at each sufficiently large $m$. The echo argument gives all inverse values with $r=S+O(P\log m+\log m)$ bits. Directory search and patch lookup do not probe the permutation. For a fixed advice string, request $k=\lfloor m/(4(q+1))\rfloor$ distinct targets, where $q$ bounds the number of permutation probes per inverse query. Explicitly verify every reported preimage with one more probe. At most $k(q+1)\le m/4$ adaptive queries can then hit all $k$ targets with probability at most $4^{-k}$ on a uniform permutation. Conditional on earlier probes, fresh positions have uniformly random remaining images. Padding to the probe cap gives sampling without replacement. A union bound over fewer than $2^{r+1}$ advice strings proves the claim. The immutable guards are fixed, and each packed permutation access reveals at most one entry in the stated word alignment. This separating example fixes query latency. Allowing it to increase admits classical permutation-inversion tradeoffs. The example prices live arithmetic on a promised value pattern and does not provide any chart bound on general SAT or diagonal runs. ## A residue projection that defeats every choice of bit masks

The local test also permits arbitrary efficiently evaluated word projections at each address and a jointly projected controller at each time. Specify the codes of concrete words and controllers, together with a fixed, clocked transition routine on the codes. The verifier checks concrete fillings in the forward direction, so different concrete and coded alphabets are allowed. On every filling with the advertised controller projection, test the concrete opcode, effective address, projected store payload and projected successor against that routine. At a load, quantify over concrete incoming words mapping to the canonical memory word. The boot and final tests must certify the true initial projection and force the same verdict for every concrete final controller in the projected class. Charge both projection and canonical transition costs to $q+1$. The six messages and the induction apply without change. The Lean theorem allows different concrete and canonical value types. It proves the local simulation induction. The directory, choice-bit costs, permutation count and SAT transfer above are manuscript arguments.

For a strict separation from the whole bit-mask model, use $m$ aligned entries, word width large enough for $3m+2$, and immutable flags $h_i\in\{0,1\}$. Scatter $3i+h_i$ to cell $\pi(i)$. Scan in public order, echo each payload through a separate fixed scratch cell, compute its remainder modulo three **from the reloaded value**, and OR the remainders into a sticky accumulator. Signal nonzero at the end. Thus the data themselves enter a numerical test. When every flag is zero, project each work word to its residue modulo three. The R replies throughout this computation are all zero. Retain exact loop counters, input addresses and accumulator, while the two data temporaries can hold residue representatives. Each transition on the canonical row is stable. On a native basis with unsigned remainder this gives constant query and local-transition costs. If the instruction basis supplies division, implement remainder as $z-3\lfloor z/3\rfloor$. After the quotient instruction use the joint projection $z-3q$ and after the multiplication use $z-p$ for $p=3q$, with arithmetic modulo the word modulus. These projections carry the same residue across the two internal steps; canonical representatives can take $q=p=0$ and $z$ equal to that residue. Initially $z-3\lfloor z/3\rfloor$ is in $\{0,1,2\}$. The other live registers keep their own projections. Choosing $P,B=O(\sqrt m)$ again gives $O(\sqrt m\log m)$ verification work and transferred bits.

In contrast, every locally stable bit-mask certificate on the same all-zero-flag run has the **full bit mask on the scratch cell**. Immediately after a marked store, toggle any unretained bit of the scratch word and keep every other register and cell unchanged. This alternative concrete state has exactly the same projected state. The just-stored word was a multiple of three. Toggling bit $k$ changes its integer value by $+2^k$ or $-2^k$, neither divisible by three. Reloading and testing it makes the sticky accumulator nonzero, whereas the genuine program returns zero. Starting the local simulation induction at this canonical row would force equal terminal verdicts. This proves the full-mask claim even for masks chosen after seeing the entire permutation. The argument uses an alternative state admitted by the certificate's universal local test, without any assumption that the scatter phase could have produced that state. [Formal one-bit and simulation lemmas](../lean/ProjectedRamFieldSteps.lean)

Consequently every marked uncut pair discloses its entire word under either bit-mask orientation. Division by three recovers the required inverse position. The preceding counting proof applies to the combined advice, including all mask descriptions. For some permutation at each sufficiently large $m$, $P=O(\sqrt m)$ and constant point-probe cost imply $S=\Omega(m)$ in that model. The residue construction works for every permutation with the same fixed projections. It applies to this program's computed data and gives no uniform residue projection for an arbitrary native instruction stream.

## Complete information can have a cheaper forward representation

Take two permutation tables $\pi,\tau$ on $[m]=\{0,\ldots,m-1\}$. Scatter $i$ to $A[\pi(i)]$ and in a separate scan scatter $i$ to $B[\tau(i)]$. For each $j$ in public order, read $A[j]$, store it to a fixed scratch cell and reload it, then compare the **reloaded** word with $B[j]$. Accumulate the OR of all mismatches. Use separate fixed-duration loops so the marked instructions have publicly computable times. On equal permutations the accumulator stays zero.

Every successful locally stable description on such a run preserves every possible distinction at the scratch cell. Immediately before a scratch reload, changing the genuine payload $y$ to any other word makes that iteration mismatch and changes the terminal verdict. No other part of the state need change. The local simulation from that time therefore implies that the fiber of the scratch code at $y$ is a singleton. The same scratch cell takes every $y\in[m]$ during the run.

Yet constant-cost forward coding suffices on every equal-permutation input. Extend $\pi$ by the identity outside $[m]$, obtaining a bijection $p$ of the whole word alphabet, and use
\[
                       f(y)=p(y)\mathbin{\oplus}p(0)
\]
on the work banks, scratch, and data registers. The code of zero is zero. The marked payloads and both table reads at index $j$ have code $j\mathbin{\oplus}p(0)$. Addresses, counters, and the mismatch flag remain exact. The canonical machine computes the code of a raw scatter counter by forward evaluation. It can compare the coded lookup words directly since $f$ is injective on the full word alphabet. The local filling test establishes the safety of a comparison on the actual row without inverting $f$. Every R field has a constant-size routine with constant query cost. This yields the same $O(\sqrt m\log m)$ path bound. On other inputs the full local checks still enforce soundness. [Forward code and injectivity in Lean](../lean/ProjectedRamFieldSteps.lean)

If the certificate additionally supplies a bounded-probe left inverse for its scratch payload codes, the echo construction twice becomes observable, once in the code and once in the concrete word. At each uncut marked pair the appropriate point evaluator supplies the code of $y$ and this inverse gives $y=\pi^{-1}(j)$. Patch at most $P-1$ cut pairs. Thus for some equal-permutation input, any such description with $P=O(\sqrt m)$ and constant total input probes per code and inversion requires $\Omega(m)$ bits of advice, including the inverse's own advice. On the equal-input family an access to the second permutation reveals the same single forward entry as the first. The elementary counting proof above applies. Every scratch payload in this example is essential to its future verdict under an isolated change. The saving comes from the cost of checking computations on the forward codes.

In fact any cheaply evaluated injective map $f_a$ of the word alphabet into itself can be used here without an algorithm for performing native arithmetic on its codes. Require the actual load reply or store payload only in the form $f_a(v)$, while store addresses remain concrete. An R evaluator may use the claimed effective load address as well as time and block. Keep genuine boundary controllers. In message four universally test injectivity on a chosen $a,u,v$; finite equal-size domains make every passing map a bijection. Define $G$ in coded payloads. A raw R transcript in message five now guesses **concrete** register words and concrete load replies. In message six check the native transition and compare the forward code of a guessed reply to its claimed code. From the boundary controller this determines a unique raw replay even for arbitrary native arithmetic or data-dependent addresses, since a coded reply at the calculated address has exactly one preimage. For a challenged consumer in message four, compare its concrete reply's forward code with the last writer's coded payload, or with $f_a(0)$ at initialization. Injectivity then gives equality of the concrete words. Input-dependent code maps are allowed, subject to the same budget and universal tests on every input. This also gives the preceding SAT-solver tradeoff for arbitrary such one-way representations of the two chronological fields. Producing an affordable coded field on an unrestricted computation remains open.
