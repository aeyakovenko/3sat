# The packed RAM reduction used in the logarithmic band

This supplies the two model-specific ingredients for the numerical exponent in the [time–space theorem](sat-time-space-band.md). The reference problem has a read-only binary encoding. There is no unit-cost operation on an arbitrarily long integer. All words encountered in a bounded computation have $O(\log H)$ bits. Constants may depend on the fixed machine. The three logarithms below count **encoded bits**, including the bits naming variables.

## A virtual formula for a bounded computation

Take a fixed, finite-instruction, nondeterministic word RAM, $m$ packed public input words and a public upper clock $h$. Let $H=\max(h,m,2)$ and $L=\lceil\log_2(H+2)\rceil$. The width $w=O(L)$, input layout and clock are known, and may be supplied as metadata. The standard bounded-run relation uses the following certificate.

1. Write the control and register states at each step. Check the initial state, final verdict, and adjacent instruction transitions. A guess instruction leaves the new word unrestricted. Idle halts pad to the clock. Each instruction emits a constant number of memory-access records with bank, address, timestamp, event order, read/write bit and value. Include one initialization record per public input word and constrain its bits to the public word. Distinguish the read-only input bank from initially zero work memory. Include dummies out to a common power of two. There are $O(H)$ records of $O(L)$ bits each.
2. Route records through a Beneš permutation network. An existential switch bit either preserves or exchanges an entire pair of records; the two output lanes share that switch. Check adjacent routed records are sorted by key (bank, address, time, within-step order), with dummy records last. A first read of an uninitialized location must see zero. A later read of an address must match the preceding record's value there. Writes set the carried value, and valid reads preserve it. Input initializations precede ordinary reads. This certifies the chronological results of every indirect access. Conversely any correct transcript can route its records into the required order. To see routability, pair the two inputs and two outputs at the outer switches, and draw an edge for each requested connection. The resulting bipartite multigraph has degree two. Color alternating edges of every cycle in two colors; direct the corresponding traffic into the two half-size subnetworks and recurse. This proves routing even with repeated record values by treating wire positions as distinct. [Routing networks in local reductions, Jahanjou, Miles and Viola](https://arxiv.org/abs/1311.3171)
3. The routing network uses $O(HL)$ switches, each acting on $O(L)$ bits. The local arithmetic and transition constraints use $O(L^2)$ bounded-fan-in gates per step. Ripple addition, subtraction and comparison use $O(L)$, a barrel shifter uses $O(L\log L)$, and multiplication by summing shifted rows uses $O(L^2)$. Integer division with nonzero divisor can use a guessed quotient and remainder, checked by $uv+r=x$ at double precision and $0\le r<v$ (here $v$ is the divisor and $u$ the quotient). Deal with zero divisor and signed conventions with fixed guards. A shift whose operand exceeds the defined range uses the specified instruction semantics. The whole verification has $O(HL^2)$ gates and constraints. Local gate-equivalence clauses, with repeated literals when needed, give a 3-CNF with that many clauses. All variable indices need $O(L)$ bits. The total binary length is $O(HL^3)$. In a representation requiring it, dummy clauses can ensure the variable-index width is also $\Omega(L)$.

**Packed access to the reduction.** It is insufficient to know that this entire formula could be generated in quasilinear time. Here is an indexing convention supporting random reads of its bits. Give each family of variables or clauses a consecutive range, padded with dummy slots. Use rectangular arrays for the time rows and the within-row gate and clause slots. For the router use (stage, wire, record-bit, fixed local slot). Padding each dimension to a power of two changes its size by a fixed factor; there are only a fixed number of dimensions. Router stage $j$ pairs wire $i$ with $i\mathbin{\mathrm{xor}}2^{d_j}$, where the butterfly dimensions $d_j$ run in forward and reverse order with the shared central stage counted once. Clearing that bit gives a common ID for the switch. All other large-index references are to an identical row, an adjacent row, an initialization index or an adjacent routed wire. The finitely many types of local records have constant fan-in.

Before starting the SAT solver, compile the **single-row** Boolean templates at the applicable width $w$; for every within-row clause store the three signs, source-family labels, within-row offsets and row-address rules. This costs $\operatorname{poly}(L)$ time and words, including the tables for padded slots. The router needs a table of $O(L)$ stage masks. To fetch a clause, determine its family, split its index into the large row or wire coordinate and the small template coordinates, read a constant number of template records, and combine their offsets and row coordinates by word arithmetic. An initialization constraint takes one selected bit from one public word. All variable numbers can be taken in contiguous bounded ranges of $O(HL^2)$ indices; unused index slots are harmless. In a fixed-width binary CNF list each clause has three fields of the same index width and fixed sign positions. Divide a requested bit address by the clause stride, then unpack the needed fields. With word division this is constant time. A read of one SAT input word intersects $O(1)$ clauses since their width is $\Theta(L)$ and the SAT word width is $O(L)$. The header has $O(L)$ bits. One such read costs $O(1)$ word operations after setup. This proof also applies to variable-length binary numerals when an accepted uniform subfamily with fixed-length literal numbers and fixed record strides is exhibited; the band note uses the fixed-width list directly.

The solver's own workspace is simulated in native memory; the reduction's read-only input is virtual throughout. When simulating a guest width on a larger fixed-constant-factor word width, mask the results or use a fixed number of limbs. Direct addresses in the SAT solver's writable store have magnitude at most $2^{O(\log(HL^3))}$ for a fixed solver. Input-generation scratch and the finite storage banks can be separately tagged. This yields the $A=a+3$, $B=b-2$ bounds in the band note. The local compiler uses only ordinary operations in the listed basis. A new primitive with a larger verification circuit, or an encoding that makes packed clause access more expensive, requires recalculating those bounds.

## Replaying one sparse snapshot

Serialize the fixed controls and registers followed by a sorted, duplicate-free list of (bank, address, nonzero value) triples and padding to the space cap. Every entry uses $O(1)$ words. A replay can check a selected snapshot, initialize a fresh simulated array from its list, and maintain its number of nonzero entries by reading the old word at writes. At the end check all listed entries of the claimed next snapshot and the total number of nonzero entries. This detects additional unlisted words without scanning the whole address domain. On real computations the number of such entries is at most the touched-word space bound. Replays from malformed or adversarially chosen snapshots have a clock and range checks; one may reject a candidate segment if the space bound is exceeded. In particular a real sequence has exact encodings; accepting every transition in a list forces that sequence to be the real run. Time for a segment of $v$ steps including both endpoints is $O(v+S+\operatorname{poly}(L))$. For **nested** checks enforce the size cap during replay from arbitrary endpoints too (using the nonzero count and a clock), so a false candidate does not expand the inner configuration bound. Keep the simulated nonzero cells in their directly addressed tagged bank; auxiliary replay code does not have to remember the history of locations which have become zero. Its own configurations have $O(S)$ nonzero entries even if a false replay touches additional addresses over time. Valid configurations of each wrapper have encodings of this size. Time and configuration length, as distinct from an accumulated touched-location count for a false wrapper run, suffice for the next checkpoint operation.

## The complementary hierarchy in this word model

For clarity one can diagonalize directly, avoiding an uncharged word-to-bit universal simulation at the very end. Fix a load/store instruction set with a fixed number of registers available to an encoded opponent. It can guess whole words. A fixed program with additional registers can use this ISA at constant overhead by spilling finitely many registers in a reserved bank. Its program text is fixed, including any fixed number of banks it needs. For the final opponent use one read-only input space and one writable space with bank tags on bounded addresses. Honest intermediate physical addresses below are bounded by $n_0^d$ for a fixed $d$. This normalization only needs to apply to the constructed opponent.

Choose an original physical word width $W=c\lceil\log_2(n_0+2)\rceil$ on inputs of $n_0$ bits, with fixed large $c$. A fixed universal machine $U$ reads an opponent description followed by padding and simulates that program on the **same input**, using the same $W$-bit instruction semantics and the same nondeterministic word choices. Accept if a rejecting branch is found within $O(n_0^2)$ universal steps. A counter cuts off every branch at this time and defaults to rejection if it has not observed one. This is a nondeterministic bounded-time language. The opponent's writable memory can be simulated at the identical address in an initially zero bank. The interpreter needs only its fixed registers for its clock, simulated fixed register file, program counter and parsing state. It may rescan the read-only description to fetch instructions. For **each fixed description** the time per simulated step at padded lengths is bounded by a description-dependent constant. Program constants can use a self-delimiting binary encoding; parsing and any malformed cases are covered by the universal clock. The universal program itself may have more finite registers than the normalized opponents.

If the constructed conondeterministic decider for this language took $o(n_0^2)$ time, run the test on its own fixed description with arbitrary sufficiently long padding. All its branches finish within the universal clock. Acceptance by $U$ would be equivalent to existence of a rejecting branch of the decider, contradicting correctness under universal acceptance semantics. This is the same complementary diagonal principle as FLMV Theorem 2.1, with constant simulation overhead for the fixed opponent on the selected padded inputs. [Bit-machine version and model details](https://lance.fortnow.com/papers/files/tst.pdf)

Here is the word-width choice in this application. The original hierarchy source simulates $W$-bit operations. Its addresses enter the **Boolean verification records as data**. The SAT solver does not physically address its simulation memory by such recorded values. For the final constructed opponent, every actual SAT call operates on at most $n_0^{2}\operatorname{polylog}(n_0)$ bits up to fixed constants (and at worst $n_0^3$ eventually). Its writable numeric addresses therefore lie below $n_0^{O(c_{\rm SAT}+1)}$ where $c_{\rm SAT}$ is the fixed SAT solver's width constant. Arrays of guesses, templates, records and snapshots use sizes bounded by $n_0^{O(1)}$. Each nesting level adds fixed bank tags; the depth is fixed. The host checks bounds on every physical guest load or store, independently of the claimed guest program counter. A forged wrapper state cannot jump past a host check. Keep the original input as a read-only view when taking nested snapshots; only the selected endpoints need to be copied. A virtual test of the original universal source handles its arbitrary $W$-bit addresses by the routing records above. Thus the maximum exponent for addresses used by the final decider can be fixed independently of enlarging $c$; larger $c$ changes the constant size of local templates. Take $c$ with headroom for these banks, the original input and the clock. Data live in one or a fixed number of physical words. This gives a final decider in the very word model being diagonalized. One cannot instead silently assume constant-overhead simulation of arbitrarily wider sparse address spaces by a fixed narrower RAM.
