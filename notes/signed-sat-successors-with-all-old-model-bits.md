# Two ordinary SAT successors when the complete old model is known

There is one computable infinite chain of uniquely satisfiable proper ASCII 3-CNFs. At each stage the old clause body is retained verbatim and two current candidates are offered. They have equal bit length $N_i$ and differ in one sign field. Exactly one has a model, obtained by uniquely extending the old one. Continue with that candidate. Apart from the header with updated counts, every old byte and variable name stays in place. The stages can be chosen with $N_{i+1}/N_i=\Theta((\log N_i)^{12})$.

* On **each** candidate, every deterministic logarithmic-word RAM correct for ordinary SAT takes $\Omega_P(N_i/\log N_i)$ instructions. A single globally correct program takes $O(N_i/\log N_i)$ on both candidates at all stages.
* Even a program promised the two genuine presentations, given the stage, the current sign, the entire previous positive file and **every bit of its unique assignment**, takes $\Omega_P(N_i/(\log N_i)^3)$ on **both** candidates at every sufficiently late stage if correct on the promise. Native replay gives the matching upper bound with that information.
* A sound partial procedure that selects the satisfiable sign with that old information also needs this latter time on every sufficiently late stage on which it returns a sign. The true branch can be generated effectively. Efficiently selecting it is a computational problem even when all the earlier witnesses have been supplied.

The first lower bound comes from a sign sensitivity test. The second comes from a deterministic time diagonal in a parsimonious SAT encoding. Both apply to unrestricted work memory. The selected list contains a common positive slow file and a common negative slow sibling for every finite portfolio of correct programs once the stage is large enough. The choice of stage for an enlarged portfolio can depend on that portfolio. No nonuniform advice about the new verdict is included.

## Building the chain

Let $b_h$ be the bit of the fixed [finite-priority computation](priority-pinned-sat.md) on scale $h$. Recall the precise property used here. A fixed program on scale $h$ that signals only if $b_h=c$ cannot signal in fewer than $\gamma 2^h$ steps at any sufficiently large scale, for a program-dependent $\gamma>0$. The construction schedules each such program in an opposite-color slot for a fixed fraction of $2^h$ native steps. A slot winning at a signal of its own sound tester would assign the opposite bit and so cannot win. Each preceding slot can permanently preempt it at most once. Direct native computation of $b_h$ costs $O(2^h)$. This is a standard finite-priority use of the almost-everywhere time hierarchy. [Geske, Huynh and Seiferas on almost-everywhere time hierarchies](https://doi.org/10.1016/0890-5401(91)90022-T)

Fix $h_1=16$ and $h_{i+1}=h_i+12\lceil\log_2(h_i+2)\rceil$. Write $t_i=2^{h_i}$. Start with a fixed unique proper formula; the seven clauses on three variables that force all three false suffice. At stage $i$, append a disjoint deterministic computation of $b_{h_i}$ with output variable $o$. Use [the locally indexed parsimonious compiler](local-sorting-for-parsimonious-ram-encodings.md) and shift the fresh variable identifiers by the old variable count. The encoded computation has $O(t_i h_i^2)$ Boolean gates. Each chronological and auxiliary wire has exactly one possible value in a legal assignment.

Add $q_i=\Theta(t_i h_i^2)$ fresh toggle bits, with a fixed computable integer rounding, one pin per bit. Expose the parity of these bits together with $o$ using functional two-input XOR gates. Pin that final bit to the public candidate sign $d$; a proper triple with two distinct forced-zero reserves implements a pin. For the actual offered pair all toggle bits are pinned zero. Clauses enforcing gate equivalences, all reserves and all padding are deterministic. Use fixed-stride, space-padded ordinary decimal fields; canonical blank and minus sign fields have equal length. Each toggle occupies one designated literal sign inside a distinct $\Theta(h_i)$-byte record. Names and clause counts do not depend on pin signs. This yields $N_i=\Theta(t_i h_i^3)$, since the toggle records alone realize the lower estimate and the old file sizes form a geometrically bounded sum. Header, offsets and strides can be computed from the public scales. Fix the rectangular sort depth and inactive slots from the known network bounds in advance so counts are computable without extracting wiring at larger scales.

For an old assignment $x$ and a new assignment $y$, the new indicator is the product of the old indicator at $x$ and the signed block indicator at $y$. For every old model the latter has exactly one extension for $d=b_{h_i}$ and zero for the other sign. A single toggle edit reverses these two cases. This proves the claimed extension and the one-sign sibling property. The comparison concerns changing the current candidate; obtaining the next stage adds the new clauses stated above. ## Accounting for everything already known

On scale $h$ a tester first checks whether $h=h_i$ for some $i$ by iterating the scale recurrence; this costs $\operatorname{poly}(h)$ instructions. For $h=h_i$, compute every preceding $b_{h_j}$ by native replay and materialize the earlier positive files and model bits. Compiling and evaluating all the gates at an earlier stage and writing its ASCII file costs $O(t_j h_j^3)$ native work, or $O(t_j h_j^4)$ even allowing an extra logarithm. The sum through $i-1$ is $o(t_i)$ since $t_i/t_{i-1}\ge(h_{i-1}+2)^{12}$. The same estimate permits physically supplying every old intermediate file and model rather than just the latest one. The current file is virtual. Keep the frozen body in an array and generate current reads by the local compiler; parity-chain links, pins, clause counts, straddling words and fresh name offsets need constant work per read after setup. The setup is $o(t_i)$. No call to the current priority computation is made to generate a current input word.

Fix a promised decider and two bits $d,a$. Simulate it on candidate $d$ with precisely the old data just constructed. Signal on answer $a$. On the genuine input this implies $b_h=d$ for $a=1$ and $b_h=1-d$ for $a=0$. Off the chosen scale sequence abstain. Through a small constant times $t_i$ actual decider steps the tester requires $O_P(T+o(t_i))$ steps, using the native fixed-register simulation with sparse addresses and the usual masking for each guest word. Taking the four color bounds gives the all-sufficiently-late lower bound on both files. An always-sound constructor returning a sign directly supplies the analogous two sound testers. A promised upper-bound algorithm evaluates $b_{h_i}$ in $O(t_i)$ and compares $d$. Providing the whole old model can therefore leave a substantial computational cost at the next stage. Precomputation containing a bit about future stages is a different assumption.

On the actual physical inputs the $q_i$ toggle sign bytes have a further effect. Flipping any one gives a well-formed formula of the opposite verdict. A correct deterministic solver must have inspected a word containing the edited bit on its original execution; otherwise the two computations remain identical through halt. At most a machine-dependent constant number of these bytes lie in a single input word because the record stride is $\Theta(h_i)$ and the solver word has $O_P(\log N_i)=O_P(h_i)$ bits. This proves the bound on actual executions of globally correct machines on both signs. The off-promise edits are essential to this counting step.

For the physical upper bound, infer candidate scales from $N$ using the two-sided $\Theta(t_i h_i^3)$ estimate. Only constantly many scales can match; the small finite exceptions can be handled separately. Rebuild the old data and compare the current physical file wordwise against the two virtual candidates. On an exact match replay the current bit, otherwise use ordinary exhaustive SAT after trying all matching scales. This is a correct decider on arbitrary files and its total work on the family is $O(N_i/\log N_i)$. Both signs, all old variables and all fresh variables are accounted for.

## How far the induction goes

For a fixed finite bound $C$ on description length, take the largest starting stage and smallest positive constant for the finitely many correct programs of that size. The genuine chain is defined independently of $C$. After reaching any later stage one obtains a hard successor for that same portfolio at the very next stage. For $C+1$ the eventual bound may have a later start. A stage for both old and new portfolios exists on this same chain; no abandonment of the old clauses or change of chain is required. The scan cost already has a direct uniform proof for every solver with a given word-width coefficient. The stronger promise statement concerns computation with the metadata supplied.

The direct upper bound prevents this particular family from separating SAT from linear time. The calculation identifies two distinct charges on the very same input and records what the algebraic extension really preserves. An improved successor for the original goal must cause further elapsed work on a globally correct solver, beyond verifying the new file and replaying its hidden bit. [Proper DIMACS pin and unique-extension audit](../audits/frozen_signed_successor_audit.py)

A literal postprocessing shortcut fails even with unlimited preprocessing. Consider two tiny proper files with a common seven-clause zero reserve and a fourth variable pinned false; the last clause pins that variable to the proposed bit $b$ with the polarity chosen so the file is satisfiable exactly for $b=1$. A comment can carry the binary clock. A globally correct solver checks this exact template and answers $b$ in time linear in its length, using an exhaustive fallback. Trying to replace the self-indexed trial by one of these two files would require $b=1$ exactly when this solver gives no timely YES on the very replacement. Neither setting works for a sufficiently large clock. A valid compression must preserve the simulated read interface or prove soundness anew on the resulting file.
