# Answering checkpoint queries without building a checkpoint

**Research journal, 24 November 2026.** A description of how one memory cell depends on the preceding checkpoint can be much easier to evaluate than the accumulated memory. Under the hypothesis that ordinary SAT takes O(m) deterministic word-RAM steps on m encoded bits, one can verify such descriptions by reconstructing only the values, addresses or unary functions that a test actually requests. The methods below use ordinary bounded reachability for a small-space auxiliary machine and charge for evaluating its succinct input. [Linear-SAT reachability bound](linear-quantifiers.md) · [Adaptive batch verification](linear-sat-batches.md)

## One predecessor cell and a shared unknown memory

Let there be P≤2^{O(n)} transitions between checkpoints and 2^{O(n)} addressable bits per checkpoint, including tape and symbol-track indices in the addresses. A single Boolean circuit with description length s, given a checkpoint index j+1 and address a, returns a predecessor address g and one of the four unary Boolean maps f. The assertion about the two checkpoints is C_{j+1}(a)=f(C_j(g)). This includes copying, moving, overwriting and toggling bits. For example a circuit reporting the XOR difference at (j,a) uses g=a. The same circuit is used at every boundary. A lookup of a requested cell follows one address at a time backward to the entry memory B=C₀ and accumulates the composition of the unary maps. It returns a pair (p,h) with C_j(a)=h(B(p)). It need not calculate B(p).

The pointer walk uses O(s+n) tape space, including workspace to evaluate the circuit, and O(P·poly(s+n)) time. Under linear SAT, applying bounded reachability to each bit of its unique output gives deterministic RAM time (s+n)·2^{O(√(n log n))} when s≤2^{O(n)}. There are O(n) output bits, absorbed by the displayed overhead. This costs no factor P in the resulting exponent. Directly traversing a chain of P differences for every read could cost that factor.

Here is a relational check that works even when B is completely unknown. A separate circuit specifies the control and head metadata at each checkpoint. To find a violation of a proposed q-step segment, guess the segment index and a final comparison address. Replay the ordinary machine from its proposed entry metadata, saving its actual writes in a temporary address dictionary. For a read before a local write, compute the entry term (p,h) for that address, obtain a candidate bit for B(p), and use h of that bit. Compare the final metadata and the final value at the chosen address with the proposed end metadata and end term, also resolving the initial value if the segment left that cell untouched. Only O(q+1) base values are requested. Every guessed reply must agree with earlier replies at the same base address. Conversely any coherent finite reply list extends to a whole Boolean memory B. This proves exactness of the violation test for the assertion that **every** entry memory makes the segment behave as claimed. A single actual execution may have much less symmetry than this assertion demands. Certifying correct behavior for just one convenient entry memory would require a separate connection to the real prefix computation.

This check can also restrict the entry memory by a succinctly presented graph of parity equations B(u) XOR B(v)=c. Join a new anchor vertex to every queried p by an edge labeled with its guessed bit. The finite replies extend to a solution precisely when the augmented graph has no closed walk of odd label parity. With no such walk, assign the value at a component root arbitrarily, taking zero at the anchor, and extend by parity along paths. A contradicting walk can be detected by reachability between (u,0) and (u,1) in the doubled graph, for some u, with each edge changing the second coordinate by its label. It suffices to guess at most twice the number of vertices in steps. For an s-bit edge predicate, the augmented-graph verifier uses O(s+q·poly(n)) space and 2^{O(n)}poly(s+q) time. Bounded reachability under linear SAT therefore checks this extension condition in (s+q·poly(n))·2^{O(√(n log n))} time when s,q≤2^{O(n)}. The actual prefix must establish the stated parity facts to apply this rule to that prefix. Independent choices of values for separate probes would be invalid.

Checking one replay fits the same bound. Use a balanced dictionary of q address records and guess the oracle reply bits for computing the required terms. Check their accuracy by universally selecting a call and testing it on the corresponding query from the replay. This is the adaptive batch calculation, and all query writing, dictionary work and comparisons cost O(q·poly(n)) RAM operations beyond the selected-call test. It avoids multiplying the number of reads by the entire cost of a term lookup.

## Two predecessors with a bounded number of pending operations

For a known explicit initial memory, allow each described cell to apply any binary Boolean function to two cells of the preceding checkpoint. Also permit constant or unary nodes. Unfold only the requested cell into an expression tree, duplicating shared subcomputations. Give leaves rank zero and preserve rank at a unary node. At a binary node with unequal child ranks take their maximum; for equal ranks add one. This is the register number of an expression tree, with a shift of convention for leaves. [Sethi and Ullman](https://doi.org/10.1145/321607.321620)

To recover a bit, nondeterministically choose which child to evaluate first. Save the other address, level, operator, pending unary map and operand order as one frame. Once the first value is known, the operator on the remaining bit is unary. Pop the saved frame and follow that child using the composed unary map. No new frame is needed for a single-predecessor step. With room for r frames, any successfully returned value is exact. If the tree has rank at most r, evaluating a lower-rank child first when possible gives a successful order. At equal child ranks both fit in r−1 frames. This observation uses no precomputed table of ranks. The [Lean kernel](../lean/PullbackEvaluation.lean) checks by induction that the bounded recursion produces precisely the genuine value when an evaluation order fits.

The auxiliary tape machine uses O(s+(r+1)n) space. At depth D the number of visits permitted by the frame cap is at most (2D+2)^(r+2). Indeed a binary node pays one visit and two recursions of depths D−1 with caps r−1 and r, while a unary step has only the latter recursion. At cap zero a binary node immediately fails. This bound covers failing choices as well. Each visit costs poly(s+n) tape time. Thus for D≤P the logarithm of the running time is O((r+1)n+log(s+2)). Test whether value one has a successful evaluation. On an overflowing tree with no successful order this defines the default bit zero. It yields one deterministic interpreted memory at every checkpoint, even for a malicious descriptor. For a feasible tree its true value is recovered. With s≤2^{σn} and a fixed polynomial-time computable cap r=o(n/log n), the linear-SAT reachability bound takes time 2^{σn+o(n)}. Unlike the unary case, a binary tree over an unspecified entry memory can examine many unknown bits; this bound uses an explicit or otherwise charged leaf evaluator.

## A test on the actual first omitted output

Use the [first-hole source](address-diagonal.md) with B=2^(20n) machine steps, d=n or 2(n−1), and a short program producing a predecessor of its first missing d-bit output w. Fix positive rationals σ,τ<5. Divide B into segments of q=2^⌊τn⌋ steps, stuttering after a halt. Suppose the actual boundary tape contents and compact metadata of this producer are described by one adjacent-checkpoint circuit and metadata circuit of total description length at most 2^(σn). Require the bit dependency trees in the proposed representation to fit the designated frame cap at all requested boundaries and addresses. Unary pullbacks automatically meet this rank requirement.

Under linear SAT, guess the program and the two descriptions and compare their interpreted checkpoints to genuine q-step tape evolution universally over a segment and a final address. Start with the explicit initial configuration, check the endpoint metadata including the halted verdict and claimed output, and check every tape bit by the selected-address test. A valid description works by construction. Conversely the deterministically interpreted checkpoints of any passing guess must be the actual configurations by induction over the segments, irrespective of default bits or a guessed circuit's internal structure. The batch replay and the bounded number of outer quantifiers give deterministic RAM time 2^{max(σ,τ)n+o(n)} for this test. No individual execution row has been requested as circuit output.

The test consequently excludes w. Applying the previous omission-score decoder gives a c>0 such that, in **every** interval [w−K,w) in range at sufficiently large n, at least c(K+1)−1 predecessors admit no such short producer with this representation under the linear SAT hypothesis. The postprocessing uses 2^(2d+o(n))≤2^(4n+o(n)) operations. Both its RAM-to-tape simulation and the source's universal simulation may be charged quadratically because 4·max(4,σ,τ)<20. Thus a sufficiently good supply of the shared descriptions on even one trailing interval would rule out linear SAT. We have not constructed that supply. [Batch and decoder clocks](linear-sat-batches.md)

Two losses of information are worth distinguishing. Every q-step run admits a short list of its changes *for each interval separately*. These lists may encode an arbitrary long sequence in total. For example, N successive singleton writes can form any of 2ᴺ final tables, although each update needs only O(log N) bits. Fewer than 2ˢ total shared descriptions cannot represent all these tables when s<N. Also, unrestricted two-predecessor rules with a small common circuit already describe any deterministic exponential-time computation: unroll a fixed single-tape machine's time-by-cell tableau, implement its constant-size local update by fixed fan-in-two gates, and use micro-layers and copy gates to give each gate only previous-layer inputs. On a length-n input the addresses have O(n) bits, and the wiring, local gate and initial bits are computable in poly(n) time. Such unrestricted rules admit no uniform deterministic 2^{o(n)} query algorithm on every such family, by the deterministic time hierarchy and polynomial RAM-to-tape simulation. This concerns succinct circuit-value queries. A separate lower bound for explicit SAT needs an additional property of its computations.
