# Address geometry on a hierarchy machine

**Research journal, 2026-11-24.** The interval condition in the [phase simulation](phase-histories.md) can be arranged on an actual nondeterministic time-hierarchy source. On that source all address queries have polylogarithmic cost under the SAT hypothesis, independent of how hard the tape symbols are to compute. We also tested whether one could obtain the same geometry for arbitrary chronological address circuits by choosing the address order and time boundaries after seeing the run.

## Remove the address-certificate assumption on the hierarchy source

Choose a multitape nondeterministic hierarchy language with clock T. Its branches have unrestricted tape space subject to the clock. Already on the original machine, consecutive times visit an interval on each tape. Indeed, between the first visits to the minimum and maximum position in a time block, the head travels through every intervening cell. Separate the tapes into disjoint numerical address ranges. For B blocks of consecutive full steps, the total number of touched intervals is O(B), for every branch. [AddressOrders.lean](../lean/AddressOrders.lean) checks the discrete intermediate-value assertion for an integer-valued head moving at most one cell per step.

The useful additional property is an efficiently accessible schedule. For example choose T=2ⁿ and a language in nondeterministic multitape time O(T) outside O(T/n²), as in the [succinct hierarchy argument](succinct.md). Represent all choices by a fixed-length O(T)-bit witness w. A deterministic tape verifier on a self-delimiting x followed by w simulates the original machine in O(T) steps, reading the witness sequentially as choices are needed. Choose the bounds so the padded verifier on general inputs is linear in the combined input length, for instance by making each simulated step consume a fixed-size choice field and stopping when the fields end. Lengths and clocks are known for the instances being simulated. By oblivious simulation there is a two-tape computation of U=O(T log T) steps whose head positions, given the combined input length and binary step number, are computable in poly(log T) time. A fixed clock and idle padding can retain a recorded halting decision. The initialization treats each witness cell as an unknown bit. Consistency across all reads of that cell supplies one common w, and unvisited witness cells can be filled arbitrarily. It costs no T-bit write in the *short verifying algorithm*. This applies the deterministic simulation theorem to a verifier with the guesses on its input. [Pippenger and Fischer](https://www.khoury.northeastern.edu/~viola/classes/papers/PippengerF-Oblivious.pdf) · [Williams, Theorem 3.2 and the related time-block construction](https://arxiv.org/pdf/2502.17779)

Assume deterministic SAT in O(mᵈ) time, d=2 or 3, with m the explicit encoded length. Given binary l,r,a and a tape number, the predicate that some t in [l,r] visits address a is decidable in poly(log T) time: compile the small circuit for the public head positions and the range test into SAT. The identical calculation works for whether some head position is ≤a or ≥a. Binary search gives the minimum and maximum in any nonempty time block. Existence queries plus binary search also give the first or last visiting time at a specified cell if there is one. These procedures have constructible Boolean circuits of size poly(log T), by unrolling polynomial-time computation on O(log T)-bit inputs. This polynomial can depend on the solver. Its independence of the size of a block's *symbol* circuit is what permits a single SAT exponent below.

Divide the U steps into B aligned blocks of length K, allowing a shorter last block. For each light block guess a circuit with ≤s gates for its constant-size chronological payload, comprising finite state and scanned/written symbols at each time. The public head schedule needs no guess. Certify local transitions and adjacent control states. Use the interval sweep per tape to identify predecessor blocks. Within a block and on a reported overlap, violations of tape-data consistency now have existential witnesses in time indices. The known small range-occupancy procedure checks there was no intervening visit. The checked read must equal the latest written symbol, treating a step that leaves a cell alone as writing its scanned value. On virgin cells enforce the initial tape convention; a first read of a witness cell can have either bit. For the fixed x portion, find each input cell's first visit using the public schedule and inspect its scanned value directly against x. This costs Õ(n(s+1)). A blank initial region outside the supplied input has a small range predicate. Inert padding after the decision may use an oblivious clock rather than a data-dependent head excursion. The theorem only requires a fixed uniform choice of an equivalent oblivious verifier; one can instead let a flagged state continue the simulated schedule and retain a latched decision.

Allow H heavy blocks to be supplied as raw strings of O(K) payload symbols each. Check all within-block constraints on their rows directly, using the public schedule to obtain predecessor times. For an overlap between distinct blocks with at least one heavy endpoint, enumerate its addresses. On each address retrieve the final visit in the earlier block and first in the later block and compare the symbols. The incoming fragments of any block are disjoint on each tape, and its outgoing fragments are disjoint as each address has at most one next visiting block. They cover at most O(K) addresses in each direction for a fixed number of tapes. Include virgin incoming fragments. Across all interfaces with a heavy endpoint there are therefore at most O(HK) addresses to inspect, even when one block meets many others. Each comparison has direct access to the raw block and costs at most Õ(s+1) including a possible light neighbor. Tape induction establishes soundness. The other O(B) fragment and block tests each cost Õ((s+1)ᵈ). Guessing and indexing descriptions and nondeterministic RAM-to-tape simulation incur polylogarithmic overheads as before. The resulting nondeterministic time is

    Õ(n(s+1) + B(s+1)ᵈ + HK(s+1)).

For each fixed 0<γ<1 with computable block parameters (for example rational γ), take K of order T^γ and B=⌈U/K⌉. Fix any circuit bound s=(log T)^b for constant b≥1. There exists a constant C such that on infinitely many accepted inputs **every** accepting payload has more than B/(log T)^C blocks requiring greater than s gates. Otherwise take H=⌊B/(log T)^C⌋, hardwire finitely many exceptions, and use the displayed simulation. Its nondeterministic tape time is o(T/n²) for sufficiently large C. Here U=O(T log T), n=log₂ T and the logarithmic overheads are fixed polynomial powers. For polynomial s=T^α a similar hard-block count follows for any constructible bounds satisfying the displayed inequality with the required hierarchy margin.

This strengthens the earlier block test by putting the conditional hardness on actual constant-alphabet chronological data alone. A proof that enough payload blocks are easy for a suitable verifier would now suffice. Tape geometry and obliviousness give an unconditional way to handle the addresses. They do not supply the missing statement about the symbols read and written.

## What if a general RAM is allowed to relabel its addresses?

There are simple address streams on which *every* common order needs Ω(T) intervals, even allowing arbitrary time-phase boundaries as far apart as T/polylog T. This strengthens the fixed-partition test in [the phase journal](phase-histories.md). The objective of minimizing runs by permuting columns of a binary matrix is the classical consecutive block minimization problem. Its reformulation by Hamming distances includes a zero endpoint column to account for the first and last run. [Chakhlevitch, Glass and Shakhlevich, discussion of the Hamming-distance formulation](https://www.sciencedirect.com/science/article/pii/S0377221713000751)

Let q be a prime, k≥2 and q≥128k. Use N=qᵏ addresses x in F_qᵏ and q−1 laps indexed by s=1,…,q−1. In lap s visit every address exactly once. The first base-q digit of its time within the lap is the standard residue

    Fₓ(s) = x₁s + x₂s² + … + xₖsᵏ  (mod q).

The remaining digits are x₂,…,xₖ in order. This gives a permutation because the coefficient of x₁ is nonzero. Both directions are computable by modular arithmetic with circuit size polynomial in k and log q. The stream has T=(q−1)N events. Let g=⌊q/(64k)⌋ and D=gN/q.

Partition the time line arbitrarily into nonempty phases of length at most D. The binary signature of x lists the phases containing x. For distinct x,y choose x≠0 by exchanging names if necessary. The polynomials Fₓ and Fₓ−Fᵧ are nonconstant. Each has degree ≤k, no constant term and takes any fixed value at most k times. The two polynomials can coincide when y=0, which only enlarges the union bound. At most 2kg laps place x within the first or last g first-digit bins. On the remaining laps any phase containing x lies wholly within that lap, so different laps give different phases. At most k(2g+1) laps have the residue of Fₓ(s)−Fᵧ(s) in the image of [−g,g]. On every remaining lap the visits to x and y differ by more than D time steps, since each bin contains N/q time steps. Thus at least q−1−k(4g+1)≥q/2 phases contain x and omit y. This proves a pairwise Hamming-distance lower bound for every allowed partition.

In any order of the N addresses the sum of Hamming distances of adjacent signatures is at least (N−1)q/2. A union of h intervals in that order has at most 2h boundaries. Summing over phases gives at least (N−1)q/4 intervals in total. Even if membership in E individual (phase,address) pairs may be wrong, correcting a bit affects at most two adjacent distances, so the described interval count plus E still has this lower bound. If some phases are longer than D, replace just those phases by singleton times with exact membership. Writing L for their total length, the interval count increases by at most L and errors cannot grow. Consequently the interval count plus E plus L is Ω(T) for *every* partition. One cannot obtain all three costs below linear just by optimizing boundaries and tolerating a few wrong memberships. With k=⌊q/128⌋ and primes tending to infinity, D=Θ(T/kq) is of order T/(log T/log log T)². For a finite check, all address-pair distances on four random partitions with q=31, k=2, g=2 had minimum 48, exceeding the corresponding elementary bound 12. These smaller parameters test the formula q−1−k(4g+1).

## Check the same stream without a shared order

A lap with exactly N rows, all addresses in an N-element universe, and no duplicate address is a permutation of the universe. Suppose each of L laps of a proposed RAM history has b chronological subblocks with small row circuits of size s. Verify that addresses are in range and test pairs of times for duplicate addresses within each lap, using O(b²) SAT calls per lap. One can omit these checks for a public known bijective schedule. Every read in lap i>1 then has its predecessor at the unique equal address in lap i−1. A disagreement is an existential pair of rows. It takes O(b²) tests across neighboring laps, regardless of how scattered the common addresses are. Check initialization and local transitions as usual, including the actual input. The resulting time bound is Õ(n(s+1)+L b²(s+1)ᵈ) under the SAT hypothesis. This assumes the one-event-per-row normalization and one visit to each address per lap.

For the polynomial stream use one subblock per first-digit bin, so b=q and L=q−1. These blocks are short enough for the interval lower bound. The equality-based check has O(q³) local tests instead of a linear number in T=qᵏ(q−1), a polynomial saving for fixed k≥3. There can be arbitrarily many addresses in an individual block intersection. One SAT call searches that whole intersection for a disagreement. For instance the payload can be identically zero, so that the stream is readily checkable. Merging whole laps also gives a single address interval if suitably small row circuits span a lap.

Padding arbitrary phases to permutation laps requires accounting for every untouched address and for its retained memory value. Guessed values on such visits must still agree across laps. The large address span alone forces no lower bound, and the interpolation stream does not constrain the chronological symbols of the chosen hierarchy verifier. Priority of the finite-field scheduling argument and its application here has not been established.
