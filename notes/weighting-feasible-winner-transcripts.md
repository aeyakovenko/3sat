# Selecting the actual advice bit from conflicting witnessed futures

A verifier can give the actual advice bit a conditional probability of at least $3/4$ **even when other fully witnessed continuations give the opposite bit**. The probability is computed by counting each public random tape admitting a witness once. The construction works on the same clean full-length phases as the [two complementary formulas](the-first-choice-in-a-winner-transcript.md). It uses positive row certificates throughout. The cost that prevents its use as an ordinary nondeterministic SAT verifier is determining which of two possibly nonempty sets of tapes has the larger measure.

## Exact cost for an ordered list

Consider $L\ge1$ publicly ordered items with known binary labels (colors). An unknown nonempty subset is feasible. The desired output is the color of the **least** feasible item. A projected score consists of $R$ fair bits and a color assigned to each tape independently of the feasible set. For that color the tape contributes one unit if at least one reply passes the verifier. Other tapes can be unused. Let $C_0,C_1$ be the two counts; condition on survival by dividing each by $C_0+C_1$, which must be positive. This definition does not count multiple witnesses for one tape. A prover who suppresses available replies does not implement this measure.

Suppose feasibility is available only by positive evidence: enlarging the feasible subset can never remove an accepting reply on a tape. The test may combine many certificates. Let $h$ be the number of consecutive runs of constant color in the ordered list. For any fixed integer $b\ge2$, the minimum number of fair bits for worst-input conditional accuracy $b/(b+1)$ is zero when $h=1$. For $h\ge2$ it is exactly
$$
 R_{\min}=\left\lceil\log_2\big((b+1)b^{h-2}\big)\right\rceil .
$$

Index runs from $j=0$ to $h-1$. Give a feasible item in run $j$ score $b^{h-1-j}$. The score of each color is the **maximum** over its feasible items, or zero if absent. To realize a maximum, reserve a disjoint interval of tapes for each color, of sizes $b^{h-1}$ and $b^{h-2}$ respectively, with the larger interval for the first color. Within the chosen interval let the offset be $u$, starting at zero. A witness supplies a feasible item of the tape's color and run $j$ with $u<b^{h-1-j}$. For each color the accepting offsets are nested initial segments, so projected counting gives precisely the prescribed maximum. The first feasible run has a score at least $b$ times that of any later run carrying the other color. The available fair tapes suffice after rounding the total size upward to a power of two.

For necessity take one representative of each run. Start with only the last representative feasible and add the others in reverse order. The correct color switches at every addition. Its initial count is at least one. The old correct count cannot decrease when more evidence becomes available, so on the next input the new correct count must be at least $b$ times that old count. On the last input the two counts are at least $b^{h-1}$ and $b^{h-2}$. The two colors use disjoint tapes. This proves the exact integer lower bound even for tests using several positive witnesses per tape. If the same tape is allowed to count separately for both colors, the same argument and nested-interval construction give $\lceil(h-1)\log_2 b\rceil$ bits instead.

This also quantifies how rarely selection may succeed before conditioning. In the disjoint-label model, if the last representative alone has correct mass $w$, its total surviving mass is at most $(1+1/b)w$. With all representatives present, total mass is at least $(b+1)b^{h-2}w$ and at most one. The survival probability on the singleton is therefore at most $b^{-(h-1)}$. This bound on ordinary sampling applies even with arbitrary fixed real tape weights, provided both projected scores remain monotone. The finite-coin lower bound separately uses the smallest possible positive tape mass.

## Trading the margin for fewer fair bits

For merely a **strict** preference, the optimal tape count before rounding is $2h-1$. On the nested suffixes the integer dominant count must increase by at least one at each switch, starting at one, so the final counts are at least $h$ and $h-1$. Conversely give run $j$ the integer score $h-j$ and realize the maximum per color by the same initial-interval test. The correct count exceeds the wrong count by at least one. Thus $R=\lceil\log_2(2h-1)\rceil$ fair bits suffice and are necessary. With $D=2^R$ tapes, the difference between the two projected probabilities on the original, unconditioned tape space is at least $1/D$. This is an additive comparison of two projected probabilities. If a constant total survival probability is desirable, use the old experiment on half the tapes and give the other half equal always-surviving masses for the two colors, using at most two further fair bits. Survival is then at least $1/2$ and the signed additive gap is at least $1/(2D)$. For winner paths this can leave a gap as small as $2^{-O(e\log(e+1))}$, whose inverse is still $2^{o(K)}$. The remaining difficulty is determining whether a witness exists on a tape. In particular the rare-survival bound for constant **conditional** accuracy does not apply to this weaker ordering requirement.

There is a second way to use a small number of runs: count color changes among *feasible* paths, even when many intervening infeasible paths have unrelated colors. Fix a cap $H\ge1$. For each color and $t$ from 1 to $H$, let an existential reply give $t$ increasing feasible paths of alternating colors starting with that color. If the actual feasible color sequence has $r$ runs, its initial color permits $r$ such paths and its other color permits $r-1$. Longer chains are impossible because each color change enters a later run. Set $W(0)=0$ and $W(t)=b^{t-1}$ for $t>0$. Allocate $W(t)-W(t-1)$ tapes of that color to the length-$t$ test. Each color then has total score $W(\min(H,t_{\max}))$. If $r\le H$, the true color wins with odds at least $b$; if $r>H$, the scores tie. Thus the cap creates an exact gap-or-tie test without false signs. The verifier may check $H$ full path certificates on one branch. If the public list contains more than $H$ color runs and only instances with $r\le H$ require a gap, the $2b^{H-1}$ tape budget before rounding is sharp: there are two alternating sublists of length $H$ with opposite initial colors. Each sublist and its suffixes meet the promise and force at least $b^{H-1}$ tapes permanently assigned to the initial color. This threshold argument is related to the mind-change method for bounded NP queries. [Beigel, *Bounded queries to SAT and the Boolean hierarchy*](https://www.sciencedirect.com/science/article/pii/0304397591901604)

## Applying the rule at the original checkpoint

In a clean full-length phase, list all length-$m$ sequences of candidate rank pairs in public lexicographic order. At most $L=(e^2)^m$ codes suffice for tag rank $e$. A public simulation can compute the two rules' error counts from the proposed awards without deciding whether those rows accept. Structurally invalid codes can be given an arbitrary color and excluded during feasibility verification. Color a valid code by its proposed better rule, using the public tie rule. The actual path is the least feasible code, by the chronological argument in the [single-choice note](the-first-choice-in-a-winner-transcript.md). Hence the construction with $b=3$ returns its color with conditional accuracy at least $3/4$. This applies to controllers with arbitrary many competing accepted pairs. A correct, complete source search, a genuine starting prefix, and a guaranteed full actual path are the promises.

A simple implementation can avoid precomputing color runs: on $2L$ fair bits, scan two-bit digits until the first nonzero digit and use the number of preceding zero digits as the code. On a completely zero tape abstain. A code $r$ has weight $3/4^{r+1}$, whereas all later codes together have weight less than $1/4^{r+1}$. Once a code is sampled, guess just its row witnesses; the color is determined by the public code (or a fixed default for invalid codes). Either implementation has branch work at most
$$
 T\operatorname{poly}(K)+2^{O(e\log(e+1))}\operatorname{poly}(K),
$$
where $T$ bounds one branch of the embedded row predicate. The second term pays for public tapes, any enumeration of candidate labels, arithmetic on scores, and ordinary simulation of short award sequences. Scores as large as $3^L$ take $O(L)$ **bits** to represent. The code index fits within the source word width at sufficiently late stages. Here $e=O(\log K)$, $m=O(e)$ and $2^{O(e\log(e+1))}=2^{o(K)}$. This extra work can exceed any fixed polynomial in $K$. The row verifier is run only along the one guessed or sampled path. For the single optional row and fallback, one can simply place one tape on the fallback color and three on the color favored when the optional row accepts; this gives certainty on the empty row and $3/4$ conditional accuracy on the nonempty row.

## How many color changes can actually fit in a phase?

There is a matching $2^{\Theta(e\log e)}$ worst-case **random-bit order** for the phase experiment when availability is supplied as positive evidence. At the first $d=\lfloor e/16\rfloor$ normal blocks choose among $Q=\lfloor e/8\rfloor$ neutral first names in rank order, paired with the common least live second. Avoid the two official first names and the current and previous second names. Starting with $e-O(\log^*(e+1))$ pool members there are enough distinct choices at every node of this prefix tree, the public guard is still active, and at least one official block remains. The $d$ digits name $Q^d$ possible leaves in lexicographic order.

Take a nonempty set of available leaves. A digit has an accepted row when a positively witnessed available leaf extends the prefix with that digit. The real priority path therefore spells the least available leaf. Neither official rule can err on these neutral blocks: the first awards differ from both rules' first names, and the response award is the previous common second, which cannot start either rule's pair. On the remaining normal blocks use just the official rule opposite to the parity of the selected leaf index. The genuinely better rule is then its parity. Hypothetical witnessed paths can select other available leaves and yield their respective parities. Increasing the leaf set only enables further positive tests.

The nested suffixes of this leaf order switch the true answer $Q^d-1$ times. The monotonicity lower bound therefore forces $\Omega(Q^d)$ fair bits in any positive projected scorer attaining $3/4$ conditional accuracy. With the public upper construction this gives $2^{\Theta(e\log e)}$ worst-case bits. The lower bound concerns a uniform positive-evidence interface to these phase trees. Giving out the first available leaf, inspecting an explicit input as a table of both positive and negative entries, or otherwise using the representation of the row program can change that bound. The native upper bound uses ordinary row programs; it does not require every possible oracle table to appear as an unmodified self-matching native bin.

On a fixed clean bin, an $O(n^k)$ SAT solver can already recover the least path in $T^k\operatorname{poly}(K)$ deterministic time by following the greedy search, testing at most $e(e-1)$ row formulas per block. The new construction obtains a preference at about the *row verification* clock by altering the acceptance criterion. Existence of a surviving tape of one color cannot certify the advice bit, since both colors can survive. For a constant conditional margin, direct sampling until survival can require exponentially many trials in the number of color runs. The smaller-margin construction avoids rare survival but still scores tapes by the existence of a witness. Removing these two costs on the genuine native predicates remains open.
