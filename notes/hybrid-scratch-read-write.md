# A SAT time lower bound from the reads and writes to each scratch address

Let $d\ge1$ be fixed. Use one unrestricted nearest-neighbor $d$-dimensional work tape, random read access to an ordinary $N$-bit SAT formula, and an initially zero logarithmic-word random-access store of arbitrary size. The controller and instruction conventions are those of the [hybrid tape theorem](hybrid-tape-cut-trading.md). Up to a constant number of ordered loads and stores per instruction are permitted. For one computation, let $r_a,w_a$ count its reads and writes to scratch address $a$. Put
$$
 P=\sum_a\min(r_a,w_a).
$$
Input reads, controller registers and accesses to the geometric tape are separate. A sound UNSAT recognizer is required to signal eventually on every unsatisfiable formula. All bounds below need only hold through its first signal on those formulas.

**Theorem.** Such a recognizer cannot have both $T=O(N^c)$ and $P=O((T+1)^\nu)$ if $c\ge1$, $0\le\nu\le1$ and
$$
 (d+1)c^2<c+d+1,\qquad c^2\nu<1.                                      \tag{1}
$$
On an ordinary RAM with no geometric work tape the first inequality can be replaced by $c^2<c+1$. At $c=1$ there is also a constant $A$ for which $T=O(N)$ and $P=O(N/\log^A(N+2))$ are incompatible.

For example, on a planar work tape $c=11/10$ and $\nu=4/5$ satisfy (1), since $3(11/10)^2=3.63<4.1$ and $(11/10)^2(4/5)=0.968<1$. This permits $O(T^{4/5})$ scratch writes at arbitrary addresses, unlimited reads and arbitrary tape usage. It also covers runs with linearly many scratch reads and linearly many scratch writes if the per-address sum is small. A machine may write a fresh address on every other step with no charge to $P$ if it never reads those words. A lower bound on occupied scratch alone cannot imply this example. The unrestricted SAT time question remains open.

## Certifying only the cheaper information for each address

Use the genuine run, tile side $u$ and maximum local group size $b$ from the [tile-cut construction](hybrid-tape-cut-trading.md#sharing-scratch-states-at-time-cuts-and-tape-contents-at-local-cuts). A translated grid has at most $T/u$ chronological tile changes. Divide each tile's visits into consecutive local groups of size at most $b$. A chronological interval ends when its tile or group changes. Thus there are $O(1+T/u+T/b)$ intervals. Record their times, labels and endpoint controllers. Record a full tile image only at an internal local-group boundary, at most $T/b$ times. At this point the chart length is
$$
 Y_0=O_d(1+T/u+T/b+u^dT/b)
$$
words. Replaying a selected group takes at most $b$ native steps, possibly belonging to several nonconsecutive chronological intervals. The group carries its tile contents through those intervals and checks its incoming and outgoing tile records. The initial controller, blank cells, interval and group order, claimed final signal and caps are checked as in the cited construction.

Index the chronological intervals $j=0,\ldots,J-1$. For each address let $D_a$ count **internal** interval endings at which its final word differs from its word on entry. Let $R_a$ count intervals in which the machine reads $a$ before making any local write there. A local write of zero is a write. A second read before a write within the same interval adds nothing. The additional data required by the new checker has length
$$
 O\!\left(1+\sum_a\min(D_a,R_a)\right)\ \le\ O(1+P).                \tag{2}
$$
For each address whose minimum is positive, declare exactly one of the following formats and use the cheaper one. The address and its tag cost $O(1)$ words, charged to its first record. Leave every address of zero minimum unlisted.

* **Changed values.** List every interval with an internal ending at which the address changes, and the new value, including zero for an erasure. The incoming value is the value at the last listed ending strictly before the interval, or zero. During replay, use a local dictionary of writes that overrides the incoming word. At an internal ending check the value of every changed-value address written in the interval and every address with a patch declared there. The patch is required exactly when the ending word differs from the incoming word. Other addresses of this format have neither a patch nor a local write and retain their values. No final scratch snapshot is needed.
* **Incoming reads.** Give one record for each interval that needs an incoming word at this address. Supply its value and the index of the latest earlier interval that wrote this address, or an initial-zero marker. Replay any interval using the record on its first such read, and use the same value until a local store. Check equality of the set of triggered records and its declared records for that interval. A record naming a writer requires the named interval's replay to write the address and finish with the supplied value. Every intermediate interval must have no write to it. An initial marker requires value zero and no write in any earlier interval. Failure of any of these obligations has a witness consisting of a record and at most one other selected group. Even a write of the same value counts as a possible intervening writer.
* **Unlisted addresses.** Use zero on a read before a local write. Forbid a pair of intervals $i<j$ and an unlisted address such that $i$ writes the address and its last write there is nonzero, while $j$ needs its incoming value. Select the two groups and the address to test this condition. Enforcing this stronger pair test allows the chart to omit all addresses having $D_a=0$ or $R_a=0$. In the first case all actual internal boundary values at the address are zero by induction from initialization. In the second case no candidate consumer exists.

A structural check sorts the lists by address and interval, rules out duplicate tags or records, checks address ranges and source indices and indexes the declared data for lookup. It costs $(1+Y)\operatorname{polylog}(T+N+2)$ for total chart length $Y$ including (2). A defect can select two groups and an address or record after seeing the whole chart. It replays the groups deterministically, using the same proposed directory, the same read rules, and the actual read-only input. The touched addresses and declared entries for all intervals in either group can be enumerated in $O(b+Y)$ dictionary operations. The chosen writer and intermediate-interval tests only inspect the specified address during those replays. Thus the existential search for a defect costs $(1+b+Y)\operatorname{polylog}(T+N+2)$ including preprocessing. Extra guessed entries and unusually long malformed intervals are limited by the verifier's clock. The number of possible defects does not multiply the time to test a single one.

On a true trace the chosen chart passes. Conversely, fix any chart passing all tests. Every local replay is uniquely determined by it. Induct chronologically over intervals. The incoming control and the active tile contents agree with the global state by controller matching and local tile continuity. Changed-value addresses agree with the predecessor index by the endpoint test at all preceding intervals. An incoming-read record specifies the initial value or the actual final value written in the last preceding writing interval, since all earlier replays in the induction already agree. At an unlisted external read, any nonzero incoming word would have a last earlier writer ending with that nonzero word and would violate the pair test. All scratch values consumed in this interval therefore agree as well, inductively through its adaptive addresses and local writes. Its steps and outgoing controller are genuine. This gives a legal run up to the signal even if different addresses use different formats and almost all accessed addresses were omitted. ## Deriving the exponents

Use the bounded nonacceptance assertion $B(e,c)$ of the [baseline proof](hybrid-tape-cut-trading.md#charging-the-public-proof-and-the-challenged-group-separately). On a source with clock $R$, public input length $m$ words and $H=\max(2,R,m)$, a sound nondeterministic nonacceptance certificate costs $(R^e+m^c+1)H^{o(1)}$. Baseline $B(c,c)$ follows from the SAT hypothesis via the ordinary locally readable 3-CNF compiler. On a true nonacceptance the recognizer's run on this virtual formula takes $T\le H^{c+o(1)}$ and gives $P\le H^{c\nu+o(1)}$. Word-width adaptation and the formula generator are implemented by the verifier of each local simulation. They are not scratch operations of the measured guest.

Write $\alpha=1/(d+1)$. For $1\le e\le c$, set
$$
 g=\max\left\{\frac{c}{1/c+\alpha/e},\ c^2\nu\right\},\quad x=g/e,\quad y=g/c .
$$
Use $b=H^{x+o(1)}$ and $u=H^{x/(d+1)+o(1)}$ rounded constructibly. The $T/u$ and $u^dT/b$ terms have exponent at most $c-\alpha x\le y$, the $T/b$ term is no larger, and $c\nu\le y$. Thus $Y\le H^{y+o(1)}$ and $x\ge y$. Guess the chart and apply $B(e,c)$ to the one nondeterministic defect search of time $H^{x+o(1)}$ with $O(m+H^{y+o(1)})$ public words. Input reads through to the original source using the local formula generator. This yields $B(g,c)$ since $ex=cy=g$. As usual $m^c$ covers the $H=m>R$ case when $g\le c$. Cap all computations on dishonest guesses and all clocks on wrong signs.

The first branch of this increasing map has positive fixed exponent $c^2-c\alpha$ and is strictly below $e$ for every $e\ge1$ if that fixed exponent is less than one. The second branch is already strictly below one under (1). Iteration from $c$ therefore reaches $g<1$ in finitely many steps, by continuity if necessary. At $c=1$ one step suffices. Strictness permits small rational slack and integer clock rounding. $B(g,c)$ contradicts complementary native bounded acceptance on the padded diagonal with $R=n^D$, $m=O(n)$ and any sufficiently large fixed integer $D>c$. The nondeterministic certificate would verify nonacceptance of its own complementary clocked interpreter in $o(R)$ time. The [packed compiler and diagonal](packed-band-transfer.md) charge the ordinary encoded length and the native interpreter. With no tape, take a group to be one consecutive interval of $b$ steps. Its geometric cost is $O(1+T/b)$ and the identical proof has $\alpha=1$, giving the golden-ratio inequality in (1)'s place.

For the logarithmic claim a single application suffices. Take a fixed complementary bounded-acceptance diagonal at native horizon $t=n^D$ for a sufficiently large fixed $D$ (for example with $D\ge3$ and fixed interpreter slack). Put $L=\lceil\log_2(t+2)\rceil$. Its ordinary SAT encoding and the linear-time negative recognizer have clock at most $tL^K$ for fixed $K$. On a true nonacceptance, a putative $P=O(N/\log^A(N+2))$ gives $P=O(tL^{K-A})$, since $N\le tL^K$ and $z/\log^A(z+2)$ is eventually increasing for each fixed $A$. Choose $u$ of order $t^\epsilon$ and $b$ of order $t^{1-\epsilon}$ with $0<\epsilon<1/(2d+2)$ rational. The directory size $Y_0$, the defect replay length $b$, and $m=O(n)$ are all $O(t^{1-\eta})$ for some $\eta>0$, allowing the fixed logarithmic factors. Guess the chart, then compile the single nondeterministic defect search into ordinary SAT with public data consisting of the chart and original input. Apply the linear-time negative recognizer on that formula with a clock cap. It signals exactly on valid charts when run to its true negative bound and can never falsely signal; the outer nondeterministic path accepts when it signals. The total time is
$$
 O\big((t^{1-\eta}+1+tL^{K-A})L^J\big)
$$
for some fixed $J$ covering dictionary operations, both compilations, copying public data and simulation. The powers $K,J$ can be fixed before $A$: use a public cap of order $t/L^{J+g+2}$ on charged chart words, where $L^g$ covers fixed universal-interpreter overhead and $K$ has already absorbed construction of the first formula. True charts fit for $A>K+J+g+3$. The cost on every path is then $o(t/L^g)$, contradicting the complementary diagonal. No numerical logarithmic exponent or optimized constant is claimed. The cap is within the polynomially related clock regime of the packed compiler.

## Repeated large states and the limit of the estimate

There is an alternative exact encoding for cuts that repeatedly return to a large scratch state. Represent all internal boundary states by the roots of a single dictionary of binary address tries, with a shared implicit zero node at each height. Intern leaf values and internal tuples (height, left child ID, right child ID) by deterministic sorting. Validate all heights and canonicalize bottom up before replay. An interval starts at a root, uses a persistent update and exact interning on each store, and compares the resulting root to its declared successor at each internal cut. Identical canonical roots are equivalent to equality of the entire address array. A dictionary of $S$ distinct charged nodes and the per-boundary roots cost $O(Y_0+S)$ words, and the defect clock is $(1+b+Y_0+S)\operatorname{polylog}(T+N+2)$. Let $L_*$ be the minimum sum of Hamming distances of a spanning tree on the distinct boundary arrays including zero. By constructing each child from its parent in that tree with persistent point updates, $S=O(1+w L_*)$ for $w$ address bits, independently of chronological order. The verifier only needs the supplied DAG, not the spanning tree. This also gives $S=O(1+w\sum_j\min(D_j,S_j))$, where $D_j$ is the Hamming distance from the preceding boundary and $S_j$ the number of nonzero words at the new boundary: attach each boundary either to zero or its chronological predecessor. [Exact interning used earlier in this journal](fair-tape-work.md#merging-full-ram-configurations) · [Driscoll, Sarnak, Sleator and Tarjan on persistence](https://www.cs.cmu.edu/~sleator/papers/making-data-structures-persistent.pdf)

Even when the head never moves, an ordinary linear-time computation can fill an array of distinct addresses and then read every word back. This yields $P=\Theta(T)$ with a fixed instruction set and full scratch capacity. Thus the linear-time SAT hypothesis alone supplies no suitable upper bound on this measure by generic native step counting. A SAT-specific argument would need more information about computations deciding the verdict. The mixed-format verification and time bounds have manuscript proofs. The code checks finite instances and the Lean file proves the patch component. Historical priority for the tradeoff remains undetermined.

For comparison, positive peak scratch exponents close to zero already follow from earlier pure-tape lower bounds. With a public cap of $S$ scratch words, replace each guest geometric cell by a box with $O(S\operatorname{polylog} N)$ physical cells. Reserve a fixed track for the guest symbol and carry a sorted sparse scratch dictionary in the current box. Scanning the dictionary simulates one guest access. On a unit head move, copy its entries to corresponding slots of the adjacent box, one shuttle of $O_d((S\operatorname{polylog}N)^{1/d})$ moves per symbol plus scanning and counter overhead. Use fixed box geometry, auxiliary counters of polylogarithmic size and separate tracks for stale scratch and guest symbols. A length header specifies the live dictionary in the new box. The pure-tape-with-subpolynomial-scratch clock is $TS^{1+1/d}\operatorname{polylog}N$ for constructible $S\ge1$. Thus an earlier pure/subpolynomial-scratch exponent $r_d>1$ yields an exclusion whenever $c(1+(1+1/d)\omega)<r_d$ under a peak cap $S=O(N^{c\omega})$. This observation matters when comparing the scope of the polynomial-occupancy curve and (1).
