# Verifying arbitrarily many XOR diagonals in aligned history charts

Use $B=2^m$ and index a table of $T'=B^2$ rows by $t=Bi+j$, with $0\le i,j<B$. Each bit column starts with a fixed-arity Boolean function of affine forms in the $2m$ index bits, XORed with rectangle indicators and with terms
$$
  [i\in I]\,[j=i\mathbin\oplus\delta].
$$
Here $I$ is an ordinary half-open integer interval. The extra hypothesis concerns only the rectangles. Give them as dyadic products $I_p\times J_q$ fixing high-order prefixes of length $p$ and $q$ respectively. Require $p\le q$ for each such term. A chart may specify all $B$ distinct values of $\delta$. Charge every listed term and column header to its size $s$. For intervals initially given by two endpoints one may use the usual disjoint dyadic decomposition and test the prefix condition on the resulting pieces.

**Lemma.** The constant-arity local gates of a regular square RAM tableau with these charts can be checked deterministically in $(1+s)\operatorname{poly}(m+1)$ word time. The number of distinct diagonal offsets enters only through their listed terms. Here the tableau uses a polynomial-in-$m$ list of local gate types with row lookups at the same row, fixed XOR neighbors or the next chronological row. Row-bit guards for sorting directions and the initial or final row are as detailed below. An arbitrary additional predicate on the row index is outside the lemma unless supplied with its own check. The certificate may include the local columns of a polynomial-in-$m$ Boolean gate implementation of a public formula-word generator, just like the instruction gates.

Apply the bijection $(i,j)\mapsto (j,d)$ where $d=i\oplus j$. On $J_q$ the top $p$ bits of $j$ are fixed. Thus the condition $i\in I_p$ is precisely a single fixed $p$-bit prefix of $d$. It follows that $I_p\times J_q$ is an ordinary dyadic rectangle in the new coordinates. The affine form in the index bits stays affine. A diagonal term becomes $d=\delta$ times $j\oplus\delta\in I$. Decompose $I$ into at most $2m+1$ dyadic intervals. XOR by a constant maps each dyadic interval to another dyadic interval of the same size, giving $O(m+1)$ rectangles. An XOR translation of the original row index before this bijection preserves the prefix lengths, translates the track offset and gives the same bound for its interval support. In particular no loop over unused offsets is necessary. [Exact prefix and supported-diagonal identities in Lean](../lean/GeometricHistory.lean)

A rectangle with $p>q$ may instead be split into $2^{p-q}$ terms by refining $J_q$ to depth $p$. Therefore $s+\sum_R 2^{\max(p_R-q_R,0)}$ can replace $s$ for an arbitrary dyadic list. The sum is over base rectangles. A maximum excess $p-q=O(\log(m+2))$ still costs only a polynomial factor in the index width.

## Counting local violations

For a fixed local test and a fixed XOR translation for each operand, collect the constantly many base affine forms used by these bits. Their joint value is $a(j)\oplus b(d)$ for two vector-valued affine maps, with each constant included only once. The rectangles contribute a separate flip mask $v(j,d)$, one coordinate per operand. Thus the claimed input bits are obtained by applying their Boolean base functions to the form values and then XORing the components of $v$. Additional guards on a constant number of individual index bits can be included among the affine coordinates.

Sweep over the integer $j$ endpoints of the rectangles. Between consecutive endpoints, maintain the joint histogram of $(b(d),v(j,d))$ over all $d$. A lazy segment tree on the compressed $d$ endpoints maintains these counts. Toggling a mask across an interval permutes a constant-size vector at each covered node, preserving the separate form coordinates. Initialize each leaf with zero mask by splitting its interval into dyadic blocks. The number of words in a block with any specified affine image is zero for an inconsistent binary linear system and otherwise is $2^{m-r}$, with $r$ the rank of all its constraints including the fixed prefix. This is computable in $\operatorname{poly}(m+1)$ steps. On a $j$-strip use the same computation for the histogram of $a(j)$, including any additional independent fixed bits of $j$. Multiply the two histograms, evaluate the Boolean base functions, apply the masks, and count exactly the grid points on which the local test fails. Integers counting points are at most $B^2$ and use $O(1)$ native words with the polynomial-clock convention. The construction uses $O((1+s)\operatorname{poly}(m+1))$ steps over all gates, since there are only polynomially many gate types and all pulled-back terms have polynomial-in-$m$ expansion.

For a chronological successor with $j<B-1$, let $r<m$ be the number of low one-bits of $j$. On that branch $t+1=t\oplus(2^{r+1}-1)$. The branch condition fixes the low $r+1$ bits of the **retained** coordinate $j$, so the strip histogram enforces it directly, with no enumeration of residues. If $j=B-1$, the old low half is a singleton. Partition $i$ by its trailing-one count to compute a fixed XOR translation for the successor, omitting a wrap past the final row when appropriate. In this case the check is one-dimensional in $i$. A dyadic rectangle restricts to at most one interval on the line, and each diagonal track hits at most one point. The affine histogram and interval sweep in one dimension count all failures including the fixed suffix of $i$. A designated initial or final row can be inspected separately. Several translated successor lookups of fixed arity permit the same proof by branching on their carry cases, retaining a polynomial-in-$m$ number of branches. An overflow of the low half by any one such translated index fixes the original $j$ to a singleton.

In the usual power-of-two bitonic schedule, stride $2^r$ uses neighbor $t\oplus 2^r$. For the merge of size $2^a$, the decision whether to emit the smaller or larger record on a lane depends on bits $a$ and $r$ of its index. A bit beyond the index width is zero. After the change of variables each of these bits is an affine bit of $(j,d)$ and they add only constantly many histogram coordinates. Adjacent comparisons in the final sorted table use the same chronological-successor check. One may idle a sound solver through the full square clock and use every row, with the endpoint handled separately. A separate cutoff on which rows are live would need to be represented or checked too. The argument concerns the augmented history including the comparator and arithmetic gate columns. A compact description for the architectural registers alone need not describe these columns.

## What fails for unrestricted pairs of prefixes

The general problem of counting violations already contains three-list 3XOR. For sets $X,Y,Z$ of $m$-bit words specify three columns. The first is a union by XOR of the disjoint singleton rows $i=x$ for $x\in X$, the second uses the singleton columns $j=y$ for $y\in Y$, and the third uses the disjoint full tracks $j=i\oplus z$ for $z\in Z$. The tuple $111$ occurs precisely when some $x\oplus y=z$. The description uses $O(|X|+|Y|+|Z|+1)$ words. One may use three copies of the same set for the usual one-set version after handling zero separately if distinct elements are required. Therefore a uniform near-linear algorithm for the unrestricted forbidden-tuple test would give a near-linear algorithm for logarithmic-word 3XOR. This implication supplies no unconditional lower bound on the cost of such a test. The row singleton has prefix lengths $(m,0)$, which the positive theorem excludes. [Dietzfelbinger, Schlag and Walzer](https://doi.org/10.4230/LIPIcs.MFCS.2018.59)

On the hard pinned pair, guessing an aligned chart and running this verifier gives an ordinary bounded-acceptance SAT instance for each tested cap. Its size is $s\operatorname{poly}(\log T')$ when the chart cap and horizon are polynomially related and both exceed the polylogarithmic setup. This removes the multiplicative number of tracks for the stated subclass. An unrestricted lower bound would still require a sufficiently short aligned chart for an actual sound computation.
