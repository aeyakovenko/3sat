# Compiling native computation blocks from short boundary descriptions

Suppose that a proposed $r$-bit boundary tuple for one computation block can be checked in $B$ RAM steps. For $h$ blocks of this kind, the compiler below uses $O(h(1+2^r/(r+1)))$ Boolean gates, preserves accepting path counts and computes each output bit in $O((B+1)\operatorname{polylog}t)$ native time when $r=O(\log t)$. For $B$ a fixed positive power strictly smaller than $t$, $h=O(t/B)$ and $r\le\log_2 B+O(1)$, the proper DIMACS file has $O(t)$ bits. A separate construction tests the direction of the threshold inequality in the shortest-presentation argument. [Unambiguous compiler criterion and threshold tests](a-canonical-short-witness-for-locally-indexed-sat.md)

## What a boundary tuple must determine

Let $t$ be the unary native clock and suppose the encoded length $s=\Theta(t)$. The input specifies, or a uniform polylogarithmic-time indexer gives, the following data.

* There are $h$ blocks, $q\le hr$ actual Boolean history coordinates and $r$ port positions per block. A port refers to a coordinate of $z\in\{0,1\}^q$ or to a public constant. Padding a shorter interface uses constants. All layout parameters, the address of each reference and each constant are locally computable with random access to the source. They are polynomially bounded in $t$.
* Each block $i$ has a predicate $P_i(y,a)$ on *every* proposed $r$-bit tuple $a$, including incorrect tuples. A fixed program computes that predicate in $O((B+1)\operatorname{polylog}t)$ native steps. It may use arbitrary random access to its own workspace. Alternatively, either claimed reply has exact bounded nondeterministic certificates in that time, under a common computable clock.
* The assignments $z$ satisfying all the block predicates on their indicated tuples are in bijection with accepting paths. In an application this is a semantic condition to prove. Unused storage, padding and redundant names cannot become free Boolean choices.

For example, take $h$ successive procedures with fresh private workspaces and a shared read-only input. Procedure $i$ computes its output state deterministically in $B$ steps from its input state and its specified local choice bits. Its predicate checks the proposed output and any acceptance flags. Count incoming state, choices and outgoing state in $r$, with one global coordinate per actual shared bit. Use fixed start-state bits and enforce the terminal test. If a procedure stops guessing early, require remaining choice bits to be zero and use one canonical encoding of each legal choice. Each accepting run then determines precisely one passing $z$. A procedure may fill $\Theta(B)$ private cells. An ordinary RAM carrying other mutable words between procedures needs a proof that the listed ports capture those words' effects.

## A locally indexed circuit for each relation

For $r\ge4$, split off $k=\lfloor\log_2 r\rfloor-1$ low input bits and put $K=2^k$, so $r/4<K\le r/2$. The high part has $H=2^{r-k}$ settings. Small $r$ uses a constant template. For low and high coordinates separately, compute every full equality indicator using a binary prefix tree. Each nonroot node ANDs its parent with the next signed input. This costs $O(K+H)$ gates. Build a library output for each of the $2^K$ subsets of low settings. For subset mask $m$, a fixed chain of $K$ gates ORs together the indicated equalities, using a false constant at excluded positions. There are $K2^K$ gates in this library.

For each high value $j$, select the library mask whose $\ell$-th bit is $P_i(y,jK+\ell)$. AND this library output with the corresponding high equality indicator, then OR over $j$. On any input exactly one high indicator is true and that row returns the required bit. The total is $O(H+K2^K)=O(2^r/r)$ gates per block. This is the classical Shannon–Lupanov circuit-size bound. Here its fixed arrangement controls local access and the number of extensions in DIMACS. [Frandsen and Miltersen, explicit construction and counting bounds](https://www.sciencedirect.com/science/article/pii/S0020019005000864)

Give every gate a fixed address. A depth-$d$ prefix with index $j$ has offset $2^d-2+j$ within its tree. The library offset is $mK+\ell$. High-row ANDs and the final OR chain have successive addresses. Only the library pointer at a high row depends on the block's truth table. Compute its $K$ mask bits by separate evaluations of the block on the stipulated tuples. Since $K=O(\log t)$, this uses $O((B+1)\operatorname{polylog}t)$ steps. In the nondeterministic version, guess the mask and certify every one of its bits, using a fresh simulated work memory for each check. This certifies both possible answers to any resulting output-bit query. The number of such certificates for one bit is unrestricted.

To make the bit index physical, reserve three global pins, forced false by the seven distinct ternary clauses that exclude the other three-bit assignments. Every gate has a fresh output variable. For each gate, take the distinct names of its output and its at most two operands, ignoring signs for this enumeration. Extend the list to three distinct names using pins. For each of their eight settings, output a clause forbidding that setting if the gate relation fails. Otherwise output a fixed clause true on the pinned values. This handles coincident and signed operands, including constant wires supplied by pins. Require each block's output by a clause padded with two false pins. Give each actual coordinate a clause containing that coordinate and a true pin so the coordinate occurs even when a predicate ignores it. Any required zero padding in a history is either a constant or constrained by its predicate. All gate names, including unused library outputs, are fixed by their gate equivalences. Thus every passing $z$ extends uniquely and every model restricts to a passing $z$.

The layout has $O(h(1+2^r/(r+1)))$ clauses and variable slots, including the $q\le hr$ inputs because $r=O(1+2^r/(r+1))$. Write canonical decimal spellings, aligned by ordinary spaces into fixed-width literal fields. The header length, the clause count, the field widths and all section boundaries follow from the layout parameters. Division by the line width locates a clause from a byte address. Its block and gate are found by fixed arithmetic. Computing even one digit of a selected library name can require all $K$ table replies, already included in the index bound. Raw output length is

$$
                 O\bigl((1+h(1+2^r/(r+1)))\log(t+2)\bigr).
$$

For $B=2^{\lfloor\alpha\log_2 t\rfloor}$ with fixed rational $0<\alpha<1$ and $h=O(t/B)$, the bit indexer is strongly sublinear. Whenever $2^r/(r+1)=o(B)$ the file has $o(t\log t)$ bits. This includes $r\le\log_2 B+\log_2\log_2 B-g(B)$ with $g(B)\to\infty$, and gives $O(t)$ bits at $r\le\log_2 B+O(1)$. Sharing row functions gives the improvement over outputting a clause for each failed tuple. Counting limits a construction that treats one block predicate as completely arbitrary. Circuits with $g$ bounded-fan-in gates, including existential auxiliary inputs, have at most $2^{O(g\log(g+r+2))}$ distinct descriptions after discarding unused auxiliary inputs and renaming the rest. There are $2^{2^r}$ relations. Some therefore need $\Omega(2^r/r)$ gates. The count concerns one arbitrary block function. Several blocks of a single RAM program may share structure.

The missing step for an unrestricted unambiguous history is a uniform choice of ports with the required size, evaluation cost and path bijection. For a block that consumes and later exports several arbitrary logarithmic-width words, each word contributes its full width to the proposed tuple. Uniqueness of a complete accepting path alone gives none of the required local evaluation algorithms.

## Compiling an actual word transition by its output bits

Suppose a block deterministically computes $m$ output coordinates and one validity bit from $d$ incoming and choice bits. Use one predicate for each output equality, on the $d$ input bits and the one proposed output bit. The validity bit needs only the $d$ inputs. The circuits above give $O((m+1)(1+2^d/(d+1)))$ gates altogether. All output coordinates are the actual shared bits of the proposed history. Correct inputs force their values. This avoids tabulating an arbitrary relation on $d+m$ bits. Each gate's local indexer invokes at most $O(d+1)$ forward block evaluations. For a $w$-bit state passed between deterministic blocks, $O(2^w)$ gates per transition suffice. The resulting file is $o(t\log t)$ if $w\le\log_2 B-g(B)$, where $B=t^{\alpha+o(1)}$, $0<\alpha<1$, and $g(B)\to\infty$. The number of maps on $w$ bits is $2^{w2^w}$, giving worst-case gate cost $\Omega(2^w)$ for their graphs by the same circuit count.

There is a sharper threshold for word transitions preserving congruences. On residues modulo $2^w$, suppose every block map $f$ satisfies
$$
       a\equiv b\pmod {2^j} \quad\Longrightarrow\quad f(a)\equiv f(b)\pmod {2^j}
                 \qquad(1\le j\le w).
$$
This condition holds for a program whose instruction choices and accessed addresses are determined by public data, with a single incoming word and word-value operations consisting of addition, subtraction and multiplication modulo $2^w$, bitwise AND, OR, XOR, complementation and fixed left shifts. Prove it by running the block on congruent words. After every step, all corresponding registers and private cells have congruent contents. Public input reads return identical words, corresponding private loads use the same address, and every listed value operation preserves the congruence. Private memory may be as large as the step clock permits. The rank of a privately addressed cell or a high-bit-dependent branch is a separate issue for a general RAM.

The $j$th low bit of $f(a)$ depends only on the $j$ lowest input bits, for $1\le j\le w$. Check that output bit against the transition run on the zero-extension of those $j$ bits. Its equality predicate has $j+1$ ports. The synthesis size is at most
$$
        O\left(\sum_{j=1}^w\left(1+\frac{2^{j+1}}{j+2}\right)\right)
                 =O(1+2^w/(w+1)).
$$
For the last estimate split at $w/2$ and sum two geometric bounds. An arbitrary publicly specified validity test on the incoming word, computable within the same block clock, costs another $O(1+2^w/(w+1))$ gates. To index unequal scalar templates, compute their $w$ cumulative section lengths from the template formulas once the block number is known; $w=O(\log t)$. At $w\le\log_2 B+O(1)$ and $B$ a fixed power of $t$, the proper file has $O(t)$ bits, including all output bits and their distinct gate completions. The short-compiler cutoff holds up to $w\le\log_2 B+\log_2\log_2 B-g(B)$.

This cost is sharp for black-box congruence-preserving maps, even when every map is invertible. For zero-based bit $i$, independently choose a Boolean function $g_i$ of the $i$ lower input bits and set the output bit to $a_i\mathbin{\mathrm{XOR}}g_i(a\bmod 2^i)$. The lower output bits recover the lower input bits inductively. Each choice of functions gives a distinct bijection, and their number is $2^{\sum_{i=0}^{w-1}2^i}=2^{2^w-1}$. The circuit counting bound therefore gives $\Omega(2^w/w)$ gates for some graph in this class. It does not establish that a fixed short native program realizes the hard map. A one-bit right shift already violates congruence modulo two on inputs $0$ and $2$, and an indirect load from a public table can implement any chosen one-bit function of its address.

## Reversing the length test admits arbitrary recorded histories

There is an unconditional presentation for every bounded nondeterministic RAM acceptance problem with the following properties. Every minimum-length formula has one model on a positive source and none on a negative source. Its length is bounded by an absolute constant and its raw bits on minimum presentations take constant time. On every pad, the strict inequality $|F(y,r)|>k$ has a polylogarithmic-time nondeterministic test for all thresholds $k$. This gives a counterexample to sparse replay when the sense of the length test is reversed. It leaves the elapsed time for deciding SAT open. [The positive threshold needed for sparse replay](a-canonical-short-witness-for-locally-indexed-sat.md#selecting-a-shortest-presentation-without-increasing-ambiguity)

Use a pad with a flag and an explicit candidate accepting trace. Include chronological and address/time-sorted events and two mutually inverse permutations associating the rows. A violation has a local witness, checking instruction steps, initial data, boundary control, registration, sorted order and the value of a read after the latest preceding write. Use a fixed layout through the allotted clock, with terminal stuttering for early acceptance. A failing index or malformed noncanonical field is itself a defect. An accepting native path gives at least one defect-free pad, and a defect-free pad reconstructs an accepting native path. The number of accepting paths of the source can also be restricted to zero or one. [Details of the local trace test](locally-short-sat-compilers-with-a-free-presentation.md)

Fix three proper files $G,C,D$ in strictly increasing lengths. Use the seven pin clauses for $G$, append the false clause on all three pins for $C$, then append another fixed clause for $D$. Thus $G$ has one model and $C$ has none. If the flag is zero, output $C$ unconditionally. If it is one, output $G$ for a defect-free accepting trace and $D$ otherwise. A positive source attains $G$. A negative source has $C$ as its minimum. On minimum pads the flag alone selects between the fixed $G$ and $C$, so every valid raw bit address has its exact constant-time reply. For flag zero compare $|C|$ to $k$. For flag one the strict-inequality test accepts unconditionally below $|G|$, rejects at or above $|D|$, and otherwise has to exhibit just one defect. At the same middle thresholds, testing the non-strict inequality for flag one requires certifying that no defect occurs.

To see the failure on dense edits, require the chronological pad array to store its one-based times $1,\ldots,t$, each in an aligned fixed-size slot, including terminal stutters. Check any nominated time against its row index. On positive files every shortest pad now has at least one nonzero word in each of $t$ distinct slots. A zero-default pad with $o(t)$ changed words cannot attain the minimum, even on a fixed deterministic always-accepting machine. The timestamps are predictable. This separation is specifically about the sparse completion justified by an accepting threshold path. Another implicit representation may encode them compactly.

## Finite checks

On all 256 ternary truth tables the synthesized circuit agreed on all eight input settings. An independently parsed proper DIMACS file for two blocks with shared, repeated and signed ports had 151 variables and 1,165 clauses. CaDiCaL checked all 16 fixed inputs, and a second call excluding the complete model gave UNSAT for each of the four positive inputs. The audit also compared 340 byte indexes to the physical file and checked every row-mask probe list in an eight-port block. A four-bit public-address word program using multiplication, XOR, shifts, private stores and private loads passed 240 pairwise congruence tests. CaDiCaL checked all 256 input/output pairs and excluded a second completed model on each of its 16 graph points. For the reversed inequality, the audit enumerated 1,152 flagged trace presentations of a deterministic two-store/one-load program and checked 27,648 integer thresholds.
