# A two-ahead scan in an arbitrary public permutation order

At an encoded length $n$, let $S$ be any publicly specified single cycle on the $Q=2^w$ word addresses, with a public starting address. At stage $i$ a controller reads $x_i=M[p_i]$, where $p_{i+1}=S(p_i)$. Every stage that continues to the next read executes the single memory write $M[x_i]\gets p_{i+2}$. The controller may exit early. Its $s$-bit internal state includes all private registers and control information, and this schedule is its only access to memory. The initial controller state is public and independent of the private sign choices. The initial memory consists of the packed file and zero elsewhere. Public parameters and the whole permutation may depend on the length. The two-ahead rule and its propagation after an equality were introduced in the [six-slot scan note](two-ahead-stores-in-a-six-slot-scan.md).

**Claim.** On the equality files constructed below, suppose that at each of arbitrarily large lengths there is an address $z$ such that, for every input in the family, $M_0[z]=S(z)$ and $z$ is absent from the initial memory image. Any controller deciding every file at those lengths has

$$
 s+O(w)\ \ge\ k,\qquad k=\Theta\!\left(\frac{n}{(\log n)^2}\right).
$$

In particular this excludes a controller with a constant number of word registers and a fixed finite control, regardless of its running time. The model takes $w=16\lceil\log_2(n+2)/16\rceil$ and allows unused variable identifiers in the DIMACS header.

## The first visit to $z$

Write $t<Q$ for the first stage visiting $z$, assuming that stage is reached. A pre-$t$ write to address $z$ must read the value $z$. This value is absent initially. Its only possible earlier producer is the stage with address $S^{-2}(z)$, since a store at $u$ has payload $S^2(u)$. In the first lap that producer has either not yet occurred or occurred exactly two stages before $t$. Therefore the only stage before $t$ that could write to $z$ is $t-1$, whose payload is $S(z)$. Hence $x_t=S(z)$, even allowing such a write. This argument concerns $Q>2$, as suffices here.

At the first equality $x_i=p_{i+1}$ the next continuing write sets $M[p_{i+1}]=p_{i+2}$. Induction determines every later read solely from the public schedule. Any controller reaching $t$ has thus entered this regime by $t$. [Lean proofs of the first-lap trigger and propagation](../lean/TwoAheadFirstLapLock.lean)

Before the first equality, at most $2h$ distinct addresses have received writes in the first lap, where $h$ is the number of distinct initial memory values. To see this, suppose a read at stage $v<Q$ obtains its value from a write at $j<v$, and that the read at $j$ in turn obtains its value from a write at $u<j$. Then $x_j=p_v=S^2(p_u)$. Thus $v-u=2$ modulo $Q$, hence exactly 2, and $j=u+1$. The earlier write to $p_j$ then required $x_u=p_{u+1}$, contradicting the prefix condition. For every write in this prefix whose destination $x_v$ lies outside the initial image, its load therefore has a most recent writer $j$ whose own load returned an original word. In particular $p_v=x_j$ belongs to the initial image. The scan visits each such $p_v$ at most once in the lap. There are at most $h$ writes to destinations outside the image and at most $h$ distinct destinations inside. The proof includes visits to cells that were overwritten with their initial value.

## Placing the two parties in scan order

Use two common variables $u,v$ forced false by eight public proper clauses. For each of $u,v$ take all four clauses with its negation and the four choices of signs on two distinct fresh dummy names. Reserve $2k$ equal-length pin records, each a single clause $(\pm x_j\lor u\lor v)$. The sign of its first literal is the sole private bit of each record.

All names have equal encoded length. For distinct public indices represented by $K=\lceil\log_2(k+6)\rceil$ binary digits, make a decimal name by emitting a leading 1 and then one block of $W=w/8$ decimal digits per index bit, namely $W-1$ zeros followed by that bit. Declare the all-ones name in the header. After rounding the header to a word boundary using whitespace, begin each literal with an aligned word consisting of $W-2$ spaces, its space-or-minus sign, and the initial digit 1. The following $K$ words encode the index. Place a fixed aligned clause terminator after each three literals. This works for large $W$. The header, dummy clauses, and all pin records fit when $k=\lfloor n/(C(\log_2 n)^2)\rfloor$ for a sufficiently large fixed $C$. Fill the remaining bytes with whitespace. Across all pin assignments and permutations of the names, the initial word alphabet has constant size, including header words, a possible partially filled final word, and the zero outside the file. The long repeated part of the maximal name in the header has period one word. Only a constant number of header words meet the ends or the clause count. The four common variable names are distinct from all $x_j$. [Word-aligned decimal naming construction](communication-bound-for-public-crossed-scans.md)

First fix these $2k$ physical sign-word addresses, which are independent of the choice of $j$ in each record. List the addresses in order of their first visit from the public start. Give the first $k$ signs to Alice and the last $k$ to Bob. Assign the name $x_j$ to the $j$-th sign in *each* part. With this name assignment fixed publicly, every non-sign word is public. The private bits occupy distinct words and never move. Satisfiability is precisely equality of the two $k$-bit strings. This construction permits any first-lap order, including one that interleaves the parties' physical records in the file.

Alice simulates until the first equality $x_i=p_{i+1}$, an early exit, or the boundary immediately before Bob's first private address. Before that boundary she knows all original words that can be requested. If the read equality arrives first, she can determine every subsequent read and run the controller to its verdict. If she reaches the handoff, she sends Bob the controller state and the address and current value of each cell written so far. These records and framing use $O((h+1)w)$ bits. The boundary is public. During the rest of the first lap Bob encounters no Alice sign again. He can answer every read using the transmitted records, his own later writes, and the publicly known or Bob-owned originals. By the first visit to $z$, the computation has either exited or all future reads are determined. The protocol terminates under the assumed total correctness of the controller. It costs $s+O(w)$ bits since $h=O(1)$. A deterministic equality protocol needs at least $k$ bits by the accepting-diagonal rectangle argument. This proves the claim.

## Length-dependent modular strides

Let $S(p)=p+d\pmod Q$, where $d$ is any public odd integer in $[1,Q/2]$, possibly different at every length. Take $z=Q-d$. Then $z\ge Q/2$ is beyond the physical file for large $n$ and $S(z)=0=M_0[z]$. Every packed seven-bit ASCII word is strictly below $Q/2$, including a zero-padded final word. Zero outside the file also differs from $z$. The claim therefore applies at every sufficiently large byte-aligned length and for any public starting address, even when this positive stride grows with $n$. The proof for a fixed negative stride using a specially padded final word is in the [fixed-stride manuscript](six-slot-two-ahead-lock.md).

This result concerns one prescribed memory schedule with no extra memory operations. Lean checks the first-lap trigger and its propagation. The communication argument is a manuscript proof. The general case of six stored instructions and the unrestricted RAM running-time goals remain open.
