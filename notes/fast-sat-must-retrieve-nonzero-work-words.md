# A fast unrestricted SAT solver must retrieve nonzero words at many addresses

On the logarithmic-word RAM with read-only random-access input and zero-initialized work memory, let $k_M(F)$ be the number of **distinct work addresses** from which the deterministic solver $M$ retrieves a nonzero value at least once on $F$. There is no bound on the addresses written, the words containing nonzero values, input rereads, the number of zero answers, or the physical workspace.

* On ordinary explicit DIMACS 3-SAT there is no simultaneous worst-case bound of $N^{c+o(1)}$ time and $N^{e+o(1)}$ such addresses when $1\le c$, $0\le e\le c$, and $c(c+e)<2$. In particular, if a linear-time solver exists it must make genuine nonzero retrievals at more than $N^{1-\epsilon}$ distinct addresses on arbitrarily long files for every fixed $\epsilon>0$. The tradeoff excludes every $e<7/15$ at $c=6/5$ and every $e<1/6$ at $c=4/3$.
* For the fixed-width binary encoding of the packed trace reduction, for every fixed integer $a\ge0$, SAT cannot have both $O(N\log^a N)$ time and $O(N/\log^{3a+11}N)$ such addresses. In particular, $O(N)$ time forces an unbounded ratio $k_M(F)/(N/\log^{11}N)$. The same exponent applies to decimal DIMACS using the bounded lookup table below.

These are unconditional tradeoffs for every solver, separately on each verdict for fixed rational exponents in the strict region and for the displayed logarithmic caps. They use the classical complementary-time hierarchy and the local reduction to SAT. The additional step is to verify the whole computation by keeping a proposed set of work addresses and monitoring one further address selected after that set. Physical space can be as large as the runtime in words. The bounds allow a linear solver that retrieves nonzero data at a linear number of addresses. [Fortnow, Lipton, van Melkebeek and Viglas](https://lance.fortnow.com/papers/files/tst.pdf) · [Local reduction and word-RAM diagonal](packed-band-transfer.md)

## A single-address check of a proposed run

Fix an input, a deterministic $T$-step decider, and a budget $k$. Denote its actual set of nonzero-retrieval addresses by $S_*$. Given any set $S$ of at most $k$ work addresses, execute its **projection** by retaining exactly the words of $S$ and answering zero on all other work reads. Every finite $T$-step projection is well defined even on dishonest choices of $S$. Pad halts by stuttering. For another address $a$, run this projection with a passive extra register initially zero, updated by every store to $a$. Set an error flag if, on this projected trajectory, a work read outside $S$ at $a$ would receive zero while the passive register is nonzero. The register never changes the projected controller.

Assuming $|S_*|\le k$, the true run accepts exactly when
$$
  \forall S\ (|S|\le k)\quad \exists a\quad
  [\text{the projection does not reject by }T
    \quad\lor\quad \text{the monitor for }a\text{ flags an error}].
$$
On a true acceptance, a rejecting projection has a first incorrect read. Up to that read all stores agree with the true run. Reads inside $S$ are exact, so at this first difference the omitted true word is nonzero and its address witnesses the flag. On a true rejection choose $S=S_*$. The projection is genuine by induction, rejects, and no address ever raises the flag. Malformed set encodings pass the outer universal test. The witness needs only one word. This argument even allows unboundedly many writes at addresses at which the true program never retrieves a nonzero value. [Lean proof for adaptive RAM traces](../lean/OneWatchedWorkAddress.lean)

Use a sorted, padded list of $k$ addresses with a length field. Validate it in $O(k+1)$ steps, including each address against the simulated guest width before indexing a host bank. A passive address can be restricted to this same domain. For each selected interval build a zero-initialized, directly addressed bank mapping the $i$th listed address to $i+1$. Zero denotes absence. This takes $O(k)$ stores at the beginning of that interval and $O(1)$ time per lookup. The current values of the $k$ slots are serialized in list order in each snapshot, so there are no large address-indexed snapshots to guess. The fixed membership bank can be reconstructed from the read-only universal list independently at every segment. For fixed $S,a$ there are $O(k+\operatorname{polylog} T)$ mutable words, also on dishonest choices. The host RAM may use a wider constant in its logarithmic word width to hold separate banks while simulating the original guest semantics exactly.

Divide this monitor run into $p$ intervals. Existentially guess its $p+1$ controller-and-array snapshots and require valid initial and passing final states. Universally choose an interval and replay it. An interval costs its length plus $O(k+\operatorname{polylog}T)$ to compare endpoints and validate their fixed-length representations. This is an ordinary three-block alternating simulation, starting universal, with the address and snapshots in the same existential block. All blocks and the final check include their public inputs in the cost estimates below. Rejecting forged snapshots cannot call an unbounded subprocedure. The interval verifier has a public cutoff and bounds all local data addresses. Ordinary zero-valued reads on any real or projected trace are unrestricted.

## The exponent calculation

Start with a bounded nondeterministic hierarchy computation on $n$ input bits and clock $H=n^2$. Its virtual SAT instance has $H^{1+o(1)}$ bits and locally retrievable input words in $H^{o(1)}$ time. Apply the hypothetical solver to that instance. In the projected execution the immutable input generator is separate from the solver's writable RAM, and its scratch and tables need only $(\log H)^{O(1)}$ words. The solver clock is $H^{c+o(1)}$ and $k=H^{e+o(1)}$. For strict inequalities take rational, constructible upper clocks just above the given exponents, absorbing all $o(1)$ terms by fixed slack.

Choose $p=H^{(c-e)/2+o(1)}$. The snapshot guess, the input lengths for later reductions, and the time of an interval replay have exponent at most $q=(c+e)/2$ with respect to $H$. The original $n$ bits have exponent $1/2\le q$. Rebuilding the dictionary for a selected segment costs only $O(k)$ times a polylogarithmic representation factor. Eliminate the innermost universal block by running deterministic SAT on the explicit bounded existential search for a failing interval and reversing its verdict. The remaining existential stage, including the checkpoint guesses and that deterministic tail, now has public input and time at most $H^{cq+o(1)}$. Apply the ordinary SAT simulation once more to remove that existential stage. The result is a conondeterministic decision of the original hierarchy language in $H^{c^2q+o(1)}$ time. When $c^2q<1$ this contradicts complementary diagonalization. This one-shot check already gives a strict region. Each intermediate SAT slowdown can use unrestricted physical workspace. The root projection uses the retrieval budget only on the actual guest run. [Classical SAT slowdowns and alternation trading](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Hierarchy and finite-width simulation](packed-band-transfer.md)

A repeated application improves the region to $c(c+e)<2$. Write $m$ for the size in words of a generic nondeterministic verifier's public input and $H$ for the maximum of $m$, its clock, and 2. Inductively suppose that such a verifier has a conondeterministic simulation of time
$$
  H^{u+o(1)}+m^{c^2+o(1)} .
$$
The ordinary SAT reduction starts this at $u=c$. Only polynomial clocks and the corresponding fixed logarithmic-word coefficients are used. Each public input contains the original $n$-bit string throughout the bounded-depth simulation on $H=n^2$. All later address ranges are $n^{O(1)}$ with exponents determined independently of the original hierarchy word-width coefficient. The local trace reduction encodes even wide source addresses as Boolean data. Choose the diagonal host coefficient large enough for the physical addresses, preserving each fixed guest width as in the packed transfer. Apply the three-block root simulation to this verifier. As before, eliminate the innermost universal choice by the **ordinary** deterministic SAT simulation. The remaining existential computation now has clock $O((H^{q+o(1)}+m)^{c+o(1)})$. Crucially, its public input consists of the original input and the proposed support, of size $m+H^{e+o(1)}$. It makes the large checkpoint guesses *inside* this existential computation. Apply the inductive simulation to this one existential computation, merging the resulting universal branch with the first universal block. For $1\le u\le c$ the next exponent can be taken as
$$
 u'=\max\{cqu, e c^2\}.
$$
The contribution $m^{cu+o(1)}$ is absorbed by the same $m^{c^2+o(1)}$ penalty. If $cq<1$, also $ec^2<1$, since $e<2/c-c$ and $2c-c^3\le1$ for $c\ge1$. After finitely many applications $u<1$. All inequalities at the crossing can absorb fixed rational slack in clocks, guesses and reduction costs. Take $H=n^2$ and $m=O(n)$ for the complementary diagonal. Here $c^2<2$, so the original input term is $o(H)$. The application then contradicts the hierarchy. This repeated use of a simulation treats the quantified input sizes explicitly at each level. It never assumes the solver's resource caps on an incorrect projected computation.

## Logarithmic costs at linear time

Let $L=\lceil\log_2(H+2)\rceil$. The packed local reduction has at most $O(HL^3)$ bits. A word is available in $O(1)$ operations after setup using $\operatorname{poly}(L)$ words. The unrestricted, materialized reduction for any other machine on $M$ input words with a clock of $R$ costs $O(J\log^3 J)$ at $J=\max(M,R,2)$, by emitting the same clauses. If SAT costs $O(N\log^a N)$, this ordinary slowdown therefore costs $O(J\log^A J)$ with $A=a+3$. Take a proposed retrieval cap $O(N/\log^b N)$ and write $B=b-3$. On the root instance use $k=O(H/L^B)$ padded word slots and $T=O(HL^A)$ guest operations. Root local indexing and support membership cost $O(1)$ per interpreted guest operation after setup. The selected segment can rebuild its membership bank and install its initial slot values in $O(k)$ time.

Use the materialized-input reduction for the innermost universal elimination. For a nondeterministic machine with public input $M$ words and a search clock $R$, it writes a formula of $O(RL^3+ML^2)$ bits in that many steps. The input bank is a bounded-degree linear-size superconcentrator carrying each address-and-word pair. At most $O(R)$ queried outputs are joined to the computation trace by an ordinary sorting-and-consistency circuit. The term for the entire public input is one logarithm cheaper than the term for replayed instructions. Consequently the ordinary deterministic SAT slowdown here costs $O(RL^A+ML^{A-1}+\operatorname{poly}(L))$. This step materializes all the data and imposes no space or retrieval cap. [Materialized public-input reduction and its construction cost](materialized-input-census.md)

Set $p=\lceil L^x\rceil$. The segment challenge has clock $O(HL^{A-x}+k+\operatorname{poly}(L))$ and public input size $O(m+L^x k+\operatorname{poly}(L))$ words. Its selected interval checks its own endpoints, with the initial/final checks imposed at the incident intervals. A possible global failure is witnessed by one such local check. The challenged verifier accesses all of $S$ in $O(k)$ time and needs precisely two adjacent rows from the checkpoint list. For a fixed list materialize that lookup circuit directly. Decode the interval number to one-hot wires. In groups of $\lfloor L/8\rfloor$ indices compute all subset ORs, shared by the $O(kL)$ requested output bits of the two rows. Each requested bit is an OR of one precomputed mask per group. With $p\ge L$ and $k=\Theta(H/L^B)$ the circuit costs $O(pk)$ gates, and constructing its masks and writing its bounded-width clauses costs $O(pkL)$ operations. The two row outputs become input values of the small replay circuit. The ordinary $O(ML^2)$ term remains for the other public words, including $m$ and $O(k)$ words for $S$ and any shared predictor advice. The existential machine guessing the whole list pays $O(pk)$ native time. The resulting contribution of the full checkpoint table to the SAT slowdown is $O(pkL^{A-2})$. [Contiguous row selection and encoding costs](checkpoint-table-selection-for-sat.md)

At the materialized inner call the leading exponents relative to $H$ are
$$
 2A-x \qquad\text{and}\qquad x-B+A-2 .
$$
The list-guess cost and the term $kL^A$ also fit the maximum at the choices below. Balance at $x=(A+B+2)/2$, obtaining $W=(3A-B-2)/2$. The time of the entire remaining existential computation is $O(HL^W+mL^{A-1}+\operatorname{poly}(L))$.

Start with a conondeterministic simulation in time $O(HL^u+mL^{2A})$ at $u=A$, using the ordinary reduction. As long as $0\le u\le A$, apply the inductive simulation only to this remaining existential computation, whose public input has size $O(m+k+\operatorname{poly}(L))$. Its two cost terms give a fresh bound $O(HL^{u'}+mL^{2A})$ with
$$
 u'=\max\{u+(3A-B-2)/2,\ 2A-B\}.
$$
Indeed the first term of the inductive bound charges the remaining clock times $L^u$, including at most $mL^{A-1+u}$. Its second term charges $k L^{2A}$, together with the original $mL^{2A}$. The scales with possibly negative log exponents are $H$ up to fixed log powers, and polynomial-in-$L$ setup fits these bounds. At $B=3A-1$ the decrement is $1/2$ and the terminal floor is $1-A<0$. After finitely many applications $u'<0$. On the short-payload diagonal $H=n^2$ this gives an $o(H)$ complementary simulation. Thus $b=3a+11$ suffices. The number of applications is fixed independently of the input length.

For conventional decimal DIMACS it suffices to reserve variable numbers in a fixed decimal-length range at each scale, shift all indices to that range, and use a whitespace byte in the positive sign slot or a minus in the negative slot. Shift the header's maximum name accordingly. Leftover unused names do not affect existence. Index lengths, signs and clause strides are then fixed. For exact width three on distinct variables, translate shorter clauses with a common fresh variable forced false, using two false helpers where needed and the seven proper clauses excluding nonzero triples. Gate templates may simplify repeated literals and discard tautologies before installing each record, padding with a fixed satisfied proper clause when necessary. The fixed number of clause types and slots keeps the size $O(HL^3)$. For every known record index its three names take $O(1)$ binary words to compute using the packed row templates. A table of powers of ten supplies any chosen decimal digit by word division. A packed guest input word needs $O(L)$ such operations. The smaller materialized reduction has $O(RL^2+ML)$ gates and clauses, each requiring $O(L)$ decimal characters, so it costs $O(RL^3+ML^2)$ here as well. This digit-at-a-time generator uses only polylogarithmic setup. Its root monitor time is $O(HL^{A+1})$. Rebalance $2A+1-x$ with $x-B+A-2$ to obtain $W=(3A-B-1)/2$. At $B=3A$ the decrement is $1/2$. This gives $b=3a+12$ for decimal DIMACS. This decimal accounting uses the ordinary word instruction set with integer division, or a fixed equivalent cost for the digit extraction.

For the logarithmic claim one can recover the packed exponent $3a+11$ even on decimal files. At each selected segment build a read-only digit table. Take $r=\lfloor(\log_{10}H)/8\rfloor$ (at least one at large scales) and tabulate the packed $r$-byte, zero-padded decimal representation of every $0\le j<10^r$. Fill it by the elementary decimal loop in $O(H^{1/8}L)$ time and $O(H^{1/8})$ words. The host may group a fixed number of words per entry. Every index has $O(\log H)$ digits, hence a constant number of chunks. Divide by the precomputed powers $10^{ri}$, look up each chunk and concatenate using a constant number of shifts and masks. Strip the fixed leading chunk padding at the public field width. All literal numbers really have that width because of the shift to a fixed decimal-length range. A guest input word intersects $O(1)$ clauses, each with a constant number of such fields, so it can be generated in $O(1)$ word operations after setup. The header is public and occupies $O(1)$ packed words. The new setup is $o(k)$ for the padded budget $k=\Theta(H/L^B)$ and costs less than the interval-verification term. Since the table is a deterministic function of the public scale, each interval challenge rebuilds it without putting its contents in any guessed snapshot. Use the digit-at-a-time generator for the polynomial-exponent proof when the allowed support list is too short to absorb a power-size table. The actual SAT solver sees conventional ASCII in both arguments.

## Comparison with the earlier snapshot bounds

The earlier entropy theorem already implies a qualitative lifetime-support lower bound at near-linear time. With a zero predictor it uses $P=L^{3a+16}$ intervals. If only $h$ addresses ever return a nonzero word then at most $Ph$ distinct (block, address) keys have nonzero value. For $M$ genuine keys and $r$ nonzero keys, their total empirical entropy is at most $r\log_2(\mathrm eM/r)+r\log_2 V=O(rL)$, where $V$ is the word alphabet. Comparing with the proved $\Omega(N/L^{2a+7})$ entropy gives $h=\Omega(N/L^{5a+24})$ on its unsatisfiable family. The value-only predecessor gives a better comparison. Use a worst-case constant-time static dictionary for just the $O(Ph)$ nonzero (block, address) keys, with arbitrary answers permitted away from genuine keys. Its advice costs $O((1+Ph)L)$ bits. That theorem's $d=0$ grid has $P=L^{3a+10}$, giving $h=\Omega(N/L^{5a+18})$. Thus the fact that a linear-time solver would need $N^{1-o(1)}$ distinct addresses already follows in the journal. The single-address verifier yields the stated stronger logarithmic obstruction, works at the displayed polynomial clocks, and monitors a dynamic native instruction independently of a fixed block grid. No priority claim is made. [Partial-domain entropy bound](partial-domain-snapshot-errors.md) · [Value-only theorem](solver-snapshot-descriptions.md) · [Fredman, Komlós and Szemerédi](https://www.cs.umd.edu/~gasarch/BLOGPAPERS/FKS.pdf)

For the per-verdict assertion, if all sufficiently long runs of one polarity obey both caps, simulate with a time limit and count distinct nonzero-retrieval addresses. After an original load returns nonzero probe a separate tag for that address, and mark it on first sight. Stop on either overflow, returning the other verdict. The wrapper uses a larger fixed coefficient in the word width for disjoint guest and tag banks, masks arithmetic to the original guest width, and addresses either bank in constant time. Thus the number of distinct addresses returning nonzero is at most twice the cap plus a constant, and the overhead in time is constant per step. Compute thresholds by fixed rational powers or use slightly looser rational exponents within the strict inequality. Handle finitely many exceptional lengths separately. The resulting globally bounded solver contradicts the theorem.

A further version replaces zero by the value of a fixed public predictor computed from input, current controller and proposed read address. The retrieval budget then counts distinct addresses at which a genuine reply ever differs from this prediction. On $S$ retain actual values initialized to zero. Elsewhere use the predictor. The passive monitor compares the predicted value with its actual last-write register at its selected address. The first-discrepancy proof is unchanged. The listed bounds apply when the predictor uses only polylogarithmic scratch and its cost fits the relevant monitor overhead on virtual input. Constant-power polylogarithmic cost preserves the polynomial-exponent result. An effective per-guest-step root overhead $L^d$, including predictor access to virtual input, gives $W=(3A+d-B-2)/2$. Integer $B=3A+d-1$ suffices. Fix a timeout and scratch bounds on every projected controller, including forged interval starts. A predictor with larger scratch or time requires charging these explicitly. [Deterministic space interpretation when time is unrestricted](one-pass-sat-with-one-nonzero-work-read.md)

For a per-verdict application with a costly predictor one can cap the guest semantically. Return the other verdict on timeout or on the discovery of a $(k+1)$st distinct discrepancy address. In the projection count distinct discrepancies *inside* the proposed $k+1$ dictionary slots using one flag per slot. Outside it the projected reply already equals the predictor. The true support through overflow has at most $k+1$ addresses, so the same proof certifies the capped verdict. In the final two bounded SAT reductions only the ordinary time-truncated solver is needed. This avoids executing the predictor inside those ordinary slowdowns.

## A predictor may use the best short advice for each input

Fix the predictor in advance, but let its read-only advice depend arbitrarily on the individual input. For a word string $Z$ let $E_Z(F)$ be the set of distinct addresses at which the actual guest gets a work reply different from its prediction. Count advice in **words** and define
$$
 g(F)=\min_Z\max\{|Z|,\ |E_Z(F)|\}.
$$
All the polynomial-exponent and logarithmic exclusions above apply if the proposed joint cap is $g(F)$ on every input. In fact it suffices to assume both caps on all sufficiently long **unsatisfiable** files. Thus under the time hypothesis some unsatisfiable file exceeds the cost bound even after optimizing its advice. Finite exceptions and constants have their usual meaning. The predictor may maintain a dense, zero-initialized array of $O(k+\operatorname{polylog}N)$ words and a constant register file, where $k$ is the proposed budget. Its known update rule sees the current guest instruction, read address and eventual reply. Its bounded cost and scratch must hold on all projected paths and on permitted forged snapshot starts. Its time to access the virtual original input is included.

In the first universal block choose both $Z$ and $S$, with $O(k+1)$ words each. A sorted list, a declared length and zero padding suffice. On a true rejection choose a minimizing advice string and its actual exceptions. The projection retains those words and predicts the rest correctly, including each update of the predictor's private state. On a true acceptance *every* advice string and proposed set either leaves the projection nonrejecting or has a first incorrect read on any rejecting projection. Before that read the predictor has seen the actual guest history, and a passive last-write register certifies the discrepancy. Include the predictor's mutable slots in each checkpoint, with $Z$ shared read-only. All list lengths and interval bounds are unchanged in order. This needs no algorithm for finding good advice. The honest certificate in this orientation is for a rejecting input. The per-verdict tag wrapper for a fixed predictor does not compute a minimizing, input-dependent advice string.
