# A sparse interval invariant for branch-controlled address updates

Consider an arbitrary deterministic interleaving of three RAM instructions. The LOAD reads $x\gets M[y]$, the address update sets $y\gets f(x)$, and the STORE writes $M[y]\gets y$. All other instructions inspect registers and direct control flow. They may choose the order and the number of executions of each site. This includes an allocation at six static slots with three comparison sites. The two destinations $x,y$ are distinct. Work memory and input cells are both writable. The five-slot proofs assumed a single continuing cycle; the following invariant holds with any number of cycles. [Five-slot model](five-instruction-loops-on-dimacs-sat.md)

Let $f(z)=S(z)=z+d\pmod {2^w}$ for a fixed odd integer $d$. Let $H$ contain all initial word values and the initial value of $x$. At every time the set $A$ of addresses ever marked by the STORE is the union of at most $|H|+1$ intervals in the cyclic order $S$. Indeed, a newly marked address is either the initial $y$, is in $S(H)$, or is $S(v)$ for a previously marked $v$. In the last case the last update of $y$ used $x=v\notin H$. The only way to load this value was to read the self-mark at $v$. Thus a new address outside the fixed root set $\{y_0\}\cup S(H)$ adjoins an existing interval. Starting from the empty set, only the first mark of a root can increase the number of components. This includes a root reached after many resets, a component crossing address zero, and a completely marked circle.

A deterministic simulator can store the intervals in a balanced ordered dictionary using the rank $y d^{-1}\bmod 2^w$ to linearize the circle. Splitting a wrapping interval uses at most one extra dictionary entry. The inverse exists since $d$ is odd and can be computed in polylogarithmic time by the Euclidean algorithm. Membership determines precisely whether to return the addressing word or the virtual original word. A mark merges with at most two neighboring intervals. Using a dynamic node pool with recycling or in-place updates takes $O((|H|+1)\operatorname{polylog}N)$ bits and polylogarithmic overhead per operation. The simulator does not need to list the roots.

For a single unary ALU site in the given basis, the periodic sign-edit family eliminates the other potentially useful address functions. Starting with its bounded initial palette, every available word lies in the closure under $f$, since self-marking only copies an address previously held in a register. A fixed bitwise operation, comparison, one-direction shift, fixed-factor multiplication, or squaring cannot generate the long consecutive interval of compulsory addresses on that family. The same holds for constant functions, doubling and reflection about a fixed word. For translation by an even increment, all starting values on that family are even, so odd compulsory addresses are missed. A nonconstant translation by either length metadata word also has an even step there. These closure arguments use the actual two operands, including repeated $x$ and intervening branches. [Arithmetic closure details](bounded-ram-programs-and-separate-sat-witnesses.md)

Using sparse decimal hard names lets $|H|\le N^\eta$ for arbitrarily small fixed $\eta>0$. For a native $O(N^a)$ clock with $a<\varphi=(1+\sqrt5)/2$, the resulting small-space simulation contradicts the Fortnow–Lipton–van Melkebeek–Viglas time–space theorem by choosing first a comparison time exponent $a<c<\varphi$, then $\eta$ smaller than its forbidden space exponent. Thus this branch-controlled subclass cannot decide ordinary DIMACS SAT at that clock. The proof does not require an ordering promise on LOAD, STORE and the arithmetic update. [Sparse name transfer](sparse-decimal-names-in-dimacs.md) · [FLMV Theorem 1.1](https://lance.fortnow.com/papers/files/tst.pdf)

There is a related invariant when the STORE instead writes $M[x]\gets y$ and the LOAD still reads $M[y]$. After a LOAD of $b$ at address $a$, the register $y$ is either $a$ or $f(b)$ until the next LOAD. Every intervening write to $M[b]$ either reverses the edge $a\to b$ read at the start of the interval or inserts the edge $b\to f(b)$. Hence every undirected edge $\{v,M[v]\}$ at every time belongs to the initial undirected edge set or to $\{\{v,f(v)\}:v\text{ a word}\}$, allowing a fixed number of initial-register edges before the first LOAD. For translation, each cell outside $H$ holds its raw value or a forward/backward neighbor, except for these initial edges. This leaves the locations of the neighbor markers unresolved. An interval bound for self-marks does not extend to them merely from this edge invariant.
