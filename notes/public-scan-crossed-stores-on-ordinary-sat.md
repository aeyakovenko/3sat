# Crossed stores during a public cyclic scan of an encoded SAT input

Consider the five-slot RAM with separate LOAD, STORE and arithmetic instructions. The mutable registers are $x,y$. In the case here the program repeatedly loads $x=M[y]$, stores a value of $y$ into $M[x]$, and advances $y$ by a fixed program literal $a\ne0$ modulo $2^w$. The two conditional branches may exit according to either register. Each of the three data instructions occurs once per traversal of the unique cycle. Starting at a LOAD, write $p_i$ for the successive scan addresses. The store between this LOAD and the next has the exact form
$$
             x_i=M[p_i],\qquad M[x_i]\gets p_{i+\delta},\qquad
             p_{i+1}=p_i+a \pmod {2^w},
$$
where $\delta=0$ if the STORE precedes the addition and $\delta=1$ otherwise. Instructions may terminate a traversal early. Any initial STORE before the first LOAD changes at most one cell. Initial additions determine $p_0$. Comparisons never write data. [Five-slot control graph and instruction convention](bounded-ram-programs-and-separate-sat-witnesses.md)

Let $M_0$ denote the original memory and let $H$ contain all its values, including the zero on unused memory. The same words also serve as numeric addresses. A run of at most $P$ passes through an injective cyclic scan changes at most $3^P(|H|+1)$ distinct addresses, including all intermediate modifications. A stronger last-writer analysis gives a polynomial bound in the pass count and an explicit $11/10$ time exclusion for the full five-slot classification. [Polynomial pass bound](ancestry-of-crossed-stores.md)

A pass here may be truncated at either end, and the bound holds for an arbitrary cyclic permutation, independent of its arithmetic description.

## The threefold bound for one pass

At the start of the pass put into $E$ all addresses ever modified so far and all elements of $H$. Let $e=|E|$. Number the reads of this pass $0,\ldots,l-1$, with pairwise distinct addresses. There are at most $e$ reads at addresses $p_i\in E$. Each gives at most one new STORE destination.

Now suppose $p_i\notin E$ and the read yields $x_i\notin H$. The cell at $p_i$ held an original value in $H$ at the start of the pass, so a previous store of this pass wrote to $p_i$. Let $k<i$ be its last writer, so $x_k=p_i$. If the read at $p_k$ had itself obtained a value stored earlier in this pass at index $j<k$, its value would have been $p_{j+\delta}$. Since $j+\delta\le k<i$, injectivity rules out $p_{j+\delta}=p_i$. Thus the read at $k$ still saw its start-of-pass value. That value $p_i$ lies outside $H$ (as $H\subseteq E$ and $p_i\notin E$), forcing $p_k\in E$. Distinct $i$ have distinct writer indices $k$ because each store has only one destination. There are at most $e$ reads of this second kind. Each can add at most one new destination. All remaining reads yield a value in $H$ or have already been counted. Hence the union of the old $E$ and all destinations in this pass has size at most $3e$.

The index inequality remains valid when numerical addresses wrap modulo $2^w$. A last STORE with $\delta=1$ may write the next pass's first address *as payload*. Its destination is still charged in its own pass. The next pass takes the resulting memory as its starting state. A final LOAD whose STORE never executes only decreases the count. Induction from $E=H$ plus at most one prologue destination gives the bound.

For $\delta=0$ there is a stronger invariant. Outside $H$ the memory equals $M_0$, provided the process starts without a stray write. Whenever $M[h]=b\notin H$ for $h\in H$, one also has $M_0[b]=h$. Writing $M[M[p]]=p$ at a destination outside $H$ therefore restores that location's original value. Writing an outside pointer $p$ at a port $h\in H$ requires $M_0[p]=h$ and preserves the invariant. The pass argument covers either order, including a prologue.

## Simulating a linear clock in sublinear workspace

Suppose the hypothetical fixed program runs in $O(N)$ steps on an $N$-bit explicit formula, with $2^w\ge N$ and $w=\log_2 N+O(1)$. Its public orbit has period $L=2^w/\gcd(2^w,a)$. Since $a$ is a fixed nonzero integer independent of $N$, $L\ge 2^w/|a|$ at all sufficiently large widths. In particular $P\le1+O(N/L)=O(1)$, with the constant allowed to depend on the program and time multiplier. This applies to fixed even increments as well as odd ones.

Use the conventional ASCII DIMACS layout with decimal digits, minus, space and newline for clauses. The header uses the additional letters in “p cnf”. Optional comments are omitted from the hard layout. There are at most 17 byte values in the file. A whole byte-aligned $w$-bit input word has at most $17^{w/8}$ possibilities. If $w$ need not be a multiple of eight, a word touches at most $\lceil w/8\rceil+1$ bytes and has at most eight offsets. The final padded word and all-zero work memory add at most two values per input. Consequently $|H|=O(N^{\log_2(17)/8})=O(N^{0.511})$ under this word-width convention.

Simulate the original RAM using a read-only input and a dictionary of changed cells, keeping prologue, partial traversals and branch results explicitly. A binary trie on $w$ address bits needs at most $O(w)$ nodes per stored address, with $O(w)$ bits per node. Lookups and writes take polylogarithmic time, including bit-cost simulation. A missing entry is fetched from the original file or returns zero outside it. The simulator never needs to enumerate $H$ or know which visits are exceptional. The theorem bounds the dictionary's actual size. On the assumed clock this gives $N^{1+o(1)}$ time and $O(N^{0.511}\operatorname{polylog}N)$ work bits.

For the lower-bound transfer one may take the locally computable fixed-record SAT instances for a bounded RAM verifier. Emit each signed identifier as a decimal token in a fixed-width field padded on the left with spaces, add a clause terminator and newline, and emit a public header giving the declared variable and clause counts. This changes the encoded length by at most a polylogarithmic factor. A bit of the virtual file requires only a field-position calculation and conversion of one logarithmic-bit identifier, in polylogarithmic time and workspace. If the starting SAT syntax has variable-length records, first use the bounded-verifier construction whose input pins read bits of that original formula. This transfer needs no materialized writable copy of the ASCII file. It suffices that tokens and header are accepted by the target SAT representation. For the above separate-operation convention a linear deterministic solver with these crossed public scans would therefore give a quasilinear-time, polynomially sublinear-space SAT algorithm. Fortnow's time-space theorem excludes that. [Locally computable bounded-run encoding](packed-band-transfer.md) · [Fortnow's deterministic SAT consequence](https://lance.fortnow.com/papers/files/tst.pdf)

This proof concerns a specified RAM schedule. A value-dependent change to the scan register can destroy injectivity within a pass, and a width allowing substantially more than $\log_2N$ bits requires a corresponding bound on the input alphabet.
