# Linearly many unpredictable long-gap reads on explicit SAT formulas

**Research journal, 24 November 2026.** Fix one deterministic predictor of writable-load values. Give it the original read-only formula, the native time, program counter, pre-load register state, slot, address, and a common string chosen after seeing the entire input. Each query starts with blank private scratch. Allow arbitrary computation and at most $q=\log^{O(1)}N$ packed input-word probes per prediction. The theorem allows unlimited access to the advice string. A fixed RAM that runs in $O(N)$ steps on a family of explicit negative formulas has, on arbitrarily long members, $\Omega(N)$ incorrect predictions **for every common string** of length at most $c_0m/((q+1)\log m)$, with $N=\Theta(m\log m)$ and fixed $c_0>0$. Each of these reads takes place $\Theta(N)$ steps after the last access to its address. Thus the sum of the preceding-access distances on wrong reads is $\Omega(N^2)$. Every finishing scan with the correct negative verdict must have received the true value on **every** designated load, even if arbitrarily many designated responses can be altered together. The predictor can also see the genuine preceding history of the scan, and can use charged timestamp-indexed probes to the entire earlier native event history, as specified below. Any input-independent advice may be fixed as part of the predictor for each length.

## Native program and encoding

Let $p=\log_2m$ be a positive integer. Store a permutation $\pi$ of $[0,m)$ in third literal names of $m$ tautologies $(x_1\lor\neg x_1\lor x_{\pi(i)+1})$, using a conventional fixed-width binary-index encoding and a constant header containing a pair of contradictory unit clauses padded to width three. The metadata for the growing variable and clause counts occupies $O(\log m)$ bits; the fixed pair of clauses is located via this metadata. Each packed input word intersects $O(1)$ names encoding permutation values. Conversely a fixed program can read any one name in $O(1)$ word steps. Use the following native computation on formulas with the contradictory guard and the appropriate bounded dimensions.

1. Read the $m$ encoded names and check that subtracting one gives a permutation of $[0,m)$. A fresh zero-initialized seen table, one check and one mark per name suffice. On a malformed table return UNSAT immediately. On every permutation the old seen flags read during this pass are zero. Read the names again and, for every $i$ and every bit position $j<p$, write $1+\operatorname{bit}_j(i)$ to work cell $(\pi(i),j)$. This writes every such cell once, and all these words are nonzero.
2. Perform $mp$ countdown iterations without touching the value bank. Clear the data registers at the end.
3. For $u=0,\ldots,m-1$ and $j=0,\ldots,p-1$ in that fixed order, read value-bank cell $(u,j)$. These are the designated loads. Return SAT if its word is outside $\{1,2\}$. Assemble a candidate $i'$ for the inverse of $u$ from the decoded bits. After its $p$ loads, read the **original immutable input** to check $\pi(i')=u$. Return SAT at the first failed check, or UNSAT after all checks pass.

The index and prefix accumulation fit in one word. If the predictor sees the pre-load controller, keep the partial prefix in a separate private scratch cell between iterations, and clear the secret data registers before every designated load. Addresses, times, loop counters, and immediate pre-load controllers are then public; the scratch cell contains only bits from earlier scan reads. Every true loaded word is $1+\operatorname{bit}_j(\pi^{-1}(u))$, so every designated load is its cell's first access since its unique scatter write, with gap $\Theta(N)$. Use constant-length native iterations on passing branches. The actual writer timestamp would disclose $i$ and is excluded from the predictor.

This is an execution of a correct SAT solver. On an input with the contradictory guard, dimension and syntax checks can be bounded by $O(N)$; if the preamble is inapplicable return UNSAT. On every genuine validated table, all inverse checks pass and the true verdict is UNSAT. On inputs without the guard run any fixed correct solver. Conditional on the existence of a linear-time solver, the wrapper is also linear-time. Moreover, consider arbitrary substitutions at the *designated* loads of a validation-passing scan, with the rest of the program operating by its ordinary semantics on the resulting state. If the scan finishes with UNSAT, its $p$ candidate bits for each $u$ comprise an index $i'$ with $\pi(i')=u$. Injectivity forces $i'=\pi^{-1}(u)$, hence all $p$ responses are genuine. Any nonempty set of actual changes therefore produces SAT, even if further values would also have been changed after a first detected failure. There is no second truth bank in this check.

Forecasting and certifying a read consequently have quite different costs on this execution. Given $u$, one can guess its inverse $i$ in a word and confirm it by **one forward-entry lookup**. That one certified word supplies all $p$ genuine responses for the key; in a partial segment an independently provided index is checked the same way. The quadratic lower bound below concerns deterministic forecasts with finite common advice. It leaves open an approach in which unpriced guesses are authenticated from the read-only input and their consistency with actual cell contents is proved at a separately charged cost. The easy verdict on these inputs and the short forward check do not give that authentication for arbitrary signed hard SAT families. A predictor that returns a word outside $\{1,2\}$ makes an error. It suffices to prove errors for bit-valued forecasts: map a returned 2 to one and every other word to zero. Every wrong binary forecast was already a wrong word. The analysis below gives one permutation simultaneously hard for all allowed strings, for the fixed predictor and sufficiently large $m$.

## A Hamming ball for each inverse

First suppose a query receives just its pre-load controller and the listed static fields. If at most $mp/16$ forecasts are wrong, at least three quarters of all target keys have predicted inverse within Hamming distance $p/4$ of the true position. Sample $h=\lfloor m/(C(q+1)p)\rfloor$ distinct keys independently of the permutation, for a sufficiently large fixed constant $C$. On any permutation where an advice string attains this error budget, the probability all sampled keys are good for that string is at least $(1/2)^h$ for large $m$. One may select a successful string as a function of the permutation before drawing the keys.

Fix the string and sampled keys. Generate their $hp$ predictions by adaptive forward probes. A packed word costs at most a fixed number of forward permutation probes, so the total number $J$ is at most $Bhp(q+1)$ for a fixed $B$. By enlarging $C$ we can make $J/m$ as small a constant as desired. Each genuinely new domain probe exposes a uniformly random previously unseen image. The probability that at least $h/2$ sampled target images were exposed is at most $2^h(J/m)^{h/2}$. This follows by a union over subsets and sampling without replacement; a strategy taking fewer than $J$ distinct probes may be padded. Conditioned on the whole query transcript, the preimages of unexposed targets form a uniform injection into the remaining positions. Their predictions are fixed. The volume of a radius-$\lfloor p/4\rfloor$ Hamming ball is at most $2^{H_2(1/4)p}$, with $H_2(1/4)<1$. Exposing the remaining preimages in sequence gives conditional probability at most
$$
 \left(\frac{2^{H_2(1/4)p}}{m-J-h}\right)^{h/2}
$$
that all are good if at least $h/2$ were unexposed. The sum of the two bounds is at most $8^{-h}$ for sufficiently large $C,m$. Union over the fewer than $2^{h+1}$ strings of length at most $h$ and divide by the lower sampling probability $2^{-h}$. The probability some such string succeeds is less than one. This proves the claimed asymptotic obstruction with a suitable $c_0$.

## Allowing the true earlier scan bits

A stronger predictor can inspect every earlier scan event, including earlier true bits for the *current* target. It gets no free precomputed index to the scatter transcript or writable memory, and no uncharged predictor state filled by earlier private probes. In this program scan events can be reconstructed from previous inverse bits and the public schedule. We may give the entire inverses of all earlier keys for free. Restrict the examined predictions to the first $\ell=\lfloor p/2\rfloor$ bits of keys $m/4\le u<m/2$. There are $\Theta(mp)$ such bits. If at most $mp/128$ of all forecasts are wrong, at least half the keys in this interval have at most $\ell/4$ errors in their examined prefixes for large $p$. Select $h$ keys uniformly there without replacement, with $h$ as before. The probability all sampled keys are good for a chosen successful string is at least $(1/3)^h$.

For fixed advice and sampled keys, evaluate them in increasing key order. Before each test reveal the full true positions of all earlier keys. This includes the selected keys tested earlier. Say a selected key is old if its image was discovered by a previous test's forward queries. To bound the number of old keys, condition at each current test also on the current key's full inverse for this calculation. Every new query outside the already fixed positions then exposes a fresh uniform remaining image, and the probability it is a not-yet-tested selected key is at most $3h/m$: at most $m/2+O(1)$ prefix images and $J\ll m$ other entries have been fixed. Free reveals of earlier keys cannot expose a future selected key. The chance at least $h/2$ old keys arise is at most $\binom{J}{\lceil h/2\rceil}(3h/m)^{\lceil h/2\rceil}$, which is at most $(6eJ/m)^{h/2}$ when $6eJ/m<1$. This estimate uses a union over probe times and their conditional hit bounds; no independence of the adaptive probes is assumed.

Just before testing a fresh key $u$, condition on the actual past without its unknown inverse. There are $L\ge m/3$ remaining positions. Their bijection to the remaining keys is uniform: earlier prediction histories depended only on previously exposed forward entries, earlier inverse values and the fixed advice. Draw a uniform auxiliary completion $\pi_0$ and an independently uniform remaining position $a$. Let $a_0=\pi_0^{-1}(u)$, and obtain the true completion by exchanging the images at $a$ and $a_0$. This has the correct law and its true inverse at $u$ is $a$.

Run the predictor with the forward oracle $\pi_0$ but supply the genuine preceding bits of $a$ as the answers are scored. The outcome differs from its true-oracle run only if it probes $a$ or $a_0$. For fixed $a$, the chance of probing $a_0$ is at most $B\ell(q+1)/L$ by deferred decisions in the independent uniform auxiliary completion. For fixed $\pi_0$, there are at most $2^\ell$ possible examined prefixes of $a$; their combined probe sets contain at most $2^\ell B\ell(q+1)$ positions. This bounds the probability of probing $a$ by $2^\ell B\ell(q+1)/L$. For a fixed $\pi_0$ the forecasts form an ordinary sequential bit predictor: specifying the error locations determines the prefix uniquely, since earlier true bits have already been reconstructed. At most $2^{p-\ell}\sum_{j\le\ell/4}\binom\ell j$ possible $a$ have a good prefix. Thus the conditional probability that a fresh key is good is at most
$$
 \delta_m=\frac{(1+2^\ell)B\ell(q+1)+2^{p-\ell+H_2(1/4)\ell}}{m/3}=o(1).
$$

If fewer than half the sampled keys are old and all keys are good, some fixed subset of at least $h/2$ consists of fresh good keys. Freshness is determined before each test. Successive conditioning and a union bound give probability at most $2^h\delta_m^{h/2}$ for this event. Together with the old-key bound this is at most $16^{-h}$ after fixing a sufficiently large $C$ and then taking $m$ large. The uniformity in fixed advice and target choices permits averaging over the sampled keys and a union over fewer than $2^{h+1}$ advice strings. Dividing by $3^{-h}$ still gives probability below one. This proves the same $\Omega(N)$ error count with true scan history and with no efficient procedure assumed for selecting the common string. Ordinary timestamp-indexed probes to the complete genuine event history are covered as well, when counting each probe to the pre-scan history against the query budget. A validation or scatter timestamp specifies the public loop counters, so its native controller and inactive, read or write fields can be reconstructed from constantly many forward fields in the formula and public arithmetic. The checked seen flag is always zero on a true permutation, and every completed scan check and its input address are determined by the earlier inverse bits. Use the fixed-duration loop with stale scratch cleared or determined by the immediately preceding public iteration. On a permutation each scatter write is the only one to its cell, and its old value, if needed, was zero. Dummy countdown records are public. A packed, fixed-width probe to any earlier event therefore either costs $O(1)$ forward probes or can be supplied by the free scan history. An index that returns the most recent matching writer directly from an address, or the true writer timestamp itself, has substantially greater power here. The theorem isolates the cost of reconstructing the bit from the explicit formula, public scan state, genuine preceding scan answers and the one charged common string. Applying a gap-weighted argument to pure elapsed time would require a better forecast on the specific hard SAT executions, or a way to certify the actual incoming words as cheaply as a claimed inverse can be checked on this example.
