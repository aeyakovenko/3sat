# Two disclosed bit edits of one SAT formula

On a fixed proper DIMACS formula of length $N$ bits, unlimited preprocessing can tabulate the SAT verdict of all one-bit changes in $N$ bits. The query supplies the changed bit's position. With two positions, every deterministic index using $N(\log N)^{O(1)}$ words of $\Theta(\log N)$ bits requires $\Omega(\log N/\log\log N)$ probes on some formula and query, at arbitrarily large sizes. This holds with the original file satisfiable, both single changes satisfiable, and explicit witnesses in all three of these cases. All length-preserving changes are to the last digits of positive literal names. The two restored layers can consist entirely of alternating four-sheet squares. Several second-layer squares have designated intact guards for use as separate query sites. [Square normal form for one designated edit](doubled-relay-square-normal-form.md)

On one restored formula, a positive matching and a negative matching of source–sink queries share the same first $\Omega(N/\log N)$ executed RAM instructions. Each matching has $\Omega(L)$ pairs, where $L$ is the number of sources of the embedded butterfly. After that prefix every one of these actual runs reads $\Omega(\log N/\log\log N)$ distinct old addresses. An old address means an immutable input address or a work address first read after the cut before any intervening write to it. The shared-prefix result holds for every correct fixed solver with unrestricted time and workspace. A sharper cut at the *first changed input-word read* is available if restored runs have near-linear length.

## A graph in one formula

Write $D(X,Y)=X(1-Y)$ on logical bits. Each logical name has physical value $X$ on the left and $1-X$ on the right. A regular second-layer square tests equality of two directed descents. For every edge $u\to v$ of a given graph impose
$$
                       D(X_u,X_v)=D(W,W)
$$
using two separate physical occurrences of a fresh logical name $W$. This enforces precisely $X_u\Rightarrow X_v$. An absent edge in a fixed set of available slots can use a tautological square with two logical self-loops. Keep one bit per graph vertex even if it is isolated.

For a pin square write the four physical bits in square order as $c=A$, $a=1-B$, $b=1-A$, $z=B$. The positive edges match $c$ to $a$ and $z$ to $b$. The negative edges match $c$ to $b$ and $z$ to $a$. Give $c,a$ intact guards and the other two the usual regular guards. A left change makes the positive entry at $c$ point to itself. A right change makes the entry at $a$ point to itself. Direct substitution into the four center relations gives exactly the following conditions.

| Left change | Right change | Condition |
| --- | --- | --- |
| no | no | $B\Rightarrow A$ |
| yes | no | $A=1$ |
| no | yes | $B=0$ |
| yes | yes | $A=1$ and $B=0$ |

Set $A=B=X_v$ using different physical sheets of that logical name. The restored pin imposes nothing. A left change at $s$ requires $X_s=1$ and a right change at $t$ requires $X_t=0$. The formula is satisfiable precisely when the graph has no path $s\leadsto t$. A path propagates the forbidden one to the sink. If no such path exists, set $X_v$ to one on the set reachable from $s$ and zero elsewhere. More generally any sets of positive and negative changes are satisfiable exactly when no positively marked vertex reaches a negatively marked one. Giving every logical vertex the same bit gives the explicit witness for either kind of single change, taking each private pair equal to its physical center in the constant orientation. [Lean proof of the local edits, implication and arbitrary sets of marked vertices](../lean/SharedSquareQuery.lean)

To keep each modified port map an involution, use a full two-entry cut per named terminal. At a source take $A=X_s$ and $B$ private, chosen zero. At a sink take $B=X_t$ and $A$ private, chosen one. The same truth table gives the same reachability verdict with two full cuts, four physical bits in total. Each whole cut in isolation is satisfiable. One named whole cut again permits complete tabulation in linear space. The version with one physical bit per terminal makes half cuts that may break the involution after editing.

To bound relay length, duplicate the physical uses as in the square normal form. Each duplicated pin square has four regular centers. Its descent equality is $D(A,A)=D(B,B)$, so its duplicate remains neutral, even when the original pins force different values. The existing balanced cloning construction therefore turns every first-layer relay into a square and leaves all original pin sites editable. The number of physical sites is $O(E+V)$ for $E$ available edge slots and $V$ vertices. For the $j$th marked positive edge use public identifiers $10j$ and $10j+1$ at its two centers, for $j\ge1$. All other public and private names can be assigned unused dense IDs of $O(\log(E+V+2))$ digits. Each change toggles one low ASCII bit. The bits for all marked sites are distinct. Counting the header and all names gives $O((E+V)\log(E+V+2))$ encoded bits. Padding absent slots with tautological squares gives $\Theta(E\log E)$ bits on the butterfly family. The site map from graph terminals to byte/bit offsets takes $O(V)$ stored words. [Compiler and DIMACS experiment](../audits/shared_square_query_audit.py)

## The static lower bound

Use Pătraşcu's reachability problem on subgraphs of a public degree-$B$, depth-$d$ butterfly. There are $L=B^d$ sources, $L$ sinks, $dL$ nonsink vertices and $E=dBL$ available edges. For a cell width $w$ and space $S$ words, the communication inequalities in Section 5 force $\Omega(d)$ query probes when $w=O(\sqrt B)$ and $\log(Sd/(dL))=O(\log B)$. Indeed with $p$ probes one inequality requires $(p/d)\log(Sd/(dL))=\Omega(\log B)$ or $(p/d)w=\Omega(\sqrt B)$. Take $B$ a power of two of order $(d\log(2d))^4$. For the formulas above $w=\Theta(\log E)$ and $S=E(\log E)^{O(1)}$ satisfy the inequalities, while $d=\Theta(\log N/\log\log N)$. Given indices $s,t$, fetch their physical offsets and run the proposed two-edit index on this single preprocessed file. Complementing the result answers the reachability question. The additive constant for retrieving offsets does not affect the bound. The actual original graph problem also admits $O(d)$ probes with an adjacency index by checking its unique public source-to-sink path. Priority for the SAT formulation is unestablished. [Pătraşcu, Theorem 1.2 and Section 5](https://people.csail.mit.edu/mip/papers/structures/paper.pdf) · [Earlier transfer to a Horn file with binary query fields](old-words-after-partial-query-disclosure.md)

## Expensive edits on one common execution prefix

For the same butterfly degree $B$ of order $(d\log(2d))^4$, put **$r=dB$ independently editable pin squares at each terminal**. Each alias names the same graph bit and has its own physical sheets. There are $2Lr=2E$ alias squares, so the file still has $N=\Theta(E\log E)$ bits. Insert $\Theta(\log E)$ bits of legal ASCII whitespace before each editable location, with a constant sufficient for the given RAM word size. Every input word intersects at most one editable bit. Formula size and word bounds are unchanged in order. Either edit format works, including the full two-entry cuts. For full cuts an alias is touched as soon as either of its two bits is read.

**Claim.** For every fixed deterministic SAT solver, on one restored formula at each sufficiently large hard scale there are $\Omega(L)$ positive two-edit inputs and $\Omega(L)$ negative ones, with pairwise distinct sources and sinks within each collection. All of their executions share the first $\Omega(E)=\Omega(N/\log N)$ executed instructions with the same restored file. Every one of those executions subsequently reads $\Omega(d)=\Omega(\log N/\log\log N)$ distinct old addresses. There is no workspace or running-time hypothesis on the solver.

Write $b=\lfloor\eta E\rfloor$ for a sufficiently small positive constant $\eta$, which may depend on the machine's instruction set. Simulate only the restored input up to its first $b$ instructions or its halt. If each instruction reads at most $h$ words, at most $hb$ aliases have been touched. Call a terminal early when *every one* of its $r$ aliases has been touched. There are at most $hb/r\le h\eta L$ early terminals in total. For every other terminal remember one untouched alias, for example the least. Any query with two non-early endpoints uses these representatives. Both of its changes are invisible throughout the prefix.

Construct an index for the state at this common cut. Store the input, the machine registers and the at most $O(b)$ changed work addresses, with constant-probe static lookup. For a non-early query, simulate from that state with its known two input edits. Cache all writes and all fetched values privately for the duration of the query. Each distinct immutable input address or old work address used before a suffix overwrite costs $O(1)$ probes. The two alias offsets, headers and saved registers cost $O(1)$ extra probes. An earlier shared halt answers directly. Thus small distinct-address cost gives genuinely low probe cost even if the run performs an unbounded number of private arithmetic operations. [Fredman, Komlós and Szemerédi on static dictionaries](https://doi.org/10.1145/828.1884)

The following robustness argument is needed because the early-terminal sets can depend arbitrarily on the graph. Reduction 5.1 in Pătraşcu's paper turns the parties' two-blocked set-disjointness instance into $L$ source–sink queries on Bob's graph. Alice's queries use every source and every sink precisely once: her edges form a perfect matching at each layer. For constants $c_A,c_B>0$ the communication bound requires at least $c_A dL\log B$ bits from Alice or $c_B dL\sqrt B$ bits from Bob, for sufficiently large scales. [Pătraşcu, Reduction 5.1 and the ensuing two-blocked communication inequalities](https://people.csail.mit.edu/mip/papers/structures/paper.pdf)

Give a pair the color of its true SAT verdict. For each graph and color, make a bipartite graph of the non-early pairs of that color that cannot be answered by running the above exact simulator for $\gamma d$ probes. Suppose on every graph at least one color has a matching of fewer than $\eta L$ such pairs. Choose that color and a maximal matching among its expensive pairs. The endpoints of this matching cover **all** expensive pairs of that color, and number at most $2\eta L$. Bob can compute this set in unrestricted preprocessing.

Bob sends Alice the chosen color and bitmaps of the covered and early terminals, costing $O(L)$ bits. At most $(h+2)\eta L$ of her $L$ pairs meet these sets, since her pairs form a matching. Alice sends those pairs explicitly and Bob returns their answers. This costs $O((h+2)\eta L\log L)$ Alice bits and $O(L)$ Bob bits. Because $\log L=d\log B$, choosing $\eta$ small enough keeps Alice's initial expenditure below a fixed small fraction of her lower bound.

For each remaining pair Alice runs the simulator in parallel for at most $\gamma d$ probes, reporting the opposite of the chosen color if it times out. Every timeout is correctly classified since the expensive pairs having the chosen color were covered. At a probe round she can encode an unordered set of at most $L$ requested cell addresses in $O(L\log(2S/L))$ bits for an $S$-cell index. Bob returns $O(Lw)$ bits, from which Alice distributes identical replies to repeated requests. This gives at most $O(\gamma d L\log(2S/L))$ additional Alice bits and $O(\gamma d Lw)$ additional Bob bits. Here $S\le E(\log E)^{O(1)}$, so $\log(2S/L)=O(\log B)$, and $w=O(\sqrt B)$. Choose $\gamma$ sufficiently small. Both parties then beat the respective lower-bound constants, which contradicts the two-blocked theorem.

Hence one graph has a matching of at least $\eta L$ non-early expensive pairs of **each** color. On that graph the baseline reached $b$ instructions, since otherwise every non-early query would have had the shared terminal answer at constant probe cost. Each expensive pair gives the claimed concrete run because at most a constant number of probes were spent per distinct old address, plus a constant initial cost. The late aliases are shared choices, one per terminal on the fixed graph, independent of which opposite terminal is queried.

The hard pairs also resist a sparse table of arbitrary exceptions. Fix any constant $K\ge0$ and let $H=\lfloor N(\log N)^K\rfloor$. If each graph has a color whose expensive pairs can all be covered by $2\eta L$ terminals and $H$ additional pairs, let Bob put the additional pairs and their correct answers in a static dictionary. Answer its hits in $O(1)$ probes and run the same protocol on the rest. The larger space still has $\log(2S/L)=O_K(\log B)$, so taking a smaller constant $\gamma$ depending on $K$ yields the same contradiction. Therefore on one graph **more than $H$ expensive two-bit inputs of each verdict survive deletion of any $2\eta L$ terminal names**. Moreover, for either color remove previously chosen matchings while at most $H$ edges have been removed. The remaining graph must have a matching of size at least $\eta L$, since the endpoints of a smaller maximal matching would give a forbidden cover together with the removed edges. This gives at least $\lfloor H/L\rfloor+1$ edge-disjoint matchings of that size for each verdict. These are separate genuine runs of the solver, all sharing the same initial execution. Their suffix costs cannot be charged to one another. This conclusion can hold on one graph for **every** choice of one untouched representative per non-early terminal. Otherwise Bob chooses a failing assignment of representatives and a failing color separately for each graph. His index already stores those $O(L)$ offsets, so the same contradiction applies.

When the restored runs have at most $E(\log E)^{O(1)}$ distinct work addresses throughout, use a stronger cut: immediately before the first read that would expose more than $\eta E$ distinct alias sites, or at halt if earlier. The early sets are still small and the snapshot fits the same index budget, even when the actual prefix is much longer. Consequently on the hard graph the common prefix itself has read $\Omega(E)$ distinct editable-site words. Without that work bound the fixed *instruction* cut above suffices.

## The first read that actually sees an edit

If the baseline run on every restored file at the hard scale halts within $T=N(\log N)^{O(1)}$ steps, the simulation can start immediately before the first instruction reading a changed word. Record the first read time of each marked offset and save its pre-instruction registers. The minimum of the two times in a query is precisely the first divergence opportunity. If neither word was read, the query gives the baseline verdict. Save the work-store history indexed by address and time. A cell's value before the chosen instruction is the value at its predecessor store, or zero. Use the order of elementary accesses within an instruction if its semantics require it, or replay the entire bounded-size instruction from its saved initial state.

A static binary prefix dictionary answers predecessor in $O(\log\log T)$ probes here. For each address store every binary prefix of its store times in a static perfect hash table with the minimum and maximum key below that prefix. Put sorted leaf predecessor links in the table as well. Binary search for the deepest prefix of the cutoff time that occurs for this address, then use the missing next branch, its stored extremum, and at most one leaf predecessor. Include the value at each store time. Address and prefix keys take $O(1)$ words. The index uses $O(T\log(T+2))$ words, still $E(\log E)^{O(1)}$. This is the usual binary-prefix predecessor search. [Willard on logarithmic-logarithmic search](https://doi.org/10.1016/0020-0190(83)90075-3)

Cache restored input reads and predecessor results per old address in the suffix. On the usual polylogarithmic-degree scale the lower bound now forces
$$
                  \Omega\bigl(\log N/(\log\log N)^2\bigr)
$$
distinct old addresses in a real run from the first instruction that sees either changed word onward. Run this simulation alongside the fixed-snapshot simulation of the preceding section. On non-early pairs interleave their next cell probes and stop when either answers. Both give the genuine verdict and the combined probe count is at most twice the smaller plus a constant. The same matching argument then forces **both** distinct-address lower bounds on each of the hard runs of both verdicts. The first differing read occurs after the common $\Omega(N/\log N)$ prefix. The post-prefix and post-divergence suffixes overlap, so their lower bounds cannot be added a second time.

The source reduction uses disclosure of edit positions for the static oracle. The simulation with the shared prefix concerns the ordinary unannounced edited file read by the actual solver. Even the sum of the common prefix and the certified suffix reads here is below the encoded input length. These bounds do not exclude an unrestricted linear-time SAT decider.

The executable check covers all 48 subgraphs of two small directed graphs, all subsets of four terminal marks, and both edit formats.
