# List circuit hardness and large algebraic refutations on the same SAT files

On one family of dense proper DIMACS files, deciding SAT as a function of the input bits has the list-based circuit lower bound, and *each negative file* requires exponentially many explicit polynomial-calculus monomials over every field. A single globally correct deterministic SAT program takes linear time on the entire family. The two lower bounds quantify over different objects: the circuit must answer all the files at a length, whereas the proof is for one fixed negative file.

## Coupling the restrictions without a circuit encoding cost

Take the [dense list projection](checking-the-sat-circuit-bound.md) with $m=2^k$ records of $2k$ bits. Denote it by $L_x$ where $x$ is the raw list of length $\ell=2mk$. It has $O(m)$ proper ternary clauses, $O(m)$ names, length $\Theta(mk)$, and each emitted bit is constant or a copy of a raw bit. Add a fixed disjunct $H_t$ made from the mod-two and mod-three branches in the [every-field proof](every-field-refutations-for-path-augmentation.md), on $t=6\lfloor m/6\rfloor+1$ vertices for sufficiently large $m$. The two branches are already unsatisfiable by their total charges. For the degree lower bound choose a bounded-degree expander as in that proof. Choose private variable indices above the list range for all new names, without shifting any list name.

To form $L_x\lor H_t$ use one fresh selector. Gate each proper ternary clause $(a,b,c)$ with the appropriate selector literal $s$ by emitting $(s,a,h)$ and $(\neg h,b,c)$ with a fresh private $h$. Fixing $s$ true allows $h=0$. When $s$ is false, the gate is feasible exactly when the original clause holds, and a bounded-support extension is $h=\neg a$. For example this choice satisfies the second clause whenever $a\lor b\lor c$ holds. The fixed $H_t$ part can be made dense and proper before gating: use a constant-size chain per bounded-width clause, simplify repeated literals, and pad binary and unit clauses using three private variables pinned to zero by the seven proper clauses forbidding their other settings. Conventional fixed-order names for all its variables keep its encoding size $O(t\log t)$. The list parameter fixes the lengths and positions of all decimal fields, even in the data-carrying list references. The new body has $O(m)$ records, each of length $O(k)$; the number of occurrences of data digits is unchanged.

Allow a fixed-alphabet DIMACS comment before the header giving $k$ and the adjacency lists of the underlying graph, with fixed-width fields for that parameter. This comment is public, fixed across the entire circuit restriction at that $k$, and costs $O(mk)$ bits. It lets a uniform RAM verify the promised syntax without recognizing expanders. The decoder checks index ranges, degree, simple undirected adjacency with reciprocal entries and $t\equiv1\bmod6$; it checks every generated hard-branch clause and its gates. Constant degree permits reciprocal checks in constant time per neighbor after interning. The all-one total charge makes each branch inconsistent on any graph passing these checks. It checks the gated list rows and their fresh names in the specified positions, recovers the original list formula, and runs the [list recognizer and duplicate test](scan-time-on-the-dense-list-projection.md). The body checks take $O(N)$ ordinary word operations by decoding or emitting a bounded number of decimal tokens per record, where $N$ is the full bit length. A mismatch invokes general SAT on the actual input. Generating the public branches takes $O(t\log t)$ steps by constant-arity truth tables and fixed consecutive indices. None of the recognition work requires proving that the graph expands. Choosing hard graphs at each length is only needed for the lower bound.

## What holds simultaneously

* The formula is satisfiable exactly when the list contains a duplicate. The full serialized file, including the graph comment, is still a bit projection at size $N=\Theta(\ell)$. The list tensor theorem consequently gives $\Omega(N(\log N)^\sigma)$ Boolean gates for some $\sigma>0$ on the restricted decision function, with the same bounded-fan-in conventions as the original SAT corollary. This uses OpenAI's imported list theorem. It adds a promise on the proof complexity of *all* negative inputs in the restriction. [Original theorem and verified specialization](checking-the-sat-circuit-bound.md)
* Fix any list with no duplicate and any coefficient field. Fix the selector to activate $H_t$ and assign the now-inactive list variables and all its private $h$'s the value zero. The remaining gated selectors and chain variables have bounded-local substitutions from the hard branch for the chosen characteristic. A PC refutation of degree $D$ of these DIMACS clauses gives a source refutation of degree $O(D+1)$. Thus $D=\Omega(N/\log N)$, and monomial size is $2^{\Omega(N/\log N)}$ by the size–degree inequality. For real sum of squares the parity branch gives the same degree lower bound. These statements hold on the *same negative file* for all fields using the clause-violation and Boolean axioms.
* The check-and-dispatch SAT program above decides all these positive and negative files in $O(N)$ deterministic RAM time. It uses the numerical sum of charges to discard the algebraically hard disjunct without building a PC proof. Therefore even a method combining these two measured lower bounds cannot infer superlinear RAM time solely from their simultaneous occurrence.

At canonical sizes the ratios of consecutive lengths are bounded by a constant. If every sufficiently large byte-aligned length is wanted, use fixed harmless whitespace padding from the largest canonical size fitting the given length, as in the original list projection. Equivalently choose $k$ from a fixed common $O(2^k k)$ upper size envelope and pad from there. The recognizer permits the specified trailing whitespace. The direct construction is a disjunction construction, and supplies no priority claim about the separate underlying lower bounds.

The [finite layout audit](../audits/combined_list_refutation_audit.py) used a seven-vertex cycle to exercise both moduli, checked the verdicts of 30 actual combined DIMACS files and checked 68 input-bit columns. Expansion and the asymptotic proof lower bounds come from the source theorems.
