# Nonlinear word operations on a guarded SAT family

On the one-lane coloring files below and their canonical proper DIMACS renderings, every correct deterministic logarithmic-word RAM executes $\Omega(N/\log^2 N)$ instructions on **every file of both verdicts** even when fixed-address affine work is free. The count includes data-dependent branches, data-dependent addresses and bounded-arity word computations that are nonlinear over $\mathbb F_2$. All fixed-address input-bit access and arbitrary input-independent affine preprocessing can be free. Here $N$ is the encoded bit length. The construction still carries arbitrary SAT. The physical read lower bound on the one-lane family is larger, $\Omega(N/\log N)$. An instruction can contribute to both bounds. [Guarded one-lane construction](guarded-coloring-on-one-free-lane.md)

## From an executed trace to affine equations

Fix a file length, machine word width $w$, and a promise cube parameterized by $x\in\mathbb F_2^t$. Every physical input bit is an affine function of $x$. Grant the machine arbitrary affine forms in the original bits before its first step, arbitrary constants independent of $x$, and free affine operations. The choice of each free operation and its locations may depend on information already revealed. This includes fixed-address loads and stores, XOR, bit permutations, fixed shifts, and extracting an output bit. The fixed instruction set accesses only a constant number of words per instruction. Variable shifts, variable indexing and other operations can be charged when their addresses, control flow or word maps require inspecting input-dependent words. The proof also allows length-specific polynomial-sized constant tables. Looking up an entry at a data-dependent address costs an instruction.

A parity decision tree can simulate this machine. At each node keep the set of inputs matching the transcript and an affine description of each known-location register or memory value on that set. At a charged instruction query the bits of its address, control or data operands as needed, at most $Cw$ adaptive parity probes for an instruction-set constant $C$. After resolving an address, the contents of the selected cell have an affine description on the remaining inputs, including the effects of prior writes. Reveal those contents too if the word operation requires them. The complete outcomes determine the instruction's nonlinear results and its continuation. All intervening affine work preserves the invariant. A branch or address already determined on a node, or an operation affine there, may be processed for free whenever that choice follows from the existing transcript. A data-selected choice of the next free operation itself requires a charged step. This argument allows unrestricted workspace and charges only instructions on the run in question. For a one-bit affine output append one final parity query. A run with $s$ charged instructions thus ends in a monochromatic affine subspace through its input of codimension at most $Cws+1$. [Parity decision trees and affine leaves](https://drops.dagstuhl.de/storage/00lipics/lipics-vol339-ccc2025/html/LIPIcs.CCC.2025.16/LIPIcs.CCC.2025.16.html)

As a separate worst-case consequence, exact multilinear degree $t>0$ over $\mathbb F_2$ implies a path with at least $t$ parity queries on **each** verdict. The indicator of a leaf reached in $d$ probes is a product of $d$ affine equalities. Summing the accepting-leaf indicators represents the output polynomial, and summing the rejecting ones represents its complement, which has the same degree. This conclusion alone does not constrain the path at an individually designated file. For example, with the earlier guard and a fixed false payload, a total of even parity certifies rejection by one parity on its binary control flags. [Earlier guard and degree calculation](guarded-coloring-on-one-free-lane.md)

## Affine certificates at an individual file

Use the existing six-residue guard with a different truth table. The total $S=\sum_i b_i\pmod6$ selects YES at $2,3$, NO at $1,4,5$, and the ordinary payload $F$ at $0$. This table is a constant-size change to the final gate test. All-zero controls preserve arbitrary SAT. Each coordinate has its own set of affected free-lane fields, and the same is true of their endpoint tokens in the proper DIMACS file. Consequently toggling any chosen pair of values at each coordinate is affine in the switch bits, even though the formula and the underlying coloring graph contain many other bits.

Through any designated file take the cube that adds $2x_i$ modulo six at coordinate $i$. Its outputs depend on $S+2|x|$ with $|x|$ the Hamming weight. Within each parity class of the total, both answers occur, for each fixed truth value of $F$. Thus any monochromatic set on this cube omits at least one residue of $|x|\bmod3$.

An affine subspace avoiding a residue of Hamming weight modulo three has dimension at most $\lfloor t/2\rfloor+1$. To see this, write it as $v+L$ and consider the coordinate linear forms on $L$. If all coincide, $L$ has dimension at most one. If two differ, say coordinates $i,j$, and $e_i+e_j\notin L$, set $x_i+x_j=1$ over $\mathbb F_2$ and delete those two coordinates. The slice has dimension $\dim L-1$. Deletion is injective on it, and every weight decreases by one, so induction in steps of two proves the bound. Otherwise every pair of different coordinate classes has $e_i+e_j\in L$. These vectors span the even-weight subspace because the graph joining different classes is connected. Then $v+L$ contains an entire parity class, which attains all three residues for $t\ge5$. The bound at $t\le4$ is direct. For $t\ge3$ equality is possible by fixing odd parity on three or four core coordinates and requiring each remaining pair to be complementary. [Affine subspace bound and packed transfer](processing-packed-control-words-in-dimacs.md)

In particular a monochromatic leaf has codimension $d\ge\lceil t/2\rceil-1$. The per-file simulation gives $s\ge(\lceil t/2\rceil-2)/(Cw)$. Here $N=\Theta(t\log t)$ and $w=\Theta(\log N)$, as specified for the one-lane encoding.

An independent Fourier estimate also establishes the linear dependence on $t$. Let $H=v+L$ be an affine subspace of codimension $d$ in $\mathbb F_2^t$, let $\omega=e^{2\pi i/3}$, and write $h(x)=\omega^{|x|}$. In the normalized Boolean Fourier expansion, the factor in $\widehat h(a)$ from coordinate $j$ is $(1+(-1)^{a_j}\omega)/2$. Its magnitude is either $1/2$ or $\sqrt3/2$. The average of a character on $H$ vanishes unless $a\in L^\perp$, when its magnitude is one. Therefore
\[
 \left|\mathbb E_{x\in H}\,\omega^{|x|}\right|
 \le 2^d(\sqrt3/2)^t.
\]
If one residue is absent, the same average lies on the line segment connecting two cube roots of unity. The segment's distance from zero is $1/2$. Every monochromatic affine leaf through the designated input must therefore have
\[
 d\ge t\log_2(2/\sqrt3)-1,\qquad
 s\ge\frac{t\log_2(2/\sqrt3)-2}{Cw}.
\]

For a fixed known payload and fixed layout, the $\Theta(t/w)$ charge is sharp in the affine-preprocessing model on the entire control family. Extract each stored binary control bit from a designated fixed physical bit distinguishing its two pin positions, complementing that bit when required. Pack groups of $\lfloor(w-O(1))/3\rfloor$ three-bit controls by a fixed affine map. One lookup in a length-specific table per group returns the sum of its valid control codes modulo six. The table has at most $2^{w-O(1)}$ entries and fits in the word address space with room for the other banks. Accumulating the group sums and applying the known payload's truth table costs $O(1+t/w)$ charged instructions. The upper bound assumes the payload verdict as a constant on this fixed family. Computing an unknown SAT payload would require additional work.
