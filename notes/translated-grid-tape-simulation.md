# A single grid shift for nondeterministic tapes of growing dimension

**Research journal, 24 November 2026.** The proposed bound $2^{O_d(t/(\log t)^{1/(2d)})}$ for each fixed dimension is valid. The earlier grouped construction in this repository gives the stronger $2^{O_d(t/\sqrt{\log t})}$. The constants there include the $3^d$ neighboring cubes which might be visited in one epoch. Enumerating a grid shift for the *actual path* removes that factor. The same $2^{O(t/\sqrt{\log t})}$ time bound holds uniformly while

$$d\log_2 B\le(9/10)\log_2 t,\qquad B=\lceil\log_2(t+2)\rceil.$$

For example this permits $d$ up to $(9/10-\epsilon)\log_2 t/\log_2\log_2 t$ for every fixed $0<\epsilon<9/10$ at all sufficiently large $t$. Use a constant number $k$ of tapes, a constant alphabet, one independent head per tape, moves along at most one lattice edge per head and step, and constant nondeterministic branching. Input is stored on a coordinate axis with blank cells elsewhere. For the parameterized statement the machine's explicit transition table and number of states may be polynomial in $t$, with a fixed polynomial bound. A uniform language corollary requires that this description, the dimension, and the time clock be available within the simulated deterministic bound. For a fixed ordinary machine its transition table mentions only a fixed number of axes. The growing-dimension statement concerns the parameterized simulation of machines, not additional axes automatically usable by a fixed finite control. [Fixed-dimensional proof](multidimensional-tape-simulation.md)

## Choosing and enumerating the sparse crossings

For $r\in\{0,\ldots,B-1\}$ index the cube containing $x\in\mathbb Z^d$ by the vector with entries $\lfloor(x_j-r)/B\rfloor$. Use the **same scalar shift** on every coordinate of every tape. For a unit move along any coordinate there is exactly one $r$ for which that move crosses a cube boundary; for a stationary move there is none. This holds at negative coordinates as well. Summing over the $B$ shifts, the total number of crossing events (one per moving head that crosses) is the number of unit moves, at most $kt$. Every length-$t$ path therefore has a shift under which it crosses at most $\lfloor kt/B\rfloor$ times. The favorable shift may depend on the nondeterministic path.

Enumerate all shifts and every set of at most $kt/B$ distinct time/tape pairs, each labeled by a signed crossing axis. There are $kt$ possible pairs, and $2d$ labels per event. The base-two logarithm of the number of patterns is

$$O_k(\log B+(t/B)\log(2Bd)).$$

This follows by summing binomial coefficients through $\lfloor kt/B\rfloor$ and allowing one label per pair. A pattern can be produced with polynomial delay by indexing combinations. Pad a halted branch with stationary absorbing steps. For a fixed pattern, cut time after each prescribed crossing step and at multiples of $B$. The resulting $r'\le O_k(t/B)$ segments all have length at most $B$. Every symbol scanned or written during a segment is in one prescribed cube per tape: a movement crossing at its final step changes the cube of the *next* scanned symbol. The start cubes are recovered by accumulating the signed moves from the known initial heads, including simultaneous moves of different tapes. The segment constraint checks that the trajectory obeys all the prescribed crossings and does not make unlisted ones.

## A uniform CSP bound

Use the same chronological group checks as in the fixed-dimensional construction. Per segment store its branch choices and claimed read symbols for all steps, plus shared boundary states and within-cube head offsets. This takes $O_k(B+\log |Q|+d\lceil\log_2 B\rceil)=O(B)$ bits per segment under the stated parameter bounds. Pin the first state and head offsets to their prescribed initial values and require an accepting final state. Each endpoint constraint replays its segment, checks every prescribed crossing, and compares the result to the next boundary data. For each tape/cube, list the segments assigned to it and partition the chronological list into groups of exactly $g$ successive visits, except for the possibly shorter final group. A group constraint starts with the initial cube or an input snapshot, replays all its segments using their records, checks every read on its tape, performs each write, and checks an outgoing snapshot if another group follows. At most $kr'/g$ internal boundaries require a shared cube of $O(B^d)$ bits. The proof of equivalence is the same induction on last writes as for fixed dimension: every read and every previous write to that cell is processed by the same cube's chronological history. [Lean verification of the chronological projection](../lean/TapeRegionHistories.lean)

Put $g=B^{d-1}$. The snapshots use $O(B^d r'/g)=O(t)$ bits. The records and offsets use $O(t)$ further bits. A record or boundary offset is used by constantly many group and endpoint checks, and a snapshot by two groups. Thus the sum of arities is $O(t)$. The largest constraint has $O_k(gB+B^d)=O(B^d)=O(t^{9/10})$ inputs. Pad with dummy variables to $v=K t$ for a sufficiently large fixed integer $K$, so the arity is at most $v^{9/10}$ with constant incidence density. Computing a cell's coordinate tuple, comparing positions, unfolding the transition table, or scanning a full $B^d$-cell temporary cube all take polynomial bit time and circuit size. Even when the ambient box contains $(2t+1)^d$ cells, the compiler enumerates only the cubes encountered by the pattern and the $B^d$ cells of each such cube. A given address tuple occupies $O(d\log t)$ bits. Internal gates of a constraint do not become separate CSP variables.

Strassle and Subercaseaux's Fact 1.3 now gives deterministic time $2^{O(t/\sqrt{\log t})}\operatorname{poly}(t)$ per pattern. The log pattern count is $O_k(t\log\log t/\log t)=o(t/\sqrt{\log t})$. The same estimate therefore holds for their enumeration on an ordinary deterministic multitape simulator. The result depends on their circuit-CSP algorithm with $v^{9/10}$-arity constraints; using only a speedup for bounded-width CNFs needs a separate compilation and cost calculation. [Strassle and Subercaseaux, Definition 1.2, Fact 1.3 and §6](https://arxiv.org/html/2611.11832v1)

## Counting accepting paths with a canonical shift

The cited Boolean tensor-contraction algorithm also counts assignments. An accepting path can have several favorable shifts, so a direct sum over all the CSPs would overcount it. Choose the least $r$ having at most $\lfloor kt/B\rfloor$ crossings on the path. Each segment can compute a histogram with $B$ entries: for every actual unit move, increment the residue of the shift at which it would cross. For a positive move from coordinate $x$ to $x+1$, the residue is $(x+1)\bmod B$; for a negative move it is $x\bmod B$. A stationary head contributes nothing. This uses reconstructed positions and the fixed pattern, even for shifts other than that of the current CSP.

Combine segment histograms in a balanced binary tree padded to the next power of two with empty leaves. A node at level $j$ counts at most $kB2^j$ events. Give each of its $B$ nonnegative counts $c$ a canonical self-delimiting encoding of length $O(1+\log_2(c+1))$, for example Elias gamma applied to $c+1$. By concavity of the logarithm their total cost is $O_k(B(1+j))$. Fix that many bits per node and require all remaining padding to be zero. A local circuit checks either one segment's histogram or coordinatewise addition of its two children. Each such record occurs in constantly many constraints. Summing over levels costs $O_k(t)$ variables and incidences, since $\sum_{j\ge0}(1+j)2^{-j}$ converges. The root uses $O(B\log t)$ bits and checks that its chosen shift is the first with sufficiently few crossings. These arities are $O(\log^2t)$ and fit the preceding cap.

Use deterministic padding transitions at a halt, unique codes for each original nondeterministic branch, zero unused bits, and pin the dummy variables. Once a path and its canonical shift are fixed, all remaining crossings, boundary fields, read symbols, group snapshots and histograms are unique. Conversely every satisfying assignment reconstructs a legal accepting path as before. The sum of assignment counts over patterns is now exactly the number of accepting paths within the clock. Since branching is bounded, its bit length is $O(t)$; the same uniform deterministic time bound suffices. [Strassle and Subercaseaux, Remark 1.4 and §6](https://arxiv.org/html/2611.11832v1)

## Relation to previous simulations

The 2026 Strassle–Subercaseaux preprint treats ordinary one-dimensional multitape machines. Williams uses blocks on multidimensional *deterministic* tapes for a space upper bound. Earlier work includes Grigor'ev's multidimensional nondeterministic geometric packing simulations and deterministic tape-to-RAM acceleration, and Loui's stronger deterministic space bound for a nondeterministic machine with one multidimensional worktape head. These results address different source models or resources. The available primary sources did not establish priority for the grouped, variable-dimension multitape consequence here. The number $9/10$ comes from a sufficient arity cap in Fact 1.3 and the cube parameters in this proof; it supplies no impossibility threshold for larger dimensions. None of these upper bounds separates SAT from deterministic linear, quadratic, or cubic RAM time. [Williams, Theorem 1.5](https://people.csail.mit.edu/rrw/time-vs-space.pdf) · [Grigor'ev](https://m.mathnet.ru/php/archive.phtml?jrnid=znsl&option_lang=eng&paperid=3101&wshow=paper) · [Loui](https://dspace.mit.edu/entities/publication/98f4da55-d84f-4d1a-978d-2a64b27f21cd)

Lean checks the counting argument giving one sparse shift from the list of residues of all unit movements. The finite audit verifies the residue formula on signed coordinates and the resulting one-cube-per-segment property with two heads.
