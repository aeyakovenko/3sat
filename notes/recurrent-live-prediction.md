# Unpredictable bits on many incoming reads of one SAT run

**Research journal, 24 November 2026.** Suppose a fixed deterministic packed-word RAM decides explicit SAT in $O(N\log^a N)$ time for fixed $a\ge0$. Write $L=\max(2,\lceil\log_2(N+2)\rceil)$. Fix $0<\gamma<1$, $\lambda,\delta>0$ with $\lambda+2\delta<\gamma$, and $w=\lceil N^\gamma\rceil$. Consider only the first incoming read at each writable address in a segment, up to the next $2w$ instructions or the first halt. Queries get the original formula, current controller, segment start, current address and offset, and the genuine strict local event history. Each program starts with fresh private scratch. Bits of code and advice are counted in its description. [Finite replay model and signed source family](live-segment-snapshot-queries.md)

On arbitrarily large unsatisfiable formulas from a single solver-dependent family there are $\Omega(N/(w\operatorname{polylog} N))$ disjoint intervals of $w$ consecutive starting times. Their forward ranges of incoming reads are pairwise disjoint. For every start in each interval there is one bit position $j$ and a subset of $\Omega(w/\operatorname{polylog} N)$ distinct genuine incoming reads such that **every** predictor with description length plus worst-case query time at most $N^\lambda$ predicts bit $j$ with probability at most $1/2+N^{-\delta}$ on the uniform subset. Both the bit and the subset can depend on the start. The predictors may be chosen separately at every start. Randomized mixtures of these deterministic predictors have the same accuracy bound. This assertion is about a hard subset; its membership need not be computable quickly.

Moreover the intervals can be selected one by one. At each selection, predictors may read an indexed public record containing the actual native events throughout the previously selected intervals and their forward ranges. For one chosen start per previous interval the record can also give the actual preceding write for **every** incoming address in its forward segment. Selection order need not be chronological. The indexed records are accessible at ordinary RAM speed. All hardness refers to the same actual run and permits any original shared bank up to the budget specified below.

## The budget at one scale

The signed schedule proof has finitely many bounded-computation reductions followed by near-linear SAT calls. On polynomially bounded clocks, the time of its certification is at most
$$
 O\big((n_0+M+g+q+1)L^D+\operatorname{poly}(L)\big)
$$
for a fixed constant $D$. Here $n_0$ is the short padded source length, $M$ counts the public row data, directory and common bank (counting bits as words is an upper bound), $g$ is the maximum segment length and $q$ the maximum decoder clock. A candidate log contains $O(g)$ words. A single wrong reply, an asserted block property, an intervening write, and a schedule defect each require at most one further elimination. Each elimination of an $r$-step existential test with $m$ public words costs $O((r+m+1)L^{a+3}+\operatorname{poly}(L))$ here, or another fixed log power for the local interpreter and formatting. The number of eliminations is independent of the payload and the exponents. The original formula is accessed virtually through $n_0$; its materialized length is $N=\Theta(n_0^2 L^3)$. This fixed log power permits a common bank considerably larger than any fixed $N^\theta$, $\theta<1$. [Materialized cost per elimination](materialized-input-census.md) · [Canonical block checks](live-segment-snapshot-queries.md)

Choose an integer $b>D+a+6$ large enough to absorb the fixed header costs. Put $B=\lfloor N/L^b\rfloor$ and $K=w/L^b$. For **each** bank of at most $B$ bits there is a full internal $w$-window in which no start admits a whole-word predictor with $s+q\le K$. To see this, otherwise choose a cheap row from every full internal window, with at most $O(1+NL^a/w)$ segments and $g\le2w$. The row data and metadata occupy $O((1+NL^a/w)(K+L))$ bits. Along with the bank, $n_0$, $g$ and $q$, these give certification time $o(N/L^3)$, contradicting the signed deadline. The verifier guesses integer parameters and covers these choices independently of $b$ and $\gamma$. Empty or incomplete end windows are handled by the initial and terminal segments.

Fix one word evaluator supporting three ordinary operations: retrieving an observed word by time and slot, evaluating a list of charged bit predictors and combining their outputs, and reading a sorted exception dictionary. The descriptions can select these modes. One can implement all as fixed algorithms with code and payload for each chosen predictor in its row and one common bounded-width interpreter. The per-invocation simulation overhead can be bounded by a fixed polylogarithm on the modeled ISA. All powers used below have strict slack. The public bank has fixed, indexed subarrays; the evaluator can see each layout and length.

## Exposing previous windows and their writers

Reserve at most $B/2$ bits for an arbitrary initial bank. Once a hard window begins at $u$, expose every timed native record from $u-2w$ through $u+5w$ where present, clipping at the beginning and end of the genuine run. Provide a table indexed by absolute time and within-instruction slot with the true returned words. For any start in $[u-2w,u+3w)$ this table answers every required predictive query during its forward segment in $O(L)$ time by binary search. The horizon or the run ending before the end of the table creates no extra obligation. Consequently the next hard window is disjoint from this expanded interval of starts. Even the forward ranges $[u,u+3w)$ of the selected windows are therefore disjoint. Include native times, addresses and controller fields in the exposed records, and make available the chronological and address orders. The records occupy $O(wL)$ bits per selection. Sorting is allowed in the unrestricted preprocessing. [Forward-interval separation in Lean](../lean/DisclosedWriterMatching.lean)

For one chosen start in this window, also expose the actual last preceding write for each incoming address in its forward segment, omitting addresses initialized to zero with no preceding write. This needs $O(wL)$ more bits, including timestamps, within-step slots, addresses and returned values. Merge these writes with the exposed trace writes into a public sorted directory keyed by address and time. Retain duplicate-free keys and permit queries for the latest disclosed write before any specified time. Indexing or duplicating a fixed number of arrays costs $O(wL)$ bits per selection in the total bank. Thus $\Omega(B/(wL))$ successive selections fit. At each step the hard window includes every permitted predictor given this entire bank. In particular it is hard when the predictor uses only the embedded original bank. No hardness statement gives a predictor its own segment's subsequently disclosed records.

## From exact words to a uniform hard subset

Fix a hard start and its current bank. Its genuine first incoming reads form a finite domain $X$ of at most $O(w)$ contexts with pairwise distinct addresses. Take $h=\lfloor K/L^4\rfloor$ and $\varepsilon=N^{-\delta}/10$. If $|X|<h$, storing all addressed words in a sorted table already beats $K$. For each bit $j$ consider all bit predictors with charged length and time at most $N^\lambda$, clocked with a fixed default on failure. Include complements in the test class. At fixed input, bank, time and bit, there are at most $2^{O(N^\lambda+L)}$ possible predictors, including encoded time caps. This count concerns finite descriptions of the fixed instruction set.

Suppose for every bit $j$ and every distribution $\mu$ on $X$ with each mass at most $1/h$ some predictor in this class has accuracy greater than $1/2+\varepsilon$. By finite minimax, for each $j$ there is a distribution over predictors with expected accuracy greater than $1/2+\varepsilon$ against every such $\mu$. The capped probability simplex is the convex hull of uniform distributions on $h$-element sets, as is seen by perturbing any two fractional coordinates of $h\mu$. Fewer than $h$ contexts can have pointwise success at most $1/2+\varepsilon/2$, since otherwise the uniform distribution on $h$ of them violates the guarantee. Draw $O(\varepsilon^{-2}L)$ independent predictors for each bit. Majority is correct off those exceptions simultaneously for all genuine reads and bits for at least one draw, by the Chernoff bound and a union bound. Store the selected predictors and a sorted exception dictionary for each bit, addressed by the actual incoming address. This is the usual minimax and boosting argument in a setting where time, stored prediction programs, and bit repairs must all be charged. [Klivans and Servedio](https://www.cs.columbia.edu/~rocco/Public/ml05.pdf) · [Goldreich, Nisan and Wigderson](https://www.math.ias.edu/~avi/PUBLICATIONS/MYPAPERS/GNW95/GNW95.pdf)

Evaluating all these majorities costs $N^{\lambda+2\delta}\operatorname{polylog}N$ time and bits, including the $O(L)$ different bit positions of a word and format overhead. Bit repairs cost $O(hL^2)$ bits in total and $O(L^2)$ lookup time. These bounds are $o(K)$. The word reconstruction uses the genuine prior local history on each required call, so it supplies an honest word row of cost at most $K$, a contradiction.

Thus for some bit $j$ there is a capped distribution on which all predictors have accuracy at most $1/2+\varepsilon$. To get an ordinary set, independently include context $x$ with probability $h\mu(x)$. Its expected size is $h$. Each predictor's expected count of correct answers is at most $(1/2+\varepsilon)h$. Chernoff bounds for independent, nonidentical Bernoulli trials control additive deviations of $\varepsilon h$ for either count with failure probability at most $2\exp(-\Omega(\varepsilon^2 h))$. Since $\lambda+2\delta<\gamma$, this dominates the logarithm of the class size, so one set has size at least $(1-\varepsilon)h$ and satisfies all the accuracy bounds at once. Dividing counts by the set size gives accuracy at most $1/2+N^{-\delta}$. The same statement for complements gives the corresponding two-sided correlation bound.

## Distinct writes supplying the hard reads

At one chosen start per selected window, pick the bit and subset just proved. For each incoming read the $O(\log N)$-time predictor returning that bit of the most recent **disclosed** write at the requested address (zero by default) is in the class for all large $N$. It errs on at least $(1/2-N^{-\delta})$ of the hard subset. Every such read has a real preceding writer that has never been disclosed: if its writer were in the directory it would be the latest disclosed writer before the start, and a genuinely unwritten address always yields zero. These errors have distinct addresses and hence distinct producing write events. All their true producers are then disclosed before the next window is chosen. The last-writer and cross-round distinctness arguments are formalized in [DisclosedWriterMatching.lean](../lean/DisclosedWriterMatching.lean). With at most a fixed number of writes in any instruction, a fixed fraction of these $\Omega(h)$ producers must occur at least $\Omega(h)$ instructions before this start.

The forward ranges are disjoint, so taking the union also gives distinct consumer reads. One bit position occurs on windows carrying at least a $1/O(L)$ share of the total subset sizes. On these entire subsets the common bit retains the prediction bound, even for predictors selected separately per window conditional on its previous exposures. Their union contains $\Omega(Bh/(wL^2))=\Omega(N/\operatorname{polylog}N)$ distinct actual read events. On the same windows there are $\Omega(N/\operatorname{polylog}N)$ distinct writer–reader pairs with the stated span and whose word differs in that bit from the latest previously revealed write. The prediction bound applies to the full subsets; filtering to the prediction errors would reveal information about the bit.

This argument gives no efficiently discoverable ordering of the hard reads and imposes no independence on their true values. A linear run can still contain this many distinct writes and reads. The quantitative gap for an elapsed-time contradiction lies in ruling out the accuracy bound for an ordinary RAM on these actual contexts, or in deriving a stronger charge for producing their answers.

## Per-read certificates that may abstain or err

Consider a relation with one proposed output bit $b'\in\{0,1\}$ at a time. A short program can accept a claim about this bit using a different existential witness on every genuine read. Allow any fixed number of alternating witness blocks. The program, advice, total witness length and verification time are at most $N^{\lambda'}$ for a fixed $0<\lambda'<\lambda$. Also allow a deterministic preliminary computation taking at most $N^{\lambda'}$ steps to form a private copy of at most $N^{\lambda'}$ public words from the actual query context and previous disclosures. In verifying the quantified claim the only variable public data are this copy, the small program and advice, and the ordinary query fields of constant word length. Thus the relation may consult a large indexed source through its preliminary computation, with every such deterministic probe charged. It can, for example, operate on selected previously revealed writes and part of the local history.

For the hard bit on the uniform set above, call an address uniquely correct if the relation accepts the true bit alone and uniquely wrong if it accepts the opposite bit alone. Then
$$
 \Pr(\mathrm{uniquely\ correct})-\Pr(\mathrm{uniquely\ wrong})\le 2N^{-\delta}.
$$
Indeed the near-linear SAT hypothesis decides the two bounded quantified claims in $N^{\lambda'}\operatorname{polylog}N$ time and space for this fixed alternation depth by the same repeated bounded-computation conversion. A fixed interpreter can handle programs supplied in the small advice. The total charged cost fits $N^\lambda$. Return the uniquely accepted bit when there is one, and use an independent fair default otherwise (equivalently, average the two constant defaults). The accuracy is one half plus half the displayed difference. In particular a sound per-read certificate covers at most $2N^{-\delta}$ of this set, even if it can abstain and a different proof is available at every covered address. This also applies to an advice-bounded generator of labelled addresses using a free witness as seed when it outputs at most one bit per genuine address. An emitter that guesses both bit values gives no unique certificate.

Materializing the public view is an actual cost in this deduction. On an arbitrary $m$-word public array a nondeterministic program can select an index and test for a nonzero entry in constant word time if it guesses one word at a step. Any deterministic decision procedure for that test on arbitrary arrays must inspect all $m$ entries on the all-zero array. A general elimination priced only by the short branch time would already fail on this example. The obstruction alone makes no assertion about the specific public histories of SAT solvers.

## Raw controller bits for quadratic and cubic solvers

There is a version directly at the two higher time targets. Let $k\in\{2,3\}$, let $A$ be a correct $O(N^k)$ SAT solver on the ordinary load/store RAM, set $r=1/k^2$, and take $\lambda,\delta>0$ with $\lambda+2\delta<r$. On the solver-dependent unsatisfiable family in the [register-history bound](chronological-solver-registers.md), there is one controller bit and a subset of $\Omega(N^r/\operatorname{polylog}N)$ different **actual prehalt** instruction times on which all bounded-fan-in Boolean circuits of size at most $N^\lambda$ have accuracy at most $1/2+N^{-\delta}$ on the uniform set. Here the circuit is chosen after seeing the whole input, and its only argument is the binary instruction time. The target is a bit of the registers or program counter. The theorem in this section supplies its own family for $k$ and does not assume a near-linear solver.

For this application the lower bound for a single circuit returning the entire controller on the padded clock is $\Omega(N^{1/4}/L^{13/4})$ at $k=2$ and $\Omega(N^{1/9}/L^{7/3})$ at $k=3$. Apply the bit argument just on the true prehalt times using $h=\lfloor N^r/L^{10}\rfloor$. There are $O(L)$ bits and polynomially many times. Polynomially many majority inputs can be counted by a Boolean circuit of near-linear size in their number using an addition tree, so the majority predictors cost $N^{\lambda+2\delta}\operatorname{polylog}N$ total gates. For each bit, store its fewer than $h$ exception times and test membership by equality on their $O(L)$-bit timestamps, using $O(h L^2)$ gates summed over bits. A hardwired comparison against the first halt time supplies the constant padded controller at and after halt for another $O(L)$ gates including output selection. These costs contradict the respective multi-output lower bound if every bit is predictable on every capped distribution. When the prehalt domain has fewer than $h$ times the direct complete table already contradicts the same bound. Rounding the remaining hard distribution to a subset works as before because there are at most $2^{O(N^\lambda L)}$ such circuits. This gives an average-case obstruction for the actual computation without assuming anything about its workspace. No separate bound on elapsed time follows.
