# A tape boundary and resource bounds for genuine SAT computations

**Research release, 24 November 2026.** The two-plane grate can be realized with one planar work tape and one ordinary linear work tape. There is a matching threshold in the number of auxiliary cells visited. In dimension $d\ge2$ the threshold is $T^{1/d}$, and that many auxiliary visit intervals must be live simultaneously on a positive fraction of all time cuts. A second result simulates nondeterministic tapes even when their dimension grows with the clock. The RAM results constrain cumulative memory, trace treewidth and the descriptions of actual reachable states. The first open SAT target remains the exclusion of deterministic $O(n)$ time with unrestricted workspace.

## Master theorem

The following three parts have different machine hypotheses. All tape heads below take one nearest-neighbor unit move or stay. In the RAM statements, $N$ counts the bits of an ordinary explicit formula on a packed logarithmic-word machine with the journal's fixed instruction basis.

**I. Tape access graphs.** In a $T$-step trace with one planar work head and a fixed number of auxiliary work heads visiting $W$ distinct auxiliary cells in total, there is a deletion set of size $O(T^{3/4}\sqrt{W+1})$ leaving every weak component of size $O(T^{3/4}\sqrt{W+1})$, for $W\le\sqrt T$. Use chronological edges and forward edges between consecutive visits to each work cell. Conversely a fixed machine with one planar work head, one linear work head and sequential read-only commands has traces with $W=\Theta(\sqrt T)$ on which every deletion of at most $\gamma T$ vertices leaves $\Omega(T^2)$ reachable ordered pairs, for some $\gamma>0$. There is a family on the same hardware for which every fixed $R$ costs $\Omega_R(T)$ placements in the PPST two-person game.

For the upper bound, randomly translate a square grid of side $u$. Along the consecutive visit intervals of any auxiliary cell, the sum of their durations is at most $T$. Some shift has at most $(W+1)T/u$ chronological or auxiliary edges crossing tiles. Inside each tile, a cut after a group of $q$ visits crosses at most $u^2+W+1$ cell or time chains. Optimize the two costs with $u\asymp T^{1/4}\sqrt{W+1}$ and $q\asymp T^{3/4}\sqrt{W+1}$.

For the lower bound, enlarge each vertex of a fault-tolerant bounded-degree graph into a square of lanes. Along an edge transfer each of a fixed number of affine lane permutations. A linear buffer receives the lanes in source order and gives them back in reverse order while the planar head visits the chosen target permutation. Each step deletion spoils at most one permanent planar lane and one buffered source lane in the current pass. The movement, including incidental visits, costs linear time in the number of lifted vertices. A second plane can execute the linear head's trajectory along one coordinate axis. Robust terminal sets connect successive stages of the pebble game. [Mixed-tape proof, game and block conventions](mixed-tape-pebble-frontier.md) · [Two-plane lane construction](two-plane-directed-grates.md) · [Simultaneous terminal sets](two-tape-robust-terminals.md)

The same construction in fixed dimension $d\ge2$ packs $m^{d-1}$ disjoint square sheets of $m$ lanes into a box of side $m$. A hard run then takes $T=\Theta_d(m^d)$ steps and visits $m$ auxiliary cells. For the converse, let $H_h$ count time cuts with more than $h$ auxiliary cells having visits on both sides. Delete both incident times of each such cut. All surviving auxiliary consecutive-visit edges have total duration at most $hT$. Shift a spatial grid and then shift cuts in the local chronological order of each tile. For $Q=T^{(d+1)/(d+2)}(h+1)^{d/(d+2)}$, at most $2H_h+O_d(Q)$ deletions leave weak components of size $O_d(Q)$. A grate surviving a fixed positive deletion fraction must have $H_h=\Omega(T)$ at $h=\lfloor cT^{1/d}\rfloor$ for sufficiently small fixed $c>0$. [Proof, including the common family for all fixed round bounds](mixed-tape-dimension-threshold.md)

**II. Nondeterministic tapes.** Let $B=\lceil\log_2(t+2)\rceil$. For a constant number of single-head $d$-dimensional tapes with fixed alphabet and constant branching, with the initial input laid along a coordinate axis, bounded $t$-step acceptance can be decided deterministically in $2^{O(t/\sqrt{\log t})}$ time whenever $B^d\le t^{9/10}$. The finite transition description has a fixed polynomial size bound in $t$ and is supplied to the simulator; the constant in the bound is uniform in $d$ with these conventions.

Translate all axes by the same residue modulo $B$. Each unit move crosses a block boundary for exactly one residue. Enumerate the shift and the $O(t/B)$ labelled crossings of a favorable computation. Their enumeration costs $2^{O((t/B)\log(2Bd))}$. In a segment each head reads one spatial cube; verify chronological groups of $B^{d-1}$ visits to a cube between snapshots. This gives $O(t)$ variables and total constraint arity, and maximum arity $O(B^d)$. Padding by a fixed constant factor meets the published circuit-CSP solver's arity bound. Fixed $d$ and $d\le(9/10-\epsilon)\log t/\log\log t$ are corollaries. In the latter formulation all logarithms in the dimension ratio are base two. [Uniform proof](translated-grid-tape-simulation.md) · [Strassle and Subercaseaux, Fact 1.3](https://arxiv.org/html/2611.11832v1)

**III. Verifying a rejecting RAM computation by checkpoints.** Use $W(e,d)$ to mean that, for each fixed nondeterministic source RAM, there is a nondeterministic machine certifying its nonacceptance on every input of $m$ public words and every clock $R$ in $(R^e+m^d+1)H^{o(1)}$ time, $H=\max(2,m,R)$. An ordinary SAT instance for timely acceptance has length $H^{1+o(1)}$ and locally readable packed words. A sound reference UNSAT recognizer of exponent $d\ge1$ gives $W(d,d)$ by materialization. Suppose a certificate describes the run of a deterministic sound UNSAT recognizer on this virtual formula, through its first negative signal. Assume an honest certificate of $H^{u+o(1)}$ bits exists for every source input with no timely accepting branch. Deterministic outer preparation takes $H^{z+o(1)}$ time, and a fixed nondeterministic defect checker takes $H^{v+o(1)}$ steps. For every source input and every certificate passing the outer checks, absence of a detected defect must imply that the source has **no timely accepting branch**. The defect machine gets read access to the public input and the supplied description. Then $W(e,d)$ gives $W(g,d)$ for
$$ g=\max\{ud,ve,z\},\qquad g\le d. $$
A direct-replay branch costing at most $H^{g+o(1)}$ may handle short runs instead. All exponents here describe fixed uniform machines and clockable bounds and allow arbitrarily small strict slack. The chart guess fits $H^{ud+o(1)}$. Apply $W(e,d)$ to the defect check, charging $m^d$ again for the inherited public input. On $H=m$ this term covers $H^g$. A finite iteration reaching $g<1$ contradicts the bounded complementary interpreter on its own short padded input. Its source clock is a fixed power of the source length greater than $d$.

For nested checks of **states**, exactness on genuine starts is enough: guess endpoints, challenge a segment and one end address, replay from the supplied starting state with a private write overlay, and compare. Induct on nesting depth. For a spurious successful list, its first false endpoint follows a genuine start, where some word or controller comparison fails. Correct endpoints permit every honest nested check. A SAT slowdown starts a fresh actual solver execution. This is the substitution step that allows the signed alternation annotations in the description corollary below. ## Corollaries for unrestricted-workspace SAT solvers

* **Cumulative memory.** Sum one plus the number of currently nonzero writable words over all steps up to the first UNSAT signal. A cumulative bound $O(N^c)$ gives a checkpoint list of exponent $c-x$ and a replay exponent $x$, by taking a minimum-size state from each window of $H^x$ times. Optimizing in III gives $g=cde/(d+e)$. With the same solver as reference, $d=c$; finite iteration crosses one for every $c<\varphi=(1+\sqrt5)/2$. Thus no such cumulative upper bound holds on all negative inputs. [Cumulative proof](cumulative-sat-memory.md)
* **Time and treewidth.** Let $T$ count steps to the negative signal and $w$ be the treewidth of the undirected chronology and last-write/load graph. A width-$w$ decomposition gives a cut of size $O((w+1)T/b)$ into components of size at most $b$. The signed replay checker charges both the cut and the component size. III gives $g=c/(1-\lambda+\lambda/d+\lambda/e)$ from an assumed bound $O(N^c)$ on $(T+1)(w+1)^\lambda$, $0<\lambda\le1$. With $d=c$ this excludes each $c<(1+\sqrt{1+4\lambda})/2$, including every exponent below $\varphi$ for $\lambda=1$. [Treewidth proof](native-treewidth-trade.md)
* **Locally decodable states.** For each fixed $c<2\cos(\pi/7)$, a deterministic $O(N^c)$ SAT solver and a fixed word decoder have arbitrarily large inputs on which a genuine state exceeds the simultaneous $N^\eta$ description-length and per-word time budgets for some $\eta>0$. One description must answer every address, given the original formula and time. Use the genuine-start induction in III in the published finite alternation-trading proof with strict exponent slack. At linear time and constant query latency, a finer calculation forces $\Omega(N/\log^9 N)$ bits for an individually encoded state on a prescribed rejecting grid. A linear-time example stores an inverse permutation and attains the exponent boundary $e+d=1$ up to logarithmic factors on that family. [Williams transfer](true-start-snapshot-trading.md) · [Grid accounting](solver-snapshot-descriptions.md) · [Inverse permutation limit](inverse-snapshot-frontier.md)

If a proposed exponent is at most one, relax it slightly above one while keeping the strict upper threshold, so the reference exponent meets the transfer hypotheses. These are worst-case statements about the specified resources. A linear-time algorithm can accrue quadratic cumulative memory and can build graphs of linear treewidth. The generated tape trajectories can even be executed by a machine that ignores every read value. None of those conclusions rules out an ordinary linear-time SAT solver.

## Priority and independent review

PPST raised the multidimensional grate question, cited Gabber and Galil's earlier two-dimensional superconcentrators, and already treated the two-round consequence of a grate. Schnitger supplied abstract grates, Klawe used expander replacement, and Blocki and Cinkoske provide the robust outer terminals used here. The stacked-grate challenger and stronger general-DAG round bounds have published antecedents. The physical plane-plus-line realization and its matching $W$ threshold are the claims to review for priority. No new general-DAG pebbling bound is claimed.
