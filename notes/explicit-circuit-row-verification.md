# Checking emptiness when the opcode row has a public circuit

Let a row have $T=2^h$ Boolean entries. Its description is part of the verified input. A Boolean circuit $C$ on $h$ index bits specifies entry $C(i)$, and the statement to be verified is a claimed integer $K=\sum_{i<T} C(i)$. Zero count tests emptiness. The black-box one-change argument raises the following question. Can the lower bound survive if the verifier can read the circuit that computes the queried instruction?

**Corollary of Reingold–Rothblum–Rothblum.** Fix any $\epsilon>0$. For public circuits of encoded length $s=T^{o(1)}$, including arbitrary depth and sharing of gates, there is a constant-round public-coin proof with perfect completeness, soundness error at most $1/2$, and total communication and verifier time $O(T^\epsilon)$. The prescribed prover uses polynomial time in $T$. The verifier is uniform in the description. More generally, the evaluator may access a separate immutable input of $N\le T^{O(1)}$ bits. If it evaluates one specified index in polynomial time in $T+N$ and $T^{o(1)}$ work space, the same conclusions hold with verifier time and communication bounded by $\widetilde O(N+T^\epsilon)$. Here the evaluator is a fixed ordinary machine and its public parameters count in the input. [Reingold, Rothblum and Rothblum, Theorem 1 and Corollary 9](https://eccc.weizmann.ac.il/report/2016/061/revision/2/download/)

Choose an integer $e\ge2$ with $1/e<\epsilon$. For a padded language take the public parameters, the immutable input, $h$, the count in $h+1$ bits and a declared work bound $U$ for one entry. Include enough zeros to give it length $m=\Theta(s+N+h+2^{\lceil h/e\rceil}+(U+1)^k)$ for a sufficiently large fixed integer $k$. Allow checkable padding up to a constant factor to cover delimiters. For explicit circuits take $U=O(s+h+1)$ with the fixed constant chosen for the circuit interpreter. A topological evaluation needs only the already computed gate bits and index counters. It can scan the gate list and work tape for wire lookups. For a fixed general evaluator, charge the space to simulate each of its occupied work words and addresses on a tape. A sequential scan for a word or for a read-only input bit costs polynomial time.

The padded decider enforces $h\le e\log_2 m$ and $U\le m^{1/k}$ before the loop. It enumerates the $2^h\le m^e$ indices, reusing its work space between evaluations, and keeps an exact $h+1$-bit count. It rejects on violations of a fixed polynomial clock or the declared work bound. It therefore runs in polynomial time and $O(m^{1/k}+\log m)$ work space on every string. On honest input with a valid work bound this machine accepts exactly the correct count. Apply Reingold–Rothblum–Rothblum, Corollary 9, with protocol parameter $\delta=1/2$. It gives communication $m^{1/2}\operatorname{poly}(m^{1/k}+\log m)$ and verifier time $\widetilde O(m)+m^{1/2}\operatorname{poly}(m^{1/k}+\log m)$. Choose $k$ above twice the fixed space-polynomial degree in the construction. The time exponent of the padded source machine can be fixed independently of $k$, since the length $m$ already includes the padding. Its simple cap arithmetic uses logarithmic counters for each fixed $k$. Both verifier bounds are then $\widetilde O(m)$. Writing the padding deterministically takes $O(m)$ time.

In particular the same protocol handles every circuit text, with worst-case cost $\widetilde O(N+(s+h+1)^k+T^{1/e})$. On the stated subpolynomial-size families this gives the claimed bounds with slack in $1/e<\epsilon$. For the generalized evaluator, a public valid bound $U=T^{o(1)}$ gives the identical conclusion. If only an asymptotic space promise is given for a fixed evaluator, one can instead use a fixed $U$ of order $T^{1/(2ek)}$. This fits the same padding budget, covers the promised space eventually, and does not depend on an unknown rate in the $o(1)$. Finitely many short lengths for that evaluator can be decided directly.

If the opcode's public specification is an algorithm and the prover proposes a shortcut circuit, the same count proof can check agreement by counting the indices where their outputs disagree and requiring zero. This applies when the **specified** evaluation of a single row entry has the polynomial time and low work space just used. Existence of a small circuit for a fixed hidden table gives the verifier no way to certify the table–circuit agreement under arbitrary black-box access. For a RAM execution the instruction text may be short while the operands presented at step $i$ depend on earlier writes throughout memory. An index evaluator for that history within this space and time bound is the missing step.

## The explicit sum-check for formulas

For a Boolean formula the round exponent is already visible in Williams's Theorem 3.4. With $r>2$ fixed prover rounds and a formula of $T^{o(1)}$ connectives on $h=\log_2 T$ bits, it verifies the count in $T^{1/(r+1)+o(1)}$ time. Divide the index bits into $r+1$ blocks. Interpolate the bits of an integer block index $j$ as univariate polynomials on a grid of size about $T^{1/(r+1)}$. The ordinary formula arithmetization has degree at most its number of leaves. After this substitution, one variable has degree at most the product of the grid size and that number of leaves. The prover sends a univariate partial sum before each fresh challenge. In the last block the verifier evaluates the arithmetized formula itself on the remaining grid. Characteristic greater than $T$ recovers the integer count. The formula degree estimate need not hold for a small deep circuit with shared gates. The bounded-space proof above covers that case without a degree estimate. [Williams, Theorem 3.4](https://drops.dagstuhl.de/storage/00lipics/lipics-vol050-ccc2016/LIPIcs.CCC.2016.2/LIPIcs.CCC.2016.2.pdf)

## A lower bound from the public description itself

Fix a constant $0<\beta\le1$ and put $L=2^{\lfloor\beta h\rfloor}$. There are explicit fan-in-two circuit descriptions of $\Theta(L\log L)$ bits, promised to describe a row with at most one mark, for which any statistical interactive proof of emptiness with completeness $2/3$ and soundness $1/3$ needs $\Omega(L)$ expected input-word probes on its all-zero member with a completeness-achieving prover. This holds for arbitrary interaction and private coins on a RAM with word width $O(\log T)$. The circuit and its input length have the same layout on every member of the family.

Use a shared binary tree to decode the low $\log_2 L$ index bits into all the $L$ singleton indicators. A shared additional gate tests whether all the high bits are zero, using $O(h)$ gates. Each of $L$ separate gates combines its singleton indicator with a reference to a constant gate. Use two constant gates numbered by consecutive integers with even lower index, so their fixed-width indices differ in one bit. Every reference initially specifies zero. Take the OR of the enabled indicators and combine it with the high-bit test. Flipping reference $j$ to the constant one marks exactly entry $j$. A fixed-width topological gate list gives the stated description length. Choose a constant-width gate record measured in fields of $\Theta(\log L)$ bits. The $L$ potentially flipped bits lie in distinct records at regularly spaced positions. A contiguous word of $O(\log T)=O_\beta(\log L)$ bits intersects at most $b=O_\beta(1)$ of them, even allowing unaligned reads.

Fix a prover strategy attaining completeness on the all-zero member. Let $p_j$ be the probability of reading a word containing the $j$-th distinguished bit in that interaction. On the input with flip $j$, the prover can use the old strategy. Coupling verifier coins makes every transcript agree until a word containing this bit is read, so soundness requires $p_j\ge1/3$ for every $j$. If $q$ is the expected number of probes on the empty instance, then $bq\ge\sum_j p_j\ge L/3$. This lower bound charges the public description and is compatible with the small-circuit protocol. For a description of essentially row length a verification lower bound can come entirely from the bits encoding the operation.
