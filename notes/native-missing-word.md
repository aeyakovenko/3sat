# Checking almost as many records as the diagonal machine has steps

**Research journal, 24 November 2026.** The first-missing-output argument previously paid twice for simulating a decoder on tapes. Changing the auxiliary source machine lets the decoder run natively. This gives a stronger necessary property of false memory histories under a hypothetical linear-time SAT solver. The first omitted word in this construction belongs to a new source.

## A bounded auxiliary interpreter

On public unary input of length n and binary name p of length less than n, run a fixed universal RAM interpreter V for B=2^(20n) steps. Its words have n² bits. This deliberate choice of word width concerns the auxiliary source. The assumed SAT solver still has ordinary logarithmic words on its own explicit formula. Include arithmetic modulo the word size's power of two, word logic, shifts with a defined overshift convention, control flow and indirect memory access. Other fixed polylogarithmic bit-cost operations of the SAT model can be emulated on short words in poly(n) time. All memory starts at zero apart from specified input regions. V has a constant number of native registers. Its remaining state occupies addressed memory. A name can contain a self-delimiting program and auxiliary data. Give wrong outputs and timeouts no n-bit value.

We need the following elementary property of the interpreter. Any fixed program whose addresses and word operands are O(n) bits and whose running time is at most B, including a program using a SAT solver on explicit instances of length 2^{O(n)}, can be run with poly(n) overhead per operation, for sufficiently large n. Store simulated words at their native addresses in a reserved region, and mask to the intended simulated width at each operation. Fixed instruction dispatch, width computations and tagged regions cost poly(n) per operation. Word widths that grow with an intermediate input length remain O(n) at these bounds. A fixed program has a name of constant length, however large its fixed constants are. On arbitrary input programs the native B-step cap and n²-bit words still bound every record.

There are only 2ⁿ−1 names of length less than n. Let vₙ be the first n-bit word they all omit by the cutoff. Form CPU-valid chronological histories and separately memory-valid address-ordered histories for this very interpreter. Use a fixed number of event slots per native step with unique ordered timestamps, including read-before-write order, initialized input and halted padding. Inactive slots can use a reserved dummy location with a fixed unchanged value. Both local checks use poly(n) storage and 2^{O(n)} time before fingerprints. In particular they may guess n²-bit words, execute the fixed native instruction on them by bit operations, and retain the program name and registers between steps. Use an append-only output convention, with output length and agreement with the proposed word checked chronologically. A pair sharing its entire event multiset glues to a genuine execution. No such pair can produce vₙ. [Chronological and address-ordered checks](public-memory-fingerprints.md)

## A near-linear panel of challenges

Assume linear-time SAT in the target model. Let g(n)=√(n log₂(n+2)), choose a sufficiently large fixed integer a, put r=⌊B/2^{a g(n)}⌋, k=⌊√r⌋ and h=max(1,⌊√(n/log₂(n+2))⌋). For a uniform integer exponent one may take the integer square root of ⌊n log₂(n+2)⌋, obtained from the bit length of (n+2)ⁿ. This changes g by less than two. Use fields with poly(n)-bit representations large enough for all stamped records, reserving at least r points outside their alphabet. Universally choose the field representation after the name p and before the first round, guarding the checks by irreducibility of the specified binary polynomial. This keeps the same name for all legitimate representations. In each round ask for up to r product evaluations. The play uses one early name p, and both logs at its leaf must reproduce every previously announced numerical reply. Also require the two logs to agree on exact integer moments of orders zero through k for a fixed integer coding of records with poly(n) bits. A fixed uniformly indexed polynomial-size panel of such orders is allowed when the indexing uses poly(n) space and 2^{O(n)} time per record.

For every real output a genuine pair meets every challenge. Given a full transcript, one can stream the two candidate histories in nondeterministic tape space (r+k²+1)poly(n) and time 2^{O(n)}. This includes storing the h panels and paired replies, the moment accumulators, the input to each local check and polynomial-time arithmetic in the lengths of the large integers being accumulated. Their bit lengths are O((k+1)poly(n)). The assumptions r≤B and k²≤B give an exponential clock whose logarithm is O(n) with constants independent of a. The previously proved bounded-reachability implication of linear SAT evaluates this leaf on a deterministic RAM in (r+1)2^{O(g(n))} time, with short word addresses for these exponentially long data. Compiling its verdict and eliminating the O(h) game quantifiers adds O(h log n)=O(g(n)) to the logarithm of the time. All input size and clock **upper bounds** used in the uniform elimination estimates can use r≤B. Hence the constant in this overhead can be bounded independently of the eventual choice of a. Computing r and padding the budgets for a chosen constant costs poly(n) preprocessing. [Bounded reachability and quantifier elimination](linear-quantifiers.md)

A fixed decoder asks n prefix-existence queries to find the first word where the game predicate is false, returning a default if all pass. These queries add a constant number of quantified blocks per call. The entire time bound, including native interpretation, is (r+1)2^{C g(n)} for a fixed overhead constant C and sufficiently large n. Choose a>C with room for rounding. The calculation then finishes within B, on a name shorter than n. If the game failed at vₙ for infinitely many n, this fixed decoder would print vₙ by B at those lengths. Every preceding word has a real producing run and passes. This contradicts its definition.

Thus under linear SAT, for all sufficiently large n there is a **single name p** at vₙ whose online numerical replies survive every legal h-round challenge. At any leaf a single false pair for p must realize all the replies. In particular choose r distinct reserved points in one round. After cancelling the common multiset, the two remaining monic products have equal degree e and agree at all r points. Since the logs genuinely differ, e>r. In every imposed order, the signed record multiplicities also change sign more than k times, by the moment test. The discrepancy consequently involves at least B/2^{O(√(n log n))} events per side and at least √B/2^{O(√(n log n))} sign changes, despite fixing the short program before the challenges.

## A polynomial fraction of the clock for a fixed number of rounds

For each fixed number h₀ of adaptive rounds there is an integer a₀ such that the same argument permits r₀=⌊B/n^{a₀}⌋ product points per round. This strengthens the event-distance conclusion to more than B/polylog(B) remaining records per side. In this version we may impose polynomially many integer moments of polynomially bounded degree. The batched algorithm in this section uses low-degree moments. The next construction recovers large exact moments on the same pair as the stronger product panels.

The first improvement is to batch the arithmetic. Buffer at most r₀ records at a time. Build the block polynomial by a balanced product tree and evaluate it at all r₀ points by a subproduct and remainder tree. Multiply the results componentwise into the running products for the whole log. Repeat per round and for both streams. Repeated points are harmless as evaluation leaves. Balanced monic division uses reversed polynomials and truncated power series inversion. These algorithms can process lists of nodes in consecutive order on tapes, level by level. Input to a level, result and temporary tapes together use r₀ poly(n) bits. The number of tape scans per level and the number of tree levels are polynomial in n. [Borodin and Moenck](https://www.cs.toronto.edu/~bor/Papers/fast-modular-transforms.pdf)

For bit costs, write the field as binary polynomials of degree less than b=poly(n) modulo the supplied irreducible polynomial. In multiplying two length-d field-polynomial arrays (d≤2r₀+2), allocate 2b−1 consecutive digit positions per array coefficient and Ω(log(db+2)) bits per digit, enough to prevent integer carries between convolution entries. Pack the zero/one coefficients into these digits and multiply two nonnegative integers of O(d poly(n)) bits. Read out the low bit of each digit and reduce the resulting binary coefficient polynomials of degree at most 2b−2 modulo the field modulus. Sequential reduction costs d poly(n) time. Quasilinear multitape integer multiplication therefore gives d poly(n) tape time per product and at most the same space. At each product or remainder level the combined array lengths are O(r₀), with an extra poly(n) factor permitted for divisions and padding. Across O(1+B/r₀) blocks, the full nondeterministic checker runs in T₀=B n^{O(1)} time with data and configuration length A₀≤(r₀+1)n^{O(1)}. The bounds' polynomial exponents can be chosen independently of a₀ for fixed h₀, using log r₀≤20n and processing a fixed maximum number of low-degree moments per record. [Harvey and van der Hoeven, multitape integer multiplication](https://annals.math.princeton.edu/2021/193-2/p04)

The second improvement is a bounded-reachability calculation for a large configuration. If the input plus a configuration and clock fit in A bits and the time cap is T, linear SAT gives a deterministic RAM bound

    (A + √(AT)) · log^{O(1)}(A+T+2).

Take F=⌈√max(1,⌈T/A⌉)⌉, rounding up to an integer. Guess F−1 checkpoints, universally choose one of the F intervals, guess F−1 checkpoints in that interval and universally choose one of its F subintervals. A leaf now checks **A steps** between its two specified configurations. Starting from the explicitly supplied tape contents, a nondeterministic tape algorithm can replay A steps in O(A polylog(A+T+2)) time, including initialization, positioning the heads, comparing the final configuration and enforcing the space and clock caps. One can give each checkpoint an elapsed step count and allow a leaf to use any ℓ≤A ordinary steps, checking once that the end count is the start count plus ℓ and is at most T. Zero-length segments cover unused capacity. This avoids charging for an absolute clock at each local step. The leaf has a quasilinear explicit SAT encoding; equivalently use the checked chronological and sorted RAM transcript with the endpoint configurations as pins. All checks together have a fixed number of quantified blocks and initial length O(FA polylog(A+T+2)). Fixed-block elimination under linear SAT gives the displayed bound. [Explicit transcript and quantifier costs](linear-quantifiers.md)

Use a padded bound A=(r₀+1)nᵈ and T=B nᶜ for fixed c,d large enough for the new leaf. The outer program, field and h₀ challenge/reply quantifiers add a fixed number of eliminations. Together with native interpretation and the prefix search, they cost another fixed power of n. The runtime is consequently bounded by a constant times

    B · ( n^{d−a₀} + n^{(c+d−a₀)/2} ) · n^{C},

for large n and a fixed C independent of a₀. The cost of computing the chosen integer cap can be absorbed in fixed polynomial preprocessing by the same routine reading a₀. Choosing a₀>c+d+2C+d+4 suffices. Its constant program name eventually fits below n, so the first-false-word contradiction applies. The fast leaf here does not evaluate exponentially high exact integer moments. Writing all intermediate integer coefficients of an ordinary subproduct tree for such moments can already exceed the allowed time.

## Binding one chunk before testing its numerical claims

There is a way to combine the two strong conclusions. For any fixed h₀ there is a sufficiently large fixed a₁ such that a single p survives h₀ rounds with r₁=⌊B/n^{a₁}⌋ points per round **and** exact integer moments through k₁=⌊√r₁⌋ on the same false pair at each leaf.

Let K=Θ(B) be the number of stamped records per log. Cut each of the two local streams into J=⌈√(K/r₁)⌉ consecutive chunks of at most C=⌈K/J⌉ records. At the end of the adaptive play, existentially supply the local checker state at every chunk boundary, all claimed chunk products at all public points, and all claimed nonnegative chunk moments through k₁. Split the streaming checker at record boundaries, cutting chronological checks at complete native steps if each step uses a fixed number of records. Controls, output counters and the retained preceding address-ordered record fit in poly(n) bits. Use the common original program and the prescribed initial and accepting conditions. Multiply the chunk products and add the exact chunk moments across each log; compare with all announced numerical replies and the required equal total moments. Total summary length and time for this fold are O(J r₁ poly(n)) because the j-th moment has O(n+j poly(n)) bits and k₁²≤r₁.

Universally select one chunk, then existentially supply its entire sequence of at most C explicit records and any local transition choices. Check its local legality from its supplied entry state to its exit. Only **after** fixing those records, universally choose a product coordinate or a moment test for that chunk. A single product coordinate takes C poly(n) time by direct multiplication. For a moment test choose j≤k₁ and a modulus 2≤d≤D. Scan the records, compute x^j mod d by repeated squaring and compare their sum modulo d with the claimed integer modulo d. Here D is a fixed constant times the maximum allowed *bit length* of any chunk moment, plus a constant, so that log₂ D=O(n). Enforce the declared bit limits on the claims. The moduli need no primality tests. The least common multiple of 1,…,D is at least 2ᴰ/(D+1): every binomial coefficient from row D divides this least common multiple because its p-adic valuation is a sum of at most ⌊log_p D⌋ terms of size zero or one in the factorial valuation formula. The largest coefficient is at least the row average. Thus agreement for every modulus forces exact equality of the bounded integers. Reading the full selected integer claim to take its residue also fits C poly(n) time. This avoids building the high powers x^j for every record.

All tests on a given chunk use the same concrete records. If each chunk passes, choose one witness per chunk and concatenate along its common boundary states. This gives one pair of entire locally admissible histories attaining the claimed numerical data. The converse uses the actual chunk records of a witnessing pair. The terminal predicate now has a fixed number of quantifier blocks and a deterministic leaf of time (Jr₁+C)poly(n)=O(√(Kr₁)poly(n)); the factor h₀ and a fixed polynomial-size panel of orders fit the overhead. For this time bound use poly(n)-time record codes, for example timestamp-first and address-first order. The slower exponential-time codes allowed in the first section need not satisfy it. Compiling the deterministic checks and eliminating the total fixed number of blocks gives time B n^{−a₁/2+O(1)}, including prefix decoding and interpretation. Take a₁ larger than twice the fixed overhead exponent. At the omitted word a single false pair must then move more than r₁ records per side and exhibit more than k₁ sign changes in every chosen order when one panel uses distinct reserved points. These statements are conditional on linear SAT. They still leave open whether every program can be refuted within the allowed budget on infinitely many of these inputs.

## Balancing each interval of an order

Exact counts give a stronger oscillation bound on the same near-linear scale as the number of altered records. In addition to the adaptive panels, always require product agreement at r distinct fixed reserved points, with r=⌊B/nᵃ⌋ for a sufficiently large constant. Choose a fixed polynomial number of orders of the complete stamped records, each with a poly(n)-time injective code of poly(n) bits. After the play, guess at most r−1 increasing cut keys per order. They divide the ordered alphabet into at most r intervals. In each interval require the two logs to have the same number of records, at most L=⌈K/r⌉. Every genuine log can supply such cuts by grouping its keys in sorted order into consecutive groups of at most L. Every complete event is distinct on a genuine run because its stamp includes the time and within-step slot. Cut keys at the first entry of each new group suffice. The cuts may depend on the witnessing pair, but are common to the two logs.

These checks preserve the native clock. In the chunk proof guess, along with the existing summaries, each chunk's integer counts in all the intervals. The global fold checks their sums and caps. After the selected chunk records have been fixed, one universal check chooses an interval and recomputes its count by scanning those records. All additional summaries fit O(Jr poly(n)) bits, and one check costs C poly(n). Increasing the fixed exponent a absorbs the unchanged form of the overhead. The same test also has a one-pass implementation with buffering: sort each buffer of r records by key, merge it with the sorted cut list and update the r counters sequentially. This takes B poly(n) tape time and r poly(n) space over the full stream.

After cancelling all common records, let e>r be the unmatched count per side, forced by the fixed reserved panel. Each interval still has equal unmatched mass of each sign. A nonempty one therefore has at least one internal sign change and at most L positive unmatched records. There must be at least ⌈e/L⌉ such intervals. Consequently the two false logs have matching prefix counts at every boundary, differ by at most L in cumulative mass at *every* prefix, and nevertheless change discrepancy sign at least Ω(r²/B)=Ω(B/n^{2a}) times along each chosen order. These properties hold on every terminal play, for one pair supporting all of its replies. No universal separator follows from this oscillation count: distinct large multisets can alternate signs repeatedly while keeping their prefix counts extremely close.

This narrows a route to excluding linear SAT. It suffices, at infinitely many lengths, to separate the candidate pairs for each name at this omitted word using the stated resources. The names may require different challenges. The remaining gap is a structural reason that the interpreter's false histories must give themselves away within that budget. A density lower bound on surviving errors by itself does not supply a separating challenge.
