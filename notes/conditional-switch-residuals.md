# What a SAT solver must carry between two sets of input pins

On a fixed 3-SAT input face whose selected verdict checks $y=Ax$, divide the live physical coordinates into the $x$ pins and the $y$ pins. In a computation giving that verdict, a *switch* occurs when successive live-bit observations come from different sides. At a switch, the memory and control state determine a Boolean function of the immutable input: would continuing from this state reach the selected verdict? Call its set of positive inputs the **residual**. Large differences between these residuals can arise even when the machine makes no writes on the entire remaining computation.

**Claim.** Write $p=\operatorname{rank}_2 A$, and let $R$ be the largest number of switches on a codeword. Some fixed alternating pattern with $r\le R$ switches occurs on a set of at least

$$\frac{2^p}{2(R+1)}$$

codewords whose ordered residual tuples are pairwise incomparable. Compare residuals by inclusion at a switch leaving the $x$ side and by reverse inclusion at a switch leaving the $y$ side; the choice of reversing all these orders gives the same incomparability statement. For a uniform random member of this set the sum of the successive conditional residual entropies, in bits, is at least $p-\log_2(2(R+1))$. This counts the new information in a residual given the actual preceding residuals. It does not multiply a physical memory width by the number of epochs.

## The physical input and the recognized relation

Let the two blocks have lengths $k$ and $l$, with $n=k+l$. Brehm, Ishai and Resch give an increasing sequence of binary systematic codes $C=\{(x,Ax):x\in\{0,1\}^k\}$ with rate tending to one half, linear-size binary linear encoders and primal and dual distances $\Omega(n)$. Fix successful encoder randomness at each of these lengths. The circuit is fixed in the checker clauses. The rank satisfies $p\ge\min(l,d_\perp-1)$: if $p<l$, some nonzero linear dependency among at most $p+1$ rows of $A$ supplies a dual codeword $(0,v)$. [Brehm, Ishai and Resch, Theorem 9](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ITC.2026.8)

Use the dense fixed-width 3-CNF layout with $M=\Theta(2^w)$ clauses of $3(w+1)$ bits, an $O(w)$-bit header and $2^w-1$ legal names. For any prescribed $s$ physical positions, a code of length $n\le c s/w$ from this sequence fits in distinct carrier records, for a sufficiently small constant $c$ and sufficiently large $s/w$. At arbitrary sizes the same claim with $p=\Theta(s/w)$ can use the graph of the identity of the required dimension; the two large-distance properties apply to the chosen good-code sequence. There are $\Omega(s/w)$ candidate records, and $s/w=O(M)$. A sign position selects the truth of a checker input via one unit constraint. A name bit selects one of two fresh complementary witness variables whose names differ at precisely that bit. At each bit significance there are $2^{w-1}-1$ disjoint legal name pairs available before exclusions. The other literals can use the fixed-false variable and all spare records can be tautologies. Gates, comparisons and carriers together use $O(n)$ clauses and names; fixed bit complements just orient the pins. The checker can assert either membership or nonmembership so that codewords give either chosen SAT verdict. All completed inputs are valid formulas. [Carrier construction](selected-input-rereads.md)

Fix any total correct deterministic solver. Ignore physical reads of fixed data when forming the color sequence. Expand each live word load into individual tests of its selected bits in a prescribed order; the word meets $O(1)$ live pins and the fixed intermediate controller stores partial replies. A cut can occur inside this expansion. Its residual includes this controller. Between tests, all physical data other than live bits are fixed, so the next selected test or halt is determined by the current controller and memory. A residual on a counterfactual immutable input means reachability of the designated halt from that state on that input. This definition also covers states reached only with another prefix: a continuation that never reaches the halt is outside the residual. There is no time truncation at the switch. All authentic computations under consideration do halt.

## Why the residuals are incomparable

Choose one codeword for each of the $2^p$ distinct outputs $Ax$. Each has distinct $x$ and distinct $y$. Group their selected-verdict paths according to the first side tested and their switch count. There are at most $2(R+1)$ groups. For the good code and for equality, every path giving the codeword verdict observes every live bit: flipping a single unread bit would leave the computation unchanged and leave the code. Both sides are therefore present. More generally $p>0$ suffices for both sides to occur, since every $y$ bit and at least one input bit (any nonzero column of $A$) must be observed on each codeword. Take the largest group. Its members have a common alternating list of colors, although the numbers of steps in their monochromatic blocks can differ.

For two members $a,b$, put $z=(a_x,b_y)$; all bits outside the face remain fixed. Use the recorded $x$-blocks of $a$ and $y$-blocks of $b$. **Each block starting at its own recorded state follows its recorded execution on $z$:** all the live bits it tests have the answers of that run, and all other input bits are fixed. This includes the first block from the common initial state and the last block through the designated halt.

Suppose the residual of $a$ contains that of $b$ at every switch leaving an $x$-block, and the residual of $b$ contains that of $a$ at every switch leaving a $y$-block. Work backwards. The last authentic block reaches the halt on $z$. At a switch, the inclusion transfers membership of $z$ from the next block's recorded entry residual to the preceding block's recorded exit residual. Following that preceding authentic block from its own entry now gives membership in its entry residual. Repeating reaches the actual initial state. The solver would give the codeword verdict on $z$, contrary to $Aa_x=a_y\ne b_y$. Interchanging $a,b$ excludes the reverse product inclusion. Thus the tuples form an antichain. Its uniform distribution has entropy equal to the logarithm of the number of selected members, since the tuples are distinct. The chain rule gives the displayed conditional-entropy bound.

The same argument permits conditioning on fixed outside data in a general splicing argument. Once a pair of coordinate sets, a coloring and outside bits have been fixed, restrict each residual to that input face; only the states at changes of color enter the proof. Whenever both cross combinations of two accepted inputs are forbidden, their corresponding restricted tuples are incomparable. Jukna's rectangle proof groups chosen accepting computations by equality of the full boundary-node tuples before splicing colored blocks. Its underlying test-count restriction is used to *find* two large sets with a common coloring. For the systematic graph above the sets are already prescribed, and the number of color switches appears explicitly in the conclusion. Priority of the residual formulation is unverified. [Jukna, Lemma 1 and Claims 1–2](https://web.vu.lt/mif/s.jukna/ftp/tradeoff-web.pdf) · [Jukna and Razborov on rereads](https://eccc.weizmann.ac.il/eccc-reports/1996/TR96-037/index.html)

## A fast example with zero suffix writes

On the graph itself, read $x$ once, compute and store $Ax$ by evaluating the fixed linear circuit, then read $y$ once in order and compare against the stored words. At the switch the residuals are exactly the distinct singleton suffix requirements $y=Ax$ (each allows every counterfactual $x$). There are $2^p$ such incomparable residuals. The entire comparison suffix makes zero writes to the work array and has a fixed index sequence. Scratch registers can be cleared after each successful comparison. The encoder is supplied as a topologically ordered gate list; the uniform RAM evaluator takes $O(n)$ word operations for any such $O(n)$-gate list and can receive the list as public data if desired. Choosing a good list for each length is nonuniform. The even simpler uniform equality predicate $y=x$ has the same one-switch behavior and $2^k$ residuals on two $k$-bit blocks.

Thus an actual SAT solver on this face with $R$ polynomial in the encoded length and $n\gg\log h$ must carry $\Omega(n)$ bits of total conditional residual information across its switches, where $h$ is the encoded length. With a single switch it must realize exponentially many different residuals at that switch. The direct graph recognition examples show why that requirement alone does not force superlinear time: an immutable table retained from the prefix can already determine all those distinct suffix functions.
