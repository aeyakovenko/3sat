# How often a short view of a real SAT run predicts the wrong answer

Consider a file claiming the results of a sequence of weighted rectangle queries. It has one satisfying assignment per incorrect claim. A deterministic RAM program can decide the file offline. Suppose instead we try to extract the *next truthful numerical answer* from the program's actual computation just before it loads that annotation. The following bound counts actual mistakes. The hard case is an ordinary honest file processed from its first instruction.

Let $n$ count operations in the weighted two-dimensional orthogonal range counting distribution of Weinstein and Yu, and write $L=\Theta(n\log n)$ for the encoded SAT bit length, $H=(\log n/\log\log n)^2$. Take the version with $u=n/(\log n)^2$ updates and $q=n-u$ original queries on an integral subsequence. Each update inserts a point in $[n]^2$ with a weight in $[n]$. Each query asks for the total weight of the points dominated by its coordinates. Draw the coordinates, weights and query points independently as in the source's §4. It is enough that all possible answers belong to $\{0,\ldots,n^2\}$. The schedule of operation types is public. For a final-update schedule, append a deterministic last query and its annotation to the SAT stream; the prediction bound counts only the original online queries. The last truth bit can still be physically changed to give a unique model. [Weinstein and Yu, Theorem 1 and §4](https://www.cs.princeton.edu/~hy2/files/2D-ORC.pdf) · [Compact ordinary DIMACS encoding and chronological conventions](weighted-range-transcript-encoding.md)

Fix any correct deterministic SAT solver $P$ on the aligned logarithmic-word RAM with the fixed word-width coefficient of the encoding. Deliver the logical input packets in order at the physical addresses of its first discoveries, keeping each packet on repeated reads. Complete every annotation with the true prior-update sum. This defines one actual immutable file per logical stream for the fixed solver. Every required fresh load occurs in finite time: before supplying the final annotation there are two ordinary completions, with its true value or with an incorrect value. Give the observer the view at a pending claim, **before** delivering that claim.

* The free part of the view contains the last $b=\lfloor\log n/(\log\log n)^3\rfloor$ query intervals of genuine native instruction records, including addresses, values, instruction pointers, register states and the elapsed native instruction counts. Mark the intermediate operation boundaries. Use the available prefix for early queries. Also supply the current update/query fields where applicable, size and logical stage.
* A deterministic observer fixed before the stream is drawn may then probe up to $d=\lfloor(\log n)^2/(\log\log n)^3\rfloor$ additional words adaptively in the earlier packet map, the prior chronological operations and truthful answers, or the frozen work array. Fresh unassigned positions have a known absence tag. Apart from its supplied view and these probes, its local computation may be arbitrary. It has no free persistent private store between queries. The observer and prediction rule must be fixed independently of the unknown stream.
* Write $Y_j$ for the true next number and $V_j$ for the resulting enriched view, including the observer's choices and replies. A prediction can use any fixed function of $j,V_j$. The numbers $Y_j$ are deterministic from the entire logical past. The view need not reveal that past.

There is an absolute constant $C$ such that the following holds, with $B_n=n/(\log n)^C$ at sufficiently large source scales. The exponent is not optimized. For **any fixed** clock factor $A$, except on a fraction $2^{-\Omega(B_n)}$ of the source streams, either the common truthful native prefix costs more than $A L$ steps or the fixed predictor makes at least
\[
                          \Omega\!\left(\frac{B_n}{\log n}\right)
                       =\frac{L}{(\log L)^{O(1)}}
\]
actual wrong predictions on it. At least this many divided by $b+1$ can have disjoint chronological observation windows, still $L/(\log L)^{O(1)}$. The two completed files differing in the final answer bit have the same measured execution through issue of that last load. There is no requirement that the last query be one of the mistaken predictions. The randomness here selects hard files; the solver itself is deterministic.

The proof also controls the information left unresolved by the actual views. If all truthful prefixes meet the linear cap, their conditional Shannon entropies, in bits, satisfy
\[
                          \sum_{j=1}^q {\mathsf H}(Y_j\mid V_j)\ \ge\ B_n .
\]
More generally the same bound is $B_n+\log_2 p$ on any fixed event of probability $p>0$ consisting entirely of fast truthful streams, using conditional entropies under that event. The summands are the uncertainty of separate answers given their respective views. They need not be independent, and their sum is not the elapsed time or joint entropy of a single machine state.

## From a tentative forecast to an online data structure

We use the distributional proof of Weinstein–Yu's small-success theorem, not merely a sequence-by-sequence worst-case statement. With $c=2$, cells of $\Theta(\log n)$ bits, and the public product distribution described above, its bound on the probability that all answers are correct and $o(nH)$ probes are made is at most $2^{-B_n}$, after taking an absolute $C$ large enough. This applies to a fallible algorithm as well. Their proof fixes the random tape against the same distribution and bounds the combined cheap-and-correct event. [Theorem 1, hard distribution and proof](https://arxiv.org/pdf/1604.03030)

Given a forecast $p_j(\cdot\mid V_j)$ on possible values, run the actual solver online using previously **emitted** numbers as the annotations. When the real query arrives, supply its physical packet, advance to the first discovery that will receive its annotation, obtain the prescribed view, and sample the forecast. Return that number to the online caller and use it as the next annotation. The real machine may not behave usefully after a bad prediction. If it halts prematurely, leaves the format, or exceeds a public polynomial cap on simulated steps, switch to a bounded fallback that continues emitting legal numbers. Along a fast path with no mistakes these cases never occur. Outside the fixed public operation format one may also switch to the fallback. No promise of correctness off the successful paths is needed in this small-success reduction.

Store the native work array, frozen exposed packets, chronological log, controller and round start offsets in persistent cells, charging all their accesses. Each native instruction yields $O(1)$ words of log. The extra bit-pin packets of one weighted update number $O(\log n)$, and their total is $O(u\log n)=O(n)$. All public formula cells can be generated by free local computation. Producing a window requires reading its logged records; each record is fetched at most $b$ times in the complete stream. On a truly fast, all-correct path the total probes are
\[
       O\big((b+1)(A L+n)+qd+n\log n\big)=o(nH).
\]
The terminal appended query needed for the formula can be omitted from the online procedure; it cannot increase its cost on the measured prefix. Allocate the simulator's cell width as a sufficiently large fixed multiple of $\log n$ to address its polynomial-size banks. Only the current operation may use uncharged transient scratch. These details allow an off-path computation to be wrong or slow without attributing its guesses or memory to the true execution.

Fix the whole logical source stream $x$. Conditional on having guessed every preceding answer correctly, the next view is *exactly* $V_j(x)$ on the truthful native run; a forecast can be sampled using fresh randomness. Therefore the probability of guessing all answers on this fixed stream is
\[
                              \prod_{j=1}^{q}p_j(Y_j(x)\mid V_j(x))
\]
on fast truthful streams. This remains valid when the instruction windows, additional probes and forecast depend on previous emitted answers. It makes no independence assumption about the answers themselves. Write $F$ for the event that the genuine common prefix obeys the linear cap and $Z=-\sum_j\log_2 p_j(Y_j\mid V_j)$, taking positive infinity if a true answer is assigned probability zero. The dynamic lower bound gives the fundamental inequality
\[
                        \mathbb E[\mathbf1_F 2^{-Z}]\le2^{-B_n}.                 \tag{2}
\]
Here and below the capped constants and source asymptotics are at sufficiently large admissible sizes.

## Mistakes, prediction lists and certification

For a deterministic predictor, use its guess with probability $1-1/n$, otherwise sample uniformly from the $n^2+1$ candidate numbers. If the truthful run has $e$ mistakes, the product above is at least $(1-1/n)^q[n(n^2+1)]^{-e}$. Thus every fast stream with $e\le B_n/(8\log_2(n^2+2))$, for example, contributes at least $2^{-B_n/2}$ for large $n$. Equation (2) bounds their fraction by $2^{-B_n/2}$. A competing description that predicts well in hindsight also costs something: take a union bound across any catalogue of at most $2^{B_n/4}$ fixed rules, each with the same width and probe budgets. On all but a $2^{-B_n/4}$ fraction of streams satisfying the alternative, a fast truthful run defeats **every** rule in that catalogue. In this last statement the exceptional mass is unconditional; dividing by the probability of a fast run yields the corresponding conditional estimate. No machine reads the entire catalogue or a long free input-dependent program during a query. Each candidate is a separate nonuniform local rule subject to the same source bound.

Individual answer bits admit a stronger mistake count. Put $\lambda=\lceil\log_2(n^2+1)\rceil$ and $m=q\lambda$. A fixed rule may predict the next bit using the same enriched view and all **earlier truthful bits of this answer word**. It receives no additional probes within a word. Take $r=\lfloor c B_n/\log\log n\rfloor$ for a sufficiently small constant $c>0$. The online algorithm independently reverses each tentative bit with probability $\alpha=r/m$, using the bits it has generated as the prefix for the next prediction. An illegal resulting word can be replaced by a fixed legal output. Whenever the truthful sequence has at most $r$ bit mistakes, reproducing it costs probability at least $(1-\alpha)^m\alpha^r$. The negative logarithm of this probability is $O(r[1+\log(m/r)])$. Since $m=O(n\log n)$ and $B_n=n/(\log n)^C$, this is at most $B_n/2$ for small enough $c$ and all large $n$. Applying (2) gives mass at most $2^{-B_n/2}$ to fast streams with at most $r$ bit mistakes. The $\Omega(B_n/\log\log n)$ bound counts bits across the words. Multiple mistakes may occur within one word.

A test for the proposed annotation can be phrased as a Boolean predicate $C_j(V_j,a)$ after the same candidate-independent view is obtained. At any site where it accepts exactly the true word, an observer with free computation can enumerate all $a$ and recover the correct number. Choose the unique accepted word whenever it exists and an arbitrary default otherwise. Every actual numerical prediction error for this rule marks a query where the test either rejects the truthful annotation or accepts some wrong word. The verifier is allowed arbitrary computation on the supplied annotation. Charging for additional probes separately for each of the $n^2+1$ hypothetical annotations would change the assertion.

For the entropy result take the forecast to be the actual conditional law of $Y_j$ given $V_j$ under the product input distribution. For the event version take the law conditioned also on the fixed event in question. These finite conditional distributions can be preassigned as nonuniform local functions before any input arrives. By (2), $\mathbb E[2^{-Z}\mid E]\le 2^{-B_n}/p$ for $E\subseteq F$ of mass $p$. Jensen's inequality gives $\mathbb E[Z\mid E]\ge B_n+\log_2 p$, with the left side equal to the sum of the claimed conditional entropies. Markov's inequality also bounds the conditional probability of $Z<B_n+\log_2p-t$ by $2^{-t}$. ## What remains on the unrestricted clock

This theorem predicts actual mistakes on a single fast run or forces its clock above a given linear cap. A correct SAT decision algorithm need only decide at the end whether every supplied number is right. It can read the claimed sums and verify them jointly. The theorem does not supply the additional implication that such batch verification would yield an online predictor with few mistakes. The recent-history condition is substantive, and the unrestricted linear, quadratic and cubic targets remain open. Unlike the Boolean disjointness result, this argument uses a word-valued stream and Weinstein and Yu's published small-success bound. The online reduction and entropy proof are manuscript arguments.
