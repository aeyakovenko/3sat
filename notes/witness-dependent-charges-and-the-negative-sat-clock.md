# Witness-dependent charges preserve the negative 3-SAT clock

There is a deterministic linear-time, linear-encoded-size reduction from arbitrary explicit DIMACS 3-SAT to the following family. A single connected graph carries a flow over the cyclic group of order six. Both the flow constraints by themselves and the source-assignment checks by themselves are feasible on every file. Each negative file nevertheless requires polynomial-calculus degree $\Omega(N/\log N)$ over every field simultaneously, total monomial size $2^{\Omega(N/\log N)}$, and real sum-of-squares degree $\Omega(N/\log N)$. Here $N$ is the length of the resulting proper 3-CNF. On these files, the necessary global charge condition is *exactly* the original SAT question. The time needed to reject just the negative files has the same linear, quadratic and cubic thresholds as deterministic decision on all explicit 3-SAT files.

## A simple graph generated within the encoded clock

Let $T_1,\ldots,T_4$ be the four positive Margulis–Gabber–Galil shear permutations on $U=(\mathbb Z/s\mathbb Z)^2$, with updates $x\gets x+2y$, $x\gets x+2y+1$, $y\gets y+2x$, $y\gets y+2x+1$, respectively. Together with their inverses their unnormalized adjacency has second eigenvalue at most $5\sqrt 2$. On $U\times\mathbb Z/13$ use the four permutations $(u,j)\mapsto(T_i u,j+i)$ and the vertical permutation $(u,j)\mapsto(u,j+5)$, together with their inverses. The ten distinct nonzero offsets make every neighborhood simple, including above loops or parallel edges of the original graph. Every neighbor takes constant word work to generate. [Margulis–Gabber–Galil spectral bound for these maps](https://isa-afp.org/browser_info/current/AFP/Expander_Graphs/Expander_Graphs_MGG.html) · [Gabber and Galil](https://doi.org/10.1016/0022-0000(81)90040-4)

On the subspace constant on each 13-point fiber the unnormalized adjacency is $A_U+2I$. Its nonconstant eigenvalues belong to $[-6,5\sqrt2+2]$. On its orthogonal complement the eight horizontal permutation terms have combined operator norm at most eight. The two vertical terms have norm at most $2\cos(\pi/13)$ there by the spectrum of the odd cycle. After division by ten this yields a uniform absolute spectral gap, and in particular connectedness. For a normalized nonprincipal norm $\rho<1$ and a vertex set of density $a>0$, Cauchy–Schwarz on the support of the walk applied to its indicator gives $|\Gamma(S)|/|S|\ge1/(a+\rho^2(1-a))\ge 1+(1-\rho^2)(1-a)$. This meets the vertex expansion conditions in both source proof bounds.

For a general input of length $n$, normalize and remove duplicate clauses. The canonical list template discussed below may keep its public order and names. A single compiler can select that case by checking its exact syntax, capping recognition at a sufficiently large fixed multiple of $n$ so all other inputs still fit the reduction clock. If $m$ distinct clauses remain, $m\log(m+1)=O(n)$ by fixed-alphabet counting. Tries suffice for the normalization in $O(n)$ time. Choose $s$ among powers of five, using the smallest one for which $t=13s^2\ge\max(m,n/\log_2(n+2))$. Then $t=\Theta(n/\log(n+2))$ asymptotically and $t\equiv1\pmod 6$. Assign each retained clause to a different vertex in a fixed order. [Native normalization and encoded-size accounting](two-permutations-and-the-explicit-sat-clock.md)

## The charge of the first failed clause

On a guessed assignment $x$, evaluate the truth of each input clause $C_i$. Maintain prefix bits saying that every preceding clause was true. At its vertex set $h_i$ to the conjunction of this prefix with the falsity of $C_i$. Set all unassigned vertices' $h$ bits to zero. This deterministic chain puts one unit at the first failed clause, or no units if $x$ satisfies the formula. An empty source clause is evaluated as false within this chain. An empty conjunction produces no charge.

Use one Boolean selector to choose $a\in\{2,3\}$. On each directed half-edge put a residue in $\mathbb Z/6$. Opposite residues must add to zero, and the outgoing sum at vertex $v$ must be $a h_v$. Use, for example, six one-hot bits per half-edge and bounded-fan-in Boolean gate definitions for local sums. Range and reversal constraints and each final vertex test involve only constant-size neighborhoods. Encode gates by their definitional CNFs, and use three fresh forced-false bits to pad short clauses after removing any repeated literals. The seven proper clauses forbidding the nonzero patterns on these three bits pin them jointly. Number names densely. There are $\Theta(t)$ variables and clauses, and the explicit dense proper 3-CNF has length $N=\Theta(t\log t)=\Theta(n)$. The lower size bound already follows from the distinct occurring names. Writing these indices and all local tests takes $O(n)$ native time.

The flow constraints admit the zero flow with all $h_v=0$. The assignment and prefix constraints are feasible for every $x$, on both verdicts. On their shared variables the sum of the required charges is zero exactly if $x$ satisfies every clause. A flow must have zero total by edge cancellation. When the total is zero here all individual charges are zero, so the zero flow is an extension. This proves the equivalence without a fixed inconsistent component, even if the algorithm is told every graph incidence, gate location, and prefix position.

## A fixed negative file over an arbitrary field

Fix any source assignment on a negative input and evaluate all prefix gates honestly. Exactly one $h_v$ equals one. Write $e$ for this vertex's indicator vector. Over characteristic different from two restrict $a=3$ and start with the ordinary mod-two Tseitin system with all vertex charges one on the same graph. Over characteristic two restrict $a=2$ and start with the Boolean indicator mod-three Tseitin system with all charges one. Write $p$ for the source modulus in each case. The all-one source and the new charge pattern have equal total modulo $p$ since $t\equiv1\bmod 6$.

Choose fixed opposite half-edge shifts $\delta_{uv}=-\delta_{vu}$ in $\mathbb Z/p$ with outgoing sums $e_v-1$. They exist on any connected graph for any zero-total right-hand side, by fixing off-tree edges to zero and satisfying leaves successively on a spanning tree. Interpret a source half-edge label $z$ as the target residue $(6/p)(z+\delta_{uv})\bmod 6$. For $p=2$ the one edge bit represents both orientations. For $p=3$ use the source directed one-hot indicators. The map embeds the source group into the target. Satisfying a source reversal or vertex relation therefore makes its corresponding target check pass. The selector and payload are already fixed.

For PC degree transfer, on valid source indicator assignments use these edge bits and the honest evaluations of every target gate. Extend each local map to every Boolean pattern. For example, a malformed mod-three indicator triple can decode to zero. A target clause violation can then occur only if one of a fixed bounded set of source clauses for its local edge or vertex is violated. On the constant-size Boolean cube, for each violating input pattern take its point-indicator times one failed source clause's violation polynomial. Summing these terms with coefficients given by the target residual derives the substituted axiom modulo Boolean axioms in constant degree. The same argument applies to substituted Boolean axioms. Substitution simulates a degree-$D$ PC proof in degree $O(D+1)$ over the original field. The linear Tseitin degree bounds and the size–degree inequality now give degree $\Omega(t)$ and monomial size $2^{\Omega(t)}$ on the same file for all fields. For real SoS use $p=2$, the sign representation, and the same local multipliers modulo the sign-domain equations. Substitution preserves squares, giving degree $\Omega(t)$. The same restriction can be passed through the path-augmentation compiler. It yields explicit two-permutation files with a packing missing three points and a signed solution with one negative entry. The compiler's tentative local assignment simulates each exact-one axiom from the source CNF in constant degree over every field, including the row pair equations in characteristic two. The output has $\Theta(t)$ columns because the distinct graph-check variables and their clauses occur in the CNF. Thus the proof bounds and the native time equivalences also hold for this packing representation. On the canonical dense-list inputs one may directly use their public clause order and existing dense names. The same construction can accept these through a fixed template with its constant number of fresh wires per gate, without interning or deleting any clauses on this subfamily. Each variable digit in a clause evaluation is then just a copy of a digit from the original formula. All other emitted bits and the output length are fixed at each list parameter. This retains the list-based lower bound $\Omega(N(\log N)^\sigma)$ for Boolean decision circuits on this particular subfamily of charge-dependent CNFs. A RAM can check this template, reconstruct the list input and decide duplicates in $O(N)$ time. The arbitrary-payload threshold below quantifies over the larger family of outputs. ## Rejecting only the negative files

For $j=1,2,3$, suppose a fixed deterministic program signals rejection on every negative image in at most $C N^j$ steps, and never signals rejection on a positive image. Its off-image behavior and its eventual positive verdict are immaterial. On input $F$ generate the image, run this fixed program up to the stated deadline and return YES unless it signaled rejection. This decides every $F$ in $O(n^j)$ time on the same unrestricted-workspace RAM. The constant $C$ may be hardwired in this existence implication. Conversely, any $O(n^j)$ SAT decider supplies the promised rejecting program directly for the CNF images and through the linear-size reverse encoding for the packing images. The lower-bound question on this negative family is therefore equivalent to the corresponding unrestricted decision question.

There is a precise failure of an attempted charge-oracle lower bound. If an oracle on $x$ reveals only the total charge for fixed nonzero $a$, telling an unsatisfiable payload from one with a unique satisfying $v$-bit assignment can require all $2^v$ queries. Follow the all-nonzero transcript and leave any unqueried assignment as the possible unique solution. Unit clauses can express every such singleton. Appending a duplicate first unit on the singleton file and its opposite on the inconsistent file keeps their clause counts equal. In the actual files the literal signs expose that singleton or the conflict in linear time on these examples. The oracle argument establishes a cost for this specific loss of information. Proving a lower bound for operations on the explicit clauses remains the missing step.
