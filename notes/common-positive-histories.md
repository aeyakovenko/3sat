# A common family of hard positive SAT computations under changes of presentation

Fix $k=2$ or $3$ and assume a correct deterministic $O(N^k)$ SAT algorithm on the packed logarithmic-word RAM. There is a computable, strictly increasing sequence of positive source lengths $n_j$ with the following property. For each length the construction below gives ordinary satisfiable 3-CNFs of the same encoded bit length $N=N(n_j)$. They include $2^{\Omega(N)}$ distinct encodings obtained by choosing the actual binary variable names independently within prescribed ranges.

Consider any fixed deterministic RAM monitor with a sound affirmative signal on explicit formulas. Fix a constant $C$ and allow the monitor $T=\lceil C N^k\rceil$ steps. For all sufficiently large $j$ and **every** presentation at that length, if it signals by $T$, the following bounded-fan-in circuit sizes are necessary, up to divisors that are fixed powers of $\log N$.

| Actual table on this one physical formula | Lower bound up to logarithms |
| --- | --- |
| Time index to the program counter, registers and status | $N^{1/k^2}$ |
| Same table augmented by the most recent preceding write time at every work-memory load, or an initialization marker | $N^{1/k}$ |
| Variable index to a satisfying assignment, in the version with anchored names | $N^{1/k}$ for every satisfying assignment |

The history stops at the first affirmative signal and idles through $T$. A circuit takes its index alone, and can be different for every presentation. The RAM uses the ordinary load/store convention in which addresses and written values come from registers and a load deposits its result in a designated register. A fused instruction with hidden memory operands requires including those native events in the observed table. Registers have a fixed logarithmic word-width coefficient and the same polynomial-bit-complexity instruction basis as in the packed reduction. A correct quadratic or cubic SAT decision algorithm is among the monitors, with a positive signal on every satisfiable formula. The sequence need not be efficiently selectable. ## Certifying existence of a presentation from the reads

Let $D>k^2+2$ be a fixed integer, $R=n^D$ and $L=\lceil\log_2(n+2)\rceil$. Choose a unary language in nondeterministic multitape time $O(R)$ outside nondeterministic time $O(R/L)$. This is the unary case of Seiferas–Fischer–Meyer, using the identity counting function and $(2n)^D/\log(2n)=o(n^D)$. Compile its fixed acceptor into 3-CNF as in the positive-witness construction. At each $n$ the result has $\Theta(R\log^3 R)$ bits after regular padding. From $n$, an index, and the fixed templates one can compute a literal field or individual bit in $\operatorname{poly}(L)$ steps. The tape is initialized with $1^n$, which can be read by index using $n$. The reduction works at both positive and negative lengths. [Unary reduction and tape simulation](positive-witness-hierarchy.md) · [Seiferas, Fischer and Meyer, Theorem 5](https://doi.org/10.1145/322047.322061)

First balance the number of appearing variables with the number of clause records. With $m$ original clause records, add $m$ tautologies, using a distinct fresh variable in each. Use contiguous lower and upper ranges for old and fresh names. There are $O(m)$ original variable slots in the regular construction, taking constant-factor padding when needed. The enlarged formula has $\Theta(m)$ distinct appearing variables, a polynomial-time-in-$L$ bit generator, and the same truth. Use one-based variable slots, and put $a=\lceil\log_2(Km+1)\rceil$ for a fixed integer $K$ large enough for all these positions, and use $h=a$. Introduce the fixed anchor name $(0,v,0^h)$ and the tagged name $(1,v,z_v)$ for each $a$-bit variable index $v$, where $z_v$ is an arbitrary binary string of length $h$. Replace occurrences in the logical clause list with the tagged names and append the two implications equating each tagged variable to its anchor, repeating a literal to enforce width three. Append them for every slot in a contiguous range so their indices can be computed directly. This gives $N=\Theta(m\log m)=\Theta(R\log^3 R)$ and $2^{\Omega(mh)}=2^{\Omega(N)}$ distinct explicit bit strings. The variable-number field has $1+a+h$ bits. The encoding permits unused variable numbers up to the declared polynomial bound. Every satisfying assignment restricts on $(0,v,0^h)$ to an assignment satisfying the original formula. Restricting its circuit costs only fixed input wires and constants.

Each bit of this new physical input has one of two descriptions computable from $(n,\text{bit index})$ in $\operatorname{poly}(L)$ time. It either has a fixed value or it is bit $j$ of the tag $z_v$. Consider any proposed controller history, which determines the immutable-input loads, their addresses, and their proposed returned words. Convert a load into individual observed bits, respecting the prescribed packing and terminal fill. The history is compatible with some **single** complete tag table exactly when all fixed observations match and no observations prescribe opposite values to one $(v,j)$. These are existentially detectable defects using one or two time/bit-offset choices. Conversely assign the prescribed bits, and assign unobserved bits zero. This completes a presentation consistent with every proposed response, even when the observed addresses are chosen adaptively. The test uses just the one or two conflicting observations. [Selector consistency in Lean](../lean/CommonTagObservations.lean)

The same check handles a separate presentation class made by independently swapping consecutive pairs of equal-width clause records in the original formula. A bit with possible values $d_0,d_1$ either is fixed, or determines the swap selector from the observed bit. Check conflicts across all observations, including observations straddling two records. Clause ordering preserves every assignment. These swaps and the variable-tag presentation are separate choices of format. One may also omit the anchors in the name construction. The history proof still works, but a satisfying assignment of the original formula can then be encoded as the last bits of the tags. The Boolean function returning the low bit of the physical variable index satisfies the resulting formula. This gives easy witnesses on some of the very same source lengths on which every timely sound monitor has a hard register history.

## Cost of checking an actual affirmative signal

Guess the code of a circuit of at most $s$ gates for the controller stream through $T$ and choose the appropriate check below. Time indices, gate addresses and source metadata have $O(L)$ bits, with constants allowed to depend on the fixed monitor. Check initialization, the terminal signal, and individual register transitions, using the proposed read replies as local transition data. The input test above certifies that all immutable reads come from one presentation. For a fixed compatible presentation, absence of any writable-memory defect forces the entire history to be its genuine run, by induction from zero work memory. Thus a successful test implies that some presentation actually receives an affirmative signal. On a negative source input every presentation is unsatisfiable, so soundness excludes success. If any genuine accepting history on any presentation has the proposed circuit size, the verifier can guess it and succeed.

* For the augmented stream a wrong last-writer pointer can be demonstrated by the load, the proposed producer, or an intervening write to the same address. Include incorrect values, bad indices and a previous write contradicting a claimed initialization. These and all input or control defects use a constant number of evaluations of the candidate and $\operatorname{poly}(L)$ index logic. One explicit SAT query tests existence of a defect. Materializing the Tseytin circuit and running the reference costs $(s+1)^k\operatorname{poly}(L)$ total time including the cost of guessing the circuit.
* For the bare stream choose a load and an earlier conflicting store, or an incorrect value at a claimed first load from an initially zero cell. Deciding whether another same-address store occurred in the open interval uses a SAT query on the proposed controller circuit. A second SAT call compiles and decides the whole nondeterministic defect search, including that first solver execution. The cost is $(s+1)^{k^2}\operatorname{poly}(L)$. The additional two-observation input test has no interval search. [Bare and augmented history defect characterizations](chronological-solver-registers.md)
* Guess a circuit for a satisfying assignment to the *original* hierarchy formula. An existential SAT query chooses a possibly falsified clause, generates its fields and evaluates the three proposed bits. A negative answer certifies the whole assignment, at cost $(s+1)^k\operatorname{poly}(L)$. The anchors transfer this bound to every assignment of every tagged presentation. [Positive witness verifier](positive-witness-hierarchy.md)

For $\ell=1$ for the augmented or assignment test and $\ell=2$ for the bare test, cap $s$ by $\lfloor R^{1/k^\ell}/L^A\rfloor$. Use one sufficiently large integer $A$ for the fixed interpreter templates, reference exponent and RAM-to-tape simulation. Program texts and cutoff constants are fixed in each verifier below. Their sizes affect multiplicative constants. The powers of $L$ for instruction simulation, circuit generation, the two-observation input test and record sorting can be chosen uniformly over these fixed texts. On a nondeterministic tape simulate the bounded native verifier by guessing its chronological instruction trace, checking word operations, and sorting a copy of its access records by address and time. The overhead is a fixed power of $L$ plus $O(n\operatorname{poly}(L))$. With $A$ sufficiently large this gives time $O(R/L)$. Exceedingly small circuits or constant input templates are covered by additive $\operatorname{poly}(L)$ costs. Since $N=\Theta(R\log^3 R)$, these caps yield the displayed gate lower bounds up to fixed powers of $\log N$.

## Choosing one computable sequence for all sound monitors

For any **finite** menu of sound monitors with their cutoffs, a nondeterministic machine on $1^n$ chooses the monitor, format and proof type. It can also try the assignment verifier. The maximum of finitely many verified clocks still fits $O(R/L)$. On all negative inputs every test rejects. If on every sufficiently large positive input even *one* of these alternatives had a small valid circuit, the machine would recognize the unary language in its excluded bound, after hardwiring finitely many exceptions. Hence there are infinitely many positive $n$ at which every test for this entire menu fails. The existential input-completion test is what simultaneously quantifies over all presentations at those lengths.

Enumerate finite machine texts, their fixed integer word-width coefficients and integer clock multipliers. For an arbitrary fixed real multiplier use the next integer clock. Given a small timely circuit at the shorter clock, clamping its time input to the old endpoint extends it with the same idle state at a cost of $O(\log N)$ gates. Dovetail over increasing source lengths and finite computations to select stage $j$. Find an $n>n_{j-1}$ which is positive and satisfies the assignment hardness tests. For each of the first $j$ clocked programs require either a finite example of an affirmative signal on an unsatisfiable input within its declared cutoff, or absence of a cheap accepting history in all the indicated formats at this $n$. All finite predicates are decidable by exhaustive search, including satisfiability, actual history up to the clock, exact finite circuit testing, and the quantified finite list of presentations. Repeatedly search larger counterexample and length bounds together. The unsound members have finite counterexamples and the sound members satisfy the finite-menu argument, so the search terminates at every stage. Every sound monitor eventually occurs in every menu and can never take the counterexample alternative. This constructs the asserted computable sequence without an effective enumeration of the semantically sound programs. The same sequence handles each integer cutoff multiplier of each sound program.

The older common-seed result gives high-probability statements at each large scale on both verdicts. Here the positive source lengths can be sparse. The lower bounds hold at every presentation at the selected lengths, including variable names with arbitrarily complex tag tables. A solver can afford these register histories in quadratic or cubic time. The history circuit sees only its time index. It has no free oracle for the physical input.
