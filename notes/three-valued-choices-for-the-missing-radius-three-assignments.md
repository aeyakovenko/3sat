# The cost of all one-control edits around a radius-two SAT slice

Let $H(s,z)$ be a width-at-most-three CNF on control bits $s$ and data bits $z$. Suppose $H(0,z)$ holds whenever $z$ has Hamming weight at most two. Let $h$ count the distinct weight-three data vectors it rejects and let $p$ count the distinct coordinates appearing in their supports. Write $N$ for the encoded bit length and $w=\Theta(\log N)$ for the RAM word width.

* For one fixed setting of the controls, the remaining question reduces to binary constraints on $h$ three-valued choices. A deterministic solver takes $O(N(1+h/w)+h^2+1.3645^h)$ time, and hence linear time when $h\le\log_{1.3645}N+O(1)$.
* The reverse construction represents every binary constraint problem on $h$ three-valued variables by a one-bit edit. The dormant data-model set is exactly a product of $h$ copies of the seven permitted three-bit patterns. It is the same set for every constraint list with that number of variables.
* All $g$ single-control edits can be answered together in $O(N+g)$ deterministic time if $p(p+1)/2\le\lfloor\log_2 N\rfloor$. This allows arbitrarily many edits on one stored body. Every control queried is explicitly designated or occurs in the input.

These statements combine the [earlier physical edit construction](affine-insertion-at-a-clause-of-an-ordinary-3cnf.md) with a shared computation on implication graphs. They are algorithms and reductions on specified families. Priority for their combination is unestablished.

## What a rejected triple specifies

Discard tautologies and shorten repeated literals. A nontautological clause on data alone can exclude a data assignment whose weight is the number of its negative literals, by setting just those coordinates to one. Consequently each surviving data-only clause has three distinct negative data literals. It excludes exactly one point on the weight-three shell. Conversely, a clause that mentions a control and still imposes a nontautological constraint at $s=0$ would reject a data assignment of weight at most two. Thus the dormant slice consists precisely of the anti-monotone constraints
$$
\bigwedge_{T\in\mathcal T}\bigvee_{i\in T}\neg z_i,
$$
where $\mathcal T$ is the family of $h$ rejected supports. At any other setting the clauses mentioning controls contribute a 2-CNF $B$. It may include an empty clause. A radix trie on the decimal spellings assigns dense indices to occurring variables in deterministic linear physical time. Sorting the triples on the three dense indices by counting sort, after ordering the three indices in each triple, removes duplicate clauses in the same bound.

## The three-valued problem

Check $B$ by its implication graph first. If $B$ is satisfiable, a list of literals extends to a model of $B$ precisely when there is no implication path from a selected literal to the complement of a selected literal, allowing the two selections to coincide. To prove sufficiency, fix all literals reachable from the selected ones true. If reachable literals include $u$ and $\neg u$, contraposition of the path from a selected literal to $\neg u$ gives a path from $u$ to the complement of that selection. Thus the fixed set is consistent. Fix its complements false. These fixes satisfy all clauses touching a fixed variable or leave their other literal forced true by forward closure. Any model of $B$ on the remaining variables completes the assignment. Necessity follows from implication along a path. [Aspvall, Plass and Tarjan on 2-SAT](https://collaborate.princeton.edu/en/publications/a-linear-time-algorithm-for-testing-the-truth-of-certain-quantifi/)

Each support $T$ contributes one three-valued variable. Its values specify which one of the three negative literals to set true. Rule out an individually impossible value, and rule out two values whose literals are incompatible by implication. There are $O(h^2)$ pairs. All selections together extend iff every selected value and pair is permitted. A satisfying assignment to $B$ and the $h$ triples supplies such selections, and an extendible selection satisfies every triple.

To construct the conflicts, condense the implication graph into its directed acyclic graph of strongly connected components. Mark the components containing positive terminals $z_i$, for the $p\le3h$ indices in the supports. In reverse topological order, take the union of each component's marked terminals and those reachable from its successors. Use word-sized batches of at most $w$ terminals. One pass over the graph per batch costs $O(N(1+p/w))$ and uses linear temporary storage per pass. A row for the component of $\neg z_i$ gives the conflicts with all queried terminals. Reachability at the same index denotes an unavailable value. If two values are individually feasible, the pair is incompatible precisely when one reaches the opposite of the other. For one-hot queries below we retain exactly the path relation including its diagonal.

The resulting instance is a $(3,2)$-CSP. Eppstein gives a deterministic $O(1.3645^h)$ algorithm for arbitrary binary constraints on $h$ variables with domains of size at most three. This yields the first bound. The trivial enumeration has base three. Simple pair tests alone do not yield Eppstein's base. The linear regime above uses a constant number of propagation passes and costs $O(h^2)=O(\log^2 N)$ to write the finite constraints. [Eppstein, *Improved Algorithms for 3-Coloring, 3-Edge-Coloring, and Constraint Satisfaction*](https://ics.uci.edu/~eppstein/pubs/Epp-SODA-01.pdf)

## An arbitrary constraint list with the same dormant product

Give variable $i$ three private data bits $p_{ia}$, one for each value $a$. Put the clause $\neg p_{i0}\lor\neg p_{i1}\lor\neg p_{i2}$ in the body. The zero bits of that triple designate available choices. Add $\neg b\lor p_{ia}\lor p_{jc}$ for every incompatible pair, so both choices cannot be zero together when $b=1$. Unary restrictions can be expressed as guarded units. For a unique zero per triple in the active slice, include the analogous guarded constraints on distinct values of the same variable. Every solution of the constraint instance gives a model with just its chosen bits zero, and conversely any active model supplies a legal choice in every group. At $b=0$ the data bit patterns range independently over $\{0,1\}^3\setminus\{111\}$ in every group. For $h>0$ the radius-three shell therefore contains exactly $h$ missing points and they have pairwise disjoint supports.

The data names can be made by extending a canonical decimal variable identifier by a single digit. Printing one clause per forbidden pair and a constant number per explicit choice variable costs linear time and encoded length when the input lists those variables and constraints. Domain size three is fixed. For an instance with an implicit huge range of unused variables, discard the unused indices when only satisfiability is wanted. Units, short clauses and the switch between $b$ and its complement can use the constant false-anchor and one-physical-bit wrapper of the earlier construction. A graph 3-coloring instance is the special case that each edge forbids equal colors. This reverse direction also shows why a template can retain hard processing in binary constraints even when the easy slice is a known Cartesian product. The familiar duality between bounded clause width and domain size is used in Eppstein's paper.

## Computing every one-hot answer together

A nontautological clause mentioning controls contains at least one negated control; otherwise it would violate the dormant promise. After literal deduplication, a clause containing two different negative controls stays satisfied at every one-hot setting. If its sole negative control is $\neg s_j$, it can impose a residual binary, unary, or empty clause only in case $j$. Thus all residual lists $B_j$ can be formed in total $O(N+g)$ time. The triples $\mathcal T$ are stored once.

Index the $p$ data coordinates in the supports and write $q=p(p+1)/2$. For a satisfiable $B_j$ form the symmetric conflict matrix $M_j$ with the $(i,k)$ bit set exactly when $\neg z_i$ reaches $z_k$. Contraposition makes the matrix symmetric. A diagonal bit forbids selecting that coordinate. Selecting a subset $S$ of coordinates to be zero is feasible iff $M_j$ has no bit on a pair from $S$, allowing a repeated coordinate. The selection satisfies all old triples iff it meets each $T\in\mathcal T$.

When $q\le\lfloor\log_2 N\rfloor$, process every $B_j$ separately by one SCC and one marked-terminal pass with $p$ bits per component. A local adjacency list and a touched-variable list restrict the cost to the clauses present in that group. A terminal variable absent from $B_j$ has an all-zero conflict row. Only touched terminal indices need to contribute rows to the packed triangular matrix. For row $i$ a right shift discards columns below $i$ and a left shift puts the remaining bits at the precomputed offset for that row. Thus this phase costs $O(N+g)$ across the groups even when many groups mention few data variables. Unsatisfiable groups return no immediately.

For completeness, the shared lookup table can be constructed in $O(N)$ at the displayed threshold. Enumerate the $2^p$ subsets $S$. Whenever $S$ meets every triple, mark the $q$-bit index complementary to the set of all pairs from $S$. The satisfying matrix indices are precisely the downward closure of the marked indices. Checking all triples, producing the mask and marking it costs $O(2^p\operatorname{poly}(p))=O(1+2^q)$, since the number of distinct triples is at most $\binom p3$ and $q$ grows quadratically in $p$.

Store the Boolean table in blocks of $W$ bits, where $W$ is the largest power of two at most $w$. For each of the $q$ index coordinates, copy true entries from the 1 side to the corresponding entries on the 0 side by OR. A low coordinate uses a masked right shift inside every block. A high coordinate ORs matching blocks. These $q$ passes take $O(q\lceil2^q/W\rceil)$ operations. The masks can be constructed in $\operatorname{poly}(w)$ operations, within $O(N)$ for standard logarithmic width. Since $q\le\log_2 N$ and $w=\Theta(\log N)$ with enough bits for an input address, the table construction costs $O(N)$. After it, every group returns its indexed bit in constant time.

For a fixed $\mathcal T$, every symmetric path matrix really can occur: use the positive binary clause $z_i\lor z_k$ for each off-diagonal bit and the unit $z_i$ for each diagonal bit. The all-one assignment satisfies this base. In its implication graph positive literals have no outgoing edges, so the reachability matrix is exactly the one requested. The explicit table covers all these possibilities. This is a bound on that table construction, not a lower bound against other shared algorithms.
