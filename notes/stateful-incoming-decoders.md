# Predicting a SAT solver's incoming reads with persistent private memory

**Research journal, 24 November 2026.** A decoder starting at a checkpoint may keep and update its own work memory as the next segment unfolds. It can spend a long time preparing for several later replies. The following bounds charge its total instruction count on the genuine trajectory. They apply to the first reads of incoming work words by a deterministic solver on a logarithmic-word RAM. The solver's physical workspace is unrestricted.

* **Unconditional.** Fix a deterministic machine with a sound UNSAT signal that occurs on every unsatisfiable formula. Put $h=\lceil N^{0.97}\rceil$ for $N$ encoded input bits. At each time $t$ preceding the first signal, charge the least $1+s_t+e_t$ for an honest decoder row of $s_t$ bits whose work on each prefix of $\ell\le h$ native instructions is at most $e_t+\ell\log^{O(1)}N$. The polynomial logarithmic allowance is fixed in advance. The worst-case **sum** of these charges on unsatisfiable formulas lies outside $O(N^{1.3622})$.
* **Under deterministic near-linear SAT.** Fix such a two-sided solver running in $O(N\log^a N)$ and fix an online decoder. There is a family of actual rejecting runs, one at every sufficiently large source padding length, with the following property. Fix $0<\kappa<\gamma<1$ and $0\le\eta<1$. Put $w=\lceil N^\gamma\rceil$. At least $N^{1-\gamma}/\operatorname{polylog}N$ disjoint windows of $w$ consecutive pre-halt times consist entirely of starts at which **every** honest row of length at most $N^\kappa$ requires more than $N^\eta$ decoder steps over the next $2w$ native instructions or until halt. Thus at least $N/\operatorname{polylog}N$ different times have the stated obstruction. Windows and sufficiently large thresholds may depend on the three exponents.

## Online access and bounded replay

Fix one deterministic bounded-arity RAM decoder and a constant word-width coefficient. Each row can include additional program text interpreted by that decoder. The immutable data at a segment start are the formula, the row and its length, the start time and the forecast horizon. Private scratch starts blank and survives all calls within this segment. The decoder sees the chronological native controller and event history since the start, through the point immediately preceding a requested reply. It may do work while handling native events as well as upon a request. Initialization and all such instructions count. The forecast horizon stays fixed even if a verification cut ends the replay early. An honest row supplies the true word on the first read of each previously unseen work address, unless there has already been a local write there. Later reads use the local write or cached reply. Immutable input loads always use the formula. The definition stops at the signal or halt relevant to the theorem.

A chart gives increasing cuts, controllers and row payloads. Give each chosen block a single work cap $Q_i$ for all of its decoder activity. At an initial cut the guest starts at zero work memory and needs no decoder. In any later block the verifier simulates the guest and decoder together. It starts a fresh decoder workspace there, records the native events, preserves the decoder's writes within the block, and declares a timeout defect as soon as the next decoder instruction would exceed $Q_i$. Thus even an ill-formed row or a diverging decoder at a forged history has a bounded test. Native bookkeeping and scratch accesses cost constant or polylogarithmic time per simulated operation using the packed machine conventions. A live guest read can issue immediately after a long private computation in an earlier native round. Starting the decoder anew at that read would change its semantics.

On a true start, a true forecast, and a sufficient cap for this prefix, induction on native events reproduces both the true replies and the corresponding private trajectory. For a general chart, first challenge any timeout. Among completed blocks one can challenge a bad controller or final verdict, or an incoming read whose tentative word disagrees with the last preceding block write to its address. For the last test, guess a consumer and a producing block with a conflicting last write, or use zero initialization if the reply is nonzero. Certify that no strictly intervening block wrote the address. In a chart with no timeout, the canonical blocks are well defined. If they have no defect, chronological induction from initialization identifies the whole guest run. The private states in two adjacent blocks need no compatibility test because the interface permits a fresh decoder at each cut. Let $g$ be the longest gap, $Q=\max_i Q_i$, and $m$ the number of public words carrying the source input, chart and metadata. The deterministic cost of replaying any selected block is $\widetilde O(g+Q+1)$. Under near-linear SAT the whole chart's validity can be decided in $\widetilde O(m+g+Q+1)$ time. Use one explicit bounded-computation SAT call to decide whether some intervening block wrote the challenged address, then another for existence of a defect. Each call consults only constantly many selected blocks per branch. This charges the largest total private work for one selected block. Work on other starts or arbitrary addresses adds no term. ## Allowing expensive windows in a certificate

Use the locally generated SAT formula for a bounded universal source with padded input length $n_0$ and clock $H=n_0^2$. Its encoded length $N$ is $\Theta(H\log^3 H)$. The verifier guesses a chart, its horizon and integer resource bounds, and signals precisely upon certifying that the target rejects. The source formula on the verifier's own padded description would be satisfiable if it signaled before the interpreter deadline. Since any signal certifies actual rejection, this formula is unsatisfiable and no chart can be certified within $H$ interpreted steps. All real exponents in the window statement enter only into the analysis of honest charts. Header lengths, address domains and interpreter overheads follow the fixed packed reduction. [Complementary diagonal on the packed RAM](packed-band-transfer.md)

Partition the internal times before the actual first halt into full disjoint windows of $w$ and a final shorter suffix. Choose one cut in each full window. All gaps, including the initial and terminal gaps, are at most $2w$ with this convention. In a window containing a start with an honest $N^\kappa$-bit row and $N^\eta$ private steps, choose that start. Its true forecast covers the next cut. In **every remaining full window** use any start and supply a literal list of incoming read words in their true order up to the next cut. This fallback is a separate verifier mode. It advances an index on each new incoming read and lets the local cache handle repeats. Its payload and work cost $O((w+1)\log N)$ bits and $O(w+1)$ steps. Omitted or inconsistent words are detected on the canonical replay or its last-writer check. Guess all cuts before laying out these lists.

Write $J$ for the number of full windows requiring the fallback. There are $O(1+N\log^a N/w)$ cuts. Including all row data, the running time through a successful certification is bounded by
$$
 (n_0+1+N^{1-\gamma+\kappa}+Jw+w+N^\eta)\operatorname{polylog} N.
$$
The no-full-window case uses only the initial block and obeys the same bound. Except for $Jw$, each term costs $o(H)$ even after the fixed logarithmic factors. On the diagonal input a successful chart cannot fit within $H$, forcing $Jw=\Omega(N/\operatorname{polylog} N)$. Every one of the $J$ disjoint windows has exclusively expensive starts by its definition. A very costly decode on one window causes only one literal-list charge. The theorem would give a near-linear SAT contradiction if an independent argument forced $Jw$ below the resulting bound for every solver.

## The unconditional sum including delayed work

Let $E$ be the first sound negative signal time, $L=\max(2,\lceil\log_2(N+2)\rceil)$, and fix integers $p\ge0$, $K\ge1$. On an honest row let $B_t(\ell)$ count all decoder steps for the first $\ell$ native instructions of the forecast, including setup. Define
$$
 e_t=\max_{0\le\ell\le\min(h,E-t)}(B_t(\ell)-K\ell L^p)_+,
 \qquad C_h=\sum_{t<E}\min_{\text{honest rows}} (1+s_t+e_t).
$$
A missing honest row has infinite cost. The allowance applies to every prefix because the cuts selected by the verifier can occur before the end of the forecast. A bound at the far endpoint alone allows a large preprocessing computation before the first reply.

Suppose $C_h=O(N^c)$ on negatives with $c=6811/5000$. Then $E=O(N^c)$ there, giving the initial nondeterministic nonacceptance simulation of work and public-input exponents $(c,c)$. In a source of scale $H$ with local formula length between $H$ and $H\operatorname{polylog}H$, use windows of $\lceil H^x\rceil$ and choose a least-cost cut in every full internal window. The sum of selected charges is at most $C_h/\lceil H^x\rceil$. Therefore both total row bits and the largest selected $e_t$ are $H^{c-x+o(1)}$ up to additive constants. For honest rows, the longest selected prefix of at most $2\lceil H^x\rceil$ steps uses at most $H^{x+o(1)}+H^{c-x+o(1)}$ private steps. The chart can guess each integer $e_t$ in its metadata and use that value plus $K g_i L^p$ as the cap for its gap $g_i$. Testing claimed sizes and clocks can be done before interpreting them. No minimization or honesty oracle is part of the verifier.

Apply the [two-level nonacceptance recurrence](live-value-replay.md). With work exponents $u,v$ and widened public exponent $B$, the balanced cut is $x=Bc/(B+uv)$. The stage starts with $B\ge u^2$ and all its iterations have $v\le u$, so $x\ge c/2$. Consequently $c-x\le x$. Private replay with the additional charge fits the very same $H^{x+o(1)}$ clock at every stage. The earlier finite computation gives $x<0.97$ on all 103 iterations, so $2\lceil H^x\rceil\le h$ for sufficiently large $H$. Applying the inner nonacceptance simulation to the intervening-write test, and the outer one to the defect, produces work exponent $\max(xuv,(c-x)B)$ with public exponent $B$. Starting from $(c,c)$ the certificate ends at work exponent $0.992574225$ and public exponent $2.508263363$. On the bounded complementary diagonal with $m$ public words and source time $m^4$, both contributions are $o(m^4)$, a contradiction. Even if the actual solver takes only $O(N)$ time, the sum charges independently chosen descriptions and private forecast computations at overlapping starts. A generic literal row can require $O(h\log N)$ bits at a single start. The unconditional sum bound therefore permits linear-time runs. The new arguments allow mutation across all queries in a block, and the second theorem counts the cost of tolerating entire exceptional windows. ## Approximate online predictions with true feedback

The unconditional result also constrains decoders that can err. Fix the same negative signal, horizon $h=\lceil N^{0.97}\rceil$, prefix allowance $K\ell L^p$ and an arbitrary deterministic online **predictor**. Give its private state and row the genuine native history before each reply. At each distinct incoming address it predicts a word and a one-word tag. The subsequent native history contains the actual word. The predictor may separately retain its uncorrected guesses in private scratch. Each finite forecast starts anew at $t$, and may use its own hindsight row $Z$. Charge its true-feedback prefix burst $e_t$ as above, including initialization at prefix zero. A forecast that never returns a required prediction or fails to complete its prescribed work has infinite cost.

For each used tag $j$, count each distinct incoming address once. Group those keys by their **residual word**, the bitwise XOR of the predicted and genuine words. Let $J_t$ be the number of used tags and $u_t$ the total number of keys outside a most frequent residual class of their own tag. Ties may be broken arbitrarily. Both counts are zero if there are no keys. Define
$$
 U_h(F)=\sum_{t<E}\min_Z(1+|Z|+e_t+J_t+u_t).
$$
Then the worst-case $U_h$ on unsatisfiable formulas is **outside $O(N^{1.3622}/\log N)$**, unconditionally. This in particular holds for the larger charge replacing $u_t$ by $\sum_j M_{tj}H_0(R\mid j)$, where $M_{tj}$ is the key count in tag $j$ and the entropy uses the uniform measure on those keys. Every nonmodal key has a residual of conditional probability at most $1/2$, so it contributes at least one bit to that entropy sum. A fixed constant tag recovers the unconditional assertion for the unpartitioned residual entropy. No restriction on the range of possible tag words is needed.

To see the sharper count directly, store a sorted directory of the used tag words and one modal residual per tag. Store a second sorted directory of the exception keys, with the correction word for each. A record includes the tag and address and occupies constantly many words. A fixed wrapper can search both directories in $O(L)$ steps on a true forecast, returning the tag's default mask unless it finds an exception. Every true incoming address occurs only once per start, and there are at most constantly many per native instruction. Hence there are $O(h)$ keys and each directory index fits in $O(L)$ bits. The entire correction costs $O((1+J_t+u_t)L)$ bits, including fixed-size offsets and counts. Restricting this construction to polynomial-length base rows suffices under the allegedly cheap total bound. A packed view preserves random access to the original $Z$ without copying it during setup. The earlier trie construction gives a tighter entropy-dependent dictionary when additive logarithmic factors matter on a single grid. [Partial-domain correction structures](partial-domain-snapshot-errors.md)

Run the fixed predictor as a subroutine with its own registers and scratch, and XOR the recovered mask into the word delivered to the native replay. Keep the predictor's raw output available to its private computation. On every genuine prefix, the previous corrected words have produced the genuine native history, while the predictor has exactly its state in the true-feedback experiment. Its next tag and raw prediction therefore agree with the pair used to build the directories. Their correction supplies the genuine next word, proving the invariant by induction. Unseen tags, keys outside the genuine forecast, malformed offsets and nonterminating forged predictions are governed by deterministic defaults or the same block timeout as above. The argument needs no accuracy promise on these cases.

The wrapper can inline the fixed predictor with constant overhead per instruction, using disjoint scratch banks and a length-bounded view of the base row. Directory lookups add $O(L)$ work per actual incoming call and occur at most constantly many times per native instruction. Constant-size format setup and the length view therefore give a corrected prefix cost of at most $O(1+e_t)+K'\ell L^{p'}$ for fixed $K',p'$. In particular a long private initialization is charged once. On any input with polynomial total candidate charge the resulting honest rows give $C_h\le O(L U_h)$ for this one wrapper and fixed enlarged allowance. An $O(N^{1.3622}/L)$ bound on $U_h$ over negatives would therefore contradict the unconditional result above. This lower bound permits both many forecasts with cheap prefixes and substantial reuse of a single genuine read across overlapping horizons. The entropy and exception counts measure those forecasts, and do not add up to elapsed solver time.

On explicit guarded formulas a correct solver can incur $\Omega(Nh)$ in this cumulative exception charge during a $\Theta(N)$-time run. Forward-oracle counting accounts for scratch retained throughout the forecast and for the genuine answers revealed after every guess.
