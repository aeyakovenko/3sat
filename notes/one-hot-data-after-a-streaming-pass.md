# Exactly how many random reads can recover a one-hot SAT selector after a streaming pass?

There is a family of canonical DIMACS files in which the first editable part selects one site $i$ out of $D$ possibilities. A later part encodes an arbitrary query vector $y$ of $D$ bits. The SAT verdict is $y_i$. At fixed $y$ the files have the same byte histogram and any two differ in exactly two physical bits. Every variable occurs at most four times. Their common length is $N=\Theta(D\log(D+2))$ bits.

Suppose the prefix containing the active site leaves at most $S\ge1$ possible states. Give the subsequent reader the entire vector $y$, the layout and this state for free. The reader may inspect packed words at addresses of its choice. Computation, storage and offline tables cost nothing in the query count. For $D\ge1$, the optimal deterministic worst-case number of data-word probes is
$$
 \left\lfloor\frac{\lceil D/S\rceil}{2}\right\rfloor .
$$
The optimum allows choosing the prefix-state function. The lower bound applies even when this function is arbitrary, provided it receives no information about the later query $y$. For any given state function, there is also a single $y$ and a common complete bounded observation on at least $\lfloor\lceil D/S\rceil/2\rfloor-q$ files of **each** verdict after a total of $q$ probes. This last bound is informative when positive. The setup is related to the systematic cell-probe model, where the original data remain accessible alongside auxiliary information. [Gál and Miltersen](https://www.brics.dk/RS/03/44/index.html)

## Encoding on genuine SAT files

Introduce $D$ data switches $x_i$ and $D$ query switches $y_i$. Use the two proper clauses $(\neg x_i\lor y_i\lor z_i)$ and $(\neg x_i\lor y_i\lor\neg z_i)$ for each $i$, with a fresh $z_i$. These clauses impose exactly $x_i\Rightarrow y_i$. Use the journal's signed occurrence copies and physical selector rows, ordering all $D$ data rows before all $D$ query rows. A selector changes the last decimal digit of a name from ASCII 2 to ASCII 3. Its row stays in the same position under canonical sorting. Copy links and false-variable pins preserve the relation while keeping degree at most four. The layout has $O(D)$ clauses and names, is dense and duplicate-free, and permits the changing bytes to be placed in distinct native words simultaneously for any fixed finite list of logarithmic word-width coefficients. Its intervening filler clauses leave $\Omega(\log(D+2))$ bytes between successive selector digits for all sufficiently large $D$. [Physical layout and size proof](physical-selector-parity-cubes.md) · [Tovey's bounded-occurrence construction](https://cedric.cnam.fr/~bentzc/INITREC/Files/CB11.pdf)

Activate one $x_i$ and set the query switches according to $y$. Exactly one implication can fail, giving the stated SAT predicate. All data switches were originally digit 2. Activating any one of them adds the same byte to the histogram and removes the same byte from it. The all-off center at this fixed $y$ is satisfiable. The stopping point for counting prefix states is immediately before the first editable query digit. All input bytes up to that point depend only on $i$ and the public layout.

## An exact probe and error tradeoff

Partition the sites by their prefix state. In a group $G$ of size $g$ choose $y$ so that its two labels occur $\lfloor g/2\rfloor$ and $\lceil g/2\rceil$ times. Run the reader with this group's state, this $y$, and all **data** switches off. The supplied state can differ from the one that a real all-off prefix would produce. This auxiliary run supplies word addresses and replies. Each probe can inspect at most one private site. Every site of $G$ whose private word is never probed follows the same execution with that site active. This follows step by step from deterministic addressing. A write before a private word's original value is read removes that difference as well. One may stop the auxiliary run after the probe or time budget. As long as a candidate site is still unseen, its valid one-hot input reproduces the auxiliary computation up to the next probe. This justifies the argument even when the original guarantee on the budget is only for valid one-hot inputs.

At least $\lfloor g/2\rfloor-q$ sites of each label share the common trace after $q$ probes. Choose a largest group, which has $g\ge\lceil D/S\rceil$. In the opposite direction, partition the sites into at most $S$ groups of size at most $\lceil D/S\rceil$. Knowing the group and $y$, probe all sites of its less frequent label until the active site is found, or return the other label after all misses. The upper bound charges only probes and may use the precomputed site addresses and membership table. With $S\ge D$, recording the site itself suffices.

There is an exact tradeoff allowing errors. Let $E$ count wrongly classified one-hot sites at a fixed $y$. A deterministic algorithm with $S$ possible prefix states and $q$ probes can have **at most $E$ errors for every $y$** exactly when
$$
 D\le S(2q+1)+2E .
$$
Indeed choose $y$ balanced separately in every nonempty state group. A group of size $g$ contributes at least $\max(0,\lfloor g/2\rfloor-q)$ errors by its all-off path. Thus $g$ is at most $2q+1$ plus twice that group's error count. Summing proves necessity. If $D\le S(2q+1)$, use groups of size at most $2q+1$. Otherwise give $S-1$ groups size $2q+1$ and put all remaining sites in the last group. Query up to $q$ minority sites in each active group and default to its majority label. Only the last group can have errors. Its bound is $\lceil(D-S(2q+1))/2\rceil$. For a uniformly sampled site and adversarial $y$, divide the optimal error count by $D$ to obtain the optimal deterministic error probability.

## Fixed streaming summaries and growing checksum moduli

A finite list of deterministic left-to-right passes on the original file yields one prefix-state tuple with at most the product $S$ of its individual state counts. All retained information, including any observable control or timing at the cut, belongs to this tuple. The suffix at fixed $y$ is common, so all final streaming replies are fixed by the tuple and $y$. Run any list of subsequent adaptive readers from this information and a fresh work store, with joint budget $q$. Their observations concatenate into one trace. At fixed $S$, $q=o(N/\log N)$ leaves $\Omega(N/\log N)$ files of each verdict with identical observations. This covers every fixed finite collection of bounded-modulus rolling checksums and arbitrary additional bounded-state streaming tests. The exact final byte histogram may be given for free since it does not vary within the chosen family.

One can include **all** affine rolling hashes with a growing cutoff on their moduli. Put
$$
 \Lambda_B=\mathop{\mathrm{lcm}}_{2\le m\le B}\exp((\mathbb Z/m\mathbb Z)^\times).
$$
For the one-hot data digit at site $i$, let $e_i$ be the number of bytes after it and before the query cut. For a recurrence $z\gets uz+f(b)\pmod m$, its prefix digest differs from the common all-off prefix by $(f(3_{\rm ASCII})-f(2_{\rm ASCII}))u^{e_i}$. If $e_i\ge\lceil\log_2 B\rceil$ for all $i$, all prefix digests for every $m\le B$, base $u$, byte map $f$ and common initialization are determined jointly by $e_i\bmod\Lambda_B$ and the public layout. To see this, reduce modulo each prime power dividing $m$. Nonunit bases divisible by that prime have vanished by the indicated exponent. For units the order divides $\Lambda_B$. Common subsequent query bytes preserve every equality. [Rolling-period calculation](two-bit-switches-at-a-prescribed-stride.md)

Each prime-power unit group here has order at most $B$, so $\Lambda_B\mid\operatorname{lcm}(1,\ldots,B)<2^{4B}$. For any fixed $0<\alpha<1$ set $B=\lfloor\alpha\log_2 D/4\rfloor$. The physical gap ensures the exponent condition for all sufficiently large $D$. Together with a fixed finite streaming tuple of at most $S_0$ values, all these checksums have at most $S_0D^\alpha$ distinct prefix outcomes on this family. Consequently, even after $o(D^{1-\alpha})$ additional adaptive probes there are $\Omega(D^{1-\alpha})$ files of each verdict with identical joint results. The statement concerns the whole specified checksum family, regardless of how many of its members a decoder chooses to consult. [Elementary lcm estimate](checksum-collisions-on-actual-sat.md)

The [executable audit](../audits/one_hot_after_stream_audit.py) exhausts 4,536 partition/probe budgets over every query vector through $D=7$, checking the error formula and the zero-error optimum. On 18 literal 63,491-byte files with 3,132 variables and 3,672 clauses, it parses the serialized clauses, checks every positive witness assignment, verifies the negative outcomes with PicoSAT, and checks the compact word layout. Nine sites have the same prefix residue modulo seven. With one common query vector, two distinct adaptive word reads have an identical trace on four SAT and three UNSAT files in that group. The second address itself takes two different values on the group's runs. Each file is processed by the same readers.

The input order and bounded retained state matter. The unrestricted RAM may store the selected site's identity in a logarithmic-size word. Its ability to keep that information throughout the computation leaves the unrestricted SAT time question open. The exact finite model, its physical realization and the growing joint checksum conclusion are manuscript arguments. Historical priority for their combination has not been established.
