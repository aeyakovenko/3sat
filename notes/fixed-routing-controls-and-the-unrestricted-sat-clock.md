# A fixed switch network with the same unrestricted SAT time thresholds

For each power of two $t\ge1$, take $R=4t$ one-bit lanes. A string of $\Theta(t\log(2t))$ independent control bits specifies a satisfiability problem. Every bit pattern is legal. There is one wiring diagram for each $t$. Both translations between these strings and ordinary explicit ASCII 3-SAT use deterministic $O(n)$ time on a logarithmic-word RAM and produce $O(n)$ bits, where $n$ is the length of the *source* in each translation. Consequently this one total control function has precisely the same $O(n)$, $O(n^2)$ and $O(n^3)$ decision questions as explicit 3-SAT, without a space restriction.

The usefulness for exhaustion is that the input consists solely of independently editable bits. At the next size two arbitrary settings embed as independent children, and the new answer is their conjunction. The transformation preserves the semantics for every old setting. To obtain a running-time lower bound one still needs to force the *best unrestricted execution* to grow, with the deadline measured against the length of the larger string.

## The control function

The unknown assignment starts as $R$ bits on the left. One control per consecutive pair optionally enforces equality. A Beneš network sends the bits to the right, without complementing, broadcasting or dropping any bit. Every switch has a public straight/cross bit. Number right positions $4j,4j+1,4j+2,4j+3$ for $0\le j<t$. The first is a public variable port, optionally pinned to zero by its own control. The other three form a clause with independently controlled signs and an enable bit. Ignore disabled clauses. Acceptance means some left assignment satisfies every enabled condition.

For $R=2$, the network has one switch. At a larger power of two, pair $i$ with $i+R/2$ in the first and last layers and put independent copies of the half-size network between them. Its switch count is $(R/2)(2\log_2 R-1)$. To route a specified permutation, make a bipartite multigraph of input pairs and output pairs, with one edge for each lane destination. Each vertex has degree two. Alternately color every even cycle, including the two-edge parallel cycles. Route one color to each half and recurse on the resulting half-size permutations. This sets the controls in $O(R\log R)$ deterministic word operations. Conversely, sending an array of $R$ word-sized labels through any settings reconstructs their permutation in the same time. The switch network and the construction of its controls are classical. [Nassimi and Sahni on Beneš setup](https://www.cise.ufl.edu/~sahni/papers/BenesNetwork.pdf)

If an encoding defined on strings of all lengths is wanted, take the prescribed concatenation of fields in a fixed recursive order, recover the dimension from the length, and reject lengths outside the sequence. Trying successive powers of two costs polylogarithmic time and changes none of the stated clocks.

## Two linear-time translations

From an ASCII file of $n$ bits, intern the names of occurring variables and normalize and deduplicate clauses. If there are $m$ distinct retained proper clauses, $m\log(2+m)=O(n+1)$ by counting strings over the finite input alphabet. The number of occurring names is at most $3m$. Fixed-alphabet tries give $O(n)$ work even for very large decimal names, long whitespace or many duplicate clauses. For nonproper clauses delete tautologies when only decision is required, duplicate a literal to fill a short nonempty clause, and handle an empty clause with a fixed negative output for decision. If designated ports are requested on an input with an empty clause, instead retain all original names and introduce a fresh contradictory pair of unit clauses. The same construction below then supplies the designated ports. To preserve models on all *occurring* variables also keep every original name as a port, including names appearing only in tautologies. The number $v$ of distinct names itself satisfies $v\log(2+v)=O(n+1)$ by their writing costs. [Encoded DIMACS normalization](dense-sorted-cores-for-ram-exhaustion.md)

Choose the least power of two $t\ge\max(1,v,m)$. Give each source variable its own public port, and set the optional pin on every unused port. Label each clause occurrence slot by its variable and each public port by its own index. Fill unused clause slots with arbitrary existing port labels and disable those clauses. Sort the $4t$ labeled slots by label, breaking ties by right index. Put the slots in this sorted order on the left, enable equality exactly inside each label group, and set the switch network to restore the desired order on the right. Program the clause signs and enables. Every label has a port. Hence each satisfying assignment to the occurring source variables has exactly one extension to all left lanes and all internal wire values, including when a source clause is tautological. Additional future unit pins on named source variables can be attached to the corresponding ports. On a fixed source incidence pattern with fixed clause order, changing any literal polarity changes just its clause sign control if the compiler retains that source layout. This one-sign guarantee has the stated linear size whenever the retained layout has $m\log(2+m)=O(n+1)$, in particular for distinct proper source clauses. On highly repetitive files the linear decision translation can deduplicate first, and an edit to only one original duplicate can require new controls. A header declaring exponentially many unmentioned variables is relevant to model counting only under a different convention.

Sorting integer pairs and setting the permutation cost $O(t\log(2t))=O(n+1)$ steps. Writing the actual bit controls costs at most the same. There is no oracle for the routing permutation.

Conversely, scan the equality controls to give each left lane the number of its contiguous equality group. Route these integer labels forward through the given switch settings. Each right port now names an ordinary Boolean variable. Output the enabled three-literal clauses with their decoded labels and the enabled negative port pins. Simplify repeated names, remove tautologies, and pad short clauses with distinct false bits forced by a fixed proper three-variable gadget. This yields a proper DIMACS file of $O(t\log(2t))$ bits in $O(t\log(2t))$ steps on **every** setting, including ones where multiple public ports coincide and a variable has no public port. A group represents a single free bit, so this elimination preserves the decision in both directions. The reverse compiler eliminates the switches before serializing. Physically serializing each switch as a separate clause gadget costs an extra logarithm in **bits**.

Fixed universal factor graphs have established precedents. Feige and Jozeph's Lemma 1 uses $O(m\log m\log v)$ variables via a sorting network acting on binary names. Valiant's edge-universal circuit construction has $O(s\log s)$ size for bounded-degree circuits. The construction here routes single unknown **values** after computing switch settings from known names. Its claimed features are the explicit two-way native clock for the packed controls, decision on arbitrary control strings, and the physical cost of preserving pin queries. No priority is claimed for universal circuits or rearrangeable switches. [Feige and Jozeph, Lemma 1 and Appendix B](https://arxiv.org/abs/1204.6484) · [Valiant, Universal circuits](https://doi.org/10.1145/800113.803649)

## What doubling preserves

Given two arbitrary settings at $t$, place their switch bits in the two recursive subnetworks at $2t$. Set both new outer layers straight. Copy the two equality arrays on the corresponding halves and set the new equality edge crossing their boundary to zero. Concatenate the public pin, sign and enable fields in cell order. No new constraint crosses between children. Satisfying assignments are exactly ordered pairs of child assignments. This is a bit projection with fixed padding, also when the two child settings are identical. Freezing one satisfiable child embeds the original decision function. Two recursive copies increase the input length by a factor $2+O(1/\log(2t))$.

Here is an explicit test against inferring extra time from this identity. Repeatedly double any one positive setting with a fixed negative sibling at the first step and arbitrary siblings thereafter, always using the embedding. The growing formulas keep a known, entirely local reason to reject. More generally a fixed globally correct decider can recognize any specified constant-size negative child separated along such a known nesting path, check the required outer-layer and boundary controls, and reject before a complete SAT computation. It can do this in $O(n)$ time on the certified branch by scanning the relevant fixed fields. Repeated copies of one positive seed with straight outer layers also have a linear-time syntactic recognition path. The identity provides independent inputs for a lower-bound induction, but does not prove one.
