# Which gate relations admit every clause repair at the same boundary?

Suppose a successor construction inserts a CNF gadget in a verifier for a RAM step. One proposed induction would pick a single inconsistent tuple of incoming and outgoing values, keep that tuple fixed, and repair the gadget after the adversary removes any one of its clauses. This requirement determines exactly which relations the gadget can represent, even with arbitrarily many existential auxiliary variables. [Lean proof of the projection theorem](../lean/PinnedClauseRepairs.lean)

**Classification.** Let $H(x,z)$ be a finite CNF, with named Boolean ports $x$ and private variables $z$. Number its physical clauses, counting repeated clauses separately. Let $R(x)=\exists z\,H(x,z)$. Assume $R(u)=0$ and that for each clause $D$ there is an assignment $z_D$ satisfying $(H-D)(u,z_D)$. Then $R$ equals the single disjunction of **all port literals occurring anywhere in $H$**. Its rejecting set fixes every occurring port to its value at $u$ and leaves every unused port free. Conversely every non-tautological clause has such an implementation, including the empty clause.

**Proof.** Every port literal is false at $u$. If a port literal of $D$ were true, the witness for $H-D$ would satisfy $D$ as well, contradicting rejection. Thus all occurrences of each port have one polarity. Now take any $v$ satisfying a port literal of $D$. Reuse $z_D$. At $u$, every other clause had to be satisfied by an auxiliary literal, so it is still satisfied at $v$. The chosen port literal satisfies $D$. If $v$ satisfies no port literal, the two residual CNFs on $z$ at $u$ and $v$ agree clause by clause and hence both reject. For the converse use the clause itself and pin all its literals false. The same argument handles a formula with no occurring ports.

**A quantitative test for partial repairs.** Suppose clauses have width at most $k>0$. Call a clause exceptional at $u$ if deleting it still leaves $H(u,\cdot)$ unsatisfiable. Let $J$ contain each globally relevant port $j$ satisfying at least one of these conditions.

1. $R(u^{\oplus j})=0$, where $u^{\oplus j}$ flips just $j$.
2. $R$ is non-unate in $j$, meaning that for some settings of the other ports changing $j$ from zero to one enables the relation, and for other settings it disables the relation.

Then there are at least $\lceil |J|/k\rceil$ exceptional clauses. For condition 1, suppose all occurrences of $j$ lay in repairable clauses. Every one of these occurrences must be false at $u$ by the first step of the proof. Flip $j$ and use the repair for a clause containing it. That clause becomes true and no previously true literal elsewhere becomes false. This contradicts the assumed rejection of the neighbor. Global relevance ensures an occurrence exists. For condition 2, existential projection of a CNF in which $j$ has only one polarity is monotone in the corresponding direction. Thus both signs occur, and a clause containing the sign that is true at $u$ is automatically exceptional. Each exceptional clause contains at most $k$ different ports, which proves the count.

For instance every exact width-three encoding of parity on $d\ge2$ ports has at least $\lceil d/3\rceil$ exceptional physical clauses at **every** rejected boundary. Every single-bit neighbor of such a boundary passes parity, so counting those neighbors alone would miss this conclusion. Even without a width limit, equality of two bits, the graph of a binary AND gate, and parity on two or more bits have rejecting sets that are not subcubes. None supports an induction requiring every row deletion to be repaired at one fixed false tuple.

## How many different rejected boundaries suffice?

Let $S$ be a nonempty set of rejected boundary tuples. Say that $S$ covers the deletions of an encoding when each physical clause $D$ can be deleted and the remainder satisfied at *some* $u_D\in S$. The auxiliary assignment can also depend on $D$. A proper 3-CNF encoding of $R$ with this property exists if and only if the following holds for every globally relevant port $j$ which is fixed to a bit $b_j$ throughout $S$.

1. Changing port $j$ from $b_j$ to $1-b_j$ preserves acceptance whenever the other bits are held fixed.
2. At some $u\in S$, changing port $j$ gives an accepted neighbor.

For necessity, a clause containing a port literal true at $x_j=b_j$ remains true at every proposed repair. Deleting this clause cannot permit any of those rejected tuples. Consequently all occurrences of $j$ have the opposite sign, which proves condition 1. By global relevance, some row contains $j$. Choose the repair for deleting that row and flip $j$ at its boundary. The row becomes true and the flip preserves all previously true literals. This proves condition 2.

For sufficiency, omit irrelevant coordinates and start with a CNF for $R$ on fresh internal copies $y$ of the relevant ports. For each port varying on $S$, bind its external value to $y_j$ with two binary clauses. Leave the external copies of the fixed ports outside this CNF for now. Split and pad to proper width three with fresh variables. Each resulting source clause contains at most one external port. Use the Papadimitriou–Wolfe transformation as given in Burjons et al., §2.2.1–2.2.4 with selector set $Q$. Its all-zero selector mode checks the source formula on precisely the supplied values. With exactly one selected source clause the corresponding gadget is contradictory, and with two or more selectors the pair prohibition fails. For each fixed relevant port append the single clause
$$
  [x_j=1-b_j]\ \lor\ [y_j=b_j]\ \lor\ \bigvee_{q\in Q}q.
$$
In an intact satisfying formula the selectors must all be zero. A fixed port given value $b_j$ then forces $y_j=b_j$, while a fixed port given value $1-b_j$ allows either internal value. By applying condition 1 one coordinate at a time, a satisfying internal tuple implies acceptance of the external tuple. Conversely choosing $y=x$ witnesses every accepted tuple.

For a deletion of a pair prohibition, the published repair sets two selectors and leaves the source variables free. For a deletion associated with a source clause $C_i$, it sets one selector and prescribes literals only on $C_i$. It sets either all of them false or just one of them true. Every appended binding is automatically true in these repairs. Since $C_i$ has at most one external port and that port varies on $S$, choose a member of $S$ matching the prescribed bit. All external ports can now be set to that tuple. For deletion of the appended binding for $j$, use a tuple $u$ from condition 2, zero selectors, and internal tuple $y=u^{\oplus j}$. The core accepts this internal tuple and every surviving binding is satisfied at $x=u$. These cases exhaust the physical clauses before width reduction.

The output widths can also be reduced with the same boundary assignments. The standard chain splitting a wide disjunction into ternary clauses has an extension after any one chain row is removed, even when all disjuncts are false: choose the chain variables to propagate a true demand up to that row and a false demand after it. All intact chains extend a true source clause. Padding a short clause by enumerating the sign patterns of fresh padding variables works after a row deletion by choosing the unique pattern that falsifies the missing padding disjunction. These operations preserve the projection and the deletion cover, as in §2.2.5–2.2.6 of the same paper. The size of this existence proof is unrestricted. [Burjons et al., construction and repairs](https://doi.org/10.1007/s00453-023-01204-1)

In particular, for a relation non-unate in every coordinate the criterion says exactly that both bit values must occur in every coordinate of $S$. Two exact values follow.

- For parity on even $d\ge2$, two complementary rejected boundaries suffice and one cannot. For odd $d\ge3$, two tuples varying in every coordinate would have to be complements and therefore have opposite parity. Three suffice. Take the rejecting parity class to be even by translating one coordinate if necessary. The three tuples $0^d$, $1^{d-1}0$, and $0^{d-2}11$ contain both bit values at each coordinate.
- For the relation on $d\ge2$ bits that rejects exactly the vectors of weight one, the minimum is $d$. The relation is non-unate in every port. Each unit vector is the only rejected input with a one in its coordinate, so all $d$ must occur. This attains the largest possible minimum among relations non-unate in all $d$ coordinates. Indeed the whole rejected set varies in each coordinate by non-unateness. In an inclusion-minimal subfamily still varying in every coordinate, each selected tuple supplies the sole occurrence of some coordinate value. If the subfamily has size at least three, distinct selected tuples need distinct coordinates. Its size is therefore at most $d$.

When the boundary values may change with the deletion, Burjons, Frei, Hemaspaandra, Komm and Wehner give a reduction to proper 3-CNF with an efficiently computable witness after each deletion. The journal also gives such a reduction of linear encoded size. The classification explains exactly why carrying the *same* false gate tuple through all row deletions is a stronger requirement. A successor proof that permits communication between gadgets or changes the interface values can evade the classification. The result does not estimate the running time of a SAT decision algorithm. Priority for the classification and width estimate has not been established.
