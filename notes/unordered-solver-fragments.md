# Checking unordered RAM fragments with three quantifier blocks

A deterministic native computation can certify its verdict through fragments listed in an arbitrary order. Even a path travelled backwards in the certificate is admissible, provided its forward execution is genuine. This gives a bounded-alternation alternative to counting endpoint parities of a succinct list. In particular, it charges the length of an index into the list rather than the number of fragments, and it does not require a circuit for finding the matching occurrence of a state. [Verdict-basin parity for actual solver runs](three-bank-solver-phases.md)

Fix a deterministic SAT solver $A$ and a fixed endpoint decoder. On a particular $N$-bit input $F$, a shared $h$-bit string describes up to $2^u$ fragment slots. For a $u$-bit index the decoder supplies an active tag, two endpoints and any native controller fields. An ordinary endpoint represents *all* writable words by allowing a query at any bounded native address. Each query, including tags and controller fields, has a specified $Q$-step budget. The formula and the shared string are available as random-access read-only inputs. Decoder failures and timeouts use fixed defaults; check formats or mask fields to the prescribed native widths. Permit only well-formed start controllers. The special endpoint $\dagger$ denotes hitting a halt of the claimed verdict, and may be used only as the end of a native fragment. A fragment must run forward from its indicated start to its end in at most $B$ native steps. The slots require no timestamps, common order or restricted input scopes.

Add one formal pair $(\text{initial},\dagger)$ to the list of endpoints. Its role is solely to specify the required boundary. Require each active endpoint occurrence, including these two, to have *exactly one* other occurrence naming the same full state. Thus every multiplicity in the augmented list is either zero or two. Soundness follows by marking exactly the states whose future deterministic runs halt with the claimed verdict, and marking $\dagger$. Every genuine native fragment has two equal marks. All marks in the augmented list cancel in pairs, forcing the initial state's mark to be one. Extra disconnected pairs of paths and components are harmless. Following matching endpoints need not follow increasing native time.

An actual halting computation has no repeated full prehalt configuration. A repetition would make it loop deterministically before reaching its first halt. Thus any partition into nonempty phases before first halt, replacing its final endpoint by $\dagger$, has this exact multiplicity property. The internal states appear twice, and the initial state and sink appear exactly once each before augmentation. An immediate halt is covered by the sole initial-to-sink fragment. The proof also allows fragments starting outside the actual trajectory. To be useful those states must still have efficient full-word representations and genuine local transitions. ## Every actual instruction occurs an odd number of times

Expand each locally verified fragment into its forward native steps, including the final formal move from a correctly labelled halt to the sink if needed. Omit the extra formal pair used only for the endpoint condition. Consider the true states $v_0,\ldots,v_E$ of the run up to its first halt. For $t<E$ mark the set $S_t$ of configurations whose future reaches $v_t$, including $v_t$ itself. The initial state is marked and the sink is unmarked. No native edge enters $S_t$ from outside. Its only outgoing edge is $v_t\to v_{t+1}$, since the halted true trajectory never returns to $v_t$. A macroedge changes the mark exactly when its expansion traverses this unique edge. XOR the endpoint marks of all certified fragments. The formal pair requires parity one. Hence **the actual native step $v_t\to v_{t+1}$ occurs an odd number of times** across the expansions, even if the certificate uses off-trajectory configurations and extra components. This holds already for general even multiplicities and an arbitrary valid choice of fragment durations.

Consequently, for every true prehalt time, this same certificate contains a fragment that can replay the exact snapshot there. A separate $u$-bit slot index and a $\lceil\log_2(B+1)\rceil$-bit offset, together with the header and budget parameters, suffice for a fixed decoder. Replay from the indicated start as far as the supplied offset and return the requested word. This takes $\widetilde O((B+1)(Q+1))$ time. The index and offset can depend on the time and the input. The argument gives no fast way to find them. Off-trajectory proofs therefore still impose structure on the true execution. ## The verifier

For fixed $F$, decoder, header and budgets the following conditions have a combined $\forall\exists\forall$ test with the stated workspace-free cost. A public outer selector chooses one condition; pad shorter conditions by dummy messages.

1. For every active slot there **exists one duration** $0\le t\le B$ such that for every address the endpoint matches the replay at time $t$. A native work read first consults a per-replay write dictionary, then the start endpoint decoder. Verify the target controller and the one challenged memory word. For a sink endpoint check a halt of the specified verdict, allowing halts to stutter. A single chosen duration must work for all addresses. Replaying a separate duration for each address would be unsound.
2. For every active endpoint occurrence there exists a different active occurrence such that **every** state field agrees. Fields range over the sink tag, controller and all legal writable addresses. The prescribed initial state and the formal sink have public encodings.
3. For every triple of distinct active occurrences there exists a field at which the three returned values are not all equal. Together with the preceding condition this excludes odd multiplicities greater than one as well as multiplicities above two. In particular, three copies of one endpoint cannot present themselves as three locally matched occurrences.

All index and address lengths, including the special formal-pair tags, are checked. The total per-branch cost, apart from reading the public original input, is $\widetilde O(h+u+(B+1)(Q+1))$ when these budgets are polynomially bounded in $N$. A $u$-bit index can itself be a string rather than a native word; the alternating branch writes or reads it as such. A bounded number of indices and constant many decoder calls per simulated access suffice. The helper passes each index as a view, without copying its $u$ bits at each decoder query. An initially empty native work dictionary implements the replay using tagged addresses in the simulated polynomial address space. No time for enumerating $2^u$ slots appears. For unrestricted multiplicities a direct parity test of the list is much stronger: include the same one-step edge on exactly those indices satisfying an input Boolean circuit and use inactive slots elsewhere. The parity at its endpoints then equals the parity of that circuit's number of models. The exact-two check exploits simplicity of a genuine halting run. ## The consequence for the explicit hierarchy inputs

Suppose a reference deterministic SAT solver runs in $O(N^d)$ time, $d\in\{1,2,3\}$. The target solver $A$ above can be any correct deterministic solver, independently of its time or space. At every sufficiently large source padding length there is an unsatisfiable explicit 3-CNF of length $N$ for which *every* unordered fragment certificate of rejection for the given endpoint decoder satisfies
$$
 h+u+(B+1)(Q+1) > N^{1/d^3}/\operatorname{polylog}N .
$$
The fixed log power can depend on the chosen programs and exponent. At $d=1$ this reaches $N/\operatorname{polylog}N$. At $d=2,3$ the respective numerator exponents are $1/8,1/27$. The bound also rules out a succinct, locally consistent set of auxiliary detours with small resources. Nothing in the proof forces such a description to exist for a fast RAM.

Use the journal's signed universal machine on an $n_0$-bit padded program, with clock $H=n_0^D$ for a fixed integer $D>d^3$. Its bounded acceptance is an explicit fixed-layout $F_x$ of length $H\operatorname{polylog}H$ with locally generatable words from the real input $x$. The local generator costs $\operatorname{polylog}H$ per physical $F_x$ read, including those made by the endpoint decoder. This avoids materializing the initial hierarchy formula. On fixed guessed header and budgets set $M=n_0+h+u+(B+1)(Q+1)+\operatorname{polylog}H$. The three-block test has matrix time $M\operatorname{polylog}H$ and each message fits that budget. Starting at the innermost block, compile a bounded existential RAM computation (or the complement for a universal block) to SAT in quasilinear size and time, run the reference solver, and repeat. This decides the test in $M^{d^3}\operatorname{polylog}H$ deterministic time. The number of compilations is exactly three. Original strings $x$, the header and the current fixed messages are copied only within this bound. The input and SAT workspace of every intermediate invocation are polynomially addressable as in the journal's signed simulation. The opponent guessed by the outer hierarchy machine chooses the header and the binary budgets on one nondeterministic branch. Limit $h+u+(B+1)(Q+1)$ to $H^{1/d^3}/(\log H)^K$, rounding down using integer powers, with a sufficiently large fixed $K$. The branch signals precisely when the deterministic verification passes. On inputs containing this opponent's own description, occurrence of such a signal within $H$ native interpreter steps would make $F_x$ satisfiable. The same signal proves $A$ rejects $F_x$, contradicting its correctness. Thus there is no signal and $F_x$ is unsatisfiable. A valid certificate within budget would finish and signal within $H$ for all sufficiently large padded lengths, since $n_0=o(H^{1/d^3}/(\log H)^K)$ and the log power absorbs interpretation and the fixed three compilation overheads. This proves the assertion. Source arithmetic and budget comparisons can equivalently cap $M^{d^3}(\log H)^{K d^3}$ before running the verifier, so rounded nonintegral roots incur no assumption about real-number computation.
