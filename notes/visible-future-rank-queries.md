# How far ahead must an offline bit-write-once algorithm read?

A program receives the entire array of future query colors at initialization. It can inspect any entry at any time, retain working storage, and preprocess before returning a single answer. Consider chronological prefix-rank queries for a sequence of $H$ public increment colors, with $w=\Theta(\log H)$-bit words and a polynomial-size alphabet. With bit-write-once working memory and a constant number of ordinary registers, constant amortized time forces the program to read almost all of the independently variable query fields early on some inputs. This result deals with actual probes made by an offline algorithm. [Online rank reduction and SAT encoding](persisting-monotone-rank-queries.md)

## The workload and the tradeoff

Partition a public query schedule into panels of $d$ answers each. A panel takes place at one event prefix. The first $d-1$ queries have fixed public colors and the final query has a private color in a word-aligned input field. Here “private” means variable across the family. The whole array of those fields is readable from the start. Repeated occurrences in public formula layouts may instead alias the corresponding input field. Touching any encoding word revealing its bits counts as a read of the field. All other input data, free initial indexes, and supplied tables depend only on the increment sequence and the schedule. Any preprocessing of the actual query array by the algorithm costs time and its probes count.

Use a sequential output operation for the specified answer at each position. A panel begins at the preceding panel's final output, with the first panel beginning at initialization. Intervening work belongs to the next panel, so elapsed panel costs are disjoint. No wall-clock deadline is needed for an individual answer. The finite computation must emit the correct full sequence in order for every query array. An output buffer available as working storage obeys the same storage rules as the rest of the algorithm. A target is *early* if its field is read strictly before the beginning of its own panel. At least $d-1$ intervening answers then separate the probe from the target's answer. The first panel cannot be early.

Take public $B=H(\log H)^{O(1)}\ge dH$ and $1\le d\le(\log H)^{O(1)}$. Each run has $Q\in[B,2B]$ query positions. Let total work be at most $FQ$ and suppose the fraction of early targets is at most $u$ uniformly over the inputs and calendars. With pure bit-write-once addressable memory,
$$
                          Fd=\Omega((1-u)\log\log H).
$$
More generally, if each run makes at most $R\le H$ downward work-memory bit changes, multiply the left side by the historical lookup cost $p$ from the [reset tradeoff](bit-resets-and-advice-in-online-rank.md). In particular $p=O_\epsilon(1)$ whenever $R\le H^{1-\epsilon}$.

With bounded amortized work and $d=1$, some workload must have at least a $1-O(1/\log\log H)$ fraction of its variable colors read before their panels. One can instead take $d=\lfloor\sqrt{\log\log H}\rfloor$ for large $H$. Then some workload has at least a $1-O(1/\sqrt{\log\log H})$ fraction of its variable fields read early, with $d-1$ intervening answers. In the latter statement only one of every $d$ queries has an independently variable color. For fixed $H$, maxima over the finite input and schedule choices attain these fractions.

## Extending a partially specified real input

Freeze a public increment string and construct a static index for arbitrary rank queries. Take a round with unresolved event prefixes $J$. Preschedule $q=\lceil B/(d|J|)\rceil$ panels at each such prefix, and none elsewhere. The quota makes $Q=dq|J|$ lie between $B$ and $2B$. Choose any calendar-dependent static table before varying the private fields. Fix a legal default color and call its encoding zero. Begin with every future field provisionally set to that color. During the actual canonical run, a read of a yet-undetermined future field binds it permanently to zero. The final colored array will therefore be consistent with every earlier observation.

At the beginning of a panel whose private field has not been bound early, try every proposed color $s$ in that field, using the fixed past and zero for all subsequent fields. These trials occur on the static encoder's private copies of the state. They have no effect on the canonical run. Since the field has never been read and other previous observations are preserved, each completion reproduces exactly the saved state and all previously emitted answers.

If all such trials finish the panel within $K$ steps, record the pre-panel state as a representative for its event prefix. Otherwise choose one expensive color as the actual input for this panel. Continue the chosen execution, binding to zero only the future fields actually probed along it. At a previously exposed panel the private field remains zero. Once a prefix has a representative, fill its remaining quota legally. At the end there is one ordinary complete input producing precisely the selected canonical trace. This argument allows indirect probes, branches depending on earlier future probes, and arbitrary use of blank memory. Previously returned answers depend only on the chronological prefix they refer to.

Every panel at an unresolved prefix was either already exposed or cost more than $K$. For $u<1$ set $K=\lceil 2Fd/(1-u)\rceil$. The exposed panels number at most $u q|J|$ on the actual completed input. The costly panels number at most $FQ/K$. Consequently the next unresolved fraction is at most $(1+u)/2$. Fresh prescheduled runs of this form cover all prefixes in $O(1+\log H/(1-u))$ rounds. When $Fd/(1-u)>\log\log H$ the pure-memory claim already holds arithmetically. In the complementary case the number of rounds is polylogarithmic, so the persisted static representation still fits $Hw^{O(1)}$ bits. The same case split works with $p\ge1$.

The arbitrary static query $(s,j)$ uses the saved state at prefix $j$. Before the current private field, provide the canonical past array. At that field provide $s$, and afterwards give zeros. A direct comparison of the field index suffices irrespective of which future words the trial reads. The program completes the panel within $K$ steps, and its final output gives the desired static rank. Historical memory can be queried with $O(p)$ probes per simulated step, including any probes used by precomputation. The static lower bound is $\Omega(\log\log H)$, proving the tradeoff. The same argument applies to the yes/no parity queries via the colored-predecessor reduction, whose public prefix transformation can give several static cuts the same event index. ## When an early read leaves no information at the boundary

There is a second version which allows early probes to be discarded. For a fixed final query array $x$ and panel $i$, keep $x_{<i}$ and use the public default for every later private field while varying this panel’s color $s$. Record the entire writable state, CPU and interface state, and elapsed clock when panel $i$ begins. Call the prefix sensitive if two choices of $s$ give different records. For the extension to a budget $R$ on bit resets, also record the cumulative reset count at that boundary. This quantity is well defined for every prefix independently of later choices. A physical read that leaves the same state and clock for every candidate need not be charged.

The same tradeoff holds with $u$ the uniform fraction of these sensitive prefixes. Here the encoder recomputes the boundary records under all candidates on their respective complete default-tail inputs. At a sensitive panel keep the current color at its default and charge the panel. At an insensitive one all candidates share exactly the same boundary state and elapsed time. Test panel costs and choose a representative or a costly candidate as before. After saving a representative use the default color for that panel, and subsequent panels at an already resolved prefix may also use defaults.

Persist one trajectory built from the **selected segments**. At the start of each panel its state and timestamp coincide with the genuine execution on the partial array completed by defaults. This holds initially. At an insensitive panel changing the current field preserves the genuine opening record. At every other panel it stays at the default. Extending by the genuine segment from that record gives the claimed identity at the next boundary. Thus at the end the total number of steps equals that on the final actual input. Every stored segment individually uses bit-write-once transitions from the previous segment's true final state, so the entire assembled word histories are bit-write-once. For the reset variant the cumulative counter telescopes in the same manner. Some internal states from the chosen segments may differ from intermediate states on the final array. Persistence only requires a path of physical word changes and a genuine starting state for each trial. At a saved panel that state is genuine on *every* queried current color with that fixed past and default future. The static index therefore returns the correct answer. The panel count applies on the final array since earlier sensitivity depends only on its prefix.

One can state either exposure theorem as a same-input disjunction. Let $F_x$ be work divided by $Q$ and $u_x$ the corresponding exposed fraction on an actual completed input $x$. If every run satisfied $F_xd/(1-u_x)\le\lambda$, choose $K=\lceil4\lambda\rceil$. In each round the unresolved fraction is at most $u_x+F_xd/K\le1-(1-u_x)/2$. Each panel costs at least one output operation, so $1-u_x\ge1/\lambda$ under this hypothesis. The number of rounds is $O(1+\lambda\log H)$ and is polylogarithmic in the only nontrivial case $\lambda=O(\log\log H)$. The resulting static query costs $O(\lambda)$ probes on pure bit-write-once memory. Hence some input either has every target exposed or satisfies $F_xd/(1-u_x)=\Omega(\log\log H)$. For the semantic version, $u_x$ refers to comparisons of genuine runs on related inputs with the same past and a default tail. It does not assert that changing a field while holding the actual later colors fixed will change the state.

A checksum illustrates a limitation and a refinement of this definition. An initial scan can XOR the colors into a retained register, even if the program never uses it. Every current color may then affect that register on the default-tail comparison. In the pure bit-write-once version one can exempt this and other cheaply reproducible controller differences. Fix a lookup procedure with $O(1)$ static probes and an allowance of $w^{O(1)}$ bits of auxiliary information at each saved panel. Charge a panel unless both conditions below hold.

* For every current color, addressable memory at the opening is identical. The opening times have spread at most a specified integer $h$.
* One allowed auxiliary string lets the lookup procedure on the current color produce its true opening controller, including the visible clock if permitted. The procedure is fixed for all panels and inputs. The saved default controller can be part of its string.

At an uncharged panel use the corrected registers for the chosen segment. Registers may change freely at the joins since only the addressable array is persisted. At a saved boundary store the auxiliary string for random-access lookup and use the recorded physical memory image. There are only $H$ saved panels across the calendars, so the total extra static space is near-linear. The encoder may use unbounded work to find strings during the canonical construction, including at unsaved panels. The assembled elapsed work can now exceed the final actual work. On changing the default color to $s_i$, the excess increases by the default opening time minus the true opening time for $s_i$, which is at most $h$. All other panels retain their default when their condition fails. Across $Q/d$ panels the assembled work is therefore at most $FQ+hQ/d$. Replacing $Fd$ by $Fd+h$ in the uniform-fraction proof gives $Fd+h=\Omega((1-u)\log\log H)$. The timestamp used to access an assembled memory history is its physical position along that path. The corrected guest may observe its own true elapsed time. Fixed-time XOR checksums in registers have short correction rules, since changing one original field XORs its difference into the checksum. Arbitrarily encoded color-dependent memory changes or controller differences need not satisfy the two conditions.

The complete offline workload admits unrestricted-word-memory algorithms that maintain one mutable count per color and read each query at its own position. It also admits offline reordering by query color if one first reads the variable fields. A single ordinary SAT solver sees the whole formula, pays for its actual computation, and owes only one final bit. The lower bound above identifies a specific way full input access can help when trying to replay a sequence of SAT decisions. It leaves the unrestricted time bounds for one SAT instance open. Priority for the prefetch tradeoff is unverified.
