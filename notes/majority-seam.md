# An exact limit for separately chosen states at a RAM checkpoint

**Research journal, 24 November 2026.** Suppose a verifier compares adjacent RAM segments by challenging their common checkpoint with a few functions of memory. Each side may supply a new full state consistent with the answers in that challenge. A two-segment deterministic linear-time computation gives a sharp obstruction. With $n=2m-1$ live bits, every challenge whose answers exclude the wrong verdict needs total Boolean polynomial degree at least $m$. All lower-budget projected views can agree exactly, even at a fixed public input.

## A computation with a fixed input and a fixed final state

Copy the $n$ public input bits $x$ into $n$ writable cells, one bit per word. This is the first segment. Starting with its controller in a fixed state, the second segment scans these cells, sums their bits, clears them, and returns one iff the count is at least $m$. Clear its scratch registers and leave only the verdict and the known terminal controller. A count fits in one logarithmic word. The loop uses a fixed sequence of addresses and takes $O(n)$ instructions, including bit extraction from a packed input. Both verdicts can use the same number of instructions. The second segment never rereads the public input.

Fix the entire input $x$ and claim the *opposite* verdict. The true first segment ends with $x$ at the checkpoint. Starting the second segment from any bit vector $z$ of opposite majority, with the same controller, produces the claimed terminal state, including the cleared memory. The two full-state requirements are incompatible.

Let a challenge query scalar multilinear polynomials over $\mathbb F_2$ of the checkpoint bits. The choice of each polynomial may depend on $x$, the claimed verdict, and earlier replies. A local check requires the transcript to have an extension to a valid run of each segment. Different challenges may use different extensions. Use the true replies from $x$. On any resulting fixed path with queries $P_i$ and answers $a_i$, the set of checkpoints yielding the same replies has indicator

$$H(z)=\prod_i (1+P_i(z)+a_i).$$

Indeed, agreement on each successive answer induces the same next query. We have $H(x)=1$ and multilinear degree $\deg H\le\sum_i\deg P_i$, since reducing $z_j^2$ to $z_j$ preserves Boolean values and can only decrease degree.

**Why both verdicts survive.** A nonzero multilinear polynomial of degree at most $d$ takes value one within distance $d$ of *every* center of the cube. Write it as $A(z')+z_1 B(z')$. If $B$ is nonzero, its degree is at most $d-1$. Inductively find a suffix within distance $d-1$ on which $B=1$, then choose the first bit to make the original value one. If $B$ is zero, apply induction to $A$ and copy the center's first bit. The constant case starts the induction. For $d<m$, the radius-$d$ balls around the all-zero and all-one vectors consist entirely of opposite majorities. Applying this to $H$ proves that the wrong segment always has a compatible extension. Equivalently, majority has algebraic immunity $m$, a known result in Boolean function theory. [Carlet, *A method of construction of balanced functions with optimum algebraic immunity*](https://eprint.iacr.org/2006/149.pdf) · [Lean verification of the support and majority degree theorems](../lean/MajoritySeam.lean)

This failure persists if the verifier checks exact agreement of the projected distributions on every common query. Use point masses on the true replies to every view. They have identical projections on their overlaps, and each individual view is supported on a transcript realized by the wrong-verdict segment. A joint distribution on full *second-segment* states would impose a stronger requirement. In particular, singleton data from the original input force a genuine jointly shared state to equal $x$ with probability one.

## Which segment relations can these challenges distinguish?

Let $A,B$ be two nonempty sets of possible checkpoint states. An adaptive decision tree separates them when no leaf can be reached both from $A$ and from $B$. If the sum of query degrees on every path is at most $D$, label the leaves reached from $B$ by one and all other leaves by zero. The XOR of the one-leaf path indicators is a polynomial of degree at most $D$ and equals zero throughout $A$ and one throughout $B$. Conversely, querying any such separating polynomial once suffices. This equivalence counts degrees and makes no bound on the work or size of the polynomial description.

For a constructive criterion, replace each state $z$ with the vector $v_D(z)$ of its nonconstant monomials of degree at most $D$. A degree-bounded polynomial is an affine functional on this vector. A separator therefore exists precisely when the affine spans of $v_D(A)$ and $v_D(B)$ are disjoint. Indeed, write the spans as $a+U$ and $b+V$. When they are disjoint, $a-b\notin U+V$, so a linear functional vanishing on $U+V$ can take value one on $a-b$. Translating its constant term gives the desired separator. If the spans intersect, no affine functional can assign different constants to them. Thus for two affine sets of states, testing linear forms really does detect incompatibility of the full sets. Given bases, Gaussian elimination finds a separating form. For a singleton $A=\{x\}$ against an arbitrary $B$, the points surviving all such challenges form the degree-$D$ closure of $B$, the common zeros of all polynomials of degree at most $D$ vanishing on $B$. [Nie and Wang on finite-degree Zariski closure](https://arxiv.org/abs/1402.3018)

## Sharpness and cost

For a particular input, exactly $\lceil m/d\rceil$ scalar degree-at-most-$d$ queries suffice to distinguish it from all opposite-majority checkpoints, for every integer $d\ge1$. Choose $m$ positions agreeing with its majority, group them in packets of at most $d$, and query the product of the literal tests for each packet. All answers are one, so any compatible state has the original majority. The polynomial argument gives the matching lower bound even if queries adapt or their coefficients are chosen with full knowledge of the input. Checking or describing the selected positions costs work in a RAM implementation. The query count treats the functions as given.

This upper bound is for a certificate chosen separately for each input. For example, when $n=5$, three linear queries suffice at any specified input. A single adaptive linear-query algorithm that must *discover* the majority requires at least four in its worst case. A tree of depth three expresses its output as the XOR of its disjoint accepting path indicators, each of degree at most three. Yet fixing the last bit to zero gives majority-one at five of the sixteen assignments to the other four bits. The XOR of those sixteen outputs is one, whereas a polynomial of degree at most three on four bits has XOR zero.

One ordinary integer sum of the checkpoint bits suffices to decide majority. Its word value contains high-degree Boolean coordinates. Moreover, an implementation that expands every bounded-fan-in deterministic gate and propagates its forced output from fixed inputs can enforce the complete run. Thus this example locates the failed step in using separately extendable, low-degree boundary views. It provides no running-time lower bound for a verifier that evaluates a segment, or for a SAT solver. [Earlier bounds on joint gate marginals](local-bag-consistency.md)
