# Predicting the first reads of a native computation

**Research journal, 24 November 2026.** Consider the native interpreter on unary length $n$, with word width $w=n^2$, cutoff $B=2^{20n}$, and first missing $n$-bit output $v_n$. Assuming linear-time SAT, every sufficiently long interval immediately below $v_n$ contains a positive fraction of outputs for which every genuine producer has hard-to-predict incoming reads. The prediction task concerns only addresses actually read in a block before any write to the same address. A further verification rule lets the predictor leave bits unspecified if every allowed filling has the same observable effect. [Native source](native-missing-word.md) · [Earlier full-configuration criterion](linear-sat-batches.md) · [Related easy-witness methods](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf)

## A partial function on a genuine run

Fix a sufficiently large integer $a$, put $C=\lceil B/n^a\rceil$, $J=\lceil B/C\rceil$, and $R=\lfloor B/n^a\rfloor$. Partition the $B$ native steps into $J$ consecutive blocks of at most $C$ steps, retaining the native halt, padding, output and within-step ordering conventions. For each block $i$ of a genuine trace define $f(i,x)$ to be the incoming word of address $x$ if the block reads $x$ before it writes there. Otherwise leave $f(i,x)$ undefined. A circuit predicting $f$ has block and address inputs and $w$ output bits. Its off-domain values are arbitrary. Measure circuit descriptions in encoded bits, including all gate references and outputs.

Let $S_n$ contain each output of a genuine name of length less than $n$ with some predictor of description length at most $R$ on its own trace. Under linear SAT, membership in $S_n$ is decidable deterministically on the target RAM in $(R+C+J) n^{O(1)}$ time. The overhead exponent can be chosen independently of $a$. As usual $J\operatorname{poly}(n)$ is eventually negligible against $R$ for each fixed $a$.

Guess the name, predictor $G$ and boundary CPU states, including the append-only output checker against the target. Local replay begins with one supplied CPU state and an empty dictionary of writes in that block. Before a local write, a read of $x$ receives $G(i,x)$. Further reads use the most recent local write whenever there is one. The replay is deterministic. Check every block's final controller against the next boundary and enforce the true initialization, final halt, and output condition.

For each block $i$ and address $x$ first-read before a local write, require a preceding source. It is either initialization or a writing block $j<i$. In the latter case replay $j$ and require its last value written at $x$ to equal $G(i,x)$. For initialization check the native initial value for this name and address. Universally check every block strictly between the source and $i$ to exclude an intervening write to $x$. These assertions compare a constant number of local replays per selected tuple. The universal address has only $w$ bits, even though the native address space has size $2^w$.

All tests refer to the same fixed $G$ and controllers. Induction over the blocks makes every replay coincide with the actual run. Within a block, a first-read address gets the correct earlier word by the source test, and the local dictionary supplies subsequent writes. Determinism makes the generated addresses and control flow correct as well. Conversely the predictor of a genuine trace passes, since replay from its true controller follows exactly its first-read domain.

The cost is additive in $C$ and $R$. To check an adaptively generated sequence of circuit queries, guess its replies, follow the entire local replay, and universally select a query for an ordinary circuit evaluation. An incorrect replay has a first wrong answer. Dictionary operations on $w$-bit native addresses can use a balanced tree with polynomial-in-$n$ overhead, so they need no array of length $2^w$. Building the explicit bounded checks and eliminating their fixed number of quantifier blocks costs $(C+R+J)\operatorname{poly}(n)$ under linear SAT. The parameters enter only as lengths, iteration caps and indices in fixed routines. ## What can be left unspecified

Instead of $G$, allow two circuits with total description length at most $R$. One provides a canonical fill word at each $(i,x)$. The other gives a predicate on a proposed incoming word there. Require the canonical word to pass everywhere. A mask specifying some bits is one such predicate. Each block may query the incoming memory adaptively. An admissible filling is any total memory obeying all that block's word predicates. Impose two additional conditions.

1. Every admissible filling gives the canonical replay's exit controller and its same write effect at every address. The effect at an address says whether a write occurred and, when one did, gives the final written word.
2. For each $x$ first-read by some admissible filling of block $i$, the last word written by its preceding canonical source, or the initialized value if none exists, satisfies the incoming predicate at $(i,x)$.

To verify the first condition, universally challenge a block, an address for the write-effect test, and an admissible local replay. Supply incoming words only on first use, keep them fixed on repetitions, and check the predicates. Canonical values at all other addresses extend these guesses to a total admissible filling. The same witness determines whether an address can be first-read in the second condition. Universal selection over candidate replays, followed by the earlier source and intervening-block checks, still has fixed alternation and the additive time bound.

For soundness, assume all earlier canonical effects and controllers are genuine. On every possibly first-read address fill in the actual incoming word, and use the canonical filler elsewhere. The second condition and the induction hypothesis make this an admissible memory. Its replay agrees with the actual one, since they coincide at every incoming address queried along that replay. The first condition now gives the canonical effects and exit controller for the genuine block. This argument allows the set of accessed addresses to change with unconstrained words. Lean verifies the adaptive filling argument for arbitrary per-address predicates. [Formal proof](../lean/FirstReadReplay.lean)

## Consequence at the first missing output

Let $S_n^*$ include outputs proved by the per-address predicates as well as exact predictors of the original size bound. A one-bit selector between these formats suffices. Soundness gives $v_n\notin S_n^*$. For a constant $c$ depending on the fixed native decoder, every $0\le K\le v_n$ satisfies, at every sufficiently large $n$,

$$
\#\{z\in[v_n-K,v_n):z\notin S_n^*\}\ \ge\ (K+1)/c-1.
$$

Indeed, a fixed native decoder can rank the omissions of $S_n^*$ by the existing maximum-gap score. Guess the $2^n$-bit membership table, universally check one selected entry with the preceding decision procedure, and check the requested bit of the ranked output. The ranking costs $2^{2n}\operatorname{poly}(n)$. Fixed-block elimination, $n$ output bits and native interpretation keep the total below $B$ for sufficiently large $a$. The one-sided gap inequality bounds the score of $v_n$, since a high enough score would encode its rank in fewer than $n$ bits even after the fixed program header. Every predecessor appearing in the displayed count is a real output, by minimality of $v_n$. [Rank bound](predecessor-batches.md) · [Batched full-table verification](linear-sat-batches.md)

For each such predecessor and *every* genuine producing name, any proposed circuit of at most $R/2$ bits makes more than $B/n^{a+O(1)}$ word errors on distinct actual first-read pairs. Otherwise append an exception table of the keys and correct values, using $O(n^2)$ Boolean gates per corrected pair and $O(n)$ bits per reference in the chosen circuit-size range. With a sufficiently small constant in the patch budget this produces an exact predictor of at most $R$ bits. In particular the initialized native memory, itself computable by a small circuit for a fixed name, supplies a baseline. At least $B/\operatorname{poly}(n)$ genuine first reads on these traces must import a changed word from an earlier block. The predicate extension also excludes short proofs that all but a few predicted bits can be ignored without changing the certified effects.

For an exact predictor permit the timestamp and within-step slot as additional circuit inputs. Cache its answer on the first external read of each address, so repeated uses remain consistent. The global test compares that first value with the preceding source as before. A one-bit format choice can include time-indexed predictors in the same ranked union. In particular the actual word returned at each stamped read of a hard producer cannot have an exact circuit of fewer than $B/\operatorname{poly}(n)$ description bits that takes just the stamp and a queried word-bit offset. Replicating any such bit circuit for all $n^2$ word positions only costs a polynomial factor. The single language with the producing name, stamp and bit offset as inputs lies in deterministic exponential time $2^{O(n)}$: direct bounded simulation with polynomial overhead in $B$ suffices. This consequence identifies the hard table with data actually read by the fixed interpreter.

## Address and time rectangles

A program-dependent collection of rectangles in $(i,x)$ can assign a predicted word on each rectangle, with a default elsewhere and a specified priority on overlaps. If the tests of membership and priority, together with the proposed words, compile to a circuit within $R/2$ bits, the same error bound applies even when the rectangles were chosen after seeing the true run. An ownership rule giving only the earlier block index still leaves the word from that block to be computed. Proving that almost all predecessors in one growing terminal interval admit a smaller predictor or admissibility proof would refute linear SAT. The earlier quantile balances concern two potentially false logs. They do not construct these predictors for genuine trajectories.

A fixed short RAM program illustrates the difference between an interval cover and a content predictor. It writes $x\bmod 2$ to addresses $x=1,\ldots,M$, and later reads them in increasing order, with the two phases separated at a block boundary. On these first reads the value circuit returns the low address bit. Yet a family of $s$ axis-aligned interval rectangles with any Boolean decoding of their membership vectors makes at least $(M-2s-1)/2$ word errors when predicting these bits. Along the scan both the block index and address are nondecreasing, so membership in each rectangle is an interval of scan positions. The membership vector changes at most $2s$ times. On a consecutive run of length $l$ with constant prediction, at least $\lfloor l/2\rfloor$ alternating bits are wrong. A long idle interval between the phases can ensure that no reading block also performs data writes from the first phase. Choosing $M=B/\operatorname{poly}(n)$ with a sufficiently large fixed polynomial leaves room for the interpreter overhead and this gap. This example tests a restriction on candidate maps. Its output can be chosen constant.

## Recovering values from earlier blocks without an owner map

The preceding test also admits dense incoming words that can be reconstructed from a shallow sequence of transfers. Use balanced blocks here, with $C=\lceil\sqrt B\rceil$ and $J=\lceil B/C\rceil$. In the true run, for every actual first-read pair $(i,x)$ whose last write was in block $j<i$, draw the directed edge $j\to i$ labelled by $x$. Omit reads whose source is initialization. Parallel edges stand for different incoming words. Measure a path's length by its number of edges.

Guess the CPU boundaries, one rank in $0,\ldots,h$ per block, and a circuit of description length at most $R$. On $(i,x)$ the circuit can either supply the incoming word directly or request reconstruction. A direct exception table is a special case. Define a unique canonical run for each block in increasing order of rank. On a first read requesting reconstruction, take the final word written at $x$ by the **latest** earlier block of strictly smaller rank that writes $x$ in its canonical replay. Use initialization if there is none. Ordinary local writes retain precedence over this rule. After the canonical replays have been defined, apply the exact controller and global predecessor checks above using *all* earlier blocks. This last comparison is essential for rejecting a spurious choice of ranks.

Suppose deleting some labelled edges from the true graph makes its longest path at most $h$. Store the incoming words at the deleted edges as direct exceptions. Rank each block by the length of a longest remaining path ending there. With the genuine controllers, induction on rank proves that each replay is genuine. For an actual first read needing reconstruction, the true latest writer has smaller rank, or no preceding writer exists. By the rank induction hypothesis every earlier lower-ranked replay has its true writes. Searching only those blocks therefore recovers the same latest word. Step-by-step determinism then identifies the entire block. In particular this proof needs neither a public schedule of addresses nor a table naming the writer of each word.

The uniform cost under linear SAT is

$$
(C+J+R+1)\,2^{O((h+1)\log(n+2))}
$$

for $1\le h\le n$, $R\le B$, and uniformly constructible budgets. To check a proposed property of one canonical block, guess all queried circuit replies, incoming words and proposed source indices along its $C$-step replay. Test the property on this deterministic local computation. Universal challenges validate a selected circuit reply, or a selected reconstructed word. For that word, its proposed source must show a last write of the claimed value, and every intervening eligible block must show no write. For the initialization case, check the initialized word and every eligible earlier block for absence of a write. A universal branch selects one such condition to continue checking. Both the last-write claim and the no-write claim are properties of a single lower-ranked deterministic canonical replay. The rank strictly falls. A proved property may specify either truth value, so checking absence takes the same form as checking presence. For the outer global comparison the initial challenge ranges over all previous blocks before the recursion proceeds down the ranks.

One play has at most $O(h+1)$ alternations. Its local replay lists and controller/exception data cost at most $(h+1)(C+J+R+1)\operatorname{poly}(n)$ bits and time along a branch, including wide-word dictionary operations. Use predetermined padded choice lists for each level and retain the decision if the recursion ends early. A fixed deterministic checker simulates the chosen path; compile its verdict into the quasilinear RAM-transcript circuit. Eliminating the resulting $O(h+1)$ quantifier blocks adds $O((h+1)\log(n+2))$ to the logarithm of the size, since its logarithm stays polynomial in $n$. The routine is fixed as $h$ varies. [Block elimination](linear-quantifiers.md)

For every fixed $h$, choose $R=\lfloor B/n^a\rfloor$ for a sufficiently large fixed $a$. The score argument applies to all outputs certified by this test. For the resulting positive-density predecessors, **every** genuine producer needs more than $B/n^{a+O(1)}$ labelled edge deletions to bring the height down to $h$. Otherwise put precisely the exceptions in a circuit of at most $R$ bits. For a growing-depth version fix any $0<\sigma<20$. Take $R=\lfloor2^{\beta n}\rfloor$ for fixed rational $\max(10,\sigma)<\beta<20$ and $h=\lfloor\varepsilon n/\lceil\log_2(n+2)\rceil\rfloor$ for a sufficiently small positive rational $\varepsilon$. Then the total clock still fits $B$ after the score decoder and native interpretation. More than $2^{\sigma n}$ deletions are necessary, since this many word exceptions fit $R$ with room for gate indices. In either version, a maximal family of edge-disjoint paths of length $h+1$ meets every such path. Deleting its at most $(h+1)$ edges per path leaves height at most $h$. The corresponding hard traces therefore contain at least the required deletion count divided by $h+1$ edge-disjoint long paths. Paths may share blocks and distinct incoming reads may use the same old write.

An exhaustive two-cell bit-RAM check covered 55,296 three-block program, start-state, rank and exception-policy combinations. In 4,348 cases every supplied CPU boundary matched even though a replay differed from the true one. The global memory check caught every such case. Supplying the words for all rank-violating genuine edges reproduced the true trajectory in every tested case. Edge-depth robustness is an established graph notion. The transfer here imposes it on every producing trace for specified outputs and permits directly predicted words to bypass dependencies. [Runnable finite check](../audits/native_first_reads_experiment.py) · [Blocki, Cinkoske et al., edge-depth robustness](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ITCS.2021.64)

The rank test is sound even when its sufficient graph condition fails, since its final global check glues the actual words. Simple multi-pass scans can have many long transfers, but a small circuit supplying the transferred values still bypasses them. Excluding linear SAT along this route requires structural information about the producing names for the specific predecessors, beyond a count of occupied address–time cells.
