# Certifying a whole interval by challenging one decoded read

**Research journal, 24 November 2026.** Suppose ordinary SAT has a linear-time deterministic solver on the packed logarithmic-word RAM. There is a family of unsatisfiable inputs on which the solver has an interval of $\Omega(N/\log^8 N)$ consecutive times before its first halt with the following property. At **each** such time, any representation of the actual writable memory using $s$ bits with worst-case per-word query time $q$ satisfies
$$
 s+q=\Omega(N/\log^{12}N).
$$
The representation can be chosen separately for each time after seeing the entire run. Queries get the formula, time, and address. Use the fixed evaluator convention allowing program bits in the representation. This is an additive lower bound even for decoders that adaptively read both the description and the input. The earlier product inequality gives a stronger length bound in some very small query budgets. [Evaluator and product bound](persistent-snapshot-query-cost.md)

There is also an unconditional result. Write $K_A(F)=\sum_{0\le t<E}\min(1+s+q)$, minimizing over all representations answering every writable-word query at time $t$ and charging the worst-case lookup latency of that representation. Every deterministic SAT solver has worst-case $K_A$ outside $O(N^{1.353})$ on unsatisfiable formulas. Even the weaker assumption of a deterministic sound UNSAT signal on all negative inputs suffices. The finite combinatorial obstruction for a single replay charged at its starting latency persists. A second nonacceptance check lets us pay for verifying the reads in a different way. ## Verifying all guessed reads

Use the same source as for the cumulative-memory diagonal. Its genuine bounded-computation formula is $F$, with a uniform word generator on the public source input. A proposed schedule specifies the initial time, increasing cuts, an ending signal time, controllers, row bitstrings and their integer query clocks. The outer verifier checks the directory and all offsets. Every internal row denotes a total writable-word array by using a fixed output on timeout. The final step needs only a controller check and a signal. [Source formula and hierarchy](cumulative-sat-memory.md)

To recognize a **defective** interval, guess the interval and a challenged ending address. Replay the target deterministically except for answers to starting-row queries, which are guessed and recorded with their row and address. A local array holds stores made since the start, with a separate presence bit. Actual input reads always consult the true formula generator. If the challenged final address is absent from the array, record its guessed starting-row value too. Record the proposed answer from the next row at that address when there is a next row. The true zero initial array is directly available. Check that the resulting controller, word, or final signal disagrees with the claim. There are $O(g+1)$ records for an interval of length $g$, regardless of the starting decoder's latency.

The remaining question is whether **any** recorded answer is wrong. An existential machine chooses one recorded index, executes its named row's decoder once on the recorded address with the associated time and clock, and compares the result. A sound nondeterministic UNSAT recognizer, called the reference, certifies that the explicit bounded-computation formula for this last test is unsatisfiable. If any record is wrong, no reference branch can certify the list. If all records are correct, the guessed replay is the true replay from the denoted starting state, by induction even when addresses depend on previous answers. A true defect therefore has an accepting branch of the interval verifier, and any such branch proves a true defect. One more application of nonacceptance to this nondeterministic interval verifier establishes the absence of **every** defect. This second application is essential. All submachines have explicit maximum clocks sufficient to include the reference's timely branch on honest UNSAT calls. Bounds are enforced even on false guesses. ## An unconditional cumulative first-moment bound

Assume for contradiction $K_A(F)=O(N^c)$ on all unsatisfiable formulas and a separate sound UNSAT reference with some accepting branch of time $O(N^d)$ on every such formula, $c,d\ge1$. The diagonal source has $m$ public words, time $R$, and scale $H=\max(R,m,2)$. All quantities below may have fixed polylogarithmic factors. Choose a least-cost time in each full internal $w=\lceil H^x\rceil$ window of the actual target run on its virtual formula. Put $B=H^{c-x}$. The total length, number and **sum of the query clocks** of the selected rows are $\widetilde O(1+B)$ by disjoint window averaging. The $O(\log H)$-bit headers and controllers per cut fit in the same word bound. In particular the maximum query clock is $\widetilde O(B)$. The maximum gap is $2w$. [Finite minimum selection and its cost](../lean/CumulativeSnapshotCuts.lean)

The inner challenge can verify the $O(w)$ recorded queries in batches. Take a public batch size $U=\widetilde\Theta(\max(m,B,1))$ with enough capacity for either selected row. For each batch include the source input, the at most two selected rows, and the corresponding portion of the recorded log. Existence of an erroneous entry has nondeterministic time $\widetilde O(B+1)$ and uses $O(U)$ public words. Materialize its bounded-computation formula and guess a timely accepting branch of the reference. Sequentially certifying all batches on the same branch costs $\widetilde O((w+U)U^{d-1})$ time. Creating the batches, guessing the replay and charged access to the original formula fit this bound. If any batch contains an error, no sequence of accepting certificates exists. The batch logs are private guesses of the interval machine. Its own public input has $\widetilde O(m+B)$ words.

Here is the exponent calculation. The case of interest has $d<2$. Write $b=d^2$. Initially arbitrary nondeterministic nonacceptance has a nondeterministic certification procedure costing $\widetilde O(R^d+m^b)$, by the ordinary reference call. Suppose such a procedure has work exponent $1\le e\le d$ and still charges $m^b$ for public data. Apply it to nonacceptance of the interval machine. Choose $x$ so that
$$
 e[x+(d-1)(c-x)]=b(c-x),\qquad c-x=\frac{ce}{b+(2-d)e}.
$$
Since $b\ge de$, $x\ge c/2$ and $w\ge B$. If $m\le B$, the new work exponent is $e'=b(c-x)$. For $m>B$, $U$ has exponent scale $m$ and $m^{de}\le m^b$. The other varying term is $w^e m^{(d-1)e}$, which is bounded by $m^b$ because $w^e=B^{b-(d-1)e}$ at the chosen balance. This preserves $\widetilde O(R^{e'}+m^b)$ whenever $e'\le b$. Thus
$$
 e'=\frac{cbe}{b+(2-d)e}.
$$
When $d^2(c-1)<2-d$, finite iteration from $d$ crosses one, unless the initial case already yields an immediate crossing. Indeed the positive fixed point is $b(c-1)/(2-d)$ for $c>1$, and reciprocals contract by $1/c$. The case $c=1$ follows by relaxation. Fixed rational clocks and sufficiently small strict slack suffice as in the cumulative theorem. Taking $R=m^k$ for fixed $k>b$ yields a faster certificate of the bounded universal machine's own nonacceptance and the diagonal contradiction. Using $d=c$ excludes every fixed exponent below the real root $1.353209964\ldots$ of $c^3-c^2+c-2=0$. In particular at $1.353$ the first strict crossing is at step 18. A single unbatched check with the same public exponent instead yields $e'=cd^2e/(d+e)$ and crosses at step eight for $c=d=1.324$. [Exact rational calculations](../lean/FirstMomentSnapshotTrade.lean)

## A long interval for a hypothetical linear-time solver

For this consequence use the fixed signed source with $n_0$ input bits, clock $h=\Theta(n_0^2)$, and explicit formula length $N=\Theta(h L^3)$ where $L=\max(2,\lceil\log_2(N+2)\rceil)$. A fixed verifier guesses the schedule, row lengths, timeouts and claimed rejecting halt $E$. For the argument it uses only schedules with polynomially capped fields. The verifier covers all the small witnesses used below and its source description is independent of the constants defining them.

Suppose every full internal window of $w$ consecutive times held a description with $s+q\le K$. Choose one such time from each disjoint full window. The maximum gap is $2w$ and the number of segments is $P=O(1+E/w)$. On honest rows $s,q\le K$ independently. The outer verifier stores all rows as packed bits, with $O(1)$ header words per row. The interval machine copies just the two selected rows out of this public pool, builds the $O(w+1)$-record log, and materializes one inner defect formula. The inner test has $O(K+1)$ native steps and $O(n_0+w+1+K/L)$ public words. The packed materialization for $r$ steps and $m'$ public words costs $O(rL^3+m'L^2+\operatorname{poly}(L))$ bits and time. Apply the linear SAT solver to this explicitly written query. Thus the interval machine's time, on all branches of the bounded test with these public caps, is $O(KL^3+(n_0+w)L^2+\operatorname{poly}(L))$. Its fixed code sees $O(n_0+P(1+K/L))$ public words. A second packed materialization and linear-time SAT call take, including the initial construction of the directory,
$$
 O\big(KL^6+(n_0+w)L^5+[n_0+P(1+K/L)]L^2+\operatorname{poly}(L)\big).
$$
All read-only formula words cost constant time after one polylogarithmic setup. Zero-length runs, empty internal schedules and partial windows are covered by replaying the final interval to the signal. [Packed construction and input cost](materialized-input-census.md) · [Native word access to the virtual formula](packed-band-transfer.md)

Set $w=\max(1,\lfloor\gamma N/L^8\rfloor)$ and $K=\eta N/L^{12}$. Since $E=O(N)$, $P=O(1+L^8/\gamma)$. The displayed time is $O(\gamma h)+O((\eta/\gamma)h)+o(h)$. Fix $\gamma$ small enough for the first term and then choose $\eta$ for the second. Both constants may depend on the solver and the fixed verifier. On the verifier's own padded description a timely success implies both satisfiability of the source formula and a genuine rejection of that formula. Hence the formula is unsatisfiable, and any cheap schedule yielding a timely success is impossible. At least one full internal window must have the stated length with no description of additive cost at most $K$. The argument works for all sufficiently large padding lengths.

The original input remains free to the decoder. Replaying a linear-time solver gives a constant-program description with linear query time, compatible with the bound. Excluding linear SAT by this route would require a stronger upper bound on the best description length plus query time **somewhere within every such long interval of a real solver**.
