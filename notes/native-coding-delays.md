# An ordinary sampler that defeats any prescribed fixed coding deadline

**Research journal, 24 November 2026.** Write $P_t^W(y)$ for the probability that a native prefix machine $W$ prints $y$ by time $t$ on fair input, and $K_t^W(y)$ for its shortest such name. For **each fixed** $A\ge0$ and $0<\varepsilon<1$, there is an efficient literal universal machine $W$ with the following properties. At every sufficiently large integer $k$, for $q_k=2^k$, $t_k=2^{q_k}$, and one $k$-bit word $y_k$,
$$
 P_{t_k}^W(y_k)\ge 2^{-O(\log k)},\qquad
 K^W_{\lceil t_k q_k^A\rceil}(y_k)\ge k.
$$
For infinitely many $k$, the same word by the **earlier** time carries at least $(1-\varepsilon)$ times the entire **eventual** probability of all $k$-bit outputs of $W$. Its unbounded prefix complexity is $K(k)+O(1)$ on every optimal reference. The words $y_k$ are independent of $A$ and $\varepsilon$.

There is also a single ordinary literal universal $W_*$ that satisfies the displayed inequalities for every fixed $A$, at all sufficiently large $k$ depending on $A$. Its simulation overhead can be bounded by $u(\log(2+u))^{h(u)}$ for any prescribed total computable nondecreasing integer $h(u)\to\infty$, with a fixed compiler for each simulated machine and for sufficiently large simulated times $u$. No fixed polylogarithmic overhead works on $W_*$. This distinction prevents either construction from contradicting the [conditional coding bound for efficient interpreters](near-clock-coding.md). No external oracle is used.

## One common choice of word

Fix efficient literal optimal native prefix machines $U,R$, with positive integers represented by their canonical binary expansions on $R$. Put $q=2^k$, $t=2^q$. Fix a sufficiently large integer $D$ and, at large $k$, let $s=2^{q-Dk}=t/q^D$. Let $y_k$ be the first $k$-bit word in lexicographic order that $U$ fails to print by $s$ on all exact names shorter than $k$. There are fewer than $2^k$ candidates for programs, so this word exists. Settle the finitely many ineligible small parameters by a fixed rule.

One fixed native algorithm $F$ takes $k$ and computes $y_k$ by direct enumeration. There are $q-1$ names to test. Stop each trial upon an excess read, timeout or halt, admitting a result only on exact consumption. Mark the produced $k$-bit words in a $q$-entry array and find the first unmarked one. Simulating an $s$-step trial with width $O(\log s)=O(q)$, resetting the touched memory and maintaining a bounded clock costs $O(sq^c)$ for some fixed $c$. One may maintain a private addressed-memory trie for each run, using fresh nodes only when touched. The exponent does not depend on $D$: constructing the binary exponent $q-Dk$ and the timeout costs only polynomial time in $q$ for each fixed $D$. The native word width can be handled in limbs during setup. With $D>c+4$, all trials and output together take $O(t/q^2)$ steps. Thus $y_k$ has a fixed ordinary generating procedure, and its length recovers $k$. [Native simulation convention](time-by-length.md)

## Two ways to run the generic simulations

A special branch with header $0$ runs $R$ on an exact name $p$ for $k$. Count the simulated steps $u$ and admit the branch only if $u\le2^{2^{\lfloor k/2\rfloor}}$. Once $k$ is known this comparison can be made on binary counters. On an admitted name, consume and discard **exactly $k$ additional bits**, compute $F(k)$, then publish the resulting word. The admission limit is $t^{o(1)}$, so even a fixed polynomial overhead on the initial run fits before $t/4$ at all sufficiently large $k$. Every admitted special name for length $k$ therefore finishes by $t$. This branch's total mass on $y_k$ is half the admitted $R$ mass for $k$. The $2^k$ different raw extensions of each $p$ are distinct exact names for the same word.

Behind a disjoint header $1^H0$ put the universal machine $U$ on its unmodified raw payload. All other headers diverge. The simulator takes at least $\lceil\log_2(j+2)\rceil^B$ physical steps for simulated step $j$, for a fixed large integer $B>A+D+1$. It can impose this delay using counters and still have fixed polylogarithmic overhead, so the combined machine is efficiently literally universal. When $s$ simulated steps have been reached, the last $s/2$ steps cost at least $(s/2)(q/2)^B$ for all large $k$. This exceeds $\lceil tq^A\rceil$. Consequently every generic name shorter than $k$ timely by the later deadline ran a $U$ payload shorter than $k$ for at most $s$ steps. It misses $y_k$ by construction. Every special name for $y_k$ already had at least $k$ additional input bits. This proves the length lower bound using **all** programs in the reference.

The native $R$ can simulate a literal integer printer on an Elias gamma code for $k$ in $\mathrm{poly}(k)$ time. Its name therefore passes the admission limit and supplies the displayed mass at every large $k$. For infinitely many $k$, there is also an admitted name of length $K_R(k)+O(1)$. For completeness, let $p$ range over $R$-programs shortest for original words of unbounded complexity, with running time $v$. Form $k$ by injectively packing $p$ and $\mathrm{bin}(v+1)$ into its binary digits, with $k\ge v+1$. A fixed routine on $p$ simulates it, retains its consumed bits, counts $v$ and prints the packed integer. It runs in $\mathrm{poly}(k)$ time and has length $|p|+O(1)$. Conversely $k$ recovers $p$ and hence its original output, giving $K_R(k)\ge |p|-O(1)$.

At these $k$ the special mass already present at $t$ is at least $c2^{-K_R(k)}$ for $c>0$ independent of $A,H$. The entire eventual $U$ mass of length-$k$ words is at most $C2^{-K_R(k)}$: its length marginal is a lower semicomputable semimeasure, bounded by a constant times the universal discrete semimeasure. Thus the generic mass of the entire length is at most $2^{-H-1}C2^{-K_R(k)}$. Taking $H$ large gives the claimed $(1-\varepsilon)$ fraction. Every special name contributing to this length has already arrived by $t$, including those from other timely integer names. [Prefix coding theorem and marginal estimate](occupied-clock-cells.md)

## All fixed exponents on one less efficient interpreter

Retain the two branches with the same program-to-output map and change only the delays on the generic branch. At simulated step $j$, impose a wait of $\lceil\log_2(j+2)\rceil^{b(j)}$ with $b(j)$ nondecreasing and tending to infinity. The preceding lower bound applies eventually with every fixed $B$. One may impose any specified unbounded computable upper exponent $h$ in the statement: spend $O(\log(j+2))$ simulated steps of a fixed enumerator sequentially computing $h(1),h(2),\ldots$, keeping the last completed value at an index at most $j$. Use half that value rounded down, capped by $\lfloor\log_2\log_2(j+4)\rfloor$, as $b(j)$; use zero before the first result. The tests and binary counters fit fixed polylogarithmic overhead, even for an enumerator that is itself very slow. The cap permits representing the wait counter in $O((\log\log(j+4))^2)$ bits. Increasing $j$ can only increase the selected exponent. It eventually exceeds each fixed bound and is at most $h(j)/2$. The sum through $u$ of the generic wait times, the other simulation work, and the extra fixed polylog overhead for any one simulated source are together at most $u(\log_2(2+u))^{h(u)}$ for large $u$. The earlier-time mass and its share of the eventual length marginal are unchanged.

A fixed efficient literal interpreter can run $F(k)$ from the short direct encoding of $k$ in $t_k q_k^{O(1)}$ time. On $W_*$ any such short program still fails at *every* fixed exponent at large $k$. This directly witnesses the failure of efficient literal universality; the upper bound on its slowdown alone would not have established failure. For the finite-$B$ machines, too, a larger fixed exponent suffices to run this short $F$-description via their generic branch. Padding creates a large timely probability without a short timely name on these clocks, even after almost all the weight of the length has arrived. For a counterexample on a fixed efficient interpreter, a fast generator of $y_k$ from the short phase description would itself be a successful short program once its compiler overhead is paid. The missing step is to make the generation rely on the random tape in a way that survives that compilation.

## A nonconstant gap for Levin cost and reciprocal-time program mass

For genuine exact finite publications define
$$
 \mathrm{Kt}_W(y)=\min_{p:W(p)=y}\bigl(|p|+\lceil\log_2(2+\tau_p)\rceil\bigr),
 \qquad S_W(y)=\sum_{p:W(p)=y}\frac{2^{-|p|}}{2+\tau_p}.
$$
Here $\tau_p$ is physical native time. For every fixed $C>0$ there is a **single efficient** literal universal machine $W$ with
$$
\mathrm{Kt}_W(0^n)+\log_2 S_W(0^n)
\ \ge\ C\log_2\log_2 n-O(\log_2\log_2\log_2 n)
$$
for all large $n=2^{2^k}$. This is an unconditional unbounded gap even for the all-zero word. The logarithm of output length is still much larger than this lower bound. Filan, Leike and Hutter study the reciprocal-time speed prior under a monotone output convention. Here the exact-name convention permits summing over independent finite publications. [Loss Bounds and Time Complexity for Speed Priors](https://proceedings.mlr.press/v51/filan16.pdf)

Use the generic branch above with $B>C+2$. On a separate fast branch read the gamma code of $k$, consume $Jk$ arbitrary further bits for a fixed integer $J>C+2$, and explicitly print $n$ zero bits. This takes $O(n)$ total steps with one bit per write. For instance, a depth-$2^k$ binary tree traversal writes one zero at every leaf using one frame per pending level and constant amortized steps per leaf. Its $O(2^k)$ stack is available at this time scale; counters and setup can equally be prepared during an initial $o(n)$ warmup. All $2^{Jk}$ special extensions have the same length and finish on the same schedule. Their combined contribution to $S_W(0^n)$ is at least $c\,2^{-O(\log k)}/n$.

An arbitrary native machine explicitly producing $n$ output bits by $u$ has $n\le c_0 u\log_2(u+2)$, since it handles only a fixed number of physical words per step. Hence $u\ge c_1 n/\log_2 n$ for large $n$, even when output is word-packed. For a special program the time part of the cost is therefore at least $\log_2 n-k-O(1)$, and its length includes $Jk$ bits. For a generic program producing this word, apply the same output bound to the virtual $U$ computation. At least the last half of its $u$ steps pay at least $(\log_2(u/2))^B$ physical steps each, so actual time is at least $c_B n(\log_2 n)^{B-1}$. Its cost is at least $\log_2 n+(B-1)k-O_B(1)$ regardless of length. The minimum over both branches and the preceding lower bound on $S_W$ give the claimed gap.

In this example a raw literal description of the entire output cannot defeat the cost estimate: even the shortest generic instruction to print zeros must pay the generic branch's physical writing time. On the other hand, one fixed generic program with a short code for $k$ can also print these zeros in $n\,\mathrm{polylog}(n)$ physical steps. Thus its overhead contributes only $O(\log\log n)$ bits to the Levin cost beyond $\log n$. Achieving a larger order through the same output would require another source of delay.

## A sparse randomized decision problem for the high-mass case

There is a second constraint on attempts to replace the oracle by one ordinary sampler. Fix positive integers $a,b$ and a single ordinary $S$. Restrict the [near-clock test](near-clock-coding.md) to $|y|\le(\log_2 t)^b$ and $P_t^S(y)\ge(\log_2 t)^{-a}$. If no fixed clock exponent and additive length allowance work on this restricted test on an efficient reference, then **one explicitly defined promise problem for $S$ admits bounded-error randomized linear time and no deterministic quasilinear time algorithm**. At each clock parameter, only polynomially many queries in the logarithm of the padded input length can even fall outside the no region. The parameter restriction includes the earlier computable-oracle example's probability regime for a suitable constant $a$; here the sampling procedure must run on an ordinary RAM.

The queries specify an epoch $q$, a depth $1\le d\le\lceil a\log_2(q+2)\rceil+2$, an exact output length $i\le q^b$, and a proposed prefix $v$ of length at most $i$. Include a fixed-format unary padding field of $2^q(q+2)^E$ bits, with $E$ a fixed sufficiently large integer. For a fair run of $S$ through $2^q$ steps let $p$ be the probability it has printed an $i$-bit word starting with $v$. The yes cases have $p\ge 2^{1-d}$; the no cases have $p\le2^{-d}$. Sample $O(2^d)$ independent bounded runs, compare the observed number of hits to the midpoint threshold, and use the multiplicative Chernoff bound at the two extremes. A sufficiently large constant gives error below $1/3$. Native simulation and checking the output length and prefix fit the padding with linear running time. Input validation can be clocked by its actual encoded length; malformed encodings can belong to the no region. At fixed $(q,d)$ and prefix depth, the events over all valid $(i,v)$ are pairwise disjoint. Fewer than $2^d$ can have $p>2^{-d}$. Summing over depths and $d$ proves the sparsity assertion, including intermediate probabilities.

Suppose there is a deterministic quasilinear-time promise decider. Use its yes/no answer on every query, clocking it explicitly if its runtime guarantee was promise-only. For each $(q,d,i)$ traverse the binary prefix tree of length-$i$ outputs, stopping at a no answer. A traversed yes node has true mass greater than $2^{-d}$. At most $2^d$ yes nodes occur per prefix depth across all lengths $i$. With the one check at each of the $q^b+1$ roots, the traversal needs only $\mathrm{poly}(q)$ calls, including rejected children. Every word of mass at least $2^{1-d}$ passes all its prefix checks. Keep the list of full words that pass, issuing a width-$2^{-d-2}$ request just the first time the word passes at depth parameter $d$. Since each issued word had mass greater than $2^{-d}$, the geometric sum of its widths is at most half its eventual mass. Enumerate whole batches in order and use the disjoint aligned cylinders of the [streaming construction](near-clock-coding.md). The explicit lists now have polynomial size in $q$ and all prior table work through epoch $q$ costs $2^q\mathrm{poly}(q)$.

For an eligible $t,y$ use $q=\lceil\log_2 t\rceil$ and $d=\lceil-\log_2P_t^S(y)\rceil+1$. The epoch admits this value and its tests all succeed. Hence there is a name costing $\lceil-\log_2P_t^S(y)\rceil+O(1)$ by $t\,\mathrm{polylog}(t)$ on any efficient literal universal reference. This proves the stated implication without using SAT, counting arbitrary witnesses, or assuming consistent answers in the intermediate band beyond the decider's being a single deterministic algorithm. Related work connects resource-bounded coding and pseudodeterministic constructions to probabilistic time hierarchies. [Lu, Oliveira and Zimand](https://arxiv.org/abs/2204.08312) · [Lu, Oliveira and Santhanam](https://arxiv.org/abs/2103.08539)
