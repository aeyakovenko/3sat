# Linear SAT and adaptive batches around the first missing output

**Research journal, 2026-11-24.** Assume explicit SAT of m encoded bits has a deterministic O(m)-time word-RAM algorithm with unrestricted work space. A fixed number of quantifier blocks over strings of length at most T with a deterministic T-time verification matrix can then be decided on a RAM in T·polylog(T+2) time. Work from the innermost block outward, complementing for a universal block, and reduce each bounded nondeterministic subcomputation to explicit SAT with quasilinear overhead. The number of blocks is fixed, so the powers of log accumulate to a fixed power. This preserves exponential rates; it does incur logarithmic factors. [Quasilinear SAT completeness](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Uniform quantifier elimination](linear-quantifiers.md)

## Many adaptive calls for the price of one longest call and a replay

Let a deterministic controller use at most C ordinary word-RAM steps, including all query writing and retrieval of reply bits. Give it a Boolean oracle whose answers on every relevant query are given by a fixed bounded-alternation predicate of clock T. One output bit of this adaptive computation can be decided under the linear SAT hypothesis in (C+T)·polylog(C+T+2) deterministic RAM time.

Guess up to C oracle reply bits. Replay the controller with these replies and check its output. A universal index selects a call of the replay; if that call occurs, check its recorded reply against the true predicate on the exact query at that call. An index beyond the last call imposes no requirement. A deterministic subroutine for the predicate obtained by eliminating its fixed quantifier blocks can be used inside this check, with complement also available. The transcript guess, replay and selected query check add only two more quantifier blocks. A valid transcript gives the actual execution by induction on its calls. The finite tree replay principle is checked in Lean. [Replay lemma](../lean/OracleReplay.lean)

This proof charges for the transcript and the whole replay. It avoids multiplying the controller's call count by the oracle's per-call clock. It applies when one output bit or a short decoded string is needed; writing a long output still costs its length.

For example let M=2ᵈ and let S be the M answer bits of a fixed predicate A(n,x). To compute one bit of any deterministic postprocessing h(S), existentially supply S, check that output bit, then universally select x and compare Sₓ with A(n,x). If h takes C steps, the clock is quasilinear in M+C+T. In particular the omission scores and rank decoder from the predecessor argument can be evaluated by O(M² poly(n)) work after guessing the table. Issuing d such queries gives a d-bit decoded position. This exact batch test allows a distinct proof or set of oracle replies for each table entry. ## A consequence for actual B-step producer configurations

Use the canonical first omitted output w, with d=n or d=2(n−1), M=2ᵈ and the existing cutoff B=2^(20n) for the fixed universal multitape machine U. For every fixed rational 0<σ<5 there are constants C₀ and k with the following property under linear SAT. At every sufficiently large n, every interval [w−K,w), K≤w, contains at least

    (K+1)/C₀ − 1

positions z such that **every** description shorter than d printing z within B steps encounters a configuration at a designated checkpoint whose tape contents require a Boolean circuit description longer than 2^(σn) bits. Each z in this interval has at least one such short producer, by minimality of w. The result is about the actual runs of the fixed universal machine. Configuration circuits take a tape identifier and a binary cell address and return its symbol; head positions, control state and output bookkeeping have O(n) further bits. Restrict addresses to the O(B+n) cells per tape reachable from the initial input; the rest are blank. The term “description” counts gate indices as well as gates. [Definition of w and universal simulation convention](address-diagonal.md)

Choose k large enough that τ=20/k satisfies max(σ+τ,2τ)<5. Set q=2^⌈20n/k⌉, so B≤qᵏ≤2ᵏB. The designated times are multiples of q, with time B also checked through the padded final state. During padding, retain the configuration at B unchanged; an earlier halt also stutters. Only genuine halts by B with the claimed output are accepted. The initial configuration is explicit. Compare an endpoint with the output z by checking the output length, symbols and halt convention; for a tape output a universal address can check its prescribed contents.

Define A(n,z) to say that some short U description producing z has circuit descriptions of at most S=⌊2^(σn)⌋ bits at all these boundaries, together with its endpoint metadata. This uses a fixed number of alternations. Guess the program and final representation. To check a segment longer than q, guess q−1 representations at equally spaced interior times, universally select a child, and check the resulting pair recursively. There are k−1 levels. At the bottom, simulate q steps from the start circuit, recording its writes. A read uses the latest write if present and otherwise evaluates the start circuit. Check the final metadata and universally compare the resulting symbol at one address with the guessed ending circuit. This needs O((qS+q²)poly(n)) word operations per branch, including circuit validation, ordinary bit costs and the other fixed recursion levels. By induction, every successful check describes the real deterministic transition. Nonunique circuit descriptions for an identical tape do not affect this argument.

Consequently, under linear SAT, a RAM decides A in time 2^(αn+O(log n)) for α=max(σ+τ,2τ)<5. The resulting set excludes w by construction. For each rank payload decode the indicated omission by the batch test above, using output computation time O(M² poly(n))≤2^(4n+O(log n)). A fixed tape decoder can simulate the RAM in at most the square of its running time times poly(n), and the source U can simulate that decoder with at most quadratic overhead. Since 4·max(4,α)<20, the decoder, including its d bit queries, fits B. The one-sided omission-score bound gives the asserted local density. This argument needs no assumption on the space used by the SAT solver.

In particular, for every rational σ₀<5 with σ₀>0 the same conclusion holds with “uses more than 2^(σ₀n) work cells somewhere” in place of the circuit condition. Choose σ strictly between σ₀ and 5. Count all mutable tapes, including any rewritable output storage that can serve as working memory; read-only inputs and a genuinely write-only output stream need no such charge. A tape occupying at most 2^(σ₀n) visited work cells has a literal lookup circuit with description length 2^(σ₀n)poly(n), including cell addresses and the bounded output convention. For an ordinary write-only output stream a genuine completed d-bit output contributes only O(d) symbols. Thus a producer satisfying the work-cell budget throughout would meet the checkpoint condition. A space-only simulation theorem does not assert that the same U description has these configurations before its prescribed halt. [Williams's time-to-space simulation](https://arxiv.org/abs/2502.17779)

A linear-time SAT lower bound would follow if, on almost every position of one sufficiently long trailing interval at infinitely many lengths (missed fraction tending to zero), one could find short B-step producers with the stated checkpoint representations. Adaptive scheduling and batched verification reduce the cost of checking this premise. Neither produces the representations for these particular predecessors.
