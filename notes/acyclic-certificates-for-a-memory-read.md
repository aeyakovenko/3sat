# How many graph edges preserve the behavior of one read?

For a finite simple graph $G$ on $n$ fixed vertices, let $a(G)$ be the largest dimension of a linear subspace through zero on which the [four-cell read](affine-guards-for-writable-memory.md) is affine. We can decide exactly when an acyclic subgraph on the same vertex set preserves this number. Preserving this one number across a sequence of edge-weight thresholds on a bipartite graph can require **every edge of a quadratically dense graph**. The certificate under discussion is obtained by deleting edges and using the same read on the retained edges.

## A single unweighted graph

Write $\nu$ for maximum matching size, $\tau$ for minimum vertex cover size, and $\alpha=n-\tau$ for independence number. Write $a=\alpha+\delta$ with $\delta\in\{0,1\}$. The pointwise read theorem says $\delta=1$ exactly when the complement of some maximum independent set contains an edge. In particular this holds for every nonbipartite graph, since otherwise that independent set and its complement would give a bipartition.

The attainable values of $a(H)$ over all acyclic edge subgraphs $H\subseteq G$ on these vertices are exactly
$$
                         n-\nu,\ n-\nu+1,\ \ldots,\ n.
$$
To attain value $t$ in this interval, the minimum number of retained edges is **exactly $n-t$**. Indeed, $H$ is bipartite, so König's matching theorem gives $a(H)\ge\alpha(H)=n-\nu(H)\ge n-\nu$. More generally $a(H)\ge n-|E(H)|$, since one endpoint per edge is a vertex cover. Conversely take any $n-t$ edges from a maximum matching of $G$. Its maximum independent sets contain every isolated vertex and exactly one endpoint per edge. Their complements are independent, so $a(H)=t$.

Consequently a preserving acyclic subgraph exists exactly when $g=\tau-\nu\le1$. Indeed the condition is $g\le\delta$. At $g=0$ it always holds. At $g>0$ the graph must be nonbipartite by König's theorem and then $\delta=1$. For $g\ge2$ the smallest possible absolute error is $g-1$, attained by the maximum matching itself. This statement allows isolated vertices and does not require the retained forest to span each original connected component by a tree.

One can also ask for *both* the maximum constant-zero dimension $\alpha$ and the maximum affine dimension $a$. Acyclic preservation of both is possible exactly when $\tau=\nu$. In that case the minimum edge count is $\nu+\delta$. For $\delta=0$ take the full maximum matching $M$. For $\delta=1$ take a maximum independent set $I$ whose complement contains an edge $e$. Its complement has size $|M|$ and meets every matched edge, hence exactly once each, so $e$ is outside $M$. The acyclic subgraph $M\cup\{e\}$ still has $I$ as a maximum independent set and still leaves $e$ in its complement. With only $\nu$ retained edges a graph of matching number $\nu$ would itself be a matching and have $\delta=0$. [Lean matching and forest lemmas](../lean/AffineReadForestGap.lean) · [Exhaustive checks](../audits/acyclic_read_dimension_audit.py)

There is a polynomial-time search for the single-threshold certificate, even on general graphs. Find a maximum matching. To test for a cover of size $\nu$, introduce a Boolean variable per matched pair choosing its covered endpoint. All unmatched vertices are uncovered. For each graph edge require one of its two endpoint-selection literals, using false for unmatched endpoints. The resulting 2-CNF is satisfiable exactly when $g=0$. In that case test for $\delta=1$ by additionally requiring both ends of a candidate edge to be covered, iterating through the edges. If the first test fails, then $g>0$ and $\delta=1$. A cover of size $\nu+1$ either covers both ends of one matched pair and one end of every other pair, or one unmatched vertex and one end of every pair. Enumerate the exceptional pair or vertex and apply the same 2-CNF test. If all tests fail, no acyclic subgraph preserves $a$. The search computes the desired matching-subset size when it succeeds. The graph need not be supplied with a minimum cover. [Edmonds on maximum matching](https://doi.org/10.4153/CJM-1965-045-4) · [Aspvall, Plass and Tarjan on 2-SAT](https://doi.org/10.1016/0020-0190(79)90002-4)

## A bipartite threshold family in which every edge must remain

Take two disjoint copies of the following bipartite graph. A copy has vertices $L_1,\ldots,L_s,R_1,\ldots,R_s$. Put an edge of weight $i+j-1$ between $L_i$ and $R_j$ whenever $i+j\le s+1$. Write $G_t$ for all edges of weight at most $t$, for $1\le t\le s$. The whole graph has $4s$ vertices and $s(s+1)$ edges.

At threshold $t$ the active vertices in each copy are the first $t$ on both sides. There is exactly one matching of size $t$, containing **all $t$ newly added edges**. Every perfect matching gives a permutation $\pi$ with $i+\pi(i)\le t+1$. The sum of its $t$ left sides is $t(t+1)$, forcing equality at every position. The same conclusion applies to any subgraph that still has matching size $t$.

Suppose a single edge subset $H$ with inherited weights satisfies $a(H_t)=a(G_t)$ for all thresholds. At $t=1$ the two disjoint edges must both remain, by the matching formula above. Fix any $t\ge2$. Since $a(G_t)\le 4s-2t+1$, bipartiteness implies $\nu(H_t)\ge2t-1$. At least one of its two copies therefore has matching size $t$. In that copy, select $L_2,\ldots,L_t,R_t$ and all its isolated inactive vertices. This set is independent already in the full prefix and is maximum in the retained copy by the matching bound. Its complement contains $L_1R_1$, which was forced at the first threshold. Augment by any maximum independent set of the other copy. We obtain $\delta(H_t)=1$, so
$$
             4s-\nu(H_t)+1=a(H_t)=a(G_t)\le4s-2t+1.
$$
Thus $\nu(H_t)=2t$. Both copies contain the whole new anti-diagonal. This holds at every threshold, forcing $H=G$. In contrast, at *each threshold separately* a matching of at most $2s$ edges preserves its answer. The all-threshold lower bound even allows the proposed subgraph to contain cycles. The targets concern the contents of the read on virtual variations of a single all-zero input. On that input the physical final bit itself is always zero.

The same construction tolerates additive error. With $b$ disjoint copies on $2bs$ vertices, if $|a(H_t)-a(G_t)|\le e$ for an integer $e\ge0$, then at least $b-1-e$ copies have full matching size $t$. At threshold one, at most $e$ initial edges are missing. If $b\ge2e+2$, at every later threshold one of the full copies has its initial edge, forcing $\delta(H_t)=1$ as above. Hence $\nu(H_t)\ge bt-e$ and at least $b-e$ copies retain their entire newest anti-diagonal at each threshold. At least $(b-e)s(s+1)/2$ of the $bs(s+1)/2$ edges must remain. This count is attainable. At each successive tier omit the newest anti-diagonal in exactly $e$ copies, alternating between two disjoint groups of $e$ copies. Every omitted copy still has its full preceding matching and all other copies have their full current one. At the first tier the dimension error equals $e$. At later tiers $a(G_t)=2bs-bt+1$ and $a(H_t)=2bs-bt+e+\delta(H_t)$, so the absolute error is at most $e$ for $e\ge1$. For $e=0$ keep the whole graph. This gives the exact optimum $(b-e)s(s+1)/2$ whenever $b\ge2e+2$.

## Tight accuracy cost on one connected graph

On a single copy, the optimum edge count for additive error $e$ at every threshold is $\Theta(s^2/(e+1))$ for $0\le e$ and $s\ge4(e+1)$. All constants are universal. Here is why dropping even one matching edge cannot make arbitrarily old edges serve a new threshold.

Write $D=e+1$. At threshold $t$, any qualifying subgraph has a matching of size $m=t-d$ with $0\le d\le D$. Its selected row indices are distinct positive integers, as are its column indices. Each set of indices therefore sums to at least $m(m+1)/2$. Every edge age $t-(i+j-1)$ is nonnegative and the total age is at most
$$
               m(t+1)-m(m+1)=md.
$$
At least half the matching edges have age at most $2D$. For cutoffs $t=s,s-(2D+1),s-2(2D+1),\ldots$ down to $s/2$, these recent intervals are disjoint. Each contains at least $(s/2-D)/2\ge s/8$ retained edges and there are at least $s/(2(2D+1))$ such cutoffs. This proves the lower bound. The zero-deficit calculation is also the proof of uniqueness of the full matching. [Lean lemmas on distinct indices and total age](../lean/StaircaseMatchingWeights.lean)

For $e\ge1$, keep all edges on the anti-diagonals of weights $e,2e,3e,\ldots$ only. At threshold $t$, the last retained tier gives matching size at least $e\lfloor t/e\rfloor$, using the empty matching below $e$. Bipartiteness bounds the upward difference by the matching deficit plus one, hence by $e$. The downward difference is at most one. This costs $O(s^2/e)$ edges. For $e=0$ keep all edges to obtain the upper bound.

This order is also **optimal in the worst case over all weighted bipartite graphs** on $n$ vertices, including graphs with ties. For $e\ge1$ and each positive multiple $je\le\nu(G)$, choose $je$ matching edges at the earliest threshold with matching number at least $je$. Retain the union of these matchings. The number retained is at most $e\lfloor\nu/e\rfloor(\lfloor\nu/e\rfloor+1)/2$. If the current matching number is $r$, the retained graph has a matching of size at least $e\lfloor r/e\rfloor$. Thus its affine dimension is at most $e$ above and at most one below the target at every threshold. Keeping every edge handles $e=0$. Combining with the one-copy lower bound gives $\Theta(n^2/(e+1))$ for even $n\ge8(e+1)$, and an extra isolated vertex covers odd lengths with the same asymptotics.

## When one perfect matching is present throughout

Consider a balanced bipartite graph on $s$ vertices per side, with a specified perfect matching $M$ already present at the first threshold of interest. Then **at most $4s-3$ edges suffice for exact preservation at all subsequent thresholds**, for $s\ge1$. Only the one-bit affine correction can change once the matching fills both sides.

Label the matched pairs $L_iR_i$ and turn every other available edge $L_iR_j$ into the directed arc $j\to i$. At every threshold a minimum vertex cover selects exactly one endpoint from each pair. Writing $z_i=1$ for selecting the left endpoint, its feasibility means $z_j\Rightarrow z_i$ on every arc. Both endpoints of that same physical edge can be covered precisely when $z_i=1,z_j=0$ is feasible. If $i$ also reaches $j$, their bits must be equal. Otherwise assigning one to the forward-reachable set of $i$ realizes the required values. Therefore $\delta=1$ exactly when some weakly connected component contains more than one strongly connected component.

Retain $M$ and one ordinary forest of at most $s-1$ arcs preserving weak connectivity at every prefix by incremental edge insertion. For strong connectivity, start from singleton components. Process thresholds in order, treating all edges already available at the first threshold as the starting batch. Whenever $r$ old strong components merge, on their contracted directed graph choose an in-arborescence and an out-arborescence rooted at the same old component. These exist because that quotient is strongly connected. Keep corresponding input arcs of weight at most the current threshold. Given the previous internal strong connections, these at most $2(r-1)$ arcs make the merged component strongly connected. Over all mergers, $\sum(r-1)\le s-1$. Adding the selected earlier-weight edges retroactively preserves the proof because each prefix remains a subgraph of the original and already contains the witnesses needed for its true partitions. The retained graph thus gives the exact affine correction at every threshold in the specified range. In the triangular lower-bound family a perfect matching on all vertices first appears at the last tier.

The true load bits themselves have a much shorter computation, for *every* assignment of the input bits. In each copy find the least left index $i$ set to one and the least right index $j$ set to one. The first threshold giving a one in that copy is $i+j-1$ if both indices exist and the sum minus one is at most $s$. Take the minimum over copies. This determines all the physical read answers in $O(bs+s)$ word steps including printing them. The dimension profile of the full graph also has a closed form, $2bs-b$ at $t=1$ and $2bs-bt+1$ at $2\le t\le s$. The lower bound is specifically the price of using a subgraph of the original stores.

Related incremental matching work bounds how many changes are needed to a maintained matching as edges arrive. The certificate studied here is one fixed subset of distinct edges used at every threshold. A lower bound on the number of replacements of an edge during a computation does not imply a bound on the number of distinct edges required in such a subset. [Bernstein and Dudeja on matching with recourse](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.FSTTCS.2020.11)

The full graph is specified by just $b,s$. An unrestricted summary can encode the family parameters or the answers, so these theorems bound edge deletion as a representation. They give no superlinear lower bound in encoded SAT input bits. The triangular unique-matching calculation is elementary. Historical priority for its use with this read observable is unverified.
