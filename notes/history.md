# Checking compressed histories of an unrestricted RAM

## 2026-11-23 · What a compressed witness would buy

Suppose a deterministic RAM decides SAT on m encoded bits in O(m^d) time, d equal to 2 or 3. Seek a faster **nondeterministic** simulation of a particular hierarchy verifier. Nondeterminism is used here only in the simulating argument. The SAT subroutine is always deterministic. This distinction lets the simulator guess small circuits without paying a second application of the assumed SAT exponent.

Let a fixed nondeterministic word-RAM verifier have a time cap T on inputs of length n, polynomial in n, with word operations of Boolean complexity poly(log T). For each accepting run, record its instruction, finite registers, nondeterministic choices, and at most one memory event per row. Normalize instructions with several events to a constant number of microsteps. Explicitly initialize the input using n successive writes and pad halted runs by inert steps. Increase the clock by a constant factor and round to a power of two. The cap bounds time only. A run can touch Θ(T) different addresses.

**First test.** Supply a circuit for the chronological table, augmented with a previous-write index for each read. The initial-value case requires that no earlier write to this address exists. Otherwise check that the claimed earlier row wrote the read value at this address and that no intermediate row wrote there. Each violation can be witnessed by one or two row indices. Once these tests and the chronological transition tests pass, induction over time gives an actual run. `TraceCheck.last_iff_read` checks the previous-write characterization for each address with arbitrary value type and arbitrary initial contents.

Split the time indices into B aligned blocks of K rows each, with BK=T. An s-gate bounded-fan-in circuit for a block takes the log K offset as input and returns all bits of its row. The descriptions may vary with the input and the accepting run. For each possible pair of blocks the violation predicate can be compiled into a circuit containing O(1) copies of the supplied circuits plus poly(log T) gates. Tseitin conversion gives an ordinary explicit width-three SAT query of size (s+1) poly(log T) bits for s ≤ poly(T). A straightforward check makes O(B²) such queries. The predecessor table itself is also part of what must compress.

## Replace all-pairs checks by routing

Put one record per time step through Batcher's bitonic sorting network. Records from real events sort by (address, time), followed by dummy records. Unique timestamps settle ties. Each real record carries the operation type and value. Check the chronological transitions before sorting and check reads against the preceding record after sorting. The first read of a new address must see its initial value, taken as zero because the input was explicitly initialized. More precisely, at a new address a **read in the first record** must see zero. After any write or valid read the current value equals that record's value. Adjacent sorted records consequently suffice. This is the standard sort-and-check verification of RAM computations. [Williams, §2.1](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf) · [Jahanjou, Miles and Viola](https://arxiv.org/abs/1311.3171) · [Batcher](https://doi.org/10.1145/1468075.1468121)

In the usual iterative bitonic network, every comparison within one stage joins wires i and i XOR p for a fixed single-bit mask p. With block number given by a right shift of log K bits, the partner block is the block number XOR the high bits of p. Each block has only one partner per stage. Chronological neighbors and final sorted neighbors occupy at most two blocks per aligned block. This property holds even if every memory access in the run is adaptive. It concerns the *verification network* built after those accesses. The Lean lemma `TraceCheck.same_partner` checks the block identity at the level needed to count partners.

**Simulation lemma (conditional).** Suppose every accepted input of length n has some accepting run such that every block in the chronological table and in every layer of the verification network has a circuit of at most s gates. Assume the integer bounds are efficiently computable. Then the language has a nondeterministic decider running in

    Õ(n(s+1) + B(s+1)^d)

under the SAT hypothesis. The tilde hides powers of log T for this fixed program and fixed d.

Guess all these circuits, reject malformed encodings, and keep the same circuits throughout the verification. This costs Õ(B(s+1)) including the O(log² T) layers. For each block and comparator stage construct a circuit whose free bits are an offset. It detects an output record differing from the specified min or max of the two input records, using at most three block circuits. The ascending/descending direction and which comparator output is required are computed from the index bits. Reject if its SAT instance is satisfiable. Run the corresponding checks for the initial projection of chronological rows to sortable records, transitions including nondeterministic choices, the start and accepting end rows, and final sorted reads. Check the n initial input writes against x by evaluating their row circuits directly in Õ(n(s+1)) time. SAT query construction, guessing, and the tests fit the displayed time. A valid computation supplies a witness under the premise. Conversely, all tests passing forces the real sorting-network evaluation of the guessed chronological records, hence a consistent accepting run. Short certificates on rejecting inputs are never assumed.

**Refinement with exceptions.** Permit H explicitly stored blocks, counted over all layers including the chronological table. Guess these blocks in full. Each enters O(1) tests because the stages, pairings, and adjacent-block checks have bounded degree. For every affected test enumerate its K offsets, looking up explicit values and evaluating neighboring succinct blocks directly. This gives the bound

    Õ(n(s+1) + B(s+1)^d + H K (s+1)).

In particular a proof of near-universal block compression could suffice; it need not cover every block. The exception term accounts for evaluating neighboring small circuits. Substituting HK alone there would require a faster batch-evaluation argument.

**One concrete target.** Take T of order n¹², K of order n⁸ and s of order n², rounding the two lengths to powers of two. For d=3 the all-small cost is Õ(n¹⁰); for d=2 it is Õ(n⁸). Zero exceptions suffice in both cases. For example H≤n at these scales still gives Õ(n¹¹). A unary language can be chosen in nondeterministic time O(n¹²) outside nondeterministic time O(n^(23/2)) using the nondeterministic time hierarchy with its polynomial margin. The usual quasi-linear nondeterministic RAM-to-multitape simulation absorbs polylogarithmic overhead inside this gap (choose an intermediate excluded multitape exponent if needed). A fixed multitape verifier for this language can be implemented on the source RAM within the stated cap. If one could establish the compression premise for a verifier of **this language**, the candidate SAT algorithm would give a contradiction. Consult the exact hierarchy and model simulation separately. [Williams, Theorems 2.1 and 2.2](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

## Attack the compression premise

**Copying arbitrary data.** Take K and n to be powers of two, K≥n, and consider runs that repeatedly copy the n input bits in order. A block circuit for the copied bit contains a circuit for the entire n-bit truth table under fixing of high index bits, up to a small offset computation and constant-rate instruction interleaving. Some strings need Ω(n/log n) gates as truth tables, since circuits with g gates on log n inputs have descriptions of length O(g log(g+log n)+log log n). A short description consisting of the program and input is insufficient grounds for a circuit smaller than this. A unary hierarchy language avoids arbitrary data arriving directly on its input.

**Unary input still leaves the nondeterministic choices.** Under the same d-time SAT hypothesis one can build a *fixed* unary verifier with expensive chronological blocks on every accepting path in a range of scales. Let s be a polynomially growing, time-constructible target gate count. Guess a Q-bit truth table z for Q a power of two of order s log²(s+2). Ask whether there is a Boolean circuit of at most 2s gates computing z. Such a circuit has O(s log s) description bits. Nondeterministically checking a candidate on all Q arguments costs Õ(Qs). A standard quasilinear RAM computation reduction turns that existential test into SAT of encoded size Õ(Qs), so the hypothesized deterministic solver decides it in s^(2d) poly(log T) time. An accepting branch requires a negative answer. Counting gives a hard table for all large s since Q exceeds the description length. [Quasilinear reduction, Williams](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

Now spend the rest of the computation cycling through the certified table. Use a fixed power-of-two number of instructions per bit by padding the read, store and index-update loop. Inside any K-row block wholly within this phase, with K greater than twice a period, there is a full copy of z in a fixed data field at regularly spaced indices. Given the log Q input bits, the corresponding local index is a constant shift and addition on log K bits, of size O(log T). Thus a circuit of at most s gates for the block would project to one of at most s+O(log T) ≤ 2s gates for z. This contradicts the test on every accepting branch. A time-constructible outer loop fixes the number of repetitions, with enough iterations to occupy Θ(T) rows and with only constant-factor variation in its total length. Padding the whole computation or normalizing its clock by constant factors preserves Θ(T/K) hard blocks when the repetition phase dominates and T/K grows.

For K≥2^{c}Q with a sufficiently large fixed c, K=o(T), and s^(2d)≤T^(1−η) for fixed η>0, the construction fits in O(T) for polynomial T and polynomially growing s. For instance, T≈n¹², K≈n⁴, s≈n, d=3 meets these conditions. It gives an accept-all-unary verifier whose **every accepting history** fails the proposed cap on a positive fraction of its chronological blocks. Since chronological blocks are one of O(log² T) layer families, the count being claimed here is Ω(T/K), not a constant fraction of all layer-blocks. This directly attacks a universal argument from short unary inputs and fast SAT to easy histories. A different verifier accepts this particular language immediately. The attack leaves open a compression theorem about a suitably chosen verifier of a hierarchy language. At T≈n¹², K≈n⁸ and s≈n², the d=3 cost estimate for the attack reaches T before logarithmic factors, so this particular construction gives no refutation there.

## What survives

The sorting network reduces the number of block comparisons from quadratic in B to nearly linear, at the price of requiring compressibility of its intermediate layers. We have neither a proof that the hierarchy verifier admits those circuits nor an argument turning their absence into a lower bound on the SAT solver. This is where this approach stops. The easy-witness literature supplies a precedent for checking succinct witnesses with SAT algorithms under additional complexity assumptions. Our simulation lemma uses a separately stated block-size hypothesis. [Murray and Williams](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf)

`python3 history_experiment.py` compares the sorted-adjacency check with sequential replay on short read/write traces, including invalid traces. It also checks the claimed partner-block property of each tested network stage. These tests leave the asymptotic compression premise open.

## A second hierarchy calculation reaches the cubic block parameters

The explicit circuit-minimization test above misses the endpoint s≈n², K≈n⁸, T≈n¹² for d=3. A different construction forces hard blocks at these parameters on infinitely many accepted unary lengths. Here the underlying verifier checks the computations of a second, shorter-clock hierarchy language.

Choose a unary language A with a fixed nondeterministic multitape machine running in O(n⁷) outside nondeterministic multitape time O(n^(13/2)). Žák's hierarchy theorem supplies this gap. Simulate the fixed machine directly on a word RAM by keeping its constant number of tape-head positions in registers and using arrays for tapes. Include the initialization writes for the unary input. Pad the clock to U, a power of two of order n⁷. [Hierarchy statement, Theorem 2.1](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

For an accepting run, serialize its chronological rows and all layers of the bitonic verification network into a single binary table. Index a bit by concatenating the following fixed-width fields, with lengths computed from n.

- A layer number selects the chronological rows, the initial sortable records, or one of O(log² U) comparator stages.
- A wire number in [0,U) selects the row.
- A bit position selects one bit of an O(log U)-bit row. Pad the row width and the number of layers up to powers of two and set unused bits to zero.

The resulting truth table has power-of-two length Q = O(U log³ U). Calling a table *valid* means that all transition, initialization, acceptance, wiring, sorted-read and padding checks succeed. A nondeterministic run's guessed choice is included in its chronological row. Each failed check has an index of O(log n) bits. A circuit on that index computes the tested row and its neighbors using polynomially many gates in log n. For example, chronological neighbors use addition by one, and a given comparator stage uses an XOR mask derived from the stage. A bounded lookup table hardwired with O(poly(log n)) gates suffices for the stage parameters. Unary initialization depends only on n and the index. Reading the constant number of selected rows costs O(log n) bit queries to the serialized table. On a RAM with the table given explicitly, all checks together take O(n⁷ poly(log n)) time.

Assume the O(m³) SAT algorithm. For **any fixed constant c**, infinitely many yes lengths of A have the following property. Every valid table on that length requires more than c n² Boolean gates as a function of its bit index. Otherwise, beyond finitely many exceptions, guess a c n²-gate table circuit. Construct the circuit for a failed check using O(log n) copies of the guess. Its explicit Tseitin formula has O(n² poly(log n)) bits. With a single deterministic SAT call the nondeterministic simulator certifies the absence of failed checks in O(n⁶ poly(log n)) time. A guessed table cannot pass on no lengths, and the finite exceptions can be hardwired. The nondeterministic RAM-to-tape simulation adds a polylogarithmic factor, contradicting the choice of A. This argument also applies under the stronger quadratic SAT hypothesis.

Now fix a unary verifier for A which guesses a table of length Q and checks it **explicitly** as above. Once it has a valid table, it spends Θ(n¹²) instructions cycling through the Q bits. It reads one bit per fixed power-of-two number of instructions, with the bit recorded at a fixed point of the loop. Masking a counter gives wraparound without varying the period. The total loop length can be controlled by a fixed-size register counter and a branch padded to constant cost. A word-length constant sufficient for the stated polynomial clock is used as in the rest of this journal. Pad the final clock to T of order n¹². For K a power of two of order n⁸, the period is o(K). Every aligned K-block wholly within the cycling phase contains an entire period. The local row offset for bit j of that period has the form base + 2^p j for a fixed integer p and a fixed base for that block. Its bit circuit costs O(log n) gates, and selecting the output data bit uses a fixed row field. Thus an n²-gate circuit for such a block would compute the table in at most n²+O(log n) gates. Taking c=2 contradicts the property on the hard lengths. The cycling phase contains Ω(T/K) such blocks on every accepting path on those lengths.

This reaches the target block scales for a particular fixed verifier using a different language A from the n¹² hierarchy target. If desired, one can put A on even unary lengths and a separate n¹² hierarchy language on odd lengths, both using half-length inputs. The resulting language still excludes O(n^(23/2)) nondeterministic time by its odd-length restriction, while the corresponding verifier inherits hard cycling blocks on infinitely many even lengths. Constant rescalings of the gate cap are covered by the arbitrary constant c. A verifier can decide the A branch by its original O(n⁷) procedure. The construction therefore defeats a claim covering **every** verifier of a hierarchy language and leaves open a claim about the existence of a suitably compressible verifier.
