# The logarithmic gap in indexing an output-linear computation

**Research journal, 24 November 2026.** Suppose a deterministic logarithmic-word RAM decides explicit SAT in time $O(n^k)$, with $k=1,2,3$ and unrestricted workspace. Put $M=2^m$. A fixed uniform RAM can print an $M$-bit table from unary input in $O(M/m)$ packed word steps whose scalar lookup function requires

$$
 \Omega\!\left(\frac{M^{1/k^2}}{m^{2+3/k+1/k^2}}\right)
$$

bounded-fan-in Boolean gates for all sufficiently large $m$. The logarithmic exponents are $6$, $15/4$, and $28/9$, respectively. A circuit asked to return a full native trace row in parallel obeys the same bound with one fewer power of $m$ in the denominator. These are conditional lower bounds for the generated tables. The [earlier hard-table proof](output-linear-hard-tables.md) also handles general RAM evaluators with preprocessed advice. Here we sharpen the cost for the specific circuit model by compiling the lookup gates directly.

## A defect instance formed from a circuit

Use the bounded signed universal program and the locally accessible packed 3-CNF $F_x$ for its computation on $n_0$ input bits in $h=n_0^D$ steps, with $D$ a fixed integer greater than $k$. Put $L=\lceil\log_2(h+2)\rceil$. Use the regular padded layout with $N=\Theta(hL^3)$ encoded bits and a target SAT clock $T=\lceil C N^k\rceil$. A chronological native trace through this clock contains $T+1$ rows, each padded to a power of two $W=\Theta(L)$ bits. Each includes the controller, memory events, and the previous-touch pointers used in the earlier proof. A rejecting trace is invalid exactly when there is a local defect. A witness selects constantly many rows, potentially using a row number read from a previous one. It checks an instruction, the endpoints, an incorrectly linked touch, or two distinct touches of one address naming the same predecessor, including two null predecessors. Distinctness and chronological order force the predecessor to be the immediately preceding touch at that address. The signed verifier first guesses a scalar or full-row mode, so both tests apply to the same diagonal formula. In scalar mode it guesses a topologically ordered Boolean gate list on $m$ index bits with $g$ gates from the fixed basis, and rejects malformed descriptions. The chosen $m$ and $g$ have fixed polynomial address-range caps in $n_0$ sufficiently large for the arities below. Decode a row at time $u$ by placing $W$ copies of the *guessed* circuit into the defect predicate. Copy $j$ receives the binary address $Wu+j$. Pad the address with leading zeroes and form it by concatenation, since $W$ is a power of two. All copies have the same guessed topology. A second-stage fetch of a predecessor row takes its time bits from the first stage; the number of stages is constant. The resulting Boolean circuit has

$$
 O\big(gL+(n_0+1)\operatorname{poly}(L)\big)
$$

gates, including the test for the stated defect. Indeed every native word and address is $O(L)$ bits, and the finitely many native arithmetic operations have uniform $\operatorname{poly}(L)$-gate circuits. To fetch a true formula word of $F_x$ at a witness-dependent address, use the packed formula's polynomial-size local gate and clause templates. The constant number of template-table accesses become multiplexers of size $\operatorname{poly}(L)$. Its occasional fetches of an actual source input word can be implemented by multiplexing over the $n_0$ public bits, using $O((n_0+1)\operatorname{poly}(L))$ gates in total. The construction works for arbitrary $x$, including the self-input whose prefix describes this verifier.

Only the witness for a defect and the Tseytin extension bits are variables in the final 3-CNF. The list topology and $x$ are fixed while this explicit instance is being constructed. Each generated gate requires a constant number of clauses, each using $O(L)$ encoded bits for variable names. Each gate-list entry can be read, renumbered and emitted in polynomial-address native memory at constant cost per output word, or with the looser time bound equal to the number of written bits. For the polynomial-size templates the same time allowance, with an additive $\operatorname{poly}(L)$ factor there, suffices. The explicit instance therefore has length and construction time at most

$$
 O\big(gL^2+(n_0+1)\operatorname{poly}(L)\big).
$$

Guessing and validating the original list costs $O((g+m+1)L)$ and fits. Each outer variable bit specifying a row or a defect type is a witness bit of this one SAT call. Hardwiring the topology here avoids the overhead of implementing $W$ calls to an interpreter for a supplied circuit by a general bounded-RAM formula.

Signal if the SAT solver finds this defect instance unsatisfiable. Any signal certifies actual rejection of $F_x$, independent of the gate count. Take $x$ to be the verifier's own padded program description. A timely signal would also make $F_x$ satisfiable by the definition of the signed source, so $F_x$ is unsatisfiable. Its correct rejecting trace exists. If a circuit for the resulting table had $g\le\epsilon h^{1/k}/L^2$, giving that circuit on the honest branch would signal inside the $h$-step clock for sufficiently small fixed $\epsilon>0$. The $n_0\operatorname{poly}(L)$ cost is $o(h^{1/k})$ since $D>k$, and the fixed costs of constructing the formula, calling SAT, and interpreting this particular verifier can all be absorbed by choosing $\epsilon$. Hence $g=\Omega(h^{1/k}/L^2)$. The fixed word-width headroom and separate guest banks are those of the packed reduction. If the alleged circuit instead has time $u$ as its input and all $W$ row bits as parallel output pins, one copy per requested row suffices, so the encoded instance costs $O(gL+(n_0+1)\operatorname{poly}(L))$ and the conclusion is $g=\Omega(h^{1/k}/L)$.

An elementary obstacle applies to the proposed shortcut of using fewer black-box bit fetches. Give the touch-consistency tester two active stores with addresses $u,v\in\{0,1\}^w$, both naming null as predecessor. These event records have a defect exactly when $u=v$. Suppose an existential test for such a defect adaptively probes bits of the two address fields. On a fixed accepting branch at $(u,u)$, it must probe every one of the $2w$ input bits. Flipping an unprobed bit would preserve all replies on that branch and remove the defect. This also allows an arbitrarily long guessed certificate, since the same guess remains available after the flip. For this generic event predicate, reducing the number of address probes below order $L$ requires some change to the test, for instance extra authenticated information. The argument places no lower bound on the gate count of a construction that looks inside the lookup circuit or shares gates across several calls.

## Padding without wasting a logarithmic power

Restrict $n_0$ to powers of two, writing $n_0=2^d$. A public bound for the number of bits in the trace is $C_0 2^{Dkd}(d+1)^{3k+1}$, for a sufficiently large fixed integer $C_0$. Choose the largest $d$ for which this bound is at most $2^m$. The ratio of successive bounds is between two positive constants independent of $m$, so

$$
 L=\Theta(m),\qquad h=\Theta\big(M^{1/k}/m^{3+1/k}\big).
$$

The printer can find $d$ by comparing these integers in $\operatorname{poly}(m)$ time. The signed verifier can guess $m$ with its address range bounded by $n_0^{Dk+1}$ for large $n_0$; it need not know the printer's $C_0$. The real table fills a constant fraction of $M$ bits under the specified regular padded layout and target clock. Its $O(T)$ native steps can be simulated while writing a constant number of words per row and keeping one last-touch index per addressed word. This takes $O(M/m)$ packed steps including the zero suffix. Substitution in the last two gate bounds gives the claims at every sufficiently large arity.

## Testing universal upper bounds

The Shannon–Lupanov gate upper bound for arbitrary $m$-input functions is $(1+o(1))M/m$. For the linear-SAT table the ratio of this upper bound to the displayed lower-bound scale is $\Theta(m^5)$. The upper bound alone cannot contradict linear SAT. Applying it only to the occupied prefix, with a test for high index bits, changes this comparison by at most a constant factor here. The table occupies a constant fraction of its range. A family-specific upper bound $o(M/m^6)$, even on infinitely many arities of this family, *would* contradict the linear-SAT hypothesis. [Frandsen and Miltersen, explicit proof of the gate upper bound](https://tidsskrift.dk/brics/article/view/21875)

For [the coded version promising very small prediction bias](biased-hard-table-lookup.md), there is a universal approximation bound as well. Split the $m$ query bits into a high block index of length $m-\ell$ and a low position of length $\ell$. Within each block, normalized Fourier coefficients of the Boolean sign function have squared sum one. Some signed parity on the low bits therefore agrees with it on at least $1/2+2^{-\ell/2}/2$ of that block. Hardwire the $\ell$ parity-mask bits and the sign as $\ell+1$ Boolean functions of the high bits, then compute the selected parity. The gate upper bound just cited gives a combined size $O((\ell+1)2^{m-\ell}/(m-\ell)+m)$ when $m-\ell$ grows. For fixed $0<\rho<1$, take $\ell=\lceil(1-\rho)m\rceil+C_2$, with the fixed $C_2$ large enough that the gate count fits $M^\rho$. Every $M$-bit table thus has some such predictor of uniform agreement at least $1/2+c_\rho M^{-(1-\rho)/2}$, for a positive constant $c_\rho$. Any family-wide upper bound $1/2+M^{-\delta}$ against all these circuits requires $\delta\le(1-\rho)/2$. The smaller bias exponents established for the coded tables satisfy this necessary condition.

There is a separate obstruction to a proposed *universal* speedup at the quadratic or cubic power. Suppose every fixed uniform packed printer taking $O(M/\log M)$ steps on unary length $M$ had output-index circuits of size $M^{\beta}\operatorname{polylog}M$ at every sufficiently large arity. Then for each rational $c>0$, every deterministic multitape language decidable in $O(2^{c r})$ time on $r$ input bits has circuits of size

$$
 2^{(1+c)\beta r}\operatorname{poly}(r).
$$

For the reduction, enumerate all $2^r$ inputs of a length and simulate the tape decider from its initial state on each, collecting one answer bit per input. Tape heads and the visited tape arrays take constant RAM operations per transition. Resetting the used region between runs can be charged to the number of cells visited, or avoided with run tags; writing and incrementing the input costs $O(r)$ per item. The total is $O(2^{(1+c)r}\operatorname{poly}(r))$ steps. Put those answer bits in the first $2^r$ table positions at printer arity $m(r)=\lceil(1+c)r\rceil+C_1\lceil\log_2(r+2)\rceil$ for a sufficiently large fixed $C_1$. On other arities the same printer writes zeroes. This arity map is strictly increasing and invertible by a search in $\operatorname{poly}(m)$ time. Its packed output budget covers all simulations and the zero suffix. Hardwiring leading zeroes in its assumed lookup circuit recovers the language at length $r$ with the displayed gate bound.

In particular $c=1$, $\beta=1/4$ would imply $\mathrm{DTIME}_{\rm tape}(2^r)\subseteq \mathrm{SIZE}(2^{r/2}\operatorname{poly}(r))$. At $\beta=1/9$ the conclusion is $\mathrm{SIZE}(2^{2r/9}\operatorname{poly}(r))$. No contradiction with an unconditional circuit lower bound is derived. These implications apply when the proposed upper bound holds for all printers and all sufficiently large arities. An argument exploiting the particular rejecting computation would bypass that universal requirement.
