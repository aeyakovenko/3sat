# A common distribution of SAT instances for all sound short certificates

**Research journal, 24 November 2026.** The earlier signed cube tested one particular solver. A second solver could recognize that cube and answer parity. Here one generator tests all programs up to a growing description length, including incorrect ones. The generator needs a fixed reference solver of the hypothesized speed but takes no target solver as a parameter. At every sufficiently large scale, almost every seed gives two formulas of opposite truth values. On these pairs *every* admitted, sound program needs more than the stated time to certify even one verdict, including when it gets the seed and the proposed truth bit for free. This gives common hard inputs for locally decodable descriptions of actual runs. None of the time thresholds for verdict checking exceeds linear in the encoded length. ## The certificate model and two choices of parameters

Assume a fixed deterministic algorithm $B$ for the packed 3-CNF encoding has time $O(N^d\log^a N)$ for $d\in\{1,2,3\}$ and fixed $a\ge0$. Fix a large integer scale $H$ and put $L=\lceil\log_2(H+2)\rceil$. A seed $r$ has $k$ bits. An additional bit $b$ selects a formula $F_H(r,b)$ of length $N=\Theta(HL^3)$; changing $b$ changes one designated literal sign. The fixed generator writes a whole formula in $O(N\operatorname{polylog}N)$ time given its parameters. The generator does not need to run $B$ to write those bits.

An offer is a computation of a binary program $e$ with nondeterministic guesses, receiving $H,r,b$ and random read access to $F_H(r,b)$. It signals the verdict $b$ within $M$ steps. A certifier for either sign can read $b$ and withhold a signal when its certified sign differs. Time includes reading or guessing the proof and running the verifier. Registers and writable storage start in a specified state. There is no space quota. A program is **sound at this scale** if all its timely offers on all seeds and both pins give the true SAT verdict. Soundness on all formulas suffices. In particular the program may be incomplete, or even have fresh nonuniform advice built into its code at each scale, provided the total code length and scale-wide soundness hold.

For all sufficiently large $H$ there is a set of at most $2^{\ell+1}-1$ exceptional seeds. For **every other seed**, simultaneously for both pins and all sound programs of length at most $\ell$:

1. $F_H(r,b)$ has SAT truth $b$.
2. There is no offer within $M$ steps. This applies equally to satisfiable and unsatisfiable inputs.

Here are two settings. Increase the fixed positive integer $K$ to pay all the polylogarithmic factors in the proof. Clocks and integer roots can be rounded down.

| Setting | Certificate time $M$ | Seed bits $k$ | Program bits $\ell$ |
| --- | --- | --- | --- |
| Scan a small program list | $\lfloor H^{1/d}/L^K\rfloor$ | $L^2$ | $\lfloor\log_2 L\rfloor$ |
| Guess the program | $\lfloor H^{1/d^2}/L^K\rfloor$ | $\lfloor M/4\rfloor$ | $\lfloor k/2\rfloor$ |

In the first setting the failure probability of a uniform seed is at most $2L/2^{L^2}$. In the second it is at most $2^{1-\lceil k/2\rceil}$. In particular, for $d=1$ the second setting charges almost linearly many steps and permits almost linearly many advice bits up to a fixed logarithmic loss. A single good seed works for all these programs. Statements about density use the displayed seed distribution, which the generator can sample, at *each* scale. They do not give a density bound among uniformly random CNFs.

## A first offer is a counterexample to its own sign

Order the $k$-bit seeds lexicographically. Let $A(e,r,b)$ mean there is a timely offer as defined above, **whether or not the program is sound**. For this one scale define

$$Q(r,b)\ \Longleftrightarrow\ \exists e,\ |e|\le\ell:\ A(e,r,b)\ \land\ \neg\exists u<r,\ c\in\{0,1\}:\ A(e,u,c).$$

There is no recursive call to $Q$ at an earlier seed. The earlier-seed test runs an untrusted program on the syntactically specified formula. Set the bounded source to accept precisely if $b\mathbin{\mathrm{xor}}Q(r,b)$ is true. Its Cook formula therefore satisfies the same equation. If a program ever offers, take its least offering seed $r$. At every pin where it offers on that seed, $Q(r,b)$ is true. The formula has the opposite verdict and the offer witnesses unsoundness. In particular a sound program never offers its proposed sign $b$ anywhere on this scale. A seed with $Q(r,b)$ true for either pin is the least offering seed of some code; each code has at most one such seed. Outside this exceptional set, truth equals $b$ and no sound certifier can certify the true sign in time. At exceptional seeds truth and $b$ may differ for just one or both pins. ## Charging the two searches and the formula's self-reference

Use the fixed bounded universal RAM and packed local formula generator. The public input to the universal machine contains a delimited checker text $t$, size metadata, $r,b$, and deterministic padding if needed. The checker run on this input always requests the formula for the universal machine with this very text as *data*. Fix $t$ to the checker's finite text. Simulating an offer accesses the bits for $(t,H,u,c)$ by the rectangular indexing rules; it does not simulate the source on $u$. The universal machine's formula is a bounded computation tableau and is defined independently of what its program answers. Metadata and padding use separate fields from the signed bits. Put $b$ on a single initialization wire with a signed pin. The fixed-format header, clause count and clock are identical across all seeds at the scale. Use, for example, at least $\lceil H^{1/10}\rceil$ zero padding bits so that the native word width is $\Theta(\log H)$ even for the $L^2$-bit seeds. Padding is an indexed string of zeros, never materialized in a short SAT query. Round dimensions and add dummy slots as in the packed construction. [Local access and bounded-clock interpreter](packed-band-transfer.md)

Use a fixed guest instruction set and guest word width $C L$ for program enumeration. Text has an externally supplied length; decode valid instructions into a randomly indexed array in $O((|e|+1)\operatorname{poly}(L))$ time and treat invalid text as having no offers. Fixed program constants and fixed additional words per address can be emulated in this convention. For a particular wider-word solver or checker, one can use a binary address trie with $O(\log H)$ steps per load or store and a fixed number of limbs for each guest word. Only polynomially many trie nodes are allocated in the bounded computation. This avoids using a fixed host word as a direct address into every possible wider guest bank. The prescribed starting constants, length metadata and separate initialized scratch banks are part of the interface. A program may itself call another SAT algorithm; all of its work counts against $M$.

For a fixed $e$, the current offer is a nondeterministic bounded computation. The test for a prior offer guesses $u,c$ as well as the branch and checks $u<r$. Either test costs $O((M+k+|e|+1)\operatorname{poly}(L))$ on the host, including all virtual input accesses and setup. Its physical public input contains the small parameters, seed and program. In particular an instance for a prior offer contains neither the full current formula nor a list of all earlier seeds. Materialize its packed Cook formula and run $B$. For an overall size $S=M+k+\ell+1$, either yes/no answer takes $O(S^d\operatorname{poly}(L))$. The exponents of these logarithms depend on the fixed interpreters, reductions and $a,d$; choosing a larger fixed margin $K$ does not increase them. The logarithms of clocks at all levels are $O(L)$ and $\log S=\Theta(L)$ in both displayed regimes.

For the small list, run both tests independently for each of fewer than $2L$ codes and take their prescribed Boolean combination. All calls can reuse scratch by a fresh-bank simulation or timestamping with charged writes. Total work is $O(LS^d\operatorname{poly}(L))=o(H)$. For the large list, a nondeterministic outer test guesses $e$ and a current offer, then uses one deterministic call to $B$ to exclude all earlier offers for this $e$. Decide this outer test by materializing one more bounded-computation formula and calling $B$. This takes $O(S^{d^2}\operatorname{poly}(L))=o(H)$. No alternation remains in the actual signed source. Starting at a uniform sufficiently large scale makes the signed equation exact there, and the first-offer order resets at every scale. There is no retirement from a small scale that could corrupt a later one.

## What this says about a solver's actual memory

Suppose $d=1$ and fix *any* correct near-linear solver and any fixed clocked polylogarithmic-time memory decoder. Use the small-list distribution. There is a constant $D$ (allowed to depend on these fixed programs) such that for all sufficiently large scales, on **both** formulas from every good seed, the cumulative snapshot-description length up to the verdict, charging $1+s_t$ at native instruction $t$, is at least $N^2/\log^D N$. Here $s_t$ is the shortest string with which the decoder answers every address of the actual writable memory given the formula and time $t$. If none exists, it is infinite. Neither the solver nor the verifier is required to find shortest strings. The same good sets work for all fixed programs once they fit the growing list. A small fallback for easy formulas is part of the tested computation.

To see this, a fixed nondeterministic certifier guesses the endpoint controllers, times and ordinary checkpoint strings. Choose cuts of minimum $1+s_t$ in disjoint windows of $w=\lfloor H/L^{J}\rfloor$ native instructions and include start and halt. The standard boundary calculation bounds total chart bits by $(1+\sum_t(1+s_t)/w)\operatorname{polylog}N$, and the longest gap is at most $2w+1$. Runs of fewer than $w$ steps need no internal snapshot. A small cumulative cost would therefore give a chart fitting the certificate budget. For a proposed block, replay from its start decoder lazily, with an overlay for subsequent writes. A defect guesses a block and an address on which the ending memory disagrees with the next claimed snapshot, or a failed control, initial or terminal condition. At the first block use true zero memory; require no memory equality after the final signal. Testing a guessed defect takes $(w+\text{chart bits}+1)\operatorname{polylog}N$ steps, including virtual formula access, sparse overlay and arbitrary advice accesses. Encoder, decoder and native clocks are fixed and totalized. Apply $B$ once to exclude any defect. Induction over the blocks gives the genuine sign even on adversarial charts. Take $J$ larger than $K$ and all overheads of this fixed certifier, then take $D$ large enough to put both the work and chart terms below $M$. This would certify a true verdict at a good seed, which was excluded. This proof also gives the windowed live-read bound with the extra intervening-write check if one uses the [live-read verification](live-value-replay.md). The snapshot statement alone needs only one defect search. It gives no upper bound on the descriptive complexity of a fast solver's memory.

For $d=2,3$, the small-list setting also gives $\Omega(N^{1/d^2}/\operatorname{polylog}N)$ gates for the *joint* actual controller and last-writer stream of a fixed correct $O(N^d)$-time solver on every good pair. A certifier guesses the gate list and uses $B$ on the single existential local-defect test for this annotated stream. With $s$ gates its work is $(s+\operatorname{poly}(L))^d\operatorname{poly}(L)$; virtual formula input needs only the $L^2$ seed bits and short parameters when embedded in the circuit. A small enough stream would yield an offer below $M$. On the positive formula *every* satisfying assignment also needs $\Omega(N^{1/d^2}/\operatorname{polylog}N)$ bounded-fan-in gates to give its bits from a variable index. A certifier guesses a smaller purported assignment circuit, asks $B$ whether any clause is falsified, and signals SAT exactly if none is. Clause addressing is a Boolean circuit of size $\operatorname{poly}(L)$ here because the entire seed is only $L^2$ bits and the rectangular generator uses short indexed arithmetic. Guessing the description and deciding the falsified-clause query costs $(s+\operatorname{poly}(L))^d\operatorname{poly}(L)$. This also works at $d=1$. The bounded source itself has a real accepting trace on a good positive pin, but substituting the answers of its internal SAT calls does not certify the intermediate steps of that trace. The direct construction from the full trace costs more than the excluded gate budget. For register streams the individually targeted one-sign bounds achieve better exponents; the distribution and simultaneous quantifiers are the gain here. ## Trying to turn the distribution into a contradiction

A deterministic small program can name an exceptional seed. Hardwire a program that offers on both pins only when the seed is all zeros. Then both formulas there have truth $1-b$. More generally, use a fixed compiler prefix with an arbitrary binary payload of $j$ bits and offer only on the seed equal to that payload followed by zeros. Programs of length $j+O(1)$ force $2^j$ distinct exceptional seeds, so the upper bound has the right order in $2^\ell$ for the specified length-delimited enumeration. These programs are intentionally incorrect on their first offers. Uniformly sampling a seed gives a highly accurate predictor by returning $b$, but a sound certifier must rule out even its exceptional inputs. In particular any short bounded program that can cheaply name or recognize just one selected seed, offer on a fixed pin there, and withhold on all other seeds forces that seed to be exceptional. Allowing nonuniform advice of $k$ bits would let programs target every seed by this argument. This explains the strict separation between program length and seed length in the second setting.

A deterministic search can find an ordinary good seed in the small-list setting by determining each program's lexicographically first offer using $O(k)$ prefix-existence queries to $B$ and picking an unlisted seed. It pays for those solver calls. The existence of this selector does not give a certificate executable within $M$. Likewise an accurate predictor alone gives neither a proof that a particular seed is good nor a short description of the tested solver's actual memory. These are concrete failed conversions to the unrestricted linear-time target.

Resource-bounded instance complexity already studies small sound programs that can abstain; immunity theory studies the lack of easy infinite subsets. Our argument uses a first witness to each program's failure, at a fixed scale, on a samplable family of syntactically explicit SAT inputs. We have not established priority for this combination.
