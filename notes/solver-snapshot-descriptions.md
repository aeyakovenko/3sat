# How short can the actual snapshots of a fast SAT solver be?

**Research journal, 24 November 2026.** Fix a correct deterministic SAT solver on the packed logarithmic-word RAM. Suppose its worst-case time is $O(N L^a)$, where $N$ counts bits in the explicit formula, $L=\max(2,\lceil\log_2(N+2)\rceil)$ and $a$ is a fixed nonnegative integer. Fix a deterministic decoder that, given the same formula, a shared string, a checkpoint index and a work address, returns one memory word in $O(L^d)$ steps for a fixed nonnegative integer $d$. The decoder gets random access to the formula and the packed string. There is no bound on the solver's workspace and no cost or uniformity requirement for finding the string.

**Claim.** Pad the actual computation to a fixed valid clock $T=\lceil C N L^a\rceil$ by making halting states idle. Split its guest steps into $P=\lceil L^{2a+d+7}\rceil$ equal intervals up to rounding. There is a solver- and decoder-dependent family of arbitrarily long **unsatisfiable** formulas on which every shared string that decodes all writable words at all internal boundaries has length
$$
  \Omega\!\left(\frac{N}{L^{a+4}}\right)\quad\text{bits}.
$$
A missing representation has minimum length infinity. The implicit positive constant may depend on the two programs and the clock. The intervals refer to the specified solver running on the ordinary formula. They do not refer to the machine used to generate it. [Machine, encoding and diagonal language](packed-band-transfer.md)

At linear time with constant-time word decoding, the statement uses $\lceil L^7\rceil$ intervals and requires $\Omega(N/L^4)$ bits in total. There is also a single-snapshot consequence. Fix any decoder for independent descriptions, give its packed descriptions an offset directory, and use a wrapper that calls it on the selected substring as a read-only view. For strings within the budget being ruled out, the directory costs $O(PL)$ bits and the wrapper has the same query exponent. Apply the claim to this wrapper. On its hard family, at least one internal snapshot needs $\Omega(N/L^{3a+d+11})$ bits for the fixed independent decoder, hence $\Omega(N/L^{11})$ for $a=d=0$. This family may depend on the wrapper. Allowing unlimited decoding time would permit an empty string and replay from the beginning.

## Checking a description without trusting it

The certificate guesses one shared bit string $Z$, its length, and $O(P)$ words of controller states including registers and instruction pointers. The address space and word width of the solver are known from the formula length. Writable memory starts at zero. The check for the last interval needs only a rejecting halt and the final controller. The internal memories can all share the same $Z$. Lengths and addresses use their fixed public domains. The checker bounds the decoder clock, starts its scratch blank per call, and uses a fixed answer on invalid accesses or timeout. A worst-case bound on well-formed descriptions suffices when its constant is included in that clock.

A defect witness selects an interval and an arbitrary legal address, or selects a violation of controller format, initial conditions or final verdict. Replay that interval from the claimed controller. Each guest read looks first in an initially empty table of writes made during this replay. Failing that it uses the start decoder, or zero for the first interval. On a write it sets both the local value and its presence bit, including when the value is zero. At the end compare the controller with the claim. At an internal endpoint compare the value at the selected address, obtained by the same lookup, with the **next** decoder. The comparison applies even if the interval never touched that address. The tables can use directly addressed zero-initialized host banks, with the native range checked at every guest access. For a decoder needing scratch, tags that increase with each call give fresh blank scratch in constant overhead per access. The replay uses the actual read-only input throughout.

If there is no defect, every legal address agrees across the first endpoint. Together with equality of controllers this identifies the entire next configuration. Induction identifies every configuration in the list and forces a real rejection. An honest list for a rejecting run has no defect. A checker limited to the replay's read addresses would permit a forged change to an untouched word at an endpoint, followed by its first use several intervals later. Testing a freely selected address removes this failure. [Checkpoint semantics in Lean](../lean/SolverSnapshotReplay.lean)

## Accounting for the formula, the decoder and the string

Let $x$ have $n_0$ bits, $h=n_0^2$, and take the bounded nondeterministic interpreter $U$ from the packed transfer. Let $F_x$ be the explicit 3-CNF for its acceptance within that clock. Use the transfer's regular padded layout with $N=\Theta(h\log^3 h)$ bits. Padding to this size by indexed tautological clauses is also possible. All logarithms here are comparable to $L$. A packed word of $F_x$ costs $O(1)$ operations after a setup of size $\operatorname{poly}(L)$ from $x$. For the checker, the input therefore consists of $x$, the claimed controllers and $Z$, together with a fixed-layout header. It does **not** include a copy of the $N$-bit formula. A read of $F_x$ by either the solver or the decoder uses this local generator. Generating the templates inside the bounded verifier costs $\operatorname{poly}(L)$ time. [Local packed formula](packed-band-transfer.md)

Write $s=|Z|$. A verifier for existence of a defect has public length $m=O(n_0+P+\lceil s/L\rceil)$ **words** and bounded time
$$
 R=O\big((T/P+1)L^d+\operatorname{poly}(L)\big).
$$
The last SAT reduction compiles this verifier, even when $m>R$, to $O(RL^3+mL^2+\operatorname{poly}(L))$ **bits**. It uses a bounded-degree superconcentrator to authenticate the subset of public words the transcript reads. Construct the instance and run the hypothesized SAT solver on it with unrestricted workspace. Its verdict tells the recognizer for rejection whether there is a defect. The time on a branch guessing an $s$-bit string is at most
$$
 O\big((T/P+1)L^{a+d+3}+(n_0+P+\lceil s/L\rceil)L^{a+2}+\operatorname{poly}(L)\big)
   = O(h/L+s L^{a+1})+o(h).
$$
Here $T=O(hL^{a+3})$, and $P=L^{2a+d+7}$ up to rounding. Guessing the packed words is included. The solver used to decide defects sees an ordinary materialized SAT instance and may use as much memory as its clock allows. [Last-stage construction and input cost](materialized-input-census.md)

## Why even one short honest branch gives a contradiction

Define one nondeterministic program $V$ on $x$. It guesses a length $s\le N$, a string of that length, and the controllers. It signals success precisely if the validity checks pass and the deterministic SAT call reports no defect. Guess the length first, then allocate and process only its actual number of words. No accepting branch exists if $F_x$ is satisfiable, by correctness of the solver and soundness of the checkpoint test. For every honest short description of a rejection there is a successful branch within the displayed length-dependent clock.

In the interpreter convention, encode $V$ so that this success is the halt observed by $U$ (called a rejecting branch of the encoded opponent in the transfer). All other branches halt in the opposite sign. At each sufficiently large padded length let $x$ consist of this fixed program description followed by padding. If $U$ observes success within its clock on $x$, then $F_x$ is satisfiable by construction, while that very branch proves the solver rejected $F_x$. Hence $F_x$ is unsatisfiable and $U$ observes no such branch. The interpreter on this one fixed description has a constant overhead per simulated instruction. Take a sufficiently small fixed $c>0$. If an honest $s\le c h/L^{a+1}$ existed, the branch above, **including interpretation**, would finish within the clock for sufficiently large $n_0$. This contradicts the preceding sentence. Since $h=\Theta(N/L^3)$ we obtain the claimed lower bound. The cutoff $s\le N$ retains all strings relevant to this contradiction. The wide host can be fixed in advance as in the transfer: actual guest calls, pooled strings and graph arrays have polynomial address bounds independent of the host width constant. The source's full-width addresses appear as data in Boolean records.

This gives one formula at each sufficiently large **source padding length**. The construction does not give a formula at every SAT bit length. Its soundness uses costs on an individual honest branch, so a large purported certificate on another branch does not affect the conclusion. The unconditional theorem used here is the bounded complementary diagonal principle on the specified RAM. A solver could satisfy the conclusion and still take linear time. Proving an upper bound on its minimum locally decodable description on these formulas would require a separate argument.

## Restricting decoder queries to words that get used

There is a related version for decoders that return a **source block as well as a value**. Require correct answers only on real incoming reads, those made before any same-block write to their address. An answer is the last strictly earlier block that wrote the address and its last value there, or the initial marker and zero. The decoder receives the consumer block and address. No promise is made about its other answers or about a word that is already dead. The same $P$ and the same $\Omega(N/L^{a+4})$ bound for the shared bits follow for every fixed decoder of this kind.

For verification, tentative replay of each block uses its local writes and the incoming value returned by the decoder. A defect may select one read slot in a consumer block. Replay the block to find out whether this is an incoming read and, if so, its address and claimed pair. For a noninitial source, require a legal earlier index, replay its block, and check that its final write to this address has the claimed value. For the initial marker require zero. A further choice of any intervening block checks that it never wrote this address. All earlier blocks count as intervening in the initial case. Check the boundary controllers as before. Each defect test replays only a constant number of blocks. Correct true incoming answers suffice for completeness, because starting from each true controller these replays follow the true trajectory. For soundness, induct on the first putatively false incoming read. All past blocks are genuine by induction, so the source and intervening-block tests identify its exact true value, also handling repeated writes of zero. Thus the same length-dependent clock and signed diagonal apply. A decoder giving only values on incoming reads does not supply this verifier's source index. The explicit list variant gives a lower bound on the number of distinct producing blocks and addresses. [Producer records and proof](solver-cross-block-writes.md)

## Requiring just values actually read

A further variant removes the obligation to name the producing block. The decoder now needs to return only the correct value on each **actual** pair $(i,v)$ where block $i$ reads $v$ before its first local write to $v$. All answers on other pairs may be arbitrary. For this interface use $P=\lceil L^{3a+d+10}\rceil$ intervals. On a solver- and decoder-dependent family of unsatisfiable formulas every valid shared string has length
$$
 \Omega(N/L^{2a+7})\quad\text{bits}.
$$
In particular this forces $\Omega(N/L^7)$ bits across $\lceil L^{10}\rceil$ intervals for a linear-time solver and constant-time word decoder, even if large regions of its memory are never read again.

Here are the two verifier calls needed for this saving. Fix a pool and the boundary controllers. Independently replay any requested block, using local writes followed by the supplied incoming value. These deterministic tentative transcripts define all their writes even when the pool is false. Guess a consumer block $i$, a read slot, and a putative earlier writer $j<i$, allowing the sentinel $j=0$ when blocks start at one. Replay the consumer and require that the slot is an incoming read of some $v$ with returned word $w$. For $j>0$, replay block $j$ and require its last write to $v$ exists and differs from $w$. For $j=0$, require $w\ne0$. In both cases test whether **some** $k$ strictly between $j$ and $i$ wrote $v$ by guessing $k$ and replaying it. Materialize a SAT instance for this last test, and accept the alleged defect exactly when its verdict is UNSAT. Separate defect types handle controller and halt failures. A second SAT call decides existence of any accepted defect.

If a pool gives the true values on real incoming reads and supplies true controllers, every tentative block is genuine, so all defect claims fail. Conversely, if there are no defects, each tentative incoming read must agree with the last earlier tentative write, or with initialization. Otherwise its true last writer in the tentative transcripts is an admissible defect witness, with no intervening writer. Chronological induction now authenticates every step and the final rejecting verdict. This argument never tests what $G$ returns on a word the tentative block passes over. [Finite last-writer semantics](../lean/CrossBlockProducers.lean)

With $R$ and $m$ as in the first verifier's accounting (using the new $P$), the search over $k$ costs $O(R)$ steps before reduction. The deterministic time to check its answer is $O(RL^{a+3}+mL^{a+2}+\operatorname{poly}(L))$. That calculation includes writing its explicit SAT instance. The next existential verifier can therefore guess the consumer and writer and decide that test within the same clock, with $O(m)$ public words. Materializing its own instance and running the solver costs
$$
 O(RL^{2a+6}+mL^{2a+5}+\operatorname{poly}(L)).
$$
All machines used by these two reductions are fixed. The known length of this branch's string determines $m$ before either reduction is built. The replay budgets and intermediate clocks are polynomial in $h$ and at least $h/L^{O(1)}$ when padded to the displayed replay allowance. Thus their word sizes and logarithms remain comparable, including for false guesses. Since $T=O(hL^{a+3})$, the first term is $O(h/L)+\operatorname{poly}(L)$. The part of the second term depending on $s$ is $O(sL^{2a+4})$. Apply the same one-branch diagonal with $s\le c h/L^{2a+4}$ to obtain the stated bound. For comparison, a program that writes zero to many fresh cells in one block and reads them back in another has many distinct cross-block producers, yet a constant-zero decoder answers all those reads with an empty pool. This illustrates what the value-only test rules out. The different interfaces use different grids and may give different hard families.

## A coarser grid for shared and independent descriptions

**Research journal, 24 November 2026.** Fix the solver, its valid padded time clock and the decoders as above. There is a sufficiently large fixed integer $K$ such that on the equal-interval grid
$$
       P=\lceil K L^{2a+d+6}\rceil
$$
one unsatisfiable formula at each sufficiently large source padding length has both properties below.

* One pool decoding all internal memories requires $\Omega(N/L^{a+4})$ bits.
* The sum of the minimum lengths of independently chosen descriptions of the internal memories is $\Omega(N/L^{a+3})$ bits. In particular one needs $\Omega(N/L^{3a+d+9})$ bits on its own.

Here independent means that each row can be chosen separately, with its fixed decoder receiving that row and its original time or grid index. Both decoders have word-query time $O(L^d)$. For linear time and constant-time lookup these are $K L^6$ intervals, total bounds $\Omega(N/L^4)$ and $\Omega(N/L^3)$ respectively, and an individual bound $\Omega(N/L^9)$. The large constant matters in this grid statement.

Write $H=\Theta(n_0^2)$ for the interpreter deadline, $N=\Theta(HL^3)$, and $T=O(HL^{a+3})$ for the padded solver clock. Use a **fixed** recognizer that guesses a grid size or a schedule, and may use either the shared-pool defect check or the independent-row defect check. In each mode no successful branch on any schedule can certify a false rejection. The independent-row evaluator used below is fixed in advance too. The program does not contain $K$ or the small payload constants. Its own bounded-interpreter formulas and its interpretation constant are thus fixed before choosing any of them. At the intended grid its maximum gap is
$$
       G\le \lceil T/P\rceil=O(H/(K L^{a+d+3})+1)
$$
with absolute-in-$K$ implied constant. The bounded-computation templates and defect simulators admit all these schedules with the same program constants. In the shared-pool branch the materialized defect check costs $O(H/K+sL^{a+1})+o(H)$ for an honest $s$-bit pool, by the accounting above. Choose $K$ large after fixing the interpreter constant and then the constant on $s\le\epsilon H/L^{a+1}$ small. This would put the recognizer's signal within the deadline. The self-input diagonal therefore excludes such a pool. [Materialized public-input cost](materialized-input-census.md)

For independent rows use the bulk selector. With $S'$ total supplied bits, $u'$ their maximum row length, and fixed $O(L^d)$ decoder time, its branch time on this grid is
$$
 O\big(H/K+(S'+u'L+P L)L^a\big)+o(H).
$$
This bound includes guessing the descriptions and constructing the decision instance. The $u'L$ term prevents simply substituting an assumed small sum into the formula. Deleting heavy rows can also create long replay gaps on this coarser grid. [Bulk selection, formula (1)](bulk-snapshot-selection.md)

Suppose the independent minimum lengths sum to $S\le\eta H/L^a$. Call a row heavy when its length exceeds $v=\sqrt\eta\,H/L^{a+1}$. There are at most $r=\sqrt\eta L$ heavy rows. Keep light descriptions unchanged except for a mode header. For each heavy time, copy the nearest preceding light description and its actual original time or index, or use the initial zero array if there is none. Add a dictionary giving the final value of every address written since that base time. The distance is at most $rG$. Zero overwrites are explicit entries. A fixed evaluator first tests membership and otherwise invokes the original decoder at the base time and original row length. This reconstructs the actual memory for every queried address, independently of how often the solver changed it.

For precision, a static dictionary of $t$ such address/value pairs uses $O((t+1)L)$ bits and constant lookup time with unrestricted preprocessing. Hash the $w$-bit keys to a power-of-two number of bins of order $t$ by the high bits of a random odd word times the key modulo $2^w$. Collision probability is at most twice the inverse bin count: the modular difference is uniform among residues of its fixed two-adic valuation and must lie within one bin-width of zero in either direction. Some choice has $\sum_j t_j^2=O(t)$, where $t_j$ are the occupancies. In each nonempty bin hash again into a power-of-two table of at least $4t_j^2$ slots; the expected number of colliding pairs is less than one. If a requested hash table would exceed the key universe, index that table directly by the key within the same space allowance. Store the two-level parameters, keys, occupied flags and values, and compare the queried key. Empty and singleton bins have direct encodings. Fixed word-width headroom accommodates the tables and their offsets. Decode length fields and switch modes in constant time. An honest branch guesses this representation; it need not build the dictionaries. Malformed representations are totalized using the existing clock and range conventions.

There are $O(rG)$ patched addresses per heavy row. This gives
$$
 \begin{aligned}
 S'&=O(S+r v+r^2G L+P L)=O(\eta H/L^a)+\operatorname{poly}(L),\\
 u'&=O(v+rG L+L)=O(\sqrt\eta\,H/L^{a+1})+\operatorname{poly}(L).
 \end{aligned}
$$
Indeed $r^2G L=O(\eta H/(K L^{a+d}))+\operatorname{poly}(L)$ and $rG L=O(\sqrt\eta\,H/(K L^{a+d+1}))+\operatorname{poly}(L)$. The replacement rows meet the same query exponent. Choose $K$ for the worst constant in the two checks. Choosing $\eta$ sufficiently small now makes the independent branch finish within the interpreter deadline as well. This contradiction proves the sum bound, and division by the number of internal times proves the single-row bound. The statements concern the specified actual rejecting traces and leave unrestricted SAT time open.

Lean verifies the effect of overlaying the latest write at each patched address, including writes of zero. It also bounds the patched row sizes individually and in total given the finite gap and heavy-row caps. The static dictionary, uniform reduction and diagonal timing are manuscript arguments.
