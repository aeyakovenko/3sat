# Local defects in a portfolio of clocked solvers

**Research journal, 24 November 2026.** Given $k$ clocked candidate programs, can a fixed subset decide SAT by taking their disjunction? On CNFs of encoded length at most $n$, nonexistence has a certificate consisting of at most $k$ deletion roots and one true terminal. For canonical CNF, that terminal is the empty conjunction. A two-sided version for alternating games gives an online decision procedure that charges at most one failed descent per removed component across the entire input stream. This extends the [local check for a single solver](checking-a-solver-with-its-own-verdicts.md).

## Disjunction on SAT

Use a restriction-closed domain $D_n$ of delimited CNFs of length at most $n$. Delete satisfied clauses and falsified literals when fixing the first occurring variable. An empty conjunction is true and an empty clause makes a CNF false. At a nonterminal the SAT value is the OR of the two child values. Write $U_I(F)=\bigvee_{i\in I} A_i(F)$ for the disjunction of the candidates retained in $I$.

Begin with every candidate and delete $i\in I$ on any of the following witnesses.

1. It accepts a false terminal.
2. It accepts a nonterminal $F$ and $U_I$ rejects both children.
3. It accepts either child and $U_I$ rejects the parent.

The second test compares the children against the whole pool. In any exact $J\subseteq I$ containing $i$, acceptance of the parent would imply satisfiability of some child and hence a vote at that child from $J$. For the third test, a child accepted by $i\in J$ would make the parent satisfiable. Thus every deletion preserves every exact subportfolio. Neither test requires the true value of the witnessed formula.

When no deletion applies, $U_I$ accepts a nonterminal exactly when it accepts some child. Every accepted terminal is true. If all true terminals are covered, induction on the number of variables proves $U_I$ exact. Otherwise present the deletion sequence and an uncovered true terminal. A verifier needs no evidence that the pool has stabilized. Every exact subset would have survived and would cover that terminal. In a canonical encoding with a unique empty conjunction the last witness is known in advance. Omitting the third test would instead require an uncovered satisfiable formula with a satisfying assignment.

The selection constraints are dual-Horn clauses on selector bits $x_1,\ldots,x_k$. A positive vote on a parent gives $x_i\Rightarrow\bigvee_{j\text{ voting on a child}}x_j$. Each vote on a child gives the reverse obligation $x_i\Rightarrow\bigvee_{j\text{ voting on its parent}}x_j$. A wrong leaf vote forbids its selector, and a true leaf gives a positive coverage clause. A mask is exact precisely when it satisfies all these clauses. The usual Horn propagation argument accounts for the short certificate even though the clauses are implicitly indexed by formulas. [Dowling and Gallier, 1984](https://doi.org/10.1016/0743-1066(84)90014-1)

If candidate evaluation takes at most $T(n)$ per call including interpretation, verification uses $O(k^2)$ calls. The witness length is $O(k(n+\log(k+1))+n)$ bits for $k\ge1$. A quasilinear-time syntax pass suffices per formula. For polynomial clocks and explicitly given programs with polynomially bounded evaluation this puts the bounded question in coNP, using unary $n$ or a resource bound polynomial in the actual input length. With a trusted SAT algorithm taking time $S^d$ on $S$ bits, the compiled refutation test takes $\widetilde O((k^2 T(n)+kn)^d)$, including reading the descriptions in the evaluation bound. One can recover a working subportfolio with at most $k$ extra such decisions, greedily deleting each candidate when existence persists. The test itself can exceed the length on which the input programs are under investigation. [RAM computation to SAT](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

## Running an unknown exact disjunction

Suppose a fixed finite menu contains an exact disjunction globally. One can answer a query even before learning which voters to keep. If the surviving pool gives no vote, the formula is unsatisfiable since an exact subset remains. Otherwise follow positive children until a true terminal certifies satisfiability or a failed local support test removes one voter. In the latter case restart. At most $k$ failures occur, so this fallback always terminates.

There is a stateless compiler attaining $O(g(n)+kT(n))$ worst-case time asymptotically for each fixed promised menu, for any unbounded increasing replay budget $g(n)$ whose clock can be implemented within that time. For example, take $g(n)=\lceil\log_2(n+2)\rceil$ with length available. From scratch on each $n$-bit input, simulate $g(n)$ steps of a fixed enumeration of all local selector clauses from all lengths. Retain fully emitted clauses with their indices, as a formula $C$. Evaluate the $k$ programs on the input and record its voter set $V$. To check if any model predicts yes, add $\bigvee_{i\in V}x_i$ to $C$. To check if any model predicts no, add $\neg x_i$ for all $i\in V$. Both tests are dual-Horn satisfiability and take linear time in the stored clause data and the $k$ new indices in a standard indexed representation. Since an exact selector is a model of $C$, at least one prediction is possible. If both are possible, run the preceding fallback.

Every globally incorrect selector violates a particular local clause. There are only finitely many selectors, so a finite prefix of the enumeration excludes all the incorrect ones. For all sufficiently large $n$ the two tests yield a unique prediction, without a correction descent. This argument gives total correctness on early inputs as well, but its asymptotic threshold depends on the menu. The bound concerns fixed $k$; the root evaluations and the two Horn tests are explicit and do not enumerate all selectors.

## Signed partial solvers on AND/OR games

Now each component can cast a positive vote, a negative vote, or abstain. Keep or remove each component as a whole. The domain is closed under children, every descent terminates, and leaves have known values. A subportfolio is exact when every node receives its true sign and receives no false sign. At a leaf a vote needs to match the label. At an internal node it needs the following support from the whole current pool.

| Parent | Positive vote needs | Negative vote needs |
| --- | --- | --- |
| OR | A positive vote at some child | A negative vote at both children |
| AND | A positive vote at both children | A negative vote at some child |

Delete a voter with a failed test. In an exact subportfolio its vote would be correct, and every child with the required sign would have a voter in that same subportfolio. Hence the deletion is compulsory. At termination the remaining votes are all correct by induction on height. An incomplete fixed point has an unlabelled witness, a node receiving neither sign. This gives the same bound of $k+1$ witness nodes, without any certificate of the final node's value. The argument works on restriction-closed bounded prenex quantified formulas with the leading quantifier determining the gate. Its verification needs polynomial-time candidate evaluation, child construction, and leaf checking, irrespective of the number of quantifier alternations. [Lean verification of support, soundness, forced removal, and conflict propagation](../lean/PortfolioLocalDefects.lean)

**Constructive use of the promise.** Suppose some fixed but unknown subportfolio is exact. Evaluate the current pool at the requested root. There is at least one vote. If all votes have the same sign, return it. On disagreement, check support at the children. A failure permanently rules out the corresponding component. If both signs have support at an OR, the positive supporting child also has a negative vote. At an AND use the negative supporting child. Follow the disagreement to a forced removal, then restart the query. A leaf with opposing votes always forces a removal. For $Q$ successive queries of length at most $n$ and height at most $h$, the total work is $O((Q+k(h+1))k(T(n)+R(n)))$, where $R(n)$ bounds syntax and restriction. Only $k$ correction descents are charged across the entire stream. If the promise is a single correct *total* candidate, compare any disagreeing pair in isolation. Follow disagreement until one of the two fails its own exact local recurrence, then delete that candidate. This sharpens the total to $O((Qk+k(h+1))(T(n)+R(n)))$. Pairwise deletion would be unsound for the weaker coalition promise because support can switch components.

There is also a stateless compiler for a fixed finite two-sided menu promised exact on the *entire* domain. On each fresh input of length $n$, spend $g(n)$ steps replaying a fair enumeration of local failures from the full initial pool, restarting the enumeration after each deletion. Take, for example, $g(n)=\lceil\log_2(n+2)\rceil$ with length available. Then run the preceding disagreement algorithm on the actual input and the remaining pool. The unbounded background process has at most $k$ deletions. After its last deletion, any outstanding local failure would eventually be visited, so the final pool is locally supported everywhere. All its votes are correct and it still covers every input. For all sufficiently large $n$, the replay therefore leaves a pool giving an immediate unanimous answer. Early inputs are answered correctly by the fallback. This yields worst-case $O(g(n)+kT(n))$ asymptotically for each fixed promised menu, including the finite replay setup in the machine-dependent constant. It does not give a time for detecting that the last deletion has occurred.

## Limits of the bootstrap

**A sharp local refutation.** Take $k$ false nodes $v_1,\ldots,v_k$, the last a false leaf, with $v_i$ for $i<k$ an OR of $v_{i+1}$ and a spare false leaf. Add a separate true terminal $t$. Candidate $i$ accepts exactly $v_i$, with candidate $1$ also accepting $t$. The only possible first deletion is $k$, then $k-1$, and so on. The sole true node becomes uncovered only after all $k$ deletions. The clauses $x_1, x_1\Rightarrow x_2,\ldots,x_{k-1}\Rightarrow x_k, \neg x_k$ are minimally inconsistent. Thus $k+1$ witnessed clauses can be necessary for this local refutation system.

**Testing all selectors may require exponentially many roots.** For even $k\ge2$, use a true tautological CNF $F_S=(z_S\vee\neg z_S)$ for every $k/2$-subset $S\subseteq[k]$, identifying each set by a bit vector in its variable name. Both restrictions produce the one true terminal. All candidates vote there, and candidate $i$ votes at $F_S$ precisely when $i\in S$. The full pool is exact. For each $S$, the selector $[k]\setminus S$ fails exactly on $F_S$, since it meets every other half-size subset. Any suite of local roots characterizing all exact selectors must therefore include at least $\binom{k}{k/2}$ roots. The certificate of nonexistence and the task of eliminating *all* incorrect selectors have different bounds even when evaluating the candidates is easy.

**No computable stabilization bound.** Even on an elementary restriction-closed CNF domain, take $F_x=(z_x\vee\neg z_x)$ with the binary string $x$ encoded in the variable name, together with the empty conjunction reached by either restriction. Every node is true. Include one always-positive component. A second component abstains on the empty conjunction and casts a negative vote at $F_x$ exactly when a fixed Turing machine $M$ halts within $|x|$ simulated steps. This is a clocked program and the first component alone is always exact. A negative vote, if it occurs, has no support at the children. Any computable bound from the menu code on the length of a first forced deletion, whenever one exists, would decide halting. The same construction precludes a computable bound on the last deletion time for a fixed fair search. In a bounded variant, let a circuit $C$ on $m$ bits govern the only component. It votes positive on the empty conjunction and on each $F_x$ with $|x|=m$ and $C(x)=0$, and abstains on all other roots in that length-$m$ family. Exact selection on that family is equivalent to circuit unsatisfiability. Thus bounded portfolio validation is already coNP-hard on a family where every game is true.

A correct fast SAT program would itself supply a one-member exact menu. The pruning and voting theorems need a source of an exact menu to decide SAT, or an independently verified refutation of *each* proposed fast menu to exclude those algorithms. Neither follows from the certificate length or the amortized bounds.
