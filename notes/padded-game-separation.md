# What a fast predictor on one padding per opponent would prove

A program prefix leaves the rest of its binary input free. The padded diagonal $J_T(py)$ returns one exactly when the program named by $p$ rejects the entire input $py$ within $T(|py|)$ instructions. A successful extension is an input on which the proposed alternating computation halts with the value of the diagonal and meets the claimed resource bounds on every branch. Each prefix is to have arbitrarily long successful extensions. The candidate may give incorrect answers elsewhere. [Original diagonal and SAT reduction](alternating-native-speedup.md)

## A single opponent against all certificates of cheap verification cost

Fix any candidate $M$, a deterministic certificate checker $C(x,a)$, and an intended set of good inputs on which $M$'s game has a definite value. The checker may return a sign, decline to certify, or run forever. On each good input, **every sign it certifies must be the game's value**. It may read the entire input $x$, including any purported proof placed in the padding. The string $a$ describes additional information needed to find or verify a certificate. Its running time $v$ includes locating all the parts it uses.

For each $b\in\{0,1\}$ there is a single opponent $P_b$ such that, on every sufficiently long successful good extension of its prefix, $M(x)=1-b$ and every certificate returning a sign has
$$
 2^{|a|}(|a|+1)^2(v+1)=\Omega_C(T(|x|)).
$$
This holds independently of how the extensions are selected. If $M$ meets the coverage requirement, both signs therefore have arbitrarily long good examples with this certificate lower bound, in their respective program cylinders.

Here and below take an integer polynomial clock $T(n)=n^r$, with $2\le r\le9$ on the journal's fixed $12\lceil\log_2(n+2)\rceil$-bit RAM. The proof also works for larger fixed $r$ with a suitably larger fixed word-width coefficient. Use budget $B=\lfloor T(n)/K\rfloor$ for a fixed sufficiently large $K$. For each length $\ell$ with $2^\ell(\ell+1)^2\le B$, the opponent tests every descriptor of that length for
$$
 \left\lfloor\frac{B}{2^\ell(\ell+1)^2}\right\rfloor
$$
checker steps. It returns the first certified sign observed, or $b$ on exhaustion. The total simulated time is below $2B$ by summing $(\ell+1)^{-2}$. Each scheduled test gets at least one step, so iterating and resetting the checker are covered at constant cost per step. Its input $x$ is shared read-only. Build the fixed-limb division lookup table once for all trials, using the original input length to choose digit sizes. Each descriptor fits in constantly many words and can be supplied from its binary counter and length. A touched list restores the work store in time proportional to the steps just simulated. Budget arithmetic uses a fixed number of words, and scheduling lengths adds $O(\log n)$ setup. Choose $K$ above the implementation coefficient, using a fixed scheduler and a numeric dyadic scaling parameter if needed. The opponent finishes within $T$ actual instructions. On any good input where it found a certificate it returned $M(x)$, so the diagonal gives the opposite answer. On a successful good input it must have exhausted the budget, whence the sign claim and the displayed lower bound. This argument uses the standard allocation principle for universal search. [Levin, 1973](https://www.mathnet.ru/eng/ppi914)

For instance, a checker reading a single designated certificate from the padding has $|a|=O(1)$. If it verifies in $o(T)$ and always exposes the correct game value on the proposed good examples, that format cannot serve at these prefixes. A checker whose output bit is trusted only on the one certificate chosen by an unknowable adviser fails the soundness hypothesis.

## An exact comparison with a worst-case language lower bound

The coefficient in a big-O time bound matters here. For the original $J_T$, a total covering predictor cannot itself be evaluated by a deterministic program using at most $T(n)$ instructions eventually, and in particular cannot be evaluated in $o(T(n))$. That argument leaves arbitrary constant multiples of $T$ untreated.

For an exact big-O statement use a prefix specifying both a program $P$ and a positive integer $c$. Let $J^*_T$ use the cutoff $\min(c,\lceil\log_2(n+2)\rceil)T(n)$. The cutoff equals $cT(n)$ eventually on each fixed prefix and costs $O(T\log n)$ simulation time uniformly over all prefixes. Use rejecting default zero for malformed prefixes. Fix $k\ge1$ and a nondecreasing constructible alternating time bound $n\le s(n)\le T(n)$. On the native RAM the following are equivalent.

1. Some total alternating $O(s(n))$-time program with at most $k$ blocks agrees with $J^*_T$ on arbitrarily long extensions of each valid prefix.
2. Some language of a total alternating $O(s(n))$-time program with at most $k$ blocks lies outside deterministic $O(T(n))$ time.

If a language in item 1 had a deterministic $D$ with running time $C T(n)$, choose its own prefix with $c>C$. The diagonal flips its value on every sufficiently long extension. Conversely, take a language $H$ in item 2. On $py$ with valid prefix $p$, run its alternating program on $y$ and return the result, including when $p$ specifies a large program. Parsing takes $O(n)$ and the input suffix supports constant-time packed word access. If some fixed $p=(P,c)$ had only finitely many agreements, then $H(y)=1-J_T^*(py)$ eventually for every $y$. Simulate $P$ on $py$ through the cutoff and return its actual answer if it halts, or one on timeout. Hardwire the finitely many exceptions. Since $p$ is fixed, $T(|py|)=O_p(T(|y|))$ and the simulator decides $H$ in deterministic $O_p(T(|y|))$ time, a contradiction.

For the machine details, simulate the guest at its actual width and length. A fixed prefix changes input length by an additive constant. Even at a width boundary a guest word occupies a bounded number of host limbs. Sparse address simulation uses a fixed-depth radix trie with digits of about $(\log_2 n)/4$ bits. The number of allocated rows is $O(T(n)\log n)$ throughout the stated clock range, so a row number and one digit fit the host width. Setup for fixed-limb division takes $O(1+n^{1/4})$. In item 1's predictor the guest for $H$ uses width based on $|y|\le n$ and can likewise be interpreted in $O(n+s(n))$. A guessed host word can be masked to the guest width without introducing a change of player. The SAT target concerns the original diagonal and its explicit compiler costs. This equivalence applies to the calibrated diagonal and total resource-bounded games. [Word arithmetic and sparse-bank implementation](native-unary-clock-band.md)

## An explicit partial predictor and its escaping opponent

Use a constructible early clock $n\le u(n)=o(T(n))$, for example $u(n)=n$. Replay the ordinary opponent for $u(n)$ steps. If it halts, return its complementary answer. Otherwise return the parity of all free suffix bits. This deterministic $O(n+u(n))$ predictor covers every prefix with arbitrarily long early halts. It also covers every prefix with arbitrarily long inputs on which the opponent leaves some suffix bit's containing input word unread throughout its clocked run. If there were no agreements at a length, every run there would exceed the early cutoff, and the opponent's saturated answer (one on timeout) would equal suffix parity on every input. Flipping one suffix bit in an unread word preserves the execution and reverses that parity, a contradiction.

A fixed opponent defeats the predictor on its entire cylinder at all large lengths. It parses the prefix, computes the parity, deliberately waits past the early cutoff and returns the parity within $T(n)$ steps. For $u(n)=n$ a simple counter suffices. For each of one, two and three free bits, the tables assigning an early sign, a late sign or a timeout to each suffix have respectively 2, 4 and 16 ways of defeating the predictor on the whole cylinder. In every such table an even suffix must receive a late zero, while an odd suffix can receive a late one or a timeout. This realizes the limitation without asking the opponent to forecast which padding will be called good.

There is a stronger explicit predictor for the original diagonal. Fix a sound arithmetical theory with an effective polynomial-time checker of binary proofs, and let $E_p$ be the arithmetic sentence asserting that on all sufficiently long extensions of the valid program prefix $p$, the saturated opponent bit (one on timeout) equals suffix parity. Use early clock $u(n)=n$. After the early-halt test, examine a self-delimiting proof supplied at the front of the free suffix. If it proves $E_p$, output complementary parity, otherwise output parity. Limit both program-prefix and proof processing in this additional check to a length threshold growing sufficiently slowly, for instance $\lfloor\log_2 n\rfloor$ bits each using a fixed polynomial-size numeral encoding and arithmetization. Other inputs use the plain parity rule. The extra check then takes $\operatorname{polylog}n$ time. Every fixed prefix and fixed proof eventually fit.

If this predictor escapes agreement on an entire cylinder at all sufficiently large lengths, $E_p$ is **true and unprovable in the chosen theory**. Indeed any proof would make $E_p$ true by soundness. Put that proof at the front of arbitrarily long paddings of $p$. An early halt gives agreement immediately, and on sufficiently long late runs complementary parity agrees with the diagonal there. This rules out a proof. With no proof the plain parity rule applies, so escape implies eventual parity by the preceding argument. An opponent that escapes this rule waits for more than $n$ steps, then runs this fixed predictor on its entire input and returns its answer. The internal early replay only sees the initial delay, and the whole calculation finishes within $T$ at all sufficiently large lengths. Thus proof-bearing padding handles all cylinders with provable eventual parity and still leaves an explicitly constructed escaped program. This is an obstruction for this particular padding heuristic.

The certificate bound and partial construction give conditions an unrestricted speedup would have to overcome. Constructing one with the charged quadratic or cubic SAT budgets remains open.
