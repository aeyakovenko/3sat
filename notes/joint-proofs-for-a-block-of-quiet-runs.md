# How short a proof that some run stays quiet would contradict a SAT clock

Fix a deterministic proof verifier $V$. It takes a program text $p$, a word size $h$ and a binary proof. The statement it checks is the following particular finite assertion $J(p,h)$.

> Among the runs of $p$ with otherwise zero initialization, the prescribed self-code seed, word size $h$, and site input $z$ in the designated constant number of $h$-bit registers, at least one fails to reach the absorbing return-one location by step $2^h-1$.

The input code bank contains exactly $p$. Assume that whenever $V$ accepts, this assertion is true. Require $V$ to halt on the finite proofs under consideration. An example is ordinary syntactic proof checking in a sound arithmetic theory for a fixed arithmetization of $J$. In a theory such as PA each true closed instance has a finite proof by finite computation. Its length and the cost of checking it matter here. Truth of an arbitrary verifier's accepted assertions is a genuine hypothesis.

For each $k=1,2,3$ we construct a fixed program $p=p_{k,V}$ using only explicit ordinary SAT calls to a prospective $k$-clocked RAM solver. Write $T=2^h$. In this note a *description* is a finite binary string fed to a fixed universal deterministic generator with public inputs $(p,h)$. Its job is to generate a proof accepted by $V(p,h,\cdot)$. One format copies a literal proof. Charge the description length, running the generator, materializing its output, and running the verifier. Fix the generator's semantics independently of the search cutoff, for example a fixed multitape universal interpreter with a proof output tape followed by the fixed verifier. Equivalently other fixed machines may be simulated with their actual translation cost charged. Let $d$ be the length in bits and $t\ge d$ this total charged time on a successful description. Polynomial overheads in $h$ below include the physical simulation of this fixed instruction set. Use of a tape for the proof generator places no restriction on the RAM SAT solver.

**Bounds on this one program.** Every block contains a quiet site. For some constants $C$ and all sufficiently large $h$, every successful description satisfies

$$
  2^d(t+1)\ \ge\ T/h^C.
$$

If ordinary SAT has a deterministic unrestricted-workspace logarithmic-word RAM solver in $O(N^k)$ on $N$ encoded input bits, the same descriptions also satisfy

$$
 \begin{array}{ll}
 t+1\ \ge\ T/h^C, & k=1,\\
 (d+1)(t+1)^k\ \ge\ T/h^C, & k=2,3.
 \end{array}
$$

There is a refinement for $k=2,3$. At any of the tested dyadic length and time caps $(D,U)$ with a successful description, let $r$ be the affine dimension over $\mathbb F_2$ of the **canonical padded descriptions** accepted at these caps. Then $(1+r)(U+1)^k\ge T/h^C$. The dimension includes the marker specifying description length and excludes auxiliary computation wires. Multiple long proofs can therefore incur the cost of few choices if they occur in a low-dimensional family. The dimension bound applies to the family at the specified caps. Rounding the caps can add descriptions and increase its dimension.

In particular if a literal proof of length $L$ can be copied and checked in $h^{O(1)}(L+1)^a$ time for a fixed $a\ge1$, the fast-clock hypothesis forces $L+1\ge 2^{h/a}/h^{O(1)}$ for $k=1$ and $L+1\ge 2^{h/(ak+1)}/h^{O(1)}$ for $k=2,3$. For quasilinear proof checking, with logarithms absorbed in powers of $h$ in this range, the respective exponents in $h$ are $1,1/3,1/4$. A proof accepted by this very verifier for this very program on infinitely many widths below the corresponding bound would settle that clock. We have no such proof. The [earlier Horn program](one-quiet-run-in-a-block-of-native-sat-tests.md) concerned certificates of a particular site's native history. Its external proof of a quiet site concerns a different program text.

## Native construction and soundness

Use the earlier bit-addressed native host with $h$-bit registers, $T$ memory bits and the externally initialized literal code seed. A fixed interpreter can read that seed when spelling the verified assertion. This avoids embedding an exponentially expanded quote of a quotation. All sites store the same seed and can reserve their site words until the last step. Small widths where the fixed code does not fit stay quiet. A fresh call to any deterministic solver starts in its prescribed initial state. Failed allocations and unfinished calls never latch their site. Code, indices, syntax, and arithmetic needed to generate queries are ordinary native computations. This is a program construction by compilation, not an assembled ISA listing. [Host and initialization](native-register-and-memory-lifts.md) · [Learning a clocked solver](one-fixed-forecast-prefix-for-clocked-sat.md)

First spend at most $T/8$ native steps on a common exhaustive search. For each exact description length $e\le h$ let its per-string simulation allowance be $\lfloor T/(2^e h^B)\rfloor$ charged steps. Skip a whole bucket if this allowance is zero or too small even to read an $e$-bit description. Initialize only touched storage. Each interpreted step and all per-string setup and clearing cost at most a polynomial in $h$ times the allowance, after skipping those buckets. This follows by digit-wise simulation, counting and addressing $O(h)$-bit counters and charging writes to the simulated execution. For the fixed tape interpreter, moves and writes have the same bound. Summing over all $2^e$ strings and the at most $h+1$ positive buckets gives the prephase budget by taking $B$ large enough. Enter return-one on a verified proof. All sites would do so together, contradicting the proof's soundness. This proves the first bound, also for $d>h$ where it is immediate. This scheduling argument is the elementary length-weighted universal search estimate. [Levin, *Universal sequential search problems*](https://www.mathnet.ru/eng/ppi914)

On the common remaining computation choose the least still-unrefuted clocked solver after $h$ steps of a fixed dovetailed search for actual finite counterexamples. If there is a correct $O(N^k)$ solver the selection is eventually a fixed correct clock, including its time multiplier. Failure to stabilize under other circumstances does not affect soundness. Given dyadic caps $1\le D\le U\le T$, construct a single proper 3-CNF $F_{D,U}$ whose models encode canonical descriptions of length at most $D$ with a successful charged computation by $U$. Use $D+1$ bits for a string followed by a one marker and zero padding, identifying the last one as the marker. Reject the all-zero word. Charge actual unpadded length. Pins and order comparisons on the padded word use the same physical order throughout. The accepting relation runs the *same* generator and the *same* verifier on $J(p,h)$. Force all auxiliary gates and memory events canonically. Each accepted padded description has precisely one extension, so uniqueness of the description suffices to recover bits even in the auxiliary part of a satisfying assignment. Construction and physical bit length are at most $h^{O(1)}(U+1)$. The fixed multitape generator can also be executed by the bounded-run word-RAM encoding with constant-many indexed tape accesses per step. [Parsimonious bounded-run compiler and cost of emitting ASCII clauses](local-sorting-for-parsimonious-ram-encodings.md)

Whichever common computation selects the final file and pins, a site checks one original clause of that file, reading the three Boolean coordinates independently using canonical public data. The site latches precisely upon a completed passing check. Every clause must have a site. A spare site checks a tautology. Use capacity guards before committing to a file and reserve sufficiently many index words to index every clause of an eligible file. A shared atom uses the same fresh query even if two sites call it in different orders or with different remaining deadlines. A call which fails to finish yields no latch there. If every site latched on this path, all the returned values combine into a single satisfying assignment. This certifies an actual proof of $J(p,h)$, so some site was quiet, a contradiction. This argument works even with a lying prospective solver. It is essential to choose one common file *before* the local tests start. Letting each site use whichever candidate file first supports its own clause would break the implication. [Lean proof of the shared-assignment implication](../lean/JointProofClauseSites.lean)

## Computing a common model within a deadline

For $k=1$, try increasing dyadic $U$ with $D=U$ and lock at the first positive existence decision. For a requested variable $i$ of the locked file $F$, guess a full satisfying assignment $x$ with $x_i=1$. Emit the ordinary SAT file for $F(y)\land y<_{\rm lex}x$, using a linear-size comparator and fresh, fully constrained gate variables. Simulate the selected clock on this inner file and require a NO. Compile the whole bounded guess and check into an outer ordinary SAT file and ask the same selected clock for its decision. The inner clock only runs the selected solver's raw code. With truthful answers this gives exactly the $i$th bit of the lexicographically first model. The inner file costs $h^{O(1)}(U+1)$ bits, the bounded verifier costs $h^{O(1)}(U+1)^k$, and the outer decision costs $h^{O(1)}(U+1)^{k^2}$. At $k=1$ both decision levels fit $h^{O(1)}(U+1)$. There are at most three such coordinates per site. After the reserved preliminary search, through the first dyadic cap covering $t$ all remaining work fits within $h^{O(1)}(t+1)$ if the selected solver is correct and a description exists. A prior YES at a smaller cap only reduces this bound. With sufficiently large polynomial slack this plus the reserved $T/8$ is below the horizon. This proves the linear-clock implication by contradiction with quietness. Lexicographic SAT optimization itself is classical. [Krentel, *The Complexity of Optimization Problems*](https://doi.org/10.1016/0022-0000(88)90039-6)

For $k=2,3$ launch one common search per dyadic pair $(D,U)$. Interleave their elementary native steps fairly until the first ready search, with a fixed tie order, or until the horizon. There are only $O(h^2)$ searches. A deterministic interpreter interleaves these with overhead polynomial in $h$ by allocating scratch banks lazily, addressing each private virtual bank with a tagged dictionary, and switching between a polynomial-size set of interpreter states. A capacity failure in one search only disables that search. Global exhaustion leaves a site quiet. To prevent one large failed search from exhausting storage ahead of a cheap one, allocate only on actual simulated writes, with bit strings and large files built incrementally. Total occupied storage before the first ready search costs at most a polynomial in $h$ per elapsed virtual step. Use checked capped arithmetic when declaring large target sizes. Whenever the claimed total work has strict polynomial-in-$h$ slack below $T$, it fits the native memory as well as the time budget.

A search first asks whether its $F$ is satisfiable. On YES, maintain a common set of pins. Ask whether two satisfying assignments extending the pins differ anywhere on the padded description. On YES, binary-search the first varying coordinate $j$, asking about disagreement in the first $j$ coordinates. Each question consists of two copies of the same $F$, the current pins on each, and the indicated disagreement test. This uses one ordinary SAT call on $h^{O(1)}(U+1)$ physical bits. Pin coordinate $j$ to zero and repeat. On NO, mark this search as ready **after** spending $(U+1)^k$ dummy steps in this search's own simulated time. The delay makes the work needed *after* the common lock comparable to the work already spent, even if a different search was cheaper. If the quota exceeds the horizon use a nonreturning delay. Up to the first ready search all decisions, pins and delays are independent of the site.

With truthful answers every new pin retains the lexicographically first padded description. Earlier coordinates agree already and both values are attained at $j$. The affine hull of the remaining words loses at least one dimension, since the new coordinate is nonconstant on the previous hull and the retained points belong to its zero hyperplane. Hence a nonempty family of dimension $r$ needs at most $r$ pins and $O(1+(r+1)\log(D+2))$ calls. This can be much smaller than its cardinality. For example $\{0^D\}\cup(\{1\}\times\{0,1\}^{D-1})$ needs one pin although it has full affine dimension for $D\ge2$.

After the common lock, query each needed variable via existence of a model of the chosen $F$ obeying all the final pins and setting that variable to one. The unique padded description and parsimonious verification give a unique *full* assignment. If the cheapest relevant search needs $Q$ work, the first ready search takes at most $h^{O(1)}Q$ elapsed work. Its own $(U'+1)^k$ delay has finished, so its at most three local ordinary positive bit questions cost at most $h^{O(1)}Q$, even when $U'$ exceeds the cap of the search used to estimate $Q$. This last charge prevents an early lock on a large file from invalidating the bound. Consequently an accepted dyadic pair of dimension $r$ would latch every site with additional work $h^{O(1)}(r+1)(U+1)^k$. Quietness proves the claimed inequality. Rounding up an individual $d,t$ by factors of at most two gives $r\le D+1=O(d+1)$ and yields the stated individual-description bound.

## A limit on reconstructing witnesses from positive checks

Here is a test of whether more elaborate SAT filters could remove the common pinning cost in complete generality. Give a protocol access to a hidden nonempty set $S\subseteq\{0,1\}^b$ only through Boolean predicates monotone in $S$. A single test may have arbitrary description and may, for example, ask if any tuple of words from $S$ satisfies a fixed relation. Allow $u$ adaptive common queries followed by $b$ separate sites each making up to $v$ further adaptive queries. Local queries can depend on their site's own replies and the common transcript. Require the reported $b$ bits to form a member of $S$ for every nonempty support. Then

$$
           2^b \le 2^u\bigl(1+b(2^v-1)\bigr).
$$

Indeed, pool all potentially asked tests in the binary decision trees. There are at most $(2^u-1)+2^u b(2^v-1)$ such tests. Begin with every word. Repeatedly delete the reported word while at least two words remain. After each deletion the reported word must change, so some pooled answer changes. Each monotone test can change just once on the entire descending chain. This proves the inequality, including for two-copy disagreement checks. Taking a fixed complement of an answer internally has no effect on the count. The nested lexicographic predicate can change in either direction as the support shrinks and escapes the premise. This lower bound is for arbitrary hidden supports. An ordinary solver reads its formula's syntax, and a verifier's accepted descriptions at a fixed width form a specific support. Neither justifies using the inequality as a RAM time bound. [Lean deletion and counting proof](../lean/MonotoneWitnessSelection.lean)

## What could establish the missing upper bound?

A shorter **nonuniform** proof on infinitely many $h$ suffices. An externally proved universal quietness statement does not automatically give a proof accepted by the chosen $V$. In particular, if $V$ checks proofs in a theory $A$, an argument invoking soundness of $A$ can live in a stronger theory. Changing $V$ changes $p$ and therefore the assertion the new proof must establish. This is the finite-reflection issue familiar from proof-length research. A fixed algorithm printing and certifying proofs of these exact sentences in $o(T/h^C)$ time would already have been executed by the first phase. Finite proof lengths for sufficiently strong theories and length-weighted search are classical; priority for the joint native construction and these parameters is unestablished. [Pudlák, *On the length of proofs of finitistic consistency statements in first order theories*](https://www.sciencedirect.com/science/article/pii/S0049237X08704622)

The [Lean file](../lean/JointProofClauseSites.lean) checks the common-clause contradiction, coherent model recovery, and a separate proof-prefix tree argument. A full prefix of arbitrary proof length cannot generally be used as an $O(h)$-bit site identifier. The stated bounds use clause indices as sites. The [finite DIMACS audit](../audits/joint_proof_site_audit.py) checks the coordinate predicates against independent model enumeration on all 256 three-bit supports and additional projected families. It also checks two-copy disagreement and the drop in affine dimension. In a 94-bit family with 1,024 projected words of affine dimension ten it takes ten pins and 78 two-copy questions. It executes the outer existential by finite enumeration. The native compiler composition, resource bounds, and any same-theory proof upper bound are outside these checks.
