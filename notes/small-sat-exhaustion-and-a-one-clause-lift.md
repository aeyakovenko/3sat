# Exhausting small SAT inputs and lifting a lower bound one clause at a time

At eight ordered clauses on a fixed triple of variables, one deterministic word-RAM program takes up to **320 steps on 144 encoded bits**. Another takes **83 steps on all 16,777,216 inputs**. The first exceeds 144 steps on 7,136,858 inputs. The calculation measures two fixed programs with identical input access. Neither measurement bounds the best unrestricted algorithm. A separate experiment below gives a genuine one-clause algebraic induction, a matching packed algorithm, and the precise condition that finite exhaustion would have to establish for unrestricted RAMs. [RAM interpreter and dynamic program](../audits/small_sat_ram_clocks.py) · [Independent direct enumeration](../audits/small_sat_native_census.cpp)

## What was counted

The input consists of a 16-bit header 0x3C1F and a sequence of 16-bit proper 3-CNF records. The names of the three distinct variables occupy bits 11–14, 7–10 and 3–6. The three low bits specify the assignment falsifying the clause. The top bit is zero. In this census all names are 1, 2, 3 in this order. Repetitions and all clause orders are included. With $m$ clauses the length is $n=16(m+1)$ bits. Individual variable names are explicit. A more general format can use a different header and unbounded binary names. The two tested programs check the header, alignment and names before returning a specialized answer. Other formats and records can transfer to a common general SAT decoder. That fallback is irrelevant to every measured path and is not implemented by the experiment.

Take $w=16\lceil\log_2(n+2)/16\rceil$ bits per word. This is a logarithmic word size, equal to 16 at every measured length. The input length is in one register and the header is at input address zero. Direct or indirect load, register move, Boolean operation, shift, addition, immediate comparison and branch (one instruction), unconditional jump, and halt each cost one. Code labels cost zero. The clock includes validation and halt. The fast paths handle lengths up to 65,520 bits as listed in the bytecode. All constants fit. Space is unrestricted.

The first program validates the records. For $m\le7$ it accepts because fewer than eight such clauses cannot cover eight assignments. Otherwise it tries each assignment in order 0 through 7, rescanning the records until it finds a clause falsified by that assignment. It accepts on the first absent sign, or rejects after finding all eight. The second program collects all encountered signs in one writable word during validation and tests that word against 255. It takes $9m+11$ steps for every ordered input in the tested format. Its code contains no SAT answer table.

The direct eight-clause census found 40,320 UNSAT inputs, precisely the permutations of the eight signs. The minimum clock was 109 and the maximum 320. Exactly 5,040 inputs attain the maximum. For larger lengths the dynamic program counts all ordered lists implicitly. For each first missing sign it records the current position and the subset of earlier signs already encountered. On first seeing a required sign at position $i$, starting at zero, it adds $6i$ to the objective. The recurrence keeps the maximum, counts ties, and recovers a witness. Unseen required signs at the last position make a branch infeasible. Thus it compares the clocks of all possible orders without treating two orders as equivalent solely because they define the same formula.

## One-clause lift of the observed slowdown

One worst eight-clause list is $0,0,1,2,3,4,5,6$. Its unique surviving assignment is 7. For $m\ge8$ repeat the initial 0 exactly $m-6$ times and follow it by $1,2,3,4,5,6$. Each extra initial zero costs the rescan program **48 more steps**, while it adds 16 encoded bits. The bitmap program spends nine more steps. Both programs solve the extended formula correctly.

Here is the exhaustive optimum for the rescan code at every $8\le m\le4094$. Let $s$ be the first missing sign and $i_j$ the first position of sign $j<s$. For $s<8$ its clock is $13+12m+7s+6\sum_{j<s} i_j$. If $s=7$, the first required hit is at zero. The six other first hits are at most the final six distinct positions, so the maximum is $48m-64$, attained in $7!$ orders. If $s\le6$, the sum is at most $sm-s(s+1)/2$, giving at most $48m-71$ for $m\ge8$. If every sign is present, the clock is $67+6m+6\sum_{j<8}i_j\le48m-101$. For $m\le7$ the clock is $6m+10$. Thus eight is the first crossing of the particular budget $T\le n$ for the rescan program on this family. The larger examples still have bounded $T/n$. Defeating a single multiplier, even at every subsequent length, is consistent with a linear running time.

## A lower bound whose algebra really extends from m to m+1

Start with eight independent bits selecting which of the eight signed clauses are included. The SAT truth function is $f_8(x)=1+\prod_{i=1}^8 x_i$ over $\mathbb F_2$. In an ordinary fixed-width explicit formula, implement an absent clause by a copy of $(x_4\lor x_5\lor x_6)$ on fresh names. Every satisfying assignment of the selected clauses extends to satisfy all copies. Each encoded bit in a slot is a constant, its selector, or its complement. This uses only proper width-three clauses.

Duplicate any one optional clause into two independently selectable copies. The new verdict substitutes $x_i\lor y=x_i+y+x_i y$ for $x_i$. If $f_m$ has the full monomial on its $m$ selectors in algebraic normal form, this substitution produces the full monomial on all $m+1$ selectors exactly once. Equivalently the XOR of all output values is unchanged because a disabled clause has one preimage, and an enabled clause has three. Inductively the exact binary degree is $m$ for every $m\ge8$, with a single optional slot added at each step. Lean checks the parity invariant, the base and this unbounded induction. [Lean proof](../lean/ClauseSelectorLift.lean) · [Packed scanner audit over 16,128 selector masks](../audits/clause_selector_lift_audit.py)

Consequently any deterministic adaptive decision tree whose tests are **arbitrary affine parities of the entire encoded input** needs at least $m$ tests on some input at every size. Indeed, substitute the selectors in each query. A test $\ell$ combines its two subtrees as $(1+\ell)f_0+\ell f_1$, so a depth-$q$ parity tree has binary degree at most $q$, including after multilinear reduction. Reading all selectors attains the bound. For a catalogue containing whole sign orbits, flipping the variable signs gives another proof of full degree. The binary sign group acts on satisfiable selector masks. The only fixed satisfiable mask is the empty one, and every other orbit has even size. This is the parity argument underlying classical symmetry-based decision-tree lower bounds. The sign-orbit statement assumes a catalogue of distinct clauses with all signs on every included support. [Rivest and Vuillemin on symmetry and evasiveness](https://www2.eecs.berkeley.edu/Pubs/TechRpts/1974/29402.html) · [Parity decision trees](https://arxiv.org/abs/1810.08668)

Even this exact induction gives only $\lceil m/w\rceil$ input-word probes on a RAM. Simulate each fresh input-word read by at most $w$ bit queries. Private computations and revisiting stored values are free in this simulation. In fact the uniform duplicate-slot family has an $O(n/w+\log w)$ word-RAM algorithm. In each packed word compare all 16-bit lanes simultaneously with each of the eight real clause encodings. XOR with a broadcast copy of the encoding. OR the result with successive right shifts by 8, 4, 2, 1, then complement and mask the low bit of every lane. Each resulting low bit marks an equal record because it depends on exactly the original 16 bits of that lane. Accumulate the eight existence flags over the input. If a general solver uses this fast path it can check that all active lanes are legal real clauses or the filler in the same pass, and otherwise transfer to its generic algorithm. Handle the header and the active mask of the last word separately. The lane constants can be prepared by doubling in $O(\log w)$ word operations. This family achieves its parity-query lower bound at every length while permitting sublinear time in encoded bits. The optimality being lifted concerns access to the selectors.

## What would certify an unrestricted RAM exclusion?

Fix an effective binary coding of standard RAM programs, their admissible word-size constants, and integer time multipliers $C\ge1$. For exponent $c$ and test horizon $H$, let $a_c(H)$ be the minimum package length among candidates returning the correct SAT answer within $C(n+1)^c$ steps on every well-formed input of length $n\le H$. Each individual finite test is decidable by bounded simulation and truth-table evaluation. The minimum exists because an exhaustive SAT decider with a sufficiently large finite multiplier passes any finite horizon.

An unrestricted $O(n^c)$ solver exists **if and only if** $a_c(H)$ stays bounded as $H$ grows. The forward implication fixes its code and multiplier. Conversely, if one length bound $K$ suffices at all horizons, the nested nonempty sets of passing packages of length at most $K$ have a common member because there are only finitely many such packages. It passes every input. Thus a valid induction for the original problem could prove that for every $K$ a finite collection of explicitly checked inputs eliminates *every* package of length at most $K$. The next induction step must defeat newly allowed programs and multipliers, as well as extending input size. The duplicate-clause lift and the rescan clock do not establish that step.
