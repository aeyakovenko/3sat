# Cumulative descriptions of sets of memories that guarantee a SAT verdict

**Research journal, 24 November 2026.** Consider a deterministic logarithmic-word RAM that signals UNSAT on every unsatisfiable explicit formula and never gives this signal on a satisfiable formula. Write $N$ for the encoded bit length and $E$ for its first signal time on an unsatisfiable input. A row at time $t$ describes a set $I_t$ of pairs of controller and writable memory. An inductive proof uses the true initial configuration for $I_0$, the set of all configurations with the chosen signal controller property for $I_E$, and arbitrary intermediate rows. It requires $\operatorname{step}(I_t)\subseteq I_{t+1}$ at each step. Halt states idle. Treat immediate signals directly. The true trace belongs to the successive sets, but a row can allow other read values, registers, control paths and final memories. Inductive set invariants and abstract interpretation are classical. The question here is how much description their use can save on actual SAT computations. [Cousot and Cousot](https://www.di.ens.fr/~cousot/COUSOTpapers/POPL77.shtml) · [Earlier time-uniform invariant lower bound in the journal](adaptive-invariant-selectors.md)

In the first format, a row string $z_t$ specifies an allowed-controller predicate $C(r)$ and a product of word domains, which may depend on that controller:
$$
 (r,M)\in I_t\quad\Longleftrightarrow\quad C(r)\land\forall a\;M[a]\in D(r,a).
$$
All predicates have fixed polylogarithmic-time deterministic evaluators with access to $t,F,z_t$. Access to the input formula and row string is random access. Require nonempty domains at permitted controllers. One convenient total syntax always allows a particular locally computable default along with other accepted words. In the more general word-label format below, domains are indexed by a class key and several addresses can share one unknown value. All rows used in the asymptotic statement have fixed uniform clocks and guaranteed nonemptiness in their format. No computation of the optimal rows is assumed. The cost is the minimum, over whole inductive proofs on this run, of
$$
 K=E+\sum_{0<t<E}|z_t|.
$$
Use infinity if no proof exists. Taking the minimum of each length independently while dropping the transition obligations would change the problem.

**Theorem.** For either format, for every fixed $c<(1+\sqrt5)/2$ the worst $K$ over unsatisfiable inputs is outside $O(N^c)$. Given a separate sound nondeterministic UNSAT reference recognizing all negatives within $N^{d+o(1)}$ steps for fixed $d\ge1$, this conclusion holds for $c\ge1$ whenever $d(c-1)<1$. With a reference in $O(N\operatorname{polylog}N)$, a signed hard family has $K\ge N^2/\operatorname{polylog}N$. In particular on that family an actual linear-time recognizer cannot always replace its memory by a cheap inductive assertion even if the assertion can discard dead memory and admit other future executions. A linear-time run can incur this cost. The published golden-ratio time–peak-space bound and cumulative-memory lower-bound framework concern related resources. Priority of the cumulative *verdict-invariant* formulation has not been established. [Williams, Theorem 4.11](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Beame and Kornerup](https://arxiv.org/abs/2301.05680)

## Detecting a bad interval by querying its two boundary rows

Choose some boundary times including zero and $E$. With rows fixed as read-only data, a defect selects two consecutive boundaries $i,j$ and is a witness to
$$
 \exists(r,M)\in I_i:\quad \operatorname{step}^{j-i}(r,M)\notin I_j.
$$
Guess an allowed starting controller and perform the native instructions in order. For every read consult a local overlay of preceding writes, including writes of zero. On an untouched address use its previously guessed initial word, or guess and remember an initial word allowed by the *starting* row at that address and the starting controller. Evaluate immutable input loads on the actual formula. At the end exhibit a forbidden controller or one address whose final word is outside the ending row's domain. An endpoint challenge to an address that was never touched can still guess its original allowed value. Initialization and terminal signal use their known predicates directly.

Every real counterexample supplies the guesses. Conversely the guessed starting words constitute a consistent finite partial memory. They extend to a whole allowed starting memory because the remaining word domains are nonempty and independent. From that full memory, determinism reproduces every proposed access and reaches the claimed defect. Consequently this test is exact for intervals, including adaptive reads. The initial state is fixed, so a chart without defects forces a true signal by induction on its boundaries. An honest proof remains valid on deleting intermediate rows, by composition of its actual one-step inclusions. A verifier uses the guessed pre-memory only on the addresses needed for this counterfactual run and the endpoint test. No last-writer across adjacent replays has to be identified.

## Shared unknown words

For a strictly more expressive format give the row a key map $k(r,a)$, a word permutation $T_{r,a}$ with both directions locally computable, and one nonempty word domain $D(r,k)$ for each class. For instance $T_{r,a}$ can XOR a public mask specific to the address. Require that for some assignment $v$ of labels,
$$
 C(r),\qquad v(k)\in D(r,k),\qquad M[a]=T_{r,a}(v(k(r,a)))\quad\text{for all }a.
$$
The label assignment is unconstrained in size, and is never transmitted. Different classes choose their labels independently. Keys have logarithmic length. For a syntax guaranteeing the two inverse maps on every row, one may fix an invertible operation such as XOR or a locally computed reversible circuit and reverse its gates for the inverse. The full product format uses one class per address.

A simulation from this row remembers the *normalized* original label for each class queried, including any endpoint queries to addresses untouched by the segment. At a first query it guesses an allowed label and at each member address transforms the label with that address's $T$. The write overlay still uses the native address, since overwriting one cell after the starting boundary need not change any other class member. Any assignment of allowed labels to the queried classes extends by the defaults on the others. At the endpoint, nonmembership has a forbidden controller, a forbidden normalized label, or two addresses with the same ending key but different normalized values. These three conditions characterize failure even when some keys have no addresses. The defect procedure can guess the two ending addresses and recover their words using the same overlay and original label assignments. Its time for an interval of width $w$ is $(1+w)\operatorname{polylog}N$ on a polynomial clock. Tagged, initially empty tables or balanced dictionaries suffice. ## Charging the proof to a complementary time simulation

Suppose $K=O(N^c)$ on all unsatisfiable inputs. The local bounded-computation formula for any $R$-step nondeterministic RAM with $m$ public words has $N=H^{1+o(1)}$ bits for $H=\max(2,R,m)$ and a polylogarithmic-time word generator from the public data. Initially absence of a bounded accepting branch is recognized nondeterministically in $(R^d+m^d+1)H^{o(1)}$ time by the ordinary materialized formula and UNSAT reference. One may take $d=c$ because $E\le K$ on negatives, so the target itself gives this reference with a cutoff.

Suppose inductively the bound is $(R^e+m^d+1)H^{o(1)}$ for $1\le e\le d$. On an honest negative select a minimum-length row in each full disjoint internal window of $w=\lceil H^x\rceil$ steps. Their combined lengths are at most $K/w$, the number of rows is at most $K/w$, and consecutive boundaries including the endpoints differ by at most $2w+O(1)$. Guess the selected rows and timestamps under these size and clock caps. A deterministic preliminary syntax check may scan their full directory. The defect recognizer then runs in $H^{x+o(1)}$ time on public data of $(m+H^{c-x}+1)H^{o(1)}$ words. It queries the selected rows and the virtual formula, and uses a new private overlay for the interval it tests. The inductive nonacceptance certificate for this recognizer proves that the entire chart is sound. Choosing $x=cd/(e+d)$ gives $e'=cde/(e+d)$, with the separate public-input term unchanged. The iterates from $d$ cross below one at a finite stage if $d(c-1)<1$. Applying the bounded complementary diagonal with $R=m^D$, $D>d$, gives the contradiction. Taking $c=d$ yields the stated golden ratio. For $c<1$ enlarge the hypothetical exponent. With a near-linear reference one can instead use the signed root directly, a cutoff $B=H^2/\log^A H$ and $w=\lceil\sqrt B\rceil$ with sufficiently large fixed $A$. Any genuine chart of cost at most $B$ permits certification of the defect test's nonacceptance before the self-input clock; the direct signed argument gives the claimed $N^2/\operatorname{polylog}N$ lower bound. [Window selection and original recurrence](cumulative-sat-memory.md) · [Signed source and local access](packed-band-transfer.md)

There is a positive analogue. For a sound deterministic SAT signal guaranteed on all positives, use the corresponding terminal region. If UNSAT has a sound reference of time $O(N^d\operatorname{polylog}N)$, infinitely many satisfiable inputs require $K\ge N^{2/d}/\operatorname{polylog}N$. Take the locally generated positive hierarchy formulas in the [unary witness argument](positive-witness-hierarchy.md). A short proof on a positive input can be guessed using windows of width close to $\sqrt K$, and the absence of its one existential defect established by one application of the reference to an explicit formula of length $O((\sqrt K+n_0+1)\operatorname{polylog}N)$, where $n_0$ is the much shorter source input length. Short charts on every sufficiently large positive length would accept the unary hierarchy language in its prohibited nondeterministic time. Its hard positives need not be the signed negative inputs above. A hypothetical $K=O(N^c)$ on positives supplies a deterministic reference by timing out the sound positive signal after $O(N^c)$ steps, giving the unconditional exclusion $c<\sqrt2$ there. The negative first-failure argument for explicitly advertised snapshot offers does not assume the whole inductive proof exists on negative inputs. The positive statement here uses the positive hierarchy instead.

## A linear-time comparison for which independent word domains are expensive

The distinction between these two formats can be quadratic up to logarithms on one and the same native execution. Use a permutation $\pi$ of $[m]$, $m=2^p$, encoded as $m$ fields of $p$ bits, so $N=\Theta(mp)$. The following fixed RAM returns a constant on these inputs. It loops over all records, and for every bit $j$ of $i$ stores that bit in **both** banks at key $(\pi(i),j)$. Then it visits all keys $(u,j)$ in increasing lexicographic order, compares the two words at that key, and signals success exactly when all comparisons pass; a discrepancy enters a permanent failure state. All loops have a fixed constant number of instructions per bit, including packed input loads with boundary handling by a fixed layout. Each bank always contains the same bits after a pair of stores, so every actual run succeeds. Repeated target indices on malformed permutation data do not change that conclusion. Outside the specified lengths one can immediately return the same constant. Runtime is $O(mp)=O(N)$.

Immediately after both banks are filled, their values are the bits of $\pi^{-1}(u)$. The last quarter of all target keys remains untouched throughout the first half of the comparison pass, an interval of $\Theta(N)$ instructions. At any time in that interval fix the true controller $r$. In any Cartesian product row of a valid proof through success, both domains for each remaining key must be the *same singleton*. Otherwise combine two unequal admissible values for that pair with the other true memory values. From the same controller the program must fail, either at this comparison or an earlier one, contradicting induction to terminal success. It follows that membership of word one at a designated first-bank address reveals one actual inverse bit, even if retrieving a value from a singleton domain would otherwise be computationally expensive.

Fix the product evaluator's polylogarithmic probe budget. Given the row, its length, the time and the controller as advice, query membership for the $p$ bits of a remaining target and test the proposed inverse by reading one forward entry. This takes at most $Q=\log^{O(1)}N$ forward permutation probes, since each input-word probe intersects only a constant number of fields. Choose $h=\lfloor m/(8Q)\rfloor$ distinct targets in the common last quarter. For a uniformly random permutation, any fixed such advice can recover all these inverses with probability at most $\binom{hQ}{h}/\binom{m}{h}\le (hQ/m)^h\le8^{-h}$. Indeed every new queried position exposes a uniformly random previously unseen image regardless of earlier answers. The verification probe for each target ensures that even an inferred inverse is exposed. A union over strings of length below $h$, times, controllers and row lengths has probability below one for large $m$; the metadata requires $O(\log N)$ bits. Hence one permutation at each sufficiently large $m$ forces $\Omega(m/Q)$ bits in **every** product row throughout this interval. Its cumulative cost is $\Omega(N^2/\operatorname{polylog}N)$. This is an information-theoretic separation with the original input available to every evaluator. [Earlier inversion exposure calculation](scatter-inverse-live-reads.md) · [Prior work on permutation inversion with preprocessing](https://eccc.weizmann.ac.il/report/2018/182/)

In contrast, one fixed shared-label evaluator uses $O(\log N)$ bits per time on **every** input to this comparison. After each pair of stores give the two copies of every key a common arbitrary word label. Between the two stores separate the just-written address into a singleton class pinned to the bit about to be duplicated. At the second store the common class can be restored. Before and after a comparison both banks retain their equalities. At the intermediate instruction after the first load, pin the current class to its loaded register; after the second load also require the two registers to agree before branching. The controller predicate fixes the clocked loop phase, counters, and other non-data registers needed for the next step. During scattering the target and computed bit can be recorded from the true input in constantly many words; during comparison permit arbitrary compared values subject to the stated current-key pins. The machine can reset the data registers at phase boundaries and overwrite a scratch register before its next use. The initial state satisfies all pair equalities, and every transition out of each displayed set preserves the next one. All these tests need only time, loop indices, a bounded number of flags or words and indexed input access, so the aggregate cost is $O(N\log N)$. This certifies the final comparison verdict across arbitrary counterfactual labels and arbitrary read values at future equal pairs. The example explains why a blanket upper bound for independent-cell verdict certificates of linear-time programs fails, and why dominance of one description format cannot be inferred merely from the small number of times each real cell is read. Its constant verdict does not provide a SAT algorithm.
