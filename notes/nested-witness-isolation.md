# A verified isolation header for witness-bit queries

**Research journal, 24 November 2026.** Let an explicit packed 3-CNF have encoded length $n$ and $v$ distinct occurring variables. Given an exact deterministic SAT algorithm of time $O(n^d\operatorname{polylog}n)$, for fixed $d\ge1$, Las Vegas preprocessing takes expected $n^d\operatorname{polylog}n$ time on a satisfiable formula. Its result specifies one actual satisfying assignment. Each requested coordinate of that same assignment is returned by **one ordinary SAT decision** in $n^d\operatorname{polylog}n$ time. The selection uses $3v+1$ public random bits per trial. In addition to the formula, keep the successful random string and an $O(\log(v+2))$-bit prefix length. The public string is real data when no shared random tape is available. The construction combines Valiant–Vazirani isolation with a search for the deepest feasible prefix and a check that it has a unique projection. [Valiant and Vazirani](https://ics.uci.edu/~vazirani/ValVaz.pdf)

## One hash and a nested search

First densely renumber occurring variables in increasing order of their input names and retain the dictionary. Let $W\subseteq\{0,1\}^v$ denote the satisfying assignments on these coordinates. The algorithm detects an unsatisfiable input by one ordinary SAT call. When $v=0$ the empty assignment suffices on a positive instance. For $v\ge1$ choose independent fair bits for the diagonals of a $(v+1)$-by-$v$ binary Toeplitz matrix $A$ and for a $(v+1)$-bit offset $t$. Let $H(x)=Ax+t$ over $\mathbb F_2$. For a nonzero difference vector, choose the least input index with a nonzero bit. In each successive output row this choice exposes a fresh highest diagonal with coefficient one. Thus the difference hashes uniformly. Conditioning on $A$, the independent offset makes the first point's image uniform, so each pair of distinct inputs has independent uniform images. Every initial segment of output coordinates inherits this property.

For $0\le j\le v+1$ let $W_j$ consist of the witnesses with the first $j$ hash bits zero. All levels use the *same* matrix and offset. Let $j_0=\lceil\log_2|W|\rceil+1$, a value needed only in the analysis. For $Z=|W_{j_0}|$ the mean $\mu=|W|2^{-j_0}$ lies in $[1/4,1/2]$. Pairwise independence gives $\mathbb E[Z(Z-1)]\le\mu^2$. The pointwise inequality $1_{Z=1}\ge Z-Z(Z-1)$ proves $\Pr[Z=1]\ge\mu-\mu^2\ge3/16$. The extra output row covers even the full witness cube.

Nonemptiness of $W_j$ is monotone in $j$. Binary-search its last true level $j_*$ in $O(\log(v+2))$ yes/no queries. Test one additional formula asking whether there exist *distinct original assignments* $x,y\in W_{j_*}$. A YES answer discards the trial. A NO answer, together with established nonemptiness, certifies uniqueness. If $W_{j_0}$ was a singleton, its nonempty subset $W_{j_*}$ is the same singleton. Independent trials therefore take at most $16/3$ attempts in expectation. For any coordinate $i$, ask whether $W_{j_*}$ contains an $x$ with $x_i=1$. After the uniqueness check all such answers agree with one actual witness, including answers to coordinates chosen adaptively. Cook-tableau auxiliary variables in the queries can have multiple completions.

For a fixed ordered output set of $h$ original coordinates the expected call count is $O(\log(v+2)+h)$ and the time bound is $O((1+h)n^d\operatorname{polylog}n)$, including materializing each query. Recovering the whole assignment takes $v$ postprocessing decisions by this method. Packed dense output uses $v$ bits; printing pairs of original names and truth values uses their combined encoded name lengths plus ordinary framing, $O(n)$ bits for the fixed-width literal encoding. Assigning zero to every unused name gives a default extension. A request to print an entry for each of an arbitrarily large declared-but-unused name range would separately incur that output length.

## Query size with dense hashes

The matrix is never expanded to $(v+1)v$ indexed incidences. Write $a_{i-j}$ for the diagonals, and form the two binary polynomials with coefficients $(a_{q-v+1})_{q=0}^{2v-1}$ and $(x_j)_{j=0}^{v-1}$. The parity of coefficient $v-1+i$ of their integer convolution is row $i$ of $Ax$. For $w=\lceil\log_2(v+1)\rceil$, pack each coefficient as a base-$2^w$ digit. Each integer-product coefficient is at most $v<2^w$, so no carry crosses digits. The operand bit lengths are $O(v\log(v+2))$. Deterministic multitape integer multiplication, followed by reading the selected digit bits and adding the offset, takes $v\operatorname{polylog}v$ bit operations in total. Simulation of these tapes on a logarithmic-word RAM fits this bound. [Harvey and van der Hoeven](https://annals.math.princeton.edu/2021/193-2/p04)

A bounded source guesses one or two dense assignments, checks all source clauses, performs the indicated hash products, and tests any additional bit or inequality. All public input, the working clock, and the guessed strings fit $n\operatorname{polylog}n$ in the explicit regime: the original binary encoding accounts for the occurrences and names. Densely renumbering by sorting is quasilinear in $n$; the inverse name dictionary is common to all queries. The packed bounded-computation reduction then produces each ordinary width-three instance in $n\operatorname{polylog}n$ time and encoded bits. Every existential quantifier here is over one ordinary computation. Verification never calls a SAT solver from inside the encoded verifier. This is why the runtime exponent $d$ stays unchanged per request. [Packed 3-CNF reduction](packed-band-transfer.md)

For a succinct input specifying local clauses of an expanded formula, $n$ in this accounting is the **expanded** binary length. If computation of a local source clause costs additional time, pay for generating the explicit formula or accessing these clauses in the source's clock. Neither a small clause circuit nor the short prefix-length transcript makes the $O(v)$ random bits free advice for a small witness lookup circuit. For a family of at most $2^z$ positive descriptors with the same coordinate dimension, $O(z+1)$ independent public trials suffice with positive probability to give at least one isolating deepest bucket for *every* descriptor, by a union bound. The shared bank then costs $O(v(z+1))$ bits, and selecting a successful trial still needs the feasibility and uniqueness tests.

## What changes with two batches

Ben-David, Chor, Goldreich and Luby already obtained a fast parallel distributional search reduction by trying universal hashes at each output length and then reducing unique search to decision. We use common prefixes of one public hash so that feasibility can be binary-searched and uniqueness can be checked before any bit request. [Ben-David, Chor, Goldreich and Luby, Section 3](https://www.wisdom.weizmann.ac.il/~oded/PSX/aver.pdf)

One can instead query *all* prefix levels in parallel, find $j_*$, then query both bit polarities at $j_*$ for every witness coordinate in a second parallel batch. Since the bucket is nonempty, it is a singleton precisely when each coordinate allows only one polarity. This validation uses only ordinary nonempty-intersection questions. Run a fixed number of independent trials together to get success probability greater than $1/2$, returning failure if none passed. The two batches use $O(v)$ decision answers in total. A zero-error algorithm can repeat both batches on failure, giving a bounded expected number of rounds rather than a deterministic two-round cap. On a sequential RAM the calls still have a total running-time charge.

For comparison, in the oracle model where the input is just $v$ and a hidden $W$, Kawachi, Rossman and Watanabe proved that a **single** nonadaptive batch for finding a witness with constant success for arbitrary $W$ requires $\Omega(v^2)$ questions, even for the wider monotone query model. Two adaptive batches avoid that bound. A hidden uniformly random singleton gives the simpler $\Omega(v)$ lower bound even with full adaptivity: after fixing the coins a depth-$q$ binary answer tree has at most $2^q$ distinct outputs. The average success probability is at most $2^{q-v}$. Neither oracle lower bound applies to an algorithm inspecting the explicit input formula or the internal computation of its SAT solver. [Kawachi, Rossman and Watanabe](https://www.math.toronto.edu/rossman/witness.pdf)

A direct sparse-XOR substitution also has a quantitative limitation. Project an exact-one formula onto its $v$ original indicator bits, so $W=\{e_1,\ldots,e_v\}$. An $O(v)$-gate running OR with a test that the next one never follows a previous one gives an explicit width-three encoding of $O(v\log v)$ bits with deterministic auxiliary extensions. For a binary $j$-row matrix and uniform right-hand side, isolation of the projections occurs with probability exactly the number of columns occurring once divided by $2^j$. At $j=\log_2 v+O(1)$, constant success demands $\Omega(v)$ distinct singleton columns. At most $2^{h_2(1/4)j}=o(v)$ column strings have weight at most $j/4$, by the binary entropy bound. Thus the matrix must have $\Omega(v\log v)$ nonzero incidences. The same expectation bound holds for randomized matrices with constant overall success and independent uniform right-hand side. A direct incidence-by-incidence encoding with fixed $\Theta(\log v)$-bit names pays $\Omega(v\log^2 v)$ bits. Shared computation, hashing auxiliary bits, or choosing a right-hand side correlated with the matrix can change that conclusion. In particular the one-hot instance itself has an easy witness; this example tests the proposed hashing step.

The finite audit compared direct Toeplitz evaluation with carry-free multiplication and exhausted every nonempty projected witness set and all public hash coins for $v=1,2,3$. The minimum probabilities of a certified singleton at the deepest nonempty level were $5/8$, $5/8$, and $73/128$, respectively. This is a resource accounting application of classical isolation. Priority for the particular nested search implementation remains unverified. The per-bit decision cost and the explicit printing cost leave the unrestricted SAT time target open.
