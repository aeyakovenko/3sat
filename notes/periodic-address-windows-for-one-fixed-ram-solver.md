# One fixed RAM solver can separate its data addresses beyond its own proposed test radius

Let $\rho$ be a partial computable map from binary program texts to nonnegative integers. Suppose $P$ decides SAT in $O(N^k)$ time for $k\in\{1,2,3\}$ on the register word RAM. There is a **single fixed equivalent program** $Q$ with the same asymptotic time bound such that, whenever $\rho(Q)$ is defined, every sufficiently long input has the following property throughout its execution. In every window of $\rho(Q)$ consecutive data-memory references, at most one distinct address other than a fixed hub $h$ appears. Every memory operation after register-only initialization is a LOAD immediately paired with a STORE to the same address (with only register instructions between them). After initialization the program counter follows a fixed repeated instruction body up to its terminal test. A graph joining distinct successive data addresses is consequently a subgraph of a star. The assertion also holds at windows crossing the beginning or end of a read/write pair.

Use totalized word arithmetic, bitwise masks, a fixed program with finitely many named registers, and separate register-addressed LOAD and STORE instructions. Program-counter instruction fetches are outside the data-address trace. Word width $W=\Theta(\log(N+2))$ grows with input length. The compiled program may use a larger fixed register file. The statement is about a standard unrestricted RAM, independent of results for a particular two-register or five-instruction census.

**One read and one write.** For a fixed $P$, store the guest PC and registers in named host registers. Unroll its finite instruction list into a branchless register computation. For each possible PC use the all-ones or zero mask stating that this slot is active. Select the actual data address from the active memory instruction; use $h$ when there is none. Read its value $v$ once. Write the guest payload at that same address for an active STORE, and otherwise write $v$. Select the new guest PC and register values from the active slot, with the read result available for an active LOAD. Conditional branches select a next-PC word. Finite dormant operations are totalized on dummy operands if necessary. This uses a fixed number of ordinary operations per guest step depending on $P$; it needs no code lookup in data memory. A literal equality mask can be built from a comparison bit and word negation. It is harmless for $h$ to be a genuine input or work address: a padding write restores exactly the word just read there. An actual guest store to $h$ retains its full intended effect. [Classical control-to-data conversion](https://doi.org/10.1145/567067.567085)

Between real steps insert $R$ dummy ticks. With a phase counter and a selection mask the dummy tick runs the very same instruction body, chooses $h$, writes its old value, and leaves the simulated guest state alone. A bounded equality test wraps the phase; the loop's only data-dependent exit observes guest termination. An a priori length clock could instead keep an absorbing guest state until that clock expires. For fixed $R$, input-dependent nonhub read/write pairs are at least $2R$ hub references apart. Collapsing adjacent equal addresses still gives the star, although deleting all dummy references can recover the guest's original address geometry.

**Choosing the radius for the actual compiled text.** Construct $Q_C$ with one binary integer parameter $C$ and the fixed algorithms $P,\rho$. Its description length is $o(C)$ as $C\to\infty$, for example $O_{P,\rho}((1+\log(C+2))^2)$ with ordinary binary literals and labels. Choose $C$ large enough that $|Q_C|\le C$. A fixed source-free procedure dovetails $\rho(s)$ on all binary strings $|s|\le C$ and reports completed natural-number outputs. There are finitely many such strings, even when some computations never halt. Their completed outputs have a finite maximum $M$, with zero as the default.

On each run the boot executes at most $W$ steps of this dovetail and retains the largest completed report seen. It does **not** access data memory. For example simulate one fixed one-tape reporter with two register-encoded stacks of tape symbols, a finite state and a report accumulator. A push consists of appending a fixed-width digit. Stop before any register overflow, discarding any incomplete report. The width can be counted using shifts on an all-ones word. A binary parameter too large to initialize, or a width unable to encode the fixed guest control, may transfer directly to $P$ on the untouched file. On all sufficiently large widths the initial registers fit. Every fixed finite prefix of the unbounded reporter uses finitely many bits, so the finite prefix through its last actual report runs to completion at every sufficiently large $W$. Further unreported searches may overflow, without changing the retained maximum. Use $R=\max(1,\text{retained maximum})$. Always $R\le\max(1,M)$ on faithful boots, and eventually $R=\max(1,M)\ge\rho(Q_C)$ whenever that value exists. A phase counter can wrap by equality before an increment that would overflow. This proof allows $\rho$ to be promised to halt only on correct fast programs. Totality and the clock bound of $Q_C$ are independent of termination of any of the subsearches.

Boot time is $O_{P,\rho,C}(1+W)$, and the slowdown per guest step is bounded by a constant depending on this one $Q_C$. The memory-free boot creates no exceptional address window at the start. The normal form obstructs a proposed necessary condition that **every** fast representative eventually exhibit two distinct nonhub data addresses in a computably selected bounded window, even when the radius is selected from its full code and the hard files may depend on that code. A lower bound on programs after separately justified elimination of these idle pairs, on windows growing unboundedly with input length, or at a preassigned exact multiplier remains a different question. In particular the larger multiplier of $Q_C$ is outside the self-size argument; $\rho$ cannot simply be replaced by an arbitrary function of that multiplier. The existing first-failure dichotomy treats finite lengths for exact deadlines. [First-failure lengths](first-failure-lengths-for-exact-sat-clocks.md)

## What changes if the address graph must have bounded degree

Take one fixed native program that reads $m$ designated physical cells in order $1,\ldots,m$, then reads them in the order $\pi(1),\ldots,\pi(m)$. An independent input array supplies any chosen permutation $\pi$ as ordinary words. The program can accumulate an order-dependent rolling hash and takes $O(m)$ steps. A **faithful physical simulation** here must visit the same $m$ distinguishable cells, or a fixed injective correspondence to them within that run, in both required orders as subsequences. Other reads, writes, scratch addresses, the topology and the correspondence itself may all be chosen after seeing the whole permutation. A simulator deciding only the final answer need not preserve these visits.

Let a candidate walk have $S$ data references, $V$ distinct addresses, maximum degree $\Delta$ and treewidth $\tau$ in the simple graph joining consecutive distinct addresses. For some permutation, every such walk obeys
$$
  (\tau+1)V + S + \sum_{i<S}\log_2(1+\deg(v_i)) = \Omega(m\log m).
$$
Consequently $S(1+\tau+\log(\Delta+1))=\Omega(m\log m)$. The permutation is hard for all possible walks simultaneously. For a tree of degree at most $\Delta$, the normalized walk needs only its choices between staying, taking a known neighboring edge and visiting a new vertex. Give fresh vertices discovery numbers, and mark each required first or second scan in the walk. The first scan assigns the physical labels; the marked second scan then recovers $\pi$. An arbitrary scratch label cannot carry additional permutation information in this decoding.

For the quantitative bound, the abstract graph itself has a description of $O((\tau+1)V)$ bits. Root a width-$\tau$ tree decomposition and contract any child bag contained in its parent, reattaching its children. After contraction every remaining nonroot bag introduces at least one vertex, and connectedness of vertex occurrences gives each vertex just one introduction. Encode the resulting rooted ordered tree with $O(V+1)$ bits. In each child list the retained parent vertices by a subset mask and the number of new vertices. Give introduced vertices fresh indices in traversal order. When each vertex is introduced, mark its edges to the retained vertices and its earlier same-bag introductions with at most $\tau+1$ flags. Edges cannot first meet from disjoint branches; if an older endpoint occurs together with the newly introduced vertex below this bag, connectedness forces it to be present already here. This recovers the whole unlabeled graph with the claimed budget. Encode the walk start and length, the next sorted neighbor or stay using $\lceil\log_2(1+\deg(v_i))\rceil$ bits, and two scan marker bits per visit. Fewer than $m!$ descriptions of length below $\log_2(m!)-1$ exist. Any permutation missed by those descriptions has the bound simultaneously for every faithful embedding. The same argument gives exponentially small density for permutations represented using fewer than a sufficiently small constant times $m\log m$ in the displayed budget.

For every fixed $\Delta\ge3$, a balanced $(\Delta-1)$-ary tree on the distinguished leaves attains $O(m\log_{\Delta-1}m)$ references by following paths between successive requested leaves (with the usual $O(m)$ floor). Thus the $\Omega(m\log m)$ limitation for bounded-degree trees is sharp for fixed $\Delta\ge3$. Conversely if $\tau=O(1)$ and $S=O(m)$ on the hard permutation, a linear number of visits are at vertices of degree $m^{\Omega(1)}$: low-degree visits cannot contribute enough to the logarithmic sum. The star construction uses exactly such a repeatedly visited address. None of these faithful simulation bounds assumes that an arbitrary SAT solver must perform the two scans.

There is an indivisible-token version without a fixed physical copy. Supply $m$ distinct opaque atoms once each in the initial memory, and require the output stream $A_1,\ldots,A_m,A_{\pi(1)},\ldots,A_{\pi(m)}$. Permit arbitrary read order, copies, advance knowledge of $\pi$, and a fixed number of token registers. In the abstract graph mark vertices initially containing an atom and give those atoms anonymous discovery numbers. For each memory visit record which current atom is loaded, retained, overwritten or copied between the fixed register slots and the current cell. Between visits arbitrary token copies induce one of only constantly many maps from the old slots to the new slots; each emitted atom additionally costs one constant-size slot choice, $O(m)$ in total. The first output pass names every anonymous original, and the second recovers $\pi$. The same weighted lower bound follows, with a constant depending on the slot count. General arithmetic can encode symbols or create values from permutation-dependent control words, so it falls outside this argument. The distinction has a literature in external-memory permutation: the classical comparison/indivisibility bound and the subsequent word-operation results are in different models from this per-run address graph.
