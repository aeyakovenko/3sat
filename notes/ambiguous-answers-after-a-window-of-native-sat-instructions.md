# What an actual SAT execution still leaves ambiguous before the next truthful answer

A fully annotated input can encode many disjointness queries and their claimed answers, with exactly one satisfying assignment per false claim. Suppose a deterministic SAT solver takes $O(L)$ steps on the truthful files in the [transcript construction](accumulated-work-on-stopped-sat-executions.md), where $L$ counts encoded bits. At many query positions on **one genuine run**, even its complete recent native instruction history is compatible with opposite values of the next truthful answer. This result measures what the one run has already computed. There is no charge for visiting empty intervals or replaying either candidate annotation.

Use $M=s^4$, $K=M^D$ for fixed $D\ge2$, $q=Ks$, $L=\Theta_D(q\log M)$, and $H=(\log M/\log\log M)^2$. After the $j$th update and its query have been delivered, stop at the issue of the load that will first receive its answer annotation. The program itself decided when to request that slot. A **round interval** extends from just before replying with the preceding answer through the next such cut. For the first round start immediately before supplying the first insertion, after graph initialization. Include the native updates between fresh loads, the true preceding annotation, the current update and query fields, and the pending address. For the first $b-1$ cuts use all available rounds when fewer than $b$ exist.

At a cut give an observer the following view, all on the actual run.

* Supply the complete instruction records over the last $b=\lfloor\log L/(\log\log L)^3\rfloor$ rounds, including register states, opcodes, memory and input addresses, read replies, stored values, and boundary positions. It may see the incoming operation fields, public logical labels and absolute clock at those boundaries. No reply from the pending answer word has been consumed.
* In addition, allow $d=\lfloor(\log L)^2/(\log\log L)^3\rfloor$ adaptive word probes. They can read the frozen native workspace, the earlier revealed packet map (including a present/absent flag), the original graph, or the actual chronological log of all earlier operations and truthful answers. Current update and query fields are known. A not-yet-revealed packet has an absence tag; supplying its future contents would be giving information unavailable at the cut. The observer starts each query with this view and no private persistent information from uncharged earlier rounds. Its fixed rule can depend on the program, size, stage and the entire supplied view. Local computation is unrestricted. A word costs $O(1)$ probes in the simulation.
* Fix the rule in advance, independently of the unknown database and stream. Its choices and replies are added to the view. Public nonuniform rules are allowed in the cell-probe model. The quantifier is “for each fixed observer”; a hindsight choice between constant-zero and constant-one predictors could itself reveal the answer.

Call the view **ambiguous** if two legal histories with truthful earlier claims give precisely this view, with different true answers to the current query. The alternative may change the earlier database or updates, but must keep all information visible in the view, including the observer's probes and their replies. Both histories extend to complete truthful ordinary files in the construction. The current logical query and update are the same in both histories.

**Theorem.** At all sufficiently large template scales, some fully truthful master has $\Omega_{P,D}(KH)$ ambiguous cuts for this observer. Greedily retaining endpoints spaced at least $b+1$ rounds apart gives $\Omega_{P,D}(KH/(b+1))$ cuts with **pairwise disjoint chronological windows**. They are on the actual execution of a single unsatisfiable file and on the common prefix of its final-bit uniquely satisfiable neighbor. For any fixed $\epsilon>0$, a sufficiently large fixed $D$ gives at least $L^{1-\epsilon}$ disjoint windows at large sizes. No strength claim about the two answers' posterior probabilities is needed. ## Exact inference from the observed values

Construct a dynamic algorithm for Ko's insert-only disjointness problem. Maintain the native simulation and assign its packet slots in first-discovery order, with graph initialization, insertions, queries and truthful answers as in the construction. Keep timestamped native instruction records in persistent cells. Store the directory of revealed packets, the graph and the chronological operation log. This takes $O(T+q+M^2)$ probes across all batches and initialization, with $T$ the common master time through its last pending answer. The initialization may be done during free preprocessing. A bounded number of words per native step suffices, and a linear prefix clock guarantees a polynomial address range for the log. Save all persistent control in charged cells.

At query $j$ fetch the last $b$ round intervals into transient local storage. Read lengths or pointers to locate their records. Over the whole stream at most $O(b(T+q))$ probes suffice for all such views: each logged record is fetched by at most $b$ windows. Execute the additional rule, reading at most $O(d)$ words. An insertion immediately before a query can be buffered in $O(1)$ persistent cells; its master simulation can be performed during either callback while respecting its order. Computation time of the observer and of the following classification is free within one cell-probe operation.

Classify whether this same view occurs with either truthful answer. For a uniform effective rule, one way is to enumerate every database and legal prefix at this finite size, run the same native simulation and observer using its truthful prior claims, and retain the histories with identical views. The proposed next answer is **never given** to the real master during this simulation. An alternative's answer can be computed from its own data during the free enumeration. Correctness of the SAT program ensures every legal history reaches its pending new load, by the opposite-completion argument. For a nonuniform local rule, the finite classification is itself a fixed local function. The classification depends only on the view and the fixed parameters. It does not have free access to the real database.

If the view determines the bit, return that bit and use it as the truthful annotation for the continuation. If both values are possible, compare the at most $s$ current-batch insertions directly with the appropriate database row in $O(s)$ probes. This fallback ensures correctness on each legal input; there is no inference from the hard distribution about the answer on other inputs. Let $A$ count the ambiguous cuts of the resulting single master. The total online probe cost is at most
\[
             O\big(b(T+q)+qd+sA+M^2\big).
\]
The same random-batch embedding as in the transcript theorem lower-bounds the expectation by $\Omega(qH)$, using Ko's Theorem 1.1 in its stated logarithmic-width model. It is legal to sample the earlier batches conditional on the database in free preprocessing, then reproduce all previous logs before the genuine batch. With $T=O(L)$ the first two displayed terms are $O_D(q(\log M)^2/(\log\log M)^3)=o(qH)$. Also $M^2=o(qH)$. Some master must therefore have $sA=\Omega(qH)$. The common final annotation pair and the disjoint-window count follow from the construction and greedy selection of window endpoints in increasing order. [Ko, Theorem 1.1](https://arxiv.org/pdf/2611.11508v1)

The same master and cuts can satisfy the stopped-pair lower bound **at the same time**. When the view is ambiguous, race the two signed continuations and the direct scan as in (1) of the preceding note. Maintain the blank-interval directory; its total $O(p\log p)$ cost is still $o(qH)$. The last term in the upper bound becomes the sum, over *ambiguous* cuts only, of $O(\min\{s,u_{j,0}+g_{j,0},u_{j,1}+g_{j,1}\}+1)$. It must supply $\Omega(qH)$ probes on some master. The cap $s$ implies $\Omega(KH)$ ambiguous cuts on it have both signed costs at least $cH$ for a sufficiently small constant $c>0$. The disjoint-window selection applies within exactly these cuts. Each may need its own alternative truthful history. The two feasible bits can have very different conditional probabilities, and the terminal cut need not itself be ambiguous.

A same-database version holds for any fixed **constant-word summary** of the observed view. In unrestricted graph preprocessing, enumerate all truthful histories for that graph and tabulate which answers occur for each combination of stage, current operands and summary. The number of keys is polynomial in $M$ for any fixed summary width in words and fixed $D$; a large enough fixed coefficient in the *simulator's* logarithmic cell width addresses the table. Native program words retain their original width. One probe to this table suffices for classification during an online query. The preceding proof supplies the same number of ambiguous cuts with alternatives on the **same database** and the same summary and public operands. It does not grant equality of the entire unbounded history in this variant. Alternatively, one may retain the original full-view conclusion while disclosing any fixed graph summary of $o(wH)$ bits per query, fetching it from persistent cells at cost $o(H)$.

## A single-run time lower bound under an observable condition

The same proof works with $b=1$. For example, suppose the transcript of each round of a given correct solver, including the query-processing instructions *before* it first receives the current answer, always determines that answer among all legal truthful histories. The classifier can then skip the direct scan every time. At every sufficiently large size some actual common prefix requires
\[
                  \Omega_{P,D}\!\left(L\frac{\log L}{(\log\log L)^2}\right)
\]
elapsed instructions. The conclusion continues to hold for an observer using $d=o(H)$ probes and at most $o(KH)$ ambiguous cuts per master. In applying this clock conclusion there is no assumption of polynomial time: if a common prefix exceeds $L^2$ it already exceeds the bound. At a scale where all common prefixes are shorter the entire simulation log is polynomially addressable.

This condition has genuine SAT deciders as examples. A program can read the canonical packed slots sequentially, verify each query by scanning the batch's earlier insertions in the graph, and keep the predicted next answer in a designated register until the next input load. On unrecognized inputs it falls back to ordinary complete SAT search. For its causal layouts the last controller already determines the answer. The program uses $O(L+qs)$ time on the family. By contrast a correct solver may copy all words before checking the alleged answers together. Correctness of the final SAT decision does not require a particular next answer to be determined from recent trace values. Proving a lower bound on how such a solver verifies its *whole* transcript remains an offline computation problem.

For a small instance the audit holds the graph fixed, changes an earlier insertion, and verifies complete identical register, address and value histories of a simple scanner from the previous truthful annotation through the next query. The two current answers are opposite, and exact model enumeration checks both candidate inputs. The asymptotic theorem permits the alternative graph to differ. The finite experiment and Lean semantic lemmas do not formalize the dynamic lower bound.
