# Can easy lengths or an easy input slice supply short histories?

## 2026-11-23 · A one-sided diagonal test

Assume a deterministic logarithmic-word RAM SAT routine of time O(m^d) on m encoded bits, d=2 or 3. The earlier [block simulation](history.md) required small witnesses throughout the accepted inputs of a suitably chosen verifier. I tried weakening that requirement to a subsequence, then tried replacing the verifier when its decision bit on the hard inputs could be inferred immediately. The two tests below have different costs in time and guess bits.

### Common representation and test

For a fixed machine M with a polynomial time cap T, use its chronological table and the bitonic sorting layers verifying memory consistency as in the block simulation. Here permit a table for a run of *any* length up to the cap. Supply its halting time and pad to the next power of two, and enforce the cap, acceptance, and the padding conventions. External input reads refer directly to the original string x in the verification predicate. Writable work memory begins at zero. This convention lets an immediate accepting computation have a short table even on a long input. The public clock construction and checking run outside the source computation. Word size is O(log n), and all rows, layers, and bit positions in a table have O(log n)-bit indices. A faulty table has an indexed local violation, including a read of a wrong input bit. Adjacent sorted reads and the deterministic routing network certify unrestricted work memory.

Fix an input-relative table description format. A descriptor supplies the halting time and a program for a fixed universal RAM interpreter that receives x, its length, and one table-bit index on read-only arrays. On each lookup give the interpreter a specified time limit and return zero on timeout. The descriptor itself is available by random access. A bit-output Boolean circuit with input queries is a special case after charging the bit description and evaluation overhead. Use one pair of description-length and lookup-time bounds consistently throughout each calculation.

For a supplied descriptor of length b with lookup time u, an existential search for a violated check takes Õ(n+b+u) nondeterministic RAM time. It guesses an O(log n)-bit violation index and calls the decoder for at most poly(log n) bits. This time allowance pays for reading x and the descriptor and for all address computations. The standard quasilinear explicit RAM-to-SAT reduction, or equivalently a sort-and-check tableau, therefore makes a SAT instance of length Õ(n+b+u). A deterministic SAT call tests for an error. Invalid descriptors are rejected. For any fixed checked machine M the resulting recognizer F_M accepts iff a descriptor of the allowed size passes. In particular F_M(x)=1 implies M accepts x. Completeness is exactly the short-description hypothesis being tested. [RAM tableaux and quasilinear simulation](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

### Deterministic diagonalization forces a constant-density hard slice

Use b=u=s=⌊n^(7/6)⌋ and T of order n¹². Determinize the search for a passing descriptor by another SAT call. Its outer nondeterministic verifier guesses the descriptor, constructs the inner query, and requires the assumed deterministic routine to report UNSAT. The outer query describes that computation. Its encoded length is Õ((n+s)^d), and the total deterministic time for F_M is Õ((n+s)^(d²)). This is Õ(n^(21/2)) for d=3, leaving polynomial room below T. Both query constructions include the input and their clock overheads.

Define a fixed deterministic RAM H on binary inputs. Read a prefix-free code of a deterministic RAM, and simulate that program on the *entire* input until a cutoff. Return the opposite of its bit if it halts before the cutoff. Accept on timeout. Choose a cutoff n¹² in universal simulation steps and implement the clock with constant-cost word operations. The resulting machine takes O(n¹²) time. A fixed target whose time is n^(12−ε) for constant ε>0 has time to finish for all large n. To spell out the universal-machine convention, use a fixed finite instruction set, encode the simulated logarithmic-word width constant in its program, store simulated words in limbs, and use a binary trie keyed by the bits of a simulated address. For a fixed target, interpreting an instruction and accessing the trie incurs at most poly(log n) overhead. Indexing the actually allocated trie memory fits a fixed word size for the universal cutoff. Malformed codes and over-budget simulations terminate by default. Elementary operations on simulated words, including arithmetic, have poly(log n) bit cost for the fixed program.

Apply the construction of F_M to H, using a fixed cap covering the implementation. Take e to be a prefix code for F_H. At each sufficiently large length, **on every x with prefix e**, we have H(x)=1−F_H(x) by simulation and F_H(x)≤H(x) by certificate soundness. Thus

    H(x)=1, and no descriptor of length s with lookup time s
    encodes a valid accepting table of H on x.

The set has exactly 2^(n−|e|) inputs. The same prefix works at every sufficiently large length, including on a computable sequence e followed by zeros. Its fraction depends on the hypothesized solver. The proof allows arbitrary access to x by the evaluator, preventing a lower bound based only on the cost of storing x. More generally the calculation works for s=n^α with max(1,α)d²<12. Since the overheads are fixed powers of log n for a fixed interpreter and solver, a sufficiently large logarithmic denominator also permits s=⌊n^(12/d²)/(log(n+2))^A⌋ at the cost boundary. One chooses A to cover the encoding and universal simulation costs. Those overhead exponents may be chosen uniformly for polynomial s in the indicated range, using the same evaluator with the integer A as a fixed parameter and constructing the cap in polylogarithmic time.

This is a conditional lower bound on descriptions of a particular machine's accepting *computations*. On the hard slice its decision bit is the constant one. On the ordinary unary alphabet, an unqualified infinitely-often *language agreement* premise is even weaker. Every unary language agrees infinitely often with either always-accept or always-reject on unary inputs. A one-sided certificate requirement can hold vacuously at a length having no yes-inputs. A suitable diagonal argument must specify which inputs the easy lengths cover.

### Testing a much weaker compression premise

The preceding positive sufficient condition is distributional. If, unconditionally for this fixed H and the specified s, the fraction of all n-bit strings that are yes-inputs without such tables approaches zero along some infinite sequence of lengths, then cubic SAT is excluded. No bound on the other lengths is needed. A fixed percentage of exceptions, even one percent, could contain the entire detector slice.

A change in scheduling allows just **one** easy accepting input to count. Build a second fixed deterministic verifier H_len. On length n≥1 let i be the exponent of two in n, enumerate deterministic RAM programs by natural-number indices, and simulate program i on the entire input with the same cutoff and default. One may encode the finite program directly by the bits of i under a fixed effective decoding, with malformed indices defaulting to accept. Computing i takes poly(log n) word operations with the input length provided, or O(n) if it must be scanned. For a fixed program i, its simulation has the same polylogarithmic overhead as before. This scheduling rule and verifier are independent of a putative SAT solver.

Let j be an index for F_H_len if a cubic solver exists. At **every** sufficiently large length satisfying n ≡ 2^j mod 2^(j+1), all 2^n inputs are accepted by H_len and none has a passing descriptor at the indicated size. On that progression H_len=1−F_H_len everywhere while F_H_len≤H_len everywhere. The progression and its first valid length may depend on the solver. Specializing to x=1^n already gives hard deterministic unary executions on all of these lengths.

Call a set of lengths thick if it contains intervals of consecutive integers of unbounded finite length. Such a set intersects every fixed arithmetic progression in arbitrarily large members. An unconditional theorem with the following premise would therefore exclude cubic SAT. On a thick set of lengths, **each length with a nonempty yes-slice contains at least one x having a short valid accepting history of H_len**. A length with an empty yes-slice is automatically good. This exemption is necessary: an index of an always-accept program yields an entirely rejecting progression for H_len at all sufficiently large lengths. The putative detector progression is entirely accepting, so the exemption cannot help there. Even the weaker recurrence property of meeting each class of fixed two-adic valuation infinitely often suffices. No ability to recognize the good lengths or construct their witnesses uniformly enters this sufficient condition. This is a genuinely different premise from having short witnesses for every accepted x at every length. It still requires treating every possible index. Finding infinitely many easy lengths by using the indices of simple programs leaves out entire arithmetic progressions. Choosing x to hold an encoding of a run would require that the encoded run remain correct when that very x is supplied. The missing mathematical step is establishing qualifying lengths, by an empty yes-slice or an easy execution, for every valuation class, including the one simulating its own detector.

One can weaken the proposed premise once more. On the qualifying lengths it suffices that **H_len has at least one rejecting input or at least one accepting input with a short table**. This allows every mixed slice without any compression proof. A detector progression under cubic SAT has neither feature. Thus the remaining case for an attempted unconditional argument is concentrated on program indices that return no accepting verdict within the cutoff for any x at the tested lengths. Their semantic verdict does not give a short computation. An input-oblivious program, for example, can carry out the same lengthy calculation on all such x before returning its bit. An external x can serve as n bits of advice to an input-relative decoder, but this observation supplies no table of the required size and lookup cost.

### Patch the verifier and test the recursion

Suppose M already decides precisely H and has a suitable polynomial cap. The soundness implication for F_M then gives a useful stronger fact. **Every** input on prefix e_M=code(F_M) is accepted by H, including small lengths. A reported one before the cutoff would make H reject and contradict soundness. A reported zero before the cutoff, or a timeout, makes H accept. Thus one may define M' that accepts immediately on this prefix and runs M elsewhere. M' still decides H. Its quick accepting branches have input-relative descriptions of polylogarithmic size and lookup cost. The early halt and read-only input convention above makes this explicit.

Try making M' use the prefix of *its own* detector via program self-reference. Even granting an exact fixed point M*, the rule now gives M*(x)=1 immediately on code(F_M*). The short accepting run forces F_M*(x)=1 there. At large lengths H(x)=0 by its time-limited simulation. Both M* and its detector work as specified. The purported equality of their underlying language with H fails on this very slice. Self-reference supplies a program string and cannot supply the semantic equality used in the old-prefix patch.

Starting with H, any finite number of patches of **old** detector prefixes preserves H. For each finite stage one can implement the verifier with a direct comparison to the finite list, followed by the original H on a miss, maintaining an O(n¹²) clock with stage-dependent constants. Its new detector prefix is distinct from every old one: on an old prefix the patched verifier has a short accepting history, and on its own detector prefix every history is hard at all large lengths. This also tests the proposed limit construction. Even if one arranges a computable time-bounded search recognizing the old prefixes eventually and keeps a fixed-clock limit verifier equivalent to H, the same argument applies to that verifier's own detector. Cheap membership recognition and a short accepting run on that prefix at infinitely many large lengths would give a contradiction. Enumeration of earlier detectors alone proves no such coverage for the limit. This leaves a possible route using some *other* verifier for a time-hierarchy language, with a substantive compression proof tied to that verifier.

### A single SAT call with a bounded number of guess bits

There is a different tradeoff if the simulation remains nondeterministic. Fix g(n)=⌊√n⌋. The same construction works with g≤n/2 eventually, efficiently computable, and g large enough to encode the small integer overheads of interest. Permit exactly g guessed description bits, including the time header and any padding, and give the universal table-bit decoder n steps. For each particular descriptor the one-sided test takes Õ(n^d) deterministic RAM time.

Construct a fixed length-preserving hierarchy verifier V. Its input consists of a prefix-free description i of a nondeterministic multitape machine, an arbitrary salt, and a final field of g+1 bits. Encode a tree node of depth j with bits w as 0^(g−j)1w. This realizes every node of a full depth-g binary tree in a fixed-size field. The all-zero field is invalid. On an internal node V accepts if machine i accepts both children, using a fresh sequence of at most g guesses for each simulation. On a leaf V tests whether i rejects the **root of that same salt** on the particular guess sequence w, supplying redundant bits if a branch halts early. Specify any fixed outcome on malformed programs or timeout. A large fixed clock bounds the time at all inputs, and each accepting run uses at most 2g guess bits. This is the length-preserving witness hierarchy of Fortnow and Santhanam, with an extra copied salt and a different prefix encoding. Constructive versions of bounded-witness hierarchies have previously been used for finding hard inputs. [Fortnow and Santhanam, Theorem 4.1](https://drops.dagstuhl.de/storage/00lipics/lipics-vol050-ccc2016/LIPIcs.CCC.2016.19/LIPIcs.CCC.2016.19.pdf) · [Chen et al., almost-everywhere hierarchy with a refuter](https://eccc.weizmann.ac.il/report/2020/150/)

Let i encode the one-sided recognizer F_V, which guesses the g-bit descriptor and does the deterministic single-SAT check above. Preserve its guess count in the multitape implementation. Given the guessed string, simulate the RAM deterministically by storing the finite list of touched addresses and scanning it for each access. This costs at most O(n^(2d) poly(log n)) time with exactly g guess bits in total. A faster nondeterministic transcript simulation could consume extra guess bits. For definiteness V can use a fixed universal tape interpreter and a time cap O(n²⁰); even a second quadratic simulation of this particular i, with logarithmic factors, fits the cap for d≤3. Simulating V itself as a RAM for the table representation incurs constant overhead per tape move for its fixed number of tapes.

For all large n and every salt, write f for F_V's report at each tree node. Soundness forces both children to report one whenever their parent reports one. At a leaf a report of one implies that particular root computation branch rejected. Thus a root report of one would force every root branch to reject. The root must report zero. Now descend through zero-report children. If neither child reports zero the current node is a true input that F_V misses. If this descent reaches a leaf, its test is true because every root branch rejected, so it too is a missed true input.

Hence at every sufficiently large n at least 2^(n−|i|−g−1) distinct yes-inputs of V have no passing g-bit descriptor with n-step lookup. For any fixed salt a deterministic search locates one missed input with at most 2g child-decision queries. Each F_V decision can be computed on a RAM by an extra SAT call in Õ(n^(d²)) time when desired. One may use the number of parent/child tests directly; there is no requirement to enumerate the 2^g leaves. Under the fast-SAT hypothesis even an all-but-an-o(2^(−g))-fraction compression bound along an infinite subsequence for this verifier would contradict the density estimate. One arbitrary salt can still have only one forced missed node from the tree logic alone: all leaf branch marks can be rejecting, all nodes below the root can report one, and only the root can report zero. This assignment obeys soundness and the root existential condition.

The constant-density deterministic argument pays the second SAT exponent. The bounded-guess argument charges only one SAT call inside the hierarchy recognizer and gives one hard node per tree. Both identify conditions that a successful compression theorem would have to meet. Neither supplies that theorem. In particular, using a generator that recognizes a previously hard prefix and returns an immediate acceptance bit does not certify the original verifier's computation.
