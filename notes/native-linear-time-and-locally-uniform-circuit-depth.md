# A linear SAT clock rules out a separate near-log-squared-depth circuit family

Let $N$ count encoded input bits. If explicit DIMACS 3-SAT has a deterministic unrestricted-workspace word-RAM algorithm in $O(N\log^c(N+2))$ time for some fixed $c\ge0$, then **every correct polynomial-size, polylog-time locally uniform, bounded-fan-in SAT circuit family** has depth at least
$$
             \epsilon\,(\log N)^2/\log\log N
$$
at infinitely many lengths, for some $\epsilon>0$. In particular an upper bound $o((\log N)^2/\log\log N)$ for such a family would exclude linear deterministic SAT time. The two implementations in the hypothesis and conclusion may be chosen independently. For native bounded nondeterministic RAM acceptance with a unary clock, a deterministic linear-time algorithm implies depth at least $\epsilon(\log N)^2$ infinitely often under the same circuit uniformity. The sequential machines may use their entire writable store. Neither alternative has been settled separately.

Here local uniformity means one fixed deterministic algorithm given the length in binary and a gate identifier returns its Boolean operation and its at most two predecessor identifiers, or a constant or input-bit index, in $(\log N)^{O(1)}$ word operations. The output gate is similarly addressable and gate identifiers use $O(\log N)$ bits. Any fixed bounded fan-in can be expanded into fan-in two at a constant depth factor. The circuit may share gates and can have any fixed polynomial size. The standard explicit permutation of gate names needed by a global space-uniform generator is not assumed available from an arbitrary other uniformity condition.

Murray and Williams give an unconditional SAT lower bound for circuits combining quasilinear size, a depth bound and a space-uniform global construction. Their Claim 20 counts the cost of eliminating alternating blocks under linear SAT. Bathie and Williams use block evaluations and alternation trading to prove quantitative logarithmic-depth lower bounds for uniform NAND circuits. The explicit-SAT implication here also follows by applying the journal's growing-depth reachability simulation to a depth-first traversal of a locally uniform circuit. The proof below treats the native and explicit encodings in the same word model and accounts for the input sent at each level. Priority for the precise disjunction is unestablished. ## A square-time opponent and a short description of its circuit input

Let $J(x)$ simulate the deterministic opponent identified by the self-delimiting program prefix of $x$ on the very same input $x$. Invert its answer if it halts within $n^2$ guest steps, where $n=|x|$, and give a fixed default otherwise. Fixed-width instruction records, a fixed register file and separate sparse memory banks implement this in $O(n^2)$ actual steps. No fixed deterministic tester taking $o(n^2)$ steps decides $J$ on every sufficiently long input: append padding to the tester's own program prefix. [Native clock and same-word-width diagonal](native-unary-clock-band.md)

On input $x$ the native reduction supplies a virtual file of length $M=\Theta(n^2)$ containing the fixed interpreter, $x$ and a sufficient unary clock. A requested input bit is available from $x$ and the interval endpoints in polylogarithmic time. For explicit SAT instead compile the $O(n^2)$-step run of the fixed interpreter to a regular Boolean gate table. There are $O(n^2\log^2 n)$ gates and clauses up to constant factors, including the memory-record routing and the local arithmetic checks. The output length $M$ may be fixed as a function of $n$ by the regular layout, with $\log M=\Theta(\log n)$. Local record indices and source bits are computable in $(\log n)^{O(1)}$ time. [Bounded computation and local clause indices](packed-band-transfer.md)

For ordinary ASCII DIMACS, reserve fixed-width fields for signed canonical decimal numerals, right-justified with leading whitespace, and put an additional separating space between fields. No leading zeros in variable names are needed. Reserve constant many rows per local gate. If three different variables per clause are required, simplify each local relation to clauses on distinct variables and pad its unit and binary clauses with distinct pins forced false by a fixed three-variable gadget. The seven clauses excluding the other bit triples give these pins a unique value. Use duplicates of a gadget clause for unused row slots. Input-value pins can choose a polarity without changing the stride. Variable IDs are assigned from fixed disjoint ranges, and the header advertises the prescribed variable and clause bounds. A requested decimal digit or whitespace byte is computed by division on an $O(\log n)$-bit variable index in polylogarithmic time. The circuit here receives the bits of this proper DIMACS file. It does not receive the original input $x$.

## Guessing the values at a circuit boundary

Let $B=\max(1,\lfloor(\log_2 n)/4\rfloor)$. Unfold at most $B$ gate levels below the gate in question into a binary tree of occurrences. Leaves encountered before or at the cutoff are evaluated from the virtual file if they are actual input bits or constants. The other boundary occurrences, at most $2^B$, receive guessed Boolean values. Evaluating this truncated tree bottom-up and locating any one of its boundary occurrences takes $2^B(\log n)^{O(1)}=o(n)$ work, including all uniform wiring queries. A shared gate may appear twice. Each occurrence is checked against its own true gate value.

For a nonnegative budget $j$ define $V_j(v)$ as the gate value found by expanding at most $jB$ levels under gate $v$, with nonterminal boundary values set to zero. This is a mathematical definition. A single fixed nondeterministic program verifies a prescribed bit for $V_j(v)$ with one call to a deterministic solver for native acceptance at level $j-1$. At budget zero a terminal is evaluated directly and a nonterminal has its fixed default. At positive budget guess the boundary string, evaluate the truncated tree and reject if its root differs from the claimed bit. For a matching root, accept exactly if the solver rejects a child native query. In that query the same program guesses one boundary index and verifies that the opposite of the supplied bit is $V_{j-1}$ at the indicated gate. With no boundary indices this challenge has no accepting branch. Induction on $j$ proves exactness. If any boundary guess is wrong, its index gives an accepting challenge. If the root claim is right, guessing all actual truncated child values defeats every challenge.

The program has two input modes, an ordinary gate claim and a boundary challenge. In the latter it parses the parent gate and boundary string, chooses an index, recovers that predecessor, and continues with the ordinary gate-claim instructions in the same invocation. A child receives the full $n$ original bits, its immediate boundary string, the relevant gate identifiers and clock metadata. Prior boundary strings are unnecessary because the challenge concerns a single gate's fixed value. All these payloads cost $O(n)$ **bits**. They can be physically copied. No verifier receives a persistent pointer into a parent computation, and no previously guessed answers become uncharged oracles. The verifier always calls a fixed deterministic program for native acceptance; it passes its own fixed code as program data from the root, and copies that same field to a child. Thus the verifier code has constant length for every $j$, without a recursive expansion of its instruction table.

## Paying the solver's cost at every level

If native acceptance itself has a linear-clock decider, call it $A$ and put $a=0$. Under the explicit-SAT time hypothesis, a fixed $A$ decides native acceptance in $O(s\log^a(s+2))$ time on $s$ input bits, for a fixed positive integer $a$. Indeed the native language has a fixed linear-time nondeterministic interpreter. Its bounded computation can be compiled and physically written in $O(s\log^{O(1)}s)$ bits and steps, by the same memory verification and fixed-stride serialization. Running the hypothesized SAT solver gives the claimed bound after increasing $a$. This nested use of $A$ pays for the full input of every call, including $x$ and the unary suffix. It needs no constant-time virtual ASCII decoder.

Put $L=\lceil\log_2(n+2)\rceil$. Take $H_0$ a fixed sufficiently large multiple of $n+1$ and $H_j=(K L^a)H_{j-1}$ for a fixed integer $K\ge2$. Use $H_j$ as the unary step bound for the verifier at budget $j$. The non-oracle work of one invocation, including the cost of interpreting its incoming challenge, is $O(n)$ before writing the next native input. A child file has $O(n+H_{j-1})$ bits. Writing it and executing $A$ costs at most $C H_{j-1} L^a$ as long as $H_j\le n^{3/2}$, with $C$ independent of $j$ and $K$. The numeric parameters can be passed as data, and lengths and multipliers can be range-checked. Fix $K>C$ with headroom for the remaining local work. Choose the root budget by multiplying up from $H_0$ until the *next* multiplication would exceed $n^{3/2}$, using an integer-square comparison. This loop costs $O(\log n)$ operations. Extract a child clock by division by $K L^a$; no computation of the circuit depth is required.

The verifier always has a payload of length $\Theta(n)$, and its guest width depends on that payload. The native solver $A$ being simulated inside it can have word width based on a polynomially longer input, including its larger unary clock. All such widths have a fixed ratio to $\log n$. Simulate wider sparse addresses by the fixed-depth radix trie and multi-limb word operations used for the native diagonal. There are at most $n^{3/2}(\log n)^{O(1)}$ accessed words per host run, within the original $12\lceil\log_2(n+2)\rceil$-bit address capacity for all large $n$. The sparse simulations use their own fresh memory and a fixed number of banks per call. A guest executes $A$ as ordinary deterministic code; only the decider's *correctness* invokes the induction hypothesis, so the physical host never keeps an unbounded stack of nested RAM simulators. [Native width simulation](native-unary-clock-band.md) · [Single-verifier construction](alternating-native-speedup.md)

For $a=0$ the available budget is $\Theta(\log n)$ layers. For fixed $a>0$ it is $\Theta(\log n/\log\log n)$ layers. In both cases the root call to $A$ costs $O(n^{3/2}L^a)=o(n^2)$. If the respective circuit depths were $o(\log^2 M)$ or $o(\log^2 M/\log\log M)$, the available $jB$ gate levels would cover the entire circuit on all sufficiently long virtual inputs. The resulting deterministic tester would decide $J$ within its opponent's clock, a contradiction. A fixed sufficiently small constant multiple of the respective depth bound on all large lengths yields the same contradiction.

To obtain a superlinear SAT time lower bound from this result would still require a circuit depth upper bound of the indicated strength for SAT, or another way to compute the diagonal within its own clock. A general RAM-to-circuit simulation of a linear-time SAT solver supplies no such depth guarantee.
