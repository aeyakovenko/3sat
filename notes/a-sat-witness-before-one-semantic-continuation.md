# A unique SAT witness before one editable continuation

Given a positive proper DIMACS file, its unique complete model, and the position of one editable bit, deciding whether its verdict will **survive** the specified edit is equivalent to deciding ordinary 3-SAT under deterministic reductions of linear encoded length and construction time. Deciding whether its verdict will **change** has the same equivalence to 3-UNSAT. The result holds when the two files differ in one ASCII identifier digit and the starting model is fixed by a public rule. Thus a check for whether a SAT solver can safely ignore one pending choice can contain the full decision problem even when the witness at the checkpoint is free. The related problem of finding a second solution in the presence of a supplied solution has a long history. [Yato and Seta](https://ipsj.ixsq.nii.ac.jp/records/31947)

## The two physical files

Normalize the source $G$ to its $v$ occurring variables and its $m$ distinct proper clauses. Use names $1,4,5$ for three padding variables forced to zero by the seven proper ternary clauses excluding the seven nonzero triples. Names $2,3$ stand for $\bar s,s$. Two binary clauses enforce that exactly one is true. Name $6$ is forced true. Pad each binary or unary constraint to three distinct literals using the required number of positive padding variables. Use consecutive remaining names for the source variables and one fresh $a_C$ per source clause. Print the following constraints:

- For every source variable $x$, print $s\lor\neg x$.
- For every $C=(l_1\lor l_2\lor l_3)$, enforce $a_C\leftrightarrow(s\land\neg l_1)$ by its three gate clauses, and print $\neg a_C\lor l_2\lor l_3$.
- End with the single row $q\lor x_1\lor x_4$, where $q$ is the **positive literal with numeric name** $2$, $3$, or $6$.

At $q=2$, $s=0$ and every source and gate variable is zero. Only names $2$ and $6$ are true. At $q=3$, $s=1$, and every satisfying assignment of $G$ has exactly one extension. At $q=6$ the final row is automatic, giving $1+\#G$ models. Here $\#G$ counts assignments on occurring names. All declared names of the output occur. The $2\to3$ edit toggles the low bit of one ASCII byte. The initial model can be printed along with the file. The reverse reduction for stability simply returns the edited file. These reductions apply to deterministic clocks $O(n)$, $O(n^2)$ and $O(n^3)$ without changing the exponent.

The edited witnesses can all be required to have the **same Hamming distance** from the public model. For each of the $v+m$ original source or gate variables $z$, add a companion $z'$ and the three clauses for $z'\leftrightarrow(s\land\neg z)$. At $q=2$ each pair is $00$. At $q=3$ each is $01$ or $10$, and names $2,3$ exchange values. Padding and name $6$ keep their values. Every edited model therefore has distance exactly $v+m+2$ among $2(v+m)+6$ declared bits. The extension is unique and the size and time stay linear. Only the center must have a unique model. On a source promise of at most one model, the edited file also has at most one. On every stable instance of the paired construction a search limited to radius $v+m+1$ around the public witness fails.

As a finite check, the 255 nonempty subsets of the eight signed ternary clauses on three names give 765 serialized output files per construction. Re-parsing each file and enumerating with PicoSAT gave the three predicted counts in every case, totaling 2,542 models in each construction. Every center had exactly the disclosed model, and all center-to-switched pairs differed in one physical bit. All 1,016 switched models of the paired construction had the predicted distance. Normalization takes $O(n)$ native steps on the packed logarithmic-word RAM. Distinct normalized rows have total length $\Omega(m\log(m+1))$ even if the original file used short names and repeated clauses. With $v\le 3m$ the output uses $O((1+m+v)\log(2+m+v))=O(n+1)$ encoded bits. The recognizer can recover the source from the ordered gate blocks by parsing the signed source names. Bounded reprinting and comparison check a claimed template in $O(n+1)$ time. This reduction charges materialization. A claim below linear time on arbitrary unsorted input would require a separate local word generator. [Packed normalization and its length analysis](dense-sorted-cores-for-ram-exhaustion.md)

## One genuine read

Given any fixed correct packed-RAM SAT solver $P$, construct a globally correct solver that handles the template prefix as follows. Recover $G$, compute $v_G=P(G)$, store that bit, then reload it before consulting the pending identifier. For the recognized suffixes return $v_G$ at $q=3$ and YES at $q=2,6$. Validate the complete syntax and fall back to $P$ on other inputs. Cap the parser's output length and work by a fixed constant times the physical input length, so any extracted instance feeding $P$ is proper and fits that budget. Thus if $P$ costs $O(N^k)$ for $k\ge1$, so does the new solver. For a prefix independent of the physical word containing $q$, put a public gap of legal whitespace before the final row, longer than two host words, and postpone validation of the gap and row. On the generated layout $\log(N+2)=O(\log(m+v+2))$, so the builder can ensure this spacing without knowing the eventual packing alignment.

The simulation uses the target class in which each fixed RAM may choose a sufficiently large constant in its logarithmic word width. Select the host coefficient large enough for disjoint tagged address ranges for the guest running on $G$, a possible fallback guest on the original file, and construction scratch. Keep the physical input intact. Initialize the first guest bank with the extracted file repacked at the guest width. Initialize the fallback bank from the physical file only if required. Fixed-width arithmetic is masked to the guest word and the native instructions admit constant-size simulation after polylogarithmic setup. The two files have equal byte length and the byte strings for the query digits differ in a single bit under either fixed byte order. No prescribed absolute bit index within the packed word is needed. This bank argument uses the freedom to enlarge the width coefficient. [Native word operations and initial memory](dense-sorted-cores-for-ram-exhaustion.md) · [Tagged guest banks](one-bit-hard-pairs-at-consecutive-sat-lengths.md)

On the center with public model, the genuine loaded bit ranges over the SAT answers to arbitrary sources. Its value dictates the true verdict on the other continuation. This makes the distinction between two shortcuts precise. A checker reconstructing the genuine read on these centers solves $G$. A solver that knows the continuation is the center can return YES immediately. If it must certify that **both** continuations have the same answer, the stability equivalence above applies. The construction fixes one program and a pair of legal continuations. An unrestricted program can read $q$ first. No cost of running $P(G)$ is forced on every program by this example.

## When independent component answers can have either polarity

Let $h:\{0,1\}^r\to\{0,1\}$ be fixed, with each input the actual SAT verdict of an independently supplied formula. Every monotone $h$ has a linear-time, linear-bit compiler to proper 3-SAT. Expand its fixed monotone DNF, guess one term, and use disjoint gated copies of the source constraints to require all components in that term. Padding and guards as above retain the length bound since $r$ and $h$ are fixed. Equivalently, a verifier may guess an underclaim vector $y$, supply assignments for its ones, and evaluate $h(y)$. On a genuine vector $s$, this accepts exactly when $h(s)=1$. Any coordinate individually pivotal at a positive input must then have value one.

If $h$ is nonmonotone, it has an adjacent downward edge. Fix all other components to constant small true or false files as prescribed by that edge. A compiler of the same cost for this $h$ gives a linear-bit, linear-time many-one reduction from 3-UNSAT to 3-SAT. Conversely, such a reduction makes every fixed $h$ compilable at that cost, by replacing negative literals in its DNF with positive SAT instances for the complemented components. This argument uses the freedom to instantiate the other components independently. Correlated or promised tuples may implement either polarity with cheaper certificates.

The downward-edge hypothesis would have a quantitative consequence for alternation trading. Let $T\ge\max(2,|x|)$ be a supplied polynomially bounded clock for a fixed alternating RAM, $h$ now the number of quantifier blocks, and all words $O(\log T)$ bits. Under the linear complement reduction, there is a uniform explicit SAT compilation with length and construction time
$$T(C\log(T+2))^{A(h+1)}$$
for fixed $A,C$, whenever the displayed budget is at most $T^2$. In particular $h=o(\log T/\log\log T)$ costs $T^{1+o(1)}$. A deterministic $O(N^k)$ SAT solver would then simulate such games in $T^{k+o(1)}$, with the exponent independent of $h$ in that range.

To see the costs, supply one length-$T$ array of guessed move words per block, ignoring unused entries. The deterministic leaf simulates the original machine and reads these arrays in phase order. All prefix arrays and the public input together occupy $O((h+1)T\log T)$ bits. Normalize each remaining game to an existential first block by keeping one polarity bit, complementing the leaf test as needed. A single nondeterministic verifier guesses this outer block. If a suffix remains, it generates a bounded-run SAT formula for the same verifier on the *negated* suffix, applies the hypothesized complement reduction, and guesses and checks a satisfying assignment. The base case simulates the leaf. A universal bounded-run constructor can receive the verifier's fixed program code as data at every level, so the verifier description does not expand. Apply one final bounded-run compilation for the root, complementing at the outermost level if it began universal. [Bounded-run RAM compiler and word costs](packed-band-transfer.md) · [Jahanjou, Miles and Viola on local reductions](https://arxiv.org/abs/1311.3171)

More explicitly, choose a polylogarithmic initialization factor covering the largest prefix and the leaf simulation. A suffix verifier with clock $R$ yields an explicitly printable proper formula in $O(R\log^a(R+2))$ time and bits for a fixed $a$, counting input initialization, variable names, and padding to proper rows. Applying the complementer and checking an assignment add linear time in that length. Guessing or copying the next prefix is covered by the initialization factor. While $R\le T^2$, each round therefore multiplies the budget by at most $(C\log(T+2))^A$. A machine computes these public integer caps by repeated multiplication. The bound allows unrestricted workspace, including all printed formulas. It neither assumes a local complementer nor uses it as a free oracle. The missing step at quadratic and cubic clocks is an actual speedup for the unrestricted solver. The one-bit test identifies the cost of certifying a semantic continuation. Both the complement compiler and the speedup remain hypotheses. [Buss and Williams on the existing alternation-trading rules](https://eccc.weizmann.ac.il/report/2011/031/)
