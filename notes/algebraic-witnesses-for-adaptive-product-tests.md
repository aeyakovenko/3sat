# Lifting a wrong matrix product past one more family of checks

In the compact DIMACS projection, $F_{A,B,C}$ is satisfiable exactly when $E=AB-C$ over $\mathbb F_2$ is nonzero. Consider a deterministic verifier that sees $E$ only through the following operations. A positive-integer slope $q$ returns **every** coefficient of $P(X,X^q)$, where $P(X,Y)=\sum E_{ij}X^iY^j$. A vector test can request all of $Ev$ or $u^\mathsf{T}E$ for an arbitrary binary vector. A scalar test may request any binary linear functional of $E$. The verifier may select each operation after examining all earlier replies. Give it the actual factors $A,B$, the dimension $d$ and any public information independent of the error for free. This is a model of access to the error; a native SAT program may inspect every original file bit and use general word instructions.

Follow the verifier on an honest product, where all replies are zero. Let $q_1,\ldots,q_k$ be the **distinct** slopes on this transcript and $p=\sum_i q_i$. With slopes alone, the space of invisible $d$-square errors has dimension
$$
 (d-p)_+ (d-k)_+.
$$
When this dimension is positive, the least possible matrix rank of a nonzero invisible error is **exactly $k+1$**. Appending an arbitrary new positive slope $q$ lifts an explicit witness by multiplying it by $Y+X^q$, provided its resulting two degrees still fit the matrix. This is a size-by-size construction with a precise stopping condition.

It also survives arbitrary choices of the other permitted tests. Write $s_L,s_R$ for the numbers of left and right vector tests and $h$ for the number of scalar tests on the same transcript. If
$$
 d-p>(k+1)s_L+h,\qquad d-k>(k+1)s_R,
$$
there is still an invisible error of rank **exactly $k+1$**. One can instead charge the $h$ scalar tests on the right inequality. The adversarial error is constructed for the given program, factors and dimension. On the honest product and on the constructed error all the native input files are valid and the two required SAT verdicts differ. The verifier sees identical test replies in every round.

## The switch and its exact rank

Put $S(X,Y)=\prod_{i=1}^k(Y+X^{q_i})$, initially 1. The substitution $Y=X^q$ annihilates $P$ if and only if $Y+X^q$ divides $P$ as a polynomial in $Y$ over $\mathbb F_2[X]$. The distinct factors are prime since their quotient rings are $\mathbb F_2[X]$. Thus a simultaneous zero reply means exactly $P=SH$. Degree in each variable adds in a nonzero product. Here $\deg_X S=p$ and $\deg_Y S=k$. Multiples fitting the array are therefore parametrized by all $H$ with $\deg_X H<d-p$ and $\deg_Y H<d-k$, proving the dimension formula. This generating-polynomial method for invisible line sums is classical in discrete tomography. [Hajdu and Tijdeman, *Algebraic Aspects of Discrete Tomography*, Theorem 1](https://math.unideb.hu/sites/default/files/inline-files/disctom8.pdf)

For the lower rank bound suppose a nonzero invisible $P$ has coefficient matrix of rank $r\le k$. Write $P=\sum_{j=1}^r a_j(X)b_j(Y)$ using a basis of its row space. Row reduction from highest degree downward makes the degrees $e_j$ of the $b_j$ strictly increasing. Order any $r$ tested slopes increasingly as $t_1<\cdots<t_r$. The matrix with entries $b_j(X^{t_i})$ has nonzero determinant. Its diagonal term has degree $\sum_i t_i e_i$. The leading degrees in every other determinant term sum to a strictly smaller value by the rearrangement inequality, and all $t_i$ are positive. The diagonal leading coefficient therefore survives even in characteristic two. Invertibility over $\mathbb F_2(X)$ makes all $a_j$ zero, a contradiction. Conversely $S$ has at most $k+1$ nonzero columns and is itself invisible, giving equality. When $k=0$ the constant monomial supplies rank one directly. Low-rank identity tests using the distinct substitutions $Y=\omega^iX$ over a suitable extension field are due to Forbes and Shpilka. The argument here uses slopes $Y=X^{t_i}$ over the original field and gives the minimum rank of the finite kernel. Priority for this rank formulation has not been established. [Forbes and Shpilka, *On Identity Testing of Tensors, Low-Rank Recovery and Compressed Sensing*](https://arxiv.org/abs/1111.0663)

If each slope returns its full dense coefficient list, then one query costs $(d-1)(q+1)+1$ returned bits. The minimum total on the zero path of a tester detecting every nonzero error of rank at most $r$ is $\Theta(d\min(r^2,d))$ for $1\le r\le d$. Detection requires either $k\ge r$ or $p\ge d$, by the exact kernel theorem. In the first case $k$ distinct positive integers sum to at least $r(r+1)/2$; the second already pays quadratic cost. The first $r$ slopes or the single injective substitution $Y=X^d$ attain the corresponding upper bounds. This counts all returned coefficients; a machine that queries individual coefficient summaries operates under different prices.

## Adding full vector outputs and arbitrary linear observations

Write $S=\sum_{j=0}^k g_j(X)Y^j$. Look for $P=R(X)S(X,Y)Q(Y)$ with nonzero $R,Q$ of degrees less than $d-p,d-k$. Under each right vector request $v$ demand that all $k+1$ coefficient vectors of $Y^jQ(Y)$ are orthogonal to $v$, one equation per $j$. There are fewer equations than the $d-k$ unknown coefficients, so a nonzero $Q$ exists. Holding this $Q$ fixed, require for each left vector $u$ that the coefficient vector of each $R(X)g_j(X)$ be orthogonal to $u$. The $h$ scalar observations are also homogeneous linear equations in the coefficients of $R$. There are fewer than $d-p$ equations. The resulting nonzero product survives as a polynomial, vanishes on each tested slope, and has matrix rank at most $k+1$ from the displayed sum. The lower rank proof applies unchanged. Choosing $R$ first instead places the scalar cost on the other side. Induction on the deterministic query transcript now proves indistinguishability. The scalar equations can include specified individual bits of $C$. A probe to a word of packed data can be represented here by up to $w$ such equations, once its actual address on the honest transcript is fixed.

For unrestricted rank a separate dimension count tolerates more observations. Restrict the linear map sending an error to the other replies to the $(d-p)_+(d-k)_+$-dimensional slope kernel. It has at most $d(s_L+s_R)+h$ scalar outputs. If that number is smaller than the kernel dimension, some nonzero error is invisible. This only guarantees existence of an error, potentially of higher rank.

## Which RAM catches these witnesses?

The bare algebraic successor fails an especially cheap native test: $S(X,1)=\prod_i(1+X^{q_i})\ne0$. Thus $E\mathbf1\ne0$ for every such example, including a monomial shift that still fits. A single global SAT program can validate the compact file layout, recover its three matrices and check $A(B\mathbf1)-C\mathbf1$. This costs $O(d^2)=O(N)$ native steps on its $N=\Theta(d^2)$-bit file. A discrepancy is a sound SAT answer on every recognized file. On a zero answer or a foreign layout the program takes its ordinary complete SAT path. The extra $Q$ and $R$ above can defeat this test if it is part of the transcript. That repair accommodates a specified number of tests; arbitrary RAM computation can access information beyond them. Checking all slope coefficients also counts as one operation only in the stated test model.

For slopes $1,\ldots,k$ the bare switch first fits at $d=1+k(k+1)/2$. Exhaustive enumeration through $d=4$ checks the whole invisible space and its minimum rank.
