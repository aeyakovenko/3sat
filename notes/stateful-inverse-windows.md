# A linear-time SAT branch with maximal cumulative forecast errors

**Research journal, 24 November 2026.** The unconditional checkpoint theorem gives a lower bound on the cost of forecasting the next segment from each starting time. Could an ordinary linear-time RAM have a universal upper bound on this cumulative cost? The following construction reaches the elementary linear-run ceiling on explicit unsatisfiable inputs. Its forecasts can keep private mutable memory and see each genuine read after predicting it. This attacks the proposed last inference from cumulative forecasting cost to elapsed time. [Stateful forecast theorem and definitions](stateful-incoming-decoders.md)

Fix a word-RAM predictor, its per-prefix allowance $K\ell L^p$ with fixed $K,p$, and a fixed $0<\gamma<1$. Write $N$ for the formula length in bits, $L=\max(2,\lceil\log_2(N+2)\rceil)$, and $h=\lceil N^\gamma\rceil$. There is a fixed correct SAT solver with arbitrarily long unsatisfiable inputs on which it spends $\Theta(N)$ native instructions, yet at $\Omega(N)$ different starting times **every** hindsight row $Z$ satisfies
$$
 1+|Z|+e_t+J_t+u_t=\Omega(h).
$$
Here $e_t$ is the predictor's work in excess of its prefix allowance, maximized over prefixes through $h$ native instructions. Each incoming word gets one predicted word and one tag. $J_t$ counts the used tags, and $u_t$ counts keys outside the most frequent XOR correction in their tag. Each distinct incoming address counts once per start. Private scratch begins blank at each start. A row may depend on the whole input, history and future. Thus $U_h=\Omega(Nh)$ on these inputs. A fixed predictor with a constant-zero mode always has $U_h=O(Nh)$ on runs of $O(N)$ steps and boundedly many word accesses per instruction. The same program construction works for each fixed predictor; the hard inputs need not coincide. If SAT has a globally linear solver, it can serve as the fallback to make this solver globally linear as well.

## Native run and what a predictor can inspect

Take $m$ a power of two and encode a permutation $\pi$ of $[m]$ in one unused literal per tautological clause, beside a fixed pair of contradictory clauses. This is an ordinary packed fixed-width 3-CNF of length $N=\Theta(m\log m)$. The projection of any input word depends on a constant number of forward values of $\pi$, since adjacent variable names have $\Theta(\log m)$ bits. The native program can extract a forward value with a constant number of word operations on this layout. A branch detecting the contradictory guard can validate the dimensions and permutation, returning UNSAT directly on an inapplicable remaining layout. On other guards use an arbitrary correct SAT solver. Dimension checks precede allocating or scanning any claimed arrays. [Encoding and earlier stateless inversion example](long-gap-inverse-bits.md)

On a valid permutation, scatter $i$ into writable cell $\pi(i)$ of the inverse array. Use a separate seen table for validation. Then make $\log_2 m$ identical passes. In each pass, for $y=0,\dots,m-1$, load the stored inverse $i$, check the original $\pi(i)=y$ with an in-range test, and continue. A failed test returns SAT and the end of the scans returns UNSAT. Failure is unreachable on a genuine validated permutation. At an actual load, replacing the reply by any other word leads to the failed test. Clear the data registers at the start of each iteration. A passing iteration costs a fixed constant $b$ instructions after padding. Its pre-load registers contain public loop parameters; alternatively their entire fixed register file can be counted as $O(L)$ further bits in the union bound below. The program uses $\Theta(m\log m)=\Theta(N)$ steps on these formulas.

Consider the pre-load start in every iteration at least $h$ iterations before the pass ends. There are $\Theta(N)$ such starts, since $h=o(m)$. Among the next $h$ instructions consider just $r=\lfloor h/b\rfloor$ successive inverse loads. They have distinct incoming addresses and public ordered target labels. The predictor sees the genuine native log beginning at this start. Truthful earlier replies in this forecast are available freely. Native reads of packed input, including neighbors of a checked literal, can be supplied by $O(h)$ forward queries. Its work addresses, new read replies other than these inverse values, and control flow can otherwise be obtained from the public counters and the preceding observations. It has no initial copy of the inverse array.

## An adaptive bound with the true answers disclosed

Let $y_1,\ldots,y_r$ be any fixed distinct target values. A procedure with fixed advice reads the forward permutation adaptively. Before learning $\pi^{-1}(y_j)$ it guesses it, then receives the true answer for free. Count an additional forward query at every in-range guessed index before its true answer is disclosed. The reply to this extra query can be kept private to the analysis. Let $Q$ be a cap on all forward queries including these tests. For integers $1\le v\le r$ and $Q+r<m$,
$$
 \Pr[\text{at least }v\text{ correct guesses}]
 \ \le\ \binom Qv\left(\frac{r}{m-Q-r}\right)^v .
$$
Use zero for the binomial coefficient when $v>Q$. Expose the permutation only by the queried forward pairs and the disclosed inverse pairs. Given a transcript, the remaining bijection is uniform. A forward query to a previously unexposed input has conditional probability at most $r/(m-Q-r)$ to expose a still-undisclosed target label for the first time. A repeated input cannot cause a new exposure. If the guess for a target is correct, either the extra probe exposes that target before disclosure, or an earlier forward probe did. Distinct correct targets require distinct first-exposure slots. Pad unused slots with nonhits. For any $v$ chosen slots, iterated conditioning bounds the chance of hits at all of them by the displayed power. Sum over slot sets. Adaptive choices, true answers supplied after guesses, and all retained private predictor state are included in this transcript argument. The resulting estimate concerns short successive inversion queries under one preprocessing choice. For classical inversion with advice in other query regimes see De, Trevisan and Tulsiani and the adaptive inversion literature. [Time-space tradeoffs for attacks on one-way functions](https://home.ttic.edu/~madhurt/Papers/dtt-new.pdf) · [Gajulapalli, Golovnev and King, On the Power of Adaptivity for Function Inversion](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ITC.2024.5)

There is a sharper finite statement. With $Q\le m$, the number of first-time forward hits is stochastically dominated by the number of marked objects in $Q$ draws without replacement from $m$ objects with $r$ marks. Just before forward slot $j+1$, let $u\le j$ count pairs first discovered by forward probes, $s$ the target hits among them and $b'$ the other pairs first exposed by free inverse disclosures. Those free disclosures expose only target labels. If an unexposed domain point remains, the conditional chance of a hit on a new query is
$$
 \frac{r-s-b'}{m-u-b'}\le\frac{r-s}{m-u}\le\frac{r-s}{m-j}.
$$
When all pairs have been exposed there can be no further hits. Repeated probes give zero. Couple the two hit counts using a common uniform draw at each slot. When their counts are equal the actual conditional success probability is no greater than that for sampling without replacement. When the actual count is smaller it cannot overtake by adding at most one. The coupling can sample the rest of each adaptive transcript conditional on that slot's hit bit. This proves domination, and the weaker displayed union bound already suffices for the asymptotics.

## Paying for a different hindsight row at each start

Use $Q=\lfloor m^{(1+\gamma)/2}\rfloor$. A row with $|Z|+e_t+J_t+u_t<c h$ has at most $K h L^p+c h$ predictor steps on the prefix. Each predictor step entails at most a fixed number of forward probes, including the entries intersecting a packed word. Along with the $O(h)$ native and guess-test probes this is below $Q$ for all sufficiently large $m$. Time-limit every proposed procedure at the cap, including on guesses of advice that fail to produce timely replies. The cap can also be enforced on the number of nonoracle simulator steps so a diverging row defines an ordinary bounded experiment.

As further advice give the procedure the list of used tag identifiers and their modal correction masks. It runs the predictor on the true history, preserving the predictor's raw guesses in its private state. It guesses the word obtained by XORing the predicted word with the mask for its tag. Give missing tags a fixed default. The list, lengths, row and any initial registers take at most $|Z|+C(J_t+1)L$ bits for a fixed $C$. Lookup time of this advice is immaterial in the forward-query bound. On the original input at most $u_t$ of the $r$ designated guesses are wrong. Choose $c<1/(4b)$, so a cheap row yields at least $v=\lceil r/2\rceil$ correct guesses for large $m$.

For any fixed advice and start, $\binom{Q}{v}\le(\mathrm e Q/v)^v$ bounds the probability above by $(C' Q/m)^v$, since $r/v\le2$ and $Q+r=o(m)$. This is $2^{-\Omega_\gamma(h\log m)}$. The number of possible advice strings of the allowed lengths is at most $2^{O(c h L+L)}$. Take $c$ small enough for that exponent to fit inside the saving. A union bound over $\Theta(N)$ starts still gives a vanishing probability of any cheap start. This union is precisely what allows the original row and the modal masks to be chosen after seeing the permutation and separately for each start. No independence between starts or passes is assumed.

## Making the same expensive forecasts on opposite verdicts

The hard permutations can also be taken in pairs of ordinary formulas differing at one literal sign. Use the three guard clauses $(z,z,z)$, $(\neg z,\neg z,w)$ and $(\ell,\neg z,\neg z)$, where $\ell=w$ or $\ell=\neg w$. Check that all remaining clauses have the prescribed tautological layout, falling back to an ordinary solver on other inputs. With $z,w$ forced true by the first two clauses, the positive pin is satisfiable and the negative pin is unsatisfiable. On a validated permutation run the same scans before returning the guarded verdict. The failed inverse check may return the other verdict, since it is unreachable on authentic loads. This gives a correct solver. For a fixed pin the forward-oracle proof is unchanged. The union bound includes both signs at a cost of two, giving the same permutation and the same order of cumulative charge up to first halt on both. The pair has an inexpensive common way to determine its two answers after verifying the guard and layout.

## Matching the bit length of a square-clock source

The same obstruction persists when the predictor can read the short source from which the entire SAT input was generated. Fix $p$ in the forecast allowance. Let $b_0=\log_2m$ and give the predictor the $s=mb_0$ forward-table bits of the permutation as an additional free random-access input, charging every packed probe. Append $m^2 b_0^4$ fixed tautological clauses with $\Theta(b_0)$-bit literal fields. The resulting size satisfies
$$
 N=\Theta(m^2 b_0^5)=\Theta(s^2\log^3 s).
$$
A formula word is locally determined by $m$, its address and at most constantly many forward-table words. For example, lay out the varying clauses first and follow them by identical tautological records. Elementary index arithmetic in polynomial time in $\log m$ suffices to choose a record. This matches the relation between short input length and explicit formula length used by the square-clock checkpoint argument. The clauses here encode guarded permutations.

Make $\Theta(N/m)$ complete inverse scans on a passing input. There are still $\Theta(N)$ pre-load starts from which at least $w=\lfloor m/L^{p+4}\rfloor$ further instructions of that pass remain. Use only the first $r=\lfloor w/b\rfloor$ designated loads at each chosen start in the probability bound, where $b$ is the constant native iteration length. The forecast horizon remains $h=\lceil N^{0.97}\rceil$ and $w<h$. Later repetitions of the same keys within this longer horizon do not affect their first incoming reads. Modal corrections can be chosen using this entire horizon. Any prefix errors after applying them count toward its $u_t$.

If the charge at a start is at most $c w\log_2 L/L$, its native and predictor forward probes within this prefix, including probes of the freely accessible short source, fit $Q=\lfloor m/L^2\rfloor$. This uses the definition of the excess $e_t$ at the **prefix** of $w$ instructions. The probability of at least $\lceil r/2\rceil$ corrected hits for fixed advice is at most $(O(Q/m))^{\lceil r/2\rceil}=2^{-\Omega(w\log L)}$. Advice for a cheap row and its modal masks costs $O(cw\log L+L)$ bits. The same union bound therefore gives
$$
 U_h=\Omega\!\left(N\,\frac{m\log L}{L^{p+5}}\right)
     =\Omega\!\left(\frac{N^{3/2}}{\operatorname{polylog}N}\right)
$$
on genuine $\Theta(N)$-step runs. In particular this exceeds $N^{1.3622}$ for sufficiently large $N$. The example rules out deriving the desired time saving just from the square-clock *length relation*, local formula access, and a large forecast charge. It leaves room to use the particular self-referential truth condition of the diagonal formulas. A source of polylogarithmic length would require a different construction to attain this exponent with an inverse table.

For $\gamma=0.97$ this yields a $\Theta(N)$-time branch with cumulative cost $\Omega(N^{1.97})$ for every fixed admissible predictor, at the very horizon of the unconditional $1.3622$ theorem. Using only one scan still gives $\Omega(Nh/\log N)$ cumulative cost on the same encoding. In the repeated-scan construction, each forecast sees only the native history since its own start. Access to all earlier scans would reveal the inverse at known timestamps. The contradiction guard makes the SAT answer efficiently recognizable. The diagonal inputs in the lower-bound theorem have a different construction. Any deduction of extra solver time on those inputs using the forecast cost must use a property beyond its magnitude on a single run. This example alone does not rule out such a deduction for those inputs. Priority for the forecast consequence is unverified. [Finite audit](../audits/stateful_inverse_window_audit.py)
