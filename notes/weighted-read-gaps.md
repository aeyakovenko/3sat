# Charging the time back to an actual memory access

**Research journal, 24 November 2026.** Fix a deterministic RAM on the ordinary explicit SAT encoding of length $N$ bits. Number its native instruction slots $1,2,\ldots$ and allow one writable access per slot. A fixed instruction with several accesses is implemented by a fixed number of ordered slots with the same controller and temporary registers. Slots with no such access still advance time. Constant-factor changes in duration and gaps preserve the exponent claims. Read-only formula loads use their own bank. Work memory starts at zero. The program may signal just one sign of SAT, with no soundness error and no deadline on the other sign.

Call a read at time $r$ eligible if there has been a store to the same word. Write $p(r)$ for the most recent previous **touch** of that word, which can itself be a read. A store of zero is a store. For fixed rational $0<\lambda\le1$ put
$$
 G_\lambda(E)=E+\sum_{\text{eligible reads }r\le E}(r-p(r))^\lambda .
$$
Here $E$ includes the first signal. An arbitrary number of writes can be forgotten forever without producing any read charge. Repeated reads pay only from the immediately preceding touch. A later overwrite starts a new interval; time spent waiting for an overwrite contributes no read charge.

**Theorem.** For either chosen sign, the worst $G_\lambda$ on genuine inputs of that sign is outside $O(N^c)$ for each
$$
 c<\frac{\lambda+\sqrt{\lambda^2+4}}{2}.
$$
In particular $\lambda=1$ gives the golden ratio, separately on satisfiable and unsatisfiable formulas. More generally, with a separate sound nondeterministic reference accepting UNSAT in $N^{d+o(1)}$ time on negatives, $c,d\ge1$, the exclusion holds when $d(c-\lambda)<1$. In the unconditional positive case a timeout on the alleged positive bound supplies a deterministic reference of exponent $d=c$. For the negative case the original signal itself supplies that reference. No workspace cap is assumed. The bounds concern temporal gaps, not the number of distinct addresses between two accesses. [Related cumulative-space lower bounds, Beame and Kornerup](https://arxiv.org/abs/2301.05680) · [Information transfer across time intervals in online data structures, Pătraşcu and Demaine](https://erikdemaine.org/papers/DynamicConnectivity_SICOMP/paper.pdf) · [Earlier SAT bound for cumulative occupied words](cumulative-sat-memory.md)

There is a second version. Give a fixed, total polylogarithmic-time predictor the formula, event time, address and CPU controller just before a read, including its within-instruction phase. It predicts the pair **(preceding touch time, returned word)**. Use timestamp zero when there was no earlier touch. For this version charge $(r-p(r))^\lambda$ only on reads where the pair is wrong, with $p=0$ and memory value zero for a first touch. The same thresholds hold for every such predictor. It may consult the formula at each call, but it sees no private trace oracle. Even on reads of an unchanged value, a wrong source time can incur a charge. The [value-only version](#when-the-predictor-only-returns-the-word) removes this requirement at a cost in the unconditional exponent.

## One record per crossing read

Fix an actual prefix with terminal time $t$. For window size $w$, choose a phase $j$ modulo $w$ and cut time into blocks of length $w$, except for end pieces. A boundary after slot $i$ separates $p$ and $r$ exactly when $p\le i<r$. A fixed interval is cut for exactly $\min(w,r-p)$ phases if cuts on the whole integer line are allowed. Ignoring redundant initial or terminal cuts can only decrease this count. For nonzero $p$ the fraction is $\min(1,(r-p)/w)$, at most $((r-p)/w)^\lambda$. This also upper bounds the chance an initial-sentinel read with $p=0$ is outside the first block: that block starts with the real blank memory. Averaging gives a phase with at most $G_\lambda(t)/w^\lambda$ crossing eligible reads. In the pair-prediction version the same bound uses just the crossing *errors*. Each such read appears in the directory only once even if its interval spans hundreds of blocks. There are $O(1+t/w)$ controllers to guess. [Finite phase and averaging argument](../lean/ReadGapPhases.lean)

Use a public sorted directory keyed by reader time. In the first version give $(p,v)$ for crossing eligible reads, where $v$ is the actual value. Replay each block independently from its proposed CPU state. Always use the latest local access when available. A local store establishes a written word, and a local read preserves its written/virgin flag. At the first access in a block, a store needs no old value. For an incoming read listed in the directory use its proposed word, predecessor and written flag set to true. For an unlisted incoming read use zero and declare its history virgin. A first block can start at the true initial memory. The CPU transitions and formula input reads are deterministic on this tentative data. Each block consequently defines an ordinary transcript even when the directory is false.

An existential defect selects slots in constantly many such blocks. It can detect a bad initial or endpoint controller, a bad final condition, a malformed record, a claimed virgin read preceded by **any store**, or an erroneous listed pair. For a listed pair require $0<p<r$, a touch of the same address at $p$, matching post-access value and positive written flag there, and no touch of that address strictly in between. A single intervening slot witnesses failure of the last condition. Enforce that the key marks an incoming read, and the expected record and flag conventions. Induction on slots now forces genuine controller states, values, flags and every timestamp used by a charge or correction check. A virgin incoming read can have earlier virgin reads whose timestamps need never be reconstructed. Two or three canonical replays suffice for every individual test. No search for an unknown last writer occurs inside a universal challenge.

For the pair-prediction version all touch times count. On an incoming read use its predicted pair, unless an explicit correction supplies the pair. For positive $p$ check previous address, value, order and lack of an intervening touch. For the sentinel check that no earlier touch occurred and the returned value is zero. Local native history and true initialization provide the pair for free inside a block. Computing the predictor also at local reads tells the replay exactly which events incur a charge.

## A budget that can be checked on positive runs

At $\lambda=1$, for a fixed finite prefix define the live set after time $i$ to consist of words already written whose next touch within the prefix is a read. The sum of these cardinalities for $0\le i<t$ is exactly the sum of the eligible gaps. Each eligible read contributes its one word at cuts $p(r),\ldots,r-1$. This definition removes dead stores, future overwrites and untouched initial zeros. It counts a true zero word when a previous store and later read require it. For the pair predictor, associate the interval only to errors. This equality explains why the offline measure can be accumulated at the read, even though future liveness cannot in general be forecast at the cut.

For fractional $\lambda$, implement a monotone integer charge $u_\lambda(g)=2^{\lfloor\lambda\lfloor\log_2 g\rfloor\rfloor}$ for $g\ge1$. It lies between $g^\lambda/2^{1+\lambda}$ and $g^\lambda$. The CPU certificate carries the cumulative counter across boundaries and checks its update using the authenticated predecessor and word at every charged read. Word-sized clocks suffice on all polynomial prefixes; powers of two and integer logs cost polylogarithmic time. The measure uses no uncomputable future information.

Suppose the claimed positive upper bound holds. Choose a public budget $B=O(N^c)$ at least its integer-cost upper bound on positives. On a negative input, stop at a halt with no SAT signal or at the first completed slot where the cumulative counter exceeds $B$. Disallow an earlier positive signal, and on an ordinary positive input give a genuine SAT signal priority. All unbounded runs eventually cross the budget because each slot costs one. The last increment is at most $1+(B+1)^\lambda$, so this prefix costs at most $2B+2$ in integer units. Thus the same phase bound supplies a short, authentic chart on **every negative** input. Conversely, a checked chart ending with this negative condition cannot occur on a positive input. This construction does not require the solver to know its last touch times or monitor its own budget. On the negative-sign version simply certify the genuine UNSAT signal: all checked charts are sound and the cheap target runs supply the honest ones.

## The exponent and a logarithmic consequence

For a bounded nondeterministic machine of clock $R$ on $m$ public words use the ordinary [locally generated 3-CNF](packed-band-transfer.md), with $H=\max(R,m,2)$ and $N=H^{1+o(1)}$. The reference gives a nondeterministic nonacceptance simulation in $(R^d+m^d+1)H^{o(1)}$ time. Suppose the current work exponent is $e$ and the public input exponent remains $d$. For $w=\lceil H^x\rceil$ the chart has $(1+H^{c-\lambda x})H^{o(1)}$ words; $T/w$ fits as $0<\lambda\le1$. The defect test takes $H^{x+o(1)}$ work and public size $(m+H^{c-\lambda x}+1)H^{o(1)}$. Its nonacceptance proves a sound negative endpoint. Choose
$$
 x=\frac{cd}{e+\lambda d},\qquad e'=\frac{cde}{e+\lambda d}.
$$
At $d(c-\lambda)<1$ the iterates decrease from $e=d$ until one goes below one. Indeed the positive fixed point is $d(c-\lambda)$, and the update is increasing and below its argument above that point. In the boundary case $c=\lambda=1$ the iterates tend to zero. Unroll only finitely many steps before applying the signed diagonal with $R=m^D$, $D>d$. If $c=1$ it is also possible to relax to a slightly larger rational bound first. As in the [cumulative theorem](cumulative-sat-memory.md), the public $m^d$ term remains explicit at every stage, and the final simulation fits inside the source clock. Taking $d=c$ gives the displayed unconditional exponent.

A sharper count is available for a solver taking $O(N)$ time through its chosen sign. On infinitely many formulas of that sign it has at least $\Omega(N/\log^6 N)$ eligible reads with gaps at least $N/\log^{K}N$ for a fixed $K$. The same statement holds for the pair predictor with **mispredicted** reads. Here is conservative log bookkeeping. Set $H=m^2$ on the signed source, $L=\lceil\log_2(H+2)\rceil$, so $N=\Theta(H L^3)$. A cutoff through sign time supplies a linear-time SAT decision algorithm. Fix the target horizon $C N$ and choose $w=\lfloor H/L^u\rfloor$ with $u$ large enough for a constant number of $w$-slot replays including the decoder. Let $b=\lfloor w/L^7\rfloor$ and $J=\lceil H/L^3\rceil$. Stop at the first of the prescribed terminal sign, elapsed cutoff, or $J$ charged reads of gap at least $b$. Through this prefix the long reads need at most $J$ crossing records, regardless of phase. For some phase the short reads require at most $CN b/w=O(N/L^7)$ more. The number of controllers is polylogarithmic. The materialized no-defect call costs $O(R' L^3+m'L^2+\operatorname{poly}(L))$ at replay clock $R'=w\operatorname{polylog}H$ with $m'=O(m+J+N/L^7+CN/w)$ public words. This is $o(H)$. [Public-input accounting](materialized-input-census.md)

On positive targets the self-input source signals when it certifies this stopped prefix has reached the long-read cutoff or has run to the elapsed cutoff or negative halt **without** an earlier positive signal. A negative formula would supply such a certificate in time, contradicting nonacceptance. Its formula is therefore positive, and the timely certificate must reach $J$ long reads since the true positive signal arrives by $CN$. Give the positive signal priority over the elapsed cutoff when tied; a tie with $J$ already implies the count. On negative targets let the source instead signal if it certifies a genuine UNSAT signal reached before $J$. Self-acceptance is impossible, so the formula is negative, and a run terminating before $J$ would supply the prohibited certificate. Both cases give the claimed lower count. Consequently, for every $f\ge0$ with $f(g)/\log^6(g+2)\longrightarrow\infty$, elapsed time plus $\sum f(g)$ over the indicated reads is outside $O(N)$ on the chosen sign. Otherwise the target is linear on that sign, and the count just proved violates its hypothesized bound. No ability to evaluate $f$ on the RAM is needed.

## When the predictor only returns the word

For a fixed polylog-time **value-only** predictor, charge the gap only when its returned word is wrong. Use all touches for $p$, including sentinel zero. In particular the constant-zero predictor charges exactly the reads returning a nonzero word, all of which have an earlier store. Use the same random phase and explicit $(p,v)$ correction on exactly those crossing errors that need it. An unlisted incoming read uses the predicted value, and no precise stamp is needed to compute its charge, which is zero. Locally known earlier touches supply the true stamp for charged local reads. Explicit correction stamps can be checked for correctness by local existential defects. For an arbitrary tentative read with value $v$, a wrong value can be certified by a prior store of a different word with no intervening store, or by $v\ne0$ and no previous store. The no-intervening-store condition on these canonical transcripts needs one **additional** nonacceptance check. This establishes both true values and the correctness of the counter. With a true zero value, the argument allows arbitrarily many prior nonzero stores followed by a genuine reset.

Applying the reference twice gives, at $x=c/(1+\lambda)$, work exponent $d^2c/(1+\lambda)$ and public-input exponent $d^2$. A strict saving below one contradicts the same diagonal using a sufficiently large clock power. Thus each $c<(1+\lambda)^{1/3}$ is excluded unconditionally, on either sign. At $\lambda=1$ the [two-stage induction for live values](live-value-replay.md) improves the unconditional exclusion to $c=1.3622$, also on either sign for this online count. To apply that induction, suppose inner and outer nonacceptance bounds have respective exponent pairs $(u,b_0)$ and $(v,a)$. The one-interval test has work $H^{x+o(1)}$ and public data of size $(m+H^{c-x})H^{o(1)}$. After the inner and outer tests the new work exponent is $\max(uvx, B'(c-x))$, with public-input exponent $B'=\max(a,b_0v)$. Missing and misdated correction records use the same or cheaper defect tests. There is no imposed forward-horizon cap in this application. The cited finite certificate starts from $(c,c)$ and ends below one at the stated rational $c$.

Under an independent deterministic $O(N\operatorname{polylog}N)$ SAT algorithm the extra nonacceptance check costs further fixed logarithms. On infinitely many inputs of the chosen sign the error-weighted cost is then at least $N^{1+\lambda}/\operatorname{polylog} N$, even if the target takes arbitrary time. For details choose a native integer budget $B=\lfloor H^{1+\lambda}/L^A\rfloor$, $w=\lceil H/L^u\rceil$ and $u,A$ successively large enough. The two levels of checks take $(m+w+B/w^\lambda+1)\operatorname{polylog}H=o(H)$ at the self-input root. For the positive side certify no positive signal by the budget, which is possible on any negative input with cost at most $2B+2$ up to cutoff. For the negative side certify a genuine UNSAT signal within budget; a negative formula with a cheap signal then yields the usual contradiction. With $\lambda=1$ and a linear target this forces $N/\operatorname{polylog}N$ mispredictions with gaps at least $N/\operatorname{polylog}N$: short gaps contribute at most $CN$ times their length threshold, and each remaining gap is at most $CN$. Choosing the constant-zero predictor gives genuine **nonzero** returned words in this conclusion.

Private, locally checkable certificates for read values are allowed in the [verified-reply extension](certified-read-gaps.md). The step from temporal gaps to an unrestricted elapsed-time lower bound still fails. A linear native run can carry linearly many values across linear gaps, and the values can defeat local prediction even on recognizable explicit formulas.
