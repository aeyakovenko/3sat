# Certificates, reflection, and the length of a hard example

## Can a rejecting computation be turned into a lower bound?

Suppose A decides explicit SAT on m encoded bits in O(m^d) deterministic word-RAM time for d equal to 2 or 3. A sound proof checker for UNSAT can then accept the empty certificate after running A on its input. In the Cook–Reckhow function convention, the proof can simply be the formula F itself: output F when A rejects a well-formed F, and output a fixed contradiction otherwise. Every unsatisfiable formula has a proof of its own encoded length in this system. The computation has moved into its verifier. A lower bound for resolution or any fixed family of inference rules transfers only after establishing that it efficiently simulates this verifier, with suitable exponents. [Cook and Reckhow](https://www.cs.toronto.edu/~sacook/homepage/cook_reckhow.pdf)

Krajíček's Theorem 2.1 gives a concrete transfer for SAT algorithms whose rejecting soundness has short proofs in a specified system. Specializing a soundness proof to a rejecting transcript yields a proof of the corresponding tautology. If such a transfer in a system P bounds proof length by O((m+t)^b log^c(m+t)) on a t-step run, a quadratic clock implies a bound O(m^(2b) log^c m), and a cubic clock gives O(m^(3b) log^c m). The constants and the system must be fixed for the particular decider. I tried to obtain the soundness premise merely from the fact that the candidate decider is correct. [Krajíček, Theorem 2.1](https://www1.karlin.mff.cuni.cz/~krajicek/sat.pdf)

## A solver with the same time exponent and unprovable soundness

Fix a consistent, effectively axiomatized arithmetic theory T supporting Gödel's second incompleteness theorem, with a standard polynomial-time proof predicate. PA with the usual finitely encoded proofs is one choice. Choose a polynomial bound O((s+1)^c) for checking whether a bit string p of length s is a T-proof of contradiction. Require T to verify the elementary syntactic computations below.

Construct a satisfiable CNF E(p) with the bits of p in a prefix, followed by padding of length Θ((s+1)^c) for a positive integer c. A constant alphabet of syntactically distinct tautological clauses on a fixed variable gives two data symbols, a delimiter, and a padding symbol. Every input with this recognized syntax is satisfiable. To keep **malformed** inputs cheap, first scan for the delimiter and count the available padding; require at least (s+1)^c padding symbols before checking p. Capped arithmetic suffices for the length comparison. This template can be recognized and p checked in O(m) on any recognized input of encoded length m. Fix a canonical encoding E for the argument inside T.

Define A_T on recognized templates to output UNSAT if and only if p passes the proof check. On every other string run A after scanning the input. Externally T is consistent, so on a template A_T always returns SAT. Hence if A is a correct SAT decider, A_T is correct and takes O(m+t_A(F)) time on F. In particular each of the two target clocks is preserved.

Let soundness mean that A_T never returns UNSAT on any satisfiable formula. In T, take any alleged proof p of contradiction. The designated E(p) has a satisfying assignment, and if p passes the check the program rejects E(p). Thus T proves that rejecting soundness of A_T implies Con(T). Gödel's theorem excludes a T-proof of this uniform soundness assertion. This argument only needs correctness of A for the external claim that A_T is a decider. The implication proved inside T uses the template branch alone. [Gödel, Theorem XI](https://doi.org/10.1007/BF01700692)

This yields a same-clock counterexample to a uniform reflection premise: no such fixed T proves the rejecting soundness of **every** correct candidate in a nonempty target time class. It does leave open short proofs of the separate finite soundness instances. It also leaves open a proof based on one well-chosen verifier. Adjoining soundness of A as an axiom changes the theory whose proofs have to be lower-bounded.

**A stronger repair also fails.** Permit the proof to choose the theory *after* seeing the solver, from any fixed computably enumerable menu of consistent theories extending enough elementary arithmetic. Assume a uniform effective enumeration of their derivations in their standard presentations. One solver defeats this entire menu. Build a fixed Turing machine U that fairly dovetails the enumerations and halts if any listed theory derives a contradiction. On a second, particularly simple template, encode t in unary using t repetitions of a tautological clause. Reject such an input exactly when U halts within t steps. Simulating t steps of a fixed ordinary tape machine costs O(t) on a RAM, and all other inputs can still go to A. External consistency of *each* listed theory ensures U never halts. Their union need not be consistent for this argument.

For any fixed listed theory Tᵢ, its finite listing event and the fair simulation of its own proof enumeration are verifiable in Tᵢ. If Tᵢ proved the patched solver never rejects a satisfiable formula, then it would prove U never halts, by considering the unary template at all time bounds. Formalized fairness implies that any contradiction derivation of Tᵢ would eventually be seen by U. Thus Tᵢ would prove Con(Tᵢ), again impossible. This rules out, even under the putative fast SAT algorithm, an effective *a priori trusted* menu covering all rejecting-soundness statements at that clock. The argument allows the choice of a menu member itself to be noncomputable. The assignment A ↦ T₀ plus the axiom asserting soundness of A escapes this version: on arbitrary faulty programs the resulting menu is not guaranteed consistent. The speed penalty of the diagonal branch stays linear even when the theories in the menu have arbitrarily costly proof predicates, because the input measures the supplied simulation time.

**Finite version.** Fix a polynomial M(s) bounding the encoded lengths of all E(p) with |p|≤s, and let R(N) express rejecting soundness up to input length N. The same argument proves in T the single implication schema obtained by instantiating a fixed universal theorem

    ∀s ( R(M(s)) → Con_T(s) ).

Here Con_T(s) excludes proofs of contradiction of length at most s. Use the term M(s) inside R rather than expanding its value in unary. In a standard string-based Hilbert calculus, appending an instance of the fixed implication and modus ponens to a proof of R(M(s)) costs O(poly(log(s+2))) symbols for a binary numeral s. Thus a finite-consistency lower bound L(s) transfers to the first-order proof length of this finite reflection statement up to that additive cost. In particular Pudlák's near-linear lower bound in s, under the hypotheses and proof calculus of his Theorem 2.9, gives an obstruction at that scale. The CNF encoding uses at least s bits and may have polynomial padding. The first-order bound does not yield a quadratic lower bound in CNF length. A further conversion would also be needed to lower-bound propositional reflection proofs. [Pudlák, Theorem 2.9](https://users.math.cas.cz/~pudlak/improved.pdf)

**Attempt to reverse the reduction.** Encode the existence of a T-proof of contradiction of length s as SAT, obtain rejection, and formally justify that rejection in T. Suppose the formula has m=Õ(s^a) bits and the entire formal justification, including translation correctness, would have length Õ((m^d)^b), for a,b>0. To beat an Ω(s/log²s) proof-length lower bound by a power, the needed inequality is adb<1. An explicit tableau carrying one bit for each position of the guessed proof has a≥1 for its written size; a proof that explicitly lists the charged run gives no b<1 saving on that budget. Even a semantically correct solver supplies no general T-proof of soundness. One route still open would need a succinctly justified equivalence inside T between a much shorter SAT instance and finite inconsistency, together with a sufficiently short formal justification of the solver's rejection. In the consistent standard model the finite inconsistency questions all have the same answer, so their truth values alone do not furnish that equivalence in T.

`lean Reflection.lean` checks the exact semantic decomposition of rejecting soundness into absence of bad proof codes and soundness off the templates. It also checks the bounded inference given a length bound for the encoding. Gödel's theorem, arithmetization, and the quantitative estimates are used in the manuscript argument.

## Attack on an efficiently generated family of certified hard instances

Try a stronger form of the desired lower bound: a constructor given a solver description e and target length m enumerates hard instances F of exactly m bits with verified labels. The constructor can specialize to the target machine. Suppose a fixed verifier V is sound for both labels it certifies. SAT witnesses can certify the positive label; a chosen refutation system can certify the negative label. The following obstruction also works if all constructor outputs have a fixed label known to be correct for **every** program parameter.

For any fixed uniform constructor G with access to its input e as data, build a solver D that obtains its own finite description e. On input x of length m, D runs G(e,m), checks produced items for equality with x and for a valid certificate, then returns the first matching certified label. It stops this search after m^d elementary work (including checks and comparisons) and then uses exhaustive SAT if needed. D is correct regardless of the constructor's behavior. Self-reference here can be implemented by taking a fixed two-argument program template H and a syntactic specialization function. The specialized program H(h,x), with h the code of H, computes its own code as specialize(h,h) in a constant depending only on H, then calls the fixed G and V. These calls can be compiled directly. The timeout can be implemented as bounded, instrumented simulation of this fixed computation with a constant number of word operations per simulated instruction and private workspace. Exhaustive fallback needs polynomially many words only, even though its time can be exponential.

On a length-m input enumerated with its valid certificate in total o(m^d) work, D finishes the fast branch in o(m^d) time, including an O(m) scan. Consequently no such always-fast certified constructor can force Ω(m^d) time on one of its certified outputs for **every correct SAT decider** infinitely often. More precisely, for this D every output whose complete certified enumeration prefix fits the budget is easy at the cost of that prefix. If the exhaustive baseline is replaced by a hypothesized O(m^d) solver, then the cap preserves that clock on off-list inputs as well.

The exponent matters for short random seeds. If b(m) seed bits index a list and generation, equality testing, and certificate checking take m^(1+o(1)) time per seed, exhaustive enumeration costs 2^(b(m)) m^(1+o(1)). Thus when b(m)≤(d−1−δ)log₂ m for any fixed δ>0, all listed instances with valid certificates are easy for the patched solver. Supplying only a hard candidate of unknown status, making the index difficult to recover from its length, or making correctness of the label rely on the unproved soundness of the target removes a stated premise. In the latter case the patched machine might be wrong, so plugging it back into a constructor guaranteed only on correct machines would be circular. Hard sequences and error-producing refuters in the literature have different quantifiers and budgets. This calculation is a restriction on explicitly labeled, efficiently reproducible lower-bound witnesses. It supplies no upper bound on general SAT. [Chen, Flum and Müller](https://www.fim.uni-passau.de/fileadmin/dokumente/fakultaeten/fim/lehrstuhl/muller/Hard_instances.pdf) · [Chen, Jin, Santhanam and Williams](https://arxiv.org/abs/2203.14379) · [Krajíček on fixed-system proof search](https://arxiv.org/abs/2104.04711)

## Exact reformulation by the length of the first error

The unary padding trick gives a source-code parameter on which the requested lower bound has an exact dichotomy. Fix an effective finite-bit program encoding, an integer d≥1, and explicitly clock every program by K(m+1)^d with its positive integer K included in the description. On expiration return a fixed default bit. Use the ordinary logarithmic-word semantics, with computable descriptions and clock constants; any decider meeting the asymptotic bound has at least one equivalent clocked description. Count only syntactically valid codes. For a wrong program e let b(e) be its least input length with a wrong SAT answer. Define B_d(l) to be the largest b(e) over all wrong codes of at most l bits, or zero if there are none. Correct codes are omitted. These conventions make B_d a total finite-valued function even when no algorithm for it is given.

* If SAT has no deterministic O(m^d) solver, B_d is computable. Enumerate all valid codes of length at most l and test all strings in increasing length against exhaustive SAT. Every one of the finitely many programs eventually exhibits an error. Record its first error length and stop once the entire list has failed.
* If a correct O(m^d) solver A exists, let BB(l) denote the largest halting time of any halting no-input program of length at most l on a fixed universal tape machine. There is a constant c such that B_d(cl+c)≥BB(l) for all sufficiently large l. To see this, given such a program p, modify A on a canonical satisfiable formula E(t) containing t copies of a tautology. Answer UNSAT exactly if the fixed universal machine with p as data halts within t steps. On other inputs preserve A. The template has encoded length at least t and O(t+log(t+2)) in the constant-variable encoding. Parsing the template and simulating t steps of the fixed tape machine takes O(m+|p|) RAM time; absorb the initialization cost into a larger clock constant. Generating the modified code by embedding the fixed A and the bits of p costs at most c|p|+c description bits, including its larger computable clock bound. For a p halting at step t₀, every error has length at least t₀, and E(t₀) exhibits an error. If p never halts the modified code is correct. The constant c may depend on the chosen A, its clock, and the encodings.
* In either case B_d(l)≤BB(c'l+c') for a constant c'. Given a wrong program e, a tape program hardwires e, exhaustively finds its first error length b(e), then writes b(e) unary marks before halting. Its description has length O(|e|+1), and writing those marks takes at least b(e) steps in the fixed tape model. A universal language that interprets this fixed search procedure plus e with linear description overhead suffices.

In particular, **a computable upper bound on the least counterexample length for every wrong clocked program is equivalent to SAT requiring more than O(m^d) time**, where the bound may be any total computable function of description length. Under a hypothetical fast solver even a computably enumerable list of exactly the correct clocked programs is impossible. Correctness is co-computably enumerable by testing inputs. The same unary construction reduces nonhalting to correctness under the hypothesis, so the correctness index set is then complete at that level. If every code is wrong the correctness index set is empty.

**Failed step towards the cutoff.** Every finite collection of wrong codes has a last first error. Treating this finite maximum as effectively available assumes the missing conclusion. Even under the fast-SAT hypothesis one can improve the *bounded* search without overcoming this gap. Fix a clocked e, a correct d-clock decider A, and a proposed numerical cutoff N given in unary. Guess a string x of length at most N and compare e(x) with A(x). For these fixed programs the nondeterministic check takes O((N+1)^d) time. A standard quasilinear computation-to-CNF reduction followed by A decides if an error exists up to N in Õ((N+1)^(d²)) time. On incorrect codes successively doubling N eventually finds such a bound. Correct codes never produce a positive answer, and the procedure supplies no criterion for when to stop increasing N. [Williams on quasilinear reductions](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

This restates the missing uniformity as an arithmetic question with no prescribed rate of growth. Lean checks the two semantic steps of the delayed-error construction in `no_early_error` and `error_on_halt`. The Busy Beaver comparison and its computability implications are paper arguments and carry no priority claim. It concerns error lengths of *candidate programs*, rather than a lower bound on the time of an individual SAT computation.
