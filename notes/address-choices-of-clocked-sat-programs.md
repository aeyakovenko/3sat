# How many addresses can clocked SAT programs schedule in advance?

Consider arbitrary deterministic RAM programs on ordinary proper DIMACS, with a fixed clock for each program at the current length. A program can use unrestricted workspace. Before seeing the input, give each memory-access slot a list of possible addresses. A run **escapes** if some access uses an address absent from that slot's list. The following tradeoff charges the size of those lists and permits an arbitrary size-unrestricted truth table on the programs' output trits at each length.

On the dense list projection, a fixed globally correct SAT solver finishing every run in $O(n/\log n)$ word steps must, on average over its time slots, allow $\Omega((\log n)^\sigma)$ possible addresses per slot to cover all its runs. Here $n$ is the physical input bit length, and $\sigma>0$ comes from the upstream list theorem. In fact any prescribed smaller lists are escaped on exponentially many SAT files and exponentially many UNSAT files of the same length. The addresses in the lists are free nonuniform data. This conclusion is compatible with the known globally correct solver attaining that very elapsed clock. ## Compiling a list of possible addresses for each clock tick

For a roster indexed by $i$, let $T_i$ count synchronous microsteps through the clock, including idle padding after halt. Expand each ordinary instruction into a fixed number of slots, each with at most one word access. Each slot can idle, read or write, with a bank tag in the effective address. This also permits data-dependent branches and multiple ordered accesses in the original instruction. At slot $t$ hardwire an arbitrary finite set $A_{it}$ of bank-address pairs. Let $W_i$ be the guest word width, sufficient to encode one address up to $O(1)$ tag bits. Let $U_i(W_i)$ bound the gate cost of one local control and register update and its memory interface, excluding the actual read or write. For variable-size programs this quantity must include instruction and register selection costs.

There is a guarded simulator returning the genuine timed trit of each covered run, and flagging the first escape of each uncovered run, of cost
$$
 O\left(1+\sum_i\left[1+T_i U_i(W_i)
       +W_i\sum_{t=1}^{T_i}|A_{it}|\right]\right).
$$
For each $a\in A_{it}$ compare the proposed bank-address with the hardwired constant. Source the old word at $a$ from its most recent *potential* write slot, or its initial input wires or initial zero. For reads, OR the old word bits gated by their respective comparisons. For a possible write at $a$, connect a fresh version whose value is the proposed word if the actual mode is write and the address matches, and the old version otherwise. This is one conditional word update per listed address, regardless of how many earlier writes competed for that address. Distinct bank tags distinguish input words from work cells. Fixed initial padding bits and metadata are hardwired. The circuit has a flag for an enabled access matching no listed address. It ignores all later outputs of a failed run. Induction on the slots shows that up to and including the first flag the control, registers, and current contents used for covered addresses agree with the native run. An escape on an earlier prefix cannot be concealed by a later return to a listed address. Idle steps require no address.

For a fixed standard program, $U_i(W)=W(\log(W+2))^{O(1)}$ suffices in the trivalent bit-network model used here. Bitwise operations, comparison and addition cost $O(W)$, a variable-distance shift costs $O(W\log(W+2))$, and multiplication admits quasilinear-size bit circuits. For division one can introduce the quotient and remainder on internal wires, verify their product identity at double width together with the remainder bound, and enforce the ISA's zero-divisor and sign conventions. Each input then has exactly one valid local evaluation. Pin any auxiliary values for an inactive operation to their prescribed defaults, or evaluate the unique total operation regardless of its selection. Composing these local relations with the guarded circuit yields exactly one consistent global evaluation for each external input, including inputs where it flags an escape. Thus the final contraction over $\mathbb F_2$ is the desired decision bit. This division argument uses the source network lower bound directly. For a different primitive the formula above applies with its actual local cost. [Harvey and van der Hoeven, Section 1, including Boolean circuits](https://www.texmacs.org/joris/nlogn/nlogn.pdf) · [Upstream Theorem 2.2](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/build/obstruction.tex#L40-L79)

On the files covered by every roster member, suppose no two opposite SAT verdicts have identical trit vectors. If $r$ distinct covered signatures occur, the exact decoder there costs $O(1+r)$ gates **even if the roster has many more coordinates**. Encode each trit in two bits. Recursively split any nonsingleton set of attained signatures on one bit that is nonconstant there. The resulting tree has $r$ leaves and at most $r-1$ internal binary multiplexers, each selecting between its two subtree output bits. It implements any required labels on the attained signatures. Outside this set its value is immaterial. Use a constant when $r=0$. Bounded fanout needed in the source model is implemented with total cost linear in the number of gate input positions plus exterior bits. Neither the address sets nor the decoder need to be computable from the length.

## Lists of possible last writers

A second compiler needs no hardwired writable addresses at all. At each possible read slot list any earlier time indices that can supply the current value by a write. For an initialized input image, also list possible original input word indices. An untouched work word supplies zero at no cost. More generally treat a writable input bank as a bank initialized from the original image. Record the simulated bank, address, write-enable bit and payload of every microstep. At a read, select the matching listed original word, if present, as a default, and then select the latest listed earlier *actual* enabled write to the queried bank-address. A priority scan ordered by increasing write time needs one word comparison and one conditional word selection per entry. It works across inactive instructions and repeated writes. No test among unlisted times is made.

A run is covered if the genuinely latest earlier write for every read with a previous write is listed, and every original input source actually needed is listed. Induction on read slots shows that this circuit reproduces the genuine timed trits on covered runs, even with arbitrary data-dependent changes of work addresses. The cost formula above uses the number of listed sources at read slots in place of the address cardinalities. Thus in the whole-list scan-time corollary below, the average number of possible genuine read sources is also $\Omega(w^\sigma)$ per clock slot when all runs are covered. For writable memory the source is a write **time**; relabelling its addresses does not change that dependency.

The source compiler need not recognize the first escape. An earlier listed write can match the right address yet carry a stale value if the later true writer was omitted. On a disjoint tail, if every input is covered and the covered signatures have no opposite pair, the same contradiction still holds. Consequently, unless there is a covered mixed pair, **some input** escapes on that tail. Getting one escape of each sign uses the explicit detection flag of the address-set compiler.

## Many disjoint restrictions of one physical length

Write $M=2^w$ and $q=2wM$ for the source record count and bit length. The SAT projection is injective because the fixed decimal digit positions display every input bit. It preserves length at each $w$ and needs only constants and copies of bits. Its physical length is $\Theta(q)$, also after canonical padding to any intermediate byte-aligned length. SAT on these files means the input list contains a duplicate.

The journal previously embedded shorter lists into disjoint fillings to count failures of modular witness extraction. The calculation here keeps an explicit density exponent and applies the restrictions to both signs of a flagged elapsed run. [Earlier disjoint restrictions](multiplicity-and-size-of-fixed-ram-verifiers.md)

For $1\le w'<w$, let $m=2^{w'}$. The first $m$ rows use the subalphabet of $m^2$ words beginning with $2(w-w')$ zeros. Their suffixes are independent $2w'$-bit records. Fill the remaining $M-m$ rows with **any ordered tuple of distinct** words outside that subalphabet. Fix one such tail. Within its actual files the SAT verdict is exactly the complement of $D_{w'}$, the distinctness test on the $m$ free rows. Thus correct decision there needs $\Omega(m(w')^{1+\sigma})$ network volume for large $w'$, even if the circuit and addresses know the whole fixed tail. Substituting constants deletes unused exterior wires. The bit projection into the network costs $O(mw')$ plus its gate input positions, since even many occurrences of a repeated input bit need at most a tree of copies with that many leaves. [Bit projection and gate-to-network conversion](checking-the-sat-circuit-bound.md)

For this tail put
$$
 K=1+r+\sum_i\bigg(1+T_i U_i(W_i)+W_i\sum_t |A_{it}|\bigg).
$$
If $K$ is below a sufficiently small absolute constant times $m(w')^{1+\sigma}$, then at least one of two events occurs on the tail.

1. Two **covered** files of opposite verdict have exactly the same genuine timed outputs for every program. Each globally correct listed decider times out on both.
2. At least one SAT file and at least one UNSAT file escape the proposed coverage. The two genuine escape events may come from different programs and different times.

Otherwise the covered signatures decode correctly, and all escaping files, if any, have one common verdict. Choose that verdict as the constant output when any simulator raises its flag. Use the decision tree everywhere else. This produces a correct network on the whole embedded list of width $w'$, contradicting its lower bound. The flag is essential for the assertion about both signs. The same proof with $w'=w$ and no tail gives the whole-list tradeoff.

There are $(M^2-m^2)_{M-m}$ disjoint tails, where $(a)_b=a(a-1)\cdots(a-b+1)$. For $m\le M/2$ its base-two logarithm is at least
$$
   q-2wm-O\big(M(m/M)^2+1\big).
$$
Indeed each factor is at least $M^2(1-(m/M)^2-1/M)$, so the loss beyond the $2w$ bits per tail row is $O(M((m/M)^2+1/M))$. For any fixed $0\le\alpha<\sigma$, choose $0<\delta<\sigma-\alpha$ and take $w'=w-\lfloor\delta\log_2 w\rfloor$. Then $m=\Theta(M/w^\delta)$, the size lower bound on each tail is $\Omega(qw^{\sigma-\delta})$, and their number is at least $2^{q-O(q/w^\delta)}$. Any construction with $K=O(qw^\alpha)$ is covered by the dichotomy independently on each tail. Address lists, decoders, and the selection of attainable types may even depend on that tail. The density statement under uniform source bits applies to a **single common** set of address lists when counting its escapes. It gives $2^{-O(q/w^\delta)}$, a subexponentially small lower bound.

For a fixed genuine scan-time SAT decider the first event is impossible at a covering deadline. With $W=\Theta(w)$, $T=O(q/w)$ and $r\le3$, its additive local cost $T U(W)$ is $q(\log w)^{O(1)}=o(qw^\sigma)$. The whole-list inequality forces $\sum_t |A_t|=\Omega(qw^{\sigma-1})$ whenever the lists cover every run. Their average size over $T$ slots is therefore $\Omega(w^\sigma)$. Lists of at most $O(w^\alpha)$ possibilities per slot, for any $\alpha<\sigma$, are escaped by at least $2^{q-O(q/w^\delta)}$ actual projected files of each verdict, for every fixed $\delta<\sigma-\alpha$ with $\delta>0$. When $\alpha=0$, apply the preceding tail calculation directly with $K=q(\log w)^{O(1)}$, still $o(qw^{\sigma-\delta})$ for each such $\delta$. After one of these address choices, the machine continues at its native cost. That explains why the count of address choices yields no superlinear elapsed-time witness against this solver.

The disjoint-tail calculation also applies to any ordinary Boolean circuit of size $O(qw^\alpha)$. It must err on some input in every tail, hence on at least $2^{q-O(q/w^\delta)}$ source inputs of the one length. This counts errors on the induced distribution of proper SAT files. Their sign can depend on the circuit. The stronger two-sign assertion above concerns explicitly flagged failures of coverage or mixed signatures. The list theorem is due to the upstream authors. Priority of these compilation and counting corollaries has not been established.
