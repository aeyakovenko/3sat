# Can a binary length make the diagonal computation succinct?

**Finding.** If explicit SAT has a deterministic word-RAM algorithm running in `O(m^d)` time, some clause-locally generated satisfiable 3-CNFs for a fixed nondeterministic hierarchy language require assignment circuits larger than `T^(1/d−ε)` on infinitely many inputs, for every fixed `0<ε<1/d`. Here T is the original exponential clock. This is a conditional lower bound on *assignment circuit size*. Its proof explains why locality of clauses cannot by itself yield an unconditional SAT time lower bound.

## Put the length in binary

Map a binary string x of length k to the unary length N whose binary expansion is the concatenation 1x. Then `2^k ≤ N < 2^(k+1)`. Every binary x occurs. A computation taking `2^k` steps on x takes only polynomial time as a function of the corresponding unary length. Any unary decision problem has a one-bit nonuniform answer at each length. A circuit that on input an index outputs a witness bit must compute a whole function of the index. The one-bit decision circuit supplies no such function.

Work directly on x when generating the clauses. For a fixed verifier with time bound `T=2^k`, Theorem 1 of Jahanjou, Miles and Viola constructs a circuit D in time poly(k) mapping a clause index to its three signed variable names. Its clause index has `k+O(log k)` bits and its variable names have `O(k)` bits. Each output bit has constant locality. The expanded 3-CNF is satisfiable exactly on accepting instances. Applying this to a binary simulation of a unary machine incurs the time needed by that simulation, which must be included in T. [Jahanjou, Miles and Viola, Theorem 1](https://arxiv.org/abs/1311.3171)

## Guess a witness circuit and charge one SAT call

Choose a fixed language L in nondeterministic multitape time `2^k` outside nondeterministic multitape time `2^k/k²`, by the nondeterministic time hierarchy (the adjacent-input-length clock condition holds). For the corresponding local reduction, suppose all sufficiently large yes-inputs admit some fan-in-two basis circuit W of size `S = 2^(αk)` computing a satisfying assignment indexed by variable name. Take a constant dyadic rational α strictly between zero and `1/d`, using ceilings for the clock. The following algorithm decides L.

1. Generate D and nondeterministically guess W in topological order. Reject malformed descriptions.
2. On input index i, a circuit B uses D(i) to obtain three names and signs, evaluates W at each name, and outputs one precisely when that clause is false.
3. Apply the Tseitin encoding to B with its output pinned to one. The resulting ordinary CNF has `O((S+poly(k)) log(S+poly(k)))` encoded bits. Use the deterministic SAT solver and accept this guess exactly when it returns UNSAT.

This test is complete on yes-inputs having a size-S witness. On a no-input, every W falsifies some clause. The machine may hardwire the finitely many exceptions in the supposition. Only one call appears because the *hierarchy machine* guesses W nondeterministically. Deterministically finding W incurs a separate cost.

The multitape machine can nondeterministically simulate the word-RAM SAT call within a polylogarithmic factor in its running time. Guess a chronological transcript, verify the fixed instruction and register transitions, then mergesort memory accesses by address and time on work tapes and check each read against the last write. Initialize the simulated input memory from the generated CNF. Each word has logarithmic size in the SAT input, and its elementary arithmetic can be checked in polynomial word length. The SAT decider is deterministic, so a rejecting computation can be certified by this same simulation. Generating the Tseitin clauses and guessing descriptions also costs `O((S+poly(k)) poly(k))` on tapes. These bounds give total time `2^(dαk) poly(k) = o(2^k/k²)`, contradicting the chosen L. The sort-and-check approach is described in §1.2, and the hierarchy/succinct-witness template in §6, of the local reductions paper. [Jahanjou, Miles and Viola](https://arxiv.org/abs/1311.3171)

For any ε in the stated range, choose dyadic α strictly between `1/d−ε` and `1/d`. The contradiction supplies infinitely many yes-inputs with witness circuit size exceeding `T^(1/d−ε)`. For d=2 the threshold approaches the square root of T. For d=3 it approaches the cube root. The language in this quantitative argument is nondeterministic; an arbitrary deterministic hierarchy machine cannot be substituted in its hierarchy step.

**Refinement at the requested integer exponents.** The losses in the verification time are polynomial in k with an exponent independent of the guessed circuit size for `poly(k) ≤ S ≤ 2^k`. More explicitly, the guessing, encoding, SAT running time and sorted-transcript checks cost at most `K S^d k^c` for fixed K and c once S dominates the polynomial-size clause generator. Choose an integer A with `Ad>c+3` and use the computable size ceiling `S=floor(2^(k/d)/k^A)` (integer d=2 or 3 allows integer root computation on O(k)-bit numbers). Eventual availability of witnesses of this size on every yes-input would give time `O(2^k/k³)`. Thus there is a constant A such that infinitely many satisfiable outputs require strictly more than `floor(T^(1/d)/(log₂ T)^A)` gates. This counts against a proof relying solely on a generic compression theorem, and still leaves SAT's own time complexity open.

## Retest with a deterministic unary computation

There is also a qualitative deterministic version. Fix by deterministic time hierarchy a binary language H in `DTIME(2^O(k))` outside P. Its unary recoding above has a deterministic polynomial-time computation. Generate the local clauses from the binary decider with an appropriate exponential clock. If all satisfiable outputs have assignment circuits of size poly(k) with a single polynomial bound, the preceding guess-and-check runs in NP under the explicit polynomial-time SAT hypothesis. That hypothesis implies P=NP, contradicting the choice of H. Thus even this deterministic unary recoding requires superpolynomial-in-k witness sizes in the sense that no one polynomial bounds them on all yes-instances. This uses only the expanded computation's satisfiability and needs no uniqueness promise on its Tseitin assignment.

The familiar NEXP easy-witness theorem assumes `NEXP ⊆ P/poly`. The NP easy-witness theorem of Murray and Williams assumes that a single fixed power of the input length bounds circuit size across *all* NP languages. A fixed SAT exponent yields a polynomial algorithm for every NP language, with the exponent depending on its reduction. Neither easy-witness premise follows by applying this ordinary completeness argument. The guess-and-check calculation above makes the missing witness bound falsifiable. A proof along this route would need to obtain short witnesses independently for the particular hierarchy family, or exploit features that avoid describing a complete assignment. [Williams, Theorem 5.2](https://www.cs.cmu.edu/~ryanw/acc-lbs.pdf) · [Murray and Williams](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf)
