# Locally extracting descriptions of the solver's own positive-run memory

**Research journal, 24 November 2026.** Fix a deterministic logarithmic-word RAM that signals SAT on every satisfiable explicit formula and never gives that signal on an unsatisfiable formula. Fix two uniform, clocked procedures. A *description extractor* gets the input, the time, the controller and indexed access to the current real writable memory. It returns the common length allowance $s_t$, the number of offers, or a specified bit of a specified offer, in polylogarithmic time per query. Pad each offer to $s_t$ bits, retaining any needed length header. A *decoder* gets just the read-only input, time, the offer and its length, and the work address to be decoded. Its polylogarithmic-time queries start with blank private scratch. In particular the decoder cannot look back at the physical work memory. A descriptor explicitly published in the machine's memory at a base and length given by its registers is one instance of this convention.

Assume that at every pre-signal time on every positive run **at least one** offered string decodes *all* writable addresses correctly. The honest offer may vary from step to step. The extractor can offer arbitrarily inaccurate strings on negative inputs. Let $N$ be the encoded formula length, $E$ the first positive signal and $K=\sum_{t<E}(1+s_t)$. For a single offer the worst positive-input $K$ is outside $O(N^c)$ for every fixed $c<\varphi=(1+\sqrt5)/2$. The conclusion holds with up to $O(N^\beta)$ offers per time for fixed $0\le\beta\le1/\varphi$ as well. The time and space of the solver itself are unrestricted.

More generally let $c,d\ge1$ and allow $N^{\beta+o(1)}$ offers, with a public cap. If there is a sound nondeterministic UNSAT reference of time $N^{d+o(1)}$ on all negative inputs, the two strict inequalities
$$
 d(c-1)<1,\qquad d\beta<1
$$
suffice. With no separate reference take $d=c$, since a deterministic timeout deciding whether any genuine positive signal occurred by $O(N^c)$ decides SAT if the claimed positive bound holds. The extractor's time and representation convention are part of this theorem. Removing the extractor leaves the weaker unconditional $\sqrt2$ exponent for independently optimal descriptions on positives; under a linear reference, even the unrestricted optimum already obeys a near-quadratic bound up to logarithms. On negative inputs a separate direct argument gives the golden ratio for optimum descriptions. ## How a negative run can verify a bad offer

Assume $K\le C N^c$ on positives and fix a public integer budget $B$ at least this bound with $B=O(N^c)$. Round powers or allow a small rational slack inside the strict inequalities. Before each guest instruction inspect its declared allowance. If the solver has signaled SAT, fail the negative branch immediately. A halt without that signal, or a next charge $1+s_t$ exceeding the remaining budget, can be a negative endpoint. Saturating length arithmetic suffices before any access to the offer bits. On an affordable pre-signal state, a third possible negative endpoint asserts that **every offer has a wrong word**. Supply one failing work address per offer. Default answers for malformed strings and out-of-range bit queries are fixed in advance. For definiteness the extractor is total, its header and counts are clocked and within the specified caps on every run; an implementation can clamp untrusted values. Statically bounded addresses, bit positions and clock counters take $O(\log N)$ bits whenever used in an affordable prefix.

On a positive input none of these negative endpoints can occur before the first true signal. On a negative input, select the earliest affordable time at which no offer is truthful, if any before a halt or overspend. Otherwise select the halt or overspend. A negative endpoint always exists because every instruction charges at least one unit. At all preceding executed times some truthful description exists, and the sum of their declared lengths plus one per step is at most $B$. The verifier never needs to prove that the endpoint is the *first* bad one. Earliest failure guarantees that cheap truthful descriptions exist for its earlier checkpoints.

Choose a time minimizing $1+s_t$ in each full disjoint internal window of $w$ instructions before this endpoint. Give its true controller, cumulative budget counter, and **one** actual complete honest description, copied into the chart. Include times, lengths and offsets. Consecutive cuts, including the initial state and terminal endpoint, differ by at most $2w+O(1)$ instructions. The whole chart occupies $(1+B/w)\operatorname{polylog} N$ bits. Its internal descriptions need not come with a proof of membership in the original list. A guessed ordinary string that decodes the right array supplies everything the verifier uses at that cut. Only the terminal failure claim depends on the actual offers.

An existential defect can choose one interval, replay the solver from its claimed controller, and check the ending controller and an arbitrary ending word against the next ordinary description in the chart. A segment begins with a read-only description and an empty private overlay for writes. A zero overwrite shadows the baseline like any other. Within the interval, obtain the true declared lengths for budget accounting by emulating the extractor, serving its real-memory queries from this overlay or the starting decoder. Stop replays crossing an earlier terminal halt or overspend and reject charts claiming any earlier positive signal. At the terminal endpoint eliminate these defects as well:

- For a claimed halt or overspend, faithfully recompute its required condition.
- For a bad-offer endpoint, check that it is affordable and pre-signal, and the supplied address directory covers the true number of offers. A defect chooses one offer whose alleged failing address does **not** witness an error.
- To test that address, replay the last interval, then run the decoder on the indicated *actual endpoint offer*. Supply each requested offer bit by running the extractor against the reconstructed endpoint memory. Compare the decoded word to that same reconstructed memory at the supplied address. This needs no copy of the terminal offer, even if it contains nearly $B$ bits. The only nested baseline decoder consults the starting checkpoint's already materialized ordinary bit string, so the number of levels of emulation is constant.

There is no terminal all-address comparison to a purported description of the bad state. The last trusted boundary and its overlay identify its full memory, including addresses never touched during the interval. Induction on boundaries now gives soundness for every passing chart, whether or not its internal rows were originally offered. On a true negative input the selected endpoint supplies all needed data. ## Charging an entire list of failing addresses only once

For a bounded nondeterministic source with horizon $R$, $m$ public words and $H=\max(2,R,m)$, apply the construction to the [ordinary locally readable bounded-computation formula](packed-band-transfer.md), of size $H^{1+o(1)}$. Each replay's genuine reads, including the extractor's and decoder's input reads, use that formula's local word generator. Guess the directory of failing addresses only for the terminal endpoint, outside all segment checks. Its length is $H^{\beta+o(1)}$ bits. The previously published induction certifies nonacceptance of a test in $(R^e+m^d+1)H^{o(1)}$ time, initially $e=d$ by the reference. For $w=\lceil H^x\rceil$, the defect test has work $H^{x+o(1)}$ and public input $(m+H^{c-x}+H^\beta+1)H^{o(1)}$. Only one terminal offer can be needed by a single defect challenge. The new work exponent is thus
$$
 \max\{xe,\ d(c-x),\ d\beta\}.
$$
For $x=cd/(e+d)$ the first two terms agree. Iterating $e\mapsto cde/(e+d)$ from $d$ crosses below one in finitely many steps when $d(c-1)<1$. The additional constant floor $d\beta<1$ preserves the first strict crossing. When $R=m^D$, $D>d$, the resulting nondeterministic nonacceptance check fits within the original clock, contradicting the signed self-input construction. All simulations have fixed depth; multiplying their fixed powers of logarithms and taking a small rational slack preserves the crossing. [Induction, diagonal and public-input accounting](cumulative-sat-memory.md)

A purely existential promise that some short string describes each positive state supplies no corresponding terminal test. Exhibiting an address that defeats one *chosen* string leaves all the other unlisted strings available. Exposing polynomially many locally extractable possibilities makes that failure test possible without assuming anything about the quality of the extractor's answers on negative inputs. Whether every hypothetical linear-time solver admits a cheap extractor of this kind on its hard positive instances remains unresolved. The theorem alone gives no elapsed-time exclusion.

## Affine decoders need no extractor for the coefficients

There is a case where the positive witnesses are fully nonuniform and need never exist anywhere inside the solver. Fix a polylogarithmic-time decoder. At each time, let its $s_t$ coefficient bits range over *all* strings in $\mathbb F_2^{s_t}$. Require that, for each word address and output bit, the decoded bit is affine in this string. The coefficients of the affine functions may depend arbitrarily on the formula, time, address and bit position, subject to the decoder time bound. The width bound $s_t$ is announced or uniformly retrievable as before, or simply fixed by the formula length. All clocked decoder outputs, including any default conventions, must obey the affine condition on every coefficient string. On positive runs the real memory lies in this affine image at every pre-signal time. Then $K=\sum_{t<E}(1+s_t)$ is outside $O(N^c)$ whenever $d(c-1)<1$. Taking $d=c$ gives the unconditional golden-ratio exponent with no further cap on the individual widths. There are $2^{s_t}$ candidate descriptions at a step.

At each induction stage choose $S=1+\lceil B/w\rceil$ for its own public budget and window size. Inspect unrepresentability **only at affordable states of width at most $S$**. On a negative, stop at the first such failure, or at halt or overspend if no such failure comes first. Before the endpoint, every full $w$-step window has total charge at most $B$. Its minimum width is therefore at most $B/w$, so that minimum-width state is among the ones guaranteed to have an honest representation. The sum of the selected costs is still at most $B/w$ by disjointness. A preceding wide state can have no representation at all on a negative input. Replay through it needs only its true physical reads and its announced width, not coefficients for that intermediate step.

At an unrepresentable terminal state of width at most $S$, every bit of the real array imposes an equation $a_i\cdot z=b_i$, where $b_i$ equals the true bit XOR the decoder's value at the zero string. The system is inconsistent, so $(0,1)$ belongs to the span of the augmented rows $(a_i,b_i)$. For example, row elimination gives the inconsistent equation $0=1$. A basis for the row space uses at most $s_t+1$ original rows. Thus there is a list of at most $s_t+1$ actual bit coordinates whose adjusted right sides sum to one and whose coefficient columns all sum to zero. The bound is attained by the $s_t$ conditions $z_i=0$ together with $\sum_i z_i=1$.

Guess that one list at the bad endpoint, recording both word address and bit offset. Replay the terminal interval once. An endpoint defect either detects the wrong parity of the $b_i$, using the same recovered memory for each listed coordinate, or chooses a single column $j$ with nonzero parity. The coefficient $a_{ij}$ is the XOR of the decoder outputs on the all-zero string and the $j$th unit vector. Both strings are virtual and answer indexed reads in constant time. Consequently a defect test reads only $O(1+s_t)$ coordinates after the replay. There is no factor of $w$ per coordinate. Guessing the list takes $(1+B/w)\operatorname{polylog}H$ bits. The local work is $(w+1+B/w)\operatorname{polylog}H$. Its additional work exponent $e(c-x)$ is already covered by the public-input term $d(c-x)$ since $e\le d$. Honest earlier cut strings can still be guessed outright. On positives the endpoint parity certificate is impossible by adding its equations. The same recurrence therefore proves the statement. [Exhaustive finite systems and tight supports](../audits/affine_snapshot_obstructions.py)

For a concrete consequence, suppose a sound signal arrives within $O(N^{6/5})$ on all satisfiable formulas. If every positive state belonged to an affine image with $\lceil N^{3/5}\rceil$ coefficients for the fixed fast decoder, then $c=9/5$ would bound the summed cost, and a time cutoff supplies $d=6/5$. But $d(c-1)=24/25<1$. Therefore arbitrarily large positive instances have at least one state outside that image. More generally a positive time bound $O(N^\tau)$ excludes a uniform such width $O(N^\gamma)$ when $\tau(\tau+\gamma-1)<1$, for $\tau\ge1$. This is a statement about the actual state of each solver and every fixed affine decoder; it supplies no upper bound on its elapsed time. Finding the true least usable width at each step is unnecessary for this peak-width consequence and remains unaddressed for a varying, unannounced width budget.

## Two adaptive advice-bit probes without linearity

The same positive cumulative bound applies to a decoder for which **each requested output bit reads at most two bits of the offered string**, with unrestricted adaptivity between them. It may read the original formula and perform other work for polylogarithmically many steps. A word can be assembled by separately querying its logarithmically many output bits, preserving the replay bound. The simulator charges individual bits of advice read, including those selected by previous answers. Two native word reads would be a different hypothesis.

Fix the truthful memory at a candidate bad endpoint of announced width $s$. For each memory bit, run the decoder on every possible path of at most two proposed advice answers. A leaf predicting the wrong memory bit forbids the conjunction of the advice literals on its path. This is a clause of width at most two; a constant wrong leaf gives an empty clause. Discard inconsistent paths, or keep their tautological clauses. A single $s$-bit offer represents the whole true memory exactly when it satisfies this implicitly specified 2-CNF. On a negative endpoint where every offer fails, this 2-CNF is unsatisfiable.

In the absence of an empty clause, its implication graph on $2s$ literals has paths from a literal to its complement and back. Indeed, a satisfying assignment is closed under implication. Conversely, when no strongly connected component contains complementary literals, assigning a literal true if its component appears later in a topological order than the component of its complement satisfies every implication: each edge also has its reversed complementary edge. Both paths can be simple, using at most $4s-2$ edges altogether. For each edge supply the actual output-bit coordinate and the at most two answers along one rejecting path witnessing the defining clause. A unit clause is doubled. A one-record certificate suffices for an empty clause, also covering the width-zero case. [Classical implication-graph criterion, Aspvall, Plass and Tarjan](https://doi.org/10.1016/0020-0190(79)90002-4)

Replay the last interval once, then verify the sequence of edges and their recovered clauses against this same endpoint memory. For each claimed path run the decoder with its specified responses to learn the actual advice positions and predicted output, and compare with the true bit at the supplied coordinate. Check edge directions, shared vertices and the complementary endpoints. The proof and the checking work after replay use $(1+s)\operatorname{polylog}N$ bits and steps. At the first affordable bad endpoint with $s\le 1+\lceil B/w\rceil$ these fit exactly the affine analysis above. There is no requirement that the solver know a description or the two implication paths. In particular the $N^{6/5}$-time versus $N^{3/5}$-width consequence holds for every fixed two-advice-bit decoder, as well as for affine decoders. [Finite failed-query and path lemmas](../lean/TwoBitSnapshotPaths.lean)

With three adaptive advice-bit probes, even the static membership question for a single all-zero target array encompasses ordinary explicit 3-CNF satisfiability. For clause position $i$, output one iff the three advice bits selected by that clause falsify it; output zero at other positions. The decoder consults the input formula for the signs and indices. The target array is representable iff the input is satisfiable. This identifies the additional content a generalization of this particular terminal certificate would require. Lee constructed minimally unsatisfiable 3-CNFs with $\Omega(s^3)$ clauses on $s$ variables. For these decoders, dropping even one corresponding target coordinate makes the remaining coordinates representable. Thus the three-probe case can actually require $\Omega(s^3)$ coordinates to witness inconsistency, although some instances may have a shorter proof using the whole formula. The affine argument can already read many advice bits, provided their contribution to each output bit is affine. [Lee, *On the Size of Minimal Unsatisfiable Formulas*](https://arxiv.org/abs/0811.0427)
