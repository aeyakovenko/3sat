# The minimum losing core when trials export their signals separately

There are two natural ways to encode the same deterministic winner on the canonical input. A single chronological computation needs at least $\Theta(2^j)$ distinct clauses to refute every wrong final rank, even a rank known to have retired at the first stage. Encoding the raw trials separately changes this conclusion. It gives short cores for ranks that retired earlier, while every still-unretired rank that loses needs $\Omega(2^{j-e})$ clauses for rank $e$, uniformly $\Omega(2^j/\log(j+4))$. The latter bound holds at a stage where an earlier rank wins, as well as at an empty stage. Both statements concern input clauses of specified formulas. ## Exact composition through a Boolean interface

Index the trials by $u$. The private CNF $T_u$ shares just its output bit $b_u$ with a scheduler. All private variable sets are disjoint. Each $T_u$ is satisfiable and forces its honest bit $x_u$. A scheduler CNF $G$ uses the output bits and its own auxiliaries. For **every** Boolean input table $b$, the scheduler has an extension, and its output in every extension is the specified $f(b)$. Write $D$ for $G$ together with a pin asserting an identified wrong output $e\ne f(x)$. Count clause occurrences. A core here is any unsatisfiable subset, and its minimum size refers to cardinality.

Let $w_u$ be the minimum number of clauses of $T_u$ that force $b_u=x_u$. For a set of indices $K$, let $\tau(K)$ be the minimum number of clauses of $D$ inconsistent with the units $b_u=x_u$ for $u\in K$, counting the units in this definition as free assumptions. Set $\tau(K)=\infty$ if the full $D$ is consistent with these units. The minimum core size of the entire pinned formula is exactly

$$
  \min_K \left(\sum_{u\in K}w_u+\tau(K)\right).
$$

For the lower bound, intersect a core with each $T_u$. Each intersection still extends at the honest bit. Its projection on $b_u$ is therefore either the honest singleton or both bits. Put the singleton indices in $K$. An assignment satisfying the retained outer clauses and agreeing with the honest bits on $K$ would extend independently through every retained trial. This contradicts the core. Thus the core pays at least the displayed inner and outer costs. Conversely, take optimal clause sets for those inner and outer choices. The inner clauses force all the assumed units, so their union is unsatisfiable. No bit has to have a unique *private* witness. With a multi-bit interface the same proof uses sets of allowed patterns; the actual set must be included and distinct private modules must still combine independently.

A certificate for loss is a set $K$ whose honest values exclude output $e$ on every completion. If $C$ is the minimum sum of $w_u$ over such certificates and $L$ is the minimum core size, it follows that $C\le L\le C+|D|$. This connects ordinary clause counts with the weighted certificate calculation previously made only for partial raw tables. Composition of Boolean certificate measures and the duality of cores and correction sets are established subjects. We make no priority claim for the composition identity. ## An ordinary formula for all trials and the greedy scheduler

At stage $i\le j$, rank $r<a_i$ gets $h_{i,r}=\lfloor 2^i/2^{r+1}\rfloor$ native interpreter ticks. In a private tableau simulate exactly those ticks, ignoring retirement and other ranks. A timed-out trial with no signal exports zero. Upon a signal enter a memory-silent absorbing state with flag one. A stopped nonsignaling trial has a silent absorbing state with flag zero. Include both as legal local states, irrespective of whether the given code reaches them. Equivalently, latch the two return values and read the flag at the deadline; put the interpreter deadline in the unrolling, so a spurious idle suffix is syntactically valid. Implement a tick by fixed program transitions or a constant-width schedule of such transitions at the native word width. One can compile the universal interpreter itself, with its program and public stage parameters fixed at initialization. The virtual zero-input reads return zero by a local rule. Thus the formula for one short trial need not allocate the stage's entire zero input. The honest initialization and every work-memory router belong to the respective trial. Any stage-wide tables used by native word simulation can instead use local polylogarithmic-cost Boolean templates for their fixed arithmetic operations. Use the final flag directly or via a separate equality. Every block has at least one disjoint local transition for each allotted tick.

The scheduler scans the columns, awarding the first active unretired one and retaining a bit for each award in its retirement mask. A bounded-fan-in circuit on $O(ja_j)$ such bits and the final rank equality has size $\operatorname{poly}(j)$ and a total Tseitin encoding. It must implement the schedule also on tables that do not arise from any genuine execution. The whole encoding has $O(2^j\operatorname{poly}(j))$ bits, since $\sum_{i\le j}\sum_{r<a_i} h_{i,r}=O(2^j)$. A clause index can be located by cumulative block sizes in a list of $O(ja_j)$ entries generated from $j$ in polynomial time in $j$; the local row and router templates then generate its literals. The canonical winner in this formula is identical at every stage to the original one. For a single private trial, a cut just before any one of its $h_{i,r}$ ticks can be spliced to a persistent return carrying either bit, keeping the true operation of that tick. Thus $w_{i,r}\ge h_{i,r}$, by the same matching of cuts to clauses as in the whole-run proof. All its clauses together cost $O((1+h_{i,r})\operatorname{poly}(i+1))$.

## A short interval of forced signals makes an identified rank win

Fix an active rank $e$ and a stage $j$ where $e$ is still unretired **before** the stage but loses. On the genuine schedule let $F(t)$ count the ranks less than $e$ unretired just before stage $t$. On the integer interval $[j-e,j]$, $F$ drops by zero or one at each step. The integer $t+F(t)$ consequently rises by zero or one, starts at most $j$, and ends at least $j$. Pick $t$ with $t+F(t)=j$. Force every active raw signal to one from $t$ through $j$. Preserve all genuine earlier stages. Suppose all ranks less than $e$ are active on this interval. The first $j-t$ stages then elect exactly the $F(t)$ remaining smaller ranks, one apiece. At $j$ the first unretired active rank is $e$ itself. This argument also covers $e=0$. For this construction it suffices that $e$ is active at $j$.

The activity condition holds uniformly at every sufficiently large jointly eligible $(e,j)$. Indeed $a_i=\lfloor\log_2(2+\lfloor\log_2(i+4)\rfloor)\rfloor$ and the increase to level $q$ first occurs at $i=2^{2^q-2}-4$ for all large $q$. The gap since the previous increase exceeds $q$, so $a_{j-a_j}\ge a_j-1$. Since $e\le a_j-1$, all ranks below it are present from $j-e$ onwards.

It suffices to turn on one bit per window stage. At stage $s$ choose the least still-pending rank $r$ among the lower ranks that were unretired at $t$, followed by $e$ at stage $j$. Keep all other true pulses. Every smaller rank has already retired and $r$ is active, so higher ranks' pulses are immaterial. After $r$, there are $j-s$ still to elect, all strictly between $r$ and $e$ inclusive. Therefore $j-s\le e-r$, or $s-r\ge j-e$. Every intended pulse has at least $\lfloor 2^{j-e-1}\rfloor$ ticks. A selected set of fewer clauses cannot force any of these modules to retain a true zero, so all chosen pulses can be realized simultaneously with disjoint private witnesses. The full scheduler then admits $e$, contradicting unsatisfiability. In particular

$$
 L_{j,e}\ \ge\ \lfloor 2^{j-e-1}\rfloor
    =\Omega\!\left(2^j/\log(j+4)\right).
$$

The first bound tracks the target's own native budget even when it was preempted. For example, when rank zero wins on an actual stage and rank one remains free, turning on rank one at that stage alone cannot change the winner. Spending one earlier award on rank zero can do so. Conversely, on a genuinely silent current trial, the whole current trial plus the scheduler suffices regardless of earlier retirements. Its size is $O((1+h_{j,e})\operatorname{poly}(j))$. Thus on silent, unretired targets the lower bound matches this direct upper bound within polynomial factors in $\log M$.

In ordinary encoded bits the distinction is sharper. By counting distinct clauses in a minimum core, dense renumbering still costs $\Omega(L_{j,e}\log L_{j,e})$ bits. Uniformly over the original active prefix, every as-yet-unretired losing pin therefore costs $\Omega(2^j j/\log(j+4))$ bits even in its shortest re-encoded unsatisfiable subformula. That already exceeds the $O(2^j)$ native time to compute the whole winner. [Explicit-record count](winner-tableau-cut-faults.md)

The proof also handles much faster releases. If active sets are prefixes with $a_{s+1}\le a_s+1$, then $a_s\ge a_j-(j-s)\ge e+1-(j-s)>r$ at the stage assigned to $r$. This follows from the same ordered-rank inequality, even if some pending ranks were inactive at $t$. Provided $e\le j$ and the window lies in the schedule, $a_j$ can grow linearly with $j$ and the bound still pays the target's *own* deadline, including its first day. For arbitrary stage- and rank-dependent budgets, the same route pays at least the minimum budget among the scheduled interventions. If those budgets vary too much for a uniform minimum, a counting consequence remains. Whenever the real scheduler elects nobody below an unretired $e$, changing just its current bit elects it. In the private encoding, a core smaller than that current trial's cost can therefore occur only on a stage won by an actual smaller rank. The winners at such stages are distinct. For an always-unretired pair $p,q$, at most $\max(p,q)$ stages admit a loss core smaller than the selected side's deadline. Even supplying the entire earlier history for free preserves this last implication.

One natural way to correlate trials preserves this bound up to a constant. For the two occurrences of a program requesting different colors, run its interpreter once per stage with a persistent signal latch and observe that latch at the two deadlines. Once the earlier deadline has signaled, the later deadline must report a signal. Arbitrary one-bit changes can therefore fail. To turn on an intended rank $r$ with the shorter deadline, splice before that deadline to a persistent one. Its twin may be turned on as well, but the twin then has smaller rank and is already retired. If $r$ has the longer deadline and is genuinely silent, splice after observing the shorter deadline and in time for the longer one. This keeps the earlier observation honest. The two deadlines differ by a factor of at least two whenever both are positive. Thus there are at least $h_{s,r}/2$ disjoint candidate cuts, even in this case. An already true intended pulse needs no change. If only one occurrence is active there is just one observation. Modules at different stages or for different program texts remain private. The window proof gives $L_{j,e}=\Omega(2^{j-e})$ again. This conclusion allows extra scheduler constraints complete on every raw table with the declared nested-deadline properties. Extra units computed from the actual word values can exclude these counterfactuals. For infinitely many never-retired ranks, a polynomial-time value analysis yields three-clause cores. ## Where a genuinely cheap losing core exists

If $e$ retires at a fixed stage $s$, include all private modules through $s$ and the entire scheduler and wrong pin at any later $j$. They force its retirement at $s$, which persists for all completions of later signals. Hence $L_{j,e}=O_e(1)+\operatorname{poly}(j)$. One can keep the early module variables and templates canonical across $j$, or regenerate their fixed-width data from their own scale. Together with the fixed-rank lower bound this gives an exact classification. For either fixed requested color, the indices $e$ whose late pinned losses have polynomial-in-$j$ cores are exactly the indices that ever retire. That set is computably enumerable and many-one complete for halting: encode a detector that signals on all sufficiently large scales if the supplied computation halts, and on none otherwise. Finitely many higher priorities can preempt it. The set tested is an *eventual* resource property of explicit finite CNFs. [Retirement completeness](pinned-retirement-cutoff.md)

For any fixed $0<\eta<1$, a core of $O(M^{1-\eta})$ clauses on a sufficiently large active stage therefore implies its pinned rank has already retired. Conversely every retired rank has such cores at all sufficiently large later stages. For a disjoint effective family of pair columns, each fixed pair eventually active, this means that even **one** such jointly active stage in infinitely many distinct columns is equivalent to actual retirements in infinitely many columns. Only finitely many columns can be active at any finite initial set of stages. In the stabilized-solver learner construction, the fast-SAT hypothesis precludes infinitely many such retirements when the learner uses this locally indexed formula. The identity exposes what would have to be proved to exploit this representation. The explicit upper bounds after retirement do not establish it.
