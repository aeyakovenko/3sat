# Can a delayed self-reference rule out a fast SAT solver?

**Research journal, 24 November 2026.** A sequence of larger explicit formulas gives a putative self-referential program room to finish. The difficulty is proving that their verdicts still agree with the first formula. The following test allows abstention, occasional wrong claims and unbounded time for constructing the formulas. It asks for a single excluded joint pattern on almost all tuples of auxiliary programs along some lengths. Obtaining such exclusions independently of the SAT lower bound remains open.

## A delayed bit and its partial predictions

Fix the exponent $d\in\{1,2,3\}$. A candidate $j$ specifies a deterministic RAM and an explicit clock $K(n+1)^d$ in the fixed model, with the encoded CNF bit length $n$. Define an ordinary computable search $R_j$ which halts on finding an explicit formula on which the candidate times out, gives a malformed answer, or disagrees with exhaustive truth assignment search. Enumerate every valid input and simulate finite clocks. The candidate passes exactly when $R_j$ never halts. All uniform big-O solvers are covered after enlarging $K$ on finitely many lengths.

Use an auxiliary universal machine $U(e,x)$ with Boolean outputs or divergence. A name $e=Hp$ consists of a self-delimiting literal program header $H$ followed by arbitrary raw data $p$. Malformed names may diverge. Run $U(e,e)$. If it halts with $b$ strictly before $R_j$ halts, call $1-b$ the **pinned bit** of $e$. Compare ordinary universal simulation step counts of the two computations and give ties to the refuter. These counts belong to the diagnostic construction, which may spend arbitrarily long verifying a native RAM cutoff.

There is a computable, acyclic system of local rules for these bits. For each $(j,e,t)$, assign zero if $R_j$ has halted by time $t$. Otherwise assign $1-b$ if $U(e,e)$ has halted by then, and copy the bit at $(j,e,t+1)$ in the remaining case. Unary $t$ makes the one dependency point to a longer description. When $R_j$ halts, every entry is determined by the first pin at or after its time. Waiting for the refutation computes all those entries. When $R_j$ runs forever, a computable solution on its slice would let a program $e$ return the proposed bit at $(j,e,0)$ on its own name. Its timely halt pins the opposite bit.

One solution has a uniformly computably enumerable set of one entries across all slices. From time $t$ wait for the first pin at or after $t$, enumerate the entry if that pin is one, and give a ray with no future pin value zero. Thus constant-size tentative root CNFs, initially contradictory and changed at most once to satisfiable, can have the *right limiting answers for every candidate*. This includes any correct candidate. Producing an ordinary final formula with a computable stopping rule would be a stronger construction.

## One excluded pattern, with errors

Fix an integer $m\ge1$ independent of the auxiliary name length $s$. A computably enumerable procedure may propose an excluded $m$-bit pattern on ordered tuples of distinct $s$-bit names. Use its first well-formed proposal on each tuple and record that proposal's enumeration stage $z$. Choose any total computable function $g(s,z)$ giving a grace period. Let $a_s$ be the fraction of all such tuples receiving no proposal. Let $b_s$ be the fraction receiving a proposal equal to the actual vector of pinned bits, with **every program halting strictly after $g(s,z)$ and strictly before the refuter**. All other proposals incur zero error. Both fractions have denominator $(2^s)_m$, where $(L)_m=L(L-1)\cdots(L-m+1)$.

**Criterion.** If $j$ passes, every such procedure satisfies $\liminf_{s\to\infty}(a_s+b_s)>0$. If $j$ fails, there is a procedure with $a_s=b_s=0$ at every eligible length. One procedure works simultaneously for every failed $j$, given $j$ as input. Thus a construction giving $\liminf(a_s+b_s)=0$ for every candidate would disprove the corresponding time bound. The successful lengths need not be recognizable and can depend on the candidate.

For the forward implication build a header $H$ containing the procedure and $j,m,g$. A program with this header receives its entire own name as input when computing $U(e,e)$. Parsing that input reveals $H$ and its total length $s$. All names in its cylinder of size $L=2^{s-|H|}$ therefore run precisely the same enumeration for that length. Put $C=(L)_m$, $k=2^m$, and wait for first proposals on at least $\lceil kC/(k+1)\rceil$ distinct internal tuples. Consider $L\ge m$.

* If this threshold is never reached, at least $C/(k+1)$ internal tuples abstain.
* On reaching it, freeze those $Q$ proposals. Exhaustively choose the lexicographically first vertex labeling $v\in\{0,1\}^L$ maximizing the number of matches. Independent uniform vertex bits match each prescribed pattern with probability $1/k$, since a tuple has distinct names. Some single labeling therefore matches at least $Q/k\ge C/(k+1)$ proposals, regardless of overlaps between tuples. Before returning the complement of its own label in $v$, each program performs more steps than the largest $g(s,z)$ among the frozen proposals. For example, it writes that many fresh tape symbols plus one. Since $j$ passes, all these late halts precede its refutation. Every match contributes one charged error.

Consequently at every sufficiently large $s$,

$$
a_s+b_s\ \ge\ \frac{(2^{s-|H|})_m}{(2^s)_m(2^m+1)}
\ \longrightarrow\ \frac{2^{-m|H|}}{2^m+1}.
$$

For the converse, wait until $R_j$ halts at $r$. Simulate all queried names through step $r$. If all are timely, exclude a vector obtained by flipping their first pinned bit. If any pin is missing, every vector is permissible. The native SAT cutoff gives no deadline for this exhaustive search.

Bienvenu, Desfontaines and Shen's theorem 7.1 already gives a positive lower density of errors or undefined answers in separating the zero and one outputs of an effectively optimal machine on words of length at most $s$. The calculation here concerns jointly excluded patterns on overlapping tuples of names of exactly the same length, with timing relative to the search for a wrong SAT verdict. The auxiliary machine uses a literal prefix so a fixed header occupies a constant fraction at each length. No priority claim is made for the joint variant. [Bienvenu, Desfontaines and Shen, theorem 7.1](https://lmcs.episciences.org/1633/pdf)

### Errors concentrated at a single time

One can fix an ordinary auxiliary universal multitape machine for which the same bound holds even on replacing $b_s$ by $\sup_h b_s(h)$. Here $b_s(h)$ charges a wrong proposal only if all its names halt at precisely the same reference-machine step $h$, with $g(s,z)<h$ and the refuter still running at $h$. This variant could use a bound on the largest single-time fraction even when summing the wrong proposals over all times gives substantial mass.

Keep a mode for ordinary universal simulation and reserve a second mode with a header $H$ specifying a table-generating program. On a name $Hp$, the second mode saves the raw $r$-bit address $p$ and determines $r$ by an equal-time scan on either bit value. It simulates the generator on clean tapes with just $H,r$ available. If the generator returns a $2^r$-bit table, read position $p$ in time independent of the contents of $p$. For example, process the address from low bit to high bit. On each pass scan the entire current table in adjacent pairs and write the selected entry of each pair to the next tape. The finite control reads both symbols, writes one symbol and moves the heads on the same schedule for both choices. Tape rewinds depend only on the table length. All names in this mode with a common header and common length therefore halt at the identical reference-machine step whenever that generator returns a valid table.

Install the preceding freeze, optimization and waiting algorithm as such a generator. Its table contains the complements of the selected labels in address order. The first branch still yields at least $C/(k+1)$ abstentions. In the second branch, at least $C/(k+1)$ wrong proposals now have every component halt at the very same $h$ for the entire length. This proves the peak bound. The converse uses the same search for the refutation. Equal-time readout is a choice of the auxiliary program encoding only. The candidate SAT solver and its native RAM clock retain the original model.

A change of the auxiliary interpreter can erase the peak completely while preserving every eventual output. On diagonal inputs $U'(e,e)$ of length $s$, run an identical deterministic dovetail of $U(a,a)$ over all $s$-bit $a$. Present discovered halts one at a time in a common order. Compare each announced name to the saved $e$ by a full fixed-schedule $s$-bit comparison and terminate exactly on the matching announcement. Every surviving name stays synchronized from one announcement to the next, and each announcement releases at most one name. An initial equal-time scan recognizes diagonal inputs. On other inputs the machine can just simulate $U(e,x)$. Thus even for a passing candidate every peak in this new diagonal convention has at most one singleton and no tuple with two distinct coordinates. Consequently the peak criterion must use the specified reference machine with table readout.

## What can generate an exclusion?

One sufficient format would be an effective procedure emitting ordinary CNFs $G_{j,E,w}$ on a tuple $E$ and proposed pattern $w$. Dovetail the constructions and truth-table checks, taking the first satisfiable formula as an exclusion. The criterion concerns coverage and the errors of those first exclusions. It places no bound on formula length or construction time. A correct proof that some claim is produced and that the joint density of abstentions and actual errors tends to zero on a subsequence would suffice. Writing a bounded simulation through a chosen deadline supplies no such proof. Padding a root formula preserves its verdict, but replacing the final padded formula by a tableau for the opposite terminal bit still requires the missing equivalence at that step.

The fixed arity matters. Reserve any constant header of density $\delta>0$ whose programs always return zero. Exclude the all-zero vector on every tuple containing such a name. Whenever all pins exist, that position is pinned to one. This procedure makes no errors for any candidate. For $m=m(s)\to\infty$ and $m\le2^s$, the chance a uniformly sampled distinct tuple misses that header is at most $(1-\delta)^m\to0$ for large $s$. Allowing the arity to grow would therefore give spurious evidence even if a correct solver existed.

The explicit formulas already obtainable here describe bounded tests of the individual relay rules. The criterion requires a claim about the *joint eventual pins* of actual programs and the actual candidate refutation time. I found no SAT-specific production of such claims meeting the density estimate. Lean checks the finite simultaneous-labeling bound for arbitrary overlapping coordinate patterns.
