# Reading a named exclusion from a guaranteed two-date disjunction

A pair of SAT queries can have a known true disjunction while a proof that identifies a true member faces a sharp query bound. We constructed an ordinary width-three CNF version whose zero-mask inputs ask about the actual consecutive winners. The lower bounds allow arbitrary prover messages and adaptive probes in the models specified below. The matching verification protocols show which savings alternation can deliver for the input mask itself.

## A physical family of questions about two genuine dates

Fix a stage $i$ of the [dense native construction](density-of-certified-winner-pairs.md). In its actual deterministic run, encode the ordered pair of winner ranks at $i,i+1$ if both words are zero and both winners are distinct earlier pool members. Encode every other case by a separate public sentinel. Call this $r$-bit result $w_i$. Choose a uniform $r=O(\log(i+2))$ sufficient for rank pairs, tags and sentinel. Only names for distinct legal pair events need be used in the menus. The genuine records and modes can be extracted from the native computation and the extended terminal comparison uses polynomial-in-$i$ circuitry.

Use $\lambda\ge1$ copies of every nonzero column $v$ of $\mathbb F_2^r$. Put a separate input pin $x_{t,v}$ at each of $N=\lambda(2^r-1)$ positions. Let

$$
             Y=w_i+\sum_{t,v} x_{t,v}v,\qquad D=\lambda 2^{r-1}.
$$

For a name $a$, the ordinary 3-CNF asks whether $Y\ne a$. Use the parsimonious [native deterministic tableau](projected-parity-holes.md#a-parsimonious-ordinary-3-cnf-near-the-native-clock), a unit fixing each mask bit by its literal sign, and exact acyclic Tseitin gates for the sum and the inequality. Repetition pads shorter clauses. Each true pin has a unique full solution when the native tableau and unused fields are canonical. At $x=0$ these are genuine individual event exclusions. At other masks the question is translated by the specified syndrome. For any two distinct names the disjunction is true on all common masks. The guarantee is for the published shared template; arbitrary pairs of unrelated physical formulas have no such promise.

The mask circuit has $O(N)$ Boolean gates. XOR the copies of each column first. For one label coordinate, pair the accumulated values whose labels differ in that coordinate, taking zero for a missing zero column. Their XORs are the new table for the remaining coordinates; the XOR of the high half is the requested coordinate of the syndrome. Recurse on the half-sized table. The total gate count over these folds is bounded by a geometric series. With $G$ native gates the whole encoding uses $O((G+N)\log(G+N+2))$ bits. Only the designated pin signs depend on $x$. In the fixed-width literal encoding a logarithmic RAM word intersects only a constant number of different mask pins. Thus a source bound in mask-bit probes transfers up to a constant to probes of physical formula words, even with a constant number of formulas sharing that mask. A RAM can compute the mask sum by accumulating a word of $r$ bits in one pass when $r$ fits a word. It can combine this with an ordinary full replay of the native computation. For clarity the following exact probe counts use individual mask bits and give the full $w_i$ away. Obtaining that native information on the required clock remains a separate issue.

## Disjoint repairs and how many names become provable at once

For any $d\ne0$, use one pivot coordinate on which $d$ is one. In each copy the singleton column $d$ and the unordered pairs $\{v,v+d\}$ on the remaining nonzero columns partition the positions into $2^{r-1}$ blocks. The sum on each block of *column labels* is $d$. Flipping all input bits in any block shifts $Y$ by $d$ on **any** starting mask. This gives $D$ disjoint repairs to any other specified value, including on a zero mask. Toggling an arbitrary collection shifts the result by $d$ precisely for an odd number of toggles. [Lean proof of the partition, count and parity identity](../lean/PairedSyndromeMenu.lean)

Every deterministic transcript fixes some mask bits. Its possible outputs form a translate of the span of the unread columns. The same observation applies to a fixed accepted nondeterministic certificate path whose conclusions must be sound for every input on that transcript. To exclude at least $m$ names out of the entire $Q=2^r$-element alphabet, put $j=\lfloor\log_2(Q-m)\rfloor$, $1\le m<Q$. The exact minimum number of probes is

$$
                    \lambda(Q-2^j).
$$

Indeed the unread columns must span dimension at most $j$, hence can occupy at most $\lambda(2^j-1)$ positions. Conversely fix a $j$-dimensional subspace and read all columns outside it. The resulting affine coset of possible values has exactly $2^j$ points. In particular $D$ probes suffice for $Q/2$ separate exclusions, and, for $r\ge2$, $3\lambda Q/4$ probes are necessary for $Q/2+1$. This count uses the entire mathematical alphabet. A specified set of legal pair labels can have different geometry. For **two** specified distinct names $a,b$, some true member can always be named in $D$ probes by evaluating $u\cdot Y$ for one public $u$ with $u\cdot(a+b)=1$. Its support has size $D$. Every no-error accepted assertion excluding a particular name on any true input needs at least $D$ probes: it must meet every disjoint repair making that assertion false.

## Statistical soundness when the name itself can depend on the conversation

Take $K$ distinct named candidates, $2\le K<Q$. On a mask whose $Y$ is outside the menu, suppose an honest strategy achieves probability at least $\gamma$ of returning some name. On every mask for which $Y$ is a menu name, require every cheating strategy to return the **wrong exclusion** naming that value with probability at most $\alpha$. Abstention is permitted. The verifier can use private or public coins, ask adaptive questions and receive arbitrary interactive replies. Its only access to the mask is through its charged probes. At *every* all-true mask with the stated completeness there,

$$
                 \mathbb E[\#\mathrm{probes}]\;\ge\;
                       D\,(\gamma-K\alpha)_+ .
$$

Fix that input $x$ and the honest strategy. On a repaired input a cheating prover can imitate the same strategy, including its private random choices and its dependence on the messages it sees. Couple all coins. Until the verifier probes a changed mask position the interactions coincide. For a specific name $a$ let $p_a$ be its honest output probability. For each of the $D$ disjoint repairs to $Y=a$, the probability of naming $a$ **and touching that repair** on the original run is at least $p_a-\alpha$. On each run naming $a$, at most the number of distinct probes many repairs were touched. Sum over the disjoint output-name events to get the stronger lower bound $D\sum_a(p_a-\alpha)_+$. There is no union over possible dishonest transcripts. This uses the sensitive-block idea underlying randomized certificate complexity. [Aaronson](https://arxiv.org/abs/quant-ph/0210020)

The expected bound is exact. With probability $\min(\gamma,K\alpha)$ return a uniformly sampled name blindly. With probability $(\gamma-K\alpha)_+$ run the exact two-name scan, and otherwise abstain. On all-true inputs its naming probability is $\gamma$ and on any input the false-name probability is at most $\alpha$.

With a **worst-case** cap of $b\le D$ probes and $\gamma=1$, the exact smallest soundness error is $(1-b/D)/K$ when proof length and work outside the probes are unrestricted. Sample a uniform public name $a$. Before the verifier selects sample locations, the prover commits to $u\ne0$ and to claimed values on the $D$ columns with $u\cdot v=1$, having parity different from $u\cdot(a+w_i)$. Inspect $b$ uniformly sampled distinct positions from this support, compare to the committed values, and output $a$ if all checks pass. A false named exclusion forces at least one discrepancy for **every** $u$ and commitment. A true name always has an honest separating $u$. At $b=0$ one can simply output the random name. When $1\le b\mid D$, replace the long commitment by $D/b$ asserted block parities and read one uniform entire block of size $b$, keeping the very same error bound. Choose a pivot of $u$ to enumerate the support by its $r-1$ other label bits and its copy index, so obtaining one block costs $O(b\operatorname{poly}(r,\log N))$ bit work and requires no full scan. This last version costs $O(b+D/b+r)$ probes plus communicated bits in the idealized model. Completeness one refers to returning a name at all-true inputs. The prover commits before the fresh inspection randomness. The positive gap over blind naming can be tiny even on actual zero-mask positive stages.

## Exact public-challenge complexity of selecting between two names

Fix distinct legal $a,b$. A separate exact public challenge test is indexed by the name $c\in\{a,b\}$. For eligibility of a name require **every** public $R$-bit challenge to admit a reply passing a deterministic matrix using at most $q$ mask probes. The matrix may read an arbitrary reply and may probe adaptively. A false name must never be eligible. Every mask must have at least one eligible name. A name is fixed *before* this universal test, so a prover cannot switch the asserted name from one challenge to the next. For $1\le q\le D$ the minimum possible $R$ is exactly

$$
                         \left\lceil D/q\right\rceil-1 .
$$

Choose a mask with $Y=a$ (all values are possible) and let $d=a+b$. Use an independent Boolean variable on each of its $D$ repair blocks: either flip that whole block or keep it. On the resulting cube the value is $a$ at even parity and $b$ at odd parity; all physical probes to variable bits depend on at most one block variable each, possibly complemented. There is only one legitimate name on each input of this cube. Consequently eligibility for the name $a$ computes exact parity there. For a fixed public challenge, a successful reply and its adaptive read path give a term of at most $q$ literals on this cube. Taking their union represents passability as a width-$q$ DNF even if replies are extremely long. Its rejection set is width-$q$ CNF. It contains inputs of only the wrong parity, so every satisfying assignment is isolated. The satisfiability coding lemma bounds its size by $2^{D-D/q}$. The $2^R$ challenges together must cover all $2^{D-1}$ wrong-parity points. Integral rounding yields the bound. At $q=0$ exact two-name selection is impossible. The parity covering argument is classical. [Paturi, Pudlák and Zane](https://cseweb.ucsd.edu/~paturi/myPapers/pubs/PaturiPudlakZane_1999_cjtcs.pdf)

For the matching upper bound use the fixed separating $u$ from the deterministic test. For name $c$ prove that the parity on its $D$ supported mask positions equals $1+u\cdot(c+w_i)$. Make $L=\lceil D/q\rceil$ blocks of at most $q$ supported bits. Each $L-1$-bit public challenge specifies all block parities of the *opposite* total, filling in the last bit. A reply names one block on which the challenge is wrong; read that block and check. Every challenge can be answered for the correct total. For an incorrect total the true block-parity vector supplies an unanswerable challenge. The two target totals for $a,b$ differ, hence a true name is always established. Only $\lceil\log_2 L\rceil$ reply bits are needed. This gives deterministic $O(\sqrt D\operatorname{polylog}(N+2))$ work **per alternating branch** at balanced sizes. A randomized spot-check with constant rejection gap cannot get that probe bound at perfect all-true naming completeness when the allowed false-name error stays a fixed fraction below the blind $1/K$ rate.

With $l\ge1$ fixed alternating blocks, each of bounded bit length, the optimal worst-case total of message bits and source-bit probes for exact two-name selection is $\Theta_l(D^{1/l})$ for the idealized query model with $w_i$ supplied. To lower bound it, fix the name and restrict to the same forced parity cube. Unroll all bounded messages, and express each deterministic terminal probe tree as either a DNF or a CNF of size $2^{O(q)}$, choosing its outer connective to merge with the innermost quantifier. This gives an unbounded-fan-in circuit of depth at most $l+1$ and size $2^{O_l(B+1)}$ for total bit-and-probe budget $B$. For variable-length messages, fixed-width padded blocks with validity guards cost at most a constant factor for fixed $l$. The parity lower bound gives $B=\Omega_l(D^{1/l})$. For $l=1$ the elementary DNF/CNF parity bound gives the same estimate. [Håstad](https://www.csc.kth.se/~johanh/paritycorr.pdf)

For the upper, group the support into a tree of fan-in $d_0=\lceil D^{1/l}\rceil$ and height $l$, padding unused leaves with known zeros. In the first $l-1$ moves a player defending a specified parity supplies the child parities consistent with it. Except on the first move, this player first chooses a child of the previous node whose claim it challenges, and defends the opposite parity there. The final player challenges one child and the matrix compares its proposed parity with a direct scan of its at most $d_0$ leaf bits. Invalid claims by a particular player lose for that player. Truthful play for the correct side and the existence of a false child of every wrong-total vector prove the game by induction. For $l=1$ directly scan, and for the opposite initial polarity complement the test for the opposite parity. Index and padding work in a bit RAM implementation adds polynomial factors in $r,\log N$, which the ideal source-bit probe model does not count.

Taking $D$ of order the native clock $M=2^i$ shows exactly where a proposed proof breaks. A per-branch clock $M^{1/k^l-\epsilon}$ cannot support a uniform exact two-name protocol **on all physical masks** for $k=2,3$, even with the authentic native offset supplied: $k^l>l$. For $k=1$, extra alternation does accelerate the mask computation. The original task allows a verifier to exploit the genuine zero mask or a locally generated layout and only needs its coverage on qualifying starts. Here the forced parity cube includes other ordinary SAT inputs, and the cheap verifier for the mask assumes access to the projection of the native winner. I have no procedure that authenticates that projection at the required time on the unmodified hard starts. The staircase, game and test scopes are checked on finite instances in the [audit](../audits/masked_two_winner_queries_audit.py). Priority for their combination with actual native pins is unverified.
