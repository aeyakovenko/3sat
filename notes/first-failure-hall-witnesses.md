# What every Hall witness at the first failed SAT instance discloses

**Research journal, 24 November 2026.** In the unconditional short list, let $j$ be the first unsatisfiable index. The previous gap concerned the cost of certifying that no program outside a proposed Hall set offers on its rows. There is an obstruction on the *actual* deficient prefix, simultaneously for all possible choices of Hall witness. Every witness contains the answers to all bounded acceptance tests implemented by programs that ignore their row. The last satisfiable prefix carries identical answers in every complete matching. A second, smaller copy of the list supplies an entire column of true nonoffers for which even one row cannot have a cheap, sound proof. No fast-SAT assumption enters these statements. [Original list and RAM conventions](first-missing-certificate-level.md)

## Tightness and the neighboring positive instance

A column is an admitted program and $A(h,e)$ means it can signal UNSAT on the actual $F_h$ in its guest clock $M$. Fix a matching of rows $0,\ldots,j-1$. In any deficient Hall pair $(S,T)$ on rows at most $j$, we have $N(S)\subseteq T$ and $|T|<|S|$, where $N(S)$ is the set of programs with at least one offer on $S$. If $j\notin S$, the matching injects all of $S$ into $N(S)$, which is impossible. Otherwise it injects $|S|-1$ elements. Hence
$$j\in S,\qquad |T|=|N(S)|=|S|-1,\qquad T=N(S).$$
This applies even to nonminimal Hall pairs. If a code offers on every row when a bit is one and on no row when it is zero, membership in $T$ returns the bit. A matching on all earlier rows must use this code in the one case: leaving it unused would let the matching extend to $j$. It cannot use it in the zero case. The earlier matching alone therefore gives the same answers using only positive offer computations. There is an unconditional always-offering code in the growing pool, so $j>0$ at all sufficiently large scales. [Lean proof](../lean/HallProbeColumns.lean) · [Finite audit](../audits/hall_probe_audit.py) · [Hall's representative theorem](https://doi.org/10.1112/jlms/s1-10.37.26)

More generally, given the true cutoff as $\ell+1$ advice bits, one nondeterministic computation can certify **all** answers of these probes by guessing one complete earlier matching with its witnesses. This costs $O(PM\operatorname{polylog}H)$ in the direct simulation for a pool of $P$ codes. It requires no proof of absence of a missing edge. The advice depends on the scale and on any parameters fixed for the whole graph. If the free input changes the graph, the same advice need not serve the new input. This is the reason a census of the matched columns does not give a fast uniform rejection algorithm. The positive-edge cost is sharp in a black-box certificate model. Give each of the $j$ earlier rows a private column and make a probe column silent. If a purported certificate omits the private edge of row $h$, erase that edge and let the probe offer on every row. The prefix still first fails at $j$: it has a matching of its $j$ earlier rows using the probe on $h$, and only $j$ nonempty columns. All the disclosed edges agree in the two graphs, while the probe's bit differs. This argument does not limit a checker exploiting program semantics.

## A common hard cell inside every actual rectangle

Take the scale parameter $m$ publicly available. Use an inner copy of the original construction at horizon $G=m$ with $L=\lceil\log_2(m+2)\rceil$, pool cutoff $\ell_i=\lfloor\log_2 L\rfloor$ and offer budget $M_i=\lfloor m/L^{K_i}\rfloor$ for a suitable fixed $K_i$. Use an outer copy with horizon $H=m L^B$, a pool cutoff $\ell_o=\ell_i+C$, and budget $M_o=\lfloor H/L^{K_o}\rfloor$. The two checker texts and all constants are fixed. Enlarging $C$ accommodates a fixed compiler prefix and a literal index of $\ell_i+1$ bits. Choose $K_o$ for the ordinary outer source, then $B$ large enough to let an outer guest simulate $G$ bounded inner-source steps with its fixed polylogarithmic overhead. Replacing $\log H$ by $L$ changes these costs by constant factors at large scales. Both lists use uniform zero padding and locally computed formula words as before. Both formula lengths $N_i,N_o$ are $m$ times fixed powers of $L$ up to constants.

In the outer pool include, through the ordinary program encoding, a code $p_a$ for each inner list index $a$. It ignores its outer formula and row, simulates the fixed inner bounded source on $(m,a)$ nondeterministically, and offers iff the simulation accepts in its own prescribed horizon. It fits in $M_o$ for every branch. This is a syntactic simulation of acceptance, with no nonacceptance oracle. At the actual outer first failure, every Hall $T$ and every earlier complete matching include $p_a$ exactly when inner $F_a$ is satisfiable. Thus they contain the *whole* inner cutoff, even if other outer programs react arbitrarily to the formula being tested.

Let $a_*$ be the inner first unsatisfiable index. All cells of the outer column $p_{a_*}$ are genuinely empty, and this column is outside every authentic Hall $T$. Fix any verifier $V$ sound for empty-cell claims on the generated outer family: a passing computation on $(m,h,e)$ implies the absence of a timely offer by $e$ at row $h$. Given the public inner index $a$, a fixed nondeterministic inner certifier guesses any outer row $h$ and uses $V$ to certify the emptiness of $(h,p_a)$. An inner positive formula makes $p_a$ offer on all rows, so this is a sound inner UNSAT certifier on every inner index. The wrapper checks the guessed row against $0,\ldots,P_o$ and the probe code against the admitted pool before calling the verifier. The row need not be certified as the failed row. Its formula and the outer verifier's random input reads are generated from the short parameters. Thus at all sufficiently large scales **no row of the column $p_{a_*}$ admits such a certificate in $N_o/\log^{D_V}N_o$ steps**, for a sufficiently large fixed $D_V$. Otherwise the wrapper would fit the inner budget $M_i$ and certify the actual inner failure. The column and the outer formulas are independent of $V$; the inclusion threshold and logarithmic overhead may depend on $V$.

The same argument excludes a short proof of *any entire actual Hall rectangle*. Here $V$ must be sound for declaring a nonempty rectangle empty. The inner certifier guesses $S,T$ and a claimed prefix, demands $S\ne\varnothing$, $p_a\notin T$, and validates emptiness of $S\times(\mathcal P\setminus T)$. It supports a sound UNSAT claim even when the guesses do not describe the first failure. Completeness for the claimed cheap proof at $a_*$ follows from exactness on the real first failure. Require fixed-length masks within the actual row and column domains and check any claimed prefix is in range. All masks have $O(\log m)$ bits. Checkers may provide these fields and the outer cutoff to $V$ as untrusted inputs; a system whose soundness presupposes an authentic cutoff needs a separate check or genuine advice. These distinctions matter because a verifier promised in advance that a rectangle is empty could simply say yes.

## A direct argument and a robust version

One can get a different bound for each fixed rectangle verifier on a single original list, without a smaller inner scale. Use a fixed prefix of the interpreter's binary program encoding to generate a block $D$ of identical programs with arbitrary ignored literal suffixes. In the externally delimited convention $|D|\ge c_V P$ at sufficiently large scales for a constant $c_V>0$. The code knows this block: equivalently use a fixed universal template that reads its finite template text and verifier as initial data, constructs their compiled prefix, and ignores the remaining suffix. This is standard program self-reference with fixed text; computing the range of codes in the block and counting them in a supplied mask costs $O(P\operatorname{polylog}H)$.

Say a proposed $S,T$ misses at most $u$ neighbors if $|N(S)\setminus T|\le u$. Suppose $V$ is sound for this assertion on any nonempty claimed $S$. Each code in $D$ ignores its actual row and runs the same nondeterministic test: guess a nonempty $S$, $T$, $u$ and a timely successful verification by $V$ for this list, with $|D\setminus T|>u$. Charge the fields, the simulated verifier and virtual formula access to the guest clock $M$. Give all copies the same clocked test on the same public scale, ignoring their payloads. Their signal is identical on every row. If such a verification exists, all copies offer on all rows. Then the accepted assertion is false since all the omitted copies are neighbors. By soundness, the copies are silent and no such verification exists.

At the actual first failure, for any nonempty row subset in the prefix we have $|N(S)|\ge|S|-1$. Suppose $|T|\le|S|-1+q$. If it misses at most $u$ true neighbors, then it includes at most $q+u$ spurious columns. Since the copies are silent, $|D\setminus T|\ge |D|-q-u$. Whenever $q+2u<|D|$, every such pair therefore lacks a proof of its error bound checkable by $V$ within $M/\operatorname{polylog}H$, choosing sufficient overhead for the fixed program. This includes every exact Hall witness with $q=u=0$. It also applies when the tested errors and allowed slack are a sufficiently small constant fraction of all codes. The block here depends on the validator; the inner-list construction gives a common column for all fixed validators. A standard length-delimited compiler can reserve a prefix for this procedure while still representing all finite guest programs. No particular opcode numbering is necessary.

There is a purely combinatorial precision limit. For $d$ duplicate columns that are simultaneously everywhere or nowhere, a deficient-prefix report with the above $q,u$ has at least $d-u$ copies in $T$ in the first case, and at most $q+u$ in the second. They are distinguishable when $d>q+2u$. This is sharp from these promises alone. At equality take two blocks $A,B$ of $d$ columns and $d+1$ identical rows. Give every row only $A$ in the first graph, only $B$ in the second. Both first fail with all $d+1$ rows. The same reported $T$ containing $d-u$ columns from each block has size $d+q$ and misses exactly $u$ neighbors in either graph. For approximate matchings there is a parallel one-sided rule. A matching within $v$ edges of the optimum $j$ in that prefix leaves at most $v$ everywhere-offering columns unused. Otherwise $v+1$ free columns and enough unmatched rows extend it to more than $j$. A nowhere-offering column is always unused. For a $d$-fold probe, $d>v$ suffices to decode it from the used set.

## Exposing the same hard bits on the positive side

With the standard $P=\Theta(\log H)$ pool, reserve a length-delimited compiler prefix for an everywhere-or-nowhere probe with $b$ payload bits. At scale $H$ take $b=\lfloor\log_2\log_2 H\rfloor-c$ and $Q=2^b=\Theta(\log H)$, with a sufficiently large fixed $c$. The probe for index $v$ computes a deterministic $Q$-bit table and offers iff bit $v$ is one. The computation may depend on $H$ and must finish within $M$. Then on the first negative instance every authentic Hall neighborhood contains this table on a fixed prefix-and-payload slice of its addresses. On the preceding positive instance the **used-code bitmap of every successful chain** contains exactly the same table.

Here is an unconditional choice of table. Fix $0<\epsilon<1$ rational. List the $Q$-bit tables produced by deterministic programs of length at most $\lfloor Q/8\rfloor$ when given $H$, a bit index in $[Q]$, and *any one* of the $P+1$ list indices as an extra public parameter. Use a fixed normalized interpreter clock of $\lfloor H^{1-\epsilon}\rfloor$ steps per bit, with a fixed default if it times out. The program may contain both an evaluator and input-specific advice in the length-delimited coding. Include also all $b$-input bounded-fan-in circuits with at most $\kappa Q/\log Q$ gates for a sufficiently small absolute $\kappa>0$. There are fewer than $2^{Q/4}$ candidate tables at large $H$: a circuit is encoded in $O(s\log(s+b))$ bits, and the multiplier $P+1$ for the first enumeration is polynomial in $Q$. Each Hamming ball of radius $\lfloor Q/10\rfloor$ contains at most $2^{H_2(1/10)Q}$ words, where $H_2(1/10)<1/2$. Take the lexicographically first table outside their union. Exhaustive simulation costs $2^{Q/8}H^{1-\epsilon}\operatorname{polylog}H$ including all public indices; checking all possible tables against the list costs at most $2^{5Q/4}\operatorname{polylog}H$. Choose $c$ large enough, depending on $\epsilon$, to make both $o(M)$. Thus the probe really does compute its own selected bit within the outer clock. The construction is deliberately on $\Theta(\log H)$-bit tables, so this exhaustive step fits before the SAT formula is formed. [Circuit enumeration and hard truth tables](https://www2.cs.sfu.ca/~kabanets/papers/mincircuit.pdf)

Consequently both bitmaps resist approximation within $Q/10$ errors on these $Q$ addresses by circuits of size $\kappa Q/\log Q$ or by the indicated time-bounded short descriptions, even giving the actual neighboring list index for free. For literal SAT-assignment bits use a fixed variant of the list: add one public-to-the-source existential guess array $y$ of $P$ bits, check at the end of each successful chain that it equals the used-code flags, and expose its bits as designated variables in an aligned, contiguous range of the Cook formula. The $P$ guesses and comparisons fit well within $H$. For free wiring of the address restriction, use a variable-area base divisible by a power of two larger than the full padded flag array. Within it reserve offset zero and use offset $2^{|e|}+\mathrm{val}(e)$ for a code $e$, padding unused slots. A literal suffix then occupies the low address bits without any addition or carry. Guesses are made *inside* the bounded acceptance relation and tied to these variables, with the same layouts on every row. Alternatively use existential input pins wired to a read-only array and perform the same final check. Recompute all offers for this variant; every earlier argument works on its own actual formulas. On the last positive formula every satisfying assignment agrees on the designated $Q$ bits. Restricting an assignment lookup circuit's variable-index input to the aligned prefix and the probe payload costs only fixed wires. Reading the virtual formula in a time-bounded predictor can likewise be simulated from $H$ and the public list index with a polylogarithmic loss; use a smaller exponent margin when transferring it to the normalized clock. These are mandatory bits of *positive witnesses*. A pure decision algorithm need not output them or a Hall pair on rejection. [Related easy-witness results and their hypotheses](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf)

## Clock saved by batching, and the remaining loss

Under deterministic $O(N\log^a N)$ SAT, the source can check a long proposed matching without spending $M$ steps on every row in sequence. Guess its array of $O(P\log P)$ bits, check distinctness, then search for a row whose chosen code has **no** timely offer. For a fixed row, offer existence is an ordinary bounded-computation SAT query, including the actual program simulation and virtual formula reads. Its deterministic cost is $M\operatorname{polylog}H$ for short formula parameters. The bad-row test guesses a row, reads its assigned code from the already fixed array, and runs this solver. A second SAT call on the bounded bad-row computation determines whether any row fails. The public array is charged at this outer call. The combined work for a guessed matching is $(P+M)\operatorname{polylog}H$. This version uses a different fixed source, whose syntax the candidates also read. Its list still realizes exactly the matching predicate. One may take *both* $P$ and $M$ of order $H$ divided by sufficiently large fixed powers of $\log H$. Previously the unconditional direct source needed $PM\operatorname{polylog}H\le H$. Two calls here mean two nested decision levels, including the cost of materializing the inner bounded computation, rather than one SAT query per row. [Packed reduction](packed-band-transfer.md)

For such a larger pool the protected probe slice can hold many more than logarithmically many hard bits. Take $Q=2^b$ of order $H/\log^J H$ with $J$ larger than both the pool and time overhead exponents (choose the pool at least a fixed factor larger than $Q$). The lexicographically first $Q$-bit table more than $Q/10$ bits from all circuits of $\kappa Q/\log Q$ gates has a bit test by a constant number of alternating bounded-quantifier blocks. For a fixed table and circuit, more than $Q/10$ disagreements can be certified by a sorted list of $\lfloor Q/10\rfloor+1$ distinct differing indices, but evaluating a size-$\Theta(Q)$ circuit separately at every such index would cost quadratic time. Instead universally challenge one entry of this fixed list: evaluate that circuit once and compare the table bit there. Checking sorted distinct indices costs $O(Q\log Q)$ before the challenge. Negating the whole predicate tests a smaller candidate table for failure; quantifying over all lexicographically earlier tables and over the selected table adds only constantly many blocks. All guessed strings and individual deterministic checks have $O(Q\operatorname{polylog}H)$ size and work. Eliminate those blocks with the hypothesized near-linear SAT algorithm. This gives a deterministic per-bit probe within $M$ by choosing $J$ with enough additional logarithmic margin. Thus at each large scale the last positive and first negative members of this conditional list have common-dimensional designated witness tables requiring $N/\operatorname{polylog}N$ gates even to approximate on the slice. On the positive side every satisfying assignment carries those bits in the pinned-bitmap variant. On the negative side the statement is about every genuine Hall witness. The two formulas can be given Gray-coded adjacent index tags to differ in a single actual sign bit, by decoding the tag inside all copies of the source. All programs use the updated virtual syntax. This does not require finding the cutoff cheaply.

Batching eliminates the multiplicative $P$ from positive matching verification. It still takes $M\operatorname{polylog}H$ work to check an arbitrary $M$-step offer. Even with the true cutoff supplied as advice, this estimate does not reach the strictly smaller clock needed to contradict the individual program bound. The replicated tests above show that the worst checks can occur inside every actual Hall witness. Neither a small Hall row set nor an approximate matching alone supplies the missing speedup. Priority for these SAT-specific combinations is unverified.
