# Local proof transfer for modular interval tensions

Let the two paths on vertices `0,...,L-1` be the increasing order and the displayed permutation. Over the field with three elements, introduce Boolean bits `b_i` on the red gaps. A proper three-colouring gives `b_i=h_(i+1)-h_i-1`, since every nonzero difference is 1 or 2. Conversely take `h_0=0` and set consecutive differences to `1+b_i`. For a blue edge with endpoints `l<r`, put `S_lr=sum_{l<=i<r}(1+b_i)`. Its equation is `S_lr^2-1=0`. Together with `b_i^2-b_i=0`, this system is feasible exactly when the two paths admit a proper three-colouring. These interval equations have degree two for every interval length. This statement also works over field extensions of characteristic three when the gaps are Boolean.

## Extension through the first path compiler

Use the actual `encode` construction in `two_hamilton_paths_sat_audit.py`. Colour every port, tail and incidence with its source vertex colour. Give its two adjacent splitter centres the two other colours in their natural order. A splitter edge is automatically proper. An external red data-pair edge is proper provided its corresponding source edge is proper. Port names associate each incidence to its owner, without any traversal depending on colour values.

Fix the topology of this instance, including any data-slot switches before passing the two orders on. The subgraph on the ends of the neutral seven-vertex blocks, formed by edges joining different blocks, has maximum degree two. Each end has exactly two external neighbour incidences overall. The induced subgraph has a proper priority assignment in three classes. This is an assignment of *which round processes each endpoint* chosen using only the supplied topology, for instance by greedy three-colouring a graph of maximum degree two. It does not require a proper colouring of the input or a third oracle. Process the three endpoint classes in order. At each endpoint choose the least colour absent from its already coloured external neighbours (these include ports, splitter vertices or data if present, and the earlier endpoint classes). At most two colours are forbidden. After three rounds every external edge incident to a block endpoint is proper, irrespective of all source colours. Each endpoint depends on a binary tree of depth at most three of source-vertex colours, allowing repeated leaves and constants. Fill each contiguous seven-block from one fixed colouring for its ordered pair of endpoint colours. One may permute the templates (0,1,2,1,0,2,0) for equal ends and (0,1,0,1,2,0,1) for different ends. These templates satisfy red 0,1,2,3,4,5,6 and blue 0,3,5,1,4,2,6. Every interior colour uses at most 16 source-vertex colours. All internal inequalities hold without further source hypotheses. This priority assignment replaces the unbounded sequential dependency of the Python extension method and produces the same kind of witness.

For a disabled data-pair edge in the switchable compiler, use the actual owner after the switch. Its two dummy source vertices can be given colours avoiding their respective single real neighbours; for an enabled pair the private edge has constant colours 0 and 1. Thus branches that implement fixed optional edges only alter bounded local dependencies. The encoding of any fixed graph may use an isolated padded vertex assigned colour zero.

## Extension through the simple-permutation successor

Make the number of source vertices even by an isolated vertex if necessary. The first map then has even output length `m=15v+22e` (with the same conclusion for switchable edges with their private vertices), and its blue permutation begins at 0. The successor uses two padding vertices and ascending high order. Write the old source-dependent colours in red order. Give the first new padding vertex a colour avoiding both final old path colours, and give the second a colour avoiding the first padding colour and the colour at 0. These choices extend the old red path and turn its blue path into a properly coloured cycle whenever all pertinent old inequalities hold. Write the resulting colours as H_i and let eps_i=(-1)^i in the three-element field. In block i at red positions s,a,b,m,c,d,t set

    s=m=t=H_i,  a=c=H_i+eps_i,  b=d=H_i-eps_i.

Within each red block and high stick (a,m,d) the inequalities hold identically. Each red block join is its old red inequality. Inside each low stick the terminal pair is its old blue-cycle inequality. Where successive low sticks join, the two spares are b and c in the same block and their colours differ. Between adjacent high sticks d_i and a_(i+1) get the *same shift* from H_i and H_(i+1), since -eps_i=eps_(i+1). The high join therefore uses one old red inequality. At the seams take x=H_0-1 and y=H_0. The last low stick ends at c_0=H_0+1 since the old blue order starts at 0 and the padded cycle is even. The first high stick begins at a_0=H_0+1. The three blue seam edges, the red initial edge x,s_0, and the red final edge t_last,y all pass, the last by the padding choice H_last!=H_0. Every successor colour depends on a bounded number of source colours. Each resulting edge inequality follows from the fixed local choices plus at most a bounded number of original edge inequalities. The same verification works on partial source assignments on these bounded supports and their local premises, independently of global satisfiability.

Combined with any preceding bounded-local translation of a bounded-degree, linearly many constraint source into a graph, this gives colours h_i that are fixed bounded-arity functions of the *original* Boolean proof variables. In particular, the truth of every output edge inequality requires only a fixed bounded set of source premises, all of bounded arity and degree. Functions need only be consistent on assignments satisfying their local premises. All bounded supported functions can be extended arbitrarily to malformed Boolean patterns.

## Polynomial-calculus simulation

Represent each h_i by its multilinear Boolean polynomial on its bounded support with coefficients in the field with three elements. Source-dependent choices, such as relabelling parity charges by a fixed tree shift, are constants for each input. Global palette vertices can be assigned three fixed distinct colours. Address-to-variable maps, endpoint priorities, permutation positions and global names identify constants or which bounded set of source variables to use. They do not introduce proof variables that encode a solution or gates that compute global assignment-dependent functions.

For Boolean source variables on a fixed set A of at most C variables and a local polynomial Q, Boolean axioms imply

    Q = sum_a Q(a) times chi_a  (modulo the Boolean axioms),
    chi_a = product_{a_i=1} x_i times product_{a_i=0}(1-x_i).

One can derive the difference in ordinary PC by repeated replacement of x_i^k by x_i^(k-1) using a monomial multiple of x_i^2-x_i, followed by linear combination. The multilinear representative is unique by Boolean evaluation in every field. Choose A to include also the variables in every needed local premise. If Q vanishes on every local satisfying assignment, for each a with Q(a)!=0 choose a violated premise P and derive chi_a P by monomial multiplication and linear combination. Reduce chi_a P modulo Boolean axioms to P(a)chi_a, divide by P(a), and combine the appropriate terms to derive Q. All these steps have degree bounded by a constant, e.g. max(deg Q,C+max deg P,C). This applies also to a Boolean encoding of a source finite-domain symbol or to spin signs after the affine change of variables valid in odd characteristic.

Use the formal polynomial substitution sigma(b_i)=h_(i+1)-h_i-1. Its degree K is bounded independently of the input. The image of b_i^2-b_i vanishes under the local premises for the red edge. The image of *the entire polynomial* S_lr is exactly h_r-h_l by formal cancellation in the polynomial ring. The image of the blue axiom is therefore (h_r-h_l)^2-1; its constant-degree derivation uses only the local premises for the blue edge. No multiplication of a long list of local derivations and no width assumption occurs here.

A degree-D refutation of the interval system produces a source refutation of degree at most max(C',KD), for a constant C' bounding the axiom derivations. PC lines are formal polynomials with like terms collected. Linear combination is preserved. At a nonzero multiplication inference P -> b_i P the predecessor has degree at most D-1, since multiplication in the ordinary polynomial ring raises degree by one. Derive, for each monomial of sigma(b_i), its product with sigma(P) by multiplying one source variable at a time, then apply linear combinations to obtain sigma(b_i) sigma(P). Each intermediate degree is at most K(D-1)+K. If sigma(P)=0 the result is zero. This treats dynamic PC, including degree falls under arbitrary linear combinations. An analogous substitution on the actual three-CNF puts each colour flag to its bounded-arity indicator, pins the common padding bit to any constant, and uses local truth tables for every physical clause (the at-least-one vertex clause and the two padded copies of each edge clause). This latter argument applies over every field if the chosen source is hard there. The interval argument uses the arithmetic identity specific to characteristic three.

For Boolean PC the quadratic interval axioms can have polynomially many expanded monomials. The hypotheses of the Impagliazzo–Pudlák–Sgall size–degree bound are still met. There are L-1 Boolean variables and maximum initial degree 2; linear required degree yields exp(Omega(L)) total monomial size. Theorem 2.1 of Lauria and Nordström states the bound for arbitrary systems over Boolean variables of bounded initial degree. Their Theorem 1.1 already gives bounded-degree graph three-colouring families of linear PC degree over every field. The specialization to the particular simple permutation, or to the modular interval representation, needs the local lifts above. [Lauria and Nordström](https://doi.org/10.4230/LIPIcs.CCC.2017.2) [Impagliazzo, Pudlák and Sgall](https://eccc.weizmann.ac.il/report/1997/042/).

The Fourier mod-two expander source in characteristic three is Theorem 10 of Buss, Grigoriev, Impagliazzo and Pitassi. Its hypotheses hold for the connected simple bounded-degree expander family and source charge shifts in the repository's witness-dependent charge note. Theorem 15 and the root-of-unity field extension and constant-degree Boolean translation in that source cover the characteristic-two case for the all-field *graph CNF* statement. [Journal paper](https://mathweb.ucsd.edu/~sbuss/ResearchWeb/lineargaps/journalfinal.pdf).

## Precisely which range queries are covered

In the algebraic proof system one may give any predetermined number of field-valued names Y_j with explicit defining *affine* equations Y_j=A_j(b), including all red prefixes and all interval sums at once. An acyclic affine circuit of names can first be composed symbolically to affine forms in b. Inlining these linear forms in a degree-D extended proof raises no degree: each extension equation becomes zero, and the same one-monomial-at-a-time simulation works with K=1. Over the field with three elements, if ternary domain axioms Y_j^3-Y_j are also included, their pullbacks follow in degree 3 from b_i^2-b_i: for an affine F3 form A, Frobenius gives A^3-A as the linear combination of b_i^3-b_i with the corresponding coefficients. Substitution at inference lines is unchanged, giving a cap max(D,3). If a ternary register is explicitly encoded by Boolean indicators for its three residues, each indicator of A=c is 1-(A-c)^2. Its Booleanity follows in degree at most 4 since (A-c)^4-(A-c)^2 = (A-c)((A-c)^3-(A-c)). Standard fixed-arity consistency relations between these indicators and A similarly follow from the field relation. The exact extension axioms have to be specified for any claim about other presentations.

This proves a degree lower bound even with free names for explicitly fixed affine statistics; there is no degree assertion here for arbitrary assignment-dependent queries, memory read by a computed address, multiplicative extension circuits of arbitrary depth, data-dependent branching outside PC, or table lookups treated as axioms. The degree proof alone gives exponential monomial *size* for the original Boolean interval system. With O(L) added Boolean indicators and fixed-degree known defining axioms the same size–degree bound still gives exp(Omega(L)). For all Theta(L^2) named intervals no such size bound follows from this degree argument alone. The field-valued extension case by itself makes a statement about degree, without a Boolean size–degree assertion for a non-Boolean presentation.

A solver may reject the generated parity-charge subclass on its source syntax in linear work even when every PC refutation of the interval equations is exponentially large. The claims quantify over proofs of these fixed polynomial equations.

## The negative promise with arbitrary SAT payloads

There is also a SAT-complete hard-negative subfamily, without making the original charge vector a public independent data item. Use the repository's reduction from an arbitrary explicit 3-SAT input F of n bits to a proper witness-dependent charge 3-CNF W(F). It gives t=Theta(n/log(n+2)) distinct occurring names/gates, Theta(t) clauses and bit length Theta(n). If F is unsatisfiable, refuting W(F) by Boolean PC over any field requires degree Omega(t). These are the established hypotheses from [the charge construction](witness-dependent-charges-and-the-negative-sat-clock.md).

Feed W(F) directly, with its known dense indexing, to the [fixed SAT-to-colouring gadget](branching-in-equations-over-six-permutations.md#encoding-arbitrary-sat-with-three-occurrences). Take the three distinct palette colours as constants and the global NAE switch s=false. For each clause (a,b,c), use its two NAE triples (a,b,d), (not d,c,s), choosing the first valid d if the clause is true and any default otherwise. Each NAE triangle is filled with the first compatible permutation of the three colours, or a default if it has no extension. A vertex that represents a signed literal depends on one Boolean variable, and an auxiliary colour within the clause depends on at most three. The only input axiom needed to make any gadget edge proper is its own source clause, when such a premise is needed. No removal of degree-one/two vertices is necessary. Keep every source clause and pad with an isolated vertex for even parity of the source graph size. The graph has Theta(t) edges and vertices. Its size is bounded below by the fresh constant-size gadgets per clause, even if two clauses happen to be copies.

Then apply the path and simple-permutation gadgets using the bounded-local extensions above. The output has L=Theta(t) permutation entries. Its representation by L fixed-width endpoint indices has bit length N=Theta(L log(L+1))=Theta(n); dense decimal fixed-width fields also have this asymptotic bit length. The compiler uses O(n) native time for W(F), O(t) word operations on O(log(n+2))-bit vertex identifiers to generate the graph and both orders, and O(N) time to render the physical bytes. The equivalence also holds for the standard colouring DIMACS rendering on O(L) variables and clauses with dense names. Where the chosen order's interval equations are discussed, the physical file supplies its endpoints by the adjacent permutation entries. Expanding every interval polynomial into its quadratic monomials would be a different input representation. For unsatisfiable F, substituting through the whole chain proves Omega(L) PC degree and exp(Omega(L)) total monomial size for its gap equations in characteristic three. The same estimates hold for the rendered Boolean graph CNF over every field by using the charge note's respective mod-p source. This combines the imported every-negative property with the fixed local simulation. The independently varied fixed-layout charge construction is a different subfamily.

More precisely, let a fixed deterministic program be globally sound for signalling unsatisfiability on the represented problem. Suppose it signals rejection within C N^j steps on every negative image of this compiler, with unrestricted workspace. On any explicit 3-SAT input F construct that image and run the program for C N^j steps, accepting on timeout and rejecting if it signals rejection by the cutoff. Correctness on positive inputs follows from soundness and correctness on negative inputs from the promised deadline. The resulting algorithm takes O(n^j) time for j>=1, with the constant hard-wired and with any finite small-input exceptions absorbed in the bound. Soundness on positive images alone suffices for this implication. Conversely, an unrestricted O(n^j) SAT decision algorithm supplies such a globally sound rejection routine on the range representation, using the linear-encoded-size, linear-time Boolean colouring CNF of the path graph. Thus the negative-time threshold on this promise is equivalent for the three clocks j=1,2,3. This implication uses syntax, reductions and deadlines. The PC lower bound on the same negative images does not supply a RAM rejection deadline or exclude one.
