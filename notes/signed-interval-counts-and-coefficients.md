# Which count information distinguishes the signed-interval systems?

Index the tips by \(0,\ldots,t-1\) and take signs \(d_i\in\{1,-1\}\subset\mathbb F_3\). Write \(y_0=0\), \(y_{i+1}=y_i+d_i\), and \(z_i=y_i-d_i\). An input permutation \(p\) accepts a sign vector when all successive tips differ. Denote the integer number of accepted sign vectors by \(C(p)\), and the oriented product of the actual tip differences by \(F_p=\prod_i(z_{p_{i+1}}-z_{p_i})\). Negating all signs pairs the witnesses, so for \(t\ge1\) pinning \(d_0=1\) gives \(C(p)/2\).

The rows of the interval-difference matrix have rank \(t-1\) for every permutation: the map from signs to tips has triangular matrix with diagonal \(-1\), and the incidence matrix of the permuted path has rank \(t-1\). Adjoining the \(t\) coordinate rows makes rank \(t\). The full rank function does determine the count. Inclusion–exclusion gives the characteristic-polynomial evaluation \(C(p)=\sum_S(-1)^{|S|}3^{t-\operatorname{rank}_{\mathbb F_3}(S)}\) on the augmented row matroid. The subsets include all coordinate and difference rows. Evaluating it exactly remains a separate computation. [Finite-field arrangement counting](https://doi.org/10.1006/aima.1996.0059)

**A linear depth of missing coefficient layers.** Take the six-tip order \(P=(0,2,1,3,5,4)\). Within one copy of \(P\), two of the factors are \(d_1+d_2\) and \(d_4+d_5\). Their product vanishes unless \(d_1=d_2,d_4=d_5\). Under those equalities the three other factors are \(-d_0,-d_3,-d_3\). The final tip \(z_4\) equals the final base \(y_6\), so a link to the first tip in the next copy contributes minus the new first sign. Consequently, on the sign cube the product for the natural concatenation of \(r\) shifted copies has the unique multilinear expression

\[
 -d_0\prod_{j=0}^{r-1}(d_{6j+1}+d_{6j+2})(d_{6j+4}+d_{6j+5}).
\]

Its degree is exactly \(2r+1\) and \(C(P^r)=16^r\), while the original formal product has degree \(6r-1\). Every squarefree coefficient in its top homogeneous degree, equivalently each maximal square subpermanent of the row matrix modulo three, vanishes as soon as \(r\ge1\). Even the upper \(4r-2\) degree layers of the full *reduced* polynomial vanish. The classical grid coefficient criterion for nonvanishing thus has no converse at any bounded depth below the top on this family. The five-tip example \((1,0,2,4,3)\) already has reduced degree two and formal degree four; exhaustion shows no earlier positive counterexample. [Alon, Combinatorial Nullstellensatz](https://doi.org/10.1017/S0963548398003411)

**Programming the integer witness count.** Concatenate blocks in disjoint consecutive red index ranges and concatenate their internal tip permutations in blue. At a block boundary record whether the preceding last tip equals the current base (state \(E\)), or differs (\(D\)). Given the current base, counts for either of the two possible unequal incoming colors coincide by symmetry. Include in each block the incoming inequality against its first visited tip, then classify the outgoing last tip against its final base. Using this convention, the following transfer matrices have rows and columns in order \(E,D\):

\[
 A=(1,2,0,4,5,3)\longmapsto 4\begin{pmatrix}1&0\\1&1\end{pmatrix},\qquad
 B=(1,5,3,4,2,0)\longmapsto 4\begin{pmatrix}1&0\\1&2\end{pmatrix}.
\]

The eight matrix entries are verified directly by the 64 sign strings for each tile. For suffix counts proportional to \((1,x)^\mathsf T\), prepending \(A\) gives ratio \(x+1\), and prepending \(B\) gives \(2x+1\), multiplying the common factor by four each time. The empty suffix has ratio one. To encode any \(X>2\), reduce an odd \(X\) to \((X-1)/2\) and an even \(X\) to \((X-2)/2\); reverse these steps by prepending \(B\), or by prepending the ordered pair \(A,B\), respectively. The values one and two use zero and one tiles. This gives \(\ell(X)\le2\lfloor\log_2 X\rfloor\) tiles and suffix column \(4^{\ell(X)}(1,X)^\mathsf T\).

**Every exact length.** Write \(t=6s+g\), \(1\le g\le6\). For any positive \(X\) with \(\ell(X)\le s\), concatenate \(q=s-\ell(X)\) copies of \(P\), the natural-order block of \(g\) tips, and the code for \(X\). Within the natural block every sign must equal the preceding sign, since an adjacent tip difference is \(-d_i-d_{i+1}\). There are two choices, both compatible with the final equal tip and base of the \(P\) prefix, and both put the output in state \(D\). If \(q=0\) the same two choices occur at the start. This exact length-\(t\) positive instance therefore has

\[
 C(p)=2\,16^q4^{\ell(X)}X.
\]

Pinning the first sign divides the displayed count by two. If \(q\ge1\), appending \(t-6q\) tips adds only \(t-6q\) linear factors to the signed product, so its reduced degree is at most \(t-1-(4q-2)\). The fixed length also admits a negative input when \(t\ge4\), by placing the impossible four-tip order \((1,0,3,2)\) before the remaining natural ranks. For that order the first and last tip inequalities force \(z_0=z_3=y_2\), contradicting their required inequality.

**Adaptive counts.** Suppose a deterministic procedure knows \(t\), and its only information about the input permutation comes from querying its witness count modulo integers \(m_i\ge2\), with no change to the underlying instance. On the transcript consisting of zeros put \(X=\operatorname{lcm}(m_1,\ldots,m_j)\), using one when the list is empty. If \(2\lfloor\log_2 X\rfloor\le s\), the positive construction and the negative input give exactly the same answers, including when the count is taken after pinning the first sign. The choice of each modulus on this transcript is identical by determinism. Correct termination therefore requires \(\sum_i\log_2 m_i=\Omega(t)\) on the negative transcript. A modulus above \(2^t\) yields the exact integer count using \(O(t)\) modulus bits, giving the matching information scale in this oracle model. When \(\log_2 X\le s/4\) the same positive witness also has \(q\ge s/2\), so even supplying the top \(2s-2\) reduced degree layers leaves it indistinguishable. These statements allow input-independent adaptive selection of moduli. Physical inspections of the permutation, input-dependent weighting, counting modified instances, or reading further polynomial coefficients provide additional information.

In particular take \(X=\operatorname{lcm}(1,\ldots,K)\). Then \(\log_2 X=\Theta(K)\). For the upper bound, the quotient from \(K=n\) to \(2n\) divides \(\binom{2n}{n}\), since each newly reached prime power in \((n,2n]\) contributes its prime to that binomial coefficient. Sum over dyadic scales. Conversely \(\binom{2n}{n}\mid\operatorname{lcm}(1,\ldots,2n)\): at each prime-power scale the difference of floor terms between \((2n)!\) and \((n!)^2\) is at most one. Hence simultaneously for all moduli up to \(c t\) for an absolute \(c>0\), and for a linear number of top signed-product degrees, one positive input of every sufficiently large exact length has the same zero tests as a negative input. The scale for this simultaneous divisibility is optimal up to constants, because a nonzero sign count is bounded by \(2^t\).

**A weighted coefficient that recovers the source count over every field.** The seven-tip compiler tile \((1,4,3,5,6,0,2)\) has two internal sign completions for each ordered pair of distinct base endpoints. In coordinates with initial base zero and final base one these are \((1,1,-1,1,1,-1,-1)\) and \((-1,-1,1,-1,-1,-1,-1)\). Negate the signs for final base two. Thus exactly one completion has its first sign positive, and both have their sixth sign equal to minus the terminal base difference. Compile an \(n\)-vertex two-path input, leaving the final auxiliary base unconstrained apart from its inequality with the last source vertex. Let \(H\) count source colorings with the first red vertex pinned to zero. Assign a weight \(X\) to a positive first sign in each of the \(n\) tiles and an additional weight \(X\) to a positive sixth sign in the last tile. Weight all other choices by one. Summing over valid sign vectors gives the integer polynomial \(H(1+X)^{n+1}\). Indeed the \(n\) independent internal choices contribute \((1+X)^n\), and the two possible final auxiliary colors contribute \(1+X\). Its top coefficient or constant coefficient is exactly \(H\) after passage to any field. Equivalently, fixing all \(n+1\) selected signs gives a parsimonious correspondence for that pinned problem. The unweighted count is \(2^{n+1}H\). Recovering a source count from this particular weighted count adds no known fast algorithm for evaluating it. None of the oracle lower bounds prices an ordinary RAM which sees the input.

**Uniform multiplication for every source permutation.** The four-tip reset \(R=(1,2,0,3)\) has transfer matrix \(\left(\begin{smallmatrix}0&4\\0&4\end{smallmatrix}\right)\). Thus for every nonempty source permutation, appending \(R\) and the code for \(X\) multiplies its integer witness count by exactly \(4^{\ell(X)+1}X\), including when the source has zero witnesses. The same statement holds with the first original sign pinned. The transfer of \(P\) is \(\left(\begin{smallmatrix}16&0\\8&0\end{smallmatrix}\right)\), so appending \(R,P^r,R\) with \(r\ge1\) has positive constant multiplier \(4\cdot8\cdot16^{r-1}\cdot4\). The internal contiguous copies of \(P\) give the same loss of at least \(4r-2\) top degree layers in the full signed product. Using one reset/code for each maximal prime power \(q\le K\) (one per prime) gives a suffix of total length \(O(\sum_q(1+\log q))=O(K)\). Their product is \(\operatorname{lcm}(1,\ldots,K)\). Generate the powers by a sieve up to \(K\) and each binary word using only integers at most \(K\); even the elementary \(O(K\log K)\)-word-operation version fits linear time in the explicit native bit length at \(K\) proportional to the source item count. This preserves both answers for arbitrary source permutations while imposing simultaneous vanishing modulo a linear range of moduli.
