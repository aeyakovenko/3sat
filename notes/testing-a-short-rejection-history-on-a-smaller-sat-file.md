# Turning a short rejection history into a missed SAT deadline

Fix a nonempty finite list of correct deterministic SAT deciders on the logarithmic-word load/store RAM. The common exponent is $k\in\{1,2,3\}$ and row $i$ has a proposed deadline $a_i(n+1)^k$, with integer $a_i\ge1$. All workspace is available. At every sufficiently large scale $h$ one can generate an **unsatisfiable** proper DIMACS file $G_h$ of length $N$ and a finite, explicitly indexed family of tests of a smaller common length $L=2^h$ bits. Here $N=L^k h^{O(1)}$ and $L<N$. At least one of the following holds.

1. Every row exceeds its deadline on $G_h$.
2. There is an unsatisfiable $L$-bit test on which every row exceeds its own deadline. The test is the local validity question built from a particular exact description of a real rejecting run on $G_h$.
3. At least one row meets its deadline on $G_h$, and **every** such row requires more than $g=\lfloor L/(Ah)\rfloor$ bounded-fan-in Boolean gates, for a fixed constant $A$, to return its augmented history as a function of time. This is $N^{1/k}/\log^{O(1)}N$ gates. Circuits may depend arbitrarily on the input, the program and its clock.

The augmented history comprises the PC and the fixed register file, plus the latest preceding work-store time at each load (or the initialization symbol). For other instructions the extra field has a fixed default. A halt is idled with fixed fields. Read-only input and zero-initialized work memory are separate. The standard arithmetic operations on a word have uniform Boolean circuits of size polynomial in the word width. A fused instruction requires exposing its bounded list of ordered memory events. A globally valid clock on even one listed solver rules out the first two alternatives. The time on the smaller test is measured in its own encoded length.

The [earlier register-history theorem](chronological-solver-registers.md) already gives the $1/k$ exponent for augmented histories under a global fast-SAT hypothesis at $k=2,3$. Here any exact small history of any timely row on a specified outer file directly supplies one smaller common deadline miss, without assuming an exact fast decider is available to check defects. This applies to every scale and to the linear deadline.

## A small test with a real yes/no meaning

Let $T_i$ be the rounded deadline on the predetermined length $N$. A circuit $D$ takes $\lceil\log_2(T_i+1)\rceil$ time bits and outputs the fields of the claimed history through $T_i$. Extra input points can have arbitrary values. A test $H(i,D)$ asks whether the description has a defect as a rejecting computation of row $i$ on $G_h$. The front end validates circuit syntax and size before admitting it as a witness. For admissible circuits the following conditions are necessary and sufficient.

* Check the initial controller, a rejecting halt by the deadline, and legal words, tags and idle transitions. At each $t<T_i$ check the transition with the proposed response. At an input load compute the actual packed input word from the address and the local description of $G_h$.
* For a work load with claimed predecessor $j$, require $j<t$, a store to that address at $j$, agreement with the stored word, and absence of any intervening store to that address. For initialization require the initial value and absence of any earlier store to that address. Ignore unused input points and enforce default predecessor fields on non-load rows, including the terminal boundary.

Any failure has a witness consisting of a constant number of time indices and a condition identifier. In particular a store in a forbidden interval takes one index. If no condition fails, induction from the true initial configuration identifies all controllers and load responses with the actual run. The predecessor is then uniquely determined at each load. Every timely rejecting computation gives a passing history. Thus $H(i,D)$ is UNSAT precisely when $D$ describes the actual bounded rejection.

Use a fixed number of copies of $D$ with shared fan-out inside each copy. Guessed indices serve as addresses, including an index supplied by a previous copy of $D$. A uniform circuit of size $h^{O(1)}$ computes local instructions, address checks, and a requested outer input word. The existential defect circuit therefore has size $O(g+h^{O(1)})$ with the chosen gate cap $g$. Print its gate constraints as proper ternary clauses, fixing constants and expanding unit and binary clauses on distinct fresh variables in all sign combinations. This yields $O((g+h^{O(1)})h)$ physical bits, below $L/2$ for sufficiently large fixed $A$ and then sufficiently large $h$. Pad to exactly $L$ bits by legal whitespace. Gate references and fixed-width decimal fields take $O(h)$ word operations per gate even with digit-at-a-time output. Generating $H$ and copying or initializing the whole $L$-bit file costs $O(L)$ time.

## Building the outer file without running its own solver

Preassign $U=L^k h$ native steps and $N=L^k h^B$ physical bits, for a fixed sufficiently large integer $B$. Both are byte-aligned for $h\ge3$. A template $V_e$ guesses a roster index and a topologically ordered circuit description of the above size. It builds $H(i,D)$ and runs each candidate on the actual padded test up to its smaller deadline. It accepts on any timely NO. All simulations start in their prescribed initial memory. The constant number of $O(L^k)$ simulations, emitting $H$ and decoding the description fit $U$ for all large $h$.

For the local view of $G_h$ in the test, use the physical bounded-computation compilation of $V_e$ on public parameters $(e,h)$ with bound $U$. Pad that formula to the preassigned $N$. A fixed rectangular layout of the computation rows, memory-routing stages and gate clauses gives $U\log^{O(1)}U$ physical bits. A word at a specified address is computable in $h^{O(1)}$ time. One can use a bitonic sorting network over the memory events, with the stage and partner in a row computed from bit indices. Each fixed instruction template has polynomial-in-$h$ width. Rectangular blocks of gate clauses and fixed-width fields, padded with legal spaces, permit extraction of a named clause or an ASCII word without generating the file. This version needs no near-linear-size optimal sorter. A fixed power $B$ absorbs the encoding overhead. Symbolic branches for public and existential bits, fixed proper-clause gadgets and the final whitespace range are among the indexed block types. [Parsimonious ASCII Batcher layout](projected-parity-holes.md#a-parsimonious-ordinary-3-cnf-near-the-native-clock) · [Quasilinear local SAT completeness, Theorem A.1](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

Here is the self-reference convention. Number one verifier template $V(e,h)$ whose defect-circuit builder inserts the bit-indexer for the computation formula of the **program numbered $e$ on $(e,h)$**. Use $e$ equal to the number of that verifier. The indexer computes block offsets, literal names, template gates and public parameter bits. It never executes the bounded verifier whose computation it encodes. The indexer can first be written for a universal finite instruction template with program code in the public initial state, so its definition does not require its own completed source as a subroutine. Fixed $e$ and the finite roster are constants. Compiling a polynomial-in-$h$ local index computation into a Boolean circuit still costs $h^{O(1)}$, even if its small working memory is multiplexed directly. Choosing a larger fixed $B$ changes the index word width by only $O(\log h)$; the $O(L)$ bound for generating the inner file absorbs every fixed polynomial in $h$. The output length and the clock being checked are consequently known before any answer is received.

Call this outer file $G_h$. If it were satisfiable, a witness would lead to a timely NO from a correct program on a test $H(i,D)$. That test would be unsatisfiable, certifying an actual rejection of $G_h$ by a correct row. This is impossible. Hence $G_h$ is unsatisfiable. If a timely row has a circuit of the allowed size, choose that very circuit in $V_e$. Its physical test is unsatisfiable. No row can return NO in time there because that would make $G_h$ satisfiable; correctness excludes every timely YES there. This proves the claimed alternatives. The witness to the second alternative can be generated from the circuit without knowing which solver is the first to miss a deadline. Searching for the circuit may itself be costly.

## Incoming programs may give false answers

For a finite pool with arbitrary outputs use a public mask of active rows at both levels. The mask, including in the indexer for $G$, is fixed throughout one trial. The same $L,N$ work for every mask. Start with every row active. A satisfiable outer trial has a witness $(i,D)$ and an actual voter $j$ returning NO on the test. Replay $i$ on the satisfiable outer file through its advertised clock. If $i$ returns NO, retire $i$ using this outer file. Otherwise $D$ cannot describe the claimed bounded rejection, so the inner file is satisfiable. Retire $j$ for its actual NO there. Both retirements come with a positive physical counterexample. At most the original number of rows are removed. Stop when the outer trial is unsatisfiable, which must happen at the latest with the empty mask.

Every globally NO-sound row survives. On the terminal trial any timely rejecting survivor with an allowed exact circuit would produce a genuinely UNSAT smaller file on which no survivor issues a timely NO. This establishes the three alternatives for the **globally correct deciders in the original pool**, without knowing which they are. For merely NO-sound rows, a missed timely NO could be a timely false YES, so only the NO-certificate statement applies. If there are no globally correct deciders the first alternative is vacuous. Adding an arbitrary program can change the terminal mask and the outer file.

This is a finite algorithm. To decide the outer trial one need only enumerate the proposed circuit descriptions and roster indices, then run the bounded verifier; its other choices can be made deterministic after those guesses. Use $O((g+h)\log(g+h))$ bits to encode a circuit with $O(h)$ outputs. Thus the mask and the removal witnesses are obtainable in $2^{O(g\log(g+h)+h)}\operatorname{poly}(N)$ steps for a fixed roster. All defect witnesses for a fixed $D$ consist of $O(h)$ bits, so a falsifying positive test can also be checked by direct enumeration in polynomial time in $N$. A final bounded simulation on $G$ and evaluation of trial circuits on all time indices can produce a particular smaller miss or certify circuit exhaustion on the timely rejecting survivors within the same overall bound. This computation does not certify that a surviving program solves SAT outside these trials. Taking $g=\lfloor L/h^2\rfloor$ gives the cheaper $2^{O(L/h)}\operatorname{poly}(N)$ search and costs one logarithm in the history bound.

## What carries to an extension of an old positive file

Fix any satisfiable proper seed. One may retain its clauses, renaming its occurring variables if necessary, in both the outer file and every smaller test. Their auxiliary variables are disjoint from the seed names. The mask proof applies verbatim because conjunction with the seed preserves each SAT verdict. Each satisfiable output extends any chosen model on the seed. Old elapsed-time misses need not survive.

There is room even for seeds of $b\le cL$ encoded bits for a sufficiently small fixed $c>0$, with the following indexing detail. Rename occurring decimal names by increasing numeric rank, which never increases their printed lengths; a digit trie with buckets by length supports this normalization in near-linear time. Supply the normalized body as packed public parameters and use separate fresh fixed-width ranges for the computation variables. The file is a new header, the normalized seed body, the regular computation clauses, and whitespace padding. Choose a format in which a selected bit of the outer constraint part consults at most a constant number of bits of the public data (the bits fixing initial inputs). Metadata containing lengths and offsets has $O(h)$ bits. In an input-load defect it suffices to guess **one** wrong bit of the returned word. A packed-word comparator on every bit is unnecessary here.

To access an arbitrary fixed $b$-bit string from its binary address inside the defect circuit, group its bits in blocks of power-of-two length $r=\Theta(\log(b+2))$, with $r\le\tfrac12\log_2(b+2)$ for large $b$. Decode the high address to one flag per block by a binary tree. For each possible block pattern OR the flags of the blocks carrying that pattern. Decode the low address and select its bit for each present pattern. Gate cost is $O(b/r+r2^r)=O(b/\log(b+2))$. This explicit version of a table lookup uses $O(bh/\log(b+2))$ printed bits; it is $O(b)$ if $b\ge\sqrt L$, and $o(L)$ otherwise. The lookup tables and their gates can be constructed in $O(L\operatorname{polylog}L)$ time, by grouping equal blocks in the array of $2^r$ possible masks. In this seed variant take $U=L^k h^{b_0}$ for a sufficiently large fixed $b_0$ and increase $B$ accordingly. Choose $A$ and then $c$ so the circuit copies, seed and table lookups together fit $L$. The two-length power and hard-core estimates are unchanged. With unpinned seeds the number of satisfying assignments may grow; only existence is used.

## Agreement on actual prehalt times

When alternatives 1 and 2 are both absent, each timely row has a single output bit and a set of genuine prehalt time indices of size at least $N^{1/k}/\log^{O(1)}N$ on which no Boolean circuit with $N^{1/k}/\log^{O(1)}N$ gates has agreement above $1/2+1/h$. The bit can belong to the predecessor field. The set, bit, and logarithmic exponents need not coincide for two different rows. At $k=1$ this gives an inverse-polylogarithmic fraction of the steps of a hypothetical linear solver.

Here are details of the finite hard-core argument. Take $g$ as above. Time addresses and the number of output bits are $O(h)$. An exact circuit on genuine prehalt times extends to all required times using the hardwired first halt and final idle state, a comparison and a selector. If the run has fewer than $g/h^5$ prehalt points, a table of exceptions gives all bits with $O(g/h^3+h^2)$ gates, already too small. Take $u=\lfloor g/h^5\rfloor$, $s=\lfloor g/h^{12}\rfloor$ and $\epsilon=1/(16h)$.

For one output bit consider distributions on the prehalt domain with point masses at most $1/u$. If for every such distribution some $s$-gate circuit has success above $1/2+\epsilon$, finite minimax gives a mixture of circuits with that success against every capped distribution. Fewer than $u$ indices have pointwise success at most $1/2+\epsilon/2$, since otherwise their uniform distribution is allowed. A majority of $O(h/\epsilon^2)$ independent draws from the mixture is simultaneously correct at every other point with positive probability by Chernoff and a union bound over at most $2^{O(h)}$ times. Hardwire the exceptional indices by equality tests. If this works for every output bit, the combined exact circuit costs $O(h[uh+(s+1)h^{O(1)}])$ gates, specifically $O(h[uh+s h^3+h^6])$ using a quadratic-size majority on $O(h^3)$ bits. This is below $g$, contradicting the exact bound.

Thus some bit has a capped distribution $\mu$ on which every small circuit has success at most $1/2+\epsilon$. Include each time $x$ independently with probability $u\mu(x)$. The expected set size is $u$ and the expected count of successes of any one circuit is at most $u(1/2+\epsilon)$. Additive deviations of $\epsilon u$ have probability $\exp(-\Omega(\epsilon^2u))$ by the Bernoulli concentration bound. There are at most $2^{O(s\log(s+h))}$ candidate circuits, so a realization simultaneously has size at least $(1-\epsilon)u$ and success count at most $(1/2+2\epsilon)u$ for each. This yields the asserted agreement bound, also for anti-correlation upon allowing a final NOT and shrinking the quoted gate budget by one. The indices are a mathematical set, with no efficient sampler claimed. This adapts Impagliazzo's hard-core argument and the journal's earlier bounded-depth prehalt calculation. [Impagliazzo, FOCS 1995](https://doi.org/10.1109/SFCS.1995.492584) · [Earlier prehalt bound for ACC circuits](trace-bit-hard-sets.md)

## One computation for a growing program budget

One can take all raw codes of a specified common length $c(h)=h-O(1)$ on a fixed universal register ISA (malformed codes idle). For a catalogue of all strings up to the budget, charge at most $2^{c(h)+1}$ mask bits. Fix the additive constant so these bits fit the same $cL$ public-data allowance as in the preceding construction, sharing the allowance with any seed. The masked verifier guesses both the row being described and a single small voter, and tests that both are active. This replaces a loop over voters; it preserves the exact existence of a timely NO. Decoding the $O(h)$-bit program and simulating one selected voter has polynomial-in-$h$ overhead per native instruction. Give the universal catalogue fixed word width coefficient, a fixed number of architectural registers, and a common time multiplier, or allow multipliers up to $h$. Include every fixed finite program under an effective length convention, such as a self-delimiting program header with unused suffixes. The outer $L^k\operatorname{poly}(h)$ bound absorbs these costs. No arbitrary growing coefficient of guest word width is assumed.

This gives actual removal witnesses and a terminal sublist from a single uniform construction for growing budgets. Bounds for the family of files are measured with its selected mask as public data. Computing which mask is terminal is part of the exponential-time census. The factor for up to $O(L)$ successive removals and the choices of row indices is polynomial in $N$. A different construction encodes the open issue in a single first-unmatched rank and gives a correct program defeating generic attempts to predict it. ## A globally correct fast path for the old outer file

For a *fixed* roster known to consist of correct rows, the seedless full-mask $G_h$ is always UNSAT. There is a different globally correct decider recognizing those particular files in $O(N/\log N)$ word steps with a $\operatorname{poly}(\log N)$-gate augmented history on them. This is a test of an induction that would reuse the same named negative after adding a new program.

Choose $B$ large enough that the unpadded layout length $U h^{d}$ times the $h^{d'}$ cost of local word production is $O(N/h)$, where $d,d'$ are fixed template bounds. Standard fixed-stride indexing uses time polynomial in $h$ with degree independent of the padding exponent $B$: only the $O(h)$-bit public length and clock parameters change. Solve for $h$ from $N=L^k h^B$ by trying $O(\log N)$ candidates and checking exact integer lengths. Compare the nonpadding words using the local generator and scan the remaining words for the prescribed spaces, accounting for partial boundary words. Return NO only on an exact match. Fall back to exhaustive SAT otherwise. This recognizer relies on the correctness of the **old** roster in its correctness proof.

On a canonical file every comparison succeeds. Implement each nonpadding word computation by evaluating a fixed uniform circuit of $h^{O(1)}$ gates for that width, sequentially in a private bank with a fixed block of microsteps per gate and block per word. The universal local indexing algorithm supplies these small circuits in $h^{O(1)}$ setup work by unfolding its polynomial-time computation at input width $O(h)$. The setup trace can be hardwired in a circuit of $h^{O(1)}$ size. Scratch locations written on one word are initialized or unconditionally overwritten before use on the next; one can clear every location on each iteration. The generator circuit and read-only lookup banks are initialized once during setup. Given a prehalt time index, locate its phase, word and instruction by division on $O(h)$-bit integers. A circuit can replay a whole local block and the previous block in $h^{O(1)}$ gates to recover the controller and the exact prior-store stamp, including bank initialization and the fixed successor word loop. On the trailing padding phase the stream is counted word increments and successful equality tests. A register-only implementation there needs no data-dependent stores. Increasing $B$ absorbs these fixed implementation costs.

On the enlarged roster the outer file's compiler contains the new code. It has a different bounded computation to check. Trying to reject that **new** family by the same syntactic rule would require a fresh correctness argument about a roster containing the rule itself. In the mixed-pool construction a false NO is a removable error. The old fast path therefore supplies a concrete incoming program against reuse of the seedless outer family, while leaving open a common miss on a smaller test. On an already unsatisfiable seed, retaining a recognizable copy of all of its clauses would likewise allow a solver to reject every such extension.

## The unresolved step for elapsed time

A writable load can depend on an arbitrarily distant store. No inequality here bounds the unrestricted circuit complexity of the augmented history above by $g$ merely because a solver finishes on $G_h$. Consequently the third alternative remains compatible with a globally fast solver. Calling an incoming program on $G_h$ and assembling a physical transcript by replay costs up to $N^k$ native steps even when the verdict is already fixed. The disjunction isolates exactly where the smaller input can be extracted from a proposed short history. Priority of the two-length formulation is unestablished.
