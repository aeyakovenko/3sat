# Testing a race between independent workers with partly observed clocks

**Research journal, 24 November 2026.** I tried to use the first, last, or median of many completion times as the integer in the [numeric coding test](sampling-at-a-numeric-length.md). The entire race can have exponentially many distinguishable histories even when only a few facts about each worker determine the answer. A deterministic decoder can exploit this if the comparisons between workers admit the description below. Its excess program length over the negative logarithm of the recovered probability is bounded by a constant. This precision matters for the high-mass test, where the excess needed for a counterexample can grow arbitrarily slowly.

## An interval reported by each worker

Fix an ordinary sampler $S$, and identify finite words with their zero-based length-lexicographic ranks. At epoch $q$ the deadline is $t=2^q$. Suppose a uniform deterministic procedure in $t\,\mathrm{poly}(q+2)$ time supplies the following data.

* There are $\mathrm{poly}(q+2)$ independent random intervals $[L_i,U_i]$ of rank values, with dyadic marginal tables. Each table has total mass one and a common dyadic denominator whose exponent is polynomial in $q+2$. Finite endpoints have polynomially many bits in $q+2$. An unbounded upper endpoint is allowed. A dyadic scalar $\beta_q\in[0,1]$ with the same precision limit accounts for the probability of selecting this collection of workers.
* A bounded-fan-in circuit of polynomial size in $q+2$ combines the workers by order statistics. Each gate returns an indicated order statistic of its incoming values. Wires and worker values may be reused. Write $G$ for the resulting function. A supplied elimination ordering of the circuit variables has width $w$. Initially connect each gate variable and all of its input variables as a clique. When deleting a variable connect all its remaining neighbors to one another. The maximum number of these neighbors is $w$.
* The interval $[G(L),G(U)]$ certifies a common eventual output measure. Precisely, for any finite interval $I$, $\beta_q\Pr[[G(L),G(U)]\subseteq I]$ is at most the probability that $S$ eventually publishes a rank in $I$. This holds, for example, if a phase of mass $\beta_q$ uses independent worker tapes, the marginal tables give verified brackets for their actual bids, and the sampler returns the indicated rank. A run with no final publication may use an infinite unresolved endpoint if the candidate finite certificates remain sound. Only the displayed domination is required. It prevents crediting every unrelated epoch as a separate probability-one sampler.

The dyadic tables may describe worker histories much more cheaply than listing the joint histories. For example, an early visible flag can certify a singleton bid or leave the full range possible. The time to generate the stated marginal tables and the ordering is charged. Unrestricted RAM traces generally do not come with such tables.

Fix an integer tolerance $D\ge0$. For the integer rank $z$ of a short word write
$$
 M_q(z)=\beta_q\Pr\big[[G(L),G(U)]\subseteq[z-D,z+D]\big].
$$
At $D=0$ this measures the chance that the worker certificates force $z$ exactly, including outcomes on which some leaves are still wholly unknown. A positive $D$ can credit a neighbor. For each fixed $J\ge0$ and efficient literal prefix reference $V$ there are constants $A,c$ such that the following holds. For $|y|\le q$, $z=\mathrm{rank}(y)$ and $M_q(z)>0$, put $d=\lceil-\log_2 M_q(z)\rceil$. If
$$
 2(w+1)+d\le q+J\lceil\log_2(q+2)\rceil,
$$
then $K^V_{2^q(q+2)^A}(y)\le d+\lceil\log_2(2D+1)\rceil+c$. The constants can depend on the fixed data procedure, $J,D,V$. If every interval is a singleton, the weaker width requirement $(w+1)+d\le q+J\lceil\log_2(q+2)\rceil$ suffices. The bounds require no SAT hypothesis.

## Computing a probability query without unfolding the race

For $I=[a,b]$ the event $[G(L),G(U)]\subseteq I$ means $G(L)\ge a$ and $G(U)\le b$. For each input or gate variable keep these two truth values as a four-state variable. At a gate returning the $j$th smallest of $r$ inputs, its first bit is true when at least $r-j+1$ input lower bits are true. Its second bit is true when at least $j$ input upper bits are true. Repeated inputs in an argument list contribute at all of their designated positions. Since order statistics are monotone, the two endpoints bound every permitted realization; both endpoint tuples themselves are realizations of the interval box. The event tests exactly when all realizations within that box are in $I$.

The two bits of one worker can be correlated. Obtain their four joint weights from the two marginal inequalities and the two-dimensional rectangle $L_i\ge a, U_i\le b$. On each input table build a balanced tree indexed by $L_i$ with a sorted list of $U_i$ values and cumulative integer weights at each node. Sorting and building costs the input table size times a polynomial in $q+2$. A query decomposes a suffix in the first coordinate into logarithmically many nodes and uses a binary search in each second-coordinate list. Thus all worker weights for one interval query cost $\mathrm{poly}(q+2)$ after the single preprocessing pass. This charge avoids scanning a potentially time-$t$ marginal table separately at each output prefix.

Use one unary weight factor per worker, a zero-one relation per gate, and an indicator of state $(1,1)$ at the root. Their product summed over all variable assignments is the desired probability. Independence is used across worker variables exactly once. Multiple appearances of a worker in the circuit refer to the same variable. In the supplied order, multiply all factors containing the next variable and sum it out. Each update sees at most $w+1$ four-state variables, so the cost per query is $4^{w+1}\,\mathrm{poly}(q+2)$. The product of the worker denominators has polynomially many bits. Intermediate integer numerators also fit polynomially many bits, even allowing the total number of assignments to all polynomially many variables. In the singleton case subtract the two exact cumulative probabilities at $b$ and $a-1$. Each needs only one Boolean threshold bit per variable and costs $2^{w+1}\,\mathrm{poly}(q+2)$. Computing cumulative distributions of lattice polynomials and summing factors along an elimination order are established techniques. [Marichal](https://arxiv.org/abs/0707.0953) · [Kask, Dechter, Larrosa and Dechter](https://doi.org/10.1016/j.artint.2005.04.004)

## Finding all qualifying words while retaining constant-bit precision

For each integer depth $d$ passing the width test, organize all ranks in $[0,2^{q+1})$ into binary prefix intervals. One unused final rank can be ignored. At a node $[u,v]$, traverse further only if the computed weighted probability for $I=[u-D,v+D]$ is at least $2^{-d}$. This preserves every qualifying leaf by interval inclusion. At a fixed level, any actual rank lies in at most $2D+1$ of the expanded intervals because the unexpanded intervals are disjoint nonempty integer intervals. By the common eventual output measure, the sum of the node probabilities is at most $2D+1$. Thus at most $(2D+1)2^d$ nodes per level can pass. Include the children of passing nodes in the running-time charge. The width test gives total time $2^q\,\mathrm{poly}(q+2)$ at the epoch, including all depth values. This uses one geometric time budget per epoch.

Issue a request of width $2^{-d}/(4\cdot 2^{\lceil\log_2(2D+1)\rceil})$ for $(z,d)$ the first time this leaf passes at an eligible epoch. The bounds need no monotonicity of the tables or their widths across epochs. For each fixed $z$ all claimed masses are at most the eventual $S$ mass of $[z-D,z+D]$. Summing these neighborhood measures over $z$ charges each eventual output at most $2D+1$ times globally. Geometric summation over $d$ shows that all requests together occupy at most half the unit interval. Lay them contiguously, choose a half-width aligned dyadic cylinder inside each one and use its bits as a prefix name. Chronologically reproducing the requests through $q$, with a dictionary of previously issued pairs, costs $2^q\,\mathrm{poly}(q+2)$. On an exact codeword the decoder can skip any earlier request as soon as its assigned cylinder disagrees with its cached prefix. Disjointness of the assigned cylinders prevents reading past the intended codeword. At its own request the true code is recognized and the rank gives the word. This is the [prefix allocation used in the near-deadline construction](near-clock-coding.md), here driven entirely by ordinary deterministic computations.

Consequently, in the high-mass case $p=P_t^S(y)\ge(q+2)^{-a}$, a race representation with $2w\le q+O(\log(q+2))$ that captures even a fixed positive fraction of $p$ already supplies the required length and time for this word. For exact worker reports $w\le q+O(\log(q+2))$ suffices. Along any sequence defeating every fixed nearby deadline by an unbounded bit gap, the ratio $M_q(z)/p$ must tend to zero along the corresponding diagonal subsequence for every such fixed representation and tolerance. This conclusion applies to a single efficient interpreter. It does not furnish the large gaps needed to decide the SAT question.

## A consequence for the actual reference machine

The same allocation upgrades the branching-work obstruction for arbitrary samplers, without assuming a race representation. Let $t=2^q$, $p=P_t^S(y)>0$ and $|y|\le q$. For a run that publishes $y$ by $t$, let $H$ count the sum of $2^j$ over its instructions, where $j$ is the number of fair bits consumed before that instruction. For each fixed integer $B\ge0$ put $\rho=\Pr[H\le t(q+2)^B\mid y\text{ published by }t]$. For some fixed $A,c$ depending on $S,V,B$, whenever $\rho>0$,
$$
 K^V_{t(q+2)^A}(y)\le \lceil-\log_2(p\rho)\rceil+c.
$$

Indeed, the [bounded traversal](fair-tape-work.md) deterministically lists the retained publications with exact weights in $t\,\mathrm{poly}_B(q+2)$ time. Every included publication actually occurred on the original fair tape. At each epoch and each integer depth through $2q+O(1)$, scan this list and issue the first-crossing requests directly. The bound on total width uses the true eventual mass with $D=0$ as above. Larger depths are covered by a literal encoding of $y$ at all sufficiently large $q$. This proof also applies to the same note’s beam search retaining at most $(q+2)^B$ full RAM configurations at each layer. Its lower approximations recover at least half of the probability of every publication on the retained histories. Thus a further constant in the name length suffices with $\rho$ equal to the corresponding conditional survival probability. These statements apply in particular to $S=V$. If the hard-deadline excess $K^V_{t(q+2)^A}(y)+\log_2 p$ grows without bound, then $\rho$ tends to zero at least exponentially in that excess, even when it grows much more slowly than $\log q$. The earlier soft-cost estimate included an additive $O(\log q)$ charge and did not give this conclusion in that range.

## Tests of the race hypothesis

In a median race, let each worker report a certified singleton $z$ with probability $3/4$ and a full unresolved interval with probability $1/4$. With 101 independent workers the probability of resolving every worker is less than $10^{-12}$, yet the median is certified equal to $z$ with probability greater than $0.999$. Thus the useful probability can survive even when a search requiring the entire tuple to resolve would discard almost all the mass. A fixed-bounded-fan-in comparison circuit realizing one such fixed-arity median meets the gate model. More generally a read-once tree of arbitrary-arity rank gates can compute a single query in time polynomial in its total number of wires: at each gate combine the four-state laws from its independent children by counting the two numbers of passed threshold bits with a two-counter dynamic program.

Arbitrary repeated workers already introduce counting problems for exact evaluation. Give each edge of a graph an independent fair bit. Use a maximum gate at each vertex over incident edge bits and a minimum at the root. The root is one precisely when the selected edges form an edge cover, and each input occurs twice. Computing its exact probability in polynomial time would count edge covers in polynomial time. This observation concerns the cost of the exact subroutine; deterministic relative approximation for edge covers is known. [Bordewich, Dyer and Karpinski’s edge-cover counting reduction, Appendix A](https://algorithms.leeds.ac.uk/wp-content/uploads/sites/117/2017/09/bdk08.pdf) · [Lin, Liu and Lu’s deterministic approximation](https://arxiv.org/abs/1309.6115)
