# Validity of a solver's own parity shortcut

**Research journal, 24 November 2026.** Suppose that a fixed deterministic RAM program $B$ decides packed binary 3-SAT in $O(N\log^a N)$ time for some fixed $a\ge 0$. A targeted program can always give the same answer, parity, on its own signed cubes while the truth of those cubes follows a selectable pattern. In particular, testing a prospective specialization on every vertex up to any computably prescribed finite size cannot certify it for all sizes. The lower bound here is on the computability of the certification problem. The construction assumes the fast SAT reference. ## The local equation

Fix the signed bounded source, using $B$ for every quantifier elimination, and an evaluator that binary-searches a sorted checkpoint table of address–word pairs, returning zero on misses. At a vertex with prescribed sign $p=\bigoplus_i b_i$, write $v$ for the formula's truth, $o$ for the targeted program's output, and $q$ for existence of an admissible chart giving output $p$. For every sufficiently large $k$ the source gives $v=p\mathbin{\mathrm{xor}}q$. Chart soundness gives $q=1\implies o=p$. Both assertions hold for a target program that makes mistakes. The fixed correct program $B$ determines the bounded source's true acceptance condition even in this case.

Let $h$ be a bit computed on the recognized vertex. Have the target run $B$ if $h=0$ and take a cheaply chartable parity branch if $h=1$. Then

$$q=h,\qquad v=p\mathbin{\mathrm{xor}}h,\qquad o=p.$$

Indeed, if $h=0$ then $o=v$. A passing chart would force $o=p$ and $v=1-p$ simultaneously. Thus $q=0$ and $v=p$. If $h=1$, the real parity computation supplies a passing chart, hence $q=1$ and $v=1-p$. This identifies the formula's truth even at every vertex where its target gives a wrong answer. ## Recognizing the same formula the checker targets

Use a fixed universal bounded source $U$. Its input is a self-delimiting tuple $(t,e,k,b)$ in which $t$ names its checker, $e$ is a public program parameter and the $k$ suffix bits $b$ have separate signed initialization pins. Call the resulting formula $F(t,e,k,b)$. Include a fixed-format, satisfiability-preserving preamble recording $k$ and the family parameters in tautological width-three clauses. One can encode a bit by the sign of the third literal in $(z\lor\neg z\lor\ell)$ and start with length-delimited fields. The ordinary CNF header specifies the field width. The preamble is included in every simulated formula access by the checker. The positions of the $b$ pins are obtained from the rectangular reduction on these parameters. [Packed layout and local word generation](packed-band-transfer.md)

Define the target program $W(t,e)$ from the parameters *before* fixing the checker text. It parses the preamble, requires that it name its own parameters, and compares every packed word of the input against the canonical $F(t,e,k,0^k)$ with exactly the designated $k$ sign positions masked. It recovers the $b$ bits from these positions. Implement the comparison with a polylogarithmic-size table of within-row clause templates and the same constant-time per-word indexing as the packed generator. Sign positions are specified by initialization record indices, so the mask for each packed word costs $O(1)$ operations after setup. Bound parsed lengths by the physical input size and reject impossible dimensions or step counts with capped arithmetic before generating any table larger than $\operatorname{polylog}N$. On a parse failure or mismatch the wrapper calls $B$ on the original input. The same fallback applies whenever $h=0$. Use separate initially blank work banks for $B$ and the recognizer. For fixed parameters recognition costs $O(N)$ time and $\operatorname{polylog}N$ work bits. Parity can be accumulated while scanning or by $k$ subsequent direct probes.

Now let $t_0$ be the text of a checker which, on $(t,e,k,b)$, evaluates its signed chart question about the native program $W(t,e)$ on $F(t,e,k,b)$. Use $t=t_0$. This gives the very same formula on the checker's side and the recognizer's side without inserting the checker's text recursively into its own source. For each fixed $e$, all these programs and formulas are effectively constructible given the fixed $B$. Code or constants for $e$ can be supplied by fixed instruction templates and a finite byte string. For large $k$ its length is at most $\log k$. The bounded interpreter can scan such a description within a polylogarithmic factor. The completed source fits its $R=k\lceil\log_2(k+2)\rceil^J$ clock for the same reason as the signed-cube construction. A constant number of quantifier eliminations use $O((M+k+1)\log^C R)$ time, with $M=\lfloor R/\log^I R\rfloor$, and fixed $I,J>C+3$. This equation is needed only at sufficiently large $k$ for each fixed $e$.

The flag $h=h(e,k,b)$ may be any fixed, uniformly implemented test taking $O(N)$ time and $\operatorname{polylog}N$ work bits on genuine vertices. Give the test an explicit clock if needed. The whole shortcut run, including recognition and this test, has the same bounds. Cut it into blocks of $\lceil\sqrt N\rceil$ steps, and use that block size as the forecast horizon. At each boundary encode the real controller and the sorted nonzero work cells, including all recognizer and test scratch. Their addresses and values use $O(\log N)$ bits apiece. The evaluator obtains each incoming value from this table, and local writes supersede it during replay. The total chart occupies $O(\sqrt N\operatorname{polylog}N)$ bits and one replay costs $O(\sqrt N\operatorname{polylog}N)$. Since $N=\Theta(R\log^3 R)$, both quantities are below $M$ at large sizes. There is no requirement to extract the chart quickly. A decoder incapable of table lookup need not admit this chart. All fallback runs retain the reference solver's unrestricted workspace and worst-case $O(N\log^a N)$ time.

Taking $h=p$ gives an all-unsatisfiable cube at every sufficiently large size. Its targeted wrapper still outputs parity and flips its verdict at every edge. Taking $h=1-p$ makes all vertices satisfiable with the same output pattern. Thus even the complete truth table of *wrapper outputs* on a cube can exhibit full sensitivity while actual SAT truth is constant.

## Two index sets

Let $e$ first index a Turing program started on blank input. Activate $h$ iff it has halted within $s(k)=\lfloor\log_2 k\rfloor$ simulated steps, for $k\ge1$. Ordinary bounded tape simulation costs $\operatorname{polylog}k$ time and space for each fixed $e$. If $e$ never halts, $W(t_0,e)$ agrees with $B$ on every input at every length. If $e$ halts, the target gives the wrong answer on **every vertex of its own cube** at all sufficiently large $k$. Outside the recognized family the target remains correct. Thus the set of wrapper indices for which the wrapper is correct on every one of its own cubes is $\Pi^0_1$-complete under computable many-one reductions. Membership follows by enumerating all $(k,b)$, computing finite SAT truth tables, and comparing with the clocked wrapper. The identical reduction works for correctness on every input. Formulating the all-length property as correctness of the wrapper handles any small sizes before the signed source has enough clock slack.

Consequently there is no computable bound, as a function of the wrapper code length, on the first erroneous cube parameter for wrappers that err. Such a bound would decide nonhalting by checking finitely many finite cubes. A sound, effectively enumerable collection of global certificates cannot certify every correct wrapper in this family. This conclusion permits individual proofs of correctness and finite checks at individual lengths. The earlier trap construction also delayed a first error by an arbitrary halting time. Here every sufficiently large erroneous cube belongs to the signed construction targeting that very program, and every one of its vertices fails together. The general uncomputability of semantic index sets is classical. [Rice, *Classes of recursively enumerable sets and their decision problems*](https://doi.org/10.1090/S0002-9947-1953-0053041-6)

For a second family let $e$ enumerate a computably enumerable set $E_e$. Activate the flag at stage $s$ iff the enumerator finishes printing a previously unprinted element on its $s$-th step. Simulate its first $s$ steps, storing at most the first $s$ tape and output symbols up to constant factors. Check earlier delimiters and compare completed strings in $\operatorname{poly}(s)$ time. This implements the flag within the bounds when $s=s(k)$. Each stage occurs at a finite nonempty interval of successive cube sizes containing $k=2^s$. Thus there is a threshold beyond which the parity shortcut is correct on every vertex iff $E_e$ is finite. If $E_e$ is infinite, infinitely many lengths have the wrong answer on every vertex. Dropping the finite initial sizes preceding the signed equation preserves both equivalences.

Eventual validity is $\Sigma^0_2$-complete, and failure at infinitely many lengths is $\Pi^0_2$-complete, on this indexed family. For membership, goodness at any one $k$ is decidable by exhaustive search. For hardness, any $\Sigma^0_2$ predicate has the form $\exists x\,\forall y\,P(e,x,y)$ with recursive $P$. At stage $n$ find the least $x\le n$ passing every test $y\le n$, using $n+1$ if there is none. These successive numbers are nondecreasing. They stabilize precisely if a witness exists, otherwise they grow unboundedly. A machine that prints each fresh such number enumerates a finite set precisely in the first case. Its stage computation may take arbitrarily long. The wrapper simulates only $\lfloor\log_2 k\rfloor$ ordinary machine instructions, so this unbounded enumerator cost never enters the shortcut clock.

## Cross-checking several solvers

Take any fixed finite list of labels $i$. Add the target label to the preamble and let $W_i$ delegate its own labelled cubes to $B$, shortcut other members' recognized cubes by parity, and delegate other inputs to $B$. At each sufficiently large own vertex local correctness forces $q_i=0$ and $v_i=p$. Hence every off-diagonal parity answer on all these cubes is correct at sufficiently large sizes. Increasing the finite list puts no pressure on its diagonal. In this example every directed edge between distinct labels can pass simultaneously with cheap charts for the answering wrapper. The signed chart on label $j$ checks the computation of $W_j$, so a cheap computation by $W_i$ for $i\ne j$ cannot serve as that chart. This argument alone asserts agreement on the stated large cubes. A fixed external wrapper can shortcut their union above any fixed valid cutoff and delegate everything else to $B$, giving a correct global shortcut on that union.

The signed equation already forbids a correct solver from having a passing chart on its own large cubes. A route to a contradiction would have to force such a chart from a separate property of actual fast computations. The index-set calculation identifies a limit of finite testing for that step. Priority for this application of the signed construction remains unverified.
