# Finding a full SAT model from a weighted range discrepancy

On the original weighted range transcript, any nonzero signed subtotal of annotation errors yields a complete satisfying assignment in deterministic $O(L)$ word time, where $L=\Theta(n\log n)$ is the encoded bit length. In particular every legal unique-model file has a deterministic linear-time search algorithm. On every satisfiable legal file an independent random subset gives a model with probability at least $1/2$ per trial, with the same bound on work per trial. The search uses the physical operands and claims in the original DIMACS. ## Locating an incorrect claim

Let $F_j$ be the true sum at a delivered query $j$ and $A_j$ its claimed answer. Put $h=\lceil\log_2(n+1)\rceil$ and $u=O(n/h^2)$ for the scheduled number of updates. Take any signs $s_j\in\{-1,0,1\}$ whose subtotal $\Delta=\sum_j s_j(A_j-F_j)$ is nonzero. The signs can be provided or generated within the time bound. This includes a random subset, the total over all queries, and the parity-of-claim signs for arbitrary low-bit flips.

Keep the queries with nonzero signs in reverse chronological order. Split their current list into two halves by cardinality. Evaluate the signed subtotal of the first half. If nonzero, retain that half and its subtotal. Otherwise retain the other half with the old subtotal. The process never discards every nonzero discrepancy and terminates at an incorrect $j$.

The time bound uses the actual retained cardinality. In a tested half of size $s$, split the records by sign and compute the two ordinary subset totals by the transposed dominance calculation. Its piece table is built once for the original height $h$. On a list of $s$ points the index thereafter takes $O(1+sh)$ construction time. In the proof of the index, use $s$ in the bound on total points at a level pair, $s/h$ for the heavy-cell count, and keep only the existing coordinate nodes. No length-$n$ array has to be cleared for a new list. Empty lists contribute zero. The count at each update costs $O(h^2)$ and a weight times that count uses at most $O(h)$ shift-adds. A merge of each retained chronological list with the sparse update times supplies the time-prefix lengths in $O(s+u)$ work. Initial parsing and sorting by the bounded logical IDs can use direct-address arrays once before this descent.

Successive list sizes have geometric sum $O(n)$ and there are $O(h)$ tests. Thus all constructions and tests take

$$
 O(nh+u h^3)=O(nh)=O(L).
$$

The integer subtotals and their differences fit a constant number of words. Directly summing the relevant earlier updates once at the located query confirms $A_j\ne F_j$ in $O(u)$ additional operations.

## Materializing the satisfying assignment

Set just the located query selector $J_j$ true. Decode its coordinates and **claimed** two-digit answer into the shared input bits and their dictionary leaves. The comparator and adder circuit computes the **true** answer from the updates. For each earlier update, use its supplied bits. Give every inactive update bank zero, including an absent bank on a legal blank-padded prefix. The physical receipt is true exactly at the selected query record. Set the anchors, reserved-name holes and other fixed variables as the template prescribes. Evaluate the selector chains, dictionary trees, comparisons, masking gates, adders, mismatch and receipt gates in their construction order. The final mismatch is true. This fills all declared variables. Full gate equivalences make this the unique assignment for the chosen $j$.

There are $O(n)$ wires and clauses. Building the variable-indexed bit array and checking every literal of the original printed file takes $O(L)$ word time including decimal parsing. Even printing the signed variable identifiers in decimal fits $O(L)$. Under a single-error or same-sign promise the all-query subtotal detects every positive. Under the low-bit-flip promise the signed subtotal equals the number of errors, with arbitrarily many errors of either sign. For general satisfiable legal files, independent fair subset signs in $\{0,1\}$ give a nonzero subtotal with probability at least $1/2$. Repeat and recover a model on the first nonzero result. The one-trial search can return “inconclusive.” Dovetailing with complete SAT search after template recognition gives an always-correct search/decision program with expected $O(L)$ time on these positive files. The clock conclusion concerns the offline family.

## Deterministic recovery inside a specified candidate set

Suppose a specified subset $D$ of at most $O(n/h)$ query records contains between one and $K$ incorrect claims, for a fixed $K\ge1$. Errors outside $D$ may be arbitrary. A deterministic search takes $O_K(L)$ time even if all errors within $D$ cancel in their ordinary subtotal. An inventory or membership array for $D$ may be prepared during the initial scan.

Use distinct integer query IDs $j\in[0,O(n)]$. For each $r=0,\ldots,K-1$, use one mask for each binary digit position of $j^r$, taking $j^0=1$. The mask retains exactly the records of $D$ with that bit set. There are $O_K(h)$ masks. If all their integer discrepancy totals vanish, linear combination with the binary place values shows that each moment $\sum_{j\in D}j^r(A_j-F_j)$ vanishes. If $k$ errors occur in $D$, $1\le k\le K$, the first $k$ equations on their $k$ nonzero discrepancies have a Vandermonde matrix on distinct integer IDs. Its determinant is nonzero over the rationals. Thus at least one mask detects an error. Apply the preceding descent to its records.

Each mask costs $O(1+|D|h+u h^2)$. The complete scan costs $O_K(|D|h^2+u h^3+h)=O_K(L)$. Powers used for forming masks have $O_K(h)$ bits. For fixed $K$ they can be generated using $O_K(h)$ shifts and additions per candidate and constant-word access to any digit. The machine uses unweighted point counts for every mask. If $D$ is known to contain all errors and their total number is at most $K$, zero in all masks also gives an exact negative decision. The candidate-size bound enters the construction cost for the separate indexes. Power sums and Vandermonde equations have long been used in deterministic sparse recovery. Here the digit masks implement the moment tests through the sparse transposed counts. [Ganguly and Majumder, *Deterministic K-Set Structure*](https://www.cse.iitk.ac.in/users/sganguly/podsrevision.pdf)

The finite audit uses the packed-index implementation for the transposed sums. It checks all 43,524 nonzero signed descents on five queries with each error and coefficient in $\{-1,0,1\}$, 14,080 candidate-set tests for $K=1,2,3$, and one full variable assignment against the parsed physical DIMACS on each of 242 positive files. The finite assignments are reconstructed independently by unit propagation after pinning the anchors and selectors. The linear-time proof uses the explicit wire evaluation above.
