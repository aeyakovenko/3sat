# A linear-time reduction to one Boolean variable per positive pair

Consider the [one-bit guard construction](affine-insertion-at-a-clause-of-an-ordinary-3cnf.md) with its named control and fixed anchors. After substituting the controls of the edited file, remove tautologies and repeated literals, merge duplicate clauses, and let $k$ count the **distinct** remaining binary clauses with two positive literals. Positive units are counted separately. Write $N$ for the original physical input length in bits and $L=\log_2(N+2)$.

**Theorem.** There is a deterministic algorithm that, for $k=O(L^{4/3})$, takes $O(N)$ time on a logarithmic-word RAM and produces an equivalent CNF on at most $k$ variables, of width at most three, with $O((k+1)^3)$ clauses. The shared formula, any knowledge of the easy file's satisfying assignments, and any work done before the edit are unnecessary for the algorithm. The same bound holds directly for any width-three input all of whose ternary clauses are entirely negative.

Indeed, every nontautological data-only ternary in a radius-two context has three negative literals. If it had fewer, setting just its negative variables to one would falsify it on the easy slice. Every clause mentioning the control has width at most two after restriction. The proof below uses just this normal form. For a globally correct width-three solver, first check the fixed clauses that pin the wrapper controls before substituting them, or use the input directly when it already has the stated normal form. Use an ordinary SAT fallback whenever neither check succeeds.

## Selecting the roots of a least model

Deal with an empty clause immediately. Write the positive pairs as $u_j\lor v_j$. Introduce one variable $y_j$ to select $u_j$ when true and $v_j$ when false. A positive unit is always selected. Write every mixed binary as an arc $x\to z$ for its implication $\neg x\lor z$. For a choice of the $y_j$, the least assignment satisfying the units, selected endpoints and all the arcs sets exactly the reachable vertices to true, allowing paths of length zero. All the remaining clauses are negative. If a model with these endpoint choices exists, the least assignment also satisfies every negative clause. Conversely the least assignment, whenever it passes these clauses, satisfies the original formula. A satisfying assignment with both endpoints of a pair true admits either choice.

Use as labels the $2k$ signed choice literals and a permanent true label. At a vertex put the labels selecting it and the permanent label if it is a positive unit. Contract the strongly connected components of the arc graph and propagate unions of the label sets in topological order. The resulting support $S_x$ contains the labels whose truth can force $x$. A negative constraint $\neg x_1\lor\cdots\lor\neg x_r$, with $1\le r\le3$, is equivalent on the least assignment to all the clauses
$$
                \neg a_1\lor\cdots\lor\neg a_r,
                \quad a_i\in S_{x_i}.
$$
If one support is empty the constraint is automatic. A permanent label contributes a false literal and may leave an empty clause. Complementary choices yield tautologies. One may repeat the last vertex to bring a nonempty negative constraint to three positions. The displayed conjunction still has exactly the same truth table. A model of the output is a choice vector. An original model can correspond to more than one choice vector, so this is a decision reduction.

## Producing the kernel in one scan's time

Intern occurring names by a decimal digit trie. Canonicalize each source clause and intern its tuple of at most three signed name indices by stable counting sorts on consecutive integer indices. One may radix-sort by width and by the three positions after padding missing positions. The total work is $O(N)$, including repeated, very long or sparsely numbered input names. After simplification the $M$ distinct nontrivial input clauses used by the algorithm satisfy $M=O(N/L)$. To see this, pick one preimage occurrence in the original file for each different clause. A set of $M$ distinct strings on a finite alphabet has total length $\Omega(M\log(M+1))$. Canonical clause strings here can be obtained by dropping duplicate literals, restricting, and ordering the remaining original decimal tokens. Their total length over the representatives is $O(N)$. For $M\le\sqrt N$ the asserted upper bound is immediate, and otherwise $\log M=\Omega(L)$. Count only vertices still occurring after simplification, at most $3M$.

Let $b=\max(1,\lfloor L/4\rfloor)$. Split the $2k+1$ labels into $g=\lceil(2k+1)/b\rceil$ blocks of at most $b$ consecutive labels. A support is now $g$ word-sized masks. The cost of computing and propagating all supports is $O((M+1)g)$. Use a Boolean table for each ordered triple of block indices. Its key consists of three $b$-bit masks. For each padded negative clause and each block triple, mark the single key formed by the corresponding slices of its three supports. This uses $O((M+1)g^3)$ operations, since the three slices already occupy individual words.

Now expand each marked key only once by taking the product of its three local sets, with $O((b+1)^3)$ work per key. Record its output clauses in a Boolean table on ordered signed-choice triples, keeping the permanent label until final simplification. There are at most $g^3 2^{3b}$ possible keys. Thus the cost including table initialization and expansion is
$$
 O\big(N+(M+1)g^3 + g^3 2^{3b}(b+1)^3
                  +(k+1)^3\log(k+2)\big).
$$
The last term allows physically printing the kernel in decimal. When $k=O(L^{4/3})$, $g^3=O(L)$, and $2^{3b}=O(N^{3/4})$. All these terms are $O(N)$. Small input lengths can be treated directly. Fixed constants in the word width cover the input and linear workspace. The three packed submasks in one key require at most $3b$ data bits. This avoids copying a $k^3$-bit relation separately for every source clause. The general connection between small sets of choices and tractable SAT restrictions is well established. [Nishimura, Ragde and Szeider on Horn and binary backdoors](https://www.satisfiability.org/SAT04/programme/51.pdf)

## Many positive pairs with a small vertex cover

Form a graph on the data variables, with one edge per positive pair. Given any vertex cover $U$ of size $h$, the same algorithm produces a kernel on $h$ choice bits in $O(N)$ time whenever $h=O(L^{4/3})$, independently of the total number of edges. A maximal matching found by a greedy scan gives a cover without additional input. If it has $r$ edges then its endpoints form a cover of size $2r$. For example, an arbitrary number of positive pairs may share the same central variable.

For $s\in U$ let $y_s$ be its guessed truth value. Seed $s$ with $y_s$, and seed each of its positive-pair neighbors with $\neg y_s$. To enforce the false choices, give $s$ one private vertex seeded only by $\neg y_s$ and forbid simultaneous truth of $s$ and this private vertex by a negative binary clause. Keep all original positive units, arcs and negative clauses. If the expanded support test succeeds, each covered edge has a true endpoint and the closure realizes precisely the chosen values on $U$. Conversely the restriction of any model to $U$ seeds only true original vertices. Its closure preserves that restriction and satisfies every negative clause, including the private bans. This construction uses at most two seeding operations per endpoint of each edge, $O(h)$ extra vertices and clauses, and $2h+1$ support labels. The block-table analysis applies with $h$ in place of $k$. One may choose the smaller of this cover and the direct one-choice-per-edge construction.

## A speedup with alternations, and a fixed-core obstruction

There is a complementary verification that avoids constructing the kernel. Let $M$ be the physical length of the hard slice in a locally accessible representation, and suppose a bound $K\ge k$ is given. For each fixed integer $q\ge1$, the normal-form problem has a constant-alternation verifier taking
$$
                 (K+M^{1/q}+1)\,(\log(M+2))^{O_q(1)}
$$
time. It suffices to have indexed clause records with signed identifiers of $O(\log M)$ bits and polylogarithmic access time. It also suffices to use promised well-formed canonical ASCII with at most three distinct variables per clause, one clause per line, single separators, canonical decimal identifiers, and a terminating zero. The latter representation needs no directory, even if a single decimal name has many digits.

Guess at most $K$ endpoint names, represented by token spans in the ASCII file, padded with inactive slots. Universally test that each positive pair contains a guessed endpoint. All positive units are additional seeds and do not need to be listed. The only remaining failure occurs if some negative constraint has all its vertices reached from these seeds by mixed binary implications. A path needs at most $M$ edges. Put $D=2^{\lceil\lceil\log_2(M+2)\rceil/q\rceil}$. To test a path of length at most $D^q$, guess $D-1$ intermediate vertices and universally select one of the $D$ subpaths. Recurse $q$ times down to single edges, allowing zero-length steps by equality. The three paths witnessing a failed constraint can be tested by selecting one of them universally. Negating this whole test exchanges its existential and universal moves. This proves the bound without constructing a table of all reachable vertices. Correctness follows from the same least-model argument as before. Compilers with polylogarithmic local access can be composed with this verifier at polylogarithmic overhead per lookup.

For the canonical ASCII claim, a row assertion supplies a constant number of token endpoints plus its line start. The byte before it is a newline or the start of file. The fixed delimiters, signs, nonzero leading digits, clause terminator and end of line are checked at specified offsets. Universal choice of an internal offset checks all remaining digit bytes; a malformed proposed row has a short countercheck. Equality of two canonical names is equality of lengths plus a universal test on one digit position. An existential assertion of an arc supplies its original row and both endpoint occurrences. The universal positive-pair test may provide its row spans and use an existential index in the seed list followed by a name equality check. These are bounded-depth combinations of a constant number of quantified index and digit tests. No scan of a long identifier is charged to a branch. The promise is on the already interpreted hard slice or on a locally supplied projection of the fixed control settings. The deterministic linear-time parser from the kernel theorem cannot simply be run inside this shorter clock.

Why should a RAM-to-SAT reduction have so few choices? A core that accepts arbitrary raw input pins has an unconditional obstruction. On $3m$ *independent* raw input bits, let the accepting predicate require even parity separately in each of $m$ disjoint triples. A fixed deterministic RAM can test this in one scan. Suppose a single normal-form CNF with $k$ positive pairs represents this predicate by projecting its models onto its $3m$ exposed coordinates, with any number of hidden variables. The exposure may permute the coordinates and complement each independently, with the convention fixed across all inputs. Then
$$
                         2^k\ \ge\ 3^m .
$$
The same inequality holds with $k$ replaced by the size of any vertex cover of the positive-pair graph.

To prove it, fix one endpoint choice per pair. The remaining unary facts, implications and entirely negative constraints are Horn. Their model family is closed under coordinatewise intersection. The projection is still intersection-closed, since intersecting full extensions extends the intersection of the exposed rows. Take the union over at most $2^k$ choices. Alternatively fix the values of a vertex cover of size $h$. Each positive pair is then satisfied, forced to a unit or inconsistent, so its projected branch is again intersection-closed, and there are at most $2^h$ branches.

Under any fixed polarity convention each exposed triple requires either odd or even parity. For odd parity take the three weight-one words. For even parity take the three weight-two words. The intersection of any two different choices in one triple has the wrong parity. Their Cartesian product across all triples gives $3^m$ accepted exposed assignments. Any two distinct product choices differ in a triple, so their coordinatewise intersection is rejected. At most one can occur in an intersection-closed branch. This proves the inequality and it applies unchanged to the remaining whole triples if other blocks are fixed. The closure of Horn model sets under intersection is classical. [Kautz, Kearns and Selman on Horn characteristic models](https://www.cs.cornell.edu/selman/papers/pdf/horn-rel.pdf)

There is a sharp general bound behind this test. Let $\mathcal F$ be a nonempty intersection-closed family of subsets of $p$ coordinates. Suppose any two different members have Hamming distance at least $d\ge1$. Then
$$
                     |\mathcal F|\le 2^{\lfloor p/d\rfloor}.
$$
For each member $j$ having a greatest proper submember $j_*$ in the family, reserve its private difference $j\setminus j_*$. This difference has at least $d$ coordinates. Two distinct such members have disjoint private differences. If a shared private coordinate existed, their intersection would contain it and could be proper below neither member, since every proper submember lies under the corresponding $j_*$. The members would then be equal. There are at most $\lfloor p/d\rfloor$ reserved differences. To see that these members distinguish the elements of the family, suppose $x\not\subseteq y$ and take a minimal $j\subseteq x$ in the family with $j\not\subseteq y$. Every proper submember of $j$ lies under $y$, so $j\cap y$ is its greatest proper submember. The map sending $x$ to the set of distinguishing members it contains is therefore injective. For equality use arbitrary unions of $\lfloor p/d\rfloor$ disjoint blocks each of size $d$, fixing unused coordinates to zero. In particular a represented nonempty relation $R$ of distance $d$ requires $k,h\ge\log_2 |R|-\lfloor p/d\rfloor$. This general statement permits nonlinear relations and any polarity convention.

The bound can approach one required choice per raw bit on a single uniformly easy language. On $p$ input bits take blocks of $B=\lfloor(\log_2 p)/4\rfloor$ bits and require the tail to be zero, treating bounded small $p$ separately. Build a maximal binary block code of distance $d=\lfloor\sqrt B\rfloor$ by accepting allowable words in numerical order. Checking all pairs costs $O(4^B B)=o(p/\log p)$ word steps. Membership then requires a table lookup per block, or $O(p/\log p)$ steps overall. Maximality covers the block cube by balls of radius $d-1$. Each ball contains at most $(B+1)^d=2^{o(B)}$ words, so the product code has $2^{p-o(p)}$ accepted inputs and minimum distance at least $d\to\infty$. The fixed normal-form core therefore needs $p-o(p)$ choices. The same conclusion holds after a bijection of the $p$ pin bits whose inverse changes at most a fixed number of raw bits per single pin flip. The represented relation still has the same size and distance tending to infinity. The argument requires exact representation on all exposed rows.

In a fixed core to which a truthful unit for each exposed input bit is merely appended, this is a bound on the number of positive pairs still present syntactically, before propagation. A compiler that specializes its nonunit clauses to the particular input, propagates the pins, or encodes the data by several jointly constrained pins can escape the premise. The paired-literal transformation on a conventional gate tableau installs a distinct disjoint positive pair for every occurring source wire. Even for a deterministic scan, a construction allocating one wire per step has no general guarantee of a sublinear number of choices. The alternating verifier thus proves a speedup on the stated target representations. A speedup for every deterministic RAM run still needs a representation theorem outside this obstruction.

## Exact relation to the variable exponent of 3-SAT

Define $s_3$ as the infimum of $\sigma\ge0$ for which deterministic width-three SAT on $v$ occurring variables has time $2^{\sigma v}\operatorname{poly}(n)$, where $n$ is the encoded file length. For this identity use scalar random-access algorithms with word width a fixed constant times $v+\log(n+2)$ and the same standard integer instructions as the host. This convention allows exponential-time programs to address exponential workspace. Define $C_d$ for fixed $d\ge1$ to be the supremum of constants $c>0$ for which there exists a deterministic $O(N^d)$ solver on the promised edited inputs with $k\le c\log_2 N$. The word width for the edited inputs is a fixed constant times $\log(N+2)$.

Then $C_d=d/s_3$, with value $+\infty$ if $s_3=0$. It is an identity of suprema and makes no assertion at a finite endpoint. For the lower bound on $C_d$, choose $\sigma>s_3$ with $c\sigma<d$. The kernel has $O((k+1)^3\log(k+2))$ encoded bits, so the polynomial factor on the kernel is absorbed by the strict exponent slack. For any fixed $c$, its word width is at most a constant times the host width. A sufficiently large fixed host word coefficient suffices. Smaller guest widths can be implemented by masking their results and using their actual signed comparisons.

For the converse, densely rename an arbitrary $v$-variable 3-SAT input, keeping only distinct clauses. Short clauses can be made proper triples with the two shared padding names of the [guard construction](affine-insertion-at-a-clause-of-an-ordinary-3cnf.md). This produces a proper source of size polynomial in $v+1$ with at most $v+2$ variables. Apply the paired-literal construction. It needs one distinct positive binary for each occurring source variable, regardless of how many times the pair is printed. Pad the result to an encoded length $N\ge 2^{(v+2)/c}$ within a constant factor for large $v$, using harmless DIMACS comment text or duplicate common clauses in both files. Rounding with any rational target $c'<c$ and taking $c'\uparrow c$ avoids assuming $c$ computable. The padding takes linear time in its output length. A promised $O(N^d)$ solver therefore gives $s_3\le d/c$. Preprocessing a source with many repeated clauses costs at most a polynomial in its original length and is covered by the definition. The converse invokes the promised solver only on valid instances.

As an explicit published bound, Liu gives deterministic $O^*(1.32793^v)$ time, hence linear edited-file time for every $c<1/\log_2(1.32793)$. The journal also cites Theorem 1.1 of the October 2026 OpenAI preprint, which states a deterministic bit algorithm for width three with runtime polynomial in $v+m$ times $2^{O(v\log\log v/\sqrt{\log v})}$. Taking that external theorem as stated gives $s_3=0$. The quantitative kernel additionally gives a single linear-time solver when
$$
 k\le a(\log N)\,\frac{\sqrt{\log\log N}}{\log\log\log N}
$$
for a sufficiently small fixed $a>0$ and sufficiently large $N$. This follows by substituting the bound into the exponent, choosing $a$ to leave room for the polynomial prefactor. This range lies below the physical $O(L^{4/3})$ kernelization limit. The upstream counting algorithm is an imported theorem here. [Liu, *Chain, Generalization of Covering Code, and Deterministic Algorithm for k-SAT*](https://arxiv.org/abs/1804.07901) · [OpenAI, Theorem 1.1](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex)
