# Locating a rare priority award in a short public window

The [signed priority computation](priority-pinned-sat.md) has public, disjoint windows in which a zero is guaranteed to occur. Inside every sufficiently late such window there is a particular zero whose winning program signals immediately, and there is also a default one. On a logarithmic-word RAM a sound search procedure for **either** sign still takes $\Omega_D(2^j)$ steps whenever it returns a scale $j$ in a sufficiently late window. The offset of the particular zero is the unique designated output of a satisfiable ordinary 3-CNF. This isolates the computational cost of eligibility and higher-priority competition even when the accepting computation of the winner is short.

## What is guaranteed inside the window

The active prefix at stage $i$ has length
\[
  a_i=\lfloor\log_2(2+\lfloor\log_2(i+4)\rfloor)\rfloor .
\]
Choose the infinite syntactic family of requirements $e$ asking for color zero whose program has an unconditional signal as its first instruction, with arbitrarily many unreachable instructions after it. These are distinct program texts in the fixed enumeration. We only need indices with the specified immediate signal uniformly recognizable by inspecting the short enumerated text. For all large $e$ the first active stage for index $e$, with indices starting at zero, is
\[
 A_e=2^{2^{e+1}-2}-4.
\]
Indeed $a_i>e$ is equivalent to $i+4\ge 2^{2^{e+1}-2}$. A scan for the first instruction and the interpreter setup for the short text fit the assigned $\lfloor 2^i/2^{e+1}\rfloor$ budget throughout this window. For the fixed length-order enumeration the relevant program text is at most polynomial in $e+1$. The activation gaps are so large that exactly the first $e+1$ indices are active at every stage in $I_e=[A_e,A_e+e+1]$.

Requirement $e$ is unretired upon activation. Every stage before it wins is won by a different, permanently retired index below $e$. Thus it wins exactly once, at a stage $J_e\in[A_e,A_e+e]$, and $b_{J_e}=0$. Moreover, at most $e+1$ stages of $I_e$ can have any award. Some stage has the default value one. This gives two finite countdowns, one for eligible predecessors and one for all remaining requirements. [Lean check](../lean/ActivationWindow.lean)

## A total short-output search problem

Give a deterministic finder the index $e$, the scale $A_e$, and random access to the virtual all-zero input of $2^{A_e}$ bits with its native logarithmic word width. It can compute $A_e$ from $e$ in this model, or take both as metadata. Let its fixed requested sign be $d$. It may abstain. Every valid output must name $j\in I_e$ with $b_j=d$. There is a constant $c_D>0$ such that every returned answer at sufficiently large such $e$ takes at least $c_D 2^j$ steps. This holds also for the unique task of outputting $J_e$.

To prove it, build a sound detector for sign $d$ on the original scale $j$. From $j$ compute $a_j$, $e=a_j-1$ and $A_e$, reject unless the index and window have the stated form, then run the finder on its prescribed virtual input. Signal only if its answer equals $j$. On a true window this simulation costs $O_D(t+\operatorname{poly}(j)+2^{j/4}\operatorname{poly}(j))$ for $t$ timely guest steps. An input word of the earlier scale fits in the host width. The [priority machine normalization](priority-pinned-sat.md) handles alternative fixed width coefficients and sparse addresses. The tester's input bank is virtual. The simulation does not spend $2^{A_e}$ steps preparing the finder's zero array. The signed detector bound gives the result. A matching total finder can replay the original computation in stage order, retaining the retirement list, and stop on the first sought stage. Its work through the returned stage is $O(2^j)$. For the particular $J_e$, stop on the award to $e$ itself. In particular a small set of possible answers and a positive trace for the winning signal do not furnish a fast sound method of locating the award.

## Ordinary formulas and prefix restrictions

There is an unconditionally satisfiable ordinary 3-CNF $C_e$ with $\lceil\log_2(e+2)\rceil$ designated output bits which have the same values in every satisfying assignment. They encode $J_e-A_e$. A fixed bounded program guesses this offset, rejects out-of-range encodings and accepts only if simulating the priority computation through that stage yields an award to $e$ there. The previous countdown proves both existence and uniqueness of the designated output. Apply the [locally readable bounded-computation compiler](packed-band-transfer.md) with public scale metadata, implicit all-zero input and a common clock $H=C2^{A_e+e}$ for sufficiently large fixed $C$. The source width is $O(\log H)$. The original small-stage arithmetic is normalized when replaying on the common host. Use the guess bits as designated formula bits. With the ordinary regular padding, the length is
\[
 N_e=\Theta(2^{A_e+e}(A_e+e)^3)=\Theta(2^{A_e} A_e^3\log(A_e+2)).
\]
Each input word can be generated after setup polynomial in $A_e$. Uniqueness here concerns only the designated bits. The compiler may permit different switch settings for its routing network.

Even given the promise, the public index and scale, extracting just the designated bits on this family costs $\Omega_D(2^{J_e})$ at each sufficiently large family member. In particular it costs $\Omega_D(N_e/((\log N_e)^3\log\log N_e))$. Simulate a purported extractor with virtual access to the formula, then return the indicated scale. The same native width normalization and sublinear startup apply. The satisfiability decision for the unpinned $C_e$ is always yes. Since the designated word is unique, a SAT oracle can read it using $O(\log(e+2))$ **nonadaptive** queries, each restricting one bit to one. With arbitrary multiplicity of valid offsets, adaptive prefix queries work. A proof of totality on its own supplies no designated bit.

More generally, suppose a fixed bounded nondeterministic verifier on this window can emit a witness consisting of an offset of the requested sign and auxiliary data. Assume every successful output is a genuine offset, including at windows where the verifier may have no witness. If a window contains even one successfully certified offset under a common cap $K_e$, one ordinary CNF can guess both the offset and the accepting branch, with $O((K_e+1)\log^3(K_e+2))$ encoded bits when $K_e$ is a fixed positive power of $2^{A_e}$ up to logarithmic factors. Here the physical public input to the compiled verifier consists just of the scale metadata. A guest load of an inert large zero input is generated directly. Solve the formula, then restrict its output by prefixes to obtain some genuinely certified offset. This yields a sound partial finder.

Consequently, under $O(N^k)$ deterministic time for explicit SAT, $k\in\{1,2,3\}$, such a verifier cannot have a successful branch in infinitely many of these windows under a constructible cap $K_e=\lfloor 2^{A_e/k}/(A_e+1)^C\rfloor$ for sufficiently large fixed $C$. Use a rounded dyadic cap with the same order if needed. The $O(\log(e+2))$ SAT calls, the logarithms from their encoding, and polynomial-in-$A_e$ setup fit in $o(2^{A_e})$ steps on windows yielding an answer. A negative first answer causes abstention. One can instead pin a particular candidate offset and perform a single SAT call in the one-sided detector on its scale. This restriction applies when only one of the several true returns admits a small proof. The unconditional formula above uses the full priority clock. A uniformly sound certificate with the smaller cap on infinitely many windows remains missing.

The unary nondeterministic time hierarchy produces bounded languages outside a smaller nondeterministic time class. It does not supply such certificates for a fixed priority language. The lower bound on the finder follows from the deterministic priority theorem at its *returned* scale.
