# Opposite SAT verdicts that first diverge at the last input load

Fix any correct deterministic word-RAM SAT program. In the compact triangle-existence DIMACS family, for **every** positive table side there are a genuine rejecting input and a genuine accepting input, one physical data bit apart, with the same execution through the address of the load that finally covers every varying bit. For a second family with $M$ independent physical data bits and $N=\Theta(M)$ encoded bits, every such program has at least $2^{M-o(M)}$ **disjoint pairs** with this property. A single globally correct program handles all members of the second family in $O(N/\log N)$ steps. No runtime assumption or space restriction is imposed on the program in the lower bounds. [Physical triangle construction](three-lookups-and-the-multilinear-sat-verdict.md)

## A dimension successor for every solver

Write the three part sizes as $a,b,c$. There are $M=ab+bc+ca$ independent edge bits, each in a distinct physical position. SAT means that some tripartite triangle exists. For $a\ge2$, interchange two vertices in the first part. Nonfixed files pair under this involution with the same verdict. In a fixed file the two vertices have identical incident edge data. Deleting one gives a bijection with the files of sizes $(a-1,b,c)$, preserving triangle existence in both directions. The parity of the number of accepting files and the parity of the number of rejecting files therefore each survive the successor. Apply this argument in all three parts. At $(1,1,1)$ the eight files have one acceptance and seven rejections. Thus both counts are odd at **every** positive triple of sizes. Unequal sides can use a square compact template padded to the next power of two with all nonhost edge positions fixed to zero.

For a fixed run, the original input words actually read determine every subsequent instruction, address and memory reply. The files on this physical cube giving a fixed terminating transcript form a subcube: they agree exactly on the varying input bits covered by those loads. Count the raw returned words even for instructions that discard some of their bits. The trace class has even size if one or more of the $M$ bits was never read. Oddness on each verdict forces an odd number of files on that verdict whose genuine runs read all $M$ bits. This uses literal, independent physical positions. No restriction on the order or adaptivity of the loads is needed. The same transposition works for a fixed vertex-colored pattern with a separate part per vertex and a separate table per pattern edge: duplicating a color representative preserves existence of a colorful copy. Colored subgraph isomorphism and decision-tree evasiveness have an extensive literature. [Kush and Rossman on the colored problem](https://arxiv.org/abs/2004.13302) · [Bollobás on complete-subgraph evasiveness](https://doi.org/10.1016/0095-8956(76)90021-6)

More generally one may cycle a prime number of vertices in one part and count orbits modulo that prime. Fixed graphs collapse the repeated vertices. For the integer signed sum introduced next, the orbit calculation includes the signs of the fixed edge orbits. The technique of computing alternating graph enumerators this way is established. [Döring, Marx and Wellnitz, Corollary 4.7](https://arxiv.org/abs/2311.08988)

## An integer bound on disjoint pairs of real executions

Let $f$ be the verdict on any independent physical $M$-bit cube with $M>0$. Its top multilinear coefficient over the integers is

$$J(f)=\sum_{x\in\{0,1\}^M}(-1)^{M-|x|} f(x).$$

There are at least $|J(f)|$ disjoint pairs of one-bit-neighbor inputs of opposite verdict, where both runs first cover all $M$ varying bits in the same input load and have identical history up to the address of that load. This applies even if execution continues for arbitrarily long after that event.

Truncate each execution just **before** the first load whose return would finish covering the varying bits, or when the computation halts if it never does. The resulting classes partition the input cube. An early halting class contributes zero to $J(f)$ since the verdict is constant and a free bit cancels its signed sum. In each remaining class $C$, all of its nonempty set of free bits are in the next word. Choose one of them and match all completions by flipping that coordinate. Each pair contributes zero if its verdicts agree and either $+1$ or $-1$ otherwise. Thus at least $|J_C|$ of these disjoint pairs have opposite verdicts, where $J_C$ is the signed sum on $C$. Summing over classes gives at least $\sum_C|J_C|\ge|J(f)|$ pairs. On every such pair the data difference is an actual physical bit and both runs reach that same load. The odd triangle census implies that its $J(f)$ is odd. The proof works for a program of any finite stored size.

For a small quantitative example, the three $2$-square tables have $J(f)=-3$. Here is a computation independent of enumerating the 4,096 files. Fix the first two tables, then alternate over all third-table bits. The inner sum is zero unless **every** third position completes a triangle; in that case its contribution is the negative of the alternating weight of the empty third table. For two nonempty first-table row masks, let $s$ be the signed sum $\sum_y(-1)^{|y|}$ over two-bit columns $y$ meeting both masks. When both masks are full, $s=-1$. When both singleton types occur, $s=1$. When exactly one singleton type occurs, $s=0$. Empty rows also contribute zero. Summing over the two allowable columns of the second table yields $s^2$; the row weights are $+1$ for the full-full case and $+1$ for each of the two orders of the singleton types. Including the preceding minus gives $-3$. For the OR of $k$ disjoint copies the top coefficient has magnitude $3^k$ by the identity $\mathrm{OR}=1-\prod(1-f_i)$.

The dense triangle family itself has a subcube with exponentially many disjoint pairs where **two entire tables** must be read. For side $d$ divisible by three, split the first two vertex parts into corresponding groups of three. Freeze first-table entries outside corresponding group pairs to zero. Each triangle now belongs to one $3$-by-$3$-by-$d$ problem. Its 9 first-table bits and its $6d$ other entries are disjoint from those for any other group, even though all groups use the same third vertex set. The restricted verdict is an OR of $d/3$ independent predicates. There are $2d^2+3d$ live bits.

For one $3$-by-$3$-by-$c$ predicate, the same alternating-sum calculation has magnitude at least $6\cdot2^c-506$. For each of the 512 first-table matrices form the signed sum $R$ of the three-bit columns that meet each of its three row masks, with weight $(-1)^{|\mathrm{column}|}$. After summing the third table the remaining signed expression, up to a global sign, is $\sum_A(-1)^{|A|}R(A)^c$. An empty first-table row gives $R=0$. Otherwise, if $q$ singleton columns and $t'$ doubleton columns meet every row, $R=t'-q-1$. Upward closure implies $-1\le R\le2$. The value two requires every doubleton and no singleton. Each row must then have at least two entries and the three different missing elements must all be witnessed by a row. Precisely the six permutations of the three two-element rows work. All six matrices have positive sign. Each other matrix contributes at most one in absolute value. Taking products over the $d/3$ groups gives $2^{\Omega(d^2)}=2^{\Omega(N)}$ disjoint opposite-verdict pairs in the original compact triangle template. On each pair the solver reads **every** live bit by the common last-covering load. Validating this subcube and testing its triangles by inspecting at most nine first-table pairs for each group and each third vertex takes $O(N)$ total native time. The frozen-cross-edge condition can be verified in the same scan.

The exact signed sum for a $3$-by-$3$-by-$c$ block, $c\ge1$, is $6\cdot2^c-18-7(-1)^c$. Enumerating its 512 possible first matrices gives signed multiplicities $-7,19,-18,6$ at $R=-1,0,1,2$ respectively, with sign $(-1)^{|A|}$. As $9+6c$ is odd, the overall sign in this convention is positive. The preceding exponential lower bound uses just the six extremal rows and needs no enumeration. The finite audit also checks 144 rectangular dimensions and compares the pairing argument against adaptive bit and word probes.

## Nearly maximal multiplicity in linear encoded length

Take $k=2^s$, $b=s$ and $M=kb$ mutable bits, arranged as $k$ blocks of $b$. Accept if one block has at least $t=\lceil b/2\rceil$ ones. The integer top coefficient of threshold on a single block is

$$\sum_{j=t}^b(-1)^{b-j}\binom bj=(-1)^{b-t}\binom{b-1}{t-1}.$$

Pascal's recurrence cancels every interior term. For the OR of all blocks the absolute coefficient is therefore $\binom{b-1}{t-1}^k$. Since this central coefficient is at least $2^{b-1}/b$, the disjoint one-bit pair count is at least $2^{M-k(1+\log_2 b)}=2^{M-o(M)}$. There are at most $2^{M-1}$ disjoint pairs of distinct points in the cube. The lower bound concerns the exponent of the number of pairs; it does not assert that a positive fraction of uniformly sampled inputs has the last-load property.

In individual bit probes the pair count for the block threshold is sharp. Read each block until either $t$ ones or $b-t+1$ zeros have appeared and stop at the first passing block. A fully read block has exactly $t-1$ ones in its first $b-1$ bits. For the first $k-1$ fully read blocks to fail their last bits must be zero. The final bit of the final block supplies the only remaining choice. Thus the number of full-read inputs on each verdict for this algorithm is exactly the stated product. For one monotone $b$-bit predicate, a central threshold also maximizes the absolute top coefficient among all choices of predicate. Its average verdict on the weight-$j$ slice is nondecreasing in $j$ by coupling adjacent slices along a random increasing chain. Express these averages by the sum of their nonnegative successive increments (with a possible initial constant). Their alternating binomial sum is then a weighted sum of threshold coefficients, with total weight at most one. This proves the optimum.

For a physical DIMACS realization use $s$ free index variables to select a block and $b$ proposed payload variables $v_q$ at that block. Fix a power of two $h=\Theta(s)$ with $h\le s/8$ at large $s$. Let the low $\log_2 h$ selector bits give an offset and the high bits give a group $g$ of $h$ consecutive blocks. Use deterministic prefix decoders of $O(k/h+h)$ gates for the high-group and low-offset flags. For each slot $q\le b$ and each $h$-bit mask $m$, define the library variable $S_{q,m}=[v_q=m[\mathrm{low}]]$. For every low offset its flag forces this equality or its complement by two proper ternary implications as in the earlier compact construction. Its value is unique on *all* library wires, including those unused by the data. For each $q,g$ include a clause requiring $S_{q,m}$ when group $g$ is active, where $m$ is the $h$ actual payload bits for that group and slot. The data portion of its decimal name consists of $h$ characters 0 or 1. Each source bit appears in a different ASCII low bit and appears just once. Pad short clauses with distinct forced-false anchors and pin unused declared identifiers. A deterministic Boolean sum and comparison on the $b$ proposed bits requires their threshold to pass. For each choice of block there is one satisfying assignment precisely when its threshold passes.

Use the fixed decimal bank prefix for $q$ with an $h$-digit suffix as in the previous chunk encoding. The $bk/h$ data clauses each cost $O(s)$ bytes. The fixed clauses for the decoders, mask definitions, fillers and threshold circuit take $O((k/h+bh2^h+b10^h+\mathrm{poly}(b))s)=O(k)$ bytes. Here $10^h\le k^{(\log_2 10)/8}$ and $b=s$. Reserve a disjoint interval for the remaining gate identifiers and include a short dimension comment. The entire file therefore has $\Theta(M)$ bits, on every input. [Independent digit and decoder construction](compact-bit-projection-of-matrix-mismatch.md)

One globally correct SAT program runs in $O(N/\log N)$ steps on **every** file in the cube. Generate and validate the fixed region byte by byte in $O(k)$ time. Cache the decimal representations of the fixed identifier prefixes and flag numbers in packed words. There are $O(k/h+b10^h+\mathrm{poly}(b))$ such identifiers of $O(s)$ bits, so direct digit enumeration also fits $O(k)$. In the data region lay out the $b$ records for one group consecutively. Each record occupies $O(1)$ native words. In a bounded number of shifts and masks check its fixed bytes, verify that the mutable digits differ from ASCII zero only in their low bits, and extract the $h$ low bits in their byte lanes. Pair the extracted words with the correct $q$ in the group. Check all bytes and the exact end of file, even when an earlier group passes.

For each group compute the $h$ threshold verdicts in parallel. A Boolean circuit of $O(b)$ gates sums $b$ bits and checks the threshold. In each weight column replace three bits by two with a full adder; this decreases the total wire count by one. When at most two bits remain per column, add the two remaining binary integers and compare in $O(\log b)$ gates. Prepare this schedule once in $\mathrm{poly}(b)$ time. Run it with wordwise Boolean operations on the $h$ occupied lanes, masking the complement at those lanes if needed. Some nonzero final lane means an eligible block. With $O(k/h)$ groups this costs $O(bk/h)=O(k)=O(N/\log N)$. A complete SAT procedure decides files that fail validation. In the other direction a covering load can expose at most $w=\Theta(\log N)$ of the $M$ varying bits, so each paired execution must take $\Omega(N/\log N)$ steps. All these files can consequently be handled in optimal packed scanning time, despite the number of late opposite-verdict pairs.

For four blocks and two-offset decimal names, an exhaustive check rendered every file for the one-of-two and two-of-three thresholds. In the two-of-three case, the SAT solver found 8,192 full models on 3,840 of the 4,096 files, exactly one per qualifying block. All 24,576 cube edges changed one physical ASCII bit. Of these edges, 1,536 changed the verdict, including 128 disjoint pairs that differ at the final editable bit of an increasing-address scan. The measured integer top coefficient was −16. The one-of-two case had coefficient −1, with all 256 files and 1,024 one-bit edges checked. [Physical threshold audit](../audits/compact_threshold_pair_audit.py)

## One explicit file for all solvers

The files forced by the parity argument may depend on the solver. There is also a particularly sensitive **fixed** triangle-free input. For equal side $d\ge2$, choose one center in each part. Include exactly the interpart edges between a center and a noncenter. This graph has $6(d-1)$ edges. It has no triangle because its edges connect centers to noncenters. Every missing noncenter–noncenter interpart edge creates precisely one triangle, completed by the third center. Every missing center–center interpart edge creates $d-1$ triangles. Thus on the same rejecting file every correct solver must fetch all $3d^2-6d+6$ absent data positions. The maximum of the minimum bit-certificate size for a negative file is precisely this number. Indeed one may extend any negative graph to a maximal triangle-free subgraph; its absent edges give a certificate, and the minimum size of such a maximal graph is $6d-6$ by the tripartite saturation theorem. [Ferrara, Jacobson, Pfender and Wenger, Construction 2 and Theorem 5](https://arxiv.org/pdf/1408.3137)

Choose uniformly a single new noncenter–noncenter edge. These $3(d-1)^2$ physical one-bit repairs all have a unique satisfying assignment. On the baseline rejection, at most $w$ new designated repair bits can be inspected per load. The accepting run on the random repair copies the baseline up to its first covering query at that bit, so its expected elapsed time is at least $(3(d-1)^2+1)/(2w)$ steps in the one-input-load-per-step convention (up to a fixed factor for boundedly many loads). There are only $O(d)$ present edges, inside the sparse neighborhood with the matching packed-clock upper bound. The lower distribution is fixed independently of the solver.

For the isolation question, keep every center–center edge absent and add an arbitrary set $R$ of noncenter–noncenter edges to this same baseline. The number of models is exactly $|R|$ plus the number of triangles entirely in $R$. Each added edge supplies one triangle through the third center. Every other triangle uses three ordinary vertices. Any two edits therefore give exactly two models, despite the large pool of individually pivotal positions. [One-sort upper bound for the two-model promise](one-sort-for-bounded-ambiguity-sat.md)

The counting argument establishes a successor for actual input coverage. The matching programs show its precise limitation as a SAT **time** argument. Even an almost maximal exponent for the number of late pairs is compatible with optimal packed scan time. To exceed linear time in encoded bits, a new invariant would have to charge additional elapsed work on the genuine executions. Priority for the combination of these SAT encodings and last-load pair counts is unestablished. The DIMACS and native clock bounds are manuscript arguments.
