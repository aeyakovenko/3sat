# Verifying dynamic writes between separately reconstructed native blocks

A block may write a fresh word at a secret address, and a later block may select that address only after reading another word. A short block description need not enumerate the potential addresses. Split a native clock $T$ into $h=\lceil T/B\rceil$ chronological blocks and suppose a $d$-bit seed suffices to replay each block of an accepting path. Two constructions below give an explicit, parsimonious proper 3-CNF. The first allows unrestricted overwrites if the replay also supplies the source block for each imported read. The second derives the needed checks without those labels if distinct blocks never write to the same address. Both allow $\Theta(T)$ persistent word writes and $\Theta(T)$ reads. The file has $T^{1-\Omega(1)}$ bits when $B=T^{\alpha+o(1)}$, $1/2<\alpha<1$, and $d\le(\alpha-1/2-\eta)\log_2 T$ for a fixed $\eta>0$. Each physical bit is computable in $B\operatorname{polylog}T$ steps. [Uniform synthesis and proper clauses](compiling-native-blocks-from-short-boundaries.md)

A separate calculation covers an unrestricted solver's own executions. If a correct explicit SAT solver runs in $O(N\operatorname{polylog}N)$ word steps, then for each fixed replay algorithm and each verdict there are actual runs in which the combined block descriptions need $\Omega(T/\operatorname{polylog} T)$ bits, for a polynomially related quasilinear clock cap $T$ specified below. This bound permits arbitrary overwrites and needs no writer labels. An equivalent solver can have a different hard family. ## A native block and its proposed record

Use the usual finite native instruction basis, logarithmic-width words, read-only input, initially zero work memory and a fixed within-instruction access order. Pad halts by a canonical idle event. A uniform deterministic replay algorithm gets the source, block ordinal and proposed seed and produces either failure or a complete record in $O(B\operatorname{polylog}T)$ steps. The record has $O(B)$ native rows, each of polylogarithmic width, including entering and exiting controllers, branch choices and ordered memory accesses. For clear complexity bounds, take $B$ and $d$ to be computable from the clock in polylogarithmic time. The source has polynomial length in $T$, with random lookup of its words.

Independently validate initial and terminal controllers, adjacent block controllers, every CPU instruction, nondeterministic choice, read-only input response and padding. Within a block keep an address dictionary of its latest writes. Check the value of a later read against this dictionary whenever the address already has a write in that block. Call any remaining read an *import*. Repeated imports of the same address before its first local write may remain separate records. In a tagged record, each import claims a strictly earlier writer block or null, and null requires the initial zero word. Other positions have one fixed empty tag. A real path fixes its entire chronological record, including all actual nondeterministic choices and the genuine origin tags when used.

Some seeds may be redundant. Require the selected seed $u$ at each block to be least among the seeds returning the same complete record. For each literal $d$-bit string $v$ use one $d$-input predicate rejecting $u$ if $v<u$ and both replays succeed with identical records. This requires two block replays for a truth-table entry, even if $v$ is the last string in the order. There are $h2^d$ such predicates. Once identical records are canonically represented, each genuine covered accepting path will give one model.

A basic example of the replay hypothesis is a block whose initial controller is reconstructed from part of its seed and its ordinal, whose remaining seed supplies its nondeterministic choices and imported bit-valued responses, and which executes all its own instructions directly for at most $B$ steps. Its computed addresses may depend on its previous imports. More generally the responses can be full words generated online from the seed. The cost of producing those values is part of the block replay time. No structure of this kind is assumed for an arbitrary SAT program.

## Tagged imports with arbitrary overwrites

For every earlier block $i$ and later block $j$, replay both on their proposed seeds. Save the address and final full word for every address written in $i$. For each import in $j$ of address $a$ with reply $v$ and claimed source $k$, perform the following checks.

* If $k=i$, the dictionary for $i$ must contain $a$ and its final word must equal $v$.
* If $k$ is null or $k<i$, the dictionary for $i$ must omit $a$.

A trie with keys of $O(\log T)$ bits uses polylogarithmic work per access. This checks the whole pair within $O(B\operatorname{polylog}T)$, including arbitrary repeated writes and all its imported reads. No address from a proposed execution occurs as a free port of the Boolean relation. Both addresses are calculated in the replays themselves.

If all pairs pass, a nonnull $k$ is the actual latest preceding block to write $a$. For null there was no such block. The within-block checks handle all accesses after a local write. Induction over native time now yields a single legal execution of the specified program on its actual input. Conversely the genuine tags pass every check. This also proves that witnesses cannot be multiplied by selecting different tags for the same path.

## Deriving consistency without writer labels

Suppose instead that all desired paths have at most one writer block per address. This permits multiple writes to one address in that block and arbitrarily many later imports. For any submitted pair of blocks first reject if their sets of written addresses intersect. This check on candidate records is needed even when every genuine accepting path has the property.

For $i<j$, compare every import of $j$ that is found in $i$'s dictionary with the last word written there; a mismatch rejects. Compute $c_{ij}$, the number of *nonzero proposed import replies* in $j$ whose address is found in $i$. Let $m_j$ be the number of all nonzero proposed import replies in $j$. Require
$$
                           \sum_{i<j} c_{ij}=m_j.
$$
Disjointness of writer address sets makes every nonzero import count at most once. Equality forces it to count once, and the matched full value has already been checked. A zero import either has a matching zero writer, or correctly uses initialization. A write after the read does not appear in this sum. Repeated reads at the same address are counted with their multiplicities. Thus the same induction over actual native steps proves soundness.

Use $O(\log(B+2))$ auxiliary bits per $c_{ij}$, each constrained to equal its corresponding two-seed predicate bit. Do likewise for the one-seed counts $m_j$. A fixed ordinary adder circuit per reader performs the sums at width $O(\log(T+2))$, retaining enough bits for all candidate values. Its gate equivalences and all count bits have exactly one possible completion.

A program can arrange unique writer locations at logarithmic elapsed-time overhead. Simulate mutable work memory with a persistent binary trie on actual word-address bits. For each store, descend the old trie, pushing its path onto a fresh immutable list. Pop this list by following links and create the new root path in previously unused physical words. A load just descends the current root. Registers hold the root and the next allocation address. The stack, child pointers and values are each written only once; unallocated branches stand for zero. The simulated program retains its branch choices. This gives $O(Tw)$ native time and allocated words for $T$ original steps with $w$-bit addresses on a host with enough address bits, as on the polynomial clocks used below. The persistent version's block seeds must still recover the values and controllers it actually uses. This transformation supplies no bound on their length. ## Physical formula and accepting counts

The local and adjacent-controller predicates have at most $2d$ inputs. The pair predicates above have $2d$ inputs, or $2d+1$ when testing a specified auxiliary output bit. Each truth-table entry needs at most a constant number of complete replays and dictionary passes. The explicit row-library construction gives a raw proper DIMACS formula with
$$
 O\!\left(1+h^2(1+2^{2d}/(d+1))\operatorname{polylog}T\right)
$$
bits, including all decimal names and the adder circuits. The $h2^d$ canonical-seed predicates above cost $O(h2^d(1+2^d/(d+1)))$ gates together and fit the same bound. Reserve regular slots for all ordered block pairs, for candidate seeds and for adder levels, using a constant true clause or a fixed gate for padding. Counts, masks, subtemplates and their address arithmetic have polynomially bounded indices. A single byte touches at most one table row, whose $O(d+1)$ entries each cost $O(B\operatorname{polylog}T)$. The header and all section lengths are indexable directly. Each gate relation has a unique internal extension, including at unused outputs. [Physical indexing construction](compiling-native-blocks-from-short-boundaries.md)

The exact model count equals the number of accepting native paths all of whose true blocks have a seed, with the stated writer convention. When the source is unambiguous, coverage of the one accepting path suffices; on a rejecting input even completely spurious proposed seeds cannot create a model. For the parameters in the introduction, $h^2 2^{2d}\le T^{1-2\eta+o(1)}$; all remaining logarithmic factors are absorbed in the polynomial saving. Applying this compiler to a persistently simulated $O(t)$ computation with clock $T=O(t\operatorname{polylog} t)$ also leaves a polynomial saving relative to $t$ whenever its replay premise holds.

## What fails on the solver's own hard files

Let $J$ be the deterministic square-clock self-input diagonal on physical input $x$ of $n$ bits and set $t=n^2$. Its regular locally indexed proper 3-CNF $F_x$ has verdict $J(x)$, length $N=t\operatorname{polylog}t$, and formula words available from $x$ in polylogarithmic time. Fix a correct deterministic SAT program $D$ taking $O(N\log^a(N+2))$ time, for any fixed $a\ge0$. Choose a computable padded native clock $T=t\operatorname{polylog}t$ covering its whole run on this layout. Fix $0<\alpha<1$ rational and use $B$ a computable integer within a constant factor of $T^\alpha$. [Diagonal, clock and proper-file layout](native-linear-time-and-locally-uniform-circuit-depth.md)

Fix a replay algorithm and allow an arbitrary common advice string and individual seeds of variable lengths. The total submitted bits, inclusive of the common string and directories, are $S$. The replayer sees $F_x$ and may use $O(B\operatorname{polylog}T)$ steps per selected block, including to read its advice. It suffices that on the proposed successful description it recovers each actual block record. Put an effective cap on all trials. The record here contains native instructions, controller and access replies only. Neither writer tags nor single-writer locations are required.

Given the descriptions, a constant number of alternations decides whether the resulting records constitute a genuine $D(F_x)$ run of verdict $b$. A local transition, a failed replay, an input or a boundary error can be witnessed at one block or block pair. For a memory defect, existentially nominate a read and its purported latest preceding write, or null. Check that the write is earlier, has the same address and stores a differing value; for null, the proposed read must differ from zero. Universally test that no strictly intervening write has the read address, including within-instruction order. With null, test all earlier writes. Every leaf needs only the relevant block replays. If the read is genuinely wrong, its actual latest write gives this witness; if a more recent write exists, the universal test refutes that nomination. Negating the defect test and existentially guessing the descriptions adds only a fixed number of quantifier blocks. A true result certifies the reported verdict independently of decoder behavior on other inputs.

At each fixed existential level, the ordinary bounded-run reduction and $D$ deterministically decide the bounded nondeterministic computation in time quasilinear in its payload and clock. Eliminate a universal level by complementing the contrary existential test. The depth is constant. Physical inputs to the leaf tests consist of $x$, the claimed descriptions, indices and the clock in binary. Queries to the longer virtual formula are computed from $x$. Consequently the deterministic test for a description of at most $P$ bits and the specified verdict costs $O((n+P+B)\log^C(T+2))$ for a fixed $C$. If variable-length seeds use an offset directory, its $O(h\log T)$ bits fit within a polynomially sublinear lower-order term. Choose $P=\lfloor t/\lceil\log_2(t+2)\rceil^{C+2}\rfloor$. The test takes $o(n^2)$ on every input, since $B=t^{\alpha+o(1)}$. [Bounded RAM reduction and fixed alternation elimination](alternating-native-speedup.md)

Write $E_b(x)$ for the answer to this test. For $b=1$, use $E_1$ as the opponent in the diagonal. Everywhere on its own code prefix at sufficiently large lengths, $J(x)=1-E_1(x)$, while $E_1(x)=1$ implies $J(x)=1$. Hence $J(x)=1$ and $E_1(x)=0$ there. For $b=0$ use $1-E_0$ as opponent; $J(x)=E_0(x)$ on its prefix, and $E_0(x)=1$ would imply $J(x)=0$. Thus $J(x)=0$ and $E_0(x)=0$ there. Each prefix can depend on the solver, the requested verdict and the fixed decoder.

On these actual positive and negative SAT files, even preprocessing chosen separately for the exact input must supply more than $P$ total bits if the block replies are to be recovered on the stated clock. As $T/t$ is polylogarithmic, this is $\Omega(T/\operatorname{polylog}T)$ total bits. In the absence of a large common string, some block needs $\Omega(B/\operatorname{polylog}T)$ bits. Supplying only $O(\log T)$ bits for each block cannot work. The rejection-side trace obstruction is closely related to the earlier hard-table construction. The signed argument here applies directly to each solver's own runs and both verdicts. A compression that preserves the SAT decision while discarding part of the executed trace remains a different mathematical question.

The same physical test accepts a charged directory of increasing, input-dependent boundaries: check that they partition the whole clock, that each block has length at most $B$, and that its record covers exactly that interval. Thus choosing cuts after seeing the run cannot evade the total bound when the directory is included. On the fixed grid take a decoder supporting a tagged fallback that copies a literal complete block record of $O(B\log T)$ bits. If all but $m$ blocks had individual seeds of length at most $P/(4h)$, using them and supplying the $m$ literal records would cost at most $P/4+O(mB\log T+h\log T)$ bits. The lower bound therefore gives $m=\Omega(h/\operatorname{polylog}T)$ blocks on the same signed run, for this fixed universal choice of decoder. The fallback costs $O(B\operatorname{polylog} T)$ time. The prefix and logarithmic exponents in this assertion are those associated with the decoder that includes the fallback.

## Checks

The finite audit exhausted 32,768 seed tuples against an independently executed native program with a nondeterministic first write, a later address selected by a preceding load, repeated accesses, zero initialization and optional inter-block overwrites. Exactly 56 countable paths survived across all inputs and both checking conventions. CaDiCaL enumerated all complete assignments on eight physical proper 3-CNFs, attaining model counts zero, one and two. [Audit script](../audits/dynamic_block_writes_audit.py)

Lean 4.19 checks the newest-writer characterization for an arbitrary ordered list of block replies, its null case and the coverage identity when each nonzero import counts at most once. The native simulation, compiler costs and signed hierarchy argument are in the manuscript. [Lean proofs](../lean/DynamicBlockWrites.lean)
