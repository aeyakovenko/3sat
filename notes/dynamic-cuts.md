# Information across time cuts and across possible future queries

**Research journal, 2026-11-23.** Can many transfers between earlier and later memory operations force superlinear time for SAT even when a machine may keep everything? There are two different quantifiers. A temporal cut concerns one stream of operations. A dynamic data structure must handle every possible next query from the same stored state. The second requirement yields a lower bound for a restricted SAT interface.

## An exact ceiling for packing adjacent time cuts

Index N successive binary arrivals by 1 through N, with one Boolean output per position. For each pair of adjacent nonempty intervals L,R, give the rectangle L×R a nonnegative weight. Require the total weight on every ordered pair i<j to be at most one. This allows charging every potential last-write/next-read transfer at most once. An entropy charge to this cut using uncertainty in the left bits visible in the right outputs, with the remaining inputs fixed, is at most min(|L|,|R|).

**Cut-packing lemma.** The total weighted charge is at most (N/2) log₂ N. For N a power of two, the maximum of the weighted sum of min(|L|,|R|) equals this bound.

Put F(d)=(d/2) log₂ d for d≥1 and F(0)=0. Give pair i<j mass a(j−i), where a(d)=F(d+1)−2F(d)+F(d−1) is nonnegative by convexity. Summing these second differences across an adjacent rectangle of lengths l,r telescopes to F(l+r)−F(l)−F(r). This equals (l+r)H₂(l/(l+r))/2, at least min(l,r) by concavity of binary entropy between 0 and 1/2 and symmetry. The mass of all ordered pairs is F(N), again by telescoping. Multiply the rectangle inequalities by their weights and sum. For equality, use the two children of each internal node of the balanced dyadic interval tree, with unit weight. Every pair is charged at its lowest common ancestor and each level contributes N/2.

With Θ(log N)-bit words, entropy divided by the bits charged per transferred cell can therefore certify at most O(N) word operations by this calculation. The dual bound concerns congestion on **every possible pair**. A proof bounding congestion only on the memory edges that actually occur could escape it. A cut selected from the observed data also needs a justification for the conditional entropy used after that selection.

The ordered-pair domain is the strict triangular Boolean matrix. Chistikov and colleagues also use a fractional linear program on this matrix, minimizing the cost of covering its entries by rectangles. The packing above instead maximizes transferred entropy under an upper bound on congestion. Priority for the precise packing statement has not been established. [Chistikov et al., Theorem 1](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2017.23)

**Did we lose anything by using one tree?** For 18 positions a fractional packing scores 107/3 while the best interval tree scores 35. Thus the optimization over trees alone misses some feasible charges between powers of two, although the upper bound still applies. The packing below was found by linear programming. Its feasibility and strict advantage can be checked with integer arithmetic independent of the solver. A pair (c,h) denotes the two half-open intervals [c−h,c), [c,c+h) on positions 0 through 17.

```python
N = 18
# Triples give boundary, half-width and three times the weight.
half = [(1,1,3),(2,2,3),(3,1,3),(4,1,1),(4,4,2),(5,1,2),(5,5,1),
        (6,1,1),(6,2,2),(7,1,2),(7,2,1),(8,1,1),(8,2,1),(8,8,1)]
cuts = half + [(N-c,h,v) for c,h,v in half] + [(9,1,2),(9,9,1)]
assert all(sum(v for c,h,v in cuts if c-h <= i < c <= j < c+h) <= 3
           for i in range(N) for j in range(i+1,N))
assert sum(h*v for c,h,v in cuts) == 107
tree = [0, 0]
for k in range(2, N+1):
    tree.append(max(tree[i] + tree[k-i] + min(i,k-i) for i in range(1,k)))
assert tree[N] == 35
```

**Test on an actual computation.** With fair independent bits xₜ, output the XOR of xₜ₋ᵈ over power-of-two delays d with t−d≥1. For *every* boundary with adjacent lengths l,r, put h=min(l,r) and let d be the largest power of two at most h. Restrict to the last d left inputs and first d right outputs. The dependency matrix has ones on the diagonal at delay d. Below the diagonal the delays lie strictly between d and 2d, so all entries there vanish. Even after fixing all other inputs the entropy of these d outputs is d≥h/2. At every equal dyadic cut the maximum h is attained. Power-of-two kernels and information transfer are classical in online convolution. [Clifford and Jalsenius](https://arxiv.org/abs/1101.0768)

This binary problem admits O(N) actual online word operations. Pack blocks of B bits, with B a power of two of order log N that fits in one word. At the start of a block XOR the already stored input blocks at delays d≥B. Each such delay is a multiple of B, so one word per delay supplies every long-delay contribution to the new block. This takes O(log N) operations per block. For delays smaller than B maintain the last B input bits in a rolling word, mask the power-of-two positions, and use a parity lookup. A table for chunks of at most half log₂ N bits takes O(√N) initialization and a constant number of lookups per word. Emit the current bit immediately and then advance the rolling word. Absent initial input blocks contribute zero. Thus even simultaneously high entropy across every adjacent cut occurs in a linear-time online computation.

## A sign-flip interface that does yield a lower bound

On a polynomial-size grid [U]² with at most n inserted points, let aᵢⱼ be the parity of the number inserted at each cell. Build a fixed CNF that forces prefix parities

    pᵢⱼ = aᵢⱼ XOR pᵢ₋₁,ⱼ XOR pᵢ,ⱼ₋₁ XOR pᵢ₋₁,ⱼ₋₁

with zero boundaries. Use binary XOR gates and their width-three equivalences. Pin each a by a unit clause. At every cell add a selector bit s, a unit clause pinning it, and the implication s→p. All selectors initially vanish. Point insertion toggles exactly one input pin. To ask a dominance-parity query, flip the selector at the queried cell, ask whether the formula is satisfiable and restore its sign. The prefix terms are uniquely determined, so this reports precisely the requested bit. Formula layout, variable identifiers and clauses are fixed before any update. The encoded length M is O(U² log(U+2)). If exactly three distinct literals per clause are required, pad short clauses with fixed-false variables as in [the sign-restriction construction](sat-extension.md).

Suppose a maintained SAT instance supports one literal-sign flip in worst-case u cell probes and a decision in expected q probes after polynomial initialization independent of the updates. This gives dynamic two-dimensional range parity with worst-case update O(u+1) and expected query O(q+2u+1). Fixed preprocessing can be treated as known initial memory in the cell-probe model. For w=Θ(log n)-bit cells, Larsen, Weinstein and Yu's Corollary 1 then implies

    q + 2u + 1 = Ω(log^{3/2} n / log³((u+2)w)).

In particular both operations cannot cost O(log M) on all these templates. The polynomial grid gives log M=O(log n). This is a corollary of the published dynamic lower bound. [Larsen, Weinstein and Yu, Corollary 1](https://www.cs.princeton.edu/~hy2/files/RangeCounting.pdf)

**A static consequence for circuit values.** Pad the grid to U≥n, so log M=Θ(log n). Consider any polynomial-size bounded-fan-in, bounded-fan-out Boolean circuit computing SAT at the corresponding lengths. Some single allowed sign flip between valid template inputs must change Ω(log^{3/2} M / (log log M)³) of its gate values, in the worst case along the range-parity instances. Fixed gates and all input bits except the pins may be hardwired. To see this, retain one value per gate. On a flip, schedule successors of the changed input. Process scheduled gates by increasing topological index, avoiding duplicates, and schedule successors only when the recomputed bit changes. Every processed gate has a changed predecessor. By induction in the topological order each receives its final new inputs. If k output or internal gate bits change, bounded fan-out schedules O(k+1) gates. Constant fan-in gives O(k+1) cell probes to read inputs and update values. The circuit topology is fixed and known, and computation and scratch based on an operation's probe transcript are free in the cell-probe model. A polynomial-size circuit needs O(log M)-bit addresses. Maintaining the value at the final gate makes the decision query constant cost. Substitution in the range-parity bound gives the claim if k is polylogarithmic; a larger k already exceeds it. This exposes a specific necessary change in *internal* representations, even though each update changes just one encoded input bit. One changing gate may serve many different updates, so summing this bound over possible flips does not give a circuit-size or running-time lower bound.

### Applying change propagation to the actual RAM trace

There is a corresponding property for **unrestricted deterministic word RAMs**. Take a polynomial clock T(M), and normalize each step to update the program counter and a constant number of word registers with at most one memory access whose address is specified by the pre-step registers. Addresses are polynomially bounded in M because the word width is O(log M). Input reads use the same access mechanism in a read-only region. Pad both runs to exactly T rows and include the answer in the halted control state. A row records the control and register state after the step and its optional event, including address, operation and post-access cell value. Two runs are compared at the same times; changing control flow may change many rows.

**Single-edit replay lemma.** If editing one input word changes k rows, a data structure for a precomputed trace can make the edit and update the complete trace in O((k+1) log log (T+4)) cell probes with polynomial preprocessing and storage. Read the final decision in one more probe.

Keep the table and an ordered set of access timestamps for each possible address. To recompute row t, inspect the previous control row and compute the resulting instruction and address anew. The predecessor timestamp below t for that address supplies the memory value after its previous access. When there is no predecessor, consult initial memory. Initially schedule the first access to the edited input cell, if it exists. Process scheduled rows by increasing t, deduplicating. When row t changes, edit its timestamp memberships as needed and schedule t+1 and the immediate future successor accesses at the old and new addresses, whenever they exist. With unchanged address but changed post-access value its single successor is included. No access occurs on an inert row.

At each stage any row violating its local transition or memory consistency condition is scheduled. Editing one row can introduce violations only at the listed successors, since no other row's control predecessor or memory predecessor can change its supplied value. Earlier rows are therefore correct when a scheduled row is processed. Its recomputed value is final. There are O(k+1) processed rows because only a genuine change adds successors. The timestamp universes are bounded by T. Van Emde Boas trees support the needed ordered-set operations in O(log log(T+4)) probes each using polynomial storage. The temporary schedule can use free local computation on the current update's probe transcript in the cell-probe model. The full preprocessed state is regenerated for the fixed initial input using only polynomial resources; input edits persist between operations. This is a time-aligned form of change propagation, a longstanding technique in self-adjusting computation. [Van Emde Boas, Kaas and Zijlstra](https://par.cse.nsysu.edu.tw/resource/paper/vEB_tree/vEB_tree_76.pdf) · [Acar et al. on computation distance](https://arxiv.org/abs/2002.05129)

Consequently, for every polynomial-clock RAM correct on these templates, a legal single-sign flip must change Ω(log^{3/2} M / (log log M)⁴) time-aligned trace rows in the worst case along the hard sizes. A sign flip edits one input word. If the maximum k is polylogarithmic, substitute u=O((k+1) log log M) and q=O(1) in the dynamic inequality. If k is larger the conclusion already holds. This is a lower bound on how stable executions of a static machine can be across paired inputs. A branch changing early can satisfy it even when the two runs each take only linear time.

**Failed transfer to ordinary SAT.** Static satisfiability on this very family, even with arbitrarily many active selectors, is decidable in O(M) word operations on promised inputs. Read the pins, compute all prefix parities in one grid pass and check the selected cells. Thus small static cost alone cannot imply O(log M) dynamic updates and decisions, even on these formulas. A proof attacking an unrestricted linear-time SAT solver through this construction needs a reason that correctness on *all* formulas gives special reuse across nearby inputs, or a way to charge sensitivity on many nearby inputs to work on one execution. The dynamic theorem by itself supplies no such implication. Its logarithmic exponents refer to per-operation cost after initialization, whereas the SAT target counts the full length on a fresh input.
