# Why compressing a uniquely accepting RAM computation fails at the quadratic and cubic SAT deadlines

Consider a native RAM run with unary instruction clock $t$, a payload of $u$ bits, and at most $\lfloor t^{1/k}\rfloor$ initial binary guesses, where $k=2$ or $3$. After deterministic setup and the guess block the machine is deterministic. Restrict even to inputs on which there is at most one accepting branch and $u\le t^{1/(k+1/8)}$. There is **no uniform compiler** with all three of the following properties.

* Each output is ordinary proper ASCII DIMACS. It has zero satisfying assignments on a rejecting instance and exactly one on the occurring variables on an accepting instance.
* The output length and any individual output bit can be computed in $(\log(t+u+2))^{O(1)}$ time, with random access to the source and its unary clock.
* The output length is $M=o(t^{1/k}\log(t+2))$ uniformly on the promised instances.

Canonical decimal identifiers suffice. Unused declared identifiers are ignored when counting models. The result uses the unambiguous time hierarchy with one bit of advice. It holds independently of the running time of SAT. In particular using such a compiler to exclude quadratic or cubic SAT time would require a compiler that already contradicts that hierarchy. [Van Melkebeek and Pervyshev, Theorem 2 and §4.1](https://eccc.weizmann.ac.il/report/2005/111/download/)

## A shorter verifier, with no SAT subroutine

A formula with $w$ occurring names needs $\Omega(w\log(2+w))$ encoded bits to spell those different names. Set a computable integer upper bound $b=O(1+M/\log(2+M))$ on $w$, using an absolute constant and rounding up. Splitting at $M=t^{1/(2k)}$ shows $b=o(t^{1/k})$ uniformly.

One fixed native verifier $V$ takes the old program, payload and clock in binary. It gets $M$, computes $b$, and guesses exactly $b$ bits upfront. It then enumerates the formula bits, parses the clauses and interns variable identifiers by first occurrence in a decimal trie. It assigns successive guessed bits to the interned names. It checks all clauses and requires every unconsumed guess to be zero. The scanner can evaluate each literal as it is completed. Numbering by first appearance handles arbitrary-length names and avoids allocating memory for a large header declaration. Every satisfying assignment on the occurring variables gives exactly one accepting computation. A binary guess on a word-guess instruction is implemented by immediately rejecting all values greater than one. There is exactly one live encoding of each bit.

For constants $C,B$ depending only on the compiler and fixed verifier, the new clock can be set to the following computable integer round-up:
$$
  h=\max\{1,b^k,\ C(1+u+M)\lceil\log_2(t+u+2)\rceil^B\}.
$$
It covers the guess block and deterministic scan. $b^k=o(t)$, and also $(1+u+M)\operatorname{polylog}(t)=o(t)$ because $k>1$. Thus $h=o(t)$. The old unary suffix is addressed by testing its endpoints. The next physical payload holds the literal old program, payload, and binary clock. No guessed bits or generated formula are carried to the next instance. Each iteration adds $O(\log t+1)$ payload bits, with the fixed program $V$ used after the first round.

## Iteration on an advised hard language

Take an unambiguous tape language in time $n^6$ with one bit of advice and outside unambiguous time $n^5$ with one bit, by the cited hierarchy. Put the appointed advice bit in the payload next to $x$. A fixed native RAM can simulate this tape using at most $T=C_0 n^6$ steps and memory locations. Guess a padded $O(T)$-bit choice log before the simulation. Use a canonical code per nondeterministic move, reject invalid codes, and require unused bits to be zero. This gives one log per accepting tape path. Give the simulation the virtual unary clock $t_0=(C_1 T)^k$ for a sufficiently large $C_1$, so it meets the initial guess and short-payload bounds. On the appointed advice the machine has at most one accepting branch on each $x$.

The outer controller can keep this clock in binary. Apply the preceding transformation while $t>n^4$, choosing the next allowance $\max(h,\lceil n^4\rceil)$. At these clocks the payload remains $n+O(\log^2 n)\le t^{1/(k+1/8)}$. Inductively $h\le t/2$ before the floor is applied, uniformly for all sufficiently large $n$. There are $O(\log n)$ rounds. The controller learns each actual $M$ from the indexer; the little-$o$ rate is not input to the algorithm. The final clock is $\lceil n^4\rceil$. All computation up to the final simulation is deterministic and costs $n\operatorname{polylog}n$ on the RAM. The final simulation preserves the zero or one accepting paths of the initial instance.

Even for $k=3$, the possibly $\Theta(n^{18})$ unary suffix is never printed or stored. Its endpoints use a constant number of $O(\log n)$-bit limbs. The initial simulator touches $O(n^6)$ locations. A checking phase uses at most $O((n+M)\operatorname{polylog}n)$ actual locations, at most $n^{6+o(1)}$ in this construction. Sparse accesses of the local indexer's polynomial-width address range can be simulated by scanning its polylogarithmically many prior writes for each generated bit. Physical payload, guess log and trie use the journal's ordinary address range with width factor 12. On the final instance simulation can stop at its step cap. [Native RAM and word-width conventions](native-unary-clock-band.md)

An unambiguous tape verifies this shorter RAM in $n^4\operatorname{polylog}n$ time. Guess a canonically padded chronological run with actual word choices. Check its instruction transitions and sort the memory records by bank, address and chronological order, including within-step order. Check reads against initialization and the latest write, using the real input words. Deterministic multitape merge passes have polylogarithmic overhead. Each actual accepting computation has exactly one accepted transcript. A fixed slightly larger clock, still below $n^5$, covers the deterministic controller and the final run. The same single advice bit now suffices in unambiguous time $O(n^5)$, contradicting the hierarchy. Only the appointed advice values must satisfy unambiguity and the original time bounds. A fixed faster-side timeout can be imposed on every advice.

## The distinction at linear time

For $k=1$ the same proof excludes $M=O(t^{1-\epsilon})$ for each fixed $\epsilon>0$, and any length bound for which the checker's total scan time and guess count are both $o(t)$. With mere polylogarithmic access to each bit, $M=o(t\log t)$ alone does not bound the scan time by $o(t)$. A separate decision-only criterion uses a hypothetical fast SAT solver to challenge one defect in the assignment. Its missing construction is a local decision-preserving compiler of that length. [Linear-clock criterion and challenge construction](compact-compilers-and-linear-sat-time.md) · [Unconditional obstruction for two batchable indexer classes](packed-verification-of-locally-indexed-unique-sat.md)

There is also a simple obstruction when an arbitrary accepting-branch count must be preserved. A program can guess $g$ independent bits in its initial phase and reject exactly the zero log. With a clock of order $g^k$ and a polynomial choice of $g$ in the short payload length, the odd count $2^g-1$ requires $\Omega(g\log(2+g))$ explicit bits in any parsimonious DIMACS encoding, even with unused identifiers. The hierarchy argument above already applies when all original counts are just zero or one. [Odd-model-count bound](compact-compilers-and-linear-sat-time.md)
