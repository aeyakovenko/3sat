# Tuning the first missing output to have nearly all predecessors easy

**Research journal, 2026-11-24.** Fix any r≥1. There exists an efficient universal decoder whose actual first missing d-bit output w, with d=n or d=2(n−1) and cutoff B=2^(20n), has this property: in **every** trailing interval [w−K,w), at least K−⌊K/2ʳ⌋ positions admit a polynomial-time computable short program. The map from these positions to their programs has a polynomial-time inverse. Thus the fast certified fraction can be arbitrarily close to one by choice of the fixed universal machine. Making the exceptional fraction vanish by increasing r has a matching cost in universal description length.

## A complete choice of decoder

Work at d>r and write M=2ᵈ and m=2ʳ. Use the fixed prefix 1ʳ to invoke an efficient universal interpreter V on the remaining string. It may receive n and r separately. Any fixed ordinary decoder can ignore the extra parameter. The other decoder headers are 0,10,…,1^(r−1)0. Their payload is read to its end. Inputs shorter than r consisting only of ones have no complete header. The construction uses no external advice and is uniform for each fixed r.

Among the M−1 raw strings shorter than d, exactly M/m−1 begin with the universal prefix. Exactly r are incomplete headers. The default modes therefore have M−M/m−r names. In increasing order of length and then lexicographic order, map them bijectively to the first M−M/m−r positive numbers below M that are not divisible by m. Both directions take poly(d) bit operations. To rank names, sum the counts of admissible strings at the shorter lengths, then rank the remaining suffix among strings of the same length. For a zero-based output rank i the encoded integer is m⌊i/(m−1)⌋+(i mod (m−1))+1. Output exactly d bits, including leading zeros. Inputs of length at least d in a default mode are irrelevant and may be rejected.

The only nonmultiples without this explicit program are the final r nonmultiples. All lie above the last multiple M−m, since m−1≥r. There are M/m multiples but only M/m−1 short universal-mode names, so at least one multiple is omitted by time B regardless of their behavior. The actual first hole w is therefore a multiple. Exactly ⌊K/m⌋ positive offsets from 1 through K are multiples of m. Those are the only positions before w in this window lacking the guaranteed default program. This proves the claimed coverage for all K≤w. The statement uses the actual cutoff; the default programs halt well before it.

A verifier can certify these positions simply by computing and checking the inverse name. For these outputs the codec itself is injective and efficiently invertible. If literal reversible tape transitions are wanted, reversible evaluation and uncomputation of these polynomial-time maps also fit a polynomial clock. The unresolved residue class consists of outputs of the universal mode. Reversibility of a long transition sequence by itself gives no comparable time bound for identifying which of these outputs occurred. [Bennett on reversible simulation](https://doi.org/10.1147/rd.176.0525)

## The smaller first-hole problem left on the multiples

Define the filtered producer at this length as follows. On q of length less than d−r, simulate the universal mode with full description 1ʳq under the original B-step clock, counting the entire run as before. If it halts with d-bit output m·j, return the (d−r)-bit quotient j. Otherwise return no value. The first hole of the tuned machine is **exactly m times the first hole of this filtered producer**. Default outputs never fill a multiple, and all exceptions among the default outputs occur above every multiple. Thus all the remaining predecessors on the residue class are genuine late-or-early quotient outputs. The easy codec supplies no information about which quotient first fails.

There are trailing windows much wider than m whenever d−r tends to infinity. A single fixed V-decoder given n,r and a raw payload can print m times the integer encoded by that payload, padded to d bits. With suffixes of length d−r−c−1 for fixed decoder-header length c, this prints the first 2^(d−r−c−1) multiples in polynomial time. Hence w≥2^(d−c−1) once those suffix lengths are nonnegative. In particular the fixed near-one rate above is attained on windows of unbounded length.

## Why letting the exceptional probability vanish does not give the target

One may define a single computable parameterized machine with r=r(n), for instance r(n)=⌊d/3⌋, using the same grammar at each length. Its default modes really do certify all but o(K) predecessors whenever K tends to infinity. But the entrance cost for the generic decoder is now r(n) bits. The loss of fast universality can be proved directly. One fixed polynomial-time program interprets any (d−r)-bit j and outputs m·j on the public length parameter. On the particular input j=w/m, every translation of this program and payload that still halts by B needs at least d raw bits on the tuned machine. The additive price is therefore at least r on that payload, independently of how one tries to route the translation. An upper bound within O(1) of r comes from the reserved branch and a fixed V code. The score method measures the same expense on all window sizes.

Let S be any computable collection excluding the actual w whose omission-score table can be constructed and ranked within B by a single generic decoder. Let c be its V-code length, independent of r. S and the decoder may use n and r. The one-sided packing estimate gives rank R(w)≤M/D(w), where D(w) is the best trailing ratio of interval length to the number of omissions in that interval including w. Number the raw suffixes in order of length and then lexicographically. Whenever d>r+c, the decoder can name all ranks 1,…,2^(d−r−c)−1 by full descriptions shorter than d. Therefore R(w)≥2^(d−r−c) and

    D(w) ≤ 2^(r+c).

For the default codec and trailing widths K=t·m−1≤w, the interval including w has length t·m and exactly t omissions from that codec. The ratio is exactly m=2ʳ. Thus the gain in the rank description matches the universal header cost up to the fixed c. Under a fast-SAT hypothesis one can include that fixed solver in the generic decoder, but its fixed code still passes through the same header. One needs an additional unbounded rank saving beyond r(n), such as a verifier covering all but a vanishing fraction of the corresponding preceding quotients, to reach a SAT contradiction.
