# The unshifted crossed scan cannot decide DIMACS SAT at any speed

Consider the five-instruction public scan with public cursor $p_i=S^i(p_0)$ on the word domain $A$, where $S(a)=a+d\bmod 2^w$ for a fixed program integer $d$. On each complete traversal of its instruction cycle it loads $x=M[p_i]$ and makes the compulsory write $M[x]\gets p_i$. The two writable registers are the load destination $x$ and the public cursor. Fixed-target comparisons and branches may leave the cycle, but every continuation of the cycle executes these same data operations. In the original five-slot case all other operands are immediate or immutable register values. The proof also allows a fixed finite control phase within this same repeated schedule. A preliminary known store, if present before the first regular load, is included in the initial memory. This is the offset-zero case in the [crossed-scan classification](ancestry-of-crossed-stores.md).

**On ordinary explicit DIMACS inputs, no such program decides SAT even with arbitrarily many allowed instructions executed.** The proof bounds how long a total program can keep scanning using only the number of distinct initial word values. Unlimited writable memory is available. The clock can vary freely with the input.

## Only the initial image can lose an edge

Write $H=\{M_0[a]:a\in A\}$ for the image of the memory after any prologue, and $h=|H|$. A single preliminary store increases the preexisting image size by at most one. Initially and after every step regard memory as a directed functional graph with the edge $v\to M[v]$ at each address, including loops. Keep just a single underlying undirected edge for two opposite arrows. If $x=M[p]$, the write adds the arrow $x\to p$ on an edge already present. It may erase a different underlying edge but cannot introduce any new one.

Each $a\notin H$ has no incoming arrow initially and its only initial neighbor is $M_0[a]\in H$. That sole underlying edge must persist forever. Otherwise $a$ would have no available edge for its own outgoing arrow. Every erased edge consequently has both ends in $H$. At most $h$ such underlying edges exist initially, since each arises as the outgoing arrow of some vertex in $H$. **There are at most $h$ edge erasures over the whole infinite scan.** An update can change orientations while preserving the undirected edge set.

## Two complete periods without an erasure

The following argument works for the periodic order consisting of any fixed nonempty list of distinct addresses, possibly omitting most of the domain. A period refers to this entire list of loads and compulsory writes. Suppose the underlying graph is constant throughout two consecutive periods, and consider one connected component of that graph. A finite functional digraph has a single directed cycle per weak component. If that cycle is a mutual pair of distinct vertices, the underlying graph there is a tree and all other vertices point along its branches toward this root edge. If the directed cycle has length at least three, any update in the component would add a reciprocal arrow where none existed. It would erase the previous outgoing edge of the updated destination, which was unreciprocated. Thus no such component is touched in the stipulated periods. A component rooted at a self-loop can only be queried at the self-loop vertex while preserving every edge. Reading a different vertex makes its destination change an unreciprocated outgoing arrow. An untouched component and repeated queries at a root self-loop both leave its memory unchanged.

In a tree component, each query at $p$ leaves a mutual root edge containing $p$. Its second endpoint is exactly $x=M[p]$. All remaining orientations are determined uniquely by the tree and this root edge. If the next query in this component is at a distinct $q$, the old root contains $p$. The old value of $M[q]$ is then the first neighbor on the unique path from $q$ to $p$, including when $q$ is the other endpoint of the old root. Hence immediately after the query at $q$ the new root edge is determined by the ordered pair of queried vertices alone. This conclusion uses the absence of erasures to keep the component tree fixed.

When at least two vertices of the component occur in the periodic list, its last two queries in either full period are distinct, and this pair is the same in the next period. The memory at the ends of the two periods therefore agrees throughout the component. With just one queried vertex, its first update creates or retains a root pair containing it. Every later query at that vertex reads its partner and writes back the same arrow. With no queried vertex, the component stays unchanged. It follows that the **entire memory agrees at the two ending period boundaries**.

At a boundary chosen after completion of the data operations, $p$ or the next public cursor is determined by the phase. The load destination is also determined there: at the final scanned address, the write preserves the word just loaded from that address, whether the write is elsewhere or is a self-write. Thus $x=M[p_{\mathrm{last}}]$ after the last write. All other data registers are unchanged fixed values. The continuing finite-control location is the same at both boundaries. This proves exact repetition of the native machine state if both boundaries are reached without leaving the cycle. Equivalently, one may place a boundary just before the next LOAD; a completed five-slot cycle has the same data state there. If an off-cycle suffix remains at a selected exit it has bounded size. The proof uses the specified controller state; a separate counter accumulating pass numbers could distinguish these two boundaries.

The [finite audit](../audits/unshifted_crossed_scan_audit.py) checks edge containment, the initial-image loss count, the loaded register and the repeated two-period boundary on 296,675 starting-memory/partial-orbit cases through six addresses. It uses every memory map and one canonical order per possible orbit length. Conjugating both memory values and addresses by the same bijection covers every other order of that length for these update properties. Two consecutive clean periods occurred by pass four in these cases. The audit also checks 243 preliminary stores before a partial scan.

## A bound on a halting scan and the SAT contradiction

Ignore exits to define the infinite sequence of memory updates. A period containing an erasure uses up at least one of the $h$ possible losses. Among $2h+2$ consecutive complete periods there must be two consecutive erasure-free periods. Otherwise a sequence of at most $h$ periods with erasures and no two clean periods in succession has length at most $2h+1$. A halting run cannot continue past both equal-state boundaries. Including an initial phase and a last incomplete period, its number of passes is $O(h+1)$. The bound holds for all public orbits, all initial contents, and every placement of the branch tests in the specified five-slot schedule.

Use the [small-alphabet equality formulas and their communication protocol](equality-communication-for-five-slot-sat.md). On the $k$-bit equality family each valid file has $N=\Theta(k\log k)$ bits and original word-image size $h=O(N^\eta)$ for any chosen constant $\eta>0$, using the existing sparse decimal names. One party owns the prefix, the other owns its complement, with a public split up to one straddling word. A fixed integer stride changes owners $O_d(1)$ times per public period. A move to a new owner transmits the last buffered value for each foreign write destination along with its address, and the bounded controller. The offset-zero last-writer argument shows every actual pair $(p_i,x_i)$ meets $H$. Equivalently this follows directly because every underlying edge belongs to the initial functional graph. Writes to foreign addresses in $H$ are charged once per handoff run. Any foreign destination outside $H$ must be reached on a scan position in $H$, and every position is visited at most once per period. With $P$ periods this costs **$O_d(w(P+1)(h+1))$ communication bits** including phase tails, buffered record counts and a possible preliminary store. It requires no prior knowledge of either party's private part of $H$. Branches may halt at different times on different inputs. An exit and its bounded register comparison are simulated by the last owner.

Every total candidate would therefore give a deterministic equality protocol with worst-case $O_d(w(h+1)^2)$ bits on these files. Choose $\eta<1/2$, for example $1/4$. This cost is $o(k)$, contradicting the $k$-bit deterministic equality lower bound from its $2^k$ accepting diagonal inputs. The proof concerns a single fixed schedule, so it permits other formulas and program runtimes to be arbitrary. At every sufficiently large scale of this family at least one file of that common length is answered incorrectly or the program fails to halt. The corresponding conclusion for a payload $S(p_i)$ instead of $p_i$ would require another argument, because that update can create a new underlying undirected edge.

The [word-aligned equality construction](communication-bound-for-public-crossed-scans.md) strengthens the length quantifier for full DIMACS. It gives $h=O(1)$ and $k=\Theta_D(N/\log^2 N)$ at every sufficiently large byte-aligned $N$, with the option of unused variables and decimal names of $O(\log^2 N)$ digits. The scan then has $O(1)$ periods on any halting input in that suite and uses $O_d(\log N)$ bits of communication. The full equality suite at each such length therefore defeats the unshifted scan regardless of its deadline. The sparse polynomial-identifier variant above already gives arbitrarily large common lengths.

The [Lean formalization](../lean/UnshiftedFunctionalScan.lean) defines the RAM update on a memory function and proves support containment at every prefix, exact immutability outside the initial image, and membership of both endpoints of every lost edge in that image. The two-pass repetition and the SAT communication contradiction above remain manuscript arguments. The [shifted-write example](shifted-crossed-scan-on-padded-dimacs.md) has three initial values and an unbounded number of different pass-boundary states on valid DIMACS files.
