# Changing the fastest description by exactly one bit

**Research journal, 24 November 2026.** I tested whether one could rule out the proposed distribution of first production times by showing that nearly incompressible words already have fast shortest programs. On a specifically constructed optimal prefix machine, exponentially slow shortest programs coexist with a quasilinear program just **one bit longer**, for a positive fraction by weight of the selected words on infinitely many phases. This part is unconditional. The linear-SAT hypothesis gives much narrower simultaneous intervals for the first completion of a shortest program. The distinction is between an exponential factor in the deadlines and a polynomial factor.

One-bit changes in measures of logical depth are classical. Antunes, Souto and Vitányi study large drops with a change of one in significance, with precise distinctions between definitions. Here the two bounds are literally the shortest description length and one greater, the fast endpoint is quasilinear, and there is a lower bound on the total weight of qualifying words with an upper as well as a lower deadline on the fastest shortest producer. I have not established priority for the result below. [Antunes, Souto and Vitányi](https://arxiv.org/abs/1310.6976)

## A universal source with a fast exact-length code

For each fixed integer D≥1 define a prefix-free native stream machine U_D. Use the logarithmic-in-elapsed-time word-width convention and fixed interpreter V of the [native construction](time-by-length.md). V supports ordinary fixed stream programs, with a fixed prefix for each program and polylogarithmic step overhead. The following three disjoint input branches define U_D. Output is published only upon halting.

* On prefix 111, simulate V. If it would publish a word of length m after consuming L bits including the initial prefix, and m−D≤L≤m−2, consume and ignore m−1−L further bits before publishing. Otherwise publish directly. Buffer the output until completion.
* On prefix 110 followed by D zero bits, simulate V directly, with no padding. This preserves literal universality by a fixed compiler prefix even for machines whose output lengths vary arbitrarily. This branch has Kraft measure at most 2^(−D−3).
* On the half of the code space starting with 0, run the literal decoder below. It only emits words whose lengths equal the exact number of input bits consumed. The remaining patterns diverge.

The clocks count all native steps, including buffering and padding. For a fixed D the two simulation implementations have polylogarithmic overhead on the bounded calculations used here. The algorithms describing these machines are uniform in D. In particular the cost in a *program name* of specifying D in the 111 branch is O(log(D+2)), independent of the runtime saving being sought.

Use the [feedback construction](adaptive-window-lists.md) with the following parameters. Start at window s=3 in phase r=6. Set b_s=2^s, W_s=2^b_s and J_3=W_3³. Recursively set J_{s+1}=2^(2^(J_s+W_s+10)). Window s uses J_s≤j<J_s+W_s. A block j has N=2^j lengths N≤m<2N. Its targets at m are the words starting with j zeroes. The full deadline is 2^(20m), and a producer must have length <m. A block is good when fewer than h=2^(j−b_s)+1 lengths have every target produced. Offer the first W_s/2^r blocks, taking the first h lengths in each. Advance r on the first successful window, one containing a good offered block. The division is integral since r≤s+3≤2^s. For a word set use weight 2^(−m) per m-bit word. Let P_{D,r} be the sum of the offered fractions 2^(−r) within phase r.

Only the two simulation branches can make a length heavy. Their combined Kraft capacity is at most 1/8+1/16=3/16. Choose one short name per word in each heavy length. The normalized word weight costs at least twice as much Kraft weight, so the sum of the heavy-length fractions over all blocks is at most 3/32. Every failed window charges more than its offered fraction to this sum. No phase can persist through infinitely many failures. Successful windows have total offered fraction Σ_{r≥6}2^(−r)=1/32. Hence Σ_r P_{D,r}≤1/8 for every D.

Each selected length in block j needs a prefix of depth j for the literal decoder. From each such prefix it reads m−j suffix bits and emits those bits preceded by j zeroes. The total requested prefix weight is at most twice Σ_r P_{D,r}, since h·2^(−j)≤2/W_s per offered block. It is therefore at most 1/4 and fits in the code-space half starting with zero. Assign cells consecutively in increasing order of depth, using one contiguous batch for the h lengths of each offered block. A depth is the total number of bits read, including the initial zero. Each literal name has length exactly m. The decoder can determine all feedback using only the short outputs of the two simulation branches, independently of this literal allocation. Exact program names are prefix-free across all three branches.

The literal computation takes m·polylog(m) time. Dispatch through the current j needs at most polynomially many operations in j=⌊log₂m⌋: skip entire length batches by their counts, using grid endpoints of at most j bits, until the input selects one of them. Tests of current-window success are unnecessary. Feedback through the preceding window can be recomputed in 2^(O_D(2^(J_{s−1}+W_{s−1}))) time by full bounded simulations. With the present spacing this is m^o(1). The next window start has a simple binary representation and is generated only when the scan reaches that window. Finally read, then copy, the raw suffix and produce the prescribed prefix. The construction deliberately spaces out the windows to obtain this stronger fast clock.

## The same halting grants across different machines

Fix a separate optimal prefix machine U_0 with random halting probability. Use a computably invertible injective pairing r=r(p,t)≥6+t+|p| for binary p and integer t. Give phase r weight w_r=2^(−|p|) if p halts on U_0 at exactly step t, consuming exactly its supplied bits, and give it zero otherwise. A pairing that takes polynomial time in r to invert and check suffices. Then (w_r) is a computable rational sequence summing to Ω_0. By the random series term test there exist δ>0 and infinitely many r for which

    w_r ≥ δ a(r),

where a is the universal discrete lower semicomputable semimeasure on integers. Zeros may be handled by adding 2^(−r), which is o(a(r)). Call this set of phases R. It uses the same phase *numbers* for every experiment D. Their actual windows can differ. Also w_r is at least a constant times 1/[r(log(r+2))²] on R. [Bienvenu and Shen, Theorem 13](https://arxiv.org/pdf/1110.5028)

For any fixed D a decoder in the padded simulation branch reads self-delimiting D and d, then the U_0 program p. After it halts at t, the decoder finds phase r(p,t). Within that phase, at each offered block and its first h lengths, request every target word missing at an earlier cutoff, ordered lexicographically. Grant the first 2^(−d)w_r units of these requests, truncating the last batch. A word at m consumes one cell of depth m−|p|−d in the remaining payload field; all earlier endpoints are on that grid. Choose d so the nominal complete name is shorter than m after paying the fixed branch and decoder header, the code of D and the code of d. One can take d≤C log₂(D+2)+C for a fixed C. Padding may append ignored bits until length m−1, which still qualifies. For large phases the grant is exactly aligned at the requested word lengths. While recovering phase r the decoder only needs feedback from completed windows. If the grant had not run out by the phase's final successful window, it would have filled every previously missing word there, making every offered block bad. Thus the grant is exhausted whenever its dispatch and unranking meet the full deadline. The single successful window costs at most 2^(1−r) target-word weight. [Cell dispatch proof](fifo-producer-credits.md)

First take the earlier cutoff to be 2^(3m). Direct native simulation of all names shorter than m, deduplication and prefix unranking through m take 2^(4m)poly_D(m) time. The lengths are visited in increasing order, the feedback uses only past windows, and native word operations on bounded transcripts can be simulated with polynomial overhead in m per step. Thus every paid word first appears on a short program after 2^(3m) and by 2^(5m) at sufficiently large m. This argument uses no SAT hypothesis.

## Forcing the fastest short producer to be a shortest program

Let Y_{D,r} consist of the selected target words in phase r, including the successful window. The sets at fixed D are finite, effectively recoverable without a clock and disjoint across r. Put K_D(y) equal to unbounded prefix complexity on U_D. The two exceptional classes below must be controlled even for competitors that halt arbitrarily late.

1. The uniform lower semicomputable sequence J_{D,r}=Σ_{y∈Y_{D,r}}2^(−K_D(y)) sums to at most one over r for each D. Hence J_{D,r}≤C₁(D+1)² a(r), by mixing over D with summable weights proportional to (D+1)^(−2). The word weight at lengths m with K_D(y)≤m−D−1 is therefore at most 2^(−D−1)C₁(D+1)² a(r).
2. Count the word weight F_{D,r} of targets with *any* fallback-branch name shorter than m. Then Σ_r F_{D,r}≤2^(−D−4) by Kraft on that branch. Mixing the uniformly lower semicomputable sequences 2^D F_{D,r} in the same way gives F_{D,r}≤2^(−D)C₂(D+1)² a(r).

Likewise P_{D,r}≤C₃(D+1)² a(r) by its uniform total bound. Outside the two exceptional classes a paid word has K_D(y)=m−1: the literal branch only gives length m, and the padded branch supplies no final length in [m−D,m−2]. On R the whole paid mass is 2^(−d)w_r, whereas both exceptional classes together cost at most 2^(−D)O((D+1)²)w_r/δ. Fix D large enough that this is less than a quarter of the grant, using d=O(log D). At all sufficiently late phases of R the successful window also takes less than a quarter. The remaining failed-window words have total weight at least 2^(−d−1)w_r, a positive D-dependent fraction of P_{D,r}.

**Unconditional conclusion.** At these words the earliest completion by a shortest program is in (2^(3m),2^(5m)], while a program *one bit longer* completes in m·polylog(m). All shortest programs take more than the first cutoff, and at least one meets the second. Grouping by blocks and lengths also gives a positive fraction of target words at a positive fraction of the selected lengths in a positive fraction of the offered block weight on those phases, since each block contributes between 1/W_s and 2/W_s and each of its h lengths contributes the same maximum weight. These are statements about the deliberately specified U_D. They put no time lower bound on SAT.

## Testing a sharper criterion against the one-bit jump

Under deterministic linear SAT on the target logarithmic-word RAM, the same argument can target a clock D_m=2^⌊xm⌋ for any fixed rational 3≤x≤4. Use an early table of outputs by ⌊D_m/m^a⌋. To count outputs with a given prefix, existentially guess sorted distinct words, universally select a row, and certify one bounded native transcript. Exact counts and prefix unranking use time (2^m+D_m/m^a)poly_D(m) under linear SAT with fixed alternation elimination. For sufficiently large fixed a the paid producer runs by D_m. Use one bounded-transcript interpreter with D supplied as data. Its clock arithmetic on O(m)-bit integers and its fixed quantifier depth give a polynomial overhead exponent independent of D at sufficiently large m for each fixed D. Thus a can be fixed before increasing D. Its header still costs O_x(log D), and the ordinary semimeasure estimates above are unchanged. Any *fixed finite library* of such clocks can use a common sufficiently large D and the same phase set R. The conclusion now puts the fastest *shortest* program in the polynomial-factor interval (⌊D_m/m^a⌋,D_m], with the same quasilinear one-bit-longer alternative. The proof also permits one fixed limit-computable x using phasewise rational approximants as in the earlier measure argument; the conditional interval then uses the actual phasewise clock, whose normalized rate approaches x. [Native verification of the early table](near-clock-credits.md) · [Moving clock centers](phase-limit-measures.md)

I tested whether deleting this last short name gives a contradiction. Change the padded branch so it pads **all** nominal lengths in [m−D,m−1] to m. The resulting source remains literally universal via its thin fallback. On the common R every genuine short output is now in one of the two exceptional classes (with K_D and feedback taken on the changed source). Thus the total short-output mass on an entire phase, at *all* clocks together, is at most 2^(−D)poly(D)a(r). This is an unconditional structural upper bound on the changed machines. The grant decoder on their padded branch must make its nominal length at most m−D−1 to ensure a short output, or use the unpadded fallback with a prefix of length D+3. Both options spend at least D extra bits up to fixed header constants. The resulting lower grant is at most on the same exponential scale as the upper estimate. The one-bit change of padding endpoint therefore removes exactly the fast-compilation property that gave a polynomial-in-D fraction of a grant. To separate linear SAT by this route one still needs an upper estimate on the **original** machines, or a cheaper way to realize the required grants on the changed ones.
