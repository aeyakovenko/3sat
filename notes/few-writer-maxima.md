# Recovering named replies from their histogram

Fredman's set-maxima observation, used as Lemma 3.9 of Khanna, Putterman and Song's minimum-spanning-tree preprint, has a concrete interpretation for a memory transcript. Each read has an announced nonempty menu of possible writers, and its actual writer is the latest member of that menu in one common order. The vector of writer counts then determines **which writer each read saw**. Below is a linear-incidence-time decoder and a sharp error bound when some proposed replies fall outside their true menus. On an actual hard computation with two possible reply vectors, one can also exhibit precisely which part of the MST learning step remains expensive. [Fredman's result in Graham, Yao and Yao](https://mathweb.ucsd.edu/~ronspubs/80_01_shortest_distance.pdf) · [Khanna, Putterman and Song, Sections 3.4–3.5](https://eccc.weizmann.ac.il/report/2026/339/download/)

## Decoding announced menus

Let $S_1,\ldots,S_m$ be fixed nonempty subsets of $w\ge1$ labels. For an allocation $a_i\in S_i$, put $h_v(a)=|\{i:a_i=v\}|$. Say that an allocation is realized by a common strict total order when $a_i$ is the maximum of $S_i$ at every row. Then
$$
a\text{ is realized by some common order}
\quad\Longleftrightarrow\quad
a\text{ is the only feasible allocation with histogram }h(a).
$$
In the forward direction, give the labels distinct integer ranks increasing with the order. Any different feasible allocation has strictly smaller total rank across all rows, so it cannot have the same histogram. For the converse, draw an arc from $a_i$ to every other member of $S_i$. If this graph has a directed cycle, take a simple one and a witnessing row for each arc. Its tail labels are distinct, hence the witnessing rows are distinct. Reassign each of those rows from the tail to the head of its arc. Each new name is permitted and the histogram stays fixed. If there is no cycle, any topological order placing arc tails higher than heads makes every chosen name the unique maximum. In particular the number of possible maximum vectors is at most $\binom{m+w-1}{w-1}$. The cycle criterion has the standard interpretation as an acyclic orientation of a hypergraph. [Vertex and orientation correspondence](https://tmuetze.de/papers/jump5.pdf)

Given the menus and only a proposed histogram, compute residual counts for labels and residual degrees counting the unassigned menus containing them. A label whose positive residual degree equals its residual count must take **every** such row in any feasible allocation. Place all such labels in a queue. When processing a still-saturated label, assign its incident live rows, decrement its remaining count and remove those rows from all incident degrees. Enqueue newly saturated positive-degree labels. Reject malformed histograms, counts above degrees, or a nonempty residue with no saturated label. If all rows are assigned, the order in which labels were processed, from greatest to least, realizes the result. In any given realizable residual family, the highest label appearing in any remaining menu is saturated. Processing any saturated label makes only forced choices and preserves existence of a realizing order on the remaining rows. This proves correctness, including rejection for a histogram admitting multiple allocations. For example two identical menus $\{0,1\}$ with counts $(1,1)$ allow allocations but neither is a common-order maximum vector.

With the two incidence directions represented as lists, the total runtime is $O(w+m+\sum_i|S_i|)$ word operations. Check that the nonnegative counts sum to $m$, and update the counts and degrees for one removed row together. Each menu is removed once, each incidence incurs constant work, and a saturated positive-degree label processed from the queue is exhausted in that scan. Stale queue entries are skipped. Labels, row indices and counts fit logarithmic words. This bound charges for the announced menus. In a RAM run the true menu can depend on a computed address; listing all reads and writes at that address or just determining the address can dominate the cost. Deleting a vertex of full prescribed indegree to decode an acyclic orientation already appears for ordinary graphs in Gioan's work. [Gioan, *Enumerating degree sequences in digraphs and a cycle-cocycle reversing system*](https://www.lirmm.fr/~gioan/telecharger/2007%20Gioan%20-%20Enumerating%20degree%20sequences%20in%20digraphs%20and%20a%20cycle-cocycle%20reversing%20system%20%5BEurop.J.Comb.%5D.pdf)

## Sharp stability under histogram and menu errors

Let $a_i$ be the genuine maximum in the same total order for all true menus. Let $b_i$ be arbitrary proposed labels. Write $e=|\{i:b_i\notin S_i\}|$, and let $D=\sum_v (h_v(a)-h_v(b))_+$, equivalently half the $\ell_1$ distance between the **counts**. Then
$$
d_H(a,b)\le (w-1)D+w e .
$$
Assign ranks $0,\ldots,w-1$. Each legal mismatch lowers the rank by at least one, and every illegal reply can raise it by at most $w-1$. Therefore the true sum of ranks minus the proposed sum is at least $d_H(a,b)-we$. The same difference is at most $(w-1)D$, by dropping negative bins and bounding each remaining bin's rank. The order need not be known to the recipient of a mathematical certificate proving the required bounds. In particular, if a feasible guessed allocation on *announced* menus has histogram within $D$ of the actual one and at most $e$ of its selections violate the *true* menus, the same estimate applies. Approximating the counts without controlling these violations need not control any named read.

Both coefficients are jointly sharp. Fix $w\ge2$ and arbitrary nonnegative integers $q,e$. For each $j=1,\ldots,w-1$ take $q+e$ copies of the menu $\{j-1,j\}$ with true reply $j$ and proposed reply $j-1$. Add $e$ singleton menus $\{0\}$ with proposed reply $w-1$. The adjacent changes cancel at every interior histogram bin, and the singleton rows cancel all but $q$ changes at the ends. Hence $D=q$, there are exactly $e$ illegal replies, and all $(w-1)q+we$ rows mismatch. The finite estimate is a rank-sum argument. Priority for this precise perturbation formulation is unverified.

## Two possible histories, one expensive true reply

Let $b_j$ be the [actual priority bit](priority-pinned-sat.md) of the journal's fixed RAM program at scale $j$ and $M=2^j$. Computing it takes $O(M)$ native steps. Every fixed sound procedure determining either bit value from the public scale takes $\Omega_D(M)$ native steps at each sufficiently late successful stage. Append two fresh cells initialized to the words zero and one. After computing $b_j$, run a suffix of $M$ reads, with positions $i=0,\ldots,M-1$. Read address $b_j\mathbin{\oplus}(i\bmod2)$ from these cells. Keep the value of the first suffix read and let that genuine reply be the final verdict. The modified program remains within $O(M)$ native time and its [ordinary packed 3-CNF](packed-band-transfer.md) has the same pin semantics. The repeated queries are an explicit diagnostic attached to this program.

For $j\ge1$, the two candidate suffix vectors are complementary alternating words. Both writer histograms equal $(M/2,M/2)$. Every position distinguishes these two words, so a one-position training set is already optimal. Its address as an index in the suffix can be chosen without any computation depending on the sign. If a fixed sound procedure ever returns a valid index $i$ and the genuine reply $v$, then $b_j=v\mathbin{\oplus}(i\bmod2)$. Filter this answer into two fixed sign detectors. The native lower bound and constant extra work imply $\Omega_D(M)$ time on every sufficiently late success, even when the procedure chooses its position adaptively. The cost statement concerns a procedure given stage metadata. With the suffix table supplied, the indicated bit could simply be read. On each actual run the two-cell example has singleton true writer menus, which change with the sign. Replacing all menus by the same announced doubleton fails the common-maximum hypothesis.

The MST paper predicts a preference vector by querying a sample that separates all sufficiently distant candidate vectors. It can obtain the **true** sampled preferences through batched path-maximum comparisons on a known forest. Section 3.4 allows enumeration of schedules and histories for free in the comparison count; Pettie and Ramachandran's MST theorem then gives the CPU-time consequence. In this RAM example the candidate histories and an optimal sample are both available explicitly. The single sampled value still carries the native time cost of the actual computation. The example does not force an arbitrary SAT solver to execute these reads. It locates the missing ground-truth access assumption in a proposed transfer to unrestricted SAT. [Khanna, Putterman and Song, Claim 3.12](https://eccc.weizmann.ac.il/report/2026/339/download/) · [Pettie and Ramachandran's MST-specific comparison reduction](https://www.cs.utexas.edu/~vlr/papers/optmsf-jacm.pdf)

## Adaptive batches conditioned on the same histogram

Fix $w$ labels, one hidden strict order and $r$ batches of public sizes $m_1,\ldots,m_r$. A deterministic rule chooses all menus in each batch from the earlier maximizing labels. Fix any additional public seed. Given a global histogram $h=(h_1,\ldots,h_w)$, the number of possible trajectories is at most the number of nonnegative **contingency tables** with row sums $h_j$ and column sums $m_i$, and hence at most
$$
             \prod_{j=1}^w\binom{h_j+r-1}{r-1}.
$$
The table records the histogram of each batch. Its first column decodes the first replies by the fixed-menu result. These determine the next menus, so successive columns decode the entire trajectory. The column-sum constraints can be dropped for the displayed bound. There is also the unconditional cap $w!$ from the one hidden order. The cost of running the menu-generating rule is separate.

For $r\mid w$, split the labels into disjoint groups of size $r$. In each of $r$ rounds ask one menu per group consisting of its remaining labels and remove its winner. All global counts are one. Independently ordering each group produces exactly $(r!)^{w/r}$ distinct histories, as any group orders extend to one global order. The product bound here is $r^w$, within a factor $e^w$ by $r!\ge(r/e)^r$. With a single group there are exactly $w!$ histories with identical counts. In that example a sample of positions leaves every permutation of the unobserved labels feasible. If at least two positions remain, a derangement makes two completions disagree on all of them. For $1\le e<w$ the minimum sample size for pairwise Hamming ambiguity at most $e$ is exactly $w-e$. For $e=0$ it is $w-1$. DLMST's Claim 3.12 samples coordinates of a family whose menus have already been conditioned on the forest and spokes. [DLMST, Lemmas 3.9–3.11 and Claim 3.12](https://eccc.weizmann.ac.il/report/2026/339/download/)

There is a stronger restriction for two batches when every global count is one. If the first batch has $k$ menus, let $B$ be a proposed $k$-element set of winners. The incidence matrix on those menus and columns $B$ must have **exactly one perfect matching**. Each matching would assign the same histogram, and the realized maxima are its unique feasible allocation. Conversely, if the matching is unique, the fixed-menu criterion on the restricted menus supplies a realizing order on $B$. Place all other labels below $B$ and use singleton menus for the unreported labels in the second batch. For fixed first menus this gives precisely the maximum possible number of such trajectories over second-batch rules.

In particular every possible $B$ is a basis over $\mathbb F_2$, since its determinant modulo two counts matchings modulo two. When $2\le k\le w-2$, attaining all $\binom wk$ contingency tables would make every $k$ columns independent. Quotient by the span of $k-2$ independent columns. At least four remaining vectors would have to be pairwise independent in dimension two, which has only three nonzero vectors. For $k=2$ the sharp count is $\lfloor w^2/3\rfloor$: columns of distinct nonzero types $01,10,11$ have a unique matching together, and equal types or a zero column never do. Balancing the sizes of the three types maximizes the number of cross-type pairs. More generally put $m=w-k+2$. After contracting any independent $(k-2)$-set, the same three-type count gives at most $\lfloor m^2/3\rfloor$ pairs extending it to a basis. Counting each basis through its $\binom k2$ choices of contracted columns gives at most $\binom wk\lfloor m^2/3\rfloor/\binom m2$ attainable winner sets.

A real RAM can produce many named-writer trajectories after its input probes have ended. Store the successor of each label on a directed Hamiltonian cycle in the label's own cell, performing these $w$ stores in fixed label order. Start at public label zero and follow $w$ pointers. The named writer at each load is its address's unique store. Every cycle visits every writer once, and the sequences of writer identities realize all $(w-1)!$ permutations starting with zero. The next address depends only on the preceding returned word. The pointer payloads carry the permutation. The conditional table bound requires the menus to be determined by earlier *maximizing labels*. The RAM example distinguishes the returned payload from that writer identity. Its scan takes $O(w)$ word operations on a given successor array, and establishes no general SAT time exclusion.
