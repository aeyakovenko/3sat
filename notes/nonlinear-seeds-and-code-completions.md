# Full PCP tests added to all binary consequences

Let $M=2^j$ be the native time for the priority bit. Fix a uniform, perfectly complete, constant-query, constant-gap Boolean PCP for one specified sign, using $r=j+o(j)$ fair bits and local computation in $\operatorname{poly}(j)$ time. For each seed $s$, let $R_s$ be its relation on distinct proof addresses, after unfolding any constant-depth adaptivity. Put $B=\bigwedge_s H_2(R_s)$, where $H_2$ contains all valid clauses of width at most two, including pins and the empty clause. For a seed set $K$, retain the **full** predicates from $K$ in addition to $B$. [Binary hulls and the signed PCP](binary-hulls-of-winner-proofs.md)

**Under linear-time SAT**, there is a fixed $D$ such that, on every sufficiently late false claim, $B\land\bigwedge_{s\in K}R_s$ is satisfiable for every $|K|\le M/(j+1)^D$. The table can depend on $K$. There is also an unconditional construction of a verifier for this same sign for which all such restrictions remain satisfiable up to $cM2^{\lceil j^{1/3}\rceil}$ selected tests, for a fixed $c>0$, on **all** sufficiently late scales. This includes every binary consequence from unselected tests. The construction has at most three complete accepting local tuples per test, constant gap and $j+O(j^{1/3})$ randomness. Its input language consists of codewords whose leading coefficient is the actual priority bit. The same verifier handles both canonical claims.

## Searching for a refuting set

Guess at most $t$ seed names. Reconstruct their predicates and the list of touched addresses in $t\operatorname{poly}(j)$ steps. Check that for every assignment to those addresses, either a listed predicate fails or its pins cannot extend to a model of $B$. To test the extension question, add the pins as unit clauses. The implicit implication graph of $B$ has $O(2^r)$ active vertices. Testing any new implication arc uses the named pin table or the seed and local slot generating a binary clause. By the [waypoint test for binary hulls](binary-hulls-of-winner-proofs.md), linear SAT decides the existence of contradictory paths in time $(t+2^{r/2})\operatorname{poly}(j)$. Specifically, guess $O(2^{r/2})$ waypoints for two paths between complementary literals and check for a deficient segment. Each segment admits an existential walk check of $O(2^{r/2})$ steps up to logarithmic overhead. The explicit current pin table fits in each bounded-run reduction. An empty clause is checked separately.

Compile the universal test for all assignments by complementing an existential search for a counterexample, then compile the outer seed guess. These are a fixed number of calls. Each has size and time at most $(t+2^{r/2})\operatorname{poly}(j)$ after enlarging the fixed polynomial. With $t=\lfloor M/(j+1)^D\rfloor$ and $D$ sufficiently large, the resulting exact inconsistency detector fits $o(M)$ time. It cannot signal on a true claim, which has a perfect proof. The [one-sign time lower bound](priority-pinned-sat.md) excludes infinitely many successes on false claims at this clock.

On a late false claim choose any inclusion-minimal inconsistent set of full tests $C$ relative to $B$. It has more than $t$ members. For every $s\in C$ there is a global model of $B$ satisfying all other tests of $C$, and that model must fail $s$. Thus the matrix of full-test failures evaluated on models of $B$ contains an identity submatrix of order $|C|$. The rank of these functions over every field is at least $|C|$. Every witness table for this submatrix still fails the soundness fraction of all full tests.

There is a more specific rank statement when each test accepts at most three full tuples. Its relation is exactly its affine hull over $\mathbb F_2$ intersected with its binary hull. Indeed, any affine space of dimension at most two projects injectively onto at most two coordinates by choosing independent coordinate columns in a basis matrix. On those coordinates the binary hull permits only restrictions actually present among the accepted tuples. An empty relation supplies an empty clause. The claim follows since the affine hull of three tuples has dimension at most two. Thus all the local parity equations, viewed as affine failure functions restricted to models of $B$, must span dimension greater than $t$. If their dimension were at most $t$, one could take a basis of that many equations from the actual tests. Imposing the full predicates of the corresponding seeds would force every equation on $B$ and therefore all the original predicates. This rank is computed after factoring out every affine identity already valid on models of $B$.

## A quantitative version for quadratic and cubic SAT

Write $k=2$ or $3$. Choose fixed rational $\alpha,\beta>0$ satisfying
$$
 2k^2\alpha<1,\qquad k(2\alpha+\beta)<1 .
$$
Under $O(n^k)$ SAT, on every sufficiently late false claim, for every set of at most $M^\alpha$ full tests there is a table passing all of them and failing at most an $M^{-\beta}$ fraction of the binary hulls.

To prove this, suppose some set $K$ of $t\le M^\alpha$ full tests obstructs that approximation. Let $U$ be the $O(t)$ distinct proof addresses they touch. Every assignment on $U$ passing the named predicates leaves a residual 2-CNF on which every extension fails more than $2^r M^{-\beta}$ binary clause occurrences. There are at most a verifier-dependent constant times $2^r$ such occurrences. By the [short contradiction bound](binary-hulls-of-winner-proofs.md), the restricted system has an inconsistent subcollection of $O((j+1)M^\beta)$ original occurrences, marking each by a seed and slot. Restore the occurrences to their unpinned form, calling this subformula $H$. Either $H$ itself is inconsistent, or one or two pins in the assignment already make $H$ inconsistent. For the second statement, in a satisfiable 2-CNF close all the pins under forward implications. If this closure contains complementary literals, the traces to them name at most two original pins. If the closure is consistent, set it true and its complements false. Every clause touching these fixed variables is satisfied or forces a literal already in the closure. Any original model on the untouched variables extends the closure. This proves the dichotomy.

Consequently either one short $H$ refutes $B$, or there is a list of at most $O((t+1)^2)$ unary and binary clauses on $U$, all valid in $B$, which together with the full tests are inconsistent. For each listed clause provide a short $H$ proving its validity when its one or two violating pins are imposed. There are only $O((t+1)^2)$ possible projected clauses. Include all those needed to forbid every surviving assignment to $U$. A checker guesses the list and the named full tests. It verifies each $H$ by explicit 2-SAT in $M^\beta\operatorname{poly}(j)$ and checks its occurrences against the local tables. It then calls the hypothesized SAT algorithm on the explicit $O((t+1)^2\operatorname{poly}(j))$-bit CNF for the projected clauses and full tests, demanding UNSAT. If the named tests alone have no assignment this empty-list case suffices. All successes are sound for falsity of the sign. The outer deterministic SAT call on the bounded search takes
$$
 \left((t+1)^2 M^\beta+(t+1)^{2k}\right)^k\operatorname{poly}(j).
$$
Our strict exponent conditions make this $o(M)$. For example $\alpha=1/9,\ \beta=1/4$ works for quadratic SAT, and $\alpha=1/20,\ \beta=1/5$ for cubic SAT. This quantifies simultaneous exact selected tests and approximate remaining binary consequences.

## Codewords whose leading coefficient is the actual winner

Let $m=j+\lceil j^{1/3}\rceil$, $Q=2^m$, $F=\mathbb F_Q$ and $d=Q/4$ for $j\ge2$. Fix a polynomial basis of $F$ using a deterministic irreducible polynomial construction for characteristic two. A binary word of length $2mQ$ is divided into blocks of two field elements. Define one pure language $L$ whose slice of this length is
$$
 W_j(g)_a=(g(a),a g(a)),\qquad
 L\cap\{0,1\}^{2mQ}=\{W_j(b_jX^d+f):\deg f<d\}.
$$
Here $0,1$ are elements of $F$, $b_j$ is the **genuine output of the fixed priority computation**, and $a$ ranges over every field element. Other lengths are rejected. The function $j\mapsto m$ is strictly increasing, so the length determines the stage. The two canonical input words are $z_{j,c}=W_j(cX^d)$ for $c\in\{0,1\}$. Exactly one belongs to $L$. Each requested bit of either is computed from $j,c$ and the address in $\operatorname{poly}(j)$ time. The two coordinates at each field position are a version of the variable inner codes in Justesen's construction. [Justesen](https://doi.org/10.1109/TIT.1972.1054893) · [Shoup](https://www.shoup.net/papers/detirred.pdf)

For every set of at most $d$ block positions, interpolate an $f$ of degree less than $d$ there with values $(c-b_j)a^d$. Then the word in the actual winning coset defined by $b_jX^d+f$ agrees with the canonical claimed word on every one of those entire blocks. On the wrong claim the canonical word is nevertheless a fixed positive relative Hamming distance from the whole length slice. Choose a constant $0<\tau<1/2$ with binary entropy $H_2(\tau)<1/2$. Call $a$ bad if some $u\ne0$ has $(u,au)$ of binary weight at most $2\tau m$. There are at most $2^{2m H_2(\tau)}=o(Q)$ bad $a$, since such a pair determines $a$ when its first coordinate is nonzero. For any honest $g$, $cX^d-g$ on the wrong claim has degree exactly $d$ and is nonzero at at least $3Q/4$ multipliers. At at least $Q/2$ good multipliers it produces relative block weight greater than $\tau$, giving relative word distance at least $\tau/2$ for large $j$.

This pure language has a nondeterministic multitape membership check in $Q\operatorname{poly}(m)$ time. Recover $j$ from the length. Verify the fixed $M$-step priority computation, by guessing its chronological log and sorting to check all RAM memory dependencies as in the [native PCP construction](low-randomness-free-winner.md). Guess an additive-FFT basis expansion of $f$ using only the first $d$ basis elements. Evaluate $f$ on all field elements and add the checked $b_j a^d$ at each position. Compare the resulting two coordinates to the input. In more detail, take nested binary subspaces $V_i$ spanned by the first $i$ basis vectors and their subspace polynomials $L_i(X)=\prod_{a\in V_i}(X-a)$. The recursion $L_{i+1}=L_i^2-L_i(v_i)L_i$ for the next basis vector makes each $L_i$ linearized with $O(m)$ terms. Products of the $L_i$ indexed by binary digits give a monic basis in increasing distinct degrees. Split a coefficient block as $f_0+L_i f_1$ for the next coset division. On each child coset of $V_i$ the value of $L_i$ is constant, so one pass combines the two halves into child coefficient blocks at the next level. There are $O(Q)$ coefficient records per level and $m$ levels. Sorting records by level indices on tapes adds polynomial-in-$m$ overhead, including any change of evaluation order before input comparison. Use a nondecreasing quasilinear clock on all input lengths. [Lin, Chung and Han](https://arxiv.org/abs/1404.3458)

Apply Theorem 2.6 of Ben-Sasson et al. with a sufficiently small fixed exponent parameter and proximity threshold below $\tau/2$. The resulting binary verifier on $z_{j,c}$ has perfect completeness, a fixed rejection gap, constant input and proof queries, $j+O(j^{1/3})$ fair bits and local time $\operatorname{poly}(j)$. On the fixed signed claim, answer the implicit input queries from the local canonical-word generator. This gives a PCP sampling full relations on the proof alone, with no extra mode bit or alternative acceptance branch.

For one seed, unfold its constant-depth decision tree, including both possible replies at every input or proof query. Each seed then touches at most a fixed $q_*$ block positions of the implicit input. Any specified $K$ seeds with $q_*|K|\le d$ admit one simultaneous proof on $z_{j,c}$. Interpolate an honest member of the actual winner coset matching the claimed word at the pooled positions and take its perfectly complete proximity proof. On each of these seeds the verifier receives exactly the input bits and proof bits it would see for that honest member. The witness may use the true bit even when the canonical claim is false. The oracle and the input are held fixed for all the selected seeds. Coding-based proximity lower bounds also exploit indistinguishability on small coordinate sets. Here both signed words are explicit and the polynomial's top coefficient is uniquely forced by the real computation. [Ben-Sasson et al., Theorem 2.6 and Definition 2.4](https://people.seas.harvard.edu/~salil/research/polylogPCP.pdf) · [Dall'Agnol et al., §5](https://arxiv.org/abs/2105.03697)

## Retaining all binary consequences while checking selected full tests

Apply the [three-answer tree compilation](binary-hulls-of-winner-proofs.md) to the verifier on the fixed canonical input, with depth at least one. Compute input-oracle replies from the signed word while generating the proof-query tree. Pad shorter paths by ignored queries to fresh proof addresses. Every internal split then queries a single shared Boolean proof bit. Given any set of at most $\lfloor d/q_*\rfloor$ compiled tests, mark their old seed trees. One genuine proximity proof for the interpolated member makes all those old seeds pass on the canonical word. Use its honest selector paths on the marked trees. In every unmarked tree activate only its root. The root-only selector passes all binary hulls because the binary hull of $p=l+r$ includes $(1,0,0)$. The honest marked trees pass all full predicates. Consequently the same table satisfies all binary hulls and every selected full test. The number of random bits increases by a constant and the false-claim gap loses only a fixed factor.

On every sufficiently late false claim every minimal refutation relative to the full binary hull consequently has $\Omega(M2^{\lceil j^{1/3}\rceil})$ members, unconditionally. Its identity evaluation minor and its affine-equation rank have the same unconditional lower bound. Taking $m=j$ gives the $\Omega(M)$ version with codeword length $2jM$. A verifier exploiting the explicit instance description knows the asserted leading coefficient and can attempt to check the native computation directly. What fails here is the inference that a small number of sampled full tests, with free access to every binary implication, must reveal the bad sign just because the local predicates came from checking the actual computation.

## Both kinds of constraints are needed in large numbers

The three-answer verifier already admits a second extension on the same selected tests: it can satisfy **all affine hulls** instead of all binary hulls. Use the interpolated shared proof and honest paths on the marked trees. Each unmarked old seed has an accepting path for some answers, by the one-seed interpolation property. Set its private flags to that path. Its root pin, leaf pins and splits are satisfied. Its child-to-shared-bit implications have three accepting tuples on two distinct coordinates, so their affine hull is the entire square. Hence this second table can retain the same shared proof. The two completions in general need different private flags.

There is also a uniform compilation into a system made up entirely of **binary clauses and disjoint ternary parity equations**. Replace each split $p=l+r$ by $p=l\mathbin{\oplus}r$. Keep the two implications from its children to opposite answers at the same query address. If all tests pass, these implications exclude $l=r=1$ and the parity equation again gives $p=l+r$ as integers. Hence a tree is perfectly satisfiable for a specified shared proof precisely when that seed accepts it. The canonical active path still violates exactly one slot on a rejected old seed. To make the parity rows disjoint, use fresh copies of the three flag occurrences in each row and link each copy to the original flag by the two binary implication clauses expressing equality. All other constraints, including the root and rejecting leaves, are binary or unary clauses. Pad to a fixed power-of-two number of slots per old seed. Optimum absolute violations for a fixed shared proof are still exactly the number of rejected old seeds, by the perfect-instance equivalence per tree and the canonical path with all copies honest. The soundness fraction is scaled by the slot count.

On each false canonical word, this system is at constant relative distance from satisfiable. Yet with $Q=2^{j+\lceil j^{1/3}\rceil}$, **every inconsistent subfamily contains $\Omega(Q)$ parity rows and $\Omega(Q)$ binary clauses**. To see the parity bound, take all binary clauses and at most $\lfloor d/q_*\rfloor$ parity rows. Mark the associated old trees, use one honest completion for them, and use root-only flags on all other trees. All the binary clauses pass. For the clause bound, take all parity rows and at most $\lfloor d/q_*\rfloor$ binary clauses. Mark the old trees touched by these binary clauses and satisfy them with all their parity rows by one honest completion. Set every other flag and private copy to zero in the unmarked trees, satisfying all their parity rows. Each construction keeps one common value per shared address. Thus even unrestricted semantic consequences from one entire class cannot make a refutation use fewer than the stated number of original constraints from the other class. The number of accepted tuples per ternary parity test in this variant is four. [Schaefer frameworks with additional modular constraints](https://arxiv.org/abs/1902.04740)
