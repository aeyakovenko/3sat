# What linear SAT would force at the linear-workspace boundary

Assume a single deterministic logarithmic-word RAM decides ordinary explicit 3-SAT in $O(N)$ time on $N$ encoded bits. Fix constructible output and seed lengths $m=\lfloor n^\epsilon\rfloor$ and $s=\lfloor n^{\epsilon^2}\rfloor$ for rational $0<\epsilon<1$. There would be a deterministic algorithm that prints a full $m$-bit output on every $n$-bit index $x$ in $n^{1+o(1)}$ time and eventually escapes **every** indexed family with simultaneous polynomial evaluation time and **$O(n)$ work bits**. For each fixed family, escape holds on every index beyond its threshold, for every $s$-bit seed. The same algorithm at the linear-space endpoint also escapes all fixed polynomial-time evaluators using $n(\log n)^{O(1)}$ work bits.

There is a quantitative version. Write $L=\lceil\log_2(n+2)\rceil$, $l=\lceil\log_2(L+2)\rceil$, and $H=\lceil\sqrt{Ll}\rceil\lceil\log_2(l+2)\rceil$. For any fixed integer-valued space bound $n\le W(n)\le n^{O(1)}$ computable from $n$ in polylogarithmic time with binary output, the printer takes $W(n)2^{O(H)}$ word operations. It escapes families computed in simultaneous time $n^{O(1)}$ and space $O(W(n))$ on a read-only-input multitape machine. In fact its census covers workspace $W(n)2^{c\sqrt{Ll}}$ for every fixed $c$. In particular setting $W=n$ gives the first statement. All clocks in this note concern one literal linear SAT hypothesis. The output is correct for each sufficiently large length of a fixed evaluator, with no assumed circuit hardness or probabilistic qualification.

The bit-evaluation bound below is a specialization of the journal’s earlier growing-depth checkpoint theorem. The new application combines its common clock with whole-output selection, then imposes the resulting bound separately on every successful input of a competing evaluator. ## Checkpointing and removing a growing number of quantifiers

Fix one machine for the bit $C_x(u)_i$. Its polynomial degree $d$ is a constant which can vary with the family. Put $S=W(n)2^{c\sqrt{Ll}}$ for the analysis, rounding the exponent up and enlarging the fixed constant to absorb metadata and machine constants. A tape configuration is represented in $O(S)$ bits including heads, input positions and flags. Pad the halting computation in its terminal state. Choose a power-of-two fanout $b=2^{\lceil\sqrt{Ll}\rceil}$ and depth $k=\lceil dL/\log_2 b\rceil+1$. Reachability in exactly $b^k$ steps can be asserted with at most $2k+O(1)$ quantifier blocks.

Guess an accepting final configuration. At a node guess its $b-1$ intermediate configurations, universally choose a segment, and pass the chosen adjacent endpoints to the next level. After the last choice check one actual transition from the selected start to the selected end, including validity of the encodings. The original initial configuration is prescribed. A true run supplies all checkpoint lists. Conversely every segment of every accepted division has a real path by induction. Concatenating those paths gives the claimed run. [Lean proof of the endpoint game at arbitrary depth](../lean/CheckpointEndpointLists.lean) The universal selector has no invalid choice because $b$ is a power of two.

On one path the quantified strings contain $O(kbS)$ bits. A uniformly constructible Boolean circuit of $O(kbS\operatorname{polylog} n)$ gates suffices for the deterministic matrix. For each level, the $\log b$ selector bits control multiplexers that select the two neighboring configurations, using $O(bS)$ gates; selections at the two ends can refer to the earlier endpoints. The single-step check can compare two tape images in a scan, decode the heads, and select the read-only input symbol with a multiplexer. Its encoding, including all variable identifiers, takes $O(kbS\operatorname{polylog} n)$ bits and time to construct. Time and space bounds for each fixed transducer can be specified in its accelerator by fixed upper constants. The census below needs none of their values.

Here uniformity matters since $k$ grows with $n$. Represent a suffix with earlier choice bits $p$ as two existential CNFs with $p$ left as parameters, one recognizing truth and one recognizing falsity. Initially use the circuit gate clauses with its output fixed to each sign. To remove an existential block $z$, use the positive suffix formula with $z$ left as ordinary SAT variables. With the remaining $p$ pinned, one call to the fixed SAT solver decides the required predicate. To remove a universal block use the negative suffix formula and reverse the verdict. The accepting and rejecting computation encodings of this one solver call give the next two existential CNFs. Each step needs only one of the two previous formulas as input.

Specifically, pin $p$ with clauses in fixed slots, so every physical bit of the solver's input is a constant, a parameter bit or its complement. Fixed-width binary fields suffice. In ordinary ASCII, a leading space or minus sign in the same slot encodes a chosen sign without moving later bytes. Unit pins can use fresh dummy names and all sign combinations if clauses must have three distinct names. The bounded RAM run construction records register transitions and routes the memory records. Where an input initialization normally pins a known bit, connect it to the parameter or its complement. Keep the parameter variable names available at the next step. The public input supplies only its actual range of records; sparse work addresses enter as data. Both signs require only the same solver plus one changed final test. All word widths are $O(\log n)$ throughout since every constructed formula is of polynomial length. [Packed RAM run compiler](packed-band-transfer.md) · [Earlier uniform native alternation elimination](alternating-native-speedup.md)

If $F$ bounds the current two encoded lengths together with the number of outstanding parameter bits, one compiler iteration costs at most $CF(\log(F+2))^a$ bits and time for fixed $C,a$. Those constants belong to the solver and compiler, independently of the level, the preceding formula's syntax and the number of previous choices. Explicit construction requires no compiler for a new machine at each depth. Starting from $F_0=O(kbS\operatorname{polylog}n)$, at all $O(k)$ iterations the logarithm of the length is $O(L)$. Indeed, as long as the sizes are below $n^D$ for any sufficiently large fixed $D$, the total increase in their logarithms is $O(k\log L)=O_d(\sqrt{Ll})=o(L)$. This also proves the bootstrap bound. Solving the final closed existential formula with the hypothesized solver gives **a fixed bit evaluator per family** with deterministic RAM time
$$
                          W(n)\,2^{O_{d,c}(\sqrt{Ll})}.
$$
The evaluator's original time exponent now enters only the coefficient of the sublinear logarithmic overhead. Classical checkpoints, time-space tradeoffs and SAT-based elimination of alternations precede this calculation. Fortnow treats growing alternation bounds, and Fortnow, Lipton, van Melkebeek and Viglas give a related fixed-depth recurrence. [Fortnow, Sections 2–4](https://lance.fortnow.com/papers/files/npvsnl.pdf) · [Fortnow–Lipton–van Melkebeek–Viglas, Lemma 5.3](https://lance.fortnow.com/papers/files/tst.pdf)

## A common clock and a whole output

Use the first $\lfloor\log_2 n\rfloor$ program codes with the one guest timeout $B=W(n)2^H$. Every fixed accelerated bit program eventually fits. Use the bounded sparse word-RAM interpreter of the hard-table construction; its word limbs, sparse-address trie and guest-clock counter add at most a fixed polylogarithmic factor at these code lengths. Timeout and malformed codes produce deterministic default bits. This supplies a uniformly decidable census of maps from $s$ to $m$ bits.

For clarity the exact-output selection argument is as follows. Take $M$ a power of two in $[B2^H,2B2^H)$ and use the output-speed hard-table constructor from the linear SAT hypothesis, instantiated for a fixed decoder of block descriptions. This gives $M$ bits for which no such decoder with advice length plus worst-case single-bit lookup time below $M/\operatorname{polylog}M$ recovers the table, for a fixed log exponent. If every full consecutive $m$-bit block occurred in the census at a given $x$, describe each by one program index and seed. Add $x$, metadata and the shorter trailing block. The advice uses $O(n+(M/m)(s+\log\log n)+m+\log M)$ bits, and one arbitrary table lookup costs at most $B\operatorname{polylog}n$. Both are $o(M/(\log M)^a)$ for every fixed $a$. This contradicts the table guarantee. Hence for **each** $x$ there is an entire block outside the union. This use of an earlier manuscript theorem is conditional on the same linear SAT hypothesis. [Hard-table constructor and decoder model](output-linear-hard-tables.md)

Recover that block using prefix search on its $O(\log M)$-bit block **index**. An extension of a partial index qualifies when it encodes a full block and for every census code and seed some position disagrees with the bounded bit evaluation. This has three quantifier blocks and a deterministic check on the public table and $x$. Constantly many symbolic elimination steps give $M\operatorname{polylog}n$ deterministic time per query including the public input. Produce the selected block, including all its bits. The total time is $W(n)2^{O(H)}$. The adversary family may depend on this very program. Its eventual presence in the census proves escape. [Whole-output hard-block argument and approximation variant](whole-output-avoidance-from-hard-table-blocks.md) · [Li and Tell, revision 1](https://eccc.weizmann.ac.il/report/2026/233/revision/1/download/)

The approximate selection theorem also extends to this endpoint. Take $W=n$, guest time $B=n2^H$, and the dyadic table size $M=n2^{K(\log_2 n)^{2/3}+O(1)}$ from that theorem with a sufficiently large constant $K$. Now $H=o((\log n)^{2/3})$. The bit-lookup clock $B\operatorname{polylog}n$, the advice for all block descriptions, and the sampled comparisons in the quantified block-address test still fit their respective bounds in the earlier analysis. In particular the lookup budget there is $M2^{-C(\log_2 M)^{2/3}}$, and the number of sampled bit comparisons is $2^{O((\log n)^{1/3})}$. The larger census now contains every original polynomial-time evaluator with $O(n)$ space, even $n2^{c\sqrt{Ll}}$ space for each fixed $c$. The same printer runtime $n2^{O((\log n)^{2/3})}$ and agreement ceiling $1/2+2^{-\Omega((\log n)^{1/3})}$ follow. Thus a predictor attaining $1/2+1/\log n$ agreement on a single index at infinitely many lengths for every printer in this clock would exclude linear SAT. The predictor may use polynomial time, linear workspace, and $s$ bits of advice at that index. The required predictor is unproved. [Hard-table agreement and selection test](whole-output-avoidance-from-hard-table-blocks.md)

**A consequence on individual inputs.** Fix a polynomial-time tape algorithm trying to reproduce the printer's entire output, with an optional $s$-bit seed chosen separately at each $x$. For any fixed constant $K$, at every sufficiently large length, on every $x$, each seed that succeeds requires more than $K W(n)$ work bits on that run. Otherwise simulate it with the space cap and return zero upon overflow. A bit evaluator can track output position and capture one bit, using a fresh simulation for each position. On any successful run within the cap the resulting eligible family contains the whole output. This contradicts escape. The construction genuinely leaves a gap between its own time allowance and the resource it rules out.

At $W=n$ it would therefore suffice to show that every printer running in the displayed $n2^{O(H)}$ time has one polynomial-time, linear-workspace evaluator that reproduces its output with one seed on some index at infinitely many lengths. That simulation is open. A pure-space replay with superpolynomial running time cannot enter this census. At one fixed length, a finite program can hard-code an output, while the proof above fixes the evaluator across infinitely many lengths. This result does not establish an unconditional SAT time exclusion. ## Can a different local proof be used at each successor?

Yes, within a precise description budget. At one index suppose a possibly length-dependent description $v$ of at most $s-1$ bits consists of a prefix-decodable program followed by raw data. Suppose it yields the proposed output bit at every position, for this one index and this same description. Normalize to a fixed binary tape alphabet and fixed number of tapes. Allow a common polynomial clock exponent and space $O(W)$ on these successful queries. Both the program and its raw data may change at every length.

One fixed eligible evaluator can represent **all** those descriptions. Encode a description of length $j<s$ by the $s$-bit representation of $2^j+\mathrm{value}(v)$. Its highest set bit determines the exact original length, including leading zeros in $v$. Reserve the zero seed for a default. This saves a separate length field. The fixed interpreter simulates the decoded program with the index, its raw data and the requested position available read-only. It can scan the short program to dispatch each step. Clock the guest and cap its tapes, producing a default bit on invalid inputs. The interpreter has polynomial time and $O(W+\log n)$ workspace, including counters. Common bounds suffice on the desired indices; clocking totalizes the evaluator everywhere else. Conversely a fixed eligible evaluator with an arbitrary $s$-bit seed gives such a description of length $s+O_C(1)$ by prefixing its own code. This identifies the actual cost of changing programs at successive lengths. Proving sufficiently short descriptions for each near-linear printer somewhere infinitely often is still the missing mathematical step.

There is also an exact boundary in the **number of extra output bits**, even when it oscillates with length. Let $g(n)=m(n)-s(n)\ge0$, with both lengths polylog-time computable from $n$, $m\le n$ and the same evaluation bounds as above. If $g$ fails to tend to infinity, choose an integer $g_0$ recurring infinitely often and look at the first $g_0$ output bits of $A(0^n)$ on those lengths. One pattern recurs infinitely often. Hard-code it and copy the seed into the tail. This one family hits $A$ infinitely often, **for every** output function $A$, even one of unbounded computational complexity. At other lengths the family may return zero.

If $g(n)\to\infty$ and SAT has linear time, take the first $p(n)=2^{\min(\lfloor g(n)/2\rfloor,\lfloor\log_2\log_2(n+4)\rfloor)}$ programs under the common clock. Now $p\to\infty$ and $p2^s<2^m$ eventually. Prefix search in the joint census gives one polynomial-time avoider on every sufficiently long index for every fixed eligible family. Searching only $s+\log_2 p+1$ prefix bits suffices, with a zero tail. If $W=n$ and $s=n^{o(1)}$, each prefix test takes $n^{1+o(1)}$ time **even for large $m$**. Guess the remaining prefix bits, universally choose a program and seed, then existentially choose one disagreeing prefix position. One bounded bit simulation suffices per path, and this is a constant number of blocks. There are $n^{o(1)}$ tests and writing the final zero tail costs $O(n)$ time. This argument does not give that same whole-output clock for large seeds and arbitrarily small positive $g$; the hard-table block argument above uses a substantial saving in $s/m$.
