# Sound certificates for programs that actually run and never signal

In the [priority computation for the pinned SAT formulas](priority-pinned-sat.md), an active rank $e$ gets $\lfloor 2^j/2^{e+1}\rfloor$ interpreter ticks at scale $j$. It can emit one signal. Write $M=2^j$ and $X_{e,j}$ for whether it would signal if tested with this full budget on the prescribed input. An inactive entry is zero. This raw outcome is defined even if an earlier winner prevents this trial. The real scheduler retires winning ranks permanently. At most $a_J=O(\log\log(J+4))$ of the first $J$ stages have any winner.

**Actual-trial theorem.** Suppose ordinary explicit SAT takes deterministic $O(N^k)$ time on the unrestricted logarithmic-word RAM, with $k=1,2$ or $3$. Fix any uniform, sound nondeterministic verifier $W(j,e)$ for the claim that rank $e$ was actually tested and gave no signal at stage $j$. It may abstain on true claims. There is a fixed $B$ and a uniformly specified growing family of ranks in the actual program with the following property. At every sufficiently large stage, a number tending to infinity of its *executed* trials consume their entire budget without a signal and admit no accepting $W$-branch of length
$$
 R_j=\left\lfloor \frac{2^{\lfloor j/k\rfloor}}{(j+1)^B}\right\rfloor .
$$
At every late stage without a winner this holds for all but a fixed finite number of the family members currently selected. The family may depend on $W$ and on the hypothesized SAT solver. No effective lower growth rate for the number actually executed on all stages is asserted. The same result holds for a verifier certifying raw silence whether or not the scheduler invokes the trial. The source receives the ordinary scale metadata, and the verifier can additionally receive the true early history specified below.

This identifies a difficulty with a proposal to prove the default verdict by certifying individually that its unsuccessful competitors are silent. The theorem concerns actual unmodified trials of the fixed priority algorithm. A proof of the final sign may bypass those trials entirely.

## Excluding a pattern on several trials at once

Let $V(j,G,z)$ be a fixed nondeterministic verifier. Its input contains an ordered tuple of distinct active ranks $G$ and a Boolean vector $z$ of the same length. Soundness means that whenever it accepts, the tuple of true raw bits $X_{G,j}$ differs from $z$. This permits any method for proving the exclusion, including inspecting the program texts. Local machine soundness is a premise about this verifier and its stated true inputs.

There is a uniformly generated tuple $G_j$ of increasing unbounded size (nondecreasing for the full active-prefix selection) for which, on every sufficiently large $j$, $X_{G_j,j}$ is all zero and **no** $V(j,G_j,z)$ accepts within $R_j$, for any of its $2^{|G_j|}$ possible vectors. For a nonzero $z$ the claimed inequality is true.

Here is the construction. Use a common program template with an integer tag $l$, the fixed texts of $V$ and the reference SAT algorithm, and a designated requested color (one may use $l\bmod 2$). Each copy recognizes the exact family of specialized texts and computes the same list of designated pairs among the first $a_j$ ranks, sorted by rank. Ordinary self-application suffices: write a template with a literal source argument $b$ able to recognize programs formed by specializing $b$ on $(b,l')$, and supply the template's own text for $b$. Literal tag data make the copies syntactically distinct. Inspect the actual active list, including the requested color, when computing $G_j$. The other color paired with the very same text is a different rank. Computing the common list uses $\operatorname{poly}(j)$ time since the underlying enumeration already generates the active texts on that budget. Every fixed designated copy eventually belongs to the list forever. There is a single fixed instruction body for the search across tags; individual tags affect the final selection of a coordinate. This uniformity is needed when the number of copies grows.

Every copy performs the following same deterministic search on the same scale before deciding what to emit. Test whether some $z$ has an accepting $V$-branch within $R_j$. If so, select the lexicographically first such $z$ and have the designated copies realize its bits: emit for a one, enter an infinite idle loop for a zero. If there is none, all enter the idle loop. A copy outside the selected list never emits on behalf of its own designated pair. Fixed setup and small scales may be handled by idling.

To implement the search, the bounded RAM program guesses $z$ with a specified prefix, guesses a branch of $V$, and simulates at most $R_j$ steps. Use the ordinary locally readable 3-CNF compiler on this program. With $O(\operatorname{poly}(j))$ public data each resulting formula has $O((R_j+\operatorname{poly}(j))(j+1)^{C_0})$ encoded bits for fixed $C_0$. The [packed compiler](packed-band-transfer.md) gives three logarithms in its standard clock regime. Take a conservative fixed power here to include width and layout conventions. A SAT test at the empty prefix, then at most $|G_j|$ prefix tests, finds the selected pattern. This never extracts a long branch witness. The word width used by the SAT machine is $O(j)$ on these virtual formulas. Materializing each formula with the uniform generator would also fit after enlarging $B$. No oracle or extra instruction is present in the tagged programs.

For large $j$ we have $2^{a_j}=O(\log(j+4))$ and $|G_j|\le a_j$. Including simulation and setup, all the work per participating copy fits $o(M/\log(j+4))$, by choosing $B$ sufficiently large. In detail, the SAT work after fixed-width adaptation is bounded by $O((a_j+1)(R_j+\operatorname{poly}(j))^k(j+1)^{C_1})$ with fixed $C_1$. Setup for native arithmetic can instead be done by fixed-limb, polynomial-in-$j$ routines. Interpreting any tagged copy adds at most another fixed polynomial in $j$: the common instruction body is fixed, the tag resides in data, and the entire instruction text currently interpreted has length $\operatorname{poly}(j)$. Thus $B$ can be chosen once. If literal code includes $B$, repeated multiplication for this fixed exponent affects constants only. All participating copies finish the same search and reach their respective branch within the smallest participating raw clock. These inequalities are required only eventually. At earlier stages any retirements exclude at most finitely many ranks from the actual-trial application.

If a bounded exclusion were found, every participating raw trial would realize the chosen vector, and its accepting branch in $V$ would then refute that very vector. Soundness precludes this. Consequently the default is realized and no bounded exclusion exists. This self-reference uses the actual program indices, not an independently chosen oracle table. Replacing the all-zero fallback by any commonly computable vector within the same clock gives the corresponding statement for that fallback. [Lean check of selection and soundness](../lean/TrialPatternExclusion.lean)

The common computation can supply further true data. In particular give $V$ the entire raw signal matrix and winner history through $j-\lceil C\log_2(j+2)\rceil$, using an empty prefix on small scales. Simulate every active trial at each such earlier stage, including retired ranks, with its true native width and time limit. The budgets at stage $i$ sum to at most $2^i$ irrespective of preemption. These simulations therefore cost $O(2^{j-\lceil C\log_2(j+2)\rceil}(j+1)^{C_2}+\operatorname{poly}(j))$ and produce only $O(j(a_j+1)\operatorname{poly}(\log j))$ data bits. A sufficiently large fixed $C$ preserves the common deadline, and the actual awards follow from the raw rows. This supplies nearly the entire history to the verifier with exact provenance. It does not supply the remaining late cells.

## Returning to actual unsuccessful trials

From the proposed $W$, form $V$ that guesses a member $e$ at a position where $z$ has a one and runs $W(j,e)$. An accepting branch soundly excludes $z$, since an actually tested silent rank has raw bit zero. A proof about raw silence suffices as well. Allow fixed slack in the branch cap for parsing and the wrapper. Apply the group construction with zero fallback. After a common finite stage none of its participating ranks can win, and ranks outside the selected family cannot emit from their designated copy before membership. Hence only finitely many designated ranks ever retire. At a late stage with no award, every remaining designated member is physically tried, finishes the common computation, and idles to its deadline. A short $W$ proof for any one of them would exclude, for instance, the vector with a single one at that member. The pattern theorem forbids it.

For the assertion at *every* sufficiently late stage, fix any integer $m$. Choose $m$ forever unretired designated ranks and let $E$ be their largest index. Eventually they are all active and no rank at most $E$ ever wins again, since each such rank may retire only once. The actual scheduler therefore reaches all $m$, even on a stage with an award, and the same lower bound applies to each. The number of such genuinely difficult trial certificates tends to infinity. The full density claim uses the upper bound $a_J$ on the total number of awards through $J$.

Without a SAT assumption there is a different bound for verifiers with explicit binary proof strings. Enumerate all patterns (at most $2^{a_j}$) and all proofs of length at most $\lfloor(1-\alpha)j-C\log_2(j+2)\rfloor$, limiting each deterministic verification to $2^{\lfloor\alpha j\rfloor}$ steps, for fixed rational $0<\alpha<1$. Their product times fixed polynomial overhead fits the raw clocks for large enough $C$. Use this search in the same construction. There is then no accepted exclusion with both that length and verification time on any sufficiently late group. This trades proof bits and verification work and does not give the nondeterministic power-scale claim unconditionally.

## What could yield an unrestricted SAT lower bound

The positive target is a single sound scheme that certifies a correct *verdict* on infinitely many scales within the smaller clock, or a sound scheme that covers at least one of these actually executed difficult trials infinitely often **for every** synchronized family generated against it. For example, a bound $O(M^{1/k-\epsilon})$ for some fixed $\epsilon>0$ on infinitely many such covered scales beats every fixed logarithmic loss in the theorem. Establishing this coverage without the SAT hypothesis would give the contradiction. A catalog explicitly trusted for one previously constructed family need not cover the new family obtained when the catalog is incorporated into the verifier. The test still allows joint information linking the participating trials to other costly computations, or a proof that the verdict is independent of their individual outcomes.

A possible way to prove silence from code is to formalize the argument that a selected pattern would invalidate the certificate used to choose it. For a fixed proof system made part of $V$, a short internal proof by this argument needs an applicable soundness statement at the proof sizes being searched. An external mathematical proof of soundness does not bound the length or checking time of such internal proofs. Finitary consistency bounds are model- and calculus-dependent; Pudlák's bounds concern specified finite consistency statements and do not provide this local clocked reflection principle. No certificate upper bound of the required kind has been derived here. [Pudlák on finite consistency](https://users.math.cas.cz/~pudlak/improved.pdf)

The group construction, cost bounds and actual-execution consequence have manuscript proofs. The Lean file verifies the finite fixed-point implication and the finite exposure facts. Historical priority for these applications of self-reference and matching to the pinned family is undetermined.
