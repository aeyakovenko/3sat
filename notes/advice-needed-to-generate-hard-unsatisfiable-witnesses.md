# How many advice bits must a certified hard-UNSAT constructor supply?

Fix one sound partial computable refutation checker \(V\). Its acceptance of \((F,\pi)\) must imply that the ordinary CNF \(F\) is unsatisfiable. Fix the scalar operations and a fixed logarithmic word-width coefficient for the constructors and checker. Programs observe the input length. The host may use a larger fixed logarithmic word-width coefficient for simulation. All times below count deterministic native instructions; \(N\) is the encoded length in bits and \(m=N+1\).

**Pointwise theorem.** Every globally correct SAT solver \(P\) has a globally correct augmentation \(P^+\) with \(t_{P^+}(F)=O_P(t_P(F)+m)\) on every file. The augmentation is chosen *before* the constructor. Fix any deterministic constructor \(G\), an integer \(a\in\{1,2,3\}\), and a constant \(A\). On a particular file \(F\), suppose that for some raw string \(y\) of length \(h\), running \(G(F,y)\) produces a refutation which \(V\) accepts, with their combined work at most \(Am^a\). Then
\[
 \min\{t_{P^+}(F),m^4\}\ \le\ C_{P,V,G,A,a}\,2^h m^a.
\]
The constant is independent of \(F,h,y\). It is also permissible for \(G\) to print \((F',\pi)\) from \(N,y\). Compare \(F'\) with the actual file before checking \(\pi\); the full comparison costs \(O(m)\). A constructor given the description of \(P^+\) can include that fixed description in its own code. The conclusion applies even when the constructor returns incorrect suggestions on every other seed or file. One fixed choice of \(P\), such as exhaustive search, gives one solver with the assertion simultaneously for all these constructors.

**Consequence for all-solver lower-bound proposals.** Suppose SAT has no \(O(N^k)\) solver, for \(k=1,2\) or \(3\), in the logarithmic-width RAM family under consideration. For each augmentation there is a single sequence of unsatisfiable files \(F_j\), of lengths \(N_j\ge j\), with \(t_{P^+}(F_j)>j(N_j+1)^k\). Indeed, if one correct solver met a fixed \(O(N^k)\) deadline on every negative file, run it to that deadline and return SAT on timeout. This gives a correct clocked solver on both verdicts. Finite exceptional lengths can be absorbed in the clock constant.

On **that same sequence**, for every fixed \(G,A,a\) as above, any advice successfully producing the certified witness at its advertised cost satisfies
\[
 h\ \ge\ (k-a)\log_2(N_j+1)+\log_2 j-O_{P,V,G,A,a}(1).
\]
This follows since \(j(N_j+1)^k\le(N_j+1)^4\). For constructors and verifiers of combined linear cost, a quadratic target requires at least \(\log_2(N_j+1)+\log_2j-O(1)\) bits, and a cubic target requires twice the length logarithm plus the same growing term. For a linear target the advice must still grow without bound. In a proposed finite-to-asymptotic construction these bits can specify choices of edits, branches or seeds, provided the resulting file and its certificate can actually be reconstructed and checked within the stated cost. The inequality is a necessary condition on a constructor of such witnesses. Existence of the hard sequence at these clocks is the open part.

## Two schedules and their native costs

For fixed \(G,A,a\), form a partial recognizer \(R\) that tries the empty string, the two one-bit strings, the four two-bit strings, and so on, in increasing length. Reset the generator and checker for each seed and cap their combined work at a fixed integer multiple of \(m^a\). Increase that multiplier to cover an implementation constant if necessary. Return UNSAT at the first checked success. A successful \(h\)-bit seed is reached within \(2^{h+1}-1\) attempts, including all shorter lengths. The program never needs the successful length as input. This gives the stated factor for **raw** advice without an extra cost for a self-delimiting encoding of \(h\). Within the relevant window \(2^h m^a\le m^4\), each trial index and its seed fit in a constant number of logarithmic words. The construction can abandon the search beyond that window.

There is an effective list \(R_0,R_1,\ldots\) of these wrapped recognizers: enumerate finite descriptions of \(G\), the three powers, and positive integer multipliers. Invalid descriptions abstain. The wrapper accepts only through the fixed checker. In a phase of budget \(B=2^r\), restart trial \(i<r\) for \(2^{r-i-1}\) interpreter ticks. The sum of all trial budgets is \(B-1\). The description indexed by \(i\) is decoded *inside* its allocation; a fixed-time counter enumerates indices \(0,\ldots,r-1\). A fixed \(R_i\) that succeeds in \(s\) guest steps succeeds by a phase of total duration \(O_i(s+1)\), including all preceding phases. Indeed the first power-of-two allocation covering its startup and its constant per-step simulation cost is within twice that required allocation. Per-trial and per-phase administrative work is \(O(B)\). Stop the race after the next power of two above \(m^5\). A fixed program index or startup constant may exceed that cap at finitely many small lengths; enlarging its constant covers them. When \(2^h m^a\le m^4\), the fifth-power cap eventually covers all constant simulation overhead. Above the fourth power the displayed inequality is automatic. Larger fixed outer windows can be used for other exponents.

For explicit memory accounting, retain \(P\)'s state while interleaving its steps with the search, and keep the original packed input untouched. Use separate banks for guest values and dirtied-address flags. A first write records the address on a list; after a restart clear only listed flags. Clearing costs at most a constant times the completed trial. A counter and loop bound of size \(m^5\) fit in constantly many logarithmic words. Choose a host coefficient large enough for the specified guest width conventions, the fifth-power counters and disjoint banks, including the input, simulated guest addresses, flags, dirty lists, advice and stage controller. When the guest sets its width from its own encoded input, use that **actual** width. In the nontrivial window a generator given the file receives \(N+O(h+\log(N+2))=O(N+1)\) bits, even with explicit framing. A constructor given only the binary length and seed may use a smaller native width; simulate its prescribed convention. Its charged, physically emitted proof contains at most \(O_A(m^a\log m)\) bits, so the verifier's entire encoded input also has logarithmic word width with a bounded fixed coefficient. If a guest word and host word have incommensurate widths, sequentially repack the two streams. Each copy operation consumes a source word or fills a destination word using shifts and masks. Store one native guest word per host array entry, and mask arithmetic to the actual guest width. Repacking costs \(O(m+1+\#\text{ emitted source words}+|\pi|/\log(m+1))=O_A(m^a)\) per candidate, including the original formula, and the embedded solver's initial copy costs \(O(m)\). An oversized or incomplete proposed proof can run out of its allocated ticks. The dirty flags distinguish the current writes from the pristine packed image. An interpreter can spend one simulation tick per elementary action of parsing a program or certificate and can suspend inside either parsing or execution. Once a particular fixed guest program has been decoded, its per-step dispatch cost is a constant specific to that guest. A guest text or immediate too large for the current allocation can time out; every fixed text fits at all sufficiently large lengths. Interleave the universal search and the embedded \(P\) at a constant ratio of host ticks, so a long reset or long candidate cannot starve \(P\). After the cap continue \(P\) alone. Global correctness follows from the soundness of a checked rejection and the correctness of \(P\). This argument uses the width allowance; it does not establish the same simulation when the host is forced to use exactly the guest's width. A common checker can cover many proof systems. For example, fix a sound computably axiomatized arithmetic theory with an effective proof predicate. A certificate may specify checker code \(W\), a theory proof that every accepting run of \(W\) certifies UNSAT, and an instance certificate. Check the theory proof and simulate \(W\) before accepting. Its fixed-code parsing cost and the fixed proof of soundness contribute constructor-dependent constants. The bound still charges the actual per-input verification. No proof about \(G\) or the original solver \(P\) is required. A true claim of soundness outside this chosen checker does not itself furnish an accepted certificate.

For a repeated algebraic construction, a single proof that the construction preserves negative verdicts suffices. Suppose \(D(N,y)\) starts with a member of a fixed finite list of known negative seeds, applies its chosen transformations, and prints an ordinary formula. Suppose the chosen theory proves that every formula it produces is unsatisfiable. Define \(W(F,y)\) to replay \(D\) on the encoded length of \(F\) and compare its output to \(F\). The one construction proof certifies this checker at every length. The candidate can supply \(y\) as its per-file evidence; there is no separate requirement to construct a resolution proof of each output. A finite mixed source set can be split by its fixed seed verdicts. If every path uses at most \(r\) choices from a fixed alphabet of size \(b\ge2\), reading digits of a base-\(b\) path index gives \(h\le\lceil r\log_2 b\rceil\) advice bits (the constructor can receive the seed length and pad unused digits). The lower bound then applies directly to the number of path choices whenever **the entire replay and comparison**, including path decoding, has the advertised running time. A deterministic lifting schedule with linear replay cannot exhibit superlinear negative witnesses for the augmented solver. This is a globally correct SAT program even away from the image of the construction.

The \(2^h\) dependence also has an exact black-box control. Give a wrapper access only to the outcome of each generator trial, and allow a single unknown length-\(h\) seed to yield the valid certificate. All failed trials may be indistinguishable. With the successful seed placed last, a deterministic wrapper can need all \(2^h\) length-\(h\) calls. This lower bound concerns black-box certificate selection; different SAT reasoning on the file may decide it immediately.

The [Lean formalization](../lean/AdviceForHardNegativeFiles.lean) checks correctness of the negative deadline, extracts the single growing hard sequence, and transfers the truncated pointwise bound to all constructors after the sequence is fixed. The native interpreter time bound is a manuscript argument.

The previous fixed-point construction builds a solver against a *specified* certified generator. Here the quantifiers allow the constructor to inspect an already fixed augmented solver, the seed length is unknown to the solver, and the extra \(\log j\) term survives at the linear deadline. Universal search and certification of algorithms have long precedents. Krajíček studies the information needed to find a proof in a fixed proof system; Chen, Flum and Müller study polynomially generated hard sequences; Hutter searches among programs with proofs of correctness and time bounds. The claim above is the pointwise native clock and raw-advice consequence, with no historical-priority claim.
