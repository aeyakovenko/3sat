# An implicit batch of balanced row queries

A single Boolean vector $z$ chooses one column in every row of a database. Each row names two or three coordinates of $z$, possibly negated, repeated or replaced by constants, and uses those bits as its column address. The decision question asks whether **some** $z$ hits only good entries. The description lists each row once and can represent exponentially many queries. This changes the earlier problem in which the incoming walk itself was supplied. [Earlier powered-walk query and table algorithm](nonlinear-work-after-the-one-bit-sat-cut.md)

For four-column balanced rows this problem takes linear time. At eight columns, a single fixed balanced table can carry all three unrestricted SAT time questions under linear-time, linear-encoded-length reductions. The complete classification below identifies which mixtures of tables do this. It specializes Schaefer’s Boolean constraint classification. The gadgets, bit-length estimates and native resource bounds give the connection to the proposed batch amplification. [Schaefer, *The Complexity of Satisfiability Problems*](https://doi.org/10.1145/800133.804350)

Use $m$ rows with dense names at most $3m$, an explicit balance mask, polarity bits and fixed-width name fields of $\Theta(\log(m+2))$ bits. Name zero provides a constant whose polarity chooses its value. Thus the encoded bit length is $N=\Theta(1+m\log(m+2))$ and each record fits constantly many $w=\Theta(\log(N+2))$-bit words. Clause order supplies the row order for the width result below.

## Complete table classification

A balanced two-bit table has two out of four tuples. Each such pair is an affine line, giving a pin or a binary XOR. All the conditions reduce to testing consistency of signed graph edges with a common zero vertex for pins. This takes $O(m+1)$ word steps.

A balanced three-bit table has four out of eight tuples. Call it affine if it is a translate of a binary vector space and bijunctive if it is definable by a 2-CNF. For a ternary relation, bijunctivity is equivalent to closure under coordinatewise majority. Indeed, the conjunction of all its one- and two-coordinate projections is a 2-CNF. If a tuple survives all its pair projections, choose three tuples of the relation, one agreeing on each pair. Their majority is the proposed tuple. Conversely every 2-clause is preserved by majority.

|Class|Number of balanced three-bit tables|
|---|---:|
|Affine and bijunctive|12|
|Bijunctive and non-affine|32|
|Affine and non-bijunctive|2|
|Neither|24|

There are seven nonzero linear functionals and two cosets for each, hence fourteen affine tables. Only the two cosets of full three-bit parity fail the majority test among them. If majority fails for any balanced table, complement coordinates so a missing majority becomes $000$. The three tuples giving that majority have disjoint nonempty supports, so they must be the three unit vectors. The fourth tuple is $111$ (full parity) or a weight-two vector. Up to coordinate permutation the latter gives $\{100,010,001,110\}$, precisely the graph of $z=\operatorname{NOR}(x,y)$. This table has one missing majority, obtained from the three unit vectors. Its signed permutations therefore yield $8\cdot3=24$ possibilities. Subtracting these classes gives the two remaining counts.

For a fixed allowable collection of tables, with arbitrary signed wiring, the following alternatives exhaust all cases.

* A bijunctive collection has a linear word-time algorithm using the implication graph.
* An affine collection gives sparse binary linear equations. If it includes full parity, it represents ordinary sparse 3-XOR consistency directly. Gaussian elimination decides it in polynomial time. The classification supplies no general linear-time algorithm for sparse 3-XOR.
* A collection containing one of the 24 gate tables can implement a complete NOR circuit with existential gate variables. A clause can be formed by a constant-size gate circuit and its final value pinned using the constant ports.
* Otherwise, a collection contained in neither tractable class contains a full parity table and a bijunctive non-affine table. Some two-coordinate projection of the latter table has exactly three tuples. If every projection were affine, their conjunction would be affine and equal to the original relation. A ternary table that is nonempty has a nonempty projection; among binary relations only the three-tuple ones are non-affine. Existentially allocate the third port privately for each use of this projection. Signed coordinate substitutions give any implication. For each source clause with literal values $a,b,c$, allocate three private marker bits $x,y,z$. Impose odd parity on the markers and the three implications $x\Rightarrow a$, $y\Rightarrow b$, $z\Rightarrow c$. An accepted marking has a true literal, and any one true literal can be marked alone. This realizes a 3-clause exactly.

The last two cases have reductions preserving the unrestricted deterministic linear, quadratic and cubic clocks in both directions. Before allocating private names for ordinary DIMACS input, normalize its ternary clauses and keep one representative per distinct clause. On $n$ encoded bits this leaves $O(1+n/\log(n+2))$ clauses and occurring names. Constantly many new rows and names per clause consequently give $O(n)$ output bits in $O(n)$ native steps, even when the original file repeats many short clauses. In reverse, rule out each forbidden row tuple with one clause, substituting constants, complementing negative ports, merging repeated literals and dropping tautologies. Pad any remaining short clause to proper width three by enumerating every sign pattern of enough fresh variables. Three globally reserved padding names suffice. This also handles an empty clause. The result has $O(m)$ proper clauses, $O(N)$ encoded bits and construction time $O(N)$. [Packed DIMACS normalization](packed-normalization-of-dimacs-clauses.md)

## Two occurrences suffice with a single table and no constant ports

There is a direct reduction even when **every variable occurs exactly twice**, every row has three distinct variables, and every row uses the single NOR table with signed ports. Feder established general hardness under fanout limitations. The construction below gives the gate count and encoded-length preservation explicitly. It enforces truth of selected clause occurrences using a monotone cycle. [Feder, *Fanout limitations on constraint systems*, Theorem 4](https://doi.org/10.1016/S0304-3975(99)00288-1)

Start with a normalized proper 3-CNF. Repeatedly delete a clause containing a variable of occurrence degree one. Its unique variable can always satisfy that clause when extending a model in reverse deletion order. Use occurrence lists, counters and a queue, taking linear time in the number of clauses. If no clauses remain, emit two gates on the same three distinct names imposing $c=a\land b$ and $c=a\lor b$, which have a common solution. Otherwise every remaining variable occurs in at least two different clause positions, and there are $m'$ clauses.

For one source variable, put a private state bit $t_i$ and a private marker $p_i$ at each occurrence, indexed cyclically. Emit one signed NOR row per occurrence. For a positive literal impose $t_{i+1}=t_i\lor p_i$. For a negative literal impose $t_i=t_{i+1}\land\neg p_i$. Both imply $t_i\le t_{i+1}$, so every state on the cycle has the same value $t$. A positive marker can be one only if $t=1$, and a negative marker only if $t=0$. Conversely any choice of markers selecting only true literals meets all these gates when the cycle states record the source truth value. Thus the markers may underreport true occurrences. This suffices for a clause disjunction.

For three clause markers $p,q,r$ use $a=\operatorname{NOR}(p,q)$ and $f=\operatorname{NOR}(\neg a,r)$, with $f$ forced false by three additional gates. The pin uses fresh $A,B,C,D$ and requires $B=f\land A$, $D=A\land C$ and $D=\neg(B\land C)$. Necessarily $C=1$ since otherwise the two equations for $D$ disagree. Then $A=D=\neg B$ and $B=f\land A$ force $A=D=1$ and $B=f=0$. These values work. Every AND, NAND and OR displayed above is a single NOR with appropriate port signs. The clause has a solution exactly when at least one marker is set. Every satisfying source assignment can mark one true literal per clause, and any satisfying network gives a satisfying source assignment by the cycle states.

Each marker belongs to its cycle gate and one clause gate. Each cycle state belongs to two different cycle gates, and the constraint table's three variables are distinct even on a two-occurrence cycle. Each name in the pin and clause gadgets belongs to exactly two rows, as inspection of the equations shows. Exactly $8m'$ rows suffice after the deletion step, comprising $3m'$ occurrence rows and $5m'$ clause rows. Dense names and the normalization bound above preserve linear encoded length and construction time. In contrast, if each name occurs at most once, the nonconstant names in distinct rows are disjoint and each row can be tested locally in one scan. This settles the occurrence threshold for carrying the SAT clocks in this signed-table representation. It does not require a gadget whose three single-use external bits are forced to be equal.

## When only a few rows escape the implication graph

Write $g$ for the number of gate tables and $h$ for the number of full parity tables. A deterministic algorithm on the dense encoding finishes in $O(N)$ ordinary steps whenever $1.365^g1.809^h\le N$, in any row order. This is a consequence of the deterministic Beigel–Eppstein algorithm, together with a bound on the time for removing the large 2-CNF portion. [Beigel and Eppstein, §5, size measure for three- and four-valued choices](https://arxiv.org/abs/cs/0006046)

Put the bijunctive rows in a 2-CNF $F$. Each NOR graph adds two binary clauses and one ternary clause, with the appropriate sign substitutions. Add the binary clauses to $F$ and keep a three-way choice of a true literal in the remaining clause. Each parity row gives a four-way choice of one accepted tuple; such a choice prescribes values of at most three named variables. Simplify constants and reject inconsistent local choices. This description allows a gate to have fewer than three remaining choices.

Test $F$ for consistency and compute reachability from each distinguished literal and its complement in its implication graph. There are $O(g+h)$ such sources, so this takes $O((1+g+h)(m+1))$ word operations. A set of selected literals extends to a model of satisfiable $F$ exactly if no selected literal reaches the complement of another selected literal, allowing the two selections to coincide. Indeed, a conflict in their implication closure gives paths $a\leadsto v$ and $b\leadsto\neg v$. Reversing and complementing the latter gives $v\leadsto\neg b$. Conversely a consistent implication closure extends to a 2-SAT model by the usual assignment of complementary strongly connected components. We may thus discard individually inconsistent choices and forbid incompatible pairs of choices at different rows. This takes $O((g+h+1)^2)$ additional time once reachability is known.

The remaining binary CSP has at most $g$ three-valued and $h$ four-valued variables, counting any smaller domains at their original upper cost. Beigel and Eppstein's deterministic algorithm measures them with weights $1$ and $2-\varepsilon$, with $\varepsilon$ about $0.095543$, and exponential base below $1.3645$. The displayed constants are rounded upward to absorb polynomial overhead in the reduced instance. Since the displayed condition implies $g+h=O(\log N)$ and $m\log(m+2)=O(N)$, the graph computations also fit the linear clock. In particular a census that only adds a few such rows to arbitrary 2-CNF wiring remains soluble in linear encoded-bit time within this band.

## What width in the row order costs on a native RAM

Let $p$ be the largest number of distinct variable names appearing both before and after any single boundary of the supplied order. One deterministic algorithm takes
$$
 O\!\left((m+1)(1+2^p/w)\right)
$$
native steps when the table fits the address space. In particular the full balanced-table language takes $O(N)$ on every supplied order with $p\le 2\log_2 w+O(1)$. No path decomposition has to be inferred. This uses the usual constraint-network dynamic program with packed Boolean masks. [Freuder, *Complexity of K-Tree Structured Constraint Satisfaction Problems*](https://cdn.aaai.org/AAAI/1990/AAAI90-001.pdf)

Compute each variable's first and last occurrence and the largest boundary size by two scans. Keep $p+3$ reusable slots. A bit in a $2^{p+3}$-bit table says that the named live variables can extend to satisfy the prefix. The bit is independent of unused slots. New variables on a row use free slots; at most three additional slots are needed. Intersect the table with the allowed mask of its named ports, formed by wordwise AND, OR and complement of the three coordinate masks in constant arity. For a forgotten slot $j$, OR together its two slices paired at distance $2^j$ and copy the result into both slices. This takes a constant number of word-vector shifts, masks and ORs. The operation computes existential quantification and restores independence of that slot. Precompute the $p+3$ coordinate-mask vectors in $O((p+3)(1+2^p/w))$ steps, by generating periodic bit patterns; masks for periods shorter than a word can be formed by successive doubling in $O(\log w)$ total per short-period mask, an additive $O((1+\log w)^2)=O(m+1)$ for growing $m$. The width is at most $3m$. If an actual word width is not a power of two, use only a power-of-two number of lanes per word within a factor two of $w$. The final table indicates whether any full selector succeeded.

There is an exact information obstruction at a forward cut. Fix $p\ge1$ shared variables. For each subset $S\subseteq\{0,1\}^p$ make an equal-length prefix. For each potential assignment $a$, in public order, compute the OR of its $p$ mismatch literals $z_i\mathbin{\mathrm{XOR}}a_i$ with a chain of NOR rows, passing the complemented previous result. Denote the resulting mismatch disjunction by $d$. Require $0=\operatorname{NOR}(d,b_a)$ with a constant port $b_a=[a\in S]$. This imposes exactly the desired exclusion if $a$ is forbidden. One bit per $a$ distinguishes the prefixes, in fixed locations. All internal gate names are private to a single link of a chain. A suffix of $p$ rows pins the shared bits to a chosen $x$, for example $1=\operatorname{NOR}(z_i\mathbin{\mathrm{XOR}}x_i,0)$. The verdict of the whole input is precisely $[x\in S]$. Every boundary has at most $p+1$ live variables.

An exact deterministic forward evaluator needs at least $2^{2^p}$ possible states at the prefix boundary, or $2^p$ bits if it uses fixed-length state encodings. Distinct subsets can be separated by appending the same pin suffix. This is the deterministic one-way indexing argument on actual balanced gate instances. A random-access machine on the promise can instead read the $p$ pins, compute the record index of $b_x$, and return that bit in $O(p+1)$ ordinary steps given the canonical size parameters. A globally correct solver can additionally validate the canonical template by scanning and ignoring the membership bits outside the selected slot, then fall back on other formats. The turn from a known selector to an existentially chosen selector recovers SAT on unrestricted wiring. The residual-table lower bound prices a specified forward evaluation, and the same instances have a linear total-time solver.
