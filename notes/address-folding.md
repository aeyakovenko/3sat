# Replaying a RAM computation with fewer physical cells

**Research journal, 2026-11-24.** Different virtual addresses can share one physical cell on a particular execution. Their values need only decode correctly when the CPU reads them. I tested how to verify such a replay, which traces admit it, and how much information the preceding physical write can supply.

## The preceding write as a read hint

Choose a fixed map h from virtual addresses to m physical cells. On a write of word u at a, store the token (a,u) in cell h(a). Initially each cell contains its own initialization tag. On a read at address b, a decoder D receives b and the token in cell h(b) and returns a word. The original CPU sees its full virtual addresses, so its arithmetic and control instructions are unaltered. A token takes a constant number of native words. Arbitrary per-address encoders Eₐ(u) and decoders Dᵦ(c) fit by composing the two on the supplied token.

For a supplied finite trace and fixed h, this works for some unrestricted decoder precisely when every occurrence of the same **(reader, preceding token)** requests the same answer. Necessity is determinism. For sufficiency set D equal to the observed answer on these pairs, filling unobserved pairs arbitrarily. Scanning the trace with the most recent token per physical cell and sorting the resulting triples by reader and token tests this criterion in quasilinear time in the explicit trace size. A small number of cells alone does not bound the description of D.

If the physical code alphabet is restricted to Q symbols, there is an exact extra condition. Make a vertex for each distinct observed write token and initialization tag. Join two tokens when some common reader must decode them to different words. A token conflicting with itself precludes every coding. Otherwise a Q-coloring is necessary and sufficient. Color a token by the physical code it stores. Conversely a reader and a color jointly determine at most one required word by the absence of monochromatic conflict edges. This is for a fixed h. A further refinement of the address partition need not preserve a particular valid decoding. For example write zero to a, one to b, zero to c, then read zero at a. With identity encoders and decoders all three can share one cell. Separating c while keeping a and b together gives the wrong read.

For binary values an intermediate case allows XOR with a static pad for each virtual address on both reads and writes. When a read at a requires u and follows a physical write of v at b, it imposes the equation pad(a) XOR pad(b)=u XOR v. A first read in a cell uses a variable for its initialized state. All pads exist exactly when the XOR around every cycle of the resulting signed graph is zero. One can propagate values from an arbitrary root of each component. This can save cells even without sophisticated decoders. Starting at address 0, read the initialized zero then write one at each fresh address in increasing order. With identity coding any two addresses sharing a cell give a wrong read. With pad(i)=i mod 2 and one physical cell initialized to zero, its state before each read is exactly the address pad. Value-dependent uses of physical storage are also studied in register allocation; the cycle criterion is classical signed-graph balance. [Chaitin et al.](https://doi.org/10.1016/0096-0551(81)90048-5) · [Harary](https://doi.org/10.1307/mmj/1028989917)

## Verifying the replay on the native source

Use the deterministic native interpreter with cutoff B=2^(20n), polynomial-bit words and the first omitted n-bit word vₙ. Guess a producing name, circuits for h and D of total encoded length S, and a division into fixed consecutive chunks of at most C native steps. Including all CPU and physical-cell states at the J=⌈B/C⌉ boundaries costs O(J(m+1)poly(n)) bits. Validate circuit format, including the range of h, or reduce its output modulo m. An initialization tag does not assume that every virtual address in a cell has the same initial value.

The guessed checkpoints describe a deterministic *folded* computation. Its agreement with the original memory is verified separately. Universally select a virtual address x. Existentially give its actual-word claim at every chunk boundary, starting with the known initialization at x for this name. Universally select one chunk. Replay its CPU and physical cells, checking the named boundaries, halt and target output. In this replay keep the single extra virtual word at x. Apply writes to x and check its reads against that word, including the claimed value passed to the next chunk. Common CPU and physical states make the folded replay identical for all choices of x. The per-address checks therefore give correct virtual memory semantics for that very stream. Conversely any faithful fold of a producing run supplies all the certificates.

The verification costs (S+J(m+1)+C)poly(n) deterministic RAM time under linear SAT. A local replay can guess answers to its adaptive circuit lookups and universally validate one selected query, after the local records are fixed. All lookups of a correct local replay have a common extension. A first wrong answer fails its selected query. This charges S once on the challenged branch. The remaining inputs, scratch, quantifier blocks and RAM-to-SAT transcript have the fixed costs used for the native source. Choosing C of order √(B(m+1)) gives time (S+√(B(m+1)))poly(n). For sufficiently large fixed a, take S≤B/nᵃ and m≤B/n^(2a). The native time also fits B when ranking the omissions of the certified output set. Guess its 2ⁿ-bit membership table, universally check a chosen entry, then compute all trailing gap scores in 2^(2n)poly(n) time. Consequently at least (K+1)/c−1 outputs in each interval [vₙ−K,vₙ) have **no producing name with such a faithful fold**, for a decoder-dependent constant c under linear SAT. At a hard output this applies even if a different h and D are selected after seeing each actual trace. Almost-complete coverage of a growing trailing interval by small folds at infinitely many lengths would refute the hypothesis. No such coverage has been proved. [Batched rank argument](native-first-reads.md) · [Gap bound](predecessor-batches.md)

The test may also admit a list of override timestamps and correct virtual words, charged at O(poly(n)) bits per row of this list. Replay uses the override at that precise read. The independent per-address check continues to enforce its correctness. For the hard predecessors of this enlarged test, feed all write tokens of any genuine producing trace through a proposed map and compare the decoder’s read forecasts on that trace. With circuits of size at most S/2 and the same cell cap, there must be more than B/n^(a+O(1)) incorrect stamped forecasts. Otherwise list all these disagreements. Induction in chronological order keeps the patched replay on the genuine trajectory, including every address it chooses later. This conclusion counts errors with the actual previous writer in each proposed cell supplied as a hint.

## What binary traces can force

Any graph can specify the exact minimum number of physical cells for a finite trace. For every edge {a,b} emit the six events

    write(b,0), write(a,0), read(b)=0, write(b,1), write(a,0), read(b)=1.

If the two addresses share a cell, both reads see precisely the token (a,0), an immediate contradiction. A proper coloring works with the identity word encoding since the gadget resets both relevant addresses. Thus the minimum is the chromatic number, irrespective of the permitted static encoder and decoder tables. The statement concerns faithful replay of the supplied trace.

A uniform five-event-per-address schedule already forces N distinct cells for exact replay with arbitrary codecs. Write zero to all N addresses in ascending order, read all the zeroes, then write one to all addresses. In descending order, read each one and then write zero at that address. Suppose a cell contains at least two addresses, with j its largest and i its next largest. Reading the zeroes required reader i to return zero on token (j,0). In the descending sweep j writes zero before i reads, and no intervening address writes to this cell. Reader i must now return one on the same token.

A uniform binary example gives a quantitative lower bound even for approximate forecasts. Take N addresses and distinct nonzero polynomials Pᵢ over the binary field with binary coefficient vectors encoding 1,…,N. Their degrees are less than u=⌈log₂(N+1)⌉. In a binary extension field of order q between 4u and 8u, use d=q² phases (a,b), with a,b independently ranging over that field. Set cᵢ(a,b) equal to one fixed nonzero binary coordinate of bPᵢ(a). In each phase, write cᵢ to all addresses in increasing address order, then read all their stored values, making no intervening writes. A fixed RAM can generate the phases and binary words in N·polylog(N+2) steps, for example by enumerating irreducible candidates at degree log₂ q and testing division by lower-degree polynomials. Field operations and recomputation per address cost polylog(N+2).

Each cᵢ has weight between 3d/8 and d/2. There are fewer than u roots, and at every nonroot half the choices of b give one. Applying the same argument to Pᵢ+Pⱼ gives the same bounds on pairwise Hamming distance. Thus for i≠j the distance of cᵢ from each of the all-zero, all-one, cⱼ and complemented cⱼ words is at least 3d/8.

Fix any static assignment of addresses to m cells and any read/write codecs, allowing arbitrary code alphabets and unbounded description length. Feed the *genuine* writes to the physical cells and count incorrect read forecasts. In each occupied cell its largest address j always wrote last. For a reader i in that cell the predicted phase word is a fixed Boolean function of cⱼ (a nonbinary prediction can be rounded to a Boolean value without increasing its error). There are only the four words above. Every nonrepresentative i therefore has at least 3d/8 wrong reads, for a total of at least **3(N−m)d/8** when m≤N. This can be a constant fraction even though every correct word is generated by a short program. A decoder also given the phase can directly compute the answer in this example.
