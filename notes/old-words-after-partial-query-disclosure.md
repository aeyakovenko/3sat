# Old words needed after a SAT solver has seen part of the query

An exact Horn certificate can retain all the information required by many queries. There is a separate cost to retrieving that information on an actual run of a general SAT solver. The cost below survives even if the solver reads several query bits before building its index, and even if it can overwrite arbitrary memory during the rest of the run. It is additive on one decision.

Use ordinary explicit Horn clauses of width at most three. On the hard scales below let $m$ be the number of edges of the *ambient* butterfly. The formula has $O(m)$ fixed-width clause records, bit length $L=\Theta(m\log m)$, and word width $\Theta(\log m)$. Put $r=\lfloor\log_2\log_2 m\rfloor$. A fixed self-delimiting input layout exposes only one logical query bit per query-dependent input word. Repeated reads of the same bit count once. Stop immediately **before** the instruction that first reads the $(r+1)$-st distinct query bit, or at termination if earlier. Call this the cut.

Fix any deterministic SAT solver and any constant $K\ge 1$. On the hard scales either some prefix through the cut uses more than $m(\log m)^K$ distinct work words, or on some input the solver reaches a nonterminal cut and its suffix reads
$$
                 \Omega_K(\log m/\log\log m)
$$
**distinct old addresses**. An old address means an immutable graph-data address, or a work address whose old value is read before any post-cut overwrite there. It may hold the initial zero word. Public format constants and the query bits themselves are free in this count. Ordinary work memory after the cut has no restriction. A word read and overwritten by a single instruction uses its old value if the instruction reads it first. In particular every hypothetical linear-time solver satisfies the second alternative for sufficiently large fixed $K$ and sufficiently large $m$.

## The formula

Use the hard static source-to-sink reachability problem on subgraphs of a public butterfly. With $O(m\,\mathrm{polylog}\,m)$ cells of $\Theta(\log m)$ bits its worst-case query time is $\Omega(\log m/\log\log m)$. In the proof in §5 take butterfly degree a power of two of order $(\log m)^4$, so the depth is $\Theta(\log m/\log\log m)$. Equivalently choose depth $d$ and degree a power of two of order $(d\log(2d))^4$. With $V$ nonsink vertices, $m=VB$, where $B$ is the degree. Thus $\log(Sd/V)=O(\log B)$ for any fixed polylogarithmic space overhead and the cell width is $O(\sqrt B)$. These are the ratios needed in the communication inequalities of §5. The reduction there uses source-sink pairs directly. [Pătraşcu, Theorem 1.2 and §5](https://people.csail.mit.edu/mip/papers/structures/paper.pdf)

Use one implication $R_u\to R_v$ for each present edge, with a public tautology in an absent edge's slot. To select a source from its binary address, give one positive unit fact per digit, naming the corresponding zero-choice or one-choice variable. Start a binary prefix tree with its root asserted. From each prefix and the matching digit fact, force the corresponding child by a two-antecedent Horn rule. Its selected leaf implies $R_s$. Make a separate tree for the sink digits, and at each sink leaf forbid its conjunction with the corresponding $R_t$. Forward chaining shows that a path from the selected source to the selected sink forces rejection. If the path is absent, activate just the two chosen paths, their supplied digit facts and the graph vertices reachable from the selected source. This is a satisfying assignment. Each selector tree has size linear in the number of endpoints. Pairing the two digit names so their identifiers differ in just one bit, and spacing the query unit records with fixed tautologies, ensures any one physical word reveals at most one logical query bit. These layout choices cost $O(\log m)$ extra records for a fixed word-size constant. All graph words and query offsets have fixed positions.

## A static data structure extracted from a single program

For each fixed graph, do unlimited preprocessing. Simulate the solver until it halts or would first load a word containing an unexposed query bit. Record the identity of that bit and branch on its two values. Once exposed, all later loads of that bit have a determined answer on this branch. Stop branching after $r$ new bits, but continue the simulation through all instructions before the next new bit. Save the registers, next instruction and sparse work memory there. Store a terminal flag and verdict on any branch that halts early. In the full power-of-two endpoint layout all bit assignments are valid. The graph and the exposed choices determine this prefix uniquely. Each leaf corresponds to a genuine partial execution.

There are at most $2^r$ leaves and fewer than $2^{r+1}$ nodes. If every prefix satisfies the work-word cap, all the leaf snapshots and the immutable graph data take $m\,\mathrm{polylog}\,m$ cells in total. Store the sparse snapshots by address with worst-case constant-probe perfect hashing, returning zero for absent keys. The polynomial address universe uses $O(\log m)$ bits per key. Preprocessing can search deterministically for suitable hash functions. Constantly many words suffice for the register file of the fixed program. [Fredman, Komlós and Szemerédi, static dictionaries](https://www.cs.princeton.edu/courses/archive/fall09/cos521/Handouts/storingasparse.pdf)

Given a query, follow the saved branch labels at cost $O(r+1)$ probes. The query algorithm already knows the whole source-sink pair. After loading the selected controller state, simulate the suffix with unlimited computation between static probes. Reads of public constants or query fields use no index probes. Cache every fetched graph word and every fetched old work value, including dictionary misses. Keep all simulated writes and cached words privately for the duration of this one query. Thus there are only $O(1)$ index probes per *distinct* old address, even if the suffix repeatedly reads it, rewrites it, or uses its contents as a pointer. This is a static cell-probe decision tree, whose next address may depend arbitrarily on the query and every earlier reply. Its output gives the genuine SAT verdict and hence reachability.

The static lower bound exceeds the $O(\log\log m)$ cost of following the prefix by an unbounded factor. It forces the asserted distinct-address count on one of the simulated suffixes. That suffix belongs to an actual single-input run of the original solver. A solver that merely peeks at a few arbitrary query words early cannot avoid the statement.

The bound can coexist with linear SAT on these Horn instances. A solver can scan the formula and run Horn forward chaining in linear word time in its number of literal occurrences. On the promised butterfly layout it can instead decode the query and test the unique public path against the edge slots directly. Even charging the bound separately for each of $k$ explicit source-sink queries would give only $k\log m/\log\log m$ word probes, while their binary identifiers alone occupy $\Theta(k\log m)$ input bits. The argument supplies one cut with a logarithmic-scale cost. Deriving a superlinear bound for SAT would require a way to force sufficiently many costs on the same input while accounting for reused data or different computations. ## A long query forces a linear number of distinct old words, without a prefix cap

There is a complementary statement about *every* deterministic solver with arbitrarily much preprocessing inside the actual run. Take $s=q=2^j$ and two private lists $a,b\in[q]^s$. Give Alice the positive units $X_{i,a_i}$ and Bob the negative units $\neg X_{i,b_i}$, in separate arrays of public layout. Repeating literals gives a width-three serialization. Identifiers have $O(\log s)$ bits, the encoded length is $L=\Theta(s\log s)$, and each aligned input word depends on at most one party. Fixed padding or a public gap between the lists handles the bank boundary. The answer is one exactly when $a_i\ne b_i$ for all $i$. Its real communication matrix is $(J_q-I_q)^{\otimes s}$ and has rank $q^s$, since $J_q-I_q$ is invertible. An exact deterministic protocol publishing the decision requires at least $s\log_2q$ bits in the worst case by the rectangle rank bound. [Split unit-clause construction and rank proof](split-unit-batch-rank.md)

Cut immediately before the first read of an $(r+1)$-st distinct Alice-dependent input word, or at an earlier halt. For the fixed solver there is a constant $c>0$ such that taking $r=\lfloor cs\rfloor$, some real execution reaches this cut and afterwards reads at least $cs$ distinct addresses of the following two types together:

- Bob-dependent immutable input words.
- Work addresses first read after the cut before any intervening overwrite there, including zero-valued addresses.

To prove it, Bob first simulates the entire prefix with his private workspace. At each new Alice-dependent input word he sends its address to Alice, gets its value and caches it. His communication up to the cut is $O((r+1)\log s)$, even if the prefix time and number of work stores are enormous. If the solver halted, publish the answer. Otherwise send Alice the constantly many words of controller state. She now simulates the suffix, keeps all post-cut stores, knows her own input, and asks Bob for each other old word just once. He has his input and the *actual* frozen memory, including its default values. Prefix-free request and response types, the handoff and the output cost at most $C(r+k+1)\log_2s$ bits for a fixed $C$, where $k$ is the number of distinct old addresses on this input. Early halts have $k=0$. Choose $c<1/(3C)$. If all runs had $k<cs$, the communication bound would be violated for large $s$. This proves the suffix claim with no bound on prefix space. A single CPU operation that probes multiple words can be split into constantly many word probes with a constant-size controller.

Here $s=\Theta(L/\log L)$. Comparing corresponding identifiers directly answers the promised SAT instance in $O(s)$ word operations. Thus the suffix lower bound attains the scale of the *entire* running time available on this family. It applies after a positive fraction of the query words have already been read and leaves the unrestricted superlinear target open.
