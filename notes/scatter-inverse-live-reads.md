# A linear RAM scan whose incoming reads resist local prediction

**Research journal, 24 November 2026.** The live-read argument for SAT asks for a cheap predictor at one start in every long interval. The following fixed linear-time RAM computation is a counterexample to a version of that shortcut applying to arbitrary explicit inputs. It includes the original input and the genuine prior events in the predictor's context.

Encode a permutation $\pi$ of $[m]$ in $m$ fields of $\lceil\log_2(m+1)\rceil$ bits, so the input length is $N=\Theta(m\log m)$. In a scatter pass write $i$ at work address $\pi(i)$. In the next pass read work addresses $1,2,\ldots,m$ in order. Both passes use $O(m)$ native operations. Use fixed-duration scan iterations, put the incoming value in a register and overwrite it before the following iteration. The control flow and scan addresses are public. One packed input read reveals at most constantly many permutation entries. The middle half of the scan has $\Theta(m)$ instruction times.

Fix a deterministic query evaluator, with the same context as in the [live-segment theorem](live-segment-snapshot-queries.md). Advice, its length, original input, address, actual time, current controller and strict prior local event history can all be read. Write $s$ for row length and $q$ for worst honest query time. Fix $0<\kappa<\min(\gamma,1/2)$ with $\gamma<1$, and $w=\lceil N^\gamma\rceil$. For all large sizes there is an explicit permutation input on which **every** start in the middle half of the scan has $s+q>N^\kappa$ for predicting the first incoming read at each applicable address in its next $2w$ instructions. Each start may use its own row with unlimited preprocessing. The claim of existence concerns a stored permutation table. An efficient algorithm producing its entries from the size alone is not known here.

There is a shared-advice version. For fixed $0\le\theta<1-\kappa$, one can choose a single permutation input such that, for **every** common bank of at most $N^\theta$ bits, some interval of at least $w$ consecutive starts has the same hardness at every start. The interval may depend on the bank. The computation is a pair of ordinary array passes, independent of the decoder.

## Deferred decisions with several starts and a common bank

Consider a proposed set of $k$ starting times at which $s,q\le r$. For each start take its first $h$ full scan reads, with $h$ small enough to fit its horizon, and require that the $k$ sets of keys be disjoint. Conditional on the proposed starting times, the sets are fixed in advance. An $O(\log m)$-bit header per start can give the true initial controller and any within-instruction phase. If a start partially overlaps one scan read, include its one word among the header guesses. Simulate the reports in chronological order within each chosen segment. Give the evaluator the simulated prefix, including the earlier native answers. On genuine predictions this prefix is the exact one required by the theorem. On dishonest predictions run the same deterministic simulation with a hard cap of $r$ per call. Record the proposed inverse of each key and probe that location in $\pi$ to verify it. Every successful simulation now makes at most $J=Ckh(r+1)$ adaptive permutation probes and finds the positions of all $kh$ chosen keys, for a fixed $C$ including bit packing. Simulating a supplied prefix or its random-access lookup can use unbounded ordinary computation in this probe argument.

For a uniform permutation, each fresh domain probe reveals a uniformly random unused image, conditional on all prior probes. Repeats can be discarded and the strategy padded with fresh probes up to $J\le m$. Finding all the designated images has probability at most
$$
 \frac{\binom J{kh}}{\binom m{kh}}\le(J/m)^{kh}.
$$
An exhaustive check on seven items gives 576 hits among 5,040 permutations for each of four adaptive strategies making four fresh probes with three designated targets, as the formula predicts. [Reproducible exposure and cycle tests](../audits/scatter_inverse_live_experiment.py)

The verification probes ensure this covers a lucky correct answer whose inverse was never read during prediction. The simulation just described fixes the bank, descriptions, clocks, headers and starts *before* drawing the permutation. A union bound over their possible values restores per-permutation preprocessing and arbitrary choice of starts.

For detail, take $r=\lfloor N^\kappa\rfloor$, $B=\lfloor N^\theta\rfloor$ and
$$
 h=\left\lfloor\min\{w/C_1,\ m/(C_1(r+1))\}\right\rfloor,\qquad
 k=\max(1,\lceil 2(B+10\log_2 m+2)/h\rceil).
$$
Choose the fixed $C_1$ sufficiently large. Then $h/(r+\log m)\to\infty$, $h=O(w)$ and $B(r+1)=o(m)$. In particular $J\le m/8$ eventually since $kh\le 2(B+10\log_2 m+2)+h$. The number of common banks, rows of length at most $r$, coordinates and headers is at most $2^{B+1+k(r+O(\log m))}$. Multiplied by $8^{-kh}$ this tends to zero. The same calculation with $B=0$ gives $k=1$ and rules out **any** cheap start. Both exceptional probabilities can be summed.

For a successful hard permutation, fix the bank. A maximal collection of disjoint cheap $h$-key intervals has fewer than $k$ elements. Every other cheap start has a key interval meeting one of these, so all cheap starts are contained in fewer than $k$ intervals of $O(h)$ scan times each. They cover only $O(kh)=O(B+h+\log m)=o(m)$ times. Some remaining gap has length $\Omega(m/k)$. If $h$ is of order $w$ then $m/k=\Omega(m/(1+B/w))\gg w$. If $h$ is of order $m/(r+1)$ then $B=o(h)$ and $k=1$ for all large $m$. These comparisons use $w=o(m)$. This proves the claimed interval, including start times between consecutive array loads.

The classical time-advice tradeoff for inverting a permutation concerns a fresh target sampled after preprocessing. Here the target keys form a prescribed contiguous portion of an actual native trace, and every earlier answer from the current portion is available to the predictor. The elementary exposure of multiple distinct, designated keys is what handles that extra information. [De, Trevisan and Tulsiani](https://www.ias.edu/sites/default/files/math/De_Trevisan_Tulsiani.pdf) · [Corrigan-Gibbs and Kogan](https://eccc.weizmann.ac.il/report/2018/182/)

## Two upper bounds and the role of the source

For a single start, record the words of its next $O(w)$ incoming reads in order. This gives $O(w\log m)$ bits and constant-time lookup using the public scan offset. For the entire scan there is a classical cycle index. Mark $O(m/b)$ evenly separated landmarks on cycles of length at least $b$, with gaps at most $2b$, storing the previous landmark on each marked cycle. The unmarked cycles have length below $b$. Starting at a target key, follow $\pi$ forward to a landmark or around its full unmarked cycle. At a marked cycle use the preceding landmark and walk forward to the target's predecessor. When the target is itself marked, use its preceding landmark, allowing a single-landmark cycle to wrap around. The index needs $O((1+m/b)\log m)$ bits. A sorted landmark array gives $O(b\log m)$ native query time; a static perfect-hash dictionary on the specified arithmetic ISA gives $O(b)$ native query time. Taking $b=\lceil\sqrt{m\log m}\rceil$ in the latter version gives $s+q=O(\sqrt{m\log m})$ uniformly. Thus this example reaches the square-root exponent and does not obstruct every possible choice of scales. [Permutation cycle index](https://eprint.iacr.org/2019/1046.pdf) · [Fredman, Komlós and Szemerédi](https://www.cs.princeton.edu/courses/archive/fall09/cos521/Handouts/storingasparse.pdf)

For fixed rational exponents, fixed evaluator and fixed generous integer clock constants, the lexicographically first suitable permutation is a computable function of $m$. One can exhaust all finite banks, rows, starts and clocked simulations in its definition. Its ordinary description length given $m$ is therefore bounded by a constant, even though it has the proven query obstruction **when supplied as the explicit forward table**. This distinguishes a short unbounded-time description from an efficient local forward generator.

In fact the obstruction disappears under the near-linear SAT hypothesis if a suitable local forward generator exists. Suppose $\pi(i)$ can be computed from $z$ public words in $u$ steps on a common polynomial scale. To test whether the preimage of a target has a given prefix, guess an index with that prefix and run the forward generator. Materialize the ordinary bounded-computation formula and decide it with the hypothetical SAT solver. Trying the two possible next bits recovers the unique inverse in $\widetilde O(u+z+1)$ native time, including $O(\log m)$ prefix tests and full construction of their instances. This applies when the original formula is a virtual locally generated $F_x$ and its public source $x$ is small. Length by itself gives no clock on the forward generator. For an arbitrary explicit permutation, materializing the $m$ public fields costs too much for this inversion shortcut. The scatter example therefore cannot refute the missing claim specifically on cheaply generated diagonal formulas.

The same prefix search handles collisions. For events indexed by $i$ whose active flag, target address and value are locally generated in $u$ steps from the same $z$ words, test if any active event at or after a threshold writes the requested address. Binary search identifies the latest such event, or certifies that there is none. Evaluate its value once, and use the initial value if there was no write. The $\widetilde O(u+z+1)$ bound is independent of the number of candidate events as long as their indices have logarithmic width. A genuinely sequential solver may need to reconstruct earlier work memory and control to generate even one event. No bound on that cost has been proved for every fast solver.
