# One false memory bank across a batch of SAT decisions

Trying several SAT files can require their claimed RAM histories to agree on one shared object. For binary affine fingerprints there is an exact limit even when the shared object specifies **every** suspect read reply in the batch. The wrapper below converts any correct deterministic SAT solver into another correct deterministic solver at an additive linear cost per input. On genuine executions its extra memory reads always return zero.

Fix $1\le m\le d$. On $m$ equally long, individually indexed ordinary SAT files let $b=(b_0,\ldots,b_{m-1})$ be their true verdicts. Use the chronological CPU and address-sorted memory checks separately. Compare their memory events with any adaptive binary affine measurements, possibly mixing files, times, addresses and bit positions. One shared false bank must supply all the chronological replies, including repeated reads within and across files. Each sorted memory table is the genuine one. Along the responses given by the genuine memory tables, the least total binary rank at which the measurements can rule out even **one** proposed verdict vector is exactly
$$
                                d-m+1.
$$
For rank at most $d-m$, every vector, including one that changes only a specified verdict, has a joint realization on the same bank for the entire batch. The bank can depend on the concluded path and desired verdicts. The result concerns event authentication; the CPU instructions themselves are checked exactly. ## A native computation with a shared possible error

After running the original solver, retain its verdict in a register. Write zero to a bank of $2d+m-1$ cells, ordered as $u_0,\ldots,u_{d-1}$ followed by $v_0,\ldots,v_{d+m-2}$. This explicit clearing works even if the solver previously used the addresses. For the file indexed by $h<m$ take the following correction in the verdict register, with arithmetic over $\mathbb F_2$:
$$
 G_h(u,v)=\sum_{i=0}^{d-1}u_i v_{i+h}+v_h+v_{2h}.
$$
A straight counted loop loads two bits per iteration, uses word AND and XOR, and accumulates in one register. Its branch and its addresses depend only on the public iteration count and file header. The final two reads are in range. Return $b_h+G_h$ in the halting control, with no output-dependent writable event. No true answer changes because $G(0,0)=0$. The wrapper uses $O(d+m)$ extra instructions, $O(1)$ registers and logarithmic-bit addresses.

For an explicit tagged family start with any $m$ proper 3-SAT payloads. An ignored ASCII DIMACS comment with a fixed-width identifier records $h$; equal-length files can be obtained by padding the shorter files with spaces. Where comments are disallowed, use the signs of the first literal in a fixed number of dedicated initial clauses, using three fresh variables per clause. These disjoint clauses are each satisfiable with either first sign. The indexed family can have all payloads or all verdicts identical if desired. The true solver still handles every file. Its wrapper can do bounded parsing and return its saved verdict on an absent or invalid index. An implementation at all lengths, for example, can use $d=\lfloor N/8\rfloor$, $m=\lfloor d/2\rfloor$ for $N$ encoded bits, with fixed defaults on tiny inputs. Any transform here preserves a hypothetical linear clock and claims no bound on the speed of the original solver.

Keep the full chronological prefix of the true execution up through the cleared bank. Thereafter use the same pair of arrays $(u,v)$ in all $m$ chronological simulations. The memory-valid table in each file still records zero at all these reads. The only differences in memory-event fields are the returned binary payloads, each of which is a projection of the same bank bits. The halt verdict and the CPU register contents are derived locally on the chronological side. In particular the allowed comparisons are on memory events, not arbitrary functions of the CPU registers: inspecting the final verdict as if it were already known would change the test.

After following genuine replies through any adaptive comparison protocol, its restrictions on the bank consist of affine equations. They hold at the zero bank. Take their effective rank $r$, counting repeated or dependent observations just once. This reasoning allows arbitrary computation to select the next affine measurements from the full prior responses. It also allows arbitrary affine combinations of per-record encodings of an individual payload bit, since replacing its two possible encodings by their two lookup values is affine in that one bit. Multiplicative fingerprint comparisons across records fall outside this claim.

## Finding a common bank

Here is a constructive proof that also covers an arbitrary nonempty affine response fiber. Write its equations as $A u+Bv=c$, with joint rank $r$. Put $b'=\operatorname{rank} B$ and $a'=r-b'$. The possible first banks form an affine space of dimension $d-a'$ by projecting off the image of $B$. For one such $u$, the $m$ output equations are linear in $v$. They give every $m$-bit target jointly with $Bv=c-Au$ if their rows are independent modulo the row space of $B$.

Represent $u$ and a nonzero output mask $\lambda$ by binary polynomials $U$ and $\Lambda$ of degrees less than $d$ and $m$. The row of the output equations selected by $\lambda$, as a coefficient vector on $v$, is the polynomial
$$
                        U\Lambda+\Lambda+\Lambda^2.
$$
There is no truncation, since its degree is at most $d+m-2$. For fixed $\lambda\ne0$ this function of $U$ is injective by cancellation in $\mathbb F_2[X]$. At most $2^{b'}$ first banks make this row land in the row space of $B$. Taking all nonzero masks rules out at most $(2^m-1)2^{b'}$ first banks. With $r\le d-m$, that is strictly fewer than the $2^{d-a'}$ feasible first banks. **One first bank even works for every output vector**, with only the second bank changed to realize the vector. When $r\le d-m-1$, more than half the feasible first banks work, so randomized Gaussian elimination finds a common bank for any given target using fewer than two trials in expectation and polynomial time in the explicit equations. At the boundary the same proof guarantees a successful search by finite enumeration. This argument uses the full-rank bilinear map behind the earlier Fourier estimate. For the matching obstruction measure $u_0$ and all $u_i$ with $i\ge m$ and require their honest values. This uses $d-m+1$ bits, all directly readable as memory-event payloads in a single file. Put $z=u+e_0$, so that $z_0=1$ and $z$ is supported below $m$. Then $G_h=\sum_{i<m}z_i v_{i+h}+v_{2h}$. The sum $\sum_{h<m} z_hG_h$ vanishes: off-diagonal terms cancel in pairs and $z_h^2=z_h$ cancels the diagonal. Thus $G=e_0$ is impossible and the vector $b+e_0$ is ruled out. [Lean verification of the symmetric cancellation](../lean/ShiftedConvolutionSlice.lean) · [Finite rank and common-first-bank audit](../audits/shared_bank_verdict_audit.py)

This defeats a specific induction from many separate accepting files to a shared verdict witness: a common substitute bank, many known sibling verdicts and adaptive affine event tests can all coexist with the opposite value on the remaining file. Even a single integer sum of the nonnegative active payload bits in the clearing suffix, compared with the genuine zero sum, settles this construction. That sum uses growing integer precision and its binary digits are nonlinear in the bank bits. A time lower bound for ordinary SAT needs an argument that applies to the solver even after this suffix is removed.

The audit enumerated 179,827 affine fibers over five finite parameter pairs, checking a common first bank on each fiber and the exact upper obstruction at each parameter. For a three-file proper 3-SAT batch with actual verdicts SAT, UNSAT, SAT, it also checked all eight output vectors after one adaptive pair of measurements. The native wrapper and the rank lower bound are manuscript proofs. The earlier Lean file checks the symmetric cancellation used for sharpness.
