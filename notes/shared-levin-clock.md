# Two descriptions that share one charge for running time

**Research journal, 24 November 2026.** There is an unconditional failure of symmetry of information for Levin's Kt complexity. A pair may be produced by two long calculations one after the other and pay for their running time only once in logarithmic units. I tested whether this failure survives when both sides of the proposed inequality pay on the same basis. A superlogarithmic failure in that setting would exclude deterministic linear-time SAT on the unrestricted-workspace RAM. A family of pairs that saturates the usual failure instead illustrates exactly how much a second time charge costs. [Hirahara, Section 2.2, on Ronneburger’s construction](https://drops.dagstuhl.de/storage/00lipics/lipics-vol234-ccc2022/LIPIcs.CCC.2022.26/LIPIcs.CCC.2022.26.pdf) · [Earlier symmetry under P = NP](https://www.sciencedirect.com/science/article/pii/S0890540185711200)

Use fixed efficient native prefix interpreters for joint, unconditional and conditional output. A joint program publishes an explicitly encoded pair. Let $m=|x|+|z|+2$, let $u(p)=\lceil\log_2\max(2,\tau(p))\rceil$ denote the log time on the specified input, and let $L(x,z)$ minimize $|e|+u(e)$ over joint programs. For $0\le\lambda\le1$ define
$$
F_\lambda(x,z)=\min\big\{|p|+|v|+\max(u(p),u(v))+\lambda\min(u(p),u(v))\big\}
$$
over $p$ printing $x$ and $v$ printing $z$ given $(x,|p|)$. The auxiliary length is the number of bits actually consumed by $p$. It can be passed by a concatenating decoder without looking up an optimal complexity.

Under linear SAT,
$$
L(x,z)-O(\log m)\le F_0(x,z)\le L(x,z)+O(\log m),\qquad
F_\lambda(x,z)\le (1+\lambda)L(x,z)+O(\log m).
$$
The canonical program indices in the final sections strengthen both displayed error terms to $O(\log(L(x,z)+2))$. A gap larger than every constant multiple of this smaller quantity on one fixed interpreter would exclude linear SAT. There are interpreters on which the logarithmic scale itself is attained unconditionally.

The first lower bound holds unconditionally. Concatenate $p,v$, simulate them in order, and encode the pair. Simulation costs at most $\max(\tau(p),\tau(v))\mathrm{polylog}(2+\max(\tau(p),\tau(v)))$ plus polynomial overhead in the returned lengths for elementary encoding. More explicitly, copying and serializing the outputs takes linear or quasilinear time in their combined explicit length, which fits the same bound up to the native word size. The minimizing cost for $F_0$ is at most $O(m)$ by literal programs. Taking logarithms thus costs $O(\log m)$ extra bits. Joint and conditional conventions can include a boundary marker or a fixed linear-time pair coding.

## Splitting a bounded set of pairs

Let $e$ achieve the joint minimum, let $j=u(e)$, $s=2^j$ and $l=|e|$. Then $l+j=L(x,z)\le O(m)$ by literal printing. Fix the two output lengths. Let $E$ be the set of pairs of those lengths produced by some name of length at most $l$ by $s$. This set has cardinality at most $2^l$ by prefix-freeness, and membership has a fixed-block test of time $s\,\mathrm{poly}(m+j+l)$ under linear SAT. Guess the name and bounded transcript and check exact input consumption and both outputs. All these parameters except $s$ may be self-delimited using $O(\log m)$ bits in total; specify $s$ by $j$.

We use a static fact about a set $B$ of words of one length $h\le m$ with a fixed-block membership test at this clock. Once the parameters are supplied, every $w\in B$ has a description of at most $\lceil\log_2 |B|\rceil+O(1)$ bits if the approximate size exponent is also supplied, with decoding time $s\,\mathrm{poly}(m+j+l)$. At each prefix of the word use projected approximate counting on $8\max(1,h)$-tuples to compute an integer upper estimate for the number of extensions with relative factor at most $2^{1/\max(1,h)}$, detecting an empty set separately. Split $[0,1)$ at each node in the ratio of the two estimated child counts. Each leaf then has width at least $1/(2|B|)$ by multiplying along its path. A dyadic cylinder of width $2^{-a-2}$ fits any leaf if $a\ge\log_2 |B|$. With $a$ in the header, a decoder reads that exact number $a+2$ of raw bits, descends the tree from the cylinder's left endpoint and tests that it is the designated cylinder in the leaf. Rational endpoints have polynomially many bits in $m$. An exponent accurate within a constant above $\log_2|B|$ therefore suffices. Here one can use the actual ceiling supplied nonuniformly in the program header. For $h=0$ the only possible word is empty. [Counting lemma](near-native-counting.md) · [Subdivision and finite verification](near-clock-coding.md)

Let $N_w$ be the number of second components paired with $w$ in $E$. Compute the same deterministic coarse lower estimate $B_w$ with $N_w/32\le B_w\le N_w$ when $N_w>0$ and zero otherwise. Choose $r=\lfloor\log_2 B_x\rfloor$ and set $X=\{w:B_w\ge 2^r\}$. Negative values of $r$ down to $-5$ are allowed. Since $\sum_w N_w\le 2^l$, $|X|\le 2^{l-r}$. Also $N_x< 64\cdot2^r$. Membership in $X$ uses one deterministic approximate count under linear SAT and has the same $s\,\mathrm{poly}(m+j+l)$ bound; simulating that fixed computation inside a subsequent fixed-block test only adds polylogarithmic factors in its time. Use the static decoder for $X$ with exponent $l-r$ and for the section of $E$ at $x$ with exponent $r+6$. Both exponents are nonnegative. Only $O(\log m)$ total header bits are needed, even if all parameters are repeated independently on the two machines. The resulting pair $p,v$ has total length at most $l+O(\log m)$, and each runs in at most $s\,\mathrm{poly}(m+j+l)$. The second decoder can ignore the supplied $|p|$. This proves the upper bound for $F_0$. Since $\min(u(p),u(v))\le j+O(\log m)\le L(x,z)+O(\log m)$, the other upper bound follows for the same descriptions.

## A simultaneous sharpness test for every extra time charge

For all sufficiently large $n$ one can unconditionally construct two $n$-bit words $x,z$ with
$$
L(x,z)=n+O(\log n),\qquad F_\lambda(x,z)=(1+\lambda)n+O(\log n)
\quad(0\le\lambda\le1).
$$
The words do not depend on $\lambda$. To choose $x$, run every candidate of length $l<n$ for $2^{n-l}$ steps on the first interpreter. Mark every actual $n$-bit output, and take the first unmarked word. There are fewer than $2^n$ candidates and the resulting word has $|p|+u(p)\ge n$ for every name. The computation takes $2^n\mathrm{poly}(n)$ steps since each length costs at most $2^n$ simulated steps before the native overhead.

For $z$, simultaneously avoid low-cost outputs conditional on $(x,k)$ for every integer $0\le k\le 2n$. Set $h=n-\lceil\log_2(2n+1)\rceil-1$. For each $k$, simulate all candidates of length $l<h$ for $2^{h-l}$ steps. Fewer than $(2n+1)2^h<2^n$ words can be marked altogether. The first unmarked $z$ has $|v|+u(v)\ge h$ under each allowed auxiliary pair. Again the work is $2^n\mathrm{poly}(n)$ at most. A joint program supplied with $n$ carries out both calculations in order, giving the stated upper bound for $L$. For the reverse bound project a joint name onto its first component, with only polylogarithmic time overhead for a linear-time pair extraction. A minimizing name costs $O(n)$, so $L(x,z)\ge n-O(\log n)$.

If $|p|>2n$ the claimed lower bound for $F_\lambda$ already holds. Otherwise $|p|+u(p)\ge n$ and $|v|+u(v)\ge h$ simultaneously. The cost with the shared charge is at least $n$; with both charges it is at least $n+h$. Taking the convex combination of these two inequalities gives $F_\lambda\ge n+\lambda h$. Conversely, two short programs can separately run the deterministic constructions for $x$ and for $z$ given $x$, within the displayed clocks and with $n$ in a short header. This proves matching upper bounds on this family without a SAT assumption.

Consequently a linear excess at any fixed $\lambda>0$ is already compatible with the conditional bounds, and its optimal leading coefficient on this family is known. The remaining target in this approach is an excess $F_0-L$ that grows faster than $\log m$ on one fixed set of ordinary interpreters. The construction has only a logarithmic allowance at $\lambda=0$. Exponential lower bounds for deciding randomized Kt promise problems use a different task and do not supply this missing excess. [Hirahara, Theorem 1.4](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2022.26)

## A bound in terms of joint cost alone

Both logarithmic errors in the shared-clock bounds can be charged to the optimal **joint cost**, even when the explicit returned words are much longer than that cost. Uniformly under linear SAT, with $L=L(x,z)$,
$$
 |F_0(x,z)-L|\le O(\log(L+2)),\qquad
 F_\lambda(x,z)\le (1+\lambda)L+O(\log(L+2))\quad(0\le\lambda\le1).
$$
The lower inequality $F_0\ge L-O(\log(L+2))$ is unconditional. Concatenating a minimizing pair of names has combined cost at most $F_0+O(\log(F_0+2))$: their physical times are at most $2^{F_0}$ and the explicit output capacity per step is polylogarithmic in their running time. Sequential simulation, copying and unambiguous pair encoding take at most a polylogarithmic factor over the larger native time. Counting the first consumed prefix for the second auxiliary input fits the same allowance. When $F_0\le L$ this proves the assertion, and when $F_0>L$ the lower inequality already holds.

For the upper bound retain $j=u(e)$, $s=2^j$, $l=|e|$ for a minimizing joint name. Then $l+j=L$. Drop the two output-length parameters. Give every candidate name of length at most $l$ a fixed-width $h=l+1$ bit key, its zero-based length-lexicographic rank among those names, leaving one unused key. Admit a name only when the joint interpreter consumes it exactly and publishes a valid pair by $s$. For any first component encountered, choose its least admitted producer key as its canonical representative; define second-component representatives separately in the same way. Let $E'$ contain $(a,b)$ precisely when $a,b$ are canonical representatives in their respective positions and some admitted joint name prints their two represented components together. This set is in bijection with the distinct full pairs in the whole time/length budget, so $|E'|\le2^l$.

Membership in $E'$ is a fixed-block test. Guess a joining name and universally challenge the canonicity with a smaller key for either component. All simulations on these names use the same $s$-step bound, with explicit comparison of the required pair components. The largest output on such a trial has $s\,\mathrm{poly}(j+2)$ bits by the native capacity bound. Reading it, locating the boundary and checking equality for unequal as well as equal lengths fit $s\,\mathrm{poly}(L+2)$ time. No length of an individual output is supplied as advice. Using a fixed self-delimiting pair encoding or the native marked boundary makes this check uniform.

Apply the static prefix-count and two-section argument above to the $h$-bit keys of $E'$. Its tuple lengths and prefix depths are polynomial in $L+2$, and all membership, nested count and reconstruction work takes $s\,\mathrm{poly}(L+2)$ time. Given the resulting first key, simulate its admitted name to obtain $x$. Given auxiliary $x$, find its canonical first key by prefix extension on the existence of an admitted joint name with that key prefix and first component equal to $x$, taking the least completion in fixed-width order. This needs at most $h$ deterministic tests under linear SAT. On the auxiliary input of interest its full explicit length fits the same native output bound. A verifier intended also for other auxiliary inputs can scan only through that bound plus one termination or boundary marker, rejecting an overlong first component. The second program ignores the supplied $|p|$ and uses the recovered first key to decode the section key, then simulates the latter's producer to recover $z$. This includes the cost of reading auxiliary input and writing both long answers.

Only $l,j,r$ and the associated depth exponents need to be described. Each has magnitude $O(L+2)$, with the earlier convention for negative $r$. Their fixed number of self-delimiting descriptions therefore cost $O(\log(L+2))$ bits in total. The data fields cost at most $l+O(1)$ bits together, and each log time is at most $j+O(\log(L+2))$. Substitution gives the displayed bounds. For a long pair generated by a short computation description, $\log L$ can be much smaller than $\log m$. The earlier sharpness family has $L=n+O(\log n)$ and already exhibits the stated leading coefficient of $1+\lambda$ for this refinement. Establishing unbounded excess $(F_0-L)/\log(L+2)$ for one fixed set of interpreters would suffice to exclude linear SAT.

## The allowance at zero extra time charge is attained

For each fixed $C>0$ there is one efficient native interpreter $W$ and a linear-time pair convention on which
$$
 F_0(0^n,0^n)-L(0^n,0^n)\ \ge\ C\log(L(0^n,0^n)+2)-O_C(\log\log(L(0^n,0^n)+4))
$$
at all sufficiently large $n=2^{2^k}$. On this family the gap is also $O_C(\log(L+2))$ unconditionally. The same physical machine is used for the joint, scalar and auxiliary-input interpretations. The multiplicative constant in its generic simulator's polylogarithmic overhead is allowed to depend on the fixed construction, as is the exponent of that overhead.

Encode a pair by a leading one, the Elias gamma code of $|x|+1$, then $x$ and $z$. The known total output length and the self-delimited first length locate the component boundary. For two $n$-bit inputs the encoded length is $2n+2\lfloor\log_2(n+1)\rfloor+2$. On a fast branch $W$ reads a gamma code for $k$ and prints precisely this encoding of $(0^n,0^n)$. This always has a leading one. The writer runs in $O(n)$ native steps. For instance an explicit binary counter stored in bit cells with amortized constant carry work can emit $2^{2^k}$ zeros, using $2^k$ counter cells; the modest setup and gamma field cost $O(2^k\,\mathrm{poly}(k+2))$ steps and can use bit arithmetic while native words are small. A second such loop emits the other component. Thus the joint cost is at most $\log n+O(\log(k+2))$. The explicit output lower bound from the [native delay example](native-coding-delays.md) also gives $L\ge\log n-k-O(1)$, hence $\log_2(L+2)=k+O(1)$.

On its other branch $W$ simulates an efficient literal prefix-universal reference, passing through the same auxiliary input if present. It spends at least $\lceil\log_2(i+2)\rceil^B$ physical steps on virtual instruction $i$, with ordinary fixed polylogarithmic upper overhead. Fix $B>C+2$. Any scalar program for $0^n$ must use this generic branch because that output starts with zero. Its virtual running time $u$ satisfies $n\le c u\log_2(2+u)$, so $u\ge c'n/\log n$ eventually; this covers word-packed output. The delayed last half of these virtual steps require at least $c_B n(\log n)^{B-1}$ physical steps. The first program's log time alone is therefore at least $\log n+(B-1)k-O_B(1)$, independent of what the conditional program can do. Subtracting the fast joint cost proves the claimed lower bound at $\lambda=0$.

For the reverse bound on these same strings, the generic simulator can run a fixed zero writer on a short name for $k$ in time $n(\log n)^{O_B(1)}$. The conditional program can simply copy the entire first component from its auxiliary input through the same simulator. The two names cost $O(\log(k+2))$ bits together and the shared log time is at most $\log n+O_B(k)$. Comparing with the explicit-output lower bound for the joint cost proves the matching order. This supplies arbitrarily large **fixed** coefficients by varying $W$; the SAT test requires an unbounded ratio on a single fixed set of interpreters.
