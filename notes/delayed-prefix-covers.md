# A fixed cylinder that a fast producer cover must leave open

**Research journal, 24 November 2026.** Almost all lengths in the dyadic blocks of the prefix-source construction have few short programs producing words of the specified length. Could a verifier certify this by listing the names it can safely exclude? For each sufficiently fast uniform exclusion algorithm there is one entire cylinder on which that algorithm can exclude no name at any sufficiently large length. On this cylinder no name actually produces a word. The conclusion holds unconditionally for short proofs with a sufficiently fast verifier. [Prefix source and block criterion](prefix-lengths.md)

## Joint exclusions

Use the explicit prefix interpreter U and clock B(m)=2^(20m) of the linked note. Write fₘ(x) for the m-bit output of its exact program x by B(m), and ⊥ otherwise. Use just rows x of length m−1. For this argument a pattern is a nonempty list of distinct such rows with a prescribed m-bit output at each. Call a pattern forbidden if some prescribed entry differs from fₘ. A sound exclusion system can designate any family of forbidden patterns at each m.

Suppose one uniform deterministic RAM procedure, given m and a string q with |q|<m, returns a designated pattern supported entirely on extensions of q whenever one exists, and returns `none` otherwise. Require it to output the whole pattern explicitly. Allow O(m)-bit words, as in computations on exponential-size explicit SAT instances, with the standard operations simulable in poly(m) bit operations. Suppose it runs in 2^(a m)poly(m) steps for a fixed 0<a<5, uniformly for |q|<m. Then **there exist a fixed q and M such that no designated pattern at any m≥M is supported entirely on extensions of q**. Moreover, every row extending this q has value ⊥ at those lengths.

Here is the construction with its program name made explicit. A fixed stream machine first reads a self-delimiting string w and a gamma-coded starting length D. It forms q=w enc(w) gamma(D), without consuming the payload. Set w equal to the compiler tag for this machine. Its physical prefix is then exactly q. Starting at m=max(D,|q|+2), run the proposed search at successive lengths. If a search returns a pattern, read exactly m−1−|q| more bits to learn the full row x. Emit the prescribed word if x occurs in the pattern and the all-zero m-bit word otherwise, then halt. All computations with the same header make the same decision about which length and pattern to use.

At the first length where the search succeeds, **every prescribed row** would be an exact program producing its prescribed word by B(m). Indeed, the scans up to m and the final lookup take 2^(a m)poly(m) RAM steps. A sequential multitape emulation by scanning addressed memory and the outer fixed compiler simulation each cost at most a square with a polylogarithmic factor. Hence U takes 2^(4a m)poly(m) steps. The degree and constants can be chosen independently of the starting length D, supplied as data; |q|=O(log D)+O(1). Choose D large enough for the strict exponent margin. The entire pattern would agree with fₘ, contrary to soundness. No search succeeds, so U never halts on this header. The syntactic self-description is a direct instance of the program self-reference used in a related diagonal argument. [Certificate reflection](certificate-reflection.md) · [Jones on efficient program self-reference](https://cgi.cse.unsw.edu.au/~eptcs/paper.cgi?DSS2013.1.pdf=)

One variant prefetches the payload. Before the first search, fill the buffer to D'−1−|q| bits for D'=max(D,|q|+2). After each unsuccessful search, read one more bit before the next search. At horizon m the consumed input now has length exactly m−1. The same contradiction applies. On each infinite stream with this header the machine keeps requesting more bits, with inter-request time bounded by 2^(4a m)poly(m) native steps at horizon m. Thus the construction also admits progressing searches. Applying it to a different interpreter with an enforced inter-request deadline requires that interpreter to support this particular wrapper within its deadline.

## Consequences for covers and advice

For an ordinary cover A(m,x) of the true m-bit producers, exclusion of x designates the singleton pattern x↦0ᵐ. If testing A costs 2^(b m)poly(m) RAM steps with b+1<5, scan all maximal rows. The result forces A(m,x) to contain every row in a fixed q cylinder at every sufficiently large m. These 2^(m−1−|q|) false positives alone exceed the target 2^(m−j) throughout every sufficiently large dyadic block j. In fact the true fractions of maximal rows producing each output length, taken among all rows at that level, sum to at most one across *all* m by prefix-freeness. The false-positive fraction above stays at least 2^(−|q|).

The same statement applies to a collection of different certified covers at each length. If there is a valid certificate w whose cover excludes some x, seek the pair (w,x) by enumeration. For example, |w|≤λm and a deterministic validation and membership check costing 2^(b m)poly(m) suffice whenever λ+1+b<5. There is then one q that **every valid cover** includes on **every sufficiently large layer**. Certificates for entire dyadic blocks can share w across all their lengths. A precision k≤j adds a polynomial factor to this search. For candidate output relations, enumerate y as well: whenever λ+2+b<5, every valid relation contains every pair (x,y) with x extending the same fixed q and y any m-bit word. Independent choices on this cylinder alone can realize each word starting with j zeroes simultaneously once its number of rows exceeds 2^(m−j).

Under the hypothetical linear SAT solver, a different bound allows long certificates. Suppose the existence of a valid certificate excluding (x,y), with a chosen prefix of the concatenation xy and with x required to extend q, has uniform explicit SAT formulas of size and construction cost at most 2^(a m)poly(m), a<5. Search for existence first, then find x and y with at most 2m prefix-fixing queries. There is no need to recover the cover certificate. This gives the required deterministic finder for a singleton forbidden pattern. The same recovery works for polynomially many displayed entries if the exclusion system has such a joint query. This is a conditional restriction on the form of a potential SAT argument. It still allows exclusions involving rows outside the fixed cylinder, and it gives no fast verification procedure for an aggregate upper bound using those dependencies.

## Several lengths in a single challenge

A possible escape is to bound the number of lengths a cylinder can affect, even when the verifier cannot locate those lengths. The joint test has a block version. At block j let N=2ʲ. A prescription may involve many output lengths m in [N,2N), with a named row of length m−1 for each m-bit output. Require the set of named rows, taken across *all* these lengths, to be prefix-free. A sound finder on input (j,q) reports such a forbidden prescription supported on q whenever there is a designated one. If it takes 2^(aN)poly(N) RAM time for a fixed a<5, there is a fixed q on which it can report none for any sufficiently large j. Use the first successful block in the wrapper construction. Parse the displayed prefix-free rows one bit at a time and emit the prescribed word the moment its row is reached. Scanning the displayed list per bit costs at most its length times poly(N) on the named rows. Every one of those computations finishes by 2^(4aN)poly(N)≤B(m). Hence the whole prescription was realized. This argument handles simultaneous assignments across lengths that a single stream machine can enact.

There is a compact application without displaying exponentially many prescribed words. For a fixed q at a large block j, let t=2^(j−1−|q|). Assign all t depth-(j−1) extensions of q in order to the first t lengths in the block. On a row with such a prefix assigned to m, read another m−j bits, then output them with j leading zeroes. This prescribes *all* the early words of each of t distinct lengths using exact names of length m−1. It is prefix-free because different lengths get disjoint prefixes, and all names within one length have equal length. Suppose a uniform test decides within 2^(aN)poly(N) RAM time whether some certified rule forbids this specified partial table independently of the other names. On its first positive result the wrapper can execute the compact prescription directly. For the resulting fixed q that test must therefore be negative at all sufficiently large blocks, although q produces nothing there. The same reasoning permits any public selection of t distinct lengths whose assignment to prefixes the wrapper can evaluate within budget. Certificates that rely on actual behavior in other cylinders need not forbid a partial assignment on q alone.
