# One fixed forecast prefix for a hypothesized SAT clock

Fix an integer $k\ge1$ and a deterministic procedure $F$ that may make adaptive calls on legal explicit files to an exact solver for ordinary SAT. A report of success after truthful answers must imply $V(W)=0$, where $V$ is the forecast bit, $W$ its binary width input and $n=|\operatorname{bin}W|$. Assume $F$ can run on the forecast's wide RAM. Count all its work $g(W)$ on the successful path, including emission and input preparation. Write $N_j$ for the encoded bit length of query $j$.

From $F,k$ alone one can compute a single wide-guest header $H_{F,k}$ with the following property. If SAT has a deterministic standard RAM decider in time $O((N+1)^k)$, then every sufficiently long width on this header is a true negative, and there is no infinite sequence there of successful exact trials satisfying
$$
                  g(W)+\sum_j (N_j+1)^k=o(W/n).
$$
Thus it suffices to produce such trials on infinitely many widths of one **specified** prefix. For instance one may choose the single width whose spelling is $H_{F,k}0^{n-|H_{F,k}|}$ at each sufficiently large length $n$. There is no condition on what happens at the other paddings. The header includes the trial procedure, the exponent, the selector described below and its fixed host width convention. It contains no description of the hypothesized SAT solver. The prefix is specified by a program construction after fixing the universal interpreter and its encoding. This note does not instantiate numeric tap constants or list a literal header bit string. ## Selecting a solver without knowing its code

Enumerate the clocked programs $D_i$ on the chosen standard RAM. A description specifies its program, logarithmic word-width convention and a positive integer multiplier $a_i$. Simulate it for at most $a_i(N+1)^k$ native instructions. A timeout or an invalid return gives NO. Each $D_i$ is now a total computable function. For legal explicit SAT files the reference verdict can be computed by exhaustive assignment search. One fixed tape machine dovetails all pairs of indices and legal files, and lists $i$ whenever it finds a disagreement. Every incorrect index eventually appears. Under the assumed asymptotic clock there is a correct index: increase the multiplier to cover all finite exceptional lengths of a total correct solver.

On input of bit length $n$, simulate the first $n$ transitions of this refutation machine from its initial state. Select the least positive index not yet listed in a completed output record. Reading these records and selecting the index costs $\operatorname{poly}(n)$ wide steps. Let $i_*$ be the least correct index, if one exists. Every index below $i_*$ has a finite counterexample and a finite reporting time, while $i_*$ is never reported. Therefore at **every** sufficiently large $n$ the selection is exactly $i_*$. The same index then answers all legal queries correctly, including adaptive queries never seen in training. The construction needs no computable bound on the stabilization length. This is identification by enumeration with an effective source of labeled instances. [Gold, *Language Identification in the Limit*](https://homepages.math.uic.edu/~lreyzin/papers/gold67.pdf)

## Running the selected program on the fixed wide guest

The guest runs $F$ using this single selection for all its queries. It returns zero only on success. Otherwise it can loop forever. It may abandon a run without returning on excessive resource use, including a query with $N>W$. A subdeadline path in the displayed bound has $N_j\le W$ for every query at sufficiently large $W$.

For a fixed selected index $i$, a simulated register at any such query has $O_i(n)$ bits. Use limbs of $d=\max(1,\lfloor n/8\rfloor)$ bits on a host with a fixed sufficiently large multiple of $n$ bits per word. Arithmetic, Boolean operations, shifts and multiplication on a fixed number of limbs cost $O_i(1)$ host steps with schoolbook operations. Integer division, if present, can use normalized basecase long division. It takes a quadratic number of operations in the number of limbs, with a two-limb by one-limb quotient estimate. The host can prepare tables for that estimate, including zero-divisor handling according to the ISA, and for leading-zero counts, once per width. There are at most $2^{3d}\operatorname{poly}(n)$ setup steps and touched words by direct enumeration and bitwise arithmetic, hence $o(W/n)$. Normalizing all limbs then costs $O_i(1)$. The setup is shared across the queries. [Brent and Zimmermann, *Modern Computer Arithmetic*, Algorithm 1.6 and Theorem 1.3](https://members.loria.fr/PZimmermann/mca/mca-cup-0.5.5.pdf)

Store virtual addresses in a radix trie of $d$-bit limbs. Give each fresh node a consecutive ID. Its slot for digit $u$ uses a physical address consisting of a bank tag, the node ID, and $u$. Zero denotes an absent child. The untouched slots already contain zero and incur no initialization cost. An address has $O_i(1)$ digits. Fresh roots distinguish calls. During at most $W$ host steps at most $O(W)$ nodes can be created, so physical addresses fit in a fixed multiple of $n$ bits. The guest can cap its total work at $W$ and abandon on overflow. Pack the input to each simulated call with its designated width in $O_i(N_j+1)$ time, including any writable-input initialization. After stabilization the trial therefore costs at most
$$
                 o(W/n)+O_{F,i_*}\!\left(g(W)+\sum_j(N_j+1)^k\right).
$$
The guest program and its header remain fixed as $i_*$ varies between hypotheses.

On its own prefix an observed return zero would latch one. At every sufficiently large width the selected solver is correct, so success would certify that the same observed bit is zero. Hence no return is latched by observation, and the untouched bit is zero. A successful exact trial with the displayed little-oh cost would finish within the guest's fixed sufficient $cW/n$ simulation budget and would latch by observation. This proves the exclusion.

For the linear milestone, $k=1$ makes the charged quantity the construction work plus the total encoded query length. The outstanding step is a sound trial satisfying that bound and succeeding infinitely often on its specified prefix.

## Removing the requirement to generate the assertion

There is a fixed choice of trial for which the sufficient condition on a zero width is **existence** of a small valid assertion. It need never be generated uniformly. Fix the elapsed-time assertion format from the journal. Include a second format allowing an ordinary Boolean circuit to supply the forecast sequence bit at a specified time. Optionally fix at construction time one additional sound deterministic proof verifier $P(W,p)$ for the negative verdict. Neither a description of an unknown SAT solver nor a size exponent for the desired certificates has to be supplied later. [Elapsed-time assertions and their ordinary defect CNFs](certifying-a-quiet-interval-on-terminal-sat-files.md)

Let $i(n)$ be the selection above. Define a fixed nondeterministic checker $A$ with input $(W,i(n))$. It guesses one finite description $p$, with its end marked, charging for all bits read. Malformed proposals reject. In the assertion branch it builds the ordinary file $D(W,p)$ asking for an initialization, preservation or endpoint defect in the claimed invariant. It accepts exactly when the clocked program $D_{i(n)}$ returns NO on that file. Here $D_{i(n)}$ is a **machine**, and $D(W,p)$ is the **file**. In the sequence branch the guessed circuit gives $z_t$ on nonnegative times through the horizon $H$. A defect chooses $t\le H$, compares the claimed bit to the fixed two-bank recurrence on the claimed earlier values, and also allows the endpoint check to fail if the proposed bit there is one. Negative times are evaluated from the two known seeds. Address subtraction, the horizon and the taps take $\operatorname{poly}(n)$ gates. Only constantly many evaluations of the proposed circuit are needed. Induction on $t$ shows that absence of any defect certifies the whole proposed sequence through $H$ and a zero endpoint. In the optional branch $A$ accepts an accepting computation of $P$ directly.

The wide guest makes a sequence of **ordinary SAT calls**. At stage $j=0,1,\ldots,n$ it prints a proper CNF asking whether $A(W,i(n))$ has an accepting branch of at most $2^j$ instructions, and runs the selected clocked SAT program on it. It returns zero at the first YES. The program and the code of $A$ are fixed. The finite index $i(n)$ is data in the bounded run. All components can be implemented in one fixed wide-word ISA using the sparse memory simulation above, abandoning overlarge simulations. The code can compute $i(n)$ again inside the trial. In particular, the trial is eventually sound under the clock hypothesis, since both the inner and outer uses then have exact answers. The silent-latch argument only needs this soundness on sufficiently large widths, not during the finitely many stages of learning before stabilization.

For clarity, a bounded-run formula for $t=2^j$ steps here can be printed in $(n+t)n^{O(1)}$ steps and bits for $j\le n$. Guess registers, instructions, nondeterministic choices and the constant number of memory events per step, with $O(n)$ bits per word. Verify consistent memory chronologically after sorting by address and time, and verify the arithmetic in each row. The public input $(W,i(n))$ has polynomial-in-$n$ size. Even at the first few stages where the simulated words are wider than $\log(t+2)$, the sorting, bit arithmetic, and decimal names cost only a polynomial in $n$ per row. Padding short generated clauses with pinned false anchors yields proper 3-CNF. The checks on an accepting NRAM branch handle arbitrary workspace addresses. **Conditional conclusion.** If SAT has the stated $O(N^k)$ decider, there is a constant $c$ such that on **every sufficiently long width on this one prefix**, the bit $V(W)$ is zero and every accepting branch of $A(W,i(n))$ costs at least $W^{1/k}/n^c$. Indeed, after stabilization let $t$ be the length of a shortest accepting branch. If $1\le t\le 2^n$, the stage $j=\lceil\log_2 t\rceil$ or an earlier stage must give YES when simulated with the truthful solver. The complete work through that stage, apart from the shared $o(W/n)$ setup, is at most $(n+t)^k n^C$ for a constant $C$. This includes all earlier files, both writing and answering the outer queries, and the selector. The zero-time case is covered by the first stage. If $t<W^{1/k}/n^c$ for sufficiently large $c$, this work is $o(W/n)$. The guest would latch a one before observation. Correct answers throughout imply that an actual accepted negative certificate exists, forcing the observed bit to be zero. This contradiction also proves the asserted zero value, because after stabilization the guest returns only for a sound acceptance. Larger $t$ already meets the bound. The geometric sequence of stages means the header does not need the constant $c$ or a bound on the stabilization length.

A valid proposal of encoded description length $L$ in either circuit format gives an accepting branch of work at most $(n+L)^k n^{C'}$ for $L\le W$. For the assertion format, every ordinary gate, query and query-argument wire is explicit. The defect emitter has size and generation work $(n+L)n^{O(1)}$ in this range, including the address checks and name spellings. For the sequence format the fixed-lag tests give the same bound. Guessing the proposal and simulating the stable solver on its defect file fit the displayed work. Therefore for some constant $c'$ every valid assertion and every exact sequence-circuit description on this prefix has
$$
                         L\ \ge\ W^{1/k^2}/n^{c'} .
$$
The bound also holds for the **number of ordinary Boolean gates** in a scalar sequence circuit, after adjusting $c'$. A circuit on $O(n)$ index inputs with $g$ bounded-fan-in gates admits an explicit description of $O((g+n)\log(g+n+2))$ bits. The optional directly checked proof instead has guessed length plus actual verifier work at least $W^{1/k}/n^{O(1)}$ on the prefix. The fixed proof verifier may use a standard polynomial-time proof calculus with an effective binary encoding; the time of its check must be charged. A different verifier defines a different header.

In particular, fix the computable zero-padded $W_n$ specified above. To exclude the proposed SAT clock it would suffice to construct, or just prove the existence of, bounded-fan-in circuits with at most $2^{(1/k^2-\epsilon)n}$ gates computing the observed stream on **infinitely many** of these widths for any $0<\epsilon<1/k^2$. Such circuits may be unrelated at different lengths and need no algorithm producing them. The required upper bound on the stream concerns every queried time through the observation. Merely hardwiring the final bit at each length always takes constant size. Under the fast-SAT assumption the endpoints are eventually zero, so no separate prediction of the verdict is required for this sufficient condition. In the positive-characteristic recurrence the circuit can use any fixed complete Boolean gate basis.

The quadratic loss in the exponent $k^2$ has a specific source. The inner deterministic SAT run tests all possible defects of a guessed circuit, and the outer SAT run searches over the circuit descriptions and verifies that inner run. Both are charged at exponent $k$. For a fixed proof format with an existential check of comparable cost, only the outer power is needed. This use of the collapse of a bounded alternation under fast SAT has precedents in the journal's hard-table argument and in the easy-witness literature. Here it selects a solver-independent sequence of actual widths of the fixed recurrence. No claim of priority for the underlying alternation argument is made. [Earlier quantitative table bound](tight-hard-table-lookup.md) · [Impagliazzo, Kabanets and Wigderson](https://www.math.ias.edu/~avi/PUBLICATIONS/MYPAPERS/IKW02/ikw02.pdf)

**What remains.** The fixed-width sequence removes the choice of solver and the need to find a description efficiently. The short description itself is still missing. A direct table of the first $H+1=\Theta(W^5)$ stream bits does not meet any of these budgets. Assuming short proofs in an arbitrary newly chosen system would not suffice either. For example, under the clock hypothesis a verifier specialized afterward can hardwire the stabilized cutoff and accept these particular zero-padded widths with an empty proof. Adding that verifier to the trial changes the header whose soundness and coverage must be established.
