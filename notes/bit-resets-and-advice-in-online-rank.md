# How many bit resets or private hints does an online counter replay need?

In the [calendar-based rank lower bound](persisting-monotone-rank-queries.md), $H$ increment events have colors in $[\lfloor H^\delta\rfloor]$ for fixed $0<\delta\le1$. The word width $w$ is $\Theta(\log H)$. A run has $B$ to $2B$ query positions, where $B=H(\log H)^{O(1)}\ge H$. The calendar and colors of the increments are known in advance. Each query color becomes public only at its appointed position. A single table of $H w^{O(1)}$ bits chosen for that calendar must work for every such query stream. We charge setup and all processing after receipt of the table. These hypotheses also give the one-bit SAT-query application of the companion note. We keep the number of ordinary CPU registers constant.

Write $F\ge1$ for a uniform upper bound on work per run divided by $B$. The following consequences constrain a simulation which tries to eliminate the infrequently updated counter bank of a [general RAM computation](normalizing-stores-in-a-sat-solver.md).

## A tradeoff for all downward bit changes combined

Suppose every run makes at most $R$ bit transitions from one to zero in addressable work memory, in any set of physical words. For $0\le R\le H$ put
$$
  A=\max\{\log_2(w+1),\ \log_2(H/\max(1,R))\},\qquad
  p=1+\max\{0,\log_2(w/A)\}.
$$
Then
$$
                              Fp=\Omega(\log\log H).
$$
In particular $R\le H^{1-\epsilon}$ for fixed $\epsilon>0$ still forces $\Omega(\log\log H)$ amortized work. An upper bound $F=O(1)$ requires $R\ge H/2^{(\log H)^{1-\eta}}$ for some fixed $\eta>0$ and all sufficiently large $H$, with constants depending on the guaranteed time. The conclusion concerns the worst run over the possible increment strings, calendars and online queries. Each query can freely choose its color from the full alphabet. If $R>H$ the displayed necessary lower bound on $R$ already holds.

Use the representative states from the companion proof. Each of $O(\log H)$ fixed-calendar runs resolves a constant fraction of the remaining prefix positions, and every color can be answered in $O(F)$ steps from its chosen representative. We may assume $F\le(\log H)^{O(1)}$, since larger values exceed the asserted lower bound. It remains to show that recovering any physical word in any one saved run costs $O(p)$ static probes using $Hw^{O(1)}$ bits. Save registers explicitly at representative times.

If a word has $d$ downward bit changes, its upward bit changes number at most $w+d$. Thus its entire history has at most $w+2d$ value changes. Index the histories of length at most $2w$ individually using small static fusion trees. For every longer history its length is at most $4d$ since $d>w/2$. Altogether the long histories have at most $4R$ records. Store the pair (physical address, change time) for every such record and its resulting word. A predecessor lookup on the combined keys, followed by an address-equality check, recovers the desired value or the initial zero. A static exact dictionary distinguishes the kinds of addresses. Multiple accesses per instruction can use ordered microstep times. [Fusion-tree bounds](https://arxiv.org/abs/1408.3045) · [Lean lifetime and recovery lemmas](../lean/PersistedRankQueries.lean)

Here is a direct bound for the combined predecessor lookup. For $R\ge1$ use a radix which is a power of two between $\max(2,\lfloor H/R\rfloor)/2$ and $\max(2,\lfloor H/R\rfloor)$, increasing it to at least a power of two of order $w$ if necessary. Its digit width is $\Theta(A)$. The polynomial-universe keys fit in $D=O(1+w/A)$ digits after leading-zero padding. Use a static dictionary of all present prefixes keyed by length and leading digits, with a nonzero sentinel for membership. Binary search on prefix length takes $O(1+\log D)$ probes. For each present internal prefix give a direct radix-sized array. For a missing child digit the entry gives the greatest leaf in a smaller child, or the predecessor of the current subtree if all such children are empty. These are valid pointers even across address boundaries since this is ordinary ordered predecessor. For an exact hit return its satellite value. There are $O(1+RD)$ prefixes, the radix is $O(w+H/R)$, and thus the near-linear space budget suffices even after repeating for all calendars. For $R=0$ there are no long histories.

Applying the static rank lower bound now gives the claimed product inequality. With $F$ bounded and $A\ge\log(H/\max(1,R))$, it gives $\log(H/\max(1,R))\le O(w/(\log H)^c)$ for some $c>0$. Reducing $c$ absorbs the constant. By itself this estimate does not reach a bank making $H/\log^h H$ resets. Closely related static predecessor tradeoffs underlie the source rank theorem. [Belazzougui and Navarro, Theorems 1–2](https://users.dcc.uchile.cl/~gnavarro/ps/talg14.pdf) · [Pătraşcu and Thorup](https://arxiv.org/abs/cs/0603043)

There is also a separate necessary condition on the most frequently changed work word. If every word changes at most $M$ times then a fusion tree for its history costs $O(1+\log_w(M+1))$ probes. Consequently $F(1+\log_w(M+1))=\Omega(\log\log H)$. At constant amortized cost a physical work word somewhere must change at least $2^{\Omega((\log\log H)^2)}$ times. This permits far fewer changes than the $O(H^\epsilon)$ per-word guarantee of the deterministic normalization, for any fixed $\epsilon>0$.

## A general upper bound for this route

Consider any query function $f(C,j,s)$ determined by the supplied event sequence, its current prefix index and a newly supplied query. Suppose some ordinary writable word-RAM algorithm meets the same fixed-calendar interface in $O(B)$ worst-case total time, with sound answers for all streams from one event/calendar table and with independently scheduled or repeated queries leaving the required value of $f$ unchanged. Then for each $C$ there is a static $Hw^{O(1)}$-bit index answering *every* query in $O(\log\log H)$ worst-case word time with only a constant number of working words. The query function must be the same on the different calendars for a common $(C,j,s)$. The free preparation can be arbitrarily expensive.

Run the same fixed-quota construction on the ordinary algorithm. Each prefix acquires an all-colors-cheap representative, and its trial reply uses a bounded constant number of instructions. Persist **all** word changes of each unrestricted canonical run by sorting (address,time) keys into one static predecessor dictionary with the new values as satellites. Binary prefix hashing gives $O(\log w)$ worst-case word time per predecessor and $O(w)$ dictionary entries per version. Exact hashing is static and its constants and tables are included. The trial's own bounded number of writes can be kept in a constant-size register overlay. The representative includes the original table, past transcript access and calendar by reference. Thus every query can be answered from the common static index even when the ordinary algorithm used past queries for caching or enjoyed only an amortized guarantee. It can also be served by a bit-write-once RAM with this prepared index. Rank attains the maximum possible separation in this general comparison. To obtain a bigger factor by pursuing a stronger static query lower bound, one would also need to change at least one hypothesis of the comparison.

## Charging private certificate bits

In the pure bit-write-once case, allow a deterministic reply checker to request private bits from a sequential packed guess tape. One machine step may request a specified number of fresh bits up to one word and is charged that many independent binary choices. A partial word has fixed padding. Request lengths may depend on earlier observations. A completed valid reply must always equal the true answer, and a failed trial is recognizable. For each fixed accepted prefix of this interactive process and each next query, require at least one completing valid reply and continued availability of answers thereafter. Require the total budgets below to hold on all completed valid streams and their accepted choices. This includes a unique, always-available, self-delimiting witness per reply. It excludes advice whose early guesses can lead to an undetectable dead end revealed only after future queries. Between-query processing is deterministic, including event handling. No private information is delivered outside the charged guesses or the calendar table.

Suppose total work and total guessed bits are at most $FB$ and $JB$ on every such run. Then
$$
                      F\,2^{O(1+J)}=\Omega(\log\log H).
$$
In particular, constant amortized work forces $\Omega(\log\log\log H)$ private bits per query in the worst-case amortized budget. There is also a statement about frequency, regardless of how many bits one hinted query can use. On pure bit-write-once memory, constant amortized work requires some workload and valid choices on it to use private hints at a constant fraction of query positions. With unique valid witnesses this counts required rather than optional hints.

For the bit bound, rerun the fixed-quota selection argument. Call a pre-query state good if for every color there is a valid trial of at most $K=\lceil16F\rceil$ steps and $b=\lceil16J\rceil$ bits. If it is bad, choose an offending color and any valid reply. Every such query spends either more than $K$ steps or more than $b$ bits. At most $FB/K$ bad queries can be charged to time and at most $JB/(b+1)$ to bits. Thus only a constant fraction of the targeted $q$-slot gaps can remain unresolved. The encoder has unbounded computation to find and check witnesses and records only completed trajectories. During the static query enumerate all length-$b$ bit strings as padded guess tapes. Reject a trial asking for a $(b+1)$st bit or needing more than $K$ steps. Some trial succeeds and soundness forces its answer to equal the true rank. The simulated trials use independent local overlays on exactly the same stored state. This costs $O(2^b K)$ static probes. The proof of the frequency statement instead defines a good state by a $K$-step trial with **zero** guessed bits for every color. If the uniform fraction of hinted queries were sufficiently small, the number of bad queries charged to time or to use of any hint would still be below half the allocated slots, and rank would have a constant-probe static solution. For both arguments the CPU stores the actual verifier state at each accepted boundary, with no hidden uncharged prover register.

An upper bound for honest witnesses on this interface uses $O(\log w)$ private bits and constant reply time. In the ordinary binary prefix dictionary on the combined (color, event index) keys, guess the length of the longest present prefix of the query key. Check presence and absence of the next prefix, with explicit root, full-key and empty-table cases. At the first missing child, the precomputed predecessor leaf (or absence of one) is determined by the current node and next digit. This length is unique and a fixed-width encoding suffices. The shared static table costs $Hw^{O(1)}$ bits. The lower and upper bit bounds differ. Deterministically the optimal time in this model is $\Theta(\log\log H)$.

## The role of future queries in a SAT reduction

These lower bounds already apply to repeated questions about the parity of one prefix rank. They therefore apply to the particular ordinary 3-CNF queries constructed in the companion note, where two literal identifiers specify the requested color and prefix. The mathematical reduction supplies the next identifier online. If the entire query list is known in advance, a trusted table can contain the correct bit per query time, and every reply takes constant time with zero resets and zero private bits. If the table has to be authenticated, matching those bits to the true guest run becomes a separate verification problem. An ordinary SAT solver can inspect its entire formula before making its first work-memory access. No unconditional elapsed-time exclusion for that solver follows here.

The origin of the persistence reduction and the prior work on write-once counter simulation are recorded in the [base argument](persisting-monotone-rank-queries.md) and [RAM normalization](normalizing-stores-in-a-sat-solver.md). Priority for these quantitative extensions has not been established.
