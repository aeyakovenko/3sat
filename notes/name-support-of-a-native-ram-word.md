# A SAT decider must form a word-value test sensitive to linearly many names

Number the vertices of a simple graph from 1 to $v$. Encode its 3-colourability by a proper ASCII DIMACS formula in a fixed layout described below. A permutation of the vertices relabels the graph and we serialize it again in that layout. For a Boolean predicate on these inputs, a **support** is a set $S$ of names such that every relabeling fixing $S$ pointwise preserves the predicate on every promised input.

**Theorem.** Fix any correct deterministic logarithmic-word SAT RAM with finitely many registers and a bounded number of word accesses per instruction. At arbitrarily large $v$, there is a native register, control location or fixed work address, a time $t$ (retaining the final state after halt), and a numerical value $a$, for which the event “the word at this location at time $t$ equals $a$” has minimum support $\Omega(v)$. The inputs can be restricted to graphs with the fixed linear edge count of the Atserias–Dawar–Ochremiak lower bound. No running-time or workspace hypothesis is required. There are $\Omega(v^2)$ individual transpositions for which some graph changes this same event. The inputs witnessing all these transpositions may be taken to be different labelings of **one underlying graph**.

This is about a function computed by one fixed observation over relabelings of inputs. The word itself has $O(\log v)$ bits. The graph embedding uses $N=\Theta(v^2\log v)$ physical bits and three named colour variables per vertex. Swapping vertex names permutes these triples and restores canonical clause order. [Atserias, Dawar and Ochremiak, Lemma 13](https://arxiv.org/pdf/1901.07825#page=30)

On one particular labeled input, even choosing the support after seeing that input still requires $\Omega(v)$ names for a genuine word-value observation. A separate sparse construction has $N=\Theta(v\log v)$ bits and forces $\Omega(N/\log N)$ distinct native reads by that time. Its names include both variable and clause points. The sections below give the two pebble-game arguments and their encodings.

## From bounded support to a bounded-variable formula

Fix a domain $D$ of size $v$ and a permutation-closed promise of relational structures. Consider a finite acyclic Boolean computation. Each noninput event is a disjunction of terms with at most $b$ earlier events in each conjunction, for fixed $b$. The number of terms, stages, constants and distinct events is unrestricted. Atomic input terms are given by fixed finite-variable relation tests, with domain parameters. Suppose every event has a support of size at most $h$, the atomic tests themselves have such supports with bounded-variable definitions, and the output is invariant.

For each event $g$, order a chosen support $E_g$. Construct a formula with a free tuple of distinct elements of that length. At a tuple $\pi E_g$ it is true on $X$ exactly if $g(\pi^{-1}X)$ holds. This is well defined since permutations agreeing on the support give the same transported event. For an invariant output choose the empty support.

For a term $g_1\land\cdots\land g_j$ in the definition of $g$, take the union of the *actual named* supports $E_g,E_{g_1},\dots,E_{g_j}$. Introduce one variable per point of this union, imposing pairwise inequality. Keep the variables for $E_g$ as the supplied free tuple. Existentially bind the rest, and conjoin the child formulas on the indicated subtuples. Take the disjunction over the original terms. A satisfying tuple of distinct values extends to a permutation $\rho$ of $D$. All the child events then hold on $\rho^{-1}X$, so the parent holds there and consequently at the supplied tuple. Conversely, extend the supplied tuple to any permutation. If the transported parent holds, one of its defining terms witnesses it and supplies suitable values for every introduced variable. Permutations used inside different child formulas may differ outside their respective supports. Agreement on the child's tuple gives exactly the needed truth value.

This uses at most $(b+1)h$ variable symbols or the constant input-definition width, whichever is larger. In a child subformula rename its free symbols to those already supplied. Its bound symbols may shadow outer symbols unused by that child. The number of variable symbols does not accumulate with nesting. Everything takes place at fixed finite size, so arbitrarily large disjunctions used here are finite. In particular the invariant output has an ordinary first-order sentence of this width on the promise. [General context on supports and finite-variable logics](https://doi.org/10.1007/s00224-016-9692-2)

## Use actual RAM observations

For every time, register or address, and possible numerical value, take its equality test as one event. Include the program counter, and give halts absorbing states carrying their answer. Each next-value event is an OR of bounded-size ANDs of previous equality tests. To obtain a term, enumerate the old controller and the values of the boundedly many words read. These specify the instruction, its effective addresses, all arithmetic, and the successor controller. For an unchanged destination cell include a test for its old value. For input reads use the equality test of the particular immutable word. A compound instruction with a constant number of sequential accesses can be expanded by enumerating its bounded transcript, including forwarding from an earlier store. Thus $b$ depends only on the fixed machine. The apparent choice among many addresses only increases the number of terms.

On the fixed finite promise there is a maximum halting time since the decider is total. Unroll to this time, however large. The invariant output event is acceptance. This argument uses equality to a *single fixed numeral* as the signal. Merely observing that a register contains the label of a neighbor would give much less information about a particular value test.

Build the DIMACS input as follows. Include $(x_{i,1}\lor x_{i,2}\lor x_{i,3})$ for each $i$. Force a public variable $f$ false using the seven proper clauses on three fresh names whose conjunction singles out the all-false assignment. Reserve a fixed-size block for every ordered pair $i,j$ and colour $c$. For a present edge put $(\neg x_{i,c}\lor\neg x_{j,c}\lor f)$ in the block. With no edge, including on the diagonal, use a fixed clause already true on the public anchors. Equalize byte lengths by spaces. At least one true colour per vertex and disjoint true-colour sets across every edge are equivalent to a 3-colouring. Field widths and block lengths are $\Theta(\log v)$ bits. Every aligned input word meets only constantly many variable blocks. Its equality to a particular integer is a truth table on constantly many adjacency atoms, with a constant number of named endpoints and a bounded-variable definition under relabeling. The rest of the text is public. These input events cannot themselves account for the asserted lower bound.

Atserias, Dawar and Ochremiak prove a linear lower bound on the number of variables of any counting-logic sentence separating the two 3-colourability cases on their sparse graphs. Ordinary first-order sentences are among the allowed sentences. If every noninput RAM value test had support less than $h$, the preceding construction would give a sentence of width $O(1+(b+1)h)$. The width lower bound therefore yields $h=\Omega(v)$ for some test. One can output the verdict in a register at halt and add one invariant final test if the implementation has several accepting halt states. The length and depth of the unrolling play no role. [Published counting-width lower bound, §5.2](https://arxiv.org/pdf/1901.07825#page=30)

There is a fixed-graph refinement. At each hard size choose a 3-colourable and a non-3-colourable graph that agree on all counting-logic sentences up to a fixed small linear width. Such a pair exists because there are finitely many graphs at this size. If every opposite pair were distinguishable, finite conjunctions and disjunctions of their separating sentences would separate the two classes at the same width. Restrict the entire argument to the union of the two relabeling orbits. It gives a single test with linear minimum support on this union. A union of supports for its two restrictions supports the test on the whole union. Thus on at least one of the two individual graph orbits its minimum support is still linear.

To count transpositions, put $i\sim j$ when $i=j$ or swapping $i,j$ preserves the event on the entire promise. This is an equivalence relation because a stabilizer is a subgroup and $(i\,j)(j\,k)(i\,j)=(i\,k)$. A set is a support precisely when its complement lies in one class, since transpositions generate the pointwise stabilizer. If the largest class has size $m$, the minimum support equals $v-m$. The number of changing transpositions is at least $v(v-m)/2$ by summing the numbers of points outside each class. This proves the second assertion.

## How quickly can this much dependence appear?

The same representation allows an $O(\log v)$-step counterexample to charging time in proportion to support. Choose two fixed vertices $u,b$ and $\lceil\log_2 v\rceil$ other fixed vertices $p_i$. Read $E(u,p_i)$ to form a binary index $j$, and return $E(b,j)$, returning zero if $j$ is out of range. In the dense DIMACS layout each requested edge can be read at a known field in $O(1)$ word operations. For example, make the first token of the neutral clause positive while the active clause begins with a minus, and put that token at the start of its block. The fixed block stride can also be padded to a power of two.

For any two distinct names $x,y$ outside these anchors, set the index bits to address $x$, put the edge $bx$ in the graph, and omit $by$. The other edges can realize the prescribed linear edge count. Swapping $x,y$ preserves the index and flips the returned bit. Consequently the minimum support is at least $v-O(\log v)$ and there are $\Theta(v^2)$ changing transpositions for this single test. This demonstrates the missing implication for the RAM goal even when the sensitivity concerns a Boolean answer to a real lookup.

Lean verifies the bounded-arity support placement, the forward and reverse game alignments, the induction over ranked disjunctions of conjunctions, and the existence of one labeling and one event defeating all small local supports, conditional on its game and input hypotheses. The published hard pair, the encoders, the RAM unrolling and the truncated-transcript law enter through the manuscript arguments here. The numerical lower bound on graph counting width is the published input. The status of prior work on this precise RAM consequence is unresolved. ## A single labeled input requires linearly many names

Call $S$ a **local support at $X$** for a Boolean event $f$ if $f(\pi X)=f(X)$ for every permutation fixing $S$ pointwise. A set may be chosen afresh for each input, time, address and numerical value tested. On the two hard graph orbits above, there exists one labeled graph $X$ and one native word-value test whose minimum local support at $X$ is $\Omega(v)$. Thus for *every* smaller proposed set of names there is a relabeling of this same input which fixes those names and changes the same test. The witnessing relabeling can be a product of several transpositions.

**Proof.** Fix a hard YES/NO pair equivalent in counting logic of width $k=\Omega(v)$. In particular Duplicator wins the ordinary $k$-pebble game on these graphs. A winning partial correspondence remains winning after forgetting pairs or relabeling either graph together with its pebbles. When fewer than $k$ names are pebbled, it can be extended by one new point chosen on either side. The source equivalence supplies these properties also with an empty initial correspondence. [Atserias–Dawar, §2](https://www.cs.upc.edu/~atserias/papers/definable-inapproximability/definable-inapproximability.pdf)

Suppose every event has a local support of size at most $h$ at every labeling of each graph. We prove the following statement by induction along the unrolling. Let $X,Y$ be any labelings from the opposite orbits, let $S_X,S_Y$ be any local supports of size at most $h$ for event $f$ at these inputs, and suppose the identity on $S_X\cup S_Y$ is a winning partial correspondence between $X$ and $Y$. Then $f(X)=f(Y)$.

For an input event, its contents are a fixed Boolean function of graph atoms involving a fixed physical tuple $T$ of at most $p=O(1)$ names. Extend the game correspondence from $X$ over all of $T$. Relabel $Y$ so that the corresponding points receive the actual names in $T$, fixing $S_X\cup S_Y$. Such a permutation exists because a partial bijection of a finite set to itself extends to a permutation. The two inputs now agree on the atoms by partial isomorphism. The value at the relabeled $Y$ agrees with its original value since $S_Y$ was fixed. Public constants satisfy the statement as well.

If an internal event disagrees, orient the two inputs so that $f(X)=1$. Choose a true defining conjunction on $X$, with at most $b$ predecessor events. Choose a local support $P_i$ for each of those events at $X$.

1. Extend the winning correspondence from $X$ over all the $P_i$. Relabel the other side, fixing $S_X\cup S_Y$, to make the correspondence the identity on these names as well. Denote the resulting graph by $Y'$. Its parent value remains zero.
2. Choose local supports $Q_i$ for the *same physical predecessor events* at $Y'$. Extend the correspondence in the reverse direction over every $Q_i$, then relabel $X$ to make the correspondence the identity throughout. This relabeling fixes $S_X\cup S_Y$ and all the $P_i$. At the resulting $X'$ each chosen predecessor is still true and $P_i$ remains a local support. Indeed every further permutation fixing $P_i$ composes with the current relabeling to give another permutation fixing $P_i$.
3. For predecessor $i$, forget all pebbles except those on $P_i\cup Q_i$. The induction hypothesis applies to $X',Y'$ with these local supports. Hence every antecedent is true on $Y'$, making the same defining conjunction true there. This contradicts its parent value zero.

The maximum number of simultaneously held names is $2h+p$ in the base step and $(2+2b)h$ in the induction step. The acceptance event has the empty set as a local support on both graph orbits and has opposite verdicts. Applying the induction from the empty position gives a contradiction whenever these bounds are at most $k$. For $h$ a sufficiently small positive constant times $v$, the failed assumption therefore identifies an actual test and labeling with the asserted local lower bound. Constant and input events have local supports of size at most $p$, so the test can be taken from the native computation.

The locally hard test can be taken at a genuine time on its witness input. First replace a false equality by equality to the word’s actual value. Any local support preserving that value also preserves the original false event. If the padded time $t$ falls after the actual halt at $r$, consider the two true tests at $r$ for the halt-state counter and the same word’s final value. Fixing local supports for both forces the relabeled execution to have halted by $r$ with that same value, hence preserves the padded event at $t$. One of the two tests at the actual halt must therefore already have at least half the asserted local support.

On that labeling the executed prefix up to the test must access $\Omega(v)$ distinct immutable input words. Indeed, take all the named endpoints of the adjacency atoms that determine the contents of the words actually read. Every permutation fixing those endpoints preserves each probed word. Determinism then preserves the entire executed prefix, including its adaptive addresses, by induction on the instructions. These endpoints form a local support for the observed event. Each distinct word contributes at most $p$ endpoints, proving the claim. The same argument requires $\Omega(v)$ distinct graph names and $\Omega(v)$ distinct adjacency atoms among the fields read. This genuine probe bound on a single labeled input lies below its bit length $N=\Theta(v^2\log v)$.

For an explicit comparison take even $v$ and the graph whose edges are exactly the fixed matching $\{1,2\},\{3,4\},\ldots,\{v-1,v\}$. A RAM can test whether all these particular edges are present by probing one fixed field for each pair in the dense layout, in $O(v)$ word operations. At this matching the test has minimum local support exactly $v-2$. If at least three names remain unpinned, two belong to distinct pairs and swapping them destroys required edges. Conversely, leave just the endpoints of one pair unpinned, and both permutations of those endpoints preserve the matching. This explicitly attains linear local support with a linear number of probes. The indirect lookup in the preceding section has a small local support at each input obtained by fixing its anchors and the selected vertex.

## Sparse DIMACS uses only a linear number of word slots

There is also a proper DIMACS family of length $N=\Theta(v\log v)$ on which some single labeled input forces a native event with minimum local support $\Omega(v)$ and an executed prefix reading $\Omega(v)=\Omega(N/\log N)$ distinct physical input words. Here $v$ counts source variables. Use the hard 3-SAT incidence structures of Atserias–Dawar–Ochremiak Theorem 3 directly. They have $m=\Theta(v)$ clause points, three named incidence ports per clause, and unary types carrying the signs. Choose a width-$\Omega(v)$ equivalent YES/NO pair as above. Label **all** $D=v+m$ domain points by $[D]$. The acting group permutes variable and clause points simultaneously, taking their types and incidences along. This differs from the vertex action in the dense graph encoding. [Atserias–Dawar–Ochremiak, §5.2, Theorem 3](https://arxiv.org/pdf/1901.07825#page=29)

Use ordinary DIMACS variables $1,\ldots,D$ and three anchors $a,b,c$ numbered $D+1,D+2,D+3$. First emit seven proper clauses forcing the anchors all false, one clause excluding each other Boolean triple. Emit the public true clause $(i\lor\neg a\lor b)$ for every $i\in[D]$, so all declared identifiers occur even when the corresponding source point is a clause. Finally emit one clause row for *every domain label* $e$. If $e$ is a clause, output its three literals in the local port order, using the numeric labels of the incident variable points. If $e$ is a variable, output the true filler $(\neg a\lor b\lor c)$. The same convention supports clauses of arity at most three on inputs allowing them. Replace an internally complementary clause with the true filler, remove repeated literals in first-port order, and pad a shorter clause to length three with distinct positive false anchors. An empty clause becomes $(a\lor b\lor c)$. Each emitted clause has three distinct underlying variables. Repetition of a whole DIMACS clause is permitted. Every source assignment satisfies the source formula exactly when its extension with false anchors satisfies the output, regardless of the Boolean values assigned to identifiers used only for source clause points.

The file declares exactly $D+3$ variables and $2D+7$ clauses. Give each signed literal an ASCII field of $1+\lceil\log_{10}(D+4)\rceil$ characters, including leading spaces as needed; delimit fields by spaces and end each row with the zero terminator and newline. The header has $O(\log D)$ bits, and every row has $\Theta(\log D)$ bits. Thus $N=\Theta(D\log D)=\Theta(v\log v)$, independently of the labeling. A logarithmic-width physical word intersects only a fixed number of rows, even when its boundary splits a variable identifier or crosses the header.

The base of the *local* proof uses an input-dependent tuple. At $X$, take the labels of the nonpublic rows a particular physical word intersects, and the labels of their actual port endpoints. There are at most four names per such row. Its type and incidence atoms on these names determine the row's bytes on every well-formed input agreeing on those atoms. In particular they determine all signs, all decimal slices, and which repeated occurrences simplify away. For the pebble step, extend from $X$ over this tuple and relabel the opposite graph as before, preserving the pebbled local supports. Partial isomorphism matches the tuple's types and incidences. Well-formed ports are functional, so their displayed endpoints already determine their contents. This gives matching physical word values. It also gives constant-size local supports for each immutable input word. The proof for internal events and the deterministic execution-prefix argument now apply without a change. A prefix reading $q$ different words is locally supported by $O(q)$ of the joint variable and clause names. Consequently $\Omega(v)$ distinct word probes on the witness labeling are necessary. At word width $\Theta(\log N)$ this is a constant fraction of the file's packed words. The bound leaves a logarithmic gap even to $\Omega(N)$ steps measured in encoded bits.

The serialization audit checks every signed clause of length at most three on three variables, including repetitions, complementary literals and the empty clause. It parses the emitted ASCII, compares satisfaction on every source assignment, checks both verdicts under full domain relabelings of two five-point examples and samples an eleven-point proper unsatisfiable example. Across four word widths it checks that fixing the determining names preserves the sampled physical values, including partial decimal fields. These finite checks cover the encoder. The asymptotic hard-pair theorem is the cited counting-width result. [Reproducible serialization audit](../audits/sparse_incidence_dimacs_audit.py)

The probe count alone admits stronger quantifiers. **Every labeling of both hard incidence structures requires $\Omega(v)$ distinct word probes by an exact deterministic decider.** On any hypothetically shorter halting transcript, take the union of the actual row labels and endpoints determining all words read. If this uses at most $k$ points, extend the empty winning correspondence over them, then label the opposite structure so this correspondence is the identity. All probed words agree at once, and the same deterministic transcript halts with the wrong verdict. This argument concerns the whole run. The existence proof for a single intermediate event with large local support uses the stronger two-direction induction above.

For a distributional version, label each of the two fixed structures uniformly at random. Any decision tree limited to $q$ distinct word probes, for $q$ a sufficiently small constant times $v$, has identical transcript distributions under these two experiments. Fix a proposed transcript. Its addresses specify a set of touched rows. Refine the specified word contents by enumerating the full type and three port contents of each of those rows. Valid completions partition the transcript event. Each completion names at most $O(q)\le k$ distinct points and amounts to a fixed conjunction of atomic facts about their injectively assigned images. The two structures give the same probability to this conjunction. Indeed, choose preimages of those names sequentially by uniform sampling without replacement in the first structure. In the bijective $k$-pebble game, Duplicator supplies a bijection of the domains before the next point is sampled, extending the pebbled correspondence. Its image is uniform among unused points in the second structure and all sampled atomic facts agree. Summing over completions proves equality. Conditioning on internal random bits gives the same statement for randomized probing strategies. Under the equally weighted mixture of orbits, a strategy that succeeds with probability $1/2+\delta$ must exceed the probe cutoff with probability at least $2\delta$. Early halts give the same answer distribution on both verdicts, while later runs have accuracy at most one. Thus a fixed positive advantage also takes $\Omega(N/\log N)$ expected distinct word probes. [Counting equivalence and the bijective pebble game](https://www.cs.upc.edu/~atserias/papers/definable-inapproximability/definable-inapproximability.pdf)
