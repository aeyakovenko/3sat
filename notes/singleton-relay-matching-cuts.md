# A linear-time cut test for two layers of sheet constraints

Take the homogeneous two-layer family with one missing crossing edge. Suppose that the two first-layer matchings coincide, so each left sheet and its matched right sheet carry complementary bits independently of all other pairs. Identify both sides with the same set of $a$ indices by this first-layer matching. In layer two write $p,q$ for the positive and negative crossing matchings as permutations from left to right, before cutting the positive edge from $0$ to $p(0)$. At its two endpoints the positive port is fixed and the guards are intact. All other second-layer centers use $P(x,b,c)=\neg x\lor b\lor\neg c$. If $p^{-1}q$ is an involution, including fixed points, there is an exact deterministic $O(a)$-step algorithm on the word layout, or $O(N)$ including parsing the named canonical $N$-bit file. The first layer has the maximum possible number of independent bits in this restriction. [Model, projection and unrestricted two-layer reduction](two-missing-guards-in-a-sheeted-sat-formula.md)

## Expressing the sheet constraints as a cut

Let $x_i$ be the left physical bit, so the right physical bit at $i$ is $1-x_i$. Set $S=\{i:x_i=1\}$ and call $i$ a descent when $x_i=1$ and $x_{q(i)}=0$. Write $D$ for the set of descent indices. Temporarily restore the crossing positive edge and put $P$ at both anchors. The left clause centered at $i$ says $x_i\land x_{p(i)}\Rightarrow x_{q(i)}$. The right clause centered at $q(i)$ says $x_i\Rightarrow x_{q(i)}\lor x_{p^{-1}q(i)}$. Consequently the clauses hold exactly when, for each descent $i$,

$$
                     x_{p(i)}=0,\qquad x_{p^{-1}q(i)}=1.
$$

In the actual file the intact anchors with fixed positive ports impose the four pins $x_0=x_{q(0)}=1$ and $x_{p(0)}=x_{q^{-1}p(0)}=0$. Under these pins the two temporary $P$ clauses automatically hold, since the two relevant $q$ edges have equal end bits. Thus imposing the pins on the cut system gives exactly the original decision problem, including cases in which some indices coincide. An inconsistent pin assignment rejects immediately.

Write $\tau=p^{-1}q$. In general a descent $i$ requires $x_{\tau(i)}=1$ and $x_{q(\tau^{-1}(i))}=0$, using $p=q\tau^{-1}$. Whenever $i$ belongs to a cycle of $\tau$ of length one or two, these two conditions say exactly that $\tau(i)$ is also a descent. In particular, if $\tau^2=1$, then any assignment satisfies the projected clauses exactly when $D$ is a union of $\tau$-orbits. The four pins continue to apply.

## How to realize a chosen set of descents

More generally, start with any partial assignment of pins on the vertices of the $q$ cycles. Between consecutive pinned vertices in cyclic order, call a directed arc mandatory if its start is pinned one and its end zero. It includes the outgoing edge of the start and the incoming edge of the end. Let $E$ be a proposed **exact** descent set, identified with its $q$ edges. It is realizable exactly when both of the following hold.

1. Pin the tail of every edge of $E$ to one and its head to zero. All these pins must be consistent with each other and the original pins. In particular a loop cannot descend, and consecutive edges cannot both descend.
2. Each original mandatory arc contains an edge of $E$.

Necessity follows by following the bits around each arc. For sufficiency remove the edges of $E$ from the directed cycles and require nondecreasing bits on the remaining edges. A consistent extension exists exactly when no directed path in the remaining graph goes from a pinned one to a pinned zero. To see this, set all vertices reachable from pinned ones to one and the rest to zero. A positive-length conflicting path could only start at an original one-pin and end at an original zero-pin. A newly pinned one has its outgoing edge removed, and a newly pinned zero has its incoming edge removed. Between any such original endpoints the directed path would contain a full mandatory arc, contrary to condition 2. Conflicts on paths of length zero are excluded by condition 1.

## One orbit suffices for the designated edit

If the two positive pins and the two negative pins lie on different $q$ cycles, color their cycles constantly as prescribed and use no descents. Each same-sign pin pair occupies one edge of $q$, also when the edge is a loop. If all four pins lie on one cycle and are consistent, the two positive vertices form one block and the two negative vertices form one block in the cyclic order of pins. There is exactly one mandatory arc. If a solution exists, some orbit in its descent set hits this arc. Retaining only that orbit preserves condition 1 by restriction and still satisfies condition 2. Conversely, any single orbit passing these tests yields an assignment by the preceding construction.

Mark the edges of the mandatory arc in one pass. Inspect each $\tau$-orbit, test whether it hits a marked edge, and compare its at most four endpoint labels with each other and the original pins. Every check per orbit has constant cost. Inverting permutations, locating cycles and marking edges takes $O(a)$ word operations. This also constructs a witness in $O(a)$ when requested, by completing the private pairs independently at the end.

## A parameter for departures from the involution

Let $k$ be the number of indices lying in $\tau$ cycles of length at least three. The same family admits a deterministic $2^{O((k+1)\log(k+2))}a$-step algorithm. This parameter measures the relative *second*-layer permutation with the first-layer pairs kept independent.

Enumerate the at most $4^k$ choices of $(x_i,x_{q(i)})$ on those exceptional indices. Discard inconsistent pins. For each exceptional descent, check its required $x_{\tau(i)}$ and $x_{q(\tau^{-1}(i))}$ values directly, since both neighboring indices in the $\tau$ cycle are also exceptional. Let $B$ be the set of fixed exceptional descents. Include all guessed endpoint values among the original pins. The remaining descent set must be a union of singleton and two-element orbits. There are at most $2k+4$ mandatory arcs. Discard arcs already hit by $B$ and let $r$ count those left.

Discard an optional orbit if its endpoint pins are internally inconsistent or conflict with the current pins. Its type is the set of as yet uncovered mandatory arcs it hits. There are $O((r+1)^2)$ possible types because an orbit has at most two edges and these arcs are edge-disjoint. Two surviving orbits conflict only when their descent edges are consecutive on a $q$ cycle. Each orbit therefore conflicts with at most four other orbits. Orbits with empty type may be dropped.

Any solution can retain just one of its orbits per uncovered arc, taking the union of these choices. This uses at most $r$ orbits and preserves realizability by the two conditions above, together with the fixed descents $B$. For each type keep up to $5r+1$ arbitrary representatives. If a solution of size at most $r$ uses a discarded orbit, at most $5(r-1)$ choices can coincide or conflict with its other selected orbits. Thus some retained representative of that same type can replace it. Iterating gives a solution in the retained list whenever any solution exists. For $r=0$, test $B$ alone.

There are $O((r+1)^3)$ representatives. Enumerate subsets of at most $r$ of them and check pairwise consistency and coverage. The resulting search costs $2^{O((r+1)\log(r+2))}$ per guess, in addition to a scan and polynomial work in $k$ for the lists. The bound follows from $r\le 2k+4$.

## One kernel before the guesses, allowing first-layer defects as well

Normalize the first positive matching to the identity and write $\rho$ for the first negative matching. Allow $t$ indices in nonsingleton $\rho$ cycles. The intact first layer enforces precisely $R_i=1-x_i$ and $x_{\rho(i)}=x_i$. Indeed, the positive edges require $x_i+R_i\ge1$ while the negative edges require $x_i+R_{\rho(i)}\le1$. The sums of their left sides over all $i$ coincide. Both inequalities must therefore be equalities on every edge. Conversely these equalities satisfy the intact layer. The two cut conditions of layer two use the same $p,q,\tau$ as before.

Before assigning any bits, mark a set $M$ of potential pins. Include the four original pins, every index on a nonsingleton $\rho$ cycle, and both endpoints $i,q(i)$ for each exceptional $\tau$ index. Write $m=|M|\le 4+t+2k$. On each $q$ cycle with a mark, divide the edges into elementary arcs between consecutive marks. A single mark gives one arc returning to it. There are at most $m$ elementary arcs. Regardless of the eventual pin values, every mandatory arc is one of these elementary arcs, because every marked vertex will receive a value. Record each optional orbit's type as the set of elementary arcs it hits, ignoring edges in unmarked cycles. Each type contains at most two arc identifiers.

Discard orbits with contradictory internal descent labels, and keep all optional orbits incident to a mark, at most $2m$. For each type keep $5m+1$ arbitrary representatives among the remaining optional orbits, or all of them if fewer. There are $O((m+1)^3)$ retained orbits. After a pass over the cycles and orbits, group their types by two counting-sort passes on the arc identifiers, using a sentinel for missing identifiers. Record required marked endpoint values and adjacency conflicts among retained orbits by looking up the preceding and following $q$ edges of each retained descent edge. This preprocessing takes $O(a)$ word operations, independently of the guessed bits.

Now enumerate bit assignments on $M$. Enforce the four original pins, all nontrivial first-layer equalities, and the exceptional second-layer descent conditions. Compute their fixed descents $B$ and remove the elementary mandatory arcs they already cover. Test up to $r\le m$ retained optional orbits as above. To justify the single common list, start with a solution reduced to at most $r$ optional orbits. Any discarded orbit in it had no marked endpoints. A retained unmarked representative of its full elementary type hits exactly the same currently mandatory arcs. It cannot conflict with any fixed descent because both endpoints of each fixed descent are marked. Among $5m+1$ representatives there is one distinct from and consistent with the other selected orbits, by the degree-four bound. Repeat this replacement for all discarded choices. The test thus costs $2^{O((t+k+1)\log(t+k+2))}$ after preprocessing, for all guesses together. A successful choice can be lifted once in $O(a)$ steps.

The combined time is $O(a)+2^{O((t+k+1)\log(t+k+2))}$. In particular the scan dominates for $t+k=o(\log a/\log\log a)$. The general two-layer reduction already has $k=0$, and a refined reduction realizes 3-SAT with every relative cycle of length exactly two in both layers. On those outputs $t=a$.
