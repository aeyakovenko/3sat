# Trading descriptions of a SAT solver's own reachable configurations

Fix a correct deterministic logarithmic-word RAM SAT solver $S$, with the fixed bounded-arity word instruction set and standard explicit input encoding. Fix a uniform deterministic decoder $D$. Its arguments are the original read-only formula $F$, an absolute instruction time $t$, one packed description $z$, its length, and a work-word address $a$. Each query begins with blank private scratch. Say that a state admits a description at budget $B$ if
$$
 \exists z,\ |z|\le B:\quad \forall a,\quad
 D(F,t,z,a)\text{ returns the actual word at }a\text{ within }B\text{ steps}.
$$
The address range is that of $S$ on this input, including untouched zero words. $S$ has a constant number of controller words which can always be added to a checkpoint header. There is no time bound for finding $z$. It can depend on the entire run and can change at every time. All formulas and all actual times before halting are covered. An idle extension after halting can reuse the terminal state's description and its original time, at an extra $O(\log |F|)$ bits; equivalently cut the clock so the terminal state is followed by a distinguished fixed-memory-free output state. If halting itself changes a bounded number of words, include those changes as a bounded-size patch to the last pre-halt state.

**Theorem.** For every fixed $c<2\cos(\pi/7)$, if $S$ runs in $O(N^c)$ on $N$-bit SAT inputs, then for every such $D$ there is an $\eta>0$ and arbitrarily large $N$ with an actual input and time whose state lacks a description at budget $N^\eta$. In particular a fixed polylogarithmic-latency decoder cannot give all reachable states subpolynomial-length descriptions. The proof uses both SAT verdicts and may select inputs of either sign. The $η$ can depend on the programs and the exponent. It is not necessary that every time or every input be hard. Interchanging $\exists z$ and $\forall a$ would allow the desired word itself as a separate small answer. An unrestricted-time decoder can replay the machine from $F$.

The exponent is the published small-physical-space exponent of Williams. Here the local description concerns the state of the given solver with unrestricted workspace. The single-list checkpoint test is already implemented in the [solver-side snapshot proof](solver-snapshot-descriptions.md). The additional step below handles arbitrary **consecutive** speedups from the alternation-trading proof, without assuming succinct arbitrary restart configurations. The [near-linear rejecting-run result](solver-snapshot-descriptions.md) gives a larger bit threshold when its stronger time and query hypotheses hold. Priority of this transfer is unverified. [Williams, Lemmas 3.3–3.4, Section 4.1 and the examples after Proposition 4.7](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Fortnow, Lipton, van Melkebeek and Viglas](https://lance.fortnow.com/papers/files/tst.pdf)

## Nested speedups with a genuine starting state

Consider one original deterministic machine $M$ on its own input $x$, with a fixed polynomial clock and locally decodable actual states. The recursive task specifies an absolute interval, a candidate initial controller and memory description, and a terminal predicate that tests the controller or at most one memory word at a designated address. A comparison word can be supplied by another endpoint's decoder given the absolute endpoint time. Negation and comparison against a fixed accepting or rejecting halt are allowed. The requirement on a recursive implementation is two-sided correctness **whenever its supplied initial state equals the true state on $x$ at that time**, for every terminal predicate, including endpoints proposed by a dishonest outer list. Nothing is required when its initial state is false. Every branch still halts within its announced clock on every input and every list.

With no further speedups, replay the interval. Access a private overlay for local stores, including explicit zero overwrites. Otherwise consult the supplied starting description. Decode the final comparison address if needed. Use a fixed time limit and default on malformed data or a timed-out decoder so every proposed string denotes a total memory. This base branch costs the interval length times $n^{o(1)}$, plus $n^{o(1)}$, when description length and latency are subpolynomial. A tagged, initially empty RAM bank implements the overlay; simulation and virtualization with logarithmic overhead also suffice. Its physical workspace can be large.

Divide a longer interval into $P$ consecutive pieces. For the existential-list orientation guess descriptions and controllers at its $P-1$ internal boundaries. Universally choose either an internal piece and an observation (a controller component or an arbitrary legal memory address), or the final piece. For an internal piece use the recursively implemented terminal predicate that its end agrees with the proposed next state on the chosen observation. On the final piece use the original terminal predicate. The choice of piece and observation together takes $O(\log n)$ bits. If the desired terminal predicate is true from the actual start, the honest list suffices on every choice. If it is false, consider any list. When some interior state differs from reality, the **first** wrong state has a true predecessor and some differing observation. The child checker rejects on that choice by its true-start guarantee. When all interiors are genuine, the final piece rejects. This proves the invariant. All earlier steps in the computation may have used arbitrarily large workspace.

For the universal-list orientation take the Boolean negation of the existential-list construction for the negated terminal predicate. The outside blocks are then universal list followed by existential choice of piece and observation. Inside this choice the desired child predicates are the corresponding negations of the tests in the previous paragraph. These still inspect at most a controller component or one word. Implement each such child with whichever orientation is prescribed for the *next* speedup. Even if this implementation differs on false starting states from the literal complement of an earlier implementation, all honest interiors and the first wrong boundary are covered by the same true-start proof. Consequently a prescribed finite word of speedup orientations can be implemented without spending an extra alternation on the memory equality test. The formal kernel verifies both list orientations with unconstrained edge checks off the true path. [Lean verification](../lean/TrueStartSnapshotTrade.lean)

The size bookkeeping is the same as in Williams's speedup rule at polynomial precision. Splitting a segment of length $n^{a+o(1)}$ into $n^{x+o(1)}$ pieces guesses $n^{x+o(1)}$ bits. The chosen branch needs only the root machine's input to this group of consecutive speedups, time indices, the chosen two endpoint descriptions and the single observation. If the root input has at most $n^{b+o(1)}$ bits, forwarding it and the selected header costs at most $n^{b+o(1)}$ time and bits for $b\ge1$. Before the choice, forwarding the full list instead costs $n^{\max(b,x)+o(1)}$. The terminal replay exponent drops by $x$. Adjacent equal quantifiers merge as usual. Carry the outer input length as a binary header through every forwarded input so the clock, word width and address range stay available. This accounts for the restricted input forwarding in Williams's Section 2. It does not require that the uncompressed work array, or the replay overlay of a forged segment, be passed between blocks.

## Which class closes the hierarchy argument

Write $\mathcal R[a]$ for full-input deterministic computations of exponent $a$ with subpolynomial descriptions and word-query time for their true states. For exponent arguments, interpret a line with negligible losses by arbitrary fixed positive slack: for every $\zeta>0$ allow an implementation of time $n^{a+\zeta}$, payload and decoding time $n^\zeta$ at sufficiently large lengths. Implementations may depend on the slack. This convention makes every guessed dimension a uniformly enforceable rational-power clock. A single solver and decoder satisfying the negation of the theorem meets every such slack. A fixed finite proof can allocate arbitrarily small slack at its finitely many calls, including after polynomial changes of input size. Use rational upper clocks and include constant-size exceptions explicitly. The class at a deterministic endpoint is closed under complement by switching the final answer.

**Slowdown.** Under the hypothesized SAT bounds, eliminate one innermost quantifier over any total time-bounded deterministic leaf. On the public input to that quantifier, a nondeterministic bounded computation guesses its string, produces the permitted next input and evaluates the leaf (or its complement for universal elimination). Its time and padded input scale have exponent $u=\max(a_{k+1},a_k,b_k,b_{k+1})$ in Williams's rule: this charges the leaf clock, guessed length, input to the eliminated block, and input forwarded to the leaf. Use $b_1=1$ at the first block. The locally indexed quasilinear reduction supplies an ordinary SAT instance of length $n^{u+o(1)}$. Simulate $S$ on that instance, answering each read from the public data with the local generator. This returns the correct sign in time $n^{cu+o(1)}$. More importantly the **new deterministic tail** meets the true-state description condition on every public input. A guest-memory lookup uses its honest code with the same virtual formula as read-only input. All wrapper registers, guest instruction time, and temporary local formula-generator memory can be included in $n^{o(1)}$ bits at any wrapper microstep. The formula generator uses polylogarithmic workspace and time per bit; scratch can be kept in a fixed small bank or explicitly reset. Reading the virtual formula in the guest decoder multiplies its latency by at most a polylogarithm. Address the guest bank through a static embedding separate from the simulator's fixed scratch. Choose the width coefficient large enough for the finitely many fixed simulations, using a bounded number of limbs when widths differ. A history-dependent dictionary for guest addresses would require a separate description of the dictionary itself. The witness for the eliminated quantifier is represented *inside* the formula and occupies no mutable store in this slowdown machine. The process applies to all its actual SAT calls, regardless of whether their inputs arose from dishonest outer quantifier guesses. [Williams, Theorem 3.1 and Lemma 3.4](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Packed bounded-run implementation](packed-band-transfer.md)

Compile a normal-form proof from deterministic line to deterministic line. At the start of each maximal group of speedups, its deterministic tail is either the original true-state machine or the new SAT simulation from a slowdown. Replace the whole group by the nested construction above. Its last leaf is a total bounded-time deterministic computation. There is no claim that this final replay leaf itself lies in $\mathcal R$ on arbitrary supplied states. The next operation is a slowdown, which requires only that leaf's time bound and restores a genuine run of the solver. Consecutive slowdowns also work because the previous tail is then a full deterministic algorithm. Thus the normal form gives a containment $\mathcal R[a]\subseteq\mathcal R[a']$ with the same exponents as the published proof, up to arbitrarily small slack. This grouping is needed: replacing physical space by description length in a one-line class inclusion and reapplying it indiscriminately would assume a property of the forged replay which has not been established.

For any $1<c_1<c'<2\cos(\pi/7)$ with $c_1$ exceeding the given solver exponent (or bounding it with slack), Williams gives a finite normal-form proof at $c'$ with initial and final time exponents $a\ge a'\ge1$. The last operation is a slowdown. Use the published $c'$ in all preceding operations and $c_1$ in the last one. The final slowdown multiplies a positive maximum by its SAT exponent, so this yields a strict decrease by a fixed margin. The final slowdown maximum is at least one, so its original exponent is at least $c'$, its improved exponent is at least $c_1$, and the normal-form starting exponent exceeds one. [Williams, normal form and the $2\cos(\pi/7)$ annotations](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

For completeness, the hierarchy contradiction here does not rely on a speed hierarchy **inside** a same-space class. From the strict decrease $\mathcal R[a]\subseteq\mathcal R[a-\delta]$, padding gives $\mathcal R[A]\subseteq\mathcal R[A(a-\delta)/a]$ for fixed $A\ge a$, with arbitrary small slack. Pad the input length to about $n^{A/a}$, verify padding by a small-space scan, and simulate on the original input. In the reverse direction serve the larger padded string virtually. A native description for the machine on that string is still eligible: its decoder's accesses to padding can be answered with near-constant overhead, and an originally subpolynomial header remains subpolynomial under a fixed polynomial rescaling. Relaxing the saving slightly absorbs ceilings and all clock slack. Initial reduction and SAT slowdown give $\mathrm{NTIME}[n^L]\subseteq\mathcal R[c_1L]$ for each sufficiently large fixed $L$. A finite number of padding iterations drops this to a deterministic exponent strictly below $L$, hence also to complementary nondeterministic time strictly below $n^L$. Bounded complementary diagonalization rules that out. The universal clock can simulate each fixed smaller-time opponent with polylogarithmic overhead, absorbed by the strict polynomial gap. This is the strict-decrease case of Williams's Lemma 4.3 with the true-state class at both ends. [Williams, Lemma 4.3](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

## An explicit length and latency tradeoff below the square-root-of-two exponent

Let $1\le c<\sqrt 2$ and let $e,d\ge0$. The same argument with just one speedup and two slowdowns excludes simultaneous SAT time $N^{c+o(1)}$, true-state code length $N^{e+o(1)}$ and word-query time $N^{d+o(1)}$ whenever
$$
 c^2+c(e+d)<2.
$$
Here one code must meet both separate budgets at its state, and all actual inputs and times are required. To see the accounting, use a full-run class with clock $n^a$, code-length exponent $ae/c$ and latency exponent $ad/c$, allowing arbitrarily small slack throughout. After a SAT slowdown at source scale $n^u$, the new clock exponent is $cu$ and the new code and latency exponents are $eu,du$. Thus the ratios to the clock are preserved. Split the initial run into $n^x$ intervals. The input sent into the universal challenge includes the original input and all codes, of exponent $\max(1,x+ae/c)$. The selected endpoint headers fit in the same bound. The replay exponent is at most $a(1+d/c)-x$, using a local write overlay. Eliminating the challenge and then the list gives final clock exponent $c^2 U$, where
$$
 U=\max\{1,x+ae/c,a(1+d/c)-x\}.
$$
For sufficiently large $a$, choose $x=a(1+d/c-e/c)/2$, with arbitrarily small rational rounding. Under the strict tradeoff this lies between zero and $a$, and the resulting clock is $a[c^2+c(e+d)]/2<a$. The final solver's actual code size and latency have the same ratios to this smaller clock. Starting with a sufficiently large nondeterministic exponent $L$, a fixed number of contractions, always at scales of order $L$, takes the deterministic simulation of nondeterministic time $n^L$ below exponent $L$. Equivalently use the same padding and complementary diagonal as above. For a linear-time solver with polylogarithmic word decoding the inequality covers every fixed $e<1$. The earlier log-precision theorem gives a sharper length threshold for its specified checkpoints. [Lipton–Viglas annotation in Williams, Section 4.1](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

No speedup for arbitrary unrestricted RAM computations follows. The theorem charges the ability to answer a word query from one description on each actual native state of the hypothesized solver. Linear time by itself does not supply such descriptions, and such a solver could have large reachable-state descriptions. The conclusion therefore gives a necessary property of fast SAT computations while leaving their existence open.

The seven-step annotation $1100100$ also gives explicit simultaneous length and latency exponents above $\sqrt 2$. It excludes $e=d=1/13$ at $c=3/2$ and $e=d=1/3000$ at $c=8/5$. [Proof and rational certificates](positive-budget-snapshot-trade.md)
