# Certifying nonreachability by recursively splitting at a boundary state

## 2026-11-23 · A one-sided alternative to a unique midpoint

For a nondeterministic computation, an accepting path can have many possible intermediate states. A certificate for **nonexistence** of a path can use upper bounds on the sets of reachable boundary pairs. Composing two such bounds needs just one universally quantified implication. This removes the requirement in [rooted transport](rooted-propagation.md) that the next state be determined by the root seed. Inductive safety invariants and their validation by SAT checks have extensive precedent in model checking. [McMillan](https://lara.epfl.ch/w/_media/fv19/mcmillan2003_chapter_interpolationandsat-basedmodel.pdf) · [Yu, Biere and Heljanko](https://cca.informatik.uni-freiburg.de/papers/YuBiereHeljanko-CAV21.pdf)

Fix input x of encoded length n and a known computation clock T=T(n). A state has w bits. A concrete circuit E(u,v,z) verifies one step u→v with nondeterministic choice or local witness z. Let I(u) and A(u) test legal initial and accepting states. Require a uniform procedure producing these circuits from x and charge all its time. All read/write memory used by later steps belongs in the state or must have a separately justified sound encoding. Replacing the state by just a program counter and the last touched word would lose this property.

**Clocks.** For the general construction take L=⌈log₂ T⌉ (T≥1). To decide whether some branch accepts by time T, start a saturating clock at zero and retain the halt flag and result. At each of the first T steps advance the clock by one, executing one instruction if running and preserving a recorded result after a halt. At clock T freeze the entire state, including any still-running flag. Accept only a state with the accepting halt flag. This gives the same verdict after exactly 2ᴸ transitions. Charge the additional O(log(T+1)) clock bits and the circuitry for saturation, halting and input initialization. The witness for a step can be empty when the step is deterministic. If a normalized machine always halts within T, accepting and rejecting absorbing self-loops suffice without a clock.

On a NO instance guess L+1 circuits `R[0], …, R[L]`, each taking two boundary states. Certify all of the following.

1. For every u,v,z, if E(u,v,z) holds then R₀(u,v) holds.
2. For every level l<L and states u,m,v, Rₗ(u,m) and Rₗ(m,v) together imply Rₗ₊₁(u,v).
3. For every u,v with I(u) and A(v), `R[L](u,v)` is false.

Pin the level or take a disjunction over levels in a circuit for any violation. A single explicit Tseitin SAT query tests whether this disjunction is satisfiable. The nondeterministic NO branch succeeds precisely on an UNSAT answer. Induction on l shows that every true 2ˡ-step path is contained in Rₗ, since its actual midpoint witnesses composition. Thus no certificate can prove NO when an accepting path exists. Exact 2ˡ-step relations supply one set of passing circuits on every NO input if circuits of the claimed sizes exist. Strict overapproximations can also succeed. The converse inclusion for a squaring step would involve finding a midpoint for every accepted pair. These certificates require only the forward implication.

**Cost and hierarchy.** Let c upper bound the total circuit encoding overhead in *gates plus input wires* for E,I,A, including w and the number of choice bits. Let s bound the gates plus input wires of each Rₗ. With all bounds constructible and U(n) the cost of producing the local circuits, the NO recognizer takes time

    U(n) + Õ((c+(L+1)s)^d)

under a deterministic time O(mᵈ) SAT algorithm on m encoded bits. This charges for guessing topologically ordered circuit descriptions, validating their wiring, instantiating a constant number of copies per implication, and writing the final formula with binary literal indices. Logarithmic factors here are in the construction sizes, the clock, and the input length. A simulation on nondeterministic tapes needs the usual polylogarithmic overhead to check a guessed chronological RAM history in address-sorted order. For instance, if c+s ≤ T^β poly(log T), U(n) ≤ T^(1−η), and βd<1 with fixed positive margins, this gives a polynomial saving relative to T. **The theorem needed for SAT** would supply such certificates on every NO input of a uniform language in nondeterministic time T outside the resulting co-nondeterministic clock, with the required small-state encoding and setup cost. A proof for a restricted transition system does not establish this. [Hierarchy and RAM simulation background](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

The same test works for a straight-line grammar for a fixed schedule of transitions: for a nonterminal X→YZ certify R_Y(u,m)∧R_Z(m,v)⇒R_X(u,v), then check the start nonterminal. Repeated occurrences share the same upper bound. With g productions, the L+1 factor becomes O(g). The actual schedule must have a short uniform grammar or another certified representation.

## A class with compact relations despite nondeterministic branching

Consider a fixed schedule of affine transitions over GF(2) on w-bit states. At one step a system of affine equations on (u,v,z) admits the new state v if some nondeterministic z satisfies it. This includes v=Mu+Nz+a with an arbitrary fresh choice z, simultaneous linear guards, and singular M. Projecting the linear solution space onto (u,v) gives an affine subspace or the empty set. Joining two such relations imposes both systems on (u,m,v) and eliminates m. This again gives an affine subspace or the empty set. Every nonempty affine relation on 2w variables can be specified by at most 2w affine equations, so each exact boundary-pair relation has an O((w+1)²)-gate Boolean circuit. Empty relations have a constant representation. For an explicit grammar the summaries can also be obtained by Gaussian elimination, in O(g(w+1)³) field operations after reducing each terminal relation to boundary coordinates. Reading and reducing terminal descriptions, including extra choice bits, costs additional time.

This affine claim has **endpoint** semantics under a fixed schedule. To use a dyadic interval when T is not a power of two, append a prearranged suffix of identity steps to the scheduled computation, or generate exactly T steps by a grammar via binary doubling. The generic clock increment and an arbitrary conditional halt rule need not be affine. To apply the affine bound to an early-acceptance problem, one must exhibit an affine normalization or otherwise account for those nonlinear operations. The endpoint accept predicate itself can be nonlinear and is charged in c.

**A bounded amount of nonlinearity.** Suppose any expanded interval under consideration has at most p designated two-input AND gates and all other constraints on its registers, intermediate wires, and nondeterministic choices are affine. Fix the two input bits at each designated gate. Its three relevant wires now have specified values, and the residual interval relation is affine after projection. Union over all 4ᵖ patterns. Each exact boundary relation therefore has a Boolean circuit of size O(4ᵖ(w+1)²), irrespective of the count of affine steps and the nonuniqueness of their midpoints. Alternatively, any number of affine-mode switches controlled solely by r read-only guard bits fixed over the interval gives at most 2ʳ affine pieces. These are sufficient mechanisms for short summaries. The first counts actual nonlinear occurrences, including repetitions of an instruction, and the second requires the same guard bits to persist. Under neither condition do ordinary nonlinear RAM operations become free.

## Attack the separating relation, including arbitrary overapproximations

Let one segment nondeterministically produce a midpoint mid(y) for every y in a set P, and let the second segment accept from mid(y) for every y in a disjoint set Q. To make a fully specified NO computation, arrange that the only live midpoints are precisely mid(P) and the accepting suffix predicate on those encodings holds exactly on Q; failed or malformed branches enter a distinct permanently rejecting state. One implementation guesses y in the prefix, verifies membership in P, and writes y in a dedicated field. The suffix guesses a membership witness for Q and accepts when it verifies. Both verifiers have fixed time caps. Clean the prefix workspace, choices, and all transient state before the midpoint, so mid(y) consists of the standard field y and fixed remaining bits. Bounded-workspace erasure is charged; a fixed dense work-tape bound can be explicitly swept. Pad each segment with its own scheduled idle steps to the same power-of-two length and initialize any counters and phase tags to specified constants at the join. The two phases can use different transition relations in the grammar, or a common step predicate carrying the phase and time. Merely leaving verifier scratch at the boundary could invalidate the substitution argument.

For any passing upper bounds, K(y)=R_prefix(start,mid(y)) contains P. A point of Q in K would concatenate with its genuine accepting suffix via the composition check, contradicting the terminal separation. Thus K excludes Q. This is the elementary interpolant forced at the midpoint. If Q is the complement of P, K must compute the characteristic function of P. For an encoding mid(y) that only copies y and pins constants, K uses no larger asymptotic circuit than R_prefix. Consequently proving generic small **separating** upper bounds already requires small circuits for any complementary pair implementable within the same costs. This observation alone supplies no general Boolean circuit lower bound at the hierarchy parameters.

There is an explicit exponential obstruction for unions of affine pieces. Let y=(v,b), v∈GF(2)^{2k}, and let P be the graph of f(v)=Σᵢv₂ᵢv₂ᵢ₊₁ (indices 0,…,2k−1). Take Q to be the complementary graph. Membership is deterministic in O(k) Boolean operations. Any affine subspace inside P projects injectively to an affine space W on which f agrees with an affine function. The polar form of f is nondegenerate alternating, so the direction space of W is totally isotropic and has dimension at most k: it is contained in its orthogonal complement of dimension 2k−dim W. Each piece contains at most 2ᵏ points; covering the 2²ᵏ graph points requires at least 2ᵏ pieces. Thus even one-bit output computed by a short quadratic circuit forces an exponentially large affine-piece summary at this boundary. A quadratic membership circuit for the same P has O(k) gates. The general Boolean-circuit certificate survives this example.

## A full-rank path family with small aggregate summaries

A b-bit counter illustrates a different way around low rank of individual rooted tests. A sweep starts carry c at 1. From low to high bit i update (xᵢ,c) simultaneously to (xᵢ+c,c xᵢ). These are constant-size quadratic updates. The sweep adds one modulo 2ᵇ and ends with c=1 exactly on overflow. Repeat this fixed sweep 2ᵇ times, and require no overflow. On initial x the t-th overflow indicator is the singleton indicator of x=2ᵇ−1−t, for 0≤t<2ᵇ. All 2ᵇ test functions are linearly independent even though the update schedule has a grammar of O(b) symbols. Every strict subset of the tests admits a seed with no listed overflow.

For 0≤l≤b, the effect of 2ˡ whole sweeps is addition by 2ˡ modulo 2ᵇ. An overflow somewhere in that block occurs exactly when the starting x is at least 2ᵇ−2ˡ. Both claims have O(b)-gate circuits. One can verify candidate jump and violation-summary circuits by a universal check for each level: Jₗ₊₁=Jₗ∘Jₗ and Vₗ₊₁(x)=Vₗ(x)∨Vₗ(Jₗ(x)), with the one-sweep base checked directly. The last summary is identically true. This proves that all seeds incur some violation while using exponentially fewer symbols than a list of individually violated tests covering all seeds. The overapproximation argument above removes the deterministic-successor requirement when proving nonreachability.

Lean 4.19 checks path bisection, coverage by the upper bounds, soundness of the final refutation, and the midpoint separation implication in `BoundaryRelation.lean`. The circuit-size hypotheses, Gaussian elimination, clock normalization, affine-cover count, and RAM running times are manuscript arguments.

## Can the summaries themselves have witnesses?

First allow Rₗ(u,v) to mean ∃p Cₗ(u,v,p). Without further structure the forward implication for joining two pieces would require finding a new proof after seeing the two old proofs. Here is one sufficient condition. Guess a circuit building a level-zero proof from each valid step witness, and for each level guess a circuit Hₗ(u,m,v,p,q) building a new proof from the two incoming proofs. Check universally that the proposed base proof passes, that

    Cₗ(u,m,p) and Cₗ(m,v,q) imply Cₗ₊₁(u,v,Hₗ(u,m,v,p,q)),

and that no proof at the last level connects a valid start to acceptance. Every violation has an existential witness, so the disjunction is still one SAT query. Induction constructs a passing summary for each genuine path. The time bound above now charges all the C, H and base circuits, proof wires and their encodings. Lean verifies this implication in `witness_no_path`. With unrestricted proof length the obvious merger concatenates two explicit paths. Its last proof can have length T. To save time the merger must normalize the proof back to short length at each level.

A second option needs neither a direct circuit on boundary states nor a merger. For each level guess circuits for a map π from t bits to t bits and a bit f on its input. The first 2w output bits of π name (u,v), with t≥2w. Check for two kinds of errors by SAT: a collision of π on distinct inputs, or preimages with the same first 2w output bits but different f. If neither exists, injectivity on a finite space of equal size makes π surjective. Every pair has a preimage and a unique f-value across its whole fiber. Define Rₗ(u,v) by that bit. To witness an inductive error, provide a preimage for each positive **and each negative** occurrence of R. Evaluate only the forward maps and bits, checking their keys. Combine these potential errors with the encoder errors in the same SAT instance. A malicious guess omitting a key must have a full-output collision somewhere. The proof does not assume a fast inverse or any one-way permutation. The use of inverse bits as two-sided certificates has precedent in work on unambiguous computation. [One-way permutations and self-witnessing languages](https://www.sciencedirect.com/science/article/pii/S0022000003000680)

Direct summaries are recovered by using the identity permutation. To test whether ordinary reversible simulation gives the stronger representation cheaply, try mapping (u,e,t) to (u,t XOR F(u,e),e) for a step with choices e. The map is bijective. Classifying the key (u,v) by whether its preimage has zero target register reports [F(u,e)=v]. Unless this bit is constant over choices e for the same pair, the fiber test rejects. Recording every choice as part of the key avoids that immediate conflict and grows the boundary state over a full execution. Reversible embedding alone therefore supplies neither short coherent keys nor compression. Small forward encoders that classify all boundary pairs consistently would suffice.
