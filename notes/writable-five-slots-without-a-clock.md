# No five-slot program containing a STORE decides ordinary DIMACS SAT

Use the journal's separate-operation word RAM, standard logarithmic width, fixed immediate integers, two terminal verdicts and ordinary proper ASCII 3-CNF. **Every program of at most five stored instructions containing a STORE errs or fails to halt on some valid input.** The proof covers arbitrary running times and all STORE operands in this ISA. Its new cases concern a fixed scratch cell, writes through the raw word, and full-period scans. It uses the earlier manuscript exclusions for the other cases. [ISA and control-graph classification](five-instruction-loops-on-dimacs-sat.md) · [Earlier case table](five-stored-instructions-and-logspace-sat.md)

A useful cycle reaching both verdicts needs two branches. Without a LOAD the answer is independent of the file. Without a numerical site the bounded-alphabet sensitive family defeats the program by counting possible original addresses. With the sole LOAD or numerical site off cycle, unboundedly many sensitive originals still cannot be reached. This leaves one LOAD, one numerical site, one STORE and two branches. The connected control multigraph is unicyclic. Each continuing turn traverses its recurrent sites in the same order; after exiting, the path never rejoins the cycle. Registers other than the destinations of the LOAD and the numerical site are fixed at each length. An unreachable STORE leaves at most four executable slots, covered by the preceding degeneracies or the read-only one-numerical-site exclusion. [Control graph and sensitive family](five-instruction-loops-on-dimacs-sat.md#the-control-graph-and-accessible-data) · [Read-only one-site exclusion](read-only-ram-with-one-arithmetic-site.md)

## One fixed scratch address

First suppose the recurrent STORE always writes to an address \(a\) fixed at that length. Use the four equality files with two private sign words, at sufficiently large lengths divisible by \(w\). Use the six fixed clauses leaving exactly \(x_2=x_3=0\) and the two sign pins on \(x_1\). Insert whole words of whitespace between records to place the two private sites \(i,j\) at distinct positive low addresses chosen below. A sign occupies the last byte of a full word and the next byte begins its decimal digit. Fill every file word, including its last, with ASCII bytes of value at least 9, using trailing whitespace. All initial file word values then exceed the input word-address range for large lengths. Include the zero outside the file when considering possible original values. Avoid \(a\), all fixed program words, all initial register values, and the input-independent addresses or payloads of the bounded partial turn before the first LOAD. There are arbitrarily many choices left for the two sign sites. In particular neither site is an initial memory *value*. [Equality gadget and two-query graph obstruction](private-probe-contexts-in-read-only-sat.md#five-stored-instructions)

If the LOAD is \(x\gets M[p]\) with distinct mutable registers, a probe of a private site fixes \(p\) and overwrites \(x\). If there is only one mutable register, its post-LOAD value is likewise fixed by the reply. The contents of \(M[a]\) may depend on the entire history. However, before a further LOAD on the continuing cycle, a mandatory STORE overwrites \(M[a]\) using only registers or an immediate. No other instruction can read the old contents. The exit path contains no LOAD. Hence, for either fixed reply, every continuation from this private site until the next private probe or verdict is independent of those old contents. During the continuation the other private site retains its original bit; reaching it ends this edge of the computation graph.

For a self-addressed LOAD \(x\gets M[x]\) and a distinct numerical destination \(p\), the latter register needs a separate argument. Immediately before probing a private site \(i\), \(x=i\). Neither its initial value nor an original memory word can supply \(i\). The preceding LOAD must therefore have returned \(i\) from the single scratch address \(a\). The last STORE before that preceding LOAD wrote \(i\) into \(M[a]\). Initial and pre-first-LOAD changes were excluded in the choice of \(i\). At that STORE, \(x=a\), since no intervening instruction sets \(x\) before the LOAD from \(a\). Thus the payload cannot be \(x\) or a fixed word. It has to be \(p=i\). From that STORE to the private probe, the only intervening LOAD is the one at \(a\) returning \(i\). Every numerical update and continuing branch in this portion of the fixed cycle therefore starts from the same registers and sees the same public intermediate words. In particular \(p\) at the private probe is determined by \(i\). After that probe, old scratch contents are dead by the previous paragraph. A LOAD with fixed address already misses sensitive originals.

There is now at most one effective query state per private site. Holding the answer to that query fixed determines the next query site, halt, or divergence through public computation, even when the old scratch bit patterns differ. A deterministic graph with two such query vertices cannot compute equality. For instance, if the first query is to bit \(u\), neither reply permits a verdict before querying \(v\), because flipping \(v\) changes equality. Returning to the same \(u\)-vertex first would repeat forever. Thus either reply must lead to the same \(v\)-vertex. If after a fixed \(v\) it returns to \(u\), it cycles on either input with that \(v\); if it halts, its answer is independent of \(u\). The other starting vertex is symmetric. The graph lemma also has a Lean proof. [Two-query obstruction](../lean/TwoPrivateProbeSites.lean)

When the STORE is off cycle, either it ran before entry, in which case its sole write was input-independent because the only LOAD is on cycle, or it cannot influence a subsequent LOAD on a run leaving the cycle. The first case is read-only with one additional public word in the initial image. In the distinct-register \(x\gets M[p]\) case the preceding two-query argument applies directly. A self-addressed \(x\gets M[x]\) with a distinct arithmetic destination cannot reach a chosen site absent from the initial image, the extra public word and the initial register values. This also handles fixed modifications that introduce an odd word.

## Writing through the raw word

Suppose \(x\gets M[p]\), the numerical site updates the distinct \(p\), and the STORE is either \(M[x]\gets x\) or \(M[x]\gets c\) for fixed-on-input \(c\). Use the small-alphabet table-indexing files of order \(t\). Across all their tables, selector choices and permitted translations at a given length, let \(H\) be their common union of original word values, including zero. Its size is bounded independently of \(t\). Add \(c\) and the initial \(x\) to get a bounded set \(B\). Every read is an original value, a previous \(x\), or \(c\), so all STORE destinations belong to \(B\). Each cell there has its initial value until its first STORE, and thereafter has either its own address or \(c\), according to the one fixed STORE opcode. The initial partial turn satisfies the same rule.

Translate the selector-pin section so every private address avoids \(B\). There are \(L=\Theta(n/w)\) translations and at most \(t|B|\) forbidden shifts. This choice is independent of the table and selector settings, and \(L>t|B|\) for large \(t\). In the computation graph for a fixed public table, one bit per member of \(B\) specifies whether that cell has been marked. Together with the remaining original input this determines the whole RAM. At a private query \(p\) is fixed and \(x\) is overwritten. Hence each private word has at most \(2^{|B|}\) possible contexts, independent of the order \(t\), for any numerical update to \(p\). Contract public runs between queries with these bits retained in the context. The table-indexing lower bound requires \(\Omega(2^t/t^2)\) contexts at some site for some table. This contradiction also handles mixed arithmetic with a fixed odd marker written through \(x\). [Encoding, graph count and translations](private-probe-contexts-in-read-only-sat.md)

## Other STORE operands

The following are the remaining rows of the [operand classification](five-stored-instructions-and-logspace-sat.md#checking-the-writable-cases), with no clock assumption.

* With coincident numerical and LOAD destinations and a variable STORE address, the register-alias proof misses sensitive originals. If a distinct-register LOAD is self-addressed, a STORE through its LOAD register destroys the next original; through the other register its payload keeps the successive self-addresses in the original palette plus fixed words, including self-marking. The fixed STORE destination was treated above. [Coincident destinations](adaptive-five-slot-prefixes-without-a-clock.md#coincident-register-destinations) · [Self-addressed LOAD](five-instruction-loops-on-dimacs-sat.md#an-address-bound-for-repeated-resets)
* For \(p\gets f(x)\), a STORE through \(p\) before its LOAD in the same interval between numerical instructions destroys that original. After the LOAD a raw writeback leaves the memory unchanged, so the two-query argument applies with any preliminary write recorded as public. A fixed payload restricts regular addresses to \(f(H\cup\{c\})\), up to the first partial turn, on the bounded-alphabet family. A self-mark \(M[p]\gets p\) is covered by the orbit-prefix proof. Through \(x\), an old-cursor payload is the unary reverse-link exclusion, and an updated-cursor payload is the second orbit-prefix exclusion. [Marked-address and marked-value proofs](adaptive-five-slot-prefixes-without-a-clock.md) · [Unary reverse links](unary-reverse-links-on-an-even-dimacs-base.md)
* For \(p\gets f(p)\), the even-base analysis leaves only translation by a fixed odd integer \(d\). Through \(x\), writing the old cursor or its successor is the unshifted or shifted crossed-scan exclusion. Through \(p\), a STORE before its LOAD destroys the original. After its LOAD a raw writeback changes nothing. A self-mark or fixed mark leaves the same word on every later visit. At the end of the first full period all scanned addresses are then stable. In the next two uninterrupted full periods both the entire memory and the registers at their ending boundaries agree: \(p\) has the same public position and \(x\) is the read reply at the same last position in the stable memory. With writeback the memory is stable already. A total solver must therefore exit within three full periods, allowing a bounded initial or final partial turn. Simulate those periods on the fixed-stride, contiguous-half equality files: only the current owner reads and writes its local scanned cell, and an orbit changes owner \(O_d(1)\) times per period. The protocol exchanges \(O_P(w)\) bits, contradicting deterministic equality on \(\Theta(n/\log^2 n)\) independent signs per party. [Even-base classification](five-instruction-loops-on-dimacs-sat.md#which-operation-can-generate-the-addresses) · [Unshifted scan](unshifted-crossed-scan-without-a-clock.md) · [Shifted scan](arbitrary-stride-private-sign-erasure.md) · [Communication family](communication-bound-for-public-crossed-scans.md)
* When the numerical instruction uses both \(p,x\), shifts, rotations, bitwise functions and comparisons miss sensitive addresses by the bounded-palette analysis. Addition, either subtraction and multiplication keep all data even on the even base when the STORE copies a register or an even fixed word. An odd payload is a fixed program literal. Through \(x\) it is covered by the table argument above. Through \(p\) before its LOAD it destroys originals. After the LOAD, multiplication preserves the evenness of \(p\). The three additive updates with a fixed odd marker have the color-interval exclusion. [Even-word argument](five-instruction-loops-on-dimacs-sat.md#which-operation-can-generate-the-addresses) · [Odd-marker proof](odd-self-marked-cursors-without-a-clock.md)

This excludes the writable allocations of five stored instructions. A candidate for full five-slot decidability must use a read-only schedule. The [read-only classification](read-only-five-instructions-on-ordinary-sat.md) handles those schedules, including two numerical sites. The unrestricted RAM time goal remains open. The two-query graph and selected helper invariants have Lean proofs; the operand exhaustion is a manuscript proof.
