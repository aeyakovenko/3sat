# Which missing outputs survive a joint matching test?

**Research journal, 24 November 2026.** A short verifier may admit many false answers for a single program. There is a way to use those answers without trusting any individual one: ask which omitted words are still possible when *all* names must receive different outputs. This gives a sufficient condition against **cubic** SAT even when each individual candidate list is ambiguous.

Put M=2ⁿ and let v be the first n-bit word omitted by the fixed native interpreter at B=M²⁰. Use any injection g from the M−1 short names into the M words whose only omission is v. There is an explicit canonical choice: simulate the original bounded outcome for each name in turn, keep its output if free, and otherwise assign the largest free output. The free-set invariant for this rule preserves the original first omission. This completion need not run within B, and the ranking algorithm below never calls it. Incompressibility applies to the original v and the original cutoff. [Native source](native-missing-word.md) · [Completion and its invariant](semantic-completion.md)

Fix a uniform verifier Q on a name p and word z with an existential certificate. Its explicit circuit, including the witness slots, has size and construction time M poly(n). Suppose every actual edge (p,g(p)) is admitted. Write S for the set of outputs omittable by **some** injective assignment using admitted edges. A different assignment can justify each membership in S.

## Computing every possible omission

Assuming cubic SAT, tabulate Q by M(M−1) explicit SAT calls in M⁵poly(n) time. Find any matching saturating the names, or return a default if none exists. For a fixed such matching f, start at its free output h. From output x one may move to f(p) whenever Q(p,x) holds. Take all outputs reachable in this directed graph. They are exactly S. Along a simple path move the corresponding matched names one by one into the preceding free output. Conversely the symmetric difference of f with a matching omitting z has an alternating path from h to z, unless they coincide. Disjoint cycles do not affect the omission. Thus the computed answer is independent of which matching was found. This is standard alternating-path structure in bipartite matching. [Dulmage and Mendelsohn](https://doi.org/10.4153/CJM-1958-052-0) · [Lean check of exchange](../lean/HoleExchange.lean)

Because the genuine g is a matching, v belongs to S. More is forced. At all sufficiently large lengths, every interval [v−K+1,v] with 1≤K≤v+1 contains at least cK members of S, for a fixed c>0 depending on the verifier and hypothetical solver. To prove this, score each z∈S by the largest length of a trailing interval there divided by its count of S elements. At most M/t endpoints have score at least t. Select a witness interval for the rightmost remaining qualifying endpoint and discard every endpoint in it, proceeding to its left. The selected intervals are disjoint and each contains at most its length divided by t qualifying endpoints. Hence ranking by descending score gives v rank ≤M/score(v). This rank table, including all M² windows if desired, fits the native clock. A fixed decoder with a raw suffix encoding its rank minus one would print v by B if the score were unbounded. In fact even the cardinality |S| must be Ω(M), by ranking all of S ahead of its complement. Uniformity is only required of Q and its circuit construction. The proof does not evaluate the actual g.

Viewed from the **true** matching g, at least cK−1 distinct outputs in any such window can therefore be exposed by chains of false admissions, starting at v. Each nontrivial step from a free label x to g(p) claims the false edge (p,x) relative to the initial g on a simple path. In particular if all true edges are included and only o(M) names admit *any* false edge, the cubic hypothesis fails when this happens at infinitely many lengths. A small reachable component may suffice even when every name has many false edges: arbitrary permutations inside unrelated fully matched components do not move the hole. The sufficient condition is to exhibit Q with a small omittable set or a sparse trailing window at the actual v. There is no such Q for the canonical completion in this journal.

## Different matchings after different challenges

There is a stronger test at the *same* native cutoff M²⁰. Let θ range over all public challenges of a fixed format with at most M poly(n) bits. An edge of Qθ is tested by a uniform existential circuit of size M poly(n), now with the challenge as part of its input. Let S* be the intersection of the omittable sets from all these graphs (empty for a graph with no saturating matching). Suppose only that for **every θ there is some matching omitting the actual v**. The matching may change completely with θ. The same lower bounds on the size and local density apply to S*. A single graph need not expose which labels fail the test.

For an explicit target z, a certificate that z is outside S* selects a challenge and a Hall obstruction after deleting z. Guess a set X of names and a set Y of remaining labels with |Y|<|X|. Test that no admitted edge joins X to a label outside Y other than z. A counterexample edge and its own verifier witness require one ordinary SAT query of size M poly(n), including the indexed lookups in the two guessed bit masks. A cubic SAT algorithm thus checks a fixed obstruction deterministically in M³poly(n) time. Guessing θ,X,Y around that check takes a second SAT call with an existentially checked RAM transcript for the required deterministic verdict, of size M³poly(n). The outer cubic solver costs M⁹poly(n). Hall's theorem proves completeness of this negative certificate, including the case that some name has an empty candidate set. The M answers, ranks and source simulation cost M¹⁰poly(n), below M²⁰. Thus producing one challenge-specific Hall obstruction for each of almost all labels near v would suffice, even if the same collection of edges cannot justify v on different challenges. A direct candidate is to process the original names in a challenged permutation when using the largest-free completion rule. Every true completion still omits v. The independent-outcome obstruction below applies to this candidate if all its lists are justified independently per name for every order. [Hall on systems of distinct representatives](https://doi.org/10.1112/jlms/s1-10.37.26) · [Quantifier and RAM transcript accounting](linear-quantifiers.md)

## How little two candidates can say

There is a different explicit total injection with the same **actual** omitted word for which a list of length two per name is free. Order the names i=0,…,M−2 and assign i when i<v and i+1 otherwise. One can compute v beforehand by exhaustive original simulation; this example puts no short clock on evaluating the injection. Admit both i and i+1 at every row. For any proposed omitted word z, thresholding at z gives a matching. Thus S contains every output. Even the path support with degree at most two on both sides permits the ambiguity to travel across the whole table.

Coverage is essential. With just the singleton predictions i↦i the predicted hole is M−1. Swapping the row initially at v into M−1 (if v<M−1) gives a true injection missing the actual v while changing only one row. High accuracy without knowing which predictions cover the truth would not justify including v in the computed S. In contrast, known abstentions can be given all possible edges.

There is an obstruction specific to possible outcomes of the **original** bounded programs. Suppose a per-name set Cₚ of candidate outcomes, including a possible timeout, contains the actual outcome. Consider any construction whose proof of Q-coverage is valid under every independent choice of one outcome in each Cₚ: with the new table's first gap in place of v, Q must contain a matching missing that gap. Fix x<v with no Cₚ equal to the singleton {x}. Change just the actual producers of x to some other listed possibility. All outputs below x remain, and x is now absent. Therefore x must belong to S, even if the construction uses completion afterwards. If the sets Cₚ are tabulable within the native clock under cubic SAT, the set of forced singleton outputs is tabulable too and misses v. The same sparse-window rank argument applied to its complement forces many such x near v (including v itself at the endpoint). An improvement beyond this obstruction requires constraints across names or a certificate that uses the fixed source program in a way independent choices do not preserve.

## Weights can matter when every hole is feasible

Let H be a full-row-rank (M−1)-by-M signed integer matrix whose entries have poly(n) bits and whose whole table can be computed in M¹²poly(n) native time under cubic SAT. We allow this bound, for example, for differences of capped counts of distinct primary witnesses. To test whether a cell count is at least i≤M, existentially supply i different accepted primary strings and a verifying auxiliary witness for each. For a verifier of size M poly(n), even pairwise comparisons cost only M³poly(n) encoded bits. Cubic SAT, binary search and M² cells fit the bound. An auxiliary proof is counted only through its primary string, so an arbitrarily ambiguous proof of the same primary claim contributes one.

Let c_z be the signed maximal minor obtained by deleting column z, with alternating signs in column order. Laplace expansion gives Hc=0 and rank gives c≠0. The weights q_z=c_z²/Σ_y c_y² sum to one. Rank the labels by these weights. As above the actual omitted word satisfies **q_v≤C/M** for all large n under cubic SAT. Indeed its rank in descending order is at most 1/q_v. The M integer determinants can be computed exactly with row pivoting and fraction-free elimination. Hadamard's inequality bounds the minor bit lengths by O(M(poly(n)+log M)); even ordinary quadratic integer arithmetic on the intermediates costs M⁶poly(n) for all determinants. Only the ranking is needed. Squared determinant weights are classical volume sampling. [Bareiss elimination](https://doi.org/10.1090/S0025-5718-1968-0226829-0) · [Volume sampling](https://arxiv.org/abs/1004.4057)

For example, write A=H with columns reordered to put v last, A=[A₀ | b]. If A₀ is invertible, the probability just computed is exactly 1/(1+‖A₀⁻¹b‖₂²). A rule assigning scores to the **actual** completion with ‖A₀⁻¹b‖₂=o(√M) infinitely often would suffice to exclude cubic SAT. Another sufficient condition lets P be the true injection's matrix of unit rows. Allow any positive row scales and let A now be the accordingly rescaled H, E=A−P. For a unit null vector u, ‖u restricted to the nonmissing coordinates‖₂=‖Pu‖₂=‖Eu‖₂≤‖E‖₂. Thus q_v≥1−‖E‖₂². The scales leave the null line invariant and need not be computed. Rational normalization matters because a nonzero integral error in an unscaled 0/1 matrix already has norm at least one. These criteria require information in the magnitudes or signs assigned to candidates; giving the entire support the path edges above with rows eᵢ−eᵢ₊₁ produces exactly the uniform null weight.

The same calculation accommodates rank deficiency. For any such scored table of rank M−d, let P₀ be the orthogonal projector onto its kernel; d≥1 here. Its nonnegative diagonal entries sum to d. If C is an independent row basis, with column c_z, then (P₀)zz=1−c_zᵀ(CCᵀ)⁻¹c_z; for rank zero take P₀=I. One may compute all these numbers with common denominator det(CCᵀ) by integer elimination and minors in polynomial time inside the same native budget. Gram entries and minors have bit lengths O(poly(n)) and O(M poly(n)), respectively. For an interval I ending at v, give its endpoint the score Σ_{z∈I}(P₀)zz/|I| and maximize over I. For any threshold t, rightmost disjoint witness intervals cover all qualifying endpoints, hence there are at most d/t of them. The native rank decoder forces Σ_{z∈I}(P₀)zz ≤ C₁ d |I|/M. In particular (P₀)vv=O(d/M). Whenever column v can be expressed as a combination of the other columns, this diagonal equals 1/(1+min‖x‖₂²), minimizing over H_{−v}x=H_v. Indeed a null vector with v-coordinate one is exactly (−x,1) after reordering, and projecting the unit vector e_v onto the nullspace gives the same extremal reciprocal norm. Thus small nullity can still be useful if the omitted column admits an unusually cheap linear representation. Informative scores for the actual source remain the missing step.

There is an unconditional control on the unchallenged table experiment. If each pair has at most (17−ε)n total witness bits for some fixed ε>0, exhaustive tabulation of all M² entries in time M³poly(n) times 2^{(17−ε)n} fits B. The same is true for scores obtained directly from those enumerated witnesses by capping and subtraction. The preceding rank bounds then hold without using a SAT solver. This rules out short brute-forceable witnesses alone as a source of a contradiction in that parameter range. It does not bound the cost of testing all public challenges in the stronger version.

The finite experiment compares alternating reachability from every compatible matching with exhaustive omission sets on all bipartite graphs through three names and four outputs. It also checks the signed-minor identities on integer examples. The matching lemmas and matrix estimates alone give no scoring rule for the bounded universal computation.
