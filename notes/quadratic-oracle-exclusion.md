# The permanent graph with oracle access to a degree-two extension of SAT

Fix any table $B:\{0,1\}^h\to\mathbb C$. For example, $B$ can be the SAT verdict of every $h$-bit string under a fixed convention for malformed inputs. An oracle is one polynomial $Q(Z_1,\dots,Z_h)$ of **individual** degree at most two with $Q(u)=B(u)$ at every Boolean $u$. The tree can submit any $h$ complex registers as a query and use the returned scalar in later queries, divisions or equality tests. A single $Q$ must account for every answer in a run. The tree is required to be correct for every such $Q$ and every ordinary input. Its topology and arbitrary complex scalar constants can depend on the table. There is no cost or degree bound on the table's multilinear extension.

**Decision theorem.** Suppose such a deterministic arithmetic computation tree decides $y=f(X)$ for a polynomial $f$ in $n$ variables. Each path has at most $T$ arithmetic, equality and query nodes altogether, including at most $r$ oracle calls. Arithmetic uses $+,-,\times,/$, with division defined at every actual use. Then some nonzero polynomial multiple of $y-f(X)$ has a division-free circuit of size
$$
 O\big(1+T+(r+1)^4\big).
$$
Size here counts binary arithmetic operations with arbitrary complex constants. The width disappears even when naming tuple coordinates is free, because the selected circuit reads only a few of those coordinates. Each coordinate must be an available register or a scalar constant. The argument is nonuniform. It selects particular Boolean points and pivots for the circuit without having to find them efficiently.

Consequently the quantitative complex permanent-graph lower bound in PR 249 still holds in this oracle model. If $f=\operatorname{per}_m$, for any finite oracle width $h$, worst-case cost is $2^{\Omega((\log m)^{4/3})}$, using the same imported border lower bound and factor theorem as in the PR. This applies even if one query can address a fixed SAT table by complex coordinates at unit query cost. The same lower bound holds with at most $s$ unknown perturbations of the unique multilinear extension, when the tree uses at most $s$ calls. Conversely, for the SAT table there is a polynomial-size tree using $2s+1$ calls in this perturbation model, with a polynomial choice of oracle width. The construction and precise perturbations are given below. A Boolean RAM solver specifies no behavior on complex queries. ## What a transcript can force

Work over a field $K$ extending $\mathbb C$. Let $V$ be the polynomials in the oracle variables of individual degree at most two and $I$ the subspace vanishing on the Boolean cube. Write $Z^{\flat\alpha}$ for the squarefree version of $Z^\alpha$. The polynomials $g_\alpha=Z^\alpha-Z^{\flat\alpha}$, for $\alpha\in\{0,1,2\}^h$ with at least one exponent two, span $I$. In fact subtracting these differences leaves the unique multilinear representative, which is zero if all its Boolean values are zero. Each $g_\alpha$ has $O(h)$ arithmetic operations.

Fix a list of $i$ query points $Y_j\in K^h$. For a row relation $\lambda$ annihilating the evaluations of every $g_\alpha$, the functional $L(P)=\sum_j\lambda_j P(Y_j)$ descends to a functional on Boolean tables. For $u\in\{0,1\}^h$ put
$$
 \delta_u(Z)=\prod_{k:u_k=1} Z_k\prod_{k:u_k=0}(1-Z_k),\qquad
 w_u=L(\delta_u).
$$
Then $L(P)=\sum_u w_u P(u)$, and **at most $i$ of the weights are nonzero**. Indeed the matrix $L(\delta_u\delta_v)$ is diagonal with entries $w_u$. The off-diagonal products vanish on the cube, and $\delta_u^2$ agrees with $\delta_u$ there. All products have permitted individual degree. The matrix is a sum of $i$ rank-one matrices from the $Y_j$, so it has rank at most $i$. The common support for *all* relations on a fixed transcript also has size at most $i$ over an infinite field. A generic linear combination of a basis of relations has no cancellation on the union of their supports.

Aaronson and Wigderson's Lemmas 4.3 and 4.5 already establish the information bound that a set of $i$ extension queries can constrain at most $i$ Boolean positions. Juma, Kabanets, Rackoff and Shpilka prove the exact lower bound for black-box summation of arbitrary multiquadratic polynomials. The issue in the graph problem is the *circuit size* of a certificate for two different algebraic input domains when the target and the Boolean table are both fixed. [Aaronson and Wigderson, Section 4.2](https://www.scottaaronson.com/papers/alg.pdf) · [Juma et al., polynomial summation](https://www2.cs.sfu.ca/~kabanets/papers/polysum-final.pdf)

For already chosen replies $b_j$, feasibility means that some single extension realizes them all. At a new point consider its row of evaluations on $I$. If that row is independent of previous rows then *every* new answer is feasible. Use zero. Otherwise, find a row relation with $\lambda_i=1$. The only feasible answer is
$$
 b_i=\sum_{u:w_u\ne0} w_u B(u)-\sum_{j<i}\lambda_j b_j .
$$
These assertions follow by solving the affine system with unknown perturbation in $I$ of any representative of $B$. They hold for adaptively chosen points after the preceding replies have been fixed. Induction preserves a nonempty solution set for the full prefix.

## Removing dependence on oracle width

For a finite coordinate set $J$ and a list of $i$ evaluation points, write $V_J$ for the **image under evaluation** of the multiquadratic polynomials using variables in $J$, and $I_J$ for the image of the ones vanishing on that Boolean subcube. Start with the all-ones span and the zero space when $J$ is empty ($i>0$). Adding a coordinate with evaluation vector $z$ transforms these spaces by
$$
 V_{J+}=V_J+zV_J+z^2 V_J,\qquad
 I_{J+}=I_J+zI_J+(z^2-z)V_J .
$$
Products of vectors are coordinatewise. For the second formula, write the polynomial as $A+ZB'+Z^2C$, where the Boolean vanishing conditions are that $A$ and $B'+C$ vanish on the old cube. Both spaces grow monotonically. Omit a coordinate whenever both spaces stay equal. The updates for all later coordinates depend only on the current pair of spaces, so omitting it preserves the final pair. The sum of the dimensions starts at one and is at most $2i$. Thus **one common set of at most $2i-1$ coordinates spans all the required value and null-polynomial evaluations**. For $V$ alone at a list of $t>0$ points, the same argument gives at most $t-1$ coordinates.

On this small set the null space of Boolean restriction is spanned by generators of the form
$$
 (Z_k^2-Z_k)\prod_{j\in J\setminus\{k\}} Z_j^{a_j},\qquad a_j\in\{0,1,2\}.
$$
Indeed successively reducing each exponent two to one telescopes the difference from a monomial's squarefree representative. Each such generator costs $O(i)$ operations. In particular a pivot column can be required to carry one distinguished factor $Z_k^2-Z_k$. This also specifies which perturbations are sufficient in the final argument.

At a dependent step choose $k\le i-1$ independent earlier rows and $k$ such generator columns giving an invertible minor on them. Solve the new row on these columns using those earlier rows, setting all remaining dependency coefficients to zero. For rank zero use the empty system. Generating the minor entries and solving at a fixed good pivot order both take $O(i^3)$ operations. To form the sparse weighted sum select at most $|S|-1$ coordinates distinguishing the points of the nonempty support $S=\{u:w_u\ne0\}$. Insert a coordinate separating two points whenever the induced partition has fewer than $|S|$ parts. Each selected $u$ has its own resulting pattern. For the indicator $d_u$ of that pattern on only the selected coordinates, $L(d_u)=w_u$. This costs $O(i^3)$ in total on the query list, even if a full Boolean point has arbitrarily many coordinates. For empty support there are no weights. The $B(u)$ and index choices may be hardwired. Recording independence only needs the existence of a nonzero minor. The extracted circuit need not search for any of these objects.

## Transferring a graph-generic execution to the ambient space

Put $g=y-f(X)$, let $K_G$ be the fraction field of $\mathbb C[X,y]/(g)$ and $K_A=\mathbb C(X,y)$. Follow the tree over $K_G$ using the feasible replies above. Alongside each register, keep an *ambient rational expression* in $X,y$ whose restriction gives its graph value. Start with the literal input coordinates. Do not substitute a circuit for $f$. At dependent queries use the small rational expression just constructed with the pivot choices and support selected over $K_G$. Choose divisions with nonzero pivot on the graph. The ambient denominators of the expressions so obtained remain nonzero on a dense open subset of the graph.

Every finite feasible graph prefix is realized at an actual complex graph point with an actual extension of the given table. To see this, pick a fixed representative $P_0$ and solve the prefix equations over $K_G$. An arbitrary solution only needs corrections $P_0+\sum_\ell a_\ell g_{\alpha_\ell}$ on a set of at most $i$ independent generator columns. The $a_\ell$ may be large rational functions, but they are used only to prove existence. Specialize them along with the path at a graph point avoiding all denominators and all expressions already tested nonzero. On that input they are ordinary complex constants. Adaptive execution asks the same sequence of questions since all earlier replies agree. The same argument works over $K_A$ on an ambient dense open set. Thus the graph-generic path cannot use an undefined division or exceed the worst-case bound, and its leaf is accepting.

Try to use the very same expressions and branch choices on the ambient generic input. The following are the possible obstructions.

1. An original equality test can vanish on the graph while its numerator is a nonzero ambient polynomial. Divisors, pivots and disequalities nonzero on the graph remain nonzero in the ambient field.
2. At each dependent query the relation with the computed weights is an identity on all of $V$ on the graph:
$$
   \sum_{j\le i}\lambda_j P(Y_j)=\sum_{u\in S}w_u P(u)\qquad(P\in V).
$$
Try its ambient lift on monomials of individual degree at most two. If it fails, one offending monomial uses at most $2i-1$ coordinates. Apply the $V$-only dimension calculation to the combined list of at most $i+|S|\le2i$ ambient query and Boolean points. The identity held on every monomial on the graph, so this one residual is the required witness. If the identity persists, the lifted row relation annihilates every null polynomial and the same sparse sum supplies a feasible reply in the ambient field. Independence on the graph stays independence in the ambient calculation as long as all earlier dependencies transferred. The earlier independent rows retain an invertible minor, the earlier dependent rows remain in their span, and the enlarged independent minor is still nonzero.

In each obstruction there is a *single* rational expression zero on the graph and nonzero in the ambient field. All its divisions have denominators nonzero on the graph. Its numerator is a nonzero polynomial divisible by $g$, since $P(X,f(X))=0$ is exactly the zero-remainder test for division by this monic linear polynomial in $y$. Only the selected prefix and the one offending expression enter the numerator circuit. Testing all the candidate generators or all Boolean points is unnecessary in that circuit. Without any obstruction the same accepting leaf would be feasible on an ambient open set. Choose a point there with $g\ne0$ and specialize the feasible oracle. This contradicts correctness.

Along the selected prefix all ordinary path operations cost $O(T)$. Each of the at most $r$ oracle replacements costs $O(i^3)$ at its index $i$. Computing the one diagnostic relation residual costs $O(i^2+1)$ more using the chosen short monomial. Keep numerator and denominator circuits as a pair through each arithmetic operation using at most four binary operations and sharing all earlier gates. Summing these costs proves the theorem. No bound on the degree or multiplicity of the resulting multiple is needed. Bürgisser's graph-case factor theorem turns this bound on exclusion complexity into a border upper bound for $f$. For the permanent the polynomial overhead in $m$ and the fixed powers of $T+1$ preserve the exponent order in the opening statement.

## What this rules out for formal reconstruction

There is also an output version. Suppose an arithmetic/equality tree must return a fixed polynomial $H(X)$ of degree $D$ on every complex input with every permitted extension oracle. Run only the ambient feasible simulation. The resulting small rational circuit agrees with $H$ on a dense open set. Convert it to a division-free circuit by choosing a constant point $a$ avoiding its denominator zeros and substituting $a+tX$. Truncate every gate modulo $t^{D+1}$, using series inversion at division gates with nonzero constant denominator. The resulting polynomial in $t$ equals $H(a+tX)$. Set $t=1$ and substitute $X-a$ for $X$ to recover all of $H$. The size overhead is $O((D+1)^2)$ per simulated operation plus the input translations. Taking $B$ to be the permanent on Boolean matrices gives a barrier to *adaptive numerical extraction* from all its individual-degree-two representatives. It still permits transformations that inspect the representative's circuit or require a particular extension. [Earlier extraction for prescribed square patterns](degree-two-permanent.md) · [Functional lower bounds](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2016.33) · [Hrubeš on hardness of multilinearization](https://users.math.cas.cz/~hrubes/PDFs/Mult.pdf)

For a pointwise robust promise it is enough to allow perturbations of **one** fixed representative $P_0$. On a finished path in either field, choose the common set of at most $2r-1$ coordinates spanning $I$ on its complete query list when $r>0$. A solution around $P_0$ needs at most $r$ independent short generator columns from that set. Specialization therefore gives at most $r$ scalar multiples of the single-distinguished-coordinate generators above, depending jointly on at most $2r-1$ coordinates. For $r=0$ use the baseline alone. This uses $O((r+1)^2)$ extra gates if a circuit for $P_0$ is supplied. In particular the proof works when this small perturbation family is the whole promise. A forbidden additional query can be detected by realizing its preceding prefix, before an answer to the extra query is needed.

## One call for the multilinear SAT extension and a matching upper bound with errors

Let the baseline now be the unique multilinear extension $M_B$ of the SAT truth table at the chosen width. Allow
$$
 Q(Z)=M_B(Z)+\sum_{a=1}^{s}(Z_{k_a}^2-Z_{k_a})H_a(Z).
$$
The $k_a$ are unknown, may repeat, and the polynomials $H_a$ are arbitrary subject to the promised individual degree if desired. The error term can be dense in the other coordinates. By the preceding argument, for the complex permanent graph a tree with **at most $s$ calls** still requires the asymptotic lower bound above whenever $s$ is polynomial in $m$ (indeed the exclusion-complexity theorem applies whenever $r\le s$). Here is a tree of $\operatorname{poly}(m,s)$ cost with **$2s+1$ calls**. Its one-call case at $s=0$ is already instructive.

Build a fixed ordinary 3-CNF template with $2s+1$ disjoint data banks of $m^2$ bits each. Its Boolean SAT verdict is that some one of the matrices is a permutation matrix. A circuit tests exactly one entry in each row and column for each bank and takes their disjunction. Standard gate-equivalence clauses and a unit on the output enforce its result. Pin each data bit through a separate unit clause whose single varying literal sign encodes the bit. In a width-three fixed-stride list one can instead use $(u\lor f\lor f)$ with only the sign of $u$ variable and a fixed separate unit forcing $f=0$. Duplicating the *varying* sign into three positions would identify formal coordinates and spoil multilinearity of the face. The auxiliary and fixed sign pins can use triples with no variable signs. The resulting truth-table width is the bit length $h=\operatorname{poly}(m,s)$ of a template instance.

Leave only the data bank for copy $j$ free and set all other raw data to the zero matrix. The physical strings form a Boolean face, up to independent reversals of data bits. On it the multilinear extension, viewed in data coordinates, is exactly
$$
 M(Z)=\sum_{\pi\in S_m}\prod_i Z_{i,\pi(i)}
                         \prod_{(i,k):k\ne\pi(i)}(1-Z_{ik}).
$$
This is interpolation by the Boolean indicators of permutation matrices. Fix a nonzero $t$ with every $1+tX_{ik}\ne0$. At most $m^2$ nonzero scalars are forbidden on an actual matrix, so trying $m^2+1$ fixed distinct nonzero constants with equality tests finds one. Query the face at $Z_{ik}=tX_{ik}/(1+tX_{ik})$, using $1-Z_{ik}$ for reversed pins. Clearing the common denominator gives the exact identity
$$
 M(Z)\prod_{ik}(1+tX_{ik})=t^m\operatorname{per}_m(X).
$$
At the $2s+1$ calls the possible non-Boolean *physical* coordinates of the selected banks are disjoint. Each perturbation can affect only the call in which its distinguished coordinate is non-Boolean. Hence at least $s+1$ answers are exactly the same $M(Z)$. Find a strict majority by field equality tests, then compare the displayed expression to $t^m y$. The choices of $t$ and majority use only polynomially many gates and branches. This recovers the baseline without knowing the erroneous calls or representing their dense errors.

These results locate the query threshold for this SAT oracle to within a factor of two in the number of unknown perturbations. Already when $s=1$, one call that must tolerate perturbing a single coordinate by a scalar multiple of $Z_k^2-Z_k$ is insufficient at polynomial arithmetic cost, while three calls suffice even for the broader error class. The single-call lower bound follows because the coordinate set for $r=1$ has size at most one.

## A lower bound for a class of functional circuits for SAT itself

Let $P$ be any polynomial over a field $F$ agreeing with the encoded SAT decision on all $h$-bit Boolean strings. Suppose some set $J$ of input coordinates has this property: after **every** Boolean pinning of $J$, the restriction of $P$ is multilinear in all remaining inputs as a formal polynomial. This includes circuits whose output has arbitrarily large individual degree on $J$ and at most one everywhere else. It also includes the dense errors with distinguished coordinates in $J$ above. Once $J$ is pinned, uniqueness of multilinear extension on the remaining Boolean cube identifies $P$ with the similarly pinned canonical extension.

For every fixed $0<\epsilon<1$ there are arbitrarily large ordinary encoded SAT lengths $h$ such that **every** arithmetic circuit computing such a $P$ with $|J|\le h^{1-\epsilon}$ has size at least $2^{\Omega_{F,\epsilon}((\log h)^{4/3})}$, using the reported formal Hamiltonian cycle lower bound over $F$. The allowed set can be chosen separately for each circuit and length. For characteristic other than two one can use the permanent lower bound and permutation-matrix template directly.

Use $s+1$ disjoint data banks in the OR template. For the all-fields version test whether a bank is the adjacency matrix of a *single directed cycle visiting every vertex*. This Boolean test has polynomial size, for example by checking one successor and predecessor per vertex and computing reachability from a fixed vertex by bounded Boolean matrix powers. Now the indicator sum $M(Z)$ ranges over cyclic permutations, and the odds identity has the formal Hamiltonian cycle polynomial on its right. There is a fixed $A$ such that the encoded length is $h=O((s+1)m^A\log^A(ms+2))$, including every bit of literal names. Each data bit varies exactly one sign in the encoding. Choose $s=\lceil m^{D_0}\rceil$ for a fixed integer $D_0$ sufficiently large that $(1-\epsilon)(D_0+A)<D_0$. Then $h^{1-\epsilon}\le s$ ultimately and $\log h=\Theta_{\epsilon}(\log m)$. At least one bank avoids all of $J$. Fix every other physical coordinate to its Boolean constant for this bank. The restriction of $P$ now computes $M(Z)$ **formally**. Nonuniformly choosing this one bank is allowed when deriving a circuit-size lower bound.

Work in $F[X][t]/(t^{m+1})$, even for a finite field. Each $(1+tX_{ik})^{-1}$ is the finite geometric series to degree $m$. Evaluate the restricted circuit there and multiply its output by $\prod_{ik}(1+tX_{ik})$. The coefficient of $t^m$ is the formal target by the same clearing-denominators identity. Implement truncated products by convolution at every gate, with $O((m+1)^2)$ operations per gate and polynomial overhead in $m,h$. This gives the bound from the imported formal circuit lower bound without using multivariate polynomial identity tests over a small field. The circuit notion here is division-free formal arithmetic; arbitrary scalar constants and a constant-factor change in gate-count convention do not affect the asymptotic lower bound. [Pinned formal lower bounds over fields](https://github.com/anthropics/formal-math/tree/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp) · [Hrubeš on VNP-hard multilinearization of easy Boolean functions](https://users.math.cas.cz/~hrubes/PDFs/Mult.pdf)

There is an explicit test of trying to drop the $J$ hypothesis. The very permutation-matrix predicate used on the free data has a linear-size **individual-degree-two** representative. For one row form the multilinear indicator of exactly one entry by scanning the bits, keeping polynomials for zero and one successes. On a new bit $z$ these become $A(1-z)$ and $C(1-z)+Az$ from the old zero and one polynomials $A,C$. Do this for all rows and all columns and multiply their indicators. Each variable appears in one row factor and one column factor. Each factor is multilinear, so the product has individual degree at most two and uses $O(m^2)$ gates. Taking OR across disjoint copies by $1-\prod_j(1-P_j)$ preserves that bound on individual degree. This circuit is valid on the raw data face; it does not decide SAT on arbitrary physical strings. Thus a hard canonical extension and a linear-size quadratic representative actually coexist on the permutation test used in the reduction. A proof for all degree-two representatives of the complete SAT table needs an additional feature of its other inputs.

Allowing carrier data to occupy an arbitrary prescribed set of physical input bits gives a stronger SAT statement for the dense encoding. It also gives the same lower bound for a globally scan-time SAT heuristic. [Arbitrary-coordinate faces and their time limit](arbitrary-sat-coordinate-faces.md)

The outstanding Boolean implication would have to make use of a property specific to a solver or to the arithmetic representation obtained from its code. The oracle in this theorem deliberately permits all the verified perturbations. A polytime Boolean algorithm does not imply that its word operations or branches remain correct under them. The result establishes no running-time lower bound on explicit Boolean SAT. Historical priority for the circuit-cost and graph transfer has not been established.
