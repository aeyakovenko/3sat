# Old RAM words needed when only \(k\) data records remain unread

There are proper DIMACS 3-CNFs with \(\ell b+k\) movable, aligned one-word records. On an actual run of any deterministic SAT solver, stop immediately before the first read of the \((\ell b+1)\)-st distinct movable word. All varying input lies in the movable words. For a solver taking \(O(N(\log N)^a)\) time in encoded bits for fixed \(a\), the suffix can require

\[
                   \Omega_J\!\left(\frac{k\log\ell}{\log\log\ell}\right)
\]

**distinct old addresses** after that cut, for every \(1\le k\le\ell^J\) and every fixed \(J>0\). An old address is an already exposed movable input position or a writable address whose prefix value is read before any suffix write there. A genuine read of initialized zero counts. The \(k\) remaining records, all fixed syntax, and all post-cut writes are free in this measure. The prefix already made at least \(\ell b\) input loads. The additional cost holds separately on satisfiable and unsatisfiable files, and is \(\Omega_J(k\log N/\log\log N)\) in their encoded length \(N\). Each satisfiable file in the construction has exactly one assignment.

The construction uses classical cell sampling and polynomial evaluation. Gál and Miltersen studied Boolean polynomial evaluation in the succinct bit-probe model. Larsen proved static and dynamic cell-probe bounds for field-valued evaluation. Here a field query spans the last \(k\) movable words on a SAT solver's genuine input-discovery schedule. The decision returns just one fixed binary linear functional of the evaluation. [Gál and Miltersen](https://doi.org/10.4230/DagSemProc.06111.17) · [Larsen, FOCS 2012](https://cs.au.dk/~larsen/papers/poly_eval.pdf) · [Earlier butterfly bounds after partial query disclosure](old-words-after-partial-query-disclosure.md)

## Polynomial and physical file

Let \(m\) tend to infinity, \(\ell=2^m\), \(1\le k\le\ell^J\), and \(b=2km\). Publicly fix a polynomial basis of \(F=\mathbb F_{2^b}\) and a nonzero binary linear functional \(\lambda:F\to\mathbb F_2\). One may take its constant basis coordinate or the field trace. The trace polynomial \(\sum_{j=0}^{b-1}x^{2^j}\) is nonzero and has degree less than \(2^b\), so it takes the value one somewhere. A database \(X\) consists of the \(\ell\) coefficients of a polynomial \(P_X\) of degree less than \(\ell\), using \(\ell b\) arbitrary bits. For a query \(z\in F\) the decision bit is

\[
                           B_X(z)=\lambda(P_X(z)).
\]

At any \(\ell\) distinct query points these \(\ell\) binary linear functionals of \(X\) are independent. Interpolation prescribes arbitrary field values at the points, and \(\lambda\) takes both binary values. This permits the fixed coordinate even when \(b\) is even and the field trace of one vanishes.

Use a fixed acyclic Boolean circuit that evaluates Horner's rule and applies \(\lambda\). Cantor and Kaltofen multiply degree-\(<b\) polynomials with \(O(b\log(b+2)\log\log(b+4))\) ring operations, each a bounded-size Boolean gate construction over \(\mathbb F_2\). Reduction modulo the fixed monic irreducible \(g\) costs within the same bound. Indeed write a raw product \(u=gq+r\), where \(\deg r<b\). For \(\operatorname{rev}_s(v)=x^s v(1/x)\), the low \(b\) coefficients of \(\operatorname{rev}_{2b-1}(u)\) equal those of \(\operatorname{rev}_b(g)\operatorname{rev}_{b-1}(q)\). Multiply by the precomputed inverse of \(\operatorname{rev}_b(g)\) modulo \(x^b\), reverse to obtain \(q\), then compute \(r=u-gq\). The circuit may use the lexicographically first irreducible \(g\) as a public constant. Use another \(k\) query flag bits and XOR their parity into the output. In the measured files all flags are zero. Changing the flag carried in any one query record always changes SAT. [Cantor and Kaltofen, polynomial multiplication over arbitrary algebras](https://kaltofen.math.ncsu.edu/bibliography/91/CaKa91.pdf)

Give each database bit a pair of complementary variables. For each of the \(k\) query records allocate two separate binary decoder trees. The first tree has \(2^{m+1}=2\ell\) leaf names for \(m\) query bits and its flag, and the second has \(\ell\) leaves for \(m\) further query bits. Assert the root and define each child by equivalence to its parent AND the appropriate signed bit. Asserting a leaf determines every bit along its path and hence the entire tree. Use equivalences for all Boolean gates and assert the output. Altogether \(O(\ell b\log^2(b+2)+k\ell)\) nodes and clauses suffice.

One database record contains a positive unit on the chosen complement-pair name and a second, fixed true unit. One query record contains two positive units on its chosen leaf names. Pad every unit or binary clause to three literals using distinct false anchor variables disjoint from its variables. Three anchors are forced false by the seven proper triples excluding the other seven assignments. A fresh fixed true variable supplies the filler. Simplify any repeated gate operands and use fresh distinct gate outputs. Assign consecutive positive identifiers to occurring variables. Each record has two clauses and two variable-length public-format decimal names of \(O(\log(\ell b^2))\) digits. Whitespace fills each record to exactly one machine word, with the fixed prefix padded to a word boundary. The record identity follows from its names. Changing the order of any of the records preserves the constraints. The formula fixes the database, the query, and all internal variables uniquely before the final output assertion.

For precision choose a byte-aligned RAM width \(w=8\lceil C\log_2(N+2)\rceil\) for a sufficiently large fixed constant \(C\), where \(N\) is the encoded length in bits. Choose \(N\) first as a power of two of order \(\ell b(m+\log(b+2))^3\) with a sufficiently large fixed factor, use the resulting width for the record padding, and fill the end with fixed whitespace. The \(\ell b+k\) records cost \(O((\ell b+k)w)\) bits. The fixed clauses and header, including an optional public DIMACS comment with \(m,k\) and the record-bank offset, fit in the remaining length. Thus \(w=\Theta_J(m)\) and \(N=\Theta_J(\ell b\,m^3)\). Only the \(\ell b+k\) movable addresses can depend on the data or on the query. The model here uses aligned word loads, read-only input, zero-initialized workspace and a fixed number of controller words.

## The cut belongs to completed SAT inputs

Fix the SAT program and a database \(X\). Supply the database-bit records, in logical bit order, at the first \(\ell b\) distinct movable positions the program reads. Cache each assignment permanently. Other input replies are public. Every prefix with fewer database records still has two genuine total completions of opposite verdicts. Place its remaining database records and the \(k\) query records in unused positions, then change one query flag. Consequently the program cannot halt at such a prefix. It also cannot run forever without discovering another record: any total completion would give the same infinite run. The same argument applies after the last database record until the solver would first read another movable word.

At this cut precisely \(k\) positions remain. Assign them, in increasing *physical address* order, to logical query chunks \(1,\ldots,k\). For every \(z\) the resulting all-zero-flag file has exactly the real prefix used above. Its suffix may visit the remaining positions in any order. All \(k\) are eventually visited, since an unread query flag could have reversed its verdict. In particular the construction does not give the machine an externally signaled change of phase.

Here is the quantitative statement with its workspace alternative. For every fixed \(A\), except for a fraction \(2^{-\Omega(\ell b)}\) of databases, either the actual prefix wrote to more than \(N(\log N)^A\) distinct work addresses, or at most a \(2^{-b/8}\) fraction of field queries have fewer than \(c_{A,J} k m/\log(m+2)\) distinct old addresses in their actual suffix. The positive constant can also depend on the program and the fixed width convention. A program running in \(O(N(\log N)^a)\) time satisfies the prefix cap for sufficiently large fixed \(A\). Even a time bound only on one verdict implies the prefix cap, because each prefix extends to that verdict. The uniform choices here are of the logical database and query. The physical placement of the database records depends on the fixed solver.

## Sampling the old memory

For a database satisfying the prefix cap, make a static index of \(S\le\ell b\,m^{O_{A,J}(1)}\) cells of width \(w\). Include the fixed-size controller, the ordered list of \(k\) remaining addresses, the earlier movable input words at their physical addresses, and the prefix workspace with zero default. Space for the sparse work map is linear in its number of entries using a static perfect dictionary with worst-case constant probes. Index construction is unrestricted, so deterministic exhaustive choice of the hash parameters suffices. Use one public capacity bound \(S\), padding all indices to that capacity. [Fredman, Komlós and Szemerédi](https://doi.org/10.1145/828.1884)

Given \(z\), read the controller and the full ordered list in \(O(k+1)\) index probes. Compute all \(k\) query words and their physical positions privately. Simulate the actual suffix. Fixed data, those \(k\) words, and post-cut stores are free. Cache the first fetch of every old input or work address, including unsuccessful dictionary lookups. Each distinct old address thus costs \(O(1)\) index probes. There is no bound on the suffix workspace or on the time between these probes. If the native suffix uses \(r\) distinct old addresses, its truthful static execution costs at most \(C_0(k+1+r)\) probes.

Write \(D=\ell b\) and \(Q=2^b\). Choose

\[
        \Delta=\left\lfloor\frac{D}{64(w+\lceil\log_2 S\rceil+1)}\right\rfloor,
        \qquad
        t=\left\lfloor\frac{b}{8\log_2(2S/\Delta)}\right\rfloor .
\]

Enlarge the public capacity to at least \(D\). For large \(m\), \(\Delta=\Theta_J(D/m)\), \(\log(2S/\Delta)=O_{A,J}(\log(m+2))\), and \(t\le\Delta/2\) since \(b/\Delta=O_J(m/\ell)\). Thus \(t/k\) tends to infinity uniformly over the whole range of \(k\). A suffix with fewer than \(c_{A,J}km/\log(m+2)\) old addresses therefore has a static simulation using at most \(t\) probes for sufficiently small \(c_{A,J}>0\).

Suppose a database has at least \(2^{-b/8}Q\) such cheap queries. Sample a uniform \(\Delta\)-element subset of the \(S\) index cells. A fixed true execution with at most \(t\) probes is fully answered by the sample with probability at least \((\Delta/(2S))^t\). This follows from sampling without replacement on its at most \(t\) distinct requested indices. Adaptivity does not change the indices of a true run when every requested cell is supplied. The expected number of fully answered cheap queries is at least \(2^{3b/4}\).

Choose a sample resolving at least \(2^{3b/4}\) queries and send its sorted addresses and contents in at most \(D/64\) bits. The decoder simulates the static algorithm on every query with only those cells, stopping a trial on a missing cell or after \(t\) probes. Dovetail all trials by a fixed deterministic schedule and take the first \(\lceil2^{3b/4}\rceil\) distinct completions, in a fixed order for ties. On a sample from the genuine index, each completed trial has exactly its genuine output. This works when a different suffix takes arbitrarily long. Encoder and decoder recover the same query set \(G\) and answers.

The rows in \(G\) have rank at least \(\log_2\binom{|G|}{\ell/2}\): two different sums over \(\ell/2\)-subsets would give a dependence of at most \(\ell\) distinct rows if their binary values agreed as row vectors. By \(\binom{a}{j}\ge(a/j)^j\) and \(b\ge2m\), the rank is at least \((\ell/2)(3b/4-m)\ge D/8\). Retain the first \(D/8\) independent query rows in a fixed ordering and send the position of \(X\) among their \(2^{D-D/8}\) solutions. For the asymptotic range \(m\ge3\), \(D/8\) is integral. This encodes the cap-respecting databases with the stipulated cheap fraction in at most \(D-7D/64\) bits.

For all but another \(2^{-\Omega(D)}\) fraction of databases, each verdict occurs on at least \(Q/4\) queries. For random \(X\) put \(\epsilon_z=(-1)^{B_X(z)}\). In the expansion of \(\mathbb E(\sum_z\epsilon_z)^\ell\), only tuples in which all multiplicities are even survive, by \(\ell\)-wise independence. At most \(\ell^{\ell/2}Q^{\ell/2}\) tuples can survive, by pairing indices and choosing one query per pair. Markov's inequality bounds the chance of an absolute sum at least \(Q/2\) by \((4\ell/Q)^{\ell/2}=2^{-\Omega(D)}\), since \(Q=2^b\) and \(b\ge2m\). On each remaining database satisfying the cap, the fraction of fast queries conditional on either verdict is at most \(4\cdot2^{-b/8}\).

## Total time and the scope of the bound

On the indicated files the time through the cut includes \(\ell b\) distinct input loads. Afterwards the run reads all \(k\) new words and the displayed number of distinct old addresses. In a model with separate single-word LOAD instructions these counts add. The program may have performed arbitrary computation before, between, and after these events.

**A polynomial prefix-time lower bound with bounded suffix latency.** Fix \(J\) and any constant \(L_0\). There is a constant \(\delta>0\) such that, on all but a \(2^{-\Omega(\ell b)}\) fraction of databases, either the actual prefix writes to more than \(N^{1+\delta}\) distinct addresses or fewer than a \(2^{-b/8}\) fraction of queries use at most \(L_0k\) old addresses after the cut. To see this, replace the prefix cap by \(N^{1+\delta}\) for \(0<\delta<1\). Then \(S=O(N^{1+\delta})\), \(\Delta=\Theta_J(D/m)\) and \(\log_2(2S/\Delta)\le\delta\log_2 N+O_{J}(\log m)\). The static simulation still costs at most \(C_0(k+1+L_0 k)\) on these fast queries, with a universal constant dictionary overhead independent of \(\delta\). Since \(b=2km\) and \(\log N=O_J(m)\), choosing \(\delta\) sufficiently small makes this cost at most \(t\). The same encoding proves the claim. In particular a solver meeting the latency bound on a fixed positive fraction of queries per database must spend superlinear time before the final \(k\) records on some actual input. A solver with a general \(N^{1+o(1)}\) clock must instead exceed *every fixed multiple of* \(k\) old probes on suitable genuine suffixes.

Even at \(k=1\) there are correct solvers with constant suffix latency. Read all other input positions on the layout, simulate a complete SAT procedure on every possible setting of the withheld word, and store the resulting decision bits packed. Use \(B=2^{\lfloor\log_2 w\rfloor}\) answers per table word. The \(2^w/B\) answer words fit in the lower half of the \(w\)-bit work-address space. Reserve the entire upper half for the independent SAT computation and the input copy. A fixed exhaustive routine uses \(O(N)\) scratch words even on arbitrary substitutions: keep clause positions and representatives of the at most \(N\) distinct occurring names, compare long decimal names by their input substrings, enumerate assignments to these representatives, and reuse the same scratch bank for every setting. The chosen width gives \(O(N)<2^{w-1}\) for all sufficiently large files. The simulated input overlays the trial word, so preprocessing never reads the actual withheld position. Finally load that word, use a shift and a mask to retrieve its answer, and halt. The program can select a withheld position using the public DIMACS comment, validate offsets before using them, and use complete SAT directly when the format is inapplicable. The potentially enormous tabulation occurs before the cut.

The same proof allows \(k\) to exceed every fixed power of \(\ell\). Put \(u=\lceil\log_2(\ell b+2)\rceil\) and require \(m/\log(u+2)\to\infty\). The layout has \(N=\Theta(\ell b\,u^3)\), \(w=\Theta(u)\), and \(S\le\ell b\,u^{O_A(1)}\). Now \(\Delta=\Theta(\ell b/u)\), the sampling logarithm is \(O_A(\log(u+2))\), and \(\ell/u\to\infty\) ensures \(t\le\Delta/2\). The \(O(k)\) address-list cost is absorbed because \(t/k=\Omega(m/\log(u+2))\). This gives \(\Omega(km/\log\log N)\) old addresses with the same two exceptional fractions. For instance choose \(m=\lceil(\log_2 k)^\alpha\rceil\) for any fixed \(0<\alpha<1\). Then \(k=N^{1-o(1)}\) records remain and the genuine suffix costs \(\Omega(k(\log N)^\alpha/\log\log N)\) old addresses.

There is a globally correct solver taking \(O(N)\) steps on *all* files in this construction. Branch on the three designated anchors, exhaustively unit-propagate each branch, and invoke complete SAT search on unresolved branches. On the family seven branches immediately conflict. On the remaining branch each unit on a decoder leaf forces its prefix and the selected bit all the way up the tree. The pinned bits then fix every gate by propagation, including the output. Parsing the dense identifiers and processing the clause occurrences costs \(O(N)\) native steps here. Thus the suffix theorem is compatible with a linear clock. Lower bounds for different cut locations also need not be additive. A RAM can make a single initial copy of its input and run a solver on that copy, paying \(O(N/w)\) extra steps. Retrieval attributed to many earlier cuts may then occur in the same final computation.

The finite audit checks the linear independence used by the sampler, the subset-rank lower bound for all \(65{,}536\) query subsets of a small field, and the two-name chunk encoding. Lean 4.19 checks the general bounded-subset collision lemma: absence of a nonzero vanishing sum on at most \(2h\) rows makes the map from masks of weight at most \(h\) to their binary vector sums injective.
