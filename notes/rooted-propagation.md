# A short refutation by comparing paths from one root

## Replace the circuit for an entire history by bits at a root

Let a finite constraint instance have a root, vertices with finite labels, and a probability distribution over tests. Each test checks a predicate on the labels of at most two named vertices. Additional directed arcs carry efficiently evaluable maps from the source label to the target label. Assume the following properties of the reduction.

1. Every vertex appearing in a test has a directed path from the root of length at most D. The path need not be efficiently findable. A proposed path and all its arcs can be checked efficiently from the succinct instance.
2. On a YES input there is a single labeling satisfying all tests and respecting every transport arc. Allow the maps to take a shared advice string as an extra argument, provided one choice of advice makes **all** arcs correct for this labeling. Arc validity and endpoint identities are publicly checkable, independently of the advice.
3. On a NO input **every** labeling violates tests of total mass at least ε. In the proof below the maps are total on their encoded domains and always produce legal labels. Invalid root encodings can instead be excluded in the final SAT instance. Let b be the total number of root-label and shared-advice bits.

**Lemma.** A NO input has a list of at most ⌈(b+1)/ε⌉ tests, with two root paths per test, for which no root label and advice passes all the listed comparisons. On a YES input every valid list and every choice of valid paths has a common passing root label and advice.

For the NO direction, fix one path to each tested vertex. Each of at most 2ᵇ seeds now determines one labeling, by following the fixed paths. This holds even for mutually inconsistent arc maps since the path to any one vertex has already been chosen. For a fixed seed, m independent tests all pass with probability at most (1−ε)^m. A union bound over seeds gives probability at most 2ᵇ exp(−εm)<1 at the displayed list size. The resulting certificate contains only the paths to the endpoints it actually uses. For the YES direction, start with the correct root label and advice. Induction along **any** valid path gives the true label at its endpoint. In particular a maliciously chosen set of paths cannot refute a YES input. The path induction and a consistency converse for the seed-free functional case are in `RootTransport.lean`. The counting argument is on paper.

### Charged implication for the SAT time question

On the NO side a nondeterministic machine guesses the list, validates it, and writes one ordinary width-three SAT instance. Its free variables include the b seed bits. The circuit computes both transported labels for each test and ANDs all test outcomes. The nondeterministic branch certifies NO when the deterministic SAT decider returns UNSAT. No path-finding subroutine or circuit giving a history bit at an arbitrary address is required.

For clarity, suppose vertex, test, and arc names use at most a bits. Let g bound the cost to **construct as well as evaluate gate descriptions** of a hardwired arc map or test on a seed/label, up to logarithmic factors, and the time to validate one such name or connection. Assume the local instance description is uniformly available within the budget. For m=⌈(b+1)/ε⌉, the cost of guessing and of building the explicit formula, including its binary indices, is bounded by Õ(b + m(D+1)(a+g+1)). Its encoded length is bounded by the same quantity. A time-O(Nᵈ) solver therefore gives a co-nondeterministic decision procedure in the d-th power of this budget up to polylogarithmic factors, plus any initial reduction cost. Polynomial-sized word operations in the logarithm of the simulated clock permit a quasilinear nondeterministic RAM-to-tape simulation.

For example, write T=2ᵏ. If ε is constant, a and D are poly(k), b≤T^β, and g≤(b+1)poly(k), the resulting time is at most T^(2βd)poly(k), assuming poly(k) setup. At d=3, β<1/6 gives a polynomial saving in T; d=2 allows β<1/4. To derive a SAT lower bound one would need such a uniform reduction for a language in NTIME(T) outside the corresponding **co**-nondeterministic time bound. A language separating the two clocks with a polynomial gap can be obtained by direct diagonalization against complement machines: on an input starting with a valid machine code, accept exactly if that nondeterministic machine accepts the same input before a generous smaller cutoff. A proposed fast recognizer of the complement is then contradicted on its own prefix. This simulates just one nondeterministic path per branch with the usual universal-simulation overhead. Choosing the cutoff strictly between the fast clock and T leaves room for that overhead. The missing ingredient is the reduction into the specified rooted constraints.

For comparison, complete path propagation holds in permutation constraint games in both directions. General two-prover projection games supply a forward map for each bipartite edge. Following a path in the underlying undirected graph can require finding a preimage. The distinction matters even at diameter six and constant soundness gap. [Khot, unique two-prover games](https://doi.org/10.1145/509907.510017)

## An obstruction with exactly two preimages

There are constant-gap unsatisfiable projection instances on Θ(n) vertices, of undirected diameter at most six, in which every projection is exactly two-to-one and every set of at most δn edges is jointly satisfiable, for an absolute δ>0. The instance uses two bits per constraint-node label and one per variable-node label. This local-consistency phenomenon has much stronger relatives in lower bounds for semidefinite relaxations of random XOR systems. The elementary version here tracks the path-certificate parameters. [Schoenebeck, FOCS 2008](https://schoeneb.people.si.umich.edu/papers/LasserreNew.pdf)

**Choose the scopes.** Choose m=2n independent triples of distinct variables uniformly. Let A be their binary incidence matrix. With probability tending to one, any at most δn rows are independent. Indeed, in a dependency on t rows all used variables occur at least twice. Put u=⌊3t/2⌋. A union bound on row and variable sets bounds the probability of any such dependency of size t by

    binom(2n,t) binom(n,u) (u/n)^(3t) ≤ (C sqrt(t/n))^t

for t≤δn and a universal C. The last inequality follows from binom(N,j)≤(eN/j)^j, u≤1.5t, and u≥t. The first factor counts choices of rows; sampling the three positions without replacement only reduces the bound (u/n)^3 for containment. Sets with u<3 are impossible. Sum first through √n, where the base is ≤C n^(−1/4), and then through δn with C√δ<1/2. The sum tends to zero. Fix such an A.

**Choose a syndrome.** For independent fair right-hand sides w, any fixed x violates a binomial(m,1/2) number of equations Ax=w. For ε₀=1/16 the union bound for existence of a solution within ε₀m violations is at most 2ⁿ·2^(−m(1−H₂(ε₀))), which tends to zero since H₂(1/16)<1/2. Choose w with every x violating at least ε₀m equations. Independence of every small row set implies that its equations admit a solution for *every* choice of their right-hand sides.

**Build the graph.** Each primary equation vertex has as labels the four triples satisfying its parity. Its three edges project onto the corresponding bits of variable vertices. Each of these projections has two preimages for each bit. Add one variable vertex z and, for each original variable i, one auxiliary vertex with the four unrestricted labels (xᵢ,z). Its two edges project to i and z. Thus the whole graph has 3m+2n=8n edges. Each original equation is within three steps of z, and every other vertex is within two. For any labeling, the bits on the original variables violate at least ε₀m primary equations. At each such equation at least one projection edge fails. The edge gap under the uniform distribution is at least ε₀/4=1/64. In contrast, any set of ≤δn observed edges touches at most δn primary equations. Solve all those equations together, choose z arbitrarily and set the auxiliary labels to the corresponding pairs. These labels pass every observed edge.

### A quantitative test of the shared-advice repair

Keep A and the incidence layout fixed and vary only the equation right-hand sides. No sound certificate protocol for NO can, on an accepting branch for a gap-NO syndrome, inspect at most δn distinct right-hand-side bits and then certify NO, even with unlimited local computation and an arbitrary guessed certificate. The inspected rows are independent, so there exists a planted completion w′=Ax′ matching all answers on that branch. It induces a perfectly satisfiable graph with the same transcript. The argument also allows adaptive probes by replaying the same choices; here “planted” means a syndrome generated from an assignment.

Apply this to a proposed uniform implementation of reverse transport using b shared bits, when each valid arc/test description reads only the right-hand sides of O(1) specified primary equations independent of those b bits. If it worked on every planted YES and retained the given gap on NO, the certificate lemma would require reading at most O((b+1)(D+1)/ε) right-hand-side bits: read those positions and build the SAT query from their values. Hence (b+1)(D+1)/ε=Ω(n). At constant diameter and gap this repair requires linear shared information. The argument charges the data inspected across **all** seeds when constructing the SAT instance. If a map can read a different global part of the syndrome for each seed, that assumption fails. The obstruction also does not supply a hard succinctly generated hierarchy instance. It rules out a general edge-local transformation that relies only on diameter, gap, and a two-element reverse fiber.

The accompanying finite experiment uses smaller parity systems. It checks the minimum unsatisfiable subsystem, optimum number of violated edges and planted completions exhaustively; it does not estimate the asymptotic constants.

## Retry on actual computations: certify the output of a jump

The same one-call argument allows **relational arcs with a unique possible output**. Supply a small Boolean circuit E(input label, output label, auxiliary bits, advice) for each arc. For a fixed advice and incoming label, all satisfying assignments to E must agree on the outgoing label. Multiple auxiliary witnesses for the same value are allowed. Assume totality for simplicity. On YES some common advice and valid labeling must have a witness on every arc. On NO fix the paths used in the counting proof. For each root seed, semantic uniqueness defines one endpoint value on every chosen path, even when finding it deterministically is expensive. In the final SAT query, give *each occurrence* of an arc fresh variables for the outgoing label and the auxiliary bits, equate consecutive labels along a path, and conjoin all predicates. Satisfiability is exactly existence of a root seed passing all sampled comparisons. No proof needs to compute or store the entire resulting assignment. Total encoded gate and variable costs, including the cost of writing the relations, replace g in the earlier formula. Uniqueness must follow from the reduction; allowing the prover simply to assert it would invalidate the counting argument. In fact the NO proof needs uniqueness only along its chosen paths, and the YES proof uses only existence of compatible transports.

A specific attempted reduction starts with deterministic checkpoint configurations and adds a jump for every dyadic time interval. A jump relation can check a local witness that the second configuration follows from the first. A deterministic run makes its output unique. With ordinary explicit segment transcripts the jump of length L still costs at least L symbols to specify in the SAT query. Replacing many short arcs by one such jump removes steps from D while charging them to g. Also a full checkpoint of an unrestricted machine can contain Θ(T) words. A proof using this repair needs short *output-unique relations* on compressed labels for long intervals, with no long global witness. Ordinary Cook–Levin verification does not establish either size bound.

There is an exact query-model test of the proposed gap amplification. A reversible one-bit counter traverses N input bits, flipping on ones. Pin its two endpoint states to zero. On odd parity every sound NO certificate using explicitly read bits must inspect all N, since flipping any uninspected bit preserves its transcript on a YES instance. Suppose a uniform transformation into the rooted gap setup inspects at most q specified input bits per supplied arc/test, including construction and validation, and uses q₀ additional setup probes. Then N ≤ q₀ + O((b+1)(D+1)q/ε). This applies also to the output-unique relational extension if its compiled SAT query only uses those inspected bits. The original bits here are explicit. A hierarchy input of length log T can describe a long computation without providing T independent bits, so the argument does not settle the intended reduction.
