# An integer grid for the permanent graph argument

The proof in PR #249 extracts a small nonzero polynomial multiple of the permanent graph equation from one path of an algebraic computation tree. The extraction also works for a sufficiently large finite integer grid. The number of bits per coordinate matters when interpreting this conclusion. [Pinned proof, §§3–5](https://github.com/1337isnot1337/solved-conjectures/blob/50e44b55f7f10adf6c8aa8f167b31dd5b23c2171/research/bss-permanent-graph/PROOF.md#4-extracting-a-small-nonzero-multiple-from-one-path)

Write f(X)=perₘ(X), g=y−f(X), and S={0,…,B−1}, with m≥2 and integer B>2^(T+2). Suppose a deterministic complex arithmetic and equality tree as in the cited proof decides g=0 in at most T steps on every input with X in S^(m²) and integer y between 0 and m!(B−1)ᵐ inclusive. Divisions need only be defined on executions for these promised inputs. Then a nonzero multiple of g has a division-free arithmetic program of at most 4T+3 operations. In particular the permanent border bound and factor theorem used in the PR apply with the same stated loss. Trees correct on all integer inputs are covered by choosing this grid for any proposed time bound T.

Represent each register by a numerator and denominator, initially of degree at most one. At step t, one complex arithmetic operation forms products, or sums of products, of the preceding polynomials. Thus both degrees are at most 2ᵗ. An equality test between A/B′ and C/D has numerator E=AD−CB′ of degree at most 2ᵗ at step t. Follow the path determined by substituting y=f(X) symbolically. For a test with nonzero substituted numerator take the unequal branch. For a division require the divisor's numerator to be nonzero. Multiply these required nonzero polynomials along the path into Q, initially 1. At most one factor is added per step. Earlier denominator nonvanishing then follows by induction from the division rule. For a prefix of at most T steps, deg Q≤Σ_{t=1}^T 2ᵗ<2^(T+1).

Each prefix so constructed is reached by a promised graph input. Its substituted product Q(X,f(X)) is nonzero, and its degree in each individual matrix entry is at most deg Q, since f is multilinear. A nonzero polynomial whose individual degrees are below B cannot vanish throughout S^(m²), by repeated univariate interpolation. Choose a surviving X and set y=f(X), which is in the stated range. This same argument at the preceding prefix rules out a next divisor whose numerator vanishes identically after substitution, as the tree would divide by zero on that promised execution. At depth T a surviving graph point rules out a further operation. An accepting leaf is therefore reached within the bound.

If every equality taken on this path has numerator identically zero as an ambient polynomial, any input with Q≠0 follows the path. The ambient polynomial gQ is nonzero and has individual degrees at most deg Q+1 because g is multilinear in each input. Interpolation supplies a point in S^(m²+1) where gQ≠0. Its y lies in the promised range, so the tree would accept a promised no-instance. Hence some equality numerator is ambient-nonzero and vanishes upon substituting y=f(X). Division by the monic polynomial y−f(X) shows that g divides this numerator. Reproducing just the arithmetic before this test costs at most four division-free operations per original operation and three more for the equality numerator, as in the pinned proof.

Taking B=2^(T+2)+1 uses T+3 bits per matrix entry in fixed-width binary, before encoding y. The grid therefore has fixed-width matrix descriptions of length m²(T+3). The argument guarantees a surviving point somewhere on that grid and gives no comparable bound for Boolean entries. Indeed, with X restricted to Boolean matrices and y still any complex scalar, a nonuniform tree tests each of the m² entries for zero and then compares y with the permanent preassigned to that leaf. Its depth is m²+1. It uses exponentially many leaves, which the PR's depth measure permits. This distinction prevents an encoded-SAT time bound from following from the grid calculation.

An exponentially large alphabet can also admit short scalar lookup trees if it has a convenient algebraic representation. Let each matrix entry be a 2ᵏth root of unity, with k≥1, and fix a primitive root ζ. From one scalar z=ζᵉ form z,z²,…,z^(2^(k−1)) using k−1 squarings. Suppose a path has recovered r=e modulo 2ʲ with 0≤r<2ʲ. Compare z^(2^(k−1−j)) with the constant ζ^(r·2^(k−1−j)). Equality means e=r modulo 2^(j+1), and inequality means e=r+2ʲ modulo 2^(j+1). The constants may depend on the path. Starting from r=0 modulo one, k tests identify the entry. Thus depth at most m²(2k−1)+1 suffices to decide graph membership for these scalar inputs and arbitrary complex y by one precomputed permanent per leaf. Taking larger finite alphabets alone does not preserve the hard generic path at small encoding length.
