# Hard writable-memory replies on each of two explicit SAT runs

Assume ordinary explicit SAT has a deterministic logarithmic-word RAM algorithm taking $O(N\log^a(N+2))$ time for a fixed $a$. This reference solver can use arbitrary workspace. Fix **any** deterministic solver $D$ correct on the promised pairs $F_{j,0},F_{j,1}$ in the pinned-family construction. Set $M=2^j$, and write
$$
   H_j=2^{\lceil\sqrt{j\lceil\log_2(j+2)\rceil}\rceil}.
$$
The physical formula length on either pin is $N=\Theta(M(j+1)^3)$. Each packed word of the formula can be generated from the pin and scale in polynomial time in $j$ and with polynomial work space in $j$. The pinned-family theorem unconditionally forbids a deterministic sound tester for either color of the pair from signaling in $o(M)$ steps on infinitely many scales. The solver and predictors below can receive both the scale and pin for free. [Pinned pairs and the deterministic lower bound](priority-pinned-sat.md)

**Theorem.** Fix a polynomial step bound $M^p$ and a fixed deterministic predictor with a polynomial time bound per prediction and update. There is a constant $K$ such that at **every sufficiently large scale, separately on each pin**, the following holds. If $D$ halts within $M^p$ steps, every predictor advice string and mutable predictor workspace of combined size at most $M/H_j^K$ bits give **more than $M/H_j^K$ incorrect words** among the genuine replies to loads of writable memory. The predictor receives the genuine current controller, memory request, and the preceding stream of instruction events in order. After offering a prediction it gets the actual reply for its state update. It can access the entire immutable formula and its own advice at any time. Each current work-load return is hidden until after the prediction. The past is available through the predictor's charged state. The predictor may spend polynomial time in $M$ between successive events. There is no requirement that it approximate a whole memory snapshot. An indexed public circuit for the stream of load replies is a special case, with its description charged as advice and its evaluation space charged as workspace.

One consequence for the actual machine uses
$$
    C_D(F)=\sum_{0\le t<T_D(F)}(1+|\operatorname{supp} W_t|),
$$
where $W_t$ is the writable store immediately before instruction $t$, initially zero. For some constant $K'$ and every sufficiently large $j$, on **both** formulas
$$
       C_D(F_{j,d})\ \ge\ M^2/H_j^{K'} .
$$
This assertion allows any halting time for $D$. When $D$ halts within $M^p$, each pin also has at least $M/H_j^{K'}$ nonzero loads whose address has gone unused while at least $M/H_j^{K'}$ distinct other writable addresses were accessed. The constant for that statement may depend on $p$. Since $H_j=N^{o(1)}$, the cumulative bound is $N^{2-o(1)}$. The explicit both-pins, every-scale guarantee uses the near-linear SAT hypothesis. Unconditional worst-case cumulative lower bounds and earlier read-gap and list-generator theorems have different quantifiers. ## Checking a proposed stream by repeating the controller simulation

First consider exact prediction. Fix $d$ and an output $y$. A tester signals if it certifies a genuine run of $D$ on $F_{j,d}$ that ends with answer $y$. This certifies one fixed color of the priority bit. The following nondeterministic tape computation guesses an advice string once, saves it on its work tapes, and enforces the advice and predictor work bounds. It runs a simulated controller with the predictor supplying every reply to a writable load. Public input reads use the local formula generator. The controller emits its stores with their actual computed addresses and values, and its loads with their proposed replies. The program counter, fixed registers and word arithmetic use $O_D(j)$ bits apart from the generator's polynomial-in-$j$ scratch. Give memory accesses within one instruction their fixed order. Equivalently split the step into a fixed number of primitive events, preserving the updates of the registers and predictor. Include mutable predictor tables, traversal indices and addresses in its space cap. A predictor using a native sparse store can be simulated by lists of occupied address-value pairs. Charging bits for the pairs directly, or allowing a factor polynomial in $j$ when only occupied words are specified, suffices below.

Whenever the main simulation reaches a load of address $u$ at event $t$, save this address and the proposed word. Start an independent copy of the controller and predictor from the same initial state with the same guessed advice. Simulate that copy from event zero up to but excluding $t$, always feeding its own proposed replies. Remember the latest value stored to $u$, initialized to zero. Check that the remembered word equals the proposed reply at $t$. The prefix copy uses no recursive checks. Both simulations see the same immutable formula and advice. They issue identical speculative events through any common prefix because they are deterministic. If all comparisons pass, induction in event order forces every proposed reply and every event of the main run to be genuine. Conversely a predictor correct on the true sequence passes every test. Signal only after the checked run halts with $y$. Enforce the step, per-event and tape caps on arbitrary advice. With honest or dishonest advice, the two copies and the outer loop take only $M^{O(1)}$ steps. The exponent can be chosen fixed independently of the eventual numeric space cap. Workspace is at most $(S+\operatorname{poly}(j))\operatorname{poly}(j)$ for combined advice and predictor budget $S$, including the tape simulation. Reusing the work tapes for each prefix is essential. The prefix copies regenerate the accesses from the common controller and advice. Lean checks that testing each load against the latest write in its regenerated prefix is equivalent to ordinary writable-array legality. [Prefix replay in Lean](../lean/PrefixReplyReplay.lean)

The actual physical input to this tape computation consists of $j,d,y$ and binary resource caps of $O(j)$ bits, in addition to its fixed program. The nominal long formula is generated from these whenever needed. Under the reference SAT hypothesis, nondeterministic tape reachability in polynomial time in $M$ at this space cap has a deterministic RAM simulation in
$$
      (S+\operatorname{poly}(j)) H_j^{O(1)}
$$
steps. The constant in the exponent is independent of the numeric cap when supplied as data. Indeed the quantified checkpoint computation uses fan-out $2^{\Theta(\sqrt{j\log(j+2)})}$ and $O(\sqrt{j/\log(j+2)})$ levels. Eliminating one block grows its size by a fixed polylogarithmic factor even for reference time $O(N\log^a N)$. The fixed test enforces its input, tape and time caps on every branch. Implement the resulting scale tester in the pinned-family word model with its supplied nominal length $M$, binary metadata and fixed-width normalization. Simulation of a sub-$M$ clock can add polynomial factors in $j$ and an $o(M)$ setup term, which are absorbed by selecting the cap below. [Quantified reachability bound](linear-quantifiers.md) · [Quasilinear SAT extension](projected-trace-lists.md) · [Native scale simulation](priority-pinned-sat.md)

Choose a fixed integer $K_0$ larger than the uniform loss exponent, allowing also for the fixed word simulation and tape factors. At $S=\lfloor M/H_j^{K_0}\rfloor$ this color test costs $o(M)$. Integer square roots, ceilings and power-of-two caps can be computed from $j$ in polynomial time in $j$. The pinned-family lower bound now forbids a successful test at **any** sufficiently large scale. Taking common constants for the four choices of $d,y$ gives the exact-prediction exclusion on both runs.

For approximate prediction, attach a sorted list of exceptional event ordinals and their correct words. Each pair uses $O_{D,p}(j)$ bits. On the speculative simulation, supply the listed correction before updating the predictor, so the predictor continues to see the same feedback as on the genuine trajectory. On correct advice an induction through successive events gives an exact predictor. An arbitrary malformed list cannot make an incorrect computation pass the rerun checks. This corrected predictor is one fixed program whose clock only increases by a fixed polynomial. Apply the exact result to that program. For large enough $K$, an original budget and an exception count both at most $M/H_j^K$ fit its forbidden exact budget, including factors polynomial in $j$. Its exponent constant need not be uniform over all predictors.

## Predictions with fresh private coins

A predictor may use polynomially many independent private coins, reading them once in order as its computation proceeds. For every such fixed predictor there is a $K$ such that, with $u=\lfloor M/H_j^K\rfloor$, at every sufficiently large scale and on either polynomial-clock run, every fixed advice string with advice length plus worst-case predictor work space at most $u$ satisfies
$$
   \Pr[\text{at most }u\text{ incorrect replies on the genuine events}]<2^{-u}.
$$
Advice is chosen before the coins and can depend arbitrarily on the entire genuine run. The clock and space bounds hold for every coin string.

Fix the genuine event stream and the advice. A test keeps the predictor's state and counts its errors while feeding it the true events and replies. The fixed stream is hardwired in the transition functions of a read-once branching program for this test. The event index, position on the random tape and counters cost $O(j)$ bits. The program can absorb deterministic work between successive coins into its transitions, and pad halted paths to its polynomial coin budget. Its log width is at most $(u+j)\operatorname{poly}(j)$, allowing the same sparse address representation. This test is used only to prove that one good seed exists. The real predictor receiving that seed still sees each current reply only after it predicts.

Nisan's generator for polynomial length and this width, with error $2^{-u-1}$, uses $(u+j)\operatorname{poly}(j)$ seed bits. If the displayed event had probability at least $2^{-u}$, it would occur for some seed. A deterministic predictor can use that seed as extra advice, generate the coins when needed, and retain the original predictor's behavior on the teacher's stream. Nisan's recursive generator has block width $w=O(\log(\text{branching-program width})+u+j)$ and depth $O(j)$. For a requested block follow its binary index down the recursion, applying the seed-specified affine convolution hash on each right branch. A block hash on $w$ bits takes $O(w^2)$ elementary bit operations with indexed access and $O(w+\log w)$ temporary bits. Sequential tape access still costs polynomial time in $w+j$. Including the seed, this takes $O(wj)$ stored bits and polynomial time in $M$ per block. If the requested random tape is shorter than a block, storing it verbatim already meets this bound. The size parameters and counters cost $O(j)$ additional bits, and a fixed interpreter handles them as data. For large enough $K$ this deterministic predictor, given the original advice and the seed, would fall below the previously forbidden budget and make at most $u$ mistakes. This proves the probability bound simultaneously for each individual fixed advice string without a union bound over advice strings. [Nisan, §§2.2–3.3 and Theorem 1](https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2013W/Nisan_PRG.pdf) · [Parameters for arbitrary error and width](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2020.25)

## Hard reads and cumulative store occupancy

Take a fixed predictor that maintains the last $R$ distinct writable addresses accessed, using least-recently-used eviction. It remembers the last value of each such address. Stores disclose the value written, and loads disclose their true reply after each prediction. On a miss it predicts zero. Its work space is $O(Rj+\operatorname{poly}(j))$ bits. It can implement each operation by scanning a list in polynomial time. Supply $R$ in binary as advice to the same predictor for every cap. Choose $R=\lfloor M/H_j^b\rfloor$ with $b$ large enough to fit the theorem's cap and let $Q$ be the number of its incorrect predictions. On each of the two runs of duration at most $M^p$ we have $Q\ge M/H_j^{O(1)}$.

Each incorrect prediction is a nonzero read absent from the cache. Its address was previously touched, since untouched cells are zero. Strictly between its last previous touch and this read are at least $R$ distinct other writable addresses. The cell stays nonzero through that intervening interval. Intervals associated with one address have disjoint interiors. In the primitive event clock, summing occupied-word counts therefore contributes at least $QR$ up to a constant factor and endpoint losses. More explicitly, at most a fixed $b_0$ primitive memory events occur per original instruction. Each interval contains at least $R/b_0-2$ complete instruction boundaries before the new read at which this word is nonzero. For the same address the intervening boundaries can be taken strictly interior, hence are never counted twice. Summing in instruction time proves $C_D\ge Q(R/b_0-2)$. For the cumulative bound take $p=2$. Any run exceeding $M^2$ steps already contributes more than $M^2$ by the unit charge. Moreover an address can contribute at most $1+b_0 T_D/R$ incorrect predictions, so at least $Q/(1+b_0 T_D/R)$ distinct addresses contribute. For a near-linear time solver this is $N^{1-o(1)}$ actual addresses on each pin.

With the weaker hypothesis that SAT takes $N^{1+o(1)}$ time, the same reasoning gives the power-scale assertions. For every fixed $\eta>0$ one may replace the forbidden space and error-count budget by $M^{1-\eta}$. Indeed, take a fixed positive fan-out exponent below $\eta/4$, giving a constant number of checkpoint levels for each fixed polynomial source clock. The initial quantified test has size at most $M^{1-\eta/2}$ for large $j$, and a fixed number of $s\mapsto s^{1+o(1)}$ eliminations retains a strict exponent saving. This yields the cumulative lower bound $N^{2-o(1)}$ on the same pinned inputs under this weaker hypothesis too. For a quadratic or cubic reference SAT clock, eliminating even a fixed number of such blocks incurs powers of the current size. The quasilinear estimate used for these conclusions is unavailable at those exponents. The use of low-space prediction is a testable consequence of assuming fast SAT. We have not proved that an unrestricted solver must admit such predictions.
