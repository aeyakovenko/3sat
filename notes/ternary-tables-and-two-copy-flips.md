# Which ternary truth tables can hide an inconsistent two-copy flip?

Fix the correspondence between the scopes and their three ports in two Boolean constraint systems. A flip vector chooses, for each variable, whether its two copies are exchanged. The matching problem asks whether the same choices carry every source table to its prescribed target table. Among aligned ternary tables, only matching a full three-variable parity equation to a full three-variable parity equation can impose a flip constraint that fails to decompose into unary pins and binary XORs. All other local matches together can be checked in linear time, and every inconsistent system of those matches is refuted with three existential pebbles. Three is the exact worst case even when each table depends on all three ports. This identifies a limitation of the local-flip mechanism used in doubled parity constructions. [Atserias–Dawar, §3, especially the construction of the doubled system](https://www.cs.upc.edu/~atserias/papers/definable-inapproximability/definable-inapproximability.pdf)

## Classifying the allowed flips

Write a truth table as its set of accepted rows $R\subseteq V=\mathbb F_2^3$, and let $R+g=\{x+g:x\in R\}$. For a target $S$, the allowed flips form $G(R,S)=\{g:R+g=S\}$. The stabilizer $H=G(R,R)$ is a vector subspace. If there is one match $a$, then $G(R,S)=a+H$, since $R+g=R+a$ exactly when $g+a\in H$. Empty matches immediately refute a system. This coset argument works at every arity.

* If $H=V$, the table is constant and every flip is allowed in a nonempty match.
* If $\dim H=2$, the table is a union of cosets of an index-two subgroup. A nonconstant table must be exactly one of its two cosets. Hence $R=\{x:c\cdot x=b\}$ for some nonzero $c$. The flip constraint is one equation $c\cdot g=b'$. Its arity is the number of nonzero coordinates of $c$. Only $c=(1,1,1)$ gives a genuinely ternary condition.
* If $H=\{0\}$, a nonempty match is the single vector $a$, giving three pins. If $H=\{0,h\}$ with $h\ne 0$, pin every coordinate outside the support of $h$ to its value in $a$. Choose any $j$ in that support. For each other $i$ in the support impose $g_i+g_j=a_i+a_j$. These permit exactly $a$ and $a+h$.

For a genuine ternary parity constraint, all binary projections are full although half the ternary rows are forbidden. This proves the exception is necessary. At the other extreme, an ordinary three-literal clause excludes just one row. Matching two such clauses specifies all three flips uniquely. When matched as *individual clauses*, inconsistency therefore means that two literal occurrences require opposite flips of the same variable. If clauses on a scope can be exchanged as a block, their conjunction can instead be a full parity table. Four ordinary clauses realize exactly this situation.

For the nonexceptional systems, build one signed edge for each required binary XOR. Encode a pin by an edge to a common zero vertex. Traverse each component, assigning potentials by XOR along the search tree, and check every edge. If a component containing the zero vertex is consistent, its potentials can be jointly complemented to give that vertex value zero. Thus a violated signed cycle, or equivalently an inconsistent path between pins, characterizes failure. The total work is $O(\#\text{variables}+\#\text{scopes})$ word operations on indexed scopes. For all ternary tables, including the exceptional ones, the matching problem is still an affine linear system. Generic elimination handles those remaining systems; the signed-graph argument concerns the sharper bound and the pebble width. [Harary, balance theorem for signed graphs](https://doi.org/10.1307/mmj/1028989917)

## Exactly three pebbles

Consider the existential homomorphism game from the match instance to the Boolean template of its allowed tables. Each source variable receives one Boolean image while pebbled. A failure is visible when all points of a source relation tuple are held and their images violate its table. Duplicator sees Spoiler's moves and may choose new bits after points are forgotten. The following strategy uses the original ternary relations even when their binary projections are absent from the vocabulary. [Kolaitis–Vardi, *A Game-Theoretic Approach to Constraint Satisfaction*](https://new.aaai.org/Papers/AAAI/2000/AAAI00-027.pdf)

For a contradictory cycle retain its starting vertex and walk around the cycle, holding the current and next vertices. If their chosen bits violate a required binary XOR, release the start when it is separate and pebble the third coordinate of that edge's original scope. No response completes the tuple. Otherwise the next bit has the predicted value and the previous vertex can be released. On returning to the starting vertex an inconsistent cycle forces a violation. A path between pins starts with the required bit and compares its predicted last bit with the ending pin. If a pinned bit is wrong, keep that variable and fill the remaining positions of its scope. An empty table can be exposed directly. Identifications among repeated coordinates can only reduce the number of distinct points needed. For individually matched clauses, pebbling the variable with opposite requirements and then the remaining variables of the offending clause wins in at most three placements.

The same three-pebble upper bound holds in the standard *incidence CSP encoding*. Variables map to Boolean values and each constraint point maps to an allowed local tuple of its type, with named incidence ports requiring the corresponding bit. Keeping a cycle anchor and the current variable, pebble the constraint point. Its chosen tuple must agree at the current variable. Release the current variable if separate from the anchor and pebble the next variable, whose bit must agree with the same tuple. This carries the required parity along the path. A final constraint incident to both held endpoints checks both bits directly. Pins are tested using their constraint point.

For tightness, take $R=\mathbb F_2^3\setminus\{000,111\}$, the not-all-equal table, and $S=R+(0,1,0)$. The allowed flip tuples are $(0,1,0)$ and $(1,0,1)$. Put this same table pair on three scopes $(u_i,u_{i+1},w_i)$ with indices cyclic modulo three and distinct private $w_i$. Consecutive $u_i$ must differ around a triangle, an impossibility. Two pebbles never expose a complete tuple in the variable-only game. In the incidence game, with just one point retained, every Boolean value at one endpoint extends to a legal tuple at an adjacent constraint, and conversely every legal tuple has a compatible value at each of its endpoints. A nonincident second point is unconstrained. This gives Duplicator a two-pebble strategy. Both $R$ and $S$ depend on all three coordinates.

## How many parity scopes does a high-width twist need?

Suppose a set of $t$ variables meets every exceptional parity scope. Leave pebbles on those variables throughout the game. Their chosen bits reduce every exceptional equation to pins, binary XORs, or a check of the choices already made. If the original match system is inconsistent, every resulting residual system is inconsistent. The preceding walk uses at most three further pebbles. Its terminal scope checks may also use the pebbles already held on fixed variables. In the incidence game, a pebbled constraint tuple must agree with all its incident fixed variables, which gives the same restriction there. Thus $t+3$ pebbles suffice. If the minimum winning number is $k$, the exceptional scopes have transversal number at least $k-3$. The variables in a maximal collection of disjoint exceptional triples form a transversal, so at least $(k-3)/3$ vertex-disjoint exceptional scopes are necessary.

The conclusion concerns the proposed system of *aligned* variable flips. A bijective game on unaligned lifted structures may also move the base scopes or act inside a multi-clause gadget. Refuting the aligned local-flip strategy provides no general implication about those games, ordinary satisfiability of the tables, or unrestricted SAT time.

The finite audit exhausts all 65,536 ordered truth-table pairs. Exactly 1,726 have a nonempty match, and exactly four escape reconstruction from all their unary pins and binary XORs. These are the two full ternary parity tables paired in all four ways.
