# Charging each program for its running time

**Research journal, 24 November 2026.** Fix one efficient native prefix-universal machine $V$. For a finite word $y$ define
$$
L(y)=\min_{V(p)=y}\{ |p|+\lceil\log_2\max(2,\tau(p))\rceil\},\qquad
W(y)=\sum_{V(p)=y}\frac{2^{-|p|}}{\max(2,\tau(p))}.
$$
Here $p$ is the exact consumed prefix and $\tau$ is the native publication time. $L$ is a prefix version of Levin's Kt complexity. The weight is the finite, halting-output counterpart of the speed prior $S_{Kt}$ studied by Filan, Leike and Hutter, who treat sequence prefixes. [Loss Bounds and Time Complexity for Speed Priors](https://proceedings.mlr.press/v51/filan16.pdf)

If explicit SAT has a deterministic linear-time unrestricted-workspace RAM algorithm, then on this same machine
$$
0\le L(y)+\log_2 W(y)\le O_V(\log_2(|y|+2))\quad\text{for every }y.
$$
Thus just one fixed efficient machine with this gap divided by $\log_2(|y|+2)$ unbounded would rule out linear SAT. Both sides of the comparison refer to ordinary deterministic programs. The sum can be defined without any externally supplied deadline. The logarithmic error here pays in part for writing a long output. No superlogarithmic gap has been established.

## One code for every output length and probability

The previous [bit-query argument](implicit-output-coding.md) imposed a polylogarithmic bound on the surprisal. It admits a uniform tradeoff with that bound removed. For a fixed native sampler $S$, let $D=\lceil-\log_2 P_t^S(y)\rceil$ for a positive-probability word of length $m$. Under linear SAT, a single prefix code of length $D+O(1)$ permits each of these operations:

* Recover any one specified bit or test whether its index is in range in $t(D+\log(2+t))^{O(1)}$ time, for binary indices fitting $O(\log(2+t))$ bits.
* Print the complete word in $t(m+1)(D+\log(2+t))^{O(1)}$ time, including when there is no given short index for it.

The same code bits serve both operations with fixed interpreter headers. They specify neither $t$ nor $D$. There is also an encoder with $t,y$ as explicit input producing such a code in $t(D+\log(2+t))^{O(1)}$ time under the hypothesis.

At epoch $q$ take $s=2^q$ and allow **all** depths $0\le d\le s+5$. Use the first qualifying epoch for each $(y,d)$, as in the [probability coding construction](near-clock-coding.md). At most $2^d$ outputs qualify in a batch because each has mass at least $2^{-d}$. For output capacity $H=s\,\mathrm{poly}(q)$, find a common polynomial-evaluation fingerprint of width $k=2d+\lceil\log_2(H+2)\rceil+2$ injective on the new words. The membership test on the $k$-bit values, projected prefix counts on $8k$ independent copies, and rational subdivision all work as in the bit-query proof. At each prefix the upper estimate for the number of extensions is within a factor $2^{1/k}$. The losses down a path multiply to at most two. Use width $U_{\varnothing}2^{-d-4}$ for the batch and a designated cylinder of width $2^{-d-6}$ for each member. The sum of allocated widths stays at most $1/4$ by charging each threshold to the word's eventual mass. A batch's computations excluding arithmetic on previously accumulated endpoints cost $2^q(q+d+2)^u$ for one fixed $u$. Indeed all the lengths previously polynomial in $q$ are now polynomial in $q+d$, the comparisons of explicit words cost $H\,\mathrm{poly}(k)$, and the number of levels, counting calls, and tuple components is polynomial in $q+d$. Each first-request predicate uses only the previous probability estimates for this same word and threshold.

Ordering the batches by $q$ alone could process exponentially many enormous depths before a later common output's short code. Instead put $r=\lceil\log_2(d+2)\rceil$ and order by $q+ar$ for a fixed sufficiently large integer $a$, breaking ties deterministically. At fixed $d$ earlier epochs still precede later ones. Up to score $J$ the sum of the local running times is at most $2^J\mathrm{poly}(J)$: a bin $(q,r)$ contains at most $2^r$ depths, and $a\ge u+2$ pays for this factor and the polynomial in $d$. There are $O(J^2)$ bins.

The cumulative endpoints need a separate check because fine earlier batches precede coarse ones. Every earlier dyadic endpoint has denominator exponent at most $2^{J/a}+O(1)$. During a descent, the additional product of at most $k$ denominators has $O(k^2)$ bits. The number of batches through $J$, endpoint operations per batch, and total bit cost of rational comparisons, additions and divisions are consequently bounded by $\mathrm{poly}(J)(2^{J/a})^{v}$ for a fixed $v$ independent of $a$. Increase $a$ past $v$. Expensive counting calls receive only their local prefix and batch parameters. They do not read the cumulative rational endpoints. Thus the endpoint work adds at most $2^J\mathrm{poly}(J)$ to the preceding local-work sum. The one-way decoder skips disjoint batches without reading past a later true code, by the earlier cylinder argument.

Take $q=\lceil\log_2 t\rceil$ and $d=D+5$. At most $t$ random bits are read by time $t$, so $d\le 2^q+5$. The lower estimate at $q$ passes and the first eligible batch appears by score $q+a\lceil\log_2(d+2)\rceil$. Its processing therefore fits the claimed bit-query time. Once the field value and batch are known, binary-search the unique output length and compute its bits by separate conditional-existence tests. Each test costs the local batch bound. For encoding, first estimate the probability at the dyadic deadline on the given word and choose the least depth passing that estimate (at most $D+5$). Locate the first eligible epoch, accumulate the preceding batch widths and follow this word's fingerprint to its designated cell. This proves the full tradeoff.

## From a clock to a speed prior

The upper sign $-\log_2 W(y)\le L(y)$ is unconditional by retaining a minimizing program's summand. Write $b=\lceil-\log_2 W(y)\rceil$ and $Q=b+2$. Exact names of running time above $2^Q$ contribute at most $2^{-Q}\le W(y)/4$ by Kraft's inequality. Split the rest by dyadic time, merging times 1 and 2. Some bin ending at $s=2^q$, $1\le q\le Q$, contributes at least $W(y)/(2Q)$. In that bin the reciprocal of the capped runtime is at most $2/s$. Hence $P_s^V(y)/s\ge W(y)/(4Q)$ and
$$
\lceil-\log_2 P_s^V(y)\rceil+q\le b+\log_2(4Q)+1 .
$$
Applying the printing program above, its log time adds $q+O(\log(m+2)+\log(b+2))$ while its length pays only for the surprisal plus a constant. A literal program gives $b\le L(y)\le m+O_V(\log(m+2))$, since it prints in polynomial time in $m+2$. This proves the stated $O(\log(m+2))$ excess.

The same argument works for a fixed sampler different from $V$, replacing $b$ by its own discounted negative log mass and retaining $O(\log(b+2)+\log(m+2))$ overhead. Existing work relates deterministic weak coding for polynomial-time samplers to complexity separations. The unit coefficient of the log running time and the comparison of an exact-output sum with its largest term are the features used here. Priority for this fine-grained implication has not been established. [Hu, Lu and Oliveira](https://drops.dagstuhl.de/storage/00lipics/lipics-vol374-icalp2026/html/LIPIcs.ICALP.2026.110/LIPIcs.ICALP.2026.110.html)

## Public and private random bits

There is also an **unconditional** interpretation of the number $b$ above. Give an efficient native prefix interpreter an additional independent public random tape. Let $B(y)$ be the smallest integer $h$ such that, on at least two thirds of these tapes, there exists some exact program that prints $y$ with length plus log time at most $h$. The program and allocation between length and time may both depend on the tape. One may take a one-way public tape; the reverse simulation below also covers random-bit reads with deferred independent values at new addresses. This is the native prefix version of probabilistic Levin complexity $\mathrm{pKt}$. Public-randomness coding theorems are known; the calculation here records the overhead against one particular discounted sum. [Lu, Oliveira and Zimand](https://arxiv.org/abs/2204.08312) · [Probabilistic Levin complexity, Section 3](https://www.dcs.warwick.ac.uk/~igorcarb/documents/papers/HLO24.pdf)

We have $B(y)=b+O(\log(b+2))$ without a SAT hypothesis. For $B(y)=h$, among the at most $h+1$ possibilities for the log time of a successful witness, some $j$ occurs on a fraction at least $2/[3(h+1)]$ of the public tapes, allowing ties. At each such tape the ordinary program stream hits an exact successful witness by $2^j$ with probability at least $2^{-(h-j)}$. A single fixed stream simulator can draw public bits and program bits from the fair stream as requested, caching any reused public bits. Thus the same joint experiment can be carried out on $V$ with a fixed literal header and $2^j\mathrm{poly}(h+2)$ steps. Cached random-address reads can store the at most $2^j$ entries in a trie. The contribution to $W$ gives $b\le h+O(\log(h+2))$.

Conversely take the dyadic time bin $s=2^q$ chosen above and let $D=\lceil-\log_2 P_s^V(y)\rceil$. Use public bits to choose a pairwise independent family of $s$-bit trial strings indexed by the $D+2$-bit words. For example take a random binary Toeplitz matrix of $s$ rows and $D+2$ columns plus an independent $s$-bit offset. Any nonzero index difference exposes $s$ independent diagonal bits, by solving for one new bit in order in each row. The offset yields pairwise-independent uniform trial strings. The expected number of successful trials is at least four, and its variance is no larger than the mean. With probability at least $3/4$ there is a successful index. A program need only contain its own index and self-delimited $q,D$. Generating that trial costs $s\,\mathrm{poly}(D+q+2)$ even by direct binary dot products, as does simulating $V$ to the deadline. Since $D+q\le b+O(\log(b+2))$, the program pays at most $b+O(\log(b+2))$ in length plus log time. The proof constructs a candidate for each index and does not search for a successful trial.

Combining the two inequalities with literal simulation gives
$$
L(y)\le B(y)+O(\log(m+2))
$$
under linear SAT. The same upper bound holds with private randomized Levin complexity on the right: a single program that succeeds on two thirds of its private tapes is one permissible public-tape witness on that same fraction. These are comparisons of costs of individual outputs. They do not give a polynomial-time procedure to evaluate any of these costs. Existing unconditional failures of the ordinary two-time-charge symmetry principle for randomized Levin complexities concern a different inequality. [Hu, Manor and Oliveira](https://eccc.weizmann.ac.il/report/2026/021/)

## Changing the interpreter

A violation of the proposed order of growth would persist on every efficient literal universal interpreter, on the **same words**. This is unconditional. Let $U,V$ be two such interpreters and write $b_U=\lceil-\log W_U(y)\rceil$. Retain the $U$ runs through $2^{b_U+2}$, which contribute at least three quarters of $W_U(y)$. A fixed literal compiler sends their distinct names to distinct exact $V$ names and enlarges each retained time by at most a factor $C(b_U+2)^a$. Therefore $b_V\le b_U+O_{U,V}(\log(b_U+2))$. The reverse comparison gives $|b_U-b_V|=O_{U,V}(\log(b_U+2))$. Simulating an $L_U$-optimal name and then interchanging the interpreters likewise gives $|L_U-L_V|=O_{U,V}(\log(L_U+2))$. Thus the two gaps differ by at most $O_{U,V}(\log(L_U+2))$, since $b_U\le L_U$. In particular this is $O(\log(m+2))$ on all $m$-bit words, and $O(\log\log(n+4))$ on $0^n$ because $L_U(0^n)=O(\log(n+2))$. Changing the interpreter can affect a constant multiplying the target scale, as the [delay construction](native-coding-delays.md) shows.

## Testing the gap on one computable external table

The [oracle schedule](near-clock-coding.md) can be changed so that $L+\log W$ itself grows linearly in the length of a word. On header $h(m)$ for an integer, a fixed oracle sampler draws a uniform $m^2$-bit row address in zone $m$, queries its $m$ output bits and publishes the result by $s_m=\mathrm{poly}(m)$, charging for writing each query address. Use the same oracle for the reference interpreter and the sampler. At a fresh zone $m$ simulate every reference program of length $l<m-1$ through $2^{m-1-l}$ steps, giving zero at previously unspecified queries and retaining all replies on earlier zones. At most $m2^m$ rows can be touched in these simulations since each length contributes at most $2^m$ steps. Choose a nonzero $m$-bit word absent from the simulated outputs. Assign it to all untouched rows in this zone and assign zero to the rows touched there. Future zones are chosen beyond all indices inspected so far; other previously supplied answers persist. As in the earlier construction, choosing first eligible parameters gives one recursive table, using finite work at each stage.

At all selected large lengths the common word $y_m$ has $L(y_m)\ge m-1$. At least half the rows produce it, so literal compilation of the sampler gives $W(y_m)\ge 2^{-|h(m)|-1-O(1)}/\mathrm{poly}(m)$. Consequently $L(y_m)+\log W(y_m)\ge m-O(\log m)$. The difference from the earlier exponential-deadline example matters here: an $m$-bit literal could have lower Levin cost than the log of an exponential sampling time. In the present example the sampler runs in polynomial oracle time. Computing a table entry on an ordinary RAM may cost much more. No such superlogarithmic gap on an ordinary machine has been obtained.

An exact rational experiment checked 4,290 positive speed masses from 2,401 finite publication tables, including 1,472 nonempty discarded tails. It also tested code availability and exact streaming consumption in schedules where 36 successive batches went backwards in their epoch numbers.
