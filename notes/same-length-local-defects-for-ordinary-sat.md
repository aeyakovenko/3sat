# Checking an entire SAT length by local defects

Fix an encoded bit length $n$, divisible by eight, and consider every legal ordinary ASCII DIMACS file of that length whose clauses have three distinct variable names. The stored program may use unrestricted work space and indirect reads and writes. A **slice-correct** candidate finishes within its declared clock and gives the right answer on every such file. The following test for failure needs one guessed $n$-bit file and a constant number of candidate runs. It works even when the error being detected is an incorrect YES on an unsatisfiable file.

## A self-reduction with no extra bytes at the root

For a file $F$, let $m$ be its clause count and let $v_*$ count occurring names greater than 3. If $m<8$ or $v_*=0$, evaluate directly by enumeration on at most 21 variables. Otherwise fix values for original names 1 and 2 and the smallest occurring name greater than 3. Branch on their eight valuations, including values for unused declared names if necessary. For each of the first eight source clauses that has yet to be made true, choose its first true literal in the given order, setting earlier unassigned literals false. Discard an inconsistent choice. Every satisfying assignment follows one surviving branch and each branch has made all eight clauses true. There are at most $8\cdot3^8$ partial assignments. Each further choice satisfies a previously uncovered clause.

Delete the eight clauses. Delete every remaining clause already made true. Discard a branch if any remaining clause is entirely false. In a surviving clause keep the unassigned literals and replace its one or two fixed-false literals, if present, by positive names 1, then 2, as needed. The retained literals have other names. Prepend six fixed proper clauses on variables 1, 2 and 3, one excluding each three-bit valuation with bit 1 or bit 2 set. These clauses force the *new* values of 1 and 2 to zero and leave 3 free. The partial assignment to the *old* variables has already been applied. Thus a branch extends to a source model precisely when the resulting proper file has a model. Conversely a child model supplies all still unassigned original variables and can be combined with the branch choices. The parent's truth is the OR of the children's, with an empty OR false. Every child has at most $m-2$ clauses. The designated pivot disappears and the pins introduce no name above 3, so $v_*$ strictly decreases as well.

Here is the byte accounting. Canonicalize counters and literal numbers to their shortest decimal spellings. A header `p cnf D m` with newline occupies no more than the valid source header, since the declared bound $D\ge3$ is retained and the new count cannot increase. Count an ordinary body row with single spaces, its zero and a final newline. Even the shortest proper row uses eight bytes. Summing those canonical charges over the old rows costs at most the old body length plus one byte, allowing EOF immediately after its last zero. The surviving rows never grow. Replacing a literal by `1` or `2` uses one byte, and all retained signs were already present. The six pins use exactly $6\cdot8+11=59$ bytes, including their eleven minus signs. The eight dropped rows release at least 64 bytes. There is room for the canonical final newline and for padding to exactly $n/8$ bytes by inserting spaces between body tokens. Every child has six pin rows even when the residual list is empty. The argument applies to comment-free files, and to legal optional comments, multiline clauses, tabs, CRLF, redundant leading decimal zeros, duplicate clauses and unused declared variables when the chosen grammar admits them. Removing optional syntax only increases available room. It assumes ordinary token-delimited DIMACS with legal extra body whitespace.

For each branch the work is $O(n)$ on a logarithmic-word RAM using byte operations. Intern normalized positive names with a ten-way digit trie, compare the declared maximum as a digit string, and count occurrences and clauses in machine words. Comparing equal-length names with the header charges the scan to the literal being checked. The declared maximum need never fit a word. Copy its normalized digits to the new header. The least occurring name above 3 can be selected in total linear time by digit length then lexical order. Parse once and reuse the indexed clauses. The number of branches is an absolute constant. Moving to children at another physical length or another guest word width is unnecessary.

## The verification theorem

A clocked row returns YES, NO or timeout. A local defect at $X$ means a timeout there, a wrong base answer, a timeout on a generated child, or an internal Boolean reply unequal to the OR of the Boolean child replies. A timeout on a child can also be certified with that child as root. Every defect implies a genuine clock failure on the listed root or one of its children. If there is no defect anywhere on the slice, induction on $v_*$ proves the row correct everywhere on the slice. Thus failure has a nondeterministic verifier guessing just $X$ and spending $O(n+t(n))$ steps for a fixed candidate with clock $t$. A Boolean inconsistency certifies that the displayed list contains an incorrect answer. Identifying an incorrectly labelled member of that list is a separate computation. Guessing one root per candidate checks failure of an entire explicitly listed $K$-row census. No certificate of unsatisfiability is needed for any individual file.

These times allow a verifier with sufficient fixed logarithmic word-width coefficient to simulate the specified guest coefficient and maintain the verifier's arrays. Mask arithmetic to the guest's width. Each simulation starts with the exact file in fresh memory. Reuse a simulation bank by logging and resetting touched cells in time proportional to writes plus input initialization. For a variable-size menu, charge program preparation and interpreter overhead, or use one fixed machine with an advice argument and a known common clock. For polynomial clocks this puts slice failure in NP with $n$ given in unary, and slice correctness in coNP. The certificate is an ordinary legal binary file of the original size.

**Certifying a verdict from an unknown good row.** Given a proposed answer $b$ to $F$, collect the candidates whose replies on $F$ differ from $b$, including timeouts. Guess and check a defect root for each of these candidates. This succeeds precisely when *either the slice has no correct candidate, or $b$ is the true answer*. If a correct candidate exists, each dissenting row is wrong when $b$ is true, and a correct row dissents when $b$ is false. If all candidates are wrong, every dissenting row has a receipt whichever bit is proposed.

In particular, if $a(n)$ advice bits give a decision algorithm for proper SAT in time $t(n)$, enumerate the $K=2^{a(n)}$ advice strings of a fixed known length. At least one row is slice-correct. Taking $b=\mathrm{NO}$ yields an ordinary **uniform nondeterministic algorithm for proper UNSAT** with at most $(K-1)n$ guessed bits and time $O(K(t(n)+n+a(n)))$ under the stated RAM simulation. Here the verifier rejects immediately if no row agrees with the proposed verdict. With a good row this changes no decision and leaves at most $K-1$ dissenters. Thus one advice bit costs at most one input-sized witness. For constant advice this preserves the time exponent, including $1,2,3$. More generally a batch of $B$ proposed verdicts at this length needs one defect witness for every candidate that disagrees *anywhere* in the batch. Requiring at least one row agreeing on the whole batch gives at most $(K-1)n$ nondeterministic bits and $O(K(B+1)(t(n)+n))$ time for a fixed finite menu. Evaluate adaptive queries from the claimed earlier answers when testing a proposed transcript. The statement establishes an upper bound for this verification problem. It leaves open the existence of the advised or uniform fast SAT algorithms.

## Deterministic batches and necessary cover size

There is also an online deterministic procedure under the same promise that the length has a correct row. At a new query record the surviving rows' answers, retiring timeouts. If two disagree, follow a disagreement down the reduction. At a base the explicit answer identifies a wrong row. Otherwise run both on the children, retiring any row that times out. If the rows disagree on a child, descend to that child. If they agree on every child, their common child OR contradicts one parent's reply, which retires that candidate. A slice-correct row always survives. Return the unanimous surviving root answer. Cache that root's votes across retirements and maintain its two lists of voters. Each retirement costs $O((v+1)(t(n)+n))$ where $v$ is the maximum occurring variable count in a root. A stream of $B$ queries costs $O((KB+K(v+1))(t(n)+n))$ since there are at most $K-1$ retirements at the length. The sum of the distinct decimal-name lengths gives $v=O(n/\log(n+2))$. For constant advice and $B\ge v$, the amortized time per query is $O(t(n)+n)$ even when later queries depend on earlier answers. Switching lengths may change the good row. This bound does not give the same worst-case time for one query.

For this receipt mechanism the optimal number of distinct guessed files is the minimum size of a set intersecting the defect set of every dissenter. It can be $K$ even on one common UNSAT query, with unrestricted finite candidates. Take many pairwise variable-disjoint positive filler clauses on names above 3, followed by all eight clauses excluding every valuation of a last triple on larger names. This root is unsatisfiable. On a genuine branch with the anchors zero, process eight filler rows, and then two per stage after the six pins have been prepended. Choose the first positive literal of each remaining selected filler row true and the designated pivot consistently true. Untouched groups survive. As many distinct reachable vertices as desired lie on this path; every reachable vertex is unsatisfiable. For each of $K$ such vertices $u$, evaluate the finite slice equations with just $u$'s reply clamped to YES. This is a total computable row by the strictly decreasing rank. It predicts YES at the common root and violates exactly the equation or base test at $u$. The $K$ defect sets are disjoint singletons. This finite construction makes no small-code or polynomial-time guarantee for the altered rows. Add the truthful row to obtain a portfolio with a correct candidate.

Defects also have no built-in sampling density. Every child starts its list with the six particular pin rows. Change a truthful Boolean row on any set of files without this prefix. The exact local Boolean defect set is the changed set, since no child has changed. A deliberately delayed but globally correct program gives the same example by timing out on an efficiently recognized set with no such prefix, whenever a truthful baseline fits the deadline with sufficient slack. The single planted exception can be an easy satisfiable file. Thus deciding whether a defect exists on a length has a short certificate; finding a deterministic small hitting set for all bounded RAMs or proving every proposed clock fails still requires another argument.

The Karp–Lipton use of SAT self-reduction, and the use of disagreements between competing provers to find a locally faulty computation, are classical. The encoding above deals explicitly with the tight byte budget for proper clauses. Priority for this exact-length formulation is unestablished.
