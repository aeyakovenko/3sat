# Separate fingerprint challenges can all accept a false RAM computation

A proposed shortening of the explicit RAM-to-3-CNF reduction replaces the permutation network with field fingerprints. One could give the SAT solver a separate formula for each evaluation point and require them all to be satisfiable. There is a fixed deterministic RAM that always rejects for which **every one of those formulas is satisfiable on the same public input**. The legal address-sorted records stay fixed in all challenges. Even when every false chronological table differs from the genuine one at a constant fraction of the reads, the SAT calls can each choose a different false table.

## Model of the proposed replacement

The compiler keeps exact local CPU transitions and checks the address-sorted records for initial values, timestamp order and consistency of reads with previous writes. Its only cross-check between the tables is a summary of the records for a chosen challenge. It can compare a vector of summaries in one call. We require that equal contributions from the distinguished reads imply equality of the total summaries when all other records agree and the two tables list them in different orders. For example, a commutative monoid can combine contributions of individual records depending on their whole timestamp, bank, address, operation and value. Products of shifted encodings in a field and sums of powers qualify. Several field values checked together count toward their **joint** range. Potential auxiliary variables must implement the proposed summary correctly on every table.

The family of read summaries is fixed at the scale, before the public array is chosen. A procedure can use the public input or answers to earlier SAT calls to choose any member of that family. If an input-dependent parameter selects from $P$ additional summary functions, include that factor in the size of the family. A predicate that accesses the full array to generate a different checking rule for each array may have a much larger family. In particular, directly testing each returned word against its known value on this particular program is a valid special-purpose compiler.

Characteristic-polynomial fingerprinting and its use on preexisting streams are classical. The ordinary compiler here must certify the existence of one RAM run. The exact permutation construction shares that entire run, and the earlier local multiset analysis also distinguished verification of two public tables from certification of guessed ones. ## Simultaneous collisions on short, well-separated descriptions

Let $\mathcal X$ be a code of length-$T$ arrays with symbols in a finite alphabet, distinct codewords differing in at least $d$ positions. For challenge $s$ let $f_s(X)$ be the contribution of all designated reads with replies $X$. It may be any function of these replies of range size at most $R_s$. Allow one content tag $g(X)$ of range size $A$ to be fixed before the challenges. For at least
$$
             |\mathcal X|-A\sum_s R_s
$$
codewords $X$, **every** challenge $s$ has some $Y_s\in\mathcal X$ distinct from $X$ with
$$
                  g(Y_s)=g(X),\qquad f_s(Y_s)=f_s(X).
$$
Indeed the pair $(g,f_s)$ isolates at most $A R_s$ codewords in singleton fibers. Take the union of the isolated sets. The unused codewords have the asserted witnesses. The tag can even be set to the honest content tag of the true reads. A tag that verifies an arbitrary relation between the public input and the reads is a different hypothesis. [Common collision in Lean](../lean/FingerprintWitnessOrder.lean)

Choose a prime $q\in[T,2T]$ for $T\ge2$. For $k\le T$ use the evaluations at $0,\ldots,T-1$ of all degree-less-than-$k$ polynomials over $\mathbb F_q$. There are $q^k$ words, all described by $k$ field elements. Two different words differ in at least $T-k+1$ positions by the polynomial root bound. If the challenge count, tag range and individual summary ranges are all polynomial in $T$, a sufficiently large **fixed** $k$ makes $A\sum_s R_s/q^k$ tend to zero. In particular, a uniformly sampled polynomial works simultaneously against all proposed challenges with probability tending to one, and the forged read streams have the same degree bound as the true one.

The threshold is tight to one bit on this code promise. Choose integers $a,c\ge0$ with $a+c\le k$. Take as the content tag the first $a$ evaluation symbols. Let each challenge name the next $c$ symbols. Its read summary reports one mismatch flag for those positions and the last $k-a-c$ symbols among the first $k$ evaluations. The flag uses OR and each designated symbol can be accumulated in its own slot modulo $q$, since each timestamp occurs once. These operations form a commutative monoid with at most $2q^{k-a-c}$ summaries. For every $X$ the challenge naming its genuine middle symbols isolates it within its tag class. Any match has the same first $k$ evaluations, which uniquely determine the polynomial. The product of tag range, number of challenges and summary range is $2q^k$, against the obstruction below $q^k$. For unrestricted arrays the same construction uses all $T$ symbols. Its resource counts explain which information the summaries must bind; constructing an exact sub-Beneš-size Boolean circuit would still require separate gate and encoding bounds.

## A deterministic rejecting source

The public data give the prime, the number of addresses, and the coefficients of $X$. The program writes $X(j)$ to work address $j$ in ascending order. On a second pass it reads each of these addresses, independently reevaluates $X(j)$ from the public coefficients and counts discrepancies in a register. It accepts only if at least $\lceil T/2\rceil$ reads disagree. It always rejects. Horner evaluation, native modular arithmetic, and a padded comparison give a fixed schedule of memory events, independent of the coefficient and reply values. Coefficients can be reread from immutable public positions. The general program can loop over the advertised coefficient count. At each fixed $k$ the machine uses $O(T)$ steps and $O(1)$ live controller words. The address and value fields fit a constant number of logarithmic words. If word width is fixed from the physical input length $n$ and $T$ is polynomial in $n$, supply an inert input padding of length $n$ with the $O(k\log T)$ active data bits. Thus the large array need never appear in the initial public data.

Fix a codeword $X$ with the simultaneous collision property. For challenge $s$ give the CPU the false replies $Y_s(j)$ in the second pass. These transitions are internally legal, and the CPU accepts when $T-k+1\ge\lceil T/2\rceil$. In the address-sorted memory table retain the genuine writes and reads of $X(j)$ everywhere. All timestamps and addresses in both tables are the correct ones. The designated memory-read payloads are the sole disagreement between the two record multisets. All genuine input reads, writes and other memory events give the same contributions, and $f_s(Y_s)=f_s(X)$ supplies the required consistency of summaries. Thus the ordinary formula for this challenge has a satisfying assignment. The same public input and the same honest content tag work for every challenge, even when the challenger adaptively chooses which separate formulas to submit.

For example, encode every complete record injectively in a field of polynomial size much larger than $T$ and take the product of the challenge minus the records. On any one fixed unequal pair of these timestamped record multisets the characteristic polynomials differ, so an independent challenge catches the error except with probability $O(T)/|\mathbb F|$ for fixed $k$. Yet all field points separately have accepting SAT witnesses. The order of choices is decisive. Insisting on the same two tables throughout permits ordinary exact checks or an interactive test making a fresh challenge after the tables are fixed.

A bound on false histories can rescue the separate-query method. Suppose on a genuinely negative instance the locally legal accepting charts produce at most $B$ **distinct** nonzero discrepancy polynomials, all of degree at most $D$. Their root sets together contain at most $BD$ points. If the field is large enough, the conjunction of separate SAT answers at any $BD+1$ distinct points is exact. A uniformly random point has false-acceptance probability at most $BD/|\mathbb F|$ even when the SAT witness is chosen after that point is announced. On genuinely positive inputs a single true history works everywhere. Only the number of distinct discrepancies needs bounding. The total number of descriptions, the maximal degree alone, and the gap for a fixed false history give different information. The cost of enumerating the points and of each SAT call must still fit the diagonal budget.

## The two pins of the actual hard computation

For any fixed polynomial bounds on the ranges and challenge count, one may incorporate the obstruction in the [priority-pinned SAT pair](priority-pinned-sat.md) itself. Use its original native bit $b_j$, computed through its padded fixed clock $O(M)$ for $M=2^j$. Retain that bit, then run the two-pass check on $T=M$ addresses in a fresh work bank. The source nondeterministically supplies $q\in[M,2M]$ and $k$ modular coefficients; fixed $k$ is chosen from the range exponents. Its output is $b_j$ XOR the flag that at least $M/2$ replies differed. Range-check all parameters and give malformed choices the original output. Nonprime moduli may be allowed because the two passes agree for **every** genuine choice. At least one prime in the interval supplies the code used in the collision proof. The coefficient count is fixed, so the chosen words can stay in the finite controller and the added time is $O(M)$.

All genuine final outputs equal $b_j$ on every branch. The ordinary exact compiler therefore gives another pair of $\Theta(M\log^3 M)$-bit 3-CNFs with a single changed output pin and exactly one satisfiable member. Every promised deterministic solver with scale and pin still takes $\Omega(M)$ on both at every late scale: each packed formula word can be generated from the scale and pin by the original local compiler, and each observed decision signals its corresponding true priority color. This uses the existing deterministic color-test theorem even though the compiled native computation admits auxiliary guesses.

Apply the proposed summary replacement to these same runs. Give the true pin the genuine chart. On the opposite pin keep the entire genuine priority prefix, and choose the prime and polynomial coefficients in the tail with the common-collision property. The earlier padded clock fixes the times of the designated reads. The single address-sorted chart keeps its genuine values. The false chronological tail can now raise the mismatch flag separately for each challenge and flip the output to the opposite pin. Other memory records are unchanged. Thus the per-challenge formulas all answer SAT on **both** pins of this augmented hard family at every sufficiently large scale. The library may include both pins' fixed functions in its challenge count. The choice of coefficients takes place inside the bounded source, so there is no nonuniform advice to the promised solver or its formula generator. This construction addresses a generic memory-consistency compiler. Recognizing and deleting this semantically redundant tail would undo the obstruction for this source.

The finite audit uses $q=7$, $T=6$, $k=4$ and read-record encodings $7j+v$ in $\mathbb F_{43}$. All 2,401 public rows have a distinct equal-fingerprint row at every one of the 43 evaluation points. For one public row the audit used 29 different alternatives, each differing at three or more addresses. Every fixed alternative fails at least 38 evaluation points. [Finite experiment](../audits/fingerprint_witness_order_audit.py)

This example rules out replacing the routing network by these independently queried short summaries, including polynomially many field challenges on low-degree read streams. It leaves open a smaller single Boolean certificate for exact permutation and the unrestricted SAT time lower bounds. The rejecting source has a trivial dedicated decider. Historical priority for this particular short-input obstruction has not been established.
