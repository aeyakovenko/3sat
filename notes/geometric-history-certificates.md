# One ordinary SAT query for histories described by rectangles and XOR diagonals

There is a deterministic checker for the following description of a long word-RAM computation. It tests every local constraint in its memory-routing tableau without expanding the tableau. On the hard signed computation of scale $M$, a description of charged size $s(1+h)$ gives an ordinary 3-CNF of $s(1+h)\operatorname{polylog}M$ **encoded bits**, up to an additive polylogarithm. For certain dyadic rectangles the factor $1+h$ can be dropped. This is an exact alternative to the $O(M\log^3 M)$ full-history encoding **when** the computation admits the smaller description. For a fixed cap, soundness holds on every input. A true verdict with no chart under the cap gives an unsatisfiable output too. The existence of suitably small descriptions for a useful implementation of the priority computation is unresolved. [Hard signed computation](priority-pinned-sat.md) · [Full-history encoding](packed-band-transfer.md)

## The representation

Round the native row bound up to $B^2$ for $B=2^m$, using inert steps and dummies. Split the binary row index into high and low halves, $t=Bx+y$, with $0\le x,y<B$. There are separate Boolean tables for bits of native configurations, access records, and intermediate verification gates. A description of a bit table consists of

- A fixed-arity Boolean function of affine forms in the bits of $x$ and $y$ over $\mathbb F_2$. Every form may involve both halves. The arity has a fixed bound independent of the clock, and the form coefficients and Boolean function are part of the description.
- A list of half-open axis-parallel rectangles on which to flip that bit.
- A list of triples $(d,l,r)$ on which to flip the bit at points $l\le x<r$, $y=x\mathbin{\mathrm{xor}}d$. We call each full graph for a particular $d$ a track. At a point covered several times, use the parity of its flips.

Let $s$ be the total size in logarithmic-width words of these descriptions, including their headers and one unit for an empty description. Let $h$ be the maximum number of distinct track offsets in any one table. Individual tables can choose different offsets. The graph $x=y$ already has full rank $B$ over $\mathbb F_2$ and costs one track. The model also permits unrelated row and column runs. A row with a constant bit on an interval is a rectangle of height one, and a column interval uses width one.

## Counting all violations without enumerating the cells

Start with any fixed Boolean constraint on constantly many bits at the same point. Ignore tracks temporarily. Each affine input form is a sum of an $x$-form, a $y$-form and a constant. Collect all forms of the participating channels; their number is constant. Sweep the rectangle start and end coordinates on the $x$ axis. Between adjacent endpoints the active rectangles flip fixed bit masks on specified $y$ intervals. Use a segment tree on the sorted distinct $y$ endpoints. At a node store a histogram indexed by the values of the $y$-forms and by the mask of currently active rectangle flips. Initially the masks are zero. A range flip permutes the histogram bins by XOR of its mask. Merge children by adding their counts. Lazy range updates and reading the root cost $O(\log(s+2))$ operations per event. Process all events at a common endpoint before evaluating its next half-open slab.

For the $x$ interval of that slab compute the histogram of $x$-form values. Combining this with the root histogram counts every point violating the constraint in the slab, even for a nonlinear fixed Boolean function of the forms. Histograms on a one-dimensional integer interval require no scan of the integers. Partition the interval into $O(m+1)$ aligned dyadic pieces. On each, fix its high bits and solve the affine equations for each of the constantly many requested form-value tuples. An inconsistent system contributes zero and a consistent one contributes two to the power of its nullity. Independent fixed-bit restrictions on $x$ and $y$ can be included in these systems. All counts through the whole grid have $O(m+1)$ bits.

Now handle the union of the tracks in this constraint, at most a constant times $h$. For one offset $d$ substitute $y=x\mathbin{\mathrm{xor}}d$. An axis-parallel rectangle pulls back to the intersection of its $x$ interval with the inverse image of its $y$ interval. This image is a union of $O(m+1)$ dyadic pieces because XOR by a constant permutes fixed-length binary prefixes. All base forms become affine forms on $x$. A one-dimensional endpoint sweep therefore gives both the original violation count on this track and the count with its designated flips applied. Subtract the former and add the latter to the grid total. Distinct offsets define disjoint graphs, so there is no overlap correction between tracks. This works for multiple coincident fragments, erasable by parity, and for any assignment claimed by a dishonest prover.

One same-point test takes $(1+s)(1+h)\operatorname{poly}(m+1)$ word operations provided the descriptions have polynomially many bits in $B$. A nonzero count means the claimed constraint is false somewhere. [Checked counting identities](../lean/GeometricHistory.lean) · [Executable sweep comparison](../audits/rectangular_history_audit.py)

## Local wiring of a real computation

Use a fixed finite word instruction basis with polynomial-in-width Boolean transition templates. Introduce their gate outputs as separate bit tables so each constraint uses constant arity. Include rows for the instruction state, data, actual memory request and response, and their inter-step consistency. A fixed microstep normalization handles multiple events. For a fully deterministic trace representation, route its records through a fixed Batcher bitonic sorting circuit over address and timestamp with unique event order and prescribed padding. Each comparator has a polynomial-in-$m$ Boolean template and the network has $O(m^2)$ stages. Wire comparison partners at each stage differ by XOR with a fixed single-bit mask. The predetermined order direction can be specified by fixed index bits. At sorted neighbors check that every read receives the preceding value of its address, or zero on its first use. A write starts the new carried value. Check dummies, initial and terminal conditions and the output bit. Thus the routing and all the auxiliary wires are forced by the genuine run once the run has been fixed. This standard local structure also underlies the earlier block-circuit simulation. [Routing and local checks](history.md) · [Jahanjou, Miles and Viola](https://arxiv.org/abs/1311.3171)

Each single-row gate, row-XOR partner and neighbor test can be checked by the sweep. Under a constant XOR translation of either coordinate, the interval part of a rectangle splits into $O((m+1)^2)$ dyadic rectangles. A track remains a track with translated offset and $O(m+1)$ fragments. For $t+1$, divide the index domain by the position of its first zero bit starting at the low end. On each of the $O(m+1)$ cases of the $2m$-bit index, increment is a fixed XOR translation and the case is a conjunction of fixed bits, separately on $x,y$. Exclude the final index for a nonwrapping adjacency check. Handle the last state separately. Tests with $t-1$ can be reindexed to use the forward neighbor, or split by trailing zeros. The number of test types and tables, and the maximum multiplicity of an input description across test types, are all polynomial in $m+1$. This explains the polylogarithmic factor in the total bound.

The source here has a locally generated, short-parameter input. For the pinned priority program use its implicit zero input. For a measured solver on $F_{j,d}$ use the fixed deterministic program simulating it with the local word generator for that formula, including template preparation and word-width normalization as ordinary instructions. It has a polynomial horizon whenever the measured run does. Its public data have $O(\log M)$ bits plus fixed program text. This convention avoids assuming that an arbitrary large public input already has a geometric description. Correctness of the asserted final sign is checked by the same tableau as everything else.

## Compiling the chart itself and deriving a lower bound

Fix a polynomial clock in $M=2^j$ and a public cap $K$ on $s(1+h)$. A nondeterministic native program guesses the descriptions and applies the deterministic checker above. It rejects excessive counts during parsing before allocating or iterating on them, checks endpoints, offsets, feature arities, fields, and the product cap, and enforces an overall clock. It accepts iff some legal description within the cap proves the claimed output. For $M^\delta\le K\le M^C$ with fixed $\delta,C>0$, the checker clock is $(K+1)(j+1)^{O(1)}$, also on bad guesses. Its words and addresses use $O(j+1)$ bits. The ordinary packed compiler gives one explicit 3-CNF with at most $(K+1)(j+1)^{O(1)}$ bits. A virtual length polynomially related to $K$ sets the appropriate native width. Given $j,K$ and the proposed sign, each packed word of the resulting physical encoding can be obtained at constant word cost after polynomial-in-$j$ setup. Only the short checker and its uniform bounds are compiled. The old full trace is never put in this new formula. [Compiler details](packed-band-transfer.md)

Suppose ordinary SAT on a logarithmic-word RAM with unrestricted workspace takes $O(N^k)$ time on $N$ input bits, for $k\in\{1,2,3\}$. For the fixed deterministic priority program there is a constant $A$ such that, at **every sufficiently large** $j$, every chart of its genuine normalized run has
$$
   s(1+h)\ \ge\ M^{1/k}/(j+1)^A.
$$
Indeed set $K$ to a constructible rounded power of two within a constant factor of $M^{1/k}/(j+1)^A$. For large $A$ the assumed SAT algorithm on the new formula, including local simulation, would finish in $o(M)$; the starting cap still exceeds $M^{1/(2k)}$ eventually. A YES answer certifies the specified sign. At false scales the formula is unsatisfiable regardless of whether the true trace is compressible. The pinned detector theorem forbids such a sound fast signal at infinitely many scales, separately for the two signs. The normalized trace may use a constant-factor larger polynomial clock. [Native detector theorem and fixed-width simulation](priority-pinned-sat.md)

There is also an unconditional statement about the individual compressed formulas. Fix any globally correct deterministic SAT algorithm $D_0$ and a polynomial cap range $[M^\delta,M^C]$. At every sufficiently late scale, on **each satisfiable** dyadic-cap formula in this range for either signed claim, $D_0$ takes $\Omega_{D_0}(M/(j+1))$ native steps. A deterministic color detector runs all $O(j+1)$ cap queries in round-robin order and signals on the first YES. Each query has its own work bank and polynomial-in-$j$ template setup. The fixed native interpreter and its optional $o(M)$ initialization are as in the pinned theorem. A single query finishing in $t$ steps with YES makes this detector signal within $O((j+1)t)+o(M)$ steps. Soundness on an incorrect color and the detector theorem give the lower bound simultaneously for all caps. On any fixed cap schedule computable in $o(M)$ time, running only that query improves the bound to $\Omega_{D_0}(M)$ whenever its formula is satisfiable. The lengths of the smallest such formulas are governed by the actual chart costs.

The same lower bound applies to the genuine extended runs of **any** fixed correct solver on **both** pinned formulas at all sufficiently large scales where it finishes within a specified polynomial clock. Use the simulator above, once per pin and output sign. Correctness of a sign for either pin determines the corresponding priority bit. Constants may depend on the solver, clock and reference SAT algorithm. The tables include internal Boolean and routing gates. If $e$ individual table entries differ from a putative chart, adding $e$ unit rectangles repairs those entries without increasing $h$, apart from constant per-entry encoding. Thus the same bound holds up to constants for $(1+s+e)(1+h)$ on approximations too. The [sheared-coordinate variant](sheared-history-charts.md) proves the corresponding bound on $s$ alone for its subclass, with arbitrarily many offsets.

This gives a sufficient test for the original goal. For $k=2$ or $3$, one fixed sound computation of a pinned sign with charts of cost $O(M^{1/k-\epsilon})$ at infinitely many true scales, for any fixed $\epsilon>0$, would contradict an $O(N^k)$ solver. The generic chart checker is unconditional. Its smallness on the required instances is an additional mathematical claim.

## An explicit failure of universal chart compression

Even a trivial zero-input computation can generate a table requiring nearly the full grid. For $B=2^m$ put $b=B/2$. On odd-odd coordinates set
$$
 F(2u+1,2v+1)=\langle u,v\rangle\bmod 2
 \quad (0\le u,v<b)
$$
and set the other entries to zero. This is a constant-description output stream: tabulate parity of all words below $b$ by the even/odd recurrence, then enumerate the cells, masking $u$ with $v$ and indexing that parity table. It takes $O(B^2)$ ordinary RAM steps. The claim concerns the table of emitted bits on its designated row axis.

Form the mixed difference over $\mathbb F_2$, taking the XOR of the four cells at $(x,y),(x-1,y),(x,y-1),(x-1,y-1)$ with cyclic endpoint convention. On odd-odd cells the mixed difference of $F$ is exactly the $b$-by-$b$ inner-product matrix. On the sampled cells the low-bit $2$-by-$2$ blocks are disjoint. A rectangle contributes at most four nonzero block parities: each of its two axis intervals can split at most two adjacent pairs. A given track intersects a block in either no points or two points, one in each row. For the block with high coordinates $(u,v)$ it can intersect only if $v=u\mathbin{\mathrm{xor}}\lfloor d/2\rfloor$. A fragment has odd intersection only if its supporting interval splits the pair $2u,2u+1$, which happens for at most two values of $u$. Thus **one fragment affects at most two sampled cells**, regardless of its length or offset. A point error affects only one sampled cell. [Finite block identities](../lean/DominoHistory.lean)

If the fixed feature budget is $c$, the mixed difference of the base alone on odd-odd cells has at most $2^{2c}$ distinct rows: only the row features at $2u+1$ and $2u$ are needed to determine a row, even if the one-axis feature functions were arbitrary. Distinct inner-product rows differ on $b/2$ columns. If the same predicted row is used for a group of $a\ge2$ rows, summing triangle inequalities over pairs shows that this group incurs at least $ab/4$ mismatches. At most $2^{2c}$ rows can be in singleton groups. For $r$ rectangles, $f$ total track fragments and $e$ wrong entries this gives the unweighted inequality
$$
    4r+2f+e\ \ge\ (b-2^{2c})b/4.
$$
Thus even an approximation on all but $o(B^2)$ entries needs $\Omega(B^2)$ terms. Full-length tracks alone contribute zero to the sampled block parities.

## Testing the obstruction on the same hard signed bit

The obstruction can be put in a real working-memory load of a linear-time implementation of the pinned program. Its answer stays $b_j$ and a single uncorrected fault in any designated load bit changes the final answer. The time alignment below ensures the lower bound applies to an actual native clock column, even when other instructions intervene between loads.

Write $D=2^{\lfloor j/2\rfloor}$, so $D^2\le M<4D^2$. Choose a fixed power of two $R>1$ large enough to execute and pad the loop bodies below in exactly $R$ primitive instructions per slot. Choose a sufficiently large fixed power of two $L$ divisible by $R$ and use prescribed square horizon $B^2$, $B=LD$. The machine receives the native scale as in the pinned program. Constant setup uses shifts to obtain these powers. Choose $R$ with room for the fixed setup offset and the position of the load inside a slot. In a separate bank, tabulate the parity of integers below $D$ in the first $B$ instructions after setup, using $B/R\ge D$ equal slots. The even/odd recurrence reads one older value per entry. The zero entry is initialized explicitly. Extra slots can be padded or compute redundant entries. Counted loops have fixed-length padded bodies including their control transfers.

The next phase has $RD$ groups, each of $B/R$ equal slots. Number groups by $X$ and slots within them by $J$. Let $i=\lfloor X/R\rfloor$ and $z=J\bmod D$. In each slot make the same single parity-table load. Its address is $(i\mathbin{\mathrm{shr}}1)\mathbin{\mathrm{and}}(z\mathbin{\mathrm{shr}}1)$ when $i,z$ are both odd, and zero otherwise. A mask implements this choice. XOR the reply into an accumulator only when $X\bmod R=0$ and $J<D$, using a mask again. These tests and loop counters can also use one flat slot index and fixed shifts. The designated replies, one for each $0\le i,z<D$, equal $F(i,z)$ for the side-$D$ instance above. Their parity is zero for all sufficiently large $D$: every nonzero inner-product row has $D/4$ ones, an even number. Run the unchanged pinned computation in its own bank, XOR its output with the accumulator, and return it. Finitely many small scales can be handled directly. The total clock, including this $RDB$-step phase and the original $O(M)$ steps, fits $B^2$ by choosing $L$ large enough. All other slots and later addresses are independent of the values of the designated replies until the final XOR.

In the prescribed row grid each designated load occurs at coordinates $(Ri+1,Rz+c_0)$ for a fixed $0\le c_0<R$: the first table used $B$ steps, each group takes $B$ steps, and the startup and load offsets sum to $c_0$. Constant setup instructions separating phases can be included in that offset. If the target column is a destination register after the load, reserve an additional slot instruction for sampling before the register is overwritten. Restrict any chart of this true column to the sampled grid. Coordinate-affine forms stay affine and interval preimages stay intervals. A track either misses the grid by its low bits or becomes an interval fragment on $i\mathbin{\mathrm{xor}}z=\lfloor d/R\rfloor$, since $R$ is a power of two and both low offsets are fixed. No term multiplies. The inequality therefore forces $r+f+e=\Omega(D^2)=\Omega(M)$ on the designated column alone, independently of any SAT hypothesis.

The original pinned implementation and this augmented one compute exactly the same bit. An algebraic verifier could prove the parity identity and skip this phase. The counterexample rules out an inference from the bit's time bound, short input and sensitivity of a monitored read stream to universal chart compression. Establishing a small certificate for a particular sound verdict is still open. The geometric checker and lower bounds have manuscript proofs. Historical priority for their combination has not been established.
