# What one SAT execution must carry across many cuts

A single unsatisfiable input can force a communication lower bound simultaneously for every short description of how to divide its execution into phases. The simulation below charges a working-memory value only when the other participant actually reads the result of its writer. It also accounts for information encoded by **which phase wrote which address**. A linear-word-time solver for ordinary 3-CNF can hide an entire permutation in this second part while sending zero working-memory values across the cuts.

The earlier phase-order theorem bounds $T\log H$ plus the cost of foreign loads and handoffs on equal permutations, and supplies a matching radix sweep. Here $T$ is elapsed time and $H$ is the phase count. This note replaces the elapsed-time term by the information in the writer-phase sets of distinct addresses, allows a previously transmitted version to be reused, and enforces the lower bound on all subsets of private input coordinates on the same diagonal. In particular it gives a tight bound on the number of shared once-written addresses even when each side spends unlimited time in its private memory. [Earlier elapsed-time theorem and radix construction](phase-ordered-zero-reads.md)

## A diagonal of ordinary formulas

Take $a,b\in[q]^s$. Use selectors $z_1,\dots,z_s$, name variables $y_v$ and the clauses
$$
            z_i\longrightarrow y_{a_i},\qquad
            z_i\longrightarrow\neg y_{b_i},\qquad
            \bigvee_{i=1}^s z_i .
$$
The last disjunction uses a public width-three OR chain. The formula is satisfiable precisely when some $a_i\ne b_i$. On a mismatch select just that position and assign its two distinct names as required. On the diagonal every selected position would force one name both ways. Repeated literal positions or fresh-variable padding give ordinary three-literal clauses. Each private clause depends on just its own side. Use an explicit fixed-width layout with the two banks separated, and space private records with public fields if necessary so each varying input word depends on just one coordinate of one bank. With $q=s^{O(1)}$, the encoded bit length is $L=\Theta(s\log s)$ and the physical word width is $w=\Theta(\log s)$. This differs from the split unit-clause predicate, which tests whether any coordinate *agrees*. [Earlier split-unit rank bound](split-unit-batch-rank.md)

Fix an exact deterministic SAT solver. One party simulates it at a time. A public plan specifies at most $H$ consecutive phases and the active party in each phase. It can specify fixed time endpoints or stopping rules that the active simulator can evaluate. The party sends the controller registers and the switch or halt signal at the boundary. Let $\ell$ be the prefix-free length of the plan in a public catalogue, or zero for one fixed plan. In particular, on a polynomial-clock run every hindsight list of $H-1$ chronological cuts costs only $O(wH)$ bits, by spelling out the times. Publicly specified stopping rules can also be used with an unbounded clock. Take $1\le H\le s^{O(1)}$, so a phase identifier fits constantly many words.

Define the following quantities on the **actual** run of the solver under this plan.

* $R$ counts distinct requests for private input words owned by the other party, cached by each requester across all its phases.
* $M$ counts distinct work addresses touched. Call an address shared here if both parties access it and at least one writes it. For each such $u$, let $W_u\subseteq[H]$ be the set of phases that actually store at $u$ and put $d_u=|W_u|$.
* $C$ counts pairs $(u,j)$ for which the final value stored at $u$ during phase $j$ is read in a later phase of the other party before any intervening store there. Repeated reads of that same version count once. Initial zeros, writes that nobody reads, and overwritten values do not count. Every pair has a distinct actual first such load.

There is a certificate protocol accepting exactly the **unsatisfiable** formulas in this family. On each diagonal input it has an accepting transcript of length at most
$$
 O\!\left(\ell+w(H+R+C)+M+
   \sum_{u\ {\rm shared}}\left[\log_2{H\choose d_u}
                         +\log_2(d_u+1)\right]\right).
 \tag{1}
$$
The constant accounts for the fixed controller and the polynomial word and phase bounds. In particular the last two terms are $O(M+D\log_2(2H))$ for $D=\sum_{u\ {\rm shared}}d_u$. There is no bound on the amount of private storage or computation of either simulator. This is a communication certificate, not a fast RAM procedure for discovering the writer phases.

## Certifying the phases that wrote an address

For each touched address prescribe a label. If it was touched by just one side, label it private to that side. Give a cell read by both and never written a read-only-zero label. Every remaining label is a shared cell's exact set of writer phases. A public function on the whole address universe can supply the labels on the used addresses with the bit budget in (1), even if their physical names are spread through all $2^w$ positions.

Here is the elementary covering argument. For each possible address independently, distribute constant probability on each private and zero label and on choosing a shared label. For the latter choose $d\in[0,H]$ with probabilities proportional to $1/(d+1)^2$, then choose a uniform $d$-subset of $[H]$. A specified labeling of $M$ keys is hit with probability at least $2^{-b}$, where $b=O(M)+\sum_{u\ {\rm shared}}(\log_2\binom H{d_u}+2\log_2(d_u+1))$, rounded upward. The number of prescriptions for at most $M$ keys is at most $(1+2^w(3+2^H))^{M+1}$. A collection of $O(2^b(M+1)(w+H+1))$ functions hits all prescriptions with this budget, by the union bound. Fix the first such collection under a public enumeration for each choice of bounds. A certificate gives $M,b$ in a self-delimiting code and an index of a function. Its length is $O(b+\log(w+H+2)+1)$, absorbed in (1). For $M=0$ use no labels. Values of the function away from the used keys are irrelevant. This is static retrieval with free construction and evaluation. [Dietzfelbinger and Pagh on retrieval](https://arxiv.org/abs/0803.3693)

The protocol can use any guessed function safely. A private cell rejects the certificate if the wrong party accesses it. A read-only-zero cell rejects a store. At a shared cell every actual store must have its current phase listed, or the branch rejects. On a read, a write already made by the current simulator in this phase takes priority. Otherwise use the latest listed *strictly earlier* writer phase or the initial zero if there is none. The owner of a listed phase must be able to produce its actual last store to that address during that phase, or the branch rejects. The owner keeps its complete history. When it is the other party, request the address and phase and fetch that value, retaining it in a private cache for the remainder of the protocol under that version key. An extra listed phase can cause rejection or be irrelevant. Omitting an actual store is detected when it occurs. Induction over the prefix shows that on any accepting branch all simulated reads, writes and the verdict are genuine. A certificate that reproduces the true labels incurs precisely the remote requests counted by $R,C$, apart from the phase handoffs. This proves (1). Related information-transfer arguments certify read/write-set disjointness between adjacent time intervals. [Pătraşcu and Demaine](https://erikdemaine.org/papers/DynamicConnectivity_SICOMP/paper.pdf)

## Simultaneous hard choices on the same run

On the $q^s$ diagonal inputs $(x,x)$ an accepting transcript, including its nondeterministic description, can occur for only one $x$. For a fixed certificate the deterministic transcript defines a rectangle. If it accepts both $(x,x)$ and $(y,y)$ for $x\ne y$, it accepts $(x,y)$, whose formula is satisfiable. This is the standard fooling-set argument. Consequently at most $2^k$ diagonal inputs have any accepting binary transcript shorter than $k$. The certificate can pick its plan and its public lookup function separately on each input. Thus one diagonal has no plan making (1) smaller than a constant times $s\log_2q$. The same statement on diagonal pairs of permutations of $[s]$ uses $\log_2(s!)$. Lengths, party changes and request types use self-delimiting messages, and both parties learn the decision bit on the accepting branch. [Fooling sets in communication complexity](https://theory.stanford.edu/~tim/w15/l/l4.pdf)

One can make even the set of private coordinates depend on the hard run. Fix a nonempty $U\subseteq[s]$, $u=|U|$. Give both parties all coordinates outside $U$ as public constants. For each coordinate of $U$ give one party its left input and the other its right input, with the ownership orientation chosen independently for each coordinate. Conditional on fixed outside values and a fixed orientation, a uniform diagonal $x$ still has $q^u$ possibilities. The same rectangle argument bounds the probability of an accepting transcript shorter than $k$ by $2^k/q^u$. Therefore, on **one** diagonal $x$, for every $U$, every orientation, and every admissible plan, the transcript length is at least
$$
 u\log_2q-\log_2 {s\choose u}-u-2\log_2(u+1)-3 .
$$
Indeed, take a union over the $\binom su 2^u$ choices at each size and sum $2^{-3}(u+1)^{-2}$ over sizes, allowing for integer rounding. The public outside values can vary with $x$ because the conditional probability bound is uniform in them. With $q=s^4$ this gives $\Omega(u\log s)$ simultaneously even for singleton subsets at large $s$. Equation (1) then bounds every such division on the *same native run*. A sparse range of name identifiers suffices. Alternatively represent each alphabet symbol by four base-$s$ digits and apply the discrepancy encoding to all $4s$ positions, choosing the same owner for all four digits of a coordinate. This uses $O(s)$ dense identifiers and the same encoded bit length. These are simultaneous constraints on phase partitions. Adding their right-hand sides across overlapping partitions would charge a physical instruction repeatedly.

**A cut consequence for actual written values.** On this one hard diagonal, partition a polynomial-time run into $H$ consecutive time blocks in hindsight and give each block either color. Suppose $u$ row pairs have all occurrences read from one wing in Alice-colored blocks and all occurrences read from their other wing in Bob-colored blocks, allowing the wing assignment to change from row to row. Choose just these pairs for $U$, in these orientations. Then $R=0$. Sending the endpoints and colors costs $O(wH)$ bits. Thus
$$
       Cw+M+D\log_2(2H)+wH=\Omega(u\log s),
$$
where the implicit constants may depend on the fixed machine. This holds for *every* such partition and coloring on the same genuine execution. For two blocks $D\le 2M$. If the run takes $O(s)$ word steps and a cut separates $\Theta(s)$ pairs, it forces $\Theta(s)$ distinct previously stored values from the earlier block to be read in the later block. Default zeros and immutable words contribute nothing to $C$. More generally $T=O(s)$ gives $M,D=O(s)$, so the conclusion for linearly many separated pairs persists whenever $\log(2H)=o(\log s)$. The statement permits a solver that compares corresponding input rows immediately and has no temporal cut separating linearly many pairs.

## Charging only nonzero values

One can also transmit only genuinely **nonzero** cross-phase values. Let $d_u^+$ count phases whose last store to shared address $u$ exists and writes a nonzero word. Let $E$ count transitions of a shared word from nonzero at the start of a phase to zero at its end, and let $C_+$ restrict $C$ to nonzero values. In (1) one can use $d_u^+$ in place of $d_u$ and $C_++E$ in place of $C$.

Use the same sparse retrieval construction for masks of positive writer phases. Explicitly advertise the address and phase of every transition counted by $E$. The named owner must check at phase end that it actually stored a final zero at that address, even if nobody queried it. Forbid two conflicting announcements for one key and phase. Every actual nonzero final store must have its phase in the positive mask. If a phase's final store to a key is zero while the latest strictly preceding announcement for it is positive, the current phase must advertise a clear. These checks concern actual stores known to their owners, plus every explicitly claimed clear. They apply before a certificate is accepted.

A read with no current-phase store consults the latest earlier announcement. A clear or empty history yields zero for free. A positive announcement requires an actual final nonzero store in that phase, checked on retrieval. These rules cannot suppress a real nonzero value: its write must be announced and a subsequent announced clear must be an actual zero store. Nor can a valid positive lookup return an obsolete nonzero value. A later nonzero final store must be flagged, and a later zero store from declared positive state must advertise a clear. A spurious positive flag with no store cannot pass a retrieval. The true masks and the true list of clears pass all checks. They incur nonlocal value requests only for $C_+$. Multiple reads use the same cached version. Local intermediate writes within a phase are handled by the active party.

The distinction matters at only **three phases**. Bob first stores one at keys $(i,b_i)$, Alice stores zero at keys $(i,a_i)$, and Bob reads his original keys. All replies are zero exactly when the lists agree. The program can check its private formula fields on these passes and use a general solver on a layout failure. On *every* equal pair all $s$ cross-phase values read are zero, $M=O(s)$, $H=3$, $C_+=R=0$ and $E=s$. The formulas still have $s\log q$ bits of diagonal fooling-set entropy. So the bound with positive support and no clear charge would be false, even for this constant number of phases and $O(s)$ elapsed steps.

Every physical work word in the journal's constant-factor normalization of a hypothetical $O(L^k)$ solver is numerically nondecreasing, for each $k\in\{1,2,3\}$. Therefore $E=0$ for every partition of every run of those equivalent solvers. In this normal form the bound charges only genuine nonzero cross versions and the writer-phase description in addition to private input requests and controller handoffs. The size of the latter description can still reach the whole input entropy on a word-write-once computation. [Unrestricted constant-factor normalization](normalizing-stores-in-a-sat-solver.md)

## Distinct shared cells with unlimited private computation

Suppose public address regions are designated private to their respective parties. Their sizes are unrestricted. A verifier can use the public owner as the private label without receiving any description of these addresses and can reject an access in the wrong phase. Therefore the $M$ term need only count the $S$ distinct addresses touched in the remaining common arena on a run respecting this assignment. Even if the RAM permits unrestricted rewriting, on a particular run where every such address has stores in at most one phase, all its mask labels cost $O(S\log(2H))$ bits. The run may still write arbitrarily often inside that one phase. This gives
$$
  \ell+(H+R+C)w+S\log(2H)=\Omega(u\log s)
$$
on the hard full-function diagonal with $q=s^4$, and with right side $\Omega(\log(s!))$ on some hard permutation diagonal. For publicly defined phases this can apply regardless of elapsed time. In particular, when $R=C=0$ and $H=o(s)$, some permutation diagonal needs $\Omega(s\log s/\log(2H))$ distinct shared addresses, even with unlimited private work and private storage, if all the runs in question have the specified shared writer restriction. If the property is asserted only of an individual hard diagonal, the same implication applies there. For arbitrary writer-phase sets the bound $O(SH)$ on their total encoding is available instead. A known partition of physical memory is one sufficient reason the private addresses can be omitted. With unknown owners there is a cost for describing or checking them.

## A permutation carried by zero reads

The earlier radix sweep used both orientations of a digit test on each entry and applies to arbitrary functions. The following one-sided variant uses digits of the *positions* of symbols in permutations. It exhibits the matching shared-address count directly. The factor $\log(2H)$ in the coarser writer-phase accounting cannot be replaced in general by a constant. Consider the discrepancy formulas above with $q=s$ on two permutations. Let $s=2^k$, choose $1\le j\le k$, put $B=2^j$ and $d=\lceil k/j\rceil$. Give each position $i$ its public, distinct $d$-digit base-$B$ code, using zero high bits in the top digit. Write $\operatorname{pos}_a(v)$ for the position of symbol $v$ in the first permutation and likewise for the second.

For each successive digit value $e=0,\ldots,B-1$, perform a Bob phase followed by an Alice phase. Bob visits every pair of axis and position $(h,i)$ for which digit $h$ of $i$ equals $e$. For each it reads a work cell named $(h,b_i)$ and accumulates whether any read was nonzero. Alice then visits the same public pairs, storing one in $(h,a_i)$ for each. The cells start at zero. Bob gets a hit exactly when, for some $v,h$, the digit of $\operatorname{pos}_b(v)$ on axis $h$ exceeds the digit of $\operatorname{pos}_a(v)$. If he gets no hit, every digit inequality is in the other direction. For each axis the two digit sums over all symbols are equal, since both inputs are permutations of the positions. Hence every single digit agrees on every symbol. The answer is equality. Conversely equality gives zero on every probe of the shared marks.

These phases take $O(sd)$ RAM steps, $O(sd)$ cells and $H=2B+O(1)$ handoffs/phases up to an additive constant. To enumerate an axis and digit value, vary the lower and higher position bits in loops, skipping nonexisting values on the top axis. There are $O(Bd)$ setup operations in addition to the $sd$ pairs, and $B\le s$. The fixed-width input and array addresses take $O(1)$ work per pair. Each party can validate its local permutation by a private seen table. A globally correct solver checks the formula's public layout and local fields, and uses a general SAT algorithm outside the tested promise. On the diagonal the validation succeeds, neither party needs a foreign input word, and every load from a cell written by the other party on the shared marking bank occurs **before its only store** and returns the initial zero. All loads of previously written work data on this family have local writers. Public loop counters can be regenerated or transmitted in the ordinary controller handoffs.

Each shared address $(h,v)$ is written in exactly one Alice phase. The phase number identifies the digit $h$ of $\operatorname{pos}_a(v)$. Across all axes the labels recover the entire permutation. Here $R=C=0$ and $M,D=\Theta(sd)$. Taking $B\asymp\sqrt{s}$ gives linear word time with $O(\sqrt{s})$ phases. Taking $B$ to grow arbitrarily slowly gives $O(s\log s/\log B)$ word time with only $O(B)$ phases. Whenever $B\to\infty$ and $B=o(s)$, the proposed alternative budget $O(M+D)+O(w(H+R+C))$ is $o(\log_2(s!))$. It therefore cannot simulate this computation as a sound certificate for the diagonal. The genuine interparty values supply none of the missing bits. The phase labels supply them. For $B=o(s)$ the bound also matches (1) in order on this zero-transfer family. At constant $H$, the same lower bound forces $\Omega(s\log s)$ total work on some diagonal if both remote input requests and genuine remote values are excluded. The unrestricted machine can compare corresponding rows directly in $O(s)$ time.
