# Rare private-probe states at many places on one unrestricted SAT run

The [single-block count](private-probe-contexts-in-read-only-sat.md) forces many possible states across runs. Here one fixed truth table is used in many lookups in a single proper 3-CNF. On a typical input of either verdict, almost every lookup block requires many actual reads or reaches a state unusual even among runs of that same verdict. The conclusion applies to arbitrary deterministic SAT solvers with unlimited writable RAM.

Let $t$ grow, $M=2^t$, and $B=M$. The input contains one balanced table $T:\{0,1\}^t\to\{0,1\}$ and $B$ independently supplied selector strings $u_1,\ldots,u_B$. The formula's SAT value is $\bigoplus_i T(u_i)$. Its encoded length can be padded to $n=\Theta(Mt^4)$ bits across all inputs of this order. Exactly one packed input word depends on each selector bit, and these words are all distinct.

Fix block $i$, all other selectors, and $T$. Treat the $t$ changing words as an oracle for their original bits. Count a **probe of block $i$** when the actual machine loads one of these original words before any write to it. Multiple loads of an intact original count separately. After a write, the cell is part of the simulated writable memory even if its new value happens to equal its original. Between probes all reads, writes, CPU work and exits can be replayed with the fixed outside input, the current overlay of writes and the real controller state. The private bit need only be requested when the next genuine probe is reached. There is one such probe per pertinent native word read.

Contract these stretches to a graph with binary query vertices labeled by bit position; its other outcomes are the two verdicts and divergence. As an intrinsic choice of state at a probe, identify equal rooted, bit-labeled continuation trees, including their leaf verdicts. Both next probes and any ensuing public steps are determined once a reply is given. Infinite trees or cycles are allowed; impossible sequences of oracle replies can be given their simulated behavior. Equally, one can use the unmerged contracted states, or any deterministic quotient preserving the labeled successors. All comparisons of states below are within one fixed outside input.

For an integer $d\ge1$ and verdict $z$, define $p_{i,d,z}(s)$ to be the probability that state $s$ is visited among block $i$'s first $d$ genuine probes. The probability is over a fresh uniform $u_i$ conditioned on the same fixed outside input and SAT value $z$. It measures the chance of **ever** visiting that state within the indicated horizon, regardless of ordinal. Its sum over all states is at most $d$.

**Theorem.** At every sufficiently large $t$ one can fix a balanced $T$, independent of both the solver and the probe budget. Put $S=\lfloor M/(1024t^2)\rfloor$ and $a=\lceil M/t\rceil$. For each deterministic correct solver, each verdict $z$, each block $i$, each fixing of the other selectors, and every $d\ge1$, at most a $2a/M$ fraction of the choices of $u_i$ giving $z$ violate the following alternative on their actual run:

* The run makes more than $d$ genuine probes of block $i$.
* Among its first $d$ probes of $i$, it reaches a state satisfying $p_{i,d,z}(s)\le d/S$.

For independent uniform selectors conditioned on $z$, the expected number of exceptional blocks is at most $2aB/M$. By Markov's inequality, with probability at least $1-2a\sqrt t/M$, all but $B/\sqrt t$ blocks satisfy the alternative **on the same run**. No independence among the block events is required.

For example, suppose a solver takes $O(n)$ native steps on this family. Set $d=\lceil t^6\rceil$. Disjointness of the blocks' physical addresses bounds the number of first-alternative blocks by $O(n/d)=O(B/t^2)$. Consequently a $1-o(1)$ fraction of inputs of each verdict contain actual probes at $(1-o(1))B$ different blocks whose conditional state frequencies are $O(t^8/2^t)$. More generally, given a clock $O(n^{2-\delta})$ for fixed $0<\delta\le1$, choose $d=\lceil M^{1-\delta/2}\rceil$. The number of first-alternative blocks is again $o(B)$ and the frequency bound becomes $O(t^2 M^{-\delta/2})$. The chosen rare states occur at different native accesses, but they can be implemented by reusing the same register.

## Choosing one table that works for both verdicts and all blocks

A graph with at most $S$ private query vertices can be padded to $S$. There are at most $t^S(S+3)^{2S+1}$ descriptions, because each vertex has a bit index and two possible successors, and there is an initial choice. This includes cyclic graphs with some inputs never reaching a terminal. The set of inputs reaching a specified verdict is determined by its description.

Sample a balanced $M$-entry table uniformly. For a fixed set of $a$ entries and one color, the probability they all have that color is at most $2^{-a}$ by drawing without replacement. For each graph and either terminal with an acceptance set of size at least $a$, take the first $a$ entries of that set. Union-bound over all graphs, both terminals and both colors. The bad probability is bounded by $4t^S(S+3)^{2S+1}2^{-a}<1$ for all large $t$. Indeed the binary logarithm of the graph count is at most $4St+O(t)\le M/(256t)+O(t)$, whereas $a\ge M/t$. Fix a surviving table. Every set selected by one terminal of a graph of this size and contained in one color of $T$ has size below $a$.

Now fix a block, the other selectors and the target verdict. Call states with $p_{i,d,z}(s)>d/S$ frequent. There are at most $S$ of them. Keep their real edges, redirecting every edge to a discarded query vertex to the opposite verdict $1-z$. Make the analogous change to the starting vertex if necessary. On an input for which the reduced graph reaches $z$, the genuine graph followed the same queries to $z$. Therefore its accepted inputs are all in one color of $T$, since the XOR of the other lookups is fixed. Conversely any true $z$ run using at most $d$ private probes and seeing only frequent states reaches $z$ in the reduced graph. The choice of $T$ bounds their number by $a$. The total number of $u_i$ in this verdict class is exactly $M/2$. This proves the theorem. State pruning is done separately for each block and outside input. The fixed table handles all the resulting graphs at once.

The counting argument uses standard ideas of Nečiporuk's method. Read-once branching programs also have direct-sum theorems for transitional information. Here the number and order of native probes and all intermediate writes are unrestricted; the measured quantity is occurrence probability in a conditional private-probe computation. Priority for this formulation has not been established. [Beame, Grosshans, McKenzie and Segoufin](https://arxiv.org/abs/1608.01932) · [A direct-sum theorem for read-once branching programs](https://doi.org/10.4230/LIPIcs.APPROX-RANDOM.2016.44)

## One shared table in proper DIMACS

Prepare $M$ table rows and $B$ query rows. Each row has a $t$-bit address, a tag and a value. Table row $j$ has public address $j$, tag zero, and value $T(j)$. A query has address $u_i$, tag one, and value zero. Use a bitonic sorting network on $2M$ records with key (address, tag), carrying the value. A compare-and-exchange takes $O(t)$ constant-fan-in gates by lexicographic comparison and conditional swaps. The network has $O(Mt^2)$ comparisons. After sorting, each query follows the unique table row for its address, possibly with other queries between. Scan the rows with two Boolean state bits, retaining the most recent table value and XORing it into the answer on each query; this uses $O(M)$ gates. [Batcher, sorting networks](https://doi.org/10.1145/1468075.1468121)

Give each wire a dense integer name, encode each gate by its truth-table clauses, and pin the final output true. Factor gates into unary and binary gates, simplify repeated literals, and extend shorter clauses with fresh-to-that-clause dummy variables from a public pool forced false by a seven-clause gadget. This preserves unit propagation after the fixed dummy assignment. The fixed circuit has $O(Mt^3)$ clauses with $O(t)$ decimal bytes per variable name. Table and selector variables have exactly one sign pin apiece. Use fixed-size, word-aligned fields for the pins, reserving a space or minus directly before the first decimal digit with the same length either way. A whole field can occupy a fixed constant number of words and have a publicly known offset at each order. Pin references in the rest of the circuit never change with their values. Choose a length $C Mt^4$ (rounded to a byte), compute its logarithmic width, and fill excess space between records or after the last clause. This gives the indicated $n$ and leaves each packed private query dependent on a single bit. Only the table of the counting proof needs a nonconstructive choice; the formula map is uniform on all supplied table and selector data.

## A linear-time control and the remaining obstacle

There is a total SAT decider taking $O(n)$ time on all these files. Read dense small variable names and build the clause occurrence lists. When the seven clauses forcing the public dummy triple false are present, assign those three forced values and perform ordinary unit propagation. Each literal occurrence is inspected only $O(1)$ times since clause width is three. All primary inputs are pinned and the circuit is acyclic, so propagation determines its output or finds a contradiction. If input structure, names, or the residual formula fall outside this fast path, use exhaustive SAT on the original file. Implementation can cap dense arrays and decimal accumulation at a linear-in-length bound and fall back on overflow. On the displayed inputs only $O(Mt^3)$ names and clauses are stored and every scanned byte costs $O(1)$ native steps. The conclusion holds if the input is initially in writable memory by putting the fast-path records in disjoint scratch space. For large selected lengths these records occupy $o(n)$ words and fit in the standard domain.

With the regular pin layout promised, one can access the table pins directly. Accumulate each $u_i$ in the same word, read the single table pin at that offset, XOR it into one parity bit, and reuse the word. This takes $O(Bt)$ native steps for the pin computation and never needs to write a selector-dependent scratch cell. Field offsets can be supplied as public length parameters on this promise. The total SAT algorithm above also covers arbitrary syntax. Thus direct summation upgrades private-state diversity to many genuine state occurrences on individual executions, yet the state information for the different blocks need never be live simultaneously. An unrestricted lower bound still needs to charge persistent or repeatedly recovered information beyond this example.
