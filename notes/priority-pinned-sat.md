# A tight unconditional time bound for a promise family of explicit 3-CNFs

There is a fixed locally generated pair of ordinary 3-CNFs $F_{j,0},F_{j,1}$ for every integer scale $j\ge1$. They have identical lengths $N_j=\Theta(2^j(j+1)^3)$ and differ only in one fixed-position literal sign at that scale. Exactly one member is satisfiable. Even a deterministic logarithmic-word RAM **promised one of these formulas and also given $j$ and its pin $d$ for free** needs
$$
  \Omega_D(N_j/(\log N_j)^3)
$$
steps on **both** members for every sufficiently large $j$, if its answers on the family are always correct. The constant and starting scale may depend on the machine $D$. A fixed promised solver with the metadata matches this time on every member. Both verdicts occur for each fixed pin as the scale varies. For pin one, the number of unsatisfiable scales through $j$ can be bounded by $O(\log\log(j+4))$.

The input has no hidden placement of an exceptional clause. Each packed word is available from $j,d$ and its address in constant time after $\operatorname{poly}(j)$ setup. The lower bound also holds for ordinary globally correct SAT solvers by ignoring the extra information. The bound is below the time to read the whole physical encoding and below the requested linear exclusion. Its content is an almost-everywhere *computational* lower bound even with the two possible presentations, their only difference and the family promise all known. It uses the deterministic bi-immunity method and an explicit packed computation encoding. We have not established priority for this realization. ## Constructing a bit from the scale

Use a native machine with an inert input of $M=2^j$ bits, its length available, and width $12\lceil\log_2(M+2)\rceil$. It will compute $b_j$ from $j$ in $O(M)$ native steps. Enumerate all pairs $(V,c)$ of deterministic normalized programs and requested colors $c\in\{0,1\}$, in a computable length order, with both colors for each program. A program $V$ is given the scale and may signal once. Its physical input at stage $i$ is the canonical zero array of length $2^i$, available virtually. At stage $i$, activate the first
$$
 a_i=\lfloor\log_2(2+\lfloor\log_2(i+4)\rfloor)\rfloor
$$
requirements. A requirement that has won at an earlier stage is retired. In index order, test each active, unretired requirement $e$ for a signal on scale $i$. Give index $e$, starting at zero, a budget $\lfloor 2^i/2^{e+1}\rfloor$ of universal instructions on that stage's machine. If one signals, set $b_i$ to its requested color, retire it and end that stage. If no tested machine signals, set $b_i=1$. Replay stages $1,\ldots,j$ to compute $b_j$. No simulation on stage $i$ depends on future choices of $b$.

One fixed universal interpreter on stage $i$ can fetch instructions from the encoded program and stop after the assigned number of its own operations. For each fixed $V$ its instruction cost per guest step is bounded by a program-dependent constant. One implementation gives the guest a separate sparse bank, implements a fixed-depth radix trie on $12\lceil\log_2(2^i+2)\rceil$ address bits, and chooses digits of $\max(1,\lfloor i/4\rfloor)$ bits. Direct numerical row-and-digit addresses use $O(i)$ bits within the host coefficient, since at most $O(2^i)$ rows are allocated in a trial. An initially unfilled slot is zero and needs no initialization sweep. Use disjoint trials, or clear touched slots in time linear in the executed universal instructions. Enumerating the short active texts, shifting the cap, and other fixed setup cost $\operatorname{poly}(i+1)$ per stage apart from the simulations. Tables of $O(2^{i/4}\operatorname{poly}(i+1))$ size, if used for fixed-limb arithmetic, can be built once per stage. The geometric budgets give $O(2^i)$ total running time at that stage, including setup for all sufficiently large $i$.

For implementation on the final host of width $12\lceil\log_2(2^j+2)\rceil$, each earlier stage word fits in one word. Mask results to the earlier width, implement oversized shifts and zero-divisor conventions explicitly, and distinguish input, simulation and scratch banks. A fixed number of earlier-width limbs deals with intermediate products if needed. The loop can count stage-interpreter ticks independently of its host operations. Word-width constants for any fixed tester can also be normalized using the sparse simulation. Only a bounded number of rows per simulated instruction are needed. Costs of discarding old trials and old stages are charged to their own allocations. Hence $\sum_{i\le j}O(2^i)=O(2^j)$. The encoded priority program has a fixed time coefficient. ## Why both verdicts take time on every late pair

If $V$ is sound for color $c$, it signals only at indices with $b_i=c$. Hardwire any finite exceptional scales as rejections if required. Its requirement asking for color $1-c$ can never win: a signal selected there would assign the opposite color at that very index. After its activation there are only finitely many wins at smaller indices of the requirement list, since each requirement retires permanently. Therefore at **every** sufficiently large scale the opposite-color requirement is tested before any stopping signal. For its fixed index $e$ the budget is a fixed positive fraction of $2^i$ and fixed-program interpretation has constant per-step overhead. Timely signals below some $c_V2^i$, $c_V>0$, consequently cannot occur. There is a quantitative common exception bound. After the first $E$ requirements are active, if any sound tester among them would signal within the budget of its opposite-color requirement of index less than $E$, some higher-priority requirement must win that stage. All such stages, simultaneously for these testers, belong to the list of at most $E$ award stages for the first $E$ indices. The locations of those awards need not be efficiently predictable. At most $a_j$ exceptional zero values can be assigned through scale $j$. Both colors occur infinitely often. Otherwise a program signaling constantly after the last exceptional scale would be sound for the cofinite color and would violate the bound. [Finite-priority lemma in Lean](../lean/DyadicLengthRequirements.lean)

To form the formulas, compile the actual deterministic priority program on the canonical input of length $M$ through $R=C M$ steps for a fixed large enough $C$. Use idle halts through the clock. Permit either halting output and designate one Boolean slot $o$ equal to its final output bit. The computation is total and deterministic, so all satisfying assignments to this unpinned encoding agree on $o=b_j$. Add two fixed fresh variables $Z,W$ pinned false by fixed repeated-literal clauses and a final clause $(L_d\lor Z\lor W)$, where $L_1=o$, $L_0=\neg o$. Exactly this sign changes between the two formulas. Repeat tautologies in the regular template as needed to fix $\Theta(R(\log R)^2)$ clause records with $\Theta(\log R)$ bits per literal name. The virtual binary input length, public words (all zero), clause stride and routing templates are known from $j$ and the fixed program; the compiler supplies constant-time access to each packed formula word after $\operatorname{poly}(j)$ setup. This yields the asserted $N_j$. [Encoding and access proof](packed-band-transfer.md)

For each pair of bits $d,y$, build a tester that simulates $D$ on $F_{j,d}$ with the promise and the advertised metadata. It signals only on observing answer $y$, using $y=1$ for SAT. This signal is sound for the color $d$ if $y=1$, and $1-d$ if $y=0$. The simulated formula word width is $O(j)$ with a fixed program-specific coefficient. Its larger sparse addresses fit the host via a constant number of limbs and fixed-depth radix rows through any $O(M)$-step trial. The local generator uses only the scale, pin, and fixed program text and initializes its templates once. Thus $t$ timely steps of $D$ give a signal within $O_D(t+\operatorname{poly}(j)+M^{1/4}\operatorname{poly}(j))$ steps on scale $j$. The additive work is $o(M)$. Take the minimum of the resulting positive constants, and the maximum of the starting scales, for these four testers. Both physical formulas then cost $\Omega_D(M)$ at every large $j$. The priority program can appear inside a tester's formula generator without recursion during generation: computing a word of the tableau encoding consults fixed transition templates, and never runs the program being encoded.

Conversely the promised algorithm computes $b_j$ directly at cost $O(M)$ and compares it with $d$. Its larger native width on a physical $N_j$-bit input simulates the scale machine at constant overhead. This verifies the matching upper bound on the enriched promise. One globally correct solver can recognize these presentations in $O(N/\log N)$ time. Enumerate the $O(\log N)$ possible scales from the length bound and compute their exact encoding lengths in polynomial-logarithmic time. Only constantly many can match, by the two-sided bound on $N_j$. For each candidate pin compare every packed word against its generator. A match permits direct evaluation of $b_j$, and a failed match for every candidate invokes general SAT. The promise upper bound uses the supplied family information.

## An unconditional limit on short signed proofs

At scale $j$ encode two closed arithmetic sentences $\theta(j,d)$ using a binary numeral for $j$ and a fixed formula defining the run on a dummy array of length $2^j$. Their lengths are $O(\log(j+2))$. In any fixed sound proof calculus with polynomial-time proof checking, the true statement has no proof shorter than $c j$ bits at all sufficiently large $j$, for instance with any fixed $0<c<1$ under binary proof encoding. Otherwise a sound detector for one of the signs could try every such proof and check it in $2^{cj}\operatorname{poly}(j)=o(2^j)$ time at infinitely many scales. Each true finite halting statement is provable in Peano arithmetic.

For sequential proof verification there is a sharper *time* assertion using the published deterministic simulation of a fixed nondeterministic multitape machine through $h$ steps in $2^{O(h/\sqrt{\log h})}\operatorname{poly}(h)$ time. A fixed tape verifier may receive the binary length $2^j$ and an arbitrary length-$2^j$ suffix-bearing input on a separate sequential read-only tape. Fix a program prefix if desired. Suppose the verifier is sound for one color on all these allowed presentations. A fixed nondeterministic multitape machine on the short scale data guesses the needed suffix symbols on first discovery, records them on a tape and reuses them on every revisit. After $h$ steps from the left end it can have visited only $h+1$ positions. For $h=o(2^j)$ they extend to one valid input. An equivalent implementation guesses the entire observable prefix of $O(h)$ bits once, retaining the prescribed initial program prefix. Use a dyadically rounded cap $h=\Theta(c_V j\sqrt{\log(j+2)})$; constructing a step counter in unary is possible within $O(h)$ steps by repeated doubling. The machine has a fixed number of tapes and constant branching. For sufficiently small $c_V>0$, the deterministic simulation on these short data fits $2^{j/2}\operatorname{poly}(j)=o(2^j)$ steps. A signaled length among these bounded computations would give a sound scale detector. It follows that, at every sufficiently large scale and on **every** permitted padding, a successful tape verification costs $\Omega_V(j\sqrt{\log(j+2)})$ steps. The same applies to a tape proof checker given a statement generated directly from binary $j$ in time $O(j)$ and making its own proof guesses. These statements concern either member of a signed pair, with the correct sign depending on the hard scale bit. [Strassle and Subercaseaux, Theorem 1](https://arxiv.org/abs/2611.11832)

## Where the SAT attack stops

The lower bound in scale time is a constant fraction of the actual $M$-step computation. The explicit formula spends a factor $\Theta((\log M)^3)$ more bits than that clock. The promised algorithm's matching upper bound prevents a linear-time exclusion for this encoding even with a better analysis of the testers. A new direction would need a more compact pair of ordinary formulas with the same computationally hard signed bit, or a different hard source. The threshold here alone implies no unrestricted linear, quadratic or cubic separation. The polynomial-clock padding construction treats a different requirement, covering all lengths of the original program cylinders under a fast-SAT hypothesis.
