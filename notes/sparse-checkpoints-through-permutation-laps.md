# Checking adaptive RAM laps without storing their address permutations

Consider a deterministic word RAM with a fixed instruction set and a constant-size controller. A transaction executes a bounded number of word instructions, with at most a fixed number of accesses to read-only input and mutable work cells. Its addresses and writes may depend on values it has just read. Transaction boundaries follow a fixed machine convention, such as grouping a fixed number of consecutive instructions. The simulator knows that convention. A cell accessed twice within one transaction has a single initial value and a single final value. Treat a cell that was only read as having its old value at the end. Initial work memory is zero or has a specified random-access initialization.

A **permutation lap** is a consecutive interval of transactions during which every cell of a common bank \([p]\) is touched by exactly one transaction. Allow the terminal lap to cover only part of the bank, still with no overlap between different transactions. A work access outside the bank violates this profile. The number of cells, their numerical order of visitation, and the lap endpoints may depend on the input. The read-only input is separate and can be consulted throughout. There is no restriction on the order's description length. With one transaction per cell and \(n\) cells a single lap can realize all \(n!\) orders on inputs supplying the order. The earlier test for permutation laps used small circuits computing chronological rows. [Address-order tests](address-orders.md)

**Behavioral SAT lower bound.** Fix an integer \(L\ge1\), a fixed transaction convention and either one of the two verdicts. No correct deterministic SAT solver can satisfy both of the following requirements.

* It decides all proper encoded instances in \(O(N^c)\) time for a fixed \(1\le c<\sqrt{(L+1)/L}\).
* Every sufficiently large instance with the selected verdict has a genuine computation admitting at most \(L\) permutation laps.

There is also no globally \(O(N\log^d N)\)-time SAT solver, for any fixed \(d\), on which every sufficiently large instance of one specified verdict has \(o(\log N/\log\log N)\) such laps, uniformly over inputs of that length. Consequently, if an unrestricted solver meets the stated clock, its actual histories violate the corresponding structural restriction for arbitrarily large inputs of **each** verdict. The bit length is that of the encoded CNF. Use the ordinary log-width RAM operations with Boolean verification circuits of polynomial size in the word width.

## One short list and one search for a defect

Let \(T\) be a constructible upper clock in transactions. Write \(w=O(\log(T+N+2))\) for the word width; in the transfer below both logarithms have the same order as the logarithm of the hierarchy clock. Guess the actual halt time at most \(T\), a bank size representable in \(O(w)\) bits, and a partition into at most \(L\) nonempty laps. If only a partial lap occurs, \(p\) can be as large as the address universe; no vector of length \(p\) is allocated. In a full lap, covering \([p]\) forces \(p\) to be at most the number of accesses. Include the register state at the start and end of every block of at most \(B\) consecutive transactions, cutting blocks at lap boundaries. To check coverage when transactions have several distinct addresses, include a running count of distinct addresses **within each transaction**, accumulated across that lap. Its increment is computed from the bounded footprint; it resets at the start of the next lap. Validate the format, boot registers, terminal verdict and full-lap count totals. Halting is required at the claimed endpoint and forbidden earlier. Idle or zero-time cases can be checked separately. The list occupies \(O((T/B+L+1)w)\) guessed bits.

A nondeterministic computation can propose a row at a selected local time in lap \(j\). Start at the preceding guessed block boundary. Simulate up to \(B\) actual transactions, with local forwarding on repeated accesses inside a transaction. As soon as an effective work address is computed, first test whether it belongs to the bank. An out-of-range address terminates this partial replay with a witnessed defect, before any predecessor or value for that address is requested. For each fresh in-range cell address needed in this transaction, obtain its initial word from the prescribed initialization if \(j=1\). Otherwise guess a time in lap \(j-1\), recursively compute its transaction, check that the address is in its footprint and use that transaction's final word at that address. A failed check rejects the proposed row. A write-only access can use a dummy read for accounting, or simply omit the read if its prior contents are irrelevant.

A **defect** consists of one successful replay to a wrong endpoint, a clock or halting violation, an incorrect per-lap count, or a successfully replayed instruction prefix that computes an out-of-bank work address. The last case stops before executing the offending access. A repeated cell in two different transactions of one lap has a certificate consisting of two successful replays. Include malformed header lists among the immediate defects. The outer test guesses the common list and declares it valid if this one nondeterministic defect search has no accepting branch.

To see why absence of a predecessor proof cannot conceal an error, use induction on laps. First-lap fetches from initial memory are exact and available. For a subsequent lap whose predecessors form a genuine full lap, every requested cell has one true supplying transaction. Every earlier in-range access in a proposed local instruction prefix has a proof of its true prior word, and all successful proofs deliver that word. This suffices to expose the first bad effective address even though that address has no predecessor in the preceding lap. With the registers at the start of a proposed block held fixed, the replay therefore gives precisely the frozen-start-of-lap computation for that block. Absence of endpoint errors concatenates all these blocks. Absence of inter-transaction duplicate addresses, together with range and the checked total, proves that the full preceding lap actually covered the bank. Frozen reads then coincide with genuine in-place execution. This argument also verifies a partial final lap. A repeated cell or an absent earlier predecessor in an invalid history cannot invalidate the induction at an earlier genuine lap. Thus even a computation outside the structural promise cannot forge an opposite terminal verdict with a defect-free list. [Exact inverse retrieval and local endpoint verification in Lean](../lean/PermutationLapReplay.lean)

For a fixed arity constant \(C\) large enough, the number of guessed transaction evaluations in a defect is \(O((CB)^L)\) for \(B\ge2\). Each guess of an earlier time costs \(O(\log T)\) binary choices. The recursion stack, arithmetic, and random header access cost at most a polylogarithmic factor per evaluation for \(L=O(\log T)\). This is an existential list followed by a universal rejection of all putative defects. At fixed \(L\), \(B=\lceil T^{1/(L+1)}\rceil\) gives total alternating time \(T^{L/(L+1)}\operatorname{polylog}(T+N)\). For \(B=\lceil(\log T)^A\rceil\) and \(L\le \log T/(4(A+1)\log\log T)\), the recursive term is below \(T^{1/3}\) at large \(T\). The list then costs \(O(T/(\log T)^{A-1})\) bits at polynomial source scales. Whole-word guesses would write it faster; the stated SAT result pays for **every guessed bit**.

## Transfer to proper SAT

Use a multitape hierarchy clock \(t=u^2\) on inputs of length \(u\). For accepting SAT histories, choose a language in nondeterministic multitape time \(O(t)\) outside nondeterministic time \(O(t/\log u)\), by the nondeterministic time hierarchy. For rejecting histories, use a language in complementary nondeterministic time \(O(t)\) outside nondeterministic time \(O(t/\log^2 u)\). For the latter one may complement the bounded universal nondeterministic acceptance problem on the machine description followed by padding, running the interpreter for \(u^2\) of its own steps. On the fixed proposed decider's description a fixed-tape interpreter simulates each step with constant overhead after normalization to a fixed number of tapes. Ordinary multitape normalization with logarithmic overhead still fits the clock. Self-simulation contradicts acceptance of the complement. [Seiferas, Fischer and Meyer](https://doi.org/10.1145/322047.322061) · [Fortnow, Lipton, van Melkebeek and Viglas](https://doi.org/10.1145/1101821.1101822)

Reduce the nondeterministic language, or the complement of the chosen complementary language, to a proper SAT file of \(M=t\operatorname{polylog}t\) bits. Each bit of the file is accessible given the original input and index in \(\operatorname{polylog}t\) time. The usual bounded-run reduction with regular routing or sorting records, fixed field strides, and proper gate clauses has this property; decimal names in an ASCII variant can be generated with ordinary polylogarithmic arithmetic and padded with whitespace at fixed strides. A native input word needs only \(O(\log t)\) such bit lookups. **Do not print this first file.** Its on-demand indices are subroutines of the short replay. They use the original \(u\) input bits and the queried coordinate, and need no large preprocessed copy. [Williams, Theorem 3.1](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Local reductions](https://arxiv.org/abs/1311.3171) · [Bounded arithmetic and input templates](packed-band-transfer.md)

Take \(T=O(M^c)\), rounding the clock up to a constructible polynomial bound with the same strict exponent margin. The outer nondeterministic opponent guesses the list and uses the hypothetical SAT solver **once** to decide whether a defect exists. This second proper SAT file may be physically constructed. Its size and construction time are \((u+(T/B+L+1)w+(CB)^L)\operatorname{polylog}t\), since its public inputs are the original input and the guessed list, and its bounded nondeterministic verifier includes the local generation of words of the first file. False headers and time indices receive the same explicit caps. The ordinary SAT execution on the defect formula only uses the global time hypothesis. Its memory accesses can be arbitrary. The selected sign of the first SAT computation is the one witnessing membership in the hierarchy language.

At fixed \(L\) the final word-RAM nondeterministic cost is at most \(t^{c^2 L/(L+1)+o(1)}+u^{c+o(1)}\). At the stated strict inequality this is polynomially smaller than \(u^2\). A fixed number of extra logarithms converts this final computation to a nondeterministic multitape computation: guess the chronological word events and check the arithmetic and sorted-address consistency on tapes. Sequential merge sorting of \(O(s+u)\) logarithmic-word events takes \((s+u)\operatorname{polylog}t\) tape time for clock \(s\), also when a word choice must be guessed bit by bit. The interpreter can therefore be kept in the exact machine model of the hierarchy theorem. At \(M\operatorname{polylog}M\) deterministic SAT time choose the constant \(A\) larger than the fixed sum of the initial reduction overhead, the cost of materializing and solving the defect formula, and the final tape conversion, with room for the outer \(w\) and the hierarchy's logarithms. The growing-lap hypothesis implies the preceding explicit lap cap for all sufficiently large inputs. Compute that cap directly; no convergence modulus is needed. The finite program's clock arithmetic with fixed exponent \(A\) uses a fixed number of log-width operations, so the universal reduction's logarithmic exponents need not grow with \(A\). Both calculations contradict the designated hierarchy.

The unrestricted-lap architecture contains complete deterministic SAT deciders: allocate a dense polynomial work bank for a conventional exhaustive polynomial-space solver, and perform a full traversal for each guest mutable-memory operation, servicing the chosen address when reached. Its number of laps can be exponential. Within a *fixed* number of laps a fixed logarithmic address width limits even the total number of transactions that each touch a cell. No existence claim for a correct SAT solver at arbitrary speed in that fixed-lap class is needed. The result concerns the joint elapsed-time and access behavior of globally correct solvers.

## Why known routing and unique writers do not supply the laps

The Pippenger–Fischer oblivious simulation of a one-dimensional multitape computation of time \(t\) takes \(O(t\log t)\) time on two tapes. Obliviousness prescribes physical head positions; it gives no per-lap promise that every work cell appears exactly once. The ordinary nondeterministic bounded-RAM reduction guesses \(\Theta(t)\) word-size rows and checks a chronological and an address-sorted ordering. The Beneš network on \(n\) records has \(2\log_2 n-1\) two-port stages and \(\Theta(n\log n)\) switch bits. Even with two-port transactions enabling one stage to span one lap, \(\Theta(\log n)\) laps makes \((C(\log n)^A)^L\) superpolynomial for constant \(A>0\). Any fixed network of two-port switches realizing all permutations needs \(\Omega(\log n)\) such layers, by the \(n!\) arrangements and at most \(n/2\) switch bits per layer. A guessed chronological trace also needs its own consistency check. This does not lower-bound an adaptive unrestricted RAM route. [Pippenger and Fischer](https://scholarship.claremont.edu/hmc_fac_pub/597/) · [Locally indexed RAM routing](packed-band-transfer.md)

A persistent binary radix tree on \(w\)-bit addresses copies \(O(w)\) new nodes per write and follows \(O(w)\) nodes per lookup. Naming every new node by its update time and depth gives an immediately known writer on \(O(tw)\) sequential node operations and words. Node contents still depend on previous dynamic values. Here is an obstruction to the proposed verification rule “follow true writer dependencies back to saved true node values.”

Use an actual word RAM computing a Walsh–Hadamard butterfly on \(n=2^d\) input words over \(\mathbb F_3\). Each pair at level \(j\) writes the sum and difference of its two predecessors, with a separate physical address for each new scalar. Give each vertex its own instruction-time slot and never rewrite a payload. An arbitrary read-only permutation \(\pi\) and its inverse may rename the row indices at every level: write slots in numerical order; when writing slot \(s\), take its logical row to be \(\pi(s)\), and use the inverse to find the two actual predecessor slots. Every record's writer time is then available directly from the physical address. The computation takes \(T=\Theta(n\log n)\) ordinary word steps. Its live scalar registers can contain a bounded number of vertex values, with other registers carrying public counters and addresses. Addition/subtraction modulo three can be treated as bounded native transactions with their temporary arithmetic derived from the two input vertices. A checkpoint of such a transaction can be supplied by its few underlying vertex values.

Between any input and output there is a unique dependency path. A vertex in level \(j\) lies on exactly \(2^j2^{d-j}=n\) input/output paths. Mark any \(k\) genuine vertex values anywhere in the execution, even after seeing it. They cover at most \(kn\) paths. Some output has at least \(n-k\) sources whose paths to it encounter no mark. Fix the all-zero scalar input and this chosen output. Give a local verifier all the true marked values **in this output's ancestor subgraph** and their locations. For every uncovered source, changing its trit to one changes the target by \(+1\) or \(-1\). It changes no supplied value: such a change would mean its unique path to the output passed through that marked vertex. The comparison keeps the same marker locations on the modified input. A checker in this model must work for arbitrary supplied locations with authentic cone values; the choice of locations is not a separately validated, input-specific certificate encoding additional information. Any sound existential certificate of the target's zero value must therefore probe each uncovered original word. This statement permits arbitrary computations on the supplied local information and arbitrary guessed writer indices. With \(k=o(n)\) it costs \(\Omega(n)=\Omega(T/\log T)\) native probes for that query, even for optimal placement of all \(k\) genuine marks. A certificate reading out-of-subgraph summaries, a different proof relation, or additional globally validated code has more information. The example does not rule out those methods or assert a time lower bound for the butterfly's one-bit decision problem.

For a separate failure of padding, use \(b\) interleaved lanes across \(n/b\) rounds. In lane \(j\) of round \(r\) read the preceding round's immutable word and write the updated parity of that lane to a fresh timestamped location. Each used location has one writer and at most one later reader. Two visits to a particular lane word are separated by \(\Theta(b)\) intervening transactions. For one fixed lane the writer-to-next-reader intervals have disjoint possible lap boundaries, since in every round the old read precedes the new write. A trace-preserving completion that retains these addresses needs \(\Omega(n/b)\) full laps of a domain of size \(\Omega(n)\), or \(\Omega(n^2/b)\) padded work. This continues to hold for fixed-size transaction groupings when \(b\) grows. Optimizing the original algorithm or changing its representation is a different operation.
