# How much information crosses a cut for repeated reads of one table?

A single lookup and a batch of lookups share their table. The following calculation prices that sharing for an exact binary-wire network. All ranks are ordinary matrix ranks over an arbitrary field. The relevant object is the zero-one relation asserting that every proposed reply equals the requested word.

Let a table have $m\ge1$ rows of $w\ge1$ bits. Put $a_i$ of the bits of row $i$ on one side of a cut, for $0\le a_i\le w$. Put the other table bits, $t$ addresses and their $t$ proposed replies together on the other side. Addresses range over $[m]$ and may repeat. Write $D_i=2^{a_i}-1$. Then the exact rank of the flattening is
\[
 R_m(t)=\sum_{S\subseteq[m],\ |S|\le t}\ \prod_{i\in S}D_i .
\]
This includes $R_m(0)=1$. Adding a row with $a$ private bits gives the exact successor
\[
 R_{m+1}(t)=R_m(t)+(2^a-1)R_m(t-1)\qquad(t\ge1).
\]
For example, for one-bit rows and two reads the ranks at $m=1,2,3,4$ are $2,4,7,11$. With $a_i=w$ throughout the sum is $\sum_{j=0}^{\min(t,m)}\binom mj(2^w-1)^j$.

## The column space

In the function space of private word $i$, use the basis consisting of the constant one and the equality indicators of the $D_i$ nonzero word values. Independence follows by evaluating first at zero, then at each nonzero word. Their products over all rows form a basis on the full table. A basis product has support $S$ if it uses a nonconstant indicator precisely at the rows of $S$.

Fix a column of the relation. Conflicting proposed replies, or failure on a bit already visible to the requester, give the zero column. Otherwise the column specifies one value in each of at most $t$ private rows. Expand any indicator for the zero word as one minus the sum of its nonzero indicators. This proves the upper bound. Conversely, for any nonempty support $S$ of size at most $t$, query all its rows and repeat one of them to fill the list. Set the proposed replies' private bits to the desired values and their other bits to the known table bits. This gives the basis product itself. The constant is in the span by summing columns for all private values of a single repeatedly queried row. With zero queries the relation is already constant. This proves the formula, including in characteristic two.

In fact an integer minor has determinant $\pm1$. Take as row inputs all private tables with at most $t$ nonzero rows. For nonempty supports use the columns just described, and order rows and basis products by support size in the same order within each size. Evaluation vanishes unless the product's labeled support is contained in that of the row. The resulting matrix, with the constant as the empty product, is triangular with unit diagonal. When $t>0$, replace the constant by the actual column for a zero private value in a fixed repeatedly queried row. The difference is a sum of the already selected singleton columns. This column operation preserves the determinant. When $t=0$, the one entry is one.

## Realizing the optimal interface

The minimum number of binary wires at such an interface is exactly $\lceil\log_2 R_m(t)\rceil$ if both sides may use polynomial local volume. Cutting $h$ wires gives rank at most $2^h$. In the other direction, code the $R_m(t)$ labeled supports densely. Given the code of $(S,u)$, the table side outputs $\mathbf1[x_S=u]$. On the requester side first check the visible bits and consistency among repeated addresses. Write $Q$ for the queried rows, $y_i$ for the requested private values, and $Q_+=\{i\in Q:y_i\ne0\}$. The coefficient at the shared code is zero unless $Q_+\subseteq S\subseteq Q$ and $u_i=y_i$ for every $i\in Q_+$. When these conditions hold the coefficient is $(-1)^{|S\setminus Q_+|}$. This follows by expanding the equality indicators for zero values. Contracting over the shared code gives exactly the desired bit over every field. Unused codes have coefficient zero.

For clarity about size, for each suffix of rows and remaining support budget store the number of possible completions, using the displayed successor. These are public constants of $O(1+mw)$ bits. Unrank a code from left to right. The first interval skips the row. Each of the next $D_i$ intervals chooses one nonzero value and uses one unit of budget. Compare, subtract and divide by the common positive interval length to choose the interval and residual index. With zero remaining budget only the skip interval is allowed. These operations on $O(1+mw)$ bits have polynomial Boolean circuits by schoolbook arithmetic. Each side checks its coefficient using ordinary gates, with a unary field table supplying the sign. Gate and copy constraints give a unique internal evaluation, and the only sum across the cut ranges over the stated code. Thus the upper bound prices the interface without hiding an exponentially large lookup in the local computation.

## What changes when a RAM writes or chooses its next address adaptively?

Fix a requester's exterior input. It starts with access to the other bits of the table and may run arbitrary deterministic local code, choose addresses from earlier replies and overwrite whole words. Suppose on every path it reads at most $t$ distinct table rows **before their first overwrite**. Simulate it by branching only at the first such read of each row. Subsequent reads on the path have a known value. Each feasible leaf fixes at most $t$ private row values, and the accepting leaves are disjoint. Their indicators sum to that input column. Hence its rank is at most $R_m(t)$, with equality attainable by the batch relation above. This argument also allows scratch memory initially independent of the private table. Initial advice independent of the private bits is allowed. Advice computed from the private bits requires accounting for the information it contains.

There is a counting consequence on actual inputs for any Boolean decision relation $F$ of rank $\rho$ across this split. For each requester column keep the indicators of only those accepting leaves that read at most $t$ distinct original rows, setting other entries to zero. This produces a matrix of rank at most $R_m(t)$. Subtract it from $F$. The difference has rank at least $\rho-R_m(t)$, and its support consists exactly of inputs accepted after more than $t$ such reads. A nonzero full-rank minor on that many rows and columns contains a nonzero determinant term. Hence there are at least $\rho-R_m(t)$ expensive accepting inputs with **pairwise distinct tables and pairwise distinct requester inputs**. Apply the same argument to $1-F$, whose rank is at least $\rho-1$, to obtain a matching of at least $\rho-1-R_m(t)$ expensive rejections. A nonpositive estimate simply gives the empty matching. Only the paths on the selected inputs have to reach the stated cost.

For example, if all $mw$ table bits are private and $\rho=2^{mw}$, taking $t=m-1$ gives matchings of sizes at least $(2^w-1)^m$ and $(2^w-1)^m-1$. Each corresponding computation reads the original contents of **every** row. For $2^w\ge m\ge2$ the first matching covers at least a quarter of the possible tables, since $(1-1/m)^m\ge1/4$. This applies to the binary product graph with $B$ held as $d$ independent $d$-bit rows because setting $A=I$ gives full rank across $B\mid(A,C)$. In this example almost all tables occur in each matching as $d$ grows. This is an exhaustion result for real decisions on tables, with the bound expressed in distinct rows read.

For a fixed batch with all $mw$ bits held by the table owner, any tensor network needs at least $\lceil\log_2 R_m(t)\rceil$ wires across this partition. Conversely, for $0\le t\le m$ there is a simple deterministic protocol. Pad the set of distinct requested rows to exactly $t$ using a public rule, send its subset index, and return the $t$ words in sorted row order. This uses
\[
       \lceil\log_2\tbinom mt\rceil+tw
\]
bits and gives a cut of this width, allowing arbitrary local network size. By the last term of the rank sum, this protocol is within two bits of the rank lower bound whenever $m\ge2$ and $2^w\ge m$. Indeed $-t\log_2(1-2^{-w})\le -m\log_2(1-1/m)\le 2$ for $m\ge2$, and rounding preserves the two-bit gap. For the stated subset protocol the two-bit allowance can be attained. At $m=64,w=6,t=56$ it uses 369 bits and the rank requires 367. For $t\ge m$, sending the whole table attains $mw$ bits and the rank is $2^{mw}$. For example, at $t=m$ the entire address cost in $m$ separate lookup prices disappears. This protocol prices fixed batches. The rank upper bound also covers adaptive programs.

In the binary matrix-product graph, restrict $t$ selected rows of $A$ to unit vectors, zero out the other rows, and expose the proposed rows of $C$ to the requester. The table consists of the $d$ rows of $B$, with $w=d$ and $t\le d$. This yields exactly the batch relation on this restricted set of rows and columns of the flattening. It reaches rank $2^{d^2}$ at $t=d$, already attainable by fixing $A=I$. Its logarithm cannot force more than $d^2$ wires. At $m=2^w=t$ the batched lookup itself has the independent superlinear network-volume lower bound imported from list distinctness, even though this optimal table cut has exactly $mw$ wires.
