# What a verdict-preserving shortcut must learn across an input cut

**Research journal, 24 November 2026.** There are explicit width-three SAT inputs in two arrays indexed by permutations $\pi,\sigma\in S_m$. Their bit length is $N=\Theta(m\log m)$ and the answer is UNSAT exactly when $\pi=\sigma$. Run any deterministic correct solver on the two equal arrays and choose any cut in its genuine execution. A shortcut may replace its entire future computation. Its only inherited data are a $b$-bit description. It can read both input arrays again. Require the right verdict on every change of the right permutation that would have produced the very same prefix with the left permutation fixed. Filling a register with the answer to the single original input would be a weaker requirement.

Call a position *observed across the cut* if the prefix reads its right-hand entry or the replacement suffix reads its left-hand entry. Give the prefix free access to the left array and the replacement free access to the right. For a uniform diagonal input, the probability that **some** choice of cut and valid description of length at most $b$ leaves at least $d$ positions unobserved across the cut is at most
$$
 \min\left(1,\ (2^{b+1}-1)\frac{\binom m d}{d!}\right).                 \tag{1}
$$
It is enough to require correctness on the permutation family. Program, registers, timestamps, prefix-log views and other public data specific to the run count in the description if passed to the replacement. The cut itself can be selected privately in hindsight and takes no bits when the replacement does not use it. Any fixed post-cut interpreter is allowed. For the lower bound even its local computation time can be unlimited. The prefix can be different for each fixed target solver. The event ranges over all cuts on its actual run, including the initial one.

For polylogarithmic $b$, outside an exponentially small fraction of diagonals, every such replacement together with its native prefix observes all but $O(\sqrt m)$ distinct positions across the cut. There is also a correct solver whose $O(N)$-time computation admits a shortcut on **every** diagonal leaving $\lceil\sqrt m\rceil$ positions unobserved with $O(\log m)$ bits. For larger $d$ the threshold number of description bits for success on all diagonals is
$$
 d\log_2(d^2/m)+O(d+\log m),\qquad \sqrt m\le d\le m.                  \tag{2}
$$
This threshold minimizes over allowed solvers and replacements at public parameters $m,d$. The upper bound uses a genuine linear-time prefix and a deterministic replacement taking at most quadratic time on the family given the description. Arbitrary time is allowed to select a description. Monotone subsequences and a compressed table of labels give the upper bound.

## An ordinary 3-CNF and its hybrid inputs

Use disjoint variable sets $z_i,w_j$. The left clauses impose $z_i=w_{\pi(i)}$ via two implications. The right clauses introduce $b_i\leftrightarrow(z_i\mathbin{\mathrm{xor}}w_{\sigma(i)})$ using four gate clauses, and require the OR of all $b_i$ by a chain of OR gates with equivalence clauses and a final pin. Repeat literals to pad short clauses to width three. There are $O(m)$ clauses and variables, with all literal names in fixed-width binary. A public layout can pad each contiguous group of clauses involving an entry by a constant number of fixed tautologies so any individual packed word depends on at most one of the two permutations' entries. Allow enough fixed bits on boundaries for the chosen word-width coefficient. Retrieving any one named entry takes constantly many packed word reads, and no such read has to reveal a different entry. The record of a read counts the coordinate that structurally supplies its variable bits, regardless of whether the program uses them. All other formula words are public. This construction also works with ordinary input words straddling clauses.

If the permutations agree, the OR cannot hold. When they differ at $i$, choose different Boolean values for $w_{\pi(i)}$ and $w_{\sigma(i)}$ and set every $z$ by its left equality. This satisfies the right OR and all its gates. Thus crossing two different diagonal pairs always changes the verdict. Codes for the two halves can be constructed independently.

For a passing diagonal $\pi$, choose its cut and description $z$, then choose $d$ positions $D$ outside both observed sets on that run. Record $D$, the ordered values of $\pi$ outside $D$, and $z$. Suppose the same record serves two different diagonals $\pi,\tau$. On $(\pi,\tau)$ the native prefix chosen on $(\pi,\pi)$ proceeds unchanged. Every right coordinate it reads agrees, by construction of $D$. The replacement chosen on $(\tau,\tau)$ also proceeds unchanged when given $(\pi,\tau)$ and the common $z$. Every left coordinate it reads agrees. These two inductions permit arbitrary adaptive addresses. This crossed run therefore rejects, contradicting the first prefix's verdict guarantee. The two privately chosen native cut times need not agree. Consequently each record serves at most one permutation. For fixed $D$ there are $m!/d!$ outside restrictions, giving (1). Using $\binom md/d!\le (\mathrm e^2 m/d^2)^d$ proves the square-root assertion, e.g. at $d\ge2\mathrm e\sqrt m$. For success on all diagonals the required length is at least $\log_2(d!)-\log_2\binom md-1=d\log_2(d^2/m)-O(d)$ when $d\ge\sqrt m$. This is an equality fooling-set argument that charges distinct positions on two different adaptive traces. [Yao, *Some Complexity Questions Related to Distributive Computing*](https://doi.org/10.1145/800135.804414) · [Earlier journal reconciliation argument](diagonal.md)

If the **same** omitted set $D$ is required for every diagonal, the factor $\binom md$ disappears. Conversely the factorial rank of the order of the $d$ remaining left values costs $\lceil\log_2(d!)\rceil$ bits. A shortcut can read the left array outside $D$, recover the missing set of values by taking a complement, and put them in their encoded order. Thus the extra choices of $D$ in (1) have real mathematical consequences for this model.

The counting argument also tolerates a specified number $E$ of erroneous right continuations per selected prefix. Require the shortcut to reject its own diagonal and let it misclassify at most $E$ of the admissible permutations. A single recorded triple can occur for at most $E+1$ diagonals. For any one of them every other member of the triple would be a different false rejection on an admissible right continuation. Thus (1) increases by at most a factor $E+1$. For a fixed omitted set, fixed-length codes and success on every diagonal, this gives the sharp alphabet size $\lceil d!/(E+1)\rceil$. The right procedure checks outside agreement, then tests the rank of the hidden order modulo this alphabet size, using the residue of the true rank as its description. There can be at most $E$ false rejections. In particular if all $m$ positions are omitted, allowing an error on a fixed fraction $\delta$ of all right permutations reduces the necessary description to $O(1+\log(1/\delta))$ bits. This quantifies the change in the verdict requirement when random hybrids are used in place of every hybrid.

There is an information bound on the omitted locations themselves. Use any distribution of choices of a valid cut and an omitted $d$-set $D$ for each uniform diagonal permutation $\Pi$, allowing random choices after seeing it. Let $Z$ contain the actual description bits. Write $H$ for base-two Shannon entropy and $I$ for mutual information. Then
$$
 I(\Pi;D)+H(Z\mid D)+\log_2(E+1)\ \ge\ \log_2(d!).
$$
Indeed $H(\Pi\mid D,Z,\Pi|_{[m]\setminus D})\le\log_2(E+1)$ by the same crossed-pair bound on each signature's multiplicity. Given $D$, the ordered outside restriction takes at most $m!/d!$ values. Expanding $H(\Pi\mid D)$ and using both bounds proves the inequality. An omitted set chosen independently of the permutation therefore retains the fixed-set lower bound even when the set has high entropy of its own. Conversely, if every diagonal uses an exact shortcut within the upper bound (2), then any such choices of the hidden sets must satisfy $I(\Pi;D)\ge\log_2\binom md-O(d+\log m)$ in the stated range. At $d=\lceil\sqrt m\rceil$, the fast construction below has a short transmitted score while the locations of its omissions carry $\Omega(\sqrt m\log m)$ bits of information about the input.

## A square-root omission in linear time

Fix $\pi$. By Erdős–Szekeres there is an increasing or decreasing subsequence of length at least $\lceil\sqrt m\rceil$. Indeed the pair consisting of the longest increasing and decreasing lengths ending at each index is distinct for every index. A subsequence can be recovered in $O(m\log m)$ time by maintaining, for every increasing length, the smallest terminal value and the predecessor attaining it, and repeating in the reversed value order. Choose a subset $D$ of the positions of this subsequence. The native prefix validates and reads its left array and compares the right entries **outside** $D$ to it. Take the cut on a matching prefix. Give the replacement the score $S(\pi)=\sum_{i=1}^m i\pi(i)$ in $O(\log m)$ bits. It reads only its right array and tests $S(\sigma)=S(\pi)$.

On every permissible continuation, the elements on $D$ are the same multiset, and $\pi$ orders them strictly monotonically there. Its score is the unique maximum or minimum among those permutations. Swapping a pair into increasing order raises the weighted sum by the positive product of the two index and value differences. This proves exactness, including for changes at several omitted positions at once. A constant number of native words suffice for the score, or $O(\log m)$ elementary operations per summand with shifts and addition. The total program can check syntax and permutation validity on each local half, with validation of the full right half after the cut. On noncanonical inputs use a fixed general SAT solver. On a mismatch the native program may compare and validate the whole instance directly. A genuine solver on the family can use the full scan as its original suffix, even when an alternative suffix is cheap. [Erdős and Szekeres, *A Combinatorial Problem in Geometry*](https://www.numdam.org/item/CM_1935__2__463_0/)

## Many omitted positions with a short description

Put $r=\lfloor m/d\rfloor\ge1$ and partition positions into $g=\lceil m/r^2\rceil$ public consecutive groups of size at most $r^2$. Here $g\le 1+4d^2/m$. A group of size $s$ admits a monotone subsequence of length at least $\sqrt s\ge s/r$. Their lengths sum to at least $m/r\ge d$. Keep exactly $d$ positions, shortening individual subsequences as needed. The deterministic native prefix can compute these sets from its own half in $O(m\log m)$ total time and then compare every right entry outside $D$.

For every value $v$ hidden at a position of $D$, label $v$ with the public group of that position. Let $H(v)$ be any total lookup function extending these $d$ prescribed labels, taking binary words of $a=\lceil\log_2 g\rceil$ bits as values. Its answers on other positions can be arbitrary. Indicate the orientation of the hidden monotone subsequence in each group. Give position $i$ weight $u_i=i$ for an increasing group and $u_i=m+1-i$ for a decreasing group. In addition to a representation of $H$, send the $g$ orientation bits and the two integers
$$
 C(\pi)=\#\{i:H(\pi(i))=\mathrm{group}(i)\},\qquad
 S_u(\pi)=\sum_i u_i\pi(i).
$$
For $g=1$ the group labels take zero bits. Given $\sigma$ the replacement tests both integers. Since all $d$ hidden positions contribute to $C(\pi)$ and the other positions agree, equality of the first integer forces every hidden value to remain in its own group. The second integer is the sum of independent group maxima on the hidden positions. Equality forces each group to attain its unique ordered arrangement. Thus both tests pass precisely on $\sigma=\pi$. Neither the list $D$ nor the distribution of the hidden elements among groups has to be sent.

The following binary recurrence stores $H$ with a leading coefficient of one on the label bits. Index values by distinct exponents $v=0,\ldots,m-1$, translating the permutation's values if necessary. Let $k=d+\lceil\log_2(4m)\rceil+2$. Choose a monic irreducible binary polynomial $P$ of degree $k$ dividing none of the nonempty sums of monomials from the $d$ hidden exponents. Each such polynomial has degree less than $m$ and has at most $m/k$ distinct degree-$k$ factors. There are fewer than $2^d$ sums. At least $2^{k-1}/k$ irreducibles are available. Indeed at most $\sum_{i=1}^{\lfloor k/2\rfloor}2^i$ elements of the binary field of size $2^k$ lie in proper subfields, and every irreducible contributes $k$ conjugate roots of full degree. The chosen parameters give strict slack. Consequently the residues $X^v\bmod P$ on the prescribed keys are linearly independent over $\mathbb F_2$. Each prescribed label bit therefore extends to a linear functional on this $k$-dimensional space.

Write $P=X^k+\sum_{j<k}p_jX^j$. Applying the functionals defines the whole word sequence by
$$
 H(v+k)=\bigoplus_{j<k:\ p_j=1} H(v+j).
$$
Store just the $k$ coefficient bits and the first $k$ label words. This uses $ka+k$ bits. The replacement can generate the values through index $m-1$ in $O(mk+k)$ word operations and inspect $\sigma$ in $O(m\log m)$ more. The native prefix can be fully uniform and independent of this possibly expensive-to-find recurrence. Only the mathematical replacement description uses hindsight. If a preprocessing algorithm is desired, uniform random monic polynomial trials suffice in expected polynomial time. Test irreducibility and full rank of the selected residue columns, discarding failures. The counts above give success probability at least a constant times $1/k$ per trial, and binary Gaussian elimination constructs the label functionals on a successful trial. One can also use unrestricted deterministic search. The total description length including the orientations and integer scores is $d\log_2(d^2/m)+O(d+\log m)$ when $d\ge\sqrt m$. Indeed $g=O(d)$, $a\le\log_2(d^2/m)+O(1)$ in that range, and the extra $O(\log m)$ initial words cost $O(\log^2 m)=O(d+\log m)$. All quantities fit $O(\log m)$-bit fields except explicitly stored arrays. The replacement costs $O(N^2)$ time on the family. The shortcut at $d=\lceil\sqrt m\rceil$ in the previous section has a stronger, $O(\log m)$, description bound and costs $O(N)$ time.

## Why the other verdict has a different bound

For any satisfiable clause-split 3-CNF with $K$ clauses and variable names in a universe of size $U$, at most $3K$ distinct names need assigned bits. The recurrence construction with one label bit gives an $O(K+\log(U+2))$-bit representation of such an assignment, even for sparse name spaces. Modular powering evaluates any requested entry without expanding all $U$ positions. Alternatively the partial-domain correction structure allows polylogarithmic lookup with $O(K+\log^{O(1)}N)$ bits on the logarithmic-word RAM. [Partial-domain retrieval](partial-domain-snapshot-errors.md)

Consider the initial cut. Give the right-hand procedure this representation for a witness satisfying both halves. It verifies its own clauses and outputs SAT if they all hold. If they do not, it can read the left half and run a complete solver. This description is sound for **every** replacement of the right half with the fixed left half, since the supplied assignment already satisfies all of the latter. On the particular positive input it reads no left entry. This gives a low cross-access bound for every positive input in this hindsight model. The assertion makes no claim that a deterministic solver can find the witness advice quickly. In the special permutation family an unequal pair can instead be exposed by the index and left value at one mismatch.

On the negative family a program can also validate and compare the two arrays in their ordinary order, taking $O(m)$ word operations on canonical inputs with padded local gadgets. It then has plentiful cross-observed positions at every cut, as (1) requires. A stronger time lower bound would require charging these positions beyond a single scan, or proving that one scan cannot serve the corresponding cuts on a different family. The upper constructions show exactly how a universally sound shortcut can conceal some positions without inheriting the actual state. All 41 small complete CNFs and 628,560 permitted right-hand hybrids passed the finite audit. Without the group-count test, 22,296 hybrids would have been falsely called equal by the positional score. Lean checks the crossed-path lemma, the Boolean mismatch encoding and the swap-score identity. The asymptotic upper and lower bounds are manuscript arguments.
