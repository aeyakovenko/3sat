# Calibrating SAT's clock relative to a recursive oracle

**Research journal, 2026-11-24.** The deterministic time needed for the oracle-gate version of explicit CircuitSAT can have any prescribed positive integer polynomial exponent in a packed word-RAM oracle model. The construction uses a dense query encoding to make the upper and lower clocks agree in word operations. It tests which features of a proposed lower bound survive the addition of oracle gates. The lower bound uses those gates in its input.

## Machine and encoding

Fix p≥1, an integer. A RAM on an n-bit input uses Θ(log(n+2))-bit words, with a machine-dependent constant sufficient to address its polynomially many cells. A query gives the start and bit length of a contiguous packed bit string in RAM and receives one membership bit. Unwritten memory starts at zero. The input initially contains at most n one bits, up to O(log n) for its descriptor. A step writes O(1) words. Query memory can persist. Specifying the length of a very large zero-filled buffer is allowed.

Use a topologically ordered circuit list with input nodes, Boolean constants and gates, and optional oracle gates of arbitrary explicitly listed arity. Each pin is a binary predecessor index of width ⌈log₂(g+1)⌉ for g listed nodes. There is one designated output. To support both this representation and the original binary-index ordinary CNF encoding at their exact bit lengths, allow two disjoint core types. A core 0D carries the explicit circuit D. A core 1F carries the original ordinary CNF F byte for byte (or bit for bit when unaligned). Malformed bodies are rejected. CircuitSAT with oracle gates asks whether some assignment causes the output to be one when oracle gates call the *same* oracle available to the solver. This is the usual kind of complete problem for relativized NP. The unrestricted arity and its explicit bit cost matter here.

## An oracle with a chosen exponent

For each p there is a recursive oracle A and an O(nᵖ) deterministic oracle RAM for this CircuitSAT problem. For every deterministic oracle RAM that solves it, there is c>0 such that the machine takes at least c nᵖ steps on infinitely many input lengths. In particular the instances p=1 and p=4 give opposite outcomes for both the quadratic and cubic exclusions. In the p=1 world, plain SAT without oracle gates in its input also has an O(n) oracle algorithm.

Let R be a set to be specified. Strings beginning with 0 ask for the corresponding suffix bit of R. For a core C of m≥1 bits put

    Qₚ(C) = 1 · C · 1ᴾ,       P = 2 mᵖ ⌈log₂(m+2)⌉.

Its total length strictly increases with m and uniquely identifies the core length. Such a string is in A exactly when its body is satisfiable under its core type, with A gates interpreted recursively in type 0 and the ordinary CNF semantics used in type 1. Other leading-one strings and the empty string are rejected. This is well-defined by induction on bit length. During the evaluation of C, every embedded oracle question lists at most m bits. This is smaller than the wrapper's length. On an n-bit input D or F, the solver emits the wrapper and subtype tags, copies the original n input bits, fills the padding in packed words and asks Qₚ(0D) or Qₚ(1F), respectively. Thus m=n+1 and the ordinary-CNF algorithm needs no conversion to a circuit list. Its cost is O(n + P/log(n+2))=O(nᵖ). A machine can choose its word-size constant for the required addresses. Baker, Gill and Solovay already construct their collapse oracle by the same strict length induction on bounded computations. The padding, use of a free raw predicate and fixed word-clock calibration below are additional details. [Baker, Gill and Solovay, Theorem 1](https://doi.org/10.1137/0204037)

**How many raw oracle bits can a wrapper see?** Fix answers of R and resolve a tagged query by exhaustive evaluation, descending recursively on its embedded queries. There is an absolute K with at most 2^(K m/log₂(m+2)) raw probes for a core of m bits, increasing K for small m. A circuit with r relevant witness inputs spends at least r explicit indices of width ≥log₂(r+1), counting a primary input used directly as output if needed. Hence r=O(m/log(m+2)). Unused input nodes need no enumeration. A type-1 core makes zero raw-oracle probes. Its ordinary exhaustive evaluation also takes 2^O(m/log(m+2)) times a polynomial in m: the r distinct appearing binary variable names themselves occupy Ω(r log(r+1)) bits in total, by counting the shortest distinct binary names. One can ignore declared but unused variables. In every circuit assignment there are O(m) gates. Any valid recursive core has at most half the current core length, because even its whole wrapper has at most m bits. The logarithm of one plus the number of raw probes is therefore bounded by a constant times

    Σⱼ (m/2ʲ)/log₂(m/2ʲ+2) + O(log²(m+2)),

over j with m/2ʲ≥1. Split at √m to bound the sum by O(m/log(m+2)). Polynomial parsing and gate-evaluation work per assignment obeys the same exponential bound for a tagged core when raw tests take unit cost. Changing any unprobed raw bit preserves this particular answer because one can replay the deterministic exhaustive evaluation with the same answers along its transcript.

**Construct R.** For k≥1 take the circuit Cₖ with k input bits y and a single oracle gate asking 0y. Its encoded length nₖ=Θ(k log(k+2)), and its answer is one exactly when R has any k-bit member. Fix a sufficiently small constant δ>0. The raw-probe estimate and the upper bound on nₖ imply that a wrapper core of size <δnₖ expands to fewer than 2^(k/3) raw probes for all sufficiently large k. The constant δ can be fixed before the machine is chosen.

At a stage for a clocked simulation of a RAM M, take k larger than every already settled raw length, with k large enough for the estimates. On Cₖ run M for ⌊c_M nₖᵖ⌋ steps under the temporary oracle given by settled R bits and zero elsewhere. Choose c_M>0 sufficiently small depending on M's word-size and write constants. A well-formed wrapper with core m≥δnₖ contains at least 2(δnₖ)ᵖ log₂(δnₖ+2) one bits just in its padding. In t steps there are at most nₖ+O_M((t+1)log(nₖ+2)) one bits in all physical memory. Thus even a reused or sparsely initialized buffer cannot expose such a wrapper before this cutoff. A malformed wrapper costs zero raw probes, and a direct raw query costs one, regardless of its length.

Resolve all questions asked during the simulation and settle the raw answers used. The total number read is at most O_M(nₖᵖ)2^(k/3)<2ᵏ. If M halted with zero, set one unprobed k-bit string to one. If M halted with one, leave all length-k bits zero. On timeout leave the slice zero. Settle any remaining strings of length at most k to zero. This preserves the simulated computation. Visit every RAM program and word-size parameter infinitely often. At most one string is ever made positive at a given length. In particular R has a deterministic linear-time algorithm with length-dependent advice specifying the positive string or its absence. Constructing that advice uniformly is part of the unresolved problem below. All operations at a stage, including the finite oracle expansions and the potentially enormous explicit memory simulation, are computable. Stage lengths increase without bound and settle all raw bits through k, so R and hence A are recursive. A correct RAM must have exceeded the cutoff at every sufficiently large one of its stages. Picking sufficiently large k and c_M can be done effectively from the instruction and word conventions. Another option is to cycle through integer lower cutoffs nₖᵖ/2ʲ and repeat each program/parameter pair at arbitrarily large fresh k, requiring the support and raw-probe inequalities before executing its diagonal stage.

This gives the relative lower bound even with unrestricted workspace. It is the validity of the *high-arity oracle gate* on Cₖ that changes when the fresh bit is set. An ordinary 3CNF clause has its truth table fixed in advance. The construction uses an explicit packed query convention. A primitive that returns membership on a circuit representing a query string would invalidate the padding charge.

## Giving both answers a unique relative witness

Could an exact count of raw members make the diagonal bit uniformly verifiable? Modify the construction so that R contains exactly one string at every length. At length h≥2 let B(h)=1 if the unique member begins with zero. The new canonical circuit guesses h−1 bits y and asks the single oracle question A(00y), which tests R(0y). Its length nₕ is Θ(h log(h+2)). To certify B(h)=0 one guesses y and tests R(1y) instead. On unary input 1ʰ the correct answer has a unique witness verifiable in O(h) time with one raw query. The census of R through length h, counting length zero, is the explicit integer h+1. Ordinary census functions and their complexity are studied by Goldsmith, Ogihara and Rothe. [Tally NP Sets and Easy Census Functions](https://www.cs.uky.edu/~goldsmit/papers/tallysets.pdf)

The same Ω(nₕᵖ) relative lower bound holds infinitely often for each machine correct on all sufficiently large canonical circuits. Maintain a frontier through which every raw length has its permanent member. Choose a fresh h beyond the frontier and fill all intervening lengths below h with their all-zero strings. During the clocked simulation use empty raw slices at lengths h and above. The earlier wrapper bound gives at most O_M(nₕᵖ)2^(h/3) raw probes after choosing δ small enough. For large h this is less than 2^(h−1), the number of candidates on *each* side at length h. If the machine reports zero, choose an unprobed member beginning with zero. If it reports one, choose one beginning with one. On timeout either side works. Let H be the maximum of h and all raw lengths touched during the simulation, including during recursive expansions. For each h<j≤H choose a permanent member outside the transcript. This is possible even for a long direct query, since the same probe bound is smaller than 2ʲ. Lexicographically first eligible choices make the stages effective. Every answer read during the simulation survives these choices, and the next stage starts above H. This proves the cutoff with a known exact census and two-sided unambiguous relative certificates. A short ordinary verifier for B, even on just its positive side, would still yield the contradiction below under fast SAT.

One can also fix the counts seen in every pair of coordinate positions. This variant uses O(h) raw members of length h. For h≥3 put r=⌈log₂(h+1)⌉ and let vᵢ be the r-bit expansion of i for 1≤i≤h. At this length R is one translate of the binary linear code consisting of all vectors (a·vᵢ)ᵢ as a ranges over r bits, with the dot product taken modulo two. Its coordinates I={1,2,4,…,2^(r−1)} recover the r bits of a. Each translate therefore has one normalized member with zeros on I. Every one-coordinate pattern occurs 2^(r−1) times and every prescribed pair of bits at distinct positions occurs 2^(r−2) times, because any two distinct nonzero binary columns are linearly independent. Translation preserves these counts.

Take B(h) to be bit 3 of the normalized member, with positions numbered from one. The canonical circuit guesses an h-bit member, tests it with one raw query, requires zeros on I, and checks bit 3. Asking for the opposite value gives the unique relative certificate on the other side. The circuit size is still Θ(h log(h+2)). Each raw probe into an empty fresh slice excludes just the single translate containing the probed string. At length h there are 2^(h−r−1) choices for each value of B(h), since 3 is outside I. This exceeds the stage probe bound for large h. At every later length j the number of translates is 2^(j−⌈log₂(j+1)⌉), a nondecreasing function of j. Consequently the same frontier construction can fix one entire untouched translate at every required later length, using the zero translate in skipped lengths and any fixed choice for h<3. The two possible values of the hard bit have identical one- and two-coordinate counts at every large length. The construction supplies no ordinary method to recognize the selected translate.

The first three coordinate positions describe exactly where the information about B reappears. Since v₃=v₁+v₂, every member x of the chosen translate satisfies x₁+x₂+x₃=B(h) modulo two. The number of members beginning with 000 is therefore 2^(r−2) if B(h)=0 and zero if B(h)=1. A single ordinary test for this three-bit pattern would recover the diagonal bit. Thus in this example every pair count is explicit and a specified triple count is already hard at the claimed relative clock.

There is a general reconstruction bound when more coordinate counts are available. Let X be an unknown set of s≥1 distinct h-bit strings. A count query specifies positions and prescribed values and returns how many members match. Counts for at most 1+⌊log₂s⌋ specified positions suffice to recover all of X. To extract one member, start with the remaining strings and an empty pattern. If m>1 strings still match, some coordinate splits them into two nonempty groups. Scan coordinates for such a split using one extra position per query. Keep the smaller group, whose size is at most ⌊m/2⌋. After at most ⌊log₂s⌋ splits a single member remains. Read each of its bits using at most one more position. Record the member and subtract its contributions from subsequent counts before extracting the next one. The empty pattern gives the initial size if necessary. This uses O(sh(1+log s)) count queries. The order bound is tight at powers of two: the even- and odd-parity classes on t+1 bits each have size 2ᵗ and agree on all patterns using at most t positions. To use reconstruction in the SAT argument, the chosen counts would themselves need a uniform ordinary evaluation procedure within the remaining clock. The short coordinate patterns that identify a member also occur in the work of Wigderson and Yehudayoff on noisy population recovery. Exact integer counts here permit the adaptive smaller-group choice. [Population Recovery and Partial Identification](https://www.math.ias.edu/~avi/PUBLICATIONS/WigdersonYe_ML2016.pdf)

## Compile short oracle requests back to ordinary SAT

For the upper-world construction take R empty, so all raw queries have known answers. All wrapper answers with core length ≤b can be precomputed into a table in 2^(b+O(b/log(b+2))) times a polynomial in b. Enumerate the at most 2^(b+1) candidate cores and use the exhaustive evaluation bound above. Even a duplicate expansion fits this cost. No hypotheses on ordinary SAT are needed.

Fix d≥1, ε with 0<ε<d, and b=⌊(d−ε)log₂(n+2)⌋. This preprocessing fits O(nᵈ). An O(nᵈ) machine deciding ordinary SAT with this particular oracle, whose submitted string lengths never exceed |Qₚ(0ᵇ)|, can therefore be simulated in ordinary O(nᵈ) deterministic word time. On this range any syntactically valid core fits in a constant number of words. A table on the possible query lengths (polylogarithmic in n) yields the putative core size or a rejection. Look up the core and check that the remaining pad bits are all ones.

For a persistent packed query range this last check need not rescan polylogarithmically many words per request. Maintain aligned groups of 2^⌊log₂ w⌋ consecutive words, where w is the word width. A summary word marks the children whose entire range is ones. Maintain the analogous summaries recursively for O(p+1) levels, enough to cover ranges of O((log n)ᵖ log log n) bits. Each normal write updates one bit or word on each level. Initial zero memory needs no setup, and the explicit input can initialize the summaries in O(n) time. A short contiguous range can be checked by testing the two partial leaf words, masking the complete children at its two boundary paths, and ascending. There are O(p+1) levels even across a top-block boundary. Summary cells can be stored in disjoint namespaces by ordinary address arithmetic using a sufficiently large constant word-size factor. This gives constant overhead per simulated step for fixed p. In a model that charges separately for emitting every query bit the simple scan would suffice as well.

Thus, to show ordinary SAT outside O(nᵈ), it would suffice to exclude that clock with this explicitly recursive oracle restricted to the indicated short lengths. Conversely an ordinary algorithm can ignore the oracle. The bound is sufficient for compilation and makes no assertion that its coefficient is optimal. Removing the length bound would include direct wrappers for full instances. The p=1 oracle solves ordinary SAT via just such a wrapper.

## Recover the padded fixed point from a fast ordinary SAT algorithm

Here is a converse test using the *same* oracle semantics. Assume ordinary SAT on m encoded bits runs in O(mᵈ) deterministic word time, for d=2 or 3, and take an integer p>d. If R is empty, or has an ordinary linear-time algorithm, the full oracle A for this p and R has an ordinary deterministic O(L)-time decision algorithm on strings of length L. The constant may depend on p, R and the hypothesized SAT machine. One must account for the recursion in an A gate when obtaining this statement.

In a wrapper with core length n, the sum over oracle gates of (one plus the query length) is O(n), since their pins and gate records are explicit. A nondeterministic verifier guesses the primary Boolean inputs and evaluates the gates in order. If it can run an ordinary exact decider on each embedded query in a known clock of K(l+1) for query bit length l, its total verification time is O(K(n+1)) up to fixed logarithmic factors. Reduce this *oracle-free* time-bounded verifier to ordinary SAT with quasilinear overhead and apply the assumed solver. The direct construction and solution cost is (K(n+1))ᵈ times a fixed power of log(2+K(n+1)). This conversion can use one fixed universal verifier with the simulated program and time bound in its explicit data. All gate answers come from deterministic subcomputations, including negative answers. [RAM simulation and quasilinear SAT reduction](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

For a uniform bound, take N₀=4, Nⱼ₊₁=Nⱼᵖ and rational d<β<α<p. Build a list of ordinary programs Dⱼ valid at all lengths through Nⱼ. Use any correct finite initial decider. On a type-1 core the wrapper program simply runs the assumed ordinary SAT solver on the original CNF body, in O(nᵈ) time. On a type-0 core the jth wrapper program contains a description of Dⱼ₋₁ and its certified clock coefficient Kⱼ₋₁. It uses the preceding bounded verification. On tag zero it runs the R algorithm. Every embedded query from a wrapper of length ≤Nⱼ has length at most its core length n≤Nⱼ₋₁, justifying correctness by induction. There is no oracle executable left inside the generated SAT instance.

Choose Kⱼ=2^⌈c αʲ⌉ for a sufficiently large fixed c. Each program runs within Kⱼ(L+1) steps at its advertised lengths. To see this, reject malformed wrappers or scan their padding in O(L) plus polylogarithmic bookkeeping. For a valid wrapper L≥nᵖ. In the simulation estimate, absorb the fixed powers of log(n+2) into (n+1)^(p−d) and the fixed powers of log(Kⱼ₋₁+2) into Kⱼ₋₁^(β−d). This gives a bound O(Kⱼ₋₁^β(L+1)), which Kⱼ(L+1) covers for all j by increasing c. The program template needs a single copy of the previous program plus a binary clock coefficient. Thus its total description length is polynomial in log Kⱼ+j; simulating its code in a fixed verifier changes only the logarithmic overhead. Clocks and programs can be generated successively in time polynomial in their total bit length, using the fixed rational α. Recursive simulations can use virtual words of O(log(Kⱼ₋₁(n+1))) bits; checking them fits the same logarithmic factors.

On length L generate the least sufficient tier j. The descriptions take poly(log(L+2)) time and log Kⱼ=O((log(L+2))^(logₚ α)). Thus Kⱼ=L^o(1). At the outermost valid wrapper the actual SAT computation costs n^(d+o(1)) rather than the coarse tier bound Kⱼ(L+1), since L=Θ(nᵖ log(n+2)). This is o(L). Together with the padding scan and the raw predicate algorithm this proves the stated O(L) bound. The strict inequality p>d is used twice in the clock argument.

Consequently, under the SAT hypothesis, ordinary deterministic time nᵈ poly(log n) suffices for CircuitSAT with A gates for *every such linear-time raw predicate* R. The simulator guesses the inputs, evaluates the gates using this O(L) algorithm and compiles that verifier into one ordinary SAT call. In particular a construction of the relative Ω(nᵖ) lower bound above that also made R uniformly linear-time decidable, for p>d, would contradict the SAT hypothesis. The diagonal construction supplies a recursive sparse R with short nonuniform advice. Its algorithm determines a stage by simulating the machines it is diagonalizing against. No linear-time algorithm to recover the required bit has been obtained. The criterion isolates the cost of finding the raw information and does not prove its existence within the required clock.

For the specific diagonal instances an even weaker premise would suffice, with a shorter proof. Write L_R={1ᵏ : R has a member of length k}. The construction above forces the lower cutoff on *any* oracle program correct on all sufficiently large Cₖ; its behavior on other circuit inputs does not enter the diagonal. Suppose L_R had an ordinary nondeterministic verifier running in O(kʳ) for a fixed r≥1 and rd<p. On canonical Cₖ, reduce that unary verifier to ordinary explicit SAT, then run the hypothesized solver. Recognizing the canonical layout, constructing 1ᵏ, the reduction, and the call all fit O(nₖ + k^(rd) polylog k)=o(nₖᵖ), since here p>d≥2. The resulting uniform machine ignores its oracle and contradicts the canonical-slice diagonal. A uniform nondeterministic O(kʳ) test for individual positive members of R would imply the same premise by guessing the k-bit member. No negative-membership certificates or upper bound on queries of noncanonical input circuits are needed in this inference. The sparse recursive construction alone supplies neither verifier. Establishing the stated tally verifier together with the calibrated diagonal would already supply a unary nondeterministic-versus-deterministic time separation at those clocks.

A second positive transfer needs no assumption on R. If all oracle gates in the *input circuit* have arity ≤l=O(log n), an oracle machine can first tabulate all strings through length l with O(2ˡ polylog n) work. It can then use a single ordinary SAT query encoding the nondeterministic n-step evaluation with that table supplied as explicit input. Its encoded length is Õ(n+2ˡ) by the RAM reduction. Under the SAT hypothesis this solves the restricted oracle-gate problem in Õ((n+2ˡ)ᵈ) relative time, uniformly over every oracle. It avoids copying a separate truth table into each gate. With l≤log₂ n, the relative clock is n^(d+o(1)). The logarithmic overhead does not give the exact endpoint O(nᵈ). The length-k existential query used to diagonalize has arity Θ(n/log n) and lies outside this positive regime.

## What a hierarchy argument must use

The nondeterministic oracle-tape time hierarchy still applies with a fixed oracle because its diagonal universal simulation forwards an explicitly written query to the same oracle, and the exhaustive terminal simulation can forward queries on each simulated branch. Lazy diagonalization separates the clocks despite the possible polynomial collapse of NP relative to A. For example one can run that argument at exponential clocks with a polynomial gap; this observation does not require a time-hierarchy theorem for an arbitrary new RAM instruction set. The underlying time-hierarchy theorem and an explicit account of the relativized version are given by Žák and Williams, respectively. [Žák](https://doi.org/10.1016/0304-3975(83)90015-4) · [Williams, Lecture 1](https://people.csail.mit.edu/rrw/cs294-2018/CS294_Scribe_Notes___Lecture_1__8_27.pdf)

An explicit bounded-arity Boolean constraint can be verified from a constant number of named bits. An oracle gate may take a length-k tuple, and changing a single previously unseen oracle answer at that tuple can reverse the entire computation. A Cook–Levin tableau with such gates needs a separate justification for every proposed oracle answer. Compiling that truth condition into a fixed small ordinary Boolean gadget is precisely where the model with R departs from ordinary SAT. Conversely a theorem using ordinary time hierarchy and explicit local predicates for one fixed verifier may already have a nonrelativizing step if it claims that the fast SAT algorithm's *own* tableau has just those local predicates. The oracle example by itself does not refute a lemma restricted to actual ordinary Boolean algorithms. Wilson also constructs oracle separations comparing deterministic and alternating classes across time scales. Priority of the particular packed-clock and cutoff formulation here has not been established. [Wilson](https://doi.org/10.1137/0216042)

[OracleReplay.lean](../lean/OracleReplay.lean) verifies that agreement on just the raw answers in a finite adaptive execution preserves its output, and that an unprobed raw bit on an empty slice can be changed without affecting that execution. The size estimates, oracle construction, and padded fixed-point simulation are manuscript arguments.
