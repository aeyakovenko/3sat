# One literal flip per cubic parity constraint suffices to encode 3-SAT

Given a nonempty proper 3-CNF $F$ with $v$ used variables and $m$ clauses, construct a simple Hamiltonian cubic graph on exactly $4v+14m$ vertices and an odd-charge Tseitin formula $B$ on its edges. Each vertex contributes four proper clauses on its three different incident edge variables. The formula $B$ is minimally unsatisfiable. Flipping exactly one literal sign in exactly one clause at every vertex produces a proper 3-CNF $F'$ with
$$
 F'\text{ satisfiable}\quad\Longleftrightarrow\quad F\text{ satisfiable}.
$$
The construction has linear encoded length and can be performed in linear deterministic word-RAM time from ordinary ASCII DIMACS, after eliminating duplicate ordered clauses. For every fixed $\rho>0$ a variant edits at most a $\rho$ fraction of the vertices with the same asymptotic bounds. The reference formula, the partition into four-clause groups and the Hamiltonian cycle can all be supplied to a solver.

## The local edit

Use three distinct wires per site, two inputs and an output. The relation $z=x\lor y$ agrees with $x\oplus y\oplus z=0$ for three of the four input pairs. On the exceptional pair $(1,1)$ one outputs 1 and the other outputs 0. Similarly $z=x\land y$ agrees with $x\oplus y\oplus z=1$ except on $(0,0)$. Negating any port toggles the reference parity and permutes the local triples. Permuting the ports preserves parity. Consequently each signed and oriented AND or OR site is obtained from its own parity relation by admitting one previously forbidden triple and withdrawing the triple differing only at the output port. In the canonical four-clause CNF this changes one sign in one clause. Each of the four new clauses still forbids a distinct triple. This is an edge constraint satisfaction problem with Boolean wires that each occur in exactly two local relations. [Kazda, Kolmogorov and Rolínek on Boolean edge CSPs](https://arxiv.org/abs/1602.03124)

## A cycle with matched ports

Give every site a left cycle edge $u$, a right cycle edge $v$ and a chord. Each chord bit is shared by its two endpoints. List one block per variable followed by one block per clause, and close the cycle. Every source literal occurrence has a chord $h$ from its variable site to its position in its clause. All other chords pair sites inside the following four-site construction.

* **Reset.** At four consecutive sites use chord labels $h,g,h,g$ in that order. In the forward direction calculate $s_1=u\land h$, $s_2=s_1\land g$, $s_3=s_2\land\neg h$ and $v=s_3\land g$. Every incoming value is possible and the outgoing value is always zero. Replacing the final $g$ by $\neg g$ keeps this behavior and toggles the site's reference parity.
* **Require one.** First complement the output of the last gate of an ordinary reset, obtaining the relation consisting of both input values and the fixed output one. Place these four gates in reverse order, exchanging left and right ports. The resulting block accepts exactly incoming value one and allows either outgoing value. Both constructions leave their two internal chords private.

At each variable, reset and then visit its occurrences, all positive ones first. A positive site requires $v=u\lor h$. A negative site requires $u=v\land\neg h$. Each selected positive occurrence ($h=1$) forces the state to one by the end of the positive sites. Once that state is one the negative sites propagate it forward and force all their $h$ values to zero. Conversely, if no positive occurrence is selected, use zero throughout the variable block, regardless of the negative selections. If positives are selected and no negatives are, use their successive OR and then state one throughout the negative sites. The following block begins with a reset and accepts either final state. This gives exactly the compatible selections, including variables of a single polarity and variables for which no occurrence is selected.

At each clause, reset, compute $v=u\lor h$ on each of its three occurrence chords in turn, then require one. Thus at least one of the three occurrences must be selected. Given a source model, select one true occurrence from each clause. These selections extend around the entire cycle, since each reset accepts every preceding value. Conversely, the selected occurrences in any solution have consistent polarities for each variable and hit every clause. Assign each variable to satisfy its selected polarity, choosing either value when there is none. This satisfies $F$.

There are $4v$ variable-reset sites, $3m$ variable-occurrence sites and $11m$ clause sites. There is one cycle and one perfect matching. Internal reset chords have endpoints separated by two cycle edges. The resets separate the variable and clause occurrence sections at the two boundaries, so no occurrence chord joins consecutive cycle sites. This makes the graph simple and cubic. Odd total reference charge can always be arranged by using the alternative last gate of one forward reset if necessary. This switch has no effect on the permitted cycle values.

For the reference formula, summing the parity equations gives a contradiction. Delete a clause at vertex $a$ and fix its three incident bits to the unique triple forbidden by that clause. This violates the original parity at $a$ and satisfies all three surviving clauses there. The graph minus $a$ is connected by its Hamiltonian cycle, and the adjusted charges there now sum to zero. Solving the remaining vertex equations on a spanning tree extends the assignment. These two parity facts are standard for Tseitin formulas. The [two-edge growth construction](width-of-clause-splitting-histories.md) also reaches the reference layouts from the eight clauses on three names. [Itsykson, Riazanov and Smirnov, Lemmas 2.12 and 2.18](https://drops.dagstuhl.de/storage/00lipics/lipics-vol236-sat2022/LIPIcs.SAT.2022.6/LIPIcs.SAT.2022.6.pdf#page=8)

## Edit density and encoding length

Insert four pure parity sites on any cycle edge, with private chords $h,g,h,g$. All four charges are zero, so the successive cycle values XOR with $h,g,h,g$ and the right endpoint copies the incoming value. These sites preserve satisfiability and odd total reference charge. With $S=4v+14m$ original sites and $r$ such insertions the fraction of edited sites is $S/(S+4r)$. For each fixed $0<\rho\le1$, taking $r=\lceil S(1/\rho-1)/4\rceil$ gives the claimed bound. The graph remains simple and Hamiltonian.

For an $n$-bit proper ASCII input, keep distinct ordered triples of signed variable names, ignoring exact duplicate clauses. A fixed-alphabet trie on their normalized token strings with separators performs this step in $O(n)$ operations. A second digit trie interns variable names, including long decimal identifiers, in linear total work. Each retained ordered triple has a different source token string. At most $O(256^d)$ strings have fewer than $d$ bytes. Taking $d$ a small constant times $\log(m+1)$ shows that the retained strings account for $\Omega(m\log(m+1))$ input bits. There are at most $3m$ used names. Bucket the occurrences by name and polarity in two passes. Unused declared names need no sites. An input with zero clauses can map to the constructed output of any fixed satisfiable proper 3-CNF.

Number all $3(S+4r)/2$ edge variables consecutively. The $4(S+4r)$ output clauses require $O_\rho(m\log(m+1))=O_\rho(n)$ bits including their dense decimal identifiers. Build decimal strings for consecutive integers by incrementing and copying a decimal counter, then look up the appropriate strings when emitting the clauses. This also takes $O_\rho(n)$ word operations without division. In a fixed-length sign field, use an ASCII space before a positive literal and a minus before a negative one. Each changed sign then alters precisely one byte of a pair of equal-length files. For a DIMACS parser permitting all six ASCII whitespace characters, carriage return (0x0d) and minus (0x2d) differ in just one bit and can serve as the two sign slots. [Lammich's verified DIMACS grammar](https://www21.in.tum.de/~lammich/isabelle_llvm/IJCAR2024.pdf)

The resulting decision promise is NP-hard by a linear-time reduction and has ordinary assignments as witnesses for satisfiability. Therefore an $O(n)$ solver on the promise would give an $O(n)$ solver for general proper 3-SAT on this RAM. The same implication holds for each fixed exponent $c\ge1$ in place of one. A RAM running-time exclusion on this promise remains open.
