# Certifying a long RAM observation from a short prefix

**Research journal, 2026-11-24.** A deterministic machine can have a long trajectory even when one output bit follows a short recurrence. The initialized run supplies a candidate predictor. One explicit SAT query can certify it on a RAM with arbitrary initial work memory. The test even succeeds when different starting states obey incompatible recurrences. A late change in a literal acceptance bit gives a sharp obstruction.

## Prediction and verification

Fix a total deterministic transition F, a one-bit observation g, and an initialized state s₀. Make halting states absorbing. Write aₜ(s)=g(Fᵗ(s)) and let S be the left shift on one-sided binary sequences. A monic q over GF(2) of degree ℓ annihilates a sequence when q(S)a=0 at all positions t≥0. It then determines the next bit from ℓ preceding bits. The polynomial 1 annihilates precisely the zero sequence.

Given a width r≥1, simulate the initialized run to collect its first 2r observed bits. Apply Berlekamp–Massey to find the shortest recurrence fitting this prefix. If its degree exceeds r, the test fails at this width. Otherwise let q be the fitted monic polynomial. If the initialized orbit is known to have order at most r, this already predicts its entire future. Indeed, two extensions satisfying monic recurrences of degrees at most r have a difference annihilated by the product of the two polynomials. The first 2r zero differences then propagate. This is ordinary finite-sequence synthesis. [Massey, 1969](https://crypto.stanford.edu/~mironov/cs359/massey.pdf)

Without a promise on the initialized orbit, define the discrepancies eⱼ(s)=(q(S)a(s))ⱼ. Ask SAT for a state s satisfying

    e₀(s)=⋯=eᵣ₋₁(s)=0   and   eᵣ(s)=1.

The first r discrepancies at s₀ vanish because ℓ≤r and the first 2r bits fit q. If the query is UNSAT, every window of r zero discrepancies is followed by another zero. Applying this implication successively to Fᵗ(s₀) proves the prediction for every future time. A satisfying answer leaves the initialized run undecided because the counterexample may lie on another orbit. This specializes SAT-based induction to a predictor learned from one trajectory. [Sheeran, Singh and Stålmarck](https://www.di.ens.fr/~pouzet/cours/mpri/sheeran-FMCAD00.pdf)

**Completeness under orbit-dependent recurrences.** Suppose every starting state s has *some* monic annihilator pₛ of degree at most r for its own observation stream. The fit at s₀ succeeds. For every s, pₛ(S)e(s)=q(S)pₛ(S)a(s)=0. Such a discrepancy stream cannot have r initial zeros followed by a one. Thus the one query always certifies the initialized prediction. More generally, if pₛ is the minimal annihilator, then pₛ/gcd(pₛ,q) annihilates the discrepancies. When these quotient degrees are bounded by h≥1 and the initialized first h discrepancies vanish, a window of h suffices. The proof only uses the absence of a zero window followed by a one, so the SAT test can also succeed outside these degree bounds.

The distinction between a common recurrence and orbit-dependent recurrences can be exponential. Let an immutable r-bit parameter describe any monic degree-r feedback polynomial p, and let r further bits be the initial shift register. Every run obeys its own p. For fixed p the first r observations are arbitrary across register initializations, so no nonzero polynomial of smaller degree annihilates all these streams. Dividing a putative common annihilator by p shows that its remainder must vanish. Across all parameters the minimal common annihilator is therefore the least common multiple of all monic degree-r polynomials. Its exact value is the product of X^(2ʲ)−X for 1≤j≤r. Indeed an irreducible of degree d has maximum exponent ⌊r/d⌋ among monic degree-r polynomials, and occurs once in each squarefree factor X^(2ʲ)−X with d dividing j. The exact common order is 2^(r+1)−2, while the initialized certification succeeds at width r.

## The cost with unrestricted memory

For a fixed word-RAM program use w-bit addresses and data words, a constant number of word accesses per step, and word operations with bit circuits of size poly(w). Take g to be a designated register bit or include the charged operations needed to read it. The SAT query uses observations 0 through r+ℓ, hence at most 2r+1 observations. Guess the initial registers and memory events for this window. Check instruction semantics in chronological order. Sort the events by address and time, breaking within-instruction ties by the order of accesses. For each address the initial work word is arbitrary, subsequent reads must return the most recent value, and writes update it. Every consistent list extends to an initial memory by setting untouched cells arbitrarily. For a fixed read-only input x, include its addressed words once in the sorted consistency check and enforce the machine's convention outside the input range. This charges |x| bits and imposes no bound on the number of work cells occupied before the window. The initializing simulation still starts with the prescribed work memory. [RAM transcript simulation](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

All r+1 discrepancies are coefficients of one product of the observed word polynomial and the reversed q. Pack their binary coefficients into digits in a power-of-two base greater than 2r+1. Ordinary integer multiplication then preserves the integer coefficient sums without carries, and the parity of each digit gives the required convolution bit. The packed inputs have O(r log(r+2)) bits. Fast integer multiplication, sorting and quasilinear Boolean encodings give a single explicit SAT instance of Õ((|x|+r+1) poly(w)) bits for a fixed program. Here Õ suppresses logarithmic factors in these parameters. Under deterministic SAT time O(mᵈ), the decision cost is this encoded length to the power d. The preliminary recurrence synthesis uses O(r²) bit operations, and the jump to time T can use O(r² log(T+2)) more by schoolbook repeated squaring of X modulo q and evaluation on the initial ℓ bits. The zero sequence is handled directly. These costs also apply when the simulated RAM's words are wider than the SAT solver's words because the window charges polynomially for w. [Schönhage and Strassen](https://doi.org/10.1007/BF02242355) · [Quasilinear reductions](https://arxiv.org/abs/1311.3171)

## Where the clock argument fails

If an acceptance flag changes from zero to one for the first time at j and remains one, its minimal forward annihilator is Xʲ(X+1). Indeed any annihilator must vanish at 1 by inspecting the constant tail. Applying S+1 turns the stream into the single impulse at j−1 when j>0. An impulse at i has minimal annihilator X^(i+1), since its shifts through i give independent unit vectors. The constant-one case j=0 gives X+1. Thus a literal late acceptance has order j+1 even when the machine changes the flag only once. For an all-zero run the fitted q=1 can likewise fail the universal test whenever a different admitted starting state has a sufficiently delayed pulse.

Even one exception with zero asymptotic density can conceal a PSPACE-complete question. Simulate a polynomial-space decider with a polynomial-bit countdown ensuring a delay of at least 2ᵏ before acceptance can be reported. On acceptance emit a one for a single step and enter a zero sink. On rejection enter the same sink without a pulse. The promised initialized observation is either identically zero or has a single one after the delay. Determining which holds is PSPACE-hard by construction and lies in PSPACE by following the succinct finite transition for at most its number of configurations. The initialized orders are zero and at least 2ᵏ+1 respectively. This concerns succession of succinct configurations.

A variant supplies two short candidate decoders and guarantees that one is exact. For a decider with at most 2ˢ configurations and absorbing halts, set B=2ˢ. Choose polynomially many disjoint one-hot rings of distinct odd prime lengths, with total length poly(s) and product P>B+3, for example the first s+3 odd primes. Rotate each ring one slot per step. From their specified aligned origins the phase is t modulo P by the Chinese remainder theorem. Equality to any specified phase uses one designated bit from each ring. Initialize the computation at phase zero and reset it on the transition from phase P−1 to zero. At phase B emit the accept bit and at B+1 emit the reject bit, with zero output elsewhere. The computation has halted by B. The true stream matches exactly one of the two supplied decoders that pulse at phase B or B+1 each period. Choosing the matching decoder remains PSPACE-complete by the same simulation and finite-state upper bound. Even linear advancement of the phase and a two-element list of exact-or-wrong candidates leave a correctness question.

A hierarchy argument would need a representation of its answer admitting the certified short window at a cost strictly below its clock, with a uniform way to read the answer from the predicted value. The literal latched flag fails the required width on late accepting runs. Fast SAT verifies the local implication when it holds, but supplies no proof that an alternative representation meeting the clock exists. No unrestricted SAT lower bound or priority claim follows.

[The Lean proof](../lean/ObservableRecurrence.lean) checks propagation from the forbidden discrepancy window, uniqueness under a fixed finite-window recurrence, the late first-pulse bound for homogeneous binary recurrences, and stabilization of an eventually constant periodic tail. The reductions and the complexity estimates are manuscript arguments.
