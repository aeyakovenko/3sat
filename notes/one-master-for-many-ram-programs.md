# One common SAT database for exponentially many clocked RAM programs

There is a family of proper ASCII 3-CNFs of $N=\Theta(d\log d)$ bits with $2d$ designated native words. For each choice of the data $X$ there is a master and a finite test suite: replace **any one** designated word by a query about an encoded bit with a proposed sign. At a fixed position and query the two signs differ in one physical bit and have opposite verdicts.

Fix one deterministic aligned logarithmic-word RAM with finitely many registers, a sufficiently large fixed width coefficient, and separate single-word loads and stores. An instruction observes at most one original word, and a load does not also perform a memory store. Elapsed time is external to the machine; every component of the controller available to the program is included in its state. Fix any finite deadline $T(N)$, for example $C N$, $C N^2$ or $C N^3$. There exist constants $c,c_0>0$ such that for all sufficiently large even $d$ and all integers $0\le t\le c_0 d$ the following holds. Take a collection of $L$ deterministic programs. For each program prescribe a catalog of at most $2^s$ complete private states at its last original data load. The catalogs may depend on the entire public layout and on the program. If
$$
                    s+\log_2 L\ \le\ cN/(t+1),
$$
then all but a $2^{-\Omega(N/(t+1))}$ fraction of the master databases $X$ satisfy the following alternative **simultaneously for every program**.

* It gives a wrong answer or misses the deadline on the master or on some file in this master's test suite.
* Its master prefix reaches a state outside its catalog at the issue of its last new data load.
* On more than three quarters of the query indices, **both** signed files at that actual last address require more than $t$ distinct original data columns to be read again after the differing load.

The hard indices and last address may differ between programs. All files involved are complete ordinary inputs. A program can be incorrect on every other database. In particular one can take **all** programs with binary descriptions of at most $C$ bits, using $L<2^{C+1}$. With $t$ fixed this handles code budgets linear in $N$ with a sufficiently small leading constant. With $t$ an appropriately small constant times $N/\log N$, it still covers polynomially many programs with logarithmic catalog descriptions. No space cap is imposed on a candidate.

## Packing logarithmically many independent rows into a formula

Take $m=d/2$. Choose a generator $G$ for a binary linear code of length $d$, dimension $m$ and minimum distance at least $\delta d$ for an absolute $\delta>0$, with an $O(d)$-size linear encoder. Such a code exists at every sufficiently large even $d$. Write $B=G^{\mathsf T}$. Every nonempty XOR of distinct columns of $B$ is a nonzero codeword, hence has weight at least $\delta d$. A linear circuit for the row-vector map $x\mapsto xB$ of size $O(d)$ follows by transposing the encoder: in reverse topological order accumulate the output coefficients at each vertex and pass them to its two XOR operands. Each original wire costs at most a constant number of additions. Fixed circuits are placed in the input's public region. The mathematical construction can choose a successful code nonuniformly per dimension; finite search of linear circuits and minimum distance is another way to specify it. [Brehm and Resch, Theorem 2 and its XOR encoders](https://drops.dagstuhl.de/storage/00lipics/lipics-vol362-itcs2026/html/LIPIcs.ITCS.2026.28/LIPIcs.ITCS.2026.28.html)

Let $a$ be a power of two within constant factors of $\log_2 d$, chosen at most $(\log_2 d)/8$. The database consists of **all** $ad$ independent bits of a uniform $a$-by-$d$ matrix $X$. The query at $(i,j)$ asks whether $(XB)_{ij}=e$. Public clauses choose exactly one row index $i$, with row-leaf flags $R_i$. For every possible $a$-bit column mask $\mu$ define a library bit $S_\mu$ equal to the bit $\mu_i$ in the selected row. One conditional constraint for each row leaf and mask enforces this. For inner column $h$ the private data packet contains the two clauses enforcing $u_h=S_{X_{:,h}}$, padded to proper ternaries. Put **two identical copies** of that packet at adjacent public positions belonging to $h$. Evaluate $uB$ by the public XOR circuit. For each output $j$ give its bit and its complement distinct names $O_{j,1},O_{j,0}$ fixed to the indicated values. A query packet replaces one entire data word with two padded pins, $R_i$ and $O_{j,e}$. The surviving twin still imposes the original column value.

Use three public false anchors forced by the seven proper triples excluding every nonzero anchor pattern. Equality, negation and XOR gates use distinct names and proper clauses after padding or simplification. Allocate each signed output pair decimal IDs with a common prefix and final digits 2 and 3. Their query files differ exactly at the low bit of one ASCII digit. Give the mask library ordinary dense names and decode the mask by its ordinal, or use a reserved prefix and the mask digits. Either choice has $O(\log d)$ bits per name. The $a2^a$ library constraints, row and output selectors, gates and data require $O(d)$ clauses and names. If any names in the declared range would otherwise be free, pin them to zero in the public region. All identifiers can be drawn from an $O(d)$ interval, including the signed pairs. There is one model per row on the master and one model on an accepted query. Each designated packet fits in one aligned word for the stated coefficient. Pack the public records with fixed-width fields, align the private region, and use public whitespace to make the total length a prescribed $\Theta(d\log d)$. This is within a constant factor of the $ad$ independent data bits. Public gate descriptions and all parts of the private input have fixed locations. [Earlier two-clause signed queries](literal-profiles-at-the-last-clause.md) · [Earlier physical erasure construction](parity-recovery-for-a-common-last-sat-word.md)

A program passing the whole suite for a particular $X$ must read every marked word on its master by the deadline. Otherwise placing a query of either sign at an unobserved slot gives the same execution through halt or timeout. A blind store to a previously unread slot likewise makes its two replacements indistinguishable. The issue of the last load, its address and all observations before it are therefore common to every signed replacement at that slot. The returned word supplies the query and its sign. Use a complete private state consisting of the registers, controller (including the pending address), and work memory. With writable initial input bank include the overlay of previously overwritten addresses and their values. Original input and fixed public data are external. A hardware operation observing an old word before writing it counts as a read.

## Counting correct continuations, including for programs that fail elsewhere

Choose independent uniform subsets $K\subseteq[d]$ and $J\subseteq[m]$ of sizes
$$
 k=\lfloor d/(2(t+1))\rfloor,\qquad
 \ell=\lfloor \eta k\rfloor,\qquad
 0<\eta<\min(1/4,\delta/(4\ln2)).
$$
Erase the columns in $K$ from the decoder's copy of $X$. Inspect output positions in $[a]\times J$, of which there are $u=a\ell$. With sufficiently small $c_0$, $k$ is large enough that $\ell\ge1$ and $u=\Theta(N/(t+1))$. For each fixed $J$, a rank failure of $B_{K,J}$ requires a nonzero sum of those columns to vanish on $K$. Its probability is at most $2^\ell(1-\delta)^k\le1/32$ by the code distance. For any good $K,J$ and fixed visible columns of $X$, the $u$ selected product bits are independent uniform bits. This is rowwise surjectivity of a binary matrix of rank $\ell$.

Fix a purported private state $z$ from one program's catalog. For every tested position simulate the two sign choices from $z$, abandoning an execution when it needs an unknown original column and truncating after $T(N)$ steps. Private stores and all inherited state in $z$ are available, including overwritten initial cells. If an execution halts, its tag and verdict predict an output bit; break ties by a fixed rule. Predictions and the positions on which any are made depend only on the visible data, $K,J,z$ and public information. On any database where $z$ is genuine and the program passes the suite, all predictions are correct. Even for a forged state, on a good trial giving at least $h$ predictions the probability that **all** predictions are correct is at most $2^{-h}$, conditional on the visible data. The predicted set can depend on $z$; it was already fixed before the erased columns were filled. Summing over the catalog costs at most $2^s$. This argument tests actual program behavior and does not assume global correctness.

Suppose a particular $X$ passes the suite, uses a catalog state, and at least one quarter of its $am$ pairs have one sign reading at most $t$ distinct original columns after the last load. For each such pair select that true suffix. Its queried output column belongs to $J$ with probability $\ell/m$. With probability at least $1-kt/d\ge1/2$ its at most $t$ input columns all avoid $K$. On that event the decoder from the genuine state can supply its entire suffix, hence predicts a correct bit. Its expected number of predictions over $K,J$ is at least $u/8$. The number is at most $u$. Rank failures contribute at most $u/32$ to that expectation. Thus with probability at least $1/32$ the trial has full rank and at least $u/16$ correct predictions, with every prediction made correct. Combining the two counts bounds the exceptional fraction of $X$ by
$$
                          32\,L\,2^{\,s-u/16}.
$$
Choose the constant in the theorem with strict slack. The same estimate applies to a correctness-only portfolio with no time restriction: for finite dimension and finitely many correct terminating candidates use the largest running time on the finite family as the analytical cap.

## Counting old work words, even in a large workspace

For a correct solver, choose a shorter summary $z$ fixing its pending controller and address. For each inherited word actually observed on a particular suffix, suppose its entire value on that input can be certified by pinning at most $g$ source columns among masters with the same $z$. Include original input words ($g\ge1$), exclude the supplied query, and charge an address when its value is observed before the first suffix write there. A conditional certificate can depend on the address, the master and the observed path. The catalog limits only the number of summary values, not the number of stored cells.

If either sign uses at most $q$ such distinct old addresses, the union of its word certificates pins at most $gq$ columns. Equality of those columns and the summary forces every reply on the chosen continuation, hence its output bit across the fiber. In the density proof, replace the clocked predictor with an unbounded observer who knows $z$ and all unerased columns; it predicts exactly those entries constant on that nonempty fiber. No knowledge of the per-word certificates is required. The same counting bound applies with $t=gq$. In particular one may have arbitrarily many cached copies or functions of individual columns, and both signed continuations still need more than $q$ old native words on most indices unless the chosen summary escapes its catalog. This version uses correctness across each summary fiber. The full-state, original-word statement above also covered programs passing only the local test suite. [Support-union replay proof](erased-columns-at-the-last-matrix-entry.md)

Revealing part of a systematic input in addition to a small stored summary has precedents in data-structure lower bounds. Here the queried word arrives at a particular SAT program's last new data load, and the same database serves a finite collection of programs that may be incorrect elsewhere. Priority for this combination is unestablished. [Garg, He, Li, Papakonstantinou and Yang, *Systematic Data Structure Lower Bounds via the Query-With-Sketch Model*](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2026.41)

## A successor preserving both old data and old answers

Let a previous master have parameters $(a_0,d_0,m_0)$ and matrix $X_0$. Its answer matrix is $Y_0=X_0B_0$. At a larger even dimension $d'$ take $a'\ge a_0$, $m'\ge m_0$, and $\delta d'>d_0$. Prescribe the entire upper-left $a_0$-by-$d_0$ data rectangle to equal $X_0$. Also prescribe every answer in the upper-left $a_0$-by-$m_0$ output rectangle to equal $Y_0$. The columns of $B'$ indexed by those $m_0$ directions remain linearly independent after deleting the first $d_0$ positions: a dependence there would give a nonzero codeword supported on at most $d_0$ positions. The still-free entries of each old row can therefore realize every requested output vector. The restrictions cut out a nonempty affine subspace of codimension $a_0(d_0+m_0)$ in the new raw input bits.

If $32 L'2^{s'-u'/16}<2^{-a_0(d_0+m_0)}$, where $u'$ is the new sampled output count, some point of that affine subspace passes the new simultaneous alternative. This allows another program, an increased time multiplier, or a much larger finite program collection at each stage. For a fixed reread threshold $t$, a sufficiently large constant factor in dimension suffices to extend a previous master and add one program to a fixed-code-budget sequence with slack. More generally use the explicit inequality to choose the next size. Black-box enumeration is finite for a computable clock and a decidable catalog, for example a fixed bound on touched writable cells. This successor preserves every old data entry and signed-query verdict. The physical file length, slot addresses and native execution histories can change.

## From states to stores and a test of the accumulation argument

For a fixed ISA with $O(1)$ registers and $w=\Theta(\log N)$ bits per word, the private states with at most $b$ written addresses at the cut have descriptions of $O((b+1)w+\log(|P|+2))$ bits: list the sorted address/value pairs, including overwritten input words, and the controller. A finite set of programs with code length at most $C$ has fewer than $2^{C+1}$ members. On one master the alternatives therefore apply simultaneously if
$$
              C+(b+1)\log N\ \le\ c' N/(t+1)
$$
for a sufficiently small constant. The code-length term absorbs the program-dependent control index. For $t=\lfloor\sqrt d\rfloor$ this yields, on a common database and for binary programs up to $c'\sqrt d\log d$ bits after adjusting constants, either a failed test, $\Omega(\sqrt d)$ distinct prefix stores, or more than $\lfloor\sqrt d\rfloor$ genuine original-column rereads on both runs of most pairs. With the separate single-word instructions specified above, this adds $\Omega(\sqrt d)$ instructions to the $2d$ mandatory discoveries on a pair. The separate resource counts are stronger than that additive bound.

The same family has a globally correct solver using $O(d)=O(N/\log N)$ native instructions on the entire suite. Parse and validate the public region. The public layout can give the XOR gates in topological order; validate the canonical constant number of gate clauses per record and allow any well-formed such circuit. The linear code's distance is only used in the lower bound. Use fixed-width aligned public fields with a fixed number of records per gate, direct-index dense names and a constant number of chunk-table lookups to parse or emit a word, as in the [packed decoder](native-product-time-from-last-packet-clocks.md). Build the $O(d)$ expected records in that time, including decoder and anchor constraints. Parsing/preparing the $o(d)$ library can even spend a logarithmic factor there. Fixed public header counts can encode the layout parameters (for instance declare exactly $K_0d$ names for a fixed integer $K_0$, dedicate disjoint name intervals, pin spare names and pad a fixed linear number of gate slots). Reject the fast path on malformed layout; preserve the original input for a complete general SAT fallback.

Scan the duplicated data in its public order. Check the keys, all the constant bits, matching data copies when both are present, and any supplied signed query. An intact copy is always available in the measured cases. Each column mask contains the data of **all $a$ rows** in one word. At each gate of the transposed encoder, a single native XOR computes its values on those rows simultaneously. This computes all $am$ output bits in $O(d)$ time. One implementation does this before loading the second copy of the final column (keeping its first copy); it can answer a late query in constant time from its private output table. A second implementation validates the paired packets in a first scan and retains only $O(1)$ data-dependent words on the unqueried master. On a late query it reads one copy of each column again and evaluates the same circuit, still in $O(d)$ total time. Public parsing workspace can depend on the public matrix. During the private scan, reuse a fixed number of temporary words for the two adjacent copies and their comparison.

The same computation checks up to $d$ signed queries for a **common row** placed instead of copies at distinct columns: the conjunction of their pins requires precisely that every stated sign match that row's output. It takes $O(d)$ steps including the scan of the whole input. This identifies where an attempted direct sum fails. Many independent queried outputs can each require nearly a fresh scan after a low-information cut. One pass evaluating the packed XOR circuit answers them together. In the finite audit all 336 prescribed pairs of old rectangles had the predicted number of extensions. On 4,864 multi-query files, direct SAT model counts agreed with the packed evaluator. Lean checks the finite incidence argument, the common survivor inside a prescribed set, and the preservation of old answers given surjectivity on the fresh columns. The code-distance, sampling and physical RAM arguments are manuscript proofs.

Transferring these per-query costs to a superlinear elapsed clock on a single SAT run needs an additional argument. Neither the unrestricted linear milestone nor the quadratic or cubic target follows.
