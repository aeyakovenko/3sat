# Indexed memory descriptions on every rejecting member of a prescribed family

Fix a correct deterministic SAT solver on the journal's logarithmic-word RAM with worst-case time $O(NL^a)$ on explicit formulas of $N$ bits, with $L$ of order $\log N$. Fix a word decoder of time $O(L^d)$ which gets the *physical formula*, its advice, a checkpoint index and a work address. The exponents are fixed nonnegative integers. At each scale there is a single 3-CNF template indexed by $K$ raw bits with the following properties.

* Its SAT verdict can be prescribed to be **exactly even parity**. Every one of the $2^{K-1}$ odd strings gives an unsatisfiable formula on which the actual solver has hard indexed snapshots. Here $K=N/\operatorname{polylog}N$. A different choice of guard below also gives hard proof queries and native memory retrieval on common runs.
* Pad each actual solver run to its valid deadline and divide it into $P=\lceil L^{2a+d+8}\rceil$ intervals of equal length up to rounding. For every odd string and **every permutation moving at most** $cN/L^{a+5}$ of the clause positions, decoding all internal snapshots of the solver on that reordered formula needs $\Omega(N/L^{a+4})$ bits of shared advice. To decode each snapshot independently, at least one needs $\Omega(N/L^{3a+d+12})$ bits. Advice is chosen after the entire run. The permutation and hard checkpoint may depend on the payload. The directory is included in the calculation below.
* The identity order admits $P=\lceil L^{2a+d+7}\rceil$ with the packed constant-time syntax generator. This yields the single-snapshot exponent $3a+d+11$ of the earlier one-input statement throughout the parity family. One can include both grids in a single certificate checker by guessing a mode.

The claim concerns a globally correct solver with the stated time bound. A program given the promise that its input belongs to this particular template can calculate the promised verdict by a parity scan. The family depends on the globally correct solver and decoder. Unrestricted workspace is allowed. [Indexed checkpoint replay and its diagonal](solver-snapshot-descriptions.md) · [Packed RAM model and local syntax](packed-band-transfer.md)

## Adding a bounded witness to ordinary SAT syntax

Put $L=\max(2,\lceil\log_2(K+2)\rceil)$, with $K$ growing through powers of two for the parity example. Choose an integer $j>a+3$ and a guest deadline $J=K L^j$. Build a uniform formula on public program text $v$, scale and raw input $x$. It accepts if the parity guard accepts or a fixed universal nondeterministic interpreter sees program $v$ signal on $(v,K,x)$ within $J$ steps. The program text is data to the constructor. The ordinary bounded-computation compiler for the interpreter is independent of what program it will run. Build both branches with shared raw input variables and one private sign pin per raw bit. The constant-time local clause generator uses affine field offsets, the usual routing indices and the public bits. The parity tree and disjunction have elementary constant-time indexed layouts. Pad to a fixed $N=\Theta(JL^3)$ bits. A formula word can be served with constant native cost after polylogarithmic setup. The host builds the small layout tables once and gives every emulated decoder invocation an immutable view of them, separate from its freshly blank private scratch. Raw bits can be physically separated by distances of at least one input word, using fixed tautological clauses. This costs $O(KL)$ bits. [Construction of the bounded interpreter](packed-band-transfer.md)

Choose $v$ to be the following *one* fixed verifier. Given its supplied text, scale and raw input, it generates words of exactly the formula above. Guess a clause permutation in a finite dictionary and check the dictionary. The nonfixed positions are a strictly increasing sequence of indices, each with an image index. Check the image indices form a permutation of the same set by looking them up and marking them in a fresh dictionary. Outside the set the permutation acts as identity. Range checks, duplicate checks and lookup cost $O(1+uL)$ word operations for $u$ moved positions. The representation takes $O(1+uL)$ bits up to a length header of $O(L)$. Choose the direction so that querying a new clause position looks up its corresponding old clause. Each reordered formula word therefore takes $O(L)$ operations to serve. Word packing at the first and last clause of a load is handled by extracting the relevant constant number of fixed-stride clause records. No actual formula, checkpoint list or permutation must be produced when constructing the *outer* formula's physical bits.

Guess the shared memory description and the $O(P)$ controller words for the real solver on this reordered formula. Test it by deciding one ordinary defect-SAT instance with the assumed solver. A defect selects an interval and a legal address. Replay the native solver using a fresh local write table and the decoded start array. Check the controller and the selected coordinate of the end array, including an address the replay never used. At time zero use the genuine state. Require rejection at the terminal end. All decoders and guest runs use clocks and fresh scratch. Each purported boundary represents a total array on every syntactically legal certificate. In the absence of a defect, induction from the true beginning identifies the trajectory and proves a genuine rejection. Conversely a correct shared description and genuine controllers pass every challenge. For the independent-description version, pack all descriptions and their $O(PL)$-bit offset directory into one string. The wrapper forwards a substring as an indexed view at constant overhead. Use this wrapper explicitly as one additional mode of $v$. [Address-challenge semantics](../lean/SolverSnapshotReplay.lean)

If the interpreter ever sees a timely signal, the physical formula is satisfiable by its interpreter branch. The same signal certifies that the correct solver rejected a clause permutation of this formula, which is unsatisfiable. This contradiction holds for **each raw input individually**, whatever the parity. Therefore the interpreter branch is always false with this fixed text. The formula has precisely the prescribed guard verdict. The entire argument also applies to any other uniformly constructed guard of the appropriate size and generation cost, even a guard testing a claim about another monitor for this very formula. This use of disjunction needs the checkpoint verifier to be sound on every raw input. It places no promise on the monitor's satisfiable runs.

## Paying for the arbitrary raw data and permutation

Let $s$ be the combined length in bits of the permutation dictionary and snapshot advice. Besides the shared public text and headers, a defect search sees $m=O(1+P+(K+s)/L)$ public words. The physical formula is accessed virtually by both the solver being replayed and the decoder. Its cost per virtual word is $O(L^g)$, with $g=1$ for the permutation and $g=0$ for the identity. Its bounded defect-search clock is
$$
 R=O((T/P+1)L^{d+g}+\operatorname{poly}(L)),\qquad T=O(NL^a).
$$
The materialized defect formula has $O(RL^3+mL^2+\operatorname{poly}(L))$ bits and takes time within the same bound to construct on the host. Check its verdict with the assumed solver. Including the guesses, permutation validation and the fixed interpreter overhead, a successful branch costs
$$
 O\big((T/P+1)L^{a+d+g+3}+P L^{a+2}+(K+s)L^{a+1}+\operatorname{poly}(L)\big).
$$
With $P=\lceil L^{2a+d+g+7}\rceil$, the first term is $O(J/L)$. The raw-input contribution is $o(J)$, since $j>a+3$. All polynomial-in-$L$ terms are $o(J)$. Thus if $s\le c_1 J/L^{a+1}$ for a sufficiently small fixed $c_1>0$, an honest branch signals inside the deadline. This yields a combined lower bound $\Omega(J/L^{a+1})=\Omega(N/L^{a+4})$ on each rejecting member. For the stated number of moved clauses their dictionary consumes at most half this threshold by choosing $c$ small. The controller and directory terms are negligible at all large scales. Dividing the remaining total by $P$ proves the single-snapshot bound. The width constant of the host is chosen in advance for finitely many simulations at polynomial address ranges. ## Indexed descriptions on the same rejecting runs as the memory cuts

Use the parity, code-neighborhood and shifted empirical tests in the [noisy dual-code construction](noisy-dual-solver-cuts.md) as the guard. Its monitor must now serve the augmented formula. Use one public text containing both the actual-rejection and the certificate-checking programs. A fixed deterministic dispatcher serves the first interpreter and a fixed nondeterministic dispatcher serves the second. Each guest receives the common public text and its mode. The pair language and universal bounded-computation templates are fixed before inserting that text. They never run either guest while generating syntax. The actual rejection monitor has the earlier $2^k$ deadline. The certificate interpreter has the smaller deadline $J=K L^j$. Here $\log K=\Theta(k)$. First fix the empirical row algorithm and the raw-symbol count as in the original construction. Choose the fixed $j$ large enough that the old physical template and its varying-size arrays fit within $O(JL^3)$ bits and $K L^{a+1}=o(J)$. Reading a clause of this additional interpreter needs only length fields of $O(k)$ bits, fixed program data, and at most a constant number of raw input pins. Increasing $j$ changes constants in these length fields. Raw bits used by any branch are shared wires bound once at their private pins. A virtual word in the combined layout takes at most $O(L^{g_0})$ operations after polylogarithmic setup for a fixed $g_0$. Use $g=g_0$ or $g_0+1$ in the corresponding checkpoint grid.

The new certificate branch is identically false. Its presence changes the formula seen by the rejection monitor. The earlier proof of rarity of empirical acceptance is uniform for precisely this change. Soundness still holds throughout the fixed-radius code neighborhood, every empirical row still makes only polynomially many raw-symbol probes, and the moments are recomputed for the monitor of the *augmented* formula. The sparse Walsh calculation depends only on the remaining satisfiable disjuncts and the single-pin layout. Consequently, under the near-linear SAT hypothesis, almost every odd raw input gives one actual rejecting execution with all three properties. Its indexed snapshots have the lower bound above. Its discovery intervals incur the actual rereads from the noisy dual-code argument. Short proof descriptions for the actual monitor fail the fresh verifier tests specified there. On every rejecting member the indexed bound survives the stated clause reorderings. The proof-query and discovery-order assertions here concern the original monitored ordering. The bounds use different checkpoints and need not pick the same instruction.

At parity alone the promised sign can be computed in linear time. A native solver can also produce difficult memory snapshots during a linear number of stores and loads. The missing implication is an upper bound on description length or a lower bound on additional elapsed work for a globally correct fast solver. The finite semantic disjunction and directory argument are independent of the quantitative compiler, which is a manuscript proof. Priority for the family and permutation assertion has not been established.

A candidate contradiction is to modify a fast solver so that it recognizes its own parity template and immediately returns the promised parity. For a template built from a previously verified solver, that modification preserves correctness on the template. Applying it to the modified program's *own* template needs a new correctness proof. On an odd payload a cheaply certified rejecting shortcut activates the interpreter disjunct, making that formula satisfiable. Even an induction proving the defect solver correct on every strictly shorter input leaves this problem at the current input length. This pinpoints the circular premise in trying to turn the prescribed truth table into an unrestricted separation. [Lean semantic implication and independent rows](../lean/GuardedIndexedSnapshots.lean)

For the parity template there is also a globally correct comparison solver. Fix a previously verified solver $S$ and hardwire its template generator in a *different* solver. Test the fixed layout length (use a monotonically padded length for the powers of two), scan the syntax masking just the private pin signs, and take parity of those signs. Compare every other bit with its generated value. On a match return the parity verdict proved above; otherwise call $S$. The constant-time template word generator and its polylogarithmic setup give an $O(N)$-time scan using polylogarithmic workspace. This comparison solver remains near-linear if $S$ was, and it has short snapshots on the whole fixed family in its original ordering. It shows concretely why transferring hardness to a single prescribed family independent of the monitored solver would require a different argument.
