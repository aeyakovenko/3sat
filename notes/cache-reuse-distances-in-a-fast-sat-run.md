# A fast SAT solver must revisit many addresses after touching many different words

Let $A$ be a correct deterministic SAT solver on a logarithmic-word RAM with read-only random-access input and initially zero work memory. On one genuine run and for each work address $a$, consider its reads returning a nonzero word. For each such read count the **distinct other work addresses** touched strictly since the most recent preceding touch of $a$. A touch can be a read or a write. Such a predecessor always exists, since work memory starts at zero. Let $D(a)$ be the maximum of these counts, with default zero. Define
$$
 J=\max\{h:\text{at least }h\text{ distinct addresses }a\text{ have }D(a)\ge h\}.
$$
Split an instruction with multiple work accesses into its fixed ordered memory events. The count uses the actual guest addresses, including bank tags.

If $A$ takes $O(N\log^q N)$ steps on ordinary DIMACS 3-SAT, for any fixed nonnegative integer $q$, then on each verdict separately
$$
 J\ \notin\ O(N/\log^{3q+11}N).
$$
Here $N$ is encoded bit length, and the formula inputs for the two verdicts can differ. There is no space, address-order or input-pass restriction on $A$. The same conclusion holds in the packed binary encoding. At polynomial clocks $N^{c+o(1)}$ a simultaneous cap $J\le N^{e+o(1)}$ is excluded when $1\le c$, $0\le e\le c$ and $c(c+e)<2$. The root simulation and its hierarchy contradiction are the ones in the [single-address monitor theorem](fast-sat-must-retrieve-nonzero-work-words.md). That proof is a manuscript argument. This application uses a fixed stateful read predictor.

## The predictor

Give the predictor $K=k+1$ slots. Maintain in recency order the last $K$ distinct work addresses touched and their latest observed values. Before a read predict the cached value on a hit and zero on a miss. After a read, update with the reply the simulated CPU received. After a store, update with the assigned value. A read is a hit exactly when its address appeared earlier and fewer than $K$ other distinct addresses have been touched since that occurrence. This follows by induction from moving each touched address to the front and truncating the recency list. On the true run a cached word is always correct. Thus the set of true read errors is supported on precisely the addresses with $D(a)\ge K$. If $J\le k$, at most $k$ addresses satisfy this condition. This is the fully associative least-recently-used cache criterion. [Mattson et al., *Evaluation techniques for storage hierarchies*](https://doi.org/10.1147/sj.92.0078)

Use fixed-index dense slots storing the resident address, value and two recency links. A direct work bank maps a resident address to its nonzero slot index. On replacement clear the evicted address's entry before installing the new one. The guest address width is preserved with disjoint simulation banks. A native cache update and prediction cost $O(1)$. At a checkpoint serialize just the $K$ slots and fixed control. To replay a selected interval, reconstruct the address-to-slot map in $O(K)$ operations on initially zero memory. Check duplicate keys, range bounds, the list links and the active count in the same time. A traversal from the head must end at the tail after exactly the active count, with consistent predecessor links. The reconstructed map is temporary, and its full physical address range is never part of a guessed snapshot. Thus each snapshot and its setup cost $O(k+1)$ words or operations even when all guessed endpoints must be checked for soundness.

For the monitor theorem retain actual values at a proposed set $S$ of at most $k$ exceptional addresses and predict all other work loads using this cache. Observe stores to one extra address selected after $S$, and compare the resulting last-written word with any read prediction at that address. Cache updates see the same load reply as the simulated CPU, including when $S$ corrects a miss. The simulation on a wrong trajectory is deterministic once $S$ is fixed. Its first wrong read, if any, is outside $S$ and is detected by the corresponding one-address monitor. On an honest run with $J\le k$, the true exceptional addresses supply an $S$ with no errors at any monitor. The included cache changes all checkpoint and time bounds by constant factors. For one-verdict hypotheses the capped simulation can count genuine disagreements once per corrected address and stop at the first overflow, as in the fixed-predictor version of the monitor theorem. This requires no advice for picking cache evictions.

## An observable consequence and its clock cost

Draw a directed edge $a\to b$ if a genuine nonzero read at $a$ has a touch of $b\ne a$ strictly since the preceding touch of $a$. Select $J$ addresses attaining the threshold and one witnessing read per selected address. Each selected row contributes at least $J$ distinct edges. Thus there are at least $J^2$ **different ordered pairs of addresses**, even if the same time interval witnesses many edges. In particular, a hypothetical linear-time deterministic SAT solver has, on each verdict along a subsequence, an unbounded ratio between its number of such distinct pairs and $N^2/\log^{22} N$. Reads of the read-only formula are excluded throughout.

The conclusion also holds if a competitor counts only when the value it stores or actually retrieves is **nonzero**. Run the recency list on just these nonzero touches, storing a latest value at each retained address. A store of zero clears that value if resident, without moving or adding an address. A zero read leaves the list in place. Thus every cached prediction equals the true value on a genuine trace, even at a retained address whose value was cleared. An absent address predicts zero. A nonzero read has a preceding nonzero touch at that same address, and its immediately preceding physical touch also carried the unchanged nonzero value, since otherwise the read could not return it. The ordinary recency lemma on the filtered event stream proves the claimed stronger counting rule. On projected paths the filter uses the value actually delivered to the simulated CPU. Arbitrarily many virgin zero reads and zero-only filler writes therefore contribute no edge to this strengthened bound.

The graph can be dense within a linear number of instructions. Store one at each of $r$ fresh work addresses in increasing order, then read them in the same order. Between the two touches of any address all $r-1$ other addresses appear. Every read returns a one, $J=r-1$ for $r\ge2$, and all $r(r-1)$ directed pairs are present in a run of $2r$ memory operations. This gives the precise obstruction to inferring the unrestricted clock from the new count. An earlier argument measures elapsed slots between touches and sums weights over events. The distinct-pair count here discards elapsed time, repeated competing addresses and repeated instances of the same ordered pair. [Earlier gap theorem](weighted-read-gaps.md)

## Many genuinely live values at the same cut

Take $h=J\ge4$ and write $T$ for the native run length. For each of the $h$ witness addresses, mark the first occurrence of each of $h$ different competitors inside its chosen gap. Put $s=\lfloor h/4\rfloor$. From immediately after marked occurrence $s$ up to immediately before marked occurrence $h-s+1$ there are at least $h-2s+1$ distinct cuts. At each such cut the gap has at least $s$ different competitors on each side, and the untouched word at its own address really is nonzero. Summing over the witnesses and averaging over the $O(T+1)$ native event cuts gives one common cut with $\Omega(h^2/(T+1))$ such live words simultaneously. Multi-access instructions permit cuts between their ordered guest accesses. Thus under a linear SAT clock, on each hard subsequence there is one cut with an unbounded ratio of simultaneous qualifying words to $N/\log^{22} N$, each with an unbounded ratio of the two-sided competitor threshold to $N/\log^{11}N$.

The same live words persist throughout an interval of $\Omega(h)$ ordered memory events around that cut: moving it by at most $\lfloor s/2\rfloor$ events can remove at most that many different competitors from one side. Both sides retain $\Omega(h)$ distinct competitors. Each witness interval contains the whole resulting interval. This remains true when competitors must carry nonzero values.

The dependence on $h^2/T$ is sharp for traces. Partition $h$ data words into batches of $\ell$ (take $\ell\mid h$). Within a batch, store one in its $\ell$ words, store one in $h$ distinct filler words, then read the $\ell$ data words. Finish the batch before starting another, reusing the filler addresses. Exactly $h$ addresses have a nonzero read, each has at least $h$ different competitors, and no cut crosses more than $\ell$ of their gaps. There are $2h+h^2/\ell$ accesses.

It also checks the nonzero-only construction with 4,096 further multivalue runs, the full directed graph through 32 addresses and 16 examples for the shared interval. ## The hard runs can avoid the preprint's entire canonical SAT projection

For every hypothesized linear-time solver $A$, on each verdict the preceding lower bound on $J$ persists when the search is restricted to files **outside** the canonical ordered ASCII list projection. Run the existing register-based recognizer for that projection, stopping after $C N$ instructions if necessary. Fix $C$ large enough for every genuine projection length, handling finitely many small lengths directly. On a match, answer by its duplicate test. On an invalid prefix or timeout, invoke $A$ on the original read-only input with a fresh work bank. The recognition stage uses at most one work read returning nonzero even on a failed attempt: before the first hit it marks fresh decoded keys, and after the hit it uses fresh private row addresses. It validates a key before performing that row's work accesses. All parser state is in a fixed number of registers. The combined solver has worst-case linear time and every canonical file has $J\le1$. In a fallback run, the nonzero reads of $A$ have exactly the original intervening touches, since the earlier recognizer never addresses its bank and each nonzero load in that bank has a prior native touch there. Adding one witness address can raise the threshold $J$ by at most one. The arbitrarily large ratios forced for the combined solver therefore occur on noncanonical files and also hold on $A$'s own runs on those files. This statement uses the explicit validation and formatting of the ordered projection. [Register-based recognizer and finite audit](one-wrong-initializer-in-a-sat-run.md)
