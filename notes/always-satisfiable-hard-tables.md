# A designated hard truth table in every witness of a satisfiable formula

Assume SAT on ordinary explicit formulas of encoded bit length $N$ has a deterministic $O(N^k)$ algorithm on the stated logarithmic-word RAM, $k\in\{1,2,3\}$. There is a locally generated family of **always satisfiable** explicit 3-CNFs with the following property. At every sufficiently large integer parameter $t$, each satisfying assignment contains a designated table of $m=2^t$ bits. Any bounded-fan-in Boolean circuit on the $t$ address bits with at most $N^{1/(2k)}/(\log N)^A$ gates agrees with that table on **less** than a $1/2+1/t$ fraction of the addresses, for a fixed $A$. Here $N$ is the actual encoded bit length of this parameter's formula. The designated $m$ entries have public consecutive variable numbers. The assertion concerns every witness, allowing each of them its own best approximating circuit.

The construction tests the inference that a fast SAT decider should supply a simple, even weakly predictive description of some satisfying assignment on every succinctly specified positive instance. It uses an average-case form of the minimum circuit size problem (MCSP) and two ordinary bounded-run compilations. Carmosino, Impagliazzo, Kabanets and Kolokolova call the inner predicate MACSP. The exact-recovery version of guessing and testing a table already appears in this journal. Here the designated witness slice has near-half error against all small circuits. The first compilation asks whether a proposed table has a good approximator. The second certifies a genuine rejecting run of the assumed solver. Truth-table construction via circuit lower bounds and range avoidance, and the use of witness circuits in complexity theory, have extensive antecedents. We make no claim of historical priority for this argument. ## The inner test

Fix any finite bounded-fan-in basis, including, for example, all binary Boolean functions. Put $s=\lfloor 2^t/t^4\rfloor$ at large $t$. A program with a public $m$-bit table $z$ guesses the gates, types, backward wires and output of a circuit of size at most $s$. For each of the $m$ addresses it evaluates that same circuit in topological order and counts agreement with the actual table bit. Reject malformed guesses. Accept when the integer count $u$ satisfies $2tu\ge (t+2)m$. This realizes exactly the stated inclusive approximation threshold, including when it is nonintegral. Its branch length is $O(m(s+t+1)\operatorname{poly}(t))$, and a bounded-run 3-CNF $C_t(z)$ has at most $m^2\operatorname{poly}(t)$ encoded bits. Arithmetic and gate descriptions fit $O(\log m)$-bit words. The template has regular bounds independent of the table. [Explicit packed compilation](packed-band-transfer.md)

For a uniform independent $z$, agreement with a fixed Boolean table has the binomial distribution with parameters $m,1/2$. Hoeffding's inequality bounds the chance of reaching $1/2+1/t$ by $\exp(-2m/t^2)$. There are at most $2^{O(s\log(s+t+2))}=\exp(O(m/t^3))$ circuit descriptions, including shorter ones. So for every large $t$ at least one $z$ makes $C_t(z)$ unsatisfiable; in fact their fraction tends to one. This count uses a union over circuits for the *same* table. [Hoeffding](https://doi.org/10.1080/01621459.1963.10500830)

## The outer formula

A fixed nondeterministic RAM guesses the table once in its initial phase and retains it unchanged. On this table it materializes $C_t(z)$ or supplies local word access, and runs the hypothesized deterministic solver on it. It accepts only on the solver's negative verdict. With a large fixed clock $R_t=2^{2kt}\operatorname{poly}(t)$, every honest run fits. Choose a particular integer power of $t+1$ and coefficient dominating the compilation, all simulation overhead and small parameters. Sparse bank simulation or a sufficiently large fixed word-width coefficient supports the solver on these polynomial-sized inputs; the outer program can take a dummy unary input of length $m$. Its clock counts steps on polynomial-size words. The packed 3-CNF for its bounded acceptance has size $N=O(m^{2k}t^D)$ bits for a fixed $D$. A counter computes the public input initialization directly from $t$. With the regular compiler, an indicated literal field is computable from $t$ and its index in $\operatorname{poly}(t)$ steps. No table or approximating circuit has to be known to generate it.

To make the output slice explicit, use a fixed initialization loop with one bit choice per table entry, fixed instruction count and writes at successive locations. Add $m$ consecutive Boolean variables and equate each to the corresponding recorded choice bit by a pair of implications with duplicated literals. These records are regularly indexed, and they add $O(m\log N)$ encoded bits. Every outer satisfying assignment yields an actual table and genuine rejection of $C_t(z)$; every table with no qualifying approximator admits an outer satisfying assignment. Use a trivial satisfiable formula at the finitely many small parameters where the counting argument gives no guarantee. Since $\log N=\Theta(t)$ and $N\le m^{2k}t^{O(1)}$, one has $N^{1/(2k)}/(\log N)^A\le s$ for sufficiently large fixed $A$. On the contiguous slice even variable indices incur only fixed offsets, which can also be chosen aligned by padding the variable range. This proves the assertion.

The approximation requirement is stronger than exact recovery on the designated slice. The construction also works with a sound nondeterministic UNSAT recognizer admitting a timely rejecting-instance certificate on all unsatisfiable inner queries. The outer machine guesses the recognizer's accepting branch and enforces its clock. Both constructions establish a lower bound for prediction on part of a satisfying assignment. A decision procedure can recognize this family by a separate argument for its guaranteed verdict. [A length-based construction for locally evaluated witnesses](padding-blind-lengths.md)

The journal also constructs a single deterministic hard table at every arity, with an explicit output-time guarantee. The formulas here admit many table choices and quantify over all satisfying assignments. Standard prefix search with the hypothesized solver could select one canonical table at additional cost.
