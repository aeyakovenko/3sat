# What if a memory log can change after the fingerprint challenge?

A deterministic execution has one genuine memory log. A chronological log satisfying the CPU transitions can nevertheless use fabricated read answers. A separately generated address-ordered log can satisfy the memory rules for different events. Public challenges can distinguish two fixed unequal logs, yet leave a different pair of false logs available for every challenge. Timestamped memory records and multiset hashing are standard techniques in offline memory checking. [Blum, Evans, Gemmell, Kannan and Naor](https://www.cs.ubc.ca/~will/papers/memcheck.pdf) · [Clarke et al.](https://people.csail.mit.edu/devadas/pubs/mhashes.pdf)

## It suffices to separate the false logs at the first omitted output

Take the actual first d-bit word w omitted by the universal multitape machine U on every description shorter than d by B=2^(20n) steps. Here d=n or 2(n−1). Encode each time step by one memory event per tape, containing its tape, address, time, old symbol and new symbol. Include halted stuttering to the fixed cutoff and track a genuine halt. The fixed number of tapes and stuttering give the same K=O(B) records for each candidate, each of O(n) bits. A chronological checker guesses the read symbols, follows the actual CPU instructions and head moves, and checks the desired output and halt according to U's output convention. An address-ordered checker verifies nondecreasing (tape,address) keys, legal coordinate and timestamp ranges, strict time increase within each key, the initial symbol computed from the same program and input, and that consecutive old/new values agree. For an output convention read from final memory, the latter checker can check the final symbols at the designated addresses as it finishes each run of records, treating unvisited cells as initialized. Alternatively an append-only output is counted and compared in the chronological checker. Each checker uses poly(n) bits before adding any fingerprints. Guess both logs with exactly K records. If their multisets match, sorting the time-stamped events gives precisely the memory semantics of the chronological run. This holds even though each local checker taken alone may have many possible logs. [First-hole convention](address-diagonal.md) · [Earlier multiset check](batch-verification.md)

Use a binary extension field F with b=O(n) large enough both to encode records injectively and to have |F|>K. For a log A put P_A(X)=Π_{e∈A}(X−enc(e)). For a tuple of r field points, guess the program and a locally admissible pair A,C which passes all r product comparisons. This is a nondeterministic small-space test even when neither log has a small circuit. Stream A and then C, keeping their products at all the supplied points. Its tape space is O((r+1)poly(n)), and its time is B·poly(r,n), including sequentially scanning the accumulators and field arithmetic. The guess of the single program is retained across the two streams. Optional locally checkable restrictions on candidate logs can be included if they preserve real matched logs and their costs satisfy these bounds.

Under a linear-time explicit SAT algorithm the bounded-reachability simulation therefore decides this fixed-tuple test in 2^(σn+o(n)) deterministic RAM time for r≤2^(σn), with fixed σ>0. The logarithm of the auxiliary machine’s running time is O(n), including when r is exponential in n. Universally quantify the r points to form a new predicate A(n,z), retaining this time bound by one quasilinear reduction to SAT and complementation. One may quantify also over the defining monic degree-b polynomial, imposing the test only for irreducible ones. Irreducibility and field multiplication are checkable in poly(n), so field setup requires no exponential preliminary search. A valid output z passes A for *every* tuple by using its one matched run. The definition also permits choosing the program and both logs anew after seeing the tuple. [Linear-SAT check for space-bounded computations](linear-quantifiers.md)

Call a tuple separating at w if **no** locally admissible pair for w matches on every point of that tuple. If any tuple is separating, A(n,w) is false. Every z<w really is printed, so A(n,z) is true on every predecessor without any promise on the complexity of its logs. A fixed decoder can find the first false value by d prefix queries asking if some extension has A false. Under linear SAT each query takes 2^(σn+o(n)) RAM steps. Return a default if there is no false value. Taking any fixed rational 0<σ<5 allows both quadratic RAM-to-tape and quadratic universal simulation within B. Thus under linear SAT, at all sufficiently large n **every** tuple of ⌊2^(σn)⌋ points admits a pair of false, locally admissible, fingerprint-matching logs at w. Conversely, producing even a nonconstructively specified separating tuple at this one word at infinitely many lengths would exclude linear SAT. Nothing is required of any later word. No such tuples have been established. [Decoder clocks](linear-sat-batches.md)

A concrete sufficient condition is a small linear span of residuals. For a fixed instance and field, take V to span all P_A−P_C for its locally admissible pairs. If dim V≤r, there are r evaluation points whose joint evaluations are injective on V. Whenever the current kernel is nontrivial, choose a nonzero polynomial in it and a field point where it is nonzero. Its degree is below K and |F|>K, so this reduces kernel dimension. Pad the tuple if needed. When there is no exact pair, every discrepancy in question is nonzero by unique factorization, and the tuple separates all of them simultaneously. The span need only be small at w. Its basis need not be supplied. More generally, if there are at most D distinct nonzero discrepancies and D(K/|F|)ʳ<1, a union bound on independent points gives such a tuple. These are conditions on the possible errors, not on the number of genuine executions.

## Binding the program before an adaptive challenge

A genuine predecessor has one short program p that works against every challenge. Guess this p **before** the field and the first public move. For each n fix a positive integer round count h=h(n), uniformly computable in poly(n) time. In round i the challenger chooses a tuple of legal points αᵢ and observes a vector vᵢ of common numerical product values. In addition to program length |p|<d, impose a total transcript cap 2^(σn+o(n)) bits on the encoded tuples and their equally long replies. For instance permit up to r=⌊2^(σn)⌋ points *in each* of h polynomially many rounds, at b=O(n) bits per point. The message lengths, padding and the total cap are fixed and constructible within the encoded size. For a fixed public field representation the game predicate is

    ∃p  ∀α₁ ∃v₁  …  ∀αₕ ∃vₕ   some admissible pair for p returns every vᵢ on αᵢ.

If multiple fields are permitted, place the universal quantifier over the defining irreducible polynomial **after** p and before the first challenge; the selected field is then fixed for that play. Restrict all universal moves to their stated formats, or ignore malformed moves through the usual guarded quantifiers. The leaf verifier streams one pair and verifies **both** logs against each reported value at each point. Merely checking equality of two products without checking the previously reported numerical value would allow the log pair to justify a different branch. The terminal pair may depend on the entire play. Every vᵢ must be chosen before later challenges are known.

For fixed h the same clock as the single-tuple argument applies. More generally it applies when h=o(n/log(n+2)). Given the entire candidate transcript, the small-space streaming test followed by bounded reachability takes 2^(σn+o(n)) deterministic RAM time under linear SAT. Compile a certificate for this deterministic verdict into a quasilinear-size explicit circuit, using the checked RAM transcript and merging its witness into the last existential block. The preceding 2h+O(1) blocks are eliminated by the uniform quasilinear recurrence. Starting from log size O(n), each elimination adds O(log n) to log size while it remains O(n), so these rounds add o(n) in total. Construction and decoding have the same exponential rate. [Uniform block elimination](linear-quantifiers.md)

Consequently, under linear SAT and σ<5, at every sufficiently large n there is **one p at this length** with an online numerical response strategy at w. It survives every legal adaptive challenge, with a single false matching pair for the chosen p at each terminal play. Otherwise the fixed decoder would return w as the first false value because every predecessor has a true matched run. The challenger need not have a succinct strategy circuit: the quantifiers themselves represent its contingent choices. A short fixed-format header i can also be guessed alongside p, provided the leaf checker binds it to the logs within the same resources, and some choice of i preserves a real run for every predecessor. In particular, if at w each possible p and header fiber had its own small separating tuple, even with no effective map from headers to tuples, this would refute linear SAT. This is a stronger witness requirement on the false pairs than allowing p to change at every challenge. There is still no known adaptive separator for the actual w at these parameters.

If a whole adaptive tree has few nodes, a simple nonadaptive corollary also applies. Put every query at every node into a single batch; a pair matching everywhere survives the path its reported values determine. More generally a deterministically specified longer policy can be verified by guessing its complete numerical play, recomputing the policy from its public input and those replies, and then checking one pair along the resulting path. This variant requires the policy description and all streaming workspace to fit the same cap, and its evaluation time to be 2^{O(n)}. Quantifying arbitrary allowed descriptions requires a fixed evaluator and enforced resource bounds. These variants do not grant access to either log while the policy selects a challenge other than through its stated public replies.

## How a surviving pair must differ

Two structural tests give more information about the false pairs that remain at w. First choose r distinct product-evaluation points **outside the record alphabet**, enlarging the field by O(1) bits if needed to reserve enough points. Remove common records with their multiplicities from both equal-length logs. If e unmatched records remain on each side, the two residual monic products have degree e. Their difference has degree at most e−1. No removed common factor vanishes at a reserved point. Agreement at all r points therefore forces the logs to be identical or e>r. Products for set reconciliation and reserving evaluation points outside the universe are classical. [Minsky, Trachtenberg, and Zippel](https://doi.org/10.1109/TIT.2003.815784)

Next order the alphabet by a publicly computable injective integer code x between zero and H, with log₂(H+2)=O(n). Let d_x be the multiplicity of x in the chronological log minus its multiplicity in the sorted log. Each log streams its exact integer moments Σ x^j for j=0,…,k, adding a term per record. Equality of these moments forces any nonzero d to change sign **at least k+1 times** along its nonzero entries. Indeed, if its sign switches at t≤k gaps, for each gap with adjacent support keys a<b use the integer factor 2X−a−b. Up to a global sign the product of the t factors then has the sign of d at every nonzero entry. Its weighted sum against d is strictly positive. Equal moments force this same sum to be zero. The roots serve only in the proof. Testing moments uses integer arithmetic. Lean checks linearity in the polynomial coefficients and the contradiction from a positive sum. [Lean proof](../lean/MomentTest.lean)

There can be many moved records even at one sign change. For example, exchanging an arbitrary set of early records for the same number of later records always changes the first moment if the sets are strictly separated in the order. The family even includes single replacements whose discrepancy vectors span the entire zero-sum hyperplane. Thus the sign test can apply to a family with large linear span of multiplicity vectors. The earlier span test concerns a different vector space of characteristic polynomials.

Each streamed moment uses O(log K+j log(H+2)) bits for a log of length K. All k+1 moments, including temporary powers, cost O((k+1)² n) bits. With k and K at most singly exponential in n, elementary integer arithmetic takes 2^{O(n)} total time. The two tests can be required on the **same** pair at the leaf of the game above. For any fixed rational 0<γ<5/2, choose k=⌊2^{γn}⌋ and choose 2γ<σ<5. Under linear SAT, the resource bound for the game still applies. Consequently, at all sufficiently large lengths there is a program at w with a false pair moving more than ⌊2^{σn}⌋ records per side after cancellation and changing multiplicity sign more than k times. A polynomial-size fixed panel of uniformly computable orders can all be imposed on that pair, provided their codes can be computed in poly(n) space and 2^{O(n)} time per record. At every genuine output the exact matching pair passes them all. To exclude linear SAT by this route, one would have to exclude these highly oscillating false pairs for every possible program at w at infinitely many lengths. The moment calculation supplies the forced oscillations, but no such exclusion for the universal machine. A different source can test nearly as many records as its entire execution has steps. [Native interpreter and its clock](native-missing-word.md)

## A fixed false output that short public digests fail to exclude

A RAM loops over m fresh bit cells. At index i it chooses a bit xᵢ, stores it, immediately reads the cell as yᵢ, and accumulates the OR of xᵢ≠yᵢ in a register. It accepts iff the accumulator is one. Every genuine execution rejects. Times, addresses and operation types follow a fixed schedule. Consider checks that reconcile the **memory-event projection** of a chronological and a sorted candidate by commutative-monoid fingerprints, with arbitrary tag functions of the stamped event. This includes multiple field-product or additive checks. CPU register tests still apply to the chronological candidate.

For any fixed public batch with at most 2^ℓ joint digest values, let H(v) be the joint digest of the read records with supplied data vector v. If ℓ<m, some distinct x,y have H(x)=H(y), even restricting all but ℓ+1 designated positions to zero. The accepting chronological candidate writes x and reads y, setting the accumulator. The sorted candidate uses the identical writes and reads back x. The joint digests match because the write factors agree and the read digests already agree. Both logs have unique timestamps. Fixed table lookup on ℓ+1 payload bits, address arithmetic and the first changed index give row circuits of description length poly(ℓ+log m) for logs supported on the first ℓ+1 positions. This refutes the inference from a separately matching accepting log at each challenge to one accepting execution.

One can make the machine deterministic and keep its input fixed across challenges. Supply x as input data for the writes. Suppose there are at most 2ᵘ permitted public batches, each with at most 2^ℓ outcomes and fixed record tag maps, and u+ℓ<m. Restrict candidate input vectors to the first u+ℓ+1 coordinates, giving a set of N=2^(u+ℓ+1) possibilities. Each H has at most 2^ℓ−1 singleton fibers on this set, since N>2^ℓ. The union of the singleton fibers of all batches leaves some one x outside. For every batch, a distinct y in its fiber gives the foregoing false accepting log on that **same deterministic input**. Arbitrary input-dependent hashing must count the distinct induced maps in the bound on batches. In the special case of ℓ-bit XOR digests the read-only map is affine in the m Boolean values for *any* fixed per-tag functions. Thus for every x and every batch with ℓ<m a nonzero kernel direction supplies y, without a restriction on the number of possible batches. This remains true of XOR maps selected using x.

The example targets memory-event fingerprints. A verifier using the program's semantics can compare each claimed read directly with the input bit in this particular program. The example's input and adversarial choices do not prove the absence of small separating tuples for the universal first-hole computation. The outstanding mathematical question is which additional cheaply checkable restrictions can exclude its false logs simultaneously while retaining the real runs for the earlier outputs.

## A short adaptive separator on stamped records

A small change to the write/read machine gives an explicit positive example for general commutative fingerprints. On a purported accepting chronology, record the first mismatching cell j in a register and append a single distinguished marker event carrying j at a fixed fresh address and time. Require the locally sorted view to contain exactly the prescribed schedule of one write and one read per cell, plus one marker. This is easy to check in address order. The marker in the sorted view is interpreted only as a memory event. First ask for its value by a fingerprint that ignores all other records. If both logs reply j, ask for the ordered pair of bits at the write and read of j. These are two components of a commutative fingerprint selecting the corresponding unique tagged records. The chronological bits at its named mismatch differ, while those in the locally valid sorted log agree. This separates every false pair in two rounds, using ⌈log₂ m⌉+2 common reply bits.

By contrast, every nonadaptive batch of arbitrary allowed commutative fingerprints with fewer than m digest bits still fails for the nondeterministic-write version of this modified machine. Choose x≠y with equal read-only digests, append their first mismatch j to both logs, and use the same writes x. The marker factors and write factors are common. The short adaptive test works because the first common reply identifies the disputed record. If the only feedback were an equality bit, every passing branch would return the same bit and the challenges on that branch would form one fixed batch.

The original machine even exhibits a finite adaptive advantage for **field products alone**, with no marker. Use twelve cells, GF(53), read tags 4i+b and write tags 4i+2+b. The visitation order may be fixed in reverse address order, so address, operation and time are determined by the tag. Each of the 4,096 possible inputs has a read-digest collision at each of the 53 points. For the fixed zero input the false chronological candidates write zero and read a nonzero vector y, whereas the sorted candidates may write **any** vector z but must read it back. The same y and z must give all the values reported on a surviving path. All 23,426 fixed triples of distinct field points admit a false pair, which also rules out fixed tests using repetitions or fewer points. No two-round adaptive product strategy separates the two sets, but a three-round strategy does, beginning at point 48. The exact search partitions both candidate sets by their numerical reply and requires a winning continuation in every bucket attained on both sides. It verifies the nonadaptive claim by finding a joint collision for every triple, and independently checks the full stamped products for a false log at each single point on the same zero input.
