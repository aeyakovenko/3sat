# Repeated reads and reachable work configurations on selected SAT input bits

Let $h$ be a dense fixed-record 3-CNF length with $M=\Theta(2^w)$ clauses, $2^w-1$ available variable names, an $O(w)$-bit header and $3(w+1)$ bits per record. Let $U$ be any prescribed set of physical input bits meeting $R$ distinct clause records. For all sufficiently large $R$, there is a valid face varying $k=\Theta(R)$ single bits selected from $U$. In particular $k=\Omega((|U|-O(w))/w)$. Choose either SAT verdict. On the face the inputs of that verdict are the codewords of a fixed binary linear code of dimension $k/2$, up to fixed bit complements. The face can be chosen independently of the solver. For any correct deterministic packed-word RAM solver, measure the following only on the genuine runs of **that verdict**.

* Let $W$ count distinct complete writable configurations immediately before loads exposing at least one selected bit. Include the controller and registers, and distinguish the fixed substeps of any multi-access instruction. The immutable formula is excluded.
* Let $s$ be the maximum, on a single such run, of the number of distinct selected bits exposed by at least two input loads. Exposure counts the bits in the returned word even if the instruction later masks them off.

Then
$$
               (s+1)\log_2(W+2)=\Omega(k).
$$
The codeword families for the two verdicts can use different fixed checker clauses. No prior bound on workspace or elapsed time is required. One may also use all reachable configurations in place of the configurations at the selected loads.

## Putting a code into the selected coordinates

Use a binary rate-half code $C$ of even length $k$ with both its minimum distance and dual minimum distance greater than $\delta k$ for a fixed $\delta>0$. We need a bounded-fan-in Boolean circuit of size $O(k)$ for the membership predicate, in order to realize either verdict and to force all gate signals by unit propagation. On its supplied lengths the systematic construction in *Fast Bounded-Independence Functions and Their Duals* has the form $C=\{(x,Ax)\}$ with $x$ of length $k/2$ and $Ax$ computable by a linear-size circuit. Compare the result with the other half, and complement the output for the opposite convention. For every sufficiently large even length use the dual XOR encoder of Brehm and Resch, Theorem 2. If its generator is $H$, then $z\in C$ exactly when $H^T z=0$. Reverse the XOR circuit for $H$, summing the contributions of the outgoing wires at each gate in reverse topological order, to compute $H^T$ using $O(k)$ gates. Choose a fixed good code nonuniformly for each even size. Gate-equivalence clauses use $O(k)$ variable names and records. [Systematic fast codes with good duals, Section 1.2](https://drops.dagstuhl.de/storage/00lipics/lipics-vol385-itc2026/html/LIPIcs.ITC.2026.8/LIPIcs.ITC.2026.8.html) · [Brehm and Resch, Theorem 2 and the XOR encoders](https://drops.dagstuhl.de/storage/00lipics/lipics-vol362-itcs2026/html/LIPIcs.ITCS.2026.28/LIPIcs.ITCS.2026.28.html)

Of the $R$ eligible records, reserve a small fixed fraction for the free coordinates. Since $R\le M$, this leaves room for all checker gates and enough unused names. Take one live coordinate in each of $k$ records. A sign position can force a checker input or its complement through a clause with two fixed-false literals. For an index position of significance $j$, let its bit choose between two fresh names differing only in bit $j$. Two fixed binary clauses force the two named variables to be complements. Requiring the chosen variable to be true pins the first one to a known orientation of the physical bit. There are $2^{w-1}-1$ disjoint valid pairs for this significance, so earlier names rule out only $O(k)$ of them. Use a small constant in the stated lower bound on $k$ to fit all carrier clauses, gates, names and fillers. All other bits, including unused positions in $U$, are fixed. A native word intersects $O(1)$ live coordinates because its width is $O(\log h)=O(w)$ and there is only one per record. ## Keeping only the codeword computations

Form a deterministic bit branching program for membership in $C$. Between loads exposing selected bits, all read-only input answers are fixed, so a full work configuration and the answer to its current load determine the next such load or the halt. These transitions may be precomputed nonuniformly. Use only states and transitions that occur on codeword inputs and send any missing transition to rejection. Return membership on reaching the designated halt. Each codeword follows its original run. Any input accepted by this program followed a sequence of true fetches and genuine deterministic transitions from the common initial state to the designated verdict, so it belongs to $C$.

A single halting run cannot visit the same complete configuration twice on an unchanged immutable input. It therefore has at most $W$ selected loads on a codeword. Layer by the ordinal number of these loads to ensure acyclicity even on inconsistent paths. Expand each load into a constant-size tree testing each of its live bits once, switching edge labels on a complemented bit. The program has size $B=O((W+1)^2)$, regardless of time spent on other instructions. One can sharpen this count to a constant times one plus the sum, over load ordinals, of the number of configurations reached there on codewords. The newly added reject leaves can share a sink.

Jukna and Razborov's Corollary 4 states the code lower bound for branching programs with a reread cap on every consistent path. Their proof of Theorem 1 allows the cap to be imposed just on codewords. Here is the step giving that refinement. Put $L=\lceil2\log_2 B+2\rceil$. Every computation must expose at least the dual distance $d_\perp$ in distinct bits: every restriction to fewer bits has a codeword extension, and accepting on such a restriction would also accept a one-bit neighbor outside the code. Proposition 3 supplies $p$ disjoint sets $I_j$ of size at most $L$ with two different partial assignments on each and corresponding merge nodes, whenever $pL<d_\perp$. For a fixed base choice on the preceding sets, the two partial assignments on $I_j$ lead to the same node after testing all coordinates on which they differ. The base assignment on the union extends to a codeword. If $L<d(C)$, changing any one block to its alternate assignment gives a noncodeword. Hence, on **every** codeword extending the base assignment, at least one differing bit of each $I_j$ must be tested again after that merge. Otherwise the alternate input would follow the same accepting suffix. The exact proposition and its ordered merges appear on pages 226–227. [Jukna and Razborov, Proposition 3, Theorem 1 and Corollary 4](https://web.vu.lt/mif/s.jukna/ftp/few.pdf)

If $L$ is a fixed positive fraction of $k$ the claimed inequality already holds. Otherwise take $p=\lfloor\delta k/(2L)\rfloor$ and obtain $s\ge p$. Moreover these reread obligations hold for the **same** $p$ disjoint groups on an entire affine subspace of the code of dimension at least $k/2-pL$: fewer than $d_\perp$ pinned coordinates impose independent conditions. Each reread along this accepting path is a second exposure on the native codeword run. This establishes the claim and its common-group version.

## A cut at a fixed number of first exposures

There is a sharper conclusion at a specified cut in the absence of reads back across that cut. Expand each selected load into its constant number of single-bit observations in a fixed order and between such loads run the native computation with its fixed input answers. Stop just after $\ell$ **distinct** carrier bits have been exposed, where $1\le 2\ell<d(C^\perp)$ and $\ell<d(C)$. To specify the boundary state, advance to the next selected-bit test, skipping only operations on fixed input positions. Keep its full native pre-load configuration and the partial load if inside a word. In this last advance, any tests of previously exposed selected bits still count as tests. Every consistent history of fewer than $d(C^\perp)$ distinct observations extends to a codeword. Before the cut, repeats can be answered from the history. Each fresh bit has two possible values, and under a uniform codeword all $2^\ell$ fresh-answer histories have equal probability $2^{-\ell}$. The computation cannot halt on such a partial assignment.

Suppose two distinct fresh-answer histories $p,q$ reach the same boundary state. Their assignments differ on at least one common position, namely the first answer where the deterministic executions diverge. Prescribe $p$ on all its positions and $q$ on its additional positions. The union has at most $2\ell$ members, so there is an affine subfamily of at least $2^{k/2-2\ell}$ codewords extending this prescription. For every such codeword $a$, flip exactly the nonempty common set of disagreements to obtain $b$. We have $0<d(a,b)\le\ell<d(C)$, hence $b\notin C$. It follows prefix $q$ to the same state. If the suffix on $a$ never exposed any of the changed bits, it would give the same designated verdict on $b$, which is impossible.

In particular, if on all codewords the solver avoids rereading its first $\ell$ distinct bits across this cut, the $2^\ell$ boundary states are different and equiprobable. Repeats confined within either side are unrestricted. Each raw native pre-load configuration supports at most a constant number of partial-word states, because a load overlaps $O(1)$ live bits. Thus the probability of any one such native configuration at that cut is $O(2^{-\ell})$. On the same distribution, for $\ell$ growing faster than $\log h$, the probability that the native configuration has fewer than $c\ell/\log h$ nonzero work words is $2^{-\Omega(\ell)}$ for a sufficiently small solver-dependent $c>0$. Indeed, a configuration with $v$ nonzero words is specified by the controller and $v$ address/value pairs, each of $O(\log h)$ bits. The time of the cut need not be specified. This is a distributional assertion at one discovery count. It also identifies an affine family of genuine crossing reads for **each pair** of merging histories when the hypothesis fails. ## Why these configurations can still be cheap to describe

A single globally correct solver can first copy every physical input word once in increasing order. Run unit propagation on the copy, signal UNSAT on conflict, SAT when the resulting partial assignment satisfies every clause, and invoke a complete solver on the remaining cases. Every gate-equivalence formula constructed here is decided by propagation because the carrier clauses force all checker inputs. The whole procedure costs $O(h/\log h)$ steps on the family with either sign, including copying and building the occurrence lists. Hence it realizes $s=0$. Only the copy phase contributes to $W$. At its pre-load states the work array consists of a prefix of the given input followed by zeros, with a constant number of bookkeeping words. Given the original input and the prefix length, a fixed decoder returns any work word in $O(1)$ time with $O(\log h)$ bits of advice. Consequently even exponentially many equiprobable reachable configurations, at the indicated cut, can each be fully queryable under the solver-side snapshot interface. The input available to the decoder accounts for the difference.
