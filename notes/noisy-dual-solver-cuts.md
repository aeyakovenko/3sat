# The solver's memory and the proof of its rejection on the same input

The earlier memory-cut argument used an expander quadratic with a known fast algorithm. The earlier self-referential formula gave difficult proof queries on genuine timely rejections but only counted initial input reads. Here a change to the SAT disjuncts makes the two conclusions hold on **the same real rejecting executions**. Every sufficiently fast solver in the problem statement is covered, including a hypothesized cubic-time solver. An unconditional elapsed-time exclusion remains unproved. [Previous monitored computation](guarded-code-rejections.md) · [Earlier snapshot calculation](discovery-epoch-snapshot-codes.md)

Use the fixed logarithmic-word RAM, an ordinary explicit width-three encoding, and separate raw-bit sign pins spaced so one word access reveals at most one raw bit. The monitored program $S$ can be any correct deterministic SAT solver. At scale $k$ use $s_0=2^{\lfloor k/4\rfloor}$, $b=k^2$, $d=s_0k^C$ rounded to an integer, and $n_0=2d$ raw symbols. There are $K=n_0 b$ independent raw bits before conditioning on their parity. The physical formula length is $N=K k^{O(1)}$, with $\log N=\Theta(k)$. Symbols serve the proof verifier. The native cuts below count **individual bits that have actually been read**. Set $\epsilon=1/\lceil k^{1/4}\rceil$, $t=\lceil4\epsilon K\rceil$, and $G=\rho K$ where $\rho=\Theta(\epsilon^3/\log(2/\epsilon))$ with a small constant fixed below. The floor or ceiling conventions can be implemented with integers and dyadic rationals throughout.

Under uniform **odd-parity** raw input, with probability at least $1-2^{-\Omega(d/(h+1))}-2^{-\Omega(G)}$ the physical SAT instance is unsatisfiable. Here $h=k^{O(1)}$ is the fixed per-row raw-symbol probe budget in the compiled verifier and $C$ is sufficiently large. On this very distribution, except on $2^{-\Omega(G)}$ joint mass of rejecting inputs, every one of the $\lfloor K/(2t)\rfloor$ disjoint intervals learning $t$ new pins in the first half of the discoveries satisfies the following statements for each fixed machine and reconstructor.

* Given the full observed trace to the interval start, the end controller, and the physical input, reconstructing the complete end memory with at most $cG$ hindsight advice bits requires the reconstructor and the actual suffix together to read more than $r=\lfloor cG/\log(2K/G)\rfloor$ distinct pins first seen in the interval. A failure to reconstruct also meets the exclusion. Advice can be chosen anew after the entire input is known, at every interval.
* The actual suffix either rereads more than $r$ of these interval pins, or consults $\Omega(G/\log N)$ distinct incoming work addresses before their first later overwrite. This second bound counts every queried value. There is also a bound on genuine changed values below.

The cut statements hold for every fixed correct solver of these formulas, including the monitored one. Probability is over inputs for a fixed choice of the machines. If $S$ finishes on these formulas in $O(N^e\operatorname{polylog}N)$ for a fixed $e<4$, all the stated unsatisfiable inputs are timely rejections of its own monitor for large $k$. On almost every such same input, **every** short header for a fixed fresh proof reader has small acceptance probability, including for a later verifier meeting the soundness and probe bounds below. None of these statements requires that a fast SAT solver exists.

## A guarded ordinary formula with a sparse Walsh expansion

Use three kinds of satisfiable disjuncts. The first accepts even raw parity. The second accepts a Hamming neighborhood of either of two code families, as specified below. The last is the existing shifted empirical proof test for the actual monitored rejection. All use the same raw-bit bank. Any correct solver that **rejects** has read every raw bit, since otherwise changing one unread bit produces an even satisfying completion. Thus every rejecting run has the stated discovery cuts. No property of accepting runs is required.

Construct a binary linear code $D$ by concatenation. Its outer field has $a=\lfloor c_0\epsilon^2 b\rfloor$ bits per element, with $c_0>0$ a sufficiently small absolute constant. In particular $2^a\ge n_0$ eventually. The outer code evaluates polynomials of degree less than $v=\lfloor \epsilon n_0/8\rfloor$ at the first $n_0$ distinct field elements. The same injective systematic binary linear map from $a$ bits to $b$ bits encodes each evaluation. Some such map puts every nonzero message at relative weight $(1\pm\epsilon/2)/2$. Indeed, in a random systematic matrix the $b-a$ nonsystematic coordinates of each nonzero message are independent uniform bits, while the fixed coordinates change its relative weight by at most $a/b$. Hoeffding's inequality and a union over fewer than $2^a$ nonzero messages suffice. A nonzero outer polynomial vanishes at fewer than $v$ points. The concatenated code has dimension $av\ge c_2\epsilon^3K$ for large $k$ and every nonzero word has relative weight in $[(1-\epsilon)/2,(1+\epsilon)/2]$. This last property only needs to hold for one selected inner map. It is a standard small-bias construction principle. [Naor and Naor](https://doi.org/10.1137/0222053)

Put $C_D=D^\perp$. The guard, which is an existential test, **allows all systematic inner matrices** and all irreducible presentations of the indicated outer field. Guess an input $z$ at distance at most $\lfloor\rho K\rfloor$ from the raw string and test $z\in C_D$ for the guessed presentation. All maps in the union have the same dimension $av$ for $D$, since the inner map is injective even if it is poorly balanced. Choose dyadic $\rho=\Theta(\epsilon^3/\log(2/\epsilon))$ small enough that $H_2(\rho)K<av/2$, with $H_2$ the binary entropy. The number of presentations is $2^{O(b^2)}$. Thus uniform raw input passes any of these guards with probability at most $2^{O(b^2)-av/2}$. Include a separate guard from exactly this construction with, say, $\epsilon_0=1/8$ and a sufficiently small **fixed** radius $\rho_0>0$. Its acceptance probability on uniform input is also exponentially small. The fixed radius is needed for the cited fixed-proximity proof verifier.

Here are the costs of compiling the dual test. Given an inner matrix $M$ with map $w\mapsto Mw$, compute $M^T z_i$ at each location. Convert that $a$-bit linear functional on the extension field to its representing element $u_i$ under the nondegenerate binary trace pairing. This is at most polynomial in $a,b$ per location, for instance by binary Gaussian elimination. Irreducibility can be checked by Frobenius powers and polynomial gcds. The remaining dual condition is $\sum_i u_i\beta_i^j=0$ in the field for $0\le j<v$, with $\beta_i$ the distinct evaluation points. Guess one polynomial $Q$ of degree less than $n_0-v$ and verify $u_i J'(\beta_i)=Q(\beta_i)$ at every point, where $J(X)=\prod_i(X-\beta_i)$. The checks are equivalent: interpolation gives $\sum_i L(\beta_i)/J'(\beta_i)=0$ when $\deg L<n_0-1$ by taking the top coefficient. Apply this to $L=X^jQ$ and use the ranks of the two evaluation maps for the converse. Product trees and fast multipoint evaluation take $n_0\operatorname{poly}(k)$ word steps, including bit-level field arithmetic. This computation is compiled once as a bounded RAM test. A virtual read of its 3-CNF uses the regular local clause generator, without running the code test. The fixed-radius guard, even-parity chain and disjunction have the same upper budget. [Multipoint evaluation](https://www.cs.toronto.edu/~bor/Papers/fast-modular-transforms.pdf) · [Packed compiler and local access](packed-band-transfer.md)

## Timely rejection and changing the verifier

Use the same universal pair language, bounded guest clock $2^k$, and shifted empirical formula as in the earlier construction, with the monitor serving this augmented formula. A correct solver cannot reject within the entire fixed-radius ball about the selected $C_{D_0}$, even if its guessed inner map and field are fixed to the good ones. Thus a uniformly random point of $C_{D_0}$ is farther than $\rho_0$ in relative bit distance from the true timely-rejection fiber. Any set of fewer than $\min\mathrm{wt}(D_0\setminus\{0\})$ bits is exactly uniform under this code distribution, since a nontrivial parity constraint on the projection would belong to $D_0$. In particular any sufficiently small constant times $d$ raw symbols have independent uniform values. The full uniform input has the same marginals.

For each header and shift, the $j$th empirical moment and the even $j$th empirical-minus-fresh moment agree between the two distributions if $j(h+1)b$ is below the dual distance. The proof expands each moment into $j$ invocations of a fixed row test on adaptively accessed raw symbols. Under the code law fresh acceptance is at most $1/4$. Under uniform input the ordinal-blind sampling estimate bounds the centered moment root by $\sqrt{j/n_0}+2jh/n_0$. For a sufficiently small constant times $d/(h+1)$ rounded to an even $j$, the empirical moment root under either law is at most $3/8$. Markov at $1/2$ and a union over $2^{s_0+b}$ headers and shifts make the empirical disjunct exponentially unlikely. Removing the even inputs costs a factor of at most two in each failure probability. These estimates prove the claimed density of unsatisfiable formulas. The monitor clock covers every fixed exponent $e<4$ because the encoded length is $2^{k/4}k^{O(1)}$ and local overhead is polynomial in $k$. [Full compiler accounting and moment argument](guarded-code-rejections.md) · [PCPP with a fixed proximity radius, Theorem 2.6](https://people.csail.mit.edu/madhu/papers/2005/bghsv2-full.pdf)

For any later verifier of this same monitor having fresh soundness $\sigma<\theta$ outside relative radius $\rho_0$, try $2^a$ proof descriptions each using at most $h'$ raw-symbol probes per fresh invocation and inducing a consistent proof for that input. The probability on uniform odd input that some description has fresh acceptance at least $\theta$ is at most $2^{a+1}(\sigma/\theta)^j$ whenever $jh'b$ is below the fixed dual distance. Indeed $j$ independent fresh tests compute the relevant moment and cannot distinguish the uniform law from the exact fixed code. This allows a verifier selected after the family is designed, fixed before the raw input is drawn. Intersecting this estimate with the actual-cut bounds gives the shared inputs in the opening statement.

## Discrepancy after conditioning on a native input prefix

For the shrinking-radius code fix one good $D$ once per scale. Let $U_0$ denote the uniform law on all $K$ bits. Let $V$ denote a uniform point of $C_D$ plus independent Bernoulli($p$) noise, $p=\rho/2$. Any rejection under $V$ requires noise weight above $\rho K$, an event of probability $e^{-\Omega(G)}$. Splitting the input into old and new symbols would not suffice to identify genuine bit rereads. The following estimate permits **every partition of the individual bits**, including those determined by the run.

Fix the start of one discovery interval. The already observed pin set $P$ has at most $K/2-t$ members. A given reachable start transcript is the cylinder fixing just these bits. Their joint distribution under the uniform codeword is exactly uniform since $|P|$ is below the dual distance. Consequently the start cylinder has the same probability under $V$ and $U_0$, and the conditional law of the *entire noise vector* still consists of independent Bernoulli($p$) bits. In particular $V(\mathrm{reject}\mid\text{start})\le e^{-\Omega(G)}$ for each such start.

Fix an arbitrary split of the remaining bits into $X$ of size $t$ and $Y$ of size at least $K/2$. Conditional on the start cylinder the density of $V$ relative to $U_0$, minus one, is
$$
 B(x,y)=\sum_{0\ne v\in D} (1-2p)^{|v|}\chi_{v_P}(P)\chi_{v_X}(x)\chi_{v_Y}(y).
$$
This follows by convolution of the uniform subspace with the noise. The notation $\chi_{v_P}(P)$ uses the fixed *values* on $P$. In normalized Walsh bases the entries of the coefficient matrix are the signed displayed coefficients at positions $(v_X,v_Y)$. No two distinct $v$ give the same pair because their difference would be supported in $P$. For any coordinate subset $T$ of relative size $s>\epsilon$, projection of $D$ onto $T$ has fibers of size at most $(s-\epsilon)^{-1}$. Indeed for a $j$-dimensional kernel, the fraction of coordinates on which all its vectors vanish is the average of the biases of its words, including the zero word. It is at most $2^{-j}+\epsilon$, and the fraction must be at least $s$. Thus in each row and column there are at most $1/(t/K-\epsilon)$ and $1/(|Y|/K-\epsilon)$ entries respectively. The operator norm is at most the geometric mean of the maximum absolute row and column sums. The normalized kernel therefore has norm
$$
 \Delta\le O(\epsilon^{-1/2})(1-2p)^{(1-\epsilon)K/2}=2^{-\Omega(G)} .
$$
This bounds the difference of expectations of **any** row-column vector inner product by $\Delta$ times its two root-mean-square norms under uniform independent row and column bits. If the column vector is allowed to depend on up to $r$ adaptively probed row bits, expansion in $V(t,r)=\sum_{i\le r}\binom ti$ row characters adds a factor $\sqrt{V(t,r)}$. These identities use the difference of two input laws. The actual SAT sign need not itself have small spectral norm.

## Applying the kernel to a real suffix with hindsight advice

Condition on any starting history. Let $E$ be the event that the run rejects and the specified interval has a cheap exact snapshot with the stated advice $s=\lfloor cG\rfloor$ and combined bit budget $r$. Count queries of both the full-array reconstructor and the actual suffix. Given the end prefix, independently fill the still-unseen bits and use a possibly different successful advice on this companion. Under $U_0$ the joint success probability is at least $U_0(E\mid\mathrm{start})^2$ by conditional Jensen. For a fixed fill, catalog the companion's $(X,c_{\rm end})$ pairs. Record its controller and advice, and at most $r$ pin positions of $X$ whose values on the two computations differ from the fill. Simulate the reconstructor on the corrected input and then the suffix on its exact array. Both executions agree with the companion. Outside $P$, the set of all pin queries contains every element of $Y$ because the native companion rejected. Delete at most $r$ positions to recover $Y$ exactly. The number of pairs is at most
$$
 J=N^{O(1)}2^{s+1} V(K,r)^2 .
$$
For each pair its end-prefix rows allowing a successful companion form a cylinder $A$ of uniform mass $u$ on this split. At fixed fill these cylinders are disjoint in the full remaining input cube even though their splits may differ.

For each candidate original advice put $1_A(x)e_{C(x)}$ on the row side, with $C(x)$ the actual end memory and $e$ a unit basis indexed by complete arrays. On the other side reconstruct a proposed memory $C'$, then simulate the suffix from it and the true formula, returning $e_{C'}$ only on a rejecting result within the combined bit cap. Return zero otherwise, including on divergence. Its row-bit degree is at most $r$ by the tree expansion and its norm is at most one. The inner product is exactly the successful-rejection indicator on $A$ for this advice. In particular it is zero on every satisfiable input, including when the simulator invents a false rejection using a wrong array. Its expectation changes by at most $\sqrt{u V(t,r)}\,\Delta$ between the two conditional laws. Sum over the disjoint cylinders and the independent original advice. On the noisy-code side their total is at most $2^{s+1}V(\mathrm{reject}\mid\mathrm{start})$. Therefore
$$
  U_0(E\mid\mathrm{start})^2
     \le 2^{s+1}\left[e^{-\Omega(G)}+\sqrt{J V(t,r)}\,\Delta\right].
$$
Here $\log_2 V(K,r)=O(c\log(2/c)G)$ using the binary subset count. Choose $c$ sufficiently small. The bound is $2^{-\Omega(G)}$ after the square root, surviving a union over the $O(1/\epsilon)$ intervals and conditioning on odd parity. This proves the whole-array statement. The same proof uses the unit-vector norm even for astronomically many different hypothetical work arrays. [Detailed exact equality calculation](discovery-epoch-snapshot-codes.md)

For the native incoming-address bound simulate a rejecting suffix with an oracle for its initial array and a local write overlay. Cap both its distinct old pin queries at $r$ and its distinct incoming word queries at $q=\lfloor cG/w_0\rfloor$, where $w_0=1+\lceil\log_2(Uv+2)\rceil=\Theta(\log N)$ for address range $U$ and word alphabet of size $v$. At fixed row and column its expansion in work characters has support size at most $(q+1)(Uv)^q$ and squared coefficient norm at most one. The companion can be replayed from the start memory by listing at most $q$ differing incoming address/value pairs. Replace $2^{s+1}$ in the catalog by $(q+1)(Uv)^q$. On genuine cut arrays the truncated indicator is again zero on all satisfiable inputs. Applying the difference bound with the extra norm factor $\sqrt{(q+1)(Uv)^q}$ proves the second assertion for small $c$. [Work-oracle expansion](spectral-work-reads.md)

## Charging words truly changed during this interval

Suppose the native solver has at most $T$ work-read slots on each of the family inputs under consideration, or restrict the bad event to runs that meet this budget. Assume $T\ge K$. Let $q$ be the number of distinct addresses the suffix reads before local overwrite whose end value **differs from the start value** at this interval. A work word written back to zero can count. Put $H=\lfloor c'G^2/(T w_0^2)\rfloor$. For $H\ge1$, the uniform probability of a rejecting run meeting the clock and some epoch meeting both $q\le H$ and the old-pin cap $r$ is at most
$$
      O(\epsilon^{-1})(2^{-\Omega(G)}+2^{-\Omega(H)}).
$$
Thus if $T=O(N^e\operatorname{polylog}N)$ with fixed $1\le e<2$, on almost every odd input each discovery interval supplies many actual later reads: either $\Omega(r)$ distinct old pins or $\Omega(N^{2-e}/\operatorname{polylog}N)$ distinct changed words. These witnesses are distinct *across* the specified intervals because each pin has a unique discovery epoch and each charged word read has a unique latest store. The proof-reader obstruction holds on the same inputs for a monitored solver with this clock.

Given the start prefix forecast the fixed start-memory value on each first incoming read. The adaptive tree polynomial approximates the indicator of a rejecting suffix with $T$ distinct incoming addresses, $H$ exceptions, and $r$ old pin probes, with uniform error $\eta=2^{-4H}$ and work degree $d'\le H+O(\sqrt{TH})$. The word “with” specifies upper caps, and a native run with at most $T$ read slots qualifies under the distinct-address cap. The approximation is valid on all hypothetical arrays. Its coefficient vector has pointwise Euclidean norm at most $1+\eta$ and support size $\le (d'+1)(Uv)^{d'}$. Replaying the companion uses at most $H$ corrections from start memory. The catalog consequently costs $\log_2 J=O(\log N)+2\log_2V(K,r)+O(Hw_0)$. The difference of expectations for its approximant on one cylinder costs at most $(1+\eta)\sqrt{uV(t,r)(d'+1)(Uv)^{d'}}\Delta$. For the two measures the total approximation error over the disjoint cylinders is at most $2\eta$. On the noisy-code side the exact indicator is bounded by actual rejection. Conditional coupling, summation and a square root now give the displayed estimate because $d'w_0=O(\sqrt{c'}G)$ and $Hw_0=O(\sqrt{c'}G)$. The two caps and the proof-reader agreement conclusion thus concern the same native run. [Adaptive few-error polynomial](adaptive-default-polynomial.md)

The costs above are compatible with a fast solver's instruction budget. At $T=N$ the changed-word threshold per interval is proportional to $G^2/(N\log^2 N)$. Even charging distinct native reads on all $O(1/\epsilon)$ intervals gives $O(G^2/(N\epsilon\log^2N))=o(N)$. The mandatory $K$ first reads also fit: the explicit private pin clauses occupy $\Omega(K\log N)$ bits. No argument here converts the same-run certificate and memory obstructions into a contradiction with the elapsed-time hypothesis. A further argument has to exploit an operation a fast solver would be forced to repeat too often, or produce a cheap reader for these genuine timely rejections.


A proposed way to turn the disjoint charges into a time contradiction was to demand that a read supplied by an interval must finish during that interval. A correct solver can first copy its entire input into a disjoint work bank and then execute its original algorithm against that copy. This takes an additional linear number of native instructions or fewer, and a fixed bank tag suffices with the standard constant-factor address headroom. Every pin-discovery interval now lies in the copying phase. The computation using the copy can occur after every such interval has ended. Monitoring this wrapper still gives the stated cut bound. An argument that needs the consumers to lie within their discovery intervals therefore requires another property of the solver.
