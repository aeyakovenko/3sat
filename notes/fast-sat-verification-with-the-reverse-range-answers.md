# A linear SAT computation with many incorrect predictions on its truthful inputs

There is an explicit family of proper ASCII 3-SAT files and a single globally correct deterministic SAT program that decides **every file in the family** in $O(L)$ steps, including every truthful UNSAT file. Here $L$ counts the encoded bits. Fix any observer of the type in the Weinstein–Yu prediction argument before drawing the stream. Except on a fraction $2^{-L/(\log L)^{O(1)}}$ of logical streams, it makes at least $L/(\log L)^{O(1)}$ numerical mistakes on the resulting truthful execution. This separates two proposed measurements of the same genuine computation.

The new family augments the original weighted transcript with **one reverse sum per query**, delivered only after every forward claim. For truthful reverse sums the two formats have exactly the same number of models, for *every possible vector of forward claims*. The construction therefore preserves every single-error neighbor and every simultaneous pattern of errors among the forward records. Verifying a reverse annotation independently is a different task. ## One relation that the solver checks in linear encoded time

Use $n$ source operations, with $u=n/(\log n)^2$ weighted updates and $q=n-u$ forward queries on the fixed Weinstein–Yu schedule and integral subsequence. Write $p=(t,x,y)$ for an insertion, of weight $w_p$, and $v=(j,a,b)$ for a query. Put
$$
D_1=[t<j],\qquad D_2=[x\le a],\qquad D_3=[y\le b].
$$
The timestamps are distinct. $F_j$ sums the weights having all three indicators one, and $R_j$ sums the weights having all three zero. Strict complements on the two spatial coordinates matter when points coincide. With $W$ the total inserted weight and $M_S(j)=\sum_p w_p\prod_{i\in S}D_i$, expansion gives
$$
 K_j=F_j+R_j=W-\sum_i M_{\{i\}}(j)+\sum_{i<k} M_{\{i,k\}}(j).
$$
This is ordinary inclusion–exclusion. Every marginal on its right uses at most two coordinates. For each coordinate pair, sort updates and queries by the first coordinate, maintain cumulative weights on the second with a binary indexed tree, and report the appropriate prefix at each query. Process equal values in the inclusive direction, using timestamps to implement the strict time test. Three such planar sweeps and the three one-coordinate scans cost $O((q+u)\log n)=O(L)$ deterministic word steps. All totals fit in a fixed number of logarithmic words. Compare the proposed integers $f_j+r_j$ against $K_j$ for all $j$ and accept the SAT instance on the first failure.

## An explicit proper 3-CNF

The header and the gate clauses are public. A one-hot query selector $J$ and its suffix OR wires specify whether each update time is earlier than the selected query. Four kinds of records specify the input: one bit-pin packet for each bit in each update's two coordinates and weight, one query-coordinate packet per query, one forward-annotation packet per query and one reverse-annotation packet per query. For the comparison use the same query IDs in both formats. One may either omit the original template’s optional final public query in both, or include it with its forward and reverse claims in both. In the latter case its forward word comes after the last source operation and contributes no online prediction. Below we count the $q$ original IDs. The $q$ forward annotations are logically interleaved with the operations. All $q$ reverse annotations come after the final operation. There are $O(u\log n+q)=O(n)$ packets. Any physical permutation is allowed.

For a selected $J=j$, the query packet pins both spatial coordinates, and its two annotation packets pin the two base-$2^b$ digits for each of $f_j,r_j$, with $b=\lceil\log_2(n+1)\rceil$. These six digit banks use shared binary decoders of $O(n)$ total size, so a packet needs only constantly many conditional clauses. Every update bit is pinned unconditionally on a full file. Compute the selected query's $F_j+R_j$ by including an update exactly when its three comparisons all agree. Ripple adders and comparisons use $O(ub)$ gates. Use $2b+1$ bits on both sides to compare with the sum of two arbitrary $2b$-bit claims, preserving the high carry. Assert inequality. Use full gate equivalences, pad short clauses with distinct false anchors, pin any identifier holes, and pad physical packets to one aligned word as in the original construction. The two low-digit dictionaries have distinct prefixes with consecutive paired suffixes ending in ASCII 2 and 3. Toggling the low bit of *either* annotation changes just one physical bit. The fixed word-width coefficient is chosen once to accommodate a packet.

The total length is $L=\Theta(n\log n)$ bits. For each selection $J=j$, the records fix all operands and every gate then has a unique evaluation. Thus the number of models is exactly $|\{j:f_j+r_j\ne K_j\}|$. If all $r_j=R_j$ this equals $|\{j:f_j\ne F_j\}|$. The last reverse annotation, for example, can turn a truthful UNSAT file into a uniquely satisfiable file by one bit.

The scan and the three planar sweeps give one **globally correct** SAT program with the stated time bound on this family. Choose a public size-indexed header and word-aligned layout, with $n$ recoverable at the start (for example from a public DIMACS comment). The program checks that this header, all fixed equations, the packet inventory and their allowed encodings form the prescribed template. An $O(L)$ byte scan, direct-indexed ID tables, and comparison with generated fixed syntax suffice, even on out-of-order packets. It runs the exact marginal check on validated files and a complete SAT procedure otherwise. Validation and sweeps succeed equally on truthful and untruthful annotations of either kind.

## Hard predictions on the fast program

One can use the physical chronological order and make the recognizing program read the packet bank sequentially, without prereading later words. More generally, for any correct solver assign logical packets to its first requests for previously unseen packet positions, retaining each assigned word on repeated requests. On the truthful master take $f_j=F_j$ throughout and $r_j=R_j$ in the suffix. Before the final reverse annotation is supplied, a partial master admits two completions, a full truthful file and its one-bit final reverse neighbor. Therefore the program eventually issues its next new load. The resulting physical files are ordinary immutable inputs. In particular, the linear-time recognizer still costs $O(L)$ on all of them. Every forward claim is issued before any reverse answer becomes available at a first discovery.

Weinstein and Yu's hard distribution has independent uniform updates and query coordinates in the public schedule. Its original operations need no modification or deletion, even when the last operation is an update. For a fixed observer, give it the last $b_0=\lfloor\log n/(\log\log n)^3\rfloor$ complete native query intervals through issue of each pending forward load, all their values and instruction counts, and $d_0=\lfloor(\log n)^2/(\log\log n)^3\rfloor$ additional word probes into frozen native state, exposed packets or earlier chronological operations. It has no uncharged persistent store. The reverse packet slots still have their unrevealed status. An online range-counting procedure can simulate the master during the forward part, emitting predictions and feeding those words back as annotations. It never has to produce the reverse suffix. Along its all-correct path, a linear master prefix costs
$$
 O((b_0+1)(L+n)+qd_0+n\log n)
   =o\!\left(n(\log n/\log\log n)^2\right)
$$
probes. Truncate off-path computations after a public polynomial deadline. For a forecast distribution the probability of staying on a fixed truthful trajectory is the product of the masses assigned to its true forward answers. The small-success bound under the source product distribution is $2^{-B}$ for $B=n/(\log n)^C$ and a fixed $C$. The mixture using a fixed numerical predictor with probability $1-1/n$ and a uniform candidate otherwise assigns probability at least $(1-1/n)^q[n(n^2+1)]^{-e}$ to a truthful path with $e$ prediction errors. Consequently the fraction of streams with a fast prefix and $e<cB/\log n$ is at most $2^{-\Omega(B)}$ for small constant $c>0$. The recognizer has a fast prefix on every stream, so the mistake alternative actually occurs. This gives many failures even on one common prefix of a fast UNSAT run and its fast uniquely SAT final neighbor. [Weinstein and Yu, Theorem 1 and §4](https://arxiv.org/pdf/1604.03030) · [Observer and trajectory proof](predicting-annotated-answers-on-a-truthful-sat-run.md)

The promise on the reverse annotations is essential for comparison with the original predicate. Increasing $f_j$ by one and decreasing $r_j$ by one can cancel if both new words are legal. No construction of the truthful reverse suffix in linear time is assumed. In fact the displayed $K_j$ identity converts a procedure that outputs **all** exact reverse sums into one outputting all forward sums, at an additional $O(L)$ deterministic cost, and conversely. The verifier only needs the paired sums. This example refutes the inference from frequent forward prediction errors and single-bit-sensitive claims to a slow batch SAT decision. The unrestricted original files give a separate randomized test and a deterministic fast path on all unique-model inputs. ## Can a short generator change the quadratic exponent?

The hard schedule also gives an explicit size test for a proposed succinct-input upgrade. Fix $c=2$ and $u=n/(\log n)^2$. Even if all coordinates of all operations are available free, the $u$ independent weights alone form a uniform $n^u$-point space given that geometry. A deterministic decoder of descriptions of at most $s$ bits covers a fraction smaller than $2^{s+1-u\log_2 n}$ of that space for each fixed geometry. The decoder may use all the free coordinates. In order for the **measure padding argument alone** to guarantee that its image intersects the complement of an exceptional event of mass $2^{-B}$, it needs $s+1>u\log_2 n-B$ up to the endpoint for the exact count. For the weakened published bound used above $B=n/(\log n)^C$ with $C>2$, this amounts to $s=\Omega(n/\log n)$. The available online work scale $n(\log n/\log\log n)^2$ is already $o(s^2)$ there. Hard instances could exist in a much smaller image; the distributional estimate cannot locate them there by mass.

There is also a test on replacing the distribution itself: a fixed distribution supported on at most $2^s$ **entire update streams** always admits a nonuniform online algorithm making $O(1)$ probes per operation and answering every query correctly with probability at least $2^{-s}$. Hardwire the most likely update stream into the unrestricted local computation, keep the current stage in one cell, and compute every answer against that stream. This uses no knowledge of future query coordinates. In particular the same $2^{-B}$ small-success ceiling cannot be transferred unchanged to $s<B$, regardless of how complicated the generator is to evaluate on a native RAM. This latter argument concerns the update stream including its geometry; it is a separate support bound from the conditional count on weights above. Weinstein and Yu discuss guessing all updates in their Proposition 1 and Appendix A.1. Neither estimate excludes a native-time proof exploiting the code of a particular succinct generator. [Weinstein and Yu, Theorem 1, Proposition 1 and Appendix A](https://arxiv.org/pdf/1604.03030)
