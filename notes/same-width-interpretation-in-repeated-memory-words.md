# Constant-code interpretation at exactly the guest width using repeated memory values

Fix the same rounded width, writable packed input, zero exterior and separate-operation word RAM on both sides. Suppose a fixed guest uses any finite number of data registers. Assume that on its runs at all sufficiently large lengths, at every guest instruction boundary some one word value occupies at least a fixed fraction $\delta>0$ of the $Q=2^w$ logical addresses. The value can depend on the input and change at any step. Every address may have been read and written. There is a single native interpreter template, with an immediate encoding the guest and a suitable integer parameter, that simulates these runs at the **same width**, in time $O_{P,\delta}(T+1+n/\log(n+2))$. Its number of stored instructions is independent of $P,\delta$ and the time bound. The physical memory has exactly $Q$ words. This is a separate construction from the [fixed-host coefficient interpretation](anchored-interpreter-for-ram-exhaustion.md).

The interpreter needs $R=O_P(1)$ words for interpreted data registers, control and decoded text. Its own fixed number of hardware registers can hold a current block number, a bitmask, a repeated word, a search cursor and a fixed number of counters and temporaries. Choose a fixed power of two $B\ge4(R+1)/\delta$, encoded with the guest. For sufficiently large $n$ we have $B\le w$, so all within-block positions fit in a single selection mask. Partition the whole address circle into $q=Q/B$ disjoint consecutive blocks of $B$ addresses. A block is eligible if it contains $R$ or more copies of some one value. Find such a value and $R$ matching positions by bounded scans of the block, trying each of its own values in turn. The $O(B^2)$ work is a guest-dependent constant. If a value occurs at least $\delta Q$ times, and $g$ blocks are eligible, then $\delta Q\le gB+(q-g)(R-1)$. Hence $g\ge\delta q/2$ at large lengths. Eligibility can also be taken as the direct hypothesis if this last bound holds by other means.

Initially use an all-zero block beyond the packed input and initialize the interpreter there. Within its active block, save the selected original word in a hardware register and place the $R$ private words at the selected positions. Other positions in that block stay unchanged. On a guest LOAD there, return the saved original if the mask selects its offset. Otherwise read physical memory. Access to a private word walks the single mask to its requested position in $O(B)$ time. An unchanged guest write to a selected position needs no physical action. On the first differing write there, keep the guest store operands in hardware temporaries, scan blocks circularly starting just after the last selected block, and take the first other eligible block. Copy the private words, restore the old selected positions to their saved value, install the new base, mask and saved value, then perform the pending write. The two active blocks are disjoint. An eligible block always exists elsewhere at large lengths. Decoding the fixed guest immediate or scanning its instruction text needs only constant additional hardware temporaries; its tables fit in the $R$ hidden words. At short lengths where the encoded text or masks do not fit, a correct fixed SAT fallback can run before modifying the input. For a guest satisfying the hypothesis eventually but possibly failing it at finitely many other lengths, the guest description may also encode a threshold before which to run fallback.

Here is the amortization for the circular search. Group block inspections into consecutive revolutions of $q$ inspections, starting from the initial scan cursor. Each complete revolution inspects each block once. At its start at least $\delta q/2$ blocks are eligible in the logical state. An initially eligible block that is rejected on inspection has since had a guest write in it. An initially eligible block that is selected and then abandoned has a guest write to one of its selected positions. These charges for distinct blocks are distinct writes; allow the final selection in the revolution without a charge. With at least two eligible blocks an individual search cannot wrap to its own active block. All complete revolutions therefore take $O_{P,\delta}(T+1)$ time. A partial final revolution costs $O_P(q)$, already charged if any full one occurred. If it is the only revolution, all except $O(1+\lceil n/w\rceil/B)$ blocks were initially wholly zero. The same per-inspected-block accounting then bounds this initial partial cost by $O_P(1+n/w+T)$. This proves the time claim even for runs making arbitrarily many changes of active block. For this accounting place the pending logical guest write just *before* its migration search. Each inspected block is disjoint from the old active one, so its eligibility agrees with this choice of timing. Since at least two blocks are eligible after the logical write, the search succeeds before returning to the old block. This convention puts every charged write between consecutive inspections or just before the first.

The equality test can also be applied to residuals $M[i]-f(i)\pmod{2^w}$ for a fixed easily evaluated address function such as zero or $i$. Remember the residual and return $f(i)$ plus that residual for a hidden original. To initialize directly on the all-zero exterior, include the constant-zero function among a fixed finite menu and allow a block to qualify under any member. Save its function index with its residual. The same amortization counts an eligibility loss against a guest write to the block.

At $D>a$, any $O(n^a)$ guest automatically retains $Q-o(Q)$ zeros because it has made only $O(n^a)$ writes and the packed input has $O(n/\log n)$ words. The address-space saturation case is different. At coefficient one, a simple native loop can fill the memory with its address in $O(Q)=O(n)$ time since $Q\le2^{16}(n+2)$. A SAT decider could do this after computing its verdict and holding that bit in a register. This defeats the repeated-value hypothesis even with a linear time budget. The identity residual recognizes that particular memory. No argument here supplies a finite menu of predictors for arbitrary computations.
