# When can sampled proof checks certify the sign of a RAM computation?

The paired SAT construction computes its hidden verdict by running the programs it monitors. A possible saving would encode a short proof of that computation in the formula and expand only a few probabilistic checks. Two separate costs arise. The prover chooses its witness after seeing the formula, and the computation being certified may itself use the verifier's public list of challenges. The following tests quantify both costs. [Paired verdict construction](shortcut-capital.md) · [Short PCPs with a full shared proof table](random-tape-decision-witnesses.md)

## Fixing tests when the claim can inspect the batch

Let $R_1,\ldots,R_d$ be independent uniform challenges. A deterministic procedure exposes at most $u$ distinct challenge positions by adaptive indexed reads. Its transcript determines a claim $x$, its false bit, and a dictionary of at most $M$ admissible proof oracles for the false bit. For each such fixed pair of claim and oracle, the probability of passing one fresh challenge is at most $\sigma<1$. Tests on an unexposed position must be the fixed verifier on that claim and proof evaluated at that position's challenge. Then the probability that **some** dictionary member passes every test is at most
$$
 \min(1,M\sigma^{d-u}).
$$
Condition on a complete exposure transcript. Its unexposed positions are still independent uniform challenges. Discarding exposed positions can only increase success. Apply independence to each fixed dictionary member and sum. The proof chosen at the end can depend on the entire published batch. To test $v$ different pins, each with this bound, sum their failure probabilities. With perfect completeness and an honest admissible proof for each true pin, $v M\sigma^{d-u}<1$ ensures a single common batch with exact signs for every pin. Its existence suffices for a worst-case family if the list itself is included in the input and in its encoded length. A direct 3-CNF can guess a short description indexing an admissible proof and unroll the tests using the same description. This requires locally evaluating that description and generating the claim's checker in the proposed size bound. A short syntax alone gives no bound on evaluation.

Both losses can occur simultaneously. Take an alphabet $B$ with $h=\sigma|B|$ an integer at least $u$, and choose each challenge uniformly in $B^M$. Expose the first $u$ challenges. For each column choose any $h$-element subset containing its exposed values. The resulting subsets form the claim. Dictionary member $i$ accepts a test if its column $i$ belongs to its subset. Every fixed member succeeds with probability $\sigma$. The probability that some member passes all tests equals $1-(1-\sigma^{d-u})^M$ by independence of the fresh columns.

The exposure condition concerns everything that sets the false verifier's acceptance predicate. It cannot be inferred from the number of reads executed by the monitored RAM. For example, let that RAM always return zero. Give the verifier an input consisting of a sorted list of at most $d$ challenges from a universe of size $K\ge 3d$. It accepts the true bit unconditionally and accepts the false bit exactly when the current challenge occurs in the input list. It uses binary search, needs no prover, and has soundness at most $1/3$ at every fixed input. If the formula publishes its very own sampled batch in that list, it accepts the false bit on every selected test. This failure persists for arbitrarily many tests by increasing $K$.

## Testing the public sample without telling the checker its index

A stronger bound allows the hidden verdict $g(R)$ to depend arbitrarily on the full batch. Store $R=(R_1,\ldots,R_d)$ as a raw, unsorted array of independent uniform symbols in a finite alphabet. For a selector $j$ and proposed bit $c$, run a fixed deterministic test $V^R(j,c,r,z)$ whose ordinary input contains the challenge value $r$ and a shared proof description $z$. It can read at most $h$ distinct raw array entries adaptively per invocation. Charge all such reads, including those used to decode the proof or interpret the public input. If a physical formula read or machine-word read reveals parts of several raw symbols, charge every distinct symbol so disclosed. In a contiguous packing of $b$-bit symbols, a $W$-bit word touches at most $1+\lceil W/b\rceil$ symbols. A locally regenerated formula word may require additional raw-symbol reads, which count in the same budget. Granting the entire touched symbol can only strengthen the tester. At position $i$, call the same program with $r=R_i$ and fresh private scratch. It gets no separate copy of the position $i$, public prefix sums, sorted copy of $R$, or uncharged preprocessing. The $s$ bits of $z$ may encode arbitrary preprocessing, and may be chosen after seeing the entire batch.

Assume that for every fixed array $R$, wrong bit $c\ne g_j(R)$, and every $z$, the acceptance probability on a fresh independent uniform $r$ is at most $\sigma$. Put $m=\lfloor d/(64(h+1))\rfloor\ge1$. For any fixed selector and bit, the probability of a false assertion supported by **some** $s$-bit description passing all $d$ tests is at most
$$
 2^s \big((8\sigma)^m+(8/m)^m\big).
$$
Sum over both bits and all $v$ selectors for a simultaneous conclusion. For $\sigma\le1/32$, $m\ge16$, a batch size $O((h+1)(s+\log(2v)+1))$ with a sufficiently large constant makes the probability of any false assertion less than one. A constant repetition of fresh coins inside a single test may first be used to reduce $\sigma$; $h$ then counts all accesses of that repeated test. If each actual true bit has an admissible description accepted on every fresh challenge, all signs on such a batch are exact. This argument imposes no bound on the number of public symbols that the original monitored RAM itself reads.

**Proof.** Fix $j,c,z$. On a batch where all tests pass, draw an edge $i\to k$ whenever the call with $r=R_i$ reads array position $k$. There are at most $hd$ edges. At least $d/2$ positions share the same answer to the question whether they read their own position. In the underlying undirected graph without loops, the degree sum is at most $2hd$. At least $d/4$ vertices of the selected type therefore have degree at most $8h$ (including the case $h=0$). Choose an ordered sample of $m$ different indices uniformly, independently of $R$, and let $I$ denote the resulting set. At each draw at least $d/4-(m-1)(8h+1)\ge d/8$ indices of the selected type are still available without creating an edge to a previous draw. Thus conditional on any such $R$, the chance of an edge-free set of the selected type, ignoring loops, is at least $8^{-m}$.

Fix $I$ and all outside entries. In the type with no self-reads, none of the selected invocations reads any element of $I$ as array data. If no completion gives the false bit, its contribution is zero. Otherwise choose one completion $R^*$ on which $c$ is false. For each argument $r$, use $V^{R^*}(j,c,r,z)$ and require that it accept without querying $I$. This fixed event has probability at most $\sigma$. On every actual batch in the event under study the selected calls are identical to these restricted calls, by induction on the probe transcript. Since the arguments $R_i$, $i\in I$, are independent conditional on the outside entries, their joint success probability is at most $\sigma^m$.

For the type with self-reads, define $H(r)$ as the first address in $I$ that the test tries to probe using challenge $r$, or a failure symbol if it never does. This function is determined by the outside entries. All calls have the *same* $H$ because the ordinal was withheld. On the selected event $H(R_i)=i$ for every $i\in I$. If $p_i=\Pr[H(r)=i]$, their joint probability is $\prod_{i\in I} p_i\le m^{-m}$ by independence, the arithmetic–geometric mean inequality, and $\sum_i p_i\le1$. Averaging over outside entries and $I$, adding the two possibilities, and dividing by the graph sampling probability proves the bound. The random deletion of interfering oracle queries is related to proofs of time–advice bounds for function inversion. Here the case of finding one's own index and the case of passing against a genuinely false completion both have to be controlled. [De, Trevisan and Tulsiani](https://www.ias.edu/sites/default/files/math/De_Trevisan_Tulsiani.pdf)

Giving the test its own index really can break the bound. It can compare $r$ with $R_i$ in a single read, accepting the false sign on equality. Every published test passes, while on a fresh challenge the acceptance probability is $1/|B|$ for alphabet $B$. The sorted table in the preceding example similarly provides an index of all samples at no cost. Arranging the raw independent samples in their draw order and charging preprocessing through $z$ are essential for the theorem.

To use this in the SAT diagonal for a time bound $T$, compile the common description and the $d$ tests into an ordinary formula with a locally generated physical layout. The tested computation can run a solver on that very layout containing raw $R$, then choose the verdict against its answer. If an exact-input proof system has the soundness above, cheap honest descriptions on every true pin, and the entire explicit formula fits $o(T^{1/e})$ bits (including all public challenges, index names, and compiled tests), an $O(N^e)$ solver would finish inside the opposing clock. The usual single-program version takes one pin whose certified native computation rejects exactly when that solver accepts the pin. The physical word generator is fixed before the simulation and serves the formula with the verifier program as a finite data parameter. Interpreter overhead on a solver of fixed width and all reduction costs must be absorbed by the strict time slack. On a batch where the signs are exact, this gives a contradiction. No verifier meeting these size and honest-description requirements is established here.

## Comparing empirical and fresh acceptance

The same sampling rule works with imperfect completeness and soundness on opposite sides of a threshold. Write $p_z(R)=\Pr_r[V^R(r,z)=1]$ and $\widehat p_z(R)=d^{-1}\sum_i V^R(R_i,z)$, suppressing the fixed selector and proposed sign. The fresh probability may depend arbitrarily on $R$. As before the verifier gets the challenge value and can address the full raw array, while the tested ordinal is withheld. If every invocation asks for at most $h$ distinct array entries, then for every even integer $k\ge2$ and fixed $z$,
$$
 \left(\mathbb E_R|\widehat p_z(R)-p_z(R)|^k\right)^{1/k}
 \le \sqrt{k/d}+\min(1,2kh/d).
$$
In particular, take $k$ proportional to $s+\log(2v/\delta)+1$ and round it up to an even integer. With probability at least $1-\delta$ the discrepancy is $O(\sqrt{k/d}+kh/d)$ simultaneously for all $2^s$ descriptions and all $v$ selectors and both bits. This is a statement about descriptions chosen after seeing $R$. The classical sampling term already occurs for a verifier that returns a fair fixed Boolean predicate of $r$. A verifier that tests membership in the first $h$ array entries gives empirical excess at least $h/d-h/|B|$ on distinct arrays over a large alphabet $B$. These examples do not resolve optimal dependence on the moment order in the second term.

To prove the moment bound, give every position an independent pair of uniform challenge values and an independent fair sign. Let the sign choose which member is public in $R$, with the other member in a new array $R'$. Thus $R'$ is an independent ghost sample. By conditional Jensen, the desired moment is at most the $k$th moment of
$$
 Z=d^{-1}\sum_{i=1}^d \big(V^R(R_i,z)-V^R(R'_i,z)\big).
$$
Expand $Z^k$ by drawing $k$ independent uniform indices with replacement. Condition on their equality pattern, giving distinct groups labeled in order of first occurrence. The actual addresses of these groups are uniform *distinct* locations, independent of their challenge pairs. A factor from group $j$ equals its fair sign times the difference of the outputs on its *two fixed challenge values* in a prescribed order. Only the sign of a group of odd multiplicity survives as a separate factor. Let $o$ count these groups.

Evaluate the test at both challenge values for each group. This uses at most $Q=\min(d,2kh)$ distinct addresses in total. For the analysis only, supply an observer with all target pairs in first-occurrence order and disclose on every probe whether the address is a target and which group it represents. The test itself sees its usual raw reply. One can generate an independent background array, plant the publicly selected member of each target pair at its hidden address, and use background entries everywhere else. All unhit target labels stay uniformly assigned to the unqueried addresses after each adaptive probe. This follows inductively since every non-target reveal is drawn from the independent background, while each hit reveals its own label and public value. Pad to $Q$ distinct inspected addresses after the actual executions by any available addresses, retaining the same distribution of hidden labels. Nothing about the fair sign at a still unhit label has been observed. Conditioned on this transcript, if an odd-multiplicity group remains unhit, the product's expectation is zero by its fresh swap sign. Each difference factor has absolute value at most one. The absolute expectation for this pattern is therefore at most
$$
 \frac{\binom Q o}{\binom d o}\le a^o,\qquad a=\min(1,2kh/d).
$$
Use the value one when $o=0$. Revealing each sampled group's actual ordinal as an extra ordinary input to the test would invalidate the uniform-hidden-location step.

If $o=k-2t$, pair off all but one occurrence in every odd group and all occurrences in every even group. This produces $t$ disjoint equality pairs in the sampled indices. Any particular matching of $t$ disjoint positions has probability $d^{-t}$ of all those equalities. Taking a union bound over matchings and using $(2t-1)!!\le k^t$ bounds the moment by
$$
 \sum_{t=0}^{\lfloor k/2\rfloor}{k\choose 2t}(2t-1)!!\, d^{-t}a^{k-2t}
 \le (a+\sqrt{k/d})^k
$$
with the empty matching counted once. This proves the assertion. The hidden-index argument is a joint use of the public samples for proof checks. We have not established priority for this moment inequality.

There is a version charging only the **total** number of distinct raw entries accessed across actual tests, summing the per-test counts. Assume merely that the test halts on all inputs. Fix a budget $dh$ and $0<\eta\le1$. On a batch satisfying that budget, truncating each test just before it exceeds $H=\lceil 2h/\eta\rceil$ distinct probes changes at most an $\eta/2$ fraction of the empirical outcomes. For upper deviation, default to zero, which can only decrease the fresh acceptance probability. For lower deviation, default to one. Apply the moment theorem to the two truncated verifiers with $k$ of order $\eta^2d/(h+1)$, using a sufficiently small constant so that the moment root at $h=H$ is at most $\eta/4$. Markov's inequality and a union over the two defaults give
$$
 \Pr[\,|\widehat p_z(R)-p_z(R)|\ge\eta,\quad \text{actual total probes}\le dh\,]
 \le C\exp(-c\eta^2d/(h+1))
$$
for universal $C,c>0$. For parameters with no even $k\ge2$ at the desired order, enlarge $C$ to cover probability one. This statement charges no probe bound on fresh invocations of the original verifier. A uniform bound over a hindsight dictionary and both bits follows by a union bound. If true bits have honest admissible descriptions with fresh acceptance above a threshold, their empirical acceptance transfers on the same batch whenever their actual costs meet the tested cap. All false descriptions below the threshold transfer in the other direction with the stated margin. A single explicit verifier may count the total probes and compare the fraction of passing tests with a fixed threshold. Compiling it into SAT requires bounding its other work as well.

## A consequence for an actual solver's rejection

Fix a globally correct deterministic SAT solver $S$, a monitored clock $T$, a deterministic test $V$, and an $s$-bit description format. Build the ordinary formula $F_R$ which guesses one $z$, executes every public check $V^R(R_i,z)$ with fixed clocks, requires at least half of them to pass, and enforces total raw-symbol probes at most $dh$. The last constraint can count every probe, or track distinct positions afresh for each check using a dictionary. Bound all simulation and bookkeeping work when compiling the formula. The decoder for virtual formula words, and any checks that use $S$'s own code or the template, operate on this actual layout with raw pinned $R$.

Here is the sole soundness premise. On every fixed batch on which $S$ does not reject $F_R$ within $T$, every $z$ has fresh acceptance at most $1/3$. No honest proof for any run is assumed. Choose $d$ large enough that except on probability $\delta$ every $z$ with total cost at most $dh$ has discrepancy below $1/6$. The moment argument allows $d=O((1+h)(s+\log(2/\delta)+1))$ with an appropriate constant. On all these good batches, $F_R$ is unsatisfiable. Indeed if it were satisfiable then its successful $z$ would have fresh acceptance greater than $1/3$. But global correctness precludes a rejection of this satisfiable input, so the premise says the opposite.

It follows on those same batches that either the actual rejecting run of $S$ takes more than $T$, or the computation really does reject by $T$ and **every** $s$-bit proposed proof with fresh acceptance at least $2/3$ costs more than $dh$ total empirical probes. Otherwise the proposal would pass the sampled threshold, making the formula satisfiable. A sound sampled-check system thus never obtains timely, cheap, convincing rejection proofs alongside timely solver runs on all batches of its own construction. A superlinear time exclusion from this disjunction needs a proof of the cheap-honest-proof upper bound on actual rejecting runs and a clock exceeding the encoded length. The theorem about the disjunction does not supply either.

## A covering bound for proofs of genuine SAT rejections

There is an unconditional version using an ordinary proof of proximity for a bounded computation. It allows the native computation to be sensitive to every raw input symbol. Fix a correct deterministic SAT solver $S$ and a deterministic proof-bit decoder with a fixed polylogarithmic query-time cap. The decoder can inspect the whole formula, its raw public batch, and a description shared over all queried proof addresses. Each proof query starts with fresh private memory. Give it the proof address and the public scale. A decoded proof is one fixed answer function on proof addresses for those public data and the description. This condition precludes choosing a new answer to the same proof address for each random challenge.

At each large integer $k$, set $H=2^k$ and $s=2^{\lfloor k/4\rfloor}$. There is a uniform family of ordinary 3-CNFs with $N=s\,k^{O(1)}$ encoded bits, indexed by all $K=db$-bit batches for $b=k^2$ and $d=s\,k^{O(1)}$. Thus $\log N=\Theta(k)$. The hard-proof assertion below concerns a standard perfectly complete PCPP witness to the statement that the actual run of $S$ rejects the particular generated formula within a fixed monitor clock. It concerns that proof's indexed bits; a solution of SAT has no obligation to build the proof.

Let $A$ be the batches on which the monitor sees this genuine rejection by its clock, and $B$ the batches giving a genuine UNSAT formula on which the monitor misses the rejection. For **every** $R\in A$, no description of at most $s$ bits in the given format decodes any perfectly accepting PCPP proof for the actual timely rejection at $R$. Codes shorter than $s$ may include an explicit length in a fixed format or be enumerated using $s+1$ bits. Equivalently the length needed is $\Omega(N/\operatorname{polylog}N)$ bits, with constants and polylogarithmic power depending on the fixed programs. Moreover if $\rho_k$ is the applicable proximity parameter and $W(K,t)=\sum_{i=0}^{\lfloor t\rfloor}\binom Ki$, the cardinalities satisfy
$$
 |B|+W(K,\rho_k K)\,|A|\ \ge\ (1-2^{-k})2^K .
$$
In particular if $S$ runs in $O(N^e\operatorname{polylog} N)$ time for $e=1,2,3$, every rejection fits the monitor and $B$ is empty. The lower bound then gives at least $(1-2^{-k})2^K/W(K,\rho_k K)$ distinct batches forcing the proof-description obstruction. With the inverse-polylogarithmic proximity in the short PCPP theorem this is $2^{(1-o(1))K}$. This is a count in the number of freely varying public input bits; its fraction of all batches can tend to zero.

**Uniform construction.** Fix a universal pair language with an explicit input $x=(P,1^k)$ and an implicit string $Y$ of length $K$. Require $K\ge2^{\lfloor k/4\rfloor}$ and accept exactly when the deterministic monitor code $P$ on $(x,K,Y)$ signals a rejection of the monitored computation within $H$ guest steps. On arbitrary inputs this is a polynomial-time pair language. The guard bounds $H$ by $16(K+1)^4$. A direct tape simulation keeping a chronological list of accessed RAM addresses, scanning it as necessary and charging the word operations, costs polynomial time in $|x|+K$ for a fixed universal interpreter with logarithmic words. Very large $k$ can be rejected by comparing its value with $4\log_2(K+1)+O(1)$ first. Malformed code defaults to rejection of the pair. Here “accept” for the pair means that a timely rejection by the monitored solver was observed.

Fix the efficient PCPP for *this* universal language first, with fresh soundness at most $1/4$. At total pair length $|x|+K$ its randomness is $O(\log(|x|+K))$ and its verification time is polynomial in $|x|$ and $\log K$. A true pair has a proof passing every coin choice; at an implicit input farther than $\rho_k$ from the true implicit fiber of this exact length and fixed $x$, each fixed proof passes at most a quarter of all coins. Use each independent raw $b$-bit symbol to supply the coins, ignoring excess bits. For the dimensions used, $|x|=O(k)$ and $\log K=O(k)$, so $b=k^2$ is ample for all large $k$. [Ben-Sasson, Goldreich, Harsha, Sudan and Vadhan, Definition 2.2 and Theorem 2.5](https://people.seas.harvard.edu/~salil/research/polylogPCP.pdf)

Use a fixed bounded verifier and a fixed physical 3-CNF compiler. For $F_{x,R}$ guess one shared proof description, perform the $d$ PCPP tests with the decoded proof, and require at least half to pass. Each test gets its challenge as ordinary data without its row index, and the raw $R$ as an indexed input. Physical lookups by the decoder are through the formula's fixed word generator. Root this generator in the encoding of the bounded verifier with its *finite verifier and decoder program text supplied as input data*. Generating a syntax word consists of decoding static gate and memory-record coordinates or a pin. It never executes the encoded test or decoder. The same generator thus serves the decoder's virtual access to its own formula. All checks use one deterministic decoded proof, so even malicious descriptions induce genuine oracle functions. The outer loop alone sees the test ordinal. It privately initializes each call and adds the verdict to the total. The shared proof description is guessed only once.

One test takes $k^{O(1)}$ time and reads at most $h=k^{O(1)}$ distinct raw symbols, including the physical formula emulator. Set $d=s k^C$ with $C$ a fixed integer large enough for simultaneous discrepancy smaller than $1/6$ except on $2^{-k}$ of batches and for the given time allowances. There is no circular exponent choice. For every fixed $C$, eventually $\log K\le k$ and $|x|=O(k)$ with constants independent of the exponent $C$ in $d$. Public dimension fields can be supplied in binary and the test need only derive $d$ from $K/b$. Fix polynomial overheads for the local syntax decoder first, using the logarithm of its clock as the size parameter. A per-test clock $k^D$ large enough for the PCPP and the chosen decoder has $\log(dk^D)=O(k)$ independently of its fixed exponent. A fixed-layout clocked RAM check with private variable and memory addresses, read-only input pins and an enforced counter yields an ordinary 3-CNF of $N=s k^{O(1)}$ bits. One may pin the $K$ raw bits at distinct literal signs, so distinct batches give distinct encoded formulas. The dimensions do not depend on any decoded proof. [Packed RAM formula layout](packed-band-transfer.md) · [Unique pin layout](unique-checksum-witnesses.md)

Now use a fixed $P$ that sees its own text in $x$, serves the physical words of this very $F_{x,R}$, and simulates $S$, signaling a rejection as soon as one occurs. All uses of $P$ by the PCPP are through the fixed universal pair language. The syntax generator and universal language are fixed before choosing $P$. At most $k^{O(1)}$ native overhead per solver step suffices on these inputs, including virtual packed-word accesses, a sparse address trie if the solver has a larger width coefficient, and the universal instruction decoding. The $H$ guest steps charged to the monitor therefore include all rejections of a solver with the claimed $O(N^e\operatorname{polylog}N)$ time when $e<4$. Take $x=(P,1^k)$ throughout this scale. The true implicit fiber of the universal pair language at this $x,K$ is exactly $A$.

**Covering proof.** Each $R\in A$ gives an actual rejection, hence an unsatisfiable $F_{x,R}$. Perfect completeness of the PCPP provides a proof of this genuine rejection. Any short description decoding a perfectly accepting proof would pass every sampled test on this very $R$, contradicting unsatisfiability. No uniformity of the choice of the short description is assumed. Next, consider a sampling-good $R$ outside all Hamming balls of radius $\rho_k K$ about $A$. The proximity theorem says every fixed proof has fresh acceptance at most $1/4$, including every decoded proof after $R$ is fixed. Simultaneous concentration for all descriptions makes every empirical acceptance fraction less than $1/2$. Hence $F_{x,R}$ is unsatisfiable. Because $R$ is outside $A$, this is a late genuine rejection in $B$. Counting the good batches gives the displayed bound. When $A$ is empty, all fixed inputs are far and at least a $1-2^{-k}$ fraction give late rejections. This empty-fiber case permits the argument without an exact-input tester for an arbitrarily sensitive RAM computation. The missing step to an unrestricted lower bound remains an upper bound on local descriptions of these PCPP proofs for timely genuine rejections.

## Exact input binding

There is already an obstruction to an exact-input verifier with few raw-array probes. Fix an $R$ and one perfect-completeness description for its true bit. For any alteration of $R$ that changes the true bit, a fresh check on $R$ must inspect the altered positions with probability at least $1-\sigma$. Otherwise the same description, used verbatim on the altered array, would pass with probability greater than $\sigma$. Consequently every collection of disjoint sensitive blocks at $R$ has size at most $h/(1-\sigma)$. If both signs have perfect completeness on every array, the total function $g_j$ thus has block sensitivity at most $b=\lfloor h/(1-\sigma)\rfloor$. Its deterministic decision-tree depth on raw array symbols is at most $(b+1)b^2$. Indeed every inclusion-minimal sensitive block has at most $b$ members, since restoring any single member at the altered array changes the answer back. A maximal disjoint collection of minimal blocks has union of size at most $b^2$, and that union is a certificate for $R$. Repeatedly choose a zero input consistent with prior answers and read its certificate, returning zero upon a match and one if there is no consistent zero input. On an actual one input each failure contributes a disjoint sensitive block in the newly queried coordinates. After $b+1$ failures one may return zero. This proof applies to arbitrary finite symbol alphabets and unbounded offline computation. In particular, parity of all binary raw symbols requires $h\ge (1-\sigma)d$. Soundness only for inputs far from a valid implicit input does not provide the fixed-input property used above.

## A sharp cost for a few public seeds

There is an infinite family of polynomial-time constructible 3-XOR systems on $m$ Boolean proof coordinates with the following property. A verifier knows the entire system and wants to report one row violated by a supplied assignment. It can read individual assignment bits adaptively. It always verifies the row it reports and may instead abort. Give it $L\ge1$ equiprobable public seeds, each specifying an arbitrary deterministic query tree, and require at most $f$ aborting seeds for every assignment, $0\le f<L$. The optimal worst-case depth of any one tree is
$$
 \Theta\!\left(\min\!\left\{m,\ 1+\frac{m}{f+1}+\log_2\frac{L}{f+1}\right\}\right).
$$
The trees may depend nonuniformly on the given system. The constants are independent of $L,f,m$. The same expression holds if the tree may output a wrong row on a failing seed, provided three additional bit queries are charged to verify it.

Use Hopkins and Lin's Theorem 1.1. Every assignment violates a constant fraction $\mu>0$ of rows, and a linear-degree Boolean pseudoexpectation satisfies every row. The authors give polynomial time for the full construction. The fixed system may be stored as a public array of triples and signs. We do not require a uniform polylogarithmic-time generator of its entries from $m$. Randomized versus deterministic search for a violated local constraint on such instances also appears in work on total search problems in ZPP. The bounds here ask exactly how many fixed public seeds can fail at a given per-seed depth. [Hopkins and Lin, Theorem 1.1 and equation (7)](https://arxiv.org/pdf/2204.11469) · [Total Search Problems in ZPP](https://drops.dagstuhl.de/storage/00lipics/lipics-vol362-itcs2026/html/LIPIcs.ITCS.2026.60/LIPIcs.ITCS.2026.60.html)

Here are the deterministic lower bounds in more detail. Let $D=\Omega(m)$ be a degree for the pseudoexpectation, and write $v_i$ for the multilinear degree-three indicator that row $i$ is violated. Then $\widetilde E[1]=1$ and $\widetilde E[v_i p]=0$ for $\deg p\le D-3$. Work in the Boolean multilinear quotient. A binary query whose indicator has real degree at most $w$ gives every depth-$q$ leaf a path indicator $P_\ell$ of degree at most $wq$. For a correct total finder labeling that leaf by $i$, one has $P_\ell=P_\ell v_i$ as functions on assignments. If $wq+3\le D$, each leaf has pseudoexpectation zero while their indicators sum to one. Hence $wq+3>D$. The argument allows arbitrary precomputation of the queries and nonlinear Boolean functions of up to $w$ coordinates.

Compose any $f+1$ distinct seed trees and return the first confirmed violation. This gives a correct total finder of bit-query depth $(f+1)q$, so $(f+1)q+3>D$. Also, if $q+3\le D$, every seed has an aborting assignment. The path followed by that assignment fixes at most $q$ input bits. Its entire subcube aborts. A uniform random assignment therefore has at least $L2^{-q}$ aborting seeds in expectation. For $f>0$ this gives $q\ge\log_2(L/f)$. For $f=0$ a single seed must already be exact. Together with the constant cost of producing a valid row, these are the stated lower bounds.

For the upper bound, preselect $a$ independent random rows for each of the $L$ seeds. Each seed reads its rows until it finds a violation or exhausts the list. For a fixed assignment and any fixed $f+1$ seeds, the probability they all abort is at most $(1-\mu)^{a(f+1)}$. A union bound over the $2^m$ assignments and $\binom L{f+1}$ seed subsets gives a valid fixed choice as soon as
$$
 a>\frac{m\ln 2/(f+1)+\ln(\mathrm e L/(f+1))}{-\ln(1-\mu)} .
$$
Each sampled row costs at most three input queries. As a second upper bound, read all $m$ proof bits and find a violated row by unrestricted local computation. This last step is a query bound. A RAM storing the public rows also pays the work of inspecting them.

## Aggregating large parts of the proof

Allow the verifier a single binary query to any parity on at most $w$ assignment bits, $1\le w\le m$. The optimal depth of an exact deterministic finder on the same family is $\Theta(m/w+\log m)$. The degree bound proves the first term. For the second, the set of row labels at all leaves must be inconsistent. Any inconsistent subfamily of $k$ rows has at most $3k$ involved variables, and reading those variables gives a total finder of depth $3k$. Thus $k=\Omega(m)$, requiring at least $\log_2 k$ binary queries in the worst case even if they could return any Boolean function of the entire proof. This lower bound also applies to arbitrary degree-$w$ binary predicates.

For the matching parity upper bound, Gaussian elimination gives a dependency summing to $0=1$ on at most $m+1$ rows. This follows by expressing one inconsistent augmented row using a basis of at most $m$ coefficient rows and comparing right sides. On every assignment the violation bits of these rows XOR to one. For $w\ge3$ partition this dependency into blocks of at most $\lfloor w/3\rfloor$ rows. Query the parity of the violations in each block until an odd block is found. Each query is one public affine parity on at most $w$ proof bits. Bisect the odd block, checking one half at a time, until a violated row remains. The depth is $O(m/w+\log m)$. For $w=1,2$ read all coordinates. Implementing a large parity from individual RAM loads must charge these loads or supply and validate a separate representation. Similarly, a deterministic tree of shallow *word*-valued probes can have more than $2^q$ row labels. The logarithmic term above counts binary responses.

## Consequence for exact verdict checks

Given any perfect-completeness, constant-soundness proof-oracle verifier, add a selector bit to the proof. Its first branch runs the original verifier. Its second branch treats proof bits as an assignment to the fixed 3-XOR system and accepts if a uniformly drawn row holds. Both branches use fresh public randomness sampled as a product. The modified verifier retains perfect completeness and constant soundness. With the public instance precomputed, checking the second branch takes a random row lookup and three proof-bit queries; exact uniform sampling can be replaced by a fixed binary range that samples each row within a factor of two. On a false claim a fixed list of $o(m)$ selected tests always has a common accepting proof through the second branch. Otherwise those rows alone would be inconsistent, contradicting the row-label lower bound. An adaptive deterministic exact check which certifies rejection by exhibiting a violated test still incurs the corresponding search cost. Random trials, in contrast, find one in constant expected trials for every *fixed* proof.

This construction rules out an implication from the usual PCP parameters alone to short sampled formulas deciding the weighted verdict. Particular verifiers may expose a cheap algebraic contradiction, including Gaussian elimination for this gadget. Interactive proof systems can also let a later message depend on an earlier random challenge. The quantifiers and adversary differ again in cryptographic RAM arguments. Using such a protocol to produce ordinary SAT still requires exact soundness against arbitrary assignments to the encoded witness variables. The present bounds concern checks of candidate proofs and leave the unrestricted SAT time question open.
