# Two LOADs and one STORE on the eight-bit sign-plane SAT catalog

Give four variables one common positive disjunction and select each positive and negative unit clause independently. Pack the selectors as $u=P+16M$, with four-bit masks $P,M$. The three consecutive writable three-bit words at addresses 0, 1 and 2 hold the low, middle and high parts of $u$, using a zero padding bit in the last word. The other five memory words and all registers start at zero. SAT requires $(P\mathbin{\&} M)=0$ and $M\ne15$.

**Finite claim.** No program with two LOAD sites, one STORE site and two fixed-target binary branch sites can decide all 256 inputs in eight executed instructions. Addresses and STORE payloads may independently be any three-bit literal or any register. Cycles, input overwrites and scratch memory are included. Even if every branch can choose its outgoing edge separately for each input and each visit, the necessary original reads and correct terminal labels are incompatible with every such control graph.

## Compulsory reads and the data palette

For each input and each original cell, try all replacements of that cell that respect the padding. Call the cell essential on this input if one replacement changes SAT. Correct execution must load its original contents before its first overwrite. Until that read, the original and edited runs have identical registers and control. If the cell is overwritten first, the two full configurations become identical. Exactly seventeen SAT inputs require all three original cells. Thus two direct LOAD sites cannot work, and a program with no repeating data site also fails. If there were only one effective branch, its two deterministic continuations after execution must both lead to different terminal answers for the total program to be nonconstant. A continuation returning to that branch would leave only one possible terminal reachable, so such a program also fails the three-read test.

Write $r$ for the first LOAD's destination and let the second either overwrite $r$ or write $s$. Unwritten registers are constant zero. In the former case exchange the LOAD names to sort their address operands. Require at least one indirect LOAD. The two address choices together with the STORE address and payload give 4,329 data palettes, including literal scratch addresses 3 through 7. For each palette and each input try any ordered list of data operations, independent of a program's control graph. If a site occurs $q$ times before a verdict on a successful path, at least $q-1$ comparisons separate those visits. Without one, the fixed data successors already constitute an endless unconditional cycle. A final comparison after the last useful data instruction accounts for a further step. Thus only lists of length $l$ with $l+\max q\le8$ need be tried. A data instruction immediately preceding a fixed terminal may instead be bypassed, preserving the verdict and improving the clock. An instruction leaving registers, memory and read mask unchanged may be omitted in this relaxed test. Omitting an original-value rewrite can only retain additional opportunities to read its original contents.

Simulate these lists on the full eight-address memory, keeping the subset of original cells loaded before any write. Exactly twelve palettes permit all essential reads for every input, using a possibly different list on each. Every survivor needs a literal STORE payload in $\{1,2\}$ and a direct LOAD at the other of these addresses.

## Static control and the eight-step clock

Name the two LOADs 0 and 1, STORE 2, the comparisons 3 and 4, and the free YES and NO terminals 5 and 6. Redirect incoming edges to bypass any data instruction with a fixed terminal as its successor, and repeat on chains. This makes it sufficient to enumerate three data successors among the five instruction sites. Sites need not all be reachable. For each comparison allow any pair of distinct successors among all seven vertices, sorting them since both edge choices are free. Select any start and name the first comparison reached site 3. Discard graphs unable to reach both verdicts within eight instructions or unable to reach YES via at least three loads. There are 734 surviving graphs.

Enumerate all paths of at most eight executed instructions in each graph to each terminal. For each of the twelve palettes and each input, some path ending in its correct verdict must actually load all its essential cells before overwrite. **Zero graph/palette pairs pass this test.** No assumption about the shape of a loop or the comparison implementation enters the final test. The stronger omniscient-edge formulation still imposes the original-read obligation; without that obligation, arbitrary input-dependent branch choices could of course answer directly.
