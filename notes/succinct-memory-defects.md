# What it costs to find a wrong read in a succinct memory history

**Research journal, 24 November 2026.** Suppose a small Boolean circuit gives the instructions, addresses and claimed read replies for an exponentially long history, indexed by time. Can a single ordinary existential SAT instance detect a false reply without the circuit having to name the previous writer? Even with one writable bit and three nontrivial event types, the general problem is complete for $\Sigma_2^P$ under polynomial-time many-one reductions. A closely related question about *true* histories is already as hard as SAT. These facts distinguish the cost of reconstructing a source from the cost of reconstructing its value. [Application to quadratic and cubic solvers](chronological-solver-registers.md)

## A complete problem on one bit

The input circuit $C$ maps each $p$-bit time in increasing order to one of four events: idle, write zero, write one, or read with alleged value one. Initialize the bit to zero. Decide whether some read has the wrong alleged value. Membership in $\Sigma_2^P$ follows by guessing a read and the time of a preceding zero write with no intervening write, or guessing that there was no previous write at all. One universally chosen time suffices to test either absence condition. For general words a guessed consumer and unequal producer plus the same universal time suffice. [Formal finite last-writer equivalence](../lean/CrossBlockProducers.lean)

For hardness start with a circuit predicate $R(x,y)$ with $u$ and $v$ input bits for $x$ and $y$. Divide the ordered times into $2^u$ rows, one for each $x$. Give each row four consecutive phases of $2^v$ slots, with $y$ the slot index. In phase zero reset the bit to zero at slot zero. In phase one write one at slot $y$ exactly if $R(x,y)$ is false. In phase two read with alleged value one at slot zero. All other events are idle. The event circuit adds $O(u+v+1)$ gates to one copy of $R$, and its time index has $u+v+2$ bits. At the read in row $x$, the alleged one is wrong precisely if every $y$ satisfies $R(x,y)$. Thus an error exists precisely if $\exists x\,\forall y\,R(x,y)$. This reduction preserves the quantifiers even though there is one address, a fixed word value at every read, and a fixed time for every read. The quantified circuit problem is the standard complete problem for the second existential level. [Stockmeyer, *The polynomial-time hierarchy*](https://doi.org/10.1016/0304-3975(76)90061-X)

An unconditional polynomial reduction of these defect instances to a single ordinary SAT instance, with SAT indicating an error, would put $\Sigma_2^P$ in NP. This observation supplies no quantitative lower bound on the verification algorithm under the research hypothesis that SAT already has a polynomial-time solver. It identifies the general quantified problem that a faster construction would also handle. It does not rule out a direct verifier for the particular circuits arising in a SAT solver.

## Source timestamps in completely honest histories

Now make the row reset write zero, have phase one conditionally write **zero** when $R(x,y)$ is true, and have the read report **zero**. Every read reply is correct for every predicate. Nevertheless its source is the reset exactly when $\neg\exists y\,R(x,y)$. In the other case the last time gives the lexicographically last satisfying $y$. The circuit for the chronological events still uses one copy of $R$ and elementary time-index tests. These events can also be executed in order by a deterministic RAM with one designated bit of data memory and separate scratch for evaluating $R$. The conclusion concerns the designated bit's history.

Consequently a uniform polynomial-time algorithm that, given a succinct honest event circuit and a read time, returns the last writer would imply $P=NP$. Conversely an NP oracle detects whether any same-address write occurs in a given interval. Repeatedly checking the right half of the interval and otherwise taking the left finds the last writer in $O(p+1)$ queries. For a circuit-valued pointer function, a polynomial-size nonuniform bound for all such honest histories would put SAT in P/poly: choose $R(x,y)$ to be the uniform polynomial-size verifier circuit for $x$ an encoded formula of a fixed length and $y$ a candidate assignment. A solver with hard incoming *values* cannot be inferred from the mere difficulty of this pointer-query problem. [Related work on verifying RAM executions](https://people.cs.georgetown.edu/jthaler/TransformationToCircuitSAT.pdf)

## Testing whether uniform diagonal inputs force easy histories

There is also a solver-quantifier issue with using the very low description complexity of the hard formulas. Fix a correct solver $A$ and the bounded diagonal verifier $V$ for its rejection. Use the fixed-description-plus-zero-padding family of formulas $F_j$ from the register-history argument. The proof derives $F_j\in\mathrm{UNSAT}$ by soundness of this particular verifier. The encoding can include the binary source length $j$ in a short fixed prefix of tautological clause records; its size and local-access bounds are preserved. A separate solver $B$ can exploit this theorem on the *whole* family.

Read the prefix, bound the candidate length $j$ and regenerate the expected formula length and header using fixed-width arithmetic. Reject the match on malformed metadata, overflow or length mismatch. The public source is the fixed code followed by zeros, so a polylogarithmic setup suffices for local word access to the expected formula. Compare the actual and expected formula one packed word at a time. Return UNSAT on equality and otherwise apply $A$ to the actual input. Handle any excluded finite source lengths by the fallback. All matches are sound because $V$ monitors $A$. The equality branch uses $O(N)$ time and $\operatorname{polylog}(N)$ writable bits. One can keep the generator tables in a dense polylogarithmic bank and do the comparison in a fixed number of registers. Even transmitting the entire bank at every one of the logarithmically many checkpoints from [the linear-time test](solver-snapshot-descriptions.md) costs only polylogarithmically many bits. $B$ retains $A$'s assumed time exponent on all inputs.

This is a change of solver, with the family fixed. Replacing the monitored solver inside $V$ by $B$ changes the formula. In particular, modifying $B$ to return UNSAT on its *own* corresponding family loses this proof of correctness: a quick trace of that return can itself cause its formula to be satisfiable. The simple input description permits a shortcut *after* diagonalizing against a different solver. It gives no common upper bound on actual histories in the matching solver-family pair. Priority for these specific formulations is unverified.

### One family for a certified collection of solvers

The quantifiers can be strengthened within an effectively enumerable collection. Fix $k\in\{2,3\}$, one actual $O(N^k)$ SAT solver $A_0$ for the verifier's SAT calls, and a sound enumeration of triples $(M,C,c)$, where $M$ is a correct solver on the fixed load/store ISA that halts within $CN^k$ steps at word width $cL$. Soundness here is an explicit hypothesis on the enumeration. Then a **single** zero-padded family satisfies the register-history bound for every listed program, with constants and a threshold allowed to depend on its triple.

In the signed verifier, guess a finite transcript showing that the enumerator printed the chosen triple. Check the transcript by running the enumerator to that point. On an honest branch for a fixed triple this is a constant amount of work, independent of formula length. Use the chosen code in the controller tests and use $A_0$ for both materialized SAT calls. A finite program can be compiled into a transition circuit by selecting an instruction according to its PC. On every fixed triple this contributes only $\operatorname{poly}(L)$ gates, with constants depending on the code. Bound the lengths of the proposed code, constants and enumeration transcript by $L$ before checking, with fixed encoding conventions; reject out-of-range computed widths or clocks (use $cL\le L^2$, $CN^k\le N^{k+1}$). Every fixed genuine triple passes these cutoffs eventually. Guest addresses here are **data in the comparison circuits**. The physical addresses of the verifier's SAT calls have the fixed width bound for $A_0$, and guesses and generated arrays are capped at a fixed polynomial in $N$. Each fixed triple therefore has the same honest-branch exponent as in the original proof. Every successful branch certifies rejection by some correct listed program. The usual signed diagonal forces UNSAT and excludes every such short branch on the same family. A finite collection is an immediate special case.

Adding the length tag and running the recognition shortcut on this joint family gives another correct $O(N^k)$ program outside the enumerated collection: its true register history on the recognized inputs has polynomial-in-$L$ circuits. For this last assertion use a fixed-duration setup of $\operatorname{poly}(L)$ steps for the generator templates followed by a loop comparing one packed word per fixed number of instructions, padding the bounded number of case distinctions. On equality each loop entry has a known successful comparison flag and an index computed from the time. A circuit can hardwire the polylogarithmic setup and immutable tables, compute the index, look up the genuine input word from the template, and replay the constantly many within-loop instructions. The final rejecting halt stutters. If this program were listed, the joint bound would apply to it at all sufficiently large source lengths. This diagonal escape is consistent with the ordinary undecidability of certifying all correct SAT programs at a fixed time exponent. It gives no exclusion of the fixed fallback solver.
