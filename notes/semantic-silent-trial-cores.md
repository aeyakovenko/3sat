# Using word values to give unretired ranks short losing cores

A sound value analysis can overcome the clause-count obstruction on actual, never-retired ranks. Here is one locally indexed CNF encoding of the priority scheduler in which infinitely many distinct such ranks have a core of **three clauses** at every sufficiently large stage. The same ranks require $\Omega_e(2^j)$ clauses in the private adjacent-row encoding. A diagonal argument identifies the quantifier still preventing a SAT lower bound. ## Which clauses the compiler emits

Start with the private-trial formula. For each active rank $e$ include the scheduler consequence $\neg o_e\lor b_{j,e}$, where $b_{j,e}$ says it pulses within its budget. A winner must have pulsed. On a recognized subset of the actual guest instruction set, statically overapproximate all reachable states of its program at the native word width $w$. If no abstract state can signal, append the unit $\neg b_{j,e}$. Otherwise emit a tautology in that clause slot. On an unrecognized instruction sequence it is always sound to emit the tautology. The added clauses follow from the *full* formula. In particular the unit is justified by the values the guest computes before the tick at which a splice would otherwise insert a false signal. With the losing pin $o_e$, the two added clauses suffice to refute it. The compiler uses the code, width and scale, with no access to the true winner or to a SAT solver.

For a concrete analysis, restrict to direct-control programs on at most four data registers using loads, copies, word constants, addition, unconditional jumps, zero tests, idle and signal. Stores may be ignored if all future loads admit every value. Distinct occurrences of these guest texts really are in the normalized program enumeration; the analysis can recognize their finite instruction templates before simulating the universal interpreter. At precision $b\le w$, retain the program counter and the simultaneous tuple of register residues modulo $2^b$. Word addition commutes with this projection. A load can set its destination to any residue. Zero tests at a nonzero residue must take the nonzero edge. At residue zero permit both edges if $b<w$, and only the zero edge if $b=w$. Use the known initial residues, or reset all used registers before consulting them. Every concrete transition projects to an admitted abstract transition, by induction on real execution time. Reachability of a signal in the finite graph therefore overapproximates signaling even with unbounded running time. The native deadline can only reduce the set of signals.

Set $b=\min(w,\max(1,\lfloor \log_2(j+2)/10\rfloor))$ when testing stage $j$. For a program with $P$ instructions, the graph has at most $P 2^{4b}$ states and at most $O(P2^{5b})$ edges, even enumerating every abstract load result. The active program texts can be recovered in $\operatorname{poly}(j)$ time by the stated enumeration. Hence indexed generation of the extra clause slot still runs in $\operatorname{poly}(j)$ time. This is a standard finite abstraction. Congruence analysis has been used for decades. The application here is the explicit core comparison on named ranks. [Cousot and Cousot](https://www.di.ens.fr/~cousot/COUSOTpapers/POPL77.shtml) · [Granger](https://www.tandfonline.com/doi/abs/10.1080/00207168908803778)

## Infinitely many real programs and a precise precision requirement

For each fixed $k\ge1$, make a guest text that computes $c=2^{k-1}$ by repeated doubling from one. If $c=0$, halt silently. Otherwise load a word $v$, double it $k$ times, add $c$, and signal precisely if the result is zero. Here the doublings are actual instructions and all arithmetic wraps at $w$ bits. For $w<k$ the first guard halts. For $w\ge k$ the result is congruent to $2^{k-1}\bmod 2^k$ for every load, so it is nonzero. Thus the program never signals at any scale. Each of its color occurrences stays unretired forever. At every sufficiently large stage $b\ge k$ and the value analysis establishes silence. The branch to signal is syntactically present, and the conclusion holds for arbitrary loaded data. Conversely, if $b<k\le w$, the analysis just defined projects both the computed constant and the final result to zero. It admits the nonzero edge at the first guard and the zero edge at the final guard. This gives the exact precision transition for this family. Three-clause losses occur in infinitely many fixed rank columns without establishing the special coverage required by the two-rank theorem.

There is also one fixed program that defeats this residue analysis at every precision $1\le b<w$. Start with $a=1$. At the top of a loop compute $z=a+a$. If $z\ne0$ copy $z$ to $a$ and repeat. If $z=0$ exit and signal only if $a=0$. The loop invariant on actual words is $a\ne0$: the only copy to $a$ follows a nonzero test of its source. The true exit has $a=2^{w-1}$. At smaller precision the abstract execution can take the nonzero edge when $z$ first becomes zero modulo $2^b$, copy that zero residue into $a$, then take both successive zero tests. Including the exact zero/nonzero status of each register and propagating the tested status along a branch is enough to prove the invariant. Registers whose arithmetic result has zero low residue may conservatively receive either consistent status. This example isolates a lost word-value property and a constant-size repair.

## Why even a sound fast rule misses late losses

For a deterministic, uniformly indexed loss test $D(j,e)$ that only returns positive on genuine losses, the coverage condition already faces an unconditional diagonal. Use a fixed program template that obtains its own designated rank in the active prefix, runs $D(j,e)$, and signals on positive. The index can be obtained by the same fixed self-description construction as for the two-tag race, with polynomial-in-$j$ startup; on stages before finding the designated occurrence it idles. If this rank ever wins then its own positive test was unsound at that stage. Hence it never retires. Once active, only finitely many smaller ranks ever win again. Every sufficiently late positive that fits its own execution budget would therefore make it win, a contradiction. A polynomial-in-$j$ deterministic loss test must miss this always-losing rank on **every** sufficiently late stage. This proof uses no fast-SAT hypothesis. It also applies when the rule is embedded in a richer but still polynomial-time deterministic preprocessing pass and $D$ inspects its indicated slot. A checker that guesses a separate proof for each loss has different quantifiers; finding an accepted proof is exactly where the hypothetical SAT algorithm enters the earlier argument.

The open step is coverage for a sound, sufficiently cheap *nondeterministic* scheme on the ranks constructed against that scheme.
