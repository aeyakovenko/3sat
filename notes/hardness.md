# Can hard witnesses supply pseudorandomness for the diagonal simulation?

The conditional witness lower bound in [the succinctness experiment](succinct.md) gives hard truth tables on infinitely many inputs. A hardness-versus-randomness argument normally needs a *uniformly accessible* function hard at all sufficiently large lengths. I tried to close that gap directly under the hypothesized SAT algorithm.

**The hard function can be constructed.** Let $r$ be the arity, $Q=2^r$, and $s=\lfloor Q/(Cr)\rfloor$, for a sufficiently large absolute constant $C$. A bounded-fanin circuit of size at most $s$ over a fixed basis can be encoded in $O(s\log(s+r))$ bits. For large $r$, the number of descriptions is less than $2^Q$, so there is a truth table of length $Q$ requiring more than $s$ gates. We construct the lexicographically first such table. Searching with an oracle for the second level of the polynomial hierarchy is a standard explicit-construction technique. [Oliver Korten, *The Hardest Explicit Construction*](https://ieee-focs.org/FOCS-2021-Papers/pdfs/FOCS2021-5stbVHiOp5jRHWlSl41FkR/205500a443/205500a443.pdf)

For a prefix $p$ ask whether there is a full extension $y$ such that every size-$s$ circuit misses a bit of $y$. Given $y$, guess a circuit and evaluate it on all $Q$ arguments to test for an exact fit in nondeterministic RAM time $\widetilde O(Qs)$. Reduce this test to explicit SAT in quasilinear overhead, call the assumed $m^d$ SAT algorithm, and complement its bit. This gives a deterministic hard-table test in $\widetilde O((Qs)^d)$ time. An outer nondeterministic verifier guesses $y$ extending $p$ and runs that test. Another quasilinear reduction and SAT call decide prefix extendability in $\widetilde O((Qs)^{d^2})$ time. All reduced lengths are polynomial in $Q$ and all words have $O(\log Q)$ bits. [Williams, quasilinear RAM reduction](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

Append zero if the resulting prefix extends to a hard table, and one otherwise. In $Q$ calls the procedure constructs a hard table at every sufficiently large arity in total time $\widetilde O(Q(Qs)^{d^2})$. On an $r$-bit input, construct the table and return its indexed bit. Even a polynomial overhead to simulate the RAM by a multitape machine preserves the $2^{O(r)}$ time bound. Thus fast SAT supplies an $E$ function of circuit complexity $\Omega(2^r/r)$ for every large $r$. The SAT hypothesis already pays for finding this independent source of hardness. The standard hardness-versus-randomness theorem then implies $\mathrm P=\mathrm{BPP}$. [Impagliazzo and Wigderson](https://doi.org/10.1145/258533.258590)

**The next inference fails on sparse accepting sets.** A generator fooling tests to additive error $1/10$ can miss a test of acceptance probability $2^{-m}$ entirely. In fact any single hitting set for all size-$O(m)$ verifiers on $m$-bit witnesses must contain every witness. For each $a$, the conjunction specifying $y=a$ has size $O(m)$ and accepts only $a$. This costs $2^m$ list entries regardless of the hardness available to generate the list.

Even succinct families illustrate the problem at the original time budget $T=2^k$. For each $k$-bit $x$, take $T$ indexed unit clauses on $T$ variables forcing $y_i=[i=x]$. A clause generator with $O(k)$ gates outputs index $i$ and the required sign by comparing $i$ with the fixed string $x$. The $T$ formulas have pairwise disjoint singleton witness sets. A single list of whole assignments hitting all of them needs at least $T$ entries. Each individual formula immediately reveals an $O(k)$-gate witness through its generator. This example concerns the attempted *input-independent* hitting set, and makes no claim about adaptive, generator-aware simulations.

A possible repair would use a randomized test with constant acceptance probability on yes-instances *without first supplying a full witness*. Its uniform construction time, verification time, and derandomization overhead would all have to fit below the hierarchy clock. The SAT hypothesis and the hard-function construction above give no such test. Simply running the explicit SAT algorithm on a length-$T$ verifier formula costs up to $T^{d+o(1)}$ under the available guarantee.
