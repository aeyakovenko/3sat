# Recovering many witness bits from one RAM execution trace

**Research journal, 24 November 2026.** Suppose explicit SAT takes linear deterministic time on the unrestricted-space logarithmic-word RAM. For a formula with one satisfying assignment, its parity against any supplied mask is then computable in quasilinear time. I tested whether formal differentiation of this computation can recover the whole assignment. The direct gradient can be wrong at every coordinate. A correction using linear forms from one execution trace gives an output-sensitive extraction theorem, including cases with dense gradient error. A linear-size parity program shows that the required number of corrections can still grow linearly.

## From a unique witness to parity coefficients

Let $F$ have encoded length $n$ and let $w$ be its unique assignment on $m$ listed variables, with $m=O(n)$. Given an $m$-bit mask $s$, test whether some satisfying assignment $z$ obeys $\langle z,s\rangle=1$ in $\mathbb F_2$. Encode the dot product with a chain of XORs and ANDs and use explicit Tseitin clauses. Under linear SAT this gives a deterministic RAM program $P$ computing the single bit $\langle w,s\rangle$ in $T=(n+m)\operatorname{polylog}(n+m+2)$ time, including construction of the query. More generally it suffices that all witnesses have the same projection on the $m$ target bits. The task is to recover the specific projected assignment. A construction that returns an unspecified NP witness for a different predicate would not suffice. [Naik, Regan and Sivakumar, §4](https://cse.buffalo.edu/~regan/papers/pdf/NRS95.pdf)

Consider any fixed deterministic RAM program with public auxiliary data, a public clock $T$, and $m$ variable mask bits, which is promised to compute a linear form $P(s)$ on the full Boolean cube. Include the length of the public data and $m$ in $T$. The model uses a fixed instruction set whose word operations have uniform polylogarithmic Boolean implementations. We use the actual RAM program to check answers on arbitrary masks below. A quasilinear existential transcript for a run would by itself furnish no deterministic Boolean circuit of that size for every mask.

## Freeze one run and expose its linear forms

Execute $P$ at the zero mask. Record the actual instruction sequence, all indirect addresses, and every control decision including halts. Build a straight-line Boolean circuit $C_0$ for this one trace. A read takes its value from the last write to its recorded address or from the initial input if there is no such write. A write updates that fixed address. A control transfer takes the observed branch. Retain the computations of the branch tests and address words as **guards** even though the recorded route is fixed. Initialized mask memory supplies actual input wires for its bits. A dictionary of the last writes suffices for construction in $\widetilde O(T)$ time. The bit circuit has $S=\widetilde O(T)$ gates with constant fan-in in the basis XOR, AND and constants, and there are $O(S+m)$ named wires. Name the original mask bits even if they are unread. Here $\widetilde O$ suppresses fixed polylogarithmic factors.

At each wire $g$ let $b_g$ be its value at zero. Compute a linear form $L_g$ in the mask by propagating formal first-order changes. An input has its coordinate form, and constants have zero. XOR adds the incoming forms. An AND of $a,b$ has
$$
L_g=b_a L_b+b_b L_a .
$$
All these linear forms have a shared XOR circuit of size $O(S+m)$. The output form can have the wrong coefficient at all $m$ positions. For example, compute a dense parity $\ell$, then output $\ell\mathbin{\mathrm{AND}}\ell$. The true answer is $\ell$, but its formal change at zero is zero. Repeated occurrences of a variable have the Boolean identity $x^2=x$, whose two sides have different formal derivatives in characteristic two. Ordinary arithmetic differentiation applies to the chosen arithmetic expression. [Baur and Strassen](https://doi.org/10.1016/0304-3975(83)90110-X)

Define $h$ as the minimum number of named wires in a list $J$ for which, on every mask,
$$
P(s)=L_{\mathrm{out}}(s)+\sum_{g\in J}L_g(s).
$$
There is always a list of size at most $m$ by using input wires for the residual coefficients. This definition allows a single dense wire form to fix arbitrarily many wrong bits.

**Extraction theorem.** Under linear SAT, the complete coefficient vector is recoverable deterministically in $\widetilde O((h+1)T)$ time without receiving $h$, the list, or any part of the answer. For a trial length $k$, guess $k$ wire indices (allow a zero sentinel), universally select a mask, then check the displayed equality using the actual $P$ and the explicit XOR circuit. All named forms are computed in one forward evaluation. Looking up $k$ entries by RAM address costs $O(k)$ word operations. The fixed two-block test, including its deterministic RAM matrix, costs $\widetilde O(T+k)$ under linear SAT. It uses the standard transcript check when compiling RAM accesses. Run the tests at bounds $0,1,2,4,\ldots$ capped at $m$. At the first successful size the list uses $O((h+1)\log(S+m+2))$ bits. Fix its bits one by one, testing existence of a completion by the same two-block procedure. The selected list now describes a single explicit linear circuit for $P$. Give its output coefficient one, run backwards through XOR gates adding each gate's accumulated coefficient to both predecessors, and output the final coefficient at every mask input. This takes $O(S+m+k)$ operations. Initialization, query construction, and all list-bit tests fit the claimed time. This extracts all $m$ original bits together when a small correction exists. ## A sufficient rank bound that accounts for indirect memory

Suppose a space $R$ of linear forms contains every guard form $L_g$ and at least one operand form for each AND. Take $R$ spanned by the guard forms and one such operand per AND, so a basis consists of named wires. Write $\rho=\dim R$. On their common kernel $K$, induction over the trace gives
$$
C_{0,g}(s)=b_g+L_g(s)
$$
for every wire. At an AND the only omitted term is $L_a(s)L_b(s)$, which vanishes because one operand form belongs to $R$. Every guard therefore retains its original value. Induction along the RAM instructions now gives identical control and addresses to the recorded run and identical computed values to the frozen circuit, even though the stored data may change. Thus $P=L_{\mathrm{out}}$ on $K$, using $P(0)=0$.

The promised linearity implies $P-L_{\mathrm{out}}\in R$. Indeed, evaluation on a basis of $R$ maps the input space onto $\mathbb F_2^\rho$ with kernel $K$. The residual vanishes on that kernel and factors as a linear form on the image. Therefore $h\le\rho$. The extraction algorithm can use this bound without ever constructing the large coefficient matrices of all the guards. The dense duplicate-AND example has $\rho=1$ if the initial parity uses only XOR, even when the ordinary gradient misses every bit. [Lean checks of the Boolean trace rule and factorization through independent measurements](../lean/UniqueWitnessBatches.lean)

**Attack on a universal small-rank conjecture.** Give a RAM program the coefficients $w_i$ as public data. Initialize an accumulator to zero, visit $i=1,\ldots,m$ in fixed order, and branch on $s_i$. Only in its true branch XOR the public $w_i$ into the accumulator. Use one separately addressed mask bit per iteration or unpack successive bits by fixed shifts and bit selection. The program computes $\langle w,s\rangle$ in $O(m)$ operations. At the zero mask, no coefficient update executes and the output form is zero. The guards include all $m$ coordinate forms. With the separately addressed input or an explicit bit-extraction circuit that just selects wires, every trace form is zero or one coordinate. For $w=1^m$ exactly $m$ corrections are required. The public coefficients in this example are trivial to read. The obstruction is specific to this trace dictionary and persists despite the global semantic linearity. The same example applies to each fixed baseline if one takes affine changes around that baseline: the executed accumulator updates then add only public constants.

For an ordinary unique-witness formula the unrestricted SAT program or the parity-query compiler may similarly introduce branching or nonlinear computations. Linear SAT alone gives no bound here on $h$ beyond $m$. An output family whose verifier yields polylogarithmic $h$ on the relevant instances would admit near-linear full recovery in its decision clock. Exhibiting such a family with an independent lower bound against full recovery is the missing step toward a SAT separation. I have not established priority for this conditional trace-based extraction bound.
