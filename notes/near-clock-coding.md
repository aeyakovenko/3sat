# Coding the combined probability of early programs at a nearby deadline

**Research journal, 24 November 2026.** Here is a single-word test for the unrestricted linear-time SAT goal. Fix a native stream sampler $S$ and an efficient literal prefix-universal reference machine $V$. On fair independent input bits, let $P_t(y)$ be the probability that $S$ publishes $y$ by time $t$. Assume explicit SAT takes deterministic linear time on the logarithmic-word RAM. Then there are constants $A,c$ such that, simultaneously for every integer $t\ge2$ and word $y$ with $|y|\le\log_2 t$ and $P_t(y)>0$,

$$
K^V_{\lceil t(\log_2(2+t))^A\rceil}(y)\ \le\ \lceil-\log_2 P_t(y)\rceil+c.
$$

The name is deterministic. Its length has no charge for specifying the deadline, the output length, or the probability. The sampler may consume one fresh random bit on every native step. Taking the sampler itself to be $V$ compares its actual time-bounded program mass to its own shortest timely program at a nearby clock. To rule out linear SAT it suffices to find one fixed sampler and reference for which the excess on the left above $-\log_2 P_t(y)$ is unbounded for every fixed clock exponent $A$. An arbitrary gap between individual and combined weights at a single deadline need not persist to the later one.

Classical prefix coding concerns unlimited decoding time. Resource-bounded coding theorems have also been studied for probabilistic representations and under hardness assumptions. The feature used here is simultaneous deterministic decoding with a polylogarithmic slowdown at the indicated output lengths. Hu, Lu and Oliveira also relate a weaker, infinitely-often coding property for Levin’s $\mathrm{Kt}$ measure to $\mathrm{EXP}\ne\mathrm{BPP}$. Their measure charges for log running time as part of the description cost. Priority for this particular implication is unestablished. [Lu, Oliveira and Zimand](https://arxiv.org/abs/2204.08312) · [Hirahara, Lu and Nanashima](https://arxiv.org/abs/2409.12744) · [Hu, Lu and Oliveira, Theorem 1](https://drops.dagstuhl.de/storage/00lipics/lipics-vol374-icalp2026/html/LIPIcs.ICALP.2026.110/LIPIcs.ICALP.2026.110.html)

## Requests at dyadic times

At epoch $q\ge1$ take the native time $s=2^q$. For $|y|\le q$ obtain a deterministic dyadic estimate $B_q(y)$ satisfying $P_s(y)/32\le B_q(y)\le P_s(y)$ and returning zero on an empty fiber. Use the [projected approximate count](near-native-counting.md) on the $s$ fair bits sufficient for this run. The relation on the bits is acceptance of a single bounded transcript with the prescribed output; the test has size $s\,\mathrm{poly}(q)$. Here a primary string is one full $s$-bit random tape. The number of such strings producing $y$ lies between $2^j/4$ and $8\cdot 2^j$ for the integer $j$ returned on a nonempty fiber. Use $2^{j-2-s}$ as the lower estimate. Its exponent has $O(q)$ bits. This step costs $2^q\mathrm{poly}(q)$ under the hypothesis even when each input stream uses all $s$ bits. The same approximation method works for one marginal of a joint output by selecting only its first component. It uses the bounded-alternation approximate-counting method of Stockmeyer and a small-overhead simulation of bounded-error tests. [Stockmeyer](https://doi.org/10.1137/0214060) · [Viola](https://eccc.weizmann.ac.il/eccc-reports/2005/TR05-137/)

For every integer $0\le d\le 2q+2$ and word $|y|\le q$, make a request at the **first** eligible epoch when $B_q(y)\ge2^{-d}$. Eligibility here means that both size constraints hold at that epoch. Estimates can fluctuate; the decoder tests all previous eligible epochs to decide whether the request is new. Its prescribed interval length is $2^{-d-2}$. Writing $P_\infty(y)$ for total eventual publication probability, the sum of all requested widths for this $y$ is at most $P_\infty(y)/2$ by geometric summation. The global sum is at most $1/2$.

Place those intervals contiguously from zero in order of $(q,d,y)$, using length-lexicographic order on words. An interval $[a,a+w)$ of dyadic width $w$ contains an aligned binary cylinder of width $w/2$: round $a$ up to a multiple of $w/2$ and take the following half-open interval of that width. Use that cylinder as the code. Different requests give disjoint cylinders, hence prefix-free words. A request at depth $d$ costs $d+3$ bits plus the fixed interpreter header.

## Decoding whole batches without enumerating the sampler's outputs

A batch fixes $q,d$. To find its total width, or the rank of a member, count the words making new requests in a specified initial segment or at a specified prefix and length. At most $2^{q+1}-1$ candidate words exist. To check whether at least $v$ qualify, guess their sorted distinct list, universally choose one row, and check that word's new-request predicate. The entire list costs $2^q\mathrm{poly}(q)$ bits. Checking a single row, including all earlier eligible epochs, is a uniform deterministic computation costing $2^q\mathrm{poly}(q)$ under the linear-SAT hypothesis. Its own physical transcript has a fixed-block verifier; no transcript for every row is copied into the formula. Binary search gives the count, and prefix extension or binary search on the length-lex index recovers the word of a given rank, within the same time bound. [Fixed-block elimination](linear-quantifiers.md)

There are only $O(q^2)$ batches through epoch $q$. Generate their boundaries in order using batch counts. All boundaries through this epoch have denominator dividing $2^{2q+4}$. On a candidate input, skip a whole batch as soon as the current prefix cylinder is disjoint from its interval; empty batches can be skipped without reading any bit. If the cylinder overlaps the batch, refine until disjointness is decided or there are $d+3$ code bits for that batch. A matching aligned cylinder identifies the request rank by arithmetic on its left endpoint and the batch start, since every request in the batch has the same width. If there is no match, continue to the next batch (or diverge on a known unused portion). On the code of a later batch, disjointness from every preceding batch is established by the last bit of the true code at the latest. Retain bits already read while advancing. Thus a successful run consumes exactly its codeword, even when an earlier batch had longer codes. The native time to decode a code issued by epoch $q$ is $2^q\mathrm{poly}(q)$.

Given $t,y$ in the theorem take $q=\lceil\log_2 t\rceil$. If $d=\lceil-\log_2 P_t(y)\rceil+5\le2q+2$, epoch $q$ meets the threshold, and the first request was made by then. If this $d$ exceeds the depth cap, a literal self-delimiting-length description of $y$ uses at most $q+O(\log(q+2))$ bits and finishes well within the stated clock. Increasing the fixed constants covers finitely many small $t$. This proves the inequality.

## Longer outputs and probabilities below any inverse polynomial

The restriction to $|y|\le \log t$ can be relaxed. Fix an integer $b\ge 1$ and a deterministic native procedure $E$ that takes a finite binary index and can publish one explicit output. If some index of length at most $(\log_2 t)^b$ makes $E$ publish $y$ by $t$, then the same coding inequality holds, with $A,c$ allowed to depend on $E$ and $b$. This includes **all outputs of length at most $(\log_2 t)^b$** by using the literal printer, allowing its fixed linear read/write overhead in the clock. It also includes much longer words with a timely short index, even when their sampling probabilities are smaller than every inverse polynomial in $t$. The decoder never receives the index or the deadline as auxiliary input.

At epoch $q$ let $r=q^b$ and represent the length-lexicographic ranks of indices of length at most $r$ in $h=r+1$ bits (reserve one unused value). Run the indexed procedure by $2^q$ steps. Represent each timely output by its least such rank. At depth $0\le d\le 2h+2$, a rank belongs to the batch exactly when it is canonical, its output's probability estimate is at least $2^{-d}$, and no index representing that same output met the depth and probability conditions at an earlier eligible epoch. These tests are feasible under linear SAT in $2^q\mathrm{poly}(q)$ time. A challenger index for canonicity or a previous epoch has polynomially many bits in $q$. Compare the two explicitly produced words, each of length at most the output capacity of the simulation, and apply the same projected counting test with the whole output supplied. Multiplicities of indices never enter the requested mass. The first eligible epoch can be tested directly for each earlier epoch without recursing on a previous new-request predicate.

There can now be far more than $2^q$ entries in a batch. Guessing their list would exceed the clock. For a prefix $v$ of an $h$-bit rank, let $N_v$ be the number of qualifying extensions. Use projected approximate counting on ordered tuples of $L=8h$ such ranks, allowing repetitions. Their number is $N_v^L$. Check each component's predicate within a factor $L$ of the single-index test. On a positive count with estimated exponent $j$, put

$$U_v=\left\lfloor (8\cdot 2^j)^{1/L}\right\rfloor,\qquad N_v\le U_v\le 2^{1/h}N_v.$$

Indeed $N_v^L\le8\cdot 2^j\le32N_v^L$. Detect an empty set separately and put $U_v=0$. All integer powers and roots in this step have polynomial bit complexity in $q$. The number of primary bits and the fixed verifier's time remain within the clock. This use of products upgrades a constant-factor count without requiring consistent estimates at different prefixes.

Allocate the entire batch a contiguous interval of width $W=U_{\varnothing}2^{-d-4}$. The total over batches is at most $1/4$: overestimation at the root is at most two, while the sum of $2^{-d}$ for all actual requests for a word is at most twice its eventual publication probability. Split the interval at each vertex in the ratio $U_{v0}:U_{v1}$, omitting empty children. Along a path the share assigned to a child is at least $2^{-1/h}$ times its true count share. Multiplying and telescoping shows each qualifying leaf gets width at least $2^{-d-5}$. Take the first aligned cylinder of width $2^{-d-6}$ contained in the leaf. All codewords in the batch now have the same length, independent of the rank and the total number of entries.

Whole-batch boundaries are still dyadic, with polynomially many bits in $q$. Once $d+6$ bits determine a cylinder meeting a batch, search the leaf containing its left endpoint by descending one branch, provided the endpoint belongs to the batch. On that path the successive split fractions have denominators of at most $h+O(1)$ bits, giving exact rational endpoints with $O(h^2+d)$ bits when the shared product of denominators is maintained. Test that the supplied cylinder is the leaf's designated one and, on a match, run its index to recover its output. Skip the other batches with the same streaming disjointness test. There are only polynomially many depths and epochs, and a polynomial in $q$ number of counting calls per visited path. Hence the native running time remains $2^q\mathrm{poly}(q)$.

For a timely index at $q=\lceil\log_2 t\rceil$, choose $d=\lceil-\log_2 P_t(y)\rceil+5$. If $d>2h+2$, supply a self-delimited index of length at most $r+O(\log(r+2))$ to the fixed emulator for $E$ instead. For large $r$ this fits the same description-length bound, and finitely many small cases are absorbed by the constants.

The extension leaves a specific extraction problem. A long output with large probability need not come equipped with any short timely deterministic index. Guessing the word and checking a selected bit can give a short decision test per bit; executing that test separately across a long word can exceed the decoding clock. The quasilinear search-to-decision literature explicitly distinguishes finding witnesses for some witness predicate from recovering a specified satisfying assignment. [Naik, Regan and Sivakumar, Section 4](https://cse.buffalo.edu/~regan/papers/pdf/NRS95.pdf)

## A synchronized two-part description

Let $S$ now publish an ordered pair, with $P_t(x,z)$ its joint probability and $p_t(x)$ the marginal for the first component. Use a fixed efficient ordinary pair encoding and a fixed efficient conditional prefix interpreter with auxiliary input. There are $A,c$ such that when $|x|,|z|\le\log_2 t$, $T=\lceil t(\log_2(2+t))^A\rceil$, and $P_t(x,z)>0$,

$$
K_T^V(x)+K_T^V\bigl(z\mid x,K_T^V(x)\bigr)\ \le\ \lceil-\log_2 P_t(x,z)\rceil+c.
$$

Here the same later clock is used for both terms. In particular if $S$ decodes a $V$-program and interprets its output as a pair, the right side is at most $K_{t'}^V(\langle x,z\rangle)+O(1)$ when the sampler has completed the pair interpretation by $t$ on that program by $t'$. Alternatively use a native pair-output convention with the component boundary marked during publication.

For the first term apply the preceding construction to the marginal. Apply it at $s=2^q$ with $q=\lceil\log_2 t\rceil$. One can choose $A$ so that its required decoding time is at most $T$, hence $k=K_T^V(x)$ satisfies $2^k p_s(x)\le C_0$ for a fixed integer $C_0$. This uses a fixed constant from the marginal decoder, independently of the code for the conditional decoder. Increasing $T$ afterwards only decreases $k$ and preserves the bound.

Given the auxiliary pair $x,k$, estimate both $p_{2^u}(x)$ and $P_{2^u}(x,z)$ by the factor-32 lower estimates above. A conditional request for $z$ at depth $d$ is allowed at epoch $u$ if $|x|,|z|\le u$, $0\le d\le 2u+2$, the marginal lower estimate is at most $C_0 2^{-k}$, and the joint lower estimate is at least $2^{-k-d}$. Give each $(z,d)$ at most one request. At every allowed epoch the true marginal is at most $32C_0 2^{-k}$. Since the true masses are monotone in time, the sum over $z$ of the suprema of the joint mass over *marginal-admissible* epochs is at most $32C_0 2^{-k}$ (take the last such epoch or monotone limits). Geometric summation now bounds total requested $2^{-d}$ by $64C_0$, uniformly in the auxiliary input. Scale by a fixed dyadic factor and decode batches exactly as above. Skip epochs with $k>2u+C_2$, using a sufficiently large fixed $C_2$; the literal description of $x$ ensures that the target epoch $q$ remains eligible. This also keeps counter sizes within the decoding bound.

At epoch $q$ the marginal check passes. Taking $d=\max(0,\lceil-\log_2 P_t(x,z)\rceil+5-k)$ meets the joint check; truncation at zero adds at most a constant to the sum bound because $2^kP_t(x,z)\le C_0$. If $d>2q+2$ a literal description of $z$ on the conditional interpreter already suffices. Both decoders and their bit overheads are fixed once $S,V$ are fixed. The argument is also valid for $k=0$ and for a marginal that later exceeds its permitted band.

## Two attempts at a counterexample

**Redundant seeds.** Suppose a fast sampler outputs one very long-lived word on many equally long input strings. The list size alone gives no obstruction. If at each epoch one can compute the counts of threshold-crossing output words in length-lex prefixes in $2^q\mathrm{poly}(q)$ directly, the interval decoder above works unconditionally. For example, if by time $2^q$ a fixed sampler uses at most $O(\log(q+2))$ input bits on every path, enumerate those polynomially many streams, simulate them to the deadline and tabulate all output probabilities. At all epochs up to $q$ this takes $2^q\mathrm{poly}(q)$ total work. Counts for prefixes of the observed outputs follow from the table. (It suffices to know a fixed input-bit cap for this construction.) A counterexample must obstruct timely aggregate decoding, not merely have many input aliases.

**A table hidden outside the input.** If long external tables are accessible via an uncharged oracle, a random seed can find a heavy output while all short deterministic programs miss it. This does not yield a sampler on the required native machine. A concrete bounded version fixes $m$ and $t=2^{3m}$. Use rows indexed by $t/ m$ bits, rounding down. A random-row machine can look up the $m$ bits of one row by time $O(t)$, even charging the cost of copying the address for each bit query. Simulate every reference program of length less than $m-1$ through $T=t\,m^a$, answering zero on every table query. Freeze every row encountered on those runs to zero. There are fewer than $2^m T$ such rows. Choose one $m$-bit word absent from those programs' outputs (and different from zero for large $m$) and put it in every other row. For each fixed $a$ and large $m$, the untouched fraction exceeds $1/2$ since the table has $2^{\lfloor t/m\rfloor}$ rows. The short deterministic transcripts survive unchanged while the random-row sampler outputs the chosen word with probability above $1/2$. The reference and sampler here are granted the same table oracle and length parameter. Making this construction into an explicit SAT instance incurs the table size; giving a succinct ordinary computation for its entries within the sampler's bound is the unresolved issue. This finite oracle example establishes no RAM lower bound.

An ordinary realization by a sparse set of exceptional rows would give the default word a short timely index. Suppose a uniform native evaluator prints an entire row within $t\,\mathrm{polylog}(t)$, given an $r$-bit address for $r\le t\,\mathrm{polylog}(t)$ and parameters encodable in $\mathrm{polylog}(t)$ bits. Suppose there are $e<2^r$ exceptional addresses and $\log_2(e+1)\le\mathrm{polylog}(t)$. At least one of the first $e+1$ addresses gives the default word. Supply its binary rank, the address width if needed and the evaluator's parameters in a self-delimited index; these fields occupy $\mathrm{polylog}(t)$ bits. A fixed emulator pads the rank to width $r$ and runs the evaluator. It need never learn the exceptional rows. The longer-output theorem above now gives a program printing the default word at entropy-optimal length under linear SAT, using its actual probability in the ordinary sampler. This also applies to a long default word when the evaluator can print it in the specified time. The finite oracle construction has $e<2^m T=t^{O(1)}$ for fixed $a$, so an ordinary evaluator meeting these bounds would fall in this case. This short-index argument uses an ordinary computation of the row when reducing to ordinary SAT.

**One computable oracle for all clock exponents.** The finite examples can be joined with neither an input-length parameter nor a different oracle per test. Use zones with queries encoding an integer $m$, a row of length $\lfloor 2^{3m}/m\rfloor$ and a bit position. One fixed sampler reads a self-delimiting $m$, chooses the row on fresh random bits, queries its $m$ entries, and prints them. In a bit-query model that charges for writing each entire address, a single uniform bound $s_m=2^{3m}m^{c_0}$ covers the decoding, sampling and copying for a fixed integer $c_0$. Treat malformed addresses as zero.

At stage $i\ge1$ choose $m_i$ strictly larger than all earlier selected zone numbers and any zone number queried in the earlier finite simulations. Choose it sufficiently large for $2^{\lfloor 2^{3m_i}/m_i\rfloor}>2^{m_i+1}s_{m_i}m_i^i$. Simulate the fixed oracle reference on all names shorter than $m_i-1$ through $s_{m_i}m_i^i$, preserving earlier answers and answering zero on every previously unspecified query. Retain those answers permanently. In zone $m_i$ put zero on every row touched at this stage. On every other row put one nonzero $m_i$-bit word $y_i$ absent from the simulated outputs. Such a word exists by counting names. The chosen zone was wholly fresh, and fewer than $2^{m_i}s_{m_i}m_i^i$ rows were touched. Later stages preserve every simulated transcript. All unselected zones can ultimately be zero.

The sampler thus prints $y_i$ by $s_{m_i}$ with probability at least $2^{-|h(m_i)|-1}$, where the fixed integer code $h$ has length $O(\log m_i)$. Its RAM output length $m_i$ is within $\log_2 s_{m_i}$. The same oracle reference still needs at least $m_i-1$ name bits through $s_{m_i}m_i^i$. As $i$ increases this violates the stated coding inequality for every fixed $A,c$ when both machines are extended by this oracle. The oracle can even be recursive: choose the first eligible $m_i$ and the first eligible $y_i$, encode each selected zone by its finite exceptional rows and default, and simulate stages until the queried zone number has been reached or passed. This argument gives no short running-time bound for computing the oracle response on an ordinary RAM. The oracle construction targets the coding statement; it does not give an oracle relative to which SAT satisfies the hypothesis.
