# Parity challenges at a weighted SAT annotation

A single aligned word can ask for the parity of any chosen subset of the bits of an unknown range sum. The solver has already read the actual query when the word is requested. Replacing it by either signed challenge gives two ordinary SAT files whose verdicts reveal that parity. An entire numerical answer therefore takes at most twice its bit length in Boolean trials. Randomizing the basis of parity questions gives a lower bound on how many different signed pairs must be costly at many positions of the **same honest run**.

Use the source distribution for weighted two-dimensional dominance in Weinstein and Yu, with $n$ operations, a public update at each multiple of $(\log n)^2$, and $q=\Theta(n)$ original queries. Work on the integral subsequence of the weighted transcript construction. Write $b=\lceil\log_2(n+1)\rceil$, $h=2b$, $H=(\log n/\log\log n)^2$ and $B=n/(\log n)^C$ for a sufficiently large fixed $C$. Their distributional proof bounds the probability of *both* correct answers to all original queries and $o(nH)$ total probes by $2^{-B}$. It permits free computation inside each operation, with persistent storage charged for reads and writes. We use log-width cells and an aligned native RAM with a fixed word-width coefficient sufficient for the packets below. [Weinstein and Yu, Theorem 1 and §§3–4](https://arxiv.org/abs/1604.03030) · [Weighted transcript, source schedule and ordinary files](weighted-range-transcript-encoding.md)

## Three tests in the same packet

The ordinary transcript selects a delivered query ID $j$, recovers its coordinates and the claimed operand, and computes the true $h$-bit sum $Y_j$. It has one satisfying assignment per incorrect annotation. Keep the two shared digit decoder trees for the annotation operand $v$. An annotation contains the guard $\neg J_j$ on the two digit pins and on two further positive pins selecting a mode and a sign $a$. Three mode wires are exactly one-hot, and the two sign wires are complementary. Compute the following Boolean values with fully defined gates.

| Mode | Tested bit |
|---|---|
| Exact | $[Y_j\ne v]$ |
| Parity | $\langle Y_j,v\rangle$ in $\mathbb F_2$ |
| Threshold | $[Y_j\le v]$ as unsigned integers |

Assert that the selected tested bit differs from $a$. A normal truthful claim on the master uses exact mode, operand $Y_j$, and sign zero. The parity and threshold circuits each need $O(h)$ gates. No table over the $2^h$ masks is needed. Two positive identifier references select the two digits of a mask, using the same $O(n)$ dictionary as a numerical claim. Give the sign wires identifier numbers $10k+2,10k+3$ from a fresh block. An annotation names one of them once, so complementing its sign flips exactly one physical bit. Pad all packet types to the same constant number of proper ternaries. Pin skipped identifiers, preserve the receipt for every delivered query and fill unused positions with their ordinary dummies. Once the query ID is chosen, all wires, including both sign wires and all mode wires, are fixed. The annotated full and truncated files still have exactly one model per incorrect delivered claim. The constant-factor increase in packet width and the $O(h)$ extra gates preserve $L=\Theta(n\log n)$ encoded bits.

For a fixed correct deterministic SAT solver $P$, assign logical packets in order at its first discoveries of variable positions and preserve every assigned word on repeats. Give it the complete truthful operands and annotations, appending the final public query of the source encoding if needed. As long as a packet remains, two full completions with opposite final verdicts force the next discovery in finite time. At each original query $j$ let the master receive the actual coordinate packet and run up to its request for the next new slot, the annotation. The achieved controller and workspace are those of an ordinary immutable file. Every earlier annotation was truthful. At that slot a parity mask $r$ and sign $a$, with future slots filled with dummies, give a satisfiable file precisely when $\langle r,Y_j\rangle\ne a$. The two signs agree on the master prefix through issue of the pending load. The masks name distinct files even if they return the same parity.

## Which real suffixes are expensive

Fix a public ordering of physical packet addresses independent of the unknown stream. For the stopped file at query $j$ with mask $r\ne0$ and sign $a$, define $c_j(r,a)=u+g$ on its genuine suffix. Here $u$ counts distinct previously exposed input packet addresses read and distinct work addresses whose frozen values are read before the first suffix write there, including initialized zeros. The candidate at the pending slot is known for free. The quantity $g$ counts maximal intervals of previously unseen positions that the suffix touches for a dummy word. These intervals are those before the pending reply. Fixed formatting words are public. Thus $c_j(r,a)$ is bounded by the number of distinct charged addresses visited, using one dummy address per charged interval. A single-word load/store execution takes at least $c_j(r,a)$ suffix instructions. A bounded number of memory subevents per instruction changes only a constant factor.

Let $\tau=\lfloor\log n/(\log\log n)^3\rfloor$. On a given truthful source stream $x$, put
$$
 p_j(x)=\frac{\#\{r\in\mathbb F_2^h\setminus\{0\}:
                 \min_{a=0,1}c_j(r,a)>\tau\}}{2^h-1}.
$$
Let $T(x)$ be the real time through issue of the last pending annotation on the extended truthful master. For every fixed $A$ and sufficiently large source sizes,
$$
 \Pr_x\!\left[T(x)\le AL\ \text{and}\
               \sum_{j=1}^{q}p_j(x)\le \frac{B}{2h}\right]\le 2^{-B/2}.
$$
Consequently, outside this exceptional event, a master meeting the clock cap has $\Omega(B/h)$ distinct query positions **each** supporting $\Omega((2^h-1)B/(qh))$ nonzero masks for which both stopped files require more than $\tau$ charged visits. Indeed positions of density less than $B/(4qh)$ contribute less than $B/(4h)$ to the sum. Every other position contributes at most one. Here $2^h=\Theta(n^2)$, so the number of masks per indicated position is $n^2/(\log n)^{O(1)}$. If one wants disjoint windows of $s$ successive query intervals immediately preceding the chosen cuts, greedy selection retains at least a $1/(s+1)$ fraction of the positions. This disjointness concerns intervals of the continuing master. Each stopped suffix is an execution on its own file.

## Online proof

Persist the master's data, work memory, controller, and pending load using $O(1)$ cell probes per native instruction. The total number of movable words is $p=\Theta(n)$. Maintain the directory of unseen intervals in $O(p\log(p+2))$ total probes. Each unseen slot points to the descriptor of its interval. On splitting one interval, relabel the smaller side. Every relabeling at least halves that slot's interval. In a stopped trial, cache old work words and observed packets, keep every branch write private, and retrieve the endpoints of a blank interval only on its first touch. Lookups of repeated or overwritten words then require no persistent probe during this operation. With an immutable choice of its own dummy completion a trial uses $O(1+c_j(r,a))$ probes, independent of its number of local instructions. The layout can split a native instruction at an ordered input-read subevent by retaining its bounded temporary state. [Directory proof and fork model](accumulated-work-on-stopped-sat-executions.md)

Choose a fresh uniform ordered basis of $\mathbb F_2^h$ per source query. For each basis vector $r$, try both sign completions up to $\tau$ charge events per trial, stopping a trial just before it would need another. If a trial halts, its sign and verdict give the correct basis coordinate. If neither halts, guess one independent fair coordinate. Whether the next event would need a charge can be determined by asking the directory with at most constant extra probes per attempted charge. More precisely, an uncached input key whose address belongs to no recovered blank interval is either an old packet or the first touch of a new blank interval, unless it is the supplied candidate. An uncached work read before any local write is an old charge. Each true stopped file is ordinary and the solver halts on it. Thus unrestricted local computation between charged events does not make the capped trial ill-defined. Solve the basis equations by free local computation, return the decoded number, and put its exact ordinary claim in the genuine master simulation. A decoded nonanswer outside the legal numerical range may be mapped to a fixed legal output. If an off-path master halts early or exceeds a public polynomial clock, use a bounded fallback. The simulation never needs an oracle for a missing annotation.

On a fast, all-correct path the persistent cost is
$$
 O\big(AL + p\log(p+2) + qh(1+\tau)\big)=o(nH).
$$
The constant in the cell width is large enough for each native value and the disjoint polynomial-range storage banks. The observer has no free persistent cache. Independent basis choices may be drawn at the start for analysis and sampled afresh at the actual operations in the algorithm.

Fix $x$ and all the bases. On the fully correct path every controller, interval and charged cost is exactly the one used to define $p_j(x)$. Let $D$ count basis vectors from the slow mask sets of these genuine cuts. Conditional on reaching each correct prefix, all recovered coordinates are correct and the missing coordinates agree jointly with probability $2^{-\#\mathrm{missing}}$. Thus success on this stream has probability at least $2^{-D}$, including with out-of-range fallback. This is a path calculation, even though a wrong word would change later master states. Every row of a uniform ordered basis is uniform on the nonzero masks. Consequently $\mathbb E[D\mid x]=h\sum_j p_j(x)$, without any independence assumption on the basis rows. Convexity gives conditional success at least $2^{-h\sum_j p_j(x)}$. Applying the Weinstein–Yu bound to the joint cheap-and-correct event proves the displayed probability estimate. ## Cost of extracting a word

For a fixed basis the two signs and different basis masks can also share one frozen-value cache during a single source query. Their suffix writes must remain private to each branch. Fix the bases and a deterministic trial order before seeing the stream, run the signs for each mask until one halts, and count $D_j$ as the union of distinct frozen work addresses, exposed packet addresses and discovered blank intervals fetched across all simulated trial prefixes in this source query. A sign simulation can yield after each newly needed retrieval. Processing the two signs alternately with that rule terminates, and cached addresses require no additional persistent access. Bases, tags and branch states live in temporary local computation. All $h$ coordinates are recovered exactly. The persistent query surcharge is $O(1+D_j)$, even if an arbitrarily large number of branch instructions consult cached values. At the next online query persistent accesses count again. Consequently, for every $f(n)$ tending to infinity,
$$
  \Pr_x\!\left[T(x)+\sum_{j=1}^q D_j(x)\le nH/f(n)\right]\le 2^{-B}
$$
at sufficiently large source scales. Indeed the exact simulator costs $O(T+p\log(p+2)+q+\sum D_j)=o(nH)$ on that event. A public polynomial cap on the continuing master does not affect these streams. The inequality counts a resource once within the source operation even if all its stopped executions use it. An arbitrary binary decision oracle on $h$ independent unknown bits can require $h$ replies in the worst case, since a depth-$t$ adaptive decision tree has at most $2^t$ leaves. This is only a bound for recovery from a priori unrestricted words by yes/no replies; a restricted range of likely answers or useful side information can reduce the number of trials.

These branch counts do not add to the clock of the single master. They measure how many different questions would cause expensive work if issued at that instant. Requiring a separate late input word on the continuing master for each of $h$ bit tests per query would itself cost $\Theta(n\log^2 n)$ encoded bits for this layout, above the $nH$ source budget. A transfer to superlinear static SAT time still needs a way to charge distinct work on that one file.
