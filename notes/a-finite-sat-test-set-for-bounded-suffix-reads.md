# A common test set for many SAT programs, and the exact price of covering every read order

Consider the four-table SAT family on the aligned logarithmic-word RAM of the [table tradeoff](the-price-of-few-reads-after-the-last-sat-word.md). There are $p=\Theta(N/\log N)$ identifiable data packets and one query packet. Two tags of the query differ in one physical bit and have opposite verdicts. A pair of files **hits** a solver if it discovers their query at the last new data-bearing address, and either its common prefix takes more than $N^3$ instructions or both runs need at least two distinct old word reads after that load.

For every fixed list of $R$ correct SAT programs, at every sufficiently large family size there exists **one collection of $O((p+1)\log(2R))$ complete pairs** hitting every listed program. The program can know the file format and choose its own access order. The pairs are common to all programs; the hitting member may vary. In particular, for every fixed code budget $C$ there is such a test set of $O((p+1)(C+1))$ pairs for all correct programs of description length at most $C$ bits. The threshold can depend on the list, including the number of words of CPU state its programs retain. The proof allows a cubic prefix and seeks only two old reads. A fast solver can pass the latter threshold and still finish in linear total time. Growing the test set or the code budget does not remove the suffix condition.

## A sound union of transcripts

Let $m$ be the bank length and $w=\Theta(\log m)$. Fix any order in which the $p$ distinguishable data records are given to a solver as it first discovers slots. This logical order is independent of the bank contents $x$. In the sparse communication protocol, a prefix with at most $N^3$ instructions has at most $S=N^3+p$ occupied variable input and work words. Bob can abort on a prefix above this time cap. For each tag run the one-probe protocol, rejecting if it cannot finish within the cap, and accepting only a completed truthful decision that decodes to $F(q,x)=1$. Write $a\le\log_2 S+O(1)$ and $b'=O_P(w)$ for Alice and Bob's communication. Both protocols together have at most $2^{a+b'+1}$ accepting rectangles and each column meets at most $2^{a+1}$ leaves. Their union contains all positive cells with a within-cap prefix and at least one cheap suffix. The same argument with any fixed $t$ uses $a\le t\log_2 S+O(t+1)$.

Each accepting rectangle with more than $L$ rows contains at most $2^{4m-4L^{1/4}}$ columns: all positions occurring in any row coordinate must hold ones in their respective bank. Hence a uniform database falls in any such large rectangle with probability at most $2^{a+b'+1-4L^{1/4}}$. Outside those columns at most $2^{a+1}L$ positive rows have a cheap tag. Choose $L=\lceil(a+b'+2\log_2 m+3)^4\rceil$. Then, for uniform independent $x,q$, the probability of a positive cell with a within-cap prefix and a cheap tag is $O_P((\log m)^4/m)$, since $S=O(m^3)$. Yet $\Pr[F=1]=1/16$. Thus with probability at least $1/16-o_P(1)$, the data and query produce a hit when the query is encountered last. The estimates hold for **every** fixed order of the data records, including orders known to the solver. [Richness proof and native word accounting](the-price-of-few-reads-after-the-last-sat-word.md)

## A distribution on files independent of the program

Choose uniform independent $x,q$ and a uniform random permutation of all $p+1$ packets. The position and identity of the packets are now fixed on both physical files. Until the query appears the executions on the two tags are identical. An unrevealed slot, chosen by any deterministic function of the prior observations, carries a uniformly random one of the remaining packet identities. One can expose that identity only when the machine first touches the slot. Both tags extend every query-free prefix, so the machine must make the next discovery in finite time. For each fixed $x,q$, the chance of seeing all $p$ data records first is exactly $1/(p+1)$. Conditional on that event, the logical order of their discovery is uniform on all $p!$ orders, independently of $x,q$. The resulting physical layout is exactly the lazy placement for that order.

For a fixed program the hit probability is consequently at least $(1/16-o_P(1))/(p+1)$. Draw pairs independently. A union bound over the $R$ programs gives a collection of the asserted size with positive probability. No distribution on programs is used. The theorem can also be applied to programs correct on this entire finite size family and its two tag completions, subject to the stated controller costs. Repeating data reads or inspecting public bytes does not affect the argument. The [parity-recovery construction](parity-recovery-for-a-common-last-sat-word.md) packs related tests together to improve this finite-list bound on a different family.

## Exact combinatorial exhaustion and successor

Fix the database and query, which fixes the contents of $p$ **distinct** data packets and of the query up to tag. A layout is a permutation of those $p$ labeled packets and a distinguished symbol $Q$. The reader knows the test collection, chooses which unseen position to examine next based on everything seen, and wins if it finds $Q$ before the last position. A collection of layouts defeats every reader if some layout puts $Q$ last along that reader's path. Denote the minimum cardinality by $M_p$. Then
\[
                            M_p=2^p.
\]
This optimum concerns *where* the one-bit pair first differs. No bound on suffix reads is asserted here. It applies to actual SAT access orders: every correct solver must keep discovering packets along query-free histories, and any finite strategy for choosing the next position can be embedded in a correct SAT solver that reads the chosen order then evaluates the file.

For the lower bound, start with one winning collection on $p+1$ positions. For each candidate first position $i$ some data label $a_i$ must leave a winning collection on the remaining positions. Otherwise the reader can start at $i$ and, for every possible data reply, use the avoiding continuation guaranteed for that reply. Observing $Q$ first also wins for the reader when $p\ge1$. Each fiber with $a_i$ at $i$ thus has at least $M_{p-1}$ layouts, since deleting the common $i$ entry is injective. There are $p+1$ positions and only $p$ data labels. Two distinct positions must use the same $a_i$. Their two winning fibers are disjoint, since that label occurs only once in any permutation. Consequently $M_p\ge2 M_{p-1}$.

For the matching successor append a new data packet $a$ to each old layout. Include both the appended layout and the layout obtained by swapping $a$ with $Q$. To force a last discovery, simulate the old adversary on old positions until the new position is touched or the reader selects the last remaining old position. In the first case give $a$ in the new position and continue with an unmodified old layout, keeping its $Q$ last. If the last old position is selected while the new position is still unseen, all other old answers are fixed; give $a$ in that old position, and its swapped mate has $Q$ in the sole remaining new position. If the new position is selected when both positions remain, the first rule still works. All replies therefore belong to a single listed layout. With $M_0=1$, the upper bound $M_p\le2M_{p-1}$ proves the formula. Equivalently label the slots $0,\dots,p$, choose an increasing subsequence of $1,\dots,p$, and move labels along the chain starting at 0, with the query at its end and all other labels at their home slots. There are $2^p$ such choices. On a request for the smallest unseen slot, return the next smallest unseen label, or the query if it is last. On other requests return the home label. This gives a direct reader-adaptive realization and is the version used for the matching Lean upper bound. Concretely for two data packets one optimum consists of $ABQ,AQB,BAQ,QAB$. All six layouts are available and exactly six of their four-element subcollections work. For $p=1,2,3,4$ the numbers of labeled minimizing collections are $1,6,162,37080$. For the last figure the audit checks 1,049,760 unions of two optimal smaller fibers. Equality in the lower bound guarantees every minimizer occurs among these unions.

There is a second sharp price if the goal is a large **probability** against every reader. The best guaranteed probability of landing $Q$ last is $1/(p+1)$, and the uniform distribution on all $(p+1)!$ layouts is the **unique** distribution attaining it. Indeed the average over a uniformly random fixed scan order is $1/(p+1)$ for every input law. Uniform layouts attain that average against every adaptive reader by deferred exposure. Conversely, for an optimal law all fixed orders must attain the average, so the probability $Q$ lies in each first slot is $1/(p+1)$. After observing a data label its conditional law on the remaining $p$ positions has minimax success at most $1/p$, by the same random scan. Optimizing the continuation separately for each observed first reply would give an unconditional success strictly below $1/(p+1)$ if any positive-probability data branch fell strictly below $1/p$. Inductively each such conditional law is also optimal. Fix any layout of positive probability and reveal any $p-1$ of its data labels. The last two positions must be equally likely to contain $Q$. The layout and its swap of $Q$ with the remaining datum therefore have equal mass. Such swaps connect every permutation, forcing full uniformity. For $p=0$ there is just one layout.

At the minimum support size $2^p$, the best guaranteed probability is exactly $2^{-p}$. Given any winning support of that size, deleting any one layout permits a reader that avoids a last discovery on every remaining layout. Thus the worst-case success probability is exactly the mass of its lightest layout. Uniform weights attain the stated value. For comparison, the full-support optimum proved above is $1/(p+1)$.

The combinatorial induction doubles the number of test layouts and forces only one more new-word discovery. A full scan still visits every position in linear time in their number. This distinction persists at every successor. The search for a lower bound on total RAM time needs extra work per input that cannot be discharged by a scan and a few later reads. Priority for the precise layout optima is unestablished.
