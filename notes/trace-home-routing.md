# Checking RAM traces with few accesses outside their assigned blocks

**Research journal, 24 November 2026.** Partition a native run of $H$ steps into consecutive blocks of $b$ steps. A fixed circuit $g$ assigns each memory address, including its bank tag, one of these blocks. Let $E$ bound the number of distinct pairs $(i,a)$ in an accepting run for which block $i$ accesses address $a$ and $i\ne g(a)$. One such pair can include any number of accesses within the block. The run may use a different address on every step. The initial writable memory is zero, and $m\le H$ packed public words are available in a separate read-only bank.

Write $L=\lceil\log_2(H+2)\rceil$, let $A(L)$ be the gate cost of checking one native instruction, and $G(L)$ the cost of computing $g$. For this bounded-run language there is an exact existential 3-CNF with encoded bit length
$$
 O\!\left(L\big[H\{A(L)+G(L)+L\log(b+2)\}
              +(E+m)L\log(E+m+2)\big]\right)
$$
on the [packed explicit SAT encoding](packed-band-transfer.md). The formula accepts exactly when a run obeying the stated budget accepts. The physical registers, full-width indirect addresses and word operations of the original machine are retained.

For example take $b=\operatorname{polylog}H$, $E+m=O(H/L)$ and $G(L)=O(L)$, as when the block is selected by fixed address bits. For each fixed $\epsilon>0$ the length is $O(HL^{2+\epsilon})$ for the ISA including multiplication and division. For addition and bitwise Boolean instructions with fixed shifts it is $O(HL^2\log L)$. The unrestricted construction currently recorded in this journal costs $O(HL^3)$ bits.

## Local summaries

Each step checks the CPU semantics and emits a bounded number of memory events. Within each block an existential Beneš network routes the events into address and time order. Check adjacent sortedness, including the within-step order. In the group for one address, each read following an event must have the value after that event. A first read imposes an incoming word requirement; a first write has none. The last event determines the value to leave in memory. Attach the final value to the group's first event by a backwards scan copying the next final value along equal addresses. A second local router puts one summary per group into a table in increasing address order, with inactive slots last. Enforce that the router preserves the marked group starts and their complete records. An equivalent implementation routes all records and checks their active tags and sorted order, so each original start remains present exactly once. This costs $O(HL\log(b+2))$ gates for all blocks. Use distinct low and high sentinels for table searches, with inactive slots treated as high sentinels.

Each summary records the address, block, optional incoming requirement and outgoing value. Superconcentrate every nonhome summary into at most $E$ ports, enforcing this budget even on false witnesses. Treat the $m$ initializers as additional public summaries at time $-1$, each an unconditional write of its true input value. Guess a marked subset of home summaries and superconcentrate all of the marked ones into at most $E+m$ more ports. The graph carries the complete records. At every selected internal vertex a path has exactly one selected predecessor and successor and carries their common payload. Selected sources must have a path and unselected ones have none. The graph is acyclic, so records cannot disappear or be copied. Superconcentration supplies vertex-disjoint paths to the requisite number of ports in some order. These compactions require $O(HL)$ Boolean gates.

## Authenticating the local and global boundary

Route the compacted ports and public initializers into address and block order by a Beneš network, with inactive ports last. Within each address, start from zero and check the input requirements and successive output values. At each unmarked home summary perform the same check with incoming value zero. A further condition is essential. **Every nonhome or initialization record at address $a$ must account for an occurrence at $a$ in the sorted local table of block $g(a)$, if one exists.**

For each such record guess one of two answers. For a present address give the index of its local summary and require the matching address and the mark. For an absent address give adjacent indices in that block whose keys strictly bracket $a$. Check block indices, endpoints, adjacency and sentinels. Authenticate these $O(E+m)$ indexed reads of local table records, including their marks, by the following circuit. Attach the physical index to each of the $O(H)$ rows, select an arbitrary subset and route the selected rows with a superconcentrator into $O(E+m)$ ports. Sort ports and claimed lookups together by index, with the port first and inactive items last. Every queried group must have a port, and all returned words must equal its genuine row. Multiple reads may use one port. This costs $O(HL+(E+m)L\log(E+m+2))$ gates. It works for witness-dependent tables and indices, including concentrated queries into a single block. [Public-port variant](materialized-input-census.md)

If an address has any nonhome appearance or initializer, the bracket test forces its home appearance, if present, onto the global list. Thus that list contains every summary for that address. If an unmarked home summary checks locally, it is the only block that ever accessed that address and it has no public initializer. Its incoming value really is zero. Extra marked home records are harmless. The verified summaries therefore compose to one genuine memory in chronological order, including read-only input accesses. Conversely on a genuine bounded run mark the home summaries at addresses having a nonhome appearance or initializer. At most $E+m$ need marking. All preceding checks have the indicated witnesses. Initial values, read-only stores and out-of-range input reads use the underlying machine's conventions at the native transition check.

## Size and uniformity

Each word has $O(L)$ bits. A circuit over bounded-fan-in Boolean gates has an explicit Tseitin encoding with $O(L)$ bits per gate in the polynomial range here. For each fixed $\epsilon>0$, the local template can use $A(L)=O_\epsilon(L^{1+\epsilon})$. For completeness, split an integer into $k$ limbs for a sufficiently large fixed $k$. Evaluate two degree-$(k-1)$ polynomials at $2k-1$ distinct fixed integers, recursively multiply the values, interpolate, then recombine. Evaluation and interpolation use $O_k(L)$ gates since their integer constants and common denominator are fixed. Exact division by this denominator is a binary long-division scan with a constant-size remainder. Signed intermediate values have $O_k(1)$ guard bits over the recursive limb size. This gives $M(L)\le(2k-1)M(\lceil L/k\rceil+O_k(1))+O_k(L)$. Choose $\log_k(2k-1)<1+\epsilon$ and induct with slack. Native division is checked by guessing quotient and remainder and verifying one full-width product, its sum and the remainder bounds. A variable shift uses $O(L\log L)$ gates. Local templates can be compiled once in $\operatorname{poly}(L)$ time.

An explicit bounded-degree linear-size superconcentrator suffices for materialization, which takes time linear in the encoded size after the small templates are constructed. For local access one can use the following fixed graph on a power of four $N$, padding the port set by a constant factor. Use the lazy Margulis–Gabber–Galil expander on the $\sqrt N$ by $\sqrt N$ torus raised to a fixed power with second singular value $\lambda<1/64$. Its constantly many edge labels are invertible affine maps modulo $\sqrt N$. Join the input and output levels directly by these expander edges. Add a recursive network of size $N/4$, joining inputs to its inputs by a second copy of the expander whose right vertices are grouped four to one. Use the reversed construction on its outputs. The base case is one port. [Gabber and Galil](https://doi.org/10.1016/0022-0000(81)90040-4) · [Classical linear-size superconcentrators](https://web.math.princeton.edu/~nalon/PDFS/acapsuper3.pdf)

For any equal-size marked input and output sets choose a maximal matching using direct edges. The remaining sets have common size less than $N/32$ by expander mixing. For any nonempty residual input subset $S$ of density $\alpha\le 1/32$, Cauchy–Schwarz applied to the normalized walk on $1_S$ gives $|\Gamma(S)|\ge |S|/(\alpha+\lambda^2)>4|S|$. Quotienting the neighbors four to one leaves at least $|S|$, so Hall's theorem matches the residual inputs to distinct recursive ports. The same holds for the residual outputs. Recursion connects these two sets with vertex-disjoint paths, proving superconcentration. There are $O(N)$ edges in total and bounded degree. Given a layer and a vertex, every neighbor is computable by constantly many native operations on $O(L)$-bit words; for reverse quotient edges enumerate the four possible preimages and invert the edge label. A binary search of the $O(L)$ geometric layer offsets identifies the layer of a given global slot in $O(\log L)$ native operations after $\operatorname{poly}(L)$ setup. Other families are rectangular routers and precompiled row templates as in the packed transfer. Thus the size improvement also admits local word access with this specified decoding time when $g$ has a uniformly precompilable template. The bound above on encoded length does not charge the SAT solver a constant time for that decoding.

## Read-only prefixes, dead writes and fresh epochs

One can safely remove entire classes of work-memory events from the count. Give each work address fixed, cheaply computable cutoffs $u(a)\le v(a)$. Before $u(a)$ allow only reads returning zero. After $v(a)$ allow only writes. Check these tests on each event and discard such events from memory routing; the CPU check still receives their real addresses and words. A read in the prefix sees the initial zero because no earlier write was allowed. Writes in the suffix have no later read at that address. The active interval covers both endpoints. Sentinel cutoffs handle designated read-only and write-only work addresses. The public input bank keeps its original checks. The new cost at a step includes the cutoff circuits. Completeness concerns an accepting run obeying their mode constraints.

For further savings a fixed function $\kappa(a,t)$ can divide the remaining life of an address into epochs. Require it to be nondecreasing in $t$ for each $a$ and to fit in $O(L)$ bits. Use $(a,\kappa(a,t))$ as the memory key and let the home rule depend on this augmented key. At the first summary of each nonzero epoch require that its first event be a write. For a global key this is checked at its first sorted summary; for an unmarked home-only key it is checked locally. The original epoch zero may start with a read of zero. The guards ensure that resetting an epoch's incoming value cannot change any accepted read. In particular choosing $\kappa(a,t)=1+\operatorname{block}(t)$ and using that block as the home gives $E=0$ on all traces in which every touched work word is written before being read in each new block. There can be arbitrarily many addresses, repeated writes, and overwritten cross-block values. These are fixed rules or rules drawn from an explicitly uniformly evaluable family with **guaranteed** monotonicity and charged decoding. An unverified guessed circuit cannot supply temporal monotonicity for free.

## A native run outside the regime

In a first scan a fixed program writes to $H/2$ distinct consecutive addresses and in a second scan it reads the same addresses, up to constant factors for loop instructions. Choose a scan length aligned with block boundaries and much larger than $b$. The two accesses to each address occur in different blocks. Every assignment $g$, even one given by an unrestricted table, therefore has at least one nonhome pair per address, making $E=\Omega(H)$. This is a counterexample to obtaining a worst-case saving by this one-block-per-address parameter.

A parameter counting only actual reads of noninitial values from prior blocks would face a further issue even at zero. Given two arbitrary arrays of word keys, sequentially read the first array and write one at each of its keys in an initially zero work bank. Then sequentially read the second array and accept exactly if every corresponding work read returns zero. With the scan boundary aligned to a block boundary, the arrays' underlying sets are disjoint exactly on accepting inputs, and **every** accepting input has zero cross-block write-to-read dependencies. All its writes are dead and all its work reads return pristine zero. On overlapping input a false record can claim the same zero. Consequently an exact fixed-topology compiler whose only input dependence is through public pins, with small verification size on this zero-budget language, supplies a correspondingly small nondeterministic Boolean circuit for disjointness of two arbitrary word lists. Public-array reads in this example have fixed indices and can be wired directly. This implication isolates a missing negative check; it gives no circuit lower bound for disjointness.

An unrestricted alternative might verify arbitrary permutations more cheaply. A fixed RAM checks a full-payload tagged permutation in linear word time by comparing each proposed $(i,v)$ to the true input word at $i$ and rejecting a repeated or out-of-range index. A general fixed-topology compiler with public input dependence only through pins must therefore handle this relation. Existing short-key sorting circuits compute ordered outputs; this comparison by itself gives no lower bound on nondeterministic verification. The construction here leaves unrestricted deterministic SAT time open. [Asharov, Lin and Shi](https://doi.org/10.1137/20M1380983) · [Jahanjou, Miles and Viola](https://arxiv.org/abs/1311.3171)
