# Winning RAM strategies that can forget parts of memory

One bounded SAT query can check a finite winning strategy for an alternating RAM even when the number of alternations grows with the input. The parameter is the size of a directed acyclic proof in which several plays may meet at a common partial description of memory. An edge may discard all information in a specified address range. This permits exponentially many different actual memories to reach the same proof node. The resulting sufficient conditions below concern the quadratic and cubic SAT targets. Conservative abstraction for games has an extensive literature. The claims here concern a particular certificate, its native checking cost and its use on padded inputs. [de Alfaro, Godefroid and Jagadeesan](https://patricegodefroid.github.io/public_psfiles/lics2004.pdf) · [Previous alternating simulation](alternating-native-speedup.md)

## A certificate for one player

Fix a word RAM with immutable input, initially zero writable words, a fixed register file and deterministic instructions interspersed with choices of one bit or a full word by either player. Player 1 wants to reach an accepting halt. Player 0 wants to reach a rejecting halt. Other infinite plays may remain unresolved. On an input of length $n$ let $w=12\lceil\log_2(n+2)\rceil$. Use unsigned $w$-bit addresses and the finite instruction basis in the native clock note. [Instructions and interpretation](native-unary-clock-band.md)

A proof for bit $y$ is a topologically ordered DAG starting at the real initial controller and all-zero work memory. Vertices specify the exact controller, registers and an abstract work array with values in $\{\mathsf{unknown}\}\cup\{\mathsf{known}(v):v\text{ a word}\}$. One entry means that every concrete state represented there has the indicated value. The other entry permits every word. The clocks used to bound proof checking are external to the simulated program.

* A terminal must have verdict $y$. A deterministic instruction has one edge. At a choice of player $y$ one legal action is sufficient. At an opposing choice all legal actions occur exactly once in numerical order, each with its own edge. A separate action for every possible guessed word is charged in full. Allowing distinct actions to have the same child preserves this charge.
* Replay the instruction on the partial state and the actual read-only input. Every work-memory load requires a known value. The action determines any newly guessed value. A store to a work address installs its known value. The edge may next forget a list of address prefixes. A prefix of length $i$, $0\le i\le w$, replaces all entries sharing its high $i$ bits by unknown. The empty prefix clears all knowledge. An absent list preserves the entire current partial array. The resulting controller and partial array must equal those at the designated later vertex.
* Every declared vertex is reachable in the claimed proof from the first one. Let $S$ count vertices, represented action edges and forget operations, with unit cost for one prefix given by its length and a word. The degree and lists of an untrusted vertex are drawn from the same budget.

Forward induction shows that each true play consistent with the chosen actions satisfies every asserted memory value and controller along its path. All opposing moves occur, all paths in the proof terminate, and the only terminal verdict is $y$. One program on one input cannot have both a valid 0-proof and a valid 1-proof. Follow the two proposed strategies against each other on the original RAM, retaining each strategy's own current proof node. Each play advances strictly in both finite DAGs and would have to reach both terminal verdicts. This also applies to a program with diverging executions elsewhere.

## An exact checker on a nondeterministic RAM

For fixed $M,y$, a native verifier on $x$ and a size cap $s$ can check existence of such a proof of size at most $s$ in $O(n+(s+1)w)$ instructions, for $1\le s\le n^4$ and all large $n$. It guesses the graph in topological order. Reserve an initially empty incoming-state slot per vertex. Initialize the first slot from the true initial state. For each edge require a larger destination in range. Its first arrival fills its slot, subsequent arrivals compare with the slot, and each processed vertex must already have a slot. Bound each list against the remaining budget as it is read. Enumerate opposing actions inclusively through the maximum value and stop there, using a final-value test before incrementing. If they exhaust the edge budget the verifier rejects. A constant number of steps per represented action suffices for this enumeration.

Represent an array by an immutable binary trie on the $w$ address bits. A uniform region at any level has a tagged root denoting its common known word or the unknown value. A nonuniform root identifies a branch with its two children. A point lookup takes $O(w)$ steps. A store or a prefix forget copies the path to one subtree and changes its root. Expand a uniform node lazily as two copies of its uniform child. On the return path collapse two equal uniform children to their common uniform value. Keep level information with references. The result is a reduced trie in which equal abstract arrays admit the same representation.

Array equality at a merge must be exact. Whenever a new branch tuple is formed, guess an identifier and consult a direct-address table at that identifier. A fresh slot is filled with the level and both child references. A previously used slot must already contain exactly that tuple. Both children are existing well-formed references of one smaller level. Uniform references carry their values directly. Slots are immutable after initialization and checked in full. Identical nonuniform identifiers thus imply semantically identical arrays, by induction on the level. The checker may guess duplicate identifiers for equal tuples, which can only cause an equality test to fail. On an honest proof assign a single identifier to every structurally identical normalized tuple, so every required merge succeeds. Cap identifiers at a fixed multiple of $(s+1)(w+1)$, since at most that many tuples are formed. Controller and root-reference comparisons have constant cost. Distinct banks for the graph slots, trie dictionary and simulated registers fit in the native address space under the stated cap. Thus the verification time includes constructing persistent memory proofs and comparing all incoming states. In particular it uses no probabilistic fingerprint.

## Two explicit diamond programs

For $m=n$ rounds, a fixed program has the opposing player choose a bit, stores it at a fresh work address indexed by the round, clears its choice register, and asks player 1 for a bit. A zero from player 1 rejects immediately and a one continues after its register is cleared. After the last round it accepts. All loop controls and the round index are deterministic at the meeting point. In a winning strategy for player 1, every string of $m$ opponent choices occurs and player 1 must continue on each history. Immediately before the final halt the concrete arrays for these $2^m$ histories are pairwise different. Any DAG merging only identical full configurations therefore needs at least $2^m$ nodes when that last shared program location is reached. One can include a fixed final deterministic instruction before the halt to make this a nonterminal location.

An abstract proof uses $O(m)$ nodes, edges and forgets. Immediately after each store forget the just-written address on both incoming histories, even when the bit written was zero. The two short branches then have identical abstract memory. Their exact registers agree upon clearing the choice bit, and both feed the next control node. None of the erased words is ever read.

Now modify only the final deterministic suffix. It reads each of the $m$ cells once, clears the loaded register, and then accepts regardless of the values. Each incoming memory at the start of this suffix must know every one of those $m$ words in a valid proof because no later store could restore a forgotten value before the corresponding mandatory load. Two distinct opponent bit strings cannot use the same abstract node there. The modified program still accepts in $O(m)$ time on every play and now requires at least $2^m$ nodes even in the partial-memory format. Thus short branches, data-independent answers and a small machine description by themselves cannot supply the needed certificate bound.

## What suffices for quadratic or cubic SAT exclusion

Let $J_8$ parse a self-delimiting opponent program from the prefix of $x$, run it on all of $x$ for $n^8$ opponent steps, and return one on observed rejection and zero otherwise. Every suffix after a valid program prefix is free. The clock counts guest steps, so every timely deterministic opponent $D$ disagrees with $J_8$ on all extensions of its own code. The interpreter runs in $O(n^8)$ native steps on the fixed width above. A sparsely addressed guest word is stored in a fixed-depth radix trie with digits of $\max(1,\lfloor\log_2(n)/4\rfloor)$ bits. Up to time $n^8$ there are $O(n^8)$ allocated rows, each requiring an address for its row number followed by one digit. These fit in a $12\lceil\log_2(n+2)\rceil$-bit word together with fixed bank tags. The same construction simulates guests with any fixed constant factor in word width by a fixed number of limbs, including normalized division. [Native width and division details](native-unary-clock-band.md)

Fix $a\in\{2,3\}$ and $\epsilon>0$. Suppose a single alternating program $M$ has the following property. Every valid opponent-program prefix has arbitrarily long extensions $x$ for which there is a proof of the correct sign $J_8(x)$ with
$$
 S=O\left(\frac{n^{8/a}}{(\log n)^{4+\epsilon}}\right).
$$
The constant in the bound can depend on the prefix. Then ordinary explicitly encoded 3-SAT has no deterministic $O(N^a)$ algorithm in the indicated logarithmic-word RAM model, where $N$ is formula bit length.

Indeed, pick rational $0<\eta<\epsilon$, write $L=\lceil\log_2(n+2)\rceil$ and let $s$ be within a fixed factor of $n^{8/a}/L^{4+\eta}$. Powers of two from $\lfloor\log_2 n\rfloor$ and $\lfloor\log_2 L\rfloor$ give such a constructible integer using shifts and fixed-denominator arithmetic. Handle the finitely many short lengths by a constant default. Form the positive bounded native query for the checker above, giving it $O(n+(s+1)L)$ guest steps. The query has that bit length as an upper bound, including its unary clock. The RAM-to-3-CNF compiler makes an ordinary virtual formula of length $O((n+(s+1)L)L^3)$ with constant-time packed-word access after polylogarithmic setup. Choosing a constant upper clock for the fixed verifier fits the same bound. On the hypothetical SAT solver the deterministic decision takes
$$
 O\!\left(((n+(s+1)L)L^3)^a\right)=O(n^8/L^{a\eta})=o(n^8)
$$
steps. All query lengths are polynomial in $n$. The word-width conversion uses a constant number of limbs and at most $O(n^8)$ trie rows on the fixed source host as above. The input to the native verifier includes $x$, so its width permits source words and dictionary identifiers, which use $O(\log n)$ bits in the indicated ranges. [Encoded formula size and local access](packed-band-transfer.md)

Output one exactly when the capped positive proof exists. On a good extension of sign one the bounded checker accepts at large enough lengths. On a good extension of sign zero the existence of its finite negative proof excludes every positive proof. The opposing verdicts cannot both have finite winning strategies even if checking a negative certificate would exceed the budget. Thus this deterministic driver agrees with $J_8$ on arbitrarily long extensions of its own program prefix, contradicting the diagonal. In particular the size bound in the criterion may be omitted for the negative proofs. The powers $8/a$ and the four logarithms arise from the chosen diagonal clock, exact trie updates and packed compiler.

With a globally sound positive proof system there is a further reduction of the coverage requirement. Suppose on every input existence of a finite positive DAG for $M$ implies $J_8(x)=1$. It suffices that small positive proofs occur arbitrarily far out in each valid program cylinder on which $J_8$ is one on **all sufficiently long extensions**. The driver above would be globally one-sided by soundness. Its own cylinder eventually contains only instances with $J_8=1$, since a positive answer by the driver there would force $J_8=0$. Coverage in that cylinder now forces such a positive answer, a contradiction. Finite simulation of $J_8$ itself provides global soundness at a cost that can reach $\Theta(n^8)$. No unconditional supply of short proofs on the required cylinders is known here.
