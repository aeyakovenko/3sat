# Long-gap reads that remain hard even to verify locally

**Research journal, 24 November 2026.** There is a fixed RAM program that runs in $O(N)$ time on a family of explicit unsatisfiable 3-CNFs of encoded length $N$ and exhibits the following behavior. Fix **any total local verifier** for its designated cold reads. For each candidate word the verifier can inspect an arbitrary private witness and use $q=\log^{O(1)} N$ packed formula probes, even with unlimited intervening computation. It gets the cold-read index and native pre-load controller, all previously returned designated bits, and arbitrary uncharged access to one $s$-bit advice string. Totality means some word is permitted at every context for every such string. Then, for arbitrarily large $N$, one formula forces **every** advice string of length $s\le cN/((q+1)\log N)$, for a sufficiently small constant $c>0$, to permit a wrong word on at least a quarter of the designated reads. There are $\Theta(N)$ designated reads, each with reuse time $\Theta(N)$ and genuine value one or two. The error-gap cost of the [total-relation theorem](certified-read-gaps.md) is $\Theta(N^{1+\lambda})$ on these linear runs, for every fixed $0<\lambda\le1$.

The program verifies the entire candidate read stream by recomputation. With the other operations genuine, any corruption of one or more designated answers changes its terminal verdict. No single inverse certificate resolves the obstruction. A passed true word need not itself have a short certificate on a bad slot: the conclusion is that the local relation permits an incorrect word. The claim gives the verifier free preceding **scan output**, not random access to the hidden work memory or the earlier encoder execution. A provider of the true value at its publicly known writing slot would reveal it immediately. Common input-independent parameters or a different verifier circuit at each length do not affect the counting proof.

## A fixed-shape program with many independent output bits

For every $a$, choose a binary linear encoder $G:\mathbb F_2^a\to\mathbb F_2^{32a}$ of distance at least $4a$ given by a circuit with $O(a)$ XOR wires. The range detector of Gál, Hansen, Koucký, Pudlák and Viola gives precisely these parameters. Replacing an $r$-input XOR by $r-1$ binary XORs preserves linear size. The code need only exist: the honest input family supplies its gate layout. The program does not trust its distance on arbitrary inputs. [Gál et al., Corollary 29](https://www.khoury.northeastern.edu/home/viola/papers/ecc-ckt.pdf)

Set $b=\lceil\log_2(a+2)\rceil$. Use one such encoder $G_1$ of dimension $a$ and a second $G_2$ of dimension $b$. Their generator matrices have $32a$ and $32b$ rows respectively. The raw data are a binary matrix $X$ of dimensions $32a\times32b$. Compute the $a\times b$ output matrix
$$
 Y=G_1^{\mathsf T}XG_2 .
$$
The flattened $L=ab$ bits of $Y$ are independent fair bits on a uniform $X$, since both generator matrices have full column rank. Every nonzero binary linear combination of the $L$ output bits depends on at least $16ab$ raw bits. Its coefficient matrix is $G_1 U G_2^{\mathsf T}$ for a nonzero $a\times b$ matrix $U$. Full ranks imply this matrix is nonzero. A nonzero column has at least $4a$ nonzero entries, hence there are at least $4a$ nonzero rows; each is a nonzero codeword of the second code and has weight at least $4b$.

A fixed interpreter transposes an XOR circuit by accumulating input sensitivities backwards over its gates: at an XOR gate add its accumulated bit to both parents. Seed the outputs with the supplied column of $X$. Fanout and designated repeated outputs are handled by the same summation. This uses linear work in gates, wires and outputs. Run the first transpose on $32b$ columns and the second transpose on $a$ rows of the intermediate result. The cost is $O(ab)$, including zeroing scratch. The small second encoder matters: it makes the distance linear in **all** raw input bits while its repeated evaluations still fit the elapsed-time bound. [Use of transposed linear encoders by Ishai et al.](https://www.cs.ucla.edu/~sahai/work/web/2008%20Publications/STOC2008.pdf)

The explicit formula has a pair of contradictory unit clauses (padded to width three), followed by tautological records $(x_1\lor\neg x_1\lor x_{j+1})$. They encode the two gate lists and the raw data, packing $\Theta(\log a)$ raw bits per variable name. Reserve enough declared names for these fields, only polynomially many, and use the stated fixed-width layout. There are $O(a)$ records, and the raw data alone require $\Omega(ab)$ bits. Consequently $N=\Theta(ab)$. A packed input probe intersects constantly many fields and depends on $O(\log N)$ raw bits, including all carry effects in computing a variable name. The layout is fixed over the raw-data cube at each chosen size. A fixed program rejects malformed guarded layouts directly. Before running a layout, check the dimensions, topological order, finite index bounds and a fixed wire-count allowance. An unguarded input can go to any correct SAT solver.

Store $1+Y_j$ in a distinct fresh cell for each output. After all these stores, spend $\Theta(N)$ register-only steps, then scan the cells in public order. Put the collected replies in a separate response array. Compare the whole array with an independent recomputation of $Y$ from the input **after the scan**; an out-of-alphabet reply also fails the comparison. Return UNSAT on agreement and SAT on disagreement. On every actual guarded computation the comparison succeeds, even if a valid circuit layout encoded a poor code. The wrapper therefore decides SAT correctly, and it preserves a linear global time bound if its fallback has one. The claimed hard runs themselves need no assumed SAT algorithm. Scratch banks and output cells are disjoint. Clear temporary registers across scans, use a data-independent schedule and retain only public counters or information available from the preceding scan outputs in the pre-load controller. The designated slots stay $\Theta(N)$ away from the corresponding writing slots, and no earlier scan slot touches the same cell.

## Why nondeterministic certificates fail on many slots

Condition the uniform raw bits $X$ on an arbitrary $Y=y$. The resulting distribution is $(16ab-1)$-wise independent on the raw bits. Indeed any nonzero parity on fewer coordinates is outside the row span of the output map, so is balanced on every such affine fiber. Equivalently, projection to any such set of coordinates is uniform. Put $t=16ab-1=\Theta(N)$.

Fix one advice string, a set $S$ of $h$ distinct scan indices, and the whole prospective output vector $y$. At slot $j\in S$, allow exactly the public context determined by the fixed layout and the earlier bits $y_{<j}$. For fixed $y$, each accepting wrong-reply transcript gives a conjunction of at most $K=O((q+1)\log N)$ raw-bit literals. It suffices to fix all touched input fields; adaptively selected subsequent addresses are reproduced on any raw data compatible with those observations. Private witness length and computation between probes do not increase the number of distinct such conjunctions, which is at most $(2|X|+1)^K$ per slot, counting $|X|$ in bits. The condition that **none** of the slots admits a wrong reply is therefore one CNF with at most $M=h(2|X|+1)^K$ clauses. Earlier true bits, private argument strings and unlimited access to the shared advice are already fixed or accounted for in this construction.

Bazzi's size-only theorem already gives additive error $2^{-\Omega(\sqrt N)}$ when replacing $X\mid Y=y$ by an independent uniform $X$. We can get nearly linear advice resistance by also using the clause **width** and the fact that only an upper bound on the CNF's acceptance is needed. The following derivation uses the switching lemma and the zero-preserving approximation from the Bazzi–Razborov proof. [Bazzi](https://doi.org/10.1137/070691954) · [Razborov, *A Simple Proof of Bazzi's Theorem*](https://people.cs.uchicago.edu/~razborov/files/bazzi.pdf) · [Beame's proofs of switching lemmas](https://users.cs.duke.edu/~reif/courses/complectures/Beame/SwitchingLemmaPrimer.pdf)

For completeness, a Boolean width-$K$ DNF has squared uniform Fourier mass above degree $d$ at most $2^{-\Omega(d/K)}$ for $d/K$ sufficiently large. Leave each raw bit free with probability $p=1/(C K)$ and fix the others uniformly. For a sufficiently large absolute $C$, the switching lemma bounds the chance the restricted DNF needs decision-tree depth greater than $v=\lfloor pd/2\rfloor$ by $2^{-\Omega(v)}$. Its Fourier degree is at most its tree depth and its total squared mass at most one. On the other hand the expected restricted mass above $v$ is $\sum_U\widehat f(U)^2\Pr[\mathrm{Bin}(|U|,p)>v]$: after fixing the free set, cross terms from distinct Fourier characters vanish on averaging the fixed signs. For $|U|>d$ the binomial probability is at least $1/2$ when $pd$ is large. These two estimates give the stated tail with an absolute multiplicative constant.

Write the complement of the CNF as a DNF $D=\bigvee_{i=1}^M A_i$. For each prefix $D_{<i}$ truncate its Fourier expansion at degree $d$ to get $g_i$ with squared error $2^{-\Omega(d/K)}$. Set $g=\sum_i A_i(1-g_i)$. The identity $D=\sum_i A_i(1-D_{<i})$ and the triangle inequality give $\|D-g\|_2^2\le M^2 2^{-\Omega(d/K)}$. Wherever $D=0$, every term vanishes and $g=0$. Thus the polynomial $P=1-(1-g)^2$ satisfies $P\le D$ pointwise and $\mathbb E[D-P]=\|D-g\|_2^2$ under uniform raw bits. Its degree is at most $2(d+K)$ after multilinear reduction on the cube. Take $d=\lfloor t/2\rfloor-K$, so every $t$-wise independent raw distribution gives $P$ its uniform expectation. The probability of the no-wrong-reply CNF on each fiber is at most its uniform probability plus $M^2 2^{-\Omega(t/K)}$. Since $K=O((q+1)\log N)$, $\log M=O(K\log N+\log h)$ and $q$ is polylogarithmic, this is additive error $\epsilon\le 2^{-c_1N/((q+1)\log N)}$. The inequality holds separately for each fixed $y,S$ and advice. Average it over uniform $y$.

In that independent experiment fix $X$, read $y$ in increasing slot order, and condition on the past. At each sampled slot the current bit is fresh and fair. The total relation permits at least one word; at most one of the two possible target bits makes **all** its permitted words correct. Hence the probability of no wrong reply on all $h$ slots is at most $2^{-h}$. The probability with the true correlated data is at most $2^{-h}+\epsilon$. This step uses totality even on contexts arising from a hypothetical independent $y$. A relation with no reply at all is not a certificate system of the stated kind.

Now choose $S$ uniformly without replacement. If at least $3L/4$ slots on a raw input admit only the correct word, then all $h$ sampled slots are good with probability at least $(2/3)^h$ for $h=o(L)$. The probability over $X$ of that many good slots for this one advice is at most $(3/2)^h(2^{-h}+\epsilon)$. Take $h=\lfloor c_1N/(2(q+1)\log N)\rfloor$ and a sufficiently small constant $c>0$, and union over fewer than $2^{cN/((q+1)\log N)+1}$ advice strings. The failure probability tends to zero. In particular there is a single input for which *every* such advice permits a wrong reply on at least $L/4$ slots. This is an existence assertion for the raw input, not a uniform fast procedure for finding it. [Finite fiber, transposition and wrong-reply CNF calculations](../audits/code_fiber_audit.py)

The construction tests the sufficiency of the read-gap criterion on genuine linear-time executions whose scan matters to their own verdict. These particular formulas also have a separate constant-size reason for unsatisfiability. To exploit the criterion for an unrestricted time lower bound one still needs an upper bound for the certifiable read errors of some correct fast solver **on its own hierarchy inputs**, or an argument that every fast solver can be transformed to have that property. Neither the hard scan nor its easy guard supplies such a transformation. Priority for this combination of a locally checked word, a native scan and shared advice is unverified.

## A fixed number of alternating local challenges

Allow a word to be permitted by a fixed number of alternating existential and universal strings, each of length $\operatorname{polylog}N$, followed by the same bounded-probe test. Keep totality on every context. The same program still defeats all such verifiers on a constant fraction of its cold reads with $cN^{\alpha}$ shared bits for some $\alpha>0$ depending on the fixed depth. Fixing $y,S$ and the advice, expand the local strings into AND/OR gates. For each leaf the finite input-probe decision tree expands into a DNF; the conjunction excluding all incorrect words at the sampled slots adds only constant depth. The result has fixed depth and size $\exp(\operatorname{polylog}N)$, including all candidate words. Braverman's bounded-independence theorem fools every such circuit to error $2^{-\Omega(N^{\alpha})}$ with $t=\Theta(N)$ for sufficiently small fixed $\alpha$. Applying the same sampling argument with $h$ a small constant times $N^\alpha$ gives the claim. This extension charges the lengths of the local quantified strings; in the single existential case the preceding width argument did not need to bound the number of private transcripts independently of their probes. [Braverman, *Poly-logarithmic independence fools AC⁰ circuits*](https://www.cs.utoronto.ca/~mbraverm/Papers/FoolAC0v7.pdf)

## What changes for a very short input description?

The raw matrix in the unconditional construction contains many independently chosen bits. Here is a separate test specifically on formulas whose every input word is computable from its length in polylogarithmic time. Assume the target hypothesis $\mathrm{SAT}\in\mathrm{DTIME}(N^k)$ for $k=1,2$ or $3$. For every fixed $0<\eta<1/k^3$ a fixed linear-time guarded RAM can have $\Omega(N)$ cold unverifiable reads on **each** sufficiently large member of such a succinct family, even with $N^{1/k^3-\eta}$ total advice bits plus witness-verification time. The program and family can depend on the verifier model and the hypothesized solver. Here the verifier receives the ordinary input, native controller, read index and time; supplying the earlier table entries as a free history oracle would change the time bound.

Use the journal's conditional packed generator of an entire $B=2^m$-bit Boolean table in $O(B/\log B)$ steps. Its indexed function resists deterministic predictors of cost $B^{1/k^2-\eta'}$ on all but a fraction $1/2+B^{-\delta}$, with a positive $\delta$ depending on a chosen fixed margin $\eta'$. Fix the universal predictor before choosing the generator. Encode a guarded formula of size $N=\Theta(B)$ by a fixed header and repeated tautologies with $\Theta(\log B)$-bit fields. There are $\Theta(B/\log B)$ such records; their positions and words are computable from $m$. On this input produce the table from its length, scatter each bit as a one-or-two word, wait $\Theta(B)$ steps, and collect the public-order scan. Check the full scan by a second table generation. Pad the phases or publish their starting clocks as $O(\log B)$ advice. A guard wrapper can cap or skip unrelated malformed dimensions. The genuine pre-load controller is computable from $m$, the index and these clocks. [Conditional average-case indexed hardness at packed output speed](biased-hard-table-lookup.md)

For any proposed advice string, classify an index as one precisely if some private witness makes the total verifier permit the word two. On every uniquely correct read this predicts the table bit correctly. Compile the bounded existential check to explicit SAT. Its physical public input is the advice plus the short parameters; provide the true formula virtually from $m$. With $s$ bits of advice and $q$ steps of checking, the deterministic classifier runs in $(1+s+q)^k\operatorname{polylog} B$ steps, including materializing the bounded computation. The simulated logarithmic word width can be accommodated by the usual fixed polynomial padding at the chosen exponent: allocate the upper verification allowance $B^{1/k^3-\eta+o(1)}$ before compilation, so its logarithm is a fixed fraction of $\log B$. At $s+q\le N^{1/k^3-\eta}$, the classifier with its advice fits $B^{1/k^2-\eta'}$ for $\eta'=k\eta/2$ at all sufficiently large arities. Consequently at least $(1/2-B^{-\delta})B$ designated reads fail unique certification. This conclusion includes the quadratic and cubic hypotheses, with advice-plus-time numerators arbitrarily close in exponent to $N^{1/8}$ and $N^{1/27}$. This second argument charges actual verifier time, unlike the unconditional raw-input probe theorem.

Thus neither free local witnesses nor succinct generation of the public input gives a general upper bound on verified read errors for all linear native programs. The remaining quantifier in a time proof concerns a correct solver on the signed computations generated *for that solver*. The guarded examples can be recognized by another solver cheaply.
