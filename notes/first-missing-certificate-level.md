# One hard UNSAT instance on a uniform list at each scale

**Research journal, 24 November 2026.** There is an unconditional version of the common-instance argument for rejection. It uses an ordinary nondeterministic source, with no SAT subroutine. At every sufficiently large scale it produces a short ordered list of explicit 3-CNFs. A prefix is satisfiable and all later formulas are unsatisfiable. The **first unsatisfiable formula** has no fast rejection certificate from any admitted program that is sound on the whole list. The formulas all have the same length. The index of the hard one is unknown, and has a matching bounded-time program-description lower bound.

For example, let $H$ be a source horizon and $L=\lceil\log_2(H+2)\rceil$. Take all binary programs of at most $\ell=\lfloor\log_2 L\rfloor$ bits; there are $P=2^{\ell+1}-1$ such strings, including invalid codes. The list has $P+1=O(\log N)$ entries of $N=\Theta(H L^3)$ encoded bits each. For a fixed sufficiently large $K$, no admitted sound certifier can produce a verifiable rejection of the indicated entry in $M=\lfloor H/L^K\rfloor$ steps. Verification time includes nondeterministically supplying the certificate. Programs receive the scale and list index for free in addition to random access to the formula. The same first-unsatisfiable index works for all fixed sound certifiers once their codes fit. This excludes time $N/\operatorname{polylog}N$ on the indicated formula. The budget is smaller than $N$.

## A chain of false offers

Write $A(e,h)$ if $e$ has a computation, using at most $M$ steps, offering UNSAT on the actual list member $F_h$. No truthfulness is required of the programs in this predicate. Use the same finite checker text and bounded source horizon for all $0\le j\le P$. Give the checker an input containing its own text as data, $H$ and $j$ in fixed-width fields. Define the source on that input to guess distinct program codes $e_0,\ldots,e_j$ and a branch witnessing each $A(e_h,h)$. Accept iff all these branches check. $F_j$ is the packed 3-CNF of this source computation. A simulated program's read of $F_h$ is supplied by replacing the index in the public source input and computing that word of the bounded tableau. Reading the formula's syntax does not require deciding its satisfiability. With this single fixed source we obtain

$$F_j\in\mathrm{SAT}\quad\Longleftrightarrow\quad
 \text{the first }j+1\text{ rows of }A(e,h)\text{ admit pairwise distinct offering codes.}$$

Any witnessing chain has a witnessing prefix at every earlier position. No chain of $P+1$ distinct codes exists, so the first failed extension occurs at some $j_*\le P$. Fix any length-$j_*$ witnessing chain, taking the empty chain if $j_*=0$. Every program used in that chain made a false UNSAT offer, since its own prefix shows that its input was satisfiable. If another program that is sound on every list member had an offer on $F_{j_*}$, its code would be distinct from all the codes of the chain. Appending its witness would show $F_{j_*}$ satisfiable. Thus $F_{j_*}$ is unsatisfiable and every admitted sound certifier lacks a timely offer there. Soundness only on inputs before $j_*$ already suffices for the exclusion. No retirement guesses or assumptions about a candidate's correctness elsewhere enter the proof. [Finite chain argument](../lean/FirstMissingCertificateLevel.lean) · [Exhaustive matching and Hall-witness checks](../audits/first_missing_offer_audit.py)

A finite implementation lets three programs inspect two physical literal-sign bits in an actual fixed-width binary clause list. Each menu gives four formulas of 168 bytes each, differing only in those two signs. Independent DPLL on all 16,384 serialized formulas agreed with the matching calculation over all 4,096 menus. The counts for first failure at indices 0, 1, 2 and 3 were 512, 640, 968 and 1,976. This exercises the finite two-probe case. [Packed compiler and DPLL experiment](../audits/first_missing_packed_example.py)

The result persists if each level has multiple seeds: permit earlier links to use any seed at their respective levels and require the last link to use the current seed. At the first level with no realizable chain at any seed, every seed is negative and has the simultaneous exclusion. The seedless statement suffices here.

## Time and length

Use one uniform guest interpreter, fixed word width $C L$, code length bounded in advance, and virtual zero padding if required to make the native word width $\Theta(L)$. A guest checks offers against the specified instruction clock. Scanning and decoding code, servicing virtual formula reads, translating work addresses when needed, and storing the history used by the universal interpreter cost at most a fixed polynomial in $L$ per guest step, including setup for codes of these lengths. Allocate clean work banks per link or keep a list of locations written and clear them between links; each clearing operation is charged to a previous write. Store the used-code flags in a table indexed by length and binary payload, checking a fresh flag before each link. Use a step counter and fail on an invalid code, false signal, duplicate or timeout. The total time is $O(P(M+\ell+1)\operatorname{poly}(L))=o(H)$ for sufficiently large fixed $K$. Building an explicit list of all program–formula truth values is unnecessary. Fixing the input fields, number of rows and clock gives identical formula lengths. The only variable data in the layouts need be the $\lceil\log_2(P+1)\rceil$ input pins for $j$. A whole member can be written in $O(N\operatorname{polylog}N)$ time and a requested word can be obtained in $\operatorname{poly}(L)$ time. A verifier that simulates a native algorithm with a different fixed word-width constant can pay logarithmic trie overhead. [Packed reduction](packed-band-transfer.md) · [Shared word and certifier conventions](common-solver-seeds.md)

The construction also permits $\ell=\lfloor\alpha\log_2 H\rfloor$ for any fixed rational $0<\alpha<1$, with $M=\lfloor H/(P L^K)\rfloor$. Table space, program decoding and clearing contribute $O(P\operatorname{poly}(L))$ and fit by the same calculation. Now the list has $O(H^\alpha)$ entries, each exclusion lasts $H^{1-\alpha}/\operatorname{polylog}H$ steps, and the unknown index has $\ell+1$ bits. Alternatively, $\ell$ may grow arbitrarily slowly if the desired list is smaller.

## Why a short list does not give a fast sound choice

There is a finite, explicit relation to bipartite matching. Join row $h$ to code $e$ when $A(e,h)$ holds. A failing prefix has a Hall witness: some nonempty subset $S$ of its rows has neighbors in a set $T$ with $|T|<|S|$. The obstacle to using this to certify $j_*$ is testable. In addition to specifying $S,T$, one must certify that **none** of the codes outside $T$ offers on any row in $S$. A nondeterministic bounded machine recognizes the *existence* of such a branch with one row, code and computation, in $O((M+P+1)\operatorname{poly}(L))$ time. A hypothetical linear SAT solver can decide this test with polylogarithmic overhead. The resulting work estimate exceeds the very cap $M$ that a contradiction needs. Hall's theorem by itself does not perform the absence test. [Matching criterion](https://doi.org/10.1112/jlms/s1-10.37.26)

Restricting the Hall search to a single row and a single code outside $T$ gives no generic simplification of that absence query. A fixed code can ignore the row and formula completely and offer exactly when a chosen bounded nondeterministic computation on the public scale parameter accepts. Any shortcut for arbitrary such rectangles must handle these computations too. This example concerns arbitrary proposed Hall witnesses. An argument exploiting a *particular* deficient prefix with an easier rectangle is still possible.

There is an independent quantitative obstruction to selecting the index. Suppose a fixed interpreter on public $H$ and a binary payload $z$ outputs $j_*$ quickly enough that the following wrapper fits the $M$-step clock. The wrapper offers UNSAT exactly when the supplied index $j$ equals its computed number. It is sound on the whole list and would offer at $j_*$. Therefore the wrapper code must exceed $\ell$ bits. With an externally length-delimited payload and fixed interpreter overhead $c$, this excludes every such $z$ with $|z|\le\ell-c$. Conversely $\ell+1$ payload bits suffice to name $j_*$ literally. Here $z$ may be chosen afresh at each scale. Thus the additive-constant description gap cannot be removed by treating a few bits of length-dependent advice as free. One can compute the actual index by exhaustive search, at a cost beyond the displayed guarantee. This argument also bounds *any* replacement list in the same model. On any list of $q$ public indices, a fixed prefix plus $\lceil\log_2 q\rceil$ bits names any one negative index and offers only there. It is sound on that list. To have even one negative member defeating every $\ell$-bit code therefore requires $q=\Omega(2^\ell)$. The constructed list meets that requirement within a constant factor.

For an unconditional example of a failed time amplification, the test itself has to run up to $P$ candidate computations of $M$ steps, and its formula encodes the full horizon $H$ in $\Theta(HL^3)$ bits. The ratio $M/N$ goes to zero even if $P$ grows extremely slowly. Inferring superlinear decision time would require a different way to certify or compress the long computations whose syntax appears in this list.

## A single output on widely separated scales

There is a different unconditional tradeoff if soundness is required across scales. Take $H_1$ large and $H_{i+1}=2^{H_i^2}$, admit codes of length at most $\lfloor(\log_2 i)/2\rfloor$, and produce just one formula at each such scale. Have its nondeterministic source accept when some admitted code offers UNSAT in $M_i=\lfloor H_i/(\log H_i)^K\rfloor$ steps on this formula and has never offered within budget on a previous scale where it was admitted. Compute previous raw offers by exhaustive deterministic simulation of the guesses of each relevant program on each earlier, syntactically specified formula. At scale $j$ there are at most $2^{O(M_j\log H_j)}$ possible tapes of guessed words; interpreting each uses polynomial time in $H_j$. The sum of this cost over previous scales and current codes is $o(H_i)$, by the growth rule and the fixed word-width convention. The time for current nondeterministic testing fits too. The scale index is public, and the preceding horizons and corresponding short inputs can be generated successively using repeated squaring of the old horizon and writing a binary power of two. Even writing the current horizon in binary fits the clock. Start at a size that covers the uniform constants in these tests.

Each positive formula charges one code's first admitted offer; the charged code is wrong there. Through stage $I$ there are at most $2\sqrt I$ such stages. At every remaining stage the lone output is unsatisfiable, and every admitted program sound throughout the sequence lacks a timely rejection there. Thus it is possible to avoid supplying a list at the price of unknown exceptions among extremely widely spaced scales. The density concerns their stage indices only. It is essential that soundness here covers the other stages as well. The hard member of the short-list construction permits soundness on just one scale.

## Consequence for solver memory

Use this same list, generated **independently of any fast SAT reference**, at every sufficiently large scale. If a fixed correct near-linear solver exists, its computation on the first negative member has cumulative shortest polylogarithmically queryable snapshot length at least $N^2/\operatorname{polylog}N$ for every fixed polylogarithmic-time decoder (the log power may depend on the programs). A guessed chart of cheap snapshots and one negative local-defect SAT query would otherwise give a sound rejection certifier in time $M$ on that member. The certifier receives the small index and generates any requested formula word from it, so no full input is copied into the defect test. This uses the [checkpoint argument](common-solver-seeds.md). For fixed $d=2,3$, an $O(N^d)$ solver likewise needs $\Omega(N^{1/d}/\operatorname{polylog}N)$ gates for its actual controller stream annotated with each load's last writer, and $\Omega(N^{1/d^2}/\operatorname{polylog}N)$ for just its controllers, on that very same negative member. The defect verifiers cost respectively $s^d\operatorname{polylog}N$ and $s^{d^2}\operatorname{polylog}N$ for $s$ gates, with small indices as public data. They use the hypothesized algorithm internally. Only this consequence, not the list theorem, uses that hypothesis. [Register-stream verifiers](chronological-solver-registers.md)

The closest comparisons located are instance complexity (small sound special-purpose programs) and hard sequences for algorithms and proof systems. The constructed short *list* is uniformly available. Naming its distinguished member cheaply is itself excluded. No priority claim is made for the list or its description consequence. ## A published hierarchy supplies an infinitely-often positive counterpart

Fortnow and Santhanam prove that for every $1\le c<2$ there is a language in nondeterministic tape time $m^2$ outside nondeterministic tape time $m^c$ with $\lfloor\sqrt m\rfloor$ advice bits. This already gives a common *satisfiable* instance against many certifiers, with different length and time quantifiers. Fix $0<\delta<1/2$, use $c=2-\delta$, and encode the hard machine's computation on $x\in\{0,1\}^m$ as $F_x$ with $N=\Theta(m^2\log^3 m)$ bits. Use all codes of length at most $\lfloor (\log_2 m)/2\rfloor-1$ and time $m^{2-2\delta}$. At infinitely many $m$ some positive $F_x$ has no timely positive certificate from *any* code sound throughout that length's family. Certifiers may see $x$ as well as virtual $F_x$.

Otherwise supply a mask of at most $\lfloor\sqrt m\rfloor$ bits specifying which codes are sound at each length. Guess a marked certifier and follow its timely offer. This would decide the hard language. For the tape-time simulation, guess a bounded RAM computation log, check each local step and verify memory by sorting address–time records on tapes; the extra time is a fixed polylogarithmic factor. One may materialize the small public input $x$, and compute bits of the virtual formula as needed. Total nondeterministic tape time is $(m+m^{2-2\delta})\operatorname{polylog}m=O(m^{2-\delta})$. Finite exceptions can be hardwired. The contradiction is to the published advice hierarchy. Here the candidates range over an exponentially long list of inputs indexed by $x$, the clock bound is polynomially below $N$, and the conclusion is infinitely often. The short negative list above has different guarantees. [Fortnow and Santhanam, *Hierarchies Against Sublinear Advice*](https://eccc.weizmann.ac.il/report/2014/171/) · [RAM log verification and tape sorting](positive-witness-hierarchy.md)
