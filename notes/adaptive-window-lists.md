# The cost of lists that sometimes hit a good block

**Research journal, 24 November 2026.** Suppose a verifier offers a short list without certifying that it succeeds. It would still help if it hits a genuinely good block infinitely often and its total normalized size is a computable real. The necessary condition is stronger. Under the relevant computation budget, a finite total cost for infinitely many successes must be a Martin-Löf random real. I tested this with a procedure that uses exact feedback from earlier windows. It produces infinitely many successes at a finite, explicitly bounded total cost. [Window construction and sound-list test](shorter-window-proofs.md)

## Which computations and costs are measured

Use the same s, b_s=2^s, W_s=2^(b_s), J_s=2^(3b_s), and I_s=[J_s,J_s+W_s). A block j in I_s is good when e_j≤1/W_s. At a good block at most 2^(j−b_s) lengths are heavy. One of the first 2^(j−b_s)+1 lengths m therefore lacks an m-bit word starting with j zeroes from all names shorter than m at the clock B(m)=2^(20m). This conclusion concerns the fixed prefix-free interpreter U.

Let a uniform algorithm supply masks A_s⊆I_s and put q_s=|A_s|/W_s. A success means that A_s contains a good block. Assume the entire run through s costs at most 2^(α·2^(J_s)) poly(2^(J_s)) RAM steps, for a fixed α<5, or has the direct multitape bound with α<10. In particular each mask can be recovered by queries to a hypothetical linear SAT solver on uniformly constructed formulas within the RAM budget. For a cubic solver use input exponent less than 5/3. Every assertion about the corresponding SAT assumption below follows by running this recovery as the mask algorithm. Fixed alternations fit the linear hypothesis. The masks can be empty, and the algorithm can use earlier outcomes within its time bound.

**Theorem.** If there are infinitely many successes and C=Σ_s q_s is finite, the binary prefixes of C have prefix complexity at least their length minus a constant. For C outside [0,1) take the fractional part, supplying the fixed integer part to the decoder. Equivalently this fractional part is Martin-Löf random. In particular, a SAT-defined schedule with infinitely many hits and a finite nonrandom total would exclude the applicable SAT time bound. This conclusion also holds unconditionally for native scans in the given budget. No novelty claim is made for the classical randomness criterion. The proof here connects it to these particular sporadic window hits. [Bienvenu and Shen on complete left-c.e. reals and convergence](https://arxiv.org/abs/1110.5028)

## Spending a short halting program on the future lists

Write C_u=Σ_{1≤s≤u}q_s. For some fixed d, every program p halting after t native steps satisfies

    C − C_t > 2^(−|p|−d).                                             (1)

One fixed stream decoder reads gamma(d), then simulates p, measuring its running time t and the number |p| of input bits actually consumed. Start allocating at stage s₀=max(t+1,|p|+d,2). At stage s≥s₀, assign each member of A_s, in order, one binary prefix of length L_s=b_s−|p|−d. Allocate adjacent half-open cells of length 2^(−L_s) in [0,1), in increasing order, abandoning the allocation if it would run past 1. The lengths L_s are increasing, so every previously used endpoint is aligned to the current grid. When the run reaches s, the decoder can compute the mask by the given scan, replaying earlier state if needed. To dispatch the input, read enough new bits to have L_s bits in this field, then compare the resulting integer with the current allocated interval. No valid prefix gets read past its end. Empty stages can be skipped. Storing endpoints and recovering the member from its within-stage rank cost poly(W_s+b_s) additional operations per stage.

Suppose C−C_t≤2^(−|p|−d). The total binary measure allocated from s₀ onwards is at most one, since it equals 2^(|p|+d)Σ_{s≥s₀}q_s. For each j in every future mask the code is then present. After reaching j, read j−b_s+1 bits for a length offset and m−j bits for the final suffix, rejecting out-of-range lengths. If j were good, some input would print an omitted word with complete name length

    header + |gamma(d)| + |p| + L_s + (j−b_s+1) + (m−j)
      = m + header + |gamma(d)| + 1 − d.

Fix d so this is less than m. The initial simulation of p and time accounting cost poly(t+1), which fits at the chosen scales since s₀>t. The mask scan, code allocation and copying the output fit B(m) by the strict simulation margins. A stateless recomputation of the scan at each stage adds at most a polynomial factor in 2^(J_s). Any small-scale clock exceptions can be skipped by a fixed initial threshold. Thus *all* masks after s₀ would miss, contradicting infinitely many successes. This proves (1).

The allocation proof admits a useful local clock. During a stage, visit the candidate indices j in increasing order, assigning the next code of the same length L_s exactly when j is included. Once the input selects an assigned code, immediately produce its output. It therefore suffices that the scan *through j* finish within 2^(α·2^j) poly(2^j) RAM steps with α<5, or with exponent below 10 for a multitape scan. There is no need to finish expensive tests at later indices of the current window before decoding j. To compute the partial costs C_u with no time bound one can always finish their windows. This version allows per-block verification of a failed prediction.

## What the limit reveals

For u with C−C_u≤2^(−k), (1) implies that no program of length at most k−d halts after u steps. Such a u is computable from k+O(1) initial bits of C. For instance, let C' be the truncation at k+2 fractional bits. Sum masks until C_u>C'−2^(−k−2). This happens since the threshold is strictly below C, and afterwards C−C_u<2^(−k). The fixed integer part costs only a constant. A computable C would make halting decidable by this procedure, so dyadic ambiguity cannot arise.

More directly, given any prefix program for these k+2 bits, run it, recover the bit length, find u and simulate all programs of length at most k−d through u steps. Some string of length k−d+1 is absent from their outputs, since the number of names is smaller than the number of strings. Print the first such string. No later halt of one of these names can print it either. This unclocked fixed transformation proves the claimed prefix-complexity lower bound, using the usual incompressibility characterization of Martin-Löf randomness.

For example, prescribe exactly floor(W_s/(s+1)²) entries per window, in positions chosen using a SAT verifier. The sum of the normalized sizes is computable because the tail is bounded by Σ_{s>u}1/(s+1)². Even **infinitely many** genuine hits at these positions would suffice; the unsuccessful masks need no soundness guarantee. The same applies to any known computably convergent upper bound on the costs with computable individual mask sizes.

## A fast procedure that defeats the bounded-total shortcut

Begin with r=1. At window s, take the first W_s/2^r indices as A_s. Increase r by one after a success and keep it unchanged after a failure. The division is exact since r≤s for s≥1. While constructing mask s, the success of each *previous* mask can be determined by full simulation. Through block j this takes 2^(42·2^j) poly(2^j) tape steps as in the [three-block calculation](shorter-window-proofs.md). The last index in I_(s−1) is less than J_(s−1)+W_(s−1), with J_(s−1)=√J_s. Thus the computation of all previous outcomes and construction of the current mask use 2^o(2^(J_s)) tape steps. Current-window outcomes need never be predicted.

If r stopped increasing, all sufficiently late masks would fail while retaining the same positive relative size 2^(−r). Every failure puts the whole mask in the bad set of its window. These disjoint sets would violate Σ_j e_j≤1/2. So r tends to infinity. Successful masks have total normalized cost exactly Σ_{r≥1}2^(−r)=1. Failed masks cost at most 1/2 altogether, by charging each of their j's more than 1/W_s to e_j. There are infinitely many successes, q_s tends to zero, and

    1 ≤ Σ_s q_s ≤ 3/2.

The theorem makes this particular total noncomputable and its fractional part random. Even an explicit constant bound on the total, combined with infinitely many hits of a shrinking list, is insufficient for a SAT separation. The feedback procedure spends its unknown part on failures. A way to certify enough successes with a nonrandom total, or to verify that its failures admit a computable tail bound, would change the conclusion. No such certificate was found for a schedule meeting the other requirements. The finite experiment checked the two budget charges on 12,951 three-stage histories. ## Proving only positive claims about producers

Call the feedback window a failure when *all* of its candidates are bad. Consider a uniform verifier which may certify that a candidate j is bad. Require every positive verdict to be sound. Suppress certified candidates from the offered masks. On successes every true good candidate remains. The filtered schedules therefore still have infinitely many hits. Use the online allocation above, so the verifier can run at the budget for the individual j it certifies. Under the assumed SAT time a uniform existential proof system with the corresponding input-size margin suffices; a fixed number of quantifier blocks is allowed in the linear case.

The surviving total cost on **successful** windows is a computable real. Evaluate the actual outcomes and all certificate predicates by unrestricted finite searches until the Rth success. Subsequent successful windows contribute at most Σ_{r>R}2^(−r)=2^(−R), even if the verifier suppresses some entries there. The whole filtered cost is finite and has random fractional part by (1). Translation modulo one by a computable real preserves Martin-Löf randomness, since the inverse translation of an effective small-measure open cover is again such a cover. Consequently **the normalized cost of uncertified candidates on failed windows itself has random fractional part**:

    Σ_{s a failure} |{j∈A_s : the verifier does not certify j}| / W_s.

These candidates are all genuinely bad. In particular, to exclude the hypothesized SAT time it is sufficient to certify every candidate on failed windows, or even to leave a residual failed cost with a computable tail. The verifier need not certify any small upper bound or any good block. For example, if the total residual failed cost while the success counter has value r is bounded by a sequence g_r with computably summable tail, then it is computable by running through successes as above. That alternative would also suffice.

Badness has positive evidence: at j in I_s it asserts that at least 2^(j−b_s)+1 distinct lengths m are heavy. For each such m and each target word beginning with j zeroes, some shorter program actually produces the word by B(m). Guess the distinct lengths, universally choose one of them and a target word, and exhibit a name and a valid producing computation. The list of lengths and the name selected on one branch fit well within the stated linear-target formula budget. A full chosen computation can take as many as 2^(20m) steps, exceeding that budget. A shorter verification of *enough positive producing runs on the failed lists* is the outstanding step.

The natural early check certifies j if the same count already exceeds the threshold after only 2^(3m) steps per program. It is sound, and an exact tally by direct tape simulation takes at most 2^(8·2^j) poly(2^j) steps at block j. The unconditioned online theorem applies. Thus even after this check, the mass of bad candidates left on failed windows has random fractional part. Mere existence of positive witnesses does not bound their verification time.

## How much positive evidence is missing in each phase?

Write D_r for the surviving normalized cost on failures while the feedback counter equals r, before its next increment. Every sound verifier with the online budget has a constant c>0 such that for all sufficiently large r,

    D_r ≥ c/[r(log₂(2r))²] − 2^(−r).                                  (2)

Use the same prefix allocator, starting from the code E(r) of length l(r)=log₂ r+2 log₂ log₂(2r)+O(1) and gamma(d). Reach the first stage in phase r by replaying previous outcomes. Those exact outcome computations fit at the later stage because of the spacing between windows. Allocate a prefix of length b_s−l(r)−d on every residual entry seen while the counter has value r. The decoder visits indices in order and can act on an entry immediately. If the total normalized cost through the successful stage in this phase were at most 2^(−l(r)−d), then all residual entries would fit in the prefix space. Some residual entry on the successful stage is good, giving a name of length m+header+|gamma(d)|+1−d for a missing word. Choose d large enough to exclude this. Since the successful stage costs at most 2^(−r), (2) follows. Thus verifying all but o(1/[r(log r)²]) failure cost on even a subsequence of phases would suffice under the SAT hypothesis. No search for that subsequence is needed.

There is an actual positive certificate of failure for some phases' windows. At stage s in phase r, present a prefix program p which prints s by 2^(2^(J_s)) steps with |p|≤r−c₀. One fixed decoder can run p, recover r from the previous windows, and read b_s−r bits to pick *any* member of the feedback mask. If that member were good, the length-offset and suffix fields would complete a name of length at most m+header+|p|+1−r. Take c₀ greater than the fixed overhead plus one. The search over the at most 2^r possible program names and their capped simulations fits even the deterministic tape budget at the start of the window. This test soundly certifies every member as bad without replaying a separate full computation for each target.

For example, it certifies failure at every sufficiently large stage s=2^v. The bound Σq_s≤3/2 and monotonicity of 2^(−r) give s·2^(−r)≤3/2 at stage s, so r≥v−1. A fixed program with the gamma code of v prints s in poly(v+1) time with O(log(v+2)) bits. The certificate succeeds on an infinite explicit subfamily. Equations (1) and (2) show why these proofs still leave too many true failures uncertified. In particular the normalized failure cost at windows left over after all such short-program certificates has random fractional part.

There is also an unclocked interpretation of the feedback counter. Let r_s be its value on entry to window s. The sequence is computable, nondecreasing, and advances by at most one. Since Σ_s 2^(−r_s) has random fractional part, the classical characterization of Solovay functions gives K(s)≤r_s+O(1) for every s and r_s≤K(s)+O(1) infinitely often. If desired, first divide the series by two to place it in [0,1); this adds one to each code length and preserves randomness. This consequence concerns unbounded prefix complexity; constructing producer certificates within the clock still requires timely descriptions. [Bienvenu and Shen, theorem 13](https://arxiv.org/abs/1110.5028)
