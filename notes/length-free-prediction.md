# From a hard private-coin output to average-case bit prediction without a length parameter

**Research journal, 24 November 2026.** I tried amplifying the gap between a short randomized producer of $y$ and its proposed deterministic replacements. A fixed binary encoding makes the following two failures equivalent. One is the high-probability [private-coin replacement failure](private-coin-prefix-coding.md). The other is a sequence of such outputs on which no comparably short deterministic local program predicts an encoded bit with advantage bounded away from zero. The query comes from the same fair stream at every length. The predictor gets no output length or deadline, may fail on many queries, and is charged only for the queries on which it returns the correct bit in time with the stipulated number of reads. I have no sequence realizing either failure.

## A code on a common query stream

For a finite word $y$ of length $m$, put $s=\lceil\log_2(m+2)\rceil$ and $r=4s$. On a fair query stream $u$, interpret its first $r$ bits as $x\in\mathbb F_{2^r}$ and the next $r$ as $a$ in the binary coordinate basis. Use the first monic irreducible polynomial in a fixed order to specify the field. Constructing it by finite search over candidate polynomials and possible factors costs $2^{O(r)}=\mathrm{poly}(m+2)$ time. With $y_i$ its bits indexed from zero, compute
$$
 P_y(X)=X^m+\sum_{0\le i<m}y_iX^i,\qquad
 C_y(u)=\langle a,P_y(x)\rangle_{\mathbb F_2}\oplus u_{2r+1},
$$
where query positions are one-based. This uses $8s+1$ bits on every query. A randomized program that first independently recovers $y$ with probability at least $2/3$ gets $C_y(u)$ correct with at least that probability for every fixed $u$.

Write $D_y=(-1)^{C_y}$. Rows from different scales have correlation exactly zero because the larger row's last query bit is fresh and occurs once. At one scale, averaging over $a$ makes the correlation of different rows equal to $\Pr_x[P_y(x)=P_v(x)]$. The leading degree marker distinguishes even unequal word lengths. The difference is a nonzero polynomial of degree less than $2^s$ and hence this correlation is at most $2^{-3s}$. This is Reed–Solomon evaluation concatenated with the binary Hadamard code, with the additional bit separating scales on the common stream. [Guruswami, §8.4.1 on the concatenated code and list decoding](https://www.cs.cmu.edu/~venkatg/pubs/papers/frozen.pdf)

## Recovering an exact word from partial predictions

Fix a deterministic native prefix interpreter with a separate one-way challenge stream, with no signal for the end of either stream. Suppose that, on a program name $p$, a fraction strictly greater than $1/2+\beta$ of challenges lead to a halt returning $C_y$, consuming **exactly** the program prefix $p$, after at most $T$ steps and at most $b$ challenge reads. Other executions may disagree, overread, run for longer, or diverge. Put $K=2^k$ with $k\ge1$, $1/K\le\beta$, and suppose $2^{-3s(m)}\le1/K^2$. Then there is an ordinary deterministic program printing $y$ with length and native time bounded by
$$
 |p|+2k+O(\log(k+2)),\qquad
 (T2^b+2^m+1)\,\mathrm{poly}(\log(T+2)+b+m+|p|+k+2).
$$
The new program receives neither $m$ nor any of the clock and challenge-read bounds. Its extra input consists of self-delimited $k$ and an occurrence rank in $2k$ raw bits.

First delimit $p$. With the $l$ already loaded candidate program bits, run a schedule of bounded deterministic simulations. For parameters $v,j\ge0$, use every $v$-bit challenge prefix through $2^j$ steps, stopping a simulation on excess challenge demand. Test if more than half of the challenges request another program bit, or if more than half halt returning a bit with exactly $l$ program bits consumed. The first outcome extends the loaded prefix by one. The second completes its parsing. The two certifying events are disjoint on the full challenge space, even when witnessed at different cutoffs. For $l<|p|$ the promised successful runs reach the extra read in time and the exact-halt test cannot pass. At $l=|p|$ they force the halt test. Enumerating $(v,j)$ by increasing $v+j$ reaches a certificate within $(T2^b+1)\mathrm{poly}(\log(T+2)+b+|p|+2)$ work per parsed bit. The input rank and its length parameter are read before this process.

For this fixed $p$, enumerate candidate words $v'$ for which the following two properties are witnessed:

* $2^{-3s(|v'|)}\le K^{-2}$.
* Some finite pair of challenge depth and machine clock certifies that more than $1/2+1/K$ of all challenge streams return $C_{v'}$ with exact consumption of $p$.

The number of different listed words is at most $K^2$. For any finite sublist of size $L>0$, use a common challenge depth and clock dominating all its certificates, increasing the depth also to include all its code bits. The union of the witnessed output cylinders gives one partial Boolean function because the predictor is deterministic. Complete it arbitrarily to a sign function $f$. Every listed row has $\mathbb E[fD_{v'}]>2/K$. For $Z$ the sum of those rows, Cauchy–Schwarz gives $(2L/K)^2\le\mathbb EZ^2$, whereas pairwise correlations give $\mathbb EZ^2\le L+L(L-1)/K^2$. These imply the asserted list bound. The argument applies to differing candidate lengths and discovery times. Filling the unspecified answers is used only to bound the list size.

At stage $H$ try triples of word length $m'$, challenge depth $v$ and log clock $j$ with $\max(m',v+j)=H$. For a fixed $(v,j)$ the three-valued answer table (zero, one, or no exact bit) costs $2^{v+j}\mathrm{poly}(H+|p|+2)$ time. Tabulate prefix sums by answer type in lexicographic challenge order. Given one of the $2^{8s(m')+1}=\mathrm{poly}(m'+2)$ cylinders used by a candidate row, its intersection mass with each type is recovered by a range sum, or by inspecting its sole ancestor when $v$ is smaller. Evaluate the code on these cylinders and add the matching masses. This tests a candidate in $\mathrm{poly}(H+k+2)$ time after preprocessing, even when the answer table is large. Enumerating all $2^{m'}$ candidate words, skipping previous discoveries via a trie, takes $2^H\mathrm{poly}(H+k+|p|+2)$ through this stage. Stop at the supplied zero-based rank in the fixed discovery order, printing its word. Our $y$ is witnessed by stage $\max(m,b+\lceil\log_2(\max(1,T))\rceil)$. This proves the stated clock and length bounds, including exact name consumption on a literal target interpreter.

## Removing the exponential search over possible words

The term $2^m$ in the elementary enumeration above can be replaced by $(m+K+2)^{O(1)}$, with a fixed exponent. This allows an output of length polynomial in the log clock. The list still spans different lengths, with the same rank and prefix parsing. Use the actual three-valued prediction table at one bounded clock and read depth. Let $g(u)$ be its returned sign on an exact halt, and zero otherwise. At a fixed scale $s$, put $F=2^{4s}$, $M=2^s$, and write $x,a,z$ for the first field symbol, the second field symbol and the final marker bit of the challenge. For $b$ in the field compute the rational numbers

$$
c_{x,b}=\mathbb E\!\left[g(u)(-1)^{z+\langle a,b\rangle}\mid x\right].
$$

Conditional averages of $g$ on each cylinder $(x,a,z)$ use the prefix counts described above. This permits a direct finite Walsh transform at each $x$. By orthogonality of the characters on $a$ and the bound $|g|\le1$, $\sum_b c_{x,b}^2\le1$. A word $y$ which passes the strict prediction test has $\sum_x c_{x,P_y(x)}>2F/K$. Indeed its fraction of correct exact answers exceeds $1/2+1/K$, and its fraction of incorrect exact answers is at most one minus its correct fraction. This estimate uses zero for every unsuccessful computation.

Keep the original scale condition $F\ge MK^2$. Take $\lambda=16KF$ and assign each field cell $(x,b)$ the nonnegative integer multiplicity $h_{x,b}=\lfloor\lambda\max(c_{x,b},0)\rfloor$. A bivariate interpolant required to vanish there to multiplicity $h$ incurs at most $h(h+1)/2$ homogeneous constraints: set to zero the coefficients of total degree less than $h$ in its formal translation to that cell. For each integer $h\ge0$, $h(h+1)/2\le h^2$, so the total number of constraints is at most $\sum h^2\le\lambda^2 F$ by the sum-of-squares bound. Use monomials $X^iY^j$ with $i+Mj\le D=24F^2=(3/2)\lambda F/K$. There are at least $D^2/(2M)$ such monomials: the sum of the integer slice sizes bounds the area of the right triangle by rounding each point down to its integer coordinates. Thus there are at least $(9/8)\lambda^2F$ unknowns, exceeding the number of constraints. A nonzero interpolant $Q$ can be found by Gaussian elimination.

On a passing word's graph the multiplicities sum to more than $2\lambda F/K-F>D$. Substitution into $Q(X,P_y(X))$ gives a univariate polynomial of degree at most $D$ since $\deg P_y<M$. At each field element $x$ it has a root of multiplicity at least $h_{x,P_y(x)}$. This follows directly in every characteristic: after writing $X=x+Z$, both translated arguments $Z$ and $P_y(x+Z)-P_y(x)$ are divisible by $Z$. Therefore the substituted polynomial vanishes identically. Extract all binary-coefficient roots up through $M$ coefficients by successive substitution and normalization. For each candidate, its highest one gives its proposed length by the monic marker. Reject zero, invalid scales and candidates failing the original exact prediction test. Extraneous truncated roots are harmless because this final test uses the actual correct-answer probability. The number of root prefixes per positive depth is bounded by the initial $Y$ degree. The use of reliability scores as interpolation multiplicities comes from algebraic soft-decision decoding. [Koetter and Vardy](https://www.site.uottawa.ca/~zhcheng/RS_soft_decision.pdf) · [Root-extraction proof](recovering-longer-outputs.md)

After building the three-valued table and its prefix counts for parameters $v,j$, the per-scale cost is $2^{O(s+k)}\mathrm{poly}(v+j+|p|+2)$. This includes the rational arithmetic on proportions of cylinders, the explicit field and matrix, binary coefficient extraction and the final check. Use a fixed integer $E$ large enough for that bound. At stage $H$ handle parameter triples with $\max(v+j,E(s+k))=H$, using one answer table per $(v,j)$ and caching its prefix counts. Through that stage the total is $2^H\mathrm{poly}(H+|p|+2)$, since there are polynomially many parameter triples and each costs that much or less. For the witness one can take $v=b$, $2^j$ just above $T$, and $s=\lceil\log_2(m+2)\rceil$. This yields

$$
\big(T2^b+(m+K+2)^{O(1)}\big)\,
\mathrm{poly}\big(\log(T+2)+b+\log(m+2)+|p|+k+2\big)
$$

native steps and the same $|p|+2k+O(\log(k+2))$ program length. The cutoffs and the scale are discovered during the scan. Lean checks the integer constraint budget and the score after rounding signed coefficients. The Fourier estimate, interpolation and schedule are manuscript arguments. ## Which separation would suffice?

Let $t=2^q$, $|y|\le(q+2)^d$ for any fixed $d$, and let $w$ be an exact private-coin program of length at most $a\log_2(q+2)$ recovering $y$ by $t$ with probability at least $2/3$. In the theorem, set $T=t(q+2)^A$, $b\le B\log_2(q+2)$ and $|p|\le |w|+c$ for arbitrary fixed $A,B,c$. Any fixed positive prediction advantage then costs only a constant number of extra program bits and a fixed further polylogarithmic time factor to recover $y$, at all sufficiently large word lengths. Conversely an exact deterministic replacement for $y$ yields a perfect predictor with the same name up to a fixed header and $8s(|y|)+1$ query reads. At these lengths the deterministic coding test is equivalent to the short integer test by whole-table recovery. Driving the randomized program with independent fair program and private tapes gives the required inputless source. [Whole-table recovery](recovering-longer-outputs.md)

Thus if high-mass replacement fails, choose witnesses with the exact length and clock allowances tending to infinity jointly. Every fixed bounded word length has literal descriptions, so the witnesses can be chosen with $|y|\to\infty$. Along this one sequence, for each fixed $A,B,c$, the maximum timely correct fraction among these short deterministic names is at most $1/2+o(1)$, in the limsup sense. Fixing any candidate positive advantage first gives a fixed $K$ and applies the extraction theorem. A family with this average-case hardness would conversely rule out exact replacement, hence [linear SAT on the unrestricted RAM](sampling-at-a-numeric-length.md). Controlling the candidate predictor's information about the length matters here: a public length input to every candidate program would be additional information in this extraction.

There is also a lower limit on the useful read budget. If $b<8s+1$, all timely outputs counted at that budget are independent of the final fresh query bit. At most half of the queries can receive correct timely answers, even when the word itself has a trivial deterministic name. In particular, logarithmically many reads in $q$ can support positive advantage only at lengths polynomial in $q$.

The challenge-read allowance has a concrete role. With unrestricted fresh challenge bits the predictor can run $w$ using those bits as its private coins, buffering them, and evaluate the code at the same challenge on the resulting word. Whenever $w$ produced $y$ with exact consumption, this predicts correctly. Dependence between the simulated coins and the challenge cannot reduce that event's contribution. Arbitrarily many query reads can therefore reproduce the original $2/3$ agreement by this method. What is missing is a randomized family that evades **all** short predictions with the stated read allowance. The transformation alone gives no such family. Priority for the length-independent resource-bounded formulation is unestablished.
