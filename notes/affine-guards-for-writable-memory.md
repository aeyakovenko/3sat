# Charging a load without linearizing every cell in memory

On the [dense inner-product family of ordinary 3-CNFs](affine-dimension-along-sat-runs.md) the input consists of $D=2d=\Theta(N)$ freely chosen bits $x$ in fixed literal positions, all physical input bits are affine functions of $x$, and the correct return bit is the split nondegenerate quadratic $Q(x)$. Here $N$ counts encoded bits. There is a way to account for every correct RAM solver that gives a store **zero charge** even when its address and its effects on memory vary nonlinearly across the surviving inputs. It also gives a concrete reason why computing the cheapest exact restriction at each load is difficult.

## Keep the stores as they were issued

A branch of the analysis retains a nonempty affine flat $H$ of source inputs, a common program counter, and affine register contents on $H$. Keep the previous writes in chronological order as pairs of affine maps (address, value), restricted to the current flat. A store appends that pair without deciding which other writes it overwrites. There is no requirement on any individual physical cell's contents. Interpret each CPU instruction as a fixed constant number of elementary register, branch and access operations. The load and store addresses have already been computed into affine registers when the corresponding access is analyzed. The mathematical analysis can search the entire log to select a flat.

* At an indirect load with current address map $A$, look backward for the **last** prior store whose address $B$ equals $A$ anywhere on $H$. If there is one, restrict to its nonempty equality fiber. Its codimension inside $H$ is the rank of the linear part of $A-B$, at most the word width $w$. Every later store misses throughout the fiber, and the selected payload is affine on it. If every equality is impossible, the load returns its initial zero without any restriction. This rule chooses a surviving flat and may discard a preselected input.
* One can instead keep an entire address guard false at cost at most one. If equality is possible but not forced, some nonconstant coordinate of $A-B$ can be fixed at one. Iterate backward, ignoring impossible guards, and stop upon a forced match or exhaustion. Choose either construction at a given load. A store can also be skipped if on its matching fiber it supplies the same word the previously represented memory would have supplied there. Equal payloads on a suffix alone do not establish what happens if none of those stores matches.
* A selected path can resolve an equality branch on two affine words at cost at most one by fixing a mismatching bit whenever the guard is not already constant. An affine register operation is free. For a general arithmetic or addressing operation one may fix its bounded number of operand words, or fewer bits if the remainder of the operation is affine. A moving *input* address can be fixed at a cost at most the rank of its address map. At the resulting public position the physical input word is affine, including at repeated literal fields.

The retained set is nonempty at every step. On it the corresponding real executions have exactly the recorded control and register functions. This follows by induction using the actual latest matching write. At termination $Q$ is affine on the final flat, so its dimension is at most $d$. Indeed the polar form $Q(u+v)+Q(u)+Q(v)$ vanishes on the direction space of any affine-output flat, and a totally isotropic space of this nondegenerate form has dimension at most $d$. Consequently the sum of the losses of dimension on this **actual path** is at least $d$. With a common terminal verdict, the pointwise sign distinction of the companion theorem also applies. Every primitive has a selected-path bound $O(w)$, and stores whose input operands are ready incur zero regardless of their number. The same argument admits any better operation-specific bound that retains an affine output. Parity decision trees and affine restrictions are standard tools. [O’Donnell, Sun, Tan, Wright and Zhao on parity certificates](https://arxiv.org/abs/1312.2143)

## What changes when the input is fixed or random?

Through a specified real input $x$, one can fix the address equality of its actual last writer (if any). For each later remaining ambiguous store, choose an address bit known to mismatch at $x$ and impose that disequality. For an initial-zero answer all actual stores miss at $x$. This gives a valid flat through $x$, and value-preserving stores may still be ignored. The number of later stores that must be considered is unbounded. The rank bound for a *selected* load fiber cannot be applied blindly to this point-centered construction.

For an average-case accounting, split a flat on a guard by testing independent equations for address equality, stopping at the first failure. Discard inconsistent guards without a test. For a consistent system of rank $r$, the chance that test $i$ is reached on a uniform point of the incoming flat is $2^{-(i-1)}$. Thus the expected loss is exactly $2(1-2^{-r})$, including the all-equal outcome. A forced guard costs zero. On each resulting flat the conditional input is again uniform. Do the same for equality branches, and at a load inspect stores backward until a match is established. The expected total charge to all these guards equals **twice the expected number of tested guards that fail**. This follows by conditioning on each visit, including adaptive visits. This tallies mathematical guard tests in the simulation, which can be numerous in a single physical load. The full partition has affine outputs at its leaves and hence expected total codimension at least $d$. In particular a machine with fixed-position input reads, affine register computations and equality branches, using no work loads, needs at least $d/2$ equality branches on average on this family. It may issue as many blind stores as it likes. General arithmetic, variable input addresses and work loads give the other ways to spend the charge.

There is also a robust form of the obstruction to an affine simulation. On a flat of codimension $c<d$, every affine Boolean output disagrees with $Q$ on at least $(1-2^{-(d-c)})/2$ of its points. The restriction of the polar form has rank at least $2d-2c$, since the orthogonal complement of the direction space has dimension $c$. Squaring the character sum for $Q$ minus an affine comparator and averaging over shifts shows that only shifts in the radical can survive, giving bias at most two to the power minus half this rank. In particular an approximate trace on that flat starting from the actual inputs and ending with an affine answer must accumulate at least this total probability of a local inconsistency. Union bound the failures of successive exact machine transitions and any erroneous initial state. This is a lower bound on cumulative error against the same uniform flat, without independence of failures.

## Exactly what can be hidden in one fixed-address load?

Let $G=(V,E)$ be a finite simple graph with one independent Boolean input bit $x_u$ per vertex. Use four zero-initialized scratch cells. For each edge $uv$, store the constant one at the two-bit address $(x_u,x_v)$. Finally read address $(1,1)$. There are no intermediate work reads. The resulting bit is $f_G(x)=\bigvee_{uv\in E}(x_u\land x_v)$. The addresses and stored values are affine. Constructing an address requires only placing bits in disjoint word positions. If SAT syntax is needed, use pinned vertex bits, an AND equivalence per edge, and an OR chain with its output asserted using ordinary clauses of width at most three. A solver can check the template and evaluate this family, with an ordinary complete fallback. The optimization below is about the actual returned word before a branch fixes it.

At input zero, the largest linear subspace preserving the zero read has dimension exactly $\alpha(G)$, the independence number. On a linear zero subspace, two adjacent coordinate functionals cannot both be nonzero. Equal nonzero functionals attain one together, as do two independent functionals. All varying coordinates therefore lie in an independent set, and freeing every coordinate of such a set attains the bound.

The largest dimension on which the read is merely **affine** through zero is $\alpha(G)+1$ if the complement of some maximum independent set contains an edge, and $\alpha(G)$ otherwise. A nonconstant affine restriction has a zero kernel of codimension one. Equality in the preceding zero-space bound forces this kernel to be the full coordinate space on a maximum independent set $I$. In its other coset choose a vector zero on $I$ by subtracting the appropriate kernel vector. Its support must contain an edge in the complement. Conversely adjoin the indicator of such an edge to the coordinate space on $I$. The resulting read bit is exactly the coset indicator.

This characterization extends to every negative input with support $S$ independent. Replace $\alpha(G)$ by the largest size $\alpha_S$ of an independent extension of $S$. In a zero flat through that point, a coordinate adjacent to an element of $S$ is zero or is determined by the coordinate of that neighbor. Indeed two nonconstant affine Boolean forms with no simultaneous one must be complements, and a constant-one neighbor forces zero. Among vertices outside the closed neighborhood of $S$ all coordinates start at zero and the varying ones form an independent set $T$. Projection to $I=S\cup T$ is injective on the flat. Conversely an independent extension supplies a full coordinate flat. In the case of equality in this bound the projection to $I$ is bijective. The same coset argument can then set all coordinates of $I$ to zero on the nonzero coset, so the affine-read optimum increases by one exactly when a maximum extension has an edge in its complement. The backward construction uses the coordinate space on that extension, which contains the prescribed point. On a positive input, fixing two true edge endpoints gives a constant-one flat of dimension $|V|-2$. Optimality follows because the zero inputs include zero and all singleton supports and therefore cannot fit in the hyperplane complementary to a constant-one hyperplane.

For a matching of $m$ edges, $\alpha=m$ and every maximum set has an independent complement. On the all-zero input this single actual load needs **$m$** dimensions to be discarded, even to become affine. By contrast, a flat on which the latest edge's two bits are both one costs at most two on a path selected by the adversary. Looking only at the true read address or at the number of distinct words ever written would miss this difference.

## The pointwise calculation for every monotone Boolean read

Let $f$ be coordinatewise nondecreasing and $x=1_S$ a zero input. Put $m=\max\{|I|:I\supseteq S,\ f(1_I)=0\}$. The largest dimension of a zero flat through $x$ is $m$. The largest dimension of a flat through $x$ with affine output is $m+1$ exactly when some maximizing $I$ has $f(1_{I^c})=1$. In all other cases it is $m$. Complementing all coordinates and the output gives the corresponding one-input theorem.

For a zero flat $x+U$ of dimension $t$, project $U$ onto $S$, with rank $r$. Choose $t-r$ pivot coordinates $J$ outside $S$ on the kernel of this projection. Some point of the flat has ones throughout $S\cup J$. Monotonicity gives $m\ge |S|+t-r\ge t$, and the full coordinate plane on a maximizing $I$ attains the bound. At equality $r=|S|$, $I=S\cup J$ maximizes, and projection onto $I$ is a bijection on this zero flat. If a nonconstant affine read has dimension $m+1$, its zero fiber through $x$ attains equality. In its opposite coset one can therefore set every coordinate of $I$ to zero. This point has value one, so monotonicity gives $f(1_{I^c})=1$. Conversely, adjoining $1_{I^c}$ to the coordinate space on such an $I$ gives a flat on which the output equals the added coordinate. This is a pointwise statement about a given read function. The audit also checks every monotone function through four variables.

## The difficulty of optimizing a certificate

Finding the optimum in this four-cell example already contains ordinary 3-SAT. For constant-zero preservation the decision threshold is exactly Independent Set. For the affine version append a disjoint triangle to $G$. Any maximum independent set of the enlarged graph uses one triangle vertex, leaving the opposite edge in its complement. The affine optimum at zero is exactly $\alpha(G)+2$. Even without adding the triangle, a certificate for affine dimension at least $k$ consists of an independent set of size at least $k$, or one of size $k-1$ with a complementary edge (take $k\ge1$). Both certificates can be checked directly.

For explicit fixed-width 3-CNF, take a variable edge per occurring variable, a triangle per clause, and join each literal occurrence to the variable choice that contradicts it. With $v$ variables and $c$ three-literal clauses the independent-set threshold is $v+c$. Hitting it selects one choice per variable and one compatible literal per clause, in both directions. The number of vertices and edges is linear in $v+c$. For many repeated clauses, deduplicate and renumber occurring names first in bit-linear time by binary radix passes on the input triples. With $w_0$-bit literal names there are at most $2^{O(w_0+1)}$ remaining triples, so the resulting identifiers have $O(w_0+1)$ bits and the graph list has linear encoded length. The trace description lists edge endpoints and a fixed store instruction template. The standard NP-completeness ingredients are classical. [Karp, *Reducibility Among Combinatorial Problems*](https://doi.org/10.1007/978-1-4684-2001-2_9)

Conversely, for a simple graph with explicitly listed vertices and a fixed-width edge list, use one Boolean selection bit per vertex, impose edge incompatibilities, and count selected vertices with a balanced binary tree of adders. At level $j$ the tree needs $O(j\lceil |V|/2^j\rceil)$ gates, for $O(|V|)$ gates in total. Test for count at least $k$, or for count at least $k-1$ and an edge with neither endpoint selected. This is exactly the affine threshold characterization above for $k\ge1$. The case $k=0$ is automatic. Gate equivalences give a width-three formula with $O(|V|+|E|)$ clauses. For simple graphs its encoded length is $O((|V|+|E|)\log(2+|V|))$, linear in a fixed-width representation listing each vertex and edge by name. The constant-zero version uses just the first count comparison. In these encodings the reductions in both directions preserve the bit length up to a constant factor and are computable in bit-linear RAM time. [Consequences with prescribed minimum spanning forests](fixed-spanning-forests-and-affine-reads.md)

One can always evaluate the concrete read just by executing the stores. The NP-complete quantity is the largest set of input directions that preserves or linearizes its value. The lower bounds on affine dimension count at most $D$ inputs' worth of independent binary constraints over a full run. The dense quadratic family itself has a correct template solver taking $O(N/\log N)$ word operations. These arguments leave the unrestricted SAT running-time targets open. Priority for the precise trace measure and graph characterization is unverified.
