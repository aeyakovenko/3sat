# Tight read-once sizes for the two DIMACS verdicts

Let $N$ be the encoded length in bits of a well-formed ASCII DIMACS 3-CNF file. The two verdicts have different complexities for nondeterministic programs that may query each input bit at most once on a path. The asymptotic bounds below hold at every sufficiently large byte-aligned length. Sizes count vertices; bounding all transition edges gives the same orders.

| Representation | SAT | UNSAT |
| --- | --- | --- |
| Nondeterministic ordered read-once branching program, with a choice of order | $2^{\Theta(N/\log N)}$ | $2^{\Theta(N)}$ |
| Nondeterministic syntactic read-once branching program, with adaptive order | $2^{\Theta(N/\log N)}$ | $2^{\Theta(N)}$ |
| Decomposable negation normal form (DNNF) | $2^{\Theta(N/\log N)}$ | $2^{\Theta(N)}$ |
| Deterministic free binary decision diagram (FBDD) | $2^{\Theta(N)}$ | $2^{\Theta(N)}$ |

Each representation must give the correct verdict on every well-formed input at that length. The same orders hold if every input is promised dense, proper and to have exactly three distinct variables per clause. The upper bound for positive SAT uses the *physical byte order*, even on files with very long, sparsely used numerical identifiers. The lower bounds allow a different order on each path. A full deterministic decision tree gives the common $2^{O(N)}$ upper bound.

## A small set of assignments readable in one pass

The number $v$ of distinct identifiers actually used as literals is at most $V=\lceil 8N/\lfloor\log_2 N\rfloor\rceil$ for all sufficiently large $N$, independently of the declared variable range. Half of $v$ distinct positive integer names have value at least $v/2$ and require $\Omega(\log(v+1))$ bits apiece for their first appearance. This yields the bound, separating $v<\sqrt N$ if necessary. The bits of an explicit assignment to names $1,\ldots,v$ would suffice on a dense file. A large sparse identifier can have $\Theta(N)$ digits. Remembering it literally while streaming could exceed the proposed size.

For each file there is a prime $p\le N^4$ that distinguishes its occurring numerical identifiers modulo $p$ for sufficiently large $N$. The product of the nonzero pairwise differences of these integers, taken in absolute value, has $O(Nv^2)=O(N^3)$ binary digits. Thus at most $O(N^3)$ distinct primes divide it. There are more primes than this up to $N^4$ by the prime number theorem. The empty product is one. The residues of decimal tokens can be accumulated left to right by $r\gets(10r+c)\bmod p$ for digit $c$.

Choose $k=\lceil V+4\log_2 N+2\rceil$ and work over $K=\mathbb F_{2^k}$. After reducing the occurring names modulo a separating prime, call their distinct residues $r_1,\ldots,r_v$. Some $b\in K$ has the property that $b^{r_1},\ldots,b^{r_v}$ are linearly independent over $\mathbb F_2$, with $b^0=1$. For any fixed nonempty subset, the polynomial $\sum_{i\in S}z^{r_i}$ is nonzero and has degree $<p$. The union of all its possible root sets across nonempty subsets has size $<(2^v-1)p<2^k$ for $v\ge1$ (and is empty when $v=0$). Independence then allows **any** desired truth assignment on the occurring names to be written as $a(b^{r_i})$ for one binary linear functional $a$ on $K$. This standard finite-field construction is related to explicit small-bias spaces. [Alon, Goldreich, Håstad and Peralta](https://doi.org/10.1002/rsa.3240030308)

At its root the ordered branching program guesses a prime, a $k$-bit field element $b$ and a $k$-bit functional $a$ in a fixed polynomial basis. It scans the bits in file order, maintaining the current residue, sign, a flag for the literal token zero, a clause-satisfaction bit and finite parser state. It skips comments and the header according to the syntax; validity is promised. The value $a(b^r)$ is hardwired into the transition for the end of a token. Within a fixed branch the position, partial byte and residue require only polynomially many states. Any branch that accepts describes a consistent assignment even when the guessed prime causes collisions. Conversely a separating prime and the interpolation above realize a satisfying assignment whenever one exists. Total size is at most $2^{2k}\operatorname{poly}(N)=2^{O(N/\log N)}$. Converting each query into a disjunction of its two literal-guarded successors and each guess into an OR gate gives a DNNF of the same order.

The memory bound is also attainable by a uniform one-pass nondeterministic streaming verifier given the public length. Guess a modulus $2\le p\le N^4$ and a monic degree-$k$ binary polynomial, then use residue arithmetic in both rings. No test of primality or irreducibility is necessary for soundness: every choice assigns a definite Boolean value to each numerical identifier. A prime and an irreducible polynomial exist for completeness. Evaluating a modular power by repeated squaring and reducing polynomial products takes $O(k+\log N)$ scratch bits. The seed and full working space total $O(N/\log N)$ bits. The procedure permits internal computation between input bits. The nonuniform branching-program count directly bounds size without charging this internal computation.

## The matching SAT lower bound

Use the bounded-degree bipartite expander on $2m$ vertices and $16m$ labeled edges from the [expander consistency calculation](linear-sat-control-for-word-travel.md). The function is one precisely when **every** edge satisfies $Z_e=X_u\mathbin{\mathrm{xor}}Y_v$. On uniform independent vertex bits and the resulting consistent edge bits, every positive rectangle across any one-third balanced partition of the $18m$ source bits has mass $2^{-\Omega(m)}$. Hence DNNF size is $2^{\Omega(m)}$ by the balanced-rectangle theorem. [Bova, Capelli, Mengel and Slivovsky](https://florent.capelli.me/publi/kc_meets_cc.pdf)

Give the second variable of each decimal pair described below the role of one source bit. On each edge put the four proper ternary clauses for the XOR relation on its two endpoints and its own edge bit. Force the first three auxiliary variables false by the seven proper clauses excluding their other settings.

Each source bit will change one ASCII low bit. Allocate an adjacent pair of decimal names ending in 0 and 1 for each coordinate, constrain their variables to be opposite using two fixed padded binary clauses, and give the second member of the pair the role of $x$ in all fixed XOR clauses. A unit clause padded with two public false names requires the variable named by the chosen member of the pair to be true. Its name ends in the single changing digit 0 or 1. With suffix 0 this sets $x=0$, and with suffix 1 it sets $x=1$. Lean checks that the selected unit and the complementary-pair clauses yield exactly one completion if the public predicate holds and none otherwise. [Lean lemma](../lean/ComplementaryNameProjection.lean) The unused numerical names up to the largest identifier can all be pinned false with one fixed padded clause each. This makes the file dense.

There are $O(m)$ variables and clauses and $O(\log m)$ bits per identifier, so the length is $O(m\log m)$. For sufficiently large target length choose a square $m=s^2$ of order $N/\log N$ with small enough constant so the file fits. Append public trailing whitespace to reach the required byte length. The formula has a unique satisfying assignment exactly on consistent tables. Fixing the public file bits and replacing each changing bit with the corresponding signed source literal preserves decomposability. It also preserves syntactic read-once access. Hence DNNF size on the SAT verdict is $2^{\Omega(N/\log N)}$, even under a promise of at most one solution. The upper bound for general SAT applies to this promise too.

## The UNSAT lower bound

The [linear-length matrix encoding](compact-bit-projection-of-matrix-mismatch.md) has opposite polarity: consistency $AB=C$ gives the UNSAT verdict, with one changing bit per matrix coordinate in a file of $\Theta(d^2)$ encoded bits. The fixed-distribution balanced-rectangle theorem gives $2^{\Omega(d^2)}$ DNNF size. It yields the exponential lower bound for UNSAT in the table. A deterministic read-once program can swap its verdicts without adding a query. This gives the exponential deterministic entry for SAT as well. [Uniform rectangle proof](product-rectangles-at-adaptive-cuts.md)

## How many accepting paths buy the smaller size?

For the SAT verdict in an **ordered** nondeterministic read-once program, let $W$ be its layered width and let $K\ge1$ bound the number of accepting paths on each well-formed file. Then
$$
 \binom{W+K}{K}\ \ge\ 2^{\rho d^2}-1
$$
on the compact matrix face of side $d$, with $d^2=\Theta(N)$ and $\rho=(3\sqrt3-5)/2$. A program that skips queries can be layered by storing its current vertex until the next relevant query in the prescribed order, with polynomial size overhead. Initial or intermediate nondeterministic choices can equivalently be incorporated into integer path counts at layer boundaries. Equivalently the counting argument can split paths at the first edge leaving the prefix, using at most the original number of edges as the dimension.

Indeed, cut the query order after $d^2$ private bits and fix all public bits to the template. The matrix $T$ of accepting path counts for left and right private inputs has rational rank at most $W$, by summing over cut states the product of prefix and suffix path counts. It has integer entries from 0 through $K$. Its support matrix is obtained entrywise by applying $q(z)=1-\prod_{j=1}^K(1-z/j)$. Write $T(x,y)$ as an inner product of $W$-component vectors. Expanding $q$ gives a sum of at most $\binom{W+K}{K}$ separated terms, indexed by monomials of degree at most $K$. On this face the support is the complement of $[AB=C]$. Its rank is at least $2^{\rho d^2}-1$ by the [permutation submatrix bound](balanced-cuts-of-the-binary-product-graph.md) and subadditivity of rank.

Hence ordered programs with at most one accepting computation per input take $2^{\Theta(N)}$ size for SAT. Every ordered program of size $2^{O(N/\log N)}$ deciding SAT has $\Omega(\log N)$ distinct accepting paths on some satisfiable file. For the latter conclusion use $\log_2\binom{W+K}{K}\le K\log_2(W+K)$; the assertion is immediate if $K>N$. The satisfying assignments of a formula and the accepting computations of a general branching program are separate quantities. The rank argument uses the latter.

The lower bound on positive SAT also follows at width two from prior work. Bova, Capelli, Mengel and Slivovsky proved exponential DNNF size for the vertex-cover predicate of a bounded-degree expander. Negating all its inputs gives the independent-set predicate. Use a fixed negative binary clause $(\neg x_u\lor\neg x_v)$ per graph edge. For each vertex use names $10i$ for a dummy and $10i+1$ for $x_i$, with the dummy forced true by a public unit. Supply the unit whose last digit is the input bit. Satisfiability says precisely that the selected vertices are independent. All clauses are Horn and use at most two literals. This gives the same positive lower exponent for Horn 2-CNF files via an existing theorem, including the cost of writing the decimal identifiers. The proper three-variable version above also controls the number of satisfying assignments. [Bova et al., *A Strongly Exponential Separation of DNNFs from CNF Formulas*, Theorem 4](https://arxiv.org/abs/1411.1995)

On the promise of at most one satisfying assignment over the **whole declared name range**, unambiguous one-pass SAT takes exactly $\Theta(N/\log N)$ bits, when unambiguity is required on promised files. Read the header and reject if it declares more than $V$ variables. Such a file has an unmentioned variable, so every model would have a distinct companion with the opposite value there. Under the promise it is unsatisfiable. Otherwise guess one value for each declared name in numerical order, exactly once, then check the clauses in file order. Validity guarantees that the numerical literal indices fit the table; leading zeros can be skipped. Each full solution yields exactly one accepting computation. The unique-model positive lower-bound projection above supplies the matching space bound.

A streaming consequence uses the fixed file order. On inputs to the UNSAT reduction, choose a physical prefix dividing the source bits between one third and two thirds. Each change of party in a $p$-pass, $s$-bit streaming verifier transmits its state and finite control. For each accepting transcript, the possible local nondeterministic choices factor into one existential condition per party. Thus each transcript is a positive rectangle, and there are at most $2^{O(p(s+1))}$ transcripts. This gives $p(s+1)=\Omega(N)$ for UNSAT; the positive SAT projection gives $\Omega(N/\log N)$ in the same way. Passes here are ordinary complete sequential scans with no auxiliary external storage. For one pass these are tight memory bounds, since buffering the entire file and brute-forcing its assignments uses $O(N)$ bits (one can give representative literal occurrences consistent truth values).

For an unambiguous nondeterministic streaming SAT verifier, $p(s+1)=\Omega(N)$ also holds on the positive verdict. Split the same physical order at a balanced threshold on the matrix encoding. For a fixed sequence of communicated states, the number of accepting computations factors into the number of compatible local histories on each side. Summing over the at most $2^{O(p(s+1))}$ transcripts gives a path-count matrix of at most that rank over $\mathbb Q$. Unambiguity makes it the true zero-one support matrix, whose rank is $2^{\Omega(N)}$. This establishes a sharp logarithmic difference between the optimal memory of arbitrary and unambiguous nondeterministic one-pass SAT verifiers on well-formed files.

The bounds measure nonuniform read-once representations of encoded files. The RAM can reread data and intermediate words. Priority for this combination of tight sizes in the DIMACS bit length has not been established.

For the matrix projection alone, the precise ordered width under a bound on the number of solutions follows from scalar product checks and a packed identity submatrix. [Read-once width under a promise](read-once-width-of-promised-matrix-products.md)
