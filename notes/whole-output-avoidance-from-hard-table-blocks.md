# A near-linear algorithm for finding a missing output under linear SAT

Assume one deterministic logarithmic-word RAM decides explicit 3-SAT in worst-case time $O(N)$ with unrestricted workspace. Fix rational $0<\epsilon<1$. For an $n$-bit index $x$, write $s=\lfloor n^{\epsilon^2}\rfloor$ and $m=\lfloor n^\epsilon\rfloor$. An eligible indexed family $C_x$ maps $s$ bits to $m$ bits and has one bit evaluator running in simultaneous polynomial time and $O(n^{\epsilon^2})$ space. The runtime degree can depend on the family. For **any** fixed, suitably constructible $f(n)=n^{o(1)}$ with $f(n)/(\log n)^c\to\infty$ for every fixed $c$, the SAT hypothesis gives a single deterministic RAM algorithm running in $O(nf(n))$ steps that **prints all $m$ bits** of an omitted output. For every eligible family, all sufficiently long $x$ have outputs outside its range. The threshold can depend on the family. For example $f(n)=2^{\lceil\log_2\log_2(n+4)\rceil^2}$ works. We assume an integer value or a constant-factor lower approximation to $f$ is computable in the advertised time. The preceding implication from Li–Tell's revised premise already gives a polynomial-time avoider. Here the algorithm searches for the address of a word in a public table. [Previous result and evaluator definitions](near-linear-sat-and-uniform-low-space-range-avoidance.md) · [Li and Tell, revision 1, Theorems 1.3 and 3.8](https://eccc.weizmann.ac.il/report/2026/233/revision/1/download/)

## Selecting a short address

Put $g=\max(1,\lfloor f^{1/8}\rfloor)$ and $B=ng$. At each length consider the first $p=\max(1,\lfloor\log_2 n\rfloor)$ binary RAM codes in length-lexicographic order. Simulate the bit computation on $(x,u,i)$ for $B$ guest steps, with a fixed zero result for malformed codes, invalid outputs or timeout. This interpreter takes $O(B\operatorname{polylog}n)$ host time uniformly in the code. Encode a guest word-width multiplier in unary in the code. Simulate its $O(\log\log n)$ host-word limbs by elementary Boolean and arithmetic instructions, with schoolbook multiplication and binary long division if needed. Keep sparse writable memory in a binary trie indexed by guest address bits. A load or store traverses $O(\log n\log\log n)$ nodes, and at most this many nodes are created in one insertion. Use native addresses for the polynomially many host nodes. Fetch instructions by a scan of the short finite code. Input-word lookups, including reading $x$ from packed storage, use the same polylogarithmic overhead. No universal RAM with an unbounded single-word operation is required.

For each fixed eligible family the low-space simulation of Nepomnjaščii gives a linear-time, fixed-alternation machine for its bit language. A fixed number of quantified blocks can be eliminated under literal linear SAT with one polylogarithmic factor in length and clock per block. Consequently there is a fixed native bit program for this family with clock $O_C(n(\log n)^{d_C})$. Its code and width multiplier eventually enter the census and every computation fits the guest cap. The proof uses a separate exponent $d_C$ for each family. [Checkpoint and encoded SAT reduction](near-linear-sat-and-uniform-low-space-range-avoidance.md) · [Uniform block elimination](linear-quantifiers.md)

Use the earlier output-linear hard-table theorem with one fixed word-RAM decoder. Given the dyadic length $M$, the conditional constructor prints a binary table $Y$ of $M$ bits in $O(M/\log M)$ word steps. For some fixed $c$, every exact bit decoder on the specified program has advice length plus worst-case lookup time at least $M/(\log M)^c$ for every sufficiently large dyadic $M$. Choose $M$ to be the first power of two at least $ng^3$. Split $Y$ into $b=\lfloor M/m\rfloor$ complete $m$-bit blocks and a tail of fewer than $m$ bits. This same candidate list is used for all $n$-bit indices. [Hard-table constructor, including its advice and computation bounds](output-linear-hard-tables.md)

Fix $x$. If every block were in the combined range of the census at $x$, give the decoder $x$, a code index and one $s$-bit seed per block, and the raw tail. Record $n,m,s,B$ and lengths in $O(\log M)$ header bits. On a request for a table position, compute its block and offset, fetch that block's code and seed, and use the universal bit interpreter. The one decoder is fixed before invoking the hard-table theorem. Its total advice and lookup cost is bounded by
$$
  O\big(n+(M/m)(s+\log(p+1))+m+B\operatorname{polylog}n+\log M\big).
$$
This is $o(M/(\log M)^c)$ for every fixed $c$. In particular, $s/m$ has a fixed polynomial saving, and $g$ dominates each fixed power of $\log n$. Random access to the preprocessed string permits selecting the indicated seed. Even physically copying that seed would cost $O(s)$ operations. Hence for each $x$ there is a block omitted by all census programs and seeds.

To find it, fix some high bits of a block address and test whether an extending legal address $j<b$ has the following property:
$$
  \forall(e,u)\quad \exists i<m\qquad Y[jm+i]\ne U_B(e,x,u,i).
$$
Code indices range over the census and seeds have length $s$. The outer existential choice of $j$ and the two displayed quantifiers form three blocks. With $x$ and the materialized $Y$ as public input, each final branch costs $O(M+B\operatorname{polylog}n)$ including input length. Constantly many near-linear SAT reductions give time $O(M\operatorname{polylog}n)$ for the test. Follow a feasible binary prefix of the address for $O(\log M)$ such calls, then copy the chosen block to packed output. The complete clock is $O(nf(n))$, including table generation, reading the public data, printing, and computing $f$. Use a fixed default for finite exceptional sizes or an empty address search. Every eligible family is eventually included on all indices simultaneously at that length for that family.

## An output far from every eligible range

There is also one deterministic $n\,2^{O((\log n)^{2/3})}$-time avoider whose whole output has agreement **at most** $1/2+2^{-\Omega((\log n)^{1/3})}$ with every range member of each fixed eligible family, at every sufficiently long index. Agreement is the fraction of the $m$ positions that match. The guarantee holds on each $x$ and each seed separately. It uses the earlier conditional hard table whose bit predictors have small agreement even with advice. [Average-case hard table at output speed](rare-approximate-output.md)

Here take $B=n2^{\lceil\log_2\log_2(n+4)\rceil^2}$ and dyadic $M=2^t$ between $n2^{K(\log_2 n)^{2/3}}$ and twice this quantity, rounding the exponent up by $O(1)$. The hard table for our fixed decoder has agreement at most $1/2+\beta$ for any advice and worst-case lookup time whose sum is at most $M2^{-Ct^{2/3}}$, where $\beta=2^{-\lfloor t^{1/3}\rfloor}$ and $C$ is a fixed constant. Fix $K>2C+2$. Let $\lambda=2^{-\lfloor t^{1/3}/2\rfloor}$. Call a block close if some combination of code and seed agrees with at least $1/2+\lambda$ of it. For every close block store a witness and use that prediction. For every other block store its better constant bit. Use an additional flag per block and store the tail literally. The previous advice and time bound with these flags still fits $M2^{-Ct^{2/3}}$. If a fraction $a$ of the $b$ complete blocks is close, the aggregate agreement is at least $1/2+(bm/M)a\lambda$. Hence $a\le 2\beta/\lambda$ for large $n$. Almost every address is a valid candidate simultaneously against the whole census. [Finite agreement bound](../lean/AvoidanceTableBlocks.lean)

Selecting a certified address must also fit the clock. For a fixed $(j,e,u)$ distinguish agreement at most $1/2+\lambda$ from agreement at least $1/2+2\lambda$. Let $v=\lceil\log_2 m\rceil$ and take $q=\lceil c_0\lambda^{-2}(\log_2(n+2))^2\rceil$ independent uniform $v$-bit samples for a sufficiently large constant $c_0$. A sample scores one if its index is below $m$ and the two bits agree there. Its mean equals $m2^{-v}$ times the true agreement. Accept the low-agreement case when the empirical mean is at most $m2^{-v}(1/2+3\lambda/2)$. The elementary Hoeffding bound gives error $\delta\le 2^{-\Omega((\log n)^2)}$ in each promised case. All cutoffs can be compared by integer arithmetic.

This randomized predicate has a deterministic constant-alternation version. Its coin string has length $l=qv$. Existentially choose $h=l+1$ shifts in $\{0,1\}^l$, and universally choose a coin string $z$. Require the sampler to accept at $z$ XOR at least one of the chosen shifts. In the low-agreement case some list of shifts covers the whole cube because $2^l\delta^h<1$. In the high-agreement case every such union covers fraction at most $h\delta<1$. These inequalities hold for large $n$, since $\log(qv)=O(t^{1/3}+\log\log n)$. [Lautemann's covering argument](https://doi.org/10.1016/0020-0190(83)90044-3)

Insert this test after the universal choice of code and seed. Searching for an extending block address now needs at most four blocks. The deterministic final check tries all shifts and pays $O(hqB\operatorname{polylog}n)$ for sampled bit comparisons, along with $O(hl\operatorname{polylog}n)$ for the shifts. These quantities are $o(M)$, so the total public-input and path cost is $O(M)$. An actual far block always satisfies the quantified predicate. Every satisfying block has agreement less than $1/2+2\lambda$ for every code and seed. The predicate can decide either way inside the promise gap, and binary prefix search uses this same fixed predicate throughout. Table generation, $O(\log M)$ SAT-based tests and printing take $M\operatorname{polylog}n=n2^{O((\log n)^{2/3})}$ time.

Thus a sufficient premise for **excluding deterministic linear SAT time** is that every RAM algorithm with clock $n2^{O((\log n)^{2/3})}$ producing $m$ bits admits one eligible family with a seed giving even $1/2+1/\log n$ agreement on some index at infinitely many lengths. The threshold $1/\log n$ can be reduced to any fixed reciprocal power of $\log n$. This is still a time-space simulation or prediction hypothesis without an unconditional proof. Finite exhaustion checked concatenated block witnesses, agreement counting and the covering comparison. Lean checks the finite witness and count lemmas. The SAT simulations, table constructions and running-time bounds are manuscript arguments. ## What can already be hit without a RAM time bound?

One fixed family ignoring $x$ can match **every** $m$-bit target on at least
$$
  1/2+(1-o(1))\sqrt{\frac{s\ln 2}{2m}}
$$
of its positions. This uses polynomial-time, polylogarithmic-workspace bit evaluation and exactly $s$ seed bits, including all private choices. The leading coefficient is best possible for covering every target at the same index. Indeed, a uniformly random target has probability at most $2^s e^{-2m\tau^2}$ of $1/2+\tau$ agreement with some string in any image of at most $2^s$ members. Taking $\tau=\sqrt{(s+1)\ln 2/(2m)}$ leaves at least half of all targets outside that threshold. This is a covering-radius calculation for unrestricted targets. [Classical covering bounds](https://doi.org/10.1109/18.59948)

Here is the matching uniform construction for the stated $s,m$. Put $r=\lfloor\log_2\log_2(n+4)\rfloor$ and $R=2^r$. Reserve $d=O(R(\log n)^2)=o(s)$ bits for independent seeds generating $R$ masks. Divide the $m$ positions into $b=\lfloor(s-d)/(r+1)\rfloor$ consecutive blocks with sizes differing by at most one. Each remaining record selects a mask and its sign on a block using $r+1$ bits. Unused seed bits are ignored. A mask is an $m$-bit output of Nisan's generator for space-bounded branching programs. Use seed length $O((\log n)^2)$ with sufficient constants for error at most $R^{-2}$ for length $m$, polynomial-width branching programs. The bit evaluator selects the indicated mask seed and expands it up to the specified position in polynomial time and polylogarithmic space. The masks need never be stored as expanded arrays. [Nisan, Sections 2–4](https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2013W/Nisan_PRG.pdf)

Fix an arbitrary target and one block of length $l$. Write its bits as signs. Against a truly uniform mask the signed correlation $Z$ is a sum of $l$ independent fair signs. Take $a=(1-r^{-1/4})\sqrt{2r\ln2}$. Then $R\Pr[Z\ge a\sqrt l]\to\infty$, uniformly over the block lengths. For a direct estimate, sum the exact binomial probabilities for the permitted parities between $a\sqrt l$ and $(a+1/\sqrt r)\sqrt l$. Stirling's bounds give each such term at least $c\,l^{-1/2}e^{-a^2/2}$ for an absolute $c>0$ at large $n$. Indeed the Gaussian exponent changes by $O(1)$ in this interval and the error $O(r^2/l)$ in the logarithmic approximation vanishes. There are $\Omega(\sqrt{l/r})$ terms, since $l$ grows polynomially in $n$. Thus the probability is at least $c' e^{-a^2/2}/\sqrt r$, which has the required property.

The same tail test for this fixed target and block is a nonuniform polynomial-width branching program reading a mask's bits and counting signed agreements. Nisan's guarantee changes its probability by at most $R^{-2}$. Independence of the $R$ short seeds makes the probability that every mask misses this tail $o(1)$. The best oriented mask then has expected correlation at least $(1-o(1))a\sqrt l$, including a nonnegative contribution whenever the tail is missed. Sum these expectations over the blocks. They may all use the **same** global list of masks. Some choice of that list attains the summed expectation, and each block can select its best signed mask independently. Since $b=(1-o(1))s/r$ and all block lengths equal $(1+o(1))m/b$, division by $2m$ gives the displayed gain in agreement. Finitely many small lengths may use a constant map. We have not established priority for this coding argument.

For fixed $\epsilon$, the unconditional gain just proved is of polynomially small order $n^{-(\epsilon-\epsilon^2)/2}$. The gain needed to contradict the fast avoider above is larger. Bridging the two requires using the computational restriction on the algorithm that produced the target. The counting upper bound applies even if a single indexed family can choose different images at different $x$ and arbitrary target strings can be chosen separately there.

## Combining an unread word with the advice budget

Let the index have $L=\lfloor n/w\rfloor$ aligned complete words of width $w=\lceil\log_2(n+1)\rceil$ and one possible partial tail. Specify a constructible $t=t(n)\le L$. At lengths with $a=s+tw$, $a\gg(\log n)^3$, and $m/a\gg\log\log n$, the leading bias for the following probe game is
$$
                 (1+o(1))\sqrt{\frac{(s+tw)\ln2}{2m}} .
$$
For the constructive direction take $t$ computable in polynomial time and $O(\operatorname{polylog}n)$ space. Take the first $t$ Vandermonde moments of all $L$ complete index words over $\mathrm{GF}(2^w)$. Concatenate their $tw$ coefficient bits with the $s$ seed bits, and use this as the $a$-bit seed of the covering construction. Its proof above needs each block length $l\gg r^2$, which follows from $l\sim mr/a$ under the assumed ratio. The number of global mask bits is still $o(a)$. The resulting bit evaluator need not store any full moment array. It computes a requested bit of a virtual moment by a fresh scan of $x$ and field arithmetic in polynomial time and polylogarithmic space, then resumes the covering decoder. Recomputing at every virtual seed access increases the polynomial time exponent by a constant. [Vandermonde family and its uniform field algorithm](unread-words-in-a-range-avoidance-index.md)

Fix any execution of a deterministic $m$-bit output algorithm leaving at least $t$ complete input words unread. Altering those unread words preserves that run and output. Any chosen $t$ free columns of the moment matrix form an invertible Vandermonde matrix. Hence the completions, together with the external seed, realize every $a$-bit covering description. Some actual completion and seed therefore give at least the displayed leading agreement gain. The indexed evaluator is fixed across lengths and across algorithms for this prescribed budget.

Conversely, fix an arbitrary indexed evaluator and a set of $L-t$ whole word addresses to inspect, also reading the tail. For any given values at the inspected positions at most $2^{s+tw}$ output strings occur over all completions and all seeds. The same binomial union bound yields a single output with gain at most $\sqrt{(s+tw+1)\ln2/(2m)}$ against all these strings. Choosing such an output after each possible observation attains the upper bound with $t$ words unread. This last minimax statement allows unlimited computational work at each length. These bounds price probes, and a complete packed scan still takes $O(n/\log n)$ ordinary word steps.

For example, an algorithm that eventually has agreement at most $1/2+2^{-c(\log_2 n)^{1/3}}$ against every eligible family on every index must leave fewer than $\lceil m\,2^{-c'(\log_2 n)^{1/3}}/w\rceil$ entire words unread on **every** sufficiently long input, for any fixed rational $0<c'<2c$. Choose an integer-rounded computable approximation for this $t$ within a constant factor. Its attainable bias scales as $2^{-(c'/2)(\log_2 n)^{1/3}}$. Finite constant factors in the word threshold can be absorbed by a strictly intermediate $c''$ with $c'<c''<2c$. The explicit conditional avoider above meets this near-complete inspection requirement.
