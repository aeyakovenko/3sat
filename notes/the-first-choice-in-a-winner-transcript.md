# Can a guessed future certify which rule makes fewer mistakes?

The [one-bit advice construction](adaptive-naming-of-winner-pairs.md) leaves a question about computation. Given the genuine history before a phase, can a nondeterministic verifier guess the rest, check the positive witnesses for the proposed winners, and certify which of two rules makes fewer errors? There is a positive answer under an agreement promise. A single extra possible first choice can invalidate the certificate. On actual scheduled runs the same first choice can defeat the verifier testing it, even when the genuinely better rule makes zero errors and the other loses every block.

## Which continuations have an ordinary SAT certificate?

Use the sparse ordinary-program allocation in the [two-date construction](adaptive-naming-of-winner-pairs.md#a-contiguous-run-of-mistakes-on-actual-dates). A *clean* phase has no interfering lower ordinary retirement in its public window. Start at the first normal date $K$ after the control programs have retired, with the authentic earlier history. On a clean matching run a complete search picks the lexicographically earliest accepted ordered pair of live pool ranks. Its two ranks win with zero on the next two dates, starting at $K$; the next normal date is $K+2$. If no row accepts, the tag wins immediately. For a nondeterministic row test, a matching run uses a correct proposed SAT solver within its cap to decide the existence of the row witness. A deterministic row test can be dispatched directly. Only these promised source runs are used below.

Write $e$ for the tag rank, $N$ for the number of live lower ranks at the starting checkpoint and $\ell=\lceil e/2\rceil$. Consider controllers that always accept at least one row while this count is at least $\ell$, and then stop. Starting with $N\ge\ell$, there are exactly
$$m=\left\lfloor(N-\ell)/2\right\rfloor+1$$
two-date blocks, since each retires two ranks. The two public rules always use different first ranks and the same second rank. At the following date neither rule can start with that second rank, so when one of the rules' pairs wins, neither can also make an error on the overlapping start. Ties in the final number of errors are broken toward rule zero.

A proposed continuation consists of $m$ named pairs and an accepting witness for each pair on its own proposed prefix. On each step verify that the pair is live, check the witness, and append the two corresponding zero awards to the proposed history. Replay the fixed phase bookkeeping, including response dates, before checking the next witness. If the public interface also records the earlier ranks and output words, these are determined by the two awards. The initial history is supplied once. A guessed path is *feasible* if these tests all pass, even when a smaller competing pair could have won.

Whenever the actual greedy path has the promised full length, it is the lexicographically least feasible full path. Its rows have witnesses. At the first difference of two feasible paths, the actual row was chosen from the very same prefix and was the least accepted row. Existence of a full feasible path alone does not ensure the greedy path has full length: the least initial choice could lead to an early stop. The always-open guard above avoids this problem.

Let $T$ bound one branch of the row predicate over this suffix, including initialization on a proposed prefix. Here $m=O(e)$, $e=O(\log K)$, and the current date is at most $K+2m$. The history representation uses polynomially many bits in $K$. Thus a fixed nondeterministic RAM can check a whole feasible path and compute its two final error counts in $T\operatorname{poly}(K)$ time for $\log(T+2)=O(K)$. If the bound for date $i$ is $2^{\tau i}\operatorname{poly}(i)$, replacing $i$ by $K+2m$ costs only another polynomial factor. The ordinary RAM-to-3-CNF compiler gives two explicit formulas of $T\operatorname{poly}(K)$ **encoded bits**, one for existence of a feasible full path favoring each rule. The reduction charges witness lengths, word width, bounded memory consistency, resetting the row simulation and printing literal addresses. [Packed RAM reduction and input convention](packed-band-transfer.md)

If **all feasible full paths agree on the better rule**, exactly one formula is satisfiable and it gives the actual bit. A single accepted name at each reachable state suffices, even with arbitrarily many witnesses for that name. A further sufficient condition, using a different verifier, is a cheaply available *exact count* of accepted names at every actual state. Guess that many distinct names and one witness per name, then choose the least among them. The supplied count makes the list complete. Induction recovers the actual trajectory with at most $e(e-1)$ names per step. The count's accuracy is a promise unless there is a separate verification of it. Both tests charge all row work. Solving the formulas under an $O(n^k)$ SAT hypothesis costs $T^k\operatorname{poly}(K)$, and nothing here supplies the authentic initial history on an arbitrary input.

With total feasible paths but no agreement promise, the exact bit compares the lexicographically least feasible path in each of the two output classes, using a sentinel for an empty class. This is the familiar distinction between feasibility and lexicographic optimization. The next construction shows it already matters with just one possible branching point. [Krentel on optimization problems](https://www.sciencedirect.com/science/article/pii/0022000088900396)

## One optional row is enough

At the first normal opportunity the pair of rule zero is ordered before the pair of rule one. Accept the zero pair when a bounded predicate has an accepting witness. Always accept the one pair as a fallback. On every subsequent guarded normal opportunity accept just the pair of the rule chosen at the first. Recover that initial choice from the first actual award and the original prefix. Stop offering when the guard expires. This is a total controller on all guarded feasible paths. The only possible disagreement about the choice of a pair is at the very first opportunity.

If the first predicate accepts, the actual error counts are $(m,0)$. If it rejects, they are $(0,m)$. All earlier control awards incur zero errors for these two rules. No extra errors occur on the response dates, and neither rule errs at the tag win. Thus the lower-error rule is uniquely zero **if and only if the optional row has no witness**. A path predicting that zero is better always has positive witnesses: take the fallback and keep following it. When the optional row accepts, the same path remains feasible but gives the wrong advice by the maximum possible margin.

In an explicit-input version the optional predicate simply checks a satisfying assignment of an arbitrary supplied ordinary 3-CNF $F$. All the other rows use deterministic public operations. The better-rule-zero decision is then exactly $\operatorname{UNSAT}(F)$. In particular a uniform polynomial-time existential test sound on both kinds of these inputs and complete on the unique-path inputs would put coNP in NP. This statement makes $F$ an input to the experiment. The actual bin family below has no independently variable $F$ field.

## A failure on the authentic computations

Fix a nondeterministic checker $B$ claiming that the lower-error rule is zero at checkpoint $K$. Give it the actual prefix, the descriptor of the dispatch, the public values $e,K,m$ and the single-first-choice template. It may abstain. Fix $k\in\{1,2,3\}$ and a branch cap $2^{(1/k-\epsilon)K}$ for some $0<\epsilon<1/k$. Assume ordinary explicit SAT is in deterministic $O(n^k)$ time on the specified unrestricted RAM. Put the bounded acceptance predicate of $B$ on this very checkpoint into the optional first row. Later normal rows follow the publicly recorded first choice. This is one fixed row verifier for $B$ with the usual clock and rank guards. It reads its enclosing bin's descriptor as input data; building the bounded row formula does not execute $B$.

There are infinitely many clean matching bins for this verifier, its correct proposed solver and an appropriate fixed cap. The sparse raw slots ensure that among the first $S$ bins only $O(\sqrt S)$ contain a lower raw retirement during the disjoint public phases, while each fixed descriptor occurs in a positive fraction. Control clearance and the phase transition then give the actual two winners for each selected pair. The test of the first row can be compiled and solved in $2^{(1-k\epsilon)K}\operatorname{poly}(K)$ time on each fixed match. Simulating the other candidate and response tests, enumerating the polynomially many live pairs, and the fixed program and width overhead still fit the native budget for sufficiently late matches. The search may repeat its row test on the response; all substantive existential decisions in this example concern the same first-row question. On rows before clearance the template can idle while controls supply the awards. On other bins it can use the ordinary bounded defaults. [Dispatch, common search and cutoffs](density-of-certified-winner-pairs.md)

On every sufficiently late clean match there is an exact equivalence
$$
  \text{the true lower-error rule is zero}
  \quad\Longleftrightarrow\quad
  B\text{ has no timely accepting branch on this checkpoint}.
$$
In particular, if $B$ is sound on all sufficiently late clean runs of these single-first-choice templates, it must abstain on *every sufficiently late clean match of its own template*. Every such missed input has exactly one feasible full path, rule zero has zero mistakes, and rule one makes $m$. Conversely, a checker giving that one sign on every sufficiently late clean unique-path positive and remaining sound even when the optional row also accepts would exclude the hypothesized $O(n^k)$ solver. For deterministic $B$ of time $2^{(1-\epsilon)K}$, dispatch the first row directly and the diagonal statement is unconditional.

The promised feasible-path certificates from the first section do cover every unique-path positive. They lose soundness on the two-path case. Guessing the fallback falsely names rule zero on precisely those cases. Watching later dates can reveal which first pair was actually chosen, but the advice in this theorem is requested **before** that award. Predictions requested later have their own [sharp observation bound](choosing-an-expert-after-observations.md). The result isolates one missing negative row certificate at the original clock. It does not construct that certificate, and the unrestricted linear, quadratic and cubic SAT lower bounds remain open. Priority for this specialized formulation has not been established.
