# The smallest certificate left after erasing DIMACS bits

Fix an ASCII DIMACS file and a public list of bit positions. Leaving these bits free and fixing every other bit gives a cube of files. Every point of the cubes below is a valid proper 3-CNF. Call the point where all editable bits are zero the *anchor*. Its certificate size is the least number of editable positions whose anchor values force the anchor's SAT verdict throughout the remaining cube. Completions may use different satisfying assignments.

* At a positive anchor, deciding whether the certificate size is at most $r$ is $\Sigma_3^{\mathsf P}$-complete. Hardness holds with a known unique model of the anchor.
* At a negative anchor the decision is $\Sigma_2^{\mathsf P}$-complete, even when every completion has at most one model and a single globally correct SAT program decides all those completions in linear time.
* In both reductions the optimum is exactly $r$ or $r+1$. On **every file in the cube**, every correct unrestricted deterministic RAM has to touch **every marked digit**. For each digit, one legal single-bit change forces UNSAT and a different legal single-bit change forces unique SAT. These edits are in the same digit as the on-cube editable bit. Thus the number of marked digits that a solver must touch can exceed the smallest on-cube certificate by an arbitrarily large factor even on one prescribed, easily decided anchor.

Minimum sufficient reasons have an established complexity theory. Barceló, Monet, Pérez and Subercaseaux prove $\Sigma_2^{\mathsf P}$-completeness for multilayer perceptrons. Implicants of existentially projected formulas are used in projected model enumeration. The construction here supplies proper DIMACS faces, the one-unit gap, both single-bit escape edits at each coordinate and a clock on the actual inputs. Priority for the certificates as a whole is unestablished. [Barceló et al., Proposition 6](https://proceedings.nips.cc/paper_files/paper/2020/file/b1adda14824f50ef24ff1c05bb66faf3-Paper.pdf) · [Möhle, Sebastiani and Biere, short projected models](https://doi.org/10.1016/j.dam.2024.10.021)

## Exact size at a given verdict

The membership tests use the usual polynomial-length witnesses. For positive certificates choose the retained positions, universally complete the other bits, then existentially choose a satisfying assignment to the resulting file. For negative certificates choose the positions and universally test all completions and all assignments of the file. A polynomial-time test can check an assignment on the occurring names even if the DIMACS header is large. The hardness constructions use dense names bounded by a polynomial.

Start with the true-or-false question $\exists u\,\forall v\,\exists w\,\phi(u,v,w)$ for an explicitly given Boolean circuit and $r=|u|\ge1$. Provide two data bits $a_i,b_i$ per $u_i$, all the $v$ bits, and as many additional independent data bits as desired. The anchor sets them all to zero. Let $B$ mean that some pair is $11$ and $H$ that every pair has at least one 1. The unquantified witness check for the positive reduction is
$$
 \neg B\ \land\bigl[(\neg H\land w=0)\lor(H\land\phi(b,v,w))\bigr].
$$
The all-zero anchor has the unique witness $w=0$. A certificate must retain at least one coordinate from each pair: otherwise the two free bits of the missed pair can both be set to one, forcing rejection independently of all other coordinates. A budget of $r$ therefore retains exactly one per pair and no other bit. When $H$ holds, the retained positions then prescribe a unique $b=u$. The free bits of the pairs can realize that $u$ simultaneously at every $v$. Incomplete pairs cause no further obligation because $w=0$ works whenever $B,H$ are both false. Thus these $r$ pins certify the positive verdict exactly when the induced $u$ wins the quantified game. In fact the budget-$r$ certificates correspond bijectively to winning first moves.

Even on a losing quantified instance, retaining one side of every pair and also the other side of the first pair suffices: $B$ and $H$ are then both always false. This proves the promise $r$ versus $r+1$.

For the negative construction take $\exists u\,\forall v\,\phi(u,v)$, with a deterministic circuit matrix. Require the file to be satisfiable exactly when
$$
                        B\ \lor\ (H\land\neg\phi(b,v)).
$$
The anchor is unsatisfiable. A budget-$r$ certificate for rejection again hits all pairs, and full pairs again leave exactly the universal test on $v$. One extra pin always works. There are no private source bits in this construction, so deterministic gate definitions will give at most one model on every completion. Both hardness proofs use standard quantified-circuit completeness. [Stockmeyer, 1976](https://research.ibm.com/publications/the-polynomial-time-hierarchy)

## Realizing a bit at a single position in a proper file

The following implementation works for any explicit Boolean witness circuit on public $x$ and private $w$. Reserve variables 1, 2 and 3 and use seven proper clauses to pin their common valuation to $000$. In data record $j\ge1$, reserve six state names $10j+e$ for $e\in\{0,1,2,3,6,7\}$. Fifteen binary clauses enforce that at most one of the six states is true, one clause forbidding each pair of simultaneous ones. The record contains one positive literal on the selected state name and the two pinned false literals 1 and 2. Hence exactly the selected state is true.

The normal record writes the decimal name $10j+2+x_j$, so only the low bit of its final ASCII digit varies. Decode $x_j$ as the disjunction of the three odd states. A record with a final digit 0 or 1 raises a rejection flag, while 6 or 7 raises an acceptance flag. Require no rejection flag anywhere. If an acceptance flag is present require $w=0$; otherwise use the original witness circuit. All other wires are deterministic. On a completely normal file the extensions are in bijection with its eligible witnesses. Changing just one normal digit by ASCII XOR 2 produces a legal rejecting file. Changing it by ASCII XOR 4 produces a legal file with exactly one model. The decoded data bit stays the same in both changes.

Use equivalences for fan-in-two circuit gates in topological order. Simplify constant or repeated operands. Use distinct pinned false variables to pad short clauses. Fresh gate names start above all reserved names. Pin unused identifiers up to the maximum to false so the model counts apply even to all declared variables. The header, literal spacings and all fixed clauses are independent of the public $x$. An optional fixed DIMACS comment gives the source witness names to try at zero. Its correctness need not be trusted.

With $S$ source circuit gates and input ports in total, including padding ports, the output has $O(S)$ variables and clauses and $O(S\log(S+2))$ bits. A bounded-fan-in circuit representation that explicitly allocates $\Theta(\log(S+2))$ bits per gate record and per port has this same order of length, and the construction runs in linear time and length from that representation. Space the final data digits by a sufficiently large constant times $\log(S+2)$ bytes. In the specified logarithmic-word model this makes every input-word interval meet at most one marked digit for all large $S$, while preserving the output-length estimate.

## An exact change from bit certificates to word certificates

Now free **three physical bits per digit**. In addition to the original data bit $x_j$, let $R_j$ toggle the ASCII digit by XOR 2 and $A_j$ toggle it by XOR 4, with all flags zero at the anchor. Every possible digit from 0 through 7 yields a legal proper file. If both flags are one, the digit is 4 or 5, selecting an unused state name pinned to false. Hence on the entire $3p$-bit cube, with $p$ marked digits, any rejection flag forces UNSAT. In their absence any acceptance flag forces unique SAT. With all flags zero one gets the original family.

Write $\kappa$ for the original certificate optimum. **The exact bit certificate size on the enlarged cube is $p+\kappa$, and the exact whole-digit certificate size is $p$.** For positive anchors each rejection flag must be retained at zero, since raising it alone forces rejection. Negative anchors require all acceptance flags at zero by the opposite edit. Restricting all flags to zero leaves a certificate for the original data, so at least $\kappa$ further bits are needed. Conversely, retaining the compulsory flags and an original optimal certificate suffices. On a positive anchor, any still-free acceptance flag that rises only helps. A raised rejection flag on a negative anchor only helps its certificate. For digit certificates a missed digit allows both single-bit overrides, whereas reading all $p$ digits fixes the entire input within the enlarged cube.

The same $p$ is the exact minimum number of marked **input words** in an anchor certificate if each complete digit lies inside a different input word. Such alignment is possible even when word width is not a multiple of eight. Choose the final bit length to be a sufficiently large power of two of order $S\log(S+2)$, so the standard width at that length is known. Insert spaces before each marker until its byte lies wholly inside a fresh word. A tail of ordinary whitespace fills the chosen length. This costs $O(\log(S+2))$ padding bytes per marker and leaves the file size bound intact. All bits outside the marker digits remain fixed in the experiment. Thus changing the query unit on the very same files hides the entire hierarchy-hard residual in the compulsory word reads.

## What a single unrestricted run must do

Fix any normal file, any one of its marked digits and any globally correct deterministic SAT solver. Select the one-bit edit at that digit with the opposite verdict. Until the run reads information from the changed input bit, both computations have identical data. If the run on the normal file finished without having accessed that part of the input, the two computed verdicts would coincide. This works separately for every digit on the very same fixed run. It also applies to machines that overwrite input: an original difference overwritten before being observed cannot affect subsequent execution. With the spacing above, the solver must execute at least one input-word access for each digit, up to the fixed number of memory accesses a single instruction permits. A solver can see all of them in a scan.

Adding $d$ dummy public coordinates preserves the certificate optimum and makes $2r+|v|+d$ digits individually compulsory. For fixed $r$ this gives unbounded divergence between the actual number of required accesses and the optimum within the erased-bit cube. The two types of marker changes have different quantifiers: the certificate has to survive completions **in the cube**, while a total SAT algorithm must also handle the legal files immediately **outside** that cube. The single-digit alternatives continue to work on all other normal completions, not only at the anchor.

For the negative construction there is a globally correct $O(N)$ fast path on all its normal files of encoded length $N$. Recognize the seven pin clauses, propagate those sound values, and use ordinary unit propagation through the other clauses. Each selected state is forced, the other five states are forced false, and each gate is determined once its predecessors are available. Contradiction certifies UNSAT; a satisfying assignment can be checked directly. For the positive anchor a second propagation pass can try zero on the names listed in the comment, which supplies $w=0$ and determines all gate values. Use a complete SAT solver whenever neither sound test gives a verdict. Dense integer ranges and linear total identifier length allow the tested families to be parsed in $O(N)$ RAM time. Only verified contradictions of the original formula justify rejection. A contradiction after trying guessed values just abandons that guess. ## Preserving the three unrestricted SAT deadlines

There is a family carrying the **full SAT decision problem** on which every normal input forces $\Omega(N/\log N)$ marked-word accesses, yet one globally correct program can finish in $O(1)$ instructions after its last previously unseen input word. No upper bound on its earlier computation is assumed.

From any $n$-bit proper 3-SAT source $F$, retain a copy of the original file as hexadecimal ASCII in a DIMACS comment. Intern the occurring identifiers and deduplicate proper clauses. If $s$ is the number of distinct names plus distinct clauses, then $s\log(s+2)=O(n+1)$. For the names and for the clauses separately, the original file spells at least that many distinct strings over a fixed alphabet, so their total writing cost gives this bound. Constant-alphabet tries give linear work, including consistent treatment of different spellings of the same decimal name. Form a bounded-fan-in circuit with $O(s+1)$ gates checking an assignment to $F$. Give it $p=\max(1,\lfloor n/\log_2(n+2)\rfloor)$ additional public data bits ignored by this witness check. Apply the preceding two-override construction, with a witness-zero test on the acceptance override, and separate the $p$ digit words. The conventions for $p$ can equivalently use a rounded integer logarithm. The size before serialization is $S=O(s+p+1)$, hence $S\log(S+2)=O(n+1)$. The comment and the digit spacing give a final length $N=\Theta(n+1)$. Trying the all-normal settings gives the source SAT answer. The reductions use linear deterministic time and encoded length: in the reverse direction read the stored source and flags and emit $F$ or a fixed formula of the forced verdict on this promise family. Thus linear, quadratic and cubic decision bounds transfer at the same exponents. Here the promise permits the exceptional digits as well as the normal ones. The lower bound on distinct accesses already holds throughout the all-normal subfamily, for both source verdicts whenever they occur.

For the promised last-word clock, a globally correct program extracts the source comment before consulting any marked word. It recompiles the expected static layout from the source and computes the expected marked word addresses and editable digit positions. Before solving the source, verify every nonmarker word against the layout and read every such input word, including padding. The source comment and its delimiters lie entirely in these words on properly generated inputs. The recognizer caps its parsing and checks lengths before assuming a given layout. Compute $\mathrm{SAT}(F)$ by any fixed correct solver on a private copy. Now scan the marked words once, checking all their static bits and decimal digits against the known layout, accumulating the two override flags. A valid normal file then needs just the last constant-size update, the branch on the flags and the return after the last word. Fixed word masks, loop limits and the source decision are already available. Any failed syntactic check can invoke an ordinary complete solver on the original input. This program has total time $O(N+T(n))$ on the family if the source solver has clock $T$. It is correct at arbitrary finite source running time as well. If the global target is excluded, the running time beyond the scan is spent on the source computation before the mandatory digit scan. Prior last-discovery bounds in the journal use packets which can disclose a query on the preceding data. [Late queries and the unconditional promise required to force old-word reads](work-after-the-last-unseen-sat-word.md)

Thus even an exact solution of the on-cube minimization problem cannot by itself undo the distinction between necessary input reads and native work after those reads. The goal would require a lower bound on that additional work, or a different family on which necessary operations already exceed a full scan.
