# Exponentially many opposite SAT pairs after one common prefix

Fix an exact deterministic aligned word-RAM SAT decider. The shared-database construction has $s$ balanced rows of $B$ bits and $Q$ independently encoded queries, where $1\le Q\le B/2$ is a power of two. Its physical length is $N=\Theta(sB)$ bits and its native word width is $w=\Theta(\log N)$. Write $m=sQ$. There is a subfamily indexed by $m$ database bits $x$ and $m$ query bits $y$. On it the left tag is unsatisfiable exactly when $x_L=y_L$ and the right tag is unsatisfiable exactly when $x_R=y_R$. Each half has $m/2$ bits. The two tags differ in one physical bit. The unsatisfiable case means every selected entry in that half is good. In particular the all-good matrix is the $2^m$-square identity. [Shared database, actual DIMACS and powered-walk construction](batched-powered-walks-on-one-sat-database.md)

**For every fixed $0<\delta<1/2$, at every sufficiently large construction size, a fraction at least $1-2^{-\Omega_\delta(m)}$ of the databases have at least $2^{(1/2-\delta)m}$ different opposite one-bit pairs on which both suffixes require $\Omega_\delta(m/w^2)$ charged native instructions.** The quantifier is for each fixed program. Every pair for one $x$ shares the same actual prefix, ending when the tag word is requested. Each hard query in this bound can have $y_L=x_L$. The roles of the halves can also be exchanged, and discarding the union of two exponentially small exceptional fractions gives both directions at once. A charge is a nonlinear old-data operation, a branch on unresolved old data or an unresolved effective address. The query, its physical seed placement, and arbitrary binary-affine processing of the old state are free in this first theorem. Prefix time and workspace are unrestricted. For $Q=B/2$ the count is $\Omega_\delta(N/\log^2 N)$ per continuation; for $Q=1$ the unread fraction of the packet array tends to zero.

Here a single cut at the full $s$-row size suffices. We use an adaptive physical placement: the first requests for new packet words get the database packets in logical order. The next new request is for the tag, and the remaining slots get the query packets in a fixed order. A correct program must make that request, since the same database admits opposite completions. For each $x$ this realizes immutable files and a controller independent of $y$. There are $p=sB/h$ database packets and $R=1+Qs/d$ other packets for $h,d=\Theta(\log N)$. Encoding the pending subset, its tag slot and the bounded controller costs $O(R\log(2+B/Q)+\log N)=o(m)$ bits. The arbitrary order of the installed database packets is captured by their **values at physical positions**. The compact header only needs to locate the tag and pending seeds. Thus the number $J$ of headers is $2^{o(m)}$. [Earlier physical placement proof and charge convention](nonlinear-work-after-the-one-bit-sat-cut.md)

## One decoder whose false positives are hard counterparts

For a fixed query, run the two continuations up to a cutoff of $q$ charged instructions each. A machine halting after exactly $q$ charges is included. If either reports a miss, output zero. Otherwise, if the left simulation reports no miss, output the raw equality bit $[x_R=y_R]$. If the right alone reports no miss, output $[x_L=y_L]$. If both time out, output $[x_L=y_L]$. Even if both report no miss, use the indicated raw half check. These final comparisons are part of the mathematical decoder and need no extra simulated RAM runs.

Let $C_{xy}$ be this output. It is one on every diagonal. With genuine memory it agrees with equality except possibly when both time out. Every off-diagonal one then has $x_L=y_L$ and $x_R\ne y_R$; the actual tags have opposite verdicts and both suffixes exceed $q$. Changing the both-timeout fallback to the right raw check reverses the orientation.

For each header and query, the indicators choosing the final left and right tests are computed by affine decision trees of depth $a=O(w(q+1))$ on the old features. Each tree has a polynomial over $\mathbb F_2$ in the squarefree monomials of degree up to $a$. Set $D(U,a)=\sum_{i\le\min(U,a)}\binom Ui$ for $U$ bits. The raw left equality columns lie in the span of just $2^{m/2}$ functions of $x$ (one indicator for each possible left half), and the same holds for the right. Multiplying two columns pointwise puts their product in the span of products of their basis functions. Multiplying by a fixed header-consistency mask preserves this dimension bound. Hence
$$
 \operatorname{rank}_{\mathbb F_2} C \le 2^{m/2+1} J D(U,a).
$$
For unrestricted old memory take all $2^w$ native words, the installed physical input and the controller as features, so $\log(U+1)=O(w)$. Take $q=\lfloor\eta m/w^2\rfloor$. The coarse bound $D(U,a)\le(U+1)^a$ gives $\operatorname{rank} C\le2^{(1/2+\delta/3)m}$ for a sufficiently small fixed $\eta=\eta(\delta)>0$. The same proof applies to the earlier standalone semantic affine convention when full old memory is represented. [Lean squarefree rank and type-dependent product bases](../lean/AffineCutRank.lean)

For any matrix with nonzero diagonal and rank $r$, the number of rows with at most $h_0$ nonzero off-diagonal entries is at most $r(h_0+1)$. Restrict to those rows and the corresponding columns. A basis chosen from its rows has at most $r$ members. Each covers at most $h_0+1$ coordinates; their union must cover every column because the diagonal is nonzero. With $h_0$ the integer part of $2^{(1/2-\delta)m}$, the exceptional fraction is exponentially small. This proves the claimed count for actual files. Distinct $y$ at a fixed $x$ change an actual decoded walk in at least one labeled segment packet and thus give distinct physical pairs. [Lean support bound](../lean/QueriedCutMemory.lean)

## Interpolating the addresses a real suffix can read

There is a sharper alternative that measures actual reads, even when different databases write to entirely different addresses. In this section use the native, operand-based charge convention. Keep symbolic registers and the suffix write overlay. A fixed-address load or store, copying, and an affine transformation of the actual operands at transcript-known addresses are free. A charged instruction resolves its boundedly many actual word operands, effective addresses or branch data. Affineness and the charged cutoff can be determined in the original formal old-word variables, substituting previously resolved operands as in the original syntactic simulator. A free instruction must be implemented by the native program; an analysis that declares an arbitrary nonlinear native result free by equating it to a never-read auxiliary old cell would require that cell in the interpolation set as well.

Let $M_0$ be a budget of native work addresses. For each database $x$, let $S$ be **any** set of at most $M_0$ addresses containing the addresses of inherited work words read on the two diagonal continuations $y=x$ before their cutoffs. An inherited read is a read before any suffix write to that address. Including the entire diagonal runs also suffices. Sets need not be computable, geometrically localized, or shared with any other database. For the bounds below cap the useful budget at the native range $2^w$ and set
$$
 L=\log_2\!\left(2+\frac{N+wM_0}{m}\right),\qquad
 q=\left\lfloor\frac{\eta m}{w L}\right\rfloor .
$$
For all but a $2^{-\Omega_\delta(m)}$ fraction of the databases, **for every such $S$** there are at least $2^{(1/2-\delta)m}$ distinct opposite one-bit pairs satisfying at least one of these conclusions:

* Both actual continuations exceed $q$ charged steps.
* Before halting or exceeding its cutoff, at least one actual continuation makes an inherited read outside $S$ whose true word differs from the polynomial completion below.

If both simulated tags stay faithful, the first alternative is the only source of a false positive. In the second alternative either orientation of the opposite pair is possible. There are no assumptions about agreement of the simulated paths beyond their first differing read.

Identify addresses and data words with $\mathbb F_{2^w}$ in a fixed public binary basis. For each row form the unique polynomial $P_x$ of degree less than $|S|$ interpolating the native cut contents on $S$; take zero for the empty set. Its coefficients, padded to $M_0$ field words, are arbitrary data-only features. At a known address $z$, evaluation $\sum_i z^i c_i$ is linear in these coefficients over $\mathbb F_2$. Crucially the decoder does not need the addresses in $S$ at all. It supplies the correct word on $S$; values at other addresses are specified by this polynomial. Only the analysis uses the polynomial. The real machine makes ordinary native reads. Retrieval with unspecified values off a prescribed set is a classical static data-structure problem. [Dietzfelbinger and Pagh](https://arxiv.org/abs/0803.3693) · [Lean interpolation and evaluation maps](../lean/QueriedCutMemory.lean)

Replay both continuations with this substitute for inherited work-word reads, preserving the physical immutable input and the simulated suffix-write overlay. Maintain original old-address symbolic expressions to select charges, translating them into polynomial-coefficient expressions only to evaluate the actual word tests. Thus algebraic coincidences in the interpolated memory do not cancel a standalone charge. Cap elapsed time by the maximum true suffix time on this finite family at the given size; an invalid substitute could otherwise run forever without charging. The cap is public for the rank proof and never stops a genuine run prematurely. By induction, until a first inherited read at which the substitute is wrong, the replay has the same concrete operands, addresses, writes, charge decisions and branches. On the diagonal the polynomial is correct by the stipulated inclusion. For any off-diagonal, even a false simulation can return one only after checking a **true raw half equality**, hence only on an actual opposite pair. If there is no differing inherited read and one actual side is fast, the decoder returns zero on such a pair.

There are $U=O(N+wM_0)$ feature bits including the raw payload, old physical input and controller. For each fixed $S$ choice per row the same matrix argument works. Pad $U$ to at least $m$, and bound the degree at $a_*=\lceil C\eta m/L\rceil$ instead of the possibly smaller actual depth. The additive $O(w)$ is absorbed for large sizes since $L=O(w)$ and $m\gg w^2$. From $D(U,a_*)\le(eU/a_*)^{a_*}$, we get $\log_2 D(U,a_*)\le O(\eta m(1+\log(1/\eta)))$. The case $a_*>U$ is avoided by taking $\eta$ small. The count of possible headers is unchanged: the coefficients can depend on $S$ and $x$, but no description of $S$ goes in a type. The row-support inequality applies as above. If too many rows each had even one bad choice of $S$, choose one witness set per such row. All other rows can have arbitrary coefficient features; restricting to the bad rows and their columns is enough and only these diagonals must be correct. This justifies the simultaneous quantifier over $S$.

In particular, on a solver taking $O(N)$ time on these files, take $Q=B/2$ and any fixed $K\ge0$. The bank may contain **everything written in the entire common prefix**, every inherited read on the two diagonal suffixes, and **any** list of at most $N\log^K N$ further addresses. With suitable constant multiples, $M_0=O(N\log^K N)$ gives $q=\Theta_\delta(N/(w\log w))$ for fixed $K$. On exponentially many opposite pairs, either both suffixes exceed that charge cutoff or a real suffix reads an initially zero work cell outside the whole list before any suffix write to it. At that read the specified algebraic completion returns a nonzero word. If all the relevant inherited work reads are guaranteed to target prefix-written addresses, the stronger charged bound itself follows for almost every database and exponentially many pairs, independently of the numerical placement of those writes.

This conclusion permits the address list to be optimized separately for each database. If at least one side of every opposite pair is cheap even at the $q$ cutoff, increasing the budget to a prescribed $M_0$ forces more than $M_0$ distinct possible inherited addresses across the continuations of one common prefix (whenever the two diagonal runs fit the budget). An individual run still takes $O(N)$ in the linear-time case. A single instruction can read an initially zero address far from the ones used on the other inputs. Dispersion across different completions is not additive elapsed work on one file.

## Almost the full query exponent, with an actual one-bit choice

For every fixed $0<\delta<1$, the number of hard **full selector words** per typical database can be raised to $2^{(1-\delta)m}$. Use the physical format with a fixed power-of-two number $t$ of consecutive equal row blocks. Two extra pending packets name any two blocks. The same one-bit tag selects which named block to test. All $m$ selector choices are still encoded in their seed packets. Choose fixed $t$ with $1/t<\delta/4$. Only the constants in the preceding charge bounds depend further on $t$. At $Q=B/2$ the unconditional bound remains $\Omega_\delta(N/\log^2 N)$ on both continuations of each recovered opposite pair. [Two-block DIMACS format and finite tests](batched-powered-walks-on-one-sat-database.md#the-same-full-query-with-any-ordered-pair-of-row-blocks)

Call a block clean when its raw payload equals its part of the query, and dirty otherwise. Start with candidate block one. Compare the current candidate and the next block by simulating the two tag choices for this ordered pair up to cutoff $q$. If either reports a miss, reject the full query. If exactly one returns fast and clean, keep the *other* candidate. In all other surviving cases use a fixed tie rule. After $t-1$ comparisons, return raw equality on the one surviving block. Coordinates of other blocks may have affected which comparisons were tried.

The diagonal is accepted with genuine memory. For the interpolating simulation, require the bank to cover the diagonal reads on the comparisons actually tried by the true diagonal procedure, at most $2(t-1)$ continuations. This requirement is determined before interpolation. On a wrong positive there is a dirty block somewhere, while the final candidate is clean. Suppose no actually compared opposite pair incurred both true timeouts or a differing actual inherited read. Whenever a dirty and clean block met, their simulations would then be faithful through their cutoffs, and at least one would finish. A fast dirty answer would reject. On a surviving comparison only the clean block could finish, so the dirty block would advance. In a homogeneous comparison either surviving candidate has the same true type, even if the substitute memory makes that comparison behave arbitrarily. Thus after the first dirty block appeared the final survivor would be dirty, a contradiction. The witness is an actual pair of fixed files selected by a comparison with opposite true answers. No counterfactual error on a comparison of two homogeneous blocks by itself witnesses the conclusion. [Lean elimination invariant](../lean/DirtyCandidateElimination.lean)

Each choice of a final block gives one raw equality matrix of rank $2^{m/t}$. The events selecting that block have depth $O(tw(q+1))$ under the earlier test simulation. Therefore
$$
 \operatorname{rank} C\le t\,2^{m/t} J D\bigl(U,O(tw(q+1))\bigr).
$$
For this fixed $t$, take a sufficiently small $\eta(\delta)$ in the respective cutoffs. The rank is at most $2^{\delta m/2}$, so at most $2^{(1-\delta/2)m+O(1)}$ database rows can have fewer than $2^{(1-\delta)m}$ off-diagonal positives. This argument works both with complete old memory and with an arbitrary protected bank per row. Each positive gives a different full $y$ in actual seed packets at this cut. The two tagged verdicts in one particular comparison depend on the two named blocks; changing other bits can change the full query without changing those two verdicts. In fact a uniformly random full query for a fixed $x$ has any clean block with probability at most $t\,2^{-m/t}$, by the union bound. Thus even the availability of a genuinely opposite pair has exponentially small probability for fixed $t$. A simulation correct outside a superpolynomially small exceptional fraction of uniform inputs could miss this entire event. The known conditional average-case simulation of polynomial time in linear alternating time supplies no unconditional contradiction here. [Li and Tell, Theorem 1.3](https://eccc.weizmann.ac.il/report/2026/233/revision/1/download/)

One can also restrict the variations to a chosen part of the pending query. For example, fix a power of two $b$ and vary only one of every $b$ complete segments inside each row block. In each slice fix both the database and query bits on all other segments to the same arbitrary string. The remaining $m'=m/b$ independent bits are equally divided among the $t$ blocks. All placement bounds are still $o(m')$, and the argument applies with $m'$ in the rank, cutoff and count. The exceptional *fraction* has the same bound within every slice, hence also overall. Each resulting full query agrees with its diagonal completion in every seed packet outside those selected segments. This permits any fixed positive dyadic fraction of the seed packets, with constants depending on that fraction.

A differing read can be located in the data used by the simulation. If an opposite comparison would be faithful with the same two cutoff outcomes and reports, it cannot cause a wrong winner when one true side is fast. Consequently an opposite comparison witnessing a simulated discrepancy can be chosen with a different resolved transcript or control outcome when every opposite pair has at least one fast side. Before the first differing resolution, both executions have the same public transcript and use the same affine form for the bit being tested. Its differing value requires at least one originally inherited, actually accessed source with nonzero coefficient at which the interpolant gave a different word. This applies to the operand-based convention above, including the final output bit. A discarded load whose contribution has canceled from the tested form cannot alone supply this witness.

## A sharp bound for counterparts close to the diagonal

Suppose $Q=B/2$ so $m=\Theta(N)$. Measure proximity by the number of the $m$ independent row/lane choices where $x$ and $y$ differ. The two physical files of an opposite pair still differ only in their tag bit; the distance here is between the full query and the database's all-good **diagonal query**. For $4t\le D\le m/4$ put $E=D\log_2(em/D)$. When $E/(N/w)\to\infty$, the worst-case smaller of the two charged suffix counts on pairs at distance at most $D$ has order
$$
 \Theta\!\left(\frac{D\log(em/D)}{w^2}\right)
$$
in the unrestricted-prefix affine convention, in the following precise minimax sense. Every correct solver encounters pairs at this lower rate. One globally correct scanner has at least one side within the upper rate on every such opposite pair of its data-first binary subfamily. Neither side of the minimax assertion caps ordinary prefix time.

For the lower bound fix $t$ according to the desired abundance exponent. Around any fixed center in each block, allow both $x$ and $y$ to range over its Hamming ball of radius $r=\lfloor D/(2t)\rfloor$ on $m/t$ bits. If $V=\sum_{j=0}^r\binom{m/t}{j}$, the product has $V^t$ payloads, and every query in it differs from every one of those payloads in at most $D$ positions. Write $e_0=t\log_2 V=\Theta(E)$, by the binomial estimates $(n/r)^r\le\binom nr$ and $\sum_{j\le r}\binom nj\le(en/r)^r$. The raw single-block equality factor in the rank calculation is now $V=2^{e_0/t}$. The layout headers still use $O(N/w)=o(e_0)$ bits. With $q=\lfloor\eta e_0/w^2\rfloor$, the logarithm of the feature factor is $O(\eta e_0)+O(w^2)$. The additive overhead is $o(e_0)$ in the stated range. Thus almost every payload in *each such product* has at least $2^{(1-\delta)e_0}$ genuinely opposite full query choices within the distance limit for which both runs exceed the cutoff. The exceptional fraction is exponentially small in $e_0$. For example, at $D=\lfloor N/(w\sqrt{\log w})\rfloor$ only a vanishing fraction of row choices differ and the bound is $\Omega(N\sqrt{\log w}/w^3)$.

For the upper bound, a public binary parity-check matrix $H$ on one block can be chosen with $O(1+D\log(em/D))$ rows and no nonzero kernel vector of weight at most $D$ (cap $D$ at the block size). Indeed each nonzero error survives undetected under $k$ uniformly chosen parity checks with probability $2^{-k}$. Choose $k$ larger than the logarithm of the number of nonzero candidate errors and use the union bound. Alternatively use the identity matrix if it is shorter. This is the classical linear-code distance argument. Conversely a syndrome detecting all such errors has to be injective on a ball of radius $\lfloor D/2\rfloor$. [Guruswami, notes on the Gilbert–Varshamov bound](https://errorcorrectingcodes.wordpress.com/2010/01/18/notes-2-gilbert-varshamov-bound/) · [Hamming, 1950](https://zoo.cs.yale.edu/classes/cs323/doc/Hamming.pdf)

On canonical data-first files the scanner validates the old data, decodes the binary payload, and computes the syndrome of each block before requesting the tag. Split a syndrome into pieces of $b=\lfloor c w\rfloor$ bits for a small fixed $c>0$. For each piece write one sentinel word at (scale, block, piece index, piece value), leaving the other candidate slots zero. A query-known address then gives equality of that piece with the corresponding piece of $Hy$. Gather $w$ such flags, pack them with fixed shifts and XOR, and test the whole group once. After validating the remaining packets, a detected discrepancy certifies a miss in the selected block. On a genuinely opposite pair the dirty block has a nonzero error of weight at most $D$, so this side finds a discrepancy within $O(1+E/w^2)$ charged steps. If all syndromes agree, use a complete SAT fallback. The program handles inputs outside the recognized binary format by fallback as well.

One uniform scanner can prepare all dyadic distance scales (and the final block length) and try them from smallest to largest. The syndrome lengths through the first scale covering $D$ have geometric sum $O(1+E)$, and there are $O(\log m)$ extra partial-word tests. These are absorbed by $E/w^2$ in the stated range. Lexicographic exhaustive selection of the parity-check matrices terminates in polynomial address space. The finite list of tables fits the specified fixed native width, using $c$ sufficiently small. If a purely syntactic simulator treats every old scratch cell as unresolved, the scanner can recompute $H$ and $Hy$ after the tag using public parameters and fresh initialized scratch. This can take a great deal of ordinary time, while involving no unknown old memory. The upper bound concerns charged instructions on the side detecting the miss. It supplies no small elapsed-time guarantee for this scanner.

## Where the attempted time amplification stops

At $Q=B/2$, adding each independent walk multiplies rank by $2^s$ until the rank logarithm is $\Theta(N)$. Any scalar matrix indexed by these $N$-bit data has rank at most $2^N$. An algorithm can also pack several queries and rows into one lookup; the batched family has a linear total-time algorithm (and the journal gives a faster packed implementation in its stated regime). The exponential increase in the number of hard counterparts therefore coexists with a linear total clock on every file in this family. A decision-time separation needs another source of work on a single execution.

Lean checks the finite row-support argument, existence of the bounded-degree interpolation, linearity of evaluation, the syndrome implication and the block-elimination invariant. An executable test also exhausts all 4,096 four-by-four binary matrices with a unit diagonal and compares actual with interpolated old reads on small sparse memories. [Audit](../audits/queried_cut_memory_audit.py) The rank-to-native accounting, physical placement, multiplicity estimates and time analysis remain manuscript arguments. Priority for the combined SAT results is unestablished.
