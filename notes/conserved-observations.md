# Learning a conserved answer from short observations of RAM states

**Research journal, 2026-11-24.** Suppose a machine runs for T steps. Can we recover its answer using only observations of single steps? This attempt assigns a vector of bits to each configuration and measures the dimension r of the changes to that vector. Under a hypothetical fast SAT algorithm, one can learn which of two terminals is reachable at a cost governed by r and the cost of inspecting a coordinate. The number of coordinates may be exponential. A family of explicit SAT inputs gives a quantitative obstruction to choosing the observations locally.

## What a query can establish

Work over the two-element field. Let F be the machine transition, with halting states absorbing, and let Φ(s,i) be a Boolean observation of state s at an index i of b bits. Write Φ(s) for the entire vector. Fix a set of allowed transitions containing every step of the initialized run. It can include every transition. Define

    E = { Φ(s) + Φ(F(s)) : s → F(s) is allowed },    W = span(E).

Every state reached from x₀ has its observation vector in Φ(x₀)+W, by telescoping the differences. A vector of coefficients defines a parity conserved on all allowed transitions exactly when it annihilates W. The cosets modulo W therefore retain precisely what can be distinguished by any collection of these linear conserved quantities.

First suppose every halting verdict has its own known fixed observation vector, τ₀ for rejection and τ₁ for acceptance, and the computation terminates. It is enough that all terminal vectors of a verdict belong to its specified coset. If τ₀+τ₁ lies outside W, exactly one augmented matrix with rows E and the single extra row Φ(x₀)+τⱼ has rank r=dim W. The other has rank r+1. The smaller rank gives the answer. If the ranks agree the test gives no decision. More generally, a supplied finite list of terminal representatives works if it covers the actual terminal and no coset in the list has two verdicts. Testing all representatives then returns a unique verdict.

To ask if a row set has rank at least q, ask SAT for q rows and q coordinate indices whose square minor is nonsingular. This equivalence holds for every finite matrix, including one too large to write out. A query for an augmented matrix can also use its specified extra row. An inverse over the binary field certifies the minor by ordinary cubic matrix multiplication. Doubling a threshold and then binary searching takes O(log(r+2)) adaptive decisions per matrix, with q ≤ 2(r+2). One need not find a basis or request a satisfying assignment from the solver.

For a fixed log-word RAM, arbitrary preexisting work memory causes no extra space assumption in these queries. Let U bound the word operations for one coordinate evaluation, one transition and any guard on that transition. The number of registers is fixed and the words have w bits. Let n be the bit length of any fixed public input. For each guessed row, all q probes must refer to the same pre-state. Guess its registers and the memory events of the probes and of the one-step update. Treat the probes as read-only inspections of the state with private scratch. Sort the word accesses by row, address and time to enforce one common value per initially touched address. The post-state uses that same memory with the step's writes applied. This can equivalently be done by saving the O(1) modified words and overlaying them on the pre-state. Unmentioned work words can be filled arbitrarily. Initial and terminal reference coordinates must themselves be computable within the charged bound. One copy of the fixed public input suffices by jointly checking its read-only accesses. With fixed word instructions of bit cost poly(w), a bound on the explicit SAT length is

    Õ((n + q²(U+1) + qb) poly(w) + q³).

The logarithmic factors include the encoding of the gate and variable indices. A guessed finite state in a succinct transition circuit can instead be provided explicitly per row with its full bit cost. The RAM estimate requires a locally decidable guard if transitions are restricted. Excluding states on the ground that they are unreachable would require a separate proof. If ordinary SAT of length m runs in O(mᵈ), the uniform test charges O(mᵈ) per decision as well as query construction. For a hierarchy contradiction one would need such a test, including the construction of the observations and terminal descriptions, strictly inside the lower clock for the chosen hierarchy machine. Affine program invariant inference has a long history. Karr's algorithm treats affine relations between program variables. Here the hypothesized fast SAT algorithm tests minors of an implicitly indexed matrix of observed changes for arbitrary transitions. [Karr](https://doi.org/10.1007/BF00268497) · [RAM-to-SAT simulation](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

## Arbitrary terminal memories without a list

The terminal representatives need not be given. Enlarge W to the space V spanned by E together with every row Φ(x₀)+Φ(z) for a locally recognizable terminal z of either verdict. Write R for its dimension. The same threshold queries compute R. For each verdict j submit one further existential query.

1. Exhibit an R-by-R nonsingular minor from the rows defining V, giving a common set of R coordinate indices. Restriction to these indices is injective on V, because it has full rank on V.
2. Exhibit a terminal z of verdict j. On just those R coordinates, exhibit Φ(x₀)+Φ(z) as a binary linear combination of at most R actual transition-difference rows. Zero selected rows are allowed.

The vector tested in the second step and the proposed sum both belong to V. Injectivity makes their restricted equality a full-vector equality. Conversely, if a terminal lies in the initialized coset, a basis of W supplies at most R rows for its representation. Thus this query detects *exactly* whether the initialized coset contains a terminal of that verdict. At R=0 the minor and sum are empty and one simply asks for a terminal of the requested verdict. If exactly one verdict is detected it is correct for a terminating run. Two detected verdicts expose an ambiguity in these observations. This costs O(log(R+2)) decision calls overall at the displayed size for q=O(R+1). Each guessed terminal uses one common symbolic memory across all its probed coordinates. No certificate for every coordinate of a terminal memory is required. The parameter R can be small even when the number of different terminal signatures is exponential in R.

## The exact support bound

If a contrast v is outside W, some parity of at most r+1 original coordinates vanishes on W and takes value one on v. Indeed, append v to a basis of r rows of W. Select r+1 columns giving an invertible minor. On those coordinates solve for a coefficient vector with inner products zero on the first r rows and one on the last. Extend by zeros elsewhere. Conversely every parity vanishing on W vanishes on its row span, so none separates a contrast in W. The support bound is attained when E consists of the r adjacent sums eᵢ+eᵢ₊₁ in r+1 coordinates and v=e₀. All coefficients of a conserved parity must then be equal. These rows arise from the path of states labeled eᵣ,…,e₀ ending at e₀, with a separate zero-labeled sink.

There can be a small separating parity even when r is large. Searching for a single suitable coordinate directly has an additional quantifier. Given a Boolean circuit Q(u,v), take two fixed states A and R, and pre-states Xᵥ with a transition to R. Let the observation at coordinate u be one on A, zero on R and 1+Q(u,v) on Xᵥ. A single coordinate separates A from R and is conserved on every transition exactly when ∃u ∀v Q(u,v). The state and observation circuits have polynomial descriptions. This proves completeness for the second existential level of the polynomial hierarchy for the single-coordinate selection problem on succinct finite states, including membership by guessing the coordinate and universally testing a step. It shows what a direct SAT compilation of that unrestricted selection problem would need to accomplish. Under the fast-SAT hypothesis one can simulate its two quantifiers, charging both levels. The row-rank method has one existential quantifier in each of logarithmically many sequential tests.

## An explicit SAT family defeats local terminal classifiers

For k≥1 give the formula two independently chosen k-bit vectors u and v. For each j add two unit clauses, forcing zⱼ to uⱼ and to vⱼ. The formula is satisfiable exactly when u=v. The k positions and all variable names are fixed and the signs carry the input. Repeating each literal gives the same construction with three listed literal occurrences in every clause. The bit length with binary names is Θ(k log(k+2)). Comparing the signs solves this promise in linear time.

Consider one feature dictionary and one allowed transition system covering the computation on **all** these inputs, including their initialized states. The immutable input, if read separately, is part of the state here. Suppose each initial coordinate (u,v) ↦ Φ(x₀(u,v),i) has binary matrix rank at most L across the displayed split. This includes every product of an arbitrary left function and an arbitrary right function for L=1. If both verdicts have distinct single terminal cosets, the support lemma yields a parity on at most r+1 coordinates whose initial value is equality or its complement. Both matrices have rank 2ᵏ. Equality gives the identity I, while its complement is I+J with J the all-ones matrix. In characteristic two J²=0 because 2ᵏ is even, so (I+J)²=I. Rank subadditivity now gives

    (r+1)L ≥ 2ᵏ.

Allowing arbitrary computation on the conserved quantities at the end cannot help when the two verdicts have single distinct cosets. Separating the two cosets by one parity already suffices. The same argument bounds the number of coordinates needed by *any* such separating parity by at least ⌈2ᵏ/L⌉.

There is a weaker conclusion when the rejecting terminal signatures can vary. Suppose there is one accepting coset and K different rejecting cosets, each distinct from the accepting one. For each rejecting coset choose a parity with support at most r+1 that differs between it and the accepting coset. Test whether this parity takes its accepting value. As a matrix on initialized inputs each such test has rank at most 1+(r+1)L. The pointwise product of these K tests is exactly equality. The rank of a pointwise product is at most the product of the ranks, by multiplying the summands in two rank-one decompositions. Hence

    2ᵏ ≤ (1+(r+1)L)ᴷ.

The dependence on the number of terminal cosets can be sharpened. Translate the accepting coset to zero in the quotient by W. The K nonzero rejecting contrasts span a D-dimensional space. Put

    h = max{ j ≤ D : 2ʲ−1−j ≤ K−D }.

They can be distinguished from zero using at most h linear checks. If the contrasts are not the whole punctured span, their union with zero is not closed under addition. Quotient the span by the line generated by a missing sum of two contrasts. No contrast maps to zero, the two summands merge, and the dimension drops by one. The number of distinct contrasts minus their dimension never increases. Repeat until the punctured span is full. Its final dimension t therefore satisfies 2ᵗ−1−t ≤ K−D. The composition of the quotients gives the desired checks. This maximum is attained for each feasible D,K: take all nonzero vectors of an h-dimensional subspace, add D−h independent new directions, and fill up to K distinct nonzero vectors. Any separating projection must be injective on that subspace. The minimum number of these checks is the critical number of the binary matroid of the contrasts. The cardinality-only obstruction for blocking all subspaces of a given codimension is classical. [Bose and Burton](https://doi.org/10.1016/S0021-9800(66)80007-8) · [Geelen and Nelson](https://www.math.uwaterloo.ca/~apnelson/trianglethreshold.pdf)

All t checks can use a *common* set of at most r+D initial coordinates. Indeed, take the subspace generated by W and one representative from each rejecting contrast relative to the accepting terminal, of dimension r+D. Pivot columns for that space determine every linear form on it. Subtract the accepting terminal vector from each initialized vector first: termination places the resulting vector in this common space. Offsets in the tests are constants. Each check on initialized inputs is affine in these r+D coordinate bits. The product testing equality to the accepting projection has degree at most t in them. Each binary variable is idempotent, so repeated factors can be removed. The matrix of a degree-j monomial is a pointwise product of j distinct coordinate matrices, hence has rank at most Lʲ. If the resulting polynomial has a constant term, complement it. Equality and its complement both have full rank here. Counting the remaining possible nonconstant monomials gives

    2ᵏ ≤ Σ_{j=1}^h binom(r+D,j) Lʲ.

On a specific terminal set the degree can be smaller than the number of linear checks. One may substitute the least degree of a binary polynomial that is one at the accepting signature and zero on all rejecting signatures for h in the monomial bound. An affine change to pivot coordinates preserves that degree. For example, in 2m coordinates let the accepting signature be zero and the rejecting signatures be all (x,y) with x·y=1, for m≥2. The polynomial 1+x·y distinguishes them in degree two. A linear projection distinguishing them needs at least m bits. Its kernel must consist of zeros of the quadratic form Q(x,y)=x·y. For any two members u,v of the kernel, Q(u+v)+Q(u)+Q(v)=0, so the kernel is orthogonal to itself under the nondegenerate bilinear form polar to Q. Its dimension is at most m. Projecting to x attains the bound. At the other extreme, distinguishing zero from all other points in an h-dimensional subspace forces degree h, since the zero indicator on that subspace has the unique multilinear polynomial ∏ⱼ(1+xⱼ).

In particular an easy equality test with r=0 can retain the entire vector u+v throughout and decide whether it is zero at the end. Its k coordinates have initial rank at most two each, and its 2ᵏ−1 distinct rejecting signatures require k linear checks to distinguish from the accepting zero. This realizes the sharp critical-number count. The example can use a machine that preserves the read-only input in every configuration and computes the verdict by scanning it. For this example take terminal signatures on its actual runs, or guard the terminal labels by consistency of the verdict.

## Many accepting signatures and a common rejection

There is an asymmetry between the two verdicts on this family. Suppose every rejection has the same coset, while accepting inputs can use arbitrarily many different cosets, all distinct from the rejection coset. Let D be the dimension of the accepting contrasts relative to the rejection coset in the quotient. Choose r+D pivot coordinates for W together with representatives of these contrasts. Then

    (r+D)L ≥ 2ᵏ.

To see why, choose D binary linear functionals on the quotient that give the coordinates of each contrast. On the initial states, each is an affine combination of the common r+D raw feature bits. Stack their values after subtracting their value on the rejecting coset. Off the diagonal the resulting vector is zero. At diagonal position i it is some vector dᵢ≠0. Let a be the vector of affine offsets. For any vector z in the common right kernel of the r+D raw feature matrices, put p=Σᵢ zᵢ over the binary field. Multiplication by those normalized matrices gives dᵢ zᵢ=ap for every i. If ap=0, nonzero dᵢ forces every zᵢ=0. Otherwise all zᵢ must be one, giving p=0 because the matrix has even size. Thus the common right kernel is zero. Stacking the raw matrices vertically gives full column rank 2ᵏ, bounded by the sum of their ranks.

For sharpness partition the 2ᵏ diagonal entries into t=r+D equally sized blocks when t divides 2ᵏ and D≥1. Raw coordinate j tests membership on the diagonal in block j, and has rank 2ᵏ/t. All unequal pairs initialize to zero and every equal pair initializes to one of the t unit vectors. Group these units into D nonempty groups. Send each unit to its group's designated unit, fixing the designated units and zero. Take zero as the rejecting terminal. The differences span dimension t−D, and the D designated units are independent modulo that span. This realizes equality in the bound as a feature-transition system. It makes no assumption that evaluating an arbitrary block indicator is cheap.

More generally let K be the number of rejecting cosets, allow any number of accepting cosets, and let m be the common pivot count for W together with all terminal contrasts relative to one terminal. For each accepting coset α translate the K rejecting signatures by α. The projection argument above supplies a polynomial Pα that is one on α and zero on **every** rejecting signature, with degree at most ⌊log₂(K+1)⌋. It may be one on other accepting signatures. Substituting the common pivots makes these polynomials affine combinations of nonconstant squarefree pivot monomials through this degree. Their matrices are zero off the diagonal, and collectively they cover the diagonal. The same common-kernel proof now applied to the monomial matrices gives

    2ᵏ ≤ Σ_{j=1}^{⌊log₂(K+1)⌋} binom(m,j) Lʲ.

One can substitute any smaller common degree attainable by a family that covers the accepting signatures and vanishes on all rejects. This removes a possible loophole in which every positive instance selects its own successful test from a fixed library. For K=1 it recovers the sharp linear bound. The earlier zero-versus-nonzero example, with a *single accepting coset*, has just k raw rank-two features. Interchanging which outcome must have a common signature changes the rank requirement exponentially on the same inputs.

A stronger algebraic fact holds in the common-rejection argument. Give the D quotient coordinates independent indeterminates and take their generic linear combination over the rational function field in those indeterminates over GF(2). The unnormalized matrix is diag(dᵢ(t))+a(t)J, where the symbols now denote binary linear forms and no dᵢ(t) vanishes identically. Its determinant is the product of the dᵢ(t) times (1+a(t)Σᵢ1/dᵢ(t)), by the rank-one determinant identity. Distinct nonzero binary linear forms have linearly independent reciprocals over GF(2): clear denominators, reduce modulo one form, and all the other forms have nonzero product in the resulting integral domain. Singularity would therefore require a≠0 and the set of forms with odd diagonal multiplicity to consist solely of a. An even number of diagonal entries precludes that parity pattern. Thus a single generic combination of the raw matrices already has full rank over this extension. The binary common-kernel proof suffices for the numerical bound.

## A width-three template that requires many signatures on both sides

One more input bit removes the freedom to put all the annotations on the easier side. Fix a width-three formula template that pins a flag b and the two strings u,v by unit signs. Its other clauses encode a bounded-fan-in Boolean circuit comparing u and v and requiring equality if b=0 and inequality if b=1. The Tseitin encoding uses O(k) variables and clauses. Short clauses can repeat literals. The encoded length is Θ(k log(k+2)). Comparing the input signs and the flag decides the promised family in linear time.

Use a common transition system and observation dictionary over both flag values. Suppose there are K₀ rejecting and K₁ accepting terminal cosets among the admitted inputs, with the verdict determined by the coset. Let m be the dimension of the transition differences plus all terminal contrasts from one reference, as above. Require initial rank at most L on each of the two fixed-flag input matrices for every feature coordinate. On the equality slice apply the diagonal-cover bound with K₀ forbidden cosets. On the inequality slice the diagonal consists of rejections, so apply it with K₁ forbidden cosets. In particular

    2ᵏ ≤ Σ_{j=1}^h binom(m,j)Lʲ,     h=⌊log₂(min(K₀,K₁)+1)⌋.

If m and L are bounded by fixed polynomials in k, then h=Ω(k/log(k+2)), since the right side is at most (1+mL)ʰ for h≥1. Thus **both** verdicts require at least 2^{Ω(k/log(k+2))} different signatures in this representation. If m=O(k) and L=O(1), then h=Ω(k). Indeed for h=o(k) and m=O(k) the logarithm of the sum is o(k), by the binomial bound (when h≤m use binom(m,j)≤(em/j)ʲ; when h>m use (1+L)ᵐ). This would contradict the displayed inequality.

Both scales are attained up to constants. Partition the k positions into s blocks of length at most B, and retain the flag and one bit of equality per block as immutable observations. Each of these equality matrices has binary rank at most 2ᴮ, even with the remaining positions free. The differences have rank zero, m≤s+1, and each verdict occurs on exactly 2ˢ signatures: for every pattern of block-equality bits, exactly one flag accepts and the other rejects. A transition system can simply preserve the input through termination, with the terminal label checked by scanning its blocks. Taking B=max(1,⌊log₂ k⌋) gives polynomial feature rank, s=Θ(k/log(k+2)), and the first scale. Taking B=1 gives rank at most two and s=k. The logarithm of the number of signatures is the storage needed to name one. An algorithm can retain all these bits within linear time. The exponential bound on the *number* of signatures is compatible with this running time.

The rank argument using an arbitrary nonzero value at each diagonal position is related to nondeterministic rank in communication complexity. De Wolf gives the diagonal support example for equality over characteristic zero. The common-kernel calculation above accounts for affine offsets over the binary field and for unions of successful tests. [De Wolf](https://homepages.cwi.nl/~rdewolf/publ/qc/nqj_final.pdf)

On the equality template, masking the terminal features to two fixed vectors can force the dimension of the changes to grow exponentially in k when the initial feature ranks are small. Taking the full input equality test as one initial observation escapes the local-rank condition and already solves this promise. An input-dependent dictionary or a different allowed set for each input also escapes the common-system argument. No conclusion about the running time of a general SAT solver follows from the inequality.

## A clock where the test would suffice

To give the missing premise a numerical scale, take a total deterministic multitape decider for a hierarchy language H in time O(2ⁿ) outside deterministic multitape time O(2^(n/2)), for n input bits. The ordinary deterministic time hierarchy gives such an H. Its tape locations can be represented with O(n) bits. Suppose that on every input a fixed polynomial-time construction provides observation and guard programs of polynomial description length. Assume they cover the actual run, use coordinate indices of at most 2^(n/48) bits and words of polynomial width in n, and that each required one-step, single-coordinate or terminal test costs at most 2^(n/48) operations of polynomial-in-n bit cost in the access model above. Impose a rank cutoff R≤2^(n/48) in the test for arbitrary terminal memories. The tests have encoded length at most 2^(n/16+o(n)), including the cubic minor check. A cubic ordinary SAT solver would run them in RAM time 2^(3n/16+o(n)). The solver uses logarithmic words in the SAT encoding length. A direct multitape simulation can scan a list of all written address-value pairs on each access, at an overall quadratic time cost up to polynomial word overhead. This gives 2^(3n/8+o(n)) multitape time, strictly inside the excluded clock. Doubling can stop and report an unknown answer as soon as the rank cutoff is exceeded. Threshold rounding and the logarithmic number of SAT calls fit the o(n) term. [Hennie and Stearns](https://www.cs.toronto.edu/tss/files/papers/HennieStearns66.pdf)

Under the cubic SAT hypothesis, every such uniformly generated set of observations that covers the authentic run must therefore fail on infinitely many accepting inputs of H and on infinitely many rejecting ones. Failure means the rank exceeds the cutoff or terminals of both verdicts share the initial coset. Indeed the bounded test is sound whenever it gives an answer. If only finitely many accepting inputs failed, defaulting to rejection on every unknown and hardwiring the finite exceptions would decide H inside the excluded clock. Defaulting to acceptance proves the assertion for rejecting inputs. Supplying a family within those same bounds that succeeds on all accepting inputs alone, even if it abstains on every rejecting input, would contradict the cubic SAT hypothesis. This last inference uses the hierarchy on the multitape model in which the simulation time was actually bounded.

The remaining uniformity problem is to generate inexpensive observations for a *particular time-hierarchy computation*, while bounding the dimension of the allowed changes and retaining terminal separation. A large supply of locally evaluable bits alone gives no such bound, even for the explicit easy formulas above. Priority of the parameterized test and the joint rank bounds has not been established.
