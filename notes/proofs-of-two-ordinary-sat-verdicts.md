# Short proofs of the verdict on a solver's own two SAT files

Fix a sound arithmetic proof checker with polynomial checking time and literal binary proofs, for example a standard presentation of $I\Sigma_1$. Given an arbitrary correct deterministic word-RAM SAT solver $M$, a proposed clock $a(N+1)^k$, and a positive proof budget $b$, one uniform generator produces two ordinary proper ASCII 3-CNFs $G,P$. Write $N=|G|$ in physical bits. The files have these properties.

* $G$ is unsatisfiable. The two true closed statements “$G$ is unsatisfiable” and “$M(G)$ returns NO” each have **no accepted proof of at most $b$ bits**. The statements name the files by the generator and its binary parameters.
* Either $M$ exceeds its proposed deadline on this particular $G$, or $P$ has exactly one model on its occurring names. In the second case the two true statements “$P$ is satisfiable” and “$M(P)$ returns YES” also have no accepted proof within the same cap.
* Even the **single disjunction of all four statements** has no accepted proof within the cap. A program that meets its clock on every file therefore produces two actual, correct verdicts with this property for every $b$.

One fixed checker works for all the solvers. No proof of $M$'s correctness is required. In $I\Sigma_1$ every true closed verdict here has a finite proof, since each generator and actual returning computation can be exhibited and each fixed file can be evaluated by finite enumeration. The proof cap is measured against the parameter $b$. The generated negative file can be much longer than $b$.

## Constructing the two files

Let $u$ encode the program, its word convention, the clock parameters, and the binary numeral for $b$. Use one program template $E(e,u,i)$ with a tag $i\in\{0,1\}$. The arithmetic phrases “file 0” and “file 1” abbreviate the results of running program number $e$ on $(e,u,0)$ and $(e,u,1)$, respectively. These phrases have fixed syntax apart from binary numerals. More formally, quantify over a terminating computation of the generator and its output before applying the SAT or machine-output predicate. Both generators below terminate on valid parameters.

On tag 0, emit an ordinary SAT instance asking whether a literal proof of length at most $b$ ends in one of five specified sentences. Four are the individual statements above, with files named as just described. The fifth is their disjunction. A length marker and zero padding cover all short proofs. The verifier constructs the five *syntax strings*, checks proof syntax and compares the last line with those strings. It never runs $e$ or $M$. Compile this polynomial-time computation into proper 3-CNF. Take $e$ to be the number of this very template and call the resulting physical file $G$.

On tag 1, generate the tag-0 bytes and measure their length $N$. Emit a parsimonious deterministic bounded-computation instance for $M$ on exactly those bytes, accepting iff the machine returns NO within $a(N+1)^k$ steps, inclusive. This is $P$. Termination is immediate from the tag order. For uniqueness use fixed input and initial memory, deterministic gates, canonical post-halt padding, a total ordering of memory events including time, and fixed values for unused padding bits and anchors. Thus $P$ certifies one determined bounded run and has either zero or one model. [Parsimonious native word-RAM encoding](local-sorting-for-parsimonious-ram-encodings.md)

Suppose $G$ were satisfiable. A proof within the cap would then certify one of the five sentences. Correctness of $M$ means it returns YES on $G$, so the tagged run encoded in $P$ fails to return NO by the deadline. Consequently $P$ is unsatisfiable and $M(P)$ returns NO. Every listed sentence is false, contradicting soundness of the checker. Therefore $G$ is unsatisfiable. The literal definition of its verifier now excludes all five proofs within the cap. If $M(G)$ returns by its deadline, its verdict is NO and $P$ has its unique model. This establishes the dichotomy without needing to decide which side holds.

The same argument works for a specified nonempty finite roster of correct solvers with separate clocks. Take the tag-1 computation to run all the clipped machines on $G$ and accept if any votes NO. The four kinds of statements now include each individual machine's verdict and one disjunction over the entire menu. In the hypothetical $G$-satisfiable case every NO vote is absent, $P$ is unsatisfiable, and every YES verdict on $P$ is absent. Thus either the one $G$ makes **all** roster clocks late, or there is one common positive $P$ and all the individual signed verdict statements require more than $b$ proof bits. The roster is supplied as data. For arbitrary untrusted programs the soundness contradiction yields an erroneous machine verdict if $G$ is satisfiable.

## Which resource this bounds

For fixed machine and clock, the target sentences have length $O(1+\log b)$. The tag-0 generator, its $b$-bit proof predicate, and $N$ are polynomially bounded in $b+1$, with the exponent depending on the proof checker. The deterministic bounded-run construction gives $P$ length $O_{M,a,k}((N+1)^k\,\operatorname{polylog}(N+2))$ for $k\ge1$. Witness slots can be required to have distinct occurring names, for example by adding clauses containing a forced-true anchor. A literal-slot construction of this kind already uses $\Omega(b\log(b+2))$ physical bits in $G$ for the decimal spellings of $b$ distinct names. A proof lower bound in $b$ supplies no superlinear elapsed-time bound in $N$.

One may give the checker the fixed additional axiom “$M$ correctly decides SAT on all proper files.” Syntactically construct that sentence from $M$, add it to the checker *before* emitting $G$, and use the same proof. For each correct $M$ the resulting theory is sound. Likewise, if a particular clock really is globally valid, its uniform time bound may be included as an axiom in a separate construction. These extensions change the pair of files. The four conclusions follow for that new pair even when proofs may use the corresponding machine axiom.

The bounded diagonal sentence is classical. The formulation here makes the conclusions about the generated files and the incoming solver's concrete returns. Krajíček relates proof lower bounds to running times for solvers whose soundness has short proofs in a specified propositional system. A transfer to running time in the present construction would require a quantitative bound converting the actual returning computation into a short proof in the same checker. Historical priority for the paired formulation is unchecked. [Pudlák, Lemma 2.1](https://users.math.cas.cz/~pudlak/improved.pdf) · [Krajíček, *A note on SAT algorithms and proof complexity*](https://www.karlin.mff.cuni.cz/~krajicek/sat.pdf)
