# SAT executions on a public dictionary of edits

Fix a correct deterministic SAT program with a known $O(n^d)$ clock on valid files for $d\ge1$. If the location of one physical bit is computable from $n$ within that clock, there is a solver of the same time order whose complete execution records on the two endpoints differ in only a constant number of instructions. This holds simultaneously for any fixed number of specified bits. It holds even when the two correct verdicts differ. For an explicitly enumerated set of larger edits, the work is a sum over the listed fillings. The list need not have power-of-two cardinality.

## The simulation and its clock

Use a standard logarithmic-word RAM with separate arithmetic, comparisons, branches, loads and stores. A fixed guest can be simulated using a sufficiently large fixed host word-width coefficient. One may take the host width to be a fixed even multiple of the guest width in the model closed under fixed width scaling. Both machines have zero-initialized writable memory and the original input is packed in consecutive words. The SAT answer concerns valid files. With read-only input the host builds a writable scrubbed copy in one pass, saves each marked half and clears input-dependent scratch before reading the next word. Only marked words then introduce differences during this scan. [Fixed-width simulation details](constant-instruction-interpreter-and-size-induction.md) · [Cook and Reckhow on RAM simulation](https://www.cs.toronto.edu/~sacook/homepage/rams.pdf)

Let $n$ be the physical bit length. A public procedure based on $n$ identifies the marked bit positions. Divide host words into two equal halves (with ordinary end padding). There are $h\ge1$ halves containing marks. At each such half, a filling specifies one word of values on its marked bits. The file $b$ obtained by zeroing every marked bit is the common base. Let $D_b$ be a list of $K\ge1$ distinct fillings. The list can depend on $b$ if its generator is uniform; only the positions to be cleared must be known before the private bits are inspected. Write $G$ for the time to generate the positions, masks and the explicit $K$ rows of $h$ words. This includes converting another representation, such as separate bit columns. Assume the public computation uses polynomial clock and address range and $K$ is polynomially bounded, with fixed exponents. The host chooses its fixed coefficient accordingly.

Write $A$ for the guest solver and $t(n)$ for a known polynomial deadline by which $A$ returns the correct answer on every valid file. For an invalid file let $T_A$ denote time to a halt, or infinity if there is none. Choose a uniform deadline that can be obtained and counted within the claimed budget, for example $C(n+1)^d$ for the three target exponents. For every valid input whose filling belongs to $D_b$, the simulator returns its correct SAT bit in

$$
 O_A\left(n+G+Kh+\sum_{p\in D_b}\bigl(1+\min\{T_A(b[p]),t(n)\}\bigr)\right)
$$

native instructions. For any two listed, valid inputs with common base the elapsed instruction counts are equal. Let $s\ge1$ be the number of marked **halves** on which they differ. At all but

$$
 O\bigl(1+s(1+\log_2(h/s))\bigr)
$$

aligned instruction positions their full records are identical. In particular one physical bit edit can affect only $O(1+\log(h+1))$ records, regardless of $K$. Insertion/deletion distance is at most twice the number of differing positions. The constants in the record bound do not depend on $h$ or $K$.

A record consists of the program counter and **all** fixed registers before and after an instruction, its opcode, any accessed address and its read or written word, and the terminal verdict if it halts. A record does not include a dump of unaccessed RAM cells. A saved difference in such a cell is precisely what permits the simulation. If the correct verdicts differ, the terminal records necessarily differ. The theorem keeps the exact output.

## Saving the edit and running the listed variants

1. Prepare the public half-word addresses and masks. For each affected physical word use a fixed sequence of loads, masks and stores to save its marked parts in private cells and overwrite the marked bits in the source with zero. Clear every register holding a private value before advancing the loop. Its counters, pointers and saved return address depend only on the public layout. At most a constant number of records can differ per changed physical word. In particular a long position-selection computation cannot carry a private bit in an idle register.
2. The host now sees the same canonical file on both endpoints. It can repack it once into the guest width in $O(n)$ ordinary operations. Generate the dictionary in order. For each filling set its $h$ marked parts in that baseline, preserving unmarked neighbors; the fixed ratio of word widths gives constant cost per half. This overwrites the corresponding parts even when the next filling specifies zeros. Start each simulation with the guest's true initial registers and memory. A guest read at an unwritten address obtains its baseline input word, or zero beyond the input. A guest write goes into an overlay with a tag identifying the current simulation. Fresh tags for the $K$ trials and disjoint, polynomially addressable banks for tags and values give constant work per guest access. A fresh tag makes all previous overlay writes invisible, including writes into the guest input region. The guest cannot address the saved actual filling, the result table or the host registers. Initialization uses constant work per trial in addition to installing that trial's $h$ parts.
3. Record a terminal verdict on a halt; choose a fixed default on a timeout. Thus invalid alternative strings may diverge without blocking any valid answer. Run **all** listed variants in the same order and store all their results. Guest-dependent halting times can vary across variants. They are identical across the two host executions for each variant, because the canonical file and that variant coincide. No access to the saved actual bits takes place in this phase, and all registers on entering it agree. The records agree throughout every simulation and between simulations. A tagged overlay is enough here because space is unrestricted. More space-efficient initializable arrays are classical. [Hagerup and Kammer](https://arxiv.org/abs/1709.10477)

## An exact lookup with few changed instructions

Use a balanced, full binary tree over the $h$ marked halves, with public constant leaves up to the next power of two. For each node, give every distinct substring appearing there in any dictionary row an ID in $1,\ldots,K$ local to the node. A leaf table maps its masked half-word to its ID. An internal-node table maps a pair of child IDs to its ID. Reserve zero for a missing entry and never insert a child pair containing zero. Each root ID names exactly one listed filling, whose answer was computed in the common phase.

Initialize these tables by processing the $K$ rows bottom-up. Each node and row needs one lookup and at most one new ID, giving $O(Kh)$ work even for a non-power-of-two number of rows. Direct addressing is legitimate in this RAM. A leaf key comprises its node index and at most half a host word. An internal key consists of its node index and two IDs at most $K$. The ranges are $O(h2^{W/2})$ and $O(h(K+1)^2)$ for host width $W$. Both fit in disjoint host banks with the stated fixed coefficient. Only occupied entries are written. No scan of either address range is incurred.

Read the saved parts and run exactly the same bottom-up evaluation on *every* filling, making one lookup at every node. The ID at a node is nonzero if and only if its entire segment occurs at that node in a dictionary row. This follows by induction because an inserted pair of child IDs uniquely specifies its concatenated segment. In particular the root tests membership exactly, including when every smaller segment occurred in some row but their concatenation did not. On a nonmember restore the saved bits, reset the guest and run $A$ with the original input. This gives global correctness on valid files outside the list, with the extra time for this fallback. On members, fetch the outcome at the root ID and use a single branch to two equal-length terminal arms.

Each node evaluation uses a fixed number of native instructions. Always clear both incoming IDs, the address-key scratch and the retrieved value from the CPU registers after saving the output ID into its node cell. The next node then starts from common public registers. The only nodes that can generate distinct records on the two endpoints are the changed leaves and their ancestors. At each level the number is at most the smaller of $s$ and the number of nodes at that level. Up to the first $\lceil\log_2(h/s)\rceil$ levels this costs $O(s(1+\log_2(h/s)))$, and above them a geometric series costs $O(s)$. The terminal lookup and the original scrub add the stated terms.

## Consequence for clock exhaustion

If $r$ designated bits are fixed in number, use all $2^r$ fillings and $h\le r$. For $d\in\{1,2,3\}$ and $G=O(n^d)$, a hypothetical $O(n^d)$ SAT program then yields another $O(n^d)$ program for which every pair differing only at these positions has $O_r(1)$ total record differences and equal running time. This refutes a universal increment based on a predetermined single edit even when the proof counts changes of registers, instruction addresses or work values. A solver-dependent location is allowed by the existing opposite-verdict trace theorem. [One-bit changes after optimal realignment](one-bit-sat-pairs-after-optimal-trace-realignment.md)

The equal-time and record statements also have an unconditional version for a solver with no stated deadline. Before each trial, check the DIMACS grammar, identifier ranges and header counts; this can be done in $O(n)$ on a RAM by scanning digit strings and comparing their canonical lengths and digits as needed. For repeated range comparisons, precompute each token's comparison with the single header bound in time linear in its own length, since the equal-length comparison only inspects that many header digits. Skip an invalid filling, and let the correct guest run to completion on every valid one. Replace the clipped sum in the clock by $O(Kn)$ validation work plus the sum of the actual guest times on the valid variants. The common simulation and its full trace now terminate for any guest that decides SAT on valid inputs, however slow it is.

If $r=O(\log n)$ and all fillings are used, the overhead can be polynomial. If only $K$ fillings are relevant, it is their $K$ simulation times that occur in the bound. Thus a polynomial-size list can protect edits across far more than logarithmically many marked bits while keeping the wrapper polynomial. Even for a one-bit edit anywhere among $h$ public half-words, the differing-record count remains logarithmic in $h$. An increasing $K$ does not in general preserve the original exponent. The result gives no upper bound on the time $A$ needs on arbitrary SAT inputs, and leaves the unrestricted time exclusions open.

## Where an actual solver must fail a deadline or change its trace

For any fixed $0<\epsilon<1$ and $a\ge1$, every sufficiently large byte-aligned bit length $L$ admits at least $L^{1-\epsilon}$ disjoint byte windows with the following property. Fix any correct SAT program on the unrestricted RAM. In **each** window either its public blank file takes more than $L^a$ instructions, or there are opposite-verdict files of length $L$ differing in just one bit of the window whose complete trace insertion/deletion distance is

$$
                    \Omega_{A,a,\epsilon}\left(
                       \frac{\log L}{(\log\log L)^{3/2}}\right).
$$

The length threshold and constant may depend on the program. The blanks are distinct, and the one-bit positions found in different windows belong to different physical input words. Thus for a polynomial-clock solver (take $a$ larger than its clock exponent), at every sufficiently large length at least $L^{1-\epsilon}$ different input words can support such a pair. The analogous statements for two uniquely satisfiable endpoints and for two unsatisfiable endpoints follow separately from the corresponding templates. For an arbitrary correct solver, at least half the windows supply individual deadline misses, or at least half supply the trace changes.

Use the three templates and the blank-file version of the [one-bit trace theorem](one-bit-sat-pairs-after-optimal-trace-realignment.md). Ko's $N$ is the universe size, his $m=N$ is the number of query sets, and his $n=N^{1/4}=s$ counts distinct insertions, each followed by one query. At source side $N=s^4$ each template has a fixed header and a fixed clause-body length $B=\Theta(N^2\log N)$ bits. All the bits changed by setup, online edits and query probes are in the body. Given $L$ take $s=\lfloor L^{\epsilon/16}\rfloor$, so $B=o(L^\epsilon)$ and $\log L=\Theta_\epsilon(\log N)$. Place candidate windows for the body after the header; separate them by $\lceil (\log_2 L)^2\rceil$ bytes. There is room for at least the stated number. To use one window, put the body there without its terminal newline and put spaces in all spare positions outside it, followed by the file's final newline. Leading spaces are on the first clause line and trailing spaces precede the final newline. The other windows consist entirely of spaces. The SAT semantics, number of models, and the Hamming distance within any chosen window are exactly those of its source template. The intervening gap exceeds any fixed logarithmic RAM word at large lengths.

For the trace conclusion one needs to apply the replay argument **to the original solver on these padded files**. A general reduction changing the guest traces would not suffice. Fix the window and use its shifted byte offsets directly in the online simulator for the earlier theorem. The public blank now has length $L$ and its required preprocessing trace has at most $L^a$ steps on the indicated arm. A changed source bit is still one changed physical bit at a known address on the actual solver. All logical initialization edits, insertions, queries, rollbacks and capped neighbor-verdict inferences remain within that same window. The proof there uses polynomial index sizes, polynomial setup on the blank, and word size $\Theta(\log N)$ in the amortized reduction. Here $L=N^{O_\epsilon(1)}$, so all three bounds hold with fixed coefficients independent of the window. Its number uses $O_\epsilon(\log N)$ public bits. Ko's Theorem 1.1 is for every cell-probe data structure at the given size, allowing free computation and arbitrary preprocessing. Its lower bound is uniform over which window is chosen in this reduction. The same replay budget therefore gives the displayed distance simultaneously window by window. The resulting endpoint files need not agree across windows. Adding the distances would count work in different runs. [Ko, Theorem 1.1 and §2.2](https://arxiv.org/pdf/2611.11508) · [Replay bounds and blank initialization](one-bit-sat-pairs-after-optimal-trace-realignment.md)
