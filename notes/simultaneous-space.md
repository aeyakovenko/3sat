# Which time and space bounds must hold on the same computation?

**Research journal, 2026-11-24.** A linear-time SAT algorithm would accelerate reachability when both the configuration size and the logarithm of the running time are small. This gives a conditional separation for a language already known to have a fast algorithm and a different small-space algorithm. For one writable tape, a separate crossing-sequence argument charges the actual distance traveled by the writable head and can dispense with an a priori time bound.

## A fixed hard source with two separate upper bounds

Let J be a fixed binary word-RAM diagonal. On input x of length n, read the prefix-free code e of an ordinary deterministic logarithmic-word RAM and simulate it on the *whole* x for at most n^(49/40) universal steps. Return the opposite bit on timely completion, defaulting to one on timeout. Use a fixed instruction set with polylogarithmic bit-cost operations and encode the simulated word-width constant. A sparse trie and interpretation of fixed e cost poly(log n) per simulated step. Globally cap the interpreter itself, including setup, to keep J in O(n^(49/40)) RAM time. Thus every fixed O(n^(6/5))-time target is complemented on its entire code prefix for all sufficiently large n. [Universal diagonal convention](sparse-lengths.md)

A one-writable-tape machine simulates a t-step fixed word-RAM computation in Õ((n+t)t) time. Keep a list of at most O(t) written address/value records, of polylogarithmic width, in time order. Scan to find the latest matching write, appending new records as needed. While walking along this *one* tape, move a copy of the sought address and current register scratch from record to neighboring record at polylogarithmic cost per record. Ordinary input can be scanned on an endmarked read-only tape. The finite constants, opcodes and bit arithmetic of the fixed RAM fit this account. This is the familiar quadratic sequential-scan overhead; unlike a nondeterministic sorted-history check it supplies a deterministic one-tape computation. [Cook and Reckhow](https://doi.org/10.1016/S0022-0000(73)80029-7)

In particular J has a deterministic one-writable-tape computation of time Õ(n^(49/20)). The recent one-writable-tape two-fifths-power theorem therefore supplies J with a fixed deterministic multitape decider using Õ(n^(49/50)) work bits. Its initial-symbol access hypothesis holds for the blank writable tape and ordinary binary input by a scan with a logarithmic-space position counter. The time of this decider is unrestricted by that theorem. The reported formalization is for the source simulation, not the present consequence. [One-tape theorem](https://github.com/openai/math/blob/main/preprints/Simulating-One-Tape-Time-in-Two-Fifths-Power-Space-September-25-2026/article.pdf) · [Source formalization scope](https://raw.githubusercontent.com/openai/math/main/lean/docs/137.md)

Assume linear SAT. For every fixed nondeterministic multitape recognizer M of J, there are a constant c>0 and a fixed binary prefix p such that, on **every** sufficiently long x extending p, J(x)=1 and **no accepting path** of M simultaneously has configuration size at most n^(11/10) and time at most

    2^(c (log₂ n)² / log₂ log₂ n).

To prove this, let D decide whether such a path exists, using the bounded-reachability simulation. Its clock is A·2^O(√(L log H)+log H), where L is the logarithm of the path clock, A=n+S+L+2 and H=L+⌈log₂ A⌉+2. With the displayed cap, A=O(n^(11/10)) and log H=O(log log n). The extra exponent is O(√c·log n + log log n). Choose c small enough, with the fixed solver and M built into D, to put D inside O(n^(6/5)). Standard integer rounding or a smaller computable rational cap preserves this margin. Now take p to be D's code. On its prefix J complements D, while acceptance by D implies acceptance by M and hence J(x)=1. The two statements force J(x)=1 and D(x)=0. In particular the actual small-space decider above must take more than the displayed time on its associated slice. Discovering one algorithm achieving the two resource bounds for J on all accepted inputs would exclude linear SAT. [Reachability bound](linear-quantifiers.md)

Williams proves the multitape square-root space bound with no corresponding polynomial-time guarantee. Applying that bound after the displayed quadratic one-tape conversion would return the exponent 49/40, even before logarithms. Liśkiewicz and Loryś do give simultaneous bounds at the square-root exponent: in their one-tape model at T≥n² the deterministic simulation takes O(T^(3/2)) time and O(√T) space, and the nondeterministic version takes O(T) time and O(√T) space. At T=Õ(n^(49/20)), that space again has exponent 49/40, above the 6/5 diagonal threshold. Substituting the two-fifths exponent into the older simultaneous theorem would be unjustified. [Williams](https://people.csail.mit.edu/rrw/time-vs-space.pdf) · [Liśkiewicz and Loryś](https://doi.org/10.1137/0219034)

## A one-writable-tape simulation charged to head travel

Consider a fixed nondeterministic machine with one writable tape and a fixed number r of read-only heads on the endmarked input. Count one unit of travel for each left or right move of the writable head. Let D≥1 be a supplied or constructible travel cap. Among accepting runs with travel ≤D, take a shortest one. During a period with no writable motion, the only mutable local data are the finite control, the scanned symbol and the r read-only head positions. All other tape cells stay fixed. Repeating this tuple allows deletion of the intervening zero-travel loop, retaining all subsequent nondeterministic choices. Thus if a suitable run exists one has time U≤O((D+1)(n+2)^r). For externally supplied longer time caps one can still use the construction below, and impose the smaller of the two upper bounds when the question concerns acceptance *by* the cap. Endmarkers matter here: unrestricted read-only head positions do not have just n+2 possibilities.

Choose width b=⌈√D⌉. For each of the b translations of a regular grid on the writable tape, count crossings. Each unit writable move crosses one translated boundary, so some translation has at most D/b crossings. Guess the translation and the chronological list of at most 1+⌊D/b⌋ visits. Record the finite control, head positions, elapsed time and accumulated writable travel at boundaries, including the initial and terminal controllers. Check adjacency of intervals, monotone times and travel counters, the final accepting control, and both caps. This costs Õ((1+D/b) log(U+n+2)) bits. Crossing-sequence simulations using alternation have prior art. [Williams, Theorem 2.1 and its cited predecessors](https://people.csail.mit.edu/rrw/qbf-lower-bd.pdf) · [Shifted-grid and replay lemmas](https://github.com/openai/math/blob/main/preprints/Simulating-One-Tape-Time-in-Two-Fifths-Power-Space-September-25-2026/build/source/sections/simulation.tex)

Universally select a writable block within reach. Initialize it from the true starting tape, then scan the read-only list of visits. At each visit selecting this block, nondeterministically replay that interval on the retained b-cell buffer and fixed read-only input, verifying the prescribed outgoing controller, exact time and travel, and that the first exit occurs when claimed. The final visit may halt without crossing. Reposition read-only input heads as needed at the start of each selected visit. This test takes polynomial time in U+n and O(b+log(U+n+2)) work bits, in addition to its read-only input and list. Local choices on different blocks need not agree on any writable cells, since the blocks are disjoint. Joining the chosen replays in chronological order gives a single legal accepting run: each entry control and input position matches the preceding departure, and only the selected block changes. Counting actual travel in the replays rules out runs with many moves entirely inside their blocks that would otherwise pass the crossing-count bound.

Under linear SAT, apply the bounded-reachability simulation to this *local* nondeterministic test. For polynomial U in n+D, its read-only input length plus work bound is Õ(n+b+D/b). Its time logarithm is O(log(n+D+2)). Eliminating the extra fixed outer quantifiers over the list and the challenged block adds polylogarithmic overhead. The resulting deterministic unrestricted RAM clock for existence of a travel-bounded accepting run is

    (n + √D) · 2^O(√(log(n+D+2) · log log(n+D+4))).

For the unary H in NTIME(n¹²) outside NTIME(n^(23/2)), this implies a resource lower bound under linear SAT. For any fixed one-writable-tape nondeterministic recognizer of H in the endmarked model, and any fixed 0<ε<1, infinitely many accepted lengths have **no accepting run with at most n^(23−ε) writable moves**, regardless of how much stationary computation the recognizer permits. Otherwise test this cap on all sufficiently large lengths, hardwiring any finite exceptions. The displayed deterministic RAM time is n^(11.5−ε/2+o(1)); its nondeterministic tape simulation still beats the excluded clock. A recognizer for this actual H beating the travel bound on all accepted lengths would refute linear SAT. A general quadratic RAM-to-tape scan does not supply that improvement. [Hierarchy and RAM verification](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf) · [The same unary hard source](epoch-dictionaries.md)

Lean verifies that a shortest run cannot contain a positive-length stationary return to the same configuration and checks the finite averaging inequality for shifted grids. Replay, the machine simulations and their clocks are manuscript arguments. [Lean checks](../lean/TapeTravel.lean)
