# A locally generated proper 3-CNF for an unknown XOR shift

Let $v=2^k$. The inputs are $v$ independent bits $X_i$, $v$ claimed result bits $Y_i$, and an independent $k$-bit word $s$. We encode the relation
$$
             Y_i=X_{i\oplus s}\qquad(0\le i<v).
$$
The shift stays unknown in the CNF. For every fixed $0<\epsilon<1/2$ there is a uniform ordinary proper DIMACS 3-CNF, of length $O_\epsilon(v(1+k)^{3/2+\epsilon})$ **physical bits**, whose projection onto these inputs is exactly the relation. A packed RAM emits the file in $O_\epsilon(v(1+k)^{1/2+\epsilon})$ instructions. Each individual physical bit has a uniform $\operatorname{poly}_\epsilon(k)$-time indexer. The physical bit function has a partition into $\operatorname{poly}_\epsilon(k)$ public intervals on each of which it has an $\mathbb F_2$ extension of degree $O_\epsilon(1+\log(2+k))$ in the ordinary physical bit address. The estimates are asymptotic and inherit the large constants in the finite Fourier construction.

The input fields may be pinned to arbitrary values in an application. Their pinning files have their own size and address complexity. For the shift relation itself the construction saves an unbounded factor versus naming each switch in the optimal intact-value router, whose $vk/2$ switches cost $\Theta(vk^2)$ physical bits with ordinary names. The resulting program computes mixed values. No hierarchy verdict has been encoded by this example. ## Unknown shift via a finite-field Fourier transform

Take $H=( (-1)^{a\cdot i})_{a,i\in\mathbb F_2^k}$ over $K=\mathbb F_5$. Orthogonality gives $H^2=vI$, with $v$ invertible. The permutation is
$$
             v^{-1}H\operatorname{diag}_a((-1)^{a\cdot s})H.
$$
The $(i,j)$ entry is $v^{-1}\sum_a(-1)^{a\cdot(i+j+s)}$, equal to one precisely when $i=j+s$, with each other entry zero. Compute all $v$ control signs from $s$ using one multiplication per nonempty index $a$: remove its highest set bit $h$ and multiply the parent's value by $(-1)^{s_h}$. For a fixed $h$ there are $2^h$ such indices and the parent drops that one bit. Field values have a constant-size Boolean representation. Each finite-field operation costs a constant number of Boolean gates, including pointwise multiplication of two unknown values.

The finite-Fourier theorem applies directly since 2 is invertible in $K$ and $-1$ has order two. Its prime-radix kernel theorem also supplies the uniform template used below. The upper bound for the shift uses this preprint's upper bound. We do not infer a lower bound for the shift from its lower bound for a linear transform. There is a weaker exponent $\theta<1$ from a separate fixed transform in the September preprint. Its executed scalar operations use $\mathbb Z[i,1/2]$: the pointwise network has coefficients in $\mathbb Z[1/2]$, the basic two-coordinate kernel has $a=(1+i)/2,b=(1-i)/2$, inverse kernels use a permutation and a forward kernel, and all other array rearrangements are input-independent. The proved matrix identity thus specializes under $i\mapsto2$ into $\mathbb F_5$ regardless of the auxiliary normalized Walsh matrices in the identity's proof. Here $C=((a,b),(b,a))=((4,2),(2,4))$ and $H_1=\operatorname{diag}(1,a/b)\,C\,\operatorname{diag}(1/a,1/b)$. In the $k$-fold tensor power these two diagonal maps take $O(v)$ field operations. This gives the same shift identity with time $O(v(1+k)^\theta)$ independently of the November exponent. ## Making every batch size a power of two

Fix $\alpha=1/2+\epsilon$. The November construction gives fixed integers $A,W,\sigma$ with $\sigma/W<A^\alpha$. On $W$ arrays of $Af$ address bits, its fixed template uses $\sigma$ single-row axis calls; each transforms the $f$-bit axis over all settings of the remaining coordinates. Between calls it uses a fixed number of pointwise row operations, public rewiring, and invertible binary changes on the fixed-width columns. Spectator bits carry unchanged through this template. Scalar choices at an address come from a fixed finite table indexed by a fixed number of exponents accumulated modulo two across the columns; global powers of two depend on $f$. Over $\mathbb F_5$ these powers depend only on their exponent modulo four. These statements concern only the binary specialization and follow from the prime-radix uniformity construction and its binary implementation.

Choose a fixed $h$ sufficiently large. With $W_*=2^h=L W+d$, $0\le d<W$, run $L$ disjoint copies of the template and transform the $d$ remaining arbitrary arrays by the ordinary $A$ axis calls per array. The new call count is $S=L\sigma+dA$, and $S/W_*<A^\alpha$ for all sufficiently large $h$ because $d$ is bounded. This step prevents rounding a batch at every recursive child.

At a $k$-bit node put $f=\lfloor k/A\rfloor$. At most $A-1$ leftover bit axes are handled by direct two-point transforms. Apply the combined template with these spectator coordinates. A single direction gives $2^{k-f}$ independent $f$-bit transforms. Collect its $f$ active bits into a contiguous field. Split the remaining bits into an $h$-bit child role and a child-batch index. Outside a fixed bounded base range $k-f\ge h$, so there are exactly $2^{k-f-h}$ child batches per direction. Unused top-level roles can be zeroed. If $T(k)$ is the operation count on a whole $W_*$-role batch, this gives
$$
  T(k)\le O_\epsilon(W_*2^k)+S2^{k-f-h}T(f).
$$
The normalized recurrence has multiplier $S/W_*<A^\alpha$, hence $T(k)=O_\epsilon(W_*2^k(1+k)^\alpha)$. Materializing a fresh output name for every row of each intermediate pointwise step, including unchanged rows, adds only a fixed multiple of $W_*2^k$ outside recursion. Pointwise copies and conversion of field elements to constant Boolean circuits have the same cost. A bounded base case has a fixed finite schedule.

## Giving each physical bit a short address formula

Collect all batches having the same sequence of direction slots from the root. Call that sequence a type. With $k_0=k, k_{j+1}=\lfloor k_j/A\rfloor$, there are exactly $2^{k-k_j-jh}$ batches at a reached type of depth $j$, by multiplying the child counts. The number of types is $\sum_{j\le O(1+\log_A(1+k))}S^j=\operatorname{poly}_\epsilon(k)$. The constants here include the fixed template.

For each type, row role, intermediate slot and Boolean gate or copy inside the fixed local template, reserve its own slab. Its varying index concatenates the batch bits and that role's $k_j$ coordinate bits. The lane count is a power of two. Pointwise scalar operands use fixed role and gate tags and the same lane; a row permutation changes a tag. A binary basis change, axis gathering, spectator placement or translation is affine on the lane bits. Across a recursive boundary the parent-batch prefix stays in place: after the relevant linear address map, the inactive bits split into a batch suffix and an $h$-bit role, followed by the active coordinate. The reverse map recombines these fields. A role selected by those $h$ bits can change a fixed wire-tag field through a table on $h$ bits; this costs constant degree, as $h$ is fixed. Output tags can equivalently reserve separate fields for type, role, step, microgate and bit to avoid that table. Dummy root rows and zero buffers have dedicated constant definitions. The ordinary direct bit layers and base cases fit the same construction.

For a varying scalar table, use a fixed circuit with coefficient bits pinned at that lane. Each pin is a Boolean function of a fixed number of parities of fixed functions of one column at a time. Each column has $A$ bits. Its function has degree at most $A$; sums do not raise this degree. The fixed final lookup has bounded degree in its arguments, and the substituted pin therefore has $O_\epsilon(1)$ degree in the lane bits. Its evaluation uses polynomial work in $k$. The shifts' unknown control-sign gates have one extra slab for each highest set bit $h'$, and their parent references have constant tags and linear coordinate maps. The relation's external $X,Y,s$ get their own tags.

Give every wire a distinct fixed-width identifier consisting of its type and local tags, and its right-padded lane fields; use $O_\epsilon(k+1)$ bits. Include field lengths or separate tags so that two different domains cannot collide. Write it as an ordinary positive decimal name using a leading 7 followed by one digit, 1 or 2, per identifier bit. An ASCII bit of one digit is affine in its identifier bit. The header may give as variable bound the largest name of this width (a 7 followed by all 2s). Each binary Boolean gate first copies each operand into a distinct local variable. A copy equality is two binary clauses padded by paired signs of a fresh distinct variable. Encode the gate truth table by one proper ternary clause for each rejected input/output tuple. Fix a unary value by four proper clauses with two separate padding variables. All types, bit roles and padding variables receive separate tags. Thus equal input wires, constant operands, unused output encodings and chain endpoints do not create an improper clause. Each deterministic gate has exactly its intended output under these clauses; the auxiliary padding variables do not change the projected relation.

Use a fixed clause profile per slab. Each lane record has $O_\epsilon(k+1)$ bytes and a power-of-two physical width by adding whitespace after its clause terminator. A slab then has power-of-two length. Place the header at the beginning of a zero-offset whitespace block of the largest slab size (or increase that aligned block by a constant factor to fit the header); then write the slabs in nonincreasing order of size. Their starting addresses are multiples of their own lengths. In the header block isolate the first aligned $O(k+1)$ bytes containing the header; the remaining bytes are all whitespace. At any valid physical bit inside a slab the low $O(1+\log(2+k))$ bits select the offset in its record; the next bits give the lane directly. The selected output is constant or one bounded-degree lane bit, including a possible coefficient polarity. Summing its product with each exact offset indicator over $\mathbb F_2$ proves the claimed degree on that interval. No assertion about the degree of the union of these intervals is required. The public interval schedule has polynomial size in $k$, so the individual bit indexer can find its interval and compute the relevant digit in polynomial time.

For the packed emitter, preprocess the polynomial-size type, interval and name-field directory. To emit all lanes of one slab in numerical order, enumerate the binary or fixed-column prefix tree; maintain the partial affine reference addresses and the finite phase counters for each literal slot. Each new column contributes its fixed values in constant time after positional weights have been prepared. Where the relevant lane coordinates are interleaved, give the lane ordinal the column-major layout needed by the fixed template. The address maps for other literal operands collect bits from the same columns. The coefficient pin has just that template's column functions, while a dedicated operand-copy clause references no other varying coefficient. A fixed number of interleaved fields or binary address copies does not increase the amortized prefix traversal cost. Thus a slab uses linear work in its number of lanes plus polynomial setup in $k$; summing the latter over all slabs is still polynomial. A shared table expands each block of at most $\lfloor k/2\rfloor$ identifier bits into packed ASCII digits. It has $O(2^{k/2})$ entries, each a fixed number of native words, constructible in linear table size by appending the last digit to the prefix expansion. Each name and each padded record occupy a constant number of $\Theta(k)$-bit words. This produces the claimed physical output in $O_\epsilon(v(1+k)^\alpha)$ native time, with no per-record decimal conversion or bit scan. All constants refer to this fixed $\epsilon$.

## Implication for the unary challenger

Set $t=\Theta(vk)$ as in the physical shift family. The resulting file needs $O_\epsilon(t(\log t)^{1/2+\epsilon})$ bits; its actual generation and packed nondeterministic verification both take $O_\epsilon(t/(\log t)^{1/2-\epsilon})=o(t)$ native instructions. ## An elementary second factorization in characteristic two

Let $Z_{S,T}=1[T\subseteq S]$ be the Boolean subset-zeta matrix. With addition in characteristic two, $Z^2=I$, so $a=ZX$ is the multilinear coefficient vector of the table $X$. For a nonzero offset in each coordinate, $b\in(\mathbb F_4^\times)^k$, translating that polynomial by $b$ changes the coefficient at $S$ to
\[
   \sum_{T\supseteq S}a_T b_{T\setminus S}
    =b_S^{-1}\sum_{T\supseteq S}a_T b_T,\qquad b_T=\prod_{i\in T}b_i .
\]
Thus this translation is a diagonal scaling, an upper zeta, and a second diagonal scaling. The subset products and their inverses take $O(v)$ fixed-field operations by removing the highest bit (inversion is squaring on $\mathbb F_4^\times$). Even when some $s_i$ vanish, choose $\lambda\in\mathbb F_4\setminus\mathbb F_2$ and write the binary shift as the sum of the everywhere nonzero offsets $(\lambda)_i$ and $(\lambda+s_i)_i$. Translate twice and evaluate the coefficient table with $Z$. Upper zeta differs from lower zeta by complementing both indices; zeta over $\mathbb F_4$ operates independently on two binary coordinates. If $c_k$ is the minimum size of a two-input XOR circuit for Boolean zeta, this gives an ordinary Boolean shift circuit of size $O(c_k+v)$ without importing a faster zeta algorithm for this factorization. The November shear lemma supplies the same square-root logarithmic upper exponent for this $c_k$. The finite audit tests this factorization separately from the odd-characteristic construction. ## Local digit templates for ordinary cyclic addition

For the ordinary shift $Y_j=X_{j+s\bmod 2^k}$, the November polynomial-convolution upper bound gives Boolean circuits of size $O_\epsilon(2^k(1+k)^{1/2+\epsilon})$ as well. Decode $s$ into a one-hot vector with a binary prefix tree in $O(2^k)$ gates. A polynomial product against the monomial of the appropriate cyclic exponent and one cyclic fold yield every shifted bit exactly over $\mathbb F_2$. The following separate construction gives a **qualitative** $o(2^k k)$ gate bound together with locally simple names without importing local properties of the convolution circuit. It works from any qualitative $o(2^r r)$ circuit bound for these small cyclic shifters. [Convolution bound over every field](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-finite-Fourier-transforms-November-24-2026/build/intro.tex)

Divide the address into consecutive digits of $r$ bits and one possibly shorter digit. To find $j+s$, digit $h$ adds $s_h+c_h(j)$ modulo its radix, where $c_h(j)$ tests whether its less significant prefix overflows. As an address permutation apply these individual digit updates from most significant to least significant, at which time every less significant digit used by its test is still original. To pull an array back along the resulting permutation, apply the digit-pullback circuits to the data in the reverse order. For each digit update, fix all other coordinates. First shift the $2^r$ data bits by the common $s_h$ with the small cyclic shifter. Then select its output at position $u$ or at position $u+1\bmod 2^r$ using the one $\{0,1\}$ carry shared by that fiber. Each of these final two-way selectors costs a constant number of gates. A shorter digit uses its own shifter or a direct butterfly at cost $O(r2^k)$ for this last stage.

All carries can be given regular local wires. For the $b$ less significant bits, enumerate the comparison of a varying public $b$-bit integer to the unknown threshold $(-s_{\rm low})\bmod 2^b$, with a special zero flag for $s_{\rm low}=0$. A binary prefix tree comparing the next known digit with its corresponding unknown threshold bit has $O(2^b)$ Boolean gates for all public integers, keeping equality and strict order at each prefix. Across noninitial digits $b$ is at most $k-1$ and increases in steps of at least one, so the total is $O(2^k)$. Each level has a power-of-two family of lanes with affine parent references, and threshold arithmetic for all digits costs $\operatorname{poly}(k)$. Thus carries add $O(2^k)$ gates for the comparisons plus $O(2^k)$ selectors per digit stage.

One way to obtain a locally indexable common template is exhaustive finite Boolean circuit search. For every $r\le R=\max(1,\lfloor\frac14\log_2\log_2(2+k)\rfloor)$ enumerate circuits through the standard cyclic shifter size bound $O(r2^r)$ and verify all $2^{2^r+r}$ input/control combinations and all required outputs. Trying every ordered pair of earlier wires and binary truth table costs $2^{O(r^2 2^r)}$ operations up to polynomial factors; this includes the choice of output wires, and all sizes through $R$ take $\operatorname{poly}(k)$ time. Choose $r$ minimizing $(c'_r+2^r)/(r2^r)$ over this prefix, where $c'_r$ is the verified optimum. Under the stated small-shifter bound that ratio tends to zero. The complete main-digit cost is $O(\lfloor k/r\rfloor\,2^{k-r}(c'_r+2^r))$, the partial digit costs $O(r2^k)$, and $r=o(k)$. Collect all copies of each microgate of each stage into a slab, exposing the free high and low address fields. External input/output references insert the constant within-digit endpoint or the fixed tag of a previous gate. Carry and comparator references concatenate, truncate, or append a fixed bit to the lane fields. At stage boundaries one can give each resulting address its own output wire using a copy before fetching it from the next stage. The preceding fixed-size operand, name and padding conventions now give $\operatorname{poly}(k)$ slabs of degree $O(1+\log(2+k))$, ordinary length $o(2^k k^2)$ and packed production time $o(2^k k)$. The small-template construction does not preserve the sharp logarithmic exponent of the nonuniform convolution bound.
