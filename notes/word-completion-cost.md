# Paying for the individual outputs that a verifier misses

**Research journal, 24 November 2026.** A proof of production may cover only part of the target set at every output length. Charging the remaining words individually yields a necessary condition on such proofs under linear SAT. It also yields an unconditional interval containing many first production times on the fixed universal machine. The distinction matters because the latter theorem is about programs that print words. The project asks about algorithms that decide SAT.

## An experiment with partial evidence

Use the fixed prefix-free multitape interpreter U with a one-way program stream and deadline B(m)=2^(20m). In block j put N=2^j. At a length N≤m<2N, let P(j,m) be the set of m-bit words beginning with j zeroes. A word in P is genuine if some program of length <m prints it by B(m). A length is heavy if every word in P is genuine. In window s put b=2^s, W=2^b, J=W³ and consider J≤j<J+W. Write h=2^(j−b)+1, so a block is bad if it has at least h heavy lengths. A successful mask A_s contains at least one block that is not bad. The feedback schedule starts in phase r=1, offers the first W/2^r blocks of each window, and increases r after a success. Each phase ends at its first success. Earlier outcomes are exactly computable within the clock of the next window. Its successful masks have total normalized size 1 and its failed masks have total normalized size at most 1/2. [Definitions, Kraft bound and feedback proof](adaptive-window-lists.md)

For each length take a certified subset E(j,m) of the genuine words. Its deficiency d_m is the fraction of P(j,m) outside E. Select the h lengths with the smallest deficiencies, breaking ties by m, and call them T_j. Define

    c(j) = Σ_{m in T_j} 2^(−m) |P(j,m) ∖ E(j,m)|
         = 2^(−j) Σ_{m in T_j} d_m  ≤  1/W + 2^(−j)  ≤  2/W.       (1)

A separate request for a name of length m−1 for each uncovered word has Kraft mass 2c(j). Choosing the h smallest deficiencies minimizes that sum over all h-length choices. A common subroutine might generate several words more economically.

The first version assumes that a deterministic algorithm can find T_j, count its omissions per length and recover a requested omitted word by rank. Include the time to determine mask membership and prices through block j. The bound is 2^(αN) poly(N) on the RAM for some fixed α<5, or directly on multitapes with α<10. Counts and the ordering are decided before assigning cells for j. These margins allow the final decoder to run on U by B(m), including at the shortest m=N of the block. The separate replay variant below weakens the unranking requirement.

**Proposition.** For any such masks with infinitely many successes and finite S=Σ_s Σ_{j in A_s} c(j), the fractional part of S is Martin-Löf random. In particular this applies to the feedback masks for every timely certification algorithm E.

**Proof.** Choose one prefix-stream decoder that reads a self-delimiting integer d and runs a prefix program p on U. If p halts at time t, begin at a window s greater than t, |p|+d and a fixed clock threshold. In increasing order of windows, blocks and selected lengths m, reserve one cell of binary depth L=m−|p|−d for each word outside E(j,m) at that length. At a common m the cells are consecutive. Endpoints from any earlier m are on the current grid. Counts determine the allocation. A branch that selects a cell uses its offset in that batch to recover the corresponding word. It reads no bits past depth L in the cell field. The branch that misses a batch can continue reading at the next depth. Initial nonpositive depths are avoided by the starting window. All counters have O(m) bits through length m, and there are at most polynomially many relevant blocks and lengths in N through j. Empty batches are skipped.

Write S_t for the sum through window t. If S−S_t≤2^(−|p|−d), all cells from the starting window onward fit in [0,1). Each emitted name has length

    header + |gamma(d)| + |p| + (m−|p|−d) < m

once d is fixed sufficiently large. The simulation of p and its step count fits because the starting window is later than t. The through-j bound, the square cost of RAM simulation on tapes if needed, and the square cost of interpretation on U finish the dispatch within B(m). Every word at the h chosen lengths is then genuine. This would make every sufficiently late offered block bad. Infinitely many successes therefore imply S−S_t>2^(−|p|−d) for every halting p.

Knowing k+2 binary digits of S after the point and its fixed integer part gives a u with S−S_u<2^(−k). Sum the computable terms until the partial sum exceeds the given lower dyadic approximation minus 2^(−k−2). All halting programs of length ≤k−d have now halted by step u. From those digits a fixed machine can print a string of length k−d+1 absent from all their outputs. This gives prefix complexity at least k−O(1) for the k+2 digits, which is the incompressibility criterion for randomness. This proof also rules out a computable or dyadic S. ## A density consequence on actual failed windows

Put q_s=2^(−r_s) where r_s is the phase of window s. Set R_s=Σ_{j in A_s} c(j) on failures and zero on successes. These terms are computable with no time restriction. The contribution on the single success in phase r is at most 2^(1−r). Its sum over successful windows is a computable real by evaluating through the Rth success and using the geometric tail. By the proposition and translation by this computable sum, ΣR_s has random fractional part.

Let a(s) be the universal discrete lower semicomputable semimeasure. Bienvenu and Shen's Theorem 13 gives a constant δ>0 such that R_s≥δa(s) infinitely often. For positive terms one may apply the theorem to R_s+2^(−s), scaling by a fixed power of two into (0,1). Addition of a computable real and such scaling preserve randomness of the fractional part. The added term is o(a(s)), as there is an explicit prefix code of length log₂ s+2 log₂ log₂(s+2)+O(1). Also q_s≤C a(s): the computable sequence (2/3)q_s has sum at most one and hence is dominated by the universal semimeasure up to a constant. [Theorem 13 in Bienvenu and Shen](https://arxiv.org/pdf/1110.5028)

Consequently R_s/q_s exceeds a positive constant on infinitely many **failed** windows. On these same windows r_s=K(s)+O(1) by the coding theorem and R_s≤2q_s. Since R_s/q_s is the average of Wc(j) over j in the mask and Wc(j)≤2, a positive fraction of those blocks have Wc(j) bounded below by a positive constant. At each such block the mean deficiency on the h best lengths is bounded below as well, by (1) and hW/2^j≤2. Take *any* h genuinely heavy lengths in this block. Their average deficiency is at least the optimum. Since each deficiency is at most one, a positive fraction of these h lengths each have a positive fraction of genuine target words outside E. All constants here can depend on the fixed verifier. The windows have unbounded phase since each phase is finite. [Solovay functions and prefix complexity](https://arxiv.org/abs/1603.08351)

This yields a concrete criterion for excluding linear SAT. It suffices to give a sound proof predicate E, recoverable within the clock assuming linear SAT, for which the mask-average of the best-h mean deficiencies tends to zero over the actual failed windows. No computable rate of convergence and no completely certified length is required. An existential predicate of encoded size and construction time 2^(βN) poly(N) for fixed β<5 fits under linear SAT. To count its words, query whether at least k distinct sorted target words extending a specified prefix satisfy E. The list requires at most 2^(2N) poly(N) bits. A universally selected index checks a single listed word with the E predicate. This gives a fixed-alternation test of size 2^(max(2,β)N) poly(N), including checking the sorted list. Binary search recovers the counts and then unranking follows by counts on prefixes. The same argument permits any fixed number of alternations in E. Under cubic SAT, individually tabulating an existential E of exponent β<1 takes 2^((2+3β)N) poly(N) RAM steps and also suffices. The choices of bounds are sufficient for this construction. ## First outputs at intermediate times

Take E to consist of words actually printed by U on a name shorter than m by time 2^(3m). Simulating the fewer than 2^m candidate names and sorting the resulting words costs 2^(4m) poly(m) native multitape steps. A simulated branch requesting more than its supplied input is discarded. Building the tables for all lengths of the block, sorting, and unranking from them fit 2^(8N) poly(N) tape steps, including earlier blocks and the feedback history. Thus the preceding density statement holds unconditionally for words whose **first** short producer finishes after 2^(3m) but by 2^(20m).

A separate coding argument puts a quantitative mass of first outputs inside a narrower interval in **every** sufficiently large phase. Write ℓ(r) for the bit length of the self-delimiting encoding of r above. There exists a fixed d such that, on the failed windows of phase r, the sum of 2^(−m) over distinct pairs (m,word) first printed by a short producer after 2^(3m) and by 2^(17m), at the selected T_j, is at least

    2^(−ℓ(r)−d) − 2^(1−r).                                            (2)

To see this, use a new decoder reading gamma(d) and the phase code for r. Begin when r starts and process that phase's missing-word requests in the same order. Each receives a cell of depth m−ℓ(r)−d while space remains. This corresponds to a normalized budget Q=2^(−ℓ(r)−d). If a batch would exceed Q, fill only its initial segment up to Q. The budget endpoint is exactly aligned on its grid at these lengths. Every assigned word has a name shorter than m for the same header calculation and sufficiently large fixed d. The early verifier and ranking procedure run in 2^(8N) poly(N) tape steps, hence these new names finish on U by 2^(16N) poly(N)≤2^(17m) at sufficiently large phases. Distinct paid words were absent at the earlier cutoff. If the phase's requests did not exhaust Q, every offered block in the phase would be bad, contradicting its final success. The one successful mask costs at most 2q_s=2^(1−r). Removing every cell spent there proves (2). With ℓ(r)=log₂ r+2 log₂ log₂(r+2)+O(1), the lower bound is eventually positive. It counts individual newly produced words by weight, complementing the [extension that produces whole heavy lengths](producer-proof-extension.md).

## Charging only genuine outputs of a single compiler

There is a stronger version of the tail argument. Allow *any* timely choice of h lengths T_j per offered block, regardless of how many words E certifies there. Assume exact counts and unranking of omissions as in the first proposition. The sum of requested prices over the offered masks may now be infinite.

**Proposition.** There is a single decoder header H, depending on the uniform procedures, with the following property. At each chosen length count only words outside E(j,m) that some name shorter than m with header H actually emits by B(m). Let a_s be the sum of their weights 2^(−m) through mask s alone, counting each (length,word) once. If the masks succeed infinitely often, Σa_s is a finite left-c.e. real with random fractional part. For the early-production test one may replace B(m) by 2^(17m) in this assertion.

**Proof.** Use the same decoder as in the tail argument, with one change. In the first batch that would overflow capacity, assign the portion that fits and stop the allocation. For each particular halting p with running time t, the unit capacity corresponds to normalized word weight Q=2^(−|p|−d). It is used exactly by the end of the first sufficiently late successful mask: otherwise every word outside E on the h chosen lengths of its good candidate would receive a short name before capacity ran out. On that candidate this is impossible. Exact exhaustion follows because the budget endpoint is aligned at each assigned depth. Every paid pair is distinct for this p, lies outside E, and has a short name with the fixed decoder header followed by the fixed gamma(d). Take this combined prefix as H. The deadline calculation holds uniformly for all halting p since windows at or before time t are skipped. Thus Σ_{s>t} a_s≥Q. Different p need not produce disjoint sets; this inequality is used separately for each p. Across all windows, select one actual producer per counted pair. Kraft's inequality and |name|≤m−1 give Σa_s≤1/2. All terms are computable by finite simulation, however expensive. The cutoff-from-digits argument above now proves randomness. Non-strict inequality in the tail lower bound suffices, since one uses a strictly smaller tail to recover the halting cutoff.

On feedback masks, the successful portion of this sum is computable by the same geometric bound. Applying Theorem 13 to its failed portion shows that a_s/q_s is bounded below by a positive constant on infinitely many failures. Since each selected length can contribute at most 2^(−j), a positive fraction of the blocks in these failed masks have a positive fraction of their h selected lengths with a positive fraction of *all target words* actually produced by H outside E. For the early test these words first appear between 2^(3m) and 2^(17m). This works even for the predetermined choice of the first h lengths of each offered block. No test of whether those lengths are heavy is needed.

For predetermined increasing lengths one can sharpen the numerical deadline. Take the first h lengths of each offered block, and form the early table for a length only when the dispatch scan reaches it. For a rational γ with 0<γ<9, simulate every short name to ⌊2^(γm)⌋ steps. Through the current length m every earlier table used a length at most m, so the cumulative tape cost is 2^((1+γ)m) poly(m). Earlier feedback outcomes take 2^o(m) steps. Compiling the stream decoder to U costs at most a square. Thus throughout this density result the first short production time can be required to lie in

    ( ⌊2^(γm)⌋, 2^(2(1+γ)m) poly(m) ].

In particular at γ=3 the upper endpoint is at most 2^(9m) for large m. Selecting the best lengths instead requires computing their prices throughout the block, accounting for the larger endpoint in (2).

This refines the SAT criterion. It would suffice for a uniformly timely sound certificate to miss a vanishing fraction, averaged over the masks and chosen lengths on failures, of all target slots occupied by genuine words. It would even suffice to establish this bound specifically for the words produced by the decoder constructed from the alleged SAT solver and that verifier. The decoder itself unpacks a rank among words declined by the verifier. The paid image of one fixed decoder can in fact be recognized efficiently by reconstructing its allocations. Enlarging E to include this image changes the omitted set used by the decoder. The new coverage requirement refers to that changed decoder. ## Paying before replaying an expensive common computation

More generally a timely algorithm can declare h lengths and a budget of D_m≤|P(j,m)| cells at each chosen length. The actual certified words need not be decidable on that fast scan. Require a replay algorithm *at a selected m* which, on the rank in its batch, recovers every word outside the certified set using some rank below D_m. Unused ranks can be rejected. The replay together with dispatch must finish within B(m) on U, and the certified set must consist of genuine words. The preceding tail proof applies verbatim with c(j)=Σ_m 2^(−m)D_m. One never replays a shared computation merely to skip its cells.

For example, let M=2^(m−j), and suppose a genuine short-name template has M suffixes. In the suffix map merge k≤M/2 disjoint pairs, leaving all other inputs fixed, then XOR all outputs with an expensive shared key. Every key leaves exactly k omitted outputs. If k>0, no particular output is guaranteed across *all* keys, since shifting one omission places it at any specified value. The price declaration k is still exact. Replaying the actual key once on the selected length enumerates all k omissions. This works for genuine templates: for instance take a prefix code for u, put j=2^u, read j−|code(u)|−a offset bits to select m starting at 2^j, and then read m−j suffix bits. For large fixed a the whole name including the interpreter header is shorter than m. The template may run a fixed 2^(7m)-step tape computation to obtain its shift, using a default value if the computation times out. After compiling to U this fits B(m). For the replay, the key can be regenerated and the shifted omitted symbols recovered by rank within the same margin. This example shows the price can be known before the key. Its fixed length-selection rule supplies no coverage guarantee on the required feedback masks.

The missing mathematical step is to prove vanishing missed genuine mass for a timely verifier on the actual failed masks. A timely declared budget with vanishing average and a replay covering the unverified words would also suffice. The algebraic example identifies one family on which the pricing works. The unconditional production-time interval (2) does not provide such a verifier.
