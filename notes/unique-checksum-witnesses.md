# Satisfying assignments and balanced checksums on one 3-CNF incidence graph

**Research journal, 24 November 2026.** Suppose explicit SAT on the packed logarithmic-word RAM takes deterministic time $O(n^k)$, $k\in\{1,2,3\}$. Put $H=1/k^2$. There is a uniform family at every sufficiently large $m$, with $M=2^m$ and common encoded formula length $N=\Theta(Mm^3)$, such that changing $O(m^2)$ designated sign positions gives the following properties.

* Every setting gives either an unsatisfiable formula or a formula with a **unique complete assignment**, including all auxiliary variables. Flipping one designated sign switches between the two verdicts. All settings share the same clause-variable incidences. For the single-index version, only $m+1$ signs vary.
* On each positive instance, any indexed description of the satisfying assignment has advice length plus worst-case lookup time at least $M^H/\operatorname{polylog}M$ in the single-index version using the exact table. The evaluator can read the actual explicit formula. Separate, arbitrarily precomputed descriptions at each positive instance are permitted.
* In the checksum version, the designated signs specify $8m$ indices and one answer bit. Under independent uniform choices of these signs the SAT fraction is exactly $1/2$. Fix $\rho,\epsilon>0$ with $2\rho+\epsilon<H$. A verdict predictor of preprocessed advice length plus query time at most $N^{H-2\rho-\epsilon}$ has agreement at most $1/2+O(N^{-\rho})$. Advice for this prediction is chosen before the varying signs. A fixed universal evaluator can charge per-arity programs, and the same exponents apply to bounded-fan-in Boolean circuits.

A second one-index version uses the [fixed-dimension coded table](biased-hard-table-lookup.md). With only $m+1$ changing signs, for every fixed $0<\eta<H$ it gives verdict-prediction agreement at most $1/2+N^{-\Theta_k(\eta^2)}$ at predictor size plus time $N^{H-\eta}$. Fixing the answer-bit input and, where necessary, complementing the verdict converts the classifier directly to a predictor for the coded table. One of the two fixed answer bits preserves its mean success. Apply the source theorem at slack $\eta/2$ to absorb encoding and simulation costs. The checksum version above uses one family for all fixed parameter choices and trades the extra sign positions for bias whose exponent can approach half of the predictor's exponent slack.

There is an information bound on the number of varying signs. For $r$ designated positions with a uniform local layout, advice can store all $2^r$ verdict bits in their lexicographic order. Reading the $r$ sign bits and indexing this table costs $O(r\operatorname{polylog}N)$ steps. Even if the positions must be supplied explicitly, $O(r\log N)$ further advice suffices. Therefore a fixed-incidence family resistant to all preprocessed cost $N^a$ needs $r\ge(a-o(1))\log_2 N$ for fixed $a>0$. The one-index family attains logarithmic order.

The [positive hierarchy witness construction](positive-witness-hierarchy.md) gives a larger exponent $1/k$ for all assignments on infinitely many positive instances. Here the whole promise family and its changing sign positions are uniform, its positive inputs are unambiguous, and its actual SAT verdict varies with the signs. These are SAT instances on both sides of the decision problem.

## A deterministic trace whose auxiliary variables are forced

Use the unary [exact table printer](output-linear-hard-tables.md), or the [coded printer with varying dimension](rare-approximate-output.md) for the biased-verdict assertion. Each writes $M$ packed bits $Y_0,\ldots,Y_{M-1}$ from an all-zero length-$M$ input within $O(M/m)$ native steps. Modify its output instruction to store each packed piece at its consecutive location in a separate workspace bank. If needed, collect the append stream into words of $2^{\lfloor\log_2 m\rfloor}$ bits using a constant number of shifts per machine word. A fixed outer loop simulates a valid clock of $O(M/m)$ instructions, using an idle state after halt. In a scheduled tail visit the whole stored output bank in ascending address order, one word per fixed-length iteration. The bit values in these returned words are the named variables $y_i$. Use equalities to an explicit block of $M$ consecutive variable names. Finally fetch the $8m$ queried bits by address in the same bank, calculate their parity and compare to a public answer bit. One-index lookup uses only the single queried bit. The number of target instructions is $T=O(M/m)$ since $8m=o(M/m)$. The all-zero input needs its length and fixed input semantics only. The separate public parameter bank consists of $O(m)$ words.

Compile this deterministic acceptance computation into ordinary 3-CNF. Write proposed chronological controller and access records through the fixed clock and enforce each transition using Boolean gate equivalences. Use the actual read words as the only undetermined memory responses. Require the program's final acceptance flag. All initialization, inactive slots, idle fields, and scratch pads have prescribed values. Add one initialization record per parameter word, treating the index and answer bits as input variables. These have pins to their chosen Boolean values. A single sign per pin suffices in width-three syntax by using two copies of an always-false padding literal and pinning that common constant once. Control and arithmetic gates, including division if used, are deterministic Boolean circuits with $O(m^2)$ gates per operation. Division can use a quadratic restoring circuit. Interpret every Boolean circuit with equivalence clauses, so its internal wire values are forced.

Sort a copy of all access and initialization records by bank, address and native slot-time order using Batcher's bitonic sorting network, with pads and a prescribed comparison result at ties. Check the initial value and the predecessor condition at every address group. Deterministic sorting removes the multiplicity of existential switch settings in a free routing network. The adjacency checks imply that each load returns the preceding stored word or its known initial value. Induction on instruction time now identifies the sole chronological log, even when an address uses a previous reply. For fixed parameter pins there is exactly one extension through *all* trace, sort, gate and output variables before the verdict test. Require every declared variable to be an actual field, wire or pinned constant. Filler clauses can repeat an already satisfied condition. The remaining constraint passes exactly when $b=\bigoplus_j Y_{i_j}$. For each tuple precisely one setting of $b$ passes. [Batcher's sorting network](https://doi.org/10.1145/1468075.1468121) · [Packed ISA and local layout](packed-band-transfer.md) · [Finite pin and slot implications](../lean/PositiveWitnessSlots.lean)

The sorter has $O(T\log^2 T)$ compare-exchange cells on $O(m)$-bit records, each using $O(m)$ Boolean gates. Thus there are $O(Mm^2)$ gates including the native part and output equalities. Binary variable indices cost $O(m)$ bits per clause. One may pad to $\Theta(Mm^3)$ encoded bits using a fixed rectangular layout with dummy clauses. A stage is indexed by two logarithmic loop counters and a wire. Its partner wire is obtained by flipping one address bit, and its direction from a further wire bit. Gate positions within an instruction template or comparator can be found in $\operatorname{poly}(m)$ time. Families, field offsets and small exceptional widths can be precomputed in $\operatorname{poly}(m)$ setup. Generating a word receiving a variable pin costs additionally a read from the $O(m^2)$-bit parameter array. Consequently a predictor's random access to the whole formula can be emulated from the parameters with $\operatorname{poly}(m)$ overhead per probe. Formula generation does not simulate the table printer. The large word addresses used by the printer are data in its Boolean trace. The size bounds charge explicitly written variable names.

Given a local witness description for one positive single-index instance, hardwire its $m+1$ parameter bits and call the description at the name of $y_j$ to retrieve $Y_j$. The formula remains available through its local generator. Since the sum of description size and query time grows by at most a fixed polylogarithmic factor, the exact table lower bound proves the per-instance assertion. The same extraction works after supplying $O(m^2)$ parameter bits per candidate for the checksum version, using the appropriate source table and hardness statement. Bulk production of the witness remains possible in $M\operatorname{polylog}M$ deterministic time by storing the true trace, evaluating every sorting/gate wire and emitting all variables. Its required workspace or local indexing cost is a separate issue.

## Amplifying the verdict by changing only signs

The varying-dimension code produces one sequence $Y$ with uniform-index accuracy less than $3/4$ against all predictor costs up to $M^{H-o(1)}$ in the precise sense of the [parameterized bound](rare-approximate-output.md). It is enough to use that bound against one fixed evaluator capable of simulating a majority of the predictors below. Use the binary values $0$ and $1$ as bits. Write $t=8m$ and $\alpha=N^{-\rho}$. The following finite minimax calculation gives the effect of the $t$ independent indices. It is the hard-core proof of Yao's XOR lemma with explicit charges for fixing the other query fields. [Impagliazzo on hard-core sets](https://doi.org/10.1109/SFCS.1995.492584) · [A modern analysis of XOR-lemma reductions](https://doi.org/10.4230/LIPIcs.APPROX/RANDOM.2020.10)

Take the finite class of scalar predictors obtained by fixing a checksum classifier's advice, the complement flag, the claimed answer bit, all but one index, and the true parity of the fixed indices. The remaining input is one index. The classifier may access the actual formula through the local generator. Each such scalar predictor's charged description plus time is at most $(N^{H-2\rho-\epsilon}+tm+1)\operatorname{poly}(m)$, using the advertised clock also on malformed data. Parameter strings can be hardwired independently for each scalar predictor. There exists a distribution $D$ on the $M$ indices with point probabilities at most $8/M$ under which **every** scalar predictor in the class has success at most $1/2+\alpha$.

Indeed, if each such capped distribution had a predictor beating this value, finite minimax would give a mixture of predictors whose success exceeds $1/2+\alpha$ against every capped distribution. There are fewer than $M/8$ positions where the mixture has success $\le1/2+\alpha/2$, since the uniform distribution on any $M/8$ of those positions would contradict the bound. Take $O(m/\alpha^2)$ independent draws from the mixture and return their majority. A Chernoff bound and union bound show that a single fixed choice is right on all the remaining positions. This yields uniform success at least $7/8$ at total cost at most $N^{H-\epsilon}\operatorname{poly}(m)+N^{2\rho}\operatorname{poly}(m)$. This is below $M^{H-o(1)}$ with fixed exponent slack. An interpreter can concatenate the sampled descriptions and reset the scratch for each call. This contradicts the coded table's hardness.

Each uniform index is a mixture with weight $1/8$ on $D$, since subtracting $D/8$ from uniform leaves a nonnegative measure. Make this mixture choice independently at all $t$ positions. With probability $1-(7/8)^t$ some position comes from $D$. Conditional on the choices, select its first such position and fix all *other* index values and $b$. Turning the classifier verdict into a prediction for the remaining true bit only needs the hardwired parity of the other true bits. The remaining index has law $D$. Averaging gives total success at most $1/2+\alpha+(7/8)^t/2=1/2+O(N^{-\rho})$. Indeed $(7/8)^{8m}<2^{-m}$ and $\rho<H/2\le1/2$. Circuit predictors can be given the tuple bits directly. For circuits on the entire explicit formula of sublinear size, hardwire constant formula input wires and substitute the appropriate pin bits or complements at the remaining leaves. Ordinary gate-list encoding overhead fits the slack by starting with a slightly smaller $\epsilon$.

## Asking for approximate values on the entire unique assignment

There is a longer formula version for the coded table. Set $u=\lfloor m^{1/3}\rfloor$ and $R_0=2^{2u}$. Add $R_0$ consecutively indexed copies of the $M$ variables $y_i$, with each copy linked bitwise to the preceding copy by two implication clauses. A chain suffices even under many repetitions. Unique extension and the checksum verdict stay unchanged. The $O(Mm^2)$ original variables are an $o(2^{-u})$ fraction of all variables. If a predictor on one positive formula agrees with the genuine unique assignment on more than $1/2+3\cdot2^{-u}$ of the uniformly sampled variable names, averaging fixes a single copy with agreement greater than $1/2+2^{-u}$. Its copy number and pins require $\operatorname{poly}(m)$ additional advice. Local name lookup on that copy predicts the original coded table with the same agreement. The encoded length is now $N'=\Theta(MR_0m+Mm^3)$, so the lookup lower bound remains $2^{H\log_2N'-O((\log N')^{2/3})}$ after increasing the constant in the subtracted term to absorb local simulation overhead. Approximation here is measured on the uniformly random variable of the *whole* assignment. The earlier version has a smaller encoding and hard designated coordinates. These are conditional obstructions to a general inexpensive witness-extraction scheme. A decision-only algorithm can still use unrestricted work memory. Priority of these constructions at the stated parameters is unestablished.

## Bounded occurrence without computing inverse wire lists

There is a bounded-occurrence variant of each family above. It retains the changing sign positions, the verdict distribution and uniqueness. An extra uniform conversion costs only a fixed power of $m$. It also permits exactly three distinct variable names in every clause. In particular the logarithmic-order lower and upper bounds on the number of changing signs coexist with bounded variable occurrence.

Given the base formula with $Q=O(Mm^2)$ literal occurrences, give each occurrence its own bit and make each base clause act on its three private occurrence bits with the original signs. Retain one more bit for every old variable as its master. Build a record per occurrence and per master consisting of its binary **fixed** old name and its bit value. Sort the records by old name with a deterministic bitonic network and require adjacent equal names in the sorted list to have equal values. Fix all padding records to dummy values at out-of-range names. A satisfying master assignment has exactly one extension, since all occurrence bits in its group must equal the master bit, and every sorting wire is functional. Conversely the masters in any satisfying new assignment satisfy the old formula. Thus the exact designated $y_i$ survive at consecutive master names. A local clause generator gets the old name for each independent record by one call to the base layout. It need never enumerate all occurrences of an old variable or invert a fanout list.

Each sorter comparator uses $O(m)$ bounded-fan-in gates on the name and bit fields. For bounded fanout, compute the comparison flag once and broadcast it through an explicit binary copy tree to its $O(m)$ data-bit selectors. The other bit wires in a ripple comparison or a bit selector have constant fanout. Each sorting wire is read only by the next network cell, or a constant number of neighboring consistency checks in the final layer. Use separate private Boolean constants for each record or gate template that needs them. This makes the number of occurrences of each Boolean circuit variable in its gate-equivalence clauses bounded by an absolute constant. Occurrence and master inputs enter one local record, plus at most one data clause. The regular stage, comparator, and broadcast-tree gate labels still have $\operatorname{poly}(m)$ local lookup. With $O(Q\log^2 Q)$ comparators and $O(m)$ gates per comparator, the new encoded length is $O(Mm^6)$, which changes the polynomial exponents in $N$ by $o(1)$ and the exact lookup bounds by only polylogarithmic factors.

For strict width three, first drop repeated copies of an identical literal in each definition clause, omitting tautological definition clauses. To fill one or two missing slots, use distinct false literals from a fresh private triple. Force that triple to the all-false assignment by adding the seven distinct width-three clauses which each exclude one of the other seven assignments. Every such clause uses three distinct names. The old data clauses already use separate occurrence bits even when their original names repeat. Equivalence of those bits is enforced only through the sort, so each variable parameter still changes just the sign of one data occurrence. In the version with many witness-bit copies, first convert the initial formula, then add the equality chains. Strict width three for these chains can also use the following locally reusable format to preserve the density of hard witness coordinates.

For each copy link from $y$ to $z$, introduce no auxiliary bits: select a third *data* bit $w$ with a different name, and use $(\neg y\vee z\vee w),(\neg y\vee z\vee\neg w),(y\vee\neg z\vee w),(y\vee\neg z\vee\neg w)$. These clauses force $z=y$ for either value of $w$. Choose $w$ in the same copy row as $z$ at index $i+1$ modulo $M$ for the link at index $i$. Then $w$ differs in name from $y,z$ and every coordinate is used in constantly many links. All but an $o(2^{-u})$ fraction of the final variables are again the repeated hard bits, since the bounded-occurrence starting formula has only $M\operatorname{poly}(m)$ variables. No constant-padding bits dilute that fraction.
