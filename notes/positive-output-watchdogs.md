# Cumulative memory before a satisfying assignment appears

**Research journal, 24 November 2026.** Consider an arbitrary deterministic RAM that prints assignment candidates for explicit 3-CNF. On every satisfiable formula it eventually finishes printing a satisfying assignment. It may print invalid assignments before that point, run forever afterwards, and behave arbitrarily on negative inputs. Its output is append-only and cannot be read back as free working storage. Let $E$ include the instruction completing its first valid candidate and charge

$$K=\sum_{t<E}(1+\#\{\text{nonzero writable words before step }t\}).$$

For each fixed $c<(1+\sqrt5)/2$, the worst-case $K$ **on satisfiable inputs** is outside $O(N^c)$ for $N$ encoded formula bits. A printer need never identify the successful candidate. The theorem also holds for a deterministic SAT recognizer that signals only on satisfiable inputs, charging its work until the first signal. No cap is imposed on negative executions, and candidate output storage plays no part in the cumulative charge. The corresponding negative-result theorem uses low-memory snapshots of actual UNSAT runs. The construction here builds a sound negative recognizer from a promise only about the positive ones. [Negative cumulative theorem](cumulative-sat-memory.md) · [Prior cumulative-memory framework, Beame and Kornerup](https://arxiv.org/abs/2301.05680)

Use the fixed-width explicit encoding with a declared, polynomially bounded variable range $[v]$ and word-sized variable and clause indices. In the basic output convention, each successive block of $v$ bits is a complete assignment in variable-index order. Unused final bits in a last partial block never finish a candidate. One instruction appends $O(\log N)$ bits. The proof needs only the fixed-width hard subfamily below, also when the algorithm handles more general encodings. Successive point edits are handled by the separate [proof using a gap reduction](gap-edit-watchdogs.md).

## One failed clause per completed candidate

Assume a positive upper bound $K\le C N^c$, enlarging the clock constant to cover small lengths. Rational exponents can be taken slightly larger within any strict inequality used below. Fix a public integer budget $B=\Theta(N^c)$ at least this upper bound. A dyadic upper approximation can be calculated in polylogarithmic time. Before simulating an instruction, charge one plus the nonzero count. Stop before an instruction that would exceed the budget. When a store changes a zero to a nonzero word or conversely, update the nonzero count using the old value and the new value. Keep the cumulative count, packed output cursor and a constant number of monitor words in separate banks. All counters have $O(\log N)$ bits for the fixed polynomial clock. This bookkeeping costs constant or polylogarithmic time per native step and at most polylogarithmic extra space.

At the start of each assignment guess the index of a clause. Read its three literals from the immutable formula. While the bits arrive, record only the three specified coordinates, including repetitions. If the complete assignment falsifies this clause, continue to the next candidate. Otherwise fail the branch. If the printer halts, or the next instruction would exceed $B$, signal UNSAT on any branch that has validated every *complete* candidate as invalid. An incomplete last block needs no challenge. An instruction that finishes one or more blocks inside budget processes every completed block before the test may signal. A deterministic stream containing a valid candidate by the budget kills every branch that reaches that candidate. This proves soundness on satisfiable inputs regardless of which indices are guessed. On an unsatisfiable input, choose a false clause of each complete candidate. The branch survives and signals even if the printer itself would run forever. Input cases with an empty variable range or a syntactically constant formula can be decided separately.

This is an ordinary sound nondeterministic reference UNSAT recognizer in $N^{c+o(1)}$ time on all negative inputs. Online guesses do not require storage of all previous clause indices. For a sound deterministic positive signal, simply fail if it occurs and allow a negative signal at timeout or an explicit negative halt. This version needs no guesses. Typically the constructor of a SAT witness has no sound signal on negative inputs, which is why the clause tests are necessary.

## Paying for all guesses on the hierarchy formulas

For a stronger simulation we must replay an individual negative run *deterministically* from its selected checkpoints. On the locally generated bounded-computation 3-CNF from a source of clock $R$ and public input length $m$ words, set $H=\max(2,m,R)$. The regular formula has $N=H^{1+o(1)}$ encoded bits and can declare at least $H$ variables that occur. If necessary append $H$ fixed-stride tautological clauses on distinct fresh variables. Both their positions and literal indices are locally computable and preserve satisfiability. Each full candidate therefore costs $\Omega(H/\log H)$ output instructions. At most $H^{c-1+o(1)}$ complete candidates occur before the cumulative cutoff, on positives or negatives alike. Their clause choices, plus a possible final choice, fit in $H^{c-1+o(1)}$ **bits**, including binary indices. The generic reference above works on other formulas even if their number of completions is much larger.

Guess this directory once on the outside of the checkpoint certificate. For a fixed directory the cutoff simulation and all clause tests are deterministic. The negative run reads one entry per candidate with a cursor. Invalid indices may fail the branch. Defaulting a missing entry to a genuine fixed clause is sound, since every completed assignment still receives the full test. On a negative input the honest run's cumulative space-time is $H^{c+o(1)}$. This charge includes the virtual formula generator's polylogarithmic scratch and counters, and uses the short source and clue directory as *read-only public data*. The outer verifier pays for guessing and passing this entire directory. It does not put a writable copy into every simulated snapshot.

Let a separate sound nondeterministic reference recognize UNSAT on negatives within $N^{d+o(1)}$ time. One may use the reference constructed above with $d=c$. As in the [complementary simulation](cumulative-sat-memory.md), start with nonacceptance of an $R$-step nondeterministic RAM test on $m$ public words certifiable in $(R^d+m^d+1)H^{o(1)}$ steps. Suppose we have instead $(R^e+m^d+1)H^{o(1)}$ for $1\le e\le d$. In each window of $H^x$ consecutive steps of an honest negative run, select the cheapest snapshot and give its sparse contents. The total size of the controller, directory and snapshot entries from these cuts is $H^{c-x+o(1)}$. A local defect requires replaying at most $2H^x+O(1)$ steps and challenging one endpoint word or controller. Its public input also contains the original $m$ words and the common sequence of clause indices. Choose

$$x=\frac{cd}{d+e},\qquad e'=\frac{cde}{d+e}.$$

If $x\le1$, the clause sequence has exponent $c-1\le c-x$, so it fits inside the snapshot payload. More generally it adds a floor $d(c-1)$ to the new work exponent. When $d(c-1)<1$, $x\le1$ for every stage with $e\ge1$, since $d(c-1)<1\le e$. Guessing and validating the payload and certifying absence of a defect then cost $(R^{e'}+m^d+1)H^{o(1)}$ whenever $e'\le d$. On dishonest guesses passing all endpoint and clause tests would prove a genuine negative signal for exactly the guessed directory. No branch on a positive formula has such a signal.

For $d=c$ in the nontrivial range $1\le c<(1+\sqrt5)/2$, the recurrence decreases from $e_0=d$ toward $d(c-1)<1$, so a fixed number of steps gives $e'<1$. The same conclusion holds whenever a separate reference satisfies $d(c-1)<1$: if $e_1\ge d$, then $c\ge2$, inconsistent with this condition for $d\ge1$. A bounded universal nondeterministic source of clock polynomially larger than $m^d$ can then have nonacceptance certified inside its own deadline, contradicting the [signed diagonal](packed-band-transfer.md). The strict margin absorbs the finitely many polylogarithmic factors. Under near-linear SAT as the separate reference, every cumulative exponent below two is consequently excluded for positive assignment enumeration. This proof gives no superlinear elapsed-time lower bound, since a linear-time RAM can incur quadratic cumulative cost.

## Failure for a stream of edits

Consider $(x_1)$, the clauses $(\neg x_i\lor x_{i+1})$ for $1\le i<v$, and $(\neg x_v)$. Repeating literals gives width three. Assignment $i$, with the first $i$ variables true and all others false, violates exactly clause $i+1$ for $0\le i\le v$. Starting from all zeroes, $v$ single-bit edits visit $v+1$ complete candidates, each requiring a different bad clause. Printing them in disjoint blocks costs $v(v+1)$ bits. The edit stream consumes only $O(v)$ word operations. The successive clause indices here do have a short description. This example defeats the output-volume bound on the number of checks; a proof charging their compressed descriptions would be a different argument.
