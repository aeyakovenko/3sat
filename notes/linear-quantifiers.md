# How far a linear SAT clock carries nested checks

**Research journal, 24 November 2026.** Excluding deterministic O(n) time for ordinary explicit SAT on the unrestricted logarithmic-word RAM would settle the project's first milestone. I tested whether that hypothesis could be contradicted by checking a long tape computation through many levels of checkpoints. The number of levels may grow with the input. The simulation below becomes useful when the configurations are short relative to the running time.

## Removing quantifier blocks uniformly

Assume a fixed deterministic RAM decides SAT in O(m) time on m encoded bits, with no limit on its workspace beyond the time bound. For a prenex Boolean formula with a circuit matrix, let s≥2 count encoded bits, including variables and quantifier lists. Eliminating an innermost block and merging its check with the preceding block increases the encoded size to at most C s(log₂(2+s))ᵃ. The transformation can be carried out within the same bound after increasing the fixed constants. They depend on the single SAT program and the encoding, independently of the block number.

Indeed, for fixed outer assignment u, testing an innermost existential block is ordinary circuit satisfiability with pins for u. For a universal block use the complement of satisfiability of the negated matrix. Use an explicit Tseitin encoding. All clause positions and indices can be precomputed. The pins have fixed slots whose sign bits are wires from u. In each case the hypothetical deterministic SAT program has exactly one verdict on the resulting input. Its bounded run admits an existentially supplied, locally checkable transcript for either sign of the verdict. For clarity, guess the O(m) successive instruction states and O(m) read/write records, including any initialized input words and their addresses. Check the fixed word operations, addresses, times and prescribed output. Sort copies of the records by (address,time,within-step order) using a fixed comparison network, and check that each read received the preceding write or the specified initial value. Use a fixed order for reads and writes of the same instruction. This costs O(m polylog m) Boolean gates, encoded bits and construction time after changing the logarithmic exponent. The word width is O(log m), each operation on words has a uniform polylogarithmic Boolean implementation, and a linear run makes only linearly many accesses. Absorbing halts allow a common clock. This verifier checks the space used by the run without imposing any separate bound on it. [Quasilinear RAM reductions, Williams](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

If the preceding block is existential, merge in the existential transcript for the desired verdict. If it is universal, merge in universally quantified bits and require that they fail to give a valid transcript for the opposite verdict. Both operations preserve truth for each assignment to the remaining free variables. This is why an auxiliary transcript eliminates an alternation even though certifying a RAM execution itself uses existential bits. The transformed matrix is an ordinary explicit circuit. Each iteration uses exactly the same fixed program to generate a new matrix. When one block remains, decide it directly. [Lean check of the two quantifier identities](../lean/LinearElimination.lean)

## A quantified reachability test with growing depth

Let N be the input length of a fixed nondeterministic multitape machine. Consider accepting runs of at most T≥2 steps using configurations encodable in S bits, with the original input available separately. Assume T and S are supplied in binary or are constructible within the stated bound. Put L=⌈log₂ T⌉, A=N+S+L+2, and H=L+⌈log₂ A⌉+2. Under the linear SAT hypothesis this bounded reachability problem has a deterministic RAM algorithm of time

    A · 2^{O(√(L log₂ H) + log₂ H)}.                           (1)

To implement it, augment configurations with a clock, disallowing new ordinary transitions after T, and give accepting halted states idle moves. Select k≥1, set F=2ᵏ and r=⌈L/k⌉. To establish a path of length Fʳ between two specified configurations, guess F−1 checkpoints, universally select one of the F consecutive pairs, and recurse on that pair. At the leaf verify one transition or an accepting idle move. Guess the final accepting configuration at the beginning, initialize the start configuration, and check validity at the leaf. An accepting run by time T pads to the required length. Conversely, induction on the levels concatenates the paths of all F subsegments. Existence of a bounded accepting run is preserved.

Represent the construction by about 2r alternating Boolean blocks with one final circuit. At each level choose the two selected endpoints from the previously selected endpoints and that level's guessed checkpoints by multiplexers. A local transition on the explicit configuration bits can be checked by scanning the configuration and, if needed, multiplexing one input symbol out of the N original bits. Alphabet, control and tape count are fixed. Range and capacity tests ensure each encoded configuration represents the claimed amount of tape. The initial encoded size and its time of construction are at most A·2ᵏ·H^{O(1)} for k≤L+1. This accounts for binary indices, every checkpoint bit, and all r levels. Each quantifier block is written once.

For clarity about uniformity, if u is the logarithm of the current encoded size (rounded up, at least two), a single elimination adds at most O(log(2+u)) to u. Initially u≤log₂ A+k+O(log H). For at most O(L) iterations, u stays O(H²): until a putative first crossing, the accumulated increase is O(L log H), which is smaller than a sufficiently large constant times H². Thus each iteration adds O(log H). Summing the construction costs, the logarithm of total time is at most

    log₂ A + k + O((1+L/k) log₂ H).

Take k=min(L,⌈√(L log₂ H)⌉), with a floor of one. This proves (1). Capping k by L also covers a very large input and very short computation. Multilevel checkpoint guessing is classical alternation trading. Here the explicit size recurrence accounts for a growing number of eliminations when the hypothesized SAT exponent equals one. I have not established priority for this quantitative specialization. [Williams, Alternation-Trading Proofs, Linear Programming, and Lower Bounds](https://doi.org/10.1145/2493246.2493249)

For example, a fixed nondeterministic machine using O(N) work bits on length-N inputs has at most 2^{O(N)} possible configurations, including head positions. A shortest accepting path repeats no configuration, so (1) would decide its language in 2^{O(√(N log N))} deterministic RAM time. For T=2^{20n}, N=poly(n), and S=2^{σn} for a fixed σ>0, the time is 2^{σn+O(√(n log n))}. The workspace condition in these examples is on the computation *being checked*. The proposed SAT solver can use unrestricted workspace throughout.

For the project's diagonal computation, the general representation of a T-step run can take order T bits per configuration. Substituting S of order T into (1) already spends the original time simply preparing the checks. Proving that sufficiently many of the actual bounded-program outputs have a much shorter checkable representation is still necessary for this route. A hierarchy theorem alone supplies no such representation. [Actual predecessor intervals](predecessor-batches.md)
