# How many affine input dimensions can a SAT run retain?

There is an ordinary 3-CNF family of encoded bit length $N$ on which **every execution of every correct deterministic word-RAM SAT solver** must discard $\Omega(N)$ independent binary dimensions to keep its intermediate registers and memory cells affine in the input. The statement permits unlimited workspace and changing read and write addresses. On the same family a globally correct solver takes $O(N/\log N)$ word steps, including recognition of the layout. The measurement distinguishes how instructions handle values, but a single dictionary lookup can consume a logarithmic number of dimensions.

## The physical family

Take $p=2^b$ for positive even $b$ and put $s=b/2$. Introduce dictionary variables $Y_v$ for all $b$-bit words $v=(a,c)$ and fix them with ordinary unit clauses to $Y_v=a\cdot c$ over $\mathbb F_2$. Units use three copies of their literal. For $p$ independently chosen names $x_1,\ldots,x_p$, build the XOR chain with first value $Y_{x_1}$ and with successive values $Z_j=Z_{j-1}\oplus Y_{x_j}$ for $2\le j\le p$, writing $Z_1=Y_{x_1}$. Require $Z_p=1$. The four clauses for $z=u\oplus v$ are $(u\lor v\lor\neg z)$, $(u\lor\neg v\lor z)$, $(\neg u\lor v\lor z)$ and $(\neg u\lor\neg v\lor\neg z)$. Each name occurring as a source for an XOR is repeated in those four clauses, in a fixed set of literal positions.

For example, with $b+2$ identifier bits use $p+v$ for $Y_v$ and $2p+j-1$ for $Z_j$. The low $b$ bits of each varying identifier are exactly the bits of its selected name. Independent polarity fields keep all other encoding bits constant. This fixed-width binary encoding has $5p-3$ clauses and length $N=\Theta(pb)$. The $D=pb=2d$ independent source bits, $d=ps$, enter every physical input bit affinely. On the occurring variables the dictionary and gate assignments are unique before the terminal pin is applied. Writing $x_i=(a_i,c_i)$, the SAT verdict is

$$
                   Q(x)=\sum_{i=1}^p a_i\cdot c_i.
$$

Varying literal identifiers inside fixed gates supplies $\Theta(N)$ source bits. Allocating a separate named unit to each source bit would spend logarithmically more encoded bits.

## Charging the real instructions

Fix a true input $x$, a fixed deterministic RAM solver and its actual sequence of instructions. Start with $H_0=\mathbb F_2^D$. At time $j$ choose an affine subspace $H_j\ni x$ contained in $H_{j-1}$. Require all executions on $H_j$ to reach the same next instruction as the true execution and require every bit of every register and of every addressed writable-memory cell in the resulting state to be affine on $H_j$. Here the cell address is held fixed **when viewing its value as a function**. The instruction is allowed to access different cells on different inputs. The read-only physical input is affine from the start. Ordinary initially zero memory and the common fixed-width registers satisfy the initial condition.

Charge $\dim H_{j-1}-\dim H_j$ on that instruction. On a given incoming flat, the least possible immediate charge is its dimension minus the largest dimension of a valid successor flat through $x$. Define the optimal **total** by minimizing the sum over nested choices, which allows ties or a larger early restriction when helpful. The lower bounds hold for every nested choice. This is a semantic quantity of the actual program on this family. It requires no algorithm for discovering a best flat.

Fixed-address affine operations cost zero. A load through a moving address also costs zero when the returned word is affine and the other state conditions hold. For instance, a table storing $u\mapsto u\oplus k$ has this property under an affine address. A store of the value already present may move freely while the entire array remains affine. At the other extreme an arbitrary word operation with $O(1)$ source words has charge $O(w)$ on a $w$-bit machine. One can fix the actual source values, the addresses of its constant number of accesses, and the values obtained there if needed, successively on the incoming flat. Fixed-address cells are affine at the start of the instruction. Once its inputs and accesses are fixed the updated state has the claimed form. This bound assumes the standard finite instruction set with bounded arity and bounded memory accesses per instruction. It allows word arithmetic, indirect loads, branches and arbitrary amounts of allocated workspace.

The charges telescope to $\operatorname{codim} H_{\rm final}$. If a common terminal instruction returns an affine Boolean bit from a register, $Q$ must be affine on $H_{\rm final}$. With separate accepting and rejecting halts, $Q$ is constant there. A convention that returns a Boolean register can be normalized by a last branch on that bit, costing at most one extra rank after it is affine. A multi-bit terminal test must itself be charged before applying the constant-verdict conclusion.

## The sharp restrictions through each input

The polar form of $Q(a,c)=a\cdot c$, grouping all left and right halves respectively, is $B((a,c),(u,v))=a\cdot v+u\cdot c$. For $Q$ to be affine on $x+U$ one needs $B|_{U\times U}=0$, by taking two differences. Nondegeneracy gives $U\subseteq U^\perp$ and $\dim U\le d$. Equality is available at every point by holding the left vector fixed. Hence **every run loses at least $d$ dimensions**, including in the affine-return convention.

For a constant verdict the maximum dimension at $x$ is exactly $d-Q(x)$, so the loss is at least $d+Q(x)$. To see the sign distinction put $q_x(t)=Q(x+t)+Q(x)$. Its signed sum is $(-1)^{Q(x)}2^d$, because summing $(-1)^{a\cdot c}$ over $c$ vanishes except when $a=0$. If $q_x$ vanishes on a $d$-dimensional $U$, then $U=U^\perp$. The signed sum on each coset $z+U$ vanishes when $z\notin U^\perp$, by the factor $(-1)^{B(z,u)}$. The surviving coset contributes $2^d$, ruling out this dimension when $Q(x)=1$.

For attainment write $x=(a,c)$. If $a=0$, all directions $(0,v)$ work. Otherwise the directions $(0,v)$ with $a\cdot v=0$ always give dimension $d-1$. If $Q(x)=0$ adjoin $(a,0)$, which is orthogonal to those directions and has $q_x(a,0)=0$. These are the two Witt indices of the translated binary quadratic form. The fixed-input codimension on which a Boolean function is constant is its classical parity certificate complexity. [Parity certificate complexity](https://people.eecs.berkeley.edu/~jswright/papers/paritykill.pdf) · [Witt indices in characteristic two](https://magma.maths.usyd.edu.au/magma/handbook/text/319)

There is also a proof directly from the fibers of a constant flat $H$. Let $K$ consist of the $v$ for which $(0,v)$ is a direction of $H$, and let $A$ be its projection to the left coordinates. Comparing $(a,c)$ and $(a,c+v)$ shows that $A\subseteq K^\perp$. Each right fiber is a translate of $K$, so $\dim H=\dim A+\dim K\le d$. For the one verdict the affine space $A$ omits zero and is a proper subset of $K^\perp$, yielding $\dim H\le d-1$. ## A matching word-time scanner

A single solver can recognize the whole template and evaluate it in $O(p)$ word operations, with $w=\Theta(\log N)$ and constant-time bitwise operations, shifts and indexed memory. Use the fixed record counts or the input header to obtain the candidate $p$, then check its power-of-two form, even $b$, physical length and all headers, including the width and variable bounds of the chosen encoding. Reject a layout match upon any discrepancy, routing that input to a complete ordinary SAT algorithm. The special decoder accepts the template only after checking *all* fixed identifiers, signs and structural bits and the four copies of each variable source field. These checks take constant word operations per clause using a constant number of adjacent packed words for each fixed-width field. The parser's cursors and field alignments depend only on the public lengths. On family inputs, the comparisons of repeated source fields agree identically.

Build a parity table for the $s$-bit words in $O(2^s)$ steps using $\pi[u]=\pi[u\mathbin{\gg}1]\oplus(u\bmod2)$ for $u>0$. In $O(p)$ steps fill a private dictionary at base zero with $D[v]=\pi[v_{\rm left}\mathbin{\&}v_{\rm right}]$ and validate every physical dictionary unit. The parity table can occupy a separate address interval. The table initialization is independent of the free input. In the chain read the suffix for each $x_i$, directly load $D[x_i]$ and XOR the results. Direct low-bit addresses avoid data-dependent arithmetic for computing table offsets. Validation and field extraction can keep every other register affine on the whole input family by using fixed shifts, masks, XORs and combinations of disjoint bit fields. Fixed parsing counters may use ordinary arithmetic. This algorithm checks and evaluates the entire promised syntax in $O(N/\log N)$ time. Its slow fallback ensures correctness on all other ordinary inputs.

The exact optimal total for this scanner with a separate terminal branch is

$$
                     d+\mathbf1[\exists i\colon a_i\cdot c_i=1].
$$

For the upper bound, at each lookup with local value zero choose the $s$-dimensional constant flat just constructed on that block. At a lookup with local value one fix its left half, making the returned value affine on an $s$-dimensional flat. The lookup charges $s$ on each independent block. If any local value is one, the last branch can fix the single affine accumulator bit. With an affine-return convention omit this last charge and use left-half fixing on every block to attain $d$ everywhere.

For the sharp lower bound with the last branch, every individual lookup result must have been affine on the final flat as well. Project its direction space $U$ to block $i$. The local quadratic is affine there, so $\dim\operatorname{proj}_iU\le s$. A final flat of dimension $d=ps$ would have to be the full product of its projected flats, each of dimension $s$. A sum of functions on independent blocks can be constant on their product only if every summand is constant on its own projected flat. Any one-valued lookup precludes an $s$-dimensional constant flat through its local point. This also explains the extra rank on some globally negative runs of this scanner.

Choosing a successor of charge at most $Cw$ at each step on a run of length $T$ gives $d\le CwT$, hence $T=\Omega(N/\log N)$ on **every** family input. The direct scanner attains this order. The result counts conditional dimensions discarded once. Their total can never exceed the original $D$ bits, and on this explicit family one word instruction can discard $s=\Theta(\log N)$ of them. Neither the encoded input family nor the rank bound separates linear, quadratic or cubic time for general SAT. Priority for the run-by-run measurement and the dictionary application is unverified.
