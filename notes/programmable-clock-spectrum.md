# Controlling exact description savings by timing alone

**Research journal, 24 November 2026.** Two efficient universal prefix machines can have exactly the same program-to-output map and agree on every shortest program length by each deadline $2^{im}$, for every integer $i\ge2$ and all sufficiently large output lengths $m$. Nevertheless, when each deadline is moved earlier by a factor of $m$, every positive exact-saving column can have a Martin-Löf random increment sum on one machine, while every odd saving has only finitely many positive increments on the other. The construction below allows independent choices at infinitely many deadlines. It uses no SAT hypothesis. It identifies a difficulty with inferring the desired clock behavior from shortest program lengths measured at the later deadlines. [Definition of the clock increments](clocked-complexity-increments.md)

## Statement

Fix $B\ge2$. Let $W_{e,i,d}$ be any uniformly computably enumerable family of sets, with $i\ge2$ and $d\ge1$. On a native prefix machine $U$, take $T_i(m)=2^{im}$, $t_{i,a}(m)=\max(1,\lfloor T_i(m)/m^a\rfloor)$ for integer $a\ge1$ and $m\ge1$. Write $K^U_s(y)$ for shortest description length by deadline $s$, using infinity when necessary. Write $E^U_{i,a,d}$ for the sum of $2^{-K^U_{T_i}(y)}-2^{-K^U_{t_{i,a}}(y)}$ over words with $K^U_{T_i}(y)=|y|-d$.

There is a family $U_e$ of efficient literal prefix-universal machines such that for each fixed $i,a,d$,

- If $B\mid d$ or $W_{e,i,d}$ is infinite, $E^{U_e}_{i,a,d}$ is Martin-Löf random.
- In every other case only finitely many words contribute a positive term. Their sum is dyadic.

The machines agree on the exact consumed programs and their outputs, including divergence. For each $e,e',i$ they agree on $K_{T_i}$ on *every* word of sufficiently large length. In particular any uniformly specified $\Pi^0_2$ relation on the pairs $(i,d)$ can be realized as the randomness pattern outside the multiples of $B$. To convert $\forall n\,\exists t\,R(i,d,n,t)$ for decidable $R$ to such a family, enumerate $s$ when witnesses have appeared for all $n<s$. A finite-sum assertion here is pointwise. It gives no uniform bound on when the last word is seen.

## A common universal part

Fix an efficient native prefix-universal stream machine $V$. Let $K$ and $K(\cdot\mid\cdot)$ refer to fixed optimal ordinary prefix machines. For $M_V(m)$, the total $V$-program weight producing words of length $m$, we have $M_V(m)\le C2^{-K(m)}$. Indeed this length distribution is a lower semicomputable semimeasure. The constant depends on the fixed references. We also use the prefix-complexity addition theorem with $K(x)$ included in the condition. [Shen, Uspensky and Vereshchagin, *Kolmogorov Complexity and Algorithmic Randomness*, Chapter 4](https://mccme.ru/shen/kolmbook/kolmbook-eng-scan.pdf)

Reserve the prefix $1^H$ for simulations of $V$, with $H$ chosen below. Behind it use the $B$ local headers of lengths $1,\ldots,B$ given by $0,10,\ldots,1^{B-1}0$. After a valid header simulate $V(p)$, buffer its output $y$, and publish only if the *full* consumed name length agrees with $|y|$ modulo $B$. Behind the longer local header $1^{B+1}$ publish unconditionally after the same simulation. Reject the unused branch. Start the simulations after a common bounded header-decoding time, count input bits and output bits as part of the common routine, and execute the same final residue calculation before publishing. The unconditional branch can wait a further fixed number of steps. Thus a successful fallback always has a strictly shorter companion on the identical payload publishing no later. Scanning headers uses no end-of-input signal. The fallback gives a fixed literal compiler with the overhead of the original efficient native simulation. The bit instrumentation and buffered publication can be done with at most polylogarithmic overhead in the native time. The generic routine is identical across $e$. [Matching-header proof](../lean/ResidueHeaders.lean)

At every deadline a shortest timely generic name has deficit divisible by $B$. The total weight of all generic names at length $m$ is at most $2^{-H}M_V(m)$ because the local headers form a prefix code. Both assertions include the unconditional branch.

## The exceptional programs

The other branch starts with $0$. Read an exact ordinary name $q$ for the canonically encoded pair $x=(i,d)$, set $k=|q|$, then read a conditional halting name $p$ with auxiliary input $(x,k)$. Invalid parameters never publish. Count the simulation steps $u_q,u_p$ in the fixed reference machines. Use a computable injective tuple code for $(x,q,p,u_q,u_p)$, with computable inverse on its range, giving an integer $r\ge100+i+d+k+|p|+u_q+u_p$. For example ordinary iterated Cantor pairing of the components, with bitstrings represented by leading-one encodings, can be enlarged by a further pairing with this lower bound. Put

$$
m=2^r,\quad h=1+k+|p|,\quad \ell=m-d-h.
$$

Consume exactly $\ell$ additional raw bits $z$ and output $0^{d+h}z$. This uses exactly $m-d$ input bits. For this tuple there are $2^\ell$ distinct outputs of length $m$ and their names have total weight $2^{-h}$. The length $m$ identifies the tuple, so exceptional programs associated with another tuple cannot compete for these words. For the same tuple $z$ is determined by the output.

Call the tuple selected if $B\mid d$ or at least $k+|p|$ distinct elements of $W_{e,i,d}$ have appeared in its first $u_p$ enumeration steps. This finite test, the reference simulations and handling the suffix and output take time polynomial in $m$ for each fixed $e$. Publish a selected tuple's output after a delay of order $2^{im}$, and an unselected tuple's output after a delay of order $2^{im-\lceil\sqrt m\rceil}$. Choose the fixed constants so that each delay uses between $c_0$ and $1/4$ times the indicated power for one $c_0>0$. A depth-first walk of a complete binary tree of depth equal to the exponent minus a fixed constant implements both delays. It uses a stack of $O(im)$ small frames, constant word operations per edge and no exponential-width counter. Here $i\le\log_2 m$. Polynomial setup costs are absorbed at all sufficiently large $m$. Publication occurs only on completion.

At the tuple's own deadline both variants are timely. Only the selected variant arrives after $t_{i,a}$ for fixed $a$ at sufficiently large lengths. At every smaller integer rate both variants arrive too late, and at every larger integer rate both arrive before its early deadline, eventually. The bounds use the gap of at least $m$ between neighboring log deadlines and $a\log_2 m=o(\sqrt m)$. These estimates are uniform over the originating rate when inspecting a fixed $i,a,e$. This proves agreement of all the specified outer complexities and agreement of the unclocked partial functions.

## Why enough of the selected words have exactly the desired complexity

Fix $x=(i,d)$, take a shortest $q$, and let $k=K(x)$. On conditional input $(x,k)$ consider lengths $n$ where the maximum halting time for descriptions of length at most $n$ strictly exceeds the preceding maximum. There are infinitely many such lengths. At a record choose a witnessing name $p$ of length $n$. From $m$ one can recover $p,n,u_p$. Simulate every conditional description of length at most $n$ for $u_p$ steps and print the first $(n+1)$-bit word absent from the outputs. This word has conditional complexity greater than $n$. Thus $K(m\mid x,k)\ge n-O(1)$ uniformly. Since $m$ determines $x$, the addition theorem now gives

$$
K(m)\ge K(x)+K(m\mid x,K(x))-O(1)\ge k+n-O(1).
$$

The constants are independent of $i,d,e$. If $W_{e,i,d}$ is infinite, the time $F(n)$ to enumerate $k+n$ distinct elements is a total computable function of $n$ with $e,i,d,k$ fixed. A conditional program of length $O(\log(n+2))+O_{e,x,k}(1)$ computes $F(n)$ and waits longer than $F(n)$ before halting. For sufficiently large $n$ its length is less than $n$. Hence at every sufficiently late record the time $u_p$ exceeds $F(n)$ and the tuple is selected. Divisibility by $B$ selects all records directly.

On these tuples the total generic weight at length $m$ is at most $C'2^{-H-k-n}$. Fix $H$ once so this is at most $2^{-h-1}$; $h=1+k+n$. Each exceptional output having any generic name of length at most $m-d$ accounts for at least $2^{-(m-d)}$ of that generic weight. Since all exceptional names together weigh $2^{-h}$, at least half of their outputs have no such generic name even with unlimited time. For each of those outputs in a selected late record,

$$
K^{U_e}(y)=K^{U_e}_{T_i}(y)=m-d<K^{U_e}_{t_{i,a}}(y).
$$

Its term is at least $2^{-K^{U_e}(y)-1}$. The terms of the column are uniformly computable nonnegative rationals, their sum is bounded by one by Kraft's inequality, and infinitely many terms dominate a fixed multiple of the universal discrete semimeasure at their indices. The computable-series term criterion gives Martin-Löf randomness. To apply the version requiring positive terms one can add a computable geometrically decreasing series whose terms are little-o of the universal semimeasure. [Bienvenu and Shen, Theorem 13](https://arxiv.org/pdf/1110.5028)

Finally suppose $B\nmid d$ and $W_{e,i,d}$ is finite. At a positive term the shortest outer name has deficit $d$, hence cannot be generic by the residue property. It must be an exceptional name for exactly this $d$. At large lengths an exceptional name can create a positive term at rate $i$ only on its own rate and only if selected. In this case $k+|p|\le |W_{e,i,d}|$, giving only finitely many pairs $q,p$. Each such pair produces finitely many words. This proves the other assertion.

## Consequence for the SAT search

Taking $B=2$, one enumeration infinite everywhere and one empty everywhere gives the example at the start. The construction changes the release time of the same actual program by a subexponential factor while preserving all the integer-rate outer complexities. The residue classes kept on every machine have bounded gaps. To use the [conditional bounded-gap result](exact-saving-blocks.md) to refute linear SAT, we would need a *single* efficient universal machine on which the gaps are unbounded. Choosing a different modulus for each desired gap does not supply that machine. The fixed literal fallback here is longer than every residue header, so this particular construction uses a finite modulus. The general lower bound for SAT remains open in this journal.

## Removing the requirement of a common residue class

There is a second realization theorem. Suppose $S(i,d)$ is any $\Pi^0_2$ relation on integer rates $i\ge2$ and positive savings $d$, and for some fixed $B$ every $B$ consecutive positive savings meet $S(i,\cdot)$ at every rate. Then a single efficient literal prefix-universal machine realizes **exactly** this relation as the randomness of $E_{i,a,d}$ for every integer $a\ge1$. Every false pair has finite support. The relation need not supply a computable rule choosing one true saving in each interval. The following change of the generic dispatcher replaces the divisibility rule. The preceding stronger agreement of the outer complexities was proved for the common-residue family.

Take an enumeration $W_{i,d}$ infinite exactly for the true pairs. Treat every nonpositive saving as true, enumerating a new element every step there. Each length-$B$ interval in the signed integers now contains a true candidate. Use the same generic headers as before. On every header, run the identical core $V(p)$ and collect its native running time $v$, the consumed payload length and output length. Put $s=2+v+|p|+m$. Estimate the rate by the nearest integer to $\lfloor\log_2 s\rfloor/m$, clamped below at 2 (ignore empty outputs). Compute the $B$ signed deficits for the short headers using this same payload. For each deficit count distinct enumerated elements at the estimated rate by stage $m$, and choose a candidate with largest count, breaking ties by header length. Implement the enumeration on a standard stream enumerator, one transition per stage, and count distinct completed outputs within those $m$ transitions by storing and sorting the tokens. The total work is $m\,\mathrm{polylog}(s)$ since the aggregate bit length of the tokens is $O(m)$ per candidate and $B$ is fixed. Indices and counters need $O(\log s)$ bits. For uniform enumerations by a machine with the indices on an input tape, supplying their binary representations costs $O(\log s)$.

Allow the winning short header and the unconditional literal fallback to publish promptly. Synchronize their schedules as before, including the same winner calculation on both. Add a common $s$-step wait. The resulting publication time $\tau$ satisfies $s\le\tau\le s\,\mathrm{polylog}(s)$ up to a fixed upper constant. Output length and input consumption in the native model cost at least one step per machine word or stream bit, so the generic compiler retains polylogarithmic simulation overhead. Other short headers can publish the same word after an additional $2^{m^2}$ steps, beyond every fixed rate at all large lengths. This version can thus keep identical unclocked program-to-output maps across the choices of enumeration. The special branch uses the enumeration test alone, including for multiples of $B$.

Fix $i,a,d$ with $S(i,d)$ false. If a prompt generic name of deficit $d$ realizes a positive term at rate $i$, its publication time is in $(t_{i,a},T_i]$. At such times $\log_2 s/m=i+O((a\log m+\log m)/m)$, by the displayed running time bounds with $i,a$ fixed. Thus the rate estimate eventually equals $i$. The fallback always has a strictly shorter winner by the same time. For a winning header to have deficit $d$, the associated interval must be one of just $B$ intervals containing $d$. In each, the false candidate's count is bounded while a true candidate's count goes to infinity. After one finite stage $d$ loses in *all* these intervals. This rules out any such generic name at large lengths. A late short header cannot interfere either. The exceptional branches at false pairs have finite support by the preceding proof. At true pairs the record and mass argument is unchanged, including its uniform choice of $H$ because the total generic name weight has the same bound. This establishes the realization claim.

This attack leaves a sharp distinction. A bounded-gap hypothesis suffices to implement the dispatcher even when the possible choices in those gaps encode undecidable information. Dropping the bound would require an efficient literal fallback with an unbounded supply of *shorter* competitors or a different argument controlling its timely outputs.
