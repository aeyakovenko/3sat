# One sign change in a forest of SAT clauses

**Research journal, 24 November 2026.** I tried to relay a solver's verdict through a very long computation while keeping the explicit query about that verdict short. A chain of signed binary clauses admits precisely such a shortcut if one can locate a sign change on the required path. I tested how much routing information this needs. Even when the endpoints are paired by the identity and one knows the exact location of the unique changed sign, identifying its starting path can compute an arbitrary iterated reversible circuit. There is a width-two example where this question is parity. The size of these explicitly expanded formulas prevents either observation from being a lower bound for the target SAT model.

## What can be checked from one internal variable

A binary clause on two distinct Boolean variables forbids one pair of values. Consider a nonempty chain of such clauses whose internal variables occur nowhere else. Two adjacent clauses use their common variable with either equal or opposite polarity. At equal polarity set that variable to satisfy both. At opposite polarity elimination gives their resolvent, a single binary clause on the two remaining ends. Equivalently, Boolean relational composition of the two four-entry tables is full in the first case and has exactly the two outer forbidden values as its missing pair in the second. Thus one same-polarity join anywhere permits all endpoint pairs. If every join is opposite, the projected relation is the clause of the two outer literals. This calculation projects out existential internal variables. [Lean verification of the composition and induction](../lean/ChainProjection.lean)

Suppose an explicit core is connected by any number $a$ of such paths, of possibly exponential lengths, with mutually disjoint interiors. Give the verifier a list of the endpoint pairs and their two outer literals. A description of each internal vertex supplies its incident signs. Assume there is a sound verifier of membership of a given vertex in a given path, complete on at least one same-polarity join of each broken path that a chosen solution needs. Guess the core assignment. For each path whose outer clause is false, exhibit a same-polarity join there and its membership certificate. The size and time of this check scale with the core, $a$, the named vertices and the actual certificate costs. There is no summand for the lengths of the paths. Soundness follows by independently extending the internal assignments. Completeness requires no certificate on paths whose outer clause is already satisfied. Computable path identifiers make the membership check direct, without indexing the vertices in traversal order. An arbitrary identifier asserted by the prover needs a sound check of its own.

For a collection of computations sharing one fixed routed forest, one can put all violated outer clauses for row $y$ in a set $A_y$ of starting paths and all broken paths for column $z$ in $B_z$. Feasibility then equals $A_y\subseteq B_z$ when the remainder of the core is satisfied. A finite-field projection handles arbitrarily many requirements per row if few distinct paths per column contain a break. The next construction pinpoints when the required common forest has been lost. [Rank and dense-set tests](column-subspace-tests.md)

## Two tracks, the same endpoints and one marked sign

Fix bits $x_1,\ldots,x_t$. Make two vertices in each layer. The $i$th transition swaps the two tracks if $x_i=1$ and preserves them otherwise. Follow the $t$ transitions by the same transitions in reverse order. Expand every directed edge $u\to v$ into the single clause $\neg u\lor v$. This is a forest consisting of two disjoint paths, and each start is paired with the identically named end. Add unit clauses forcing the first start true and its matching end false. Change the **incoming** clause at middle track one from $\neg u\lor v$ to $\neg u\lor\neg v$. The marked variable now occurs negatively on both sides. All other internal variables retain opposite polarities.

The resulting ordinary 2-CNF is satisfiable exactly when $\bigoplus_i x_i=1$. The middle track of the pinned path is the parity, and any path that misses the marker preserves its endpoint implication. In particular, the terminal pairing, the number of breaks and the vertex name of the unique break are identical across all these inputs. Every local switch-query certificate for either answer must inspect all $t$ independent bits, since flipping one uninspected switch changes the answer. A uniform distribution gives error one half on any decision-tree leaf with fewer than $t$ different queries. With explicit switches the parity is of course recoverable by one scan. If instead a small circuit gives $x_i$ on a binary index over all $2^r$ inputs, this same restricted succinct problem computes the parity of the circuit's number of satisfying assignments. [Lean check of mirrored switches](../lean/ChainProjection.lean) · [Independent 2-SAT checks on all 1,022 switch strings through length nine](../audits/word_path_flat_experiment.py)

There is a limitation on separating row and column dependencies even at width two. Let $g(y,z)$ be any Boolean table, index its columns by $i=1,\ldots,L$ and put $g(y,0)=0$. In the forward half set the $i$th switch for row $y$ to $g(y,i-1)\oplus g(y,i)$, so that after $i$ steps the pinned path is on track $g(y,i)$. Use an additional identity transition before reversal if needed to keep every named position internal. Column $z$ introduces the sole break on track one at position $z$, independently of $y$. The SAT matrix is exactly $g$. A local switch evaluation costs two queries to $g$. Taking the bounded program from the previous journal entry makes this an actual uniformly computable family, even if that program's table has high rigidity. A common pair of track *names* across rows is insufficient. The sets of starting paths affected by a given physical mark depend on the row's routing. ## A single known midpoint can encode an entire computation

Let $P$ be a reversible circuit on $w$ bits and $T$ a binary iteration count. First apply $P^T$ to the data, copy one specified output bit into a separate flag by XOR, and apply $P^{-T}$ to the data. This sequence is a permutation $C$. On starting state $(x,0)$ it produces $(x,P^T(x)_i)$. Follow the whole sequence by its exact inverse. The layered state graph is a disjoint union of paths and every start returns to itself. Put the unique same-polarity join at the midpoint state $(x,1)$. Pin the start $(x,0)$ to true and its own end to false. The ordinary 2-CNF on this graph is satisfiable exactly when $P^T(x)_i=1$. There is just one marked variable in the entire graph. A reversible elementary-gate list provides both directions of the local wiring, and its copy-and-uncompute design is classical. Bit queries recover the complete iterate, known to be hard for polynomial-space computation under polynomial-time oracle reductions. This implication concerns succinct graph instructions, whose explicit expansion is large. [Bennett](https://www.cs.princeton.edu/courses/archive/fall06/cos576/papers/bennett73.html) · [Eppstein](https://arxiv.org/abs/2112.11607)

One can place a fixed time-hierarchy computation in the same template and quantify the certificate needed for the SAT goal. Choose an ordinary deterministic multitape language $H$ decidable in $2^{O(n)}$ time and outside $\mathrm{DTIME}(2^n)$ on that model by the deterministic time hierarchy. Its $2^{O(n)}$-step tableau has a fixed uniform Boolean circuit of size $2^{O(n)}$. For instance encode one-tape local transitions cell by cell and time by time on a padded square array, after a polynomial-overhead tape simulation. Gate names and the local wiring take $\mathrm{poly}(n)$ time on binary indices. Initialize a known state with $x$ and zero work bits. Evaluate each circuit gate into a fresh zero ancilla using a constant number of reversible gates, copy the final answer into the flag, and uncompute all ancillas. Mirror the entire sequence and use the single midpoint break just constructed. Even though a general track now has exponentially many bits, the two distinguished states have short descriptions, and individual route-gate names have only $O(n)$ bits. No verifier gets free operations on an entire track.

Suppose there were a uniform nondeterministic verifier that on $x$ certifies this particular marked path membership only on members of $H$, certifies every sufficiently long member, and takes at most $2^{\alpha n}$ steps on every branch. Hardwire the finite exceptions. Its reduction to explicit SAT has encoded length $2^{\alpha n}\mathrm{poly}(n)$. If SAT ran in $O(m^d)$ deterministic time on $m$ encoded bits, the resulting RAM algorithm could be simulated on deterministic tapes in $2^{2d\alpha n}\mathrm{poly}(n)$ time by scanning prior writes on each RAM memory access. Thus $2d\alpha<1$ would contradict the chosen hierarchy. This gives a scale for a missing membership proof and handles unrestricted solver workspace. Producing or traversing the expanded graph would far exceed the budget. I obtained certificates for named broken paths, and no certificate with this bound for the marked path of the hierarchy computation.
