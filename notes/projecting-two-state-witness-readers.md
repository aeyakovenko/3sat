# Eliminating the hidden bits of a two-state witness reader

A layered reader has two total states, labelled 0 and 1. At layer $i$ the next state is $A_i(z)$ from 0 and $B_i(z)$ from 1, where both are affine Boolean forms in all bits $z=(x,y)$. The $v$ public bits $x$ are fixed and the private bits $y$ are existentially quantified. This permits the two states to read different literals, repeated reads, and even arbitrary parities of public and private bits in one layer. Extra absorbing states would change the model.

**Projection theorem.** Suppose a Boolean decision list has $L$ guards, each testing whether one affine bit is zero. Each successful guard and the default return an affine bit. Its existential projection onto $v$ public coordinates has a decision list of exactly the same kind with at most $\min(L,\max(0,v-1))$ guards. The bound is sharp. A polynomial-time algorithm produces the list from the coefficient vectors, including when the number of hidden coordinates is part of the input. The same algorithm, with leaf complementation, eliminates any prefix of existential and universal coordinate quantifiers in polynomial time.

Every two-state reader above is such a list. At row $i$ the state update permutes its two possible inputs iff $D_i=A_i+B_i=1$, in which case it adds $A_i$. When $D_i=0$ it resets to $A_i$. In reverse order of the rows, use guard $D_i=0$ with leaf $\sum_{j\ge i}A_j$. The default is the initial bit plus $\sum_i A_i$. This tests the unique last reset. Conversely a list can be realized with affine successor rows. Starting with its default, build the guards in reverse list order. For a guard $g=0$ with leaf $h$, replace the old state $q$ by $q+h$ and then by $g(q+h)+h$. Both updates have affine successors for each fixed incoming state. An initial reset can write an affine default. The classical width-two characterization for literal queries precedes this work. Priority for closure under existential projection and the precise length bound is unestablished. [Bshouty, Tamon and Wilson](https://doi.org/10.1016/S0020-0190(97)00204-4) · [Bergadano et al., Fact 1](https://eccc.weizmann.ac.il/report/1996/009/download/)

## Proof of projection

At any stage the still-undecided public points form an affine space $V$. The eligible lifts form a flat $S$ projecting onto $V$. The invariant is that acceptance of an undecided point equals existence of a lift in $S$ accepted by the remaining source list. Initially both spaces are full. Any affine form on a flat extends to the ambient space by completing a basis.

For a guard $g=0$ split $S$ into its zero and one slices $T,U$. An empty $T$ lets us skip the row. An empty $U$ leaves only the current leaf. Otherwise the two projected slices are either complementary hyperplanes of $V$ or both equal $V$. Indeed if $g$ is constant on every projection fiber it descends to an affine public bit. If it varies along any vertical direction, translation by that direction interchanges the two slices over every public point.

Write $h$ for the leaf at the current guard. Within the image of $T$, the points $P=\pi(T\cap\{h=1\})$ constitute the empty set, the whole image, or a hyperplane. Imposing one equation before projection loses at most one dimension in the image. The indicator of $P$ on $\pi(T)$ is therefore an affine Boolean bit.

* For complementary public slices, emit one guard selecting $\pi(T)$ and return that affine indicator there. Continue on $U$.
* If both slices project onto $V$ and $P$ is empty, continue on $U$. If $P=V$, return one on the remaining domain. In the other case emit a guard accepting $P$ and continue on $U\cap\pi^{-1}(V\setminus P)$. The complement of a hyperplane in a binary affine space is its parallel hyperplane. Every remaining public point still has eligible lifts.

For the final leaf apply the same one-equation projection on the remaining $S$. The procedure produces at most one guard per source guard. Each emitted guard reduces the dimension of the active public space by one. On a line any two Boolean answers specify an affine function, so a last split of a line folds into the default. A point needs no guard. This proves the upper bound. For sharpness use AND on $\min(v,L+1)$ public bits, with constant true for zero variables. Its algebraic degree is the number of these bits. Each guard can increase degree by at most one since the rule computes $(1+g)h+g f$ for the tail $f$. Padding with guards that always continue realizes any larger specified source length.

Gaussian elimination with private pivots ordered first implements the proof. After reduction against the current equations, a form with a remaining private coefficient takes both values over every remaining public point. The last-line fold solves the two point restrictions. Quantifier blocks may be eliminated from the inside out, permuting coordinates as needed. Universal elimination complements all leaves, projects existentially, and complements the result. Both dimension and guard count stay bounded by the original input throughout. [Symbolic compiler, exhaustive checks and sharpness tests](../audits/projected_affine_list_audit.py)

## The first failures on proper clauses

A function represented by an affine decision list either is affine or agrees with an affine bit on an entire affine hyperplane. Inspect the first effective guard. This necessary condition survives any number of hidden bits by the projection theorem. Restrictions to affine flats preserve the class as well.

For two disjoint proper clauses with positive literals the accepted public set is $R=(\mathbb F_2^3\setminus\{0\})^2$. A nonzero linear form on one block takes its two values three and four times on nonzero triples. Hence if the hyperplane normal uses one block, the slice has 21 or 28 accepted points. If it uses both blocks, the counts are $3^2+4^2=25$ and $2\cdot3\cdot4=24$. An affine bit on a five-dimensional slice accepts 0, 16 or 32 points. Thus no single two-state affine reader, of any length and with any number of hidden bits, preserves the assignments satisfying these two clauses. One clause alone is an ordinary two-state OR.

More precisely, **two proper ternary clauses admit such a reader exactly when they share at least two variable names**. Literal complementations and relabellings preserve the reader class. For exactly one shared name with the same sign, pin it false in both clauses. The restriction is $R_2=(\mathbb F_2^2\setminus\{0\})^2$. On a hyperplane seeing only one block, fix a nonzero pair from that block in the specified half. The other block leaves an OR with three satisfying inputs, which is nonaffine. On a hyperplane seeing both blocks, change bases within the blocks to write $y_1=x_1+c$. The derivative of $1_{R_2}$ in $x_2$ is zero at $x_1=1$ and is one at $x_1=0,y_2=1$. No restriction to such a hyperplane is affine. For opposite signs on the shared variable, the rejected set consists of two disjoint affine planes in five dimensions, one with the first clause’s two unshared coordinates free and one with the second clause’s two unshared coordinates free. Their directions and the difference of their base points span all five dimensions. Every hyperplane meets this eight-point set in strictly between zero and eight points. An affine bit on a four-dimensional hyperplane has 0, 8 or 16 ones. Apply this to the complement.

For the converse, each of the two forbidden patterns on its literal triple determines values on at least two common coordinates. There is a nonzero parity of the common coordinates taking the same value on both patterns. On the opposite hyperplane the formula is identically true. On the remaining hyperplane there are at most three relevant free bits. Every function of three bits has an affine decision list. To see this, if its weight is odd, the two slices obtained by fixing one coordinate have opposite weight parity. On a two-bit domain even weight is exactly the affine class. If the weight is even, the cubic coefficient vanishes. The polar form of the remaining quadratic part is alternating and has a nonzero radical in three dimensions. A plane containing a radical vector is isotropic, so the restriction there is affine. In either case the other plane needs at most one further split into lines. Smaller dimensions follow by restriction.

Four public bits are the minimum dimension of failure. The exact census gives 50,304 representable truth tables out of 65,536. The minimum number of distinct proper ternary clauses on four variables exhibiting failure is three. One example is
$$
(x_2\lor x_3\lor x_4)\land(x_1\lor x_3\lor x_4)\land(x_1\lor x_2\lor\neg x_4).
$$
Its five rejected words, with $x_1$ the least significant bit, are $0,1,2,8,12$. They form an affine basis. Every hyperplane contains between one and four of them. A hyperplane with four contains four affinely independent words, while four ones of an affine bit on a three-dimensional domain form a plane. Thus there is no affine first slice. Each proper ternary clause rejects only two words on four variables. With at most two clauses the rejected words lie in a hyperplane, leaving the opposite hyperplane constantly accepting and at most three free coordinates on the remaining side. The census finds 768 obstructing triples among the 4,960 choices of three distinct clauses. This minimality orders by the number of public variables first. Two clauses suffice on five variables by the overlap theorem. [Truth-table and clause census](../audits/affine_list_census.py)

The task solved by the reader is to tell which assignments satisfy the clauses, after giving it arbitrary extra guesses. A SAT algorithm asked only for the verdict on disjoint positive clauses can simply return satisfiable. A linear-time three-state check handles any number of those clauses on a proposed assignment.

## Adding independent constraints

Take $r\ge1$ two-state affine readers of lengths $L_i$, all required to accept the same public input and the same existential witness. The shared witness may be arbitrarily long. For each vector of last-reset locations, the jointly accepted lifts form one affine flat, possibly empty. Indeed a reset specifies a zero test, every later permutation a one test, and the resulting verdict a single affine phase equation. Each reader's no-reset case also imposes only affine equations. Their intersection projects to an affine flat contained in the public relation. Thus at most $\prod_i(L_i+1)$ flats cover that relation. Affine constraints on all variables can be imposed for free in this covering argument.

For $m$ independent positive ternary clauses the accepted set has $7^m$ public words. Every affine flat contained in it projects into a proper affine subspace in each triple, of size at most four. Its cardinality is at most $4^m$. Consequently
$$
  \prod_{i=1}^r (L_i+1)\ \ge\ (7/4)^m,\qquad
  \sum_{i=1}^r L_i\ \ge\ r\big((7/4)^{m/r}-1\big).
$$
The right side of the covering inequality grows by exactly $7/4$ for each added disjoint clause, even if each new verifier is redesigned from scratch. At linear total row count, this forces $r=\Omega(m)$, and one constant-length reader per clause attains that order. The base $7/4$ is optimal for the affine-cover count up to a polynomial factor. In each block independently choose a uniform nonzero $a$ and require $a\cdot x=1$. For every fixed satisfying word the product flat covers it with probability $(4/7)^m$. More than $m\ln(7)(7/4)^m$ independent product flats cover all $7^m$ points with positive probability. Realizing a given flat cover by readers is an additional requirement. The growth bound on the cover optimum is nonvacuous at every size. For fixed $r$ the row inequality is a necessary condition for a verifier to exist.

There is a successor inequality on the **true minimum** $\tau_m$ of the number of affine flats covering the accepted relation. Slice a proposed cover of the larger instance at each of the seven nonzero values of the last block. Each slice needs at least $\tau_m$ surviving flats and a given flat survives in at most four slices. Thus $4\tau_{m+1}\ge7\tau_m$, even when no part of an optimal cover at size $m$ is reused.

A sharper integer version comes from binary coding. Enlarge each nonempty flat to a product of affine planes $a_j\cdot x_j=1$, which is possible because each projected affine subspace avoids zero. Collect the last normals of a minimum cover of size $t$ as columns of a three-row generator matrix. Every nonzero message $u$ gives a codeword of weight at least $k=\tau_m$, since its 1 positions index a cover of the slice. The resulting binary linear code has dimension three. Griesmer's bound gives
$$
   \tau_{m+1}\ \ge\ \tau_m+\left\lceil\tau_m/2\right\rceil+
                         \left\lceil\tau_m/4\right\rceil .
$$
For a direct proof, delete the support of a minimum-weight codeword of weight $w$. Every independent word has at least $\lceil w/2\rceil$ ones outside that support, since it and its sum with the minimum word both have weight at least $w$. The residual code loses exactly one dimension. Repeat once more. [Griesmer, 1960](https://doi.org/10.1147/rd.45.0532)

Starting at $\tau_0=1$ gives $\tau_1=3$ and $\tau_2=6$ exactly. The three coordinate planes cover one block. For two blocks choose any six of the seven nonzero $a$ and use the planes $a\cdot x=a\cdot y=1$ in product form. For independent $x,y$ two different $a$ satisfy both equations, and for $x=y\ne0$ four do. Deleting any one $a$ preserves coverage. The successor forces at least eleven flats on three blocks. The probabilistic upper bound above also follows from standard integral versus fractional covering estimates. This recursion bounds a quantity that every reader must pay for. The native computation on the encoded files below uses a different operation. [Lovász, 1975](https://doi.org/10.1016/0012-365X(75)90058-8)

**Three blocks require exactly twelve flats.** Here the Griesmer inequality alone allows eleven. Index the seven nonzero labels by the three-bit integers 1 through 7 and let $M_{x,a}$ be one when $x\cdot a=1$. Over the integers $M^{\mathsf T}M=2I+2J$, where $J$ is the all-ones matrix. A column has four ones and distinct columns intersect twice.

In a six-box cover of two blocks, let $p_a$ be one coordinate's normal multiplicity and set $c=Mp$. Each $c_x\ge3$. The vector $e=c-3\mathbf1$ is nonnegative with sum three. Multiplying by $M^{\mathsf T}$ gives $2p=M^{\mathsf T}e$. Modulo two, the XOR of labels having odd $e_x$ vanishes. Thus the excess is one at each of three distinct labels $u,v,u+v$. For every $a$, at most two of these three labels have dot product one with $a$, so $p_a\le1$. This conclusion applies to each of the two coordinates of every six-box cover.

Now suppose eleven product boxes covered three blocks. On the first coordinate $c_x\ge6$, so $e=c-6\mathbf1$ has sum two. This time $2p=2\mathbf1+M^{\mathsf T}e$. The XOR condition requires the whole excess at a single exceptional label. Each of the other six slices is a six-box cover on the remaining blocks. Two of the eleven boxes must repeat the same second-coordinate normal. Their first-coordinate planes meet in at least two different labels, so both boxes occur together in at least one nonexceptional slice. This contradicts the distinctness just proved. Smaller covers are excluded by the successor inequality.

For the upper bound the following twelve triples give the three-coordinate normals of product boxes. Each decimal digit represents one nonzero normal.

$$
166,\ 277,\ 653,\ 567,\ 252,\ 546,\ 134,\ 333,\ 421,\ 715,\ 672,\ 344.
$$

Among the 343 target triples, the numbers covered with multiplicities one through seven are respectively $80,149,75,33,4,1,1$. The exhaustive check verifies the witness, both incidence identities used by the lower proof, and all eligible one-coordinate multiplicity profiles. In particular $\tau_4\ge21$. We have not established priority for the exact three-block optimum. [Finite audit](../audits/three_clause_flat_cover_audit.py) · [Lean certificate of coverage](../lean/ThreeClauseFlatCover.lean)

For the binary matrix-product graph use $D=d^2$. There are $2^{2D}$ accepted public inputs $(A,B,AB)$, and every affine flat in the graph has size at most $2^D$. Briefly, project its factor directions to a space $P$ of first-factor matrices with common kernel $K$. Polarization forces each possible second-factor direction above zero to have image in $K$. With $k=\dim K$ the two contributions to dimension are at most $d(d-k)$ and $dk$. Fixing $A$ and varying $B$ attains equality and partitions the whole graph into exactly $2^D$ flats. Hence **every simultaneous verifier in this model satisfies**
$$
      \prod_i (L_i+1)\ge 2^{d^2},\qquad
      \sum_i L_i\ge r\big(2^{d^2/r}-1\big).
$$
In particular poly$(d)$ total rows require $\Omega(d^2/\log d)$ readers. One reader is impossible at *any* length for $d\ge2$. The graph spans all $3D$ coordinates affinely, as witnessed by $(A,0,0)$, $(0,B,0)$ and the products $(I,B,B)$. Every hyperplane then meets it in strictly between zero and $2^{2D}$ points. A nonzero affine function on a hyperplane has at least $2^{3D-2}$ ones, already too many. This one-reader argument uses projection closure. The product count applies to several readers even with shared witnesses. Both proofs use the values of the product entries. General binary-wire tensor networks allow arbitrary trivalent tensors and weighted contraction, so the unrestricted bit-network volume of this graph remains open. ## The SAT verdict on physical files with at most one model

For each $m$, print an ordinary ASCII DIMACS header specifying three variables and $m+7$ clauses. Seven fixed proper ternary clauses on these variables forbid the seven assignments other than $000$. Append $m$ signed ternary records with names 1, 2, 3 in that order. In record $j$ write a space for a positive literal or a minus sign for a negative one in each of three fixed byte positions. Separate successive fields by a fixed space. Let $x_{jk}$ be the indicator of a minus sign. Every choice of the $3m$ public bits gives a valid file of the same length $N=\Theta(m)$. Each physical input bit is constant, a copy, or a complement of exactly one public bit.

The only possible assignment of the file is $000$. It works exactly when every record has a minus sign, i.e. $x\in(\mathbb F_2^3\setminus\{0\})^m$. Consequently the exponential product bound applies to **deciding SAT on the physical files**, including the promise of at most one satisfying assignment. Substitute the byte projection into every reader transition. Arbitrary affine forms remain affine, and witnesses are still freely chosen and shared. A one-reader decision procedure is already impossible at $m=2$. For each fixed positive $r$, an $r$-reader procedure valid at all lengths has $2^{\Omega(N/r)}$ total rows on these lengths. Signs from independent records supply the Cartesian product even though only three SAT variable names appear anywhere in the file. Repeating clauses in DIMACS is permitted. [Lean semantics of the seven pins](../lean/PinnedClauseMaskSat.lean) · [Actual ASCII, assignments and single-sign changes](../audits/pinned_clause_mask_dimacs.py)

There is also a version in which each public bit occurs in **one physical bit position exactly once**. Pin seven variables to the assignment with odd names true and even names false. The 21 fixed clauses come in groups of seven on triples $(1,2,3)$, $(3,4,5)$ and $(5,6,7)$, each enforcing the prescribed triple. In record $j$ write the three **positive** decimal names $2+x_{j1},4+x_{j2},6+x_{j3}$, with ordinary single separators. Each ASCII digit varies only in its low bit. Every record has three distinct names in increasing order. This removes the variable sign bytes and the two additional changing physical bits per sign in the first layout. Each input-bit flip now has Hamming distance one even on the serialized file. The fixed pins and data rows still give the same exact number of models. [Both physical encodings](../audits/pinned_clause_mask_dimacs.py)

On either family the optimal worst-case word-RAM time is $\Theta(N/\log N)$. For the lower bound set exactly one mask bit per record. Clearing it in any one record makes the file unsatisfiable. A correct program must touch each record's sensitive position on that satisfiable run, and a logarithmic word intersects $O(\log N)$ records. The first read of the last remaining sensitive word also occurs on its opposite-verdict neighbor, giving the lower bound on each verdict. For the upper bound check the header against the actual length, check the fixed prefix, then run a fixed finite automaton over the constant-width record alphabet. It checks the exact syntax and keeps whether every completed record has a true literal. A fixed globally correct SAT solver can invoke a general decision routine if recognition fails. On these files tabulate the automaton on chunks of at most $\tfrac12\log_2 N$ bits, rounded down to whole bytes. Setup costs $O(\sqrt N\,\mathrm{polylog}\,N)$ word steps and the scan costs $O(N/\log N)$. This argument uses packed inputs and standard logarithmic-word operations.

A three-state verifier on the $3m$ public signs also handles this family in one pass, recording an unmet clause, a met clause, and permanent rejection. Accepting runs never visit that third, rejecting state. Over any field a trivalent binary-wire network needs just two OR gates per triple and $m-1$ binary AND gates to join them, with a constant-size output pin if required. Thus the unique-model examples yield exponential two-state-reader bounds alongside linear exact network volume and a packed-scan RAM clock. Independent local records cannot establish the desired unrestricted time blowup by this induction.

## Verification and the unrestricted clock

A separate Lean proof checks the shared-witness count given affine acceptance cases, integral amplification by $7/4$, and both optima on one and two blocks. Lean also verifies coverage by the twelve displayed boxes on three blocks. The eleven-box exclusion has a manuscript proof and a separate profile census. The sharp guard-count refinement, the Griesmer application, the graph specialization, and the RAM clocks are manuscript arguments. They leave open the time needed by an unrestricted deterministic RAM to find any common witness or decide that none exists.
