# SAT verdicts that stay hard to read with a long public random tape

A canonical hard table can occur in every positive witness while one visible flag gives the promised decision. Here an ordinary 3-CNF instead tests a **raw indexed bit** of a canonical table. The table is selected to resist average-case prediction by short *program descriptions*. This lets us rule out fast decisions on most pin pairs, including when the solver can inspect the full public protocol tape, which may be far longer than the table. The theorem has no SAT-time assumption. Its quantitative yardstick is the number of distinct query indices. [Earlier witness-only comparison](canonical-witness-pins.md) · [Conditional isolation-tape bounds in encoded input length](random-tape-decision-witnesses.md)

Fix any positive integer $B_0$ giving a per-query work ceiling $V^{B_0}$. There are infinitely many scales $b$, with $V=2^b$ selectors, a common short parameter string and formulas $F(R,j,c)$ for a uniform public bit tape $R$, $j\in[V]$, $c\in\{0,1\}$. All formulas at a scale have the same incidence pattern and encoded length $N$, where $b\le\log_2N\le b^{O(1)}$ for large $b$. The common parameter includes the construction advice; its length is at most $2^{O(\sqrt b)}$. The physical compiler given this advice and the parameters is uniform. No method of finding correct advice in the claimed lookup time is required. There is a fixed Boolean table $g$ independent of $R$. Except with probability $2^{-3b}$ over $R$, all $2V$ verdicts simultaneously satisfy
$$
 F(R,j,c)\in\mathrm{SAT}\quad\Longleftrightarrow\quad g(j)=c .
$$
For fixed $R$, only $b+1$ sign occurrences vary. All the bits of $R$ and of the short parameter remain available to a query evaluator. The distribution is on a promised family of ordinary formulas.

For every fixed deterministic evaluator and integer $a>0$ there is a constant $K$ with the following property on these same hard scales. Except on a fraction $O(2^{-b})$ of tapes, every successful predictor of sign-one verdicts with uniform agreement at least $1/2+2b^{-a}$ exceeds the budget
$$
 (s+b+1)(p+1)\le V/b^K
$$
or the work ceiling. Here $s$ is the length of an arbitrary shared advice string chosen **after reading $R$**; $p$ counts the distinct public tape bits its computation sees per address, including those disclosed by physical formula reads. The evaluator is clocked, stateless between queried selectors, and its verdict prediction is total, for example by giving timeouts a fixed default. Malformed inputs or excessive probes also receive a default. All computational work is charged; the tape-probe budget can be substantially smaller than the work. The statement is simultaneous over budgets at a fixed scale by dyadic rounding and a union bound. Uniform agreement here uses the raw $b$-bit address, with no added checksum coordinates.

In particular, fix any correct deterministic SAT solver. On almost every tape, on all but $O(b^{-a})$ of the indices, **both** opposing formulas take longer than $V/\operatorname{poly}(b)$ to decide. More precisely, neither run can finish within the tested joint work-and-probe budget, with the constant adjusted for running both pins. This also holds for a solver on this promise that is exact on the particular good tape, provided its common advice is charged. There is no lower bound here above the encoded formula length: the physical input may have $2^{b^{O(1)}}$ bits and includes the long tape. Indexed reads then cost one native operation on $\Theta(\log N)$-bit words.

## Selecting a table by a dense property

Fix a deterministic multitape interpreter and a time cutoff $V^J$ per index, for a fixed integer $J$ taken sufficiently large below. On candidate strings of length $M$ put $b=\lfloor\log_2 M\rfloor$ and use their first $V=2^b$ bits. A binary description of length $l\le V$ defines a total table, with a default on timeout. Let $u$ count the indices where this table agrees with the candidate. Require, for every such description,
$$
  (2u-V)^2 \le 8V(l+b+2).
$$
On small dimensions one may allow every string. The property lies in coNP in $M$: guess an offending string and evaluate it at all $V$ indices to check the inequality. The interpreter includes its own overhead in its cutoff. For any fixed description, on a uniformly random candidate $u$ is binomial with parameters $V,1/2$. The probability of strict failure is at most $2\exp(-4(l+b+2))$. Summing over all $2^l$ descriptions at each length gives density greater than $1/2$. Length-dependent overheads, including a simulator program, must be counted when using this property. In particular, producing a table with agreement $>1/2+\eta$ on a hard prefix requires description length at least $V\eta^2/2-b-2$ even if the program may spend $V^J$ time per index.

Apply Chen, Li and Liang's Theorem 1.3 with their parameter $k=2$ to this property, following their §4 truncation at lengths that need not be powers of two. Their Arthur–Merlin construction selects one canonical string at each length with correct advice, and this string hits the property at infinitely many lengths $M$. Its time is $2^{(\log M)^{O(1)}}$ and the advice length is $2^{(\log M)^{1/2}}$ up to rounding. At a hard $M$ use its canonical prefix as $g$. Include $M$ and its advice in the parameter. These hard $M$ give unbounded $b$. The property is designed against a time-bounded description class, so the argument does not have to translate word-RAM accesses to a small Boolean circuit. [Chen, Li and Liang, Theorem 1.3 and §4](https://eccc.weizmann.ac.il/report/2024/182/revision/1/download/) · [Published version](https://dspace.mit.edu/entities/publication/328980f1-24af-4726-9536-cdc79ac19663)

Testing a bit of the output gives a protocol for each of its two signs by the same conformity and resiliency properties. Normalize the constant-round public-coin protocols to Arthur's one random message followed by Merlin's response, with constant completeness/soundness gap, as in the paper. Draw $O(b)$ independent bundles of coins shared across all indices and signs. Write $R$ for their concatenation. The formula asks whether responses exist accepting the chosen sign on a majority of the trials (use a fixed separating threshold in case of an asymmetric gap). On an individual sign, the existence of a successful response is then an independent Bernoulli experiment across trials. Taking a sufficiently large constant in $O(b)$ makes the probability of any error on any index and sign at most $2^{-3b}$. The same reasoning would fail on an unreduced multi-round protocol if one gave Merlin the full future tape.

Encode this bounded nondeterministic computation by a fixed-layout clocked verifier with public strings pinned at its input. The varying $j,c,R$ enter only as public sign pins. Given the scale, physical word address, and short parameters, the static clause layout can be decoded in $\operatorname{poly}(b)$ time apart from lookups into the parameter data and $R$: the time bound of the protocol and its circuit encoding have logarithms polynomial in $b$. In this layout the only physical bits that depend on $R$ are its individual pinned literal signs. To reconstruct a packed word the decoder fetches precisely those tape positions whose signs the word discloses, at most $\operatorname{poly}(b)$ positions. It can test a position against its probe budget before reading the bit. All dynamic work of the protocol is represented by trial variables and gate checks in the formula. Padding can ensure $N\ge V$. This is the usual locally indexable Cook layout, with nondeterministic choices for the responses. ## Removing the public tape without preserving its promises

Here is the more general accounting behind the displayed tradeoff. Assume the joint event of a good tape and the existence of a clocked $s$-bit advice achieving raw-bit agreement at least $1/2+2\eta$ has probability at least $\beta$. Fixing the best advice string leaves at least $\beta/2^{s+1}$ probability. On every tape this evaluator defines one Boolean function, even on timeout. Let $X$ be its uniform agreement with the fixed $g$.

Replacing independent tape coordinates by one output bit of a random degree-less-than-$d(p+1)$ polynomial over a binary extension field preserves the first $d$ moments of $X$. Indeed for every $j'\le d$, $X^{j'}$ is the probability that the same evaluator gives all correct answers on $j'$ independent addresses using one tape. Conditional on addresses, its combined adaptive transcript touches at most $j'p$ distinct tape positions. First-visit interpolation and consistency at repeat reads give exactly the original transcript law. This uses no conditioning on good protocol coins. Distinct bit addresses fit as distinct field elements of $w=b^{O(1)}$ bits when the budgets in question are polynomial in $V$. Parameters can include a defining irreducible polynomial of $w+1$ bits. [Adaptive transcript argument](random-tape-decision-witnesses.md) · [Kernel lemmas](../lean/SampledProofOracle.lean)

For $0<\eta\le1/8$ some fixed replacement has $X>1/2+\eta$ as soon as $d=O((s+\log(2/\beta)+1)/\sqrt\eta)$ with a sufficiently large absolute constant. This follows by applying the degree-$d$ Chebyshev polynomial to $X$ and separating the mass above $1/2+2\eta$ from the interval $[0,1/2+\eta]$. Independent sampled tests with a majority threshold also give the result with $O((s+\log(2/\beta)+1)/\eta^2)$ moments. The replacement tape need not preserve any SAT verdict. Only the accuracy of its resulting lookup table against the already fixed $g$ matters. [Moment separation, proof and sharpness](semantic-moment-transfer.md)

A plain program for the resulting table stores the public construction advice, the clocked evaluator and its selected $s$ bits, the field specification and $d(p+1)$ coefficients. With self-delimiting size parameters it occupies at most
$$
  O\bigl(2^{O(\sqrt b)}+s+b^{C_1}(d+1)(p+1)\bigr)
$$
bits for a fixed $C_1$. This program lies within the interpreter clock of the dense-property test. For clarity, assume $s,p,d(p+1)\le V^2$, as holds in the contradiction regime with $\beta=2^{-2b}$ and $\eta=b^{-a}$ or the exponential-precision regime below. Simulate at most $V^{B_0}$ native steps. Scan stored registers and work-memory records on tape for random accesses, at most polynomial time in $V^{B_0}$ per access, with $\operatorname{poly}(b)$ additional factors for word operations. Scanning the fixed advice fields costs at most $V^2\operatorname{poly}(b)$ per lookup. Horner evaluation for each new tape position takes $O(d(p+1)\operatorname{poly}(b))$ field-bit work up to polynomial overhead for the universal tape. Choose, for example, a direct fixed multitape interpreter simulating this bounded register-and-list algorithm by a quadratic tape simulation. A sufficiently large $J$ depending on $B_0$, such as $20(B_0+2)$ with direct tapes and schoolbook arithmetic, covers these fixed powers. The construction of $g$ may later choose its own fixed power in the word width or input decoder's $\operatorname{poly}(b)$ cost. Each such factor is $V^{o(1)}$, so there is no dependency of the chosen power $J$ on the resulting protocol runtime exponent. This accounts for the original input formula through its *virtual* word generator.

If this description is $o(V\eta^2)$ and $V\eta^2\gg b$, it contradicts the dense property at that hard $M$. For any fixed $a$ and sufficiently large $K$, the displayed budget indeed gives this contradiction at $\eta=b^{-a}$, $\beta=2^{-2b}$. There are polynomially many in $b$ dyadic choices of $s+1,p+1$ up to $V^2$. Use dyadic upper bounds to group evaluators. Store the exact integer cutoffs, each of $O(b)$ bits, with the tape-chosen advice *before* fixing an advice string in the probability argument. This preserves the evaluator’s timeout defaults. The added bits fit the $s+b+1$ factor. The union of their exceptional sets, and the bad protocol tapes, has probability $O(2^{-b})$. For the decision-time claim, simulate each pin up to the tested cap and accept its implied bit when either finishes. On a good tape all such answers are exact. Of the two possible defaults on double timeout, one gives accuracy at least $1/2$ plus half the probability of either completing. The work and probe caps grow by at most a fixed factor apart from explicit bookkeeping for distinct addresses. The no-advice elapsed-time bound can count every input access as up to $\operatorname{poly}(b)$ coin probes. For the separate distinct-probe test, a binary trie on bit addresses enforces the cap in $b^{O(1)}$ time per simulated step. For a claimed per-pin clock $V^B$ choose the construction’s master exponent $B_0=B+2$ at the outset. This covers both simulations and metering on the same family. For the stated $V/\operatorname{poly}(b)$ elapsed-time consequence a master exponent of one already suffices after enlarging the log loss.

As an example with exponentially small advantage, take $\eta=V^{-\rho}$ for $0<\rho<1/2$ and $\beta=2^{-2b}$. Any fixed $\delta>0$ of slack in the inequality
$$
(s+b+1)(p+1)\le V^{1-5\rho/2-\delta}
$$
suffices whenever the exponent is positive. The canonical advice $2^{O(\sqrt b)}$ fits below $V^{1-2\rho}$ there. This uses the square-root dependence in the moment argument. Actual pin pairs then have at most $O(V^{-\rho})$ probability of either verdict arriving within the corresponding budget on nonexceptional tapes.

## Why an inexpensive tape need not preserve the decisions

A black-box derandomization of the public messages would run into a distinct obstruction. Give an Arthur-first verifier an extra response option: accept if Merlin supplies a circuit of size at most $S$ generating the whole public random message by coordinate. Check it by evaluating it at all $L_R$ positions and comparing with the visible message, using a fixed truth-table convention for a partial last block. There are at most $2^{O(S\log(S+\log L_R))}$ such circuits. With $S\log(S+\log L_R)\ll L_R$, the extra false acceptance probability is exponentially small in $L_R$. Verification time remains polynomial in the original time when $S\le L_R$. True completeness is retained. Yet every such circuit-generated message now lets either sign pass this verifier. One may first pad public randomness by ignored uniform bits before adding this option. For repetitions supplied as separate verifier messages, a small circuit generating the full tape yields small circuits for each message after fixing the block index, with fixed padding/selector overhead; choose the threshold with that slack. This operation concerns the individual verifier/protocol presented to a black-box substitution. Statistical accuracy transfer avoids demanding that a short replacement still be a good public message.

The family uses a published nonrelativizing construction and ordinary SAT formulas. It gives actual semantic query-time and public-input-probe obstructions even if a target solver has very large worst-case time. An exclusion of deterministic linear, quadratic or cubic time still needs a clock exceeding the encoded input length to the corresponding power.
