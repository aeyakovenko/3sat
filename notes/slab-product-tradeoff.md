# Replaying separated components of a SAT computation

Let a fixed deterministic logarithmic-word RAM signal UNSAT soundly and eventually signal on every unsatisfiable input. For such an input of encoded bit length $N$, let $E$ count instructions through the first signal. Form a graph on these instructions with edges joining consecutive times. For every load from writable memory, add an edge to the instruction that last wrote its address, when such a write exists. Write $h$ for the order of the largest clique minor. On the packed RAM and explicit encoding of the [bounded-computation reduction](packed-band-transfer.md), the worst-case product
$$
 (1+E)(1+h)
$$
on unsatisfiable inputs is outside $O(N^c)$ for **every** $c<(1+\sqrt{17})/4=1.2807764064\ldots$. In particular an UNSAT recognizer whose rejecting graphs omit one fixed clique minor cannot always signal in $O(N^{1.28})$ instructions. There is no workspace restriction. The [earlier proof](pebbling-live-producers.md) obtained the exponent 1.0001 by storing overlapping blocks of a path decomposition.

The same conclusion holds after minimizing $h$ over the following choices of edges of the genuine execution. For each writable load of value $v$, choose **any** preceding write to its address of value $v$ such that every subsequent write there before the load also stored $v$. When $v=0$ and no write of a different value preceded the load, the choice may instead be initialization, with no edge. Order multiple accesses in one instruction by their native slots. Edges inside an instruction can be discarded. A legal choice always exists from the true last write or initialization. This variant measures some redundant transfers directly. In the pair-address construction with $r$ phases, writing zero once to each initially zero pair cell and later reading it yields a $K_r$ minor under last-write edges. Choosing initialization for all these loads leaves just the chronological path. Writing one to those cells instead leaves the $K_r$ minor also under the choice rule. Both programs can return a constant. [Pair-address construction](pebbling-live-producers.md)

## A short list for the cut instructions

Fix a choice graph on a genuine rejecting trajectory, and any integer $b\ge1$. There is a set of instructions $S$ of size
$$
 O((h+1)E/\sqrt b)
$$
such that every connected component outside $S$ contains at most $b$ instructions. For each component of size $u>b$, delete an $O((h+1)\sqrt u)$-vertex balanced separator and recurse on the remaining components, each of size at most a fixed $\alpha u$ with $\alpha<1$. The graph and its subgraphs exclude $K_{h+1}$. Charge each of the $u$ vertices $O((h+1)/\sqrt u)$ for that deletion. Along the chain containing a given vertex the charges sum to $O((h+1)/\sqrt b)$ by geometric shrinkage. Summing over all vertices proves the bound. Graph separators are used only to show that an honest list exists. [Conroy, Le and Spalding-Jamieson, Theorem 1](https://arxiv.org/abs/2611.00663)

A certificate gives the end time, the sorted times in $S$, complete instruction records there, and one component label for each nonempty chronological interval left by deleting these times. A record specifies the controller before and after the instruction, its accesses and its writable-load values and anchors (an earlier slot or initialization). Every consecutive pair of instructions is adjacent in the graph, so each interval has one label and there are at most $|S|+1$ intervals. Intervals with the same label may be far apart. The certificate costs $O((|S|+1)\log(E+N+2))$ bits. Use a fixed polynomial cap on the claimed time in the construction below. The verifier validates the headers, the increasing times, the partition and the $b$-step size cap per label by summing interval lengths. Adjacent or empty cut cases use just the nonempty intervals. No full list of $E$ labels is needed.

## Computing one component and checking two

For any syntactically valid certificate, its cut records and the following deterministic procedure define one proposed trajectory. For one requested component, iterate its intervals in chronological order. At the beginning of an interval use the true initial controller if it starts at time zero, or the claimed post-instruction controller at the immediately preceding cut time. Retain the component's writes between intervals. Before a writable read, take the most recent preceding write to its address in this component or among the cut records, in native slot order. Return its word and use that slot as the load's anchor. With no such write, return zero and use initialization. An ordinary immutable read uses the true input. Local native steps use these replies and the fixed machine instructions. A malformed register, address or illegal transition is a defect (equivalently totalize with a failure flag). For the cut records, validate each native step from its claimed controller and writable replies, including immutable input loads, and retain its claimed anchors. The formula is available through its local word generator when the proof is applied to a bounded source.

For an honest cut every computed component trajectory is genuine. Induct in the chronological order of its own instructions and their slots. When the chosen anchor for the read is a writer, that writer lies in the same component or in the cut, since the associated edge cannot join different components after the deletion. Every later true write before the read has the same value. Consequently the latest retained write also has that value, and all intervening true writes agree with it. For a chosen initialization its value is zero and all earlier writes there were zero. The assigned load anchor might differ from the chosen edge, but still satisfies the same value condition. Cut records can use genuine last-write anchors.

To validate the concatenation on an arbitrary guess, a defect machine selects a pair of groups, counting the entire cut set as one additional group. It obtains their records by deterministic replay, reusing the same computed records for equal groups. It can also test an individual group, initialization and the final signal. Check the following for all choices by looking for a failed test.

* At adjacent instruction times, the earlier post-controller equals the later pre-controller. The initial controller is genuine, native transitions hold, and a valid terminal signal occurs.
* For each writable read in the first group, an initialization anchor requires value zero. A noninitial anchor must be a slot in the claimed timeline strictly before the read. If its instruction belongs to the second group, that slot must actually write the stated address and value.
* For each such read, the second group may contain no write to its address **of a different value** strictly after its anchor and before the read. Initialization is earlier than every slot.

Every timeline slot belongs to some group, so passing all pair tests certifies the claimed anchor and every intervening write. The actual most recent write therefore has the returned value, or the address still holds zero. Induction from the initial state over native instructions and slots now gives the genuine run and signal, including effective addresses that depend on earlier loads. Different choices of the two groups see identical records for every repeated group, by the deterministic definition. [Finite anchor and component checks in Lean](../lean/SlabProduct.lean)

A defect machine need only nondeterministically select the groups, a specific adjacent-controller pair or one load and a proposed offending slot or anchor type. It can first produce all records of the two requested groups, and directly inspect the chosen coordinates. Selecting just one potential violation avoids an all-pairs comparison of two large logs. Sort the cut writes by address and time for binary-search predecessor lookups. Within a computed group, use a directly addressed dictionary of its latest store, with a presence tag, retaining both the slot and the value. Take the later eligible result. Scan the interval directory once per requested group and skip intervals with other labels without processing their instructions. Header validation, sorting and replay take $(b+|S|+1)\operatorname{polylog}(H+2)$ native steps for polynomially bounded times and addresses in a source scale $H$. Bounds and group membership for a proposed anchor are checked from the interval directory and the slot enumeration. The defect computation's input includes the short source as well as the cut payload, and the parameterized nonacceptance bound below charges for both. Finite fixed nesting on the packed model supplies fresh bounded dictionaries and host word-width headroom as in the [transfer](packed-band-transfer.md).

An exhaustive two-cell experiment with adaptive addresses tried 127,232 certificates on four-instruction programs. The full check accepted no wrong trajectory. In 80 genuine layouts, an equal-value anchor allowed a cut that the last-write rule would disallow. Dropping the intervening different-write test admitted 1,566 certificates giving a wrong final register. [Experiment](../audits/separator_replay_experiment.py)

## Near-linear runs after supplying selected load values

Suppose a deterministic solver decides SAT in $O(N\log^a N)$ time for fixed $a\ge0$, and let $L=\max(2,\lceil\log_2(N+2)\rceil)$. There are constants $K,B$ and a family of arbitrarily long unsatisfiable formulas, one for every sufficiently large source padding, on which the minimized choice graph has a clique minor of order at least $\lfloor\sqrt N/L^B\rfloor$. This strengthens the earlier $\sqrt N/2^{O(\sqrt{L\log L})}$ bound. It remains true after deleting all load edges at any chosen set of at most $N/L^K$ writable read slots. The remaining loads can still choose their legal anchors individually on the original genuine trajectory.

More generally, fix a deterministic policy evaluator with a fixed polylogarithmic clock per query. It may inspect the original input, true current controller, access address, native time and slot, any earlier replies within the same instruction, and a shared advice string. Fresh temporary memory per invocation permits deterministic replay. On a query it supplies a word or abstains. Allow arbitrary advice of length at most $N/L^K$ bits and retain only choices that supply correct words on the genuine trajectory. Delete every edge at a supplied load. The same minor bound holds, even in the presence of the separate exceptional slots. Constants and source family may depend on the solver and evaluator and their clocks. The advice, exceptional slots, legal anchors and cuts may vary by input. A time-and-slot table for the exceptional answers costs $O((1+N/L^K)L)$ bits. Exceptional answers take precedence over policy calls. A policy that also supplies an authenticating anchor with each value can use the one-defect-call proof below.

For the value-only case, define a group's deterministic replay as before, using the exception table or the policy first, and the retained latest write or initialization on abstention. The cut is taken in the residual choice graph. On the true cut and advice, genuine supplied replies, and retained legal anchors for every remaining import, give correct native instructions by induction inside each component. To establish soundness for arbitrary cut records and policy advice, test controllers, native rules and the true output as before. A bad memory read with returned word $v$ can now be recognized without displaying its true writer in that load's record. Guess the read, an earlier write of a different word to that address, or the initialization case with $v\ne0$. Replay the specified groups to check these facts. One more nondeterministic test guesses a group and checks a proposed write to that address strictly between the proposed source and the read. Certify that this last test has no accepting branch using the hypothesized SAT solver on the explicit bounded-computation formula. If the true current word differs from $v$, the latest actual write in the *proposed* chronological logs (or initialization) provides a valid choice. Conversely any such witness with no intervening write proves the proposed read wrong. All tests refer to the same deterministic group logs. Another call establishes that the entire defect machine has no successful branch. This certifies the genuine signal even for dishonest advice. When every deleted read carries an anchor, the preceding pair-of-groups test checks all supplied values in one defect call; individual exceptions can always include a genuine last-write slot.

For costs, use the quadratic signed source with $n_0$ padded input bits, deadline $H=\Theta(n_0^2)$ and encoded formula length $N=\Theta(H\log^3 H)$. It is available virtually from $n_0$ through the locally queryable reduction. Let $s=|S|$, let $u$ be the number of exceptional slots and $z$ the bit length of advice. For polynomially bounded parameters, the source verifier's time on an honest chart is at most
$$
 C(n_0+b+s+u+z+1)L^J
$$
for a fixed $C,J$. Indeed header validation and forming the guessed data cost $O((s+u+z+1)L^{O(1)})$. Any one component takes $(b+s+u+z+1)L^{O(1)}$ steps including the bounded policy calls and local formula generation. A single conversion of a nondeterministic test with $m$ words of physical input and clock $R$ to an explicit formula costs $(m+R+1)L^{O(1)}$ steps and bits. Deciding it multiplies by at most another fixed log power. There are at most two such calls nested along a branch and their physical inputs use the short source, cut payload, exceptions, advice and selected indices. Hence $J$ is fixed *before* choosing the following powers. All clocks can be enforced on false guesses; data-dependent integer caps and a polynomial maximum timeline suffice. [Explicit public-input costs](materialized-input-census.md) · [Signed source and its deadline](packed-band-transfer.md)

Choose an integer $U>J+5$, take $K\ge U$, and set $b=\lfloor N/L^U\rfloor$. If the claimed minor lower bound fails, take $h+1=O(\sqrt N/L^B)$. Since $E=O(NL^a)$, the cut has $s=O(N L^{a+U/2-B})$. Choose $B>a+3U/2$, giving $s=O(N/L^U)$. All honest costs above are $o(N/L^3)=o(H)$. On the signed verifier's own padded input a timely success would make the source formula satisfiable while certifying that its solver signals UNSAT. It follows that this formula is unsatisfiable and none of these cheap cuts can exist for any eligible advice and choices. Guess the integer budgets rather than hardwiring $U,B$ into the source interpreter. A fixed polynomial cap on all lengths ensures physical addressing headroom. This argument also shows that on this family any valid cut with an honest policy and exceptions must have $b+s+u+z+1=\Omega(N/L^{J+3})$, for the fixed verifier.

## Improving the nonacceptance clock

Suppose for contradiction the product is $O(N^c)$ for a fixed $1\le c<(1+\sqrt{17})/4$. One can enlarge $c$ slightly within this interval to absorb powers of logarithms or choose rational parameters. Write $W(e,d)$ for the following property of each fixed bounded nondeterministic RAM computation. Nonacceptance within $R$ steps on $m$ public words has a sound nondeterministic certificate with a successful branch within $(R^e+m^d+1)H^{o(1)}$ steps, where $H=\max(2,R,m)$. Materializing its acceptance formula of $H^{1+o(1)}$ bits and running the hypothesized recognizer gives $W(d,d)$ for $d=c$, since the product bounds rejection time alone. On an accepting computation no branch may certify nonacceptance. The locally generated formula allows subsequent uses to access its guest input virtually from the same public words. [Reducer for public data](materialized-input-census.md) · [Earlier two-exponent simulation](first-moment-heavy-bootstrap.md)

Suppose $W(e,d)$ holds with $1\le e\le d=c$. On the bounded source's unsatisfiable formula use the product assumption *again*, this time for its choice graph. With $b=H^{x+o(1)}$, the payload has at most $H^{y+o(1)}$ bits for $y=c-x/2$. Choose
$$
 x=\frac{2cd}{2e+d},\qquad y=\frac{2ce}{2e+d},\qquad e'=xe=yd.
$$
Here $x\ge y$, so the nondeterministic defect machine has time $H^{x+o(1)}$, public input $m+H^{y+o(1)}$, and no defect exactly when the proposed cut certifies a genuine rejection. The outer verifier guesses the payload and uses $W(e,d)$ on this bounded machine to certify absence of a defect. Enforce data and replay caps sufficient for every well-formed chart under the chosen budgets. A timeout on a malformed guess may be treated as a defect. All $o(1)$ factors arise at fixed nesting depth and can be covered by fixed clocks with arbitrarily small exponent slack. The result takes $(H^{e'}+m^d+1)H^{o(1)}$ steps. Because $e'\le d$, the case $H=m>R$ is absorbed by $m^d$, giving $W(e',d)$. This argument also works with a signed reference exponent $d\ge1$ different from $c$ whenever the stated balance and exponent inequalities hold.

The update is $e'=2cde/(2e+d)$, increasing on positive arguments with positive fixed point $d(c-1/2)$. Starting from $e=d$, its iterates decrease to that point for $c<3/2$. In fact $1/e'=1/(cd)+(1/(2c))(1/e)$. Since $c(c-1/2)<1$, finitely many iterations give an exponent $e'<1$. At $c=d=1.28$ the sixth iteration already crosses one. Fix a bounded universal nondeterministic source interpreter of clock $R=n_0^D$ with fixed $D>d$, on its own padded description of $O(n_0)$ public words. A sound certificate for its nonacceptance within the resulting $o(R)$ clock contradicts the signed diagonal because the interpreter accepts upon seeing the very signal certifying its nonacceptance. For each fixed opponent the interpreter overhead is constant. The fixed number of nested physical RAM bounds and symbolic wide guest addresses are handled as in the [packed diagonal](packed-band-transfer.md). [Earlier complementary diagonal in the literature](https://lance.fortnow.com/papers/files/tst.pdf)

Earlier work uses planar separators for computation graphs of nondeterministic queues, and uses multi-pushdown separators and segregators for tape-machine simulations. The RAM argument here authenticates the latest value of an adaptively computed address across separated components. [Queue simulation](https://eprints.illc.uva.nl/id/eprint/1009/1/CT-1989-03.text.pdf) · [On separators, segregators and time versus space](https://doi.org/10.1109/CCC.2001.933895)

This exponent is the limit of the displayed update with $d=c$. When $R<m$, the defect machine still receives all $m$ original public words. Applying the same update again preserves the $m^d$ term. It gives no upper bound on the size of a valid cut of an arbitrary fast solver. In particular the distinct pair-address write-one construction realizes a clique minor of order proportional to $\sqrt E$ with a constant verdict. Excluding such necessary transfers in every candidate fast SAT computation remains open. Priority for this time versus minor calculation is unverified.
