# How often must a genuine fast SAT run admit a different short execution with the same endpoints?

Consider the actual execution of a correct deterministic SAT solver on an ordinary explicit formula. Cut the execution into intervals. For each interval fix its duration, its true entry and exit controllers (all registers, instruction pointers and halt states), and the real, immutable input. A candidate must execute the specified program correctly from **some** initial work memory and meet those endpoints. In particular its internal reads must see the last local store, and repeated incoming reads must agree. In the first interval require zero initial work memory. The real interval always qualifies. Across an interval boundary only the controller is fixed in this definition.

The string associated to a candidate has one token per instruction. It records the work-read replies and which read slots are active; an instruction with no work read has a fixed empty token. Starting from the given controller on the given input, the string uniquely specifies the native interval. A polynomial-clock computation has an alphabet of size polynomial in the input bit length N. Measure distance between two strings by the minimum number of single-token insertions, deletions and substitutions. Call an alternative **far** if this distance from the real interval exceeds r.

For interval i let Kᵢ be the number of far alternatives and Dᵢ the number of distinct *genuine work addresses* at which one of those alternatives can first depart. A first departure occurs on the real execution's actual instruction and address, since all earlier replies are the same. It must be a first incoming read of that address in the interval: a prior write or read would have determined the word. The same address in two different intervals is counted twice.

## Near-linear time forces independent alternatives in short windows

Suppose a fixed deterministic SAT solver runs in O(N Lᵃ) time, for a fixed nonnegative integer a and L=ceil(log₂(N+2)). Work memory is unrestricted. Pad its run to a fixed such clock by idle steps after halting. Fix any nonnegative integer s. Set r=floor(Lˢ), and cut into consecutive intervals of B=ceil(L^{3a+s+11}) instructions, with a shorter last interval. Then the ratio
```
           Σᵢ min{ L Dᵢ, log₂(1+Kᵢ) }  /  (N / L^{2a+8})
```
is unbounded on arbitrarily long satisfiable files. It is unbounded separately on unsatisfiable files. This applies to ordinary ASCII DIMACS and the fixed-width binary encoding in the local SAT reduction below.

For example, a linear-time solver on some genuine accepting runs must have more than any constant times N/log⁹ N distinct (interval, authentic read address) pairs with this property; the same holds on some genuine rejecting runs. One may require the alternative to differ by more than log N edits and still take intervals of only O(log¹² N) instructions. The bound is on native addresses reached by the solver itself. The alternative uses another starting work memory in that interval.

An interval contributes at most O(BL) bits to the numerator and contributes zero unless it has a far alternative. Thus on those runs the number of disjoint intervals admitting such an alternative, divided by N/L^{5a+s+20}, is also unbounded. Choose one alternative in each of any k such intervals. All 2^k choices give distinct same-verdict candidate histories with exactly the authentic controllers at every boundary and the authentic steps outside the altered intervals. The edit-distance guarantee is per altered interval, allowing realignment anywhere inside it. Concatenation need not preserve memory across the altered boundaries.

The earlier projected-list bound applied to arbitrary polynomial-time space-bounded generators, with a loss of exp(O(sqrt(log N log log N))) on negative files. Here the witnesses are localized native executions, the loss is a fixed power of log N, and first-departure addresses must admit an alternative even after excluding an entire edit ball around the real window. ## Authenticating one local choice

A chart lists the genuine controllers, local advice at each interval, and a common binary hash seed. The checker treats these as untrusted guesses. Its tests need only the domain of each local menu of possible paths. For an honest chart, construct singleton menus as follows.

A radius-r edit ball around a length-B string over an alphabet of size A has size at most 2^{O((r+1)log((B+r+2)(A+2)))}. Encode a string in the ball by a script, specifying a position, operation and symbol at each edit. For the parameters here the logarithm of this bound is O((r+1)L). This volume estimate also holds for the polynomial-radius theorem below.

One option in interval i is to supply the start-memory values at its Dᵢ first-departure addresses. Locally enforce those values on incoming reads. Every far alternative is excluded at its first difference, so only edit-ball strings remain. A second option is to supply no addresses. Then at most the edit-ball size plus Kᵢ strings can compete with the real string. In either case also supply a short tag that distinguishes the real string from every remaining competitor.

For the tags encode each local string unambiguously in at most b=O(BL) bits with fixed padding. A random binary Toeplitz matrix on b bits has a 2b−1 bit seed. For each nonzero difference vector the first u product bits are jointly uniform, for u≤b. Indeed use the first nonzero coordinate and expose the diagonal bits in triangular order. For a local menu with at most k competitors, take ceil(log₂(k+1))+ceil(log₂(2p)) tag bits, where p is the number of intervals. If that reaches b, send the literal string instead. Otherwise the collision probability for the authentic string is at most 1/(2p). One common seed works for *every* interval by the union bound. These hashes are deterministic filters once supplied. For related matrix hashing see [Mansour, Nisan and Tiwari, *The computational complexity of universal hashing*](https://www.sciencedirect.com/science/article/pii/030439759390257T).

Choosing the cheaper option separately in each interval yields an honest chart of bit size at most
```
 O( BL + p(r+1)L + Σᵢ min{L Dᵢ, log₂(1+Kᵢ)} ).
```
The chart includes a directory, mode bits and O(p) controller words. The address mode needs at most B entries per interval. For polylogarithmic B all individual formatting, hashing and local candidate verification costs are polylogarithmic. A file can have many close spurious traces; none of them needs to be named individually.

## Many alternatives for the very same first wrong word

The isolation proof permits an arbitrary exception set in place of the edit ball. In each block take any set of at most 2^{C(r+1)L} token strings for a fixed C, possibly depending on the entire genuine execution. Count only false paths *outside* that set in Kᵢ and Dᵢ. The same bounds hold, even if the sets were chosen to minimize the numerator. Given the Dᵢ incoming words, all remaining competitors belong to the exception set. The short tag excludes them by cardinality alone. The verifier never needs to enumerate the set, compute it, or test membership. The chart can use new tags for every input.

Here is a consequence for the attempt to realize false replies on nearby inputs. Fix a polynomial deadline N^d covering the solver's honest runs on the files in question, or take any other fixed d>0 and compare just that prefix. For a linear-time solver take r=ceil(log₂(N+2)). On some genuine satisfiable runs and separately on some genuine unsatisfiable runs, the number of authentic (interval, first-read address) pairs with the following property divided by N/log⁹ N is unbounded.

* Keep the complete authentic prefix up to that read in its interval. One particular different reply at that read admits at least 2^{rL} locally realizable continuations back to the authentic exit controller.
* Their work-reply strings in the interval are pairwise more than r token edits apart. Each is also more than r token edits away from **every substring of the genuine execution on every well-formed file within r bit edits of the original formula**, up to the stated deadline. The comparison allows a new alignment, a different verdict, and a different candidate input for each substring. Intervals are at most O(log¹² N) steps.

To see this, assign each false path to the actual address of its first differing read. In a block there are at most B such sites, and each address has only one possible first-departure site since the block enforces local memory. Mark all groups of size at most 2^{C₁(r+1)L} as exceptions. The total cost in log cardinality is O((r+1)L). The theorem forces more than any constant times N/L^{2a+9} surviving sites along a sequence of files. For each such group fix the most frequent first wrong reply; this loses at most the polynomial word alphabet size.

There are at most 2^{O((r+1)L)} nearby binary files (including insertions and deletions), and at most polynomially many substrings per genuine clocked run. Even after taking radius-r token neighborhoods their union contains at most 2^{C₂(r+1)L} strings of the given window length. Each individual token ball discards at most 2^{C₃(r+1)L} strings. Choose the fixed C₁ bigger than C₂ and C₃+2, with slack for the reply choice. Remove the union and greedily pack the remaining group by discarding one ball per selected string. This leaves at least 2^{rL} mutually separated choices. Large constants in advice and word encodings change neither logarithmic exponent. One may also allow up to r adversarial changes of work words during each comparison run. Even adaptively chosen changes on a particular trajectory have a description by at most r triples (time slot, address, replacement word). There are only 2^{O((r+1)L)} such descriptions before a polynomial deadline on the log-word machine. This includes changing up to r words of the genuine block-entry memory before replay. These enlarged comparison families fit the same constants argument. Thus each selected path is feasible from some initial block memory, but it can be required to stay more than r token edits away even after r input edits and r work-word corruptions on a real comparison run. A further comparison starts the block at its authentic controller on F using any snapshot from those nearby runs, followed by up to r word changes, with a fixed zero-extension convention for compatible address banks. Its description still needs only O((r+1)L) bits, including the snapshot time. In particular every initial memory realizing any selected alternative differs from the real entry memory in more than r cells. In fact the minimum memory distance for a given alternative is exactly the number of distinct addresses it reads before writing whose required incoming value differs from the authentic entry word. Each of these changes is necessary. Making just these changes suffices by induction over the alternative path. Its first departure address occurs on the authentic run; the later addresses can belong only to the alternative. This shows the difference in work-memory contents independently of the alignment of the reply strings. The same argument works for any fixed s in the near-linear theorem. This is a statement about the multiplicity and realizability of wrong continuations from a **single authentic site**. It does not require every erroneous continuation to be far.

## A sound test on a false chart

Guess the chart existentially. Check its initial and terminal controllers and declared bounds. Use one shared array of controllers, so adjacent endpoints refer to the same value. Give each row deterministic bounded parsing semantics, including a defined empty-menu behavior for invalid offsets. For a path to enter a menu, check its endpoints, immutable reads, local work memory and the selected filter. An initially unknown word can be guessed at first use and cached across the interval. The checker can alternatively accept a complete candidate string and replay it with its own fresh scratch and presence flags. The segment length and observation clocks are public.

Use one universal challenge followed by one existential answer. Both refer to the same fixed chart.

* A challenge naming an interval demands one path from its menu.
* A challenge exhibiting two distinct paths in the same menu defeats the chart if both pass their local tests. This enforces singleton menus and allows multiple encodings of the same visible path if needed.
* A challenge claiming an incorrect incoming read gives the consuming block and path, the address, and a producing earlier block and path, or the zero initializer. The consumer must really read that address before writing it. The proposed producer's last store to it must have a value different from the claimed incoming value. Both supplied paths must pass their indicated menus and the writer must precede the consumer. For initialization the incoming value must be nonzero, and any earlier block is eligible to intervene. An invalid challenge passes automatically. For a valid challenge the answer must exhibit a strictly intervening block with a path in its menu that writes this address.

The true singleton chart passes. Conversely, if the first two types pass then each menu has exactly one visible path. Concatenate them in order. If a global read is wrong, choose the first such read. Local consistency makes it an incoming read with a specific mismatching last writer or the zero initializer. A third-type challenge using the actual last writer has no possible answer. Hence a passing chart describes a genuine run with the stated verdict for *any* guessed hash seed, tags, memory pins or offsets. The verdict polarity is selectable. The proof uses existence of one honest short chart on the sign under study. ## Time of the verifier

Use a bounded nondeterministic RAM source with public input of m words and clock H, where m≤H. Its explicit SAT encoding has N=O(H log³ H) bits and is padded to this order. The chosen local reduction supplies its words virtually from the source input with at most polylogarithmic setup and query cost. The logarithms of H and N are comparable. A bounded nondeterministic query of time U with v public words materializes to O(U log³ H+v log² H+polylog H) bits and construction time at polynomial scales. This public-input charge matters here. A SAT solver of time O(N logᵃ N) decides either polarity of that query in O(U log^{a+3}H+v log^{a+2}H+polylog H) time. The materialized calls themselves are ordinary SAT calls. These are the previously established packed reductions, with the short-digit table or slower polylogarithmic on-demand arithmetic available for local ASCII access; only polylogarithmically many local accesses occur in the short-window argument. [Local Cook–Levin encoding](packed-band-transfer.md) · [Cost of public words](materialized-input-census.md) · [DIMACS access and same-sign composition](memory-addresses-needed-to-certify-a-sat-verdict.md)

For fixed chart and challenge, search for an answer by one ordinary SAT call. The local deterministic path tests take polylog H steps. For fixed chart, another ordinary call searches for a defeating challenge using the first call's deterministic verdict. If the chart takes G words, these two calls together, the outer guess included, cost
```
 O( (G+m) log^{2a+5} H + polylog H ).
```
The second call may explicitly access the full chart. A first-call result of size/time proportional to (G+m)log^{a+2}H is charged the additional log^{a+3}H factor. There is no unit-cost oracle assumption.

A verifier need only materialize the selected row information for a local replay; charging the entire public chart at each reduction, as above, safely overestimates its cost.

If the claimed ratio were bounded on every sufficiently long file of the chosen sign, its honest chart would have G=O(N/L^{2a+9}+p(r+1)+B) words. Here p=O(N/L^{2a+s+11}+1), so the second and third terms also fit. Cap the nondeterministic guess at the hypothesized bound, allowing any fixed constant. The result is a sound recognition of that sign of the original source in time
```
 O( H/log H + m log^{2a+5}H + polylog H ).
```
For negative certificates, the standard complementary bounded-RAM diagonal with H a sufficiently large fixed power of the original input length contradicts this saving. For positive certificates the transformation preserves nondeterminism and the same physical input. Apply it a fixed number J of times to a unary nondeterministic tape hierarchy language with time n^D, D>1. Each current machine has a fixed explicit clock; repeated substitution saves log^J n, with an additive O_J(n polylog n). The public input remains the unary string. Converting the last nondeterministic RAM back to tapes verifies a guessed memory trace, sorting the address-time records in time times a fixed polylogarithmic overhead independent of J. Choose J to save more than this overhead plus one logarithm. This contradicts the unary nondeterministic time hierarchy. Finite exceptional SAT lengths may be hardwired. This proves each polarity, possibly on different files. [Complementary diagonal and positive iteration](memory-addresses-needed-to-certify-a-sat-verdict.md) · [Seiferas, Fischer and Meyer](https://doi.org/10.1145/322047.322061)

## A nearly linear radius in a single interval

There is a second scale for the same theorem. On a near-linear solver, both the token-edit distance and the number of necessary changed incoming memory words at one authentic site can be required to exceed N/log^C N, for a fixed C, still returning to the actual controller within o(N) instructions. More precisely there is a fixed integer h, depending on a and the local implementation, for which one can take
```
 B = ceil(N/Lʰ),      r = floor(N/L^{h+3a+11}).
```
The same bounds on the sum and the heavy sites hold on each verdict. At each heavy site the fixed alternative reply still admits at least 2^{rL} pairwise separated choices with the preceding robustness guarantees.

For the larger windows use fast Toeplitz evaluation. For b=O(BL) bits, pack binary polynomial coefficients into integer digits of width ceil(log₂(2b+2)), multiply the two integers and take the parity of each convolution coefficient. No carry crosses a coefficient boundary. Fast integer multiplication or binary polynomial multiplication, together with virtual input queries, address filters and local path tests, gives per-challenge native time O(BLᵈ+polylog H) for a fixed integer d. This d can be fixed before choosing h: all data lengths are polynomially bounded, with polylogarithms measured in the original size. Use h>d+2a+10. The table cost still fits O(N/L^{2a+9}) words under the contrary small-sum assumption: the common seed costs O(B) words and p(r+1)=O(N/L^{2a+11}+L^{a+h}). The local work after both eliminations is O(BL^{d+2a+6}+polylog H), at most O(N/L⁴), hence O(H/log H). The previous contradictions apply. This requires comparing against at most polynomially many substrings per perturbed run. Its large-radius statement does not place all changed cells on the authentic trajectory. [Uniform polynomial multiplication](https://kaltofen.math.ncsu.edu/bibliography/91/CaKa91.pdf)

## An unconditional product with actual elapsed time

Fix a rational c with 1≤c<∛2 and a rational γ≥0 with c²(c+γ)<2. Let M be any deterministic RAM procedure sound for SAT that eventually accepts every satisfiable input. On a satisfiable file let E be its **actual** time to first acceptance. Set r=floor(N^γ) and use block length B=ceil(sqrt(max(1,E)(r+1))), clipped to at most max(1,E). No idle padding is needed. Put
```
 S = Σᵢ min{ Dᵢ, log₂(1+Kᵢ) }.
```
Then (1+E)(1+S) is outside O(Nᶜ) on satisfiable inputs. The same theorem holds for the time to first sound rejection for a procedure signaling on all unsatisfiable inputs, with the product measured on unsatisfiable files. No speed or space assumption on M is made in this result. For instance one may take c=5/4 and γ=1/50, since (5/4)²(5/4+1/50)<2. The exponent on E alone remains open.

Suppose instead the product is bounded by C Nᶜ throughout the sign in question. Running M until this clock and defaulting to the opposite answer yields an ordinary deterministic SAT decider of time O(Nᶜ). A nondeterministic verifier can directly simulate a genuine signal through time N^{1−η}, for a sufficiently small fixed rational η>0. For later honest branches, E≤C Nᶜ and S=O(N^{c−1+η}). Guess E and its chart subject to both bounds. On this branch r<E for sufficiently large N by choosing η<1−γ. Both B and p(r+1) are O(N^{(c+γ)/2}+1). The total number of chart words is at most O(B+p(r+1)+S), since charging each raw bit as a word in S is safe. The local verifier may read its own bounded O(B) words of data. Hashing a length-O(B log N) bit vector by a Toeplitz matrix is a binary polynomial convolution of linear length. Fast polynomial multiplication gives B^{1+o(1)}·polylog N uniform time. Reading addresses, parsing paths and detecting local writes/duplicate pins by a scratch bank or sorting also fit. Validating the full guessed size belongs to the outer cost. [Cantor and Kaltofen on fast polynomial multiplication](https://users.cs.duke.edu/~elk27/bibliography/91/CaKa91.pdf)

Since c<2, choose η so c−1+η<(c+γ)/2. Under the standard bounded computation reduction, the two ordinary SAT eliminations cost at most
```
 H^{c²(c+γ)/2 + o(1)} + m^{c²+o(1)}
```
on the long branch. On the direct branch the bound is H^{1−η+o(1)} plus input/setup overhead. All polynomial exponents on H are strictly below one. On the positive sign use the same-sign unary hierarchy with H=n^D and D sufficiently large to absorb the input term, the direct branch and RAM-to-tape overhead. On the negative sign use the complementary diagonal with the same input slack. Enforcing clocks makes every short witness sound even if M has arbitrarily long behavior on other inputs. Thus the product assumption is impossible. The result charges authentic locations individually by interval. A repeated physical address in many intervals can contribute repeatedly.

The product also holds when its second factor counts only genuine sites with many widely separated continuations. Fix a comparison deadline N^d and the edit, corruption and changed-snapshot comparison families defined above. Let D be the number of pairs (interval, genuine first-read address) where one fixed wrong reply leads to at least 2^{rL} pairwise edit-r-separated alternative strings, each more than r edits from every comparison string. Each requires changes to more than r genuine entry-memory words, since the comparison includes replay after r changes at this very interval. When the genuine entry time exceeds the comparison deadline, include that particular entry snapshot and controller explicitly as one extra starting point. Its r-word neighborhood has the same count. For a run exceeding the deadline, the comparison against other genuine runs uses only their stated prefixes.

Then (1+E)(1+D) is outside O(Nᶜ) for each sign. Indeed, under the contrary product assumption E≤CNᶜ on that sign, so the comparison counts, the number of alternative first reply values, and the edit-ball bound have the same logarithmic costs as above. At any site failing the stated property, the entire group of alternatives has size at most 2^{C₁(r+1)L} by the removal and packing argument. In each interval pin the genuine word at every counted site. At most O(B) uncounted groups plus the real path remain. They require only O((r+1)L) tag bits. The honest chart therefore has O(B+p(r+1)+D) words and the long-branch proof goes through verbatim. In particular (1+E)(1+D) exceeds arbitrarily large multiples of N^{5/4} at radius floor(N^{1/50}). The exact minimum set of changed entry addresses for any feasible trace is formalized in [IncomingTraceRepair.lean](../lean/IncomingTraceRepair.lean).

## Why this has not yielded a time lower bound

A fixed globally correct SAT solver can exhibit many such excursions while running in linear time on an easy, data-dependent family. Pin m input bits in ordinary proper DIMACS, compute their parity with a chain of XOR gates, and pin the output to the public desired parity. Use fixed-false padding anchors for all short clauses. An input bit can be encoded by a single 0/1 name digit in a complemented pair. The explicit layout has N=Θ(m log(m+1)) bits. Validate the entire layout, write the private bits to distinct work words, and then make one branchless pass through those words, accumulating parity. Reset temporary data registers at each iteration boundary and branch only after the final comparison. A complete SAT procedure handles any failed layout check. [Physical pin convention](one-false-read-and-a-subcubic-graph.md)

On the all-zero data file, change any even set of work replies in a complete run of scan iterations inside one time window. The parity and exit controller are restored. The complete interval is genuine on an appropriate initial work memory. The changed scan segment can even be realized on a different well-formed input by changing the corresponding pinned bits. Each nonzero token in the modified scan costs at least one edit from the original zero-data scan, whose only tokens there are the fixed empty token and a zero read. On windows surrounded by a full block of scan iterations there are Θ(B) candidate first-divergence addresses admitting more than r edits whenever r=o(B); select an even number of changes in the remainder. The final scan has Θ(m) such addresses up to its two end windows. Either genuine verdict can be chosen by the public pin. For a site in the first half of such a window the even-parity tail alone has 2^{Ω(B)} possible read strings. Since (r+1)L=o(B) here, removing the comparison runs and greedily packing token balls also gives the heavy-group property in the preceding section. This illustrates why even that strengthened property, as a counting requirement by itself, permits linear elapsed time.

Requiring the entire exit memory to agree changes the conclusion. At constant overhead a polynomial-clock guest can store each work-read reply in a private, never-read bank indexed by its time and read slot. The guest and log use disjoint address ranges, enlarging the fixed word-width constant if needed. For intervals bounded by guest instruction boundaries the first changed reply causes a different store at the very same log address; no later step can overwrite it. This argument allows arbitrary initial contents in the log bank. A macro can implement the load and immediate store using a dedicated temporary containing the raw word until the store. Thus even an otherwise fast solver could eliminate every alternative with identical full exit memory. In the scan of m fresh words, logging, clearing the guest words and resetting the registers leaves exactly 2^{wm} possible exit logs with all other exit data fixed, for w-bit reads. Pinning any k of those log words leaves 2^{w(m−k)} trajectories, even if the pins are selected for this particular authentic log and used as equality tests. A hierarchy speedup that supplies the full boundary has to pay for access to those log contents.

The new ingredient relative to the earlier address and list certificates is the chart of independently isolated, short *locally memory-consistent* paths, each allowed to start in a different incoming memory. A proof of the full RAM lower bound still needs to constrain the cost of securing these choices on the genuine hard files, or find a different speedup. Priority for these quantitative bounds is unestablished. The hierarchy applications and asymptotic encodings are manuscript arguments.

The native finite audit enumerates block programs with direct and register-indexed reads and stores, checks the first-departure pins against exact edit distances, and exhausts the small Toeplitz difference distributions. These and the Lean checks do not verify the asymptotic clock reduction.
