# All orders of interval unranking have one attainable union

**Research journal, 2026-11-24.** Suppose several producers fill omissions from different length scales, using the outputs of previous producers as already certified. Could a choice of the order, made after seeing the first missing word w, certify almost all its near predecessors? For interval producers taking first available ranks, one public order produces the exact union of the occupied positions of *every* order. With short producer names this gives an unconditional obstruction on w. [Canonical missing word](address-diagonal.md)

## Exchange across crossing intervals

Start with an arbitrary occupied set S in {0,…,M−1}. Each token t has a fixed closed interval [lₜ,rₜ]. It fills the first still-unoccupied position in this interval, or does nothing if the interval is full. Each token can be spent once. Tokens with the same interval implement a quota. One can pick the next token after seeing all prior choices and their outputs, and stop at any point.

**Claim.** Process every token by increasing rₜ, breaking ties by its index. The resulting occupied set is exactly the union of the occupied sets over all schedules.

First, applying a fixed token is monotone in the starting occupied set. If S⊆S′ and its selected position x from S is outside S′, every preceding interval position was already in S, hence is in S′. The token still selects x from S′.

Now exchange two adjacent tokens. If one has no initial choice, that token remains ineffective after spending the other one. If the initial choices differ, selecting one leaves the other's first choice available. If both want x, the next claim after x has common lower bound x+1: in either interval all positions before x were already occupied. Look at the next vacancy y>x in the entire address order. The remaining token takes y exactly if y exists and y≤its own right endpoint. Giving x to the token with the smaller right endpoint therefore preserves every position the other ordering occupied. The final state may have one more position. Monotonicity propagates this inclusion through every subsequent token. Extend any partial ordering by appending its unspent tokens and sort it by exchanges. Since the sorted schedule is itself attainable, its final set equals the union. Ties in right endpoint can be exchanged with equality.

Matching unit jobs to slots in release/deadline windows is classical. Here the statement needed for a diagonal is inclusion of every *position* attainable by first-available allocation over all orders, including crossing intervals. Cardinality optimality alone would not imply this inclusion. [Glover's matching algorithm, as described by Brodal et al.](https://cs.au.dk/~gerth/papers/mfcs07matching.pdf)

## Charging for private rank and interval choices

Suppose instead that one token may choose any of its first k positive vacancy ranks, skipping the token if its chosen rank is unavailable. As an upper bound, replace it by k first-available subtokens for its interval. If an original step chooses x and the expanded process already contains x, the inclusion persists. Otherwise x's vacancy rank in the expanded process is at most its old rank. Processing the k subtokens therefore includes x. This comparison applies after every adaptive step, then the exchange theorem dominates the expanded sequence by one canonical order. An allowed window chosen adaptively from a finite menu can similarly be charged one full set of subtokens for each possible interval. It suffices to enumerate the expanded tokens without knowing the successful order or choices. The rank charge k is sharp in isolation: a single token permitted any of k ranks can attain k different positions.

The interval condition matters. With ordered lists (0,2) and (0,1), the two orders occupy respectively {0,1} and {0,2}. No order occupies their union. The same example uses two ordinary intervals on three positions with opposite internal orders by moving the shared first choice to position 1. Thus arbitrary orderings within a set cannot be absorbed by the deadline exchange without a further charge.

## How much can fragmented windows reveal?

A list consisting of f disjoint increasing intervals per token is dominated by giving it one ordinary token per component. In an original run, process all its component tokens when it acts. If its selected position has not already been captured, it is the first available position in its own component, so the component token captures it. The canonical deadline order then covers every attainable position with at most f times as many tokens. With private rank up to k the corresponding direct charge is fk.

The factor f can be necessary up to a constant. For p=2ʰ tokens and 1≤f≤h+1, use a binary tree of depth f−1 and give its leaves equal-sized groups of tokens. Give each internal node of depth j a distinct block of p/2^(j+1) positions. Give each leaf a block of p/2^(f−1) positions. Arrange all blocks in level order. Each token sees only the f blocks on its path, in increasing global position order. To make a given node's entire block reachable, work down its path: process precisely the tokens from the sibling subtree at the current ancestor. These share the ancestor's first unfilled block and exactly fill it. Finally process the target node's tokens. Thus every position in every block is reached under some schedule. Their number is p(1+(f−1)/2), although each fixed schedule uses at most p positions. At f≈log₂ p this covers a universe of order p log p with only p tokens. Accepting a guessed schedule without proving its outputs belong to the bounded program image can therefore accept the actual hole.

This scheduling problem is known as serial dictatorship in house allocation. The full-depth logarithmic expansion has a classical recursive construction attributed to Henze, Jaume and Keszegh. Theorem 2 of Asinowski, Keszegh and Miltzow bounds the union for arbitrary strict preference lists by Σ_{i≤p}⌊p/i⌋. One can append private dummy choices to shorter lists and remove initially occupied positions to apply the bound to newly occupied real positions. Their Theorem 10 also shows that testing whether a particular position is reachable is NP-complete even with three ordered entries per token. The cardinality bound by itself does not provide a fast uniform enumeration of that union. [Asinowski, Keszegh and Miltzow, Theorems 2 and 10 and Example 8](https://arxiv.org/html/1401.5354)

## A short deterministic list for arbitrary strict preferences

There is an inexpensive constructive substitute for computing the exact union for arbitrary lists. Sweep through the p tokens in a fixed order, assigning the first still-available listed position to each token. Reuse all tokens in the same order on every sweep while keeping previously assigned positions occupied. After L=⌈log₂(p+1)⌉ sweeps, the set of at most pL **newly occupied** positions contains every position attainable in a one-use schedule. A sweep may include positions that no such single schedule could attain.

To prove coverage, fix one target schedule and its set E of newly assigned positions, paired injectively with the tokens that obtained them. At the start of one sweep let k positions in E still be unoccupied. Of these, let m become occupied during the sweep. Consider the k associated tokens. At most m of them can find their own targets occupied before their turn, since these targets are distinct and were unoccupied at the start. Every remaining token selects an element of E: its own target is available and every preferred position was either occupied initially or assigned earlier in the target schedule. Thus at least k−m of the tokens select distinct new elements of E. This gives k−m≤m. The number left after L sweeps is at most ⌊p/2ᴸ⌋=0. The argument holds for all target schedules simultaneously.

This bound on the sweep count is exact for a fixed public order. In the full-depth binary construction above, visit tokens in left-to-right leaf order on every sweep. The left half of the tokens spend their entire first sweep filling the root block, and the right half never touch the left subtree. The remaining left subproblem starts fresh on sweep two and obeys the same recurrence. The leftmost leaf's position first appears on sweep h+1 when p=2ʰ, although it is attainable in a single suitably chosen schedule. The construction tests an explicit superset-producing heuristic; it does not assert a polynomial algorithm for exact singleton reachability.

## A genuine schedule certificate of a bounded-machine output

For a concrete positive verifier, start from an empty occupied set. Suppose the entire indexed preference table has at most 2ⁿ poly(n) tokens and entries in total and can be generated on tapes within that clock. An accepting witness for x gives a complete order of the p tokens and a selected rank or exhaustion indication for each token. For a selected rank, each strictly preferred entry must have been filled earlier. For an exhausted token this must hold for every listed entry. Sort the records by position to verify uniqueness of the proposed assignments and compare the assigned ordinal with every required upper bound there. Check the order is a permutation and that x is among the assignments. Sorting and checking use quasilinear time in the table's bit length, hence 2ⁿ poly(n). These conditions characterize greedy execution exactly, by induction along the proposed order.

This predicate can certify **actual** bounded-machine outputs without a halting history for any of the original producers. The long-program decoder enumerates the deterministic sweep superset and uses a payload naming one of its pL token visits. If that visit fills a position, output it. For the stated explicit tables the simulation easily fits B: even scanning M occupied bits separately for each inspected entry costs at most O(L·M·2ⁿ poly(n)) native tape steps, and L=O(n) for p≤M. If pL=o(M), every reachable position therefore has a description shorter than d for all sufficiently large n. For example one can use p=⌊2ⁿ/n²⌋ tokens each with polynomially many explicitly generated entries and d=n. Exact reachability can be tested by a nondeterministic order witness while the shorter description specifies a visit in another, deterministic computation.

The same proof of soundness applies to tables larger than the witness clock when only the long decoder is needed. For p≤M and uniform access to each row/rank entry in 2ⁿ poly(n) tape steps, generating at most pM entries costs 2^(2d+n+O(log n)); the repeated sweeps cost O(LpM² poly(n)) by sequential scans. Both stay below B after quadratic universal simulation. To test near-predecessor coverage, add the F-fast outputs to the computed superset after the sweeps. If pL=o(M), this combined set excludes w. The one-sided ranking bound again forces a constant fraction of unattainable predecessors in **every** sufficiently long trailing interval. This shows exactly where this positive verifier falls short: naming the sweep superset gives it soundness and simultaneously limits its local coverage. ## Consequence for the actual missing word

Take M=2ᵈ with d=n or 2(n−1), and start from all the short-description outputs that halt within the intermediate cutoff F=2^(2n). Fix a uniform family of expanded, indexed tokens with computable count Nₙ≤M. For concreteness assume the count and each token's two endpoints are computable within 2ⁿ poly(n) deterministic tape steps. A fixed decoder given n and an index produces the interval records, sorts them by deadline and index, and simulates the sorted schedule. If its token fills a vacancy, it emits that d-bit value and halts. The fast initial set can be tabulated in 2^(4n+O(log n)) native tape steps. Even a separate full sequential scan of the M occupied bits per token fits 2^(2d+O(log n)), and computing the endpoints takes 2^(d+n+O(log n)). The total and its quadratic universal simulation lie beneath B=2^(20n).

Let c be this decoder's fixed prefix length. At any sufficiently large length with Nₙ≥1 and c+⌈log₂ Nₙ⌉<d, **every** position occupied by the sorted schedule has a genuine short description, including those in the fast initial set. Every fixed construction with Nₙ=o(2ᵈ) eventually satisfies the naming condition. The case Nₙ=0 uses just the fast initial set. Thus the entire attainable union excludes w, including outcomes of schedules chosen nonuniformly with full knowledge of w. Apply the sharp one-sided ranking bound to the tabulable sorted set. For a fixed C, each [w−K,w) contains at least (K+1)/C−1 previously printed-by-B positions unattainable by any of the allowed schedules, simultaneously for all K≤w. For private-rank choices the same conclusion holds when the *expanded* subtokens fit the naming budget. [One-sided ranking proof](predecessor-batches.md)

The obstructions use no SAT hypothesis. They allow any single-use scheduling order with fixed producer lists under the respective name budgets. They leave open producers whose available lists change with evidence acquired during the run, and families whose reachability is sound for reasons other than the short deterministic description above.

On four positions the finite check enumerates every order for all 715 multisets of four intervals and all 16 initial occupied sets. It also checks the expanded bound across all orders and allowed nontrivial rank choices for 1,540 multisets of three tokens with rank cap one or two. It also checks the repeated-sweep envelope on all 56 multisets of three full rankings of three positions, for every initial set, target order and sweep order, and tests the sharp sweep delay through tree height eight.
