# Exact product verification on dense alphabets and Chen's real-input theorem

Chen's November 25 preprint, Theorem 1, states that a real arithmetic decision tree of cost $s$ verifying a bilinear graph on every real input gives complex border rank at most $30s$. Its proof in §4.1, after choosing one open set of graph inputs with the same accepting path, uses correctness again: **every nearby zero of that path's equality tests must be on the graph**. Exact answers on a dense alphabet do not supply this second property. The obstructions below already use test values of degree at most two in the matrix entries. [Chen, v1, Theorem 1 and §4.1](https://arxiv.org/html/2611.34814v1#S4.SS1)

## A single quadratic-cost test on all rational triples

Fix a real $\alpha$ transcendental over $\mathbb Q$. On $d$-square matrices use $v=(1,\alpha,\ldots,\alpha^{d-1})^{\mathsf T}$ and return whether $A(Bv)=Cv$. Computing the powers and the three matrix-vector products takes $O(d^2)$ of the exact real operations charged by Chen. The same constant and loop work at every dimension. Each tested scalar is a polynomial of degree at most two in the input coordinates. For rational inputs each residual row $(e_j)$ gives $\sum_j e_j\alpha^j=0$ exactly when all $e_j=0$. Thus this tree is exact on **all rational scalar matrices**, of unbounded numerator and denominator. The same argument works for any countable alphabet, by choosing $\alpha$ transcendental over the field it generates.

For $d\ge2$, the nonzero row $(\alpha,-1,0,\ldots,0)$ annihilates $v$. For every real graph point $(A,B,AB)$ there are arbitrarily close false triples $(A,B,AB+tD)$ with exactly the same zero-test outcomes: take any nonzero $t$ tending to zero and put that row in $D$. Thus even where all graph points take the same path, the local output uniqueness needed by §4.1 fails at every point. For the equations of this test the Jacobian in the proposed output has rank only $d$, with $d^2$ output coordinates. [Earlier full-rank Jacobian criterion and the Boolean SAT reduction](verifying-matrix-products-from-sat.md)

The same construction with $\alpha=2^{1/(rd)}$ works if all entries in any one input triple lie in some real number field $K$ of degree at most $r$; the field may vary with the triple. Eisenstein gives $[\mathbb Q(\alpha):\mathbb Q]=rd$, so the tower law gives $[K(\alpha):K]\ge d$. Input magnitude and allowing bounded-degree extensions do not ensure local output uniqueness. These counterexamples use the arithmetic model's permitted exact constants.

## Finite integer grids with rational operations

For integer entries with absolute value at most $H$, each residual entry has absolute value at most $E=dH^2+H$. Use the preceding algorithm with the integer $R=E+2$ in place of $\alpha$. If $\sum e_j R^j=0$, reducing modulo $R$ forces $e_0=0$ since $|e_0|<R$. Dividing the equation and repeating proves the claim. For a prescribed alphabet, $R$ is independent of the input, so the degrees of the scalar tests in the matrix entries are again at most two. The coefficients are rational. The dimension and even the alphabet width can grow, and every one of these trees has $O(d^2)$ exact arithmetic cost. The uniform version for unbounded integer inputs first computes $H$ by an $O(d^2)$ scan; this variant does not claim the same global degree bound in the data. Korec and Wiedermann already proved quadratic deterministic integer verification in a large-integer arithmetic model. [Korec and Wiedermann, SOFSEM 2014](https://doi.org/10.1007/978-3-319-04298-5_33)

Restricting *every* scalar to a bounded number of bits still allows nonuniform trees on any finite ordered alphabet: locate every coordinate by a binary comparison tree and put the correct Boolean result at each leaf. This uses $O(d^2\lceil\log_2|\Gamma|\rceil)$ tests and no arithmetic. For an integer alphabet the thresholds fit in the original scalar width. Exponential stored tree size makes this a different control from a single small native program. The two constructions separately expose the roles of scalar precision and nonuniform control; neither yields an $O(d^2)$ logarithmic-word integer verifier.

## Exact price for vector checks over a finite field

If the matrices lie in $\mathbb F_p$, allow the $i$-th public test vector to take its coordinates in an extension of degree $h_i$. For a single residual row, $e\mapsto(e v_i)_i$ is linear over $\mathbb F_p$ and its target has dimension $\sum_i h_i$. Exactness on every row implies $\sum_i h_i\ge d$. This holds even when tests are chosen adaptively from previous residual responses: consider the fixed sequence on all-zero responses. Every row in its joint kernel follows that sequence, and any row is realizable by $A=0$ and a suitable $C$. This access restriction matters; vectors chosen by other inspections of the input are outside the claim. Equality is attained by one check with a basis of $\mathbb F_{p^d}$, or $d$ base-field standard vectors. One extension scalar can therefore hold all the information needed by the checksum, costing $d\log_2 p$ bits to represent arbitrary outcomes.

For integer tests with $|v_{ij}|\le V$, injectivity on rows in $\{0,\ldots,H\}^d$ requires $(H+1)^d\le(2dHV+1)^k$ for $k$ fixed vectors. Otherwise a difference of two rows produces zero on every check; it is realized using $A=I$ and those two rows in $B,C$. This is also valid on the zero-response path of a residual-only procedure. The bounds count information returned by those linear tests and place no lower bound on other RAM instructions.

One positive transfer requires the constants to belong to the tested field. For a fixed tree with coefficients in a real closed subfield $K\subseteq\mathbb R$, and a bilinear map defined over $K$, correctness on **all** $K$-points implies correctness on all real points. A counterexample on any given path satisfies an existential formula of ordered fields with parameters in $K$: name the intermediate gate values, specify the signs, impose the division equations with nonzero denominators, and specify the incorrect graph verdict. Tarski–Seidenberg transfers that counterexample to $K$. Include reachable division by zero as a separate forbidden path when checking totality. This gives transfer for real algebraic inputs with real algebraic constants and no degree or height bound on those inputs. A uniform RAM time bound for SAT on finite packed strings supplies no bound for simulating unbounded algebraic inputs at fixed real-operation cost. [Tarski–Seidenberg principle, Basu, Pollack and Roy, Theorem 2.80](https://www.cs.umd.edu/~gasarch/COURSES/752/S26/slides/AlgorithmsInRealAlgGeom.pdf)

A separate finite-field argument gives an exact rank bound from an equality tree on a sufficiently large field when all equalities on the formal graph path are affine in the proposal, or stationary quadratic in odd characteristic. It uses correct answers on that one field. [Dense finite-field criterion](finite-field-dense-equality-tests.md)

The finite audit checks the equality of computed and tested products on integer grids, the residual-kernel obstruction for all small binary test collections, and the exact two-coordinate false row modulo $X^d-2$. The argument only uses Chen's stated theorem and §4.1 for its scope. We have not refereed its limiting-minimizer proof. No unrestricted deterministic RAM time bound for SAT follows.
