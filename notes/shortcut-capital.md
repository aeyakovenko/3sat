# How many pairs can one sound SAT shortcut answer in time?

For any fixed positive integer $p$, there is a uniform list of pairs of ordinary packed 3-CNFs at every sufficiently large scale. Write $H=2^k$, $V=2^{\lceil\log_2(k^p)\rceil}$ and let $N=Hk^{O(1)}$ count encoded bits, with $N\ge H$. One index $j<V$ and one sign bit select a formula. All clauses have the same incidence pattern throughout the list. Each pair has one unsatisfiable member and one with a unique complete satisfying assignment. The $V$ pairs differ through only $1+\log_2 V$ designated signs. Their addresses and the sampler are public.

There is a constant $C$ with the following **unconditional** clock tradeoff. Give a deterministic program $e$ its code and optional shared advice as one externally length-delimited binary string of length $s$, measured in the universal machine below. It sees $k,j$ and can inspect either actual formula. It may assert which pin is satisfiable, or abstain. If all its timely assertions are correct on this list, then it can assert on at most
$$
s+\lambda(s),\qquad \lambda(s)=d+2\lfloor\log_2(d+1)\rfloor+1,\quad d=\lfloor\log_2(s+1)\rfloor
$$
distinct indices within $\lfloor H/(2^s k^C)\rfloor$ native interpreter steps per index. The same list works for every such program, also when its string is selected nonuniformly after seeing the entire list. The statement is substantive for $s<V$ and positive clocks. Fixed overheads for calling the interpreter can equivalently be charged through a larger fixed log power. There is no global SAT-time or space hypothesis.

In particular a fixed correct SAT solver, tried on both pins in alternating native steps, takes more than $N/\operatorname{polylog}N$ steps **on both members** of all but a constant number of pairs at each scale. The constant can depend on the solver. More generally, arbitrary deterministic shortcuts sound on this list fall under the same quantifiers, even when they can recognize the entire family. The index and the pin themselves give no certified answer. The time stays below the encoded length. Earlier journal entries constructed a first unsatisfiable list member against nondeterministic certificates, and under a fast-SAT assumption a common signed distribution. Here one gets opposite signs on every pair and program-specific exceptions at every scale using a deterministic source. [First failed matching prefix](first-missing-certificate-level.md) · [Earlier common signed distribution](common-solver-seeds.md)

Orponen, Ko, Schöning and Watanabe studied the length of a time-bounded program that is correct wherever it answers and can abstain elsewhere. Lynch constructed sets on which every solver for a language outside P is slow almost everywhere. Here correctness is required only on the particular finite list, the same program is tested across its indices, and the time threshold is below the encoded length. The question of priority concerns this combination of parameters. [Instance complexity](https://doi.org/10.1145/174644.174648) · [Lynch's complexity cores](https://groups.csail.mit.edu/tds/papers/Lynch/jacm75.pdf)

## Assigning answers while simulating the programs

Use a fixed bounded deterministic interpreter with fixed $O(k)$-bit words and a fixed instruction set, and the local fixed-layout construction of its ordinary 3-CNF. A true output bit has one fully determined chronological log. A deterministic sorting network checks work-memory consistency, comparison and instruction gates use equivalences, and all inactive wires are fixed or omitted. Give the interpreter a finite data field containing its program text, $k$, the selector and the pin. Compile a clock of $H$ with a prescribed convention for acceptance at halt. Padding fixes the encoded size to $Hk^{O(1)}$. Each packed word of any variant is computable in $k^{O(1)}$ steps. Pinning one bit by a single signed occurrence uses two forced false literals. In particular generating a word of a variant does not call the program being encoded. [Unique deterministic clock encoding](unique-checksum-witnesses.md) · [Packed input generation](packed-band-transfer.md) · [Batcher's sorting networks](https://doi.org/10.1145/1468075.1468121)

For the checker program $D$ let each candidate of length $s$ start with mass $w_s=2^{-s-\lambda(s)}$. The $\lambda(s)$-bit prefix code writes $d+1$ with an Elias gamma code and appends the low $d$ bits of $s+1$. Its length satisfies the displayed formula. There are $2^s$ candidates at that length, so the mass across all lengths is at most one by the prefix property. On row $j$, independently clock all candidates with positive budget. Record assertions of zero, one, or abstention. Choose the bit $g_j$ whose asserting candidates have smaller total surviving mass, breaking ties by zero. Double the masses that asserted $g_j$, delete the masses that asserted $1-g_j$, and leave abstainers alone. The total never increases. A candidate that never errs has mass $2^h w_s$ after $h$ timely answers, giving the claimed bound. A known exception to a particular program need never be found by the solver.

On input $(D,k,j,c)$ run this deterministic table computation through row $j$ and accept exactly when $c=g_j$. When simulating a candidate that reads a formula, serve words of the clocked interpreter on $(D,k,i,c')$ with the desired fields. The fixed interpreter and its physical decoder were chosen first, and the finite text field is passed as data. The simulations themselves are cut off even if a candidate tries to simulate $D$. Induction on the row number shows that computing different requested prefixes gives the same common $g$. The unique encoded run makes the two pins complementary. A sound solver taking time $t$ on either formula can provide the bit in $O(t)$ native guest steps, with any fixed width-simulation log losses charged as above. The wrapper requires no promise of a fast answer on the opposite pin.

For an explicit budget let the host simulate a virtual guest step in $k^{d_0}$ time for some fixed $d_0$, including its virtual inputs, register width, and bounded program decoding. Initializing work banks between trials by clearing the touched cells costs at most a fixed multiple of the work of those trials. Limit enumeration to $s$ with positive budget. There are $O(H/k^C)$ candidate strings. Each length contributes at most $H/k^C$ guest steps per row, and there are at most $k+1$ lengths. All rational weights are exactly integral after multiplying by the common power-of-two denominator of the smallest initial weight. Numerators, denominator and sums fit $O(k)$ bits because the mass stays at most one. Code lookup and per-entry bookkeeping have polynomial cost in $k$. The total through the last row, including interpreter simulation (a fixed solver with a larger word-width coefficient can be compiled to operations on multiple guest words and an address trie with polynomial logarithmic overhead), is at most $Hk^{p+d_1+2-C}$ up to a fixed constant, for a suitable fixed $d_1$. Take $C$ larger than $p+d_1+3$. The outer source meets its advertised clock at every large scale, on every pin. The $k$ field can equivalently be recovered from fixed padded dimensions, so the layout is consistent before $D$ is specified. ## Tolerating mistakes and counting advice sharply

The same construction can test fallible early predictions. Split each prior into two pieces, one for the preceding exact betting rule. Use a second rule whose funds are multiplied by $3/2$ on a correct offer and by $1/2$ on a wrong one. Both average multipliers on an offer are one over the two possible table bits. Choose the bit with smaller total *post-update* mass, summing both rules. Then a program with $h$ correct and $m$ wrong offers satisfies $h\log_2(3/2)-m\le s+\lambda(s)+O(1)$. The exact rule in this combined version pays one extra bit. Exact numerator lengths for the fractional rule grow by at most $V$ additional bits. Here $V=\operatorname{poly}(k)$, so the increased arithmetic cost is still covered by enlarging $C$. The clock and list in the leading statement use the exact rule alone. The update is related to the classical weighted majority algorithm. [Littlestone and Warmuth](https://doi.org/10.1006/inco.1994.1009)

On an arbitrary list that has opposite verdicts at every pair, $h$ bits of shared advice always suffice to answer correctly at the first $h$ public indices, with a fixed sound program that abstains elsewhere. Include the common format and use the length of the supplied suffix as $h$. A query costs polynomial time in $k$, including the public selector fields. This gives the leading coefficient one in the exception bound. There is no certificate that an arbitrary incorrect advice string is sound; the theorem quantifies each string that is sound on this list.

### A converse from covering every possible verdict table

Martin-Löf's complexity oscillation theorem already uses a divergent sum and a sweep through binary intervals to compress prefixes of every infinite binary sequence. The finite form below handles tables that can change completely at the next scale, indexes by the length of the advice, and charges the decoder's running time. [Martin-Löf, Theorem 1](https://archive-pml.github.io/martin-lof/pdfs/Complexity-Oscillations-in-Infinite-Binary-Sequences-1971.pdf)

The logarithmic surcharge for simultaneous advice lengths has a quantitative explanation. Let $a_s\ge0$ be an efficiently computable integer schedule, with $h_s=s+a_s$ nondecreasing and $a_s=O(\log(s+2))$. Suppose $\sum_s2^{-a_s}$ diverges. For **any** table of the paired verdicts, a single fixed shortcut with hindsight advice can assert at least $s+a_s$ correct bits, and nothing false, for arbitrarily large allowed advice lengths $s$ as the scale increases. It runs in $\operatorname{poly}(k)$ time. Any fixed additive surplus in the desired number of assertions can be absorbed by increasing all $a_s$ by a fixed constant, which preserves divergence. The fixed code header costs only a constant number of bits beyond the advice. Equivalently start the schedule at the length including that header, reducing each level's available share by the same constant factor.

Partition the lengths into successive finite intervals on each of which the sum of $2^{-a_s}$ first reaches one. Inside such an interval, let $x_s$ be the sum of earlier shares, restarting at zero in the next interval. A candidate $s$-bit advice value $z$ proposes the $h_s$-bit integer $2^{h_s}x_s+z$ as the first $h_s$ verdicts. Abstain outside those indices or if the integer overflows. The offset is integral since $a_i\le h_i\le h_s$ for every previous $i$ in this interval. Level $s$ covers the dyadic interval from $x_s$ to $x_s+2^{-a_s}$, clipped at one. Every binary verdict table with at least $\max h_s$ rows lies in at least one such cylinder. One sound advice string therefore supplies all $h_s$ true answers in its prefix. This uses just integer addition, shifts and extraction of a chosen bit. At each sufficiently large $k$ one can take the last completed length interval ending at most $k/2$, for which $h_s\le V$. These intervals tend to infinity. Computing the offset and interval by iterating through $s$ uses $\operatorname{poly}(k)$ guest time, below the diagonal's per-query clock there.

Conversely a summable schedule with a fixed bound on its sum supports the weight proof with initial masses proportional to $2^{-s-a_s}$. A constant normalization gives $s+a_s+O(1)$ exceptions, with the same time accounting when the exponents and dyadic weights fit the stated word sizes. For example $a_s=\lceil\log_2(s+2)\rceil+O(1)$ fails the summability test, whereas the prefix lengths used above pass. This converse concerns sound advice selected after the formula family is known. It does not assert that this advice can be found cheaply. [Prefix code and cylinder checks](../audits/shortcut_capital_audit.py)

## An upper bound on the whole family

On the promise with $k,j,c$ given, running the checker $D$ to completion already decides every formula in $O(H)$ native steps. The construction also admits a choice of padding for which **one globally correct SAT solver** takes $O(N/\log N)$ native steps on *every* member, with all the preceding lower bounds still valid. This distinguishes the difficulty of spotting a few sound shortcuts from a lower bound exceeding the cost of a full scan.

Choose this padding when fixing the physical compiler, before $D$ simulates any contestants. Suppose the core layout has at most $Hk^A$ packed words and generating a core word costs at most $k^B$ steps for large $k$. Fix the total clause count to be $2^{k+E\lceil\log_2(k+1)\rceil}$ for an integer $E>A+B+3$. Fill the remaining clause slots with the same tautology on an existing variable. This introduces no new variables. Only the public clause-count header changes, all variants still have the same layout, and each filler clause occupies $\Theta(k)$ bits. The public word decoder distinguishes the core from the periodic suffix by the address and uses $k^{O(1)}$ steps in either region. Thus $D$ still fits the original clock after choosing its simulation exponent $C$ for this layout. In particular, it simulates the actual padded inputs, including any program that recognizes the padding.

On an arbitrary input, read and check the header. The strictly increasing prescribed clause counts determine at most one candidate $k$, recoverable in $\operatorname{poly}(\log N)$ work on family inputs. Read its designated selector and pin. Compare every core word with the expected word for that selector and pin, including the header and boundary bits. The work is at most $O(Hk^{A+B})$. Scan the periodic suffix, testing each packed clause in constant word operations with shifts and masks; each clause spans only a constant number of words. Check the exact end of the encoding. If all tests pass, compute the verdict by running $D$ on these parameters. On every failed recognition test use any complete SAT algorithm. The global decision is correct. The total on a family input is $O(Hk^{A+B}+N/k+H)=O(N/\log N)$ because $N/k$ dominates $Hk^{A+B}$ and $\log N=\Theta(k)$. The padding choice here is optional for the lower bound.

The computation of the hidden bits charges the full executions it supervises. For a fixed short solver its per-pair time quota is already below $H$, and the explicit formula costs at least $H$ bits. A way past this specific loss would have to certify the chosen answer while charging less than the full time of a candidate whose decision it reverses, with soundness retained on both pins. Priority of the paired SAT construction at the stated parameters is unverified.
