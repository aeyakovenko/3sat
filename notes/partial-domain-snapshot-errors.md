# How often must an approximate checkpoint decoder err on real reads?

**Research journal, 24 November 2026.** Assume a correct deterministic packed-word RAM decides explicit SAT in time $O(N L^a)$ on inputs of $N$ bits, where $L=\max(2,\lceil\log_2(N+2)\rceil)$ and $a$ is a fixed nonnegative integer. Fix any deterministic base decoder of time $O(L^d)$ that receives the same formula, shared advice $Z$, a block index and a writable address. Its answer is a whole predicted word. As in the exact theorem, use a bounded clock and fix a default on timeout. There is no restriction on the solver's workspace.

Set $d'=\max(d,6)$ and pad the genuine run to its specified valid clock $T=\lceil C N L^a\rceil$. Use $P=\lceil L^{3a+d'+10}\rceil$ equal intervals up to rounding. In a block, call an address incoming if the solver really reads it before writing it in that block. Form $X$ from the distinct triples (block, incoming address, word-bit position). The target bit is the value of this word at entry to the block. A pair read several times in its block contributes its word only once. Write $K=|X|$. For a base string $Z$, let $E$ be the number of mispredicted bits on $X$ and set $e=\min(E,K-E)$. Define $f(K,e)=e\log_2(2K/e)$ for $e>0$, and $f(K,0)=0$, including when $K=0$.

On an unbounded solver- and decoder-dependent family of unsatisfiable inputs, simultaneously for **every** base string,
$$
 |Z|+f(K,e)\ =\ \Omega\!\left(\frac{N}{L^{2a+7}}\right).
$$
Consequently there is $c_0>0$ such that every $Z$ with $|Z|\le c_0 N/L^{2a+7}$ both misses and correctly predicts at least $\Omega(N/(L^{2a+7}\log L))$ distinct genuine read bits on these inputs. For a linear-time solver the denominator is $L^7\log L$. The counting measure concerns bit coordinates of word values. An arbitrarily large set of untouched addresses contributes zero. [Exact value-only checkpoint theorem](solver-snapshot-descriptions.md)

For the same inputs there is a **word entropy bound with no restriction on the residual alphabet**. Let $M$ count the distinct actual (block, incoming address) pairs. On each such key form the predicted word XOR its actual value, and let $H_0$ denote the base-two entropy of this residual under a uniform genuine key. Then $|Z|+M H_0=\Omega(N/L^{2a+7})$ simultaneously for every $Z$. With no advice and a constant zero prediction the genuine words themselves obey this entropy bound. The proof below uses one pool of hash functions shared by the whole word dictionary.

## Correcting a binary function on its genuine domain

Suppose a finite set $X$ of $K$ distinct $O(L)$-bit keys carries binary correction labels. Record one polarity bit so the minority class $A$ initially has size $e$ and label one in the normalized representation. The other class $B$ has size $K-e$. At a level with $u=|A|>0$, choose a power of two $m$ with $2u\le m<4u$ and $k=\lceil\log_2(2+2|B|/u)\rceil$. Make $k$ independent hash tables, each an $m$-bit array marking every image of $A$ under its hash. A key passes if it hits marks in all arrays. A uniformly random binary matrix of the appropriate shape hashes two distinct keys to the same position with probability $1/m$, since each row has an independent fair inner product with their nonzero difference. The probability that a fixed $b\in B$ passes a single array is at most $u/m\le1/2$ by a union bound. The expected number of keys $F\subseteq B$ passing all arrays is at most $|B|2^{-k}\le u/2$, so some ordinary fixed matrices achieve $|F|\le u/2$.

A failed test immediately returns the label of $B$. On a pass the possible valid keys are precisely $A\cup F$. Continue with the new target set $F$ and the new opposite set $A$, reversing the two label roles. If the new target set is empty, return the remaining label. Each nonempty target shrinks by at least a factor of two. Induction gives the prescribed bit everywhere on $X$. The evaluator may give either answer elsewhere. If $e=0$ the polarity bit alone suffices, and on $X=\varnothing$ even this choice is immaterial. [Finite cascade semantics](../lean/CascadeSnapshotErrors.lean)

The initial arrays cost $O(e\log(2K/e))$ bits. At each later level the new sizes are $u\le v/2$ and $|B|=v$, so the arrays cost $O(u\log(2+v/u))=O(v)$. The sum over these levels is $O(e)$ by geometric decay. More explicitly, the first level costs at most $12e\log_2(2K/e)$ and the later ones together at most $32e$ bits. There are $O(L)$ levels and $O(L)$ hashes per level, each described by an $O(L^2)$-bit matrix and ordinary packed offsets. Thus the whole description costs $O(f(K,e)+L^4)$ bits. Each bit can be queried in $O(L^4)$ elementary word steps even with a separate operation for every matrix entry. No key list or recognizable description of $X$ is needed at lookup. For a fixed known $X$ and prescribed minority size $1\le e\le K/2$ there are $\binom Ke$ possible minority sets. Counting binary descriptions shows that some labeling needs at least $\log_2\binom Ke-1$ bits, giving the same order of dependence for unrestricted binary labels.

Alternating false positives are the established cascade Bloom filter construction. Compressed static functions and relative membership also address queries restricted to a given domain. The application here charges every hash matrix in a checkpoint certificate for the actual incoming reads of SAT. Priority of the SAT consequence is unverified. [Tripunitara and Carbunar](https://ece.uwaterloo.ca/~tripunit/papers/enforcement-dist-RBAC-sacmat-09.pdf) · [Belazzougui and Venturini](https://pages.di.unipi.it/rossano/assets/pdf/papers/SODA13.pdf) · [Li et al.](https://arxiv.org/abs/2308.13632)

## Applying the exact obstruction

Package $Z$, its length and the correction structure into one shared string. The fixed wrapper obtains the decoder's word once and queries the structure separately for each bit, returning the XORs. Use an offset into the packed string to present $Z$ to the base decoder. The wrapper bounds lengths, loops and all array accesses and returns a default on malformed data. True data use $O(L)$-bit keys, a polynomially bounded array address space, $O(L)$ bits per guest word, and $O(L^{d'})$ work per word. The allowed description length in the contradiction is sublinear in $N$. A combined string exceeding that length already gives the claimed lower bound through its construction cost. The same wrapper works for every base string. It recovers the exact value on every actual incoming address, precisely the premise of the value-only replay theorem. Apply that theorem **to the wrapper** to obtain a family independent of $Z$. Absorb the additive $O(L^4)$ into the lower bound.

Each instruction makes only a constant number of word accesses, so $K\le C_1 N L^{a+1}$. Put $p=2a+7$ and $K_{\max}=C_1NL^{a+1}$. For $x=cN/(L^p\log L)$, the function $y\log_2(2K_{\max}/y)$ increases on $0<y\le x$ at sufficiently large $N$, and $\log_2(2K_{\max}/x)=O(\log L)$ for every fixed $c>0$. For a sufficiently small fixed $c$, the cost at $x$ is below the remaining description threshold, since its ratio to $N/L^p$ tends to $c(a+1+p)$ with base-two logarithms. Thus $e>x$ for sufficiently short $Z$. The factor $\log L$ comes from coding the minority density among possible genuine keys. The direct directory storing a full address per mistaken bit would charge $O(L)$ bits per correction here. The earlier hard-subset result permits predictors with more context and gives a different measure on selected reads. [Hard subsets of incoming reads](recurrent-live-prediction.md)

A refinement allows a fixed tag with $L^{O(1)}$ possible values on keys, computable in polylogarithmic time. Build the same structure for each nonempty tag using a packed directory with one offset and polarity per tag, including defaults for empty tags. With tag lookup within the word query clock, the same argument lower-bounds $|Z|+\sum_j f(K_j,e_j)$ on the corresponding wrapper's family. Here $K_j$ is the number of actual bit keys of tag $j$ and $e_j$ its minority correction count. For a slower tagger increase $d'$ to cover evaluation at all word-bit positions. All extra headers, offsets and matrices remain polynomial in $L$. In particular the tags can be the word-bit positions themselves, allowing their minority orientations to differ.

## Entropy of the entire word correction

Let $M$ count the distinct actual incoming **word** keys (block, address). For each such key let $R$ be the base word XOR the genuine word. Let $D$ count the distinct residual masks and $H_0(R)$ be the empirical base-two Shannon entropy of their distribution, giving each distinct word key equal weight. Set $M H_0=0$ for an empty domain. There is a fixed wrapper giving a single hard input family for the word entropy inequality and the bit-error inequality above. Write $S=N/L^{2a+7}$.

Build a compressed binary prefix trie on the $D$ masks, suppressing chains with one child. Store the actual word at each leaf. At every branch $v$, encode the correct child bit on the word keys whose true residual reaches $v$. Although these keys involve the unknown residual, the lookup has no need to recognize its domain. Following the returned children from the root recovers the entire correction at a leaf. On each genuine key the induction premise for the next branch holds. There are at most $2D-1$ nodes for $D\ge1$ and at most one branch per word-bit position along any path.

At a branch with $m_v$ keys and smaller child count $e_v$, $f(m_v,e_v)\le2m_v H_2(e_v/m_v)$ by the binary entropy formula and $e_v/m_v\le1/2$. The branch entropies telescope,
$$
\sum_v m_v H_2(e_v/m_v)
=M\log_2 M-\sum_r n_r\log_2 n_r=M H_0(R),
$$
where $n_r$ counts occurrences of residual $r$. Separate matrices for every branch would cost $O(DL^4)$ extra bits. The following sharing argument reduces the cost of describing the tree and hashes to $O(DL+L^5)$.

Round the initial positive minority count in a branch upward to a power of two $A$, and write $B$ for the initial opposite count. Use the predetermined integer capacities $A_j=A/2^j$ for $0\le j\le\log_2 A$, ending at one. At stage $j$, each hash array has $2A_j$ slots. Use $k_0=\lceil\log_2(16+16B/A)\rceil$ hashes at the first stage and $k_j=\lceil\log_2(32(j+1)^2)\rceil$ thereafter. Conditional on every previous stage meeting its capacity, the target size is at most $A_j$ and each other key passes a single hash with probability at most $1/2$. The expected number of false positives is at most $A/16$ initially. At later stages the opposite size is at most $A_{j-1}=2A_j$, so the expectation is at most $A_j/(16(j+1)^2)$. The matrices for the current stage are independent of the previous ones. Markov's inequality bounds the conditional chance of more than $A_j/2$ false positives by $1/(8(j+1)^2)$, including $j=0$. Summing over the first failing stage gives failure probability less than $1/2$ for a whole random schedule. At $A_j=1$ the promised upper bound on the integer false-positive count forces zero. An empty target can be encoded with blank bitmaps at every remaining stage. Lookup at the first such stage returns the opposite label on every active key. Because capacities and hash counts are prescribed, no additional per-stage parameters are needed.

The marked arrays cost $O(e_v\log(2m_v/e_v))$ bits at the first stage. All later ones together cost $O(e_v)$ since $\sum_{j\ge1}2^{-j}\log(32(j+1)^2)$ converges. Now draw $\lceil\log_2(4(D+1))\rceil$ independent **whole schedules** and make this bank available to every branch. Store each matrix with fixed $O(L)$ input and output dimensions, taking the required number of output rows at a specific stage. A bank has $O(L)$ schedules, each with $O(L)$ stages and $O(L)$ hashes per stage, hence $O(L^5)$ bits. The probability that a particular node has no good schedule is at most $2^{-\lceil\log_2(4(D+1))\rceil}$. The branch domains and their labels were fixed by the genuine keys before choosing this bank. A union bound over the nodes gives a bank serving every node, with no need for good-schedule events at different nodes to be independent.

At a branch store its schedule index, initial size parameters, polarity, packed-array offset and child identifiers, taking $O(L)$ bits. Its later offsets can be computed sequentially from the prescribed sizes. The leaf masks together take $O(DL)$ bits. Full queries visit $O(L)$ cascades for at most $O(L^5)$ elementary steps beyond querying the base decoder, reading individual matrix entries from the packed seed data. Bounds-check every level, child and offset on malformed data. A fixed format flag selects the earlier bit repair or this word repair, and another lets the wrapper use a constant zero word in place of the base prediction. Thus the raw-word and residual bounds hold on the same family. Its true input length satisfies
$$
\Omega(S)\ \le\ O\bigl(|Z|+MH_0(R)+DL+L^5\bigr).
$$
There is no construction-time requirement for this advice. For $D=0$ or $D=1$ use an empty table or a single leaf and skip the bank.

**Absorbing the alphabet cost.** First use the displayed inequality with the empty base string on its hard input. For that base $D\le M$ and $H_0\le\log_2(\max(1,M))=O(L)$ since $M=O(NL^a)$. Thus $M=\Omega(S/L)$ on this family and $\log_2 M=\Theta(L)$ for all sufficiently large members. The key count depends only on the solver's genuine run and is shared by all base strings. For any other $Z$ with $D\ge2$, choose one most frequent symbol. Every other multiplicity $u\ge1$ obeys $2u\le M$. Since $u\le2^{u-1}$, we have $u^u\le(2u)^{u-1}\le M^{u-1}$, so each such class contributes $u\log_2(M/u)\ge\log_2 M$ to $M H_0$. Summing gives $M H_0\ge (D-1)\log_2 M$. Hence $DL=O(MH_0)$ uniformly for $D\ge2$ on this family. When $D\le1$, $DL$ is only $O(L)$. Absorbing $L^5=o(S)$ proves $|Z|+M H_0(R)=\Omega(S)$ as claimed. [Finite absorption inequality](../lean/CascadeSnapshotErrors.lean)

If $D\le L^c$ for fixed $c$, every short $Z$ on this family has at least $\Omega(S/\log L)$ genuine word keys **outside its most frequent residual class**. Indeed, writing $u=M-\max_r n_r$ gives $M H_0(R)\le M H_2(u/M)+u\log_2(D-1)$ when $D\ge2$. For $u>0$ this is at most $u\log_2(\mathrm{e}M/u)+u\log_2(D-1)$, with $\mathrm{e}$ Euler's number. Invert this bound as for bit errors using $M=O(N L^a)$. A single constant mask cannot occur under these budgets on sufficiently large hard inputs. This forces that many whole-word errors even after applying the best constant XOR mask.

**Conditional entropy given a local tag.** Fix $0\le\alpha<1$ and a fixed polylog-time algorithm that, given the actual query key, the formula and $Z$, computes an integer tag between zero and $\lceil N^\alpha\rceil-1$. On the hard family of the wrapper including this tag algorithm, one also has
$$
 |Z|+\sum_j M_j H_0(R\mid j)=\Omega(S).
$$
Here $M_j$ is the number of genuine word keys with tag $j$ and $H_0(R\mid j)$ is their empirical residual entropy, with empty terms zero. Put the offset of a separate word trie at each possible tag in a directly indexed directory, marking empty groups. The directory and the seed banks of all nonempty groups together cost $O((N^\alpha+1)L^5)=o(S)$. Group membership can use advice and need never be enumerated during a query. For groups with $M_j<N^{(1-\alpha)/2}$, all labels and node metadata together cost $O((N^{(1+\alpha)/2}+1)L)=o(S)$ since $D_j\le M_j$. In the larger groups $\log_2 M_j=\Omega(L)$, so every $D_j\ge2$ contributes $O(M_j H_0(R\mid j))$ metadata by the same singleton estimate. One-leaf groups cost $O((N^\alpha+1)L)$ overall. Recover the tag once and look up the corrected word. Increase $d'$ to cover the tag evaluator when necessary, using the corresponding exact-theorem grid. The bound demands no efficient procedure for identifying the genuine keys. An unrestricted distinct tag for every genuine key could make every conditional entropy zero.

## Tags with a nearly linear range

There is a quantitative form between fixed power savings and a distinct tag on every key. Write $g$ for the tag range, assume the tag evaluator meets the query clock, and put $H_{\rm tags}=\sum_j M_j H_0(R\mid j)$. Build the forest of word tries using one bank of schedules for the **whole forest**. There are at most $M$ branching nodes in its nonempty groups, since it has at most $M$ leaves. Every node has a fixed labeled domain before any hash is chosen. The same union bound uses $O(\log(M+2))$ schedules in total. The node headers, leaves and the directly indexed group directory cost $O((g+1+\sum_j D_j)L)$ bits, where $D_j$ counts distinct residual words in group $j$. The seed bank costs $O(L^5)$ bits once.

For every integer threshold $v\ge2$ up to the polynomial size of the domain, groups with $M_j<v$ contribute at most $gv$ distinct residuals altogether. Every larger group with $D_j$ distinct residuals pays for at least $(D_j-1)\log_2 v$ through its empirical entropy. The full exact description therefore gives
$$
 |Z|+\left(1+\frac{L}{\log_2 v}\right)H_{\rm tags}
       +(g+1)vL+L^5=\Omega(S).
$$
The threshold is used only to bound the length of one fixed description. The lookup algorithm does not need it.

Fix $\rho>0$ and take $g\le N/L^{2a+8+\rho}$. With $v=\lceil L^{\rho/2}\rceil$ the directory and small-group terms are $o(S)$. For sufficiently short advice $|Z|\le c S$ on the hard family this forces
$$
 H_{\rm tags}=\Omega\!\left(\frac{N\log L}{L^{2a+8}}\right).
$$
The constants can depend on $\rho$. At linear time the tag can take nearly $N/\log^{8+\rho}N$ different values. This is an extension of the prediction bound on genuine reads, with a logarithmic loss in entropy. For arbitrary tables a description-length argument faces a cost even when the entropy in every group is zero. Fix a key in each of $g$ nonempty groups, give each group an arbitrary independent $W$-bit constant, and take a fixed zero predictor. All these labelings have zero conditional entropy. There are $2^{gW}$ possible tables on the same keys and same tags, so a fixed exact decoder requires at least $gW$ bits for at least one labeling. At word width $W=\Theta(L)$ and $g$ of order $S/L$, this term alone can account for the entire description threshold. This counting example concerns arbitrary labelings and does not construct a SAT solver attaining them.

The finite audit exhausts all partial binary labelings of eight keys and tests larger finite-field examples with genuine second and later layers. It checks the returned bit at every valid key, halving at each level, the depth and the space bound for the marked arrays. Separate checks reconstruct multi-bit words through recovered branch choices, verify the branch entropy sum, and exercise the bank of whole hash schedules shared between nodes. Another 204 tagged forests reuse one bank across groups and test the alphabet-cost bound at four thresholds. The SAT consequence and its asymptotic running-time accounting are manuscript arguments. Obtaining an unrestricted time separation would require an upper bound on these residuals for some suitable decoder for every fast solver.
