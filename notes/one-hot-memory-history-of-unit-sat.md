# A one-hot memory history for a SAT solver

The pinned matrix-multiplication preprint gives a trivalent tensor-network volume bound for list distinctness. The journal's transfer gives a bound for two lists of units, positive and negative, with distinct names within each list. For $N=2^w$ names per list of $O(w)$ bits, computing the product of $t$ promised SAT answers over a fixed finite field takes $\Omega(tNw^{1+\sigma})$ volume for some $\sigma>0$, at every sufficiently large $w$ and $1\le t\le N$. The volume counts binary wires and bounded-arity tensors. The result takes the manuscript's mathematical theorem as an external input. [Preprint, Theorem on volume of list distinctness](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/build/obstruction.tex) · [Signed transfer to promised unit-SAT, including the batched product](matrix-list-unit-sat.md#one-sat-answer-tensor-with-two-ordered-lists-of-literal-positions)

There is one globally correct deterministic SAT solver whose **entire sequence of writable-memory read values** on these inputs has only $tN+1$ possibilities, with constant-time indexed decoding given its index. On every such run, every data cell changes value at most twice and finishes at its initial zero. All dictionary writes precede all dictionary reads, except for a final write-only reset. The volume lower bound still holds for checking the solver's history, even when allowed a fixed positive gap in relative Hamming distance.

## The actual program and the size of its physical inputs

Combine the formulas into a single conjunction by prefixing each name with its list number, then putting all positive records before all negative records. Write $P=tN$. In a fixed-width unit-clause serialization this is one ordinary CNF on $L=\Theta(tNw)$ encoded bits, with $\log L=\Theta(w)$. The marker address fits in $O(\log L)$ bits. The target RAM convention permits a word-width coefficient sufficient for the polynomial address range, sparse writable memory initially zero, indirect access, and unrestricted space. The map on physical input bits uses constants and wires, or $O(L)$ bit gates with a fixed offset convention. A decision on this family computes the product of the original unit-SAT answers. The lower bound thus applies on this same physical layout.

The solver recognizes lists of unit clauses in a sequential read-only scan using a fixed number of registers. It sends other formulas to a complete SAT procedure. It can also recognize exact-width-three presentations in which each unit $u$ is expanded into the four clauses $(u\lor\pm a\lor\pm b)$ with all four sign combinations and two privately named reserve variables per slot. Public reserve identifiers in a disjoint namespace allow this test to use registers only. Such a recognized block imposes exactly the unit. The claimed history concerns the recognized family. Read-only formula fetches and register uses are distinct from writable-array reads.

Use a dictionary of one-bit markers indexed by the original variable names. Reserve a permanently zero cell and set one further cell to one. Scan the full formula, writing one to the marker of each positive literal. Scan the full formula again, visiting its negatives in order with a Boolean register `clean` initially true. While `clean` holds, read the negative name's marker. The first one sets `clean` false forever. After that point, each remaining negative instead reads the reserved zero cell. At the end read the reserved one cell if `clean` is true and the zero cell otherwise. The resulting $P+1$ read replies contain **exactly one one**, at the first conflicting negative or at the final sentinel if the conjunction is satisfiable. Duplicate names within either sign list also cause no error in this algorithm.

Erase the markers by writing zero to every positive name in a final sequential pass and restore the reserved one cell to zero. All write addresses and values depend only on the read-only formula, independently of the writable-memory replies. Each touched marker undergoes at most one transition in each direction. In particular there is no sorting, input-dependent payload word, exchange of records, or chain of general-purpose address computations. One irreversible change of the `clean` register directs the later probes to a known address. The verifier of an alleged history must still determine whether any of the actual input names collide. The program takes $O(P)$ word operations, or $O(L/\log L)$ steps on the physical promise, and touches $O(P)$ marker cells. On a batch of $t$ lists the short history records a single global position.

## Tolerant verification still costs the list volume

One can arrange a Hamming gap while retaining just the same short description and the same histogram on every run. Between the sentinel and the reset, append $r$ reads of the constant cell holding `clean`'s value, followed by $r$ reads of the other constant cell. These are actual indirect reads from the two reserved locations. Let $H_+$ be the one public string consisting of $P$ zeros, the positive sentinel, $r$ ones, then $r$ zeros. Every run has length $P+1+2r$ in writable-memory replies and exactly $r+1$ ones. Its full reply to any given index is computable by a constant number of comparisons from the one-hot position, $P$, and $r$.

On every satisfiable input the actual reply string equals $H_+$. On every unsatisfiable input its Hamming distance from $H_+$ is exactly $2r+2$: one moved one in the first block and complementary echo blocks. Fix any $0<\rho<1$. Choose $r=c(P+1)$ for a fixed integer $c$ with $2c/(1+2c)>\rho$. The running time remains $O_\rho(P)$, and every unsatisfiable run is farther than relative distance $\rho$ from the same $H_+$. Consequently a trivalent network on the physical formula and a claimed history which accepts equality and rejects distance greater than $\rho$ decides the whole product when its claim inputs are fixed to $H_+$. The same holds if the claim is just the short sentinel-position code. Pinning the extra inputs costs $O_\rho(P+w)$, so the lower bound is $\Omega_\rho(tNw^{1+\sigma})$. Arbitrary behavior at intermediate distances is allowed. Even allowing unique accepting witness extensions in a bounded-fan-in Boolean validator leaves this implication intact: summing the witnesses with gate-equivalence tensors returns its exact Boolean acceptance indicator.

For an alternative output requirement, suppose a bounded-fan-in circuit prints a reply string with at most a $\delta$ fraction of wrong bits on every physical input, for fixed $0\le\delta<1/2$. Take $r$ large enough that $\delta(P+1+2r)<r$. Comparing the printed echo segment with its two possible complementary words recovers the SAT verdict by majority. A balanced tree of carry-propagating adders uses $O_\delta(P)$ gates in total: level $d$ adds $O(d+1)$-bit counts for $O(P/2^d)$ blocks. Thus the same superlinear bit-circuit lower bound applies to producing a uniformly accurate approximation. This statement requires accuracy on each input; a promise of correctness in expectation over an input distribution has different quantifiers.

The public complete-history claim is a test about the run of a particular correct RAM solver. That solver itself checks the claim in linear word time by running the marking pass. This provides a counterexample to transferring the preprint's volume lower bound to RAM time on the basis of short locally decodable work-read replies, fixed histograms, or complete reset of mutable memory. It leaves the unrestricted SAT time question open.
