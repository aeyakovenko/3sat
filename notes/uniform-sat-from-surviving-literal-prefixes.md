# Uniform SAT time from the number of advice prefixes surviving finite tests

Let a fixed deterministic scalar word-RAM template decide ordinary proper ASCII DIMACS SAT in at most \(C(n+1)\) steps with one coherent tuple of \(r\) binary literal streams. On an \(n\)-bit file it uses their low \(w(n)\) bits, where \(w(n)=16\lceil D\log_2(n+2)/16\rceil\), and \(C,r,D\) are fixed. The finite structure and clock are known to the simulation. For dyadic \(M\ge 16\), let \(H(M)\) be the complete set of \(r w(M)\)-bit tuples that meet this clock and give correct answers on **every** legal input of length at most \(M\); smaller runs truncate the tuple to their actual width. Write \(W(M)=|H(M)|\). Every prefix of the stipulated infinite solver belongs to the corresponding set. The uniform procedure neither assumes that all surviving tuples extend to infinite solvers nor tries to identify the specified infinite tuple.

**Proposition.** If \(W(M)=O(M^\beta)\) on dyadic horizons for some \(0\le\beta\le1\), ordinary SAT has a deterministic uniform \(\widetilde O(n^{2+\beta})\)-time logarithmic-width RAM decider. If \(W(M)\) is polylogarithmic, the bound is \(\widetilde O(n^2)\). The polylogarithmic exponents can depend on the fixed width coefficient and the number of streams. More precisely a stage from \(m\) to \(2m\) costs \(\widetilde O(m^2 W(m))\) whenever \(W(m)=O(m)\). A direct enumeration at the final length instead costs \(\widetilde O(n^{2+rD})\), so the new exponent is strictly smaller when \(\beta<rD\). The extra hypothesis concerns finite-horizon ambiguity, not merely the number of infinite paths. The proposition supplies no unconditional bound on this ambiguity for SAT.

## A verified witness of an incorrect shorter response

For a candidate \(h\) at horizon \(M\), a witness contains a byte-aligned \(d\le M\) and one legal \(d\)-bit file \(X\). At this length use the repository's closed self-reduction. A base has fewer than eight clauses or no occurring identifier greater than three; truth is checked directly since the former has at most 21 occurring variables and the latter at most three. In a nonbase choose old values for identifiers 1 and 2 and a pivot greater than 3, then satisfy the first eight original clauses by the first true literal consistent with the branch. Delete them; apply the partial valuation to the remaining clauses, discarding contradictions. Fresh meanings for names 1 and 2 supply false padding literals, enforced by six proper clauses on 1,2,3. At most \(8\cdot3^8\) children are needed. The eight dropped rows save at least 64 bytes; the six enforcing rows use 59, retained rows never grow, and legal body whitespace restores the original length exactly. Each child has at most the parent's clause count minus two. The parent is SAT if and only if some child is SAT. The proof covers numerical canonicalization and the missing last newline. [Full self-reduction](same-length-local-defects-for-ordinary-sat.md)

A local defect is a timeout, a wrong base answer, or an internal response unequal to the OR of the children's responses. A child's timeout can also be treated as a defect. All candidate runs here use width \(w(d)\) and files of exactly \(d\) bits. Absence of defects implies correctness on the entire slice by induction on clause count, so a false YES on an unsatisfiable formula has a short **defect witness** without any requirement that the formula itself have a short externally supplied refutation. Parsing, building the constant child list, and simulating the fixed linear clock cost \(O(M)\) native steps for the guessed witness. A widened uniform host can pack the guest's input words sequentially, with masked operations thereafter and sparse scratch initialization.

## Batch removal with a table of surviving candidates

Exhaust the constant first horizon directly. Suppose \(H(m)\) has been computed. Let \(M=2m\), and let \(S\) initially contain every extension to width \(w(M)\) of every member of \(H(m)\). The doubling changes each literal width by \(O_D(1)\), so \(|S|=O(W(m))\). Every member of \(H(M)\) lies in \(S\).

For the current table \(S\), build the ordinary proper SAT query \(E_S\) expressing existence of \(h\in S\) and of a local defect for \(h\) at some \(d\le M\). Witnesses guess a table index, \(d\), and the root file; pad these fields to \(O(M)\) raw nondeterministic bits. The table is public, including the actual candidate literal residues. When \(W(m)=O(m)\), its bit length is \(O(M\log M)\); it can be scanned or initialized within \(O(M\log M)\) work. After reading the indexed string, the verifier performs the preceding root/child checks. Thus the existing quasilinear compilation of a clocked RAM on its free input bits gives an explicitly generated proper DIMACS query of length \(O(M\log^4(M+2))\), uniformly over all intermediate subsets. Padded witnesses and public memory also fit that bound. [RAM-to-DIMACS construction](local-sorting-for-parsimonious-ram-encodings.md)

Choose one byte-aligned length \(L=O(M\log^4(M+2))\) sufficient for *all* these queries and all pinning steps. This bound can be computed from the initial table size at the stage; the algorithm does not require an external bound on \(W\). Pin only the raw nondeterministic bits, at most \(O(M)\) of them, with the proper four-clause unit construction. The compilation's internal circuit and sorting wires remain existential. Their deterministic semantics guarantee that any extendible pin assignment is a genuine witness of the existential verifier. Per-pin decimal names have \(O(\log M)\) bits, so all pins together fit the selected bound. Rebuild and pad each query to exactly \(L\) before simulation. [Pinning on ordinary encoded files](finite-sat-exhaustion-with-unbounded-literals.md)

List every extension of \(H(m)\) to width \(w(L)\). There are at most
\[
 K = W(m)\,2^{r(w(L)-w(m))}=W(m)(\log M)^{O_{r,D}(1)}
\]
of them, because \(L/m\) is polylogarithmic. One list entry is the actual coherent tuple at \(L\). The list stays fixed while \(S\) shrinks.

For each larger candidate \(b\) in this list, run the usual pin-to-false assignment search on \(E_S\) using \(b\)'s decisions at length \(L\). Check the resulting raw witnesses by *running the original verifier*, including membership in the current \(S\). A timeout or failed check ends this candidate's turn and advances to the next \(b\). On a verified defect remove its one named \(h\) from \(S\), rebuild \(E_S\), and try the same \(b\) again. Stop if \(S\) becomes empty or the larger-candidate list ends. No verified deletion removes a good horizon tuple. During the true larger candidate's turn, every satisfiable \(E_S\) yields a verified defect. Its turn can therefore end only after all bad tuples have already been deleted. The final set is exactly \(H(M)\). In particular the algorithm never asserts that the larger candidate is correct just because its search returns failure.

Each trial costs \(\widetilde O(M^2)\) for at most \(O(M)\) pin queries, each of length \(L\), and for generating the formula and checking the witness. There are at most the initial \(|S|\) successful trials in total and at most \(K\) failed trials. This is an additive count; an independent full examination of every smaller tuple against every larger tuple is unnecessary. Iterating up to the first dyadic \(M\ge n\) and using any final survivor on the input gives the claimed running time. A fixed finite collection of template structures can be kept in the tables as an additional constant-size field, as long as one structure has a coherent correct path and \(W\) counts all surviving tuples. This is a deterministic bound under an explicit further premise, not a quasilinear removal of arbitrary coherent advice.

## What this says about a finite-to-infinite induction

For any one template in the proposition there is a fixed exponent $L$ such that, if $W(m)\le m/\log^L(m+2)$ eventually, the uniform decider runs in $O(n^3)$. Choose $L$ at least as large as the accumulated fixed logarithmic exponent in the stage bound. Therefore a proof excluding cubic time would force every coherent *linear*-time template, if any exist, to have more than $m/\log^L(m+2)$ finite survivors at arbitrarily large dyadic horizons for its corresponding $L$. This brings the finite exhaustion closer to the cubic target than an unspecified polynomial-time uniformization. The cost still exceeds linear time even in the narrowest case.

A large survivor count need not signal a long list of distinct useful algorithms. Given any hypothetical coherent linear-time template, add one stream whose intended value is zero. At length $n$ first inspect only its lowest $\lfloor\log_2\log_2(n+2)\rfloor$ bits. A nonzero result makes the wrapper time out; otherwise use the original template. Use a new fixed linear clock that covers the wrapper's overhead. At least one valid padded formula exists at every sufficiently large byte-aligned length, so any ancillary stream admitting all horizons must be exactly zero. But at horizon $m$ its other $w(m)-O(\log\log m)$ bits are free, giving at least $2^{w(m)-O(\log\log m)}$ survivors. The example can be removed from this particular template merely by deleting the unnecessary stream. It shows the difference between uniqueness of infinite ancillary data and uniqueness of finite survivors in the displayed algorithm.

Lean checks that verified deletions preserve all good candidates, an honest candidate at any position clears the remaining bad ones, and the numbers of successful and failed trials add. The native compilation, self-reduction and time bounds are manuscript arguments. Historical priority for this parameterized exponent is unestablished.
