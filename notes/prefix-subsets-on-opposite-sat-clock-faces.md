# Opposite SAT deadlines on all subsets of a list of original prefixes

Suppose proper explicit DIMACS 3-SAT has no deterministic $O(n^k)$ solver on the logarithmic-word RAM with unrestricted workspace, with $k=2$ or $3$. Fix a nonempty finite portfolio of correct programs and a constant $C>0$. At arbitrarily large lengths $N$ there is a physical Boolean cube with $t$ mask bits and one polarity bit. Every program in the portfolio takes more than $CN$ instructions on **every** vertex. Every mask has one SAT vertex at polarity zero and one UNSAT vertex at polarity one. There are $\Theta(\log N)$ such opposite-verdict pairs for $k=2$, and $\Theta(N\log N)$ for $k=3$.

The mask implements all subsets of $t$ **distinct partial assignments of the original variables** at a single depth of one search. Write them $p_1,\ldots,p_t$. There are also two disjoint nonempty fixed lists $Z,U$ of other prefixes at that depth. Before imposing the source clauses, the prefixes allowed at polarity one are precisely
$$
                  U\ \cup\ \{p_i:z_i=1\}.
$$
At polarity zero the allowed prefixes are $Z\cup\{p_i:z_i=0\}$. Switching one mask bit exchanges a single named prefix between the two sides. All $2^{t+1}$ allowed sets are distinct. On the hard cube all satisfying completions in the live list extend a prefix in $Z$. Thus all the SAT vertices have precisely the same **nonempty set of source witnesses**, and every such witness extends uniquely to each SAT file.

The earlier parity-child menu can have directions with both children satisfiable. The physical parity selector can give opposite verdicts on every edge by selecting between two source children. Here the family simultaneously realizes every independently chosen subset of a list of original prefixes, with each polarity pair opposite on the hard residual. This is a necessary condition for the stated unrestricted time exclusion. ## Search and first loss

Normalize the source to a list of $v$ occurring variables and $c$ distinct proper triples. Comparing lengths and lexicographic digits handles sparse decimal names. The usual digit trie and radix sorts take $O(n)$ word steps. Distinct variable and clause spellings give $v+c=O(n/\log(n+2))$ after removal of duplicates. Use a fixed ordering of these variables. Start with the empty assignment and maintain a list of at most $3t$ distinct prefixes of the same length. Append the next variable with both possible values to each prefix. If there are now more than $3t$ entries, apply the following pruning round until at most $3t$ remain. [Normalization and input model](dense-sorted-cores-for-ram-exhaustion.md)

At a round the list size $q$ lies in $(3t,6t]$. Take $t$ entries as the zero block $Z$, another $t$ entries as individual $p_i$, and the remaining at least $t$ as the one block $U$. For each mask and polarity run each program for an integer timeout at least $CN$ on the file described below. On any timely YES retain the indicated subset. On any timely NO retain its complement. Stop testing the round once a reply arrives. Either selection preserves at least one satisfying completion if one was available. When every trial times out, discard $Z$ and retain all other entries. A timely selection and a default both remove at least $t$ entries, so at most three pruning rounds are needed per source variable. At the final depth, test each remaining complete assignment against the source and accept only upon finding an actual witness.

On a positive source where the search returns NO, consider the first step that loses all satisfying completions. Appending the next variable preserved every old completion. A timely reply would have preserved a completion. Thus the loss occurred on a default, and all the previously available completions extended $Z$. Exactly the claimed two faces result. This argument concerns actual bounded executions on valid inputs; simulations don’t charge one run's cost to another.

## Compact files for a list of long prefixes

Assign a fresh one-hot state to each of the $q$ entries. One disjunction and the pairwise exclusions force exactly one selected state, costing $O(q^2)$ gates or clauses. The first $j$ bits of the source assignment must equal entry $j'$ if state $j'$ is selected, where $j$ denotes the current prefix length. Build the following shared tables to avoid printing $q$ implications per original variable.

Split the states into twelve banks, possibly empty, of size at most $\lceil q/12\rceil\le\lceil t/2\rceil$. In each bank make an OR gate for each subset of size at least two, using its least element and the output for the smaller subset. Singletons use their state signals directly. For every source variable in the prefix, select in each bank the states at which that variable is one. Set the original variable equal to the OR of the nonempty selected bank outputs, or pin it false when there are none. Each column of the prefix list thus costs $O(1)$ additional gates after table construction. Distinct list entries ensure each allowed assignment has only one possible selected state.

Use proper triples to pin three anchors to $(0,0,1)$ by excluding the other seven triples of truth values. The two false anchors allow unit and binary clauses on other names to be padded by distinct names. Use the standard functional OR, equality and complement relations on fresh variables. For each mask bit and for the test output allocate a pair of complementary variables at adjacent decimal IDs ending in 2 and 3. Use a clause with the two false anchors and one member of that pair to stipulate its chosen value. Each of these $t+1$ choices changes exactly one physical ASCII bit. Give the test output value zero on $Z$ and one on $U$ using implications from the selected state. On each tagged state use two guarded implications equating the output with its mask bit. Its own one-clause pin selects the polarity. All other clauses are shared. Reserve the paired identifiers before allocating the source and internal variables, and pin the $O(t)$ unused identifiers between the reserved names false. This gives dense IDs throughout.

All constraints on states and auxiliary gate outputs are functional once a source assignment satisfying the requested prefix test is given. In particular, writing $a_Z,a_U,a_1,\ldots,a_t$ for the counts of source witnesses with the indicated live prefixes, the number of complete models at polarity one is exactly $a_U+\sum_i z_i a_i$. At polarity zero it is $a_Z+\sum_i(1-z_i)a_i$. The exhausted menu implements this entire table on every residual. At first loss only $a_Z$ is positive. The counts concern assignments to occurring source variables.

## Time and encoded length

For quadratic time take $t=\lfloor\log_2\log_2 n\rfloor$; for cubic time take $t=\lfloor\log_2(n\log_2 n)\rfloor$, with harmless small-length exceptions. There are $O(v+c+t^2+2^{\lceil t/2\rceil})$ names and rows in each file. Their decimal encodings and the header take $O(n)$ bits in both regimes, since in the larger regime even $\sqrt{n\log n}\log n=o(n)$. Pad by common whitespace to $N=Kn$ bits for a sufficiently large fixed positive integer $K$, preserving byte alignment. All mask changes occur at distinct common byte positions. Scanning the $O(vt)$ prefix bits, assembling the precomputed bank indices, and serializing every row and the padding take $O(n)$ word steps per file. Prefix filtering and doubling also fit $O(n)$ steps per round. Checking the terminal list takes $O(t(v+c))=O(n)$ steps on the normalized source.

A fixed program in the portfolio can be simulated for $O(n)$ steps with its own word width, by choosing a sufficiently large fixed host width coefficient. A write log restores scratch memory within the same bound. The time of the entire deterministic search is $O((v+1)2^t n)$, hence $O(n^k)$. It can reject malformed sources during initial validation. If only finitely many positive source lengths caused an erroneous rejection, a fixed finite exception table would give a correct solver within that clock. The lower-bound hypothesis therefore gives infinitely many first losses. The theorem supplies no unconditional deadline miss.
