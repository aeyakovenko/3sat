# How much information has to cross a proof tape?

**Research journal, 24 November 2026.** I tried checking a RAM transcript by comparing its chronological records with its memory records in small groups. After timestamps identify the records, the correspondence is a permutation. Greedily removing monotone subsequences of length at least the square root of the remaining length gives O(√M) groups for M records, allowing either monotone direction. A group can be compared by two independent scans. Moving a single head between the scans is the unresolved expense in that argument. The bounds below account for this expense even when several challenges share a freely supplied certificate.

## A sufficient budget on the actual hierarchy problem

Consider a nondeterministic verifier with one large writable tape, a fixed number of endmarked read-only tapes of combined length N, and auxiliary mutable storage of at most s bits, including the auxiliary head positions. Use a polynomial cap U≥N+2 on time in the application. Specify a uniform encoding of the auxiliary configuration with self-delimiting code length c(a)≤O(s+log U), decodable and measurable in polynomial time and O(s+log U) space. Literal and sparse encodings with a tag are examples. Charge a large-tape move made with resulting auxiliary state a a weight c(a)+C log₂(U+2). Choose C large enough for the control, the finitely many input-head positions, and the time and weight counters. A stationary step costs no such weight but counts against U. Let W be the budget for the sum of the move weights; use W≤poly(U).

Under linear SAT one can test for an accepting path within both caps on a deterministic RAM in time at most

    (N+s+√(W+1)) · 2^{O(√(log U · log log(U+4)))}.              (1)

Partition the writable tape into blocks of width b=⌈√(W+1)⌉. Each unit move crosses exactly one of the b shifted grids. For some shift the total weight at crossings is at most W/b. Guess the shift and the list of crossing controllers, with the initial and final controllers as needed. Compressed auxiliary states and the other fields fit O(s+log U+W/b) bits. The last move of a visit writes the departing cell; the next visit reads the destination. The outgoing auxiliary state is also the incoming state of the next visit.

Universally select a block. Replay its subsequence of visits while keeping only its b cells, the auxiliary configuration, and small counters. At each departure test the compressed state and controller. Check the movement weight *throughout* each visit and the recorded cumulative weights and times at its endpoints. This includes moves inside the block. The list and original input remain read-only. All local replays together concatenate along the shared controllers, irrespective of which internal choices worked on each block. Each selected replay uses O(b+s+log U) space and polynomial time in U. The bounded-reachability simulation under linear SAT and a fixed number of further quantifier eliminations give (1). Initial contents are blank or accessible from the charged input. [One-tape replay](simultaneous-space.md) · [Quantifier and reachability costs](linear-quantifiers.md) · [Shifted-grid construction](https://raw.githubusercontent.com/openai/math/main/preprints/Simulating-One-Tape-Time-in-Two-Fifths-Power-Space-September-25-2026/build/source/sections/simulation.tex)

For example, fix the unary H★ in NTIME(n¹²) outside NTIME(⌊n¹²/log₂(n+2)⌋), and set T=n¹². Allow a list of public challenges with total description length L. For each list, one nondeterministic prefix can prepare a common proof on the large tape. Later tests use the same proof. They may use fresh nondeterminism, write to a scratch track, and finish with the scratch cleared. A scratch interval can be cleared by sweeping back over the range visited. Count those moves, returning to the specified start position, all shared preparation, and any mutable state needed to restore the challenges. The whole list now defines one sequential computation to which (1) applies.

Suppose every sufficiently large YES input passes **every** permitted list by some such common proof and sequential run within the caps. Suppose each NO input has **one** permitted list for which no such run exists. The rejecting list can depend on the input. The YES proof may depend on the entire list. A fixed uniform verifier with polynomial cap U, and L,s,√W≤T^(1−δ) for a fixed δ>0, would exclude linear SAT. Indeed an outer universal quantifier selects the list, and (1) checks it. This costs T^(1−δ+o(1)) on a RAM, still inside the excluded clock after nondeterministic tape simulation. The public list is part of the read-only input charge in (1). This gives a precise target for a shared-proof verifier. It does not establish that suitable lists or a sufficiently cheap verifier exist for H★. ## Exact cost for independent copied bits at fixed positions

Place two copies of each of K Boolean variables at specified positions in an input region on the large tape. Fill remaining positions with specified metadata or padding. The task here is to validate the supplied copies. A good input is any of the 2ᴷ consistent words. In addition to the input, allow an arbitrary certificate initially present on a separate track of that same tape. Fix q public challenges. For every good input there must be one common certificate and an accepting branch for each challenge. No inconsistent input may pass all q with any one certificate. The verifier can overwrite the tape on an individual branch, starting each branch on its initial image. Public schedule data, read-only head conventions, challenge list and format are fixed independently of the data bits. An uncharged second head on the proof or an independent random-access copy of the data would change this model.

For a cut c between tape cells let d(c) count the pairs with one copy on each side. The sum of d(c) over cuts is exactly the sum, over all pairs, of the physical distances between the copies. [Lean proof of the identity and the splice test](../lean/CrossingLoad.lean)

For each good input pick any passing certificate and accepting branches, for example ones minimizing their total cost. At a cut record the crossing controllers for all q branches in order of challenge and occurrence. A self-delimiting record gives the challenge index, control, auxiliary state, and read-only head positions. Include elapsed time or cumulative counters when acceptance has such restrictions. A continuation bit per record and one final stop bit suffice; empty challenge streams need no separate delimiters. The initial head side is fixed, and the direction alternates at each crossing. The record length can be bounded by c(a)+O(log(qU+2)). Its information must include every external mutable state component which survives the move.

Fix all bits whose two copies are on the same side of c. The signature at c distinguishes all 2^{d(c)} settings of the other bits. Otherwise splice the left input and certificate from one good run with the right input and certificate from another with the same signature. For each challenge use the chosen local run on its side until the next crossing. The recorded states make these pieces a legal accepting branch. The certificate splice is the same for every challenge. A differing bit across c makes the combined raw input inconsistent, contradicting soundness. This is the crossing-sequence argument with a shared certificate and a whole panel of challenges. [Hennie, One-Tape, Off-Line Turing Machine Computations](https://www.eecs.tufts.edu/~aloupis/comp260/lectures/hennie-1965.pdf)

The signatures are prefix-free, so their average length on uniformly random good data is at least d(c), also after unfixing the other bits. Summing over c charges each crossing record to one head move. Up to one terminating bit per cut, the expected total crossing charge is at least the sum of all pair distances. For a fixed layout with an explicit read-only directory of the pairs, or a directory indexer using logarithmic space and polynomial time, a single forward scan attains that weighted cost up to logarithmic overhead per cell. Between cells, keep the bits of precisely the pairs whose second copy has not been seen, in a fixed computable order. Insert the first copy or compare and remove at the second. One can compute ranks by scans of the public layout, shift the auxiliary list in place, and clear temporary storage before moving the large-tape head. This uses polynomial stationary time, at most max d(c)+O(log U) mutable bits, and d(c)+O(log U) crossing bits at cut c. Thus in this example substituting peak memory for the sum of live information can lose the relevant cost.

## Allowing the prover to lay out the records

There are M equal-width records, and a bit of an edge label occurs in both endpoint records. Allow the permutation π of the records to depend on all the data. The checker can read π and the schedule as public metadata. Soundness on inconsistent inputs must hold under each admitted π. The prover may choose its preferred layout, common certificate and branches on each good input. If there are P layouts, then for any fixed physical cut c and integer k≥1, uniform independent edge bits obey

    Pr[signature length at c < d(π,c)−⌈log₂ P⌉−k] ≤ 2^(−k).   (2)

For fixed π there are 2^{K−d(π,c)} choices of the bits that do not cross the cut. For any such choice the same splicing proof permits at most one setting of the remaining bits per signature. Count binary strings of length below the bound, multiply by the number of noncrossing assignments, and sum over the P layouts. The count is at most 2^{K−k}. This reasoning holds for any data-dependent choice policy. If there are Z physical input cells, take k=⌈log₂(2Z)⌉ and use a union bound. Some good input has all its central signatures long simultaneously, including cuts inside records.

Here is a family arising from the ordinary register and memory consistency conditions of a RAM. Start with a constant-degree expander on V vertices with linearly many edges across each balanced cut. For example symmetrize the bounded-degree monotone bipartite expanders so the vertex expansion holds on both sides. It implies linear edge boundary for sets containing a constant fraction of the vertices and leaving a constant fraction outside. Split every vertex into a path of d ports for fixed degree bound d. Allocate one port at each endpoint of each original edge, joining the paired ports by a matching. Fill unused slots with dummy ports. In chronological order list the ports of each vertex consecutively. This gives a graph on M=dV records with a chronological path and a matching. Every balanced cut still has Ω(M) crossing edges. If many vertex paths split, their internal edges give the bound. Otherwise a constant fraction of the clusters lie fully on each side. The original graph has linearly many outgoing edges from the full clusters, and at most d times the number of split clusters can end at such a cluster. [Expander source](https://arxiv.org/abs/1501.05020) · [Related tape layouts](tape-partitions.md)

Assign independent b-bit words to the chronological edges and matching edges. A chronological record shows the register arriving and leaving. Its outgoing register is freely guessed. Each matching edge has a fresh address. Its earlier endpoint writes a freely guessed word, and its later endpoint reads the word. Use a dummy memory operation at unused ports. Fix the schedule and timestamps. The only required comparisons of these payloads are copies of a register value at consecutive times and copies of a memory word at its write and read. These are legal macro-records of a nondeterministic RAM, with a constant number of operations plus the bit guesses per record. For b=C log M a fixed constant word-width multiplier suffices. The read-only public schedule contains no guessed payload. The example concerns verification of a supplied computation; its underlying existential language can be easy.

Each record has Θ(b) bits including the public fields when b≥C log M. At every physical cut in the central third of the region, Ω(M) graph edges go between whole records on opposite sides. Discarding a single split record loses only constantly many such edges. Thus d(π,c)=Ω(bM) for every π. Even granting all P=M! layouts, taking the fixed C large enough absorbs log₂ P. There are Θ(bM) central cuts. Equation (2) proves **Ω((bM)²) weighted travel** on some valid log, even for data-selected layout and an arbitrary shared certificate track. Equivalently the total number of moves cannot have a fixed power saving over (bM)² when a crossing communicates only polylogarithmically many bits. This applies to a common panel sound for every inconsistent raw word under the given schedule. A different, input-specific panel need not distinguish all these words. A verifier allowed to choose a particularly simple valid computation also has a different task.

The bound rules out a blanket argument that few monotone groups in the timestamp permutation make the shared raw log cheap to check on one tape. The time-to-travel implication still has two possible sources of saving on a hard language: a panel separating all spurious proofs of the particular negative input, or a positive proof that avoids supplying independent raw records. The [streaming test](streaming-transport.md) considers the latter possibility. The weights, adaptive-layout counting and clock bounds above are manuscript arguments. I have not established priority for those refinements.
