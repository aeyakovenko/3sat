# Hard SAT witnesses can change at every one-instruction extension

Consider a deterministic word RAM with zero-initialized registers and memory, ordinary arithmetic, indirect loads and stores, conditional branches and a testable encoded input length. Count *stored instruction slots*. Fix a single native width rule with \(w\ge\lceil\log_2(N+2)\rceil\) and \(w=O(\log(N+2))\), where \(N\) is the encoded input length in bits. An extension inserts one instruction at program entry. All old instruction labels refer to the same old instructions under this order-preserving insertion. Relative branch encodings among the old instructions are unchanged. Equivalently, prepend one instruction to an unchanged assembled body using relative jumps.

**Proposition.** There are fixed, globally correct deterministic SAT programs \(U_0,U_1,\ldots\), a fixed globally correct program \(V\), and explicit families \(F_0,F_1,\ldots\) of ordinary proper ASCII DIMACS 3-CNFs such that:

1. \(U_{i+1}\) is obtained by inserting one increment at the entry of \(U_i\). Each program is uniform over all input lengths. Each \(F_i\) contains infinitely many formulas of each verdict.
2. \(U_i\) runs in \(O_i(N)\) on \(F_i\). For every fixed \(j\ne i\), on all sufficiently large files of **either verdict** in \(F_i\), \(U_j\) executes at least \(2^{\Omega_j(N/\log N)}\) steps. A uniform lower bound \(2^{\Omega(N/(\log N\log\log N))}\) also holds for every other represented guest, including indices growing with the file. The single fixed program \(V\) runs in \(O(N)\) on the entire union, with a common constant.
3. After the entry increments and up through the first differing return decision, the \(U_i\) running on the same input have the same instruction labels, memory addresses, values loaded and stored, whole memory arrays, and all register values except their private selector. After initialization the private selector is used only in the test for taking a return branch. After this branch the slower computation can continue arbitrarily long.

### Proper files and chronological search

Use base-two logarithms. Choose an integer \(\ell\ge 4\), let \(L=\max(2,\lfloor\log_2\log_2\ell\rfloor)\), and choose \(0\le i<L\). Put the three names \(u,p,q=2^i,3\cdot2^i,5\cdot2^i\) in class \(i\), where the class of a positive name is its 2-adic valuation. For each \(0\le h<L\) other than \(i\), take \(b_h=\lceil\ell/L\rceil+\lceil\ell/2^h\rceil\) names \(x=2^h(2t+1)\), \(1\le t\le b_h\). Write \(B=\sum_{h\ne i,\,0\le h<L}b_h=\Theta(\ell)\) for their number: the uniform terms alone sum to at least \(\ell/2\), and the geometric terms sum to at most \(2\ell+L\). Create the four clauses \((u\lor s p\lor t q)\) over both literal signs \(s,t\). For every data name \(x\) include the two clauses \((\neg u\lor x\lor p),(\neg u\lor x\lor\neg p)\). These are the positive files. The negative ones also include all four sign variants of \((\neg u\lor s p\lor t q)\). Take the highest actual name as the variable bound in the DIMACS header. The sign variants on \(p,q\) force their shared first literal. The two clauses for \(x\) impose \(u\Rightarrow x\). Every clause has three distinct names. For all sufficiently large \(\ell\), class \(i\) is recognizable as the unique occurring class with exactly three names. The positive and negative families have the stated verdicts.

With decimal names and the ordinary terminators, \(N=\Theta(B\log\ell)\), uniformly in \(i\). For the lower bound, each data class has at least \(\ell/L\) names, a positive fraction of which have at least \(\Omega(\log(\ell/L))=\Omega(\log\ell)\) printed digits. For the upper bound, every name is \(O(\ell+2^L\ell/L)=O(\ell+\ell\log\ell/L)\). There are \(O(B)\) occurrences and clauses.

Guest \(j\) orders the occurring names of class \(j\) first, then the remaining names; first occurrence in the file breaks ties. Each guest does chronological binary search with false before true. It prunes upon a fully falsified clause and accepts when every clause already has a true literal. It can omit unit propagation. Maintain for each clause the number of unassigned literals and the number of true literals, with global totals of conflicted and satisfied clauses. Apply and undo an assignment in \(O(1+\text{number of occurrences of its name})\) steps via a shared read-only incidence list; an explicit stack stores the current frames. All guests are complete global SAT decision procedures. This is elementary backtracking in the tradition of [Davis, Logemann and Loveland](https://doi.org/10.1145/368273.368557).

Guest \(i\) first branches on the three special names. Its constant-size top tree charges \(O(B)\) for the high-incidence operations. No assignment to these names survives for a negative file. In a positive file every surviving assignment fixes \(u=1\), and assigning false to any remaining name \(x\) immediately falsifies one of its two clauses since \(p\) is assigned. Each such \(x\) has two occurrences. The remaining search takes \(O(B)\) steps in total; stopping early upon acceptance only lowers the cost.

For \(j\ne i\) with \(j<L\), the first \(b_j\) names are all data. On any partial assignment just to these names no clause is falsified because the guard is unset, and the untouched padded-unit clauses prevent early acceptance. Every negative file is unsatisfiable. On every positive file the only extendible assignment to these \(b_j\) names is all true, which comes last. Thus the guest visits all \(2^{b_j}\) prefixes of length \(b_j\) on both verdicts. For any fixed \(i,j\), both belong to \([0,L)\) eventually. Since \(b_j\ge\ell/2^j\) and \(N=\Theta(\ell\log\ell)\), this gives the claimed bound for every fixed opposing guest. The uniform term \(b_j\ge\ell/L\) gives the second bound even when the represented opposing index grows.

### One common RAM body, including its initialization cost

The body computes \(K=\max(2,\lfloor\log_2\log_2(N+4)\rfloor+2)\); using \(\lfloor\log_2\max(4,N)\rfloor\) as the inner integer argument instead avoids an overflowing addition and retains \(K\ge L\). Parse the file once, build incidence lists and a first-occurrence name vector, and prepare one search state per \(0\le j<K\). The same fixed program handles every \(j\). A bounded numeric-name fast path can directly index by the largest actual name, keeping the occurring-name vector dense. If a field exceeds the capacity bound or the input is outside proper 3-CNF, use the common complete fallback below. A byte scan of the packed file takes \(O(N)\) steps. Fixed-width streaming decimal conversion checks for overflow before multiplying. Classify each name by successive shifts, stopping at \(K\) factors of two since larger classes are second-tier for all guests. Produce each ordering in two scans of the name vector. Shared initialization takes \(O(N+\max\mathrm{name}+K B)\) on the displayed families.

In every round loop once through all \(K\) guests, running one fixed elementary instruction of the common iterative evaluator in each still-active guest; freeze a finished guest. The evaluator's saved control state and registers have constant size, and arrays can be addressed by a constant number of scalar operations. Updates of an incidence list are interruptible between successive entries. A round costs \(O(K)\) native instructions, irrespective of the degree being processed. In a second scan consider the finished guests only. Offer a return tagged \(j+1\) for each finished guest \(j\), and also one return tagged zero as soon as any guest has finished (choose its verdict in the scan). Every offered tag uses the same comparison and returns its associated verdict precisely when the private selector matches. If *all* have finished, return a verdict unconditionally. All verdicts agree. Neither loop reads the private selector except for the comparison branching to return. The data on every other branch and every write arise from common state. This proves the stated common-prefix claim by induction on executed instructions within the common body, identifying labels after the entry insertion. Both computations can enter an identical return path together if their timings and decisions agree. The claim compares states through the first differing return decision whenever one exists.

For \(U_i\), prepend \(i+1\) copies of `ADD selector, selector, 1` to that body, with the register initially zero. Distinct selectors may coincide at small widths because of modular wrap. A selector outside \([0,K]\) is still correct by the all-finished rule. Eventually \(i+1\le K<2^w\) for every fixed \(i\). On a family with \(i<L\), the selected guest requires \(O(B)\) rounds. The resulting time is \(O(i+N+\max\mathrm{name}+KB)=O(i+N)\) because \(K=O(\log\log N)=O(\log\ell)\). Conversely every selected slow guest must execute its \(2^{b_j}\) steps before the all-finished rule can fire. Define \(V\) to enter the same controller with zero increments: selector zero takes the first available verdict. Its time on every displayed file is bounded by the same cost for its fast guest, uniformly over \(i\), and it is globally correct. Moreover every \(U_i\) has an alternative one-slot extension with this same first-finished timing, up to its fixed startup cost. Insert `MOV selector, 0` between its increments and the shared body. If insertion must be at entry and signed (or truncated integer) immediates are available, prepend `MOV selector, -(i+1)` instead: the old increments restore zero modulo the native word width. Thus one legal extension can make *every* family in the union linear, simultaneously, for each parent.

For the minimal width coefficient, the packed input occupies \(O(N/w)\) words. The arrays just described require at most \(c(1+\max\mathrm{name}+K(1+B))\) extra words on these families, for one implementation constant \(c\). This total is \(o(N)\), since \(\max\mathrm{name}=O(\ell+\ell\log\ell/L)\), \(B=\Theta(\ell)\), \(L\to\infty\) and \(K=O(\log\log N)\). Reserve it after the input. Use a first validation/counting pass that checks field magnitudes against a safe fraction of the address capacity and checks the required allocation before use. Every sufficiently large displayed file passes, uniformly over the eligible \(i\). The few small lengths can be handled separately at constant total asymptotic cost. On a general file that fails the resource or fast-format checks, a fixed complete fallback can enumerate one truth bit per literal occurrence in a packed binary counter. For each candidate it checks equal values for occurrences of the same variable and checks the clause verdicts by repeated input scans. Even arbitrarily long decimal names can be compared as spans ignoring leading zeroes. The extra space is \(O(N/w+1)\) native words, in addition to a fixed number of cursors; use an explicit overflow indication on the final counter increment. All these checks and the fallback are independent of the selector. The construction therefore works with one common width convention for every member, including the minimal logarithmic width asymptotically.

This supplies an infinite sequence of exact slot extensions where a particular growing hard family for the smaller program becomes linear for its successor: use \(F_{i+1}\) against \(U_i\). The larger program still has hard files in other families. A size induction remains possible if it constructs different witnesses using additional information. The construction gives no lower bound on the minimum time over all SAT programs. The existing [fixed-size interpreter](constant-instruction-interpreter-and-size-induction.md) and [finite-suite patches](semantic-patches-for-finite-sat-suites.md) concern other ways witnesses may fail to transfer. No priority claim is made for round-robin simulation or the variable-order effect.

The accompanying executable checks actual proper DIMACS files, chronological search events and stopping policies on finite examples, including the first-finished control. The Lean helper checks Boolean padding, no early pruning on pure data prefixes, and equality of any two still-live states driven by the same transition under arbitrary retirement predicates.
