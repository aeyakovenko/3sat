# How cheaply can parity certify the actual priority computation?

Let $M=2^j$ and let $b_j$ be the [priority output](priority-pinned-sat.md). A fixed sound deterministic procedure that signals only for $b_j=c$ takes at least $\gamma 2^j$ native steps on every sufficiently late success, for some positive constant depending on the procedure. The following results test a parity version of the signed-graph construction on this actual bit.

## A genuine cycle with precisely one exceptional edge

Pad the fixed deterministic computation of $b_j$ through a constructible $T=\Theta(M)$ native clock. Choose a constant large enough for its known worst-case bound and use deterministic idle transitions after halting. At each tick record the controller and fixed registers and a fixed set of slots for that instruction's memory addresses, values and enable bits. Use $O(j)$ bits per tick and set all unused bits to zero. A fixed positive number of word fields per tick gives $m=\Theta(Mj)$ bits in this serialization. It suffices to record these events; the entire memory array need never occur in a record. Given the purported history $y$, replay the fixed program from its canonical zero input and workspace, compare every field to $y$ and check the final pin $c$. This takes $O(M)$ word steps with a read-only packed record and unrestricted working storage. There is one accepting record exactly when $b_j=c$, since the chronological record includes only determined data. A nondeterministic routing certificate with several valid switch settings would lose this property.

Take the cyclic group of positions $\{0,\ldots,2^m-1\}$, identifying a position with its $m$-bit representation. On the edge from $y$ to its cyclic successor, request an XOR difference equal to the preceding record check. A cycle of binary XOR equations is inconsistent exactly when its edge-label parity is odd. Hence this genuine cycle for the true pin has exactly one nonzero label and the cycle for the false pin has none. Adding a vertex potential changes the labels by $C(y)\oplus C(y+1)$ and preserves their parity. The constant-zero potential already leaves the smallest possible odd number of exceptions. The cost is in accessing the positions and verifying their labels.

An adaptive deterministic bit test on the full $m$-bit cube accepts a disjoint union of subcubes. At an accepting leaf where exactly $m-d$ distinct input bits have been read, all $2^d$ assignments to the remaining bits reach that leaf. If the accepted count is positive with 2-adic valuation $h$, some accepting leaf has $d\le h$: otherwise $2^{h+1}$ divides the sum of all leaf sizes. An odd count forces some accepting computation to touch every position. For queries returning words of at most $w$ bits, count the union of their raw positions. This gives at least $\lceil(m-h)/w\rceil$ reads when $h<m$. The addresses may depend on all previous replies. On the unique genuine record above this requires $\Omega(M)$ reads from the record at word width $O(j)$. The conclusion is about an exact label checker with full-domain soundness; restricting its input in advance to legal transcripts would remove the work needed to establish legality.

## Exactly what a small cycle chart would imply

Fix a color $c$. Consider a different uniform chart with $p(j)=\operatorname{poly}(j)$ bits per position and one polynomial-time computable binary label $A(j,y)$ per cyclic edge, for every $y\in\{0,1\}^{p(j)}$. Take $p$ polynomial-time constructible, or take a fixed polynomial upper bound and force padding bits to zero. Suppose odd edge parity entails $b_j=c$ and occurs infinitely often. Then the unary language of its odd stages is an infinite $\oplus\mathsf P$ subset of $\{1^j:b_j=c\}$. Guess the $p(j)$ bits and evaluate the label, using one accepting path per positive index. Conversely, any such unary $\oplus\mathsf P$ subset gives a cycle of exactly this kind. For a variable-branch-length binary parity verifier, guess a full polynomial-length tape, follow its actual choices and require every unused guess bit to be zero. This gives each true accepting path exactly one padded representation. The language input is $1^j$, so polynomial time here means polynomial in the *scale* $j$. [Papadimitriou and Zachos on parity of computation paths](https://publications.csail.mit.edu/lcs/pubs/pdf/MIT-LCS-TM-228.pdf)

Therefore producing this smaller uniform chart alone would prove $\mathsf P\ne\oplus\mathsf P$. Equality would give a deterministic polynomial-time detector on the unary scale, simulable from $j$ in $\operatorname{poly}(j)=o(2^j)$ native steps on infinitely many correct scales. This class consequence would not itself settle any of the requested SAT time bounds. It identifies a substantive additional theorem implicit in proposals to apply the graph reduction to the native bit.

There is an unconditional lower bound on how small the edge-label circuits of a candidate can be, using the pinned October preprint as an external theorem. Suppose circuit $A_j$ is produced from $1^j$ in $\operatorname{poly}(j)$ time and counts $s_j$ for its number of input bits plus its bounded-fan-in Boolean gates. Ordinary truth-table gate equivalences and an output unit give a 3-CNF with $v=O(s_j+1)$ variables and $O(v)$ clauses. Each accepted input has exactly one gate extension. Declare the input variables, including any unused inputs. The cited exact counting algorithm runs in $\operatorname{poly}(v)2^{O(v/\sqrt{\log(v+2)})}$ bit operations. For sufficiently small fixed $a>0$, at $s_j\le a j\sqrt{\log_2(j+2)}$ this takes $o(2^j)$ time, including uniform construction and simulation of the bit algorithm. The counter's space is polynomial in $v$, and its computation at this threshold can also be simulated from the short scale with polynomial overhead in $v$ per bit operation. Thus every sufficiently late odd success has $s_j>a j\sqrt{\log_2(j+2)}$. This lower bound on the succinct verifier size is relative to the cited counting theorem. [Pinned exact-counting theorem, lines 73–85](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/build/main_full_version.tex#L73-L85)

The same threshold, with another constant, works for existentially selected charts assuming explicit SAT takes $O(n^k)$ for fixed $k$. Require a uniform polynomial-time chart admissibility test and soundness of the odd sign for **every** admitted chart. Guess a bounded encoded circuit and its admissibility proof, with witness length and checking cost polynomial in $j+s_j$. Run the preceding exact counter and signal on oddness. For $s_j\le a j\sqrt{\log(j+2)}$ and small enough fixed $a$ this entire nondeterministic computation takes $2^{j/(2k)}\operatorname{poly}(j)$ steps or less. One [bounded-run 3-CNF](packed-band-transfer.md) and the hypothesized SAT solver give a sound deterministic detector in $o(2^j)$. A nonuniform circuit simply hardwiring the unexplained answer fails the soundness or admissibility requirement.

## Finding a potential when one exists

Keep a fixed uniformly polynomial-time local label checker with $p(j)=\operatorname{poly}(j)$. For a positive integer $d$, let $D_j$ be the minimum, over Boolean circuits $C$ of description length at most $(j+1)^d$ on the cyclic position, of the number of ones of
$$
 A(j,y)\oplus C(y)\oplus C(y+1).
$$
Include a constant circuit in the allowed descriptions. Under $\mathsf P=\mathsf{NP}$ there is a deterministic procedure computing the exact edge parity in time $(D_j+1)\operatorname{poly}_d(j)$. The minimizing circuit may depend nonuniformly on the scale.

For each supplied circuit, counting these defects is a #P function on $(1^j,C)$. Stockmeyer's deterministic polynomial-hierarchy algorithm gives a multiplicative constant-factor approximation. Use a factor of two allowing error on both sides and test zero by ordinary satisfiability if necessary. Under the hypothesis this procedure is deterministic polynomial time in $j+|C|$. Find a circuit minimizing the *computed estimate* among all admissible descriptions. The predicate asking if a circuit with a specified prefix and estimate below a proposed threshold exists is in NP under the hypothesis, hence in P. Equivalently recover the least polynomial-bit output value by prefix minimization, then recover one attaining circuit. An integer estimate within a fixed constant factor suffices and can be encoded with $O(p(j)+1)$ bits. The chosen circuit has at most a fixed constant times $D_j$ true defects. [Stockmeyer, On Approximation Algorithms for #P](https://doi.org/10.1137/0214060)

Enumerate its true defect positions with a depth-first traversal of the binary prefix tree. An existence query on a prefix is in P under the same hypothesis. With $D$ actual leaves there are at most $1+2p(j)(D+1)$ tested nodes. Flip a counter bit at each full leaf and only return a parity after exhaustion. The sum of changes of the selected potential around the cycle is zero, so the returned parity is exact even when the approximate count is inexact. Consequently on every sufficiently late odd success of a sound chart for the real sign, $D_j\ge 2^j/\operatorname{poly}_d(j)$ under the hypothesis. To use this criterion in a proof against polynomial-time SAT would require both the short uniform labels and circuits with sufficiently few residual defects on infinitely many real signing cycles. The genuine chronological cycle violates the position-width and local-time assumptions.

## A compressed part of the computation that really runs

The scheduler has individual long trials whose entire **guest memory** permits a small uniform description. Choose one fixed guest text in its enumeration. Initialize a counter $r=0$ and repeat the following constant-length sequence of guest instructions. Compute $3r+5$ and $2r+1$ in the native word ring. Signal if the low bit of $2r+1$ is zero; otherwise write $2r+1$ to address $3r+5$, increment $r$, and repeat. The guard never fires. Registers, control and memory start in the usual fresh trial bank. The program uses only fixed word operations allowed by the native model. It never retires. Once this fixed rank $e$ is active, only finitely many smaller ranks can ever preempt it, since each may retire at most once. Thus at every sufficiently large stage its real trial runs through the assigned $\lfloor M/2^{e+1}\rfloor$ universal instruction budget. The fixed program has bounded interpreter overhead per guest step at the stated native widths. Initialization is sublinear in $M$, so it completes $\Theta_e(M)$ guest loop iterations.

At native width $w=12\lceil\log_2(M+2)\rceil$ all reached iteration counts are less than $2^{w-1}$. For a guest address $u$, let $d$ be the least nonnegative residue of $3^{-1}(u-5)$ modulo $2^w$. Immediately after $t$ completed iterations the guest word is
$$
 \begin{cases}2d+1&d<t,\\0&d\ge t.\end{cases}
$$
Multiplication by three is invertible, so precisely one iteration can have written the queried address. The formula follows by induction and covers every guest address. For a partial loop use $t+1$ in the memory formula if its write instruction has already executed; its program counter and registers follow from $t$ and a constant-size phase. All these quantities, including the modular inverse, can be computed by $\operatorname{poly}(j)$ bit circuits. The actual number of occupied guest words after $t$ iterations is exactly $t$. In particular this is a succinct description of a genuine trial with $\Theta_e(M)$ live writable words.

The formula parameterizes the guest state by completed guest iterations. It does not claim a fast decoder for the interpreter's own allocation directories at each universal tick. The scheduler only uses the trial's signal and discards its guest memory. Its contribution to the decision is certified for **every** truncation time by the parity guard; no exact conversion between universal ticks and guest iteration counts is required. A compiler can recognize this fixed family and omit its trial while preserving its scheduler effect. This certifies a constant fraction of work for the indicated rank. The remaining ranks include arbitrary programs, and their budgets can still sum to order $M$. The earlier [semantic-silence note](semantic-silent-trial-cores.md) explains why uniform quick certificates for selected silent texts need not extend to the ranks that perform the diagonalization.

## A sublinear-time forecast that recovers almost every real rare award

There is a deterministic $o(2^j)$-time forecast of the original bit $b_j$ with arbitrarily slowly diverging cumulative mistake allowance. It recovers an asymptotic fraction one of the genuine rare zero awards. An asymptotic fraction one of its own predicted zeros are correct as well. It also supplies a tentative winner identity and retirement set at the same cost.

Take nondecreasing, polynomial-in-$j$ computable integers $e(j), d(j)$ tending to infinity, with $1\le d(j)\le j$ at positive scales. Replay the true scheduler through $j-d(j)$, including its retired ranks. Then simulate the remaining $d(j)$ stages, suppressing every rank below $e(j)$ throughout this final window. Return the simulated winner, sign, and retirement set. Under the journal's native simulation conventions, the first phase costs $O(2^{j-d(j)}+1)$ and the total trial time of the second is $O(2^{j-e(j)})$ by the geometric budgets in rank and stage. Fixed-limb table setup costs at most $2^{j/4}\operatorname{poly}(j)$ overall, and the small rank and interval bookkeeping fits in $\operatorname{poly}(j)$. Trials use disjoint or cleared scratch banks. A skipped trial that would have stayed silent has no effect on any later decision. Thus the runtime is $o(2^j)$.

If no rank below $e(j)$ actually wins anywhere in the final window, the truncated simulation agrees on every winner in it. Starting with the same retired set, it skips only tests that would not have produced the first pulse; the actual winner or default is preserved, so both versions update to the same retired set. Induct on the stages of this window. For all endpoints $j\le J$, a discrepancy in *any* of the three returned items consequently requires an actual winning event of one of the first $e(J)$ ranks within the previous $d(J)$ stages, counting the endpoint itself. Each rank wins at most once. Each such event can affect at most $d(J)$ endpoints, hence the cumulative number of bad forecasts through $J$ is at most $e(J)d(J)$. The suppressed losing trials need not have the same internal traces as a skipped computation.

Write $Z(J)$ for the number of actual zero awards through $J$. It diverges by bi-immunity and is $O(\log\log(J+4))$ for the fixed original scheduler. The count $K(J)=Z(\lfloor\log_2(J+1)\rfloor)$ is a cheap, nondecreasing, unbounded lower bound for $Z(J)$. Compute it by genuine replay through that earlier stage in $\operatorname{poly}(J)$ time on the current host. Let $F(J)\ge1$ be any nondecreasing computable unbounded mistake allowance. If its evaluation is expensive, take a polynomial-time unbounded minorant: simulate the sequential computations of $F(1),F(2),\ldots$ for $J$ bit operations, returning the last finished value capped at $J$ or one if none has finished. A conventional simulation bounded by $\operatorname{poly}(J)$ suffices. Write $F_0$ for this minorant. For large $J$, take
$$
 e(J)=d(J)=\max\big(1,\min(\lfloor\sqrt{F_0(J)}\rfloor,
                                   \lfloor\sqrt[3]{K(J)}\rfloor)\big).
$$
Initialize at one and clamp to $J$ if necessary. Both quantities diverge; $e(J)d(J)\le F(J)$ and $e(J)d(J)=O(1+K(J)^{2/3})=o(Z(J))$. The runtime gain $2^{\min(e,d)}$ need only diverge. In particular, this estimate supplies no arbitrarily prescribed polynomial-in-$j$ saving to absorb bounded-run SAT encoding costs.

Let $E(J)$ count bit mistakes. Missed actual zeros and false predicted zeros each number at most $E(J)=o(Z(J))$. The number of true positive zero forecasts is $Z(J)-o(Z(J))$, and the total number of predicted zeros is $Z(J)+o(Z(J))$. These give both claimed ratios. Both kinds of mistakes still occur infinitely often. The predictor returns infinitely many zeros by the ratio, and infinitely many ones since $Z(J)=o(J)$. If one kind of mistake were finite, hardwiring that finite set of exceptions would turn the corresponding predicted color into an infinitely often successful sound $o(2^j)$ detector.

In fact any particular $o(2^j)$-time bit forecast $R$ can be improved by an unbounded factor in cumulative mistakes. Its true cumulative count $E_R(J)$ is computable, nondecreasing and unbounded by the same eventual-soundness argument (finitely many total errors would make it exact after a fixed stage). Use $F(J)=\max(1,\lfloor\sqrt{E_R(J)}\rfloor)$ as the prescribed allowance for the new forecast. The new mistake count is $o(E_R(J))$, although its running time may approach the native clock more slowly.

Finally, the indicator of a mistake on a particular stage retains the original native hardness. If a sound procedure detects one fixed error status, compute the forecast and use its value to split the signal between two sound detectors for the original colors. On all sufficiently large successes one of the two color bounds applies. Subtracting the $o(2^j)$ forecast overhead leaves a program-dependent $\Omega(2^j)$ lower bound for the error-status detector. The whole error prefix through $h$ is available in $O(2^h+1)$ by summing genuine computation and forecast costs geometrically. The [missing-pattern theorem](sparse-award-syndromes.md#an-exact-native-lower-bound-for-certifying-a-missing-pattern) uses just these properties. Therefore even certifying that there were at most 100 forecast mistakes in a growing recent window costs $\Omega(2^j)$ on every sufficiently late deterministic success. In logarithmic windows the statement holds at density one, by the cumulative upper bound. A short sound nondeterministic certificate of this statement on infinitely many such genuine windows would give the same unrestricted SAT contradiction at its appropriate clock. High precision and recall alone give no certificate identifying a correct stage.
