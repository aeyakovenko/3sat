# Choosing an excluded pair after a public challenge

At a genuine eligible start of a [dense reporter bin](density-of-certified-winner-pairs.md), form a public menu of $M\ge2$ distinct ordered pairs of different live pool members. Each event claims that its two members win consecutively with zero, beginning now. All live pool members eventually win with zero. At most one menu event can occur. On a genuine positive tag win none can occur. The deterministic and nondeterministic thresholds persist even if a verifier can make almost $e/4$ outright mistakes in each bin of endpoint rank $e$. A cheap rule that names a pair attains the leading constant $1/4$. Public-coin protocols can instead trade the choice of a fixed name against an explicit probability gap.

## The number of incorrect exclusions a verifier can afford

Call a start a mistake for $W$ when a timely accepting branch excludes a specific pool pair that actually wins with zero on those two dates. Such a pair is unique, even if many replies accept. Count distinct erroneous starts $E$ during the bin phase through the positive tag win, including errors outside normal mode. The checker is given each proposed pair and the genuine earlier history. There is no requirement that every certificate be sound.

Assume deterministic $O(n^k)$ SAT and fix a bounded nondeterministic $W$ with branch time $2^{(1/k-\epsilon)i}$, where $0<\epsilon<1/k$. A deterministic $W$ of time $2^{(1-\epsilon)i}$ requires no SAT assumption. Consider the infinitely many large bins matching $W$ and, when necessary, a correct SAT solver and suitable cap. Write $h$ for the number of lower ranks outside the pool, $p=e-h$ for its initial size and $\ell=\lceil e/2\rceil$. Here $h=O(\log^*(e+1))$. If $W$ certifies at least one live pool exclusion on **every sufficiently late positive tag win having at least $\ell$ honest lower ranks**, then in *every sufficiently late matching bin*

$$ E>e/4-h. $$

An honest lower rank is live and really will win with zero. All comparisons use the encoded formula length and the same word RAM as the dense theorem. In particular, for every fixed $\delta>0$, exhibiting such coverage with at most $(1/4-\delta)e$ mistaken starts per sufficiently late bin would rule out the hypothesized fast SAT solver. The completeness requirement is about winning dates while the error bound is about actual events in each whole phase. A low global density of errors, measured against the long stretches of dates between bins, does not give this bound.

To prove the claim, dispense with the assumption of soundness in the phase accounting. A normal first pool win is followed by a ready live responder. Either an earlier outsider preempts the response, or the responder wins. In the first case one pool member retired and a distinct outside retirement pays for it. In the second case two pool members retired: the event really occurred and the retained search had an accepting branch for precisely that pair on that start. A response win never initiates another response; the mode triggers only on a first win in normal mode. Thus these episodes are disjoint. There are no pool wins outside such episodes before the tag wins. The tag cannot win on a response date when the complete search is replayed successfully. If $A$ denotes the number of preempted-response episodes and $F$ the number of successful-response episodes, the exact number of live pool members at the positive win is

$$p-A-2F,\qquad A\le h,\quad F\le E.$$

On the tag's winning date *no* live pool pair has an accepted exclusion in its search clock. This follows from the complete normal search alone: any selected first member would have offered ahead of the tag. The coverage hypothesis forces the date to have fewer than $\ell$ honest lower ranks. The pool survivors all qualify, so $e-2h-2E<\lceil e/2\rceil$, or equivalently $2E\ge \lfloor e/2\rfloor+1-2h$. This implies the strict bound above. Only the $F$ particular false reports resulting in successful responses were needed for the lower bound. [Phase implementation and ordinary SAT reduction](density-of-certified-winner-pairs.md)

There is an unconditional deterministic rule giving the same leading constant on the actual bins, including bins with other dispatched programs and proposed solvers. At each eligible date $j$ with at least $\ell$ live lower ranks and at least three live pool members, let $s_j$ be the least live pool rank. Choose $s_j$ as the second name. Choose the first name $f_j$ outside $\{s_j,s_{j-1}\}$ among the current live members, using the preceding date's least live pool rank when defined. At the phase start omit the previous-rank restriction. Return only this ordered exclusion. The rule reads the genuine past and the rank allocation in $\operatorname{poly}(i)$ time. It names a pair on every sufficiently late qualifying positive win because at most $h=o(e)$ lower ranks are outside the pool. The two proposed members will genuinely win with zero, regardless of the descriptor.

If its reports at consecutive starts $j,j+1$ were both wrong, the winner on the shared date would have to equal both $s_j$ and $f_{j+1}$. The choice forbids this. Errors at starts separated by at least two consume distinct pairs of ranks by retirement. Before its last error there must therefore be at least $2(E-1)$ already retired ranks below $e$. Its guard on that start required at least $\ell$ still live. Consequently on **every** bin it makes at most

$$\left\lfloor\frac{e-\lceil e/2\rceil}{2}\right\rfloor+1$$

mistakes. This gives a concrete checker with the required positive-win coverage and at most $e/4+1$ mistakes. Together the two estimates locate the tolerable count within $O(\log^*(e+1))$ near $e/4$ on matching bins. The unconditional checker uses its allowance for errors. More generally, with public live-rank threshold $\ell$ and $\ell-h\ge3$, the same lower counting gives $2E\ge e-\ell+1-2h$, while the same unconditional procedure gives $E\le\lfloor(e-\ell)/2\rfloor+1$.

## One bit of advice beats this error threshold

Two fixed deterministic rules suffice if a bit may select one of them **for the entire bin** after its outcomes are known. Both propose the same second name $s_j$ as above. When the live-rank guard holds and there are at least four live pool ranks, choose the first two distinct eligible first names outside $\{s_j,s_{j-1}\}$. Rule zero proposes the first of them, and rule one proposes the second. Both name honest pairs on every sufficiently late qualifying positive win. At any date at most one of their different names can be wrong. At consecutive dates no combination of rules can be wrong twice, since the proposed second on the first date is forbidden as a first on the next. If $E_0,E_1$ count their actual mistaken starts on a bin, the retirement and last-date argument now gives

$$E_0+E_1\le\lfloor(e-\ell)/2\rfloor+1.$$

Choosing the lower-error rule for this bin gives at most $e/8+1$ mistakes when $\ell=\lceil e/2\rceil$. The bit can be computed retrospectively from the actual completed history, by checking the two named events against the recorded pair of winners at every eligible start. More generally, $C$ distinct first names with the same second give total errors at most the same bound over all $C$ rules. Require $C+2$ live pool names before making any proposals. At a qualifying win this condition holds when $C+2\le\ell-h$. In particular one may take $C=\lfloor(e-\ell)/2\rfloor+2$ for sufficiently large bins with half-prefix qualification. At least one of these rules makes **zero** mistakes throughout that bin. Choosing it needs at most $\lceil\log_2 C\rceil$ bits per bin. These guarantees allow a fresh advice value on each bin, and the checkers use only the selected value and the genuine past during the phase.

There is an unconditional obstruction to computing even the better-of-two bit uniformly in advance. Let $B$ predict the bit from the bin identifier and genuine pre-phase history at $J$, with deterministic work $2^{(1-\epsilon)J}$ for fixed $\epsilon>0$. Make the deterministic verifier that reconstructs this very prefix on every eligible start, runs the predictor at the original width and uses its chosen expert throughout the bin. The fixed simulation and polynomial overhead fit $2^{(1-\epsilon')i}$ for some $\epsilon'>0$ and $i\ge J$. The verifier covers all sufficiently late qualifying positive wins whichever bit is predicted. In every sufficiently late bin matching this verifier in **deterministic** mode, the selected expert makes more than $e/4-h$ genuine errors, by the unconditional counting argument. The other makes at most $h+O(1)$ by the joint bound. Thus the less error-prone expert is unique there, and the predicted advice bit is wrong. This statement allows a different advice bit per bin and computes it from authentic complete outcomes. It gives no ordinary SAT time lower bound.

## A contiguous run of mistakes on actual dates

In a variant of the same ordinary SAT family, the $e/4$ tradeoff holds for **one uninterrupted run** of erroneous two-date blocks. At asymptotic density one within each fixed descriptor's matching bins, there is a public release point $K$ with the following exact behavior. At each of $K,K+2,\ldots,K+2F-2$ the search certifies an exclusion and its two named ranks actually win on that date and the next. Then the search certifies no live pool exclusion at $K+2F$, and the positive tag wins there. If the checker covers every sufficiently late qualifying positive win, the contiguous burst on each such late matching bin satisfies

$$2F\ge p-\lceil e/2\rceil+1,\qquad p=e-O(\log^*(e+1)).$$

Thus limiting just the **longest run** to $(1/4-\delta)e$ for fixed $\delta>0$, even if the checker may make arbitrarily many mistakes elsewhere in the bin, would suffice for the corresponding SAT lower bound when combined with qualifying-win coverage. The same unconditional rule above gives the upper bound $e/4+1$ for burst length by bounding all its mistakes. A run here consists of consecutive nonoverlapping two-date blocks. It has a false accepted exclusion at the first date of every block. The checker may also certify other true exclusions at these starts.

First retain the original bin allocation. The normal dates strictly before the tag win consist of the $F$ successful-response starts, the $A$ preempted-response starts, and the dates when an outsider beat both tag and pool straight away. The latter dates and the preempted responses have **distinct** outside winners. If $N$ counts the normal dates strictly before the tag win, $N-F\le h$. Under qualifying-win coverage, $F>e/4-h$ already follows from the exact retirement count. Thus on at least a $1-O(h/e)$ fraction of the normal dates a timely branch actually certified a false statement. The post-control behavior gives the contiguous conclusion.

During the initial part of the phase every live control supplier offers, even during cooldowns. Its rank is lower than every pool rank and the tag. If the responder remains live after the last of its $b+1$ suppliers wins, it must win on the very next date. Otherwise the responder was preempted on the distinct successors of *all* $b+1$ supplier wins, using a different rank below $b$ each time. There are only $b$ such ranks. Consequently there have been no pool wins when the last live control member retires. The tag remains live. After all controls retire, guards are idle, earlier bins have cleared their non-raw ranks, and the only possible preemptors of a selected pool member are lower raw slots. A date following a lower raw retirement can be a cooldown; after controls have retired the first normal eligible date can be identified from the genuine past.

The phase windows are disjoint. Below the first $S$ bin endpoints there are at most $S$ ordinary raw slots, plus finitely many initializations. Each raw slot wins at most once over the entire construction. For the stated dispatch via the exponent of two in $s+1$, each fixed descriptor occurs in $\Theta_{\mathrm{descriptor}}(S)$ of the first $S$ bins. Thus already in the original allocation infinitely many matching bins have at most a descriptor-dependent constant number of lower raw retirements during the phase. After control clearance an interruption between consecutive successful-response blocks requires such a retirement: it preempts a normal or response offer, or causes a cooldown. Hence an $\Omega(e)$ number of successful responses yields one $\Omega_{\mathrm{descriptor}}(e)$-length contiguous run on those bins. The constant can depend on the descriptor. Full elimination of these interruptions on a dense set of matches takes the following change.

**Sparse ordinary slots.** In bin $s=j^2$ use its original raw slot for ordinary program $j$, starting at $j=0$. In other bins give that slot the guard rule, including persistent zero offers only after its phase and final response have passed. The eight initialization ranks and all other bin roles, times and search clocks stay as in the dense construction. Detecting squares and computing their integer roots for an active bounded index costs polynomial time in $i$. Every ordinary reporter still has one fixed finite rank, hence eventually gets a fixed positive fraction of the native clock. Previous non-raw ranks still retire before the next phase. New non-raw slots can be included among the guards when evaluating the number of honest outsiders. The same uniform simulation and packed compiler yield ordinary explicit 3-CNFs of length $2^i\operatorname{poly}(i)$. A qualifying date and a proposed exclusion use the actual histories of this auxiliary enumeration. [Physical implementation](density-of-certified-winner-pairs.md)

Among the first $S$ bins at most $1+\lfloor\sqrt S\rfloor$ can have **any** lower raw retirement during their phase: charge each such bin to an actual distinct raw program with a square slot in the first $S$ bins. Later raw slots rank above its tag. The ratio of this exceptional count to the $\Theta_{\mathrm{descriptor}}(S)$ matching bins tends to zero. No effective prediction of which bins are clean follows from this density calculation.

On a clean bin there is no cooldown after the public initial date. Take $K$ to be the first normal date after all controls have retired. At that point every pool member and the tag is live. In a sufficiently late matching bin every common search and response completes. If the search selects a pair, its first member wins on that date, its responder wins on the next, and the pool returns to normal on the following date. If the search selects no pair, the tag wins immediately. Higher ranks cannot affect either alternative. Iteration proves the claimed pattern, with exactly $p-2F$ pool survivors at the tag's win. Completeness on qualifying wins forces $p-2F<\lceil e/2\rceil$, proving the bound. A deterministic verifier uses no SAT assumption here. For a nondeterministic verifier the clean matches must include an actual correct proposed SAT algorithm so that every selected pair really has an accepting branch within the clock. The existence of the clean dates itself is unconditional. Lean checks the numerical bounds and the exact list of burst dates once the control-free transition is supplied. ## A public challenge on which the prover can change its answer

Let $A(x,c,p)$ be a bounded predicate on a menu name, a challenge and a reply. Assume that if event $x$ actually occurs, some challenge $c$ has no accepting reply for that name. Give the prover a table containing one challenge $c_x$ per name. Allow it to choose the name **after** seeing this entire table. The following equivalence is exact:

$$
\bigl[\forall (c_x)_{x=1}^M\ \exists x,p\ A(x,c_x,p)\bigr]
\quad\Longleftrightarrow\quad
\bigl[\exists x\ \forall c\ \exists p\ A(x,c,p)\bigr].
$$

If every name has a bad challenge, one table contains a bad challenge for each. The converse uses the same winning name for every table. This gives a fixed name with a sound individual test even if the prover's outputs on different tables never agree. Given an $O(n^k)$ SAT algorithm, one can test the individual predicates under two SAT eliminations and enumerate the names separately. The table costs a polynomial in the stage $i$ times the length of one challenge, because $M=\operatorname{poly}(i)$. Thus if all sufficiently late qualifying positive wins pass the table test, branch time $2^{(1/k^2-\epsilon)i}$ for fixed $\epsilon>0$ suffices for the dense-bin contradiction. The search for a qualifying date need not be performed. The argument uses the dates provided by the theorem for the resulting fixed deterministic tester. [Physical SAT compilation and quantified tests](public-challenges-for-two-future-verdicts.md)

A single common tape with an arbitrary deterministic expansion into the table can fail. Suppose each challenge has $D$ possible values and one table $(z_x)$ is outside the expansion's image. In row $x$ reject exactly at challenge $z_x$ and accept at every other challenge. Every generated table permits a name, but no fixed name passes every challenge. Thus a universally valid generator for such unstructured rows must have at least $D^M$ possible seeds. The ordinary product table attains this bound. Restricting the inputs to genuine SAT computations may introduce further dependencies among the bad challenges.

## How much statistical advantage suffices

Consider a public random tape, followed by one prover reply. For each name $x$ write $p_x$ for the probability that **some** reply names $x$ and is accepted. Suppose the probability that *any* name has an accepting reply is at least a public rational $\gamma$ on each sufficiently late qualifying positive win. If a menu event $x$ really occurs on any genuine eligible input, suppose $p_x\le\alpha$. The protocol may abstain, and the tapes counted for different names can overlap. Some name on each such win has $p_x\ge\gamma/M$, by a union bound. Blind uniform naming gives completeness one and false-output probability at most $1/M$. For exact fair-coin sampling one may keep the first $2^{\lfloor\log_2 M\rfloor}$ members of the menu, reducing its size by less than a factor two. In what follows $M$ is the size after any such restriction.

* With $R$ random bits, enumerate the $2^R$ tapes. The test for an individual name guesses accepting replies on at least $\lceil 2^R\gamma/M\rceil$ distinct tapes. It can traverse every tape in order and count verified replies. This is sound for $\alpha<\gamma/M$. No lower bound on the gap is needed. If $R=O(\log i)$ there is one SAT elimination at branch time $2^{(1/k-\epsilon)i}$. More generally, for one run costing $T$, exact enumeration costs $2^R(T+\operatorname{poly}(i))\operatorname{poly}(i)$ before this elimination. The public threshold must be computable within the bound.
* If the public gap $\gamma/M-\alpha$ is at least an inverse polynomial in $i$, amplify around its midpoint by independent repetitions, allowing a separate reply on each tape. Let $d$ be the amplified tape length. With $\operatorname{poly}(i)$ repetitions, the set $C$ of accepting tape vectors for a name of probability at least $\gamma/M$ has complement density below $1/[4(d+1)]$. For the actually occurring name with probability at most $\alpha$, $C$ has density at most $1/2$. This follows by Chernoff bounds because $R\le T\le 2^{O(i)}$ and the number of repetitions can dominate $O((\gamma/M-\alpha)^{-2}\log(d+2))$. Constants can be chosen uniformly for fixed clock and gap bounds.

There is a two-quantifier-block test for the amplified condition. Universally give $g=\lceil\log_2(d+1)\rceil$ binary generators and existentially give a translate and accepting replies for every vector in the translate of their span. Duplicate vectors are harmless. When $C$ has the large density above, a random translate meets its complement with probability less than $2^g/[4(d+1)]<1$, for each span. When $C$ has density at most $1/2$, some span of $g$ generators has **no** translate contained in $C$. Indeed start with $U=C$. Choose each next generator $z$ so that $U\cap(U+z)$ has density at most the square of the current density, as follows by averaging. After $g$ choices the number of remaining points is at most $2^{d-2^g}<1$. The surviving points would be exactly the origins of translates contained in $C$. [Translate-cover argument of Lautemann](https://www.sciencedirect.com/science/article/abs/pii/0020019083900443) · [Alternating-time bounds of Viola](https://drops.dagstuhl.de/entities/document/10.4230/DagSemProc.06111.11) · [Finite span estimates](../lean/ShortSpanCover.lean)

Checking all $2^g=O(d+1)$ amplified transcripts costs $T(1+R)\operatorname{poly}(i)$ per branch, charging the transcripts and the generation of the translates. If $T\le 2^{\tau i}\operatorname{poly}(i)$ and $R\le 2^{\rho i}\operatorname{poly}(i)$, two SAT eliminations fit below the native time when $k^2(\tau+\rho)<1$. In particular polynomially many random **bits** allow $\tau<1/k^2$, even when exact enumeration of the tapes would be too costly. The [three-block translate cover](public-challenges-for-two-future-verdicts.md) instead tests just one translated transcript per branch, after amplifying the small density below $1/[4(d+1)]$. This costs $T\operatorname{poly}(i)$ before three eliminations and suffices for $k^3\tau<1$. Both versions extract the same individual-name verifier for the dense-bin argument. No gap on arbitrary incomplete, true exclusions is needed. A qualifying win in this application must have a name in the offered menu. All sufficiently late matching hard wins supply large menus of live pool members.

## What one can actually obtain from the previous verifier

Fix a program $W$ with bounded Boolean witness predicate $W(x,u)$ for a named exclusion, including its stage, past and bin parameters. Use a bin dispatch whose search on a normal date first checks if $\exists u\ W(x,u)$ and selects the first accepted live pair in public order. Under the fast-SAT hypothesis one can fix an actual correct proposed solver $S$ for these searches. A rule restricted to these descriptors can compare the embedded program and solver to their fixed texts and abstain elsewhere. A deterministic dispatch can also run the actual test directly. Enforce normal-mode starts from the genuine past. A first winner in response mode obeys a different selection rule.

On such normal starts, **if a menu event $x$ occurs, the bounded predicate $W(x,u)$ accepts for some $u$**. The first winner was the selected first rank, and only its designated responder can produce the next pool win. Conversely at a positive tag win with a complete normal search, every live row has no accepting witness, since an earlier selected rank would otherwise have offered. These statements concern decisions made by the actual search. No semantic soundness premise on $W$ is needed for either implication. The uniform clock estimates give complete searches on sufficiently late bins matching fixed appropriate descriptors. An unknown or incorrect solver’s positive answer cannot be used as evidence for a witness.

For any single named pair, therefore, $\forall u\ \neg W(x,u)$ is already a sound exclusion test on these inputs, complete on the specified positive wins. A deterministic $W$ requires only one bounded call. For a nondeterministic $W$, directly replaying one branch with a challenge $u$ has perfect completeness and at least one detecting challenge for a real event. It requires a *universal* block, and elimination by SAT costs the $k$th power of the branch time up to encoding overhead. This construction inspects one candidate's own predicate. Replaying the entire lexicographic search is unnecessary. Testing a predicate at its full clock, or eliminating its complementary block, does not supply an individually accepting existential witness below that clock on its own matching bin.

With two names $x<y$ in the public search order there is a total choice whenever the per-row computation finishes. Reproduce the dispatcher's bounded decision on $x$. If it says no, exclude $x$. If it says yes, exclude $y$, since an accepted $x$ precedes $y$ and prevents its selection. In either case an actual normal first win and its pool responder cannot realize the named event. This form uses only the Boolean used by the dispatcher. It also applies to an incorrect proposed solver if the bounded candidate-call semantics are reproduced exactly, with fresh state, identical inputs and width, and abstention on unfinished calls. A phase search that times out without selecting anyone cannot realize a first pool win. The cost of computing the one decision on a self-matching bin remains.

There is also an actual lottery with a small statistical improvement on blind naming. Pad the witness strings to $w$ bits, $D=2^w$. Pick a uniform name and a uniform $w$-bit offset. On its row query $b\le D$ different positions by adding the offset (bitwise XOR) to $b$ fixed distinct strings. If any query accepts, abstain; otherwise name that pair. It always produces a name on a clean positive win. If the real event is in the menu, fix one of its accepting witnesses. The shifted subset hits that witness with probability $b/D$, so the probability of falsely naming the event is at most $(1-b/D)/M$. With a single accepting witness this is exact. Its running time is $b$ single witness checks plus the sampling overhead. The advantage for one accepting witness and one probe is $1/(M2^w)$, too small for inverse-polynomial amplification when $w$ grows faster than $\log i$ and $M=\operatorname{poly}(i)$. Exact enumeration also has to pay for the $w$ random bits in this construction.

## Optimal black-box dependence on the number of witnesses

Give an algorithm membership probes to an $M$-by-$D$ Boolean table. On the empty table it must return some name with probability at least $\gamma$; on a table with $1\le h\le D$ marked entries confined to one row, measure the probability that it names that particular row. Allow adaptive queries, public-coin prover replies, and at most $b\le D$ probes on each path. The least possible worst-case erroneous naming probability, for finite lotteries allowing the stated probabilities, is

$$
\frac{\gamma}{M}\frac{\binom{D-b}{h}}{\binom{D}{h}}.
$$

Use the convention that an impossible choice has binomial coefficient zero. For the lower bound, on every successful public tape of the empty input select one accepting reply and transcript. Some row $x$ is named by these selected transcripts on a set of tapes of mass at least $\gamma/M$. Place a uniformly random $h$-set of marks in that row. Each such transcript probes at most $b$ distinct locations in the row, so with probability at least the displayed binomial ratio it misses the entire set. Taking the same reply on that tape preserves every adaptive answer and the erroneous name. Averaging fixes a single marked table giving at least the claimed mass. The same lower bound allows several rounds and private verifier coins when one fixed prover strategy achieves completeness on the empty table. Replay this strategy without consulting the planted entries. On each tape whose old transcript misses the marks, every public message and the final name remain identical. For the upper bound, attempt a uniform name with probability $\gamma$, sample $b$ distinct positions uniformly in its row, and return the name exactly when all queried positions are blank. The miss probability is $\binom{D-h}{b}/\binom{D}{b}$, equal to the stated ratio. The uniform finite subset lottery realizes the bound abstractly; the XOR-offset implementation above realizes it with bounded fair bits for $h=1$ and dyadic $\gamma$ and $M$ a power of two.
