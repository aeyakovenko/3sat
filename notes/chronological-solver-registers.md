# Circuits for the actual register history of a quadratic or cubic SAT solver

**Research journal, 24 November 2026.** Fix $k=2$ or $3$ and a correct deterministic $O(N^k)$-time SAT solver on the packed logarithmic-word RAM. Here $N$ counts formula bits and $L=\max(2,\lceil\log_2(N+2)\rceil)$. On the ordinary load/store instruction set, a writable-memory load returns its word in a designated register, a store takes its address and value from the pre-instruction controller, and arithmetic operates on registers. The controller includes the program counter and halt status. There is no bound on work memory.

Let $G_F(t)$ be the entire controller **before instruction $t$** on formula $F$, padded by idling after halt through a fixed valid clock $T=\lceil C N^k\rceil$. A Boolean circuit for $G_F$ is specific to this one input. Its only input is a binary time, and its $O(L)$ output bits give all the controller fields. Require equality at $0\le t\le T$ and allow arbitrary values elsewhere. For each sufficiently large source padding length there is an unsatisfiable formula $F$ for which this function requires the following numbers of bounded-fan-in Boolean gates.

| Assumed SAT time | Gates for the actual register and PC history |
| --- | --- |
| $O(N^2)$ | $\Omega(N^{1/4}/L^{13/4})$ |
| $O(N^3)$ | $\Omega(N^{1/9}/L^{7/3})$ |

The bound measures the actual run of the specified program. The circuit supplies no snapshots, memory cells, addresses as inputs, or last-writer timestamps. On an ISA with fused memory and arithmetic operations whose fetched values are hidden, the same proof applies to the controller together with the bounded list of native memory events per instruction. The register-only statement uses the load/store convention above. [Packed machine and bounded source encoding](packed-band-transfer.md)

## Checking only what the registers disclose

Guess an acyclic circuit $G$ with $s\le N$ gates, check its coding, and require the true initial controller and a rejecting halt at time $T$. Times, gate indices, addresses and words have $O(L)$ bits. For any time $t<T$, the two outputs $G(t),G(t+1)$ determine the instruction, effective address, written word for a store, and returned word for a load. First check the register transition with that returned word treated as the proposed reply. Include the read-only formula's true value for an input load, and check PC updates, preserved registers, bad instruction encodings, bounds and halt padding. The remaining issue is whether a proposed writable-memory load value is genuine.

A memory defect has a consumer $t$ and an earlier same-address store $j<t$ whose written value differs, with no intervening same-address store. The initialization alternative uses a load disagreeing with the initial zero and no earlier store. This is an equivalence on the **proposed** event stream. Applying it to every read forces the true trace by induction from initialization. Each accepted local transition has exactly the reply prescribed by all previous writes. Conversely, the true rejecting controller trace passes. [Value-only defect characterization](succinct-memory-defects.md) · [Finite last-writer lemma](../lean/CrossBlockProducers.lean)

For fixed candidate consumer and producer, an intervening store is an existential SAT test. Take a constant number of copies of $G$, add the time comparisons, instruction decoding and word address tests, and Tseytin-encode the gates. The resulting explicit 3-CNF has $O((s+\operatorname{poly}(L))L)$ bits, including binary literal indices. An initialization defect uses the same test on its prefix. The inner test asks only about a store in the proposed register history and never reads $F$. Generate and solve this ordinary instance in $O((sL)^k+\operatorname{poly}(L))$ word steps. The absence of a store is the negative verdict from this deterministic SAT call.

The **outer nondeterministic defect test** chooses a local transition failure or guesses $t,j$ and their defect type, evaluates the corresponding rows, and performs that deterministic inner SAT call when required. The outer test receives the circuit as public data. It is the *whole program*, including all steps of the inner SAT solver, that is converted to one further explicit 3-CNF. This accounts for the second SAT exponent. With outer clock $R$ and $m$ public words, the packed conversion uses $O(RL^3+mL^2+\operatorname{poly}(L))$ bits. Solving that instance deterministically establishes whether any defect exists. [Materialized input conversion](materialized-input-census.md)

## The signed input and the two costs

Take a bounded nondeterministic interpreter on an $n_0$-bit input $x$ with source clock $h=n_0^{2k^2+2}$. Its locally addressable packed formula $F_x$ has $N=\Theta(h\log^3 h)$ bits. Every read of $F_x$ by the outer test is generated from the original $x$. It does not receive a separate $N$-bit public array. Its public data occupy $O(n_0+s+\operatorname{poly}(L))$ words. The combined cost of writing the instances, running the solvers and processing the guessed circuit is therefore
$$
 O\big(s^{k^2}L^{k^2+3k}\big)+o(h).
$$
Indeed the outer execution takes $R=O((sL)^k+\operatorname{poly}(L))$ steps, after which its $RL^3$ term is raised to the $k$th power. The additional $(n_0 L^2)^k$ and all fixed polylogarithms are $o(h)$. Fixed-width timestamp fields and regular padding give computable query lengths, and an intermediate clock $\max(R,m)$ adds at most an $mL^3$ term to the generated length, which fits the same final bound here. A larger fixed host word-width constant handles this source polynomial. The physical arrays accessed by the fixed programs have polynomially bounded addresses in $n_0$, and the arbitrary source word values and addresses go into the virtual trace encoding as data. [Bounded interpreter and width conventions](packed-band-transfer.md)

Define a single program that signals success on a guessed circuit precisely when it certifies rejection and has no defect. On its own padded description $x$, $F_x$ is satisfiable exactly if the interpreter sees such a signal by time $h$. Every signal certifies that the correct solver rejects $F_x$. Thus $F_x$ is unsatisfiable and no signal occurs by that deadline. If its **true** rejecting register stream had a circuit of size $s\le c h^{1/k^2}/L^{1+3/k}$, guessing it would produce a timely signal for sufficiently small fixed $c>0$. Since $h=\Theta(N/L^3)$, this gives the claimed gate bound $\Omega(N^{1/k^2}/L^{1+3/k+3/k^2})$. The self-inputs consist of a fixed program description followed by padding, one at each sufficiently large source length. [Signed bounded-clock argument](../lean/SolverSnapshotReplay.lean)

## When the stream also gives the last writer

Augment each genuine load row by the time of its latest earlier same-address write, or an initialization marker. At a guessed time, a defect can now show an erroneous named source or select an intervening same-address store. All relevant rows, including the target of a predicted index, come from a constant number of directly composed copies of the augmented circuit. One ordinary existential 3-CNF therefore suffices. Public-input load checks can be included as Boolean circuits. On the fixed padded inputs $x$, each source-input read is a bounded lookup in a fixed program header and zero padding. Alternatively a uniformly generated selector for arbitrary $x$ costs $n_0\operatorname{poly}(L)$ gates. Its $k$th-power cost remains $o(h)$ on the chosen clock. The virtual generator's fixed word operations on $O(L)$ bits cost $\operatorname{poly}(L)$ gates per selected formula word.

The resulting verification costs $O((sL)^k)+o(h)$. The same signed argument yields $\Omega(N^{1/k}/L^{1+3/k})$ gates for the jointly augmented stream. One verifier can guess a format bit and implement either check, giving both conclusions on the same source family. For each format the successful branch uses its own length-dependent clock.

There are a fixed number of controller fields. Combining separate word-output circuits shows that at least one component, possibly the PC, needs the register-stream lower bound up to a constant. A single component recurs on an infinite subfamily. For individual output bits, or a single Boolean accessor with an extra bit-position input, composing at most $O(L)$ circuits gives the same lower bound divided by $O(L)$. The hard bit position can depend on the input length. The argument establishes an obstruction to compressing actual solver trajectories under the assumed time bound. It leaves open whether those solvers exist. Related easy-witness results study circuit encodings of accepting witnesses; priority for these particular actual-register bounds is unverified. [Murray and Williams](https://people.csail.mit.edu/rrw/easy-witness-nqp.pdf)
