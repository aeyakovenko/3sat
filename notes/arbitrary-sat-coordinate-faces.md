# A Hamiltonian-cycle face inside any large set of SAT input bits

Consider an explicit 3-CNF encoding with a header of $O(w)$ bits followed by $C=2^w$ fixed-stride records of three literals. A literal has a sign and a $w$-bit variable name. Names $1,\ldots,2^w-1$ are available, unused names are allowed, and repeated literals are allowed. Use the header for this actual variable range and clause count. These legal widths give an increasing sequence of lengths $h=h_w=3C(w+1)+O(w)$. A Boolean function on all $h$-bit strings can handle malformed inputs in any fixed way specified by the language. The construction uses only valid CNFs, with no variable-length integers or arbitrary padding fields among the records.

**Face lemma.** Let $U$ be any set of $k$ physical bit positions. For constants $A,c_0>0$, and every sufficiently large $m$ satisfying
$$
 m^2\le (k-O(w))/(3(w+1)),\qquad m^A\le c_0 C,
$$
one can leave exactly $m^2$ bits of $U$ free and pin *all* other bits to Boolean constants so that the SAT verdict on the face tests whether the free matrix, up to reversing individual bits, is a permutation matrix consisting of one directed Hamiltonian cycle. One can also use the test for an arbitrary permutation matrix. In particular every set of $h^\epsilon$ positions permits $m\ge h^{\delta}$ for some $\delta>0$ at fixed $\epsilon>0$. Name bits alone suffice when $U$ contains no sign bits.

**Circuit consequence.** Fix a field $F$ and let $P$ agree with SAT on the Boolean cube at length $h$. Suppose that for **every Boolean assignment outside $U$**, the remaining polynomial in $U$ is formally multilinear. There is no degree restriction at all outside $U$. For $|U|\ge h^\epsilon$, every division-free arithmetic circuit for $P$ has size at least $2^{\Omega_{F,\epsilon}((\log h)^{4/3})}$ on these lengths, using the reported Hamiltonian cycle circuit lower bound over $F$. In particular, if the entire output is formally multilinear in each of at least $h^\epsilon$ individual physical bits, the conclusion applies. The set $U$ can be chosen separately for each proposed circuit. ## Placing a matrix bit in a preselected record

Discard the header positions. Every record accounts for at most $3(w+1)$ positions of $U$. Pick $m^2$ distinct records with a designated position of $U$ in each. In each make the two other literals positive occurrences of one common variable $f$, and force $f=0$ by a separate fixed unit. This makes the selected literal a unit without duplicating any varying input bit.

* For a selected sign, use a fresh variable. Its forced value or the complement of that value is the corresponding matrix bit.
* For a selected name bit in place $j$, use a fixed positive literal whose two possible names are $a_0,a_1=a_0\mathbin{\mathrm{xor}}2^j$, with bit $j$ of $a_0$ zero. Add the two fixed clauses $(a_0\lor a_1)$ and $(\neg a_0\lor\neg a_1)$, repeating a fixed literal when necessary for padding to width three. These constrain the two variables to be opposite, leaving their values free until the selected unit is read. The value forced on $a_1$ is the physical name bit. Per-bit reversals are harmless.

There are $2^{w-1}-1$ disjoint name pairs of any specified type $j$ avoiding the forbidden zero name. Previously used names spoil at most one pair each for the new $j$. Allocate the names of all carriers and $f$ first, avoiding collisions even between a future signal and an earlier auxiliary. For small enough $c_0$ and $A\ge2$ there are always unused pairs. Then allocate the remaining checker variables by unused names. No step assumes that $U$ contains whole words, low bits, adjacent coordinates or positions in a convenient part of the clause list.

The remaining fixed records impose gate equivalences for a bounded-fan-in Boolean circuit on the $m^2$ signal variables, with a unit requiring its output to be true. The circuit checks unique incoming and outgoing edges and reachability from one specified vertex. For instance repeated Boolean matrix squaring of the adjacency matrix with the diagonal added computes reachability with polynomially many gates. Thus $A$ can be any sufficiently large fixed constant, increasing it to absorb gate layout and temporary wires. Choose $c_0$ to leave room for every clause and variable. Place equivalences at any of the remaining record positions, and fill residual slots with true fixed tautologies, such as $(f\lor\neg f\lor f)$. For every filling all carrier variables have their intended Boolean values. Gate induction gives the desired verdict. Foreknowledge of $U$ is used only when exhibiting one face in a nonuniform lower-bound proof.

## Extraction and its quantitative limit

The complement of $U$ has been pinned. Pinning the unused positions within $U$ preserves formal multilinearity in the remaining $m^2$ independent bits. The restricted $P$ now agrees on the cube with the one-cycle predicate. By uniqueness of multilinear extension it equals
$$
 M(Z)=\sum_{\pi\text{ one cycle}}\prod_i Z_{i,\pi(i)}
               \prod_{i=1}^m\prod_{j\ne\pi(i)}(1-Z_{ij})
$$
as a formal polynomial in data coordinates. Here one can simply take the degree-$m$ homogeneous part. Each cycle term already contains $m$ present-edge variables and all its absent-edge factors have constant term one. Consequently $[t^m]M(tX)=\operatorname{HC}_m(X)$ over every field. Truncation at degree $m$ suffices throughout the circuit. The formal HC circuit has size at most $\operatorname{poly}(h,m)(1+\operatorname{size}(P))$ by ordinary convolution. Arbitrary reversals of free physical bits use $1-Z_{ij}$. The polynomial loss is absorbed by the stated formal lower bound at $m\ge h^\delta$. [Truncated computation and the odds identity](quadratic-oracle-exclusion.md)

More precisely, if $P$ has size at most $h^D$ for a fixed $D$, then every eligible $U$ has at most $\exp(O_{F,D}((\log h)^{3/4}))$ positions. Indeed choose the largest $m$ allowed up to fixed constants by the smaller of $\sqrt{(k-O(w))/(3(w+1))}$ and $(c_0 C)^{1/A}$. The extracted circuit has size $h^{O_D(1)}$, which forces $\log m=O_{F,D}((\log h)^{3/4})$. The second cap grows as a fixed positive power of $h$, so for all large widths it cannot be the smaller one on such a circuit. The first cap gives the claimed bound on $k$, including the $O(w)$ header loss and floors. This derives the subpolynomial cutoff directly.

## The same tests on a scan-time Boolean language

The carrier formulas expose a flaw in using this circuit bound to infer a lower bound on native time. On valid strings of the selected lengths, propagate every forced unit until a conflict occurs or the queue empties. Return true exactly when all clauses are satisfied by the resulting partial assignment without conflict. On malformed inputs or outside the specified lengths return false. This is a sound positive SAT test. On every face built above it gives **exactly the same answer as SAT**. The carrier units and the forced-false variable fix every data signal. Each Boolean gate equivalence forces its gate value once its inputs are known. In the accepting case all fixed clauses, including filler tautologies using $f$, become satisfied. In the rejecting case the required output conflicts. Gate order in the physical encoding is irrelevant to propagation.

Implement propagation with an occurrence list per literal, a queue, assignment flags, and constant work per visited occurrence of a width-three clause. Ignore duplicate literals when determining whether a clause is a unit; recognize repeated-literal units even before a variable is assigned. The header check and fixed-width parsing cost $O(C+v+\operatorname{poly}(w))$ word operations for $v=2^w-1$. A literal record intersects a constant number of logarithmic words. Each newly assigned variable visits its occurrences once. One last scan suffices to check the resulting assignment against all clauses. Thus the Boolean language has deterministic time $O(h/\log h)$ on the logarithmic-word RAM, with immediate rejection at lengths outside the dense layout after a length/header check. Yet it has the same functional-circuit lower bound for every large set $U$ above. This gives an explicit limit on what the face lemma alone can prove about the unrestricted SAT time goal.
