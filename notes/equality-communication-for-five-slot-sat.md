# A near-three-halves lower bound for the five-instruction DIMACS model

For every fixed $\epsilon>0$ there is no five-slot program deciding ordinary DIMACS SAT in time $O(N^{3/2-\epsilon})$ in the [separate-operation RAM](five-instruction-loops-on-dimacs-sat.md). Here $N$ counts the entire formula, and the logarithmic word-width rule is the byte-aligned one in the [sparse-name theorem](sparse-decimal-names-in-dimacs.md), including its uniformly computable fixed coefficients $D\ge1$. In each hard family used below the declared variable bound is polynomial in the file length, with a fixed power that may depend on $D$ and $\epsilon$. The result is a static five-slot exclusion. It leaves the arbitrary-program-size time question open.

The only instruction allocation in the earlier proof that needs a new argument is the public crossed scan, with $p_i=p_0+id\bmod 2^w$ for a fixed nonzero program integer $d$. Its writes between consecutive loads have form $M[x_i]\gets p_{i+\delta}$, $x_i=M[p_i]$, $\delta\in\{0,1\}$. The proof below uses a communication bound on this actual schedule. It allows arbitrary register-only comparisons, early exits and the full workspace. The same proof applies to the portion of the fixed lookahead-two scan before its forced suffix. ## Explicit SAT inputs for equality

Give Alice $u\in\{0,1\}^k$ and Bob $v\in\{0,1\}^k$. The first half of a formula forces each $x_i$ to the value $u_i$, and the second half forces $x_i$ to $v_i$. Use four distinct-variable 3-clauses per pin by disjoining the specified signed literal with all four choices of signs on two shared distinct dummy names. The entire formula is satisfiable precisely when $u=v$. Every sign uses a reserved space or a minus, with a separator before the sign so that no tokens join. Fixed-width fields and line terminators give the same lengths and a public midpoint for all pairs. One may pad the midpoint to a word boundary with less than a word of spaces, or send the one straddling word's private bytes at startup in $O(w)$ bits. All other original bytes on each side depend only on that party's private string. Initial workspace and metadata are public.

For every fixed $\eta>0$ the variable names can be chosen to give at most $h=O(N^{\eta})$ different original word values on every one of these files. Use $K=\lceil\log_2(k+3)\rceil$ index bits and put a fixed, sufficiently large number of decimal zeros between their digits. The source identifiers for the $k$ pins and two dummies are distinct. Using the fixed-width name and sign fields of the sparse-name construction gives $N=\Theta_{\eta,D}(k\log k)$ and $h\le N^{D/(8t)+o(1)}$ for a fixed gap $t$. Choose $D/(8t)<\eta$. This is an injective variable renaming permitted by the standard DIMACS convention allowing unused variables. ## Communicating an actual scan

Split the cyclic physical address range into Alice's contiguous initial interval and its complement held by Bob. Each party initially knows all its words. Ignoring exits, $p_i$ travels by fixed displacement $d$ around this circle. In any one orbit period $L=2^w/\gcd(d,2^w)$, the reader changes owners at most $2|d|+O(1)$ times: a switch must start within $|d|$ residues of an interval boundary, and no address recurs within that period. Include the first and final incomplete phases. For $m>0$ reads and $P=\lceil m/L\rceil$, at most $O_d(P)$ contiguous runs of one owner's reads occur. A pre-scan write adds a constant communication charge. In a run, its owner locally simulates all loads and all register/control instructions. It buffers the last value sent to each foreign write destination in that run. The other party performs no reads before the handoff, so transmitting only these final values, their addresses, the registers and control suffices for exact simulation. A final halt transmits the output if needed. An end marker or record count uses $O(w)$ bits since the domain has $2^w$ words.

By the last-writer theorem there exists a set $U$ of at most $(P+1)(h+O(1))$ addresses such that every pair $(p_i,x_i)$ has an endpoint in $U$. The protocol does **not** need to compute $U$, know $m$, or know the other side's input. A foreign destination in $U$ is charged at most once per ownership run. For a foreign destination outside $U$, the source $p_i$ must be in $U$, and each such source occurs at most $P$ times. Thus at most $O_d(P^2(h+1))$ word records are transmitted on that particular input. A fixed clock therefore gives an all-input protocol with at most $O_d(w(P_{\max}+1)^2(h_{\max}+1))$ bits. Here $P_{\max}$ and $h_{\max}$ are worst-case upper bounds across the equality files at this length. The same argument works before the first forced equality at lookahead two; an owner finding the equality can locally compute the remaining output from the public schedule and the registers and send that verdict.

Deterministic equality on $k$ bits requires at least $k$ bits of worst-case communication. The $2^k$ accepting diagonal inputs must have different accepting transcripts: if $(u,u)$ and $(v,v)$ for $u\ne v$ shared one, then $(u,v)$ would follow it too by induction over the messages. Self-delimiting binary protocols with worst-case $b$ bits have at most $2^b$ leaves. Combining these bounds with $w=O(\log N)$, $L=\Omega_d(N)$ and $m\le T$ gives
$$
 k\le O_d\!\left((\log N)(1+T/L)^2(h_{\max}+1)\right).
$$
If $T=O(N^{3/2-\epsilon})$ for $0<\epsilon<1/2$, choose $\eta<2\epsilon$. The right side is $O(N^{1-2\epsilon+\eta}\log N)=o(k)$ because $k=\Theta(N/\log N)$. This contradicts equality. Bounds with larger $\epsilon$ follow by inclusion. An arbitrary correct solver is allowed to use different amounts of time on different equality inputs.

## Combining the five-slot cases

The periodic edit and arithmetic cases already force wrong answers or $\Omega(N^2/\log^2 N)$ steps, including the marked additive excursion. In each remaining case except the public crossed scan, the simulator needs at most $O((h+1)\operatorname{polylog} N)$ bits, or a fixed number of public counters. Use virtual hard DIMACS instances with $h\le N^{0.01}$ by choosing a sufficiently large fixed gap. At a hypothetical $O(N^{3/2})$ clock the resulting simulation of nondeterministic linear time has time $O(n^{1.501})$ and space $O(n^{0.012})$ after polylogarithmic factors. At $c=1.501$ the forbidden exponent $((c+2)/c^2-c)/2$ exceeds $0.026$. This rules out those schedules. The argument from sufficiently large lengths also covers finite initial exceptions. [FLMV, Corollary 5.8](https://lance.fortnow.com/papers/files/tst.pdf) · [Five-slot case analysis](five-instruction-loops-on-dimacs-sat.md)

For unrestricted machines the equality construction has a different behavior. A machine can read the two matching fixed-stride sign fields for each variable consecutively, compare them and advance to the next pair. It then crosses the ownership boundary order $k$ times; the fixed-increment scan crosses only $O_d(P)$ times. A fast path on this promise family is therefore compatible with the unrestricted SAT goal. The communication argument does extend to arbitrarily many controller instructions when the same public read schedule is retained and a write may use any of a bounded number of future addresses as its payload. Using legal names of up to $O(\log^2 N)$ decimal digits gives the explicit $\Omega_D(N^{D+1/2}/(\log N)^{3/2})$ bound on these schedules. The other five-slot cases already exclude an $O(N^{3/2})$ clock. At $D=1$ this gives an infinitely-often $\Omega_P(N^{3/2}/(\log N)^{3/2})$ lower bound for any correct five-slot program on full DIMACS. The implicit constant may depend on the program.
