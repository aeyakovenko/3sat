# Exhausting all ways to combine the outputs of clocked RAM programs

Fix one physical bit length $N$ and any deterministic collection of measurements on legal ordinary proper DIMACS files of that length. Its signature $s(X)$ may be the vector of timely YES, timely NO and timeout for a list of arbitrary RAM programs. Suppose the range on this slice has $r$ elements. A decoder is **any** Boolean function of the signature, including a lookup table chosen separately at this length. There is no charge for its code in the following impossibility test.

**If every decoder fails on this slice, at most $r+1$ actual $N$-bit root files certify that fact.** The verifier runs the measurements on these roots and on a constant number of same-length children per root. It checks a sequence of local implications. It needs no SAT oracle or certificates of unsatisfiability. Conversely every accepted certificate implies that two files among the roots and their children have the same measured signature and opposite actual SAT verdicts. The bound $r+1$ is attained for every $r$, even when each feature can be computed in linear time for fixed $r$. This sharpness concerns certificates made of local root tests. Given externally established true labels, two files already witness a collision. [Self-reduction on ordinary files of exactly the same length](same-length-local-defects-for-ordinary-sat.md) · [Earlier three-file universal interpreter census](three-files-for-the-unrestricted-sat-clock.md)

## The local test

Use the exact-length reduction with branching bound $D=8\cdot3^8$. A small base formula can be evaluated in $O(N)$ time. Every other true formula has a true child, and any true child makes its parent true. There are no cycles in the actual reduction, because the number of occurring names above 3 decreases at each step. After replacing a file with its signature, cycles and identifications between different files may occur.

Mark a signature to mean “the table must decode this value as UNSAT.” Start with no marks. A false base permits a mark at its own type. At any internal root $X$ allow these two rules.

1. If every child type is marked, mark $s(X)$. An empty list of children satisfies this condition.
2. If $s(X)$ is marked, mark the type of any specified child.

A true base forbids a mark at its type. Each rule follows from the requirement that the parent decode to the OR of the decoded children. These are ordinary Horn rules on the false-value indicators. Their least closed set is obtained by adding new marks until no rule adds another. If this set misses every true base, assigning NO exactly to its marks satisfies *all* base tests and local equations. Induction in the original file reduction then makes this table correct everywhere. If all tables fail, some true base is marked at closure. Record a physical root justifying each of at most $r$ newly marked types and the final true base where a mark is forbidden. Which child is used and which rule applies cost only constant metadata per step. The generic Horn bound is classical. [Davydov, Davydova and Kleine Büning, Corollary 10](https://doi.org/10.1023/A:1018924526592) · [Kullmann and Shukla on minimal unsatisfiable Horn clause-sets](https://doi.org/10.1007/978-3-031-30820-8_23) · [Lean proof of the equivalence for finite Boolean signatures](../lean/SatSignatureConflict.lean)

If all physical files mentioned in this certificate admitted a consistent mapping from their signatures to their true values, their actual SAT labels would satisfy every recorded original equation and base test. This contradicts the checked derivation. Thus the certificate contains an opposite-verdict pair with exactly the same outputs of *every* measured program. Exhaustive assignment checks can identify a pair explicitly. Every globally correct total program in this measured list must time out on both members, because even its timed response agrees on the pair. The certificate alone suffices to certify existence of such a pair. It does not assume any program is globally correct.

For a uniform roster with polynomially many possible signatures and polynomial measurement cost, existence of a collision on the whole slice is therefore in NP with $N$ given in unary. The certificate uses at most $(r+1)N$ guessed file bits plus $O(r)$ bits for the rule choices. Run the measurements on each root and its children and store the marked signatures in a trie. The number of measurements is $O_D(r+1)$ for the entire vector, with the time for generating the vector charged each time. There is also a uniform negative verifier whenever a correct table is promised. A genuinely negative requested type must be marked by closure, by induction on its file, whether or not every type decodes consistently. If a correct table exists only negative types can be marked. Guessing the one sequence of at most $r$ mark justifications can certify any number of requested negative files at the same length and amortizes their shared witnesses. At fixed $r$ this costs $O(N+t(N))$ per single input if the roster's total measurement cost is $t(N)$.

There is a deterministic cross-exponent consequence as well. Given a root, maintain representatives of all different signatures in the current reduction layer. Directly test the bases. Expand all other representatives into their children, then keep one child per signature. If any original root is positive and the slice has a correct decoder, discarding a duplicate preserves a positive representative whenever one exists. Each non-base continuation strictly decreases the number of occurring names above 3, so after at most $v+1$ layers the decision is complete, where $v=O(N/\log(N+2))$ is the maximum possible number of distinct names. The total deterministic cost is $O_D((v+1)r(N+t(N)))$, including byte construction and the lookup of measured vectors when their encoding cost is included in $t$. No decoder need be given. In particular, if the quadratic RAM exclusion holds, then every fixed finite roster of $O(N\log N)$-time measurements has a same-length opposite pair of identical signatures at arbitrarily large lengths. Otherwise the layer algorithm, with only constantly many distinct trit vectors and finitely many exceptional lengths hardwired, decides SAT in $O(N^2)$. The analogous consequence of the cubic exclusion holds for $O(N^2\log N)$ measurements. These implications start with the respective unproved time exclusions.

## Sharpness on ordinary files

Fix $r\ge1$. On a base give a true file color $r$ and a false file color 1. Give an empty internal OR color 1. Otherwise set the color to the smaller of $r$ and one plus the largest child color. Every satisfiable file has color $r$. At any node where recursion has reached depth $r-1$ return the lower bound 1: along that branch the successive increments already saturate the original root at $r$. Thus one can compute the root's exact color in $O_D(D^{r}N)$ time by bounded exploration. This computes one signature uniformly, without solving SAT on the internal nodes.

For $j=0,\ldots,r$, consider the $r+1$ threshold tables which answer YES exactly on colors greater than $j$. A true base invalidates only $j=r$. A false base or empty OR invalidates only $j=0$. At a nonempty internal root the maximum child color is either the root color itself or one smaller. At most one threshold table can disagree with the OR of the children. Consequently **any $r$ physical root tests leave a table** passing all of them.

The whole length slice can still have no correct table. Take an UNSAT formula consisting of sufficiently many disjoint positive filler triples and the eight clauses excluding every assignment of a final disjoint triple. Put the fillers first with the contradictory triple on the largest names. Choose a branch that satisfies each selected filler at its first literal and carries the two false anchors. The subsequent roots begin with the six padding clauses of the reduction, so only two more filler rows are required per stage on this path, besides any touched by the designated pivot. Choosing all names in consecutive order makes the least fresh pivot lie in the first untouched filler. The negative root can have any prescribed path depth, hence color $r$. A true base can be spelled at the same physical length by whitespace and has color $r$. On a longest path of this finite negative reduction its height takes all smaller integer values, so all $r$ colors occur. For any fixed $r$, padding both inputs gives these conclusions at every sufficiently large byte length. For finite binary OR trees, Lean additionally verifies that lowering a cap truncates the old palette and that any collection of at most $r$ tested roots leaves a common threshold decoder. The physical realization uses the ordinary bounded-arity reduction just described. The [exhaustion using ten actual equal-length files](../audits/same_length_local_defect_audit.py) enumerates all Boolean decoders for $r=1,\ldots,6$; run with the option `--quotient`.

The palette can be implemented even by globally correct SAT programs with clocked outputs. Use the bits of $r-\operatorname{color}(X)$ as the signature: when its designated bit is one, the program returns a timely NO. This is sound since the color is then below $r$. Otherwise it exceeds its declared deadline before falling back to a complete SAT decider. Thus the all-timeout signature is exactly the top color. These deliberate delays calibrate the **cost of the method of exhaustion**. They do not show a hard input for an additional unrestricted solver. If fallible probes are allowed, $m$ probes can encode $r=3^m$ colors as timely YES, timely NO and timeout. The exponential value of the sharp bound then holds for testing arbitrary Boolean combinations of those probes. The number of globally correct binary-vote probes for the previous construction is $\lceil\log_2 r\rceil$.

**An exact one-program successor.** Keep every earlier program. At stage $r$ include the $r-1$ programs for levels $j=1,\ldots,r-1$. Program $j$ returns a timely NO exactly when the color computed with cap $j+1$ equals $j$; on other files it misses its clock before running a complete fallback. Its timely branch recognizes precisely the unsatisfiable files whose full reduction tree has height $j-1$, with height zero at a base or empty OR. The resulting signature is equivalent to the single color at cap $r$: it has one NO indicating the height level, or all timeouts at the top. Adding program $r$ splits only that top class. It gives a timely verdict on an old negative witness of height $r-1$, while a satisfiable file and a negative file of height $r$ still have identical responses. The optimum local certificate size increases **from $r+1$ to $r+2$**. A single sufficiently large length supports any fixed finite number of successive steps. In the 592-byte audit, the old and new UNSAT files in the third-to-fourth-color transition have reduction heights two and three. The third added level voter separates the first from a positive base and still times out on the second. The script prints content hashes for all three files. No program-code encoding is needed to make this statement. It describes a specified sequence of entrants and gives no guarantee for an arbitrary next entrant.

There is a growing uniform calibration at quadratic and cubic clocks. Take $s$ with $2^s>D+1$ and $r(N)=1+\lfloor\lfloor\log_2(N+2)\rfloor/(2s)\rfloor$. The bounded-depth color computation costs $O(N^{3/2})$. A fixed binary-indexed template computes the requested bit, with a fixed logarithmic word-width coefficient. An early NO therefore meets a single fixed quadratic multiplier at all lengths (increase it for finitely many small lengths). On the other branch the program deliberately misses its quadratic, or respectively cubic, deadline before giving the correct verdict. For each large legal length the requisite filler path uses $O(r(N)\log(r(N)+2))$ bits before whitespace padding, so it fits at that very length. This gives $\Theta(\log N)$ necessary local-root tests to exclude every decoder of the measured outputs of $O(\log\log N)$ genuine SAT programs, instantiated from one template. It remains possible to establish the mixed pair very cheaply by a different proof.

## Adding a clock or looking for a witness in a fixed search tree

After adding **one arbitrary clocked program**, each observed signature splits into at most three types. Run Horn closure again on the *same* recorded physical roots using the refined readings. If it still reaches a true base, the same root collection already contains the required collision at the larger program list. If it does not, the least closure yields an explicit decoder satisfying every recorded local test. A verified conflict whose file occurrences never split would still be a conflict. Consequently a new program clearing all old local conflicts must split a type in the files of each old conflict. This gives a finite checkable way to reuse a previous exhaustion and identifies exactly when further roots must be sought. A new program might split every old opposite-verdict pair by computing its actual SAT answer in time. The sharpness examples give no universal obstacle to that behavior.

A different use of the measured outputs can be made in a single proof-prefix search. At each depth keep one representative of each distinct output vector among the child prefixes under consideration, evaluating every vector on an actual physical file. If the root has a passing word and the search fails to recover one, some true prefix must have been discarded in favor of a false prefix with identical outputs. This follows at the first depth at which the represented list loses its last live prefix. With at most $r$ signatures per layer this needs at most $2r$ new vectors per level of the binary tree and $r$ final direct checks. Pad all prefix questions, including the root, to one fixed physical length. Thus a returned mixed pair is composed entirely of issued same-length queries. Inserting this search in a fresh self-referential clock program still requires an accepted proof within the cap to establish a live root. A fixed cutoff on the number of representatives gives an additional possible outcome: the search has actually seen more signatures than the cutoff at one layer. In contrast, the polynomial search over voters in the [two-sign recovery construction](polynomial-portfolio-search-on-the-sat-clock.md) does not require a small range, and its negative witness can be an implicit comparison at the least proof. Neither construction supplies the all-budget cap crossing.
