# How much working storage does a long proof of the actual sign need?

Let $M=2^j$ and let $b_j$ be the [priority output](priority-pinned-sat.md). Fix a uniform deterministic or nondeterministic recognizer that can signal only when $b_j=c$, for one fixed color $c$. Supply it with $j$ and stage data whose requested words are computable uniformly from $j$ in $\operatorname{poly}(j)$ time and space. In particular it can run an ordinary solver on either locally generated physical pin. If ordinary SAT has a deterministic $O(n)$ algorithm on the unrestricted logarithmic-word RAM, then:

* On every sufficiently large $j$, **every** signaling computation of this recognizer with a fixed polynomial clock $M^{O(1)}$ uses at least $M/2^{O(\sqrt{j\log(j+2)})}$ work bits in a standard tape configuration encoding. For a sparse word RAM one may count nonzero scratch words instead, absorbing a factor $O(j)$ in the denominator. The constants depend on the program and the clock. This applies separately to each verdict of every fixed polynomial-time deterministic SAT solver on the actual pair, including when the solver gets the pin and scale for free.
* There is an explicit family of wrong-pinned Horn 3-CNFs for this same computation with both a polynomial-size tree-like resolution proof and a polynomial-size width-three DAG proof. Under linear SAT, **any** tree-like resolution proof of the wrong pin using clauses of width $\operatorname{poly}(j)$ has at least $2^{\Omega(j^2/\log(j+2))}$ nodes, at every sufficiently large $j$. The conclusion also holds when the verifier may retain $M^{1-\epsilon}$ reusable such lemmas for any fixed $\epsilon>0$, provided each lemma's own derivation is checked and the size counts all materialized tree nodes.
* Without the linear-SAT hypothesis there is an alternative relevant to **all three** milestones. In a sound local system with $\operatorname{poly}(j)$-bit labels and polynomial-in-$j$ local checking, tree derivations with at most $M^{1/k}/(j+1)^B$ nodes, on infinitely many true scales of one color, exclude ordinary deterministic $O(n^k)$ SAT for $k=1,2,3$ and sufficiently large fixed $B$. Here the entire tree fits into a single existential check. The much larger tree-size threshold above uses the *linear* SAT hypothesis.

In these statements, a nondeterministic proof is guessed as it is read. A read-only tape holding an arbitrary two-way certificate would itself provide free persistent information. Its contents must be counted or checked for consistency to apply the simulation.

## Searching with both a time and a storage cap

Use the [uniform elimination of a growing number of quantifiers](linear-quantifiers.md). For a fixed nondeterministic tape computation with short explicit input length $p$, time cap $T$, and full configurations encodable in $S$ bits, put $L=\lceil\log_2(T+2)\rceil$, $A=p+S+L+2$, and $H=L+\lceil\log_2 A\rceil+2$. Under linear SAT the time to decide existence of a capped accepting computation is at most
$$
 A\,2^{C(\sqrt{L\log_2 H}+\log_2 H)} .
$$
The proof writes down evenly spaced checkpoints, universally selects a segment and recurses. The uniform near-linear overhead of each SAT-based quantifier elimination gives this bound even for a growing number of levels. It searches all nondeterministic choices. It does not simulate the prover that found one successful choice. Multilevel bounded-tree computation and verification have classical precedents. [Ruzzo](https://doi.org/10.1145/800135.804428) · [Fortnow, Lipton, van Melkebeek and Viglas](https://www.sciencedirect.com/science/article/pii/S0022000099916719)

For a polynomial stage clock, $L=O(j)$, $p=\operatorname{poly}(j)$, and $H=O(j)$ for workspace cap at most $M$. Use a cap $S=2^{j-\lceil D\sqrt{j\lceil\log_2(j+2)\rceil}\rceil}$ with sufficiently large fixed $D$ (round integer roots upward). The search now takes $o(M)$. If the cap admitted a signal infinitely often this would be a timely sound detector for the color, contrary to the priority construction. A normalized nondeterministic or deterministic RAM through $M^a$ steps uses $O(j)$ bits per address and value. On tapes keep a list of live address/value pairs, erase entries written to zero, and handle an indirect access by scanning the list. Through the stated clock this costs polynomial time and $O((W+1)j+\operatorname{poly}(j))$ bits for peak occupancy $W$. Generate requested input words from the metadata using the actual generator. Passing a full read-only formula of size $\Theta(Mj^3)$ as an explicit input to the capped search would destroy the saving. A native deterministic solver with unbounded overall runtime obeys the same statement on every signaling run which finishes by the selected polynomial cap.

For long proofs fix $\epsilon>0$. Take $S\le M^{1-\epsilon}$ and clocks up to $2^{\gamma j^2/\lceil\log_2(j+2)\rceil}$, increasing the clocks by a fixed polynomial factor in $M$ if necessary. Then $H=O(j^2)$ and the exponent added to $\log_2 A$ is at most $C'\sqrt{\gamma}\,j+o(j)$. A sufficiently small fixed $\gamma>0$ makes the deterministic capped search $o(M)$. The clock and cap descriptions have polynomially many bits in $j$. The same search works if the recognizer happens to use much more time or space on unsuccessful branches. Each of the four tests for the two promised pins and two possible verdicts is one fixed detector. Their finite union of exceptional scales is finite.

The polynomial-clock result has a qualitative extension to any SAT algorithm of time $n^{1+o(1)}$. Fix a space saving $S\le M^{1-\epsilon}$ and a clock $T=M^a$. Use a large *constant* number $r$ of waypoint levels with $2^{\lceil aj/r\rceil}$ segments per level. The initial quantified circuit has encoded size at most $(S+\operatorname{poly}(j))2^{aj/r}\operatorname{poly}(j)$. Choose $a/r<\epsilon/3$. At a fixed number of levels the $s^{1+o(1)}$ elimination overhead composes to $s^{1+o(1)}$. This again fits $o(M)$. Hence every polynomial-time solver requires $M^{1-o(1)}$ live storage on both pins in that hypothesis, and no fixed polynomial-size, polynomial-in-$j$ width derivations with $M^{1-\epsilon}$ live lemmas can certify the actual sign on infinitely many stages. If the SAT overhead is any fixed power of $\log n$ over linear time, the quantitative estimates above still hold: one elimination adds $O(\log(u+2))$ to the log size $u$, with a different constant. These variants place no workspace cap on the hypothesized SAT algorithm.

For unrestricted *length*, an implicit graph with state names of at most $s$ bits has simple witnessing paths of length below $2^{s+1}$ whenever it has a witnessing path. If adjacency (including any short existential edge label) is checkable in $\operatorname{poly}(s+j)$ local time, the same waypoint QBF has initial log size $O(\log(s+j)+k)$ for segments of fanout $2^k$. Its $O(1+s/k)$ eliminations cost total log time $O(\log(s+j)+\sqrt{s\log(s+j+2)})$ when $s\ge\log(j+2)$. The bit cost of the polynomial-size local adjacency circuit is included. Under linear SAT, the actual signed claim therefore has no such positive reachability certificate with state cap $s\le c_0 j^2/\log(j+2)$ on infinitely many correct stages, for a sufficiently small constant $c_0>0$. This also applies to resolution blackboard configurations with bounded total encoded content: a transition downloads a locally generated axiom, resolves two present lines or erases a line. Here $s$ counts the whole named configuration; it is not a lower bound of $j^2/\log j$ on the *number of clauses*.

## Replaying a proof tree with few pending obligations

Use a fixed local proof system in which one line has a binary label of length at most $b$, an axiom has a locally checkable witness, and a binary inference can be checked from the parent, the two children and local witness bits. For the application all these fields have length $\operatorname{poly}(j)$, and the checks have $\operatorname{poly}(j)$ time and space cost. An address into an implicit input-clause list is a permissible axiom witness. For a tree with $Z$ nodes, guess a root justification and traverse it depth first, guessing child labels and each rule at first use. Visit a smaller subtree first and keep the other root label pending. This ordering can be guessed. Whenever the stack gains a pending sibling that remains on it, the as-yet-followed subtree is at most half the size of the tree at that push. Thus at most $1+\lfloor\log_2(Z+1)\rfloor$ labels need be pending at once. A one-child step is a tail call. The checker enforces time and space caps and accepts only after discharging every obligation. Any accepting trace unfolds into a genuine finite proof, irrespective of the guessed visitation order.

In a variant first derive named, reusable lines one by one, referencing only lines already established. The checker may delete a stored line when desired. A single independent tree may then use any live line as an axiom. One can store the live dictionary between successive trees. With at most $K$ stored labels and total $Z$ visited nodes, the space is $(K+\log(Z+2)+1)\operatorname{poly}(j)$ bits when labels have polynomial-in-$j$ width and $\log Z=\operatorname{poly}(j)$. A sequential search through the dictionary costs at most a polynomial in $M$ per node for $K\le M$. The time clock stays $Z M^{O(1)}$. If $K\le M^{1-\epsilon}$ this fits the preceding long-proof search with, for instance, half the original space-exponent margin. The argument charges the space used by live shared lines and the time of *all* recomputations. A positive ordinary tree proof with $Z\le M$ can instead be named and verified in $Z\operatorname{poly}(j)$ nondeterministic RAM time without the smaller-first convention. Its bounded-run 3-CNF has at most $Z\operatorname{poly}(j)$ encoded bits. Under $O(n^k)$ SAT this explains the third assertion.

## An actual closed computation with separate short and narrow proofs

Use a uniform closed bounded-fanin Boolean circuit $C_j$ computing $b_j$. Here is one elementary locally accessible construction. Use the fixed $O(M)$-step deterministic priority program with a fixed word width $O(j)$. Unroll its steps. Keep one word for each possible writable address at each step, updating it through equality tests, and use balanced read multiplexers. The number of possible addresses is $2^{O(j)}$. All operations on words have uniform polynomial-in-$j$ circuits in the stated instruction model. Using regular padded tables for time, address, operation and bit, one gate and its input labels can be generated in $\operatorname{poly}(j)$ time. Virtual input words are zero. This circuit may be much larger than the native clock, but it has $m=M^{O(1)}$ gates and $\operatorname{poly}(j)$-bit locally readable identifiers. The local proof search never constructs the whole circuit.

Give each gate two atoms, one for each possible value. For each truth table row use the Horn implication from the corresponding predecessor atoms to the output atom; the clause has width at most three. Constant gates have their true fact. To express $b_j=c$ add the single negative unit forbidding the output rail $1-c$. This is an ordinary Horn 3-CNF (repeat literals as needed). All true gate rails are forced by forward induction. The assignment containing exactly these rails is closed under the rules. The pin is therefore satisfiable precisely at the correct sign. The construction permits spurious positive atoms, which never invalidate that characterization.

On the wrong pin there is a width-three DAG proof using $O(m)$ lines by deriving the actual rail at each gate from the already derived predecessor units and finally using the pin. There is also an $O(m)$-node tree search: query the actual rail at each gate in topological order; the value false immediately falsifies that gate's honest row, and the value true continues. At the last gate the negative unit is falsified on the continuing branch. This tree exists whether or not one can name the actual rail quickly. To extract a tree-like resolution proof, label each leaf by its falsified input clause. At a split, if both child clauses contain the appropriate opposite pivot, resolve them. If a child's clause already omits the pivot, keep that child's proof. Each resulting clause is falsified by the common prefix and the root clause is empty. Clauses on the long continuing branch can be wide. The local tree checker above certifies the opposite color by checking a refutation of this particular formula. It applies to either actual output.

Ben-Sasson proved unconditional size/width tradeoffs for specific Horn pebbling formulas, including examples with separate short and narrow proofs. The application here is to the rails of the *actual priority computation*, even when the verifier can reuse many lemmas. The natural DAG proof uses a large dictionary. The natural linear tree uses wide clauses; its existence alone gives no fast detector. Historical priority for the general tradeoff is not claimed. An actual family of refutations combining the displayed resource bounds on infinitely many stages would change the unrestricted linear SAT conclusion.
