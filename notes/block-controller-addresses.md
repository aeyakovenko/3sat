# Checking a chronological controller by the distinct addresses in short intervals

The sorted rank circuit in the [single-index decision-run test](one-index-solver-memory.md) can be eliminated when the real computation reuses work addresses within short time intervals. The total number of addresses retained between intervals can be arbitrarily large, subject only to the clock. The price in the short verifier is proportional, up to polynomial factors in the timestamp width, to the number of intervals times a per-interval address bound. This allows the bound to approach the entire interval length.

## Verification algorithm

Suppose a proposed chronological controller $G$ on $u$ time bits is given by a depth-$d$ ACC$[m]$ circuit of size $s$. Include the native gate-value annotations when required by the instruction set as in the single-index theorem. Let $T=2^u$. Check a specifically requested halt sign and all local controller and read-only input transitions. Take aligned blocks of $B=2^l$ rows for $l<u$. Suppose each block of the genuine history touches at most $D$ distinct writable addresses, where $1\le D\le B$. An address includes its bank tag and has $w=O(u)$ bits. The algorithm below accepts on some nondeterministic branch when this history is genuine. Every accepting branch verifies a genuine history even when the address promise fails.

Choose the least power of two $q$ greater than $2wD$. View the bits of an address $z$ as coefficients of a polynomial $P_z$ of degree less than $w$ in a field of size $q$. For each $\alpha$ in the field put $h_\alpha(z)=P_z(\alpha)$. For a particular address in a given block of at most $D$ distinct addresses, at most $(w-1)(D-1)$ points can collide with any of its competitors, since each nonzero difference polynomial has degree at most $w-1$. A uniform point isolates the given address with probability greater than $1/2$. Guess one common list of $u+1$ points. Some list isolates every address of every block at least once, by a union bound over at most $T$ block-address incidences. There is no random error in the verifier. For each fixed list member, every output bit of $h_\alpha$ is a fixed parity of address bits. A finite-field model and these coefficient masks can be built in $q^{O(1)}\operatorname{poly}(u)$ time. For instance find an irreducible polynomial of degree $\log_2 q$ by enumerating binary candidate polynomials and testing divisibility by all monic polynomials through half that degree. Existence of a field of each prime-power order ensures termination.

Fix a block index as the Boolean circuit input. Hardwire all $B$ possible low time suffixes to copies of $G$ to obtain all the rows of this block. Any event's next state, including one across the block boundary, is obtained by an additional query to $G$. Local defects at the final row are gated by the halt convention. A circuit checks **coverage** by requiring, for every active row $j$, some chosen $\alpha$ for which all active rows with hash $h_\alpha(z_j)$ have address $z_j$. This has fixed depth including the parity layer. Also compute a flag for any bad local controller/input transition in the block. For each chosen $\alpha$ and each of its $q$ buckets, construct output circuits for the following summary.

* An empty bucket, or one containing two distinct addresses, is marked absent. An isolated bucket reports its address. A block can report the same address under several hashes.
* For an isolated bucket, require all loads preceding its first store to report one common incoming value if there are any such loads. Output this requirement and value. For each other load, require the value of its last earlier store. Flag any disagreement. Output the value of the last store if there is one.

These circuits have depth bounded in terms of $d$ and fixed decoder depth alone. Inside one bucket a first store, a last store, or an intervening store is a finite unbounded AND/OR over hardwired row slots and a proposed ordered pair. The comparisons and selection of a representative or an output word use boundedly many such layers, with polynomial size in $B,s,u$. Batched memory reports may also be checked by comparing each consecutive pair inside the isolated bucket, treating loads as carrying their reported value forward. A collision is tested against actual distinct addresses and a coverage failure always rejects. Lean verifies that the entire chronological projection onto an isolated bucket equals the projection onto its true address, that the proposed two-word effect agrees with direct execution for every incoming value, and that the effects compose across blocks. [Finite block semantics](../lean/BlockAddressCertificates.lean)

Compute the complete truth table of each of these circuits on the $u-l$ free block-index bits. There are $O(uq w)+O(1)$ output bits per block. Deduplicate the isolated summaries within each block by the reported true address. Coverage ensures each touched address gets exactly one summary after deduplication. Local consistency has checked every load after a store. Traverse blocks in chronological order using an initially empty dictionary of actual last-written words, with default zero. Compare each required incoming value against its dictionary entry and then apply the optional last-write update for each address. Duplicates must be removed before these updates. Induction across the blocks proves all work loads correct. Together with the native local checks this establishes soundness. The isolating-list argument supplies the genuine summaries for completeness. A tree dictionary or offline sorting of records ordered by address and then block index incurs a factor polynomial in $u$ per summary.

For fixed $d,m$ and fixed transition and input decoders there is a fixed $C$ such that each output circuit can be transformed to a SYM-of-ANDs representation in time and size $2^{O((\log((B+2)(s+2)(u+2)))^C)}$. The fixed verifier modulus can be a multiple of $2,3,m$. When the transformed size is $2^{o(u-l)}$, Williams's truth-table evaluation costs $(2^{u-l}+\operatorname{poly}(\text{transformed size}))\operatorname{poly}(u)$ for each output bit. Charging the circuit construction, copying, every output, and dictionary operations gives a nondeterministic time bound
$$
D\operatorname{poly}(u)\left(\frac{T}{B}+2^{O((\log((B+2)(s+2)(u+2)))^C)}\right).
$$
Enlarge $C$ or the constant as needed to pay the field setup, and use $q=O(wD)$. The use of the full truth-table algorithm matters. Evaluating $G$ separately at every time within every block would consume the intended saving. [Williams, Lemmas 4.1 and 4.2](https://people.csail.mit.edu/rrw/acc-lbs-journal-final.pdf)

## Omitting addresses initialized before local use

Call a load *incoming* if there is no earlier store to its address in its block. Guess a Boolean circuit $F(z)$ on the bank and address bits. It has fixed depth and modulus and at most $s$ gates, and the same $F$ is used in all blocks. It may depend on this input and run. Suppose $F$ contains the address of every actual incoming load, meaning $F(z)=1$ there. It may contain other addresses too. The preceding bound holds whenever each block touches at most $D$ distinct addresses with $F(z)=1$. A block may additionally write to arbitrarily many other addresses up to its instruction count, and may load from them after a matching local store.

To check this, use a copy of $F$ at each hardwired row of the block. Keep all native transition checks. For every load at a row $j$ with $F(z_j)=0$, require a store at some earlier row $i$ of the same block with address $z_j$ and with the reported load value. Require also that no row strictly between $i$ and $j$ stores to $z_j$. An OR over $i<j$ and an AND over their intervening slots implement this test in fixed depth and size polynomial in $B,s,u$. Use only rows with $F(z)=1$ for the hash collisions, coverage requirements, effects and dictionary. The global dictionary now checks the chronological subsequence on the retained addresses. Every access to each retained address belongs to that subsequence because $F$ is a single function of the address. Every load outside it has already been checked against its latest local store. Induction in native time gives soundness even for a dishonest filter. For completeness, any filter meeting the two stated conditions on a genuine run passes the local tests, and some common hash list isolates all retained addresses.

Guessing and composing $F$ fits in the same displayed cost, allowing $C$ to depend on its fixed depth and modulus too. The extra local failures contribute just one output bit per block, and the hash field size and the number of summary bits still depend on $D$. Separate unrelated filters per block would lose the dictionary invariant. For example, a store omitted in one block could then precede a retained load of the same address in the next block.

## Consequences on genuine SAT decision runs

Use the same bounded-signaling interpreter and explicit formula decoder as in the [single-index theorem](one-index-solver-memory.md), with the program on its self-input now guessing $G$ and the common hash list. Fix rational $0<a<b<1$ sufficiently small that $bC<1$. On input length $k$ take $u=k+\lfloor k^a\rfloor$, $s=2^{\lfloor k^a\rfloor}$, $l=\lfloor k^b\rfloor$, and $B=2^l$. Choose $D=2^{l-2\lfloor k^a\rfloor}$ for all sufficiently large $k$. The transform and its construction cost $2^{o(k)}$ even after multiplication by $D\operatorname{poly}(k)$. The first term costs $2^{k-\lfloor k^a\rfloor}\operatorname{poly}(k)$. All fixed polylogarithmic costs of universal tape simulation fit within $o(2^k)$. Consequently, for **any** correct ordinary decision solver and every sufficiently large source length, its particular unsatisfiable formula has at least one property below.

1. The solver has yet to halt at $T-1$.
2. Its actual idled chronological controller exceeds the stated depth-$d$ ACC$[m]$ size bound.
3. Some aligned block of $B$ steps touches more than $B/2^{2\lfloor k^a\rfloor}$ distinct work addresses.

Using the filter verifier strengthens the third alternative on its diagonal family. For **every** allowed $F$ containing the addresses of all actual incoming loads, some block touches more than $D$ distinct addresses with $F(z)=1$. The particular block may depend on $F$. The constant-one filter recovers the unfiltered conclusion on the same family. The strengthened statement ignores a stream of fresh writes into a recognizable scratch bank if every load from that bank follows a local store. It still charges any address used by a later block before local initialization. The same quantifier applies to the closer-to-linear parameter choice below.

The same source can enforce this disjunction and the earlier one using sorted ranks: let its verifier guess which sound rejection test to perform and decrease $a,b$ to meet both clock inequalities. The formulas in both conclusions then coincide. A test requiring that all $T$ timestamps are described alone supplies no universal bound on the number of addresses per block.

There is a closer-to-linear variant. For a fixed $e\ge0$ take $u=k+\lceil e\log_2(k+2)\rceil$, keeping $s$ and $B$ as above. Set $D=\lfloor B/k^J\rfloor$. The verification costs $2^k k^{e-J+O(1)}+2^{o(k)}$, including the fixed simulation losses. For a sufficiently large fixed integer $J$ it meets the bounded clock. This gives the same three alternatives with address threshold $\lfloor B/k^J\rfloor$. If a solver has global running time $O(N\log^c N)$ on this encoding, one can choose $e$ so the first alternative is impossible. The exponent of the clause-count overhead is fixed by the universal source, independently of the fixed program description placed in the padding. A RAM can stream a fresh address on each step, and a short description of the program does not imply a small circuit for its state at a binary time. Neither remaining alternative gives an elapsed-time lower bound. Earlier phase tests used interval geometry, address-order maps or pairwise tests for specific visit patterns. Here addresses from different blocks may be arbitrarily interleaved. The basic test guesses the chronological circuit and hash points, and the filtered version additionally guesses the address filter. Priority of this application of isolating hashes and batched ACC evaluation is unverified. [Earlier phase tests](phase-histories.md) · [Earlier address-order results](address-orders.md)

The finite audit checked 103,308 block verifications against direct RAM memory, including insufficient hash lists, repeated reports, and a three-address example in which every tested hash collides but each address is isolated somewhere. It checked all 1,679,616 pairs of a four-row log and a tentative rank function in the single-index test. Of the 6,561 logs, precisely the 2,401 genuine ones pass with their unique sorted rank function. [Executable audit](../audits/one_index_memory_audit.py)

A separate finite check of the filter rule enumerated four-row logs with a dummy instruction or a load or store of either bit at either of two addresses. For each of the $9^4$ logs it tested all four filters and block widths $1,2,4$. Direct simulation and coverage of all incoming loads agreed with the conjunction of retained-address simulation and excluded-address local-store checks in all 78,732 cases. Exactly 18,702 cases passed. The linked Lean proof covers the underlying address projections and block effects. The filter extension and its asymptotic cost are manuscript proofs.
