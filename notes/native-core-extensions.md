# A linear-time SAT solver on extensions of native computation formulas

Can extra SAT queries about an actual solver's computation on the calibrated family force that solver to reveal the hidden word more cheaply? There is a class of queries broad enough to constrain any internal tableau bit, admit fresh existential witnesses, and hide the positions of the original clauses, on which a globally correct solver can always use direct native replay. A one-literal change to an augmented template shows exactly where the argument using unique extension can fail.

## A recognizable core with a computable unique model

Let $B_j$ be the *unpinned* parsimonious encoding of the fixed, total deterministic stage program from the [calibration construction](learning-from-earlier-sat-verdicts.md). Assert validity of the computation and expose its output. Omit the predicate testing an external label. There is exactly one assignment $v_j$ to the entire declared variable set. Run the native program once, retain the complete chronological row values, then evaluate the deterministic sorting and verification circuit in topological order. This produces the values of *every* gate variable. The work is $O(2^j+s_j)$ when $s_j$ is the number of constant-size template records, including the gates and their clauses. This uses the [deterministic sorting version](projected-parity-holes.md#a-parsimonious-ordinary-3-cnf-near-the-native-clock). A permutation router with freely chosen switch settings would lose the uniqueness used here. Even without using a direct-address table for the guest, the host can record reads and writes with a balanced dictionary in $O(2^j(j+1))$ work. Choose $d\ge1$ large enough in the layout below so this bound fits in $O(s_j)$.

Use the following explicit regular layout to obtain the linear clock below. Number the actual variables densely and choose $s_j=\Theta(2^j(j+1)^d)$ clause records for one fixed sufficiently large integer $d$. Harmless repeated fixed clauses can fill the difference. Use nested counters for the stage of the bitonic sorting network, wire and local Boolean gate. At a given layer the partner wire is the wire index XOR a precomputed power of two. Comparator direction is a single mask bit. The table of $\operatorname{poly}(j)$ within-record template offsets identifies all local fan-ins and clause signs. Row transitions go to the same or adjacent row, and network fan-ins go to the same or partner wire in the previous layer. Fixed row blocks, layer base offsets and any tails can consequently be generated in $O(1)$ operations per emitted record after $\operatorname{poly}(j)$ setup. Precompute the local gate tables once per scale, including the $O(j^2)$ layer descriptors. All identifiers fit in $O(j)$ bits. Fix the public dense variable names and all padding *before* compiling any label. Include one shared forced-zero reserve of three bits, enforced by the seven clauses forbidding the seven nonzero patterns. Fill short gate clauses using distinct reserve bits as needed, after simplifying tautologies and repeated literals. Repetition of complete valid core clauses fills the prescribed core slots. Append the label’s signed pins and deterministic predicate gates using fresh dense names, with the core names, reserve, and full core clause multiset identical across the stage. The original metadata generator can address this layout in polynomial time in $j$ without running the native program. This specifies one realization of the calibrated construction. The shuffled-extension linear bound is asserted for these exact names and records. Earlier archived encodings require their own membership and timing check. If only the older abstract $\operatorname{poly}(j)$-per-word generator is specified, the direct scan gives a polylogarithmically weaker bound. The linear estimate uses this explicit layout. [Single-row table technique](packed-band-transfer.md#a-virtual-formula-for-a-bounded-computation)

Consider ordinary fixed-width binary 3-CNFs $F$ of $N$ encoded bits with $C$ clauses, literal identifier width $w=O(\log(N+2))$, and $Cw=O(N)$. Permit arbitrary clause and literal orders. Call the following test successful at scale $j$ if

1. Every clause of $B_j$ occurs in $F$, with multiplicity at least that in the template, using its public variable identifiers.
2. Upon substituting $v_j$ and performing unit propagation, the residual contains a contradiction or has width at most two.

There is one deterministic globally correct SAT solver spending $O(N)$ word-RAM time on **every** formula passing this test, without receiving the scale or an embedding hint. It returns the correct verdict on a matching core because every model of the whole formula restricts to $v_j$. Conversely every satisfying assignment of the restricted residual extends that core. If propagation leaves width two, use the implication graph and strongly connected components. This is the standard linear-time 2-SAT algorithm. The same subsolver succeeds if no fresh variables occur, if every extra 3-clause touches an old variable, or if fresh variables compute an acyclic AND/OR/NOT circuit on known tableau bits using full gate equivalences followed by pins. In the last case unit propagation can evaluate one gate after another. Fresh isolated variables in declared headers have no effect on the verdict. The literature on SAT backdoors also exploits restrictions yielding tractable residual formulas. Here the whole old assignment is forced and can be constructed by native replay. [Aspvall, Plass and Tarjan](https://mathweb.ucsd.edu/~sbuss/CourseWeb/Math268_2007WS/2SAT.pdf) · [Williams, Gomes and Selman](https://ijcai.org/proceedings/2003/167)

For the time bound, normalize each signed triple by sorting its three words. Put the triples in lexicographic order by binary radix passes on their $3(w+1)$ bits, in $O(C(w+1))$ work. Group duplicates and retain counts. Also compress the fresh names once to dense graph indices by radix grouping all literal occurrences while keeping their input positions. Enumerate the scales with $s_j\le C$ and variable names fitting in $w$ bits. There are $O(w+1)$ scales, since the core contains at least $2^j$ different variable names. Their total $s_j$ is $O(C)$ by the two-sided regular size bound and geometric summation. Size setup over $j\le O(\log(N+2))$ costs $\operatorname{polylog}(N)=O(N)$. For the membership check, group equal template triples and compare their multiplicities with the sorted input dictionary. Sorting a single template by radix takes $O((w+1)s_j)$ and binary search needs $O(w+1)$ comparisons per distinct triple because there are at most $2^{3(w+1)}$ different triples. The total of these costs is $O(N)$. For each candidate that matches, reconstruct $v_j$, index old values by the original dense core names, and scan all $C$ clauses. Unit propagation uses literal occurrence lists and per-clause counters, so the total work per candidate is $O(C+s_j)$ including the implication graph on the occurring names. Summed over candidates this is $O(N)$. If all tests fail, invoke any ordinary SAT solver. A globally fast fallback, if one exists, retains its $O(N^k)$ worst-case bound for $k\ge1$. Inputs with other encodings can go directly to the fallback.

In particular, a query can ask about a conjunction of conditions on all times of the native computation, and it can involve an unbounded number of fresh 2-SAT variables. Clause and literal shuffling, clause duplication, and these added constraints do not by themselves force superlinear time on the resulting physical inputs. The solver performs one charged native replay per successful test and can record all values. This construction improves the scope of the [older two-pin recognizer](priority-pinned-sat.md). It does not accelerate native replay to the rooted clock. An argument which also uses the solver's behavior on auxiliary existence formulas outside this class still has a possible premise to exploit.

## How many independent fresh 3-clauses survive?

The replay also gives a quantitative test at each target exponent $k=1,2,3$. At a matching core, discard tautologies and repeated literals, apply the forced assignment and unit propagation, and form a greedy maximal family of variable-disjoint surviving clauses of width exactly three. Write $q$ for its cardinality. Each selected clause permits seven assignments to its three different variables. Enumerate all $7^q$ combinations. Every surviving width-three clause meets a selected variable by maximality, so restricting a combination leaves a 2-CNF. Return yes exactly when some residual 2-CNF is satisfiable. A depth-first enumeration with a linear scan and 2-SAT test per leaf costs $O(7^q(C+s_j))$ time for that candidate. The case $q=0$ recovers the preceding test.

A single globally correct solver at index $k$ runs this procedure only when $7^q\le N^{k-1}$, testing the integer inequality by capped multiplication. Its total recognition and search work before fallback is $O(N^k)$, including every candidate scale. Its running time on every extension satisfying this test at some matching scale is therefore $O(N^k)$ regardless of the fallback's cost. The result allows unboundedly many residual width-three clauses sharing a small set of variables. At the quadratic and cubic clocks a construction using such extended cores must escape even these logarithmic packing thresholds to force larger time on every correct solver.

## One literal can release an entire bank of existential choices

Adjoin to the native core a variable $z$, a bank of $K=2^{2j}$ variables $u_i$, a pin $\neg z$, and clauses $z\lor\neg u_i$. The gadget has the unique extension $z=u_1=\cdots=u_K=0$. The fixed padded layout for this augmented family has geometric growth as well. Each new variable is an old core variable when extensions are tested. Encode the short pin and bank clauses at exact width three using fixed distinct false variables. For example, seven clauses on three reserve bits forbid every assignment to them except $000$. Keep that gadget disjoint from $z,u_i$.

Let $G$ be any ordinary 3-CNF on at most $K$ bank bits. Add its clauses to the augmented core. With the pin intact the verdict equals $G(0^K)$. Flip the single sign of the pin to $z$. The resulting verdict equals $\exists u\,G(u)$, since at $z=1$ every bank assignment is legal and the underlying native core has a model. Simply deleting the pin gives the same latter verdict. Thus the paired queries can have identical headers and identical clauses except for **one physical sign bit**, while the changed side encodes arbitrary 3-SAT.

For a fine-grained size check, start with ordinary nonempty 3-CNF on $v$ dense, occurring variables with fixed-width names. Choose the smallest $j\ge1$ with $K=2^{2j}\ge v$, giving $K=O(v+1)$ and the unaugmented core $O(\sqrt{v+1}\,\operatorname{polylog}(v+2))=O(v+1)$ records. Copy $G$ with the bank-name shift, and append the core and bank. The new name width is $O(\log(v+2))$ because all names are dense. Every variable occurs in $G$, so its clause count is at least $v/3$. The total encoded length and reduction time are linear in the original encoded length. Consequently an $O(N^k)$ decider for all these sign-flipped presentations would give an $O(n^k)$ decider for dense fixed-width 3-SAT, for each $k\ge1$. The reduction keeps the native stage growing with $v$. Its released bank is deliberately added to the core. No claim about the sensitivity of the unmodified native CPU circuit follows.
