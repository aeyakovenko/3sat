# A verdict-flipping DIMACS word with the same native shift count

Use the marked positive physical word $A$ in the first-address-producer construction at byte-aligned native width $w$. It terminates one repeated clause with the bytes for `d 1 0` and newline near its low end, then has a long run of spaces, and ends at its high byte with ASCII digit `4` starting the next clause. The fixed prefix forces $x_4$ true while $x_5$, $x_1$ and $x_d$ are false. At every sufficiently large width there is a word $B$ of the same byte length such that

$$
                      B\equiv A\pmod w.
$$

Replacing any nonempty subset of the homogeneous records by $B$ reverses the ordinary proper DIMACS verdict. The upper byte of $B$ is the digit `5`; remaining changes are entirely whitespace between two clauses. On the same positive file the original alternative that changes just the high digit is still a one-bit pivotal edit. The lower bound using the congruence can use several changed bytes per word. ## Filling all odd residues with ordinary whitespace

Write $w=2^s q$ with odd $q$ and $W=w/8$. Byte alignment implies $q\le W$. Starting with the single-digit alternative, allow selected space bytes in its long interval between the newline and the final digit to be ASCII tab (9), line feed (10), or space (32). Work only at byte positions $i\ge\lceil\log_{256} w\rceil$, numbering from zero at the low end. The high digit change and every adjustable-byte difference are divisible by $2^s$. There are $W-O(\log w)$ adjustable bytes; the fixed low clause content uses $O(\log w)$ positions. Each adjustable byte adds $256^i\{9,10,32\}$ to the available residue sums modulo $q$, up to a fixed translation.

For $q>23$, the three residues are distinct. The difference between the first two is a unit modulo $q$. For any nonempty residue set $S$, adding one such three-element set gives at least $\min(q,|S|+2)$ residues. Subtract its first element and multiply by the inverse of that unit, obtaining shifts $\{0,1,u\}$ of a rotated and rescaled copy of $S$, with $u\notin\{0,1\}$. If $S$ is proper and has at least two maximal cyclic runs, shifting it by one exposes at least two new residues. If $S$ has just one run, $S\cup(S+1)$ is an interval of length $|S|+1$. When this is still proper, the only translates of a cyclic interval of length $|S|$ contained in that interval are its initial and final segments. They have offsets zero and one. Thus $S+u$ adds at least one further residue. This proves the estimate over composite as well as prime $q$.

After $\lceil(q-1)/2\rceil$ adjustable bytes every odd residue is available. The number $W-O(\log w)$ exceeds that many for all sufficiently large $w$, as $q\le W$. For $1<q\le23$, the choices 9 and 10 alone add at least one residue at each byte until all $q$ are available; for $q=1$ no correction is needed. Choose the residue that restores $A\bmod q$. Together with agreement modulo $2^s$, this gives the claimed congruence modulo $w$. The replacement also remains a positive, large native word, so full shifts saturate on both raw count values.

An explicit algorithm keeps a Boolean array indexed by residues modulo $q$. Start with difference zero and for each adjustable byte use the possible increments $0$, $-23\cdot256^i$ and $-22\cdot256^i$. First-discovery predecessor pointers recover the actual chosen bytes. A length-$q$ snapshot before each update prevents reusing a byte. This requires $O(Wq)$ word operations and polynomial space in $w$; the selected word can be used at every marked address. All inserted newlines lie after a clause terminator and before the first digit of the next clause. Header, clause count and all token boundaries are preserved. At congruent counts every modulo shift or rotation with an edited raw word solely as the count returns its old value. The other generic small-address estimates in the first-producer argument concern the base value $A$ alone. In particular the possible small bitwise-AND results for any partner are globally sparse because every ASCII byte of $A$ has high bit zero. Agreement of every low address bit on $A,B$ is unnecessary for this application.
