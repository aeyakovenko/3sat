# Circuit cost of a batch of read-only word lookups

Take $m=2^w$. A table contains $m$ words of $w$ bits. The input supplies $m$ addresses $I_j$ of $w$ bits and $m$ claimed replies $Y_j$. Consider the one-output Boolean predicate
$$
 G_w(X,I,Y)=\prod_{j=1}^m [X_{I_j}=Y_j].
$$
Addresses may repeat, and all queries are available before any reply. For some $\sigma>0$ every bounded-fan-in Boolean circuit for $G_w$ has size $\Omega(mw^{1+\sigma})$ for all sufficiently large $w$. The same lower bound holds for the circuit that outputs all the replies and for a trivalent binary-wire network realizing their exact graph over a fixed finite field, with a field-dependent exponent allowed. Across this batch the lower bound per word lookup is $\Omega(w^{1+\sigma})$. A RAM reads its table without writing, verifies all the replies with a constant number of word registers, and takes $O(m)$ steps. The journal already derived the full-word sorted lookup identity inside a spanning-tree verifier. Here the indexed-order check bounds how many times any row is read, an inverse table gives a second reduction, and splitting the replies locates a range of subword widths with superlinear cost. ## A single accepting order

First take a table $K$ of $m$ keys of $2w$ bits each. Let $H(K,I)$ test
$$
 K_{I_1}<K_{I_2}<\cdots<K_{I_m}.
$$
An accepting sequence reads distinct *values*, so it also uses $m$ distinct addresses and covers the whole table. If a key is repeated no order passes. If all keys are distinct, their strict sorted order specifies exactly one passing sequence of indices. In particular
$$
 \sum_{I\in[m]^m} H(K,I)=\operatorname{DISTINCT}(K)
$$
over the integers and every field. There is no promise on the indices supplied to $H$. Lean checks this as a cardinality identity and derives coverage of every table index from the implemented adjacent-order check. [UniqueIndexOrder.lean](../lean/UniqueIndexOrder.lean)

Apply OpenAI's exact list lower bound over a fixed finite field to the right side. A network for $H$ would yield the left side by attaching a unary all-ones tensor to every address bit at cost $O(mw)$. Hence $H$ itself needs $\Omega(mw^{1+\sigma})$ volume. Converting a Boolean circuit with $s$ bounded-fan-in gates to a network costs $O(s+mw)$ including explicit copying and the output pin. The circuit lower bound for $H$ follows. A RAM can test the chain with a counter, previous key and a constant number of temporary registers. If it stops at the first failed comparison, at most one table address appears twice and no table address appears three times. All inspected address-list entries are read in order. By choosing the largest complete layout that fits and ignoring trailing padding, one obtains a single uniform language at every sufficiently large bit length $B$ with $O(B/\log B)$ decision time, $O(1)$ writable words, and $\Omega(B(\log B)^\sigma)$ Boolean circuit size. Consecutive complete lengths have bounded ratio. A packed input can use shifts and a constant number of adjoining-word reads per field. The visit count in this paragraph counts logical table-word lookups. Split each $K_i$ into two $w$-bit halves. Sum over $m$ guessed $2w$-bit replies. Check their adjacent strict order with $O(mw)$ gates. Check each half against the table with a copy of $G_w$, sharing the requested addresses using explicit copy trees. On fixed $K,I$ there is exactly one sequence of genuine replies, even when addresses repeat. The contraction gives $H$ exactly. This proves the lower bound for $G_w$. Computing the replies by a Boolean circuit would give a circuit for the predicate by comparing them with $Y$ in $O(mw)$ extra gates. Conversely the exact graph tensor has the same entries when the claimed values are designated output legs.

The preprint already proves a closely related lower bound for *tagged permutations*. It verifies that requested (address, payload) pairs permute the tagged rows of the input. Its predicate also checks that every address occurs once. There is a second short reduction from this source to two copies of the total lookup predicate. For indices numbered $0$ through $m-1$, sum
$$
 G_w(X,I,Y)\;G_w(J,I,(0,1,\ldots,m-1))
$$
over all hidden tables $J$. A repeated address would have to store two different row numbers. With a permutation of addresses there is exactly one $J$, its inverse. This independently explains why the additional permutation requirement can be removed from the source. Both proofs count all Boolean inputs to the resulting lookup predicate. Priority for the lookup corollary is unestablished. ## Upper bound and narrower payloads

For an upper bound on the graph predicate, sort the $2m$ tagged table and query records by address, breaking ties by putting the table record first. Every address has precisely one table record. Within each address group require adjacent payloads to agree. This gives a Boolean circuit of $O(mw^2)$ gates using $O(mw)$ comparators on $O(w)$ bits. For the multi-output operation, propagate the most recent table payload in sorted order along equal-address runs, then use the stored comparison bits to run the swaps backwards. Unrestricted depth is allowed. The gate and exact-network costs per lookup thus lie between $\Omega(w^{1+\sigma})$ and $O(w^2)$ for this batch. The bounds concern shared circuits over the whole batch. They do not assign a fixed cost to each individual access. [Ajtai, Komlós and Szemerédi, sorting network](https://www.researchwithrutgers.org/en/publications/sorting-in-c-log-n-parallel-steps/)

For $1\le b\le w$, replace each word-wide check with $k=\lceil w/b\rceil$ parallel checks on $b$-bit payloads and the same $w$-bit addresses. Charge $O(kmw)$ for the address copies and all exterior legs. If $b/w^{1-\sigma}\to\infty$, this is $o(mw^{1+\sigma})$ and the size of one narrow check must be $\Omega(mb w^\sigma)$. For example $b=\lceil w^{1-\sigma/2}\rceil$ suffices for a superlinear bound relative to the $\Theta(mw)$-bit input (take $0<\sigma\le1$). This calculation leaves the single-bit payload case open at the balanced query count. Holmgren and Rothblum study that bit multiselection problem and give linear-size circuits for sufficiently few queries. [Holmgren and Rothblum, CCC 2024](https://doi.org/10.4230/LIPIcs.CCC.2024.11)

There is also a direct relation at payload width one. Given $m$ addresses, constrain every reply from a hidden $m$-bit table to be zero. Sum over its cells with unary weights $+1$ for zero and $-1$ for one. Each addressed cell is forced to zero. Each unaddressed cell contributes $1-1=0$. The result is the indicator that the addresses form a permutation, over every field. This reduces *uncolored* permutation checking to a single one-bit lookup predicate. The upstream tagged lower bound also requires checking word payloads. On the SAT side, pin the $m$ table variables by $m$ unit clauses and supply one claimed-bit unit per query at its address. These dense formulas have zero or one assignment on all declared variables. Their length in a fixed-width binary encoding is $\Theta(mw)$. A superlinear lower bound for the one-bit lookup **decision predicate** at this scale would give the same bound on this fully pinned SAT promise. The narrow-payload estimate above falls short at $b=1$.

The RAM used for this circuit lower bound spends constant time per word lookup. To obtain a superlinear SAT time lower bound from circuits or networks one still needs a bound exceeding the cost of simulating a whole candidate RAM computation.
