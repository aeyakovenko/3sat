# Clique minors in the memory transfers of a hypothetical fast SAT solver

**Research journal, 24 November 2026.** Assume a fixed deterministic packed-word RAM $A$ solves ordinary SAT on $N$ encoded bits in $O(N\log^a N)$ time for fixed $a\ge0$, with arbitrary workspace. There is a family of unsatisfiable formulas, one for every sufficiently large source padding length, on which the following holds. Fix $0<\pi<1$ and $P=\lceil N^\pi\rceil$. Partition the computation into $P$ chronological blocks of at most $b=N^{1-\pi+o(1)}$ steps each. One may idle at the rejecting halt up to a fixed valid worst-case clock and partition that padded run evenly.

At the first read of a writable address in each block before any local write, draw an edge from its most recent earlier writing block, if any. Merge parallel edges between the same two blocks. The resulting undirected graph has **pathwidth larger than $P^{1-\delta}$** for each fixed $\delta>0$, on all sufficiently large members of the family. It contains a **$K_{\lfloor P^{1/2-\delta}\rfloor}$ minor** for every fixed $0<\delta<1/2$. These conclusions hold simultaneously for the eligible partitions, including boundaries chosen after seeing the execution. The native graph with chronological edges and a last-write edge for each read contains this block graph as a minor by contracting each connected chronological block and deleting surplus edges. Taking $\pi$ arbitrarily close to one gives a clique minor of order at least $N^{1/2-\epsilon}$ for each fixed $0<\epsilon<1/2$ in that native graph. Adding a padded path of idle instructions does not increase a clique minor of order at least three.

The same conclusions hold after supplying any chosen collection of at most $N^\theta$ genuine incoming words explicitly, for fixed $0\le\theta<1$, removing each covered read from the edge definition. One may also use a deterministic policy that either supplies a word or abstains, with all supplied answers correct on the genuine trajectory. Its program, parameters and any shared advice are contained in $N^{\theta+o(1)}$ public bits; it uses at most $N^{\theta+o(1)}$ temporary bits and polynomial time per call on a multitape verifier. The policy may read the formula, current native registers, address, time and the strict prior local log. A universal, clocked policy interpreter can support all fixed polynomial clocks, with the polynomial exponent fixed for a family or supplied as a fixed integer. Fixed polynomial resource cutoffs can instead be used throughout. On malformed data or a timeout the interpreted policy abstains. Its supply decision is part of the algorithm. Removing all correct outputs of an arbitrary fallible predictor could require an unaccounted list of which calls are correct. If other uncovered reads still induce the same block pair, the edge remains.

There is a separate **unconditional** consequence for every deterministic sound UNSAT recognizer that signals on every unsatisfiable input. On such an input let $E$ be its time to the signal and $h_A$ its largest clique-minor order in the native chronology-plus-last-write graph up to that signal. The worst-case product $(1+E)(1+h_A)$ on unsatisfiable inputs cannot be $O(N^{1.0001})$. In particular, restricting all these native graphs to a fixed excluded clique minor rules out $O(N^{1.0001})$ time without a separate workspace restriction. The constant-depth calculation below gives this weaker exponent without a near-linear SAT assumption.

## Reconstructing a block using possible producers

Guess the cuts and controller at each boundary. Give every block $i$ a set of earlier candidate producers $G_i$. On a first incoming read in block $i$, first consult the policy or explicit exception table. If neither supplies an answer, use the last word written at that address by the **chronologically latest** member of $G_i$ that wrote it, or zero if no such member exists. Stores and repeated reads use the block's own overlay and cache. Immutable formula reads are genuine. Induction on the chronological block index defines a unique native log at every block for any well-formed guesses, even if a guessed controller disagrees with its predecessor. On honest inputs this reconstructs the real logs whenever the candidate sets contain the genuine producers of all uncovered reads. Adding earlier candidate blocks cannot hurt completeness.

A tentative log includes one source ID per uncovered incoming address, with zero for initialization. Check its local instructions, controller, addresses, policy, cached replies and stores. Require any claimed source to belong to $G_i$ or be zero, and require zero value for the initialization case. For each $j\in G_i$ there is **one pairwise check** with its candidate log. If an incoming read claims $j$, its word must equal the last write by $j$ to that address, which must exist. If a read's proposed source is earlier than $j$ (including zero), $j$ must have no write to that address. A single pair check can scan the complete two logs and test all their relevant entries with polynomial time and $O(b\log N)$ scratch bits on tapes. These obligations force exactly the canonical log of $i$ once the candidate predecessor logs are canonical. In particular a block with a thousand candidate sources can compare them at different times without holding all their logs simultaneously. Lean checks the last-write value from these pairwise conditions, preservation under candidate supersets, intersection at the later introduction, and consistency of repeated occurrences. ## A path decomposition costs two indices per block

A path decomposition represents each block by an interval of bag positions. At most $k$ intervals are live at once, and every graph edge has overlapping intervals. Alphabetize the starts and ends within each original bag, processing all its starts before its ends, to obtain distinct event positions in $\{1,\ldots,2P\}$. This preserves overlaps and the width. Guess these two indices per block. Take as $G_i$ **all** earlier blocks whose intervals intersect block $i$'s interval. This interval supergraph automatically contains every edge covered by the layout. Its entire public representation uses $O(P\log N)$ bits even when a block has degree of order $P$. No graph matrix or path-decomposition algorithm is needed.

A bounded nondeterministic tape verifier processes the listed introductions and forgettings in event order. Validate the directory (repeated scans of the read-only input suffice) and enforce the live-record cap. At an introduction guess the whole block log, check it locally, and compare it with each live block with which it forms a candidate pair. At a forgetting discard its record. Every intersecting pair is checked exactly once. The resulting global assignment, if accepted, equals the canonical logs by the chronological induction above. The canonical assignment always passes these pairwise checks, since it uses the chosen candidate sets by definition. Consequently this procedure can test any specified local property of a canonical block, including its truth or falsity. It can compare a constant number of specified local results by recording the bounded requested fields. Validate the layout and its live-record bound, then derive actual tape space and time caps from the fixed algorithm, gap, overlap, and the policy interpreter’s own enforced bounds; every canonical property query can finish within those caps. All scans and checks cost polynomial time in $N$, even if their order differs greatly from the order of native instructions. The work tape uses $O((k+1)(b+1)\log N)$ bits plus the policy scratch, polylogarithmic bookkeeping and a constant number of row buffers. Computing true formula symbols from the short source only uses polylogarithmic scratch and polynomial time here.

The final verifier needs genuine memory even if a guessed layout omits a real dependency. It tests initialization, adjacent controllers and the terminal signal, and tests for any incoming read whose returned word disagrees with the chronologically last actual write in the concatenation of *canonical* logs. Guess a relevant read, address, and earlier source block with a different last written value, or choose zero initialization and a nonzero read. Require that no intervening block writes that address. Such an intervening write is an existential query for one block property. This includes policy-supplied answers. If these tests find no defect, the native instructions, controllers and all returned words form the actual rejecting run, by induction from the beginning. The absence of a defect proves UNSAT for any guessed interval layout. [All-address consistency using queries on canonical blocks](live-segment-snapshot-queries.md)

## Shortening a small-space verification under the SAT hypothesis

A bounded nondeterministic multitape test with $I$ public input bits, $S$ work bits and $T'$ steps can be decided, under the hypothesis above, in
$$
 (I+S+\log(T'+2)+2)\,2^{O(\sqrt{\log(T'+2)\log\log(T'+I+S+4)}+\log\log(T'+I+S+4))}.
$$
For a near-linear SAT clock $O(n\log^a n)$, eliminating one quantifier block multiplies size by a fixed power of its logarithm, with the power now depending on $a$. The same multilevel reachability calculation therefore applies. It guesses many equal-length subpath endpoints and universally selects the pair to check at the next level. The number of blocks is chosen by balancing the number of endpoints against the repeated polylogarithmic increase. [Uniform construction and exact clock](linear-quantifiers.md)

Here $I=\widetilde O(n_0+P+N^\theta)$, with $n_0$ the source input length, and $S=\widetilde O((k+1)(b+1)+N^\theta)$. For polynomial $T'$ the exponential factor is $N^{o(1)}$. The packed signed diagonal has source deadline $H=\Theta(n_0^2)$ and formula length $N=\Theta(H\log^3H)$. The actual SAT formula is available virtually from the $n_0$ source bits. A constant number of further alternating choices for the global defect is eliminated with polylogarithmic cost using this same fast SAT solver. On honest schedules with $k\le 1+P^{1-\delta}$, all preprocessing, guessed input, work space times the acceleration factor, and the final tests fit $o(H)$ because $(k+1)b\le N^{1-\pi\delta+o(1)}+N^{1-\pi+o(1)}$. On the fixed verifier's padded self-input a timely signal both makes its own bounded-computation formula satisfiable and certifies that $A$ rejects it. Thus the formula is unsatisfiable and no such timely witness exists. Real powers only select honest witnesses; the verifier guesses integer resource budgets. With an explicitly advertised per-call clock, all honest fixed polynomial policy bounds give $\log T'=O(\log N)$ and can be supported by a single verifier. [Source diagonal and word widths](packed-band-transfer.md)

For the graph conclusion, invoke the uniform $O(h\sqrt u)$ balanced-separator theorem for $K_h$-minor-free graphs on $u$ vertices. Recursively path-decompose the components left by each separator, concatenate their decompositions and add the separator to every bag. Along a branch the sizes shrink by a fixed factor, so the sum of separator sizes is $O(h\sqrt P)$. Take $h=\lfloor P^{1/2-\delta}\rfloor$ and use the proved pathwidth bound with $\delta/2$. The older $O(h^{3/2}\sqrt u)$ separator gives the independent weaker exponent $1/3-\delta$. [Conroy, Le and Spalding-Jamieson, Theorem 1](https://arxiv.org/abs/2611.00663) · [Alon, Seymour and Thomas](https://collaborate.princeton.edu/en/publications/separator-theorem-for-graphs-with-an-excluded-minor-and-its-app/)

There is an explicit version of the native bound. For a fixed polynomial policy clock and $L=\log_2(N+2)$, let $D=2^{C\sqrt{L\log_2(L+2)}}$ with a sufficiently large constant $C$ depending on the fixed machines and clock. Use $P=\lfloor N/D\rfloor$ almost equal blocks on a near-linear padded run, so $b=O(D L^a)$. If the native graph had no $K_{\lfloor\sqrt N/D^3\rfloor}$ minor, neither would the block graph. Its separator decomposition would use $k=O(\sqrt P\sqrt N/D^3+1)=O(N/D^{7/2}+1)$ live records. Here $I+S$ is $\widetilde O(N/D+N^\theta+n_0)$, and the polynomial-time reachability multiplier is $2^{O(\sqrt{L\log L})}$. Fixing $C$ bigger than this overhead makes the certified schedule faster than $H$. The coefficient is independent of $C$ because all honest directory, block and space caps are at most polynomial in $N$ with fixed powers. Thus the true native graph has a clique minor of order $\sqrt N/2^{O(\sqrt{\log N\log\log N})}$. For the raw graph take the policy that always abstains. The conjectured RAM time bound is a hypothesis throughout.

## An unconditional time versus clique-minor tradeoff

Suppose for contradiction that $(1+E)(1+h_A)=O(N^c)$ on all unsatisfiable inputs for $c=10001/10000$. Two consequences of this one hypothesis will pay for different parts of the verifier.

1. Materialized explicit formulas have nondeterministic certificates for **both verdicts** in time $O(m^{c+o(1)})$ at bit length $m$. A satisfying assignment can be guessed and checked in quasilinear time, for example by sorting literal occurrences to enforce consistency. For UNSAT run $A$ to its signal with a sufficiently large fixed cutoff $C\lceil m^c\rceil$ on every branch. Its soundness excludes false signals. The hypothesized cost bounds its time on every genuinely unsatisfiable instance. The bound does not impose any requirement on positive inputs beyond soundness.
2. On every unsatisfiable source formula take $P=\lceil N^{2/3}\rceil$. If $E<P$, direct native replay from initialization using the virtual input yields a timely signal, a separate allowed certificate mode. Otherwise take $b=\lceil E/P\rceil$ and nearly equal nonempty blocks. Their producer graph excludes $K_{h_A+1}$ by the explicit minor contraction. Its path decomposition needs only $k=O((h_A+1)\sqrt P+1)$ simultaneous records. Thus $kb=O((1+h_A)(1+E)/\sqrt P)=O(N^{c-1/3})$. The interval directory and the public source input use $\widetilde O(P+n_0)$ bits. Use the wholly abstaining policy and no exception table.

Now the RAM $A$ need not have a quasilinear clock. We instead eliminate a **fixed** number of quantifier blocks, charging exponent $c$ for each elimination. The following constants exhibit a strict margin. Validate the public directory in $\widetilde O(P+n_0)$ native time by sorting introduction/forgetting positions and checking its actual maximum overlap; verify ordered cuts, end times and maximum gap. Give the local tape verifier a work budget $S=O((k+1)(b+1)\log N+\operatorname{polylog}N)$ computed from those checked caps and its fixed tape encoding. It cannot be set smaller by an untrusted witness. Similarly the local time budget is large enough for *all* queries on well-formed data. This ensures an absent log or incorrectly shortened search cannot turn a true defect into a negative answer.

For this policy-free test one may use $T'=N^{100}$ for all sufficiently large $N$, including on false guesses after imposing $b\le N^2$ and $P,k\le N$. For an explicit loose count, use an array of live records and implement indexed accesses by full scans on tapes. There are at most $Pb$ events in the array and $O(\log N)$ bits per event, including its rectangle of native fields and claimed source. A scan or fixed-word calculation with indexed operands then costs $N^{4+o(1)}$ tape steps, including queries to the public input by scanning. Native transition validation can loop over a block's own earlier events; a pair comparison can loop over every possible incoming event in one record and every write in the other. Over at most $P^2$ pairs these loops cost $O(P^2(b+1)^2\operatorname{polylog}N)$ indexed operations. Checking the layout, generating one virtual formula word using the uniform template and source, and maintaining the live array with sequential scans fit these loose budgets. Only $k$ records need to reside on the work tapes. This supplies the claimed polynomial time cap with slack, independent of $c$. Read-only physical input is the short source plus directory and requested indices. The SAT solver's arbitrary native addresses are compared as $O(\log N)$-bit data in the records.

Take $r=1024$ levels of reachability subdivision and fanout $f=2^{\lceil(100/r)\log_2 N\rceil}$. There are at least $T'$ available machine transitions after accepting idle padding. At each level guess $f-1$ intervening configurations in the bounded tape space, universally select one adjacent pair and pass that pair to the next level. Check a single transition at the leaf. The initial matrix and the quantifier lists, including input access and all endpoint selection circuits, have size and construction time
$$
 \widetilde O\big(f(I+S+\log T')\big)\le N^{c-1/3+100/1024+o(1)}
$$
on the honest branch. The constant $r$ levels each write their checkpoint buffers once. This coding works for acceptance of the test of any stated canonical block property, including absence of writes to a specified address, since the whole local log is available to the property checker. The outer test for a global defect guesses its type, one consumer, a source or sentinel and a constant number of words or indices. It universally selects a local controller, producer, consumer or intervening-block condition to check. Each requires only one indicated canonical-log property, of either specified sign. Putting the negation of this defect test together with the reachability formula uses at most $2r+20$ blocks, including the leaf and endpoint choices. The initial directory is guessed separately and charged in the signed machine's running time.

For a matrix and its remaining quantifier prefix of total encoded size $m$, consider its innermost block with the outer variables still free. Freeze those variables by input pins and reduce the desired existential circuit verdict (or the complement of a universal verdict) to explicit SAT with $m^{1+o(1)}$ bits. The two-sign certificate from step 1 has a bounded locally checkable RAM transcript for either truth value of that quantified statement, using $m^{c+o(1)}$ bits and construction time including the explicit gate and variable indices. If the preceding block is existential, append a certificate of truth to that block. If it is universal, quantify a proposed certificate of falsity and require that it be invalid. The transformations agree at EACH assignment of the remaining outer bits. The final signed verifier only needs a nondeterministic certificate of truth; a final universal block uses the certificate of the appropriate complementary verdict. Thus these eliminations use no deterministic SAT decision hypothesis. Local reference cutoffs large enough for the promised branch are fixed constants of the verifier. [Transcript elimination principle](linear-quantifiers.md)

In total the honest exponent is at most $(c-1/3+100/1024)c^{2068}+o(1)<0.97+o(1)$. Indeed $c^{2068}\le(1-2068/10000)^{-1}$ by comparison of the binomial expansion with the geometric series. There are only finitely many subpolynomial overheads. The directory guess and validation fit this bound as well. Since $N=\Theta(H\log^3 H)$, the resulting nonacceptance signal arrives in $o(H)$ source steps. On the verifier's own padded description any such signal would make this very formula satisfiable and prove that the recognizer $A$ genuinely signaled UNSAT on it. The formula is therefore unsatisfiable, and the hypothesized cheap honest run supplies the contradictory signal. All nested formulas relevant to the honest clocks have lengths polynomial in $N$. As in the signed transfer, fixed host width headroom handles their solver addresses, while the original universal machine's native addresses occur in its Boolean reduction only as symbolic data. This proves the unconditional product assertion. It leaves open whether $A$ can run in linear time with large clique minors on the hard inputs.

## Permitting recomputation

For an explicitly described candidate graph there is a separate test with repeated block occurrences. Guess records and check their local instructions at introduction. Each occurrence keeps a discharge mask over its candidate producers. When a child occurrence and an occurrence with a candidate producer's label coexist, check their complete pairwise condition and mark that port discharged. Forget a record only when all its ports have been discharged. At termination require that a distinguished occurrence with the requested property has been introduced and the live set has been emptied. A record may have checked its child before its own ports were fully verified. In any accepted finite schedule every such producer obligation was eventually discharged. Induction on the block index over *all occurrences with that label* proves that every occurrence has its canonical log. The rank is the chronological label, independent of the introduction order. Duplicates cannot support inconsistent values. [Prior occurrence proof for Boolean gates](forcing-pebble-layouts.md)

For this variant take $\pi<1/2$ so a raw adjacency matrix costs $O(P^2)=N^{2\pi+o(1)}$ bits and an occurrence's $P$-bit mask fits in $\widetilde O(b+1)$ space. Use a cap $M$ on schedule operations and $k$ on live records. The replay predicate has branch time $M\operatorname{poly}(N)$, while its space is $\widetilde O((k+1)(b+1)+N^\theta+\log M)$. The outer verifier also asks if **some** block lacks any accepted evaluation under these caps, and rejects that guess if so. This is necessary when the graph or budget is dishonest. If every block is evaluable, the predicate for either sign of every block property is exact, since a successful schedule for its label may be reused unchanged with the true property. The previous actual-memory defect test now applies.

For any fixed $\pi\in(0,1/2)$, $\delta\in(0,1)$ and $\theta<1$, some $\epsilon>0$ suffices to allow
$$
 M=2^{\left\lfloor\epsilon(\log N)^2/\log\log(N+4)\right\rfloor}.
$$
The reachability multiplier is $N^{O(\sqrt\epsilon)+o(1)}$; choose $\epsilon$ after the fixed exponents, solver and verification routines. Thus on the same hard family, if $k\le P^{1-\delta}$, at least one block lacks a legal schedule within both caps on the genuine residual producer graph. One universal verifier may guess which of the two tests and which numerical caps to use. A black pebbling placing a block only with its predecessors already pebbled gives such a schedule, by checking its at most $P$ ports while those parents are live. This costs $O(P+1)$ verifier operations per pebble move and at most one extra live occurrence, harmless with constant slack in the caps. Sequential comparisons in the occurrence proof also handle a high-degree star in constant space by guessing the central log and discharging its sources individually. The restriction thus concerns more than the simultaneous parent count. Classical tradeoffs and the $O(P/\log P)$ general space bound are for the bounded-indegree black pebble game. They do not guarantee $P^{1-\delta}$ space or the stated move budget for this data-dependent transfer structure. [Paul, Tarjan and Celoni](https://doi.org/10.1145/800113.803643) · [Lengauer and Tarjan](https://collaborate.princeton.edu/en/publications/asymptotically-tight-bounds-on-time-space-trade-offs/)

## A native obstruction to a graph-only shortcut

For each pair $1\le i<j\le r$ allocate one initially zero word addressed by the pair. During phase $i$ read all words $(u,i)$ with $u<i$ and write one to every $(i,v)$ with $i<v$. The $r$ consecutive phases have $O(r^2)$ steps in total and the true producer graph on these phases is $K_r$. One may return a constant verdict. The simple graph on individual chronological steps and read-to-last-write edges has $O(r^2)$ edges and a $K_r$ minor. A clique minor of order $h$ requires at least $\binom h2$ different edges between branch sets. Hence the square-root power of the native bound is already possible by elementary RAM access geometry. A constant-one policy supplies every incoming read in this example and erases all producer edges. The missing universal step would have to exploit which values a solver can supply cheaply, or another semantic feature of correct SAT algorithms. No unrestricted time exclusion follows here.

The earlier ranked reconstruction demands short depth after exceptions on a different, missing-output source. Deep chains can pass the present occurrence or path test at constant width. The earlier native trace layout checks an entire chronological trace with extra coverage and memory-order conditions. The present result instead concerns the simple graph of genuine imported writes of an ordinary SAT solver after value prediction, with the prefix controllers paid for separately.
