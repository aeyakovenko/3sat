# Verifying the actual native gate table with ordered decision diagrams

A predictor of [balanced explicit checksum SAT](sat-on-random-checksums.md) can parse the public field point, mask and terminal pin from the CNF header in $\operatorname{poly}(j)$ work. Its remaining task is to evaluate a field symbol of the genuine, uniquely determined computation table. Here is a certificate that verifies that table without a universal clause challenge. Use a layered ordered binary decision diagram (OBDD) reading the row address from its least significant bit to its most significant bit. A diagram can return a bit or a tuple of bits. Its width counts states at the widest layer. Transitions may depend on the layer. The construction uses a specified regular layout of the near-native computation; short local generation of an arbitrary other layout alone would not establish the required properties of its wiring.

Let $M=2^j$. There is a parsimonious explicit checksum family of $M\operatorname{poly}(j)$ encoded bits for the actual priority bit $b_j$ with the following property. Suppose each local gate's operand and result bits **together**, as functions of its row, have width at most $w_j$ in this order. Arbitrary nonuniform diagrams may be used at each stage. The correct native output admits a sound nondeterministic verification in $(1+w_j)\operatorname{poly}(j)$ word steps if $w_j\le M^{O(1)}$. Under an unrestricted deterministic $O(n^k)$ SAT algorithm, for $k=1,2,3$ there is a fixed $B$ such that on every sufficiently late stage at least one actual gate tuple requires width greater than $2^{\lfloor j/k\rfloor}/(j+1)^B$. If only the widths of the **individual** columns are bounded by $w_j$, the verifier costs $(1+w_j)^2\operatorname{poly}(j)$ and the corresponding width threshold is $2^{\lfloor j/(2k)\rfloor}/(j+1)^B$. In particular the latter test reaches exponent $1/6$ for cubic SAT. Finding small enough diagrams on the actual stages would be required to use this argument to exclude that SAT clock.

## Wiring for an actual row-indexed family

Run the fixed deterministic [priority program](priority-pinned-sat.md) at its logarithmic word width for $T=2^{j+c}$ ticks with fixed $c$ chosen from its native running time bound, idling after halt. The initial registers, scale and all-zero input are public. Each tick has a fixed power-of-two $P$ of ordered memory-event slots, sufficient for the instruction set, including dummy no-ops. Index the common row grid by $u=P t+s$ for $0\le t<T$ and $0\le s<P$. It has $2^d=PT$ rows, $d=j+O(1)$. Chronological controller and event fields for a tick can be held on slot zero, with unused entries of those columns forced to zero. A comparator-network record at slot $s$ obtains its corresponding tick fields from $u$ with the bottom $\log P$ bits reset. A local gate can select the field for the actual slot by an ordinary constant-size multiplexer. Dummies have completely specified contents. Many gates use the identity row map.

Use the [chronological and sorting-network verifier](projected-parity-holes.md#a-parsimonious-ordinary-3-cnf-near-the-native-clock). Check the initial state, instruction transition and enabled event records with Boolean circuits for the fixed word instruction set on $O(j)$ bits. The previous or next chronological tick has row offset $\pm P$, guarded at the endpoints. Sort the events by bank, address, time and slot with a public bitonic sorting network and deterministic binary comparator gates, including fixed tie conventions. Sort keys include the required live/dummy tag. For each bank/address run in sorted order, a row records the post-event contents of the cell. Its pre-event contents equal the preceding row's post-event contents for the same live key, else the prescribed initial value. Require every read to return its pre-event contents and every write to update them. This extra field is uniquely determined in increasing row order; its neighbor offset is $-1$, guarded at row zero. Verification checks each row's Boolean constraints directly by asserting its local valid bit. There is no need for an unstructured final conjunction tree. Halting by the endpoint and the output register are checked on specified rows. Guessing all chronological data and sort-network gate bits satisfying these clauses yields precisely the true execution. Sorting gives the correct last write for each read, deterministic transition gives the unique trace by induction on ticks, then all comparator, memory and checker bits are forced. This is the same semantic check for which a regular layout is used in the parsimonious CNF.

There are $\operatorname{poly}(j)$ gate or field column types. Comparator substeps have partners $u\mathbin\oplus2^r$ for a **fixed** bit position for each stage/substep; the direction bits are projections of the lane index in that template. Word arithmetic consists of polynomially many ordinary fan-in-two gate columns at a common row. Time bits of the initial unsorted events are individual lane projections. A convenient fully uniform representation allocates a fresh output column to each auxiliary projection, guard and conditional gate, and fixes unused slots. Guarded assertions can use the Boolean gate for the implication followed by an assertion that its result is one. Equivalently one can test equality only on a public guard by masking both sides to zero elsewhere. Guards in this layout are constant-state tests or combinations of polynomially many prescribed gate templates. Constants, endpoint tests, slot-equality tests and individual direction bits have small OBDDs directly. Replacing short clauses by exact-three clauses with fixed shared false bits, if desired, preserves unique extension.

All row maps just described are synchronous finite transductions in least-significant-bit-first order. XOR by a constant and resetting or setting prescribed bits emit one transformed bit at each level. Adding a fixed signed offset modulo $2^d$ uses the known digits of the offset and one carry bit, dropping the final carry. End-of-grid guards explicitly exclude unintended wraparound. Compositions of the constant number of maps on an input wire still have bounded state. Each gate template, predecessor column, transduction and boundary constraint is constructible in $\operatorname{poly}(j)$ work, including the Boolean implementation of the fixed RAM program. Assign variable names by a column tag followed by all $d$ row bits, padding unused tags and gate positions with prescribed zeros. The CNF has $M\operatorname{poly}(j)$ bits, and any word is obtainable from $j$ and its address in $\operatorname{poly}(j)$ operations by the explicit layout. Interpolate this rectangular array in its row and tag bits. The public-selector AND and XOR checksum suffix and its header are exactly those of the balanced construction and lie outside the table being interpolated. This choice of numbering defines one member of the regular-layout family.

## Exact verification and field evaluation

To guess an OBDD, specify each layer's array of two successor indices, one root, and final output labels. Reject malformed sizes, pointers or totals. A transducer with $a$ states pulls a width-$w$ diagram back to a width-$aw$ diagram by storing its transducer state beside the simulated diagram state. Levelwise projection of a tuple changes only its terminal labels. For equality of two root functions, label terminal states jointly by their output value. At each preceding level sort all ordered pairs of child labels in the union of the diagrams, assigning the same new integer to equal pairs. Two states get equal labels exactly when every suffix yields the same output, by induction. Each check costs $O(S\log(2+S))$ for $S$ total nodes using ordinary deterministic word comparisons. This is the ordered decision-diagram canonicalization algorithm; binary `Apply` is also classical. [Bryant, *Graph-Based Algorithms for Boolean Function Manipulation*](https://doi.org/10.1109/TC.1986.1676819)

For each gate template guess one diagram for the triple of the two **translated** operand values and the output value at the addressed row, omitting absent operands for unary gates. Mark reachable states from its root and check every reachable terminal satisfies the gate truth table. Check every input projection equals its named source output pulled back by the specified transducer. For raw input fields guess a single column diagram shared by all their uses; check public fixed fields and final assertions by the same equality or endpoint tests. These tests define one value for every variable and prove every local constraint at every row. They therefore prove the guessed sign. On the true table such triples exist at their actual joint widths. Given individual input diagrams of widths $w_X,w_Y$, form the reachable paired states of their pulled-back diagrams and label each terminal by $(x,y,f(x,y))$. This produces the true tuple within $O(w_Xw_Y)$ width. Alternatively build only the gate result this way and compare it with the proposed output by canonicalization. For a particular gate only the reached pairs need to be built. Unary transformations need no binary product. Any costs from the polynomial number of gates, levels, guards and transducers are covered by the displayed $\operatorname{poly}(j)$.

The time thresholds use one ordinary bounded-acceptance SAT call for each sign with a constructible cap. At each stage meeting the representation hypothesis the correct sign has a witness; a false sign never does. The [packed RAM compiler](packed-band-transfer.md) makes the clock-$R$ check into an ordinary SAT question with $R\operatorname{poly}(j)$ encoded bits when $R\le M^{O(1)}$, charging guess symbols, topology, indexing and output. All addresses and array lengths then take $O(j)$ bits. For the stated width caps and sufficiently large fixed $B$, a postulated $O(n^k)$ solver would give a fixed sound sign detector using $o(M)$ steps on every successful sufficiently late stage. The native priority theorem rules out infinitely many such successes. The shift from the generic checksum recovery bound comes from checking the whole represented table directly.

If the diagrams are already known to represent the genuine columns, compute the exact dense checksum for a given public field point. At each internal node with children valued $V_0,V_1$ substitute $(1-p_i)V_0+p_i V_1$ at its level. Shared children are evaluated once. A second sum with the public tag interpolation weights assembles the rectangular table. This evaluates its canonical multilinear extension, since each level uses a different variable, and costs the total diagram size times $\operatorname{poly}(j)$. A guessed but unverified small diagram cannot by itself certify this SAT decision.

For a grid of $2^d$ rows with a fixed alphabet of $K\ge2$ possible outputs, the sharp worst-case minimum width in the fixed order is
$$
             \max_{0\le i\le d}\min(2^i,K^{2^{d-i}})
                   =\Theta_K(2^d/d).
$$
At depth $i$ there are at most $2^i$ prefixes and $K^{2^{d-i}}$ different suffix tables. Conversely prescribe distinct suffix tables to as many prefixes at a maximizing depth as possible, which forces that width. For the upper asymptotic bound, if $2^{d-i}\ge d/(2\log_2 K)$ take the prefix bound; otherwise the suffix count is at most $2^{d/2}$. For a binary explicit example put $r=\lceil\log_2 d\rceil$ and $i=d-r$ for $d\ge2$. Treat the first $i$ bits as data and the last $r$ bits as an index into them, returning zero outside the available positions. The $2^i$ data prefixes give distinct residual functions; this index bit is computable with a constant number of ordinary word operations given the public widths, using shifts and a comparison. Thus easily computed columns alone can require $\Theta(2^d/d)$ width in this order. For the actual grid $2^d=PT=\Theta(M)$ this generic upper bound is $O(M/(j+1))$ *per column or constant-alphabet gate tuple*. It neither counts all $\operatorname{poly}(j)$ columns nor pays for the layers, successor pointers, verification or SAT encoding. The argument supplies no bound at the precision $M/(j+1)^B$ needed above for the linear-SAT test.

## When products can be avoided for affine gates

Over $\mathbb F_2$ write each two-input truth table as $c_0+c_1x+c_2y+c_{12}xy$. Start with proposed diagrams for all individual columns. Pull back operands to the consuming row. Add a product diagram for $xy$ only when $c_{12}=1$, and add public constants and guard diagrams as above. Include a common all-one diagram. To test a guarded equality, include copies of each participating summand multiplied by the same small public guard; this costs at most its polynomial size factor. Let $S$ count all nodes across the resulting diagrams, including their copies and the products actually built. If products are generated by enumerating the reachable paired states, charge these states and transitions before minimization to $S$. Gate correctness now consists entirely of binary-linear identities between root functions, including the constant terms and source constraints. Endpoint values can also be tested separately.

At layer $i$ let $r_i$ be the dimension over $\mathbb F_2$ of the span of the **suffix functions** of all nodes in this union, including the added products or guard-restricted nodes. Put $r=\max_i r_i$. Guess one $r_i$-coordinate vector per node, two $r_i\times r_{i+1}$ binary matrices at each level, and a linear readout at the terminal level. Check the coordinate of each child equals its parent's vector times the matrix for that input bit. Check every leaf's readout against its actual known label. At the roots check every required affine identity as a vector sum. Soundness follows by following each suffix through the linear maps and readout; no independence of the guessed coordinates is assumed. For completeness choose bases of the actual suffix spans. Restricting a linear combination of suffix functions to a first bit is linear and maps into the next span, so the required matrices exist. Every true functional identity then holds as a vector identity. Dense bit arithmetic costs $O((1+S+d)(1+r)^2)\operatorname{poly}(j)$ including witness length and explicit matrices; at a guessed cap bound and test all sizes. Thus low residual rank makes the treatment of affine gates near-linear in the supplied diagrams and the reached products at genuinely nonlinear gates. This uses the standard linear-representation principle for automata equivalence. [Tzeng, *A Polynomial-Time Algorithm for the Equivalence of Probabilistic Automata*](https://doi.org/10.1137/0221017)

The width of a tuple cannot be replaced by the largest individual width even for XOR. In row-bit reading order place $a,b,t\in\mathbb F_2^e$ consecutively. Let $X=a\cdot t$, $Y=b\cdot t$, $Z=(a+b)\cdot t$. Each output admits width $2^e$ (after the first suffix bit the residual is a shorter linear form plus one constant bit). At the cut before $t$, the tuple distinguishes all $2^{2e}$ ordered pairs of linear functionals, hence has width at least $2^{2e}$. The affine identity is exact, and the suffix span at this cut of the three individual diagrams is only $e$. This rules out a linear bound for the naive joint-state construction on XOR. It leaves open the complexity of checking arbitrary affine gates by other algorithms. No bound on the actual priority table's widths or cofactor ranks sufficient for the unrestricted separation is known here.
