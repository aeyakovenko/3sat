# Verifying a RAM trace by reindexing its loads

**Research journal, 24 November 2026.** There is a one-index test for a chronological SAT solver trace that never sorts its accesses. It permits a small circuit to name both a load and its source using a common index, even when recovering the source from the load time requires a large circuit. A second circuit separates two sets of keys recording forbidden writes. The test gives an unconditional disjunction on genuine rejecting runs by the bounded diagonal. A fixed fast RAM stream distinguishes this certificate from sorted ranks and direct producer circuits for prime-power gate moduli. A more general succinct verification problem already captures a second-level quantified Boolean formula.

## Covering a load gap by intervals

Use the machine, encoding, local input circuit and native transition checks of the single-index theorem. There are $T=2^u$ padded timestamps. For a work load of bit $b$ at address $z$ and time $t$, choose an anchor. The initialization anchor requires $b=0$ and gives cut $c=0$. A store anchor is a time $s<t$ at which a store to $z$ writes this bit as $b$, giving cut $c=s+1$. In either case require that no store to $z$ in $[c,t)$ writes the opposite bit. Same-value intervening stores are allowed. The true last writer or initialization supplies a valid anchor. Conversely, any valid anchor gives the actual bit under the preceding stores. This applies separately to every bit of a word. [Single-index model and signed construction](one-index-solver-memory.md) · [Finite anchor equivalence](../lean/SuccinctClaw.lean)

Fix the full binary interval tree on the $T$ timestamps. For each work store at timestamp $r$, address $z$, bit position $j$ and written bit $v$, place $(z,I,j,v)$ in a first set $A$ for every ancestor interval $I$ of the leaf $r$, including itself. For a load with the proposed anchor above, put $(z,I,j,1-b)$ in a second set $B$ for every maximal aligned dyadic interval $I$ contained in $[c,t)$. A key in both sets is precisely a store writing the opposite bit inside one of the proposed gaps. Address keys include the bank. Such an intersection is sometimes called a claw between the two key generators.

At each fixed level at most two maximal intervals occur. If an interval of that length is neither the first nor the last aligned interval wholly in the gap, its sibling also lies in the gap, contradicting maximality. Try the first and last complete intervals at each length and test containment of the interval and noncontainment of its parent, treating the root separately. Endpoints and parent identities use shifts by hardwired amounts, comparisons and binary addition, at fixed depth and size polynomial in $u$. Use an extra endpoint bit to represent $T$. An empty gap produces no keys.

## Providing a cover of the load times

Guess a permutation $L$ on the $u$-bit timestamps given by a bounded number of triangular layers and coordinate permutations. One triangular layer has $y_j=x_j\mathbin\oplus C_j(x_{<j})$ in a specified order. The syntax restricts the inputs of each $C_j$. For any proposed output, its preimage bits are determined successively in that order. Hence the layer covers every timestamp. Evaluating the layer in the forward direction takes one parallel application of the given circuits and one XOR layer. Position orders, wiring and syntax are checked when reading the guessed description.

Guess a circuit $P(i,j)$ supplying the anchor for bit $j$ of the load at $L(i)$, including the initialization flag. For a nonload at $L(i)$ it has no obligations. Guess a Boolean circuit $S(z,I,j,v)$ and demand it return one on $A$ and zero on $B$. At free index $i$, check the native transition and the store keys for timestamp $i$. Also obtain the row and load response for $t=L(i)$ from the chronological controller $G$. For every hardwired $j$, check the source row named by $P(i,j)$ or its initialization flag, and test $S$ on the at most two eligible cells per level of the load gap. The same $S$ is evaluated on both kinds of key. A spurious generator, permutation or separator can never validate a false read. Indeed $L$ covers every load, and any forbidden intervening store would require both values at one input of $S$. Chronological induction with the native checks authenticates the run. Conversely every genuine run has an unrestricted certificate, with $L$ the identity, the ordinary last writers, and the indicator of $A$ as its separator. Smallness of these certificates is a separate question.

For fixed circuit depth, gate modulus and layer bound, the combined defect circuit on $i$ has fixed depth and size polynomial in $u$ and the total candidate size. It never quantifies over an independently chosen producer in addition to $i$. The levels and bit positions are unrolled. Thus for any correct deterministic SAT solver, and these fixed parameters, there is $0<a<1$ and a family of ordinary unsatisfiable inputs, one at each sufficiently large $k$, of lengths $2^k\le N_k\le 2^k k^{O(1)}$. With $u=k+\lfloor k^a\rfloor$, the actual run either has yet to halt at $2^u-1$ or it has no such joint certificate $(G,L,P,S)$ of total size at most $2^{\lfloor k^a\rfloor}$. To obtain this family, put the new test in the bounded complementary diagonal for the one-index theorem. A timely valid description certifies rejection on an input that it makes satisfiable. Testing the defect circuit by fixed-depth ACC satisfiability saves $2^{\Omega(u^\delta)}$ over $2^u$ for $a$ sufficiently small. The circuit guess, local input decoder and deterministic SAT test together fit $o(2^k)$ including the fixed tape simulation factors. A verifier can also accept any of the earlier sound sorted-rank or block certificates, giving their prohibitions on the same family after reducing $a$ as needed. Conventional multiplication and division use the native-operation annotations in $G$ from the original theorem. ## A forward map whose inverse evaluates width-five programs

Use $r$ lanes with one constant-width generator code $g_j$ and state code $s_j$ in each. Generator codes select a permutation on five states, fixing extra binary state codes. Unused generator codes select the identity. Take $s_0=0$ and define
$$
 F(g,s)=(g,d),\qquad d_j=s_j\mathbin\oplus g_j(s_{j-1}).
$$
Each output bit depends on a constant number of input bits. Order the unchanged generator fields first and then the state fields in successive lanes. This makes $F$ one triangular layer. Its inverse satisfies $s_j=d_j\oplus g_j(s_{j-1})$. On $d=0$, the last state is the result of applying the group word to zero. The two inverse identities for this causal construction are kernel-checked over an arbitrary involutive word mask. [Lean proof](../lean/SuccinctClaw.lean)

First store one to $F(t)$ for every $t$ in binary order, then load one from each address $z$ in binary order. Every load is genuine. Exactly one store can justify its low bit. A direct producer indexed by load ordinal $z$ must recover $F^{-1}(z)$. A sorted-rank circuit also recovers $F^{-1}(z)$ since the store for $z$ has rank $2z$ among the accesses. Nonmemory rows come after every work access in the sorted convention. In contrast, use parameter $i$ to name the load of address $F(i)$ and the store of address $F(i)$. The producer ordinal is $i$. All stores write one and all loads return one, so a separator returns one on a key precisely when its bit agrees with the corresponding bit of the constant word one. These are polynomial-size bounded-depth Boolean certificates for the whole stream.

This stream can occur inside a fixed native solver on a guarded family of explicit negative formulas. Detect a fixed contradictory pair, and otherwise invoke an arbitrary correct solver. On the guard choose a lane count tending to infinity with $N$, small enough for the packed lane word and for $2^{U}=O(N)$, where $U$ is the packed index width. Generate the repeating lane masks in the registers, then perform the two scans. Bitwise gates, fixed shifts and a fixed lookup expansion for the constant lane alphabet evaluate $F$ in constantly many word steps by operating on each bit position of every lane in parallel. The temporary registers contain fixed compositions of these operations on the counter and masks. Clear registers at phase boundaries and use a fixed power-of-two instruction count per iteration by padding. A load mismatch can return the opposite verdict, since it never occurs on the true scan. The prelude can use only register and input operations and take polynomial time in $U$, so its length-specific register truth table can be hardwired in polynomial size. Choosing, for example, the number of lanes proportional to $\log N$ with a sufficiently small coefficient makes the guard branch $O(N)$ in time, on layouts where the guard is available in the header or first clauses. This wrapper is globally linear if its fallback is globally linear.

On these native timestamps the phase and low instruction-slot bits are preserved by $L$, which applies $F$ to the counter field in the load phase. A fixed offset for setup can be handled by subtracting the offset modulo the timestamp domain, applying the phase-controlled layer and adding it back. Addition by a fixed constant is triangular from least to most significant bit. The anchor similarly produces the physical store time by counter shifts and an offset. Conversely, the store time returned at rank $2z$ or supplied for the low load bit gives the counter back by a subtraction and shift.

For a prime $p$ choose $q\in\{2,3\}$ distinct from $p$. Set $g_j$ to the identity or a fixed $q$-cycle on states including zero according to input bit $x_j$. Recovering whether the last state is zero computes $\mathrm{MOD}_q(x)$. By Smolensky's bound every fixed-depth AND/OR/NOT/MOD$_p$ circuit recovering the inverse has size $\exp(r^{\Omega(1)})$. An equality test of the constant number of final state bits only changes the fixed depth. This applies to both direct producer and sorted-rank circuits. More generally, a polynomial-size ACC circuit family of fixed depth and modulus for these inverses would put nonuniform $\mathrm{NC}^1$ in nonuniform ACC of that modulus and bounded depth per language. Barrington's programs select one of two group elements per input instruction, with output product the identity or a fixed five-cycle. Their selected generator code bits are constants, input literals or their negations. The image constraint $d=0$ then exposes the computation at the last state. The separation extends to a fixed prime-power modulus $p^e$. A MOD$_{p^e}$ gate can be simulated at constant depth and polynomial size by MOD$_p$ gates. If $H$ input wires are true, the $i$th base-$p$ digit of $H$ is $\binom{H}{p^i}\bmod p$. This follows by expanding $(1+X)^H=\prod_{j}(1+X^{p^j})^{H_j}$ over $\mathbb F_p$ and taking the coefficient of $X^{p^i}$. Compute each digit's zero test by counting the ANDs of all $p^i$-subsets of the input wires modulo $p$, for $0\le i<e$, and conjoin. The blowup has fixed polynomial degree for fixed $p,e$. The assertion for moduli with multiple prime factors remains an implication. [Smolensky, STOC 1987](https://people.cs.umass.edu/~immerman/cs601/Smolensky.pdf) · [Barrington, JCSS 1989](https://people.cs.umass.edu/~barring/publications/bwbp.pdf)

## Direct producers for general Boolean gate computations

Håstad previously constructed a LOGSPACE-uniform family of $\mathrm{NC}^0$ permutations with P-complete inversion by masking a straight-line computation. The lane example above uses this masking principle on a width-five program to permit a constant-step native forward evaluation. The following application to trace certificates uses arbitrary bounded-fan-in circuits and a polynomial number of steps per address. [Håstad, *Oneway Permutations in NC⁰*](https://www.csc.kth.se/~johanh/onewaync0.pdf)

Let $C$ have $n$ input bits and $t$ gates in topological order, and put $U=n+t$. On the address $(x,s)$ with one proposed bit $s_i$ per gate, preserve $x$ and output
$$
 d_i=s_i\oplus g_i(x,s_{<i}),
$$
where $g_i$ reads its gate's at most two specified operands. For each fixed wiring this is one triangular permutation $F_C$ with constant locality. Inverting at $(x,0^t)$ gives the true gate values successively. Any designated output of $C$ is a projection of the inverse. In the two-phase stream the sorted ranks and low-bit anchors both recover this inverse on all addresses. The forward reindex certificate still uses only $F_C$, simple time arithmetic and the separator for a constant stored word.

One fixed RAM can implement this entire family of streams. Include the gate records as data in tautological clauses beside the contradictory guard. Check dimensions and operand references first, and process this branch only when its announced scan fits the physical input length. For any desired $C$, pad with tautologies to a length $N=2^U U^{O(1)}$ large enough that a whole address fits a word and the scan fits $O(N)$ steps. A fixed larger coefficient in the word width suffices. Read each gate's opcode and operand positions from the immutable input. For each store ordinal $(x,s)$ compute the $d_i$ independently from its original bits, accumulating the packed result in a register. This costs $U^{O(1)}$ steps per address and uses no auxiliary memory accesses before the designated store. Choose power-of-two padded iteration lengths covering the gate loop, with schedule independent of the ordinal, and pad the load phase similarly. The chronological controller for each fixed formula still has polynomial-size AC$^0$ circuits in $U$. At a specified inner time the accumulated word consists of a prefix of the independent $d_i$ and a fixed filler suffix. The inner positions, their gate parameters, the prelude states and schedule-dependent address arithmetic can be hardwired in tables of $U^{O(1)}$ entries. Extracting operand bits, the few temporary bit operations and counter updates have bounded depth. The only data varying over the exponentially many ordinals are the ordinal itself, its indicated bits and their fixed local functions. Sorted store ranks recover the ordinal by subtracting the prelude offset and shifting off the slot bits, as before. All resource bounds on the certificates here are measured in $U$, the logarithmic timestamp scale, rather than $N$.

Consequently, if direct-producer circuits of some fixed depth and modulus and size $U^{O(1)}$ suffice on **all** these valid presentations, then $\mathrm{P/poly}\subseteq\mathrm{ACC}^0$ for that modulus. The analogous bound on sorted-rank circuits gives the same inclusion. Indeed apply the hypothesis to each circuit $C_n$ of a polynomial-size nonuniform Boolean circuit family, and hardwire its instance-specific selector or rank circuit at $(x,0^t)$. Its size remains polynomial in $n$. This conclusion concerns polynomial certificates and does not itself exclude the stretched-exponential budgets of the diagonal. The forward certificate verifies the real computation in which this inverse occurs.

## Changing a single reported value changes the verification problem

For arbitrary succinct maps $A,B$, first store one at all addresses in $\operatorname{im} A$, then read every address in $\operatorname{im} B$. If all loads report zero, validity is image disjointness. If all report one, validity is image containment $\operatorname{im} B\subseteq\operatorname{im} A$. Already the latter is $\Pi_2^P$-complete for polynomial-size AC$^0$ address maps given explicitly. For $\forall x\exists y\,\phi(x,y)$ with a 3-CNF matrix, parameterize stores by $(x,y)$ and send the store to $(1,x)$ when $\phi$ holds, otherwise to a disjoint dummy address. The load map emits $(1,x)$, ignoring unused bits. This uses only a constant-depth test and bit selections. Conversely containment has the displayed universal–existential form. General succinct stream validity also belongs to this level. For each load and bit, require a prior matching store if the bit is one, and for every prior opposite-bit store require a strictly later matching store before the load. The actual last store, or zero initialization when none exists, proves the characterization.

Consequently a universal polynomial bound on one-index certificates of the form above for every valid polynomial-size succinct stream would give $\Pi_2^P\subseteq\Sigma_2^P$, collapsing the polynomial hierarchy at level two. Guess the certificate and use a universal index to test its polynomial-time predicates. This implication concerns all succinct presentations and polynomial witness sizes. The diagonal uses larger $2^{u^a}$ descriptions and solver-specific ordinary inputs. Neither this hierarchy implication nor the prime-modulus example excludes a faster algorithm for those inputs.
