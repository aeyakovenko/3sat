# Processing after the database packets of a SAT file have been read

Take a fixed deterministic SAT decider on an aligned logarithmic-word RAM with one initially populated writable memory, separate load and store instructions, fixed terminal verdicts and a fixed number of registers. Use the sufficiently large fixed word-width coefficient of the packed row-query construction. For arbitrarily large encoded lengths $N$, there are opposite proper 3-CNFs differing in one bit whose common execution prefix has read every database packet. Among the $\Theta(N/\log N)$ variable packet slots only $R=\Theta(N\log\log N/\log^2 N)$ remain to be read. If cut memory has $N\log^{O(1)}N$ occupied words on the construction, **each continuation requires $\Omega(N/\log N)$ in the processing measure below**. The storage condition follows in particular from a near-linear prefix running time.

A LOAD by itself contributes zero to the measure. The solver can parse a new seed packet at a known address and compute on its bits for free. There is a uniform $O(N)$-time solver on the constructed family, so the conclusion locates scan-scale processing in the late part of two real executions. ## The charge on a real suffix

At the cut, treat all the registers and the delivered tag word as known. Let $H$ be the remaining packet positions just before the tag reply, including the tag position. The query fixes their initial contents. Mark the result of each subsequent load, with this exception: when its address operand is unmarked and the cell contains an original hole word or the result of a suffix write, the result is unmarked. An unmarked address has an exact numerical value available in the replay. A copy preserves the mark. Arithmetic outputs are unmarked, and using a marked input to compute them is counted. A branch consumes its operands without changing them.

* Count $c$ noncopy numerical operations or comparison branches having a marked operand.
* Count $m$ stores having a marked address or payload.
* Let $D$ be the set of distinct numerical addresses and payloads appearing in all other suffix stores. Repeating unmarked writes with the same endpoint values does not increase $|D|$.

The announced bound is on $c+m+|D|$. It implies a bound of the same order on executed instructions since one store contributes at most two new words. With **arbitrary prefix time and workspace**, both files instead have
$$
                  c+m+|D|+p=\Omega(R).
$$
Here $p$ counts distinct numerical values actually loaded from original hole cells and later used, unmodified except for register copies, as the address of a subsequent LOAD. The cut reply can be included at unit additive cost. Mere arithmetic on a directly read unmarked query word does not contribute to $p$. The native width is $\Theta(\log N)$, so even unrestricted prefix workspace has polynomially many addressable words. The end of the common prefix is a particular physical tag request. The theorem concerns a single run from reset on a complete file in each case.

## A static index of the cut, independent of the query replies

Let $f$ be cut memory with every location of $H$ temporarily set to zero. The preprocessor knows these locations; the actual query supplies their initial words. For a frozen representation with $S$ nonzero cells, index the functional graph on the support of $f$, its image, $H$, and zero. Every outside word points to zero. As in the single-word simulation, a constant-size label permits testing $f^j(u)=a$ from the labels of $u,a$, and a level-ancestor and cycle index returns the numerical word $f^j(u)$ in $O(1)$ probes. Give every origin $u$ a second label: the least $j\ge0$ for which $f^j(u)\in H$, together with that hole's address, or a special value if no such $j$ exists. A reverse search from all holes computes these labels. For an outside origin use the label at zero and one extra step. The entire static index occupies $O((S+|H|+1)\log(S+|H|+2))$ words. Its construction can take arbitrary preprocessing time. [Level ancestors](https://www3.cs.stonybrook.edu/~bender/newpub/2004-level.pdf) · [Static dictionary construction](https://www.rasmuspagh.net/papers/det-jour.pdf)

Supply the addresses and words of $H$ as query-side information **after** reading the compressed directory described below. Cache every orbit label actually fetched. Resolve each suffix store's operands at the time of the store, and retain its timestamp, address and payload in free local storage. Fetch labels for its two endpoints on first use. For an unmarked-address load the simulator can compare the known numerical address against the suffix writes and against $H$ locally. If its contents are known by the marking exception, return the word immediately. Otherwise, keep a deferred register as an origin followed by the chronological subsequence of its dependent LOADs; copies can share the same subsequence. A load through an already deferred register appends its own load time. No branch is taken on an unexamined marked numerical result.

To resolve a deferred register, start at its origin and exponent zero. At each recorded load time, test the then-current symbolic address $f^j(u)$ against the **latest matching earlier suffix store**. A hit resets the origin to the numerical payload and the exponent to zero, including on writes of zero. Otherwise consult the first-hole label of $u$. If it names the current exponent, return the initial query word there as the next origin with exponent zero. If it does not, increment the exponent. Between resets the exponent cannot pass the first hole: encountering it without an overriding write would have reset the chain. A store that shadows the hole would also have reset it. At the endpoint, obtain $f^j(u)$ by a constant-probe lookup if $j>0$, or take $u$ directly if $j=0$. The time at each load matters even when later stores modify that same address.

Each charged computation or marked store resolves constantly many operands and can fetch the label of each starting origin and its final numerical value. All suffix-write endpoints are either paid by marked stores or are among $D$. An intermediate origin obtained from a hole only needs a fresh label if the raw word is actually used for another load in that chain. This is one of the $p$ words, and its label can be reused for all resolutions, including resolutions of overlapping chains. A hole word terminating a chain needs no label to give its numerical value. Consequently a terminating continuation needs at most
$$
                  C(1+c+m+|D|+p)
$$
static probes, once the header is read, for a model constant $C$ (and a fixed controller overhead). Its native run may perform many more loads, stores, or local arithmetic steps. There is no initial probe for every hole or for every implicitly mentioned seed. The integer audit compares pointer chains with fully materialized execution, including zero overrides, address zero as a hole, and several holes on one cycle. [Independent finite replay and physical half-selection checks](../audits/many_hole_replay_audit.py) Lean proves the first-hit identity and equality of deferred and eager execution for arbitrary sequences of load times and time-indexed overriding stores. The probe count uses the static index and the native dataflow argument above. [Kernel-checked time-sensitive replay](../lean/FirstHolePointerReplay.lean)

## Transferring the static lower bound to both executions

Recall the packed construction on $s$ balanced rows of $B$ bits, where $B=\Theta(\log s/\log\log s)$. It has $N=\Theta(sB)$ physical bits, $\Theta(sB/\log s)$ database packets, $\Theta(s/\log s)$ segment-seed packets, and a single half-selection tag. Every variable packet fits in one aligned word and the variable slots can be permuted. On the half named by the tag, the query asks whether any selected entry is zero. Each eligible seed packet specifies the selected columns in a whole segment. The two actual tags differ in one physical bit.

On a fixed balanced database, install the prescribed data packet at each newly requested slot until all data packets have been read. Stop at the next new slot, supply the tag there, and place the seed packets in the other unused positions in increasing physical order. Correctness still forces disclosure with initially writable input. Before the first attempted overwrite of an unread private slot, put the tag in that very slot and complete the file identically everywhere else in the two tag choices. One half can select only ones, and the other can miss by choosing a zero in the first row of a segment. This gives opposite verdicts. The overwrite would erase the only differing word and make the two executions identical. Early halting is excluded by the same pair. Public cells may have changed before the cut; use their actual values in $f$. The construction never postulates a change to an input during a real execution.

At the master size $k$, put $M=kB$. The static row bound on balanced databases, with $S_*$ cells of $W=\Theta(\log M)$ bits, forces some all-ones query to use
$$
      \Omega\!\left(\min\{M/W,\; k/\log(2+S_*W/M)\}\right)
$$
probes. The lower bound follows from cell sampling and the projection expansion of the segment seeds. In particular it is $\Omega(M/\log M)$ for $S_*=M\log^{O(1)}M$ and $\Omega(k/\log M)$ for polynomial $S_*$. Use one first-hole orbit index at each node of the same dyadic decomposition down to $\sqrt{2k}$ rows. Input words and $H$ contribute $O(N/\log N)$ cells per node before indexing. The extra index logarithm and the number of levels preserve the near-linear-polylogarithmic and polynomial space regimes. [Row-sampling proof and parameters](near-complete-disclosure-on-one-bit-sat-pairs.md#a-static-cell-probe-bound) · [Cell-probe certificates](https://arxiv.org/abs/1404.5743)

The set of variable slots omitted in the prefix is database-dependent. Use its enumerative code and the distinguished tag index. At a node with $R_s=1+\Theta(s/\log s)$ holes this directory uses $O(R_s\log B+\log M)$ bits. It tells the query simulator exactly where to install every known reply. On one dyadic descent the directories cost $o(k/\log M)$ probes in total. They are not supplied as free advice.

Suppose at each node each genuinely opposite pair had a cheap continuation for at least one of its tags. Simulate both tags, using a cutoff on the **number of actual static probes**, not on the time when a register's eventual use as a pointer first becomes apparent. A cheap complete continuation must halt before its probe cutoff. A halt returning a miss answers the parent. A halt returning no miss reduces the question to the other child unless its result is already known. If both simulations hit their probe caps, the halves must have the same true verdict, so choose one child. No path needs both recursive calls. Local time between probes is free and both original continuations terminate on valid completed files.

For near-linear prefix storage, take a native charge cutoff $\eta sB/\log(sB)$ on $c+m+|D|$; even on that continuation $p\le R_s$. Across one root-to-leaf path the $R_s$ sum is $O(k/\log k)=o(M/\log M)$. The two simulations' probe budgets therefore total $O(\eta M/\log M)+o(M/\log M)$ including headers and $O(\sqrt k)$ direct leaf probes. For arbitrary storage take a cutoff $\eta s/\log(sB)$ on the **entire** charge including $p$. This gives $O(\eta k/\log M)+o(k/\log M)$ over the path. A sufficiently small fixed $\eta$ contradicts the applicable static lower bound. The resulting opposite pair has the claimed lower bound on both suffixes at its own size, which tends to infinity with $k$.

There is an intermediate bound as well. For fixed $0<\gamma<1$ suppose cut occupancy is at most $N\exp(O((\log N)^\gamma))$. The combined index space is at most $M\exp(O((\log M)^\gamma))$. The same proof uses cutoff $\eta s/(\log(sB))^\gamma$ on $c+m+|D|$, since the sum of $R_s$ is still lower order. All node logarithms are within a fixed factor of $\log M$. On both suffixes this gives
$$
       \Omega\left(\frac{N\log\log N}{(\log N)^{1+\gamma}}\right)
$$
without charging raw uses of the seed words as addresses.

## Why raw use of the new words matters with polynomial preprocessing

A globally correct program can make only one marked comparison and no suffix stores on the data-first, tag-then-sorted-seed completions when the prefix may take polynomial time and space. Read and validate the public bytes and canonical database packets, then precompute the answer for every legal seed value for every segment. Use the actual packed DIMACS word for segment $j$ and seed $v$ as a native address. These keys are distinct: the segment flag and the library-name fields determine $j,v$. The raw spellings occupy a high address region disjoint from the short physical input. A good seed maps to the next segment's physical slot, or to a clean self-loop if this is the last segment in its half. A seed that hits a zero maps to a miss self-loop. The two sentinels are outside both the input region and the packet-key region. There are at most $O(R_s 2^h)$ populated keys, with $h=O(\log N)$.

After the tag, validate *all* seed words by direct-address loads, unmarked under the rule above. Each has a bounded number of decimal fields. Its canonical layout, expected segment flag and allowed contiguous seed-name range can be checked with register arithmetic and loops, using parameters retained at the cut. An unexpected word or layout transfers to a general SAT solver on the genuine input. For the requested half, start at its first physical seed slot and do exactly two pointer loads per segment. One reads the literal seed word and the other follows its table entry. The self-loops make early termination unnecessary. One last comparison distinguishes the two sentinels. Thus $p$ can carry the whole lower bound with unrestricted preprocessing, even for a globally correct program. Near-linear prefix occupancy prevents using this full table in the proof. [Physical packet fields and layout](../audits/packed_row_queries.py)

The inequalities price a real suffix after many independent data words have been disclosed. They can still be attained on a family handled in linear total time. Summing charges from nested cuts would require proving that the charges correspond to distinct instructions on one complete execution.

## One physical pair for an entire roster of programs

A separate slow pair for each tested program leaves open whether their easy inputs cover each other's hard ones. Here the pair can be chosen **in common**. Fix $q\ge1$ correct total SAT RAM programs in the same physical model. At arbitrarily large $N$ there is a single opposite one-bit pair and a prefix for each program, identical on the two files, such that each program has already read at least $\lfloor P/q\rfloor$ distinct original data packets, where $P=\Theta(N/\log N)$ is their total number. It has yet to read any seed packet or the tag. On both members of this same pair **every program** incurs $\Omega_q(N/\log N)$ subsequent charge $c+m+|D|$ under the common near-linear-polylogarithmic prefix storage bound. For unrestricted prefix storage, every program incurs $\Omega_q(R)$ subsequent charge including $p$. The programs can use different read orders, cut times and private data structures. When there is more than one program, some ordinary database packets may still be unread by an individual program at its cut.

At each dyadic node allocate the same database packets to physical slots for the entire roster. Run each program until it has read $\lfloor P/q\rfloor$ different variable slots. Maintain one shared partial assignment from slots to the prescribed original data packets; keep each program's *writes* and registers private to that simulation. On an already assigned slot, return its assigned data if the program has not subsequently written there. On a new slot install the next data packet. The union of the private sets of first-read slots has at most $q\lfloor P/q\rfloor\le P$ elements. Fill unused positions with the remaining data, leaving $R$ holes, and designate any one as the tag. A correct program reaches its quota. On its own data-only prefix it cannot halt, run forever without another first read, or first overwrite an unread variable slot. For the last assertion, make that slot the tag in two opposite completions. Completeness of this argument for a given program only needs compatibility with the data that *it* has read; the counterfactual completions for that step need not agree with other programs. All actual prefixes, on the other hand, replay on the single shared final assignment by construction.

Optionally extend each private simulation until it issues its first request to $H$ and pause before returning the word. Even if these requests differ, there is only one tag in the final file. The set $H$ and its compressed directory are shared. Charge the registers, index offsets and the actual first-hole functional graph of each program separately. Copies of a physical address in different machines are different cells in the static representation. The initial tag need not be granted to a program that has yet to request it; the simulator knows its value and provides it through the overlay at the genuine load. One can also give the simulator the earlier prefix's controller directly at unit cost per register.

At each node run all $2q$ static simulations up to their respective probe caps. For the contradiction suppose every opposite pair has **at least one program and one sign** with a cheap continuation. If any simulation halts, its answer gives the same decision or one-child reduction as before. If all time out, both half verdicts agree by the supposition. Thus one root query still descends a single path. Multiplying the number of static simulations by fixed $q$ only changes constants. The negation yields one pair on which every one of the $2q$ genuine continuations is expensive.

The bookkeeping also permits a growing roster. For each master size $k$, use the same list throughout all its dyadic subproblems. Suppose $q=o(\log k/\log\log k)$, the native word-width and per-instruction arity constants are uniform, the number of starting controller words per program is at most $\log^{O(1)}k$, and the stated prefix occupancy bounds hold uniformly at all the tested sizes. Code can be known to the static simulators. Use cutoffs $\eta sB/(q\log(sB))$ for the charge excluding $p$ in the near-linear case, and $\eta s/(q\log(sB))$ including $p$ in the polynomial-space case. Even the total $O(q\sum_s R_s)=O(qk/\log k)$ cost of all private seed-reply labels is $o(M/\log M)$ in the near-linear case. Reading all controllers and directories on a path costs only a polylogarithm plus the same compressed-header bound. Summing the cutoffs over $2q$ programs and tags now gives the original contradiction. The resulting common lower bounds per continuation are $\Omega(N/(q\log N))$ and $\Omega(R/q)$ respectively, with the growing $q$ of the master problem. Constant factors between the logarithms at the master and at the resulting node are uniform.

The $1/q$ in the amount of shared disclosure is inherent if the first encounter with any hole defines the cut. Partition the variable slots into $q$ initial blocks of size at most $\lceil(P+R)/q\rceil$. A globally correct program can scan its block first and then run any SAT solver. Every nonempty $H$ intersects at least one such block, so some program encounters a hole by its $\lceil(P+R)/q\rceil$-th distinct variable-slot read. This rules out a near-complete data-only prefix for *every* member of an arbitrary roster. The construction gives a common test even as programs are added; its per-program clock bound decreases with roster size.
