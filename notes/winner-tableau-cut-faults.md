# Every clock transition is needed to refute a false final rank

The [two-rank certificate test](disjoint-winner-certificates.md) proposed finding a small unsatisfiable subset of one of two ordinary formulas. For the final-register implementation specified there, every losing rank at every eligible stage already needs at least the full native clock in distinct input clauses. This corrects the earlier description of the small-subset test as an open possibility for that implementation.

## One assignment for each omitted transition

Fix the deterministic priority program on its canonical input at scale $M=2^j$. Use the [adjacent-row compiler](packed-band-transfer.md) with $H=CM$ transitions, an absorbing halt that issues dummy memory events and preserves its registers, and a register containing the winner code. All register values in the output range are syntactically legal in this halt. The ordinary pin $o_e$ compares the final register with the eligible rank $e$. The no-award code is distinct. All equalities for other ranks and their pairwise mutual exclusions can be present. The statement allows arbitrary Boolean gate templates within a transition. Each gate used privately for testing transition $t$ belongs to that transition, with separate clause occurrences for distinct transitions. Boundary row bits can of course be shared. A final-state pin is never folded into the transition templates by preprocessing.

Let $B_t$ be the clauses for the local CPU, event and next-row check at tick $t$, for $0\le t<H$. These $H$ sets of clause occurrences are disjoint. Pick any $t$. Retain the genuine CPU rows through $t$ and the genuine memory operations **through tick $t$ inclusive**. At row $t+1$ place the halted controller with register $e$, and leave it there. All subsequent memory events are dummies. Every real read, including a read at the cut itself, has its genuine preceding value. The input initialization records are untouched. Sort these new records and choose new switches and internal gate values for the entire memory router. The permutation network can route this particular list just as it can any other consistent list. The old switch settings need not work. All gate values outside $B_t$ can now be assigned to satisfy the chronological checks, routed-record checks, final pin and rank comparisons. Within $B_t$ the computed next controller can disagree with the chosen row. This construction also works on the first tick, on the last tick, and after the true computation has halted.

An unsatisfiable subset must therefore meet $B_t$ for each $t$. This proves the $H$-clause bound. If two losing claims use disjoint variables, a satisfiable fragment from each combines to a satisfying assignment, so every unsatisfiable subset of their conjunction has the same lower bound. These conclusions are unconditional. Since $H=\Theta(M)$, the earlier proposed $O(M^{1/k^2-\epsilon})$ upper bound fails for every fixed $k\in\{1,2,3\}$ and $\epsilon>0$ at all sufficiently large scales. A SAT algorithm is free to recognize the formula, derive semantic facts about the source program, or use another representation. An axiom-count bound charges none of those operations.

The bit-length consequence survives dense variable renumbering. Any unsatisfiable subset contains an inclusion-minimal core, whose clauses are pairwise distinct after canonicalization. Otherwise a duplicate could be dropped. If $L$ clauses are necessary, at least $L/2$ of their standalone binary records have length at least $\lfloor\log_2 L\rfloor-1$, simply by counting shorter strings. With fixed-width literal indices the same bound follows from the number of different triples. Injective variable renaming preserves distinct clauses. Thus even the shortest unsatisfiable subset, re-encoded as an ordinary explicit formula, costs $\Omega(L\log L)$ bits. In this tableau $L\ge H$. This explains why trimming clauses and renumbering variables cannot make a losing instance shorter in encoded bits than its source clock. It assumes each literal record names its variable, as in the project's explicit input convention.

More generally, after the cut one may use any legal suffix that starts from the post-operation memory and ends at the pinned output. A memory-independent $q$-step return routine followed by a suitable idle halt preserves the argument for each cut with room for that routine. Long-range constraints that exclude the spliced histories require a fresh analysis. The [companion input-dependent implementation](winner-input-core.md) instead counts fixed input bits, and the [trial decomposition](private-trial-cores.md) gives a representation in which some of the same losses have short certificates.

The counting principle is the familiar fact that a core must intersect every set of clauses whose removal restores satisfiability. Local transition relations and proof-based abstractions also occur in bounded model checking. The application here identifies a disjoint repair for each tick of this particular rank encoding, including its *global* RAM consistency checks. Historical priority for that application is unestablished.
