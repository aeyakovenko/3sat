# Isolating a bounded proof with clocked negative SAT votes

A polynomial number of explicit SAT query types suffices to extract a bounded proof from collective coverage of negative files by unknown, sound voters. The program tries each individual voter in two roles. Its runtime is polynomial in the **number of voters**, even when no single voter covers all negative files. A missed deadline follows only at widths where the proof fits the prescribed cap.

## The finite search problem

Fix a satisfiable proper seed $B$ with a supplied satisfying assignment. Throughout, $g_B(Q)$ is the physical proper DIMACS extension that keeps the old clause body and appends a disjoint copy of $Q$ and a satisfiable extra clause. Its truth is exactly the truth of $Q$. All machine deadlines apply to the respective **new physical bit lengths**. Fix $m\ge1$ raw clocked texts. Each can vote NO, vote YES, or abstain at its deadline. Call a subset $H$ negative-sound if none of its members votes NO on a satisfiable file in this image. In particular the globally correct total SAT solvers form such a subset. The program receives neither $H$ nor the correct labels. [Encoding, clock, and seed conventions](proof-length-and-the-next-sat-clock-witness.md)

Let $F(x)$ be a deterministic polynomial-time test on $d\ge1$ distinguished bits, with at least one passing string. For the application $d=h^4+1$, using a last-one marker and zero padding for a literal proof of at most $h^4$ bits. The test checks the actual proof and the exact closed sentence about the current program. Write $C_x$ for an ordinary proper CNF expressing
$$
   \exists y\in\{0,1\}^d\quad F(y)\ \land\ y<_{\rm lex}x.
$$
Use one fixed, deterministic byte emitter for these files, inside and outside guest simulations. If $z$ is the least passing string, $g_B(C_z)$ is UNSAT. It is a specific physical query that can be materialized afterwards even when $z$ was unknown during the run.

For each raw voter $i$, build a proper CNF with distinguished bits $x$ whose projected solutions are
$$
 F_i(x)= F(x)\ \land\ [i\text{ votes NO by its deadline on }g_B(C_x)].
$$
Guess $x$, build the actual bytes, and run the clipped deterministic computation with its true initial input, width and multiplier. A bounded-computation encoding with fresh auxiliary variables represents this test. The inner guest only sees the comparison file. If $i\in H$ votes NO on $g_B(C_z)$, then $F_i$ has **exactly one projected solution**, namely $z$. Every other passing $x$ satisfies $x>z$, so its comparison is satisfiable and $i$ cannot reject it. Auxiliary assignments need not be unique.

## A polynomial number of parity queries

Choose the least power of two $q\ge8md$ and construct $\mathbb F_q$ in a polynomial basis. Testing monic polynomials of the requisite degree against all possible monic divisors up to half that degree costs polynomial time in $q$. Fix a nonzero binary linear functional $L$ on this field. For each ordered pair $\alpha,\lambda\in\mathbb F_q$, make a mask with coordinates $a_r=L(\lambda\alpha^r)$ for $0\le r<d$, taking $\alpha^0=1$. Keep multiplicities. For nonzero binary $v$, its polynomial $P_v(X)=\sum_r v_rX^r$ has at most $d-1$ roots. Off the roots, $L(\lambda P_v(\alpha))$ is balanced over $\lambda$. Thus every nontrivial binary character has absolute mean at most $\epsilon=(d-1)/q<1/(8m)$. A linear subspace of codimension $e$ contains at most a $2^{-e}+\epsilon$ fraction of the masks, by expanding its indicator as the mean of its $2^e$ annihilator characters. These are standard polynomial evaluation and small-bias arguments. [Reed and Solomon](https://doi.org/10.1137/0108018) and [Naor and Naor](https://doi.org/10.1137/0222053)

For every $i,a$ and bit $u$, physically issue $g_B(F_i(x)\land[a\cdot x=u])$ to every voter $j$. Encode the parity circuit and the conjunction with fresh names. For each **ordered** pair $i,j$, take all its raw NO votes as equations $a\cdot x=1-u$. Solve that binary linear system, skipping inconsistent systems and those with more than $2m$ solutions. Test each remaining solution with the original deterministic $F$. Return a string only after it passes.

**Dichotomy.** If this completed procedure returns no string, then for each negative-sound $H$, one of the following holds.

1. No member of $H$ votes NO in time on the UNSAT file $g_B(C_z)$.
2. For each $i\in H$ voting NO there, some **actually issued** UNSAT parity file for $F_i$ receives no timely NO from any member of $H$.

Indeed fix such an $i$. Its singleton projection makes exactly the wrong side $u=1-a\cdot z$ unsatisfiable at every mask occurrence. If $H$ covers every wrong side, some $j\in H$ rejects at least a $1/m$ fraction of the occurrences. It never rejects the correct side. Its equations therefore contain $z$, and the span of its mask rows has codimension $e$ satisfying $1/m\le2^{-e}+\epsilon$. In particular $2^e\le 2m$. The decoder would enumerate $z$ and return a verified passing string. This proves the dichotomy, including the empty $H$ case in the first alternative. For correct total solvers, the common missing NO on an UNSAT file is a common missed deadline. The single comparison at $z$ is an implicit alternative. Listing all $2^d$ comparison files takes no part in the native search.

A version using larger answers avoids binary linear systems at the same asymptotic cost. Choose a prime $q>md$ of size $O(md+1)$, found by trial division. For each voter $i$ and each $\alpha,u\in\mathbb F_q$, issue the test $F_i(x)\land[P_x(\alpha)\ne u]$ through $g_B$. For a singleton there is one UNSAT choice $u=P_z(\alpha)$ per coordinate. Under collective coverage some sound voter returns this symbol at $d$ distinct coordinates. Interpolate there, check all coefficients are binary, and check $F$. For arbitrary voters, take the first $d$ distinct coordinates with exactly one rejected symbol each. The same dichotomy uses these symbol queries in its second alternative.

## Explicit witnesses for every negative subportfolio

An external checker that can search finite sets can assemble at most $m+1$ files witnessing that every negative subportfolio errs somewhere, provided the procedure failed despite the existence of $z$. First compute $z$ by exhaustive verification. Remove each $i$ for which $F_i(x)$ holds at some $x>z$, retaining one such $g_B(C_x)$. This is a SAT file on which $i$ issued NO, with $z$ witnessing the comparison. For every remaining $i$ that rejects $g_B(C_z)$, its projection is now known to be the singleton $z$. Take that list of $i$'s before making any further removals. For all their parity queries on the side $u=a\cdot z$, remove each remaining voter that issued NO, keeping one such SAT counterexample per removed voter. At most $m$ voters have been removed in total.

If no survivor rejects $g_B(C_z)$, keep it as the common missed negative. Otherwise fix a surviving rejecting $i$. The remaining voters are sound on the true sides for this particular $i$. If they covered every false side, the preceding rank argument would recover $z$. Keep an uncovered false side as the common missed negative. Each subportfolio containing a removed voter issues NO on that voter's SAT counterexample. Every other subportfolio defaults to YES on the common negative. This receipt needs ground truth externally. The timed native run uses none. The extra comparisons $C_x$ with $x>z$ in this stronger, all-subportfolio receipt can require separate materialization.

## Consequence for the native program

Install this search in a new fixed program $p$ whose only return-one transition follows genuine verification of a proof of its own $J_h$, the assertion that it stays quiet through $2^h-1$ steps. Construct the program uniformly in the finite axiom-list code before fixing the theory and use the sound proof checker and syntactic extraction axiom as in the fixed-cap construction. The header in the checked sentence must name this new program. Soundness now precludes a successful return. At each valid active width with a proof inside the cap and enough time to finish the search, the dichotomy therefore supplies a common negative deadline miss for all the globally correct listed texts. [Finite reflection and the fixed header](fixed-cap-reflection-on-the-native-program.md)

For fixed $k\in\{1,2,3\}$, there are $m\le 2^{c+1}+2$ voters at a code budget $c$. The algorithm uses at most $2m^2q^2$ outer clipped runs. Formula construction, both linear algebra and proof checking, and the fixed-depth nested compilation cost $2^{O_k(c)}(h+|B|+1)^{O_k(1)}$ bit operations altogether. To see the dependence on $c$, the multiplier and word-width coefficient encoded in $c$ bits are at most $2^c$. A clipped run on $N$ bits has at most $2^c(N+1)^k$ steps, each manipulating $O(2^c\log(N+2))$ bits per word for the fixed elementary ISA. Even a linear search of previously written addresses per guest access incurs only a polynomial in these parameters. Ordinary circuit and DIMACS encodings of a bounded deterministic simulation incur a fixed polynomial overhead, including decimal variable names. The nesting depth is fixed. A native host can implement the bit computation using $O(1)$ words per tape symbol, provided its total running time and allocated addresses fit its horizon. With the small literal seeds of the tag convention, this holds for $c=o(h)$, in particular whenever $4^c\le h$ at all large widths. The latter regime also keeps the actual query lengths polynomial in $h$. This is the resource bound for the search at one active width. The cost of any separate retirement learner must be charged separately. The condition that a proof fit $h^4$ bits on each new budget remains unproved.

The [combined native program](polynomial-portfolio-search-on-the-sat-clock.md) specifies linear-in-width growing code budgets and two physical query lengths. The qualitative complexity collapse associated with logarithmic one-sided voter descriptions is already implied by the classical conjunctive reduction to a sparse set. [Arvind et al., Corollary 3.4](https://doi.org/10.1007/3-540-55719-9_72)
