# Learning linear combinations of actual SAT verdicts from local checks

**Research journal, 24 November 2026.** For $k$ clocked SAT candidates there is a suite of at most $k+1$ local CNF tests that characterizes every correct XOR of their outputs on a bounded domain. If any XOR is correct, $k$ tests suffice. The suite also yields an exclusion test on the programs' actual responses to explicit SAT instances about their own errors. A proof that every candidate pool fails that test would be a further step.

## The local suite

Let $D$ be a finite, restriction-closed domain of explicit CNFs. A terminal has a known value. Every other formula $F$ has two children obtained by fixing its first occurring variable. Both have fewer variables, and the value at $F$ is the OR of the child values. Use total clocked candidates, with timeout scored as zero. Write $v(F)=(A_1(F),\ldots,A_k(F))$ in $\mathbb F_2^k$. The prediction with fixed selector $c$ is $c\cdot v(F)$. A local test means comparing the predicted bit to the terminal bit or to the OR of the two **predicted** child bits.

Visit all nodes with children before parents. Keep an independent set of feature vectors, each paired with a label. These labels specify a unique linear functional $l$ on their span. At a terminal take its required label $b$ directly. At a branch take $b=l(v(F_0))\lor l(v(F_1))$. Both child features already lie in the span. Take one of three actions.

* If $v(F)$ is independent of the preceding vectors, retain this root and extend $l$ by $l(v(F))=b$.
* If $v(F)$ is in the span and $l(v(F))=b$, skip the root.
* If $v(F)$ is in the span and $l(v(F))\ne b$, retain this root and stop with a conflict.

Before a conflict, each processed formula's feature lies in the span and its label is its true SAT value. This follows by induction over the traversal, including the skipped roots. A selector obeying all retained local tests agrees with $l$ on the current span. At a retained branch, agreement on the previous pivots fixes both child predictions, and the local test forces the new label. Thus a conflict excludes *every* selector. If the traversal finishes, the selectors satisfying the retained tests are precisely those that are correct throughout $D$. Extending $l$ to the full vector space always gives at least one such selector. There are at most $k$ independent insertions and one conflict. This argument applies unchanged to any known bounded-fan-in gates on an acyclic domain. It avoids writing down the quadratic equations obtained by expanding OR over the binary field.

A conflict certificate lists only the retained roots in order. Its verifier recomputes the root and child tuples with the actual programs, checks the indicated span memberships, and replays the label updates. It can check each intermediate root is independent and the last is dependent with a conflicting label. Verification costs $O(k^2T(n)+kn\,\mathrm{polylog}(n+2)+k^3)$ for $k\ge1$, if $T(n)$ bounds one interpreted candidate call on each root or child, lengths are at most $n$, and restriction is quasilinear. Gaussian elimination uses $O(k^2)$ bit operations per processed tuple. The root descriptions occupy $O(k(n+\log(k+1)))$ bits with ordinary framing. For unary $n$ and polynomial evaluation clocks this puts bounded nonexistence in NP. The guarantee that a successful suite covers *all* nodes uses the exhaustive traversal. Merely checking a list of independent insertions gives no coverage guarantee.

The $k+1$ bound is sharp for suites of local tests on genuine CNFs. Use a true terminal with vector $e_1$, and $k$ tautologies $F_j=(z_j\lor\neg z_j)$ whose two restrictions both equal that terminal. Give $F_j$ vector $e_1+e_j+e_{j+1}$ for $j<k$ and $F_k$ vector $e_1+e_k$. Simple programs reading $j$ implement these votes. The resulting local constraints are $c_1=1$, $c_j=c_{j+1}$ for $j<k$, and $c_k=0$. Removing any one makes the system consistent. The corresponding disjunctive selector family can require exponentially many local tests to characterize all exact selectors even when an exact disjunction exists. ## Answering a stream with an unknown exact selector

Suppose a single selector is correct on all descendants of all queries. Start with the empty pivot ledger. On reaching a formula with feature in the span, return its ledger prediction immediately. On each other formula evaluate the local gate recursively, then insert its feature and computed bit if that feature is still independent. Recursion may already have made it dependent. Under the promise, all inferred bits agree with the same selector, by induction on the ledger updates. Both children may be evaluated, including when one already establishes the OR.

For $Q$ input roots of maximum descent height $H$, the entire stream takes $O(Q+k(H+1))$ visits at constant fan-in. A call outside the span on entry has an insertion in its subtree. Otherwise its feature would still be outside on exit, forcing an insertion at the call itself. Each of at most $k$ insertions has at most $H+1$ ancestors, so the number of expanding calls is at most $k(H+1)$. Only these calls add recursive children. Each visit costs at most $O(kT(n)+k^2+n\,\mathrm{polylog}(n+2))$ including restriction. This is a promise algorithm for an explicit menu. Establishing an exact selector for an unrestricted fast menu is the original difficulty.

## Self-queries that can exclude a whole pool

Encode the NP assertion that a pivot conflict through length $n$ exists as an explicit challenge CNF $Q(V,n)$ for menu $V$. Use a uniformly specified reduction and pad to length at least $n$. The bounded nondeterministic RAM-to-SAT reduction gives length and construction time $\widetilde O(k^2 T(n)+kn+k^3)$ with the evaluation bounds above. Let $t$ be a true terminal. If any $c$ decides SAT globally, every such challenge is unsatisfiable, so $c\cdot v(Q(V,n))=0$ while $c\cdot v(t)=1$. Consequently the observed dependence

$$
v(t)\in\operatorname{span}_{\mathbb F_2}\{v(Q(V,n_i)):1\le i\le h\}
$$

excludes **all global XOR selectors**. Gaussian elimination extracts a dependence using at most $k$ challenge vectors. Only clocked evaluations on these explicit instances are needed. This extends the positive self-query rule for a single candidate. [RAM-to-SAT reduction](https://people.csail.mit.edu/rrw/automated-lbs.pdf) · [Single-candidate challenges](checking-a-solver-with-its-own-verdicts.md)

In phase $m$ of the fixed-program construction, $k=O(m)$ trial codes have clocks $C(n+1)^d$ with parameters polynomial in $m$. For $d\in\{1,2,3\}$ choose $n=2^{\lfloor 2m/d^2\rfloor}$. Construction of the challenge and all candidate evaluations on it together take $n^{d^2}\mathrm{poly}(m)\le 2^{2m}\mathrm{poly}(m)$. The same budget permits polynomially many smaller $n_i$. Separately, one can certify all exact selectors through length $2m$ by scanning all strings through that length in order of increasing variable count, ignoring invalid encodings, and applying the traversal. The extra $O(m)$ scans ensure children are processed first. The algebraic ledger uses $O(k^2)$ bits independently of the number of formulas. [Phase budget and clock conventions](fixed-program-parity.md)

The same argument works for any explicitly evaluable feature map $\Phi(v)$ of dimension $D$, replacing $k$ by $D$ in the algebra. For degree at most $s$, take the $D=\sum_{j=0}^{\min(s,k)}\binom{k}{j}$ squarefree monomials, including the constant. All fixed-degree postprocessors of $O(m)$ programs fit the same phase overhead. One can even cover **every Boolean postprocessor** of a smaller menu. Enumerate codes of length at most $\lfloor\log_2\log_2(m+4)\rfloor$. This gives $k=O(\log m)$ programs and still eventually includes every fixed code. Index a one-hot vector by the observed tuple, so $D=2^k=\mathrm{poly}(m)$. A challenge that receives exactly the same tuple as the true terminal excludes every global Boolean postprocessor of this smaller menu, since one input requires bit zero and the other bit one under the existence premise.

There is no proof that the observed dependence must occur. In the singleton case, take a candidate that evaluates SAT exactly through a fixed cutoff $H$ and returns zero thereafter. For $n\le H$ the challenge has no conflict witness, and the candidate returns zero either by correctness or by cutoff. For $n>H$ the padding makes it return zero. Its true terminal can still receive one. This incorrect linear-time implementation evades every such challenge. Local testing does eventually expose it. A uniform way to force a dependency or another certified failure for *every* unrestricted candidate, without assuming access to the correct labels, is missing.
