# Genuine native trace differences forced by dynamic Boolean lower bounds

**Research journal, 24 November 2026.** Rewinding at the first changed input read can charge an entire suffix even if the two executions rejoin one step later. Here only slots whose native records actually differ are charged. This gives an instability theorem for every polynomial-time SAT solver on sequences of constant-word edits to fixed-size ordinary 3-CNFs. The bound concerns distances between executions on different formulas.

## Skipping unchanged instructions

Fix a deterministic word RAM with a bounded number of registers, polynomial address range and polynomial clock $L$ in a scale $m$. Use native access slots with at most one input read, work read or work store per slot. A usual instruction with a bounded number of accesses can be split into these slots by including partial results in the controller. Each trace record consists of the incoming controller, native operation, address and answer or stored value where applicable, and the next controller. Keep a single verdict emission at halt and then use a common inactive record with cleared controller. Pad both executions to $L$ in this manner. Persistent work memory can remain occupied after halt. Define $D$ as the Hamming distance of the two lists of records.

Given a maintained trace and an edit of $h$ input words, the new trace and verdict can be maintained with
$$
                    O((1+h+D)\log\log(m+2))
$$
cell probes. The word size is $O(\log m)$, with constants depending on the polynomial bounds. The initial trace and its index can be built in $O(L\log\log(m+2))$ probes up to the cost of data-independent initialization. For a public initial formula the initial contents of the entire index depend only on the scale and program. Such a table is free in the cell-probe model: represent subsequent modifications by an overlay with a presence flag, and compute the initial value of any unmodified cell using free computation. This simulator makes no claim about the uniform RAM initialization time of a freely supplied table.

Keep the old records at their time indices. Store two predecessor/successor indices keyed by (namespaced address, time): one for all old accesses and one for old work stores. Thus the work value immediately preceding any time can be found even for an address absent from the corresponding old instruction, and the next old access to any specified address can be found. The joint key universe is polynomial. A van Emde Boas index permits predecessor, successor, insert and deletion in $O(\log\log m)$ probes using polynomial space. Keep the old indices unchanged during one repair and buffer the differing records for application at the end. Trace-distance approaches to incremental computation have prior work in self-adjusting programming languages. Here the alignment is by identical native indices and the mutable RAM operations are unrestricted. [van Emde Boas, Kaas and Zijlstra](https://doi.org/10.1007/BF01683268) · [Ley-Wild, Acar and Blelloch](https://www.cs.cmu.edu/~blelloch/papers/LAB12.pdf)

At the current time maintain the new controller and a direct table of exactly those work addresses whose *current* values differ from the old run at this same time, recording the new value. Schedule the next old access to each such address, and to each edited input word. A second integer priority queue maintains the earliest scheduled slot. Empty future access lists place no appointment. Read-only input and writable work have separate address spaces.

If controllers currently agree, jump straight to the earliest scheduled slot or the end, copying the old controller at the destination. All skipped reads and writes concern matching contents and have the old effects. No skipped store can have removed a tracked difference because all accesses, including stores, to differing addresses have appointments. If controllers differ, execute the current slot immediately. At any slot being executed, resolve arbitrary new work reads by the tracked differences or the old predecessor-store index. Compare old and new events. Only the old and new store addresses, at most two, can change the difference table. For each such address compute its old and new post-values, add, change or remove its entry and reschedule its next old access. Re-arm the processed old access's appointment if the difference persists. These operations preserve the invariant for the next native time. A buffered differing emission can update the verdict by removing the old bit contribution and adding the new one.

Every visited slot whose records differ contributes to $D$. A visited slot whose records agree must have been selected by an appointment: otherwise its incoming controller already differed. An identical load from a differing address is impossible because the reply is in the record. Hence an identical visited slot is a store that extinguishes an existing work-value difference. Every such difference was introduced by a previously differing slot, and at most two new ones can be introduced per differing slot. The work-difference table starts empty on every edit. Therefore at most $3D$ slots are visited. Pending changes, live differences at the end, and all buffer/index updates can be cleaned up in $O(1+h+D)$ ordered-set operations. The bound also covers an unread edited word and arbitrary intervals of identical work occurring between actual differences.

## Consequences for actual SAT solvers

Use the feedback-linked prefix CNFs with $m$ edits, each changing $O(1)$ input words of a $\Theta(m\log m)$-bit formula. For every solver polynomially clocked on these versions the indexed simulator can emit each successive answer of the hard Boolean Group Range stream at total cost
$$
           O_M\!\left((m+\sum_{j=1}^mD_j)\log\log m\right).
$$
The public zero version is independent of the incoming stream. The Group Range lower bound therefore implies that some sequence has $\sum_jD_j=\Omega_M(m\log m/\log\log m)$. Its exponentially small success theorem also applies to sequences on which the simulator fits the paper's small-probe budget. This lower bound survives discarding *every* aligned slot whose two records are equal, including arbitrary long equal suffixes. A fixed solver already decides every single member in $O(m)$ native time on this same family. [Reduction, encoding and single-run upper bound](linked-queries-and-rollback.md) · [Alman, Wang and Yu, Theorem 1.2](https://arxiv.org/pdf/1704.06185)

For the constant-edit two-dimensional dominance encoding in the same note, suppose every insertion changes at most $\log^{O(1)}m$ aligned records of a polynomial-clocked solver. Its induced dynamic data structure has polylogarithmic worst-case update time. If all query edits changed at most $Q$ records it would have worst-case query time $O((1+Q)\log\log m)$. The dynamic parity tradeoff forces some query with
$$
                    Q=\Omega_M\!\left(
                        \frac{(\log m)^{3/2}}{(\log\log m)^4}
                    \right).
$$
In particular a uniform $O(\log m)$ bound on the number of changed records per operation is impossible. This is a discrepancy between two actual native traces, not the time needed to read one static input. The estimates supply an explicit behavioral condition for conversion to an online lower bound. They do not imply that an unrestricted solver meets such a condition merely by running quickly. Priority of the exact native bound remains unverified.
