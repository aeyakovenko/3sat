# Checking a RAM history by the addresses touched in each phase

**Research journal, 2026-11-24.** In the earlier block test the proof describes every intermediate layer of a sorting network over the RAM's memory events. Here it suffices to describe the chronological rows, the phases of that chronology, and the address sets touched in each phase. The number of distinct addresses can reach the time bound. A stronger certificate reduces the number of nested SAT calls, but constructing that certificate in general would yield exact counting.

## Only linearly many pairs of phases need to communicate

Use the normalized T-row RAM tableau in [the earlier simulation](history.md), with zero initial memory, explicitly initialized input, and constant many registers. Inert steps can be given a dummy write of zero to one reserved address. Each row now has one address, a read/write type, and the word observed on a read or installed on a write. This word is the value at that address after the step. Let consecutive nonempty phases partition the time indices. Guess their endpoints and, for each phase p, a circuit Wₚ mapping time to a complete row. Guess a sorted list of disjoint, nonempty address intervals for each phase whose union Sₚ is its *exact* set of visited addresses. Use half-open intervals and sufficiently many index bits for the upper endpoint. Let h be the number of phases plus the total number of listed intervals, and s bound each circuit's gate and interface size, with logarithmic overheads suppressed below.

Sweep the phases in order. Maintain the label of the most recent phase covering each address, initially a special zero-memory label. For each interval I of the new phase, report the current constant-label fragments of I, then overwrite I with the new label. The total number of reported fragments is O(h). Each update splits at most two old pieces at its endpoints. The pieces it reports are all deleted, and its insertion and these splits have increased the total lifetime count of pieces by at most a constant. Charge each reported piece to its deletion. A balanced ordered dictionary supports the entire sweep in O(h log(h+2)) word operations, including the reports. This argument allows a phase to intersect many earlier phases. Disjoint intervals from the same phase cannot accidentally communicate with one another.

On each reported fragment we now know exactly which earlier phase contains the previous event for the *first* access to each address in the current phase. Within a phase the order of visits can be arbitrary. Each access is checked against its immediate predecessor at that address. The first access in the whole execution uses initial zero. Chronological register transitions and adjacent phase endpoints are checked separately. These conditions imply correct unrestricted memory semantics by induction in time.

## Two ways to find the predecessor

Assume an O(mᵈ) deterministic solver for SAT on m encoded bits. The first method uses the row circuits alone. Check that every address of Sₚ is visited and that no row visits an address outside it. For an interval missing a visit the error has the form ∃a in I ∀t in phase p, addr(t)≠a. For an outside visit, check each gap between listed intervals, including the end gaps, for a row whose address falls in that gap. Both tests take only O(1) copies of Wₚ per predicate.

Within one phase a bad read has witnesses u<t at the same address, with a wrong value and with no visit to that address in between. For a reported overlap of earlier phase q and current phase p, guess a read at t in p and a row at u in q at the same address in the fragment. Require their values to disagree, and universally check there is no earlier visit in p before t and no later one in q after u. The zero-memory fragment needs just the first-visit test and a nonzero read. Every error predicate has at most an existential block followed by a universal block. Implement the inner search for a counterexample by one SAT call and complement its bit. The outer nondeterministic search is then reduced to a second SAT call by the quasilinear RAM computation encoding. All phase endpoints, the relevant fragment, and the one or two circuits are constants for this query. The resulting nondeterministic simulation, including guessing the certificates, takes

    Õ(n(s+1) + h(s+1)^(d²))

for a fixed polynomial clock T on inputs of length n. The n(s+1) term covers the actual input initialization writes. Phase endpoints for those writes can be found with logarithmic overhead. The tilde covers powers of log T and the constants of the fixed simulation. The standard nondeterministic simulation on multitape machines also incurs a polylogarithmic factor. On a fixed unary input with a succinct initialization convention, direct universal tests can check those writes.

The second method gives a single SAT exponent. In each phase supply two more circuits, of size at most s. Pₚ(a) counts the phase's events at addresses strictly below a, and Jₚ(t) gives the zero-based number of earlier visits to addr(t) in the phase. Require Pₚ(0)=0, Pₚ(U)=length(p) at the address-universe endpoint U, with values in the indicated range. Check Pₚ(a+1)>Pₚ(a) in each declared interval and equality on each complementary gap. For every row t with address a require

    0 ≤ Jₚ(t) < Pₚ(a+1)−Pₚ(a).

Check distinctness of (a,Jₚ(t)) for distinct rows, and strictly increasing ranks for time-ordered rows at a common address. The total number of permitted pairs is length(p) by telescoping. Injectivity therefore ensures coverage of every pair and correctness of both functions. Each failure has an existential witness. Now last, first and consecutive visits are recognized by their ranks. Guessing two rows suffices for every bad read on a reported fragment, even if finding the inverse map from a rank to a time is computationally hard. All tests are single explicit SAT calls on formulas of Õ(s+1) bits. The simulation time becomes

    Õ(n(s+1) + h(s+1)^d).

A fixed positive margin below the clock of an appropriate hierarchy verifier would suffice for a contradiction if certificates at those parameters existed on all its accepting inputs. These are sufficient conditions on a computation, with no space cap. The precursor is the general RAM method of sorting all accesses by address and time. Here interval overwrites identify exactly which pairs of phases have to be checked. [Williams, RAM computation reductions](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf) · [Previous block test](history.md)

## Remove the counting requirement with dyadic emptiness certificates

For each phase guess a circuit Eₚ(a,v) for the statement that address a occurs at some time in dyadic interval v of a balanced tree on all time indices. Pad to a power of two and treat out-of-phase leaves as inactive. Check two identities for every address and node. At a leaf its bit must equal the address test on Wₚ and the phase-membership test conjoined. At an internal node its bit must equal the OR of its children. A single SAT query searches for either error. Induction gives the exact occupancy bit on every node. Testing an arbitrary interval of times now takes O(log T) dyadic queries to Eₚ. In particular, the rank-free tests for first, last and consecutive visits in the first method all have existential counterexamples once Eₚ is supplied. One test per listed address interval or gap also verifies its membership bits against Eₚ at the root.

If r bounds the size of each Eₚ, this gives a third simulation time, Õ(n(s+1)+h(s+r+1)ᵈ). It eliminates the need for counts or an inverse address map. The circuits are extra certificate material. Their mere polynomial existence for arbitrary small address circuits is a requirement that already follows from SAT∈P.

More precisely, consider the assertion that all Boolean address circuits C mapping binary times to binary addresses have dyadic occupancy circuits of size polynomial in their full description length, with one common polynomial. This assertion is equivalent to NP being contained in P/poly. In the forward direction take a polynomial-time NP verifier with fixed-length padded witnesses. At each input length build C on times (x,u) which emits (1,x) if the verifier accepts u for x and a dummy tagged zero otherwise. The root occupancy bit at (1,x) decides membership for that length. In the reverse direction the language of tuples (C,a,v) for which some time in v maps to a is in NP. Polynomial-size circuits for that one language yield the desired occupancy circuits by substitution, padding valid query descriptions to one fixed length per C. Neither direction assumes an efficient inverse.

Thus a hypothetical quadratic or cubic SAT solver *already implies* polynomial-size dyadic summaries for every polynomial-size address circuit. This is a positive transfer from decision SAT. Its exponent and the sizes of the chronologies matter: polynomial in s need not fit h(s+r+1)ᵈ below T. For an explicit upper bound, run the assumed SAT solver on the formula asking for a time in the dyadic range. A polynomial-clock RAM has a polynomial-size Boolean circuit simulation, for example by using a multiplexer over all previously written words at each read. This gives r=s^{O(d)} with polynomial factors in log T absorbed, without claiming that checking a guessed RAM tableau is the same as computing its output by a quasilinear-size deterministic circuit. When s is polylogarithmic in T this method certifies each phase with polylogarithmic overhead. A proof of the needed tradeoff between the number of phases and the actual chronological row complexity is still missing.

## Try to force fragmentation, then change the phases

Take 2ᵏ addresses labeled by k bits. In phase j visit all addresses with bit j equal to one. Even a freely chosen global reordering of addresses leaves Ω(2ᵏ) intervals in total for those k prescribed phases. Between each two adjacent distinct labels in the order, some coordinate changes. A set covered by r intervals contributes at most 2r boundaries. Thus the sum of the interval counts is at least (2ᵏ−1)/2. This approaches linear in the total number k2^(k−1) of events up to a logarithm.

Merge the phases and that obstruction disappears. Visit the addresses of each j in increasing order. One phase now has support [1,2ᵏ), with multiplicity popcount(a) at address a. The time index gives j and the address obtained by inserting a one at bit j of the within-phase offset. Its visit rank is the popcount of a's bits below j when the phases proceed by increasing j. The cumulative count below a is the sum over bits i of their numbers of ones in [0,a), obtained from complete cycles of length 2^(i+1) and one partial cycle per bit. All three functions have circuits of size polynomial in k. This rules out using fragmentation at a designated partition to infer hardness for the prover, who gets to choose the partition.

## Test the cost of constructing ranks

Already for addresses 0 and 1, consider this universal claim: each Boolean circuit C on k bits, of encoding length L≥k, has polynomial-size phase rank and count circuits, with a common polynomial bound, for the trace consisting of one visit to each address followed by visits to C(t) in increasing order of t. Here the time range has 2ᵏ+2 rows and the support always is [0,2). No RAM-specific instruction verification is needed in this test.

Under SAT∈P the claim is equivalent to every #P function being computable in deterministic polynomial time. In the forward direction, guess and verify these circuits by the preceding injectivity, ordering and endpoint checks. Input and output indices have O(k) bits. With a fixed polynomial size cap, existence of a good completion of a partial circuit description is in the second level of PH. Under SAT∈P it is in P. Recover a passing description a bit at a time. Subtract one from the certified multiplicity of address 1 to obtain #CircuitSAT(C). Parsimonious circuit encodings give the same conclusion for #P functions. In the reverse direction the rank of t is the number of earlier time indices u with C(u)=C(t), with the two fixed visits treated separately; the endpoint counts are of the same form. These are #P counts on polynomial-size binary inputs. A polynomial-time counting algorithm can be unrolled to obtain the claimed circuits with C fixed. The claim concerns all circuits and a uniform size bound. Proving such ranks small for one chosen hierarchy verifier could be easier.

For the two-address example the first simulator needs no ranks or counting. Its nested tests certify memory semantics directly from the chronological address and value circuits. The unresolved task is to get the required joint bound on h and s on actual hierarchy instances. In particular, a short program for a RAM computation does not give a short circuit for its row at a binary time index. [PhaseAccess.lean](../lean/PhaseAccess.lean) verifies the equivalences used to identify adjacent visits within a phase, adjacent visits in distinct phases and the first visit at an untouched address. It also checks that the local OR identities recover true dyadic occupancy. [phase_experiment.py](../audits/phase_experiment.py) matches the sweep against chronological predecessors on all 27,993 combinations of nonempty three-address traces of length at most six and their consecutive phase partitions. The sweep bound, certificate sizes, counting equivalence and simulation times are manuscript arguments. Priority of these particular formulations has not been established.
