# Reading any satisfying assignment on a positive hierarchy family

**Research journal, 24 November 2026.** If explicit SAT takes deterministic time $O(N^d)$ on the packed RAM for a fixed rational $d\ge1$, infinitely many satisfiable 3-CNFs of encoded bit length $N$ have the following property. For **every** satisfying assignment, a fixed evaluator returning its bits by variable index needs advice length plus worst query time at least $N^{1/d}/\operatorname{polylog}N$. The evaluator can consult the original formula at each query. Its string may be chosen after the whole assignment is known. A fixed universal evaluator can charge the program in the string. The hard formulas come from a family with a word generator using only a binary length parameter. Membership of that length in the positive subfamily need not be easy.

The circuit-only result at quadratic and cubic SAT exponents already appears in the [local clauses and witness circuits argument](succinct.md). Here a read of the actual formula and a query to an indexed advice array are native operations, with the RAM's ordinary writable memory available during the query. This formulation gives a running-time and memory tradeoff for the positive executions of a search printer. The proof also works if unsatisfiability of an explicit formula of length $m$ has a sound nondeterministic certificate within $O(m^d\operatorname{polylog}m)$ RAM steps. The fixed reference can run longer on irrelevant branches when a suitable clock and a timely authentic branch are known on all negative instances. [Williams on verifying succinct witnesses](https://www.cs.cmu.edu/~ryanw/acc-lbs.pdf) · [Murray and Williams on easy-witness hypotheses](https://doi.org/10.1137/18M1195887)

## The positive hierarchy input

Take an integer $D>d+1$, $R=n^D$. The unary nondeterministic time hierarchy gives a fixed multitape language $L\subseteq\{1\}^*$ in $\operatorname{NTIME}(R)$ outside $\operatorname{NTIME}(R/\log(n+2))$. Apply Seiferas–Fischer–Meyer Theorem 5 with the identity real-time countable function. Its rounded inverse is the identity, and the smaller clock at $2n$ is $o(R(n))$. A fixed constant multiplier on the upper clock suffices for all positive lengths. Simulate the fixed acceptor by a nondeterministic RAM with a tape-head position and memory bank per tape, and encode bounded acceptance by the [local packed formula](packed-band-transfer.md). Allow the ordinary zero-initialized tape convention and read-only unary input or initialize the bounded public input explicitly. The formula $F_n$ has $N=\Theta(R\log^3 R)$ bits after regular padding. The uniform layout generates its clauses or input words from $n$ in $\operatorname{polylog}R$ time and setup. The unary tape input bits and end positions have a direct test from $n$. Positive lengths are exactly those of the hierarchy language. [Seiferas, Fischer and Meyer](https://doi.org/10.1145/322047.322061) · [Jahanjou, Miles and Viola on local reductions](https://arxiv.org/abs/1311.3171)

For a positive length, suppose some indexed witness uses $s$ advice bits and query clock $q$. Guess the string, its length, and the clock. A bounded evaluator defines one bit per variable on all guesses, with a default at timeout. A defective clause can be recognized nondeterministically by choosing its index, generating its signed names, and querying all three bits of this same proposed assignment. The evaluator's accesses to $F_n$ obtain locally generated true words. Each query starts with blank scratch. Construct an ordinary explicit SAT formula for this defect machine, using the guessed string and short length parameters as its physical public input. Its bit length and construction time are $(1+s+q)\operatorname{polylog}R$, including the public data, bounded interpretation and local generation. Certify that this defect formula is unsatisfiable with the reference machine. This accepts the source only if the proposed assignment satisfies every clause. In particular a claimed computation need never be authenticated as the actual history of a particular search printer. [Public-input compilation](materialized-input-census.md)

To track the logarithm, set an overall branch budget $s+q\le \lfloor R^{1/d}/\log^A R\rfloor$ with sufficiently large fixed $A$. All overheads in encoding, reference clocks and timing the verifier, apart from the power $d$, cost fixed powers of $\log R$. Computing rational power thresholds on logarithmic-bit integers costs $\operatorname{polylog}R$. The resulting nondeterministic RAM can be simulated by a nondeterministic multitape machine with polylogarithmic time overhead plus $n\operatorname{polylog}R$ for the input. For this, guess the chronological trace, verify native instructions with logarithmic-bit arithmetic, and sort copies of the $O(1)$ access records per step by bank, address and time using tape mergesort. Adjacent records enforce the initial values and every subsequent load. A public input initialization bank also fits this cost. Clock-bounded guesses prevent a malformed transcript from exceeding the budget. Choosing $A$ large enough gives total time $O(R/\log(n+2))$. Eventual existence of such a witness at every positive length would recognize $L$ in its excluded time bound, hardwiring the finitely many exceptions. This proves the claimed bound on infinitely many positive inputs. In particular the quadratic and cubic hypotheses give numerators $\sqrt N$ and $\sqrt[3]N$ respectively. The proof establishes the conclusion for every assignment on each hard positive instance.

## Turning a deterministic witness stream into indexed access

A witness printer is a deterministic RAM that marks completion of its output and, at the first completion marker on each satisfiable input, has printed a complete satisfying assignment. Count work configurations before each step through completion. Let $S_t$ be the bit length of an encoding of all registers, control, and nonzero work-memory addresses and values at time $t$, excluding immutable input and write-only output. Put
$$
 K=\sum_{t<T}(1+S_t).
$$
The same exponent results hold if counting nonzero words and then paying logarithmic factors for addresses and values. Bounds on an alleged cheap run are polynomial in $N$. The deterministic state includes anything the machine can use from past output. We first take the specified output format to be consecutive bits in variable order, optionally packed into words.

For integer $b\ge1$, select a least-cost configuration in each complete disjoint internal time window of $b$ steps. Include time zero for free, and use the end of the run as a terminal bound. The gaps are at most $2b$ and the sum of the internal checkpoint sizes is at most $K/b$. Store each configuration, its time, the number of output bits already emitted and record offsets. The directory costs $O((1+T/b)\log N)$ bits. For a specified output bit with zero-based index $i$, binary-search for the last checkpoint whose output cursor is at most $i$. Run its next segment to reach the bit. Equal cursors and empty-output segments are harmless. A packed chunk can include the queried bit between successive cursors. Initialize the selected sparse checkpoint in time proportional to its encoding length by writing the listed entries to a blank bank. On an honest chart this cost is at most the total checkpoint length. The description and worst-case query time together are
$$
 O\big((1+b+K/b)\operatorname{polylog}N\big).
$$
At $b=\max(1,\lceil\sqrt K\rceil)$ this gives $\widetilde O(1+\sqrt K)$ for the combined cost. [Sparse window bounds in Lean](../lean/CumulativeSnapshotCuts.lean) · [Output cursors, named slots and pins in Lean](../lean/PositiveWitnessSlots.lean)

Fix one universal evaluator for the hierarchy family. On its hard positive instances, every fixed correct ordered printer therefore has $K\ge N^{2/d}/\operatorname{polylog}N$ for all sufficiently large members of that same family. Indeed, the printer code is constant advice, and a run with superpolynomial $K$ already meets the bound. Every hypothetical cheaper run has the polynomial clock needed by the checkpoint accounting. Constants can depend on the fixed printer. In particular if SAT has a linear-time reference, an ordered printer that itself takes $O(N)$ steps on positive instances requires $N/\operatorname{polylog}N$ encoded configuration bits on average on this common positive family. For fixed native operations and logarithmic words, a linear run holds at most $O(N\log N)$ such bits at any instant. It follows by averaging that at least an inverse-polylogarithmic fraction of the steps have $N/\operatorname{polylog}N$ configuration bits, with a possible increase in the power of the logarithm. This conclusion concerns algorithms actually producing a witness.

The same **positive time-hierarchy consequence** holds for a printer emitting $(i,\mathrm{bit})$ records in arbitrary order, one per variable. In this case the theorem need not give a fast deterministic lookup for the stream in the supplied order. Guess instead the cut chart with the emission counts of each segment and the public total variable count $V$. The first cursor is zero, the final one is $V$, and cursors must be nondecreasing. Totalize every segment replay from its claimed state under the time cap, with a failure flag on formatting errors. An existential defect can exhibit a segment emitting a different number of records from its prescribed count, an ill-formed or out-of-range variable name, or two different slots with the same name. Guess segment IDs and within-segment slots to obtain the needed records, replaying constantly many segments. If these tests all pass, the $V$ records from all segments give a permutation of the $V$ variable names. A false clause can now be exhibited by its index and three record slots returning the required names and falsifying all its signed literals. The same slot can serve repeated literals. These tests have one existential block. Guessing the chart and certifying absence of all such defects accepts only on a genuinely satisfiable source, even if successive claimed starting configurations do not match. An honest chart for a true output passes them. Its size and defect-check time are each $\widetilde O(1+\sqrt K)$.

Consequently, if every satisfiable formula has $K=O(N^c)$ for this deterministic printer and the reference UNSAT certificate time exponent is $d$, we must have $cd\ge2$. Otherwise the same one-call simulation for $L$ fits its excluded clock. A printer with this positive cumulative bound also gives an all-input SAT decider within $O(N^c\operatorname{polylog}N)$: stop the printer at its implied time cap, save the marked output in external work memory and check names, completeness and clauses before accepting. Malformed outputs or failure to finish within the cap give a negative verdict. On dense explicit encodings this validation is quasilinear in input plus output length. One can first rename just the occurring variables densely in quasilinear time if the input convention allows additional unused names. Thus $c<\sqrt2$ is excluded without an assumed reference machine. A stronger cumulative bound from an additional counter maintained on false-input runs is derived in the [positive-output watchdog argument](positive-output-watchdogs.md). No efficient deterministic witness printer follows from the mere semantics of a decision algorithm. Naik, Regan and Sivakumar distinguish several notions of search-to-decision reduction, including one allowing a general witness relation different from an actual SAT assignment. [On Quasilinear Time Complexity Theory](https://cse.buffalo.edu/~regan/papers/pdf/NRS95.pdf)

## The same-sign argument for decision traces

The positive hierarchy construction applies to an ordinary deterministic sound SAT signal that eventually occurs on every satisfiable input. For the cumulative bound guess full configurations on the sparse cut chart and require the real initial state, valid controller transitions, and the terminal signal. An existential defect can replay one segment and challenge any address at its end against the next claimed memory. Unqueried addresses at this particular segment still require this endpoint check. For the last segment verify the signal directly. With all challenges passing, the cut states are the true ones. Thus again $cd\ge2$ if $c$ bounds positive cumulative cost and $d$ bounds the reference. This test uses the whole claimed trajectory where the required output is a decision bit.

There is a positive-input graph tradeoff as well. Let $E$ be time to a genuine positive signal and $h$ the largest clique-minor order of its native chronology-plus-producer graph. Allow the value-preserving choice of earlier write used in [the separator proof](slab-product-tradeoff.md). If $(1+E)(1+h)=O(N^u)$ on positive instances, take $b=\lceil N^{2u/3}\rceil$ as the component cap. The cut set has $O(1+N^u/\sqrt b)=O(1+N^{2u/3})$ instruction records. A single existential defect checks for a bad pair of reconstructed components, including the sign of the terminal verdict. Its public input and time cost are $N^{2u/3}\operatorname{polylog}N$ on an honest chart. A reference of exponent $d$ would recognize $L$ too quickly when $2ud/3<1$. Independently, $E=O(N^u)$ on all positives allows a timeout to serve as the general deterministic reference with $d=u$ up to harmless logarithms. Thus **every $u<\sqrt{3/2}$ is excluded on positive runs** without an external SAT hypothesis. The argument uses the product on those runs only. An arbitrary linear-time RAM can have $h$ of order $\sqrt N$, so this does not give a pure time bound. Priority for these positive-input tradeoffs is unresolved.

## Short descriptions of the actual positive-run memory

Fix a deterministic RAM $M$ with a sound positive signal on every satisfiable formula and a fixed deterministic indexed memory decoder $U$. Let $S_t^{U}$ be the minimum length of a string from which $U$, given the true explicit input, the step number $t$ and a work address, returns the actual memory word at that address immediately before step $t$. Require a worst-case $\log^a N$ query clock, for a fixed $a$, on every modeled address. Include all work banks, and count registers and control separately as $O(\log N)$ bits per selected checkpoint. Different descriptions may be chosen for every time and input by arbitrary preprocessing. If no such description exists, take $S_t^U=+\infty$. A universal decoder can support both a literal addressed array and sparse-list lookup, charging the encoding and program. The run ends at the first sound positive signal. Define its cost by

$$K_U(F)=\sum_{t<T}(1+S_t^U).$$

**Positive-signal bound.** With an UNSAT reference of exponent $d$ as above, infinitely many satisfiable $F_n$ in the unary hierarchy family satisfy

$$K_U(F_n)\ge N^{2/d}/\operatorname{polylog}N.$$

In particular there is no positive-input upper bound $K_U=O(N^c)$ with $cd<2$. This charges independently chosen descriptions of the actual memory, including on runs with large physical workspace. The exponent on the logarithm can depend on the fixed programs, reference clock, and decoder clock.

To prove this take the sparse temporal cuts above with weight $1+S_t^U$ in place of the raw memory size. Guess each selected description, controller, time, clock and offsets. Include the true initial state and require a terminal positive signal. To replay a segment, start with a new initially blank table of *writes performed since that segment's beginning*. Mark each written address explicitly even on a write of zero. A subsequent load first probes this table, then, if untouched, calls $U$ on the segment description and true input word generator using fresh scratch. A separate tag or touched-address list can clear scratch within the query bound up to polylogarithmic factors. Thus a length-$2b$ segment costs $O((1+b)\operatorname{polylog}N)$, regardless of how much physical memory was live at its beginning. Malformed or timed-out decoder calls can be given a default so each string defines an entire candidate memory function. At a shared cut one existential challenge chooses a work bank and *arbitrary* machine address and compares the segment's current word there with the next description's word. Comparing controllers checks the other part of the state. Finite polynomially bounded runs have $O(\log N)$-bit program-specific addresses. This test covers cells that neither neighboring segment touched. An induction from the actual initial state makes the terminal signal sound when no challenge succeeds. The last segment checks the actual signal. The authentic cuts pass every challenge.

The defect verifier has public data and time $O((1+b+K_U/b)\operatorname{polylog}N)$, also charging the directory of $O(1+T/b)$ entries since $T\le K_U$. If $K_U$ is finite and below the displayed target divided by a sufficiently large log power, choose $b=\max(1,\lceil\sqrt{K_U}\rceil)$. The reference and tape simulation for the unary hierarchy then yield acceptance inside its forbidden clock. If this occurred at every sufficiently large positive length, finite hardwiring would contradict the hierarchy. For an ordered witness printer, the same compressed segment replay gives a bit evaluator without requiring endpoint checks, and the indexed-witness theorem gives the bound on its common hard positive family. Named-slot printers can instead use the existential slot and clause checks above.

An elapsed-time cutoff on all positive inputs bounded by $K_U=O(N^c)$ supplies a deterministic SAT decider in $O(N^c\operatorname{polylog}N)$ for either a sound signal or a complete witness printer. Hence $c<\sqrt 2$ is excluded even without a separate reference. Under genuine linear-time SAT the positive-signal bound is $K_U\ge N^2/\operatorname{polylog}N$ infinitely often for **every fixed** sound SAT solver and polylogarithmic decoder. If that solver also takes linear time, actual positive-run snapshots on these inputs have *average* minimum description length $N/\operatorname{polylog}N$. If the decoder supports literal sparse-memory lists by binary search, each minimum is at most $O(N\log N)$ for a linear run. Therefore at least an inverse-polylogarithmic fraction of its steps require $N/\operatorname{polylog}N$ advice bits; the powers of the logarithm may increase. No bound on physical workspace was imposed in deriving this conditional conclusion.

Even the sound-signal statement admits common hard lengths for all fixed pairs of programs and polylogarithmic decoder clocks (with pair-specific powers of the logarithm). For a finite list, the hierarchy verifier guesses which sound machine and decoder to use and runs its individual timed chart check. Soundness holds on every branch. Choose each member's logarithmic threshold with enough spare slack to give time $o(R/\log n)$ on the honest short-chart branch; hardwiring a finite choice costs only a constant factor. If every sufficiently large positive length admitted a cheap chart for *some* member of this finite list, this verifier would decide the excluded language too fast. Hence there are arbitrarily large positive lengths hard for every member of each finite list. Order the countable set of the sound pairs externally, select an increasing hard length for each prefix, and take the resulting common subsequence. This last selection asserts existence and does not require an algorithm for recognizing sound RAM programs.
