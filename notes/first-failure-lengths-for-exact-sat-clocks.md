# How long can the first failed SAT clock test be hidden?

Fix $k\in\{1,2,3\}$. In this note SAT and its deadlines refer to decision on the tested domain of valid proper DIMACS 3-CNFs. A finite description $d=(P,D,C)$ specifies a native deterministic RAM program, a positive integer word-width coefficient and a positive integer deadline multiplier. Let $b_k(d)$ be the least encoded bit length of a proper DIMACS 3-CNF on which $P$ gives a wrong verdict or fails to return the correct one within $C(N+1)^k$ steps. Leave $b_k(d)$ undefined for a description that passes every test. Define

$$ H_k(s)=\max\bigl(\{0\}\cup\{b_k(d):|d|\le s,\ b_k(d)\text{ defined}\}\bigr). $$

**First-failure dichotomy.** If SAT has no deterministic $O(N^k)$ solver in this RAM model, $H_k$ is computable. If SAT has such a solver, $H_k$ eventually exceeds every total computable function. In the second case the lower bound already holds for one fixed program template with one varying integer literal, one common word-width coefficient and one common deadline multiplier. Every instantiated program decides SAT correctly. Its only possible missed deadline is on a single uniquely satisfiable file. Even its worst-case running time is bounded with a larger coefficient common to the whole family.

Thus a computable upper bound on the lengths needed to expose every failing finite description is equivalent to the sought time lower bound. Requiring the function to flag every *actually failing* description matters. A finite physical suite can test each machine without providing any decision about the existence of an unobserved failure. Previous [finite exhaustion with a universal interpreter](anchored-interpreter-for-ram-exhaustion.md) bounds how many descriptions remain after one deliberately chosen file. The result here concerns the largest least failure when passing descriptions, if any, are omitted.

## Computing the cutoff in the exclusion case

For each syntactically valid description of at most $s$ bits, enumerate proper files by nondecreasing bit length. Obtain their exact labels by exhaustive assignment to the occurring names and simulate the specified RAM for the displayed finite deadline. The word widths, immediate truncations, addresses, and each transition are effective, irrespective of the verifier's own runtime or space. In the exclusion case every search terminates. Taking the maximum returns $H_k(s)$. In particular this procedure supplies a length bound for all globally correct solvers in the census too. It never needs to decide in advance which programs are globally correct. A total solver with an asymptotic $O(N^k)$ bound meets an all-input deadline of this form after raising its multiplier on the finitely many small inputs. [Finite program quantifiers](bounded-ram-programs-and-separate-sat-witnesses.md)

## One fixed native guard with a common deadline

Suppose $B$ decides SAT within $C_B(N+1)^k$ at its own width $w=16\lceil D\log_2(N+2)/16\rceil$. Retain that width and the original input layout. For $t\ge1$, define exactly one byte string $F_t$. Its header declares $3t$ variables and $7t$ clauses. For $i=0,\ldots,t-1$ use the ordered triple $(3i+1,3i+2,3i+3)$ and include the seven sign patterns whose falsifying triples are different from $(1,1,1)$, in lexicographic order of the falsifying triple. Use decimal tokens without leading zeroes, one ASCII space between tokens, and one newline after each line. All rows have three distinct variables, no rows repeat, and the all-ones assignment is the unique model. Write $N_t=|F_t|$ in bits. These lengths increase strictly, satisfy $N_t=\Theta(t\log(t+2))$, and exceed $8(2t+2)$.

A fixed read-only recognizer checks this exact format in $O(N)$ operations and a constant number of registers. The header supplies the number of triples through its variable count divided by three, with an exact-divisibility check. One may instead count completed triples while scanning and compare both header counts at EOF. For this latter implementation each input number is accumulated in two words and rejected as soon as it exceeds $N$ before another digit is read. Multiplication of the preceding accumulator by ten needs only bounded shifts and adds with carry. A missing byte, surplus byte or noncanonical representation fails the recognition. The packed-byte cursor can move forward with a word pointer and an intra-word offset. A mismatch enters $B$ with its public registers and input intact. On a success the verdict is already known to be YES, so subsequent simulation may reuse the memory occupied by the file. [RAM conventions and fixed-control interpretation](constant-instruction-interpreter-and-size-induction.md)

Fix a deterministic universal tape machine $U$ with a finite transition table. Its input $u$ is stored in a single native immediate $e(u)$. Encode the bits low pair first by `01` and `10`, followed by `11`. The encoded length is $L=2|u|+2$. On $F_t$, decode at most $w/2$ pairs. A missing terminator returns YES immediately. For a genuine $e(u)$ the terminator is visible exactly when $w\ge L$. On visibility set $a=2^{L-1}$, which fits in one word, and return YES if $t<a$. Otherwise run the first $h=t-a$ transitions of $U(u)$, detecting a first halt precisely at the last transition, with the initial state checked when $h=0$. This is a bounded simulation of **universal machine transitions**. Its per-transition constant is independent of $u$. Any overhead of interpreting the task encoded by $u$ is already part of the $U$ transition count. At $t\ge a$ the bound $N_t>2t$ guarantees visibility of the entire literal. Consequently, if $U(u)$ first halts after $h_u$ transitions, exactly $F_{a+h_u}$ triggers. A nonhalting $u$ never triggers.

Word width can be recovered in $O(w)$ steps if needed. Decode into a register or private cells only after recognizing $F_t$. On the simulation arm $|u|\le t$ and $h\le t$. A fixed one-sided universal tape uses at most $|u|+h+O(1)$ cells through this time and each head movement, symbol update and finite-control transition costs $O(1)$ native steps. Explicitly clearing a sufficient interval before loading the initial tape costs $O(t+1)$ and fits the address space. Any finitely many endpoint conventions can be fixed directly. This accounts for finite input memory, blank initialization, code visibility and the parse. It gives a constant $C_*$ bounding every nontriggered run by $C_*(N+1)^k$, independent of $u$. Choose it before installing the triggered branch. Fixed finite-control transfer does not require a scan of program text.

On the trigger, execute strictly more than $C_*(N+1)^k$ instructions, then return YES. A fixed number of copies of $k$ nested loops of $N+1$ iterations implements the delay using $k$ word counters. It requires neither a register capable of storing $N^k$ nor extra addressable memory of that size. All triggered runs still cost at most $C'(N+1)^k$ for another common constant $C'$. Hence every program is globally correct and the deadline $C_*$ has exactly the claimed failure set. The constant $C_*$ need not be small or prescribed in advance. For every larger prescribed multiplier one can enlarge the delay in the template accordingly.

## Eventual domination and the exact index set

Let $f$ be any total computable function. For each integer $s$ choose a universal input $u_s$ containing a fixed algorithm for $f$ and the self-delimiting binary numeral for $s$. It computes $f(s)$, executes at least $f(s)+1$ extra transitions and halts. It has $O_f(1+\log(s+2))$ bits. Use a conventional effective universal encoding with a fixed interpreter prefix and literal data. Ordinary binary encodings of the fixed template, its width, its common multiplier and its varying integer immediate take $O_f(1+\log(s+2))$ bits altogether. Thus they fit within $s$ for **every sufficiently large $s$**. The first failed file is then longer than $f(s)$. This is the busy-beaver growth argument, applied to a positive file of a globally correct SAT program. [Radó, *On Non-Computable Functions*](https://doi.org/10.1002/j.1538-7305.1962.tb00480.x)

If $B$ exists, the set of descriptions that pass their specified deadline everywhere is $\Pi^0_1$-complete under computable many-one reductions. Failure has a finite decidable witness. The guard reduces nonhalting to the passing property even under the promise of correct SAT decision, a uniform larger clock, and at most one exception. In this case $H_k$ has exactly the Turing degree of the halting problem. An oracle for $H_k$ lets one test the guard exhaustively through $H_k(|d|)$, deciding halting. A halting oracle can determine whether each of the finitely many searches for a given $s$ ever returns, and ordinary enumeration then computes all defined least failures. The existence of $B$ and a bound $C_B$ is used only to fix constants in these reductions.

There is also an unconditional control on the recognized family $\{F_t\}$. Invoke the ordinary exhaustive SAT decider outside it in place of $B$. Every resulting program is globally correct and the same simulation hides its first deadline failure *on the recognized family* beyond every computable size-only horizon. Other files may have earlier timeouts. This control cannot determine the global cutoff.

## Allowing a private multiplier for each program

A single delayed file can always be absorbed into a program's private $O(N^k)$ coefficient. To test the asymptotic clock itself, use a fixed universal machine with a distinguished one-step output event. On $F_t$ delay for $(N_t+1)^{k+1}$ steps precisely when simulated step $h=t-a$ is an event. The machine then always returns YES. Runtime, including the delay loops, is bounded by a **common** $C''(N+1)^{k+1}$. Finitely many event times yield $O(N^k)$ after increasing the private multiplier. Infinitely many yield an unbounded time-to-$(N+1)^k$ ratio along distinct $F_t$. Only the designated uniquely satisfiable file can trigger at each size.

When $B$ exists, membership in the class of programs deciding SAT in $O(N^k)$ is therefore $\Sigma^0_2$-complete, even when the reduction is promised to produce globally correct programs with the common larger clock just stated. The upper bound is $\exists C\,\forall F$ with a decidable bounded predicate. For hardness, start with any $\Sigma^0_2$ property $\exists i\,\forall j\,R(e,i,j)$ with $R$ computable. At stage $r$ compute the least $i\le r$ for which all $j\le r$ satisfy $R(e,i,j)$, using $r+1$ if none qualifies. This sequence is nondecreasing. It stabilizes at the least true witness if one exists, and otherwise tends to infinity. Have the universal computation emit once per strict increase, waiting for each finite stage to finish. Stages may take arbitrarily many simulated steps. The native guard uses the actual transition number of the event, so each distinct emitted event has a corresponding file. This proves the reduction without a speed assumption on $R$.

The same construction can hide a genuine asymptotic slowdown past $f(s)$ for every sufficiently large $s$. After waiting $f(s)+1$ transitions, the input $u_s$ starts an endless sequence of events. Its program first exceeds the common $C_*$ only after the wait and subsequently exceeds every private multiple on some $F_t$. Choose events sufficiently late that the $(N_t+1)^{k+1}$ delay exceeds the common test deadline. All these asymptotically slow programs remain globally correct. Classical undecidability results already distinguish verifying a prescribed clock from verifying a big-O class, with notably different behavior on single-tape and multitape machines. The additions proved here concern the SAT promise, physical failure files, shared constants, and the finite-description cutoff. [Gajser, *Verifying Time Complexity of Deterministic Turing Machines*](https://arxiv.org/abs/1307.3648)
