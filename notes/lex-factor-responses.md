# Recovering one rigid-matrix bit from responses to earlier competitors

**Research journal, 24 November 2026.** Let $R_J$ be the row-major lexicographically first binary $J$-by-$J$ matrix at Hamming distance greater than $E=\lfloor J^2/16\rfloor$ from all matrices of binary rank at most $r=\lfloor J/16\rfloor$. Under the quadratic or cubic SAT hypothesis the journal's bounded candidate program computes this matrix on its local side. I examined how much of the $J^2$ sequential prefix search can be removed and which earlier competitors already have efficient certificates. [Candidate selection, clocks and original prefix search](fixed-program-parity.md)

## A two-quantifier test of a single bit

Fix a uniform evaluation model and a cap $S\ge J^2$ for both the length and evaluation time of an advised procedure $D$. A Boolean circuit with its encoded gates in topological order is one option. The procedure takes an arbitrary earlier competitor $B$ and produces binary $J$-by-$r$ and $r$-by-$J$ factors. It can choose both factors using all of $B$. Suppose a product of such factors can be computed in $M(J)$ operations in the model, including bit and address overhead up to logarithmic factors. Strassen gives $M(J)=O(J^{\log_2 7}\operatorname{polylog} J)$.

Existentially supply a matrix $A$ with requested bit one and a description of $D$. A universal challenge makes either of two checks. On supplied factors $U,V$ check $d_H(A,UV)>E$. On a supplied $B<A$ evaluate $D(B)$ and check that the product of its output factors is within $E$ of $B$. Reject malformed descriptions and failed evaluations. The same $D$ is fixed before the challenge. A procedure specific to the length and to $R_J$ is allowed. One can restrict the second challenge to matrices with both rows and columns in lexicographic order. Indeed every earlier qualifying matrix would have an equally qualifying lex-minimal representative under row and column permutations, and that representative is earlier too and sorted in both directions.

Any accepted candidate equals $R_J$. Conversely, if a capped $D$ succeeds on all sorted competitors below $R_J$, the predicate returns exactly the requested bit of $R_J$. If there is no such $D$, it returns zero on every position. Completeness requires products for the competitors in the promise. It does not require $D$ to solve general low-rank approximation.

The verifier costs $T=\widetilde O(S+M(J))$ per branch. Under a correct deterministic $O(n^d)$ SAT solver, eliminating the inner universal block by complement and quasilinear SAT encoding, then eliminating the outer existential block, costs $T^{d^2}\operatorname{polylog}(T)$ for a bit, with the usual fixed word-width and reduction conventions. With a fixed rational cap exponent one may use the same candidate trial, clocks and phase reset even when candidates are wrong. The original prefix method costs $J^2 M(J)^{d^2}$ up to logarithmic factors. Thus for $M(J)=\widetilde O(J^v)$ the direct-bit construction saves a power if $S=O(J^{v+\xi})$ with $0\le\xi<2/d^2$. The original program and the proof of its equivalence remain available without this extra premise. Fast unrestricted decisions of nonrigidity do not by themselves supply such a common response circuit.

## Where the first nonzero row of the actual canonical matrix occurs

Put $c=1/16$ and write $H$ for binary entropy. Let $k_J$ be the number of rows from the first nonzero row of $R_J$ through the end. All these rows are nonzero by lex order and row-permutation symmetry. Two constants bound its position:

$$
0.2752186\ldots\ =\lambda_-\ \le\ \liminf_J k_J/J
\ \le\ \limsup_J k_J/J\ \le\ \lambda_+\ =\ 0.2980461\ldots .
$$

**Construct the responses on a whole suffix.** Fix $t=\lfloor\lambda J\rfloor$ and allow arbitrary entries in the trailing $t$ rows with zeros above. One quick response stores $r-1$ rows exactly and rounds each other row to zero or all ones. This costs at most $\max(0,t-r+1)\lfloor J/2\rfloor$ edits. A single fixed **column** space handles a larger suffix in near-quadratic time.

Take a fixed binary linear code of block length $b$, dimension $a$ and covering radius at most $\delta b$. Split the trailing rows into successive blocks of length $b$. In each column round each block to a nearest codeword and leave a possible short final block literal. The resulting columns lie in a common space of dimension at most $(a/b)t+b$ and the whole matrix changes in at most $\delta tJ$ positions. Fixed lookup tables return coefficients of the nearest codeword in a fixed basis. They give the factors explicitly in $O(J^2)$ word operations, even counting time to write dense factors. They fit $O(J^2\operatorname{polylog}J)$ encoded circuit length and evaluation time at each length.

For fixed $0<\delta<1/2$ and any rate $R>1-H(\delta)$, a finite block can have $a/b<R$. Start with the zero code, whose radius-$\lfloor\delta b\rfloor$ balls cover a fraction $v=2^{-b}\sum_{i\le\delta b}\binom bi$. If the fraction still uncovered is $p$, adding one uniform translation vector to the generators leaves expected uncovered fraction $p^2$, by averaging the intersection of the old uncovered set with its translate. After $a$ suitable vectors the fraction is at most $(1-v)^{2^a}\le\exp(-v2^a)$. Once $v2^a>b\ln2$ there are no uncovered words. The binomial estimate $\log_2v=b(H(\delta)-1)+O(\log b)$ now gives the claim with strict rate slack for large fixed $b$. The code and decoder are constants independent of $J$. This uses the classical asymptotic linear sphere-covering bound. [Blinovskii on the covering radius of linear codes](https://www.mathnet.ru/php/archive.phtml?jrnid=ppi&option_lang=eng&paperid=802&wshow=paper)

Let $\lambda_-$ solve $H(c/\lambda_-)+c/\lambda_-=1$ with $0<c/\lambda_-<1/2$. For any fixed $\lambda<\lambda_-$ sufficiently near it, choose both $\delta$ and $R$ strictly below $c/\lambda$ while $R>1-H(\delta)$. The fixed code gives rank at most $r$ and distance at most $E$ on the entire suffix subcube for large $J$, absorbing rounding and the last block. Smaller suffixes are contained in it. Every such matrix is lex earlier than $R_J$, since there is no qualifying matrix with that many initial zero rows. The same approximation works on any specified set of $t$ active rows by permutation. It can tolerate $o(J^2)$ extra ones outside them by retaining strict slack in $\delta$.

**Some suffix is already rigid.** For $t/J\to\lambda$, the number of rank-$j$ matrices on a $t$-by-$J$ suffix is at most $2^{j(t+J)}/|\mathrm{GL}_j(2)|$. Every rank-$j$ matrix has $|\mathrm{GL}_j(2)|$ full-width factorizations, one per basis of its column space. Since $|\mathrm{GL}_j(2)|=2^{j^2}\prod_{i=1}^j(1-2^{-i})\ge c_0 2^{j^2}$ for an absolute $c_0>0$, summing for $j\le r$ gives at most $(r+1)2^{r(t+J-r)}/c_0$ possibilities when $r\le t$. Enlarge each by a Hamming ball of radius $E$ on the suffix. The proportion covered is exponentially small if
$$
 H(c/\lambda)+c(\lambda+1-c)/\lambda<1.
$$
The equality defines $\lambda_+$ in the indicated range. For any fixed $\lambda>\lambda_+$ sufficiently close to it, some suffix escapes. Padding that suffix above with zero rows preserves its distance lower bound by restriction to the suffix. Lexicographic minimality now bounds $k_J\le t$. Thus for every small fixed margin, all earlier matrices have at most about $0.2981J$ potentially active trailing rows, and the fixed code already handles all with at most $0.2752J$. The unresolved competitors can also share entries with $R_J$ inside the intervening rows. The row-location statements about the trial program are conditional on its stabilized candidate being correct.

**A list of row spaces can be much larger than a response procedure.** On the entire trailing-row subcube one fixed row space of dimension $r$ supplies at most $2^{rt}$ distinct approximants after restriction to the active rows. Counting their error balls requires any fixed menu of row spaces to have at least
$$
2^{tJ-rt-tJH(E/(tJ))}
$$
members when $E<tJ/2$. At $t/J\to3/16$ one has $r/J+H(1/3)<0.981$. Exponentially many row spaces are therefore required on a family already handled by the explicit response above. Restricting competitors to doubly sorted matrices loses at most a factor $(J!)^2$ in this counting bound, since the subcube contains the lex-minimal orbit representative of each of its members. The analogous count for column spaces uses $rJ$ in place of $rt$. For any fixed $\lambda>\lambda_-$ sufficiently near the threshold, exponentially many fixed column spaces would be needed to cover the entire subcube.

This gives a sharp asymptotic limit even for schemes that inspect the entire matrix before dividing its active rows into blocks of at most $h=o(J)$ and selecting an arbitrary linear code on each block. There are at most $t^t$ row partitions. A block of size $a$ has at most $2^{a^2}$ subspaces, since each has a generating list of $a$ padded vectors. Thus all blockwise direct sums form a menu of size at most $t^t2^{ht}=2^{o(J^2)}$. The column-space count rules out covering the whole subcube above $\lambda_-$ by these adaptive schemes of total rank at most $r$. A construction using interactions between different blocks subsequently exceeded this limit, producing factors on a fraction $0.2816$ of active rows. Sparse perturbations disqualify the whole subcube through $0.2881$ without the same factor extraction bound. The verifier can use the row-count theorem directly as a short response, including the later $0.2883$ improvement. ## Batching the first rows without a response circuit

A zero-prefix extension query is monotone in the number of requested initial zeros, so binary search locates the first active row in $O(\log J)$ queries. After a prefix of rows has been recovered, place adjacent columns with identical prefixes in classes. Each class is contiguous, and in the next row its entries consist of zeros followed by ones by column-permutation minimality. For a class of size $h$, test extendibility after writing $a$ further zeros there. Binary search finds its actual leading zero count in at most $\lceil\log_2(h+1)\rceil$ queries. After the first $i$ active rows there are at most $2^i$ classes. This recovers the first $u$ active rows using $O(2^u\log J)$ queries in addition to locating the zero rows.

This batching alone still has a quadratic worst-case phase on the actual $R_J$. Erasing its last $\lfloor J/16\rfloor$ rows costs at most $E$, hence the preceding prefix already has rank greater than $r$. It has more than $r$ different columns. The final $\lfloor J/16\rfloor$ rows retain these classes or refine them, so the procedure that performs a binary search per class uses $\Omega(J^2)$ queries. The fast common response for competitors beyond the fixed-code domain remains the missing step.
