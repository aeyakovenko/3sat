# An opponent that reads only the input length

Suppose explicitly encoded SAT has deterministic time $O(N^k)$ on the packed logarithmic-word RAM, with $k\in\{1,2,3\}$. A single deterministic opponent for the $n^8$ diagonal can ignore every input bit and still defeat **every fixed sound verifier of either sign on every padding at all sufficiently large lengths**, at the verification budget below. Its diagonal bit is one at all but $O(\log\log n)$ lengths up to $n$, and takes both signs infinitely often. This gives a satisfiable 3-CNF at every source length. At every sufficiently large source length all its satisfying assignments require polynomial-size circuits, with an explicit exponent. An individual challenge to the candidate proof was whether free padding or length sparsity alone could guarantee a short winning strategy. ## Separating a single verifier from the simultaneous claim

Let $J_8(x)=1$ when the program named by the prefix of $x$ rejects the whole input within $|x|^8$ guest steps. For **one** globally sound positive verifier $V$, one opponent suffices with $J_8=1$ on its **entire** cylinder at every sufficiently large length. Use an opponent that reads its program prefix $p$ and the total length $n$. Decide by SAT whether some extension $x'$ of $p$ of length $n$ admits bounded acceptance by $V$. Guess the extension and run the clocked verifier with that one immutable input. Accept if this search succeeds, and reject otherwise. On its own prefix the resulting bit is constant across all suffixes. If a successful search caused acceptance within the diagonal clock, every length-$n$ extension would have $J_8=0$, including the one supplying $V$'s accepting branch. Soundness therefore forces rejection and failure of the entire search. A verifier clock $O(n^{8/k}/\log^{3+\epsilon} n)$ leaves sufficient time, since guessing the extension costs $O(n)$ and the compiler contributes three logarithms to the formula length. A single prefix-dependent verifier recognizing that eventual-positive cylinder can hardwire its prefix and a sufficiently large length. Thus simultaneous defeat of **all semantically sound verifiers** on a single eventually positive cylinder is impossible.

This first opponent can also dispense with reading the prefix. Build a fixed template $G(u)$ that computes the self-delimiting program prefix for “instantiate template $u$ with the literal parameter $u$,” then performs the search above using that prefix and the real length. Instantiate $G$ with its own text. The resulting program constructs its own prefix using constant work at all sufficiently large lengths. It never observes any data bit. This substitution uses the same fixed code generator both in the running program and when forming its program text. Consequently a sufficient condition for the corresponding linear, quadratic or cubic exclusion is a uniform verifier for just the following task. On a claimed program and length, every success for a syntactically length-only opponent must correctly certify rejection within $n^8$. For each such opponent that rejects within the clock at **all sufficiently large lengths**, the verifier must have $O(n^{8/k}/\log^{3+\epsilon}n)$-time successes at **infinitely many** lengths. Public padding, if allowed, is freely guessable. Soundness on any other kind of computation is unnecessary. Whether this sparse certification condition holds is unresolved. The simultaneous construction below has a different quantifier on the exceptional lengths.

## One almost-everywhere obstruction for every sound verifier

Put $L(n)=\lceil\log_2(n+2)\rceil$ and $v(n)=n^{8/k}/L(n)^7$. Use the ordinary native model of the journal, including full-word nondeterministic choices. We first construct a bit $b(n)$ in deterministic $o(n^8)$ time from the length alone. Relative to the unary universe $\{1^n\}$, **neither** color of $b$ contains an infinite language in $\mathrm{NTIME}_{\rm RAM}(O(v))$. This property is called bi-immunity. The set of zeros through $n$ has size $O(\log\log(n+4))$. Deterministic almost-everywhere hierarchies, bi-immunity, and the distinction between deterministic and nondeterministic hierarchies have a long history. Here a deterministic machine uses the hypothesized SAT solver to search whole blocks of unary lengths. Historical priority for the construction and its application to SAT witnesses has not been established. [Balcázar and Schöning](https://doi.org/10.1007/BF01699457) · [Almost-everywhere deterministic separation](https://doi.org/10.1016/0890-5401(91)90022-T) · [Almost-everywhere nondeterministic hierarchies](https://doi.org/10.1016/0304-3975(93)90117-C)

Enumerate pairs consisting of a normalized nondeterministic RAM program and a requested bit. Include both bits for each text. Every fixed program occurs at finite indices, with program texts among the first $a$ computable in $\operatorname{poly}(a+1)$ time by using length-lexicographic binary texts. In block $I_j=[B,2B)$ of integer lengths, $B=2^j$, activate the first $a_j=\lfloor\log_2(j+2)\rfloor$ pairs. Process them in index order. A pair that already received a length in a previous block is finished forever. For each unfinished pair, search for the least still unclaimed $m\in I_j$ where its program has an accepting branch on $1^m$ within the block's universal simulation clock. If such an $m$ exists, give it the requested bit and finish the pair. Give every unclaimed length bit one. This rule defines all blocks without any advice or soundness oracle.

For the accounting, choose a dyadically rounded universal clock $h_j=\Theta(B^{8/k}/(j+1)^6)$. Powers of two with exponents $\lfloor 8j/k\rfloor-6\lceil\log_2(j+1)\rceil$, clamped to at least zero in the exponent, suffice. One fixed nondeterministic search machine guesses $m$ in a stated subinterval of $I_j$, excludes the already claimed positions there, and interprets the given program on virtual unary $1^m$. It runs the interpreter for at most $h_j$ **universal instructions**. All query metadata have $\operatorname{poly}(j+1)$ bits. Use a public dummy string of $\Theta(B)$ bits to supply native logarithmic width. For fixed program text, each guest step costs a constant after setup, and the guest's canonical unary input words and end padding are computed directly from $m$. Thus every branch of a fixed $O(v(m))$ decider eventually fits, since $v(m)=O(h_j/(j+1))$ throughout the block. The clock on arbitrary program texts bounds the search even before that asymptotic guarantee applies. The search uses at most $O(B+h_j+\operatorname{poly}(j+1))$ steps. Width $12L(m)$ and larger fixed width coefficients can be simulated by fixed-limb arithmetic and sparse banks. For the enumeration it suffices to normalize each fixed program to width $12L(m)$ in advance. At all three clocks, even $k=1$, at most $O(B^8)$ rows are needed. Concatenating a row number with a digit of at most $\lceil(\log_2 B)/4\rceil$ bits and fixed bank tags fits within width $12L(m)$ for large $B$. [Native sparse simulation](native-unary-clock-band.md)

Compile this fixed search machine with its public data into an explicit formula of $O((B+h_j+\operatorname{poly}(j+1))(j+1)^3)$ bits. A binary search using the existence query locates the least available length in $O(j+1)$ calls. Processing a whole block uses at most $O((j+1)^2)$ calls, including empty searches. For large $j$ their combined SAT cost is $O(B^8/(j+1)^{3k-2})$. Direct formula setup or materialization, table initialization, and the search bookkeeping fit this bound; the locally readable version also suffices. To compute $b(n)$, replay the blocks through $j=\lfloor\log_2 n\rfloor$, including the whole last block. The exponential growth of $B^8$ makes the sum $o(n^8)$ even at $k=1$, where $3k-2=1$. Reset the query scratch between calls by recording touched cells or by allocating fresh rows. The full run allocates $o(n^8)$ rows, which fit the native sparse address implementation on the original host. [Packed compiler and instruction basis](packed-band-transfer.md)

Each exceptional length was awarded to a different activated pair, so there are at most $a_{\lfloor\log_2 n\rfloor}$ of them through $n$. For an infinite unary language accepted by a fixed $O(v)$ machine, consider its pair requesting zero. If the pair never finishes, take an eligible block after its activation and after every award ever made to a smaller index. There are infinitely many blocks with a member of the language and at most finitely many smaller awards. The least eligible length in this block is still available when the pair gets its turn, a contradiction. The pair requesting one obeys the same argument. Every infinite language in this class consequently meets both colors. Both colors are infinite, since the cofinite unary sets belong to this class. The same proof allows any slower unbounded, nondecreasing, efficiently computed activation count below $a_j$. [Lean proof of the priority step](../lean/DyadicLengthRequirements.lean)

Use as opponent the program that rejects exactly when $b(n)=1$ and otherwise accepts. It only asks for the input length. At large $n$ its whole cylinder has diagonal value $b(n)$ on every suffix. For any fixed nondeterministic verifier $V$ giving a sound sign $d$ on that cylinder, suppose infinitely many lengths admitted a successful branch of $O(v(n))$ steps on some padding. A clocked unary machine guesses the free suffix, simulates $V$ and accepts precisely on seeing that sign within its cap. An integer clock within a fixed factor of $v$ is constructible by shifts as above. Choose the constant in the cap above the supposed branch times. If soundness on the cylinder starts only at large lengths, reject the finitely many earlier lengths. This gives an infinite fast unary language of color $d$, which is impossible. Soundness is required for all paths producing the sign; slow or diverging paths elsewhere cause no difficulty. This applies to either sign, with each fixed verifier's own finite exceptions, simultaneously over **all** padding strings. In particular it applies to any fixed strategy checker whose finite proofs soundly certify $J_8$ on the cylinder and whose checking time meets this cap. Infinitely many negative lengths put this cylinder outside the eventual-positivity promise in the earlier one-sided criterion.

There is also a proof-length consequence with the same program for every fixed sound proof calculus. Let $\theta(n,d)$ be the closed sentence saying that this particular length-only program computing $b$ halts on unary length $n$ with output $d$. Use binary numerals, a fixed arithmetization of its input and instructions, and no unrolling in the sentence. The two statements for a given length have $O(\log(n+2))$ symbols and exactly one is true. Suppose a sound system's binary derivations can be guessed and checked against this sentence in $O((u+L+1)^e L^c)$ steps for proof length $u$, with fixed $e\ge1,c\ge0$. At all sufficiently large $n$, every proof of the true one has length $\Omega(n^{8/(ke)}/L^{(7+c)/e})$. A unary machine guesses a proof at the proposed cap and checks the specified sign. It recognizes a fast subset of that color, so succeeds only finitely often. This holds separately for each fixed proof system without a shared theory certifying the soundness of those systems. ## Ordinary 3-CNFs with a guaranteed satisfying assignment at every length parameter

On unary input $1^n$ compile the deterministic $b$ computation through a regular clock $R=n^8$ into a 3-CNF $F_n$. Allow either halting output, idle the machine after it halts, and expose a fixed output slot $o$ equated to its bit. Every sufficiently large $n$ has a completed run. Hardwire the finite exceptions in the compiled program, or enlarge the clock by a fixed factor, to obtain a satisfiable formula for every $n$. Every satisfying assignment has $o=b(n)$. Choice of routing switches in a RAM history certificate does not affect the deterministic run. Use regular padding as in the packed compiler, with bit length $N=\Theta(R L(n)^3)$ and each clause or word computable from $(n,\text{index})$ in $\operatorname{poly}(L(n))$ time. The generator uses the fixed program text of the hypothesized SAT algorithm as part of the simulated machine's code. Generating a clause never requires running that algorithm. [RAM reduction](packed-band-transfer.md)

For some constant $A$, **at every sufficiently large $n$, every satisfying assignment of $F_n$ requires more than $N^{1/k^2}/(\log N)^A$ bounded-fan-in Boolean gates** to return its bits from the variable number. To see this, for each proposed sign $d$ use a unary nondeterministic verifier. Guess the wiring and gate types of a circuit with $q$ gates; check the encoding, evaluate it on $o$, and require the bit $d$. Decide existence of a falsified clause by SAT. A clause index has $O(\log N)$ bits, its three fields can be generated locally, and the circuit can be evaluated at all three names in $O((q+1)\operatorname{polylog}N)$ time including its encoding. Supply the defect query with the binary representation of $n$ and the guessed circuit. The original unary input is implicit in the clause generator. The compiled defect query and setup therefore have size and time $(q+1)\operatorname{polylog}N$. The verifier accepts if the defect query is unsatisfiable. Every accepted length belongs to color $d$, and the verifier succeeds whenever an assignment of the indicated size and bit exists. With the displayed cap on $q$, the total verification cost is at most $O(v(n))$ for large fixed $A$, since $N=\Theta(n^8L(n)^3)$. Dyadic caps can be rounded above the claimed bound and the logarithmic exponent increased by a constant. Bi-immunity makes the accepted length set finite for each of the two verifiers. Their union contains all small-witness lengths. [Earlier infinitely-often witness bound with larger exponent](positive-witness-hierarchy.md) · [Easy-witness theory](https://doi.org/10.1137/18M1195887)

The same argument permits a fixed uniform RAM evaluator with an assignment-specific advice string, blank scratch per variable query, and random access to the generated formula. Charge advice length plus the maximum query time. Guess and cap both quantities, give the evaluator the genuine locally generated input words, and test its three bits per alleged violated clause with fresh scratch. One machine per sign again gives a finite set of successful lengths. For $k>1$ the exponent is weaker than the earlier infinitely-often $1/k$ bound. For linear SAT it gives a nearly linear circuit lower bound up to logarithmic divisors; here the formula is satisfiable at every source length, with no hidden selection of positive lengths.
