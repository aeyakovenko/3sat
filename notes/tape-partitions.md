# Checking a tape computation across a partition of its visits

**Research journal, 24 November 2026.** A large tape can store many unrelated words that never need to be checked together. I tested whether this makes arbitrary long computations cheap to certify under a linear SAT hypothesis. For a fixed unary hierarchy language, that hypothesis forces some accepting computations to have nearly linear treewidth in the number of epochs, in the sense quantified below. Two writable tapes already realize visit graphs of linear treewidth with a constant number of head reversals. The remaining possibility is that the actual words carried across a partition admit short descriptions even when the graph is wide.

## What is public, and which words have to agree

Consider a fixed nondeterministic multitape machine with a constant number of tapes, running in T steps on N input bits. Use a block-respecting presentation with blocks of b cells and epochs of b steps. Up to the last move of an epoch, each writable head stays in one block. Suppose B epochs suffice, padding in the halting state if necessary. In the hierarchy application b=n, B=O(n¹¹), T=O(n¹²), and the input is unary. All numerical bounds below are constructible. [Block simulation, Strassle and Subercaseaux, Lemma 3.1](https://arxiv.org/html/2611.11832v1) · [Earlier transition checks](epoch-dictionaries.md)

Guess a public record for each epoch giving times or epoch indices, finite control, block numbers, head offsets and directions of boundary moves, including input-head information. Check chronological consistency, the initial and accepting controls, and valid address ranges. For each writable tape and each block, connect consecutive visits to that block by an edge. Sorting by tape, block and time constructs these edges with quasilinear overhead. Multiple tapes can give parallel edges. An edge carries the b-cell word left by the first visit and found by the second. At a first visit use the actual initial word, and at a last visit allow an arbitrary final word unless an output condition is prescribed. The chronological controls are already in the public record. The graph G used below contains only the edges carrying words. It has B vertices and maximum degree at most twice the number of writable tapes, counting multiplicity.

For a fixed assignment of these words, each epoch has a local existential check. Guess its internal nondeterministic choices and verify the prescribed control, motions and incident words by simulating b steps. For read-only input the true input remains available. Checking all epochs suffices. The words transmitted by every consecutive pair agree, so chronological concatenation yields a legal accepting run. This charges no public record of b data bits per epoch.

## When a different description can be chosen in each part

Guess a rooted partition tree for the epochs, of height h and O(Bh) nodes, with the epochs divided among its leaves. Check its structure and the membership of each epoch. An edge belongs to the lowest common ancestor of the leaves of its endpoints, or to their common leaf. The owner and the slot of every edge can be computed within O(B polylog(T+2)) time when h=O(log(T+2)). One may sort edge identifiers at each owner and number them consecutively.

At a node, guess one description of the words on its owned edges. It can be a literal table in slot order or a Boolean circuit taking an edge identifier and an offset and returning the symbol. Bound the total description length on any root-to-leaf path by P. Next a universal choice selects the child. At a leaf, after its description is fixed, universally select one of its epochs. Existentially guess its incident words and local nondeterministic choices and run the local check. Universally select one supplied symbol to compare with the appropriate ancestral description. Literal tables use the precomputed slots, and circuits are validated and evaluated on the selected edge and offset. The final check pays for one circuit evaluation and one local run. It never needs to evaluate the same long circuit separately on all b offsets.

Soundness uses the order of the quantifiers. The description of an edge is fixed before challenges split toward its two endpoints. Choices made in distinct subtrees can be combined, retaining their common ancestor descriptions. Thus successful answers to all challenges fix one word on every edge and admit local realizations everywhere. Conversely a run with the stated descriptions supplies all the required choices. Branches can use different encodings of the unrelated words that they own. One need not transmit the concatenation of *all* the descriptions. Lean checks the equivalence between the alternating choices and one global tree labeling. [Lean proof](../lean/PartitionWitness.lean)

Let V=N+B+b+P+2. For h=O(log(T+2)), V polynomially bounded in T+N, a quantified circuit implementing this test has O(h+1) blocks and initial encoded size V·polylog(T+N+2). For instance reserve P bits per level, check the used lengths along the path, perform the indexing and verification in quasilinear RAM time, and express that last verification with a guessed deterministic computation transcript. The guesses of the public records and the partition tree are included. Under linear SAT the fixed uniform elimination rule adds O(log log(T+N+4)) to the logarithm of the size at each step here: through O(log(T+N+2)) steps the logarithm itself remains polynomial in log(T+N+2). Hence a deterministic RAM can test existence within

    V · 2^{O((h+1) log log(T+N+4))}.                           (1)

This accepts exactly the property with the proposed caps; an arbitrary NO instance of the original computation has no such certificate. The SAT hypothesis in (1) puts no space restriction on the solver. [Elimination rule and cost accounting](linear-quantifiers.md)

## Keeping an unknown entry tape symbolic

There is a way to combine the cut test with the cellwise checkpoint rules. Let M be a common read-only parameter with arbitrarily many bits, addressed by O(log(T+N+2))-bit names. A word on an owned edge can now be represented bitwise by a term f(M(p)), where its circuit returns both p and a unary Boolean map f. Constants are allowed. The entry tape and any required exit words must be specified by such terms as well. Require the proposed segment to work for every M, allowing the internal nondeterministic choices in each epoch to depend on M.

No enumeration of M is needed. After an epoch is selected, existentially supply the list of terms for its incident words, and require that a universally selected list entry agrees with its actual circuit. There are O(b) entries with logarithmic-bit addresses. Universally supply a bit for the base position of each entry. When two entries name the same position their bits must agree; an inconsistent proposal places no requirement. For a consistent proposal apply each term's unary map and require that some local run realizes all those concrete words and the controller. Sort the address/reply list to check repeated positions, then replay locally. These are a fixed number of additional quantifier blocks. The test pays for evaluating one selected circuit and sorting O(b) small records. The clock (1) still applies with logarithmic factors in the stated overhead. Every consistent finite list of base replies extends to a total M, by filling other positions arbitrarily. Conversely, for each actual M the same preselected tree descriptions now give agreeing concrete words at both ends of every edge, so legal local runs concatenate. The order requires the tree descriptions to be chosen before the base bits. [Cellwise checkpoint rules](checkpoint-pullbacks.md)

For instance in the two-tape construction below, let the machine preserve arbitrary initial tape words while following a fixed schedule. Taking the physical block and offset as the base address certifies the entire transfer across the wide graph uniformly in those initial words. Two regions can also carry corresponding bits from the same base, making an equality test sound on every such pair even when neither word is fixed. For the hierarchy application an unknown base introduced in mid-computation needs a proof that the incoming data have the claimed form. This method does not provide a short description for arbitrary interactions among blocks.

## A consequence for an actual hierarchy language

If G has treewidth at most w, every induced subgraph has a vertex separator of size at most w+1 leaving components of at most half the vertices. In a tree decomposition, assign each vertex's weight to one bag containing it and take a weighted centroid. Removing that bag separates the subtrees by the connected occurrence condition. For a piece of size m>3(w+1), keep the separator as one terminal part and split the other components into two groups of size at most 2m/3. If a component already has size between m/3 and 2m/3, use it as one group. Otherwise accumulate components of size below m/3 until reaching m/3. Only edges incident to the separator can cross between these three parts. Smaller pieces are terminal. This gives a ternary partition of depth O(log(B+2)), with O(w+1) owned edges at each node, including leaves, by the bounded degree.

Collapse k consecutive levels at a time. A new node owns the old edge lists of at most 3^{O(k)} nodes. The new height is O(1+log(B+2)/k). Literal descriptions now suffice with path cost b(w+1)·3^{O(k)}polylog(T+2), counting a constant alphabet and the slots. The partition itself still takes only B polylog(T+2) bits: contracting levels never adds nodes, and membership can be checked from parent pointers. There is no need for the algorithm to construct an optimal tree decomposition. Choose k of order √(log(T+N+2) log log(T+N+4)). By (1) the time to recognize acceptance with these certificate caps is at most

    (N+B+b(w+1)) · 2^{O(√(log(T+N+2) log log(T+N+4)))}.      (2)

The language recognized by this test can also contain YES inputs of larger treewidth that have a suitable partition. Its acceptance always implies a genuine run, and it accepts every input with an accepting width-w run.

Choose once a unary language H★ in NTIME(n¹²) outside NTIME(⌊n¹²/log₂(n+2)⌋), using equivalent rounded time-constructible clocks, and fix its block-respecting verifier at b=n. The unary hierarchy grants this stronger choice of lower clock. Under linear SAT there is a constant a such that at infinitely many accepted lengths **every accepting run of this verifier** has

    treewidth(G)+1 > n¹¹ / 2^{a√(log₂ n · log₂ log₂ n)}.       (3)

Indeed, otherwise cap the integer width at the rounded right side at all large lengths and use (2). Its hidden constant is independent of the cap. Choosing a sufficiently large constant, the resulting deterministic RAM clock, including a quasilinear nondeterministic simulation on multitape machines, fits the excluded time. Exceptional lengths can be hardwired. One can use powers of two and rounded binary logarithms in constructing the caps. Thus any fixed power saving in the required width on a suitable accepting run at every large accepted length would rule out linear SAT. We have no such width bound for H★. The partition-circuit test (1) asks a weaker question about the *values* at large cuts. [Unary hierarchy and RAM simulation, Williams, Theorems 2.1–2.2](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

The graph test can also be applied to the original head motions, without first adding a tape for block synchronization. Partition each writable tape into width-b blocks with an offset modulo b. For each head move of one cell, exactly one offset makes it a block crossing. Averaging gives offsets with O(T/b) total crossings over the fixed number of tapes. Split the run after any step that crosses a boundary and also after at most b steps. This gives O(1+T/b) epochs, each confined to one block per head until its last move. Guess the offsets, epoch lengths and controllers, enforce their time cap, and apply exactly the same word checks. At a finite tape boundary use the truncated block. This works for nondeterministic paths since the schedule is guessed for the particular run. The Hennie–Stearns simulation supplies a two-writable-tape presentation of the same hierarchy language in O(n¹² log n) time: its tape simulation is deterministic apart from choosing the simulated transition at each simulated step. In (2), at b=n the extra logarithm in the epoch count is absorbed by the displayed overhead. On infinitely many accepted lengths every accepting schedule of that two-tape presentation satisfying the epoch count cap still has the width lower bound (3). [Hennie and Stearns](https://www.cs.toronto.edu/tss/files/papers/HennieStearns66.pdf) · [One-tape movement and time](simultaneous-space.md)

## Two writable tapes can have a wide visit graph

For a single writable tape G is just a union of paths, one per block. An arbitrary constant number of writable tapes changes the possible graphs. Here is a two-tape implementation of a monotone-matching layout. A bipartite graph on ordered sides of N vertices each is d-monotone if its edges are the union of d order-preserving partial matchings. Use distinct phases for the d matchings. In odd phases visit the 2N terminals in the order of the left side followed by the reversed right side. In even phases reverse the entire order. Each terminal has two epoch slots. Tape B uses one physical block per terminal, traversing these positions back and forth over the phases, staying at each terminal for its two slots. Thus all epochs assigned to a given terminal form one connected set of consecutive-visit edges on tape B, independent of the other terminal sets.

Tape A starts every phase at block 0. On the first half, if a terminal is matched, use the current block in the first slot and move up one for the second. On the second half move down one between slots for a matched terminal, using the destination in the second slot. For unmatched terminals keep the same block. Since the matching is monotone, the second-half endpoints appear in reverse order of their matched partners. Between a push slot and its matching pop slot every visit is to a strictly higher block. Thus they have a direct consecutive-visit edge on tape A. Contract the disjoint connected terminal sets of tape B. The resulting graph contains every matching edge. The original graph is a minor of G. The schedule has 4Nd epochs, at most 2d changes of motion direction on tape A and at most d on tape B, ignoring stays. These are legal nearest-neighbor block schedules with stays. Physical heads can sweep across a block between outward crossings in the same direction, wait at an endpoint, or reverse at the boundary; for a schedule-only realization one can also keep each block one cell. The choice of matched terminals can be provided to the controller. This construction concerns allowable schedules, independently of the particular verifier for H★.

For at most d reversals on tape A, put the stack base at block N and grow the stack to alternating sides of that base in successive nonempty phases. The pop direction is then the push direction for the next phase. Preposition A from 0 by at most N epochs in the initial push direction. The direct consecutive-visit edges persist. There are at most (4d+1)N epochs. Lean checks that the two endpoint slots of any matched push and pop in a nested schedule have no intervening visit to their common block. [Lean proof](../lean/StackVisit.lean)

Dujmović, Sidiropoulos and Wood construct an infinite family of 3-monotone bipartite graphs on equal N-vertex sides in which every set of at most N/2 left vertices has at least 1+ε times as many right neighbors. Their one-sided expansion is enough. A width-w decomposition gives a separator Z of at most w+1 vertices leaving at most N/2 **left** vertices in each component, by the weighted centroid proof. Sum the expansion bound on the remaining left sets of all components. Neighbors outside Z belong to their own component. A right vertex in Z occurs in at most d neighbor sets by bounded degree. Therefore

    (1+ε)(N−|Z∩Left|) ≤ N + d |Z∩Right|.

This gives w=Ω(N). Treewidth is monotone under minors, as contracting an edge simply joins the occurrence subtrees of its two endpoints in a decomposition. Hence the two-tape construction has treewidth Ω(B) for arbitrarily large B, with at most **three reversals on A and two on B**. This routing argument uses stationary moves and counts reversals of nonstationary movements. It concerns the graph of block positions; choosing one cell per block realizes the same reversal bounds by physical heads. The computational check reconstructs the visits directly for 12,900 small matching families. [Dujmović, Sidiropoulos and Wood](https://arxiv.org/abs/1501.05020) · [Galil, Kannan and Szemerédi](https://doi.org/10.1016/0022-0000(89)90036-6) · [Routing check](../audits/tape_routes_experiment.py)

There is a positive case for two writable tapes that permits exceptional epochs. Suppose deleting E common epochs makes each tape's block-position sequence monotone up to one reversal (the reversal may be at a different epoch on each tape). An edge of the original graph with both endpoints retained still joins consecutive occurrences on its tape in the shortened sequence. Within a monotone leg, repeated positions are consecutive. Edges that span the turn join the final visit on the first leg to the first visit to the same position on the second. Their endpoints are nested, since the return order reverses the initial order. Drawing the first tape's nontrivial arcs above the ordered epochs and the second tape's below gives a planar graph, including adjacent pairs on the common line. Planar separators give width O(√B) by recursive decomposition: along a branch the separator sizes decrease geometrically in the square root of the current piece size. Adding back the E epochs to every bag gives width O(√B+E). Thus a low-cost schedule in (2) can contain many reversals provided deleting a sufficiently small exceptional set removes them. [Lipton and Tarjan](https://www.cs.princeton.edu/courses/archive/fall06/cos528/handouts/sepplanar.pdf)

Large treewidth alone does not force complex transmitted words: a machine can carry zero on every one of these edges. Conversely, no structural theorem about two writable heads and their number of reversals alone gives the width saving needed in (3). The next issue is whether a suitable *accepting* computation can simplify the words at cuts, or change the schedule, while preserving its answer. The quantitative implications and the two-tape routing argument are manuscript proofs. Priority of these deductions has not been established.
