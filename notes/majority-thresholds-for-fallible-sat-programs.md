# Recovering a SAT assignment from fallible candidate programs by threshold queries

The [finite-literal exhaustion](finite-sat-exhaustion-with-unbounded-literals.md) enumerates $K$ programs at one good padded length and uses up to one adaptive prefix restriction per variable per candidate. I tested whether the factor counting variables must multiply the number of candidate programs. With a known finite family of possible joint reply tables, only $2(K+\lfloor\log_2 H\rfloor)$ calls to the actual candidates and $K$ assignment checks suffice, where $H$ counts the possible tables. The condition is only that one row is truthful. All other rows may be inconsistent with every possible set of witnesses. The price of the reduction is computing where a majority of the remaining tables changes its answer. This computation need not be fast. The quantified cost below makes the distinction relevant to the RAM-time target.

## Proper, same-length threshold formulas

Number the $M=2^v$ assignments to the $v$ occurring variables of a formula $F$ in lexicographic order, starting at zero. Let $W\subseteq[0,M)$ be its satisfying assignments. Query $t\in[0,M]$ asks whether $W$ meets $[0,t)$. The answer at zero is hardwired to no for every candidate. At $t>0$ append to $F$ a comparator forcing the assignment, in binary, to be at most $t-1$. Rename the occurring variables to dense indices first. Their original distinct decimal names have total length $\Omega(v\log(v+2))$ for large $v$, by counting short strings. Hence $v$ fresh gates, with $O(\log(v+2))$ digits per identifier, take $O(n)$ additional bits for an input of $n$ bits, including long or sparse original identifiers after normalization. [Normalization and dense indices](dense-sorted-cores-for-ram-exhaustion.md)

Write $G_{v+1}=1$ for the empty suffix. Scanning backwards, use $G_i=\neg x_i\land G_{i+1}$ if bit $i$ of the bound is zero, and $G_i=\neg x_i\lor G_{i+1}$ if it is one. Assert $G_1$. The usual gate equivalences have width at most three. Pad binary clauses by both signs of a fresh variable and units by all sign combinations of two fresh variables. The resulting proper 3-CNF has an extension of an assignment precisely when its number is below $t$ and the assignment satisfies $F$. All thresholds can be padded to the same byte-aligned length $L\ge B(n+1)$ for a fixed sufficiently large $B$. The $v=0$ case can be answered directly. A polynomially clocked candidate at length $L$ gives a fixed answer to each query. A timeout counts as no. The original formula verifies any proposed assignment directly.

## A search using joint response tables

Consider a public set $\mathcal H$ of $H\ge1$ binary tables with rows indexed by the $K$ candidate programs and columns indexed by the thresholds. It contains the actual response table. At least one actual row answers all thresholds according to the same genuine $W$. Given $\mathcal H$, the following is a deterministic decision tree. Only actual candidate calls and point verifications are charged at this stage.

Keep the tables that agree with every observed answer. For the current candidate, write $b(t)$ for the majority bit at column $t$ over those tables, with ties settled by a fixed rule. If $b(M)=0$, ask the actual row at $M$. An agreeing response finishes this candidate without a point. A truthful row for a nonempty $W$ could not give that response.

If $b(M)=1$, there is some $j<M$ with $b(j)=0$ and $b(j+1)=1$, since $b(0)=0$. No monotonicity is required. Locating such a pair in a supplied majority row can also be done by bisecting opposite-valued endpoints. Ask the actual row at these two columns, omitting the hardwired zero. If both responses agree, verify assignment $j$. If it succeeds, return yes. Otherwise finish this candidate. On a truthful row the disagreeing truth values of the adjacent thresholds imply that $j$ itself satisfies $F$.

Whenever an observed bit disagrees with the majority used to propose its certificate, retain only the compatible tables and retry the same candidate. At least half of the tables present at the start of that attempt are discarded. This holds also if a first probe agreed and a second probe disagreed with its original majority. Successful probes can discard further tables. The actual table always remains, so there are at most $\lfloor\log_2 H\rfloor$ failed attempts across all rows. Each completed candidate uses at most two probes in its final attempt, and at most one assignment is verified there. Returning no after processing all rows is correct. A truthful row for a nonempty $W$ must have supplied a verifying point. This proves the stated bound.

For example, fix the original length $n$, variable count, candidate list at length $L$, deterministic restriction builder, and threshold numbering convention. Vary the genuine input over the admissible $n$-bit files. The resulting joint reply tables number at most $2^n$, even if each table contains extraordinarily many columns. These tables can be generated by finite computation before testing a particular input. The bound gives at most $2(K+n)$ actual candidate calls and $K$ verifications under this interface. It does not assert an $O(K+n)$-step method for obtaining their queries. Explicitly generating all compatible tables, simulating their candidates and computing enough majorities can be exponentially expensive.

More quantitatively, suppose an implementation can maintain the compatible-family information and, for each attempt, produce a majority certificate and incorporate its at most two observed bits in $u(n)$ native steps amortized, with initial cost $I(n)$. It need only produce the final negative threshold or a pair of adjacent thresholds with the stated majority bits. If assembling a query and simulating a chosen candidate each cost at most $T(n)$, and verifying an assignment costs $V(n)$, the resulting uniform time is
$$
 O\bigl(I(n)+(K+\log H)(u(n)+T(n))+K V(n)\bigr).
$$
A simple binary search in the interval of columns makes up to $v$ majority evaluations per attempt if only individual majority bits are available. Those costs belong in $u(n)$. Even an efficient majority procedure would still have to pay for the candidate calls. At a good padded length the slot bound can leave $K$ polynomial in $n$ with an exponent depending on the slot budget. This estimate does not preserve a linear, quadratic or cubic deadline in general.

## Exact black-box cost without the shared-table constraint

There is a matching obstruction to uniformly reducing the product scale on *independent* candidates, even with stronger questions. Take $K$ publicly disjoint buckets, each of $m\ge1$ points. Row $i$ has a hidden singleton $u_i$ in bucket $i$. A question to that row can be any subset and returns whether $u_i$ lies in it. One additional identified row answers no to everything. The genuine witness set is promised to be empty or $\{u_j\}$ for some $j$. It can be tested by asking for the membership of one point. At least one row is always a truthful existential oracle on every subset. Only the final yes/no decision about the genuine set is required.

Let an arbitrary subset call cost $A>0$ and a point verification cost $B>0$. The deterministic minimax cost is exactly
$$
 K\min_{0\le a\le\lceil\log_2 m\rceil}
 \left(Aa+B\left\lceil m/2^a\right\rceil\right).
$$

For the upper bound, in every bucket number $2^a$ groups of at most $\lceil m/2^a\rceil$ points, allowing empty groups. Ask $a$ subset questions revealing the bits of the group number and then verify every point of that group until success. This uses at most two batches if all queries in each stage are issued in parallel.

For the lower bound follow an all-negative verification transcript. In each bucket maintain a set of still possible hidden points, all untested. For a subset query retain the larger part of this set. A verification of an element of the set removes it and returns false. When a verification removes the last remaining point, fix that point as this oracle's hidden singleton for all further questions, and call the bucket finished. Replies when the bucket is finished remain consistent with the all-negative case: its singleton may be a fabricated witness. Before finishing, every surviving point can also be made a genuine witness without changing the transcript. A correct negative decision must therefore finish every bucket.

If a bucket has had $a$ subset calls, $u$ point checks, and has $r$ live possibilities, then $m\le2^a(r+u)$. A subset call reduces $r$ by at most a factor of two, and a verification reduces it by at most one. These update rules preserve the inequality in the forward direction, starting at $(a,u,r)=(0,0,m)$. At completion $u\ge\lceil m/2^a\rceil$. Larger $a$ than the displayed maximum only adds cost since at least one verification remains mandatory. Work done on one disjoint bucket cannot shrink any other. Summing gives the lower bound even for adaptively interleaved questions. For equal costs and $m=2^b$, the cost is exactly $K(b+1)$ unit operations. Without the identified always-no row the all-negative world in this construction would have no truthful candidate.

For unit costs the common-table bound is therefore sharp up to an absolute constant when only $K$ and $H$ are specified. Allow bucket $i$ to have $2^{b_i}$ ordered assignments, with $\sum_i b_i=h$. There are $H=2^h$ distinct joint threshold tables: a singleton in an ordered bucket is identified by where its threshold row changes. The independent-bucket proof gives cost at least $\sum_i(b_i+1)=K+\log_2 H$ even with arbitrary subset questions. Ordinary threshold bisection followed by one membership check per bucket attains this count. There are $K+1$ candidate rows including the always-no row. This calibrates the previous information bound with threshold predicates themselves.

The private tuples of the product example range over $m^K$ possibilities. Arbitrary subset descriptions and bucket comparisons in this query model have no size charge. Giving an explicit proper formula that pins the bits of the hidden point would expose those bits directly in the DIMACS clauses. These are reasons the product lower bound does not transfer to the actual RAM. The common-input majority bound shows quantitatively where independent black boxes cease to model the exhaustive candidate list.
