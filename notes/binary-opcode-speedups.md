# When a RAM speedup lifts to a two-word oracle instruction

A black-box instruction returning one bit has two different costs in an alternating simulation. Guessing the replies to a whole run costs one packed word per word-width of steps. Passing those guesses as public input to another computation can cost one **bit per step**. This distinction determines which speedup statements a binary opcode could refute. For the recursive instruction that defeats statistical protocols, the second cost can also be removed by the choice of its trial lengths. [Statistical lower bound and recursive construction](two-word-interactive-barrier.md)

## Arbitrary binary opcodes

Let a fixed deterministic RAM on an input of $n$ bits have a known polynomial upper clock $T$, word width $w=\Theta(\log(n+2))$, and one additional instruction returning $O(a,b)\in\{0,1\}$ for two words. Assume $T$ and the input layout are available as metadata or computable within the claimed bounds. Pad halts by inert steps. The host makes full-word existential and universal choices and has random read access to packed public data. Programs can read the original input and a guessed array as separate banks. A concatenated encoding with their lengths in a header implements the same reads at constant cost. Word widths before and after a polynomial increase in input length differ by a constant factor. For this simulation one may use a fixed sufficiently wide host and mask smaller guest words, as in the native model. [Packed RAM conventions](packed-band-transfer.md)

Consider the following **ordinary deterministic decision predicate** for this one program. It receives $x$, its clock, a packed $T$-bit string $z$, an instruction index $t$, and a claimed query type and operands. Run the machine from its actual initial state, replacing the oracle reply at step $i$ by $z_i$. On a query challenge decide whether the specified step is an ordinary step, or issues exactly the claimed query, as asserted by the challenge response. On a verdict challenge decide whether the replay accepts by the clock. This predicate takes $O(T+1)$ word steps and has $n+T+O(w)$ input bits. Its decisions for *every* supplied string are ordinary computations. Its program is independent of the contents of $O$.

**Lifting lemma.** Suppose this predicate, on the described public inputs, has a $k$-block alternating algorithm of time $s$. Then the original oracle program has an alternating oracle algorithm using at most $k+3$ blocks, at most one actual oracle call on each branch, and time
$$
 O\big(1+\lceil T/w\rceil+s\big).
$$
Guess $z$ using $\lceil T/w\rceil$ word choices, then universally choose a verdict test or one instruction index. For the latter test, existentially supply its type and operands. If an oracle call is claimed, require $O(a,b)=z_t$ for these operands. In both cases invoke the ordinary decision procedure for the chosen test. Range-check selectors or accept out-of-range universal challenges. Neither the original input nor the guessed transcript needs a second copy. All statements concern correctness on a fixed oracle, with the construction uniform across oracles.

The genuine replies give one successful outer guess whenever the genuine machine accepts. Conversely, on a successful guess the ordinary test fixes the operands at each challenged index uniquely, independent of the responder's choice. At the first instruction where a simulated transition could differ, the states and operands still coincide, so the challenged reply forces the genuine transition there too. Induction and the separate verdict test give acceptance on the genuine computation. [Checked induction, including steps without a query](../lean/OpcodeReplay.lean)

In particular, an $o(T)$ constant-block speedup for **all ordinary** $O(T)$ computations with $O(T)$ packed public *bits* would give an $o(T)$ speedup for every such computation with an arbitrary two-word binary opcode, for $n=O(T)$ and growing $w$. This observation uses the ordinary speedup on the enlarged public input. A speedup supplied only for a particular short-input diagonal need not transfer. A reply of $b$ bits incurs a transcript cost $bT$ bits and $O(1+\lceil bT/w\rceil)$ guess steps for $1\le b\le w$. In particular the argument for arbitrary word-valued instructions gives no sublinear guess bound. The technique of guessing adaptive replies and checking a selected call also occurs in the earlier checkpoint argument. The size of the resulting native input is decisive here. [Checkpoint pullbacks](checkpoint-pullbacks.md) · [Williams on long queries in other oracle models](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

## A statistically hard opcode with a constant-word exact description

One can choose a fixed recursive binary instruction $O$ with all of the following properties.

1. Empty-row verification for this oracle has no statistically sound interactive proof with $o(T)$ verifier work and polynomial communication for $T=n^2$, even with arbitrarily many rounds. The native nondeterministic and deterministic linear-time classes differ relative to this instruction.
2. At every operand width $w$, the entire restriction of $O$ to pairs of $w$-bit operands has a description of $O(w)$ **bits**. There is one ordinary uniform interpreter for these descriptions. After $O(w)$ word steps of setup, one oracle call costs $O(1)$ ordinary word steps.
3. For **every** $T$-step deterministic program using this $O$, its acceptance is a two-block test followed on one branch by an *ordinary* $O(T+w)$-step decision. The ordinary public input has just $n+O(w)$ bits. The two new blocks use $O(1)$ word choices in total. Thus any constant-alternation speedup applying to all these short-input ordinary predicates at these clocks carries over, up to $O(w)$ additional time and two blocks.

Use the private-coin verifier diagonal for empty rows, interleaved with the equality trials described below. At stage $j$ choose the trial input length $n_j$ beyond the entire freezing frontier and put $w_j=12\lceil\log_2(n_j+2)\rceil$. Write $\ell$ for binary length, taking $\ell(0)=1$. Require $\ell(n_j)\ge2^j$ and, after the first stage, $\ell(n_j)>2w_{j-1}+2$. All stages mark at most one pair $(a_j,b_j)$, with $\ell(n_j)\le\ell(a_j)\le w_j$ and $b_j<a_j^2$. All future row keys exceed the current frozen frontier. In particular marked row keys have distinct, at least geometrically growing binary lengths.

On a row trial choose the mark, if needed, in row $a_j=n_j$ among $0\le b_j<n_j^2$. Truncate the verifier at $\lfloor n_j^2/8\rfloor$ total steps and reject on overflow. If the maximum acceptance probability of the truncated verifier on the provisionally empty row is at least $1/2$, some position is queried by an attaining strategy with probability at most $1/8$. Marking it leaves a cheating strategy accepting with probability at least $3/8$, including in the untruncated protocol. If the maximum is below $1/2$, keep the row empty. Repeat each capped uniform verifier at fresh lengths. Freeze the full range of first operands available during its trial, as well as the entire $w_j$-bit domain, using the larger frontier. All later stages take place beyond that frontier. This gives the recursive oracle and the relative native linear-time separation as in the original construction.

At operand width $w$ record precisely the marked pairs for which both operands fit. Their row lengths sum to at most $2w$ by doubling, and $\ell(b_j)\le2\ell(a_j)$. A unary length followed by the bits for each operand and a terminator for the list costs $O(w)$ bits in total. Parse the list into two initially zero, directly addressed work banks. At index $a$ one bank contains the occupied flag and the other stores the partner $b$. Reject malformed syntax, overlong entries, and duplicated row keys. Lookup tests the flag and compares the full second operand with the stored one. The work banks require no scan of their address range, and at most $O(w)$ locations are written even on a malformed code of the allowed length. A fixed host coefficient large enough for the two bank tags suffices when the source uses the full $w$-bit address range. The whole setup takes $O(w)$ word steps even when parsing the code bit by bit.

For the simulation existentially choose the packed description. Universally select either a pair of operands or the computation branch. A pair challenge calls the actual oracle once and compares the result with the decoded table. On the computation branch, the ordinary decision predicate parses the same description, builds the directory, and runs the program with its calls replaced by lookups. The rejecting convention for invalid syntax is used at the root or in the computation branch. The predicate can parse and initialize its own directory directly from the short public code, so the expanded directory never has to be passed as public input. All pair challenges pass precisely when the candidate implements the actual instruction at this width. This proves item 3. The statement is at the levels of ordinary predicate, clock and public length specified above. If an available speedup is for decision at fixed clock exponents on short public inputs, adding $O(w)$ bits of metadata preserves these exponents.

There are also nonuniform fan-in-two Boolean circuits of $O(w)$ gates and $O(\log(w+2))$ depth for this instruction at every operand width. For both operands compute shared flags for all suffixes of high bits being zero. A balanced binary interval tree computes the OR within every interval on an upward pass, then sends each child the OR of the bits to the right of its interval on a downward pass. This gives every suffix flag in linear total size and logarithmic depth. Compare the low significant bits to each listed pair in a balanced tree and check the corresponding two high-zero flags. The sum of the significant lengths is $O(w)$, and the answers can be combined by one balanced OR. The hardwired advice or circuit is not uniformly supplied to the statistical verifier. An untrusted prover can name a candidate table, but the one-change calculation prevents a statistical verifier from checking it across operands cheaply. One universal operand challenge does check it. ## A uniform explicit circuit can miss just one operand pair

The same construction can supply a uniform polynomial-time generator on input $1^w$ for a circuit $C_w$ of $O(w)$ gates and logarithmic depth with the following promise. On the **entire** two-word domain, $C_w(a,b)\le O(a,b)$ and the number of disagreements is at most one. Even with this particular circuit supplied, verifying perfect agreement has no statistically sound interactive proof of verifier work $o(2^{2w})$ and polynomial messages at $w=12\lceil\log_2(n+2)\rceil$, with padded input $0^n$. This statement uses ordinary explicit gates in the approximation, and still requires access to the oracle for the target of the comparison.

Implement the computable stage construction on a fixed bit machine with a logical step counter. A transition may read the counter one bit at a time. Simulating its first $w$ transitions, including the counter updates, takes polynomial time in $w$ on an ordinary machine. Emit a marked pair as a completed record only when its stage publishes it. In addition to the numerical conditions above, choose $\ell(n_{j+1})$ strictly greater than the cumulative step count through publication and completion of stage $j$. At stage $j$ delay the publication of any current mark until more than $w_j=12\lceil\log_2(n_j+2)\rceil$ cumulative transitions have elapsed. These are finite delays. They do not alter any of the finite tests. No time bound is imposed on computing the actual recursive oracle.

To generate $C_w$, simulate the first $w$ transitions and compile their completed marked pairs within the visible domain into the suffix-flag circuit above, in a fixed canonical order. A partially written pair has no completed record. If two visible stages $i<j$ both had unpublished marks at that time, stage $i$ would have finished before $\ell(n_j)\le\ell(a_j)\le w$. Thus at most one pair can be missing. This is a width-dependent family of approximations. An unpublished mark can enter the public approximation at a later width. The circuit generator uses only ordinary computations. It reads the width in unary and outputs gate indices in binary in polynomial time in $w$. [Spacing implication in Lean](../lean/OpcodeReplay.lean)

Interleave two types of verifier trials, repeating every candidate of each type. The earlier row-emptiness trials preserve the first lower bound and the relative linear-time separation. For an equality trial, present $0^{n_j}$ and the canonical circuit $C_{w_j}$ to the candidate verifier. All earlier stages finished by step $w_j$, and no mark of the current stage can have been emitted by then. Thus the text of this circuit is determined from the earlier pairs **before** evaluating the trial. Run the verifier on the provisionally empty new rows, with this same public text. On the entire visible domain it is an equality instance. Put $D=2^{2w_j}$ and clip the verifier to $\lfloor D/16\rfloor$ steps, rejecting on overflow. If the clipped acceptance maximum is below $1/2$, keep the row empty. Otherwise consider all $D/2$ pairs with first operand in the upper half of the $w_j$-bit range and arbitrary second operand. Each row key is fresh, has length $w_j$, and is large enough that every proposed second operand is below its square. Under a clipped strategy attaining that maximum, some candidate pair is queried with probability at most $1/8$. Mark it. This changes the equality answer while leaving the public circuit and all its gates identical. Freeze all rows within the maximum of the candidate verifier's operand range and the full $w_j$-bit domain before proceeding. These choices preserve the verdict at this trial permanently and keep the post-change pair within the promised distance. The coupling uses no restriction on the number of rounds or computation of the prover. At the prescribed width the domain size is polynomial in the padded input length, so the ordinary polynomial caps cover every proposed sublinear-in-domain verifier. An exhaustive deterministic scan matches the $O(2^{2w})$ work bound. Generate the uniform list of published pairs once, put them in the direct dictionary, then compare one actual and one proposed value at each pair.

The lower bounds also hold for expected work on genuine positive inputs. A sound verifier with valid communication caps cannot trigger the marking case on any of its sufficiently large assigned trials. If it did, the clipped strategy would extend to a cheating strategy accepted with probability at least $3/8$ in the final oracle. On each such trial the approximation is therefore exact (or the selected row is empty in a row trial). The clipped optimum is below $1/2$. Every strategy attaining completeness $2/3$ for the actual untruncated protocol must encounter the cutoff with probability at least $1/6$, by coupling with its own clipped interaction. Its expected verifier work there is $\Omega(D)$, respectively $\Omega(n_j^2)$. This argument requires polynomial bounds for the message representations on the trial and a finite number of coin bits per clocked verifier step. It allows long execution paths beyond the cutoff. [Finite cutoff count and work bound](../lean/OpcodeReplay.lean)

Consequently the generator supplies a uniformly explicit approximation, correct except possibly at one of $2^{2w}$ pairs. At a particular width one optional pair repairs it exactly; comparing a guessed repair against every operand is one universal challenge. Statistical verification with a constant gap still faces the single-change lower bound. If the public circuit is promised *exact* and no external agreement is to be checked, counting its marked entries is governed instead by the explicit-circuit protocol above. These results concern different access to the unknown value.

## What the two simulations say about the SAT objective

For quadratic or cubic SAT, guessing a full binary transcript before building a bounded-acceptance formula still pays $T$ public bits. This defeats the hoped-for saving on that SAT call even though placing the transcript in RAM took $O(T/w)$ steps. The sparse instruction shows that the earlier statistical impossibility persists with a very short *nonuniform* instruction description while any short-input ordinary alternating speedup would still lift to that extension. A counterexample to that speedup for this sparse opcode would already refute the corresponding ordinary uniform simulation. The existence of the speedup for ordinary high-clock deterministic RAM computations, and the unrestricted SAT lower bounds, remain open.
