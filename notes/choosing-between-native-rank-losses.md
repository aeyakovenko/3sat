# A two-date disjunction with no fast choice of endpoint

The actual [past-conditioned native scheduler](learning-from-earlier-sat-verdicts.md) supplies an unconditional verifier of a two-date disjunction once the output pin is changed. Let $L(e,j)$ say that reporter rank $e$ **does not win** at date $j$. The unmodified scheduler computes the winning rank or default marker as part of its chronological execution and records it in the history. Build an explicit ordinary 3-CNF for this fixed deterministic stage computation and assert that its winner differs from the public $e$ (a default differs from every rank). Taking $e$ active puts its identifier in $O(\log(j+2))$ bits. The same regular bounded-run layout as the [parsimonious native compiler](projected-parity-holes.md#a-parsimonious-ordinary-3-cnf-near-the-native-clock), with a polynomial-in-$j$ output comparison, gives $2^j\operatorname{poly}(j)$ encoded bits and polynomial-in-$j$ time per locally generated input word. Comparing with a public rank does not alter the scheduler or rerun it with a different history.

For every $i$ and $e$, $L(e,i)\lor L(e,i+1)$ holds: a real winner retires permanently. The two underlying computations are at distinct dates. A verifier for the disjunction needs no challenges, replies, or future data. Nevertheless a uniform, sound, fast selector can fail to choose either endpoint even on a sequence of pairs where **both** formulas really are satisfiable.

## A reporter that offers only when the selector identifies its next loss

At each even start $i$, a fixed deterministic RAM program $D$ gets $e,i$ and the genuine history through $i-1$. It may claim $L(e,i)$, claim $L(e,i+1)$, or abstain. Require soundness only for starts with $e$ active and still unretired. A time bound on unsuccessful or divergent executions is unnecessary. The native clock charges each virtual formula read for the work of its local generator. If physical formula words are instead given at unit cost, simulation gives only the corresponding bound divided by the maximum word-generation cost, which is polynomial in $i$. Finite exceptions to soundness are permitted under one common cutoff in the start date.

**For every such sound selector there are infinitely many actual ranks $e$ that never win. At each such rank there is $c_{D,e}>0$ such that every claim at every sufficiently late even start takes more than $c_{D,e}2^i$ steps.** An $o(2^i)$ selector at these ranks must eventually abstain on every even-start pair. No uniformly correct total chooser has this subnative clock on all active unretired ranks, even if convergence of the clock ratio may depend on each fixed rank.

Make infinitely many copies of a reporter with different literal tags. Each determines its own actual program rank $e$ using the existing effective rank specialization. A copy stays silent until it can identify an even-start pair on which it was already active at the start. At either date, reconstruct the exact prefix preceding the even start and run $D(e,i,\text{prefix})$ at the start's word width. If $D$ names the current date, emit a fixed legal word; otherwise stay silent. At the second date the simulation ignores the outcome at the first date, so it reproduces the same deterministic choice. The disjoint pairing ensures at most one offer per pair. Simulation may time out and then emit nothing. Fixed-rank interpreter overhead is constant per simulated instruction, with polynomial-in-$i$ setup for rank, history and word-width adaptation. Both dates have budget at least $2^i/2^{e+1}-1$ for this fixed rank. For each fixed $e$ choose $c_{D,e}>0$ small enough to cover both fixed simulation constants and leave time to emit the word. At every sufficiently late eligible pair, a choice computed within $c_{D,e}2^i$ steps therefore results in an actual timely offer on the selected date if $e$ remains unretired. [Self-indexed word reporters on the same scheduler](winner-informed-positive-stages.md#a-word-reporter-that-actually-wins)

Only finitely many ranks have activated by any fixed soundness cutoff. Take any of these tagged copies activating later. If $e$ ever wins, it offered on the very date declared a loss by $D$ at an eligible pair start. This contradicts the soundness of $D$. Thus $e$ never retires. A timely claim at a sufficiently late even start would cause its offer on the selected date, and a smaller rank would have to win instead. Each smaller rank can win only once. After their finitely many wins this is impossible. Both $L(e,i)$ and $L(e,i+1)$ hold on every later pair for this unretired $e$. For a total chooser assumed correct beyond a uniform cutoff, taking a new tag repeats the contradiction past that cutoff. This gives the stated unbounded errors. The smaller-rank argument is the same counting principle that bounds a [tag's delay before a genuine win](../lean/WinnerInformedStages.lean).

There is also a single infinite increasing sequence of unretired ranks with eventual abstention for **every** fixed uniformly sound subnative selector. For each finite list of sound subnative selectors, form one program which runs them all at the same start and returns the first available claim, or abstains if all abstain. Its time is still $o(2^i)$ at each fixed rank, and its late abstention forces every constituent to abstain. Enumerate the countably many sound selectors externally. For the first $r$ choose a fresh tag larger than all previously chosen tags and activating after their common soundness cutoff. On the ranks so chosen, each fixed selector eventually abstains throughout every sufficiently late rank's tail of even starts. The selection of the common rank sequence is existential; it does not require recognizing sound programs.

Under deterministic $O(n^k)$ SAT, the same eventual absence of claims holds for a fixed uniformly sound nondeterministic verifier with a branch guess choosing either endpoint at $T_i=2^{\lfloor i/k\rfloor}/(i+1)^B$, for sufficiently large fixed $B$. Test the two individual bounded acceptance questions by ordinary SAT and select the first endpoint with an accepting branch. The encoded reduction and search cost $(T_i+\operatorname{poly}(i))^k\operatorname{poly}(i)=o(2^i)$, including simulation of any physical formula reads. Thus on the tags selected for this compiled deterministic program there are eventually no accepting branches for either endpoint. This gives no efficiency bound for deciding unrestricted SAT itself.

## Where substitution of the pin loses the SAT contradiction

For the [trace-product pair criterion](public-challenges-for-two-future-verdicts.md), any reporter that detects a positive verdict can propose the all-zero word at its own rank. If it won, it would falsify that positive verdict. In contrast only rank $e$ can falsify $L(e,j)$ by winning. A detector specialized to a different rank $f$ produces no contradiction with $L(e,j)$ even when $f$ wins. This also matters if one tries to hardwire a cutoff after $e$'s possible win: changing a program's text generally changes its rank, and a retired $e$ cannot win again. For one fixed $e$ there is always a nonuniform finite cutoff beyond its possible win, after which a constant choice is correct. An eventual correctness threshold allowed to vary freely with $e$ would make the total-choice statement false. The theorem uses one uniform soundness guarantee across active ranks. The tagging argument also accounts for knowing one's own rank; that information by itself cannot select a sound endpoint on these fresh tags.
