# Certifying relative outputs after a one-word preprocessing phase

**Research journal, 24 November 2026.** Can two computations be compared without certifying their shared, possibly very long, preprocessing phase? For local parity equations the selector from the [parity-fiber construction](parity-fibers.md) can itself have a particularly simple form. Its expensive work depends only on the public prefix and produces one ordinary RAM word. A fixed short algorithm can answer all subsequent queries using that word. There is an exact limit to verifying the answers while treating the saved word as arbitrary.

## Compressing a selected array for local observations

Use the previous notation. There are h≤√log₂ n programs, D=2^{Θ(n)} slope coordinates, and each query asks for S(b,·)·z. Suppose now each admitted equation explicitly lists at most q=(log n)^{O(1)} coordinates with a right-hand bit. Coordinates can repeat and their coefficients add modulo two. As before a fixed number of Boolean quantifier blocks and n^(3/2) construction and bit-size budgets are available for testing admission. The conclusion holds for any fixed polynomial exponent in the bound on q.

If the affine solution sets leave any array uncovered, some **word-sized description** gives an array outside every one of them. At an uncovered array, choose one violated equation for each program. Let F be the union of the listed coordinates, of size k≤hq. By the sparse-support lemma, the selected right-hand values of these h tests can be realized by a set B of at most h coordinates. Intersect B with F. An array that agrees with its indicator on F still violates all selected equations. It may take any values away from F. [Sparse-support proof](../lean/ParityFibers.lean)

Encode the coordinates as integers in [0,D). For a set of k integers in that interval, there is a prime p₁=O(1+k²log(2D)) whose reduction map is injective on the set. The product of the nonzero pairwise differences is at most D^{k(k−1)/2}. If all primes through a sufficiently large constant times 1+k²log(2D) divided that product, their product would be larger, by the elementary Chebyshev bound on the logarithm of the primorial. Use the same argument on the first residues to choose p₂=O(1+k²log(2p₁)). Handle k≤1 with any fixed prime. This prime universe reduction occurs in the classical perfect hashing construction. [Fredman, Komlós and Szemerédi, Lemma 2](https://www.cs.princeton.edu/courses/archive/fall09/cos521/Handouts/storingasparse.pdf)

Store p₁, p₂ and the at most h values H(x) for x∈B, where H(x)=(x mod p₁) mod p₂. The returned array is one exactly when the queried residue occurs in the stored list. On F this agrees with B by injectivity. Since k=polylog(n), p₁≤log(D)·polylog(n) and p₂=polylog(n). Using field widths determined by n and the fixed q bound, the whole description has

    log₂ log₂ D + O(log log n + h log log n) = (1+o(1)) log₂ n bits.

Thus it fits one word with any fixed width constant greater than one for sufficiently large n. The selected array may have many nonzero coordinates, while its stored list has length at most h. For a query on b,z, scan the coordinate strings to compute the residues and take the requested parity in n·polylog(n) RAM time. The evaluation program is fixed and uses no SAT call.

Under linear SAT this description can be produced in n^(3/2+o(1)) RAM steps from a alone. For an alleged description, ask whether each listed program has an admitted equation that it violates, by universally selecting the program and existentially selecting its local equation and admission witnesses or challenges with their original quantifier order. Every local coordinate can be evaluated in n·polylog(n) time and only q such evaluations are needed for the single selected equation. It is unnecessary to enumerate the relevant coordinates or find the primes by exhaustive search. Prefix-fix the O(log n) description bits using a satisfiability test for existence of an extending description each time, with a fixed default if none exists. Fixed-block elimination preserves the time bound. Therefore even restricting the comparison to predictors with this literal two-phase architecture preserves the proposed diagonal: the hypothetical counterpredictor itself belongs to the family, with ample margin below the n² universal clock. [Fixed-block checking](linear-quantifiers.md)

## A fast verifier and its exact loss on a pointer

For any syntactically two-phase program that discards its preprocessing workspace, try all potential retained words *symbolically*. To verify a proposed parity equation involving q output probes, universally quantify the common retained word and check that the q executions of the terminal algorithm give the asserted parity. Basis-vector probes read individual slope bits conditional on linearity. If a terminal execution takes A steps, the explicit check costs q(A+n)polylog(q(A+n)) bits and construction time by standard RAM history verification. It yields correct equations regardless of preprocessing time, including cases where a relationship between several terminal responses holds for every retained word. The same construction can allow a common unknown memory at the cut: when a suffix computation first reads an address before any private write to it, use a common initial value across all suffixes. Assign private copies to subsequent writes in each execution. Sorted first-read records enforce common initial values without writing down the whole memory. The syntactic split must genuinely place all input dependence that can differ between runs in the terminal phase; private writes after the cut are allowed. [RAM history checks](linear-quantifiers.md)

Now suppose the retained word is simply a pointer j∈{0,…,p−1}. On query x∈{0,1}ᵖ the fixed terminal code returns xⱼ. These are legitimate parity-fiber slopes: use p bits of the salt b as x and output xⱼz₁. Other input bits may be ignored. For any explicit list x¹,…,xᵗ the XOR of the corresponding slope values is exactly the jth coordinate of x¹⊕⋯⊕xᵗ. Thus every affine fact sound for the actual pointer but false for some other pointer excludes a specific candidate value. Conversely, an exclusion j≠k certifies equal responses on 0 and the unit vector eₖ. Arbitrarily many relative probes give no finer kind of linear information on this example. The terminal RAM uses one indexed bit read from x.

There is an information bound for this test. If a family with K retained bits can distinguish every pair among D possible coordinates, the D coordinate signatures across all 2ᴷ snapshots must be distinct. Hence D≤2^{2ᴷ}. At D=2ᵖ the pointer family distinguishes every pair with p modes, meeting the cardinality lower bound exactly; deleting mode k makes 0 and eₖ indistinguishable. More generally if every nonempty parity of at most q distinct coordinates is nonzero on at least one snapshot, the XOR signatures of all subsets of size at most ⌊q/2⌋ are distinct. Thus the number of snapshots is at least log₂(Σ_{t≤⌊q/2⌋} binom(D,t)). This counts states of the terminal evaluator over all allowed preprocessing outputs. It does not imply that they are all reachable on one prefix.

## Many unconditional equations when their supports may grow

The common-state verifier actually attains the required ranks for every program in a restricted family. The quantitative mismatch is in the number of coordinates per equation. Let the retained state have a specified cap K=⌈log₂ n⌉+e, where 0≤e=o(log n), and cap the terminal code's universal running time by A=n·polylog(n), with fixed encoding overheads. For every public prefix a and every program enumerate conceptually the L=2ᴷ terminal outcomes at a given coordinate, one per hypothetical state. Use basis-vector probes if the terminal algorithm's domain also includes z. This gives a binary column of length L. For k'≤g+1 divide the D coordinates into k' disjoint groups of size at least ⌊D/k'⌋.

Within each group take the XOR signatures of all r-element coordinate subsets. There are only 2ᴸ signatures. For r a sufficiently large constant times 1+2ᵉ, one has r=n^{o(1)} and log₂ binom(⌊D/k'⌋,r)>L: the left side is at least r(log₂ ⌊D/k'⌋−log₂ r), while log₂ D=Θ(n). Two distinct subsets therefore have the same signature. Their nonempty symmetric difference gives a homogeneous equation with at most 2r coordinates that holds for *every* retained state. The equations from distinct groups are independent by disjoint support. Taking k'=g+1 gives at least |i|+1 independent certified equations for **every** program, on **every** prefix.

The uniform verifier accepts a listed equation if the XOR of the terminal responses at its explicit coordinates is zero for every K-bit state. It does not have to find the colliding subsets or enumerate the 2ᴷ columns. With 2r probes, its fixed-block formula and construction cost are n^{1+o(1)}. One may provide a constructible upper bound on r with this growth. This is a direct construction of sound relative-output certificates for arbitrary preprocessors under the stated state and query-phase caps.

Trying to conclude linear SAT fails at the interface between this certificate and its selector. The sufficient arity bound provided here is O(1+2ᵉ). Substituting this arity in the two-prime construction gives a description of at most log₂ log₂ D+O(h(e+log log n)) bits; it does not establish the required *exact cap* ⌈log₂ n⌉+e for the self-predictor. Even two bounds of the form (1+o(1))log₂ n need not be ordered in the required direction. For the actual self-predictor's terminal code, any array it produces from one of the tested states satisfies all universal common-state equations by definition. A genuine escape must exploit which state the preprocessing reached, change the certification method, or justify a different resource comparison.

## A terminal algorithm with a one-probe gap

The query boundary is exact for a different explicit terminal family. The retained state specifies either zero or one squarefree monomial of degree at most d in a p-bit query address x, with d<p. The tail reads its selected input coordinates and takes their product. A relative test is a parity sum over q distinct addresses with a claimed right-hand bit. On one side, *every* nonzero homogeneous test with q<2^(d+1) can be falsified by some retained monomial. On the other, a homogeneous test on the 2^(d+1) vertices of any coordinate (d+1)-cube is true for every retained state. Thus an extra probe at this exact threshold can change the existence of any nontrivial fact independent of preprocessing. This is the dual minimum distance of the binary Reed–Muller code, here applied to the states of an explicit terminal program. [Muller](https://doi.org/10.1109/IREPGELC.1954.6499441)

For the lower bound let X be a nonempty set of fewer than 2^(d+1) addresses. If |X| is odd the constant monomial works, which also handles d=0. Otherwise split X on any coordinate j that takes both values. Its smaller nonempty side has size less than 2^d. By induction a monomial M of degree at most d−1 has odd sum on that side. Multiply by its indicator xⱼ or 1+xⱼ. In the second case at least one of M and xⱼM has odd sum, supplying a monomial in either case. On a full (d+1)-cube at least one varying bit is absent from any degree-d monomial, so its values cancel in pairs. A claim with right-hand bit one is always falsified by the zero state.

There is a simultaneous version. If h selected local equations use at most q addresses apiece and hq<2^(d+1), the evaluation vectors of the degree-d monomials span all functions on their joint address set: a proper span would have a nonzero annihilating mask on fewer than 2^(d+1) addresses. Any consistent set of h desired right-hand bits is realizable by the XOR of at most h such monomials, by choosing pivot columns in this linear system. The terminal state lists at most hd input-coordinate indices. For a single program with fixed d its state occupies O(log n) bits. Certifying a strictly shorter equation about this family requires some knowledge of the retained state, however complicated or simple the preprocessing may be.

## Can a proof at least rule out one pointer value?

Fix p=⌊n^(1/4)⌋ and any uniform sound exclusion verifier V taking a program description i, public prefix a (with n available), and candidate pointer k. Soundness means that whenever its certificate is accepted, the designated n²-clocked preprocessing program does not return k, taking zero as the default. Assume V has a fixed number of quantifier blocks and size and construction cost n^(3/2). Under linear SAT there is a fixed preprocessor i₀ that actually returns zero on **every** a at all sufficiently large n, yet V cannot certify i₀'s pointer differs from any k on any of these prefixes. The program determines its own literal description using fixed syntactic specialization. It tests whether any k is excluded for this description and prefix. If there is one it outputs the first such k, and otherwise it returns zero. Prefix-fixing k costs O(log n) fixed-block queries, so the n² universal cutoff permits this fixed program to finish on all sufficiently large inputs. A positive test would falsify V's own exclusion. The same obstruction is unconditional for ordinary deterministic verifiers with at most λlog₂ n proof bits for fixed λ<1/4: enumerate all p candidate values and all proofs. The resulting time is n^(7/4+λ+o(1)), still strictly below the cutoff. [Program self-reference construction](certificate-reflection.md)

The word-sized selector and the common-state check remove the necessity of replaying a long preprocessing computation for relations forced by the terminal code. The pointer example shows exactly what extra state information the check needs to distinguish on its simplest full family. I found no sufficiently fast certificate of an excluded value that works for every unrestricted preprocessor, even allowing the public prefix to depend on the program and the length.

Exhaustion of all 65,535 nonempty masks on four-bit addresses gave minimum valid-test weights 2, 4, 8 and 16 at degrees zero through three.
