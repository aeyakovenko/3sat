# Certifying an actual computation from the pathwidth of its memory accesses

**Research journal, 24 November 2026.** Suppose a short program prints a candidate predecessor of the project's first missing output. Make a graph of the *actual* run by joining consecutive instruction times and consecutive visits to each tape cell. If this graph has pathwidth at most k, there is a nondeterministic verifier using O((k+1)(log B+n)) bits and B·poly(k,n,log B) time for a B-step run on a public input of O(n) bits. The verifier guesses the program, the events, their memory links and their layout together. It can enforce global coverage while storing only live events. Under linear SAT this gives a width criterion on the short descriptions of the actual predecessors.

## Certifying coverage in a layout supplied one operation at a time

Consider D distinct public vertex labels and a connected public graph on them of constant degree. Further named edges and their predicates may depend on the values guessed for the vertices. Each vertex record has a bounded number of ports. A port specifies a neighbor label, a reciprocal port name, and the local condition on the two endpoint records. The connected public edges are mandatory. Introduce a record, check an edge between two live records, or forget a record. Check each port exactly once using a mask per live record. An edge check must pass at both reciprocal ports and sets both bits. At forgetting require every present port to have been checked. Start and end empty, require the anchor label once or more, and count at most D introductions. Cap the number of simultaneously live records at k+1. Repeated introductions of forgotten labels are syntactically permitted.

On an accepting schedule the introduced labels are closed under public neighbors, since each port of each occurrence was matched. The anchor and connectedness force coverage of every label. With at most D introductions, each then occurred exactly once. Its live times form an interval and each edge was checked with both ends live. These live sets are a path decomposition of width at most k. All guessed vertex records therefore define a single global assignment satisfying all port checks. Conversely, for any consistent assignment with a width-k path decomposition, introduce a vertex at its first bag and forget it after its last. Between bags first forget the departing vertices, then introduce the arriving ones. Check each edge once in a bag containing it. This supplies an accepting sequence using O(D) operations for constant degree. A verifier can cap the schedule accordingly. In particular the few records retained on a branch need no indices into a supplied decomposition, and the guessed graph can depend on the data being checked. The [Lean proof](../lean/MemoryLayout.lean) shows that neighbor closure and the occurrence bound force a permutation of the labels.

An identity matching between two copies of grid sites plus two shift matchings can already impose every horizontal and vertical tile constraint. The identity forces both copies of a site to carry the same tile. The two shifts then check the two grid directions, with wraparound constraints disabled at a boundary if needed. This elementary grid encoding is also formalized in Lean.

For a public connected bounded-degree graph with explicit adjacency and no additional constraints this gives an ordinary nondeterministic recognition algorithm for pathwidth at most k in polynomial time and O((k+1) log D) space. The maximum degree supplies the constant-size per-occurrence mask. The parameterized complexity literature discusses supplying decompositions as part of the input, and the computational problem of constructing them. Priority of this bounded-degree argument is unestablished. [Bodlaender, Groenland, Nederlof and Swennenhuis, §2.6](https://doi.org/10.1016/j.ic.2024.105195)

## Authenticating the visit chains

Fix the efficient universal multitape machine U from the missing-output construction. Guess a raw program of length less than d and a halting time h≤B; use h instruction records, treating a possible immediate halt separately. The chronological path on 0,…,h−1 is public. Each record specifies the bounded control, head positions, old and new symbols, and at most one predecessor and one successor for each tape. A chronological edge checks that U takes the displayed transition, including its head movements and control transfer to the next record. Initial conditions and the terminal transition check that the run halts on time with the prescribed output. Output can be monitored on the chronological path for an append-only convention. For a final output tape, track in chronological order the contents of the O(d) cells needed for the claimed length-d output and its delimiter, starting from their public initialized values, under the usual delimited convention. Charge O(n) bits per live record in that case. The machine and its output convention remain fixed across lengths.

The chronological path also carries the minimum and maximum address visited so far on each tape, initially indicating an empty range and updated by the current head position. Unit head movements make the visited addresses an interval. Thus the first visit to any address is locally recognizable. It must have no predecessor and read the prescribed initial symbol. Every later visit must have a reciprocal, strictly earlier, same-address predecessor on this tape. An edge between visits compares the earlier new symbol with the later old symbol. Each visit has at most one successor on that tape. Follow the predecessor of any noninitial occurrence repeatedly. Strict time decrease makes this end, and the unique first visit to its address is the only possible endpoint. Outdegree at most one then puts all occurrences of this cell on the same chronologically increasing chain. Its edges are exactly the real successive visits. This proves soundness by induction on instruction time, even when U's chosen program and the links were guessed. A genuine halting run supplies all the records. For ordinary random access one can instead add a path ordered by (address,time), authenticate it by increasing ranks through the full record count and check consecutive memory events there. The tape argument avoids those additional cross-address edges.

Put an edge between consecutive instruction times and between consecutive visits to each cell of each tape. For this actual computation graph the verifier accepts at budget k exactly when a timely short program for the specified output exists with pathwidth at most k. Each live event uses O(log B + d + log(n+2)) bits for the public inputs and conventions here. Looking up two of k+1 live events and updating the small records by scanning a multitape work array gives the stated time and space when log B=Θ(n) and d=O(n). A forward sweep touching m distinct cells followed by a reverse sweep has width at most two even when it stores m symbols. For the one-tape head sequence 0,…,m−1,m−1,…,0, let uᵢ and vᵢ denote the first and second visit to i. For each consecutive pair i,i+1 take the bags {uᵢ,vᵢ,uᵢ₊₁} and {vᵢ,uᵢ₊₁,vᵢ₊₁}, in this order. They cover all chronological and same-cell edges, including the turn. A claim that *all* possible fixed-page computation graphs admit small separators runs into the results on pushdown expanders. They concern the available graph class; for an output here one may choose *any* timely short program printing it. [Dvir and Wigderson, *Monotone Expanders: Constructions and Applications*, §1.2](https://theoryofcomputing.org/articles/v006a012/)

## Consequence for the missing output

Let d=n or 2(n−1), B=2^{20n}, and w be the first d-bit string U omits within B on all descriptions shorter than d. For a fixed rational 0<σ<5, put k=⌊2^{σn}⌋ (equivalently use a rounded-down binary exponent). Let Sₙ contain every d-bit output printed within B by at least one such description with actual computation graph of pathwidth at most k. Then w is absent from Sₙ. The verifier above has branch time 2^{O(n)} and work space 2^{σn+o(n)}. The project's quantified reachability simulation under an unrestricted linear-time explicit SAT algorithm decides membership in Sₙ in deterministic RAM time 2^{σn+o(n)}. The space bound concerns that verifier, whose computation is being checked. [Quantified reachability calculation](linear-quantifiers.md) · [Definition of w](address-diagonal.md)

Under this hypothesis there is a constant C such that, at all sufficiently large lengths, every trailing interval [w−K,w) contains at least (K+1)/C−1 words outside Sₙ. Here is the clock calculation even when σ is close to five. Set M=2^d. Guess an entire M-bit membership table, then universally challenge an entry and test it by the exact deterministic procedure above. This specifies exactly one table. On that table compute the [one-sided omission score](predecessor-batches.md) of every omission and order the omissions by decreasing score, breaking ties by position. The score of an omitted endpoint dominates the ratio of interval length to number of omissions for every interval ending there. The bound on the number of endpoints with score ≥u is M/u. The score and the word at a supplied omission rank are computable in O(M² poly(n)) RAM time by enumerating the candidate starts at each endpoint with prefix counts, then sorting the exact rational scores. To find a designated bit of the ranked word, put this computation together with the challenged entry in the fixed-block check. Query construction and evaluation thus cost at most 2^{max(4,σ)n+o(n)} RAM time under linear SAT, including the explicitly guessed table. Retrieving d successive bits changes only the polynomial factor.

A quadratic RAM-to-multitape simulation followed by a quadratic universal simulation fits inside B since 4·max(4,σ)<20. A fixed decoder can therefore print w from its rank among omissions, with fixed overhead plus at most the rounded-up logarithm of the one-based rank in raw payload bits. The absence of any description shorter than d bounds the score of w by a fixed C. Applying the score to [w−K,w] proves the claim, including w itself as one omission. Consequently a sequence of unbounded trailing intervals on which all but o(K) true predecessors have a qualifying short run would exclude linear-time SAT. The intervals and their layouts may both be unknown.

## A sorting transcript can retain a grid

Consider a RAM emitting l² records in row-major order (i,j), keyed by address j·l+i. All accessed addresses are distinct, so zero initial read values give genuine records. The two orderings used by the [multitape transcript verifier](single-valued-checkpoints.md) are row-major initially and column-major after sorting. In the ordinary record-movement graph of mergesort, connect successive records on each of those two scans, and connect copies of the same record through intermediate passes. The l² copy paths are disjoint. Contracting each path gives all horizontal and vertical grid edges. Any path decomposition of an l-by-l grid has a bag of size at least l: each row union one column is connected, and all such crosses pairwise intersect. Their intervals of bags therefore have a common point. A bag meeting every cross must meet every row or every column. Width is monotone under edge contractions, by replacing the endpoints in every bag with their common label. The record-movement graph thus has width at least l−1. The same minor occurs directly in a RAM execution that first visits all these addresses in row-major order and then in column-major order, using the successive-visit edge at each address.

This proves the obstruction for the record-movement graph and the stated RAM execution. The transcript verifier in the cited note specifies mergesort at the algorithm level. Identifying that grid as a minor of its literal multitape *instruction* graph requires a concrete implementation and a disjoint routing of the per-record copies through its tape visits. I have not assumed this for that verifier or for a short program for an actual diagonal predecessor.

The surviving question concerns the *minimum* pathwidth among all timely short programs for each predecessor. Neither the finite geometry of tape motion nor the sparsity of selected outputs bounds those minima on an actual trailing interval. I do not have that bound. A [finite experiment](../audits/trace_pathwidth_experiment.py) exhausts predecessor assignments for all 2,187 seven-move head walks. Exact subset dynamic programming gives pathwidth two for the forward/reverse traces on two through eight cells, and widths three and five for paired row/column traversals of two-by-two and three-by-three arrays. Lean checks the vertex coverage, the forcing of consecutive visits by reciprocal predecessor links, and a grid consistency identity. The machine simulation and running times are manuscript arguments.
