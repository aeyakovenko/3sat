# Every circuit has a coordinate face that a single SAT solver decides in linear time

Let $C$ be a Boolean circuit with $k\ge1$ inputs and $s$ binary gates, with arbitrary four-bit gate tables. There is a proper ASCII DIMACS 3-CNF file with $k$ independently variable physical bits, each used **once**, whose SAT verdict on this entire coordinate face is $C(x)$. All other bits of the file are fixed. Its physical length is $N=O((k+s)\log(k+s+2))$. Every declared variable occurs. Each accepting file has exactly one model.

One fixed, globally correct deterministic logarithmic-word RAM SAT solver decides every file in all these families in $O(N)$ steps. It also decides in $O(N)$ **every extension by any number of proper clauses on the original variables**, where $N$ now charges the entire extended file. Added clauses can change the answer. The guarantee survives clause and literal permutations, arbitrary injective renaming by canonical decimal identifiers, uniform polarity flips for any subset of variables, duplicate clauses, and legal comments and whitespace. It concerns files retaining the construction's clauses. Arbitrary equivalent formulas can have different clauses and lie outside the guarantee.

Consequently the restricted Walsh spectra, affine symmetries, and verdict-preserving successor maps at *every* successive input arity can coincide exactly with those of a prescribed circuit family inside a region where the same SAT solver runs in linear time. In particular this applies simultaneously to all lengths of the cyclic cover predicate with the affine classification in this journal, now on ordinary files with a growing number of independent bits. Even if the circuit family is nonuniform the solver is fixed and receives only the DIMACS file. There is no circuit description input or advice to that solver. ## One independent physical bit per input

Give every input or gate wire $i$ two different variable names $w_{i,0},w_{i,1}$. A true rail states the value of the wire. Use distinct fresh names throughout. Give input $i$, numbered starting at one, the decimal names $10i+2,10i+3$. Their printed names differ only in the low bit of the final ASCII byte. Assign consecutive names above that bank to the gate rails, then to three shared anchors.

Force the three anchors false by the seven proper clauses on them that forbid every other assignment. Pad each subsequent binary clause with the first positive anchor and each unit with the first two. Use the following clauses before padding.

* For every input include the positive unit $w_{i,x_i}$. This is the only data-dependent record for that input. For every wire include $(\neg w_{i,0}\lor\neg w_{i,1})$.
* For a gate $j=g(i,i')$ include $(\neg w_{i,a}\lor\neg w_{i',b}\lor w_{j,g(a,b)})$ for each $a,b\in\{0,1\}$. If the two input references and values coincide, remove the duplicate negative literal and pad the resulting binary. When the references coincide and the values differ, the two negative literals use distinct names. Wires are in topological order.
* Pin the zero rail of the output false. Force every unused numeric identifier below the highest allocated name false by a padded negative unit. There are $O(k)$ of these gaps.

The result has three distinct variables in every clause. All signs, decimal field lengths, delimiters, header counts, and occurrences of each input rail except its one selected unit stay fixed. The source-bit positions are distinct, and arbitrary simultaneous flips assemble the exact canonical file. There are $O(k+s)$ clauses and names, each of $O(\log(k+s+2))$ digits. The number of distinct occurring identifiers also gives $N=\Omega((k+s)\log(k+s+2))$ in the unpadded canonical layout: their total decimal length has that order.

Once the anchors are assigned false, each chosen input rail becomes true and its partner false. If the input wires of a gate have their forced values, exactly one relevant row forces the correct output rail true, and its partner is forced false. All filler names are forced as well. Before the output pin, this yields a unique complete assignment $a_x$ to the occurring names. Consequently an extended file with an arbitrary conjunction $D$ over these names has verdict $C(x)\land D(a_x)$. This also identifies why adding constraints on arbitrary *fresh* names falls outside the universal fast guarantee: those variables can carry a wholly independent residual SAT instance.

## A single solver that discovers the initial units

On a proper file, group clauses by the unordered triple of their unsigned variable names. On each such support the eight possible sign patterns forbid its eight assignments one at a time. Eight distinct patterns certify contradiction. Seven leave exactly one tuple; enqueue its three forced literals. Duplicates do not change the mask. Any conclusions from other supports are also sound, even when the added clauses introduce additional forced tuples.

Run unit propagation via occurrence lists and a queue. Return UNSAT on incompatible assignments or a falsified clause. If every clause already has a true literal, return SAT. Otherwise use complete assignment search on the residual formula. These operations are sound on every input. On a constructed file the original anchor support either gives its three initial units or has all eight patterns. After the three pins, the gate induction forces the entire original assignment unless a contradiction is found earlier. All extra clauses now have fixed values. In particular the residual-search branch is never needed at any length on these inputs. A global renaming or a polarity flip sends every such unit derivation to the corresponding derivation on the transformed file.

For the deterministic linear bound, skip comments and tokenize the input. Intern decimal identifiers in a trie with ten children per node, so a long or sparse name costs time proportional to its physical occurrence length and does not require allocating its numeric value. After interning, sort the three identifiers within each clause at constant cost. Group these triples by three stable counting-sort passes on the dense occurrence identifiers. Every distinct variable enters the propagation queue for processing at most once, and its assigned value visits each of its occurrences once; even tests of all three literals cost constant time. Conflicting or duplicate queue entries incur only the work charged to their generating clauses. The final scan also costs $O(N)$. The valid-file promise can be supplemented by ordinary linear-time syntax validation. Conventional circuit encodings have the same gate propagation property after a complete input assignment. The construction here arranges that assignment with distinct proper clauses, one changing physical bit per independent input, and an identifiable initial triple. ## The exact packed-word scale on parity

For the canonical files the same algorithm admits a branch taking $O(N/\log(N+2))$ word instructions. When the header's maximum numeric identifier is at most $N$, decode the names as native unsigned integers; the canonical labels meet this test. Take $b=\Theta(\log N)$ bytes small enough that $256^b\operatorname{poly}(b)\le N^{1/2}$. Precompute the finite lexical effect of each $b$-byte block, including its list of digit fragments, token finishes, signs and clause delimiters. Pack each fragment as its integer value and digit count, with a precomputed decimal place multiplier. An integer straddling blocks is assembled from the previous carry by a multiply and add, with range validation against the header if required. For very small headers the ordinary scanner suffices. A bounded header itself can be handled in constant many blocks on canonical inputs; a generic fallback to the byte scanner on an unrecognized header syntax preserves $O(N)$ on all encodings.

On the dense branch, use initially zero direct-address words to intern occurring integers up to $N$ and track the dense renumbering; no initialization scan over all $N$ positions is needed. The number of token fragments is at most the number of tokens plus the number of block boundaries that split a token, and whitespace runs internal to a block require no per-byte scan. Tokenization, grouping and propagation therefore take $O(1+N/\log(N+2)+c)$ steps for a canonical file with $c$ clauses. Here $c=O(k+s)=O(N/\log(N+2))$. Unit-cost word multiplication, packed input access and a fixed sufficiently wide logarithmic word are the native conventions. Take $C$ to be a chain computing the parity of its $k$ independent inputs with $k-1$ XOR gates. On **every** file in that face, every free bit is pivotal. The selector positions in successive input-unit records are separated by $\Omega(\log k)$ physical bits, because both shared anchor identifiers in every such record have $\Theta(\log k)$ digits. A word of $\Theta(\log N)=\Theta(\log k)$ bits contains at most a constant number of free positions. A correct deterministic solver must read each pivotal position before destroying its input information: until a word covering a changed bit is read, the execution cannot distinguish the corresponding opposite instance. Thus every correct solver executes $\Omega(k)=\Omega(N/\log N)$ input-word reads on every file in this face. The packed implementation attains that order. This lower bound has both verdicts and exponentially many proper files; it prices observing the independent data.

Restricting SAT to a coordinate face commutes with evaluating any circuit-defined verdict predicate, but the running time of a particular implementation is additional information. Even the entire sequence of spectra and successor maps only describes the restricted Boolean functions. A transfer to superlinear time would have to use how a proposed hard encoding makes *every* correct program process those data. Replacing the source predicates by exponentially large lookup circuits is always possible; the displayed length then charges those circuits. The physical size bound depends on the circuit size. A local requirement of consecutive physical lengths can also be met in the natural byte unit. For any finite interval of source arities $j=a,\ldots,b$, let $M$ be the largest canonical byte length on the interval. Append legal whitespace so the files at stage $j$ have exactly $M+j-a$ bytes. This changes neither the free-bit positions at that stage nor its restricted verdicts and maps. With circuits of size $O(j)$ on $[a,2a]$, every padded size remains $\Theta(a\log(a+2))$ bytes and the number of free input bits grows from $a$ to $2a$. This realizes arbitrarily long consecutive byte-length intervals. It makes no claim of a single infinite sequence with one new byte at every stage, or of a specific local edit relating the printed files.

There is even a globally injective physical bit map on each such consecutive pair if the source successor $g_j$ is injective. Permute coordinates and add the baseline bit vector to identify each face with $(x,0)$ inside its physical cube. In these coordinates use $(x,u)\mapsto(g_j(x),J_j u)$, where $J_j$ is any injective linear map on the complementary coordinates. The target has eight extra physical bits and one extra free bit, hence seven extra complementary dimensions. Undo the coordinate identifications. This preserves the affine or bounded-degree upper bound on the successor and preserves the SAT verdict on every point of the designated face. Injectivity on ambient bit strings does not establish SAT equivalence for proper files outside the face. A lower-bound argument using that global semantic requirement would need to prove it separately.
