# Making all small modular witness counts vanish on a SAT-equivalent family

For every nonempty signed-interval instance on \(s\) triangles, every \(K\ge2\), and every \(r\ge0\), one can append \(O((r+1)K)\) triangles to its single permuted list and preserve its verdict. Render the result as an ordinary proper 3-CNF \(G\) as described below. Put \(L=\operatorname{lcm}(1,\ldots,K)\). For every restriction \(\rho\) fixing \(h\le r\) Boolean variables of **the emitted formula**, one has the integer divisibility
\[
                  L^{r+1-h}\ \mid\ \#\mathrm{SAT}(G|_\rho).
\]
Counts refer to extensions on the remaining variables. The statement includes pins on newly added variables, at block boundaries, and on either truth value. Satisfiable prefixes have positive unrestricted counts. Unsatisfiable prefixes stay unsatisfiable.

Taking \(r=K=\lfloor\sqrt{s}\rfloor\) for large \(s\) gives this promise with linear overhead in the physical bit length \(N=\Theta(s\log s)\). Both the number of observed witness bits and the largest modulus can therefore grow on the order of \(\sqrt{N/\log N}\). Arbitrary explicit SAT already reduces to the unconstrained prefix in linear native time and encoded length. Conversely \(G\) is itself a SAT input. Thus a deterministic decision algorithm on this promise with deadline \(O(N^j)\) supplies the same deadline on all explicit SAT for \(j=1,2,3\). The same transfer works for fixed \(K\) with \(r=\Theta(s)\), or \(r=0\) with \(K=\Theta(s)\). ## A count factor at each pair of absolute boundary colors

The red triangles are \((y_i,z_i,y_{i+1})\). Colors are in \(\mathbb F_3\). Set \(y_0=0\). A sign \(d_i\in\{1,-1\}\) determines \(y_{i+1}=y_i+d_i\) and \(z_i=y_i-d_i\). An input permutation specifies one blue path through all the tips \(z_i\), whose consecutive colors must differ. To append an order, shift all its tip indices by the previous number of tips and concatenate in blue order. A boundary state is the ordered pair (previous blue tip color, current red base color). The transfer entry counts continuations between specified states, including the inequality to the first visited tip. At the very start there is no previous tip. The theorem appends to a nonempty prefix, so each of its completions supplies a boundary state.

First amalgamate the nine states into equal and different pairs, in that order. Color symmetry makes the two row sums to these classes well defined for any representative. Two six-tip orders have the following transfers.
\[
 A=(1,2,0,4,5,3)\longmapsto4\begin{pmatrix}1&0\\1&1\end{pmatrix},
 \qquad B=(1,5,3,4,2,0)\longmapsto4\begin{pmatrix}1&0\\1&2\end{pmatrix}.
\]
These are finite counts over 64 sign strings for each order. A suffix with totals proportional to \((1,x)^{\mathsf T}\) changes its ratio to \(x+1\) or \(2x+1\) when prefixed by \(A\) or \(B\). Starting at the empty suffix \((1,1)\), encode any positive integer \(q\) in a block word \(C_q\). For odd \(q>1\) use \(B\) followed by the code for \((q-1)/2\). For even \(q>2\) use \(A,B\) followed by the code for \((q-2)/2\). Values one and two use the empty word and \(A\). Its length \(\ell\) in blocks satisfies \(\ell\le2\lfloor\log_2 q\rfloor\). In particular the sum of the *absolute* transfer row from every different-color pair is \(4^\ell q\). [Finite matrices and decoder induction in Lean](../lean/SignedIntervalCountTiles.lean)

That row sum alone is insufficient for pins on distant absolute colors. The seven-tip order
\[
                             U=(1,2,0,5,3,6,4)
\]
has exactly **two** extensions from each of the nine possible incoming absolute states to each of the six different-color outgoing states. Every equal-color outgoing state has zero extensions. Let \(T\) be its matrix and \(D\) the set of different-color pairs, so \(T_{ij}=2[j\in D]\). This is an exhaustible statement about 128 sign strings per incoming state. For the absolute transfer \(H\) of \(C_q\), multiplication now gives
\[
 (THT)_{ij}=4[j\in D]\sum_{u\in D}\sum_v H_{uv}
           =24\,4^\ell q[j\in D].
\]
Thus the block sequence \(U,C_q,U\) contributes a multiple of \(q\) even after specifying *both* absolute endpoints. Summing over exits gives the same positive multiplier \(144\,4^\ell q\) on every prefix completion. An independent search through all 873 nonempty orders on at most six tips found no nonzero absolute transfer with identical rows. [Lean proof of all entries and the matrix product](../lean/AbsoluteTipReset.lean) · [Exhaustive search and independent matrix products](../audits/absolute_tip_reset_audit.py)

For each prime \(p\le K\), let \(q\) be its largest power at most \(K\). Append \(r+1\) copies of \(U,C_q,U\). The product of the distinct \(q\)'s is \(L\). The sum of their bit lengths is \(O(K)\), from \(\log L=\Theta(K)\). For the needed elementary upper bound, the ratio \(L_{2m}/L_m\) divides \(\binom{2m}{m}\) because each newly reached prime power contributes its prime to that binomial coefficient. Summing over dyadic scales yields \(\log L_K=O(K)\). The elementary sieve and per-power decoder use \(O(K\log(K+1))\) word operations plus the number of emitted tips. The compiler stores each \(q\) in a word and never constructs \(L\). [Chebyshev estimates](https://terrytao.wordpress.com/2014/11/23/254a-notes-1-elementary-multiplicative-number-theory/)

## Counting actual assignments of proper 3-CNF

Give each red base and each tip three Boolean flags, constrain exactly one color, and forbid each shared color on every triangle edge and every blue edge. Pin the initial base to zero. A sign flag for each triangle has its unique value forced by the two adjacent base colors, using the two negated color flags and the appropriately signed flag in a clause. For padding, three fresh variables are uniquely forced false by seven proper clauses, one forbidding each nonzero triple. Use one or two of these false variables to pad binary or unit clauses. Each clause contains three distinct variables. Every accepted sign sequence gives exactly one model including **all** auxiliary flags, and every model comes from one such sequence. For \(t\) tips there are \(7t+6\) variables, \(O(t)\) clauses and \(\Theta(t\log(t+2))\) physical bits in fixed-width decimal literal fields. Preparing decimal strings for all indices and copying them takes linear time in that length.

Fix the padding and boundary states first in the counting sum. Each sign or color condition in the interior of a block restricts that block's transfer. A shared vertex occurs in the specified boundary state and its filter may be assigned to the boundary itself. Equivalently assign each variable to the block that emits it and test it once. At most \(h\) of the \(r+1\) blocks for any particular prime power can lose their unrestricted transfer. Every term retains at least \(r+1-h\) entrywise factors of that prime power. Inconsistent pins give zero. Summing over all intermediate states preserves divisibility, and distinct prime powers are coprime. This proves the claimed integer statement.

For each \(h\le r\), it follows that *any* integer polynomial weight of total degree at most \(h\), summed over the full witnesses, gives a multiple of \(L^{r+1-h}\). Reduce on the Boolean cube and expand into monomials. Each monomial asks for the count with its support pinned true. Its number of terms and the total number of distinct variables across the polynomial are unrestricted. In particular, for a prime \(p\le K\) and any equations \(f_i=0\) over \(\mathbb F_p\) with \((p-1)\sum_i\deg f_i\le r\), the number of witnesses satisfying all the equations is zero modulo \(p\). Their joint indicator on the field is \(\prod_i(1-f_i^{p-1})\). The conclusion also applies to any adaptive sequence of residue queries with separately chosen pins within the budget on the same instance. Every answer is zero on both verdicts.

There is a separate, stronger estimate for dense binary hashes. Use one seven-tip source tile per vertex of the two-path source before appending these blocks. Conditional on one source coloring, the last auxiliary endpoint and the entire appended assignment, each source tile has two independent fillings. They fix both endpoints and both blue ports. The two local strings of Boolean flags, including the sign flags, differ only in that tile's private positions. If there are \(b\) source tiles, the fiber is an affine binary cube of dimension \(b\). Consequently \(k\le b\) arbitrary binary affine equations leave a multiple of \(2^{b-k}\) models, after summing these fibers. The elementary cube-degree argument gives even counts for polynomial filters over \(\mathbb F_2\) of combined degree below \(b\). When \((r+1)K=O(s)\), one can keep \(b=\Theta(t)\). Randomized isolation permits higher rank. [Exact ranks and sharp thresholds for the prefix](xor-isolation-in-seven-triangle-tiles.md) · [Valiant and Vazirani](https://doi.org/10.1016/0304-3975(86)90135-0)

## Which statements reach the RAM

Use the guarded source reduction first, then the seven-tip tiles and the count blocks. Changing a control to reverse the verdict only changes a bounded set of tip fields in the source part. Different controls own disjoint fields, the suffix is identical at fixed length, and the layout of the DIMACS renderer is fixed. The guard proof therefore applies to these same outputs. On **each** file of either verdict every correct promised solver must read \(\Omega(t)=\Omega(N/\log N)\) words when the number of appended tips is at most proportional to the source length in tips. An uncolorable induced subgraph on too few vertices is impossible for the same reason, since every changed edge has a moved endpoint in the prefix. The all-zero controls retain the reduction of arbitrary SAT. [Guard construction, two verdicts and physical reads](guarded-coloring-on-one-free-lane.md)

The count obstruction applies to specific operations on witnesses. In particular the appended list depends only on the length and parameters. Given that split, a RAM can discard the entire addition and decide the original prefix. An unrestricted program can inspect the clauses and use arbitrary intermediate representations. No step here forces it to evaluate any of these modular counts. The resulting time lower bound stops at reading a linear number of **words**.

On a positive formula with \(v\) Boolean variables the stronger *unrestricted* count multiple \(L^{r+1}\) already implies \(v\ge(r+1)\log_2 L\). Thus the count-block construction has the right order of variable overhead for this strong divisibility when applied to a fixed small prefix. For the weaker condition of divisibility by each prime just once after every \(r\) pins, a separator argument bounds \((r+1)K\) by \(O((w+1)v\log(v+1))\) at primal treewidth \(w\). For binary constraint chains the logarithmic loss disappears. These converses quantify costs of hiding counts. [Proofs and tight path example](local-witness-counts-and-treewidth.md)

The independent frontier DP scans the red order while retaining just the tip colors needed by future actual blue edges. It uses no prescribed tile matrices. The audit compares it with exhaustive PycoSAT model counts and a byte-level DIMACS round trip on all 873 source permutations through six tips, checks three actual signed flag pins against exact PycoSAT counts on every one of those small files, then checks the unrestricted factors and 200 more flag restrictions on larger extended orders (149 with positive counts). The Lean files certify the exact small tables and multiplication identities. The general compiler, restriction argument and RAM statements above are manuscript proofs.
