# Can the sparse parity verifier be recovered from unary questions?

**Research journal, 2026-11-24.** The parity-certificate proposal has a stronger consequence than a cubic time exclusion for arbitrary SAT inputs. For the CRT version of the sparse table J, a verifier attaining the proposed ranks would already separate linear nondeterministic time from much larger deterministic clocks on a tally language. At the original fixed verifier budget it would force slow SAT decisions on a uniformly generated, polylogarithmically sparse family of explicit 3-CNFs. The transfer uses the known location of J's possible nonzero coefficients. [Construction of J](coded-diagonal.md#fewer-claims-when-all-of-them-are-sound)

## Recover the proposed equations without knowing the sparse table

At source length n write N=2ⁿ and b=2n. Rows are the allowed binary linear forms on N coefficients obtained by taking a residue modulo a monic degree-b irreducible and then a b-bit mask. Fix the lexicographic table convention of the construction. For large n, every nonzero coefficient of J lies among the final d=nb coefficients. For each proposed signed row (ℓ,a), project to v=(ℓ restricted to those d positions, a). The projected row can be computed in poly(n) time. Compute X^(N−d) modulo the given modulus by repeated squaring, then take the next d powers and apply the mask. The bit length of the exponent is O(n).

Let R be one fixed nondeterministic verifier and T an integer time budget. Let W(n,T) be the binary span of the projections of every signed claim accepted by time T. Write D=d+1. The following queries have metadata consisting only of n, T and indices of O(log n) bits.

* A rank query at r asks for r independent projected accepted claims. Guess their original names and independent accepting executions of R, then check the projected matrix.
* A bit query at (r,i,j) guesses r independent projected accepted claims and checks bit j in row i of their reduced row-echelon form, with pivot columns ordered from left to right and pivot rows ordered by their pivots. Say yes precisely when that bit is one.

Binary search on the first query gives the exact rank r≤D. In the second query use that exact r. Every valid guessed set now spans W(n,T), so all witnesses give the same reduced matrix. When r=0 use the empty basis. This recovers W with poly(n) Boolean decisions, without extracting a witness from any decision. The input to each decision omits the original modulus and mask.

A deterministic program given the recovered matrix can propose every *original* signed row whose projection belongs to W. This is a finite-length guarantee. If the claims accepted by R up to T at this n are sound, the vector (J's tail,1) annihilates W. Consequently every new proposal is sound with respect to the *full* table. The set of proposals includes every original R proposal, so its full unsigned rank cannot decrease. Distinct original rows may have the same projection.

A local strengthening will be used below. Any at most n original CRT rows have exactly the same unsigned row rank after projection to the d tail coordinates. The product of their distinct irreducibles has degree at most nb. The last d powers of X span the whole residue space modulo this product, because multiplication by X is a unit there. Thus any N-coefficient table has a tail-supported replacement with the same residues at all these moduli. Any dependence on the restricted rows is therefore a dependence on the full rows. The same conclusion for signed rows follows by including the sign coordinate separately. For arbitrary larger collections the projected rank still need only be at least the smaller of n and the full rank.

## What the two clocks imply

Encode each query as a unary string 1ᴷ. An explicit suffix code suffices. Use the binary expansion of T≥1 followed by padding and the reverse of a prefix-free code of the metadata (n, tag, r, i, j). Each small integer in this code can use its binary digits preceded by a unary code for their number. Use exactly A⌈log₂(n+2)⌉ zero padding bits for a fixed sufficiently large A. Reading backward removes the metadata and prescribed padding and recovers T. Restrict log₂T≤2n, allowing every cap used here eventually. The resulting length satisfies K=T·(n+2)^O(1) and K≥T(n+2)^A. Malformed codes, non-unary strings and illegal indices are rejected.

These questions define **one tally language** T_R in nondeterministic linear time on a multitape machine. A scan verifies the unary input and counts its length in linear time using amortized binary carries. Decoding and checking integer fields cost poly(log K) before launching any long verification. Each query has an ordinary nondeterministic verifier taking T·poly(n) bit time, absorbed by the padding. This holds directly for a multitape R. For a word-RAM R, use standard word operations of bit cost poly(n) and width poly(n) on the clocks here. Guess the chronological memory events and their values and check the transitions, sorting by address and time to check write-to-read consistency. This gives a nondeterministic tape verification in T·poly(n) bit time, including each of the O(n²) trial rows. No assumption about how many work addresses the computation used enters the reduction. [RAM transcript simulation](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

Assume at a fixed computable cap T(n)=2ⁿ·n^(A₀), with A₀ a fixed nonnegative integer, the full normal ranks are unbounded along lengths where all claims at this cap are true. Then for each fixed 1≤c<20, T_R has **no deterministic multitape decider in O(Kᶜ)**. Given one, a single tape program reconstructs W at the designated cap and makes the membership proposals above. It writes each needed unary input, runs the decider, and computes the proposed row's projection on its own signed claim input. This takes 2^(cn+o(n)) tape time, inside the existing J stage cutoff of 2^(20n). For its fixed stage index i, all sufficiently large sound lengths must consequently have rank at most i−1. This contradicts unbounded rank there. A fixed deterministic word-RAM decider in O(Kᵘ), 1≤u<10, gives the same contradiction by simulating its writes on tapes with quadratic overhead and polylogarithmic word cost. These deductions use the original tape-staged J. Their conclusions bound fixed time exponents. They allow a larger polynomial-time algorithm for the tally language.

There is also a direct SAT formulation. For each n and every possible rank or bit query at that fixed cap, compile its nondeterministic calculation into ordinary explicit 3-CNF of bit length m≤2^(n+O(log n)). Use harmless repeated tautological clauses so that m≥2ⁿ. This is one uniformly generated family. Every member has a generation seed of O(log n)=O(log log m) bits and a generation time 2^(n+O(log n)). At most (log(M+2))^O(1) members have length at most M, since n≤log₂ M and each metadata index is polynomial in n. If an ordinary deterministic RAM were correct on just these formulas in O(mᵘ) time for any fixed 1≤u<10, the predictor would fit the same cutoff, including construction and tape simulation. Hence the rank premise would already give a time exclusion on this sparse promise family. Advice specifying the answers to the entire poly(n) menu can be short. The assertion concerns uniform decisions.

The factor of two in these exponent bounds comes from simulating the proposed deterministic RAM on the *tape programs staged in J*. One can define a different J with RAM stages by giving each simulated program a padded ordinary input of length 2ⁿ+poly(n) carrying the claim. Standard logarithmic input words can then address its exponential computation. Enumerate word-width constants and fixed programs, simulating at stage indices ≤n only constants ≤n, eventually including each fixed constant. Limit each simulated RAM to 2^(20n) of its own steps. The outer tape constructor can scan sparse lists of writes and directly emulate the bit operations of polynomial-width words in 2^{O(n)} total time. A standard RAM predictor for this variant can use larger O(n)-bit virtual words with constant-factor or polynomial-in-n bit overhead. A tally RAM or SAT-on-the-menu RAM with exponent strictly below 20 would now suffice for the contradiction. This changes the diagonal table whose parity facts the verifier must certify.

To avoid unnecessarily requiring the stronger exponent, one may instead set the tape cutoff in the definition of J to 2^(6n+⌈√n⌉). The factor 2^⌈√n⌉ absorbs every fixed polynomial in n from the rank questions, conversion and simulation. A cubic SAT algorithm on the displayed promise still reaches the contradiction, this time including the endpoint exactly. The direct tally transfer excludes O(K⁶) tape time or O(K³) word-RAM time under the verifier premise for this modified J. For padded RAM stages the corresponding cutoff is 2^(3n+⌈√n⌉). No verifier property for one cutoff automatically transfers to a different resulting J.

## A verifier may change its answers after a sound prefix

For a fixed candidate tally decider, form a tape predictor with its own positive stage index i available as a constant. Ordinary effective program encodings permit such self-reference: fix a template which receives its own template text, specializes that same text to itself using the encoding's program constructor, computes the index of this resulting specialized program, and executes the algorithm below using that index. The specialized program is the one that actually runs. These text manipulations take constant time for a fixed program. Alternatively use a length-lex program enumeration and hardwire a threshold large enough to exceed the chosen short program's index, by constructing it as an exponential tower from a short constant. Only the existence of one fixed program with the correct threshold is used.

For an upper cap U, use unary rank queries and binary search to find the *earliest integer time* T≤U when the projected signed rank reaches i. If it never does, abstain. Otherwise recover the whole W(n,T) by rank and bit queries, and use the same membership rule. The number of calls is poly(n) when log U=O(n). Suppose that at a tested length some unknown prefix T₀≤U is entirely sound and its full unsigned rank is at least i, with n≥i. The tail-projection lemma ensures the chosen T exists and T≤T₀. At T the projection is sound, so adjoining the sign does not increase its rank: the sign equals evaluation at J's tail. Therefore the resulting full proposals are sound and have rank at least i. This contradicts stage i at sufficiently large such lengths, within the applicable time bound. False claims that R emits after T₀ can be arbitrary. The allowed prefixes need not have a positive multiplicative gap before the first error.

In particular the same tally separation for T_R holds for unknown sound prefixes of unbounded rank below 2ⁿnᴬ⁰, with the preceding tally exponents. The polylog-sparsity assertion for SAT formulas used a *fixed* cap and does not follow directly for these adaptively queried times.

A verifier whose useful computation is substantially shorter would have a further consequence. Suppose that for **every** fixed ε>0 there are error-free prefixes of duration at most 2^(εn) with unbounded ranks along unbounded lengths. The effective verifier can be fixed even when the prefix time and the good lengths are not known. Then T_R is a tally language in NP outside P. Indeed a proposed polynomial-time tally decider runs in O(Kᶜ) tape time for some fixed positive c. Choose a positive rational ε<min(1,20/c). The self-indexed program runs the earliest-time search up to 2^⌊εn⌋, within 2^(c ε n+o(n)) tape time. Use ε/2 in the premise to absorb rounding. This contradicts the diagonal. The usual unary-to-binary translation consequently gives E≠NE: the binary length language of any tally NP language is in NE, and an E decider for it would put the tally language in P. A 2^{o(n)} verifier that attains the ranks and is sound on the chosen lengths is a special case. This derivation avoids assuming a computable sublinear rate for the verifier's useful prefixes. [Hartmanis, Immerman and Sewelson](https://people.cs.umass.edu/~immerman/HIS85.pdf) · [Goldsmith, Ogihara and Rothe](https://www.cs.uky.edu/~goldsmit/papers/tallysets.pdf)

## A finite menu cannot use sparsity alone

Try replacing support advice by a fixed menu of k partial predictors and relying on one being sound at infinitely many lengths. At a single length, if k≤n and every menu member proposes k or more independent full unsigned CRT rows, there is an at-most-k-sparse table in the known tail on which *every* menu member makes an error. Choose one row per member, fresh relative to all previously chosen rows, and demand the opposite of its proposed sign. Tail restriction preserves independence of the k selected normals by the CRT argument. The k affine equations therefore have a tail-supported simultaneous solution. A solution lexicographically minimized on this tail has at most k ones by the column-dependence argument used for J. This statement quantifies over all tables obeying the published sparsity and tail promises. It does not locate the particular J among them.

If every predictor uses rows from one common modulus, the required menu is larger. The b powers of X on the last b positions are a binary basis modulo that modulus. Polynomials of weight at most n=b/2 on those positions realize at least 2^(b−1) different residues, by complementing supports. Each menu member making g independent claims about this residue can be sound on at most 2^(b−g) possibilities. At least 2^(g−1) menu members are necessary to cover this sparse promise. A menu for all 2ᵍ choices of a fixed g-bit projection suffices. These counts show why a bounded menu and the known tail do not yield the unbounded sound ranks required of an actual verifier.

The projection does not supply a rank test without nondeterminism. An unknown span can encode even a single arbitrary acceptance question: make R propose one fixed nonzero projected row exactly when a nominated witness computation accepts. Rank at least one tests precisely that acceptance. This toy example gives no sound labels for J. The open step remains a construction that simultaneously certifies many independent true full rows within a useful prefix. Lean checks the sound lifting to aliased original names, transfer of XOR dependencies under a simultaneous tail realization, canonical-bit recovery given an exact basis, and soundness at the earliest rich prefix.
