# The cost of eliminating a growing number of native alternations

Let \(J\) be the square-time diagonal language on the logarithmic-word RAM. If \(J\) has a uniform alternating word-RAM algorithm running in \(O(t/\log^{1+\epsilon}t)\) time with \(o(\log\log t)\) quantifier blocks, for \(t=n^2\) and some \(\epsilon>0\), then deterministic and nondeterministic linear time differ on this RAM. The same conclusion follows from \(O(t/\log^\epsilon t)\) time if every choice in every block that passes control to the other player is binary. The missing premise is an alternating algorithm for \(J\) with these bounds.

The input length \(n\) counts bits. Words have width \(w(n)=12\lceil\log_2(n+2)\rceil\). The native problem \(U\) receives a program, a payload and a unary instruction clock. Its guest uses the width determined by its payload. The variable-program interpreter and the fixed-program reduction give \(U\in\mathrm{DTIME}[n]\) exactly when \(\mathrm{DTIME}[n]=\mathrm{NTIME}[n]\) on this instruction basis. The argument below uses a hypothetical deterministic linear-time decider \(A\) for \(U\). [Machine, encoding and completeness proof](native-unary-clock-band.md)

## How much of the path becomes a public input?

Fix an alternating program \(M\) on input \(x\). A block consists of consecutive choices by the same player, with deterministic steps allowed between them. Suppose all paths halt. Denote the maximum path length in instructions by \(s\), and the maximum number of blocks by \(k\). Let \(b\) be the maximum number of choice bits already consumed immediately before the first choice of a new block, over all changes of player on all paths. Set \(b=0\) if there are no changes. A word choice costs \(w(n)\) bits and a designated binary choice costs one bit. The latter instruction can be implemented by using only the low bit of a guessed word. Thus \(b\le s\,w(n)\), even when the locations of the changes depend on the guesses.

For \(s=O(n^2)\) and \(k=O(\log\log n)\), the hypothesis on \(A\) gives a deterministic simulation taking

\[
  O\!\left(C^{k+1}(n+|M|+s+b+1)\right).
\]

Here \(C>1\) depends on \(A\) and the fixed interpreter. It is independent of \(M\), \(k\), and the lengths of the individual blocks. For length-wise bounds take maxima over all inputs of length $n$. The bound holds for all sufficiently large \(n\) for each fixed \(M\). The simulator does not need algorithms for computing \(s,k,b\). In particular, even a full word choice at every step of the terminal block costs only instruction time when that path never changes player again.

## One fixed verifier

Give a trial two positive integer bounds \(P,j\), with \(P\ge n+|M|+1\). Truncate the game after \(P\) source instructions, before passing a prefix longer than \(P\) choice bits to the next block, or before entering a block beyond the depth budget \(j\). A terminal state reached within the caps keeps its verdict. Give every unresolved leaf the same bit \(d\). Setting \(d=0\) and \(d=1\) yields a lower and an upper bound on the original verdict, since OR and AND are monotone in all child values. [Lean proof of the two-default test and the refutation identity](../lean/AlternatingNativeCutoffs.lean)

Start with an existential block, allowing it to be empty when the first actual choice is universal. All paths fit within \(k+1\) such blocks.

A single nondeterministic verifier \(V\) takes \(M,x\), a packed prefix of actual choices, the bounds, and the current player \(q\). Its payload also contains the cutoff bit \(d\), the numerical clock parameters described below, and a literal program string \(v\). The driver sets \(v\) to the code of \(V\). A root or child query uses \(v\) both as the program field of the native instance and as data in its payload. Copying these two constant-size fields suffices at every depth.

The signed question for \(q=\exists\) asks whether the truncated subgame has value one. For \(q=\forall\) it asks whether the value is zero. In either case \(V\) seeks one sequence of the current player's choices. It replays \(M(x)\) from the start with the public prefix, then supplies each new choice of \(q\) nondeterministically. Replay recovers the original registers, memory and control from those bits. At a halt or cutoff, \(V\) accepts exactly if the resulting bit is the one sought. At an allowed change of player it constructs the child query with the extended prefix, the opposite player and one less unit of depth. It runs \(A\) on that query and accepts exactly if \(A\) returns zero. A child success would witness the opposite signed verdict. Induction on \(j\), starting with the final block, gives the stated meaning of every query.

Prefix lengths count only bits consumed, and the replayed instructions specify the width of the next choice. Every verifier payload contains the full original input, so a native guessed word can supply a source word by masking it to the original width. A branch buffers new choices in packed storage with \(O(1)\) word operations per source choice. If its prefix exceeds \(P\) bits it can cease recording, continue simulating, and assign \(d\) only if it reaches a switch or another cutoff. Thus even a long terminal block takes \(O(P)\) replay and guessing steps and sends no child operand. At an allowed switch, the full transferred payload, including \(x,M\), the prefix and a fixed number of binary metadata fields, has \(O(P)\) bits in the polynomial length range below.

## Clocks and machine widths

Use clocks \(H_j=K^jP\), where \(K=2^a\) is a fixed power of two. Supply \(H_j\) and \(a\) as data. \(V\) computes its child's clock by a shift. It can physically write the child program, payload and all \(H_{j-1}\) unary bits. If \(j=1\), no child operand is needed. The cost excluding a child call is \(O(P)\) for replay and prefix handling, plus \(O(P+H_{j-1})\) for operand construction when a call occurs. \(A\)'s deterministic run costs \(O(P+H_{j-1})\) as well. A single execution of \(V\) simulates the explicit program \(A\) on this one operand. Its correctness uses \(A\)'s decision about the shorter game, so the implementation needs no recursively expanded verifier or stack of nested interpreters.

For the width accounting, restrict trial budgets to \(D\le n^3\) as below. All payloads and native input lengths lie between \(n\) and \(O(n^3)\). A simulator uses digits of \(\max(1,\lfloor\log_2(n)/4\rfloor)\) bits. Each guest word then has a bounded number of digits. Fixed-limb arithmetic, normalized division, and a radix trie for sparse guest work addresses give constant overhead per instruction. A table of leading-bit positions for single digits costs \(O(1+n^{1/4})\) setup. Each new trie row gets a fresh number, and the row number followed by one digit fits in the host word for \(O(n^3)\) simulated steps. The driver can release a finished trial's storage using a list of touched cells at the same time cost. Packed operand reads span only constantly many storage words. This argument uses the band of lengths of the individual operands, so its constants apply at every depth. Decoding the supplied fixed-record program \(M\) once per replay costs \(O(|M|)\) with a uniform constant. [Sparse addresses and division in the native model](native-unary-clock-band.md)

Consequently the one-level time bounds have absolute coefficients once \(A\) and the interpreter are fixed. Choose \(K\) after these coefficients so \(H_1\) pays the base cost and \(H_j\) pays the replay, construction, and simulation at each later level. The verifier obtains \(a\) from the payload, so choosing \(K\) does not change its program. The binary metadata for an ordinary trial takes \(O(\log n)\) bits. On well-formed calls the unary clock never cuts off a required accepting branch, in either signed orientation.

## Finding sufficient bounds within the same time estimate

Starting from \(D\ge n+|M|+1\), double \(D\) after each unsuccessful round. In a round, try depths \(j=1,2,\ldots\) for which

\[
 P_j=\left\lfloor D/(2K)^j\right\rfloor\ge n+|M|+1 .
\]

Test both defaults at each such depth. Their agreement determines the true verdict even if the cutoffs removed some paths. Each root clock \(K^jP_j\le D/2^j\), so the entire round takes \(O(D)\), including the construction of each actual operand and the run of \(A\). The powers used in this loop are obtained by shifts. Test the bound before each multiplication that could exceed the budget.

At \(j=k+1\) both answers agree once \(P_j\ge n+|M|+s+b+1\), since no actual path is truncated. The first sufficient \(D\) is at most \(2(2K)^{k+1}(n+|M|+s+b+1)\). The total over earlier rounds is geometric. For every fixed \(M\) in the stated range this bound is \(n^{2+o(1)}\) or smaller, hence below \(n^3\) eventually. A driver that stops at the polynomial ceiling can hardwire the finitely many exceptional input lengths' answers for that fixed language. This proves the simulation with \(C=2K\).

## The diagonal and the leading constant in the alternation bound

On a padded input containing an opponent program, \(J\) simulates that program on the whole input for \(n^2\) opponent steps and accepts on observed rejection. The same-width bounded interpreter takes \(O(n^2)\) time. A deterministic \(o(n^2)\)-time decider for \(J\) would finish on all sufficiently long inputs containing its own program, giving the opposite verdict to \(J\) there. Thus this specific language suffices for the separation. [Native diagonal construction](native-unary-clock-band.md)

If \(k=o(\log\log t)\), then \(C^{k+1}=(\log t)^{o(1)}\). With \(s=O(t/\log^{1+\epsilon}t)\) and \(b\le s\,w(n)\), the simulation would decide \(J\) in \(o(t)\) deterministic time. More generally \(s+b=O(t/\log^\epsilon t)\) suffices. This gives the binary-choice conclusion even when the final block makes full word choices. The contradiction excludes a linear decider for the native complete language. An exclusion for explicitly encoded SAT requires a reduction preserving the desired bit-length and time bounds.

Uniformity in \(M\) also permits a family of speedups. It suffices that for some common \(\epsilon>0\) and **each** \(\delta>0\) a fixed program \(M_\delta\) decides \(J\) with \(s+b=O_\delta(t/\log^\epsilon t)\) and at most \(\delta\log_2\log_2 t+O_\delta(1)\) blocks. After \(A\) fixes \(C\), choose \(\delta\log_2 C<\epsilon\). That one program contradicts the diagonal. The argument uses no effective procedure for producing \(M_\delta\).

## Accuracy needed on padded programs

Use the encoding of $J$ in which a self-delimiting program prefix $p$ leaves the entire suffix free, and the opponent receives the entire string. If a deterministic tester $D$ finishes in fewer than $n^2$ steps everywhere at large lengths, then on **every** extension of $p_D$, its own program prefix, $J$ has value $1-D(x)$. This is a fraction exactly $2^{-|p_D|}$ of all inputs at each such length.

Consequently the native criterion only requires a fixed alternating procedure to be correct and fast on arbitrarily long extensions of **each** valid program prefix. For example, let $t=n^2$ and suppose each prefix has arbitrarily long extensions where all branches halt, the game gives $J(x)$, $s+b=O(t/\log^\epsilon t)$, and $k=o(\log\log t)$. The asymptotics may be taken along the chosen extensions of that prefix. Cap the two-default search at a constructible budget of order $t/\log^\eta t$ for rational $0<\eta<\epsilon$, returning zero on exhaustion. This deterministic tester finishes in $o(t)$ on every input. On sufficiently large good extensions it has enough budget to settle the full game. Apply that statement at its own prefix. Nothing is required of the alternating procedure on the other inputs. As a special case, joint correctness and these resource bounds on a $1-o(1)$ fraction of uniform inputs along an infinite sequence of lengths suffice.

Li and Tell's Theorem 1.3 gives an average-case alternating simulation for every polynomial-time language under their low-space range-avoidance and circuit-hardness hypotheses. It gives constant block count and linear time, and their simulations can be implemented on multitape machines. In particular their conditional conclusion supplies the good-input premise for $J$ on our RAM by simulating its fixed number of tape heads directly. In the October version the hard family was fixed before the algorithm. Under $P=NP$, a polynomial-time bit evaluator for that fixed family makes the question of an omitted completion of a prefix decidable in $P$ by a $\Sigma_2^P$ test. On 26 November the authors revised the premise to allow the choice of family after the avoider. To handle that ordering under an arbitrarily near-linear SAT hypothesis, accelerate all simultaneous low-space evaluators to a common polynomial clock and use one census. Its hardness hypothesis is open. ## A sufficient speedup for ordinary linear-time SAT exclusion

Fix $k\ge1$ and $\epsilon>0$. It suffices to construct one alternating procedure $M$ such that each valid opponent-program prefix has arbitrarily long extensions $x$ where all branches halt, the verdict is $J(x)$, there are at most $k$ actual blocks, and
$$
 s(x)+b(x)=O\!\left(n^2/(\log n)^{3k+\epsilon}\right).
$$
The bound may have a different constant on each fixed prefix. This criterion concerns the fixed-width binary literal encoding and RAM instruction basis of the packed reduction. For $k=1$ the pre-switch bit cost is zero. The procedure may fail elsewhere.

To prove the implication, assume a linear-time solver for ordinary explicit SAT. Compile the fixed nondeterministic interpreter for $U$ with its $O(N)$ clock on any $N$-bit input into a virtual explicit 3-CNF. There are $O(N\log^3 N)$ encoded bits with constant-time packed reads after polylogarithmic setup. Running the hypothesized SAT solver gives a deterministic native solver $A$ for $U$ taking $O(N\log^3 N)$ steps. Its slightly wider words and sparse addresses are handled as above. [Packed reduction, including the literal-index cost](packed-band-transfer.md)

Put $L=\lceil\log_2(n+2)\rceil$. Fix rational $0<\eta<\epsilon$ and take $P$ within a fixed factor of $n^2/L^{3k+\eta}$, rounded down to an integer. For example, use a shift by $\lfloor(3k+\eta)\lfloor\log_2 L\rfloor\rfloor$ in the denominator. The driver first runs $M$ through its deterministic prefix for at most $P$ steps. It handles an early halt or cutoff directly and otherwise begins with the owner of the first choice, inverting the signed root answer for a universal first block. This avoids charging an empty initial block. The verifier still replays from the original input with the same source-step cap. Test both defaults at depth $k$, returning zero if they differ.

Use native verifier clocks $H_1=KP$ and $H_j=K L^3 H_{j-1}$ for $2\le j\le k$, giving $K,L$ to the verifier as data. Every well-formed child input has $O(P+H_{j-1})$ bits and word width $O(L)$, so one child call and its construction take $O(L^3 H_{j-1})$ steps. Choose $K$ large enough for these uniform constants. The root call costs $O(L^3 H_k)=O_k(P L^{3k})=o(n^2)$, including the two tests and the deterministic prefix. Every sufficiently large good extension satisfies the step and transferred-bit bounds within $P$, so the driver gives the correct verdict there. The cylinder of the driver's own code contradicts this conclusion. The logarithmic loss here is a sufficient charge per call for this compiler. An unconditional linear-time SAT exclusion still requires a procedure meeting the premise, or another argument.

For fixed $k$, one can even assume only $(n+s+b)L^{3k}/n^2\to0$ along the good extensions of each prefix. Set $P=\lfloor\gamma n^2/L^{3k}\rfloor$ for a small fixed rational $\gamma>0$. All well-formed trials finish in at most $C_k P L^{3k}+o(n^2)$ actual instructions, for a fixed upper coefficient. Implement the chooser with a numeric dyadic factor and a fixed driver, or pass the factor to a fixed native interpreter, so choosing it introduces no new coefficient in the repeated simulation. Choose $\gamma$ below the reciprocal of twice that coefficient. The driver then finishes inside $J$'s exact $n^2$ clock on every sufficiently large input. The little-$o$ condition ensures that $P$ eventually covers the whole game at good extensions of its prefix, giving the same contradiction.

A simple padding heuristic illustrates the force of the quantifier. Reading the last padding bit and returning it costs constant time. A valid opponent can return that very bit on every extension of its code. On that entire cylinder $J$ returns its complement, so even this sparse success requirement defeats the heuristic.

## Comparison with published speedups

Dymond and Tompa prove a deterministic multitape Turing machine speedup to alternating time \(O(t/\log t)\). Their construction with \(r\) time blocks has time \(O(r\log t+t/\log r)\) and \(O(r/\log r)\) alternations. Taking a polynomial number of blocks gives the full logarithmic saving. With a slowly growing \(r\), the displayed saving is only of order \(\log r\), while the alternation-elimination bound here is exponential in the number of quantified blocks. Those estimates do not supply the missing alternating algorithm for the word-RAM diagonal. [Dymond and Tompa, Theorem 2 and its analysis](https://cs.uwaterloo.ca/research/tr/1983/CS-83-08.pdf)

The Cook–Mertz tree-evaluation algorithm gives Williams's deterministic multitape simulation in space $O(\sqrt{t\log t})$. Standard alternating reachability for configurations using $S$ bits takes $O(S^2)$ bit time by guessing a midpoint and checking one half at each of $O(S)$ levels. Substituting this space bound only yields $O(t\log t)$ in that argument. The alternating-time question is listed separately in Williams's paper. Williams's earlier random-access version of the Dymond–Tompa speedup also distinguishes random-access Turing machines and RAMs with logarithmic operation cost. [Williams, §5](https://people.csail.mit.edu/rrw/time-vs-space.pdf) · [Williams, Corollary 4.2](https://people.csail.mit.edu/rrw/qbf-lower-bd.pdf)
