# Printing a shallow circuit's truth table in packed output time

Let a Boolean circuit have \(\ell\) input bits, fixed depth \(d\) and at most \(\ell^A\) wires for a fixed \(A\). There are polynomially many gate records, with a supplied output identifier and indexed lists of incident wires. Gates are unbounded-fan-in AND and OR, and unary NOT. A deterministic word RAM, given the circuit explicitly, can print its entire truth table in binary index order in
\[
 O_{A,d}(1+2^\ell/\ell)
\]
instructions. Host words have \(W=\Theta(\ell)\) bits and enough address bits for the output and scratch arrays, e.g. \(W=12\ell+O(1)\). The same bound holds for one output gate testing the sum of polynomially many such circuit outputs modulo any **fixed** integer \(q\ge2\). Outputting the \(2^\ell\) bits already costs this many packed writes.

Applied to the fixed unary nondeterministic source \(H(1^n)\) of time \(t=Cn^2\), this gives a worst-case lower bound of \(\Omega(n^2\log n)\) **file bits** for uniformly supplied shallow bit-index circuits describing an equivalent ordinary proper DIMACS file. Both verdicts have arbitrarily large examples, simultaneous for every producer in any fixed finite roster. The time for deciding an already printed SAT file remains open. [Native unary source and interval proof](a-fixed-unary-ram-source-for-physical-sat-compilers.md)

## Keep the physical low bits together

Take \(s=\lfloor\log_2 W\rfloor\), \(L=2^s\) and \(m=\ell-s\). A logical word contains the \(L\) answers at consecutive settings of the low \(s\) bits. The other \(m\) bits address logical words. All estimates below are asymptotic in \(\ell\); finitely many small cases use direct evaluation. Normalize the circuit to alternate gate polarities by level. Paired gates push negations to literals, and gate copies and unary identity gates embed irregular levels in a fixed alternating schedule. For instance, each original depth can use an AND level followed by an OR level, propagating intermediate signals by unary gates. This changes wire size polynomially and depth by a constant factor. Denote the normalized depth by \(D\), counting from the literal inputs.

Fix a large constant \(c\), chosen below. Put \(k=\lceil c\log_2 \ell\rceil\) and
\[
 h_i=\left\lceil m^{1-i/D} k^{i/D}\right\rceil,
 \qquad 0\le i\le D .
\]
These integers are computable by comparisons of fixed integer powers, with the endpoints set to \(m,k\). Choose nested subsets \(H_0\supset H_1\supset\cdots\supset H_D\) of the high positions, \(|H_i|=h_i\), each uniformly among the subsets of its predecessor with the given size. Choose an independent random assignment of all high bits. At stage \(i\), release their assigned values on \(H_{i-1}\setminus H_i\). Values on \(H_D\) are never revealed.

For a fixed low lane, the bottom gate's target (one for OR, zero for AND) is a width-one DNF. At stage \(i\), build the canonical decision tree of each gate's current target DNF under the newly released assignment, stopping if its height exceeds a fixed integer \(b\). Remove falsified terms, return one when a term is satisfied and zero when all terms are falsified. Otherwise query every remaining literal variable of the first surviving term in a fixed order, then repeat. When a gate succeeds, its zero-leaf path descriptions give an ordered DNF of width \(b\) with at most \(2^b\) terms for the opposite target. That target is exactly the one needed at the next level. Concatenate the child path lists for each next gate, respecting the given wire order. Each gate has only polynomially many intermediate terms. Stop and mark the cofactor bad if any tested tree exceeds the cutoff, at any level or lane.

At every stage, conditional on the entire previous restriction, the next set and the newly assigned values have the fixed-size random-restriction distribution. For a single width-\(b\) DNF, the canonical switching bound gives failure probability at most \((13b h_i/h_{i-1})^b\) once the ratio is sufficiently small. Each ratio is \(O((k/m)^{1/D})\). There are polynomially many gates and \(L=O(\ell)\) lanes. For any desired fixed \(K\), choose \(b\) so that the overall probability of a bad cofactor is at most \(\ell^{-K}\). The argument uses a union bound and allows the lanes to have exactly the same tower and high bits. In particular, some single tower has at most this fraction of bad assignments on \(H_0\setminus H_D\). The constants in the exponent required for \(b\) are independent of the fixed value ultimately chosen for \(c\). [Impagliazzo, Matthews and Paturi, Lemma 1.4 and canonical tree definition](https://arxiv.org/pdf/1107.3127) · [Håstad, switching lemma](https://doi.org/10.1145/12130.12132)

## Finding a tower deterministically

Every \(H_1\) has \(O(m^{1-1/D}k^{1/D}+1)\) elements. Enumerate all choices and their nested continuations. The number is at most \(2^{O_D((h_1+1)\log \ell)}=2^{o(\ell)}\); fixed-size subsets admit elementary polynomial-delay enumeration, including the case \(D=1\).

For any fixed tower, badness is an \(AC^0\) predicate of the released bits with depth bounded in terms of \(D,b\) and polynomial size in \(\ell\). To see this directly, represent a query variable by one-hot flags for its \(\ell\) possibilities. The truth, falsity and surviving-variable flags for a width-\(b\) term are ANDs/ORs of selected assignment bits and their complements. Prior branch replies and at most \(b\) previous query names can be included in these tests. The first surviving term is selected by its flag and the negation of the OR of all earlier flags. Within it the fixed order selects a list of at most \(b\) live variables; their order can be selected by enumerating the constantly many subsets of term positions. Unroll the query bundle and recursive calls through at most \(b+1\) individual queries on a path. The resulting constant number of branch addresses record their names, answers and terminal labels. They explicitly specify the next gate's child path list, using flags for absent paths. A dummy inactive representation can be used after failure. Iterate through the fixed number of circuit layers and OR all failure flags over gates and low lanes. Dynamic selection of an assignment bit is an OR of its matching position flags and bits. The finite sequential depth of this construction is independent of \(\ell\).

By Braverman's bounded-independence theorem, some \(r=(\log \ell)^{O_{A,D,b,K}(1)}\) suffices to estimate every such predicate's mean to error \(\ell^{-K}\). To score a tower enumerate the whole seed space of an \(r\)-wise independent distribution: take a random polynomial of degree below \(r\) over a binary field of order between \(\ell+1\) and \(2(\ell+1)\), evaluate at distinct positions and take a fixed nonzero binary linear coordinate. Any \(r\) evaluations are independent and uniform by interpolation. A suitable irreducible polynomial can be found by exhaustive divisibility tests in polynomial time in \(\ell\). The seed length is \(O(r\log \ell)=o(\ell)\); a native RAM computes each seed's badness by the preceding polynomial-time bounded recursive test. For example an integer \(r=2^{\lceil\log_2\log_2(\ell+4)\rceil^2}\) eventually dominates every required fixed polylogarithm while its seed is still \(o(\ell)\), and one may use full independence for smaller sizes where \(r>\ell\). Choose a tower minimizing the observed fraction. Its true bad fraction is at most \(3\ell^{-K}\). All tower and seed searches together take \(2^{o(\ell)}\) time. [Braverman, *Poly-logarithmic independence fools AC⁰ circuits*, Corollary 2](https://www.cs.toronto.edu/~mbraverm/Papers/FoolAC0v7.pdf)

## Printing good and bad cofactors

Run the bounded recursive simplifier for every setting of the \(m-k\) released positions and all low lanes. Per cofactor this and the coefficient setup below take at most \(\ell^J\) steps for a constant \(J=J(A,D,b,q)\). Pick \(c>J+2\), so all such setup work fits within \(O(2^m)\). For a bad cofactor evaluate the original circuit once per remaining assignment, bit-sliced over the \(L\) lanes. A high input is a full zero or one mask, and the periodic low-input masks are prepared once. A fixed-modulus top gate may accumulate one-hot residue masks with a constant number of Boolean word operations per child. Including setup for high addresses, direct evaluation takes a fixed polynomial in \(\ell\) per word with exponent depending only on the original circuit size. Choose \(K\) above that exponent *before* choosing \(b,J,c\). The total fallback time is \(O(2^m)\).

On a good cofactor each output, in each lane, is a tree of height at most \(b\). Use polynomials over \(\mathbb Z/q\mathbb Z\), taking \(q=2\) for the single Boolean output. A decision tree node on \(X_v\) with child functions \(P_0,P_1\) becomes
\[
 P_0+X_v(P_1-P_0).
\]
It has degree at most the tree height. Work with square-free monomials on Boolean assignments. Sum all desired child outputs before applying the residue test. Combining all \(L\) lanes puts each coefficient in a fixed number of words, for instance one word for each possible residue. Addition and subtraction of packed coefficients cost \(O_q(1)\); residue \(a\) of a sum has mask \(\bigvee_i (U_i\land V_{a-i})\). No invertibility of nonzero residues is used.

Store the coefficients by degree and within each degree in colexicographic order (sorted by largest differing position). For a node with \(r\) high variables still free, fix the largest to zero or one. The first \(\binom{r-1}{j}\) positions of the degree-\(j\) array omit that variable, followed by the terms containing it, in the order of their remaining indices. The zero child keeps the lower segments; the one child adds into each degree-\(j\) segment the upper segment at degree \(j+1\). All offsets are precomputed binomial coefficients of polynomial magnitude. This costs \(O_q(\sum_{j=0}^b\binom rj)\) per node with constants depending on \(b\). The total per cofactor is \(O_{b,q}(2^k)\), since
\[
 \sum_{r=0}^k 2^{k-r}\sum_{j=0}^b\binom rj
 \le 2^k\sum_{j=0}^b\sum_{r=j}^\infty 2^{-r}\binom rj
 = 2^{k+1}(b+1).
\]
At the leaf the mask of the desired residue is the entire logical word. The recursion carries the integer physical address, setting the original bit position each time the one child is taken. Thus every write lands at the correct logical word, regardless of how scattered the high survivor positions are. Make one final increasing-address pass, concatenating \(L\)-bit logical words into \(W\)-bit output words using shifts, masks and a partial-word buffer. Each append crosses at most one physical word boundary. The sum of preprocessing, good and bad work, and physical copying is \(O(2^m)=O(2^\ell/\ell)\). Fast exhaustive evaluation of bounded-degree Boolean polynomials is already established; the physical low-lane convention permits its use in this ordering. [Bouillaguet, *Evaluating a Boolean Polynomial on All Possible Inputs*](https://doi.org/10.1145/3699957)

## What an equivalent SAT file must cost

Let a fixed deterministic producer with ordinary uniform code, in \(o(n^2)\) native work on every length, emit a length \(M\) and an explicit index circuit of fixed depth and \((\log(2+n))^A\) wire size, of the gate types above. Its bit at \(i<M\) is the raw file bit of an ordinary proper DIMACS file having verdict \(H(1^n)\); there is no accepting-path promise. Use \(\ell=\lceil\log_2(2+M)\rceil\) index positions, or fix any redundant high address bits to zero. On \(M<n\) direct evaluation of the first \(M\) bits takes \(O(n\operatorname{polylog}n)=o(n^2)\). For \(n\le M\le n^2\log n\), \(\ell=\Theta(\log n)\) and the circuit meets the polynomial size hypothesis in \(\ell\). The source host has enough address bits for the table and scratch, since its width is at least twelve times the rounded binary logarithm of the unary input length. On that host materializing the first \(M\) bits takes \(O(M/\log n)\) steps. The last partially used word is masked as necessary. In either range, after production the standard packed nondeterministic SAT verifier fits the same total time. [Packed verification of proper DIMACS](packed-verification-of-locally-indexed-unique-sat.md)

For a finite list and specified fallback \(d\), use the unary source's interval opponent. It generates each candidate's length and circuit and consumes the first with \(M\le n^2\log n/p\), returning \(d\) if none qualify. The bound on *every path* is \(o(n^2)+O(n^2/p)\), with constants uniform in the public interval quota \(p\). Select a sufficiently large fixed \(p\) after fixing the opponent code. Every sufficiently late interval assigned to the resulting pair contains a length at which the opponent disagrees, forcing \(H(1^n)=1-d\) and all file lengths above the cutoff. Applying both fallbacks gives the stated lower bound for the two verdicts. A nonuniform sequence of supplied per-length indexers could simply hardcode the correct verdict in a constant file. The uniform producer assumption carries the diagonal argument.

Lean checks exact tree conversion and its degree bound in characteristic two, and checks that coefficient descent agrees with evaluation in each lane.
