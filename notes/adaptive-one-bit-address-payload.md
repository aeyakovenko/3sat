# Changing one address bit permits arbitrary bit writes

Take a deterministic word RAM whose controller may choose each read address adaptively. At address $p$ it observes $x=M[p]$. It may skip the write, write $M[x]\gets p$, or write $M[x]\gets p\mathbin{\mathrm{XOR}}1$. These are its only memory operations. The controller pays for register arithmetic, branches and probes. A fixed guest RAM with $w$-bit words and time $T(N)$ on an $N$-bit input has a simulator on this machine using $2w$-bit words and time $O_P(N+wT(N))$. Both machines start with the same packed input and zero workspace. The only width change is the fixed factor two in a family closed under doubling. ## Two probes to assign a bit

Use the physical words at addresses $0$ and $1$ as temporary storage. Suppose $p\ge2$ holds an old bit $c\in\{0,1\}$. To assign a desired bit $t$, read $p$ and write the unmodified address $p$ to $M[c]$. Next read $c$. It now contains $p$, so the second probe writes to $M[p]$. Choose its payload as $c$ if $c=t$ and as $c\mathbin{\mathrm{XOR}}1$ otherwise. The new value at $p$ is $t$. The only other possible change is to the temporary word at $c$. A probe that skips its write reads the bit in one step. [Lean verification of the exact two updates](../lean/AdaptiveOneBitPayload.lean)

## Simulating ordinary input and workspace

Assume $w=\Theta(\log(N+2))$ with $2^w\ge N$. Set $W=2w$ and $B=2^{W-1}$. Represent bit $j$ of guest address $a$ at host address $B+aw+j$, for $0\le j<w$ and $0\le a<2^w$. This entire bank fits because $w2^w\le 2^{2w-1}$. It starts above both temporary words and the original input at all sufficiently large lengths. Physical input words use little-endian bit order and the last one is zero-padded.

Before any writes, read host words $0$ and $1$ into two registers, skipping the write both times. Scan the original $N$ bits in order. For either saved address, use its register copy. At all other addresses use a read that skips its write. For each input bit equal to one at offset $i$, assign one to bank address $B+i$ with the two probes above. The bank was zero initially, so all remaining original guest bits, including the unused high bits in its final word and all guest scratch cells, are already correct. No write in this loop touches a later raw input word except for the two addresses whose contents were saved. The scan costs $O(N+w)$ including width setup. It works for arbitrary input bit strings and hence for ordinary ASCII DIMACS.

Keep the fixed guest registers in host registers, implement numerical operations with the guest-width mask, and use the guest length and width as its metadata. For each guest LOAD, read its $w$ bank bits without writing and assemble the word by shifts and Boolean operations. For each guest STORE, assign all $w$ bank bits by the two-probe rule. Address arithmetic costs constant time per bit. By induction the bank always represents exact guest memory, including overwrites of the guest input. The short initial lengths can be handled by fixed finite control. This proves the claimed simulation. For every fixed $a\ge1$, a lower bound excluding $O(N^a\log N)$ for all such adaptive controllers would exclude $O(N^a)$ on the ordinary RAM. The simulation leaves a logarithmic factor between these clocks.

## Four possible values per cell outside the initial image pairs

Let $H$ be the image of initial memory, and let $[p]=\{p,p\mathbin{\mathrm{XOR}}1\}$. Draw the initial undirected edges $[p]$ to $[M_0[p]]$. Throughout any execution every current edge $[p]$ to $[M[p]]$ belongs to this initial graph. Indeed, on a write with $x=M[p]$ the new edge out of $[x]$ ends at $[p]$, giving the same undirected edge just observed. Skipping a write preserves the graph condition as well.

If $[p]\cap H=\varnothing$, no initial pointer points to either member of $[p]$. Every initial neighbor of $[p]$ therefore comes from the original outgoing edge of one of its two members. Hence $M[p]$ always lies in the union of $[M_0[p]]$ and $[M_0[p\mathbin{\mathrm{XOR}}1]]$, at most four possible words. The exceptional pairs together contain at most $2|H|$ addresses. On the initially zero scratch bank these two neighbor pairs coincide with $\{0,1\}$ whenever both cells start zero and the pair misses $H$. A constant number of possible values per cell still accommodates one independent bit in each of arbitrarily many cells. [Lean proof of the quotient graph invariant for all finite runs](../lean/AdaptiveOneBitPayload.lean)

When the payload is always the current address $p$, the same undirected-edge argument applies on the original address space because each write reverses the edge $p$ to $M[p]$. Every address outside $H$ has a single original neighbor, hence retains its original value forever. This exact reversal invariant already occurs in the five-instruction case analysis. For a payload equal to an unrestricted next address, a different simulation achieves constant overhead per guest access.
