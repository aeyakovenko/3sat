# An unconditional tape and auxiliary-memory bound for proper 2-CNF

Let a machine have a two-way, read-only input tape, one unrestricted writable work tape, and an auxiliary store with at most $2^{p(n)}$ possible states. Each tape has one nearest-neighbor head and a fixed finite alphabet. The auxiliary state can be accessed and transformed arbitrarily in each step. It includes all extra registers, addresses, and mutable storage outside the tapes and finite control. The input is ordinary ASCII. All logarithms below have base two.

For definiteness, put $G=\min\{\sqrt n,n/(p(n)+\lceil\log(n+2)\rceil)\}$ and suppose $G\to\infty$. At every sufficiently large byte length, a deterministic SAT decider requires time $\Omega(n\log G)$ on each of the two answers, on proper 2-CNF files. The bound on the unsatisfiable files holds even for the shortest accepting path of a sound and complete nondeterministic **UNSAT** recognizer. When $p\le n^{1-\delta}$ for fixed $\delta>0$, the time bound is $\Omega_\delta(n\log n)$. With $p=n/(\log n)^a$ for fixed $a>0$, it is $\Omega_a(n\log\log n)$. There is no restriction on the ordinary work tape. Independent random input access or a second unrestricted work tape changes the model.

This is an adaptation of the decision lower bound of Wolfgang Maass, Georg Schnitger, Endre Szemerédi and György Turán (MSST). Their original theorem concerns equality testing for sparse transposes and already covers nondeterministic machines with the two tape heads and no auxiliary store. Their graph, separator lemma and cut-and-paste argument are the lower-bound ingredients here. The changes are the actual DIMACS layout, the larger blocks carrying many complete rows, the auxiliary-state accounting, and the count of satisfiable partners. Priority of these particular extensions has not been established. [MSST, *Two tapes versus one for off-line Turing machines* (1993), Theorem 1.1 and §3](https://igi-web.tugraz.at/PDF/61.pdf#page=3)

## Why these files decide transpose equality

Let $t$ be dyadic, $w=\log t$, and let $A,B$ each consist of $t^2$ independent $w$-bit words in row order. Number a cell $(i,k)$ by $j=it+k$. Use pins $p_0=1,p_{t^2}=0$, then put one clause $\neg p_j\vee x_{j,A_{ik}}$ in the first array, in $(i,k)$ order, and one $\neg x_{j,B_{ki}}\vee p_{j+1}$ in the second, in $(k,i)$ order. Equality $B=A^{\mathsf T}$ closes the implication path and makes the file UNSAT. At any mismatch $j_*$, make exactly the $p_j$ for $j\le j_*$ true, and make $x_{j,z}$ true precisely when $j\le j_*$ and $z=A_{ik}$. This satisfies the file. Express each pin with two distinct-variable binary clauses using a fresh variable. All clauses now have two distinct variables.

Use fixed-width decimal names with one digit 1 or 2 for each data bit and fixed-width tags for coordinates. This gives an actual constant slot length on each side, $V=t^2w$ independent diagonal bits, and a file length $n_t=\Theta(V)$. Each of the $t$ rows occupies $\Theta(tw)$ consecutive bytes in its section. The hard input to the machine is the formula itself. For an arbitrary large $n$, choose the largest dyadic $t$ fitting $n_t\le n$ and insert the extra spaces before a fixed clause terminator outside both sections. The successive $n_t$ have bounded ratio, so $V=\Theta(n)$ and each of the two data sections still occupies $\Theta(n)$ bytes. ## Recording the two heads and the auxiliary store

Fix a machine and a deadline $T=\lfloor cn\rfloor$ with $c=\varepsilon\log G$. Round the physical block size $b=n/G^{2/3}$ up to an integer. Then $b\ge n^{2/3}$, $b=o(n)$, and $b/(tw)\to\infty$. Given a path of length $T$, adjust a common offset for the length-$b$ partitions of both tapes. Summing the number of crossings over the $b$ offsets charges at most two per step. Some offset therefore divides the computation into $r=O(1+T/b)=O(cG^{2/3})$ segments. In a segment all the reads on each tape use one block. Read and write before moving the heads, so a crossing step finishes its old segment. Freeze a halted path in place through the deadline, preserving its verdict.

A common record fixes the offset, crossing times, locations of both heads, finite states, and the full auxiliary configuration at each boundary, including both ends. On these deadlines head positions and times use $O(\log n)$ bits. The number of possible records is at most $2^{L_1}$, where

$$
 L_1=O\bigl(\log n+r(p+\log n)\bigr)
      =O(nc/G^{1/3}).
$$

A store with a bounded number of *occupied* random-address words fits this definition when the stored addresses as well as their contents are charged. The proof permits nondeterministic state transitions. Fixing the full auxiliary boundary state allows segments from two paths to be joined regardless of the accesses inside them.

For an auxiliary RAM with ordinary addressed reads and writes, the record can be smaller on the **actual length-$T$ paths**. At a boundary call a side-memory address live if its current value will be read before the next write to that address and before the deadline. Record the current registers and an injectively encoded, address-labelled map of the live values. The final control retains the verdict. Suppose a segment from either source path is replayed with its registers and entry-live map correct. Each read uses its proper value, since the cell was either live at entry or last written during this segment. The same instructions, addresses, and nondeterministic choices therefore replay. Each exit-live address written in the segment has the proper new value. Every other exit-live address was also live at entry on that source path, so its value remains correct. The common exit signature then supplies the induction hypothesis even when the next segment comes from the other path. Arbitrary garbage at other addresses is harmless. This claim uses the addressed-memory semantics in which a single-cell read or write and explicitly recorded registers account for every dependence on the side store.

Consequently the same counting proof holds when $p$ bounds the bit length of these signatures at the selected boundaries, instead of the size of the whole auxiliary RAM. Include the domain of each partial map, its values, registers and any persistent controller in the length. A varying length at most $p$ costs at most $p+1$ bits in the logarithm of the number of possibilities. It suffices that each path used in the counting has at least one offset with both the stated crossing bound and these small signatures. For the nondeterministic lower bound, apply this to the timely accepting paths having that property. For the deterministic partner count, the argument below uses the diagonal prefixes through the deadline, whether halted or still running. The live bound on those prefixes is an extra hypothesis and places no restriction on garbage accumulated, or on off-diagonal executions.

A per-step average suffices as well. For a fixed actual path define $e_u$ as the length of the encoded live map and register state **after** step $u$, for $1\le u<T$. Put $e_u=0$ when neither head moves. Suppose $\sum_{u<T}e_u\le Tp$. Over all $b$ offsets, a moving step contributes at most twice to the number of crossings and at most $2e_u$ to the total crossing payload. For a uniform offset the respective expectations are at most $2T/b$ and $2Tp/b$. Markov's inequality and a union bound give one offset with both costs at most three times those bounds. If a mean is zero its cost is always zero. The initial side state is fixed by the machine, and the final boundary needs only the verdict and finite control. Registers used during the last segment are reproduced from its entry. Self-delimit each interior signature, for example by writing each payload bit as 00 or 01 and appending 1. All the payloads together then cost $O((T/b)(p+1))$ bits, which fits $L_1$. Thus in the addressed model the theorem also applies with an upper bound $p$ on the average of these encoded live-state costs on the relevant diagonal paths.

For one common record, make a vertex for each segment and join successive visits to the same writable tape block. This is the planar block computation graph in MSST §3. Concretely there is one chain for each physical block visited, and these chains alone already form a planar graph. Chronological finite-control, position, and auxiliary messages have all been fixed in the record, so only successive-work-block edges are needed. Label the vertices by the read-only input block used in the corresponding segment.

There are $\Theta(n/b)$ physical blocks wholly inside each of the two data sections. Since the total number of labels counted with multiplicity is $r$, select $s=\Theta(n/b)$ blocks on each side whose multiplicities are all at most $k=O(c)$. For any unvisited chosen block add an isolated dummy vertex with its label. This adds $O(n/b)=O(r_0)$ vertices with $r_0=1+T/b$, leaving the same asymptotic separator estimate (use $r_0$ in place of $r$ if necessary). Dummy vertices carry no tape contents. Apply MSST Lemma 3.1. It gives $z\ge s/9^k$ labels on each side, and a vertex set $S$ of size $O(k\sqrt r)$ such that no remaining component uses selected labels from both sides. The entering and leaving contents of the active writable block at every vertex of $S$ cost in total

$$
 L_2=O(bk\sqrt r)=O(nc^{3/2}/G^{1/3})
$$

bits. The selection and the separator can be chosen deterministically from the common record, without new bits. Each separator vertex can be replayed using the path belonging to its own input label, since both its incoming and its outgoing block contents are fixed. [MSST, Lemma 3.1, p. 397](https://igi-web.tugraz.at/PDF/61.pdf#page=6)

Each selected block contains $\Omega(b/(tw))$ whole rows of the physical array it meets. These rows are disjoint between blocks of the same side. Select their intersection in matrix coordinates, using the rows from the first array and columns from the second. All $w$ bits in each such cell occur only in the selected blocks on their respective sides. The number of independent diagonal bits thus selected is at least

$$
 \Omega\!\left(w\left[\frac{zb}{tw}\right]^2\right)
 =\Omega\!\left(n\,9^{-2k}\right).
$$

Choose the positive constant $\varepsilon$ sufficiently small that $9^{2k}=O(G^{1/6})$. Fix a sufficiently small constant $a>0$. For every record, retain exactly $D=\lfloor a n/G^{1/6}\rfloor$ of the selected bits by a fixed ordering. The total loss $L=L_1+L_2=o(D)$ as $G\to\infty$. This is where the choice of block size accommodates the extra store.

### A sharper separator charge after the chronological state is fixed

The same number $z\ge s/9^k$ of labels on each side can be separated here by at most $2k-1$ real work-block vertices. To see this, concatenate the disjoint work-block chains, including isolated dummy vertices, into one line. All original work-block edges are edges of this line. Make it the spine of a rooted binary tree by adding unlabelled leaves so that every interior spine vertex has two children. Retain the input-block labels on the spine itself. MSST Fact 4.2 gives the two sets of labels and at most $2k-1$ tree edges whose removal separates them. Discard cuts on dummy leaves, which have no labels. For each cut spine edge delete its earlier endpoint from the line, counting only real vertices for the payload. Distinct nondeleted vertices connected by an original work-block path remain in the same uncut component of the tree. The isolated labelled dummies have no actual computation to replay. The same cut-vertex splice now charges at most $O(bk)$ bits. This argument uses the fact that all chronological messages between adjacent time segments have been recorded. [MSST, Fact 4.2, p. 399, quoting Babai, Pudlák, Rödl and Szemerédi](https://igi-web.tugraz.at/PDF/61.pdf#page=8)

In particular, one can use $b=\lceil K\sqrt{n(p+\log(n+2))}\rceil$ for a sufficiently large file-layout constant $K$. This is at least four times the maximum physical row length, and it is $o(n)$ for $p=o(n)$. For $1\le c=O(\log n)$ the combined record and separator expense is $O(c\sqrt{n(p+\log(n+2))})$. The crossing submatrix still supplies $\Omega(n 9^{-2k})$ independent bits for $k=O(c)$. These estimates give a second derivation of the stated time order and a smaller explicit record cost.

## Splicing, both answers, and the count of slow inputs

Group diagonal paths first by record and separator contents and then by the values of the $V-D$ remaining diagonal bits. There are at most $2^{V-D+L}$ buckets. The selected $D$ coordinates may change from one record to the next, which does not affect this count.

Given two paths in a common bucket, with diagonal matrices $A,A'$, build a path on the file with first array $A$ and second array $(A')^{\mathsf T}$. Use the first path in components with a selected first-array label and the second in components with a selected second-array label. Components with neither label can use either path. At a separator vertex use the path belonging to the selected input side it sees, if any. The input symbols outside the selected coordinates agree. Each work-block edge between components meets a separator vertex with fixed boundary contents. Consecutive chronological segments agree at the recorded head positions, times, control and auxiliary state. Hence all local transitions of the assembled path are legal, including its final verdict. The construction uses accepting paths as witnesses and never asks the nondeterministic machine to select their records.

For a nondeterministic UNSAT recognizer choose one accepting path per equal input if a path accepts by $T$. Two distinct such inputs in one bucket would give an accepting path on a satisfiable file, violating soundness. The fraction of equal inputs with any timely accepting path is at most $2^{-D+L}$. The same bound applies to a deterministic solver returning UNSAT. A nondeterministic recognizer for the opposite answer can guess a mismatching cell on the canonical promise.

For deterministic SAT deciders, take all diagonal paths through time $T$, retaining early halts with a latched verdict. They all have the property that no SAT answer has been given. Each bucket of size $q$ now supplies, for each $A$ in it, $q-1$ distinct unequal columns with the same property, and hence $q-1$ genuinely satisfiable inputs requiring more than $T$ steps. At most a $2^{-D/2+L}$ fraction of rows can lie in buckets of size smaller than $2^{D/2}$. In any of the larger buckets at least $2^{D/2}-1$ unequal partners are late. All variations are on exactly $D$ available Boolean coordinates. For any fixed $0<\lambda<1/2$ with binary entropy $H_2(\lambda)<1/2$, fewer than $2^{D H_2(\lambda)}$ partners differ in at most $\lambda D$ bits. In particular, exponentially many of these slow partners differ in $\Omega(D)$ bits. The same deterministic $A$ has the slow diagonal and the many slow unequal partners outside an exceptional fraction $2^{-\Omega(D)}$.

For a fixed linear deadline $T=Cn$, the average-live formulation has an unconditional consequence for machines with an arbitrarily large addressed side store. Except on a $2^{-\Omega_C(n)}$ fraction of diagonal rows, **every** timely sound accepting path for UNSAT has $\sum_{u<T}e_u=\Omega_C(n^2)$. To check the constants, set the candidate average cap $p=n/K_0$ for a sufficiently large constant $K_0$ depending on $C$, the machine, and the fixed file layout. Use the sharper separator accounting. Enlarge $K_0$ so enough whole blocks fit in each array and $s/9^k\ge1$. The cross-cell count is at least $a_C n$ for a constant $a_C>0$ independent of $K_0$. The record cost is $O_C(n/\sqrt{K_0})+o(n)$ and can be made smaller than $a_C n/2$. The injection for timely accepting paths with average at most $n/K_0$ gives the claimed exceptional fraction. In particular an everywhere $Cn$-time deterministic decider incurs this cumulative cost on almost every equal input. For standard $O(\log n)$-bit word addresses and values and a constant number of registers, encode the cardinality followed by the sorted list of live address/value pairs. If $q_u$ words are live after a head-moving step $u$, the bit cost is $O((1+q_u)\log n)$. Thus a timely path on a typical equal file uses $\sum q_u=\Omega_C(n^2/\log n)$ live word-times, even counting only head-moving steps. On this canonical promise the order is attained with sequential input by storing the first $t^2=\Theta(n/\log n)$ words by coordinate in side RAM and comparing the second section against them as it arrives. Parsing and checking a fixed-width record takes $O(\log n)$ steps, giving $O(n)$ time and $O(n^2/\log n)$ live word-times. The result concerns work storage used with a sequential input head.

## A local reduction from the original sparse language

There is also a direct lengthwise projection that recovers the result with no auxiliary store on a different, padded family. In the hard promise used by MSST, both matrices are binary $m\times m$, and only positions whose row and column are multiples of the designated stride $s=\Theta(\log m)$ can carry a one. Entries arrive in row order on both sides, with row separators. On this promise their proof requires acceptance of every matching pair and rejects each mixed unequal pair. It still applies when every source symbol has an extra finite-alphabet, read-only track depending only on input length and position. Fixed tracks agree on every mixed file. This advice is available on the existing input head. [MSST, pp. 393–395 and the mixed-input contradiction on p. 398](https://igi-web.tugraz.at/PDF/61.pdf#page=7)

Use the compressed active row and column indices in the clause construction and one data bit per active cell. Dilate each source position into $J$ output bytes for a fixed sufficiently large integer $J$. Successive active source positions have at least $s$ positions of separation. The initial inactive rows leave ample space for the header and pin gadgets. Place the clause for each active position in its own interval of $O(\log m)$ bytes, with its single variable data digit aligned with the start of that position's dilated cell. Its variable name has the form of a fixed tag and coordinate digits followed by this data digit. The rest of the literal, the other literal in the clause, and the terminating zero fit within the space on its two sides. One can extend the whitespace before a terminating zero over intervening inactive positions. For transparent endpoint accounting restrict to dyadic $m=2^h$ with odd $h>1$. The stride at this dimension is $h$, which does not divide $m$. The last row of each matrix is inactive and provides $\Theta(m)$ spare bytes. The MSST proof works at every sufficiently large fixed such dimension. All unused bytes can be assigned inside clause whitespace, with the last clause terminator and its newline exactly at the end.

For each position a fixed finite track supplies its $J$ output characters, with a marker for the one slot at which to substitute its actual 0/1 digit as ASCII 1/2. This is a single finite alphabet since $J$ is constant. A nearest-neighbor virtual head is simulated by the physical input head and an offset $e$ satisfying $0\le e<J$, each step costing constant time. The writable work tape is available to the simulated machine. This is a **lengthwise projection with a fixed advice track**. A uniform one-work-tape preprocessor with constant simulation overhead is a stronger requirement. The dense-family proof above instead works directly on the proper DIMACS bytes and needs no preprocessing assumption.

The nondeterministic statement is about recognizing UNSAT. The deterministic statement supplies lower bounds for actual inputs of both answers. Each argument uses a single unrestricted work tape with sequential input and separates a cost that disappears when the records have random input access. Neither the auxiliary-store bound nor the local projection proves the unrestricted RAM time milestone.

The [Lean replay lemma](../lean/BlockEpochSplice.lean) checks agreement with the previous visit to every writable block and preservation of the terminal controller. The graph selection, counting, and physical tape and RAM models are verified here at the manuscript level.
