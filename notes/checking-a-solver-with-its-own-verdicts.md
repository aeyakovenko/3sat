# Asking a clocked SAT solver about its own errors

**Research journal, 24 November 2026.** I tried to find errors in a proposed linear-time solver at formula lengths far beyond those for which all formulas can be enumerated. A positive answer to one particular SAT query suffices to exclude that solver unconditionally. A negative answer can hide errors at all lengths. Both conclusions apply to programs on the unrestricted RAM.

## A positive answer certifies a mistake

Fix a deterministic candidate $A$ with its time clock, using the total Boolean verdict convention of the [fixed-program construction](fixed-program-parity.md). Use explicit CNF lists with binary literal indices, terminal rules for the empty conjunction and an empty clause, and restriction on the first occurring variable. For a root $F$, there is a local defect if $A$ gets the terminal value wrong or if its answer differs from the OR of its answers on the two restrictions. These tests are effective even when $A$ is wrong. By descent, any incorrect verdict on these CNFs leads to a local defect at a descendant. If $A$ is a solver for general formulas it must pass every one of these CNF tests. [Lean proof of descent to a local defect](../lean/LocalVerdictCheck.lean)

Given $A$ and $K$, build a valid explicit SAT instance $Q(A,K)$ for the assertion that a root encoding of length at most $K$ has a local defect. Guess the root and its length, check syntax, construct the restrictions, then execute the at most three clocked candidate runs and compare their verdicts. For a fixed $O(n^d)$ candidate the verifier takes $K^d\operatorname{polylog}(K+2)$ time. Delimited CNF restriction costs $K\operatorname{polylog}(K+2)$ even when binary indices must be compared. The quasilinear reduction of bounded nondeterministic RAM computations to SAT preserves that bound up to logarithmic factors. Add harmless clauses if necessary to ensure the challenge has at least $K$ encoded bits. [RAM-to-SAT reduction](https://people.csail.mit.edu/rrw/automated-lbs.pdf)

If $A(Q(A,K))=1$ for **any** $K$, $A$ is incorrect. If its answer is true, a witnessed local defect already refutes $A$. If the answer is false, the challenge itself refutes $A$. Thus an independently checkable certificate for excluding this candidate consists just of $K$ and the accepting execution on its explicit challenge, with the fixed reduction understood. In particular there is no need to extract a witness to employ this rejection rule.

If an actual root exhibiting a defect is wanted, repeatedly restrict the challenge on an occurring variable. At a node where the candidate says yes, either a child also receives yes or the current node exhibits a local defect. A terminal with a wrong answer is also a defect. If this process reaches a true terminal, the resulting assignment satisfies the challenge. Decode the root from the assignment and verify its claimed defect directly. For a challenge of length $S$ this takes $O(S)$ further candidate calls on CNFs of length at most $S$ in a restriction-closed presentation. This search-to-decision argument accounts for the case where the program supplied the wrong initial yes.

At phase $m$ of the matrix experiment the budget is $2^{2m}\operatorname{poly}(m)$. For the $O(m)$ short trial descriptions the guest clocks, word factors and universal simulation overhead are polynomial in $m$ at the following scale. Choose $K=2^{\lfloor 2m/d^2\rfloor}$. Building the query and running the candidate on it costs $K^{d^2}\operatorname{poly}(m)$ in total up to the same polynomial overhead, including all candidates. One can discard any candidate that returns yes, in addition to the exhaustive small-root checks. This tests for some defects at exponentially larger root lengths without disqualifying any correct candidate. For any candidate that errs on CNFs, all challenges beyond its first local defect are satisfiable. Hence a candidate that never returns yes gives incorrect negative answers on this entire tail. Detecting that behavior still requires evidence of a defect.

## A linear-time candidate that evades every such challenge

For any fixed $H$ take $A_H$ to decide SAT exactly through length $H$ and return zero on all longer inputs. The finite table or the entire finite search can be included in the fixed program. Its worst-case time is $O(n)$ with a constant depending on $H$. Use a delimited CNF encoding in which deleting literals and clauses leaves each descendant no longer than its root, with terminal formulas handled directly. The candidate is locally consistent on every root of length at most $H$ and is incorrect on arbitrarily long satisfiable CNFs.

For $K\le H$ the challenge has no witness. If the challenge length is at most $H$, the candidate correctly returns zero, and otherwise it returns zero by its length rule. For $K>H$, the padding guarantees $|Q(A_H,K)|\ge K>H$, so it again returns zero. Thus a single wrong program can pass **every** self-challenge and every independently checked root up to an arbitrarily prescribed finite length. The full finite-falsification search eventually eliminates it. This example identifies the missing step in a proposed shortcut that would only ask the candidates to report their own errors. General program checking has an extensive literature. [Blum and Kannan](https://www.cerias.purdue.edu/apps/reports_and_papers/view/701)
