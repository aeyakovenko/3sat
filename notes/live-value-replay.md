# Cumulative descriptions of just the read values used in the near future

**Research journal, 24 November 2026.** Fix a deterministic logarithmic-word RAM and a fixed, polylogarithmic-time word evaluator. At each pre-signal instruction $t$, begin a fresh local history. Over the next $h$ instructions or up to the signal, whichever comes first, predict the first writable read of each address that has not yet been written in this interval. Cache earlier reads and let writes override the cache. The evaluator receives the formula, $t$, $h$, a string, its length, the current address, controller, offset and strictly preceding native history since $t$. It need only predict the words of the genuine execution and receives no writer indices. Use a bounded total evaluator on arbitrary strings and histories, with a fixed clock and default answer. Let $s_t$ be the least honest string length (infinity if there is none) and $C_h=\sum_{t<E}(1+s_t)$ through the first signal. The strings can be chosen with full hindsight, independently at every starting time. They need never be extracted or published by the solver. [Precise incoming-read interface](live-segment-snapshot-queries.md)

**Unconditional result.** For every deterministic sound UNSAT signal occurring on all unsatisfiable formulas, the worst-case $C_h$ on unsatisfiable inputs is outside $O(N^{1.3622})$ for $h=\lceil N^{0.97}\rceil$ and $N$ encoded input bits. No negative run length, physical workspace limit or behavior on positive inputs is prescribed. There is also a positive-side result. For a deterministic sound SAT signal on all satisfiable inputs, $C_h$ on positives is outside $O(N^c)$ for every $c<\sqrt[3]2$ when $h=\lceil N^{2/3}\rceil$. These are bounds on a sum of description costs. A linear-time machine can fill nearly every position in each interval with a read value requiring a word of advice when written literally.

The [negative full-state theorem](cumulative-snapshot-descriptions.md) attains $\varphi$ but asks each string to return the contents of every address at its particular checkpoint. Here a decoder can give arbitrary answers at all addresses it never encounters, and its answer at any one address can depend on the preceding local history. Ordinary time–peak-space alternation-trading bounds have a different hypothesis. Priority for these read-value cost statements is unverified. [Buss and Williams on the rules for classical alternation trading](https://mathweb.ucsd.edu/~sbuss/ResearchWeb/npProofLimits/samCCC-cr.pdf)

## Two nonacceptance tests, charged separately

Assume $C_h=O(N^c)$ on every negative input. Use the locally indexed formula for a nondeterministic source with horizon $R$ and $m$ public words. Set $H=\max(R,m,2)$. Its encoded length is between $H$ and $H\operatorname{polylog}H$ with the regular padding. Write $W(u,b)$ when nonacceptance of every such fixed bounded source can be certified nondeterministically within $(R^u+m^b+1)H^{o(1)}$ steps. The assumption implies $W(c,c)$ by running the recognizer on the materialized formula. An unsatisfiable input always has a timely signal, and a satisfiable input cannot have one. [Reduction, clocks and diagonal](packed-band-transfer.md) · [Public-input recurrence framework](cumulative-sat-memory.md)

Choose $w=\lceil H^x\rceil$ with $x<0.97$. Guess cuts at times of minimum $1+s_t$ in each disjoint full internal window of $w$ steps. The public chart contains the terminating time, times, true controllers and ordinary bit strings for these cuts; it starts at the prescribed zero state. It uses $H^{c-x+o(1)}$ bits, including directories. Enforce a polynomial native time cap and bound the largest gap by $2w+O(1)$. All full strings are ordinary read-only data, and their true minimality need never be checked. At sufficiently large sizes $2w+O(1)\le h$. Running a proposed block from its own start controller, with the chart bits on first incoming reads, uniquely determines a transcript in $H^{x+o(1)}$ deterministic steps. The first block reads zero at previously untouched addresses. The input and all decoder accesses to the input use the genuine local formula generator. The evaluator is told the original $h$ even if the verifier stops a replay earlier. Bounded histories and its per-call fresh scratch can be implemented within the stated work.

A defect can select a bad initial or terminal control condition, a controller mismatch between neighboring blocks, or a wrong incoming value. For the latter guess a read in block $i$ and a candidate previous writing block $j<i$ or the initial sentinel. Replaying the indicated blocks shows that the last write to this address in $j$ stored a word different from the proposed value. For the sentinel test that the read is nonzero. This witnesses a defect only if *no* strictly intervening block writes the address. The latter assertion is the nonacceptance of a shorter test that guesses an intermediate block and replays just that block on the same chart. This characterizes defects exactly by considering the actual last writing block in the concatenation of the canonical transcripts. If there are no defects, induction from zero identifies the concatenation as the real run. The displayed criterion also catches intervening same-value writes by using the latest writing block when demonstrating a wrong read. It needs no certificate for addresses absent from the entire read sequence. [Canonical blocks and intervening-write check](live-segment-snapshot-queries.md)

Suppose $W(u,b)$ and $W(v,a)$ have already been established. Set $y=c-x$. Use $W(u,b)$ for the *intervening-block* test, whose work is $H^{x+o(1)}$ and public data size is $(m+H^y+1)H^{o(1)}$. Thus the defect itself has a nondeterministic test of clock $(H^{xu}+H^{yb}+m^b+1)H^{o(1)}$, also covering its ordinary replays. Its public data are still just the original source and chart. Use $W(v,a)$ on that defect, after guessing the chart. A proposed rejection is now certified in
$$
 (H^{xuv}+H^{By}+m^B+1)H^{o(1)},\qquad B=\max(a,bv).
$$
Increasing $B$ is harmless. In each use the public chart has already been fixed; the guesses of the intervening-block procedure are private to its defect branch. The chart validation scan can be done outside the defect test. Absorbing $H=m$ into $m^B$ is valid whenever the resulting work exponent is at most $B$. As usual all claimed lengths, horizons and bounded machines are clocked. Choosing rational powers and a fixed small slack at each of the finitely many calls preserves a strict crossing below one.

## A finite exponent certificate

Balance at $x=Bc/(B+uv)$ to obtain $W(cBuv/(B+uv),B)$. Fixing an inner pair $(u,b)$, first widen its outer public exponent to $B\ge bu$. Repeatedly use that same inner pair, with the successive outer work exponents $v$ starting at $u$. While $1\le v\le u$, the public exponent $B$ remains sufficient. The positive fixed point of $v\mapsto cBuv/(B+uv)$ is $B(c-1/u)$; the computation uses finitely many transformations and upward rounding at each stage. For $c=6811/5000$ the exact-rational certificate gives:

| Stage | Transformations at this stage | Work exponent obtained | Public exponent |
|---:|---:|---:|---:|
| 1 | 20 | 1.165483837 | 1.855588840 |
| 2 | 25 | 1.090385654 | 2.162658802 |
| 3 | 27 | 1.049589692 | 2.358132133 |
| 4 | 30 | 1.013410597 | 2.475071180 |
| 5 | 1 | 0.992574225 | 2.508263363 |

Across all 103 transformations the largest $x$ is below $0.967$. Each completed stage supplies the next inner pair. The final public exponent is below three. On the signed padded self-input with $m$ public words and clock $R=m^4$, both work terms are $o(R)$, contradicting the bounded complementary diagonal. The proof gives no optimality assertion about this choice of stages. ## Positive inputs and shorter horizons

Let a separate sound nondeterministic UNSAT reference on negatives have time $O(N^d\operatorname{polylog}N)$ for fixed $d\ge1$. For a positive signal, if $h=\lceil N^\gamma\rceil$, $0<\gamma\le1$, infinitely many satisfiable formulas have
$$
 C_h \ \ge\ N^{1/d^2+\min(\gamma,1/d^2)}/\operatorname{polylog}N .
$$
Use the unary positive nondeterministic time-hierarchy family with original machine clock $R$, explicit $N=\Theta(R\log^3 R)$ and only the logarithmic length parameter needed for local formula access. Choose $w$ the smaller of $h/4$ and $R^{1/d^2}/\log^A R$, rounded suitably. A hypothetically cheap positive run has a chart of size $(1+C_h/w)\operatorname{polylog}R$. The two successive reference calls above certify an honest positive chart in $(w+C_h/w+1)^{d^2}\operatorname{polylog}R$ time. This accepts only if the deterministic program actually gave its sound positive signal. Take the threshold for $C_h$ to be $wR^{1/d^2}/\log^{A'}R$ with sufficiently large constants. If every sufficiently large positive length allowed such a chart, its source language would be in the excluded $O(R/\log R)$ nondeterministic tape time, including the quasilinear tape simulation and physical unary input. Hardwire any finite exceptions. This also proves the unconditional cube-root result: a positive $O(N^c)$ bound gives the all-negative deterministic reference with exponent $d=c$ from an elapsed-time cutoff, and $c<\sqrt[3]2$ gives a strict exponent gain for $\gamma=2/3$. For $c<1$, relax it to 1. [Positive hierarchy and RAM-to-tape proof](positive-witness-hierarchy.md)

At small horizons one can improve this last application. Take $w=R^x$, $x\le\gamma$ with enough constant or logarithmic clearance for the longest replay. On the unary root its public input is short. Write $y=c-x$ for the exponent bounding the total chart length. In the defect's intermediate-block test, partition rows of length $\le w$ into groups of total size $O(w)$, charging also a word of metadata per row. There are $O(1+R^y\operatorname{polylog}R/w)$ such groups by greedy packing. A group test guesses just one of its supplied rows and replays it. Its public inputs are the selected rows, address, endpoints and short unary formula parameters. It can recognize whether any row in that group wrote the address in the specified interval. For each group use one reference certificate of nonacceptance. Directly replay each individual larger row from a read-only view of the original chart; there are at most $R^{y+o(1)}/w$ such rows and replay takes $w\operatorname{polylog}R$ time regardless of its string length. The group construction itself takes $R^{y+o(1)}$ time. The resulting nondeterministic defect test costs $(w^d+R^yw^{d-1})R^{o(1)}$. One final nonacceptance reference charges its work and the *full* chart. This excludes every positive bound with
$$
 \max\{d^2x,\ d(c-x)+d(d-1)x,\ d(c-x)\}<1 .
$$
For example at positive cumulative exponent $c=d=1.1$, $x=0.22$ gives a largest exponent of $0.9922$, enough for $h=\lceil N^{0.23}\rceil$. The single-call alternative without grouping would cost $1.0648$ in its public-input term.

Under deterministic near-linear SAT, there is also a positive family at *every sufficiently large source padding length*, depending on the solver and evaluator. Fix $\gamma$, choose $w$ as above for $d=1$, and cap the chart at $R/\log^{A'}R$ bits. The property that some chart passes is decidable deterministically in $(w+R/\log^{A'}R+n_0)\operatorname{polylog}R$ time, by a constant number of ordinary bounded-computation SAT eliminations for the chart guess, the defect and the intervening-write guess. Here $n_0$ is the short physical padded self-input, and $R=n_0^D$ for fixed $D>1$. Pick the fixed logarithmic margins large enough that the test fits inside $R$. On its own input let the source accept precisely when this deterministic test finds no passing positive chart for its bounded-computation formula. If that actual formula were negative the signal's soundness would forbid any passing chart, forcing source acceptance. Thus the formula is positive, and it cannot admit a passing chart within the cap. In particular on this family the genuine positive run has $C_h\ge N^{1+\gamma}/\operatorname{polylog}N$. The family is tailored to the program and the evaluator. This fixed-point argument calls for deterministic near-linear SAT; the positive subsequence argument above needs only the stated nondeterministic UNSAT reference.

## One sign cube with hard positive and negative runs at every horizon

Under the same deterministic near-linear SAT hypothesis, let $A$ be a **correct two-sided** solver. For every sufficiently large integer $k$ there is a single locally generated formula layout with $k$ designated literal-sign bits and otherwise fixed encoding. For *every* setting $b\in\{0,1\}^k$ the resulting formula $F_b$ is satisfiable precisely when $b$ has odd parity. Every vertex of this cube has a hard live-read run of its own actual sign. There is a fixed $D$ such that simultaneously for every integer $4\le h\le N$,
$$
 C_h(F_b)\ \ge\ \frac{N\min(h,N/\log^D N)}{\log^D N}
$$
for all sufficiently large $k$ (enlarge $D$ to absorb constants). The physical work memory is unrestricted. The layout has $k\ge N/\operatorname{polylog}N$ varying signs and depends on $A$ and the evaluator.

Here are the quantifiers in the diagonal. Give a universal bounded source a fixed checker program and a delimited $k$-bit suffix $b$. Its common clock is $R=k\lceil\log_2(k+2)\rceil^J$ for a large fixed $J$. Compute $p=\bigoplus_j b_j$. With guessed chart bit length and block work capped at $M=\lfloor R/\log^I R\rfloor$ (increasing $I$ as necessary), deterministically decide the existence $Q$ of a passing chart for $A$ giving sign $p$ on this very source's bounded formula. The chart can choose any integer $h'\le N$ for use by its evaluator and any gaps below its cap. Its soundness only uses the checked incoming values from the concatenated canonical replays. One horizon that happens to produce a valid chart already certifies a genuine native signal. No branch for a different purported horizon can counterfeit an incorrect verdict. Make the source accept iff $(p\land\neg Q)\lor(\neg p\land Q)$.

Each quantifier elimination takes time linear in its short physical data plus bounded work, times a fixed power of $\log R$. There are constantly many eliminations and $k$ public bits. Thus the whole test takes $O((M+k+1)\log^K R)$ for a fixed $K$. Choose fixed $I,J>K+3$. The logarithmic overhead exponent $K$ comes from a fixed number of reductions, interpreter and SAT calls on polynomial-size objects and is independent of these fixed clock-margin choices. This test finishes by $R$ on every suffix. On a parity-one suffix, $Q$ would certify a genuine SAT verdict yet make the source reject. On a parity-zero suffix, $Q$ would certify a genuine UNSAT verdict yet make the source accept. Both alternatives contradict $A$'s correctness. Thus $Q$ is false on *every* suffix and the bounded formula has truth $p$.

In the regular reduction fix all layout parameters from $k$. Initialize each suffix input bit by a single signed pin on its own wire. A width-three version uses $(\ell_b\lor f\lor f)$ with a common pinned-false variable; only that one sign of $\ell_b$ changes. All bit tests in the checker, including its parity computation, are inside the bounded computation and induce no other $b$-dependent clauses in the formula encoding. The encoded size is $N=\Theta(R\log^3 R)$. Hence any two adjacent cube vertices differ in one actual encoded bit and have opposite verdicts. Every native run must inspect every one of its designated sign positions: if a run omitted one, flipping that bit would leave its entire computation unchanged. Distinct clause records have $\Omega(\log N)$ bits each, so this requires $\Omega(k)$ input-word probes at each vertex.

On a genuine run and any $4\le h\le N$, use least-cost cuts in windows of $w=\max(1,\lfloor\min(h/4,M/8)\rfloor)$ instructions. Gaps are at most $2w+1$ including endpoint rounding, which lies within both the forecast horizon and the replay cap. A chart of $(1+C_h/w)\operatorname{polylog}N$ bits with busy-replay work $w\operatorname{polylog}N$ gives a timely verification, shrinking $w$ by a further fixed power of the logarithm in the $M$ term if the replay cap measures simulated rather than native instructions. The absence of any passing chart within the caps implies the stated estimate after enlarging $D$. Since the horizon was a chart field, the family and the power $D$ are simultaneous over $h$.

A stronger version of the same cube permits one read-only advice bank at native random-access speed in addition to the separate row strings. Guess that bank once inside $Q$. Reserve, for example, a quarter of its bit budget for it and a quarter for checkpoint strings and headers. It can be any string of up to $N/\log^{D'}N$ bits for a sufficiently large fixed $D'$, even chosen separately for each entire suffix and run. On the resulting layout every vertex's lower bound above applies for every such bank after a further fixed increase of $D$. Guesses of banks and horizons are inside the chart test, so no union bound over $2^k$ vertices or over advice strings is needed.

A different solver can recognize this particular layout and return parity on it. Its own signed layout can change. A proposed self-specializing solver that returns parity on *its own* suggested cube cannot justify that branch by this theorem: the parity conclusion used the correctness of that very solver. Checking the truth intrinsically by simulating the deterministic source instead spends up to $(M+k+1)\operatorname{polylog}N$ work, consistent with failure of a chart capped at $M$. The same-sign hardness and sensitivity on the cube do not eliminate this circularity. [Signed truth table and adaptive pin sensitivity in Lean](../lean/LiveValueReplay.lean)
