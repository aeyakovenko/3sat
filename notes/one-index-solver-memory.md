# One-index verification of a SAT decision run

Fix any correct deterministic SAT solver $A$, a depth $d$, and a modulus $m\ge2$. There are a rational $a>0$ and an effective family of **unsatisfiable, explicit** 3-CNFs $F_k$, one for each sufficiently large $k$, with encoded bit length $2^k\le N_k\le 2^k k^{O(1)}$. Write $u=k+\lfloor k^a\rfloor$ and $T=2^u$. On each $F_k$, either the solver has yet to halt at time $T-1$, or the following two functions of a single $u$-bit index cannot both have depth-$d$ ACC$[m]$ circuits of at most $2^{\lfloor k^a\rfloor}$ gates.

* $G(t)$ returns the actual program counter and fixed register file before native instruction $t$, with the rejecting state idled after halt.
* $Q(i)$ returns the timestamp at rank $i$ in the ordering of those same instructions by work-memory address and then timestamp. Non-memory instructions form a separate dummy group ordered by timestamp.

This first statement uses a logarithmic-word load/store RAM with a fixed register file, read-only packed input, initially zero work memory, and register instructions having uniformly constructible polynomial-size constant-depth AC$^0$ circuits on their word operands. This covers ordinary addition, subtraction, Boolean operations, comparisons and shifts. There is no restriction on the amount of workspace. A version for multiplication and division appears below. The circuits are specific to the individual input and may hardwire it. The theorem requires no worst-case running-time hypothesis on $A$ and uses no call to $A$ inside the verifier. In particular, if $A$ takes $O(N\log^b N)$ steps for any fixed $b$, it is the second alternative that holds. For large $k$, even $N_k 2^{(\log_2 N_k)^a/3}<T-1$.

## Checking the two functions

Check the deterministic initial state, rejection at $T-1$, and the local transition at each $t<T-1$ using $G(t),G(t+1)$. Check the actual input word on an input load. A work load puts its reported word into the designated destination register. A store takes its address and value from the pre-instruction state. Once local conditions hold, every work instruction thus discloses its address and a post-access word, either its store value or its reported load. Treat row $T-1$ as a dummy after checking rejection there.

For any proposed $(G,Q)$ construct the key $K(t)=(\mathrm{dummy}(t),\mathrm{bank}(t),\mathrm{address}(t),t)$, with bank and address fixed at zero for dummies. Require $K(Q(i))<K(Q(i+1))$ at all nonfinal ranks. A repeated timestamp would repeat its entire key because its bank and address come from the *same* $G$. Hence $Q$ is injective, then bijective on the $T$ slots. Its order and its output are uniquely determined by $G$. At a load $Q(i)$, require its reported value to equal the previous post-access word if the preceding record exists and has the same active bank and address. Otherwise require zero. Stores impose no condition on the previous word. Induction first in address order and then in native time proves that a passing candidate gives exactly the real rejecting trajectory. The real idled trajectory and its sorted ranks pass every test.

A single circuit on $u$ inputs ORs the chronological and address-order failures at that index and the boundary failures. It computes comparisons and increment in AC$^0$ and composes a constant number of copies of the two proposed circuits, e.g. $G(Q(i)+1)$ to obtain a load reply. The width of each row is $O(k)$, and every word bit of an input load can be produced as described below. The defect circuit therefore has a fixed depth $D$, fixed modulus $M$ and size $\operatorname{poly}(k,s)$ for candidates of size $s$. Counting explicit wires in their descriptions changes only that polynomial. There is no second freely quantified timestamp. The key-order proof is a succinct use of the classical sort-and-check verification of RAM memory. An earlier journal entry used a ranked address path as an additional trace layout. The earlier register-only test used two quantified times for a possible consumer and intervening store. [Jahanjou, Miles and Viola, §1.2 and Theorem 12](https://arxiv.org/pdf/1311.3171) · [Earlier ranked layouts](trace-pathwidth.md) · [Earlier register bounds](chronological-solver-registers.md)

## An explicit formula with inexpensive packed input reads

Fix a universal multitape interpreter $U$ whose input $x$ describes a nondeterministic program followed by arbitrary padding. Its bounded acceptance test is that it sees a success signal during its first $H=2^{|x|}$ simulation steps. A counter and fixed-interpreter overheads give a deterministic multitape verifier with a sequential choice string and time $H\operatorname{poly}(|x|)$. Equivalently one can clock the interpreter's own steps directly. A fixed finite-tape program can be interpreted with polylogarithmic overhead per step amortized, by a fixed-tape universal simulation. Applying the local reduction to this fixed verifier gives, for each $k$-bit $x$, a circuit $D_x$ in time $\operatorname{poly}(k)$. It maps $\ell=k+O(\log k)$ bits to three signed $O(k)$-bit variable names. Each output bit depends on at most a fixed constant number of index bits. The resulting formula is satisfiable exactly when some simulated branch signals in time. Given the dependence bound $c$, evaluating the supplied circuit on all strings of weight at most $c$ finds each relevant coordinate by comparing inputs differing in one position. Each coordinate with genuine influence has such a pair supported on the at most $c$ relevant coordinates. This gives explicit constant-size truth tables per output. [Jahanjou, Miles and Viola, Theorem 1](https://arxiv.org/pdf/1311.3171)

Use an ordinary packed fixed-width list with a short binary header and three signed literal fields per clause. Allow unused variable names. Zero-extend the old names, rounding the combined sign-and-name field width up to a power of two, with room for a fresh largest name. Add at least $2^k$ copies of a tautological 3-clause using the high name, e.g. $(z,\neg z,z)$, to fix the declared width and the lower bound on $N_k$. The header, ranges, literal width, total length, and any bounded conversion of zero-based to one-based names are computable in $\operatorname{poly}(k)$ time. A word read at physical word address $h$ can fetch each of its $w=O(k)$ bits independently. To form $wh+j$, partition $h$ into base-$2^p$ digits for $2^p\ge w$ and $p=O(\log k)$. Each digit product by fixed $w$ is a polynomial-size lookup and has at most two digits. Add the two assembled rows by one ordinary binary addition, and add $j$ at full precision. Range checks, the header and end padding are explicit. After subtracting the header, the dyadic width gives a literal number by a shift. Dividing that number $z'$ by three requires only AC$^0[3]$. Bit $b$ of the quotient equals one exactly when $(z'\mathbin{\gg} b)\bmod 6$ belongs to $\{3,4,5\}$. Parity of the integer is its low bit and its residue modulo three is the alternating weighted sum of its binary digits modulo three. The literal selector is $z'\bmod 3$. Query the selected local clause or fixed padding clause. All these circuits have size $\operatorname{poly}(k)$ and fixed depth. One may take $M=\mathrm{lcm}(3,m)$, replicating a MOD$_j$ input $M/j$ times to implement MOD$_j$ for $j\mid M$. An encoding with its own uniformly constructible fixed-depth decoder needs no such padding argument. No stage writes out $F_k$ inside the short verification.

## The signed decision and its actual clock

Use a program $V$ that on input $x$ constructs the packed-input decoder for the bounded interpreter on that very $x$, guesses small circuits for $G,Q$, verifies their encodings and signals precisely when the defect circuit is unsatisfiable. Define $x_k$ to contain the fixed description of $V$ with padding to length $k$, and take $F_k$ to be the explicit binary instance just constructed for $x_k$. There is no code-generation fixed point. The generic compiler for $U$ is fixed before $V$ and $V$ simply receives the same input $U$ is simulating it on. Any timely signal would make $F_k$ satisfiable by construction while certifying that the correct $A$ rejects it. Hence $F_k$ is unsatisfiable, whether or not a small certificate exists. [Finite bounded-clock implication](../lean/SolverSnapshotReplay.lean)

Williams's Theorem 4.5 gives constants $\delta>\epsilon>0$ for $D,M$ such that ACC-SAT on $u$ bits and size $2^{u^\epsilon}$ costs $2^{u-\Omega(u^\delta)}$. Fix a rational $0<a<\epsilon$; the defect depth is independent of $a$. For $s=2^{\lfloor k^a\rfloor}$, constructing and guessing the circuitry costs $2^{O(k^a)}\operatorname{poly}(k)$ and the defect size fits. The decision and fixed polylogarithmic simulation costs total at most
$$
2^{k+\lfloor k^a\rfloor-\Omega(k^\delta)}\operatorname{poly}(k)+2^{O(k^a)}\operatorname{poly}(k)=o(H).
$$
If the decision algorithm for ACC-SAT uses random access, the nondeterministic tape program can guess its chronological transcript, check its actual deterministic output and sort its memory records on multitapes. The cost is its running time times $\operatorname{poly}(k)$ on these computations. Honest computation has such a branch and no false ACC-SAT output passes. This simulation is for the short verification algorithm; no assertion of succinctness is made about its transcript. Thus an early halt and two small genuine circuits would give a timely signal, proving the disjunction. [Williams, Theorem 4.5 and §4.1](https://people.csail.mit.edu/rrw/acc-lbs-journal-final.pdf)

For register operations with an arbitrary uniformly constructible $\operatorname{poly}(k)$-size bounded-fan-in circuit, including conventional multiplication and division, the same conclusion holds with an augmented $G$. Its row also outputs the actual internal evaluations of the fixed native operation circuit at that instruction. Parallel gate-equation tests validate all these bits in constant depth, their wiring being fixed for this width, and determine the correct result. These annotations are canonical functions of the true operands. The proof for this instruction set gives a lower bound on the joint description including those bits. It does not establish the corresponding conclusion for the register-and-rank functions alone.

If one substituted $T=N^2$ or $N^3$, the displayed SAT algorithm would have cost bound $N^{2-o(1)}$ or $N^{3-o(1)}$ even with this single index. If one used two full timestamp indices, the same bound would already be $T^{2-o(1)}$ at the linear frontier. The proof forces an individual fast computation to have expensive descriptions in a restricted circuit class. It leaves open how long an unrestricted computation must take. The published local reduction and ACC witness arguments supply the complexity ingredients; priority of this application to a single actual rejecting decision run is unverified.

On the prehalt portion, the exact obstruction also forces a single controller or rank bit to be hard to predict on a uniform set of indices. The set and output coordinate may depend on the run. [Hard-set proof and prediction advantage](trace-bit-hard-sets.md)
