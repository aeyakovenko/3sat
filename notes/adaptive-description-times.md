# Paying for the next stage with programs that just finished

**Research journal, 24 November 2026.** Between $2^{3m}$ and $2^{4m}$ steps, some single $m$-bit word has **at least $c\sqrt m$ strictly improving shortest-description lengths**, at every sufficiently large $m$, on every fixed efficient native prefix-universal machine $V$. Its description by the final deadline uses at most $3\lceil\log_2(m+2)\rceil$ bits. The construction is unconditional and one uniform algorithm computes the word from $m$. The [linear-SAT implication](successive-description-times.md) gives $\Omega(m/\log m)$ for precisely the same statistic. This improves the fixed-threshold enumeration by funding each new stage from the program mass observed in the preceding interval.

## One prefix code across lengths and stages

Let $b=\lceil\log_2(m+2)\rceil$, $L=\lfloor\sqrt m\rfloor$, $k=\lfloor\delta L\rfloor$ and $S_j=2^{3m+j(3L+Ab)}$ for $0\le j\le k+1$. Here $A$ is a fixed integer paying polynomial overhead and $\delta>0$ is a small fixed dyadic. We require $S_{k+1}\le2^{4m}$ for large $m$, which holds for $\delta<1/4$. At length $m$ consider the $2^L$ candidates $0^{m-L}z$, $|z|=L$. Write $M_j(m)$ for the total weight of exact $V$-programs of length at most $L$ that publish *any* $m$-bit output by $S_j$. For distinct $m$ only disjoint names are counted. At a fixed $m$ the increments over nonoverlapping time intervals also count disjoint names. Thus $\sum_{m,j\ge1}(M_j(m)-M_{j-1}(m))\le1$ when the stage indices are restricted to the indicated ranges.

Make one Kraft request for each $(m,j)$ with $1\le j\le k+1$ and $m\ge1$. Take

$$
g_{m,1}=2^{-4b-5},\qquad g_{m,j+1}=2^{-4b-5}+\tfrac18\bigl(M_j(m)-M_{j-1}(m)\bigr)\quad (1\le j\le k).
$$

Request a codeword of length $a_{m,j}=\lceil-\log_2 g_{m,j}\rceil$ and total weight $2^{-a_{m,j}}$. These requests fit in a single prefix code. The arrival terms sum to at most $1/8$, and the baseline terms sum to less than $1/2$ since $k+1\le m+1$ and $2^{-b}\le1/(m+2)$. The baseline also gives $a_{m,j}\le4b+5$, even if no useful program arrived. Order the requests by the integer $\log_2 S_{j-1}(m)$, breaking ties by $(m,j)$. Each request depends only on computations through its assigned deadline.

Use online Kraft–Chaitin allocation in this order. Start with a free root. To grant length $a$, take the longest free node of depth at most $a$ and split until depth $a$, reserving one sibling at each split. There is at most one free node of each depth. A finite list consisting only of deeper nodes has total weight strictly less than $2^{-a}$ and so cannot be the entire free list at this request. This proves availability and yields an effective common code. A decoder on a one-way stream need not read past its codeword: maintain the trie of allocations seen so far. When its current input prefix is an allocated leaf, stop parsing the code. Read another bit only if the prefix is already an internal node, otherwise advance the enumeration. A later allocation cannot turn an internal node into a leaf. On each allocated code the parser succeeds no later than its allocation plus polynomial overhead for the trie operations. [Kraft–Chaitin construction and prefix coding](https://mccme.ru/shen/kolmbook/kolmbook-eng-scan.pdf)

## The charge for lowering a threshold

Let $h_j=a_{m,j}+c$, where the fixed reserve $c$ exceeds all interpreter and dispatcher header bits. It can be supplied self-delimited to the fixed dispatcher and chosen large enough to pay for this field as well. Let $\ell_1=L-1$. The initial pool consists of the candidates with $K_{S_0}(y)\ge\ell_1$ and has size at least $2^L-2^{L-1}$. At stage $j$ the pool has at least $n_j=2^{\ell_j-h_j}$ words, each satisfying $K_{S_{j-1}}\ge\ell_j$. After the code for $(m,j)$ a decoder reads $\ell_j-h_j$ raw rank bits and prints the corresponding member of this pool in lexicographic order. The program length is strictly less than $\ell_j$. The runtime verification below puts these $n_j$ distinct publications by $S_j$.

Restrict the old pool to the words with $K_{S_j}<\ell_j$; this includes all $n_j$ words just produced. Set $u=\ell_j-1-h_j+h_{j+1}$. Take as $\ell_{j+1}$ the largest $0\le t\le u$ for which the restricted pool contains at least $2^{t-h_{j+1}}$ words with $K_{S_j}\ge t$. Those words constitute the next pool. Thresholds below $h_{j+1}$ can be interpreted using rational quotas in this choice; the resulting cutoffs stay larger by the estimate below. A zero threshold qualifies when $u\ge0$ and $n_j\ge1$. A qualifying $t$ is strictly below $\ell_j$, since all words in the restricted pool have complexity strictly below $\ell_j$. In particular $u$ need not itself be below $\ell_j$. After stage $k$ apply the same transition to select survivors without issuing additional rank programs.

Write $d_j=u-\ell_{j+1}$. If $d_j\ge1$, the test at $t=\ell_{j+1}+1$ failed. Fewer than $2^{t-h_{j+1}}\le n_j/2$ of the $n_j$ generated words can then have $K_{S_j}\ge t$. Each of at least half has a name of length at most $\ell_{j+1}$ by $S_j$. Any such name must have arrived after $S_{j-1}$ by the earlier lower test and $\ell_{j+1}<\ell_j$. Distinct outputs have distinct names. Hence

$$
M_j(m)-M_{j-1}(m)\ge (n_j/2)2^{-\ell_{j+1}}=2^{d_j-h_{j+1}}.
$$

But the very request for $(m,j+1)$ has weight parameter at least one eighth of this mass, and $2^{a_{m,j+1}}\le2/g_{m,j+1}$. It follows that $2^{d_j}\le2^{c+4}$; this also holds for $d_j=0$. Every unexpectedly large threshold reduction would have paid for a shorter stage header, so $d_j$ is bounded by a constant on every stage and at every length.

For any initial $s$ completed transitions the exact telescope is

$$
\ell_1-\ell_{s+1}=s+h_1-h_{s+1}+\sum_{j=1}^s d_j\le (c+5)s+h_1.
$$

We have $h_j\le4b+5+c$. Choose $\delta\le1/(8(c+6))$, using for instance a fixed dyadic determined by the reserve $c$. Thus every cutoff through stage $k+1$ stays above $L/2$ at sufficiently large $m$. Inductively, before each transition the cap $u$ is positive, the test at zero is available, and the bound through that transition ensures the next actual rank field is nonnegative. The construction can diverge on ill-sized small parameter cases. The choice of $\delta$ through $c$ avoids a circular dependence between the program reserve and the number of stages.

## Decoding the global code in time

The dispatcher initially knows neither the length nor the stage. To enumerate requests through a log deadline $E$, loop over exponents in increasing order and list the finitely many pairs with that deadline. Only $m'\le E/3$, $j'\le m'+1$ are possible; simple integer tests and the tie order suffice. For each pair enumerate the fewer than $2^{L'+1}$ finite inputs of length at most $L'=\lfloor\sqrt{m'}\rfloor$ through its preceding clock. Count a halt only when the exact consumed length equals the tested length. This computes the requested arrival mass with finite dyadic arithmetic. Each virtual step and its instrumentation cost $\mathrm{poly}(E)$ physical time by the native simulation theorem. Simulations can discard outputs longer than the relevant length, and can reuse a sparse store with fresh trial identifiers. A time-bounded interpreter simulates physical instructions only up to its cutoff even if the program being simulated is another copy of the dispatcher.

At the request for $(m,j)$, $E=\log_2 S_{j-1}(m)\le4m$ at large $m$. In every request processed up to this one, $L'\le\sqrt{4m/3}\le2L$ eventually. Their **entire** enumeration, including all ties, dyadic calculations and trie work, consequently takes at most $S_{j-1}2^{2L}\mathrm{poly}(m)$ native steps. Once $(m,j)$ is known, enumerate the $m$-length trials through $S_{j-1}$ to tabulate for each candidate its shortest length at every earlier clock up to the cutoff $L$. A sorted lookup table or trie suffices. Reconstruct all previous requests for this length, cutoffs and pools from these records. These scans, testing at most polynomially many thresholds and stages on the $2^L$ candidates, fit the same bound. The decoder determines $\ell_j$ using masses up to $M_{j-1}$ only. It never needs $M_j$ before its own stage is over. The clock ratio $2^{3L+Ab}$ absorbs the bound with a fixed sufficiently large $A$.

Finally, one fixed program reads only $m$ self-delimited, runs the same finite analysis through $S_k$, and prints the first member of the final pool by $S_{k+1}$. Its length is eventually at most $3\lceil\log_2(m+2)\rceil$. For each $j$ a survivor had $K_{S_{j-1}}\ge\ell_j$ and $K_{S_j}<\ell_j$. Thus the same word realizes all $k=\Theta(\sqrt m)$ strict drops in the required interval. This argument still uses a factor exponential in $L$ to inspect the early programs at every stage. With constant average threshold loss its logarithmic clock budget is of order $kL$. Reaching order $m/\log m$ by this route would require a more efficient way to test the actual histories. The unrestricted SAT bound remains open. [Finite checks of the mass charge](../audits/adaptive_profile_experiment.py)

## When the number of decreases is linear in the word length

The same construction with $L=\lfloor m/2\rfloor$ and $k=\lfloor\delta L\rfloor$ yields $\Omega(m)$ strict improvements of one word, still reaching a final program of at most $3b$ bits. Unconditionally one can use the interval $[2^{3m^2},2^{4m^2}]$. Set $S_j=2^{3m^2+j(3L+Ab)}$. At an earlier request considered by the global enumeration, $3(m')^2\le4m^2$, so $L'\le2L$ eventually. The same exhaustive simulation, mass charge, induction and final word selection all apply. No string starting with finite description length $O(m)$ can have more than $O(m)$ strict decreases thereafter, simply because the lengths are integers. A raw literal code with a self-delimiting length supplies that finite upper bound long before these deadlines.

Under linear SAT the interval $[2^{3mb},2^{4mb}]$ suffices with $S_j=2^{3mb+Ajb}$ and $\delta$ small enough also for this clock ratio. The global request computations can now *count* the timely names instead of simulating them individually. For each exact name length, ask if a sorted list of a given size exists with distinct names of this length, and universally select one row for a verified bounded transcript with the required output length and exact input consumption. Binary search gives the integer count. At a request through the target log deadline, $m'=O(m)$; the list has $2^{O(m)}\mathrm{poly}(m)$ bits, far below $S_{j-1}$. Each count costs $S_{j-1}\mathrm{poly}(m)$ after fixed-block elimination. All earlier global requests, lengths and threshold searches add only polynomial factors. To reconstruct a pool, use the [fixed-block history count](successive-description-times.md) with previously determined thresholds. Compute their values successively, and perform rank selection by prefix counts. This avoids making a separate costly query per candidate word. The stage ratio $2^{Ab}$ pays all these costs with $A$ large. The weight charge and upper bound $d_j\le c+4$ are identical. Thus linear SAT would imply a linear number of decreases within logarithmic clock growth $O(m\log m)$, whereas the unconditional construction for this number spends $O(m^2)$. Neither assertion is an exclusion of linear SAT. [Lean check of the rank telescope](../lean/SuccessiveDescriptions.lean)
