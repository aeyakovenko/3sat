# Certifying even one parity of a sparse priority computation

There is a fixed deterministic priority program with outputs $z_1,z_2,\ldots\in\{0,1\}$, computable through stage $J$ in $O(2^J)$ native RAM steps, for which the following holds. Write $U_J=4+\lfloor\log_2(1+\lfloor\log_2(J+16)\rfloor)\rfloor$ and let $x_J$ be the last $\lfloor\log_2 J\rfloor$ outputs through stage $J$, for $J\ge2$.

* The actual total number of ones through $J$ is $o(U_J)$.
* Suppose ordinary explicit SAT takes deterministic $O(n^k)$ time on the unrestricted logarithmic-word RAM, for fixed $k\in\{1,2,3\}$. Fix any nondeterministic verifier soundly certifying claims $x_J\notin F$ for nonempty affine flats $F$ over $\mathbb F_2$. There are constants $B$ and $\epsilon>0$ depending on the verifier and SAT solver such that every accepted claim with a run of at most $2^{\lfloor J/k\rfloor}/(J+1)^B$ steps has $\operatorname{codim}(F)\ge\epsilon U_J$ at every sufficiently large $J$. A verifier may choose the flat and the scales. It need only work when it has a successful proof.
* For every fixed rational $\delta>0$ there exists a fixed, polynomial-in-$J$ deterministic verifier of a true exclusion of codimension at most $\lceil\delta U_J\rceil+1$ at every sufficiently large $J$. The initial threshold can depend on $\delta$ non-effectively. A test requiring no such threshold uses $\lfloor U_J/2\rfloor+1$ specified positions whenever they fit. Both tests exclude the flat requiring ones in all the specified positions.

A rank-one exclusion certifies the value of a single parity. A higher-rank exclusion merely certifies that at least one of several affine equations fails. It need not identify which one. A sound bounded nondeterministic proof of **any one parity of the true window**, even its total-count parity, on infinitely many stages would thus exclude the chosen SAT clock. The conclusion uses a modified program which may reserve future output bits. Its actual signed 3-CNFs are obtained by applying the [packed compiler](packed-band-transfer.md) to this specific machine. They need not have the signs of the earlier [priority program](priority-pinned-sat.md).

## Setting the bits of a proposed flat

Keep the true output prefix as part of the computation. A proposed nonempty flat is given by independent equations $Ax=b$. Perform row operations on the augmented rows, using the rightmost nonzero coefficient as pivot. This produces distinct rightmost pivots $p_1<\cdots<p_r$ and equivalent equations. Each row mentions only $p_s$ and earlier positions. For any chosen earlier bits, at the pivot stage set $z_{p_s}$ to the right-hand side XOR the earlier contributions. An uninterrupted schedule satisfies the whole flat. It can set every nonpivot bit in this interval to zero and uses at most $r$ ones. In particular an excluded flat of codimension one only needs the ability to set one bit. The quasilinear sparse-CNF compilation is needed in the SAT transfer, whereas Gaussian elimination here operates only on polynomially many stage-index bits.

## A finite priority construction with interruptions

Enumerate deterministic native predictor programs with indices $e=0,1,\ldots$. They receive their stage $i$, their rank $e$ as a public integer and the publicly specified zero input. They have no private access to the stored prefix, and may announce a flat. Rank $e$ can start a reservation at $i$ only if the codimension lies between one and
$$Q_e(i)=\left\lfloor U_i/4^{e+1}\right\rfloor.$$
The report specifies a horizon $i\le J\le2i$ and binary affine rows on coordinates $1,\ldots,J$. Require that the smallest rightmost pivot after elimination is precisely $i$. Cap the accepted record at $O((i+1)^2)$ bits, for example by requiring at most $J$ rows of $J+1$ bits with a fixed header. Independent basis rows always fit. Admit only ranks with a positive quota, and retire a rank permanently once it completes a reservation.

At a stage with no pending reservation, test all active unretired ranks in priority order. When a reservation is pending, test only active unretired ranks of strictly higher priority. At the first qualifying report, discard any pending reservation and start the new one immediately. Use its pivot rule at that very stage. A current reservation supplies the prescribed bit at every pivot and zero elsewhere, completing at its last pivot; if no reservation is pending and none starts, output zero. A reservation ends by its horizon. These rules define every bit from earlier stages and bounded computations.

Allocate at most $\lfloor2^i/2^{e+1}\rfloor$ universal instructions to the stage-$i$ trial of rank $e$. Use the fixed native interpreter and word widths of the [ordinary priority construction](priority-pinned-sat.md). The returned word can be a pointer to a bounded-size result in the guest's bank. Decode only the validated polynomial number of fields with checked indices; malformed, incomplete or overflowing records do not qualify. The host can inspect a polynomial number of guest words using the same fixed-depth sparse banks. Polynomial parsing and row reduction per trial, and retaining a polynomial-size schedule until its last pivot, cost $\operatorname{poly}(i)$ overall per stage. Pivots in a pending schedule from stage $h$ have horizon at most $2h$ and $h\le i$. Looking up the actual earlier bits to implement a pivot takes polynomial time because the host recorded them as they were computed. A predictor itself must compute any past information it wishes to inspect. The simulator resets each trial's memory and charges its normal fixed-program overhead. Thus one stage costs $O(2^i)$, and all stages through $J$ cost $O(2^J)$. In particular, a self-referential predictor which tries to simulate the very same computation is cut off at its native deadline.

Let $S_e$ be the total number of starts by a rank. All but possibly its last start are interrupted by a new start at a strictly smaller rank. Distinct interrupted starts charge distinct interruptions. Thus $S_e\le1+\sum_{f<e}S_f\le2^e$ by induction, also for a rank whose last reservation never completes because it too is interrupted. Up to any stage $J$ the ones contributed by each start of rank $e$ are at most $Q_e(J)$. Consequently the total is at most $U_J\sum_{e\ge0}2^e/4^{e+1}=U_J/2$. For any fixed $E$, the finitely many starts by ranks $e<E$ contribute a finite absolute total independent of $J$, since every horizon is finite. The remaining total is at most $U_J/2^{E+1}$. As $U_J\to\infty$, this proves the little-o claim.

Suppose a predictor at fixed rank $e$ announces only flats genuinely excluding the actual sequence whenever its report qualifies. It never completes a reservation, since completion would put that prefix in the reported flat. All higher starts have finite horizons and occur finitely often. After they have stopped, any qualifying report by $e$ within its deadline would start a reservation, interrupting any lower rank, and complete it. A reservation by $e$ left over from an earlier stage also ends in finite time. This proves the native obstruction. In particular a timely sound one-bit guess is ruled out by reporting the opposite singleton at pivot $i$. Both colors occur infinitely often by the constant-guess test. Thus each fixed sound one-color tester still costs $\Omega(2^i)$ on every sufficiently late success, and the locally indexed pair of explicit pinned formulas has the native computational hardness asserted by the packed construction.

This construction also makes the **cumulative parity** $c_i=z_1\oplus\cdots\oplus z_i$ separately hard at the full native clock. A sound guess of $c_i$ announces the opposite parity flat on $1,\ldots,i$, with just one pivot at $i$. The additional work to produce its row is polynomial. Thus the new $c_i$ bits change only $o(\log\log i)$ times through $i$, while every fixed sound detector of either cumulative parity takes $\Omega(2^i)$ on each sufficiently late success. The same argument applies to any polynomial-time family of affine readouts on the prefix whose current-bit coefficient is one. The native obstruction concerns the newly constructed sequence; it does not assume the cumulative parity of the older sequence has that property.

## An effective error bound for approximate bits

The sparsity rate for the actual bits is ineffective, but one can predict them with an **effective** sublinear error allowance at a subnative clock. Fix a nondecreasing integer delay $d(j)\le j$. Replay the actual scheduler through $j-d(j)$, retaining its output prefix and any pending reservation. For the final $d(j)$ stages, continue that reservation if present, suppressing all **new** starts. A pending row is evaluated against the predicted prefix. If there is no actual new start during this interval, the forecast is exact by induction, even when the interval begins inside a long reservation. Thus through stage $J$ the total number of errors is at most $d(J)$ times the number of actual starts up to $J$.

Every rank that could start by $J$ satisfies $4^{e+1}\le U_J$. The earlier interruption count gives at most $\sum_e 2^e\le\sqrt{U_J}$ starts over these ranks. Hence the cumulative number of incorrect predictions is at most $d(J)\sqrt{U_J}$. Taking $d(j)=\max(1,\lfloor U_j^{1/4}\rfloor)$ (with early clamping) gives an explicit $O(U_J^{3/4})$ mistake bound and forecast time $O(2^{j-d(j)}+\operatorname{poly}(j))$. Earlier replay includes its true prefix, so continuing a polynomial-size reservation adds only polynomial overhead. This establishes a computable rate of approximation to the actual output at a clock saving by an unbounded factor. It supplies no computable rate for the number of ones in the predictions themselves.

For example, at every late endpoint $J$ compute the forecasts throughout its final $L=\lfloor\log_2 J\rfloor$ positions. The true window is in the Hamming ball of radius $\lceil d(J)\sqrt{U_J}\rceil$ around the forecast window. The claimed ball is genuinely certified by the preceding counting argument. Generating its center costs $O(2^{J-d(J-L+1)}+\operatorname{poly}(J))$ by geometric summation. One may exclude the flat demanding the opposite forecast at $\lceil d(J)\sqrt{U_J}\rceil+1=o(U_J)$ positions. The resulting constructive certificate spends much more than $2^{J/k}/(J+1)^B$ in the target clock ranges. Replaying one old coordinate of the window is itself an inexpensive source of a single equation. The extra conclusion here is agreement with a single computed center simultaneously on all but the stated number of positions.

## Moving a certified claim back to its first pivot

Give the verifier $J$ and a public description of a nonempty affine flat in independent basis form on its window, together with its nondeterministic guesses. A reported disjunction can be converted to this form by reducing the equations for **all** of its disjuncts to fail. They must be jointly consistent; a tautological disjunction gives the empty flat and is excluded from the theorem. Repeated dependent rows can be eliminated when a polynomial-size description is supplied. The smallest rightmost pivot can be computed deterministically by exact Gaussian elimination in polynomial time. One may always expand the rows with zeros to use the full coordinates $1,\ldots,J$.

At stage $i$ a deterministic predictor can find a certified exclusion whose earliest pivot is $i$ under the SAT hypothesis. It tries $i\le J\le i+2\lceil\log_2(i+2)\rceil$ for which $i$ belongs to that window. For large $i$ these are all possible endpoints and are at most $2i$. For each endpoint and candidate rank up to $U_i$, ask about the existence of independent basis rows and an accepting computation of the verifier with that rank, the right pivot and the stated clock. The explicitly encoded bounded-run 3-CNF has length at most $(R_J+\operatorname{poly}(J))J^{O(1)}$ at $R_J=\lfloor2^{\lfloor J/k\rfloor}/(J+1)^B\rfloor$. Polylogarithmic bit overhead also covers making and accessing the physical formula and adapting logarithmic word widths. The nondeterministic computation checks every public qualification before accepting. A deterministic $O(n^k)$ SAT solver decides the query. Take the least achievable rank over all endpoints and find an actual public row list by binary prefix queries. This recovers only polynomially many output bits; it does not extract the accepting computation. If no rank qualifies, the predictor stays silent.

The search makes polynomially many calls in $i$. All candidate budgets $R_J^k$ are $O(2^i(i+2)^{O(1)-kB})$ since these windows have logarithmic length. Construction and simulations therefore cost $o(2^i)$ for a sufficiently large fixed $B$. The polynomial degree of the auxiliary work may be chosen independently of $B$: computing the constant power $(J+1)^B$ uses $O_B(1)$ arithmetic operations on $O_B(\log J)$-bit integers, and the fixed bounded-run compiler incurs only the usual fixed polylogarithmic overhead. Searches at future endpoints use public computations from $J$ and the guessed rows. They do not query any future true bits. This eliminates the apparent cycle.

This predictor has some fixed rank $e$. Whenever any certified exclusion available to it has rank at most $Q_e(i)$, its minimum-rank report also meets the quota. It is sound on every returned record, by soundness of the verifier and correctness of the SAT answers. The native obstruction precludes such a late start. Since $U_i/U_J\to1$ uniformly over these windows, this gives the claimed positive constant $\epsilon$, for instance any fixed $\epsilon<4^{-e-1}/2$ at sufficiently large scales. An unconditional deterministic analogue holds when basis records can be located in aggregate $o(2^i)$ time at their first pivot. In particular a fixed polynomial-size, polynomial-time list of candidate masks with a polynomial-time sound test or a polynomial-time procedure producing a sound exclusion needs no SAT assumption. Trying all its masks, ranks and endpoints and retaining the smallest valid rank implements that predictor directly.

The restriction can be rephrased without linear algebra. A sound verifier might instead certify a numerical upper bound $b$ on the **actual** number of ones in the window. When $b+1$ fits, choose any $b+1$ window positions and exclude the flat that they are all one. Thus a single verifier providing such bounds $b=o(U_J)$ within the specified clock on infinitely many stages suffices for separation at $k$. The mathematical estimate on the true cumulative count supplies exactly that asymptotic slack. Its proof chooses a cutoff beyond the last start of each finite initial segment of ranks. It gives no uniform, timely way to validate numerical cutoffs at growing precision. There is an unconditional frequency consequence: for every polynomial-time numerical proposal $g(J)=o(U_J)$ with nonnegative integer values and every infinite polynomial-time recognizable set of endpoints, the actual window count exceeds $g(J)$ at infinitely many of those endpoints. Otherwise hardwire the finitely many exceptions and produce the corresponding all-ones exclusion on that set, using the deterministic predictor. Thus even passing to a publicly selectable infinite subsequence fails to make the asymptotic sparsity effectively recognizable at this precision. The explicit upper exclusions with fixed $\delta$ in the opening statement each hardwire one true cutoff. On the other hand the input-independent cap $U_J/2$ holds at every stage.

In fact the convergence of the cumulative count divided by $U_J$ to zero has no recursive modulus. The same holds for the window count, including on any fixed infinite polynomial-time recognizable set of endpoints. A modulus would be a total computable $h$ such that at every allowed endpoint $J\ge h(t)$ the ratio is at most $2^{-t}$. On input $J$, simulate the computations of $h(1),h(2),\ldots,h(J)$ in order for at most $J$ Turing steps in total. Keep the largest initial segment whose computations finished and whose binary threshold values are all at most $J$; stop upon an excessive value or timeout. With a standard simulation, binary output comparison and counters this costs $\operatorname{poly}(J)$. Its length $t(J)$ tends to infinity since every fixed initial segment terminates with finite thresholds. If no computation qualifies take $t(J)=0$. Output $g(J)=\lfloor U_J/2^{t(J)}\rfloor$, using zero as soon as $t(J)$ reaches the bit length of $U_J$. At $t=0$ the absolute cap applies. This would be a polynomial-time upper bound $g(J)=o(U_J)$ on the chosen endpoints, contradicting the deterministic construction. This is a statement about convergence thresholds even without the SAT hypothesis.

## The information in a genuine modulus

For either ratio, on **every fixed infinite polynomial-time recognizable set of endpoints $S$**, every total modulus computes the halting problem $0'$, and $0'$ computes a modulus. Taking $S$ to be all endpoints gives the unrestricted convergence statement. The rank metadata above makes the indexing uniform. Given a machine $P$ with a fixed blank input, compile a predictor containing its description and the chosen decider for $S$ into the fixed effective length-ordered program enumeration; its index $e=e(P,S)$ is computable. The guest reads that same $e$ without knowing the history or receiving stage-dependent advice. Such effective self-indexing can alternatively be implemented by standard parameterized self-reference, but the explicit metadata suffices here. [Terwijn, formulation of Kleene's recursion theorem with parameters](https://link.springer.com/article/10.1007/s00153-020-00712-z)

Put $s=2(e+1)$. At stage $i$ this predictor simulates $P$ for at most $i$ ordinary Turing steps. If it sees no halt it announces nothing. After seeing a halt, scan $i\le J\le2i$ for an endpoint $J\in S$ for which
$$
 q'=\left\lfloor U_J/2^{s+1}\right\rfloor\ge1,\qquad i=J-q'+1,\qquad q'\le Q_e(i).
$$
Choose the least eligible $J$ and report the $q'$ coordinate equations demanding that the consecutive bits from $i$ through $J$ all equal one. They have smallest rightmost pivot $i$, with last pivot at the declared endpoint $J$. An unrepresentable early-stage value or record simply stays silent. At fixed $P,S$ joint cost for the step-limited Turing simulation, the scan and writing the rows is polynomial in $i$. Membership is needed only for at most $i+1$ candidate endpoints, with polynomial-size indices. Thus every sufficiently late eligible post-halt trial fits its native deadline. Upon completion this predictor makes a real burst by falsifying the announced exclusion.

Every sufficiently large $J\in S$ supplies a candidate start $i=J-q'+1$ tending to infinity along $S$. Indeed, for $J\ge256$ one has $U_J\le\lfloor\log_2 J\rfloor$: with $m=\lfloor\log_2 J\rfloor\ge8$, $U_J\le4+\lfloor\log_2(m+2)\rfloor\le m$. Thus $i\ge J/2$ eventually. For $J\le2i$, $U_J\le U_{2i}\le U_i+1\le2U_i$, which gives $q'\le\lfloor U_i/2^s\rfloor=Q_e(i)$. Choosing the least eligible $J$ when there are several still gives completion at an endpoint in $S$. Let $G(e)$ be the first integer at least $256$ with $U_{G(e)}\ge2^{s+2}$, computable by unbounded search. At any completed reservation starting at $i\ge G(e)$ the floor satisfies $q'\ge U_J/2^{s+2}$. All $q'$ ones lie in the final $\lfloor\log_2 J\rfloor$ positions, making both the cumulative and the window ratios at least $2^{-s-2}$ at this very endpoint of $S$.

Given a purported modulus $h$ valid on $S$ for either ratio, simulate $P$ for $H=\max(G(e),h(s+3))$ steps. If $P$ were to halt after $H$, the predictor could not already have announced, since it inspects at most $i$ steps of $P$ on stage $i$. From then on arbitrarily late eligible starts exist while it remains unretired, by infinitude of $S$. Higher-priority starts and the horizons of any existing higher-priority reservations are finite in number. Consequently either it has already completed a post-$H$ reservation at an endpoint of $S$, or it eventually does so after all higher interference has ended. The ratio at that $J>H$ exceeds the stipulated $2^{-s-3}$, a contradiction. The finite simulation through $H$ decides halting without using an effective time for the last higher-priority injury. Conversely, given $t,n$, the existence of a later $J\ge n$ **in $S$** at which the computable ratio exceeds $2^{-t}$ is computably enumerable. A halting oracle answers this question. Searching for an $n$ with negative answer terminates by convergence and constructs a $0'$-computable modulus for $S$.

## The endpoint cost

For any fixed logarithmic coefficient in the window length the same future-search cost is absorbed into $B$. More generally one may use a public polynomial-time left endpoint $\ell(J)$ with $J/2\le\ell(J)\le J$ and diverging length, with time budget $2^{\lfloor\ell(J)/k\rfloor}/(J+1)^B$. Search $i\le J\le2i$; $i\ge\ell(J)$ pays for all candidates that include $i$. The existence of a cheap rank-one exclusion does change on much older supports. For any given left endpoint one can determine its bit by true replay through $\ell(J)$ at cost $O(2^{\ell(J)}+\operatorname{poly}(J))$, and exclude its wrong value. In particular this fits the larger budget $2^{\lfloor J/k\rfloor}/(J+1)^B$ whenever $\ell(J)\le J/k-(B+2)\log_2(J+2)$ eventually. For the linear clock, this makes the logarithmic distance scale necessary for a blanket no-parity assertion at a fixed logarithmic budget loss.

Finite extensions and resource-bounded genericity are classical. The construction here allocates a sparse budget across interrupted rightmost-pivot constraints, then uses the earliest pivot to price a bounded SAT search. Priority for this quantitative variant is unverified. The outstanding step for unrestricted SAT is a timely certificate reaching a codimension $o(U_J)$ at infinitely many actual windows, or a different direct contradiction.
