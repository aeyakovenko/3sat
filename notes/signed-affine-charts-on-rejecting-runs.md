# A time tradeoff for Boolean combinations of wordwise affine invariants

Fix a deterministic packed logarithmic-word RAM that signals UNSAT on all unsatisfiable explicit formulas and never signals it on a satisfiable input. Its workspace is unrestricted. Let $T(F)$ be its first signal time on an unsatisfiable formula $F$ of encoded bit length $N$. A certificate may give cuts along that run and use the same small circuit to describe a set of possible states at each cut. The set can be any Boolean combination of explicitly declared assertions, each of which requires a succinctly indexed collection of affine equations on individual memory words. Both an assertion and its negation are available. At every cut one can, for example, permit states in a union of affine products, each with exponentially many equations, or states where at least one addressed comparison fails.

Let $C(F)$ minimize the **bit length of the entire chart plus its largest time gap plus one**, with the precise syntax below. For every fixed $c<(1+\sqrt5)/2$,
$$
       \max_{|F|=N,\;F\ {\rm UNSAT}}(1+T(F))C(F)
           \quad\hbox{is outside }O(N^c).
$$
Equivalently, no such upper bound holds on all sufficiently long unsatisfiable inputs. More generally suppose there is a separate sound nondeterministic UNSAT recognizer with a timely accepting branch of length $O(N^d\operatorname{polylog} N)$ on every negative, $d\ge1$. A product bound $O(N^c)$ is impossible if $d(c-1)<1$. The golden-ratio case uses the program itself as that reference. Polynomial slack suffices throughout. The antecedent gives an $O(N^c)$ time bound for the signal on **every** negative since $C\ge1$.

Williams proved a golden-ratio bound for time times peak space. Here a row can describe a collection of memories logically, use different polarities at a cut, and present its equations through a shared time-indexed circuit. The old and new resources can differ even on the same trace. Inductive invariants and the underlying time-space lower bound are established techniques. Priority for the specific product bound is unverified. ## Chart syntax and soundness

A chart is finite bit data giving a terminal time, a number $J$ of gaps, and a circuit computing the time at cut $i$ from its binary index. Require cut zero at time zero, the last cut at the first actual signaling time for the cost minimum, and strictly increasing times with gaps at most the claimed $\ell$. The verifier need only prove a real signal by the chosen final time. Open-ended times do not enter the proof since the advertised costs and clocks bound all timestamps polynomially in the application. Immediate signals can be checked directly. The schedule can have exponentially more cuts than its description has bits.

A common row circuit receives a boundary index $i$, a controller $\rho$ including all registers, a catalog number $1\le j\le b$, and a label $y$ whose width is declared for that catalog. Charge the $b$ truth bits plus the sum of the declared label widths in the description length. This allows the number of catalogs to grow and pays for holding one label per catalog at one cut. One may equivalently list separate templates and charge all their declared inputs. It returns an address $a$, a word-length mask $\lambda$, and a bit $e$. For this $i,\rho,j$, the atom means that **every** label satisfies
$$
                   \langle\lambda,M[a]\rangle=e \quad\text{over }\mathbb F_2.
$$
Zero masks permit constants. A second circuit combines the $b$ truth values with $i,\rho$ to decide membership. Circuits are ordinary explicit Boolean circuits of charged encoding length, including their declared inputs and outputs. Formula-dependent constants may be hardwired. The row circuits have **no uncharged access to the source formula**. This ensures that one consistency check below has only the chart and a local transcript as input. The original solver retains its ordinary random input access throughout. One may additionally let all row evaluations use a fixed chart list of source words if their addresses and values are charged and verified before the local tests.

The endpoint sets are fixed meanings: the singleton initial state and the set of signal controllers. The initial zero memory is itself a single such atom, using an address and bit position in the label to test a bit for zero. Exact arbitrary configurations are available by a circuit predicting each bit from the cut index and address. Internal sets must be forward inductive across the actual deterministic block map on **all** states they contain. Their truth on the initial state and consecutive inclusions give the genuine signal. There is always a one-block chart of gap $T$ on a negative input. On configurations outside the native controller convention use a fixed total extension. Time, addresses and word lengths for the argument below use $O(\log H)$ bits, though the native alphabet and physical work memory can vary across the reductions.

## Why a failure of induction uses two quantifiers

For a proposed gap, guess its entrance controller and a consistent local transcript of the block. Guess initial word values for the finitely many addresses touched and maintain a private overlay for writes. Freeze the initial values on these addresses and the outgoing values after the final writes. Source input probes in this step use the actual locally generated formula. The transcript has $O((1+\ell)\operatorname{polylog}H)$ bits. A consistent completion of the frozen entrance values yields exactly this native trace, since every read, computed address and branch replays deterministically.

Guess the $b$ truth bits of both endpoint rows. Require the entrance combination true and the outgoing combination false. For each proposed **false** atom guess one label and impose the complementary equality on its word. Over $\mathbb F_2$ the failure of an equation means equality with the opposite right-hand side. For each proposed **true** atom impose every one of its indexed equations. Include the ordinary frozen entrance words as equations pinning each bit. On a written word, an outgoing equation can be evaluated against its frozen final value and reduced to a constant. A constant failure is represented by $0=1$ at a fixed address. All remaining exit equations refer to untouched incoming values or to words whose frozen entrance value was only read. The same method treats the known endpoint rows.

It remains to determine whether **all** these equations have a simultaneous solution in the full starting memory. Equations from the old row, new row and trace may be united before checking. Different addresses are independent. At a fixed address take each row as a vector $(\lambda,e)$ in $\mathbb F_2^{w+1}$, where $w$ is the native word width. The system is inconsistent exactly when $(0,1)$ is in their span. To see the converse, in the absence of $(0,1)$ every linear combination of the masks has a well-defined corresponding right-hand side. Extend this linear functional on their span to all $w$ coordinates to obtain a satisfying word. A basis of the augmented rows has at most $w+1$ members. Thus global inconsistency has a witness at one address using at most $w+1$ named rows whose XOR is $(0,1)$. Each identifier either names an old or new label and atom, a false-atom witness, or one frozen bit.

Inconsistency on a fixed local transcript is an ordinary bounded nondeterministic check taking $\widetilde O(S)$ steps on $\widetilde O(S)$ data when $C\le S$ and $S$ is a positive power of $H$. It selects the claimed rows and checks their address and XOR by evaluating the circuits. Even with many false atoms, their imposed complementary rows can be generated on demand from the guessed label array. They need no separate comparison with the real input. Looking up written words and handling constant equations can be done by scanning the frozen transcript once per selected row. Only $O(\log H)$ rows are selected. Parsing the entire chart, checking its syntax and guessing all the false-atom labels all fit this scale. Crucially the test now uses only the supplied chart and frozen transcript. It never makes a source ROM query. Existence of a bad gap is precisely existence of a valid transcript and polarity choices **with no inconsistency witness**. The nondeterministic UNSAT reference of exponent $d$ verifies that last condition using a bounded-computation SAT formula of $\widetilde O(S)$ bits, constructed in the same time up to logarithms. Thus a nondeterministic machine for a *defect* uses $\widetilde O(S^d)$ steps on $\widetilde O(m+S)$ public data, where $m$ counts original source input words. Malformed cut endpoints or a bad adjacent timestamp are alternative directly checkable defects. Syntactic errors may instead reject the guessed chart immediately. The mismatch between the two input lengths here matters to the iteration.

## Pinning every negative source reduction

Let a fixed nondeterministic machine run for $R$ steps on $m$ public words, and put $H=\max(R,m,2)$. Take its locally accessible bounded-acceptance 3-CNF $G$ of size $H\operatorname{polylog}H$. Form a new fixed-layout 3-CNF for
$$
                     G\ \lor\ (p_1\lor\cdots\lor p_H)
$$
with an extra negative unit pin on every $p_i$. One explicit implementation uses a switch $z$. Guard the clauses of $G$ with $z$ so they apply when $z=0$; a four-literal guarded clause can be split into two ternary clauses with a private fresh variable. When $z=1$ require the displayed disjunction using a linear OR chain. Thus with all pins negative the modified formula has the same SAT bit as $G$. Reversing any pin makes it satisfiable for every $G$. Unit and binary clauses can be expanded into exact width three with disjoint constant-size gadgets. In that version reverse all occurrences of the one pinned literal in its gadget. Each pin has a distinct constant-size edit region; each physical word intersects at most constantly many such regions in a fixed-width clause layout.

If the original computation has no accepting path, the signal time on this **all-zero pinned input** is $\Omega(H)$ word probes. Otherwise the deterministic run has skipped some pin region and would also signal on its satisfiable neighbor. The new formula has length $N=\widetilde O(H)$; its words can be generated at a chosen address with $\operatorname{polylog}H$ work and random access to the $m$ source words. The guards are constant-size replacements, and the switch, OR chain and pins have regular offsets. The local generator never needs a writable copy of the whole formula. Consequently a hypothetical product bound supplies an honest chart of cost
$$
                    S=\widetilde O(H^{c-1})
$$
on **each nonaccepting source input**, even when the input is used inside a recursive simulation.

## Bootstrapping the complementary simulation

Assume $c>1$. Smaller exponents are covered by increasing $c$ with strict slack. Suppose nonacceptance of any fixed $R$-step nondeterministic computation on $m$ public words has a bounded nondeterministic recognizer with time $\widetilde O(R^e+m^d)$, initially $e=d$. For initialization materialize the ordinary bounded formula at cost $\widetilde O(H)$ and use the reference. For an improvement guess a chart of the stated cost on the pinned virtual formula. Check that the deterministic solver signals by a cap $\widetilde O(H^c)$ using the final timestamp and the inductive proof. All arithmetic indices are capped before simulation. A satisfiable formula has no such chart. A negative formula has a timely honest one by the product bound.

Apply the prior nonacceptance procedure to the *defect machine* on the guessed chart and original public input. It has work $\widetilde O(S^d)$ and public data $\widetilde O(m+S)$, with no cost proportional to $H$ for its source formula's input probes. Therefore the complete nondeterministic verification costs
$$
 \widetilde O\bigl(S^{de} + (m+S)^d\bigr)
       =\widetilde O\bigl(R^{(c-1)de}+m^d\bigr)
$$
whenever $1\le e\le d$ and $(c-1)d<1$. The term $S^d$ is absorbed since $e\ge1$, and the new work exponent is below $d$. The guess and its syntax scan are absorbed as well. If $H$ is dominated by $m$, the unchanged $m^d$ term handles the substitution. The reference used *inside* each defect check stays at exponent $d$; it is the *outer* nonacceptance procedure whose work exponent improves. The explicit frozen transcript in the inner test prevents the original $m$ from being raised to the power $de$.

Every finite iteration while $e\ge1$ multiplies it by $\gamma=(c-1)d$. At $0<\gamma<1$ this crosses below one after finitely many iterations. To use fixed rational clocks, increase exponents slightly before beginning, retaining $\gamma<1$; each fixed iteration absorbs its fixed polylogarithms or uses a little of this slack. The schedule size cap, trace cap and source halt convention apply to every guessed branch, including malformed ones. Binary metadata carries the source scales. On the ultimate diagonal input all uncapped and padded polynomial scales of the finitely many subcalls have comparable log word widths up to constants.

Now take the bounded nondeterministic universal acceptance source with $R=m^D$ for fixed $D>d$ and padded input naming the resulting nondeterministic nonacceptance recognizer itself. All its branches run in $o(R)$ since the work exponent is below one. On that fixed description, the interpreter accepts exactly when the recognizer accepts, while the recognizer accepts precisely when the interpreter has no accepting computation. The host word constant may be chosen once with headroom for the polynomial addresses of these finitely nested SAT calls and tagged local work banks. The unbounded choice of words in the source interpreter appears only as bounded-width symbolic data in virtual SAT records. It does not become an address into a physical chart table. This is the same-width bounded complementary diagonal and local encoding used in the earlier cumulative proof. [Native width and reduction](packed-band-transfer.md) · [Separate public-input term and diagonal details](cumulative-sat-memory.md) · [Fortnow, Lipton, van Melkebeek and Viglas](https://lance.fortnow.com/papers/files/tst.pdf)

**Chart size alone at the three target clocks.** Suppose the signal time on negative inputs has some fixed polynomial bound, and keep the separate UNSAT reference of exponent $d$. A uniform bound $C(F)=O(N^\beta)$ on all negatives with $\beta d<1$ would give exactly the same contradiction: take $S=\widetilde O(H^\beta)$ directly, use the polynomial bound to cap the timestamps, and multiply $e$ by $\beta d$ at each iteration while $e\ge1$. One can increase $\beta$ slightly to a positive rational with $\beta d<1$. It suffices to assume the chart bound on the all-zero pinned formulas above for the bounded-computation sources used in the simulation. More precisely, even allowing a different big-O constant for each fixed source, the bound cannot hold for the pinned reductions of **every** such source: only finitely many fixed machines occur upon expanding the successful exponent iteration at the complementary diagonal. This does not assert hardness on a preselected source. In particular an $O(N^k)$ SAT solver, used also as its own reference, must have $C$ outside $O(N^{1/k-\epsilon})$ on negatives for every $0<\epsilon<1/k$, for each $k\in\{1,2,3\}$. The exponents concern minimum chart cost on actual rejecting runs. Each conclusion remains compatible with the stipulated running time.

## Limits of this route

The bound on the size of a contradictory subsystem relies on every row mentioning only one word. With two named bits per row, a cycle of $m$ parity equations with odd right-hand-side sum is inconsistent and every proper subfamily is consistent. There is also a complexity boundary for the succinct equality-only subcase. Given a circuit for a function $f$ on $k$-bit addresses with a fixed point $t$, impose $x_u=x_{f(u)}$ at every address and pin $x_s=0,x_t=1$. The system is inconsistent precisely when the forward orbit of $s$ reaches $t$. Indeed equality identifies weak components of the functional graph. Every vertex weakly connected to the fixed point eventually reaches it, as can be seen by propagating that property along an undirected path in either direction. A circuit for the one-step configurations of a deterministic polynomial-space decider, with a designated accepting sink, proves PSPACE-hardness of this succinct consistency test (for consistency use closure of PSPACE under complement). The equality-only problem is in PSPACE by checking reachability between oppositely pinned vertices of its exponentially large succinct undirected graph using polynomial space. These complexity statements measure the row-generator encoding, with a possibly exponential address space. They do not establish a fine-grained running time lower bound on explicit SAT. [Succinct functional-graph reachability in the primary literature](https://eccc.weizmann.ac.il/report/2024/023/download/)

A single existentially failing affine row is one permitted polarity. Used **alone**, that format can require a long gap on a linear-time program whose verdict is constant on actual inputs. Have the program check that each of $m$ initially zero words is zero, failing on the first nonzero. For the first $m-O(1)$ scans two unreached words can each change the eventual answer on their own while the controller stays fixed. Any true single-label witness examines at most one word and therefore admits a modified memory giving the opposite outcome. No inductive internal cut in that interval can contain the real state with this one polarity alone. The full format can require all remaining words zero with one universal catalog and use cuts at consecutive instructions. Thus the restriction to a single polarity would artificially inflate the new resource. The general tradeoff above supplies no upper bound on $C(F)$ in terms of time that would rule out linear, quadratic or cubic unrestricted SAT.
