# Can five stored instructions decide ordinary SAT at any speed?

**No, in the journal's standard-width ISA.** The manuscript now excludes every program of at most five stored instructions with either read-only or writable input, even with unrestricted running time. The earlier deadline argument at `a1c4285` had a clock assumption. Its five-slot case split was never an end-to-end Lean theorem. The new proof uses clock-free arguments for all operand allocations. [Final theorem with exact scope](five-instructions-cannot-decide-dimacs-sat.md) · [Earlier time bound](equality-communication-for-five-slot-sat.md)

Five means five **stored** instructions. The program is fixed across lengths and may loop. A LOAD, numerical instruction, STORE and branch are separate instructions. The two fixed verdicts are terminals. A finite sign-selector experiment does have an actual five-instruction solver, with a different input convention and just sixteen possible inputs. [Finite program and exact minimum](static-program-size-on-two-sign-planes.md)

## What can now be excluded without choosing any clock

* **Unshifted compulsory scan.** Let $p$ run through a fixed-stride orbit, read $x=M[p]$, then write $M[x]\gets p$. Suppose the only changing registers are the cursor and loaded word, as in this five-slot allocation. Every update stays on an existing undirected memory edge. With $h$ different initial memory values, at most $h$ edges can disappear. Two consecutive complete passes without a disappearance yield the same machine state at their respective endpoints. Consequently a halting run makes $O(h+1)$ passes. On suitable proper DIMACS formulas this would give a deterministic equality protocol using $O(\log n)$ bits for $\Theta(n/\log^2 n)$ private bits. This excludes the allocation even with no deadline. The state repetition and communication argument are manuscript proofs. [Proof](unshifted-crossed-scan-without-a-clock.md) · [Lean on the actual memory update](../lean/UnshiftedFunctionalScan.lean) · [Finite exhaustive check](../audits/unshifted_crossed_scan_audit.py)
* **Read-only RAM with one numerical site.** With any fixed number of loads and branches and a single numerical instruction, no program decides SAT at arbitrary speed. The case that can enumerate all input addresses is a cursor incremented by a fixed odd integer. A LOAD into that cursor resets every register into a small set of values on the equality inputs. A repeated post-reset state or a repeated complete-lap state would run forever. This bounds the number of handoffs in the equality protocol. [Opcode and control proof](read-only-ram-with-one-arithmetic-site.md)
* **Read-only fixed scan with a second numerical site for one accumulator.** Across each party's part of a scan, the allowed single opcode induces a map on the incoming accumulator with an $O(w^2)$-bit description. For example, compositions of adds and subtractions remain affine, and shifting a data word by the accumulator has only $O(w)$ possible results after the first operation. Exchanging the maps lets each party test exits on every lap up to state repetition. Placing the equality pins in the order of first visit also covers an arbitrary input-independent unary cursor orbit once the prologue is fixed. The communication again falls short of equality. [Proof and operand conventions](one-accumulator-scan-without-a-clock.md)

* **Shifted compulsory scan.** Reading $x=M[p]$ on a public stride and writing the next cursor to $M[x]$ loses the original literal signs on a family of proper 3-CNFs. For any fixed odd signed stride and arbitrary starting cursor, all undisturbed sites lose their signs before their second regular read. This rules out every fixed-register controller on that schedule at any speed, even allowing a bounded number of extra accesses. With an even stride a fixed residue class already misses sensitive original words on the periodic DIMACS base. The shifted scan can nevertheless go through many different memory states on another input. [Proof for arbitrary odd strides and sparse extra probes](arbitrary-stride-private-sign-erasure.md) · [Ascending example](erasing-private-signs-in-a-shifted-scan.md) · [Long transient](shifted-crossed-scan-on-padded-dimacs.md)
* **Several adaptive writable schedules.** A union of prefixes of word-function orbits describes which original cells remain readable under two adaptive marking rules. A separate argument handles a constant odd marker placed at the current read address, including the reflected update $p'=x-p$. Reversing the old memory edge before a unary cursor update also fails on an even-word DIMACS family. [Orbit prefixes and splicing](adaptive-five-slot-prefixes-without-a-clock.md) · [Odd-marker walks](odd-self-marked-cursors-without-a-clock.md) · [Old-cursor reverse writes](unary-reverse-links-on-an-even-dimacs-base.md)
* **A single read-only LOAD and two mutable registers.** If the LOAD overwrites $x$ at the address in the distinct register $p$, four explicit eight-clause formulas defeat every such program, with arbitrary register operations, adaptive addresses and unlimited time. For fixed $p$ the old $x$ is dead when its replacement is read. Contracting public computations leaves a two-query graph; all 3,125 possibilities miss equality. For a general read-only controller, a larger table-index family forces many distinct live states at a single private probe. ## How the last cases close

For a third live register in a read-only loop, moving the private selector words among many admissible positions gives one placement with too few possible probe states. The remaining numerical opcodes preserve a common low-bit pattern, visit too few addresses, or give an input-independent order. On writable loops, a mandatory write to a fixed scratch cell destroys its previous contents before they can influence the next private read. When the STORE instead marks an address found in the raw word, the translated private probes can avoid the entire bounded set of marks. [Read-only case split](read-only-five-instructions-on-ordinary-sat.md) · [Writable case split](writable-five-slots-without-a-clock.md)

The theorem gives a lower bound on stored code size. Whether six slots can decide ordinary DIMACS and whether unrestricted SAT requires superlinear RAM time are both open in the journal.
