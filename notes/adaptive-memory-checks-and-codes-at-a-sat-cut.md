# Adaptive checks on a SAT run, and the exact capacity of a family of checks

Suppose a deterministic RAM decides ordinary DIMACS 3-SAT in $O(N\log^a N)$ time, with any amount of workspace. A checker sees the chronological events of a proposed run, including a proposed reply at every work load. It can use the real immutable input and discard the candidate when it finds an inconsistency. Call it *transparent* if every genuine execution passes, for every permitted advice string. The checker may change what it remembers after every event and may store functions of the data. Its private state has $O(k+\operatorname{polylog}N)$ fixed word slots, it gets up to $k$ words of read-only advice, and it uses $O(1)$ native steps per guest operation, including access to the virtual input at the root of the reduction. Its setup and the restoration of a selected checkpoint must fit $O(k+\operatorname{polylog}N)$ steps, apart from the public scale table allowed for decimal input. It has a fixed program, and bounded costs apply on forged histories too.

For $k=\lceil C N/\log^{4a+14}(N+2)\rceil$ with any fixed $C>0$, there are arbitrarily long **unsatisfiable** files on which every permitted advice string leaves an accepting candidate that passes the checker. The candidate follows the actual solver program, uses the real input and obeys the same upper clock. Only its work-load replies can be false. For fixed polynomial exponents the same assertion excludes joint time $N^{c+o(1)}$ and a successful checker budget $N^{e+o(1)}$ when $c^2(c+e)<c+1$, with the public clocks and slack of the underlying theorem. A checker with a sparse dictionary can also be used when its checkpoint admits the same slot and restoration costs.

Indeed, if every sufficiently long negative file had advice excluding every accepting candidate, then SAT would be equivalent to: for every advice string there exists a passing accepting execution. On a positive file choose the true execution for each advice. Normalize invalid advice to a transparent no-op. Once the advice is fixed, the remaining machine is nondeterministic: guess a reply for each native work read, follow the real CPU, and update the checker. Its mutable state consists solely of the CPU, the checker and the clock. Guess its checkpoint list, universally select an interval, and existentially run that interval by guessing its local replies. All four quantifier blocks, snapshot sizes and public inputs are those of the misread-address certificate proof. There is no dictionary of actual guest work values in this simulation. Diagonalizing the resulting complementary simulation proves the assertion. Finite exceptional lengths can be handled by fixed code. The satisfiable-file version uses the same-sign hierarchy argument from the same proof: for $k=O(N/\log^{6a+20} N)$ every allowed advice string on some satisfiable file still permits a false explicitly rejecting candidate. The true rejecting run survives every checker on unsatisfiable files. Transparency must hold even when advice chosen for one file is given to a different input. [Quantifier elimination, both encodings and references](memory-addresses-needed-to-certify-a-sat-verdict.md)

One example is a programmable observer that keeps a bounded set of current address/value facts. It may drop facts, record stores, and remember a load reply for comparison with a later load if no intervening write changed the word. It may reject when an observed reply contradicts a fact. A trusted update enforces these rules, and code in the advice may choose the retained facts after seeing each event. Every possible policy is transparent. A policy can successively check arbitrarily many distinct addresses with one slot when each store is followed immediately by its load. More generally the checker may use checksums when the actual computation supplies the required order. Classical memory checking permits randomized detection of an individual faulty interaction. Here a successful advice string must eliminate *all* accepting histories on the given negative input. [Blum et al., *Checking the Correctness of Memories*](https://www.cs.ubc.ca/~will/papers/memcheck.pdf)

## Two input blocks and an exact finite exhaustion

Take private inputs $x,y$ from a common finite set $X$, with SAT verdict $[x=y]$. For ordinary proper DIMACS put one pin per bit of $x$ in a left block and the corresponding pins for $y$ in a right block on the same data variables. Give two fresh public helpers fixed Boolean values with the seven proper three-variable clauses excluding all but one triple on three fresh helper variables. Add the two now-false helper literals to each unit. A private bit can be encoded in a fixed-width sign slot (space or minus) with public delimiters. The blocks have private-independent offsets and total encoded length $N=\Theta(m\log(m+2))$ for $x,y\in\{0,1\}^m$. Each equal pair has exactly one model, and each unequal pair is unsatisfiable. Align the block cut with a word boundary using public whitespace.

First take a strict input cut. A deterministic computation has at most $H$ possible CPU controllers at the cut, including all trusted buffered input, PC, registers, early halts and any accessible clock. For a time-limited candidate, also include the elapsed time at the cut in the controller class even if the guest cannot read it. This keeps the spliced trajectory within the original deadline. Proposed work-load replies are untrusted. There are $G$ passive deterministic checkers, counting each possible choice of advice as a different checker, each with at most $K$ possible boundary states. The checker state includes all its private information passed across the cut; a fixed checker index is public on both sides. The checkers cannot inject data into the guest. Each sees its own event prefix or suffix; any independent input access it makes obeys the same input cut. Local computation on either side may be arbitrary. Require all genuine accepting traces to pass all checks. Assume every false accepting candidate on an unequal pair is rejected by at least $d$ of the $G$ checks, for $1\le d\le G$. A stronger assumption is that $d$ checks on each unequal pair individually rule out every candidate.

Write $A_K(G,d)$ for the maximum number of length-$G$ words on $K$ letters with pairwise Hamming distance at least $d$. The exact abstract cut capacity, for **either** detection requirement above, is
$$
             H\,A_K(G,d).
$$
For the upper bound, group genuine equal-file traces by CPU controller. Assign to each such input its vector of $G$ checker states. Given distinct $x,y$ in one group, take the genuine prefix for $(x,x)$ followed by the genuine suffix for $(y,y)$ on the mixed input $(x,y)$. Supply the latter suffix's work replies regardless of the actual preceding stores. This is one concrete false accepting chronology. Every checker with equal states at the two cuts passes this very chronology. Its vector labels must consequently differ in at least $d$ coordinates. This proves the upper bound even if every rejecting checker depends on the complete proposed false chronology. The hybrid and the finite encoding argument are [formalized in Lean](../lean/GuardedDiagonalCodes.lean).

For sharpness with free local encoders, encode an input label by a freely transferable controller digit and a codeword from an optimal $K$-ary code. The left side stores the codeword in untrusted work memory, and each checker remembers its one coordinate. The right side tests the controller digit and compares all retrieved coordinates with the right label. A false accepting run must report the entire right codeword. At each differing coordinate its corresponding checker detects that discrepancy on every such run. This attains the stronger detection requirement too. The abstract optimum permits unrestricted local computation to encode the labels. A physical prefix may instead compute a checksum on its input and a physical suffix the same checksum on the sequence of work replies, using ordinary packed RAM instructions for the specific codes described below.

In particular, with $d=1$, the capacity is exactly $HK^G$. With $G=2^b$ advice choices, $K\le2^s$ possible $s$-bit states and $m$ binary data bits, this gives the tight abstract inequality $m\le\log_2 H+2^b s$. A native one-pass solver on the displayed layout writes the left vector to packed work words, then compares its retrieved vector with the right. A checker given one of $G$ chunk numbers retains just the corresponding $\lceil m/G\rceil$ bits, up to $O(\log N)$ bits for control, and verifies that chunk's work replies. On any mismatch one chunk excludes every false acceptance. On this layout the solver runs in $O(N)$ steps including parsing, with a complete SAT fallback on other valid layouts. For a genuinely one-pass fallback it can also write an input copy in a separate bank during validation. The candidate computations on the template perform validation and choose the fast path using only true input and registers.

## The algebraic successor and the limit on error detection

Deleting any $d-1$ code positions preserves injectivity, giving the Singleton bound $A_K(G,d)\le K^{G-d+1}$. For a field of $K$ elements and $G\le K$, represent a label by the coefficients of a polynomial of degree less than $G-d+1$ and use evaluations at $G$ distinct field points. Two different polynomials agree at most $G-d$ times. Thus $A_K(G,d)=K^{G-d+1}$ in this range. Adding one observer at fixed $d$ multiplies capacity by $K$ while there is another field point. This is a successor theorem about the stated resources: both the lower bound and an explicit larger construction survive the extension. For one checkpoint symbol per coordinate, evaluating a polynomial by Horner's rule needs only a field accumulator and the evaluation point across the input stream. These are standard Reed–Solomon codes. [Singleton, *Maximum Distance Q-Nary Codes*](https://luca-giuzzi.unibs.it/corsi/Support/papers-coding/%40private/01053661.pdf) · [Reed and Solomon, *Polynomial Codes Over Certain Finite Fields*](https://doi.org/10.1137/0108018)

For binary one-bit monitors there is a different exact boundary. Let $G=2^r-1$, $r\ge1$, and require a majority $d=2^{r-1}$ of all checks to catch each false chronology. In a code with $M$ words, pairwise Hamming distances sum to at least $d M(M-1)/2$ and at most $G M^2/4$, by counting unequal pairs per column. Therefore $M\le G+1$. Label the inputs by $r$-bit strings and take all nonzero binary linear forms as the $G$ coordinates. Exactly $2^{r-1}$ forms separate any pair. Hence $A_2(2^r-1,2^{r-1})=2^r$. This is the usual binary simplex construction and Plotkin counting argument. The equality files realize it with a true comparison of the raw data. A monitor computes its linear form on the genuine left and on the purportedly equal right work replies; an accepting comparison fixes every reported bit to the corresponding genuine right bit. With two boundary states per monitor and $H=1$, accepting false comparisons on $2^r$ labels can be detected by a strict majority, and one further label already exceeds capacity.

## Charging unrestricted input access

A random-access solver need not read left then right. On each genuine diagonal trace select one arbitrary cut and classify the private input words by side. Let the *off-side catalog* list the right private word positions read before that cut and the left private positions read after it, with their true values and side tags. The same cut is used by all checkers for that trace. Suppose the checkers inspect only the observed CPU events, or any independent private reads are also included in the common catalog. Within a class of identical catalogs and CPU controller, the hybrid above still works: every off-side word needed by either half has the genuine value. Therefore, if at most $C_{\rm off}$ catalogs occur at the selected cuts, there are at most $C_{\rm off} H A_K(G,d)$ qualifying diagonals. No uniform rule for selecting the cuts is needed. If independent checker access sets are not common, take their union or charge their checker-specific catalogs together.

On the fixed-layout proper formulas there are $O(m)$ private physical words, each taking $O(1)$ possible values: successive signs are separated by full-width helper or data names, or the format may insert public padding of $\Theta(\log m)$ bytes per pin. With at most $P$ distinct off-side words, $C_{\rm off}\le\sum_{j=0}^P\binom{O(m)}j O(1)^j$. In particular, if $P=o(m)$ then $\log_2 C_{\rm off}=o(m)$. With $H=m^{O(1)}$ and $2^b s=o(m)$, an exponentially small fraction of all $2^m$ equal inputs have such a cut in a solver admitting the $d=1$ protection hypothesis on every unequal pair. Unrestricted input access also gives a direct fast algorithm: read corresponding pins from the two blocks together and compare them in registers. Its off-side access count defeats the common-cut estimate. None of these equality files forces superlinear unrestricted SAT time.
