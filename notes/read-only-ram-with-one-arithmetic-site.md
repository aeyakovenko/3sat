# A read-only RAM with one arithmetic site cannot decide DIMACS SAT at any speed

Use the journal's [DIMACS RAM](five-instruction-loops-on-dimacs-sat.md). The word width is $w=16\lceil D\log_2(N+2)/16\rceil$ for fixed admissible $D\ge1$, where $N$ is the byte-aligned encoded bit length. Registers start at zero apart from optional public length and word width. A fixed program may have any finite number of register or immediate LOADs, register/immediate comparison branches with fixed targets, and jumps. It has no STORE and at most one numerical instruction site, with one fixed destination register $y$ and one fixed unary or binary operation on its listed source registers or literals. Successors, register names and literals are part of the fixed program. Returns have fixed verdicts. All branch choices, numbers of loop iterations and visits to the single numerical site may depend on the input.

**No such program decides ordinary DIMACS SAT, regardless of running time.** This includes the read-only five-slot allocations with at most one arithmetic site, even when more than two branches create complicated control flow. It does not classify the allocation with two numerical sites.

## Where a new address can come from

Let $H$ be the set of all initial memory word values including zero. At every point, each register other than $y$ belongs to $H$ or to the set of initial register values. This follows because its only possible write is a LOAD from immutable memory. A LOAD may also overwrite $y$; this resets its value to $H$. Write $B$ for $H$ together with the initial register values and all numerical literals, interpreted at the current width. These literals may be enormous fixed integers. The number of them is a program constant.

Use the [periodic even-word DIMACS family](five-instruction-loops-on-dimacs-sat.md) for the following exclusions. Its original words are all even, $|H|=O(1)$, and an unbounded interval of $\Theta(N/w)$ consecutive input addresses must each be read on the base by any solver correct on its single-word alternatives. If an address is never read, its single edit cannot influence the verdict. Both possible initial metadata values $N,w$ are even. Immediate LOAD addresses can be anywhere, including at an odd address, but there are only constantly many of them.

* If the numerical site has no source operand reading the previous $y$, both source values always belong to $B$. Its image has at most $|B|^2+|B|+1$ possibilities at this length. All indirect and immediate LOADs together then have only a bounded set of available addresses. The same conclusion holds with no numerical site at all.
* A move or a constant function only copies or introduces fixed values. A word comparison adds at most two values. For a bitwise operation, two bit positions agreeing on every initially available word in $B$ continue to agree in all generated words. The resulting number of available words is at most $2^{2^{|B|}}$, uniformly in $w$. For a one-direction logical or arithmetic shift there are at most $w+1$ possible iterated shifts per word in $B$, since composing shifts in the one direction saturates the data value after a total shift of $w$. Reduced shift counts on individual instructions do not change that conclusion. For a rotation there are at most $w$ rotations per original word. These claims also allow data-dependent counts, either operand order, and subsequent input resets of $y$. The total number of attainable load addresses in any of these cases is $o(N/w)$.
* Modular multiplication involving $y$ preserves evenness on the periodic base regardless of the multiplier. With addition or subtraction and two mutable source operands, both operands and the result stay even by induction. This also covers two occurrences of $y$. A mutable source other than $y$ can only take an even initially supplied or loaded word. For a fixed even operand, addition and either subtraction preserve evenness. The bounded collection of literal LOAD addresses cannot supply all the required odd addresses. This reasoning permits indirect LOADs to use any currently even register and permits any number of control tests.
* With one fixed odd operand, $y\gets c-y$ has orbits of size at most two between resets, so only $O(|B|)$ addresses are available. The remaining add/subtract forms all give $y\gets y+c$ modulo $2^w$ for a fixed odd program integer $c$, possibly negative. An immutable register holding zero, the length or $w$ is always even, so it cannot supply this exceptional operand. The last case is handled separately below.

All address counts include fixed register initializations, the raw words that indirect loads can supply, and the program's direct LOAD addresses. Thus a LOAD using the same register as address and destination is also covered. In the parity argument the literals in a comparison do not change registers.

## A public cursor with arbitrary control and input resets

Suppose the only numerical site adds the fixed odd $c$ to $y$. On any input put $B_0=H\cup\{0,N,w\}$, using the actual available metadata. If the program has $r$ data registers and $s$ reachable control locations, a terminating execution makes at most $s|B_0|^r$ LOADs that overwrite $y$. Immediately after every such instruction all registers belong to $B_0$. Repeating a post-reset state with the same PC and tuple would repeat the entire state of this read-only deterministic machine forever. This argument uses neither monotonicity of the PC nor a bound on time before the next reset.

Between successive resets, ignore instructions that leave $y$ unchanged. Its successive increments then follow a fixed additive orbit. At each complete lap, take the state immediately after the increment returning to the segment's initial cursor value. The control location has at most $s$ possibilities and the other registers have at most $|B_0|^{r-1}$ tuples. The same no-repetition argument bounds the complete laps in each such segment by $s|B_0|^{r-1}$. An unfinished segment contributes at most one more orbital traversal for counting cursor movement. Instructions retesting or reloading at an unchanged cursor require no additional crossing between owners. On a bounded-image family, the numbers of segments and laps are consequently bounded by program constants over *all* halting executions.

Apply the [word-aligned two-party equality family](communication-bound-for-public-crossed-scans.md). For all sufficiently large byte-aligned $N$ there are ordinary proper files whose halves encode $u,v\in\{0,1\}^k$ and are jointly satisfiable exactly when $u=v$, with $k=\Theta_D(N/\log^2 N)$. Their memory image is uniformly bounded in size. Decimal names may have $O(\log^2 N)$ digits and the format allows unused declared variables. Alice owns one contiguous address interval and Bob owns its complement on the word-address circle. Empty cells have the public zero default.

The parties exchange the lists of word values in their own portions of the file, retaining each distinct value only once. They now know $B_0$. They also exchange the original contents at the addresses in $B_0$ and at every program-immediate LOAD address. This costs $O_P(w)$ bits on the chosen family. Any load through a register other than $y$, or through a literal, can subsequently be evaluated by either party.

The current owner of the numerical address $y$ simulates the processor, including all branches and every LOAD through $y$. If a LOAD resets $y$ into the other party's region, hand over the PC and register tuple. An increment also triggers a handoff when the cursor changes owner. In one complete additive lap there are at most $2|c|+O(1)$ such crossings because the old address lies within $|c|$ unit positions of an interval boundary and cannot recur in the same lap. This bound also covers a partial lap. There are only constantly many resets and laps on each terminating run at these lengths. Local simulation time is free in a deterministic communication protocol. The total communication including the verdict is $O_P(w)$ bits. A correct total solver would therefore decide equality of $k$ private bits with $o(k)$ worst-case communication, contradicting the accepting-diagonal rectangle bound.

The exclusions for the non-cursor instructions use the even-word compulsory-read family; the cursor exclusion uses the two-party family. These source families need not coincide. Each proof quantifies over fixed programs and unrestricted running time. Separate arithmetic sites can retain a second independently computed word across resets and laps, so the bounded-image argument does not automatically extend to that case.
