# Fast SAT would produce hard Boolean truth tables at output speed

**Research journal, 24 November 2026.** Suppose a correct deterministic logarithmic-word RAM decides explicit SAT in $O(n^k)$ time, for $k=1,2$ or $3$, with unrestricted workspace. There is a fixed deterministic RAM that, given an all-zero input of length $M=2^m$ with its length available, writes a packed $M$-bit string $Y_m$ in $O(M/\log M)$ word steps. For every sufficiently large $m$, the Boolean function whose truth table is $Y_m$ requires at least
$$
 \frac{2^{m/k^2}}{m^{O(1)}}
$$
bounded-fan-in Boolean gates. Thus the numerators for the linear, quadratic and cubic SAT hypotheses are $2^m$, $2^{m/4}$ and $2^{m/9}$ respectively. The output bound counts the writes of all padding bits. This bulk constructor operates on $\Theta(m)$-bit words with the fixed constant needed for its address space. A machine given only the $m$-bit query index has a different input length.

The lower bound also holds for $s+q$ when a fixed RAM evaluator gets $m$, an index and an arbitrary preprocessed $s$-bit string and returns the requested bit within $q$ steps on every index. Use a fixed universal code-and-data evaluator on the specified ISA if different programs are desired at each arity. The constructor can depend on this evaluator and the hypothesized solver. For Boolean circuit hardness take an evaluator that interprets an ordinary gate list. The encoded list of a $g$-gate circuit has $O((g+m)\log(g+m))$ bits and bit evaluation takes $O(g+m)$ native steps. The result permits unbounded preprocessing and arbitrary nonuniform circuits.

The classical prefix search for a hard truth table with a polynomial-hierarchy oracle gives a polynomial-time constructor if P equals NP. It can spend a separate expensive decision call on every output bit. Here the construction writes one genuine solver execution and needs no prefix search. The distinctive parameters are the time to produce the **whole** table, the hardness exponent at each SAT exponent, and the guarantee at every sufficiently large arity. I have not established priority for this combination. ## Authenticating chronological memory with one predecessor per event

Run a deterministic target on its actual explicit formula. Record its controller at the start of each instruction and its bounded list of access slots, in native within-instruction order. Include bank, address, active flag, read/write tag, loaded or stored value and, for each active writable-bank event, the slot of the **preceding touch** to the same address, or a null tag. The post-access word is the returned word on a load and the written word on a store. For the genuine table a separate initially blank dictionary indexed by the target address suffices to produce the annotation online, including for zero reads and writes. Assign slots tags separate from the null tag. This costs constant native operations per slot on a host with sufficient word width.

A checker finds a defect by guessing a time or a pair of slots. It verifies the following requirements.

* The initial controller is prescribed and the clock-padded final controller is a rejecting halt. Each native instruction and its input loads, active slots, and successor controller follow from its claimed replies and the true read-only formula. Halts idle.
* Each non-null predecessor is active, strictly earlier and at the same writable address. On a load the claimed value equals its predecessor's post-access value, or zero at null.
* At a given writable address two different active slots cannot claim the same predecessor. This includes two null claims. One guessed pair detects any violation.

For each address, order its active slots by actual time in the **claimed** trace and rank them from zero. At rank $i$, encode null as $0$ and predecessor rank $j$ as $j+1$. The candidate key is at most $i$. Distinctness of the keys forces the key at rank $i$ to equal $i$: all smaller keys have already been occupied, by induction. Thus the indicated predecessor is the immediately preceding touch, and induction over time establishes every memory word, effective address and controller in the run. No sorted table is needed by the producer or checker. A pair of spurious null heads would otherwise permit an address to be reinitialized halfway through its history. ## One SAT call for an error in an indexed table

Use the bounded signed universal source on a padded input $x$ of $n_0$ bits with clock $h=n_0^D$, for a fixed integer $D>k$. Its explicit encoded formula $F_x$ has length $N=\Theta(h\log^3 h)$. Every formula word is computable from $x$ after polylogarithmic setup, in constant native lookup time on the specified packed ISA. Let the target solver and the solver for defect instances both be the assumed SAT algorithm. Set the target clock $T=\lceil C N^k\rceil$ with a valid fixed clock constant. The genuine table has $T+1$ rows. Use a uniform power-of-two row width of $O(\log h)$ bits, enough for all fields of a fixed program. Put the rows first in the binary output, then pad by zeroes. [Local formula construction, diagonal and width normalization](packed-band-transfer.md)

A fixed nondeterministic source verifier guesses $m$, a row description $z$ and a numeric query cap $q$. Check the headers, address bounds and that the $2^m$ positions contain the declared table. Impose fixed polynomial upper bounds in $n_0$ on the arity's **address range**, query caps and string lengths; the choices below have slack in all these caps. Decode a claimed row by $O(\log h)$ bit queries, with the same $m,z$, returning a fixed bit on malformed code or timeout. Thus all guesses define total rows. One bounded nondeterministic defect computation reads constantly many such rows, possibly reading another row indexed by a decoded predecessor. It uses the true source $x$ for any input consistency check. With $L=\max(2,\lceil\log_2(h+2)\rceil)$ its public data and clock give an explicit defect formula of bit length at most
$$
 (n_0+s+q+1)L^{O(1)},\qquad s=|z|.
$$
Construction time obeys the same bound. The fixed word-returning computation, including physical read-only input and every emulated memory access, is covered by the usual bounded RAM reduction. Fresh scratch or tagged banks isolate the bit queries. A fixed wider guest decoder can also be simulated by a trie on addressed words using polynomially many physical locations and polylogarithmic overhead within these caps. The verifier need not trust any claimed prefix of $x$. Its actual public input fits this bound since $D>k$. [Packed defect compiler](materialized-input-census.md)

The verifier signals precisely when its SAT call reports the defect formula unsatisfiable. Any signal certifies an actual rejection of $F_x$. Take $x$ to be this verifier's own fixed program description followed by zero padding. By definition of the bounded source, a timely signal would also make $F_x$ satisfiable. Therefore $F_x$ is unsatisfiable and no branch signals in time $h$. Its genuine rejecting table exists. If at a permitted padding arity it had an evaluator with $s+q\le h^{1/k}/L^B$ for sufficiently large fixed $B$, the honest branch would signal in $o(h)$ steps, since $n_0^k L^{O(1)}=o(h)$. This contradiction gives the lower bound. This use of time hierarchy is conditional on the SAT call fitting the clock of the smaller defect instance.

## From a padded input to each Boolean arity

Choose $n_0=2^{\lfloor(m-B_0\lceil\log_2(m+2)\rceil)/(Dk)\rfloor}$ for a sufficiently large fixed integer $B_0$. Handle small arities directly. Then $h^{1/k}=2^{m/k^2}/m^{O(1)}$, the clock $T=O(M/m^2)$, and the genuine table fits in $M$ bits. The header caps in the preceding proof can be taken, for example, with address range $M\le n_0^{Dk+1}$ for all large $m$. These caps are fixed before padding the verifier; the finitely many interpreter constants do not alter the exponents.

Generate $x$ from the fixed verifier code and $n_0$, and simulate the target on $F_x$ through its padded clock. The host provides independent address banks for target memory and preceding touches. Its word width is a fixed multiple of $m$ sufficient for both banks. The genuine table is already in chronological order and each padded row occupies a constant number of host words. Generating it takes $O(T+n_0+\operatorname{poly}(m))$ steps. Writing the packed zero suffix takes $O(M/m)$ more. This proves the stated worst-case construction time at **every** large arity, even if two neighboring arities use the same $n_0$. A circuit for either padded string would still supply the genuine rows at that permitted arity.

The result identifies an obstacle for using source simplicity to prove the elapsed-time lower bound. Under the very SAT assumption being tested, linear-output-time generation on a unary input is compatible with large nonuniform lookup complexity. The reduction does not give an upper bound on lookup cost for the genuine table. The missing step for this route would be such an upper bound that uses another property of the SAT computation. ## Testing the predictor even when the last writer is given for free

Under **linear SAT** there is a fixed linear-time RAM on unary inputs returning a constant verdict with the following stronger behavior. It first generates $Y_m$, unpacks one bit per word, and copies those words to a fresh bank in increasing address order. It then scans that bank in the same order. Implement the copy and the scan with fixed-length branch-padded iterations; clear construction registers at their boundaries. The final read can be kept observable by accumulating a parity in one register, comparing with the parity from the copy phase, and returning the fixed success verdict on equality. The alleged predictor may also know the copy phase's starting time and iteration period, so the last writer for *every* scan load is explicitly known. The preprocessing and these two phases together take $O(M)$ native steps. Only the copy and scan have this prescribed address schedule.

For any fixed $0<\kappa<\gamma<1$, set $w=\lceil M^\gamma\rceil$. In the scan there is a window of $w$ consecutive native start times at each of which predicting the actual incoming loads up to $2w$ subsequent instructions costs $s+q>M^\kappa$. This holds for any fixed evaluator on the common model, even if it sees the original unary input, the genuine preceding native events of its local segment, current registers, and the writing time of the queried cell. One can stop at scan end. This example does not use SAT correctness as the workload's final decision. The SAT hypothesis is used in its construction and the proof of its hardness.

Suppose instead every full $w$-window in the scan has a start with $s+q\le M^\kappa$. Select one in each disjoint full window. Gaps are at most $2w$, and there are $O(M/w+1)$ cuts. Store the short descriptions, the true cut controllers and true times, and the copy and scan starting times, as common advice. Directly record the bits for the initial and terminal fringes, of $O(w)$ steps in total. This costs $\widetilde O(M^{1-\gamma+\kappa}+w+1)$ bits. To recover an arbitrary $Y_m[i]$, calculate its known scan time, find its segment and retrieve that segment's advice. A true partial log can be recovered at one position in $\widetilde O(w+M^\kappa+1)$ time under linear SAT. Guess its $O(w)$ native records, check CPU transitions, and allow a challenge to a single load answer by running its predictor on the strictly preceding coded prefix at that load. The authenticated times make all writing timestamps and unary input reads easy to supply. An absence-of-error test and the outer existential request for a specified output bit are a fixed number of bounded SAT eliminations on the selected row and the local log. Correct row descriptions ensure the unique passing log is genuine. [Adaptive-log evaluation](live-segment-snapshot-queries.md) An advertised absolute time, register, or parity at the beginning of a cut occupies only $O(\log M)$ bits and is included in the advice.

This would give one exact evaluator for $Y_m$ whose total description length plus lookup time is $\widetilde O(M^{1-\gamma+\kappa}+M^\gamma)$, contradicting the linear-SAT table bound for all sufficiently large $m$. The exact table construction can monitor a fixed universal evaluator which includes this recovery program; for a specified predictor the same argument uses a fixed compiled recovery evaluator. The obstruction persists on all-zero data and when both the consumer addresses and the times of their true last writes are easy to compute. A shortcut that uses only those facts would also apply to this constant-verdict scan.
