# When a static-instruction induction has a finite stopping point

Here static size counts instruction slots and leaves the bit lengths of fixed immediate literals uncharged. The word-RAM family permits a host with exactly twice the word width of a guest. For example, one can take widths $b\lceil\log_2(n+2)\rceil$ for integral $b\ge1$, or allow twice any admissible rounded width. Input is the same little-endian bit string on both machines, literals are reduced modulo word width, and the instruction set has ordinary fixed word arithmetic and indirect loads and stores. This observation concerns the uniform SAT time question for a family closed under this doubling. The exact five-slot census uses its own specific width rule.

**Proposition.** There is a finite integer $s_*$ independent of the solver, time exponent, clock multiplier and guest width coefficient with the following property. If any fixed guest program decides explicit SAT in $O(n^a)$ time for $a\ge1$, then a program with at most $s_*$ host slots also decides it in $O(n^a)$ time. The host may have a much larger fixed immediate and a larger clock multiplier. Thus a correct size induction up to $s_*$, uniform over literals, admissible word widths and time multipliers, would already reach the unrestricted goal in this model. This is a universal-interpreter observation. Fixed-program and stored-program RAM simulations go back to Cook and Reckhow. [Original RAM-model comparison](https://www.cs.toronto.edu/~sacook/homepage/rams.pdf)

To see the quantifiers explicitly, write one interpreter over the fixed ISA and leave one immediate $e$ for the encoded guest text. Interpret a guest word of width $w$ on a host of width $W=2w$. If width is not supplied, shifts until zero recover $W$ in $O(\log n)$ startup time. Prepare the guest mask, sign bit and memory-bank offsets once. For sufficiently large $n$ the full fixed integer $e$ fits. Parse it once, rename the guest's finitely many registers densely, and store its decoded instructions in private host memory. Even fetching a guest instruction by scanning this table costs $O_e(1)$ per step. Arithmetic including multiply, shifts and signed comparisons uses a fixed number of host word operations and a guest-width mask.

The initial guest word at address $i$ is the low or high half of the host input word at $\lfloor i/2\rfloor$, selected by the parity of $i$. Use the low host address range only for these original reads. Above it use separate banks for the guest dirty bits, guest values and private interpreter arrays, for example at $2^{W-2}$, $2\cdot 2^{W-2}$ and $3\cdot 2^{W-2}$. For sufficiently large inputs each bank accommodates all $2^w$ guest addresses or the fixed interpreter tables. An unwritten guest cell reads its original half-word, which is zero outside the physical input. A written cell reads its value bank. This handles guest writes to the input and arbitrary sparse access at constant cost. It uses neither an $n$-word address remapping step per instruction nor a lookup in an uncharged advice table. Guest registers initially containing public metadata receive the guest values. The code of this interpreter has constant length, irrespective of $e$.

For a total solver at small lengths the same code can detect truncated text. Encode successive guest bits in low-to-high pairs `01` or `10` and terminate with `11`. A proper low-bit truncation never contains the terminal pair. Stream-decode with word shifts, and transfer to a fixed ordinary brute-force SAT solver if the end marker is absent. Resource checks for setup may use the same fallback on finitely many small lengths. The fallback needs only a fixed program and space polynomially bounded as addresses permit: for example, enumerate truth bits per literal occurrence, check equality of occurrences of the same name by rescanning their encoded names, and test clauses. The number of occurrence bits is at most the input length and the host has at least quadratically many addresses. At all sufficiently large lengths the guest is simulated correctly in $O_e(T(n)+\log n)$ time. All short-length costs are finite for a fixed guest and can be absorbed in its asymptotic constant. Counting the fixed fallback and interpreter slots gives $s_*$; this proof does not compute a small numerical value for it.

When program size charges *bits*, the long immediate contributes throughout the induction and there is no such uniform bound on the interpreter description length. When the clock multiplier is fixed in advance, the guest-dependent simulation constant also matters. In particular this observation does not turn a finite-horizon small-slot census into a lower bound. It identifies exactly what a case analysis at a constant syntactic cutoff would ultimately have to exclude.
