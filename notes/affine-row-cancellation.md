# Checking dense affine implications about unrestricted RAM memory

**Research journal, 24 November 2026.** A rejecting computation can have a certificate whose individual invariant rows depend on the parity of arbitrarily many memory bits. We give a universal local check for one class of such certificates, even when finding a violated predecessor row takes linear time. The construction checks cancellation of formal occurrences. It never evaluates a dense parity on a supplied memory assignment. The explicit example in the [row-selection experiment](row-selection-gap.md) admits this symbolic inference.

## A locally checked algebraic rule

Fix the load/store word RAM, an input $F$, a valid clock $T$, and the padded single-step semantics from the [register-history note](chronological-solver-registers.md). Write a state as $(\rho,M)$ with controller $\rho$ and writable word array $M$. For every $(t,\rho)$ the candidate invariant is a conjunction of affine equations over $\mathbb F_2$ in the individual bits of $M$. Represent an equation by a bounded list of occurrences whose XOR must vanish. A term is an addressed bit or the constant one. An inactive slot contributes nothing. Constants, repeated variables and empty rows are allowed. A finite circuit supplies the term or inactive marker from the time, controller, row and slot. All indexing fields have a fixed $O(\log N)$ width, for encoded input length $N$. The number of rows and slots can therefore be polynomial in $N$. The field widths, masks and local circuits are part of the charged proof description.

To justify one outgoing row, consider a putative instruction view. It gives the old controller and the bounded sequence of native words returned by the instruction. Compute effective addresses, writes and the new controller from these words. Public input reads are checked against $F$. Reads of earlier writes are checked inside the step. Every remaining writable-memory read is from old memory and contributes a list of unit equations fixing its bits to the proposed word. Views with incompatible repeated replies can be discarded. All actual transitions have a view passing these checks.

Substitute each written constant bit into the outgoing row at its address, using the last write there. This yields a target row in old memory. An initial challenge uses fresh memory set to zero and substitutes zero into the challenged row at the required starting controller. To exclude an accepting or nonhalting terminal controller, use the constant contradiction $1=0$ as target. A rejecting halted controller needs no terminal challenge.

For each challenge, a proof circuit selects a subset of the old invariant rows and read-value equations, indexed independently of the uninspected old memory. The initial case selects none. Give each term of the target and each active term of each selected equation its own occurrence index in a fixed tagged layout. Inactive terms, zero constants and unselected rows are excluded. A second circuit supplies a proposed partner index for each occurrence. For every active index $i$ check the following.

1. Its partner $j$ is a different in-range active index for this same challenge.
2. The terms at $i$ and $j$ are the same normalized address and bit position, or both are the constant one.
3. The partner at $j$ is $i$.

The index domain is finite. Its active terms split into disjoint pairs, hence the concatenation of the target and all selected old equations evaluates to zero on **every** memory. Whenever the old invariant holds on an actual state, the selected predecessor residuals vanish. The read-value equations hold by the actual instruction view. The target residual therefore vanishes. At initialization the checked identity justifies every row after zero substitution. At termination an actual nonrejecting controller would imply $1=0$. This proves rejection by induction. It also explains why a malicious certificate cannot suppress inconvenient terms of a selected equation. Activity is recomputed from the common row generator and mask, independently of the partner circuit. [Finite cancellation and soundness in Lean](../lean/AffineRowPairs.lean)

For fixed finite term lists, every zero affine identity admits a pairing: each active label has even multiplicity. Likewise a finite affine implication has a linear-combination witness when the source system is consistent, by elementary linear algebra. With an inconsistent source system the target need not be in its augmented row span. Permit a separate contradiction mode which targets $1=0$ from the sources and thereby justifies any outgoing row. Its flag depends only on the challenge and the instruction view, so the same mode applies at every occurrence. These completeness observations concern unrestricted tables. They give no bound on the size of succinct row selectors or partner circuits.

## Cost on the signed input

A single purported defect consists of an initial, transition or terminal challenge, a valid instruction view as applicable, and an occurrence where a universal check fails. One bounded-fan-in circuit checks all of this from finite strings. Define $g$ to count the gates, interface fields and proof-description circuitry for one expanded check, including the bounded number of uses of the same selection, term and partner templates. Malformed encodings are rejected before the defect query. For the diagonal's native formula reads only, add the public input-word generator, costing $(n_0+1)\operatorname{poly}(L)$ gates for source input length $n_0$ and $L=\max(2,\lceil\log_2(N+2)\rceil)$. The certificate circuits have no free table lookups. An instance-dependent table must be charged as circuitry, or accessed via an explicitly charged public-input interface. The polynomial number of formal terms need not be listed.

Consequently a deterministic $O(N^k)$ SAT solver for $k=2,3$ has a solver- and verifier-dependent UNSAT family on which every such affine certificate costs
$$
 g=\Omega\bigl(N^{1/k}/L^{1+3/k}\bigr).
$$
To see this, use the signed source clock $h=n_0^{2k+2}$ and its bounded-computation formula of length $\Theta(h\log^3h)$. A source branch guesses a proof of small cost and solves the explicit Tseitin encoding of a defect, with $O((g+(n_0+1)\operatorname{poly}(L))L)$ bits. It signals success on UNSAT. On the verifier's own padded description, timely success would make the formula satisfiable while proving the correct solver rejects it. Thus it is unsatisfiable and lacks any timely success. For sufficiently small constant $c$, $g\le c h^{1/k}/L$ makes that honest branch timely, including the cost of guessing, emitting and solving its defect formula. This yields the bound. A single verifier may guess a tag and check either this proof format or the [adaptive row-selection format](adaptive-invariant-selectors.md); they then share the same hard family. ## Why this still leaves the time question open

On the layered example, the check that all variable occurrences cancel can use the public permutations and their inverse tables. The complementary pair of charges contributes the extra constant one needed to justify contradiction. This symbolic rule survives the linear lower bound for inspecting a mutable assignment. Parity proof logging and affine program invariants are established techniques. The result here uses succinctly paired occurrences at arbitrary-address RAM steps and charges them on the same scale as a hypothetical SAT algorithm. [Gocht and Nordström, certifying parity reasoning](https://ojs.aaai.org/index.php/AAAI/article/view/16494) · [Karr, affine relationships among program variables](https://www-apr.lip6.fr/~mine/enseignement/mpri/attic/2014-2015/exos/karr.pdf)

Every finite deterministic rejection does admit exact-state singleton affine rows if given the complete trace. For example, one row per memory bit fixes its value, and constant equations disallow every controller except the actual one at that time. Their proof can be built with unrestricted tables, using the true run to supply values and source rows. Producing sufficiently small descriptions of such rows or a weaker inductive invariant is the missing upper bound. The unrestricted linear, quadratic and cubic running-time questions remain open.

## What affine conservation forgets at a packed routing network

Consider replacing the Beneš router in the bounded-computation formula by all its affine consequences on the record bits. Keep the instruction checks, sorted-order checks and adjacent memory-value checks exact. This relaxation admits a false accepting trace, even when the chronological register trace and all the router's input records are fixed. [Packed record fields and switch semantics](packed-band-transfer.md)

For fixed input records $r_1,\ldots,r_m\in\mathbb F_2^w$, put $D=\operatorname{span}\{r_i+r_j:i,j\in[m]\}$. The affine hull of the possible output lists is exactly
$$
\left\{(y_1,\ldots,y_m): y_i\in r_1+D\text{ for all }i,\quad
                    \sum_i y_i=\sum_i r_i\right\}.
$$
Every permutation satisfies these equations. Conversely, put any designated pair of input records at two chosen output positions, then transpose them. The difference of the two routings places their record difference at precisely those two positions. Linear combinations can therefore add any $d\in D$ at any pair of positions. Using one position as an anchor realizes every tuple of changes in $D$ with zero total. This also works for repeated records. Each genuine permutation extends to an assignment of the internal switch and wire variables, so each output in the hull extends to the affine hull of full router assignments with these fixed inputs.

For a concrete source program, preload registers holding zero and one and align four consecutive store instructions to guest times $4j,\ldots,4j+3$. All four write to scratch address $B$ in the same native event slot, with respective values $1,0,0,0$. Their full record XOR is the unit vector $d$ of the low value bit. Bank, address, store tag and event slot are constant across the four, and the four binary timestamps have zero XOR. Thus $d\in D$. Next load two registers from a distinct untouched zero-initialized address $A$, and accept precisely if both loads returned one. A genuine execution rejects.

On the **chronological** side, supply one at both loads and follow the resulting accepting controller trace. Start the **sorted** side with those same records correctly sorted, then change the two read-value words to zero. The sorted keys are unchanged. The reads from $A$ now pass the genuine zero-initialization and predecessor checks. The writes at $B$ are genuine throughout. No other active field or dummy record needs to change. The two altered output positions each differ by $d$, and their changes sum to zero, so this sorted output satisfies every affine consequence above. Extra data-dependent provenance columns could change the hull. The example uses the fields of the stated packed encoding. For instance, adjoining the product of the low value bit and a timestamp bit distinguishing the two reads detects this particular pair of changes.

This is a counterexample to eliminating the router by affine conservation before imposing sorted-memory consistency. It is a native bounded-source program. The [degree calculation for tagged tables](tagged-routing-degree.md) treats permutation-invariant nonlinear checks. The example leaves open proofs exploiting the joint nonlinear constraints or the specific program in the signed self-input.
