# Exactly three tests suffice for a finite interpreter census if the SAT time lower bound holds

Count input bits and fix $d\in\{1,2,3\}$. There is a fixed finite RAM instruction template $V(e)$ with one arbitrary integer parameter and word width $H(N)=16\lceil4\log_2(N+2)/16\rceil$ having the following property. Write $k_d(C)$ for the minimum number of labeled valid proper DIMACS files that together defeat **every** $V(e)$ at deadline $C(N+1)^d$. A program fails a file by returning a wrong verdict or by missing its deadline. Set $k_d(C)=\infty$ if no finite suite works.

* If SAT lacks a deterministic $O(N^d)$ algorithm on the unrestricted logarithmic-word RAM (any fixed positive integer width coefficient), then **$k_d(C)=3$ for every sufficiently large $C$**. The forward upper bound holds for every positive integer $C$.
* If such an algorithm exists, then **$k_d(C)=\infty$ for every sufficiently large $C$**.

The three files consist of a known UNSAT input of $O(\log(C+2)\log\log(C+4))$ bits, a SAT input and a second UNSAT input. The last two can both be required to exceed any prescribed length or to extend any fixed satisfiable seed. They need not have the same length. After the first file, the open mathematical obligation for each $C$ is to find two opposite labels on which a **specified, finite, computable vector of actual bounded RAM responses is identical**. This quantifies over one structure sufficient for every ordinary finite solver and arbitrarily long immediate literals. The code size and the evaluation clock are different parameters; the interpretation can change a solver's constant. We do not know how to force these collisions for every $C$.

## The three files

Give $V$ a mode implementing the [one-parameter RAM interpreter](anchored-interpreter-for-ram-exhaustion.md) and additional modes for the elementary classifiers described below. A fixed number of tag bits suffices. The low-to-high two-bit encoding has two data symbols and a first terminator; higher bits are ignored in the decoder and its subsequent timing. On a malformed or truncated description use the same correct fallback, enumerating every assignment on an unsatisfiable file. In particular every ordinary guest solver with a fixed positive integer width coefficient at its original $O(N^d)$ time can be simulated by one fixed $V(e)$ in $O(N^d)$ time, with possibly larger constant. The code for $V$ has fixed finite length. The optional probe modes inspect either the file bits or the binary public length. These constructions specify native algorithms and existence of a fixed compiled template; there is no measured numerical instruction count for that universal interpreter here.

For the first file $A_C$, take all eight sign clauses on three variables plus disjoint positive clauses through a suitable $v=3+3j$ occurring variables. Its fallback takes at least $2^v>C(|A_C|+1)^d$. Consequently every parameter passing this first test has a complete description in the $H(|A_C|)$ low bits. Retain one representative per terminated prefix. Its semantics and timing at all lengths are identical to any other parameter with that prefix. Including representatives that fail the anchor is harmless. There are at most $2^{H(|A_C|)/2}=O((|A_C|+2)^2)$ prefixes. No infinite coherent literal can evade the test by displaying new code later.

Let these representatives be $p_1,\ldots,p_s$. On any valid file $x$ define the signature
$$
 \sigma(x)=(R_1(x),\ldots,R_s(x)),\qquad R_i(x)\in\{\mathrm{YES},\mathrm{NO},\mathrm{timeout}\},
$$
where $R_i$ is the actual verdict of $V(p_i)$ within $C(|x|+1)^d$, or timeout. For fixed $C$, there are finitely many signatures. A uniform RAM computes the vector in $O_C(|x|^d)$ native time by separate bounded simulations, restoring the guest's initial memory and word width each time. Use a sufficiently large fixed host coefficient, as allowed for the target class. The constant can depend arbitrarily badly on the fixed census; the argument uses no advice indexed by the input length.

Suppose that above some length no SAT file and UNSAT file share a signature. On this tail each observed signature determines its verdict. Hardwire one bit per signature and handle the finitely many shorter files separately. The resulting uniform algorithm decides SAT in $O(N^d)$ time. Hence under the lower-bound hypothesis there are arbitrarily large opposite-labeled $x,y$ with $\sigma(x)=\sigma(y)$ (both lengths above the threshold). A representative timing out fails both. One giving a verdict fails the endpoint of the other label. Together $A_C,x,y$ defeat every parameter. The finite-vector argument also underlies the journal's earlier tests of Boolean postprocessors. Here the anchor makes the single native template finite at the chosen clock. [Earlier finite verdict vectors](linear-verdict-pivots.md) This proof allows arbitrary unsound and partial programs: it needs no way to recognize them. Exhaustively comparing the signatures of pairs with their offline SAT labels eventually finds a pair **if the hypothesis holds**. Conversely a single actual $O(N^d)$ solver yields a $V(e)$ passing every file once $C$ absorbs its constant and its finite initial exceptions. [Lean collision and finite-cover statements](../lean/ThreeFileCensus.lean)

The collision can be required on more than one transformed input per source. Fix any finite collection of uniformly $O(n^d)$ builders with output lengths $O(n)$, each preserving the source verdict. Concatenate all corresponding signatures of their outputs on a source $F$. A separating table on that finite range would again decide arbitrary SAT at the forbidden clock. In particular use *all* corners and lengths of the fixed-dimensional, homogeneous canonical cubes glued to a fixed satisfiable seed, using both logical sources equal to $F$. A pair of opposite source verdicts with equal matrices is then available. At any aligned coordinate the anchor and the two corresponding files are a sufficient three-file suite. No equality between the two independent source lengths follows. This gives an alternative certificate for the [nested successor search](nested-satisfiable-seeds-for-ram-exhaustion.md) with one common negative counterpart in place of separate semantic error records for machines.

### An algebraic successor that cannot produce the three-file witness

Two fixed, generally unsound native programs suffice to fit $A_C$ together with **every corner of any one parity cube**, regardless of its dimension, positions or length. Both first reject on detecting the eight fixed sign clauses of the anchor. Otherwise the first returns the parity of all physical input bits, and the second returns its complement. The guard is sound and costs at most linear time on valid files (a fixed collection of delimited clauses suffices). Bit parity takes $O(N)$ steps even by processing one bit at a time. Both programs are therefore implementable by fixed parameters of $V$ within $C(N+1)^d$ at all large $C$; a correct fallback at short lengths can only improve their fit.

On a cube whose coordinate moves each flip one particular bit, physical parity at mask $z$ equals the base parity XOR the parity of $z$. When SAT alternates on all edges, its label has the same form, with just the base bit possibly different. One of the two programs therefore fits *all* corners. The guard never rejects a SAT corner and can only give the desired answer on an UNSAT corner. Both pass the anchor. In particular **an anchor plus any opposite pair at odd Hamming distance cannot be a defeating triple**, even if globally sound programs take a long time on both endpoints. Changing one bit per new coordinate and enforcing the algebraic parity recurrence preserves this obstruction forever. For any fixed $h$ consecutive lengths, a finite extension of the same rule selects the orientation using $N/8\bmod h$ and an $h$-bit table, so it can fit all such cubes at once. The sufficient clock multiplier for this last statement can depend on $h$. [Physical parity cubes](physical-selector-parity-cubes.md) · [Direct classifier audit](../audits/parity_cube_anchor_audit.py)

There are further necessary congruences for the proposed **identical-signature** search. Include in the fixed template a mode that selects a bit of the residue of the tagged input, or of its public length, modulo a serviceable integer $q$. A bit index and a modulus up to $B$ use at most $\log_2 B+O(\log\log(B+4))$ data bits; a streamed remainder uses $O(N)$ steps uniformly when $q$ is small enough for a host word. Consequently there is a fixed $b>0$ such that for $L=|A_C|$ sufficiently large, all these tested bits for $2\le q\le B=\lfloor L^2/(\log_2 L)^b\rfloor$ have complete prefixes at the anchor. Take the signature on all complete prefixes, even if some fail the anchor. At large $C$ any pair of test files longer than the anchor having identical signatures must have both its tagged integers congruent modulo $\operatorname{lcm}(1,\ldots,B)$ and its lengths congruent modulo that same integer. Two different lengths must differ by at least $2^B/(B+1)$ by the elementary lcm bound below. These congruences provide actual tests to reject proposed pairs. Actual opposite-verdict inputs satisfying all these checksum constraints can be constructed, even at distance two. The selector used in the construction allows an unrestricted RAM to tell them apart. [Concrete collision and algebraic successor](checksum-collisions-on-actual-sat.md)

### If the two large tests must have identical lengths

There is an exact change to the hypothesis. The following two statements are equivalent, for the same template and $d$ as above.

1. SAT lacks an $O(N^d)$ algorithm with $O(1)$ advice bits depending only on the encoded bit length.
2. For every $C$ there are arbitrarily large lengths with an opposite-verdict pair of that **same** length which, together with $A_C$, defeats the entire template.

Indeed, under the first statement some signature collision must occur at arbitrarily large common lengths. Otherwise at each sufficiently large length its own table on the *same finite signature alphabet* correctly decodes SAT. Supplying that table as advice costs only a fixed number of bits, although it may depend on $C$. Conversely compile one program per advice string for an advised solver. Add to each program a sound initial test for the eight fixed contradiction clauses on variables 1,2,3 in every anchor. Testing for this fixed finite set on the canonical anchors costs $O(N)$ uniformly; on general valid inputs choose a sound bounded scan, fall back to the advised computation on a miss, and preserve its clock. Each of these finitely many programs passes the anchor once $C$ is sufficiently large and the anchor width sees the compiled codes. At every large length one of those programs also decides every file correctly within the common clock. Thus no opposite pair at that length plus the anchor defeats the template. This explains precisely why the unconditional *equivalence to the uniform lower bound* uses independently chosen lengths.

There is a weaker same-length consequence of the original uniform target. A constant-advice $O(N^{d-1}\log(N+2))$ solver for $d=2,3$ would yield a uniform $O(n^d)$ solver. Try its finitely many fixed advice values separately in a self-reduction, padding every child restriction to the *same* length $\Theta(n)$, and verify the resulting full assignments. Advice correct at that common length supplies a successful path on satisfiable inputs. Cap simulations at the fixed clock, and discard paths that time out; an unsatisfiable source never passes verification. There are $O(n/\log n)$ variables after normalization. Consequently uniform nonquadratic SAT would force a same-length opposite signature collision against $CN\log N$ clocks, and uniform noncubic SAT would do so at $CN^2\log N$. Neither transfer removes this loss for the original exponent. ## Why two files always fit

Include constant verdicts, one-bit probes and comparisons of the input length with one parameter in $V$. Encode a nonnegative index by a self-delimiting binary field of $\log_2(i+2)+O(\log\log(i+4))$ data bits, for example by encoding its bit length first. On two files with identical labels use a constant. With different labels and different lengths, test equality with the shorter length. With equal lengths choose one differing physical bit and test it. The orientation of each test is one code bit. The chosen index is at most the shorter bit length. The entire two-bit-coded parameter therefore fits at **both** widths once that shorter length is sufficiently large. The bit probe uses native word/bit offsets, computable even by elementary bit division in $O(\log^2(N+2))$ steps. Decoding and a length comparison fit the same bound. Thus a single constant $C_0$ suffices for all pairs at linear time. For shorter inputs the fallback is correct and has a finite worst time over these lengths. A bounded-index probe that fits at one width but truncates at a smaller one can only hit the correct fallback there. Enlarging $C_0$ covers these cases too. The classifiers can be unsound elsewhere; two-file compatibility is exactly what is required. This proves sharpness for the stated template.

## A single scale can require logarithmically many tests even with this fixed template

Fix $1\le h<2$, $\epsilon>0$ with $h+\epsilon<2$, and a sufficiently large lower length $a$. For **any** $k$ distinct files of bit lengths between $a$ and $a^h$, with **any** binary labels, one parameter can fit them all in linear time provided
$$
 k\le \frac{2-h-\epsilon}{3}\log_2 a .
$$
The clock constant here is uniform over the files, their labels and $k$. This uses one further fixed mode of $V$. The three-file upper bound exploits the separation between the anchor length and the possible collision lengths. In particular a fixed number of files of comparable, sufficiently large sizes always fit. The proof uses ordinary fingerprints and finite-field interpolation. Universal hashing and universal sets long predate this analysis. [Carter and Wegman](https://www.sciencedirect.com/science/article/pii/0022000079900448) · [Rabin on fingerprints](https://www.cs.cmu.edu/~15-749/READINGS/optional/rabin1981.pdf) · [Naor, Schulman and Srinivasan on universal sets](https://users.cms.caltech.edu/~schulman/Papers/splitters.pdf)

Encode each input as the integer whose binary representation is a leading one followed by all its bits in a fixed order. Put $M=\max |x_i|$. The $k$ integers are distinct. There exists a modulus $p=O(1+k^2(M+1))$ giving $k$ distinct residues. Indeed if every integer $2,\ldots,t$ caused a collision then each would divide the nonzero product of all pairwise differences. Its absolute value has at most $O(k^2(M+1))$ bits. But $\mathrm{lcm}(1,\ldots,t)\ge 2^t/(t+1)$: each binomial coefficient of order $t$ divides that lcm by the prime valuation formula (each power of a prime contributes zero or one), and the largest coefficient is at least the binomial average. Taking a sufficiently large $t$ is a contradiction. Apply the same argument to these first residues for a **second** modulus $q=O(1+k^2\log(p+2))$. The final $u_i=(x_i'\bmod p)\bmod q$ are still distinct, all below $q$, where $x_i'$ denotes the tagged integer.

Set $s=k+\lceil\log_2(q+1)\rceil+1$ and work in $\mathbb F_{2^s}$ with any degree-$s$ irreducible polynomial. Some $\alpha$ makes the $k$ elements $\alpha^{u_i}$ linearly independent over $\mathbb F_2$. Every nonempty subset gives a nonzero formal polynomial $\sum_{i\in I}z^{u_i}$ of degree less than $q$. Their union of root sets has size less than $2^k q<2^s$. With these independent vectors choose a binary linear functional giving the prescribed labels. In the polynomial basis this is a single $s$-bit parity mask.

The data payload gives $p,q,s$ in self-delimiting binary, the low $s$ coefficients of the monic irreducible polynomial, the $s$ bits of $\alpha$ and the $s$ coefficients of the functional. Together with the fixed mode tag this takes
$$
 \log_2(M+2)+3k+O(\log(k+2)+\log\log(M+4))
$$
data bits. For $k$ in the displayed range the payload and terminator fit in $H(a)/2\ge 2\log_2(a+2)$ two-bit symbols. Each input is processed once by the recurrence $r\gets (2r+b)\bmod p$, starting at one. The intermediate fits a host word for the indicated range and one conditional subtraction suffices. Scan packed words bit by bit for $O(N)$ work. Reduce the first residue modulo $q$ by binary division and compute a power in the supplied polynomial basis by repeated squaring and carryless shift/XOR multiplication. A constant number of limbs suffices or one can reduce after every shift. This takes $\operatorname{polylog} N$ elementary steps uniformly for all fitted parameters in this range. Decoding and the final parity use the same budget. No primality check or search for the parameters is performed on the fitted runs. The existence proof may search for them offline.

The template can run the same classifier on the binary representation of the *public input length* instead of the file. Suppose a fixed number of files have minimum length $a$ and maximum length $M$, and that their labels agree whenever their lengths agree. After duplicate lengths are merged the longest source for this interpolation has only $O(\log(M+2))$ bits. For three files the payload needs at most $\log_2\log_2(M+4)+O(\log\log\log(M+16)+1)$ data bits. Thus, for any $\epsilon>0$, such a triple with $M\le 2^{a^{2-\epsilon}}$ always fits at linear time for sufficiently large $a$. In particular, a triple consisting of the short anchor and two longer, oppositely labeled tests of different lengths must span still larger scales or it cannot refute the template. An equal-length pair cannot be distinguished by metadata. This is an obstacle to a practical three-file exhaustion even though there is no known bound on how far the exhaustive search must go.

### Nearly exact capacity across a length interval

For fixed $1\le h<2$ take byte-aligned $a$ and let $M$ be the largest byte-aligned bit length at most $a^h$. Add one further fixed mode that regenerates a binary universal set. Let $s_h(a)$ be the largest $k$ between zero and the window's domain size for which **every** set of at most $k$ distinct valid files with lengths in $[a,M]$ and **every** binary labeling of it can be fitted by one template parameter within a common sufficiently large linear-clock constant. Then
$$
 (2-h)\log_2 a-O((\log\log a)^2)\ \le\ s_h(a)\ \le\ (2-h)\log_2 a+O(1).
$$
Both inequalities continue to hold with the domain restricted to the dense canonical files of maximum occurrence four. This quantifies the number of arbitrary small examples that a finite experiment at one scale can fit, including when the two end lengths in the experiment differ by a polynomial factor.

For the lower bound, hash twice as above. There are now $q=O(k^2\log(p+2))=\operatorname{polylog}a$ positions. Theorem 6 of Naor, Schulman and Srinivasan gives a deterministic binary $(q,k)$-universal family with $2^k k^{O(\log k)}\log q$ rows that can be listed in linear output time. Any labels on the $k$ distinct positions occur together in one row. Encode $p,q,k$ and that row's index. The total is at most $\log_2 M+k+O((\log\log a)^2)$ data bits, including self-delimitation. The decoder streams the first fingerprint, computes the second, and regenerates the universal table to look up the one bit in the named row. Even listing the whole table costs $2^k k^{O(\log k)}\operatorname{poly}(q,\log a)$ elementary steps. Taking $k\le (2-h)\log_2 a-K(\log\log a)^2$ with a sufficiently large fixed $K$ puts this cost within $O(a)$ and ensures a complete prefix is visible at every input width. Constants and finite small cases can be handled by the elementary classifier modes. This uses the published global construction; a local universal-set evaluation is unnecessary. [Naor, Schulman and Srinivasan, §5.2, Theorem 6](https://users.cms.caltech.edu/~schulman/Papers/splitters.pdf)

For the upper bound, give one chosen file at the short length $a$ the label opposite to the correct fallback verdict. A parameter fitting that label must display a complete description at width $H(a)$. At most $R=O(a^2)$ different complete functions or partial programs remain across *all* longer lengths. For arbitrary-label counting extend divergences arbitrarily to bits; this can only increase compatibility. Let $U$ be the number of files at length $M$, omitting the short file if necessary. If every choice and labeling of $k-1$ further files fits, then these $R$ rows cover all patterns on each $k-1$ positions of a $U$-column matrix. Fix $k-3$ columns. Each of their $2^{k-3}$ possible patterns defines a disjoint bucket of rows. Inside every bucket any two remaining columns have to be distinguishable because both can be prescribed together. Each bucket thus contains at least $\log_2(U-k+3)$ rows. For $k\ge3$ this gives $R\ge2^{k-3}\log_2(U-k+3)$.

In fact $U\ge2^{\Omega(M)}$ even for dense canonical files of maximum occurrence **one**. Partition the $3m$ consecutive names into unordered triples and use one positive clause per triple. Ignoring signs there are $(3m)!/(6^m m!)$ different sorted files, all of the same length $\Theta(m\log m)$. The next value of $m$ increases the length by $O(\log m)$ bytes. To reach the exact desired byte length, choose the largest $m$ whose base fits and negate the first required number of name occurrences, using numerical name order. For large $m$ at most $3m$ signs suffice; each name occurs once. Distinct partitions still give distinct files. Their log count is $\Theta(m\log m)=\Theta(M)$. Substitution in the row bound gives $k\le2\log_2 a-\log_2 M+O(1)$, as claimed. The upper bound deliberately prescribes an arbitrary label on the short file. For actual SAT labels the interpolation lower bound still applies, but this counting upper bound gives no SAT counterexample.
