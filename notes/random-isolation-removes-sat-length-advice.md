# Removing SAT length advice with random weights

Suppose a fixed deterministic RAM decides ordinary proper 3-SAT with length advice. At every sufficiently large physical bit length $n$, one string in an explicitly enumerable menu of size $K(n)$ works on every legal file of that length. Give every row the same known constructible time envelope $t(n)$ and clip all trials to a fixed Boolean answer on timeout. Write $\widetilde O$ for a fixed polylogarithmic overhead. If $K(n)=n^{o(1)}$ and $t(n)=n^{c+o(1)}$ for $c\ge1$, there are two **uniform randomized** RAM algorithms:

* One has time $n^{c^2+o(1)}$, always rejects an unsatisfiable input, and accepts a satisfiable input with probability at least $1/2$.
* The other has time $n^{c+o(1)}$ and error at most $1/3$ on each input. Its proof uses a PCP whose honest proof can be calculated in quasilinear time.

For $K(n)=\log^{O(1)}n$ and $t(n)=n^c\log^{O(1)}n$ the overheads over $n^{c^2}$ and $n^c$ are polylogarithmic. All trials are deterministic conditional on the stated random bits. The hypothesis is length advice for deterministic clocks, with the correct row allowed to change at every length. The [deterministic removal](implicit-assignments-remove-length-advice-for-sat.md) uses a different isolation procedure.

## Choosing one model

Intern the $v$ occurring variable names of the input $F$. Handle $v=0$ directly. Independently choose each weight uniformly in $\{1,\ldots,W\}$, where $W$ is the least power of two at least $2v$. This costs exactly $v\log_2 W$ random bits. A model has weight equal to the sum on its true variables. For a nonempty model family the minimum is attained uniquely with probability at least $1-v/W\ge1/2$. Indeed, after fixing all other weights, at most one value of weight $i$ can tie the best model containing $i$ with the best one omitting it. Any two distinct minima create such a tie at some coordinate on which they differ. [Mulmuley, Vazirani and Vazirani, *Matching is as easy as matrix inversion*](https://people.eecs.berkeley.edu/~vazirani/pubs/matching.pdf)

Each trial row $h$ first performs binary search among $0,\ldots,vW$, asking whether a model of $F$ has weight at most the threshold. Use a fixed sentinel for “no such weight.” The clipped Boolean replies produce a definite candidate $s_h$ even if they violate monotonicity. Off-range candidates can be discarded. Construct proper files by guessing the $v$ assignment bits, checking all clauses, and adding the integer weights in $O(v\log(v+2))$ Boolean gates or quasilinear deterministic checking time. All threshold files and all subsequent coordinate files are padded with legal whitespace to **one** constructible physical length $S=\widetilde O(n)$ for the source length. Choose the common envelope large enough for either kind of coordinate computation used below. One truthful row at $S$ suffices throughout this stage. A fixed initial segment of unsupported lengths can be hardwired or handled by exhaustive search. [Quasilinear construction of ordinary SAT queries](implicit-assignments-remove-length-advice-for-sat.md)

## One-sided error by checking a false clause

For each index $i$, row $h$ defines $a_h(i)$ by its answer to the question whether a model of weight exactly $s_h$ has bit $i$ set. When isolation succeeds, the truthful row delivers a satisfying assignment, coordinate by coordinate. Every other row still defines an assignment. To test each row, ask for a short index of a clause false under $a_h$. The nondeterministic verifier guesses a valid clause index and performs its at most three coordinate computations directly, generating the files and executing the fixed row $h$. Compile this verifier with an index prefix to proper SAT and pad all these questions to $L=\widetilde O(S+t(S))$. At $L$, try every candidate row and follow its prefix answers through the $O(\log n)$ index bits. Verify the final index directly. Discard $h$ exactly when some trial yields a real false clause.

On a NO input every assignment has a false clause, which the truthful row at $L$ will find. On a YES input a genuinely satisfying assignment can never be discarded. Accept iff a row survives. The cost, including constructing files, is $\widetilde O(K(S)K(L)(L+t(L)))$ for nondecreasing effective envelopes. The only randomness needed is for the weights. Independent repetitions reduce the false-negative probability.

## Bounded error at the original exponent

Use the uniform PCP for bounded nondeterministic RAM acceptance from Ben-Sasson et al. For a computation bounded by $T$, its honest prover given an accepting transcript runs in $T\,\operatorname{polylog}T$ time for a fixed machine. The verifier uses polylogarithmically many proof-bit queries, quasilinear time in the explicit instance for the parameters here, perfect completeness, and constant soundness error at most $1/2$ after a constant number of repetitions. The verifier uses $O(\log T)$ random bits per such trial. These are sequential work and query bounds. [Original construction, Theorem 1 and §5](https://eccc.weizmann.ac.il/report/2012/045/revision/3/download/) · [Explicit bit-query and randomness parameters, Theorem 6.9](https://eccc.weizmann.ac.il/report/2025/010/revision/1/download/)

Take the fixed RAM that verifies $x$ as a model of the explicit $F$. Its bounded transcript can be constructed from $(F,x)$ in $\widetilde O(n)$ time, by running the deterministic check and recording the registers and accesses. Fix an adequate power-of-two time bound $T=\widetilde O(n)$ and a deterministic honest prover, with canonical padding outside the proof. Denote its output on this transcript by $\pi(F,x)$. For each requested PCP position $i$ generate the ordinary file asking

$$
\exists x\quad F(x)=1,\qquad \mathrm{weight}(x)=s_h,\qquad \pi(F,x)_i=1 .
$$

The bounded verifier computes the entire honest proof from the guessed model, then reads the requested bit. Its quasilinear running time, including transcript generation, gives a quasilinear-length, quasilinear-work proper SAT compilation. Only the indicated answer is returned by the advised row. This query uses the same length $S$ as the weight thresholds.

Fix the weights first. For each remaining $h$, its claimed optimum and its answers to these coordinate files define **one fixed binary PCP string**. Even if the PCP verifier queries adaptively, equal positions use identical files, fresh solver state and the same $h$. The coordinate file contains no PCP verifier coins or previous query history. When isolation succeeds the honest $h$ supplies $\pi(F,x)$ for the unique optimum $x$, which passes every verifier trial.

Use two independent choices of weights. For each choice and each $h$ run $\lceil\log_2(12\max(1,K(S)))\rceil$ independent PCP tests on fresh coins. Accept if some row passes all trials for either weight choice. On a satisfiable input the probability neither choice isolates a model is at most $1/4$. On an unsatisfiable input, conditional on the weights, each fixed candidate string passes every trial with probability at most $1/(12K(S))$. The union bound over the two menus gives error at most $1/6$. The time is $\widetilde O(K(S)(t(S)+S)(1+\log(K(S)+1)))$. The random work includes the two weight arrays and fresh $O(\log T)$-bit strings for the verifier trials. No whole witness or PCP is produced by the uniform decision algorithm.

The argument gives an upper bound on uniform randomized time from an advised deterministic clock. It provides no unconditional elapsed-time lower bound for a correct SAT solver. Hirahara's selector framework addresses identifying a useful oracle from a menu with a trustworthy member. Historical priority for the quantitative SAT bounds here is unestablished. [Hirahara, *Identifying an Honest EXP-NP Oracle Among Many*](https://doi.org/10.4230/LIPIcs.CCC.2015.244)

## Two models defeat an input-independent list of weights

Fix $q$ positive integer weight vectors on $v$ data coordinates with entries at most $W$. If $2^v>(vW+1)^q$, two distinct subsets have the same tuple of $q$ sums. Remove their common elements to obtain disjoint supports $A,B$. Both are nonempty for $q\ge1$ because every weight is positive. Construct a formula whose two possible data supports are exactly $A$ and $B$. Use one coordinate of $A$ as the pivot, require every other member of $A$ to equal it, require each member of $B$ to equal its complement, and fix all other bits to zero. Turn these equalities and units into proper clauses with three shared anchors forced false by the seven clauses excluding the other three-bit patterns. The anchors have the same values in both models and are outside the $v$-coordinate count. If names are interned by first occurrence, introduce the anchors first, then each data name in order in a clause satisfied by a negated anchor and containing another distinct anchor.

Every listed weight ties the two models. Even an honest row answering whether some optimum has a specified bit set produces the union $A\cup B$, which violates a pivot constraint. The construction uses $O(v)$ clauses and $O(v\log(v+2))$ physical bits. At sufficiently large byte-aligned length $n$ choose $v=\Theta(n/\log n)$ with small constant, account for the three fixed anchor coordinates in the published menu, and pad the finished file to $n$ bits. This defeats every list chosen only from the length and coordinate count with $q=o(n/\log^2 n)$ and $W=n^{O(1)}$. The conclusion concerns a common list fixed before the file is chosen. Input-dependent weights can exploit the displayed equalities directly. General lower bounds for universal isolating weight families have a long history. [Chari, Rohatgi and Srinivasan, *Randomness-Optimal Unique Element Isolation*](https://doi.org/10.1137/S0097539793250330)
