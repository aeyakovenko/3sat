# Fast partial solvers on the two priority pins

Let $b_j$ and $F_{j,d}$ be the priority bit and the two locally indexable CNFs at scale $j$. The CNF is satisfiable exactly when $b_j=d$. Write $Z=\{j:b_j=0\}$ and let $a_j$ be the construction's nondecreasing computable upper bound on $|Z\cap[1,j]|$, of order $\log\log(j+4)$. Both $Z$ and its complement meet every infinite set of scales decidable in $o(2^j)$ native time infinitely often. Indeed, if one intersection were finite, a decider for that set, with the finitely many exceptions hardwired, could soundly signal the other color at infinitely many scales. All logarithms below are binary. [Priority construction and time bound](priority-pinned-sat.md)

Fix a binary programming system for the deterministic RAM with a common normalized word-width coefficient, a fixed instruction set, and a readable program text. A partial solver may return SAT, UNSAT, or unknown. On the promise it receives $F_{i,d}$, the scale $i$, and the pin $d$. Soundness means every definite answer is correct on every member of the promise. The solver need only give a timely definite answer on the instance being measured. One may instead impose a fixed public timeout on all invocations, with timeout treated as unknown. Code length includes embedded data. A fixed interpreter with an arbitrary binary parameter suffix permits literal comparisons with an $s$-bit string using $s+O(1)$ bits of code.

**Minority scales.** There is a fixed $C$ such that, for infinitely many $j\in Z$, on **each** of $F_{j,0}$ and $F_{j,1}$, every sound partial solver giving a definite answer within $t(j)=\lfloor 2^j/(j+1)^C\rfloor$ steps has code length at least
$$
\log j-\log(a_{2j}+1)-O(1).
$$
The bound still holds when different programs are chosen for the two pins. At every scale a promise solver of length $\lfloor\log j\rfloor+O(1)$ can compare the input scale with a hardwired $j$, use a hardwired correct bit upon equality, and abstain elsewhere. The latter test runs in polynomial time in the binary length of $j$ at the target. Both length estimates concern nonuniform choices of programs.

**Every default scale.** For every $j\notin Z$, a promise-sound program of $O(\log\log(j+4))$ bits answers correctly on both pins in $\operatorname{poly}(\log(j+2))$ target time. On a density-one set of scales an $O(\log\log\log(j+16))$ code length suffices. These programs can depend on the chosen scale. The original fixed-program lower bound applies at all sufficiently large scales to each particular sound program.

## Testing the ordinal of a prediction

In the block $2^k\le j<2^{k+1}$ put $A=a_{2^{k+1}}$ and $L=k-\lceil\log(A+1)\rceil-4$. An invalid program text gives no predictions. For a program $p$ and a fixed pin $d$, list the scales $i$ in increasing order at which $p$ gives the *minority verdict* on $F_{i,d}$ by time $t(i)$. This verdict is SAT for $d=0$ and UNSAT for $d=1$. The definition is syntactic and makes sense even for wrong programs. Cover every point of the current block that appears among the first $A$ entries of one of these lists for a text of length at most $L$. Earlier entries outside the block are counted in the ordinal.

There are fewer than $2^{L+2}$ program-pin pairs for large $k$. They cover at most $2^{L+2}A\le 2^{k-2}$ points in a block of size $2^k$. The set $H$ of uncovered scales is infinite. Membership at $j$ uses only invocations through $j$ and the explicit cap $A$. If $p$ is sound, all its minority predictions through $j$ occur in $Z\cap[1,j]$. Thus any such prediction at $j$ by a short sound program would cover $j$. The Lean companion proves the finite counting step for arbitrary overlapping prediction lists. [Lean counting argument](../lean/MinorityInstanceComplexity.lean)

Here is a uniform cost bound for deciding $H$, including texts that turn out to be wrong. There are $O(j)$ texts at scale $j$, each of length $O(\log j)$. For each earlier scale $i$ and each pin, simulate at its prescribed width $O(i+1)$ and generate the virtual formula words locally. The fixed-width interpreter can scan a whole short text for every instruction, decode its operands, mask a constant number of limbs, and use a sparse bank reset by its list of touched slots. All these operations have a common $O((j+1)^B)$ overhead for some fixed $B$ independent of the text. This uniformity uses a common width coefficient and instruction set. Polynomial setup, and the optional local-generator tables costing $2^{i/4}\operatorname{poly}(i+1)$, can be charged separately even if rebuilt for every trial. Hence all trials together cost at most
$$
O\!\left((j+1)^{B+2}\sum_{i\le j}
  (1+2^{i/4}+2^i/(i+1)^C)\right)
$$
after increasing $B$ to absorb setup powers. The sum of the last term is $O(2^{j/2}+2^j/(j+1)^C)$ by splitting at $j/2$. Choose $C>B+3$. This gives $o(2^j)$ on the native RAM. The prefix test requires no simulation of the actual priority-bit computation. [Virtual input access](packed-band-transfer.md) · [Native RAM conventions](native-unary-clock-band.md)

Consequently $Z\cap H$ is infinite. At each of its scales, both correct pin answers are minority verdicts. Membership in $H$ excludes every short sound solver for each pin, proving the stated bound since $2^{k+1}\le 2j$. Any globally sound SAT partial solver is sound on this promise, so the exclusion transfers in that direction. The matching upper bounds use the promise. On unrestricted physical inputs comparing a candidate formula with all generated words costs $O(N_j/\log N_j)$, already above $t(j)$.

## Short default programs

Choose $J=2^{2^m}$ minimal with $J\ge j$. At large $j$, $\log J<2\log j$. Put $r=|Z\cap[1,J]|$. For $j\notin Z$, the positive product $D=\prod_{z\in Z\cap[1,J]}|j-z|$ is at most $J^r$. There is an integer $h=O(1+r\log J)$ with $h\nmid D$. To see this, $\operatorname{lcm}(1,\ldots,s)\ge 2^s/(s+1)$ since every $\binom{s}{k}$ divides that least common multiple. For each prime, the factorial valuation formula gives at most one unit per prime power at most $s$, proving the divisibility. Taking $s=4(1+r\lceil\log(J+1)\rceil)$ makes the lower bound exceed $D$. Some $h\le s$ therefore fails to divide $D$. Such an $h$ divides none of the individual differences.

Hardwire $m,h,j\bmod h$. Upon receiving scale $i$, predict the default bit if $i\le J$ and $i\equiv j\pmod h$, and abstain otherwise. Every admitted scale lies outside $Z$. The code length is $O(\log(m+2)+\log(h+2))=O(\log\log(j+4))$, including delimiters. Comparing binary lengths implements the cap, and standard binary arithmetic on the small constants fits the promised target time.

For a density-one refinement, split scales into blocks $(2^{2^{m-1}},2^{2^m}]$ and set $P$ to the least power of two at least $(m+1)^2$. At most $a_{2^{2^m}}=O(m+1)$ residues modulo $P$ contain any exceptional scale in the block. On any remaining residue hardwire $m$ and the residue, test the block and low bits, and give the default. The code has $O(\log(m+2))$ bits. In any initial segment of length $u$ of that block, the contaminated classes occupy at most $O(u/(m+1)+m+1)$ points. Summing this estimate over complete blocks and the last partial block gives asymptotic density one for the admitted default scales. A short program for a given point depends on which residues actually contain exceptions.

## Error budgets and descriptions

With a public upper bound $E_k$ on erroneous minority predictions per pin through the block, replace $A$ by $A+E_k$ in the count and in $L$; the same proof works when that cap is efficiently computable and $L$ is nonnegative. Merely permitting each program finitely many errors gives no such uniform bound. In fact, for any computable nondecreasing unbounded $g$, write a program with parameter $m$ that computes a scale $J_m$ with $g(J_m)>2m$ and then waits at least $J_m+1$ further simulated steps. On input scale $i$, run that fixed computation from its start for $i$ simulated steps. If it has not finished, give a hardwired bit, else abstain. The computation eventually finishes, so either choice of bit has only finitely many erroneous scales. For a target $j$ with $g(j)\le j$, choose $m=g(j)$ and choose the correct bit. When $g(j)>j$, the one-scale comparison program already costs $O(\log(j+2))$ bits and runs in target time. Monotonicity implies $J_m>j$ for all large $j$. At that target this program answers in $\operatorname{poly}(j)$ time with $O(\log(g(j)+2))$ bits of code. The computation may use a fixed multitape model, one time-limited simulation at a time. Thus the minimum length in the finite-error model is $o(g(j))$ at every sufficiently large scale, for each computable nondecreasing unbounded $g$. A fixed finite-error program can still have all its exceptional scales patched out.

The exceptional scales also include indices with a gap between bounded and unbounded plain Kolmogorov complexity. On a fixed width-independent binary-output universal multitape machine, try every program of length at most $\lfloor\log j\rfloor-3$ for $\lfloor 2^j/(j+1)^3\rfloor$ steps. A native RAM can simulate each tape step directly at constant cost, with polynomial setup per text. The set of $j$ for which no such trial halts with the exact binary output $j$ is decidable in $o(2^j)$ native time and infinite by counting on dyadic blocks. Infinitely many of its members lie in $Z$. At each such $j$, the bounded description length is $\log j-O(1)$ or greater, while the unbounded plain description needs only the ordinal of $j$ among the recursively enumerable exceptions, hence $\log(a_j+1)+O(1)$ bits. Conversely, $Z$ meets the infinite set of power-tower indices, which is recognizable in polynomial time in the binary index length, so large bounded description length is not necessary at every exceptional scale. The scale itself is free metadata for the SAT solver.

Fortnow and Kummer's instance complexity also minimizes the length of consistent partial programs under a time bound. Their NP-hard-set result assumes the relevant separation from P; the priority promise here supplies a specific unconditional sublinear clock in the physical encoding. The advice bounds above neither shorten the CNFs nor contradict a solver running in time linear in their encoded length $N_j=\Theta(2^j(j+1)^3)$.
