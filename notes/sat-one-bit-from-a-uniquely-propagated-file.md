# SAT one physical bit away from a uniquely propagated proper file

For every ordinary DIMACS CNF $H$ of encoded length $N$, one can construct in deterministic $O(N+1)$ logarithmic-word RAM instructions two proper 3-CNF files $B_H,J_H$ of equal length $O(N+1)$ which differ in exactly one physical bit. The closed file $B_H$ belongs to the old-variable extensions in [the fast-face construction](any-circuit-on-a-fast-face-of-ordinary-sat.md). It has one model recovered by the same fixed support-mask and unit-propagation algorithm. Projecting the models of the edited file $J_H$ onto designated old-variable names gives a bijection with the models of $H$ on its occurring variables. All names in both output files belong to the original closed circuit construction, and every declared variable occurs. The result holds even if the easy file, its unique model, and the location of the changed bit are supplied together with the edited file.

First suppose $H$ has three distinct variable names per clause. Use the fast-face construction on $k$ inputs, all assigned 1, with zero gates and the last input designated as the output. Call the three initially false anchors $a,b,c$ in padding order and call the one-rail of the first input $p$. Every nonanchor clause of the original base contains the positive literal $a$, because all these clauses were originally binary or unary. Every gap below the largest identifier belongs to a distinct filler forced false on the closed file. Take $k$ large enough to have one filler $X_v$ for each occurring source variable and one additional filler $t_i$ for each distinct source clause. Thus $k=O(M+1)$ if the source contains $M$ distinct clauses. In the following formulas source literals stand for their signed $X_v$ counterparts.

Add four clauses equivalent to $p=\neg a$ by replacing each of $(a\lor p)$ and $(\neg a\lor\neg p)$ with its two proper ternary extensions using $b$ and $\neg b$. For every name $z$ outside the source fillers, clause fillers, anchors, and $p$, add $(\ell_z\lor b\lor c)$, choosing $\ell_z$ true in the closed base's known assignment. For each source clause $(u\lor v\lor w)$ add

\[
 (\neg a\lor u\lor t_i),\quad
 (\neg t_i\lor a\lor b),\quad
 (\neg t_i\lor\neg u\lor b),\quad
 (\neg t_i\lor v\lor w).
\]

All clauses are proper. Distinct source names are mapped to distinct fillers. Since $b=0$ in either mode, the first three clauses impose $t_i=a\land\neg u$. The last clause then enforces the source clause when $a=1$. On the closed file $a=0$ and all $t_i=0$, so every added constraint holds. The original base still forces the entire unique assignment. Supply the chosen assignment directly if requested.

Globally rename variables so that the ASCII identifiers of $a,p$ are respectively `2`,`3`. Change only the original anchor clause $(\neg a\lor b\lor c)$ into $(\neg p\lor b\lor c)$, flipping the low bit of a single digit. Since $p=\neg a$ holds unconditionally, this exchanges the row prohibiting $(a,b,c)=(1,0,0)$ for the row prohibiting $(0,0,0)$. The other six rows still prohibit all other triples. Therefore the edited file forces $(a,b,c,p)=(1,0,0,0)$. Every original nonanchor clause is now already satisfied. The additional pins fix every irrelevant variable, each $t_i$ is determined by $X_v$, and the remaining requirements say precisely $H$. All source assignments satisfying $H$ extend uniquely.

To charge the encoded length, delete duplicate clauses after sorting their signed, interned identifiers within each record. Intern decimal strings by a digit trie and perform three stable counting-sort passes on the dense signed identifiers. These steps take linear time including reading sparse or long names. Any $M$ distinct proper signed clauses require $\Omega(M\log(M+1))$ bits in total. For example, if all three names are at most $M^{1/3}/4$, then there are at most $8(M^{1/3}/4)^3=M/8$ such signed unordered clauses. For sufficiently large $M$, a positive fraction thus contain a name with $\Omega(\log M)$ digits. At most $3M$ variables occur. There are $O(M+1)$ constructed clauses and identifiers of $O(\log(M+2))$ digits. Printing, including the original anchors, dense renaming and the optional copied closed model, is linear in the source length. For $M=0$ take one closed input and no source ports; the additional pins leave exactly one assignment on each side.

## Wide clauses within the same bit bound

Here is the preprocessing for a general DIMACS CNF. Use base-two logarithms and take $h=\max(1,\lfloor\log(N+2)/32\rfloor)$ bytes. Scan the actual clause body, encoding each signed literal in its original canonical decimal spelling followed by one separator. Compress identical whole token sequences to one representative with a trie over this fixed alphabet. Normalizing whitespace, leading zeros when allowed, and line comments uses linear time. The total canonical token length of the retained representatives is $O(N+1)$. If $M$ distinct clause sequences remain, then $M\log(M+1)=O(N+1)$, since the number of strings of at most $j$ bytes is $O(256^j)$. Consequently $M\log(N+2)=O(N+1)$, by considering $M\le\sqrt{N+2}$ and its complement. The same argument bounds $V\log(N+2)$ for the number $V$ of occurring variable names. Intern names with a digit trie, so that arbitrarily long identifiers cost time proportional to their printed lengths.

Within each retained clause, put consecutive complete tokens into a group until the next would take the group over $h$ bytes. A token longer than $h$ forms a group alone. The total number of groups is $O(M+N/h)$: any consecutive pair of ordinary groups in a run consumes more than $h$ bytes, and each long singleton or clause boundary starts at most one new run. A short group has one of $O(256^h)$ possible byte strings. Build a binary OR circuit for a short group only on its first occurrence, and cache its output for every subsequent occurrence. The total number of gates inside all these shared groups is $O(256^h h)$. A long singleton already denotes one signed source variable. Combining each clause's group outputs with binary ORs and requiring its final output true takes $O(M+N/h)$ further gates and requirements.

Tseitin's two implications for each binary gate determine its value uniquely from its inputs. Reduce repeated literal occurrences within the resulting clauses and drop tautological clauses. Pad binary and unary constraints by one or two fresh, always-false names from an independently pinned triple of anchors. An empty source clause gives one false constraint, implemented by the disjunction of the three false anchors. Include a true ternary clause $(X\lor\neg a_0\lor b_0)$ for each source variable $X$ with two of these false anchors. This preserves the occurrence of variables in tautological clauses. Equivalently, simplify a gate with equal inputs to its input and one with opposite inputs to the true constant before emission. Each assignment on the occurring source variables extends uniquely precisely when it satisfies $H$.

Use consecutive names in this intermediate formula. The number of printed constant-width clauses and variables is $O(1+V+M+N/h+256^h h)$, and each identifier costs $O(\log(N+2))$ bits to print. Thus both the total output length and the deterministic time are $O(N+1)$. Short group keys can be retained in a character trie charged to the input scan. Construction of the first representative's gates and decimal printing is covered by the displayed bound. More than one clause can reuse a short group's output. Lemma 2.1 of the cited preprint discusses the parsimonious gate encoding with a literal-occurrence length. Here the additional grouping calculation charges each decimal auxiliary name in the emitted DIMACS file. ## Consequence for an online choice of witness

This embeds ordinary CNF SAT in a fixed one-bit perturbation of the preceding tractable promise. An online constructor can keep both files available until the solver first reads the changed input word. A solver can read that very word at the beginning when its position is supplied. If two-phase preprocessing plus answering the edit took linear total time uniformly on these pairs, composing with this reduction would give linear-time ordinary CNF SAT. The cost of deciding the edited file remains open.

For $k=1,2,3$ the equivalence can be made pointwise on both verdicts. If a correct solver has an $O(N^k)$ bound on just the satisfiable edited outputs, use the reduction, run the solver up to that bound and return UNSAT on timeout. This is a correct $O((|H|+1)^k)$ decider for ordinary SAT. An analogous rule defaults to SAT when the solver is fast on just the unsatisfiable outputs. Thus if ordinary SAT escapes that exponent, every correct solver exceeds every fixed multiple of $N^k$ on edited files of each verdict at unbounded lengths. Choose a solver with the linear propagation front end on the closed neighbors. On any edited run longer than the clock on its particular closed neighbor, it must read a word containing the modified bit by the end of that closed clock; otherwise both deterministic runs would already have halted together. Even if the bit is overwritten before it is read, the two states would coincide permanently. On these long runs all but $O(N)$ steps therefore occur after a read that can distinguish the two inputs. This equivalence localizes the required cost without assuming that any of these long runs exist.

Burjons, Frei, Hemaspaandra, Komm and Wehner construct a different SAT reduction in which *every* one-clause deletion comes with a polynomial-time computable model. Their Theorem 1 concerns clause-deleted neighbors. The construction above tracks a single physical bit, native linear overhead, uniqueness on the closed side, and model counts on the edited side. Priority for the combination of these parameters is unestablished. [Finding Optimal Solutions with Neighborly Help](https://doi.org/10.1007/s00453-023-01204-1)
