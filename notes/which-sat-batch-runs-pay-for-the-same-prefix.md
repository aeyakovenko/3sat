# Which SAT batch runs pay for the same prefix?

For an OR of independent SAT instances take an all-unsatisfiable input. For an AND take an all-satisfiable one. Call each component's value on such an input *neutral*. Given a deterministic solver, an adversary can pick one neutral and one opposite instance per component so that a single box of $2^k$ complete inputs forces the bounds below. They concern genuine computations, including computations on mixtures of the independently chosen alternatives.

Suppose one input-word read sees private data from at most one component. Shared words may contain fixed public data. Domains may be arbitrary finite promise sets of physical word arrays, with both verdicts present in every component. Write $D_i$ for the optimal worst-case deterministic word-query depth of component $i$ on that domain, measured at the **batch** word width, and sort these depths as $D_{(1)}\le\cdots\le D_{(k)}$. For any box let $X_S$ use the opposite input exactly in the components indexed by $S$. In the decision-tree model the following value is exact, for every $0\le s\le k$:

$$
\min_A\ \max_{\text{box}}\ \sum_{|S|=s} Q_A(X_S)
=\sum_{j=1}^k D_{(j)}\binom{k-j+1}{s}.
$$

Here $A$ must decide the entire product domain, $Q_A$ counts probes, and an out-of-range binomial coefficient is zero. The same algorithm attains all upper bounds. For any given algorithm one box gives all lower bounds at once. If $D_i=D$, the neutral run uses at least $kD$ probes and the $s$-th opposite layer uses at least $D\binom{k+1}{s+1}$ probes in aggregate for $s\ge1$. All lower bounds apply to executed RAM steps in the single-input-load convention. The minimax equality charges only word probes. General deterministic direct sums and composition in the query model are classical. [Jain, Klauck and Santha](https://arxiv.org/abs/1004.0105) · [Montanaro](https://arxiv.org/abs/1302.4207)

## Choosing one box after observing a single run

Run a separate adversary on each component. Its state is the set of locally possible inputs; the potential is the exact decision-tree depth on that set. At potential greater than one, any requested word has a nonempty answer class with residual depth at least the old depth minus one. Otherwise that word followed by optimal trees would improve the old depth. A positive-depth class has completions of both verdicts. At depth one choose any reply allowing a neutral completion; once the residual function is constant, preserve that neutral value. The independence of the domains makes all these replies consistent on one genuine neutral tuple. On a deterministic RAM the adversary answers only actual first reads of unknown data, respecting repeated reads and any previous writes.

Let $r_i$ be the probe at which component $i$ first becomes forced neutral. Each component reaches this point before the solver halts, since while any residual is nonconstant there are opposite batch verdicts compatible with the whole transcript. For component $i$, pick an opposite input still possible immediately before $r_i$. It agrees with every earlier local answer. The neutral representatives can be chosen at the end of the run. Consequently each $X_S$, $S\ne\varnothing$, follows the very same genuine machine prefix through the issue of the probe at $\min_{i\in S}r_i$.

In order of resolution $\pi_1,\ldots,\pi_k$, the probe at $r_{\pi_j}$ comes only after charging at least $\sum_{\ell\le j}D_{\pi_\ell}$ probes including that one, since each charged component lost all its initial potential. There are $\binom{k-j}{s-1}$ subsets whose first switched component is $\pi_j$. Summing their common-prefix bounds gives $\sum_jD_{\pi_j}\binom{k-j+1}{s}$. The coefficients decrease, so putting the smallest depths first minimizes this expression. For $s=0$ just sum the potential losses. Conversely, evaluate optimal component trees in order of increasing $D_i$, stopping at the first opposite verdict. On every box and subset its query count is at most the sum of depths through the first switched block, or all depths at the center. This proves equality, including the simultaneous claim.

In particular, the neutral file and the file switching only $\pi_k$ have opposite verdicts and both issue at least $\sum_i D_i$ probes. The first differing reply on this pair arrives only after the program has paid that whole sum through the issue of the distinguishing probe.

On *every* neutral execution there is a separate input-specific statement. The observed private words in each component certify its verdict within that promise domain. An opposite instance agreeing with all those words would give the opposite batch verdict by changing just that component while preserving the whole execution. The per-component minimum word certificate sizes therefore sum to a lower bound on executed steps on that particular file.

## After a component's last read

Fix any such box, even one chosen independently of the program. In each component let $t_i$ be the last native instruction in the neutral run that reads a word differing between its two representatives. Each $t_i$ exists by correctness and is distinct from the others. Write $T$ for the neutral running time. Use complete **private** configurations, including registers, control, halt verdict and all work memory. Immutable input contents are external. For a writable-input RAM the equivalent representation is its underlying input and a private map of writes, initially empty. Include observable clock values if the instruction set supplies them.

For every nonempty $S$, no configuration on the neutral run from immediately after $\max_{i\in S}t_i$ through its halt occurs **at any time** on the run on $X_S$. If the configurations matched, the entire remaining neutral suffix would replay from the matching state. Every original input word needed by the suffix is identical on the two files, so the final verdict would agree. Thus even arbitrary realignment of the two sequences must delete at least $T-\max_{i\in S}t_i+1$ neutral configurations. Sorting the distinct last instructions and summing gives at least $\binom{k+1}{s+1}$ such deletions for each $s\ge1$. This statement measures full private configurations; a single differing cell can persist through a long sequence of matching instruction records.

## A word-linear native control

In proper ASCII DIMACS, force names $1,4,5$ false with the seven clauses excluding the nonzero triples. Force name $2$ false and $3$ true by padded units. Pin $u_0$ true and $u_k$ false, where $u_i$ has name $6+i$. For $1\le i\le k$ print the proper clause $\neg u_{i-1}\lor u_i\lor q_i$, with $q_i$ the positive literal named $2$ or $3$. The all-$2$ chain is inconsistent. If a nonempty subset switches to $3$, take the variables through the first broken implication's left endpoint true and all later variables false. This is an OR of $k$ independent editable bits with a single physical-bit edit per switch.

Put $\Theta(\log(k+2))$ bytes of public whitespace at the end of each chain row, with a sufficiently large constant for the fixed logarithmic-word RAM. The $k$ differing digits then occupy distinct input words. Encoded length is $\Theta(k\log(k+2))$ bits. One fixed globally correct solver handles this whole family in $O(k)$ steps: recognize the prescribed template wordwise, accumulate the OR of the $k$ varying digits, and send unrecognized files to a correct fallback. The program derives $k$ from the checked header and bounds it against file length before allocation. Consecutive decimal names can be emitted in a constant number of packed words with a decimal odometer; carries cost $O(k)$ digit updates in total. Comparing the clauses and the prescribed whitespace touches $O(1)$ words per row, including unaligned endpoints. Initial header arithmetic costs polylogarithmically many steps. [Packed decimal construction](dense-sorted-cores-for-ram-exhaustion.md)

Here the singleton layer forces $\Omega(k^2)$ genuine elapsed time *summed across the $k$ opposite files*, while all files have a word-linear solver. In the promise probe model a single scan stopping at the first changed word attains the exact coefficient on every layer. The finite audit enumerated all 104 reduced query-depth profiles for one unequal-depth example and found the predicted optima $(4,7,4,1)$. Direct assignment enumeration on 62 proper chain files checked the OR and the distinct-word condition. [Reproducible audit](../audits/neutral_batch_audit.py)

Fixing neutral siblings gives a uniform one-instance algorithm if the siblings and the physical layout are uniformly constructible. That algorithm still pays for the batch program's intervening operations. A specialized decision tree can erase probes whose answers it already knows because it charges no internal work. Existence of a small timetable of private reads does not supply a native program that constructs or jumps over those intervening operations in the same time. OR-compression also measures the size of a computed instance, and its obstruction has complexity-collapse hypotheses. The unrestricted SAT milestone still needs a lower charge beyond the number of input words on an individual run. [Fortnow and Santhanam](https://www.sciencedirect.com/science/article/pii/S0022000010000917) · [Drucker](https://doi.org/10.1137/130927115)
