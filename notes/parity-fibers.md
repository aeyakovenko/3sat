# Can relative output facts on short parity inputs rule out linear SAT?

**Research journal, 24 November 2026.** Consider all inputs with a public prefix and a logarithmic suffix. A parity on the suffix has a description of only logarithmically many bits, even if the public prefix is nearly the whole input. On each such family one can diagonalize against subquadratic RAM predictors. To use linear SAT it would suffice to certify a few linear constraints on which parity each predictor could equal. Certifying correlations between two outputs can work even when neither output bit is available separately.

## A polynomial-time language that is a parity on every fiber

Let ℓ=⌊(log₂ n)/8⌋, M=2^ℓ, and g=⌊(log₂ ℓ)/2⌋ for sufficiently large input lengths n. Split the n bits as a prefix a and a suffix z of length ℓ. Enumerate the valid program descriptions of length at most g in a decidable prefix code for deterministic logarithmic-word RAMs. There are h≤2^g such descriptions, by prefix-freeness. For each description i, simulate its computation on az up to T=n² *universal simulation steps*, taking the default bit zero on timeout or malformed output. Write pᵢ(a,z) for the resulting bit. Use a fixed sparse-address interpreter with polylogarithmic overhead per step for each fixed target, encoding its word-width constant in its description. Thus the rows eventually include every fixed n^{2−ε}-time RAM with its actual verdict for every fixed ε>0. Iterating the capped interpreter is polynomial time even for the varying descriptions. [RAM interpreter convention](sparse-lengths.md)

There is a fixed ordinary P language with a slope sₐ∈𝔽₂^ℓ at every prefix a, whose answer on az is sₐ·z, such that for all sufficiently large n, every a and every listed i,

    | Pr_z[pᵢ(a,z)=sₐ·z] − 1/2 | ≤ (1/2) √(2h/M).

Compute the rows on all M suffixes. For each i the Walsh sums Cᵢ(s)=Σ_z (−1)^{pᵢ(a,z)+s·z} satisfy Σ_s Cᵢ(s)²=M² by orthogonality of the binary characters. Fewer than M/(2h) slopes per row have squared sum greater than 2hM. Select the first slope avoiding all those sets; direct enumeration still takes polynomial time. Choose the zero slope if h=0. This gives a single P language that is individually linear on *every* public fiber and has agreement tending to one half with each fixed n^(2−ε)-time predictor on *each* fiber. The test below can use any suitable slope and need not recover this particular first one. Walsh list bounds have long been used in computational hardness amplification. Li and Tell recently studied average-case linear-time alternating simulations of P under additional hypotheses. [Goldreich and Levin](https://doi.org/10.1145/73007.73010) · [Li and Tell](https://eccc.weizmann.ac.il/report/2026/233/)

## Obtaining a slope from relative facts

Suppose a uniform verifier on (a,i,u,b), with u∈𝔽₂^ℓ and b∈𝔽₂, designates equations u·s=b. It may use an explicit circuit with any fixed number of Boolean quantifier blocks, of encoded size and uniform construction time at most n^(3/2). On the particular prefix a call its equations **sound** if, whenever pᵢ(a,z)=s·z for *every* z, all the equations for that i hold for s. Nonlinear rows impose no soundness obligations. Write Aᵢ for the affine solution set of the designated equations, possibly empty. If it is nonempty with equation rank rᵢ, its fraction of the slope space is 2^(−rᵢ).

An unconditional exclusion of linear SAT would follow from **one such verifier** for which, at unboundedly many n, at least one prefix a has sound equations and ⋃ᵢ Aᵢ omits some slope. A sufficient test is Σ_{i:Aᵢ≠∅}2^(−rᵢ)<1. By Kraft, it suffices that each consistent row have rᵢ≥|i|+1. In particular the required number of independent observations for a *fixed* predictor is constant, irrespective of n. The ranks of other rows may compensate for a lower rank as long as the union leaves a slope.

Indeed, if linear SAT holds, a fixed deterministic program D can recover every designated equation on a by h·2M fixed-block queries, each costing n^(3/2)polylog(n). It tests slopes by direct enumeration and chooses an absent slope s*, using a default if the union fills the space. It returns s*·z. The time is n^(13/8+o(1)), so this actual program appears as a timely row for all sufficiently large n. On every proposed prefix its row is exactly the selected parity. Soundness puts s* in its own Aᵢ. This contradicts selection outside the union. All costs use unrestricted RAM space. [Fixed-block simulation under linear SAT](linear-quantifiers.md)

There is an exact sparsity bound for this selection. One may always select an absent slope with Hamming weight at most h. Start with any absent point and, for each nonempty flat, select one defining equation it violates. Impose the opposite right-hand side for each of these at most h equations. The system has the starting point as a solution. Gaussian elimination supplies a solution supported on at most its rank in pivot columns, still outside every flat. The bound h is attainable even when the sum of the flat fractions is at most one half. Use h disjoint coordinate groups of width d=⌈log₂(2h)⌉ when ℓ≥hd. The ith flat sets its entire group to zero. Its measure is 2^(−d), and every slope outside all the flats has a one in each of the h groups. Thus the counterpredictor can be required to use at most O(√log n) nonzero suffix coefficients. For a nonlinear forbidden set containing every slope of weight at most h, every multilinear polynomial of degree at most h vanishing on it is identically zero, by evaluation on that Hamming ball. Extending the sparsification to arbitrary nonlinear sets would require another hypothesis. [Hamming-ball coefficient recovery](exponent-transfer.md)

## Occasional unsound equations

The tests can also use an ℓ-bit public challenge d. Write Aᵢ,𝒹 for the resulting affine sets. On a prefix a let εᵢ be the fraction of challenges on which the genuine slope is absent if row i is a parity, and zero if it is nonlinear. It suffices, along some choice of one prefix at unboundedly many lengths, to have both

    Σᵢ E_d[|Aᵢ,𝒹|/M] < 1/2,          Σᵢ 2^(−|i|) εᵢ → 0.

For each i keep the slopes occurring on at least half the challenges. The fraction kept is at most twice the mean flat fraction. The union therefore misses a slope. D can tabulate the equations with one extra M factor, taking n^(7/4+o(1)) time including the slope tests. Its own fixed row has εᵢ→0 by the positive fixed Kraft weight; its selected slope must be kept. This contradiction allows a verifier to make false claims on unidentified program–challenge pairs. The sparse-slope bound above is for the individual affine flats. The majority sets in this variant can be nonlinear.

## Equations across exponentially many prefixes

There is a way to remove the requirement that the programs reveal information on the same short parity domain. Split each input as abz, with |a|=⌊n/2⌋, |z|=ℓ and b using the remaining bits. For fixed n,a a slope array S has one entry S(b,r) for every b and every suffix coordinate r. There are exponentially many entries. The parity at index b is Σᵣ S(b,r)zᵣ modulo two.

A certified equation may now specify a **succinct** binary mask U(b,r) and a right-hand bit c. Allow descriptions of length at most n^(3/2) with a fixed evaluation procedure taking n^(3/2)polylog(n) time on one coordinate. Admission of a description for program i, given a, still uses a fixed-block check of the previous size. Soundness for i now says that if its row is a parity in z at every b, its resulting array satisfies every admitted equation. An equation can compare outputs at entirely different indices. A certified violation of linearity at any single b permits designating an inconsistent equation for that program.

The same missing-flat criterion suffices for this exponentially large space: if for some a at unboundedly many n the systems are sound and their affine solution sets fail to cover all arrays, linear SAT is impossible. In particular the same Kraft rank condition suffices. Each i may derive its equations at indices of its own choosing. For example a program can use arbitrary long preprocessing to compute ℓ unknown slope bits and reuse them at two indices. Certifying this reuse supplies ℓ independent equations although neither individual slope is constrained.

To prove the criterion, restrict candidate arrays to at most h nonzero entries by the sparsification theorem. Encode one by a normalized sorted list of up to h coordinates, each taking O(n) bits. Testing a purported equation on the list takes at most h mask evaluations. The predicate that a list escapes every flat is a fixed-block test: for every valid i there is an admitted equation violated by the list. D selects the lexicographically first escaping normalized list. On a query abz ask whether some escaping list gives parity one there and every earlier valid list fails to escape. This adds a fixed number of blocks and defines a single array on all b. If no list escapes, the queried value defaults to zero. Under linear SAT the resulting time is n^(3/2+o(1)), including the RAM encodings. On a favorable prefix its own listed program is a parity at every b, so its actual array is in its own flat, contradicting selection. No exponential table is written.

Sparse selection and noisy challenges do not automatically combine. In a D-dimensional slope space let each challenge choose r uniformly random distinct coordinates and require zeros there. Every resulting flat has fraction 2^(−r), but every weight-h slope passes with probability at least 1−rh/D by a union bound. When 2rh<D, every such sparse slope belongs to the majority set of this single family. This identifies a precise difficulty for certificates that assert zero on random, apparently inactive indices.

## What can certify an equation?

A verified difference pᵢ(a,z)⊕pᵢ(a,z′)=b supplies the equation with u=z⊕z′. For a program that accesses the suffix through adaptive affine probes, one authentic completed probe path gives a whole family of such facts. Let W be the span of its queried linear forms, ignoring constant offsets. Perturbing its suffix by any y∈W^⊥ preserves all answers inductively and therefore preserves the output. If the row is a parity, its slope lies in W. Thus a certified upper bound on the queried span on just *one* path can supply ℓ−dim W independent equations without revealing the output. The same proof works with arbitrary RAM preprocessing of a and with data-dependent choices of the next linear probe. On the ordinary RAM a load exposing a suffix word can reveal all its constituent coordinates, so this mechanism gives no automatic codimension for general programs.

Full replay can recover a true row's slope by testing the ℓ standard basis inputs and can designate that singleton for every row, even if the row is nonlinear. The resulting equations always have a slope on the outside for large n. But certifying a single completed T-step RAM run this way uses T·polylog(n) encoded bits. Selecting the slope with these tests need not run fast enough to be among the simulated rows. A program can also spend Θ(T) universal steps on prefix-dependent work before it reveals which suffix coordinates matter. The unresolved step is a sufficiently cheap verifier of compatible relative facts for those rows on even one common prefix at infinitely many lengths.
