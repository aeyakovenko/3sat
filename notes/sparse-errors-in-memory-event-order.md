# How many rows of a SAT solver's memory history can be out of order?

Fix a deterministic logarithmic-word RAM deciding ordinary ASCII DIMACS SAT, with unrestricted writable workspace. On the dense 3-SAT projection of list distinctness, consider the permutation that sorts all memory events by bank, address and time. There is a quantitative obstruction to predicting that permutation, even allowing some of its rows to be arbitrarily misplaced. It applies separately to accepting and rejecting runs.

Let \(n\) be the encoded bit length, \(w=\Theta(\log n)\) the RAM word width, \(T\) a polynomially bounded proposed deadline, \(m=\lceil n/w\rceil+O(T)\) the number of rows defined below, and \(g(w)\) the Boolean cost of one deterministic processor step given its load replies. Fix a target verdict and a predictor of size \(s\) that always permutes its supplied rows. Its inputs and preservation requirement are specified below. A fixed permutation of the time slots is a predictor of size zero, since it is just rewiring. Let \(0\le r\le m\).

If **every** projected input with the chosen verdict halts by \(T\) and the predictor puts at most \(r\) rows in the wrong positions on each of those runs, then
\[
 n+Tg(w)+mw+s+r w\log_2(r+2)
       =\Omega\!\left(n w^\sigma\right).
\]
Here \(\sigma>0\) is supplied by Theorem 2.2 of the November 24 matrix multiplication preprint over \(\mathbb F_2\), and may be decreased to be less than one. The bound holds at every sufficiently large byte-aligned encoded length for the padded projection. The estimate on the left is a bit cost for a verifier. All steps in \(T\) are native word steps. [Preprint theorem used](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/build/obstruction.tex#L1-L79) · [List projection, length padding and verification of its source theorem](checking-the-sat-circuit-bound.md)

For example, suppose \(T=O(n/w)\), \(g(w)=w^{1+o(1)}\), and \(s=O(n)\). Then for each target verdict and each predictor, some projected input of that verdict either takes longer than \(T\) or puts at least \(\Omega(m/w^{1-\sigma})\) rows in wrong positions. Indeed \(m=\Theta(n/w)\), the base cost is \(o(nw^\sigma)\), and \(\log_2(r+2)=O(w)\). If a solver halts by the deadline throughout, the distance conclusion holds on each side. The fraction can vanish with \(w\). A single transposition, regardless of how far it moves the two rows, contributes two errors.

## A sparse test for row multiplicities

For two arrays \(P,B\) of \(m\) complete rows, mark all positions where their rows differ. If both arrays have the same multiset on the marked positions, they have the same multiset everywhere, and conversely. The unmarked copies cancel with multiplicities. Compute these marks deterministically. Compact the marked rows at the front of each array, carrying a mark bit and the entire row as payload. Check that at most \(r\) were marked. In the first \(r\) slots on each side, normalize every unmarked entry to a fixed inactive symbol. Sort these two length-\(r\) arrays by their full tagged contents and compare them. For \(r=0\) simply test that no mark is set. Full-row comparison prevents a forged record with a genuine time stamp and an altered word from passing.

Asharov, Lin and Shi's Theorem 1.2 gives deterministic 1-bit-key compaction with \(O(mw)\) bounded-fan-in Boolean gates for this payload width. Each row fits in \(O(w)\) bits and includes a slot identifier of \(\lceil\log_2(m+1)\rceil\) bits. Padding to this width meets their stated logarithmic-payload special case. Stability within a marked group is unnecessary, as the small arrays are sorted afterwards. An AKS network uses \(O(r\log(r+2))\) comparators, each costing \(O(w)\) Boolean gates for these rows. The marks, the overflow check, the normalization, and input copies are included in \(O(mw+r w\log(r+2))\). [Asharov, Lin and Shi, Theorem 1.2](https://arxiv.org/pdf/2010.09884#page=4) · [Ajtai, Komlós and Szemerédi](https://doi.org/10.1145/800061.808726)

## Unique certificates for the bounded runs

The projected input consists of \(N=2^k\) records of \(2k\) bits. Its physical 3-SAT serialization has \(n=\Theta(Nk)\) bits, obtained by copying bits and setting constants. A duplicate gives a satisfiable formula, and an all-distinct list gives an unsatisfiable one. Pack these physical bits in \(\lceil n/w\rceil\) public words, pinning unused tail bits. Reserve one initializer row for each public word, with fixed bank, address and initializer ID and the actual word as payload. In a unified RAM image the initializer is an ordinary initial write to the affected address. In a read-only input bank CPU checks forbid later stores to that bank. Initial writable words at all other addresses are zero. A model returning zero at out-of-range input reads uses that convention. Any length register or header outside the image is fixed by the machine's initialization. [Actual DIMACS encoding](checking-the-sat-circuit-bound.md#3-a-projection-to-dense-decimal-ascii-3-sat)

Give each of the \(T\) steps its fixed number of ordered access slots. Guess one reply word per slot. The circuit simulates the fixed-register CPU from its initial state, feeding it the guesses on reads. Require zero guesses for writes, idle slots and padding following halt. An active slot emits its bank, address, unique position, operation, and the word read or written. Initializers precede all native accesses. Give every idle slot a distinct ID, an idle tag, and zero for unused fields. Count every initializer and slot in \(m\). Require the simulated processor to halt at the chosen verdict within \(T\).

Write \(A\) for these chronologically wired rows and guess another array \(B\). Check that \(B\) is in strict canonical order, with active records ordered by bank, address and time, followed by idle records in ID order. A scan along the wires of \(B\) checks memory consistency. At a bank/address change the incoming word is zero. An initializer or native write replaces it by the carried word, and a read must equal it and leaves it unchanged. Idle rows have no memory effect. Physical bank checks come from the CPU and the initializer generator. These gate chains can have linear depth and cost \(O(mw)\) gates.

The predictor is an arbitrary fixed bounded-fan-in circuit for this length. It receives \(A\), and may additionally inspect the input bits, the read guesses and \(B\) itself. It must output a permutation \(P\) of \(A\) **for every assignment** to these inputs, including fabricated transcripts. For instance, deterministically controlled swap networks meet this requirement even with controls depending on \(B\). A fixed ordering can be chosen nonuniformly at each length and separately for either target verdict. Apply the sparse multiset test to \(P,B\). Its success ensures that \(B\) contains exactly \(A\) with multiplicities. The predictor's promise on fabricated rows is needed at precisely this point.

By induction over the native slots, each successful read guess is the actual word left by the last write or the physical initialization. The CPU check therefore reproduces the deterministic run. Its chronological rows have unique IDs, hence its sorted table \(B\) is uniquely determined. Conversely the genuine read replies, zeros on unused slots, and genuine sorted table pass all the checks exactly when the target verdict occurs by \(T\) and the predictor meets the radius. This remains true when the predictor reads \(B\). The score on a genuine run uses that run's unique sorted table.

## From the verifier to the list tensor

Represent each deterministic Boolean verification gate by its truth tensor, and copy wires by trivalent equality tensors. For fixed list bits, summing over the reply and table guesses returns the number of passing witnesses in the field. The preceding argument makes that integer zero or one. The \(O(mw)\) guessed bits, the \(O(n)\) input projection and the gate and wire counts are included in the displayed size. With rejection as target, this contraction directly computes distinctness under the coverage hypothesis. With acceptance as target, introduce a selector bit. On one branch require every witness bit to be zero and contribute \(+1\). On the other require a passing verification and contribute \(-1\). Each branch uses deterministic gate evaluation; the first branch does not constrain the unused verdict. Summing gives one minus the duplicate indicator even in characteristic two. Thus the trivalent tensor computes list distinctness. Applying the source volume bound proves the inequality. Merely knowing a lower bound for deterministic Boolean decision circuits would not justify this step.

The estimate permits an arbitrary SAT solver to run for \(O(n)\) native word steps, or to produce distant event orders already at \(O(n/w)\) steps on this projection. The raw list problem itself has a linear-in-records deterministic RAM algorithm. A failure to predict its physical event order imposes no extra native instruction on that algorithm. No historical priority claim is made for the sparse verifier. [RAM algorithm and previous candidate-writer test](matrix-list-unit-sat.md#testing-the-transfer-on-a-ram)
