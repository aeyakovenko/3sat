# Selecting a sound stream of local computation records

**Research journal, 2026-11-24.** To certify acceptance, a one-pass filter may discard as many valid runs as it likes. It suffices that some locally realizable stream passes, and that all locally realizable streams passing the same filter agree on the transmitted bits. Here agreement means equality between the two copies of each bit **within** a stream. Different passing streams can carry unrelated values. Under linear SAT this gives a conditional lower bound on the sum of filter description and scratch space for an actual unary hierarchy language.

## Two reachability tests with the same filter

Use the block-respecting tape verifier and visit ledger from the partition construction. For input length n, an epoch lasts b steps and there are at most B epochs. The ledger contains controls, positions and boundary motions in chronological order. It determines the two endpoint epochs and ports of each transmitted block word. A prover also supplies a permutation giving the order in which to stream the B epochs. Validate both, including initial and accepting controls. One can produce the checked incident-edge identifiers, first-visit flags and permuted ledger by sorting in Õ(B) time when the run length is polynomial in n. Their total description is O(B polylog(n+2)) bits. [Ledger and local gluing proof](tape-partitions.md)

The record at an epoch supplies its incoming and outgoing words at the labeled ports. A local generator guesses the entering words and an internal nondeterministic run, simulates the b steps, and checks the prescribed controls, motions and initial words on first visits. It emits the incoming and outgoing words of that local run. Adjacent epochs need not yet agree on an edge word. From one epoch to the next the generator needs only the public ledger, the stream cursor and O(b+log n) bits of workspace for local simulation and buffering. Output conditions on last visits, if present, are checked locally. Assign a fixed binary encoding to tape symbols.

Guess an S-bit program F for a one-pass nondeterministic filter. It may inspect the original input and checked ledger read-only. Its stream head can pause, advance or read the end marker. It cannot revisit a discarded symbol. Specify a fixed interpreter with a constant number of work tapes. For a given scratch cap R, count all mutable filter storage, including its work-head positions and finite program state, or allow O(log(n+S+R+U+2)) bookkeeping for the fixed interpreter. Count a stream as passing when some branch reads to its end and accepts within R bits and U steps. The certificate may choose these caps under the announced upper budgets. They are part of the fixed data for both tests.

1. Test bounded nondeterministic reachability of an accepting state of the product of the local generator and F. This asks whether a locally realizable passing stream exists.
2. Test bounded nondeterministic reachability in the same product augmented by a monitor. The monitor guesses a public edge and one bit offset in its word before generating the stream. It records which of zero and one occur at its two specified endpoint ports. It accepts together with F only when both occur. Require this second product to have **no** accepting path.

The records in the two searches can differ. The second search is free to choose *any* passing stream, local choices, filter choices and mismatching bit. Its failure makes every stream certified by the first search consistent on every edge. Choose such a stream, restore chronological order, and concatenate the local runs using the agreed words and ledger controls. This produces a legal accepting run. Conversely, every nonempty subset selected by F among the local streams, all of whose members are consistent, passes both tests, even if F admits other streams that cannot be locally realized. This is the usual language-intersection emptiness test for a bad property, with a separate nonemptiness requirement. Lean checks the two-endpoint monitor in arbitrary stream order and the logic of the two searches. [Vardi and Wolper on verification by language intersection](https://spinroot.com/spin/Doc/lics86.pdf) · [Lean proofs](../lean/StreamFilter.lean)

## Cost on the unary hierarchy verifier

Fix H★ in NTIME(n¹²) outside NTIME(⌊n¹²/log₂(n+2)⌋) on unary inputs, with its fixed verifier at b=n and B=O(n¹¹). Fix any polynomial upper bound nᵏ on U. Write Q≤n¹² for a constructible cap on S+R. This range suffices for the lower bound below. In each product the input and full read-only data use O(n+B polylog(n+2)+S) bits. A configuration uses O(b+R+log(n+Q+U+2)) further bits. The violation monitor stores just indices and two flags. A fixed multitape interpreter can scan the read-only program or ledger to perform an access, charge the scan to its own step count and retain only the index. The total time cap of each product is polynomial in n+B+b+Q+U, including all record generation. The original step and scratch limits for F still apply inside it.

Under linear SAT the bounded-reachability theorem therefore decides either product in unrestricted deterministic RAM time at most

    (n+B+b+Q) · 2^{O_k(√(log n · log log n))}.

Here and below n is sufficiently large, with fixed polynomial degrees for the budgets. Polylogarithmic factors from input encodings fit in the multiplier. The common existential choices of the ledger, order, F and caps add only polylogarithmic overhead. Indeed, guess them once, validate the public structures and run both deterministic tests on those same data, checking their required opposite verdicts. This bounded nondeterministic computation has a quasilinear explicit SAT reduction, followed by the hypothesized linear solver. In particular the validation does not enumerate the B·b symbols of a whole candidate stream in this outer computation. [Bounded-reachability algorithm](linear-quantifiers.md) · [Quasilinear simulation and unary hierarchy](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

For each fixed k there is a constant a>0 such that at infinitely many accepted lengths **every** ledger, order and filter with a nonempty sound passing language under U≤nᵏ satisfies

    S+R > n¹² / 2^{a√(log₂ n · log₂ log₂ n)}.

Otherwise use the integer part of the displayed cap for Q, with computable rounding of the logarithms and a suitably large constant. The ledger term n¹¹ polylog(n) stays below the cap eventually. Taking a sufficiently large absorbs the subpolynomial multiplier and the quasilinear nondeterministic tape simulation, deciding H★ inside the excluded n¹²/log₂(n+2) clock. Finitely many exceptional accepted lengths can be hardwired. Soundness already excludes every NO input. The filter can be chosen nonuniformly per length and need only let one legal stream through. A fixed-power saving in S+R on every sufficiently large accepted length for one fixed polynomial filter clock would refute linear SAT. Such filters for H★ remain unknown.

## An expander with exponentially many passing streams

Consider the independent-copy RAM example in which a chronological path of registers and a matching of memory write/read pairs together have linear edge expansion across balanced cuts. Each record displays an incoming and a freely guessed outgoing register of b bits. At each matched memory port it also displays a b-bit write or read. The public schedule specifies port types and addresses. Choose chronological order. Require every matched memory word to be zero and compare each incoming register with the preceding outgoing register. A fixed filter uses O(b+log B) scratch and polynomial time. It can stream a record with the incoming register first, allowing reuse of its b-bit buffer. The local generator admits these zero memory values, and the comparison enforces every chronological copy. [Explicit path and matching construction](crossing-bits.md)

Fix the end registers and leave the B−1 internal chronological register words independent. The filter accepts all 2^{b(B−1)} resulting legal streams. Thus this filter handles a wide graph while leaving an arbitrarily long sequence of values unspecified. It restricts the other set of transmitted words to a value one can check at each port separately. The example and the conditional hierarchy bound concern different computations.
