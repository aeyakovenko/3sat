# A circuit lower bound for dense signed-graph consistency from list distinctness

Write $N=2^w$. A signed-graph instance lists edges on at most $4N$ vertices, with a bit on each edge. It asks whether there exist binary vertex labels whose endpoint XOR equals the sign on every edge. The input family below has $4N$ edges, $O(N)$ possible vertex names and $n=\Theta(Nw)$ encoded bits. Each equation has an equivalent pair of binary CNF clauses of that same asymptotic encoded size. The vertices have dense identifiers even on lists whose record values repeat arbitrarily often.

**Consequence of the pinned OpenAI manuscript's volume theorem.** For some $\sigma>0$ and every sufficiently large $w$, any bounded-fan-in Boolean circuit deciding consistency on the encoded family has size $\Omega(n(\log n)^\sigma)$. More generally, a single such circuit answering whether **all** of $t$ independently specified graphs are consistent requires $\Omega(tn(\log n)^\sigma)$ gates for $1\le t\le 2^w$. Here a gate is an arbitrary Boolean function of at most two bits, and size counts gates. A fixed constant bound on fan-in only changes the constant. The use of the external volume theorem is a mathematical dependency. This journal has not independently verified its proof. [OpenAI, Theorem “Volume of list distinctness”](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/build/obstruction.tex)

## Recovering the full payload from parity of decision answers

First consider $N$ records $(p_i,a_i)$ and $N$ outputs $c_j$, where every field has $w$ bits. The desired test accepts if the tags $p_i$ form a permutation and $a_i=c_{p_i}$ for all $i$. Introduce distinct banks of $N$ binary variables $H_j,V_v$. Use the following $2N$ equations, in a prescribed order.
$$
     H_{p_i}=V_{a_i}\quad (0\le i<N),\qquad
     H_j\mathbin{\oplus}V_{c_j}=z_j\quad(0\le j<N).
$$
For each fixed binary string $z$ the signed-graph decision answer is one bit. Take the **parity over all distinct right-hand sides** $z$. An individual feasible right-hand side contributes one, irrespective of the number of satisfying vertex labellings.

The assignments satisfying the first set of equalities form a binary vector space. The jointly attainable $z$'s form its linear image, of size $2^r$ if its rank is $r$. The desired parity is one exactly when that rank is zero. In the graph of the left equalities one may assign a bit independently to each connected component. Rank zero therefore means that every $H_j$ and $V_{c_j}$ already lie in the same component. A missing tag makes $H_j$ isolated and violates this condition. If all tags occur they form a permutation. Each $H_j$ then has just one neighbor and no component contains two different $V$-vertices. Thus the condition says precisely $c_j=a_{p^{-1}(j)}$ for all $j$. This proof permits arbitrary repeated payloads.

## From the original hard list with no promise

An input to list distinctness consists of $N$ unrestricted words $x_i=(a_i,b_i)$ of $2w$ bits. Introduce internal bits for tags $p_i$ and a proposed sorted list $(c_j,d_j)$. Check in a bounded-fan-in Boolean circuit that the $N$ proposed pairs are in strictly increasing lexicographic order. Comparing adjacent $2w$-bit pairs and taking their conjunction costs $O(Nw)$ gates.

Make two disjoint signed graphs as above, sharing the proposed tags. The first compares $a_i$ with $c_j$ and the second compares $b_i$ with $d_j$. Give the two banks independent right-hand-side vectors. Their disjoint union is a single instance with $4N$ variables and $4N$ equations. Use two tag bits as the bank prefix and a $w$-bit index as its suffix. If a format requires each of the declared names to occur, append one fixed self-equation with zero sign at every vertex. Each input bit of this encoded graph is a constant, a copy of an input or internal bit, or its complement. For the binary CNF encoding, each equality with sign zero gives two opposite directed implications. Sign one reverses the polarity of one endpoint in both clauses. The number of literal occurrences stays $O(N)$ and every identifier has $w+O(1)$ bits.

Over $\mathbb F_2$, sum the graph decision tensor over both sign vectors. The sum factors and gives the product of the two exact tagged tests. Now weight by the strict-order test and sum over tags and target words. If the original records are distinct, exactly one strictly ordered target and one permutation survive. If two records coincide, none survive. The resulting exterior tensor is exactly the list-distinctness tensor $D_w$. The independent signs, tags and target bits are internal wire indices of the network. Their number of possible values does not affect the number of gates and wires required to form a contraction.

To obtain the circuit bound, take a circuit of size $S$ for the decision problem on the graph family. Replace each gate by its Boolean truth-relation tensor, copy its output through equality trees wherever it fans out, and pin the final bit to one. At most $2S$ wire uses are incoming to gates, so this trivalent network has volume $O(S+n)$. Circuit gating, the comparisons, bit copying, summation and constant pins in the preceding construction cost another $O(Nw)$. For $t$ graph instances with one common all-consistent output, apply this substitution to each input's local wiring. The sum recovers $D_w^{\otimes t}$, since the graph answers multiply and all local summation variables are separate. Total volume is $O(S+tNw)$. The cited theorem requires volume greater than $t(2Nw)w^\sigma$ over $\mathbb F_2$, giving the stated gate bound. This is a tensor contraction of the decision function. A Boolean many-one projection from distinctness to one signed instance would be a different reduction.

## Which one-bit readouts can replace XOR?

There is a small obstruction to using only Horn clauses in the same parity test. Collapse the left equality components. For any directed graph $G$ on the components, assign independent Boolean labels $x_v$ and record $f(x_u,x_v)$ on every directed edge. Suppose the number of **distinct** record vectors is odd exactly when every edge is a loop. Among all binary Boolean functions $f$, precisely XOR and its complement have this property.

A single loop forces $f(0,0)=f(1,1)$. A single nonloop forces $f$ to be nonconstant. If exactly one off-diagonal value differs from the diagonal value, $f$ is an indicator of an oriented cut or the complement of such an indicator. On the directed two-edge path, the cut indicator realizes three vectors. Either neither edge crosses in the designated direction, only the first crosses, or only the second crosses. Both cannot cross in that direction. Complementing all output bits or reversing the direction preserves the count. This odd count violates the requirement. Thus both off-diagonal values differ from the diagonal value, leaving XOR and its complement. Conversely XOR has a linear image of size a power of two, with rank zero precisely when all edges are loops. Complementing the image translates it and preserves cardinality. The path is possible even in the tagged construction with a genuine permutation: take the shared labels on the two source rows to be $a,b$ and the corresponding compared labels to be $b,c$, adding a self-comparison for $c$ if needed.

Each surviving readout has disequality as one of its two fibers. Models of a Horn formula are closed under coordinatewise AND, and projecting away auxiliary variables preserves that closure by taking the AND of their witnesses. Disequality contains $(1,0),(0,1)$ while omitting their AND. Hence a fixed one-bit readout with both fibers existentially expressible by Horn clauses cannot implement this particular test. This conclusion concerns a single local readout and leaves room for other dense Horn reductions.

## Native time and the occurrence assumption

A log-word RAM builds an adjacency list in $O(N)$ steps on this family. Assign an arbitrary bit at each new root, propagate endpoint signs through its component and reject if an already labelled vertex would receive the other bit. This decides every instance in $O(N)$ word steps with $O(N)$ working words. Variable occurrence in the graph is unbounded. For example, when all $a_i$ are zero, one payload variable appears in $N$ left edges. Renaming each edge endpoint independently loses the equality among these occurrences. The theorem supplies a restricted Boolean circuit consequence while all three unrestricted SAT time targets stay open. Priority for this transfer has not been established.
