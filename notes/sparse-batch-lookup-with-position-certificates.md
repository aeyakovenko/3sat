# Certifying a sparse batch of reads and writes in an ordinary 3-CNF

Let \(v=2^k,\ k\ge1\). Supply two independent bit banks \(X,Y\) of length \(v\), and \(m\le v\) chronological events, each with an unknown \(k\)-bit address, a read/write bit and a data bit. Reads claim the current value and writes replace it. The following existential proper 3-CNF accepts exactly the legal batches that start in \(X\) and finish in \(Y\). In particular, every unmentioned bank position is checked. Put \(G=v+m(k+1)^2\).

* The circuit underlying the verifier and the number of clauses are \(O(G)\).
* Sparse legal decimal identifiers give \(O(G(k+1))\) physical DIMACS bits, computable a bit at a time in \(\operatorname{poly}(k+1)\) time. A packed RAM prints the file in \(O(G+\operatorname{poly}(k+1))\) steps.
* On each of \(\operatorname{poly}(k+1)\) public consecutive intervals, a raw physical bit as a function of its ordinary binary address has an extension of degree \(O(1+\log(k+1))\) over \(\mathbb F_2\).

The read-only problem has stronger deterministic functional constructions. Holmgren and Rothblum give size \(O(v+m\log^3 v)\) and logarithmic depth, and use superconcentrators to retrieve disjoint values with routing advice. Here all routing choices are existential. We charge the verification of the claimed origins and of both complete memory states. Priority for these combined parameters is unestablished. [Holmgren and Rothblum, CCC 2024, main theorem and §2.1](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.CCC.2024.11)

## Compressing a set of touched addresses without carrying every address

The case \(m=0\) consists of componentwise equalities. Otherwise round the number of event slots up to the next power of two, disabling unused slots. Start with the \(v\) source positions. Whenever the current layer has size \(2R\) with \(R\ge16m\), add a layer of size \(R=2^j\). Left vertex \((b,p)\) is adjacent to \(C_a(p)\) for every port \(a\). Here the \(C_a\) are a fixed constant number of explicit signed coordinate permutations on \(j\) bits whose normalized adjacency \(P\) has nontrivial singular values at most \(1/4\). Viola and Wigderson give explicitly uniform signed coordinate permutations in every dimension. If necessary add identity and take a fixed power to control negative eigenvalues. Each incoming port at \(y\) has label \((b,a)\) and predecessor \((b,C_a^{-1}(y))\). At termination there are \(O(m)\) top vertices, including the case where all vertices were already at the top. [Viola and Wigderson, Theorem 1 and its Schreier graph construction](https://www.math.ias.edu/~avi/PUBLICATIONS/ViolaWi2017_v2.pdf)

For any nonempty \(U\) of \(s\le m\) projected left coordinates, Cauchy–Schwarz applied to \(P1_U\) gives
\[
 |N(U)|\ \ge\ s^2/\|P1_U\|_2^2
 \ \ge\ s/(1/16+s/R)\ \ge\ 8s .
\]
An arbitrary set of at most \(m\) left vertices projects to at least half as many coordinates. Hall's condition therefore holds on all its subsets. Pick a matching at each layer, in order, to route all distinct touched sources to distinct tops. No verifier computes a matching.

Guess one active bit per vertex and one selection bit per edge. Require the number of selected outgoing edges at a nontop vertex to equal its active bit, and the same of incoming edges at each nonsource vertex. Degrees are constant. Active paths are consequently disjoint and run from source to top. At an inactive source require \(X_i=Y_i\). On an active source carry \((X_i,Y_i)\); along a chosen edge require the pair to be copied. At level \(h\), also store the \(h\) incoming port labels seen since the source. On each selected incoming edge copy the previous \(h-1\) labels and append its own. The resulting constraints cost
\[
       O\!\left(\sum_{h\ge0}(h+1)v/2^h\right)=O(v).
\]
A menu of constant-size port selectors then decodes each active top's source \(k\)-bit name by applying the recorded inverse neighbors starting at that top. Each inverse step copies or complements bits according to a fixed permutation and prefixes one bit. It costs \(O(k)\) gates even when the port choice is unknown. All decodes cost \(O(mk^2)\). This delayed decoding avoids carrying a \(k\)-bit source label across every edge in the large lower layers. The two endpoint data bits at each active top now have authenticated provenance.

## Chronology and the final state

For each active top create an initial record and a final record at its decoded source, with the carried bits. Include the live supplied events, with their hardwired distinct time numbers. Inactive and padding records have a dummy type. Round the whole list to power-of-two length \(O(m)\). Guess switches in a rearrangeable Beneš permutation network on these records. Each two-way switch moves a full record of \(O(k+1)\) bits with a common control. Its two outputs are a permutation of its inputs for either value of its control; every desired permutation is realized. The usual recursion uses \(O(m\log(m+2))\) switches. For completeness, connect the input and output pairs for a desired permutation by its wires. This is a bipartite 2-regular multigraph. Alternating edges on its even cycles select the two child subnetworks, and induction routes the two halves.

Check that the outputs are sorted, with dummies last, then by address and event order within the live prefix (initial, increasing event time, final). Check the start/end of each live address group are an initial/final record, with no further endpoint records inside. Require the initial bit to enter the running state, ordinary reads to equal that state, writes to replace it, and the final bit to equal the last state. This uses an \(O(k+1)\)-gate comparator and a bounded number of state constraints per position. Every original event is present. A live group cannot use somebody else's initial or final bit because distinct active paths have distinct sources. An extra active source with no events is checked by its consecutive initial/final records. Together with the inactive-source equalities, this proves the projection exactly, even for a malicious route, duplicate event addresses or read claims depending on earlier reads. Adaptive executions also require the separate CPU constraints that prescribe the events. The checker alone allows all legal event lists.

## From gates to actual file bits

Group clauses by layer, port, bit role, stage of the Beneš network and constant gate/constraint type. A varying lane in each group is a binary node or switch number; all ranges are dyadic. High bits for \(m\) and the actual event count can be handled by decomposing each occupied or disabled prefix/suffix into \(O(k+1)\) aligned dyadic intervals. Adjacent sorted-record constraints indexed by \(i>0\) use roles determined by the least set bit of \(i\): fix the trailing zeros and that one, and vary the remaining high bits. Then both \(i\) and \(i-1\) are affine in the free lane bits. Degree-one coordinate maps suffice for both directions of the concentrator, for skipping the fixed Beneš switching bit, and for the branch controls and chronological time bits. Decoding an unknown port is itself a circuit on a single lane with role for each possible port and coordinate. Its wiring only refers to fixed permutations and fixed roles. Variable-width decoders can equally store \(k\) bits and set unused bits to zero.

Assign every wire a fixed-width injective tuple of tag, role and lane fields totalling \(O(k+1)\) bits. Use an ordinary decimal name consisting of a leading 7 followed by one digit 1 or 2 per tuple bit. Bounds in the header may leave IDs unused. Introduce local distinct operand copies, pad one- and two-literal clauses with all signs of fresh variables, and encode each fixed Boolean gate by its rejected truth-table tuples. These transformations preserve the existential projection with three distinct names per clause. A slab has one clause shape and power-of-two record width \(\Theta(k+1)\) bytes, using trailing whitespace. Place the header in an aligned initial block the size of the largest slab and place the slabs in nonincreasing size order. This adds only constant-factor space. Within a slab, low offset bits choose a byte and ASCII bit, and the next bits give the lane without subtraction. Each chosen name bit is affine there. An indicator for an offset uses \(O(1+\log(k+1))\) bits; summing the products with the corresponding affine bits proves the degree assertion. Isolate the \(O(k+1)\)-byte header in its own dyadic initial interval, followed by constant whitespace.

The fixed stage and variable-name directory and the explicit local expander maps take \(\operatorname{poly}(k+1)\) preprocessing. In one slab traverse the binary tree of lane prefixes and maintain the affine literal identifiers, adding the precomputed XOR masks as each bit is chosen. Total work is linear in the number of leaves plus polynomial setup per slab. One shared \(O(2^{k/3}\operatorname{poly}(k+1))\)-word table expands pieces of a name into ASCII digit fields, using a constant number of words per whole name. Thus \(O(G+\operatorname{poly}(k+1))\) native operations physically emit the formula. [Related physical identifier and alignment proof](locally-encoding-an-unknown-xor-shift.md)

## Applying the bound to arbitrary exceptions

For a bulk relation \(B_i=X_{f(i)}\) already encoded on all positions, allow an explicit list of at most \(m\) exceptional pairs \((i,a)\), with unknown indices and replacement sources. Read their values from \(X\) with the checker and write them to the target at positions \(i\), taking \(B\) as the initial bank and \(Y\) as the final one. Duplicates can follow chronological last-write semantics or be forbidden by an adjacent check in the sorted lists. For \(t=\Theta(vk)\), a bulk checker using \(O_\epsilon(v k^{1/2+\epsilon})\) gates still has that size when \(m=O(v/k^{3/2-\epsilon})\); genuinely arbitrary exceptions of that cardinality fit. This also works for a fixed number of synchronized banks. Pinning wire values or describing the exception list itself must be charged separately unless these are internal shared variables.

This is a physical compiler for a specified part of a proposed accepting-history representation. It leaves open whether the fixed unary hierarchy challenger has the required bulk structure or few exceptions. The unrestricted SAT clock exclusions require a result on that premise or another route.
