# How many incidence switches make a sheeted SAT formula satisfiable?

Let $H$ be a signed not-all-equal instance on triples. Write $u$ for the minimum, over all Boolean assignments, of the number of monochromatic triples. Replace each triple of signed literals by two ordinary clauses, its disjunction and the disjunction of its three complemented literals. Call the resulting 3-CNF $F$. Fix $d$ labeled sheets, initially $d$ disjoint copies of $F$. A switch chooses a **single literal occurrence of a single base OR-clause** and two distinct sheets, then transposes the variable endpoints to which those sheets currently connect at that occurrence. The signs stay in their original slots. The two complementary clauses have independent permutations. Every $d$-sheet factor graph cover with those labeled fibers is obtainable this way. Finite factor graph covers are classical. [Vontobel](https://arxiv.org/abs/1012.0065) · [Schaefer on Boolean satisfiability relations](https://doi.org/10.1145/800133.804350)

**The exact minimum number of switches to reach any satisfiable cover is $du$ for every $d\ge2$.** With a budget of at most $r$ switches, the smallest attainable number of unsatisfied lifted clauses, minimizing also over the assignment, is $\max(du-r,0)$. There is a fixed list of $du$ switches on pairwise disjoint occurrence positions that realizes this curve for **every subset** of the list. The successive minima at $d$ and $d+1$ differ by exactly $u$. The theorem allows arbitrary permutations and intermediate lifts, including connected and disconnected lifts. Additional requirements that the final lift be connected may change the optimum.

## The lower bound for every rewiring

Freeze any Boolean assignment on all the lifted variables. On the identity lift, each sheet violates precisely one ordinary clause per monochromatic base triple of that sheet, hence at least $u$ ordinary clauses. At one switch the two changed literal truth values exchange places. If they agree, both clauses retain their former value. Otherwise only one clause gains a true literal. Consequently the total number of unsatisfied clauses can drop by at most one. Apply this along the entire path to the assignment attaining the final cover's optimum. The lower bound remains valid if the two endpoints chosen at later switches depend on what earlier switches did. This proof counts each indexed clause separately if input rows repeat.

## An optimal set of independent switches

Partition the sheets into pairs, with one triple when $d$ is odd. Give the first sheet of each pair an optimal assignment $a$ for $H$ and the second sheet its bitwise complement. Use the assignments $a,\neg a,a$ in a triple. A base triple which is mixed under $a$ satisfies both OR-clauses on every sheet without any change.

For a monochromatic triple, consider its two OR-clauses separately. Each OR-row is initially either all true or all false. A recipient needs one true literal. In a pair the single donor switches its first port with the single recipient. In a three-sheet group with two donors and one recipient, one donor switches its first port with the recipient. With one donor and two recipients, the donor switches its first port with one recipient and its second port with the other. Each donor retains at least one original true literal even when every prescribed switch is applied. The other member of the complementary clause pair uses its own disjoint positions. This is where arity three handles odd sheet counts.

With this fixed assignment, applying any selected subset of $r$ switches repairs exactly $r$ distinct initially false clauses. The unused switches and the other rows cause no extra failures. The lower bound proves global optimality of the remaining $du-r$ defects. This includes repeated literals or variable names within a triple when each incidence has its own port. For ordinary proper 3-SAT take distinct variables in every base triple. If duplicate-free rows are required, choose distinct base triples up to permutation and complementation with distinct signed expansions. A given lifted row still contains three distinct base variable names, and at any port distinct sheets of the same base clause use distinct variable endpoints. There are therefore no accidental identical rows. For $d=1$ an unsatisfiable base has no feasible repair by switches.

## What the successor costs a RAM

Each coordinate of the Boolean cube choosing these $du$ switches changes just two variable identifiers in the serialized formula. On that cube the ordinary SAT function is AND of all $du$ selectors. At the all-switched endpoint a correct deterministic solver must inspect at least one physical word meeting a changed bit for every coordinate. Otherwise reversing that coordinate on the actual file keeps its entire execution and changes the answer. For the last coordinate first inspected, the single-reversal UNSAT run shares the prefix up to that load. This gives the same lower bound up to constants on both verdicts when a word intersects only constantly many identifier fields.

For example, take the four signed triples on the same three distinct variables, one for each sign pattern modulo simultaneous complementation. Each assignment violates exactly one of the four NAE rows, so $u=1$. The ordinary paired base consists of all eight sign clauses on that triple. Encode the $3d$ lifted names by consecutive integers in $[10^b,10^b+3d)$ with $b=\lceil\log_{10}(3d)\rceil$. Use the maximum name in the DIMACS header, which permits unused names. Each of the $8d$ proper ternary rows has identifier fields of $b+1$ decimal digits. All switches preserve the strides and the file length $N=\Theta(d\log d)$. Each aligned $O(\log N)$-bit load meets only a constant number of fields. At this seed there are thus actual SAT and UNSAT files both requiring $\Omega(N/\log N)$ native word loads. The neighboring files in this argument exchange two identifier fields. Their Hamming distance may exceed one bit.

The entire selector cube here also admits a globally correct linear-time program, even when the identifiers and rows are permuted. After decoding, find the incidence components. Each component in this particular construction uses at most nine variables because every switch is internal to a pair or triple of sheets. Try all assignments on each component of size at most nine and use exhaustive SAT on larger components. Parsing these ASCII files, where name magnitudes are $O(d)$, takes $O(N)$ native steps. On a general file arbitrary long names can be interned by a digit trie or passed to a general parser. In the ordinary fixed-width binary encoding with word-readable identifier fields and dense names $1,\ldots,3d$, the same component algorithm takes $O(d)$ steps on the whole cube, matching the probe bound. Thus the linear growth in repair distance is compatible with a scan of the packed words. The exact successor measures the number of changes required of the input. It supplies no superlinear estimate on processing it.

## An expanding incidence graph at the exact minimum

For even $d$, an optimal satisfiable lift can also have incidence treewidth $\Omega(d)$. Take $g$ copies of the four-triple seed, sharing one variable $x$ and using private pairs $y_h,z_h$ in copy $h$. Every assignment violates one NAE constraint per copy, so $u=g$. With the optimal all-zero assignment and its all-one complement, only the all-positive and all-negative OR-clause of each seed need repairs.

Divide the sheets into two equal sides carrying these opposite assignments. Choose separate perfect matchings across the sides for each of the $2g$ active signed base clauses, with arbitrary coincidences allowed between matchings. For each matched pair swap the occurrence of $x$ in the two lifted rows. Exactly $gd$ independent switches result. The same subcube calculation applies. Each full switch fixes one false row and the donor retains its two true private literals.

At the full endpoint contract a connected branch set for each sheet. Include all its variables and all clause vertices bearing its sheet index. In each seed six unmodified signed rows join all three local variables and every modified clause retains edges to $y_h,z_h$. The shared $x$ connects the seeds on that sheet. Across two matched sheets there is a surviving edge through the switched port. Thus the union of the $2g$ matchings is an incidence-graph minor. With fixed $g$ one may choose a bounded-degree bipartite expander decomposed into a constant number of perfect matchings, doubling its list of matchings if an even list size is needed. For example Gabber and Galil construct bipartite expanders from permutations. Any tree decomposition of width $k$ supplies a separator of size $k+1$ leaving components of at most half the vertices, by taking a weighted centroid bag. In a bounded-degree expander such a separator has linear size. Indeed, if fewer than one quarter of the vertices are removed, group components into a set of between one quarter and one half of the vertices, taking one large component by itself if necessary. Its external neighbors all lie in the separator. This gives the asserted treewidth, and the actual graph has $O_g(d)$ vertices. [Gabber and Galil](https://doi.org/10.1016/0022-0000(81)90040-4) · [Explicit permutation construction](https://www.tau.ac.il/~nogaa/PDFS/Publications/Eigenvalues%2C%20expanders%20and%20superconcentrators.pdf)

A linear-time algorithm still handles the whole face on these named inputs, including arbitrary choices of the perfect matchings. The six intact clauses in each seed and sheet force $x_i=y_{h,i}=z_{h,i}$ because they exclude the six mixed truth triples. An active clause has two sheet-$i$ private literals of identical polarity, together with an $x_j$ of that polarity. Replacing the private variables by $x_i$ therefore produces ordinary 2-SAT. On the canonical fixed-width binary layout, the program decodes and validates all expected roles, including all six required clauses per seed per sheet, and checks that every remaining row has the stated form. On success it solves the quotient by strongly connected components of its implication graph in $O_g(d)$ word steps. On failure it can run a general correct SAT algorithm. For the displayed ASCII layout $O(N)$ steps suffice. The expander minor rules out a small-treewidth explanation of the full endpoint. The six clauses explain how one program still processes these instances quickly. [Aspvall, Plass and Tarjan on 2-SAT](https://doi.org/10.1016/0020-0190(79)90002-4)
