# Can two mutually exclusive winners give a short certificate for a loss?

A priority stage has at most one winner. For any two distinct named ranks, at least one loses the stage. To turn that fact into a fast SAT contradiction, one needs a short sound certificate for an *identified* loser. The distinction persists even for a particular pair in the actual [priority program](priority-pinned-sat.md) whose two members never win.

**Two-rank theorem.** Fix a uniform nondeterministic RAM verifier $W(j,e)$ that can accept only if $e$ does not win at stage $j$. It need not accept every loss. Suppose SAT on $N$ ordinary encoded bits takes deterministic time $O(N^k)$ for $k\in\{1,2,3\}$. There are two distinct fixed ranks $p,q$ and a constant $B$ such that neither rank ever wins. At every sufficiently large $j$, neither true loss has an accepting $W$-branch within $R_j=\lfloor 2^{\lfloor j/k\rfloor}/(j+1)^B\rfloor$ steps. The truth of the disjunction therefore gives a total search task with two allowed answers at these stages. Producing a witness that the given fixed verifier accepts is an additional requirement. The quantifier order is one pair for each fixed verifier and SAT solver.

To prove this, put two programs in the actual enumeration using a common template and a literal tag. Each computes the same two designated ranks from their program texts and requested colors, as in the [group construction](synchronized-priority-trials.md). Build the two bounded-acceptance CNFs for $W(j,p)$ and $W(j,q)$ under clock $R_j$. Run a reference SAT solver on both, alternating one simulated instruction per unfinished query with a fixed tie order. A negative answer removes that query from the race. Only a positive answer selects a rank. Its designated program signals, while the other idles forever. Idle also when neither returns a positive. Branches on malformed or unsupported tiny parameters may simply idle. Each rank emits only after computing a positive answer for its own query. The other-color occurrence of the same program text is a separate requirement that may preempt once, just as any other rank can.

In fact any globally correct deterministic SAT solver $S$ can serve as the reference for this argument. A designated rank never wins: if it did, a positive answer certifying its loss would have been correct at the very stage it won. This conclusion needs no time bound and persists even on an early stage where the two clocked programs have run for different durations. After some fixed stage no rank below $\max(p,q)$ ever wins again. Both designated ranks are then unretired, active, and physically reached unless one of them wins. If a true YES on either query could be obtained in $o(M)$ native steps on infinitely many such stages, the round-robin race would select a rank early enough for its own trial to win, where $M=2^j$. More precisely, there is a fixed $\delta_S>0$ such that **each satisfiable query** takes at least $\delta_S M$ native steps on every sufficiently late stage. Use the [fixed-program packed input simulation](priority-pinned-sat.md#why-both-verdicts-take-time-on-every-late-pair): computationally identical races use the same instruction-order tie rule, each has constant per-step width adaptation after $o(M)$ setup, and both trial budgets are fixed positive fractions of $M$. The verifier input consists only of the two small indices and the scale; any needed virtual zero input is generated locally. The formula templates and clock arithmetic have polynomial-in-$j$ setup. This lower bound is conditional on that individual query being satisfiable. It asserts nothing expensive on an unsatisfiable query.

Under $O(N^k)$ SAT, the ordinary formulas have $O((R_j+\operatorname{poly}(j))\operatorname{poly}(j))$ bits. Choose $B$ to absorb the fixed compiler powers; even writing the formula where necessary fits the native race. A YES would be obtained in $o(M)$ steps. Both bounded queries must therefore be unsatisfiable at every sufficiently late stage. The same proof works with a single rank; using two exposes the gap between certifying a disjunction and certifying one of its true terms.

## Ordinary formulas with joint and separate witnesses

Use a fixed bounded RAM program computing the priority winner at stage $j$ in $O(M)$ time, with a separate value for no winner. Output its binary rank and indicator bits $o_e$ for all $e<a_j$. For instance designate the final rank word's bits in the [standard tableau](packed-band-transfer.md) and append ordinary equality gates against each eligible index. Allow a special no-winner code. Add each redundant binary clause $\neg o_e\lor\neg o_f$ for distinct $e,f$. These additions cost only $\operatorname{poly}(j)$ encoded bits. With the usual padding the common satisfiable 3-CNF $H_j$ uses $\Theta(M(j+1)^3)$ bits, and its clause records can be generated in $\operatorname{poly}(j)$ time from an address after the fixed template setup. For the bounded *local* proof verifier, use polynomial-in-$j$ word arithmetic throughout, with no $M^\delta$ setup. A fixed transition template, permutation network wiring and the small rank comparisons are indexable with those costs. On all satisfying assignments the indicated winner is the true one; auxiliary witness bits need not be unique. Put $A_{j,e}=H_j\land o_e$. Then $A_{j,e}$ is unsatisfiable exactly when the rank loses.

With the *same* tableau variables, $H_j\land o_p\land o_q$ has a two-inference resolution refutation from the two units and the binary exclusivity clause. If two independent claims use separate tableau variables, the formula is instead $A_{j,p}(U)\land A_{j,q}(V)$ on disjoint variable sets. A pure binary resolution inference needs complementary pivot literals. Lines derived from different variable sets have no such pivot. Tracing back the empty clause in a resolution DAG therefore extracts a refutation using axioms of one component, with no increase in line count. Proof lines shared within that component remain shared. This uses ordinary resolution with no freely introduced bridge axioms. An empty input clause already belongs to its own component. [Lean derivation checks](../lean/DisjointWinnerResolution.lean)

Let $W$ check an ordinary binary resolution refutation of $A_{j,e}$. It guesses a proof whose lines explicitly list literals, axiom indices or parent indices and a pivot, checks input axioms by indexed generation, and verifies the final empty clause. The verifier need never read all of $H_j$. Give it canonical sorted clauses with no duplicate literals. In a valid resolution step each parent has at most one more literal than the printed resolvent, since all its nonpivot literals occur in the resolvent. Check parent lengths before scanning, then merge and compare. Even with reused parents, a proof of $s$ encoded bits, $s$ polynomial in $M$, can be verified within $(1+s)\operatorname{poly}(j)$ steps. Cap all guessed lengths during bounded simulation. By the two-rank theorem, under a fast SAT hypothesis there is a pair for which **both** separate formulas and their disjoint conjunction need more than $M^{1/k}/(j+1)^{B'}$ encoded proof bits on every sufficiently large $j$, for a fixed $B'$. Extracting and reindexing a component changes the encoded size by at most a fixed polynomial in $j$. A bound on encoded proof bits need not give the same bound on the number of proof lines.

There is a proof-system-independent version for small unsatisfiable subsets. Use a verifier that guesses a list of clause indices from $A_{j,e}$, generates them exactly, densely renumbers their variables and runs the hypothesized SAT solver on that explicitly encoded subset. Accept on UNSAT only. This verifier is sound for loss independently of its guesses, assuming the reference solver is correct. For $s$ selected clauses it takes at most $(s+1)^k\operatorname{poly}(j)$ time, including sorting, variable remapping and a self-delimiting list. Apply the theorem to this verifier. For a suitable pair, every subset of at most $M^{1/k^2}/(j+1)^{B''}$ clauses of either component is satisfiable, at all sufficiently late stages. The same holds for their disjoint conjunction since assignments on disjoint variables combine. The pair can be common to both the resolution and clause-subset assertions by putting the two checks behind a single guessed format bit. For $k=2,3$, the exponent $1/k^2$ charges locating a witness via SAT and the inner SAT test on the proposed subset. Any refutation obtained from explicitly referenced input clauses by sound consequence rules must use more than this many distinct input clauses. In particular for $k=1$ the result is also a resolution line-count lower bound of $M$ divided by a fixed polynomial in $j$. For a proposed Horn core the inner check is deterministic near-linear and the proof-bit exponent $1/k$ applies with logarithmic slack.

## A fixed family that does not use the code of a fast SAT algorithm

For any specified $k\in\{1,2,3\}$ there is also a single effective generator of pair columns on which one can test the resolution and clause-subset upper bounds. Its code is fixed before assuming a fast SAT solver. The qualifying pair index need not be identified by a uniform search.

Enumerate deterministic SAT machines together with a width convention and an integer time coefficient. Enforce a clock $C(1+N)^k$ on ordinary valid $N$-bit inputs, returning NO on timeout. There is one fixed dovetailing computation that lists every incorrect candidate: enumerate input formulas, compute their correct verdicts by exhaustive search, and compare the bounded answers. At scale $j$ simulate just $j$ steps of this dovetailing machine and take the least candidate index not yet refuted. Denote its clocked decision by $S_j$. Computing the index is polynomial in $j$. If the SAT hypothesis holds, a correct candidate exists. Every earlier incorrect candidate is eventually refuted and the least correct candidate is never refuted. Hence $S_j$ is one fixed globally correct clocked program at every sufficiently large scale. The stabilization stage is unknown to the construction. [Finite stabilization and spoiled-pair bounds](../lean/PriorityCandidateLearning.lean)

Use one common tagged template with a pair number $l$ and a left or right tag. At scale $j$ a copy idles unless $l\le a_j$ and both designated ranks for its pair occur in the active prefix. Call these the active pair columns. For column $l$ use the public branch cap $\lfloor 2^{\lfloor j/k\rfloor}/(j+1)^{l+1}\rfloor$. A bounded product or early comparison computes it in $\operatorname{poly}(j)$ time uniformly in active $l$. Every fixed column eventually activates. Recognize these occurrences by scanning that prefix. Once both are active, race the two ordinary bounded-verification formulas for that pair using $S_j$. As before select just the first positive query. The verifier has two acceptance modes. One verifies a resolution proof of $A_{j,e}$ by local clause access. The other guesses a subset and runs $S_j$ on its generated explicit clauses, accepting on a negative answer. Under the SAT hypothesis the verifier is uniformly sound on **all** ranks once the candidate stabilizes. Computing $S_j$ inside the verifier also costs only $\operatorname{poly}(j)$ work. The fixed $H_j$ encodes the original priority program on zero input. Its clause generator never needs to know the winner when serving a clause. The new tagged programs occur in its ordinary enumeration; generating code for their formulas requires only their names and the fixed verification templates.

No designated rank can win after stabilization. Any such winner would have had a correct positive answer certifying its actual loss. Before stabilization only finitely many stages occur, each retiring at most one rank. Call a pair spoiled if it had a designated winner before stabilization. There are finitely many spoiled pairs. For every other fixed pair, its two members are always unretired, and eventually no rank below either one ever wins again. After stabilization there is a fixed logarithmic power sufficient for the common query generation and the selected solver. Exclude also the finitely many $l$ with $l+1$ smaller than this power. The bounded-race argument gives both lower bounds for **all but finitely many fixed pair numbers**, at every sufficiently late scale of each pair, with logarithmic exponents allowed to depend on that fixed $l$. The choice of $l+1$ in the clock makes the construction independent even of that overhead threshold. Both $H_j$ and the effective pair index mapping are independent of which fast solver might exist.

There is also a simultaneous version. On a late stage with no award the scheduler reaches every active unretired rank. The common clock estimates are uniform over pairs whose two tags are both active: the tags are data in a fixed instruction body, the active prefix has $a_j$ entries, the chosen SAT program after stabilization is fixed, and the smallest active raw budget is $\Omega(M/\log(j+4))$. The finitely many small-$l$ columns can again be excluded. On each such stage both sides of **every** other active unspoiled pair have the corresponding lower bounds with their own clock exponent $l+1$. Uniformly over all active $l$, the loss from $(j+1)^{l+1}$ is at most $(j+1)^{a_j+1}=M^{o(1)}$. This preserves every fixed power saving in the following count. At most $a_J$ stages through $J$ have any award. Thus under the SAT hypothesis, apart from $O(1)+a_J$ stages through $J$, at most a fixed number of active pairs per stage can have either side with a core of $O(M^{1/k^2-\epsilon})$ clauses, for any fixed $0<\epsilon<1/k^2$ and fixed multiplicative constant. At stages before both tags activate the estimate makes no claim.

These implications give two sufficient tests on fixed ordinary formulas. Infinitely many distinct fixed columns each having a core this small on infinitely many scales would contradict the fast solver. So would an unbounded number of distinct active pair columns with such cores on a positive-density set of scales, if that number tends to infinity along the set. Both tests allow the small side and the clause indices to vary nonuniformly. They charge no time for locating the cores. For the specified final-register implementation the upper bounds are impossible: every losing core must meet every native transition. [Per-transition repairs](winner-tableau-cut-faults.md)

There is a finite test per column as well. Fix a common $\epsilon>0$ and a common multiplicative constant in the small-core bound, and put $E_l=\max(p_l,q_l)$. On a jointly active stage at which such a core exists, the indicated loss query receives a timely positive answer once the learner and uniform clock bounds apply. In an unspoiled pair the selected rank cannot win. Some other rank strictly smaller than the selected one must therefore win that stage. These blocking winners are distinct across stages since winners retire permanently. There are at most $E_l$ ranks below $E_l$. Only finitely many columns first activate before any fixed common startup threshold. Consequently it already suffices to prove the specified core upper bound on **$E_l+1$ distinct jointly active stages per column, for infinitely many distinct columns**. The stage, the small side and its clauses need not be found algorithmically. Merely exhibiting one easy stage per moving column does not meet this counting criterion.

## Testing the proposed shortcut

The shared refutation is short for a reason one can reproduce without any complexity hypothesis. For two disjoint literal chains of length $L$, put a false unit at the beginning of each chain, implications propagating falsity, and a true unit at its end. Each chain separately is minimally unsatisfiable: deleting one implication permits a change from false to true there, and deleting an endpoint unit permits a constant assignment. Any unsatisfiable subset of their disjoint union must contain one entire chain. If the two end bits instead belong to one shared representation with their mutual exclusion as a clause, forcing both true gives the constant refutation immediately. The independent histories are what a positive proof for an individual pin must address.

The remaining upper-bound question is about sound, locally checkable proofs of an identified loss. A proof costing $O(M^{1/k-\epsilon})$ for one member of the pair formed against its own verifier, on infinitely many scales, would contradict $O(N^k)$ SAT. A different locally indexed CNF encoding can also use the conditional small-core tests with their stated quantifiers. For the adjacent-row final-register encoding above, the unconditional $\Omega(M)$ core bound rules out that upper bound. With separate trial modules, subpower-size cores characterize earlier retirement on late stages, and the stabilized learner can spoil only finitely many designated pairs under the fast-SAT hypothesis.
