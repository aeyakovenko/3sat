# Short adaptive SAT queries on a linear native source

There is a nondeterministic language of native time $O(n)$ that no controller of the following kind decides on all inputs. On physical length $n$ it makes at most $C\ell(n)$ adaptive yes/no queries to ordinary proper ASCII 3-SAT, with $\ell(n)=\max(1,\lceil\log_2(1+\log_2(n+2))\rceil)$. Every query has $O(n)$ **encoded bits**. Given the input and any answer prefix, its next query can be emitted in packed form, or its final answer returned, in $o(n/\ell(n))$ deterministic native steps. The constants may depend on the fixed controller. Both positive and negative answers can change subsequent files, and the restrictions apply to every proposed prefix within the cap. The controller may issue $\Theta(\log\log n)$ different linear-size files on one actual input.

The underlying quantitative statement concerns a fixed uniform branching procedure. A putative answer to its next question is an existential predicate evaluable from the current input and the answer prefix in $o(n/\ell(n))$ one-bit-guess RAM steps with at most $O(n/\log n)$ guess bits. Its stopping/final-verdict procedure obeys the same deterministic step bound. No separate table specifying the final Boolean function is required. With a full $O(n)$-bit proper SAT query, the packed nondeterministic verifier uses $O(1+n/\log n)$ time and guessed bits in addition to the cost of emitting it. The word RAM has zero-initialized memory, the native band's wide logarithmic words, known input length and unit-cost ordinary arithmetic. The underlying packed verifier assumes valid syntax and canonical decimal names even off the true answer path. ## Delayed simulation indexed by answer prefixes

Use the finite-arity tree relay with width varying by stage. At a site $y$ of length $m$, assign a child to each possible question prefix of length less than $a(m)=C\lceil\log_2(1+\log_2 m)\rceil$, rounding up and increasing the fixed integer $C$ to absorb the difference from $C\ell(m)$. The usual binary heap numbers for prefixes of lengths zero through $a(m)-1$ fit in $a(m)$ bits. Reserve the remaining label for a dummy. If that prefix has no next query, its assigned child returns zero. On every other nonroot site the source runs just the current prefix's existential question for the virtual parent, with the parent’s fixed answer-prefix string. Give each such simulation an outer linear clock. This selected question can look at both signs in the prefix. The simulator makes no claim about the honest answers there. [Fixed-arity relay and its native simulation](separate-short-inputs-for-a-finite-boolean-combination.md) · [Žák's hierarchy](https://doi.org/10.1016/0304-3975(83)90015-4) · [Bounded query classes](https://doi.org/10.1137/0219058)

Given all child verdicts, one can decide the controller at the parent by following its actual path, using at most $a(m)$ of its up to $2^{a(m)}$ children. At the root, deterministically evaluate this rule recursively, computing a short leaf's actual controller verdict by exhausting the witnesses to each question on its path. Return the complement of the resulting value. If the controller agreed with the source everywhere, every child would give its parent's actual answer at that child's designated prefix. Induction from the leaves would give the controller's actual root verdict just before the prescribed complement, a contradiction. It is sufficient for the root to visit the children chosen during this evaluation. Soundness uses exact deterministic evaluation of the leaves, including correct negative answers.

## How the lengths pay for the adaptive paths

For a base $B=2^b$ and fixed positive integer $C$ define $L=\lfloor B/(32 C b)\rfloor$, $b_0=b$, and $n_i=2^{b_i}$. Choose an integer $c$ depending on the fixed resource constants and put
$$
e_i=\lceil\log_2(b_i+1)\rceil,\quad
u_i=c+\lceil\log_2 e_i\rceil,\quad b_{i+1}=b_i+u_i.
$$
Here $a(n_i)=Ce_i$. For large $B$ we have $b_i\le B$ through stage $L$. Indeed, as long as $b_i\le B$, $u_i\le c+\lceil\log_2(b+1)\rceil$, and even multiplying this upper bound by $L$ leaves the final exponent below $B$. A short path field needs at most $\sum_{i=1}^L Ce_i \le C(b+1)L < B/16$ bits. The physical input contains a fixed common header specifying the opponent, the parameters and stage, the root-to-site sequence of these digits and zero padding. The digit widths can be computed in one forward pass and recorded at the root if needed. Even at the smallest physical length, computing the entire schedule takes $O(B)$ steps: for each of $L$ iterations an elementary bit-length calculation on an $O(b)$-bit number costs $O(b)$ steps. More efficiently its packed input can be parsed without touching the whole zero tail; malformed inputs default at the hard outer clock. Fixed opponent metadata occupy $O(\log B)$ bits. To simulate the parent on a good input remove the last digit, change the stage header, and extend the zero tail. A packed parent word takes constant-time access to the shortened track prefix and the modified header. For fixed $c$, the parent word width is within a constant factor of the child's.

At every nonroot site the component time, including virtual input simulation, is $o(n_i)$, since $n_{i+1}/n_i=2^{u_i}\le 2^{c+1}e_i$ and $e_{i+1}\ge e_i$. The regular setup just described fits a fixed uniform linear clock independent of the opponent: the elementary schedule loops over $L=O(B/(Cb))$ iterations at fixed native instruction cost, or can maintain the next powers-of-two thresholds by comparisons and increments. A fixed code interpreter is used for the opponent; its fixed factor times the little-oh guest cost is still little-oh. Untrusted metadata are decoded and processed under the same cap.

The root needs at most $P_i=\prod_{j=i+1}^L (C e_j)$ calls to stage $i$. For large $B$, $e_{i+1}\le 2e_i$. Hence for every $i<L$,
$$
\frac{P_i n_i}{P_{i+1}n_{i+1}}
   =\frac{Ce_{i+1}}{2^{u_i}} \le 2C\,2^{-c}.
$$
Choose $c$ large enough that this ratio is at most $1/4$. Visiting one internal node costs $o(n_i)$ for all its at most $Ce_i+1$ controller preparations, including final verdict. The root can resume after a queried child by regenerating the next request from the retained short answer prefix, so no guest work memory needs to survive across recursive calls. The root simulator can construct a node's physical input explicitly in $O(n_i/\log n_i+\operatorname{poly}(b))$ wide-word operations from its path. If the path words are stored as the descent takes place, obtaining a digit does not require scanning its ancestors. Even copying the whole root-to-current path costs $O(1+B/\log B)=o(n_i)$ packed operations. Stage lengths can be held in a root-side array; gathering a node's metadata and digits requires no new stage sweep. Uniformly in the stage, total interior work is $o(n_L)$ by the displayed geometric sum.

Let leaf questions have at most $G\le gB/b$ guessed bits, enlarging a fixed $g$ as needed. Exhausting one short leaf controller costs at most $2^G\operatorname{poly}(B)$, including all its sequential questions and construction of each file. The endpoint exponent obeys
$$
 b_L-\log_2 P_0
 \ \ge\ b+(c-1-\log_2 C)L .
$$
A further fixed increase of $c$ makes this exceed $2gB/b+\Omega(B/b)$. There is consequently room for $P_0$ exhaustive leaf decisions within $o(n_L)$ steps. The root's logarithmically wide words are ample to represent the $G$-bit witness counter in a constant number of limbs, or the choices can be streamed from a binary counter with polynomial-in-$B$ overhead per leaf assignment. The root simulates each node at its declared guest width. It stores the simulated program counter and every guest register in separate host cells, masks arithmetic and shifts to that width, and uses the guest division and out-of-range conventions. On the root host every smaller word fits in one word. For the slightly wider virtual parent at a nonroot site a fixed number of limbs suffices, with the division setup from the native simulation. Input reads stay in the guest read-only bank. Each fresh computation receives a fresh root for its sparse writable bank, so its initial registers and unallocated memory read as zero. Use trie digits of at most one quarter of the host input bit-length logarithm. Give a node's row a never-reused identifier and address a child by the ordered pair of row and digit. A lookup need not allocate and a write creates only a fixed number of rows. The clock bounds all allocated row identifiers by a constant times the physical input length, and the given host width accommodates the pair and a bank tag. Resetting a guest forgets its root. This gives independent scratch across hypothetical questions, witnesses and recursive calls while charging allocation only to executed writes. Controller text is parsed into fixed-size typed instruction records once per source invocation; the register-operand, branch-target and memory-bank checks cost constant time per simulated instruction. [Width convention and simulation](native-unary-clock-band.md)

A single source can carry the fixed parameters and opponent texts in the common header of each tree, as in the finite-arity relay. For each alleged controller, first choose resource constants $C,g$ and then take the fixed $c$ prescribed above. The root evaluator, including its recursive stack, schedule construction, leaf enumeration and all interpreter instructions, runs *inside* the same fixed source clock as every nonroot computation. This clock counts actual host instructions. A malformed input or an exhausted clock returns a fixed default. The uniform setup costs at most an absolute constant times the local length; for each fixed opponent on good inputs all further nonroot and root costs above are little-oh of that length. A single sufficiently large absolute linear cap therefore admits the entire chosen tree for arbitrarily large $B$. The varying track field is genuine binary input data. No tally assertion is used.

## Recovering an unknown number of actual repairs

The quantitative statement applies to a proposed exact physical compiler for this source. Suppose a base file has at most $r(n)\le(1+\log n)^d$ wrong locations for some fixed $d$. The integer exponent bound $d$ is available to the controller. Each wrong site has one intended replacement. Sound certificates identify only actual sites and their intended replacements. Complete certificates can jointly identify every subset of actual sites, including all of them, within the stated resource bounds. Repeated names count once. The true set and its size remain unknown. Define $U_j$ to accept on a certificate of $j$ distinct true sites. Define $V_j$ to accept on such a certificate plus a satisfying assignment to the file after applying those $j$ corrections simultaneously. Assume one uniform program evaluates a selected $U_j$ or $V_j$ in $o(n/\ell(n))$ one-bit-guess steps and $O(n/\log n)$ guessed bits on every branch, with all costs included. For instance, the correction certificates and subset verification together may fit within those bounds, and the corrected proper $O(n)$-bit file may be emitted and supplied to the packed verifier within the residual budget. The assumptions must hold even when too few corrections were made; a total capped verifier with an explicit base semantics suffices in that case.

The true $U_j$ form exactly the initial segment ending at the actual count $s$. Adaptive binary search recovers $s$ using $O(\log(r(n)+2))=O(\log\log n)$ existential questions. Now $V_s$ must repair the entire file on any accepting branch, and it can choose the true repairs if that file is satisfiable. The true output is therefore the single last answer $V_s$. The relay excludes such a compiler even when the pristine SAT verdict and the number of genuinely changed sites are both unknown. The reduction uses the count alone; its controller never learns the names or replacements of the repaired sites. This extends the fixed upper bound on repairs in the earlier relay.

The finite program checks the arithmetic schedule at eighteen choices of base and resource constants and all 8,456 small adaptive leaf tables and gate labelings in its declared families. Core Lean verifies replay under agreement on just the visited questions, the per-gate depth bound and induction on the relay. The source and simulator bounds are manuscript arguments. An Ansatz that splits a single bounded computation into this many quickly emitted near-clock SAT files with adaptive real oracle answers would fail on the source constructed here. Existing local Cook reductions can still output an actual formula of quasilinear size; their power of the logarithm is material to this application. A superlinear lower bound for deciding the supplied ordinary file would require a separate transfer. This result leaves all three unrestricted SAT time targets open.
