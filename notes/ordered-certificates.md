# Can a short menu certify an ordered search over universally checked candidates?

**Research journal, 2026-11-24.** Fix an input x. A g-bit integer w is a valid candidate when every z passes a local test. Write this as V(w) iff there is no z with B(w,z)=1. We want to decide whether any candidate is valid. An ordinary SAT query detects failure of a *specified* candidate. Searching freely for a candidate in the presence of that check adds a quantifier. The following sufficient condition compiles a certificate for the negative answer into a single ordinary SAT instance.

## Labels on cutoff positions

Number the N=2ᵍ positions from zero through N−1. A positive input has a least valid candidate μ. A label function f on positions is suitable on this input if

1. f(i)≠f(j) whenever i<μ≤j.
2. The suffix from μ through N−1 contains at most s distinct labels.

In fact, μ can be any valid position separated in this way. It need not be the least. The least position recovers the usual cutoff interpretation. Here s≥1 is a known budget. Label values can be long strings. Their equality is observable. No procedure assigning truth values to individual labels is required. In particular a reduction of the ordered cutoff problem “is there a valid w≤c?” to an unknown language would suffice if it uses at most s different positive codes on this instance. We use no promise at all on the labels on negative inputs. The use of ordered witness prefixes and sparse reduction images goes back to the left-set approach to Mahaney's theorem. [Mahaney](https://doi.org/10.1016/0022-0000(82)90002-2) · [Grochow on sparse reductions and pruning](https://eccc.weizmann.ac.il/report/2016/162/download)

Start at c₁=N−1. A negative certificate supplies at most s+1 triples (cᵢ,jᵢ,zᵢ) satisfying

    jᵢ ≤ cᵢ,      f(jᵢ)=f(cᵢ),      B(jᵢ,zᵢ)=1.

A subsequent step is allowed only for jᵢ>0, at cᵢ₊₁=jᵢ−1. The certificate must either end at jᵢ=0 or exhibit s+1 pairwise distinct upper labels f(cᵢ).

**Completeness on negative inputs for every map.** Every candidate has a bad witness z. At each step choose jᵢ to be the earliest occurrence anywhere of f(cᵢ). There is one at or before cᵢ. All subsequent upper positions are strictly below this earliest occurrence, so that label can never recur. The chain reaches zero or obtains s+1 distinct upper labels. Its verifier just checks the displayed conditions and the ending. It need not decide whether jᵢ was an earliest occurrence.

**Soundness on a positive input with a suitable map.** Suppose cᵢ≥μ. Equality of the two labels gives jᵢ≥μ by the first condition. The bad witness excludes jᵢ=μ. Hence jᵢ>μ and even jᵢ−1≥μ. By induction the chain cannot end at zero and every upper label lies in the suffix with at most s values. Both possible endings are impossible.

Take a uniformly generated menu of M label functions. Construct the negative-certificate query for each and accept the original input if at least one query is UNSAT. On a negative input all are SAT for arbitrary menu contents. On a positive input one suitable map suffices, and the successful map can depend on the input. Even a map failing the two sufficient conditions still gives a sound positive test when its negative-certificate query is UNSAT. This avoids the cost of validating maps individually. For a single uniformly computed map that works on each positive input, the complement language has an ordinary nondeterministic verifier under polynomial parameter bounds. For an explicit polynomial menu with the same coverage, all M certificates together verify a negative answer.

## Decision clocks and witness recovery

Let U bound the explicit bit costs of computing f, checking B at one pair, and supplying the indices, labels, and bad witnesses for one step. Assume uniform generation at the charged cost. Use logarithmic overhead for ordinary circuit-to-SAT conversion. Verifying the chain takes Õ((s+1)U) bits of explicit SAT, including sorting the upper labels to test distinctness. A solver with deterministic time O(mᵈ) on m encoded bits gives time Õ(M((s+1)U)ᵈ), plus any menu-generation time. Separate calls avoid raising M to the power d. This removes a quantifier level when applying fast SAT to a fixed candidate was already part of the original verifier. When V itself is an ordinary short existential test, guessing w directly in that original test already suffices.

The labels give a faster deterministic way to recover a list of at most s candidate positions. No SAT query is needed to construct this list. Again start at c=N−1 with an empty set S.

1. Add f(c) to S. Maintain a left endpoint a with label outside S and a right endpoint b with label inside S, starting at a=−1, a sentinel outside S, and b=c.
2. Inspect a midpoint's label. Move the right endpoint there if its label is in S, and the left endpoint there otherwise. When the endpoints become adjacent, record j=b. This only uses the two endpoint conditions. Membership in S can oscillate between the endpoints.
3. If j=0 stop. Otherwise restart at c=j−1. Its label lies outside the previous S, so a new label is added on every restart. Stop after recording s positions.

Fix any μ for which the separation and suffix-budget properties hold. As long as the cursor is at least μ, every label added so far belongs to that suffix, and none can occur before μ. The recorded j has such a label, so j≥μ. Unless it equals μ, the next cursor is still at least μ. Avoiding μ on all s records would give s distinct suffix labels and one further fresh suffix label at the next cursor. Thus the list includes **every** position structurally protected by the map, irrespective of the checker V. This argument replaces a search for a globally earliest equal label by a search for a local boundary.

With a dictionary of seen labels the cost of listing is Õ((s+1)(g+1)U) deterministic time. Test each listed position independently by a single SAT query for a violation. For M maps the total is Õ(M(s+1)((g+1)U+Uᵈ)), plus generation time, and a passing position is a valid witness. Conversely, a sorted list of at most s positions gives a suitable map at all its listed positions by changing to a fresh label exactly there, using a dummy label beforehand. Thus a cheap menu of cutoff maps supplies a short, deterministically recoverable list. A small list on which at least one witness is valid suffices. The cost to *produce* the list matters, and a map can be queried without printing a whole list in advance.

For an explicit hierarchy application take the deterministic multitape language H in time O(2ⁿ) outside time O(2^(n/2)) used in [the observation test](conserved-observations.md). Suppose H has an exact presentation ∃w∀z ¬B(x,w,z) with the menu coverage above. If the menu is generated in polynomial time and M,s,U≤2^(n/48) up to polynomial factors, then a cubic ordinary SAT solver implements the negative-certificate algorithm in RAM time 2^(7n/48+o(n)). The quadratic-overhead multitape simulation takes 2^(7n/24+o(n)), below the excluded clock. The deterministic list method improves these exponents to 5n/48 on the RAM and 5n/24 on the multitape machine, using g≤U. The simulation imposes no working-space restriction on the SAT solver. The missing premise is the uniformly generated representation of *this* H with the stated local costs and coverage. Under cubic SAT, an exact base presentation meeting the local bounds cannot have such a menu succeed on all positives except finitely many, since a finite error set could be hardwired.

## How much information does the menu require?

Consider a label function that is fixed independently of the hidden position μ. If it works for m different thresholds μ₁<⋯<μₘ, then f(μ₁),…,f(μₘ) are distinct. For i<j the position μⱼ separates μᵢ from μⱼ. All m labels occur in the positive suffix for μ₁. Therefore m≤s. A fixed menu supporting every hidden position requires Ms≥N. This counting bound is attained with ⌈N/s⌉ functions. Partition the positions into blocks of at most s consecutive positions. For one block, give each of its positions a distinct label, repeat the last label after the block, and use a separate dummy before the block. This works for every threshold in the block. If only K thresholds are possible and their locations are known, one can group these ordered locations in the same way, keeping a label constant up to the next grouped location. Input-dependent label evaluation can escape this fixed-menu lower bound.

### Adversarial errors in the labels

Allow up to e erroneous positions on a positive input. Precisely, a threshold μ is supported by f when some set C of at most s labels agrees with the suffix indicator everywhere except at most e positions: at i the prediction is one iff f(i) belongs to C. The set C is unknown and may depend on μ.

One fixed map can support at most **e+(2e+1)s** different thresholds. Choose its least supported threshold μ₀, if any, with label set C₀. At most e positions from μ₀ onward have a label outside C₀. Fix c in C₀ and consider a supported position μ≥μ₀ with f(μ)=c. If more than e occurrences of c precede μ and more than e occurrences are at or after μ, assigning either truth value to c causes too many errors. Hence among the occurrences from μ₀ onward only the first e+1 and the last e can be supported positions of color c. Summing proves the bound. It is exact on a domain of that size. Prepend e dummy positions to s monochromatic blocks of length 2e+1, using separate labels for the dummy and each regular block. At a cut inside a regular block use the majority side of the cut to classify its color and declare the later block colors positive. Inside the dummy prefix declare all regular block colors positive. Every cut position then incurs at most e errors. Restricting a prefix gives the same coverage on shorter domains.

There is also a uniform deterministic procedure to list O((e+1)(s+1)) positions containing every supported threshold. Put B=2e+1. If B≥N, list the whole domain. Otherwise split it into B nonempty residue classes modulo B, indexed in increasing order within each class, and run the error-free s-position listing on each. For a listed position j include the interval [max(0,j−B+1),j] in that class's cover. Also include [last+1,N−1] in its cover, where last is the class's greatest position; this interval is empty when last=N−1. Retain a position only if at least e+1 classes cover it.

For any fixed supported μ choose an error set of size at most e. At least B−e=e+1 whole classes avoid it. In such a class either μ exceeds its greatest position, which the tail interval handles, or the first class member j≥μ is a protected threshold in the compressed order. Its predecessor in that class, if present, is strictly below μ. For a first class member the clipping at zero suffices. Thus each clean class covers μ, even if μ itself carries a wrong label. Each class contributes at most B(s+1) covered positions, counting its intervals before merging. The total retained count is at most B²(s+1)/(e+1). Sorting interval endpoints and sweeping coverage finds the retained positions without scanning the full domain. Intervals in one class have disjoint integer interiors and endpoints since their right endpoints are at least B apart; its final tail starts after its greatest member. The listing cost is Õ((e+1)(s+1)(g+1)U) including the sweep and output. Testing the resulting candidates costs a further Õ((e+1)(s+1)Uᵈ). Neither step needs the error positions or the label set.

Checking that a *given* map protects the **least** valid position can already decide a universally then existentially quantified problem. From a Boolean circuit Q(u,z) give candidate position u+1 the test V(u+1) iff ∀z Q(u,z), choose a strictly larger final position, make that last candidate valid unconditionally, and make all other positions invalid. There is always a valid candidate. Supply the fixed two-label map that changes only at the last position and set s=1. If every earlier candidate fails, this map is suitable. If any earlier candidate succeeds, the label at zero equals the label at the first success, crossing the cutoff. Protection of the least valid candidate is therefore equivalent to ∀u∃z ¬Q(u,z), a complete problem for the second universal level of the polynomial hierarchy. The fallback itself is always protected in this example. Checking whether **some** valid position is protected has a different bound. For polynomial parameters the midpoint algorithm lists every structurally protected position. At each listed j, validity is coNP, and failure of structural protection has a witness consisting of a cross-cut collision or s+1 distinct suffix labels. A polynomial disjunction of these coNP tests is in coNP. It is coNP-hard even with an always-valid fallback: take f constant so only position zero is protected, and give that position the arbitrary universal test. The menu decision algorithm avoids both kinds of validity check.

## A directly checkable ordered class

For an independent source of short ordered checks, suppose each z describes an interval I_z of candidate integers, or the empty set. Let B(w,z) mean w belongs to that interval. On a positive input assume only that the initial segment strictly before the first uncovered point μ can be covered by t of the *listed* intervals. Its empty prefix costs zero. There is no cover-size condition on negative inputs.

One ordinary SAT query tests whether [0,c] is coverable by at most t listed intervals. Guess an ordered chain extending the continuously covered prefix by adjacent or overlapping intervals to at least c. This property decreases monotonically with c. Use O(g+1) queries to find the longest such prefix, allowing an empty prefix. Test the next point for membership in any listed interval with one further SAT query, or reject directly if the entire domain is covered. On a positive input the next point is exactly μ. On a negative input every tested point has a blocker. The decision time under fast SAT is Õ((g+1)((t+1)U)ᵈ) when U pays one endpoint evaluation and its index widths.

Greedy interval covering can use smaller queries. At the first still-unprocessed point p, ask whether a listed interval contains p and extends at least as far as a specified endpoint. Binary search over endpoints finds the greatest available right endpoint using O(g+1) SAT decisions of size Õ(U), or discovers that p is uncovered. Jump to one past the farthest endpoint. In any cover of the required prefix choose an interval containing p; the greedy jump passes its right endpoint, so that interval can be discarded from the remainder of that cover. Induction gives at most t jumps before reaching μ. Apply one final point check and reject on failure. This gives time Õ((t+1)(g+1)Uᵈ), uniformly and without checking a proposed labeling map.

The interval condition alone places no restriction on the original quantifiers. For arbitrary B(w,z) let the index (w,z) describe the singleton interval [w,w] when B(w,z)=1 and the empty interval otherwise. The uncovered candidates are precisely the valid candidates for the original ∃w∀z problem. Even a bad prefix whose union is one unbroken interval can require one listed singleton per point. The cover size used by the algorithm is an additional premise about the available local witnesses. Neither ordered construction supplies those witnesses for a general hierarchy machine.

[OrderedCertificates.lean](../lean/OrderedCertificates.lean) proves that every negative input has a bounded jump certificate for every label map, that a map protecting any valid candidate excludes all such certificates, and that per-positive menu coverage gives an exact decision. It also verifies that midpoint bisection with opposite endpoint values finds a boundary in the allowed number of probes, and that every listing obeying the boundary rule includes each protected position. The SAT compilation and asymptotic clocks are manuscript arguments. Priority of the particular certificate and quantitative listing formulation has not been established.
