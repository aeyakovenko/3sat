# A fixed program whose last output bit tests the SAT time bounds

**Research journal, 24 November 2026.** Can one fixed program replace the random selection of program names in the [earlier parity test](parity-of-program-fibers.md)? For a plain interpreter with literal compiler headers, the answer is yes if we count all cells. The program copies its data and appends one computed bit. If SAT takes linear time, its computed bits, arranged in a square, differ on more than one sixteenth of the entries from every binary matrix of rank at most one sixteenth of the side. A small-rank approximation to the program's actual bits at infinitely many lengths would exclude linear SAT. I have no such approximation. The construction gives separate tests of the quadratic and cubic hypotheses.

## A fixed procedure that can use an unknown solver

The target is explicit Boolean SAT on the deterministic logarithmic-word RAM. Input size counts encoded bits, and there is no space cap. Fix the instruction set with the usual bit-polynomial implementations of word operations. For each exponent $d$ in $\{1,2,3\}$ enumerate programs together with a positive integer time constant and their parameters for the fixed RAM word convention. A candidate, clocked at $C(n+1)^d$, defines a total bit on valid formulas by treating timeout or invalid verdict as zero. Any correct solver of the claimed asymptotic running time has a representative in the list. Increasing $C$ covers the finitely many initial lengths. Conversely a fixed clocked candidate that gives every correct verdict can be implemented with an explicit countdown in a fixed number of words, at constant overhead per guest step.

At phase $m$ try descriptions of length at most $\lfloor\log_2(m+2)\rfloor$, in length-lexicographic order. Parse numbers in binary, so their values are polynomial in $m$. Test each candidate on every valid formula whose encoding has at most $\lfloor\log_2(m+2)\rfloor$ bits. Determine the true verdict by enumerating assignments to the variables actually appearing. The full small-input search costs $\mathrm{poly}(m)$ bit operations. Use the first candidate passing the tests, with a fixed zero fallback. If any candidate is globally correct, every earlier incorrect candidate has a finite counterexample. At all sufficiently large phases the selected candidate is exactly the first globally correct one. The construction has no oracle for the stabilization threshold. This finite-falsification device also appears in Lipton and Regan's account of universal SAT algorithms. [Original discussion](https://rjlipton.com/2014/05/03/does-program-size-matter/) · [Lean proof of eventual stabilization](../lean/SolverTrialStability.lean)

All the larger computations below use an auxiliary interpreter able to address its clock, for instance a length-aware plain RAM interpreter with native word width $(|p|+2)^2$ on program $p$ and explicit literal headers. At these deadlines its word operations have bit cost polynomial in $m$. A trial candidate simulated on an exponentially long formula has guest word width at most $\mathrm{poly}(m)$, including its varying word constant. A sparse binary trie on guest addresses simulates memory in polynomial work per access. Clocks, reductions and code lookups have the same uniform overhead bound. The SAT assumption itself refers to the fixed logarithmic-word model on the length of the SAT instance. Only the auxiliary machine runs on short programs addressing exponential time.

## Which matrix the program tries to compute

Write $r=\lfloor J/16\rfloor$. Say that a binary $J$-by-$J$ matrix $A$ qualifies if its Hamming distance from every binary matrix of rank at most $r$ over $\mathbb F_2$ exceeds $\lfloor J^2/16\rfloor$. At most $2^{2Jr}$ products of two factors of inner dimension $r$ are possible. The number of disqualified matrices is at most $2^{(1/8+H_2(1/16))J^2}<2^{J^2}$ by the binary entropy bound. Let $R_J$ be the lexicographically first qualifying matrix in row-major order. It exists and is rigid by counting alone. The question for the SAT project is whether a particular time-bounded program actually computes its bits. Efficient oracle constructions of rigid matrices have been studied by Alman and Chen. [Alman and Chen](https://joshalman.com/AlmanChenFOCS19.pdf)

The data consist of a two-bit mode and two strings $y,z$ of $m$ bits each. Put $L=2^m$. Modes 00, 01 and 10 respectively select $d=1,2,3$. Mode 11 returns zero. For the other modes, first apply the phase check below, returning zero if it fails. On a passing phase use the selected candidate for the entire computation.

* For $d=1$ put $J=L$. Test the requested bit by asking whether some qualifying $A$ with $A_{yz}=1$ has no smaller qualifying competitor. Qualification can be tested with a universal choice of factors $U,V$ and a proposed product $Z$. Require that $Z$ be far from $A$ or that some cell of $Z$ disagree with the corresponding dot product of $U,V$. This uses only a scan of $O(J^2)$ bits and one dot product per branch. Negating qualification and quantifying a rival matrix still gives a fixed number of alternations. Each branch, including the row-major comparison, costs $J^2\mathrm{poly}(m)$. The fixed-alternation simulation under linear SAT queries the selected solver and decides this bit within the same bound up to a polynomial in $m$. It need only produce a single bit on this input. [Transcript reduction and fixed-alternation accounting](linear-quantifiers.md)
* For $d=2,3$ let $s$ be the largest integer satisfying $2^{2s}7^{sd^2}\le 2^{2m}$. Put $J=2^s$ and use the low $s$ bits of each of $y,z$. For supplied $A$, a certificate against qualification consists of factors $U,V$. Multiply by Strassen's recursion and count the disagreements in $J^{\log_2 7}\mathrm{poly}(m)$ deterministic work. A quasilinear reduction of this nondeterministic check to explicit SAT and one clocked solver call decide qualification upon complementing the answer. Next guess a completion of a given row-major prefix and run that check. One more SAT simulation decides prefix extendibility. Recover all $J^2$ entries of the first qualifying matrix, testing extension by zero at each step. The work per original input is $J^2(J^{\log_2 7})^{d^2}\mathrm{poly}(m)\le 2^{2m}\mathrm{poly}(m)$. When the selected candidate is correct, the larger $L$-by-$L$ output bit matrix consists of copies of $R_J$. [Strassen's recursion](https://doi.org/10.1007/BF02165411) · [RAM reduction and prefix search](suffix-block-sat-exponents.md)

These are fixed algorithms with an explicit candidate as data. For the reduction at each level use one fixed clocked universal verifier, implemented with the sparse simulation above. Descriptions under test have polynomially bounded constants, so each of the fixed number of reductions has uniform $\mathrm{poly}(m)$ overhead. Prefix search always makes exactly $J^2$ decisions, even after an inconsistent answer. Thus the bit computation is total, and its time bound holds even when all candidate solvers fail. Its agreement with $R_J$ for all sufficiently large phases is conditional on the corresponding SAT time hypothesis.

## An exact alternative for the computed tables

We can arrange that failure of the SAT hypothesis produces recognizable zero tables. Let $c_d(i)$ be the selected candidate index or the special value for no candidate at phase $i$. At phase $m\ge2$ permit the matrix computation only if all indices from $\lfloor\log_2 m\rfloor$ through $m$ equal the same live candidate. Otherwise set the output bit to zero for every $y,z$ in this mode. Repeating all the finite tests costs only $\mathrm{poly}(m)$, since each test phase is at most $m$. If a globally correct candidate exists, all sufficiently large phases pass and the previous rigidity conclusion holds.

Suppose every candidate is incorrect. Each fixed index is eventually absent because its finite counterexample eventually appears. There must be arbitrarily large $j$ for which $c_d(j)$ is absent or differs from $c_d(j-1)$. Otherwise the choices would eventually be one constant live index. For every $j\le m<2^j$, the window contains both $j-1$ and $j$. It therefore fails throughout that interval. At its right endpoint almost all phases so far have zero tables. Consequently **the following are equivalent** for each fixed $d$:

* SAT has no deterministic $O(n^d)$ solver in the target model.
* At infinitely many phases the computed local bit table lies within $\lfloor J^2/16\rfloor$ changes of rank $\lfloor J/16\rfloor$ or less.
* At arbitrarily large $j$ that table is identically zero at every phase $m$ from $j$ through $2^j-1$.

In the second condition one can even require the upper asymptotic density of such phases to equal one. The full output graph still contains the tag-zero copies when the bit table is zero. The equivalence concerns a single mode's bit table. This sharpening is a consequence of finite falsification and the chosen phase check. It does not supply independent evidence that the zero intervals occur. Observations at finitely many phases can precede the stabilization of a correct but previously untested solver. ## Using the native clock to check many more formulas

There is a version with an independently verifiable test for eliminating a candidate. Write $a(F)$ for its clocked Boolean verdict, including the timeout convention. At nonterminal $F$ pick its first occurring variable and form the restrictions $F_0,F_1$ by substituting zero and one and simplifying. A correct candidate satisfies $a(F)=a(F_0)\lor a(F_1)$, and must return the true bit on terminal formulas. The number of distinct variables strictly decreases on each descent. If every local identity and every terminal bit is correct, induction gives $a(F)=\mathrm{SAT}(F)$ for every valid $F$. Thus every wrong candidate has a single finite formula at which a local check fails. Verification of that failure requires only parsing, restriction and at most three clocked runs. No satisfying assignment or proof of unsatisfiability needs to accompany the formula.

At phase $m$ enumerate all strings of length at most $2m$, test every valid root against these identities, and discard a candidate on the first local failure. The two children of a root have polynomial length in $m$, even with a polynomial-cost encoding normalization. There are fewer than $2^{2m+1}$ roots and $O(m)$ trial descriptions. The entire test therefore fits $2^{2m}\mathrm{poly}(m)$, the original bit computation budget. Repeating it for all phases in the window fits as well, since $\sum_{i\le m}2^{2i}=O(2^{2m})$. Replacing the initial small-input test with this one preserves both directions of the phase dichotomy. For explicit clause lists with binary literal indices and delimiters, restriction simply removes clauses and literals. When the encoding of descendants never increases, passing the tests actually certifies the candidate's decisions on **every** such formula up to $2m$ encoded bits, by the same descent. For other serializations the valid statement concerns every failure whose root is within the tested length. The finite test gives no certificate at untested lengths. Asking a candidate whether a much larger local defect exists sometimes eliminates it with one call. A wrong linear-time candidate can pass every one of these self-queries. [Local descent in Lean](../lean/LocalVerdictCheck.lean) · [Self-query and counterexample](checking-a-solver-with-its-own-verdicts.md)

## Selecting the outputs with a literal prefix

Choose an integer $t\ge2$. On data $\mu,y,z$ and bit $b$ computed above, a native routine prints the two consecutive halves
$$
0^{t-2}\,\mu\,y\qquad\quad 0^{t-1}\,z\,b.
$$
The output length is $q=2m+2t$. The raw data have length $q-a$ for $a=2t-2$. Take the header $h$ to consist of the literal compiler header for this routine followed by a self-delimiting representation of its parameter $t$. Its length is a fixed constant plus $O(\log t)$, so we can and do fix $t$ large enough that $a\ge |h|+2$. At every large even output length the computation fits the journal deadline $T(q)=2^q(q+2)^{\lceil\log_2(q+2)\rceil}$, including the fixed interpreter overhead. Different raw data yield different output words, and their order is preserved in the full row-major array.

An eligible name $v$ of length at most $q-2$ has index $2^{|v|}+\mathrm{bin}(v)$ in $q-1$ bits. Pin its initial bits to
$$
0^{a-|h|-2}\,1\,h.
$$
The first one pins the length. The remaining literals pin the program. Thus this one fixed prefix selects exactly the names $hu$ with $|u|=q-a$. Their multiplicity modulo two at each word equals the indicator of the output graph. The two columns for each $z$ in an active row contain $1+b$ and $b$ over $\mathbb F_2$. The second columns alone recover the computed bit table. This argument counts all entries, including those reached by other programs at earlier times. Indeed, for sufficiently large padding, simple copy routines can already print both tags early. [Lean verification of the name selector and timed image parity](../lean/LiteralBranchParity.lean)

If the $O(n^d)$ hypothesis holds, fix its mode. Every rank-$r$ approximation to the full graph restricts to rank at most $r$ on each $J$-by-$J$ tile of the tag-one submatrix of that mode. Hence it must incur more than $L^2/16$ errors there, a fixed positive fraction of $2^q$. It would already suffice, at infinitely many phases, to approximate just the actual $J$-by-$J$ table at rank $r$ with at most $\lfloor J^2/16\rfloor$ edits. For $d=1$ this would complete the project's first goal. The matrix defined to be lexicographically first among qualifying matrices can never have that approximation. The table made by the bounded trial program is an independently defined object.

The fixed-prefix statement uses a literal compiler. On a specially chosen interpreter even the unweighted parity of *all* eligible names gives the same graph. Let names starting in 0 run just this fixed graph generator on the remaining raw bits, with invalid lengths producing nothing. For names starting in 1 of length at least two, ignore the second bit and run the old interpreter on the suffix. Implement this branch without inspecting the ignored bit, so paired names execute identically through every cutoff. Give the remaining short names no output. Each generic computation is counted twice, while the graph appears once per image word. The new interpreter retains a literal universal compiler through its generic branch. Universality with a general computable compiler permits a different behavior for raw bit queries. [A matching of equivalent program names](paired-name-probes.md)

## What an upper bound would have to use

Copying the data, sorting the outputs, and using a single computed bit allow an arbitrary timely Boolean predicate of $y,z$ in this construction. In fact the rank after approximation of the doubled image on active rows is controlled in both directions. Restricting to the tag-one columns gives a bit-table approximant. Conversely, an approximant $D$ with $e$ errors gives the two column sets $1+D,D$ with $2e$ errors and rank at most $\operatorname{rank}(D)+1$. A useful upper bound must exploit the computation of the bit. One sufficient condition is that most of its rows occur, up to a small total number of edits, in a few shared strings of length $2J-1$. The window argument yields a low-rank approximation in that case. A periodic low-rank family needs linearly many such strings even with errors.
