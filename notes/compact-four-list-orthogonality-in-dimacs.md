# A bit-once DIMACS projection for four-list orthogonality

Fix $k\ge2$ and $a>0$. The input consists of $k$ labeled lists, each with $m$ Boolean vectors of dimension $1\le h\le m^a$. A solution is an ordered tuple of **record indices**, one from each list, such that no coordinate is one in all the selected records. For every input there is a proper, dense ASCII DIMACS 3-CNF of encoded length $N=\Theta_{k,a}(mh)$ with exactly as many full satisfying assignments as solution tuples. Each of the $kmh$ input bits occupies a distinct low bit of an ASCII digit, once in the file. All remaining bits are fixed for the chosen dimensions. The file can be generated or matched and decoded in $O_{k,a}(mh)$ word operations. Repeated vectors in a list still count as distinct record choices.

For four lists the consequences run in both directions on this specific family. An $O(N^3)$ SAT solver gives a deterministic $O(m^3h^3)$ four-list algorithm. A four-list algorithm with that bound gives a globally correct SAT program with a cubic fast path on this family. No supercubic lower bound on four-list orthogonality is established here. We give two parameter ranges where the family already admits that fast path.

## The projection and its size

Write $t=\lceil\log_2 m\rceil$ and choose a power of two $b=\Theta(\log m)$ such that $b\le t/16$ for sufficiently large $m$. Use $b=1$ at small dimensions. In each list make a $t$-bit selector for its record. Decode its low $\log_2 b$ bits and its remaining bits separately, with one-hot flags built by prefix-tree gate equivalences. Forbid every high group beyond the end of the list by a unit. For a partially filled last group, forbid each out-of-range low flag conditional on its high flag. This costs $O(2^t/b+b)$ clauses per list and excludes dummy records, including on all-zero input arrays.

For each pair (list $p$, coordinate $j$) make a proposed bit $y_{pj}$ for that selected coordinate. Give the pair its own public bank number $B\in[1,kh]$. For each of the $2^b$ masks $D$, introduce a variable named by the ordinary decimal representation of $B$ followed by precisely $b$ decimal characters, each 0 or 1. Conditional on the selector's low flag at lane $v$, two ternary clauses enforce
$$
                    S_{B,D}\ \longleftrightarrow\ [y_{pj}=D[v]] .
$$
This determines even mask variables that the actual input never references. In each occupied high group, write one implication from its high flag to the mask name whose suffix is the $b$ input bits of this coordinate in consecutive records of this group. The missing lanes of a last partial group are public zeros. Each real data bit therefore changes only the low bit of one ASCII byte. This uses the matrix projection's [shared mask and decimal-name construction](compact-bit-projection-of-matrix-mismatch.md).

At each $j$, force the AND of $y_{1j},\ldots,y_{kj}$ to zero with an equivalence chain and a final unit. The three fixed padding variables $1,2,3$ are forced jointly false by seven proper clauses; use distinct false variables to pad all other short clauses. Allocate nonbank signals beyond the bank range, and pin every unused numerical name below it to zero with a padded unit. Every name occurs and every clause uses three distinct variables. For a chosen valid tuple of selectors, exactly one high group per list is active and all proposed bits are forced. Every other gate value and filler is uniquely determined. The final tests accept exactly the orthogonal tuples. This proves the full model-count statement.

The number of clauses is
$$
 O\big(kh\lceil m/b\rceil + k(m/b+b)+kh b2^b+kh10^b+kh\big).
$$
The $10^b$ term pays explicitly for gaps among ordinary decimal names. For the chosen $b$, both $b2^b$ and $10^b$ are $o(m/\log m)$. All names require $O_{k,a}(\log m)$ bits since $h\le m^a$. Thus $N=O_{k,a}(mh)$, and the distinct data digits give the matching lower bound. Two blank lines of $m$ and $h$ spaces just after the header allow a uniform parser to recover the dimensions even when the input layout is unknown. These lines add $O(m+h)$ bytes.

To generate the file from packed row-major input, first copy to a layout with a power-of-two number of usable lanes per word. The columnwise reads for data digits then take constant native time per bit. One can precompute row bases by running additions. Generate public gate IDs by consecutive ranges and precompute their decimal strings by extending prefixes in a radix-ten tree. Generating every record in time proportional to its length fits $O(mh)$. The inverse parser verifies the header, dimension fields, public records, legal digit positions and the exact end; first check $8kmh\le N$ without overflow before allocating. It can store the decoded input in packed words and fall back to ordinary complete SAT on any other file. The upper bounds here use this complete template check. The comparison with usual fine-grained algorithms uses logarithmic words wide enough to address their polynomial work space. The two native fast paths below also fit the journal's minimum word width.

## A cubic solver for low dimensions

For each list let $c_p(S)$ count the records whose set of one-coordinates contains $S$. Inclusion–exclusion gives the exact number of orthogonal tuples:
$$
                    \sum_{S\subseteq[h]}(-1)^{|S|}\prod_{p=1}^4 c_p(S).
$$
An individual tuple with common support $I$ contributes $\sum_{S\subseteq I}(-1)^{|S|}$, which is one if $I$ is empty and zero otherwise. This is the standard subset-transform approach; the following blocking gives it a small address footprint. For related trimmed subset transforms see [Björklund, Husfeldt, Kaski and Koivisto](https://arxiv.org/abs/0802.2834).

Take $b_0=\min(h,\lfloor\log_2m\rfloor)$. For one fixed subset of the upper $h-b_0$ coordinates, scan all the lists. Among the records containing that subset, tabulate the frequency of each mask in the bottom $b_0$ coordinates. On each of the four tables run the usual superset transform: for each low bit, add the entry with that bit set to the corresponding entry without it. All $2^{b_0}$ resulting counts are now available for the current upper subset. Accumulate its signed terms and reuse the tables for the next upper subset. There are at most $m$ entries per table. For $h=O(\log m)$ all vector masks occupy $O(1)$ words, even if some mask ordinals exceed the native address range. Only the bottom $b_0$ bits index the tables.

Scanning costs $O(m+2^h)$ word steps after reading the explicit bits, because either $b_0=h$ or $2^{b_0}>m/2$. Transform additions cost $O(h2^h)$. The final answer is in $[0,m^4]$, so signed accumulation may use modulus $2^u>m^4$ with $u=O(\log m)$. All counters and products use $O(1)$ native words. Even without a multiplication instruction, shift-and-add costs $O(\log m)$ per term. Total time is $O(mh+(h+\log m)2^h)$ and scratch is $O(m)$ words. In particular the native SAT program takes $O(N^3)$ on all these files for
$$
                h\le 3\log_2m+2\log_2\log_2m+O(1).
$$
For $h\ge\log_2m$ in this range, $2^h=O(m^3\log^2m)$ and $N=\Omega(m\log m)$; smaller $h$ gives a faster bound. The additive constant may be any fixed constant.

## A cubic solver for large dimensions

Put $\omega_S=\log_2 7$. A second native fast path works whenever $h\ge m^{1/(5-\omega_S)}$, whose exponent is about $0.4561$. For $h\ge\sqrt m$, enumerate the $m^4$ tuples and check each in $O(h)$ time, which already fits $O((mh)^3)$. The following argument handles the interval below $\sqrt m$.

A tuple is orthogonal precisely when the intersection of its first two masks has ordinary integer dot product zero with the intersection of its last two masks. Take $H$ a power of two with $h\le H<2h$ (or $H=h$). Organize each side into blocks of $H$ intersections: fix the first record of its pair, and range the second record over consecutive batches of size $H$. There are $O(m^2/h)$ such blocks per side, none of which needs to be held persistently. For each pair of blocks produce the two $H$-square binary matrices of padded pair intersections, and multiply them in the appropriate orientation over $\mathbb Z/(2^u)$, $u=\lceil\log_2(h+1)\rceil$. Inspect only output cells for real records. Their integer dot products are in $[0,h]$, so zero modulo $2^u$ is equivalent to zero over the integers.

Strassen's seven-product identities hold over this ring and use $O(H^{\omega_S})$ scalar operations. Work depth-first, accumulating the output quadrants one product at a time; the recursive scratch is $O(H^2)$ words. To implement scalar multiplication on the separate-operation RAM, tabulate all products modulo $2^u$ once in $O(h^2)$ steps by successive row-wise additions. Concatenating the two $u$-bit residues addresses this table. Here $h\le\sqrt m$, so $O(h^2)$ words and the addresses fit within the native range on large templates. Forming and inspecting the matrices costs $O(H^2)$ work per block pair. No array of $m^2$ pair indices or $m^4$ answers is created. This yields $O(mh+m^4h^{\omega_S-2})$ steps. The second term is at most $(mh)^3$ at the stated threshold. A solver can guard this method by the integer test $h^2\le m$, then choose between it and enumeration by alternating steps and returning the first completed exact verdict. This avoids testing a real-valued exponent or allocating a square above the allowed range. [Strassen, *Gaussian Elimination is not Optimal*](https://doi.org/10.1007/BF02165411)

## What the remaining dimension range would imply

A globally correct solver with a cubic clock on every four-list template would decide four-list orthogonality in $O(m^3h^3)$ time for all $1\le h\le m^a$ of any fixed polynomial bound. Conversely the template recognizer followed by such a four-list algorithm gives a cubic clock there. For the converse when specifying a particular RAM, use a four-list algorithm whose word and address bounds fit the template RAM; the two explicit fast paths above do. A supercubic lower bound for four-list decision in these input units would therefore suffice for the unrestricted SAT objective. Neither the projection nor its parsimonious character proves such a lower bound.

The conditional consequence can be seen directly. Partition the variables of a CNF into four blocks. A block's list enumerates partial assignments, marking a clause by 1 exactly when this assignment satisfies none of that clause's literals in the block. Orthogonal tuples are in bijection with satisfying assignments of the original CNF. For $v$ variables arrange blocks of equal size by adding at most three dummy variables (decision is preserved), so $m=2^{\lceil v/4\rceil}$ and $h$ is the number of clauses. For every fixed clause width, removing duplicates gives $h=v^{O(1)}$. A uniform cubic clock on the projected family over these dimensions would decide bounded-width satisfiability in $2^{3v/4}\operatorname{poly}(v)$ time, contradicting the deterministic Strong Exponential Time Hypothesis. Conversely SETH does not assert hardness at each fixed coefficient of $\log m$. This is the usual split-and-list conditional reduction; here the file length, number of models and physical bit map are explicit. [Dürr, Kipouridis, Lampis and Węgrzycki, discussion of the k-OV implication](https://doi.org/10.4230/LIPIcs.ICALP.2026.85)

The logarithmic quantifier can be made explicit. Suppose **for every fixed** $C$, four-list orthogonality up to $h=C\log_2m$ has a deterministic $O_C((mh)^3)$ algorithm. For fixed clause width $q$, apply the sparsification lemma with parameter $1/8$. It produces at most $2^{v/8}$ sparse formulas, each with at most $D_q v$ clauses for a constant $D_q$. The split above puts every leaf below $C\log_2 m$ for $C=4D_q$. Thus $q$-SAT has a $2^{7v/8}\operatorname{poly}_q(v)$ deterministic algorithm for every fixed $q$, contradicting SETH. Under SETH there is consequently **some** fixed coefficient $C$ where the cubic family clock fails. The proof does not locate that coefficient. [Impagliazzo, Paturi and Zane, sparsification lemma](https://cseweb.ucsd.edu/~russell/ipz.pdf)

Two exact-algorithm results matter for the logarithmic regime. For $h=C\log_2 m$ with any fixed $C$, forming the two lists of $m^2$ pair intersections and applying Chan and Williams's deterministic counting algorithm for binary two-list OV gives $m^{4-\delta_C}$ time for some $\delta_C>0$ in the usual logarithmic-word model with polynomial address space. Their improvement depends on the dimension coefficient; it does not yield $m^3\operatorname{polylog}m$ for arbitrary $C$. Independently, Dürr, Kipouridis, Lampis and Węgrzycki give deterministic decision time $O(m2^{(1-\epsilon_k)h})$ for each fixed $k$ and some $\epsilon_k>0$. Their separate two-list randomized improvement has different guarantees. The stronger running time than quartic enumeration at a chosen coefficient is compatible with the conditional hardness statement above. No priority is claimed for the reduction from list orthogonality to satisfiability. [Chan and Williams, *Deterministic APSP, Orthogonal Vectors, and More*](https://epubs.siam.org/doi/10.1137/1.9781611974331.ch87) · [Dürr et al., ICALP 2026](https://doi.org/10.4230/LIPIcs.ICALP.2026.85)

The [finite audit](../audits/compact_kov_projection_audit.py) parsed 555 proper dense files for arities two through five. It enumerated 5,610 complete satisfying assignments and matched every selector tuple and multiplicity to brute force, including non-power-of-two list sizes. It separately compared the blocked subset count with exhaustive tuple enumeration on 240 instances. The asymptotic counting, length and time bounds are manuscript proofs.
