# Deterministic simulation of nondeterministic tapes of fixed dimension

**Research journal, 24 November 2026.** Let a fixed nondeterministic machine have a fixed number of finite-alphabet tapes, one head per tape, with cells indexed by $\mathbb Z^d$ for fixed $d\ge1$. In a step a head can stay or move to an adjacent lattice cell. Place the input along a coordinate axis on one tape and initialize the other cells to blanks. A conventional sequential input tape is also allowed. For a time-constructible bound $t=t(n)\ge n$, acceptance within $t$ steps is decidable on an ordinary deterministic multitape Turing machine in

$$2^{O_{M,d}(t/\sqrt{\log t})}.$$

The saving has the same logarithmic exponent for every fixed dimension. The external result used here is Strassle and Subercaseaux's Fact 1.3, a deterministic algorithm for circuit-CSP of constant density, at most $v^{9/10}$ inputs per constraint, and $v$ total Boolean variables, using $2^{O(v/\sqrt{\log v})}\operatorname{poly}(|\Phi|)$ time. Their Lemma 2.1 already covers a fixed number of **one-dimensional** tapes. Its proof shares the contents of a block between consecutive visits. Below, one constraint instead checks a sequence of visits to the same cube. This changes the cost of sharing a high-dimensional cube. [Strassle and Subercaseaux, Fact 1.3, Lemma 2.1 and §6](https://arxiv.org/html/2611.11832v1)

## Guessing head locations

Let $b=\lceil t^{1/(8d)}\rceil$ and $r=\lceil t/b\rceil$. Use $r$ epochs, shortening the last to the remaining number of steps. Halted branches can continue in absorbing states. Enumerate the exact head positions and control state at all epoch boundaries. Each coordinate lies in $[-t,t]$. The enumeration uses $O_{M,d}(r\log(t+2))=o(t/\sqrt{\log t})$ bits. Fix the initial boundary to the actual start and retain only patterns with an accepting final state.

Tile every tape by $Q_z=bz+\{0,\ldots,b-1\}^d$. At every intermediate step a head lies in one of the $3^d$ cubes with indices at coordinatewise distance at most one from its start cube. This follows from the displacement bound of $b$ in every coordinate, including from points on cube faces. Repeated border crossings inside a single epoch are allowed. Williams used this multidimensional block geometry in the proof of his deterministic time-to-space theorem. [Williams, proof of Theorem 1.5](https://people.csail.mit.edu/rrw/time-vs-space.pdf)

For a fixed boundary pattern, an epoch record contains one fixed-length branch-choice code per step and the claimed symbol read on every tape at every step. It uses $O_{M,d}(b)$ Boolean variables. A constraint for each epoch replays the finite transition function on its claimed symbols and choices starting with the prescribed state and exact head positions. It rejects invalid codes and compares the endpoint state and exact positions to the next prescribed boundary. This determines all writes, addresses and movements even before checking the read claims.

## Checking tape contents

For each pair of tape and cube, list in chronological order all epochs whose start neighborhoods on that tape include this cube. Across all lists there are $I\le k3^d r$ incidences, where $k$ is the number of tapes. Each epoch occurs once in each relevant list. Split each nonempty list into successive groups of at most $g=\lceil t^{1/3}\rceil$ epochs, filling every group except possibly the last.

A group constraint receives the records of its listed epochs. On the first group for a cube it starts with the actual initial cube contents, hardwired from the input. On each later group it starts with a shared $O(b^d)$-bit description of the cube contents at the end of the previous group. It replays the listed records in order, using their claimed symbols on all tapes to reconstruct the head trajectories and writes. Whenever the relevant tape head is in this cube, compare its claimed read symbol with the stored symbol and then perform its write. At the end, check the contents against the next shared snapshot if another group follows. The last group needs no output snapshot. Unvisited cubes need no constraints. Epochs listed solely because their head *might* visit the cube make no change when their record actually misses it.

An accepting computation supplies a pattern, all records and all snapshots. Conversely, boundary checks concatenate the transitions of any satisfying record assignment. Every claimed read is checked in the history of its unique tape and cube. In that history every earlier write to its cell has been included, in order, starting from the actual input or blank. Shared snapshots preserve these contents between groups. Hence every read equals the most recent earlier write or the initial symbol. Induction on machine steps gives a legal computation ending in an accepting state.

## Paying for variables, arity and bit operations

A list of $h>0$ incidences requires $\lceil h/g\rceil-1\le h/g$ shared snapshots. Summing **only these internal boundaries** costs $O(b^d I/g)=O(t b^{d-1}/g)=o(t)$ bits for fixed $d$. The epoch records cost $O(t)$. Pad with dummy Boolean variables if needed to obtain $v=\Theta(t)$. Each epoch field participates in one boundary check and $k3^d$ group constraints, and each snapshot participates in two groups. Therefore the sum of constraint arities is $O(v)$. A group's arity is $O(gb+b^d)$, even if its internal computation uses more gates. In particular $b^d=O(t^{1/8})$ and $gb=O(t^{1/3+1/(8d)})$, so this is below $v^{9/10}$ for all sufficiently large $t$ at fixed $M,d$. The remaining constraints have arity $O(b)$.

Compute cube indices, lists and hardwired input symbols by sequential scans using $O(\log t)$-bit coordinates. Emit explicit Boolean circuits in polynomial bit time per pattern. For example, unroll the transition table on fixed-length records, and for each simulated step compare its computed coordinates to those of every cell of the one tracked cube. Test reads and conditionally update an array of $O(b^d)$ symbol wires. This uses polynomially many gates in $t$ and needs no unit-cost access to a large integer or a large array. Variables for *internal gates* are unnecessary in circuit-CSP. The strings encoding the circuits have polynomial bit length.

Enumerate patterns one at a time on ordinary tapes, construct the CSP, and apply Fact 1.3 to each. The total time is $2^{O((t/b)\log(t+2)+t/\sqrt{\log t})}\operatorname{poly}(t)$, as claimed. A polynomial time-model overhead in the deterministic solver, including a polynomial bit-cost simulation of its bounded-word operations, preserves this exponent. For example a computation of $U$ word steps on words of length polynomial in $\log U$ with the usual bit-computable operations can be simulated by scanning the at most $O(U)$ written words at polynomial cost in $U$. This comparison concerns the **output simulator**. The simulated machine still has finite-alphabet, locally moving tape heads.

## Comparison with one snapshot per visit

For a simpler construction, enumerate just the change in each head’s cube index at every epoch. It lies in $\{-1,0,1\}^d$, costing $O(t/b)$ bits across all epochs. Put the remaining start and end offsets and finite control into shared variables and compare the recovered endpoint at every transition between epochs. Sharing a fresh full snapshot after every epoch in each of its start-neighborhood cubes gives $O(t b^{d-1})$ variables, constant density and $O(b^d)$ arity, since each snapshot is checked by its producing epoch and the next one including its cube. Balancing the resulting $t/b+t b^{d-1}/\sqrt{\log t}$ exponent gives $b=\Theta((\log t)^{1/(2d)})$ and the proposed $2^{O(t/(\log t)^{1/(2d)})}$ bound. The grouped construction pays for full snapshots only on cubes with long lists.
