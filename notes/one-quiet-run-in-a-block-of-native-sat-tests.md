# One quiet run in every block of native SAT tests

Fix $k=1,2,3$. There is an effectively specified deterministic program $P_k$ with the following properties. A block consists of runs of the same program with the same word size $h$, one run per site. A site is a constant number of $h$-bit words. The observation is after $2^h-1$ native steps. A run is quiet if it has not reached the absorbing return-one location.

1. **Every block has a quiet site**, independently of the complexity of SAT and independently of whether the selected prospective SAT solver gives truthful answers.
2. If explicit SAT has a deterministic unrestricted-workspace logarithmic-word RAM solver in time $O(N^k)$, then at every sufficiently large $h$, **every quiet site** requires at least $2^{h/k^2}/h^{O(1)}$ in combined description and per-atom query time for a native permission table. In particular every layered matrix chart there has width at least $2^{h/(2k^2)}/h^{O(1)}$. A chart of finite width exists for every quiet site.
3. For the implementation below, every quiet site already needs $\Omega(h)$ in combined description and bit-query time, and matrix width $\Omega(h^{1/5})$, unconditionally.

Thus an upper bound on matrix width of $2^{(1/(2k^2)-\eta)h}$ for some fixed $\eta>0$ at just **one site on infinitely many blocks** would exclude the stated SAT clock. The site and its chart may both depend nonuniformly on the block. We have proved existence of a quiet site at each size. We do not know a sufficiently small representation of its permissions. This is a new native program construction alongside the earlier [single-run trial](native-register-and-memory-lifts.md) and the [shared query for one negative width](one-negative-width-beyond-a-threshold.md).

## Each site checks one grounded Horn clause

Use the bit-addressed auxiliary RAM from the single-run trial with $h$-bit registers, $2^h$ memory bits, and an explicit bounded observation. Its proposed SAT solver is separately simulated on its specified standard logarithmic-word machine. For fixed site $y$ and program $p$, make Boolean atoms permitting a program location at time $t$, a particular value of a register at $t$, or a particular bit at memory address $a$ at $t$. Native initialization forces the actual starting facts. Each instruction induces local implications. For example, a permitted LOAD, a permitted pointer $a$, and a permitted bit at $a$ imply a permitted new value for the destination register. STORE and frame conditions allow the actual bit to persist at every different address. Branches and unaffected registers have their own implications. Static arithmetic guards on indices determine whether a clause is present. Require the return-one location to be forbidden at the horizon.

Each ground rule has a conjunction of positive atoms in its body and one positive atom or false as its head. There are no disjunctive existence rules. Induction from the initialized state forces every true location, actual register value, and genuine memory bit into any table satisfying the rules. Thus a satisfying table proves the actual run at $y$ quiet. Conversely the exact native history is a satisfying table when $y$ is quiet. As a finite Boolean function of its indices it has a finite layered matrix representation. This implication holds for *all* semantic tables, whatever their description length.

Let $C_{h,y,z}$ denote the local rule checked at site $z$ for target $y$. Tags distinguish instruction and clause schemas. A constant number of fields specifies time, address, and the operand values occurring in one native rule. Choose the site arity $q$ large enough once, since instructions have fixed arity, even if the program has many registers. There is a site for every rule. Unused codes check a tautology. The $q$ incoming site words initialize $q$ designated registers. The finite program description $p$ is also present at fixed initial bit addresses, and is set externally to this very program's code. In the chart verifier the description, literal initialization, and site parameter refer to exactly that code and that run. One can measure $h$ by the shift-until-zero loop. For the finitely many small sizes before the fixed seeds and schema tags fit, stipulate quiet runs. This specifies a finite program by ordinary compilation and a fixed seed. The universal program has not been assembled into a numerical instruction listing.

## One common choice, many local verdicts

On input $(h,z)$, implement the following operations separately at every site. The common part has no access to the site's value except as preserved input for the final choice of clause. All queries are proper ordinary SAT files. Use the same deterministic encoding and fresh virtual solver state for every call. A failed capacity check in the main computation, timeout of the site itself, or unfinished main call leaves the site quiet. The capped preliminary search has a separate fallback as specified below. Finite per-program clock and invalid-return conventions are functions of the query alone.

* Simulate the common refutation learner for $h$ tape steps and choose the least unrefuted $k$-clocked program. If a correct one exists, the selection eventually stabilizes to a fixed correct program. Direct binary numbering suffices. [Clock selection and simulation conventions](one-fixed-forecast-prefix-for-clocked-sat.md)
* Try dyadic budgets $b=1,2,4,\ldots$ in order. At each budget allow either (a) a deterministic atom evaluator with code and advice of total length at most $b$ bits and at most $b$ execution steps per atom, or (b) a native layered matrix chart of width at most $\lfloor b^{1/5}\rfloor$. A pair of separate bounds and a bound on their sum differ by at most a constant. Ask whether **any** site $y$ has a valid permitted table described in either of these formats. On the first YES, fix this budget for all remaining work.
* Fix the $qh$ target bits in a public order. For the next bit ask whether a valid description exists with the current prefix followed by zero. Append zero on YES, one otherwise. Arbitrary answers still specify a target if the loop completes.
* To obtain permission for atom $a$, ask whether a valid description at the locked budget for the locked target **omits** $a$. Treat NO as permitting it. Query just the bounded number of atoms in $C_{h,y,z}$. Reach return one only if the clause holds.

Each format-(a) description declares its own execution limit $r\le b$ and includes its program and advice. The limit is encoded in binary and counted in its description. Use one fixed deterministic RAM instruction set, a fixed logarithmic coefficient for words indexed by $h+r+1+$ description length, ordinary work memory and advice, and an instruction reading one specified bit of the atom. Out-of-range input probes return zero. The virtual word convention and default after $r$ steps are properties of the description, so testing it again at a larger budget preserves every answer. The atom consists of fixed tagged fields and $O(h)$ bits of indices and values. Start each evaluation afresh. Reject malformed codes identically on both search paths. A syntactically valid program returns zero at its declared timeout. The only public decoder data are its fixed-shape atom and $h$. Any information about the target site used by the evaluator must be in its counted code or advice. The evaluator does not consult the selected SAT solver as a primitive. The bit convention matters in the unconditional small-budget proof. A packed input probe of $O(\log(h+b))$ bits costs that many bit probes here. Topologically listed Boolean circuits have a fixed evaluator taking time linear in their binary gate-list length plus polynomial in $h$ for input handling. A matrix table of width $w$ has a fixed evaluator of code, advice and per-atom cost $h^{O(1)}(w+1)^2$ when $\log(w+1)=O(h)$, by propagating one binary row per layer. Thus large matrix tables still qualify through format (a), independently of the cap on format (b).

The query always concerns validity of *all* the clauses for the supplied target, even when it asks only for a permission at a single atom. Large-budget queries use two levels of ordinary SAT as specified below. [Native chart semantics](native-register-and-memory-lifts.md) · [Ordinary RAM-to-SAT encoding](local-sorting-for-parsimonious-ram-encodings.md)

**Unconditional quietness.** Suppose every site latched. Their completed common computations selected the same cap and target $y$. All completed reads of a particular permission atom agree because they use identical data and deterministic fresh simulations. Complete unqueried atoms arbitrarily. Every $C_{h,y,z}$ holds on this one table. Native soundness then makes $y$ quiet, contradicting its latch. If a site cannot finish the common computation, it already supplies a quiet site. Allowing each site to try different successful tables separately would invalidate this argument.

**Why truthful SAT answers can fill the table without finding an entire witness.** If an affordable chart exists anywhere, true answers take the cap search to a nonempty class, then the prefix queries retain nonemptiness and end at some target $y$ with a chart. A permission bit from the last step is one exactly when every chart in this nonempty class permits that atom. The resulting semantic table is their intersection. It satisfies every ground Horn rule. If all body atoms survive, they hold together in each chart, so each positive head survives as well. A forbidden head cannot have every body atom present, since there is at least one chart. No bound is needed on the matrix width of this intersection. In particular the cost per site is independent of the number of satisfying chart descriptions. Intersecting arbitrary 3-CNF models would fail this test. Closure of Horn models under intersection is classical. [Kautz, Kearns and Selman](https://cdn.aaai.org/AAAI/1993/AAAI93-006.pdf)

## Time and the unconditional finite search

Write $T=2^h$. Before consulting the prospective SAT solver on each existence, prefix or omission question, first run the exact preliminary algorithm below with a fixed cutoff of $\lfloor 2^{h/3}\rfloor$ native steps. Use its result if it finishes exactly. A timeout or a preliminary capacity failure immediately invokes the fallback, including when the candidate synthesis graph is much too large to address. Allocate preliminary state lazily and check before forming addresses. Reset scratch between attempts, for example by keeping a list of touched addresses. This order is part of the fixed program being certified.

**The two SAT levels.** For a *supplied* description and target, a defect is witnessed by one ground rule. Evaluating its constantly many atoms with the supplied description checks the witness. Rejecting an implication is determined by these values and the syntax of that rule. The native instruction schemas and index arithmetic have $h^{O(1)}$ cost. Evaluating the bounded program fits $h^{O(1)}(b+1)$ time, including fixed-ISA interpretation and reading its description. A width-$b^{1/5}$ matrix description also fits this bound, including all its layers. Thus a physical proper SAT file for a defect has construction work and bit length $h^{O(1)}(b+1)$, for $\log(b+1)=O(h)$. Initialize code and advice as read-only data banks in the event-sorting bounded-run compiler. One indexed opcode or advice fetch per elementary access then incurs the compiler’s usual logarithmic factors, absorbed in $h^{O(1)}$. Selecting an entry by a separate full multiplexer per step would lose this estimate.

An outer nondeterministic machine guesses the description and any unrestricted target bits, tests the prefix and optional omitted atom directly, constructs the inner file, and simulates the selected $k$-clock on it. Accept if it answers NO and all direct tests passed. Compile this nondeterministic run to an ordinary proper SAT file and ask the same selected clock for its verdict. A truthful clock implements exactly the intended existence, prefix or omission question. An untruthful one still gives a deterministic function of the public query data. This is a bounded two-level test. No inner call is allowed to invoke this outer protocol recursively. In the generation and simulation, time and allocation caps for the selected raw code are taken from its explicit clock. A fixed selected code gives outer length and construction time $h^{O(1)}(b+1)^k$, and actual time for the final decision $h^{O(1)}(b+1)^{k^2}$. This second power of $k$ pays for checking arbitrary succinct atom evaluators.

For the bit-addressed host, implement word arithmetic bit by bit and translate virtual addresses with a trie on their digits. After selection stabilizes, its fixed conventional SAT solver uses $O(h)$-bit keys in the relevant range. Each simulated instruction, including clearing charged scratch, costs $h^{O(1)}$ native steps. Check capacities before writes. With the strict subdeadline below the time and the used memory both fit. An untruthful or changing selection need not have this efficiency for unconditional quietness.

Through the first successful cap, including target selection and all local atoms, each site makes $O(\log(b+1)+qh+1)=O(h)$ outer calls. Capped preliminary work contributes at most $2^{h/3}h^{O(1)}$. For $b\le 2^{h/k^2}/h^B$ with sufficiently large fixed $B$, the rest of the work finishes before observation on every site, even after doubling the first available budget. Existence of any chart fitting that resource bound therefore contradicts quietness under the SAT clock hypothesis. Conversion of a width-$w$ matrix chart to a bit evaluator gives the asserted square-root threshold. The calculation never adds the runtimes of all sites.

**Exact preliminary search.** For format (b), use the native finite-alphabet dynamic program at width $w=\lfloor b^{1/5}\rfloor$. At each layer choose the chart matrices and the same next digit of each target word for all tests. Restrict those choices by the target prefix, or fix the target for an omission question. Initialization equalities use these digit choices. Testing omission of a specified atom adds a single-factor terminal condition. Each native failure test uses at most four synchronized width-$O(w+1)$ factors. A reachable subspace has a basis of actual factored rows. Storing the four factors for each of $O_P((w+1)^4)$ basis rows costs $O_P((w+1)^5)$ bits. The dynamic program runs in $2^{O_P((w+1)^5)}h^{O(1)}=2^{O_P(b)}h^{O(1)}$ time. At small caps the needed addresses fit $h$ bits. [Factored-basis search](witness-search-on-the-forecast-clock-files.md#exhaustion-of-growing-matrix-widths)

For format (a), enumerate the $2^{O(b)}$ codes and advice strings. Given one such decoder and a rule schema, test for a violating ground instance by enumerating the answer bits supplied to its constantly many atom evaluations. There are at most $2^{O(b)}$ joint transcripts. Run the computations on those answers, recording each bit position read and the returned value. Keep only transcripts giving a violating pattern of atom values. Ground index variables, including the operands of bitwise operations, may now be checked by digit scan. The native relations for equality and inequality, increment or decrement by one, bitwise operations and fixed-position shifts have constant-state synchronous digit checks. Fixing a queried digit of an atom field adds a prescribed bit in its column. Equality with static constants, bank or position tags is explicit. Equivalently introduce copies of all atom arguments and enforce the static arithmetic by the same transducers. Feasibility of all recorded constraints is decidable in $h^{O(1)}$ time by reachability through the digit layers. Repeated or overlapping reads must agree on one tuple. For larger scalars or a different instruction set this finite-state dependency has to be checked afresh.

The site $y$ is **one common existential choice**. It occurs only in the actual initial values of the $q$ site registers. Apart from those initial units, every clause of this fixed program is independent of $y$. For each such register test that an allowed value exists in its specified prefix subcube by one accepting evaluator transcript and digit feasibility. These $q$ values may be chosen independently because the site space uses all $qh$ bit strings. Initialization of code memory and all other registers remains universal as stipulated. An omitted atom, asked only with a fixed target, can be evaluated directly. This proves the $2^{O_P(b)}h^{O(1)}$ preliminary algorithm for the entire menu.

Choose $c>0$ sufficiently small after fixing the program. Through every budget at most $2ch$, all the preliminary calls finish inside their timeout. A chart with evaluator code, advice and query time bounded by $ch$, or a matrix chart of width at most $(ch)^{1/5}$, would therefore lead to truthful common choices and every site latching, without any hypothesis on SAT. This proves the unconditional bounds on the same program. On word sizes two through four the transcript audit matched exhaustive grounding in 5,796 checks, including repeated-bit constraints across different atoms. ## Locating one quiet site by following the actual run

There is an unconditional offline algorithm finding a quiet site in $T^2h^{O(1)}$ work, without looping over the $2^{qh}$ sites and without a chart. This uses an auxiliary machine with $O(h)$-bit words and $T h^{O(1)}$ bits of addressable storage. It is not a fast procedure on a succinct standard RAM input.

Run one arbitrary site through observation. If it is quiet, output it. Otherwise recover its completed common budget and target $y$. Run $y$ through observation, recording its native trace. If it is quiet, output $y$. For the remaining case define a common permission table by evaluating each requested atom from the canonical post-selection baseline for at most $T$ steps with a fixed default if unfinished. Every atom used by a site that latched agrees with that table because it got an answer within its actual smaller remaining budget. A site can test all its atoms eagerly. Then a false clause under the table always names a site that did not latch.

The actual return-one location at the terminal time is a true execution fact. If its permission is present, the forbidden-head clause fails. Otherwise start from that missing true fact. At a positive time the recorded execution supplies a specific transition implication with this fact as its head and actual facts one tick earlier as its body. Either every body atom is permitted, exposing a false clause, or one is a missing true fact at an earlier time. At time zero a missing true fact exposes a false initialization clause. This path visits at most $T+1$ levels and queries constantly many atom values per level. For a register or control fact use the recorded predecessor instruction and operands. For a memory fact consult the actual store address and bit, if any, and otherwise use its persistence implication. The true earlier bit on a persistence step is the current bit. The trace can also store the former bit on every actual write. Together with bounded atom evaluation this proves the offline time bound. A timed-out atom on its own need not identify the quiet site. The algorithm returns the site of a false clause. [Lean descent on timed Horn derivations](../lean/HornBackwardWitness.lean)

Obtaining the quiet site's **number** is weaker than obtaining a short permission table certifying it. The native trace itself gives an $O_P(T)$-width exact table. Store one timestamped singleton per step for control and registers. For each bit address, begin with its initial value and toggle it on the suffix of times following each actual value-changing store to that address. A timestamp comparison and an address singleton have constant layered width at a fixed binary threshold and address. The sum over $\mathbb F_2$ has width proportional to the number of events. This upper bound remains above every width sufficient for the SAT contradiction.

Local checks alone need not have a useful density of failures. On a run that actually reaches return one, fix any transition time. Follow the exact trace up to that transition, preserve the genuine updated memory and registers, then substitute the absorbing quiet control location for the genuine next control location and continue in it. The singleton table satisfies initialization, terminal quietness and every other transition slice. Only the required control successor at the cut can fail. Thus even fully specified tables can concentrate the fault at any one of the $T-1$ slices. This is the native-permission version of the earlier cut construction. [Single-cut faults in time-indexed computation formulas](winner-tableau-cut-faults.md)

## Two more explicit tests for the missing upper bound

Even giving the chart evaluator unlimited preprocessing at a fixed quiet site and unlimited computation between bit probes does not make small probe depth automatic. A binary decision tree of depth $d$ on the fixed $O(h)$-bit atom format has an explicit description of $O(2^d\log(h+2))$ bits by storing each internal queried position and leaf value, using a complete tree layout. A fixed evaluator follows it with $O((d+1)\operatorname{polylog}(h+2))$ work apart from any fixed addressing overhead (the table can be indexed by the path so far). For the relevant $d=O(h)$, a packed array of node labels of width $O(\log h)$ gives $O(d+1)$ word accesses. The unconditional lower bound forces worst-case depth at least $\log_2 h-\log_2\log_2(h+2)-O(1)$ for every valid table. Under $O(N^k)$ SAT it forces depth at least $h/k^2-O(\log h)$. One can therefore attack a specific, unrestricted decision-tree *upper* bound for permissions at one quiet site; no uniform algorithm has to construct that tree.

Once the interpreter, compiler and clock numbering are fixed, there is one Boolean function per $k$ that avoids an existential choice of site in its definition. Choose the quiet site by the deterministic backwards algorithm above, with a fixed tie order, and run that site for $T-1$ steps. Form two public arrays of $T$ records. The first gives the native control and registers at each time. The second lists actual bit stores sorted lexicographically by (address,time), storing the bit written, with a dummy tag on remaining records. Initial memory is public. The combined table has $O_P(Th)$ bits. Query one bit by a tagged $h$-bit row index and $O(\log h)$ column bits. Use zero for unused fields. The two arrays can be built in $T^{O(1)}$ time, also on a deterministic multitape machine by a polynomial-overhead simulation and sorting. Hence this bit function is in deterministic time $2^{O(m)}$ for query length $m=h+O(\log h)$, with a uniform length convention (e.g. recover $h$ from the strictly increasing length $h+\lceil\log_2(ch+c)\rceil+1$ and assign zero on unused lengths).

Given a circuit computing these table bits on that length, a chart evaluator reads true control and register entries from the first array. For a memory atom it uses binary search in the second array for the last store at the address strictly before the observation time, returning the initial bit if there is none. $h^{O(1)}$ bit queries to the circuit suffice, including reading and comparing record keys. The exact permissions so obtained are a valid chart for this particular quiet run. A $g$-gate bounded-fan-in Boolean circuit has a topological binary description of $O((g+h)\log(g+h+2))$ bits. Consequently a putative $O(N^k)$ SAT clock forces $2^{h/k^2}/h^{O(1)}$ gates for this single specified bit function at all sufficiently large supported lengths. An upper bound below that threshold infinitely often would contradict the clock. A generic near-linear-size table encoding in $T$ leaves the required saving open. The sites and sorted traces used here are mathematical constructions. We have not generated a numerical trace of the full universal program.

## Consequence for an individual ordinary solver

One can also fix any globally correct ordinary SAT solver $S$ directly in a variant and use the explicit matrix verifier from the single-run construction for all large-budget queries, avoiding nested calls to an unclocked $S$. Use just matrix widths $1,2,4,\ldots$ as the common menu here. That verifier checks a supplied width-$w$ chart in $h^{O(1)}(w+1)^{12}$ time by propagating spans for every ground defect, before the one outer call to $S$. Quietness still holds in every block. Suppose some site has a width-$w$ chart, with $h^{A}(w+1)^{12}=o(T)$ for a sufficiently large fixed $A$ to cover file emission and host overhead. Then at least one ordinary query to $S$ through the first successful cap and its local checks takes $\Omega_S(T/h^{a})$ actual $S$ instructions for some fixed $a$. Otherwise every required call would fit on every site, including emission and $O(h)$ calls per site, so all sites would latch. The set of ideal queries is finite and effectively enumerable given $h,w,S$. A finite exact history alone gives no suitable size bound.
