# A short witness for an unreachable counter word

For each sufficiently large $m$ there is an ordinary 3-SAT template with $m$ pinned data bits $x$. Its positive inputs form a set $B_m$ of at most $O(m^4)$ words. Unsatisfiability on the template has a $\log_2(m/\log m)+O(1)$-bit certificate checkable with $O(\log m)$ data-bit probes. This proof length is optimal up to an additive constant at that probe budget. Yet in **every** affine binary coordinate system on $x$, a conjunction of polynomial equalities on those coordinates that recognizes the negative inputs requires a single equation with $2^{m/2-O(\log m)}$ squarefree monomials. The minimum total number of monomials, optimized over coordinate systems, is $2^{m/2+o(m)}$. Each coefficient field may be chosen arbitrarily for the basic equation bound. The affine changes are on the binary input bits. Equations are expanded in ordinary $0,1$ variables.

## A small set with an efficiently verifiable complement

Set $L=\lceil 2\log_2 m\rceil$ and assume $2L\le m$. Let $B_m$ contain all words for which some $p\in\mathbb F_2^L$ satisfies
$$
 x_{i+L}=\sum_{j=0}^{L-1}p_j x_{i+j}\quad (0\le i<m-L).
$$
The initial $L$ bits and the coefficient vector specify the word, giving $|B_m|\le 2^{2L}<4m^4$ (use a non-strict bound if desired). A fixed Boolean circuit tests all the recurrences using $O(mL)$ gates. Existentially quantify $p$, pin the $x_i$, and convert these gates into ordinary 3-CNF by their local tables. Thus the files have $O(m\log^2 m)$ encoded ASCII bits. A unit pin is expressible as four triples with two distinct fresh variables in all four sign patterns; binary clauses can likewise be padded with opposite signs of a fresh variable. Choosing a space or a minus sign before a data literal keeps every file in a template at the same length.

Write the displayed equations as $Ap=b$. On a negative word $(0,\ldots,0,1)$ belongs to the row span of $[A\mid b]$: otherwise a linear functional vanishing on that span and taking one on this last unit vector gives a solution $p$. A basis of the augmented rows has at most $L+1$ members. Listing at most $L+1$ row indices whose sum is that unit vector takes $O(\log^2 m)$ bits. A checker reads at most $L+1$ windows of $L+1$ consecutive bits and XORs them. On input supplied by random access the checked proof requires only polylogarithmic work. The indices identify ordinary data bits; instantiating arbitrary-index lookups in a Boolean circuit on unknown data has a separate cost.

Membership can also be decided deterministically. Solve the first $L$ equations (from the first $2L$ samples) by elimination, reject on inconsistency, and take any coefficient vector passing them. Extend the initial samples by that recurrence and compare with the entire input. Any two infinite order-$L$ recurrence sequences agreeing on their first $2L$ entries coincide. Their difference is annihilated by the product of their two monic degree-$L$ polynomials in the forward shift, hence satisfies a monic order-$2L$ recurrence with zero initial data. Thus any choice passing the prefix suffices. On a word RAM of width $\Theta(\log m)$, the $L$-bit state fits a fixed number of words. Parity for one feedback step can be tabulated on chunks of $\lfloor(\log_2 m)/2\rfloor$ bits in $O(\sqrt m)$ steps, so the data test takes $O(m+\operatorname{polylog}m)$ steps. Template checking and re-creating the fixed names in decimal takes $O(N)$ word steps on the $N$-bit files, with ordinary exhaustive SAT as fallback on other syntax. The synthesis of a minimum-length feedback register for a finite word is classical. [Massey on shift-register synthesis](https://www.isiweb.ee.ethz.ch/archive/massey_pub/pdf/BI411.pdf)

There is an optimal shorter certificate. First solve the prefix system exactly as in the decision algorithm. If it is inconsistent, every continuation is negative. Otherwise fix the canonical prefix solution, with free variables set to zero in a fixed elimination order. The full word is negative precisely when some equation fails for that solution. Partition the $m-L$ row indices into consecutive blocks of $h$ indices. Guess one block and verify the rows there, accepting when any one fails. The checker reads at most $2L$ prefix bits and $h+L$ bits in one consecutive data window. Its fixed-length proof takes $\lceil\log_2\lceil (m-L)/h\rceil\rceil$ bits. At $h=L$ its bit work is $\operatorname{polylog}(m)$.

For the converse, $0^m$ is positive. Flipping any one of the last $m-L$ bits gives a negative: a homogeneous recurrence from its first $L$ zero bits stays zero. If a sound and complete negative verifier has $b$ fixed proof bits and probes at most $q$ data bits on each proof on $0^m$, the baseline traces together must probe all $m-L$ positions. Otherwise their adaptive replies are unchanged by one such flip, and no proof can recognize that negative word. Thus $2^b q\ge m-L$. For $q\ge4L$, taking $h=\min(m-L,q-3L)$ matches the lower bound to within a constant number of proof bits. This query bound concerns the promise of the published template and random access to its pinned data. A raw read of a fixed literal sign field depends on at most one such bit. Full input validation on an arbitrary DIMACS file takes its own work.

## Why expanded equations become long

Use the standard small-bias field construction. For $q=2^L$, choose $z\in\mathbb F_q$ and an $\mathbb F_2$-linear functional $u$ of this field independently and uniformly. Take $x_i=u(z^i)$ for $0\le i<m$ with $z^0=1$. A nonzero binary parity has bias at most $(m-1)/q$: conditioning on $z$, averaging $u$ gives zero unless $z$ is a root of the corresponding nonzero polynomial of degree at most $m-1$. These sampled words belong to $B_m$. Multiplication by $z$ is an $L$-dimensional linear map, whose monic characteristic polynomial supplies the recurrence. Repeated sampled words cause no issue because we only use the expectation. [Alon, Goldreich, Håstad and Peralta, small-bias constructions](https://doi.org/10.1002/rsa.3240030308)

In any affine basis each coordinate of this distribution is zero with probability at least $(1-(m-1)/q)/2$. In this basis some $v\in B_m$ has at least $(m-1)/2$ zeros. A system with common zero set $\{0,1\}^m\setminus B_m$ must contain one polynomial $f$ nonzero at $v$. Its support in value space lies inside $B_m$. Pin the one coordinates of $v$ to one. The remaining $d$-variable polynomial is nonzero at zero, has at most $|B_m|$ nonzero values and has no more squarefree monomials than before. For an $s$-sparse multilinear polynomial over any field nonzero at the origin, there are at least $2^d/s$ nonzero values. This is the uniform case of Awasthi–Feldman–Kanade's Lemma 11 and has an earlier binary case due to Karpinski and Luby. It gives $s\ge 2^{(m-1)/2}/|B_m|$. Independently, the standard degree bound $|\operatorname{supp}(f)|\ge 2^{m-\deg(f)}$ shows that any nonzero equation of this system has degree at least $m-\log_2|B_m|$ in the selected basis. The degree bound follows by fixing all variables outside a monomial of maximal degree: in every such restriction its coefficient survives. [Awasthi, Feldman and Kanade, Lemma 11](https://proceedings.mlr.press/v30/Awasthi13.pdf) · [Karpinski and Luby](https://www.sciencedirect.com/science/article/abs/pii/S019667748371014X)

Here is a short rank proof of the uniform sparse-polynomial bound. In the Boolean quotient $x_i^2=x_i$, multiplication by $f$ has rank equal to its number of nonzero values, since evaluation identifies this ring with the direct product of copies of the field. In the squarefree monomial basis each column $x^S f$ has at most $s$ entries. The image contains the point indicator $\delta_0=\prod_i(1-x_i)$, since $f\delta_0=f(0)\delta_0$. This indicator has all $2^d$ coefficients nonzero. A basis of the image chosen from the original columns must cover these coefficients, giving $2^d\le s|\operatorname{supp}(f)|$. A coordinate face through zero attains equality. Related work on Möbius support for simplicial complexes and infinite locally finite posets uses different hypotheses; the sparse-polynomial probability bound above already gives the required general finite-field result. [Cao and Lü, Theorem 3.5](https://arxiv.org/abs/0908.3174) · [Goh on Möbius inversion](https://arxiv.org/abs/2302.02466)

For the matching leading exponent, translate the coordinates by a uniformly random word. With positive probability every word of $B_m$ then has at most $m/2+O(\sqrt{m\log m})$ zeros, by the binomial tail bound and a union bound over $O(m^4)$ words. Use one equation $\delta_v(x)=0$ per translated word $v$. Each such point indicator has exactly $2^{\#\text{zeros}(v)}$ ordinary squarefree terms, proving the upper bound for the total size.

There is a quantitative dependence on the coordinate convention. Over $\mathbb F_2$, allow $m+a$ affine binary features of full rank on the counter. Choose $m$ independent linear parts to make a coordinate system. Substituting for the remaining $a$ features expands any one feature monomial into at most $\sum_{j=0}^{\min(a,m)}\binom mj$ ordinary squarefree monomials: its product of extra affine factors has degree at most $a$, and the independent-coordinate factors are a single monomial. Divide the preceding size lower bound by this binomial sum. For $a=o(m)$ its leading exponent remains $1/2$. Polynomial sparsity requires $a=\Omega(m)$. Conversely $a=m$ suffices: use both $x_i$ and $1+x_i$ as coordinates and test every forbidden point by one positive monomial. Even in the original coordinates, retaining products in factored form gives a polynomial-size description. A changing time parameter or independent witnesses are different representation choices.

## A checkpoint on the solver's own prefix

In the [one-sided forecast argument](one-sided-certificates-on-a-forecast-prefix.md) the wide guest runs a sound compiler and a correct SAT solver, reporting zero only on a satisfiable answer. On this guest's own diagonal header no such report can latch before the observation. Insert the following preamble in the guest before running those same two programs. Set $n=|\operatorname{bin}W|$ and $m=\lfloor\log_2 W\rfloor-K\lceil\log_2(n+2)\rceil$ for a sufficiently large fixed $K$; skip finitely many short inputs. Enumerate every $m$-bit counter word. Test membership in $B_m$ by the deterministic algorithm above. For a nonmember clear the scratch, enter a designated instruction with only the counter varying, and run the same membership test again. An affirmative result here would immediately report zero, without running the compiler. All other paths continue enumeration and eventually run the compiler and solver. Bits outside the counter at the designated entry can be reset to fixed values: all work on a trial uses $\operatorname{poly}(m)$ predetermined addresses. This preamble takes $2^m\operatorname{poly}(n)=o(W/n)$ wide instructions. Its extra return is genuinely unreachable. Hence the new guest's own prefix has the same one-sided dichotomy for the actual SAT call as before, with the new prefix and constant.

At this guest-level instruction all $x\notin B_m$ occur with ample time left. For every hypothetical $x\in B_m$ with the same fixed auxiliary values the second test causes the otherwise forbidden report in $\operatorname{poly}(n)$ instructions. A clock-independent assertion on the $m$ data bits used to allow all genuine visits and forbid this local return therefore has precisely the common zero set analyzed above. In particular a literal list of squarefree monomials in any affine data basis needs $W^{1/2}/\operatorname{polylog}W$ terms on this portion of the guest. This exceeds the cubic SAT transfer's formula budget. The failed-block index supplies a short existential proof for every individual genuine checkpoint, and inspecting the duplicate membership test proves safety of this entire preamble directly. It gives no certificate for the subsequent call to the actual solver. No unrestricted RAM or general proof-size lower bound for SAT follows.
