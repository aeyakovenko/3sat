# Eliminating an unknown tape word shared by several sweeps

**Research journal, 2026-11-24.** Once tape addresses are public, can a verifier leave a long common tape word unspecified and ask if its neighboring blocks can all use it? The synchronized case below has a sublinear-in-word-length test when the finite controls change state infrequently. Two other synchronized sweeps already support PSPACE-complete reconciliation on succinct instances, even though each sweep alone always has a short completing word.

## Choose the common symbol independently at each position

Consider r constraints scanning the same existential word of length L in the same order. Constraint j has a finite control with prescribed initial and final states. At position i its step from u to v on the shared letter z is allowed by a public predicate Cⱼ(i,u,v,z). Include time-index lengths, state descriptions and the cost of any public input-dependent tests in a size bound S for one predicate and its interfaces. Charge U for uniformly producing the local descriptions from the original input. The r constraints may represent successive passes over unchanged data. If a machine changes a boundary symbol subsequently reused at another position, that dependency needs a separate constraint. This is a hypothesis about the representation of the verifier.

Guess the state changes of each controller, recording the old and new states and the time of every change. Check time and state ranges, ordering, endpoints and the cap R on the total number of changes. For controller j with Rⱼ changes, split its time axis into at most 2Rⱼ+1 nonempty half-open intervals: singleton change positions and intervening constant-state segments. The transition pair is constant within each piece. There are P≤r+2R pieces in total. Initial/final state sets can also be used by checking the guessed endpoints. A class where the change cap is automatic consists of partially ordered finite controllers whose allowed strict moves always increase state. In this case R≤Σⱼ(heightⱼ−1), even if every pass reads a long arbitrary word.

Once the trajectories are fixed, at each i there is a collection of r subsets Aⱼ(i) of the shared alphabet, one allowed set per active piece. The existence of a single common word now means exactly that every column intersection is nonempty. No information that varies from column to column needs to be guessed. In particular, for a shared bit an empty intersection has two witnesses, a constraint forbidding zero and a constraint forbidding one. They can coincide. Test single pieces and each pair of overlapping pieces from different controllers. Guessing a time i in their common interval and checking exclusion of both possible letters is an ordinary explicit SAT query of length Õ(S). The pair test takes the union of the exclusions; it does not assume a predetermined direction for which controller excludes which letter.

There are O(Pr) such tests. In fact, for fixed h, the number of overlapping tuples of at most h pieces from distinct controllers is at most

    P · Σ_{j=0}^{h−1} binom(r−1,j).

Assign each tuple to its last-starting piece, breaking simultaneous starts by a fixed order. At that start time each of the other controllers has at most one containing piece. The bound and enumeration follow by a sweep over starts and ends, removing expired half-open pieces before processing starts. This extends the check to any allowed-set family where emptiness has a subfamily of at most h members and incompatibility of such a subfamily at a given position has a short existential test. A finite alphabet of constant size h qualifies by testing all its letters. For interval subsets of an ordered alphabet with succinctly evaluable lower and upper endpoints, h=2 suffices, also checking for an individually empty set. A Helly bound alone does not give an efficient incompatibility test for a succinct infinite family.

For a Boolean letter and O(mᵈ) deterministic SAT on m encoded bits, the total nondeterministic time is U+Õ(Pr(S+1)ᵈ), including sorted events, circuit descriptions and tests. As in the [hierarchy setup](address-orders.md), the RAM computations on explicit queries can be simulated on nondeterministic tapes with polylogarithmic overhead. For example, r=T^α, bounded controller heights and S=T^β permit a clock strictly below T by a polynomial factor if 2α+dβ<1 and setup also fits. Each YES input needs one accepting joint trajectory under the cap. On a NO input no guess passes. Proving such representations for a genuine near-T hierarchy language would produce the desired contradiction. Public tape addresses alone do not bound these control changes or imply this synchronous factorization.

## A second way to eliminate the word despite frequent state changes

Fix the number of controllers, their state alphabets, and a finite shared alphabet. For each public column type form a binary relation on **joint** states. A pair belongs to it if at least one common letter enables all controllers' transitions for that pair. The type at index i is given by a size-S circuit; with fixed alphabets its full relation can also be computed from the individual predicates by a constant enumeration. The product of these relations in chronological order, using ordinary relational composition, is exactly the relation between possible initial and final joint states. This product existentially removes both the shared word and all private controller trajectories.

Suppose the fixed monoid generated by the permitted column relations is aperiodic. Schützenberger's theorem gives a fixed star-free expression for the words taking an allowed starting state to an allowed ending state. Evaluate that expression on intervals of the succinct type word. Base cases for a letter or the empty word are local. Union and complement cost Boolean operations. For concatenation, guess a binary position splitting the interval, run the two child tests on the two pieces, and determinize this existential check by SAT. Let a be the maximum number of concatenations nested on a branch of this fixed expression. After charging quasilinear RAM-to-SAT encoding, deterministic time is Õ((S+log(L+1)+1)^(d^a)), charging any setup separately; the base circuit is evaluated in quasilinear description time. The expression and its constants are fixed for the whole instance family. Growing monoids or an uncharged search for an expression are outside this estimate. This computation never constructs an accepting track. [Schützenberger](https://doi.org/10.1016/S0019-9958(65)90108-7) · [RAM computation encoding](https://www.cs.cmu.edu/~ryanw/improved-algs-lbs2.pdf)

For example, two-state instructions that preserve the state or reset it to zero or one can generate a trajectory changing at every position. The last reset fixes the endpoint. SAT existence queries on index ranges and binary search locate the last reset in O(log(L+1)) calls of size Õ(S+log(L+1)). This improves on directly nesting a search for a reset around a test that no later reset exists. The aperiodicity condition concerns the relations *after* the shared letter has been eliminated. Merely checking each annotated local step by a short-range predicate permits the next example.

**Try forcing aperiodicity with a clock.** Append a clock 0,…,L to any finite-state trajectory. Each instruction advances the clock, and past L everything goes to a sink. Every nonempty instruction word repeated sufficiently often then has constant sink action. This makes the enlarged monoid aperiodic. It also destroys the fixed-expression bound, even for a two-state parity controller.

More precisely, take letters A that flip one bit and B that preserve it, executing exactly L instructions. Every star-free expression over the raw letters giving the correct parity on all length-L words has nested concatenation depth at least log₂ L−O(1), regardless of its size or of length-specific advice in the choice of expression. Allow atomic languages ε, individual letters, sets of letters, the full and empty languages. On words AⁱBʲ a depth-a expression depends only on min(i,Dₐ) and min(j,Dₐ), with Dₐ=2^(a+1). At depth zero this follows for each atomic language and its Boolean combinations. For a concatenation of depth-(a−1) children, transfer an accepting split to any word with the same capped run lengths. If the split lies in the A-run and that run is short, keep the same split there. If both A-runs have length at least 2Dₐ₋₁, preserve the shorter side whenever it has fewer than Dₐ₋₁ letters. When neither side is short, give each side at least Dₐ₋₁ letters. The unsplit B-run has matching capped length. Splits in the B-run are symmetric. This proves both directions by induction; Boolean operations preserve the invariant. For L≥2Dₐ+1, the words with i=Dₐ and i=Dₐ+1, j=L−i, are indistinguishable and have opposite parity. Thus adding a succinct clock field does not keep the depth of this particular elimination procedure small. The bound is for star-free expressions on the instruction alphabet, without extra numerical predicates on positions.

## Two easily completable sweeps with a hard joint answer

Take a fixed finite group G, fixed start s and target t (or encode the constant-size endpoints). An index circuit gives the letters g₀,…,g_{L−1}. The common existential track has L+1 group elements y₀,…,y_L with prescribed endpoints s,t. One left-to-right sweep checks

    yᵢ₊₁ = yᵢ gᵢ

only for even i. The other checks it only for odd i. Include the endpoint pins for both. For L≥2 each individual sweep always has a completion: its edges are disjoint and none connects both endpoints. Moreover a small circuit for a completing track can set a free left endpoint to the identity, propagate across one edge, or solve backwards from a pinned right endpoint using its inverse. Each symbol lookup costs O(1) indexed letter evaluations and index arithmetic. With any explicit list of additional pins, individual feasibility just tests for conflicting pins or a violated edge with both endpoints pinned. An actual tape can guess the long track once and check the colored edges in two monotone scans; producing an indexed letter during a scan has its own evaluation cost. The shared alphabet and the memory needed to compare a pair of track symbols are constant.

Joint completion exists if and only if s g₀⋯g_{L−1}=t. With G=A₅ this is PSPACE-complete in the size of the circuit describing the word (choose s=t=identity). This uses the circuit-indexed word representation, where each letter is computed on its binary position. A multiplication straight-line grammar for a word instead permits evaluating the group element once per grammar rule. The PSPACE-completeness of the succinct nonsolvable group word problem is known. [Vollmer, Corollary 3.3](https://www.researchgate.net/publication/2823258_Succinct_Inputs_Lindstr_om_Quantifiers_and_a_General_Complexity_Theoretic_Operator_Concept) · [Barrington's group-program construction](https://people.cs.umass.edu/~barring/publications/bwbp.pdf)

Consequently, under SAT∈P, the claim that polynomial-size circuits for common tracks exist on all compatible succinct A₅ instances is equivalent to P=PSPACE. For one direction guess a bounded-size track circuit and use SAT to search over indices for a failed update or pin. Under P=NP this gives a polynomial-time algorithm. For the converse, computing a prefix group product lies in polynomial space (scan a binary counter and a group register), so under P=PSPACE the unique true product track has a polynomial-size circuit with the original input hardwired. The two independent sweep completions always admit small circuits unconditionally. The equivalence says nothing about arbitrary quadratic or cubic SAT time without an implication producing the common representation.

## Exact cost of checking additional shared positions

Suppose the endpoints are incompatible. Fix any internal position j. Put the propagated prefix from s at every position left of j and the backwards-propagated suffix from t at every position right of j. There are two ways to fill yⱼ: satisfy its incoming edge, or satisfy its outgoing edge. The values differ, since otherwise they yield a full consistent run. Those two incident edges have opposite colors. Assign each sweep the version satisfying its own edge. Both are valid for their respective sweeps, and their completing tracks agree at *every other position*. In particular every nonadaptive set of shared pins missing an internal position admits some answers consistent with both sweeps individually. The argument also works with all letters equal to the identity and unequal endpoints. Even testing equality at L−2 of the L−1 internal positions can miss the contradiction of these particular local tests.

There is an exact adaptive tradeoff. Give a checker rounds with at most p₁,…,p_k pins per round. The checker sees the labels assigned at earlier pins and may then ask for new labels, with the two independent sweeps checked for extendibility after each round. Rejection must come from one of these extendibility tests. Permit unrestricted internal computation by the checker.

* If ∏ⱼ(pⱼ+1)<L, an adversary can prevent rejection. Maintain one interval between consecutive pinned positions whose true product disagrees with the pinned endpoint labels. Keep every other interval consistent. New pins in the exceptional interval split it into at most pⱼ+1 intervals. Select a longest one. From the old left endpoint propagate forward to set its left boundary and the earlier pins. From the old right endpoint propagate backwards to set its right boundary and the later pins. The chosen interval remains inconsistent and all others agree. Answer pins outside the interval by their consistent values. After all rounds an exceptional interval of length greater than one remains. Apply the single-missing-position construction inside that gap to give valid separate completions through the answers.
* If ∏ⱼ(pⱼ+1)≥L, the checker can force rejection by splitting one inconsistent interval as evenly as possible at every round. It can determine an inconsistent child by computing true subinterval products. The largest remaining length is at most ⌈L/∏ⱼ(pⱼ+1)⌉, so eventually two consecutive pins violate an edge of one sweep. Recomputing the products explicitly may take order L work; the numerical bound is sharp for the number of pins when computation is free.

Thus the nonadaptive threshold is L−1, while ceil(log₂ L) adaptive one-pin rounds suffice in this interface. For independent sweeps the local SAT operation with arbitrary existing pins is already easy. In the A₅ example the interval-product computations used for balanced diagnosis can be as hard as the original succinct instance.

**Change the shared statistic.** For the additive two-element group and even L, one common bit can replace all coordinate pins if each sweep can determine the parity of its entire internal track. Summing its disjoint updates cancels every internal symbol in the comparison of the two sums. More explicitly, the even sweep forces the parity of y₁,…,y_{L−1} to be s XOR the parity of the even-indexed letters. The odd sweep forces it to be t XOR the parity of the odd-indexed letters. The two parities agree exactly when the boundary product is correct. This defeats the coordinate model, even for a track with many state changes. For succinctly presented letters, evaluating one projected sweep's permitted bit can itself encode parity of a circuit's full truth table by placing the circuit on the even positions. The hard computation has moved into validating the summary. [Related geometric certificates for parity](parity-fillings.md)

A finite minimax check on binary identity updates with incompatible endpoints recovered the product threshold in all 120 cases with 2≤L≤9, zero through three rounds and one or two pins per round.
