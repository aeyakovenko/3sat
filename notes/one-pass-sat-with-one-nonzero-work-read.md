# One nonzero work read suffices for nondeterministic one-pass SAT

On every well-formed DIMACS CNF there is a linear-time nondeterministic word-RAM solver with a one-way input stream whose **accepting paths make zero work reads returning a nonzero word**. Every path, including every rejecting path, makes at most one. The bound of one for the worst path is optimal even on an explicit family of binary-clause formulas with at most one model. On the very same family the deterministic optimum is $\Theta(N/\log^2 N)$ worst-case nonzero work reads. Both bounds concern actual RAM replies. There is no charge for a read that returns zero, and the deterministic lower permits arbitrary time between probes.

## Model and upper bound on all formulas

The $N$-bit input has a public length and is read one physical word at a time in forward order. A constant number of $\Theta(\log N)$-bit registers hold the control, including the current input word. Work RAM is initially zero and has polynomially many addressable words. A fixed sufficiently large constant in the word width, for example $12\lceil\log_2(N+2)\rceil$, suffices below. Work stores do not implicitly read their old value. The domain consists of well-formed files. In particular there is no need to validate that a huge numeric literal is within a huge declared upper bound on sparse inputs.

For each literal occurrence with variable name $x$, guess one bit $b$, the value of the **variable**. Use a label $r(x)$ and two work cells per label. Probe the cell for $(r(x),1-b)$. If it is one, reject immediately. Otherwise write one into $(r(x),b)$. A register accumulates the OR of the signed literal values in the current clause. Reject on an unsatisfied clause at its terminator, and accept when all clauses pass. An empty conjunction accepts and an empty clause rejects. This algorithm can store into the same cell repeatedly. Every store writes one. A read of an earlier-written cell consequently returns one and ends that path.

When the declared name bound is at most $D=16(N+1)^2$, use the integer name itself as its label. Accepting paths are then in bijection with satisfying assignments on the occurring variables. Each accepting path gives consistent values at all occurrences. Conversely a satisfying assignment determines every guessed bit. This includes formulas with unused declared variables, whose values do not enter the count. In particular the verifier is unambiguous on the promise of zero or one model over the *whole* declared name range. On such a positive file every declared variable occurs, so the small-name rule always applies.

For a larger header, guess an integer $d$ in $[2,D]$ using a fixed number of binary guesses and reject out-of-range codes. Use $r(x)=x\bmod d$, accumulating the remainder in decimal as the literal is streamed. Equal names always receive equal labels, including spellings with leading zeros when the format permits them. Hence every accepting computation still gives a genuine model. For fixed $d$ it represents exactly the models constant on the residue classes of the occurring names. Different guesses of $d$ may represent the same model.

For completeness some candidate $d$ separates all occurring numeric names. For distinct names $x_1,\ldots,x_v$ take $P=\prod_{i<j}|x_i-x_j|$, with empty product one. Choose one spelling of length $s_i$ decimal digits per name. Then $\log_2 P\le 4(v-1)\sum_i s_i\le4N^2$ for $v\ge1$. For $g=4(N+1)^2$, the least common multiple $L$ of $1,\ldots,2g+1$ satisfies $L\ge4^g$. Indeed $L\int_0^1 z^g(1-z)^g\,dz$ is a positive integer by expansion, while the integral is at most $4^{-g}$. Since $L>P$, some $2\le d\le 2g+1\le D$ fails to divide $P$. No nonzero difference is divisible by this $d$. Decoding a decimal digit takes constant word operations, since the next remainder requires at most nine subtractions. The size of the header can first be compared to $D$ by saturating a register. A constant number of registers suffice throughout, and the native time including all guesses is $O(N)$ on every path. [Small-modulus argument](linear-encoding.md)

Rubtsov and Vyalyi's Lemma 6 gives a related one-way nondeterministic set-automaton algorithm for an NP-complete language with a supplementary name list. Their algorithm stores guessed variables and tests membership of a witness literal. The work-read bound here comes from testing for a contradictory guess in ordinary clause order. Priority of the combined quantitative separation below is unverified. [Rubtsov and Vyalyi, *On Computational Complexity of Set Automata*](https://arxiv.org/abs/1704.03730)

## The binary-clause family

Take $m$-bit strings $x,y$. Start a pair of Boolean lanes $(a,b)$ at $(0,0)$. At coordinate $i$ apply these four operations in order.

1. Swap the lanes if $x_i=1$.
2. Complement the first lane if $y_i=1$.
3. Swap the lanes if $x_i=1$.
4. Complement the first lane if $y_i=1$.

A block is the identity if either control is zero. With two unit controls, both lanes are complemented. Require the final first lane to equal one. The verdict is exactly the inner product $x\cdot y\bmod 2$.

Give each lane at each of the $4m+1$ stages its own variable, using consecutive names. Each transition consists of two equations $v=u$ or $v=\neg u$, each written as two binary clauses. Force a fresh pair $z,w$ to $(0,0)$ with $(\neg z\lor\neg w),(\neg z\lor w),(z\lor\neg w)$. Express the initial and final pins as the desired literal OR $z$. All clauses have two distinct variables and all declared names occur. The anchors are fixed, and once the initial lanes are set each later lane is forced. The file therefore has exactly one model for odd inner product and none for even inner product.

Place the header, anchors, pins and all swap transitions in a physical prefix, grouped by coordinate. Put all complement transitions in the suffix, again grouped by coordinate. At a swap both source names occur twice regardless of the switch. Both CNF encodings of the equation type use exactly two minus signs across their two clauses. The lengths of each region and the entire file are therefore independent of $x,y$. Insert $O(\log m)$ public whitespace bytes at their boundary, choosing a physical word cut in that gap so no word reveals private data from both sides. The implicit constant may depend on the fixed RAM word-width coefficient. Every $x$ determines a prefix, every $y$ a suffix, and all $2^{2m}$ concatenations are legitimate. Their common length in bits is $N=\Theta(m\log m)$. To obtain proper exact-width-three files, add the same fresh false literal to every binary clause. Force its variable and two fresh helpers to zero by excluding each of their seven nonzero assignments with one ternary clause. This preserves every model count and both input banks.

## The deterministic lower and matching upper

Let $P$ be the number of possible controllers at the physical cut, including buffered input, the input head and early halting states. For a fixed program $P=N^{O(1)}$. Registers are charged and there is no independent unbounded clock available to an instruction. Let $U$ be the number of work addresses, $V$ the word alphabet size, and $k$ the largest number of distinct *nonzero incoming* work words retrieved on any of these inputs. An incoming word is read in the suffix before the first suffix store at its address. All other work accesses are unrestricted. The sign matrix $H_{x,y}=(-1)^{x\cdot y}$ satisfies
$$
2^{m/2}\ \le\ \operatorname{signrank}(H)\ \le\ P(k+1)(UV)^k.
$$
The first inequality is Forster's theorem, since $HH^\top=2^m I$. [Forster, *A linear lower bound on the unbounded error probabilistic communication complexity*](https://www.sciencedirect.com/science/article/pii/S0022000002000193)

For the second inequality, group prefix inputs by controller. For fixed controller and $y$, each row $x$ supplies its incoming work array. Run the suffix as a decision tree that asks only for words of that array, servicing its own writes locally. Keep the union of honest paths for these rows, a finite tree since each run halts. Order leaves lexicographically on the returned words, with zero least. For leaf $j$ in increasing order starting at zero, give it coefficient $2^j$ times its verdict sign. Its feature is the product of equality indicators for its *distinct nonzero* address/value observations. At a real input, its own leaf's product is one. Every larger leaf is killed by the probe at first divergence, where the larger answer is nonzero and disagrees with the real one. All smaller weights together have absolute sum less than the true weight. The sign of the resulting linear combination is exactly the required verdict. There are at most $(k+1)(UV)^k$ row features per controller. Multiplying them by that controller's row indicator and allowing column-dependent coefficients proves the inequality. In particular, arbitrarily many off-path, zero-valued, locally written or repeated probes cannot reduce the bound. [Earlier arbitrary-order argument](half-read-reuse.md) · [Formal leaf-weight inequality](../lean/PositiveQueryLeaves.lean)

Since $U,V$ are polynomial in $N$, some run retrieves $\Omega(m/\log N)=\Omega(N/\log^2 N)$ distinct nonzero words from across the cut. To see sharpness, read and validate the swap records, packing the successive $x_i$ into consecutive words with one store per completed word. Read and validate the complement records in the same coordinate order. Pack each block of $y$, load the corresponding $x$-word once, and XOR its bitwise intersection with that block into a register. Compute the parity of this register at the end. This uses at most $\lceil m/b\rceil$ total work reads for $b=\Theta(\log N)$ packed bits. The validator can recognize the displayed header and each expected equation from the record number using constant registers and no work loads. A deterministic solver correct on *all* valid files can write a private input copy during its forward scan and invoke a general SAT fallback on that copy only if validation fails. The private copy and packed bits occupy disjoint address ranges. Hence the upper bound holds even when the solver must be correct off the template. The width-three version has the same scanner with the additional public guards.

## A genuine nonzero read is unavoidable for nondeterminism

Suppose some one-pass nondeterministic solver has zero nonzero incoming work reads on **every** path on the binary family. Replace the entire incoming array by zeros at the cut. For any reachable prefix computation and fixed suffix choices, the resulting computation is identical to the genuine one. Before a suffix store, any first discrepancy would itself be a genuine nonzero incoming read. After a suffix store, the value is already available locally. This argument also covers arbitrary nondeterministic choices on rejecting paths.

For each cut controller the pairs with an accepting computation through it now form a rectangle. The prefix can reach that controller independently of $y$, and the zero-initialized suffix can accept independently of $x$. At most $P$ such rectangles cover the entire odd-inner-product set without covering a single even entry. Every monochromatic rectangle $A\times B$ of the Hadamard matrix has area at most $2^m$, by bounding $|\mathbf1_A^\top H\mathbf1_B|$ with $\|H\|\sqrt{|A||B|}$. There are $(2^m-1)2^{m-1}$ odd pairs. Consequently $P\ge (2^m-1)/2$, contradicting polynomial controller size at sufficiently large scales. This forces one actual incoming nonzero read on some branch, even if arbitrary suffix-local reads are free. The upper algorithm is unambiguous on this family and performs every nonzero read immediately before rejection.

The separation measures one-pass working-memory traffic even for a polynomial-time problem. With random access to the input, two register-held input pointers can stream the two banks together, validate them and compute the parity in $O(N)$ time without a work read on the promised layout. Binary-clause SAT also has the classical implication-graph algorithm. An unrestricted RAM time lower bound would need an additional argument charging either the reads or their avoidance to superlinear elapsed time. [Aspvall, Plass and Tarjan](https://www.sciencedirect.com/science/article/abs/pii/0020019079900024) · [Finite audit](../audits/one_pass_sat_memory_audit.py)

## With unrestricted random access to the input, the deterministic measure equals space

For a halting deterministic RAM run let $h$ count distinct work addresses at which some load returns a nonzero word. On the same input the run can be simulated in $O((h+1)\log N)$ **bits of deterministic space**, with no time hypothesis and no advice about which addresses to retain. Here the input can be reread. Conversely a deterministic machine with read-only input and $s\ge\log N$ workspace bits can pack its used work tape into $O(1+s/\log N)$ addressable words, provided $s$ is polynomially bounded. This gives equivalence up to constants for worst-case resource bounds. In particular, proving unboundedly many distinct nonzero retrieval addresses for every unrestricted deterministic SAT solver is equivalent to proving $\mathrm{SAT}\notin\mathrm L$. A bound of a constant on *total* nonzero reads yields the same language class, since logspace calculations fit in a constant number of RAM registers.

To prove the simulation, let $S_*$ be the actual set of $h$ addresses. If an omniscient simulator keeps only these words and uses zero for all other loads, it reproduces the true run instruction for instruction. Let $Q$ count the fixed program's possible controllers on this input, and $V$ the word alphabet size. The projected computation is deterministic. It cannot repeat a nonhalting configuration, so its running time $T$ is at most $QV^h$ up to a fixed additive constant. Hence one simulation clock costs $O((h+1)\log N)$ bits. This argument uses $S_*$ to bound the clock only.

The actual simulator builds a set $S$ as it goes, retaining the current contents of its words and updating them on stores. On a load at address $a\notin S$, replay all earlier instructions from time zero with a fresh zero-initialized copy of the words of $S$. Answer all other past loads with zero and track the last store to $a$ in one more register. Every nonzero reply on the already simulated prefix was at a member of the current $S$. The replay therefore has the true instruction sequence, and the tracked word gives the correct new reply. Add $a$ to $S$ with that value if it is nonzero. This proves the space bound by induction. The simulation uses at most $O(T^2)$ emulated instructions, in addition to dictionary and multiword-clock operations. Random input access on a space-bounded Turing machine may be implemented by moving its input head. The time sacrifice matters when relating small space to a particular SAT clock.

## With nondeterminism, one genuine nonzero reply permits polynomial space

Without a time bound, the one-pass-input languages of these polynomial-address RAMs with at most one nonzero work reply on every path are exactly $\mathrm{PSPACE}$. This also holds when each positive input must have a unique accepting path. For the lower inclusion, take a deterministic polynomial-space machine and encode each bit of its bounded workspace in two indicator words, exactly one of which is one. Initialize the polynomially many cells by stores and copy the physical input in one pass into further indicator pairs. Whenever the simulated machine needs a bit, guess its value and probe the indicator for the opposite value. A one rejects immediately, and a zero confirms the guess. A simulated write sets both indicators to their assigned values without reading either. Head positions fit the fixed registers. Exactly one sequence of guesses follows the deterministic source all the way to its verdict. This construction may write zeros and ones. The faster occurrence verifier above needs only one-valued stores.

Conversely, the entire RAM configuration has polynomial size, and nondeterministic polynomial space equals deterministic polynomial space by Savitch's theorem. With a polynomial time bound the corresponding class is $\mathrm{NP}$, or $\mathrm{UP}$ under unambiguity. For the lower inclusions simulate a polynomial-time tape machine in the same two-indicator format using a polynomial initialization and retaining each original nondeterministic move. Correct read guesses are unique for each original path. For the upper inclusions ordinary polynomial-time simulation of the RAM preserves its branches. With zero nonzero replies on *all* branches and random access to the input, discarding all work stores gives precisely $\mathrm{NL}$, or $\mathrm L$ for deterministic machines. Registers can hold a logspace machine's entire work tape. [Savitch, *Relationships between nondeterministic and deterministic tape complexities*](https://www.sciencedirect.com/science/article/pii/S002200007080006X)
