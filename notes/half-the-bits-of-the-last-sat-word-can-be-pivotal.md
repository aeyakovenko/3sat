# Half the bits of a last SAT word can be pivotal after all expensive work has finished

For an arbitrary ordinary SAT source $F$ of $n$ encoded bits, a deterministic linear-time reduction gives proper DIMACS files $G(F,z)$ of one common length $N=\Theta(n+1)$. The key $z$ consists of $b=\Theta(\log N)$ independent physical bits in one aligned input word. All $2^b$ word settings are legal. At **every** key and on **each** source verdict, flipping at least $b/2$ individual bits reverses the SAT verdict. A fixed key recovers the source verdict.

If a deterministic logarithmic-word RAM decides general SAT in time $T(n)$, a globally correct RAM can process every file in this image in $O(N+T(O(N)))$ time, with **constant elapsed instructions after its first read of the designated word**. Every other physical input word has already been read. In particular the uniform linear, quadratic and cubic deadlines for this family are equivalent to the corresponding deadlines for general SAT. The equivalence holds across all sufficiently large *source* sizes; physical outputs may be padded to dyadic lengths.

A strict majority at the distinguished source-preserving key would have a different consequence. For **any** polynomial-time family on all SAT inputs in which an efficiently specified base file has verdict $\operatorname{SAT}(F)$, suppose strictly more than half of an efficiently enumerable, polynomial-size list of its neighbors reverse that verdict, on both source verdicts. Then $\mathrm{NP}=\mathrm{coNP}$. On an UNSAT source, guess distinct indices and satisfying assignments for a strict majority of those neighbors. Verify the assignments on the actual neighbor files. Such a certificate exists on every UNSAT source and on no SAT source. Thus this majority test is an NP procedure for UNSAT. It even needs only a strict majority on UNSAT sources and at most half SAT neighbors on SAT sources. The argument does not require a promise about how the compiler obtained its outputs. It is the standard closure of NP under a polynomially specified majority of existential tests.

## A four-bit truth table

Let $b=4r$. Divide the key bits into four groups of $r$ and take the parity of each group, producing a nibble $j$ in little-endian order. The following string gives the mode for $j=0,1,\ldots,15$:
```
A00111001010011A
```
Mode 0 means an unsatisfiable target, 1 means a satisfiable target, and A selects the source verdict. On the four-cube, for each of the two Boolean interpretations of A, the number of neighbors of opposite verdict has minimum exactly two. This can be checked directly on sixteen rows. For either value of A and for every $z$, each of the four possible nibble flips is induced by $r$ different physical-bit flips. Thus the minimum sensitivity is $2r$. Exactly the two nibbles 0 and 15 use A. In particular $z=0$ always recovers the source answer. At that key the two neighbors in constant mode 0 and two in constant mode 1 account for the exact half on both source verdicts.

The trit design also explains the limit without complexity assumptions within this particular interface. For a base in mode A, a neighbor that reverses the zero interpretation must be in fixed mode 1. A neighbor that reverses the one interpretation must be in fixed mode 0. These sets are disjoint, so their smaller cardinality is at most $\lfloor b/2\rfloor$.

## The proper clauses

Use three guard variables pinned jointly to false by the seven proper clauses forbidding the other assignments. Denote one guard by $f$ and use two fresh control bits $u,v$. Require $u\lor v$ padded with $f$. For each normalized source clause with literals $a,b',c$, express $u\lor a\lor b'\lor c$ using a fresh $y$ and the two clauses $(u\lor a\lor y)$ and $(\neg y\lor b'\lor c)$. This makes extendibility of the guarded portion exactly $u\lor(v\land\operatorname{SAT}(F))$ when the controls are fixed.

For each allowed key create a flag $K_z$. Emit $(\neg K_z\lor \ell_u\lor f)$ and $(\neg K_z\lor\ell_v\lor f)$, choosing the literals to force $(u,v)=(0,0),(1,0),(0,1)$ in modes 0, 1, A respectively when that flag is true. The eventual selected flag is asserted by one last clause $(K_z\lor f_1\lor f_2)$ with distinct false guards. All other flags can be set false. Thus each file has exactly the required verdict. No existential encoding of the *complement* of the source was used. Minimizing the number of auxiliary assignments is outside this claim.

Use the journal's linear-length normalization to proper 3-CNF and remove repeated clauses. For $m$ distinct proper clauses after normalization, $m\log(m+2)=O(n+1)$ by counting distinct strings over a fixed alphabet, after choosing a shortest spelling of each. This permits $O(m)$ new source or gate names with $O(\log(n+2))$ bits per spelling. The normalization and deduplication have deterministic linear-time implementations on the stated RAM. Choose $N$ as a power of two between constant multiples of $n+1$, with enough slack for the generated text. At sufficiently large sizes choose, for example, $r=\lfloor\log_2 N/256\rfloor$. For a key $z$, the decimal DIMACS identifier of $K_z$ is the character 1 followed by its zero-padded, $\lceil b/3\rceil$-character octal spelling. DIMACS reads those characters as decimal digits. Each of the $b$ independent low digit bits changes one physical bit within that identifier. The other occurrences of flag identifiers are in the *fixed dictionary*, identical for every choice of $z$. Keep the guards and source names disjoint from the flags, for instance by starting the fresh source block above their largest numerical identifier. There are $2^b$ flag entries and the largest flag spelling has $O(\log N)$ bits. Emitting and verifying the dictionary costs $o(N)$ steps.

Place the final clause at the start of a designated complete input word near the end, padding the prefix and the rest of the file with permitted whitespace. The word contains the entire key spelling, two fixed guard literals, the terminating 0, and its fixed whitespace. There is room since $8\lceil b/3\rceil+O(1)<w$ for the standard byte-aligned $w\ge\log_2 N$. One may leave another physical word after it. Small sizes use fixed templates. This puts the actual data in a full word and makes its address computable from $N$ before receiving any file content.

## Computing the answer across the last load

Cache every original word other than the designated one. Recognize the guarded-prefix layout and extract the underlying source from the pair of clauses per gate. This can be done by verifying the guard section, fresh gate indices, prescribed control literals and dictionary, clause count, and surrounding whitespace. The source gate rows and dictionary rows occupy consecutive sections; the latter has a known size from $N$. Integer identifiers fit in a fixed multiple of a logarithmic word. One can reject malformed fields or oversized headers from this fast path while scanning. On any unrecognized layout use the general solver on the actual input.

On a recognized prefix decide the extracted source. Before loading the held word build a table on the raw $8\lceil b/3\rceil$-bit digit field giving lexical validity and its mode. This costs $2^{8\lceil b/3\rceil}\operatorname{polylog}(N+2)=o(N)$. On the actual final load compare all fixed bits, extract the digit field, make one table lookup, and use the previously computed source verdict for mode A. A word outside the prescribed layout goes to the general fallback. The complete program is correct for unrestricted SAT, makes no guess about the final word, and has the stated clock on the image. With $T$ a general worst-case bound and the usual nondecreasing convention, it retains $O(N+T(O(N)))$ even off the image.

The earlier old-cell lower bounds force a hard last data packet on different templates. They give the lower-bound construction control over which combinatorial query remains hidden. On this family the machine can withhold one whole word with a growing alphabet whose entire response table depends on only one previously computed SAT verdict. Raw-bit sensitivity at the last load alone cannot turn a scan-scale portfolio witness into a superlinear deadline.
