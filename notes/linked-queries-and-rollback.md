# When an online lower bound survives replaying a static SAT solver

**Research journal, 24 November 2026.** A dynamic Boolean computation can be hard to perform online even if its final bit is computable in linear word time, each intermediate bit changes the next genuine range query, and intervening on any feedback wire flips the final verdict. There is a quantitative bridge for actual static SAT solvers. Besides the final solver time it charges the lengths of execution suffixes that must be discarded as successive records arrive.

## A hard Boolean stream with a cheap, sensitive final answer

Let $m=2^s$, $s=\log_2m$, and use the group of $s$-bit words under XOR. At round $t$, for $1\le t\le m$, store an independent word $U_t$ at array position $\mathrm{rev}_s(t-1)$, where $\mathrm{rev}_s$ reverses $s$ bits. The other fields of the round are a prefix endpoint $R_t\in[0,m)$, a selected bit $k_t\in[0,s)$ and a salt bit $e_t$. Let $H_t$ be bit $k_t$ of the XOR of the current array at positions $0,\ldots,R_t$. The array starts at zero. Emitting every $H_t$ as its round arrives has total cell-probe lower bound $\Omega(m\log m)$ at word width $\Theta(\log m)$. The hard distribution uses independent uniform words, endpoints and bit labels. This is the Group Range theorem specialized to this group and its usual binary encoding. [Alman, Wang and Yu, Theorem 1.2 and §5.1](https://arxiv.org/pdf/1704.06185)

Put a fixed all-ones sentinel at position $-1$. Define $H_0=b_0=0$ and $p_t=e_t\oplus\mathrm{parity}(R_t)\oplus\mathrm{parity}(k_t)$. Given $b_{t-1}$, select one of the *two distinct intervals* $[0,R_t]$ or $[-1,R_t]$, including the sentinel precisely when $b_{t-1}=1$. XOR the selected query bit with the previous ordinary query bit $H_{t-1}$ and $p_t$ to obtain $b_t$. An implementation can cache the ordinary bit for the next round. Algebra gives
$$
  b_t=b_{t-1}\oplus H_t\oplus H_{t-1}\oplus p_t
      =H_t\oplus\bigoplus_{i=1}^t p_i .
$$

Delivering every $b_t$ online therefore delivers every $H_t$ with a running checksum and $O(1)$ extra probes per round. Computation of word parity is free in the cell-probe reduction. All salts may be zero on the hard distribution. On every valid raw stream, replacing any already-computed feedback bit by its opposite changes the next interval if there is one and flips every remaining feedback bit, including the final bit. Every raw salt, and every valid single-bit change to an earlier endpoint or bit label, flips the final verdict on the recomputed stream. This latter claim concerns earlier query fields, not arbitrary update payload bits.

Offline one needs only the last prefix bit and one checksum. Scan the payloads in final position order, XOR those below the final endpoint (including equality), and select the final bit. The XOR of all endpoint and label words can be reduced to parity once after the scan. The result takes $O(m)$ native word operations. The equivalence is deterministic on every legal stream, including streams with endpoints or labels chosen from earlier answers. The online lower bound uses the specified random distribution on the raw fields.

## Constant-edit ordinary 3-CNFs

The current stopped-prefix verdict has a representation with $O(m)$ ordinary width-three clauses and $N=\Theta(m\log m)$ encoded bits, including all variable names. Future payload and checksum records start as zeros. A round changes $O(1)$ fields of $O(\log m)$ bits and hence $O(1)$ native input words at fixed offsets. The formulas encode the algebraically simplified verdict.

Choose bit-selector variables $E_0,\ldots,E_{s-1}$, pin $E_k$ to one using its literal name, and enforce pairwise that at most one selector is true. The $O(s^2)$ clauses fit. Define $P_0=0$. For $0<v<m$ put
$$
 P_v=P_{v\mathbin{\&}(v-1)}\oplus E_{\nu_2(v)}.
$$
These gates give $P_v=$ bit $k$ of $v$ simultaneously for every $v$. Define fixed pinned variables $D_v=\mathrm{parity}(v)$. A decreasing Boolean threshold chain $L_0,\ldots,L_m$ has clauses $L_{i+1}\Rightarrow L_i$ and two pins $L_R=1,L_{R+1}=0$, using the current query endpoint. Its unique value is $L_i=[i\le R]$.

At array position $i$ form the product $L_iP_{U}$, where the *literal name* in the gate selects $P_{U}$. XOR these products and the checksum terms $D_{R_t},D_{k_t},e_t$ in a chain, pin its starting zero and final one, and encode every gate equivalence in width three. Short clauses can repeat literals. Payload records can be maintained in final position order and checksum records in arrival order. A round changes one payload reference, two checksum references and a salt field, the selected-bit pin, and the two threshold pins. Every variable is determined before the final test, making the formula unique-SAT or UNSAT according to the stopped verdict. On each fixed-width template word names fit $O(1)$ words. A globally correct solver can validate the known template while computing the offline answer in $O(m)$ word steps, falling back to a complete SAT method on any mismatch. Computing the public $\nu_2(v)$ by counting trailing zeros for successive $v$ costs $O(m)$ in total. Static popcount parities can be generated by the recurrence for $v\mathbin{\&}(v-1)$ in an $O(m)$ work table. No large group operation or dense gate family is hidden in the input length.

One can also require the ordinary CNF to contain the actual intermediate feedback wires. Build a persistent binary interval tree for the group array. On an update, create the new leaf and its $s$ ancestors, with $s$ payload-bit wires per node and XOR equivalences for each new aggregate. Decompose the current prefix into at most $s+1$ canonical intervals, and XOR the selected bit of their current aggregates to compute $H_t$. The two interval options are the aggregates without and with the all-ones sentinel; a mux controlled by $b_{t-1}$ selects the bit. XOR with $H_{t-1}$ and $p_t$ and pin only $b_m$ at the end. Standard gate equivalences force the full linked transcript uniquely before this final pin. With fixed-size record slots, this version uses $\Theta(ms^2)$ clauses and $\Theta(ms^3)$ encoded bits. A validator tracks the current tree-node names while scanning the template, verifies the $O(s)$ interval references per round from the recorded endpoint and bit label, and uses the telescoping identity for the verdict. This takes $O(ms^2)$ native steps on the family, with full SAT fallback off it. The constant-edit result below uses the smaller simplified encoding. The larger version makes the distinction between logical dependence and compulsory algorithmic evaluation visible inside ordinary CNF clauses.

## An unconditional constraint on discarded native work

For any deterministic RAM solver and two adjacent versions of the fixed-size formula, let $R_j$ be the number of native steps of the old trace from and including its first read of a changed input word through halting. Use $R_j=0$ if no changed word was read. Let $T_j$ be the ordinary time of version $j$, including halting, and count every input modification since the preceding version. A deterministic online simulator for the new answer uses the unchanged prefix of length $T_{j-1}-R_j$ and runs the solver from there. Its new suffix has length $T_j-T_{j-1}+R_j$. Reads are in ordered native slots or registers include partial instructions.

Save the old register state and old values of stores for each observed step. Maintain the earliest read of each input word on the current trace, deleting this entry when that very first read is popped. Before an edit, the least of the earliest reads of the changed words gives the rollback point. The simulator undoes the old suffix, edits the input, and executes and records the new suffix. Induction on unchanged reads gives the correct new state and answer. Constant-word bookkeeping per native step suffices. Starting from a public $O(m)$-word template, running version zero and adding these replay costs for $m$ constant-word edits costs
$$
             O\!\left(m+T_m+2\sum_{j=1}^{m}R_j\right)
$$
cell probes in total. This is a bound in terms of the solver's genuine static traces. The identity follows by telescoping, so long intermediate runs are fully accounted for. To use words of $O(\log m)$ bits even for an arbitrarily slow solver, truncate the entire simulator at the desired $O(m\log m)$-probe budget. Every live trace index on that simulation fits the word model. The simulated RAM uses a polynomial address range as usual.

The simulator emits the linked verdict after every insertion. It recovers the ordinary group bit by XORing the running checksum. A truncated simulator can return guesses after exhaustion; on every sequence whose full replay cost fits it gave all answers correctly. Consequently the small-cost success bound of Alman, Wang and Yu applies. For any sufficiently small budget allowed by their theorem, the probability that this replay uses that budget and gets every answer is exponentially small in $m$. In particular a bound $T_m+\sum R_j=o(m\log m)$ on every sequence is impossible, and a solver with $T_m=O(m)$ on this family has sequences requiring $\Omega(m\log m)$ discarded native steps. The specialist above satisfies the static $O(m)$ bound itself. Thus extensive instability under cheap edits and rapid one-shot SAT decisions can occur for the same machine and the same family. This is one precise cost which a conversion from unrestricted static to online time must pay.

## A super-logarithmic query bound under a trace-stability condition

The same replay rule can treat updates and queries individually. Let an edit's cost be one plus the length undone plus the length rerun. If the update edits always have cost at most $u$ and the query edits have expected cost at most $q$ under a dynamic hard distribution, the simulated online data structure has worst-case update and expected query probe costs $O(u)$ and $O(q)$. Polynomial initial trace length suffices for the address convention, as does a polynomial clock on relevant versions. The fixed initial empty data structure is independent of all subsequent updates. It can be represented by its precomputed public initial memory, with later writes overlaid. The cell-probe model allows unbounded computation between probes.

For a concrete application maintain up to $m$ point insertions for two-dimensional dominance parity on polynomial-universe coordinates. Write a coordinate in base $m$ with a fixed number of digits. For each digit position of the shared query create a decreasing threshold chain as above, and one gate per digit value giving equality from two consecutive thresholds. A point record references these tables by the literal names for its own digits. A constant-gate lexicographic comparator per coordinate, two ANDs including the activation bit, and an XOR accumulator suffice per record. This costs $O(m)$ width-three clauses and $N=\Theta(m\log m)$ bits. Each insertion changes a constant number of literal names and one activation bit. A new query changes a constant number of boundary pins. Insertions alone suffice for the cited lower bound.

Larsen, Weinstein and Yu prove that for dynamic 2D range parity, expected query probe time is $\Omega((\log m)^{3/2}/(\log(wt_u))^3)$ at worst-case update time $t_u$. Apply their result to the actual replay simulator. If every insertion has polylogarithmic rollback-and-rerun cost at $w=\Theta(\log m)$ and all relevant static traces have polynomial length, the worst-case query replay cost must be at least $\Omega((\log m)^{3/2}/(\log\log m)^3)$. The expectation is over the hard instance where the distributional argument applies; in particular this gives an individual query. If query edits always cost less, some insertions must violate the hypothesized stability. This measures elapsed work per edit of a real execution. The family itself permits one-shot decisions in $O(m)$ native steps by a format-checking scan. [Larsen, Weinstein and Yu, Corollary 1 and §7.1](https://arxiv.org/pdf/1703.03575)
