# The elapsed cost of deciding SAT through reads of as-yet-unwritten words

**Research journal, 24 November 2026.** There is a correct deterministic SAT solver with the following behavior on the two-permutation 3-CNFs. Color its instructions by which input array the instruction processes. On every equal pair it reads no input from the opposite side, and **no writable-memory load reads a word last stored by the opposite side**. Nevertheless, in polylogarithmically many color phases it decides the verdict in $O(N/\log\log N)$ word steps, where $N$ is encoded formula length. The number and length of phases and the live controller at every internal phase boundary can be public. Unequal inputs change whether a store precedes a read of the same address. A test that charges only values delivered by earlier stores misses this dependence on the diagonal.

Conversely, every deterministic SAT solver needs $\Omega(N/\log\log N)$ steps on almost every diagonal if its actual run can be colored into polylogarithmically many phases with those two properties. The coloring in the lower bound can depend on the whole run. Both statements concern the same explicit formula family. This gives a sharp elapsed-time bound with the color-phase and load restrictions. It leaves the unrestricted linear-time question open.

## A bound on every coloring of the native run

The $N=\Theta(m\log m)$-bit template encodes permutations $\pi,\sigma$ of $[m]$ in separate fixed-width clause records. Its verdict is UNSAT exactly on the equal pairs. Left clauses force $z_i=w_{\pi(i)}$ and right clauses require $z_i\ne w_{\sigma(i)}$ for at least one $i$. The gate constraints use width three. Every input word depends on at most one private entry. The same verdict equivalence holds for any two functions $[m]\to[m]$ in the template. [Formula and encoding](semantic-cut-permutations.md)

Use the deterministic logarithmic-word RAM with a fixed number of controller words, polynomial address universe, zero-initialized writable memory, and a fixed bounded number of ordered access slots per instruction. Fix one correct solver. For a complete diagonal run of $T$ instructions assign each instruction either color, allowing a different assignment on every run. Let

* $q\ge1$ count its maximal consecutive phases of one color,
* $p$ count distinct private input entries read by the opposite color, and
* $r$ count writable loads for which an actual preceding store exists and the latest such store to that address has the opposite color.

Outside a fraction $2^{-\Omega(N)}$ of the $m!$ diagonals, **simultaneously for all their colorings**,
$$
 T\log_2(2+q)+(q+p+r)\log_2(N+2)=\Omega(N).                 \tag{1}
$$
Constants may depend on the solver and encoding. If the schedule, boundary times and complete boundary controllers are given by a fixed public function of $m$, one may replace the $q$ term by $1$ for that coloring. A public list merely of color names does not give the controllers.

It suffices to consider $T\le N$. On any cheaper colored diagonal make the following certificate shared by two independent verifiers, Alice with $\pi$ and Bob with $\sigma$. Supply the starting color, phase lengths, and boundary controllers. Each verifies its own phases by simulation. Supply the $p$ off-side entry indices, sides and values, authenticated by their owners. For each of the $r$ cross-color loads record its phase, instruction offset and slot, the address, the phase of the latest store, and the word read. The reader checks the stated address and slot. The writer checks that its claimed phase had a store at that address and its **final** such store wrote the claimed value. These records and headers use $O((q+p+r+1)\log N)$ bits. No list of the other native addresses is transmitted.

For each writable load the reader imposes a constraint on opposite-color stores. For an unreported load it proposes its own last store to that address, or initialization if there was none, and uses that value for simulation. If it has a preceding own store in the current phase then no opposite store can intervene. Otherwise let $i$ be the phase of the proposed store, with $i=0$ for initialization, and $j$ the phase of the load. For a reported load, take $i<j$ from the record and check that no own store occurred after $i$ and before this load, including earlier slots in phase $j$. In either case require the opposite color to have **no store to the address in phases $i+1,\ldots,j-1$**. For reported loads the writer already checked the endpoint phase $i$. The read phase $j$ itself has the reader's color. These tests suffice for every proposed value to be genuine by chronological induction, including reads of initial zeros. Incorrect reports which happen to describe a genuine last store are harmless.

To enforce all the interval exclusions, use a complete dyadic tree on the phases, padding to the next power of two. The reader places a forbidden key $(a,v)$ for each node $v$ in the maximal dyadic partition of an excluded phase interval at address $a$. At most two nodes occur per tree level. Each writer places $(a,v)$ for every ancestor, including the leaf, of the phase of each store at $a$. A forbidden set and the opposite write set intersect exactly when some required exclusion fails. Each set has size $O(T\log(2+q))$. The keys belong to a public universe of size polynomial in $N$.

Two disjoint sets in a universe of size $M$ whose total size is at most $L$ admit an exact separating two-color map with a shared description of $L+O(\log(L+2)+\log\log(M+2))$ bits. A uniform random map gives the required colors with probability at least $2^{-L}$. A public family of $O(2^L(L+1)\log(2M+2))$ maps covers all such pairs by a union bound. Use its index, taking the lexicographically first suitable covering family for the public size parameters. Include a logarithmic-size header for $L$. Each verifier checks the prescribed color locally on every one of its own keys. Supply one map for each reader-writer orientation. This use of separation to authenticate missing cell accesses extends the two-interval retrieval-dictionary simulation of Pătraşcu and Thorup. Here the forbidden objects are address/phase-tree pairs for locally generated intervals. [Pătraşcu and Thorup, Lemma 5](https://people.csail.mit.edu/mip/papers/unions/unions.pdf)

For each fixed certificate the local acceptance tests, including the final UNSAT halt, define a rectangle in input pairs. If both accept, concatenate the local phase simulations. Initial and boundary controllers match. The no-intervening-store tests make every load consistent with the glued history, so the deterministic machine truly rejects the pair. Thus a certificate serving two distinct diagonals would also reject a satisfiable crossed pair. At most one diagonal per certificate is possible. There are fewer than $2^{b+1}$ strings of length at most $b$. Since $\log_2(m!)=\Theta(N)$, taking the small constant in (1) sufficiently small proves the probability claim, with no union bound over colorings. A public true schedule and controllers can instead be reconstructed by both verifiers. [Equality rectangle argument](semantic-cut-permutations.md)

## A solver with zero last-write transfers on the rejecting inputs

Represent entry values by $0,\ldots,m-1$. Choose a power of two $2\le B\le 2m$, put $b=\log_2 B$ and $k=\lceil\log_2(m)/b\rceil$. Validate the full template, including literal names, repeated occurrences, and public auxiliary clauses, by a linear scan of the $O(m)$ fixed-width records. The A instructions validate the left records and the B instructions validate the right records. Check values are in range. Template failure invokes an ordinary complete SAT decision algorithm. Equality of the two functions decides every valid template, so permutation validation is unnecessary. Either validating the two sides or regenerating and comparing the public words costs $O(m)$ native instructions. Padding keeps the variable records local to their owner.

Each side independently builds $B$ private buckets. Give each triple $(i,j,s)$ its own shared marker address, for $i\in[m]$, digit position $0\le j<k$ and orientation $s\in\{+,-\}$. For the $j$th digit $u$ of its entry at $i$, place $(i,j,+)$ in bucket $u$ and $(i,j,-)$ in bucket $B-1-u$. Implement each bucket by a private head and one private next-word per item, using a positive sequential item number and zero sentinel. The two sides have disjoint head and next arrays. The fixed-width digit is extracted by shifting and masking. Constructing both collections costs $O(mk+B)$ steps, including initializing all bucket heads. The marker bank consists of untouched, initially zero RAM words. No clearing pass writes to it. All banks fit at addresses of $O(\log N)$ bits.

Sweep buckets in the public order $v=0,\ldots,B-1$. For each $v$, first B visits its bucket and reads each item's marker, accumulating the OR in B-private storage. Then A visits its bucket and sets each listed marker to one. At the end B returns SAT iff its accumulator is nonzero. Each item costs a constant number of operations at insertion and at its one visit per side. All digit positions and both orientations share the same sweep through $B$ buckets. The implementation performs one word test per item. It uses no parallel comparison of scattered marker words. The elapsed time is $O(mk+B)$ with $O(B)$ phases.

For a plus item, B reads a one iff the left digit is smaller than the right digit. For a minus item it reads a one iff the left digit is larger. Hence the answer is exact on every pair of valid functions. On a diagonal, the B read and A write for an item occur in the same numbered bucket, in that order. **Every shared load reads initialization and every shared store occurs after the only read of its address.** All remaining loads and stores concern private banks. Thus $p=r=0$ on every diagonal. An unequal digit moves one of its two stores ahead of the paired read, which sets the mismatch bit.

Temporary controller words can be reset to public values before each handoff. Keep B's accumulator in its private bank, use disjoint fixed locations for each side's state, terminate each bucket loop at the common zero sentinel, and pass only public counters and parameters. No early return on a detected unequal digit is needed. On permutations the cardinality of every bucket is public: the multiset of all digit values at each position is determined by $m$, for both permutations separately. Each loop iteration can use the same fixed instruction sequence. Thus each phase's length depends only on $m,B$, including on unequal permutation pairs. The result is read at the last B phase after all sweeps. This supplies the public-boundary version of (1) on the family, including the authentic rejecting traces.

An implementation that stops at the first marker equal to one has exactly **one** cross-color last-write-to-load event on every unequal permutation pair, and zero on every equal pair. To keep even the positive completion time public, B can instead redirect all subsequent marker probes to one B-private zero word after it learns the answer. A word mask derived from B's private accumulator selects the address in constant time. This keeps each phase's instruction count independent of the answer and preserves the one-event bound. Conversely, if $p=r=0$ on *every* input pair and the entire schedule and internal boundary controllers are public, the party owning the final phase can compute the verdict from its own input alone. It simulates its private phases, serves each load from its own most recent store or initialization, and starts each phase at the public controller. Equality is not such a function. With public phase times alone, controllers may carry input-dependent words. The parties can then simulate the phases in chronological order, sending each actual boundary controller to the other party at $O(\log N)$ bits per switch. This simulation assumes $p=r=0$ on every pair; on that hypothesis, chronological induction verifies every local read against the real machine. A load with no preceding own store obtains its public initial word, zero in the stated RAM. The same proof works for any publicly known initialization. A terminal answer bit suffices for both parties to learn the verdict. The deterministic protocol uses $O(q\log N)$ communication, and the $m!$ diagonals require $\log_2(m!)$ bits by the rectangle argument. Consequently zero cross-color loads on all pairs require $q=\Omega(m)$ even with private boundary controllers and fixed public phase times. The one-event construction attains constant phases with $O(N)$ elapsed time.

For example, a power of two $B$ within a constant factor of $\log m$ gives $q=O(\log m)$ and $T=O(N/\log\log N)$. A power of two $B$ of order $m^{1/d}$ for a fixed positive integer $d$ gives $O(m)$ time with $O(m^{1/d})$ phases. Setting $B=2$ gives constant phases and $O(N)$ time. In all cases the public-controller bound gives the corresponding $\Omega(N/\log(2+q))$ time on almost all diagonals when $p=r=0$. A general solver can compare pairs of ordinary words directly and use $\Theta(m)$ switches or cross-color reads. Formula correctness forces a cost, but obligatory comparison of many unknown orderings does not by itself force superlinear time in the encoded length. The priority of the native phase tradeoff is unverified.
