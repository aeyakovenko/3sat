# How many independent lookups fit in the last clauses of a SAT query?

Let a database determine an arbitrary CNF $B_i$. A query determines a packet $Q_j$ of at most $r$ clauses on a common universe of variable names. The packet may contain names absent from the database. Preprocessing, auxiliary variables, the widths of clauses and the number of models of a positive answer are unrestricted. The database and query must be supplied separately. Measure cost by the number of distinct names **actually occurring** in the database formula.

## Exact capacity and successor

Suppose $B_i\land Q_j$ is satisfiable exactly when $i=j$, for indices from 1 to $M$. If each database uses at most $s$ names then
$$
                         M\le {s+r\choose r}.
$$
Equality is attained. In particular the first impossible identity table has one more entry than this binomial coefficient. Increasing $s$ by one adds exactly ${s+r\choose r-1}$ entries to the maximum for $r\ge1$. For $r=1$, the maximum is $s+1$ even if the one clause can be arbitrarily wide.

Here is a stronger weighted version. Choose a diagonal model for each $i$. Pick one literal made true by this model from each clause of $Q_i$, keeping the set $T_i$ of distinct picks. Pick a set $H_i$ of literals true in the same model that hits every clause of $B_i$. One can always use at most the number of occurring names and at most the number of baseline clauses. Put $D_i=\{\bar\ell:\ell\in H_i\}$. Then
$$
              \sum_i { |D_i|+|T_i|\choose |T_i|}^{-1} \le 1 .
$$
Indeed the diagonal sets are disjoint. If $D_i\cap T_j$ were empty, $H_i\cup T_j$ would be a consistent partial assignment. Extending it arbitrarily would satisfy $B_i\land Q_j$. Thus each ordered off-diagonal intersection is nonempty. In a random permutation of all the signed literals used, consider the event that every $T_i$ element comes before every $D_i$ element. Its probability is the indicated reciprocal. Two such events are incompatible: elements of $T_i\cap D_j$ and $T_j\cap D_i$ would have to come in both orders. Summing the probabilities proves the inequality. This is an application of the classical Bollobás set-pairs inequality. The choices may minimize the size of a baseline certificate compatible with a diagonal model. The uniform result also bounds *any subfamily* whose baselines have at most $s$ names. [Bollobás, *On generalized graphs* (1965)](https://doi.org/10.1007/BF01904851)

For equality use the $r$-subsets of an $(s+r)$-element universe. Database $U$ pins all names outside $U$ false. Query $V$ pins all names in $V$ true. Compatibility means $V\subseteq U$, hence equality. Partition the $r$-subsets according to whether they contain a newly added name to obtain the stated successor. For **proper ternary DIMACS**, there is a realization with at most $s+3$ baseline names. Add three public anchors and seven proper clauses forbidding each truth pattern except all-false. Pad each unit with two distinct positive anchors. Exact attainment at $s$ above is for ordinary CNFs permitting units. A header can declare the whole common universe.

## Positive polarity for independent table lookups

Fix positive constants $k,r$. Give the database $k$ binary tables $x_i:[m]\to\{0,1\}$. A query $q\in[m]^k$ asks whether all $x_i(q_i)$ equal one. In a positive encoding the query is represented by at most $r$ clauses and its answer is the SAT verdict. Consider the $m^k$ databases with a single one at a chosen address of each table. Their query matrix is identity. At most ${s+r\choose r}$ of these databases can use $s$ or fewer names. For fixed $k,r$ at least half therefore require $\Omega_{k,r}(m^{k/r})$ names for large $m$. Writing these distinct positive integer identifiers at least once costs $\Omega_{k,r}(m^{k/r}\log m)$ bits in decimal DIMACS.

This exponent is attainable when $1\le r\le k$, for *every* database. For powers of two $m$, concatenate the $k\log_2 m$ address bits. Divide them into $r$ strings whose lengths differ by at most one. For each string the baseline has one selector bit per position and a flag for every possible whole string value. A binary prefix tree deterministically computes all of those flags in linear size in the number of flags: the root is true, and a child is its parent AND the next bit with the appropriate polarity. A unit pin on one leaf forces that whole chunk. Reassemble all selector bits in their original order. A multiplexer tree for each bank returns the addressed database bit in $O(m)$ gates with its leaves fixed by the database. Assert the conjunction of the $k$ answers. The query pins the $r$ indicated chunk flags.

This construction has $O_{k,r}(m+m^{k/r})$ gates, clauses and names. A functional Tseitin encoding uses a bounded number of clauses per gate. Simplify constants, repeated inputs and tautologies, then pad short clauses with distinct public false anchors. Use private names for gates and dense decimal IDs. This yields proper ternary files with $O_{k,r}((m+m^{k/r})\log m)$ bits. Padding the tables to the next power of two gives the same bounds for all $m\ge2$. Splitting the address *bits* permits nonintegral exponents. For example four banks and three late clauses have exponent $4/3$. A [subset encoding with shared chunk tests](few-names-for-late-lookup-packets.md) gives the optimal exponent in **names** for every $r$, namely $\max(k/r,1/3)$, and the exact leading constant when $r<3k$.

## Reversing the verdict for one ternary clause

Now let the SAT verdict mean **some** selected bank has a zero. The query is one clause with at most three literals. Put $g=\lceil k/3\rceil$ and $t=k-3(g-1)$, which is 1, 2 or 3. For fixed $k$ and growing $m$ the optimal worst-case number of names occurring in the baseline is
$$t m^g+O_k(m^{g-1}).$$
For $k=3g$ and $m\ge3$, the exact optimum for ordinary CNFs is **$3m^g-m^{g-1}$**. For $1\le k\le3$ and $m\ge3$ it is $km-1$. Proper ternary DIMACS can realize these upper bounds with three additional public names. For three banks and a single late clause, the ordinary-CNF optima are exactly $m^3-1$ names for the AND and $3m-1$ for its complement when $m\ge3$.

Take the $km$ databases labeled $(i,a)$ with just one zero in the whole database. Every sample baseline is satisfiable since some query selects that zero. Let the support of a signed literal be the sample rows on which it extends to a model of the baseline. The supports of the query literals cover exactly $E_q=\{(i,q_i):1\le i\le k\}$. Every used support is contained in some $E_q$. A support of size $h$ fixes $h$ different indices of every query using it, hence is usable on at most $m^{k-h}$ queries. Its name actually occurs on at least $km-h$ sample baselines. If the variable were absent on any of these rows, a satisfying model there could be extended to the requested sign. For $m\ge3$, two useful signed literals of opposite signs cannot share a name. Their supports would cover all $km$ satisfiable sample rows, but their combined size is at most $2k$.

Define $f(0)=0$ and $f(h)=(1-h/(km))m^h$ for $1\le h\le k$. Give a query a charge of $f(h)$ for each distinct used literal of support size $h$. The charge of one such literal summed over queries and divided by $m^k$ is at most $1-h/(km)$. This quantity is at most that name's frequency of occurrence across sample baselines. The distinct-name observation therefore bounds the mean query charge by the mean number of occurring baseline names.

The three support sizes for each query, padded with zeros, sum to at least $k$. The price $f$ is increasing and discretely convex for $m\ge3$. For $2\le h<k$ its second difference, multiplied by $km/m^{h-1}$, is $(m-1)^2(km-h)-(m^2-1)\ge0$. At $h=1$ and $k\ge2$ the corresponding difference $f(2)-2f(1)$ equals $m((m-2)km-2(m-1))/(km)\ge0$. Balancing three sizes with total $k$ minimizes their charge, giving the finite lower bound
$$\max_i |\operatorname{vars}(B_i)|\ \ge\ t f(g)+(3-t)f(g-1).$$

For the upper bound partition the banks into $t$ groups of size $g$ and $3-t$ groups of size $g-1$, omitting empty groups. Each group and local address tuple has a flag meaning that some selected entry of this group is zero. Pin **only the false flags** in the baseline. Each true flag can take either value, and each query asks for the disjunction of its group flags. This gives the correct existential verdict. On an all-ones database use one unsatisfiable baseline, for example the empty clause. Dense public identifiers give encoded length $O_k(m^g\log m)$ and the distinct-name lower bound gives matching worst-case order in decimal DIMACS.

If $k=3g$, every database with a zero has at least $m^{g-1}$ true group flags. The baseline therefore uses at most $3m^g-m^{g-1}$ names. The finite lower bound gives the same number. For $k\le3$ there is one singleton group per bank, and any database containing a zero needs at most $km-1$ names, again equal to the lower bound. For other $k$ the leading term follows by using the balanced groups above. Exact constants here concern distinct names in ordinary CNFs allowing unit clauses, and a fixed common universe can be declared in a DIMACS header. ## Consequence for the RAM exhaustion

These are size bounds for representing queries by final clauses. A solver can spend arbitrary time preprocessing a particular baseline, delay a different part of the input, or use several late words. Thus the exact successor here counts representable static tests. It supplies no induction on program size or executed instructions. In particular, replacing a many-clause lookup packet by a single positive clause on the same small databases can fail before any RAM clock enters the argument. The associated [clock equivalence](literal-profiles-at-the-last-clause.md) identifies the ordinary SAT function problem behind a constant-time finish. Priority for the SAT formulation and the polarity comparison is unestablished. [Lean semantics and cross-intersections](LateClauseLiteralProfiles.lean) · [Finite audit](late_clause_support_audit.py)

Related models include nonadaptive bit-probe membership, in which the query reads bits of one stored string, and knowledge compilation, which studies transformations and subsequent queries on propositional theories. Here a query tests existential compatibility with an entire CNF under a bounded number of newly supplied clauses. The two-families inequality is classical. A focused literature search did not settle priority for the stated SAT representation thresholds.
