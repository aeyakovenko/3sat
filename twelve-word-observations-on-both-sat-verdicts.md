# A one-bit pair forcing twelve observed words per seven source clauses

For every $m\ge1$ and every globally correct deterministic SAT RAM, there are two ordinary proper ASCII DIMACS files of the same length $N=\Theta(m\log(m+2))$, differing in a single bit, with the following properties.

* One file has a unique satisfying assignment even on all declared variables. The other is unsatisfiable.
* On both, the RAM has to observe each of the same $12m$ different original input words before answering. On the positive run $5m$ of those words specify disabled literals. All its enabled choices are the last ones read in their respective source clauses.
* The two executions coincide through every step preceding the first observation of the differing word.

Initially writable input and arbitrary workspace are allowed. An observation here means an operation actually depending on the original contents of the word. A write replacing an unseen original word cannot distinguish two of its possible initial values. On an instruction set with at most a fixed number of original-word reads per instruction this gives $\Omega(m)$ executed steps. There is one globally correct program with $O(m)$ steps on the entire displayed family.

## The physical switches

On each of $m$ disjoint triples put the seven signed clauses forbidding all triples of truth values except $111$. At its one model, three clauses have one true literal, three have two, and one has three. Thus there are $12m$ live occurrences in all and $7m$ clauses. Only the positive occurrences are live. Each may independently be disabled.

Assign the $3m$ original variables identifiers $10j+2$ for $1\le j\le3m$ and use header limit $V=30m+3$. Force variables $1,2,3$ to zero by the seven clauses forbidding their seven nonzero assignments. Force **every** other declared identifier except the original variables to zero by a row $(\neg u,1,2)$. In this notation the last two literals are the positive literals on identifiers $1,2$. Each row has three distinct names. A switch in the source rows changes the positive occurrence of $10j+2$ to the permanently false $10j+3$. Only the low bit of the last ASCII digit changes. Clauses remain proper even if all their enabled positions are disabled. All identifiers have occurrences. An original variable also occurs in the fixed negative literals, independent of its switches.

Pad the body with whitespace so any two switch bytes are farther apart than twice the physical word width. For example the gaps can be a sufficiently large fixed multiple of $\lceil\log_2(m+2)\rceil$ bytes, depending on the fixed word-width coefficient. The file still has $\Theta(m\log(m+2))$ bits, with its header and padding independent of the mask. Even a read of an unaligned interval of one word can see at most one switch. For the usual aligned word RAM there is a designated original input word at each of the $12m$ sites.

Changing occurrences to false strengthens the seven-clause formula. Any satisfying assignment must therefore have every original variable true. It succeeds exactly when each of the $7m$ clauses retains at least one enabled live occurrence. The fixed-false rows determine every other declared variable. ## An adaptive adversary producing two fixed inputs

Run the machine with all nonswitch bits fixed. In each clause answer the first observation of an undecided switch with the disabled value while another switch in that clause remains undecided. The last such observation receives the enabled value. Keep answers fixed on repeated reads. If the machine writes a switch word before reading it, that operation conveys nothing about its original choice. One can equivalently maintain the set of full inputs consistent with all original observations and simulate writes in a separate overlay. Any lost unseen switch still admits both original values in that set.

If some clause has no observed enabled switch, there are still consistent inputs of **both** verdicts. For one completion, enable a remaining switch in every unfinished clause. For the other, disable all remaining switches of one unfinished clause. All past address calculations, branches and writes are identical on these completions. Thus a correct solver cannot halt in that situation. Nor can it run forever without finishing: there are finitely many unknown switches, and after a last observation any consistent input would reproduce the infinite execution. Correctness and halting on all well-formed files therefore force the observation of all $12m$ sites, exactly one enabled site and $t-1$ disabled sites in a clause with $t$ live occurrences.

This determines a concrete uniquely satisfiable file. Flip its last newly observed switch. Every other live occurrence in that clause was disabled, so the edited file is unsatisfiable. Its execution through the last new observation still touches all $12m$ sites. Which positive file the adversary selects can depend on the program and on $m$.

To attain the order bound, a fixed program can recognize the canonical template and keep one surviving-literal flag per clause. It recovers $m$ from the header, checks that the advertised length and layout match, and falls back to a complete SAT decider off the template. For valid sizes precompute the packed decimal spelling of each identifier from the spelling of its quotient by ten and the final digit. All spellings fit a constant number of words and there are $O(m)$ identifiers. Appending or checking each token and its canonical whitespace likewise takes $O(1)$ word operations. The program can first compare the file length with the expected order of growth and use the general fallback if the header is implausibly large. The resulting $O(m)$ upper bound together with the adversary gives $\Theta(N/\log N)$ time on the family. Appending one more seven-clause block increases the compulsory observation count by twelve. To lift this to superlinear SAT time would require a growing cost beyond checking each of those original words once.
