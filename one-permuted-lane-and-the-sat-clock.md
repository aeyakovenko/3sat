# One freely permuted list in the strip carries all three SAT clocks

Keep the eighteen-vertex anchor and red strip $x_1,\ldots,x_m$ of the [one-point construction](one-point-growth-with-mandatory-ram-reads.md). In the first blue gap, list every odd subscript in its natural order. In the second gap, allow **any permutation of the even subscripts**. The one-point negative chain uses the increasing permutation there. All possible choices still give simple permutations.

**Theorem.** Deciding three-colorability on just this family has the same deterministic $O(N^j)$ RAM thresholds as ordinary encoded SAT, for $j=1,2,3$, with unrestricted workspace. It suffices to use odd $m$. Every correct deterministic algorithm on this promised family takes $\Omega(m)$ word operations on **each** colorable member, regardless of how the free list is ordered. The physical length is $N=\Theta(m\log m)$. Both assertions also hold for the canonical proper DIMACS representation. An $\Omega(m)$ bound on every positive file also holds if the input is just the packed free list and its length.

## A seven-triangle relation

Use the alternating red sequence $y_0,z_0,y_1,z_1,\ldots,z_6,y_7$. Consecutive $y$ vertices are also adjacent in the fixed blue list. The seven triples $(y_i,z_i,y_{i+1})$ are triangles. Visit their tips in the free blue list in the order
$$
                     z_1,z_4,z_3,z_5,z_6,z_0,z_2 .
$$
In every proper coloring the first and last tips have color $y_0$, and $y_0\ne y_7$. Conversely for every ordered pair of distinct colors $(a,b)$ this relation extends. Write $d$ for the third color. One filling, with entries in natural subscript order, is
$$
 (y_0,\ldots,y_7)=(a,b,d,b,d,a,d,b),\quad
 (z_0,\ldots,z_6)=(d,a,a,a,b,b,a).
$$
For necessity normalize $y_0=0,y_1=1$. There are $2^6$ possible continuations of the $y$ path, and each tip is forced by its triangle. Only two continuations pass the six blue inequalities. Lean proves the relation for arbitrary colors and supplies a witness for all distinct endpoints. [Exact tile theorem](SevenTrianglePorts.lean)

For fixed, distinct endpoint colors $(a,b)$ there are exactly two fillings of the eight bases and seven tips. The first interior base $y_1$ is either $b$ or the third color, and its choice determines all remaining colors. Both fillings expose the same tip colors at the joins. Thus if the base endpoints of each of $k$ tiles are fixed compatibly at all joins, the tile interiors contribute a factor of $2^k$ to the number of colorings. Counting choices of padding or anchor colors is a separate step. The single-tile count is kernel-checked in [`exactly_two_fillings`](SevenTrianglePorts.lean).

Start from any two paths given by the identity and a permutation on $s$ vertices. Add three fresh vertices in common order before both paths and three in common order after both. Given any coloring of the original paths, prescribe color 0 on the first and last padding vertices. Choose the third prefix color to avoid the two old starting colors and choose the second to avoid both its neighbors. Fill the suffix in reverse by the same rule. For an empty source choose any suitable six-vertex path coloring with end colors zero.

Allocate a tile to each of the $s+6$ vertices. Concatenate their $y$ paths in source red order, identifying the end of a tile with the start of the next one. Concatenate their seven-tip blue lists in source blue order. A tile's start color is its source vertex color. Consecutive starts in red differ by the tile relation, and consecutive starts in blue differ by the join between the exposed tip colors. Conversely these are the only source inequalities needed to choose a filling for each tile. Give the last free $y$ endpoint color 2. The first $y$ has color 0 and the first and last blue tips both have color 0. The normalized anchor has $R_0=1,R_1=0,A=C=2,B=D=1$, so all six attachment edges are proper. Restricting any output coloring to tile starts recovers a source coloring without assuming any chosen palette normalization.

The output has $m=14(s+6)+1$ strip sites. Constructing its two orders takes $O(s+1)$ word operations and its index array has $O((s+1)\log(s+2))$ bits. The established linear-bit, linear-time reduction from explicit SAT to coloring two paths therefore composes within each of the three clocks. Conversely, render the given strip using three Boolean flags per vertex and the ordinary path-edge clauses in $O(N)$ bits and native time. If reading arbitrary strings is required, validate the representation before using it. These reductions also work between the length-plus-free-list representation and the fully rendered simple order. [Two-path source reduction](sat-on-a-single-simple-permutation.md) · [Compiler and constructive extension](single_lane_sat.py)

Each hard negative from the earlier [local proof transfer](local-color-extensions-for-interval-equations.md) can pass through the same construction. Padding colors use only the old endpoint colors. Each tile color uses at most its two source starts, with the final endpoint fixed. The constant-arity substitution proof gives the same linear polynomial-calculus degree on the negative images, in every field for the Boolean coloring CNF and in characteristic three for the modular interval presentation. A fast rejection algorithm for all negative images, sound on positives, would decide arbitrary explicit SAT at the same deadline. These proof-complexity conclusions allow unrestricted RAM algorithms to use any alternative method of rejection.

There is an equivalent input language with no anchor or prescribed boundary at all. Supply only a permutation of $0,\ldots,t-1$. Seek signs $d_i\in\{-1,1\}$ modulo three. For each consecutive pair in the permutation, sorted as $i<j$, impose
$$
                 -d_i+\sum_{i<k<j} d_k-d_j\ne0\pmod 3 .
$$
Indeed choose $y_0=0$ and take $y_{i+1}=y_i+d_i$. The unique tip in the triangle has color $z_i=y_i-d_i$, so the expression displayed is exactly $z_j-z_i$. All red and fixed-list constraints hold automatically. Conversely translate a proper coloring to make $y_0=0$ and read its nonzero differences. Replacing every vertex of an arbitrary two-order source by the seven-triangle tile in the two orders as above transfers its verdict here, with no prefix or suffix padding needed since the external boundary colors are free. The last base port can always be chosen different from its tile start. This is a succinct, single-permutation system of modular interval constraints equivalent to explicit SAT at each of the three clocks. Each compared value depends on the numerical signs along its interval.

## A lower bound on every colorable input in the restricted problem

Four consecutive tips, in local notation $z_0,z_1,z_2,z_3$, can be made uncolorable by giving them four consecutive free-list slots in the order $z_1,z_0,z_3,z_2$. Indeed $z_1\ne z_0$ forces $y_0\ne y_2$ in the first two triangles and therefore $z_0=y_2$. Likewise $z_3\ne z_2$ in the last two forces $z_3=y_2$. The blue edge $z_0z_3$ contradicts these equalities. This obstruction is independent of all attachments and anchor colors.

On **any** colorable input choose $h=\Theta(m)$ disjoint natural blocks of four consecutive interior tips, excluding strip endpoints if necessary. Also choose $h$ disjoint consecutive four-position windows in the physical free list. For a run on that input, each inspected free-list field belongs to at most one set of original positions of a natural block and at most one positional window. Fewer than $h$ distinct inspected positions leave both an entire natural block and an entire window untouched. Permute the at most eight entries in the union of their positions so that the four tips occupy the window in the obstructing order. This preserves the permutation even when the sets overlap. It gives a negative simple input with the same run up to the alleged acceptance. Consequently the run must inspect at least $h$ fields. A logarithmic word meets only constantly many of them. In DIMACS, assign each endpoint literal slot to its free-list entry when applicable. Each input word then observes only constantly many entry indices even though each entry occurs at more than one offset. The same untouched-block argument applies.

The edits can also be chosen with disjoint supports. Pair the $h$ disjoint natural blocks with the $h$ disjoint physical windows arbitrarily. Each of the resulting supports has at most eight positions, and each position belongs to at most two supports. Greedily keeping a support and discarding all intersecting ones keeps at least $h/9$ supports. Any nonempty combination places an impossible four-tip pattern in at least one intact window. On this binary family incident to each positive input the verdict is exactly $\prod_{i=1}^k(1-s_i)$ for $k=\Omega(m)$. Every physical bit is constant, a switch, or its complement. Thus the exact Boolean polynomial degree on this family is $k$ over every field. Four is the minimum number of consecutive tips for a boundary-independent obstruction of this form: on at most three triangles take $y_i=i\bmod3$, giving pairwise different tips compatible with any order. A separate finite audit checked 760 legal negative modifications of 32 positive full orders. [Local obstruction audit](four_tip_blocker_audit.py) · [Lean local proof](SevenTrianglePorts.lean)

Combining this with the negative-input lower bound gives $\Theta(N/\log N)$ on **every** member of the constructed disjoint-swap cube under the optimal globally correct shortcut, including all its positive members. On arbitrary free lists the positive lower bound still holds, while the worst-case time on that larger class is the unrestricted SAT question. [Negative chain, encoding and cube recognizer](one-point-growth-with-mandatory-ram-reads.md)

## How far the SAT embedding goes from the ordered strip

Let $b$ count the missing undirected baseline edges $(x_i,x_{i+2})$ internal to the strip. Reversing a long run can move many entries while changing few of these edges. Every tile of the construction loses four of the six natural adjacencies between its seven $z$ sites. Only the pairs $\{3,4\}$ and $\{5,6\}$ survive. Joins between different tiles cannot restore the missing internal pairs. Thus every image, positive or negative, has $b\ge4(s+6)$. The simple clock-equivalent reduction uses a linear number of missing edges.

## An exact decoder when either or both parity lanes are permuted

Let the red gap of the 18-point anchor contain $x_1,\ldots,x_m$ in their natural order, $m\ge2$. Insert any permutation of the odd vertices in the blue gap $8\to5$ and any permutation of the even vertices in the blue gap $15\to0$, using the original zero-based anchor ranks for the gap names. Set

$$
b=\#\{i: 1\le i\le m-2,\ \{x_i,x_{i+2}\}\text{ is absent from the actual blue edges}\}.
$$

**Theorem.** A deterministic word RAM can decide three-colorability of this family in $O(m+2^b)$ time and $O(m)$ words, including recognition of the anchor and validation of both lane permutations in the physical rank array. The result holds for either verdict. For $b\le\log_2 m+O(1)$ the bound is linear in native words; lane order and orientation are arbitrary. It is an input-parameter upper bound on these permutations.

The cut anchor forces $13,5,0$ to share one color, $8,15$ to share a second, and $14$ to take the third. The open anchor admits this signature. Normalize these to colors $1,2,0$, respectively. It remains to check inequalities along the red strip, along both blue lanes, and at the six actual endpoints attaching them to the anchor. A singleton blue lane touches both ends of its gap.

**Preprocessing.** Scan the two lanes with a direct-address array checking ranks, parity, and uniqueness. Mark each undirected distance-two edge by its greater index. Store every remaining within-lane edge as a chord. The ordered starts of the spans are 1 and each greater endpoint $s=i+2$ of a missing skip edge, found by a scan of the marks. Assign each strip position to its span in one pass. Assign each chord's check to the span containing its greater endpoint. Assign the six anchor inequalities to their endpoint spans. All array lengths and this entire preprocessing cost are $O(m)$.

**Coloring and branching.** Enumerate the six distinct color pairs at $x_1,x_2$. As long as the skip edge from $x_{j-2}$ to $x_j$ is present, the red edges complete a triangle, so $x_j$ must have the third color. This is exactly period-three rotation. At the start $s$ of a new span, the skip is missing and both choices distinct from $x_{s-1}$ must be tried. Once $x_s$ is chosen, the default color at $s+1$ is the third color relative to $x_{s-1},x_s$; if $s+1$ starts another span, the default is never used. Store the three period colors for the current span. The color of any already assigned strip position is obtained from its owning span and the offset modulo three. Check precisely the attached chord and anchor inequalities and explore the two children if all checks pass. The depth-first hypotheses use only earlier spans, so the palette at each depth can be overwritten on backtracking. Every actual coloring follows a branch, and any accepting branch meets every edge. Length two has a single span and no skip edges. All arguments still apply when a lane has just one vertex or when two missing skip edges are consecutive.

**Constant work per branch node.** A vertex more than two positions from the ends which retains both natural lane neighbors already has degree two within its lane. It cannot be incident to a chord or an anchor attachment. Thus any exceptional vertex is a strip endpoint among $1,2,m-1,m$, or is an endpoint of a missing skip edge. For a span $[s,t)$ in consecutive integer indices, with $t=m+1$ at the final span, the only possible greater endpoint of a missing skip in that span is $s$. Any smaller endpoint of a missing skip inside the span either has its greater endpoint at $s$, impossible for positions $\ge s$, or has it at or beyond the next start $t$, and so is $t-2$ or $t-1$. There are consequently at most seven candidates per span, including the four global ends. Their chord degrees are at most two. The time to evaluate the checks owned by a span is therefore bounded by a fixed constant independently of its length and $b$. The search has at most six binary trees of depth $b$, and an explicit depth-first stack needs $O(b+1)$ words. Modulo-three offsets can be pretabulated during the linear input scan on a RAM without a division instruction. No operation counts to $2^b$ or uses an exponentially wide machine word.

An even-lane permutation with at most $q$ adjacent transpositions deletes at most $2q$ undirected original lane edges, since swapping neighbors changes only the two exterior adjacencies. This gives $O(m+4^q)$ for such perturbations. Permuting a long reversed subblock can have equally small $b$ despite displacing many points.

The implementation in `one_lane_phase_decoder.py` accepts the full rendered permutation or its two parity lists. Its independent test builds the actual graph, checks all anchor as well as strip vertices by ordinary three-color backtracking, and compares both answers over every pair of lane permutations through length nine. The long-input checks include lane reversals, which must keep $b=0$ even when they change endpoint constraints.

The bound counts native word operations on a supplied packed order. For a canonical DIMACS file a deterministic scan suffices to validate its header and rows and recover the order in $O(N)$ time. An implementation requiring $O(m)$ packed word operations can radix-sort its fixed-width literal slots along with a table of the expected packed names, including signs. The keys have $O(\log m)$ bits and a counting-sort pass uses $O(m)$ buckets, so a constant number of passes determines the dense IDs. Regenerate the records to validate them. On other inputs use a general SAT solver. [Decoder and independent graph search](one_lane_phase_decoder.py)

## A compression obstruction for sparse deviations on negative inputs

Let a deterministic polynomial-time, linear-encoded-output-size reduction take every explicit 3-CNF to an order of the anchored strip, preserving the SAT verdict. Let $m$ be the number of variable strip vertices and $b$ the number of absent internal edges $x_i x_{i+2}$ of its canonical square. If for some fixed $\delta>0$ every **negative** image has $b=O((m+1)^{1-\delta})$, then $\mathrm{coNP}\subseteq\mathrm{NP/poly}$ and the polynomial hierarchy collapses to its third level.

To prove this, start with an arbitrary 3-CNF on $v$ variables. Densely renumber, remove tautologies and duplicate clauses, and render the result in polynomial time. There are $O((v+1)^3)$ distinct clauses, so the rendered size is $O((v+1)^3\log(v+2))$. Run the reduction, giving $m=O((v+1)^3\log(v+2))$. The red order, the anchor and the baseline strip are determined by $m$. A description of the actual graph needs $m$, the missing canonical distance-two edges, and the blue edges outside the retained internal collection. There are $b+O(1)$ of the latter, since the blue path has $m+O(1)$ edges and the canonical internal collection has $m-2$ for $m\ge2$. The description costs $O((b+1)\log(m+2))$ bits. The recipient needs only the graph to decide colouring.

The polynomial-time sender computes $b$. Choose fixed rational $0<\eta<\min(1,\delta)$ and a constant $K$ covering all negative files. If $b>K(m+1)^{1-\eta}$, the sender can immediately answer YES. Otherwise it sends the description above to an unbounded oracle, which returns the verdict in one bit. This deterministic oracle communication protocol has outgoing cost $O(v^{3-\epsilon})$ for some $\epsilon>0$, since the powers of logarithms are absorbed in the slack between $3(1-\eta)$ and $3$. Finitely many small $v$ can be handled directly. This is a restriction on reductions promising polynomially sublinear edge deviations. It leaves deviations such as $m/\log m$ open.

Dell and van Melkebeek's Definition 1 permits a polynomial-time sender and an unbounded recipient and charges only the sender's bits. Their Theorem 1 for every fixed integer $d\ge3$ and real $\epsilon>0$ gives the collapse consequence for cost $O(v^{d-\epsilon})$ on $v$-variable $d$-CNF. The deterministic single-message protocol here is a special case. [Dell and van Melkebeek, JACM 2014, Definition 1 and Theorem 1](https://pages.cs.wisc.edu/~dieter/Papers/sparsification-jacm.pdf)
