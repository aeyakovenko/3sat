# The global direct-addressing optimum is nine steps

The subsequent full census establishes a global optimum of nine in this finite model with arbitrary addressing. [Complete theorem and replay](exact-nine-step-clock-for-four-sat-words.md)

Take the four-bit native RAM and the 16-bit unit-selector SAT catalog. Allow arbitrary code size, unrestricted registers, every native arithmetic instruction, signed and unsigned binary branches, and writable memory. Suppose LOAD and STORE use literal addresses along a fixed instruction path. The exact unrestricted-code worst-case optimum at this length is **nine executed instructions**. Direct addressing is a restriction on this finite result. The unrestricted RAM retains the eight-to-nine interval. ## Direct memory on one path

On a path whose addresses are literal, each load reads from a known cell. If that cell was written earlier it returns a copy of the last stored value. An unwritten scratch cell returns zero and an unwritten original cell supplies its input column. Replace each direct read or write by the resulting register renaming, or by a source for the raw input. A correct path on one of the targets requires a read of every original value before overwriting it. After charging four instructions for these fresh loads, an eight-step path with $c$ comparisons uses at most $4-c$ binary arithmetic operations. Comparisons may move past subsequent operations on this one fixed path, since their outcomes determine control but do not modify data.

Represent the surviving test as a conjunction of $c$ comparisons on four original columns, literals and results of up to $4-c$ native operations. Remove an arithmetic gate when its value has no directed path to a comparison. Every one of the four raw columns must then occur as an operand somewhere in the remaining graph. Otherwise changing that one column from any accepted target to an overlapping mask would leave its verdict unchanged. This necessity holds regardless of how many literal input addresses the original program repeated.

A graph with $a$ retained arithmetic gates and $c$ binary comparisons has $2a+2c$ operand slots. At least $a$ slots must refer to a retained gate and at least four must refer to distinct raw columns. Thus there are at most $a+2c-4$ literal *occurrences*. With $c=1$ there are at most three ALUs and one literal. At least two ALUs are needed to use four columns with one comparison. With $c=2$ there are at most two ALUs and two literals. This count includes shared arithmetic subexpressions.

## Exhaustive support check

Choose the directed operand wiring in a topological order, with zero, one or two distinct literal placeholders as allowed by the bound. Retain only graphs using all four columns and every arithmetic gate. Swapping both operands and reversing an opcode accounts for noncommutative operations. The census tries all 20 opcodes. Interchange the first two independent ALUs when needed to put their operand pairs in sorted order; refer to their renamed outputs in all later gates. For a terminal comparison enumerate equality, unsigned order in both directions and signed order in both directions, and both branch outcomes. Two retained comparisons can repeat. A tautological comparison can be removed or replaced by a duplicate of the other when it is the only effective test.

Run each choice on the 64 targets and 3,456 negative examples. The latter include 00FF and every negative file obtained by replacing one of the two complementary pairs by an overlapping pair while keeping the other pair fixed. Full-domain soundness implies a path must reject every file in this suite. For one comparison, the 552 wiring templates and 90,388,089 arithmetic/literal assignments admit no test covering 33 targets and rejecting all negatives. For two comparisons, the 2,628 templates and 58,578,564 assignments admit no test covering 17 targets and rejecting all those negatives. Reusing a negative lane for pruning changes the runtime of this check only. Every surviving candidate is tested against all the other negative lanes. The four bounds give at most $64/2^c$ target files per accepting path under a hypothetical eight-step program. Since at least one reachable terminal rejects, the Kraft sum of the accepting comparison transcripts is strictly less than one. Their union cannot cover the 64 targets. This proves the direct-addressing lower bound. In particular an unrestricted eight-step algorithm for this catalog, if one exists, must use value-dependent memory addressing in a way that defeats one of the one- or two-comparison support bounds.

Compile and run `c++ -O3 -std=c++20 eight_step_direct_guard_census.cpp -o /tmp/sat-direct-guards && /tmp/sat-direct-guards`. The result concerns one finite length. The entire unit-selector catalog itself admits a word scan as its length increases.
