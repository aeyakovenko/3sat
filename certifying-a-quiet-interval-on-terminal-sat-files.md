# What an invariant can certify before a SAT solver's first YES

The same-clock learner produces actual uniquely satisfiable $N$-bit files on which any fixed correct deterministic SAT program eventually returns YES but takes $\Omega_P(B)$ native instructions, with $N=\Theta(B(\log B)^3)$. Consider trying to shorten the learner's formula by certifying only *absence of a YES through a proposed deadline* $b$. It would be enough to improve the construction on the selected terminal masks. Two limitations already occur on those actual positive files. They concern reusable state assertions and locally checked boundary states respectively. [Construction and terminal-mask guarantees](locally-indexed-formulas-for-the-delayed-forecast.md)

## Exactly which elapsed times reusable assertions certify

Fix the actual complete file, the solver and its initial configuration $s_0$. Extend its transition function $F$ by absorbing halts. On a positive file let $T$ be the first instruction time at which it has returned YES. A safe state has not yet returned YES. Take a finite directed proof graph with a start and a designated safe endpoint. Each edge $u\xrightarrow{d}v$ has a fixed duration $d\ge0$. A certificate gives an arbitrary set of states $I_v$ for each vertex. Require $s_0\in I_{\rm start}$, $F^d(I_u)\subseteq I_v$ for every edge, and safety of **every** state in the endpoint set. Neither an effective representation nor a size restriction is imposed on the sets.

Such assertions exist if and only if *every* start-to-end path has elapsed length strictly below $T$. Indeed, induction places the genuine state after the sum of the edge lengths in the terminal assertion. Conversely take $I_v$ to be the genuine states reached after exactly the elapsed lengths of paths from the start to $v$. These sets are closed under every prescribed implication. The converse is semantic and supplies no efficient verifier for those sets. To justify a particular deadline $b$, the graph must also reach its safe endpoint on a path of length at least $b$. Absorption then gives safety at time $b$.

A positive-duration cycle on a path from start to end is impossible. Repeat the cycle, then follow its suffix to the endpoint. This would force a safe state arbitrarily late in the *same* genuine execution. Intermediate assertions need not be safe. Delete zero-duration cycles from a path reaching the deadline. If there are $g$ vertices and the largest primitive advance is $L$, then $(g-1)L\ge b$. In particular, a proof DAG that reuses an unparameterized, positive-duration subderivation twice on one expanded path would repeat its starting assertion and create exactly this obstruction. Branching alone cannot fix it when each edge is required to work on every state in its source assertion.

These bounds have clock-sensitive variants. Suppose edge permissions depend on a finite timing controller with $m$ states, whose update for each permitted edge is prescribed. Allow assertions to depend on the controller state. Apply the same theorem to the product graph to get $(gm-1)L\ge b$. A time residue modulo $m$ is one such controller. The count is sharp even for unit advances: use $g$ stages and an external clock modulo $m$, prolonging each stage until residue $m-1$, then advancing to the next stage as the clock wraps. The final residue of the last stage occurs at time $gm-1$. Run a deterministic machine whose first YES is at $gm$ or later, and use the exact singleton states at the successive stage-residue pairs. With no external clock this is the usual path of $g$ vertices. When every primitive advance is checked by explicitly unrolling all its $d$ steps, the distinct positive advances on the chosen path already require at least $b$ step records, even if subproofs are shared elsewhere. For target $k$, a certificate of encoded length $o(b^{1/k})$ with at most that many explicitly named assertions and no further clock states would need an individual certified advance of $\omega(b^{1-1/k})$.

The number of semantically distinct assertions can be much larger than their text. A binary counter gives $2^w$ possible timing states with $w$ bits. A predicate parameterized by its current or starting counter value can support a long jump in one arithmetic statement. A transition guarded by data in the actual RAM state can also depend on information that an unparameterized graph edge does not carry. The product argument applies only when the enabled edge works from *every* state in its specified source class and has its promised target class. A may-transition witnessed by just one state cannot be repeated in this proof. [Lean equivalence and cycle theorem](QuietIntervalCertificates.lean)

## A boundary state that requires a linear number of raw probes

Take **any** correct total SAT solver $S$. Construct $S^\dagger$ with disjoint banks for the simulated $S$ and a fresh initially zero guard bank. Before every simulated instruction, read the guard word at a cycling counter $i$, starting from zero. Return an absorbing YES immediately on a nonzero word. Otherwise advance $i$ modulo $\max(1,N)$ and take the simulated instruction. Never write to the guard bank. The external input is still an ordinary physical SAT file. Distinct tagged addresses can use a larger fixed logarithmic-word coefficient; when simulating $S$, keep its original widths and word layout. Each simulated step costs at most a fixed $K_S$ native instructions, including packed input and any access overlay. This construction preserves the verdict on every actual input, runs in $O_S(T_S+1)$ time, and uses only $O_S(1)$ additional nonzero working words beyond the simulation and any constant-factor representation of its bank. A syntactic compilation of each fixed instruction with a bank tag can store nonzero input overrides explicitly when the physical input is writable. Such simulation details can add $O(T_S)$ overlay entries when needed; the **guard** contributes no written array entry. In a read-only-input/separate-work ISA the ordinary tagged simulation needs no writable-input overlay.

Use the terminal file for the actual program $S^\dagger$ on the universal learner's chain, at any sufficiently large scale after its code is included. Its first true YES occurs later than $b=\lfloor c_SB\rfloor$ for a sufficiently small fixed $c_S>0$. The file is satisfiable, so it cannot instead stop with NO. Taking $b<N$ avoids counter wrap in the part of the execution of interest. Let $s$ be the boundary state at the first guard, including the complete original input and the initialized simulated registers. Any fixed startup is absorbed by shortening $b$ by its setup cost. A fixed-tag implementation starts the simulated program with constant work; even a standard input-layout conversion need not copy the physical file, since source packed words can be extracted on demand.

Keep everything in $s$ fixed except the guard array. Choose a constant $K\ge K_S$ that also covers the few instructions for the nonzero return. On the genuine run the first visits to guard addresses $i=0,\ldots,J-1$, with $J=\max(0,\lfloor(b-2K)/K\rfloor)$, are within the deadline with room for return. If the initially supplied guard at just address $i$ is changed to one, all earlier instructions see identical replies. The first read there starts the YES return by time at most $K(i+1)+K\le b$. These altered boundary states are counterfactual: an ordinary SAT input never initializes this fresh bank with a one.

Fix a proposed proof of safety and the verifier's successful computation on $s$. The verifier may use the actual formula, any input-dependent advice, and the proof freely. Suppose its only dependence on the offered guard state is by adaptive word probes, and that accepting a guard state with this proof implies no YES by $b$ **when execution is started from that state**. On this genuine accepting path it must probe every one of those $J=\Theta_S(B)$ distinct addresses. An unprobed one-address change would follow the very same verifier path and violate safety. The conclusion applies even if the rest of the proof uses binary clocks, branching, arbitrary mathematical predicates or long transition summaries. It counts all state-dependent probes, including those needed to choose subsequent tests. For checking the guard contribution alone this scan bound is tight up to a constant: test the at most $b+O(1)$ addresses reachable by the guard counter in $b$ native steps. This does not decide whether the simulated solver itself can signal early. [Lean adaptive-probe lemma](QuietIntervalCertificates.lean)

## A short proof that escapes the probe requirement

A checker may start from the true machine initialization or bind the boundary to a certified earlier execution. The fixed program has a symbolic proof that the guard bank begins zero and no instruction of the guarded simulation ever writes it. One induction covers the entire bank. For $S^\dagger$ this removes all unreachable guard-triggered YES paths, reducing the quiet question back to the real solver $S$. A small circuit explicitly supplied as the canonical bank with proven provenance also differs from an arbitrary raw array. Checking whether such a circuit has any nonzero value on the threatened addresses has a direct defect SAT formula using the circuit, an address comparison and a nonzero test. A separate proof or UNSAT check is still needed when the proposed circuit is unconstrained.

There are genuine terminal positive files where the entire quiet interval has a short arithmetic certificate. For example, take a fixed solver that scans $\lceil N/w\rceil$ packed input words before it is allowed to return YES, then calls an arbitrary correct SAT solver. It may carry the zero-bank guard as above. The added scan preserves every proposed worst-case upper bound $O(N^k)$ for $k\ge1$ if its underlying solver meets it. From the canonical initialization, each scan iteration advances the loop counter by at most one; while it is below $\lceil N/w\rceil$ the program cannot enter the deciding phase. This proves silence through $b<\lceil N/w\rceil$, which includes the selected fixed fraction of $B$ at all sufficiently large terminal scales. A verifier specialized to this fixed loop may use that proved rule and just check the binary inequality on $O(\log N)$-bit integers. Equivalently compile the arithmetic check into a small ordinary existential formula. Its arithmetic cost is polynomial in $\log N$. The rule remains sound if the guard's zero initialization and lack of writes are included. Arbitrary raw boundary states would again need $\Theta(b)$ reads for the guard condition. This exhibits the difference on the same actual file between using the verified program semantics and admitting all offered boundary states.

The full learner needs sound, sufficiently cheap evidence for the whole active race. The short scan proof covers a known prelude, and the guard transformation isolates a failure of state-only certification. A proof for an unrestricted competing solver that can decide the file during that interval is still missing. The unrestricted SAT time bounds remain open.

## Short inductive certificates for the actual delayed forecast

There is a different test that covers the **entire** physical observation horizon. It has one ordinary SAT query. Its coverage is limited even for invariant circuits whose encoded lengths grow as positive powers of the width.

Write $n=|\operatorname{bin}W|$, let $L$ be the maximum lag, and let $X$ be the $L=O(W)$ bits of the physical stream in reverse chronological order. At initialization $X$ contains the two specified historical ones. A step $F$ puts the product of the two fixed-size tap parities into position zero and shifts the remaining register by one. After $H=PkW^5+s_0+1$ steps, $X[0]$ equals the observed bit $V(W)$. The constants and two initial positions are fixed by the recurrence. Accesses outside the register return zero. [Physical recurrence](one-variable-delay-and-one-binary-product.md)

A compiler proposes a deterministic Boolean circuit $R(a,X)$ with an ordinary gate list and up to $q$ ordered bit probes. Each probe's address may depend on the answers to the earlier ones. Use $s$ for the number of ordinary gates and probe nodes; account separately for the $O(n)$ address wires per probe. The phase $a$ is time modulo a positive proposed period $h\le H$. Branches can be padded with ignored probes. A valid proposal satisfies all three conditions

1. $R(0,X_{\rm init})$ holds.
2. For every $a<h$ and every $L$-bit $X$, $R(a,X)$ implies $R((a+1)\bmod h,F(X))$.
3. For every $L$-bit $X$, $R(H\bmod h,X)$ implies $X[0]=0$.

Induction then proves $V(W)=0$. A compiler can write **one defect CNF** that is UNSAT exactly when these three conditions hold. Guess a failed check. For preservation, guess $a$ and the at most $2q$ probe answers from the two evaluations of $R$. Also guess the values at the constant number of old taps used to compute $F(X)[0]$. Evaluate the two circuit copies in query order. A read of $F(X)$ at positive in-range address $j$ requests the old bit at $j-1$. Its address-zero answer is computed from the guessed tap bits. Require every occurrence of the same in-range old address to receive the same value and every out-of-range read to return zero. A consistent list extends to a full $X$ by assigning zero at never-requested addresses. Thus this test captures exactly a counterexample, including adaptive addresses. Initialization uses the known two-seed register. For the final condition include the offending bit $X[0]=1$ in the old-address consistency test. No $L$-bit checkpoint is guessed.

Sorting the address/answer pairs by address with a fixed bitonic network and checking consecutive pairs uses $O(n(q+1)\log^2(q+2))$ gates. Fixed-lag and clock arithmetic adds $\operatorname{poly}(n)$ gates, including computing the horizon and endpoint residue, or the emitter can precompute those constants. The rest contributes $O(s+n(q+1))$ gates. Standard gate clauses give encoded length $O(g\log(g+2))$ for this gate count $g$, including ordinary decimal names. A direct emitter has polynomial logarithmic overhead per gate. In particular the file does not contain $h$ copies of the invariant.

For a fixed phase there is also a deterministic validity test. Enumerate the $2^{2q+O(1)}$ answer strings above and compute all circuit gates and address checks. Every extendible string represents an actual defect whenever it passes its test. Enumerating all $h$ phases, including the separate initial and endpoint checks, has wide-RAM cost at most
$$
          h\,2^{2q+O(1)}(s+n(q+1))\operatorname{poly}(n+\log(s+q+2)).
$$
This bound uses the explicit gate list. For the subdeadline regime its addresses and the enumeration counter fit a fixed multiple of $n$ bits. A checker can abort oversized proposals or use multiple words for bookkeeping outside that regime.

Fix **any uniform generator** for such proposals and put it in a wide forecast guest. On its own width the guest runs the generator and validity test, returning zero only when the proposal is valid. A returned zero observed in time would latch one, but validity implies $V(W)=0$. Thus every sufficiently large width of the guest's own header has $V(W)=0$, and a true proposal there takes $\Omega(W/n)$ combined generation and validity-test work. In particular, if generation costs $o(W/n)$, $h\le W^\alpha$, $s\le W^\gamma$, and $q\le\beta\log_2 W$ for nonnegative fixed exponents with $\alpha+\gamma+2\beta<1$, no sufficiently large width on that header has a valid proposal meeting these bounds. The same conclusion holds for a list of candidates when generation plus the sum of their tests fits the budget. This is a derived lower bound for a certificate format on an actual negative forecast prefix. A fixed program can generate a very long circuit inside the bound even when its probed support and number of phases are small. [Wide simulation and the untouched home track](one-sided-certificates-on-a-forecast-prefix.md)

For the SAT-clock attack one can instead put the generator, defect emitter, and a proposed SAT decider in the guest, returning zero precisely on **UNSAT**. The same own-header argument makes each sufficiently late, valid, cheaply emitted proposal there an ordinary unsatisfiable file on which that decider takes $\Omega(W/n)$ instructions. To exclude $O(N^k)$ the file must have $N=o((W/n)^{1/k})$ on infinitely many such widths. This argument allows a proposal to be invalid on arbitrarily many other widths. It still requires valid hits on the specific header of the compiler and decider; short proofs of a solver's initial prelude do not supply those hits. The period-and-probe exclusion above uses the header of the exhaustive **validity checker**, which may differ from the SAT-decider header.

## A late latch defeats every cyclic phase certificate, irrespective of size

The horizon must occur in the semantics of the invariant. Even with arbitrary predicates and unlimited probes, the three phase conditions above have a solution **if and only if**
$$
   (F^u(X_{\rm init}))[0]=0\quad\text{for every }u\ge0\text{ with }u\equiv H\pmod h.
$$
For necessity, apply preservation along the actual orbit. For sufficiency take the assertion at phase $a$ to consist of all actual states reached at nonnegative times congruent to $a$. Thus a certificate for the periodic conditions can fail to exist on a width whose answer at the specified observation is genuinely zero.

There are actual widths realizing this obstruction for every period simultaneously. Use a fixed narrow diagonal guest that returns zero only after more than $W^4$ genuine guest instructions. It reads the bit length $n$ of its binary width and runs a binary counter on $O(n)$ bits for $2^{6n}$ iterations. The narrow interval interpreter processes guest instructions in sequence; the guest's polynomial-in-$n$ bank and all its fixed scratch fit in $W-1$ cells for large $n$. It eventually returns. At row $W^4$ the home verdict bit is still zero. After return the complemented verdict is a stationary one at the same simulated cell on every later row. The observation slot recurs with fixed positive physical stride $D=PkW$, where $k$ and $P$ are the slot constants in the forecast construction. For every $h\ge1$, times $H+jhD$ eventually carry a one and all have residue $H\bmod h$. Hence on this entire sufficiently late cylinder **no period works**, even an arbitrarily large one. The cylinder itself has an easy proof of its true verdict by the running time of the explicit counter. [Row embedding, stationary latch, and narrow interpreter](one-variable-delay-and-one-binary-product.md#reconstructing-a-tape-from-a-one-bit-delay-line)

The obstruction can also be put on a self-test header for any fixed compiler and deterministic SAT decider. Run their trial with a native cap $cW/n$, using the fixed-width wide guest and a small enough constant that all banks used by the bounded trial fit inside the simulated interval. Return zero immediately on a timely claimed successful test. On any other outcome execute more than $W^4$ guest instructions and then return zero. Implement the delay by a fixed number of nested loops with counters in the fixed wide registers and bounds $W$; five full loops suffice. The delay performs no additional guest work-bank accesses. Use the direct sparse interpreter with one address/value entry per touched guest work word, updating register and controller fields in place. This implementation does not keep a chronological log of instructions and admits the eventual return even on the slow branch. Thus a stationary one is eventually latched on both branches. On a trial that regards only a **valid** cyclic invariant as success, the early branch is impossible for every period by the preceding argument. The actual verdict at the finite observation is zero on all these sufficiently late widths. This modified self-test prevents any claim of coverage on *all* such compiler/decider headers from following merely from truth at the horizon. It does not exclude the possibility of valid hits on a differently specified header.

The temporal implications are checked separately from the implementation of the guest. [Lean reachability and phase lemmas](QuietIntervalCertificates.lean)

One can remove the obstruction without writing $H$ copies of a predicate. Give it the *binary elapsed time* $a\in\{0,\ldots,H\}$, check its initial value at zero, enforce preservation only for $a<H$ with next time $a+1$, and test the desired bit at $H$. A defect still uses a single guessed $O(\log H)$-bit time and the same address consistency checks. With unrestricted predicates a certificate now exists exactly when the observation is zero: take the singleton actual state at every elapsed time. The remaining short-certificate question is whether a generator can obtain suitably small circuit descriptions of such time-bounded assertions on the decider's own widths. The semantic fix supplies no such size bound.

## How much of the elapsed clock a short invariant must use

Allow an invariant to ask an adaptive parity or comparison question about **all** $d=\lceil\log_2(H+1)\rceil=O(n)$ bits of the nonwrapping time. A parity question supplies a $d$-bit mask $m$ and receives $m\cdot t$ over $\mathbb F_2$, with $t$ written in binary. A comparison supplies a $d$-bit integer $b$ and receives $[t\le b]$. These are the circuit's only inputs from the clock. Its $r$ clock questions and $q$ memory-bit probes may be interleaved; a mask, threshold, address or query type can depend on all previous answers. Use an explicitly listed, topologically ordered circuit with $s$ ordinary bounded-fan-in gates and query nodes in total. The $O(n)$ wires for each query argument are counted separately. Branches can use ignored query slots. Individual clock bits are available as singleton parities. In particular the model can inspect the full clock in $d$ questions; it can also test an arbitrary cutoff in one question.

For this format the entire elapsed-time invariant can be checked deterministically in wide-RAM work at most
$$
  2^{2(q+r)+O(1)} M\operatorname{poly}\bigl(n+\log(M+2)\bigr),
       \qquad M=s+n(q+r+1).
$$
There is no factor of $H$. For a possible preservation defect enumerate the answer transcripts of the two circuit evaluations and the constant number of old tap bits. After fixing those answers, replay both evaluations in order. Every query argument is then known, even when an earlier clock answer chose a memory address or an earlier memory answer chose a clock mask. Check agreement of the old memory locations and the computation of the shifted register as above. The remaining condition is existence of **one** time in $[0,H-1]$ consistent with all the recorded clock answers, the first evaluation having used $t$ and the second $t+1$.

This last condition has a polynomial-time test. Since $t<H\le2^d-1$, the $d$ bits of $t$ have a first zero when read from least to most significant. Enumerate its position $k<d$. Set the lower $k$ bits of $t$ to one and bit $k$ to zero. Within this case, the bits of $t+1$ equal the bits of $t$ xor the mask of the lowest $k+1$ positions. Each parity answer about either clock therefore gives one affine equation in the bits of $t$. Each comparison answer, positive or negative, contributes an integer lower or upper bound on $t$, translating comparisons at $t+1$ by one in ordinary integer arithmetic. Intersect those bounds with $[0,H-1]$; an empty interval rules out the case.

To impose a nonempty interval $[L_0,U_0]$ on the affine system, express $t\ge L_0$ as the union of equality to $L_0$ and the at most $d$ binary prefixes that first exceed $L_0$ at one chosen bit. Do the same for $t\le U_0$, using prefixes that first fall below $U_0$. Intersect each pair of prefixes, rejecting contradictory pins. The surviving prefixes give at most $(d+1)^2$ systems with extra bit equations. Gaussian elimination decides their consistency. With $2r+O(d)$ rows and $d$ columns one can insert each row into an echelon basis of at most $d$ rows in $O(d^2)$ bit operations. Hence the per-transcript bound stays linear in the number of supplied rows up to polynomial factors in $n$. In a feasible case choose the indicated $t$ and complete the consistent memory answers by filling all other old addresses with zero. Their joint execution reproduces both enumerated transcripts. Conversely a real defect generates one feasible pair of transcripts. Initialization and the endpoint have fixed clock values and require only their corresponding memory checks. The enumeration establishes the displayed upper bound. Under the exponent bounds below all indices and the enumeration counter fit a fixed multiple of $n$ bits.

Fix a uniform proposal generator $G$ executable under the wide guest convention. Run $G$ and this exact validity checker in a guest that returns zero only after verifying a valid proposal; on an invalid proposal it remains silent. There is a fixed header depending on $G$ and the checker on which every sufficiently large width has $V(W)=0$. Indeed, a return observed before the deadline would latch one, whereas validity proves zero at the observation. The wide simulation therefore forces at least $c_GW/n$ combined guest instructions on every successful proposal there, for some fixed $c_G>0$. This work includes generating, inspecting and evaluating the explicit circuit. If generation is $o(W/n)$ and $M\le W^{O(1)}$, every such valid proposal on this header satisfies
$$
       2(q+r)\ \ge\ \log_2 W-\log_2 M-O_G(\log n).
$$
The estimate is automatic for $q+r\ge\log_2 W$; otherwise the enumeration fits the wide-word convention above. Consequently, for fixed nonnegative exponents $\gamma,\beta,\rho$ with $\gamma+2\beta+2\rho<1$, no sufficiently late width on that header has a valid, cheaply generated proposal with $s\le W^\gamma$, $q\le\beta\log_2 W$, and $r\le\rho\log_2 W$. For $s=\operatorname{poly}(n)$ and $q+r=O(n)$ the necessary total is at least $\tfrac12\log_2 W-O_G(\log n)$. This excludes cheap coverage by a specified generator. It makes no claim about the existence of short predicates left ungenerated on the same widths.

The ordinary defect CNF remains short when many clock questions are permitted. Guess $t$ explicitly, share one binary increment for the second evaluation, and implement each parity or comparison question with $O(n)$ ordinary gates. Together with the memory consistency test this gives $g=O(s+nr+n(q+1)\log^2(q+2)+\operatorname{poly}(n))$ gates and $O(g\log(g+2))$ encoded formula bits. Putting this emitter and a specified SAT decider in the guest gives the separate decider-header implication above. A superlinear RAM conclusion still needs valid formulas of the required size on that particular header. The clock and memory inequalities just proved concern the exhaustive checker's own header. The transcript test and its quantitative bounds are manuscript arguments; the exact semantic condition for the nonwrapping clock is checked in [Lean](QuietIntervalCertificates.lean).

## Shorter defect formulas for memory consistency

Fix a width and one proposed elapsed-time invariant. A preservation defect asks whether $K=O(q+1)$ claimed bits at old addresses can all belong to the same register. Each address has $b=O(n)$ bits. Keep an active flag, so padding and prescribed out-of-range reads can be checked separately. The initial and endpoint tests use at most the same number of records. The emitter can precompute the binary constants for the horizon, register length and tap positions in $\operatorname{poly}(n)$ time. With these constants specialized, $O(s+n(r+1))$ gates suffice outside the address checks, except for the $O(bK)$ gates for forming and classifying old addresses, which are included in the bounds below.

First, guess switch settings in a Beneš permutation network and require its output to be sorted by active flag and address. Check agreement on adjacent active records with equal addresses. Pad to the next power of two with inactive records. For every setting the output is a permutation of the input; for any input there is a setting realizing a sorted permutation. Thus acceptance is exactly consistency. Multiple settings for the same sorted order are permitted in this existential defect test. Each of $O(K\log(K+2))$ switches moves $O(b+1)$ bits, giving $O(K(b+1)\log(K+2))$ gates. This saves one logarithm over the Batcher address block. [Earlier local router and its rearrangeability proof](packed-band-transfer.md)

A shared choice of code coordinates lets us route much shorter keys. Encode every $b$-bit address by the same explicit binary code with length $m=O(b)$, constant relative distance $\delta>0$ and an $O(b)$-wire bounded-fan-in encoding circuit. Pad to the next message size of Spielman's doubling family. Set $D=\lceil C\log_2(K+2)\rceil$, with a fixed $C$ large enough to make $\binom K2(1-\delta)^D<1$. When $D\ge b$, use the raw $b$-bit key. Otherwise $D<b\le m$. Of $D$ independently sampled code coordinates, the chance of missing all differences for any one unequal address pair is at most $(1-\delta)^D$. Thus a single choice separates every distinct address in the list. Discard repeated sampled coordinates and pad with other distinct coordinates to exactly $D$; the enlarged set still separates all pairs. [Spielman, Theorem 19 and encoder construction](https://www.cs.yale.edu/homes/spielman/PAPERS/linearTimeIT.pdf)

To apply that choice to every address, use one explicit $m$-input, $m$-output bounded-degree superconcentrator of $O(m)$ edges. At each nonsource node guess a selector for one of its incoming wires, and copy the selected bit. Fix a total deterministic choice for every selector setting, including unused bit patterns. Use the **same** selectors at the corresponding nodes for every key. The first $D$ outputs now give the same function of the codeword for every key, regardless of which selectors were guessed. In particular equal addresses always receive equal shortened keys. For completeness, some vertex-disjoint paths connect the $D$ selected input positions to those $D$ outputs. Setting the selectors along those paths realizes all the distinguishing coordinates in one common order. No prescribed input-output pairing is needed. The remaining selectors can take arbitrary values. Multiple paths outside the chosen paths may carry copies; each selected path still carries its prescribed bit. Padding an explicit superconcentrator to an allowed larger size of $O(m)$ uses extra constant sources if needed. The two graph templates can be generated in $\operatorname{poly}(b)$ work once per circuit; replicating their gates and the incidences of the shared selectors costs $O(Kb)$ gates and wires. [Gabber and Galil, explicit superconcentrators](https://doi.org/10.1016/0022-0000(81)90040-4) · [Earlier use of tagged subsets](materialized-input-census.md)

Guess Beneš switches and require their outputs to be lexicographically sorted by activity class first and shortened key second. Carry each claimed bit with its record. This keeps inactive records out of every active key group. Enforce agreement on every adjacent pair of active records with equal shortened keys. A false consistency claim includes two occurrences of the same real address with opposite bits. They have the same shortened key for every choice of shared selectors and belong to one contiguous group in every accepted ordering, which makes the adjacent checks fail. For consistent data, take selectors separating all distinct active addresses and a sorted permutation. Then every adjacent check passes. This proves exactness even though the formula never checks that the selectors distinguish distinct addresses.

The three-bit simplex-code audit exhausts all 4,096 lists of three signed address claims using two shared code coordinates. It rejects all 720 inconsistent lists. Separate examples show how an inactive filler can hide a disagreement when the activity class is omitted from the sort key, and how independent coordinate choices can give two different keys to the same address. [Reproducible fingerprint audit](forecast_address_fingerprint_audit.py)

The full address consistency block now costs
$$
 O\!\left(K\bigl[b+\min\{b,\log(K+2)\}\log(K+2)\bigr]\right)
$$
bounded-fan-in gates, including its witness bits and wiring. When $\log^2(K+2)=O(b)$ this is linear in the number of presented address bits. For example, if $q=\Theta(n)$, $b=\Theta(n)$, $r=O(n)$ and $s=O(n^2)$, the complete defect circuit has $O(n^2)$ gates. Its proper ASCII DIMACS 3-CNF has **$O(n^2\log n)$ encoded bits**, compared with the $O(n^2(\log n)^2)$ guarantee from routing full addresses. For general gate count $g$ including witness input bits, gate clauses cost $O(g\log(g+2))$ bits. Simplify repeated literals and tautological clauses, pin three fresh false anchors by the seven proper triples excluding their other assignments, and fill any short clause to three distinct variable names with these anchors. Consecutive decimal names cost $O(\log(g+2))$ characters apiece. The direct emitter costs $\operatorname{poly}(n)$ for constants and graph templates and a polynomial logarithmic overhead per listed gate and wire, including serialization.

Changing the emitter changes the file passed to a solver and can change the diagonal guest's header. Put the chosen emitter, generator and correct solver together in a **new** guest and apply the same deadline argument on its own prefix. If generation and writing together take $o(W/n)$ and produce a valid invariant there, that solver takes $\Omega(W/n)$ time on the new unsatisfiable file. The size savings hold on every proposal. Establishing sufficiently frequent valid proposals on the new guest's prefix is still necessary for the unrestricted SAT time result.


For comparison with the three RAM deadlines, take $n=|\operatorname{bin}W|$, $b=O(n)$ and proposal counts polynomial in $W$. Then $\log(q+s+r+2)=O(n)$. The displayed bounds give at most $O(sn+(r+1)n^2+(q+1)n^3+\operatorname{poly}(n))$ encoded bits. For each fixed $k\in\{1,2,3\}$ it suffices for the **file-length** test that
$$
 s=o(W^{1/k}/n^{1+1/k}),\qquad
 r=o(W^{1/k}/n^{2+1/k}),\qquad
 q=o(W^{1/k}/n^{3+1/k}).
$$
In particular the sufficient native-memory probe budgets are $o(W/n^4)$, $o(\sqrt W/n^{7/2})$ and $o(W^{1/3}/n^{10/3})$, respectively, whenever the other two size tests hold. Then $N^k=o(W/n)$ for the serialized length $N$. Generation and emission must also fit $o(W/n)$ work, and validity must actually occur on infinitely many widths of that same compiler-and-solver header.
