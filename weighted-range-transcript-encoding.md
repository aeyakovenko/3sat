# A weighted dominance transcript in proper 3-SAT

A sequence of $n$ planar dominance operations with a public schedule of $u=O(n/\log^2 n)$ insertions and $\Theta(n)$ queries has a proper ASCII DIMACS transcript of length **$\Theta(n\log n)$ bits**. Each query supplies one movable native word for its coordinates and one subsequent movable word for its proposed answer. Both words carry the query's logical ID. Each complete model chooses exactly one incorrect answer, and there is exactly one model for each such choice. This holds for the full transcript and for prefixes ending after any fully annotated query, with all remaining physical positions set to their dummies. The physical order of the records can be arbitrary.

We use the dynamic weighted orthogonal range-counting problem of Weinstein and Yu. An insertion supplies $(x,y,w)\in[n]^3$, where $[n]=\{1,\ldots,n\}$. At query $(a,b)$ the correct integer is the sum of the weights of all earlier insertions with $x\le a$ and $y\le b$. Every insertion contributes separately, including repeated coordinates. Section 4 takes independent uniform operations, with an update at each **one-based** time divisible by $\log^c n$ and a query at every other time. Take $c=2$. On the subsequence $n=2^{2^s}$ with binary logarithms the period is integral and divides $n$, so the last hard operation is an update. Append one extra fixed query $(n,n)$ after time $n$. Its true answer is the sum of all weights, available online with one running counter. This extends each hard stream and keeps every original update and query. The encoding itself works for any public schedule with the stated cardinalities. The theorem on the source distribution uses its specified schedule. [Weinstein and Yu, §§1 and 4](https://arxiv.org/pdf/1604.03030)

## Select one completed query

Put $b=\lceil\log_2(n+1)\rceil$ and $R=2^b$. The selected coordinates use $b$ bits each and a proposed answer uses two base-$R$ digits. The exact sum is at most $un\le n^2<R^2$. Use one-hot leaves $J_j$ for the logical query times, including the optional final query. A chain of prefix OR equivalences and clauses forbidding a leaf together with the preceding prefix OR enforces exactly one selected time when its terminal OR is true. Scan the schedule backwards using suffix ORs to obtain, for each update time $t$, a wire $H_t$ true exactly when the chosen query is later than $t$.

For each coordinate and each answer digit, give one shared set of $b$ input bits a binary prefix decoder with $R$ named leaves. Its root is true. Each child is equivalent to its parent AND the appropriate signed next bit. Asserting leaf $a$ forces all $b$ bits of $a$ and then fixes every decoder wire. Four decoders together use $O(n)$ gates. There are no separate digit dictionaries per query.

Each physical position $v$ has one receipt wire $h_v$. Assert their disjunction. Encode records by the following clauses, padding with fixed true rows to a constant record length.

* A query record $(j,a,b')$ gives $h_v\leftrightarrow J_j$. Two binary clauses conditional on $J_j$ select leaf $a$ for the first coordinate and leaf $b'$ for the second.
* An annotation $(j,A)$ sets $h_v=0$. Two binary clauses conditional on $J_j$ select the low and high leaves of the proposed answer $A$.
* Each update $t$ has three public banks of $b$ fresh bits for its coordinates and weight. A movable packet $(t,\text{field},i,d)$ sets $h_v=0$ and, if $H_t=1$, pins bit $i$ in the named bank to $d$. A public clause for every such bit forces it to zero if $H_t=0$. These default values fix the model even when later update packets are completely absent, or their actual values differ from zero.
* A dummy sets $h_v=0$.

There are $3bu$ update-bit packets and twice as many query-related packets as query times. Their combined count $p$ is $\Theta(n)$. An update may be revealed over several successive word discoveries during a single source operation. No extra source query is interleaved between those bits.

## Arithmetic and the model count

The public circuit compares the selected two coordinates to those of each update. Unsigned comparison needs $O(b)$ Boolean gates, for example by keeping the comparison of the less significant suffix and resolving the next bit. Mask each $b$-bit weight by the conjunction of the two dominance tests and $H_t$. Add the resulting words in $2b$ bits using ripple-carry full adders. Assert that at least one bit of the sum differs from the corresponding bit of the proposed two-digit answer. Full gate equivalences give unique internal values. The total circuit cost of arithmetic is $O(ub)$, including all carries. No modular wraparound occurs on the stated inputs.

Consider an arbitrary physical permutation of a logical stream prefix ending after a query and its annotation, with dummies everywhere else. The receipt requires the selected $J_j$ to refer to a delivered query. That record and its single annotation pin both coordinates and both answer digits. Precisely the updates before $j$ have $H_t=1$, and all their bits were delivered. All other banks are forced to zero, even if their records were delivered before the prefix ended. Thus every input, receipt, and gate of the chosen test is determined. The assignment satisfies the final comparison exactly when that one answer is wrong. This gives a bijection from models to the incorrect annotated query IDs, including when the same coordinates occur at several times. With no delivered queries the receipt disjunction is impossible.

## One-word packets and a one-bit last annotation

If the actual low digit is $a$, reserve its leaf identifier in a block of numbers of the form
\[
          B+10\lfloor a/2\rfloor+2+(a\bmod2)
\]
with public $B$ a multiple of ten. The leaf names for $a$ and $a\mathbin{\mathrm{xor}}1$ have identical decimal prefixes and end in ASCII 2 and 3. The annotation refers to this low name exactly once. Its high-digit clause, logical ID, receipt, and filler are fixed. Replacing the integer $A$ by $A\mathbin{\mathrm{xor}}1$ changes one physical bit. Both integers are in $[0,R^2)$. Pin all skipped identifier numbers in the block to a fixed value. The number of holes is $O(R)$. Use consecutive identifiers for all remaining variables.

Three distinct anchor variables can be pinned false by seven ternary clauses, one for each forbidden nonzero setting. Pad every unit or binary with distinct false anchors. Use a satisfied ternary on anchors as filler. Simplify gates on constants or equal/complementary operands before generating their equivalences. Every output row has three distinct variables and no complementary pair. Repeated filler clauses are harmless. The header counts all clauses and declares only occurring variables, so unused declared variables cannot multiply the model count.

There are $O(n+ub+p)=O(n)$ clauses and variables, each name using $O(\log n)$ ASCII bits. Choose a sufficiently large fixed byte-aligned width coefficient in $w=\Theta(\log N)$ so that one position of a constant number of proper clauses fits in one word. Choose the public target $N$ first, for instance a power of two of order $n\log n$ with a large fixed factor. With its resulting width, pad the public source to a word boundary, give each of the $p$ records one aligned word including added whitespace, and fill any remaining bytes with public whitespace. The packet bank itself uses $\Theta(n\log n)$ bits. Only these $p$ words depend on the operands or annotations. This one-word assertion concerns aligned input loads with the stated width coefficient.

On a truthful full stream the file is UNSAT. On the file changing only the last annotation's low bit it is uniquely satisfiable. This also forces discovery in a lazy layout: give the next scheduled packet at the first read of a previously unused physical position. Until the final annotation has been supplied, there are two genuine full completions agreeing on all disclosed words and differing only in the final annotation. A correct decider must eventually request the next fresh position, since otherwise it halts identically on the two completions or runs forever on both. At the final pending word the two completed files have the same preceding native execution. For each earlier fully delivered query, two blank-padded continuations with its truthful and one-bit-wrong annotations also give opposite verdicts if all earlier annotations were truthful. Constructing these two continuations presupposes the true integer answer for that query. A single binary SAT decision on an equality claim does not recover an arbitrary unknown range sum.

For an online use of the Weinstein–Yu bound, a reduction can recognize deviation from the public operation-type schedule as soon as it occurs. It can retain all earlier updates in an append-only list for $O(u)$ probes on the measured schedule, then switch to direct summation on an unexpected query or changed schedule. Subsequent operations can be handled by continuing to maintain this list. This preserves exactness on arbitrary legal streams if the reduction was already exact on the scheduled ones. The extra final public query is generated internally after the last genuine source operation.

The finite audit builds actual constant-width blocks of proper DIMACS, parses the printed clauses, and counts assignments by branching and unit propagation. It checks shuffled placements, duplicate updates, coordinate equality and strict exclusion, digit carry, wrong high digits, dummy-padded prefixes, and the one-bit replacements.
