# Checking the superlinear Boolean circuit lower bound for 3-SAT

**Corollary of the November 24 list-distinctness theorem.** For some absolute $\sigma>0$, every fan-in-two Boolean circuit deciding ordinary ASCII DIMACS 3-SAT on valid inputs of length $n$ needs $\Omega(n(\log n)^\sigma)$ gates at every sufficiently large byte-aligned length. The clauses can have three distinct variables, the decimal identifiers can be dense, and the serialization permits whitespace before a newline. The bound also holds for specified fixed-width binary encodings below. The circuits have one Boolean output, unrestricted depth, arbitrary sharing and free choice of a different circuit at each length. Input pins are free. The exponent $\sigma$ is unspecified.

## 1. What the source proves

Take $N=2^w$, $q=2wN$, and let $D_w$ test whether $N$ unrestricted records of $2w$ bits are pairwise distinct. Theorem 2.2 of the matrix-multiplication preprint gives volume greater than $q w^\sigma$ for any trivalent binary-wire tensor network over a fixed finite field realizing one copy of $D_w$, for all sufficiently large $w$. We use $\mathbb F_2$. The theorem allows simultaneous tests of several lists, but one list suffices. It is stated independently of any hypothesis on the matrix multiplication exponent. Its proof divides into fields with and without ports and invokes other preprint results. The square exponent $9/4$ is downstream of this list theorem. ## 2. From ordinary Boolean circuits to the source model

For a circuit of $s$ gates on $q$ inputs, use the zero-one truth table of each gate as a tensor with at most two input wires and one output. Replace fanout by trees of three-leg equality tensors. The total number of downstream input positions is at most $2s+1$, including the designated output pin. Thus the total number of copy vertices is $O(s+q)$. Ignore unused input bits through unary all-one tables and pin the output to one. Take the tensor product of all these vertices, permute the ports, and contract internal wires. This construction works with arbitrary circuit depth and costs $O(s+q)$ vertices and wires. For fixed exterior inputs, a topological evaluation gives exactly one assignment consistent with all gate and copy tables. Pinning retains it precisely for a yes input. The contraction therefore returns the exact decision bit even in characteristic two. ## 3. A projection to dense decimal ASCII 3-SAT

Split each $2w$-bit record into eight chunks of $b=\lceil w/4\rceil$ bits, padding high positions with fixed zeros. Introduce a selector $s_i$ for each record and a bank of $2^b$ Boolean flags for each chunk position. If row $i$ is selected, its flag in each bank must be true. Require that at least two rows are selected and that at most one flag per bank is true.

These constraints are satisfiable precisely when two records agree in every chunk. Two selected rows enable the same flag in every bank. Conversely, select any duplicate pair and turn on just its flags. Both threshold constraints have fixed $O(N+8\,2^b)$-size width-three encodings. A running prefix records whether a flag has appeared in a bank. Two running prefix bits record whether one row or two rows have appeared. Encode each constant-fan-in update with its clauses. Turn a binary clause $C$ into $(C\lor p)\land(C\lor\neg p)$ and a unit into four clauses using the signs of two distinct padding variables. All original gate clauses use distinct gate inputs and outputs. Thus every final clause has exactly three distinct variables. [Binary two-bank version and strict-clause padding](matrix-list-unit-sat.md) · [Formal chunk-selector equivalence](DenseAsciiCircuitTransfer.lean)

In bank $j\in\{1,\dots,8\}$, write the flag name as the decimal digit $j$ followed by the $b$ chunk bits printed as the ASCII digits 0 and 1. Each name is positive, has the same length, and needs just copies of the source bits and constants in its serialized representation. The largest reserved identifier is below $9\cdot10^b=O(N^{(\log_2 10)/4})=o(N)$. Number all other variables consecutively above the reserved range. To ensure every integer identifier occurs, add a fixed clause $(g\lor X_v\lor z)$ for each reserved identifier $v$, with fresh distinct guard variables $g,z$ above the reserved range. Setting $g$ true extends every satisfying assignment of the original constraints. This adds $O(N)$ clauses. Using eight smaller banks avoids a general binary-to-decimal conversion in the circuit.

A fixed $w$ determines the header, token boundaries, every clause position, and the exact output length $L_w$. Each output bit is a constant or a copy of an input bit. The $O(N)$ clauses cost $O(w)$ bits each. The variable fields in the eight row references also give $L_w=\Omega(Nw)$, so $L_w=\Theta(q)$ and $w=\Theta(\log L_w)$. A circuit deciding SAT on those inputs, composed with the bit projection and one output negation, decides $D_w$. Its network has at most $A(s+q+1)$ size for an absolute $A$. The list lower bound gives $s\ge q w^\sigma/A-q-1=\Omega(L_w(\log L_w)^\sigma)$. Since $L_w=\Theta(2^w w)$, consecutive lengths have bounded ratio. For any larger byte-aligned length between them, insert fixed spaces before the last newline to reach that length. The same restriction argument gives the bound at every sufficiently large byte-aligned input length.

The original binary construction uses two banks indexed by $w$ source bits each, plus $O(N)$ public clause and variable identifiers. This also applies to Definition 2.1 of Yianni and Allahyar. Choose an absolute integer $c$ so that $m=2^{w+c}-1$ dominates the variable and clause counts for every sufficiently large $w$. Write each valid identifier in their $w+c$-bit little-endian field, retain their sign convention, and pad to exactly $m$ clauses by repeating a fixed public clause already present. Their encoding permits repetitions and unused variables. Its length $3m(w+c+1)$ is $\Theta(q)$. The bit map costs $O(q)$ even if constant offsets are added to name the banks. Hence their total Boolean function also has the stated superlinear lower bound at all sufficiently large field widths. [Yianni and Allahyar, Definitions 2.1 and 2.2](https://arxiv.org/html/2611.30887v1#S2)
