# A fourth boundary derivative of the binary outer-product graph has the matrix multiplication exponent

The exact graph $[C=ab^{\mathsf T}]$ of the outer product of two $d$-bit vectors has deterministic fan-in-two Boolean circuit size $\Theta(d^2)$. Compute the $d^2$ ANDs, compare them with the claimed entries, and conjoin the answers. With both factors zero, flipping any one claimed output bit changes the verdict. An output cone of $s$ binary gates can depend on at most $s+1$ distinct inputs. A trivalent binary-wire network for the same graph uses one AND table per entry and copy trees distributing the factor bits, for $O(d^2)$ vertices; each input pair fixes every internal value. Its $d^2$ output legs alone require $\Omega(d^2)$ vertices by trivalence. Give each input bit the normalized weights $(1-x_i,x_i)$ or $(1-y_j,y_j)$. Give output bit $C_{ij}$ the weights $(1,1+\sum_{c=1}^k t_c Z^c_{ij})$. At $t=0$ the scalar contraction equals one identically in all the input means. Let $M_k$ be its mixed coefficient $[t_1\cdots t_k]$, a formal polynomial over any chosen field. The matrices $Z^c$ are differentiating directions, with independent entries. There is no division by a factorial in this definition.

For each $1\le k\le3$, $M_k$ has an $O_k(d^2)$-gate division-free arithmetic circuit, even with arbitrary variable means. For $k=4$, fix any field $F$ and measure formal division-free arithmetic circuit size over $F$. The infimum exponent for the family $M_4$ equals the square matrix multiplication exponent $\omega(F)$. The November 24 theorem states $\omega(F)=9/4$ for every field. Thus for each fixed $F$ and each $\epsilon>0$ the family has cost $O_{F,\epsilon}(d^{9/4+\epsilon})$, and an $O(d^{9/4-\epsilon})$ bound for all dimensions is impossible. The Boolean decision itself has quadratic size at every dimension. These statements concern simultaneous mixed derivatives in the supplied directions; an individually specified output coordinate has a different cost. ## The threshold at four labelled edges

Each pair $a,b$ has exactly one output $C$. Expanding and summing therefore gives

$$M_k=\sum_{e_1,\ldots,e_k\ {\rm distinct}}\ \prod_{c=1}^k Z^c_{e_c}\ \prod_{i\in L(e)}x_i\ \prod_{j\in R(e)}y_j.$$

Here the edges are grid positions and $L(e),R(e)$ are their distinct row and column indices. A normalized input bit contributes its mean when required to be one, and contributes one when free. The distinct-edge condition comes from choosing at most one direction at each physical output socket.

Group placements by their two partitions of the $k$ labels into equal rows and equal columns. Discard partitions that prescribe a repeated edge. The resulting finite pattern is a bipartite graph whose edges carry their distinct matrices and whose used vertices carry the unary weights. The sum over labelings injective on each side can be evaluated by inclusion–exclusion over equalities among distinct pattern vertices on that side. Each term is an unrestricted weighted graph homomorphism sum on a quotient bipartite graph. When vertices merge, multiply their unary weights; when edges become parallel, multiply their edge matrices entrywise. All coefficients are integral and the number of terms depends only on $k$. The homomorphism-basis method for small subgraphs is classical. [Curticapean, Dell and Marx](https://arxiv.org/abs/1705.01595)

For $k\le3$, every resulting simple bipartite graph is a forest. Root each component. At each leaf-to-parent step, sum over all values of the child for each value of the parent, multiplying the edge and accumulated child weights. The cost is $O(d^2)$ per edge. At $k=4$, the only additional possibility is a single four-cycle. Its sum is the trace of a product of four matrices with the unary factors placed on the incident matrices. Two matrix products followed by an entrywise inner product suffice. This gives the claimed upper bounds over every field.

For the lower bound let $d=2m$ (an unused row and column allow odd $d$). Divide both sides into two groups of size $m$ and allow each direction to live in just one block. In cyclic order around the four blocks place

$$ Z^1_{U_i,V_j}=A_{ij},\quad Z^2_{W_k,V_j}=B_{jk},\quad Z^3_{W_k,S_l}=D_{kl},\quad Z^4_{U_i,S_l}=[l=i]. $$

Set all input row means to $x$ and all column means to $y$. Every term occupies each row group and each column group. The coefficient $[x^2y^2]M_4$ therefore has exactly one selected index per group. The last edge identifies $l=i$, leaving exactly $\sum_{i,j,k}A_{ij}B_{jk}D_{ki}$. All four edges are physically distinct and each labelled placement contributes once. Truncating two degree markers through $(2,2)$ at each gate costs a constant factor. Reverse differentiation of the resulting trilinear form in the $D$ variables gives all entries of the matrix product with a constant-factor arithmetic overhead. This argument applies in every characteristic because each $D$ entry has exponent one. More explicitly, if $S_F(d)$ denotes the minimum cost of the fourth mixed coefficient and $T_F(d)$ that of square matrix multiplication, these constructions give $T_F(\lfloor d/2\rfloor)=O(S_F(d)+d^2)$ and $S_F(d)=O(T_F(d)+d^2)$. For $d\ge2$ every one of the $d^2$ variables in the first direction occurs in a distinct placement monomial in the displayed edge expansion, so $S_F(d)\ge d^2-1$ by binary fan-in. The inequalities give the stated equality of infimum exponents. The two finite-size gate counts are compared at different dimensions. [Baur and Strassen, *The complexity of partial derivatives*](https://doi.org/10.1016/0304-3975(83)90110-X)

## An easy selector changes the threshold to one

The threshold at four applies to the fixed outer-product graph with two vector factors. There is a different exact graph, also of Boolean size $\Theta(d^2)$ and with every output of rank at most one, whose **first** mixed output coefficient already has arithmetic exponent $\omega(F)$ over every field $F$.

Its Boolean inputs are two $d$-square matrices $A,B$ and a selector vector $q$ of length $d$. Let $k$ be its first one, using indices $1,\ldots,d$. If it exists, output $C_{ij}=A_{ik}B_{kj}$; an all-zero selector outputs the zero matrix. A prefix scan of the selector gives all first-one indicators in $O(d)$ gates. Form each of the $d$ chosen row-indexed $A$ bits and $d$ chosen column-indexed $B$ bits by an OR of $d$ masked bits, and form their outer product. Comparing with $C$ again gives a quadratic Boolean test with the same $d^2-1$ gate lower bound from flipped output bits. Copy trees give a quadratic trivalent network, with every internal value fixed by the inputs.

Give the single selector bits independent normalized means $Q_k$, the two factors independent normalized entry means $X_{ik}, Y_{kj}$, and use the earlier output covectors $(1,1+tZ_{ij})$. The first response is exactly

$$[t]\,\mathcal H=\sum_{k=1}^d w_k \sum_{i,j} X_{ik}Y_{kj}Z_{ij},\qquad w_k=Q_k\prod_{h<k}(1-Q_h).$$

This follows by conditioning the bit sum on the first selected index. All subsequent selector bits are free and sum to one. The empty selection contributes only to the constant term. The formula is an integral polynomial identity, including in characteristic two. For arbitrary $Q_k$ compute all weights by one prefix product, scale each column $k$ of $X$ by $w_k$, multiply by $Y$, and take the inner product with $Z$. This costs $O(T_F(d)+d^2)$ gates. Conversely set all $Q_k=u$. Each selector weight is $u(1-u)^{k-1}$ with linear coefficient one. Thus $[ut]\mathcal H=\sum_{ijk}X_{ik}Y_{kj}Z_{ij}$. First-order truncation in $u$ and formal differentiation in $Z$ recover matrix multiplication from any arithmetic circuit for the first response, with constant-factor overhead. This proves equality of infimum exponents. The obstruction already holds for a normalized, uniquely extending graph family that performs a single data-dependent selection and forms just one outer product on each Boolean input.

## What the first derivative returns on the full product

For the true graph $[C=AB\bmod 2]$ use individual normalized means $X_{ik},Y_{kj}$ for the two input matrices and weights $(1,1+tZ_{ij})$ on the output. The constant term is one. In characteristic two its coefficient of $t$ is exactly the formal matrix multiplication contraction $\sum_{ijk}X_{ik}Y_{kj}Z_{ij}$. Indeed on each Boolean point the bit at $ij$ is the sum of the products over that field. The corresponding terms each depend on two independent input bits, so summing with normalized weights multiplies their means.

In any characteristic, first scale all $X$ by another marker $u$. The coefficient $[ut]$ of the scalar contraction is the same trilinear form. One direct proof uses the integer multilinear polynomial for parity, $\sum_{\varnothing\ne S}(-2)^{|S|-1}\prod_{k\in S}v_k$. Here $v_k=A_{ik}B_{kj}$ at a Boolean point, and distinct $k$ use distinct bits in each fixed output entry. After summing, the term for $S$ has $u$-degree $|S|$. The singleton terms give the assertion, with no division by two.

Accordingly an arithmetic circuit that evaluates this normalized response up to the indicated constant order gives a matrix multiplication circuit at constant-factor overhead. A linear-time SAT hypothesis yields a fast RAM decision on the actual bit graph and a small exact binary-wire network by checking a unique padded computation. Turning that decision into a comparably cheap calculation of the formal first response is the unresolved step. The quadratic outer-product example shows that even constant-order responses of exact, uniquely extending networks can already carry matrix multiplication complexity. ## The full canonical extension on the same rank-one graph

If the output bits also use normalized pairs $(1-z_{ij},z_{ij})$, the contraction is the unique multilinear extension of the Boolean graph. A polynomial-size division-free circuit for this canonical polynomial would imply polynomial-size formal circuits for the directed Hamiltonian cycle polynomial over the same field. In particular, applying the November 23 Hamiltonian-cycle lower bound gives size $d^{\Omega((\log d)^{1/3})}$ for the canonical polynomial at all sufficiently large $d$ in every fixed characteristic. The quantitative lower bound is an external input. Hrubeš previously established the general hardness of multilinearizing simple Boolean functions, including monotone 2-CNFs. The reduction below applies to this one explicit family of rank-one multiplication graphs. [Hrubeš](https://users.math.cas.cz/~hrubes/PDFs/Mult.pdf) · [Hamiltonian-cycle lower bound, formal statement](https://github.com/anthropics/formal-math/blob/11b6c7e3c927df2658f513b6b68ea7f8929c62c5/vp-vnp/Statement.lean#L39-L47)

For a CNF with $n$ variables, take $2n$ left vertices for its positive and negative literals and $M$ right vertices for its clauses together with $n$ two-literal conditions requiring at least one representative of each variable. Connect each right vertex to its member literals. For a graph edge pin the corresponding output to zero. For every other output use neutral weights $(1,1)$. These choices permit selected left and right sets exactly when they form a bipartite independent set. Give the left literal $i$ mean $uW_i$ and every right vertex mean $v$.

Fix a selected left set $S$. Its right summation is $(1-v)^{|N(S)|}$, since adjacent right vertices are forced off and all others are free. Its coefficient of $v^M$ is $(-1)^M$ when $S$ hits every condition, zero otherwise. Such an $S$ has size at least $n$ by the disjoint variable-pair conditions. The left weight is $u^{|S|}\prod_{i\in S}W_i\prod_{i\notin S}(1-uW_i)$. Thus $(-1)^M[u^n v^M]$ yields precisely the sum of the weights of satisfying assignments: size exactly $n$ selects one literal per pair and the original clauses are all hit. Applying signs modulo two preserves each equality.

The column weights just used really can be recovered from the fully normalized extension. On unpinned outputs in characteristic different from two set $z_{ij}=1/2$ and multiply by two per such socket. In characteristic two set all these $z_{ij}$ to the same marker $h$ and extract its coefficient of degree equal to their count. The top coefficient of each of $(1-h,h)$ is one in either state. Padding the bipartite graph to square size can use frozen zero factor bits and zero output pins wherever the factors force zero.

Use a deterministic Boolean circuit on directed edge bits to test whether the selected edges form a single Hamiltonian cycle on $m$ labelled vertices. One incoming and one outgoing edge per vertex, together with reachability from vertex one, suffice; $m-1$ rounds of reachability propagation and pairwise degree checks use $O(m^3)$ gates. Its definitional CNF has one extension of each accepting edge assignment. Set $W_i$ to the edge variable for each positive edge literal and to one for other literals. The resulting weighted polynomial counts every cycle once, over every field. The host side $d$ can be chosen at most $K m^3$ for fixed $K$. All marker truncations involve at most three variables of polynomially bounded degrees, so ordinary gatewise convolution incurs polynomial overhead over the original field. Padding shows monotonicity in $d$. The imported $m^{\Omega((\log m)^{1/3})}$ lower bound survives both the dimension change and polynomial overhead.

The full normalized extension consequently carries far more arithmetic complexity than its underlying Boolean outer-product test. This supplies a concrete obstruction to evaluating arbitrary symbolic boundary weights cheaply by exploiting uniqueness alone.
