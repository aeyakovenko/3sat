# Checking narrow-word RAM histories in packed host time

Fix a nondeterministic guest program, a constant register file, and the journal's ordinary indirect-address ISA. Let its payload have \(u\) bits, its unary allowance be \(t\ge u\ge1\), and its word width be \(w=12\lceil\log_2(u+2)\rceil\). Let the verifying RAM run on the actual unary-clock file of \(N=\Theta(t+u+1)\) bits with \(W=12\lceil\log_2(N+2)\rceil\)-bit words. The guest can use its entire address space. Fix \(0<\epsilon<1\). Whenever \(w=o(W)\), a uniform nondeterministic host verifies acceptance in
\[
 O_{P,\epsilon}\left(1+u+t^\epsilon+\frac{t w^2}{W}\right)
\]
native instructions. It has exactly one accepting branch per accepting guest path. Alternatively one existential block followed by a single universally chosen bank/address verifies the verdict in
\[
 O_{P,\epsilon}\left(1+u+t^\epsilon+\frac{t w}{W}\right)
\]
instructions per branch. Both procedures use \(O_P(1+tw/W)\) upfront host-word guesses after deterministic setup. These are \(O_P(1+tw)\) binary bits. The alternating verifier makes its address challenge after that whole block.

In particular, deterministic guest computations admit exactly unambiguous *nondeterministic* host verification of either verdict in \(o(t)\) steps for \(w=o(\sqrt{\log t})\). An arbitrary nondeterministic guest admits the same time bound for its accepting paths. With one universal address verification takes \(o(t)\) steps for every \(w=o(\log t)\). Here \(u=2^{O(w)}=t^{o(1)}\). The count-preserving example below separates the first instruction saving from the size of an ordinary 3-SAT output on an actual guest with only \(\Theta(\log t)\) input bits. [Word width in bounded native acceptance](native-unary-clock-band.md)

Memory verification by sorting address/time records is established. Robson studies the size of RAM-to-satisfiability reductions in his model. Ben-Sasson, Chiesa, Genkin and Tromer use nondeterministically routed memory records, and Jahanjou, Miles and Viola give local reductions of bounded nondeterministic computation to 3-SAT. Packed stable distribution and lookup tables occur in word-RAM algorithms, including work on wavelet trees. The estimate here uses the *different actual guest and host widths*, omits all time fields and preserves path counts. Priority for this quantitative combination has not been established. ## Chronological records without time fields

Guess exactly \(t\) records in fixed-stride slots. A slot includes the control and register state before that instruction, an explicit nondeterministic choice if it is a guess instruction, and the claimed response for each of its at most constantly many reads. Every irrelevant field is zero. The width \(h\) is \(O_P(w)\) bits, including fixed program counters. From a slot alone, CPU arithmetic computes the next controls and registers and emits the ordered memory events of that instruction. In case of two events on the same cell, retain the ISA's specified internal order. Reject an invalid instruction, field, bank action or computation. Adjacent slots must agree exactly with the computed next controls and registers. The first state is the stipulated initial state and the final transition must have reached acceptance. Use deterministic canonical stutters after halting. On an accepting guest branch the chronological string is uniquely determined, including actual choices whose results later become irrelevant.

Read packed guest input words, zero the unused high positions of the final guest input word, and prepend the corresponding writes to a distinguished input bank. All work cells initially hold zero. Guest reads outside the valid input can be filtered, truncated or returned zero by the prescribed input semantics; ordinary instructions never write the read-only bank. The permitted accessible input length and other initial registers can be checked separately. Given an unaligned starting bit, a guest input word comes from at most two host words since \(w\le W\). At most \(O(1+u/w)\) initialization events are required. Validate the length fields, fixed code, padding boundaries and every bit in the unary suffix, with a packed comparison costing \(O(1+t/W+u)\) native work. A known virtual unary suffix needs only its endpoints. Truncation and unused last host-word bits have canonical values.

All tables are computed from the widths, the fixed program and the numeric sizes at this length. Choose a chunk budget of a sufficiently small fixed fraction of \(\epsilon\log_2(t+2)\) bits. A chunk contains an integral number of slots; give its final short chunk a separate count. For sufficiently large \(t\) with \(w=o(W)\) the budget fits many slots. One table entry checks the CPU consistency inside a chunk and supplies its entry state, exit state and its densely packed, chronologically ordered list of events. Check the interfaces of consecutive chunks in constant time. A constant number of host words suffice for any table result, after allowing for all event slots of one CPU instruction. The table can be filled by ordinary direct finite simulation in \(t^{\epsilon/2}\operatorname{polylog}t=O_\epsilon(t^\epsilon)\) steps by shrinking the initial bit fraction. The same estimate covers the additional tables below, including a \(w\)-bit address parameter if needed. Any \(w\)-bit arithmetic operation of the fixed basis can be computed in a constant or fixed polylogarithmic number of host steps for tabulation, masking arithmetic back to guest width. The fixed program selects direct simulation instead at small or comparable widths. This keeps one uniform finite verifier for each fixed \(P,\epsilon\).

Each existential instruction guesses a complete host word of the packed record array. A final partial word rejects any unused one bits. Equivalently the host may use integral, zero-padded fixed-width record chunks and reject all unused bits in every chunk. Either convention preserves the exact number of accepting paths. A physical stream uses \(O(1+th/W)\) host words. A read of at most one host word's worth of bits at an unaligned position uses at most two physical words. A packed append splits its field at the available space of its current last word and starts the next word when necessary. No prealigned destinations are assumed.

## Grouping every address, or challenging one address

CPU checking has produced one chronological stream of \(O_P(t+u/w+1)\) events. A record contains its bank, address, read/write tag and \(w\)-bit value. The output of a read is its claimed response. A store carries its written value. The position in the stream, including initialization and same-step order, already determines time.

For each of the \(w+O(1)\) key bits from least to most significant, stably split the whole current stream into its two packed subsequences. For a chunk, digit position and final chunk count, the table returns its selected and unselected event words and their bit lengths, preserving order on each side. Append each to the corresponding destination stream. After the scan concatenate the two packed destinations with the same unaligned-append operation. One pass costs \(O_P(1+(t+u/w)w/W)\) steps, including copying and a partial boundary word. The constant increases for small clocks. By induction on the processed digits this is stable numeric order on bank/address. In particular every event at a given key remains in the exact original time order; neither a clock field nor an inverse permutation is guessed. The verifier itself performs the sorting, so no routing switch introduces extra accepting branches.

In the resulting stream process each address group from initial zero. A read must equal its current value, and a write replaces it. For a packed chunk, tabulate whether its internal checks pass, which value its first key requires from the preceding chunk (if any), and the last key/value pair it leaves. All internal group changes start at zero. If the first and last key coincide and the chunk only reads that key, the last value is its recorded final read. Compare the required value with the previous chunk's last value on the same key, or with zero on a new key. This takes one more packed scan. Correct local transitions and memory consistency together reconstruct a real guest execution by induction on time. Conversely its actual history passes every check.

For the alternate verifier retain chronological order, universally pick just one legal bank/address, and discard events at other addresses. A chunk's filtered events compose to an impossible relation or to a partial map requiring at most one incoming value and optionally replacing it by one outgoing value. The empty projection is the identity. Include this address in the table query and stream the resulting partial maps from initial zero. Every guessed history passes every address challenge exactly when all its memory reads are genuine. This removes all radix passes. The deterministic sorting procedure is still needed for the stated one-block count correspondence. [Cell-summary composition](batch-trace-grammar.md)

## Short physical payload, long ordinary SAT output

One fixed guest reads \(m\) in binary, with \(u=\Theta(\log(m+2))\) bits. It guesses \(m\) full native words, maintains their bitwise OR in a register, and accepts if it is nonzero. Its remaining-loop counter consists of \(O(1+\log m/w)\) limbs in base \(2^w\). Keep a pointer to its highest nonzero limb. A decrement walks the initially zero low limbs, turning them into all ones, then subtracts one from the first positive limb. If that limb was the highest and becomes zero, lower the highest pointer once or mark the counter empty. The digit path is deterministic and the total number of visited limbs is \(O(m+\log(m+2))\) by the geometric series of carry frequencies. All limb indices and the highest pointer fit the guest word; they are bounded by \(u+O(1)\). This supplies a fixed \(C\) such that unary allowance \(t=C(m+1)\) suffices on every path. The guest does not need access to its external clock.

There are exactly \(2^{mw}-1\) accepting paths. Their packed host verification takes \(O(t(\log\log t)^2/\log t)\) instructions. Any nondeterministic host with word alphabet \(2^W\) and at most \(s\) choices on a branch has at most \(2^{Ws}\) accepting leaves, by prefix-freeness or padding. A count-preserving simulation of this family therefore already needs \(\Omega(tw/W)\) host word choices. An ordinary proper DIMACS formula with a model count equal to the path count, or a positive multiple of it, must use at least \(mw-O(1)\) occurring variables. Even when unused declared variables count as choices, they multiply by a power of two and cannot account for the odd factor \(2^{mw}-1\). Spelling the distinct canonical variable names therefore requires
\[
             \Omega(t\log\log t\,\log t)
\]
physical bits. This is the odd-count obstruction on a genuinely short physical payload with a sublinear native verification clock. Decision on every positive-length counter instance is immediate. Any further argument for SAT's deterministic time requires a decision-preserving compression that can change counts or a genuinely short certificate on sparse accepting computations. ## A no-pad ordinary compiler at very small guest widths

For comparison fix a source program and let \(S=(2^w+r)w+O_P(1)\) bound the full configuration bits with \(r\) registers, including its control. The immutable payload is fixed. A shortest accepting path repeats no configuration: deleting the part between two equal states gives a shorter legal accepting path. An explicit guest instruction counter can be part of its ordinary memory. The *external* bound asks for acceptance by the deadline and is absent from its configurations. Replacing \(t\) by \(H=\min(t,2^S)\) preserves the verdict, leaves a subset of the original accepting paths, and preserves zero/one ambiguity. Compute the capped exponent by comparing \(S\) to the bit length of \(t\) before any nonsaturating power is needed. Use the standard local bounded-run proper-CNF compiler for the shorter machine. To preserve unambiguity when needed, route chronological memory records using a deterministic sorting *circuit* with unique internal gate values (including a chronological index for ties), and pin every unused field. Its named physical length and construction time are \(O_P((u+H+1)\operatorname{polylog}(t+2))\); each raw bit is computable uniformly in \(\operatorname{polylog}t\) time. [Regular packed layout and local source access](packed-band-transfer.md)

For a fixed \(k\in\{1,2,3\}\) and \(S\le (1/k-\delta)\log_2 t\), \(0<\delta<1/k\), the output has \(o(t^{1/k})\) encoded bits. For example choose \(u\le c((\log t)/\log\log t)^{1/12}\) at a sufficiently small fixed \(c=c(k,\delta)\); bounded rounding factors in \(2^w\) are included. This really produces the ordinary formula and uses no free presentation. The [one-fewer-binary-guess hierarchy](short-branch-verification-and-the-one-guess-compiler-barrier.md) instead supplies \(\Theta(t^{1/12})\) actual guest payload bits even though that padded payload has an \(O(\log t)\)-bit description. On the square-time unrestricted diagonal, \(u\) is polynomial in \(t\), hence \(w=\Theta(W)\). The packed record count gives no growing factor there.

Its CPU program includes two independent word guesses, an indirect write and a read-then-write instruction whose destination can alias its source. The tests use partial host words, native stutters, out-of-range input reads and multiple choices of event chunk boundaries.
