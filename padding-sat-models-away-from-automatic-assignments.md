# A linear-size SAT extension that controls the weight of every model

Let $v$ count the variables actually occurring in a proper, explicit 3-CNF with $N$ encoded bits. A proper clause here has three distinct variables. There is a deterministic $O(N)$-time map to another proper 3-CNF with $V=\Theta(v+1)$ occurring variables and $O(N)$ encoded bits. For sufficiently large $v$, it has all the following properties.

* Projecting onto the old occurring variables gives a bijection of satisfying assignments.
* Every extended assignment has one common prescribed Hamming weight. No assignment of that weight, in **any** order of the variables, is an affine function of the binary variable index.
* Fix $0<\epsilon<1$. Every model is at Hamming distance at least $v^{\epsilon-o(1)}$ from every assignment produced by binary deterministic finite automata with output having at most $(1-\epsilon)\log_2 v/\log_2\log_2 v$ states, and likewise from every permuted affine assignment. For each fixed state budget the distance is a positive fraction of $v$. This holds even if the automaton and the permutation of the variables are chosen after reading the file and seeing its model. The input to the automaton is the fixed-length binary index, most significant bit first, including leading zeroes.

Thus a solver fast on the image would give a solver for arbitrary proper 3-CNF with the same one of the $N,N^2,N^3$ deadlines. The construction preserves the unrestricted decision problem under a linear-time reduction. For a particular machine its running time on $F$ gives no lower bound on its running time on the extended file. All logarithms below are binary.

## Choosing the weight before generating the new clauses

Take $V$ to be the least power of two at least $4(v+3)$, and $L=\log V$. For each old variable $x_i$ introduce a twin $y_i$ constrained to equal $\neg x_i$. Add three fresh anchors pinned false by the seven distinct proper clauses that forbid their seven other settings. If $p,q$ are two anchors, the clauses $(x_i\lor y_i\lor p)$ and $(\neg x_i\lor\neg y_i\lor p)$ enforce each twin relation. The $R=V-2v-3$ remaining variables are pins. A single proper clause $(z\lor p\lor q)$ or $(\neg z\lor p\lor q)$ fixes each pin. Making $j$ of them true gives every model the same weight $v+j$. Every old model has exactly one extension. If the header declares unused names, all model counts in this statement refer to the occurring variables.

For a fixed automaton, compute its weight by counting paths of exactly $L$ binary transitions from its initial state. In each round send each state's integer count along each of its two outgoing arcs. Sum the terminal counts on states with output one. Each count is at most $V$. A permutation of variable names or positions preserves the resulting weight.

An accessible $s$-state transition table has a canonical breadth-first numbering starting at zero. Among the $2s$ ordered transition slots mark the $s-1$ first discoveries of noninitial states. For every unmarked slot give one of at most $s$ old destinations. Add $s$ output bits. Enumerating all such descriptions and discarding invalid ones takes at most $A_s\,\mathrm{poly}(s)$ operations for $A_s=2^{3s}s^{s+1}$. It covers all behaviors, since unreachable states can be removed. This first-discovery representation is established in the automata literature. [Almeida, Moreira and Reis](https://arxiv.org/abs/0906.3853)

For the stated $s$, $A_s=v^{1-\epsilon+o(1)}$. The sum over all smaller sizes, including the $\mathrm{poly}(s)L$ work per description, is $o(v)$. Mark all weights generated this way and the three affine weights $0,V/2,V$ in a length-$V+1$ bitmap. A nonconstant affine bit function on the full binary cube has exactly $V/2$ ones by pairing indices that differ in a direction on which its linear part is one. The interval $[v,v+R]$ has length greater than $v$, so some weight in it is unmarked. Choose the integer in the interval maximizing the distance to the nearest marked weight, including marks outside the interval. Two passes over the bitmap compute all these distances. If there are $D$ marked weights, the integer radius-$r$ neighborhoods of the marks cover at most $D(2r+1)$ integers. Taking $r$ a sufficiently small multiple of $v/D$ leaves an admissible weight uncovered. The actual Hamming distance from any candidate word is at least the difference in the two weights. Since $D\le v^{1-\epsilon+o(1)}$, this proves the claimed distance, including all permutations. For fixed state budget $D$ is bounded independently of $v$. Small $v$ with a separately specified constant state budget can be handled by increasing the power of two until its free interval exceeds the finite description count plus three. This last choice has constants depending on the budget.

There is an encoding pitfall. Renumber old names by increasing **numeric** value among the occurring names. Each dense replacement identifier is no longer in decimal than the occurrence it replaces. A decimal trie, with leading zeros normalized, gives this order in linear time by breadth-first traversal with digits visited in order. Store the decimal rendering of each new identifier once. The new clauses cost $O(v\log(v+2))=O(N)$ bits because $v$ different names over a fixed alphabet already require this much total length. The parse, rendering and writing therefore cost $O(N)$ logarithmic-word RAM operations, including the case of very long sparse identifiers. Applying the construction to its own output for the next fixed budget preserves the model projection by composition. Equivalently the larger budget may be imposed directly on the original file. This gives an algebraic successor for **witness classes**. One can instead take the least power of two at least $4\max(v+3,\lceil N/\lceil\log(N+2)\rceil\rceil)$. Then $V=\Theta(N/\log(N+2))$, the physical output has $\Theta(N)$ bits even for a heavily padded source, and the same proof gives state threshold $(1-\epsilon)\log N/\log\log N$ and distance $N^{\epsilon-o(1)}$. Any fixed positive slack in the threshold absorbs integer roundoff and the change of logarithms. An integer-only cutoff can enumerate successive state sizes while $A_s$ times a fixed polynomial in $s$ and $\log V$ is below $V^{1-\epsilon/2}$, using rational slack; this covers the stated threshold.

## A single ordinary solver that searches a growing automaton class

There is also a uniform algorithm in the other direction. It checks each ordinary input for an automaton model before falling back to complete search. Use zero-based indices in order of first appearance to specify the order for this test. Let $\lambda=\max(1,\lceil\log v\rceil)$. First intern the names and remove repeated ordered clauses. Over a fixed alphabet, $d$ distinct clause strings, in canonical spelling and with separate terminators, require $\Omega(d\log(d+2))$ total symbols. The strings of the retained representatives together use $O(N)$ symbols. A trie of the signed, normalized *original names* implements duplicate detection in linear time. Store the corresponding dense triples for subsequent checking. Thus $v+d=O(N/\log(N+2))$, including files with many repetitions or padding. The same preparation works for clauses of width at most three.

Pack $b=\Theta(\log N)$ candidate automata of the same size into word lanes. For each input symbol and state pair keep a word marking which lanes take that transition. At a node of the binary prefix tree keep one word per possible current state. Advancing all lanes down an edge takes $O(s^2)$ bitwise operations. There are $O(v+1)$ nodes in the complete depth-$\lambda$ tree. Save one word of outputs per occurring variable. Three word literals per retained clause and a final intersection test every lane. Mask unused lanes in the last batch. The work after preparation, through level $s$, is at most

$$
O\!\left(\sum_{j=1}^{s}\left[\left(A_j/b+1\right)(v j^2+d+1)+ A_j\,\mathrm{poly}(j)\right]\right).
$$

Taking the largest $s$ with $2^{3s}s^{s+4}\le(\lfloor\log(N+2)\rfloor)^2$ bounds this expression by $O(N)$. The sum of the geometric upper bounds is dominated by its last term. Partial batches add at most $O((v+d+1)s^3)=O(N)$. Computing the cutoff can use saturated arithmetic. For every fixed $\delta>0$ the cutoff eventually exceeds $(2-\delta)\log\log N/\log\log\log N$. The leading factor two here comes from the cost of physical identifiers and from word-parallel testing. The automaton may vary arbitrarily between positive inputs. Returning YES only for verified lanes and doing exhaustive search on abstention yields a globally correct ordinary solver with one uniform linear-time guarantee on this class of positive inputs. The fixed-order affine search covers another class in the same time. [Affine score computation](affine-scores-on-proper-sat-files.md)

The unrestricted RAM can read the pins, use any number of states, or choose its witness bits by computation on the entire formula. For example, with just a supplied target weight and a freely chosen permutation, even the template that assigns one to an initial interval can realize every assignment of that weight. The reduction rules out explaining hardness by the absence of the specified simple witnesses alone. Establishing a time lower bound on the image still requires an argument about every ordinary solver.

## Applying the extension to the short forecast witnesses

Use the compact variable count on the explicit bitonic bounded-run layout. Its $g$ gates and choice variables have dense numeric names, $v=\Theta(g)$, and the file has $N=\Theta(g\log g)$ bits. The transformed file still has $\Theta(g)$ occurrences and $N'=\Theta(g\log g)$ bits. A generator that knows a short true run can replay every old numeric gate value in $O(g)$ operations. In another $O(g)$ operations it can compute the forbidden-weight bitmap and the chosen weight, put opposite bits on the twins, and emit every added occurrence bit in the stipulated order. Rendering decimal variable names is unnecessary. The generator can use the original numeric gate IDs directly because their increasing renumbering is the identity. Generating the file itself during the guest computation still costs $O(N')$.

Consequently the outer SAT files in the witness-search obstruction may have **all** their models at polynomial Hamming distance from these automata under every ordering. At the aged stages their physical size is still $\Theta(2^{\lfloor\eta h\rfloor}h^4)$, which leaves a bounded list of candidate parameters from $N'$ alone. After a shared parse, the generator and occurrence checker still cost $O(g)=o(N')$ on a supplied passing cycle. The earlier contradiction therefore applies to the modified header with this encoder at each of the three clocks. This demonstrates on the same construction how a hard-to-index assignment can still be generated quickly from the semantics of the program. The original header still needs a passing certificate.
