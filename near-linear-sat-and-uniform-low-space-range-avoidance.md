# What near-linear SAT would imply for low-space range avoidance

Li and Tell revised their quantifiers on 26 November 2026. In their Theorem 1.3, after an algorithm for finding a missing output is specified, the hard indexed family can be chosen in response. Its polynomial-time evaluator may have an arbitrarily large fixed running-time exponent. The following implication uses just the simultaneous time and space requirement on that family and its claimed hardness. [Revision history](https://eccc.weizmann.ac.il/report/2026/233/) · [Revision 1, Assumption 1.1, Theorems 1.3 and 3.8, Definitions 3.2–3.3](https://eccc.weizmann.ac.il/report/2026/233/revision/1/download/)

**Conditional lower bound.** Under the simultaneous low-space, polynomial-time range-avoidance hardness premise of the revised Theorem 1.3, there exists a constant $\eta>0$ for which ordinary explicit 3-SAT has no deterministic $O(N^{1+\eta})$-time solver on the standard logarithmic-word RAM with unrestricted workspace. Here $N$ counts encoded bits. The independent circuit-hardness premise in that theorem can be omitted for this implication. The value of $\eta$ is unspecified.

## Put every eligible bit evaluator under the same clock

Suppose instead that for **each** rational $\eta>0$ there exists a deterministic SAT RAM with worst-case time $O_\eta(N^{1+\eta})$. Distinct exponents may use different programs. Fix a rational $0<\epsilon<1$ in the range of the avoidance premise and write $s=\lfloor n^{\epsilon^2}\rfloor$, $m=\lfloor n^\epsilon\rfloor$. For an $n$-bit index $x$ and $s$-bit seed $u$, one fixed machine for the family computes bit $i$ of $C_x(u)$ in simultaneous polynomial time and $O(n^{\epsilon^2})$ space. The tuple $(x,u,i)$ has length $\Theta(n)$ using an ordinary self-delimiting length field. Rounding or finitely many exceptional lengths do not affect the argument.

1. The bit language of any fixed eligible family has a linear-time alternating machine with some fixed number $k$ of blocks. Nepomnjaščii’s simulation shows that for fixed $d$ and $a<1$, simultaneous time $n^d$ and space $n^a$ is contained in fixed-alternation linear time. One can take $a$ strictly between $\epsilon^2$ and 1 to absorb machine constants and counters. Here $k$ can depend on the original polynomial degree. [Li and Tell, Theorem 3.8](https://eccc.weizmann.ac.il/report/2026/233/revision/1/download/) · [Fortnow, Sections 2–4](https://lance.fortnow.com/papers/files/npvsnl.pdf)
2. Separate the $k$ choice blocks into $k$ strings of $O_k(n)$ choice bits with a deterministic final path check. Any unused choices are ignored. The strings and the input together have length $O_k(n)$. For a fixed alternating tape machine the path check on a word RAM takes $O_k(n)$ time. Eliminate the last block first. Guess its string and run the current deterministic suffix decider, negating the predicate before and after existential simulation for a universal block. A nondeterministic RAM clock $t\ge n$ has a 3-CNF encoding of length $t(\log t)^{O(1)}$ generated in that much time up to another fixed polylogarithm. The explicit constructor pays for words, arithmetic, and sorted memory records. Ordinary ASCII clause lists incur only polylogarithmic overhead. If proper clauses are required, remove tautologies, replace shorter clauses by all sign choices on fresh variables up to width three, and handle the empty clause by a fixed contradiction. This increases length by at most a polylogarithmic factor. [Encoded RAM reduction](packed-band-transfer.md) · [Cook's quasilinear SAT reduction as stated in Fortnow, Lemma 2.2](https://lance.fortnow.com/papers/files/npvsnl.pdf)
3. A suffix taking $n^{b+o(1)}$ steps becomes a deterministic suffix taking at most $n^{b(1+\eta)+o(1)}$ steps. Here the limit is in $n$ with the machine, $k$ and $\eta$ fixed. Clocks may use integer-rounded rational powers and fixed polylogarithmic upper bounds. Choose $\eta$ *after* $k$ so that $(1+\eta)^k<2$. Starting at $b=1$ gives a deterministic evaluator running in at most $n^2$ RAM steps at all sufficiently large lengths, uniformly in $x,u,i$ for this fixed family. This makes a separate existence claim about one finite program for each family. This step does not require a procedure for selecting the codes of the SAT solvers or the block bound.

A common **machine model** matters as well. An ordinary multitape machine simulates a fixed $t$-step RAM here in $O_M((n+t)^2\operatorname{polylog}(n+t))$ time, by storing the at most $O(n+t)$ initialized or accessed words as address-value records and scanning on a load or store. Fixed word-width multipliers and the standard arithmetic basis affect constants or logarithms. Thus, for example, every eligible bit evaluator has some fixed ordinary TM code that runs in at most $n^5$ steps on all well-formed tuples at all sufficiently large lengths. The exponent 5 is shared across families. This replacement need not obey the original space bound.

## One algorithm against all those families

At length $n$ take the first $p=\max(1,\lfloor\log_2 n\rfloor)$ programs in a fixed effective enumeration of binary TM codes, including all finite codes eventually. Set $r=s+\lceil\log_2 p\rceil+1$. Eventually $r\le m$. On $(x,u,i)$ simulate each code for $n^5$ **guest** steps, using a fixed universal interpreter, and use zero for a timeout or invalid result. The interpreter takes polynomial time uniformly in $n$ and in these short codes. For each $x$, the resulting $r$-bit output prefixes cover at most $p2^s<2^r$ possibilities.

Given a prefix $v$ of length at most $r$, ask whether some extension $vz$ of length $r$ differs from the projected output for every code and seed. This is a single uniform $\Sigma_2^P$ predicate. Its existential choice is $z$, its universal choice is a code index and seed, and its verifier computes the projected output with $r$ bounded simulations. The census and timeout are fixed parts of the predicate. The fast SAT hypothesis implies $P=NP$ and hence $\Sigma_2^P=P$. Starting at the empty prefix, take the zero extension whenever it still has an omitted completion, and otherwise take the one extension. After $r$ queries append $m-r$ zeros. For the finitely many lengths where $r>m$, output an arbitrary $m$-bit string.

This gives **one** deterministic polynomial-time algorithm $A_\epsilon$. For *each* fixed eligible family, its accelerated bit program is eventually inside the census and finishes within the timeout on every index, seed and output position. From that length onward, $A_\epsilon(x)$ is outside $\operatorname{Range}(C_x)$ on **every** $x$. In particular it defeats the eligible family selected after $A_\epsilon$ in the revised assumption. Taking the contrapositive proves the stated SAT lower bound. The finite omitted-prefix principle applies to arbitrary tables, including invalid programs after totalization. ## How much hardness would suffice?

For one fixed rational $\epsilon$, it suffices to assume that for every deterministic polynomial-time $A$ with $m$ output bits, some eligible family has $A(x)\in\operatorname{Range}(C_x)$ on **one index at each of infinitely many lengths**. This is the precise negation of eventual universal avoidance for these lengths and parameters. No claim of average-case hardness is needed. Any attempt to prove this by hard-coding finitely many counterexamples fails the infinitely-many-lengths requirement. Letting a different machine hard-code the answer at every length loses uniformity.

The prefix-search calculation for a single fixed polynomial-time evaluator already works under $P=NP$. Its polynomial exponent can depend on that evaluator. The common clock above is what permits one predicate, and one avoider, for the revised ordering. Li and Tell's Theorem 6.12 also fixes the family first and uses a circuit-hardness assumption for an average-case guarantee. Li and Tell already define a universal missing-output problem in Definition 5.13. The use of low-space checkpointing and SAT-based elimination of alternations is classical. Fortnow, Lipton, van Melkebeek and Viglas also give a more general common-clock simulation via their Lemma 5.3. Priority for the specific uniform-avoidance implication here has not been established. The weaker infinite-hit premise remains unproved. ## Exhausting the one-hit premise at a single length

Let $L=2^n$ be the number of indices, $q=2^m$ the number of outputs, and $B=2^s$ the maximum range size at one index. First allow every table $A$ from the $L$ indices to the $q$ outputs as a possible avoider. At a single length, each such table does agree with some globally polynomial-time algorithm with a finite lookup table in its program. Its description size can depend on the tested length.

A collection of evaluators hits every such $A$ somewhere **if and only if** at some one index its combined ranges cover all $q$ outputs. Otherwise choose $A(x)$ from the omitted entries independently at each $x$. Consequently the minimum number of evaluators is exactly $q/B=2^{m-s}$. For the upper bound take one evaluator per $(m-s)$-bit prefix and append the seed. Taking $m$ to $m+1$ with $s$ fixed doubles this minimum. The lower bound holds even for an unrestricted set of evaluators picked specifically for the tested length. With a uniform constant bound on the number of evaluators, this successor eventually provides an avoider at each separate length. The open issue is computing the omitted entries across lengths with one fast algorithm. [Lean proof of the exact one-hit threshold](UniformRangeCensus.lean)

One can also require a *single* evaluator to hit $A$ on at least $h$ indices. With full $B$-element ranges at every index, one evaluator hits at most
$$
V_h=\sum_{j=h}^L {L\choose j} B^j(q-B)^{L-j}
$$
of the $q^L$ tables. Smaller ranges can be filled out. Thus at least $q^L/V_h$ evaluators are required. For $h=L$ the bound $(q/B)^L$ is exact, since one may choose the prefix table independently at every index and append the seed. These are ordinary finite covering counts. When $B=1$ the intermediate bound is the classical Hamming sphere-covering bound. The computational audit exhausts all candidate collections up to the first covering size for several small alphabets. Its unequal answers at the same output and seed lengths distinguish hitting at one index from recovering a positive fraction of an arbitrary table. [Finite audit](finite_range_hit_audit.py) · [Classical sphere bound and improvements, van Wee](https://research.tue.nl/en/publications/improved-sphere-bounds-on-the-covering-radius-of-codes/)

There is also a complexity-class obstruction to proving even infinite hitting by unrestricted padding. If $P=\mathrm{PSPACE}$, one polynomial-time algorithm eventually avoids every simultaneous evaluator above. To see this, simulate the first $p$ ordinary machine codes with a polynomial space cap shared across all codes, including the cost of encoding their tapes and states. A cap such as $n^2$ in a fixed binary universal simulation eventually covers every eligible fixed code. Timeout using a polynomial-bit counter larger than the logarithm of the number of legal bounded configurations, defaulting invalid or nonterminating computations to zero. Each bit can now be computed in polynomial space. The same omitted-prefix question is in PSPACE by enumerating completions, seeds and codes while reusing space. If $P=\mathrm{PSPACE}$, the prefix search therefore runs in polynomial time. The weak infinite-hit premise would already separate $P$ from $\mathrm{PSPACE}$. Dropping the polynomial-time requirement on the family leaves this particular obstruction intact. Li and Tell use a related universal space-bounded map in their Definition 5.13. [Li and Tell, Section 5.3](https://eccc.weizmann.ac.il/report/2026/233/revision/1/download/)

A direct attempt can enforce almost a full input scan. A seed-independent Vandermonde family hits any candidate with a run leaving at least as many whole input words unread as there are output words. An explicit polynomial attains the matching probe bound while leaving one fewer word unread, and a packed XOR scan avoids it in sublinear encoded-bit time.
