# Realigning a RAM execution after a physical input edit

Let $A$ be a deterministic logarithmic-word RAM with a fixed number of registers. Record each native step by its incoming controller (program counter and registers), operation, address, read reply or stored value if any, and outgoing controller. Include the verdict at halt. Use separate slots for the bounded number of accesses of a compound instruction. A blind store records its payload; if the instruction observes the overwritten value, record the read separately. Use the actual finite trace without padding, and do not attach an external absolute timestamp to a record. The program can still keep its own clocks. Let $D$ be the insertion/deletion edit distance between the complete traces on two equal-length files.

A supplied old trace can be indexed so that, after one announced input-word edit, **the new answer and an optimal trace edit script can be found in $O((1+D)^2\log(L+T+2))$ deterministic word time**, where $L$ is the input length, $T$ is the old run length, and the horizons are polynomial in $L+T$. A static predecessor index improves the corresponding cell-probe bound to $O((1+D)^2\log\log(L+T+4))$. Only the old trace is supplied. In particular a branch which inserts one instruction before a long unchanged computation is charged for the actual insertions and deletions. The wavefront search is Myers's algorithm. The additional ingredient is a way to extend matches in a new RAM execution that has never been materialized. [Myers, Lemmas 1–2](https://par.cse.nsysu.edu.tw/resource/lab_relative/Myer86.pdf) · [Earlier time-aligned replay](incremental-native-traces.md)

Trace-distance bounds for change propagation have a substantial literature. Acar defines an intrinsic minimum over trace correspondences, and later work treats changes to structured reads and writes. Here the distance is ordinary string insertion/deletion distance on full native records, and the searched second string is an unmaterialized deterministic RAM execution. Priority for the exact bound in this formulation is unestablished. [Acar, *Self-Adjusting Computation*](https://csd.cs.cmu.edu/sites/default/files/phd-thesis/CMU-CS-05-129.pdf) · [Acar et al., *Traceable Data Types for Self-Adjusting Computation*](https://www.cs.cmu.edu/~blelloch/papers/ABLT10.pdf)

## The old index and the next unequal read

Index the old stores and the old accesses by address and old position, with the initial memory available. At old boundary $i$ this gives the old value of any cell by predecessor store and the next old access to it by successor. Sorted arrays and binary search suffice in the native time bound. For a polynomial old clock all records fit constantly many words. The arrays can be built deterministically in $O((L+T)\log(L+T+2))$ time or by constant-pass radix sorting the polynomial-width keys with $O(L+T)$ time and touched words. For static cell probes, a prefix trie on the packed keys with static perfect hashing takes $O((L+T)\operatorname{polylog}(L+T))$ space and permits $O(\log\log(L+T+4))$ predecessor probes by binary search on prefix length. It is enough that query probes be deterministic after preprocessing. [Willard, linear-space predecessor searching](https://doi.org/10.1016/0020-0190(83)90075-3)

At a pair of boundaries $(i,j)$ keep the actual new controller and describe new memory by its differences from old memory just before $i$. One initial edit creates at most one difference. Inserting a new step or deleting an old one changes at most one further address for a single-access instruction. For each current difference at $a$, store the new value and the next old access to $a$:

* For a read, schedule that old position as a mismatch.
* For a blind store, the difference expires immediately after that store if reached along matched records. Its expiration can be tested lazily by comparing positions.
* If there is no such access it can never spoil a subsequent match.

If controllers disagree the next records cannot match. Otherwise copy the old segment up to its earliest scheduled read, or to old halt if there is none. Induction gives equal controllers and equal full records throughout that segment. A matched store writes the same value on both executions and can remove a difference. A matched load can never create one. The scheduled read really does differ if reached. Consequently this jump extends the maximal common run. It also works if initially writable input is edited. [Lean proof of the segment criterion and surviving differences](FirstReadBeforeOverwrite.lean)

To delete an old step, keep the new controller and memory and advance the old boundary. At an old store use the old predecessor value or the current difference to recover the unchanged new value. Compare it to the new reference value and refresh the entry. When deleting an old read of a differing word, reschedule that word at its next old access. To insert a new step, obtain its actual load reply from the difference map or the old predecessor-store index. Execute its true transition and refresh a difference only for its store address. Expired entries are ignored. No skip requires fetching all addresses written inside the matched segment.

## Finding an optimum without receiving its alignment

Myers's wavefront keeps the furthest reached pair on each diagonal $i-j$ at each edit cost. From the two neighboring diagonals it can consume one old or new step and then run the maximal match above. At equal $(i,j)$ the new RAM state is unique. The usual furthest-point dominance thus applies to these implicit records just as it does to two explicit strings. At a string boundary any continuing solution needs at least the remaining length difference; a furthest point already at that boundary can attain it by consuming the other string. There are $O((1+D)^2)$ frontier states before the first complete alignment. No advance past a halted new machine is permitted. Store parent choices and individual inserted records to recover the edit script. For an update to the saved index search to **both** endpoints, including any old suffix to delete. A budgeted query can stop after a specified number of edit layers and report that no complete script of that cost exists.

In the cell-probe model a frontier's local map and its copies during a query are free. Each advance or jump needs only a constant number of old-index queries. For actual word time keep two persistent balanced dictionaries, one by address for the differences and one by next mismatching read for the minimum appointment. Only the encountered address can need reinsertion or deletion. Pure-store expirations never contribute a read appointment, so they can be left stale in the address map and tested when that address is used. Each branch copies $O(\log(2+D))$ dictionary nodes per change. In the deterministic time statement one may charge $O(\log(L+T+D+2))$ per state if $D$ exceeds every polynomial in $L+T$; the simpler first display is for polynomial horizons or $D\le(L+T+2)^{O(1)}$, as throughout the applications. With $h$ named edits, initialize the $h$ differences once. The per-branch map depth becomes $O(\log(2+h+D))$.

The executable audit gives the replay code only the program, initial memory, edit and indexed **old** execution. It compares the returned script with an independent quadratic-time distance calculation and checks that applying it reconstructs every new record. On 1,821 test pairs it covers loops, indirect addresses, writes to edited inputs, and overlapping arithmetic and memory operations. A separate example has 200 mismatched time-aligned slots and insertion/deletion distance seven. [Replay audit](realigned_ram_replay_audit.py)

## A dynamic index for successive repairs

During a repair the old trace is frozen. Its positions can be live record handles instead of integers. Use an order-maintenance list and a doubly linked list of the current records, with boundary sentinels. For the furthest comparison on each diagonal, only relative old order is needed. A jump ends at an old handle and takes the controller from the adjacent record. The diagonal changes by one at an edit, independently of the length of a jump. No rank or select query on the entire mutable trace is required. A script changes only $O(D)$ live records. A successful committed patch also replaces the baseline input word. A speculative search changes neither baseline. The old addresses, old values and appointments can be indexed using colored predecessor/successor on one copy of the order for all accesses and another for writes. Each record has at most one address per copy.

Use index words large enough to address the polynomial history and to emulate the source word, with width $\Theta(\log U)$ when $U$ bounds the file, address alphabet, traces and history. For a deterministic implementation, Munro and Nekrich's Lemma 4 allows queries in $O(\lambda^3)$ and updates in $O(\log U)$ time for a polynomial address alphabet, where $U$ bounds the relevant sizes and $\lambda=\log\log(U+4)$. Order comparisons take constant time. This gives $O((1+D)^2(\lambda^3+\log(2+D))+(1+D)\log U)$ per one-word repair. Their Lemma 5 also gives $O(\lambda^3)$ for insertions and deletions, reducing the total to $O((1+D)^2(\lambda^3+\log(2+D)))$. [Munro and Nekrich, Lemmas 4–5](https://arxiv.org/pdf/1507.06866)

For an expected amortized implementation over a polynomial horizon, keep *historical* record handles in an insertion-only master order, marking deleted records inactive. Place a new record immediately before its specified old successor, using the ordinary historical predecessor pointer to that successor and insert-after. Keep a separate live order by links. Kopelowitz's insertion-only theorem gives order queries in constant time and predecessor queries on disjoint historical color classes in $O(\lambda)$, with insertions in $O(\lambda)$ expected time. Use a constant number of copies, reversing orders for successors. To filter historical results, each color has its own list of all its historical records in that order, with the currently live entries marked. Its insertion position is given by the historical colored predecessor. Empty colors and the two ends are handled separately by sentinels. Mehlhorn and Näher’s marked-list operations find an adjacent marked item, change a mark, and insert an item in $O(\lambda)$ amortized time or better. Doubly link the marked items so either direction is available (test order against the original handle). Thus deletions use just unmarking and a constant number of ordinary link changes. Historical length is bounded by the initial length plus the total number of insertions in the polynomial sequence. This argument needs only the insertion operations explicitly present in Kopelowitz's Theorem 5.1. [Kopelowitz, Theorem 5.1](https://arxiv.org/pdf/1208.3798) · [Mehlhorn and Näher, Lemma 3](https://people.mpi-inf.mpg.de/~mehlhorn/ftp/DynamicFractionalCascading.pdf)

Search to a budget $r$, patching the reference only if requested and a complete script was found. The expected amortized upper bound over the whole sequence of one-word edits is $O((1+r)^2(\lambda+\log(2+r)))$ per edit, plus initialization. Persistent dictionaries use order comparisons when keyed by a deadline. Their $O(\log(2+r))$ factor is additive to the constant number of colored predecessor queries per frontier. Read-only speculative searches and discarded far queries cause no insertions into the master order. When $r\le\log U$ this costs $O((1+r)^2\lambda)$. An amortized structure initialized on a large baseline may have initial potential. The application below pays the entire initialization by repeating independent online batches on one database.

## What a pair of edits costs after one preprocessing

Apply the static procedure to a public uniquely satisfiable butterfly template of $L$ bits. Suppose the old run takes $L\operatorname{polylog}L$ steps. Preprocessing its static index retains $L\operatorname{polylog}L$ words. If every two-bit query of a chosen verdict had distance at most $r$, search up to $r$ and default to the other verdict upon exhaustion. This would correctly decide every query in $O((1+r)^2\log\log L)$ probes. Pătraşcu's $\Omega(\log L/\log\log L)$ lower bound forces a query of that chosen verdict with $D=\Omega(\sqrt{\log L}/\log\log L)$ somewhere on the hard graphs. Apply the proof separately to the two verdicts. For the positive choice the new unique assignment can be within $O(\log L)$ coordinates of the public one. This is a static space–query consequence. A larger base time on a hard graph is a separate possible outcome if there is no uniform near-linear baseline bound. [Two-bit construction and displacement](two-bit-warm-repair-of-unique-3sat.md) · [Pătraşcu, Theorem 2 and §5](https://arxiv.org/pdf/1010.3783)

A one-bit theorem for actual SAT-to-SAT, UNSAT-to-UNSAT and opposite-verdict pairs follows by using the dynamic index on a different family. [One-bit trace lower bound with optimal realignment](one-bit-sat-pairs-after-optimal-trace-realignment.md)
