# A nonlinear algebraic successor for adaptive walks on one SAT database

There are proper ASCII 3-CNFs with $N=\Theta(d\log d)$ bits on which a single signed query asks for the outcome of $\Theta(d)$ dependent table reads. Every run from a designated starting state makes $\Theta(d)$ choices of its next read address. A fixed designated start admits $2^{\Theta(d)}$ address patterns, and the Boolean answer has multilinear degree $\Theta(d)$ in the coded row. On these same formulas the [finite-program store/reread tradeoff](one-master-for-many-ram-programs.md) still holds. When one more program joins the collection, the larger database can preserve every old raw data bit, every old state-to-state verdict and the old logical sequence of table addresses and replies as an initial segment.

One globally correct SAT program handles all these files in $O(d)=O(N/\log N)$ native steps. It computes all rows and all starting-state answers together. This gives a test for an argument that would multiply the single-query reread cost by the number of successive queries. Even a long address-dependent computation with high-degree answers on one complete input can fit the original scan clock.

## Both outcomes of a cyclic query graph in one formula

Use the packed database of the [prior construction](one-master-for-many-ram-programs.md), with $a=\Theta(\log d)$ rows, $m=d/2$ coded bits per row, and binary array $Y=XB$. A public $O(d)$-gate circuit computes the $m$ bits of any one selected row. It uses one copy of each gate. Each raw column of $X$ is coded in two identical aligned private words. Both copies constrain the same selector wire.

Give a directed graph $Q$ states and $E$ arcs. Each arc is enabled by one signed bit of the selected coded row. A deterministic binary decision state has two complementary arcs on one index. More generally any number of arcs may be enabled, and the question is whether **some finite walk** from a selected source $s$ reaches a selected target $t$. Source equal to target counts as reachable. The compiled template takes $O(d+Q+E)$ proper ternary clauses, independent of cyclic walks' lengths.

Public selectors choose exactly one row, one source, one target and a sign. One signed test replaces a private word with three padded units pinning the row, source and signed target. The target-mode flags are the conjunctions of a target flag and the respective choice of mode. Assign paired flag names ending in the digits 2 and 3. The signs differ in one ASCII bit. Each original data word has an always-true third record, so three records fit both formats with a sufficiently large fixed coefficient in the logarithmic word width. The other copy keeps the complete original data constraint. The master with no replacement is satisfiable, for example by choosing equal endpoints and positive mode. Opposite query signs force an actual load of every original marked word by each program correct on the suite, including on a writable input bank.

* For the positive mode, introduce a Boolean choice per arc and require every chosen arc to be enabled. Add one incoming port at the selected source and one outgoing port at the selected target. At each vertex at most one port in each direction is chosen, and their two ORs agree. Prefix ORs enforce at-most-one in linear total size. A simple directed path supplies these choices. Conversely, count the ports in the set reachable from $s$. Every chosen arc leaving a reachable tail has its head in that set. If $t$ were outside, the source port would give the set strictly more incoming than outgoing ports, contradicting local balance. Extra disjoint selected cycles cause no problem.
* For the negative mode, choose a set of states containing $s$ and omitting $t$. Along each enabled arc impose forward closure. This set exists exactly when $t$ is unreachable. Both verifiers can coexist. In negative mode set the positive endpoint ports and all chosen arcs to zero. In positive mode use the empty cut and omit its endpoint pins.

One-hot selectors use linear-size OR/at-most-one constraints. Public true and false anchors pad smaller clauses after simplifying repeated literals. Allocate all gates and names within $O(d+Q+E)$, use one fixed-width public record layout and pin unused names. These steps cost $\Theta((d+Q+E)\log(d+Q+E))$ bits for the padded family. A canonical generator can expose the arc list directly in the syntax: use a fixed number of public gate records per arc carrying the guard/flow and endpoint cut identifiers. Include ignorable records identifying endpoints of self-loops, e.g. an always-true clause containing the negated false anchor and the two role-specific endpoint names. A parser recovers the incidence lists, regenerates all public clauses and checks them in full. Graph syntax need not be trusted on an arbitrary SAT file. Reachability and flow/cut duality are classical. The use here combines a signed query at the solver's actual last original packet with a row-dependent graph. [Ford and Fulkerson, *Maximal Flow Through a Network*](https://doi.org/10.4153/CJM-1956-045-5)

## A linear-degree answer with exponentially many possible address patterns

Write $y\in\mathbb F_2^m$ for one coded row. Divide its first $6g$ bits, $g=\lfloor m/6\rfloor$, into groups of six. In each group form three parities of disjoint pairs of bits, denoted $c_h,p_h,q_h$. Define
$$
 H(y)=\bigoplus_{h=1}^g\bigl(p_h+c_h(p_h+q_h)\bigr)
                +\Big[\sum_{h=1}^g c_h\equiv0\pmod3\Big],\qquad
 z_j=y_j+H(y).
$$
Start $s_j$ reads $y_j$ into an accumulated parity and joins a common controller. At group $h$ read the two control bits to obtain $c_h$. According to that value, read the two bits of $p_h$ or the two bits of $q_h$, add their parity and update the selector count modulo three. At the end add the bit indicating residue zero and branch to the accepting or rejecting target. The controller has $O(m)$ states and arcs, since it carries a fixed number of bits at each specified stage. A yes/no query to the accepting target asks for $z_j$ with the selected sign.

Each run from $s_j$ reads $1+4g$ selected bit positions with repeats allowed. The $g$ independent controls give $2^g$ distinct address sequences at every start. At every row assignment, toggling either selected payload bit of any group flips $H$. At most one such bit can be $j$, so at least $2g-1$ different single table-bit edits flip $z_j$ on every input. Every coded row occurs because $B$ has full column rank. In the unique multilinear representation on the $g$ controls, the coefficient on a set of $k$ controls in the residue-zero bit is the parity of $\sum_{i\equiv0\ (3)}\binom{k}{i}$. Indeed this coefficient sums the truth values on the assignments supported on that set over $\mathbb F_2$. For $k=1,2,3$ the parities of the three residue-class sums are $(1,1,0),(1,0,1),(0,1,1)$. Pascal's recurrence then repeats these triples with period three. Thus at positive $k$ the coefficient is one exactly when $3$ does not divide $k$. Substitution of the disjoint XOR pairs preserves degree, as can also be seen by setting the second bit of every control pair to zero. The other terms have degree at most two. For $g\ge4$ the exact degree is $g-\mathbf1_{3\mid g}$. Surjectivity of the linear row map $x\mapsto xB$ gives a linear right inverse, so the degree in the raw row is the same. For a bit-level projection one may use library identifiers with a fixed decimal prefix and $a$ literal ASCII digits from $\{0,1\}$ describing the mask. Their numeric interval has size $O(10^a)=o(d)$ for $a\le(\log_2 d)/8$. Pinning its unused names takes $o(d)$ clauses. Every physical bit of a fixed signed test is then constant or a copy of one raw bit. The pointwise sensitivity bound above concerns the independent coded bits.

## The same common database and its successor

Write $\Phi(y)=y+H(y){\bf1}$. Complementing all coordinates leaves every pair parity unchanged, hence $H(y+\mathbf1)=H(y)$. Consequently $\Phi$ is a polynomial involution at each dimension.

The random-column erasure proof for the [common last load](one-master-for-many-ram-programs.md#counting-correct-continuations-including-for-programs-that-fail-elsewhere) still works. Use the chosen source $s_j$, the fixed accepting target and both signs at each tested index. For $k=\lfloor d/(2(t+1))\rfloor$ erased source columns and $\ell=\lfloor\eta k\rfloor$ tested output indices, put $u=a\ell$. The failure probability for full rank on those coordinates stays at most $1/32$ for small constant $\eta$ and sufficiently small $c_0$ in $0\le t\le c_0d$. Conditional on visible data and full rank, the tested *raw coded* coordinates $y_{ij}$ are independent uniform bits. On a fixed purported state the decoder's predicted sites and values for $z$ depend only on its visible information. Each row of correct predictions forces the corresponding $y$ entries up to its one unknown complement bit $H(y)$. On any $h$ predicted positions this costs a factor of at most $2^a$: the probability all predictions are correct is at most $2^{a-h}$ even when the common bits depend on everything erased.

As before, on an exceptional locally correct master admitting a catalog state and at least a quarter fast pairs, a full-rank trial with at least $u/16$ correct predictions occurs with probability at least $1/32$. The exceptional master fraction across $L$ programs, each with at most $2^s$ catalog states, is therefore at most
$$
                  32L2^{s+a-u/16}.
$$
Choose $c_0$ small enough that $\ell\ge64$. For $s+\log L\le cN/(t+1)$ with sufficiently small $c$, almost every single master simultaneously forces each program to miss a deadline or err on its suite, escape its state catalog at the last new data load, or reread more than $t$ distinct original columns on both signs for more than three quarters of the hard-family indices $(i,j)$. In particular $t=\lfloor\sqrt d\rfloor$ gives the same tradeoff for programs with up to a sufficiently small constant times $\sqrt d\log d$ code bits: every passing program writes $\Omega(\sqrt d)$ distinct addresses before the last new load or rereads more than $t$ old columns on both files for most pairs.

For the successor fix $a_0$ old rows, their $d_0$ raw columns and $m_0$ old coded columns. At new dimension $d'$, assume $a'\ge a_0$, the code distance exceeds $d_0$, and at least one full new group lies beyond the old coordinates. The new multiplier punctured at the first $d_0$ input columns still maps onto **all** $m'$ coded coordinates: a nonzero linear dependence would be a codeword supported on the removed positions. Give each old row its original $d_0$ raw bits, and fix its first $m_0$ coded bits to the old $y$. The remaining coded bits range uniformly. Require the added groups' selector count to be zero modulo three and their selected-payload parity to be zero. This makes the combined tail preserve *every* incoming accumulator value. New groups may start with old unused bits when $m_0$ is not divisible by six. Take $d'$ large enough to reserve two wholly fresh groups beyond them.

The following polynomial repair gives a subset with relative size exactly $2^{-a_0(d_0+m_0+3)}$ in all new raw data. In each old row make the two fresh groups' first control bits pivots. With all other controls given, a chosen pair of control parities can complete any required residue modulo three: use $(0,0),(1,0),(1,1)$ for the residues $0,1,2$. Keep the XOR of the first payload bits of $p$ and $q$ in one of these groups. Varying the two first bits by the same flip varies the selected payload parity by that flip under either selector. Use this third pivot to cancel the added groups' total selected-payload parity. Exactly one canonical setting of these three pivots works for each choice of the other coordinates in this parametrization. The residue update is a fixed finite Boolean operation at each group and has a polynomial representation over $\mathbb F_2$. A linear right inverse on the unpinned raw columns lifts the resulting row. Conditional uniformity under the surjective map gives the claimed exact subset size.

This preserves all old raw data and all old coded inputs. Every old initial or intermediate state runs through the same remaining old table addresses and replies. Embed those states by their stage, accumulated parity, carried bit and residue, and identify the two terminal states. The added tail leads to exactly the terminal the old run would have reached. It has no transitions back to old nonterminal states. Hence reachability between **every pair** of embedded old states, including intermediate states and terminals, is preserved for every old row. Physical native SAT addresses and run histories can change. Making the new exceptional fraction smaller than the displayed subset gives the successor, including extension to one further program. The subset is described by polynomial constraints.

## What an unrestricted word RAM can do

On the nonlinear family compute the $m$ packed output columns from the $d$ packed inputs with the original $O(d)$ word-XOR circuit. Each column stores all $a$ rows in one native word. Compute all rows of $H$ with a constant number of word operations per group. Two bit planes (or three one-hot masks) track all row residues modulo three in parallel. XOR the resulting word into every output column. All $am$ answers are now available in $O(d)$ total time. A solver can recognize this specific controller by regenerating its canonical public records; canonical packet recognition and a general SAT fallback are as in the [earlier packed decoder](one-master-for-many-ram-programs.md#from-states-to-stores-and-a-test-of-the-accumulation-argument).

The full intermediate-state relation also has a packed index. Store the prefix parity and the prefix selector count modulo three of all complete groups, for all rows in parallel. Crossing a sequence of complete groups translates the carried pair in $\mathbb Z_2\times\mathbb Z_3$ by the difference of its two stored prefix aggregates. At a given row, source and target, compare their logical stage positions. Simulate a possible initial read and the partial first group, apply the aggregate across the interior, then simulate the partial last group (or the last group and its terminal test). Every query now takes $O(1)$ steps after $O(d)$ packed preprocessing and storage. This covers all $aQ^2$ possible row/source/target triples. In this controller each nonterminal step increases logical stage by exactly one, so the same index answers an exact-horizon question $f^h(s)=t$ in constant time, with terminal states made absorbing. For a nonterminal target additionally require $h$ to equal the difference of stages; for a terminal require $h$ at least that difference, as well as reachability. This can be compiled with one extra late pin choosing a horizon saturated at the last stage and $O(Q)$ additional gates. Use a one-hot selector on the $O(Q)$ horizon values. Decode one-hot stage selectors to binary with a binary OR tree whose occupancy flags at right children are ORed separately at each level, using $O(Q)$ total wires. Group source or target flags by stage before decoding. Subtraction/comparison costs $O(\log Q)$ more gates. The signed output now chooses the positive condition (reach and timing) or its complement (unreachable or timing fails); the cut and flow witnesses certify the reach bit as above. A fixed wider logarithmic word holds four padded pins. This timing extension uses the equal-stage property of this particular adaptive graph.

To attain constant time after the **actual** last new data load on every master and every single-replacement file, first read one copy of every column. If the query was found in this scan, choose a different column with an intact first copy; otherwise choose any column. Reserve its second copy to load last. Read all other second copies, check their syntax and agreement, and recover every raw mask, including the mate of any earlier query. Prepare the full endpoint index and a saved query answer if one was already present. The final native load is now either the expected data word or the only signed query; both take constant time to validate and decide on the family. This choice of last word handles a query in either member of any duplicate pair.

Even for arbitrary public guarded graphs, one signed query takes $O(d+Q+E)$ steps to parse the records, build the enabled adjacency list from the requested row and search it. The unconstrained master has an immediate equal-endpoint extension. For a deterministic graph with possibly missing successors, make each undefined successor a self-loop. For a fixed row, peel indegree-zero nodes in a queue to locate the cycles, label cycle components and run depth-first searches on the reverse in-trees with cycle edges removed. A cycle target is reachable exactly when its component agrees with the source's component. A noncycle target is reachable exactly when its tree agrees and its DFS interval contains the source's. This uses $O(Q+E)$ preprocessing and $O(1)$ per ordered pair. A RAM can prepare all $a$ row indices in $O(d+a(Q+E))$ steps, at most linear in the physical bit length for this encoding. The full relation for arbitrary enabled branching includes Boolean matrix products by the usual three-layer directed graph. A single query still admits the stated scan bound.

Thus a proof against all linear-clock RAMs needs to explain why each efficient way of sharing the logical queries fails on its witnesses. The last-read counting argument continues to certify genuine rereads, but placing many adaptive visits on one logical walk does not transfer their separate reread costs to the native execution.

The finite audit exhausts all 4,608 graph/source/target triples at three vertices, including self-loops, and checks 1,664 one-bit signed pairs on physical proper formulas. It also evaluates 51,584 nonlinear walks, solves 96 physical files carrying designated nonlinear queries, and checks 4,096 extensions or canonical repairs. It compares 495,616 lifted endpoint verdicts and the sources’ logical read prefixes, and checks 184,832 packed interval lookups against direct walks. Lean checks balance soundness, walk witnesses with unrestricted multiplicities, cut equivalence, the row involution and the elementary repair identities. The proper encoding and the counting and RAM bounds are manuscript proofs. Priority for this template and successor is unestablished.
