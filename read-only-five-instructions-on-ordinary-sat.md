# Five read-only instructions cannot decide ordinary DIMACS SAT at any speed

**Theorem.** In the journal's separate-operation RAM, with fixed width coefficient $1≤ D<2$, no program with at most five stored instructions and no STORE decides all well-formed ASCII DIMACS 3-CNFs. This includes programs whose read address depends on the previous reply, programs with a separate accumulator, and programs without a running-time bound. A program may have two different terminal verdicts and any fixed immediate integers. As in the model definition, a binary numerical instruction reads at most two registers or literals, has a fixed operation and writes one register. [RAM and encoding](five-instruction-loops-on-dimacs-sat.md)

## A family with two zero low bits

Let $j$ grow, let the length in bytes be $B=128(j+1)10^j$, let $N=8B$, and let $W=w/8$ be the packed word length in bytes. The header declares three variables and $10^j$ clauses. Seven clauses on distinct variables 1, 2, 3 forbid all assignments except $(1,0,0)$. Every remaining clause is $(1∨2∨3)$ in positive DIMACS notation. Negating its first literal makes the whole formula unsatisfiable.

For $W≥4$, write the header using a word starting with `p` and padded with spaces, a word starting with ` cnf` and padded with spaces, a word starting with ` 3` and padded with spaces, and a word of spaces ending in `1`. Append $j$ ASCII zero digits and pad through a final newline in the last byte of a full word, adding a word if necessary. The decimal digits of the count are contiguous. Give each clause five full words. Its first three words start with a space, then a space or minus, then the one-digit variable name, and are padded with spaces. The fourth word starts with ` 0`; the fifth is spaces followed by a newline. Pad the file with whitespace to $B$ bytes. Any partial last RAM word has ordinary zero padding. These fields fit for all large $j$ since $W=O_D(j)$, and in the specified range $5W<128(j+1)$ for all sufficiently large $j$.

Every memory word, including zero outside the file, has both low bits zero in little-endian order. The initial metadata $N,w$ does too. The word palette $H$ has bounded cardinality as $j$ grows. The one-word alternatives affect distinct addresses in an arithmetic progression of difference five and length $10^j-7=Θ(N/w)$. A solver must read *each* such address on the positive base. The progression contains all four residues modulo four.

## Bounding the number of live probe states

Use the bounded-alphabet table-index files from the [private-probe theorem](private-probe-contexts-in-read-only-sat.md). At common length $n=Θ(2^t t^2)$, formulas for all tables $T$ and private bit strings $u$ have value $T(u)$. Only $t$ word replies depend on $u$. The private section can be translated to any of $L=Θ(n/w)$ consecutive offsets by moving aligned whitespace. The union of possible raw replies over tables and translations is a set $H$ of constant size $h$. Write $Q=2^w=O_D(n^D)$.

The following sufficient criterion will be used at several instruction phases. Suppose that separately from one first probe, every continuing turn can be represented by a code in a common set of size $M$. Its next probe address $a$ and the live state there after *either* next reply must be determined by the code and that reply. The address function of the code must be independent of the table and translation. The code may describe a state after a numerical instruction, and impossible codes may be included. If a code also describes the discarded previous reply, there is no need to retain that word after the new LOAD.

For each $a$, let $m(a)$ be the number of codes specifying address $a$. Thus $\sum_a m(a)≤ M$. Averaging over the $L$ translations produces one placement with $\sum_{j=1}^t m(a_j)≤ tM/L$: each private site ranges over $L$ distinct positions. Allow one exceptional slot at each private site for the input-independent first probe. The total number $S$ of slots is at most $t+tM/L$. The private-probe theorem gives $S=Ω(2^t/t)$ by contracting deterministic public steps and counting the resulting graphs on labeled slots. Consequently **$M=Q\operatorname{poly}(w)$ is impossible** for a decider when $D<2$. Indeed $t= Θ(\log n)$, the upper bound is $O(n^{D-1}\operatorname{polylog} n)$, and the lower bound is $Ω(n/t^3)$. A direct bound of $\operatorname{poly}(w)$ live contexts per specified private address is also impossible, with no averaging.

**Corollary for two writable registers.** With $1\le D<2$, no fixed deterministic read-only RAM with only two writable word registers decides all these formulas, even with arbitrarily many stored LOADs, numerical instructions and branches. Fixed immutable metadata are allowed. Immediately after any LOAD one register is an original reply from $H$, the other has at most $Q$ values, and the finite control has only a program-dependent constant number of possibilities. From this state follow as many computation-only steps as necessary until the next LOAD, verdict, or divergence. This determines the next probe address and its context without consulting the table again. Across LOAD destinations and control states there are only $O_P(hQ)$ codes, which the preceding criterion excludes. This argument permits arbitrary deterministic operations on the registers between LOADs. Each LOAD overwrites one register with its unmodified reply; combining a read with an arithmetic operation changes the model.

## Control and register aliases

A fixed acyclic program cannot make the required reads on the positive base. A reachable cycle and two reachable terminal verdicts require at least two binary branches. To see this, forget edge direction but retain multiplicities in the reachable graph. With $s$ instruction vertices, $b$ binary branches and two terminals there are at most $s+b$ edges on $s+2$ vertices. Connectedness and a cycle require at least $s+2$ edges. When $b=2$ the graph has at most one independent cycle. If a directed cycle exists it is simple, with bounded acyclic entry and exit paths. While the computation stays in the cycle its instruction order is fixed.

The [one-arithmetic-site theorem](read-only-ram-with-one-arithmetic-site.md) covers any number of LOADs and branches with at most one numerical instruction. Thus only one LOAD, two numerical sites and two binary branches remain. The LOAD must recur. Its address cannot be an immediate or a register constant throughout the cycle. Before the first LOAD all initial and prologue values are fixed at this length. If a numerical instruction is off the cycle, it executes at most once, in a public prefix or in an exit suffix with no fresh LOAD. Ignore suffix exits when counting possible regular probes, and include their true behavior when contracting public paths.

If at most two distinct registers vary around the cycle, two cases suffice. When the LOAD destination is different from its mutable address register, a specified address fixes the latter and the LOAD overwrites the former, leaving one live context. This includes both numerical instructions changing the same cursor. When the LOAD takes its own destination as address, immediately after a LOAD the raw reply in $H$ and at most one unrestricted register determine the entire next continuing turn. This gives $M≤ hQ$ codes in the criterion. Other registers are fixed on the cycle, including any prefix constants. With three distinct destinations, a self-addressed LOAD that is never a numerical destination only probes the previous raw reply, so its reachable addresses lie in $H$ plus at most the first address. This misses the sensitive progression. These cases cover off-cycle numerical sites as well.

The remaining form has three distinct registers. The LOAD alone writes $x← M[p]$, one numerical site alone writes the cursor $p$, and the other alone writes $y$. All three sites recur once per turn in fixed order. All other operands are fixed at this length. Choose the cut just before the LOAD. The first full cut is public. Branches may inspect any registers. The proofs using probe codes or compulsory reads ignore exits only to bound possible continuing states; the verdicts of real exits remain unrestricted.

## All operand choices

1. **The cursor update ignores old $p$.** At its instruction the numerical result is a function of $y,x$ and fixed words. The current $y$ and the raw reply $x∈H$ determine the new cursor and every other update before the next LOAD. This gives $M≤ hQ$.
2. **The cursor update reads only $p$ and fixed words.** The next address follows a public unary orbit, with $y$ as the sole accumulator. The [public-orbit equality proof](one-accumulator-scan-without-a-clock.md#any-unary-orbit-of-public-read-addresses) applies in either numerical order, with data-dependent guards, arbitrary period and transient, and every allowed numerical accumulator opcode.
3. **The cursor update uses both $p$ and $x$.** It is independent of $y$ by the arity bound. On the aligned sensitive base, addition, subtraction and multiplication preserve the two zero low bits of $p$. For every bitwise Boolean function, the two low bits of $p$ stay equal: the two old cursor bits agree and the corresponding raw bits are both zero. Such a cursor never reaches residues 1 and 2 modulo four. A move has either a public orbit or a bounded image, and a comparison yields at most two addresses. For a shift or rotation with $p$ as data, all addresses are successive same-direction shifts or rotations of the initial cursor. There are $O(w)$ such words, including any saturation or sign extension. With $x$ as data, there are $O(hw)$ shifts or rotations of words of $H$. These bounds contradict the required reads independently of the accumulator and exits.
4. **The cursor update uses both $p$ and $y$.** Call the update $F(p,y)$, permitting either operand order. If the update to $y$ ignores its old value, then at that instruction its operands are among $p,x$ and fixed words. Immediately after that update the pair of *pre-update* words $p,x$ determines the whole numerical state until the next LOAD, in either ordering. This gives $M≤ hQ$. If both numerical sites ignore $x$, the pair $p,y$ is public when one follows the continuing path without exits. Only the last raw reply can affect departure and the verdict on departure. Fix the indexing table to XOR of two private bits. On this public schedule consider the earliest possible exit over their four settings. At that point every execution so far has continued; the exit and its answer depend on at most one private bit. At least two settings with different XOR values would return the same answer. A fixed exit independent of the reply also fails. A decider must have some terminating exit, so this is a contradiction.

It remains in case 4 that $y$ is updated using both $y$ and $x$, with no third operand. If this update is bitwise, partition the bit positions by their columns in $H$ and the initial $y$. Every later $y$ stays constant on each class, giving at most $2^{2^{h+1}}$ possible words. For a same-direction shift or rotation with $y$ as data there are $O(w)$ possibilities; with $x$ as data there are $O(hw)$. Comparisons have two outputs, and a move drops an operand. For a specified private address the only other live word after the LOAD is $y$, so even $O(hw)$ possibilities contradict the private-probe theorem.

The remaining accumulator opcodes are modular addition, subtraction in either orientation and multiplication. On the aligned sensitive base the accumulator always has low pair 00. If $F$ is arithmetic, the cursor retains low pair 00. If $F$ is any bitwise function, the cursor retains two *equal* low bits. Either restriction misses compulsory addresses. A move drops an operand, and a comparison yields at most two addresses. A shift or rotation with $p$ as the data again has only $O(w)$ descendants of its initial value.

Finally consider $F$ where old $p$ supplies the shift or rotation **count** and $y$ supplies the data. Under the allowed shift conventions, old $p$ affects the output through at most $w+1$ effective counts. At the address update, encode that count, the full $y$, and the raw $x∈H$. This determines the new $p$, any later accumulator update, and the state after either next reply. The old unrestricted $p$ has been overwritten. Thus $M≤(w+1)Qh$, which violates the translated-probe criterion. This covers counts reduced modulo $w$ as well as those saturating at the word width.

These cases exhaust fixed unary and binary numerical operators and all choices of their register operands. The theorem concerns read-only programs with five stored instructions. The translated-probe step supplies the restriction $D<2$. The counting method is an application of Nečiporuk's subfunction argument.
