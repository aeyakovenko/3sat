# How many original columns must both SAT continuations reread?

Consider a binary product $Y=XB$ at side $d$. For each database, prepare one complete DIMACS master. At any marked word, replacing that word by a signed entry query produces two files differing in one ASCII bit. On a correct program's execution on the master, use its actual last previously unseen marked word. This gives a common prefix for all $2d^2$ replacements at that word. All memory is available to the program and the prefix has no time bound.

Let $Z$ encode the complete private state there, including controller, registers, the pending load address, and any overwritten input cells with their addresses and values. Work memory is initially zero. In an immutable-input implementation its original contents are external to the state. Let $s=H(Z\mid B)$ on independent uniform $X$ and uniform invertible $B$, in bits. For a uniform entry $(i,j)$, let $Q$ be the smaller, over the two tag runs, of the numbers of **distinct original inner columns of $X$** read after that load. Here a column counts on access to either physical copy of a left data packet carrying that column. Private copies can be taken entirely from the supplied state. For $1\le k\le d$,
$$
 dk\,\mathbb E\left[\frac{\binom{d-Q}{k}}{\binom d k}\right]
 \ \le\ s+d\,\mathbb E_{B,K,J}[\,k-\operatorname{rank}(B_{K,J})\,]
 \ <\ s+d .
$$
Here $K,J$ are independent uniform $k$-subsets; an impossible binomial numerator is zero. If $s\le d^2/8$ and $d$ is sufficiently large, with probability at least $1/3$ **both actual runs** reread $\Omega(d^2/(s+d))$ distinct inner columns after the last discovery. One physical old word contains data from at most one inner column. The $N=\Theta(d^2)$ packed layout preserves this distinction even at native logarithmic word width.

### The master and its genuine continuations

Use the [signed two-clause product-entry layout](literal-profiles-at-the-last-clause.md). Put the immutable-format gate constraints in public positions. Put each factor chunk in a single aligned data packet with true padding if needed, and put two identical copies at known addresses. In the compact encoding every chunk of $X$ lies within **one column**, over consecutive rows. The right factor chunks are organized by inner row. A two-pin query (a signed row flag and a column flag) can replace any one packet. Its twin still provides the missing constraint. The opposite query tag changes one ASCII low bit. The number of packets and the total length grow by only a constant factor. [Underlying compact matrix projection](compact-bit-projection-of-matrix-mismatch.md)

If the program halts before reading every marked slot on the master, opposite queries at an unread slot give the same observations. A destructive store before the first load at a marked slot also erases the distinction. A correct program therefore reaches the designated load; on both replacements the computation up through its issue is genuine. There is no input-dependent permutation to store. This differs from online placement of chunks, which could place information in the finished address map. [Earlier erasure at a common physical slot](parity-recovery-for-a-common-last-sat-word.md)

### A certificate inequality

Fix any deterministic summary $Z$ of $(X,B)$, even a nonlinear one. For each $(i,j)$ define $C_{ij}$ to be the least size of a set $U$ of inner columns such that $X_U$, $B$ and $Z$ together force $Y_{ij}$. More precisely, all $X'$ with these same columns and the same summary at this $B$ have the same output bit. The support can depend on the full $X$ and can be selected with unlimited computation. With the complete private state for $Z$, $C_{ij}\le Q_{ij}$: pin all original left columns read on the better suffix, replay from the identical state and signed query, and the verdict is forced throughout the fiber. Pinned data words include any original values read as operands. A read-modify-write that observes the old contents counts as a read.

Erase the $k$ left columns in $K$; leave the rest visible. Test all $d$ rows at the output columns in $J$. Given $B,K,J$ and the visible data, the $dk$ requested bits have entropy exactly $d\,\operatorname{rank}(B_{K,J})$. Each row is an independent uniform point in the corresponding affine image. On also supplying $Z$, let $D$ be the number of those positions whose bit is then logically forced. The remaining conditional entropy is at most $dk-\mathbb E D$, since for each observation the positions and values of all forced bits are determined. Conditioning additionally on $Z$ can reduce entropy by at most $H(Z\mid B)$. On the other hand each minimal support of size $c$ avoids the erased columns with probability $\binom{d-c}{k}/\binom d k$. The tested output indices are chosen independently. This proves the displayed weak inequality with $C$ in place of $Q$, hence also with $Q$. For a fixed possibly singular $B$ the same formula holds with its own expected minor deficiency and $H(Z\mid B=b)$.

For random invertible $B$, each nonzero vector supported on $J$ maps to a uniform nonzero vector. The expected number of nonzero vectors in the minor kernel is $(2^k-1)(2^{d-k}-1)/(2^d-1)<1$. Nullity is bounded above by this count on each minor. For the probability claim take $k=\lceil2(s+d)/d\rceil$. When $Q\le d/(4k)$, the union bound gives avoidance probability at least $3/4$. Consequently the fast fraction is at most $2/3$. This uses the full values of the old words and permits arbitrary subsequent computation and addresses.

A smaller summary can replace the full state. It must fix the initial controller and pending address. Suppose each inherited word a suffix actually uses, read before its first suffix write, has its *value* certified by at most $g$ original columns on the current $(B,Z)$ fiber. Count unmodified input on the same terms, with $g\ge1$. Pin the union of these supports on one true path. Induction on the reads reproduces the whole transcript, including its addresses and final answer, although support sets may differ between the two paths. Thus $C_{ij}$ is at most $g$ times the number of distinct inherited words on either suffix. This version permits an arbitrarily large store of separately column-dependent transformations.

The resource inequality is distributional. A solver can copy the data into private memory before the cut, which accounts for $\Theta(d^2)$ bits of conditional information. The [coded rectangular version](one-master-for-many-ram-programs.md) gives a single-input alternative for exponentially many programs and a method of extending an earlier database. Earlier systematic data-structure results use conditional entropy after revealing partial inputs; here the observations are the continuations of complete SAT files.
