# A read-only scan with one accumulator cannot decide SAT at any speed

Consider the [separate-operation RAM](five-instruction-loops-on-dimacs-sat.md) with $w=\Theta(\log N)$-bit words, $Q=2^w$, a fixed finite program and no stores. Suppose its recurrent control path, when exits are ignored, executes one original load $x\gets M[p]$, one cursor update $p\gets p+d\pmod Q$ for a fixed program integer $d$, and one numerical instruction updating an accumulator $y$. Their order is fixed and each occurs once per iteration. The accumulator operation is at most binary, with fixed operand roles among $y,x,p$, literals and registers fixed throughout the scan. Guards can compare the actual registers with one another or with literals and exit at any of the fixed sites. A bounded acyclic prologue and bounded acyclic exit paths are allowed. **No such program decides ordinary DIMACS SAT, even with unrestricted time.**

This includes the no-STORE five-slot allocation of one LOAD, two numerical instructions and two branches when the numerical sites and loop have these roles. It leaves other cursor updates and other five-slot allocations open.

## One lap determines all future laps

Use the [two-party equality formulas](equality-communication-for-five-slot-sat.md). Alice and Bob have $k$ bits each. Their halves of the formula pin the same $k$ variables to their respective strings, using fixed-width fields and a reserved sign byte. The formula is satisfiable precisely when the strings agree. Its $N=\Theta(k\log(k+1))$ bits occupy a public range of addresses. Give Alice a contiguous cyclic interval holding her half and Bob its complement, including the public zero words. They can exchange a straddling word if necessary. A bounded prologue, including adaptive reads and its final registers, costs $O_P(w)$ bits to simulate together. Hence the scan's initial registers and start address are known to both parties, including a start address that depends on the input.

Cut each iteration just before its LOAD, so the previous $x$ is overwritten before use in the iteration. A fixed number of instructions from the entry point to the first such cut can be simulated directly. A lap visits $L=Q/\gcd(d,Q)$ addresses for $d\ne0$, and $L=1$ for $d=0$. The address order is the same on every lap. There are $O(1+|d|)$ consecutive ownership runs in a lap. An ownership change must start within $|d|$ addresses of one of the two boundaries, and no address recurs in one lap. Empty intervals and a split at the beginning of the lap only lower the count or add one run.

If guards always continue, every ownership run defines a total function on its entering accumulator. Its owner knows the word from each LOAD and both the pre-update and post-update cursor values. The run's sequence of nonaccumulator operands $t_1,\ldots,t_s$ can therefore be computed privately. The following descriptions use $O(w^2)$ bits and determine the run's final $y$ for *every* entering $y$.

* For addition, subtraction in either order and multiplication with one accumulator operand, each update is affine modulo $Q$. Composition is specified by two words. Moves are copies, and an instruction independent of the incoming accumulator just overwrites it with a known final word. If both its operands are $y$, the computation is the public $s$-fold iterate of the fixed unary map $z\mapsto f(z,z)$. The same reasoning handles a unary instruction on $y$ alone.
* With one operand $y$, a bitwise truth table acts separately on each bit. Its composition is determined by its outputs on zero and the all-one word. This includes every binary Boolean truth table, in either operand orientation.
* If $y$ is the data operand of a fixed left shift, logical right shift or arithmetic right shift, compose the effective shift distances by addition, capping at $w$ (or $w-1$ for sign propagation). The per-instruction effective count can be reduced modulo the width or saturated according to the ISA. For a fixed rotation, add the distances modulo $w$. If $y$ instead supplies the count, the first update has at most $w+1$ possible outputs, indexed by the first effective count. The owner sends one final word for each possible count after privately composing the rest of the run. Both parties know how to extract that index from the entering $y$.
* A numerical comparison outputs zero or one. Send its first external operand and the two final words for those first outcomes. The fixed operand roles and comparison type give the first outcome from the entering $y$, including signed or unsigned order. Branch instructions can perform different comparisons from the numerical site. They do not enter this transfer map because the transfer assumes continuation.

These cases use a single fixed update site. Two different sites mixing arithmetic, bits and shifts in successive iterations need not have transfers of these forms.

Both parties exchange all ownership-run descriptions for a *single* lap. Then both can compute the accumulator at every ownership boundary on every hypothetical lap, without further messages. For the actual termination test, each party privately replays the guards inside all its own runs, starting each run at its hypothetical entering state, and finds its earliest exit ordered by lap, iteration and instruction position. It suffices to inspect $Q$ laps. If all continued, among the first $Q+1$ lap boundaries two would have the same $y$. The cursor, program counter and fixed registers agree there and the old raw word is dead. Determinism would repeat those entire laps forever. This conclusion also covers $d=0$.

Each owner transmits its earliest exit index or a sentinel. This takes $O_P(w)$ bits since $L\le Q$ and there are a fixed number of instructions per iteration. The earlier exit is exactly the one taken by the machine. Its owner can transmit the branch destination and live registers; the bounded suffix can be simulated by exchanging any requested word and the final answer. Input-dependent guards are thus handled without encoding a potentially large set of exceptional accumulator values in a transfer map.

The total communication is $O_P((1+|d|)w^2)$ bits over all inputs, irrespective of the number of real laps. A total SAT decider would give a deterministic equality protocol of this cost. Two distinct accepting diagonal pairs cannot have the same protocol transcript, since the corresponding mixed pair would follow it and be accepted. Equality therefore requires at least $k$ communicated bits in the worst case, while $w=O(\log k)$. The contradiction gives the stated no-clock exclusion for this scan class.

## Any unary orbit of public read addresses

The same no-clock exclusion holds when the cursor evolves by **any** fixed-on-input-length rule $p\gets F(p)$ with no dependence on $x$ or $y$. The function may depend on register values fixed by a bounded prologue. To remove the bound on ownership changes for a fixed physical partition, place the paired pins after the scan order has been determined. The resulting test family can depend on the program. [Related construction using a common expander-based family for many cyclic orders](orbit-orders-and-parity-pinned-sat.md)

For a parameter $K$ prepare $2K$ fixed-length clause records of the form $(\pm t\lor a\lor b)$ and a public proper-clause gadget forcing $a,b$ false. Reserve space for a sign and a right-aligned decimal identifier long enough for $O(K)$ names. Use $\Theta((\log(K+2))^2)$ bytes per record, with the unused space filled by whitespace. This gives $N=\Theta(K\log^2(K+2))$ encoded bits and $w=O(\log(K+2))$. In particular no packed input word contains two private sign positions. The header and total length are fixed in advance, and unused declared names are permitted. Fill every provisional record with a positive pin on the same fresh dummy variable.

Execute the bounded prologue on this provisional file, including any partial iteration up to the first cut just before a LOAD. Freeze the complete records containing any byte read during that execution. At most $O_P(1)$ records are frozen because each record is longer than a word. Their contents stay as independent satisfiable positive dummy pins. The rest of the construction, including the private signs, changes no word observed on the prologue, so the same prologue and post-prologue state occur on every resulting file. If the prologue halts, an equal-length family with both answers and unchanged observed bytes already contradicts correctness. If necessary freeze one further dummy record to leave an even number $2k=2K-O_P(1)$ of editable signs.

The public unary orbit starting at this state consists of a transient followed by a cycle. Together the transient and one cycle contain at most $Q$ addresses, all distinct. Sort the $2k$ editable sign positions by the first visit to their containing word. Append the unvisited positions in any fixed order. Pair the $i$th sign with the $(i+k)$th sign for $1\le i\le k$. Give these two records the same fresh name, distinct for each pair. Use Alice's private string for the first $k$ signs and Bob's for the last $k$, with the same convention for both. All nonsign bytes are now public. This gives precisely equality on $k$ bits. The owner of a physical word depends only on its private sign, if any. Within the transient followed by a single lap the visited signs consist of Alice's prefix followed by Bob's suffix, possibly with one side empty. Each phase therefore has at most two consecutive ownership runs, because all intervening public words can be allocated to either owner. The same runs repeat on every lap. An arbitrary off-orbit suffix read is still simulated directly from its sign owner.

Exchange the $O(w^2)$ descriptions of those runs, including the one-time transient, and compute the actual earliest exit as above. The protocol now uses $O_P(w^2)$ bits regardless of the shape of $F$, its period, or the physical stride of any step. Since $k=\Theta(K)$, equality contradicts this bound for sufficiently large $K$. The guards may still make their exit decisions from input data. Permitting input data to choose the next cursor address changes the order of the sign words and is outside this proof.
