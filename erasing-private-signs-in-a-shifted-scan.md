# A shifted ascending scan forgets two SAT signs before it can compare them

Fix a word RAM whose recurrent data instructions, in completed iterations, read $x=M[p]$, advance $p$ by one modulo $Q=2^w$, and write $M[x]\gets p$ using the advanced cursor. It starts its first scan at zero on the original memory. The only changing data registers are the cursor and the loaded word. Inside a continuing iteration its register comparisons may exit the loop. Upon exit its verdict can use its currently available registers. This covers two branch sites and three data sites all on one fixed cycle with terminal exits. **No such program decides ordinary DIMACS SAT at any speed.** Even permitting a different register-only exit rule at each position of the first lap does not help.

The [long transient](shifted-crossed-scan-on-padded-dimacs.md) prevents a general bound on the number of laps as a function of the initial memory image size alone. Here the entire memories of four inputs, including the original input words, agree by the first lap boundary. Before then, the only private register observations depend on one sign at a time.

## Two private signs in ordinary files

At arbitrarily large widths divisible by sixteen let $m=\lfloor 2^w/(2w)\rfloor$ and $n=mw$. The model gives $w=16\lceil\log_2(n+2)/16\rceil$. Write $W=w/8$ for the word length in bytes and take it larger than the public header and short forcing prefix below. Words are little-endian. Choose two bits $a,b$, with 1 designating a negative sign. The nonempty prefix of the file has the following layout. Fill the remaining packed words of the file with ASCII spaces and the rest of RAM with zero.

| Address | Bytes in the word |
| --- | --- |
| 0 | Header `p cnf 7 12`, newline, eight public clauses forcing variables 2 and 3 false, then spaces |
| 1 | Public word $B_1$ of spaces ending in newline |
| 2 | $U_a$, all spaces except possibly a minus in the last byte |
| 3 | `1 2 3 0`, newline, then spaces |
| 4 | Public word $B_2$ of spaces with newline as its first and last byte |
| 5 | $U_b$ |
| 6 | `1 2 3 0`, newline, then spaces |
| 7 | Fixed $U_0$ |
| 8 | `4 2 3 0`, newline, then spaces |
| 9 | Fixed $U_1$ |
| 10 | `5 2 3 0`, newline, then spaces |

For the eight public clauses use $(\neg x_i\lor \pm x_6\lor\pm x_7)$ with all four sign pairs at $i=2,3$. The two private clauses now force the same value of $x_1$ precisely when $a=b$. The final two clauses can always be satisfied by choices of $x_4,x_5$. Thus the four valid proper 3-CNF files have the equality labels. Every clause has three different variables. In this grammar whitespace may separate tokens. A word whose final byte is a minus has that byte immediately before the next digit.

Both anchors $B_1,B_2$ are unique original memory values, each occurring at its indicated address only. Their high bytes are 10. All the physical input words have a nonzero high byte of at least 10; $m$ is eventually smaller than all of them, as $m/Q\le1/(2w)$. The four distinguished addresses $B_1,B_2,U_0,U_1$ are mutually distinct and exceed the input range.

## Following every read in the first lap

At a physical input address the first ascending lap reads the original word, by induction. All preceding input reads yield values greater than $m$, and hence their stores go outside the input. Before any such destination is read, the scan at 7 and at 9 has already overwritten the respective possible scratch writes made by the private reads. An additional write of the same public word later in the physical input is harmless. At the end of the physical input the only possible differences among the four entire memories are at the original addresses 2 and 5.

From this point there is no private observation during the lap, since neither address will be read again. The remaining task is to check that they are overwritten before the lap ends. Put $(i,B)=(2,B_1)$ or $(5,B_2)$. The scan at $i-1$ saw $B$ and wrote $i$ at address $B$. No further original input word equals $B$. Among the remaining scratch reads at addresses $p<B$, a value $B$ cannot be fetched. Those addresses originally contain zero, and a noninitial $B$ could only be a payload from the step $B-1$. There is no address strictly between $B-1$ and $B$ in this scan. Thus the read at $B$ returns $i$ and its store overwrites the private cell with the public value $B+1$. Once both rewrites have occurred all four entire memories agree. The cursor is public, and the loaded register at the end of the lap is also common.

## Earliest possible exit

Follow the continuing loop hypothetically through the complete lap in each of the four runs, recording all exit opportunities. At any one opportunity the available registers depend on at most one of the bits $a,b$. This includes the interval between a private load and the next load, irrespective of the cursor increment or guard placement. If there is an exit during the first lap on any input, choose the earliest exit across all four inputs. Flip the bit that cannot influence the registers at that opportunity. The second input has exactly the same branch outcome and register-only exit behavior. It had no earlier exit by the choice of time. The two true SAT labels differ, giving a contradiction. If all four executions complete the lap, the entire machine states agree and all subsequent behavior is identical. A common divergent continuation fails correctness as well.

The [Lean proof](ShiftedScanExitLists.lean) checks the decision-list inference including a possibly divergent continuation. The memory and DIMACS arguments above are manuscript proofs. The [finite integration audit](erased_shifted_signs_audit.py) checks all four labels with full assignment enumeration at four word widths and simulates every read and the complete boundary memory with the existing exact run-length engine. It compares the first-lap read functions except at 2 and 5, proves equality of the observed final memories in these finite tests, and checks the overwrite values. The argument does not assume a short transient on arbitrary formulas or impose a clock on the solver.

## Arbitrary register computation between the compulsory scans

The same construction excludes a controller with any fixed number of word registers and arbitrary register computation and branching, provided its input/work-memory access sequence along a continuing computation is still exactly the specified compulsory scan. A register can remember an earlier sign. Use two lists of signs, the first for Alice and the second for Bob, so that after Alice's list the register state would have to distinguish $2^k$ possibilities. Local computation and halting time are unbounded.

For a width $W=w/8$ in bytes choose $k=2^{\lfloor W/4\rfloor}$. Use public clauses forcing variables 1 and 2 false with the four sign choices on 3 and 4, as before. For each $j=1,\ldots,k$, use a private clause $(\pm x_{6+j}\lor x_1\lor x_2)$ in Alice's list and one on the same name in Bob's. Include the two public decoys on distinct fresh names 5 and 6 after the two lists. The formula is satisfiable exactly when the two $k$-bit strings are equal. With $2k+10$ clauses and $k+6$ variables, the header and eight fixed forcing clauses fit in one word for all sufficiently large widths. The decimal name of the largest private variable requires fewer than $W/8$ characters for all sufficiently large $W$, so every clause suffix fits in one word ending in space.

In increasing physical address order, place the initial public prefix, then one triple of words per private occurrence: its anchor, its $U_0$ or $U_1$ sign word, and its clause suffix. Then place the two fixed sign words with their decoy suffixes. The anchors are distinct words made entirely of whitespace, each ending in a newline. For example encode the occurrence number in the low $1+\log_2 k$ byte positions using spaces and tabs, and fill the remaining unused positions with spaces. If desired newlines can replace tabs in these low positions, since arbitrary whitespace is permitted between clauses. No other constructed word ends in newline. Each anchor is unique, exceeds $m$, and is disjoint from the two sign hubs. Append ordinary spaces to give exactly $m=\lfloor Q/(2w)\rfloor$ physical words. Since $6k+O(1)<m$ for all large $w$, the construction fits at the same width-consistent lengths.

On the hypothetical uninterrupted run the preceding proof now applies to every sign-source address. Up to the end of physical input, every word is read in original form. After the two decoy reads, the stored data at either sign hub are public. The remaining original differences are at the private input cells alone. Each is erased at the visit to its own anchor before the end of the first lap, independently of the others. Therefore all observations after the physical input and the memory at the lap boundary are public regardless of controller decisions to continue. Inside the physical input, all private observations from Alice precede every private observation from Bob.

Alice locally simulates through the cut before Bob's list, sending either the early verdict or the register words, finite-control location and an indicator of continuation. Bob has all information needed to compute his remaining read replies. In particular he does not need the values Alice may have written at the two sign hubs, since there is no read there before the fixed decoys. After the lap boundary he can compute the common complete memory by running the public scan on a fixed dummy pair of lists, then initialize the continuation with the actual registers he has computed. If the proposed program decides SAT, Bob gets the equality verdict. Neither party transmits its computation time. At the cut two different Alice strings must yield different messages, since Bob can choose the first string as his own and distinguish the two. The message thus requires $k$ bits in the worst case. The $O_P(w)$ bits available from any fixed register controller are insufficient. More generally this construction forces $\Omega(2^{w/32})$ bits of transferable controller state on the prescribed schedule. This is a restriction on how registers and memory interact in the scan. An unrestricted RAM can choose different reads or stores.
