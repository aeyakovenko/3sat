# Shared variables in a SAT patch family can be evaluated together

Let $N$ be the encoded bit length of a proper ternary DIMACS file, $h=\lfloor\log_2(N+2)\rfloor$, and let $K$ be the largest integer satisfying

$$
                  2^K\lceil\log_2(K+2)\rceil\le h^3 .
$$

There is one globally correct deterministic logarithmic-word RAM program that decides the file in $O(N)$ steps if, in **each biconnected block separately** of its primal variable graph, deletion of at most $K$ vertices leaves a forest. The program finds these sets itself. On positive files it can return a satisfying bit per occurring variable in the same time. The local bound allows $K=(3-o(1))\log_2\log_2 N$. A block may contain arbitrarily many clauses, and different blocks may use different shared variables.

For the proposed finite exhaustion this permits a concrete countertest. Start with any forest of local variables. A patch on an edge $xy$ may choose a signed clause on $x,y$ and any of $K$ common variables. Other patches may use one local variable or only common variables. Their choices can be correlated arbitrarily or generated in response to earlier computations. All resulting files satisfy the theorem if the printed local edges stay in the forest. Two identifiers ending in ASCII 2 and 3 with the same decimal prefix permit an actual one-bit input patch to choose different common variables. Sorting the patches into separate copies or providing their construction history is unnecessary. This gives an upper bound on a globally correct program's actual native time on every output of this construction.

## Logical and physical costs

Normalize repeated clauses and numeric variable identifiers. A decimal trie on significant digits, sorting the three signed indices locally, and a constant number of counting-sort passes on dense indices takes $O(N)$ word steps, even with very long names. Build the simple primal graph by grouping duplicate edges and assign each proper clause to the block of its triangle. Root the block-cut forest. A child block sends two Boolean values indicating which settings of its parent articulation variable extend to a model. At each articulation take the intersection of all child messages. A block therefore receives at most one unary domain per variable. Reconstructing a model uses a top-down pass choosing a consistent value at each articulation. [Normalization, biconnected blocks and assignment conventions](one-or-two-old-variables-in-clause-batches.md) · [Tarjan's graph algorithm](https://doi.org/10.1137/0201010)

Write $m$ for the number of distinct proper clauses. We use $m=O(1+N/h)$ even if the original file contains many repeated short names or whitespace. There are $O(10^{3d})$ signed triples whose normalized names have at most $d$ decimal digits. Consequently $m\log(m+2)=O(N)$ by charging a long token in at least half of the distinct clauses. If $m\le\sqrt N$ the desired bound is immediate, and otherwise $\log m$ is comparable to $h$. The sum of the numbers of clauses, vertices and edges of the individual blocks is $O(m)$, counting articulation occurrences in all their blocks.

Run Iwata's feedback vertex set kernelization on each block with cap $K$. It takes $O((K+1)^4(e+1))$ time on a block with $e$ edges. The kernel has at most $2K^2+K$ vertices and $4K^2$ edges, or reports that the cap fails. The algorithm uses graph traversals and half-integral augmentations. Its array indices, counters and doubled half-integral values take $O(\log N)$ bits at this parameter. The solution can be lifted without rerunning a decision oracle on individual vertices. Record the deleted vertices whose deletion decreased the budget. Retain the original names for all surviving vertices. Degree-two suppression is reversed by subdividing the replacement edge. Deleting an endpoint of that edge also suffices. Removing low-degree vertices or discarding redundant parallel edges needs no additional deletion. In the cycle-cover rule a solution of the modified graph either contains its center or contains the entire set joined to the center by double edges. The removed edges are then harmless, as in the reverse direction of Lemma 3. Check the resulting deletion set and the remaining forest directly. [Iwata, Sections 2–5 and Lemma 3](https://drops.dagstuhl.de/storage/00lipics/lipics-vol080-icalp2017/LIPIcs.ICALP.2017.68/LIPIcs.ICALP.2017.68.pdf)

Many blocks share the cost of solving small kernels. Locally number each kernel, including multiplicities, and use a fixed-width edge-list key of $O((K+1)^2\log(K+2))$ bits with its residual budget. Once per input scale enumerate all keys and solve each well-formed kernel by enumeration of deleted-vertex subsets and checking the forest condition for multigraphs. Store one solution if present. The total time is $2^{O((K+1)^2\log(K+2))}=N^{o(1)}$. Even charging a polynomial in $K$ per block for initializing keys or recovering labels fits $O(N)$ at this cap. On a failed cap the globally correct program can invoke general SAT search. The empty clause set is handled directly.

## A binary tree calculation inside a block

Let $Z$ be the recovered vertex set in one block and locally index its variables by $1,\ldots,k$, $k\le K$. Fix a valuation $z$ of $Z$ temporarily. Each clause has at most two variables outside $Z$, since a triple of such variables would form a triangle in the residual forest. Combine the clauses on each local forest edge into a binary relation, and those on a single local vertex into its unary domain. All-core clauses give Boolean factors directly. A vertex-to-parent message gives the set of parent values compatible with at least one available child value and the edge relation. At each vertex intersect its unary domain with incoming messages. At a component root test whether its domain is nonempty. All components and all-core factors must pass. To compute the outgoing block message, perform the calculation for the two possible fixed values of its parent articulation, treating this pin as another unary factor, including when the parent lies in $Z$.

This calculation is a rooted binary **tree** with $O(m_B+1)$ nodes for a block of $m_B$ clauses, after replacing intersections of many children by binary intersections and joining its components under one tree. Each relation or child message is consumed just once. States are finite: an edge relation is four bits, a unary message two bits, and a test one bit. A clause leaf is specified by a fixed local pattern and at most three signed indices into $Z$. A child-block constraint is represented by its resulting two-bit domain. Every node thus has a label of $O(\log(K+2))$ bits, independent of the total number of variable names. A direct bit-parallel evaluation stores one word sequence for each possible state, marking precisely the shared valuations producing that state. Fixed-arity transitions cost $O(1+\lceil2^k/h\rceil)$ word steps. This simpler method by itself gives the linear deadline when $2^K=O(h^2)$.

## Grouping local operations before scanning the valuations

Choose $B=\max(1,\lfloor c h/\lceil\log_2(K+2)\rceil\rfloor)$ for a sufficiently small absolute $c>0$. Use the linear-time binary tree covering: a tree of $s$ nodes can be split into $O(1+s/B)$ vertex-disjoint connected pieces of at most $2B$ nodes, each with at most two child connections apart from its one parent connection. This is the binary-tree covering of Farzan and Munro, in the disjoint formulation of Munro and Wild's Lemma 4. For a tree with at most $B$ nodes use a single piece. [Tree covering for binary trees, Lemma 4](https://livrepository.liverpool.ac.uk/3051855/1/1903.02533v1.pdf) · [Farzan and Munro](https://cs.uwaterloo.ca/research/tr/2008/CS-2008-11.pdf)

Encode a piece by a preorder description including arity, node labels and up to two named holes. Shape, holes, labels, header and padding altogether use $O(B\log(K+2)+\log h)$ bits, at most $h/4$ at sufficiently large scales. The indices refer to this block's local enumeration of $Z$. For all keys, all $2^K$ assignments on those positions, and each tuple of hole states, evaluate the piece by direct scalar computation. Store its resulting state as a bit vector indexed by the valuation, one vector for each state and hole tuple. Unused shared positions can be ignored or repeated. For pieces without holes also store whether any valuation passes its scalar final test and one such valuation. The per-scale table construction takes $2^{h/4+K}\operatorname{poly}(h)=O(N)$ native operations, including memory initialization. Piece encodings can be assembled by shifts, reserving zero padding by length so that small keys need time proportional only to their node counts apart from a constant header.

Work upwards through the tree of pieces. For each permitted tuple of child states intersect the corresponding child valuation masks with the tabulated mask for the output state, then take the union across tuples. There are only constantly many states and holes. The masks use $O(1+2^K/h)$ words apiece. For blocks with more than $B$ nodes, the total number of pieces is $O(m/B)$. On smaller trees the one-piece scalar existence answer is available by a single lookup, without scanning a valuation mask. This distinction matters when the file contains many small blocks. All other construction and traversal work totals $O(N)$, giving the additional evaluation cost

$$
 O\!\left(m+\frac{m}{B}\left(1+\frac{2^K}{h}\right)\right)=O(N)
$$

by the definition of $K$. A root valuation can be recovered from a nonempty mask or the one-piece table. After selecting the global root values, rerun each block's scalar forest calculation once under a compatible shared valuation and follow the stored child choices. Records for both parent settings can store a valuation at the first pass. The recovered assignment is checkable against all original clauses in $O(N)$ time.

## Polynomial deadlines and a full-SAT control

A separate globally correct procedure can compute a minimum feedback vertex set in each block by exact branching and then run the scalar forest calculation once for each valuation. If $\tau$ is the largest minimum feedback vertex set over the blocks, this takes $O(N+m\,3.46^\tau)$ using the deterministic exact FVS algorithm of Iwata and Kobayashi. Reading adjacency lists and the smaller $2^\tau$ term are included. One may run increasing parameter caps, whose single-exponential bounds sum geometrically. The search algorithm tracks chosen vertices. For the explicitly polynomial clocks, stop the specialized procedure at the deadline and use standard general SAT search if necessary. Dovetailing with the packed linear procedure preserves its faster guarantee. In particular a sequence forcing every globally correct program beyond $N^i$, for $i=2$ or $3$, cannot be established within a promise $m\,3.46^\tau=O(N^i)$. [Iwata and Kobayashi, *Improved Analysis of Highest-Degree Branching for Feedback Vertex Set*](https://arxiv.org/abs/1905.12233)

There is a complementary parsimonious linear reduction to files with arbitrarily large local feedback vertex set. Normalize a source with $m$ distinct proper triples. Give each source occurrence its own variable and retain its original signed clause. Link occurrences of each source variable in a chain of binary implications in both directions, padding each binary clause with a common false $W$. Three anchors $U,V,W$ are pinned to $(1,1,0)$ by forbidding the other seven triples with proper clauses. Add the satisfied clause $(U,V,x)$ for each occurrence variable $x$. All occurrence vertices and all anchors lie in one biconnected block: every occurrence is joined to both $U,V$, as is $W$, and the anchors themselves form a triangle. The $m$ actual source clauses form $m$ vertex-disjoint triangles, forcing the block's feedback vertex set to have size at least $m$. There are $O(m+1)$ variables and clauses, so the printed length and the deterministic reduction time are $O(N)$ by the normalization bound. Counting assignments on occurring variables, occurrence copies and the anchor values extend each satisfying source assignment uniquely. If declared unused variable names are counted as additional free bits, preserve their number separately. The reduction and counts here use the occurring-variable convention. A large feedback set alone gives no time lower bound. A proof that these particular unrestricted instances exceed a deadline would apply to full SAT, while the small shared-variable patch families have the globally correct fast program proved above.

This calculation uses classical feedback-set conditioning, finite-state tree evaluation and small-table precomputation. The contribution here is the bit-length accounting for independent blocks and the resulting limit on the proposed patch successor. The finite audit compares complete shared-valuation masks to brute force on 256 independently parsed files (207 satisfiable), checks all 1,024 adjacent physical one-bit pairs, and compares another 180 seeded forests. On 11 high-interaction examples it verifies biconnectivity after each possible vertex deletion, the disjoint triangles, and the exact source-to-target correspondence of satisfying assignments, including an unsatisfiable example.
