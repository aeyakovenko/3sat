# A computable successor search that keeps the old SAT clauses

Fix $d\in\{1,2,3\}$ and the class of deterministic logarithmic-word RAMs with unrestricted workspace and fixed positive integer width coefficients, allowing the simulator to choose a sufficiently large one. Start with **any fixed satisfiable dense canonical proper 3-CNF of maximum variable occurrence four**. There is a partial computable exhaustion with the following properties.

* At stage $j$ it adds all valid RAM descriptions of at most $j$ bits to its cumulative list and raises the time multiplier to $j$. An output includes $j$ consecutive byte lengths. At each length there is a $j$-dimensional cube of dense proper 3-CNFs, obtained by flipping independent, specified ASCII bits. All corners are SAT, all have maximum occurrence four, and **every** corner retains all clauses of the previous designated SAT corner, with their original names. Every old model extends to a new model at each corner.
* For each listed machine, the output supplies either an actual wrong halt on a valid input, or the fact that it fails to return by $jN^d$ on **every** corner at all $j$ lengths. Here $N$ is the actual encoded bit length of the corner. Errors anywhere can be included in a finite certificate. Every globally sound machine, even one that can abstain by looping, must pass the second test. Choose one corner at the first length as the next seed.
* **Every stage terminates if and only if there is no unrestricted deterministic $O(n^d)$ SAT algorithm.** This equivalence holds separately for each of the three exponents. In particular, under the lower-bound hypothesis the search produces a single recursively enumerable chain on which every fixed correct solver eventually exceeds every fixed time multiplier. Since the minimum output length strictly increases, the designated sequence of files is also a recursive set. The search time at each stage has no stated complexity bound.

This moves the finite test from a union of unrelated witnesses to one common block containing the preceding positive seed. The budget here charges the full machine description, including literals and its width coefficient. A one-bit increase in that budget can introduce completely different programs. The proof below does not show that the next search succeeds unconditionally. [Earlier finite-list criterion](bounded-ram-programs-and-separate-sat-witnesses.md) · [Lynch's original recursive complexity-core theorem](https://groups.csail.mit.edu/tds/papers/Lynch/jacm75.pdf) · [Orponen, Ko, Schöning and Watanabe on partial programs and instance complexity](https://helda.helsinki.fi/server/api/core/bitstreams/6f664207-1169-4984-a33c-60aa7e1715bd/content)

## Extending a fixed satisfiable seed

Let the old seed $B$ use exactly the names $1,\ldots,v$. Choose the least multiple of ten $a\ge v+3$. Cover the new names $v+1,\ldots,a$ by positive triples on consecutive new names, one for each possible three-name window. There are between three and twelve names in this gap. They all occur, each at most three times, and assigning them all true satisfies the gap. Translate **every** name of the fresh degree-four parity cube by $a$, preserving signs. All clauses of $B$, the gap and the translated cube occupy separate variable intervals. Sorting puts the entire old clause body first and leaves the gap and new body separate. The translated selector alternatives still end in decimal `2` and `3` because $10\mid a$. Each chosen digit remains one physical bit, its position fixed throughout the cube at the given length. The widths of the two alternative names agree even at a decimal carry. Additional fresh, disjoint triples realize the exact target lengths by choosing signs. Their variables can always be assigned to satisfy them. [Construction on unrestricted source formulas and exact degree-four padding](physical-selector-parity-cubes.md)

For fixed seed, dimension and finite set of width coefficients, the new templates on an $n$-bit source have $O(n)$ bits. More explicitly, normalize the sources, which leaves $O(n/\log n)$ clauses. The new names after translation have $O(\log n)$ digits for all sufficiently large $n$. The old file has constant length at this stage. One can choose a sufficiently large fixed $K$ and pad to byte lengths $K(n/8)+i$, $0\le i<j$. The number of fresh padding rows is $O(n/\log n)$ since the distinct names in $u$ rows take $\Omega(u\log(u+2))$ digits. Generate and sort the numerical rows, and use the packed decimal builder to realize a corner in $O(1+n/\log(n+2))$ native time for fixed $j,B$. Translation cannot decrease the number of bytes separating distinct selector sites. The filler count can be fixed large enough for the indicated word coefficients and target sizes. All previous assignments on $B$ extend whenever the fresh formula is satisfiable, because they impose no conditions on any of the new variables.

## Why a search over finite certificates suffices

A program is sound if every actual verdict on a well-formed file is right. One can enumerate all its violations by interleaving bounded simulations on all valid files and deciding their labels offline by assignment enumeration. Only an observed wrong halt retires a program; silence never retires it. All statements on a proposed finite block can be tested with finite simulation to the actual prescribed deadlines. A certificate can therefore list either one concrete error (including a sufficient run limit), or the timeouts on all of its corners, independently for each member of the finite list. A class containing both constant-answer programs presents no problem. Both can be retired with evidence. [Lean statement of the certificate equivalence](NestedTimedCores.lean)

Assume no deterministic $O(n^d)$ SAT solver exists, and fix the current seed and finite list. For each arbitrary source $F$, take **two copies of $F$** as the two logical inputs of the physical parity cube, build its extensions of $B$, and try the sound members of the list on all corners and lengths for $jN^d$ steps each. The list of sound members is used only in this *existence proof*. At a fixed stage it is a finite set and can be hardwired into a hypothetical solver. If every sufficiently large satisfiable source has one timely answer, accept on any timely YES and default to NO. This decides all large sources: soundness prevents accepting an unsatisfiable one. The finite small exceptions can be hardwired. There are only $j2^j$ corners across lengths, constant for this algorithm, and all cost $O(n^d)$ to build and try in total. Use a sufficiently large fixed host width to simulate the finite guests with disjoint scratch space, logging writes to reset the guest between trials. This would contradict the assumed lower bound. Thus there are arbitrarily large satisfiable sources for which **none** of these sound programs returns on **any** corner within the deadlines.

For the remaining programs finitely many wrong-halt records suffice. A single dovetailed search over sources and all finite records eventually finds a complete certificate. Alternatively dovetail semantic error detection and enumeration of tests against the surviving pool; revisit earlier tests fairly as error records arrive. Check all SAT labels and the claimed inclusions offline before publishing a block. The minimum length may be required to exceed the entire previous block. This proves inductively that the partial computable search completes every stage under the hypothesis. Conversely, a total correct $O(n^d)$ solver appears permanently in the list beyond a finite description bound. It can never be retired. Increasing $j$ absorbs its clock constant (including its finitely many initial lengths), after which even one claimed slow corner is impossible. Hence that solver prevents completion of all stages. The one-stage proof re-establishes slowness of old machines on the *new input*; there is no monotonicity rule for their runtimes under adding clauses.

## Keeping opposite verdicts and consecutive lengths

For $d=2,3$ we can additionally require a second block after each all-SAT stage. Use the designated positive corner of that first block as its anchor. On a normalized $n$-bit input $F$, conduct the [verified assignment search](one-bit-hard-pairs-at-consecutive-sat-lengths.md). At each visited fork take the two child restrictions as the logical sources of the physical parity cube. At every available byte length simulate each sound solver on **all corners** for a timeout $t(n)$. A timely YES or NO from any corner is a truthful report about its parity-selected child. If a satisfiable source loses its last extension along this path, the two child labels are opposite and **every corner timed out on every solver at every queried length**. All cube edges at that fork change the verdict. The new seed is any SAT corner. Its clauses again stay in the next block.

Write $H$ for the requested number of consecutive lengths and $r$ for the cube dimension. For $r\log(n+r)=O(n)$ and $H\le n/8$, lengths can be chosen in a common interval of bit lengths $\Theta(n)$ for all forks on the same source. The normalization, pinning and checking of a prefix and its two child restrictions fit in $O(n/\log n)$ work per constructed corner. For an input having $v$ occurring variables, the complete verified search takes
$$
 O\left((1+v)H2^r\,[n/\log(n+2)+t(n)]\right).
$$
The finitely many width coefficients, the fixed old anchor and the simulation constants are absorbed. A satisfiable source is lost on arbitrarily large inputs if this budget is $O(n^d)$ and SAT has no solver of that time. As before, enumerate the nonsound-machine error records in parallel. This produces an effective second block. For fixed $r=H=j$, one may for example take timeout $jN^{d-1}\lfloor\log_2(N+2)\rfloor$ in the certificates, since $v=O(n/\log n)$. The unknown finite constants again do not affect the assumed exclusion.

The same proof allows both cube dimension and block length to grow as explicit functions of $n$. For example, let $L=\lfloor\log_2 n\rfloor$, $r=\lfloor(\log_2 L)/3\rfloor$, and $H=\lfloor L^{1/3}\rfloor$. Under the quadratic lower-bound hypothesis, for **any** fixed finite list of sound programs and $C>0$ there are arbitrarily large $n$ such that every program takes more than $C N(\log N)^{1/3}$ on **all** $2^r$ vertices at **every** one of $H$ consecutive byte lengths. Every edge is a physical bit flip with opposite labels. The inequality $H2^r=O(L^{2/3})$ pays for the searches. Under the cubic hypothesis one can instead take $r=\lfloor\log_2 n\rfloor$, $H=\lfloor\log_2 n\rfloor$ and timeout $CN$, obtaining $\Theta(n)$ slow vertices of alternating verdict at each length. Taking $r$ and $H$ to be at least the fixed stage $j$ eventually allows either version inside the computable search. These are conditional geometric consequences. The unchecked premise is precisely the unrestricted running-time exclusion.

## Why the retained seed must be satisfiable

If a fixed old seed is UNSAT, every formula containing all its clauses with their original names is UNSAT. A globally correct RAM solver can search a valid file for these finitely many fixed clauses, reject immediately when all occur, and use any total SAT decider on a miss. On the dense canonical family a scan for a fixed set of clauses takes $O_B(N)$ even byte by byte: compare each delimited literal token with a fixed string using bounded state, with no conversion of long integers. On the fresh-variable extensions above the old body is an exact prefix after the header. For those extensions the same solver can find the end of the header in $O(\log N)$ byte steps (dense names and counts at most $N$) and compare the next fixed number of bytes, checking token boundaries. Thus no arbitrarily slow chain against every correct solver can retain a single UNSAT seed this way. This includes keeping all corners of an old alternating cube as clause subsets on their corresponding new faces. The negative corners would carry fixed contradictions recognizably forever.

For the positive chain the disjointness has its own limitation. The exhaustive construction can compute a common satisfying assignment by extending a chosen old model with a model of each new disjoint block. If a single RAM routine generates correct values for all occurring names on this chain in $O(N^d)$ total time (including checking the produced assignment), testing that assignment with a general fallback would defeat the requested lower bound on the positive centers. A construction that simply plants an efficiently known global assignment cannot prove stage termination. The [finite audit](nested_timed_core_audit.py) exercises the selector, retained clauses, bounded execution certificates and the negative-seed obstruction. The proofs of asymptotic construction cost and stage termination equivalence are manuscript arguments. Priority for these structural refinements of a complexity core is unestablished.
