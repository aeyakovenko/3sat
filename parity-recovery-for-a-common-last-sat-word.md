# A common SAT file with a one-word query at any last slot

There is a list of \(p+1\) pairs of explicit DIMACS files derived from one database \(x\) and one query \(q\). Every pair differs in a single physical bit and has one satisfiable and one unsatisfiable member. For any fixed collection of \(R\) correct deterministic SAT programs, at all sufficiently large sizes **one choice of \(x,q\) works for all of them**. For each program, at least one pair reaches the same last previously unseen data word on both runs. On that pair either its shared prefix already takes more than \(N^3\) steps or **both** suffixes read at least two distinct old addresses. Here \(N=\Theta(m)\) is the encoded bit length and \(p=\Theta(m/\log m)\). Exactly \(p+1\) pairs are necessary if the collection includes scans ending at each of the \(p+1\) possible slots. The count is of pairs, with \(2(p+1)\) individual files in this list.

One need not know the programs' access orders to sample the list. The construction extends the four-table lower bound by allowing a query to overwrite *any* one-word data packet of the same actual file. The suffix cost is additive and still permits a linear-time solver on this family. ## One erasure at a shared physical position

Use four \(m\)-bit tables \(x_j\), with \(m\) a power of two. A query \(q\in[m]^4\) tests \(F(q,x)=\bigwedge_j x_j[q_j]\). For \(s=\log_2 m\) choose a power of two \(h=\Theta(s)\) with \(h\le s/8\), and divide each table into \(m/h\) disjoint \(h\)-bit chunks. Write \(\mu_{j,a}\) for the bits of chunk \(a\) in bank \(j\). There are \(p=4m/h\) regular packets. The remaining packet contains the four masks

\[
                         \mu_{j,*}=\bigoplus_a\mu_{j,a}.
\]

All \(p+1\) packet slots are aligned native words and have public positions. The **master** file puts its data packets and joint parity packet at these positions in one fixed public order. It has no query packet.

The fixed clauses implement one-hot high and low selectors in each bank. Assert the root of each binary tree, encode parent \(=\) OR of the children, and forbid both children from being true. This gives exactly one selected leaf and a unique setting of the tree for each choice. For every \(h\)-bit mask \(\mu\), use one library wire \(S_{j,\mu}\). For each offset \(i\), the selected low leaf \(i\) forces this wire to the bit \(\mu[i]\). All library wires are determined even when no packet uses their names.

Introduce one scalar variable \(Y_{j,a}\) for every regular chunk and one \(Y_{j,*}\) for each bank. The regular packet expresses \(Y_{j,a}\leftrightarrow S_{j,\mu_{j,a}}\) by two clauses. The parity packet expresses the four equalities \(Y_{j,*}\leftrightarrow S_{j,\mu_{j,*}}\) by eight clauses. In the public part assert \(Y_{j,*}=\bigoplus_aY_{j,a}\), using a deterministic XOR circuit. A binary multiplexer or a disjunction of one-hot high-leaf conjunctions gives the selected \(Y_{j,a}\) in each bank. A fixed gate takes the AND of the four selected bits. Give this gate two complementary output names whose decimal identifiers agree except for a final digit 2 or 3.

A query packet consists of eight positive units selecting the high and low leaves and one positive unit selecting the output name for tag \(b\). It asserts \(F(q,x)=b\). For each slot \(i\) make two files by replacing that master packet by the query with tag zero or one. The files differ in exactly one ASCII bit. Fix \(q\). If the erased packet was the joint parity packet, all regular values determine the four parity values. If a regular packet in bank \(j\) was erased, its value is uniquely recovered from the retained parity and all other scalar values in that bank. The mask identity above holds at **every** possible low offset in that bank. The four low offsets are independent. Every gate, name and selector now has a unique value before the tag is asserted. Exactly one replacement is satisfiable, and it has one model. On the unqueried master every choice of four indices gives one model, including when all four selected data bits are zero. Thus the master itself has \(m^4\) models.

These are proper ordinary 3-CNFs. Use three public false anchors fixed by the seven triples excluding the other assignments. Pad units and binary clauses with distinct false anchors, and fill shorter packets to nine ternary rows with satisfied public clauses. The two occurrences of a mask name in an equality are both in its one packet. Decimal mask names may use a fixed nonzero bank prefix and an \(h\)-digit binary suffix. Filling the intermediate identifier ranges costs \(O(10^h)\) variables. The fixed region uses \(O(m/h+h2^h+10^h)\) clauses, including the parity circuits and the high selectors. Each ordinary clause costs \(O(\log m)\) bits. A sufficiently large fixed width \(w=8C\lceil\log_2(N+2)\rceil\) holds even the joint packet or the nine query units after proper padding. Align the start of the slots by whitespace and give each exactly one word. Choose \(N\) as a public power of two of order \(m\), large enough for the fixed text, slots and trailing whitespace. The physical promise uses aligned loads. [Selector, padding and population of dense names](the-price-of-few-reads-after-the-last-sat-word.md)

A globally correct solver can check the public syntax, packet keys, formats and multiplicities, unpack every mask and compute four bitwise XORs in \(O(N)\) steps. With one missing regular packet the corresponding checksum recovers its mask; when all regular packets are present their masks determine the answer directly. It also checks every supplied checksum in an intact bank before a fast return. On a master with all checksums verified it accepts. Unrecognized or inconsistent layouts go to a complete SAT procedure.

## The last slot is chosen by the actual master execution

Run a program \(P\) on the completed master. Before it has inspected every slot, choose an unread slot. The two files obtained by replacing that slot by the same query with opposite tags give the exact same observations up to this point but opposite eventual verdicts. Thus \(P\) cannot halt there. It also cannot run forever before its next fresh load, since it would do so on both completions. Consequently there is an actual last fresh slot \(i_P(x)\). The address of this load, the prefix elapsed time and the full prefix state depend on \(P,x\), and are independent of \(q\) and its tag. The suite contains the pair at \(i_P(x)\) without computing \(i_P(x)\).

An old address is a previously exposed input packet, or a work address read before the first suffix write to that address. Cache repetitions, including initialized zero. Fixed input data and the final query word are free. For a given \(P,x,q\), call its pair a success if the master prefix through issue of its last fresh load exceeds \(N^3\) elapsed steps, or if both actual replacement suffixes at that slot need more than one distinct old address. The counts below also allow a fixed common constant multiplier on the cubic cap.

## How often a master and query work

Let \(x\) be uniform on the \(4m\) database bits and choose \(q\) uniformly and independently. Conditional on \(F=1\), this distribution is easy to sample: choose \(q\), set its four addressed bits to one, and choose the remaining data bits independently. The conditioning event has probability \(1/16\).

First fix one program and one tag. Bob knows \(x\) and simulates the master up to the cut. Mark a prefix exceeding the time cap as aborted. Otherwise its input packets and occupied work cells have total support \(S=O(N^3)\). Bob sends the controller, the last slot, and the auxiliary sparse-dictionary description from the four-table protocol. Alice knows \(q\) and the tag. She can simulate the genuine suffix, privately handling writes, constants and the final packet. Permit one distinct old address. Stop with an abort at the request for a second. A halt with verdict implying \(F=1\) is retained; all other outcomes are discarded. Thus every retained transcript is entirely contained in \(F^{-1}(1)\). Each tag uses its own **one-read** protocol. After proving a density bound we can take their union.

With fixed message lengths, at most \(a=\log_2\max(1,S)+O(1)\) bits go from Alice to Bob and at most \(b'=O_P(w)\) bits from Bob to Alice. The leading coefficient one in the Alice cost comes from two bucket labels whose combined range is \(O(S)\). Bob sends the original stored key so an absent key is detected exactly. For a fixed column at most \(2^a\) transcripts occur, since Bob's actions are determined by Alice's bits and this column. In total there are at most \(2^{a+b'}\) transcripts. [Exact one-probe sparse-address simulation](the-price-of-few-reads-after-the-last-sat-word.md) · [Miltersen, Nisan, Safra and Wigderson on asymmetric communication and richness](https://www.math.ias.edu/~avi/PUBLICATIONS/MYPAPERS/MILTERSEN/JOURNAL/final.pdf)

Set \(L=\lceil(a+b'+2\log_2(m+2)+1)^4\rceil\). A monochromatic positive rectangle with \(r\) distinct query rows forces a one at every coordinate in its four projections. These projections have product at least \(r\), so their total size is at least \(4r^{1/4}\). Thus the fraction of all database columns in such a rectangle is at most \(2^{-4r^{1/4}}\). Rectangles with larger than \(L\) rows together meet at most a \(2^{a+b'-4L^{1/4}}\) fraction of columns. Those with at most \(L\) rows cover at most \(2^aL\) queries per column. Consequently under independent uniform \(x,q\) the retained fraction for one tag is at most

\[
                  \frac{2^aL}{m^4}+2^{\,a+b'-4L^{1/4}}.
\]

Divide by \(\Pr[F=1]\) and sum over the two tags. At the cubic cap the failure probability for the resulting **whole block of \(p+1\) pairs** is bounded by \(\epsilon_P(m)=O_P((\log m)^4/m)\). Aborted long prefixes are already successes. Hence the estimate applies to every correct program, at any speed. It is the two separate densities of truthful one-read transcripts that give the cubic-cap statement for a pair of opposite tags.

For a collection of \(R\) programs take any common bound \(\epsilon<1\) on these failure probabilities. Sample independent blocks. With \(B\) blocks the chance any program fails all of them is at most \(R\epsilon^B\). Taking \(B=\lceil\log(2R)/\log(1/\epsilon)\rceil\) gives a common suite of \((p+1)B\) pairs. In particular one block suffices when \(R\epsilon<1\). For fixed \(R\) this holds for all sufficiently large \(m\). For a growing family with a uniform constant bound on the number of registers, \(O(w)\) bits for the program counter and the same width and cubic cap, the constants are uniform. One block then suffices for \(R=o(m/(\log m)^4)\), and \(O((p+1)(1+\log R/\log m))\) pairs suffice generally at those scales. Unbounded code and register sizes specialized to one \(m\) require using the actual \(a,b'\) in the density estimate.

**One sequence for all fixed programs.** At size \(m=2^s\) sample one block conditional on \(F=1\). For each fixed correct program the failure probabilities are \(O_P(s^4/2^s)\), a summable sequence. With probability one this program fails at only finitely many sizes. Intersecting these probability-one events over the countably many fixed programs shows that one sequence of exactly \(p+1\) pairs per size eventually covers every such program. The size after which coverage holds may depend on the program.

Such a sequence can even be chosen computably without a time bound on its construction. Enumerate the fixed RAM programs. At size \(s\), check each of the first \(s\) programs for correctness and termination on the finite collection of all masters and their tagged replacements at that size. This check is decidable: at a fixed word width each program has finitely many control and memory configurations, so a repeated complete configuration detects a nonhalting run. The true verdicts on this collection are known. Search all blocks with \(F=1\), and take the lexicographically first maximizing the initial segment length for which every program is either locally incorrect or covered by the block. For any fixed initial segment, the preceding density proof applies at a given size to every locally correct member of that segment, regardless of its behavior elsewhere. The finitely many constants are uniform over that segment. Hence a block covers all its locally correct members at every sufficiently large size. The maximizing choice eventually does so as well. In particular each globally correct program is eventually covered by this single computable sequence.

To see the slot lower bound, include \(p+1\) programs that scan the public slots in fixed orders ending at the respective slots. They can copy the file in linear time before applying a complete solver, with the nominated slot last. A physical tag pair has a common prefix through the address of that last load only for the scanner whose last slot contains its query. Every such scanner has a prefix below the cubic cap. Therefore a suite of these single-packet query pairs covering all scanner endpoints must contain at least \(p+1\) pairs. The scanners can use constant register count and a single literal slot parameter. This lower bound concerns coverage at the last load and does not imply a superlinear unrestricted SAT clock.

A globally correct SAT solver can recognize this entire layout in $O(N)$ time on its members. Generate and compare the public clauses, parse each of the $p+1$ known packet positions, check its format and key, and record the location and contents of a query if present. Check that there is at most one replacement. If one regular key was replaced, recover its whole mask from the joint parity packet and the other regular masks in its bank. If the parity packet was replaced, the regular masks already determine all four selected bits. Check all available parity identities before a fast return, and on an unrecognized file use a complete SAT decision procedure. For a valid master the answer is always true. This takes a constant number of scans, with decimal parsing and template generation within the encoded bit budget.
