# Locating a mixed pair in a known failed SAT search

A satisfying assignment and a failed [ordered-cutoff search](ordered-cutoffs-for-two-bit-ram-exhaustion.md) certify that some batch contains two opposite-verdict files with the same timed replies. Naming one such batch can itself decide arbitrary SAT. This holds for a constant observer, an always-satisfiable source with the all-one model given for free, and just two possible batch indices. The reduction takes $O(n)$ native steps and emits $O(n)$ encoded bits. It therefore applies at the linear, quadratic and cubic clocks of the unrestricted RAM question. It leaves the existence of failures at every clock multiplier open.

## A degree-four source whose least witness determines the batch

Given a proper 3-CNF $G$, first make a distinct signed copy of each occurrence and prepare a cyclic equality link $x\to y$ for successive copies of any variable with at least two occurrences. Reserve $H,L$ as the two most significant assignment bits, in that order. Use the two root clauses
$$
 (H,L,z),\quad (H,L,\neg z).
$$
They force $H\lor L$. Make one fresh pair of variables $f_i,t_i$ for each source row or equality link. Start with $(f_0,t_0)=(H,L)$ and at each step append
$$
  (f_{i-1},\neg t_{i-1},\neg f_i),\qquad
  (f_{i-1},\neg t_{i-1},t_i).
$$
Thus $H=0,L=1$ forces all $f_i=0,t_i=1$. Each new variable appears once as a child, at most twice in the next step and at most once more in a source or link row. Each root occurs at most four times.

For a source row on signed copies $A,B,C$ add $(f_i,A,\neg u),(u,B,\neg v),(v,C,\neg t_i)$. A link contributes $(\neg x,y,f_i)$. At $H=0,L=1$ the three source rows project to $A\lor B\lor C$ and the directed links force all copies to agree. At $H=L=1$ the all-one assignment satisfies every clause. At $H=1,L=0$ setting every other bit to one also gives a model. The all-zero assignment violates just $(H,L,z)$. In fact this is the only purely positive clause and every other clause is mixed. All names occur, each at most four times, each clause is proper and the output can be sorted. Assign $H,L$ the largest and second-largest names. Normalization, the number of clauses and dense printing give linear encoded length and native time as in the [single NAE triple reduction](sat-with-one-not-all-equal-triple.md).

A constant observer assigns all copies the same reply. The pruning algorithm consequently retains only the leftmost (all-zero) prefix at every depth, so it always rejects this planted source. With $v$ occurring variables its two inclusive cutoffs at depth $t=1,\ldots,v$ are $2^{v-t}-1$ and $2^{v-t+1}-1$. For a positive least model $\mu$, exactly one batch is mixed, the one satisfying $2^{v-t}\le\mu<2^{v-t+1}$. The first two depths here have successive endpoint verdicts
$$
 \mathrm{YES},\quad \mathrm{SAT}(G),\quad \mathrm{NO}
$$
in order of *decreasing* cutoff. Thus depth 1 is mixed for unsatisfiable $G$, and depth 2 for satisfiable $G$. All later batches are entirely negative. This proves hardness of naming any valid batch even when only the first two need be supplied. Conversely on the promise that exactly one of these first two batches is mixed, the known failure and all-zero observation give its identity by one SAT call asking whether the source has a model below the middle cutoff. In the explicit two-tag family this simply pins $H=0$. The common source with these two batches has an $O(n)$ representation. Writing the entire expanded trace can cost more, so the linear reduction uses the source and the two batches or their compact specification. [Lean dyadic-batch proof](LeastWitnessBatch.lean) · [Physical source audit](almost_mixed_cutoff_audit.py)

There is a related implication test using only mixed clauses. Change the roots to $(\neg H,L,z),(\neg H,L,\neg z)$, which impose $H\Rightarrow L$. The constant assignments both satisfy this version. The only possible unequal setting is $H=0,L=1$, which still activates $G$. Thus deciding whether two named bits are equal in *every* model of a fully mixed proper degree-four formula is coNP-complete, with the same linear reduction from UNSAT. This is a joint constraint on two variables even though each can take either value separately. Frozen variables in Boolean constraint languages have an established complexity theory. [Jonsson and Krokhin](https://eccc.weizmann.ac.il/report/2003/062/download/)

## Three explicit files suffice for the decision reduction

One can pose the problem directly on genuine canonical proper degree-four files without giving an execution transcript. Supply three files of the same length, indexed $B,M,C$. The first is known SAT, the last known UNSAT, their distance is four physical bits, and the two adjacent distances are two bits. An answer names two files at distance two with opposite verdicts. There is exactly one answer. Returning which pair it is is equivalent to deciding SAT even at the exact $O(n^d)$ exponents above.

Use the planted source just built. Add four independently pinned physical bits using the [signed-copy selector template](physical-selector-parity-cubes.md). The third switch, when active, requires $H=0$. The fourth, when active, requires $L=0$. The first two bits are inert and any forcing clauses in this compilation are included in the common file. Encode these three masks in order
$$
      B=1100,\qquad M=0110,\qquad C=0011.
$$
The first file has an explicit model. The last imposes $H=L=0$, contradicting the roots. The middle has a model iff $G$ does. The selector positions each exchange ASCII 2 and 3, so all three byte histograms agree and the three distances are as claimed. The fixed-size selector overhead and linear-size source compilation keep the total number of emitted bits $O(n+1)$. An algorithm in the other direction can decide the single middle file directly. Two supplied files would leave only one unordered pair to name on the promise that a valid answer exists. Three is therefore minimal for encoding this decision into the *choice* of an unlabelled pair in this formulation.

In the [audit](three_cutoff_files_audit.py), one source clause gives three 9,820-byte files with verdicts YES, YES, NO. All eight clauses on one triple give three 93,307-byte files with verdicts YES, NO, NO. Each parsed positive model was checked clause by clause. The script also checks the two distances, the endpoint distance, the histograms and degree. It can write all nine tested files with its `--write-dir` argument.

There is also an unconditional obstruction for extraction certified by resolution. On an unsatisfiable source $G$, the negative file $M$ admits a constant-or-literal projection back onto all clauses of $G$. In the inner planted formula set $H=0,L=1$, all $f_i=0,t_i=1$, collapse occurrence copies, and in a source triple substitute $u=A,v=\neg C$. In the outer physical template set the switches to the middle mask, give each ordinary copy its underlying literal or constant, and set the signed input copies to the corresponding forced polarities. All links then contain complementary literals or a true constant. Give every forced-false auxiliary gadget a model and set disjoint positive filler triples true. Only the middle row of each original source triple survives. The [resolution projection lemma](literal-projection-of-the-nae-core.md) implies that any resolution refutation of $M$ on the cubic-expander Tseitin sources requires $2^{\Omega(N/\log N)}$ lines, where $N$ is its encoded size. Here the only eligible opposite pair is $B,M$. Thus a procedure requiring a resolution refutation of the named negative endpoint can incur exponential certification time even with an explicit model of the planted source and a known failed search. This is a proof-system cost.

## How many SAT decisions are needed on general failed traces?

Fix a list of observers with a polynomial-time simulable deadline and a polynomial-size pruning trace, or supply the explicit trace under the promise that it is valid. On a satisfiable source with a known witness and rejected terminal list, a deterministic polynomial-time procedure can return a mixed batch using $O(\log n)$ adaptive SAT queries, where $n$ is the input length of this search problem. Sort the polynomially many logged cutoff endpoints, binary-search their unique transition, and read off a same-color pair straddling it. The interval-cover solution gives the more precise instance-dependent query bound, including the case of no additional queries. [Extraction game and exact costs](failed-cutoff-extraction-game.md)

The function problem, with a deterministic rule to choose among correct answers, admits an $\mathrm{FP}^{\mathrm{NP}[O(\log n)]}$-complete version. For example return the first valid batch in chronological order and its first pair in a fixed order. Once the transition is known, every eligible pair can be tested. Hardness already holds when the valid batch index is unique, so returning an arbitrary valid index on that subclass is equally hard. Polynomial-time metric reductions here permit polynomial-time decoding of the returned index. This is a complexity classification of the *extraction*, with the failure given. [Krentel on completeness of optimization functions](https://www.sciencedirect.com/science/article/pii/0022000088900396)

For completeness, consider a polynomial-time function computation that asks $q=O(\log n)$ adaptive SAT queries. Pad all its branches to the same $q$, using an unsatisfiable dummy query once the computation has halted. Enumerate its polynomially many putative answer transcripts $z$. Simulate the given computation along each transcript and conjoin fresh-variable copies of precisely those query formulas to which $z$ answered YES. Call the resulting SAT instance $G_z$, using a tautology for an empty conjunction. The true transcript is feasible. At the first differing bit, a lexicographically greater transcript must assert YES on the genuine machine's negative query, so is infeasible. The largest feasible $z$ is exactly the correct transcript. [Lean proof of the transcript comparison](LeastWitnessBatch.lean)

Give one high-order tag bit per transcript, in increasing order of transcript rank from most to least significant, and place a fallback tag first, more significant than all these bits. Require at least one tag to be true. Whenever tag $z$ is true require $G_z$ to have a model, with disjoint witnesses. The fallback tag alone always has a known extension, computable by assigning the inactive gated circuits. Among all feasible choices the least assignment has its leading one at the tag of the largest feasible $z$. Indeed activating that tag alone is possible, and moving the leading one further right would require a still larger feasible transcript. Give all gate variables lower significance than all tags. The constraints can be emitted as proper 3-CNF in polynomial time by ordinary gate clauses. The constant observer again follows all zeros and fails. The unique mixed batch reveals the leading tag and therefore the answer transcript. This proof of function-class hardness uses polynomial encodings. The two-depth and three-file decision reductions above preserve linear size.

## What a short named certificate would imply

Suppose a polynomial-time verifier could certify a *named*, correctly mixed batch for every promised failed trace, with a polynomial-size certificate for at least one valid batch and no certificates accepted for wrong indices on the promise. Then NP equals coNP. On input $G$ construct the planted source above and accept an alleged UNSAT certificate precisely when the verifier certifies depth 1. Only that depth can be mixed when $G$ is unsatisfiable, and it cannot be mixed when $G$ is satisfiable. Conversely if NP equals coNP, a positive batch member has the ordinary assignment witness and a negative one has a polynomial-size UNSAT certificate. Verify both labels and their equal timed replies by the stipulated polynomial-time bounded simulation. This yields a verifier certifying a named batch on every promised failure. The same equivalence holds for certifying the unique distance-two answer on the three-file promise.

The positive witness for the *existence somewhere* of a mixed batch already found in the journal is compatible with all of these statements. Proving that an unrestricted finite census always has at least one failed search is a separate unresolved step. The reductions and complexity classifications are manuscript arguments. The Lean files check the indicated order, propagation and oracle-count lemmas.
