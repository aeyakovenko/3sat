# Checking a word-matrix transpose with ordinary 2-SAT

**Open step addressed.** Can the tape lower bound use the accepting or rejecting run of a SAT decider directly? Under the absence of ports in characteristic zero, yes. For every sufficiently large byte length $n$ a deterministic finite-alphabet multitape machine deciding ordinary 2-SAT takes $\Omega(n\sqrt{\log n})$ steps, with no space restriction. Both satisfiable and unsatisfiable valid inputs attain the bound. This holds on an explicit family with two physically separated arrays of clauses. Variable-count Weak ETH implies the no-ports hypothesis in the cited preprint. An unconditional lower bound from this argument still requires handling the ports case. The input length can equally be counted in bits. The conditional conclusion concerns a language already in deterministic polynomial time. [OpenAI, partial transposition and the recorded-head construction](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-integer-multiplication-on-tapes-November-24-2026/build/lower.tex) · [Port hypothesis and direction of implication](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-integer-multiplication-on-tapes-November-24-2026/build/graphs.tex)

## The file and its two possible answers

Take a $t\times t$ matrix of $w$-bit records twice, with $w=\lceil\log_2 t\rceil$, $t\ge2$. The first list $A$ arrives in row order. The second list $B$ arrives in the row order of the *proposed transpose*. For $i,k$ from zero to $t-1$, write $j=it+k$ and $m=t^2$. Use backbone variables $p_0,\ldots,p_m$ and data names $x_{j,z}$ for record values $z$. Pin $p_0$ true and $p_m$ false. The first section contains in $(i,k)$ order the clauses
$$
                   \neg p_j\ \vee\ x_{j,A_{ik}} .
$$
The second contains in $(k,i)$ order
$$
                   \neg x_{j,B_{ki}}\ \vee\ p_{j+1} .
$$
The inputs are independent until the solver compares them. If the arrays agree after transposition, the implications force $p_m$ true and the file is unsatisfiable. For a mismatch at $j_*$, set $p_j$ true exactly for $j\le j_*$. Set $x_{j,z}$ true exactly for $j\le j_*$ and $z=A_{ik}$. These values satisfy every clause. Unused names can be assigned arbitrarily. A formula with exactly two distinct literals in every clause can express a pin $u$ as $(u\vee z)\land(u\vee\neg z)$ for an extra variable $z$. Replacing each binary clause by its two ternary extensions on a fresh common variable also transfers the deterministic conclusion to proper 3-SAT. [Lean proof of both directions and the binary pin](TransposeEqualityTwoCNF.lean)

Encode names as ordinary positive decimal integers. Use a nonzero namespace digit, fixed-width coordinate fields using decimal digits 1 and 2 for the binary coordinates, and a fixed-width field for $z$ where applicable. Fixed digits pad smaller fields. Reserve the largest appearing name for a harmless pinned header auxiliary if desired. All variable names and clause slots now have $O(w+\log t)$ bytes. Every name is in the declared range; the range may contain unused names. The header, anchors and padding are independent of the records. Each row section for one row of $A$ and each column section for one row of $B$ has $\Theta(tw)$ consecutive bytes. The entire file has $n_t=\Theta(t^2w)$ bytes. A terminal with a whole row or column can render its own contiguous section, using only local data. In particular, no binary tape transpose is hidden in preparing the file. The experiment writes and reads actual ASCII files in the two indicated orders. [DIMACS audit](transpose_tape_2cnf_audit.py)

The orientation matters. Suppose independent chunks $R(A)$ and $C(B)$ of *any* CNF, with fixed shared clauses allowed, instead give a satisfiable conjunction exactly on equality. For each matching input let $v_A$ be the number of distinct occurring names. In one common probability space of independent fair bits for all names across this finite family, the assignments satisfying its diagonal file have measure at least $2^{-v_A}$. These events are disjoint: a common assignment on two different diagonals satisfies the off-diagonal formed by the first row chunk and second column chunk. Hence $\sum_A2^{-v_A}\le1$. At most a $2^{-d}$ fraction of the $2^V$ equal inputs can have $v_A<V-d$. Merely spelling $v_A$ distinct identifiers costs $\Omega(v_A\log(v_A+2))$ bits. A positive-on-equality transfer in this independent-chunk format therefore cannot have $O(V)$ encoded length on all diagonals. If the emitters first exchange $c$ bits in a deterministic protocol, its transcripts partition the input pairs into rectangles, and the sum is at most $2^c$ by applying the argument on each rectangle.

## The word version of partial transposition

Write $V=t^2w$ for the number of independent data bits and $b=tw$ for the number at each row or column. Assume characteristic zero has no ports. Consider a rational network of bounded bundle degree and bundle width $O(b)$ with $2t$ distinct terminals. Suppose that for at least a $2^{-\rho V}$ fraction of all $A$, fixing the row inputs leaves a nonzero multiple of the basis vector for $A^{\mathsf T}$ on the column outputs, where $0\le\rho<1-1/\sqrt2$. The network needs $\Omega(t\sqrt{\log t})$ vertices, uniformly in $w\ge1$. The published table theorem states the bit-entry case. Its geometry and entropy lemmas yield this word-entry version directly. [Preprint, geometry, entropy and partial transposition](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-integer-multiplication-on-tapes-November-24-2026/build/lower.tex#L27-L234)

In detail, let $P$ be the number of vertices rounded up to a power of two and take $P=O(t\sqrt{\log t})$, since a larger count already suffices with a constant bound. Apply the short-edges lemma with its width parameter $b$. Supply price is $O(bP/\sqrt{\log P})$. Use its two terminal lists of length $t$. The mean absolute departure of their pairwise distances from one is $o(1)$, since the mean square is $O(P/(t\log P))$. Apply the paired-terminal entropy inequality to all $V$ individual bits under a uniform good input. There are $w$ bits for each terminal pair, and every conditional bit entropy is at most one. The total distance error is at most $V\,o(1)$. The sum of the conditional entropies is at least $(1-\rho)V$. Row pin entropies $h_i$ satisfy $h_i\le b$, $\sum h_i\le V$ and $\sum h_i^2\le t b^2$. Their central price is at most $V/\sqrt2+O(b\sqrt{tP/\log P})=V/\sqrt2+o(V)$. The positive gap forces $P=\Omega(t\sqrt{\log t})$. The tape paper uses Weak ETH to obtain exactly the geometric no-ports premise here. It does not prove its converse.

## Fixing a head record for a decision

Use epochs and tape blocks of length $b$ cells on a fixed multitape machine. In a deadline $T$, there are at most $2^{O_M(1+T/b)}$ sequences of block indices at epoch boundaries: each head starts at a prescribed position and moves at most one block per epoch. For a fixed record one bounded-degree rational table per epoch checks the actual internal run, its boundary state and head offsets, and the incoming and outgoing contents of the constantly many neighboring blocks. Pass each block directly to its next possible use. Deterministic transition checks give 0/1 entries. Attach separate row and column terminals to the initial file cells. Each data section meets only a constant number of physical blocks and each block meets only a constant number of sections. Fixed cells come from constants. Thus the network has $O_M(t+T/b)$ vertices and width $O_M(b)$; the column terminals are open **input data to the machine**, viewed as output legs of the relation. There is no tape transducer producing the second array.

First count runs which return UNSAT by the deadline. Every accepted pair has $B=A^{\mathsf T}$ by correctness. From every timely equal pair choose its record. If an initial $2^{-\rho V}$ fraction of all $A$ were timely, a common record retains at least $2^{-\rho V-O_M(1+T/b)}$. For $T\le V\sqrt{\log t}$ the record loss is $o(V)$. Choose a fixed $\rho'$ strictly between $\rho$ and $1-1/\sqrt2$. On the retained fraction each fixed row input leaves exactly its valid column basis vector. The word theorem gives $T\ge c_{M,\rho}V\sqrt{\log t}$ for all large $t$. Equivalently, at a sufficiently small constant times this deadline all but a $2^{-\rho V}$ fraction of equal pairs are late, for any fixed positive $\rho$ in the range. The same argument applies to the shortest accepting path of a sound nondeterministic **UNSAT recognizer**: select one accepting path per timely input and count legal epoch continuations over the rationals. Gluing their boundary data gives real paths. All contributions are nonnegative, so an accepting path gives a nonzero coefficient.

For a deterministic solver, consider instead the record relation that the machine **has not answered SAT** by $T$. Every equal input satisfies this relation. If, for a particular $A$, all unequal $B$ receive SAT by $T$, the full relation on this row has only the transposed column in its support. Pigeonhole the actual equal-pair record on the set of such $A$ and repeat the preceding argument. For all but a $2^{-\rho V}$ fraction of $A$, at least one unequal $B$ is consequently late. This proves a lower bound on actual satisfiable files too. It uses the deterministic clock and does not assert a nondeterministic lower bound for recognizing mismatches. Such a recognizer can guess a mismatched cell and compare its stored records in a scan.

To reach every sufficiently large byte length choose the largest dyadic $t$ with $n_t\le n$. The canonical lengths $n_t=\Theta(t^2\log t)$ have bounded successive ratios. Insert exactly $n-n_t$ ASCII spaces between the fixed anchor literal and its clause-terminating zero, before the data sections. This preserves every clause and assigns no padding to a data terminal. The additional $O(t)$ physical blocks are fixed, and translating a data section by the padding length leaves it incident to only constantly many blocks. Then $n=\Theta(V)$ and $\log n=\Theta(\log t)$. The bounds hold for each of these fixed padded layouts, with constants independent of the choice of padding. If lengths are counted in bits, the admissible byte-aligned lengths are $8n$. The claims allow record-independent auxiliary tape data fixed for the size, as in the upstream theorem. [DIMACS, *Satisfiability Suggested Format*, §2.1](https://www.cs.ubc.ca/~babic/doc/dimacs_cnf.pdf)

## How many different satisfiable files can be late on one row input?

Under the same no-ports hypothesis, fix $\rho,\eta>0$ with $\rho+\eta<1-1/\sqrt2$. For each deterministic decider $M$ there is a $c>0$ such that, at every sufficiently large $t$, all but a $2^{-\rho V}$ fraction of row inputs $A$ have at least $2^{\eta V}$ different unequal column inputs $B$ on which $M$ takes longer than $T=cV\sqrt{\log t}$. For each fixed $0<\kappa<\eta$, at most $2^{t^2+\kappa V}$ of these columns can differ from $A^{\mathsf T}$ at fewer than $\kappa t^2$ word positions. Indeed, one chooses a subset of positions and at most $\kappa t^2$ replacement words. Since $w=\lceil\log_2 t\rceil$, this removes a vanishing fraction of the guaranteed late columns.

Choose $\mu$ with $\eta<\mu<1-1/\sqrt2-\rho$ and a fixed integer $K$ such that $(1-1/K)\mu>\eta$. We need a code on the $t$ column blocks of $b$ bits. Regard each block as a symbol in $F=\mathbb F_{2^b}$. A bounded-degree network with $O(Kt)$ vertices encodes these inputs into $L=Kt$ symbols so that distinct inputs differ in at least $L-t+1$ outputs. To see this, take a directed $L$-superconcentrator of bounded degree and linear size. Use $t$ designated inputs and pin the rest to zero. Let each noninput vertex, including each output, form a linear combination of its predecessors with one variable coefficient per incoming edge. For any specified $t$ outputs, the determinant of their transfer matrix is a nonzero polynomial. Setting coefficients to route along $t$ vertex-disjoint paths to those outputs makes that matrix a permutation matrix. Each transfer entry has degree bounded by the number of edges, so the determinant has degree $O_K(t^2)$. The union bound and the polynomial zero bound give a simultaneous good specialization once $2^b>\binom{Kt}{t}O_K(t^2)$, which holds for all large $t$ since $b=t\lceil\log_2 t\rceil$. Agreement at any $t$ outputs would now imply equal inputs. Every fixed field operation and copy has a rational $0/1$ table encoding its action on $b$ bits. [Pippenger, *Superconcentrators*](https://doi.org/10.1137/0206022) · [Drucker and Li, superconcentrator-induced codes over large fields](https://arxiv.org/abs/2402.00378)

Set $r=\lceil\mu V/L\rceil$. At each encoded output independently choose a uniform binary linear map from $b$ bits to $r$ bits and a uniform target of $r$ bits. Require every output to meet its target. For any fixed diagonal column $B_0=A^{\mathsf T}$ this event has probability $2^{-rL}$. Conditional on the event, all the maps remain uniformly and independently distributed, because the targets were independently uniform. For any other $B$, the probability that it too meets all targets is at most $2^{-r(L-t+1)}$, by block distance and independence. Thus if a row has fewer than $2^{\eta V}$ spurious columns, with probability at least $2^{-rL-1}$ only its diagonal survives among these candidates for large $t$. Here $r(L-t+1)>\eta V+1$ and $rL=\mu V+O_K(t)$.

Suppose at least a $2^{-\rho V}$ fraction of rows had fewer than $2^{\eta V}$ late unequal columns. Fix one head record shared by their diagonal runs up to the deadline on at least a $2^{-\rho V-O_M(1+T/b)}$ fraction of all rows. On these rows each spurious column supported by the record for “has not answered SAT by $T$” is one of the listed late inputs. Averaging fixes one choice of all maps and targets that leaves exactly the diagonal on at least a $2^{-(\rho+\mu)V-o(V)}$ fraction of all rows. Multiply the record relation by the filter, keeping the original $B$ available on each of its $t$ separate external column terminals. Each external block can be copied once for the encoder. The local target tests each have one input bundle. Thus the combined rational network has bounded degree, bundle width $O_M(b)$ and $O_M(t+T/b)+O_K(t)$ vertices.

Choose $\rho'$ strictly between $\rho+\mu$ and $1-1/\sqrt2$. The filtered network must have $\Omega_{D,\rho'}(t\sqrt{\log t})$ vertices by the word-entry theorem. Choose $c$ sufficiently small after fixing the degree, width and density constants. The network then has fewer vertices than required for all sufficiently large $t$, giving the claim. The count $2^{\eta V}$ can still represent an exponentially small fraction of the $2^V$ possible columns.

## Machines promised a gap in word distance

Suppose the machine must return UNSAT on $B=A^{\mathsf T}$ and SAT when the two arrays differ at $\kappa t^2$ or more word positions. At every smaller positive distance it may answer arbitrarily or run forever. Fix $\kappa,\eta,\rho>0$ with $\rho+\max(\kappa,\eta)<1-1/\sqrt2$. Under the same no-ports hypothesis there is a constant $c>0$ such that, for all sufficiently large $t$, all but a $2^{-\rho V}$ fraction of rows $A$ have **both** of the following properties at deadline $T=cV\sqrt{\log t}$.

- The equal pair has yet to receive its UNSAT answer.
- At least $2^{\eta V}$ different columns at distance at least $\kappa t^2$ have yet to receive their SAT answer.

For each fixed row, the number of unconstrained columns is at most $2^{t^2+\kappa V}$. Choose fixed numbers $\lambda>\max(\kappa,\eta)$ and $\rho_1>\rho$ with $\lambda+\rho_1<1-1/\sqrt2$. To prove the first property, assume a $2^{-\rho_1V}$ fraction of diagonals return UNSAT by $T$. Retain one common head record and use its relation for that answer. Every spurious column must lie at an unconstrained distance. To prove the second, assume a $2^{-\rho_1V}$ fraction of rows have fewer than $2^{\eta V}$ late far columns. Retain one common diagonal head record from that set and use its relation for absence of a SAT answer by $T$. Its spurious columns consist of at most the unconstrained columns and the late far columns. In either case their number is below $2^{\lambda V}$ for large $t$, because $t^2=o(V)$. The hash isolation argument with $(\rho_1,\lambda)$ gives a contradiction in each case. Use the smaller of the two deadline constants. The union of the exceptional row sets has fraction at most $2\,2^{-\rho_1 V}\le 2^{-\rho V}$ for large $t$.

### Any fixed gap below one on an encoded family

For every fixed $0<\kappa<1$, a deterministic multitape machine distinguishing equality from disagreement on at least a $\kappa$ fraction of the word positions still requires $\Omega_{M,\kappa}(n\sqrt{\log n})$ time at every sufficiently large DIMACS byte length $n$, under no ports. Here the hard inputs come from a code. The density statement below counts original messages within that code.

Choose $\varepsilon>0$ with $(1-\varepsilon)^2>\kappa$. For all sufficiently large dyadic $t$, take a binary linear code $E:\mathbb F_2^t\to\mathbb F_2^N$ of relative distance at least a fixed $\delta>0$ with a bounded-fanin encoder using $O(t)$ wires and $N\le 8t$. Spielman's rate-$1/4$ family has message lengths that double, so one may use a message length in $[t,2t]$ and pin the extra inputs to zero. A binary copy tree for each gate output bounds fanout at linear total cost. Put $L=8t$. [Spielman, *Linear-Time Encodable and Decodable Error-Correcting Codes*, Lemma 3 and Theorem 19](https://cs.yale.edu/homes/spielman/Research/ITsuperc.pdf) · [Ishai, Kushilevitz, Ostrovsky and Sahai, XOR and copy implementation, Theorem 3.2](https://web.cs.ucla.edu/~sahai/work/web/2008%20Publications/STOC2008.pdf)

Fix $L$ ordered $d$-tuples of code coordinates, $J_{u,1},\ldots,J_{u,d}\in\{1,\ldots,N\}$. Choose them so that every $S$ of size at least $\delta N$ meets more than $(1-\varepsilon)L$ tuples. Such a choice exists for a constant $d=d(\delta,\varepsilon)$. For independent uniform entries the probability of failure is at most $2^{N+L}(1-\delta)^{d\lceil\varepsilon L\rceil}$, by enumerating the set $S$ and a set of $\lceil\varepsilon L\rceil$ tuples missing it. A sufficiently large fixed $d$ makes this bound less than one. Grouping these outputs of $E$ gives an encoder whose output symbol at $u$ consists of the bits of the selected $d$ coordinates. Distinct input strings now differ at more than $(1-\varepsilon)L$ output symbols. For words of $s$ bits, apply the same binary encoder in each bit position. A differing bit position gives the same distance guarantee, with $ds$ bits per output symbol. All $Ld$ coordinate uses can be supplied with $O_\kappa(t)$ edges. Grouping coordinates to increase relative distance has earlier explicit implementations with linear-time encoders. [Guruswami and Indyk, *Near-optimal linear-time codes*](https://doi.org/10.1145/509907.510023)

Write $w_L=\lceil\log_2 L\rceil$, put $s=\lfloor w_L/d^2\rfloor$, and take original $t\times t$ matrices $X,Y$ of $s$-bit words. Apply the grouped code along both axes of $X$. If $e_{a,i}$ denotes an entry of the binary encoder matrix, the bit with internal indices $(p,q,h)$ in output word $(u,v)$ is
$$
  \sum_{i,k} e_{J_{u,p},i}\,e_{J_{v,q},k}\,X_{i,k,h}\pmod 2
  \qquad(1\le p,q\le d,\; 1\le h\le s).
$$
Pad the $d^2s$ bits in this word to $w_L$ with fixed zeros. Apply the same construction to $Y$ with the two internal indices exchanged in the final word. Thus the encoded column array is the transpose of the encoded row array exactly when $Y=X^{\mathsf T}$. Indeed, the display commutes with transposition after the index exchange. Any nonzero difference has a nonzero original row. After encoding along that row, more than $(1-\varepsilon)L$ columns have a difference in some bit of a grouped symbol. For each such column, encoding down the other axis creates differences at more than $(1-\varepsilon)L$ row positions. More than $(1-\varepsilon)^2L^2$ final words differ. Every encoded pair is therefore inside the machine's promise.

The encoding can be attached to a head-record network at a cost of $O_\kappa(t)$ vertices. On each original input row one local table computes the entire within-row encoding of length $Lds$ bits from its $ts$ bits. To encode down the other axis, apply one copy of the $O(t)$-wire binary circuit to the $t$ resulting vectors, operating independently on every one of their $Lds$ lanes in each local table. Gather the $d$ selected vectors per output row, add the fixed suffix to each word and render that row's DIMACS section. Use the same operations for the physically column-ordered half, including the within-word index exchange. The original $2t$ terminals stay distinct. Bundles throughout have width $O_\kappa(ts)$, since $L=8t$, $d$ is fixed, and $s=\Theta_\kappa(\log t)$. These are nonuniform local tables in the lower-bound network. The running time of an external tape program for the encoding plays no role in the composition.

Set $V_0=t^2s$. After composition every unequal original pair maps to a promised SAT file and every equal pair to a promised UNSAT file. Apply the word-entry and hash arguments at the **original** terminals. The field required by the hash exists with $b_0=ts=\Theta_\kappa(t\log t)$ bits per symbol. The physical tape block length is $Lw_L=\Theta_\kappa(b_0)$, so the head-record count has logarithm $o(V_0)$ at the asserted deadline. For any $\rho,\eta>0$ with $\rho+\eta<1-1/\sqrt2$, outside a $2^{-\rho V_0}$ fraction of original row messages both the diagonal input and at least $2^{\eta V_0}$ distinct promised far column inputs are late, using the same slack in $\rho$ as above. Injectivity makes these distinct physical files. At an arbitrary sufficiently large byte length take the largest dyadic $t$ for which the file at side $8t$ fits and pad the fixed separator. The physical length is $\Theta_\kappa(V_0)$ and adjacent canonical lengths have bounded ratio. This establishes the gap bound at each such byte length. At this stage the row fraction refers to the $2^{V_0}$ encoded row arrays.

### Counting late partners across all physical arrays

Put $W=L^2w_L$ and let $\mathcal C$ be the binary linear image of the row encoder. Add any fixed ambient mask $Z$ to its output and $Z^{\mathsf T}$ to the column encoder's output, using bitwise XOR. The diagonal condition and word distance are preserved. The masks can be fixed in the tables rendering the corresponding rows or columns, with identical vertex and width bounds for every $Z$. Each such row coset therefore has exceptional fraction at most $2^{-\rho V_0}$ with the same deadline constant. The cosets partition all $2^W$ physical row arrays. This gives the same exceptional fraction across all rows, though the exponent so far counts original message bits.

In fact, for every fixed $0<\kappa,\lambda<1$ there are constants $c,\gamma>0$ such that all but a $2^{-\gamma W}$ fraction of the **physical** row arrays $A$ have a late diagonal and at least $2^{\lambda W}$ distinct late column arrays at word distance at least $\kappa L^2$ from $A^{\mathsf T}$. The deadline is $cn\sqrt{\log n}$ at every sufficiently large byte length. To prove this, choose $\kappa'$ strictly between $\max(\kappa,\lambda)$ and $1$ and construct the preceding code with relative distance greater than $\kappa'$. Keep fixed positive $\rho,\eta$ with $\rho+\eta<1-1/\sqrt2$. We may increase $d$ until $\kappa'-(1-\eta)/(64d^2)>\lambda$.

Choose independently and uniformly an invertible binary linear map on the $w_L$ bits at each physical cell $(u,v)$, and write $\Phi$ for their product. Use exactly the same cell map at $(v,u)$ on the column side. These maps preserve equality and word distances and can also be fixed in the rendering tables. For each $\Phi$, applying the coset argument to $\Phi(\mathcal C)$ shows that all but a fraction $p=2^{-\rho V_0}$ of ambient rows have a late diagonal and at least $2^{\eta V_0}$ late far partners in their matching coset. Averaging over $\Phi$, all but a fraction $2p$ of rows enjoy these properties for at least half the choices. Fix one such row. The expected number of late far partners $B$ with $D=B^{\mathsf T}\mathbin\oplus A\in\Phi(\mathcal C)$ is at least $2^{\eta V_0-1}$.

For any fixed nonzero ambient $D$, its inclusion probability is zero when its word weight is below $\kappa' L^2$. For each $z\in\mathcal C$ of the same nonzero support as $D$, independent cell maps send $z$ to $D$ with probability $(2^{w_L}-1)^{-|\operatorname{supp}(D)|}$, since invertible maps act transitively on nonzero words. A codeword with different support has probability zero. A union bound over the $2^{V_0}$ codewords bounds inclusion by $2^{V_0}(2^{w_L}-1)^{-\kappa' L^2}$. Summing this upper bound over all late far partners of the fixed row and comparing with the expectation shows that their number is at least
$$
  2^{-(1-\eta)V_0-1}(2^{w_L}-1)^{\kappa' L^2}
  =2^{\kappa' W-(1-\eta)V_0-o(W)}.
$$
Since $V_0/W\to 1/(64d^2)$, this exceeds $2^{\lambda W}$ and the exceptional fraction $2p$ is at most $2^{-\gamma W}$ for some fixed $\gamma>0$. The deadline constants throughout are uniform in the masks and cell maps. The exponent $\lambda$ can be arbitrarily close to one for a correspondingly chosen deadline constant. A constant fraction of all columns need not be late.

At the endpoint $\kappa=1$ a deterministic machine can compare just the two words at $(0,0)$ in one scan of the promised file. If they agree the promise forces equality, and if they differ the answer is SAT. Thus this endpoint has an unconditional $O(n)$ algorithm.

The late partners can still have vanishing density. On canonical files a deterministic tape machine can remember the entire first row of $A$ and, while scanning $B$, compare its stored words successively with the first word of each incoming column. The $t$ comparisons and the complete layout scan take $O(n)$ time. A mismatch certifies SAT after the canonical syntax checks pass. On other files, or if this test sees no mismatch, run any total solver. For each canonical $A$ the fraction of all $B$ reaching that fallback is at most $2^{-tw}$ on the canonical domain. Thus no positive constant lower bound on the fraction of late columns in each row is possible for all deciders, even in the no-ports case.

## Matching upper exponent on the promised files

There is one deterministic multitape algorithm taking $n(\log n)^{1/2+o(1)}$ time on the canonical equal and unequal inputs in this construction. Parse the records and strip the tags, leaving two arrays of $w$-bit words in their incoming orders. Optionally verify the canonical layout and fall back to a complete solver on other inputs. Widths, position counters and expected identifiers can be generated and compared in $O(\log t)$ tape steps per record on dyadic sizes. To use the upstream **binary** transposer, attach to each bit its index $0,\ldots,w-1$ within the word. Group by index stably by radix sorting these small tags in $O(V(1+\log w)^2)$ tape steps. Corresponding bit planes now occur in the same order. Transpose each $t\times t$ binary plane of $A$ and compare it with the next plane of $B$. Rewinding the fixed working tapes across uses costs at most the same order as the work already spent. The upstream upper bound is unconditional. Thus the promised problem has conditional optimal logarithmic exponent $1/2$. This is an upper bound on the explicit family. [Upstream transposition upper bound](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-integer-multiplication-on-tapes-November-24-2026/build/intro.tex#L54-L84)

Bounded-error tape checking on this promise has a linear-time alternative. Draw $t$ independent fair bits $u_i$. While reading $A$ row by row, XOR each row with $u_i=1$ into one $tw$-bit work array, restarting that work tape for each row. While reading the second array compute its corresponding $w$-bit weighted sum for one column at a time, scanning $u$ from its start for each column. Compare each column sum to its stored counterpart. All scans and resets together cost $O(V)$ on a fixed number of tapes. Equal arrays always pass. If they differ, at least one fixed output bit is a nonzero linear form of $u$, so the probability of a false equality is at most $1/2$. Independent repetitions reduce this at constant overhead. The conditional lower bound uses exactness essentially. [Related matrix fingerprint principle, Freivalds](https://doi.org/10.1007/3-540-09526-8_5)

A word RAM stores the first records by coordinate and compares the second records in incoming order, in $O(t^2)=O(n/\log n)$ steps on the canonical lengths; each fixed-width digit string occupies a constant number of native words. Thus these instances cannot supply a superlinear RAM time bound. The conditional tape statement imports the geometric and entropy arguments of the November 24 preprint. Its 2-CNF application, word accounting and timeout-list argument are manuscript proofs; the Lean file verifies the implication chain. Priority of the specific decision corollary has not been established.

## What can be recovered from a single head record in the ports case?

There is an unconditional way to fill in every missing matching pair using one deterministic record. Its coefficients expose a further requirement for an exact tensor identity. Assume for this paragraph that *all* equal inputs receive UNSAT by time $T$. Pad halted runs to that time. The sets of row inputs for the different equal-pair records partition $\{0,1\}^V$. Some record has a nonempty set $G$ of density $\delta\ge 2^{-O_M(1+T/b)}$. Its rejecting-run network is exactly
$$
       F(A,B)=1_G(A)1_{B=A^{\mathsf T}} .
$$
All off-diagonal inputs have coefficient zero by correctness, and determinism gives a single history of weight one on each matching input with this record. A particularly dense record on which *some* equal inputs are fast suffices with the corresponding $\delta$.

Choose independently $K=\lceil(V+1)/\delta\rceil$ uniform $V$-bit shifts. For each $A$ the probability that none of $A+S_j$ belongs to $G$ is at most $e^{-(V+1)}$. A union bound over $2^V$ choices fixes a covering list. Sum the translated network $F(A+S_j,B+S_j^{\mathsf T})$ over the index $j$. Each row and column terminal can apply its own portion of the shift from a fixed local table. A bounded-degree copy tree carries the same index to all $2t$ terminals, and the root can disallow unused indices. This adds $O(t)$ vertices and $O(\log K)$ bits of width. At $T\le V\sqrt{\log t}$ we have $\log K=O_M(T/b+\log V+1)=O_M(b)$. The result has strictly positive rational coefficients on **every** matching pair and zero everywhere else. This counts vertices with wide bundles and arbitrary local tables. Expanding a terminal into binary trivalent tables can cost much more.

Exact scalar normalization is possible in the same size when the record indicator has sufficiently sparse Fourier support. Write the rational Walsh expansion of $1_G$ on the $V$-bit cube and let $s$ count its nonzero coefficients. Choose $d=\lceil\log_2(s+1)\rceil$ independent uniform generators in the cube. For each nonconstant character, the probability of annihilating all $d$ generators is $2^{-d}$. A union bound fixes generators for which no nonconstant character in the support survives averaging over their binary combinations. The resulting average is exactly $\delta$ everywhere. The terminals need only the shared $d$-bit index to look up their parts of its shift. After scaling at the root by $1/\delta$, the network has coefficient one on every matching pair. Thus $\log(s+1)=O(b)$ suffices here. No bound of this strength on the Fourier support of an arbitrary fast record has been established.

Density alone cannot supply that exact normalization by a weighted sum of few shifts. Take $G$ to be the cube with just the zero vector removed. For arbitrary signed rational weights, let $\lambda_S$ be the total weight of shift $S$, zero if unused, and $z=\sum_S\lambda_S$. The diagonal coefficient at $A$ is $z-\lambda_A$. To be the same nonzero number for every $A$, all the $\lambda_A$ must agree. If any one is zero they are all zero, which gives zero output. Hence every one of the $2^V$ distinct shifts is necessary in this additive construction, although two distinct shifts already cover the whole cube. This example allows more general nonlinear constructions: for instance two translates with full union have an exact Boolean OR. An exact single transpose also differs from the list-distinctness tensor in the unconditional circuit lower bound. Applying a lower bound in the ports case still requires the correct target tensor and the relevant cost for its local maps.
