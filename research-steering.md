# Steering the SAT lower-bound project

**28 November, the frame value on round-robin ladders.** On the round-robin overwrite ladder with C cells and T steps the frame value is at least C·log₂((T+C)/(4C)); with the cone-restricted bisection it is therefore C·log₂(T/C) ± O(C), and Θ(C·log(T/C)) once T ≥ 8C. This answers, for round robin, the question both frame-game notes left open; other ladders touching C cells can have value O(C + log T). The proof transfers the Challenger of Chan, Lauria, Nordström and Vinyals's Lemma 4.5 (arXiv 2305.19104) to the frame game, with the upper-bound note's Lemma 5 in place of their Lemma 4.3 and a potential for pebbles carried into each new focus; every step was re-derived during review, and independent reimplementations of the Challenger and of the closure check found no failure. The result concerns one move class of truth-claim games and says nothing about time or SAT. [Round-robin ladders](notes/frame-value-on-round-robin-ladders.md)

**28 November, a 50-instruction decider for the padded table-index family.** A fixed five-slot program of 50 stored instructions decides, in linear time, the padded, translated table-index family F5 that the five-slot proof uses, when the tree clauses list their literals in the theorem's displayed order (a second 50-instruction program handles the other order). It takes at most 16.62 steps per file word on the timed files and is correct for every t by a manuscript argument, checked at t = 5 to 12 with CaDiCaL agreeing on every file it was run on. A 107-instruction dispatcher decides six of the fooling families built so far. The program's stores escape the bound K ≤ 2^{|B|} of W5's lemma, not the private-probe count, so there is no contradiction with the five-slot theorem; this is not a time bound for SAT and marks where the fooling-family method stops. [Padded table-index family](notes/a-50-instruction-program-decides-the-padded-table-index-family.md)

**28 November, RAM time T in word-priced alternating time O(T/log log T).** On the native-band RAM, DTIME_RAM[T] ⊆ ATIME^word_RAM[O(T/log log T)] for T ≤ m^6 computable in O(T/log log T) steps, with word-priced guesses, unboundedly many alternations and no bit-priced gain. The chain is a seeded write-once array (packed presence tables on composite keys hashed by a degree-2 polynomial modulo a prime, expected O(n(1 + log n/log w)) word steps on every fixed sequence), a write-once normal form, and a truth-claim game whose loads name their writers, each checked during review, with Dymond–Tompa's Lemma 1 read at source; Paul–Tarjan–Celoni's recurrence solution is cited and the word steps are argued, not instrumented. It meets the normal-forms note's condition g = o(log T). Consequence (A), A_RAM ∉ DTIME_RAM[o(N log log N)], would give target (U) in a stronger form but is a proof outline whose width bookkeeping is not yet written; it is not (K), not the milestone, and not about SAT. Novelty is not established. [Seeded write-once array](notes/ram-time-t-in-word-priced-alternating-time-t-over-log-log-t.md)

**28 November, why the round-five attempts stopped.** The round-five attempts that produced no separate note are recorded, with the exact reason each stopped. A static certificate checker certifies the verdict of a stand-in for the description-first opponent, but the standing opponents need identities of their own, and a self-referential opponent shows that a coverage theorem needs reflection; one shared transition table in the compiler is a control; guessed fields in memory make the truth-claim game unsound; the switching-lemma induction gives only product-form parity bounds for k-block opcode verifiers, and that form is the method's ceiling; the two-block density statement is exact on the chain only; a transfer-matrix game folded into two blocks cannot tell runs apart; a Σ₂ counting barrier holds only for queries that cannot read the structure; a one-instruction computer changes nothing on the program-size line; a sound digest is an injective fingerprint, and landmark sets of expected size O(m/log Q) cap the cones of the chained overwrite table at Q; and nine versus ten ANDs is down to a few open first-gate orbits. The note closes with the idea generator's own judgment that the loop has stopped producing steps toward the target. [Round-five attempts](notes/parallel-proof-attempts-of-28-november-round-five.md)

**28 November, a write-once array with packed presence tables.** On the random alternating workload, model W has a deterministic array scheme with one register between operations whose expected amortized cost is O(log m / log w) loads plus writes per operation, so with the write-once note's Lemma A′ the amortized cost is Θ(log m / log log m) at w = Θ(log m); Lemma A's worst-case form is not matched, since one merge writes Θ(min(n, m)) cells. Correctness and W-legality hold for every sequence and the cost bound for the random workload only, checked by an instrumented simulator up to m = 2^23 and by an independent simulator written during review; arbitrary sequences need a hashed seed and are open. The gain is asymptotic only, and nothing here bounds SAT. [Packed presence tables](notes/packed-presence-tables-for-a-word-write-once-array.md)

**28 November, one-verdict loops, exit code and LOAD loops without arithmetic.** A LOAD loop with no numerical instruction loads only original words, the address it has just read, or boundedly many stored values, so on the property-1 base it reads a bounded set of addresses; this phase lemma, with its hypothesis on memory at the loop's entry checked class by class, excludes all 18 two-loop classes of the six-instruction map. Lemma E (one-time code only after the exit or on a bypass, opening the one-site theorem's proof) and Lemma V (a LOAD loop that reaches only one verdict) exclude 12 of the 22 one-site classes, while the other 10 keep 23,832 graphs with one-time code before a two-verdict loop; Lemma V also excludes 7 of the 33 five-slot-schedule classes. The map moves from 932/73/14 to 969/36/14, checked during review by an independent enumerator. The lemmas are manuscript proofs, and nothing here is a time bound. [One-verdict loops and LOAD loops without arithmetic](notes/one-verdict-loops-exit-code-and-load-loops-without-arithmetic.md)

**28 November, even multipliers with odd strides at every speed.** Under native initialization, every six-slot scan x = M[p]; M[x] ← a·p; p += d with an even literal multiplier (or a = w, or a = n when D ≥ 2) and an odd literal stride fails on the equality files at every speed: for each member, at every large enough length where gcd(3K+4, |d|) = 1 (always for d = ±1, ±3) and, at D = 1, outside one exceptional interval, some unequal file runs identically to an equal one. Odd addresses outside the file's palette are never written, and both sign words recur at such addresses after the flipped cell, so the two stamps are overwritten alike before they are read. So the even-multiplier note's clock bound is vacuous in these cases. The conditions are sufficient, not necessary; even strides (where the method provably fails for a = d = 2) and the other payloads of the generic corollary stay open. No class of the six-instruction map changes status; nothing here is a time bound. [Odd strides at every speed](notes/even-multiplier-scans-with-odd-strides-fail-at-every-speed.md)

**28 November, an upper bound for the frame game on overwrite ladders.** On every overwrite ladder touching C ≥ 2 cells, a bisection that cuts only the ancestors of the claim currently challenged wins the frame game within C·log₂(T/C) + 2C + 2log₂C + 2 placements, so the frame value is o(T) whenever C = o(T). With the lower bound C − 1, a ladder family has frame value at least c·T at every T exactly when liminf C(T)/T > 0. This settles negatively, for the frame game, the conjecture left open for ladders touching o(T) cells. It bounds the frame game only: the interval game cuts whole layers and is worth C·⌈log₂T⌉ on round robin at every size computed, and the node game is not covered. Open: whether the frame value is Θ(C) or Θ(C·log(T/C)) when C = o(T). [Frame-game upper bound](notes/frame-game-upper-bound-on-overwrite-ladders.md)

**28 November, reading vertex tables through prices.** An external review suggested reading the network's vertex tables through prices for the fixed-B slices. The vertex-site price inequality (P) behind the list-distinctness technique, and its single-vertex dual (D) that charges each vertex the price of its own table, both cap at O(N log N): one Beneš graph with N(6 log₂N − 3) edges passes (P) at every placement and (D) with all-GHZ tables, for every N-leg target over every field, and every 2×2×2 table over a finite field is dominated by GHZ at every spectral point (checked exhaustively over F₂ and F₃, and over F₅ during review). So "B⊕B not a subspace" is invisible to them; this is the general form of the technique-ceiling note's Lemma 2. Open escapes: price inequalities with multi-vertex pieces, and diagonal counting as in the upstream batch bound. Nothing here is a lower bound. [Price inequalities](notes/the-price-inequality-and-its-table-reading-dual-cannot-certify-more-than-n-log-n.md)

**28 November, odd multipliers in the six-slot scan.** Every six-stored-instruction program x = M[p]; M[x] ← a·p; p += d with an odd literal |a| ≥ 3 and a literal stride, in any data order, that answers every equality file correctly needs Ω_{D,d,a}(N^{D+1/2}/log²N) steps on some satisfiable equality file, and Ω_{D,d,a}(N^{D+1/2}/log^{3/2}N) for a ≤ −3 and for the lookbehind payload. The key lemma bounds increasing runs of i ↦ a·i + c mod L by (a+1)(⌊log_a(L−1)⌋+1) for a ≥ 3 and by |a|+1 for a ≤ −3, so last-writer chains advance O(R) links per pass. With the even-multiplier and communication notes, every literal or public-word multiplier with a literal stride now has such a bound. The even-multiplier note's §8 sketched the route; the proofs and checks are new, including an independent machine simulation during review (11.3 million reads, 0 violations). Clock-only, conditional on correctness and possibly vacuous; no class of the six-instruction map changes status. [Odd multipliers](notes/odd-multiplier-stores-in-a-six-slot-scan.md)

**28 November, the alternation dichotomy for DIMACS SAT.** The alternation criterion of the alternating-speedup note, stated there only as an implication, is now stated and proved as an unconditional dichotomy with explicit parameters: either no O(N)-time program decides DIMACS SAT, even only on the rendered compilations of native instances, or for every k and every alternating program some prefix of the diagonal J has no sequence of good extensions of growing length along which (n + s + b)·L^{3k}/n² → 0. Forms are given for SAT time N·log^a N (exponent (3 + a)k), for classes (correct but conditional and not new) and for the native milestone. It is a precise restatement for citation, whose only new step is Lemma B, rendering the binary encoding as ASCII DIMACS at O(1) per literal so that the exponent stays 3k. Banked at an external review's suggestion and checked during review; not progress on the open problem. [Alternation dichotomy](notes/alternation-dichotomy-for-dimacs-sat.md)

**28 November, the Weisfeiler–Leman time bound and the compiler route.** An unrefereed upstream preprint (September 2026) proves that k-WL equivalence needs n^{ck} time on the log-word RAM at every large order for explicit matrices (the proof's constant is c₀ = 10⁻⁹; c and k₀ are existential), by the deterministic time hierarchy plus a compiler from a deterministic one-tape run into the bijective pebble game, with one non-adaptive round of cutoff calls and no quantifier elimination. For SAT the same step needs the existential player: a compiler short and fast enough to exclude O(N^{k₀})-time SAT gives a one-block procedure for the diagonal J in o(n²) steps, and for k₀ = 1 it sits between strong and weak forms of the journal's open one-block speedup premise, which restates the diagonal-only compiler criterion of round three and the black-box routes note; for k₀ = 2, 3 it needs a polynomial one-block speedup. If correct, the preprint is a second instance, beside the forecast theorem, of the hierarchy-plus-succinct-compiler template. Raised by an external review; the TeX source was read in full but not refereed; nothing here is a SAT bound. [WL time bound](notes/weisfeiler-leman-time-bound-and-the-compiler-route.md)

**28 November, unique-witness verifiers for SAT.** The journal's RAM-trace simulation is unambiguous and total, so a deterministic SAT program running in time T gives unique-witness verifiers for SAT and for UNSAT of size O(T log² N). The quadratic exact-network construction loses uniqueness: over F₂ its witness count is the parity-OR count 1 + ∏(1 + c_j), so its ceiling, O_p(N²) over each fixed field, caps fixed-field volume and parity size but not the unique-witness size U(SAT), which has no known polynomial cap (one would mean NP ⊆ UP/poly in circuit form), while U(UNSAT), nondet(UNSAT) and TU(SAT) have none unless coNP ⊆ NP/poly. The absence of a known cap is not evidence for a lower bound. For the linear milestone the only addition is that a lower bound on U(UNSAT) also suffices. The named next step, a characteristic-zero network bound, concerns a family that RAMs solve quickly and has three unverified dependencies, among them whether ℚ has no ports. Raised by an external review and checked during review; nothing here is a lower bound. [Unique-witness verifiers](notes/unique-witness-verifier-size-of-sat-and-unsat.md)

**27 November, a frame-game lower bound on overwrite ladders.** Every black pebbling of the frame DAG of an overwrite-ladder run touching C cells holds at least C pebbles at some time, by an induction over the chains that carry each cell's initial value, so the frame game of round three's truth-claim entry has value at least C − 1; on the round-robin ladder that is ⌈T/2⌉ − 1, which settles that entry's restated conjecture for the frame game in its existential form, witnessed by ladders touching a constant fraction of T cells. For ladders touching Θ(T/log T) cells the bound is o(T) and the conjecture stays open. C + 1 pebbles always suffice, so black pebbling can give no more; by Chan's theorem the game value plus one is the reversible pebbling price (checked by exhaustive search on the 64 table instances with T ≤ 9), and on the round-robin ladder the reversible numbers are about T at T ≤ 10, so T − o(T) needs an argument specific to reversible pebbling. A node-game bound (T − 1) − max(P* − 1, 0) is included. Checked during review with independent solvers; a bound inside one move class, not a time bound. [Frame-game lower bound](notes/frame-game-lower-bound-on-overwrite-ladders.md)

**27 November, mutable arrays on write-once memory.** In model W (w-bit cells written at most once and never loaded before written, O(1) registers, a public clock), a mutable array of m words has read cost Ω(log m/log(w·t_u)) when each update writes at most t_u cells, and amortized cost Ω(log m/log log m) per operation on a random alternating workload when w = Θ(log m), by a routine instance of the Fredman–Saks chronogram whose one W-specific step is that an address the decoder does not know must be a cell written in the epoch. So an online conversion of a RAM run into write-once form followed by pebbling gains at most an O(log log t) factor on average; offline conversions with look-ahead are not covered, and Irani–Naor–Rubinfeld's t·log t/log log n simulation is bit-write-once and does not apply. Whether the log log gap is real is open. Manuscript level, checked during review; the bounds are asymptotic (from m = 2^266) and not a time bound for any language. **27 November, black-box routes through the diagonal compile.** In a black-box model of the compiler criterion with hidden clause signs, deciding the verdict of a compiled formula of M bits costs Ω(M·log^a M) solver charge on Tseitin structures, so under linear SAT no route through the model passes compile length o(s); the bound is matched on files without repeated clauses. ## Where the hierarchy proof stops

In the direct simulation, a configuration with $S$ live words costs $\Theta(S)$ words to specify. With $P$ candidate segments, the input to the error checker contains $\Theta(PS)$ words and its replay takes at least the simulated segment's allotted time. Nesting improves the balance while the snapshots fit. It gives no saving when even a single snapshot can cost the whole time budget. For a linear-time RAM the elementary cap is $O(n)$ touched words, or $O(n\log n)$ bits. That is $b=-1$ in the notation of the band. A candidate unrestricted speedup must account for reconstruction and checking of memory read by a later segment when earlier segments wrote to arbitrary addresses. A new small-space *simulation* would have to retain the time bound required by the hierarchy argument.

PPST separated deterministic and nondeterministic linear time on multitape Turing machines. Williams proved a time-to-space simulation on tapes. Strassle and Subercaseaux give a deterministic simulation of nondeterministic tape time. These are model- and resource-specific statements. There is also a genuine pure-space consequence for RAMs: Li and Tell record Williams's observation that quadratic simulation by one tape followed by a two-fifths-power space simulation gives about $t^{4/5}$ space up to logarithms. The derivation supplies no corresponding near-linear time bound. [PPST](https://trotter.math.gatech.edu/papers/34.pdf) · [Williams](https://arxiv.org/abs/2502.17779) · [Strassle and Subercaseaux](https://arxiv.org/abs/2611.11832) · [Li and Tell, §1 footnote 1](https://eccc.weizmann.ac.il/report/2026/233/download/)

The decoded-snapshot and producer proofs give such speedups for two classes of random-access executions that can touch large memory. Extending their coverage to every fast solver remains the prerequisite for this route. A proof must certify that every imported word has the value of its last write and pay for this certification in the saved clock. A construction for a strict subclass should identify how an unrestricted solver could escape it. The hierarchy is one route to a contradiction; the gate also admits a different unconditional theorem with a proved transfer.

Ordinary SAT in the stated explicit encoding can guess an assignment and check the formula in linear word time. Excluding a deterministic linear-time solver would therefore also separate nondeterministic from deterministic linear time on this RAM. Quasilinear completeness in the opposite direction loses logarithmic factors. A lower bound for an arithmetic circuit or for permanent-graph decision trees likewise needs a separate, costed transfer to Boolean SAT. [SAT transfer and its logarithmic losses](https://lance.fortnow.com/papers/files/tst.pdf) · [Permanent-graph analysis](notes/pr249-grid.md)

The cumulative sum of shortest description length plus query time now excludes every exponent below $1.3760858894\ldots$ unconditionally. Under linear SAT there is an interval of $\Omega(n/\log^8 n)$ times with additive query cost $\Omega(n/\log^{12} n)$ at every time.
