# Two and three states on a common SAT witness

Fix a complete, layered reader of Boolean witness bits. At a layer it reads the indicated bit and moves to the next layer. An absorbing rejection state counts toward its width. Witnesses are assignments to the occurring names unless an explicit ambient set is supplied.

* A two-state reader with $L$ layers over $v$ names admits **exact model counting** in $O(L+v)$ word operations if the address read at each layer is independent of the state. Names can repeat in any order. If the two states may name different bits at the same layer, the bound is $O(L+v\log(v+2))$. This is linear in an ordinary explicit encoding that writes all occurring names. The RAM can output the binary count.
* With three states, two readers on a common witness suffice for the unrestricted SAT time question. Each reads **every witness bit exactly once**, in a fixed order independent of the input at that length. The entire second reader, including its transitions, is fixed. There is a total language of packed controls for the first reader that reduces to and from ordinary ASCII 3-SAT in deterministic linear time and linear encoded length. A single three-state reader can also execute both passes, reading every bit exactly twice.
* One two-state oblivious reader can be intersected with a deterministic read-once reader of any fixed width $d$, in a different order, in $O_d((L+v)\log(v+2))$ word operations. This includes witness recovery and counting modulo any fixed modulus. With explicit fixed-width name fields and all $v$ names occurring, the decision and modular-counting clock is linear in encoded bits.

The width refers to the device checking a proposed witness. A deterministic RAM searching for a witness has unrestricted workspace in all three statements. For the three-state control language, a worst-case RAM lower bound at the linear, quadratic or cubic deadline would transfer to SAT at that same deadline. These reductions leave that lower bound open.

## Counting by the last reset

For any fixed assignment, a step of a two-state reader is one of four unary functions. Identity and flip are the permutations. The other two maps set the state to zero or to one. Every run has a unique last reset, or has no reset. On the suffix following a last reset, the final state equals its reset value XOR the parity of the flips. The no-reset case uses the initial state instead. Lean proves that the acceptance indicators of these cases sum to the indicator of the actual verdict for every assignment, including repeated names and state-dependent addresses. Width-two decision-list representations have a long history. [Lean proof](LastResetWitnessReader.lean) · [Bshouty, Tamon and Wilson](https://doi.org/10.1016/S0020-0190(97)00204-4) · [Gopalan, Meka, Reingold, Trevisan and Vadhan, Theorem 6.13](https://eccc.weizmann.ac.il/report/2012/123/download)

Sweep the rows backwards. For each name $i$ and bit $b$, record whether $x_i=b$ permits every already scanned occurrence of this name to act as a permutation. If it does, retain the XOR of the flips from those occurrences. The allowed suffix words form a product of unary domains. Keep the number of empty domains, the number $f$ of two-choice domains, a baseline parity from one allowed choice in each nonempty domain, and the number of two-choice names whose two contributions differ. A change to one domain updates all four quantities in constant time.

For each allowed value at the current name that makes this row a reset, temporarily pin the name and count suffix assignments attaining the required parity. If a domain is empty, this contributes zero. Otherwise an attainable target has $2^f$ assignments when all contributions are fixed, or $2^{f-1}$ when a flexible parity remains. Restore the variable and permanently update its two entries to allow only current permutations, adding their flip bits. After all rows, process the no-reset case. Accumulate contributions in a histogram indexed by exponents. Its entries and all carries are $O(L+1)$ because there are at most $2L+1$ contributions. One final pass through $v+1$ positions produces the exact binary count. This avoids treating a $v$-bit integer addition as one RAM step. [Implementation and exhaustive test](fixed_order_witness_reader_audit.py)

### When the read address depends on the state

At row $i$ let $A_i(x),B_i(x)$ be the successor bits from states zero and one. Each is a signed witness bit or a constant, possibly on different names. For this assignment, the row permutes exactly when $A_i+B_i=1$ over $\mathbb F_2$, adding flip $A_i$. A reset has $A_i+B_i=0$ and writes $A_i$.

Maintain the system of inequality equations for the suffix already scanned and its affine flip sum $P$. Replace $P$ by $P+A_i$. Temporarily impose $A_i+B_i=0$ and count solutions with $P$ equal to the target. Restore and permanently impose $A_i+B_i=1$ to continue. A contradictory permanent system rules out every longer permutation suffix. At the beginning of the program the remaining phase must equal the target XOR the initial state.

These two-variable equations describe components in which each bit equals its root bit plus a fixed offset. One can keep a distinguished constant root, or use the gauge convention in the implementation. Store the reduced affine phase as one coefficient per free root and one constant. Merging two roots substitutes one root into the other, updating the support size and the constant in constant time once their offsets are known. A consistent system with $f$ free bits has either zero or $2^f$ solutions to a constant phase test. A nonconstant phase test has $2^{f-1}$ solutions. The trial equality needs only the hypothetical root counts and phase changes. Only the permanent merges relabel actual members. Moving the smaller component on every merge gives $O(v\log(v+2))$ total member moves and $O(1)$ time per row apart from these moves. The histogram finishes as before. The audit checked full last-reset histograms for 56,860 small programs, 700 additional programs and both choices of initial and target states. [State-dependent implementation and tests](state_dependent_reader_count.py)

A reader with additional uncounted early halts represents a different state space. In the hard construction below, rejection that persists through all future layers consumes the third state. This distinction matters when comparing width-two satisfiability results that allow sinks at intermediate levels. [Makita et al., model definitions in Section 2](https://doi.org/10.1587/transfun.2021EAP1120)

## A second reader in a different order

Keep the unary suffix information from the oblivious two-state sweep. For each name in the second reader’s order, build a Boolean relation on pairs $(q,p)$ of a state of that reader and a parity bit. For each locally allowed $b$ include the transition from $(q,p)$ to $(\delta(q,b),p+e_i(b))$, where $e_i(b)$ is the accumulated first-reader suffix contribution. Give omitted names identity action on the second state, each with its own leaf. The product of these $v$ relations gives the possible second-reader outcomes and total parities. A pinned last reset, its restoration, and the permanent update each change only the leaf of the current name. A balanced product tree recomputes $O(\log(v+2))$ constant-size nodes per change. The root answers each candidate. Once a successful case is found, tracing a compatible intermediate state at each node recovers one witness in $O_d(v)$ time. For modular counting sum transition multiplicities over the residue ring, then sum disjoint last-reset cases. Keep Boolean feasibility separately when a witness is required. The deterministic second reader contributes one path per assignment. [Mixed-order audit](mixed_order_reader_audit.py)

There is another bound when several readers may all reuse names. Intersecting any fixed $r$ oblivious two-state readers has an exact counting algorithm costing $O_r(v+\prod_i(L_i+1))$ word steps, where $L_i$ are their lengths. In particular two or three required final states fit the quadratic or cubic deadline respectively on a compact name schedule that can be expanded within that budget. The proof maintains attainable parity vectors across the readers. [Simultaneous final-state calculation](simultaneous-final-states-of-two-state-witness-readers.md)

## A fixed three-state pair for unrestricted SAT

The input at a scale with $R$ lanes is the journal’s packed control string for a Beneš network. It selects equalities between adjacent input lanes, straight or crossed settings at switches, signed enabled ternary clauses on designated output lanes, and optional output pins. Every setting is legal. Its length $M$ is $\Theta(R\log R)$ bits. The known forward translation normalizes an explicit formula, groups its occurrences by name, and computes switch settings by alternately coloring the cycles at each stage of the recursive permutation network. The reverse translation propagates equality-group identifiers through the given switches and prints only the resulting clauses and pins. Both translations cost linear time and bits in their respective source lengths. In particular, the reverse translation pays for the names in the output. [Original control language, both reductions and model correspondence](fixed-routing-controls-and-the-unrestricted-sat-clock.md) · [Beneš network setup](https://www.cise.ufl.edu/~sahni/papers/BenesNetwork.pdf)

Give every lane segment its own Boolean wire. For each switch with input wires $a,b$ and outputs $u,v$, reserve four candidate equalities between input and output wires. Enable either $a=u,b=v$ or $a=v,b=u$. Reserve two binary clauses for each candidate equality. Also reserve rows for each possible left equality, right pin, and signed right clause. A disabled row imposes no constraint. The sequence of variable names in these slots is fixed at each scale. Only signs, enables and pins depend on the control string. Each left-lane valuation has exactly one assignment to the internal wires respecting the enabled switches.

Now give **each literal occurrence its own witness bit**, including disabled slots. The first reader visits occurrence bits in clause order. Its states record an unmet row, a row already met, and persistent rejection. At the last bit of each row it either starts the next row with the unmet state or irreversibly rejects. Disabled rows always pass. The second reader visits the very same bits grouped by wire identifier. It remembers the group's first bit as zero or one and enters its third, rejecting state on a mismatch. At a group boundary the first input of the next group sets the remembered bit again, provided the reader has survived. Thus this reader and its visiting permutation are fixed by $R$ alone. A common accepted word is exactly a consistent occurrence expansion of an accepting wire assignment. All wires occur. Each satisfying wire assignment has precisely one expansion, even in slots whose row test was disabled. Lean checks the clause reader, the consistency reader, agreement of their common witness with the original predicates, and the read-once permutations under the stated occurrence hypotheses. [Lean construction](CommonWitnessThreeState.lean)

There are $\Theta(M)$ occurrences. Both orders and all layer transitions can be generated in $O(M)$ word steps by enumerating switch ports in their fixed layout, counting occurrences of each dense wire identifier, and grouping positions by counting sort. The raw input is still the $M$ independent control bits. Writing a fresh $\Theta(\log M)$-bit identifier for every position as part of that raw input would change the length. To concatenate the two readers, carry the first reader's rejection into the second reader's rejection state and start its first group normally on any surviving execution. The resulting repeated scan has only two live states and one common absorbing rejection state. If the fixed equality reader is retained and the row reader is replaced by an arbitrary two-state reader in the first order, substitute the known wire name at each occurrence and use the $O(L+v)$ repeated-name algorithm. The resulting decision is linear even on the compact representation.

NP-hardness of two different-order passes and the trick of making literal occurrences independently named and then testing their consistency are established. The additions here use the existing packed control problem to fix **both** permutations and **all** of the second reader, preserve the encoded-time deadlines in both directions, and give explicit algorithms for the two-state cases. We have not established priority for the combination. [Bollig, Sauerhoff, Sieling and Wegener, Theorem 1](https://eccc.weizmann.ac.il/report/1994/026/download/) · [Feige and Jozeph on universal factor graphs](https://arxiv.org/abs/1204.6484)

The previous routing construction embeds the conjunction of arbitrary child controls when the lane count doubles. This fixed reader pair inherits the same embedding. The last-reset algorithm explains why a finite exhaustion confined to the two-state cases can succeed at every tested length. At width three a bound on actual RAM time for finding a common accepted word is still needed. Checking the word itself already takes $O(M)$ native steps. The test suite checked 5,120 routed input valuations and independently corrupted both complete internal wires and individual occurrences. [Reader audit](fixed_order_witness_reader_audit.py)

Under the stronger requirement of preserving the accepted relation on public assignment bits, existentially hiding bits of one two-state reader with affine successors still gives an affine decision list.
