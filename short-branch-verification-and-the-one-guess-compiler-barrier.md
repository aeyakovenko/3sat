# How many variables must a short RAM-to-3-SAT reduction introduce?

On a logarithmic-word RAM, a proper 3-CNF with `M` encoded bits and `v` occurring variables has a nondeterministic verifier with one upfront block of at most
\[
     (\log_2(4/3)+o(1))v
\]
binary guesses and deterministic checking time \((1+M)\operatorname{polylog}(2+M)\). The error is uniform as \(v\to\infty\). The running time holds on every guess string. This uses the binary and ternary covering codes of the deterministic Schöning algorithm and bounds the work on a single branch, including on high-occurrence variables. [Moser and Scheder, Algorithms 1–2 and Lemma 9](https://arxiv.org/abs/1008.4067)

Salamon and Wehar study limited nondeterminism and bound general CNF witness length in terms of the encoded file size. The calculation here counts guesses per occurring variable for width three. Priority for this precise RAM-resource formulation is unestablished. [Salamon and Wehar, Lemmas 19 and 21](https://doi.org/10.1007/s00224-023-10119-x)

This gives an unconditional obstruction to decision-preserving local compilers at both proposed SAT deadlines. Fix \(k=2\) or \(3\). Give a native nondeterministic RAM a unary clock \(t=g^k\), at most \(g\) initial binary guesses after deterministic setup, then deterministic execution. Let a fixed compiler map each such instance to proper ASCII DIMACS 3-SAT with its acceptance verdict. Require the output length and each requested bit to have deterministic random-access algorithms of time \(\operatorname{polylog}(2+t)\) on the short payloads below. The compiler may change accepting multiplicities arbitrarily.

There exist a fixed native program, a constant \(B\), and, **on each verdict separately**, instances of that program at arbitrarily large \(g\) with public payload \(O(\log t)\) on which its output satisfies
\[
 M>t/(\log_2(2+t))^B
 \quad\text{or}\quad
 v\ \ge\ (1-o(1))\frac{g}{\log_2(4/3)}.
\]
Thus, among compilers with the first term uniformly small, some accepting and some rejecting instances require asymptotically at least \((2.4094\ldots-o(1))g\) occurring variables. Unused header variables give no credit. Each of those outputs uses at least \(8\sum_{j=1}^v(1+\lfloor\log_{10}j\rfloor)\) bits for spelling identifiers. If the length alternative occurs it already exceeds any constant multiple of \(g\log g\) eventually. This improves the [unique-computation compiler test](short-unique-verifications-at-the-three-sat-deadlines.md) for compilers defined on sources with arbitrary branch counts. A compiler defined only on uniquely accepting sources can fall outside the new test.

## A short branch for a satisfiable formula

Intern the occurring decimal names in a digit trie. Construct occurrence lists in file order. Write \(m\) for the number of literal occurrences. Guess first the values of the variables with degree more than \(D=\lceil(m/v)\log_2(v+2)\rceil\), of which there are at most \(v/\log_2(v+2)\). Restrict the formula to these values. Let \(s\) be the number of other variables, including formerly occurring names removed from the formula by this restriction. Handle \(v=0\) directly. All the other guesses described below can be obtained in the same upfront block, since their budgets depend only on \(v,s\).

Take a block length \(b\) divisible by three, tending to infinity as \(\Theta(\log\log(v+4))\), with a fixed positive minimum. For \(q=2,3\) greedily construct a radius-\(b/3\) Hamming cover of the \(q\)-ary words of length \(b\). Each new center covers at least the Hamming ball's density in the remaining uncovered points, by averaging. At most \(1+\lceil b\ln(q)q^b/\mathrm{Vol}_q(b,b/3)\rceil\) centers suffice. Enumerating words and pairs explicitly for each iteration costs \(q^{3b}\operatorname{poly}(b)=\operatorname{polylog}(v+2)\). With \(H\) the binary entropy function, the binary center index costs \((1-H(1/3))b+O(\log b)\) bits and the ternary center index costs \(b/3+O(\log b)\) bits. For the latter use \(\mathrm{Vol}_3(b,b/3)\ge\binom b{b/3}2^{b/3}\). Use integer index widths and reject out-of-range indices when consumed.

Guess one binary center per full block of the \(s\) variables and literal values for its short final block. For any model extending the guessed high-degree values some such center vector has distance at most \(R=\lfloor s/b\rfloor b/3\) from its restriction. Maintain a current vector and radius \(r\), starting at that center and \(R\). Accept whenever an actual assignment satisfying the restricted formula is reached.

* Greedily choose disjoint currently false clauses of width three, stopping at \(b\) or when maximal. If there are \(b\), each has a coordinate on which a fixed nearby model satisfies it. Some ternary center names such a coordinate in all but at most \(b/3\) clauses. Flip the named bit in each of the \(b\) clauses. Disjointness makes the distance decrease by at least \(\Delta=b/3\). Subtract \(\Delta\) from the radius. Reject this step if the radius was smaller than \(\Delta\), which cannot discard the promised branch because \(b\) disjoint false clauses alone require \(b\) changes.
* Otherwise guess the target values on the fewer than \(3b\) variables of this maximal set and restrict them permanently. Every remaining clause false at the old center now has width at most two: an original false full-width clause met the maximal set, and any newly false clause lost a variable. Fix a literal of a currently false clause to true, using at most one guessed bit, and repeat for at most the remaining \(r\) corrections. Each permanent restriction preserves the property that every false clause has width at most two. A nearby model survives some branch: choose its values on the pinned variables, then always choose a literal it satisfies. Every correction consumes a still-unfixed discrepancy from the center. Reject empty false clauses immediately.

After \(j\) full batches at most \(R-j\Delta\) correction bits are needed. A single shared bit pool, parsed adaptively after it was guessed, therefore suffices with \(R(1+O(\log b/b))+O(b)\) bits for the entire repair. In particular the two phases do not each need a separate radius budget. Adding the center and high-degree guesses gives a computable integer bound \(h(v,s)\le(1-H(1/3)+1/3+o(1))v=(\log_2(4/3)+o(1))v\). One explicit repair pool uses \(3b+R+\lceil R/\Delta\rceil\max(0,\lceil\log_2|C_3|\rceil-\Delta)\) bits, where \(C_3\) is the ternary covering code.

For the time bound maintain lists of currently false clauses by residual width, and the current literal truth counts. A flip inspects at most \(D\) occurrences. To build a greedy disjoint batch temporarily remove from the false width-three list all clauses meeting the three variables of each chosen clause, then restore the removed entries. With membership flags and doubly linked lists this costs \(O(b(1+D))\) per batch. There are at most \(R/\Delta+1\) batches. Permanent restrictions use the occurrence lists as well. Initialization after setting the high-degree variables costs one full pass. The total number of occurrence visits is \(O(m+v+(v+b)(1+D))=O((1+m)\operatorname{polylog}(v+2))\), including on an unsuccessful branch. Properness gives \(v\le m\), and small \(v\) costs are absorbed by absolute constants. This running-time accounting is the reason for guessing the high-degree variables separately; applying the exponential running-time theorem alone would leave the per-branch checking cost unspecified.

## Descent by one guess with constant-size program text

Use a unary nondeterministic multitape language in \(\operatorname{NTIME}(n^6)\) outside \(\operatorname{NTIME}(n^5)\). The unary time hierarchy applies to this polynomial gap. A fixed base RAM simulates its tape computation on \(1^n\), given \(n\) in binary and \(g_0=Cn^6\) upfront binary guesses, with \(C\) chosen for the machine's finite branching. The base clock is \(g_0^k\). [Seiferas, Fischer and Meyer, Theorem 5](https://doi.org/10.1145/322047.322061) · [Unary specialization and native simulation](positive-witness-hierarchy.md)

Define a single program \(V\). Its payload includes its own literal code, \(n,g_0,g\) and a fallback bit. At \(g=g_0\) it implements the base simulation. Otherwise it constructs the descriptor of the **same** program with the same code, \(n,g_0\), and fallback bit, replacing \(g\) by \(g+1\) and giving this instance the virtual unary clock \(T=(g+1)^k\). Supplying the literal code as a field allows \(V\) to copy that field into its predecessor payload and into the program slot. The old descriptor has no nested histories. Its unary suffix can be addressed by its endpoints. Each stage therefore has \(O(\log T)\) physical payload when \(g\ge \lceil n^{4/k}\rceil\).

Consult the compiler on this virtual descriptor. If its length exceeds \(T/\log^B(2+T)\), return the fallback bit. Otherwise intern the names and compute the checker's guess budget from its degree census. If the budget exceeds \(g\), again return the fallback bit. Otherwise run the checker within the current clock \(g^k\), using at most \(g\) guesses. Integer logarithms and constant-factor rounding can be used in the length test. Choose \(B\) larger by two than the combined logarithmic exponents in local bit access, parsing and checking. In the scanning case this costs \(o(T)\), hence fits \(g^k\) at large \(g\), including setup and guess costs. The indexer accesses a polynomially bounded virtual source relative to the final tape input length. Constantly many bounded-width limbs and sparse simulation of its polylogarithmically many scratch writes per bit suffice. The other data structures have size \(O((M+1)\operatorname{polylog}T)\). [Native word and address convention](native-unary-clock-band.md)

Fix one verdict. Suppose all sufficiently large instances of \(V\) with this verdict survive both cutoffs when their compiled formulas are checked with one fewer bit than the advertised guess budget. Set the fallback to the opposite verdict. For each sufficiently large \(n\), induct downward on \(g\). At the base the native verdict is the hierarchy language's answer. A cutoff on a predecessor now returns its correct answer by hypothesis; on passing both cutoffs the decision-preserving compiler and verifier return that same answer. Thus the bottom computation at \(g=\lceil n^{4/k}\rceil\) decides the hierarchy language in \(O(n^4)\) RAM time. **Only this last computation runs.** The downward induction connects its verdict to the base without charging \(\Theta(g_0)\) real iterations or storing a chain of nested payloads. A nondeterministic multitape machine guesses the chronological trace and deterministically sorts the address/time records to check all reads and initialization in \(O(n^4\operatorname{polylog}n)\) time. This contradicts the excluded \(O(n^5)\) time bound. [RAM trace simulation](https://arxiv.org/abs/1311.3171)

Consequently for each fallback choice and the opposite verdict there are arbitrarily large predecessor clocks \(t=g^k\) failing a cutoff. Failing the guess cutoff means the computed verifier budget is at least \(g\), which implies the claimed variable count. The hierarchy attacks local compression of bounded nondeterministic acceptance. The branch verifier itself uses guesses, and the original deterministic running-time questions for unrestricted SAT remain open.

The terminal-phase clause-width invariant and the Boolean induction behind signed descent compile in Lean 4.19. The asymptotic resource bounds and the hierarchy application are manuscript proofs. A finite check with batch size three used a greedy radius-one cover of six ternary centers. Over all 343 choices of nonempty sets of target-true literals in the three disjoint clauses, the minimum of the best available Hamming-distance improvements was one, attaining the claimed batch decrement.
