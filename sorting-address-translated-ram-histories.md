# Sorting can destroy compression of the addresses on a genuine RAM run

For each fixed $k\ge2$ and $q\ge2$ there are $k$ explicit lists of $q$ nonnegative integers with the following property. Write $T=q^k$. A RAM enumerates the ordered tuples and marks their sums in $O_k(T)$ steps. The chronological sequence of its $T$ store addresses has a grammar with $1+k(q-1)$ rules when a rule can translate its child by a constant address offset. The same addresses in sorted order require at least $(q-1)^k$ concatenation rules in any such grammar. This counts every different intermediate string just once. All addresses fit in $2k\log_2 q+O_k(1)$ bits.

For $k=2,3$ these are actual memory operations of a globally correct SAT solver on ordinary proper DIMACS files of $N=\Theta_k(q)$ bits and on inputs of either verdict. Even with three quarters of each input mask set, sorting the mark addresses needs $\Omega_k(N^k)$ rules while $O_k(N)$ rules generate their chronology. A different globally correct solver takes $O(N)$ on these very files. The construction tests a proposed way to compress quadratic or cubic computation histories by supplying both the chronological and address-ordered tables. The full time lower bound for unrestricted SAT remains open.

## Distinct adjacent gaps

A terminal generates one address. A binary rule concatenates two earlier strings, adding a chosen offset to every address of each child. The offsets may differ between children and between uses of a rule. In the integer version there is no wrap. The lower bound also permits all additions modulo the native word modulus. A translation preserves the directed difference between consecutive entries. Each binary concatenation introduces at most one new difference, from the last element on the left to the first on the right. Empty children introduce none. Induction over the grammar DAG therefore bounds the number of distinct adjacent differences in any output by the number of concatenation rules. Extra coordinate fields with independent translations do not help with the address projection. If reversal or reflection is permitted as well, count differences up to sign and choose the modulus larger than twice the entire address range.

Let $x=(x_1,\ldots,x_k)\in\{0,\ldots,q-1\}^k$, $R=2q$, and $H=2q^{k+1}$. Put
$$
 P(x)=\sum_{j=2}^k R^{j-2}(q-1-x_1+x_j),\qquad
 Q(x)=\sum_{j=1}^k q^{j-1}\binom{x_j+1}{2},\qquad
 S(x)=H P(x)+Q(x).
$$
Each coordinate contributes a separate nonnegative summand. List 1 at $i$ contains $H(q-1-i)\sum_{j=2}^k R^{j-2}+\binom{i+1}{2}$. List $j\ge2$ contains $H R^{j-2}i+q^{j-1}\binom{i+1}{2}$. The address is their ordinary integer sum. Since $P<R^{k-1}$ and $0\le Q\le q(q^k-1)/2<H$, it fits the advertised width. A single leaf at zero suffices to generate the chronology. On adding a list, concatenate $q$ translated copies of the previous word using $q-1$ binary concatenations. Each copy offset can be applied on its edge into the concatenation tree. The order corresponds to nested loops with the most recently added coordinate outermost. If chronological mark ordinals are needed as a second field, the same copies also translate that field by multiples of the child length.

The base-$R$ digits of $P$ determine all differences $x_j-x_1$. Its fibers are segments with integer step $\mathbf1=(1,\dots,1)$. Within a segment $Q$ strictly increases. Different segments have disjoint ranges of $S$, sorted by $P$. Every $x\in\{0,\ldots,q-2\}^k$ therefore gives two *consecutive* entries in the sorted table. Their gap is
$$
               S(x+\mathbf1)-S(x)=\sum_{j=1}^k q^{j-1}(x_j+1).
$$
Its $k$ base-$q$ digits recover $x$ uniquely. This proves the bound and distinctness of all $T$ store addresses. Lean verifies the consecutive-difference catalogue for an integer-shift grammar DAG with arbitrary reuse. The sumset construction and native bounds are manuscript proofs. [Lean catalogue theorem](TranslatedTraceGaps.lean)

The witness uses only integer shifts. The proof also handles the stronger modular grammar because distinct positive gaps are smaller than the modulus. Distinct consecutive differences have been used to study sumset growth. Priority for this explicit ordered sumset application is unestablished. [Ruzsa, Shakan, Solymosi and Szemerédi](https://arxiv.org/abs/1910.02159) · [Finite checks](translated_history_audit.py)

## Running the experiment on actual SAT files

The input data consist of $k$ independent $q$-bit eligibility masks and a target $z$ of $2k\lceil\log_2 q\rceil+O_k(1)$ bits. The formula says that there are eligible indices $x_j$ with $S(x)=z$. Use the compact list-selection DIMACS template at dimension one. For list $j$ it supplies the binary index $x_j$, enforces its range, and returns the selected mask bit. Pin each returned bit to one with a padded unit. Compute $S(x)$ on the existing selectors by a Boolean circuit and compare to the target bits, pinned by signed units. Ordinary schoolbook arithmetic on $O_k(\log q)$-bit integers costs $O_k(\log^2 q)$ gates for fixed $k$; use sufficiently wide exact intermediate values and compute the division by two in each triangular number by one shift. Constant-fanin gate equivalences can use fresh output signals and the template's distinct pinned false names for short rows. Simplify gates with repeated operands before encoding. Every internal value is determined by the selectors. The additional names and clauses cost $O_k(\log^3 q)$ physical bits. The compact selector costs $O_k(q)$ and has $kq$ independent mask digits, so the total physical length $N$ is $\Theta_k(q)$. The shape can be generated and validated, including target pin signs and exact end of file, in $O_k(N)$ word steps. Each satisfying assignment corresponds to precisely one eligible tuple giving $z$. [Physical selection template and size accounting](compact-four-list-orthogonality-in-dimacs.md)

One globally correct SAT program recognizes this layout, extracts each set $E_j$ of eligible indices, enumerates the product of the $E_j$, writes one at each sum in a fresh zero-initialized bank, and reads the cell at $z$. It uses a complete SAT fallback outside the layout and when the bank would exceed its native address range. For $k=2,3$ word width $12\lceil\log_2(N+2)\rceil$ suffices, including bank tags. It can precompute the $O_k(q)$ list numbers by additions or in $O_k(q\log^2 q)$ steps by direct word arithmetic, bounded by $O_k(q^k)$, and use a running sum at each loop depth. On masks with $|E_j|\ge3q/4$ the native runtime is $\Theta_k(q^k)=\Theta_k(N^k)$. The specific stream analyzed consists of the writes to the mark bank. Decoding and loop bookkeeping use other banks. Taking a sum of an eligible tuple for $z$ or a value above the whole sum range gives both verdicts.

For nonempty masks let $e_j=|E_j|$ and $b_j=|\{i:i,i+1\in E_j\}|$. The chronological stream uses at most $1+\sum_j(e_j-1)$ rules, by skipping ineligible translated copies (a singleton's shift can be carried to the next edge or root). Each tuple with $x_j,x_j+1\in E_j$ retains its two neighbors in the sorted order. They were consecutive in the full table, and removing other entries cannot put anything between them. Their base-$q$ gaps remain distinct. Thus the sorted lower bound is at least $\prod_j b_j$. Removing one index destroys at most two consecutive pairs, so $b_j\ge q-1-2(q-e_j)$. On the stated dense masks the lower bound is at least $(q/2-1)^k$, and all-ones masks recover $(q-1)^k$. There are exponentially many eligible mask choices with the density guarantee, for example by fixing all but $\lfloor q/4\rfloor$ bits per mask to one. This also gives a lower bound for the full event table sorted by bank, address, and timestamp. All events in the dedicated mark bank are contiguous. The single target read can split at most one adjacency between successive mark stores, and other banks split none. Projecting every full record to its address coordinate therefore leaves at least $\prod_j b_j-1$ of the distinct gaps. The bound for the chronological grammar was only for the mark writes.

When the inner $k-1$ masks are all ones and the outer mask is arbitrary there is a variant with a short grammar even for the address sequence of *all active memory operations* in chronological order. During its $O(N)$ template validation the solver records whether all inner masks are full. On this branch it need not load lists in the inner loops. Every $A_j(i)$ above is quadratic in $i$, so its consecutive difference is affine in $i$ and its second difference constant. At each loop nesting level keep the counter, its current $A_j$, its next difference, and the outer partial sum in registers. Increment and reset these using a fixed number of additions and tests. For fixed $k$, the total number of registers is constant. Precompute coefficients once in $\mathrm{polylog}\,q$ steps. For each outer index, read its eligibility and then, if eligible, emit just mark stores while enumerating all inner indices. These inner store sequences are translated copies of one word. The $O(q)$ outer mask reads and the $O_k(N)$ preprocessing and final-read operations may be included literally. Concatenating them with at most $q$ uses of the translated inner word keeps the complete active address chronology at $O_k(N)$ rules. For a three-quarters-dense outer mask the sorted chronology still costs $\Omega_k(N^k)$. This gives the stronger upper for both verdicts on an exponentially large family of masks. It does not assert a short description of all CPU registers or mandatory records for idle slots.

For a faster solver first validate the template. Divide $z$ by $H$, decode the $k-1$ high base-$R$ digits, and reject any excess digits. They determine offsets $d_j=x_j-x_1$, with $d_1=0$. Intersect the integer intervals $0\le t+d_j<q$. On the resulting interval the low part $Q(t+d_1,\ldots,t+d_k)$ is strictly increasing. Binary search tests equality to the target residue and recovers the unique possible tuple. Check its $k$ mask bits directly. Even if division and multiplication take polynomial time in the word width, the additional work is $\mathrm{polylog}\,q$. This globally sound branch takes $O(N)$ including validation. Both algorithms compute the SAT verdict on the family. Its sorted-address lower bound concerns the particular marking algorithm.

## Allowing polynomial offsets within a grammar rule

An edge might add a trend rather than a constant to its child: the address in local position $i$ becomes $a_i+p(i)$. A quadratic sequence such as the first construction uses within each line has only a constant second difference. To test this stronger grammar, fix $s\ge1$ and allow every edge any integer-valued polynomial $p$ of degree less than $s$, including modular reduction after the addition. Edge coefficients and their computation can even be free. Define the $s$th forward difference on a window of $s+1$ successive addresses by repeated differencing, with $\Delta a_i=a_{i+1}-a_i$. Position-wise addition of $p$ preserves every such difference. On a binary join, at most $s$ windows cross the join. Thus all distinct $s$th differences of a grammar output belong to a catalogue of size at most $s$ times its number of concatenations, irrespective of the grammar DAG's reuse. Generating address fields via a fixed grammar and then projecting to a single coordinate preserves this bound for independent polynomial decorations on the fields.

Keep $P$ as above, replace the low part and separator by
$$
Q_s(x)=\sum_{j=1}^k q^{j-1}\binom{x_j+s}{s+1},\qquad
H_s=1+\binom{q-1+s}{s+1}\sum_{j=1}^k q^{j-1}.
$$
The sequence sorted by $H_sP+Q_s$ still breaks into complete diagonal lines, since $Q_s<H_s$ and its first forward difference along each line is strictly positive. For $0\le x_j<q-s$ the $s+1$ successive tuples $x,x+\mathbf1,\ldots,x+s\mathbf1$ give one window in this order. Applying Pascal's identity $s$ times gives
$$
\Delta^s Q_s(x)=\sum_{j=1}^k q^{j-1}(x_j+s).
$$
The digits range from $s$ to $q-1$. All $(q-s)^k$ windows therefore have distinct differences, even modulo the word modulus. The sorted grammar needs at least $(q-s)^k/s$ joins. The chronological grammar still uses constant shifts and $1+k(q-1)$ rules. These addresses have $\log_2(q^{2k+s-1})+O_{k,s}(1)$ bits since $H_s=O_{k,s}(q^{k+s})$ and $P<(2q)^{k-1}$. On a standard RAM one can choose any sufficiently large fixed word-width coefficient. The journal's specific coefficient 12 already accommodates $2k+s-1<12$, including affine and quadratic edge offsets at both $k=2,3$.

The same $\Theta(q)$-length mask templates work: computing a binomial of fixed order with a growing argument uses a fixed number of multiplications and a division by a fixed factorial, all with polynomial-in-$\log q$ circuit size. Every absent mask index can destroy at most $s+1$ consecutive starting indices per coordinate. Each mask therefore retains at least $q-s-(s+1)(q-e_j)$ starts. For fixed $s$ and masks missing at most $q/(2(s+1))$ indices, at least $(q/2-s)^k$ distinct windows remain. The final query can disrupt at most $s$ original windows in the sorted full history. On the full-inner-mask branch the degree-$(s+1)$ list entries are generated by maintaining their differences through order $s+1$, in a fixed number of registers. Thus the complete chronological active addresses still use $O_{k,s}(N)$ ordinary rules and the sorted table uses $\Omega_{k,s}(N^k)$ rules even with degree-$(s-1)$ edge polynomials. The directly computed SAT verdict is still recoverable by monotone search on the high-part fiber. These are fixed-degree results; the construction changes with the permitted degree. The audit checks the explicit finite differences and polynomial invariance. The Lean proof covers $s=1$ and integer constant translations.

### One native family works through logarithmic difference order

There is also a family in which the input file and marking solver are independent of the allowed polynomial degree. Fix $k=2$ or $3$. Write $B=2^L$, $L\ge2$, and $q=BL$. A list entry is indexed by its block $0\le b<B$ and lane $0\le r<L$. For a tuple of entries define
$$
\begin{aligned}
  J&=2B^2,\quad H'=J^k,\\
  P'&=\sum_{j=1}^k B^{j-1}b_j+
  B^k\sum_{j=2}^k(2L)^{j-2}(L-1-r_1+r_j),\\
  D_j&=(2b_j+1)2^{r_j},\qquad
  Q'=\sum_{j=1}^k J^{j-1}D_j,\qquad
  S'=H'P'+Q'.
\end{aligned}
$$
All terms are separable into $k$ nonnegative list entries: allocate $L-1-r_1$ to list one and $r_j$ to list $j$. Each $0<D_j<B^2<J$, giving $Q'<H'$. The high key $P'=O_k(B^k L^{k-1})$ fixes every block and every lane difference $r_j-r_1$. Hence each high-key fiber is a consecutive segment in sorted order. Along the segment all lanes increase by one and $Q'$ doubles. For every $1\le s<L$, its $s$th forward difference at a valid window start equals $Q'$ there, by $\Delta 2^i=2^i$ and induction. The constant high part contributes zero. These differences are distinct at *all* starts: base $J$ recovers each $D_j$, whose exponent of two recovers $r_j$ and whose odd part recovers $b_j$. Every tuple with $r_j<L-s$ has $s$ successors in the same fiber. Consequently the sorted address sequence contains at least $B^k(L-s)^k$ distinct $s$th differences.

For every $1\le s\le L/2$ simultaneously, these counts are at least $(q/2)^k$. The resulting grammar lower bound against arbitrary degree less than $s$ edge polynomials is $(q/2)^k/s$ binary joins. The addresses satisfy $S'=O_k(B^{3k} L^{k-1})=O_k(q^{3k})$. Thus the *same* construction stays within $12\lceil\log_2(N+2)\rceil$ native bits for all these degrees at both quadratic and cubic clocks. It has $N=\Theta_k(q)$ on the infinite sequence $q=L2^L$. In the physical mask template, extract block and lane by division by the public $L$, shift by $r_j$, then compute the displayed expressions with polynomially many gates in $\log q$. Their encoded cost remains $o(q)$. For the alternative linear SAT algorithm the high key again selects one fiber, with strictly increasing low part.

Keep all inner masks full and force, in the outer mask, every lane of the first $B/2$ blocks eligible. Its other $q/2$ bits are arbitrary. In the sorted write stream the surviving windows from those first blocks alone number at least $B^k(L-s)^k/2$. One final target read can spoil at most $s$ of them. Thus the complete sorted table needs at least $(B^k(L-s)^k/2-s)/s$ joins. Uniformly over $1\le s\le L/2$, this is $\Omega_k(N^k/s)$ on $2^{q/2}$ masks and both verdicts. In the active chronology, the block and lane counters are kept in a fixed number of registers. At an inner loop level maintain each high summand by constant increments on advancing a block or lane, resetting the lane contribution on crossing a block boundary. Obtain the low summand by shifting $2b+1$ by $r+(j-1)(2L+1)$. The high-part multiplier $H'$ is also a power of two. This takes a constant number of native instructions per update. The $O(q)$ preprocessing reads and outer eligibility checks can again be included literally. Each selected outer entry emits a translated copy of the same inner store stream. The complete chronological list of active addresses thus has $O_k(N)$ ordinary grammar rules and the native runtime is $\Theta_k(N^k)$. The explicit construction is an obstruction to this proposed encoding of a run. A hard SAT formula for every solver remains missing.

## What two short translated descriptions would buy

For any fixed-arity RAM trace format, give two proposed grammars on complete fixed-width event records. One expands in chronological order and the second in lexicographic order by bank, address and timestamp. Use a constant number of fields in cyclic groups of orders $2^{b_j}$ with $b_j=O(\log T)$, and specify which fields a grammar edge translates. Static fields have offset zero. Include distinct timestamp and within-step slot in each record. CPU state can be included on both sides, or the sorted grammar can describe just the memory projection of the chronological rows. Check initial, transition and final CPU constraints in chronological order and successive-event constraints in sorted order. Check reads of immutable input directly against the public input at the named location. For zero-initialized work memory the first read at any address must see zero unless preceded there by a write. Normalizing all slots, including input loads and inactive slots, with distinct bank tags lets both grammar roots retain the same number of records. A local challenge chooses a position. Expansion lengths and a root-to-leaf descent retrieve its two neighbors in $O(g\,\mathrm{polylog}\,T)$ time for $g$ rules, with input-word and address checks as in the original trace verification. The length of every reachable rule can be capped at the given deadline.

The remaining constraint is equality of multiset multiplicities. A short existential *defect* certificate suffices even when modular translations wrap. Let $U=\max_j 2^{b_j}$ and suppose at most $T$ events occur on each side. Choose an integer $p>1$ of $O(\log(T+U+2))$ bits and residues $r_j$ satisfying $r_j^{2^{b_j}}=1\pmod p$. Evaluate each leaf $a$ as $\prod_j r_j^{a_j}$ and each translated child as its ordinary sum of evaluations multiplied by $\prod_j r_j^{\delta_j}$. Concatenation adds. A discrepancy between the roots is a defect. Equal multisets have equal sums for *every* allowed choice, including composite $p$. No primality test or probability of an undetected error is required for soundness.

If the multisets differ, take a power of two $U'\ge U$ greater than $T$ and less than $2\max(U,T+1)$. Linnik's theorem supplies a prime $p\equiv1\pmod {U'}$ of the advertised width. Thus the finite field contains all the required roots of unity, and multiplicity differences of absolute value at most $T$ are faithful modulo $p$. Each cyclic Fourier matrix is a Vandermonde matrix on distinct roots, hence invertible. Their tensor product separates every nonzero difference vector. One choice of the $r_j$ detects the defect. Exponentiation and arithmetic use a fixed number of $O(\log(T+U+2))$-bit limbs and polynomial time in their width. A weight for every accessible rule can thus be evaluated in $O(g\,\mathrm{polylog}(T+U+2))$ word steps. This construction uses character separation of the group algebra. Related powerful skew circuits apply polynomial identity testing to translated compressed objects. [Xylouris on the least prime in an arithmetic progression](https://doi.org/10.4064/aa150-1-4) · [König and Lohrey](https://arxiv.org/abs/1502.04545)

Consequently the two descriptions plus a single universally selected defect test verify the whole accepting or rejecting computation. For example, suppose a deterministic $O(N^d)$ solver, $d=2$ or $3$, had both descriptions with $O(N^{u})$ rules on every unsatisfiable formula, for a fixed $u<1/d$. The time of the defect search and size of the certificate are $N^{u+o(1)}$. Applying the journal's bounded complementary time hierarchy transfer with one slowdown from $W(d,d)$ gives exponent $du<1$, a contradiction. Equivalently, a solver satisfying the proposed clock must exceed every such grammar cap on some unsatisfiable inputs at arbitrarily large lengths. Here a full trace includes the actual input loads and controller, and the checker can test a named initializer by direct local access. The comparison with the two list algorithms above shows the difficulty of proving the premise from a short chronological memory pattern alone. ## What a single translated mark stream can express

Even a weak operation on a compressed trace already represents list sums. Given three lists $a_i,b_j,c_\ell$ of polynomially bounded integers, mark all $a_i+b_j$ by translating the list of $b_j$-stores, then require zero on every address $-c_\ell$. Choose sufficiently wide words or add a common base to keep all addresses nonnegative. The chronology has $O(q)$ rules for lists of length $q$ and expands to $q^2+q$ events. The reads are consistent exactly when there is no zero-sum triple. This is an explicit reduction without any 3SUM time assumption. [Baran, Demaine and Pătraşcu](https://erikdemaine.org/papers/3SUM_WADS2005/)

With exponentially many expanded instructions, a single positive read is NP-complete for a succinct version. Declare the address width $3m$ for a proper formula with $m$ clauses and $v$ occurring variables. Allow a translation by an elementary offset $\pm2^j$, writing its bit position $j$ in binary. Unary translation rules are interchangeable with shifted binary edges when the succinct encoding explicitly lists bit positions of the offset. Start from a write of one at zero. In stage $i$, form two differently translated copies of the previous stream, one for each truth choice of variable $i$. Add $2^{3j}$ for every literal it makes true in clause $j$, numbered from zero. In each of $m$ more stages make three copies with increments $0,2^{3j},2^{3j+1}$. Require one at address $\sum_{j<m}3\cdot2^{3j}$. That target is given sparsely or shifted to zero by the same elementary translations. All sums have digits between zero and five in base eight. A digit can finish at three exactly when the original clause had one, two or three true literals, and the required added digit is then unique. The number of writes at the target equals the number of satisfying assignments. The trace has $2^v3^m$ writes but $O(v+m)$ rules and elementary shifts, with $O((v+m)\log(v+m+2))$ encoded bits. This is linear in the source DIMACS length after renaming and deduplicating clauses for decision. Indeed $m$ distinct strings over the fixed DIMACS alphabet cost $\Omega(m\log(m+2))$ total bytes and $v\le3m$. This construction uses the familiar no-carry subset-sum encoding in a translated mark stream. [Classical reduction of satisfiability to subset sum](https://www.cs.princeton.edu/courses/archive/spring18/cos423/lectures/08IntractabilityI-2x2.pdf#page=19)

For membership in NP a proposed root-to-leaf path determines one marked address by summing its translations. Use unary address width or require a width polynomial in the compressed description. The $3m$ bits in this reduction fit one word only on the expanded time scale. This NP-completeness statement thus supplies no polynomial-clock hardness in the journal's $O(\log N)$-bit input-word model. The exact quadratic and cubic store-stream example above does respect that native width.
