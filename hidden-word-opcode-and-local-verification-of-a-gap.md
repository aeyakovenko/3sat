# Checking a constant fraction of hidden RAM operations

There is a single recursive, width-indexed, two-input **word-valued** instruction \(O\) and a deterministic \(O(T)\)-step computation on a unary input of \(T\) bits with the following property. Its promised yes case has zero marked steps, and its promised no case has at least \(\eta T\) marked steps, for a fixed \(\eta>0\). No uniform verifier at all sufficiently large widths can simultaneously have these resources:

* an arbitrary first proof of \(o(T)\) **bits**, sent before the challenge or private coins;
* at most \(T^3\) subsequent possible branches per fixed random tape and first proof, counting both the explicit universal choices and all possible subsequent prover responses;
* \(o(T)\) native instructions per branch, two-sided statistical error at most \(1/3\), and access to the very same opcode.

The result includes a common proof followed by a universal choice of one, two, or three time indices and a deterministic local check, and a probabilistic verifier with arbitrary coins and at most \(3\log_2 T-O(1)\) total subsequent prover bits in a fixed padded message format. In the latter case the number of public or private random tapes can be much larger than \(T^3\). In a protocol with a separate universal selector, a yes proof must pass every selector with probability at least \(2/3\); against every prover on a no input at least one selector must reject with probability at least \(2/3\). In fact fixed sufficiently small positive multiples of \(T\) already suffice for the two caps stated as little-oh. This opcode can also separate nondeterministic from deterministic linear time on the associated RAM.

The earlier bit-valued opcode defeated statistical verification by changing a single ordinary row entry. Its empty row has an immediate exact universal index test. Here a positive table and a negative alternative can differ on a constant fraction of the **real run**, while an early common proof and a polynomial list of short deterministic tests still miss every changed query. This addresses one proposed way to authenticate the chronological data of an arbitrary RAM. The number of postproof branches and the word-valued return are essential scope conditions for this argument. It gives no time lower bound for ordinary SAT. ## The deterministic computation

Use topologically numbered directed acyclic graphs \(G\) of indegree at most two on \(T\) vertices. For infinitely many \(T\), deleting any \(e=\lfloor cT/\log_2 T\rfloor\) vertices leaves a directed path on at least \(d=\lceil c'T\rceil\) vertices, for absolute \(c,c'>0\). This is an existing depth-robustness theorem. Pad with isolated vertices to the next power of two and reduce the constants to obtain distinct powers of two. Parent lookups can be supplied by a public, label-independent tag of the instruction, so no polylogarithmic parent-generation cost is hidden in the linear clock. [Blocki, Cinkoske, Lee and Son, §4](https://drops.dagstuhl.de/storage/00lipics/lipics-vol219-stacs2022/LIPIcs.STACS.2022.14/LIPIcs.STACS.2022.14.pdf) · [Alwen, Blocki and Pietrzak, Lemma 2.2](https://arxiv.org/pdf/1705.05313)

Set \(h=\lceil\log_2(T+2)\rceil\), \(\lambda=16h\), and use \(w=32h\)-bit words. Each vertex has an opcode cell for every candidate tuple of its parent labels, each label having \(\lambda\) bits. Pack a tag, input length, vertex number, and first proposed label into one word, and the second label into the other. Fixed zero fields serve at an absent parent. These keys are disjoint from parent-directory keys. A response contains a \(\lambda\)-bit label and one flag. The deterministic program visits vertices once in topological order, issues the query with their actual previously stored parent labels, keeps the returned label and accumulates the OR of flags. The program takes \(O(T)\) steps, with unrestricted work memory. It can validate the unary input by a scan. The tested predicate accepts when the OR is zero.

In the positive planting choose independent uniform labels \(Z_v\) from an alphabet of size \(A=2^\lambda\). Put \((Z_v,0)\) at vertex \(v\)'s genuine key. Other cells have independent decoy responses; equivalently, choose and fix a complete independent decoy table first, and overwrite its genuine keys. The argument below even accommodates deterministic fixed decoys. A negative modification changes flags without changing labels, so the genuine keys are identical before and after modification. In particular the number of changed genuine flags counts steps in the actual deterministic run.

## What short branches can observe together

Consider first one **fixed** proof string and one fixed collection of deterministic executions. They may share all responses between rounds, which gives a stronger query model. Suppose each execution has at most \(R\le d/2\) rounds and the aggregate issues at most \(T^6\) oracle queries. Only responses from earlier rounds can determine the queries submitted in the next batch.

For probabilistic bookkeeping grant the simulation equality comparisons against both proposed parent labels even at an incorrect key. When a candidate tests a still-unrevealed \(Z_p\) and matches, record \(p\) as an early guess and reveal its label. Test the candidates in one round **before** releasing any response obtained by querying a genuine key in that round. At the end of the round reveal \(Z_v\) for every genuine key of \(v\) that was queried. Queries to unrelated or malformed keys need no comparisons. This augmented experiment determines every ordinary transcript.

Until it is revealed, a label is uniform outside its previously excluded candidate values. One can prove this inductively conditional on the augmented transcript: failed comparisons remove individual values, a successful comparison fixes its tested coordinate, and a response revealing a new coordinate gives its value without constraining the remaining ones. The decoy responses were fixed independently. There are at most \(M=2T^6\) comparisons. Each conditional chance of a new early guess is therefore at most \(1/(A-M)\). A union bound on the chosen positions of \(e\) first discoveries bounds the probability of at least \(e\) early guesses by
\[
               {M\choose e}(A-M)^{-e}
          \ \le\ \bigl(M/(A-M)\bigr)^e = 2^{-\Omega(T)}.
\]
The last estimate uses \(A\ge T^{16}\) and \(e=\Theta(T/\log T)\). A union bound over every binary string of length at most \(\delta T\) still leaves failure probability tending to zero when \(\delta>0\) is sufficiently small. This accounts for arbitrary encoding of oracle information in the first proof.

Delete the early guesses. For any surviving directed edge \(u\to v\), a genuine query at \(v\) requires that the label of \(u\) was already returned in an earlier round. Otherwise its correct operand would be an early guess at \(u\). On any surviving directed path, queried genuine keys form an initial segment with strictly increasing rounds. Some path has at least \(d\) vertices. At least \(d-R\ge d/2\) genuine keys therefore remain unqueried. The path and its missed suffix may depend on the proof. The table is shared across every proof. Random-oracle labelings and the accounting for guessed labels have substantial antecedents; this proof uses them for a simultaneous short-proof decision test. [Dwork, Naor and Wee, *Pebbling and Proofs of Work*](https://www.wisdom.weizmann.ac.il/~naor/PAPERS/peb.pdf) · [Mahmoody, Moran and Vadhan, *Publicly Verifiable Proofs of Sequential Work*](https://scholar.harvard.edu/files/salil/files/moody.pdf)

## Private coins and a decision gap

Take \(J=\lceil24T\rceil\) independent verifier tapes. For one first proof simulate every allowed continuation on each sampled tape, including every selector and every possible tail response. Each individual trajectory has at most \(T\) oracle calls under the cap. The aggregate has at most \(JT^4\le T^6\) calls for large \(T\). Conditional on the sampled tapes, the planting argument simultaneously applies to all first proofs.

There is also a uniform guarantee in the other conditioning order. Fix the positive table, a first proof and a subset \(S\) of vertices. On one fresh tape let \(p\) be the probability that *some* continuation, across all selectors and all tail responses for this proof, touches a genuine key in \(S\). If \(p>1/6\), the probability that the sampled tapes miss it throughout is at most \((5/6)^J\). Union bound over at most \(2^{1+\delta T}\) proof strings and \(2^T\) subsets. With probability tending to one, any such set entirely missed on the sample has \(p\le1/6\). Both guarantees hold jointly for some planting and sample. Dependence of the eventual \(S\) on the positive table, on the sample and on the honest proof is allowed.

If completeness already fails on the positive table, keep it. Otherwise fix an honest first proof and strategy and choose the missed \(S\) from its surviving path. Flip just the flags at these genuine keys. For every selector the probability of any changed query under the positive simulation with the fixed strategy is at most \(1/6\). On every other random tape exactly the same strategy and replies give the same transcript on the negative table. Acceptance probability is at least \(2/3-1/6=1/2\) for every selector, violating soundness. Negative inputs have at least \(\eta T\) marked steps, with \(\eta=c'/2\) up to harmless rounding.

At each trial only a finite opcode table is required. Fix a native instruction model with a separate pair table at each width, as with the usual width-indexed arithmetic operations. Repeat every uniform verifier with explicit clocks and branch caps infinitely often at unused widths supporting the graph bound. Truncate at the prescribed fixed linear advice and work caps; an alleged little-oh verifier eventually agrees with the truncation. For an effective construction use finite polynomial clocks, including charged finite random bits and messages, as in the native model. All finite tables and finite deterministic prover strategies on bounded histories can be searched exhaustively to find a promised table witnessing failure. The existence argument does not charge this external search to the deterministic computation. Use the default graph of isolated vertices and zero table at unused widths; stages and widths may be chosen recursively by finite exhaustive graph search upwards from the preceding width. This yields a recursive instruction. For a given width, graph queries may include the actual input length as well as the vertex number, or nontrial lengths of that width may use a default graph of the requested length.

At alternate fresh widths use a disjoint opcode tag for the predicate that one of \(T^2\) public positions is marked. A nondeterministic machine guesses the position and checks it in addition to validating unary input. For each clocked deterministic linear machine keep the row empty if it accepts on the empty row, and otherwise mark a position which it never queried there. The flag-graph computation and this marked-row predicate use separate tags. This standard diagonal supplies the stated relative linear-time separation on the same opcode. [Binary marked-row argument](two-word-interactive-barrier.md)

## Two checks on the scope

**An upper bound when communication between parallel queries is free.** Give the \(T\) topological ordinals \(\lceil\log_2T\rceil\) bits. Classify each edge by the highest bit where its endpoints differ. Select the \(k\) least frequent bit positions and mark the heads of edges in those classes. There are at most \(2Tk/\lceil\log_2T\rceil\) marked heads. Among the remaining vertices, deleting the selected bits from the ordinal yields a strictly increasing integer on each remaining edge. A proof lists the marked heads and their true labels, using \(O(Tk)\) bits. A parallel evaluator propagates through the residual graph in at most \(2^{\lceil\log_2 T\rceil-k}\) batches with at most \(O(T)\) real opcode calls overall, then also checks the guessed labels and all flags. If all checks pass, induction in the *original* topological order authenticates the entire run. For a fixed sufficiently large constant-factor saving in rounds this costs \(O(T)\) proof bits, matching the order of the lower bound for the communicating model. This upper algorithm uses shared responses between queries. This is Valiant's depth reduction by deleting binary levels. [Valiant's argument, as applied by Alwen and Blocki](https://www.ndss-symposium.org/wp-content/uploads/2017/09/attacking-data-independent-memory-hard-functions.pdf)

**An algebraic alternative.** If each label/flag coordinate of the opcode at a vertex has degree at most \(s\) in its at most \(2\lambda\) parent bits, all its coefficients can be recovered from the values at Hamming weight through \(s\). These are input-independent queries. For \(s=o(\log T)\) the total is \(T^{1+o(1)}\) across all vertices. A communicating parallel evaluator can learn them in one batch, evaluate the graph using ordinary local computation, then query every genuine key in a second batch if desired. This counts oracle batches only. It identifies an algebraic feature of standard operations that the arbitrary-opcode argument cannot rule out. The main theorem permits unrestricted local computation in the *finite aggregate query lower bound*, while its uniform recursive-instance version uses clocked algorithms. Neither statement gives an ordinary constant-alternation time separation.
