# Short-branch verification of an explicit RAM table computation

There is a deterministic word-RAM computation using \(O(T)\) steps on an ordinary read-only input with the following limits on verification. Fix rational \(c\ge0\) and \(\gamma>0\). An initial proof of \(o(T)\) **bits**, followed by at most \(T^c\) possible deterministic continuations, each taking \(o(T)\) native steps, cannot verify the computation on all inputs of length
\[
                   N=\Theta(T^{1+c+\gamma}\log T).
\]
Every yes input in the hard pairs has no flagged operation in the genuine execution, and its no partner has at least \(\eta T\) flagged operations for an absolute \(\eta>0\). There are hard pairs at infinitely many scales, or a failure of completeness at a zero-flag input. Uniformity of the verifier is unnecessary for that conclusion. The graph, the response tables and the changed flag bits are ordinary input data. A table entry has a single subscript obtained by adding the two parent labels, even when other vertices reuse either parent.

There is a private-coin version with completeness and soundness error at most \(1/3\). Count all postproof universal choices and subsequent prover responses together in the \(T^c\) bound **on each fixed tape and initial proof**. For a negative promise of at least \(D\) genuinely flagged steps, \(1\le D\le \eta T\), the input length sufficient for this lower bound is
\[
                N=\Theta(T^{1+c+\gamma}D\log T).
\]
In particular exact decision, which requires correctness even with a single genuine flag, has the same exponent as the deterministic statement. A constant-fraction execution gap under private coins costs an additional factor \(T\) here. Fixed sufficiently small positive multiples of \(T\) suffice in place of the two little-oh caps, with constants allowed to depend on \(c,\gamma\).

These input lengths exceed the deterministic execution time. The gap counts genuine table accesses and does not claim that a constant fraction of the physical input must be changed. The theorem gives a lower bound on a proposed verifiable speedup for explicit random-access computations. Its input is not a SAT instance. [Earlier two-operand, width-indexed opcode result](hidden-word-opcode-and-local-verification-of-a-gap.md)

There is also an unconditional obstruction for local reductions to ordinary SAT. With \(A\) records in each of \(T\) rows, consider any fixed finite list of correct compilers computing each output bit in at most \(\tau\) source-record probes and \(\operatorname{polylog}T\) rounds. One common pair of opposite-verdict inputs forces every file to have \(\Omega(TA/\tau)\) bits on **both** members. If a local call returns a packed output word of \(w=\Theta(\log N)\) bits, the bound is \(\Omega(TAw/\tau)=\Omega(N/\tau)\) bits. Thus constant-probe packed local reductions can be forced to retain a constant fraction of the entire physical source even when the original computation visits only one of the \(A\) records per row. The proof works for any target predicate. Its full assumptions appear below.

## Encoding and evaluating the graph

Use topologically numbered graphs on \(T\) vertices, with at most two distinct predecessors at each vertex. On infinitely many sizes there are such graphs on which deletion of any \(e=\lfloor aT/\log_2 T\rfloor\) vertices leaves a directed path of at least \(d=\lceil a'T\rceil\) vertices, for fixed \(a,a'>0\). Repeated edges can be combined without changing paths. Powers of two can be obtained by padding with isolated vertices and adjusting the constants. Supply the actual parent indices in the input. [Blocki, Cinkoske, Lee and Son, §4](https://drops.dagstuhl.de/storage/00lipics/lipics-vol219-stacs2022/LIPIcs.STACS.2022.14/LIPIcs.STACS.2022.14.pdf) · [Alwen, Blocki and Pietrzak, Lemma 2.2](https://arxiv.org/pdf/1705.05313)

Let \(A\) be the next power of two at or above \(T^{c+\gamma}\) (private coins: \(DT^{c+\gamma}\)). Each vertex \(v\) has a row of \(A\) records. Every record holds a label modulo \(A\) and one flag. A header gives the dimensions. Given \(v\), read the genuine labels at its predecessors from native workspace, add them modulo \(A\), and read the record at that subscript in row \(v\). With one predecessor use its label, and at a root use zero. Save the new label and accumulate the OR of all flags. The predicate accepts exactly when that OR vanishes. No condition on the unused records is needed.

For example, take \(T=2^h,A=2^\ell\). Use one fixed self-delimiting encoding of the two nonnegative numbers \(h,\ell\) at the start, followed by zero padding to a record boundary. Set the record width \(L\) to the next power of two above \(100(h+\ell+2)\) bits. One header record precedes \(T\) graph records giving parent indices plus one, with zero fields for no predecessor. The cell for \((v,s)\) starts at bit \(L(1+T+vA+s)\), for zero-based vertices. On valid dimensions the short header takes at most \(\operatorname{polylog}T\) scalar operations to decode and the physical extent is \(N=L(1+T+TA)\). The native word width is a fixed multiple of \(\log(N+2)\). Record and native widths differ by bounded factors. Thus each input-word load reveals at most constantly many records, including reads crossing a boundary, and the evaluator reads any selected record in constantly many native steps by the quotient and remainder of its bit offset by the word width. Bit offsets and all table indices fit a fixed number of words. Checking the parent list takes \(O(T)\) time; arbitrary padding can be ignored. There is a single evaluation program for the whole family. The hard-input proof fixes the graph and the layout, so revealing both to the verifier at no cost only strengthens it.

## How a premature sum query can reveal a label

Write \(Z_v\) for independent uniform elements of \(\mathbb Z/A\mathbb Z\). In the positive table plant \((Z_v,0)\) at subscript \(\sum_{p\to v}Z_p\) in row \(v\). All other entries have fixed decoy records chosen independently of the labels, for example zeros. Induction in topological order gives the stated genuine labels. At any later modification considered below all labels stay fixed.

Consider any collection of deterministic continuations with at most \(R\le d/2\) synchronized query rounds and \(M\) aggregate record queries. It can share all replies between rounds. Fix the first proof, coin tapes and any other public information independently of the planting. Within one round the whole list of queries is now determined. Process that list without releasing any newly returned **child** labels until the end of the round. The analysis maintains an augmented transcript recording the truth of each tested row-sum equality, including at a decoy with the same numerical return as a genuine record. It may release some **parent** labels early by the following rules.

* Count earlier failed equalities involving each still-concealed parent. If such a parent about to be tested has accumulated at least \(A/2\) failures, mark and reveal it before testing. Each failed query contains at most two different parents, so at most \(4M/A\) parents are marked in this way.
* If the proposed subscript equals the genuine sum and any parent is still concealed, mark and reveal all those parents. At most two are marked per such success. When no parent is concealed the query needs no early discovery.
* At round end release the true child label at each genuine key queried in the round. The ordinary numerical transcript is now determined, including all decoys. Revealing a label earlier than its own genuine row query always records a mark unless it was already released by its genuine query in an earlier round.

Immediately before a test that still has a concealed parent \(p\), its conditional chance of success is at most \(2/A\). To prove this, condition also on the labels of every vertex except \(p\). Realizations of \(Z_p\) consistent with this augmented transcript are uniform on their admissible values. Every prior successful test involving \(p\) would have revealed it. Each earlier failed sum involving \(p\) excludes at most one value since the coefficient of this parent is one. Known child-label replies do not constrain \(Z_p\) further, since child labels are independent before planting. For a fixed transcript the adaptive probe list, choice of light parent, heavy counters and earlier disclosures are determined by these past comparisons and disclosed values. Fewer than \(A/2\) exclusions involving this parent have occurred. Thus more than \(A/2\) choices remain and the current equality selects exactly one. This remains valid when two concealed parents participate, when failed tests form cycles of pair sums, and for the composite modulus \(A\). Averaging over the other labels preserves the bound.

Whenever \(4M/A=o(e)\), marking \(e\) vertices requires at least \(k=\lfloor e/3\rfloor\) of the fresh successes for large \(T\). Multiplying the conditional bound at any fixed \(k\) ordered test positions and summing over their choices gives
\[
              \Pr[\text{at least }e\text{ marks}]
               \le {M\choose k}(2/A)^k
               \le \left(\frac{2\mathrm e M}{Ak}\right)^k .
\]
Here \(\mathrm e\) in the last numerator is Euler's constant. With \(J\) sampled tapes (one tape in the deterministic case), \(M=O(JT^{1+c})\). Taking \(J=O(D)\) in the statistical case, our choice of \(A\) gives \(M/A=O(T^{1-\gamma})\), so this probability is \(2^{-\Omega_\gamma(T)}\). The bound holds for every fixed tape list. A union bound includes every initial proof string of length at most \(\delta T\) for small fixed \(\delta>0\).

Delete the marked vertices. On every surviving edge \(u\to v\), a genuine query in row \(v\) required the label of \(u\) to have already been returned at a genuine query in a strictly earlier round. Otherwise the test would have marked \(u\). A surviving path of length \(d\) therefore contains at least \(d-R\) rows whose genuine keys are absent from the entire aggregate transcript. This supplies at least \(\eta_0 T\) missed keys for a fixed \(\eta_0>0\).

## Deterministic checks and private coins

For deterministic continuations choose a planting on which every initial proof has fewer than \(e\) marks. If the verifier is complete there, take an honest first proof and flip the flags at \(\lfloor\eta_0 T\rfloor\) of its missed genuine keys. Every continuation has the same transcript on the new input. The computation itself now visits all those changed flags, violating the verifier's soundness.

Under private coins, fix \(J=\lceil C_0 D\rceil\) independent sampled tapes, with a constant \(C_0\) chosen below. Include every continuation on each tape, with no restriction on the total supply of private tapes. The preceding probability bound, integrated over the tape sample and unioned over first proofs, supplies one positive table on which the probability over samples that **any** first proof has at least \(e\) marks is \(o(1)\). This follows by averaging over positive tables; genuine-table records are shared across all proofs and samples after this choice.

Fix one honest proof there, or conclude that completeness already failed. On one fresh tape let \(p_v\) be the probability that some allowed continuation for this proof probes row \(v\)'s genuine key. For the independent sample the expected number of keys never visited is \(\sum_v(1-p_v)^J\). This uses the union of **separate ordinary runs** across the sampled tapes; the aggregate analysis above allowed extra sharing, and applies in particular to their actual union. The lower bound on missed keys puts the expectation at least \((1-o(1))\eta_0 T\). If fewer than \(\eta_0 T/2\) vertices had \(p_v\le1/(6D)\), it would instead be at most \(\eta_0 T/2+T\exp(-C_0/6)\). Choose \(C_0\) so that the second summand is at most \(\eta_0 T/4\). For \(D\le\eta_0 T/2\), choose \(D\) low-probability vertices and flip their genuine flags. With probability at least \(5/6\) no continuation on a fresh tape probes any changed cell. On those tapes the honest positive strategy and the same first proof reproduce every transcript when used on the negative table. For every universal selector, acceptance on the negative table is at least \(2/3-1/6\), contradicting two-sided soundness. This also covers a common proof followed only by private random checks; no later prover is needed.

The deterministic exponent \(1+c+\gamma\) approaches a limit of this particular missed-cell proof. If a public file has \(o(T^{1+c})\) words, \(T^c\) deterministic scans of disjoint known fragments can between them read the whole file in \(o(T)\) rounds. This observation concerns aggregate coverage; the scans need not thereby solve the predicate.

At the exact exponent one can exclude logarithmically shorter proofs and checks. Fix \(\xi>0\). Take \(A\) the next power of two at or above \(\max(2,T^c)\) in the deterministic case, or \(\max(2,DT^c)\) under private coins. If \(R=O(T/(\log T)^{1+\xi})\), then \(M/A=O(T/(\log T)^{1+\xi})\). The preceding binomial tail is \(2^{-\Omega_\xi(T\log\log T/\log T)}\). The same hard pair or completeness failure persists with initial proof length \(o(T\log\log T/\log T)\), including \(O(T/\log T)\) bits. The input now has \(\Theta(T^{1+c}\log T)\) bits deterministically or \(\Theta(DT^{1+c}\log T)\) bits statistically. In particular, for \(c=1\) this yields a concrete ordinary native computation on \(\Theta(T^2\log T)\)-bit inputs which defeats the specified packed proof and one-index deterministic local check at those clocks.

## Shorter local runs and the encoded length of a SAT reduction

Use instead a family of constant-indegree graphs on \(T\) vertices that is \((e,d)\)-depth robust for \(e=\Theta(T)\) and \(d=\Theta(T^{2/3})\), on an unbounded sequence of sizes. This is the consequence of Schnitger's Theorem A stated explicitly by Blocki and Cinkoske in §3.2. Replace each vertex of indegree greater than two by a bounded-size binary tree combining its incoming edges, and send all original outgoing edges from its tree's root. Keep a single vertex for original indegree zero, one or two. A deletion of \(m\) expanded vertices marks at most \(m\) original vertices. Each path of intact original vertices lifts from root to root through intact trees, visiting at least one expanded vertex per original vertex. The total number of expanded nodes is linear. Pad to the next power of two and adjust the fixed constants. The graph lives in the input and the evaluation procedure is unchanged. [Schnitger, *On depth-reduction and grates*](https://doi.org/10.1109/SFCS.1983.38) · [Blocki and Cinkoske, §3.2](https://drops.dagstuhl.de/storage/00lipics/lipics-vol185-itcs2021/LIPIcs.ITCS.2021.64/LIPIcs.ITCS.2021.64.pdf)

For \(R\le d/2\) and \(M\le \kappa A T\) aggregate record queries, with \(\kappa>0\) sufficiently small, at most \(e/4\) vertices are marked with probability \(1-2^{-\Omega(T)}\). Indeed \(4M/A\le e/16\) by reducing \(\kappa\), and the same binomial bound with \(k=\lfloor e/16\rfloor\) makes the chance of the remaining required fresh successes exponentially small. A constant fraction of all genuine keys is still missed, even though \(d\) is now sublinear. As long as at most \(e\) vertices have been removed, find a surviving path and remove exactly \(d\) consecutive vertices from it. Repeat starting with the early marks. This collects at least \(e/2\) vertices on disjoint paths for large \(T\), since \(d=o(e)\). On each such path at least \(d-R\ge d/2\) genuine keys were missed by the *original* collection of queries: all vertices were already unmarked before the path-packing procedure. The same uniform selection works with an arbitrary initial proof of \(\delta T\) bits for sufficiently small \(\delta\).

For example, fix \(k>0\). A proof of \(o(T)\) bits and at most \(T\) deterministic continuations with at most \((\log T)^k\) steps each now fail already with \(A\) a power of two of order \(C(\log T)^k\), with a sufficiently large constant \(C\). The physical input length is \(\Theta(T(\log T)^{k+1})\), with \(\Omega(T)\) genuine flags changed on the opposite input. The same parameters work for private coins with one genuine flag changed, using a sufficiently large constant number of sample tapes for the probability argument above. An arbitrary fixed constant factor in the local clock can be absorbed into the choice of \(C\).

For the compiler statement let \(2\le A\le T^{O(1)}\) be a power of two. Each member of the fixed roster returns its output length and any requested output unit containing \(b_0\) bits, with at most \(\tau\ge1\) source-record probes per query, on every input. Length computation can instead consume a separate shared probe allowance \(o(TA)\). Its adaptive rounds plus the maximum number of rounds per output-unit lookup must fit \(d/2\), as holds for polylogarithmic local computation with polylogarithmic setup. A shared common-input preparation phase is allowed within these same round and aggregate-probe budgets. In particular, length selection or preliminary compilation cannot privately scan the entire source or first run the \(T\)-step oracle walk. A physical input-word load touches at most constantly many records in the stated padded format, including arbitrary crossing loads. Correctness means the target verdict on every emitted file equals the source verdict. The interpreted target can be SAT and the file can have arbitrary 3-CNF syntax.

Assume \(\tau=o(TA)\) so that accumulating a bounded number of lengths and rounded terminal units costs \(o(TA)\) probes. Compute all the length answers. For each file of reported size at most \(K=\lfloor\kappa' T A b_0/\tau\rfloor\) bits, run every one of its output-unit lookups in parallel, with \(\kappa'>0\) chosen sufficiently small for the roster size and constant query units. The entire collection uses at most \(\kappa AT\) record probes, with no proof messages. Select a planting with the preceding missed set and flip the genuine flags at those rows. Induction on the query rounds preserves the entire aggregate transcript, including *which* files qualified for enumeration. Any qualifying compiler would have emitted a bit-identical file on two opposite-verdict inputs, contrary to correctness. Therefore each compiler emits more than \(K\) bits on both members of this one pair. All computation on the output units, and even an arbitrary target decision function, can be free in this argument.

Taking \(b_0=1\) gives \(\Omega(TA/\tau)\) encoded bits. Taking \(b_0=w=\Theta(\log N)\) gives \(\Omega(N/\tau)\) in the padded input layout. For example a single constructible choice \(A=2^{\lceil\sqrt{\log_2 T}\rceil}\) yields a source of \(T^{1+o(1)}\) bits on which any fixed finite roster with \(\tau=\operatorname{polylog}T\) needs \(T2^{\sqrt{\log_2 T}}/\operatorname{polylog}T\) output bits on a common opposite pair. For a fixed probe exponent \(k\), \(A\) of order \((\log T)^{k+2}\) already forces \(\Omega(T\log^2 T)\) bits from \(\tau=O((\log T)^k)\) bit-local compilers, on \(O(T(\log T)^{k+3})\)-bit inputs. This leaves open compact reductions for sources with genuinely short, structured physical payloads. A clock bound alone supplies no such payload restriction.
