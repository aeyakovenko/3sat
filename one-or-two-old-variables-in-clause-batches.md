# Adding clauses through one or two previously used variables

Suppose each step appends a batch of proper ternary clauses and shares at most $a$ variables with **all** preceding clauses. An old variable must already have occurred in a clause. New variables may occur several times in the batch. Let $r$ be the maximum number of clauses in a batch. These are parameters of the printed formula and its possible construction histories. They do not limit the storage or instructions of its eventual solver.

| Old variables $a$ | Batch size $r$ | Consequence |
| --- | --- | --- |
| 1 | arbitrary | The minimum possible $r$ equals the largest number of clauses in a biconnected block of the primal graph. |
| 1 | $r\le c\log N/\log\log N$ | One deterministic RAM decides SAT in $O(N)$ time for a fixed absolute $c>0$, with no history or decomposition supplied. |
| 2 | 1 | Every such formula is satisfiable. |
| 2 | 2 | Full proper 3-SAT reduces in deterministic linear time and bit length. The minimum positive model count on a nonempty formula is exactly six, so an at-most-five promise decides the verdict immediately. |
| 2 | 3 | There is a parsimonious linear-time and linear-length reduction from full proper 3-SAT, counting on the occurring variables. |

Here $N$ is ordinary ASCII DIMACS length in bits, and proper means three distinct variables with arbitrary signs. For the one-variable structural test count one copy of each distinct signed clause after normalization. If repeated clauses are to count separately in a construction history, use their multiplicities in the same block formula instead. The model-count convention avoids having to explicitly list the potentially enormous set of unused declared identifiers. Decision on valid DIMACS is independent of their assignments.

## Recovering the optimum for one old variable

Build the primal graph on occurring variables, connecting the three pairs of each clause. Each clause triangle belongs to exactly one maximal vertex-biconnected block. Appending a batch on at most one old variable preserves separation of the old graph from every new vertex through that single variable, if any. A proper new clause necessarily has new vertices. Enlarging the graph this way cannot join biconnected blocks across the attachment. Induction puts every final block's clauses inside a single batch. Conversely, root each tree of the block-cut forest and add the clauses of each block in parent-first order. The only possible common vertex with preceding blocks is its articulation vertex toward the root. This gives the claimed exact minimum, taking zero for an empty formula. Every edge of this primal graph belongs to a clause triangle. [Tarjan, *Depth-First Search and Linear Graph Algorithms*](https://doi.org/10.1137/0201010)

All graph construction fits deterministic $O(N)$ time. Scan bytes, stripping leading zeros in decimal names, and intern the normalized digit strings in a trie with ten child addresses per node. This also handles names too long for a native word. Lex and validate the proper triples according to the input grammar. A declared name bound too large to fit a word can be checked against each token first by normalized decimal length, then by digit comparison on ties, charging that comparison to the token. Count actual clauses when validating the header. Use bounded dense indices for the resulting $v$ variables. Sort the literals in each clause, then use a constant number of stable counting-sort passes on signed indices in $[1,2v]$ to deduplicate clauses. The same method groups repeated primal edges while retaining a pointer from each clause to one of its three edges. Tarjan's linear graph algorithm labels the edge blocks. A single pass assigns the clauses through their retained edges. The same literal-set normalization can be done in packed scan time under the more specific grammar of the earlier note. [Packed normalization](packed-normalization-of-dimacs-clauses.md)

For the SAT algorithm, root the block-cut forest. An articulation vertex combines the feasible truth values from descendant blocks by intersection. A block receives one allowed subset of $\{0,1\}$ on each of its descendant articulation variables, and allows both values at its other variables. Its message gives the possible values of its parent articulation variable, or simply satisfiability for a root block. Conditional on that common variable all descendant branches have disjoint remaining variables, which proves the recurrence. Many child blocks at one articulation cost their total degree. Each cut-vertex incidence is charged once.

Here is a uniform cost bound for these local queries. Let $h=\lfloor\log_2(N+2)\rfloor$. For sufficiently large $N$ set $R=\lfloor h/(100\lceil\log_2(h+2)\rceil)\rfloor$; bounded sizes can be handled directly. A block with at most $R$ clauses uses at most $3R$ variables. Relabel them by first occurrence while scanning its clauses, using a global scratch array reset only at the touched indices. A fixed-length key contains an encoding of its clause count, the signed triples in slots of width $\lceil\log_2(3R+1)\rceil+1$ per literal, the unary domains on at most $3R$ local variables, and the index of the parent variable or a root flag. Pad unused slots with zeros. This requires $3R\log_2(3R+1)+O(R+\log(R+1))$ bits. For the specified $R$ it is at most $h/4$ at sufficiently large scales. There is no assumption that isomorphic blocks receive the same key.

A single program enumerates all keys, rejects malformed keys, and tries the at most $2^{3R}$ local assignments per key. Save the answer and one realizing assignment for each feasible parent bit. This once-per-input cost is at most $2^{h/4+3R}\operatorname{poly}(h)=O(N)$. The table and its addresses fit the logarithmic-word RAM. Computing actual keys need only touch the present clauses and variables: form the populated fields by shifts and append or skip the known lengths of the zero tails. The widths/offsets for each local count can be pretabulated. Do not clear an $R$-entry array for every tiny block. The block-cut forest and all local records together have size linear in the normalized input records. The table consequently gives the $O(N)$ bound and also reconstructs a satisfying assignment by a top-down pass fixing the selected parent bits. It can be returned as a bit per occurring variable with a pointer to its original name. On other inputs one globally correct solver uses complete search.

## The two-old-variable threshold

With a single proper clause per step, at least one of its literals is on a new variable. Whatever the old values, one can satisfy the clause by choosing that literal true. Repeating preserves satisfiability.

For two clauses per step, start with one fresh variable for every literal occurrence in the source. Introduce each source clause in a separate batch on its three new occurrence variables with the original signs. For every source variable, order its occurrence variables and impose equality along a chain. Equality of two occurrence variables is the conjunction of two binary implications. For each required binary clause $(\ell_1\vee\ell_2)$ introduce its own private new pad $z$ and add one batch

$$
 (\ell_1\vee\ell_2\vee z),\qquad(\ell_1\vee\ell_2\vee\neg z).
$$

The old variables in this step are just the two endpoints. Its projection is the binary clause. If that clause holds, there are two choices of $z$. Thus if $b$ binary implications were introduced, the final model count equals $2^b$ times the original model count on occurring variables. Equality chaining and the use of signed copies preserve arbitrary mixtures of positive and negative occurrences.

The failure of unique satisfiability at this width is inherent. Fix an assignment on old variables before a batch. Every new row retains at least one fresh variable unless an old literal already satisfies the row. A conjunction of at most two such residual clauses is inconsistent only when both are opposite unit clauses on the same fresh variable. Indeed two nonempty Boolean clauses can be satisfied together by compatible choices of winning literals unless their only choices are opposite singletons. To leave opposite units, both original proper rows must use precisely the same two old variables with the same signs, false at this assignment. The new third variable occurs with opposite signs. For *every* admissible old assignment the old binary disjunction is therefore true and the fresh variable is free.

If any batch eliminates a solution of its preceding prefix, consider the last such batch. Provided the final formula is satisfiable, some surviving old assignment has its two extensions at this batch, and each subsequently has an extension through every remaining batch. If no batch ever eliminates a prefix solution, the first nonempty batch already has at least two models: each proper clause excludes one eighth of assignments on its occurring-variable cube and there are at most two clauses. Both solutions continue to the end.

There is a stronger bound on each individual model. For a history of nonempty batches let $a_i$ be the actual number of previously used variables in batch $i$. Every satisfying assignment lies in an affine subspace over $\mathbb F_2$ consisting entirely of satisfying assignments, of dimension at least

$$
                         \sum_i(2-a_i).
$$

To prove this, fix the model $s$. For one clause, fixing a literal true at $s$ is a sufficient affine equation. For two clauses on the same triple, let $u,v$ be the two forbidden points on those three bits. There is a linear functional $\ell$ with $\ell(u-s)=\ell(v-s)=1$. Both arguments are nonzero and are either equal or linearly independent over $\mathbb F_2$. Thus the plane $\ell(x-s)=0$ contains $s$ and satisfies both clauses. If the union of the two supports has at least four variables, use at most two equations, each fixing a literal true at $s$ in one clause. In both cases the number of new variables minus the number of equations is at least $2-a_i$. Take all the equations at once. Their intersection contains $s$, its codimension is at most the sum of their counts, and it implies every clause. Summing new variables counts every occurring variable exactly once, proving the bound.

More precisely, a single affine equation through $s$ suffices for two rows exactly when each has a true literal on some variable common to their two supports. Any hyperplane avoiding the forbidden assignments of a row must have its normal supported within that row's triple: otherwise a coordinate outside the triple can be adjusted on a forbidden assignment to put it in the plane. Restrict both normals to the common coordinates. The one required normal must evaluate to one on both restricted differences from the forbidden patterns. This is possible exactly when both differences are nonzero, by the same two-vector argument. Two equations always suffice by fixing satisfying literals.

The first nonempty batch has $a_i=0$. Thus every nonempty satisfiable two-old, two-row file has at least four models. The empty conjunction has one model on its empty set of occurring variables. This decides the at-most-two promise immediately on recognized inputs. Each subsequent batch with zero old variables adds at least two more dimensions to the bound, and each batch with one adds at least one. These contributions survive all subsequent permitted links even when a chosen satisfying assignment is known only at the end.

The sharper counting argument varies the separating affine equations through the same chosen model. It gives at least $3\cdot 2^{d-1}$ models for $d=\sum_i(2-a_i)$ on a nonempty satisfiable file. The minimum six at $d=2$ is attained by two distinct clauses on the same three variables, excluding two of their eight assignments. When there are at least two forbidden flats, the stronger minimum-complement bound gives at least eight models in this class. In particular a history with at least two nonempty batches cannot produce a model count between one and seven. This still holds with arbitrary links to previously created variables satisfying the two-old rule. Membership in the two-old, two-row class can also be recognized in $O(N)$ without a supplied history. Work backwards and peel a set of one or two clauses if at most two of its variables occur outside it. Any such choice is safe: restrict a witnessing history to the remaining clauses, taking subsets of its batches and skipping empty batches. The sets of old variables in this restricted history can only shrink. More generally any other sequence of legal removals can be replayed after a chosen removal by subtracting previously removed clauses from each batch, because the exterior variable set only shrinks. Hence complete peeling has a unique residual set and recording the removals gives a history precisely when that set is empty.

A variable of live degree one nominates its clause as a legal singleton. When no singleton is available, all live variables have degree at least two. For two clauses sharing $s$ variables let $p$ count those shared variables of live degree exactly two. Their total number of exterior variables is $6-s-p$. Thus a legal pair at such a stall satisfies $s+p\ge4$, and at least one shared degree-two variable nominates the pair. Maintain a queue of variables when their live degree first reaches two or one, including initial degrees. Test a nominated pair by counting all its exterior variables, even if a singleton is available elsewhere. With linked incidence lists, every check and every removal takes constant time per clause. If a stalled pair becomes eligible after an earlier failed test, some newly private shared variable has just reached degree two, or a variable unique to one of its clauses has reached degree one. If the latter singleton is still present, it can itself be peeled. Thus the queue cannot terminate while any legal batch remains. This yields a linear recognition algorithm even though deciding the SAT verdict on the recognized class encompasses general 3-SAT.

Three clauses per step suffice to remove every free pad parsimoniously. First create a dedicated false anchor $A$ by the two padded batches for $(\neg A\vee y)$ and $(\neg A\vee\neg y)$. In the first batch $A,y$ and its pad are new. The second batch uses the same $A,y$ and a fresh pad. These batches force $A=0$ and leave $y$ and their two pads free. For each free pad $z$, including these three initial free variables, take a fresh $p$ and use the batch

$$
 (\neg z\vee A\vee p),\qquad
 (\neg z\vee A\vee\neg p),\qquad
 (z\vee A\vee\neg p).
$$

Since $A=0$, this forces $z=0$ and $p=0$ uniquely. Apply these cleanups also to every private pad in the source compiler. Every cleanup shares only $A,z$ with the old formula. Each source assignment now has precisely one extension if it satisfies the source and none otherwise. The construction uses elementary CNF equivalences and variable copying. The general gate and extension-variable method for CNF has a long history. [Tseitin, *On the Complexity of Derivation in Propositional Calculus*](https://yurichev.com/mirrors/SAT/Tseitin/Tseitin1968_en.pdf)

## Encoded length and the unrestricted deadline

Let $m$ be the number of distinct proper source clauses after the linear-time normalization above. Then $m\log(m+2)=O(N)$. To see the bit accounting directly, if every variable name in a clause has fewer than $d$ normalized decimal digits there are $O(10^{3d})$ signed triples of such names. Set $d=\lfloor(\log_{10}m)/6\rfloor$. For large $m$ at least half the distinct clauses must therefore use a token of $\Omega(\log m)$ bits each, in separate clause occurrences of the original file. The bounded cases satisfy the estimate as well.

There are $3m$ occurrence variables and at most $6m$ binary implications. The gadgets use $O(m+1)$ clauses and variables in all. Printing fresh consecutive decimal identifiers, even by ordinary digit operations, uses $O((m+1)\log(m+2))$ time and bits with the usual fixed-base word arithmetic. If word division is omitted, precompute the literal strings for these consecutive integers by repeatedly incrementing a decimal digit array, and pay for each emitted digit once. The header counts are equally small. The input scan plus construction thus costs $O(N)$, including on highly duplicated files or very long names. This gives a reduction of SAT on valid proper ternary files to the two-old classes preserving each proposed linear, quadratic or cubic worst-case deadline, up to constant factors. Under the two-clause reduction the verdict is preserved, and under the three-clause reduction the full count is preserved. These reductions do not prove any of those time lower bounds.

On the easy side, iterating a successor that attaches each small batch through one old variable keeps every biconnected block within the proved cap, however long the assembled input becomes. Two arbitrary old contacts can link parts created in unrelated, distant steps. The latter permission is what the equality chains use.
